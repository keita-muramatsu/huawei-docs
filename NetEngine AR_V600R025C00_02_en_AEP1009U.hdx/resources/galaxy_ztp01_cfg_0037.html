Verifying USB-based Deployment

Procedure

  1. Observe the USB indicator on the device to determine the USB-based deployment progress.

    When no USB flash drive is inserted into the device after the device is started:

    • The USB indicator is off.

    After a USB flash drive is inserted into the device:

    • Blinking green: USB-based deployment is in progress.
    • Steady red: USB-based deployment fails.

    When the device restarts after it obtains deployment files and the system specifies files including the system software as the files for next startup:

    • Blinking green: USB-based deployment is in progress.
    • Steady red: USB-based deployment fails.

    During device startup:

    • The USB indicator is off.

    After the device restarts, the system checks whether the files loaded to the device are the same as those in the USB flash drive based on the USB indicator:

    • Steady green: The files are the same and the USB-based deployment succeeds.
    • Steady red: The files are different and the USB-based deployment fails.

  2. After the USB-based deployment is completed, log in to the device to check whether the startup file on the device is the same as the required one.

    display startup

Follow-up Procedure

If deployment fails, analyze USB logs on the device to determine the cause. ZTP-related logs are saved in the ztp_YYYYMMDDHHMMSS.log file in the flash:/ directory and in the ztp_esn_YYYYMMDDHHMMSS.log file in the root directory of the USB flash drive.

You can run the display device esn command to obtain the ESN of a device.
