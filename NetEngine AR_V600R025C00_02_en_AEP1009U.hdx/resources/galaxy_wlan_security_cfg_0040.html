Example for Configuring Authentication in OWE Transition Mode

Networking Requirements

The OWE transition mode provides backward compatibility with STAs that do not support OWE authentication. That is, these STAs access the network in open authentication mode, while OWE-capable STAs access the network in OWE authentication mode. In OWE transition mode, only the AES encryption mode is supported.

The OWE transition mode has no special requirements for networking. Before configuring this security policy, ensure that the network is connected and APs can go online. For details about the basic networking example, see Configuration Examples for WLAN STA Management.

To complete the configuration, you need the following data:

  • AP group name: ap-group1
  • SSID profile name: wlan-ssid; SSID name: wlan-net
  • Security profile 1:
    • Name: wlan-security-open
    • Security policy: open
  • Security profile 2:
    • Name: wlan-security-owe
    • Security policy: OWE transition mode
  • VAP profile 1:
    • Name: wlan-vap-open
  • VAP profile 2:
    • Name: wlan-vap-owe

Configuration Roadmap

  1. Configure STA access services so that STAs can access the WLAN properly.
  2. Configure the OWE transition mode using open authentication and AES encryption in a security profile to ensure data security.

Precautions

  • No ACK mechanism is available for multicast packet transmission over unstable wireless links of air interfaces. For this reason, multicast packets are usually sent at low rates to ensure stable transmission. However, if a large number of multicast packets are sent from the network side, air interfaces may be congested. Therefore, you are advised to configure multicast packet suppression to reduce the impact of numerous low-rate multicast packets on the wireless network. Exercise caution when configuring the rate limit if there are multicast services on the network, as this may affect the multicast services.
    • In direct forwarding mode, you are advised to configure multicast packet suppression on the interfaces of a switch connected to APs.
    For details about the configuration method, see How Do I Configure Multicast Packet Suppression to Reduce Impact of a Large Number of Low-Rate Multicast Packets on the Wireless Network?

  • The port isolation configuration is recommended on the ports of the device directly connected to APs. If port isolation is not configured and direct forwarding is used, a large number of unnecessary broadcast packets may be generated in the VLAN, blocking the network and degrading user experience.

Procedure

  1. Create the SSID profile wlan-ssid and set the SSID name to wlan-net.

    [WAC] wlan
[WAC-wlan] ssid-profile name wlan-ssid
[WAC-wlan-ssid-prof-wlan-ssid] ssid wlan-net
[WAC-wlan-ssid-prof-wlan-ssid] quit

  2. Create the security profile wlan-security-open and configure an open security policy in the profile.

    [WAC-wlan] security-profile name wlan-security-open
[WAC-wlan-sec-prof-wlan-security-open] security open
[WAC-wlan-sec-prof-wlan-security-open] quit

  3. Create the VAP profile wlan-vap-open, set the service data forwarding mode and service VLAN, and bind the security profile wlan-security-open and SSID profile to the VAP profile.

    [WAC-wlan] vap-profile name wlan-vap-open
[WAC-wlan-vap-prof-wlan-vap-open] service-vlan vlan-id 101
[WAC-wlan-vap-prof-wlan-vap-open] security-profile wlan-security-open
[WAC-wlan-vap-prof-wlan-vap-open] ssid-profile wlan-ssid
[WAC-wlan-vap-prof-wlan-vap-open] quit

  4. Create the security profile wlan-security-owe and configure an OWE transition security policy in the profile.

    [WAC-wlan] security-profile name wlan-security-owe
[WAC-wlan-sec-prof-wlan-security-owe] security enhanced-open aes transition-ssid wlan-net
[WAC-wlan-sec-prof-wlan-security-owe] quit

  5. Create the VAP profile wlan-vap-owe, set the service data forwarding mode and service VLAN, and bind the security profile wlan-security-owe and SSID profile to the VAP profile.

    [WAC-wlan] vap-profile name wlan-vap-owe
[WAC-wlan-vap-prof-wlan-vap-owe] service-vlan vlan-id 101
[WAC-wlan-vap-prof-wlan-vap-owe] security-profile wlan-security-owe
[WAC-wlan-vap-prof-wlan-vap-owe] ssid-profile wlan-ssid
[WAC-wlan-vap-prof-wlan-vap-owe] quit

  6. Bind the VAP profiles wlan-vap-open and wlan-vap-owe to radios 0 and 1 of APs in the AP group ap-group1.

    [WAC-wlan] ap-group name ap-group1
[WAC-wlan-ap-group-ap-group1] vap-profile wlan-vap-open wlan 1 radio 0
[WAC-wlan-ap-group-ap-group1] vap-profile wlan-vap-owe wlan 2 radio 0
[WAC-wlan-ap-group-ap-group1] vap-profile wlan-vap-open wlan 1 radio 1
[WAC-wlan-ap-group-ap-group1] vap-profile wlan-vap-owe wlan 2 radio 1
[WAC-wlan-ap-group-ap-group1] quit

 security-profile name wlan-security-open

 vap-profile name wlan-vap-open
  service-vlan vlan-id 101
  ssid-profile wlan-ssid
  security-profile wlan-security-open
 security-profile name wlan-security-owe
  security enhanced-open aes transition-ssid wlan-net
 vap-profile name wlan-vap-owe
  service-vlan vlan-id 101
  ssid-profile wlan-ssid
  security-profile wlan-security-owe

  radio 0
   vap-profile wlan-vap-open wlan 1
   vap-profile wlan-vap-owe wlan 2
  radio 1
   vap-profile wlan-vap-open wlan 1
