Connecting the Deployment Terminal to the Device

Prerequisites

The device has been powered on and has passed the self-check.

Context

The deployment person confirms that a deployment email has been received on the deployment terminal (such as a laptop or PC), installs and starts the device to be deployed onsite, and then connects the deployment terminal to this device using an Ethernet cable for email-based deployment.

The following uses a laptop running Windows 10 as an example to describe how to connect the deployment terminal to the device in wired mode.

Procedure

  1. Connect the laptop to the device's management interface using an Ethernet cable.

    The management interface of a device is usually marked with the Management or MGMT silkscreen. The management interfaces of some device models do not have this silkscreen.

  2. Configure the IP address of the laptop.

    Configure the laptop to automatically obtain an IP address, as shown in Figure 1.

    If the laptop automatically obtains an IP address but cannot ping the IP address of the connected management interface, you can configure a static IP address on the same network segment as this management interface's IP address. If the laptop can ping the management interface IP address successfully, this laptop has been successfully connected to the device.
