Configuring DAI

Context

Dynamic ARP inspection (DAI) allows an AP to detect the ARP Request and Reply packets transmitted on the VAPs, to discard invalid and attack ARP packets, and to send an alarm to the connected WAC. This function prevents ARP packets of unauthorized users from accessing the external network through APs, protecting authorized users against interference or spoofing attacks. Additionally, the DAI function protects an AP's CPU from ARP attacks, which, if not prevented, will interrupt some functions on the AP or even crash the AP.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a VAP profile and enter its view.

    vap-profile name profile-name

    By default, the VAP profile default exists in the system.

  4. Enable DAI.

    arp anti-attack check user-bind enable

    By default, DAI is disabled.

  5. Return to the WLAN view.

    quit

  6. Apply the VAP profile by referring to Binding a VAP Profile to make the configuration take effect.

Verifying the Configuration

Run the display vap-profile { all | name profile-name } command to check the configuration and application of a VAP profile.
