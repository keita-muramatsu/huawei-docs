Querying the Memory Usage

Description of MIB Objects

You can use hwEntityMemUsage in hwEntityStateTable to obtain the memory usage of all entities.

Object

OID

entPhysicalName

1.3.6.1.2.1.47.1.1.1.1.7

hwEntityMemUsage

1.3.6.1.4.1.2011.5.25.31.1.1.1.1.7

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.
  2. Perform the Walk operation on entPhysicalName to query the entity index entPhysicalIndex. As shown in Figure 1, the obtained entity index is 16777217.
    Figure 1 Querying the entPhysicalIndex value through entPhysicalName


  3. Perform the Walk operation on hwEntityMemUsage to query the memory usage of the corresponding entity based on entPhysicalIndex. As shown in Figure 2, the memory usage of the entity with the index 16777217 is 24%.
    Figure 2 Querying the memory usage through hwEntityMemUsage and entPhysicalIndex
