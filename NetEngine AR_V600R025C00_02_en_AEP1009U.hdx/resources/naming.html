Naming Conventions

AR8000 Series

Figure 1 shows naming conventions of AR8000 series routers. Table 1 describes the meaning of each letter and digit.

Figure 1 Naming conventions of AR8000 series routers

Table 1 Naming conventions of AR8000 series routers

Field

Meaning

Description

A

Product name

AR: application and access router

B

Product platform

8: AR8000 product platform

C

Chassis height

Market positioning (applicable only to the AR8700-8)
  • 1: 1 U
  • 2: 2 U
  • 3: 3 U
  • 7: enterprise network market (applicable only to the AR8700-8)

D

(Optional) Maximum number of slots supported by the chassis
  • 2: two slots
  • 4: four slots
  • 6: six slots
  • 8: eight slots
  • 0: 10 slots

E

Product generation

NOTE:

This field is applicable only to 1 U models. The value is fixed at 0 for 2 U/3 U models.

Different hardware platforms

F

(Optional) Additional information about the router

NOTE:

This field starts with a hyphen (-) and specifies supplementary interface descriptions or other possible configurations.
  • nG: The router provides n GE interfaces.
  • nXG: The router provides n 10GE interfaces.
  • 8: The router provides eight subcard slots. (This field is applicable only to the AR8700-8.)
  • T: The router supports trustworthiness measurement.

AR5700 and AR6700 Series

Figure 2 shows naming conventions of AR5700 and AR6700 series routers. Table 2 describes the meaning of each letter and digit.

Figure 2 Naming conventions of AR5700 and AR6700 series routers
Table 2 Naming conventions of AR5700 and AR6700 series routers

Field

Meaning

Description

A

Product name

AR: enterprise router

B

Product platform
  • 6: small and midsize AR
  • 5: micro AR

C

Market positioning
  • 7: enterprise network market

D

Product generation

The first digit indicates the generation and the second digit is fixed at 0.

E

Series and model
  • L: lite edition
  • S: standard edition
  • H: advanced edition

F

Number of interfaces

Number of interfaces

G

Interface type
  • S: GE optical interface
  • T: GE electrical interface/GE combo interface
  • TS: GE combo interface
  • P: PoE interface
  • X: 10GE optical interface
  • Y: 25GE optical interface
  • N: 2.5GE electrical interface
  • W: Wi-Fi interface
  • DS: VDSL 35B
NOTE:
  • T: Refer to the description of the corresponding product model to determine whether the interface type is GE electrical or GE combo interface.
  • P: Refer to the description of the corresponding product model to determine which interfaces are capable of PoE.

H

(Optional) Capability flag

E: performance enhancement

I

(Optional) Support for cards

n: number of supported slots

J

(Optional) Additional information about the router
  • LTEnX: LTE CAT mode and frequency bands in the corresponding area. For example, LTE4EA indicates LTE CAT4 mode and frequency bands in Europe, Middle East, and Africa.
  • T: support for trustworthiness measurement
  • NRGL: Support for 5G NR frequency bands outside China.
