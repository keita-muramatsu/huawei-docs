Example for Using an Advanced ACL to Prevent External Hosts from Accessing an Internal Server

Networking Requirements

As shown in Figure 1, different departments of an enterprise are connected through the switch. The enterprise allows only internal hosts to access the financial server, but prevents external hosts from accessing this server.

Figure 1 Network diagram of using an advanced ACL to prevent external hosts from accessing an internal server

Configuration Roadmap

The configuration roadmap is as follows:

  1. Configure an advanced ACL and ACL-based traffic classifier to filter the packets from external hosts to the financial server, thereby preventing external hosts from accessing this server.
  2. Configure a traffic behavior to permit the packets that match the ACL's permit rules.
  3. Configure and apply a traffic policy for the ACL and traffic behavior to take effect.

Procedure

  1. Add interfaces to VLANs and assign IP addresses to the corresponding VLANIF interfaces.

    # Add 10GE0/0/1, 10GE0/0/2, and 10GE0/0/3 to VLAN 10, VLAN 20, and VLAN 30, respectively. Then add 10GE0/0/4 to VLAN 100, and assign IP addresses to the corresponding VLANIF interfaces. The following uses 10GE0/0/1 and VLANIF 10 as an example. The configurations of 10GE0/0/2, 10GE0/0/3, and 10GE0/0/4 are similar to the configuration of 10GE0/0/1, and the configurations of VLANIF 20, VLANIF 30, and VLANIF 100 are similar to the configuration of VLANIF 10.

    <HUAWEI> system-view
[HUAWEI] sysname Switch
[Switch] vlan batch 10 20 30 100
[Switch] interface 10GE 0/0/1
[Switch-10GE0/0/1] port link-type trunk
[Switch-10GE0/0/1] port trunk allow-pass vlan 10
[Switch-10GE0/0/1] quit
[Switch] interface vlanif 10
[Switch-Vlanif10] ip address 10.164.1.1 255.255.255.0
[Switch-Vlanif10] quit

  2. Configure an advanced ACL.

    # Create advanced ACL 3002 and configure rules to permit the packets from the president office, R&D department, and marketing department to the financial server and deny those from external hosts to this server.

    [Switch] acl 3002
[Switch-acl-adv-3002] rule permit ip source 10.164.1.0 0.0.0.255 destination 10.164.4.4 0.0.0.0
[Switch-acl-adv-3002] rule permit ip source 10.164.2.0 0.0.0.255 destination 10.164.4.4 0.0.0.0
[Switch-acl-adv-3002] rule permit ip source 10.164.3.0 0.0.0.255 destination 10.164.4.4 0.0.0.0
[Switch-acl-adv-3002] rule deny ip destination 10.164.4.4 0.0.0.0
[Switch-acl-adv-3002] quit

  3. Configure an advanced ACL-based traffic classifier.

    # Configure a traffic classifier named c_network to classify packets that match ACL 3002.

    [Switch] traffic classifier c_network 
[Switch-classifier-c_network] if-match acl 3002
[Switch-classifier-c_network] quit

  4. Configure a traffic behavior.

    # Configure a traffic behavior named b_network and set the action to permit (default value).

    [Switch] traffic behavior b_network
[Switch-behavior-b_network] quit

  5. Configure a traffic policy.

    # Configure a traffic policy named p_network and associate c_network and b_network with the traffic policy.

    [Switch] traffic policy p_network
[Switch-trafficpolicy-p_network] classifier c_network behavior b_network
[Switch-trafficpolicy-p_network] quit

  6. Apply the traffic policy.

    # Apply the traffic policy p_network to the outbound direction of 10GE0/0/4 (because all traffic from internal and external hosts is sent from 10GE0/0/4 to the server).

    [Switch] interface 10GE 0/0/4
[Switch-10GE0/0/4] traffic-policy p_network outbound 
[Switch-10GE0/0/4] quit

  7. Verify the configuration.

    # Check the ACL rule configuration.

    [Switch] display acl 3002
Advanced ACL 3002, 4 rules                                                       
Acl's step is 5

 rule 15 permit ip source 10.164.3.0 0.0.0.255 destination 10.164.4.4 0 (0 times matched)       
 rule 20 deny ip destination 10.164.4.4 0 (0 times matched)

    # Check the traffic classifier configuration.

    [Switch] display traffic classifier
  Traffic Classifier Information:    
    Classifier: c_network

         if-match acl 3002                                                    

Total classifier number is 1

    # Check the traffic policy configuration.

    [Switch] display traffic policy p_network
