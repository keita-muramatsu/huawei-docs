Configuring BGP MVPN Peer Relationships

Context

To exchange BGP A-D and BGP C-multicast routes, different PEs on an MVPN must discover other PEs on the MVPN through a process called MVPN membership auto-discovery. An NG MVPN implements this process through BGP, which defines a new address family (BGP-MVPN address family) to support MVPN membership auto-discovery.

On an MVPN using SD-WAN tunnels, PEs are classified into sender PEs and receiver PEs. To transmit multicast traffic from multicast sources to multicast receivers, sender PEs must establish BGP MVPN peer relationships with receiver PEs. Only then can the PEs on the same MVPN use BGP to exchange BGP A-D and BGP C-multicast routes.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the BGP view.

    bgp as-number

  3. Enter the BGP-MVPN address family view.

    ipv4-family mvpn

  4. Configure a BGP MVPN peer.

    peer { ipv4-address | group-name } enable
