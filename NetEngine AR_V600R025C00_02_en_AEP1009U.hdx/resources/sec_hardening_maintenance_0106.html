Weak Security Algorithm/Protocol Feature Package WEAKEA

Overview

As the security performance between protocols or algorithms varies, some protocols or algorithms may pose security risks. For security purposes, you are advised not to use insecure protocols or algorithms. If you need to use them, install the weak security algorithm/protocol feature package WEAKEA. By default, the device provides the weak security algorithm/protocol feature package WEAKEA.

Procedure

  • Install the weak security algorithm/protocol feature package WEAKEA.

    install feature-software WEAKEA

  • Uninstall the weak security algorithm/protocol feature package WEAKEA.

    uninstall feature-software WEAKEA
    • If configurations related to weak security protocols Telnet, FTP, TFTP, TLS 1.0, TLS 1.1, SSHv1, SNMPv1, and SNMPv2c exist in the system, the system displays a message indicating that the weak security protocol feature package fails to be uninstalled. In this case, you need to delete the configurations related to the weak security protocols first.
    • Telnet, FTP, TFTP, TLS 1.0, TLS 1.1, SSHv1, SNMPv1, and SNMPv2c have security risks. You are advised to use SFTP, STelnet, SNMPv3, SSHv2, TLS 1.2, as well as DTLS 1.2 and later versions.
    • After the weak security algorithm/protocol feature package WEAKEA is uninstalled, use secure protocols if you need to use the plug-and-play function.

Example

The following describes how to install and uninstall the weak security algorithm/protocol feature package WEAKEA:

  • Example 1: When the weak security algorithm/protocol feature package WEAKEA is not installed, the FTP function fails to be enabled on the device. After the weak security algorithm/protocol feature package WEAKEA is installed, the FTP function can be enabled.

    # Enable the FTP function on the device. An error message is displayed indicating that the FTP function fails to be enabled.

    <HUAWEI> system-view
[HUAWEI] ftp server enable
Error: This protocol is insecure. To use it, please execute the command "install feature-software WEAKEA".

    # Install the WEAKEA package.

    <HUAWEI> install feature-software WEAKEA
Info: Checking, please wait for a moment...done.
Info: Start to install the package WEAKEA.
Info: Operating, please wait for a moment..This operation will install weak algorithm software, and weak algorithms will be allowed to be used.
.....done.
Info: Succeeded in installing the software.

    # Enable the FTP function on the device again.

    <HUAWEI> system-view
[HUAWEI] ftp server enable
[HUAWEI] quit
  • Example 2: When configurations related to weak security protocols exist in the system, the weak security algorithm/protocol feature package WEAKEA fails to be uninstalled. After these configurations are deleted, the weak security algorithm/protocol feature package WEAKEA can be uninstalled.

    # Run the command for uninstalling the WEAKEA package. If configurations related to weak security protocols exist in the system, the command fails to be executed.

    <HUAWEI> uninstall feature-software WEAKEA
Info: Checking, please wait for a moment...done.
Warning: This will uninstall the package WEAKEA. Continue? [Y/N]:y
Info: Start to uninstall the package WEAKEA.
Info: Operating, please wait for a moment..
Error: WEAKEA feature-related configurations are running in the system. Delete those configurations before performing this operation.
Error: Failed to check before uninstalling the feature software package.

    # Disable the FTP function on the device.

    <HUAWEI> system-view
[HUAWEI] undo ftp server
[HUAWEI] quit

    # Uninstall the WEAKEA package again. The operation succeeds.

    <HUAWEI> uninstall feature-software WEAKEA
Info: Checking, please wait for a moment...done.
Warning: This will uninstall the package WEAKEA, Continue? [Y/N]:Y
Info: Start to uninstall the package WEAKEA.
Info: Operating, please wait for a moment......................................done.
Info: Succeeded in uninstalling the software.

Verifying the Security Hardening Result

Run the display startup or display startup feature-software command to check whether the displayed information is the same as the name of the desired feature software package.
