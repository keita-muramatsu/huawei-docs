Exception in the PoE Power Supply of a PD Connected to an RU

Symptom

A powered device (PD), such as an AP, phone, or camera connected to an RU cannot be powered on.

Possible Causes

  • The power of the RU is insufficient.
  • The PoE configuration of the RU is incorrect.
  • XLDP is not enabled on the central device.
  • The PD is a non-standard PD.

Procedure

  1. Check the PoE information about RUs and check whether the power is sufficient.

    # Run the display remote-unit poe command to check RU PoE information. Check whether the power is sufficient and whether the voltage is normal. For example, if the total power is 60 W and the voltage is about 50 V, the power is normal.

  4. For non-standard PDs, configure forcible power supply or change the power supply mode.

    # If a non-standard PD cannot be powered on, run the poe force-power port number command to enable forcible power supply for the interface or run the poe af-inrush enable port number command to configure the power supply mode for the interface. [HUAWEI-remote-unit-3] poe force-power port 1
[HUAWEI-remote-unit-3] poe af-inrush enable port 2
[HUAWEI-remote-unit-3] commit
[HUAWEI-remote-unit-3] quit
