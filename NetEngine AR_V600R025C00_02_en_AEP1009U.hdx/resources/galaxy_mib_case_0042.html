Querying Information About LLDP Neighbors

Description of MIB Objects

You can use the following objects to obtain information about LLDP neighbors.

Object

OID

lldpStatsRemTablesLastChangeTime

1.0.8802.1.1.2.1.2.1

lldpStatsRemTablesInserts

1.0.8802.1.1.2.1.2.2

lldpStatsRemTablesAgeouts

1.0.8802.1.1.2.1.2.5

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.

  2. Perform the Walk operation on lldpStatsRemTablesLastChangeTime to query the time of the last change in LLDP neighbor information. As shown in Figure 1, the time of the last change in LLDP neighbor information is 0 days 03h:58m:17s.91th.

    Figure 1 Querying the time of the last change in LLDP neighbor information

  3. Perform the Walk operation on lldpStatsRemTablesInserts to query the number of added LLDP neighbors. As shown in Figure 2, 1 LLDP neighbor is added.

    Figure 2 Querying the number of added LLDP neighbors

  4. Perform the Walk operation on lldpStatsRemTablesAgeouts to query the number of LLDP neighbors deleted due to information aging. As shown in Figure 3, 0 LLDP neighbors are deleted due to information aging.

    Figure 3 Querying the number of LLDP neighbors deleted due to information aging
