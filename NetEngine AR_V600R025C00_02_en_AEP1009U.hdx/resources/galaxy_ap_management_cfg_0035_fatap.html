Checking AP Hardware Information

Procedure

  • Run the display ap optical-info ap-id ap-id command to check optical module information about an AP.
  • Run the display ap fan ap-id ap-id command to check fan information about an AP.
  • Run the display ap power ap-id ap-id command to check power supply information about an AP.
