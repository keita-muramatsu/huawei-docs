Defense Against ICMP Flood Attacks

Overview

A network administrator typically monitors a network and rectifies faults using the ping tool as follows:

  1. The source host sends an ICMP Echo message to a target device.
  2. Upon receiving the ICMP Echo message, the target device sends an ICMP Echo Reply message to the source host.

As shown in Figure 1, if the target device receives many ICMP Echo messages from an attacker, it becomes occupied and unable to process other data packets. As a result, normal services are affected.

Figure 1 ICMP flood attack

Figure 2 shows how the device resists ICMP flood attacks. With defense against ICMP flood attacks enabled, the device rate-limits ICMP messages to ensure that system resources are not exhausted when the device is attacked.

Figure 2 Defense against ICMP flood attacks

Impact on the System

None

Procedure

  1. Enter the system view.

    system-view

  2. Enable defense against ICMP flood attacks.

    anti-attack icmp-flood enable

    You can also run the anti-attack enable command in the system view to enable attack defense against all attack packets, including ICMP flood attack packets.

  3. Configure the rate limit for ICMP flood attack packets.

    anti-attack icmp-flood car cir cir-num

Checking the Security Hardening Result

Run the display anti-attack statistics icmp-flood command to check statistics relating to defense against ICMP flood attacks.
