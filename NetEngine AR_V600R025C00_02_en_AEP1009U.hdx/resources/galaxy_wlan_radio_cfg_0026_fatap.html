Configuring User CAC

Prerequisites

Before configuring user CAC, you have completed the following task:

  • Configure AP onboarding and STA access.

Context

On WLANs where many users exist, such as WLANs in high density scenarios, users compete fiercely to occupy resources as the number of online users increases. As a result, network quality deteriorates. To ensure network access experience of online users, you can configure the user CAC function. This function allows an AP to control user access based on the number of online users or the terminal SNR, which enables provisioning of high-quality network access services.

CAC can be implemented in the following modes:
  • User CAC based on the number of users uses a simple algorithm. This mode is recommended when most users have the same service type and similar service traffic volumes.
  • SNR-based user CAC controls access from weak-signal users, and is applicable to scenarios where the WLAN has good signal coverage and weak signals only at the edge of WLAN coverage areas.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an RRM profile and enter its view.

    rrm-profile name profile-name

  4. Configure the CAC implementation mode and threshold, and enable CAC.

    The two user CAC modes (based on the number of users and based on the terminal SNR) can be configured together.

    • Configure CAC based on the number of users.
      1. Enable CAC based on the number of users.
        uac client-number enable

        By default, the user CAC function is disabled.

      2. Configure the CAC threshold based on the number of STAs.
        uac client-number threshold access access-threshold [ roam roam-threshold ]

        By default, the user CAC access and roaming thresholds based on the number of users are both 64. Ensure that the roaming threshold (roam-threshold) is greater than or equal to the access threshold (access-threshold).

    • Configure CAC based on the terminal SNR.
      1. Enable CAC based on the terminal SNR.
        uac client-snr enable
      2. Configure the CAC threshold based on the terminal SNR.
        uac client-snr threshold threshold

        By default, the user CAC threshold based on the terminal SNR is 15 dB.

  5. (Optional) Configure the action to be taken to control subsequent access users after the number of access users reaches the threshold.

    uac reach-access-threshold { hide-ssid | priority-replace }

    By default, after the number of access users reaches the threshold, the SSID is not hidden, and existing access users are not replaced based on priorities.

  6. Return to the WLAN view.

    quit

  7. Bind the RRM profile to a radio profile.

    1. Bind the profile to a 2.4 GHz radio profile.
      radio-2g-profile name profile-name
rrm-profile profile-name
    2. Bind the profile to a 5 GHz radio profile.
      radio-5g-profile name profile-name
rrm-profile profile-name

  8. Bind the radio profile.

    For details, see Binding a Radio Profile.

Verifying the Configuration

Run the display rrm-profile name profile-name command to check the user CAC configuration.
