Configuring ACL Information Push

Prerequisites

ACL information push can be configured only for the following types of IPsec policies that use IKEv1 negotiation:

  • ISAKMP IPsec policies
  • Template IPsec policies

Context

When the headquarters and branch establish an IPsec tunnel using ACLs, to simplify ACL configuration and maintenance in the branch, you can configure the ACL information push function on the headquarters device. This function allows the headquarters device to push ACL information to the branch device after the first-phase IKE SA is established between the two devices and the headquarters device receives a request from the branch device to obtain ACL information. The ACL defines the range of traffic that can be sent from the branch to the headquarters. The branch traffic whose destination address is not in the range defined by the pushed ACL will not be transmitted through the IPsec tunnel.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the IKE peer view.

    ike peer peer-name

  3. Configure the ACL information push function.

    resource acl acl-number

    By default, ACL information push function is not configured.

    acl-number specifies an existing advanced ACL.
