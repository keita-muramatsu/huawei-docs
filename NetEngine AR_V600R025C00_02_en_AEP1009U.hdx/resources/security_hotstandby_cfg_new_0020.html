Configuring Monitored Items

Prerequisites

Before configuring hot standby, ensure that the device meets the following requirements:

  • The two devices that form a hot standby group are recommended to be of the same model.
  • The system software versions and patch versions of the two devices that form a hot standby group must be the same. Note that the two devices can temporarily run different versions of system software during version upgrade or rollback. For example, one device can run the software version V*R*C00, while the other runs V*R*C00SPC100. However, after the upgrade or rollback is complete, you must ensure that both devices run the same version of system software.
  • The active and standby devices must use the same service and heartbeat interfaces. For example, if the active device uses 10GE 0/0/1 as a service interface and 10GE 0/0/4 as a heartbeat interface, the standby device must do so too.

Before configuring monitored items, you must understand the impact of each monitored item on device priorities and the relationship between monitored items. For details, see Device Priority and Fault Monitoring.

Procedure

  1. Enter the system view.

    system-view

  2. Configure the device to monitor interfaces.

    hrp track interface interface-type interface-number

    Configure the device to directly monitor an interface. You can also configure a VRRP group in the interface view to monitor the interface. For details about how to configure VRRP, see CLI Configuration Guide > High Availability Configuration > VRRP Configuration.

  3. Configure the device to monitor Eth-Trunk member interfaces.

    hrp track trunk-member enable

    By default, this function is enabled. That is, you do not need to configure member interfaces to be monitored.

  4. Configure the device to monitor a static BFD session.

    hrp track bfd-session local-discr-value

    Before configuring the device to monitor a static BFD session, configure this session. For details about how to configure a BFD session, see "Configuring Single-Hop or Multi-Hop BFD" in CLI Configuration Guide > High Availability Configuration > BFD Configuration.

    The device can monitor only static BFD sessions whose local discriminators are manually specified using local-discr-value. This is because the local discriminators of dynamic BFD sessions and the automatically allocated local discriminators of static BFD sessions change when the two devices perform renegotiation.
