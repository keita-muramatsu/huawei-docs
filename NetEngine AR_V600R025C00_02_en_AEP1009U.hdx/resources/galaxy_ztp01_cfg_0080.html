Example for Configuring DHCP-based Deployment (with a Controller)

Networking Requirements

In Figure 1, DeviceA and DeviceB are two unconfigured devices on the network, and both are connected to DeviceC, which functions as the egress gateway of DeviceA and DeviceB. DeviceC has reachable routes with both the DHCP server and controller.

The customer requires that DeviceA and DeviceB automatically load the system software and configuration files after they are powered on to reduce labor costs and device deployment time.
Figure 1 Network diagram for DHCP-based deployment (with a controller)

In this example, interface1, interface2, and interface3 represent 10GE0/0/1, 10GE0/0/2, and 10GE0/0/3, respectively.


Configuration Roadmap

The configuration roadmap is as follows:

  1. Add DeviceA and DeviceB on the controller.
  2. Configure the DHCP server.
  3. Configure the DHCP relay agent.
  4. Power on DeviceA and DeviceB to start the ZTP process.

Procedure

  1. Add DeviceA and DeviceB on the controller. For details, see SD-WAN Solution & iMaster NCE-Campus Product Documentation.
  2. Configure the DHCP server.

    # Configure the IP address pool that the DHCP server uses to allocate IP addresses to clients and set DHCP Options by referring to Table 1. In this example, a Huawei device is used as the DHCP server.

    Table 1 DHCP Options

    Option

    Description

    Value

    Option 1

    Subnet mask of an IP address.

    255.255.255.0

    Option 3

    Egress gateway of a DHCP client.

    10.1.1.1

    Option 148

    IP address and port number of the controller.

    agilemanage-mode=ip;agilemanage-domain=10.1.3.2;agilemanage-port=10020

    		 
    <HUAWEI> system-view
[HUAWEI] sysname dhcp_server
[dhcp_server] dhcp enable
[dhcp_server] ip pool pool1
[dhcp_server-ip-pool-pool1] gateway-list 10.1.1.1
[dhcp_server-ip-pool-pool1] network 10.1.1.0 mask 255.255.255.0
[dhcp_server-ip-pool-pool1] option 148 ascii agilemanage-mode=ip;agilemanage-domain=10.1.3.2;agilemanage-port=10020
[dhcp_server-ip-pool-pool1] quit
[dhcp_server] vlan batch 10
[dhcp_server] interface 10ge 0/0/3
[dhcp_server-10GE0/0/3] portswitch
[dhcp_server-10GE0/0/3] port link-type trunk
[dhcp_server-10GE0/0/3] port trunk allow-pass vlan 10
[dhcp_server-10GE0/0/3] quit
[dhcp_server] interface vlanif 10
[dhcp_server-Vlanif10] ip address 10.1.2.2 24
[dhcp_server-Vlanif10] quit

  3. Configure the DHCP relay agent.

    # Configure the DHCP relay function on DeviceC. Set the IP address of the interface connecting DeviceC to DeviceA and DeviceB to 10.1.1.1 to configure DeviceC as the default gateway of DeviceA and DeviceB.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceC
[DeviceC] vlan batch 10
[DeviceC] interface 10ge 0/0/1
[DeviceC-10GE0/0/1] portswitch
[DeviceC-10GE0/0/1] port link-type trunk
[DeviceC-10GE0/0/1] port trunk allow-pass vlan 10
[DeviceC-10GE0/0/1] port trunk pvid vlan 10
[DeviceC-10GE0/0/1] quit
[DeviceC] interface 10ge 0/0/2
[DeviceC-10GE0/0/2] portswitch 
[DeviceC-10GE0/0/2] port link-type trunk
[DeviceC-10GE0/0/2] port trunk allow-pass vlan 10
[DeviceC-10GE0/0/2] port trunk pvid vlan 10
[DeviceC-10GE0/0/2] quit
[DeviceC] interface vlanif 10
[DeviceC-Vlanif10] ip address 10.1.1.1 24
[DeviceC-Vlanif10] quit
[DeviceC] dhcp enable
[DeviceC] interface vlanif 10
[DeviceC-Vlanif10] dhcp select relay
[DeviceC-Vlanif10] dhcp relay server-ip 10.1.2.2

  4. Power on DeviceA and DeviceB to start the ZTP process.

Verifying the Configuration

After the ZTP process is completed, you can then log in to the devices to check the status of the NETCONF connections between the devices and controller. If the status is successful, the ZTP process is successful. The following uses the command output on DeviceA as an example.

<DeviceA> display netconf session
------------------------------------------------------------------------------------------------------------------------------------
NETCONF Session ID   : 18265
Transport            : netconf-ssh
User Name            : huawei
Host Identifier      : 10.1.1.1
Login Time           : 2019-09-17 17:37:02
Input Rpc            : 755
Input Bad Rpc        : 1
Output Rpc Error     : 12
Output Notification  : 0
------------------------------------------------------------------------------------------------------------------------------------
