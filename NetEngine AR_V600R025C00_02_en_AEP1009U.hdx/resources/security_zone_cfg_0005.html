Configuring a Security Zone

Context

Security zones on devices are classified into predefined security zones and customized security zones. To assign a security level that is not specified by predefined security zones to a network, you can customize a security zone on a device and set the priority for the security zone. After the security zone is created, you need to add interfaces to it. Then the packets sent or received by the interfaces are considered to be sent or received by the security zone.

Procedure

  1. Enter the system view.

    system-view

  2. Create a security zone and enter the security zone view.

    firewall zone [ name ] zone-name

    Determine whether to configure the name parameter as follows:

    • If the security zone already exists, you do not need to specify the name parameter.

    • If the security zone does not exist, specify the name parameter in the command to create the security zone and enter the security zone view. In addition, you can run the firewall zone name zone-name id id command to specify the ID of the security zone. If no ID is specified, the system automatically assigns an available ID to the created security zone.

    For a predefined security zone (which cannot be deleted), you can run the firewall zone zone-name command to enter the security zone view.

  3. Configure the description of the security zone.

    description description-text

    To facilitate identification and maintenance of a customized security zone, you can configure a description for it.

  4. (Optional) Configure the priority for the security zone.

    set priority security-priority

    By default, a customized security zone does not have a priority.

    A larger value indicates a higher priority.

  5. Add interfaces to the security zone.

    add interface interface-type { interface-number | interface-number.subinterface-number }

    The MEth management interface does not belong to any security zone and cannot be added to any security zone. An interface can be added to only one security zone. You can run this command multiple times in a security zone to add multiple interfaces to the security zone.

    The Local zone defines a device itself, including the interfaces on the device.

    • No interface can be added to the Local zone.
    • Adding an interface to a security zone except the Local zone means configuring the network connected to the interface to be part of the security zone, but the interface still belongs to the Local zone.

Verifying the Security Zone Configuration

Run the display zone [ zone-name ] [ interface | priority ] command to check configuration information about the security zone.

Follow-up Procedure

Configure security zone-based policies to control the traffic transmitted between different security zones.
