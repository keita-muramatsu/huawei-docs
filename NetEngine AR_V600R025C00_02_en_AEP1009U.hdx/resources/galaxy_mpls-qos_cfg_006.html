Configuring Priority Mapping

Context

The process of configuring the priority mapping function is as follows:

  1. Configure the priority trust mode for the device to perform mapping based on EXP values on an MPLS network.
  2. Configure a DiffServ domain to determine mappings between EXP values and internal priorities so that the device can provide differentiated services based on internal priorities.
  3. Apply the DiffServ domain to an object so that the mappings in the DiffServ domain take effect.
