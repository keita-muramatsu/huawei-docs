Adjusting Security Policy Rules

Context

You can rename, move, copy, enable, or disable the configured security policy rules.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the security policy view.

    security-policy

  3. Adjust rules.

    To...

    Run...

    Description

    Rename a rule

    rule rename old-name new-name

    An existing security policy rule can be renamed.

    Move a rule

    rule move rule-name1 { up | down | top | bottom }

    rule move rule-name1 { after | before } rule-name2

    Generally, an earlier configured rule has a higher priority. You can run the rule move command to move a rule to change its priority.

    Copy a rule

    rule copy rule-name new-rule-name

    If a rule you want to create is similar to an existing rule, you can run the rule copy command to clone the existing rule as a new rule.

    Enable or disable the current rule

    rule name rule-name

    enable / disable

    You can enable or disable a rule in the corresponding rule view.
