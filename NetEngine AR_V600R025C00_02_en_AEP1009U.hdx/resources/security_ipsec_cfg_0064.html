Configuring the Maximum Number of IKE SAs to Be Negotiated

Prerequisites

The maximum number of IKE SAs to be negotiated takes effect only for the following IPsec:

  • ACL-based IPsec (involving ISAKMP IPsec policies and template IPsec policies)
  • Route-based IPsec (involving IPsec profiles)

Context

You can set the maximum number of IKE SAs to be negotiated to prevent DoS attacks initiated by external networks on IKE SA negotiation.

Procedure

  1. Enter the system view.

    system-view

  2. Set the maximum number of IKE SAs to be negotiated on a single CPU.

    ike call admission limit in-negotiation-sa limit-value

    By default, the maximum number of IKE SAs to be negotiated on a single CPU is 2048.
