Disabling Interfaces on an RU

Context

RU interfaces are enabled by default. When an interface on an RU is not connected to a cable or fiber, you are advised to disable it to prevent exceptions caused by interference.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the single RU view.

    remote-unit { id | connect-interface interface-type interface-number | name remote-unit-name }

  3. Disable the corresponding downlink interface.

    shutdown port { port-id1 [ to port-id2 ] } &<1-32>

  4. Deliver the configuration to the RU.

    commit
