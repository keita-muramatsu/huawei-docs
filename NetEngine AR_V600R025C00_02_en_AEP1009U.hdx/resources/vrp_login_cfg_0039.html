What Can I Do If I Forget the Password for Console Port Login?

Fault Description

If you forget the password for logging in through the console port, use either of the following methods to set a new password.

Procedure

  • Logging in to the device through STelnet or Telnet to set a new console port login password

    The following uses the example of logging in to the device using STelnet to change the console port login password. After logging in to the device through STelnet, perform the following operations.

    # Password authentication is used as an example. Set the new password to YsHsjx_202206.

    <HUAWEI> system-view
[HUAWEI] user-interface console 0
[HUAWEI-ui-console0] authentication-mode password
[HUAWEI-ui-console0] set authentication password cipher YsHsjx_202206
[HUAWEI-ui-console0] user privilege level 3
[HUAWEI-ui-console0] quit
[HUAWEI] quit
<HUAWEI> save

    # AAA authentication for user interface login is used as an example. Set the user name and password to admin123 and YsHsjx_202206, respectively.

    <HUAWEI> system-view
[HUAWEI] user-interface console 0
[HUAWEI-ui-console0] authentication-mode aaa
[HUAWEI-ui-console0] user privilege level 3
[HUAWEI-ui-console0] quit
[HUAWEI] aaa
[HUAWEI-aaa] local-user admin123 password
Please configure the login password (8-128)
It is recommended that the password consist of four types of characters, including lowercase letters, uppercase letters, numerals and special characters. 
Please enter password:                                      
Please confirm password:                               
[HUAWEI-aaa] local-user admin123 privilege level 3
[HUAWEI-aaa] local-user admin123 service-type terminal
[HUAWEI-aaa] quit
[HUAWEI] quit
<HUAWEI> save

  • Clearing the console port login password through the BootLoader menu

    You can use the BootLoader menu to clear the console port login password and save the configuration after starting the device and changing the password. For details, see Example for Clearing the Console Port Login Password Through the BootLoader Menu.
