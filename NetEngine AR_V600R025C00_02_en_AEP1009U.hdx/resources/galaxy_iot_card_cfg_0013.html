Configuring an IoT Card Based on the Container

Prerequisites

A container has been loaded on the AP. For details, see Installing or Uninstalling a Container on an AP.

Context

To install a USB card on an AP, you need to first enable the USB function of the AP. For details, see Configuring the USB Function for APs.

To install a PCIe card on an AP, you need to first enable the PCIe function of the AP. For details, see the power enable command.

For the built-in Bluetooth module, you need to first set the Bluetooth working mode of the AP to IoT. For details, see Configuring the Bluetooth Working Mode for an AP.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an IoT profile and enter its view.

    iot-profile name profile-name

    By default, no IoT profile is created.

  4. Configure the domain name, IP address, and port number of the host computer.

    management-server { domain domain-name | server-ip server-ip } server-port server-port-num [ ext-channel ]

    By default, no host computer is configured.

  5. Return to the WLAN view.

    quit

  6. Set the connection type between IoT cards and APs to container.

    The configurations take effect in the following views listed in descending order of priority: IoT card interface view of an AP, IoT card interface view of an AP group, AP system profile view.

    • Configuration in the IoT card interface view of an AP group or a single AP
      1. Enter the AP view or AP group view.
        • Enter the AP group view.
          ap-group name group-name
        • Enter the AP view.
          ap-id ap-id
      2. Enter the IoT card interface view.
        card { card-number | usb | ble }
      3. Set the connection type between IoT cards and APs to container.
        card connect-type container

        By default, the connection type between IoT cards and APs is serial.

      4. Bind the IoT profile and configure the local port number mapping to the IoT card interface.
        iot-profile profile-name config-agent { tcp | udp } [ port port ] [ ext-port ext-port ]

        By default, no IoT profile is bound to an IoT card interface.

        A port number within the range from 50200 to 50202 is recommended. If another port number is used, a port conflict may occur, which generates an alarm.

    • Configuration in the AP system profile view
      1. Create an AP system profile and enter its view.
        ap-system-profile name profile-name

        By default, the AP system profile default exists on the device.

      2. Set the connection type between IoT cards and APs to container.
        card connect-type container

        By default, the connection type between IoT cards and APs is serial.

      3. Return to the WLAN view.
        quit
      4. Enter the AP view or AP group view.
        • Enter the AP group view.
          ap-group name group-name
        • Enter the AP view.
          ap-id ap-id
      5. Bind the AP system profile to an AP group or a single AP.
        ap-system-profile profile-name

        By default, the AP system profile default is bound to an AP group, but no AP system profile is bound to an AP.

      6. Enter the IoT card interface view.
        card { card-number | usb | ble }
      7. Bind the IoT profile and configure the local port number mapping to the IoT card interface.
        iot-profile profile-name config-agent { tcp | udp } [ port port ] [ ext-port ext-port ]

        By default, no IoT profile is bound to an IoT card interface.

        A port number within the range from 50200 to 50202 is recommended. If another port number is used, a port conflict may occur, which generates an alarm.

Verifying the Configuration

  • Run the display ap-card all command to check brief information about cards on APs.
  • Run the display ap ap-id card { all | card-number | usb | ble } command to check detailed information about cards on an AP.
  • Run the display ap-card statistics { all | ap-id ap-id [ card { card-number | usb | ble } ] } command to check statistics about packets sent and received by cards on APs.
