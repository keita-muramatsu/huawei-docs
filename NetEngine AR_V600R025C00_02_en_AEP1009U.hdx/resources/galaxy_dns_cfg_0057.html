Configuring DNS Relay/Proxy

Prerequisites

Before configuring DNS relay/proxy, you have configured the IP address of the DNS server or the local domain name resolution table on the DNS relay agent/proxy agent. For configuration details, see Configuring Dynamic Domain Name Resolution and Configuring Static Domain Name Resolution.

Procedure

  1. Enter the system view.

    system-view

  2. Enable DNS relay.

    • Enable IPv4 DNS relay.
      dns relay enable
    • Enable IPv4 DNS proxy.
      dns proxy enable
    • Enable IPv6 DNS relay.
      dns relay ipv6 enable
    • Enable IPv6 DNS proxy.
      dns proxy ipv6 enable

  3. (Optional) Configure an IP address for the DNS relay agent to communicate with a DNS client. The DNS relay agent processes only DNS request packets destined for this IP address and uses it as the source IP address in DNS reply packets.

    • Configure an IPv4 address for the DNS relay agent to communicate with a DNS client.
      dns server bind local-ip ip-address [ vpn-instance vpn-instance-name ]
    • Configure an IPv6 address for the DNS relay agent to communicate with a DNS client.
      dns server bind local-ip ipv6 ipv6-address [ vpn-instance vpn-instance-name ]

    By default, no IP address is configured for a DNS relay agent to communicate with a DNS client.

  4. (Optional) Configure the DNS resolution policy function.

    After the DNS resolution policy function is configured, an administrator can allow users to access only specified domain names or websites.

    1. Enable the DNS resolution policy function for class A or AAAA query requests.

      dns resolve policy { a | aaaa } enable

      By default, the DNS resolution policy function is disabled for class A or AAAA query requests.

    2. Enter the DNS resolution policy view.

      dns resolve policy

    3. Configure a DNS resolution rule.

      rule rule-id [ if-match name name ] { deny | permit | spoofing { ip-address | ipv6-address }* }

      By default, no DNS resolution rule is configured.

  5. (Optional) Configure the DNS proxy agent to forward all reply packets from the DNS server to a DNS client.

    dns proxy [ ipv6 ] forward-any-response

    By default, the DNS proxy agent forwards only the reply packets that are successfully resolved by the DNS server to a DNS client.
