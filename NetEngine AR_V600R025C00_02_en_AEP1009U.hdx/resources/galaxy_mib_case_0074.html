Querying the STP Type

Description of MIB Objects

hwMstpForceVersion describes the STP type. It describes the STP type in process 0 when there are multiple processes. The value 0 indicates STP, the value 2 indicates RSTP, and the value 3 indicates MSTP.

hwMstpProTable describes MSTP process information, including the enabling status, priority, and root bridge type. You can use hwMstpProForceVersion in hwMstpProTable to obtain the STP types of all processes. The value 0 indicates STP, the value 2 indicates RSTP, and the value 3 indicates MSTP.

Object

OID

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.
  2. Use either of the following methods to query the STP type:
    • Perform the Get operation on hwMstpForceVersion to query the STP type.
      Figure 1 Querying the STP type
    • Perform the Walk operation on hwMstpProForceVersion to query the STP type.
      Figure 2 Querying the STP type
