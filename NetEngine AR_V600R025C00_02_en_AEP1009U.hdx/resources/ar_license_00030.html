Introduction to N1 Licenses

Definition

N1 refers to IDN One Software, which is an innovative business model introduced in Huawei CloudCampus Solution. This business model decouples the purchase of campus network software from hardware, which simplifies software transaction. By flexibly packing software of Huawei CloudCampus Solution components, a variety of N1 software packages are provided to meet typical requirements. These software packages can be migrated to new hardware to support continuous evolution and protect your investment.

N1 software packages adopt the "perpetual license + SnS" business model. A perpetual license is sold together with SnS services, such as software patches, software upgrades (including new features of new releases), and remote support. SnS services are priced based on the same measurement units as those of licenses, and customers periodically pay for SnS services as required. In this way, the long-term values of software products throughout the lifecycle are achieved. When Huawei sells a software product to a customer for the first time, the customer has to buy both the license and SnS services that are valid for a certain period of time. If the customer does not renew the SnS upon expiry, the customer can only use the licensed functions of the current software version, and can no longer use the SnS services.

Purpose

In the traditional model, licenses are sold independently and customers need to purchase different licenses or license packages based on their service requirements. These licenses take effect permanently. However, if new functions or features are required, customers need to purchase new licenses.

In the N1 model, software packages are sold as a whole based on solution scenarios. Within the SnS validity period, if the purchased software packages have new functions, customers can upgrade the license files on the ESDP to obtain new N1 licenses. After selecting N1 software packages based on their service requirements, customers do not to need purchase them again. This reduces the overall purchase cost and protects customer investments.

Using N1 Software Packages

Applying for an N1 software package license: After a customer purchases an N1 software package, the license authorization certificate contains the entitlement IDs of different product components based on the solution scenarios. The customer can apply for the license of a specific product component on the ESDP based on the entitlement ID.

Installing an N1 software package license: Customers need to install and activate licenses of product components on the components.

SnS control items: By purchasing SnS services, customers can obtain the latest product technologies and ensure the secure and reliable running of software. After SnS services expire, if the customer does not renew SnS, Huawei will no longer provide the software and services within the SnS. The SnS services include:
  • Upgrade: involves new software versions and software patches, including the upgrade of certain features of an existing version and excluding on-site services required for version upgrades (such as installation, commissioning, and integration).
  • Maintenance: Huawei provides customers with hotlines, responds to customers within the specified time, records, analyzes, answers customers' questions and inquiries about software usage, and provides consultation, reply, and knowledge sharing on the website or through emails.
  • Migration: Licenses can be migrated between different versions and different devices.

Precautions for Using N1 Software Packages

N1 software packages need to be activated only on iMaster NCE-Campus, but not on routers.
