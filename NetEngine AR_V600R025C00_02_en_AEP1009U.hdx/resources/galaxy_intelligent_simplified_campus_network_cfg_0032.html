RU Authentication Failure

Symptom

  • After the display remote-unit verbose command is run in the user view of the central device to check information about a connected RU, the following information is displayed (showing that Version match is NO and Authen Result is Fail):

Total number: 1

POE version          : 7692

  • After the display alarm active command is run in the user view of the central device to query alarms, the following information is displayed:
    <HUAWEI>display alarm active          
----------------------------------------------------------------------------------------------
Sequence   AlarmId    Severity    Date Time    Description                            
---------------------------------------------------------------------------------------------- 
62        0x4092014    Major      2023-04-26   The authentication to the remote unit failed.          
                                   07:47:36    (RemoteUnitEsn=QU2276013135) 
61        0xF1FFFF     Major      2023-04-26   Remote unit certificate version does not match                                
                                   07:47:36    the central switch. (RemoteUnitEsn=QU2276013135)
  • Configurations cannot be delivered to an RU, such as restarting the RU, configuring interface isolation, and adding an RU interface to a VLAN. For example, running the reboot all command in the RU view cannot restart the RU; instead, the following error information is displayed:
    [HUAWEI-remote-unit]reboot all  
Warning: This Command will restart the remote-unit. Continue? [Y/N]:y 
Error: Unable to restart the device QU2276013135, please check the authentication state.

Possible Causes

  • The firmware version of the RU is too early. The RU can be managed by the central device running V600R023C00 or later only after being upgraded.

Procedure

The firmware version of the RU is too early. The RU can be managed by the central device running V600R023C00 or later only after being upgraded.

Scenario 1: A central device running V200R022C00 or later is available.

  1. Connect the RU running an earlier version to the central device running V200R022C00 or later. Then, run the upgrade right-now command. After the RU is upgraded and restarted, it can be connected to a central device running V600R023C00 or later.

    <HUAWEI> system-view
[HUAWEI] remote-unit
[HUAWEI-remote-unit]upgrade right-now  
Warning: After the upgrade is successful, the connected RUs will restart, causing service interruption. Do not power off the RUs during the upgrade. Otherwise, they may fail to start.  
Continue? [Y/N]:y

Scenario 2: No central device running V200R022C00 or later is available, and the RU uses local power supply.

  1. Run the upgrade right-now command to upgrade the RU.

    <HUAWEI> system-view
[HUAWEI] remote-unit
[HUAWEI-remote-unit]upgrade right-now  
Warning: After the upgrade is successful, the connected RUs will restart, causing service interruption. Do not power off the RUs during the upgrade. Otherwise, they may fail to start.  
Continue? [Y/N]:y

  2. (Optional) Run the display remote-unit upgrade information command to check the upgrade progress.

    [HUAWEI-remote-unit]display remote-unit upgrade information  
Firmware information:  
--------------------------------------------------------------------------------

--------------------------------------------------------------------------------

S5731              POE        POE            7812               Startup software
S5731              BIOS       BIOS           231214011          Startup software

Remote-unit during cooling down:
--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
--------------------------------------------------------------------------------

Upgrading remote-unit information:
--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
S5731-L8T2ST-RUA       10GE0/0/1                 APP        3%
--------------------------------------------------------------------------------

  3. Run the display remote-unit upgrade record command to check the status of uploading the system software package. It may take several minutes for the upload to complete.

    [HUAWEI-remote-unit]display remote-unit upgrade record  
-----------------------------------------------------------------------------

----------------------------------------------------------------------------- 
2023/04/26 07:59:47    10GE0/0/1                  POE        Success             
2023/04/26 07:59:23    10GE0/0/1                  APP        Success             
-----------------------------------------------------------------------------

  4. Restart the RU. Manually power off the RU from the equipment room. After 10 seconds, manually power on the RU so that it restarts to load the new firmware.
  5. After the RU is restarted, run the display remote-unit verbose command to check whether the authentication is successful and whether the firmware version is the new version.
