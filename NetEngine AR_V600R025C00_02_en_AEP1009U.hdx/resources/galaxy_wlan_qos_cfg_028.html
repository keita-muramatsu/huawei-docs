Configuring the Intelligent Multimedia Scheduling Algorithm

Prerequisites

Before performing the configuration, you have completed the following tasks:

  • Configure AP onboarding and STA access.
  • Enable the WMM function. To enable WMM, run the undo wmm disable command. By default, WMM is enabled. The 6 GHz frequency band is supported since 802.11ax. The WMM function on the 6 GHz frequency band cannot be disabled. That is, the wmm disable command does not take effect on the 6 GHz frequency band.
  • Ensure that the traffic has been identified as VI/VO traffic in one of the following ways:
    • Priority carried by the traffic
    • Manually adjusted priority mapping
    • DFI function
  • Only some AP models support this function. You can visit Info-Finder (enterprise network, carrier), search for the target AP model, and check whether the AP supports this function based on the specifications.
  • For APs that do not support the intelligent multimedia scheduling algorithm, if both upload/download and multimedia services are running on the live network, you are advised to run the rate-limit client { up | down } rate-value command to configure static rate limiting for users. It is recommended that the uplink and downlink static rate limits for each user be set to 40 Mbit/s (40000 kbit/s) to ensure that the channel utilization is lower than 80%. If the channel utilization exceeds 80%, set the lower rate limits.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an RRM profile and enter its view.

    rrm-profile name profile-name

  4. Configure the intelligent multimedia scheduling algorithm.

    multimedia-air-optimize enable

    By default, the intelligent multimedia scheduling algorithm is disabled.

  5. (Optional) Configure the user packet thresholds for the intelligent multimedia scheduling algorithm.

    multimedia-air-optimize threshold { voice voice-value | video video-value } *

    By default, the video user packet threshold is 100 pps, and the voice user packet threshold is 30 pps.

  6. (Optional) Enable the delay guarantee function for uplink services.

    undo multimedia-air-optimize uplink-delay-guarantee disable

    By default, the delay guarantee function for uplink services is enabled.

  7. (Optional) Configure the guaranteed delay for voice and video services.

    multimedia-air-optimize downlink-delay-guarantee { voice | video | best-effort | background } { low | medium | high | off }

    The default guaranteed delay for voice and video services is medium.

    For AirEngine X776 APs running V600R023C10 or V600R024C00: If a large number of upload/download services and multimedia services are running on the live network, it is recommended that multimedia-air-optimize downlink-delay-guarantee video high be configured to meet the delay requirement of high-priority services; if some services (such as gaming and voice) have high requirements for the delay, it is recommended that multimedia-air-optimize downlink-delay-guarantee voice high be configured. Alternatively, you are advised to set the static rate limits for uplink and downlink traffic of each user to 40 Mbit/s (40000 kbit/s) to ensure that the channel utilization is less than 80%. If the channel utilization exceeds 80%, configure lower rate limits.

  8. (Optional) Configure the slicing ratio for voice and video services.

    multimedia-air-optimize downlink-slice-ratio { voice | video } { low | medium | high | off | slice-ratio ratio-value }

    The default slicing ratio for voice and video services is medium.

  9. (Optional) Enable the TCP window adjustment function for voice and video services.

    undo multimedia-air-optimize congestion-control tcp-window-tuning disable

    By default, the TCP window adjustment function for voice and video services is enabled.

  10. Bind the RRM profile.

    Bind the RRM profile to an AP group or a single AP so that the configuration in the profile can take effect. For details, see RRM Profile.

Verifying the Configuration

Run the display rrm-profile { all | name profile-name } command to check the configuration of the intelligent multimedia scheduling algorithm.
