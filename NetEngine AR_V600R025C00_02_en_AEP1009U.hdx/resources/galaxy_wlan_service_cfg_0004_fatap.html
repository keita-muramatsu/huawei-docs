Reference Relationships Between WLAN Profiles

Various WLAN profiles are designed based on different WLAN service functions. Understanding the functions that can be configured using these profiles and their reference relationships can help you in deploying WLAN services.

Figure 1 shows the WLAN profiles supported by the device and their reference relationships.
  • The following types of profiles can be bound to APs and AP groups: regulatory domain profile, radio profile, VAP profile, AP wired port profile, AP system profile, scenario profile, AP PKI realm profile, IoT profile.
  • Some profiles can be bound to upper-level profiles. For example, a service set identifier (SSID) profile and a security profile can be bound to a VAP profile. If a WLAN profile is bound to its upper-level profile, this upper-level profile must be further bound to an AP group or AP.
  • The profiles marked with * in the figure below have default settings.

Some profiles, such as radio profiles and VAP profiles, can also be bound in the AP radio view or AP group radio view.

Figure 1 Reference relationships between WLAN profiles

WLAN profiles are used to facilitate configuration and maintenance of WLAN functions. When configuring WLAN service functions, set parameters in the corresponding WLAN profiles. After completing the configurations, bind the profiles to upper-level profiles, AP groups, or APs. The configurations are then automatically delivered to and take effect on the APs. The typical procedure is as follows:

  1. Create a profile.
  2. Set service parameters in the profile.
  3. Apply the profile.

For example, to configure WLAN security functions, you can create a security profile, set related parameters, bind the security profile to a VAP profile, and then bind the VAP profile to an AP group or a single AP. In this manner, security configurations are automatically delivered to APs in the AP group or the specific AP and take effect. If reference relationships between profiles have been preconfigured, parameter settings in the security profile will be automatically delivered to APs.
