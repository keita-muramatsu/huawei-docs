Understanding Blacklist

Types of Blacklist Entries

The source IP addresses or destination IP addresses of packets can be added to the blacklist. Table 1 describes the blacklist.

Table 1 Types of blacklist entries

Type

Description

Source IP addresses

After a source IP address is added to the blacklist, the device discards all packets from this IP address.

Destination IP addresses

After a destination IP address is added to the blacklist, the device discards all packets destined for this IP address.
