Configuring Centralized License Control

Prerequisites

The network between a license client and the license server is reachable.

Procedure

  1. License Server
    1. Enter the system view.

      system-view

    2. Enter the WLAN view.

      wlan

    3. Enable centralized license control.

      license centralized enable

      By default, centralized license control is disabled.

  2. License Client
    1. Enter the system view.

      system-view

    2. Enter the WLAN view.

      wlan

    3. Enable centralized license control.

      license centralized enable

      By default, centralized license control is disabled.

    4. (Optional) Configure the local IP address of the license client.

      license client source { ip-address ip-address | ipv6-address ipv6-address }

      By default, the CAPWAP source address is used as the local address of a license client.

      • This configuration is private and does not support wireless configuration synchronization.
      • If the license clients work in VRRP HSB mode, configure different local IP addresses on the master and backup license clients.
      • If the license client works as a standalone device, the source address configuration is not required. Instead, the CAPWAP source address is used as the local address of the license client by default.

    5. Configure the IP address of the license server.

      license server { ip-address ip-address | ipv6-address ipv6-address }

      By default, no IP address is specified for the license server.

      This IP address must have been configured as the CAPWAP source IP address on the license server.

Verifying the Configuration

  • Run the display license centralized configuration command to check the configuration of centralized license control.
  • Run the display license resource usage detail to check the usage of license resources.
  • Run the display license member info mac mac-address command to check information about AC members in centralized license control.
  • Run the display license pool info command to check information about the license resource pool.
