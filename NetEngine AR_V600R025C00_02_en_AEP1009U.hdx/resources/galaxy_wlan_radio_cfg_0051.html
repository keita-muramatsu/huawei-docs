Scenario Profile

In some typical scenarios of WLAN projects, there are fixed recommended settings for functions and parameters such as radio calibration, load balancing, and smart roaming. The fixed recommended configurations for these typical scenarios are extracted into scenario profiles. Based on these profiles, you only need to bind preset scenario profiles to APs as required, greatly simplifying service configuration in project delivery.

Configuring effective priorities of scenario profiles

When a parameter is set in multiple ways, the parameter setting delivered to an AP takes effect in the following sequence: parameter in the scenario profile bound to an AP > parameter directly configured for an AP > parameter in the scenario profile bound to the AP group to which the AP belongs > parameter directly configured for the AP group to which the AP belongs. If the value of a configuration item in the scenario profile is displayed as a hyphen (-), the configuration is empty. In this case, this configuration mode is skipped when the system determines the priority of the configuration item.
