Preparing for Upgrade Maintenance

To ensure the smooth upgrade maintenance of a device, make relevant preparations based on requirements.

Upgrade Maintenance Preparation

Purpose

Operation

Check the existing software version of a device.

Prevent an upgrade failure due to a version mismatch.

Run the display version command to check the existing basic software version of the device.

Check the CPU and memory usage of the device.

Prevent upgrade maintenance failures caused by high CPU and memory usage.

Run the display health command to check the CPU and memory usage. If the CPU and memory usage is too high, reduce the usage before performing upgrade maintenance operations. It is recommended that the CPU usage be less than or equal to 70%, and that the memory usage be less than or equal to 90%.

Check the working status of the device.

Ensure that the device works properly and prevent upgrade and maintenance failures caused by operations such as hardware unregistration or device startup.

Run the display device command to check the running status of the device. If the Register field value is Unregistered, the board in the corresponding slot is not registered. If the Alarm field value is Abnormal, the board in the corresponding slot runs abnormally.

Set up the SFTP environment.

Back up existing resource files before an upgrade and upload new resource files required for an upgrade.

If SFTP is used for an upgrade:

  • If the device to be upgraded functions as a client and a PC functions as a server, install the SFTP server application on the PC. The SFTP server application is not delivered with the device and must be obtained separately.
  • If the device to be upgraded functions as an SFTP server and a PC functions as an SFTP client, the SFTP server application does not need to be installed on the PC. By default, the SFTP server function is disabled on the device to be upgraded. To enable this function, run the sftp server enable command in the system view.

Back up important data in the storage medium on the device to be upgraded.

Prevent loss of important data due to upgrade maintenance.

Run the copy source-filename destination-filename command to back up important data in the storage medium of the device to be upgraded.

Check the remaining space of the storage medium of the device to be upgraded.

Ensure that there is sufficient space for storing upgrade maintenance files.

Run the dir [ /all ] [ filename ] command to check the remaining space in the storage medium of the device to be upgraded. Ensure that there is sufficient space for storing the software files to be uploaded and related documents.

Stop service configurations.

Prevent upgrade maintenance failures due to service configurations being performed during an upgrade.

-

Obtain the required upgrade maintenance software package.

Obtain the required upgrade maintenance software package (such as a basic software package, a feature software package, an independent-hardware-release packages, a patch, or a *.MOD module file).

Obtain a system software package of a specified target version and matching documentation from the Huawei enterprise technical support website.

Obtain the upgrade guide.

Device upgrades are closely related to newly released versions. Each new version comes with a corresponding upgrade guide, which provides instructions for performing an upgrade.

For details, see the official installation or upgrade guide released by Huawei.

Obtain the license permission.

Purchase and install licenses if you need some service function modules or capacity-based capabilities that are controlled by licenses.

For details, see License User Guide.
