Configuring Airtime Scheduling

Prerequisites

Before performing the configuration, you have completed the following task:
  • Configure AP onboarding and STA access.

Context

Airtime scheduling computes wireless channel occupation time of STAs transmitting the same service and preferentially schedules resources for the STAs that occupy the channel for a shorter period of time. This ensures that STAs leverage channel resources in a relatively fair manner.

Airtime scheduling supports the following configuration modes:

  • enable: enabled
  • disable: disabled
  • auto: self-adaptive (The device automatically enables or disables this function based on the number of STAs associated with APs.)
The airtime scheduling function is supported by the following models (enabled by default but cannot be configured using commands):
  • AirEngine x760
  • AirEngine series central APs and RUs
  • AirEngine 9700D-S (including matching ORUs)
  • AirEngine 5763-11W
  • AirEngine X776
  • AirEngine X773
  • AirEngine X576
  • AirEngine X573
The following models support airtime scheduling (enabled adaptively by default from V200R023C10, which supports command-based configuration; enabled by default in V200R023C00 and earlier versions, which does not support command-based configuration):
  • AirEngine X761
  • AirEngine X762
  • AirEngine X771
  • AirEngine X56X

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an RRM profile and enter its view.

    rrm-profile name profile-name

  4. Configure airtime scheduling on an AP radio.

    airtime-fair-schedule { enable | disable | auto }

    By default, airtime scheduling is enabled adaptively on an AP radio.

  5. Bind the RRM profile.

    Bind the RRM profile to an AP group or a single AP so that the configuration in the profile can take effect. For details, see RRM Profile.

Verifying the Configuration

Run the display rrm-profile { all | name profile-name } command to check the airtime scheduling status in an RRM profile.
