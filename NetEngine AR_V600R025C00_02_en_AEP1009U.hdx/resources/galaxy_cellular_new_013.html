Example for Configuring Access to the Internet Through a Single Cellular Channel Interface

Networking Requirements

A remote branch of an enterprise needs to exchange service traffic with the headquarters. But the branch has no access to the wired WAN access service. The branch uses DeviceA to connect to the Internet through a carrier network, as shown in Figure 1. This achieves WAN interconnection with DeviceB at the headquarters and meets service requirements.

In addition, the network to be accessed needs to be automatically selected. The branch gets the APN 4gnet from the carrier.

Figure 1 Network diagram for connecting to the Internet through a single cellular channel interface

Configuration Roadmap

The configuration roadmap is as follows:

  1. Configure a network connection mode.
  2. Create an APN profile, set parameters, and bind the profile to a cellular channel interface.
  3. Enable the dial-up function on the cellular channel interface. Then, configure a default route, and specify the cellular channel interface as the outbound interface.

Procedure

  1. Create a cellular profile, set the network connection mode to auto, and apply the profile to a cellular interface.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] cellular-profile 4g
[DeviceA-cellular-profile-4g] mode auto
[DeviceA-cellular-profile-4g] quit
[DeviceA] interface cellular 2/0/0
[DeviceA-Cellular2/0/0] cellular-profile 4g
[DeviceA-Cellular2/0/0] quit

  2. Create an APN profile and bind it to the cellular channel interface.

    [DeviceA] apn-profile 4gprofile
[DeviceA-apn-profile-4gprofile] apn 4gnet
[DeviceA-apn-profile-4gprofile] quit
[DeviceA] interface cellular 2/0/0:1
[DeviceA-Cellular2/0/0:1] apn-profile 4gprofile

  3. Enable the dial-up function.

    [DeviceA-Cellular2/0/0:1] ip address modem-alloc
[DeviceA-Cellular2/0/0:1] quit

  4. Configure a default route and specify Cellular2/0/0:1 as the outbound interface.

    [DeviceA] ip route-static 0.0.0.0 0 cellular 2/0/0:1

Configuration Scripts

DeviceA
#
sysname DeviceA
#
interface Cellular2/0/0
 cellular-profile 4g
#
interface Cellular2/0/0:1
 apn-profile 4gprofile
 ip address modem-alloc
#
apn-profile 4gprofile
 apn 4gnet
cellular-profile 4g
 mode auto
#
ip route-static 0.0.0.0 0.0.0.0 Cellular2/0/0:1
#
return
