Configuring Defense Against Bogus ND Server Attacks

Context

If a bogus ND server exists at the STA side, STAs may obtain incorrect IPv6 addresses or network parameters, resulting in communication failures. As such, you can disable the ND trusted port on APs. In this manner, when receiving ND OFFER, ACK, or NAK messages, an AP considers the message sender as a bogus ND server. The AP then discards these messages and reports the server's IPv6 address to the connected WAC.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a VAP profile and enter its view.

    vap-profile name profile-name

    By default, the VAP profile default exists in the system.

  4. Disable the ND trusted port on an AP.

    undo nd trust port

    By default, the ND trusted port is disabled on an AP in the VAP profile view.

  5. Return to the WLAN view.

    quit

  6. Apply the VAP profile by referring to Binding a VAP Profile to make the configuration take effect.
