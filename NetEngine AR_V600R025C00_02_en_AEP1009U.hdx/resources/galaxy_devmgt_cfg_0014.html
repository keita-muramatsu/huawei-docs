Configuring the Input Power for Power Modules

Context

If the maximum output power provided by the power cabinet is less than the rated power of power modules, the power-on management module still manages power-on of the boards based on the rated power by default. However, the actual output power provided by the power cabinet is insufficient. As a result, the powered-on boards may be powered off or restarted. To eliminate this issue, enable the power-on management module to manage power-on of the boards according to the actual input power of the power modules, so as to ensure that the powered-on boards work stably when the maximum output power provided by the power cabinet is less than the rated power of power modules.

Configure an input power for power modules in the following scenarios:

  • If a device is installed for the first time and the maximum output power supplied by the power cabinet is less than the rated power of power modules, you are advised not to install boards. Instead, configure the input power for the power modules after the main control board starts. Then estimate the number of boards to which the configured input power can be allocated based on the rated power of the boards, and install boards based on the actual situation.

  • If additional boards need to be installed on a device and the maximum output power supplied by the power cabinet is less than the rated power of power modules, configure the input power for the power modules. Then estimate the number of additional boards to which the remaining power of the power modules can be allocated based on the rated power of the boards, and install boards based on the actual situation.

Only the AR6700-H and AR8700 series support this function.

Procedure

  1. Enter the system view.

    system-view

  2. Configure the input power for power modules.

    device power single-pm input-power power-value

    The default input power of power modules is their rated power.

Verifying the Configuration

Run the display device power system command and check the Total Power Capacity with Backup and PowerNo fields in the command output.
