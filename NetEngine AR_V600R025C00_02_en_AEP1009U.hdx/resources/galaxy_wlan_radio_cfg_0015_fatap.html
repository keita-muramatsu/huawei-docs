Verifying the Configuration

Procedure

  • Run the display radio { all | ap-group ap-group-name | ap-id ap-id } command to check AP radio information.
  • Run the display radio-2g-profile { all | name profile-name } command to check the configuration of a 2.4 GHz radio profile.
  • Run the display radio-5g-profile { all | name profile-name } command to check the configuration of a 5 GHz radio profile.
  • Run the display references radio-2g-profile name profile-name command to check reference information about a 2.4 GHz radio profile.
  • Run the display references radio-5g-profile name profile-name command to check reference information about a 5 GHz radio profile.
  • Run the display rrm-profile { all | name profile-name } command to check the configuration of an RRM profile.
  • Run the display references rrm-profile name profile-name command to check reference information about an RRM profile.
  • Run the display ap configurable channel ap-id ap-id [ radio radio-id ] command to check the configurable channels supported by a specified AP.
  • Run the display channel switch-record { all | calibrate | ap-id ap-id radio radio-id | reason { unknown | dfs | configuration | unsupported | 3gpp-bs-notification | iot-notification | ap-sync } } command to check channel switching records.
  • Run the display ap radio-mode all command to check the radio mode that takes effect on online APs.
  • Run the display wlan calibrate global configuration command to check the global radio calibration configuration.
