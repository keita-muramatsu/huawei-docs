Signing an EULA

Context

They can be signed through the input of commands, making it easy to agree on responsibilities in situations where face-to-face communication and negotiation are not possible. For details, see Huawei Enterprise End User License Agreement.

Procedure

  1. Sign the EULA.

    <HUAWEI> accept eula 
Warning: 
Your use of the product is subject to the HUAWEI end user license agreement https://e.huawei.com/en/about/eula. Activation of the software command line interface will be evidence of your acceptance of this agreement. Are you sure you want to accept it? [Y/N]:y 
Info: Operation succeeded.

    If you select N, the system exits the manual signing state. If the EULA is not signed within 10 days, the user agrees to the EULA terms by default and the system automatically signs the EULA.

Verifying the Configuration

Run the display eula status command in any view to check the EULA signing status in the current system.
