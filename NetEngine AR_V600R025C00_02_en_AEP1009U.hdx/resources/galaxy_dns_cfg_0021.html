Example for Configuring a Device as an IPv4 DNS Client for DNS Query (Static Domain Name Resolution)

Networking Requirements

In Figure 1, DeviceA functions as an IPv4 DNS client. The customer wants DeviceA to communicate with DeviceB using the domain name (DeviceB).
Figure 1 Network diagram of IPv4 static domain name resolution

In this example, Interface1 represents 10GE 0/0/1.


Configuration Roadmap

The configuration roadmap is as follows:

  1. Configure a static IPv4 DNS entry on DeviceA and enable DeviceA to communicate with DeviceB using a domain name.

Procedure

  1. Configure an IPv4 address for 10GE 0/0/1 on DeviceA.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] vlan batch 10
[DeviceA] interface 10GE 0/0/1
[DeviceA-10GE0/0/1] port link-type trunk
[DeviceA-10GE0/0/1] port trunk allow-pass vlan 10
[DeviceA-10GE0/0/1] quit
[DeviceA] interface vlanif 10
[DeviceA-Vlanif10] ip address 192.168.1.1 24
[DeviceA-Vlanif10] quit

  2. Configure a static IPv4 DNS entry on DeviceA.

    [DeviceA] ip host DeviceB 192.168.1.2
[DeviceA] quit

Verifying the Configuration

<DeviceA> display ip host

Total    :  1

Configuration Scripts

#
 sysname DeviceA
#
ip host DeviceB 192.168.1.2
#
vlan batch 10
#
interface Vlanif10
 ip address 192.168.1.1 255.255.255.0
#
interface 10GE0/0/1
 port link-type trunk
 port trunk allow-pass vlan 10
#
return
