Configuring the Radio Working Mode

Context

The working mode of a radio determines whether the radio provides both the WLAN service data transmission and monitoring functions or only the former.

An AP radio can work in the following modes:
  • normal: normal mode
    • If no functions related to air scan are enabled on a radio, the radio only transmits common WLAN service data.
    • If any function related to air scan is enabled on a radio, the radio provides the monitoring function in addition to transmitting common WLAN service data. WLAN services may encounter a transient increase in latency during a radio scanning period, which does not affect network access. However, if any latency-sensitive services (such as videoconferencing) are running, it is recommended that a separate radio be used for scanning.
  • monitor: monitoring mode

    In this mode, the radio can only transmit WLAN services scanned by the air interface but cannot transmit common WLAN services.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Enter the radio view.

    • Enter the AP group radio view.
      ap-group name group-name
radio radio-id
    • Enter the AP radio view.
      ap-id ap-id
radio radio-id

  4. Configure the radio working mode.

    work-mode { monitor | normal }

    By default, the working mode for all AP radios in an AP group is normal, and that for radios on a single AP is not configured but is the same as that configured in the AP group to which the AP belongs.
