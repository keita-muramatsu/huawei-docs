Generating Code

GPB-encoded data can be serialized and deserialized using code automatically generated by tools.

In this example, GPB encoding in telemetry involves the following .proto files:

  • huawei-grpc-dialin.proto: describes the dynamic subscription RPC definition supported by the device that functions as a server.
  • huawei-telemetry.proto: describes sampling information, including the sampling interval and sampling path.
  • huawei-cpu-memory.proto: defines the format of sampled data.

In this example, the device acts as a client and pushes sampled data to the collector by initiating data push RPC requests. You need to compile the preceding .proto files using protoc to generate corresponding code for serialization and deserialization.

  1. Compile the .proto files that describe sampling information and define the sampled data format.

    In the protos directory, create the proto_py folder to store the generated Python files. Compile huawei-telemetry.proto and huawei-cpu-memory.proto, which produces two Python files huawei_cpu_memory_pb2.py and huawei_telemetry_pb2.py. Each generated file defines message structures along with the serialization (SerializeToString) and deserialization (ParseFromString) methods. The compilation commands are as follows:

    D:\Telemetry\protos> protoc --python_out=./proto_py huawei-telemetry.proto
D:\Telemetry\protos> protoc --python_out=./proto_py huawei-cpu-memory.proto

  2. Compile the .proto file that defines the gRPC service, which generates two Python files:

    • huawei_grpc_dialin_pb2.py: used for protobuf data interaction and defines the methods to serialize and deserialize data.
    • huawei_grpc_dialin_pb2_grpc.py: used for interacting with gRPC. It defines the classes for RPC methods, including request and response parameters, and can be invoked directly from Python.

    The commands for compiling this .proto file are as follows:

    D:\Telemetry\protos> python -m grpc_tools.protoc -I. --python_out=./proto_py --grpc_python_out=./proto_py huawei-grpc-dialin.proto
  3. A total of four Python files have now been generated. Add them to a Python project you have created.
