Querying Interface Up/Down Information

Description of MIB Objects

You can use ifAdminStatus and ifOperStatus in ifTable to obtain up/down information about all interfaces, and then use ifIndex to query up/down information about an interface.

Object

OID

ifIndex

1.3.6.1.2.1.2.2.1.1

ifDescr

1.3.6.1.2.1.2.2.1.2

ifAdminStatus

1.3.6.1.2.1.2.2.1.7

ifOperStatus

1.3.6.1.2.1.2.2.1.8

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.

  2. Perform the Walk operation on ifDescr to query the entity index ifIndex. As shown in Figure 1, the index of 10GE8/0/1 is 9.

    Figure 1 Obtaining the mapping between an interface and its index

  3. Perform the Walk operation on ifAdminStatus to query the ideal physical status of the corresponding interface based on the value of ifIndex. As shown in Figure 2, the ideal physical status of 10GE8/0/1 with the index of 9 is up.

    Figure 2 Obtaining the ideal physical status of an interface

  4. Perform the Walk operation on ifOperStatus to query the current configuration status of the corresponding interface based on the value of ifIndex. As shown in Figure 3, the current configuration status of 10GE8/0/1 with the index of 9 is down.

    Figure 3 Obtaining the current configuration status of an interface
    • The ideal physical status of 10GE8/0/1 with the index of 9 is up, and the current configuration status is down. This means that the undo shutdown command has been run on the interface, but the physical status is still down (for example, because no network cable is connected to the interface).

    For a Layer 2 physical interface, the current configuration status (ifOperStatus) specifies the physical status of the interface. The protocol status is consistent with the current configuration status (ifOperStatus).
