Configuring an E1/CE1 Interface to Work in E1 Mode

Context

As shown in Figure 1, the branch and headquarters of an enterprise are connected through the transmission network of a carrier. The enterprise leases 2 Mbit/s E1 private lines from the carrier.
Figure 1 Branch accessing the transmission network through E1 private lines

The E1/CE1 interface of the branch needs to be configured to work in E1 mode.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the E1/CE1 interface view.

    controller e1 interface-number

  3. Configure the E1/CE1 interface to work in E1 mode.

    using e1

    By default, an E1/CE1 interface works in CE1 mode. After the working mode of an E1/CE1 interface is changed to E1, the system creates a serial interface serial interface-number:0, where interface-number specifies the number of the E1/CE1 interface. The interface can be further configured, including configuring the IP address and PPP protocol.

    For example, after you run the controller e1 1/0/0 command to enter the E1/CE1 interface view and configure the interface to work in E1 mode, the serial interface created by the system is serial 1/0/0:0.

  4. Configure other parameters for the E1/CE1 interface.

    The parameters except the clock mode of the E1/CE1 interface on the local end must be the same as those on the peer end. Otherwise, the communication may be abnormal.

    1. Configure a clock mode for the interface.

      clock { master | slave }

      By default, the clock mode of an interface is master.

    2. Enable or disable data inversion.

      data-coding inverted enable
undo data-coding inverted enable

      By default, data inversion is disabled on an interface.

    3. Configure a line idle code for the interface.

      idle-code { 7e | ff }

      By default, the line idle code of an interface is 7e (0x7e).

    4. Configure an interframe filling tag and the number of interframe filling tags for the interface.

      itf type { 7e | ff }
itf number number

      By default, the interframe filling tag of an interface is 7e (0x7e), and the number of interframe filling tags is 4.

    5. Configure a CRC mode for a serial interface.

      interface serial interface-number
crc { 16 | 32 | none }

      By default, a serial interface uses the 16-bit CRC mode.

Verifying the Configuration

  • Run the display controller e1 interface-number command to check the status and parameters of a specified E1/CE1 interface.
  • Run the display interface serial interface-number command to check the status of and statistics about a specified serial interface.
