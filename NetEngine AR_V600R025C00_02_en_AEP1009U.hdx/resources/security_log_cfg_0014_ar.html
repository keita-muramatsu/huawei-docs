Example for Sending IPv4 Session Logs in Binary Format to SecoManager

Networking Requirements

As shown in Figure 1, DeviceA is deployed at the network border as a gateway. A NAT policy in PAT mode is configured on DeviceA to perform the address and port translation for packets that access external networks from the internal network.

The administrator wants to check IPv4 PAT session logs on SecoManager to understand the creation of sessions by packets in a timely manner and, when necessary, perform NAT source tracing.

Figure 1 Networking diagram of checking IPv4 session logs on the log host

In this example, interface1 represents 10GE0/0/1.


Configuration Roadmap

To meet the preceding requirements, the administrator needs to consider the following key configurations:

  • Configure a NAT policy in PAT mode on DeviceA, and set interconnection parameters to output logs to SecoManager.
  • Configure log access on SecoManager and associate the collector with the log source.

Procedure

  1. Configure DeviceA.

    1. Check whether the time zone and time of the device are the same as those of the SecoManager collector. In the case of inconsistency, run the following commands to adjust the time zone or time of the device.

      # Adjust the time zone of the device to keep consistency with that of the SecoManager collector. Assume that the SecoManager collector is in the Beijing time zone. The time of the collector is 8 hours earlier than default Universal Time Coordinated (UTC) on the device. Therefore, use the add 08:00:00 parameter. If the SecoManager collector is in a time zone where the time is later than UTC, use the minus parameter.
      <HUAWEI> clock timezone BJ add 08:00:00

      # Adjust the time of the device to keep consistency with that of the SecoManager collector. Assume that the current time of the SecoManager collector is 00:00:00 on August 1, 2020.

      <HUAWEI> clock datetime 0:0:0 2020-08-01

      After the preceding configurations are complete, run the display clock command to view the configuration results.

      <HUAWEI> display clock
2020-08-01 16:26:51.835 +08:00
2020-08-01 16:26:51+08:00
Saturday
Time Zone(Beijing) : UTC+08:00

    2. Configure an IP address for an interface. The following uses the interface connecting the device to SecoManager as an example.

      [DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] undo portswitch
[DeviceA-10GE0/0/1] ip address 172.16.81.1 16
[DeviceA-10GE0/0/1] quit

      If the device and SecoManager belong to different networks, you need to configure a route to SecoManager on the device.

    3. Configure a NAT policy.

      # Configure the NAT address pool and use the PAT mode (also the default mode). If the mode no-pat command is used to specify the No-PAT mode, the device will generate No-PAT session logs.

      [DeviceA] nat address-group addr1
[DeviceA-address-group-addr1] mode pat
[DeviceA-address-group-addr1] section 0 192.168.5.100 192.168.5.120
[DeviceA-address-group-addr1] quit

      # Configure the NAT policy and reference the NAT address pool.

      [DeviceA] nat-policy
[DeviceA-policy-nat] rule name policy1
[DeviceA-policy-nat-rule-policy1] source-address 192.168.0.0 24
[DeviceA-policy-nat-rule-policy1] action source-nat address-group addr1
[DeviceA-policy-nat-rule-policy1] quit
[DeviceA-policy-nat] quit
    4. Set the IP address of the log host to 172.16.110.168 and port to 9002.
      [DeviceA] firewall log host 1 172.16.110.168 9002
    5. Set the source IP address and port for the device to send session logs.
      [DeviceA] firewall log source 172.16.81.1 6666
    6. Set the output format of session logs to binary (also the default format).
      [DeviceA] firewall log session log-type binary

    7. Enable session logging.

      # Enable session aging logging.

      [DeviceA] firewall log session aging enable

      # Enable NAT session logging.

      [DeviceA] firewall log session nat enable

  2. Configure SecoManager.

    The SecoManager GUI is for reference only. The GUI may vary depending on the version.

    1. Optional: Open the Device Log Management app, choose Log Access > Log Source Management, and click Add.

    2. Open the Device Log Management app, choose Log Access > Log Access Management, and click Create.

    3. The new task is displayed in the log access task list and is in the Running state.

Verifying the Configuration

After the preceding configurations are complete, when users on internal networks access external networks, corresponding NAT sessions are generated on the device. The device sends the session logs to SecoManager. Then you can view the session logs on SecoManager.

  1. Open the Device Log Management app, and choose Session Analysis > IPv4 Session Log.
  2. Set parameters for querying logs and click Query.

Configuration Scripts

#                                                                               
sysname DeviceA                                                                     
#                                                                         
firewall log source 172.16.81.1 6666
firewall log host 1 172.16.110.168 9002
firewall log session log-type binary
firewall log session aging enable
firewall log session nat enable
#
interface 10GE0/0/1                                                       
 ip address 172.16.81.1 255.255.0.0
#
nat address-group addr1 0
 mode pat
 section 0 192.168.5.100 192.168.5.120
#
nat-policy
 rule name policy1
  source-address 192.168.0.0 mask 255.255.255.0
  action source-nat address-group addr1
#
return
