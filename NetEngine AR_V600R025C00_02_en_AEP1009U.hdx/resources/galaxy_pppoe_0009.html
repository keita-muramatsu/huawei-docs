Configuring a Dialer Interface

Context

Before configuring the device as a PPPoE client, you need to configure a dialer interface and an IP address for the interface.

You can configure an IPv4 address for a dialer interface using either of the following methods:

  • Configure an IPv4 address on the interface.
  • Configure the interface to obtain an IPv4 address through IP address negotiation.

You can configure an IPv6 address for a dialer interface using any of the following methods:

  • Configure an IPv6 address on the interface.
  • Configure stateless address autoconfiguration for the interface to automatically generate a global IPv6 address.
  • Configure address allocation by DHCPv6.

The IP address negotiation function of PPP allows a server to assign an IP address to a client. If the PPPoE client interface runs PPP at the link layer but is not configured with an IP address, and the PPPoE server has an assignable IP address, you can configure IP address negotiation on the PPPoE client interface so that it can obtain an IP address from the PPPoE server. For details about how to configure PPP, see Configuration Guide > Configuring PPP.

Procedure

  1. Enter the system view.

    system-view

  2. Create a dialer interface and enter the dialer interface view.

    interface dialer number

  3. Configure an IP address for the dialer interface.

    Before configuring an IP address for the dialer interface, you need to configure PPP as the link layer protocol of the interface. For details, see Configuring PPP in CLI Configuration Guide > WAN Access.

    Configure an IPv4 address for the dialer interface. Perform either of the following operations as required:

    • Configure an IPv4 address on the dialer interface.
      ip address ip-address { mask | mask-length } [ tag tag-value ]
    • Configure the dialer interface to obtain an IPv4 address from the remote interface.
      ip address ppp-negotiate

      By default, IP address negotiation is disabled on an interface.

    Configure an IPv6 address for the dialer interface.

    First, enable the IPv6 function on the interface.
    ipv6 enable

    Then, configure an IPv6 address for the interface. Perform any of the following operations as required:

    • Configure the global unicast IPv6 address function on the interface.
      ipv6 address { ipv6-address prefix-length | ipv6-address/prefix-length } [ tag tag-value ]
    • Configure stateless address autoconfiguration for the interface to automatically generate a global IPv6 address.
      ipv6 address auto link-local
ipv6 address auto global
    • Configure address allocation by DHCPv6.
      ipv6 address auto link-local
ipv6 address auto global
ipv6 address auto dhcp

  4. (Optional) Configure network address translation (NAT).

    If the device functions as a PPPoE client on an IPv4 network and connects to users in a downstream LAN, you need to configure NAT on the device to translate the users' private IP addresses into public IP addresses so that the users can access the Internet.

    For the configuration procedure, see NAT Configuration.
