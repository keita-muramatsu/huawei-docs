Logging In to the CLI Console from the Web System

Context

The CLI console redirects administrators from the web system to the CLI window, where they can configure advanced functions.

Procedure

  1. Click the CLI Console icon in the upper right corner of the web system, as shown in Figure 1.

    Figure 1 Opening the CLI console

  2. Click the black background of the window to start the CLI configuration, as shown in Figure 2.

    Figure 2 CLI window

    In the upper right corner of the CLI window, there are four function buttons:

    • : displays the CLI window in full screen.

    • : disconnects from the CLI window and releases related system session resources. You can click the black background again to reconnect to the CLI window.

    • : clears the information displayed in the current CLI window.

    • : minimizes the CLI window. Clicking the title bar in the CLI window can also minimize the CLI window.
