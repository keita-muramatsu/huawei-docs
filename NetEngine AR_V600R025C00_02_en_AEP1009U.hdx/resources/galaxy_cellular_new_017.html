Configuring the Operating Frequency Band of a Cellular Modem

Context

A cellular modem uses wireless signals to communicate with a base station. The frequency range of these signals is called the operating frequency band. Multiple frequency bands are usually available for users to access a carrier network. By default, a cellular modem automatically selects a frequency band and adjusts it if the network's frequency bands change. But such changes can cause the following problems:

  • Signal quality deterioration: Signal quality may degrade if a user device switches frequency bands. This may cause slow data transmission or a network connection failure.
  • Network congestion: When a frequency band reaches its maximum capacity, the carrier may switch user devices to another frequency band. This may cause network congestion as more devices share the same frequency band.

To prevent these problems and improve the link stability, you can manually configure the optimal operating frequency band for a cellular modem.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the cellular profile view.

    cellular-profile profile-name

  3. Configure the operating frequency band of the cellular modem. The device supports two frequency band selection modes: automatic and manual.

    • Enable the cellular modem to automatically select an operating frequency band for cellular network access.
      band auto

      By default, a modem automatically selects a frequency band for accessing a wireless network. The band auto command deletes the configured frequency band and enables the modem to automatically select a frequency band for accessing a wireless network.

    • Manually configure the operating frequency band of the cellular modem.
      • Configure the frequency band for accessing a 5G network.
        band nr { n1 | n28 | n41 | n77 | n78 | n79 }*

        By default, a cellular modem automatically selects a frequency band for accessing a 5G network.

        This command is supported only on devices that support the 5G function.

      • Configure the frequency band for accessing an LTE network.
        band lte { band1 | band2 | band3 | band4 | band5 | band7 | band8 | band20 | band28 | band34 | band38 | band39 | band40 | band41 }*

        By default, a cellular modem automatically selects a frequency band for accessing an LTE network.

        This command is supported only on devices that support the 4G function.

      • Configure the frequency band for accessing a 3G network.
        band wcdma { wcdma2100 | wcdma1900 | wcdma850 | wcdma900 }*

        By default, a cellular modem automatically selects a frequency band for accessing a 3G network.

        This command is supported only on devices that support the 3G function.

Verifying the Configuration

Run the display cellular interface-number modem-configuration command and check the operating frequency band of the cellular modem. This is shown in the Current Bands Config field in the command output.
