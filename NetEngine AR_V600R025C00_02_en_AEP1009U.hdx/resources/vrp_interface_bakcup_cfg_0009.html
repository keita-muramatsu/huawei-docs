Understanding Association Between Interface Backup and a Route Monitoring Group

If interface backup is configured and an indirect upstream link of the active interface fails, the interface backup module cannot detect the fault, leading to service interruptions. To address this issue, you can configure association between interface backup and a route monitoring group on the standby interface. This enables the system to monitor the status of routes in the route monitoring group on the primary link and implement a primary/backup link switchover. When a valid route exists in the route monitoring group, the primary link is used for service transmission. If all routes in the route monitoring group become invalid, the standby interface is started, and the backup link temporarily transmits services. Once the routes in the route monitoring group recover, services are switched back to the primary link.

On the network shown in Figure 1, DeviceA, the egress gateway of the headquarters (HQ), connects to the Internet through interface1. The link between interface1 and the Internet serves as the primary link to transmit services and communicate with the branch, and interface2 serves as the backup link's outbound interface. Association between interface backup and a route monitoring group is configured on the standby interface interface2 to monitor the route status of the primary link. If the link from DeviceD to DeviceB fails and the corresponding route becomes invalid, the route monitoring group detects the fault and instructs DeviceA to start interface2 (the standby interface). The backup link then temporarily transmits services. After the link recovers, services are switched back to the primary link.
