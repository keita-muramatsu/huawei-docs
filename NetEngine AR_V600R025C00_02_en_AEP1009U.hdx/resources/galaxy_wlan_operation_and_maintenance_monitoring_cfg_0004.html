Configuring APs to Directly Report KPI Information

Prerequisites

The WAC has been configured to report information in Telemetry mode. For details, see "Telemetry Configuration" in CLI Configuration Guide > System Monitoring Configuration.

If KPI information reported by APs needs to be displayed on an analyzer, ensure that APs are configured on the WAC to report NE data through Telemetry. For details, run the sensor-path huawei-wlan-ap:wlan-ap/ap-instances command in the sensor group view.

Context

Only WMI-capable APs can report KPI information to a WMI server.

To avoid waste of destination server resources, do not configure multiple report channels with the same destination address and port number.

Ensure that the system time on the device is the same as that on the WMI server. Otherwise, the reported data may fail to be displayed on the WMI server.

The primary/backup WMI server scheme is supported. In the primary/backup scheme, you must configure the destination address and port number of the primary WMI server and then configure the backup WMI server. If the primary/backup scheme is not used, you only need to configure the primary WMI server. Do not configure the backup server before configuring the primary server.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a WMI profile and enter its view.

    wmi-server name profile-name

    By default, no WMI profile is created.

  4. Configure the destination address and port number of the primary WMI server to which APs report KPI information.

    server { ip-address ip-address | ipv6-address ipv6-address } port port

    By default, no destination address or port number of the primary WMI server is configured for APs to report KPI information.

  5. Optional: Configure the destination address and port number of the backup WMI server to which APs report KPI information.

    server backup { ip-address ip-address | ipv6-address ipv6-address } port port

    By default, no destination address or port number of the backup WMI server is configured for APs to report KPI information.

  6. Optional: Configure a PKI realm for interconnection between APs and a WMI server.

    pki realm realm-name

    By default, the PKI realm default is used for interconnection between APs and a WMI server.

  7. Optional: Set parameters for interconnection between the APs and WMI server.

    keepalive { interval interval | retry-interval retry-interval | retry-number retry-number } *

    By default, the heartbeat interval is 3 minutes, the reconnection interval is 5 minutes, and the number of reconnection attempts is 0.

    The value 0 for the number of reconnection attempts indicates that the server and APs always attempt to reconnect to each other.

  8. Optional: Configure the maximum data length of KPI information reported by APs to the WMI server.

    max-packet-size size

    By default, the maximum data length of KPI information reported by APs to the WMI server is 5 KB.

  9. Optional: Configure the interval at which APs report KPI information to the WMI server.

    report-interval interval

    By default, the interval at which APs report KPI information to the WMI server is 60 seconds.

  10. Optional: Configure APs to report logs of a module with the specified ID to the WMI server.

    ap log module mid mid [ name name ]

    By default, an AP is not configured to report logs of a module with the specified ID.

    If APs need to report logs to a WMI server, specify the ID of a module whose logs are to be reported and enable the log report function. Otherwise, the APs do not report logs of this module.

  12. Return to the WLAN view.

    quit

  13. Create an AP system profile and enter its view.

    ap-system-profile name profile-name

    By default, the AP system profile default exists on the device.

  14. Bind the specified WMI profile to the AP system profile.

    wmi-server profile-name index index

    By default, no WMI profile is bound to an AP system profile.

  15. Return to the WLAN view.

    quit

  16. Enter the AP view or AP group view.
    • Enter the AP group view.
      ap-group name group-name
    • Enter the AP view.
      ap-id ap-id
  17. Bind the AP system profile to an AP group or a specific AP.

    ap-system-profile profile-name

    By default, the AP system profile default is bound to an AP group, but no AP system profile is bound to an AP.

Verifying the Configuration

  • Run the display wmi-server { all | name wmi-server-name } command to check configuration and reference information about a WMI profile.
  • Run the display references wmi-server name wmi-server-name command to check reference information about a WMI profile.
