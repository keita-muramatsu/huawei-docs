Configuring Dot1q Termination Sub-interfaces to Implement Inter-VLAN Communication

Context

When a device connects to users in different VLANs and on different network segments through a Layer 3 Ethernet interface, you can configure dot1q termination and IP addresses on sub-interfaces so that the users can communicate with each other at Layer 3.

To implement inter-VLAN communication, the default gateway address of hosts in a VLAN must be the IP address of the corresponding sub-interface.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the sub-interface view.

    interface interface-type interface-number.subinterface-number

  3. Configure an IP address for the sub-interface.

    ip address ip-address { mask | mask-length } [ sub ]

  4. Configure the VLAN tag to be terminated by the sub-interface.

    dot1q termination vid low-pe-vid
    After this command is run successfully, the termination sub-interface processes packets as follows:
    • It removes the tag in received packets and then forwards the packets at Layer 3. The outbound interface determines whether the forwarded packets carry tags.
    • It adds the VLAN information in the packets received from the remote end to the packets to be sent, and then sends the packets.

    After the dot1q termination vid command is configured on a sub-interface, the encapsulation dot1q-termination configuration is automatically generated on the sub-interface, indicating that the encapsulation type of the sub-interface is dot1q termination. After the undo dot1q termination vid command is configured on the sub-interface, the encapsulation dot1q-termination configuration on the sub-interface is also deleted.
