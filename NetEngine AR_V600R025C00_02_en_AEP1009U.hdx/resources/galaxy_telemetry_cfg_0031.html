JSON Encoding

JSON is a lightweight data exchange format. Based on a subset of ECMAScript (a JavaScript standard developed by the ECMA), JSON uses a text format independent of programming languages to store and express data with a simple and clear structure, so that the data can be easily read or compiled by development personnel and parsed or generated by devices. Table 1 shows the JSON encoding format.

For data transmitted between devices and the collector, data encoded in GPB format has a higher information load capability than that encoded in other formats (JSON or XML). GPB encoding ensures telemetry data throughput capabilities and reduces the CPU usage and required bandwidth.

If telemetry uses JSON encoding, the data packets sent to the collector do not contain typesetting characters such as carriage return or space, reducing the size of JSON-encoded data.
