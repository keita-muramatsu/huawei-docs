Creating a Super-VLAN

Prerequisites

Before configuring a super-VLAN, you have configured sub-VLANs.

Procedure

  1. Enter the system view.

    system-view

  2. Create a VLAN and enter the VLAN view.

    vlan vlan-id

    The value of vlan-id in this step must be different from the ID of a sub-VLAN.

  3. Create a super-VLAN.

    aggregate-vlan

    You can run the undo aggregate-vlan command in the view of a super-VLAN to change it to a sub-VLAN.

  4. Add a sub-VLAN to the super-VLAN.

    access-vlan { vlan-id1 [ to vlan-id2 ] } &<1-10>

    Only sub-VLANs can be added to a super-VLAN. Before adding sub-VLANs to a super-VLAN in batches, ensure that no VLANIF interfaces are configured for these sub-VLANs.
