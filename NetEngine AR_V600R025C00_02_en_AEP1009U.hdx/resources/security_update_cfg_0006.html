Preparations for Signature Database Update

Context

To ensure that a signature database can be updated successfully, you need to make the following preparations:
  • Check the license status of the device.
  • Check the available flash space and memory space.
  • Check the update status of the current signature database.
  • Check the version information of the current signature database.
  • To update the signature database online, ensure that the device can access the update center through the Internet.
  • When the device is directly connected to the update center through the Internet to update the signature database online, check whether the initial CA certificate has been loaded to the device memory.

Procedure

  1. Check the license status of the device.

    display license verbose

    Before updating the signature database, ensure that you have purchased and activated the license control items according to the precautions for signature database update.

    Ensure that the license control items for signature database update have been activated and have not expired.

    No license is required for updating the SA signature database and geolocation database.

  2. Check the available flash space and memory space.

    1. Check the available flash space.
      dir

      The available flash space must be at least the size of the signature database file plus the size of the flash memory required for installation. The sizes of these two items are as follows:

      • Signature database file size: The signature database update period is short. Therefore, the size of the signature database file is subject to the size of the downloaded file.
      • Size of the flash memory required for installation: Table 1 lists the requirements for the available flash space during the installation of the signature database.
        Table 1 Flash space for updating each signature database

        Signature Database Name

        Required Available Flash Space

        IPS signature database (IPS-SDB)

        ≥ 60 MB

        Antivirus signature database (AV-SDB)

        For the AR8700 series: ≥ 240 MB

        For the AR8100 series: ≥ 240 MB

        For the AR6700 series: ≥ 40 MB

        For the AR5700 series: ≥ 40 MB

        SA signature database (SA-SDB)

        ≥ 50 MB

        Geolocation database (Location-SDB)

        ≥ 10 MB

      If the available space is insufficient, run the delete command to delete unnecessary files from the flash memory. After the delete command with the /unreserved parameter specified is run, the files are deleted and cannot be restored.

    2. Check the available memory space.
      display memory

      The difference between the value of Total Physical Memory and that of Total Physical Memory Used is the available memory space. If there is insufficient memory and the update fails, contact Huawei R&D engineers to identify the problem.

  3. Check the update status of the current signature database.

    display update status

    Before updating a signature database, check whether the update status of the signature database is Idle. You can update a signature database only when the update status is Idle.

  4. Check the version information of the current signature database.

    display version { av-sdb | ips-sdb | sa-sdb }*
display version location-sdb

    Before updating a signature database, check the version information of the signature database.

  5. If the signature database is updated in online mode, check whether the initial CA certificate has been loaded to the device memory.

    During an online update of the signature database, the initial CA certificate used by default when the device connects to the update server at the Huawei Intelligent Security Center is stored in the NVRAM memory. You need to run the pki import-certificate default_ca realm default command to load the initial CA certificate to the default realm. Otherwise, the update may fail.

    You can run the display pki certificate ca filename default_ca.cer command to check whether the initial CA certificate is loaded. If the initial CA certificate is not loaded, the message "Info: Can not find certificates in store." is displayed.

Follow-up Procedure

After the preparations for updating the signature database are complete, you can configure signature database update. For details about the configuration, see Configuring Online Signature Database Update or Configuring Offline Signature Database Update.
