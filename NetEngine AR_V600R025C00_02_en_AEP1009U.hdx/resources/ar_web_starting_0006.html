Changing the Administrator Password

Context

After logging in to the web system, you can change the current administrator password.

Procedure

  1. You can change the administrator password in either of the following ways:

    • In the upper right corner of the web system, click the administrator name and select Change Password from the drop-down list, as shown in Figure 1.
      Figure 1 Changing the administrator's password

      In the dialog box that is displayed, enter the current password and new password, and click OK.

    • Choose System > Administrator > Administrator. The Administrator List page is then displayed. Click the name of an administrator and change the administrator password.
