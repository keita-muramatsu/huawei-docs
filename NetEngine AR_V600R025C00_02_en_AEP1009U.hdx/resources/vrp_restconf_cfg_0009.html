GET

The GET method is used to obtain device configuration and state data.

If the GET operation succeeds, the response returned by the server contains the "200 OK" status code and carries the queried data in the response message-body. The data format is restricted by the YANG model, and the data content is processed based on the request and relevant restrictions.
