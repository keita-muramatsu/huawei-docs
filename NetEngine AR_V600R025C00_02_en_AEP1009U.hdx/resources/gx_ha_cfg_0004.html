Overview of Active/Standby Switchover

Introduction

Active/standby switchover is an effective way to ensure intra-chassis high availability, which is implemented through dual main control boards. The 1:1 redundancy mode is generally used to provide reliability for the main control boards. In this mode, one active main control board and one standby main control board are deployed. If the active main control board fails, an active/standby main control board switchover is performed to ensure service continuity.

Active/standby main control board switchovers can be performed in the following modes:

  • Automatic active/standby switchover
  • Manual active/standby switchover

Automatic Active/Standby Switchover

If the active main control board is abnormal (for example, it is powered off manually or resets due to a fault) and Ready is displayed in the Switchover State field, the system automatically performs an active/standby main control board switchover. After the switchover is completed, the standby main control board automatically becomes the active main control board to take over services, ensuring service continuity.

Manual Active/Standby Switchover

If an automatic active/standby main control board switchover fails to be performed because the triggering conditions are not met (for example, the CPU usage is high) and Ready is displayed in the Switchover State field, you can manually perform an active/standby main control board switchover. After the switchover is completed, the original active main control board restarts and becomes the standby main control board. The original standby main control board automatically becomes the active main control board.

The running services are not interrupted during an active/standby switchover.
