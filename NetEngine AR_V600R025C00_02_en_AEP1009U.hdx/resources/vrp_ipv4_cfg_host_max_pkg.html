Configuring the Maximum Rate at Which Host Packets Are Processed

Context

If certain types of packets on a live-network host are heavy and packet loss occurs, you can increase the rate so that the host can process more packets. Conversely, if the live network is attacked by certain types of packets, you can reduce the maximum rate at which these packets are processed to protect the CPU.

Procedure

  1. Run the system-view command to enter the system view.
  2. Run the host-packet rate-limit { port-unreachable | ttl-exceeded | icmp-echo } rate-value all command to configure the maximum rate at which Port Unreachable or TTL Exceeded packets are processed.
