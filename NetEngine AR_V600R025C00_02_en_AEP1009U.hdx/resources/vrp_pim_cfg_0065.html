Data Fails to Be Forwarded Along the SPT on a PIM-DM Network

Symptom

After PIM-DM configuration is complete on a network, user hosts use IGMP to order programs of multicast group G. However, they cannot receive any multicast data.

Procedure

  1. Run the display ip routing-table [ table-name msr ] prefix { mask | masklength } prefix { mask | masklength } [ verbose ] command in any view to check whether there is a unicast route to the multicast source.

    Multicast routing depends on unicast routes. If the device does not have a unicast route to the multicast source, configure a unicast routing protocol to dynamically generate a route or configure a unicast static route to the multicast source.

  2. Run the display pim interface [ interface-name | interface-typeinterface-number | up | down ] [ verbose ] command in any view to check whether PIM-DM is enabled on the interface, especially on the RPF interface.

    If no PIM information is displayed on the interface or the PIM mode on the interface is sparse, PIM-DM is not enabled on the interface. In this case, run the pim dm command in the interface view to enable PIM-DM.

  3. Run the display igmp interface [ interface-typeinterface-number | interface-name ] [ verbose ] command in any view to check whether IGMP is enabled on the interface directly connected to the network segment of user hosts.

    If no information is displayed on the interface, run the igmp enable command in the interface view to enable IGMP.
