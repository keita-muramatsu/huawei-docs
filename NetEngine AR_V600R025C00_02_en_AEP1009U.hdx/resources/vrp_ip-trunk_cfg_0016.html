(Optional) Resetting Statistics on an IP-Trunk Interface

You can reset the existing statistics on an interface before re-collecting traffic statistics on the interface.

Context

To reset the existing statistics on an interface, perform the following operation in the user view.

The statistics of an IP-Trunk interface cannot be restored after you reset them. Exercise caution when performing this operation.

Table 1 Resetting statistics on an interface

Operation

Command

Reset the interface statistics displayed in the display interface ip-trunk interface-number command output.

reset counters interface ip-trunk interface-number
