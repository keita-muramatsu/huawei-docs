Enabling the PoE Function

Context

Ensure that the PoE function is enabled on an interface before powering on a PD connected to the interface.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the interface view.

    interface interface-type interface-number

  3. Enable PoE on the interface.

    poe enable

    By default, the PoE function is enabled.

    If you run the shutdown command to shut down a PoE-enabled interface, the power supply for the interface is not affected. To stop power supply for the interface, run the undo poe enable command in the interface view.

  4. Return to the system view.

    quit

  5. (Optional) Configure the association between the PoE function and the shutdown command on an interface.

    poe track shutdown

    By default, the PoE function is not associated with the shutdown command on an interface. To disable the PoE function on an interface, you need to run the undo poe enable command. After the PoE function is associated with the shutdown command on an interface, the PoE function is disabled when the shutdown command is run on the interface.

  6. (Optional) Configure the PoE anti-interference frequency.

    poe anti-interference frequency { 50 | 60 }

    The default PoE anti-interference frequency is 50 Hz.

    To use the PoE function in countries or regions where the utility frequency is 60 Hz, run the poe anti-interference frequency 60 command to configure the PoE anti-interference frequency.

  7. (Optional) Disable PSE heartbeat detection.

    poe pse-heartbeat disable
