Example for Configuring Association Between VRRP and a Route Monitoring Group

Networking Requirements

To improve device reliability, an access device is dual-homed to gateways on the Layer 3 network, and VRRP is deployed on the dual-homed network to implement gateway redundancy.

If an uplink route changes, the access-side user cannot detect the change and still uses the route to transmit traffic. As a result, service traffic loss occurs. To resolve this issue, configure a VRRP group to track a route monitoring group. When the route becomes inactive, the route monitoring group instructs the VRRP group to perform a master/backup switchover based on the configured down weight.

On the network shown in Figure 1, DeviceA and DeviceB are added to the same VRRP group, and VRRP is associated with a route monitoring group on DeviceA (master). The route monitoring group contains a route destined for an interface on DeviceC. When the interface on DeviceC goes down, the down weight of the route monitoring group is increased. When the down weight of the route monitoring group reaches the fault threshold, a master/backup VRRP switchover is performed. When the interface goes up, the down weight of the route monitoring group decreases. When the down weight falls below the fault threshold, the VRRP group performs a master/backup switchover again, and service traffic is switched back to the original master.

Figure 1 Network diagram of configuring association between VRRP and a route monitoring group

In this example, interface 1 and interface 2 represent 10GE0/0/1 and 10GE0/0/2, respectively.


Precautions

To improve security, you are advised to configure a VRRP security policy. For details, see Example for Configuring VRRP in Master/Backup Mode.

Configuration Roadmap

The configuration roadmap is as follows:

  1. Assign an IP address to each interface to ensure link connectivity.

  2. Configure a VRRP group and a route monitoring group on DeviceA (master) and DeviceB (backup).

    If the link of DeviceA goes down, the VRRP group performs a master/backup switchover, and traffic is switched to the link of DeviceB for forwarding.

  3. Bind a route to the route monitoring group on DeviceA and associate the VRRP group with the route monitoring group so that VRRP can track the route from DeviceA to DeviceC through the route monitoring group.

    If a tracked route in the route monitoring group is withdrawn or becomes inactive, the down weight of the route monitoring group increases. When the down weight reaches the upper threshold, DeviceA's VRRP priority decreases by 40, triggering a master/backup VRRP switchover.

To complete the configuration, you need the following data.

  • Interface IP addresses on DeviceF, DeviceA, DeviceB, and DeviceC. For details, see Configuration Scripts.

  • Virtual IP address of the VRRP group: 10.1.1.10; preemption delay of the master after it recovers: 20s.

  • VRRP associated route monitoring group G1 and route to 192.168.1.0/24 in G1.

Procedure

  1. Configure interface attributes on DeviceF and assign IP addresses to interfaces on DeviceA, DeviceB, and DeviceC.
    # Configure DeviceF.
    <HUAWEI> system-view
[HUAWEI] sysname DeviceF
[DeviceF] interface 10ge 0/0/1
[DeviceF-10GE0/0/1] quit
[DeviceF] interface 10ge 0/0/2
[DeviceF-10GE0/0/2] quit
[DeviceF] vlan 10
[DeviceF-vlan10] port link-type acces
[DeviceF-vlan10] port 10ge 0/0/1
[DeviceF-vlan10] port 10ge 0/0/2
[DeviceF-vlan10] quit
[DeviceF] interface vlanif 10
[DeviceF-Vlanif10] ip address 10.1.1.3 24
    # Configure DeviceA.
    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] ip address 10.1.1.1 24
[DeviceA-10GE0/0/1] quit
[DeviceA] interface 10ge 0/0/2
[DeviceA-10GE0/0/2] ip address 192.168.1.1 24
[DeviceA-10GE0/0/2] quit

    # Configure DeviceB.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceB
[DeviceB] interface 10ge 0/0/1
[DeviceB-10GE0/0/1] ip address 10.1.1.2 24
[DeviceB-10GE0/0/1] quit
[DeviceB] interface 10ge 0/0/2
[DeviceB-10GE0/0/2] ip address 192.168.2.1 24
[DeviceB-10GE0/0/2] quit
    # Configure DeviceC.
    <HUAWEI> system-view
[HUAWEI] sysname DeviceC
[DeviceC] interface 10ge 0/0/1
[DeviceC-10GE0/0/1] ip address 192.168.1.2 24
[DeviceC-10GE0/0/1] quit
  2. Configure basic VRRP group functions.

    # Configure VRRP group 1 on DeviceA. Set the VRRP priority of DeviceA to 120 to ensure it functions as the master, and set the preemption delay to 20s.

    [DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] vrrp vrid 1 virtual-ip 10.1.1.10
[DeviceA-10GE0/0/1] vrrp vrid 1 priority 120
[DeviceA-10GE0/0/1] vrrp vrid 1 preempt timer delay 20
[DeviceA-10GE0/0/1] vrrp recover-delay 20
[DeviceA-10GE0/0/1] quit

    # Configure VRRP group 1 on DeviceC.

    [DeviceB] interface 10ge 0/0/1
[DeviceB-10GE0/0/1] vrrp vrid 1 virtual-ip 10.1.1.10
[DeviceB-10GE0/0/1] quit
  3. Configure IS-IS.

    # Set the IS-IS entity name to 10.0000.0000.0001.00 and the IS-IS level to 1 on DeviceA.

    [DeviceA] isis 1
[DeviceA] is-level level-1
[DeviceA-isis-1] network-entity 10.0000.0000.0001.00
[DeviceA-isis-1] quit
[DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] isis enable 1
[DeviceA-10GE0/0/1] quit
[DeviceA] interface 10ge 0/0/2
[DeviceA-10GE0/0/2] isis enable 1
[DeviceA-10GE0/0/2] quit

    # Set the IS-IS entity name to 10.0000.0000.0002.00 on DeviceC.

    [DeviceC] isis 1
[DeviceA-isis-1] network-entity 10.0000.0000.0002.00
[DeviceA-isis-1] quit
[DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] isis enable 1
[DeviceA-10GE0/0/1] quit
  4. Bind the route to 192.168.1.0/24 to the route monitoring group G1.

    # Configure association between the route monitoring group and route on DeviceA, so that the down weight of the route monitoring group G1 increases by 100 when the route is withdrawn.

    [DeviceA] ip route-monitor-group G1
[DeviceA-route-monitor-group-G1] track ip route 192.168.1.0 255.255.255.0 down-weight 100
[DeviceA-route-monitor-group-G1] monitor enable
[DeviceA-route-monitor-group-G1] quit
  5. Associate VRRP with route monitoring group G1.
    [DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] vrrp vrid 1 track route-monitor-group G1 failure-ratio 50 reduced 40
[DeviceA-10GE0/0/1] quit

Configuration Scripts

  • DeviceA
    #
sysname DeviceA
#
isis 1
 is-level level-1
 network-entity 10.0000.0000.0001.00
#
ip route-monitor-group G1
 track ip route 192.168.1.0 255.255.255.0 down-weight 100
 monitor enable
#
interface 10GE0/0/1 
 ip address 10.1.1.1 255.255.255.0
 vrrp vrid 1 virtual-ip 10.1.1.10
 vrrp vrid 1 priority 120
 vrrp vrid 1 preempt timer delay 20
 vrrp recover-delay 20
 vrrp vrid 1 track route-monitor-group G1 failure-ratio 50 reduced 40
 isis enable 1
#
interface 10GE0/0/2
 ip address 192.168.1.1 255.255.255.0
 isis enable 1
#
return

#

#

#
