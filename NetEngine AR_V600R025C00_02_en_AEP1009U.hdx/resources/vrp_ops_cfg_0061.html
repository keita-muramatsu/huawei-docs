Example for Configuring a Script Assistant for Using a User-defined Command to Monitor Changes of Important Routes

Networking Requirements

As shown in Figure 1, a user manages a device through a remote network and wants to use a user-defined command to monitor changes of important routes and generate logs to detect changes of important routes as soon as they occur.

Figure 1 Networking diagram of monitoring key route changes using user-defined commands

Configuration Roadmap

  1. Make Python scripts climuti.py and route_track.py to customize the command for monitoring changes of important routes and generate logs when important routes change.

  2. Remotely manage the device, upload the Python script to DeviceA, and install the script climuti.py.

  3. Configure a Python script assistant.

Precautions

  • It is recommended that the name of the command subscribed through ops.cli.subscribe be different from that of the Python script file. Otherwise, the Python script file cannot be copied or deleted.
  • The .pyc file is generated after the Python script file is compiled. Whether the .pyc file is generated is irrelevant to whether the corresponding Python script is successfully installed. Therefore, you do not need to pay attention to the .pyc file.
  • The .pyc file cannot be deleted independently. When you run the ops uninstall file command to uninstall a Python script, the .pyc file is automatically deleted.
  • The script-assistant python route_track.py command is displayed in the configuration file only after you enter the routetrack command to trigger the subscribed event in the climuti.py script.

Procedure

  1. Configure an IP address for the specified interface.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] undo portswitch
[DeviceA-10GE0/0/1] ip address 10.1.1.1 24
[DeviceA-10GE0/0/1] quit

  2. Make a Python script.

    # Make a Python script to implement the following functions:

    • The climuti.py script is used to customize the routetrack command to enable the function of monitoring key route changes and install the route_track.py script.
    • The route_track.py script monitors the changes of key routes and generates logs when routes change.

    # Example of the climuti.py script

    # -*- coding: utf-8 -*-
import ops         # Import the ops module.
import sys         # Import the sys module.
import os         # Import the os module.
# Subscription processing function
def ops_condition(_ops):
    # Customize the command routetrack.
    value1, err_str1 = _ops.cli.subscribe("cli1", "routetrack", enter=True)
    # Customize the command no routetrack.
    value2, err_str2 = _ops.cli.subscribe("cli2", "no routetrack", enter=True)
    #Combined event. Enter the command routetrack or no routetrack.
    value10, err_str10 = _ops.correlate("cli1 or cli2")
    return 0
# Work processing function
def ops_execute(_ops):
    # Obtain the system environment variable _cli_input, which indicates the command entered by the user.
    key, value = _ops.environment.get("_cli_input")
    _ops.set_model_type("YANG")
    # When the user enters the routetrack command, perform the following steps:
    if key == "routetrack":
        # Open the command line channel.
        handle, err_desp = _ops.cli.open()
        # Run the ops install file route_track.py command to install the route_track.py script.
        result, n11, n21 = _ops.cli.execute(handle,"ops install file route_track.py")
        # Run the system-view command to enter the system view.
        result, n11, n21 = _ops.cli.execute(handle,"system-view")
        # Run the ops command to enter the OPS view.
        result, n11, n21 = _ops.cli.execute(handle,"ops")
        # Run the script-assistant python route_track.py command to configure the script assistant of route_track.py.
        result, n11, n21 = _ops.cli.execute(handle,"script-assistant python route_track.py")
        # Close the command line channel.
        result = _ops.cli.close(handle)
        # When the user enters the no routetrack command, perform the following steps:
    elif key == "no routetrack":
        # Open the command line channel.
        handle, err_desp = _ops.cli.open()
        # Run the system-view command to enter the system view.
        result, n11, n21 = _ops.cli.execute(handle,"system-view")
        # Run the ops command to enter the OPS view.
        result, n11, n21 = _ops.cli.execute(handle,"ops")
        # Run the undo script-assistant python route_track.py command to delete the script assistant of route_track.py.
        result, n11, n21 = _ops.cli.execute(handle,"undo script-assistant python route_track.py")
        # Run the quit command to return to the system view.
        result, n11, n21 = _ops.cli.execute(handle,"quit")
        # Run the quit command to return to the user view.
        result, n11, n21 = _ops.cli.execute(handle,"quit")
        # Run the ops uninstall file route_track.py command to uninstall the route_track.py script.
        result, n11, n21 = _ops.cli.execute(handle,"ops uninstall file route_track.py")   
        # Close the command line channel.
        result = _ops.cli.close(handle)
    else:
        return 1
    return 0

    # Example of the route_track.py script

    # -*- coding: utf-8 -*-
import ops         # Import the ops module.
import sys         # Import the sys module.
import os         # Import the os module.
# Subscription processing function
def ops_condition(_ops):
    # Monitor changes of OSPF routes on network segment 10.1.1.1/24.
    value, err_str = _ops.route.subscribe("route1", "10.1.1.1", maskLen=24, optype="modify", protocol="ospf")
    return 0
# Work processing function
def ops_execute(_ops):
    # Record user-defined critical-level logs to prompt route changes.
    status, err_log = _ops.syslog("Syslog: The important route changed.", "critical", "syslog")
    return 0

  4. Configure a Python script assistant.

    # Configure a Python script assistant and register the CLI event in the script port_description_lldp.py. Wait for the event to be triggered.

    <DeviceA> system-view
[DeviceA] ops
[DeviceA-ops] script-assistant python climuti.py
[DeviceA-ops] script-assistant python route_track.py
[DeviceA-ops] quit
[DeviceA] quit
