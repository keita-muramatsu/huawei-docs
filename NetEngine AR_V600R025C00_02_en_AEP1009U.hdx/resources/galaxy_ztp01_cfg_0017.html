Starting Email-based Deployment

Prerequisites

  • A browser has been installed on the deployment terminal.
  • The deployment terminal has been connected to the device.
  • The device is unconfigured.
    • Only devices directly connected to the deployment terminal can be deployed using an email.
    • Email-based deployment can be performed only on a PC. The following browsers support email-based deployment: Firefox 107 and later versions, Chrome 107 and later versions, and Edge 107 and later versions.

Procedure

  1. Open the deployment email, copy the URL to the address bar of the browser, and enter the password. The browser displays a deployment portal page, as shown in Figure 1.
    Figure 1 Portal page for email-based deployment

  2. (Optional) Click View Configuration Parameters to view the deployment configuration parameters, as shown in Figure 2.
    Figure 2 Deployment configuration parameters

    There is no need to modify the parameters on the Configuration Parameters page because the system will deliver commands based on the parameters configured in the deployment URL no matter whether you have modified these parameters.

  3. Click Confirm Deployment to start the deployment process, as shown in Figure 3.
    Figure 3 Starting the deployment process

    If this is not the first time for the device to be deployed, click Restore Factory Settings to clear its configurations before the deployment. If the configurations are not cleared, the deployment may fail.

  4. After the device completes the deployment configuration and registers with the controller, the page shown in Figure 4 is displayed on the deployment terminal, indicating that the deployment succeeds.
    Figure 4 Successful deployment
