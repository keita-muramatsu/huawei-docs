Understanding NetStream Sampling Rate Calculation

The NetStream sampling rate is specified by the packet-number parameter in the netstream sampler { ip | ipv6 } fix-packets packet-number { inbound | outbound } command.

The NetStream sampling rate needs to be set according to the packet processing capability of a device, number of interfaces with NetStream sampling configured, sampling direction, interface rate, and average packet length on the network.

It is recommended that the minimum NetStream sampling rate be calculated as follows:

In the preceding formula:

  • Forwarding bandwidth = Number of interfaces on a device x Interface rate (Gbit/s). If NetStream sampling needs to be configured in both the inbound and outbound directions of each interface, the forwarding bandwidth is calculated as follows: Forwarding bandwidth = Number of interfaces x Interface rate x 2.

    Number of interfaces: indicates the number of interfaces configured with NetStream sampling.

    Interface rate: indicates the rate of interfaces configured with NetStream sampling.

    For example, when NetStream sampling is configured on four 10GE interfaces in the inbound direction and on another six 10GE interfaces in both the outbound and inbound directions, the forwarding bandwidth is calculated as follows when the interfaces work at the maximum rate: Forwarding bandwidth = 4 × 10 + 6 × 10 × 2.

  • Average packet length: indicates the average length of packets on the network, in bytes.

  • 20: indicates the length of the interframe gap (IFG) and preamble, in bytes.

  • When NetStream is configured in both the outbound and inbound directions of all the interfaces on a device, and the interfaces work at the maximum rate, you are advised to set the NetStream sampling rate to at least 2048 if the calculated NetStream sampling rate is less than 2048. In other cases, calculate the NetStream sampling rate according to the formula.

  • The NetStream sampling rate must be a power of 2.
