Implementation of Spectrum Analysis

Network Architecture

As shown in Figure 1, the network architecture of spectrum analysis contains the spectrum sampling engine, spectrum analyzer, and interference visualization module.
  • Spectrum sampling engine: collects and sends spectrum information collected on a WLAN to a spectrum analyzer.
  • Spectrum analyzer: analyzes spectrum data, identifies interference source types, and sends the report about interference devices to the interference visualization module.
  • Interference visualization module: displays interference source information in graphs, including real-time spectrum graphs.
Figure 1 Spectrum analysis network architecture

Fundamentals

Spectrum analysis is implemented as follows:

  1. Each AP functions as a spectrum sampling engine to scan and sample the spectrum.

    1. The APs periodically scan the radio environment.

    2. The APs obtain original spectrum sample data from channel scanning. Each piece of spectrum sample data contains a group of subcarriers, which can be used for interference identification.

  2. The spectrum analysis module of each AP serving as a spectrum analyzer computes the sample data based on an algorithm to identify non-Wi-Fi devices.

    A common algorithm involves the following processing steps: pulse signal extraction, pulse signal combining, pulse clustering, extraction of time signatures, extraction of frequency characteristics, period calculation, and duty cycle calculation.

    After the computation is complete, the AP can compare one or more characteristics with those in the interference source signature database to identify non-Wi-Fi devices.

    Currently, APs can identify the following types of non-Wi-Fi devices: Bluetooth devices, microwave ovens, 2.4 GHz cordless phone sets and bases, Zigbee devices, game controllers, 2.4 GHz/5 GHz wireless video and audio devices, baby monitors, and fixed-band devices. Due to spectrum differences, some non-Wi-Fi devices may not be identified.

    The AP adds the identified device to the non-Wi-Fi device list. You can query the non-Wi-Fi device list using the CLI or web system. If the type of an identified device is not in the non-Wi-Fi device list, the AP reports an alarm but it will not report alarms of the same type within 10 minutes. If the type of the identified device is already in the list, the AP does not report an alarm.

  3. The AP reports the data to the interference visualization module.

    The AP can report data to the interference visualization module directly or through the WAC. iMaster NeoSight or iMaster NCE-CampusInsight can be used as an interference visualization module. You can view the spectrum graph on the web system of the WAC.

Spectrum Graphs of Non-Wi-Fi Devices

The AP reports the spectrum data to the spectrum drawing server which then displays the data in graphs. Through the spectrum graphs, users can learn channels, interference strength, and types of interference sources in the wireless environments.

You can determine the frequency of an interference source based on the spectrum density on the spectrum graph, where the signal strength is distinguished by different colors. How is the interference source type determined? The following describes several typical spectrum graphs of non-Wi-Fi devices. When analyzing a spectrum graph, you can identify the interference source type based on the spectrum characteristics.

Typical non-Wi-Fi devices are classified as frequency-hopping devices or fixed-frequency devices.

  • Frequency-hopping devices

    The frequency of a frequency-hopping device changes with time. For example, most of cordless phones, Bluetooth devices, and game controllers are frequency-hopping devices. Figure 2 shows the spectrum of a Bluetooth device (horizontal axis: time; vertical axis: frequency). The red squares indicate the signal of the Bluetooth device. The signal appears at the 2465 MHz frequency in the time scale [6,9] and hops over to the 2475 MHz frequency at the next time scale [9,12].

    Figure 2 Spectrum of a frequency-hopping device

  • Fixed-frequency devices

    The frequency of a fixed-frequency device remains unchanged. Typical fixed-frequency devices include microwave ovens, wireless cameras, and wireless video and audio transmitters. In terms of bandwidth occupation, fixed-frequency devices are classified as broadband or narrowband devices.
    • Broadband devices: occupy large bandwidth, such as microwave ovens that operate on several channels such as 11, 12, and 13. Figure 3 shows the real-time spectrum of a microwave oven (horizontal axis: time; vertical axis: frequency). In addition to broadband characteristics, the microwave oven also has obvious frequency scanning features, that is, the center frequency drifts up and down.
      Figure 3 Spectrum of a broadband device
    • Narrowband devices: occupy small bandwidth, such as wireless cameras, wireless video and audio transmitters, and baby monitors. Figure 4 shows the realtime spectrum of a baby monitor (horizontal axis: time; vertical axis: frequency).
