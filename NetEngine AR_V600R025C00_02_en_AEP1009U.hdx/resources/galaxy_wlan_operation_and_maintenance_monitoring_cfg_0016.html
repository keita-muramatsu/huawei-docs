Configuring CSI Sensing Data Collection and Reporting

Context

CSI data in Wi-Fi signals can reflect the motion status of objects within a given space. Under conditions where the locations of the Wi-Fi signal transmitter and receiver remain constant, the CSI values typically remain stable in the absence of moving objects. However, when a person is moving in the environment, the CSI values change significantly as a result of the signal reflections caused by the person's movement. Based on these characteristics, after the CSI sensing function for APs at a single site is enabled, the AP itself sends and receives Wi-Fi signals for collecting CSI data to sense and identify nearby people. After the data is uploaded to iMaster NCE-CampusInsight, the results of sensing and identifying human presence can be displayed on physical and digital maps, facilitating power control and energy saving. After iMaster NCE-CampusInsight is connected to a third-party building management system, more functions can be implemented, such as intelligent shutdown of electrical appliances and intrusion detection.

Only some APs running V600 support the CSI sensing function. For details, query the specifications on Info-Finder (Enterprise Network or Carrier).

CSI sensing can be configured in the AP system profile view and AP view, and the configuration in the AP view takes precedence.

Procedure

  • Configuring the CSI sensing function for APs in batches using an AP system profile
    1. Enter the system view.

      system-view

    2. Enter the WLAN view.

      wlan

    3. Create an AP system profile and enter its view.

      ap-system-profile name profile-name

      By default, the AP system profile default exists in the system.

    4. Enable CSI sensing on APs.

      csi enable

      By default, the CSI sensing function is disabled for APs in the AP system profile view.

    5. (Optional) Configure CSI sensing parameters.

      Adjust the parameters based on the network planning result, CloudCampus APP test result, and CSI sensing requirements.

      • Configure the CSI sensing distance range of APs.
        csi distance-range presence-enter-range enter-value presence-leave-range leave-value

        By default, the distance range for sensing people leaving and entering are both 100 decimeters in an AP system profile. In the AP view, the CSI sensing distance range is not configured by default, and the configuration in the AP system profile is used.

      • Configure the action sensing sensitivity level of the CSI sensing function for APs.
        csi action-sensitivity-level level-value

        By default, the action sensitivity level is high for APs in the AP system profile view. In the AP view, the system uses the configuration from the AP system profile by default.

      • Configure the motion detection threshold of the CSI sensing function for APs.
        csi motion-detection-threshold threshold-value

        By default, the motion detection threshold of the CSI sensing function is 0 in the AP system profile view. In the AP view, the system uses the configuration from the AP system profile by default.

      • Configure the human presence aging time, that is, the duration during which the CSI sensing function detects no person after human presence is determined.
        csi presence-aging-time time

        By default, the human presence aging time of the CSI sensing function is 600s in the AP system profile view. In the AP view, the system uses the configuration from the AP system profile by default.

      • Configure the person re-entry delay, that is, the delay for re-detecting human presence after the human presence state is aged.
        csi presence-re-enter-delay delay-time

        By default, the person re-entry delay of the CSI sensing function is 0s in the AP system profile view. In the AP view, the system uses the configuration from the AP system profile by default.

      • Configure the distance sensing sensitivity of the CSI sensing function for APs.
        csi distance-sensitivity value

        By default, the distance sensing sensitivity of the CSI sensing function is 100 in the AP system profile view. In the AP view, the system uses the configuration from the AP system profile by default.

    6. Configure APs to report CSI sensing data.

      Select one or more of the following data reporting modes based on the network requirements:

      • Configure APs to report CSI sensing data to iMaster NCE-CampusInsight.

        To display CSI data on iMaster NCE-CampusInsight, you need to configure APs to report KPI information to iMaster NCE-CampusInsight through WMI and run the collect-item csi-data enable command to enable the function of reporting CSI data. For details, see Configuring APs to Directly Report KPI Information.

      • Configure APs to report CSI sensing data to the container. To report CSI sensing data to the container, ensure that the container has been loaded to APs. For details, see Installing or Uninstalling a Container on an AP.
        csi report-to-container

        By default, CSI sensing results are not reported to the container in the AP view or AP system profile view.

      • Configure APs to report CSI sensing data to a server.
        csi report-to-server { ip-address ip-address | ipv6-address ipv6-address | domain domain } port port-num

        By default, no server is specified for receiving CSI sensing results reported by APs.

    7. Return to the WLAN view.

      quit

    8. Enter the AP view or AP group view.

      • Enter the AP group view.
        ap-group name group-name
      • Enter the AP view.
        ap-id ap-id

    9. Bind the AP system profile to an AP group or a specific AP.

      ap-system-profile profile-name

      By default, the AP system profile default is bound to an AP group, but no AP system profile is bound to an AP.

  • Configure the CSI sensing function for a specified AP in the AP view.
    1. Enter the system view.

      system-view

    2. Enter the WLAN view.

      wlan

    3. Enter the AP view.

      ap-id ap-id

    4. Enable or disable the CSI sensing function for a specified AP.

      csi { enable | disable }

      By default, the system uses the configuration for this function from the AP system profile.

    5. (Optional) Configure CSI sensing parameters.

      Adjust the parameters based on the network planning result, CloudCampus APP test result, and CSI sensing requirements.

Verifying the Configuration

  • Run the display ap-system-profile name profile-name command to check the CSI configuration in the AP system profile.
  • Run the display ap config-info ap-id ap-id command to check the CSI configuration of a specified AP.
