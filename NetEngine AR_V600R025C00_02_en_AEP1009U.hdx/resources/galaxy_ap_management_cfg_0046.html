(Optional) Configuring LLDP Power Capacity Negotiation

Context

You can configure the TLV in LLDP packets so that the device can classify PDs using LLDP. Devices that are not configured with LLDP detect and classify PDs by analyzing current and resistance between the device and PDs. Compared with current and resistance analysis, the LLDP function provides a more comprehensive and accurate analysis.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Enable LLDP.

    undo ap lldp disable

    By default, LLDP is enabled in the WLAN view.

  4. Create an AP wired port link profile and enter its view.

    port-link-profile name profile-name

    By default, the AP wired port link profile default exists on the device.

  5. Enable LLDP on AP wired interfaces.

    undo lldp disable

    By default, LLDP is enabled on AP wired interfaces.

  6. Configure LLDP to advertise the Power Via MDI TLV.

    undo lldp tlv-disable dot3-tlv power

    By default, an AP wired interface advertises the Power Via MDI TLV.

  7. Configure LLDP to advertise the 802.3 Power via MDI TLV.

    lldp dot3-tlv power { 802.1ab | 802.3at | 802.3bt }

    By default, a UPoE interface advertises 802.3 Power via MDI TLV in compliance with 802.3 bt, and a PoE interface advertises 802.3 Power via MDI TLV in compliance with 802.3 at.

  8. Configure LLDPDUs sent by an AP to carry its power capability.

    undo lldp tlv-disable legacy-tlv power-capability

    By default, LLDPDUs sent by an AP carry its power capability.

  9. Configure AP wired interfaces to advertise Cisco's proprietary TLVs.

    undo lldp tlv-disable legacy-tlv four-pair-power

    By default, an AP wired interface advertises Cisco's proprietary TLVs.
