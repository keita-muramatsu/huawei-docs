(Optional) Setting Global Service Parameters of SPR

Context

Based on the service plan and networking requirements of the live network, adjust service parameters related to SPR to improve service forwarding quality and efficiency.

Global service parameters of SPR include the flapping suppression period, link switchover period, interval at which link quality data is updated, and link switchback period.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the SPR configuration view.

    smart-policy-route

  3. Adjust global service parameters based on the link quality requirements of different services.

    Table 1 Global service parameters of SPR

    Operation

    Command

    Description

    Set the flapping suppression period.

    suppress-flapping-period period-value

    By default, the flapping suppression period is not set.

    NOTICE:

    If the link switchover period is set, the flapping suppression period must be set to a value of at least twice the link switchover period.

    Configure the link switchover period.

    switch-period period-value

    Set the switchover period based on service characteristics. For example, voice services have high requirements on real-time performance, so a short switchover period should be set for such services.

    NOTICE:

    If the flapping suppression period is set, the link switchover period cannot be set to a value greater than half of the flapping suppression period.

    By default, the link switchover period is 5 seconds.

    Configure the interval for updating link quality data.

    refresh-period period-value

    The device periodically obtains link quality data based on the interval for updating link quality data.

    By default, link quality data is updated at an interval of 5 seconds.

    Configure the link switchback period.

    wait-to-restore-period period-value

    By default, the switchback period is not set.

    Enable the SPR switchover alarm suppression function.

    suppress-switch-trap enable

    By default, the SPR switchover alarm suppression function is disabled.

    Configure the SPR switchover alarm suppression threshold.

    suppress-switch-trap threshold threshold-value

    By default, the SPR switchover alarm suppression threshold is 100. That is, SPR switchover alarms that exceed the limit of 100 are suppressed.

    Configure the period in which SPR switchover alarms are suppressed.

    suppress-switch-trap time time-value

    By default, the period in which SPR switchover alarms are suppressed is 120 seconds.
