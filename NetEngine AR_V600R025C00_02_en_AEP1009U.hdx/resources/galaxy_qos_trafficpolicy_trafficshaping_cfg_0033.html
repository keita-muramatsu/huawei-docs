Verifying the Configuration

Procedure

Operation

Command

Check the configured traffic classifiers.

display traffic classifier [ classifier-name ]

Check the configured traffic behaviors.

display traffic behavior [ behavior-name ]

Check the configured traffic policy.

display traffic policy [ policy-name [ classifier classifier-name ] ]

Check the traffic policy application records.

display traffic-policy applied-record

Check the traffic statistics after MQC-based traffic policing is enabled.

display traffic-policy statistics

Check the CAR profile configuration.

display qos car [ name car-name ]

Check the application status of IP address-based traffic policing on an interface.

display qos car apply-state [ interface { interface-type interface-number | interface-name } ] [ inbound | outbound ]

NOTE:

The AR5710-S8T2S, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8P2X, and AR5710-S10T1X2 do not support this function.

Check statistics about traffic policing based on an IP address range on an interface.

display qos car ip-range statistics interface { interface-type interface-num | interface-name } { inbound | outbound }

NOTE:

The AR5710-S8T2S, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8P2X, and AR5710-S10T1X2 do not support this function.
