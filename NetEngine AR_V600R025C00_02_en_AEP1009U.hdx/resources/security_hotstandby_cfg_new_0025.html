Configuring an SD-WAN EVPN Dual-Gateway Site

Prerequisites

Before configuring an SD-WAN EVPN dual-gateway site, you have completed the following tasks:

  • Configure SD-WAN EVPN sites on the two devices that form a hot standby group. For details, see Steps 1 through 3 in "Configuring TNP" in CLI Configuration Guide-VPN Configuration > SD-WAN EVPN Configuration.
  • Configure hot standby. For details, see Configuring Hot Standby.

Context

The dual-gateway mode improves reliability and increases bandwidth for sites in the SD-WAN EVPN solution. In this mode, the two devices use the hot-standby channel to transmit the information that must be synchronized and the status entry information required by dual-gateway mode. For details, see Status Information Backup.

To determine the application type of packets and execute appropriate route selection policies, devices need to learn the complete TCP session interaction process. If packets are sent and received over different paths, the devices at either end of the link process only unidirectional packets and cannot determine their application types. Upon receipt of TCP-ACK packet, if the local device finds that it did not process the corresponding TCP-SYN packet and it does not have the application identification information of the session table corresponding to the TCP-ACK packet, it sends the TCP-ACK packet and subsequent packets to the peer device through the specified link. After processing bidirectional packets, the peer device determines the application type of the packets, records the application type in the application identification information of the session table, and forwards the packets based on a route selection policy. The local device can also process subsequent packets after the application identification information of the session table is synchronized to it.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the site view.

    evpn site site-id

  3. Set the gateway type of the site to dual-gateway.

    gateway dual peer-system-id peer-system-id

    The device configured with dual-gateway exchanges status information with the peer device through HRP packets.

    By default, the gateway type of a site is single-gateway. If TNP is configured for a site, the gateway type cannot be changed. To change the gateway type, run the undo transport-network-port command to delete the TNP configuration first.

  4. Return to the system view.

    quit

  5. Enter the interface view.

    interface interface-type interface-number

  6. Configure an interface type.

    port-type { uni | nni | ini }

    If the local device does not process the TCP request packet corresponding to a TCP reply packet it receives from a WAN interface (NNI), it sends the reply packet to the peer device through the interlink interface.
