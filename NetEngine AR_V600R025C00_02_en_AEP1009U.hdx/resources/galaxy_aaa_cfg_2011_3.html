(Optional) Configuring VIP Users

Context

You can configure users as VIP users to preferentially guarantee their services.

For example, in some high-density access scenarios such as exhibition halls and stadiums, many user terminals work on the same channel. To reduce the impact of factors such as concurrent services and air interface contention, the number of access STAs on a radio or VAP usually needs to be limited in these scenarios. Once the number reaches the maximum, new STAs are not allowed to access the network. This, however, also causes VIP users to fail to access the network, affecting VIP user experience. In this case, you can configure some users as VIP users. When the number of access users reaches the threshold, the device allows VIP users to access the network and disconnects online non-VIP users. This preferentially guarantees access experience of VIP users.

You can configure VIP users using the following methods:

  • Authorize users as VIP users: Remote server authorization and local domain authorization are supported.

Only wireless users support this function.

Procedure

  • Authorize a user as a VIP user.
    1. Enter the system view.

      system-view

    2. Enter the AAA view.

      aaa

    3. Enter the service scheme view and configure the user priority.

      service-scheme service-scheme-name
priority priority-value

      By default, the user priority is 0. If the priority of a user is 1, the user is a VIP user.

    4. Return to the AAA view.

      quit

    5. Configure authorization.

      • Remote server authorization: Configure VIP users and their authorization information on the server.
      • Local domain authorization: Bind a service scheme to a user authentication domain.
        domain domain-name
service-scheme service-scheme-name

Verifying the Configuration

  • Run the display service-scheme [ name name ] command to check the service scheme configuration.

Follow-up Procedure

Configure preferential access of VIP users. For details, see Configuring Preferential Access of VIP Users.
