Configuring Alarm Thresholds for Optical Power

Context

By configuring alarm thresholds for optical power, you can mask the alarms that you are not concerned about.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the interface view.

    interface interface-type interface-number

  3. (Optional) Preconfigure a medium type for the interface.

    device transceiver transceiver-type

    Alarm thresholds can be configured for optical power only after an optical module is inserted into an interface. If no optical module is inserted into the interface, you can perform this step to preconfigure the medium type of the interface as fiber.

  4. Configure alarm thresholds for optical power.

    set transceiver { rx-power | tx-power } { { low-threshold low-threshold-value } | { high-threshold high-threshold-value } } *

    By default, no alarm threshold is configured for optical power.
