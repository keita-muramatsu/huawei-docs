(Optional) Configuring Periodic Alarm Synchronization

Context

After the periodic alarm synchronization function is enabled, the master device periodically obtains active critical and major alarms from member devices and displays the obtained alarms on WebMaster. This allows you to centrally view and handle alarms.

All commands in this section need to be configured on the master device.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the net assistant view.

    net-assistant

    By default, the net assistant view is not displayed.

  3. Enable periodic alarm synchronization.

    alarm-synchronization enable

    By default, periodic alarm synchronization is enabled.

  4. Set an interval for periodic alarm synchronization.

    alarm-synchronization interval interval-paravalue

    By default, the interval for periodic alarm synchronization is automatically adjusted based on the number of approved member devices that support alarm management. The adjustment rules are as follows:

    If the number of member devices is less than or equal to 50, the synchronization interval is 5 minutes.

    If the number of member devices is greater than 50 but less than or equal to 100, the synchronization interval is adjusted to 10 minutes.

    If the number of member devices is greater than 100 but less than or equal to 200, the synchronization interval is extended to 20 minutes.

    If the number of member devices exceeds 200, the synchronization interval is set to 30 minutes.
