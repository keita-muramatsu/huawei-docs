Configuring LLDP on an AP

Context

LLDP helps the NMS obtain information such as the device topology, device interface status, and management address.

After LLDP is configured on an AP, the AP can send LLDPDUs carrying local system status information to directly connected neighbors and parse LLDPDUs received from neighbors.

To enable an AP to discover neighbors, enable LLDP on the AP and access device to which the AP directly connects.

After LLDP neighbor reporting is configured on an AP, the AP sends neighbor information to the WAC so that the NMS can obtain LLDP information about APs from the WAC to obtain the network topology.

An AP can send and receive LLDPDUs only after LLDP is enabled in both the WLAN view and the AP wired port link profile view.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Enable LLDP.

    undo ap lldp disable

    By default, LLDP is enabled in the WLAN view.

  4. Configure the LLDP neighbor reporting function for APs in the AP system profile view.
    1. Create an AP system profile and enter its view.

      ap-system-profile name profile-name

      By default, the AP system profile default exists on the device.

    2. Configure the LLDP neighbor reporting function.

      lldp report enable

      By default, the LLDP neighbor reporting function is disabled on an AP.

    3. Return to the WLAN view.

      quit

  5. Configure LLDP in the AP wired port link profile view.
    1. Create an AP wired port link profile and enter its view.

      port-link-profile name profile-name

      By default, the AP wired port link profile default exists on the device.

    2. Enable LLDP on an AP's wired interface.

      undo lldp disable

      By default, LLDP is enabled on an AP's wired interface.

    3. Configure the types of TLVs that can be advertised from an AP's wired interface.

      undo lldp tlv-disable basic-tlv { all | management-address | port-description | system-capability | system-description | system-name }

      By default, an AP's wired interface advertises all types of TLVs.

    4. Return to the WLAN view.

      quit

    5. Create an AP wired port profile and enter its view.

      wired-port-profile name wired-port-profile-name

      By default, the AP wired port profile default exists on the device.

    6. Bind the AP wired port link profile to the AP wired port profile.

      port-link-profile profile-name

      By default, the AP wired port link profile default is bound to an AP wired port profile.

    7. Return to the WLAN view.

      quit

  6. Enter the AP view or AP group view.
    • Enter the AP group view.
      ap-group name group-name
    • Enter the AP view.
      ap-id ap-id
  7. Bind the AP system profile to an AP group or a single AP.

    ap-system-profile profile-name

    By default, the AP system profile default is bound to an AP group, but no AP system profile is bound to an AP.

  8. Bind the AP wired port profile to an AP group or a single AP.

    wired-port-profile profile-name interface-type interface-number

    By default, the AP wired port profile default is bound to an AP group, but no AP wired port profile is bound to an AP.
