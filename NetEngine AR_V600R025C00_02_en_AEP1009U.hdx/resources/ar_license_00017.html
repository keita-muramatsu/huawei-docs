Restoring an Invalidated License

Prerequisites

The license has been invalidated on the device and the license code has been obtained.

To obtain the codes of invalidated licenses, run the display license revoke-ticket command in any view on the device.

Context

If a license is revoked on a device by mistake and becomes unavailable, you can use the Revoked License Recovery function to recover the license.

Compared with the old license file, the new license file has a different license serial number (LSN) only. This has no impact on services.

The capacity, functionality, product, version, and ESN information in the new license file is the same as that in the invalidated license file, and only the LSN is different.

Only permanent commercial licenses can be recovered. Fixed-term commercial licenses cannot be recovered.

Procedure

  1. Click Add Revocation Code.

    Path: License Management > License Commissioning and Maintenance > Revoked License Recovery

  2. Enter the revocation code and click Verify Revocation Code.

  3. Select a record and click Submit. Then the license file is automatically generated. Click Save.
