MIB Description

The MIB is a collection of managed objects (MOs). It defines the following attributes of an MO:

  • Object name

  • Access permission

  • Data type of the object

The Structure of Management Information (SMI) stipulates how to define and organize the MOs. It also defines the data types for these objects, for example, counter and gauge.

The MIB designates the variables maintained by the network elements. The variables are the information that can be queried and set by NMS. The MIB provides a data structure of the combination of the all the possibly managed objects on a network.

To ensure that the original third-party NMS-side software can still work properly after MIB upgrade, the MBI modification can only be suffixed to the original definition once the MIB file is officially released. The abandoned MIB cannot be deleted, ensuring compatibility. Therefore, after you load the MIB file released with the product through the third-party NMS software, not all MIBs on the software page can be read or written. You can read and write the MIBs described in this document through the third-party NMS. The MIBs not supported by the device are not mentioned.
