Example for Configuring MP

Networking Requirements

In Figure 1, two pairs of E1 interfaces on DeviceA and DeviceB are bundled into MP-Group interfaces and interconnect the two devices, increasing bandwidth quickly, efficiently, and securely.

Figure 1 Network diagram of adding E1 interfaces to MP-Group interfaces

In this example, interface1, interface2, interface3, and interface4 represent E1 1/0/1, E1 1/0/2, E1 2/0/1, and E1 2/0/2, respectively.

Configuration Roadmap

Bundle PPP links to implement MP and increase transmission bandwidth.

Interfaces on different cards can be added to an MP-Group interface. During this configuration, you need to create an MP-Group 0/0/X interface first.

Procedure

  1. Create MP-Group interfaces.

    # Create an MP-Group interface on DeviceA and configure an IP address for the interface.

    <HUAWEI> system-view 
[HUAWEI] sysname DeviceA 
[DeviceA] interface mp-group 1/0/1
[DeviceA-Mp-group1/0/1] ip address 10.1.1.1 255.255.255.0
[DeviceA-Mp-group1/0/1] quit

    # Create an MP-Group interface on DeviceB and configure an IP address for the interface.

    <HUAWEI> system-view 
[HUAWEI] sysname DeviceB 
[DeviceB] interface mp-group 2/0/1
[DeviceB-Mp-group2/0/1] ip address 10.1.1.2 255.255.255.0
[DeviceB-Mp-group2/0/1] quit

  2. Create synchronous serial interfaces and add the interfaces to corresponding MP-Group interfaces.

    # Configure E1 interfaces on DeviceA as synchronous serial interfaces and add them to the MP-Group interface on DeviceA.

    [DeviceA] controller e1 1/0/1 
[DeviceA-E1 1/0/1] channel-set 1 timeslot-list 1-15 
[DeviceA-E1 1/0/1] quit 
[DeviceA] controller e1 1/0/2
[DeviceA-E1 1/0/2] channel-set 1 timeslot-list 16-31 
[DeviceA-E1 1/0/2] quit 
[DeviceA] interface serial 1/0/1:1 
[DeviceA-Serial1/0/1:1] link-protocol ppp 
[DeviceA-Serial1/0/1:1] ppp mp mp-group 1/0/1 
[DeviceA-Serial1/0/1:1] quit 
[DeviceA] interface serial 1/0/2:1 
[DeviceA-Serial1/0/2:1] link-protocol ppp 
[DeviceA-Serial1/0/2:1] ppp mp mp-group 1/0/1 
[DeviceA-Serial1/0/2:1] quit

    # Configure E1 interfaces on DeviceB as synchronous serial interfaces and add them to the MP-Group interface on DeviceB.

    [DeviceB] controller e1 2/0/1 
[DeviceB-E1 2/0/1] channel-set 1 timeslot-list 1-15 
[DeviceB-E1 2/0/1] quit 
[DeviceB] controller e1 2/0/2
[DeviceB-E1 2/0/2] channel-set 1 timeslot-list 16-31 
[DeviceB-E1 2/0/2] quit 
[DeviceB] interface serial 2/0/1:1 
[DeviceB-Serial2/0/1:1] link-protocol ppp 
[DeviceB-Serial2/0/1:1] ppp mp mp-group 2/0/1 
[DeviceB-Serial2/0/1:1] quit 
[DeviceB] interface serial 2/0/2:1 
[DeviceB-Serial2/0/2:1] link-protocol ppp 
[DeviceB-Serial2/0/2:1] ppp mp mp-group 2/0/1
[DeviceB-Serial2/0/2:1] quit

  3. Restart all the interfaces for the configuration to take effect.

    # Restart the synchronous serial interfaces and the MP-Group interface on DeviceA.

    [DeviceA] interface serial 1/0/1:1 
[DeviceA-Serial1/0/1:1] shutdown 
[DeviceA-Serial1/0/1:1] undo shutdown 
[DeviceA-Serial1/0/1:1] quit 
[DeviceA] interface serial 1/0/2:1 
[DeviceA-Serial1/0/2:1] shutdown 
[DeviceA-Serial1/0/2:1] undo shutdown 
[DeviceA-Serial1/0/2:1] quit 
[DeviceA] interface mp-group 1/0/1 
[DeviceA-Mp-group1/0/1] shutdown 
[DeviceA-Mp-group1/0/1] undo shutdown  
[DeviceA-Mp-group1/0/1] quit

    # Restart the synchronous serial interfaces and the MP-Group interface on DeviceB.

    [DeviceB] interface serial 2/0/1:1
[DeviceB-Serial2/0/1:1] shutdown 
[DeviceB-Serial2/0/1:1] undo shutdown 
[DeviceB-Serial2/0/1:1] quit 
[DeviceB] interface serial 2/0/2:1 
[DeviceB-Serial2/0/2:1] shutdown
[DeviceB-Serial2/0/2:1] undo shutdown 
[DeviceB-Serial2/0/2:1] quit 
[DeviceB] interface mp-group 2/0/1 
[DeviceB-Mp-group2/0/1] shutdown  
[DeviceB-Mp-group2/0/1] undo shutdown  
[DeviceB-Mp-group2/0/1] quit

Configuration Scripts

  • DeviceA
    # 
sysname DeviceA 
# 
interface Mp-group1/0/1 
 ip address 10.1.1.1 255.255.255.0 
# 
controller E1 1/0/1 
 channel-set 1 timeslot-list 1-15 
# 
interface Serial1/0/1:1 
 link-protocol ppp 
 ppp mp Mp-group1/0/1 
# 
controller E1 1/0/2 
 channel-set 1 timeslot-list 16-31 
# 
interface Serial1/0/2:1  
 link-protocol ppp 
 ppp mp Mp-group1/0/1  
#
return

    # 
sysname DeviceB

#
