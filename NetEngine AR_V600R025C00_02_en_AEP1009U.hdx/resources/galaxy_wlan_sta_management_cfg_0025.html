Configuring the STA Blacklist and Whitelist

Context

On a WLAN, a STA blacklist or whitelist can be configured to filter access from STAs. The blacklist or whitelist allows authorized STAs to connect to the WLAN and rejects access from unauthorized STAs.

  • A whitelist contains MAC addresses of STAs that are allowed to connect to a WLAN. After the STA whitelist function is enabled, only the STAs matching the whitelist can connect to the WLAN.
  • A blacklist contains MAC addresses of STAs that are not allowed to connect to a WLAN. After the STA blacklist function is enabled, STAs matching the blacklist cannot connect to the WLAN.

If the STA whitelist or blacklist function is enabled but the whitelist or blacklist is empty, all STAs can connect to the WLAN.

To allow only a few STAs to connect to the WLAN, configure a STA whitelist profile and bind it to an AP system profile or a VAP profile. To forbid only a few STAs to connect to the WLAN, configure a STA blacklist profile and bind it to an AP system profile or a VAP profile. When the STA whitelist or blacklist profile is bound to different types of profiles, their effective scopes are different.

  • AP system profile: The STA whitelist or blacklist profile takes effect based on the AP. If an AP uses the AP system profile, the STA whitelist and blacklist profiles take effect on all STAs connected to the AP (including all its VAPs).
  • VAP profile: The STA whitelist or blacklist profile takes effect based on the VAP. If an AP uses the VAP profile, the STA whitelist and blacklist profiles take effect on all STAs on the corresponding VAP.

When a STA blacklist or whitelist profile is bound to both an AP system profile and a VAP profile, a STA that fails to meet any access condition cannot go online.

In a VAP profile or an AP system profile, either the STA whitelist profile or STA blacklist profile takes effect at a time.

To improve privacy protection capabilities, some mainstream smart STAs (such as Android phones) can use random MAC addresses to associate with a WLAN. The MAC addresses used by STAs to associate with a WLAN may not be their real physical MAC addresses. Therefore, MAC address-based services cannot take effect. You are not advised to configure the blacklist or whitelist service for smart STAs.

Procedure

  • Configure a STA whitelist.
    1. Enter the system view.

      system-view

    2. Enter the WLAN view.

      wlan

    3. Create a STA whitelist profile and enter its view.

      sta-whitelist-profile name profile-name

      By default, no STA whitelist profile is created.

    4. Add STAs to the whitelist. You can perform both or either of the following steps:

      • Configure the MAC address of a STA in the whitelist.
        sta-mac mac-address [ description description ]

        By default, the MAC address of a STA is not added to the whitelist.

      • Configure the OUI of a STA in the whitelist.
        oui oui [ description description ]

        By default, the OUI of a STA is not added to the whitelist.

    5. Return to the WLAN view.

      quit

    6. Bind the STA whitelist profile to an AP system profile or VAP profile.

      • Bind a STA whitelist profile to a VAP profile.
        vap-profile name profile-name
sta-access-mode whitelist profile-name

        By default, no STA whitelist profile is bound to a VAP profile.

      • Bind a STA whitelist profile to an AP system profile.
        ap-system-profile name profile-name
sta-access-mode whitelist profile-name

        By default, no STA whitelist profile is bound to an AP system profile.

  • Configure a STA blacklist.
    1. Enter the system view.

      system-view

    2. Enter the WLAN view.

      wlan

    3. Create a STA blacklist profile and enter its view.

      sta-blacklist-profile name profile-name

      By default, no STA blacklist profile is created.

    4. Configure the MAC address of a STA in the blacklist.

      sta-mac mac-address [ description description ]

      By default, the MAC address of a STA is not added to the blacklist.

    5. Return to the WLAN view.

      quit

    6. Bind the STA blacklist profile to an AP system profile or VAP profile.

      • Bind a STA blacklist profile to a VAP profile.
        vap-profile name profile-name
sta-access-mode blacklist profile-name

        By default, no STA blacklist profile is bound to a VAP profile.

      • Bind a STA blacklist profile to an AP system profile.
        ap-system-profile name profile-name
sta-access-mode blacklist profile-name

        By default, no STA blacklist profile is bound to an AP system profile.

Verifying the Configuration

  • Run the display sta-whitelist-profile { all | name profile-name } command to check configuration and reference information about a STA whitelist profile.
  • Run the display sta-blacklist-profile { all | name profile-name } command to check configuration and reference information about a STA blacklist profile.
  • Run the display references sta-whitelist-profile name profile-name command to check reference information about a STA whitelist profile.
  • Run the display references sta-blacklist-profile name profile-name command to check reference information about a STA blacklist profile.
