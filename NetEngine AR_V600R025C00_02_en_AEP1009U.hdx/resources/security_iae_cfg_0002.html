Overview of ASE

Definition

The Adaptive Security Engine (ASE) is a high-performance integrated content security detection engine that integrates various functions of content security detection and filtering on packets.

Purpose

The device currently supports various functions of content security detection and filtering on packets, including URL filtering, intrusion prevention system (IPS), and antivirus. Before the introduction of the ASE, each service module separately performed content inspection and filtering on packets. This negatively impacted device performance because content inspection was performed each time packets passed through a service module.

The ASE integrates content security-related service functions to perform integrated detection and processing on packets. In this manner, service modules concurrently process packets and packet detection needs to be performed only once to implement multiple content security functions. As a result, there is a significant improvement in device performance.
