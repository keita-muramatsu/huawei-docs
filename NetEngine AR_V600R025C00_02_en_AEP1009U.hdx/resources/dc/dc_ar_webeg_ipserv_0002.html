Example for Configuring the Device as a DHCP Server to Dynamically Assign IP Addresses to Users

Applicable Product and Version

This example applies to all models of routers running V600R025C00 and later versions.

Networking Requirements

On the network shown in Figure 1, the router needs to function as a DHCP server to dynamically assign IP addresses to users on the network segment 10.10.1.0/24, which is divided into two subnets 10.10.1.0/25 and 10.10.1.128/25. In this example, Ethernet interfaces 10GE0/0/2 and 10GE0/0/7 on the router are configured with IP addresses 10.10.1.1/25 and 10.10.1.129/25 and belong to VLAN 10 and VLAN 20, respectively. It is required that PCs on the 10.10.1.0/25 subnet be assigned IP addresses with a lease period of 10 days and 12 hours, a DNS server address of 10.10.1.2, a NetBIOS server address of 10.10.1.4, and an egress gateway address of 10.10.1.1. For PCs on the 10.10.1.128/25 subnet, IP addresses must be assigned with a lease period of 5 days, with the same DNS server address 10.10.1.2, egress gateway address of 10.10.1.129, and no defined NetBIOS server.

Figure 1 Network diagram for configuring the DHCP server function

Context

1. On the VLAN page, create VLANs 10 and 20, set the IP addresses of VLANIF 10 and VLANIF 20 to 10.10.1.1/25 and 10.10.1.129/25 respectively, and assign Ethernet interfaces on the router to the VLANs as planned.

2. On the DHCP page, create two DHCP interface address pools. For the first address pool, set the address segment to 10.10.1.0/25, lease period to 10 days and 12 hours, DNS server address to 10.10.1.2, NetBIOS server address to 10.10.1.4, and egress gateway address to 10.10.1.1. For the second address pool, set the address segment to 10.10.1.128/25, lease period to 5 days, DNS server address to 10.10.1.2, and egress gateway address to 10.10.1.129, and leave the NetBIOS server address empty.

Procedure

  1. Configure IP addresses for interfaces.
    1. Choose Config > LAN Configuration > VLAN. The VLAN page is displayed, as shown in Figure 2.

      Figure 2 VLAN list

    2. On the VLAN page, click Create. On the Create VLAN page that is displayed, set the VLAN ID to 10, as shown in Figure 3.

      Figure 3 Creating a VLAN

    3. Click , select 10GE0/0/2, set the interface mode to Trunk, and click OK, as shown in Figure 4.

      Figure 4 Select Interface

    4. Select next to Create a VLANIF Interface, and enter the IPv4 address 10.10.1.1 and mask 255.255.255.128, as shown in Figure 5.

      Figure 5 Creating a VLANIF interface

    5. Click OK to submit the configuration.

    Repeat this step to create VLAN 20, and set the IP address of 10GE0/0/7 to 10.10.1.129 and subnet mask to 255.255.255.128.

  2. Configure the router as a DHCP server to dynamically assign IP addresses to users on the 10.10.1.0/24 subnet.
    1. Choose Config > IP Services > DHCP. The DHCP Address Pool page is displayed, as shown in Figure 6. Toggle on Enabled globally to enable the DHCP function globally.

      Figure 6 DHCP

    2. On the DHCP Address Pool page, click Create. On the Create Address Pool page shown in Figure 7, create an address pool to dynamically assign IP addresses to PCs on the 10.10.1.0/25 subnet. Specifically, set Address pool type to Interface address pool, Interface to VLANIF 10, Lease period to 10 days and 12 hours, Reserved IP address to 10.10.1.2 and 10.10.1.4, Primary DNS to 10.10.1.2, and Primary WINS server to 10.10.1.4.

      Figure 7 Creating an address pool

    3. Click OK to submit the configuration.
    4. On the DHCP Address Pool page, click Create to create another address pool to dynamically assign IP addresses to PCs on the 10.10.1.128/25 subnet. Specifically, set Address pool type to Interface address pool, Interface to VLANIF 20, Lease period to five days, and Primary DNS to 10.10.1.2, as shown in Figure 8.

      Figure 8 Creating an address pool

    5. Click OK to submit the configuration.
  3. Verify the configuration.

    # Verify that the DHCP Address Pool list displays the created address pools, as shown in Figure 9.

    Figure 9 DHCP address pool list

    # Run the ipconfig command on a PC to verify that it has obtained an IP address. Figure 10 shows a sample command output.
    Figure 10 Host IP address
