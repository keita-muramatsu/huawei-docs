Example for Configuring Internet Access Through Automatic LTE/5G Dialup

Applicable Product and Version

This example applies to LTE/5G-capable AR routers running V600R024C10 and later versions.

Scenario

This section provides a typical example for configuring Internet access on an egress router. It presents a detailed plan of configuring Internet access through LTE/5G dialup on an egress router, provides a configuration example based on the plan, and offers references for networking planning and device configuration.

Networking Requirements

On the network shown in Figure 1, Router connects to a base station through LTE/5G and dynamically obtains an IP address for its Internet-facing interface from the base station. It has source NAT configured on that interface to connect LAN-side intranet users to the Internet. In this example, a DNS server is deployed at 172.16.0.1/24, and the IP addresses of VLANIF 100 and VLANIF 200 are 192.168.10.1/24 and 192.168.20.1/24, respectively. The VLANIF interfaces have the DHCP server function configured to assign IP addresses to wired terminals in their respective VLANs.

Figure 1 Internet access in LTE/5G mode

Configuration Roadmap

  1. On the Internet access wizard page, set the Internet access mode to the LTE/5G mode and select a cellular interface to be used for Internet access. Enter an APN name, user name, and password (optional), and specify a DNS server address. NAT is enabled by default.

  2. On the LAN configuration wizard page, add LAN-side interfaces to VLANs as planned, create VLANIF 100 and VLANIF 200, and set their IP addresses to 192.168.10.1/24 and 192.168.20.1/24, respectively.
  3. (Optional) If IP addresses need to be assigned to wired terminals, enable the DHCP server function on VLANIF 100 and VLANIF 200 using the LAN configuration wizard. By default, the DHCP server function is enabled on VLANIF 1.

Precautions

  • If you need a specified DNS server, obtain the DNS server's IP address from the ISP.
  • If you need an APN and specified username and password for accessing external PDNs, obtain the information from the ISP.

Procedure

  1. Choose Config > Config Wizard > Online Config Wizard, set the Internet access mode to LTE/5G Dial-up, select a cellular interface and a cellular channel interface to be used for Internet access, and specify a DNS server address. The APN, username, and password are optional. NAT is enabled by default. Figure 2 shows the configuration page.

    Figure 2 Configuring LTE/5G dialup parameters

  2. Choose Config > Config Wizard > LAN Config Wizard, select LAN-side interfaces, and add them to VLANs as planned. Then create VLANIF 100 and VLANIF 200 and set their IP addresses to 192.168.10.1/24 and 192.168.20.1/24, respectively.

    1. Add LAN-side interfaces to VLAN 100, create VLANIF 100, and set the IP address of VLANIF 100 to 192.168.10.1/24.
      1. Add LAN-side interfaces to VLAN 100, as shown in Figure 3.
        Figure 3 Adding LAN-side interfaces to VLAN 100
      2. Click Apply.
      3. Create VLANIF 100 and set its IP address to 192.168.10.1/24, as shown in Figure 4.
        Figure 4 Creating VLANIF 100

      4. Click OK.

    1. Add LAN-side interfaces to VLAN 200, create VLANIF 200, and set the IP address of VLANIF 200 to 192.168.20.1/24.
      1. Add LAN-side interfaces to VLAN 200, as shown in Figure 5.
        Figure 5 Adding LAN-side interfaces to VLAN 200
      2. Click Apply.
      3. Create VLANIF 200 and set its IP address to 192.168.20.1/24, as shown in Figure 6.
        Figure 6 Creating VLANIF 200

      4. Click OK.

  3. (Optional) If IP addresses need to be assigned to wired terminals, enable the DHCP server function on VLANIF 100 and VLANIF 200 using the LAN configuration wizard. By default, the DHCP server function is enabled on VLANIF 1.
  4. Verify the configuration.

    After the configuration is complete, verify that intranet users can access the Internet through Router.
