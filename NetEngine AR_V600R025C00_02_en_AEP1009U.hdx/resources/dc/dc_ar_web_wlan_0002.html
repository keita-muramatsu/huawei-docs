Example for Configuring Basic Services on a WLAN Fat AP

Applicable Product and Version

This example applies to AR routers that run V600R024C10 and later versions and contain W in the model name (for example, AR5710-S8T1XWE).

Scenario

This section provides a typical example for configuring an egress router to function as a Fat AP. It presents a detailed plan of configuring an egress router as a Fat AP to provide wireless Internet access for end users, provides a configuration example based on the plan, and offers references for networking planning and device configuration.

Networking Requirements

As shown in Figure 1, an enterprise provides the WLAN service for users. Router functions as a Fat AP and has source NAT enabled on its Internet-facing interface to connect intranet users to the Internet. Additionally, its VLANIF interface is configured with the DHCP server function to assign IP addresses to wireless users.

Figure 1 Internet access through a WLAN Fat AP

Configuration Roadmap

  1. On the wireless wizard page, set the country/region and AC source address. When the device goes online for the first time, set the username, password, and offline VAP key for the AP.
  2. On the LAN configuration wizard page, create VLANIF 100 and set its IP address to 192.168.10.1/24.
  3. On the wireless service configuration page, set an SSID name, set VLAN 100 as the service VLAN of the SSID, set an IP address with a mask, select the WPA2-WPA3 or WPA-WPA2 security policy, and set a WLAN access password for wireless access.

Precautions

  • The default AC source address of a Fat AP is the address of VLANIF 4094 and the default management VLAN of the built-in AP is VLAN 4094. Therefore, if you need to use VLAN 4094 as the service VLAN for STAs, you need to change the management VLAN to a different one.
  • The DHCP server function must be enabled on the VLANIF interface. Otherwise, STAs cannot obtain IP addresses after connecting to the WLAN. The DHCP server function is enabled by default on VLANIF 1 and VLANIF 4094. If you want to use another VLANIF interface to provide the DHCP server function, ensure that you have enabled the DHCP server function on that VLANIF interface using the LAN configuration wizard.

Procedure

  1. Choose Config > Config Wizard > Wireless Wizard and set the country/region and AC source address. If the device goes online for the first time, set a username, AP password, and offline VAP key for the AP.

    1. Set the country/region, and set the AC source address to the address of VLANIF 4094 (which is the default setting), as shown in Figure 2. If the device goes online for the first time, set an AP username, AP password, and offline VAP key.
      Figure 2 Fat AP parameter settings

    2. Click Apply.

  2. Choose Config > Config Wizard > LAN Config Wizard, create VLANIF 100, and set its IP address to 192.168.10.1/24.

    1. Click Create to create VLANIF 100 and set its IP address to 192.168.10.1/24, as shown in Figure 3.
      Figure 3 Creating VLANIF 100

    2. Click OK.

  3. Configure WLAN services.

    1. Choose Config > Config Wizard > Wireless Wizard and click Create in the Config Wireless Service area. In the Create SSID window as shown in Figure 4, set VLAN 100 as the service VLAN, set an IP address and mask, set the encryption policy to WPA2-WPA3 or WPA-WPA2, and specify a password for WLAN access, such as YsHsjx_202206.
      Figure 4 SSID settings
    2. Click OK.

  4. Verify the configuration. After the configuration is complete, verify that wireless users can access the Internet.

    Choose Config > Config Wizard > Wireless Wizard. In the Config Wireless Service area, check the SSID configuration. Verify that STAs can connect to the SSID wlan and access the Internet after entering the password YsHsjx_202206.
