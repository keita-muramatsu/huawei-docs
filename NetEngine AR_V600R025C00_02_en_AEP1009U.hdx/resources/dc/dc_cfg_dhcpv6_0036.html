Example for Configuring a DHCPv6 Client

Networking Requirements

On the network shown in Figure 1, DeviceA is required to function as a DHCPv6 client so that it can obtain an IPv6 address and other network configuration parameters from the DHCPv6 server. The address of the DHCPv6 server is fc00:3::1/64, and the client and server are on the same link.

Figure 1 Network diagram of configuring a DHCPv6 client

In this example, interface1 represents 10GE0/0/1.


Configuration Roadmap

The configuration roadmap is as follows:

  1. Enable IPv6 on the interface to implement IPv6 communication.

  2. Enable the DHCPv6 client function so that the device can obtain an IPv6 address through DHCPv6.

Precautions

To enable a device to process STA IPv6 services in wireless scenarios, run the sta-ipv6-service enable command in the WLAN view.

Procedure

  1. Add the interface to a VLAN.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] vlan batch 10
[DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] portswitch
[DeviceA-10GE0/0/1] port link-type access
[DeviceA-10GE0/0/1] port default vlan 10
[DeviceA-10GE0/0/1] quit

  2. Configure the IPv6 function on the interface.

    [DeviceA] interface vlanif 10
[DeviceA-Vlanif10] ipv6 enable
[DeviceA-Vlanif10] ipv6 address auto link-local
[DeviceA-Vlanif10] ipv6 address auto global default

  3. Enable the DHCPv6 client function.

    [DeviceA-Vlanif10] ipv6 address auto dhcp
[DeviceA-Vlanif10] quit
[DeviceA] quit

  4. Verify the configuration.

Configuration Scripts

DeviceA

#
sysname DeviceA
#
vlan batch 10
#
interface Vlanif10
 ipv6 enable
 ipv6 address auto link-local
 ipv6 address auto global default
 ipv6 address auto dhcp
#
interface 10GE0/0/1
 portswitch
 port link-type access
 port default vlan 10
#
return
