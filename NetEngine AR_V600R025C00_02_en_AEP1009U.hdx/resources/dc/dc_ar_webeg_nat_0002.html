Example for Configuring NAT Server to Enable an Internal Server to Provide Web Services for External Users

Applicable Product and Version

This example applies to all models of routers running V600R025C00 and later versions.

Networking Requirements

On the network shown in Figure 1, an enterprise's internal server needs to provide web services for external users. The server's private IP address is 192.168.1.2/24 and public IP address is 1.1.1.3/24. To enable external users to access the web server using its public IP address, configure the NAT Server function on the router to implement translation between private and public IP addresses. In this example, the IP addresses of 10GE0/0/1 and 10GE0/0/2 on the router are 192.168.1.1/24 and 1.1.1.2/24, respectively, and 10GE0/0/2 connects to a carrier-side interface at 1.1.1.1/24.

Figure 1 Network diagram for configuring NAT Server

Context

1. On the Internet access wizard page, configure IP addresses for interfaces. Specifically, set the Internet access mode to static IP address mode, specify an interface for Internet access, and set the IP address and subnet mask of this interface.

2. On the server mapping page, configure the NAT Server function to enable translation between private and public addresses. Specifically, enter public and private IP addresses, select the TCP protocol, and enter public and private port numbers.

3. On the static route page, configure a default route to ensure that the Internet-facing interface has a reachable route to the remote end.

Procedure

  1. Configure IP addresses for interfaces.
    1. Choose Config > Config Wizard > Online Config Wizard and set Internet access mode to Static IP, as shown in Figure 2.

      Figure 2 Internet access through a static IP address

    2. Set other parameters for 10GE0/0/1 and click Confirm.

    Repeat this step to configure the IP address 1.1.1.2 and subnet mask 255.255.255.0 for 10GE0/0/2.

  2. Configure NAT Server on the router to enable translation between private and public IP addresses so that external users can access the WWW server using the server's public IP address.
    1. Choose Config > IP Services > NAT Policy > Server Mapping. The Server Mapping List page is displayed, as shown in Figure 3.

      Figure 3 Server mapping list

    2. In Server Mapping List, click Create to create a server mapping entry. In the displayed dialog box as shown in Figure 4, enter a name, set Public IP Address to Specify Public IP Address, enter the public IP address 1.1.1.3 and private IP address 192.168.1.2, set Protocol to TCP, and set both Public Port and Private Port to 80.

      Figure 4 Add Server Mapping

    3. Click OK. The NAT Server configuration is complete.
  3. Configure a default route to ensure that the Internet-facing interface has a reachable route to the remote end.
    1. Choose Config > IP Services > Routing Protocol and click the Static Route tab, as shown in Figure 5.

      Figure 5 Static Route page

    2. On the Static Route tab page, click Create and configure a default route. Specifically, set the destination IP address to 0.0.0.0, subnet mask to 0.0.0.0, and next hop to 1.1.1.1, as shown in Figure 6.

      Figure 6 Creating a static route

    3. Click OK.
  4. Verify the configuration.

    # After the configuration is complete, verify that the configured server mapping entry is displayed in the server mapping list, as shown in Figure 7. If there is such an entry, external users can access the WWW server using the server's public IP address.

    Figure 7 Server mapping list
