Example for Configuring a DHCPv6 PD Server and DHCPv6 PD Client

Networking Requirements

As shown in Figure 1, DeviceA and DeviceB are located on the same link. DeviceB functions as the gateway of PC1 to PCn and connects to PC1 to PCn through interface2 to interfacen. DeviceA and DeviceB are required to function as the DHCPv6 PD server and DHCPv6 PD client, respectively. PC1 to PCn need to automatically generate IPv6 addresses through route advertisement based on the IPv6 address prefixes obtained by the DHCPv6 PD client. This implements hierarchical deployment of host IPv6 addresses.

Figure 1 Network diagram of configuring the DHCPv6 PD server and client

In this example, Interface1 and Interface2 represent 10GE0/0/1 and 10GE0/0/2, respectively.


Configuration Roadmap

The configuration roadmap is as follows:

  1. Configure the DHCPv6 PD server function on DeviceA to dynamically assign IPv6 address prefixes to the DHCPv6 PD client. Specifically, configure an IPv6 address for the interface, configure an IPv6 address pool, and enable the DHCPv6 PD server function on the interface.

  2. Configure the DHCPv6 PD client function on DeviceB to dynamically obtain IPv6 address prefixes from the DHCPv6 PD server. Specifically, configure the IPv6 function and enable the DHCPv6 PD client function on the interface.

  3. Bind the obtained IPv6 address prefixes on DeviceB so that PC1 to PCn can automatically generate IPv6 addresses through route advertisement.

  4. Configure PC1 to PCn to automatically obtain IPv6 addresses.

Precautions

  • To enable a device to process STA IPv6 services in wireless scenarios, run the sta-ipv6-service enable command in the WLAN view.
  • Hosts connected to the DHCPv6 PD client can also be planned on multiple network segments.

    In this example, the length of the prefixes obtained by the DHCPv6 PD client is 63 bits, and the hosts can be deployed on two network segments: ::0:0:0:0:1/64 and ::1:0:0:0:1/64. In addition, the downstream interfaces of the DHCPv6 PD client connected to the hosts are deployed in two VLANs, and on the two VLANIF interfaces corresponding to these VLANs, the ipv6 address myprefix ::0:0:0:0:1/64 command is run on one and the ipv6 address myprefix ::1:0:0:0:1/64 command is run on the other.

    The mappings between the planned prefixes and network segments are as follows:

    • If 63-bit prefixes are obtained, two network segments can be planned (the number of network segments is 2 to the power of [64 – 63]).
    • If 62-bit prefixes are obtained, four network segments can be planned (the number of network segments is 2 to the power of [64 – 62]).
    • If 61-bit prefixes are obtained, eight network segments can be planned (the number of network segments is 2 to the power of [64 – 61]).

      The same rule applies to other scenarios.

Procedure

  1. Configure the DHCPv6 PD server function on DeviceA.

    # Configure an IPv6 address for the interface.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] vlan 100
[DeviceA-vlan100] quit
[DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] port link-type trunk
[DeviceA-10GE0/0/1] port trunk allow-pass vlan 100
[DeviceA-10GE0/0/1] quit
[DeviceA] interface vlanif 100
[DeviceA-Vlanif100] ipv6 enable
[DeviceA-Vlanif100] ipv6 address fc00:3::1/64
[DeviceA-Vlanif100] quit

    # Configure an IPv6 PD address pool.

    [DeviceA] dhcpv6 pool pool1
[DeviceA-dhcpv6-pool-pool1] prefix-delegation fc00:2::/60 63
[DeviceA-dhcpv6-pool-pool1] quit

    # Enable the DHCPv6 PD server function on the interface.

    [DeviceA] dhcp enable
[DeviceA] interface vlanif 100
[DeviceA-Vlanif100] dhcpv6 server pool1
[DeviceA-Vlanif100] ipv6 nd ra halt disable
[DeviceA-Vlanif100] ipv6 nd autoconfig managed-address-flag
[DeviceA-Vlanif100] ipv6 nd autoconfig other-flag
[DeviceA-Vlanif100] quit

    # Configure an IPv6 static route to the network segment (FC00:2::) where the hosts reside, with the next-hop IPv6 address being the peer interface's IPv6 global unicast address (FC00:3::865B:12FF:FE36:595B).

    [DeviceA] ipv6 route-static FC00:2:: 64 vlanif100 FC00:3::865B:12FF:FE36:595B

  2. Configure the DHCPv6 PD client function on DeviceB.

    # Configure the IPv6 function on the interface.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceB
[DeviceB] vlan 100
[DeviceB-vlan100] quit
[DeviceB] interface 10ge 0/0/1
[DeviceB-10GE0/0/1] port link-type trunk
[DeviceB-10GE0/0/1] port trunk allow-pass vlan 100
[DeviceB-10GE0/0/1] quit
[DeviceB] interface vlanif 100
[DeviceB-Vlanif100] ipv6 enable
[DeviceB-Vlanif100] ipv6 address auto link-local
[DeviceB-Vlanif100] ipv6 address auto global

    # Enable the DHCPv6 PD client function on the interface.

    [DeviceB-Vlanif100] dhcpv6 client pd myprefix
[DeviceB-Vlanif100] quit

  3. Bind the obtained IPv6 address prefixes on DeviceB. The interface IPv6 address and the prefix obtained by the DHCPv6 PD client are combined into a 128-bit IPv6 address, and the 64-bit IPv6 prefix is advertised. The following uses 10GE0/0/2 as an example.

    [DeviceB] vlan 200
[DeviceB-vlan200] quit
[DeviceB] interface 10ge 0/0/2
[DeviceB-10GE0/0/2] port link-type access
[DeviceB-10GE0/0/2] port default vlan 200
[DeviceB-10GE0/0/2] quit
[DeviceB] interface vlanif 200
[DeviceB-Vlanif200] ipv6 enable
[DeviceB-Vlanif200] ipv6 address auto link-local
[DeviceB-Vlanif200] ipv6 address myprefix ::0:0:0:0:1/64
[DeviceB-Vlanif200] ipv6 nd ra halt disable
[DeviceB-Vlanif200] quit

  4. Bind the obtained IPv6 address prefixes on DeviceB. The interface IPv6 address and the prefix obtained by the DHCPv6 PD client are combined into a 128-bit IPv6 address, and the 64-bit IPv6 prefix is advertised. The following uses 10GE0/0/3 as an example.

    [DeviceB] vlan 300
[DeviceB-vlan300] quit
[DeviceB] interface 10ge 0/0/3
[DeviceB-10GE0/0/3] port link-type access
[DeviceB-10GE0/0/3] port default vlan 300
[DeviceB-10GE0/0/3] quit
[DeviceB] interface vlanif 300
[DeviceB-Vlanif300] ipv6 enable
[DeviceB-Vlanif300] ipv6 address auto link-local
[DeviceB-Vlanif300] ipv6 address myprefix ::1:0:0:0:1/64
[DeviceB-Vlanif300] ipv6 nd ra halt disable
[DeviceB-Vlanif300] quit

  5. Configure the PCs to automatically obtain IPv6 addresses.

Configuration Scripts

  • DeviceA

    #
sysname DeviceA
#
vlan batch 100
#
dhcp enable
#
dhcpv6 pool pool1
 prefix-delegation FC00:2::/60 63
#
interface Vlanif100
 ipv6 enable
 ipv6 address FC00:3::1/64
 ipv6 nd ra halt disable
 ipv6 nd autoconfig managed-address-flag
 ipv6 nd autoconfig other-flag
 dhcpv6 server pool1
#
interface 10GE0/0/1
 port link-type trunk
 port trunk allow-pass vlan 100
#
ipv6 route-static FC00:2:: 64 Vlanif100 FC00:3::865B:12FF:FE36:595B
#
return

  • DeviceB

    #
sysname DeviceB
#
vlan batch 100 200 300
#
interface Vlanif100
 ipv6 enable
 ipv6 address auto link-local
 ipv6 address auto global
 dhcpv6 client pd myprefix
#
interface Vlanif200
 ipv6 enable
 ipv6 address myprefix ::0:0:0:0:1/64
 ipv6 address auto link-local
 ipv6 nd ra halt disable
#
interface Vlanif300
 ipv6 enable
 ipv6 address myprefix ::1:0:0:0:1/64
 ipv6 address auto link-local
 ipv6 nd ra halt disable
#
interface 10GE0/0/1
 port link-type trunk
 port trunk allow-pass vlan 100
#
interface 10GE0/0/2
 port link-type access
 port default vlan 200
#
interface 10GE0/0/3
 port link-type access
 port default vlan 300
#
return
