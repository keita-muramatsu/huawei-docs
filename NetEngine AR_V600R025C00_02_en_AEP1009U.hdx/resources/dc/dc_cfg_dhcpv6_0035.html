Example for Configuring a DHCPv6 PD Client

Networking Requirements

On the network shown in Figure 1, DeviceA is required to function as a DHCPv6 PD client so that it can obtain an IPv6 address prefix from the DHCPv6 PD server. Configure DeviceA as a DHCP PD client to assign IPv6 addresses and other network configuration parameters to users. This reduces the burden on the DHCPv6 server and implements hierarchical IPv6 deployment. The address of the DHCPv6 PD server is fc00:1::1/64, and the DHCPv6 PD client and DHCPv6 PD server are on the same link. In this example, the DHCPv6 PD client assigns network configuration parameters including the DNS server address fc00:2::1/64 and DNS suffix example.com to users.

Figure 1 Network diagram of configuring a DHCPv6 PD client

In this example, interface1 and interface2 represent 10GE0/0/1 and 10GE0/0/2, respectively.


Configuration Roadmap

  1. Enable the IPv6 function on the interface connecting DeviceA to the DHCPv6 PD server to implement IPv6 communication.
  2. Enable the DHCPv6 PD client function on the interface connecting DeviceA to the DHCPv6 PD server so that the device can obtain an IPv6 address prefix through DHCPv6.

Precautions

To enable a device to process STA IPv6 services in wireless scenarios, run the sta-ipv6-service enable command in the WLAN view.

Procedure

  1. Add interfaces to VLANs.

    # Add 10GE0/0/1 and 10GE0/0/2 to VLAN 10 and VLAN 20, respectively.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] vlan batch 10 20
    [DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] portswitch
[DeviceA-10GE0/0/1] port link-type access
[DeviceA-10GE0/0/1] port default vlan 10
[DeviceA-10GE0/0/1] quit
[DeviceA] interface 10ge 0/0/2
[DeviceA-10GE0/0/2] portswitch
[DeviceA-10GE0/0/2] port link-type access
[DeviceA-10GE0/0/2] port default vlan 20
[DeviceA-10GE0/0/2] quit

  2. Configure the IPv6 function for VLANIF 10 on DeviceA.

    [DeviceA] interface vlanif 10
[DeviceA-Vlanif10] ipv6 enable
[DeviceA-Vlanif10] ipv6 address auto link-local
[DeviceA-Vlanif10] ipv6 address auto global default

  3. Configure the DHCPv6 client function on DeviceA.

    # Enable the DHCPv6 PD client function on VLANIF 10.

    [DeviceA-Vlanif10] dhcpv6 client pd myprefix 
[DeviceA-Vlanif10] quit

    # Set the DNS suffix to example.com.

    [DeviceA] dns domain example.com

  4. Configure DeviceA to send RA messages to assign address prefixes to hosts.

    # Configure the device to send RA messages and set the M and O flags.

    [DeviceA] interface vlanif 20
[DeviceA-Vlanif20] ipv6 enable
[DeviceA-Vlanif20] ipv6 address auto link-local
[DeviceA-Vlanif20] ipv6 nd ra halt disable
[DeviceA-Vlanif20] ipv6 nd autoconfig managed-address-flag
[DeviceA-Vlanif20] ipv6 nd autoconfig other-flag
[DeviceA-Vlanif20] ipv6 address myprefix ::1:0:0:0:1/64  
[DeviceA-Vlanif20] quit
[DeviceA] quit

  5. Verify the configuration.

    # Run the display dhcpv6 client command on DeviceA to check the DHCPv6 PD client configuration.

    <DeviceA> display dhcpv6 client

Configuration Scripts

DeviceA

#
 sysname DeviceA
#
dns domain example.com 
#
vlan batch 10 20
# 
interface Vlanif10
 ipv6 enable
 ipv6 address auto link-local
 ipv6 address auto global default
 dhcpv6 client pd myprefix
#
interface Vlanif20
 ipv6 enable
 ipv6 address myprefix ::1:0:0:0:1/64
 ipv6 address auto link-local
 ipv6 nd ra halt disable
 ipv6 nd autoconfig managed-address-flag
 ipv6 nd autoconfig other-flag
#
interface 10GE0/0/1
 portswitch
 port link-type access
 port default vlan 10
#
interface 10GE0/0/2
 portswitch
 port link-type access
 port default vlan 20
#
return
