Example for Configuring a DHCPv6 Server and DHCPv6 Client (DHCPv6 Stateful Mode)

Networking Requirements

As shown in Figure 1, DeviceA and DeviceB are located on the same link. DeviceA needs to be configured as a DHCPv6 server and DeviceB as a DHCPv6 client so that DeviceB can obtain an IPv6 address and a DNS server address from the DHCPv6 server.

Figure 1 Network diagram of configuring the DHCPv6 server and client

In this example, Interface1 represents 10GE0/0/1.


Configuration Roadmap

The configuration roadmap is as follows:

  1. On DeviceA, configure the DHCPv6 server function so that the DHCPv6 server can dynamically assign the IPv6 address and DNS server address to the DHCPv6 client. Specifically, configure an IPv6 address for the interface, configure an IPv6 address pool, and enable the DHCPv6 server function on the interface.

  2. On DeviceB, configure the DHCPv6 client function so that the DHCPv6 client can dynamically obtain the IPv6 address and DNS server address from the DHCPv6 server. Specifically, configure the IPv6 function and enable the DHCPv6 client function on the interface.

Before the configuration, ensure that the DHCPv6 server and DNS server are routable to each other.

Precautions

To enable a device to process STA IPv6 services in wireless scenarios, run the sta-ipv6-service enable command in the WLAN view.

Procedure

  1. Configure the DHCPv6 server function on DeviceA.

    # Configure an IPv6 address for the interface.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] vlan 100
[DeviceA-vlan100] quit
[DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] port link-type trunk
[DeviceA-10GE0/0/1] port trunk allow-pass vlan 100
[DeviceA-10GE0/0/1] quit
[DeviceA] interface vlanif 100
[DeviceA-Vlanif100] ipv6 enable
[DeviceA-Vlanif100] ipv6 address fc00:3::1/64
[DeviceA-Vlanif100] quit

    # Configure an IPv6 address pool.

    [DeviceA] dhcpv6 pool pool1
[DeviceA-dhcpv6-pool-pool1] address prefix fc00:3::/64
[DeviceA-dhcpv6-pool-pool1] dns-server fc00:4::1
[DeviceA-dhcpv6-pool-pool1] quit

    # Enable the DHCPv6 server function on the interface.

    [DeviceA] dhcp enable
[DeviceA] interface vlanif 100
[DeviceA-Vlanif100] dhcpv6 server pool1

    # Configure the device to advertise RA messages so that the DHCPv6 client can learn the default route to the IPv6 gateway through RA messages, and configure the M and O flags in RA messages so that the DHCPv6 client can obtain an IPv6 address and other network parameters through DHCPv6.

    [DeviceA-Vlanif100] ipv6 nd ra halt disable
[DeviceA-Vlanif100] ipv6 nd ra prefix default no-advertise       //Configure RA messages not to carry the default prefix generated based on the interface IPv6 address.
[DeviceA-Vlanif100] ipv6 nd autoconfig managed-address-flag
[DeviceA-Vlanif100] ipv6 nd autoconfig other-flag
[DeviceA-Vlanif100] quit
[DeviceA] quit

  2. Configure the DHCPv6 client function on DeviceB.

    # Configure the IPv6 function on the interface.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceB
[DeviceB] vlan 100
[DeviceB-vlan100] quit
[DeviceB] interface 10ge 0/0/1
[DeviceB-10GE0/0/1] port link-type trunk
[DeviceB-10GE0/0/1] port trunk allow-pass vlan 100
[DeviceB-10GE0/0/1] quit
[DeviceB] interface vlanif 100
[DeviceB-Vlanif100] ipv6 enable
[DeviceB-Vlanif100] ipv6 address auto link-local

    # Enable the DHCPv6 client function on the interface.

    [DeviceB-Vlanif100] ipv6 address auto dhcp

    # Configure the DHCPv6 client to learn the default route to the IPv6 gateway through RA messages.

    [DeviceB-Vlanif100] ipv6 address auto global default
[DeviceB-Vlanif100] quit
[DeviceB] quit

Configuration Scripts

  • DeviceA

    #
sysname DeviceA
#
vlan batch 100
#
dhcp enable
#
dhcpv6 pool pool1
 address prefix FC00:3::/64
 dns-server FC00:4::1
#
interface Vlanif100
 ipv6 enable
 ipv6 address FC00:3::1/64
 ipv6 nd ra halt disable
 ipv6 nd ra prefix default no-advertise 
 ipv6 nd autoconfig managed-address-flag
 ipv6 nd autoconfig other-flag
 dhcpv6 server pool1
#
interface 10GE0/0/1
 port link-type trunk
 port trunk allow-pass vlan 100
#
return

  • DeviceB

    #
sysname DeviceB
#
vlan batch 100
#
interface Vlanif100
 ipv6 enable
 ipv6 address auto link-local
 ipv6 address auto global default
 ipv6 address auto dhcp
#
interface 10GE0/0/1
 port link-type trunk
 port trunk allow-pass vlan 100
#
return
