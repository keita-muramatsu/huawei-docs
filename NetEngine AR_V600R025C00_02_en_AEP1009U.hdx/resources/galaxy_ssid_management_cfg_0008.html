(Optional) Configuring the Scheduled VAP Auto-Off Function

Prerequisites

A time range has been configured using the time-range command in the system view.

Context

In a WLAN application, a network administrator wants to disable WLAN services in a specified period for security or energy-saving purposes. For this, the scheduled VAP auto-off function can be used.

This configuration is applicable to scenarios where WLAN services need to be disabled in a specified period when high security is required or the user service traffic volume is low.

  • The scheduled VAP auto-off function enabled in a VAP profile takes effect only on the APs using the profile.

  • The scheduled VAP auto-off function enabled in a radio profile takes effect only on the APs using the profile. For details about how to enable the scheduled VAP auto-off function in the radio profile view, see "Configuring a Radio Profile" in CLI Configuration Guide > WLAN Configuration > RRM Configuration.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a VAP profile and enter its view.

    vap-profile name profile-name

  4. Enable the service mode of a VAP

    undo service-mode disable

    By default, the service mode of a VAP is enabled.

  5. Enable the scheduled VAP auto-off function, and set the time range during which the VAP is disabled.

    auto-off service time-range time-range-name

    By default, the scheduled VAP auto-off function is disabled.

Verifying the Configuration

Run the display vap-profile { all | name profile-name } command to check the configuration and reference information about of a VAP profile.

Follow-up Procedure

After the configuration in a VAP profile is complete, bind the VAP profile to a single AP or an AP group. For details, see "Binding a VAP Profile" in WLAN STA Management Configuration > Configuring Basic WLAN STA Access Functions.
