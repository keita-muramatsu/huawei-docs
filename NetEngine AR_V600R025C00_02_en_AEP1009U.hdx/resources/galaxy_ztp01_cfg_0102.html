Configuring a File Server

Prerequisites

There must be reachable routes between the file server and the unconfigured device.

Context

A file server stores the files to be downloaded to the device, including the system software, configuration file, patch file, and intermediate file. On an SZTP network, the file server must have the HTTPS server capability, and the device functions as an HTTPS client.

If the length of a deployment file name exceeds the limit, it will fail to be downloaded. The length limits for different deployment files are as follows:

  • System software: The name is a string of 4 to 124 characters suffixed with .cc.
  • Configuration file: The name is a string of 5 to 64 characters suffixed with .zip or .cfg.
  • Patch file: The name is a string of 5 to 63 characters suffixed with .pat.
  • MASTERKEY file: The name is a string of 5 to 64 characters suffixed with .ini.

Procedure

  1. Configure the file server.

    The file server used for SZTP must have the HTTPS server capability, but Huawei devices do not provide the capability. Therefore, a third-party server needs to be deployed. For details about how to configure a third-party server, see the third-party server operation guide.

  2. Place the deployment files to the working directory of the file server.

    To ensure security of the file server, configure a unique user name for the file server and assign the read-only permission to the user to prevent unauthorized file modifications. After the deployment process is complete, disable the file server function.
