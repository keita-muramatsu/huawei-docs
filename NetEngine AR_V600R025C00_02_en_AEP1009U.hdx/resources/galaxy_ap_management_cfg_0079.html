Configuring Wireless Login to an AP

Prerequisites

Before configuring wired login to an AP, you have completed the following task:

  • Configuring the User Name and Password for AP Login

Context

In addition to AP login through a wired interface, you can wirelessly log in to APs using other methods, such as STelnet.

To log in to an AP wirelessly through a WLAN, you need to enable the AP local management function and use STelnet to log in to the AP using the AP's IP address. By default, the IP address for AP local management is 192.168.254.254/32, which can be changed as required.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP system profile and enter its view.

    ap-system-profile name profile-name

    By default, the AP system profile default exists on the device.

  4. Enable the AP local management function to allow STAs to log in to APs through service VAPs.

    local-management enable

    By default, the AP local management function is disabled.

    For details about how to create and apply a VAP, see Configuring Basic WLAN STA Access Functions.

  5. Configure the IP address used for AP local management.

    local-management ip-address ip-address { mask | mask-length }

    By default, the IP address for AP local management is 192.168.254.254/32 (Loopback 1023).

  6. Configure STelnet login.

    1. Enable the STelnet server function on an AP.
      undo stelnet server disable

      By default, the STelnet server function is enabled on an AP.

    2. Enable first-time authentication on the SSH client.
      ssh client first-time enable

      By default, first-time authentication on the SSH client is disabled.

      When an SSH client accesses an SSH server for the first time and the SSH server's public key is not configured on the SSH client, you can enable first-time authentication on the SSH client to allow the SSH client to access the SSH server.

  7. Optional: Enable Telnet on an AP.

    telnet enable

    By default, Telnet is disabled on an AP.

    The Telnet protocol has security risks. You are advised to use the secure SSHv2 protocol.

  8. Optional: Enable the SFTP server function on an AP.

    undo sftp server disable

    By default, the SFTP server function is enabled on an AP.

  9. Return to the WLAN view.

    quit

  10. Enter the AP view or AP group view.
    • Enter the AP group view.
      ap-group name group-name
    • Enter the AP view.
      ap-id ap-id
  11. Bind the AP system profile to an AP group or a single AP.

    ap-system-profile profile-name

    By default, the AP system profile default is bound to an AP group, but no AP system profile is bound to an AP.

Verifying the Configuration

  • Run the display ap-system-profile { name profile-name | all } command to check information about an AP system profile.
  • Run the display references ap-system-profile name profile-name command to check reference information about an AP system profile.
