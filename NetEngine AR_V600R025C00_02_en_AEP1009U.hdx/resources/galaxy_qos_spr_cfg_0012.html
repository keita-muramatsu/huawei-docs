Setting Link Switchover Thresholds

Context

The delay, jitter, packet loss rate, and CMI thresholds specify the minimum acceptable link quality for services. SPR switches links for services based on these thresholds. If a service has requirements on one or more of the preceding thresholds, specify the corresponding switchover thresholds.

If the detection result is greater than the configured link switchover threshold, the link quality does not meet service requirements.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the SPR configuration view.

    smart-policy-route

  3. Enter the policy profile view.

    spr-policy node node-index

  4. Configure link switchover thresholds based on link quality requirements of different services.

    Table 1 Link switchover thresholds

    Operation

    Command

    Description

    Configure the delay threshold.

    delay threshold threshold-value

    By default, the delay threshold is 5000 ms.

    Configure the jitter threshold.

    jitter threshold threshold-value

    By default, the jitter threshold is 3000 ms.

    Configure the packet loss rate threshold.

    loss threshold threshold-value

    By default, the packet loss rate threshold is 1000‰.

    Configure the CMI threshold.

    cmi threshold threshold-value

    By default, the CMI threshold is 9000.

    The CMI is calculated according to the following formula: CMI = Delay + Jitter + Packet loss rate.
