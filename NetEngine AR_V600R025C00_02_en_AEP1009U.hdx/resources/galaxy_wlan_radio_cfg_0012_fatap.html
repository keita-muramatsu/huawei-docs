Configuring Manual Radio Calibration

Context

To enable APs to better transmit and receive radio signals, you can configure and optimize radios based on the actual network environment to improve WLAN signal quality.

Basic radio parameters can be configured in the AP group radio view or AP radio view. The parameter settings in the AP group radio view take effect on all specified radios in the AP group, whereas the parameter settings in the AP radio view take effect only on the specified radios of the AP and take precedence over those configured in the AP group radio view.

  • Configure the operating frequency band.

    For some AP models, some radios support switching between different frequency bands, but a radio can operate on only one frequency band at a time. You can configure the operating frequency band for AP radios based on the frequency bands supported by STAs.

  • Configure the operating bandwidth and channel for a radio.
    • If neighboring APs work on overlapping channels, signal interference may occur, affecting APs' working status. To prevent signal interference and improve WLAN quality, you can manually configure neighboring APs to work on non-overlapping channels.
    • Operating channels supported by radios vary depending on country codes. To comply with laws and regulations in local countries or regions, you can configure different operating channels for radios under different country codes. (For details about the channels supported in different countries or regions, see WLAN Country Codes and Channels Compliance.) To check the configurable channels for a specified AP under the current country code, you can run the display ap configurable channel command.
    • The configured channels must be supported by STAs; otherwise, the STAs cannot discover radio signals.
  • Configure the antenna gain.
    • The antenna gain is the ratio of the power density produced by an antenna to the power density that should be obtained at the same point if the power accepted by the antenna is radiated equally. The gain of an antenna can be used to measure the antenna's capability of receiving and sending signals in a specific direction, which is also used for selecting base station antennas. Under the same condition, a higher antenna gain indicates a longer signal propagation distance.
    • The antenna gain of an AP radio configured using the command must be consistent with the gain of the antenna connected to the AP.
  • Configure the transmit power.
    • Configure the transmit power and antenna gain for radios based on the actual network environment, so that radios can provide the required signal strength and improve WLAN signal quality.
    • The maximum transmit power of a radio must comply with local laws and regulations. For details, see WLAN Country Codes and Channels Compliance.
  • Configure the radio mode.
    For a triple-radio AP, you can flexibly configure its radio mode based on the application scenario.
    • In large-bandwidth scenarios, the dual-radio mode is recommended. In this mode, an AP can provide high throughput.
    • In high-concurrency scenarios, the triple-radio mode is recommended. In this mode, an AP allows for access of more STAs, improving the WLAN capacity.
    • In high-interference scenarios, the dual-radio + independent scanning radio mode is recommended. In this mode, an AP can use an independent radio to scan the air interface without affecting performance, facilitating WLAN quality monitoring and optimization in real time.

It is recommended that radio calibration be performed during off-peak hours.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Set the mode for triggering radio calibration to manual.

    calibrate enable manual

    By default, the mode for triggering radio calibration is auto, the radio calibration interval is 1440 minutes, and the start time for radio calibration is 03:00:00.

  4. Enter the AP group radio view or AP radio view.

    • Enter the AP group radio view.
      ap-group name group-name
radio radio-id
    • Enter the AP radio view.
      ap-id ap-id
radio radio-id

  5. Enable the radio.

    radio enable

    By default, radios of all APs in the AP group radio view are enabled, and the radio state in the AP radio view is the same as that in the AP group radio view.

    A radio can work only after being enabled. When radios of all APs are disabled in the AP group radio view, to enable radios on a single AP in the AP radio view, run the radio enable command in the corresponding AP radio view.

  6. Configure the operating frequency band for a radio.

    frequency { 2.4g | 5g | 6g }

    By default, radio 0 in the AP group radio view operates on the 2.4 GHz frequency band, radio 1 on the 5 GHz frequency band, and radios 2, 3, and 4 on the 6 GHz frequency band. If radio 2, 3, or 4 does not support the 6 GHz frequency band, it operates on the default frequency band. There is no default value of the operating frequency band for radios in the AP radio view. The configuration in the AP group radio view is used.

    If the configured frequency band is not supported by an AP, the default frequency band takes effect.

  7. Configure the operating bandwidth and channel for a radio.
    1. Disable the DCA function.

      calibrate auto-channel-select disable

      By default, the DCA function is enabled on radios in an AP group. If this function is not configured for radios on a single AP, the configuration in the AP group takes effect.

      Before configuring the operating bandwidth and channel of a radio, disable this function. Otherwise, the manual configurations do not take effect.

    2. Check the channels supported by the AP.

      display ap configurable channel ap-id ap-id [ radio radio-id ]

    3. Configure the operating bandwidth and channel for a radio.

      channel { 20mhz | 40mhz-minus | 40mhz-plus | 80mhz | 160mhz | 320mhz } channel

      By default, the working bandwidth of radios is 20 MHz and their working channels are not configured in an AP group. If the working channel or bandwidth of radios on a single AP is not configured, the configurations in the corresponding AP group take effect.

      If an AP works in dual-5G mode, configure the two 5 GHz radios to work on non-adjacent channels. For example, if 40 MHz plus channels 36, 44, 52, and 60 are supported on the 5 GHz frequency band and one radio is deployed to work on channel 36, it is recommended that channel 52 or 60 be configured for the other radio. Channel 44 is not recommended in this case.

      Only 5 GHz and 6 GHz radio channels support the bandwidth settings of 320 MHz, 80 MHz, 160 MHz, and 80+80 MHz.

      For the 6 GHz frequency band, it is recommended that the preferred scanning channels (PSCs) defined in Wi-Fi 6E be preferentially configured, including channels 5, 21, 37, 53, 69, 85, 101, 117, 133, 149, 165, 181, 197, 213, and 229. Otherwise, the STA access speed may be slow.

  8. Configure the transmit power of the radio.
    1. Disable the TPC function.

      calibrate auto-txpower-select disable

      By default, the TPC function is enabled in the AP group radio view and disabled in the AP radio view.

      Before configuring the transmit power of a radio, disable the TPC function. Otherwise, the manual configurations do not take effect.

    2. Configure the transmit power of the radio.

      eirp eirp

      In the AP group radio view, the default transmit power of a radio is 127 dBm. The transmit power that takes effect on APs is related to the AP type, country code, channel, and channel bandwidth. The transmit power in effect is the maximum transmit power that the AP radio supports under the current configuration. You can run the display radio ap-id ap-id command to view the AP ID.

      In the AP radio view, no transmit power is configured for a radio by default. The transmit power configured for the radio in the corresponding AP group takes effect.

  9. Configure the antenna gain for the radio.

    antenna-gain antenna-gain

    By default, no antenna gain is configured. The antenna gain of a single AP radio depends on the configuration of the AP group to which the AP radio belongs. The antenna gain of AP group radios depends on the default antenna gain of each AP. The default antenna gain of AP radios depends on AP types and working channels of AP radios. To check the default antenna gains of radios on different AP types, run the display ap-type { id type-id | type ap-type } command.

  10. Configure the radio mode.
    1. Enter the AP system profile view.

      quit
quit
ap-system-profile name profile-name

    2. Configure the radio mode.

      radio-mode { 2radio-standard | 2radio-2g-enhanced | 2radio-5g-enhanced | 2radio-independent-scan | 3radio | 4radio | 4radio-independent-scan | 5radio }

      By default, no radio mode is configured on an AP, and the default radio mode of the AP is used.

      Switching the radio mode will cause an AP to restart.

      To check the radio modes supported by APs, run the display ap-type command. If the radio mode delivered by the WAC is not supported by an AP, the default mode supported by the AP is delivered.
