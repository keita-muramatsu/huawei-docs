Understanding IPv4 Static Route FRR

FRR can be performed for two static routes with the same prefix but different priorities. The route with a higher priority is the primary route, and the route with a lower priority is the backup route. If the link of the primary route fails, traffic is rapidly switched to the backup route, reducing the number of lost packets. On the network shown in Figure 1, DeviceA has two static routes to DeviceC. The two routes have different priorities and work in primary/backup mode. Both the two routes are delivered to the forwarding table on DeviceA. When link A (primary link) is working properly, traffic is preferentially transmitted over link A. If link A fails, traffic is quickly switched to link B.

Figure 1 Network diagram of IPv4 static route FRR

Static routes support only manual FRR. FRR cannot be performed for static routes if these routes recurse to multiple pairs of primary and backup next hops.
