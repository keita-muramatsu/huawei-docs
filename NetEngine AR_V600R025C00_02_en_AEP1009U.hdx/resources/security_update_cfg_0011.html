Configuring Manual Online Signature Database Update

Prerequisites

  • The operations in Preparations for Signature Database Update have been completed.
  • If the device connects to the update center through the Internet to update the signature database online, the operations in Configuring the Device to Communicate with the Huawei Intelligent Security Center have been completed.

Context

The device supports manual online signature database update. Before performing an update, consider real-time network conditions and ensure that the update will not occupy the network resources of key services.

Procedure

  1. Enter the system view.

    system-view

  2. Configure manual online signature database update.

    update online { av-sdb | ips-sdb | sa-sdb }

    After the command is executed, the device immediately queries and downloads the signature database, and then updates the local signature database to the latest version.

    For the AR5700 series, only the AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S and AR5710-S10T1X2 do not support the ips-sdb and av-sdb parameters.

  3. Optional: Configure forcible manual online update for the signature database.

    update force online { av-sdb | ips-sdb | sa-sdb }

    For the AR5700 series, only the AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S and AR5710-S10T1X2 do not support the ips-sdb and av-sdb parameters.

    If there is insufficient system memory for the signature database update, the update fails. In this case, you can run this command to forcibly update the signature database. After the command is executed, the ASE does not take effect in a short period of time and all ASE-related session entries are reset. Exercise caution when running this command.
