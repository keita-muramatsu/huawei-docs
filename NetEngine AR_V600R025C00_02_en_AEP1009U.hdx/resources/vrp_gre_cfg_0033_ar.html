Example for Configuring the EoGRE Primary/Backup Solution

Networking Requirements

As shown in Figure 1, an enterprise has two DCNs working in active/standby mode. STAs connect to the active and standby DCNs through two EoGRE tunnels. When the connection to the active DCN is faulty, services need to be switched to the standby DCN securely and reliably. In this case, the EoGRE primary/backup solution can be deployed on DeviceA to implement secure and reliable gateway switching and provide remote disaster recovery.

Figure 1 EoGRE primary/backup solution networking

In this example, interface1, interface2, and interface3 represent 10GE0/0/1, 10GE0/0/2, and 10GE0/0/3, respectively.


Configuration Roadmap

To meet the preceding requirements, deploy the EoGRE primary/backup solution between DeviceA and the two gateways.

The configuration roadmap is as follows:

  1. Deploy IGP between all devices for communication on the public network.

  2. Create tunnel interfaces on DeviceA and deploy GRE tunnels. The source address of a tunnel interface is the IP address of the physical interface that sends packets, and the destination address is the IP address of the physical interface that receives packets.

  3. Create a VE interface on DeviceA and add this interface to the corresponding VLAN.

  4. On DeviceA, bind the VE interface to GRE tunnel interfaces, and configure the priorities of the two tunnel interfaces to specify the primary and backup EoGRE tunnels.

  5. Configure heartbeat detection on DeviceA to prevent the VPN from selecting an unreachable GRE tunnel and subsequent data loss.
  6. Configure preemption as well as the preemption delay for the primary and backup EoGRE tunnels on DeviceA so that the primary tunnel switches back to the forwarding state after recovering from a fault.

Procedure

  1. Configure IP addresses for interfaces.

    Configure an IP address for each interface according to Figure 1. For detailed configurations, see Configuration Scripts.

  2. Configure tunnel interfaces and deploy GRE tunnels.

    # This example assumes that IGP runs between all devices for communication on the public network, the source and destination addresses of EoGRE Tunnel_1 on DeviceA are 10.1.1.1 and 10.3.1.1 (Gateway1), respectively, and the source and destination addresses of EoGRE Tunnel_2 on DeviceA are 10.2.1.1 and 10.4.1.1 (Gateway2), respectively.

    [DeviceA] interface tunnel 1
[DeviceA-Tunnel1] tunnel-protocol gre
[DeviceA-Tunnel1] ip address 10.10.1.1 255.255.255.0
[DeviceA-Tunnel1] source 10.1.1.1
[DeviceA-Tunnel1] destination 10.3.1.1
[DeviceA-Tunnel1] quit
[DeviceA] interface tunnel 2
[DeviceA-Tunnel2] tunnel-protocol gre
[DeviceA-Tunnel2] ip address 10.20.1.1 255.255.255.0
[DeviceA-Tunnel2] source 10.2.1.1
[DeviceA-Tunnel2] destination 10.4.1.1
[DeviceA-Tunnel2] quit

  3. Create a VE interface and add it to the corresponding VLAN. Ensure that the VE interface and the inbound interface of STA packets are added to the same VLAN.

    [DeviceA] interface virtual-ethernet 0/0/1
[DeviceA-Virtual-Ethernet0/0/1] port link-type trunk
[DeviceA-Virtual-Ethernet0/0/1] undo port trunk allow-pass vlan 1
[DeviceA-Virtual-Ethernet0/0/1] port trunk allow-pass vlan 101
[DeviceA-Virtual-Ethernet0/0/1] quit

  4. Bind the VE interface to tunnel interfaces so that Ethernet packets can be forwarded over GRE tunnels. Configure the priorities of the two tunnel interfaces bound to the VE interface to specify the primary and secondary EoGRE tunnels.

    # Configure DeviceA.

    [DeviceA] interface tunnel 1
[DeviceA-Tunnel1] map interface virtual-ethernet 0/0/1 priority 255
[DeviceA-Tunnel1] quit
[DeviceA] interface tunnel 2
[DeviceA-Tunnel2] map interface virtual-ethernet 0/0/1
[DeviceA-Tunnel2] quit

    # Check the mapping between the VE interface and tunnel interfaces on DeviceA.

    [DeviceA] display tunnel mapping interface Virtual-Ethernet 0/0/1
-------------------------------------------------------------------
Virtual-Ethernet port     Tunnel port   Priority    Status  Role
-------------------------------------------------------------------
Virtual-Ethernet0/0/1     Tunnel0/0/1   255         UP      Active
Virtual-Ethernet0/0/1     Tunnel0/0/2   128         UP      Standby
-------------------------------------------------------------------
Total:2

  5. Configure heartbeat detection.

    # Configure DeviceA.

    [DeviceA] interface tunnel 1
[DeviceA-Tunnel1] keepalive
[DeviceA-Tunnel1] quit
[DeviceA] interface tunnel 2
[DeviceA-Tunnel2] keepalive
[DeviceA-Tunnel2] quit

    # Configure heartbeat detection on Gateway1 and Gateway2. The configuration procedure is not mentioned here.

  6. Configure preemption for the primary and backup EoGRE tunnels and set the preemption delay.

    # Configure DeviceA.

    [DeviceA] interface virtual-ethernet 0/0/1
[DeviceA-Virtual-Ethernet0/0/1] gre preempt enable
[DeviceA-Virtual-Ethernet0/0/1] gre preempt delay 70
[DeviceA-Virtual-Ethernet0/0/1] quit

Verifying the Configuration

After the configurations are complete, run the display tunnel mapping configuration command on DeviceA to check configurations in the EoGRE primary/backup scenario, including information about the tunnel interfaces bound to the VE interface, whether preemption is enabled for the primary and backup EoGRE tunnels, and the preemption delay.

[DeviceA] display tunnel mapping configuration
Interface                             : Virtual-Ethernet0/0/1
Preempt                               : enable
Preempt delay(sec)                    : 70
--------------------------------------------------------------------------------
Tunnel port   Priority  Icmp-detect Period(sec) Retry times
--------------------------------------------------------------------------------

Tunnel2       128       disable      15           3

Configuration Scripts

  • DeviceA

    #
sysname DeviceA
#
vlan batch 10 20 101
#
interface Vlanif10
 ip address 10.1.1.1 255.255.255.0
 #
interface Vlanif20
 ip address 10.2.1.1 255.255.255.0
#
interface 10GE0/0/1
 portswitch
 port link-type trunk
 port trunk allow-pass vlan 10
#
interface 10GE0/0/2
 portswitch 
 port link-type trunk
 port trunk allow-pass vlan 20
 #
interface 10GE0/0/3
 portswitch 
 port link-type trunk
 port trunk allow-pass vlan 101
#
interface Virtual-Ethernet0/0/1
 port link-type trunk
 undo port trunk allow-pass vlan 1
 port trunk allow-pass vlan 101
 gre preempt enable
 gre preempt delay 70
#
interface Tunnel1
 ip address 10.10.1.1 255.255.255.0
 tunnel-protocol gre
 source 10.1.1.1
 destination 10.3.1.1
 map interface Virtual-Ethernet0/0/1 priority 255
 keepalive
#
interface Tunnel2
 ip address 10.20.1.1 255.255.255.0
 tunnel-protocol gre
 source 10.2.1.1
 destination 10.4.1.1
 map interface Virtual-Ethernet0/0/1
 keepalive
#
return
