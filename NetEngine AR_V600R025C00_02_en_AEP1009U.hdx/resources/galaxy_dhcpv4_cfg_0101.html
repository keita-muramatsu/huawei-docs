(Optional) Configuring a DHCP Option Template

Context

You can configure network parameters in a DHCP Option template and bind it to static clients so that these clients can be assigned network parameters different from those assigned to dynamic clients.

Network parameters configured in a DHCP Option template take effect only for static clients. For such clients, if a network parameter is configured in both the DHCP Option template view and global address pool view, the configuration in the DHCP Option template view takes effect.

Procedure

  1. Enter the system view.

    system-view

  2. Create a DHCP Option template and enter its view.

    dhcp option template template-name

    By default, no DHCP Option template is created on a device.

  3. Configure network parameters in the DHCP Option template as required.

    Table 1 Configuring network parameters in the DHCP Option template

    Operation

    Command

    Description

    Configure a gateway address for a client.

    gateway-list ip-address &<1-8>

    By default, no gateway address is configured for a client.

    Configure DNS information allocated by the DHCPv4 server.

    dns-list ip-address &<1-8>

    By default, the IPv4 address of the DNS server is not specified, and no DNS domain name suffix is configured.

    Each address pool can be configured with a maximum of eight DNS server addresses.

    Configure user-defined options.

    option code [ sub-option sub-code ] { ascii ascii-string | hex hex-string | cipher cipher-string | ip-address ip-address &<1-8> }

    By default, no user-defined option that a DHCPv4 server allocates to a DHCPv4 client is configured.

  4. Return to the system view.

    quit

  5. Enter the global address pool view.

    ip pool pool-name

  6. Bind a DHCP Option template to a specified static client.

    static-bind ip-address ip-address mac-address mac-address option-template template-name

Verifying the Configuration

Run the display dhcp option template [ name template-name ] command to check the DHCP Option template configuration.
