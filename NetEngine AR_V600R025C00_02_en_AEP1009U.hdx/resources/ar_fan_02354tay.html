Table 3 Indicators on the FAN-240SN-B
Silkscreen Name Color Status Description
- STATUS indicator Green Fast blinking (4 Hz) The fan module has not established communication with the main control board or communication loss occurs.
Green Slow blinking (0.5 Hz) The fan module is working and communicating with the main control board properly.
Red Slow blinking (0.5 Hz) An alarm is generated, and the fan module is faulty.
Yellow Steady on The fan module is abnormal. The possible cause is that the monitoring unit software of the fan module is abnormal or the fan module fails.
