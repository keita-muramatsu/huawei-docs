Configuring EoGRE

Prerequisites

The following describes the EoGRE configuration procedure on the AC side.

GRE tunnels must be established prior to the configuration of basic EoGRE functions. For details, see Configuring a GRE Tunnel.

If DeviceA is added to a VRRP group, the source IP address of the GRE tunnel must be set to the virtual IP address of the VRRP group.

Procedure

  1. Enter the system view.

    system-view

  2. Create a VE interface and enter its view.

    interface virtual-ethernet ve-number

  3. Set the link type of the VE interface to trunk.

    port link-type trunk

  4. Remove the VE interface from VLAN 1.

    undo port trunk allow-pass vlan 1

  5. Add the VE interface to VLANs.

    port trunk allow-pass vlan { { vlan-id1 [ to vlan-id2 ] }&<1-10> | all }

  6. Return to the system view.

    quit

  7. Enter the tunnel interface view.

    interface tunnel interface-number

  8. Set the tunnel encapsulation type to GRE.

    tunnel-protocol gre

  9. Bind the VE interface to the tunnel interface.

    map interface virtual-ethernet ve-number

    By default, no VE interface is bound to a tunnel interface.

  10. Return to the system view.

    quit

  11. (Optional) Disable a VE interface from forwarding broadcast, multicast, and unknown unicast packets to devices in the same VLAN.

    gre map virtual-ethernet forward-broadcast disable

    By default, a VE interface can forward broadcast, multicast, and unknown unicast packets to devices in the same VLAN.

    When a branch CPE sends packets to an HQ CPE, if the branch CPE cannot obtain the MAC address of the HQ CPE, the branch CPE sends broadcast, multicast, and unknown unicast packets to the VE interface bound to the tunnel interface of the HQ CPE. The VE interface then forwards the packets to other CPEs in the same VLAN. This consumes a large amount of network bandwidth, increases the workload of the HQ CPE, and may lead to loss of normal packets. To prevent this problem, you can run this command to disable the VE interface from forwarding broadcast, multicast, and unknown unicast packets to other CPEs in the same VLAN.

Verifying the Configuration

  • Run the display interface virtual-ethernet [ ve-number ] command to check the status and statistics about a VE interface.
  • Run the display tunnel mapping [ interface tunnel interface-number ] command to check the mapping between the tunnel interface and VE interface.
