Overview of MAC Address Authentication

Definition

MAC address authentication controls network access rights of users based on interfaces to which users' terminals are connected and MAC addresses of these terminals.

Benefits

No client software needs to be installed on terminals, and users do not need to enter user names and passwords on terminals during MAC address authentication. Dumb terminals that do not support 802.1X authentication, such as printers and fax machines, can be authenticated.

Authentication System

As shown in Figure 1, the MAC authentication system is a typical client/server structure, which consists of three types of entities: terminal, access device, and authentication server.

Figure 1 MAC address authentication system
  • Terminal: attempts to access the network.
  • Access device: a network access control point that enforces security policies. It allows, rejects, isolates, or restricts network access of terminals based on the customized security policies.
  • Authentication server: checks whether the identities of users who attempt to access the network are valid, and if so assigns network access rights to such users.

User Name Format

During MAC address authentication, there is no need for users to enter user names or passwords on their terminals. Instead, the user name and password used for MAC address authentication must be configured on the access device and authentication server in advance. Table 1 lists the formats of the user name used for MAC address authentication on the access device. In actual applications, ensure that the authentication server supports the configured user name format.
