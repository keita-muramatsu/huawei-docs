Configuring a DHCPv6 Server

Pre-configuration Tasks

Before configuring a DHCPv6 server, you have completed the following tasks:

  • Ensure that the DHCPv6 client and device can communicate with each other.

  • (Optional) In the scenario where a DHCPv6 relay agent exists, configure a route from the device to the DHCPv6 relay agent or DHCPv6 client.

Configuration Logic

The following configuration tasks are performed in sequence.

    Configuring a DHCPv6 DUID
    Configuring an IPv6 Address Pool
    (Optional) Configuring Network Server Addresses for an IPv6 Address Pool
    (Optional) Configuring User-Defined Options for an IPv6 Address Pool
    (Optional) Configuring the Function to Save DHCPv6 Data
    (Optional) Binding an IPv6 Address Pool to a VPN
    Enabling the DHCPv6 Server Function
    (Optional) Configuring the Function of Recording a Log When an IPv6 Address or Prefix Is Allocated
    Verifying the DHCPv6 Server Configuration
