(Optional) Configuring an RU on the Central Device

After an intelligent simplified campus network is deployed, you can run commands on the central device to specify one or all RUs for configuration delivery to ensure stable system running and easy management. Configurations that need to be delivered to the RUs are delivered through XLDP packets.
