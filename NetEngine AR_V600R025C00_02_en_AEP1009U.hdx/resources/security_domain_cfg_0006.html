Configuring a Domain Group

Procedure

  1. Enter the system view.

    system-view

  2. Configure a DNS server.

    dns server ip-address

  3. Set the maximum committed rate for resolving DNS reply packets.

    dns analyze maximum-rate maximum-rate

    The maximum committed rate refers to the maximum number of DNS reply packets that the device can resolve per second. If the rate of DNS reply packets exceeds the maximum committed rate, the device permits the excess packets without recording the mappings between domain names and IP addresses.

    By default, the maximum committed rate for resolving DNS reply packets is 80000 packets per second. In some scenarios that have high requirements on performance, you can change this value accordingly.

  4. Create a domain group and access its view.

    domain-set name domain-set-name

  5. Add a domain name.

    add domain domain-name

    You can run this command repeatedly to add multiple domain names to a domain group.

    The device does not proactively send DNS request packets to query the domain name containing a wildcard character based on the suffix matching rule. It can only record the IP address corresponding to the domain name by resolving DNS reply packets.

  6. (Optional) Configure the domain group description.

    description description

    The proper description helps you to maintain and manage domain groups.

Verifying the Configuration

Run the display domain-set { all | verbose { domain-set-name [ domain domain-name ] | ip-address { ipv4-address | ipv6-address } } } [ slot slot-id cpu cpu-id ] command in any view to check information about the domain group.
