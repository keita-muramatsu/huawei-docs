Querying the Minimum Number of Up Physical Interfaces in a Trunk Interface

Description of MIB Objects

You can use hwTrunkIfMinLinkNum in hwTrunkIfTable to obtain the minimum number of up physical interfaces in all trunk interfaces, and then use hwTrunkIndex to query the minimum number of up physical interfaces in a trunk interface.

Object

OID

hwTrunkIndex

1.3.6.1.4.1.2011.5.25.41.1.3.3.1.1

hwTrunkIfID

1.3.6.1.4.1.2011.5.25.41.1.3.3.1.2

hwTrunkIfMinLinkNum

1.3.6.1.4.1.2011.5.25.41.1.3.3.1.7

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.
  2. Perform the Walk operation on hwTrunkIfID to query the entity index hwTrunkIndex. As shown in Figure 1, the index of Eth-Trunk10 is 10.
    Figure 1 Obtaining the mapping between a trunk interface and its index
  3. Perform the Walk operation on hwTrunkIfMinLinkNum to query the minimum number of up physical interfaces in the corresponding trunk interface based on the value of hwTrunkIndex. As shown in Figure 2, the minimum number of up physical interfaces in Eth-Trunk10 with the index of 10 is 1.
    Figure 2 Querying the minimum number of up physical interfaces in a trunk interface
