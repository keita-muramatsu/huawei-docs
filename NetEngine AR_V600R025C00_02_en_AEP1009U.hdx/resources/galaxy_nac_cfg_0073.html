Configuring Multi-mode Authentication

Pre-configuration Tasks

The access profile and authentication profile have been configured:
  • For details about MAC address authentication, see: Configuring MAC Address Authentication.
  • For details about 802.1X authentication, see Configuring 802.1X Authentication.
  • For details about Portal authentication, see Configuring Portal Authentication (Portal Server Using the Portal Protocol) or Configuring Portal Authentication (Portal Server Using HTTP or HTTPS).

Procedure

  1. Enter the system view.

    system-view

  2. Enter the authentication profile view.

    authentication-profile name authentication-string

  3. Configure the user authentication mode.

    • Configure MAC address authentication and 802.1X authentication.
      1. Bind a MAC access profile to the authentication profile.
        mac-access-profile access-profile-name
      2. Bind an 802.1X access profile to the authentication profile.
        dot1x-access-profile access-profile-name
    • Configure MAC address bypass authentication.
      1. Bind a MAC access profile to the authentication profile.
        mac-access-profile access-profile-name
      2. Bind an 802.1X access profile to the authentication profile.
        dot1x-access-profile access-profile-name
      3. Enable MAC address bypass authentication.
        authentication dot1x-mac-bypass

        By default, MAC address bypass authentication is disabled.

    • Configure MAC address-prioritized Portal authentication.
      1. Bind a MAC access profile to the authentication profile.
        mac-access-profile access-profile-name
      2. Bind a Portal access profile to the authentication profile.
        portal-access-profile access-profile-name

  4. Return to the system view.

    quit

  5. Enter the interface view.

    interface interface-type interface-number

  6. Switch the interface working mode to Layer 2.

    portswitch

    Determine whether to perform this step based on the current interface working mode.

  7. For wireless users, enter the VAP profile view.

    wlan
vap-profile name profile-name

  8. Apply a specified authentication profile to the VAP profile.

    authentication-profile profile-name

    By default, no authentication profile is applied to a VAP profile.
