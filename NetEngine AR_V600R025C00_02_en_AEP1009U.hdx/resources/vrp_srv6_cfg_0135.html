Configuring HSB for SRv6 TE Policy

Prerequisites

Before configuring hot standby (HSB) for SRv6 TE Policy, you have completed the following task:

  • Configure an SRv6 TE Policy.

Context

Unaffiliated BFD (U-BFD) for SRv6 TE Policy can quickly detect segment list faults. If all the segment lists of the primary path are faulty, U-BFD triggers a candidate path HSB switchover to reduce the impact on services.

Procedure

  1. Enter the system view.

    system-view

  2. Enable SRv6 globally and enter the SRv6 view.

    segment-routing ipv6

  3. Enable HSB for SRv6 TE Policy.

    HSB for SRv6 TE Policy supports both global configuration and single-policy configuration. Select either of the following configuration modes as needed:

    • Global configuration

      1. Enable HSB for al SRv6 TE Policies.

        srv6-te-policy backup hot-standby enable

    • Single-policy configuration

      1. Enter the SRv6 TE Policy view.

        srv6-te policy name-value

      2. Enable or disable HSB for the SRv6 TE Policy.

        backup hot-standby { enable | disable }

    If an SRv6 TE Policy has both the global configuration and the single-policy configuration, only the single-policy configuration takes effect.

Verifying the Configuration

Run the display srv6-te policy [ endpoint endpoint-ip color color-value | policy-name name-value | binding-sid binding-sid ] command to check detailed SRv6 TE Policy information.
