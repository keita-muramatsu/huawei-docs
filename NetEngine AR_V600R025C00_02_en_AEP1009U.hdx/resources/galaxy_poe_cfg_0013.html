Configuring the Power Supply Priority for a PoE Interface

Context

When the power available to PoE interfaces is insufficient, the device powers the interfaces on or off based on their priorities and numbers.
  • The power supply priorities of interfaces are critical, high, and low in descending order. An interface with a higher power supply priority is powered on first.
  • If interfaces have the same power supply priority, the interface with a smaller number is powered on first.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the interface view.

    interface interface-type interface-number

  3. Configure the power supply priority for the PoE interface.

    poe priority { critical | high | low }

    By default, the power supply priority of a PoE interface is low.

Verifying the Configuration

Run the display poe power-state [ slot slot-id | interface { interface-type interface-number | interface-name } ] command to check the power supply priority of the PoE interface based on the Port power priority or Priority field.
