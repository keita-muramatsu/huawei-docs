Example for Using a Basic ACL to Prevent Source Address Spoofing Attacks Through URPF

Networking Requirements

As shown in Figure 1, Router's 10GE0/0/1 is connected to PC1 and PC2, and 10GE0/0/2 is connected to an upstream router. To prevent source address spoofing attacks, configure URPF strict check on 10GE0/0/1 and 10GE0/0/2. In this example, Router is required to perform URPF check only on the packets from PC2 (with the IP address 10.0.0.3).

Figure 1 Network diagram of using a basic ACL to prevent source address spoofing attacks through URPF

Configuration Roadmap

The configuration roadmap on Router is as follows:

  1. Configure ACL-based URPF on 10GE0/0/1 to perform URPF check only on the packets from PC2.
  2. Configure the URPF check mode on 10GE0/0/2 to prevent source address spoofing attacks.

Procedure

  1. Configure ACL-based URPF on 10GE0/0/1 to perform URPF check only on the packets from PC2.

    <HUAWEI> system-view
[HUAWEI] sysname Router
[Router] interface 10GE 0/0/1
[Router-10GE0/0/1] ip address 10.0.0.1 24
[Router-10GE0/0/1] urpf strict acl 2001
[Router-10GE0/0/1] quit
[Router] acl number 2001
[Router-acl-basic-2001] rule permit source 10.0.0.3 0.0.0.255
[Router-acl-basic-2001] quit

  2. Configure the URPF check mode on 10GE0/0/2.

    [Router] interface 10GE 0/0/2
[Router-10GE0/0/2] ip address 10.0.1.1 24
[Router-10GE0/0/2] urpf strict
[Router-10GE0/0/2] quit

  3. Verify the configuration.

    # Check the ACL rule configuration.
    [Router] display acl 2001 
Basic ACL 2001, 1 rule                                                           
 ACL's step is 5                                                                  
 rule 5 permit source 10.0.0.0 0.0.0.255
    # Check the URPF configuration on 10GE0/0/1.
    [Router] interface 10GE 0/0/1
[Router-10GE0/0/1] display this 
#                                                                                
interface 10GE0/0/1                                                           
 ip address 10.0.0.1 255.255.255.0                                               
 urpf strict acl 2001                                                            
#                                                                                
return
    # Check the URPF configuration on 10GE0/0/2.
    [Router] interface 10GE0/0/2
[Router-10GE0/0/2] display this 
#                                                                                
interface-10GE0/0/2                                                           
 ip address 10.0.0.1 255.255.255.0                                               
 urpf strict                                                 
#                                                                                
return

Configuration Scripts

Router

# 
 sysname Router 
#                                                                                
acl number 2001                                                                   
 rule 5 permit source 10.0.0.0 0.0.0.255  
#                                                                                
interface 10GE0/0/1                                                             
 ip address 10.0.0.1 255.255.255.0                                                
 urpf strict acl 2001                                                            
#                                                                                
interface 10GE0/0/2                                                          
 ip address 10.0.1.1 255.255.255.0                                                
 urpf strict 
# 
return
