Configuring an Address Object

Procedure

  1. Enter the system view.

    system-view

  2. Create an address object and access its view.

    ip address-set address-set-name type object

    address-set-name cannot be set to any or all. You need to specify the type parameter when creating an address object. After an address object is created and its view is displayed, you do not need to specify this parameter.

  3. Add an IP address.

    • Add an IPv4 address.
      address [ id ] { ipv4-address { wildcard { 0 | wildcard } | mask { mask-address | mask-len } } | range start-ipv4-address end-ipv4-address } [ description  description ]
    • Add an IPv6 address.
      address [ id ] { ipv6-address ipv6-prefix-length | range start-ipv6-address end-ipv6-address } [ description description ]

    You can run this command repeatedly to add multiple IP addresses to an address object.

  4. (Optional) Configure address description.

    description description

    The proper description helps you maintain and manage addresses.

Verifying the Configuration

  • Run the display ip address-set type object command in any view to check information about all address objects.
  • Run the display ip address-set verbose address-set-name { item | reference } command in any view to check detailed information about a specified address object.
  • Run the display ip address-set address { ipv4-address | ipv6-address } command in any view to check information about the address object or address group that contains a specified IP address.
