Disabling the Device from Processing STA IPv6 Services

Context

Currently, IPv4 WLANs are widely deployed. If many IPv6 packets exist on an IPv4 WLAN, the performance of the WLAN is affected, and the CPU processing capability of devices will also be degraded. To improve performance of a pure IPv4 network, you can disable devices on the network from processing STA IPv6 services.

After the function of processing STA IPv6 services is disabled, the following situations occur:

  • WACs and APs do not process IPv6 packets on the wireless side.

  • IPv6 functions on the wireless side, such as IPv6 address learning, are disabled even if they are enabled in the default settings.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Disable the function of processing STA IPv6 services.

    undo sta-ipv6-service enable

    By default, the function of processing STA IPv6 services is disabled.
