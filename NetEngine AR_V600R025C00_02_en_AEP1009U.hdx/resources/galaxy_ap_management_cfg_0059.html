Configuring the Working Mode and VLANs for an AP's Wired Interface

Context

You can configure the mode and VLANs for an AP's wired interface to implement wired network communication. You need to add an AP's wired interface to a VLAN or a group of VLANs in tagged mode. However, wired terminals cannot receive packets with VLAN tags. Therefore, you need to add the AP's wired interfaces directly connected to wired terminals to a VLAN or a group of VLANs in untagged mode. When sending data frames, the interface removes VLAN tags from the frames and sends the frames to wired terminals.

Frames sent from wired terminals are untagged. Therefore, the wired interface directly connected to the wired terminal must be configured with a PVID to add a tag to the received untagged frames. This ensures that wired packets can be sent to the upper-layer network and prevents packets from being discarded due to no tag or incorrect PVID.

An AP's wired interface can work in root, middle, or endpoint mode. You can configure different working modes for an AP's wired interface depending on specific scenarios.
  • Root mode: The AP's wired interface functions as an uplink interface to connect to an uplink device.
  • Middle mode: The central AP's wired interface connects to a downlink RU.
  • Endpoint mode: The AP's wired interface functions as a downlink interface to connect to wired terminals.

  • After configuring the working mode for an AP's wired interface, restart the AP to make the configuration take effect.

  • If the AP's uplink interface is incorrectly configured to work in endpoint mode and the AP can go online properly, run the mode command to modify the configuration. If the AP cannot go online, you are advised to press and hold the Default button to restore the factory defaults of the AP.
AP's wired interfaces are added to different VLANs and PVIDs by default when working in different modes.

There are two scenarios in which APs are directly connected to wired users: in the centralized architecture, APs' wired interfaces are directly connected to wired users; in the agile distributed architecture, RUs' wired interfaces are directly connected to wired users.

Procedure

  • In the WAC + Fit AP architecture, an AP's wired interfaces are directly connected to wired users.

    As shown in Figure 1, the AP's wired interface interface1 connects to a wired terminal. Perform the following configurations to implement wired network connectivity.

    Figure 1 Network diagram for directly connecting wired users to APs' wired interfaces in the WAC + Fit AP architecture
    • Configure the AP's wired interface interface2 on the WAC.
      1. Enter the system view.
        system-view
      2. Enter the WLAN view.
        wlan
      3. Create an AP wired port profile and enter its view.
        wired-port-profile name wired-port-profile-name

        By default, the AP wired port profile default exists on the device.

      4. Configure the description of an AP's wired interface.
        description description

        By default, no description is configured for an AP's wired interface.

      5. Optional: Configure the working mode for the AP's wired interface.
        mode root
      6. Specify the VLANs to which the AP's wired interface is to be added.
        vlan tagged { { vlan-id1 [ to vlan-id2 ] } &<1-10> }

        By default, an AP's wired interface allows packets from all VLANs to pass. The wired interface is added to VLAN 1 in untagged mode and to other VLANs in tagged mode.

      7. Return to the WLAN view.
        quit
      8. Bind the AP wired port profile to an AP group or a specific AP. For details, see Binding an AP Wired Port Profile.
    • Configure the AP's wired interface interface1 on the WAC.
      1. Enter the system view.
        system-view
      2. Enter the WLAN view.
        wlan
      3. Create an AP wired port profile and enter its view.
        wired-port-profile name wired-port-profile-name

        By default, the AP wired port profile default exists on the device.

      4. Configure the description of an AP's wired interface.
        description description

        By default, no description is configured for an AP's wired interface.

      5. Configure the working mode for the AP's wired interface.
        mode endpoint
      6. Specify the VLANs to which the AP's wired interface is to be added.
        vlan untagged { { vlan-id1 [ to vlan-id2 ] } &<1-10> }

        By default, an AP's wired interface allows packets from all VLANs to pass. The wired interface is added to VLAN 1 in untagged mode and to other VLANs in tagged mode.

      7. Configure the PVID for an AP's wired interface.
        vlan pvid vlan-id

        By default, the PVID of an AP's wired interface is 1.

      8. Return to the WLAN view.
        quit
      9. Bind the AP wired port profile to an AP group or a specific AP. For details, see Binding an AP Wired Port Profile.
