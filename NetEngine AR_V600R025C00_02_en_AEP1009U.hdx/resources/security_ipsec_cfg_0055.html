Configuring IPsec Tunnel Index Retention

Prerequisites

  • IPsec tunnel index retention takes effect only for the following IPsec types:
    • ACL-based IPsec (involving ISAKMP IPsec policies, template IPsec policies, and manual IPsec policies)
    • Route-based IPsec (involving IPsec profiles)
  • Both ends of an IPsec tunnel use fixed IP addresses and establish only one IPsec tunnel.

Context

In an MIB table, an IPsec tunnel index is the unique identifier of an IPsec tunnel. During IPsec tunnel establishment, the device generates an IPsec tunnel index mapping table to record the mapping between IPsec tunnel indexes and IPsec tunnels. In this mapping table, the device searches for an IPsec tunnel based on its IPsec tunnel index. However, during the reestablishment of an IPsec tunnel, its IPsec tunnel index changes by default. As a result, the remote device cannot find the IPsec tunnel based on its original IPsec tunnel index. You can configure the IPsec tunnel index retention function to ensure that the remote device can find the IPsec tunnel based on the fixed IPsec tunnel index.

Procedure

  1. Enter the system view.

    system-view

  2. Configure IPsec tunnel index retention.

    ipsec tunnel-index based remote-ip

    By default, IPsec tunnel index retention is disabled.

    After this function is enabled, the device can only ensure that the indexes of the first 1024 IPsec tunnels remain unchanged based on the sequence in which IPsec tunnels are reestablished.
