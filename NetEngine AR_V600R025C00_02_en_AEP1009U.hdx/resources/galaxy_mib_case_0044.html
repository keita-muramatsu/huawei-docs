Querying Data on LLDP Neighbors

Description of MIB Objects

You can use the following objects in lldpRemTable to obtain data on LLDP neighbors.

Object

OID

lldpRemChassisIdSubtype

1.0.8802.1.1.2.1.4.1.1.4

lldpRemChassisId

1.0.8802.1.1.2.1.4.1.1.5

lldpRemSysName

1.0.8802.1.1.2.1.4.1.1.9

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.

  2. Perform the Walk operation on lldpRemChassisIdSubtype to query the sub-types of ports on LLDP neighbors. As shown in Figure 1, the sub-type of ports on the LLDP neighbor is macAddress.

    Figure 1 Querying the sub-types of ports on LLDP neighbors

  3. Perform the Walk operation on lldpRemChassisId to query the IDs of ports on LLDP neighbors. As shown in Figure 2, the ID of the port on the LLDP neighbor is 2C.AB.00.79.20.F6.

    Figure 2 Querying the IDs of ports on LLDP neighbors
