Adjusting the RX/TX Sensitivity Threshold

Context

You can adjust the anti-interference capability of the device based on the RX/TX sensitivity threshold to reduce radio interference in some areas.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Enter the radio profile view.

    • Enter the 2.4 GHz radio profile view.
      radio-2g-profile name profile-name
    • Enter the 5 GHz radio profile view.
      radio-5g-profile name profile-name

  4. Adjust the anti-interference capability of APs for sending and receiving packets.

    • Configure the receiver sensitivity threshold of APs.
      rx-sensitivity threshold

      By default, the receiver sensitivity threshold of APs is –128 dBm.

    • Configure the AGC threshold for APs.
      agc-threshold high high-threshold

      By default, the AGC threshold is not configured.

  5. Return to the WLAN view.

    quit

  6. Bind the specified radio profile to an AP group or a specified AP.

    For details, see Binding a Radio Profile.

Follow-up Procedure

  • Run the display radio-2g-profile name profile-name command to check the interference detection configuration in a 2.4 GHz radio profile.
  • Run the display radio-5g-profile name profile-name command to check the interference detection configuration in a 5 GHz radio profile.
