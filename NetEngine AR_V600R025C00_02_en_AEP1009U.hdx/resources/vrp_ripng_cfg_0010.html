Multi-Process and Multi-Instance

For easy management and effective control, RIPng supports multi-process and multi-instance. The multi-process feature allows a set of interfaces to be associated with a specific RIPng process, ensuring that this process performs all protocol operations only on this set of interfaces. As such, multiple RIPng processes can work on a single device and each process is responsible for a unique set of interfaces. In addition, the routing data is independent between RIPng processes; however, routes can be imported between processes.

On VPN-capable devices, each RIPng process is associated with a specific VPN instance. As a result, all the interfaces attached to a RIPng process should be associated with the same VPN instance as the RIPng process.
