Viewing Virus Threat Logs

Context

After the antivirus profile is referenced in a security policy, the device performs virus detection on traffic that matches the security policy. If viruses are detected, the device generates a virus threat log. You can check virus threat logs to obtain basic information about viruses and further deploy defense actions.

Procedure

  1. Enter the system view.

    system-view

  2. Enable the log sending function of the antivirus module.

    engine log av enable

    By default, the log sending function of the antivirus module is enabled.

  3. Optional: Enable the antivirus log aggregation function.

    av log merge enable

    By default, the antivirus log aggregation function is enabled.

    After the antivirus log aggregation function is enabled, the system aggregates multiple identical antivirus logs generated within a short period of time into one log and then outputs the aggregated log.

Example

You can obtain basic information such as the traffic IP address and protocol, virus name, virus file type, and virus file name from logs.

The following is a virus threat log detected by the signature database-based antivirus function:
AV/4/VIRUS(l):CID=0x814f0421;A virus was detected. (SyslogId=1, VSys="public", Policy="policy1", SrcIp=192.168.1.2, DstIp=192.168.0.2, SrcPort=21, DstPort=53038, SrcZone=untrust, DstZone=trust, User="unknown", Protocol=TCP, Application="FTP", Profile="default", EventNum=1, SignatureId=16424404, VirusName="EICAR.Test.FILE.1", DetectionType="full-scan virus detect", Direction=download, FileName="eicar.com", FileType="eicar", Action=Block, Hash="267D772D8ED87333", Severity="high", UserGroup="unknown")

Follow-up Procedure

Run the display av-signature database command to view the viruses that can be detected.
