Adjusting the Cellular Dial-up Interval

Context

A device enabled with auto dial-up automatically tries to set up a dial-up connection with the core network without being triggered by data packets. If the dial-up fails, the device tries again at specified intervals (called the cellular dial-up interval).

The dial-up interval affects the data transmission rate and network connection stability. If it is too short, the device will frequently dial up. This puts further stress on the network and slows down data transmission. The core network may also consider this an attack. Conversely, if the interval is too long, the device cannot quickly set up a connection. This negatively affects the network connection stability.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the cellular profile view.

    cellular-profile profile-name

  3. Configure the auto dial-up interval.

    dialer timer { seconds seconds | minutes minutes } [ exponential [ times times ] ]

    By default, the auto dial-up interval is 10s.

    To stop frequent dial-ups being considered by the core network as attacks, you can specify exponential times times. This parameter increases the dial-up interval exponentially. The interval for the nth dial-up attempt is calculated as follows: T(n) = T(n – 1) + 2n + Random (180 x n). T(n – 1) indicates the interval for the (n – 1)th dial-up attempt, and Random (180 x n) indicates a random number in the range from 0 to 180 x n.
