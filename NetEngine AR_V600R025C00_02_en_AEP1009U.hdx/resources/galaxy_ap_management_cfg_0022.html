Configuring the User Name and Password for AP Login

Context

After the user name and password for AP login are configured, you can log in to APs through various methods, such as STelnet.

To keep the device secure, change the password periodically. To further improve password security, you can configure an AP login password policy.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Configure the user name and password for AP login.

    ap username name password cipher password-value

    By default, no user name or password is configured for AP login.

    If the weak password dictionary maintenance function is enabled, the passwords defined in the weak password dictionary cannot be used. To view these passwords, run the display security weak-password-dictionary command.

  4. Optional: Configure an AP login password policy.

    1. Enable the AP login password policy function and display the AP password policy view.
      ap password policy

      By default, the AP login password policy function is disabled.

    2. Set the password validity period.
      password expire day

      By default, the password validity period is 90 days.

    3. Set the number of days in advance users are notified that their passwords are about to expire.
      password alert before-expire days

      By default, the number of days in advance users are notified that their passwords are about to expire is 30 days.

    4. Enable the device to prompt users to change initial passwords.
      password alert original

      By default, the device is enabled to prompt users to change initial passwords upon login to the AP.

    5. Set the maximum number of historical passwords recorded for each user logged in to the AP.
      password history record number number

      By default, a maximum of five historical passwords are recorded for each user logged in to the AP.

Verifying the Configuration

Run the display ap username command to check information about users logging in to the AP.
