Configuring WPA/WPA2-PSK Authentication

Context

Both WPA and WPA2 support PSK authentication and the TKIP and AES encryption algorithms. They offer almost the same security level, mainly differing in the protocol packet format.

WPA/WPA2-PSK authentication applies to small networks (such as individual and home networks) that do not require high network security or deployment of an authentication server. If a STA supports only WEP encryption, the STA can implement PSK+TKIP without hardware upgrading, whereas the STA may need to upgrade its hardware to implement PSK+AES.

STAs typically support different authentication and encryption modes. To enable various types of STAs to access the network and facilitate management by network administrators, you can configure both WPA and WPA2. If the security policy is set to WPA-WPA2 authentication, STAs supporting WPA or WPA2 can be authenticated. If the encryption mode is set to TKIP-AES, any STAs supporting TKIP or AES can encrypt service packets.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a security profile and enter its view.

    security-profile name profile-name

    By default, the security profile default exists in the system.

  4. Configure a security policy.

    • Configure WPA-PSK or WPA2-PSK authentication in a security policy.
      security { wpa | wpa2 } psk { pass-phrase | hex } key-value { aes | tkip | aes-tkip }

      By default, no security policy is configured.

    • Configure WPA-WPA2-PSK authentication in a security policy.
      security wpa-wpa2 psk { pass-phrase | hex } key-value { tkip [ aes ] | aes | aes-tkip }

      By default, no security policy is configured.

  5. (Optional) Enable the periodic PTK update function.

    wpa ptk-update enable

    By default, the periodic PTK update function is disabled.

    When periodic PTK update is implemented, some STAs may encounter service interruptions or go offline due to individual problems.

  6. (Optional) Configure the periodic PTK update interval.

    wpa ptk-update ptk-update-interval ptk-update-interval-value

    By default, the interval for updating PTKs is 43200 seconds.

  7. (Optional) Disable key negotiation for multicast traffic.

    wpa group-key-negotiation disable

    By default, key negotiation for multicast traffic is enabled.

  8. (Optional) Enable the function of disconnecting STAs when the device does not receive the last packet from the STAs during unicast key negotiation.

    wpa unicast-key-negotiation time-out kick-sta enable

    By default, the device does not disconnect STAs when it does not receive the last packet from the STAs during unicast key negotiation.
