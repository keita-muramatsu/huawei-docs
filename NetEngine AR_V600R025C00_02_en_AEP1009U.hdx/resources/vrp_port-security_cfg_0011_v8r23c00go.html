Configuring Static MAC Address Flapping Detection

Context

Assume that a static secure MAC address is configured on interface B of the device, enabling a user to access the device. When the user disconnects from interface B and then connects to interface A of the device, interface A receives packets whose source MAC address matches the static MAC address entry of interface B. The device considers this as static MAC address flapping and discards the packets. As a result, the user cannot access the device.

To configure the device to report an alarm when static MAC address flapping occurs, enable the static MAC address flapping detection function on the device and port security on interface A. In this way, interface A will perform port security protection actions like reporting an alarm when static MAC address flapping occurs.

Procedure

  1. Enter the system view.

    system-view

  2. Enable static MAC address flapping detection.

    port-security static-flapping protect

  3. Enter the interface view.

    interface { interface-name | interface-type interface-number }

  4. Change the interface working mode from Layer 3 to Layer 2.

    portswitch

  5. Enable the port security function and set the maximum number of MAC addresses that the interface can learn.

    port-security enable [ maximum max-number ]

  6. (Optional) Configure a protection action for port security on an interface.

    port-security protect-action { protect | restrict | error-down }

  7. Exit the interface view.

    quit

Verifying the Configuration

Check the port security-related alarms by running the display trapbuffer command or through the NMS.
