(Optional) Configuring Dynamic BFD for DHCPv6

Context

Dynamic BFD for DHCPv6 helps you quickly detect link faults between DHCPv6 clients and servers. When enabled on a DHCPv6 client, it allows the client to quickly detect a faulty link connected to a DHCPv6 server. Upon detection, the client releases the current IP address and periodically attempts to apply for a new one from the server until the link recovers and it obtains a new IP address.

In VRRP hot standby scenarios, this function takes effect when the links connected to master and backup devices in the VRRP group all fail.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the view of an existing interface, or create a logical interface and enter its view.

    interface { interface-name | interface-type interface-number }

    By default, no interface of this type is created.

  3. Switch the interface working mode to Layer 3.

    undo portswitch

    Determine whether to perform this step based on the current interface working mode.

  4. Enable IPv6 on the interface.

    ipv6 enable

    By default, IPv6 is disabled on an interface.

  5. Configure the interface to automatically generate a link-local address.

    ipv6 address auto link-local

    By default, an interface does not automatically generate a link-local address.

  6. Enable the interface to automatically obtain an IPv6 address and other network configuration parameters through DHCPv6.

    ipv6 address auto dhcp [ hint ipv6-address ] [ rapid-commit ] [ unicast-option ]

    By default, an interface is disabled from automatically obtaining an IPv6 address and other network configuration parameters through DHCPv6.

  7. Enable dynamic BFD for DHCPv6.

    dhcpv6 bfd enable

    By default, dynamic BFD for DHCPv6 is disabled.

  8. Configure parameters for dynamic BFD for DHCPv6 sessions.

    dhcpv6 bfd { min-rx-interval receive-interval | detect-multiplier multiplier-value }

    By default, the interval at which BFD packets are received is 1000 milliseconds, and the local detection multiplier is 3.
