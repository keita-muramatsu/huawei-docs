Configuring a Device as an SFTP Client

Prerequisites

After a device is configured as an SFTP client and connects to an SFTP server, client authentication and bidirectional data encryption ensure secure file transfer between the server and client and file and directory management on the server.

Before configuring a device to access files on the SFTP server through SFTP, you have completed the following tasks:

  • Ensure that there are reachable routes between the device and SFTP server.
  • Obtain the IP address of the SFTP server and SSH user information, and ensure that the SSH user has been assigned the highest privilege level.
  • Obtain the port number configured for the server if the standard port number is not used.

Context

SFTP, based on the SSH protocol, uses the encryption and authentication functions of SSH to implement secure communication and user authentication, improving data transmission security. During the configuration, you need to configure SSH to implement the SFTP client function.

Procedure

  • (Optional) Configure the source interface or source IP address for the SFTP client.

    The source IP address to be configured must be that of a stable interface, such as a loopback interface. This configuration makes it easier to configure ACL rules. You simply need to specify the source or destination IP address in an ACL rule as the interface IP address, thereby allowing the device to filter incoming and outgoing packets.

    Table 2 Configuring the source interface or source IP address for the SFTP client

    Operation

    Command

    Description

    Enter the system view.

    system-view

    -

    Configure the source interface or source IP address for the SFTP client.

    sftp client-source { -a source-ip-address [ public-net | -vpn-instance vpn-instance-name ] | -i { interface-type interface-number | interface-name } }

    or

    sftp ipv6 client-source -a source-ipv6-address [ -vpn-instance ipv6-vpn-instance-name ]
    • By default, the source IP address is 0.0.0.0.
    • If an interface is specified, set an IP address for the interface. Otherwise, the SFTP connection fails to be set up.
    • To use -i to specify a logical interface as the source interface, ensure that the logical interface has been created.
    • If the specified source address does not exist, the configuration can be successful, but the function does not take effect.

  • Configure the mode for connecting a device to the SSH server for the first time.

    For details, see "Configuring the Mode for Connecting a Device to the SSH Server for the First Time" in CLI Configuration Guide > Security Configuration.

  • Configure SFTP client parameters.

    For details, see "Setting SSH Client Parameters" in CLI Configuration Guide > Security Configuration.

Verifying the Configuration

  • Run the display sftp client command to check the configuration of the SFTP client.
  • Run the display ssh server-info command to check the mapping between all SSH servers and public keys on the client.
