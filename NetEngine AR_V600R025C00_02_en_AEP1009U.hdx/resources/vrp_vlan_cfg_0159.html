Configuring a Voice VLAN (Identifying Voice Packets based on MAC Addresses)

Context

When MAC address-based voice VLAN is configured, a device determines whether a data packet received by an interface is a voice data packet based on the source MAC address field in the packet. If the source MAC address in a data packet matches the OUI configured for a voice device, the device considers the data packet as a voice data packet and increases its priority.

Procedure

  1. Enter the system view.

    system-view

  2. Configure the OUI for a voice VLAN.

    voice-vlan mac-address mac-address mask oui-mask [ description text ]

    By default, no OUI is configured for a voice VLAN.

  3. Enter the interface view.

    interface interface-type interface-number

  4. Change the interface working mode from Layer 3 to Layer 2.

    portswitch

    Determine whether to perform this step based on the current interface working mode.

  5. Configure a VLAN as a voice VLAN and enable the voice VLAN function on the interface.

    voice-vlan vlan-id enable [ include-untagged ]

    By default, the voice VLAN function is disabled on an interface.

  6. Configure the interface to increase the priority of voice packets based on MAC addresses.

    voice-vlan remark-mode mac-address

    By default, the priority of voice packets is increased based on VLAN IDs.

  7. Add interfaces to VLANs. For details, see Configuring Interface-based VLAN Assignment (Statically Configuring the Interface Type).
  8. (Optional) Set the working mode of the voice VLAN to secure.

    voice-vlan security enable

    By default, a voice VLAN works in common mode.
