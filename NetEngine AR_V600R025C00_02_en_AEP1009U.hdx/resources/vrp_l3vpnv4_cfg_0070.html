Configuring ASBRs Not to Filter VPNv4 Routes Based on VPN Targets

Context

By default, an ASBR filters the VPN targets of only the received VPNv4 routes. Eligible routes are imported into the routing table, and other routes are discarded. Therefore, if no VPN instance is configured on the ASBR or no VPN target is configured for the VPN instance, the ASBR discards all the received VPNv4 routes.

In inter-AS VPN Option B, an ASBR does not need to store VPN instance information, but must store information about all VPNv4 routes and advertise these routes to the peer ASBR. In this case, ASBRs need to import all the received VPNv4 routes without filtering them based on VPN targets.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the BGP view.

    bgp as-number

  3. Enter the BGP-VPNv4 address family view.

    ipv4-family vpnv4 [ unicast ]

  4. Enable the function to exchange VPNv4 routes between the PE and ASBR in the same AS.

    undo policy vpn-target
