Overview of Multi-mode Authentication

On a network with diversified clients, different clients support different access authentication modes. Some clients (such as printers) support only MAC address authentication, while some hosts that have 802.1X client software installed support 802.1X authentication. To meet various authentication requirements on the network, multiple authentication modes need to be deployed on access interfaces so that users can select a proper authentication mode to access the network.
