SNMP-based Network Management

SNMP-based network management consists of four components:

  • NMS

    An NMS is an independent device that runs network management programs. A network management program provides at least one man-machine interface through which the network administrator manages the network.

  • SNMP agent

    An agent is a software module on a managed device. It receives and handles the request packets from the NMS, and returns response packets to the NMS. In some urgent cases, the agent sends a trap packet to the NMS.

  • SNMP

    As an application layer protocol in the TCP/IP suite, SNMP exchanges management messages between the NMS and the managed device.

  • Management Information Base (MIB)

    The MIB is a set of managed objects that serve as a bridge between the NMS and an agent, enabling standard interconnection between the NMS and devices. Each agent maintains such a MIB for the NMS to read and configure the MIB objects.

Figure 1 SNMP-based network management.

Figure 1 shows the relationships between the main components involved in network management. The communication modes between the components are as follows:

  • Using SNMP, the NMS communicates with the agent of the device to read and modify MIB objects, thereby implementing device monitoring and management.

  • SNMP is responsible for the communication between the NMS and the agent. Data is exchanged using protocol data units (PDUs). The SNMP packets are transmitted through a transport layer protocol such as UDP.

  • The agent is a process running on a device. It communicates with the NMS and maintains the MIB to manage and monitor device modules.

  • The MIB stores the information about device modules. The NMS maintains and monitors a device by reading or modifying the MIB objects.
