Comparison Between Link Aggregation Modes

Table 1 describes the differences between Eth-Trunk in manual mode and Eth-Trunk in LACP mode.
Table 1 Comparison between link aggregation modes

Item

Manual Mode

LACP Mode

Eth-Trunk setup mode

An Eth-Trunk interface is manually created and member interfaces are manually added to the Eth-Trunk interface. LACP is not involved.

An Eth-Trunk interface is manually created and member interfaces are manually added to the Eth-Trunk interface. LACP participates in dynamic link adjustment and maintains the link status. That is, LACP automatically adjusts or disables link aggregation when the link aggregation condition changes.

LACP

Not required

Required

Data forwarding

When an Eth-Trunk is operating normally, all links are active and participate in data forwarding. If one active link fails, traffic is load balanced among the remaining active links.

When an Eth-Trunk is operating normally, some links are active. All active links participate in data forwarding. If an active link fails, the system selects one of the backup links as a new active link, ensuring the unchanged number of links participating in data forwarding.

Fault detection

Only member link disconnections in an Eth-Trunk can be detected in this mode. Other faults, such as incorrect link connections, cannot be detected.

Besides member link disconnections, other faults, such as incorrect link connections, can be detected.
