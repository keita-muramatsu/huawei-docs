Binding an AP Wired Port Profile

Context

After the configuration is complete, bind the AP wired port profile to an AP group or a specific AP so that the configuration in the profile can take effect.

You can perform the following operations as required:
  • Bind the AP wired port profile to all AP groups in the WLAN view.
  • Bind the AP wired port profile to a single AP group in the AP group view.
  • Bind the AP wired port profile to a single AP in the AP view.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Bind the AP wired port profile to all AP groups.

    ap-group all wired-port-profile profile-name interface-type interface-number

    By default, the AP wired port profile default is bound to an AP group.

  4. Enter the AP view or AP group view.
    • Enter the AP group view.
      ap-group name group-name
    • Enter the AP view.
      ap-id ap-id
  5. Bind the AP wired port profile to an AP group or a single AP.

    wired-port-profile profile-name interface-type interface-number

    By default, the AP wired port profile default is bound to an AP group, but no AP wired port profile is bound to an AP.
