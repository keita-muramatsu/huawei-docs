Configuring Antivirus

Prerequisites

You have obtained the latest virus signatures after completing the operations in Updating the Antivirus Signature Database.

Context

The device has a default antivirus profile default. You can also create a customizable antivirus profile and reference the profile in a security policy.

Procedure

  1. Enter the system view.

    system-view

  2. Configure the service performance mode of the device.

    forward performance mode { routing | security | security-enhance }

    To enable security services, you are advised to switch the device's service performance mode to the secure forwarding mode (security) or enhanced security mode (security-enhance).

    You can run the display forward performance mode command to check the current service performance mode of the device.

    Some models do not support this command or some parameters. For details, see the command reference.

  3. Set the maximum number of files that can be detected concurrently by the ASE on each CPU and the maximum size of a single file detected by the ASE.

    av full-scan-mode { max-file-number max-number-value | max-file-size max-size-value }

  4. Optional: Enable the decoding function for a specified protocol.

    decoder decoder-name enable

    Antivirus detection depends on the protocol decoding function. By default, the HTTP/2 decoder is disabled, and decoders of other protocols are enabled.

  5. Configure the customizable antivirus profile.

    1. Create the customizable antivirus profile.
      profile type av name name
    2. Configure the file types to be detected by antivirus.
      file-type av { items file-type-name &<1-18> | all }

      By default, signature database-based antivirus can detect OFFICE, PE, ELF, SCRIPT, EICAR, EML, FLASH, PDF, RTF, MACOS, JAR, APK, and ARCHIVE files.

    3. Configure the protocol detection function.

      Protocol

      Command

      Default Setting

      HTTP

      http-detect enable

      http-detect { direction { upload | download | both } | action { block | alert } }

      http-detect direction { upload | download | both } action { block | alert }

      By default, HTTP detection is enabled in both the upload and download directions, and the action is block.

      FTP

      ftp-detect enable

      ftp-detect { direction { upload | download | both } | action { block | alert } }

      ftp-detect direction { upload | download | both } action { block | alert }

      By default, FTP detection is enabled in both the upload and download directions, and the action is block.

      SMTP

      smtp-detect enable

      By default, SMTP detection is enabled in the upload direction, and the action is alert.

      POP3

      pop3-detect enable

      By default, POP3 detection is enabled in the download direction, and the action is alert.

      IMAP

      imap-detect enable

      imap-detect direction { upload | download | both }

      By default, IMAP detection is enabled in both the upload and download directions, and the action is alert.

      NFS

      nfs-detect enable

      nfs-detect direction { upload | download | both }

      By default, NFS detection is enabled in both the upload and download directions, and the action is alert.

      SMB

      smb-detect enable

      smb-detect { direction { upload | download | both } | action { block | alert } }

      smb-detect direction { upload | download | both } action { block | alert }

      By default, SMB detection is enabled in both the upload and download directions, and the action is block.

      For details about the detection directions and actions supported by the protocol detection, see Table 2.

    4. Optional: Configure the FTP detection mode.
      ftp-detect scan-mode { proxy | flow }

      By default, the antivirus detection engine works in flow mode (the FTP detection mode).

      When the antivirus detection engine works in proxy mode, the effect of blocking malicious files is better, but the performance overhead is higher and the device performance is greatly affected. When the antivirus detection engine works in flow mode, the effect of blocking malicious files is reduced, but the performance overhead is lower.

      Evaluate the impact before switching the detection mode. The switching takes effect only for new sessions.

      The detection mode configuration takes effect only for the current antivirus profile.

    5. Optional: Configure malware exceptions.
      exception av-signature-name av-signature-name
exception av-signature-name av-signature-name action { allow | block-source-ip [ timeout time ] }

      The files with an exception virus are permitted if no action (action) is specified for the exception virus.

      You can also set the action to block-source-ip. The device then adds the source IP address of the traffic matching the exception virus to the dynamic blacklist and takes different actions based on the protocol type.

      • Take the block action for HTTP, FTP, and SMB traffic.
      • Take the delete attachment action for SMTP, POP3, and IMAP traffic.
      • Permit and generate the log AV/4/VIRUS for NFS traffic.

      The dynamic blacklist generated by the virus exception function can take effect only after the blacklist function is enabled using the firewall blacklist enable command.

    6. Return to the system view.
      quit

  6. Commit the configuration.

    engine configuration commit

    The related configuration will not take effect immediately after being modified. Commit the configuration for activation.

  7. Enter the security policy view.

    security-policy

  8. Create a security policy rule and enter the security policy rule view.

    rule name rule-name

  9. Reference the antivirus profile in the security policy.

    profile av profile-name

    When you use the preceding command to reference the profile in the security policy, enter a complete profile name; otherwise, the profile fails to be referenced.

    This section provides only the configuration steps for referencing the default antivirus profile in the security policy. For details about other matching conditions, see "Security Policy Configuration" in CLI Configuration Guide > Security Configuration.

  10. Configure the action of the security policy rule.

    action permit
quit
