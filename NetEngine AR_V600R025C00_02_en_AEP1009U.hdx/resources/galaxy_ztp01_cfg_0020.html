Example for Configuring Email-based Deployment

Networking Requirements

In Figure 1, an enterprise manages and maintains the network through iMaster NCE-Campus, which communicates with the enterprise network over the Internet. The enterprise headquarters connects to the Internet through two gateways. An enterprise branch needs to be added and connected to the Internet through the gateway DeviceA to communicate with the enterprise headquarters. After the network administrator plans and configures the enterprise branch network on the controller, the installation and maintenance engineer can install and deploy DeviceA onsite. As such, there is no need to arrange another engineer to deploy the device onsite.

The following provides controller information and DeviceA information:

  • The IP address and port number of the controller are 1.1.1.1 and 10020, respectively, and the deployment mailbox address is admin@test.com.
  • DeviceA connects to the Internet through interface1 and has a public IP address statically configured.
Figure 1 Network diagram of email-based deployment

In this example, interface1 represents 10GE0/0/1.


Prerequisites

The device to be deployed must be unconfigured. Otherwise, the deployment will fail. Run the following commands to clear the configuration file for next startup, and then restart the device to restore the factory configurations. If you cannot log in to a device, press and hold the RST button for at least 5 seconds to restore the factory settings.

  1. Clear and cancel the configuration file specified for the next startup to restore the default configurations.
    reset saved-configuration
  2. Restart the device and clear the service configurations and data files to restore the factory configurations.
    reset factory-configuration

Configuration Roadmap

The configuration roadmap is as follows:

  1. The network administrator configures a deployment email on the controller and sends the email to the deployment mailbox.
  2. The installation and maintenance engineer (who is also the deployment person) confirms that the deployment email has been received, installs the device onsite, and then connects a laptop to the device using an Ethernet cable for email-based deployment.

Procedure

  1. Configure and send a deployment email.

    Log in to iMaster NCE-Campus and configure email-based deployment as a network administrator. For details, see "Email-based Deployment" in the SD-WAN Solution & iMaster NCE-Campus Product Documentation.

  2. Connect a laptop to the device using an Ethernet cable.

    Use a laptop to log in to the mailbox, confirm that the deployment email has been received, and bring the laptop to the site as a deployment person. After the device starts successfully, connect the laptop to the device using an Ethernet cable.

    1. Connect the laptop to the device's management interface using an Ethernet cable.

      The management interface of a device is usually marked with the Management or MGMT silkscreen. The management interfaces of some device models do not have this silkscreen.

    2. Configure the IP address of the laptop.

      Configure the laptop to automatically obtain an IP address, as shown in Figure 2.

      If the laptop automatically obtains an IP address but cannot ping the IP address of the connected management interface, configure a static IP address on the same network segment as this management interface IP address. If the laptop can ping the management interface IP address successfully, this laptop has been successfully connected to the device.
      Figure 2 Configuring the IP address of the laptop

  3. Use the laptop to perform email-based deployment.

    1. Open the deployment email, use a browser to access the URL in the email, and ignore the security certificate warning. The deployment page is displayed.

    2. In the displayed browser window, enter the password as prompted. The password must be the same as the email-based deployment URL encryption key set in the global parameter configuration on iMaster NCE-Campus.

    3. On the deployment portal page, click View Configuration Parameters to verify that the configuration parameters are correct.

    4. Click Confirm Deployment to start the deployment process.

    5. The welcome page is displayed on the laptop, indicating that the deployment succeeds.

  4. Verify the configuration.

    1. Log in to iMaster NCE-Campus, open the site monitoring page, and verify that the registration status of the new enterprise branch gateway is Normal and the network administrator can manage the gateway through the controller.
    2. View the CTRL indicator to check the device's deployment status
      • Steady green: The device has been connected to the controller.
      • Blinking green: The device is being deployed. (Some device models do not support this indicator status.)
      • Steady off: The device is not connected to the controller.
