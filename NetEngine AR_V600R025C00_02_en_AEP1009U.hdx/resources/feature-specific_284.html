Example for Configuring Local N:1 Port Mirroring

Networking Requirements

On the network shown in Figure 1, the marketing department, R&D department, and administration department of an enterprise access the Internet through DeviceA, and the Server acting as a monitoring device is directly connected to DeviceA. Internet access traffic of the three departments needs to be monitored through the Server.

Figure 1 Networking diagram of local port mirroring

In this example, interfaces 1, 2, 3, 4, and 5 represent 10GE 0/0/1, 10GE 0/0/2, 10GE 0/0/3, 10GE 0/0/4, and 10GE 0/0/5 respectively.


Procedure

  1. Configure 10GE0/0/4 on DeviceA as a local observing port.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] observe-port 1 interface 10ge 0/0/4

  2. On DeviceA, configure 10GE0/0/1, 10GE0/0/2, and 10GE0/0/3 as mirrored ports to copy the received packets to the local observing port.

    [DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] port-mirroring observe-port 1 inbound
[DeviceA-10GE0/0/1] quit
[DeviceA] interface 10ge 0/0/2
[DeviceA-10GE0/0/2] port-mirroring observe-port 1 inbound
[DeviceA-10GE0/0/2] quit
[DeviceA] interface 10ge 0/0/3
[DeviceA-10GE0/0/3] port-mirroring observe-port 1 inbound
[DeviceA-10GE0/0/3] quit

Verifying the Configuration

# Check the mirroring configuration

[DeviceA] display port-mirroring
  Observe port mirroring:
  -----------------------------------------------------------------------------
  MirroringPort         Direction        ObservePort : Interface
  -----------------------------------------------------------------------------
  10GE0/0/1             Inbound                    1 : 10GE0/0/4
  10GE0/0/2             Inbound                    1 : 10GE0/0/4
  10GE0/0/3             Inbound                    1 : 10GE0/0/4
  -----------------------------------------------------------------------------

Configuration Scripts

DeviceA

#
sysname DeviceA
#
observe-port 1 interface 10GE0/0/4
#
interface 10GE0/0/1
 port-mirroring observe-port 1 inbound
#
interface 10GE0/0/2
 port-mirroring observe-port 1 inbound
#
interface 10GE0/0/3
 port-mirroring observe-port 1 inbound
#
return
