Example for Quickly Restoring Configurations After a Device Is Powered Off

Networking Requirements

  • If service configurations are not saved before the device is powered off, the configurations will be lost. You can roll back configurations to the latest rollback point to quickly restore the configurations.
  • After IP addresses are configured for the interfaces shown in Figure 1, the device is powered off and the configured IP addresses are lost.
Figure 1 Configuration rollback

In this example, Interface1, Interface2, Interface3, and Interface4 represent 10GE0/0/1, 10GE0/0/2, 10GE0/0/3, and 10GE0/0/4 respectively.


Configuration Roadmap

The configuration roadmap is as follows:
  1. The IP address configurations for interfaces are not saved to the configuration file.
  2. The configurations are lost after the device is restarted upon a power failure.
  3. Check information about configuration rollback points and find the latest configuration rollback point.
  4. Roll back the configurations.

Procedure

  1. Configure IP addresses for 10GE0/0/1, 10GE0/0/2, 10GE0/0/3, and 10GE0/0/4 on the device. The IP addresses for these interfaces are as follows: 10.0.0.1/30, 10.0.1.1/30, 10.0.2.1/30, and 10.0.3.1/30.

    <HUAWEI> system-view
[HUAWEI] sysname Device
[Device] interface 10ge 0/0/1
[Device-10GE0/0/1] ip address 10.0.0.1 30
[Device-10GE0/0/1] quit
[Device] interface 10ge 0/0/2
[Device-10GE0/0/2] ip address 10.0.1.1 30
[Device-10GE0/0/2] quit
[Device] interface 10ge 0/0/3
[Device-10GE0/0/3] ip address 10.0.2.1 30
[Device-10GE0/0/3] quit
[Device] interface 10ge 0/0/4
[Device-10GE0/0/4] ip address 10.0.3.1 30
[Device-10GE0/0/4] quit
[Device] commit label label_ipaddress
[Device] quit

  2. The configurations are lost after the device is restarted upon a power failure.
  3. Check information about configuration rollback points and find the latest configuration rollback point.

    <Device> display configuration commit list verbose
1)  CommitId: 1000000006 
        Label: label_ipaddress
        User: root 
        User-Intf: VTY 1 
        Type: CLI 
        TimeStamp: 2025-09-16 02:00:01 
        Description: -  
2)  CommitId: 1000000005
        Label: 20250915 
        User: root 
        User-Intf: VTY 1 
        Type: CLI 
        TimeStamp: 2025-09-15 02:00:01  
        Description: -

  4. Perform configuration rollback.

    # Roll system configurations back to what they are before the most recent configuration rollback point is generated.

    In this example, the rollback configuration last 1 command is equivalent to the rollback configuration to commit-id 1000000006/rollback configuration to label label_ipaddress command, both indicating that system configurations are rolled back to what they are before configuration rollback point 6 is generated.

    <Device> rollback configuration last 1
Warning: This operation will revert configuration changes to the previous status. During the rollback configuration process, some configurations involving differences may be temporarily invalid. Continue? [Y/N]:Y
Checking changes...
Loading rollback changes
Committing
Check rollback result
Configuration rollback succeeded.
Please use 'display configuration commit changes last 1' to view the changes.

Verifying the Configuration

# Check the configuration file to verify that the configuration rollback operation is successful.

<Device> display current-configuration interface
#
interface 10GE0/0/1
 shutdown
#
interface 10GE0/0/2
 shutdown
#
interface 10GE0/0/3
 shutdown
#
interface 10GE0/0/4
 shutdown
#
