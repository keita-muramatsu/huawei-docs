Configuring iCSSR

Context

This function is applicable to education (excluding high-density stadiums and auditoriums) and open office (excluding desktop cloud) scenarios. You are advised to enable this function in these scenarios.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an RRM profile and enter its view.

    rrm-profile name profile-name

  4. Enable iCSSR

    co-sr enable

    By default, iCSSR is disabled.

  5. Return to the WLAN view.

    quit

  6. Bind the RRM profile to a radio profile.

    1. Bind the RRM profile to a 2.4 GHz radio profile.
      radio-2g-profile name profile-name
rrm-profile profile-name
    2. Bind the RRM profile to a 5 GHz radio profile.
      radio-5g-profile name profile-name
rrm-profile profile-name

  7. Bind the radio profile.

    For details, see Binding a Radio Profile.

Verifying the Configuration

Run the display rrm-profile name profile-name command to check the iCSSR configuration in the RRM profile.
