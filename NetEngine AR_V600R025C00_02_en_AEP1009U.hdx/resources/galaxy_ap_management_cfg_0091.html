Enabling the Emergency State of Cloud AP Licenses

Context

If an AP cannot be managed by the WAC because the cloud AP license is not renewed, you can enable the emergency state of the cloud AP license. After this state is enabled, the AP can continue to access the WAC for seven days.

The emergency state of a cloud AP license can be enabled only after the license expires and for only once.

Procedure

  1. Enable the emergency state of cloud AP licenses.

    cloud-ap-license emergency
