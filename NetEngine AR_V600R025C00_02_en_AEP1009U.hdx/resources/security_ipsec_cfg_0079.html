Understanding IPsec in NAT Scenarios

When both IPsec and network address translation (NAT) are configured, the device can function as a NAT gateway between two devices that establish an IPsec tunnel or as both a NAT gateway and an IPsec gateway that establishes an IPsec tunnel with the remote end.

IPsec NAT Traversal

In Figure 1, DeviceB functions as a NAT gateway between two devices (DeviceA and DeviceC) that establish an IPsec tunnel. This scenario is also called IPsec NAT traversal. The branch, as the negotiation initiator, is located on a private network. It sends negotiation packets across the Internet through DeviceB to negotiate and establish an IPsec tunnel with the responder (headquarters). To ensure that negotiation packets can pass through the NAT gateway, you need to enable NAT traversal on the devices (DeviceA and DeviceC) at both ends of the IPsec tunnel.

Figure 1 IPsec NAT traversal

IPsec Gateway with NAT Configured

When the device functions as an IPsec gateway to establish an IPsec tunnel with the remote end and also functions as a NAT gateway, there are two scenarios based on where the NAT gateway is deployed:

Scenario 1: Branches' IPsec gateways function as NAT gateways.

In Figure 2, the IPsec gateways (DeviceB and DeviceC) of the two branches also function as NAT gateways to ensure security of the branch networks.

In this scenario, if the data flows requiring NAT need to be directly sent to the Internet without being transmitted over an IPsec tunnel, a NAT policy needs to deny IPsec data flows. If the private IP addresses of two branches overlap, NAT needs to be performed on the data flows of the two branches before the data flows are transmitted through their respective IPsec tunnels.

Figure 2 Branches performing NAT through their own IPsec gateways

Scenario 2: The headquarters' IPsec gateway functions as a NAT gateway.

In Figure 3, the IPsec gateway (DeviceA) at the headquarters also functions as a NAT gateway, and the branches perform NAT through DeviceA.

Figure 3 Branches performing NAT through the headquarters' IPsec gateway
