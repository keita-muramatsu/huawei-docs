Splitting a License

Context

The configuration quotation phase adopts the summary quotation mode because the site deployment is unclear. Partners at all levels can split entitlements based on actual delivery conditions.

Example: In the business distribution scenario, partners at all levels can split entitlements by part number based on frontline sales and delivery requirements of different customers, generate new entitlements, and distribute them.

  • You can split an entitlement only when the entitlement type is Huawei-developed software which is not yet activated. Note that entitlements of third-party software cannot be split.
  • The original entitlement cannot be split into null values. The split is irreversible.

Procedure

  1. Enter a contract number and other required information, and click Search.

    Path: Entitlement Management > My Entitlements > All Entitlements

    Search criteria that are frequently used can be saved as a template.

  2. Click Split in the Operation column.

    For entitlements that meet the split criteria, the Split button is displayed in blue and available. For entitlements that do not meet the criteria, however, the Split button is displayed in gray and unavailable.

  3. Set a split value and click Confirm. You can split an entitlement to a specified number of new entitlements or by part.

    If there are multiple entitlement groups, click Add Entitlement Group. Typically, entitlement groups are split by site. To delete an entitlement group, click . You can click Save as Draft to save the data temporarily. To split an entitlement into multiple entitlements with the same criteria, enter the number of new entitlements.

  4. Click Entitlement ID to view the splitting result on the Splitting Details tab page.
