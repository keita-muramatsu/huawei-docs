Maintenance Assistant

OPS uses the maintenance assistant function to implement automated device management and maintenance. You can create an assistant and define both a trigger condition and task for the assistant. If an assistant task is started, the system monitors the device running status in real time. When the configured trigger condition is met, the system automatically performs the configured task. Assistants enable the system to monitor its running status and take actions in different conditions, improving system maintainability.

Table 1 lists different types of maintenance assistants.
Table 1 Comparison between maintenance assistants

Type

Trigger Condition

Task

Application Scenario

Command assistant

Command-based
The following trigger conditions are configured using commands:

  • Timers

  • Software and hardware alarms

  • Software and hardware events

  • SNMP trap OID

  • Log

Run a command.

If you want a device to run a few commands automatically in a specific condition to implement a function, bind the commands to a command assistant.

Batch file-based

Run a batch file.

If you want a device to run a few commands automatically in a specific condition to implement a function, write the commands one by one to a batch file with the file name extension *.bat. Then, load the batch file and bind it to a command assistant. When the device runs the command assistant, it executes the commands in the batch file in sequence.

Python script-based

Run Python scripts.

To test whether a Python script runs normally, or if you do not want to bind a Python script to a trigger condition but want to run this script, manually trigger the execution of this script using a command.

Script assistant

Defined by Python scripts

Defined by Python scripts

You can configure a Python script assistant and register the subscription event in the script. When the subscription event is matched, the device automatically executes the action defined in the Python script.

The extended functions of the maintenance assistant include the Maintain-Probe (MTP) function, which is used to monitor the connection status of each protocol (such as BFD). When a protocol is disconnected, the maintenance assistant script is triggered to collect the onsite information, improving the maintainability of the entire device.

You can run the condition timer cron command to set the time (in cron format) when setting trigger conditions for an assistant. The time can be a single moment, multiple moments, time range, or interval. Table 2 lists the cron time formats.

Table 2 Cron formats

Usage Scenario

Format

Description

Example

Specifying a single moment

time

It uses a set of integers to indicate a specific moment.

The condition timer cron 0 1 2 5 * 2020 command configures a maintenance assistant to be executed at 01:00 on May 2, 2020.

Specifying multiple moments

time1,time2,time3

It uses a set of integers to indicate multiple moments, each of which is separated by a comma (,) without spaces. There is no restriction on the sequence of moments.

The condition timer cron 0 1,2,3 2 3 * 2020 command configures a maintenance assistant to be executed at the following moments:

  • 01:00, March 2, 2020

  • 02:00 on March 2, 2020

  • 03:00 on March 2, 2020

Specifying an interval

time/step

time is a set of integers indicating a specific moment, and step specifies an interval. time and step are separated by a slash (/) without spaces.

The time is calculated in the format of time, time + 1 x step, …, time + n x step, where n is determined by step in the command. The maximum time must be within the time range.

The condition timer cron 0 0/10 * 3 * 2020 command configures a maintenance assistant to be executed at the following moments:

  • 00:00 on March 1, 2020

  • 10:00 on March 1, 2020

  • 20:00 on March 1, 2020

  • 00:00 on March 2, 2020

  • ...

  • 20:00 on March 31, 2020

Specifying a period

time1-time2

time1 and time2 are integers that specify the start and end time of an assistant task. time1-time2 represents a time range, with two moments being connected by a hyphen (-) without spaces. time2 must be greater than or equal to time1.

The time is calculated in the format of time1, time1 + 1, time1 + 2, ..., time2.

The condition timer cron 0 0-3 1 3 * 2020 command configures a maintenance assistant to be executed at the following moments:

  • 00:00 on March 1, 2020

  • 01:00 on March 1, 2020

  • 02:00 on March 1, 2020

  • 03:00 on March 1, 2020

Specifying a periodical moment

*

* indicates all possible moments.

The condition timer cron 30 10 * 1 1 2020 command configures a maintenance assistant to be executed at 10:30 every Monday in January, 2020.

Specifying a time combination

The previous formats can be used together.

Moments are separated by a comma (,) without spaces.

The condition timer cron 0 0/10,2,4-5 1 3 * 2020 command configures a maintenance assistant to be executed at the following moments:

  • 00:00 on March 1, 2020

  • 02:00 on March 1, 2020

  • 04:00 on March 1, 2020

  • 05:00 on March 1, 2020

  • 10:00 on March 1, 2020

  • 20:00 on March 1, 2020
