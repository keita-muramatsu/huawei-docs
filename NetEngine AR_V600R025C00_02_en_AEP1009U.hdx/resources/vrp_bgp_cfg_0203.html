Configuring BGP Best External

Prerequisites

Before configuring BGP Best External, you have completed the following task:

  • Configure basic BGP functions.

Context

If multiple routes to the same destination are available, a BGP device selects one optimal route based on BGP route selection rules and advertises the route to its peers. The optimal route may be learned from an EBGP peer or an IBGP peer.

However, in scenarios with master and backup provider edges (PEs), if routes are selected based on the existing BGP route selection rules, no backup link may be available. As a result, route convergence takes a long time if a link fails. To solve this problem, configure BGP Best External.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the BGP view.

    bgp as-number

  3. Enter the BGP-VPNv4 address family view.

    ipv4-family vpnv4

  4. Configure BGP to select a suboptimal route (Best External route) if the route preferentially selected by BGP is an IBGP route.

    bestroute best-external

  5. Configure BGP to advertise Best External routes to a specified peer.

    peer ipv4-address advertise best-external

Verifying the Configuration

After configuring the function, verify the configuration.

  • Run the display bgp peer verbose command to check the BGP Best External status.
