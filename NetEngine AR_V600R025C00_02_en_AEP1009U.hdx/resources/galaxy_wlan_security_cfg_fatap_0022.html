Configuring WAPI-Certificate Authentication

Context

WAPI allows only robust security network association (RSNA), providing higher security than WEP or WPA/WPA2.

WAPI-certificate applies to large-scale enterprise networks or carrier networks that can deploy and maintain an expensive certificate system.

WAPI certificates are imported using the Public Key Infrastructure (PKI) certificate management platform.

WAPI defines a dynamic key negotiation mechanism, but there are still security risks if a STA uses the same encryption key for a long time. Both the unicast session key (USK) and multicast session key (MSK) have a lifetime. The USK or MSK needs to be updated when its lifetime ends. To enhance security, WAPI provides the time-based key update mechanism.

Procedure

  1. Enter the system view.

    system-view

  2. Import the ECC key pair and certificate to the device memory.

    pki import ecc-key-pair keyname [ exclude-cert ] { pkcs12 | pem } filename [ exportable ] [ password password ]

  3. Configure a PKI realm.
    1. Create a PKI realm.

      pki realm realm-name

    2. Return to the system view.

      quit

    3. Import a certificate to the PKI realm.

      pki import-certificate { ca | local } realm realm-name { der | pkcs12 | pem } filename file-name

  4. Enter the WLAN view.

    wlan

  5. Create a security profile and enter its view.

    security-profile name profile-name

    By default, the security profile default exists in the system.

  6. Configure the ASU server.
    1. Bind the PKI realm.

      wapi certificate pki realm realm-name

    2. Configure an IP address for the ASU server.

      wapi asu ip ip-address

    3. (Optional) Set the number of retransmissions of certificate authentication packets.

      wapi cert-retrans-count cert-count

  7. Set the security policy to WAPI-certificate authentication.

    security wapi certificate

    By default, no security policy is configured.

  8. (Optional) Set the interval for updating a BK and the BK lifetime percentage.

    wapi { bk-threshold bk-threshold | bk-update-interval bk-update-interval }

    By default, the interval for updating a BK is 43200s, and the BK lifetime percentage is 70%.

  9. (Optional) Set the timeout period of a security association.

    wapi sa-timeout sa-time

    By default, the timeout period of a security association is 60 seconds.

  10. (Optional) Configure the WAPI USK or MSK update.

    wapi { usk | msk } key-update { disable | time-based }

    By default, USKs and MSKs are updated based on time.

  11. (Optional) Set the interval for updating a USK and the number of retransmissions of USK negotiation packets.

    wapi { usk-update-interval usk-interval | usk-retrans-count usk-count }

    By default, the interval for updating a USK is 86400s, and the number of retransmissions of USK negotiation packets is 3.

  12. (Optional) Set the interval for updating an MSK and number of retransmissions of MSK negotiation packets.

    wapi { msk-update-interval msk-update-interval | msk-retrans-count msk-retrans-count }

    By default, the interval for updating an MSK is 86400s, and the number of retransmissions of MSK negotiation packets is 3.
