Configuring the Quiet Function

Context

If a user frequently fails NAC authentication within a short period, system performance will be affected, and it might indicate brute force attacks against the user.

After the quiet function is enabled, the device sets the user to the quiet state for a period of time if the number of authentication failures for the user within 60 seconds exceeds the specified value. During the quiet period, the device will not accept the authentication request packets of the user, preventing frequent authentication failures within a short period.

When the user quiet table is full, the device denies the access of new users who are not in the quiet table.

Procedure

  • Configure the quiet function for 802.1X users.

    1. Enter the system view.

      system-view

    2. Enable the quiet function for 802.1X users.

      dot1x quiet-period

      By default, the quiet function is enabled for 802.1X users.

    3. Configure the maximum number of authentication failures within 60 seconds before the device sets an 802.1X user to the quiet state.

      dot1x quiet-times fail-times

      By default, an 802.1X user enters the quiet state after 10 authentication failures within 60 seconds.

    4. Configure the quiet period for 802.1X users who fail authentication.

      dot1x timer quiet-period quiet-period-value

      By default, the quiet period is 60 seconds for 802.1X users who fail authentication.

  • Configure the quiet function for MAC address authentication users.

    • The quiet function for MAC address authentication users takes effect only after the undo authentication pre-authen-access enable command is run to disable the pre-connection function and the undo authentication event action authorize command is run to disable the device from assigning network access rights to users before successful user authentication.

    1. Enter the system view.

      system-view

    2. Configure the maximum number of authentication failures within 60 seconds before the device sets a MAC address authentication user to the quiet state.

      mac-authen quiet-times fail-times

      By default, a MAC address authentication user enters the quiet state after 10 authentication failures within 60 seconds.

    3. Configure the quiet period for MAC address authentication users who fail authentication.

      mac-authen timer quiet-period quiet-period-value

      By default, the quiet period is 60 seconds for MAC address authentication users who fail authentication. If the value of quiet-period-value is 0, the quiet function is disabled for MAC address authentication users.

  • Configure the quiet function for Portal authentication users.

    1. Enter the system view.

      system-view

    2. Enable the quiet function for Portal authentication users.

      portal quiet enable

      By default, the quiet function is enabled for Portal authentication users.

    3. Configure the maximum number of authentication failures within 60 seconds before a Portal authentication user enters the quiet state.

      portal quiet-times fail-times

      By default, a Portal authentication user enters the quiet state after 10 authentication failures within 60 seconds.

    4. Configure the quiet period for Portal authentication users who fail authentication.

      portal timer quiet-period quiet-period-value

      By default, the quiet period is 60 seconds for Portal authentication users who fail authentication.
