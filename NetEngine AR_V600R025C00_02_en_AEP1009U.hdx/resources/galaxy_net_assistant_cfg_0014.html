Example for Enabling the Net Assistant Function and Logging In to WebMaster

Networking Requirements

On the network shown in Figure 1, devices on the network are physically connected and powered on. DeviceA functions as the egress gateway, DeviceB functions as the master device and DHCPv4 server, and DeviceC, DeviceD, and DeviceE function as member devices and start with default configurations.

After the net assistant function is enabled, the system automatically generates a virtual IP address. You can use this IP address to log in to WebMaster and implement unified configuration and management of network devices through simple web operations. For details, see WebMaster Solution Overview.

Figure 1 Enabling the net assistant function

Configuration Roadmap

The configuration roadmap is as follows:

  1. Enable DHCP on DeviceB and configure an IP address for VLANIF1.
  2. Create a local account on DeviceB.
  3. Configure the master role for DeviceB.
  4. Open the web browser on a PC connected to the network, use the created local account to access the virtual IP address of the master device, and log in to WebMaster.

Procedure

  1. Enable DHCP and configure an IP address for VLANIF1.

    <HUAWEI> system-view 
[HUAWEI] sysname DeviceB
[DeviceB] dhcp enable
[DeviceB] interface vlanif 1 
[DeviceB-Vlanif1] ip address 10.10.1.1 24

  2. Enable VLANIF1 to use the DHCP interface address pool.

    [DeviceB-Vlanif1] dhcp select interface
[DeviceB-Vlanif1] dhcp server gateway-list 10.10.1.1
[DeviceB-Vlanif1] quit

  3. Create a local account.

    [DeviceB] aaa
[DeviceB-aaa] local-user admin123 password irreversible-cipher YsHsjx_202206
[DeviceB-aaa] local-user admin123 service-type http
[DeviceB-aaa] local-user admin123 privilege level 3
[DeviceB-aaa] quit

  4. Configure the master role for the device.

    [DeviceB] ual role controller

Verifying the Configuration

Open the browser on a PC connected to the network and enter https://10.231.10.253:443 to access the virtual IP address of the master device. Enter the username admin123 and password YsHsjx_202206 to log in to WebMaster.
