Querying LLDP-EXT-DOT3-MIB Information

Description of MIB Objects

LLDP-EXT-DOT3-MIB allows you to query information about TLVs defined by IEEE802.3, including whether the TLVs can be sent, auto-negotiation support on the local and remote ports, powering capabilities, link aggregation, and maximum frame length. The OID of the root object is 1.0.8802.1.1.2.1.5.4623. For details, see LLDP-EXT-DOT3-MIB.

You can use the following objects to obtain extended LLDP information.

Table 1 Description of MIB Objects

Object

OID

lldpXdot3PortConfigTLVsTxEnable

1.0.8802.1.1.2.1.5.4623.1.1.1.1.1

lldpXdot3LocPortAutoNegSupported

1.0.8802.1.1.2.1.5.4623.1.2.1.1.1

lldpXdot3RemPortAutoNegSupported

1.0.8802.1.1.2.1.5.4623.1.3.1.1.1

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.
  2. Perform the Walk operation on the lldpXdot3PortConfigTLVsTxEnable object to query whether TLVs defined by IEEE 802.3 can be sent through the local LLDP port. As shown in Querying whether TLVs defined by IEEE 802.3 can be sent through the local LLDP port, TLVs defined by IEEE 802.3 can be sent through the local LLDP port.
    Figure 1 Querying whether TLVs defined by IEEE 802.3 can be sent through the local LLDP port
  3. Perform the Walk operation on lldpXdot3LocPortAutoNegSupported to query whether the local LLDP port supports rate auto-negotiation. As shown in Querying whether the local LLDP port supports rate auto-negotiation, the local LLDP port supports rate auto-negotiation.
    Figure 2 Querying whether the local LLDP port supports rate auto-negotiation
  4. Perform the Walk operation on lldpXdot3RemPortAutoNegSupported to query whether the remote LLDP port supports rate auto-negotiation. As shown in Querying whether the remote LLDP port supports rate auto-negotiation, the remote LLDP port supports rate auto-negotiation.
    Figure 3 Querying whether the remote LLDP port supports rate auto-negotiation
