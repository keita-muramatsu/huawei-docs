Configuring UAL Functions

Context

The UAL mainly provides protocol channels for automatically discovering and managing NEs for WebMaster. Through this protocol, WebMaster implements autonomous discovery, networking, and diagnosis of campus network devices.

For details about configurations on WebMaster, see WebMaster Configuration Guide.

Procedure

  • Configure basic UAL functions.

    • Device role election
      1. Enter the system view.
        system-view
      2. Configure the specified NE as the master device.
        ual role controller
    • Automatic NE discovery

      The master device automatically discovers NEs on the network through the UAL protocol. No manual configuration is required.

    • One-click NE topology re-collection
      • Configure one-click network topology re-collection in the user view.
        reset ual topo-info

  • Enhanced UAL functions

    • Accurate loop topology blocking

      After the STP configuration is delivered on WebMaster, the accurate loop topology blocking function is automatically enabled. No manual configuration is required.
