Configuring AP Installation Position Information

Context

To facilitate management and maintenance, you can configure AP installation positions as required.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Enter the AP view or AP group view.
    • Enter the AP group view.
      ap-group name group-name
    • Enter the AP view.
      ap-id ap-id
  4. Configure AP installation position information.

    location location-value

    By default, the installation position of an AP is not configured.

Verifying the Configuration

  • Run the display ap config-info ap-id ap-id command to check the AP installation position based on the AP location field.
  • Run the display ap-group { all | name group-name } command to check AP installation position information based on the AP location field.
