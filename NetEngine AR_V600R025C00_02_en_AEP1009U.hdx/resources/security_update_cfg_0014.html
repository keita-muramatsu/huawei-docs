Rolling Back the Signature Database Version

Prerequisites

The signature database version to which the current version can be rolled back (rollback version) is stored in the flash:/update/ directory of the device.

To perform a version rollback for the IPS signature database, antivirus signature database, , ensure that the corresponding license control items have been purchased and activated.

Context

If a fault (for example, false positive or system performance deterioration) occurs on the current signature database, you can roll back the current signature database to the previous version. A version can be rolled back only to the previous version. When version rollback is performed repeatedly, the version is switched between the current version and rollback version.

Procedure

  1. Enter the system view.

    system-view

  2. Roll back the signature database version.

    update rollback { av-sdb | ips-sdb | sa-sdb }
update rollback location-sdb

    For the AR5700 series, only the AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S and AR5710-S10T1X2 do not support the ips-sdb and av-sdb parameters.

  3. Optional: Forcibly roll back the signature database version.

    update force rollback { av-sdb | ips-sdb | sa-sdb }

    For the AR5700 series, only the AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S and AR5710-S10T1X2 do not support the ips-sdb and av-sdb parameters.

    If there is insufficient system memory for the signature database rollback, the rollback fails. In this case, you can run this command to forcibly roll back the signature database. After the command is executed, the ASE does not take effect in a short period of time and all ASE-related session entries are reset. Exercise caution when running this command.
