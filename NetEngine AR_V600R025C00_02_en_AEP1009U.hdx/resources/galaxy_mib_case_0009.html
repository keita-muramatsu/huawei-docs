Querying the Average Management Plane CPU Usage of an Entity Within 5 Seconds

Description of MIB Objects

You can use hwCpuDevDuty in hwCpuDevTable to obtain the average management plane CPU usage of an entity within 5 seconds.

Object

OID

hwCpuDevIndex

1.3.6.1.4.1.2011.6.3.4.1.1

hwCpuDevDuty

1.3.6.1.4.1.2011.6.3.4.1.2

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.
  2. Perform the Walk operation on hwCpuDevDuty to query the average management plane CPU usage of an entity within 5 seconds. As shown in Figure 1, the first digit in the index value indicates the chassis number, the second digit indicates the slot number (Slot number = Slot ID + 32 x CPU ID), and the third digit is used for extension and is fixed at 0.
