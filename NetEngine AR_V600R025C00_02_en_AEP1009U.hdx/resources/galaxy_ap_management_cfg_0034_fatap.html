Checking AP Neighbor Information

Context

You can view AP neighbor information to analyze AP deployment and neighbor relationships, facilitating subsequent network planning and rogue AP detection.

Procedure

  • Run the display ap lldp neighbor { ap-id ap-id [ interface interface-type interface-number ] | brief } command to check LLDP neighbor information on a specified AP.
  • Run the display ap around-ssid-list ap-id ap-id command to check SSIDs of neighbors of a specified AP.
