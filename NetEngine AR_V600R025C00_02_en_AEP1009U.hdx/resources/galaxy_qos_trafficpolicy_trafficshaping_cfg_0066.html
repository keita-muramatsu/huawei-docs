Configuring MQC to Implement Traffic Shaping

Context

In class-based queuing (CBQ) mode, after referencing a flow queue (FQ) profile in a traffic behavior, you can associate the traffic behavior with a traffic classifier in a traffic policy and apply the traffic policy to an interface to implement traffic shaping for traffic matching traffic classification rules. For details about the CBQ mode, see CBQ Configuration Model.

Procedure

  1. Enter the system view.

    system-view

  2. Create a WRED drop profile and enter the WRED drop profile view.

    drop-profile drop-profile-name

    By default, a WRED drop profile named default exists on the device.

    A maximum of 63 WRED drop profiles, including the default drop profile, can be configured on the device. The default drop profile cannot be deleted, and only parameters in the profile can be modified.

  3. Set WRED parameters.

    • Configure the current WRED drop profile to drop packets based on the default priority.
      wred blind
color blind low-limit low-limit-percentage high-limit high-limit-percentage discard-percentage discard-percentage

      The default mode is blind and does not need to be changed. By default, the upper drop threshold in percentage, lower drop threshold in percentage, and maximum drop probability in a WRED drop profile are all 100.

    • Configure the current WRED drop profile to drop packets based on the DSCP priority.
      wred dscp
dscp { start-dscp-value [ to end-dscp-value ] } &<1-10> low-limit low-limit-percentage high-limit high-limit-percentage discard-percentage discard-percentage

      The default mode is blind. Before configuring a WRED drop profile in DSCP mode, change to DSCP mode first. By default, the upper drop threshold in percentage, lower drop threshold in percentage, and maximum drop probability in a WRED drop profile are all 100.

    For the AR8700 series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, and AR6710-L50T2X4-T, the default mode of a WRED drop profile is blind and cannot be configured. Therefore, only WRED parameters in blind mode can be configured.

    Only the AR8100 series, AR6700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L14T2X4, and AR5700 series support the setting of WRED parameters in DSCP mode.

  4. Exit the WRED drop profile view.

    quit

  5. Create an FQ profile and enter the FQ profile view.

    flow-queue flow-queue-name

    By default, no FQ profile is created. A maximum of 1024 FQ profiles can be configured on the device. A maximum of 128 FQs can be configured in an FQ profile.

  6. Set QoS parameters for an FQ in the FQ profile.

    For the AR6700-H series and AR8100 series:
    queue queue-name { pq | drr weight weight-value [ weight-fix ] } { shaping { shaping-value | { shaping-percentage | cir-shaping-percentage } shaping-percentage-value } [ pbs pbs-value ] } [ queue-length packets packets-value ]

    For the AR8700 series:

    queue queue-name { pq | drr weight weight-value [ weight-fix ] } { shaping { shaping-value | { shaping-percentage | cir-shaping-percentage } shaping-percentage-value } [ pbs pbs-value ] } [ queue-length depth-value ]

    For the AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, and AR6710-L50T2X4-T:

    queue queue-name { pq | drr weight weight-value } { shaping { shaping-value | { shaping-percentage | cir-shaping-percentage } shaping-percentage-value } [ pbs pbs-value ] } [ queue-length depth-value ]
    For the AR5700 series, AR6710-L8T3TS1X2, and AR6710-L8T3TS1X2-T:
    queue queue-name { pq | drr weight weight-value } { shaping { shaping-value | { shaping-percentage | cir-shaping-percentage } shaping-percentage-value } [ pbs pbs-value ] } [ queue-length [ depth-value ] [ packets packets-value ] ]

    For the AR6710-L14T2X4:

    queue queue-name { pq | drr weight weight-value } { shaping { shaping-value | cir-shaping-percentage shaping-percentage-value } [ pbs pbs-value ] } [ queue-length packets packets-value ]

    By default, QoS parameters are not set for an FQ in an FQ profile.

  7. Configure a traffic classifier.

    For details about how to configure a traffic classifier, see Configuring a Traffic Classifier in "MQC Configuration".

  8. Configure a traffic behavior.
    1. Create a traffic behavior and enter the traffic behavior view, or enter the view of an existing traffic behavior.

      traffic behavior behavior-name

    2. Reference an FQ profile in the traffic behavior.

      flow-queue flow-queue-name queue queue-name

    3. Exit the traffic behavior view.

      quit

  9. Configure a traffic policy.
    1. Create a traffic policy and enter the traffic policy view, or enter the view of an existing traffic policy.

      traffic policy policy-name

    2. Bind a traffic behavior and a traffic classifier to the traffic policy.

      classifier classifier-name behavior behavior-name [ precedence precedence-value ]

    3. Exit the traffic policy view.

      quit

  10. Apply a traffic policy.

    The application direction supported by a traffic policy is related to the configured action in a traffic behavior. For details, see configuration precautions for the feature.

    • Apply a traffic policy to an interface.
      1. Enter the interface view.
        interface interface-type interface-number
      2. Apply a traffic policy to the interface.
        traffic-policy policy-name { inbound | outbound } [ preprocess | firstprocess  ]
        traffic-policy policy-name inbound decap-process

        If the decap-process parameter is specified, you need to run the qos car inbound decap-process command in the interface view to configure the bandwidth limit for the decapsulation service in the inbound direction of the interface.

      3. Exit the interface view.
        quit
    • Apply a traffic policy to a site group.

      This command is supported only on the AR8100 series, AR6700-H series, and AR8700 series.

      1. Create a site group and enter the site group view.
        evpn site-group name
      2. Apply a traffic policy to the site group.
        traffic-policy policy-name outbound
      3. Exit the site group view.
        quit
