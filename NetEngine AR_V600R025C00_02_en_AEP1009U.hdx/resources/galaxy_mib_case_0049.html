Querying HUAWEI-LLDP-MIB Information

Description of MIB Objects

You can use the following objects to obtain LLDP extended information defined by Huawei.

Object

OID

hwLldpEnable

1.3.6.1.4.1.2011.5.25.134.1.1.1

hwLldpLocManIPAddr

1.3.6.1.4.1.2011.5.25.134.1.1.2

hwLldpNotificationEnable

1.3.6.1.4.1.2011.5.25.134.1.1.4

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.

  2. Perform the Walk operation on hwLldpEnable to query the global LLDP status (enabled or disabled). As shown in Figure 1, the global LLDP status is enabled.

    Figure 1 Querying the global LLDP status

  3. Perform the Walk operation on hwLldpLocManIPAddr to query the LLDP local management IP address. As shown in Figure 2, the LLDP local management IP address is 192.0.2.9.

    Figure 2 Querying the LLDP local management IP address

  4. Perform the Walk operation on hwLldpNotificationEnable to query the global LLDP alarm status. As shown in Figure 3, the global LLDP alarm status is enabled.

    Figure 3 Querying the global LLDP alarm status
