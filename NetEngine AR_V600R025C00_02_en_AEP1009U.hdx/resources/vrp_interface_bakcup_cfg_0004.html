Understanding Association Between Interface Backup and NQA

Network Quality Analysis (NQA) is a real-time network performance detection and statistics collection technology. It measures network performance and collects statistics about the response time, jitter, and packet loss rate. On the network shown in Figure 1, DeviceA (the egress gateway of the headquarters) connects to the Internet through interface1. The link between interface1 and the Internet is used as the primary link to transmit services and communicate with the branch, and interface2 is used as the backup link's outbound interface. An NQA test instance is configured on DeviceA, and association between interface backup and NQA is configured on interface2. When the primary link fails, the NQA test instance detects the fault and instructs DeviceA to transmit services through interface2.

The primary/backup link switchover principles are as follows:

  • When NQA detects that the primary link is normal, the primary link transmits services.
  • When NQA detects that the primary link is unreachable or has poor quality, it instructs DeviceA to transmit services temporarily through the backup interface.
  • When NQA detects that the primary link is restored, traffic is switched back to the primary interface.
