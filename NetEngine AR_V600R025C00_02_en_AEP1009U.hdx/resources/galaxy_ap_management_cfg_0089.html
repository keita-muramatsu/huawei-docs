Configuring an Eth-Trunk on AP Wired Interfaces

Context

To improve connection reliability and increase bandwidth, you can bind multiple interfaces into an Eth-Trunk. As shown in Figure 1, the AP wired interfaces GE0/0/0 and GE0/0/1 are connected to GE0/0/1 and GE0/0/2 of the switch, respectively. The Eth-Trunk configuration is required on both the AP and switch. For details about Eth-Trunk implementation, see "Eth-Trunk Configuration" in CLI Configuration Guide > Ethernet Switching Configuration.

Figure 1 Network diagram of the Eth-Trunk configuration on AP wired interfaces

When configuring Eth-Trunk on AP wired interfaces, pay attention to the following:

  • Physical interfaces to be added to an Eth-Trunk cannot have other configurations. If there are any configurations, clear them first. The configurations to be cleared do not include the interface status, description, LLDP function, or CRC alarm configuration.

  • After the configuration, you need to restart the AP to make the Eth-Trunk configuration on the AP's wired interfaces take effect.

  • This configuration is not supported by APs with only one uplink network port.

  • Downlink interfaces on an AP do not support the Eth-Trunk function.

  • Eth-Trunk member interfaces do not support the PVID or user isolation configuration.
  • For an AP that has gone online, configure the Eth-Trunk function before connecting physical cables. Otherwise, loops may occur, causing the APs to go offline.
  • For an AP that has not gone online, connect physical cables and then configure the Eth-Trunk function in the following sequence:
    1. Before the AP goes online, connect multiple physical cables between the AP and a switch. By default, the switch interfaces are enabled and are not configured with the Eth-Trunk function.
    2. Run the shutdown command in the interface view on the switch to shut down interfaces. Among the interfaces connected to the same AP, reserve only one enabled for the AP to go online.
    3. Configure the AP to go online, and configure the Eth-Trunk function on AP wired interfaces. Restart the AP so that the Eth-Trunk configuration takes effect.
    4. Configure an Eth-Trunk on the switch and run the undo shutdown command in the interface view to enable the interfaces that have been shut down.
  • For an AP that supports only one Eth-Trunk, the configuration takes effect only when the Eth-Trunk ID is set to 0.
  • If a member interface of an Eth-Trunk is connected to a peer end, the peer interface directly connected to the local interface must also be a member interface of an Eth-Trunk.
  • An Eth-Trunk cannot be added to another Eth-Trunk as a member interface.
  • Do not configure any member interface of an Eth-Trunk as an observing port. If this cannot be avoided, ensure that the bandwidth of service traffic on the member interface and the bandwidth of the mirrored traffic do not exceed the bandwidth limit of the interface.
  • An Ethernet interface can be added to only one Eth-Trunk. To add the Ethernet interface in an Eth-Trunk to another Eth-Trunk, delete it from the original Eth-Trunk first.
  • After an interface is added to an Eth-Trunk, MAC address entries and ARP entries are learned based on the Eth-Trunk but not based on member interfaces.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP wired port profile and enter its view.

    wired-port-profile name wired-port-profile-name

    By default, the AP wired port profile default exists on the device.

  4. Add an AP's wired interface to an Eth-Trunk.

    eth-trunk trunk-id

    By default, an AP's interface is not added to any Eth-Trunk.

  5. Return to the WLAN view.

    quit

  6. Enter the AP group view or AP view.
    • Enter the AP group view.
      ap-group name group-name
    • Enter the AP view.
      ap-id ap-id
  7. Bind the AP wired port profile to an AP group or a single AP. Repeat this step to bind all Eth-Trunk member interfaces to the AP wired port profile.

    wired-port-profile profile-name interface-type interface-number

    By default, the AP wired port profile default is bound to an AP group, but no AP wired port profile is bound to an AP.

Follow-up Procedure

After adding member interfaces to an Eth-Trunk, you need to configure attributes for the Eth-Trunk interface. For details, see Configuring the Working Mode and VLANs for an AP's Wired Interface. After the configuration is complete, run the wired-port-profile profile-name eth-trunk interface-number command in the AP group or AP view to apply the configuration in the AP wired port profile to the Eth-Trunk. For details, see Binding an AP Wired Port Profile.
