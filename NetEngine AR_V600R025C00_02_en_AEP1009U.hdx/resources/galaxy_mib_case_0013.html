Querying the Temperature

Description of MIB Objects

You can use hwEntityTemperature in hwEntityStateTable to obtain the temperature of all entities.

Object

OID

entPhysicalName

1.3.6.1.2.1.47.1.1.1.1.7

hwEntityTemperature

1.3.6.1.4.1.2011.5.25.31.1.1.1.1.11

The temperature obtained by the MIB query tool is that of the temperature sensor on the CPU.

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.
  2. Perform the Walk operation on entPhysicalName to query the entity index entPhysicalIndex. As shown in Figure 1, the obtained entity index is 16777217.
    Figure 1 Querying the entPhysicalIndex value through entPhysicalName


  3. Perform the Walk operation on hwEntityTemperature to query the temperature of the corresponding entity based on entPhysicalIndex. As shown in Figure 2, the temperature of the entity with the index 16777217 is 32°C.
    Figure 2 Querying the temperature through hwEntityTemperature and entPhysicalIndex
