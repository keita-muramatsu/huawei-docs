Configuring Fast Power-On for a PoE Interface

Context

If a PoE device is powered off, interfaces on this device cannot be powered on until the device is restarted. During this period, PDs connected to these interfaces remain powered off. To enable the PoE device to supply power to the PDs immediately after being powered on, without waiting until it finishes restarting, configure the fast power-on function for PoE interfaces on the device. When configured, this function shortens the power outage time of the PDs if the PoE device is restarted due to a power outage.

The fast power-on function takes effect only during cold start of the device.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the interface view.

    interface interface-type interface-number

  3. Enable fast power-on for a PoE interface.

    poe fast-on enable

    If the PD connected to an interface supports LLDP negotiation, you are not advised to enable fast power-on. Otherwise, LLDP negotiation may fail, and you can rectify this negotiation failure by powering on the PD again.

Verifying the Configuration

Run the display poe power-state [ slot slot-id | interface { interface-type interface-number | interface-name } ] command to check whether fast power-on is enabled for the PoE interface based on the Port Power fast-on state field in the command output.
