(Optional) Configuring the Function of Recording a Log When an IPv6 Address or Prefix Is Allocated

Context

Recording a log on the DHCPv6 or DHCPv6 PD server when an IPv6 address or prefix is allocated, renewed, or released, or an IPv6 address or prefix conflict is detected facilitates routine maintenance and fault locating.

  • After the log recording function is enabled, the server frequently records logs if a large number of clients request IPv6 addresses or prefixes. This may deteriorate device performance.
  • IP address allocation logs are recorded in the AM module. To view logs, you must enable the information center function. The default configuration of the log output function varies according to the log level and output direction. For details, see "Information Management Configuration" in CLI Configuration Guide > System Management Configuration.

Procedure

  1. Enter the system view.

    system-view

  2. Create an IPv6 address pool and enter its view.

    dhcpv6 pool pool-name

    By default, no IPv6 address pool is created on a device.

  3. Enable the function of recording a log when the DHCPv6 or DHCPv6 PD server allocates an IPv6 address or prefix.

    logging [ allocation-address-success | allocation-prefix-success | detect-address-conflict | release-address-success | release-prefix-success | renew-address-success | renew-prefix-success ] *

    By default, the function of recording a log when the DHCPv6 or DHCPv6 PD server allocates an IPv6 address or prefix is disabled.
