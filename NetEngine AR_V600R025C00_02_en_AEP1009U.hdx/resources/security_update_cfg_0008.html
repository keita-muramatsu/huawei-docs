Understanding Online Signature Database Update

Methods for Online Signature Database Update

If configured to do so, the device can obtain the latest version of the signature database file from the update server at the Huawei intelligent security center through the Internet, and then perform an online signature database update, as shown in Figure 1.

Figure 1 Online signature database update

Online update is classified into automatic online update and manual online update. The two modes use the same signature database download address and update process. The differences between the two modes are as follows:
  • In automatic online update function, the device automatically connects to the update server at the Huawei Intelligent Security Center at a specified update interval to check for a newer version of the signature database file. If a newer version is found, the device automatically downloads it and updates the local signature database. Within 24 hours of the device starting for the first time, it attempts to update the signature database every five minutes until the current signature database version is the latest.
  • In manual online update mode, the administrator manually connects the device to the update server at the Huawei Intelligent Security Center to check for a newer version of the signature database file. If a newer version is found, the device automatically downloads it and updates the local signature database. Manual online update can be performed at any time.

In a hot standby scenario, the active device immediately updates the signature database online after an active/standby switchover.

Online Signature Database Update Process

The update service at the Huawei Intelligent Security Center is provided together by the control server, download server, and release server. The functions of each server are as follows:

  • Control server: The control server is used to allocate a download server to the device and manage the status of the download server. The default domain name of the control server is sec.huawei.com.

  • Download server: The download servers are used to store signature database files. The download servers are deployed in different regions.

  • Release server: The release server is used to distribute signature database files to the download server.

The update environment in the Huawei Intelligent Security Center uses a distributed architecture and is known as the update server of the Huawei Intelligent Security Center. The device can update the signature database online only when it connects to the update server at the Huawei Intelligent Security Center. The device uses the domain name and IP address of the control server to connect to the update server.

Figure 2 shows the online signature database update process.

Figure 2 Online signature database update process

The release server periodically distributes the latest signature database file to the download server, which then interacts with the device to update the signature database file. The interaction process is as follows:

  1. The device connects to the control server and initiates a signature database update request for the IP address of a download server.

    The device connects to the control server using HTTPS and port 443. The request sent by the device contains the device model, version, ESN, signature database type, current signature database version, and country information (optional). The data is used only to identify the device and the country/region where the device is located (no personal data is involved). Data is encrypted during transmission and only Huawei is involved in the data processing.

  2. After receiving the request, the control server allocates the IP address of a download server to the device based on the information contained in the request.

    • If the country information is provided in the request, the control server preferentially allocates a download server in a region to which the device belongs.
    • If the country information is not provided in the request, the control server allocates a download server in a region to which the IP address of the device belongs.

  3. The device connects to the download server using HTTPS and port 443 and requests to download a signature database file.

  4. After receiving the request, the download server sends the encrypted signature database file to the device.
