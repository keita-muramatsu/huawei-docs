IoT Profile

Overview

An IoT profile is a mandatory object to be referenced in serial port protocol–based interconnection scenarios. It allows you to configure trusted hosts and shared keys for communication between APs and host computers.

For details about how to configure an IoT profile, see "Configuring an IoT Card Based on the Serial Port Protocol" in CLI Configuration Guide > WLAN Configuration > IoT Card Configuration. The following only describes how to create and apply an IoT profile.

Creating a Profile

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an IoT profile and enter its view.

    iot-profile name profile-name

    By default, no IoT profile is created on the device.

Applying a Profile

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Enter the AP view or AP group view.
    • Enter the AP group view.
      ap-group name group-name
    • Enter the AP view.
      ap-id ap-id
  4. Enter the IoT card interface view.

    card { card-number | usb | ble }

  5. Bind the IoT profile to an AP group or a specific AP, and configure the local port number mapping to the IoT card interface.

    iot-profile profile-name config-agent { tcp | udp } port port [ ext-port ext-port ]

    By default, no IoT profile is bound to an AP group or a specific AP.
