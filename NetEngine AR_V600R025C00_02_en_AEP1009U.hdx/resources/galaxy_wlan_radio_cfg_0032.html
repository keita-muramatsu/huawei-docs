Configuring Interference Visualization for Co-channel APs

Prerequisites

The interconnection with the analyzer has been configured by referring to Configuring the KPI Reporting Function.

Context

The analyzer can implement interference visualization by displaying information such as received and sent packets of multiple co-channel APs, thereby presenting air interface interference behavior to users. This function requires that interference visualization be enabled on AP radios (a maximum of 20).

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Enter the AP view.

    ap-id ap-id

  4. Enter the radio view.

    radio radio

  5. Enable interference visualization for AP radios.

    interference-visualization enable

  6. Return to the WLAN view.

    quit
quit

  7. Configure APs to report logs to the analyzer.

    • In WMI mode:
      wmi-server name profile-name
ap log module mid ffdc0000
    • Through the log server in UDP mode:
      ap-system-profile name profile-name
log-server ip-address server-ip-address [ port port ]

      By default, the UDP port number is 514.

Result

Run the display interference-visualization configuration command to check information about AP radios on which interference visualization has been enabled.
