Configuring Parameters for Optimizing IPv4 over IPv6 Tunnel Performance

Context

You can configure parameters listed in Table 1 for the IPv6 header attached to original packets to ensure effective transmission of packets in an IPv4 over IPv6 tunnel.

Procedure

Table 1 Configuring parameters for optimizing IPv4 over IPv6 tunnel performance

Operation

Command

Description

Specify the maximum number of nested IPv6 encapsulations that can be performed on intermediate nodes in an IPv4 over IPv6 tunnel.

tunnel ipv4-ipv6 encapsulation-limit encapsulation-limit

When an intermediate node in an IPv4 over IPv6 tunnel is an ingress node of another IPv6 tunnel, an IPv4 over IPv6 tunnel packet can be encapsulated again as a payload with another IPv6 tunnel header. This process is called a nested IPv6 encapsulation. A packet with too many nested encapsulations will be oversized and discarded. Therefore, you are advised to set the maximum number of nested encapsulations for IPv6 packets when there are non-Huawei devices residing along the IPv4 over IPv6 tunnel. By default, a maximum of four nested IPv6 encapsulations are supported.

Configure a flow label value.

tunnel ipv4-ipv6 flow-label label-value

You can configure a flow label value to identify a specified service flow, to enable special processing to be performed on this flow. By default, the flow label value is 0.

Set a hop limit.

tunnel ipv4-ipv6 hop-limit hop-limit

Setting a tunnel hop limit can quickly terminate packet transmission upon routing loops on an IPv4 over IPv6 tunnel. To ensure that IPv6 packets can reach the egress node of a tunnel, set a tunnel hop limit according to the actual network topology. By default, the hop limit is 64.

Configure a traffic class value.

tunnel ipv4-ipv6 traffic-class { original | class-value }

You can configure a value for the Traffic Class field in the IPv6 header to identify the service type of an IPv4 over IPv6 tunnel packet. This field is similar to the type of service (ToS) field in an IPv4 header. By default, the traffic class value is 0 for an IPv4 over IPv6 tunnel.
