Client Obtains an IPv4 Address from a DHCPv4 Server Slowly

Possible Cause

Broadcast traffic suppression is configured.

Troubleshooting Roadmap

Check whether broadcast traffic suppression is configured between the DHCPv4 server and client. If the number of DHCPv4 request messages broadcast on the network exceeds the threshold, excess DHCPv4 request messages are discarded.

Solution

Adjust the threshold for broadcast traffic suppression based on the service volume.

Possible Cause

STP is enabled on the DHCPv4 server or relay agent.

Troubleshooting Roadmap

Check whether STP is enabled on the DHCPv4 server or relay agent. If so, address allocation may be slow.

Solution

If STP does not need to be enabled, run the undo stp enable command to disable it.
