Specifying the Configuration File for Next Startup

Context

When the system restarts, it uses the specified configuration file to restore configurations.

Before specifying the file for the next startup, you can run the display startup command to view the current specified file.

If no configuration file is specified for the next startup, the default configuration file default.cfg or preset configuration file will be used for the next startup.

If no configuration file for the next startup is available, the device starts with empty configuration.

  • Manually constructing a configuration file is not recommended because manual construction is prone to file format errors. The format error may cause a failure to restore configurations or an error during configuration restoration.
  • The configuration file for the next startup must exist and be saved in the root directory of the storage medium.
  • You can perform one of the following operations to set the configuration file according to the actual situation.
  • If whether the configuration file contains local user configurations (such as the local login user name and password) does not need to be checked, you can run the configuration check local-user disable command to disable local user configuration check.

Procedure

  • Configure the configuration file for the next startup.

    startup saved-configuration configuration-file

  • Configure the configuration file containing key information for the next startup.

    startup shareable-configuration configuration-file [ password ]

    If the configuration file configured for the next startup contains key information, you need to enter a password for authentication before using the file.

  • Configure the preset configuration file.

    startup default-configuration configuration-file

    The preset configuration file must be saved in the root directory of the device before this command is executed, with a file name extension as .defcfg. If no configuration file is specified for the next startup, the preset configuration file will be used during system startup.

  • (Optional) Configure the startup mode of the configuration file for the next startup.

    configuration next-startup-mode { cfg | default }

    By default, the device starts through loading a database file.

    When the device starts with configurations in a database file, the system checks whether the database file version matches that of the basic software package and whether the database file is consistent with the configuration file for next startup. If the version does not match or the files are inconsistent, even if the database file is configured to be preferentially loaded, the device starts with configurations in a text file.

  • Specify the PAF file that takes effect at the next startup.

    startup paf { default | file-name }

Verifying the Configuration

Run the display configuration recover-result command to check the configuration restoration result after the restart and the failure cause.

Run the display configuration next-startup-mode command to view the startup mode of the configuration file for next startup set using the configuration next-startup-mode command.
