Checking Information About APs' Going-Offline Records and Onboarding Failures

Context

When APs go offline or fail to go online, maintenance personnel can check the corresponding records for locating reasons.

Procedure

  • Run the display ap online-fail-record { all | mac mac-address } command to check onboarding failure records of APs.
  • Run the display ap offline-record { all | mac mac-address } command to check going-offline records of APs.
