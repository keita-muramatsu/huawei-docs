Configuring RTU Licenses for APs

Prerequisites

Before configuring RTU licenses for APs, you have completed the following tasks:

  • Obtain the contract number.

  • Obtain the ESN list of APs.

Context

From V200R019C10, some AP models support right-to-use (RTU) licenses.

RTU is an authorization mode for selling hardware capabilities in installments, such as the number of spatial streams, capacity, and ports. An RTU license cannot be migrated after being bound to a device. As a part of hardware value, RTU licenses have the same lifecycle and the same entitlement as the hardware. For example, after applying for RTU licenses in batches, you will obtain an RTU license package. You need to upload the RTU license package to the AC or AP, and then load the package to automatically deliver the RTU licenses to the corresponding APs.

This method is applicable to scenarios when RTU licenses are purchased for APs.

One RTU license can permanently authorize the enhanced hardware capability for one AP. If there are a large number of APs, online batch license activation is recommended to obtain an RTU license package for multiple APs. The RTU license file is a .zip package and does not need to be decompressed.

Procedure

  1. Apply for a license.
    1. Log in to the ESDP and go to the Online Batch Activation page. Search for the activation ID based on the contract number and product name (L-WiFi6-RTU). Export the table that contains the activation ID, enter the ESNs of APs, save the table, and then import the table.

      The following figure shows the format of the exported table. Enter the ESNs of APs to bind the APs to RTU activation IDs.

    2. After the table is imported, download the RTU license package.

      The package contains the RTU license files for each AP.

  2. Upload the obtained license file to the root directory of the storage medium on the device. For details, see "File System Management Configuration" in CLI Configuration Guide > Basic Configuration.
  3. Install the license.
    1. Enter the system view.

      system-view

    2. Enter the WLAN view.

      wlan

    3. Unzip an RTU license package and automatically deliver the unzipped RTU licenses to the corresponding APs.

      ap rtu load filename filename

    4. Wait for a period of time and check the RTU license loading status of the APs.

      display ap-rtu-status { all | by-state state }

      When the RTU license loading status is Activating(Need reboot), go to the next step to reset the APs.

    5. Resets APs on which RTU licenses have been loaded but have not taken effect.

      ap-reset wait-rtu-validate

Verifying the Configuration

  • Run the display ap-rtu-status { all | by-state state } command to check the RTU license loading status of APs.
