Querying the Status of a VRRP Group

Description of MIB Objects

vrrpOperTable describes VRRP group information, including the VRID of the VRRP group, virtual MAC address, and interval at which VRRP Advertisement packets are sent.

You can use vrrpOperState in vrrpOperTable to query the status of all VRRP groups. The status can be initialize, master, or backup.

Object

OID

vrrpOperState

1.3.6.1.2.1.68.1.3.1.3

Procedure

  1. Search for the location of an object in the MIB tree. You can search for a node based on its location in the MIB tree. However, it is difficult to find a node if a large number of MIB files are imported to MIB Browser. In this case, press Ctrl+F to locate an object.
  2. As shown in Figure 1, select vrrpOperState and perform the Walk operation to query the status of all VRRP groups. In the query result of vrrpOperState.115.1 (integer) master(3), 115 indicates the index of the interface where the VRRP group is configured, 1 indicates the VRRP group ID, and master(3) indicates the VRRP group status.
