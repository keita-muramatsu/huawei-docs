Configuring Loopback Detection on an E1/CE1 Interface

Context

Loopback detection is used to detect the status of an interface or a link. Disable this function when the interface or link is working properly.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the E1/CE1 interface view.

    controller e1 interface-number

  3. Configure a loopback detection mode for the E1/CE1 interface.

    loopback { local | payload | remote }

Follow-up Procedure

Perform either of the following operations depending on a configured loopback detection mode:

  • If the loopback detection mode is set to local for the E1/CE1 interface, run the display interface serial interface-number command on the local device to check whether the physical status (current state) of its serial interface is UP.

    If current state is UP, the local device can send and receive packets normally. Otherwise, the local device fails to send and receive packets.

  • If the loopback detection mode is set to remote for the E1/CE1 interface, run the display interface serial interface-number command on the remote device to check whether the physical status (current state) of its serial interface is UP.

    If current state is UP, the link between the devices is working normally. Otherwise, the link between the devices fails.
