Log Format

When outputting logs, a device encapsulates log information in different formats, which apply to different log types. Logs can be encapsulated in the following formats.

Binary Format

The binary format is a common format of log encapsulation, and is usually used for transmission over the network. Encapsulation in binary format has a limited impact on the device performance, but the transmission efficiency is high. This encapsulation format is applicable to logs that are large in quantity, for example, session logs.

From this data, you cannot obtain the specific log information. Therefore, a log server that supports this format is required to parse the log information.

Syslog Format

Logs are encapsulated as text in syslog format that complies with the universal syslog format standards.
