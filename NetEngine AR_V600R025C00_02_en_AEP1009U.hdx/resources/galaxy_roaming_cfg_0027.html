Configuring Fast Roaming Using PMK Caching

Prerequisites

Before configuring fast roaming using PMK caching, complete the following task:

  • Configure intra-WAC roaming.

Context

After the basic services are configured, STAs can perform fast roaming using PMK caching only when the STAs support this roaming mode and the security policy configured on the AP is one of the following:

  • WPA2-802.1X
  • WPA2-WPA3-802.1X
  • WPA3-802.1X-AES
  • WPA3-802.1X-gcmp256
  • WPA-WPA2-802.1X (WPA2 specified on the 802.1X client)

The following describes how to configure enhanced fast roaming using PMK caching as required to shorten the roaming latency for 802.1X STAs and improve user experience. However, there is a possibility that roaming fails in certain scenarios. In this case, you are advised to disable this function.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an SSID profile and enter its view.

    ssid-profile name profile-name

    By default, the SSID profile default exists on the device.

  4. Enable enhanced fast roaming using PMK caching.

    pmk-cache-roam enhancement enable

    By default, enhanced fast roaming using PMK caching is disabled.

  5. Apply the SSID profile. For details, see Applying a Profile.

Verifying the Configuration

  • Run the display ssid-profile { all | name profile-name} command to check configuration and reference information about an SSID profile.
  • Run the display references ssid-profile name profile-name command to check reference information about an SSID profile.
