Applying an SPR Policy to a VPN Instance

Prerequisites

A VPN instance has been configured on the CPE at a site.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the SPR configuration view.

    smart-policy-route

  3. (Optional) Configure the site list to which a policy is applied.
    1. Enter the site list view.

      site-list site-list-name

    2. Bind a peer site to the site list.

      peer-site site-id

    3. Exit the site list view.

      quit

  4. Enter the policy profile view.

    spr-policy node node-index

  5. Apply the policy profile to a specified VPN instance.

    apply-to vpn-instance vpn-instance-name

  6. (Optional) Apply the policy profile to a specified site list.

    apply-to site-list site-list-name

    By default, a policy profile is not applied to a specified site list.
