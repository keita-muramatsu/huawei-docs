Local Security Policy

A security policy can control not only the traffic passing through a device but also the local traffic on the device. Local traffic refers to the traffic destined for or sent from a device.

In many applications where the device needs to send and receive packets, set the Permit action in the security policies for local traffic. The application scenarios include:
  • The device requires management, such as management through Telnet login and SNMP NMS access.
  • The device serves as a client to initiate requests or as a server to process requests from clients in the FTP, NTP, DNS, upgrade service, or email sending scenario.

The device is located in the Local zone, which is the key point for configuring security policies to control local traffic.
