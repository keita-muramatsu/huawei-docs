Understanding BFD with Automatically Negotiated Discriminators

A BFD session can be set up on an IP link for quick fault detection. You must configure a BFD session with automatically negotiated discriminators on the local device to communicate with the peer device and allow BFD to detect static routes, in BFD for static routes scenarios where a dynamic BFD session is set up on the peer device that does not support static BFD sessions. BFD with automatically negotiated discriminators supports the following types of sessions:

  • BFD session for IPv4 with automatically negotiated discriminators: detects link connectivity between Layer 3 interfaces with IP addresses on an IPv4 link.

  • BFD session for IPv6 with automatically negotiated discriminators: detects link connectivity between Layer 3 interfaces with IP addresses on an IPv6 link.
  • Multicast BFD session with automatically negotiated discriminators: detects link connectivity between interfaces without Layer 3 attributes (for example, without IP addresses).
