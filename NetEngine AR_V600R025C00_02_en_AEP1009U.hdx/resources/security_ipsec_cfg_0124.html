Diagnosing IPsec Negotiation Failures

Table 3 Diagnosing IPsec negotiation failures

Operation

Command

Diagnose IPsec negotiation failures through the IP protocol based on the source and destination IP addresses and source and destination ports of IPsec data flows.

diagnose ipsec data-flow ip source-ip source-ip destination-ip destination-ip [ vpn-instance vpn-instance-name ] [ timeout timeout ]

Diagnose IPsec negotiation failures through the TCP or UDP protocol based on the source and destination IP addresses and source and destination ports of IPsec data flows.

diagnose ipsec data-flow { tcp | udp } source-ip source-ip destination-ip destination-ip [ source-port source-port ] [ destination-port destination-port ] [ vpn-instance vpn-instance-name ] [ timeout timeout ]

Diagnose IPsec negotiation failures based on the specified remote IP address.

diagnose ipsec peer [ vpn-instance vpn-instance-name ] [ remote-ip ] [ timeout timeout ]

Diagnose IPsec negotiation failures based on interfaces.

diagnose ipsec interface interface-type interface-number [ timeout timeout ]

Displaying IPsec Statistics

Table 4 Displaying IPsec statistics

Operation

Command

Check IKE running statistics.

display ike statistics { v1 | v2 } [ slot slot-id cpu cpu-id ]

Check statistics of an IKE process queue.

display ike message-queue [ slot slot-id cpu cpu-id ]

Check statistics about IPsec tunnel established through IKEv2 negotiation.

display ikev2 statistics { error | notify-info | packet | sa | modecfg } [ slot slot-id cpu cpu-id ]

Check IPsec packet statistics.

display ipsec statistics [ policy-name policy-name [ seq-number ] | profile-name profile-name ] [ slot slot-id cpu cpu-id ]

NOTE:

Before checking IPsec packet statistics based on an IPsec policy or IPsec profile, run the ipsec policy-statistics enable command to enable the traffic statistics collection function based on IPsec policies.

Displays IPsec tunnel statistics.

display ipsec statistics

Check IPsec tunnel statistics.

display ipsec statistics tunnel-number

Check IPsec route injection statistics.

display ipsec statistics route [ slot slot-id cpu cpu-id ]

Check statistics about messages exchanged between the IPsec module and DNS module.

display ipsec statistics dns [ slot slot-id cpu cpu-id ]

Check statistics about the release and subscription events between the IPsec module and NHRP module.

display ipsec statistics service

Check backup statistics about sent or received IPsec packets.

display ipsec backup statistics { send | receive } [ slot slot-id cpu cpu-id ]

Check last IPsec backup statistics.

display ipsec backup statistics last { send | receive } [ slot slot-id cpu cpu-id ]

Clearing IPsec Statistics

IPsec statistics cannot be restored after being cleared. Exercise caution when performing this operation.

Table 5 Clearing IPsec statistics

Operation

Command

Delete established IKE SAs.

reset ike sa [ conn-id conn-id | remote ip-address ] [ slot slot-id cpu cpu-id ]

Delete established IPsec SAs.

reset ipsec sa [ remote ip-address | policy policy-name [ sequence-number ] | profile profile-name | parameters ip-address { ah | esp } spi | slot slot-id cpu cpu-id ]

Delete IKE running statistics.

reset ike statistics [ slot slot-id cpu cpu-id ]

Delete IPsec packet statistics in the current system.

reset ipsec statistics [ policy policy-name [ sequence-number ] | profile-name profile-name ] [ slot slot-id cpu cpu-id ]

Delete IPsec packet statistics in all systems.

reset ipsec statistics

Delete statistics about the release and subscription events between the IPsec module and NHRP module.

reset ipsec statistics service

Delete backup statistics about sent or received IPsec packets.

reset ipsec backup statistics { send | receive } [ slot slot-id cpu cpu-id ]

Delete last IPsec backup statistics.

reset ipsec backup statistics last { send | receive } [ slot slot-id cpu cpu-id ]

Delete information about IKE negotiation failures.

reset ike error-info [ slot slot-id cpu cpu-id ]

Delete information about the IPsec tunnel established through IKE negotiation.

reset ike offline-info [ slot slot-id cpu cpu-id ]

Delete history information about IPsec tunnels.

reset ipsec history record [ slot slot-id cpu cpu-id ]

Delete IPsec route injection statistics.

reset ipsec statistics route [ slot slot-id cpu cpu-id ]
