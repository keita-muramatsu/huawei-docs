Modifying the AP Group to Which an AP Belongs

Prerequisites

The new AP group for an AP to join has been created using the ap-group name group-name command.

Context

Each AP must be added to an AP group. If no AP group is configured for an AP (using the ap-group ap-group command in the AP view), the AP automatically joins the AP group default.

You can modify the AP group for APs in the following situations:
  • The current AP group is not applicable to an AP or the AP is added to an incorrect AP group.
  • A large number of APs with the same configuration need to be added to an AP group. In this case, you can bring the APs online and then run the ap-regroup command to change the AP group for the APs in batches.

Changing the AP group for an AP will restart the AP and interrupt services. Exercise caution when you perform the operation.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Add the AP to the new AP group.

    ap-regroup ap-id ap-id new-group new-group

    When multiple APs are specified through the parameter ap-id, use commas (,) to separate AP IDs or use hyphens (-) to indicate continuous AP IDs. For example, the value 5,8,10-13,20 indicates the list of APs with IDs 5, 8, 10, 11, 12, 13, and 20.

Verifying the Configuration

  • Run the display ap config-info ap-id ap-id command to check the AP configuration.
  • Run the display ap { all | ap-group ap-group | by-mac mac-address | by-sn sn | [ ap-group ap-group ] by-ssid ssid | by-state state [ ap-group ap-group ] } command to check the AP onboarding result.
