Configuring a Radio Profile

Context

Basic radio parameters, such as the channel and transmit power, are configured in the AP group radio view or AP radio view, and other radio parameters are configured in the radio profile view.

  • Configuring radio profiles: Radio profiles are classified as 2.4 GHz or 5 GHz radio profiles, which take effect on 2.4 GHz and 5 GHz/6 GHz radios, respectively. The differences between 2.4 GHz and 5 GHz radio profiles are as follows:
    • A 2.4 GHz radio profile allows for the parameter settings only for 2.4 GHz radios, and a 5 GHz radio profile allows for the parameter settings only for 5 GHz and 6 GHz radios.
    • The 2.4 GHz radios support the 802.11b/g/n/ax/be mode, and 5 GHz and 6 GHz radios support the 802.11a/n/ac/ax/be mode.

    By default, the 2.4 GHz and 5 GHz radio profiles both named default exist on the device, which are bound to all AP groups. Using the default radio profiles can simplify the operation procedure. However, in practice, you are advised to create different radio profiles and set parameters in the profiles to meet different service requirements.

  • Configuring the radio rate: The actual data transmission rate of STAs on a WLAN is closely related to the radio rate.
    • The basic rate set includes all rates supported by both the AP and STA. A STA can associate with an AP only when the AP and STA support all rates in the basic rate set.
    • The supported rate set includes rates specifically supported by the AP and those in the basic rate set, allowing the AP and STAs to transmit data at more rates.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Configure an RRM profile.
    1. Create an RRM profile and enter its view.

      rrm-profile name profile-name

      By default, the RRM profile default exists in the system.

    2. Enable dynamic EDCA parameter adjustment.

      dynamic-edca enable

      By default, dynamic EDCA parameter adjustment is enabled.

    3. Enable the spatial reuse (SR) function.

      spatial-reuse enable

      By default, the SR function is disabled.

    4. Enable the BSS coloring function.

      bss-color enable

      By default, the BSS coloring function is disabled.

    5. Configure the AP antenna mode.

      antenna-mode { direction | omnidirection | auto }

      This function takes effect only on APs that support Dynamic-Zoom smart antennas.

    6. Configure the interval and traffic threshold for checking the retransmission rate.

      calibrate retransmission-rate-check interval inter-val traffic-threshold traffic-threshold-val

      By default, the interval for checking the retransmission rate detection is 1 minute, and the traffic threshold is 1250 kbit/s.

    7. Enable the user CAC function.

      Enable CAC based on the number of users.

      uac client-number enable

      Enable CAC based on the terminal SNR.

      uac client-snr enable

      By default, the user CAC function is disabled.

    8. Return to the WLAN view.

      quit

  4. Create a radio profile and enter its view.

    • Create a 2.4 GHz radio profile and enter its view.
      radio-2g-profile name profile-name

      By default, the 2.4 GHz radio profile default exists in the system.

    • Create a 5 GHz radio profile and enter its view.
      radio-5g-profile name profile-name

      By default, the 5 GHz radio profile default exists in the system.

  5. Bind the RRM profile.

    rrm-profile profile-name

    By default, the RRM profile default is bound to a radio profile.

  6. (Optional) Configure the radio type.

    • 2.4 GHz radio profile:
      radio-type { dot11b | dot11g | dot11n | dot11ax | dot11be }

      By default, the radio type in a 2.4 GHz radio profile is dot11be.

    • 5 GHz radio profile:
      radio-type { dot11a | dot11n | dot11ac | dot11ax | dot11be }

      By default, the radio type in a 5 GHz radio profile is dot11be.

  7. (Optional) Configure basic protocol parameters.

    • Configure the aggregate MAC protocol data unit (A-MPDU) function.
      undo a-mpdu disable

      By default, the A-MPDU function is enabled.

    • Configure the function of sending 802.11 frames in A-MSDU mode.
      a-msdu enable

      By default, the function of sending 802.11 frames in A-MSDU mode is in self-adaptive state.

    • (Only for 5 GHz radio profiles) Configure the maximum number of subframes that can be aggregated into an A-MSDU at one time.
      vht a-msdu max-frame-num max-frame-number

      By default, a maximum of two subframes can be aggregated into an A-MSDU at one time.

  8. Configure the clear channel assessment (CCA) threshold is configured for APs.

    cca-threshold cca-threshold

    By default, no CCA threshold is specified, and APs use the default CCA threshold of the chip.

  9. (Optional) Configure the radio rate.

    Perform this step only when 802.11a, 802.11b, or 802.11g STAs exist on the network.

    • Configure an 802.11a basic rate set in the 5 GHz radio profile.
      dot11a basic-rate { { 6 | 9 | 12 | 18 | 24 | 36 | 48 | 54 } * | all }

      By default, the 802.11a basic rate set in a 5 GHz radio profile includes rates 6 Mbit/s, 12 Mbit/s, and 24 Mbit/s.

    • Configure an 802.11b/g basic rate set in the 2.4 GHz radio profile.
      dot11bg basic-rate { { 1 | 2 | 5 | 6 | 9 | 11 | 12 | 18 | 24 | 36 | 48 | 54 } * | all }

      By default, the 802.11b/g basic rate set in a 2.4 GHz radio profile includes rates 1 Mbit/s and 2 Mbit/s.

    • Configure an 802.11a supported rate set in the 5 GHz radio profile.
      dot11a supported-rate { { 6 | 9 | 12 | 18 | 24 | 36 | 48 | 54 } * | all }

      By default, the 802.11a supported rate set in a 5 GHz radio profile includes rates 6 Mbit/s, 9 Mbit/s, 12 Mbit/s, 18 Mbit/s, 24 Mbit/s, 36 Mbit/s, 48 Mbit/s, and 54 Mbit/s.

    • Configure an 802.11b/g supported rate set in the 2.4 GHz radio profile.
      dot11bg supported-rate { { 1 | 2 | 5 | 6 | 9 | 11 | 12 | 18 | 24 | 36 | 48 | 54 } * | all }

      By default, the 802.11b/g supported rate set in a 2.4 GHz radio profile includes rates 1 Mbit/s, 2 Mbit/s, 5.5 Mbit/s, 6 Mbit/s, 9 Mbit/s, 11 Mbit/s, 12 Mbit/s, 18 Mbit/s, 24 Mbit/s, 36 Mbit/s, 48 Mbit/s, and 54 Mbit/s.

  10. Configure the guard interval (GI) mode.

    For 802.11n or 802.11ac STAs:

    guard-interval-mode { short | normal }

    For 802.11ax/be STAs:

    guard-interval-mode dot11ax { dot8 | 1dot6 | 3dot2 }

    By default, the GI mode in 802.11n/ac is short, and that in 802.11ax/be is dot8 (0.8 us).

  11. (Optional) Configure the request to send-clear to send (RTS-CTS) operation mode.

    • Configure the RTS-CTS operation mode.

      2.4 GHz radio profile:

      rts-cts-mode { cts-to-self | disable | rts-cts }

      By default, the RTS-CTS operation mode is rts-cts in a 2.4 GHz radio profile.

      5 GHz radio profile:

      rts-cts-mode { disable | rts-cts }

      By default, the RTS-CTS operation mode is rts-cts in a 5 GHz radio profile.

    • Set the RTS-CTS threshold
      rts-cts-threshold rts-cts-threshold

      The default RTS-CTS alarm threshold is 1400 bytes.

  12. (Optional) Set the interval for sending Beacon frames.

    beacon-interval beacon-interval [ dyn-range ]

    By default, an AP sends Beacon frames at an interval of 100 TUs, and dynamic small-range adjustment of the Beacon interval is disabled on the AP.

  13. (Optional) Configure radios to send packets at the maximum power.

    utmost-power enable

    By default, a radio sends packets in adaptive mode.

  14. (Optional) Enable the scheduled VAP auto-off function, and set the time range during which the VAP is disabled.

    auto-off service time-range time-range-name

    By default, the scheduled VAP auto-off function is disabled.

  15. (Optional) Enable the L-SIG field length compatibility function of the 802.11n protocol.

    dot11n legacy-signal-length-compatible enable

    By default, the L-SIG field length compatibility function of the 802.11n protocol is disabled.

    On a Wi-Fi network, if 802.11n STAs encounter severe packet loss, the possible cause is that the length of the L-SIG field sent by the STAs does not comply with the 802.11n standard. In this case, you can run this command to enable the L-SIG field length compatibility function of the 802.11n protocol.
