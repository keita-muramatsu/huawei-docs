Verifying the HQoS Configuration

Procedure

  • Run the display traffic classifier [ classifier-name ] command to check the traffic classifier configuration.
  • Run the display traffic behavior [ behavior-name ] command to check the traffic behavior configuration.
  • Run the display traffic policy [ policy-name [ classifier classifier-name ] ] command to check the parent and child traffic policy configuration or CBQ traffic policy configuration.
  • Run the display traffic-policy applied-record [ policy-name ] command to check the application records of a specified traffic policy.
  • Run the display traffic-policy applied-record connection [ connection-id ] command to check the application record of a connection-based traffic policy.

    This command is supported only by the AR8000 series and AR6700-H series.
