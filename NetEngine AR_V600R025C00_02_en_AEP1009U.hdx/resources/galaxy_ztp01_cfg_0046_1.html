Preparing the Intermediate File and Deployment Configuration File

Context

Before performing streamlined USB-based deployment, you need to configure ZTP deployment parameters on iMaster NCE-Campus, which then generates the intermediate file and deployment configuration file based on site configurations.

Procedure

  1. Log in to iMaster NCE-Campus and set parameters for streamlined USB-based deployment. The controller automatically generates the intermediate file USB_AR_V600.INI and deployment configuration file ZTP_V600.INI. For details about fields in the files, see Understanding an Intermediate File and Understanding the Deployment Configuration File. For details, see "Configuring USB-based Deployment" in the SD-WAN Solution & iMaster NCE-Campus Product Documentation.

    To perform streamlined USB-based batch deployment, you need to configure the device ESNs when adding devices.

  2. Save the intermediate file USB_AR_V600.INI and deployment configuration file ZTP_V600.INI to the root directory of the USB flash drive.
