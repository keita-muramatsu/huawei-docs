Example for Configuring BGP4+ 6PE

Networking Requirements

On the network shown in Figure 1, the link between CE1 and PE1 and the link between PE2 and CE2 are IPv6 links, and the link between PE1 and PE2 is an IPv4 link. BGP4+ runs between CE1 and PE1 and between PE2 and CE2. MPLS runs between PE1 and PE2. It is required that 6PE be configured to implement interworking between IPv6 networks.

Figure 1 Network diagram for configuring BGP4+ 6PE

In this example, interface1, interface2, and interface3 represent VLANIF 100, VLANIF 200, and VLANIF 300, respectively.


Precautions

Note the following during the configuration:

  • To improve security, you are advised to deploy BGP4+ security measures. For details, see "Configuring BGP4+ Authentication." Keychain authentication is used as an example. For details, see Example for Configuring Keychain Authentication for BGP4+.

Configuration Roadmap

The configuration roadmap is as follows:

  1. Configure OSPF between PE1 and PE2 to ensure that they can learn the loopback interface addresses from each other.

  2. Configure BGP4+ between CE1 and PE1 and between PE2 and CE2.

  3. Configure MPLS between PE1 and PE2 to set up LSPs.

  4. Configure 6PE between PE1 and PE2 to implement interworking between IPv6 networks.

Procedure

  1. Assign IP addresses to interfaces. The configuration of PE1 is used as an example. The configurations of other devices are similar to the configuration of PE1.

    # Configure PE1.

    <HUAWEI> system-view
[HUAWEI] sysname PE1
[PE1] vlan batch 100 200
[PE1] interface vlanif 100
[PE1-Vlanif100] ipv6 enable
[PE1-Vlanif100] ipv6 address 2001:db8:1::2 64
[PE1-Vlanif100] quit
[PE1] interface vlanif 200
[PE1-Vlanif200] ip address 10.0.0.1 30   
[PE1-Vlanif200] quit
[PE1] interface 10ge 0/0/1
[PE1-10GE0/0/1] port link-type access
[PE1-10GE0/0/1] port default vlan 100
[PE1-10GE0/0/1] quit
[PE1] interface 10ge 0/0/2
[PE1-10GE0/0/2] port link-type access
[PE1-10GE0/0/2] port default vlan 200
[PE1-10GE0/0/2] quit
[PE1] interface loopback0
[PE1-loopback0] ip address 10.2.2.2 32
[PE1-loopback0] quit

  2. Configure OSPF between PE1 and PE2 so that they can learn routes from each other.

    # Configure PE1.

    [PE1] ospf 1
[PE1-ospf-1] area 0
[PE1-ospf-1-area-0.0.0.0] network 10.2.2.2 0.0.0.0
[PE1-ospf-1-area-0.0.0.0] network 10.0.0.0 0.0.0.3
[PE1-ospf-1-area-0.0.0.0] quit
[PE1-ospf-1] quit

    # Configure PE2.

    [PE2] ospf 1
[PE2-ospf-1] area 0
[PE2-ospf-1-area-0.0.0.0] network 10.3.3.3 0.0.0.0
[PE2-ospf-1-area-0.0.0.0] network 10.0.0.0 0.0.0.3
[PE2-ospf-1-area-0.0.0.0] quit
[PE2-ospf-1] quit

  3. Configure BGP4+.

    # Configure CE1.

    [CE1] bgp 100
[CE1-bgp] router-id 1.1.1.1
[CE1-bgp] peer 2001:db8:1::2 as-number 200
[CE1-bgp] ipv6-family unicast
[CE1-bgp-af-ipv6] peer 2001:db8:1::2 enable
[CE1-bgp-af-ipv6] network 2001:db8:5::5 64
[CE1-bgp-af-ipv6] quit
[CE1-bgp] quit

    # Configure PE1.

    [PE1] bgp 200
[PE1-bgp] router-id 2.2.2.2
[PE1-bgp] peer 2001:db8:1::1 as-number 100
[PE1-bgp] ipv6-family unicast
[PE1-bgp-af-ipv6] peer 2001:db8:1::1 enable
[PE1-bgp] quit

    # Configure PE2.

    [PE2] bgp 200
[PE2-bgp] router-id 3.3.3.3
[PE2-bgp] peer 2001:db8:2::1 as-number 300
[PE2-bgp] ipv6-family unicast
[PE2-bgp-af-ipv6] peer 2001:db8:2::1 enable
[PE2-bgp] quit

    # Configure CE2.

    [CE2] bgp 300
[CE2-bgp] router-id 4.4.4.4
[CE2-bgp] peer 2001:db8:2::2 as-number 200
[CE2-bgp] ipv6-family unicast
[CE2-bgp-af-ipv6] peer 2001:db8:2::2 enable
[CE2-bgp-af-ipv6] network 2001:db8:6::6 64
[CE2-bgp-af-ipv6] quit
[CE2-bgp] quit

    # Check whether the peer relationship is established on PE1 and PE2.

    [PE1] display bgp ipv6 peer

 BGP local router ID : 10.2.2.2
 Local AS number : 200
 Total number of peers : 1                 Peers in established state : 1

  Peer                      V    AS  MsgRcvd  MsgSent  OutQ  Up/Down          State PrefRcv

  2001:DB8:1::1             4   100       32       35     0 00:27:20   Established       1
    [PE2] display bgp ipv6 peer

 BGP local router ID : 10.3.3.3
 Local AS number : 200
 Total number of peers : 1                 Peers in established state : 1

  Peer                      V    AS  MsgRcvd  MsgSent  OutQ  Up/Down          State PrefRcv
  2001:DB8:2::1             4    300      31       37     0 00:28:08   Established       1

  4. Configure MPLS between PE1 and PE2 to set up LSPs.

    # Configure PE1.

    [PE1] mpls lsr-id 10.2.2.2
[PE1] mpls
[PE1-mpls] lsp-trigger all
[PE1-mpls] quit
[PE1] mpls ldp
[PE1-mpls-ldp] quit
[PE1] interface vlanif 200
[PE1-Vlanif200] mpls
[PE1-Vlanif200] mpls ldp
[PE1-Vlanif200] quit

    # Configure PE2.

    [PE2] mpls lsr-id 10.3.3.3
[PE2] mpls
[PE2-mpls] lsp-trigger all
[PE2-mpls] quit
[PE2] mpls ldp
[PE2-mpls-ldp] quit
[PE2] interface vlanif 200
[PE2-Vlanif200] mpls
[PE2-Vlanif200] mpls ldp
[PE2-Vlanif200] quit

    # Take PE1 as an example. The command output shows that LSPs have been established.

    [PE1] display mpls lsp

  5. Configure 6PE.

    # Configure PE1.

    [PE1] bgp 200
[PE1-bgp] peer 10.3.3.3 as-number 200
[PE1-bgp] peer 10.3.3.3 connect-interface LoopBack0
[PE1-bgp] ipv6-family unicast
[PE1-bgp-af-ipv6] peer 10.3.3.3 enable
[PE1-bgp-af-ipv6] peer 10.3.3.3 label-route-capability
[PE1-bgp-af-ipv6] import-route direct
[PE1-bgp-af-ipv6] quit
[PE1-bgp] quit

    # Configure PE2.

    [PE2] bgp 200
[PE2-bgp] peer 10.2.2.2 as-number 200
[PE2-bgp] peer 10.2.2.2 connect-interface LoopBack0
[PE2-bgp] ipv6-family unicast
[PE2-bgp-af-ipv6] peer 10.2.2.2 enable
[PE2-bgp-af-ipv6] peer 10.2.2.2 label-route-capability
[PE2-bgp-af-ipv6] import-route direct
[PE2-bgp-af-ipv6] quit
[PE2-bgp] quit

    # Check the connection status of 6PE peers.

    [PE1] display bgp ipv6 peer

 BGP local router ID : 10.2.2.2
 Local AS number : 200
 Total number of peers : 2                 Peers in established state : 2

  Peer            V     AS  MsgRcvd  MsgSent   OutQ  Up/Down        State PrefRcv

  10.3.3.3        4    200     1248     1342      0 18:06:28 Established       1
  2001:DB8:1::1   4    100       32       35      0 00:27:20 Established       1

    The command output shows that a BGP4+ 6PE connection has been established between PE1 and PE2.

Configuration Scripts

  • CE1

    #
sysname CE1
#
vlan batch 100
#
interface Vlanif100
 ipv6 enable
 ipv6 address 2001:DB8:1::1/64
#
interface 10GE0/0/1
 port default vlan 100
#
interface LoopBack0
 ip address 10.1.1.1 255.255.255.255
#
interface LoopBack1
 ipv6 enable
 ipv6 address 2001:DB8:5::5/64
#
bgp 100
 private-4-byte-as enable
 router-id 10.1.1.1
 peer 2001:DB8:1::2 as-number 200
 #
 ipv4-family unicast
 #
 ipv6-family unicast
  network 2001:DB8:5:: 64
  peer 2001:DB8:1::2 enable
#
return

  • PE1

    #
sysname PE1
#
vlan batch 100 200
#
mpls lsr-id 10.2.2.2
mpls
  lsp-trigger all
#
mpls ldp
#
interface Vlanif100
 ipv6 enable
 ipv6 address 2001:DB8:1::2/64
#
interface Vlanif200
 ip address 10.0.0.1 255.255.255.252
 mpls
 mpls ldp
#
interface 10GE0/0/1
 port default vlan 100
#
interface 10GE0/0/2
 port default vlan 200 
#
interface LoopBack0
 ip address 10.2.2.2 255.255.255.255
#
bgp 200
 private-4-byte-as enable
 router-id 10.2.2.2
 peer 10.3.3.3 as-number 200
 peer 10.3.3.3 connect-interface LoopBack0
 peer 2001:DB8:1::1 as-number 100
 #
 ipv4-family unicast
  peer 10.3.3.3 enable
 #
 ipv6-family unicast
  import-route direct
  peer 10.3.3.3 enable
  peer 10.3.3.3 label-route-capability
  peer 2001:DB8:1::1 enable
#
ospf 1
 area 0.0.0.0
  network 10.2.2.2 0.0.0.0
  network 10.0.0.0 0.0.0.3
#
return
