Configuring a STUN Server

Procedure

  1. Enter the system view.

    system-view

  2. Enter the STUN server view.

    stun server

  3. Configure an IP address to be checked by the STUN server for STUN messages.

    stun server listening-ip ip-address [ vpn-instance vpn-instance-name ]

    The device can function properly as the STUN server only after it is configured with a checked IP address and enabled with the STUN server function. The configured checked IP address must be a local IP address and a maximum of 30 checked IP addresses can be configured. After a checked IP address is configured, the STUN server checks and responds to the STUN messages received by the port at this IP address.

  4. (Optional) Configure the port number to be checked by the STUN server.

    stun server listening-port port-number

    The default port number checked by the STUN server is 3478. If the STUN service is unavailable because the port number checked by the STUN server has been used by another service, run this command to change the checked port number.

  5. (Optional) Configure an authentication username and a password for the STUN server.

    authentication-mode hmac-sha256 username username cipher password

    Currently, only HMAC-SHA256 authentication is supported. The STUN client and server must be configured with the same authentication username and password.

  6. Enable the STUN server function.

    stun server enable

    With this function enabled, the device acts as the STUN server. It will receive binding requests from STUN clients and respond to them, helping them determine the presence of NAT devices.

Verifying the Configuration

  • Run the display stun server configuration command to check the STUN server configuration.
