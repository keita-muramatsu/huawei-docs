MAC Security

Overview

MAC address flapping occurs on a network when the network encounters a routing loop or is attacked. To prevent MAC address flapping, use either of the following methods:

  • Increase the MAC address learning priority of an interface. If the same MAC address is learned by interfaces of different priorities, the MAC address entry learned by the interface with the highest priority overrides those learned by other interfaces.

  • Prohibit MAC address entry overriding between interfaces with the same priority. If the interface on an unauthorized network device has the same priority as the interface on an authorized network device, the MAC address entry of the unauthorized network device that is later learned by the device does not override the previously learned correct one. If the authorized network device is powered off, the device learns the MAC address of the unauthorized network device. After the authorized network device is powered on, its MAC address cannot be learned.

You can configure MAC address flapping avoidance to ensure that MAC addresses are learned by correct interfaces, preventing access from unauthorized devices.

For example, if 10GE 0/0/1 is a network-side interface and 10GE 0/0/2 is a user-side interface, you can set the MAC address learning priority of 10GE 0/0/1 to 3, which is higher than the default MAC address learning priority (0) of 10GE 0/0/2.

Impact on the System

None

Procedure

  1. Enter the system view.

    system-view

  2. Prevent MAC address entries from being overridden on interfaces with the same priority.

    undo mac-address learning priority priority-id allow-flapping

  3. Enter the interface view.

    interface interface-type interface-number

  4. Configures a MAC address learning priority for the interface.

    mac-address learning priority priority-id

Checking the Security Hardening Result

Run the display mac-address flapping active-table command to view active MAC address flapping records and run the display mac-address flapping aged-table command to view aged MAC address flapping records.
