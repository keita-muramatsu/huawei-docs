Enabling NETCONF Operation Log Query

Context

To query NETCONF operation logs, you need to enable NETCONF operation log query. Only NETCONF request packets and query failure response packets are recorded in operation logs.

Procedure

  1. Enter the system view.

    system-view

  2. Enable NETCONF.

    snetconf server enable

  3. Enter the NETCONF user interface view.

    netconf

  4. Enable NETCONF operation log query.

    rpc-message log protocol-operation get
