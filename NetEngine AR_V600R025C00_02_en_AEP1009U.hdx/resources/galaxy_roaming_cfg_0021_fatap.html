Configuring 802.11r Fast Roaming

Prerequisites

Before configuring 802.11r fast roaming, complete the following task:

  • Configure intra-WAC roaming.

Context

During STA roaming, authentication or key negotiation needs to be performed again, which interrupts services for a short period of time. You can configure 802.11r to reduce the number of information exchanges during roaming, thereby reducing latency.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an SSID profile and enter its view.

    ssid-profile name profile-name

    By default, the SSID profile default exists on the device.

  4. Enable the 802.11r function.

    dot11r enable [ over-the-ds ]

    By default, the 802.11r function is disabled.

  5. Apply the SSID profile. For details, see Applying a Profile.

Verifying the Configuration

  • Run the display ssid-profile { all | name profile-name } command to check the configuration and reference information about an SSID profile.
  • Run the display references ssid-profile name profile-name command to check reference information about an SSID profile.
