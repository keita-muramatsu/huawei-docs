Configuring a Global Unicast Address with a DHCPv6 PD Prefix for an Interface

Context

On a hierarchical network, IPv6 addresses are generally configured manually, which has poor extensibility and is not beneficial for uniform IPv6 address planning and management.

DHCPv6 prefix delegation (PD) is a prefix allocation mechanism. It allows a downstream device to request IPv6 address prefixes from the upstream device and an upstream device to allocate appropriate prefixes to the downstream device. In this way, you do not need to configure IPv6 address prefixes for user-side links on the downstream device. The downstream device divides the obtained prefix (which is typically less than 64 bits long) into subnet segments with 64-bit prefixes and sends an RA message on the link that IPv6 hosts directly connect to. This enables IPv6 hosts to automatically configure IPv6 addresses, implementing hierarchical address deployment.

Procedure

  1. Enter the system view.

    system-view

  2. Create a VLAN.

    vlan vlan-id

  3. Exit the VLAN view.

    quit

  4. Enter the VLANIF interface view.

    interface vlanif vlan-id

  5. Enable IPv6.

    ipv6 enable

  6. Configure a global unicast address with a DHCPv6 PD prefix for the interface.

    ipv6 address dhcpv6-prefix { ipv6-address prefix-length | ipv6-address/prefix-length }
    • A maximum of 16 global unicast addresses can be configured for each interface.
    • If the ipv6 address dhcpv6-prefix1 2001:db8:1::1/64 and ipv6 address dhcpv6-prefix1 2001:db8:1::2/64 commands are configured on interfaces A and B respectively, the network prefixes of interfaces A and B are the same. As a result, the configuration is successful but takes effect only on one interface. If the preceding case occurs, check whether any address conflict exists.
    • After this command is run on an interface, the IPv6 address is not immediately added to the interface. The device uses the obtained prefix and configured address to generate a new prefix address only after the DHCPv6 PD client function is enabled and the prefix is obtained. If the DHCPv6 PD client function is enabled but no prefix is obtained, the configuration does not take effect. In this case, no address is available on the interface.
