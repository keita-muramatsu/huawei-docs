Starting Registration Query Center-based Deployment

Prerequisites

  • To implement ZTP through the registration query center, you need to connect iMaster NCE-Campus to the registration query center.

    For details about how to configure iMaster NCE-Campus, see SD-WAN Solution & iMaster NCE-Campus Product Documentation.

  • To ensure successful deployment, ensure that the device uses factory settings, has no console port input, and has no user login. Otherwise, the deployment will fail. Run the following commands to clear the configuration file for next startup, and then restart the device to restore the factory configurations. If you cannot log in to a device, press and hold the RST button for at least 5 seconds to restore the factory settings.
    1. Clear and cancel the configuration file specified for the next startup to restore the default configurations.
      reset saved-configuration
    2. Restart the device and clear the service configurations and data files to restore the factory configurations.
      reset factory-configuration

Context

An unconfigured device has never started ZTP before. In its factory configurations, the ZTP function is enabled by default. To start ZTP, you only need to power on the device.

Procedure

  1. Power on the device.
  2. Enable the ZTP function on the device.

    set ztp enable

    By default, the ZTP function is enabled on a device. After an unconfigured device is powered on and starts, the ZTP process is automatically executed, and you do not need to perform this step.

    To disable an unconfigured device from running the ZTP process upon startup, run the set ztp disable command on the device.

  3. (Optional) Restart the unconfigured device.

    reboot fast
