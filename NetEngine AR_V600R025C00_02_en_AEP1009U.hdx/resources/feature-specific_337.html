Configuration Roadmap

  1. Configure IP addresses and a unicast routing protocol for interfaces on each device. Configure OSPF on DeviceA and DeviceB, and set the OSPF process ID and area ID to 1 and 0.0.0.0, respectively.

  2. Create a GRE tunnel between DeviceA and DeviceB so that data is transmitted between them through the GRE tunnel.

  3. Enable the multicast function on all devices that provide multicast services.

  4. Enable PIM-SM on the interface connecting DeviceA to the multicast source, the interface connecting DeviceB to the user network, and all GRE tunnel interfaces.

Procedure

  1. Assign IP addresses to device interfaces and configure a unicast routing protocol. For detailed configurations, see Configuration Scripts.
  2. Configure a tunnel interface.

    # Configure a tunnel interface on DeviceA.

    [DeviceA] interface tunnel 1
[DeviceA-Tunnel1] tunnel-protocol gre
[DeviceA-Tunnel1] ip address 10.1.2.1 255.255.255.0
[DeviceA-Tunnel1] source 10.1.1.1
[DeviceA-Tunnel1] destination 10.1.1.2
[DeviceA-Tunnel1] quit

    # Configure a tunnel interface on DeviceB.

    [DeviceB] interface tunnel 1
[DeviceB-Tunnel1] tunnel-protocol gre
[DeviceB-Tunnel1] ip address 10.1.2.2 255.255.255.0
[DeviceB-Tunnel1] source 10.1.1.2
[DeviceB-Tunnel1] destination 10.1.1.1
[DeviceB-Tunnel1] quit

    After the configuration is complete, the tunnel interfaces become up and can ping each other successfully.

    [DeviceA] ping -a 10.1.2.1 10.1.2.2

  3. Configured a static route for the tunnel interface.

    # Configure DeviceA.
    [DeviceA] ip route-static 192.168.2.0 255.255.255.0 Tunnel1
    # Configure DeviceB.
    [DeviceB] ip route-static 192.168.1.0 255.255.255.0 Tunnel1

  4. Enable the multicast function on all the devices and enable PIM-SM on all the involved interfaces.

    # Configure DeviceA. The configuration on DeviceB is similar to that on DeviceA. For detailed configurations, see Configuration Scripts.
    [DeviceA] multicast routing-enable
[DeviceA] interface 10GE0/0/1
[DeviceA-10GE0/0/1] pim sm
[DeviceA-10GE0/0/1] quit
[DeviceA] interface 10GE0/0/2
[DeviceA-10GE0/0/2] pim sm
[DeviceA-10GE0/0/2] quit
[DeviceA] interface tunnel 1
[DeviceA-Tunnel1] pim sm
[DeviceA-Tunnel1] quit

  5. Configure a static RP.

    # Configure DeviceA. The configuration on DeviceB is similar to that on DeviceA. For detailed configurations, see Configuration Scripts.
    [DeviceA] pim
[DeviceA-pim] static-rp 10.1.2.1
[DeviceA-pim] quit

  6. Add the interface that is connected to the user host to a static IGMP group.

    # Add DeviceB's interface that is connected to the IGMP user to the static IGMP group 225.1.1.1.
    [DeviceB] interface 10GE0/0/2
[DeviceB-10GE0/0/2] igmp enable
[DeviceB-10GE0/0/2] igmp static-group 225.1.1.1
[DeviceB-Tunnel1] quit

Configuration Scripts

  • DeviceA

    #
sysname DeviceA 
# 
multicast routing-enable 
# 
interface 10GE0/0/1 
 ip address 10.1.1.1 255.255.255.0
 pim sm 
 # 
interface 10GE0/0/2
 ip address 192.168.1.1 255.255.255.0
 pim sm 
# 
interface Tunnel 1 
 ip address 10.1.2.1 255.255.255.0
 tunnel-protocol gre
 source 10.1.1.1
 destination 10.1.1.2
 pim sm 
# 
ospf 1 
 area 0.0.0.0
 network 10.1.2.0 0.0.0.255
 network 10.1.1.0 0.0.0.255
 network 192.168.1.0 0.0.0.255 
# 
pim 
 static-rp 10.1.2.1 
# 
ip route-static 192.168.2.0 255.255.255.0 Tunnel1 
# 
return
