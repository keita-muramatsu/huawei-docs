Maintaining HQoS

Context

Once HQoS is enabled on an interface, you can check the packet statistics of that interface. To re-collect packet statistics on an interface, clear existing statistics, and then check packet statistics again.

Statistics cannot be restored after they are cleared. Exercise caution when clearing packet statistics.

Procedure

  • Check packet statistics on an interface to which queue scheduling HQoS is applied.

    display traffic-policy statistics interface { interface-type interface-number | interface-name } [ policy-name ] outbound [ { classifier-base | rule-base } [ class classifier-name  [ son-class son-class-name ] ] ]

  • Clear packet statistics on an interface to which queue scheduling HQoS is applied.

    reset traffic-policy statistics interface { interface-type interface-number | interface-name } [ policy-name ] outbound [ classifier-base classifier-name ]

  • Check statistics on packets matching a site connection-based traffic policy.

    display traffic-policy statistics connection connection-id outbound [ classifier-base [ class classifier-name ] ]

    This command is supported only by the AR8000 series and AR6700-H series.

  • Clear statistics on packets matching a site connection-based traffic policy.

    reset traffic-policy statistics connection connection-id outbound [ classifier-base classifier-name ]

    This command is supported only by the AR8000 series and AR6700-H series.

  • Check packet statistics on an interface to which hierarchical CAR HQoS is applied.

    display traffic-policy statistics interface { interface-type interface-number | interface-name } [ policy-name ] inbound [ { classifier-base | rule-base } [ class classifier-name  [ son-class son-class-name ] ] ] decapprocess

  • Clear packet statistics on an interface to which hierarchical CAR HQoS is applied.

    reset traffic-policy statistics interface { interface-type interface-number | interface-name } [ policy-name ] inbound [ classifier-base classifier-name ] decapprocess
