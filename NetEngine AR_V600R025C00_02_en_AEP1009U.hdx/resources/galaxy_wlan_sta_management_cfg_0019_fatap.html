Verifying the Configuration

Context

After configuring basic WLAN STA access functions, you can verify the configurations.

After configuring basic WLAN STA access functions is complete, APs generate WLAN signals in their coverage areas. STAs, such as mobile phones and laptops with wireless network adapters, can associate with WLANs of the configured SSIDs. After entering the user names and passwords, users can associate with the WLANs. By checking the STA access result, you can find STAs connected to the WLAN.

Procedure

  • Run the display vap { all | ssid ssid } or display vap { ap-group ap-group-name | ap-id ap-id [ radio radio-id ] } [ ssid ssid ] command to check information about service VAPs.
  • Run the display vap-profile { all | name profile-name } command to check the configuration and application of a VAP profile.
  • Run the display vap create-fail-record { ap-mac ap-mac | all } command to check records about VAP creation failures.
  • Run the display references vap-profile name profile-name command to check reference information about a VAP profile.
  • Run the display station { ap-group ap-group-name | ap-id ap-id | ssid ssid | sta-mac sta-mac-address | vlan vlan-id | all } command to check STA access information.
