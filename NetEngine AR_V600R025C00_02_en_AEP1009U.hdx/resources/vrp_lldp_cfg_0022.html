Maintaining LLDP

To clear LLDP statistics or neighbor information, perform the following operations in the user view.

LLDP statistics cannot be restored after being cleared. Exercise caution when running the commands.

Table 1 Clearing LLDP information

Operation

Command

Clear global LLDP frame statistics or LLDP frame statistics on a specified interface.

reset lldp statistics [ interface interface-type interface-number ]

Clear neighbor information globally or on a specified interface.

clear lldp neighbor [ interface interface-type interface-number ]

Clear statistics about non-LLDP packets received by all interfaces or a specified interface.

reset lldp mdn statistics [ interface { interface-type interface-number | interface-name }]

Clear MDN neighbor information of all interfaces or a specified interface.

clear lldp mdn neighbor [ interface { interface-type interface-number | interface-name }]
