Example for Configuring Web UI Login Through HTTPS (Two-Factor Authentication)

Networking Requirements

In Figure 1, an administrator account admin123@huawei.com is configured on the RADIUS server, and the account can be used to log in to the web UI of DeviceA through HTTPS. DeviceA uses two factors ("user name + password" and verification code) to authenticate the administrator. The RADIUS server sends a dynamic code or SMS verification code to the administrator.

Figure 1 Networking diagram for web UI login through HTTPS (two-factor authentication)

In this example, Interface1 and Interface2 represent GE0/0/1 and GE0/0/2, respectively.

Configuration Roadmap

  1. Configure all interfaces to be used to access the web UI.
  2. Configure a login interface for the device.
  3. Configure the interface connecting the device to the RADIUS server.
  4. Configure a security policy.
  5. Configure a RADIUS server template.
  6. Configure an authentication scheme.
  7. Configure an authentication domain and reference the RADIUS server template and authentication scheme.
  8. Configure a RADIUS server.
  9. Log in to web UI using the administrator account and password.

    This example describes only the administrator configuration on the device. For details about the RADIUS two-factor authentication process, see RADIUS Two-Factor Authentication.

Procedure

  1. Configure all interfaces to be used to access the web UI.
    <HUAWEI> system-view  
[HUAWEI] sysname DeviceA 
[DeviceA] web-manager server-source all-interface
  2. Configure a login interface for the device.
    1. Configure IP addresses for interfaces.
      [DeviceA] interface ge 0/0/1
[DeviceA-GE0/0/1] ip address 10.3.0.1 255.255.255.0
[DeviceA-GE0/0/1] quit
    2. Add an interface to a security zone.
      [DeviceA] firewall zone trust  
[DeviceA-zone-dmz] add interface ge 0/0/1 
[DeviceA-zone-dmz] quit
  3. Enable the web service function.
    1. Enable the web server function to allow HTTPS access using port 443.
      [DeviceA] web-manager enable port 443
    2. Enable forcible redirection from HTTP to HTTPS.
      [DeviceA] web-manager http forward enable
  4. Configure the interface connecting the device to the RADIUS server and add the interface to a security zone.
    1. Configure an IP address for an interface.
      [DeviceA] interface ge 0/0/2 
[DeviceA-GE0/0/2] ip address 172.16.0.1 255.255.255.0 
[DeviceA-GE0/0/2] quit
    2. Add an interface to a security zone.
      [DeviceA] firewall zone dmz  
[DeviceA-zone-dmz] add interface ge 0/0/2 
[DeviceA-zone-dmz] quit
  5. Configure a security policy so that the device can proactively communicate with the RADIUS server.
    [DeviceA] security-policy 
[DeviceA-policy-security] rule name rule1 
[DeviceA-policy-security-rule-rule1] source-zone local 
[DeviceA-policy-security-rule-rule1] destination-zone dmz 
[DeviceA-policy-security-rule-rule1] destination-address 172.16.0.2 24 
[DeviceA-policy-security-rule-rule1] action permit 
[DeviceA-policy-security-rule-rule1] quit 
[DeviceA-policy-security] quit
  6. Configure a RADIUS server template to implement communication between the device and the RADIUS server.
    [DeviceA] radius-server template radius_server 
[DeviceA-radius-radius_server] radius-server authentication 172.16.0.2 1812 
[DeviceA-radius-radius_server] radius-server shared-key cipher Huawei@123456789 
[DeviceA-radius-radius_server] quit
  7. Configure an authentication scheme and set the authentication mode to RADIUS.
    [DeviceA] aaa 
[DeviceA-aaa] authentication-scheme auth1 
[DeviceA-aaa-authen-auth1] authentication-mode radius 
[DeviceA-aaa-authen-auth1] quit
  8. Configure an authentication domain and reference the RADIUS server template and authentication scheme.
    [DeviceA-aaa] domain huawei.com 
[DeviceA-aaa-domain-huawei.com] authentication-scheme auth1 
[DeviceA-aaa-domain-huawei.com] radius-server radius_server 
[DeviceA-aaa-domain-huawei.com] quit 
[DeviceA-aaa] quit
  9. Configure a RADIUS server.

    The configuration includes adding a device, adding a user, and setting the user privilege level to 3. For details, see the related documents of the RADIUS server.

  10. Log in to web UI using the administrator account and password.
    1. Set the IP address of the administrator's PC to 10.3.0.100/24.
    2. Open the browser on the PC and access https://10.3.0.1:443.
    3. Enter the created web user account (user name: admin123@huawei.com; password: YsHsjx_202206) and click Login.
    4. After the user name and password are authenticated, the RADIUS server sends a verification code to the mobile phone or email address of the administrator. On the page that is displayed, enter the received verification code and click Submit to log in to the device web UI.

Verifying the Configuration

The administrator uses a web browser to access the device web UI and checks whether the login is successful based on the two factors ("user name + password" and SMS verification code).
