Understanding Bidirectional NAT

Bidirectional NAT translates both source and destination information in packets. It is a combination of source NAT and destination NAT that applies to the same flow. When receiving a packet, the device translates both its source and destination addresses.

To implement bidirectional NAT on the device, configure both source NAT and NAT Server. The NAT processing on the device is as follows:

  1. When receiving a request packet, the device translates the destination address and port number of the packet based on the server mapping entry generated by NAT Server.
  2. The device replaces the source IP address of the packet with a private IP address from the source NAT address pool, replaces the source port number with a new one, creates a session entry accordingly, and sends the resulting packet out.
  3. When receiving a response packet, the device searches the session table for the entry created in step 2, translates the source and destination addresses as well as the source and destination ports according to the entry, and then sends the resulting packet out.
