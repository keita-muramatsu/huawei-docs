(Optional) Configuring Authentication-Free Users

Context

Authentication-free rules can be defined to grant unauthorized users some basic network access rights, such as downloading an 802.1X client and updating the antivirus database. The device uses an authentication-free rule profile to uniformly manage authorization information for authentication-free users. You can define some network access rules in the profile to determine network access rights that can be obtained by authentication-free users. You need to bind a configured authentication-free rule profile to an authentication profile. Users using the authentication profile then can obtain authentication-free authorization information.

For wired users, an authentication-free rule profile takes effect for all wired users after it is created in the system view, without having to be bound to an authentication profile.

Pay attention to the following when using a common authentication-free rule:
  • When multiple authentication-free rules are configured simultaneously, the system matches the rules one by one.
  • If you specify both the VLAN ID and interface number in an authentication-free rule, the interface must belong to the VLAN. Otherwise, the rule is invalid.
  • If the destination port number is configured in an authentication-free rule, fragmented packets cannot match the rule and thus cannot be forwarded.

Procedure

  1. Configure an authentication-free rule profile.
    1. Enter the system view.

      system-view

    2. Create an authentication-free rule profile and enter the authentication-free rule profile view.

      free-rule-template name free-rule-template-name

      The system has only one built-in authentication-free rule profile named default_free_rule.

    3. Configure an authentication-free rule.

      Operation

      Command

      Description

      Configure a common authentication-free rule.

      free-rule rule-id { destination { any | ip { ip-address mask { mask-length | ip-mask } [ tcp destination-port port | udp destination-port port ] | any } } | source { any | { interface interface-type interface-number | ip { ip-address mask { mask-length | ip-mask } | any } | vlan vlan-id } * } }

      By default, no authentication-free rule is configured.

    4. Return to the system view.

      quit

  2. For wireless users, bind an authentication-free rule profile to the authentication profile.

    1. Enter the authentication profile view.
      authentication-profile name authentication-profile-name
    2. Bind the authentication-free rule profile to the authentication profile.
      free-rule-template free-rule-template-name

      By default, no authentication-free rule profile is bound to an authentication profile.

Verifying the Configuration

Run the display free-rule-template configuration [ name free-rule-name ] command to check the configuration of an authentication-free rule profile.
