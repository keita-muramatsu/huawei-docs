Maintaining PoE

Checking PoE Information

  • Run the display poe device command to check information about the devices that support the PoE function.
  • Run the display poe-power [ slot slot-id ] command to check PoE power supply information.
  • Run the display poe information [ slot slot-id ] command to check PoE running information.
  • Run the display poe power [ slot slot-id | interface { interface-type interface-number | interface-name } ] command to check the power of an interface.
  • Run the display poe power-state [ slot slot-id | interface { interface-type interface-number | interface-name } ] command to check the PoE power supply status.

Adjusting the Alarm Threshold Percentage of a PoE Power Supply

Run the poe power-threshold threshold-value command to adjust the alarm threshold percentage of the PoE power supply to the specified value.

By default, the alarm threshold is 90%.
