Configuring IPv4 Static Route Backup

Context

After multiple IPv4 static routes with the same destination but different preferences are configured on a device, the device can perform route backup. On the network shown in Figure 1, two static routes from DeviceA to DeviceC are configured. In most cases, only the static route with DeviceB as a next hop is active in the routing table because this route has a higher priority. The other static route with DeviceD as the next hop serves as a backup route. This backup route is activated and takes over data forwarding only when the static route with DeviceB as the next hop becomes "Inactive." After the static route with DeviceB as the next hop becomes active again (indicating that the routing table restores), this route takes over data forwarding again. Therefore, the backup static route is also known as a floating static route.

Figure 1 Network diagram of IPv4 static route backup

Procedure

  1. Enter the system view.

    system-view

  2. Perform either of the following operations to configure an IPv4 static route. Repeat the operation to configure two or more IPv4 static routes with the same prefix and mask but different preferences.

    • Configure an IPv4 static route on the public network.
      ip route-static ip-address { mask | mask-length } nexthop-address preference preference
ip route-static ip-address { mask | mask-length }{ interface-name | interface-type interface-number } [ nexthop-address ] preference preference
ip route-static ip-address { mask | mask-length } vpn-instance vpn-instance-name preference preference
    • Configure an IPv4 static route in a VPN instance.
      ip route-static vpn-instance vpn-source-name destination-address { mask | mask-length }{ interface-type interface-number } [ nexthop-address ] preference preference
ip route-static vpn-instance vpn-source-name destination-address { mask | mask-length } nexthop-address preference preference
ip route-static vpn-instance vpn-source-name destination-address { mask | mask-length } vpn-instance vpn-destination-name preference preference

Verifying the Configuration

Run the display ip routing-table command to check information about active routes in the IPv4 routing table.
