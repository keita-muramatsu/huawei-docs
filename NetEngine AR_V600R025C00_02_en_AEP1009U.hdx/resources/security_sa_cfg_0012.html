(Optional) Configuring Global Parameters for Application Identification

Context

Advanced global parameters can be configured for application identification in the SA view. Table 1 lists the configurable global parameters.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the SA view.

    sa

  3. Configure global parameters for application identification.

    Table 1 Global parameters for application identification

    Operation

    Command

    Description

    Enable unidirectional traffic detection.

    detect uni-direction

    When a device is deployed on a network where the forward and return paths of traffic are inconsistent, you can run this command to enable unidirectional traffic detection.

    Configure the maximum number of packets the application identification module reads before determining that it cannot identify an application and switching to port-based identification.

    port-identification packet-number-threshold packets-number

    If the application identification module cannot identify the application after reading the maximum number of packets, it attempts to identify the application based on the port information.

    Configure the maximum number of packets that the application identification module is allowed to detect in a session.

    detect max-packets max-packets

    The configured maximum number of packets applies to both directions of a session. That means the maximum number is the sum of the packets that the application identification module is allowed to detect in both directions.

    Configure the maximum duration in which the application identification module detects sessions.

    detect max-time max-time

    You are advised to use the default value. If the maximum time is set to a large value, the device performance deteriorates. If the maximum number is set to a small value, specific applications cannot be identified.
