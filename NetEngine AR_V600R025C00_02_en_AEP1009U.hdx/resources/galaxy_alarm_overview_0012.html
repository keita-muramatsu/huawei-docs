Querying the Corresponding Trap Using This Document

This document describes alarm traps and event traps. You can use either of the following methods to view traps:
  • View traps on the NMS.

  • Run the display trapbuffer [ size buffersize ] command on the CLI to view traps displayed in the trap buffer.

    The number of traps displayed in the trap buffer is determined by the value of buffersize. If the number of traps in the trap buffer is less than the specified value, the actual number of traps is displayed on the CLI.

You are advised to use the following tips to find the specific trap quickly:

  • A trap OID uniquely identifies a trap. You are advised to search for the trap OID in the document to quickly find the description and handling procedure of the trap.

    Traps with the same OID but triggered by different causes are identified by different error codes (for example, BaseTrapProbableCause). You can search for the error code in the document.

  • Do not search for traps in this document based on variable information, such as the trap generation time, interface number, process ID, and device name.

Alarm information is displayed on the terminal screen through the Monitor or Console channel. The format of alarm information displayed on the screen is different from that of the alarm log recorded in the log buffer and of the alarm trap recorded in the trap buffer. However, the information content is the same.

You can determine whether a trap is an alarm trap or event trap based on the Alarm or Event field in the trap attributes. An alarm ID uniquely identifies an alarm. You are advised to search for the alarm ID in the document to quickly find the description and handling procedure of the alarm.
