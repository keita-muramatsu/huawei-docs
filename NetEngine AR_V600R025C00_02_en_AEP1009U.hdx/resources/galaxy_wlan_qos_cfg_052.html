Understanding VIP FastPass

VIP FastPass is a preferential scheduling technology for VIP users based on the innovative FastPass mechanism. Upon AP congestion, air interface resources are reserved for VIP users to improve their service experiences.

In wireless scenarios, co-channel preemption and interference severely affect air interface performance. When one or more common users run bandwidth-extensive services (such as download, HD video playing, and file upload), the AP air interface environment is congested. If greedy STAs with non-standard preemption capabilities are involved, STAs of VIP users may fail in the contention for channel resources on the air interface. This ultimately affects service experience of VIP users. As such, the VIP FastPass function is introduced to improve VIP user experience on the air interface. This function enables APs to provide deterministic air interface preemption capabilities for VIP users.

VIP FastPass Implementation

VIP FastPass is an enhancement to air interface bandwidth reservation for VIP users. This technology focuses on channel contention optimization for VIP packets on the air interface.

As shown in Figure 1, after the VIP FastPass function is enabled, the device reserves specified time slices in the FastPass scheduling period. Within the reserved time slices, the air interface bandwidth is exclusively occupied by VIP users, and multiple VIP users are scheduled in polling mode. Within common contention time slices, the air interface bandwidth is reserved for both VIP users and common users based on air interface bandwidth reservation for VIP users and intelligent multimedia scheduling.

Figure 1 VIP FastPass mechanism
  • Number of FastPass VIP users: The value is configurable. The default value is 5. Assume that the default value 5 is used. When there are fewer than five VIP users, services for all VIP users are guaranteed based on the user access sequence. When the number of VIP users reaches 5, no service guarantee is provided for subsequent VIP users.

Within the reserved time for a single VIP user, FastPass preferentially provides reliable transmission opportunities for uplink traffic (STA -> AP) and preferentially schedules VI/VO queue packets for downlink traffic (AP -> STA).

Scheduling in the Common Contention Time Slice

Assuming that the scheduling period is 20 ms, the common contention time slice is 15 ms. During the common contention time slice, the FastPass function does not take effect; instead, the air interface bandwidth reservation for VIP users and the intelligent multimedia scheduling take effect.
