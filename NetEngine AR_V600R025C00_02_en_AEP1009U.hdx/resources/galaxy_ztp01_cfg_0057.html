Making an Intermediate File

Context

An intermediate file needs to be manually edited before intermediate file-based deployment.

Procedure

  1. Create a text file using either of following methods:

    • Create a text file in .ini format, for example, ztp_script.ini.
    • Create a Python file in .py format, for example, ztp_script.py.

  2. Edit the intermediate file as required.

    • If an .ini file is used, edit the file content by referring to Intermediate File in the INI Format.
      • Obtaining a configuration file by saving the configuration file on another device

        If the password parameter is not specified when the save shareable-configuration command is executed to save the configuration file, leave the EXPORTCFG field empty.

        If the password parameter is specified when the save shareable-configuration command is executed to save the configuration file, set the EXPORTCFG field to a value that is the same as the password entered in interactive mode.

      • Obtaining a configuration file by changing the system master key

        The value of the SET_MASTER field must be the same as the master key of the device that provides the configuration file.

    • If a Python file is used, edit the file content by referring to Intermediate File in Python Format.
      • Obtaining a configuration file by saving the configuration file on another device

        If the password parameter is not specified when the save shareable-configuration command is executed to save the configuration file, set the master_exportcfg field to None.

        If the password parameter is specified when the save shareable-configuration command is executed to save the configuration file, set the master_exportcfg field to a value that is the same as the password entered in interactive mode.

      • Obtaining a configuration file by changing the system master key

        The value of the is_set_master field must be the same as the master key of the device that provides the configuration file.
