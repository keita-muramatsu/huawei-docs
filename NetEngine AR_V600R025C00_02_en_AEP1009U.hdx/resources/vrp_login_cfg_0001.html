CLI-based Device Login Configuration

  • For security purposes, change the password periodically.
  • When logging in to the device for the first time, the local administrator must change the initial password. To ensure service security, you are not advised to run the undo password alert original command to disable the function of prompting users to change initial passwords or run the local-user user-name password-force-change disable command to disable the function of prompting specified users to change initial passwords.
  • The length of a character string displayed in the CLI help is in bytes.
