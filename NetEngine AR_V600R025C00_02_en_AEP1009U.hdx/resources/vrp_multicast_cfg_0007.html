IPv4 Multicast Protocols

In the IP multicast transmission model, the sender only needs to send data to a specified destination address without knowing the locations of receivers. It is the responsibility of network devices to forward data from the sender to the receivers. Multicast devices on the network must collect information about receivers, and replicate and forward multicast messages along correct paths. During multicast development, a complete set of protocols are established to complete this task.

Internet Group Management Protocol (IGMP)

IGMP manages IPv4 multicast group members and runs on a multicast network's last segment (that is, the network segment where a Layer 3 multicast device is connected to user hosts). Hosts use IGMP to join or leave multicast groups, and upstream Layer 3 multicast devices use IGMP to manage and maintain group memberships. IGMP can exchange information with upper-layer multicast routing protocols.

Currently, IGMP has three versions: IGMPv1, IGMPv2, and IGMPv3.

All the IGMP versions support the ASM model. IGMPv3 can be directly applied to the SSM model, whereas IGMPv1 and IGMPv2 require the support of SSM mapping.

Protocol Independent Multicast (PIM)

PIM is a multicast routing protocol used on an IPv4 network to forward multicast data to the multicast device connected to group members that have requested the multicast data. This implements multicast data forwarding based on routes.

PIM-DM is applicable to small-scale networks with densely distributed multicast group members, whereas PIM-SM is applicable to large-scale networks with sparsely distributed multicast group members.

PIM-DM does not need to differentiate between the ASM and SSM models.

PIM-SM differentiates between the ASM and SSM models based on multicast addresses in data and protocol messages.
  • If multicast addresses are in the SSM group address range, PIM-SM uses the SSM model. PIM-SSM is efficient and simplifies the multicast address allocation process. It is especially applicable to scenarios where a specific group has only one specific source.
  • If multicast addresses are in the ASM group address range, PIM-SM uses the ASM model.

Multicast Source Discovery Protocol (MSDP)

MSDP is an inter-domain multicast protocol developed for interconnection among multiple PIM-SM domains. It is used to discover multicast source information in other PIM-SM domains by sending information about active sources in the remote domain to receivers in the local domain. This implements inter-domain multicast message forwarding.

MSDP is required only when the ASM model is used in PIM-SM.
