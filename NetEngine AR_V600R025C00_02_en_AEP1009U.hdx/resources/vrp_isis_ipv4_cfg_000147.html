Checking IS-IS Information

Context

After IS-IS functions are configured, you can run the following commands in the user view to check IS-IS information.

The following table lists only common keywords in display commands. For details about other command formats, see the corresponding command page or command association information.

Table 1 Checking IS-IS information

Operation

Command

Check IS-IS neighbor information.

display isis peer

Check information about the interfaces enabled with IS-IS.

display isis interface

Check IS-IS routing information.

display isis route

Check brief IS-IS information.

display isis brief

Check statistics about error LSPs and Hello packets received by IS-IS.

display isis error

Check information about the IS-IS interfaces that are up but have no neighbors.

display isis interface no-peer

Check IS-IS LSDB information.

display isis lsdb

Check information about the ECMP group of an IS-IS process.

display isis ecmp-group

Check IS-IS process statistics.

display isis statistics

Check information about IS-IS neighbor changes.

display isis last-peer-change

Check the stored history information about the LSDB.

display isis lsdb history

Check the logs about IS-IS SPF calculation.

display isis spf-log

Check the logs about the IS-IS FRR component.

display isis spf-log frr

Check the topology of SPF trees.

display isis spf-tree statistics

Check the packet statistics of an IS-IS process.

display isis statistics packet

Check information about BFD for IS-IS interfaces and sessions.

display isis bfd

Check information about microloop avoidance on nodes.

display isis avoid-microloop information

Check the traffic control information of IS-IS interfaces.

display isis interface traffic-eng

Check the TE information advertised by TE.

display isis traffic-eng advertisements

Check IS-IS TE statistics.

display isis traffic-eng statistics
