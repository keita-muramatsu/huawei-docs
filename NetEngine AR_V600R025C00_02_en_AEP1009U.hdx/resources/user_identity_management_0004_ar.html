Users and Security Groups

User

Users are network access subjects and basic units for network behavior control and network permission assignment.

Before a user accesses network resources, they must be authenticated by the device or a third-party authentication system. Then the user can go online. The online user table on the device records the mapping between a user and the user's IP address. Applying a policy to a user is to apply a policy to the user's IP address.

Security Group

A security group on a device maps the actual organizational structure of an enterprise. For example, the marketing department of an enterprise corresponds to security group marketing, and users in the marketing department are added to this security group. After the administrator configures a policy for a security group, the policy takes effect on all users in this security group, which makes user management easier and more flexible.

Security groups on the current device are tiled and have no hierarchical relationship.
