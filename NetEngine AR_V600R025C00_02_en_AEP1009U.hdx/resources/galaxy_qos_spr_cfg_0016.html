Verifying the Configuration

Procedure

  • Run the display smart-policy-route command to check the global SPR configuration.
  • Run the display smart-policy-route service-map { all | name } command to check the configuration of the SPR service profile.
  • Run the display smart-policy-route spr-policy { all | node-index } command to check the configuration of the SPR policy profile.
  • Run the display smart-policy-route spr-instance { { dest-site site-id } | { vpn-instance vpn-instance-name } | { spr-policy node-index } } *, display smart-policy-route spr-instance { { ipv6 ipv6-prefix [ ipv6-mask-length ] } | { vpn-instance vpn-instance-name } | { spr-policy node-index } } *, display smart-policy-route spr-instance { { ip prefix [ mask-length ] } | { vpn-instance vpn-instance-name } | { spr-policy node-index } } * or display smart-policy-route spr-instance all command to check information about SPR instances.
