Overview of Intrusion Prevention

Definition

Intrusion prevention is a security mechanism that detects intrusions based on the attack signature database and takes certain response measures to terminate the intrusions in real time.

Purpose

Trojan horses, worms, botnets, spyware, overflow attacks, and injection attacks are on the rise, threatening network security. In addition, security vulnerabilities within operating systems and applications can be exploited by hackers to hack into systems. To address such problems, Huawei provides the intrusion prevention function to defend against various attacks and protect the network from being attacked.

As shown in Figure 1, when an extranet user accesses the enterprise intranet, the device detects the access traffic. If an intrusion behavior is detected, the device blocks the access. Otherwise, the traffic is allowed.

Similarly, when an intranet user accesses an external network, if the accessed web page or server contains malicious codes, the device blocks the access. Otherwise, the traffic is permitted.

Figure 1 Networking diagram of intrusion prevention

Benefits

Intrusion prevention has the following advantages:

  • Real-time attack blocking: A device is deployed on a network in in-path mode. When detecting an intrusion, the device blocks the intrusion and attack traffic in real time, minimizing intrusion impacts.
  • In-depth protection: New attacks are hidden at the application layer of TCP/IP. Intrusion prevention can examine the content of application-layer packets, reassemble network data flows for protocol analysis and detection, and determine the traffic that must be blocked based on the attack type and policy.
  • All-round protection: Intrusion prevention provides various protection measures against attacks such as worms, viruses, Trojan horses, botnets, spyware, adware, Common Gateway Interface (CGI) attacks, cross-site scripting attacks, injection attacks, directory traversal attacks, information leakage, remote file inclusion (RFI) attacks, overflow attacks, code execution, DoS attacks, and scanning attacks, providing all-around protection for network security.
  • All-scenario protection: Intrusion prevention not only protects traditional IT networks and assets, but also protects Internet of Things (IoT) assets such as cameras and printers as well as Operation Technology (OT) control systems such as the supervisory control and data acquisition (SCADA) system.
  • Internal and external protection: Intrusion prevention can protect enterprises from both external and internal attacks. The intrusion prevention-capable device can detect the traffic passing through and protect servers and clients.
  • Precise protection: The intrusion prevention system (IPS) signature database is continuously updated, enabling the device to deal with the latest threats. You can periodically update the IPS signature database of a device from the Huawei security center to ensure continuously effective intrusion prevention.
