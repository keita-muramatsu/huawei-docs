Configuring AP Indicators

Context

  • Turning off AP indicators

    Different states of AP indicators indicate different meanings, thereby facilitating installation and management. However, blinking indicators of APs deployed in some indoor scenarios, such as hospitals and hotels, may affect people's nighttime rest. To address this, you can turn off AP indicators after APs are installed and run properly.

  • Configuring information reflected by the blinking frequency of the wireless indicators on APs

    To help onsite installation personnel know the signal strength or traffic status in real time, you can configure information reflected by the blinking frequency of the Wireless indicators.

  • Configuring AP indicator blinking

    When AP positions are not clear, you can attach labels to the APs for locating them. However, this method is inconvenient, and the labels are not elegant and may be damaged. In this case, you can configure the AP indicators blinking function to easily locate APs.

The priority of the AP indicator blinking function is higher than that of turning off AP indicators. That is, if AP indicators are configured to blink during the indicator turn-off period, the indicator turn-off operation takes effect after the indicator blinking is complete.

Procedure

  • Turn off AP indicators.
    1. Enter the system view.

      system-view

    2. Enter the WLAN view.

      wlan

    3. Create an AP system profile and enter its view.

      ap-system-profile name profile-name

      By default, the AP system profile default exists on the device.

    4. Turn off AP indicators or turn them off during the specified time range.

      led off [ time-range time-range ]

      By default, AP indicators can be turned on.

    5. Return to the WLAN view.

      quit

    6. Enter the AP view or AP group view.

      • Enter the AP group view.
        ap-group name group-name
      • Enter the AP view.
        ap-id ap-id

    7. Bind the AP system profile to an AP group or a single AP.

      ap-system-profile profile-name

      By default, the AP system profile default is bound to an AP group, but no AP system profile is bound to an AP.

  • Configure information reflected by the blinking frequency of the wireless indicators on APs.

    Only APs with Wireless indicators support this configuration.

    1. Enter the system view.

      system-view

    2. Enter the WLAN view.

      wlan

    3. Create a radio profile and enter its view.

      • Create a 2.4 GHz radio profile and enter its view.
        radio-2g-profile name profile-name

        By default, the 2.4 GHz radio profile default exists in the system.

      • Create a 5 GHz radio profile and enter its view.
        radio-5g-profile name profile-name

        By default, the 5 GHz radio profile default exists in the system.

    4. Configure the information reflected by the blinking frequency of the Wireless indicator on an AP.

      wifi-light { signal-strength | traffic }

      For details about the default information reflected by the blinking frequency of the Wireless indicators on an AP, see the wifi-light command description in the Command Reference.

      This command takes effect only on Mesh-enabled APs. If the Mesh function is disabled on an AP, the Wireless indicators always reflect the service traffic volume.

      Only APs with Wireless indicators support this command.

    5. Return to the WLAN view.

      quit

    6. Bind the radio profile.

      For details, see Binding a Radio Profile.

  • Configure AP indicator blinking.
    1. Enter the system view.

      system-view

    2. Enter the WLAN view.

      wlan

    3. Configure the AP indicator blinking function.

      led blink-time blink-time { ap-id ap-id | ap-mac ap-mac }

      By default, the AP indicator blinking function is not configured.

Verifying the Configuration

  • Run the display ap-system-profile { name profile-name | all } command to check information about an AP system profile.
  • Run the display references ap-system-profile name profile-name command to check reference information about an AP system profile.
