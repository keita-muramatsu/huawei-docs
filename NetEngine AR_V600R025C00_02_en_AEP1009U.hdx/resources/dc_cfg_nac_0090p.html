Configuring the Rate Limit for HTTPS Packets Sent to the CPU (Portal Authentication)

Context

If the device processes too many HTTPS packets, the CPU may be too busy to process services. To prevent this problem, run the access-user https speed-limit command to set the rate limit for HTTPS packets sent to the CPU. After this command is run, the device discards HTTPS packets that exceed the rate limit.

Procedure

  1. Enter the system view.

    system-view

  2. Configure the rate limit for HTTPS packets sent to the CPU.

    access-user https speed-limit value

    By default, the rate limit of HTTPS packets sent to the CPU varies according to the device.
