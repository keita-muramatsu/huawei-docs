Example for Configuring URPF

Networking Requirements

As shown in Figure 1, the R&D department and marketing department of an enterprise connect to DeviceA through 10GE0/0/6 and 10GE0/0/4, respectively. DeviceA has a reachable route to Server, and R&D and marketing employees can access Server through DeviceA. The enterprise wants to configure URPF check on DeviceA to prevent employees in other departments using spoofed source IP addresses to obtain services from Server without authorization.

Figure 1 Network diagram for configuring URPF

Configuration Roadmap

The configuration roadmap is as follows:

Configure URPF on 10GE0/0/4 and 10GE0/0/6, and allow special processing for the default route.

Procedure

  1. Configure the URPF check mode on the interfaces.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] interface 10ge 0/0/4
[DeviceA-10GE0/0/4] ip urpf strict allow-default-route
[DeviceA-10GE0/0/4] ip address 10.10.1.5 24
[DeviceA-10GE0/0/4] quit
[DeviceA] interface 10ge 0/0/6
[DeviceA-10GE0/0/6] ip address 10.10.2.5 24
[DeviceA-10GE0/0/6] ip urpf strict allow-default-route

  2. Verify the configuration.

    # Run the display this command in the interface view of 10GE0/0/4 to check the URPF configuration.

    [DeviceA-10GE0/0/4] display this
#
interface 10GE 0/0/4
 ip address 10.10.1.5 255.255.255.0
 ip urpf strict allow-default-route
#
return

    # Run the display this command in the interface view of 10GE0/0/6 to check the URPF configuration.

    [DeviceA-10GE0/0/6] display this
#
interface 10GE 0/0/6
 ip address 10.10.2.5 255.255.255.0
 ip urpf strict allow-default-route
#
return

Configuration Scripts

DeviceA configuration file

#
sysname DeviceA
#
interface 10GE0/0/4
 ip address 10.10.1.5 255.255.255.0
 ip urpf strict allow-default-route
#
interface 10GE0/0/6
 ip address 10.10.2.5 255.255.255.0
 ip urpf strict allow-default-route
#
return
