Creating a Sub-VLAN

Procedure

  1. Enter the system view.

    system-view

  2. Enter the interface view.

    interface interface-type interface-number

  3. Change the interface working mode from Layer 3 to Layer 2.

    portswitch

    Determine whether to perform this step based on the current interface working mode.

  4. Set the Layer 2 interface attribute to access.

    port link-type access

    By default, the link type of an interface is hybrid.

  5. Exit the interface view and return to the system view.

    quit

  6. Create a sub-VLAN and enter the sub-VLAN view.

    vlan vlan-id

    If multiple VLANs are created on the device, you are advised to configure names for the VLANs to facilitate management and maintenance. That is, run the name vlan-name command in the view of a VLAN to configure a name for the VLAN. After a VLAN name is configured, you can run the vlan vlan-name vlan-name command in the system view to enter the corresponding VLAN view.

  7. Add a port to the VLAN.

    port interface-type { interface-number1 [ to interface-number2 ] } &<1-10>
