Configuring Static Telemetry Subscription

The following provides a simple example of the static subscription configuration on the device. For details, see Configuring Static Subscription.

Typical CLI Configuration

Description

#

telemetry

#

sensor-group testSensor

sensor-path huawei-ifm:ifm/interfaces/interface/mib-statistics

#

destination-group testDest

ipv4-address 10.10.10.10 port 1239 protocol grpc no-tls

#

subscription testSub

sensor-group testSensor sample-interval 1000

destination-group testDest

#

return
