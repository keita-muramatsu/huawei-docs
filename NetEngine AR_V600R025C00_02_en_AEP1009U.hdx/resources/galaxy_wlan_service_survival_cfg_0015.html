Configuring an Authentication-Server-Down Backup Service VAP

Prerequisites

Before configuring an authentication-server-down backup service VAP, complete the following task:

Deploy basic WLAN services and ensure that STAs can properly access the WLAN.

Context

If the type of a VAP is set to authentication-server-down backup service, the VAP is automatically enabled to allow network access of STAs when the authentication server is not accessible.

You can run the vap-service-backup auth-server-down command to manually enable or disable an authentication-server-down backup service VAP. You can also run the type service-backup auth-server-down vap-auto-off delay-time radius-server template template-name [ reject-new-access ] command to enable the auto-off function for the authentication-server-down backup service VAP and specify the delay in disabling the VAP.

Additionally, you can run the auth-server-down vap-auto-hide radius-server template template-name command to automatically hide service VAPs when the authentication server is down.

For an authentication-server-down backup service VAP:

  • Only the WPA3 SAE, WPA2-WPA3 PSK-SAE, open, WPA+PSK, WPA2+PSK and WPA-WPA2+PSK authentication modes are supported.

  • This VAP type is exclusive with the AP-offline backup service VAP.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a security profile and enter the security profile view.

    security-profile name profile-name

    By default, the security profile default exists in the system and has no security policy configured. To ensure that STAs properly access the WLAN, you must configure a security policy in the security profile.

  4. Run the security command in the new security profile to set the security policy to WPA3 SAE, WPA2-WPA3 PSK-SAE, open, WPA+PSK, WPA2+PSK, or WPA-WPA2+PSK for the authentication-server-down backup service VAP. For details, see Configuring Security Policies.

    By default, no security policy is configured.

  5. Return to the WLAN view.

    quit

  6. (Optional) Create an SSID profile and enter its view.

    ssid-profile name profile-name

    By default, the SSID profile default exists on the device.

  7. (Optional) Configure the SSID name.

    ssid ssid

    By default, the SSID HUAWEI-WLAN is configured in an SSID profile.

  8. Return to the WLAN view.

    quit

  9. Create a VAP profile and enter its view.

    vap-profile name profile-name

    By default, the VAP profile default exists on the device.

  10. The configuration in this VAP profile must be the same as that in the original VAP profile. For details about configurations supported in a VAP profile, see "WLAN STA Management Configuration" in CLI Configuration Guide > WLAN Configuration.
  11. Set the VAP type to authentication-server-down backup service.

    type service-backup auth-server-down [ vap-auto-off delay-time ] radius-server template template-name [ reject-new-access ]

    The default type of a VAP is service.

  12. Bind the security profile to the new VAP profile.

    security-profile profile-name

    By default, the security profile default is bound to a VAP profile.

  13. (Optional) Bind the SSID profile to the new VAP profile.

    ssid-profile profile-name

    By default, the SSID profile default is bound to a VAP profile.

  14. Bind the new VAP profile to the same radio as the original VAP. For details, see Binding a VAP Profile.
  15. Return to the WLAN view.

    quit

  16. Enables or disables the authentication-server-down backup service VAP.

    vap-service-backup auth-server-down { inactive | active } [ vap-profile profile-name ]

    By default, no authentication-server-down backup service VAP is configured.

    When an authentication-server-down backup service VAP is manually disabled, STAs associated with the VAP are disconnected.

Verifying the Configuration

Run the display vap-service-backup auth-server-down [ vap-profile profile-name ] command to check the status of an authentication-server-down backup service VAP.
