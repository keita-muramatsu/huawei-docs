Configuring Immediate Security Policy-based Acceleration

Context

After a security policy is added or modified on a device, you can run the policy accelerate trigger command to make the security policy-based acceleration take effect. Security policy-based acceleration consumes CPU and memory resources. Therefore, you are advised not to run this command frequently but use this command after all security policy configuration is complete. After this command is run, security policy-based acceleration takes effect immediately for all policies such as security policies, bandwidth policies, and NAT policies.

Procedure

  1. Trigger immediate security policy-based acceleration in the user view.

    policy accelerate trigger
