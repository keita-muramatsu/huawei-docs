Configuring an LDP LSP on an IPv4 Network

Configure an LDP LSP on the IPv4/MPLS backbone network to forward IPv6 packets.

Procedure

  1. Enter the system view.

    system-view

  2. Specify an LSR ID.

    mpls lsr-id lsr-id

  3. Enable MPLS and enter the MPLS view.

    mpls

  4. (Optional) Enable the LSP triggering policy. This step is required if labels need to be distributed to other types of routes or only to specified routes.

    lsp-trigger { all | host | ip-prefix ip-prefix-name | none }

  5. Return to the system view.

    quit

  6. Enable LDP for the system.

    mpls ldp

  7. Return to the system view.

    quit

  8. Enter the interface view.

    interface interface-type interface-number

  9. Enable MPLS on the interface.

    mpls

  10. Enable LDP on the interface.

    mpls ldp
