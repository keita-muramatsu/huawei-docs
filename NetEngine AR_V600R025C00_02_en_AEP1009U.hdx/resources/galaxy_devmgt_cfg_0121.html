Configuring a Board Not to Reset Upon Message Congestion

Context

By default, if a board detects that message congestion lasts for more than 30 minutes, the board resets. You can run a command to configure the board not to reset when message congestion lasts for more than 30 minutes.

Procedure

  1. Enter the system view.

    system-view

  2. Configure the board not to reset when message congestion lasts for more than 30 minutes.

    set flow-control-message reliability disable

    By default, if message congestion lasts for more than 30 minutes, the board resets.
