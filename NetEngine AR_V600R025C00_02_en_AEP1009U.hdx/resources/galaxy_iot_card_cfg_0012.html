Maintaining IoT Cards

Procedure

  • Run the iot-card reboot ap ap-id ap-id card { card-id | usb | ble } command to reset an IoT card installed on an AP.
  • Run the iot-card reset-factory-configuration ap ap-id ap-id card { card-id | usb | ble } command to restore the factory settings of an IoT card.
  • Run the iot-card reset-network-configuration ap ap-id ap-id card { card-id | usb | ble } command to reset the network parameters of an IoT card.
  • Run the iot-card switch-firmware ap ap-id ap-id card { card-id | usb | ble } command to switch the active and standby partitions of an IoT card.
  • Run the reset ap-card statistics { all | ap-id ap-id [ card { card-id | usb } ] } command to clear statistics about packets sent and received by cards on APs.
  • Run the iot-card { ap-group ap-group-name | ap ap-id ap-id } card { card-number | usb | ble } iot-command command command to transparently transmit a command to an IoT card for execution.
  • Run the display iot-card iot-command-result { all | ap ap-id ap-id card { card-number | usb | ble } } command to display the execution results of commands transparently transmitted to IoT cards.
