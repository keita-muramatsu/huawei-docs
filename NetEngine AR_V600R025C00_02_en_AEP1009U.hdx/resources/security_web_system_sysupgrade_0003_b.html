Upgrading Feature Packages in Batches Locally

Context

An administrator can upgrade and roll back feature packages as well as set the files for next startup in batches to shorten the upgrade or rollback time window.

Procedure

  1. Choose System > Device Upgrade. The System Upgrade page is displayed, as shown in Figure 1.

    Figure 1 System Upgrade page

  2. Click Batch Install. On the page shown in Figure 2, select the feature packages to be upgraded and click Upgrade. Alternatively, click Next startup to specify the files for the next startup. You can click Upload or Delete to upload or delete feature packages.

    Figure 2 Batch Install page

    This upgrade method is applicable only to feature packages.

    Files in running status cannot be deleted.

  3. Click Batch Uninstall. On the page shown in Figure 3, you can roll back the feature packages that have been upgraded in batches. The feature packages that have not been upgraded cannot be selected for batch rollback.

    Figure 3 Batch Uninstall page
