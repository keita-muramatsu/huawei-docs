Configuring the IPSG Function for APs

Prerequisites

STA IP address learning has been enabled using the undo learn-client-address ipv4 disable command in the VAP profile view.

Context

The IP Source Guard (IPSG) function is used to defend against IP address spoofing attacks. After IPSG is enabled in a VAP profile, APs can filter received IP packets to prevent unauthorized packets from passing through, thereby improving network security.

IPSG checks IP packets received on APs' interfaces against a binding table that contains the bindings between source IP addresses, source MAC addresses, VLANs, and inbound interfaces. Only IP packets matching the binding entries or DHCP packets are forwarded, and other IP packets are discarded.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a VAP profile and enter its view.

    vap-profile name profile-name

    By default, the VAP profile default exists in the system.

  4. Enable the IPSG function for APs.

    ip source check user-bind enable

    By default, the IPSG function is disabled on an AP.

  5. Return to the WLAN view.

    quit

  6. Apply the VAP profile by referring to Binding a VAP Profile to make the configuration take effect.

Verifying the Configuration

Run the display vap-profile { all | name profile-name } command to check the configuration and application of a VAP profile.
