Upgrading the System Software and Patch File Locally

Context

An administrator can view the system software and patch file that are running currently, and specify the system software for next startup.

Procedure

  1. Choose System > Device Upgrade. The System Upgrade page is displayed, as shown in Figure 1.

    Figure 1 System Upgrade page

  2. View the version of the current system software in Current Version. Click Details and view detailed version information in Version Information.
  3. View the path and file name of the current system software and those of the system software for next startup in the System File row. Click Software Management in the Operation column. You can set the system software for next startup in the System Software Management dialog box that is displayed, as shown in Figure 2.

    Figure 2 System Software Management dialog box

    Operation

    Description

    Upload

    Click to upload the startup software to the flash memory.

    Download

    Click to download the startup software from the flash memory.

    Rename

    Click to rename the startup software.

    You can rename only the startup software that does not run.

    Take effect upon next startup

    Click to configure the startup software to take effect upon restart.

    When changes to , the setting succeeds.

    Delete

    Click to delete unnecessary system software from the flash memory to save the storage space.

  4. View the path and file name of the current patch file and those of the patch file for next startup in the Patch File row. Click Patch Management in the Operation column. You can set a patch file in the Patch File Management dialog box that is displayed, as shown in Figure 3.

    Figure 3 Patch File Management dialog box

    Operation

    Description

    Upload

    Click to upload the patch file to the flash memory.

    Download

    Click to download the patch file from the flash memory.

    Install/Uninstall
    • Loading a patch: Click . On the Load Patch File page, select Currently enabled or Enabled on next startup and click OK. The loading process takes about 50 seconds.

      The patch runs successfully when Status changes to .

    • Uninstalling a patch: Click . The uninstallation process takes about 80 seconds.

    Rename

    Click to rename the patch file.

    You can rename only the patch file that does not run.

    Delete

    Click to delete the patch file.

    For details about the impact of patch installation on the device, see the patch release notes.
