Configuring an E1/CE1 Interface to Work in CE1 Mode

Context

As shown in Figure 1, the branch and headquarters of an enterprise are connected through the transmission network of a carrier. Multiple low-rate (128 kbit/s or 256 kbit/s) E1 channels are required to transmit different services. In this scenario, timeslots in the E1 line need to be bundled into multiple channels. Each channel transmits a type of service. For example, two timeslots are bundled to transmit voice services, and four timeslots are bundled to transmit data services.
Figure 1 Branch accessing the transmission network through E1 channels

The E1/CE1 interface of the branch needs to be configured to work in CE1 mode.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the E1/CE1 interface view.

    controller e1 interface-number

  3. Configure the E1/CE1 interface to work in CE1 mode.

    using ce1

    By default, an E1/CE1 interface works in CE1 mode.

  4. Configure timeslot bundling on the E1/CE1 interface.

    channel-set set-number timeslot-list slot-list

    After this step is performed, the system creates a serial interface serial interface-number:set-number, where interface-number and set-number specify the number of the E1/CE1 interface and the number of the channel set, respectively. The interface can be further configured, including configuring the IP address and PPP protocol.

    For example, after you run the controller e1 1/0/0 command to enter the E1/CE1 interface view, configure the interface to work in CE1 mode, and run the channel-set 1 timeslot-list 2 command to configure timeslot bundling, the serial interface created by the system is serial 1/0/0:1.

  5. Configure other parameters for the E1/CE1 interface.

    The parameters except the clock mode of the E1/CE1 interface on the local end must be the same as those on the peer end. Otherwise, the communication may be abnormal.

    1. Configure a clock mode for the interface.

      clock { master | slave }

      By default, the clock mode of an interface is master.

    2. Configure a frame format for the interface.

      frame-format { crc4 | no-crc4 }

      By default, the frame format of an interface is non-CRC-4.

    3. Enable or disable data inversion.

      data-coding inverted enable
undo data-coding inverted enable

      By default, data inversion is disabled on an interface.

    4. Configure a line idle code for the interface.

      idle-code { 7e | ff }

      By default, the line idle code of an interface is 7e (0x7e).

    5. Configure an interframe filling tag and the number of interframe filling tags for the interface.

      itf type { 7e | ff }
itf number number

      By default, the interframe filling tag of an interface is 7e (0x7e), and the number of interframe filling tags is 4.

    6. Configure the content of Sa bits in the transmit direction.

      sa sa4 sa5 sa6 sa7 sa8

      By default, the content of five Sa bits in the transmit direction is 0.

    7. Configure a CRC mode for a serial interface.

      interface serial interface-number
crc { 16 | 32 | none }

      By default, a serial interface uses the 16-bit CRC mode.

Verifying the Configuration

  • Run the display controller e1 interface-number command to check the status and parameters of a specified E1/CE1 interface.
  • Run the display interface serial interface-number command to check the status of and statistics about a specified serial interface.
