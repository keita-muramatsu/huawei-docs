Configuring the EoGRE Primary/Backup Solution

Context

STAs connect to the active and standby DCNs through two EoGRE tunnels. When the connection to the active DCN is faulty, services need to be switched to the standby DCN securely and reliably.

The EoGRE primary/backup solution can be deployed on devices to implement secure and reliable switching and provide remote disaster recovery.

When the primary and backup EoGRE tunnels are deployed, the primary tunnel is in the standby state due to a fault. By default, a primary EoGRE tunnel does not proactively switch to the forwarding state after fault recovery. To enable the primary EoGRE tunnel to automatically switch to the forwarding state after it recovers, you can run the gre preempt enable command to enable preemption for the primary and backup EoGRE tunnels and set a preemption delay as needed.
  • To prevent frequent switchovers between the primary and backup EoGRE tunnels, you can configure a preemption delay using the gre preempt delay delay-time command to ensure that the tunnel interfaces to which a VE interface is bound do not frequently alternate between up and down repeatedly.
  • To enable the primary tunnel to switch to the forwarding state immediately after it recovers, you can configure a preemption delay of 0.

Preemption for primary and backup EoGRE tunnels takes effect only when the VE interface is bound to two tunnel interfaces.

Prerequisites

Before deploying the EoGRE primary/backup solution, establish GRE tunnels. For details, see Configuring a GRE Tunnel.

Procedure

  1. Enter the system view.

    system-view

  2. Create a VE interface and enter its view.

    interface virtual-ethernet ve-number

  3. Set the link type of the VE interface to trunk.

    port link-type trunk

  4. Remove the VE interface from VLAN 1.

    undo port trunk allow-pass vlan 1

  5. Add the VE interface to VLANs.

    port trunk allow-pass vlan { { vlan-id1 [ to vlan-id2 ] }&<1-10> | all }

  6. (Optional) Enable preemption for the primary and backup EoGRE tunnels.

    gre preempt enable

    By default, preemption for the primary and backup EoGRE tunnels is disabled.

  7. (Optional) Configure a preemption delay for the primary and backup EoGRE tunnels.

    gre preempt delay delay-time

    By default, the preemption delay for the primary and backup EoGRE tunnels is 60s.

  8. Return to the system view.

    quit

  9. Enter the tunnel interface view.

    interface tunnel interface-number

  10. Set the tunnel encapsulation type to GRE.

    tunnel-protocol gre

  11. Bind the VE interface to the tunnel interface and set the binding priority.

    map interface virtual-ethernet ve-number priority priority-value

    By default, no VE interface is bound to a tunnel interface.

  12. Configure heartbeat detection.

    Configure heartbeat detection based on Keepalive packets for the GRE tunnel.

    keepalive [ period period [ retry-times retry-times ] ]

Verifying the Configuration

  • Run the display interface virtual-ethernet [ ve-number ] command to check the status and statistics about a VE interface.
  • Run the display tunnel mapping [ interface { tunnel <interface-number> | virtual-ethernet ve-interface-number } ] command to check the mapping between tunnel interfaces and VE interfaces.
  • Run the display tunnel mapping configuration command to check configurations in the EoGRE primary/backup scenario, including information about the tunnel interfaces bound to a VE interface, whether preemption is enabled for the primary and backup EoGRE tunnels, and the preemption delay.
