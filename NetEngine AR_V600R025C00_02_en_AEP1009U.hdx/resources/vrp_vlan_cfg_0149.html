Configuring an IP Address for the VLANIF Interface of a Super-VLAN

Context

The IP address of a super-VLAN's VLANIF interface must be on a subnet where users in all sub-VLANs reside. This IP address is shared by all sub-VLANs, saving IP addresses.

Procedure

  1. Enter the system view.

    system-view

  2. Create a VLANIF interface for a super-VLAN and enter the VLANIF interface view.

    interface vlanif vlan-id

  3. Configure an IP address for the VLANIF interface.

    ip address ip-address { mask | mask-length } [ sub ]
