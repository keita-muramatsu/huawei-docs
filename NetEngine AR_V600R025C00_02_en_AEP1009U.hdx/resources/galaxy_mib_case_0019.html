Querying Optical Module Information

Description of MIB Objects

hwOpticalModuleInfoTable describes basic information about an optical module, including the temperature, voltage, receive optical power, and transmit optical power.

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.
  2. Perform the Walk operation on entPhysicalName to query the component index entPhysicalIndex. As shown in Figure 1, the obtained index of GE2/0/0 is 16912641.
    Figure 1 Querying the entPhysicalIndex value through entPhysicalName
  3. Perform the Walk operation on the corresponding object based on the entPhysicalIndex value to query information such as the vendor serial number and receive optical power. As shown in Figure 2, the vendor serial number of the optical module with the entPhysicalIndex value of 16912641 is EC203100711387.
    Figure 2 Querying the vendor serial number in hwEntityOpticalVendorSn based on the entPhysicalIndex value
