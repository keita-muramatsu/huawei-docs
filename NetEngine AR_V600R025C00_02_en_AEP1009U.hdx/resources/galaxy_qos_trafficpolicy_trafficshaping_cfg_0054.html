Maintaining Traffic Policing, Traffic Shaping, and Interface-based Rate Limiting

Context

Flow-based traffic statistics cannot be restored after they are cleared. Exercise caution when running the below commands.

Procedure

  • Clear the statistics about packets forwarded and discarded on a specified interface for which traffic policing is configured to implement interface-based rate limiting.

    reset qos car statistics interface { interface-type interface-number | interface-name } { inbound | outbound }

  • Clear queue-based traffic statistics.

    reset qos queue statistics { interface { interface-type interface-number | interface-name } | slot slot-id } [ cpu ]

  • Clear statistics about traffic policing based on an IP address range on an interface.

    reset qos car ip-range statistics interface { interface-type interface-num | interface-name } { inbound | outbound }

    The AR5710-S8T2S, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8P2X, and AR5710-S10T1X2 do not support this function.
