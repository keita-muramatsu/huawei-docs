Configuring the MSS of TCP Packets on a VAP

Prerequisites

Before performing the configuration, you have completed the following task:
  • Configure AP onboarding and STA access.

Context

The MSS is an option defined in the TCP protocol and refers to the maximum length of TCP packets that can be received by a device. When setting up a TCP connection, the local and peer devices negotiate an MSS value. If the length of TCP packets sent from the peer device exceeds the MSS value, the packets are fragmented.

You can configure the MSS of TCP packets based on VAPs.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a traffic profile and enter its view.

    traffic-profile name profile-name

  4. Configure the MSS of TCP packets in the traffic profile.

    traffic-optimize tcp adjust-mss value

    By default, the MSS of TCP packets is not configured in a traffic profile.

  5. Bind the traffic profile.

    Bind the traffic profile to an AP group or a single AP so that the configuration in the traffic profile can take effect. For details, see Traffic Profile.

Verifying the Configuration

  • Run the display traffic-profile { all | name profile-name } command to check the MSS of TCP packets in a traffic profile.
