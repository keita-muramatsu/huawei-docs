Verifying the Configuration

After configuring HDLC, check information about the interface status, the link layer encapsulation protocol, and so on.

Prerequisites

HDLC has been configured.

Procedure

  • Run the display interface [ interface-type [ interface-number ]] command to check the interface status, link layer protocol, and configuration.
  • Run the display hdlc interface [ interface-type interface-number ] command to check HDLC link information on interfaces.
