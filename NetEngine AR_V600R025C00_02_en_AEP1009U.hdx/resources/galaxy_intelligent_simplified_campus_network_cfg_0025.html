Clearing Statistics

Context

Before collecting statistics within a specified period, you must clear the original statistics.

Cleared statistics cannot be restored. Therefore, exercise caution when clearing them.

Procedure

Operation

View

Command

Clear onboarding and disconnection records of RUs.

User view

reset remote-unit connect record

Clear configuration delivery records of RUs.

User view

reset remote-unit commit result

Clear upgrade records of RUs.

User view

reset remote-unit upgrade record

Clear XLDP packet statistics on all interfaces or a specified interface.

User view

reset xldp statistics [ interface interface-type interface-number ]

Clear the interface statistics about an RU.

User view

reset remote-unit port [ portid ] statistics [ connect-interface interface-type interface-number | name remote-unit-name ]

Clear statistics about MACsec-protected data packets on RU ports.

User view

reset remote-unit macsec statistics port [ port-id ] { connect-interface { interface-name | interface-type interface-number } | name remote-unit-name }
