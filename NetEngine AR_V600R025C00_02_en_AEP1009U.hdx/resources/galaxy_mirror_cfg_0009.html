Example for Configuring Local 1:1 Port Mirroring

Networking Requirements

On the network shown in Figure 1, the administration department of an enterprise accesses the Internet through DeviceA, and the Server acting as a monitoring device is directly connected to DeviceA. Internet access traffic of the administration department needs to be monitored through the Server.

Figure 1 Networking diagram of local port mirroring

In this example, interfaces 1, 2, and 3 represent 10GE 0/0/1, 10GE 0/0/2, and 10GE 0/0/3, respectively.


Procedure

  1. Configure 10GE0/0/2 on DeviceA as a local observing port.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] observe-port 1 interface 10ge 0/0/2

  2. On DeviceA, configure 10GE0/0/1 as a mirrored port to monitor the packets sent by the administration department.

    [DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] port-mirroring observe-port 1 inbound
[DeviceA-10GE0/0/1] quit

Verifying the Configuration

# Check the mirroring configuration

[DeviceA] display port-mirroring
  Observe port mirroring:
  -----------------------------------------------------------------------------
  MirroringPort         Direction        ObservePort : Interface
  -----------------------------------------------------------------------------
  10GE0/0/1             Inbound                    1 : 10GE0/0/2
  -----------------------------------------------------------------------------

Configuration Scripts

DeviceA

#
sysname DeviceA
#
observe-port 1 interface 10GE0/0/2
#
interface 10GE0/0/1
 port-mirroring observe-port 1 inbound
#
return
