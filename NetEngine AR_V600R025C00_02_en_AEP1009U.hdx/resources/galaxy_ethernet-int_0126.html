Example for Configuring the Working Mode of a Combo Interface

Networking Requirements

As shown in Figure 1, DeviceA, DeviceB, and DeviceC are connected to GE0/0/1, GE0/0/2, and GE0/0/3, respectively, on DeviceD. Due to special restrictions on DeviceD, the maximum transmission rates of GE0/0/1, GE0/0/2, and GE0/0/3 are 100 Mbit/s. DeviceD connects to the Internet through the combo interface GE0/0/4. You can configure the working mode of the combo interface based on the type of the remote interface on the Internet side. In this example, the remote interface is an optical interface.

Figure 1 Network diagram of configuring the working mode of a combo interface

In this example, interface1, interface2, interface3, and interface4 represent GE0/0/1, GE0/0/2, GE0/0/3, and GE0/0/4, respectively.


Configuration Roadmap

Configure the combo interface to work as an optical interface so that the working mode of the combo interface does not change when the transmission medium changes (for example, a GE copper transceiver is installed).

Procedure

  1. Configure the combo interface interface4 to work as an optical interface.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceD
[DeviceD] interface ge 0/0/4
[DeviceD-GE0/0/4] combo enable fiber
[DeviceD-GE0/0/4] quit

Verifying the Configuration

Run the display interface ge 0/0/4 command in any view to check the working mode of the combo interface.

[DeviceD] display interface ge 0/0/4
...
Port Mode:     COMMON FIBER,     Port Split/Aggregate:           -          
Speed:                  100,      Loopback:                       NONE          
Duplex:                FULL,     Negotiation:                    DISABLE          
Input Flow-control: DISABLE,     Output Flow-control:            DISABLE          
Mdi:                      -,     Fec:                                
...

The Port Mode field in the command output shows that the combo interface works as an optical interface.

Configuring Scripts

#
sysname DeviceD
#
interface GE0/0/4
 combo enable fiber
#
return
