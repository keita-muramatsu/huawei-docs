Logging In to the Web System

Context

To log in to the device through the web system, you need to configure the IP address and interface for accessing the web system on the CLI and create a level-3 web administrator account. For details, see "Configuring Web UI-based Login" in CLI Configuration Guide - Basic Configuration.

Procedure

  1. Connect the network port of your PC to the login interface of the device through an Ethernet cable or a Layer 2 switch.
  2. Set the IP address of the PC to be on the same network segment as the IP address of the login interface on the device.
  3. Enter https://ip-address:port in the address box of the browser.

    ip-address is the IP address of the login interface configured through the CLI. If the browser displays a message indicating that the certificate is insecure, select to continue browsing.

  4. On the login page that is displayed, select the language of the web system, enter the created user name and password, and click Login, as shown in Figure 1.

    Figure 1 Logging in to the web system using an account

    When you access the web login address, the browser cannot verify the default certificate provided by the device, and a security warning is displayed. You can click Download CA Certificate to download the certificate and double-click the certificate file to install it. No security warning is displayed upon the next login.

    By default, a verification code is required when you log in to the web system. To disable this requirement, run the undo web-manager captcha enable command.

  5. When you log in to the device using a new administrator account for the first time, the page for changing the initial password is displayed. Enter the current password, new password, and confirm password, and click OK.
  6. On the login page that is displayed, enter the user name and new password and click Login.

Follow-up Procedure

After the successful login, you can perform the following operations to set login-related parameters:

  • Creating other administrators on the web system: Choose System > Administrator > Administrator.
