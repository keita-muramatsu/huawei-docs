Example for Quickly Clearing Configurations Through Configuration Rollback

Networking Requirements

  • After testing new features on the device, you need to clear the feature configurations. If the new feature configurations are large in volume and distributed across multiple service domains, the traditional method of clearing configurations not only requires extensive operations but also carries the risk of manual omissions. You can compare configuration differences between rollback points to quickly restore configurations.
  • After IP addresses are configured for the interfaces shown in Figure 1, the configurations need to be deleted in batches.
Figure 1 Configuration rollback

In this example, Interface1, Interface2, Interface3, and Interface4 represent 10GE0/0/1, 10GE0/0/2, 10GE0/0/3, and 10GE0/0/4 respectively.


Configuration Roadmap

The configuration roadmap is as follows:
  1. Before configuring new features, run the commit label command to generate a configuration rollback point.
  2. Configure IP address for interfaces and perform function tests.
  3. After the test is complete, restore the configurations. Check information about configuration rollback points and find the latest configuration rollback point.
  4. Roll back the configurations.

Procedure

  1. Generate a configuration rollback point.

    <HUAWEI> system-view
[HUAWEI] sysname Device
[Device] commit label label_test

  2. Configure IP addresses for 10GE0/0/1, 10GE0/0/2, 10GE0/0/3, and 10GE0/0/4 on the device. The IP addresses for these interfaces are as follows: 10.0.0.1/30, 10.0.1.1/30, 10.0.2.1/30, and 10.0.3.1/30.

    [Device] interface 10ge 0/0/1
[Device-10GE0/0/1] ip address 10.0.0.1 30
[Device-10GE0/0/1] quit
[Device] interface 10ge 0/0/2
[Device-10GE0/0/2] ip address 10.0.1.1 30
[Device-10GE0/0/2] quit
[Device] interface 10ge 0/0/3
[Device-10GE0/0/3] ip address 10.0.2.1 30
[Device-10GE0/0/3] quit
[Device] interface 10ge 0/0/4
[Device-10GE0/0/4] ip address 10.0.3.1 30
[Device-10GE0/0/4] quit
[Device] commit label label_ipaddress
[Device] quit

  4. Perform configuration rollback.

    Roll back system configurations to what they are before the most recent configuration rollback point is generated.
