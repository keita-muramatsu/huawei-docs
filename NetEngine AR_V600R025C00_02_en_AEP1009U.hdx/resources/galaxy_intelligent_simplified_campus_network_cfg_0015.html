Adding RU Interfaces to VLANs

Context

By default, an RU uses the transparent VLAN mode. After receiving a packet, the RU adds a transparent transmission tag to the packet, searches the MAC address table for the corresponding outbound interface based on the VLAN ID in the VLAN tag, and removes the transparent transmission tag from the packet on the outbound interface. To divide the services of terminals connected to an RU by VLAN, you first need to add the interfaces on the RU to VLANs. Configuring the default VLAN for an RU interface is equivalent to configuring the PVID for a hybrid interface.

Procedure

  • Add RU interfaces to VLANs in batches in the global RU view.
    1. Enter the system view.
      system-view
    2. Enter the global RU view.
      remote-unit
    3. Configure the RU to work in manual VLAN mode.
      vlan mode manual
    4. Add the uplink interfaces of the RU to VLANs.
      • Configure the default VLAN for the uplink interfaces of the RU in batches.
        remote-unit { ruid1 [ to ruid2 ] } &<1-8> port uplink default vlan vlanid
      • Configure the allowed VLANs for the uplink interfaces of the RU.
        remote-unit { ruid1 [ to ruid2 ] } &<1-8> port uplink { tagged | untagged } vlan { vlan-id1 [ to vlan-id2 ] } &<1-10>
    5. Add the downlink interfaces of the RU to VLANs.
      • Configure the default VLAN for the downlink interfaces of the RU in batches.
        remote-unit { ruid1 [ to ruid2 ] } &<1-8> port { portid1 [ to portid2 ] } &<1-32> default vlan vlanid
      • Configure the allowed VLANs for the downlink interfaces of the RU.
        remote-unit { ruid1 [ to ruid2 ] } &<1-8> port { portid1 [ to portid2 ] } &<1-32> { tagged | untagged } vlan { vlan-id1 [ to vlan-id2 ] } &<1-10>
    6. Deliver the configuration to all RUs or a single RU.
      commit { all | name remote-unit-name | interface interface-type interface-number }
  • Add RU interfaces to VLANs in the single RU view.
    1. Enter the system view.
      system-view
    2. Enter the single RU view.
      remote-unit { id | connect-interface interface-type interface-number | name remote-unit-name }
    3. Configure the RU to work in manual VLAN mode.
      vlan mode manual
    4. Add the uplink interfaces of the RU to VLANs.
      • Configure the default VLAN for the uplink interfaces of the RU.
        port uplink default vlan vlan-id
      • Configure the allowed VLANs for the uplink interfaces of the RU.
        port uplink { tagged | untagged } vlan { vlan-id1 [ to vlan-id2 ] } &<1-10>
    5. Add the downlink interfaces of the RU to VLANs.
      • Configure the default VLAN for the downlink interfaces of the RU.
        port { portid1 [ to portid2 ] } &<1-32> default vlan vlanid
      • Configure the allowed VLANs for the downlink interfaces of the RU.
        port { portid1 [ to portid2 ] } &<1-32> { tagged | untagged } vlan { vlan-id1 [ to vlan-id2 ] } &<1-10>
    6. Deliver the configuration to the RU.
      commit
