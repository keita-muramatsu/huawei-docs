Example for Deploying an Intelligent Simplified Campus Network (Active and Standby Links)

Networking Requirements

To simplify the network architecture, an enterprise uses Huawei's Intelligent Simplified Campus Network Solution to build an office network.

As shown in Figure 1, RUs connect to the central device through active and standby links, and the two neighboring RUs back up each other.

The S5731-L4T2ST-RUA is used in this example. On each RU, the first uplink port connects to the central device, and the second uplink port connects to another RU.

Figure 1 Intelligent simplified campus network with active and standby links

In this example, interface1 and interface2 represent 10GE0/0/1 and 10GE0/0/2, respectively.


Configuration Roadmap

The following uses backup group 1, consisting of DeviceB (RU101) and DeviceC (RU102), as an example to describe only the configurations for setting up an intelligent simplified campus network with active and standby links.

  1. Connect the RUs to the local power supply. Then, connect an uplink port of the RU to the central device through a single link, and connect the other uplink port of the RU to another RU to form a standby link.
  2. Bind the interconnection interface on the central device.
  3. Add two RUs to a backup group on the central device and specify the backup port for each RU.

Procedure

  1. Connect the uplink port of each RU to the central device and check whether the RUs are successfully online.

    # Check the RU status. Normal indicates that the RU is running properly.

    <HUAWEI> system-view 
[HUAWEI] sysname DeviceA 
[DeviceA] display remote-unit 
------------------------------------------------------------------------------------------------------------------------
ESN                     ID        Type               ConnectInterface     Status    VersionMatch   Name 
------------------------------------------------------------------------------------------------------------------------
219801176801XXXXXXXX    -         S5731-L4T2ST-RUA    10GE0/0/1           Normal      YES            - 
219801176802XXXXXXXX    -         S5731-L4T2ST-RUA    10GE0/0/2           Normal      YES            -
------------------------------------------------------------------------------------------------------------------------
Total: 2, printed: 2
  2. Configure the interconnection interfaces and interface isolation for the RUs.

    # Bind the interconnection interfaces for the RUs on the central device.

    [DeviceA] remote-unit 1
[DeviceA-remote-unit-1] name RU101
[DeviceA-remote-unit-1] description RU101_10ge0/0/1
[DeviceA-remote-unit-1] bind interface 10GE0/0/1
[DeviceA-remote-unit-1] quit
[DeviceA] remote-unit 2
[DeviceA-remote-unit-2] name RU102
[DeviceA-remote-unit-2] description RU102_10ge0/0/2
[DeviceA-remote-unit-2] bind interface 10GE0/0/2
[DeviceA-remote-unit-2] quit
  3. Add two RUs to a backup group on the central device and specify the backup port for each RU. Backup group 1 of DeviceB (RU101) and DeviceC (RU102) is used as an example. The configurations of other backup groups are similar.
    # Configure a backup group in the global RU view and deliver the configuration to the RUs.
    [DeviceA] remote-unit
[HUAWEI-remote-unit] backup-group 1 remote-unit 1 remote-unit 2
[HUAWEI-remote-unit] quit
    # Specify the backup port in the single RU view for DeviceB (RU101) and DeviceC (RU102).
    [DeviceA] remote-unit 1
[DeviceA-remote-unit-1] backup-group backup-port uplink 2
[DeviceA-remote-unit-1] commit
[DeviceA] remote-unit 2
[DeviceA-remote-unit-2] backup-group backup-port uplink 2
[DeviceA-remote-unit-2] commit
