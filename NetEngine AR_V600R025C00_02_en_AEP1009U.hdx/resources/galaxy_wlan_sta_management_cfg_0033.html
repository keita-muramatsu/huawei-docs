Maintaining the Onboarding Failure and Disconnection Records of STAs

Context

The records about STAs' onboarding failure and disconnection records can help maintenance personnel take proper troubleshooting actions so that STAs can connect to the WLAN properly.

Procedure

  • Run the display station offline-record { all | ap-id ap-id | sta-mac sta-mac-address } command to check STAs' disconnection records.
  • Run the display station online-fail-record { all | ap-id ap-id | sta-mac sta-mac-address } command to check STAs' onboarding failure records.
  • Run the reset station offline-record { all | ap-id ap-id | sta-mac sta-mac } command to clear STAs' disconnection records.
  • Run the reset station online-fail-record { all | ap-id ap-id | sta-mac sta-mac-address } command to clear STAs' onboarding failure records.

    The cleared records cannot be restored. Therefore, exercise caution when performing this operation.
