Configuring the USB Function for APs

Context

To expand storage or transfer files using the USB interface provided on APs, you need to enable the USB function for APs. When the USB function is enabled, the power consumption of an AP increases, which may affect other functions. It is recommended that the USB function be disabled using the undo usb enable command when this function is not needed.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP system profile and enter its view.

    ap-system-profile name profile-name

    By default, the AP system profile default exists on the device.

  4. Enable the USB function for APs.

    usb enable [ 5w | 9w ]

    By default, the USB function on an AP is disabled.

    The USB and other functions of an AP may be restricted at different power supply levels:
    • The USB function is unavailable at specific power supply levels.
    • When the USB function is available and enabled, other functions (such as the number of spatial streams, IoT card, and transmit power) may be affected differently depending on power supply levels. The affected AP functions are restored after the USB function is disabled.

    For detailed restrictions, visit Info-Finder, select a product series, and view hardware specifications in the hardware center. You can check the power supply downgrade restrictions at different power supply levels.

  5. Return to the WLAN view.

    quit

  6. Enter the AP view or AP group view.
    • Enter the AP group view.
      ap-group name group-name
    • Enter the AP view.
      ap-id ap-id
  7. Bind the AP system profile to an AP group or a single AP.

    ap-system-profile profile-name

    By default, the AP system profile default is bound to an AP group, but no AP system profile is bound to an AP.

Verifying the Configuration

  • Run the display ap-system-profile { name profile-name | all } command to check information about an AP system profile.
  • Run the display references ap-system-profile name profile-name command to check reference information about an AP system profile.
