Example for Configuring a VDSL Interface in PTM Mode for Internet Access

Networking Requirements

An enterprise requires a carrier to provide a data access mode that is easy to deploy and provides high-speed upstream and downstream transmission to meet various service requirements, such as data transmission and video on demand (VoD). In Figure 1, the carrier provides a VDSL line to meet the service requirements of DeviceA for the enterprise. The upstream interface of DeviceA must be a VDSL interface, and DeviceA is connected to the DSLAM through the VDSL interface. The VDSL parameters of the DSLAM are set as follows: The bit exchange function, seamless rate adaptation function, and trellis coding function are enabled.
Figure 1 Network diagram of configuring VDSL

Procedure

  1. Enter the VDSL interface view.

    <HUAWEI> system-view 
[HUAWEI] sysname DeviceA
[DeviceA] interface Ethernet 1/0/0

  2. Enable bit exchange.

    [DeviceA-Ethernet1/0/0] adsl bitswap on

  3. Enable seamless rate adaptation.

    [DeviceA-Ethernet1/0/0] adsl sra on

  4. Enable trellis encoding.

    [DeviceA-Ethernet1/0/0] adsl trellis on

Configuration Scripts

DeviceA

#
 sysname DeviceA
#

 adsl bitswap on
 adsl sra on
 adsl trellis on
#
return
