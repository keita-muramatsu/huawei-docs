RRM Profile

Overview

A radio resource management (RRM) profile enables APs to check the surrounding radio environment, dynamically adjust channels and transmit power, and evenly distribute access users. This profile helps reduce radio signal interference, adjust radio coverage, and enable a WLAN to quickly adapt to changes in the radio environment. With the RRM profile, the WLAN can provide high service quality for STAs and maintain an optimal radio resource utilization.

The configuration in an RRM profile can take effect only after the profile is bound to radios in an AP group or on an AP.

Creating a Profile

  1. Enter the WLAN view.

    system-view
wlan

  2. Create an RRM profile.

    rrm-profile name profile-name

Applying a Profile

  1. Enter the WLAN view.

    system-view
wlan

  2. Bind an RRM profile to an existing radio profile.
    • Bind an RRM profile to a 2.4 GHz radio profile.
      radio-2g-profile name profile-name
rrm-profile profile-name
quit
    • Bind an RRM profile to a 5 GHz radio profile.
      radio-5g-profile name profile-name
rrm-profile profile-name
quit
  3. Bind a radio profile to an AP group or a single AP. Perform one of the following steps:
    • Bind a radio profile to an AP group.
      ap-group name group-name
radio-2g-profile profile-name radio { radio-id | all }
radio-5g-profile profile-name radio { radio-id | all }
    • Bind a radio profile to an AP.
      ap-id ap-id
radio-2g-profile profile-name radio { radio-id | all }
radio-5g-profile profile-name radio { radio-id | all }
    • Bind a radio profile to radios on APs in an AP group.
      ap-group name group-name
radio radio-id
radio-2g-profile profile-name
radio-5g-profile profile-name
    • Bind a radio profile to radios on an AP.
      ap-id ap-id
radio radio-id
radio-2g-profile profile-name
radio-5g-profile profile-name
