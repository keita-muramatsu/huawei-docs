Example for Configuring a DHCPv6 Server

Networking Requirements

If a large number of enterprise user IPv6 addresses are manually configured, the configuration workload of the administrator is heavy and the addresses are difficult to manage. The administrator requires that IPv6 addresses and network configuration parameters be automatically obtained to facilitate unified management and implement hierarchical IPv6 deployment.

Figure 1 Network diagram of configuring the DHCPv6 server

In this example, Interface1 represents 10GE0/0/1.


Configuration Roadmap

The configuration roadmap is as follows:

  1. Enable IPv6 on the interface to implement IPv6 communication.

  2. Enable the DHCPv6 server function so that the device can assign an IPv6 address through DHCPv6.

Precautions

To enable a device to process STA IPv6 services in wireless scenarios, run the sta-ipv6-service enable command in the WLAN view.

Procedure

  1. Enable DHCP.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] dhcp enable

  2. Configure a DHCPv6 server.

    [DeviceA] dhcpv6 pool pool1 
[DeviceA-dhcpv6-pool-pool1] address prefix fc00:3::/64  
[DeviceA-dhcpv6-pool-pool1] dns-server fc00:4::1 
[DeviceA-dhcpv6-pool-pool1] quit

  3. Configure the IPv6 function on the interface.

    [DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] undo portswitch
[DeviceA-10GE0/0/1] ipv6 enable
[DeviceA-10GE0/0/1] ipv6 address fc00:3::1/64

  4. Enable the DHCPv6 server function on the interface.

    [DeviceA-10GE0/0/1] dhcpv6 server pool1

  5. Configure the device to advertise RA messages so that the DHCPv6 client can learn the default route to the IPv6 gateway through RA messages, and configure the M and O flags in RA messages so that the DHCPv6 client can obtain an IPv6 address and other network parameters through DHCPv6.

    [DeviceA-10GE0/0/1] ipv6 nd ra halt disable
[DeviceA-10GE0/0/1] ipv6 nd autoconfig managed-address-flag
[DeviceA-10GE0/0/1] ipv6 nd autoconfig other-flag
[DeviceA-10GE0/0/1] ipv6 nd ra prefix default no-advertise       //Configure RA messages not to carry the default prefix generated based on the interface IPv6 address.
[DeviceA-10GE0/0/1] quit
[DeviceA] quit

  6. Verify the configuration.

    # Run the display dhcpv6 pool command on DeviceA to check information about the DHCPv6 address pool.

    <DeviceA> display dhcpv6 pool pool1
DHCPv6 pool: pool1
-------------------------------------------------------------------------------
  Address prefix:
    FC00:3::/64
    Lifetime valid 172800 seconds, preferred 86400 seconds
    0 in use, 0 conflicts
-------------------------------------------------------------------------------
  DNS server address       : FC00:4::1
  Information refresh time    : 86400(s)
  Conflict-address expire-time: 172800(s)
  Renew-time-percent          : 50
  Rebind-time-percent         : 80
  Active normal clients       : 0
  Active pd clients           : 0
  Logging                     : Disable
  VPN instance                : _public_
  VPN match                   : Enable

    # Run the display dhcpv6 server command on DeviceA to check information about the DHCPv6 server.

    <DeviceA> display dhcpv6 server
  Interface                                DHCPv6 pool                           
  10GE0/0/1                                pool1

Configuration Scripts

DeviceA

#
 sysname DeviceA
#                                                                               
dhcp enable   
#                       
dhcpv6 pool pool1                                                               
 address prefix FC00:3::/64
 dns-server FC00:4::1                                                             
#                       
interface 10GE0/0/1                                                  
 ipv6 enable                                                                    
 ipv6 address FC00:3::1/64                                                    
 ipv6 nd ra halt disable
 ipv6 nd ra prefix default no-advertise
 ipv6 nd autoconfig managed-address-flag
 ipv6 nd autoconfig other-flag
 dhcpv6 server pool1
#  
return
