Configuring a TE-Class Value

Procedure

  1. Configure a traffic classifier. For details, see "MQC Configuration" in Configuration Guide > QoS Configuration.
  2. Configure a traffic behavior.
    1. Enter the system view.

      system-view

    2. Create a traffic behavior and enter the traffic behavior view.

      traffic behavior behavior-name

    3. Set a TE-Class value for packets.

      set te-class class-value

    4. (Optional) Enable the statistics collection function for the traffic policy.

      statistics enable [ history-record interval interval-value ]

      To conserve memory resources, the statistics collection function of traffic policies is disabled by default. To check traffic policy statistics, you need to enable the statistics collection function for the traffic policy.

    5. Return to the system view.

      quit

  3. Configure a traffic policy.
    1. Define a traffic policy and enter the traffic policy view.

      traffic policy policy-name

    2. Specify a traffic behavior for the traffic classifier and set a policy-based matching priority.

      classifier classifier-name behavior behavior-name [ precedence precedence-value ]

    3. Return to the system view.

      quit

  4. Apply the traffic policy.
    1. Enter the interface view.

      interface interface-type interface-number

    2. Apply the traffic policy to the interface.

      traffic-policy policy-name { inbound | outbound }

    3. Return to the system view.

      quit
