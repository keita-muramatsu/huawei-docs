Configuring an ACL-based Simplified Traffic Policy on AP Wired Interfaces

Prerequisites

Before configuring an ACL-based simplified traffic policy on AP wired interfaces, you have completed the following tasks:

Context

An ACL-based simplified traffic policy enables the device to match packet information with ACL rules and provide the same QoS service for packets that match the same ACL rules, implementing differentiated services.

To control traffic on an AP's wired interface, configure an ACL to match information such as the source IP address, fragment flag, destination IP address, source port number, and source MAC address. Then, configure an ACL-based simplified traffic policy so that the device can filter packets that match ACL rules.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP wired port profile and enter its view.

    wired-port-profile name wired-port-profile-name

    By default, the AP wired port profile default exists on the device.

  4. Configure ACL-based IPv4 or Layer 2 packet filtering on AP wired interfaces.

    traffic-filter { inbound | outbound } { l2 acl { acl-number-l2 | name acl-name-l2 } | ipv4 acl { acl-number | name acl-name } | ipv4 acl { acl-number | name acl-name } l2 acl { acl-number-l2 | name acl-name-l2 } }

    By default, ACL-based IPv4 or Layer 2 packet filtering is not configured on AP wired interfaces.

Follow-up Procedure

After the configuration is complete, bind the AP wired port profile to an AP group or a specific AP so that the configuration in the profile can take effect. For configuration details, see Binding an AP Wired Port Profile.
