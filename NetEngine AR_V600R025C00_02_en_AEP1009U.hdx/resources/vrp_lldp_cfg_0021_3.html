Example for Configuring LLDP in a Link Aggregation Scenario

Networking Requirements

On the network shown in Figure 1, DeviceA and DeviceB are connected through an Eth-Trunk, the NMS has a reachable route to DeviceB, and SNMP is configured on the devices and NMS.

A network administrator wants to obtain Layer 2 configuration information about DeviceA and DeviceB to learn details about the network topology and configuration conflicts.

Figure 1 Networking with link aggregation

Configuration Roadmap

  1. Add the physical Ethernet interfaces of DeviceA and DeviceB to the Eth-Trunk.
  2. Enable LLDP globally on DeviceA and DeviceB.
  3. Configure management IP addresses for DeviceA and DeviceB.

Procedure

  1. Configure IP addresses and routing protocols for interfaces, as shown in Figure 1. For details, see Configuration Scripts.
  2. Configure the Eth-Trunk interfaces on DeviceA and DeviceB.

    # Configure DeviceA.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] vlan batch 100
[DeviceA] interface eth-trunk 1
[DeviceA-Eth-Trunk1] trunkport 10ge 0/0/1 to 0/0/3
[DeviceA-Eth-Trunk1] portswitch
[DeviceA-Eth-Trunk1] port link-type trunk
[DeviceA-Eth-Trunk1] port trunk allow-pass vlan 100
[DeviceA-Eth-Trunk1] quit

    # Configure DeviceB.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceB
[DeviceB] vlan batch 100
[DeviceB] interface eth-trunk 1
[DeviceB-Eth-Trunk1] trunkport 10ge 0/0/1 to 0/0/3
[DeviceA-Eth-Trunk1] portswitch
[DeviceB-Eth-Trunk1] port link-type trunk
[DeviceB-Eth-Trunk1] port trunk allow-pass vlan 100
[DeviceB-Eth-Trunk1] quit

  3. Configure LLDP globally on DeviceA and DeviceB.

    # Configure DeviceA.

    [DeviceA] lldp enable

    # Configure DeviceB.

    [DeviceB] lldp enable

  4. Configure management IP addresses for DeviceA and DeviceB.

    # Configure 10.10.10.1 as the management IP address of DeviceA.

    [DeviceA] lldp management-address 10.10.10.1

    # Configure 10.10.10.2 as the management IP address of DeviceB.

    [DeviceB] lldp management-address 10.10.10.2

Configuration Scripts

  • DeviceA

    #
sysname DeviceA
#
 vlan batch 100
#
interface Vlanif100
 ip address 10.10.10.1 255.255.255.0
#
interface Eth-Trunk1
 portswitch
 port link-type trunk
 port trunk allow-pass vlan 100
#
interface 10GE0/0/1
 eth-trunk 1
#
interface 10GE0/0/2
 eth-trunk 1
#
interface 10GE0/0/3
 eth-trunk 1
#
lldp enable
#
lldp management-address 10.10.10.1
#
return
  • DeviceB
    #
sysname DeviceB
#
 vlan batch 100
#
interface Vlanif100
 ip address 10.10.10.2 255.255.255.0
#
interface Eth-Trunk1
 portswitch
 port link-type trunk
 port trunk allow-pass vlan 100
#
interface 10GE0/0/1
 eth-trunk 1
#
interface 10GE0/0/2
 eth-trunk 1
#
interface 10GE0/0/3
 eth-trunk 1
#
lldp enable
#
lldp management-address 10.10.10.2
#
return
