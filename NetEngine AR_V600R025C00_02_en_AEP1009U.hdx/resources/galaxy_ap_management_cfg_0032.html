Configuring Login to an AP Through the Bluetooth Serial Port

Prerequisites

Before configuring login to an AP through the Bluetooth serial port, you have completed the following task:

  • Configuring the User Name and Password for AP Login
  • AP login through the console port has been enabled using the undo console disable command.

Context

APs may be widely distributed on a network. For a highly mounted AP, if the console port login is required for fault diagnosis and debugging, the onsite personnel need to climb high and connect the serial cable to the AP, which is dangerous and time-consuming. The Bluetooth serial port on an AP allows users to connect to the AP through Bluetooth and log in to the AP using the CloudCampus APP. This facilitates fault diagnosis and debugging for the AP.

When configuring login to an AP through the Bluetooth serial port, pay attention to the following:

  • Some physical attributes of the Bluetooth serial port cannot be configured, as listed in the following table.
    Table 1 Commands that are not supported by the Bluetooth serial port

    Command

    Description

    speed speed-value

    Sets the data transmission rate of a user interface.

    databits { 5 | 6 | 7 | 8 }

    Sets the data bit of a user interface.

    parity { even | none | odd }

    Sets the parity bit of a user interface.

    stopbits { 1.5 | 1 | 2 }

    Sets the stop bit of a user interface.
  • Currently, only the CloudCampus APP on mobile phones can be used to log in to an AP through the Bluetooth serial port.
  • The Bluetooth serial port function does not support the RFCOMM+SPP protocol.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP system profile, and enter its view.

    ap-system-profile name profile-name

    By default, the AP system profile default exists on the device.

  4. Configure the Bluetooth serial port mode.

    console ble-mode { dynamic | persistent | disable }

    By default, the Bluetooth serial port mode is dynamic.

  5. Return to the WLAN view.

    wlan

  6. Enter the AP view or AP group view.
    • Enter the AP group view.
      ap-group name group-name
    • Enter the AP view.
      ap-id ap-id
  7. Bind the AP system profile to an AP group or a single AP.

    ap-system-profile profile-name

    By default, the AP system profile default is bound to an AP group, but no AP system profile is bound to an AP.

  8. In the Bluetooth coverage of an AP, enable Bluetooth on the user terminal and start the CloudCampus APP.
  9. Choose Tool > Bluetooth Serial Port.
  10. Find the target AP based on the MAC address and touch Connect.
  11. Enter the user name and password as prompted to log in to the user interface.

    If the login dialog box is not displayed after you touch Enter, touch any key on the terminal keyboard to activate the screen.

Verifying the Configuration

  • Run the display ap-system-profile { all | name profile-name } command to check the Bluetooth serial port mode in the AP system profile.
  • Run the display wlan console ble statistics ap-id ap-id command to check statistics about the Bluetooth serial port on an AP.

    To clear Bluetooth serial port statistics on an AP, run the reset wlan console ble statistics ap-id ap-id command.

  • Run the display wlan ble-link-info ap-id ap-id command to check connection information about the Bluetooth serial port on an AP.
