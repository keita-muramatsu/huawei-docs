Configuring Service Reliability Assurance Upon Memory Overload

Context

In most cases, the system generates an alarm when a board's memory usage exceeds the preset alarm threshold. If no effective measures are taken and the memory is continuously overloaded, services will be adversely affected. To improve service reliability when memory overload occurs, you can set alarm thresholds for memory overload on a device. The alarm thresholds are classified into a notice threshold, an overload threshold, and an exception threshold in an ascending order of memory overload severity. When the memory usage reaches a threshold, the system checks whether the device meets the conditions for an active/standby switchover and perform specific operations based on the check result. An active/standby switchover is performed when the memory usage of the active board reaches the exception threshold, the memory usage of the standby board is lower than the threshold, and the standby board has been in position for more than one day.

  • Conditions met: No action is taken when the memory usage of the board reaches only the notice or overload threshold. The system performs an active/standby switchover only when the memory usage of the board reaches the exception threshold.
  • Conditions not met: The system notifies all components of information about up to 10 components that occupy more than 5% of memory resources on the device. The notified components then execute their own service reliability assurance mechanisms based on the memory overload severity.

Procedure

  1. Enter the system view.

    system-view

  2. Enable service reliability assurance upon memory overload.

    memory-usage reliability switch on

    By default, service reliability assurance upon memory overload is disabled.

  3. Set the notice threshold, overload threshold, exception threshold, and recovery threshold of memory overload.

    memory-usage reliability notice-threshold notice-threshold-value overload-threshold overload-threshold-value exception-threshold exception-threshold-value [ slot slotId ]

    The default notice, overload, and exception thresholds for memory usage reliability are 70%, 85%, and 95%, respectively.

  4. Set the alarm threshold for memory usage on the standby board.

    memory-usage reliability slave-switch-over threshold threshold-value

    By default, the alarm threshold for memory usage on the standby board is 70%.

    This function is supported only by the AR6700-H and AR8700 series.

Verifying the Configuration

Run the display current-configuration command to check memory usage thresholds and whether service reliability assurance upon memory overload is enabled.
