Configuring Association Between Interface Backup and a Route Monitoring Group

Prerequisites

Before configuring association between interface backup and a route monitoring group, you have completed the following tasks:

  • Configure routing protocols on the primary and backup links to ensure connectivity at the network layer.

  • Configure a route monitoring group on the local device (DeviceA) to monitor the connectivity of the primary link. For detailed configurations, see Configuring an IPv4 Route Monitoring Group.

Procedure

  1. Enter the system view.

    system-view

  2. (Optional) Set a delay for the backup function to take effect on the route monitoring group after the system is started.

    standby track route-monitor-group warmup seconds

    • By default, the backup function takes effect on the route monitoring group 60 seconds after the system is started.

    • After an active/standby board switchover, the warmup delay function does not take effect.

  3. Enter the standby interface view.

    interface interface-type interface-number

  4. Configure association between interface backup and the route monitoring group.

    standby track route-monitor-group group-name [ weight weight-num ]
    • A standby interface can be associated with only one route monitoring group, whereas a route monitoring group can be associated with multiple standby interfaces.
    • If interface backup is associated with a route monitoring group and no weight is configured, the standby interface goes up only when all routes in the route monitoring group are unavailable.
    • After interface backup is associated with a route monitoring group, if the group cannot obtain the route status, the standby interface remains physically down.
    • After interface backup is associated with a route monitoring group, the standby interface remains physically down during the warmup delay.
    • The monitor enable command must be run in the route monitoring group view to enable the routing module to notify the route monitoring group of the route status. If this command is not run, the standby interface remains physically up.

Verifying the Configuration

Run the display standby state command to check the interface backup status and route monitoring group status.
