Example for Configuring MSTP Multi-Process

Networking Requirements

In Figure 1, DeviceA and DeviceB that function as PE devices are connected to DeviceC to DeviceH that function as CE devices, forming multiple access rings. DeviceA, DeviceC, and DeviceD are in a ring; DeviceB, DeviceG, and DeviceH are in another ring; DeviceA, DeviceB, DeviceE, and DeviceF are in the third ring.

In this case, MSTP multi-process can be deployed to allow each access ring to calculate a spanning tree independently.

Figure 1 Network diagram of MSTP multi-process

In this example, interface 1, interface 2, interface 3, interface 4, and interface 5 represent 10GE 0/0/1, 10GE 0/0/2, 10GE 0/0/3, 10GE 0/0/4, and 10GE 0/0/5, respectively.


Procedure

  1. Configure basic MSTP functions, add devices to an MST region, and create instances.

    # Add DeviceA to an MST region and create instances.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] stp region-configuration
[DeviceA-mst-region] region-name RG1
[DeviceA-mst-region] instance 1 vlan 2 to 100
[DeviceA-mst-region] instance 2 vlan 101 to 200
[DeviceA-mst-region] instance 3 vlan 201 to 300
[DeviceA-mst-region] quit

    # Add DeviceB to the MST region and create instances.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceB
[DeviceB] stp region-configuration
[DeviceB-mst-region] region-name RG1
[DeviceB-mst-region] instance 1 vlan 2 to 100
[DeviceB-mst-region] instance 2 vlan 101 to 200
[DeviceB-mst-region] instance 3 vlan 201 to 300
[DeviceB-mst-region] quit
    # Add DeviceC to DeviceH to the MST region and create instances. The following uses DeviceC as an example. The configurations of DeviceD to DeviceH are similar to the configuration of DeviceC.
    <HUAWEI> system-view
[HUAWEI] sysname DeviceC
[DeviceC] stp region-configuration
[DeviceC-mst-region] region-name RG1
[DeviceC-mst-region] instance 1 vlan 2 to 100
[DeviceC-mst-region] quit

  2. Enable MSTP on DeviceA and DeviceB.

    By default, a spanning tree protocol is enabled on the device, and no operation is required. You can run the stp enable command in the system view to enable STP/RSTP/MSTP.

    # Enable MSTP on DeviceA.

    [DeviceA] stp enable

    # Enable MSTP on DeviceB.

    [DeviceB] stp enable
    # Enable MSTP on DeviceC. The following uses DeviceC as an example. The configurations of DeviceD to DeviceH are similar to the configuration of DeviceC.
    [DeviceC] stp enable

  3. Create multiple MSTP processes on the devices and add ports to the processes.

    # On DeviceA, create process 1 and process 2, and add 10GE 0/0/3 and 10GE 0/0/4 to process 1 and 10GE 0/0/2 to process 2.

    [DeviceA] stp process 1
[DeviceA-mst-process-1] quit
[DeviceA] stp process 2
[DeviceA-mst-process-2] quit
[DeviceA] interface 10ge 0/0/4
[DeviceA-10GE0/0/4] portswitch
[DeviceA-10GE0/0/4] stp binding process 1
[DeviceA-10GE0/0/4] quit
[DeviceA] interface 10ge 0/0/3
[DeviceA-10GE0/0/3] stp binding process 1
[DeviceA-10GE0/0/3] quit
[DeviceA] interface 10ge 0/0/2
[DeviceA-10GE0/0/2] portswitch
[DeviceA-10GE0/0/2] stp binding process 2
[DeviceA-10GE0/0/2] quit

    # On DeviceB, create process 2 and process 3, and add 10GE 0/0/3 and 10GE 0/0/4 to process 3 and 10GE 0/0/2 to process 2.

    [DeviceB] stp process 2
[DeviceB-mst-process-2] quit
[DeviceB] stp process 3
[DeviceB-mst-process-3] quit
[DeviceB] interface 10ge 0/0/4
[DeviceB-10GE0/0/4] portswitch
[DeviceB-10GE0/0/4] stp binding process 3
[DeviceB-10GE0/0/4] quit
[DeviceB] interface 10ge 0/0/3
[DeviceB-10GE0/0/3] portswitch
[DeviceB-10GE0/0/3] stp binding process 3
[DeviceB-10GE0/0/3] quit
[DeviceB] interface 10ge 0/0/2
[DeviceB-10GE0/0/2] portswitch
[DeviceB-10GE0/0/2] stp binding process 2
[DeviceB-10GE0/0/2] quit
    # Create processes on DeviceC to DeviceH. The following uses DeviceC as an example. On DeviceC, create process 1 and add 10GE 0/0/1 and 10GE 0/0/2 to process 1. The configurations of DeviceD to DeviceH are similar to the configuration of DeviceC.
    [DeviceC] stp process 1
[DeviceC-mst-process-1] quit
[DeviceC] interface 10ge 0/0/1
[DeviceC-10GE0/0/3] stp binding process 1
[DeviceC-10GE0/0/3] quit
[DeviceC] interface 10ge 0/0/2
[DeviceC-10GE0/0/2] portswitch
[DeviceC-10GE0/0/2] stp binding process 1
[DeviceC-10GE0/0/2] quit

  4. Configure a shared link.

    # Configure DeviceA.

    [DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] portswitch
[DeviceA-10GE0/0/1] stp binding process 2 link-share
[DeviceA-10GE0/0/1] quit

    # Configure DeviceB.

    [DeviceB] interface 10ge 0/0/1
[DeviceB-10GE0/0/1] portswitch
[DeviceB-10GE0/0/1] stp binding process 2 link-share
[DeviceB-10GE0/0/1] quit

  5. Enable MSTP for processes.

    # Configure DeviceA.

    [DeviceA] stp process 1
[DeviceA-mst-process-1] stp enable
[DeviceA-mst-process-1] quit
[DeviceA] stp process 2
[DeviceA-mst-process-2] stp enable
[DeviceA-mst-process-2] quit

    # Configure DeviceB.

    [DeviceB] stp process 3
[DeviceB-mst-process-3] stp enable
[DeviceB-mst-process-3] quit
[DeviceB] stp process 2
[DeviceB-mst-process-2] stp enable
[DeviceB-mst-process-2] quit
    # Configure DeviceC. The configurations of DeviceD to DeviceH are similar to the configuration of DeviceC.
    [DeviceC] stp process 1
[DeviceC-mst-process-1] stp enable
[DeviceC-mst-process-1] quit

  6. Configure other functions.

    # On DeviceA, configure priorities and root protection.

    [DeviceA] stp process 1
[DeviceA-mst-process-1] stp instance 0 root primary
[DeviceA-mst-process-1] stp instance 1 root primary
[DeviceA-mst-process-1] quit
[DeviceA] stp process 2
[DeviceA-mst-process-2] stp instance 0 root primary
[DeviceA-mst-process-2] stp instance 2 root primary
[DeviceA-mst-process-2] quit
[DeviceA] interface 10ge 0/0/2
[DeviceA-10GE0/0/2] portswitch
[DeviceA-10GE0/0/2] stp root-protection
[DeviceA-10GE0/0/2] quit

    # On DeviceB, configure priorities and root protection.

    [DeviceB] stp process 3
[DeviceB-mst-process-3] stp instance 0 root primary
[DeviceB-mst-process-3] stp instance 3 root primary
[DeviceB-mst-process-3] quit
[DeviceB] stp process 2
[DeviceB-mst-process-2] stp instance 0 root secondary
[DeviceB-mst-process-2] stp instance 2 root secondary
[DeviceB-mst-process-2] quit
[DeviceB] interface 10ge 0/0/2
[DeviceB] portswitch
[DeviceB-10GE0/0/2] stp root-protection
[DeviceB-10GE0/0/2] quit

    • In each ring, the CE devices have lower MSTP process priorities than the PE device. By default, the priority of a device in a specified spanning tree is 32768. The priority of a CE device does not need to be configured.

    • For DeviceA and DeviceB in the dual-access ring, you are recommended to configure them as the primary or a secondary root bridge in different instances.

    # On DeviceA, enable shared link protection for the MSTP process.

    [DeviceA] stp process 2
[DeviceA-mst-process-2] stp link-share-protection
[DeviceA-mst-process-2] quit

    # On DeviceB, enable shared link protection for the MSTP process.

    [DeviceB] stp process 2
[DeviceB-mst-process-2] stp link-share-protection
[DeviceB-mst-process-2] quit

  7. Create VLANs and add ports to the VLANs.

    # On DeviceA, create VLANs 2 to 200, and add 10GE 0/0/3 and 10GE 0/0/4 to VLANs 2 to 100 and 10GE 0/0/1 and 10GE 0/0/2 to VLANs 101 to 200.

    [DeviceA] vlan batch 2 to 200
[DeviceA] interface 10ge 0/0/3
[DeviceB-10GE0/0/3] portswitch
[DeviceA-10GE0/0/3] port link-type trunk
[DeviceA-10GE0/0/3] port trunk allow-pass vlan 2 to 100
[DeviceA-10GE0/0/3] quit
[DeviceA] interface 10ge 0/0/4
[DeviceA-10GE0/0/4] portswitch
[DeviceA-10GE0/0/4] port link-type trunk
[DeviceA-10GE0/0/4] port trunk allow-pass vlan 2 to 100
[DeviceA-10GE0/0/4] quit
[DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] portswitch
[DeviceA-10GE0/0/1] port link-type trunk 
[DeviceA-10GE0/0/1] port trunk allow-pass vlan 101 to 200
[DeviceA-10GE0/0/1] quit
[DeviceA] interface 10ge 0/0/2
[DeviceA-10GE0/0/2] portswitch
[DeviceA-10GE0/0/2] port link-type trunk 
[DeviceA-10GE0/0/2] port trunk allow-pass vlan 101 to 200
[DeviceA-10GE0/0/2] quit

    # On DeviceB, create VLANs 101 to 300, and add 10GE 0/0/3 and 10GE 0/0/4 to VLANs 201 to 300 and 10GE 0/0/1 and 10GE 0/0/2 to VLANs 101 to 200.

    [DeviceB] vlan batch 101 to 300
[DeviceB] interface 10ge 0/0/3
[DeviceB-10GE0/0/3] portswitch
[DeviceB-10GE0/0/3] port link-type trunk
[DeviceB-10GE0/0/3] port trunk allow-pass vlan 201 to 300
[DeviceB-10GE0/0/3] quit
[DeviceB] interface 10ge 0/0/4
[DeviceB-10GE0/0/4] portswitch
[DeviceB-10GE0/0/4] port link-type trunk
[DeviceB-10GE0/0/4] port trunk allow-pass vlan 201 to 300
[DeviceB-10GE0/0/4] quit
[DeviceB] interface 10ge 0/0/1
[DeviceB-10GE0/0/1] portswitch
[DeviceB-10GE0/0/1] port link-type trunk
[DeviceB-10GE0/0/1] port trunk allow-pass vlan 101 to 200
[DeviceB-10GE0/0/1] quit
[DeviceB] interface 10ge 0/0/2
[DeviceB-10GE0/0/2] portswitch
[DeviceB-10GE0/0/2] port link-type trunk
[DeviceB-10GE0/0/2] port trunk allow-pass vlan 101 to 200
[DeviceB-10GE0/0/2] quit
    # Configure DeviceC. On DeviceC, create VLANs 2 to 100, and add 10GE 0/0/1 and 10GE 0/0/2 to VLANs 2 to 100. The configurations of DeviceD to DeviceH are similar to the configuration of DeviceC.
    [DeviceC] vlan batch 2 to 100
[DeviceC] interface 10ge 0/0/1
[DeviceC-10GE0/0/3] portswitch
[DeviceC-10GE0/0/3] port link-type trunk
[DeviceC-10GE0/0/3] port trunk allow-pass vlan 2 to 100
[DeviceC-10GE0/0/3] quit
[DeviceC] interface 10ge 0/0/2
[DeviceC-10GE0/0/2] portswitch
[DeviceC-10GE0/0/3] port link-type trunk
[DeviceC-10GE0/0/3] port trunk allow-pass vlan 2 to 100
[DeviceC-10GE0/0/2] quit

Verifying the Configuration

  • Run the display stp interface brief command on DeviceA.

    # 10GE 0/0/4 is a designated port in the CIST of MSTP process 1 and in instance 1.

    [DeviceA] display stp process 1 interface 10ge 0/0/4 brief
 MSTID      Port                    Role  STP State       Protection
   0        10GE0/0/4              DESI  FORWARDING      NONE
   1        10GE0/0/4              DESI  FORWARDING      NONE

    # 10GE 0/0/2 is a designated port in the CIST of MSTP process 2 and in instance 2.

    [DeviceA] display stp process 2 interface 10ge 0/0/2 brief
 MSTID      Port                    Role  STP State       Protection
   0        10GE0/0/2              DESI  FORWARDING      ROOT
   2        10GE0/0/2              DESI  FORWARDING      ROOT

  • Run the display stp interface brief command on DeviceB.

    # 10GE 0/0/4 is a designated port in the CIST of MSTP process 3 and in instance 3.

    [DeviceB] display stp process 3 interface 10ge 0/0/4 brief
 MSTID      Port                    Role  STP State       Protection
   0        10GE0/0/4              DESI  FORWARDING      NONE
   3        10GE0/0/4              DESI  FORWARDING      NONE

    # 10GE 0/0/2 is a designated port in the CIST of MSTP process 2 and in instance 2.

    [DeviceB] display stp process 2 interface 10ge 0/0/2 brief
 MSTID      Port                    Role  STP State       Protection
   0        10GE0/0/2              DESI  FORWARDING      ROOT
   2        10GE0/0/2              DESI  FORWARDING      ROOT

Configuration Scripts

  • DeviceA

    #
sysname DeviceA
#
vlan batch 2 to 200
#
stp enable
#
stp region-configuration
 region-name RG1
 instance 1 vlan 2 to 100
 instance 2 vlan 101 to 200
 instance 3 vlan 201 to 300
#
stp process 1
 stp instance 0 root primary
 stp instance 1 root primary
 stp enable
stp process 2
 stp instance 0 root primary
 stp instance 2 root primary
 stp link-share-protection
 stp enable
#
interface 10GE0/0/1
 portswitch
 port link-type trunk
 port trunk allow-pass vlan 101 to 200
 stp binding process 2 link-share
#
interface 10GE0/0/2
 portswitch
 port link-type trunk
 port trunk allow-pass vlan 101 to 200
 stp binding process 2
 stp root-protection
#
interface 10GE0/0/3
 portswitch
 port link-type trunk
 port trunk allow-pass vlan 2 to 100
 stp binding process 1
#
interface 10GE0/0/4
 portswitch
 port link-type trunk
 port trunk allow-pass vlan 2 to 100
 stp binding process 1
#
return
