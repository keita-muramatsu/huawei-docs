Understanding the KPI Reporting Function

Definition

The KPI reporting function allows APs to report KPI information to a WLAN Maintaining Insight (WMI) server for analysis and monitoring.

Purpose

To improve the efficiency of handling Wi-Fi network problems, you can report AP KPIs to a WMI server for fault cause analysis. In addition, centralized statistics help you better observe the change trends of APs and networks and identify possible AP or network problems in advance.
