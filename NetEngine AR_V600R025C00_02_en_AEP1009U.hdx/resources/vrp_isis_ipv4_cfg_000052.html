Understanding Equal-Cost IS-IS Route Processing Modes

If multiple equal-cost IS-IS routes are available on a network, they can balance traffic, improving link utilization and preventing network congestion caused by link overload. Figure 1 shows the typical networking for load balancing.
Figure 1 Network diagram of load balancing

Devices A, B, C, and D run IS-IS for IP interworking.

They belong to area 10 and are Level-2 routing devices.

Without load balancing, traffic from DeviceA is always transmitted along the optimal route obtained using the SPF algorithm, which may easily result in unbalanced traffic on different links. If load balancing is enabled on DeviceA, traffic to DeviceD is balanced between DeviceB and DeviceC, which relieves the load on the link of the optimal route.

Load balancing can be implemented per packet or per flow. IS-IS supports load balancing among routes in either the same process or different processes.
