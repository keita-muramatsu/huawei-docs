Example for Configuring a Script Assistant for Risk Warning by Saving and Restoring Script Variables

Networking Requirements

As shown in Figure 1, a user manages a device through a remote network. The user hopes that when the arp learning on-different-segment disable command is entered for the first time, a message prompting potential risks is displayed on the terminal and the user is asked to confirm the execution of this command. If the user does not execute this command, the same message is displayed on the terminal when the user enters the command next time. Once the user executes this command, the command is directly executed when the user enters it next time, and no prompt information is displayed.

Figure 1 Networking diagram of risk warning by saving and restoring script variables

Configuration Roadmap

The configuration roadmap is as follows:

  1. Make a Python script riskwarning.py to enable the device to display a warning message when a high-risk command needs to be executed.

  2. Upload the Python script to the device and install the script.

  3. Configure a Python script assistant.

Procedure

  1. Configure an IP address for the specified interface.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] undo portswitch
[DeviceA-10GE0/0/1] ip address 10.1.1.1 24
[DeviceA-10GE0/0/1] quit

  2. Make a Python script.

    # Make a Python script named riskwarning.py to implement the following functions:

    • Register the CLI event to trigger a warning message when a high-risk command needs to be executed.

    • Determine whether to execute the high-risk command based on the user input. If the user does not execute this command, the system asks the user whether to execute the command when the user enters the command next time. Once the user executes this command, the command is directly executed when the user enters it next time, and no prompt information is displayed.

    The following is an example of the Python script:

    # -*- coding: utf-8 -*-
import ops         # Import the ops module.
import sys         # Import the sys module.
import os         # Import the os module.
# Subscription processing function
def ops_condition(_ops):
    # Match the risky command arp learning on-different-segment disable.
    value, err_str = _ops.cli.subscribe("cli1", "arp learning on-different-segment disable", enter=True, sync=True, async_skip=False, sync_wait=60)
    # Clear the script variable value saved last time.
    value1, descri_str1 = _ops.context.retrieve("input")
    return 0

# Work processing function
def ops_execute(_ops):
    # Obtain the system environment variable _cli_vty, which indicates the user channel.
    key, value = _ops.environment.get("_cli_vty")
    # Read user input from the terminal and save the user input as a variable named input. Next time, the input of the user on the terminal is obtained by restoring the script variable.
    value1, descri_str1 = _ops.context.retrieve("input");
    # When a user enters the arp learning on-different-segment disable command for the first time, no risk information is displayed on the terminal. Therefore, value1 = = None is matched.
    # If a user enters a value other than Y or y after the system displays a message indicating that the command has risks when the user enters the arp learning on-different-segment disable command last time, value1 != "Y" and value1 != "y" is matched.
    if (value1 != "Y" and value1 != "y") or value1 == None:
    # Display a message indicating that the command line has risks on the terminal.
        a, b = _ops.terminal.write("The device cannot learn the ARP entries of IP addresses in different network segments. Are you sure to continue?[Y/N]:\n", vty=key)
      # Read user input from the terminal and save the user input as a variable named input.
        value2, descri_str2 = _ops.terminal.read(512, timeout=30, vty=None)
        value3, descri_str3 = _ops.context.save("input", value2)
      # If you enter a value other than Y or y, the arp learning on-different-segment disable command is not executed.
        if value2 != "Y" and value2 != "y":
            return 0
      # If you enter Y or y, the arp learning on-different-segment disable command is executed.
        else:
            return 1
    # After a message indicating that a command has risks is displayed on the terminal, if you enter Y or y, the command is directly executed when you enter the arp learning on-different-segment disable command again, and no message is displayed.
    else:
        value3, descri_str3 = _ops.context.save("input", "Y")
        return 1

  3. Upload the script file to the device and install it.

    # Configure DeviceA as the SFTP client to download the Python script from the SFTP server.

    [DeviceA] sftp 10.2.1.1
Trying 10.2.1.1 ... 
Press CTRL+K to abort 
Connected to 10.2.1.1 ... 
Please input the username:  
Enter password: 
sftp-client> get riskwarning.py
Info: Transfer file in binary mode.
Please wait for a while...
/    2648 bytes transferred
Info: Downloaded the file successfully.

    # Install the Python script on DeviceA.

    [DeviceA] quit
<DeviceA> ops install file riskwarning.py

  4. Configure a script assistant.

    <DeviceA> system-view
[DeviceA] ops
[DeviceA-ops] script-assistant python riskwarning.py
[DeviceA-ops] return

Verifying the Configuration

# Run a risky command and check whether a message is displayed. The risky command specified in the current script is arp learning on-different-segment disable and is executed in the system view.

[DeviceA] arp learning on-different-segment disable
The device cannot learn the ARP entries of IP addresses in different network segments. Are you sure to continue?[Y/N]:
[Warning] The ops script is reading your input,please pay attention to your privacy information!

If you enter N, the device does not execute the arp learning on-different-segment disable command. After the display current-configuration | include arp command is run in any view, the command output does not contain arp learning on-different-segment disable.

If you enter Y, the device executes the arp learning on-different-segment disable command. After the display current-configuration | include arp command is run in any view, the command output contains arp learning on-different-segment disable.
