Configuring a Deployment Email

Prerequisites

  • The controller can send a deployment email to a specified email address.
  • The network administrator has completed network deployment configurations for the site to be deployed on the controller, including gateway selection, and device parameter configuration, as well as WAN-side and LAN-side link parameter configurations.

Before performing email-based deployment, ensure that the physical network connection is normal. If an interface on an LPU is used for email-based deployment, ensure that the LPU has been installed in the correct slot based on the configuration on the controller and the LPU has been registered successfully. Otherwise, the deployment will fail.

Procedure

The deployment email needs to be configured by the network administrator on iMaster NCE-Campus. For details about the configuration procedure, see "Email-based Deployment" in SD-WAN Solution & iMaster NCE-Campus Product Documentation.

After the configuration is complete, the deployment person will receive an email containing the URL for device deployment. The URL is automatically generated based on network parameters such as the network access interface and access mode configured on the controller.
