Configuring Routing Loop Detection for Routes Imported into IS-IS

Prerequisites

Before configuring routing loop detection for routes imported into IS-IS, you have completed the following task:

  • Configure basic IS-IS functions.

Context

When an IS-IS process imports routes, routing loops may occur. If a device on which routing loop detection is enabled for routes imported into IS-IS detects that it imports a route advertised by itself, it sends this route with a large link cost to other devices by default. After receiving this route, these devices preferentially select other paths, preventing routing loops.

Procedure

  1. Enter the system view.

    system-view

  2. (Optional) Exit the routing loop detection alarm state and clear related alarms.

    clear route loop-detect isis alarm-state

    If the device detects an IS-IS routing loop, it reports an alarm. Because the device cannot automatically detect whether the routing loop is eliminated, you need to run this command after the routing loop is eliminated to prevent the device from advertising a large link cost for imported routes and manually clear the IS-IS routing loop alarm. If this command is executed when the routing loop has not been eliminated, the alarm is reported again.

  3. Enable routing loop detection for routes imported into IS-IS.

    route loop-detect isis enable [ alarm-only ]

    To disable routing loop detection for routes imported into IS-IS, run the undo route loop-detect isis enable command.

    The device does not advertise a large link cost when detecting that it has imported a route advertised by itself. Instead, the device reports a loop detection alarm. If the cost is changed, traffic forwarding paths may change accordingly. If the network that has rigid requirements on the traffic forwarding paths, you can configure alarm-only to prevent cost changes. After alarm-only is configured, the cost is not increased. To prevent routing loops in this case, you need to properly plan configurations when handling related alarms.
