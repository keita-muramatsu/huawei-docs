Configuring Dynamic Subscription

Before performing the following configurations, ensure that the device supports the HTTP service. You are advised to use the more secure SSL protocol.

The following provides a simple example of the dynamic subscription configuration. For details, see Configuring Dynamic Subscription.

Typical CLI Configuration

Description

#

grpc

#

grpc server

server-port 10000

source-ip 10.1.1.1

server enable

#

Configure the port number used by the device to function as a server.

Configure the IP address used by the device to function as a server.

Enable the gRPC service.

The configuration information (for example, ConfigeData.xml) of the collector is as follows:

<?xml version="1.0" encoding="GB2312"?>   
<RESULT>   
<VALUE>   
  <NO>1</NO> 
  <REQUEST_ID>1111</REQUEST_ID> 
  <ENCODING>0</ENCODING> 
  <PORT>10000</PORT> 
  <IP>10.1.1.1</IP> 
  <USERNAME>username</USERNAME> 
  <PASSWORD>password</PASSWORD> 
  <PATH>huawei-ifm:ifm/interfaces/interface</PATH> 
  <SAMPLEINTERVAL>1000</SAMPLEINTERVAL> 
</VALUE>   
</RESULT>

After the configuration is complete, the collector initiates a gRPC connection with the device through dynamic subscription to request RPC. The device then pushes the collected data to the collector.
