Configuring Traffic Optimization on an AP's Wired Interface

Context

When an AP's wired interface needs to forward a large number of packets, network congestion may easily occur, deteriorating the performance of the AP's wired interface. You can configure traffic limiting and TCP properties on an AP's wired interface to adjust traffic on the interface in real time, reducing the impact of a large number of packets on the interface and improving network performance.

When a large number of broadcast, multicast, or unknown unicast packets are transmitted on a network, a lot of network resources are occupied, affecting normal network services. When the traffic volume of these packets reaches the maximum value on an AP's wired interface, the system discards excess packets to control the traffic volume in a proper range, thereby preventing flooding attacks.

Exercise caution when configuring the rate limit if there are multicast services on the network, as this may affect the multicast services.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP wired port profile and enter its view.

    wired-port-profile name wired-port-profile-name

    By default, the AP wired port profile default exists on the device.

  4. Configure traffic optimization on an AP's wired interface.

    • Configure the maximum volume of broadcast, multicast, or unicast packets allowed on an AP's wired interface.
      traffic-optimize { broadcast-suppression | multicast-suppression | unicast-suppression } packets packets-rate

      By default, the broadcast, multicast, or unknown unicast traffic is not suppressed on an AP's wired interface.

    • Configure the maximum segment size (MSS) of TCP packets on an AP's wired interface.
      traffic-optimize tcp adjust-mss value

      By default, the MSS of TCP packets is not configured in the AP wired port profile.

Follow-up Procedure

After the configuration is complete, bind the AP wired port profile to an AP group or a specific AP so that the configuration in the profile can take effect. For configuration details, see Binding an AP Wired Port Profile.
