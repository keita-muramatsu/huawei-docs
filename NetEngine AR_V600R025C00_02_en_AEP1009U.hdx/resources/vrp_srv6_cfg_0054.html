Configuring Network Slice-based Route Forwarding

After SRv6 BE services are configured, they can be forwarded through network slices. You can associate services with forwarding resources through a slice ID by associating a route color with the slice ID.

Prerequisites

Before associating a route color with a slice ID, complete the following task:

  • Configure SRv6 BE services, including BGP L3VPN, EVPN L2VPN, EVPN L3VPN, and public network IP services. For details, see Example for Configuring EVPN L3VPNv4 over SRv6 BE.

Context

A slice ID connects the control and forwarding planes. After the association between a route color and slice ID is configured, if services recurse to an SRv6 BE path, they are forwarded along this path. During data forwarding, the ingress encapsulates the HBH header (which carries the slice ID corresponding to the route color) and the IPv6 basic header into a packet. The ingress then finds the network slice interface based on the slice ID and forwards the packet over this interface.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the network slice instance and color mapping view.

    network-slice color-mapping

  3. Associate a route color with a slice ID.

    color index network-slice sliceId
