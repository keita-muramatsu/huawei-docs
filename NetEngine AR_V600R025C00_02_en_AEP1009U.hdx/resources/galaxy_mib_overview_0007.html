SNMP Packet Processing

An agent receives request packets from the NMS through UDP port 161.

The agent processes a received packet as follows:

  1. Decoding: Based on ASN.1 encoding rules, the agent generates a packet that is represented in the internal data structure. If errors result in a decoding failure, the agent discards the packet.

  2. SNMP version comparison: The agent compares the SNMP version in the received packet with the SNMP version supported by itself. If they are inconsistent, the agent discards the packet and no further action is taken.

  3. Community name verification: The agent obtains the community name, which is provided by the NMS that sent the packet. If the community name is not supported, the agent discards the packet and returns a trap packet to the NMS.

  4. PDU obtaining: The agent obtains the SNMP PDU from the authenticated ASN.1 object. If the operation fails, the agent discards the packet and no further action is taken.

  5. PDU processing: The agent handles the PDU according to its SNMP entity. Specifically, the agent searches the MIB tree for an object that maps the variable to be managed. It then obtains the variable value from the corresponding module. After that, the agent generates the response and returns it, encoded, to the NMS.

  6. The NMS performs the same operations as the agent and displays the final result.

For details about the SNMP configuration, see "SNMP Configuration" in CLI Configuration Guide > System Management Configuration.
