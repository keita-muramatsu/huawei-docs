Relationship Between Security Configuration and Security Hardening

Security hardening is to analyze and fix the vulnerabilities of host systems (involving common components such as the operating system, database, and network platform), application systems, network devices, and security devices, and enhance their security. Security hardening measures include version and patch repair, configuration modification, and security configuration baseline check for host systems, application systems, network devices, and security devices.

Security configuration is a part of security hardening. During product operation, maintenance, and troubleshooting, various configurations (including security configurations) need to be modified, which affects product security. Therefore, you need to check security configurations during routine maintenance to detect security configuration risks in a timely manner.
