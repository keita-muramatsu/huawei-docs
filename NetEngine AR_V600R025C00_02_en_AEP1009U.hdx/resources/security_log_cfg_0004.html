Log Types

The device can output multiple types of logs, each with different functions:

  • Session logs

    After processing a packet, the device sets up a session for it. The device can output session information.

  • System logs

    The device can output the operating information about function modules. You can refer to the Log Reference to learn about system log information generated by the function modules on the device.

  • Service logs

    The device identifies and controls traffic based on applications and services, and records logs.
