AP Wired Port Profile

Overview

An AP wired port profile allows you to configure an AP's wired interface. After an AP wired port link profile is bound to the AP wired port profile, you can set link-layer parameter settings on the AP's wired interface.

For details about the configuration supported in an AP wired port profile, see "Configuring an AP's Wired Interface" in CLI Configuration Guide > WLAN Configuration > AP Management.

Creating a Profile

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP wired port profile and enter its view.

    wired-port-profile name wired-port-profile-name

    By default, the AP wired port profile default exists on the device.

Applying a Profile

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Enter the AP view or AP group view.
    • Enter the AP group view.
      ap-group name group-name
    • Enter the AP view.
      ap-id ap-id
  4. Bind an AP wired port profile to an AP group or a specific AP.

    wired-port-profile profile-name interface-type interface-number

    By default, the AP wired port profile default is bound to an AP group, but no AP wired port profile is bound to an AP.
