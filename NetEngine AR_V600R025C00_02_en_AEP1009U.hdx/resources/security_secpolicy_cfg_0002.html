Overview of Security Policies

Definition

A security policy is used to check the data flows passing through a device and control its traffic forwarding. Figure 1 shows the implementation of security policies.

Figure 1 Traffic control based on security policies

A security policy defines a particular set of control rules that contain specific matching conditions (such as 5-tuple and time range) and actions. When receiving traffic, a device identifies traffic attributes (such as 5-tuple and time range) and matches them against the conditions specified in a security policy. If all the conditions are met, the traffic matches the security policy. The device then takes the action specified in the security policy.

  • If the action is Permit, the device processes the traffic as follows:
    • If content security detection is not configured, the device permits the traffic.
    • If content security detection is configured, the device determines whether to permit the traffic based on the content security detection result.

  • If the action is Deny, the device does not allow the traffic to pass through.

Purpose

You can configure security policies to control network access behavior, protect a specific network against attacks from an "untrusted" network, and allow legitimate communication between two networks.
