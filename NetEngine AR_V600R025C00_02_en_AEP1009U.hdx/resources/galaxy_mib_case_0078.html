Querying the IP Address of an Interface

Description of MIB Objects

You can query ifDescr and the corresponding ifIndex in ifTable to obtain the mapping between the corresponding interface and its index.

You can use ipAdEntIfIndex in ipAddrTable to obtain the IP addresses of all interfaces, and then use ifIndex to query the IP address of an interface.

Object

OID

ifIndex

1.3.6.1.2.1.2.2.1.1

ifDescr

1.3.6.1.2.1.2.2.1.2

ipAdEntIfIndex

1.3.6.1.2.1.4.20.1.2

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.
  2. Perform the Walk operation on ifDescr to query the entity index ifIndex. As shown in Figure 1, the index of 100GE0/0/1 is 7.
    Figure 1 Obtaining the mapping between an interface and its index
  3. Perform the Walk operation on ipAdEntIfIndex to query the IP address of the corresponding interface based on the value of ifIndex. As shown in Figure 2, the IP address of 100GE0/0/1 with the index of 7 is 1.1.1.1.
    Figure 2 Querying the IP address of an interface
