Configuring PoE for an RU

Context

Some PDs can be powered on only after the PoE power supply is configured.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the single RU view.

    remote-unit { id | connect-interface interface-type interface-number | name remote-unit-name }

  3. Set PoE parameters for the RU.

    • Configure the power supply mode for the RU interface.
      poe { at-inrush | af-inrush } enable port port-id

      RU interfaces that support PoE++ use this mode (also referred to as the bt-inrush mode) by default. Interfaces that do not support PoE++ use the at-inrush mode. To check the default power supply mode of an RU, run the display remote-unit port poe command.

      For PDs requiring the standard power supply mode, you can run the poe at-inrush enable port command to configure PoE interfaces to work in PoE+ power supply mode.

      Some non-IEEE-standard PDs do not support high-current power supply, and instead only support low-current power supply. To ensure these PDs can be successfully powered on, you can run the poe af-inrush enable port command to configure PoE interfaces on RUs to work in 802.3af power supply mode.

    • Set the power supply delay for the RU interface.
      poe power-on delay delay-time port port-id

      The holding current of a non-standard PD is insufficient in the moment it is powered on. So, an RU assumes that the PD has been disconnected and powers it off. To solve this problem, you can set the power supply delay for RU interfaces on the central device. When the delay expires, the RUs detect the holding current to ensure that non-standard PDs can be properly powered on.

    • Enable forcible PoE power supply on the RU interface.
      poe force-power port port-id

      If the system power is sufficient, you can run this command to enable forcible power supply on RU interfaces connected to non-standard PDs when the RU, as the PSE, cannot detect the PDs.

    • (Optional) Configure the PoE anti-interference frequency.
      poe anti-interference frequency { 50 | 60 }

      The default PoE anti-interference frequency is 50 Hz.

      To use the PoE function in countries or regions where the utility frequency is 60 Hz, run the poe anti-interference frequency 60 command to configure the PoE anti-interference frequency.

  4. (Optional) Disable the PoE function on the downlink interface of the RU.

    poe disable port port-id

    By default, the PoE function is enabled on the downlink interface of the RU. To stop the power supply to a PD, you can run this command to disable the PoE function on the corresponding interface.

    This command can be delivered only to S5751-L series RUs.

  5. Deliver the configuration to the RU.

    commit
