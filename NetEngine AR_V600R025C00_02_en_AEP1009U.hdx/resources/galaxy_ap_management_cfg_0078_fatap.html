Checking Connectivity Between an AP and Network Devices

Context

When a network fault occurs, use an AP to ping other network devices to check the connectivity.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Configure an AP to ping a network device to check the connectivity between the AP and network device.

    ap-ping ap-id ap-id [ -c count | -s packetsize | -m time | -t timeout ] * host

  4. Check the ping progress and result.

    display ap-ping status
