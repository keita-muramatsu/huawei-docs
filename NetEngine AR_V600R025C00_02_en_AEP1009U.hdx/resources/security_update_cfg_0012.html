Configuring Offline Signature Database Update

Prerequisites

The operations in Preparations for Signature Database Update have been completed.

Context

If the device is isolated from the Internet and cannot directly access the update server at the Huawei Intelligent Security Center, you can update the signature database using the offline update function, as shown in Figure 1.

Figure 1 Offline signature database update

The geolocation database can be updated only in offline mode.

Procedure

  1. Download the signature database file of the latest version.
    1. Log in to the Huawei Intelligent Security Center (isecurity.huawei.com) and choose Security Signature Update > Downloading the Signature Database and Component Package.
    2. Select the type, series, name, and version of your product.
    3. Click the tab for the signature database to be updated and download the corresponding signature database file.
  2. Upload the signature database file to the root directory of the device.

    The signature database file is in .zip format and does not need to be decompressed. You can upload the file to the root directory (flash:/) of the device using FTP, SFTP, or TFTP. For details, see "File System Management" in the CLI Configuration Guide > Basic Configuration.

  3. Enter the system view.

    system-view

  4. Configure the device to perform an offline update using the signature database file in the root directory.

    update local { av-sdb | ips-sdb | sa-sdb } file file-name
update local location-sdb file file-name

    For the AR5700 series, only the AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S and AR5710-S10T1X2 do not support the ips-sdb and av-sdb parameters.

  5. Optional: Configure forcible offline signature database update.

    update force local { av-sdb | ips-sdb | sa-sdb } file file-name

    For the AR5700 series, only the AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S and AR5710-S10T1X2 do not support the ips-sdb and av-sdb parameters.

    If there is insufficient system memory for the signature database update, the update fails. In this case, you can run this command to forcibly update the signature database. After the command is executed, the ASE does not take effect in a short period of time and all ASE-related session entries are reset. Exercise caution when running this command.
