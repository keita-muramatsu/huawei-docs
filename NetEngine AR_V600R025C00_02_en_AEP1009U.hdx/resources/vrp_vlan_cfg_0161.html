Configuring a Voice VLAN (Identifying Voice Packets Based on VLAN IDs)

Context

When VLAN ID-based voice VLAN is configured, the device considers packets received by an interface as voice packets and increases the packet priority if the VLAN ID in the packets is the same as the voice VLAN ID configured in the system.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the interface view.

    interface interface-type interface-number

  3. Change the interface working mode from Layer 3 to Layer 2.

    portswitch

    Determine whether to perform this step based on the current interface working mode.

  4. Configure a VLAN as a voice VLAN and enable the voice VLAN function on the interface.

    voice-vlan vlan-id enable [ include-untagged ]

  5. Configure the interface to increase the priority of voice packets based on VLAN IDs.

    voice-vlan remark-mode vlan

  6. Add interfaces to VLANs. For details, see Configuring Interface-based VLAN Assignment (Statically Configuring the Interface Type).
  7. Enable LLDP to advertise voice VLAN information to IP phones.

    quit
lldp enable
interface interface-type interface-number
undo lldp disable

    By default, LLDP is disabled globally. After LLDP is enabled globally, LLDP is enabled on interfaces by default.
