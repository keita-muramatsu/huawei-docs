(Optional) Configuring a Trap Message Sending Method for IP-Trunk Member Interfaces

You can configure IP-Trunk member interfaces to send trap messages through a private message information base (MIB).

Context

Perform the following steps on the device where an IP-Trunk interface has been created.

Procedure

  1. Enter the system view.

    system-view

  2. Configure the device to use the private MIB to send a trap message when the status of an IP-Trunk member interface changes to up or down.

    trunk-member trap in private-mib enable

    By default, the device uses the public MIB to send a trap message when the status of an IP-Trunk member interface changes to up or down.

    The trap message sent through the public MIB does not carry information about the IP-Trunk interface. If you want such a trap message to carry IP-Trunk interface information, run this command to configure the device to send trap messages through the private MIB.
