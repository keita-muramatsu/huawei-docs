POST

The POST method is used by the client to create configuration or invoke a remote procedure call (RPC) operation. It carries operation parameters through the message-body of the HTTP message.

The server uses the target resource type to determine how to process the request.
  • If the target resource type is YANG-defined configuration, the POST operation is used to create configuration.
  • If the target resource type is YANG-defined RPC method, the POST operation is used to invoke an RPC operation.
Table 1 POST operation methods

Target Resource Type

URI Format

Description

Configuration

/restconf/data/identifier

Creates data and returns the specific state. identifier specifies the data node on which data will be stored.

RPC operation

/restconf/operations/moduleName:rpcName
Invokes a YANG-defined RPC operation.
  • moduleName specifies a module name.
  • rpcName specifies the name of a YANG-defined RPC operation.
