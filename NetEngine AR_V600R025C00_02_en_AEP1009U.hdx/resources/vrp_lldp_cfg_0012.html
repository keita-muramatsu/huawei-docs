Default Settings for LLDP

Table 1 describes the default settings for LLDP.

Table 1 Default settings for LLDP

Parameter

Default Setting

LLDP function

This function is globally disabled.

Management IP address advertised in LLDP frames

The management IP address is automatically obtained and is not bound to any interface.

Type of TLVs that can be advertised by LLDP

All types of TLVs except Protocol Identity TLVs

Interval for sending LLDP frames

30s

Delay in sending LLDP frames

2s

Hold time multiplier of device information on neighbors

4

Delay in initializing interfaces

2s

Number of LLDP frames quickly sent by the device to a neighbor

4

Delay in sending a notification after neighbor information changes

5s
