Overview of IPsec

Definition

Internet Protocol Security (IPsec) is a suite of protocols developed to ensure IP network security by enabling two devices to establish an IPsec encrypted tunnel, through which data is securely forwarded.

IPsec is classified into point-to-point IPsec and point-to-multipoint IPsec based on networking requirements. Point-to-point IPsec is used to establish an IPsec tunnel between two devices, in order to secure point-to-point communication between two LANs, as shown in Figure 1.

Figure 1 Point-to-point IPsec

Point-to-multipoint IPsec is used to establish IPsec tunnels between one device and multiple devices, in order to secure communication between one LAN and multiple LANs, as shown in Figure 2.

Figure 2 Point-to-multipoint IPsec

Purpose

As the Internet rapidly develops, enterprises increasingly connect their LANs to the Internet. A large number of untrusted users and network devices exist on the Internet. Because IP does not provide security functions, the security of IP packets cannot be ensured. When service data between different LANs of an enterprise traverses the Internet, the data may be forged, tampered with, or stolen. IPsec secures the IP layer and effectively prevents data security risks when service data between enterprises traverses the Internet.

Benefits

IPsec uses encryption and authentication to provide secure transmission of IP packets. It provides the following security services:

  • Data encryption

    The sender encrypts data and transmits it in cipher text on the Internet. The receiver decrypts the received data and then processes or directly forwards the decrypted data.

  • Data integrity

    The receiver authenticates received data to ensure that it has not been tampered with during transmission.

  • Data origin authentication

    The receiver authenticates the sender to ensure that the data has been received from a valid source.

  • Anti-replay

    The receiver rejects old or duplicate packets in order to prevent attacks initiated by malicious users resending obtained packets.
