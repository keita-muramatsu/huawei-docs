Configuring Open Authentication

Context

Security policies support open authentication.

Open authentication in a WLAN security policy indicates that there is no authentication and no encryption, and allows any STA to access the WLAN without authentication. Therefore, it is recommended that another authentication mode be deployed together with open authentication, so that STAs can access the network and devices only after successful authentication.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a security profile and enter its view.

    security-profile name profile-name

    By default, the security profile default exists in the system.

  4. Configure open authentication in the security policy.

    security open

    By default, no security policy is configured.
