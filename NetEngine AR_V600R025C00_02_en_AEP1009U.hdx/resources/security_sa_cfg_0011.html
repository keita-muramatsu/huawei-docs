(Optional) Configuring an Application Group

Context

To simplify policy configuration, applications with the same management and control requirements can be added to an application group on a device, and the application group can then be directly referenced in policy rules.

Procedure

  1. Enter the system view.

    system-view

  2. Create an application group and enter the application group view.

    application-group name application-group-name

  3. Optional: Configure a description for the application group.

    description description

  4. Add applications to the application group.

    add application application-name

Verifying the Configuration

Run the display application-group { name application-group-name | all } command to check the configuration of the application group.

Follow-up Procedure

The created application group can be applied in specific features. For details, see configuration documents of specific features.
