Configuring Multi-CA Authentication

Prerequisites

  • Multi-CA authentication takes effect only for RSA-based digital signature certificate authentication.
  • Multi-CA authentication takes effect only for template IPsec policies.

Context

When a template IPsec policy uses RSA signature authentication for IKE negotiation, you can configure multi-CA authentication and set the certificate request payload to empty to allow branches that use the certificates issued by different CA authorities to access the headquarters. The headquarters then performs certificate authentication in the PKI realms to which certificates are imported based on certificate information of branches.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the IKE peer view.

    ike peer peer-name

  3. Configure multi-CA authentication.

    certificate-request empty-payload enable

    By default, multi-CA authentication is disabled, and the certificate request payload sent by the device contains CA information.
