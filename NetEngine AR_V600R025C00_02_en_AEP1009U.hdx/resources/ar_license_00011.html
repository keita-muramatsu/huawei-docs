Uninstalling a License

Context

You can uninstall an unneeded license file to free up the storage space of the device.

Procedure

  1. Run the license revoke command in the user view so that the license to be uninstalled enters the Trial state.
    <HUAWEI> license revoke 
Warning: The license will enter the Trial state and will not be activated again. Continue? [Y/N]:y, 
Info: Succeeded in revoking the license. The revoke ticket is xxxx.
  2. Upload and activate a new license file. For details, see Installing a License.
  3. Run the delete filename command in the user view to delete the license file to be uninstalled.

    If the license file is not activated, skip Step 1 and Step 2, and run the delete filename command to delete the license file.
