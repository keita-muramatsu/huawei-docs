Configuring LLDP for an RU

Context

When LLDP is enabled on a device, the device sends LLDP packets carrying its status information to its LLDP-enabled neighbors and obtains their status information by receiving LLDP packets from them.

This function can be configured only for S5751-L series RUs.

Procedure

  • Configure LLDP in the global RU view.
    1. Enter the system view.
      system-view
    2. Enter the global RU view.
      remote-unit
    3. Enable LLDP globally on RUs.
      undo lldp disable

      By default, LLDP is enabled on an RU.

    4. Deliver the configuration to all RUs.
      commit all
  • Configure LLDP in the single RU view.
    1. Enter the system view.
      system-view
    2. Enter the single RU view.
      remote-unit { id | connect-interface interface-type interface-number | name remote-unit-name }
    3. Enable or disable LLDP on the RU.
      lldp { enable | disable }

      By default, LLDP is not configured for a single RU, and the configuration in the global RU view is used. If LLDP is enabled or disabled in the single RU view, the configuration in the single RU view is used.

    4. Deliver the configuration to the RU.
      commit

Verifying the Configuration

  • Run the display remote-unit lldp neighbor { connect-interface { interface-type interface-number | interface-name } | name remote-unit-name } [ port portid ] command to check the neighbor status of all or specified RUs on a device.
  • Run the display remote-unit lldp neighbor { connect-interface { interface-type interface-number | interface-name } | name remote-unit-name } brief command to display brief information about neighbors of an RU.
