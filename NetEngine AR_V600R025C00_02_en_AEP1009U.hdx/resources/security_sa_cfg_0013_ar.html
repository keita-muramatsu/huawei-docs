(Optional) Configuring IP Database-based Application Identification

Prerequisites

You can update an SA-SDB to obtain the latest predefined applications.

Context

The current IP database contains signatures of six types of common OA applications, such as Office 365 and Microsoft Teams. After this function is enabled, such applications can be identified based on the IP address of the first packet, enabling management and control of their traffic. By default, an IP database has been loaded to an SA-SDB. If IP database-based application identification is disabled, only application signature information except the IP database in the SA-SDB can be used for application identification. After IP database-based application identification is enabled, the entire SA-SDB is used for application identification.

For AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S10T1X2 , AR5710-S8T2S, this feature is not supported.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the SA view.

    sa

  3. Enable IP database-based application identification.

    ip-identification enable

Follow-up Procedure

  • Run the display sa ip-info [ ip-address ip-address | slot slot-id cpu cpu-id ] command to check information about applications in a specified IP database.
  • Run the delete sa ip-info ip-address ip-address command to delete an application with a specified IP address from the IP database.
