Configuring a Cellular Profile

Context

You need to create a cellular profile and set basic cellular network parameters in the profile.

For the SIC-NRGL-V2 subcard, AR5710-H2T4N2X-NRGL, AR5710-H2T4PN2X-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8P2XE-NRGL, AR5710-S8T1XWE-NRGL, the device generates the following configurations by default:

ip vpn-instance _wanu_server_manage_
ipv4-family
interface cellular interface-number
wan-unit enable
ip binding vpn-instance _wanu_server_manage_
ip address ip-address mask-length
dhcp select interface

You are advised not to modify the default configurations. Otherwise, the module may go offline.

Procedure

  1. Enter the system view.

    system-view

  2. Create a cellular profile and enter its view.

    cellular-profile profile-name

    By default, no cellular profile is created.

  3. Configure the network connection mode of the cellular modem.

    mode { auto | wcdma-only | lte-only | lte-wcdma | nr-only | nr-lte }

    By default, the network connection mode of a cellular modem is auto. This means that the modem automatically identifies the currently connected network. For example, if both a 4G card and a 4G SIM card are installed on the device and the auto mode is used, the device preferentially connects to an available 4G network. When no 4G network is available, the device connects to a 3G network. You can select the following modes:

    • auto: The device automatically connects to the 3G/4G/5G network.
    • wcdma-only: The device connects to only the 3G network.
    • lte-only: The device connects to only the 4G network.
    • lte-wcdma: The device connects to only the 4G or 3G network.
    • nr-only: The device connects to only the 5G network.
    • nr-lte: The device connects to only the 5G or 4G network.

    Only devices that support the 5G function support the nr parameter.

    Only devices that support the 4G function support lte parameters.

    Only devices that support the 3G function support wcdma parameters.

  4. (Optional) Configure the default APN for the cellular network.

    apn-profile default-bearer apn-name [ user username password password authentication-mode { pap | chap } ] sim-id sim-id

    By default, no default APN is configured. Some carriers need this to be configured for network access.

    After the default APN is configured, the interface uses the default APN to set up a dial-up connection.

  5. (Optional) Configure the international mobile subscriber identity (IMSI) of the SIM card for which dial-up is allowed.

    permit imsi imsi

    By default, dial-up is allowed for all SIM cards. If the IMSI of the current SIM card is the same as that configured using the preceding command, the SIM card can be used for dial-up. Otherwise, dial-up will not be triggered.

  6. Return to the system view.

    quit
