Example for Deploying an Intelligent Simplified Campus Network (Terminals Connected to the Same VLAN)

Networking Requirements

An enterprise builds an office building to meet service development requirements. Each office in the building needs to be equipped with one to four PCs.

Device deployment solution: To simplify the network architecture, deploy an intelligent simplified campus network. As shown in Figure 1, deploy a central device (DeviceA) in the ELV room of the office building, and deploy an RU (RUn, where n indicates a room number) in the ELV box of each office. The RUs are connected to the central device through a single link and managed by the central device. In addition, add the PCs in the building to VLAN 1300 for communication based on network planning.

Figure 1 Networking for RU deployment in the office building

In this example, interface1, interface2, interface3, interface4, and interface5 on DeviceB represent 10GE0/0/1, 10GE0/0/2, 10GE0/0/3, 10GE0/0/4, and 10GE0/0/5, respectively.


Configuration Roadmap

This example only provides the configurations for RUs connected to DeviceA. Other configurations are not provided. DeviceB (RU101) is used as an example. The configuration roadmap is as follows:

  1. The RU obtains power locally. Connect the RU to the central device, and onboard the RU in plug-and-play mode.
  2. Bind an interconnection interface for each RU on the central device and configure interface isolation for the RU.
  3. On the central device, configure the interfaces for connecting to the RU and add the interfaces to VLAN 1300.

Procedure

  1. Connect the uplink port of each RU to the central device and check whether the RUs are successfully online.

    # Check the RU status. Normal indicates that the RU is running properly.

    <HUAWEI> system-view 
[HUAWEI] sysname DeviceA 
[DeviceA] display remote-unit

Total: 4, printed: 4
  2. Configure the interconnection interfaces and interface isolation for the RUs.

    # Bind the interconnection interfaces for the RUs on the central device.

    [DeviceA] remote-unit 0
[DeviceA-remote-unit-0] name RU101
[DeviceA-remote-unit-0] description RU101_10ge0/0/1
[DeviceA-remote-unit-0] bind interface 10GE0/0/1
[DeviceA-remote-unit-0] quit
[DeviceA] remote-unit 1
[DeviceA-remote-unit-1] name RU102
[DeviceA-remote-unit-1] description RU102_10ge0/0/2
[DeviceA-remote-unit-1] bind interface 10GE0/0/2
[DeviceA-remote-unit-1] quit
[DeviceA] remote-unit 2
[DeviceA-remote-unit-2] name RU103
[DeviceA-remote-unit-2] description RU103_10ge0/0/3
[DeviceA-remote-unit-2] bind interface 10GE0/0/3
[DeviceA-remote-unit-2] quit
[DeviceA] remote-unit 3
[DeviceA-remote-unit-3] name RU104
[DeviceA-remote-unit-3] description RU104_10ge0/0/4
[DeviceA-remote-unit-3] bind interface 10GE0/0/4
[DeviceA-remote-unit-3] quit

    # Configure interface isolation in the global RU view and deliver the configuration to the RUs.

    [DeviceA] remote-unit
[DeviceA-remote-unit] isolate enable
[DeviceA-remote-unit] commit all
[DeviceA-remote-unit] quit
  3. Create a VLAN and configure the allowed VLAN for the interfaces. For example, add the interconnection interface 10GE0/0/1 to VLAN 1300. The configurations for other interconnection interfaces are similar.
    [DeviceA] vlan 1300
[DeviceA] interface 10GE0/0/1
[DeviceA-10GE0/0/1] description to_RU101
[DeviceA-10GE0/0/1] portswitch
[DeviceA-10GE0/0/1] port link-type hybrid
[DeviceA-10GE0/0/1] port hybrid pvid vlan 1300
[DeviceA-10GE0/0/1] port hybrid untagged vlan 1300
[DeviceA-10GE0/0/1] quit
  4. Configure the allowed VLAN for the uplink port of the central device.
    [DeviceA] interface 10GE0/0/5
[DeviceA-10GE0/0/5] portswitch
[DeviceA-10GE0/0/5] port link-type trunk
[DeviceA-10GE0/0/5] port trunk allow-pass vlan 1300
[DeviceA-10GE0/0/5] quit
