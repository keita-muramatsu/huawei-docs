Configuring Dynamic EDCA Adjustment for a Radio

Prerequisites

Before performing the configuration, you have completed the following task:
  • Configure AP onboarding and STA access.

Context

Adjust WMM EDCA parameter settings as follows:
  • Manual adjustment: allows you to manually adjust EDCA parameter settings.
  • Dynamic adjustment: The dynamic EDCA parameter adjustment function detects the traffic volume of access categories (ACs) and flexibly adjusts physical channel contention parameters to reduce the probability of collisions. This greatly increases the overall throughput and improves user experience.

If dynamic EDCA parameter adjustment is configured when you manually adjust EDCA parameters, the dynamic adjustment function takes effect preferentially.

For details about manual EDCA parameter adjustment, see Configuring EDCA Parameters.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an RRM profile and enter its view.

    rrm-profile name profile-name

  4. Enable dynamic EDCA parameter adjustment.

    dynamic-edca enable

    By default, dynamic EDCA parameter adjustment is disabled.

  5. Bind the RRM profile.

    Bind the RRM profile to an AP group or a single AP so that the configuration in the profile can take effect. For details, see RRM Profile.

Verifying the Configuration

  • Run the display rrm-profile name profile-name command to check settings of dynamic EDCA parameter adjustment in an RRM profile.
