Configuring an APN Profile

Context

The device can access multiple types of external network services. You can configure APN information to define which network service types the device can access.

The device supports multiple SIM cards and multiple service types, allowing for various usage scenarios, such as a single SIM card and a single network, a single SIM card and two networks, or two SIM cards.

  • Scenario: Single SIM Card and Single Network

    In Figure 1, the device has one SIM card installed, uses one cellular channel interface, and is bound with APN1 to connect to the Internet.

    Figure 1 Connecting a user device to the Internet
  • Scenario: Single SIM Card and Two Networks

    In Figure 2, the device has one SIM card installed and uses two cellular channel interfaces. Cellular channel interface 1 is bound with APN1 to connect to the IMS network. Cellular channel interface 2 is bound with APN2 to connect to the Internet.

    Figure 2 Connecting to two networks through two cellular channel interfaces
  • Scenario: Two SIM Cards

    In Figure 3, the device has two SIM cards from different carriers installed and uses one cellular channel interface, and two APN profiles are configured on the cellular channel interface. APN1 is bound to the active SIM card to generate a primary link for connecting to the Internet. APN2 is bound to the standby SIM card to generate a secondary link for connecting to the Internet. If dial-up fails, traffic is automatically switched to the standby SIM card. (Dial-up may fail because the active SIM card enters the no-service state, fails, or has poor link signal quality. It may also fail because the connected network is faulty.) In this way, the impact on user services is minimized.

    Figure 3 Connecting to the Internet using two SIM cards in active/standby mode
    • Currently, only dual-card single-standby is supported. That is, only one SIM card can work at a time.
    • During the SIM card switchover, traffic is interrupted for a short time.

Procedure

  1. Enter the system view.

    system-view

  2. Create and configure an APN profile. To create multiple APN profiles, repeat this step.
    1. Create an APN profile and enter its view.

      apn-profile profile-name

      By default, no APN profile is created.

    2. Configure the APN name.

      apn apn-name

      By default, a device uses the APN profile name as the APN name. To get an APN name, contact the carrier.

    3. (Optional) Associate the APN profile with a SIM card.

      sim-id sim-id

      By default, no SIM card is specified.

      The value of sim-id can be 1 (active SIM card) or 2 (standby SIM card).

    4. (Optional) Configure the user name, password, and authentication mode for accessing the network identified by an APN.

      user name username password password [ authentication-mode { auto | pap | chap } ]

      By default, the user name, password, and authentication mode for accessing a network identified by an APN are not configured. To get the user name, password, and authentication mode, contact the carrier.

      PAP authentication has low security. If you select auto or pap, the password is sent in cleartext on the network. This poses security risks. You are therefore advised to select chap. Select an authentication mode based on carrier network requirements.

      For security purposes, change the password periodically.

    5. Return to the system view.

      quit

Verifying the Configuration

  • Run the display apn-profile configuration [ apn-profile-number ] command to check the APN profile configuration.

Follow-up Procedure

To manually switch between SIM cards if automatic SIM card switchover is not configured or the switchover condition is not met, you can run the sim switch to sim-id command in the cellular interface view.
