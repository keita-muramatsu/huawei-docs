Verifying Streamlined USB-based Deployment

Procedure

  1. After the streamlined USB-based deployment is completed, log in to the device to check the NETCONF connection status between the device and iMaster NCE-Campus.

    display netconf session

Follow-up Procedure

If deployment fails, analyze USB logs on the device to determine the cause. ZTP-related logs are saved in the ztp_YYYYMMDDHHMMSS.log file in the flash:/ directory and in the ztp_esn_YYYYMMDDHHMMSS.log file in the root directory of the USB flash drive.

You can run the display device esn command to obtain the ESN of a device.
