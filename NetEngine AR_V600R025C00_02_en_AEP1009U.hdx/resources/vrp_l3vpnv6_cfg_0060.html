Configuring MP-IBGP Between PEs

Context

If VPN sites in a basic IPv6 L3VPN need to communicate, PEs must use MP-IBGP to advertise VPNv6 routes carrying the RD attribute to each other. Because all the PEs reside in the same AS, MP-IBGP peer relationships can be set up between them. In the current implementation, IPv4 BGP peer relationships are set up between PEs.

Perform the following steps on each PE.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the BGP view.

    bgp as-number

  3. Configure the remote PE as a peer.

    peer ipv4-address as-number as-number

  4. Specify an interface for setting up a TCP connection with the BGP peer.

    peer ipv4-address connect-interface loopback interface-number

    A PE must use a loopback interface address with a 32-bit mask to set up an MP-IBGP peer relationship with the peer PE so that VPN routes can recurse to tunnels. The route to the local loopback interface is advertised to the peer PE using IGP on the MPLS backbone network.

  5. Enter the BGP-VPNv6 address family view.

    ipv6-family vpnv6

  6. Enable the function to exchange VPN-IPv6 routes with the peer.

    peer ipv4-address enable
