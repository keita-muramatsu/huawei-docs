Configuring Intelligent Flow Control for APs

Prerequisites

Before performing the configuration, you have completed the following task:
  • Configure AP onboarding and STA access.

Context

When there are a large number of broadcast, multicast, and unknown unicast packets, the CPU becomes busy processing these packets and the buffer of the packet receiving queue decreases. When the traffic rate reaches the threshold, the device automatically limits the rates of broadcast, multicast, and unknown unicast packets within the specified range. You can specify the rate limit for intelligent flow control as required. Rate limiting takes effect only for incoming upstream and downstream traffic.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP system profile and enter its view.

    ap-system-profile name profile-name

    By default, the AP system profile default exists in the system.

  4. Configure the rate limit for broadcast traffic.

    broadcast-suppression auto-detect packets packets

    The default rate limit for broadcast traffic is 256 pps.

  5. Configure the rate limit for multicast traffic.

    multicast-suppression auto-detect packets packets

    The default rate limit for multicast traffic is 256 pps.

  6. Enable intelligent flow control for unknown unicast packets.

    undo unicast-suppression auto-detect disable

    By default, intelligent flow control for unknown unicast packets is enabled.

  7. Configure the rate limit for unknown unicast traffic.

    unicast-suppression auto-detect packets packets

    The default rate limit for unknown unicast traffic is 128 pps.

  8. Bind the AP system profile.

    Bind the AP system profile to an AP group or a single AP so that the configuration in the profile can take effect. For details, see AP System Profile.

Verifying the Configuration

Run the display ap-system-profile name profile-name command to check the AP intelligent flow control configuration in the AP system profile.
