Example for Configuring Static Subscription (IPv4 Collector)

Networking Requirements

As the network scale increases, you need to optimize networks or rectify faults in a timely manner based on device information. As shown in Figure 1, DeviceA supports telemetry and establishes a gRPC connection with the collector.

Figure 1 Network diagram of configuring gRPC-based static subscription

Procedure

  1. Configure a destination collector for receiving sampled data.

    # On DeviceA, create the destination group destination1 to which a destination collector belongs, set the IP address and port number of the destination collector to 10.20.2.1 and 10034 (if the collector is iMaster NCE-Campus and both the collector and device use Huawei default certificates, set the port number to 10034; if they use non-Huawei default certificates, set the port number to 10035), respectively, and set the gRPC encryption mode to TLS.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] telemetry
[DeviceA-telemetry] destination-group destination1
[DeviceA-telemetry-destination-group-destination1] ipv4-address 10.20.2.1 port 10034 protocol grpc
[DeviceA-telemetry-destination-group-destination1] quit

  2. Configure a sampling path.

    # Configure the sampling sensor group sensor1.

    [DeviceA-telemetry] sensor-group sensor1

    # Set the sampling path to huawei-cpu-memory:cpu-memory/board-cpu-infos/board-cpu-info.

    [DeviceA-telemetry-sensor-group-sensor1] sensor-path huawei-cpu-memory:cpu-memory/board-cpu-infos/board-cpu-info
[DeviceA-telemetry-sensor-group-sensor1-path] quit

    # Set the sampling path to huawei-cpu-memory:cpu-memory/board-memory-infos/board-memory-info.

    [DeviceA-telemetry-sensor-group-sensor1] sensor-path huawei-cpu-memory:cpu-memory/board-memory-infos/board-memory-info
[DeviceA-telemetry-sensor-group-sensor1-path] quit
[DeviceA-telemetry-sensor-group-sensor1] quit

  3. Create a static subscription.

    # On DeviceA, create a subscription named subscription1 and associate it with the sampling sensor group sensor1 and destination group destination1.

    [DeviceA-telemetry] subscription subscription1
[DeviceA-telemetry-subscription-subscription1] sensor-group sensor1 sample-interval 60000
[DeviceA-telemetry-subscription-subscription1] destination-group destination1

Configuration Scripts

DeviceA
#
sysname DeviceA
#
telemetry
 #
 sensor-group sensor1
  sensor-path huawei-cpu-memory:cpu-memory/board-cpu-infos/board-cpu-info
  sensor-path huawei-cpu-memory:cpu-memory/board-memory-infos/board-memory-info
 #
 destination-group destination1
  ipv4-address 10.20.2.1 port 10034 protocol grpc
 #
 subscription subscription1
  sensor-group sensor1 sample-interval 60000
  destination-group destination1
#
return
