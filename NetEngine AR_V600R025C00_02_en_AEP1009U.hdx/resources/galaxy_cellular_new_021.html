Restarting a Cellular Modem to Recover a Link

Context

A device's wireless link can work normally only when the cellular modem does. A cellular modem can automatically restart when it detects an exception. If the modem fails to automatically restart, you can manually restart it.

Restarting the modem will interrupt services on the cellular channel interface.

Procedure

  1. Enter the system view.

    system-view

  2. Enable the cellular modem to automatically restart when it is not attached to a Packet Switched (PS) domain and specify the restart interval.

    cellular-profile profile-name
modem-event packet-service-detached interval interval action { none | modem-reboot retry-times retry-times }
quit

    By default, the interval for automatically restarting a modem is 3600s, and the maximum number of restarts is 3.

    The PS domain of a cellular network is also called the data domain. It is mainly used to transmit data, such as Internet data and emails. A cellular modem attached to a PS domain has registered with the PS domain and obtained network services.

  3. Configure the no-service state detection interval and number of detection times. Also, configure the self-recovery action when an exception occurs and the cellular modem enters the no-service state.

    cellular-profile profile-name
modem-event services-unavailable interval interval action { none | { modem-reboot | sim-switch } retry-times retry-times }
quit

    By default, the no-service state detection interval is 3600s, the number of detection times is 0 (unlimited), and the self-recovery action is to restart the cellular modem.

  4. Configure the function of sending ICMP packets to detect whether the DNS server is reachable when the traffic is abnormal and restarting the modem to recover the link if the DNS server is unreachable.

    cellular-profile profile-name
modem-event icmp-unreachable action { none | modem-reboot retry-times retry-times }
quit

    By default, traffic exception detection is enabled, and the maximum number of restarts is 3. The device checks the uplink and downlink traffic on the cellular modem every minute. If only unidirectional traffic exists for 10 minutes, the traffic is considered abnormal.

  5. Configure the threshold at which consecutive dial-up failures trigger a cellular modem to restart and the maximum number of modem restarts.

    interface cellular interface-number
modem-event dial-failed fail-times fail-times action { none | modem-reboot retry-times retry-times }
quit

    By default, the modem is restarted a maximum of three times after 30 consecutive dial-up failures.

  6. Configure the link monitoring function. If a wireless link is unstable due to weak signals or noises, it may fail to provide access to external networks even if the dial-up succeeds. In this case, you can configure an address to be detected. When the number of consecutive failures in detecting this address reaches the threshold, the self-recovery action (modem restart or re-dialup) is triggered to recover the link.

    1. Enter the cellular channel interface view.
      interface cellular interface-number
    2. Configure the address to be detected and enable the detection function.
      modem-event detect ipv4 ipv4-address

      By default, address detection is disabled.

    3. Specify the detection interval.
      modem-event detect interval interval

      By default, the detection interval is 60 seconds.

    4. Set the threshold for the number of consecutive detection failures.
      modem-event detect fail-times fail-times

      By default, the threshold for the number of consecutive detection failures is 5.

    5. Configure the device's self-recovery action triggered when the number of consecutive detection failures reaches the threshold.
      modem-event detect action { redial | modem-reboot | apn-switch }

      By default, the self-recovery action is modem-reboot.

    6. Configure the maximum number of times that the self-recovery action is triggered.
      modem-event detect retry-times retry-times

      By default, the self-recovery action is triggered a maximum of three times.

    7. Return to the system view.
      quit

  7. (Optional) Manually restart the cellular modem if it fails to automatically restart.

    interface cellular interface-number
modem reboot
