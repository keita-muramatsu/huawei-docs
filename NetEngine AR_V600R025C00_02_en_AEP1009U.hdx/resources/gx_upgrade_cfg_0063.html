Example for Downloading the Basic Software Package That Takes Effect at the Next Startup from the Package Pool

Networking Requirements

If the current software version of a device cannot meet users' requirements, the basic software package needs to be upgraded to optimize the device performance, add new features, and solve the problem that the current version is not updated in time. For devices that do not need to work continuously for a long time, Huawei provides a basic software package that takes effect at the next startup to support more specifications and features.

You may have difficulty in selecting a basic software package suitable for your devices. In this case, you can preferentially download the package pool file to your PC and then download the desired basic software package from the package pool.

On the network shown in Figure 1, the system software of DeviceA cannot meet customer's requirements and needs to be upgraded. Huawei has provided related upgrade software files. You can perform a software upgrade for the device.

Figure 1 Network diagram for specifying the basic software package that takes effect at the next startup

Configuration Precautions

  • The key data in the storage medium on the device must be backed up to the PC.

  • The CPU usage and the remaining space in the storage medium must meet the upgrade requirement.

  • SFTP is recommended because it is more secure than FTP.

Configuration Roadmap

The configuration roadmap is as follows:

  1. Download the package pool file from the SFTP server.
  2. Specify the software package for next startup.
  3. Restart the device.

Procedure

  1. Log in to Huawei enterprise technical support website and download the package to the local PC.
  2. Configure the PC to function as an SFTP server.
  3. Download the basic software package that matches the device from the package pool on the SFTP server.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] quit
<DeviceA> smart-load sftp server-ip 10.2.1.1 username testname filename commonPkgPool.zip
Enter Password: 
Info: Operating, please wait for a moment.............done. 
Info: The following files are downloaded successfully: newbasicsoft.cc.

  4. Specify the basic software package for next startup.

    # For devices with a single main control board:

    <DeviceA> startup system-software newbasicsoft.cc

    # For devices with dual main control boards:

    <DeviceA> copy flash:/newbasicsoft.cc newbasicsoft.cc all flash:/
<DeviceA> startup system-software newbasicsoft.cc all

  5. Check the system software package to be loaded at the next startup and make sure that it is the specified version. (The actual command output varies depending on the device. The following command output is only an example.)

    <DeviceA> display startup
MainBoard:   
  Configured startup system software:        flash:/basicsoft.cc   
  Startup system software:                   flash:/basicsoft.cc   
  Next startup system software:              flash:/newbasicsoft.cc
  Startup saved-configuration file:          flash:/vrpcfg.zip   
  Next startup saved-configuration file:     flash:/vrpcfg.zip   
  Startup paf file:                          default   
  Next startup paf file:                     default   
  Startup patch package:                     NULL   
  Next startup patch package:                NULL

  6. Restart the device.

    <DeviceA> reboot

Verifying the Configuration

After DeviceA restarts, run the display version command. If the version of the current system software in the command output is a target one, it means that the upgrade succeeds.

Configuration Scripts

# For devices with a single main control board:

#
sysname DeviceA
#
smart-load sftp server-ip 10.2.1.1 username testname filename commonPkgPool.zip

#
reboot
# 
return
