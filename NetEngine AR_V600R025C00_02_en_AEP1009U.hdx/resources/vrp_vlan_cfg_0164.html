Example for Configuring a Voice VLAN (Identifying Voice Packets Based on MAC Addresses and Receiving Untagged Voice Packets from IP Phones)

Networking Requirements

In Figure 1, IP phones A and B are connected to DeviceA. IP phone A has a downstream device Host1 and IP phone B has no downstream device. IP phones send untagged voice packets, which DeviceA transmits in VLAN 2. Host1 sends data packets, which DeviceA transmits in VLAN 3. Users want to increase the transmission priority of voice packets to ensure the quality of voice services.

Figure 1 Network diagram of configuring a voice VLAN to identify voice packets based on MAC addresses

In this example, interface 1 and interface 2 represent 10GE 0/0/1 and 10GE 0/0/2, respectively.


Procedure

  1. Create VLANs on DeviceA and add interfaces to them.

    # Create VLANs.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] vlan batch 2 3

    # Add interfaces to VLANs.

    [DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] portswitch
[DeviceA-10GE0/0/1] port link-type hybrid
[DeviceA-10GE0/0/1] port hybrid pvid vlan 3
[DeviceA-10GE0/0/1] port hybrid untagged vlan 2 to 3
[DeviceA-10GE0/0/1] quit
[DeviceA] interface 10ge 0/0/2
[DeviceA-10GE0/0/2] portswitch
[DeviceA-10GE0/0/2] port link-type hybrid
[DeviceA-10GE0/0/2] port hybrid untagged vlan 2 to 3
[DeviceA-10GE0/0/2] quit

  2. Configure the OUI for a voice VLAN.

    [DeviceA] voice-vlan mac-address 00e0-fc12-3456 mask ffff-ff00-0000

  3. Enable the voice VLAN function on interfaces and configure them to increase the priority of voice packets based on MAC addresses.

    [DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] voice-vlan 2 enable include-untagged
[DeviceA-10GE0/0/1] voice-vlan remark-mode mac-address
[DeviceA-10GE0/0/1] quit
[DeviceA] interface 10ge 0/0/2
[DeviceA-10GE0/0/2] voice-vlan 2 enable include-untagged
[DeviceA-10GE0/0/2] voice-vlan remark-mode mac-address
[DeviceA-10GE0/0/2] quit

Verifying the Configuration

Run the display voice-vlan 2 status command to check whether the voice VLAN configuration is correct.

[DeviceA] display voice-vlan 2 status

--------------------------------------------------------------------------

Configuration Scripts

#
sysname DeviceA
#
voice-vlan mac-address 00e0-fc12-3456 mask ffff-ff00-0000
#
vlan batch 2 to 3
#
interface 10GE0/0/1
 portswitch
 port link-type hybrid
 port hybrid pvid vlan 3
 port hybrid untagged vlan 2 to 3
 voice-vlan 2 enable include-untagged
 voice-vlan remark-mode mac-address
#
interface 10GE0/0/2
 portswitch
 port link-type hybrid
 port hybrid untagged vlan 2 to 3
 voice-vlan 2 enable include-untagged
 voice-vlan remark-mode mac-address
#
return
