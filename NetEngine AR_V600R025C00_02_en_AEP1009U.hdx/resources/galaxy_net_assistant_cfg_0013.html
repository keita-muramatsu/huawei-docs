(Optional) Configuring a WLAN

Context

If a WAC is deployed on the network, you can configure the WLAN on the master device and deliver the WLAN configuration to the WAC through the HTTPS communication channel between the master and member devices. This allows the WAC to manage APs. The configuration includes the SSID, password, encryption mode, and authentication mode of the WLAN.

All commands in this section need to be configured on the master device.

Procedure

  1. Set the device role to wac (wireless access controller). For details, see (Optional) Approving and Configuring a Member Device.
  2. Enter the system view.

    system-view

  3. Enter the net assistant view.

    net-assistant

    By default, the net assistant view is not displayed.

  4. Enter the network view.

    network

    By default, the network view is not displayed.

  5. Configures a country code for the device.

    country-code country-code

    The default country code is CN.

  6. Set an approval mode for APs on the network.

    ap-granted-mode { auto | manual }

    By default, the AP approval mode is manual.

  7. Create a network-wide WLAN SSID and enter the SSID view.

    wlan-ssid ssid-paravalue profile-name name

    By default, no SSID is configured.

  8. Configure a network-wide WLAN encryption mode.

    wpa-type { wpa | wpa2 | wpa-wpa2 | wpa3 | wpa2-wpa3 } psk psk-paravalue

    By default, no WLAN encryption mode is configured.

  9. (Optional) Configure a network-wide WLAN data encryption algorithm.

    encryption-method { tkip | aes | aes-tkip }

    By default, no WLAN encryption algorithm is configured. After the wpa-type command is run, the default encryption algorithm AES is automatically generated.

  10. Configure a network-wide WLAN radio mode.

    radio { 2.4g | 5g | 5-6g } *

    By default, no WLAN radio mode is configured.

  11. Bind the WLAN configuration to the AP group and create the network-wide configuration for the binding relationship.

    ap-group ap-group-paravalue

    By default, the WLAN configurations are not applied to an AP group.

  12. Return to the network view.

    quit

  13. Create a VLAN and enter its view.

    vlan vlan-paravalue name name-paravalue

    By default, no VLAN is configured.

  14. Bind the VLAN to the WLAN SSID.

    bind wlan-ssid ssid-paravalue

    By default, no WLAN SSID is bound.
