Checking AP Running Statistics

Context

After AP management configurations are complete, you can check AP running statistics.

Procedure

  • Run the display ap run-info ap-id ap-id command in any view to check AP running information.
  • Run the display ap version { all | { ap-group group-name | version-name version-name } * } command to check AP version information.
  • Run the display ap power-workmode { all | ap-id ap-id | ap-mac ap-mac | ap-group ap-group } command to check the current power mode of an AP.
  • Run the display ap led { ap-mac ap-mac | ap-id ap-id } command to check the blinking status of LED indicators on an AP.
  • Run the display ap statistics command to check statistics about AP types.
  • Run the display ap performance statistics ap-id ap-id command to check AP performance statistics.
  • Run the display distribute-ap { all | ap-id ap-id | ap-mac ap-mac | central-ap-id central-ap-id | central-ap-mac central-ap-mac } command to check RU information.
  • Run the display license resource usage detail command to check the usage of license resources.
  • Run the display cloud license command to check the license resources delivered from iMaster NCE-Campus to the WAC.
  • Run the display ap service-config acl [ ipv6 ] ap-id ap-id command to check the ACL configuration on a specified AP.
  • Run the display ap port { all | ap-id ap-id | ap-mac ap-mac } command to check the AP port status and traffic information.
