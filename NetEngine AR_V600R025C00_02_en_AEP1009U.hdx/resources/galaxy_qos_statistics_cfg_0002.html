Overview of Traffic Statistics Collection

Traffic statistics collection allows the device to collect statistics on packets that match traffic classification rules. With this function enabled, the device can collect statistics on forwarded and discarded packets matching traffic policies, helping administrators to locate faults and determine whether traffic policies are correctly applied. You can run the display traffic-policy statistics command to view statistics on forwarded and discarded packets matching traffic policies only when MQC is used to implement traffic statistics collection.

Table 1 describes the differences between traffic statistics collection and interface statistics collection.
Table 1 Differences between traffic statistics collection and interface statistics collection
