Configuring a Weak Password Dictionary

Context

A device provides the function of weak password dictionary maintenance. With this function, you can configure a weak password dictionary containing prohibited passwords in advance and load the dictionary to the device.

The weak password dictionary to be loaded has been generated in .txt format and uploaded to the device.

Procedure

  • Load a weak password dictionary.

    load security weak-password-dictionary filePath

    Before the loading, ensure that the weak password dictionary in .txt format has been uploaded to the device.

  • Unload the weak password dictionary.

    unload security weak-password-dictionary

Verifying the Configuration

  • Run the display security weak-password-dictionary command to check the weak passwords that cannot be used on the device.
