Clearing the Going-Offline Records and Onboarding Failure Records of APs

Context

After clearing AP onboarding failures and going-offline information, you can re-collect AP statistics to facilitate AP management and maintenance.

The cleared records cannot be restored. Therefore, exercise caution when performing these operations.

Procedure

  • Run the reset ap online-fail-record { all | mac mac-address } command to clear onboarding failure records of APs.
  • Run the reset ap offline-record { all | mac mac-address } command to clear going-offline records of APs.
  • Run the reset ap-type undefined record command to clear the types of the APs that fail to connect to a WAC because they are not supported by the WAC.
  • Run the reset ap unauthorized record command in the WLAN view to clear the list of unauthorized APs.

    You can clear the list of unauthorized APs to clear the removed or unauthorized APs that disconnect with an AC. This operation allows you to re-collect and confirm unauthorized APs.
