Introduction to Logs

The log module of the system software logs events occurring during system operations.

Logs provide reference information for system diagnosis and maintenance, and help you check the device running status, analyze network conditions, and locate faults.

Generated logs are saved in the log buffer by default. You can run the display logbuffer [ starttime starttime-value [ endtime endtime-value ] | level { severity | level } | size value ] * command to view logs in the log buffer.
