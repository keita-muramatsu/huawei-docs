GPB Encoding

GPB encoding is a language-neutral, platform-neutral, and extensible mechanism for serializing structured data of communications protocols and data storage.

gRPC uses GPB encoding (the GPB-encoded file name extension is .proto) to provide a flexible, efficient, and automatic mechanism for serializing structured data. Different from XML and JSON, GPB is a binary encoding format with good performance and high efficiency. For details about gRPC, see Overview of gRPC.

Two GPB versions are available: v2 and v3. Currently, devices support GPB v3.

gRPC connections use .proto files to describe gRPC definitions and gRPC messages.

GPB uses a .proto file to describe a dictionary for encoding, which is the data structure description. The collector can use a tool such as Protoc (for example, the protoc-3.0.2-windows-x86_64.exe file) to automatically generate code (for example, Java code) based on a .proto file. Then, users can perform secondary development based on the automatically generated code to achieve interconnections with devices.
