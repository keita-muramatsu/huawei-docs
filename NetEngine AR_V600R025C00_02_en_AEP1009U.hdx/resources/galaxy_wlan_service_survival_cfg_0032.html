Example for Configuring an AP-Offline Backup Service VAP

Networking Requirements

Enterprise users can access the network through WLANs, meeting the basic mobile office requirements. Furthermore, users' services are not affected during STA roaming in the coverage area.

The enterprise requires that a backup SSID be automatically enabled for STA access in case of a WAC fault so that data forwarding of STAs is not affected, thereby improving WLAN reliability.

For details about how to configure wireless network access, see Configuration Examples for WLAN STA Management.

  • WAC networking mode: Layer 2 off-path networking
  • Service data forwarding mode: direct forwarding

Configuration Roadmap

  1. Configure an AP-offline backup service VAP and bind it to the same radios as the original VAP.

Procedure

  1. Check basic WLAN configurations.

    Check Item

    Command

    Data

    AP group to which the AP belongs

    display ap all

    AP group: ap-group1

    All profiles bound to the AP group

    display ap-group name ap-group1

    VAP profile: wlan-net

  2. Configure a backup VAP.

    # Create an SSID profile and configure an SSID for the backup VAP.

    <WAC> system-view
[WAC] wlan
[WAC-wlan] ssid-profile name wlan-net-temp
[WAC-wlan-ssid-prof-wlan-net-temp] ssid wlan-net-temp
[WAC-wlan-ssid-prof-wlan-net-temp] quit

    # Create a security profile and configure a security policy for the backup VAP.

    [WAC-wlan] security-profile name wlan-net-temp
[WAC-wlan-sec-prof-wlan-net-temp] security wpa-wpa2 psk pass-phrase YsHsjx_202206 aes
[WAC-wlan-sec-prof-wlan-net-temp] quit

    # Create a backup VAP profile, change the VAP type to AP-offline backup service, and bind the security profile and SSID profile to the VAP profile. Retain the remaining configurations of the original VAP profile.

    [WAC-wlan] vap-profile name wlan-net-temp
[WAC-wlan-vap-prof-wlan-net-temp] service-vlan vlan-id 101
[WAC-wlan-vap-prof-wlan-net-temp] type service-backup ap-offline
[WAC-wlan-vap-prof-wlan-net-temp] security-profile wlan-net-temp
[WAC-wlan-vap-prof-wlan-net-temp] ssid-profile wlan-net-temp
[WAC-wlan-vap-prof-wlan-net-temp] quit

    # Bind the backup VAP profile to an AP group, and apply the backup VAP profile to radio 0 and radio 1 of APs.

    [WAC-wlan] ap-group name ap-group1
[WAC-wlan-ap-group-ap-group1] vap-profile wlan-net-temp wlan 2 radio 0
[WAC-wlan-ap-group-ap-group1] vap-profile wlan-net-temp wlan 2 radio 1
[WAC-wlan-ap-group-ap-group1] quit

Verifying the Configuration

The WLAN with the SSID wlan-net is available for STAs connected to the APs, and these STAs can connect to the WLAN and go online normally. In this case, if the APs are disconnected from the WAC, the STAs can detect only the backup SSID wlan-net-temp. After connecting to the backup SSID, the STAs go online normally.
