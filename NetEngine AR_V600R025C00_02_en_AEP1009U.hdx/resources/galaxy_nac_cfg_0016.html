Quiet Timer for MAC Address Authentication

As shown in Figure 1, if a user frequently fails MAC address authentication within a short period, system performance will be affected, and it might indicate brute force attacks against the user. After the quiet function is enabled, the device sets the user to the quiet state for a period of time if the user fails the maximum authentication attempts within 60 seconds. During the quiet period, the device does not accept the authentication request packets of the user.

Figure 1 Quiet function for MAC address authentication
The quiet function for MAC address authentication does not take effect in the following scenarios:
  • The pre-connection function has been enabled using the authentication pre-authen-access enable command.
  • Network access rights have been configured for users in abnormal authentication state using the authentication event action authorize command.
