Example for Configuring the Offline Management SSID Function for AP Login

Networking Requirements

As shown in Figure 1, the AP is online on the WAC, joins the AP group ap-group1, and has the MAC address of 00e0-fc11-1111. The offline management SSID function is required, so that users can still log in to an offline AP using STelnet for fault locating and other maintenance operations.

Figure 1 Network diagram of the offline management SSID function

Procedure

  1. Configure the user name and password for AP login.

    <HUAWEI> system-view
[HUAWEI] sysname WAC
[WAC] wlan
[WAC-wlan] ap username huawei password cipher YsHsjx_202206

  2. Configure the password for logging in to the offline management SSID in the WLAN view.

    [WAC-wlan] temporary-management psk YsHsjx_202206

  3. Enable the offline management SSID function in the AP system profile temporary-system.

    [WAC-wlan] ap-system-profile name temporary-system
[WAC-wlan-ap-system-prof-temporary-system] undo temporary-management disable
[WAC-wlan-ap-system-prof-temporary-system] quit

  4. Bind the AP system profile temporary-system to the AP group ap-group1.

    [WAC-wlan] ap-group name ap-group1
[WAC-wlan-ap-group-ap-group1] ap-system-profile temporary-system
[WAC-wlan-ap-group-ap-group1] quit

Verifying the Configuration

When an AP goes offline unexpectedly, manually add a WLAN named hw_manage_1111 (1111 is the last 4 digits of the AP's MAC address) on the STA and associate the STA with the offline management SSID.
