(Optional) Configuring Types of TLVs Allowed to Be Advertised by LLDP

Context

TLVs that can be encapsulated in an LLDPDU include basic TLVs, TLVs defined by IEEE 802.1, TLVs defined by IEEE 802.3, and some LLDP-MED TLVs.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the interface view.

    interface interface-type interface-number

  3. Perform one or more of the following operations to configure the types of TLVs that can be advertised by LLDP based on device configuration requirements.

    • Configure the types of basic TLVs that can be advertised on an interface.
      undo lldp tlv-disable basic-tlv { all | management-address | port-description | system-capability | system-description | system-name }
    • Configure the types of TLVs defined by IEEE 802.1 that can be advertised on an interface.
      lldp tlv-enable dot1-tlv { protocol-vlan-id vlan-id | vlan-name vlan-id | protocol-identity }

    • Configure the types of TLVs defined by IEEE 802.3 that can be advertised on an interface.
      undo lldp tlv-disable dot3-tlv { all | link-aggregation | mac-physic | max-frame-size | power }
    • Configure the types of MED TLVs that can be advertised on an interface.
      lldp tlv-enable med-tlv { capability | power-over-ethernet | network-policy }
      • To enable the advertisement of the MED Capabilities TLV, first enable the advertisement of the 802.3 MAC/PHY Configuration/Status TLV.
      • To disable the advertisement of the 802.3 MAC/PHY Configuration/Status TLVs, first disable the advertisement of the MED Capabilities TLV.
      • To enable the advertisement of other types of MED TLVs, first enable the advertisement of the MED Capabilities TLV.
      • To disable the advertisement of the MED Capabilities TLV, first disable the advertisement of the other types of MED TLVs.

  4. (Optional) Set the format of the Power Via MDI TLV to be sent by the interface to 802.1ab or 802.3at.

    lldp dot3-tlv power { 802.1ab force | 802.3at | 802.1ab }

  5. Enable the interface to advertise LLDP packets carrying peer device identity TLVs.

    When a controller is used to automatically deploy network services, you can manually manage a device on the controller web UI. When multiple devices directly connected to the device go online, the controller cannot determine which configurations are to be delivered to which devices. You can configure the interfaces to advertise LLDP packets carrying peer device identity TLVs. The directly connected devices can receive the identity TLVs and notify the controller, which can then deliver corresponding network service configurations to the devices based on their identity TLVs.

    1. Configure the peer device identity TLV.
      port identity identify-para
    2. Configure the LLDP packets advertised by the interface to carry the peer device identity TLV.
      identity enable
