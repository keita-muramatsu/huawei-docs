Configuring the Console User Interface

Prerequisites

To locally configure and manage a device through the console port after logging to the device for the first time, you need to configure attributes for the console user interface as needed.

You have logged in to the device from a terminal.

Context

Table 1 describes the process of configuring the console user interface.

Table 1 Console user interface configuration process

No.

Task

Description

Remarks

1

Configuring physical attributes for the console user interface

Configure physical attributes including the transmission rate, flow control mode, parity bit, stop bit, and data bit.

Tasks 1, 2, 3, 4, and 5 can be performed in any sequence.

2

Configuring terminal attributes for the console user interface

Configure terminal attributes including the connection timeout period, maximum number of lines displayed on a terminal screen, and maximum number of historical commands that can be buffered.

3

Configuring the user privilege level for the console user interface

Configure the user privilege level for the user interface.

4

Configuring the AAA authentication mode for the console user interface

Perform either of the following two tasks:

  • Configure the AAA authentication mode and local AAA user name and password.
  • Configure the password authentication mode and authentication password.

Configuring the password authentication mode for the console user interface

5

Disabling the console user interface

Disable the console user interface if it is not required for login.

Procedure

Table 2 Configuring physical attributes for the console user interface

Operation

Command

Description

Enter the system view.

system-view

-

Enter the console user interface view.

user-interface console interface-number

-

Set the transmission rate.

speed speed-value

By default, the transmission rate is 9600 bit/s.

Set the flow control mode.

flow-control { hardware | none | software }

By default, the flow control mode is none.

Set the parity bit.

parity { even | mark | none | odd | space }

By default, the parity bit is none.

Set the stop bit.

stopbits { 1.5 | 1 | 2 }

By default, the stop bit is 1.

Set the data bit.

databits { 5 | 6 | 7 | 8 }

By default, the data bit is 8.

Exit the console user interface view.

quit

-

Return to the user view.

quit

-

To log in to a device through a console interface, you must ensure that physical attribute configurations on the terminal emulator for the console user interface are the same as those of the console user interface on the device. Otherwise, you cannot log in to the device.

Table 3 Configuring terminal attributes for the console user interface

Operation

Command

Description

Enter the system view.

system-view

-

Enter the console user interface view.

user-interface console interface-number

-

Set the connection timeout period.

idle-timeout minutes [ seconds ]

If a connection remains idle during the specified period, the terminal will be automatically disconnected from the device.

By default, the connection timeout period is 5 minutes.
NOTE:

If the connection timeout period is set to too large a value, the terminal will remain connected, posing security risks. To prevent such risks, you are advised to run the lock command in the user view to lock the connection.

Set the number of lines to be displayed on a terminal screen.

screen-length screen-length [ temporary ]

The temporary parameter specifies the number of lines to be temporarily displayed on a terminal screen.

By default, 24 lines are displayed on a terminal screen.

Set the buffer size for historical commands.

history-command max-size size-value

By default, a maximum of 10 historical commands can be buffered.

Exit the console user interface view.

quit

Return to the user view.

quit

Table 6 Configuring the password authentication mode for the console user interface

Operation

Command

Description

Enter the system view.

-

Enter the console user interface view.

user-interface console interface-number

-

Set the user authentication mode to password authentication.

authentication-mode password

-

Set the authentication password.

set authentication password [ cipher password ]

The password can be a ciphertext or cleartext password. If you do not specify cipher password, you can enter a cleartext password in interactive mode. If you specify cipher password, you can enter a cleartext or ciphertext password. Both types of passwords are saved to the configuration file in cipher text. For security purposes, change the password periodically.

NOTE:

After the weak password dictionary maintenance function is enabled, the passwords (which can be queried using the display security weak-password-dictionary command) defined in the weak password dictionary cannot be specified in this command.

Table 7 Disabling the console user interface

Operation

Command

Description

Enter the system view.

system-view

-

Enter the console user interface view.

user-interface console interface-number

-

Disable the console user interface view.

shutdown

By default, the console user interface is enabled.

After the shutdown command is run, the specified user interface is disabled and you cannot log in to the device through the user interface. However, you can still configure commands in the user interface view.

To enable the console user interface view, run the undo shutdown command.
