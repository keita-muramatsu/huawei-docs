Overview of Route Monitoring Groups

Definition

All monitored network-side routes of the same type can be added to a route monitoring group. Each route monitoring group is identified by a unique name.

A route monitoring group can monitor a certain number of route sets. Each route in a set has a down-weight, which indicates the link quality. The greater the down-weight, the more important the link. The down-weight can be set based on parameters such as the link bandwidth, rate, and cost. If a route in the route monitoring group becomes inactive, its down-weight is added to the down-weight sum of the group. If a route in the route monitoring group becomes active again, its down-weight is subtracted from the down-weight sum of the group.

Purpose

As the down-weight sum of a route monitoring group reflects the quality of network-side links, service modules can be associated with a route monitoring group as required. When the down-weight sum of a route monitoring group reaches a threshold, the RM module instructs the service module to perform a link switchover. When the down-weight sum of the route monitoring group falls below the threshold, the RM module instructs the service module to perform a link switchback.

Benefits

In a dual-device backup scenario, a service module can be associated with a route monitoring group to detect faults on the primary link on the network side in time, preventing traffic overload and forwarding failures and thereby improving user experience.
