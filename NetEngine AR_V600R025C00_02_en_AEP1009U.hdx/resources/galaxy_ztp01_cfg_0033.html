Preparing Deployment Files

Context

Deployment files need to be prepared before USB-based deployment. For the types of deployment files that can be loaded to a device, see the enumerated types of the *TYPE_n parameter in an intermediate file. Among the deployment files, a configuration file can be manually compiled or copied from other devices, while other deployment files such as the system software package need to be downloaded from Huawei technical support website.

The configuration file name is a string of 5 to 64 characters and suffixed with .zip or .cfg. The configuration file is used for the next startup.

To ensure security, you are advised to export a configuration file from another device instead of compiling it manually.

Ensure that the configuration file for deployment contains the console port password or an AAA user name that can be used to log in to the device remotely. Otherwise, the configuration file cannot be successfully set, causing a deployment to fail.

If the country code is required, you are advised to add the country code configuration to the configuration file for deployment.

Procedure

  1. Obtain deployment files.
    • Obtain the configuration file from another device.
      1. Save the configuration file on another device that has been deployed.
        save shareable-configuration configuration-file
      2. Export the configuration file using SFTP.

        For details, see "Backing Up the Configuration File to an SFTP Server or Client" in the CLI Configuration Guide > Basic Configuration > Configuration File Management.

    • Download other deployment files.
  2. Copy all deployment files to the USB flash drive.

    The directory where the deployment files are saved in the USB flash drive must be the same as the directory specified by the DIRECTORY field in the intermediate file in .ini format or the file path specified in the intermediate file in Python format.

    If this parameter is left empty or set to DEFAULT (default value), deployment files are stored in the root directory of the USB flash drive.
