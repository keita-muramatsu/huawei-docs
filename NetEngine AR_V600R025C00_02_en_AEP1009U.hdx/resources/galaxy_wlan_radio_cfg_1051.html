User CAC

On WLANs with a large number of users exist, such as high-density WLANs, STAs contend with each other to occupy the channels more fiercely as the number of online STAs increases. This deteriorates network quality for each STA. As such, the user call admission control (CAC) function can be configured to ensure network access experience of online STAs. User CAC allows APs to control STA access based on the number of online STAs or the STA SNR. STA access is controlled based on the specified thresholds, ensuring network access quality of online STAs.

CAC leverages two thresholds to control new STAs and roaming-in STAs respectively. When a new STA connects to an AP, the AP checks whether the number of online STAs or the STA SNR reaches the new STA threshold. If so, the AP denies access of the STA and hides the SSID to prevent other STAs from accessing WLAN services through the current radio. When user CAC based on the number of online STAs is configured, to ensure online STAs on other APs can roam to the local AP, some resources are reserved for roaming-in STAs. However, if too many STAs roam to the AP, experience of online STAs on the local AP will be affected. Therefore, CAC supports the configuration of the roaming-in STA threshold. After this threshold is reached on a radio, the AP denies access of roaming-in STAs to the radio.

CAC is implemented in the following modes:

  • Based on the number of STAs

    CAC based on the number of STAs uses a simple algorithm. This mode is recommended when most STAs have the same service type and similar service traffic volumes.
    • When receiving a new STA access request on a radio, the AP calculates the current number of online STAs on the radio. If it reaches the new STA threshold, the AP allows the STA to go online. Otherwise, the STA is denied access.
    • If the number of online STAs reaches the new STA threshold after a new STA accesses the AP, the AP will reject access requests of other new STAs, send an alarm, and hide its SSID. When a STA roams in, the AP checks whether the number of online STAs reaches the roaming-in STA threshold. If so, the AP rejects the access request of the STA and sends an alarm.
    • If the number of online STAs falls below the new STA threshold after some STAs go offline, the AP sends a clear alarm and exposes the SSID, allowing new STAs to go online.

  • Based on the STA SNR

    CAC based on the STA SNR controls access from weak-signal STAs, and is applicable to WLANs that have good signal coverage overall and weak signals only at the edge of coverage areas.

    When receiving a new STA access request, the AP checks the STA SNR against the new STA threshold. If it does not reach the threshold, the AP allows the STA to go online. If so, the STA is denied access.
