Configuring WPA2-WPA3 Hybrid Authentication

Context

Because WPA2 is still widely used, to enable WPA3-incapable STAs to access a WPA3-configured network, the device supports the WPA3-SAE transition mode, that is, WPA2-WPA3 authentication.

This mode applies only to WPA3-Personal, not to WPA3-Enterprise. In addition, WPA3 can be used together only with WPA2, and only AES encryption is supported.

WPA2-WPA3 hybrid authentication automatically enables the PMF function in optional mode. That is, the pmf { optional | mandatory } command configuration does not take effect in WPA2-WPA3 hybrid authentication scenarios.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a security profile and enter its view.

    security-profile name profile-name

    By default, the security profile default exists in the system.

  4. Configure WPA2-WPA3 authentication in a security policy.

    security wpa2-wpa3 psk-sae pass-phrase key-value aes

    By default, no security policy is configured.

  5. (Optional) Disable key negotiation for multicast traffic.

    wpa group-key-negotiation disable

    By default, key negotiation for multicast traffic is enabled.

  6. (Optional) Enable the function of disconnecting STAs when the device does not receive the last packet from the STAs during unicast key negotiation.

    wpa unicast-key-negotiation time-out kick-sta enable

    By default, the device does not disconnect STAs when it does not receive the last packet from the STAs during unicast key negotiation.
