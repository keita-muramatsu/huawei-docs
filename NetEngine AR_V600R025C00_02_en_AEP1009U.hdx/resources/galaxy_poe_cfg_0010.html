(Optional) Configuring LLDP Power Capacity Negotiation

Context

You can configure the TLV in LLDP packets so that the device can classify PDs using LLDP. Devices that are not configured with LLDP detect and classify PDs by analyzing current and resistance between the device and PDs. Compared with current and resistance parsing, LLDP provides more comprehensive and accurate parsing capabilities. In certain scenarios, for example, if only hardware detection is performed for some cameras that support LLDP negotiation, the cameras can be powered on but the obtained power is low. In this case, while the cameras may be powered on, they are unable to operate. Consequently, LLDP must be configured for power capacity negotiation.
  • After LLDP is configured to advertise the Power Via MDI TLV, the device can analyze the interface type, power line pairs, power priority, whether the PSE supports MDI, the MDI power supply status of the PSE, and whether the PSE can control line pairs.
  • After LLDP is configured to advertise the extended Power Via MDI TLV, the device can analyze the power type, power supply, and interface power priority.

Procedure

  1. Enter the system view.

    system-view

  2. Enable LLDP globally.

    lldp enable

  3. Enter the interface view.

    interface interface-type interface-number

  4. Enable LLDP on the interface.

    undo lldp disable

    By default, LLDP is enabled on an interface if it is enabled globally, but disabled on an interface if it is disabled globally.

  5. Configure LLDP to advertise the Power Via MDI TLV.

    undo lldp tlv-disable dot3-tlv power

    By default, LLDP is configured to advertise the Power via MDI TLV.

  6. Configure LLDP to advertise the extended Power via MDI TLV.

    lldp tlv-enable med-tlv power-over-ethernet

    By default, LLDP is configured to advertise the extended Power via MDI TLV.
