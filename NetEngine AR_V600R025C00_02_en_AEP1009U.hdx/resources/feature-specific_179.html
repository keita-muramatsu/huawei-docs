Example for Configuring Basic Functions of Route-Policies

Networking Requirements

As shown in Figure 1, a company has two departments, A and B, which are located far from each other. DeviceA and DeviceF function as the egress devices of departments A and B, respectively. Devices in AS 100 use OSPF as an IGP. The requirements are as follows:
  • BGP is deployed to enable departments A and B to communicate.
  • Route-policies are configured so that the link (DeviceB <-> DeviceC <-> DeviceD) is used as the primary link to forward traffic between DeviceA and DeviceF; if the primary link fails, traffic is automatically switched to the other link (DeviceB <-> DeviceE<-> DeviceD).

    In this example, interface1, interface2, interface3, and interface4 represent 10GE0/0/1, 10GE0/0/2, 10GE0/0/3, and 10GE0/0/4, respectively.

Configuration Roadmap

The configuration roadmap is as follows:

  1. Assign IP addresses to interfaces.

  2. Create ACLs and configure filtering lists.

  3. Configure route-policies.
  4. Configure BGP peers.
  5. Configure OSPF.

Procedure

  1. Assign IP addresses to interfaces. For detailed configurations, see Configuration Scripts.
  2. Create ACLs and configure filtering lists.

    # Configure DeviceB.

    [DeviceB] acl number 2000  
[DeviceB-acl4-basic-2000] rule 0 permit source 10.20.0.0 0.0.0.255
[DeviceB-acl4-basic-2000] quit

    # Configure DeviceD.

    [DeviceD] acl number 2000 
[DeviceD-acl4-basic-2000] rule 0 permit source 10.50.0.0 0.0.0.255
[DeviceD-acl4-basic-2000] quit

  3. Configure route-policies.

    # Configure DeviceB.

    [DeviceB] route-policy local-pre permit node 10    
[DeviceB-route-policy] if-match ip route-source acl 2000
[DeviceB-route-policy] apply local-preference 200
[DeviceB-route-policy] quit

    # Configure DeviceD.

    [DeviceD] route-policy local-pre permit node 10    
[DeviceD-route-policy] if-match ip route-source acl 2000
[DeviceD-route-policy] apply local-preference 200
[DeviceD-route-policy] quit

  4. Configure BGP peers.

    # Configure DeviceA.

    [DeviceA] bgp 200  
[DeviceA-bgp] router-id 1.1.1.1
[DeviceA-bgp] peer 10.20.0.2 as-number 100    
[DeviceA-bgp] ipv4-family unicast
[DeviceA-bgp-af-ipv4] undo synchronization
[DeviceA-bgp-af-ipv4] network 10.10.0.0 255.255.255.0   
[DeviceA-bgp-af-ipv4] peer 10.20.0.2 enable
[DeviceA-bgp] quit

    # Configure DeviceB.

    [DeviceB] bgp 100    
[DeviceB-bgp] router-id 2.2.2.2
[DeviceB-bgp] peer 10.2.0.101 as-number 100  
[DeviceB-bgp] peer 10.40.1.101 as-number 100
[DeviceB-bgp] peer 10.20.0.1 as-number 200  
[DeviceB-bgp] ipv4-family unicast
[DeviceB-bgp-af-ipv4] undo synchronization
[DeviceB-bgp-af-ipv4] preference 255 100 130    
[DeviceB-bgp-af-ipv4] peer 10.2.0.101 enable
[DeviceB-bgp-af-ipv4] peer 10.2.0.101 route-policy local-pre export    
[DeviceB-bgp-af-ipv4] peer 10.2.0.101 next-hop-local    
[DeviceB-bgp-af-ipv4] peer 10.20.0.1 enable
[DeviceB-bgp-af-ipv4] peer 10.40.1.101 enable
[DeviceB-bgp-af-ipv4] peer 10.40.1.101 next-hop-local
[DeviceB-bgp] quit

    # Configure DeviceD.

    [DeviceD] bgp 100    
[DeviceD-bgp] router-id 4.4.4.4
[DeviceD-bgp] peer 10.1.0.101 as-number 100    
[DeviceD-bgp] peer 10.50.0.1 as-number 300    
[DeviceD-bgp] peer 10.30.0.101 as-number 100   
[DeviceD-bgp] ipv4-family unicast
[DeviceD-bgp-af-ipv4] undo synchronization
[DeviceD-bgp-af-ipv4] preference 255 100 130    
[DeviceD-bgp-af-ipv4] peer 10.1.0.101 enable
[DeviceD-bgp-af-ipv4] peer 10.1.0.101 next-hop-local    
[DeviceD-bgp-af-ipv4] peer 10.1.0.101 route-policy local-pre export
[DeviceD-bgp-af-ipv4] peer 10.30.0.101 enable
[DeviceD-bgp-af-ipv4] peer 10.30.0.101 next-hop-local    
[DeviceD-bgp-af-ipv4] peer 10.50.0.1 enable
[DeviceD-bgp] quit

    # Configure DeviceF.

    [DeviceF] bgp 300    
[DeviceF-bgp] router-id 6.6.6.6
[DeviceF-bgp] peer 10.50.0.2 as-number 100    
[DeviceF-bgp] ipv4-family unicast
[DeviceF-bgp-af-ipv4] undo synchronization
[DeviceF-bgp-af-ipv4] network 10.60.0.0 255.255.255.0    
[DeviceF-bgp-af-ipv4] peer 10.50.0.2 enable
[DeviceF-bgp] quit

  5. Configure OSPF.

    # Configure DeviceB.
    [DeviceB] ospf 1
[DeviceB-ospf-1] import-route direct
[DeviceB-ospf-1] import-route bgp
[DeviceB-ospf-1] area 0.0.0.0
[DeviceB-ospf-1-area-0.0.0.0] network 10.1.0.0 0.0.0.255
[DeviceB-ospf-1-area-0.0.0.0] network 10.30.0.0 0.0.0.255
[DeviceB-ospf-1] quit

    # Configure DeviceC.

    [DeviceC] ospf 1
[DeviceC-ospf-1] area 0.0.0.0
[DeviceC-ospf-1-area-0.0.0.0] network 10.1.0.0 0.0.0.255
[DeviceC-ospf-1-area-0.0.0.0] network 10.2.0.0 0.0.0.255
[DeviceC-ospf-1] quit

    # Configure DeviceD.

    [DeviceD] ospf 1
[DeviceD-ospf-1] import-route direct
[DeviceD-ospf-1] import-route bgp
[DeviceD-ospf-1] area 0.0.0.0
[DeviceD-ospf-1-area-0.0.0.0] network 10.2.0.0 0.0.0.255
[DeviceD-ospf-1-area-0.0.0.0] network 10.40.1.0 0.0.0.255
[DeviceD-ospf-1] quit

    # Configure DeviceE.

    [DeviceE] ospf 1
[DeviceE-ospf-1] area 0.0.0.0
[DeviceE-ospf-1-area-0.0.0.0] network 10.40.1.0 0.0.0.255
[DeviceE-ospf-1-area-0.0.0.0] network 10.30.0.0 0.0.0.255
[DeviceE-ospf-1] quit

Configuration Scripts

  • DeviceA
    #
 sysname DeviceA
#
interface 10GE0/0/1
 ip address 10.10.0.1 255.255.255.0
#
interface 10GE0/0/2
 ip address 10.20.0.1 255.255.255.0
#
bgp 200   
 router-id 1.1.1.1
 peer 10.20.0.2 as-number 100   
 #
 ipv4-family unicast
  undo synchronization
  network 10.10.0.0 255.255.255.0    
  peer 10.20.0.2 enable
#
return
