Configuring BGP4+ Peer Tracking

Prerequisites

Before configuring BGP4+ peer tracking, you have completed the following task:

  • Configure basic BGP4+ functions.

Context

BFD can be configured to detect peer relationship status changes in order to implement rapid BGP4+ convergence. BFD, however, needs to be configured on the entire network and has poor extensibility. If BFD cannot be deployed to detect BGP4+ peer relationship status changes, you can configure BGP4+ peer tracking on the local device to quickly detect link or peer unreachability, implementing rapid network convergence. In addition, you can adjust the interval between peer unreachability discovery and connection interruption to suppress BGP4+ peer relationship flapping caused by route flapping. This improves BGP4+ network stability.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the BGP view.

    bgp as-number

  3. Configure BGP4+ peer tracking for a specified peer or peer group.

    peer { group-name | ipv6-address } tracking [ delay delay-time ]
