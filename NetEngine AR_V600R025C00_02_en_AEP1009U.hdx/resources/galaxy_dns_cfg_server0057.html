Configuring a DNS Proxy/Relay Agent to Send DNS Requests to a Specific DNS Server

Context

On a network with a DNS proxy or relay agent, a DNS client sends a DNS request to the DNS proxy or relay agent, which then forwards the request to a DNS server it serves. After receiving a response from the DNS server, the DNS proxy or relay agent forwards the response to the DNS client for domain name resolution. When a DNS proxy or relay agent serves multiple DNS servers, the destination DNS server can be determined based on the DNS server selection mode configured through the dns-server-select-algorithm command. Alternatively, a DNS server can be specified as the destination for specific DNS requests. In this case, the DNS proxy or relay agent will forward the specified DNS requests to the specified DNS server. You can configure the DNS proxy or relay agent to forward DNS requests to a specific DNS server.

When no DNS server is specified as the destination, a DNS proxy or relay agent can forward both IPv4 and IPv6 DNS requests to DNS servers. However, when a destination DNS server is specified, a DNS proxy or relay agent can forward only IPv4 requests to this server.

Procedure

  1. Enter the system view.

    system-view

  2. Create a DNS group on the DNS proxy or relay agent.

    dns group group-name

    By default, no DNS group is created on the DNS proxy or relay agent.

    • After the undo dns proxy forward-any-response command is configured on the device, the device preferentially sends DNS requests to DNS servers in the DNS group. If the resolution still fails (the response count is 0, the response carries an error code, or there is no response) when the number of retransmissions of the DNS requests reaches the upper limit configured by the dns forward retry-number command, then the device sends the DNS requests to global DNS servers.
    • After the dns proxy forward-any-response command is configured on the device, the device preferentially sends DNS requests to a DNS server in the DNS group. If the device receives a response, it does not send DNS requests to other DNS servers in the DNS group or global DNS servers even if the resolution fails. Instead, it directly sends the resolution result to the corresponding DNS client. If the device does not receive a response, it selects another DNS server in the DNS group based on the configured algorithm to send DNS requests. If the number of retransmissions of the DNS requests on all DNS servers in the DNS group reaches the upper limit, the device sends DNS requests to global DNS servers.

  3. Configure the DNS server IP address and source interface for the DNS proxy or relay agent to forward DNS requests.

    dns server ipv4-address [ source-interface { interface-name | interface-type interface-number } ]

    By default, no DNS server IP address and source interface are configured for the DNS proxy or relay agent to forward DNS requests.

    You can configure a maximum of three DNS servers in a DNS group.

  4. Enable the DNS resolution policy function for class A query requests.

    dns resolve policy a enable

    By default, the DNS resolution policy function is disabled for class A query requests.

  5. Enter the DNS resolution policy view.

    dns resolve policy

  6. Configure a DNS resolution rule to match specified DNS requests with the configured DNS group.

    rule rule-id [ if-match name name ] { permit | deny | spoofing { ip-address | ipv6-address } * | dns-group group-name }

    If you run the rule command to configure a DNS resolution rule and do not specify the DNS requests that match this rule, this rule matches all DNS requests by default.

    If a DNS request does not match any DNS resolution rules configured using the rule command, you can run the dns-server-select-algorithm command to configure a DNS server selection mode for this DNS request.
