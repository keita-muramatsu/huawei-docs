Querying ARP Information

Description of MIB Objects

ipNetToPhysicalTable describes the mapping between IP and MAC addresses on a device. For IPv4, ipNetToPhysicalTable describes ARP information, including the interface index, IP address type, IP address, MAC address, type, last update time, neighbor reachability detection status, and row status of an ARP entry.

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.
  2. Use ipNetToPhysicalTable to obtain ARP entries of a device, as shown in Figure 1.
    Figure 1 Querying ARP entry information through ipNetToPhysicalTable

  3. Query ARP entry information (MAC address) through ipNetToPhysicalPhysAddress.

    Figure 2 Querying ARP entry information through ipNetToPhysicalPhysAddress

    For example, in the first line shown in Figure 2, 622, 1.4, 192.168.80.1, and 80:FB:06:B0:A8:95 indicate the interface index, IPv4 address type, IPv4 address, and MAC address, respectively.

  4. Query ARP entry information (last update time) through ipNetToPhysicalLastUpdated.

    Figure 3 Querying ARP entry information through ipNetToPhysicalLastUpdated

    For example, in the first line shown in Figure 3, 622, 1.4, 192.168.80.1, and 0 days 00h:02m:30s.51th indicate the interface index, IPv4 address type, IPv4 address, and time when the entry was last updated (that is, the entry was updated 150.51 seconds ago), respectively.

  5. Query ARP entry information (ARP entry type) through ipNetToPhysicalType.

    Figure 4 Querying ARP entry information through ipNetToPhysicalType

    For example, in the first line shown in Figure 4, 622, 1.4, 192.168.80.1, and dynamic indicate the interface index, IPv4 address type, IPv4 address, and dynamic ARP entry, respectively.

  6. Query ARP entry information (neighbor reachability detection status) through ipNetToPhysicalState.

    Figure 5 Querying ARP entry information through ipNetToPhysicalState

    For example, in the first line shown in Figure 5, 622, 1.4, 192.168.80.1, and reachable indicate the interface index, IPv4 address type, IPv4 address, and neighbor reachability detection status, respectively.

  7. Query ARP entry information (row status) through ipNetToPhysicalRowStatus.
    Figure 6 Querying ARP entry information through ipNetToPhysicalRowStatus

    For example, in the first line shown in Figure 6, 622, 1.4, 192.168.80.1, and active indicate the interface index, IPv4 address type, IPv4 address, and row status, respectively.
