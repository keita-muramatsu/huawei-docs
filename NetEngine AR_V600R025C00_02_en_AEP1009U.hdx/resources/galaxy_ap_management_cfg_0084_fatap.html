Configuring ACL-based Login Control for VTY User Interfaces of APs

Context

You can use an access control list (ACL) to restrict login permissions on the virtual type terminal (VTY) user interface. Before this configuration, however, you need to run the acl command in the system view to create an ACL and enter the ACL view, and then run the rule command to add ACL rules.

ACL rule:
  • When the action in an ACL rule is permit:
    • If the ACL is applied to the inbound direction, the devices whose packets match the ACL rule can access the local device.
    • If the ACL is applied to the outbound direction, the local device can access the devices whose packets match the ACL rule.

  • When the action in an ACL rule is deny:

    • If the ACL is applied to the inbound direction, the devices whose packets match the ACL rule cannot access the local device.
    • If the ACL is applied to the outbound direction, the local device cannot access the devices whose packets match the ACL rule.

  • When an ACL rule is configured but the packets from other devices do not match the ACL rule:

    • If the ACL is applied to the inbound direction, other devices cannot access the local device.
    • If the ACL is applied to the outbound direction, the local device cannot access other devices.

  • When no rule is configured in an ACL:

    • If the ACL is applied to the inbound direction, any other device can access the local device.
    • If the ACL is applied to the outbound direction, the local device can access all other devices.

For details about the ACL configuration, see "ACL Configuration" in CLI Configuration Guide > IP Addresses and Services.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP system profile and enter its view.

    ap-system-profile name profile-name

    By default, the AP system profile default exists on the device.

  4. Configure ACL-based login control for a VTY user interface.

    user-interface vty ui-number acl [ ipv6 ] acl-number { inbound | outbound }

    By default, login through a user interface is not restricted.

    • To prevent users with specified IP addresses or on a specified IP address segment from logging in to the device, specify inbound in the command.
    • To prevent users who have already logged in to a device from logging in to other devices, specify outbound in the command.

  5. Return to the WLAN view.

    quit

  6. Enter the AP view or AP group view.
    • Enter the AP group view.
      ap-group name group-name
    • Enter the AP view.
      ap-id ap-id
  7. Bind the AP system profile to an AP group or a single AP.

    ap-system-profile profile-name

    By default, the AP system profile default is bound to an AP group, but no AP system profile is bound to an AP.

Verifying the Configuration

  • Run the display ap-system-profile { name profile-name | all } command to check information about an AP system profile.
  • Run the display references ap-system-profile name profile-name command to check reference information about an AP system profile.
