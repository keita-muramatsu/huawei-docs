Maintaining Intra-chassis High Availability

Configuring the Timeout Period for Batch Backup

During batch backup of system components in the active/standby scenario, the device generates an alarm if the backup is not complete 5 minutes before the batch backup timeout period expires. If the backup is not complete when the timeout period expires, the standby main control board is reset. You can set the batch backup timeout period as required.

slave batch-backup self-healing-timeout timeoutVal

The default timeout period for batch backup is 1440 minutes.
