Verifying the PPPoE Configuration

Context

After the PPPoE client is configured, it can be used by hosts on the LAN to dial up to access the Internet. After a PPPoE session is set up between the PPPoE client and server, you can view the PPPoE session status on the device.

Procedure

  • Run the display pppoe-client session { packet | summary } [ dialer number ] command to check PPPoE sessions and statistics on a PPPoE client.
