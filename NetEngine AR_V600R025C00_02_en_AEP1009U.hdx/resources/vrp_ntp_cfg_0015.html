(Optional) Configuring the NTP Client/Server Mode

Context

When the client/server mode is used, you need to perform the following configurations on the client:

Once the server clock is synchronized, the server can function as a clock server. Other devices can then be synchronized to that server. If the clock stratum of the server is higher than or equal to that of a client, the client does not synchronize time with the server.

Procedure

  1. Enter the system view.

    system-view

  2. (Optional) Configure the maximum polling interval in unsynchronized mode and the step value by which a polling interval is decreased.

    ntp unsync max-poll-interval poll-interval-value dec-step step-value

    By default, the maximum polling interval in unsynchronized mode and the step length to be decreased in the actual polling interval are not configured.

  3. (Optional) Specify the source interface for sending NTP packets.

    ntp [ ipv6 ] source-interface { interface-name | interface_type interface_num } [ vpn-instance vpnName ]

    By default, no interface is specified for sending NTP packets.

    The IP address of the source interface specified in this step must be able to communicate with the IP address of the server specified in the following step. Otherwise, clock synchronization fails.

  4. Specify the service mode of the NTP server.

    ntp unicast-server { ipv4Addr [ version versionNum | authentication-keyid authkeyid | port portNumber | source-interface { ifName | interface_type interface_num } | vpn-instance vpnName | preferred | maxpoll max_number | minpoll min_number | burst | iburst | preempt ] * | ipv6 ipv6Addr [ authentication-keyid authkeyid | port portNumber | source-interface { ifName | interface_type interface_num } | vpn-instance vpnName | preferred | maxpoll max_number | minpoll min_number | burst | iburst | preempt ] * | domain domainName [ version versionNum | authentication-keyid authkeyid | port portNumber | source-interface { ifName | interface_type interface_num } | vpn-instance vpnName | preferred | maxpoll max_number | minpoll min_number | burst | iburst | preempt ] * }

    The IP address of the NTP server is a host address and cannot be a broadcast address, a multicast address, or the IP address of the reference clock. By default, no NTP server is configured.

    You can run this command to configure multiple servers, and the client selects the optimal clock source.

    If the source-interface parameter is specified, the configured server IP address must be able to communicate with the IP address of the specified source interface. Otherwise, clock synchronization fails.

    If the source interface is specified in Step 3 and this step, the configuration in this step takes precedence.

    If the authentication-keyid parameter is specified, perform the operations in Enabling NTP Authentication first.

    If the port parameter is specified, specify the same port number on the server using the ntp source-port portNum command.
