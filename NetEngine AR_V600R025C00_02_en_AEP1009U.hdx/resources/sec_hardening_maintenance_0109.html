Weak Security Algorithm/Protocol List

The security performance between protocols or algorithms varies. For security purposes, you are advised not to use weak security protocols or algorithms. If you need to use them, install the weak security algorithm/protocol feature package WEAKEA. For details, see Weak Security Algorithm/Protocol Feature Package WEAKEA.

  • Weak security protocols: Telnet, FTP, TFTP, TLS 1.0, TLS 1.1, DTLS 1.0, SSHv1, SNMPv1, and SNMPv2c.
