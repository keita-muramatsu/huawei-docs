Configuring a Blacklist

Procedure

  1. Enter the system view.

    system-view

  2. Enable the blacklist function. The blacklist entries take effect.

    firewall blacklist enable

    A dynamic blacklist takes effect only after the blacklist function is enabled using this command.

Verifying the Configuration

Run the display firewall blacklist item command to check information about blacklist entries.

Follow-up Procedure

Run the undo firewall blacklist dynamic item command to delete a blacklist entry.
