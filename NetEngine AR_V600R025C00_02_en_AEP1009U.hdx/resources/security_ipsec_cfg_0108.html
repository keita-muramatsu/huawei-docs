Understanding IPsec Multi-Instance

IPsec multi-instance provides the VPN leased line service to enterprises or implements internal network isolation for enterprises.

In Figure 1, the headquarters of three small enterprises use the same IPsec gateway (DeviceA), and the networks of the three enterprises must be isolated from each other. IP addresses in the internal network of each enterprise's headquarters are planned independently, so IP addresses on these networks may overlap. In this situation, the IPsec multi-instance function needs to be configured on DeviceA to bind the IPsec tunnels of the three enterprises to their respective VPN instances. This function ensures that packets with the same destination IP addresses can be correctly forwarded to different enterprise networks.
