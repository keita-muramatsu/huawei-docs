Making an Intermediate File

Context

An intermediate file needs to be manually edited before USB-based deployment.

Procedure

  1. Create a text file on the terminal according to the intermediate file format.

    • For an intermediate file in .ini format, name it usb.ini.
    • For an intermediate file in Python format, name it ztp_script.py.

    The intermediate file in Python format applies only to USB-based deployment of unconfigured devices.

  2. Edit the intermediate file according to Intermediate File in the INI Format or Intermediate File in Python Format.
  3. Copy the intermediate file to the root directory of the USB flash drive.
