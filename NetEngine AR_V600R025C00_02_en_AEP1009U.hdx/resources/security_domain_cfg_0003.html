Understanding Domain Group

IP Address Learning Based on Domain Names

  • When a user accesses a domain name, a DNS request packet is sent. If the domain name to be accessed is in the domain group, the device records the mapping between the domain name and IP address by resolving DNS reply packets sent back by the DNS server.
  • A DNS server is configured on a device, and the device initiates DNS request packets to obtain the IP addresses corresponding to domain names in the domain group.

Domain Name Matching Mode

Domain names can be matched in exact matching and suffix matching modes. Table 1 compares the two matching modes.
Table 1 Domain name matching mode

Matching Mode

Description

Example Item

Matching Result

Exact matching

A domain name matches an item only when it is exactly the same as the specified character string.

www.example.com

The following domain name matches the specified item:

  • www.example.com

The following domain names do not match the specified item:

  • www.example.com.cn/news
  • www.example.org/news

Suffix matching

A domain name is matched if it matches the specified suffix.

*.example.com

NOTE:

A domain name supports a maximum of one wildcard character (*), which must be placed at the beginning of the character string. In addition, a domain name supports two to four inconsecutive dots (.) and cannot end with a dot. That is, only the following formats are supported: *.X.X, *.X.X.X, or *.X.X.X.X

In this matching mode, all domain names that end with example.com match the item, for example:

  • www.example.com
  • test.example.com
  • test.abc.example.com

The following domain name does not match the specified item:

  • example.test.com
