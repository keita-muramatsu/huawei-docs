Configuring Association between LDP and Static Routes

Prerequisites

Before configuring association between LDP and static routes, complete the following tasks:

  • Enable MPLS.

  • Enable MPLS LDP globally and on interfaces.

  • Ensure that LDP sessions are set up between devices.

Procedure

  • Enable association between LDP and static routes.
    1. Enter the system view.

      system-view

    2. Configure association between LDP and static routes.

      ip route-static [ vpn-instance vpn-source-name ] ip-address { mask | mask-length } interface-type interface-number [ nexthop-address ] [ preference preference | tag tag ] * ldp-sync [ description text ]

      By default, association between LDP and static routes is not enabled.

  • (Optional) Set a value for the hold-down timer.

    Perform the preceding configurations on both ends of the primary and backup links.

    1. Enter the system view.

      system-view

    2. Enter the view of the outbound interface of the static route over the primary link.

      interface interface-type interface-number

    3. (For an Ethernet interface) Switch the interface working mode to Layer 3.

      undo portswitch

      By default, Ethernet interfaces work in Layer 2 mode.

      If any Layer 2 configuration exists on the interface, this command cannot be executed. Therefore, delete all Layer 2 configurations from the interface before running this command.

      If multiple Ethernet interfaces need to have their working modes switched, run the undo portswitch batch interface-type { interface-number1 [ to interface-number2 ] } &<1-10> command in the system view to perform the switching in batches.

    4. Configure a period during which static routes remain inactive and wait for an LDP session to be established.

      static-route timer ldp-sync hold-down { timer | infinite }

      By default, the value of the hold-down timer is 10 seconds.

      • If the value of the hold-down timer is set to 0s, association between LDP and static routes is disabled on the interface.

      • If the hold-down timer is set to infinite, the timer never expires. In this case, the static route becomes active and MPLS traffic is switched only after an LDP session is established.

Verifying the Configuration

After configuring association between LDP and static routes, run the display static-route ldp-sync command to check the configurations.
