Clearing Log Statistics

Context

Log statistics cannot be restored after they are cleared. Exercise caution when performing this operation. To clear log statistics, run the following commands in the user view.

Table 1 Clearing log-related information

Operation

Command

Clear statistics on every module in the information center.

reset info-center statistics

Clear information in the log buffer.

reset logbuffer
