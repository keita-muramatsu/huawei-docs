Configuring the Device to Obtain CPU-Forwarded Packets

Context

If some services whose packets are forwarded by the CPU on a device are not running as normal, you can configure the device to obtain these packets for analysis. In this way, you can process invalid packets promptly to ensure stable running of services.

A maximum of eight instances for obtaining CPU-forwarded packets are supported.

Procedure

  1. Configure an instance for obtaining CPU-forwarded packets based on a specified ACL and interface.

    capture-packet soft-forward [ acl [ ipv6 ] { acl-number | name acl-name } ] interface { interface-type interface-number | interface-name } [ inbound | outbound ] destination { file filename | terminal } [ time-out time-value | packet-num number | packet-len length | sample-rate sample-rate ] *

    You can configure the command parameters listed in Table 1 to obtain packets that match specified rules.

    Table 1 Parameters in the capture-packet soft-forward acl command

    Parameter

    Description

    acl [ ipv6 ] { acl-number | name acl-name }

    Obtains packets that match a specified ACL.

    interface { interface-type interface-number | interface-name } [ inbound | outbound ]

    Obtains packets on a specified interface.

    • inbound: obtains incoming packets.
    • outbound: obtains outgoing packets.

    If no direction is specified, the device obtains both incoming and outgoing packets.

    destination { file filename | terminal }
    • destination file file-name: Saves obtained packet information to a specified .cap file.
    • destination terminal: Displays obtained packet information on a terminal.

    time-out time-value

    Specifies the timeout period for obtaining packets. The device stops obtaining packets when the timeout period expires.

    packet-num number

    Specifies the number of packets to be obtained. The device stops obtaining packets when the specified number of packets are obtained.

    You can set packet-num number and time-out time based on the traffic volume on an interface. Specifically, if a large number of packets are forwarded on the interface, set a small value of time and a large value of number; otherwise, set a large value of time and a small value of number.

    packet-len length

    Specifies the length of obtained packets to be displayed on the terminal or stored on the storage medium.

    sample-rate sample-rate

    Specifies the number out of which one packet is obtained.

  2. Configure an instance for obtaining packets that need to be forwarded by the CPU but are discarded on the CPU based on a specified ACL and interface.

    capture-packet soft-forward drop [ acl [ ipv6 ] { acl-number | name acl-name } ] [ interface { interface-type interface-number | interface-name } ] destination { file filename | terminal } [ time-out time-value | packet-num number | packet-len length | sample-rate sample-rate ] *

    You can configure command parameters to obtain discarded packets that match specified rules. The parameters are the same as those in Table 1.
