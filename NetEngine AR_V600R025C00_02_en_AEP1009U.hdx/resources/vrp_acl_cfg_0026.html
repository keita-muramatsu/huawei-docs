Example for Using a Basic ACL to Control Access to an FTP Server

Networking Requirements

As shown in Figure 1, the switch functions as an FTP server and grants different access rights to different users.

  • All the users on subnet 1 (172.16.105.11/24) are allowed to access the FTP server at any time.
  • All the users on subnet 2 (172.16.107.11/24) are allowed to access the FTP server only within a specified time range.
  • Other users are not allowed to access the FTP server.

The routes between the switch and subnets are reachable. You need to configure the switch to control access to the FTP server.

Figure 1 Network diagram of using a basic ACL to control access to an FTP server

FTP can be used only after the weak security algorithm/protocol feature package (WEAKEA) has been installed using the install feature-software WEAKEA command in the system view.

Procedure

  1. Configure time ranges.

    <HUAWEI> system-view
[HUAWEI] sysname Switch
[Switch] time-range ftp-access from 0:0 2023/1/1 to 23:59 2023/12/31
[Switch] time-range ftp-access 14:00 to 18:00 off-day

  2. Configure a basic ACL.

    [Switch] acl number 2001
[Switch-acl-number-2001] rule permit source 172.16.105.0 0.0.0.255
[Switch-acl-number-2001] rule permit source 172.16.107.0 0.0.0.255 time-range ftp-access
[Switch-acl-number-2001] rule deny source any
[Switch-acl-number-2001] quit

  3. Configure basic FTP functions.

    [Switch] ftp server enable
[Switch] ftp server source -i Vlanif 10
[Switch] aaa
[Switch-aaa] local-user huawei password irreversible-cipher SetUserPassword@123
[Switch-aaa] local-user huawei privilege level 15
[Switch-aaa] local-user huawei service-type ftp
[Switch-aaa] local-user huawei ftp-directory flash:/
[Switch-aaa] quit

  4. Configure access rights on the FTP server.

    [Switch] ftp server acl 2001

Verifying the Configuration

Run the ftp 172.16.104.110 command on PC1 (172.16.105.11/24) in subnet 1. The command output shows that PC1 can connect to the FTP server.

Run the ftp 172.16.104.110 command on PC2 (172.16.107.11/24) in subnet 2 on Monday in 2023. The command output shows that PC2 cannot connect to the FTP server. Run the ftp 172.16.104.110 command on PC2 (172.16.107.11/24) in subnet 2 at 15:00 on Saturday in 2023. The command output shows that PC2 can connect to the FTP server.

Run the ftp 172.16.104.110 command on PC3 (10.10.10.1/24). The command output shows that PC3 cannot connect to the FTP server.

Switch
# 
sysname Switch
# 
ftp server enable 
ftp server source -i Vlanif 10 
ftp server acl 2001 
# 
time-range ftp-access 14:00 to 18:00 off-day 
time-range ftp-access from 00:00 2023/1/1 to 23:59 2023/12/31 
# 
acl number 2001 
 rule 5 permit source 172.16.105.0 0.0.0.255 
 rule 10 permit source 172.16.107.0 0.0.0.255 time-range ftp-access 
 rule 15 deny

aaa 
 local-user huawei password irreversible-cipher SetUserPassword@123
 local-user huawei privilege level 15

# 
return
