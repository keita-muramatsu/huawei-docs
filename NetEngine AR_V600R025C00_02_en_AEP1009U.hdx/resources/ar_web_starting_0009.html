Changing the Language of the Web System

Context

Before logging in to the web system, you can select a display language for the web system. If you have logged in to the web system, click the language switch button in the upper right corner of any page to change the language.

Procedure

  1. Before logging in to the web system, select a language for the web system below the Login button in the lower right part on the login page. The web system will be displayed in the selected language.
  2. Enter the user name and password for login.

    After logging in to the web system, you can click the language switch button in the upper right corner of any page to change the language.
