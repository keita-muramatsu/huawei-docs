AP PKI Realm Profile

Overview

A PKI realm is a set of configuration information required by a PKI entity to enroll a certificate. An AP PKI realm profile allows you to configure the CA certificate, local certificate, and private key files for APs.

For details about how to configure an AP PKI realm profile, see "Configuring an AP PKI Realm Profile" in CLI Configuration Guide > WLAN Configuration > AP Management. The following only describes how to create and apply an AP PKI realm profile.

Creating a Profile

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP PKI realm profile and enter its view.

    ap-pki-profile name profile-name

    By default, no AP PKI realm profile is created on the device.

Applying a Profile

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Enter the AP view or AP group view.
    • Enter the AP group view.
      ap-group name group-name
    • Enter the AP view.
      ap-id ap-id
  4. Bind an AP PKI realm profile to the AP group or the specific AP.

    ap-pki-profile profile-name

    By default, no AP PKI realm profile is bound to an AP group or a specific AP.
