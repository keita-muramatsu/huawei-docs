Configuring the Sensitivity of Correction for False DFS Radar Detection

Context

In some regions, radar systems operate on 5 GHz channels, which interfere with radio signals of APs operating on the same channels. Based on the dynamic frequency selection (DFS) mechanism, APs operating on these channels can automatically switch their channels upon detection of radar signals. However, some APs may frequently detect radar signals by mistake. To prevent unnecessary channel switching, you can adjust the correction sensitivity as required to reduce false radar detection.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Enter the 5 GHz radio profile view.

    radio-5g-profile name profile-name

  4. Configure the sensitivity level of correction for false DFS radar detection.

    dfs radar-filter sensitivity level

    By default, the sensitivity level of correction for false DFS radar detection is 0.

    If radar signals are often falsely detected, you are advised to set the sensitivity level to 5 and then adjust the value based on the false radar detection events. For example, if an AP often falsely detects radar signals, the sensitivity level for radar detection is high. In this case, set the sensitivity level to 5 and then continuously observe false radar detection. If false radar detection events persist, gradually increase the sensitivity level.

Verifying the Configuration

Run the display radio-5g-profile name profile-name command to check the sensitivity level of correction for false radar detection based on the DFS radar-filter sensitivity field in the command output.
