Configuring WLAN Experience Assurance Optimization

Prerequisites

Before configuring air interface traffic pre-aggregation and OFDMA + MU-MIMO joint scheduling, you have configured the intelligent multimedia scheduling algorithm.

Context

The actual rates at which users access a Wi-Fi network are affected by various factors, such as the network capacity, number of concurrent users, and application type. Heavy-traffic services often preempt air interface resources, affecting experience of key services such as audio and video services. A traditional solution is to limit the rate of users. However, when there is no key service on the network, rate-limiting heavy-traffic services cannot ensure high-speed service experiences for users. To address this problem, when the intelligent multimedia scheduling algorithm is enabled to preferentially guarantee user experience of key services, you can enable air interface traffic pre-aggregation to increase the concurrent rate of multiple users and enable OFDMA + MU-MIMO joint scheduling to improve the multi-user concurrency capability on a single AP. In this way, network capabilities are fully utilized for actual user services.

Air interface traffic pre-aggregation and OFDMA + MU-MIMO joint scheduling optimize WLAN service experiences significantly in office and school dormitory scenarios. When configuring radio parameters in such a scenario, you can use a scenario profile to simplify the configuration process. For details, see Configuring a Scenario Profile.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an SSID profile and enter its view.

    ssid-profile name profile-name

    By default, the SSID profile default exists in the system.

  4. Enable MU-MIMO, which will also enable air interface traffic pre-aggregation.

    undo mu-mimo disable

    By default, downlink MU-MIMO scheduling is enabled. Before enabling downlink MU-MIMO scheduling, run the undo beamforming disable command to enable beamforming.

  5. Enable uplink OFDMA, which will also enable OFDMA + MU-MIMO joint scheduling.

    undo ofdma uplink disable

    By default, the uplink OFDMA function is enabled.

  6. Exit the SSID profile view.

    quit

  7. Create a VAP profile view and enter its view.

    vap-profile name profile-name

  8. Bind the SSID profile to the VAP profile.

    ssid-profile profile-name

    By default, the SSID profile default is bound to a VAP profile.
