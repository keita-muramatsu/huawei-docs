(Optional) Configuring Seamless Channel Switching

Context

After a STA associated with an AP detects that the AP channel is switched, the STA needs to reassociate with the AP on the new channel. During this process, services of the STA are interrupted, affecting Internet access experience. After the seamless channel switching function is configured, the AP instructs the STA to switch the channel after a fixed Beacon interval. In this way, the AP and the STA can switch channels at the same time, without the need of STA reassociation. This function helps quickly restore services and improve user experience.

The channel switch announcement (CSA) function must be supported by both the AP and STA.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a radio profile and enter its view.

    • Create a 2.4 GHz radio profile and enter its view.
      radio-2g-profile name profile-name

      By default, the 2.4 GHz radio profile default exists in the system.

    • Create a 5 GHz radio profile and enter its view.
      radio-5g-profile name profile-name

      By default, the 5 GHz radio profile default exists in the system.

  4. Enable the CSA function.

    undo channel-switch announcement disable

    By default, the CSA function is enabled.
