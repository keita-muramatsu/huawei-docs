Configuring a VRRP6 Group to Track a Route Monitoring Group

Prerequisites

Before configuring a VRRP6 group to track a route monitoring group, you have configured a route monitoring group.

Procedure

  1. Enter the system view.
    system-view
  2. Enter the view of the interface where a VRRP6 group resides.
    interface interface-type interface-number
  3. Switch the interface working mode from Layer 2 to Layer 3.
    undo portswitch

    Determine whether to perform this step based on the current interface working mode.

  4. Configure a VRRP6 group to track a route monitoring group.
    vrrp6 vrid virtual-router-id track ipv6 route-monitor-group route-monitor-group-name failure-ratio failure-ratio-value [ link | reduced priority-value ]

    By default, if the tracked route in the route monitoring group is withdrawn or becomes inactive, the master device in the VRRP group reduces its priority by 10.

Verifying the Configuration

Run the display vrrp6 [ interface { interface-name | interface-type interface-number } ] [ virtual-router-id ] [ verbose ] command to check the VRRP6 group status.
