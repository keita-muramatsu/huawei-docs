Switching the AP Working Mode

Context

To upgrade an AP and switch the AP working mode, you can configure in-service AP upgrade and then switch the AP working mode. In scheduled AP upgrade mode, the AP working mode cannot be switched.

  1. Configure the AP upgrade mode.
  2. Configure in-service AP upgrade, and do not reset the AP.
  3. Switch the AP working mode, as detailed in this section. After the AP restarts, it loads the corresponding system file and switches its working mode.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Enter the AP provisioning view.

    provision-ap

  4. Configure the AP working mode.

    ap-mode { fit | fat | cloud }

    By default, the AP working mode is not specified in the AP provisioning view.

  5. Deliver the configuration to online APs.

    commit { ap-mac ap-mac | ap-id ap-id | ap-group ap-group | all }

    Configurations in the AP provisioning view are not automatically delivered to APs. You have to manually deliver them to APs.

    After the configuration is committed, an AP receives the configuration and compares the configuration with its local configuration.
    • If they are consistent, the AP does not process the received configuration.
    • If they are inconsistent, the AP saves the committed configuration and automatically restarts so that the received configuration takes effect.

    If a static IP address is configured for an AP in the AP provisioning view, the configuration can be delivered only to the AP with the specified MAC address or AP ID.

    If you commit configurations to a large number of APs simultaneously, some of the APs may fail to receive the configurations. In this case, you are advised to commit the configurations again.

Verifying the Configuration

  • Run the display provision-ap parameter-list command to check parameter settings in the AP provisioning view.
