Querying the MAC Address of an Interface

Description of MIB Objects

You can use ifPhysAddress in ifTable to obtain the MAC addresses of all interfaces, and then use ifIndex to query the MAC address of an interface.

Object

OID

ifIndex

1.3.6.1.2.1.2.2.1.1

ifDescr

1.3.6.1.2.1.2.2.1.2

ifPhysAddress

1.3.6.1.2.1.2.2.1.6

Procedure

Querying the MAC address of a physical interface
  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.

  2. Perform the Walk operation on ifDescr to query the entity index ifIndex. As shown in Figure 1, the index of 10GE8/0/1 is 9.

    Figure 1 Obtaining the mapping between an interface and its index

  3. Perform the Walk operation on ifPhysAddress to query the MAC address of the corresponding interface based on the value of ifIndex. As shown in Figure 2, the MAC address of 10GE8/0/1 with the index of 9 is D0:C6:5B:95:12:01.

    Figure 2 MAC address of a physical interface
Querying the MAC address of a VLANIF interface
  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.

  2. Perform the Walk operation on ifDescr to query the entity index ifIndex. As shown in Figure 3, the index of Vlanif1 is 56.

    Figure 3 Obtaining the mapping between a VLANIF interface and its index

  3. Perform the Walk operation on ifPhysAddress to query the MAC address of the corresponding interface based on the value of ifIndex. As shown in Figure 4, the MAC address of Vlanif1 with the index of 56 is D0:C6:5B:95:12:03.

    Figure 4 MAC address of a VLANIF interface
