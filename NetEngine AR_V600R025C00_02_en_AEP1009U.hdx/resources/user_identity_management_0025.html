Configuring the Connection Between the Device and the TSM SSO Server

Context

To implement TSM SSO, the administrator needs to set parameters for communication with the device on the TSM SSO server, so that the server can send user login or logout messages to the device. In addition, the administrator needs to set parameters for the device to communicate with the TSM SSO server.

Procedure

  1. Add the interworking device on the TSM SSO server.

    On the TSM SSO server, configure the IP address, device name, port, encryption algorithm, access key, and endpoint address list of the online behavior management device. The port, encryption algorithm, and access key must be the same as those configured on the device. For details, see the configuration of online behavior management in the iMaster NCE-Campus product documentation.

  2. Add a TSM SSO server to the device.

    1. Enter the system view.
      system-view
    2. Enter the identity management view.
      identity-management
    3. Enter the TSM SSO view.
      sso-tsm
    4. Configure the IP address, port number, and shared key of the TSM SSO server.
      server ip ip-address port port-num shared-key key [ source-ip source-ip-address ] [ vpn-instance vpn-instance-name ]

      The shared key configured on the device must be the same as that on the TSM SSO server. You are advised to periodically change the shared key.

      By default, the AES-256-GCM algorithm is used to encrypt packets for the communication between the device and TSM SSO server. The algorithm cannot be changed.

      When the device proactively accesses the TSM SSO server (for example, TSM online user synchronization function), the following situation may occur: if the source IP address of the device is different from the device IP address added to the TSM SSO server, you need to specify the source-ip-address parameter. For example, if the device IP address added to the TSM SSO server is the IP address of a loopback interface, but the source IP address used by the device to access the TSM SSO server is the IP address of the physical outbound interface queried based on the route, you need to set source-ip-address to the IP address of the loopback interface.

  3. Configure the IP address and port number for the device to receive TSM SSO messages.

    local-server ip ip-address port port-number [ vpn-instance vpn-instance-name ]
