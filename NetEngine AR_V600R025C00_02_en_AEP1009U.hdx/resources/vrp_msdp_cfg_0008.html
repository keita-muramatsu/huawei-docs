Default Settings for MSDP

Table 1 describes the default settings for MSDP.

Table 1 Default settings for MSDP

Parameter

Default Setting

MSDP

Disabled

MSDP peer

None

MSDP authentication

Not configured

SA cache

Enabled after an MSDP peer relationship is established

Content of the SA message

(S, G) information, multicast data packets not encapsulated

SA message filtering rule

No filtering rule is available, and SA messages are not filtered out.

Source RP address in an SA message

Address of the RP that creates an SA message (the actual RP address)
