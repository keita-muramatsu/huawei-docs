Configuring Manual Active/Standby Switchover

Context

If an automatic active/standby main control board switchover fails to be performed because the triggering conditions are not met (for example, the CPU usage is high) and Ready is displayed in the Switchover State field, you can manually perform an active/standby main control board switchover.

Before performing an active/standby main control board switchover, check whether the switchover conditions are met. Do not perform an active/standby switchover on a device in any of the following situations:

  • The file system is being operated. For example, a file or directory in the CF card is being created, deleted, or saved.

  • The active and standby main control boards have different models.

During a device's active/standby main control board switchover, do not insert, remove, or reset active and standby main control boards, service interface boards, power modules, or fan modules. Otherwise, the device may restart or fail.

Procedure

  1. Check whether the conditions for an active/standby main control board switchover are met.

    display switchover state

    You can perform an active/standby device switchover only when Ready is displayed in the Switchover State field.

  2. Enter the system view.

    system-view

  3. Enable the active/standby main control board switchover function.

    slave switchover enable

    By default, this function is enabled.

  4. Manually perform an active/standby main control board switchover.

    slave switchover [ slot slot-id ]

    In a scenario where two main control boards are used, you can choose any of the following methods to ensure a fast service switchover after an active/standby switchover:

    1. You can add an interface card to connect GE1/0/1 on Device1 to GE0/0/1 on Device2. Figure 1 shows the solution in scenario 1.

    2. The AR8700 can also connect to GE0/0/1 of the peer device through a panel port.

      For the AR6700-H, the panel ports are the outbound interfaces of the two main control boards. The interfaces are physically isolated. When an active/standby switchover is performed, service traffic is switched over. Connecting to GE0/0/1 of the peer device according to the solution a is recommended. To use panel ports as active/standby service ports, deploy Device3 (switch) between Device1 (AR) and Device2 and add the ports of the AR device and Device2 to the same VLAN through the switch. In addition, the two panel ports must be added to the same switch. Figure 2 shows the solution in scenario 2.
