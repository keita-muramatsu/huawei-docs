Verifying the Configuration

Procedure

  • Run the display cpu-defend policy [ policy-name ] command to check the attack defense policy configuration.
  • Run the display cpu-defend configuration [ packet-type packet-type ] { all | slot slot-id | mcu } command to check the rate configuration for protocol packets sent to the CPU.

    On the AR8700 series and AR6700-H, you can view the CAR configuration only on the main control board. That is, only the mcu field is supported.

    You cannot view the CAR configuration of the main control board on the AR5700, AR6700-L, and AR8100 series. That is, the mcu field is not supported.

    You cannot specify slot-id on the AR8700 and AR6700-H.

  • Run the display cpu-defend dynamic-adjust history-record [ packet-type packet-type ] { all | slot slot-id } command to check the historical records of adaptive CPCAR adjustment for protocol packets in wired mode.
  • Run the display cpu-defend linkup statistics [ packet-type packet-type ] { all | slot slot-id } command to check statistics on application layer association.

    You cannot specify slot-id on the AR8700 and AR6700-H.

  • Run the display cpu-defend linkup configuration [ packet-type packet-type ] { all | slot slot-id } command to check the configuration of application layer association.

    You cannot specify slot-id on the AR8700 and AR6700-H.

  • Run the display cpu-defend session-car configuration [ packet-type packet-type ] { all | slot slot-id } command to check the session CAR configuration.

    You cannot specify slot-id on the AR8700 and AR6700-H.

  • Run the display cpu-defend session-car statistics [ packet-type packet-type ] { all | slot slot-id } command to check session CAR statistics.

    You cannot specify slot-id on the AR8700 and AR6700-H.

  • Run the display cpu-defend rate [ packet-type packet-type ] { all | slot slot-id } command to check the CPCAR value configured for protocol packets.

    You cannot specify slot-id on the AR8700 and AR6700-H.

  • Run the display cpu-defend statistics [ packet-type packet-type ] { all | slot slot-id } command to check statistics on the packets sent to the CPU.

    When the ICMP fast reply function is enabled, statistics on ICMPv4 and ICMPv6 packets are not differentiated. The total number of ICMPv4 and ICMPv6 packets is recorded in the icmp field.

    You cannot specify slot-id on the AR8700 and AR6700-H.
