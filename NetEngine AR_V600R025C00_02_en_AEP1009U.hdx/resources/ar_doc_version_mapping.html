System Software Versions

For details about the mappings between device models and system software versions, see the software version mapping table in the Release Notes. To obtain the Release Notes, perform the following steps:
  1. Log in to the Huawei enterprise technical support website.
  2. Enter the product series, version number, and release notes in the search box.
    • Product series: for example, AR8000
    • Version number: The format is VxxxRxxxCxx or VxxxRxxxCxxSPCxxx, for example, V600R023C00
