Configuring the Device to Communicate with the Huawei Intelligent Security Center

Prerequisites

The operations in Preparations for Signature Database Update have been completed.

Context

When the device connects to the update center through the Internet for online signature database update, the device needs to directly connect to the update server at the Huawei Intelligent Security Center. Therefore, you need to set parameters for communication with the Huawei Intelligent Security Center.

Procedure

  1. Enter the system view.

    system-view

  2. Set parameters for connecting the device to the update server at the Huawei Intelligent Security Center.

    update server { domain domain-name | ip ip-address } [ port port-number ]
update server ca-certificate certificate-file-name

    By default, the domain name of the update server at the Huawei Intelligent Security Center is sec.huawei.com, the HTTPS protocol uses port 443, and the device uses the initial CA certificate to communicate with the Huawei Intelligent Security Center through HTTPS.

    The initial CA certificate is stored in the NVRAM. Run the pki import-certificate default_ca realm default command to load the initial CA certificate to the default domain.

    To connect the device to the update server at the Huawei Intelligent Security Center, you can specify the IP address of the update server using the ip ip-address parameter. The IP address specified by ip-address cannot be an IPv6 address. You are advised to preferentially use the domain name of the update server at the Huawei Intelligent Security Center for the interconnection. The IP address of the update server needs to be obtained from Huawei.

    If the initial CA certificate is used for communication with the Huawei Intelligent Security Center and the message "Connecting to the security server failed" is displayed during a signature database update, check whether the failure is caused by a network fault. If not, the initial certificate file may be manually replaced with an abnormal file. In this case, you are advised to enter the backend flash:/default-sdb/ directory to delete related files from the directory, restart the device, and then update the signature database.

  3. Optional: Configure a DNS server.

    If the interconnection parameters include the domain name of the update server at the Huawei Intelligent Security Center, you must configure a DNS server to resolve the domain name.

    1. Enable the domain name resolution function of the DNS server.

      dns resolve

    2. Configure an IP address for the DNS server.

      dns server ip-address [ vpn-instance vpn-instance-name ]

      If the device connects to the DNS server through a VPN instance, you must run the dns server ip-address vpn-instance vpn-instance-name command to bind the VPN instance to the DNS server.

  4. Optional: Configure the outbound interface or source IP address of online update request packets.

    update host source { ip ip-address [ vpn-instance vpn-instance ] } interface { interface-type interface-number\ interface-name } }

    By default, the source IP address of online update request packets is not configured. Generally, this command is optional. If the administrator does not configure this command, the system searches a route based on the IP address of the update server and uses the IP address of the outbound interface as the source IP address of update request packets.

    If the interface has multiple IP addresses, you are advised to run the update host source ip ip-address command to configure the source IP address of online update request packets and ensure that the device can receive response packets. Otherwise, online update may fail. The source IP address of update request packets cannot be the address of a loopback interface.

    If the device connects to the Internet through a VPN instance, the update host source command must be configured to ensure that the device can receive response packets. Otherwise, the update may fail.
    • When configuring the update host source interface { interface-type interface-number | interface-name } command, ensure that the interface is bound to the corresponding VPN instance.
    • When configuring the update host source ip ip-address command, you must specify vpn-instance vpn-instance.

    When both the update host source interface { interface-type interface-number | interface-name } and update host source ip ip-address [ vpn-instance vpn-instance ] commands are configured, the system preferentially uses the value of ip-address as the source address of update request packets. That is, the update host source interface interface-type interface-number command does not take effect.

Verifying the Configuration

Run the ping host command to test the connectivity between the device and the updater server at the Huawei Intelligent Security Center. The host parameter specifies the domain name or IP address of the update server at the Huawei Intelligent Security Center.

Follow-up Procedure

After the device connects successfully to the update server at the Huawei Intelligent Security Center, the device performs automatic online signature database updates at fixed update intervals. You can also configure manual online signature database update. For details, see Configuring Manual Online Signature Database Update.
