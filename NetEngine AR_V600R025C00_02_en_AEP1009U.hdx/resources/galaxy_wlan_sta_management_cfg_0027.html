Configuring Dynamic Load Balancing

Context

After a STA connects to an AP, the WAC checks whether the number of STAs on itself reaches the load balancing threshold. Then, the AP determines whether to steer the STA to a neighboring AP that meets the load balancing conditions based on a load balancing algorithm.

The dynamic load balancing function applies to scenarios where there is a high degree of overlap between APs' coverage ranges. If APs engaged in load balancing are far from each other, a STA may connect to a distant AP, which affects wireless experience of users.

Ensure that APs participating in load balancing are associated with the same WAC.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an RRM profile and enter its view.

    rrm-profile name profile-name

    By default, the RRM profile default exists in the system.

  4. Enable dynamic load balancing.

    undo sta-load-balance dynamic disable

    By default, the dynamic load balancing function is enabled.

  5. (Optional) Configure the device to preferentially steer STAs to the 6 GHz frequency band.

    sta-load-balance dynamic prefer 6g

    By default, STAs are steered to the 5 GHz or 6 GHz frequency band.

  6. (Optional) Set the start threshold for dynamic load balancing based on the number of STAs.

    sta-load-balance dynamic sta-number start-threshold start-threshold

    By default, the start threshold for dynamic load balancing based on the number of STAs is 20.

  7. (Optional) Set the load difference threshold for dynamic load balancing based on the number of STAs.

    sta-load-balance dynamic sta-number gap-threshold { percentage percentage-value | number number-value }

    By default, the load difference threshold for a dynamic load balancing group based on the number of STAs is 6.

  8. (Optional) Set the RSSI threshold for members in a dynamic load balancing group.

    sta-load-balance dynamic rssi-threshold rssi-threshold

    By default, the RSSI threshold for members in a dynamic load balancing group is –65 dBm.

  9. (Optional) Set the RSSI difference threshold for members in a dynamic load balancing group.

    sta-load-balance dynamic rssi-diff-gap diff-gap-threshold

    By default, the RSSI difference threshold for members in a dynamic load balancing group is 5 dB.

  10. (Optional) Set the interval for reporting Probe frames.

    sta-load-balance dynamic probe-report interval interval

    By default, Probe frames are reported at an interval of 120 seconds.

  11. (Optional) Set the number of attempts to steer STAs in deauthentication mode.

    sta-load-balance dynamic deauth-fail-times deauth-fail-times

    By default, the number of attempts to steer STAs in deauthentication mode is 0.

  12. Return to the WLAN view.

    quit

  13. (Optional) Configure MAC addresses of unsteerable STAs in smart roaming, AI roaming, band steering, and load balancing algorithms.

    station-unsteerable sta-mac sta-mac

    By default, no MAC addresses of unsteerable STAs are configured.

  14. Create a radio profile and enter its view.

    • Create a 2.4 GHz radio profile and enter its view.
      radio-2g-profile name profile-name
    • Create a 5 GHz radio profile and enter its view.
      radio-5g-profile name profile-name

  15. Bind the RRM profile.

    rrm-profile profile-name

    By default, the RRM profile default is bound to a radio profile.

Verifying the Configuration

  • Run the display station neighbor sta-mac mac-address command to check the neighbor list of a STA.
  • Run the display station neighbor all command to check neighbor information about the STA.
  • Run the display sta-load-balance fairness command to check the fairness of load balancing.
  • Run the display station unsteerable command to check the "unable to roam" record of the STA.

Follow-up Procedure

Bind the radio profile and VAP profile to an AP group or a specific AP.
