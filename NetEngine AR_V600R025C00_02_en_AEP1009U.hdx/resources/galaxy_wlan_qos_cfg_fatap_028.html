Configuring ACL-based Packet Filtering on the Wireless Side

Prerequisites

Before performing the configuration, you have completed the following tasks:

  • Configure AP onboarding and STA access.

  • Create an ACL rule.

    The ACL referenced by traffic-filter can be a numbered ACL that is not configured. You can configure the referenced ACL after running this command.

Context

You can configure ACL-based packet filtering in a traffic profile to permit or deny packets matching ACL rules, thereby controlling network traffic.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a traffic profile and enter its view.

    traffic-profile name profile-name

  4. Configure ACL-based packet filtering in a traffic profile.

    traffic-filter { inbound | outbound } ipv4 acl { acl-number | acl-number-user | name acl-name }

    Or

    traffic-filter { inbound | outbound } l2 acl { acl-number-l2 | name acl-name-l2 }

    Or

    traffic-filter { inbound | outbound } ipv4 acl { acl-number | acl-number-user | name acl-name } l2 acl { acl-number-l2 | name acl-name-l2 }

    Or

    traffic-filter { inbound | outbound } ipv6 acl ipv6-acl-number

    By default, ACL-based packet filtering is not configured in a traffic profile.

  5. Bind the traffic profile.

    Bind the traffic profile to an AP group or a single AP so that the configuration in the traffic profile can take effect. For details, see Traffic Profile.

Verifying the Configuration

Run the display wlan traffic-filter applied-record command to check information about all ACL-based packet filtering applications on the device.

Run the display traffic-profile { all | name profile-name } command to check the configuration of ACL-based packet filtering.
