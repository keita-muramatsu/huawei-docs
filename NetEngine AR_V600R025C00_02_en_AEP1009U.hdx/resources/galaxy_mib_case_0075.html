Querying the Forwarding Status of an Interface

Description of MIB Objects

hwMstpProNewPortTable describes information about an interface, including the enabling status and priority. You can use hwMstpProNewPortState in hwMstpProNewPortTable to obtain the forwarding status of an interface.

Object

OID

hwMstpProNewPortState

1.3.6.1.4.1.2011.5.25.42.4.1.29.1.1

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.
  2. Perform the Walk operation on hwL2IfPortName to query mappings between interface names and interface indexes.
    Figure 1 Querying mappings between interface names and interface indexes
  3. Use hwMstpProNewPortState in hwMstpProNewPortTable to query the forwarding status of an interface. Deduct 1 from an interface index to obtain the hwMstpPortId1 value. For example, the interface index of 10GE5/0/7 is 17. Deduct 1 from 17 to obtain the hwMstpPortId1 value 16 (0.0.hwMstpPortId1=16.0.0.0.0), that is hwMstpProNewPortState.0.0.16.0.0.0.0 (integer) disable(1). Therefore, the forwarding status of 10GE5/0/7 is disabled.
    Figure 2 Querying the forwarding status of an interface
