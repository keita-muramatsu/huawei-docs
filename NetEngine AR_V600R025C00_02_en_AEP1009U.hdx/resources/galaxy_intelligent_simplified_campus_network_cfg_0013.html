Configuring the Interface Rate for RUs

Context

In non-auto-negotiation mode, if the rates of the interfaces on two interconnected devices are different, the two devices may fail to communicate with each other. To prevent this, you need to configure the interface rate for RUs.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the single RU view.

    remote-unit { id | connect-interface interface-type interface-number | name remote-unit-name }

  3. Disable the auto-negotiation mode for an RU interface.

    undo negotiation auto port { portid1 [ to portid2 ] } &<1-32>

  4. Configure a fixed rate for an RU interface.

    speed speedvalue port { port-id1 [ to port-id2 ] } &<1-32>

    The value of speedvalue is 2500, 1000, 100, or 10.

  5. Deliver the configuration to the RU.

    commit
