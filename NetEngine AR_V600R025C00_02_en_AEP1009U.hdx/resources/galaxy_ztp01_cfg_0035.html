(Optional) Configuring Deployment File Security Verification

Context

To ensure security of USB-based deployment files for deployment of a device with a configuration file, you can set the COMPRESS_ENCRYTION field in the intermediate file to enable file compression with a password, and set a verification code in the HMAC field. Then you can perform encrypted compression and HMAC key-based integrity check on the deployment files.

  • When the function of compressing deployment files with a password is enabled in the intermediate file and the file needs to use HMAC to verify the integrity of the deployment files, the device decompresses the deployment files and then performs HMAC verification. The device continues the deployment only after the deployment files are decompressed and verified successfully.
  • When the function of compressing deployment files with a password is enabled in the intermediate file but the file does not need to use HMAC to verify the integrity of the deployment files, the device only decompresses the deployment files. The device continues the deployment only after the deployment files are decompressed successfully.
  • When the function of compressing the deployment files with a password is not enabled in the intermediate file and the file needs to use HMAC to verify the integrity of the deployment files, the device only performs HMAC verification on the deployment files. The device continues the deployment only after the deployment files are verified successfully.

Before compressing deployment files and configuring HMAC key-based verification, you must calculate the hash value for the files and compress the deployment files with a password.

Password for decompressing deployment files

  1. Before copying deployment files to the USB flash drive, you need to compress the deployment files into a .zip package using the specified password. The password must be the same as the password for decompressing the deployment file package.
    • Deployment files can only be encrypted and compressed on Huawei devices.
    • The .zip package name must be in the name_nametype.zip format, where name is the name of the file extracted from the package, and nametype is the type of the extracted file.
    • Each deployment file is compressed into a separate .zip package, and one .zip package can contain only one deployment file.
  2. During USB-based deployment, the device downloads the deployment files and uses the preset password to decompress them.

HMAC key for verifying the integrity of deployment files

  1. Before copying deployment files to the USB flash drive, you can use the openssl dgst tool to run the openssl dgst -hmac key -sha256 filename command to calculate a hash value based on the configured HMAC key for the deployment files and write it to the HMAC field in the intermediate file.
  2. During USB-based deployment, the device downloads the deployment files and uses the configured HMAC key to calculate the hash value of the deployment files.
  3. The device compares the calculated hash value with that of the HMAC field in the intermediate file. If the two values are the same, HMAC-based integrity verification succeeds.

Procedure

  1. Enter the system view.

    system-view

  2. Set a password for decompressing a deployment file.

    ztp usb-deployment file-compress password [ filepasswordval ]

    By default, no password is configured for decompressing a deployment file. The password must be the same as that used to compress the deployment file.

    If the weak password dictionary maintenance function is enabled, the passwords defined in the weak password dictionary cannot be used. To view these passwords, run the display security weak-password-dictionary command.

  3. Configure an HMAC key for deployment file integrity verification.

    ztp usb-deployment file-integrity password [ hmacpasswordval ]

    By default, no HMAC key is configured for deployment file integrity verification. The key must be the same as the HMAC key used to calculate the hash value of the deployment file.

    If the weak password dictionary maintenance function is enabled, the passwords defined in the weak password dictionary cannot be used. To view these passwords, run the display security weak-password-dictionary command.
