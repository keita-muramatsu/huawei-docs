Configuring a Radio

Context

You can configure and optimize radio parameters based on the actual network environment to enable APs with better signal transmit and receive capabilities, thereby improving wireless signal quality.

Radio profiles are used to configure parameters for optimizing radios. Radio profiles are classified as 2.4 GHz or 5 GHz radio profiles, which take effect on 2.4 GHz and 5 GHz/6 GHz radios, respectively. By default, the device provides the 2.4 GHz radio profile default and 5 GHz radio profile default, which are bound to all AP groups. Using the default radio profiles can simplify the operation procedures. However, in actual scenarios, it is recommended that you create different radio profiles and configure parameters in the profiles as required to meet various service requirements.

This section describes only the basic radio configuration procedure. For more parameter settings, see "RRM Configuration" in CLI Configuration Guide > WLAN Configuration.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an RRM profile and enter its view.

    rrm-profile name profile-name

    By default, the RRM profile default exists in the system.

  4. Return to the WLAN view.

    quit

  5. Create a radio profile and enter its view.

    • Create a 2.4 GHz radio profile and enter its view.
      radio-2g-profile name profile-name
    • Create a 5 GHz radio profile and enter its view.
      radio-5g-profile name profile-name

  6. Bind the RRM profile.

    rrm-profile profile-name

    By default, the RRM profile default is bound to a radio profile.

  7. Return to the WLAN view.

    quit

  8. Enter the AP group radio view or AP radio view.

    • Enter the AP group radio view.
      ap-group name group-name
radio radio
    • Enter the AP radio view.
      ap-id ap-id
radio radio

  9. Enable the radio.

    radio enable

    By default, radios of all APs in the AP group radio view are enabled, and the radio state in the AP radio view is the same as that in the AP group radio view.

    A radio can work only after being enabled. When radios of all APs are disabled in the AP group radio view, to enable radios on a single AP in the AP radio view, run the radio enable command in the corresponding AP radio view.

  10. Bind the radio profile.

    radio-2g-profile profile-name

    Or

    radio-5g-profile profile-name

    By default, the 2.4 GHz radio profile default and 5 GHz radio profile default are bound to AP group radios, and no radio profiles are bound to AP radios.
