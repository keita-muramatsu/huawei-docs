Applying Hierarchical CAR HQoS on an Inbound Interface

Context

On the forwarding plane of the device, the inbound interface cannot determine whether packets need to be decapsulated or on which interface the packets need to be decapsulated. Therefore, a flag needs to be delivered to the tunnel interface on which packets are decapsulated to notify the forwarding plane that the tunnel interface is the interface that decapsulates packets. In addition, ensure that the SD-WAN tunnel encapsulation protocol of the tunnel interface is set to sd-wan. A traffic policy needs to be executed after packets are decapsulated. A traffic policy containing a parent traffic policy for hierarchical CAR is applied to an inbound interface, which is the physical interface where the tunnel interface that performs decapsulation resides.

After the function of executing a traffic policy after decapsulation is enabled on a tunnel interface, the traffic policy for hierarchical CAR configured on a physical interface is executed when traffic passes through the tunnel interface. In this way, hierarchical CAR is implemented in the inbound direction in the SD-WAN EVPN scenario.

Procedure

  1. Enter the system view.

    system-view

  2. Configure a global CAR profile and specify the bandwidth in the inbound direction.

    qos car car-name { percent percent-value | cir cir-value [ kbps | mbps | gbps ] [ cbs cbs-value [ bytes | kbytes | mbytes ] [ pbs pbs-value [ bytes | kbytes | mbytes ] ] | pir pir-value [ kbps | mbps | gbps ] [ cbs cbs-value [ bytes | kbytes | mbytes ] pbs pbs-value [ bytes | kbytes | mbytes ] ] ] }

    The value of cir cir-value is the interface base value for hierarchical CAR.

  3. Enter the tunnel interface view.

    interface tunnel interface-number

  4. Configure the SD-WAN tunnel encapsulation protocol for the tunnel interface.

    tunnel-protocol sd-wan

    By default, the SD-WAN tunnel encapsulation protocol is not configured for a tunnel interface.

  5. Enable the function of executing a traffic policy after decapsulation on the tunnel interface.

    traffic-policy decap-process enable

    By default, the function of executing a traffic policy after decapsulation is disabled on a tunnel interface.

  6. Exit the tunnel interface view.

    quit

  7. Enter the interface view.

    interface { interface-type interface-number | interface-name }

  8. Configure a global CAR profile to be applied after decapsulation in the inbound direction.

    qos car inbound car-name decap-process

  9. Configure the parent traffic policy for hierarchical CAR to be applied after decapsulation in the inbound direction.

    traffic-policy policy-name inbound decap-process

    policy-name specifies the name of the parent traffic policy.
