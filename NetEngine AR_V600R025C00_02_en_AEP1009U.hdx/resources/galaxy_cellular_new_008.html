Configuring Basic Cellular Functions

Prerequisites

As shown in Figure 1, the procedure for configuring basic cellular functions consists of three parts: First, configure a cellular profile and an APN profile to select the network service type. Then, apply the cellular profile and APN profile to the cellular interface and cellular channel interface. Finally, configure the dial-up function. After the configuration is complete, the device can connect to a cellular network.
