Configuring a Manual IPv6 over IPv4 Tunnel

Context

A manual IPv6 over IPv4 tunnel is established between tunnel interfaces on two devices, and as a result, you need to configure tunnel interfaces on both devices. Before configuring a manual IPv6 over IPv4 tunnel, ensure that devices on both ends of the tunnel support IPv4/IPv6 dual stack.

Procedure

  1. Enter the system view.

    system-view

  2. Create a tunnel interface.

    interface tunnel interface-number

  3. Set the tunnel mode to manual IPv6 over IPv4.

    tunnel-protocol ipv6-ipv4

    Changing or deleting the tunnel mode of a tunnel interface will delete all tunnel-related configurations on the interface, such as the MTU. Exercise caution when performing this operation.

  4. Configure a source address or source interface for the tunnel.

    source { ipv4-address | interface-type interface-number }

    In device implementation, you can specify a Layer 3 interface or a loopback interface as the source interface of a tunnel. Similarly, you can specify a Layer 3 interface address or a loopback interface address as the source address of a tunnel.

  5. Configure a destination address for the tunnel.

    destination ip-address

    The destination address of the tunnel is the IP address of the destination interface, which can be a Layer 3 interface address or a loopback interface address.

  6. Enable IPv6 on the tunnel interface.

    ipv6 enable

  7. Configure an IPv6 address for the tunnel interface.

    ipv6 address { ipv6-address prefix-length | ipv6-address/prefix-length }

Verifying the Configuration

  • Run the display tunnel-interface [ interface-number ] command to check the working status of a tunnel interface.
  • Run the ping { -a source-ip-address | vpn-instance vpn-instance-name } command to check connectivity between physical interfaces on both ends of the tunnel.
  • Run the ping ipv6 { -a source-ipv6-address destination-ipv6-address | vpn-instance vpn-instance-name } command to check connectivity between tunnel interfaces on both ends of the tunnel.
