(Optional) Enabling 6PE Routes to Share the Explicit Null Label

Enabling IPv6 Provider Edge (6PE) routes to share the explicit null label can save label resources on 6PE devices.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the BGP view.

    bgp as-number

  3. Enter the BGP-IPv6 unicast address family view.

    ipv6-family unicast

  4. Enable all 6PE routes to be sent to the same 6PE peer to share the explicit null label.

    apply-label explicit-null

    If you run this command after a 6PE peer relationship is established, temporary packet loss occurs.
