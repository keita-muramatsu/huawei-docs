Configuring a Country Code

Context

A country code identifies the country or region in which APs are deployed. Different countries or regions have their own regulations on AP radio attributes, such as the transmit power and supported channels. The correct country code configuration ensures that AP radio attributes comply with local laws and regulations.

For channels supported in different countries, see WLAN Country Codes and Channels Compliance. You can also search for this document at Huawei technical support website.

The country code is configured in a regulatory domain profile. The following two configuration scenarios are typically involved:
  • If the APs managed by a WAC are distributed in the same country or region, you need to configure only one country code.
  • If a WAC needs to manage APs in different countries or regions, you need to configure different country codes for the APs.
Figure 1 shows a scenario requiring multiple country codes. The WAC centrally manages and controls the APs in country 1 using regulatory domain profile 1 and the APs in country 2 using regulatory domain profile 2. In this case, you need to configure the country code of country 1 in regulatory domain profile 1 and the country code of country 2 in regulatory domain profile 2.
Figure 1 Application scenario with multiple country codes

Before an AP goes online, the country code must be configured correctly to conform to local laws and regulations.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a regulatory domain profile and enter its view.

    regulatory-domain-profile name profile-name

    By default, the regulatory domain profile default exists in the system.

  4. Configure a country code.

    country-code country-code

    The default country code is CN. Note that changing the country code in a regulatory domain profile will interrupt services.

  5. Configure the calibration bandwidth and calibration channel set.

    • Configure the calibration channel set.
      dca-channel { 2.4g | 5g | 6g } channel-set channel-value

      By default, a calibration channel set contains channels 1, 6, and 11 on the 2.4 GHz radio and contains all channels supported by the corresponding country code on the 5 GHz radio and 6 GHz radio.

      The configured channels must be supported by STAs; otherwise, the STAs cannot discover radio signals.

      If some STAs on the network do not support all the channels in the calibration channel set and these STAs require continuous coverage, you are advised to adjust the channel configuration as follows:

      1. When channel resources are sufficient, modify the calibration channel set to ensure that the channels supported by STAs are allocated to APs.

      2. When channel resources are insufficient, disable automatic channel selection and manually plan channels.

    • Configure the calibration bandwidth.
      dca-channel 5g bandwidth { 20mhz | 40mhz | 80mhz | auto }
dca-channel 6g bandwidth { 20mhz | 40mhz | 80mhz | 160mhz | 320mhz | auto }

      By default, the calibration bandwidth value is auto.

  6. (Optional) Configure the indoor channel mode for outdoor APs.

    channel-load-mode indoor

    In some countries or regions, indoor and outdoor APs support different channels. That is, if an indoor AP and an outdoor AP are configured with the same country code, they may still work on different channels. In case that outdoor APs need to be used for indoor communication, you need to change the channel mode to indoor.

    By default, an outdoor AP uses the outdoor channel mode.

    After the channel mode is switched, the channel power limit is also switched to the indoor or outdoor specifications. For details about power limit values, see WLAN Country Codes and Channels Compliance.

  7. Return to the WLAN view.

    quit

  8. Enter the AP group view or AP view.

    • Enter the AP group view.
      ap-group name group-name
    • Enter the AP view.
      ap-id ap-id

  9. Bind the regulatory domain profile.

    regulatory-domain-profile profile-name

    By default, the regulatory domain profile default is bound to an AP group, and no regulatory domain profile is bound to an AP.

Verifying the Configuration

Run the display regulatory-domain-profile { all | name profile-name } command to check the country code and calibration channel set configured in a regulatory domain profile.
