Example for Configuring Queue Scheduling HQoS (Configuring a Drop Profile to Ensure Proper Bandwidth Utilization)

Networking Requirements

In Figure 1, there are three types of users on the network: user1, user2, and user3. They are assigned different IP address segments, and each type of users has their own services. A minimum assured bandwidth is configured for each user type, and the interface bandwidth needs to be shared to maximize its usage. Traffic from users of type user1 (VIP) must be preferentially transmitted.

Table 1 and Table 2 list the configuration requirements for different user types and services.

The AR6710-L14T2X4 does not support the configuration of the peak information rate (PIR) (specified by pir) for users. You can configure combined PQ and WDRR scheduling and a drop profile to properly use the remaining bandwidth.

Configuration Roadmap

The configuration roadmap is as follows:

  1. Assign an IP address to 10GE 0/0/1 (where HQoS will be applied) on DeviceA.
  2. Configure HQoS child traffic policies on DeviceA.
    1. Configure a WRED drop profile.
    2. Configure FQ profiles and set scheduling and shaping parameters for different services.
    3. Configure FQ traffic policies. Classify traffic based on DSCP values and reference FQ profiles in traffic behaviors.
  3. Configure an HQoS parent traffic policy on DeviceA.
    1. Configure an SQ profile and set scheduling and shaping parameters for different users.
    2. Configure an SQ traffic policy. Classify traffic based on DSCP values and reference the SQ profile and HQoS child traffic policies in traffic behaviors.
  4. Apply the HQoS parent traffic policy to the outbound interface 10GE 0/0/1 on DeviceA.

Procedure

  1. Configure 10GE 0/0/1 on DeviceA.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] undo portswitch
[DeviceA-10GE0/0/1] ip address 192.168.3.1 24
[DeviceA-10GE0/0/1] quit

  2. Configure a WRED drop profile on DeviceA.

    [DeviceA] drop-profile WRED
[DeviceA-drop-WRED] wred dscp
[DeviceA-drop-WRED] dscp 8 low-limit 12 high-limit 87 discard-percentage 50
[DeviceA-drop-WRED] dscp 10 low-limit 12 high-limit 87 discard-percentage 50
[DeviceA-drop-WRED] dscp 10 low-limit 12 high-limit 87 discard-percentage 50
[DeviceA-drop-WRED] dscp 14 low-limit 25 high-limit 87 discard-percentage 10
[DeviceA-drop-WRED] dscp 18 low-limit 25 high-limit 87 discard-percentage 50
[DeviceA-drop-WRED] dscp 20 low-limit 37 high-limit 87 discard-percentage 30
[DeviceA-drop-WRED] dscp 22 low-limit 50 high-limit 87 discard-percentage 10
[DeviceA-drop-WRED] dscp 24 low-limit 75 high-limit 87 discard-percentage 5
[DeviceA-drop-WRED] dscp 26 low-limit 12 high-limit 87 discard-percentage 50
[DeviceA-drop-WRED] dscp 28 low-limit 12 high-limit 87 discard-percentage 30
[DeviceA-drop-WRED] dscp 30 low-limit 50 high-limit 87 discard-percentage 10
[DeviceA-drop-WRED] dscp 32 low-limit 62 high-limit 87 discard-percentage 5
[DeviceA-drop-WRED] dscp 46 low-limit 62 high-limit 87 discard-percentage 5
[DeviceA-drop-WRED] dscp 48 low-limit 75 high-limit 87 discard-percentage 5
[DeviceA-drop-WRED] quit

  3. Configure HQoS child traffic policies on DeviceA.

    # Configure FQ profiles.

    [DeviceA] flow-queue fq1
[DeviceA-flow-queue-fq1] queue user1_meeting pq shaping 10000 drop-profile WRED
[DeviceA-flow-queue-fq1] queue user1_voice pq shaping 50000 drop-profile WRED
[DeviceA-flow-queue-fq1] queue user1_video pq shaping 5000 drop-profile WRED
[DeviceA-flow-queue-fq1] queue user1_data pq shaping 20000 drop-profile WRED
[DeviceA-flow-queue-fq1] quit
[DeviceA] flow-queue fq2
[DeviceA-flow-queue-fq2] queue user2_voice drr weight 10 shaping 50000 drop-profile WRED
[DeviceA-flow-queue-fq2] queue user2_video drr weight 20 shaping 200000 drop-profile WRED
[DeviceA-flow-queue-fq2] queue user2_data drr weight 20 shaping 160000 drop-profile WRED
[DeviceA-flow-queue-fq2] quit
[DeviceA] flow-queue fq3
[DeviceA-flow-queue-fq3] queue user3_voice drr weight 20 shaping cir-shaping-percentage 100 drop-profile WRED
[DeviceA-flow-queue-fq3] queue user3_video drr weight 20 shaping cir-shaping-percentage 100 drop-profile WRED
[DeviceA-flow-queue-fq3] queue user3_data drr weight 40 shaping 200000 drop-profile WRED
[DeviceA-flow-queue-fq3] quit

    # Configure FQ traffic policies.

    [DeviceA] traffic classifier user1_meeting type or
[DeviceA-classifier-user1_meeting] if-match dscp ef
[DeviceA-classifier-user1_meeting] quit
[DeviceA] traffic classifier user1_voice type or
[DeviceA-classifier-user1_voice] if-match dscp cs4
[DeviceA-classifier-user1_voice] quit
[DeviceA] traffic classifier user1_video type or
[DeviceA-classifier-user1_video] if-match dscp cs6
[DeviceA-classifier-user1_video] quit
[DeviceA] traffic classifier user1_data type or
[DeviceA-classifier-user1_data] if-match dscp cs3
[DeviceA-classifier-user1_data] quit
[DeviceA] traffic classifier user2_voice type or
[DeviceA-classifier-user2_voice] if-match dscp af13
[DeviceA-classifier-user2_voice] quit
[DeviceA] traffic classifier user2_video type or
[DeviceA-classifier-user2_video] if-match dscp af12
[DeviceA-classifier-user2_video] quit
[DeviceA] traffic classifier user2_data type or
[DeviceA-classifier-user2_data] if-match dscp af11
[DeviceA-classifier-user2_data] quit
[DeviceA] traffic classifier user3_voice type or
[DeviceA-classifier-user3_voice] if-match dscp af23
[DeviceA-classifier-user3_voice] quit
[DeviceA] traffic classifier user3_video type or
[DeviceA-classifier-user3_video] if-match dscp af22
[DeviceA-classifier-user3_video] quit
[DeviceA] traffic classifier user3_data type or
[DeviceA-classifier-user3_data] if-match dscp af21
[DeviceA-classifier-user3_data] quit
[DeviceA] traffic behavior user1_meeting
[DeviceA-behavior-user1_meeting] flow-queue fq1 queue user1_meeting
[DeviceA-behavior-user1_meeting] quit
[DeviceA] traffic behavior user1_voice
[DeviceA-behavior-user1_voice] flow-queue fq1 queue user1_voice
[DeviceA-behavior-user1_voice] quit
[DeviceA] traffic behavior user1_video
[DeviceA-behavior-user1_video] flow-queue fq1 queue user1_video
[DeviceA-behavior-user1_video] quit
[DeviceA] traffic behavior user1_data
[DeviceA-behavior-user1_data] flow-queue fq1 queue user1_data
[DeviceA-behavior-user1_data] quit
[DeviceA] traffic behavior user2_voice
[DeviceA-behavior-user2_voice] flow-queue fq2 queue user2_voice
[DeviceA-behavior-user2_voice] quit
[DeviceA] traffic behavior user2_video
[DeviceA-behavior-user2_video] flow-queue fq2 queue user2_video
[DeviceA-behavior-user2_video] quit
[DeviceA] traffic behavior user2_data
[DeviceA-behavior-user2_data] flow-queue fq2 queue user2_data
[DeviceA-behavior-user2_data] quit
[DeviceA] traffic behavior user3_voice
[DeviceA-behavior-user3_voice] flow-queue fq3 queue user3_voice
[DeviceA-behavior-user3_voice] quit
[DeviceA] traffic behavior user3_video
[DeviceA-behavior-user3_video] flow-queue fq3 queue user3_video
[DeviceA-behavior-user3_video] quit
[DeviceA] traffic behavior user3_data
[DeviceA-behavior-user3_data] flow-queue fq3 queue user3_data
[DeviceA-behavior-user3_data] quit
[DeviceA] traffic policy sub-policy1
[DeviceA-trafficpolicy-sub-policy1] classifier user1_meeting behavior user1_meeting
[DeviceA-trafficpolicy-sub-policy1] classifier user1_voice behavior user1_voice
[DeviceA-trafficpolicy-sub-policy1] classifier user1_video behavior user1_video
[DeviceA-trafficpolicy-sub-policy1] classifier user1_data behavior user1_data
[DeviceA-trafficpolicy-sub-policy1] quit
[DeviceA] traffic policy sub-policy2
[DeviceA-trafficpolicy-sub-policy2] classifier user2_voice behavior user2_voice
[DeviceA-trafficpolicy-sub-policy2] classifier user2_video behavior user2_video
[DeviceA-trafficpolicy-sub-policy2] classifier user2_data behavior user2_data
[DeviceA-trafficpolicy-sub-policy2] quit
[DeviceA] traffic policy sub-policy3
[DeviceA-trafficpolicy-sub-policy3] classifier user3_voice behavior user3_voice
[DeviceA-trafficpolicy-sub-policy3] classifier user3_video behavior user3_video
[DeviceA-trafficpolicy-sub-policy3] classifier user3_data behavior user3_data
[DeviceA-trafficpolicy-sub-policy3] quit

  4. Configure an HQoS parent traffic policy on DeviceA.

    # Configure an SQ profile.

    [DeviceA] qos-user-profile uq1 
[DeviceA-qos-user-profile-uq1] user-queue user1 pq cir 85000  
[DeviceA-qos-user-profile-uq1] user-queue user2 drr weight 50 cir 410000 
[DeviceA-qos-user-profile-uq1] user-queue user3 drr weight 80 cir 300000 
[DeviceA-qos-user-profile-uq1] quit

    # Configure an SQ traffic policy.

    [DeviceA] traffic classifier user1 
[DeviceA-classifier-user1] if-match dscp ef cs4 cs6 cs3 
[DeviceA-classifier-user1] quit 
[DeviceA] traffic classifier user2 
[DeviceA-classifier-user2] if-match dscp af13 af12 af11 
[DeviceA-classifier-user2] quit
[DeviceA] traffic classifier user3 
[DeviceA-classifier-user3] if-match dscp af23 af22 af21
[DeviceA-classifier-user3] quit
[DeviceA] traffic behavior user1
[DeviceA-behavior-user1] qos-user-profile uq1 user-queue user1
[DeviceA-behavior-user1] traffic-policy sub-policy1
[DeviceA-behavior-user1] quit
[DeviceA] traffic behavior user2
[DeviceA-behavior-user2] qos-user-profile uq1 user-queue user2
[DeviceA-behavior-user2] traffic-policy sub-policy2                       
[DeviceA-behavior-user2] quit
[DeviceA] traffic behavior user3
[DeviceA-behavior-user3] qos-user-profile uq1 user-queue user3
[DeviceA-behavior-user3] traffic-policy sub-policy3                      
[DeviceA-behavior-user3] quit
[DeviceA] traffic policy parent-policy
[DeviceA-trafficpolicy-parent-policy] classifier user1 behavior user1
[DeviceA-trafficpolicy-parent-policy] classifier user2 behavior user2
[DeviceA-trafficpolicy-parent-policy] classifier user3 behavior user3
[DeviceA-trafficpolicy-parent-policy] quit

  5. Apply the HQoS parent traffic policy to the outbound interface on DeviceA.

    [DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] qos queue-scheduling enable   //Run this command if the queue capability is disabled on the device interface.
[DeviceA-10GE0/0/1] traffic-policy parent-policy outbound
[DeviceA-10GE0/0/1] quit
