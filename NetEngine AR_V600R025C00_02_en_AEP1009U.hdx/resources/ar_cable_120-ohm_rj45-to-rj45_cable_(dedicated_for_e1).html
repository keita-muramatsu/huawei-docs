Connection

A 120-ohm RJ45-to-RJ45 cable is connected as follows:

  • One RJ45 connector is connected to a router.
  • The other RJ45 connector is connected to a network device.

If the default length is not enough for cable connection, you can use a 120-ohm trunk extension cable as an extension cable.

When using a 120-ohm trunk extension cable to prolong a 120-ohm RJ45-to-RJ45 cable, connect one RJ45 connector of the trunk cable to a network interface connector and the other RJ45 connector to the remote device, as shown in Figure 2.
