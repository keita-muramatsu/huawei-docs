Upgrading a Cellular Modem

Context

Running a firmware version that is too early on a cellular modem may result in the link becoming abnormal and affect services. If this happens, you are advised to upgrade the modem firmware. The following procedure uses Modem_LTE as an example.

  • The modem restarts after a firmware upgrade. Exercise caution when performing this operation.
  • Before performing the upgrade, ensure that the modem is correctly installed. Otherwise, the modem may become faulty. If the modem fails after the upgrade, contact technical support engineers.

Procedure

  1. Check the current versions of the device and modem.

    Run the display device command in any view and check the slot information, power supply information, and registration status of the cellular card.

    <HUAWEI> display device                                                 
xxxxx's Device status:                                               
-----------------------------------------------------------------------------------
Slot  Card   Type                     Online   Power Register     Alarm     Primary
-----------------------------------------------------------------------------------
0     -      xxxxx                    Present  On    Registered   Normal    Mast
1     -      Modem_LTE                Present  On    Registered   Normal    NA
-----------------------------------------------------------------------------------

    Run the display cellular hardware command in any view to check the modem version. This information is shown in the Modem Type and Modem Firmware Version fields.

    <HUAWEI> display cellular 1/0/0 hardware
Hardware Information:
  Modem Type                  : xxx modem
  Modem Firmware Version      : AAR01A02M2G_HJ
  International Mobile Equipment Identity (IMEI)  : 868227050005255

  2. Get the latest software and upload it to the device.

    1. Get the latest modem software package for the modem in use (Modem_LTE in this example).
    2. Use FTP or SFTP to upload the software package to the device. SFTP is recommended because it is more secure than FTP.

      Run the ftp command in the user view of the device to log in to the server (PC).

      <HUAWEI> ftp 10.1.2.0
Trying 10.1.2.0 ..
Press CTRL+K to abort
Connected to 10.1.2.0.
220 FTP Server ready.
User(10.1.2.0:(none)):1
331 Password required for 1.
Enter password:
230 Logged on

      In the FTP view, run the dir command to check the .pac package on the PC. Then, run the get command to download the latest software package from the PC to the root directory of the flash memory on the device. After that, run the dir command to check whether the software package is successfully downloaded to the device.

      During modem upgrade, the software package needs to be stored in the root directory of the flash memory.

      [ftp] dir *.pac
200 Port command successful.
150 Opening data connection for directory list.
-rw-rw-rw-   1 ftp      ftp     81742452 August 04 2022 module.pac
226 File sent ok
FTP: 81742452 byte(s) received in 0.3 second(s) 2.76Kbyte(s)/sec.
[ftp] get module.pac
200 Port command okay.
150 Opening data connection for module.pac.
226 Transfer complete.
FTP: 81742452 byte(s) received in 98.790 second(s) 827.43Kbyte(s)/sec.
[ftp] quit
[HUAWEI] quit
<HUAWEI> dir *.pac
Directory of flash:/
Idx  Attr     Size(Byte)  Date        Time       FileName
 0   -rw-     81,742,452  Aug 04 2022 11:33:48   module.pac
613,768 KB total (94,608 KB free)

  3. Upgrade the modem.

    Run the module-upgrade interface { interface-name | interface-type interface-number} directory command in the diagnostic view to upgrade the firmware of the cellular modem.

    [HUAWEI] diagnose
[HUAWEI-diagnose] module-upgrade interface Cellular1/0/0 flash:/module.pac
Warning: The service will be stopped during the upgrade. Do not reset, remove, or power off the module. Continue? [Y/N]:y 
Info: Delete the firmware after the upgrade is complete?[Y/N]:n 
Info: Start to upgrade the module.

  4. Check whether the upgrade is successful.

    If Module upgrade success. (Interface=[interface-name]) is displayed on the device, the modem has been upgraded successfully. If Module upgrade failure. (Interface=[interface-name]) is displayed, the modem failed to be upgraded.

    Alternatively, run the display cellular hardware command in any view and check the Modem Firmware Version field to determine whether the modem is upgraded successfully.
