Querying Electronic Label Information

Description of MIB Objects

hwRUModuleInfoTable describes electronic label information about device components, including the component model, BOM number, and production date.

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.
  2. Perform the Walk operation on entPhysicalName to query the component index entPhysicalIndex. As shown in Figure 1, the obtained component index is 16777217.
    Figure 1 Querying the entPhysicalIndex value through entPhysicalName

  3. Perform the Walk operation on hwEntityBomId based on the entPhysicalIndex value to query information such as the BOM number and production date. As shown in Figure 2, the BOM number of the component whose entPhysicalIndex value is 16777217 is 02354MKE.
    Figure 2 Querying the BOM number in hwEntityBomId based on the entPhysicalIndex value
