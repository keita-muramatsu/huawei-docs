Precautions for Using .proto Files

In most cases, .proto files are used by a collector to automatically generate code of the corresponding development language using a Protoc tool. The code then can be integrated into a development project. For example, when Intellij Idea is used as the compilation environment and a collector is developed using the Java language, the Protobuf Support plug-in can be used to process .proto files. In this case, note that the device releases one .proto file for each module. Each .proto file can be used independently. The .proto files generated for some complex modules may be large in size, resulting in a large amount of Java code generated based on these files. For example, when Java code is automatically generated based on the huawei-network-instance.proto file (480 KB), the size of the generated HuaweiNetworkInstance.java file reaches 78 MB, which exceeds the processing capability of Intellij Idea. As a result, an error indicating a large file size is reported during compilation. In this case, you need to delete unnecessary messages from the .proto file and re-compile the .proto file based on the actual interconnection requirements.
