Example for Configuring Traffic Policing Based on Application Identification

Networking Requirements

In Figure 1, an enterprise uses DeviceA as the gateway to connect to the Internet. To ensure network quality, avoid bandwidth waste, and ensure normal running of services, DeviceA detects the packets of FileShare_P2P applications (such as BT and eDonkey_eMule) and limits the rate of FileShare_P2P packets within 4 Mbit/s.

Figure 1 Network diagram for configuring traffic policing based on application identification

In this example, interface 1 represents 10GE 0/0/1.


Procedure

  1. Create an application group named FileShare_P2P and add the BT and eDonkey_eMule applications to the application group.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] application-group name FileShare_P2P 
[DeviceA-application-group-FileShare_P2P] add application BT
[DeviceA-application-group-FileShare_P2P] add application eDonkey_eMule
[DeviceA-application-group-FileShare_P2P] quit

  2. Configure a traffic classifier to match the application group FileShare_P2P.

    [DeviceA] traffic classifier p2p
[DeviceA-classifier-p2p] if-match app-group FileShare_P2P
[DeviceA-classifier-p2p] quit

  3. Configure a traffic behavior to limit the rate of identified FileShare_P2P packets.

    [DeviceA] traffic behavior p2p
[DeviceA-behavior-p2p] car cir 4096
[DeviceA-behavior-p2p] quit

  4. Configure a traffic policy and apply it to the inbound direction of an interface.

    # On DeviceA, create a traffic policy p2p and bind a traffic classifier to a traffic behavior in the traffic policy.

    [DeviceA] traffic policy p2p
[DeviceA-trafficpolicy-p2p] classifier p2p behavior p2p
[DeviceA-trafficpolicy-p2p] quit

    # Apply the traffic policy p2p to the inbound direction of interface 1 and enable application identification on the interface.

    [DeviceA] interface 10GE0/0/1
[DeviceA-10GE0/0/1] traffic-policy p2p inbound
[DeviceA-10GE0/0/1] sa enable
[DeviceA-10GE0/0/1] quit

Verifying the Configuration

# Check the traffic classifier configuration.

<DeviceA> display traffic classifier p2p
  Traffic Classifier Information:
    Classifier: p2p
      Type: OR
      Rule(s):
        if-match app-group FileShare_P2P

# Check the traffic policy configuration.

<DeviceA> display traffic policy p2p                                             
  Traffic Policy Information:                                                   
    Policy: p2p                                                                 
      Classifier: p2p                                                           
        Type: OR                                                                
      Behavior: p2p                                                             
        Committed Access Rate:                                                  
          CIR 4096 (Kbps), PIR 4096 (Kbps), CBS 32768 (Bytes), PBS 32768 (Bytes)
          Color Mode: color blind                                               
          Conform Action: pass                                                  
          Yellow  Action: pass                                                  
          Exceed  Action: discard

Configuration Scripts

DeviceA

#
sysname DeviceA
#
application-group name FileShare_P2P
 add application BT
 add application eDonkey_eMule
#
traffic classifier P2P type or
 if-match app-group FileShare_P2P  
#
traffic behavior P2P
 car cir 4096 kbps
#
traffic policy P2P 
 classifier P2P behavior P2P precedence 5
#
interface 10GE0/0/1
 traffic-policy im inbound 
 sa enable
#
return
