Replacing an RU

Context

You can replace an RU when it is faulty or needs to be replaced, for example, a 4-interface RU needs to be replaced by an 8-interface RU.

Procedure

  1. Remove the cable from the uplink interface on the original RU and connect the cable to the uplink interface on the new RU.
  2. Replace an RU.
    • If you replace an RU with the same model or an RU containing fewer interfaces with another RU containing more interfaces, you do not need to modify the configuration.
    • If you replace an RU with fewer interfaces with an RU with more interfaces, perform the following operations:
      1. Enter the single RU view.
        remote-unit { id | connect-interface interface-type interface-number | name remote-unit-name }
      2. Check the configuration of the current RU. Add the new interfaces in the interface configuration.
        display this

Verifying the Configuration

  • Run the display remote-unit connect record command to check disconnection records of the original RU and onboarding records of the new RU.
  • Run the display remote-unit command to check RU information. In the command output, the ESN field displays the new RU ESN. The original RU entry has been deleted.
