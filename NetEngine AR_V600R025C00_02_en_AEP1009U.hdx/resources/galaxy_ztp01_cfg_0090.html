Understanding Option Parameters

The DHCP server uses Option parameters to transmit network configurations to devices to implement automatic configuration during ZTP.

The device sends a DHCP Discover message that carries DHCPv4 Option parameters when the DHCP Discover phase starts in DHCPv4 scenarios. Table 1 describes the parameters.

Table 2 describes the DHCPv4 Option parameters to be configured on the DHCPv4 server.

The DHCP server does not support authentication and may be spoofed. You are advised to use a trusted DHCP server for deployment on a secure network.

Table 1 DHCPv4 Option parameters in a request

Option

Function

Example

Option 60

Vendor ID, which indicates the vendor and model of a device.

"huawei AR8140-12G10XG"

Option 61

Client ID, which indicates the MAC address of a device.

"00e0-fc12-3456"
