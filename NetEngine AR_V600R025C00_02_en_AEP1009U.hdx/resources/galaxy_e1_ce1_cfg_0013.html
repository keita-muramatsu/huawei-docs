Example for Configuring a Branch Site to Access the Headquarters Through an E1 Leased Line (E1 Mode)

Networking Requirements

As shown in Figure 1, a branch site is connected to the headquarters through an E1 leased line for communication. The E1 leased line works in E1 mode and uses PPP encapsulation and CHAP authentication.

Figure 1 Network diagram of configuring a branch site to access the headquarters through an E1 leased line

Procedure

  1. Configure the E1/CE1 interface to work in E1 mode.

    <HUAWEI> system-view 
[HUAWEI] sysname DeviceA
[DeviceA] controller e1 1/0/0
[DeviceA-E1 1/0/0] using e1
[DeviceA-E1 1/0/0] quit

  2. Configure PPP encapsulation and CHAP authentication.

    [DeviceA] interface serial 1/0/0:0 
[DeviceA-Serial1/0/0:0] link-protocol ppp   
[DeviceA-Serial1/0/0:0] ip address 2.2.2.2 24
[DeviceA-Serial1/0/0:0] ppp chap user user1  
[DeviceA-Serial1/0/0:0] ppp chap password cipher YsHsjx_202206

Verifying the Configuration

# Run the display interface serial 1/0/0:0 command to check the configuration of the interface. The command output shows that the physical layer status and link layer status of the interface are both up.

# Check that the branch device and headquarters device can ping each other.

Configuration Scripts

DeviceA

#
 sysname DeviceA 
#
controller e1 1/0/0
 using e1
#
interface serial 1/0/0:0
 link-protocol ppp
 ip address 2.2.2.2 255.255.255.0   
 ppp chap user user1
 ppp chap password cipher %@%@#0p7U*q6k~qRN7$#9'oY&\z&%@%@
#
return
