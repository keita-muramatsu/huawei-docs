Overview of Application Identification

Definition

Application identification allows a device to precisely identify applications/application-layer protocols commonly used on a network by analyzing the application/protocol signatures in traffic passing through the device.

Purpose

Without application identification, a device identifies applications based on protocols and port numbers. If different applications use the same protocol and port number, the device cannot distinguish them. To address this issue, the application identification feature was developed. This feature allows a device to more precisely identify applications by analyzing application-layer signatures in traffic.

For example, application identification allows a device to use application signatures to distinguish web games from web videos that both use HTTP and port 8080 for data transmission.
