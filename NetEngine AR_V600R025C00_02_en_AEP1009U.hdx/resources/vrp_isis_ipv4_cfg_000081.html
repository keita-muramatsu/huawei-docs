Configuring a Convergence Priority for Some IS-IS Routes

Prerequisites

Before configuring a convergence priority for some IS-IS routes, you have completed the following task:

  • Configure basic IS-IS functions.

Context

You can configure the highest convergence priority for some IS-IS routes so that these routes converge first when a network topology changes.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the IS-IS view.

    isis [ process-id ]

  3. Configure a convergence priority for the IS-IS routes that match a specified filtering rule.
    • For IPv4 IS-IS:
      prefix-priority [ level-1 | level-2 ] { critical | high | medium } { ip-prefix prefix-name | tag tag-value }
    • For IPv6 IS-IS:
      ipv6 prefix-priority [ level-1 | level-2 ] { critical | high | medium } { ipv6-prefix prefix-name | tag tag-value }

    By default, the convergence priority of IS-IS host routes (with a 32-bit mask) is medium, and the convergence priority of the other IS-IS routes is low.

    The rules for applying the convergence priorities of IS-IS routes are as follows:

    • If an IS-IS route matches the filtering conditions of multiple convergence priorities, the highest convergence priority is used.

    • By default, the convergence priority of Level-1 IS-IS routes is higher than that of Level-2 IS-IS routes.

    • If no level is specified in the prefix-priority command, the configuration takes effect on both Level-1 and Level-2 IS-IS routes.

    After the prefix-priority or ipv6 prefix-priority command is run, the convergence priority of 32-bit IS-IS host routes is changed from medium to low, and the convergence priorities of the other IS-IS routes are changed based on the configuration of the prefix-priority or ipv6 prefix-priority command.
