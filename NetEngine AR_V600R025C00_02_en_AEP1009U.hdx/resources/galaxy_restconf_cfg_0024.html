PUT

The PUT method is used to update or replace configuration data. If the PUT operation succeeds, the "200 OK" status code is returned without carrying the message body.

Unlike the PATCH method, the PUT method creates new data if the target data does not exist. It replaces the data completely. Therefore, all data needs to be sent. If some data is missing, the data that is not sent is cleared.

Update the login-alarm-threshold data.

  • Request

    PUT /restconf/data/huawei-aaa:aaa/login-alarm-threshold HTTP/1.1
Host: X.X.X.X
Accept: application/yang-data+xml
Content-Type: application/yang-data+xml
Content-Length: 180
Authorization: Basic YXBpLWFkbWluOkFkbWluQDEyMw==

<login-alarm-threshold xmlns="urn:huawei:yang:huawei-aaa">
   <report-times>50</report-times>
   <resume-times>40</resume-times>
   <period>30</period>
</login-alarm-threshold>

  • Response

    HTTP/1.1 200 OK
Date: Wed, 18 Apr 2022 12:00:00 GMT
Content-Type: application/yang-data+xml
Content-Length: 0
