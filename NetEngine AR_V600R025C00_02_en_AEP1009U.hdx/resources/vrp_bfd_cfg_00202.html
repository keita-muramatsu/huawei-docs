Example for Configuring a Multicast BFD Session with Automatically Negotiated Discriminators

Networking Requirements

As shown in Figure 1, a multicast BFD session is configured on DeviceA and DeviceB. The BFD session uses the default multicast IP address and is bound to interface1 to monitor link connectivity between interfaces.

Figure 1 Configuring a multicast BFD session with automatically negotiated discriminators

In this example, interface1 represents 10GE0/0/1.


Configuration Roadmap

The configuration roadmap is as follows:

  1. Enable BFD globally on DeviceA and DeviceB.

  2. Configure a multicast BFD session with automatically negotiated discriminators on DeviceA and DeviceB.

Procedure

  1. Enable BFD globally and configure a multicast BFD session with automatically negotiated discriminators on each device.

    # Configure DeviceA.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] bfd
[DeviceA-bfd] quit
[DeviceA] bfd atoa bind peer-ip default-ip interface 10GE 0/0/1 auto
[DeviceA-bfd-session-atoa] quit

    # Configure DeviceB.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceB
[DeviceB] bfd
[DeviceB-bfd] quit
[DeviceB] bfd atob bind peer-ip default-ip interface 10GE 0/0/1 auto
[DeviceB-bfd-session-atob] quit

Configuration Scripts

  • DeviceA

    #
sysname DeviceA
#
bfd
#
interface 10GE0/0/1
 ip address 10.1.1.1 255.255.255.0
#
bfd atoa bind peer-ip default-ip interface 10GE0/0/1 auto
#
return

  • DeviceB

    #
sysname DeviceB
#
bfd
#
interface 10GE0/0/1
 ip address 10.1.1.2 255.255.255.0
#
bfd atob bind peer-ip default-ip interface 10GE0/0/1 auto
#
return
