Configuring a Scenario Profile

Prerequisites

  1. WLAN planning has been completed based on user scenarios by referring to Scenario-based WLAN Planning Design.

    Scenario-based enterprise WLAN design provides network planning and design guidance for various scenarios. During project delivery, you can complete the network design by referring to the corresponding scenario-based design guides based on actual project deployment scenarios. By referring to sub-scenarios in the scenario-based design guides, you can configure scenario profiles for APs in different sub-scenarios.

  2. Configure APs to go online.

    When grouping APs, ensure that APs in the same group are deployed in the same scenario, that is, the same scenario profile is applicable to them. This way, the scenario profile can be configured for an AP group. For example, in an office area with several functional sub-areas, the user density is different in the sub-areas, therefore requiring different scenario profiles.

Context

In actual scenarios, there are fixed recommended settings for radio parameters such as the channel, bandwidth, and transmit power. Recommended settings for these typical scenarios are configured into scenario profiles. When configuring wireless services, you only need to bind a scenario profile to an AP group or a single AP, greatly simplifying service configuration.

To view the parameter settings in preset scenario profiles, run the display wlan scene command. If the value of a parameter is empty, a hyphen (-) is displayed, indicating that the parameter is not configured.

The service parameters on an AP take effect in the following sequence: Parameters in the scenario profile bound to an AP > Parameters directly configured for an AP > Parameters in the scenario profile bound to the AP group to which the AP belongs > Parameters directly configured for the AP group to which the AP belongs.

The calibration bandwidth of the 5 GHz frequency band is used as an example. Assume that the value of a parameter in a scenario profile a bound to the AP is empty, its value in scenario profile b bound to the AP group is B (80 MHz), its value configured for the AP is D (20 MHz), and its value configured for the AP group is E (40 MHz). Then the value of the parameter takes effect on the AP in the following sequence: empty > D > B > E. That is, the value in effect is D (20 MHz).

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Configure a scenario profile for an AP group.

    1. Enter the AP group view.
      ap-group name group-name
    2. Configure a scenario profile.
      scene scene-name

      By default, no scenario profile is bound to an AP group or a single AP.

    3. Return to the WLAN view.
      quit

  4. (Optional) Configure a scenario profile for an AP.

    If APs in an AP group involve differentiated scenarios or the scenarios identified by the analyzer are not accurate, you can configure scenario profiles for the APs, which take effect preferentially.

    1. Enter the AP view.
      ap-id ap-id
    2. Configure a scenario profile.
      scene scene-name

      By default, no scenario profile is bound to an AP group or a single AP.

Verifying the Configuration

  • Run the display wlan scene { name scene-name | all } command to check information about a scenario profile.
  • Run the display references scene name scene-name command to check reference information about a scenario profile.
  • Run the display ap-group name group-name command to check the scenario profile configured for an AP group.
  • Run the display ap config-info ap-id ap-id command to check the scenario profile and wireless service parameters configured on an AP.
