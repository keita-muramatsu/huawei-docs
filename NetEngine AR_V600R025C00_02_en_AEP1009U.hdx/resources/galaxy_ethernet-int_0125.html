Example for Configuring the Auto-Negotiation Rate Range of Ethernet Interfaces

Networking Requirements

As shown in Figure 1, DeviceD is connected to the Internet through 10GE0/0/4.

The rates of the network adapters on DeviceA, DeviceB, and DeviceC are all 100 Mbit/s. The rate of 10GE0/0/4 that connects DeviceD to the Internet is also 1000 Mbit/s. Typically, the rate of an Ethernet interface is determined by auto-negotiation with the peer end. The negotiated rate can be any rate supported by the Ethernet interface. If no auto-negotiation rate range is specified, the rates negotiated between 10GE0/0/1 and DeviceA, between 10GE0/0/2 and DeviceB, and between 10GE0/0/3 and DeviceC are 1000 Mbit/s. This may result in congestion on the outbound interface 10GE0/0/4. Users want to resolve data packet loss and congestion problems.

Figure 1 Network diagram of configuring auto-negotiation rates

In this example, interface1, interface2, interface3, and interface4 represent 10GE0/0/1, 10GE0/0/2, 10GE0/0/3, and 10GE0/0/4, respectively.


Configuration Roadmap

Configure the auto-negotiation rate range so that Ethernet interfaces can negotiate their rates within the configured range and thereby prevent congestion.

Procedure

  1. Configure auto-negotiation.

    # Configure auto-negotiation on interface1.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceD
[DeviceD] interface 10ge0/0/1
[DeviceD-10GE0/0/1] undo negotiation disable
[DeviceD-10GE0/0/1] quit

    # Configure auto-negotiation on interface2.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceD
[DeviceD] interface 10ge0/0/2
[DeviceD-10GE0/0/2] undo negotiation disable
[DeviceD-10GE0/0/2] quit

    # Configure auto-negotiation on interface3.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceD
[DeviceD] interface 10ge0/0/3
[DeviceD-10GE0/0/3] undo negotiation disable
[DeviceD-10GE0/0/3] quit

  2. Configure auto-negotiation rates.

    # Set the auto-negotiation rate of interface1 to 100 Mbit/s.

    [DeviceD] interface 10ge0/0/1
[DeviceD-10GE0/0/1] speed auto 100
[DeviceD-10GE0/0/1] quit

    # Set the auto-negotiation rate of interface2 to 100 Mbit/s.

    [DeviceD] interface 10ge0/0/2
[DeviceD-10GE0/0/2] speed auto 100
[DeviceD-10GE0/0/2] quit

    # Set the auto-negotiation rate of interface3 to 100 Mbit/s.

    [DeviceD] interface 10ge0/0/3
[DeviceD-10GE0/0/3] speed auto 100
[DeviceD-10GE0/0/3] quit

Configuring Scripts

DeviceD

sysname DeviceD
#

 undo negotiation disable
