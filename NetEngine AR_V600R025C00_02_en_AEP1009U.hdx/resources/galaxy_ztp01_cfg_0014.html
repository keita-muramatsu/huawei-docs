Preparing a URL

URL Format

When configuring a deployment email, a network administrator can use a URL to specify configurations required for deployment, including the network access mode, network access interface, controller IP address, and controller port number. A device then parses these parameters in the URL to complete the deployment configuration.

The URL in the deployment email is in the following format: https://ip/portal?ac_host=ac_host_value&ac_port=ac_port_value...&url_pass=url_pass_value. In this format, ... represents one or more parameters separated by ampersands (&). ip indicates the IP address of the web system. The default IP address of the web system is 192.168.1.1 and the subnet mask is 255.255.255.0.

In this example, the IP address and port number of the controller are 192.168.1.10 and 10020, respectively, the device's network access interface is GE0/0/4, the network access mode is PPPoE, the user name and password for PPPoE authentication are user and User@123, respectively, the VPN instance name is aA, the NTP server IP address is 1.1.1.1, the email generation time is 21:00 on February 27 in 2022, the language of the deployment Portal is English, and the URL verification code is 7b94b70e5e58139ee1ac6857848a0d94538c9c41dbd8088ca7b6987e3bbd5122. In this format, the URL is as follows:

https://192.168.1.1/portal?ac_host=192.168.1.10&ac_port=10020&link_if=GE0/0/4&link_model=PPPoE&link_user=user&link_password=User@123&link_vrf=aA&ntp_server=1.1.1.1&link_deliverytime=21:00:00/2022-02-27&url_lang=zh&url_pass=7b94b70e5e58139ee1ac6857848a0d94538c9c41dbd8088ca7b6987e3bbd5122

URL Parameters

Parameter

Mandatory or Not

Description

Value

Example

ac_host

Yes

IPv4 address of the controller.

NOTE:

A maximum of two IPv4 addresses can be configured. If two IPv4 addresses are configured, the value format is as follows: ac_host1=X.X.X.X;ac_host2=X.X.X.X.

The value is a character string in dotted decimal notation.

ac_host=10.1.1.1

ac_ipv6host

No

IPv6 address of the controller.

NOTE:

A maximum of two IPv6 addresses can be configured. If two IPv6 addresses are configured, the value format is as follows: ac_ipv6host1=X:X:X:X:X:X:X:X;ac_ipv6host2=X:X:X:X:X:X:X:X.

The value is a 128-bit IPv6 address in the format X:X:X:X:X:X:X:X, where X contains four hexadecimal digits.

ac_ipv6host=2001:db8:1::1

ac_port

Yes

Port number of the controller.

The value is an integer in the range from 1 to 65535.

ac_port=12345

link_esn

No

Device ESN.

The value is a character string, which must be the same as the device ESN.

link_esn=2102113374P0G3000324

link_if

Yes
Type and number of the network access interface on the device.
NOTE:

If the interface is an LTE interface, you need to configure APN information.

The value is a character string and must be the same as the interface name displayed on the device.

link_if=GE0/0/0

link_member_if

No

Name of an Eth-Trunk member interface.

The value is a character string. Separate multiple member interface names with commas (,).

link_member_if=GE0/0/1,GE0/0/3

link_ethtrunk_mode

No

Working mode of the Eth-Trunk interface.

The value is of the enumerated type.

  • lacp: static LACP mode.
  • load-balance: manual load balancing mode.

link_ethtrunk_mode=load-balance

checkIntegrity

No

Indicates whether to perform validity check.
The value is of the enumerated type.
  • 0: The parameters on the deployment page can be modified, and validity of the URL parameters is not verified.
  • 1: The parameters on the deployment page can be modified, and validity of the URL parameters is verified.
  • 2: The parameters on the deployment page cannot be modified, and validity of the URL parameters is not verified.
  • 3: The parameters on the deployment page cannot be modified, and validity of the URL parameters is verified.

When this parameter is not specified, the value 3 is used.

checkIntegrity=0

modification

Yes

Indicates whether a parameter can be modified.

Currently, this parameter has a fixed value of 14336. In the binary representation of this value, the value is 0 (a parameter cannot be modified) or 1 (a parameter can be modified) for each bit.

modification=14336

link_model

Yes

IPv4 network access mode.
The value is of the enumerated type.
  • DHCP: The device obtains an IPv4 address for its network access interface through DHCP.
  • PPPoE: The device obtains an IP address for its network access interface through PPPoE dial-up.
  • LTE: The device obtains an IPv4 address for its network access interface through LTE dial-up. If the network access interface is a cellular interface, LTE dial-up must be used.
  • Static: The device obtains a static IPv4 address for its network access interface.

link_model=DHCP

link_ip

No

IPv4 address of the interface on the device.

The value is a character string in dotted decimal notation.

link_ip=172.16.1.1

link_mask

No

Mask length of the IPv4 address.

The value is an integer in the range from 0 to 32.

link_mask=24

link_gateway

No

IPv4 address of the default gateway.

The value is a character string in dotted decimal notation.

link_gateway=10.0.0.0

link_bindifppp

No

Number of the dialer interface or Virtual-Template interface.

The value is a character string in the format of Dialer* or Virtual-Template*/*/*.

link_bindifppp=Dialer0

link_user

No

User name used in an LTE dial-up scenario. In this scenario, an APN authentication user name is specified.

The value is a string of 1 to 64 case-sensitive characters without spaces.

link_user=admin

link_password

No

Password used in an LTE dial-up scenario. In this scenario, an APN authentication password is specified.

NOTE:

This password must be encrypted even in plaintext scenarios.

The value is a string of 1 to 32 case-sensitive characters without spaces.

link_password=XXXXXXXX

web_password

Yes

Web user password used for device deployment.

NOTE:

This password must be encrypted even in plaintext scenarios.

The value is a string of 8 to 128 case-sensitive characters in plaintext or a string of 62 case-sensitive characters in ciphertext. The value can contain letters or digits.

web_password=XXXXXXXX

encrypt_key

No

Name of the parameter whose value needs to be encrypted in plaintext scenarios.

The value is a character string. Multiple parameter names are separated by commas (,).

encrypt_key=web_password,link_password

link_apn

No

APN network name in an LTE dial-up scenario.

The value is a string of 1 to 64 case-sensitive characters, without spaces.

link_apn=chinamobile

link_vrf

No

Name of a VPN instance.

The value is a string of 1 to 99 case-sensitive characters without spaces. It can contain letters, digits (0-9), hyphens (-), and underscores (_).

link_vrf=underlay_mpls

vrf_rd

No

Route distinguisher (RD) for a VPN instance address family.
The value format is as follows:
  • 2-byte AS number in integer format:4-byte user-defined number, for example, 101:3. An AS number ranges from 0 to 65535, and a user-defined number ranges from 0 to 4294967295. The AS number and user-defined number cannot both be 0. That is, an RD cannot be 0:0.
  • 4-byte AS number in integer format:2-byte user-defined number, for example, 65537:3. The AS number ranges from 65536 to 4294967295. The user-defined number ranges from 0 to 65535.
  • 4-byte AS number in dotted notation:2-byte user-defined number, for example, 0.0:3 or 0.1:0. Generally, a 4-byte AS number in dotted notation is in the format of x.y, where x and y are both integers in the range from 0 to 65535. The user-defined number ranges from 0 to 65535. The AS number and user-defined number cannot contain only zeros. That is, an RD cannot be 0.0:0.
  • IPv4 address:2-byte user-defined number, for example, 192.168.122.15:1. An IP address ranges from 0.0.0.0 to 255.255.255.255, and the user-defined number ranges from 0 to 65535.

vrf_rd=2222:2222

ntp_server

No

IPv4 address of an NTP server.

NOTE:

A maximum of two NTP server addresses can be configured, which are separated by a comma (,), for example, ntp_server=10.10.10.10,10.20.10.10.

The value is a character string in dotted decimal notation.

ntp_server=10.1.1.1

link_deliverytime

Yes

Email generation time.

The value is a character string in the HH:MM:SS/YYYY-MM-DD format.

link_deliverytime=00:00:00/2017-01-01

link_factoryset

No

Indicates whether to use factory configurations for the deployment.
The value is of the enumerated type.
  • 0: The factory configurations are not used for the deployment.
  • 1: The factory configurations are used for the deployment.

When this parameter is not specified, the value 0 is used.

link_factoryset=1

url_lang

No

Language of the deployment Portal.
The value is of the enumerated type.
  • en: English
  • zh: Chinese

url_lang=en

link_vlanid

No

Single-tagged VLAN ID for Dot1q termination on a sub-interface.

The value is an integer in the range from 1 to 4094.

link_vlanid=100

ac_token

No

Token for verifying the device type and validity period.

The value is a string of 48 characters.

The token is generally generated by invoking the Common interface.

ac_token=123456789012345678901234123456789012345678901234

link_ifmedia

No

Interface mode.
The value is of the enumerated type.
  • 0: The interface is configured to work as an optical interface.
  • 1: The interface is configured to work as an electrical interface.

link_ifmedia=1

link_ifmode

No

Interface negotiation mode, working mode, and rate.

The value is an integer in the range from 0 to 15.

The value is a decimal number. After the decimal number is converted to a four-bit binary number, each bit from right to left is explained as follows:
  • The first bit indicates the interface negotiation mode. The value 0 indicates the auto-negotiation mode, and the value 1 indicates the non-auto-negotiation mode.
  • The second bit indicates the interface working mode. The value 0 indicates the full-duplex mode, and the value 1 indicates the half-duplex mode.
  • The third and fourth bits indicate the interface rate. The values 00, 01, 10, and 11 indicate interface rates of 10 Mbit/s, 100 Mbit/s, 1000 Mbit/s, and 10000 Mbit/s, respectively.
For example, if the value of link_ifmode is 9, which is 1001 after being converted to a four-bit binary number, the interface negotiation mode is non-auto-negotiation, the working mode is full-duplex mode, and the interface rate is 1000 Mbit/s.

link_ifmode=9

link_tag

No

Tag of a static route. By configuring different tag values, you can classify static routes to implement different routing policies. For example, static routes with specified tag values can be imported into routing protocols through routing policies.

The value is an integer in the range from 1 to 4294967295. The default value is 0.

link_tag=10

link_type

No

Type of the IP address used for device deployment.

The value is a character string.

  • ipv4: IPv4
  • ipv6: IPv6
  • dual-stack: dual-stack (IPv4 and IPv6)

link_type=ipv4

link_ipv6_model

No

IPv6 network access mode.
The value is of the enumerated type.
  • DHCPv6: The device obtains an interface IP address through DHCPv6.
  • Static: The device obtains a static interface IP address.
  • PD: The device obtains an interface IP address from the IPv6 PD address pool.

link_ipv6_model=DHCPv6

link_ipv6

No

IPv6 address.

The value is a 128-bit IPv6 address in the format X:X:X:X:X:X:X:X, where X contains four hexadecimal digits.

link_ipv6=2001:db8:1::1

link_ipv6_mask

No

Mask length of the IPv6 address.

The value is an integer in the range from 1 to 128.

link_ipv6_mask=24

link_ipv6_gateway

No

IPv6 address of the default gateway.

The value is a 128-bit IPv6 address in the format X:X:X:X:X:X:X:X, where X contains four hexadecimal digits.

link_ipv6_gateway=2001:db8:1::1/64

ntp_ipv6_server

No

IPv6 address of an NTP server.

NOTE:

If multiple NTP server addresses need to be configured, separate them using commas (,), for example, ntp_ipv6_server=2001:db8:1::1,2001:db8:1::2.

The value is a 128-bit IPv6 address in the format X:X:X:X:X:X:X:X, where X contains four hexadecimal digits.

ntp_ipv6_server=2001:db8:1::1

link_ipv6_pd

No

Name of the DHCPv6 PD prefix bound to an interface.

The value is a string of 1 to 63 characters.

link_ipv6_pd=sdwanprefix

link_ipv6_pd_addr

No

IPv6 address and length of the DHCPv6 PD prefix bound to an interface.
The value is a character string in the format of IPv6 address/prefix length.
  • IPv6 address: The value is a 128-bit IPv6 address in the format X:X:X:X:X:X:X:X, where X contains four hexadecimal digits.
  • Prefix length: The value is an integer in the range from 1 to 128.

link_ipv6_pd_addr=::1/64

link_dhcpv6_opt16_type

No

Character string type of the Option 16 field carried in the request packets sent by the DHCPv6 client.
The value is a character string. The options are as follows:
  • ascii: indicates that the customized option code is an ASCII character string.
  • hex: indicates that the customized option code is a hexadecimal string.

link_dhcpv6_opt16_type=ascii

link_dhcpv6_opt16

No

Option 16 carried in the request packets sent by the DHCPv6 client.

The value is a string of case-sensitive characters without spaces. The value range is as follows:

  • When link_dhcpv6_opt16_type is set to ascii, the value ranges from 1 to 250.
  • When link_dhcpv6_opt16_type is set to hex, the value is a string of 10 to 256 characters and can contain digits (0-9), uppercase letters (A-F), and lowercase letters (a-f).

link_dhcpv6_opt16=101068,0001

link_dhcpv6_pd

No

DHCPv6 PD client function.

The value is a string of 1 to 63 case-sensitive characters without spaces.

link_dhcpv6_pd=sdwanprefix

ac_callhome

Yes

Name of a callhome template.

The value is a string of 1 to 31 characters.

ac_callhome=huawei-root

ac_endpoint

No

Name of an IPv4 NETCONF connection instance.

The value is a string of 1 to 64 case-sensitive characters, without spaces. Spaces can be contained if the string is enclosed in double quotation marks (" ").

ac_endpoint=GE0/0/1_192.168.1.1

ac_ipv6_endpoint

No

Name of an IPv6 NETCONF connection instance.

The value is a string of 1 to 64 case-sensitive characters, without spaces. Spaces can be contained if the string is enclosed in double quotation marks (" ").

ac_ipv6_endpoint=GE0/0/1_2001:db8:1::1

ac_ssh_user

Yes

SSH user name for creating a NETCONF channel. In SD-WAN scenarios, the value is fixed to huawei.

The value is a string of 1 to 253 characters.

ac_ssh_user=huawei

apn_profile_name

No

APN profile name.

The value is a string of 1 to 64 case-sensitive characters, without spaces. The value can contain letters, digits, dots (.), and hyphens (-), and must start and end with a letter or digit.

apn_profile_name=5gprofile

apn_auth_mode

No

Authentication mode for accessing an external PDN network.
  • pap: Password Authentication Protocol (PAP) authentication.
  • chap: Challenge Handshake Authentication Protocol (CHAP) authentication.

PAP authentication has low security. When pap is used, the password is transmitted in plaintext on the network, which poses security risks. Therefore, you are advised to use chap. Select an authentication mode based on carrier network requirements.

apn_auth_mode=chap

web_user

No

Web user name used to log in to the device to deliver deployment configurations.

The value is a string of 1 to 253 characters.

web_user=Huawei

certificate_host

No

IP address of the certificate server, which is used to apply for a certificate.

In the scenario where no initial certificate is available on the controller, the device needs to apply for a certificate from the certificate server and bind the certificate to itself before registering with the controller.

The value is an IP address, not a domain name. Only the IP address of one certificate server is supported.

certificate_host=10.1.1.1

certificate_ipv6host

No

IPv6 address of the certificate server, which is used to apply for a certificate.

In the scenario where no initial certificate is available on the controller, the device needs to apply for a certificate from the certificate server and bind the certificate to itself before registering with the controller.

The value is an IPv6 address, not a domain name. Only the IP address of one certificate server is supported.

certificate_ipv6host=2001:DB8:1::1

certificate_port

No

Port number of the certificate server.

The value is an integer in the range from 1 to 65535.

certificate_port=65421

certificate_verify_type

No

Verification type of the certificate server.
  • esn
  • verify-code
    NOTE:

    Currently, the value can only be set to esn.

certificate_verify_type=esn

url_pass

Yes

URL verification code, which is encrypted using SHA2-256.

NOTE:

This parameter is supported only when a URL is in plaintext.

The value consists of all preceding URL parameters, their values, and ampersands (&), excluding the verification parameter. The value format is as follows: Parameter1+Value1&Parameter2+Value2&Parameter3+Value3 ... ParameterN+ValueN.

url_pass=XXXXXXXX
