Configuring Network Cable Quality Check

Context

The network cable quality check function enables you to quickly locate network cable quality issues and adjust the cables accordingly, preventing services from being affected due to packet loss.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the interface view.

    interface interface-type interface-number

  3. Configure network cable quality check.

    cable-snr-test
    • This function checks real-time quality of the network cable on an interface. The network cable quality changes with the external environment.
    • An interface that is down or in loopback detection mode does not support the network cable quality check.
    • After the interface goes up, wait several minutes before running this command. Otherwise, the command fails to be delivered.
    • This command can be used after a network cable is connected to the interface.
