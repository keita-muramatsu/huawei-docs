Configuring STA IP Address Conflict Check

Context

When IP address conflicts occur on a network, frequent route flapping occurs, which greatly affects user services. In this case, you can enable STA IP address conflict check to prevent IP address conflicts. In a headquarters-branch scenario, private IP addresses of each branch are independently planned, and IP addresses of different branches may be on the same or overlapping network segment. To prevent STAs at different branches from failing to go online due to IP address conflicts, disable STA address conflict check in the VAP profile.

Disabling STA address conflict check takes effect only in direct forwarding scenarios.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a VAP profile view and enter its view.

    vap-profile name profile-name

  4. Enable STA IP address conflict check.

    undo learn-client-address { ipv4 | ipv6 } conflict-uncheck

    By default, STA IP address conflict check is enabled.

    Before disabling STA IP address conflict check, run the undo learn-client-address { ipv4 | ipv6 } disable command to enable STA IP address learning.
