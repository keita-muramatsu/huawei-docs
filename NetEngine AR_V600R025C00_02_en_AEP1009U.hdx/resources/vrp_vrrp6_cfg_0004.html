VRRP6 Fundamentals

VRRP is classified as VRRP for IPv4 or VRRP for IPv6 (VRRP6) by network type. As shown in Figure 1, multiple gateways are grouped to form a virtual gateway, and the host uses the virtual gateway's IPv6 address as the default gateway address to communicate with the external network. If a gateway fails, VRRP selects a different gateway to forward traffic, thereby ensuring reliable communication.

Figure 1 Network diagram of a VRRP6 group
Table 1 describes basic concepts of VRRP.
Table 1 VRRP fundamentals

Concept

Meaning

Virtual router

Also referred to as a VRRP group, consists of one master device and one or more backup devices. It serves as the default gateway for hosts within a shared LAN and is identified by a virtual router ID and one or more virtual IP addresses.

VRID

ID of a virtual router. A group of devices with the same VRID form a virtual router.

Virtual IP address

The IP address of a virtual router. A virtual router can have one or more IP addresses, as configured by users.

Virtual MAC address

A virtual MAC address is generated by a virtual router based on the virtual router ID. A virtual router has one virtual MAC address, in the format of 00-00-5E-00-01-{VRID} (VRRP for IPv4) or 00-00-5E-00-02-{VRID} (VRRP for IPv6). A virtual router uses the virtual MAC address instead of the actual interface MAC address to respond to ARP (VRRP for IPv4) or NS (VRRP for IPv6) requests.

IP address owner

A VRRP device is considered an IP address owner if it uses the virtual IP address as a real interface address. If an IP address owner is available, it usually functions as the master in a VRRP group.

Primary IP address

An IP address (usually the first configured one) selected from the set of real interface IP addresses. The primary IP address is used as the source IP address in a VRRP Advertisement packet.

VRRP router

A device running VRRP. It can belong to one or more virtual routers.

Virtual router master

A VRRP device that forwards packets.

Virtual router backup

A group of VRRP devices that do not forward packets. Instead, they can be elected as the new master if the current master fails.

Priority

Priority of a device in a VRRP group. A VRRP group elects the master and backup devices based on priorities.

VRRP preemption mode

In this mode, a backup device preempts the master role if it has a higher priority than that of the current master.

Non-preemption mode

In this mode, a backup device does not preempt the master role even if it has a higher priority than that of the current master, provided that the current master is working properly.

Adver_Interval timer

The master device sends a VRRP Advertisement packet each time the Adver_Interval timer expires.

Master_Down timer

A backup device preempts the master role after the Master_Down timer expires. The Master_Down timer value is calculated using the following formula: Master_Down timer value = (3 x Adver_Interval timer value) + Skew_Time, where Skew_Time = (256 - Priority)/256
