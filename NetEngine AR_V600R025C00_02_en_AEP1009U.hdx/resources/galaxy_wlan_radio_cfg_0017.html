Configuring Air Scan

Context

Before performing radio calibration, the WAC needs to analyze the air interface environment of APs. Therefore, the APs need to periodically scan radio signals in the surroundings and report the collected information to the WAC or server for data analysis.

The air scan profile takes effect only after being bound to a radio profile.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an air scan profile and enter its view.

    air-scan-profile name profile-name

    By default, the air scan profile default exists in the system.

  4. Enable the air scan function.

    undo scan-disable

    By default, the air scan function is enabled.

  5. (Optional) Configure the air scan period.

    scan-period period-time

    By default, the air scan period is 60 ms.

    When an AP scans the air interface, it continuously scans surrounding radio signals and reports the collected information to the WAC or server for data analysis services such as radio calibration. A longer air scan period indicates a higher volume of collected data and more accurate data analysis results. However, an excessively long air scan period affects normal WLAN services. The default value is recommended.

  6. (Optional) Configure the air scan interval.

    scan-interval interval-time

    By default, the air scan interval is 10000 ms.

    If the requirement for real-time data analysis is high, configure a small air scan interval using this command to improve the scan frequency. A higher scan frequency in turn imposes much larger impact on the services. Therefore, the scan interval of 3000 ms to 10000 ms is recommended.

  7. (Optional) Configure an air scan channel set.

    scan-channel-set { country-channel | dca-channel | work-channel }

    By default, an air scan channel set contains all channels supported by the country code of an AP.

  8. (Optional) Enable the scanning enhancement function.

    scan-enhancement

    By default, the scanning enhancement function is disabled.

  9. Return to the WLAN view.

    quit

  10. Enter the radio profile view.

    • Enter the 2.4 GHz radio profile view.
      radio-2g-profile name profile-name

      By default, the 2.4 GHz radio profile default exists in the system.

    • Enter the 5 GHz radio profile view.
      radio-5g-profile name profile-name

      By default, the 5 GHz radio profile default exists in the system.

    When the configured air scan channel set contains only 2.4 GHz channels, you only need to enter the 2.4 GHz radio profile view.

    When the configured air scan channel set contains only 5 GHz or 6 GHz channels, you only need to enter the 5 GHz radio profile view.

    When the configured air scan channel set contains 2.4 GHz, 5 GHz, and 6 GHz channels, you need to enter the 2.4 GHz and 5 GHz radio profile views accordingly.

    You can bind the created air scan profile to the current radio profile bound to the AP. To bind the air scan profile to a new radio profile, bind the radio profile to the radios of an AP group or a specific AP first. For details, see Applying a Profile.

  11. Bind the air scan profile.

    air-scan-profile profile-name

    By default, the air scan profile default is bound to a radio profile.

  12. # Configure the full-channel status monitoring function.
    1. Return to the WLAN view.

      quit

    2. Enter the AP radio view or AP group radio view.

      # Enter the AP group radio view.

      ap-group name group-name
radio radio

      # Enter the AP radio view.

      ap-id ap-id
radio radio

    3. Enable the full-channel status monitoring function.

      channel-monitor enable

      By default, the full-channel status monitoring function is disabled on radios in an AP group. If this function is not configured for radios on a single AP, the configuration in the AP group takes effect.

Verifying the Configuration

Run the display air-scan-profile { all | name profile-name } command to check the configuration of an air scan profile.

Run the display references air-scan-profile name profile-name command to check reference information about an air scan profile.
