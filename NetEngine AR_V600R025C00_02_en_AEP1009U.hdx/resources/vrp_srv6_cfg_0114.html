Configuring TE Attributes

Context

After receiving TE attributes configured for links, IS-IS advertises them to a controller through BGP-LS. This enables the controller to adjust links based on the TE attributes during SRv6 TE Policy computation.

TE link attributes are as follows:

  • Link bandwidth

    This attribute is mandatory if you want to limit the bandwidth of a path of an SRv6 TE Policy.

  • Link-specific TE metric

    The IGP metric or link-specific TE metric can be used for SRv6 TE Policy computation by a controller. This makes SRv6 TE Policy computation more independent of the IGP, facilitating path control.

  • Link administrative group

    The affinity attribute of an SRv6 TE Policy determines the link attributes used by the policy. The administrative group and affinity attribute are used together to determine the links that can be used by the policy.

  • SRLG

    A shared risk link group (SRLG) is a group of links that share a public physical resource, such as an optical fiber. Links in an SRLG are at the same risk of faults. If one of the links fails, other links in the SRLG also fail.

    An SRLG enhances SRv6 TE Policy reliability on a network with CR-LSP hot standby or TE FRR enabled. Links that share the same physical resource have the same risk. For example, if an interface goes down, its sub-interfaces also go down. As such, the interface and its sub-interfaces all share the same risk. Similarly, if the link of the primary path of an SRv6 TE Policy and the links of the backup paths of the SRv6 TE Policy are in an SRLG and the primary path goes down, the backup paths will most likely go down.

Procedure

  • Enable TE attributes.
    1. Enter the system view.

      system-view

    2. Enable TE attributes.

      te attribute enable

  • (Optional) Configure link bandwidth.

    In real-world applications, link bandwidth attributes only need to be configured on the outbound interface of the link through which an SRv6 TE Policy passes.

    1. Enter the system view.

      system-view

    2. Enter the interface view of the TE link.

      interface interface-type interface-number

    3. Configure the maximum reservable link bandwidth.

      te bandwidth max-reservable-bandwidth max-bw-value

    4. Configure link-specific BC0 bandwidth.

      te bandwidth bc0 bc0Bw

      • The maximum reservable link bandwidth cannot be higher than the physical link bandwidth. You are advised to set the maximum reservable link bandwidth to be less than or equal to 80% of the physical link bandwidth.

      • The BC0 bandwidth cannot be higher than the maximum reservable link bandwidth.

  • (Optional) Configure a link-specific TE metric value.
    1. Enter the system view.

      system-view

    2. Enter the interface view of the TE link.

      interface interface-type interface-number

    3. Configure a link-specific TE metric value.

      te metric metric-value

      By default, an IGP metric value is used as the TE metric value of a link.

  • (Optional) Configure the administrative group attribute in hexadecimal format.
    1. Enter the system view.

      system-view

    2. Enter the interface view of the TE link.

      interface interface-type interface-number

    3. Configure a link administrative group.

      te link administrative group group-value

  • (Optional) Configure the administrative group attribute based on the affinity bit name and administrative group name.
    1. Enter the system view.

      system-view

    2. Create an affinity bit name-value mapping template and enter the template view.

      path-constraint affinity-mapping

      This template must be configured on each node involved in SRv6 TE Policy path computation. The global mappings between the names and values of affinity bits must be the same on all the involved nodes.

    3. Configure the mapping between the name and value of each affinity bit.

      attribute bit-name bit-sequence bit-number

      This step configures only one bit of an affinity attribute, which has a total of 128 bits. Repeat this step as needed to configure some or all of the bits.

    4. Return to the system view.

      quit

    5. Enter the interface view of the TE link.

      interface interface-type interface-number

    6. Configure a link administrative group.

      te link administrative group name bit-name &<1-32>

      The name-string value must be in the range specified for the affinity attribute in the template.

  • (Optional) Configure an SRLG.
    1. Enter the system view.

      system-view

    2. Enter the interface view of the TE link.

      interface interface-type interface-number

    3. Add the interface to an SRLG.

      te srlg srlg-number

      In a hot-standby or TE FRR scenario, the SRLG attribute needs to be configured for the SRv6 TE Policy's outbound interface on the ingress and other member links in the SRLG to which the interface belongs. A link joins an SRLG only after SRLG attributes are configured for any outbound interface of the link.

      To delete the SRLG attribute configurations of all interfaces on the local node, run the undo te srlg all-config command.
