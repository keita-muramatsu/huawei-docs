fields

The fields parameter can be used to retrieve the subsets of the target data content. This parameter is allowed only for the GET or HEAD method. If it is used in other operation methods, "400 Bad Request" is returned.

Example: query nodes of domainName and accessLimit.

  • Request

    GET /restconf/data?fields=huawei-aaa:aaa/domains/domain(name;authen-scheme-name) HTTP/1.1
Host: X.X.X.X
Accept: application/yang-data+xml
Content-Type: application/yang-data+xml
Content-Length: 57
Authorization: Basic YXBpLWFkbWluOkFkbWluQDEyMw==

  • Response

    HTTP/1.1 200 OK
Date: Wed, 18 Apr 2022 12:00:00 GMT
Content-Type: application/yang-data+xml
Content-Length: 449

<?xml version="1.0" encoding="UTF-8"?>
 <data xmlns="urn:ietf:params:xml:ns:yang:ietf-restconf">
    <aaa xmlns="urn:huawei:yang:huawei-aaa">
      <domains>
        <domain>
          <name>default</name>
          <authen-scheme-name>default</authen-scheme-name>
        </domain>
        <domain>
          <name>default_admin</name>
          <authen-scheme-name>default</authen-scheme-name>
        </domain>
      </domains>
    </aaa>
</data>
