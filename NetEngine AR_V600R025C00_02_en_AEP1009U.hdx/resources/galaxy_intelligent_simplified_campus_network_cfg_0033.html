RU Onboarding Exception

Symptom

Connect an RU to the central device, power on the RU, and run the display remote-unit command in the user view on the central device to check RU information. The following situations are considered abnormal:

  1. The RU status is not Normal, Upgrading, or Configuring.
  2. Information about the RU is not displayed.

Possible Causes

  • The upstream link of the RU is incorrectly connected.
  • XLDP is not enabled on the central device.

Procedure

  1. Check whether the uplink is correctly connected.

    1. Check whether the uplink interfaces of the RU are directly connected to the central device. Check the cable connection between devices and ensure that the uplink interfaces of the RU are directly connected to the central device.
    2. Check whether the two uplink interfaces of the RU connect to the same central device. Check the cable connection between devices and ensure that the two uplink interfaces of the RU are connected to the same central device.
    3. Check whether the two interfaces connecting the central device to the RU are added to the same Eth-Trunk. Check the cable connection between devices, record the two interfaces connecting the central device and the RU, enter the views of the two interfaces on the central device, and run the display this command to check the Eth-Trunk to which the interfaces are added. Ensure that the two downlink interfaces connecting the central device and the RU are added to the same Eth-Trunk.
      <HUAWEI> system-view
[HUAWEI] interface 10GE0/0/1
[HUAWEI-10GE0/0/1] display this
 eth-trunk 111
return
[HUAWEI-10GE0/0/1] quit
[HUAWEI] interface 10GE0/0/1
[HUAWEI-10GE0/0/1] display this
 eth-trunk 111
return
[HUAWEI-10GE0/0/1] quit

    If the preceding links are correctly connected, go to Step 2.

  2. Check whether XLDP is enabled on the central device.

    1. Check whether XLDP is enabled globally.
      # Run the display current-configuration | include xldp command to check global XLDP configurations. If the command output contains xldp disable, XLDP is disabled globally. In this case, run the xldp enable command to enable XLDP. If no information is displayed, XLDP is enabled globally.
      <HUAWEI> system-view 
[HUAWEI] display current-configuration | include xldp
 xldp disable
[HUAWEI] xldp enable
[HUAWEI] display current-configuration | include xldp
    2. Check whether XLDP is enabled on the interface connecting the central device and RU.
      # Run the display this include-default | include xldp command on the interface to check the XLDP configuration. If the command output contains xldp disable, XLDP is disabled globally. In this case, run the xldp enable command to enable XLDP. If no information is displayed, XLDP is enabled globally.
      [HUAWEI] interface 10GE0/0/1
[HUAWEI-10GE0/0/1] display this include-default | include xldp
 xldp disable
[HUAWEI-10GE0/0/1] xldp enable
[HUAWEI-10GE0/0/1] display this include-default | include xldp
[HUAWEI-10GE0/0/1] quit

  3. Check statistics about sent and received XLDP packets on the interface connecting the central device and RU.

    [HUAWEI] display xldp statistics interface 10GE0/0/1 
Statistics for 10GE0/0/1: 
Transmitted frames total      : 13 
  Hello frames                : 13 
  Channel frames              : 0 
Received frames total         : 13 
  Hello frames                : 13 
  Channel ACK frames          : 0 
[HUAWEI] quit

    In the command output, Transmitted frames total indicates the number of XLDP packets sent by the central device interface, and Received frames total indicates the number of XLDP packets received by the central device interface. If there are no statistics about sent and received XLDP packets on the interface, perform Step 4.

  4. Enable debugging on the central device and collect debugging information for maintenance personnel to preliminarily determine the fault.

    # Before running this command, run the terminal debugging and terminal monitor commands to enable system debugging.
    <HUAWEI> terminal debugging 
<HUAWEI> terminal monitor
<HUAWEI> system-view
[HUAWEI] info-center enable
[HUAWEI] diagnose 
[HUAWEI-diagnose] debugging remote-unit manage all

  5. Collect log and configuration information and contact technical support personnel. You can run the display diagnostic-information command to collect diagnostic information.
