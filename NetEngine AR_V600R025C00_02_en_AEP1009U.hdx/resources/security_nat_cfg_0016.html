Configuring a Source NAT Address Pool

Context

To configure NAPT, 3-tuple NAT, or NAT No-PAT, you need to create a NAT address pool, specify the post-NAT address range, and configure a blackhole route before creating a NAT policy.

You do not need to configure a source NAT address pool if source NAT in Easy IP mode is used.

Procedure

  1. Enter the system view.

    system-view

  2. Create a NAT address pool and enter the NAT address pool view.

    nat address-group group-name [ group-number ]

  3. Specify IP address ranges in the address pool using either of the following methods:
    • Configure one or more IP address ranges.
      section [ id ] start-ipv4 [ end-ipv4 ]
    • Specify a large address range and exclude some addresses or ports from the range.
      section [ id ] start-ipv4 [ end-ipv4 ]
exclude-ip { ip-address1 [ to ip-address2 ] | ip-address1 mask { mask-value | mask-length } }
exclude-port port1 [ to port2 ]

      Each address pool can have a maximum of 100 address ranges excluded. You can run the exclude-port command for an address pool for a maximum of 100 times, and each time you can exclude a maximum of 256 ports.

  4. Configure a source NAT mode for the address pool.

    Table 1 Configure a source NAT mode for the address pool.

    Source NAT Mode

    Command

    Description

    NAT No-PAT

    mode no-pat { global | local }

    There are one-to-one mappings between private and public IP addresses, and port translation is not performed. You can configure local or global No-PAT.

    NAPT

    mode pat

    Multiple private IP addresses share one or more public IP addresses, and both source IP addresses and port numbers are translated.

    3-tuple NAT

    mode full-cone { global | local } [ no-reverse ]

    Optional: smart-fullcone exclude-dest-port port1 port2

    Multiple private IP addresses share one or more public IP addresses, both source IP address and port numbers are translated, and Internet users are allowed to proactively communicate with private network users.

    Smart 3-tuple NAT supports a reserved port range for NAPT translation.

  5. Configure a blackhole route to prevent routing loops.

    Table 2 Configuring a blackhole route

    Command

    Function

    route enable

    Enables the function of delivering open programming routes (OPRs) for addresses in a NAT address pool.

    route enable vpn-instance

    Generates OPRs for addresses in a NAT address pool in a specified VPN.

Verifying the Configuration

Run the display nat address-group command to check information about the NAT address pool.
