(Optional) Configuring the Device to Obtain the DNS Server Address Specified on the PPPoE Server

Context

If the device functions as a PPPoE client and connects to a downstream LAN on which hosts directly access domain names, you need to configure the device to obtain the DNS server address specified on the PPPoE server.

You can configure the PPPoE client to accept the DNS server address specified on the PPPoE server or request a DNS server address from the PPPoE server.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the dialer interface view.

    interface dialer number

  3. Configure the PPPoE client to obtain the DNS server address allocated by the PPPoE server.

    Perform either of the following operations as required:

    • Configure the PPPoE client to accept the DNS server address specified on the PPPoE server.
      ppp ipcp dns admit-any

    By default, a PPPoE client does not accept the DNS server address specified on a PPPoE server.

    • Configure the PPPoE client to request a DNS server address from the PPPoE server.
      ppp ipcp dns request

    By default, a PPPoE client does not request a DNS server address from a PPPoE server.

    After the configuration is complete, restart the interface in the corresponding interface view to make the configuration take effect.

  4. Configure the device to borrow the DNS server IP address obtained by the specific interface as the local DNS server IP address.

    Perform any of the following operations as required:

    • Configure the device to borrow the DNS server IP address obtained by the specific interface as the local DNS server IPv4 address.
      dns server unnumbered interface { interface-type interface-num | interface-name }

    • Configure the device to borrow the DNS server IP address obtained by the specific interface as the local DNS server IPv6 address.
      dns server ipv6 unnumbered interface { interface-type interface-num | interface-name }
