(Optional) Configuring HDLC Link Status Monitoring

To effectively monitor the status of HDLC links, configure the HDLC link status monitoring function.

Context

The parameters for HDLC link status monitoring include:

  • Keepalive time

    • Polling interval

      The polling interval determines how frequently an interface sends a Keepalive packet to the peer device. The interval begins when HDLC is configured as the link layer encapsulation protocol on the interface.

    • Keepalive count

      Each time the local device does not receive a Keepalive packet from the peer device within a specified polling interval, the Keepalive count increments by 1. After a specified Keepalive count is reached, the device considers the link faulty and sets the link status to down.

    The Keepalive time equals the polling interval multiplied by the Keepalive count. In situations with a considerable amount of network delay or congestion, a short Keepalive time may cause network flapping. On the other hand, a long Keepalive time may lead to delayed detection of link faults. Consider the actual network situation when setting these parameters.

Procedure

  • Set a polling interval.
    1. Enter the system view.

      system-view

    2. Enter the interface view.

      interface interface-type interface-number

    3. Set a polling interval.

      timer hold interval

      The polling intervals set on the two ends of a link must be the same. If the polling interval is set to 0 on both ends, the link detection function is disabled.

  • Set a Keepalive count.
    1. Enter the system view.

      system-view

    2. Enter the interface view.

      interface interface-type interface-number

    3. Set a Keepalive count.

      keepalive count number
