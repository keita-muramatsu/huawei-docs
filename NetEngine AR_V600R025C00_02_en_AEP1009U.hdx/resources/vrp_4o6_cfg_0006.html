Configuring an IPv4 over IPv6 Tunnel

Context

An IPv4 over IPv6 tunnel is established between tunnel interfaces on two devices, and as a result, you need to configure tunnel interfaces on both devices. A tunnel interface is a logical interface and goes down in the following situations:

  • The destination address configured for the tunnel interface is unreachable or is its own IP address.

  • The source interface configured for the tunnel interface is down.

  • The IP address configured for the tunnel interface is invalid.

Procedure

  1. Configure a source interface for an IPv4 over IPv6 tunnel.
    1. Enter the system view.
      system-view
    2. Create a loopback interface.
      interface loopback loopback-number

      In device implementation, you can specify a Layer 3 interface or a loopback interface as the source interface of a tunnel. Similarly, you can specify a Layer 3 interface address or a loopback interface address as the source address of a tunnel.

    3. (Optional) Bind the loopback interface to a VPN instance.
      ip binding vpn-instance vpn-instance-name
    4. Enable IPv6 on the loopback interface.
      ipv6 enable
    5. Configure an IPv6 address for the loopback interface.
      ipv6 address { ipv6-address prefix-length | ipv6-address/prefix-length }
    6. Exit the loopback interface view.
      quit
  2. Configure a tunnel interface.
    1. Create a tunnel interface.
      interface tunnel interface-number
    2. Set the tunnel type to IPv4 over IPv6.
      tunnel-protocol ipv4-ipv6

      Changing or deleting the tunnel mode of a tunnel interface will delete all tunnel-related configurations on the interface, such as the MTU. Exercise caution when performing this operation.

    3. Configure a source IPv6 address or source interface for the tunnel.
      source { ipv6-address | interface-type interface-number }

      In device implementation, you can specify a Layer 3 interface or a loopback interface as the source interface of a tunnel. Similarly, you can specify a Layer 3 interface address or a loopback interface address as the source address of a tunnel.

    4. Configure a destination IPv6 address for the tunnel.
      destination [ vpn-instance vpn-instance-name ] ipv6-address

      The destination address of the tunnel is the IP address of the destination interface, which can be a Layer 3 interface address or a loopback interface address.

    5. Configure an IPv4 address for the tunnel interface.
      ip address ip-address { mask | mask-length } [ sub ]

      By default, no IPv4 address is configured for a tunnel interface.

    6. Exit the tunnel interface view.
      quit
  3. Configure routing to forward packets along the tunnel.
    • Configure a static route.
      ip route-static ip-address { mask } tunnel interface-number

      Static routes must be configured on both ends of a tunnel. For each static route, the destination address is the destination IPv4 address of the original packet before being encapsulated, and the next hop is a tunnel interface on the remote device. In a VPN scenario, you also need to specify the VPN instance to which the next-hop address belongs.

    • Configure a dynamic routing protocol.

      You need to enable the dynamic routing protocol on the tunnel interface and the IPv4 network interfaces at both ends of the tunnel. For details, see the IP Routing Configuration Guide.

Verifying the Configuration

  • Run the display tunnel-interface [ interface-name] command to check the working status of a tunnel interface.
  • Run the display ip routing-table command to check IP routing information.
  • Run the ping { -a source-ip-address | vpn-instance vpn-instance-name } command to check connectivity between the two ends of the tunnel.
