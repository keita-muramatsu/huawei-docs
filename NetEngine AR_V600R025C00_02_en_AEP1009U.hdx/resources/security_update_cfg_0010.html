Configuring Automatic Online Signature Database Update

Prerequisites

  • The operations in Preparations for Signature Database Update have been completed.
  • If the device connects to the update center through the Internet to update the signature database online, the operations in Configuring the Device to Communicate with the Huawei Intelligent Security Center have been completed.

Context

With the automatic online update function, the device automatically queries and downloads the signature database at a preconfigured time, and then updates the local signature database to the latest version.

The recommended interval for online update of each signature database is as follows:
  • IPS signature database: once a week
  • Antivirus signature database: once a day
  • Application identification signature database: once a week

Select an update interval and update time based on your network requirements, and ensure that the update will not occupy the network resources of key services during peak hours.

Procedure

  1. Enter the system view.

    system-view

  2. Enable automatic online update for the signature database.

    update schedule { av-sdb | ips-sdb | sa-sdb } enable

    For the AR5700 series, only the AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S and AR5710-S10T1X2 do not support the ips-sdb and av-sdb parameters.

  3. Configure an interval for automatically updating the signature database.

    update schedule
update schedule { daily | weekly { mon | tue | wed | thu | fri | sat | sun } } time
update schedule { ips-sdb | av-sdb } { hourly minute | { daily | weekly { mon | tue | wed | thu | fri | sat | sun } } time }
update schedule sa-sdb { daily | weekly { mon | tue | wed | thu | fri | sat | sun } } time
    • The update schedule command is used to randomly select a time from 00:00 to 07:59 as the scheduled time for updating all signature databases every day.
    • You can specify the hourly minute parameter to configure the signature database to be updated at the specified interval.
    • You can specify a time for daily or weekly updates using the { daily | weekly { mon | tue | wed | thu | fri | sat | sun } } time parameter.

    For the AR5700 series, only the AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S and AR5710-S10T1X2 do not support the ips-sdb and av-sdb parameters.
