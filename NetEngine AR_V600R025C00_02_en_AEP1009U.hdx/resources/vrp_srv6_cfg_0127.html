Configuring BGP EPEv6

Context

BGP egress peer engineering (EPE) is used to allocate Peer-Node and Peer-Adj SIDs to peers. These SIDs can be reported to a controller through BGP-LS for orchestrating E2E SRv6 TE Policies. BGP EPE is also called BGP EPEv6 in SRv6 scenarios. Unless otherwise specified, BGP EPE refers to BGP EPEv6 in this section.

Procedure

  1. Enter the system view.

    system-view

  2. Enable SR.

    segment-routing ipv6

  3. Return to the system view.

    quit

  4. Enable BGP and enter the BGP view.

    bgp { as-number-plain | as-number-dot }

  5. Create a BGP peer.

    peer ipv6-address as-number { as-number-plain | as-number-dot }

  6. Enable BGP EPE.

    You can enable EPE using either of the following methods based on site requirements. The two methods override each other. If both methods are used, the configuration performed using the latter method takes effect.

    • Enable BGP EPE and specify a locator to be used for SID allocation to a specific peer.
      peer peerIpv6Addr egress-engineering srv6 locator locator-name
    • Enable BGP EPE and inherit a globally referenced locator.
      1. Specify a locator to be globally referenced by BGP EPE.
        segment-routing ipv6 egress-engineering locator locator-name
      2. Enable BGP EPE and inherit the globally referenced locator for SID allocation.
        peer peerIpv6Addr egress-engineering srv6 inherit-global-locator
  7. (Optional) Configure a static SID.

    The peer peerIpv6Addr egress-engineering srv6 inherit-global-locator command must have been configured before you perform this step.

    The following commands can be configured separately or together based on the application scenario.

    • Configure a static End.X SID (PSP) or End.X SID (no flavor).
      peer peerIpv6Addr egress-engineering srv6 static-sid { psp psp-sid | no-flavor no-flavor-sid }
    • Configure a static End.X SID (PSP, USP, and USD).
      peer peerIpv6Addr egress-engineering srv6 static-sid psp-usp-usd sid-value

Verifying the Configuration

Run the display bgp egress-engineering command to check BGP EPE information. If SIDs are displayed in the SRv6 SID and SRv6 SID (PSP) fields, the configuration succeeds.
