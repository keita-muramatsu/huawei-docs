NAC Bypass Mechanism

The NAC bypass mechanism grants specified network access rights to users when the authentication server is down, when users fail authentication, or when users are in pre-connection state. The bypass solutions that are supported depends on the authentication mode in use.

Wireless 802.1X users do not support authentication event authorization for bypass authorization, including authorization upon no response from the 802.1X client, authorization upon server down, authorization upon authentication failures, and pre-connection authorization.

After the pre-connection function is enabled on the device, the device assigns network access rights configured in each network state, in listed order of priority:
  • If the authentication server is down: network access rights assigned when the authentication server is down > network access rights assigned when users fail authentication > network access rights assigned when users are in pre-connection state
  • If users fail authentication: network access rights assigned when users fail authentication > network access rights assigned when users are in pre-connection state
  • If users are in pre-connection state: network access rights assigned when users are in pre-connection state
  • If the 802.1X client does not respond: network access rights assigned when the 802.1X client does not respond > network access rights assigned when users are in pre-connection state
  • If the Portal server is down: network access rights assigned when the Portal server is down > network access rights assigned before the Portal server is down
