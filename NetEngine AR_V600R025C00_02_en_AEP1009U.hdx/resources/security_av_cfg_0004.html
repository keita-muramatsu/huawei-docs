Antivirus Processing Procedure

The antivirus processing procedure consists of two parts: virus detection using the Adaptive Security Engine (ASE) and antivirus processing. Figure 1 shows the process. The ASE identifies the application protocols contained in traffic, and then performs virus detection on traffic with a protocol type that supports virus detection.

Figure 1 Antivirus processing procedure
  1. Perform application protocol identification.

    The virus detection capability of the antivirus feature is implemented by the adaptive security engine (ASE). After traffic enters the engine, the engine performs in-depth analysis to identify the protocol type and file transfer direction. The engine checks whether virus detection has been enabled for the protocol used to transfer files in the current file transfer direction. If virus detection has been enabled for the protocol, the engine sends the traffic to the virus detection module.

    • The device can perform virus detection over the files transferred using the following protocols: FTP, HTTP, POP3, SMTP, IMAP, NFS, and SMB.
    • The device can perform virus detection over the files transferred in both the upload and download directions. The upload direction indicates that files are transferred from the client to the server, and the download direction indicates that files are transferred from the server to the client.
  2. Virus detection

    The device extracts signatures of files that support virus detection and matches the extracted signatures against the virus signatures in the antivirus signature database. If the signatures match, the file is considered a virus file and is then sent to the antivirus module. If the signatures mismatch, the file transfer is permitted.

    The antivirus signature database stores the signatures of common virus files on the network, which can be used by the antivirus function for virus detection. Periodically updating the antivirus signature database enhances the virus detection capability of a device against new viruses. For details, see Updating the Antivirus Signature Database.

  3. Response

    After detecting a virus file, the device processes the virus file based on configurations in the antivirus profile.

    1. Check whether this virus file is an exception. If it is an exception, the device processes the file according to the action defined for the exception.

      To prevent file transfer failures resulting from false positives, you can add the names of the viruses that are identified as false positives to virus exceptions and set the action to permit, so as to disable the virus rules. If a file is detected to be an exception, it is permitted to transfer.

    2. If a file is not an exception, it is processed according to the action specified in the profile.
      • Alert: indicates the device permits the virus file and generates a virus log.
      • Block: indicates the device blocks the virus file and generates a virus log.
