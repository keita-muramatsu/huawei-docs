WMI Profile

Overview

To improve the efficiency of handling Wi-Fi network problems, you can report AP KPIs to a WMI server for fault cause analysis. In addition, centralized statistics help you better observe the change trends of devices and networks and identify possible device or network problems in advance.

For details about how to configure a WMI profile, see "Configuring the KPI Reporting Function" in CLI Configuration Guide > WLAN Configuration > WLAN O&M Monitoring Configuration.

Creating a Profile

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a WMI profile and enter its view.

    wmi-server name profile-name

    By default, no WMI profile is created.

Applying a Profile

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP system profile and enter its view.

    ap-system-profile name profile-name

    By default, the AP system profile default exists on the device.

  4. Bind the specified WMI profile to the AP system profile.

    wmi-server profile-name index index

    By default, no WMI profile is bound to an AP system profile.

  5. Return to the WLAN view.

    quit

  6. Enter the AP view or AP group view.

    • Enter the AP group view.
      ap-group name group-name
    • Enter the AP view.
      ap-id ap-id

  7. Bind the AP system profile to an AP group or a specific AP.

    ap-system-profile profile-name

    By default, the AP system profile default is bound to an AP group, but no AP system profile is bound to an AP.
