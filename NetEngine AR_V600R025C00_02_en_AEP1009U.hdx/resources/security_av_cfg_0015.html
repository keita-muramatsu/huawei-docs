Example for Configuring Antivirus

Networking Requirements

As shown in Figure 1, DeviceA is deployed at the border of an enterprise network. Intranet users can download files and emails through the web server and POP3 server. The intranet FTP server needs to receive files uploaded by Internet users. The enterprise uses the antivirus function provided by the device to prevent virus files from entering the protected network, ensuring the security of intranet users and servers. Intranet users fail to download important software from the web server. It is found that the software (virus name: EICAR.Test.FILE.1) is blocked because it is identified as a virus by the device. Having confirmed the importance of the software and the trustworthiness of the software source, the administrator temporarily permits the virus file to ensure that users can successfully download the software.

Figure 1 Antivirus network diagram

In this example, interface1, interface2, and interface3 represent 10GE0/0/1, 10GE0/0/2, and 10GE0/0/3, respectively.


Configuration Roadmap

  1. Configure an IP address for each interface, assign interfaces to security zones, and complete basic parameter settings.
  2. Configure antivirus profiles.
    • Configure the antivirus profile profile_http_pop3, set matching conditions and response actions for HTTP and POP3, set the file types for detection to all, and configure virus exception with virus name EICAR.Test.FILE.1 in the profile.
    • Configure the antivirus profile profile_ftp, set matching conditions and response actions for FTP, and set the file types for detection to all.
  3. Configure a security policy for the traffic from the Trust zone to the Untrust zone, and from the Untrust zone to the DMZ, respectively. Then, reference the antivirus profiles in the policies respectively.
    • Configure the security policy policy_sec_1 for the traffic from the Trust zone to the Untrust zone and reference the antivirus profile profile_http_pop3 in the policy to detect and defend against viruses in files and mails downloaded by intranet users from the Internet.
    • Configure the security policy policy_sec_2 for the traffic from the DMZ to the Untrust zone and reference the antivirus profile profile_ftp in the policy to detect and defend against viruses in files received by the intranet FTP server from the Internet.

Procedure

  1. Configure an IP address for each interface, assign interfaces to security zones, and complete basic parameter settings.
    1. Configure an IP address for 10GE0/0/1, and add the interface to the Untrust zone.

      <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] undo portswitch
[DeviceA-10GE0/0/1] ip address 1.1.1.1 24
[DeviceA-10GE0/0/1] quit
[DeviceA] firewall zone untrust
[DeviceA-zone-untrust] add interface 10ge 0/0/1
[DeviceA-zone-untrust] quit

    2. Configure an IP address for 10GE0/0/2, and add the interface to the DMZ.

      [DeviceA] interface 10ge 0/0/2
[DeviceA-10GE0/0/2] undo portswitch
[DeviceA-10GE0/0/2] ip address 10.2.0.1 24
[DeviceA-10GE0/0/2] quit
[DeviceA] firewall zone dmz
[DeviceA-zone-dmz] add interface 10ge 0/0/2
[DeviceA-zone-dmz] quit

    3. Configure an IP address for 10GE0/0/3, and add the interface to the Trust zone.

      [DeviceA] interface 10ge 0/0/3
[DeviceA-10GE0/0/3] undo portswitch
[DeviceA-10GE0/0/3] ip address 10.3.0.1 24
[DeviceA-10GE0/0/3] quit
[DeviceA] firewall zone trust
[DeviceA-zone-trust] add interface 10ge 0/0/3
[DeviceA-zone-trust] quit

  2. Configure antivirus profiles.

    1. Configure the antivirus profile for HTTP and POP3 and add virus name EICAR.Test.FILE.1 as an exception in the profile. The antivirus profile applies only to HTTP and POP3. Therefore, disable virus detection for other protocols.
      [DeviceA] profile type av name profile_http_pop3
[DeviceA-profile-av-profile_http_pop3] http-detect direction download action block
[DeviceA-profile-av-profile_http_pop3] pop3-detect enable
[DeviceA-profile-av-profile_http_pop3] exception av-signature-name EICAR.Test.FILE.1
[DeviceA-profile-av-profile_http_pop3] undo ftp-detect enable
[DeviceA-profile-av-profile_http_pop3] undo smtp-detect enable
[DeviceA-profile-av-profile_http_pop3] undo imap-detect enable
[DeviceA-profile-av-profile_http_pop3] undo nfs-detect enable
[DeviceA-profile-av-profile_http_pop3] undo smb-detect enable
[DeviceA-profile-av-profile_http_pop3] quit
    2. Configure the antivirus profile for FTP. The antivirus profile applies only to FTP. Therefore, disable virus detection for other protocols.
      [DeviceA] profile type av name profile_ftp
[DeviceA-profile-av-profile_http_pop3] ftp-detect direction upload action block
[DeviceA-profile-av-profile_http_pop3] undo http-detect enable
[DeviceA-profile-av-profile_http_pop3] undo smtp-detect enable
[DeviceA-profile-av-profile_http_pop3] undo pop3-detect enable
[DeviceA-profile-av-profile_http_pop3] undo imap-detect enable
[DeviceA-profile-av-profile_http_pop3] undo nfs-detect enable
[DeviceA-profile-av-profile_http_pop3] undo smb-detect enable
[DeviceA-profile-av-profile_http_pop3] quit

  3. Configure security policies.

    1. Configure a security policy for the traffic from the Trust zone to the Untrust zone, and reference the default antivirus profile default.
      [DeviceA] security-policy
[DeviceA-policy-security] rule name policy_sec_1
[DeviceA-policy-security-rule-policy_sec_1] source-zone trust
[DeviceA-policy-security-rule-policy_sec_1] destination-zone untrust
[DeviceA-policy-security-rule-policy_sec_1] source-address 10.3.0.0 24
[DeviceA-policy-security-rule-policy_sec_1] action permit
[DeviceA-policy-security-rule-policy_sec_1] profile av profile_http_pop3
[DeviceA-policy-security-rule-policy_sec_1] quit
    2. Configure a security policy for traffic from the DMZ to the Untrust zone, and reference the default antivirus profile default.
      [DeviceA-policy-security] rule name policy_sec_2
[DeviceA-policy-security-rule-policy_sec_2] source-zone dmz
[DeviceA-policy-security-rule-policy_sec_2] destination-zone untrust
[DeviceA-policy-security-rule-policy_sec_2] source-address 10.2.0.0 24
[DeviceA-policy-security-rule-policy_sec_2] action permit
[DeviceA-policy-security-rule-policy_sec_2] profile av profile_ftp
[DeviceA-policy-security-rule-policy_sec_2] quit
[DeviceA-policy-security] quit

  4. Commit the configuration in the system view.

    [DeviceA] engine configuration commit
Info: The operation may last for several minutes, please wait. Try "display engine information" for detail.
[DeviceA] 
Info: AV submitted configurations successfully.
Info: Engine configuration is complied successfully.

  5. Save the configuration, so it can be automatically loaded during the next startup of the device.

    [DeviceA] quit 
<DeviceA> save

Verifying the Configuration

  • When an intranet user downloads an infected mail using POP3, the device generates a virus threat log.
  • When an Internet user uploads an infected file using FTP, the upload connection is blocked and the device generates a virus threat log.
  • Intranet users can download important software infected with virus EICAR.Test.FILE.1.
  • To view antivirus statistics, run the display file-frame statistics [ slot slot-id cpu cpu-id ] command.

Configuration Scripts

# 
sysname DeviceA 
# 
interface 10GE0/0/1
 ip address 1.1.1.1 255.255.255.0 
# 
interface 10GE0/0/2
 ip address 10.2.0.1 255.255.255.0 
# 
interface 10GE0/0/3
 ip address 10.3.0.1 255.255.255.0 
# 
firewall zone trust 
 add interface 10GE0/0/3 
# 
firewall zone untrust 
 add interface 10GE0/0/1 
# 
firewall zone dmz 
 add interface 10GE0/0/2 
# 
profile type av name profile_http_pop3
 http-detect direction download action block
 undo ftp-detect enable
 undo smtp-detect enable
 undo imap-detect enable
 undo nfs-detect enable
 undo smb-detect enable
 exception av-signature-name EICAR.Test.FILE.1 action allow
profile type av name profile_ftp
 undo http-detect enable
 ftp-detect direction upload action block
 undo smtp-detect enable
 undo pop3-detect enable
 undo imap-detect enable
 undo nfs-detect enable
 undo smb-detect enable
# 
security-policy 
 rule name policy_sec_1 
  source-zone trust 
  destination-zone untrust 
  source-address 10.3.0.0 mask 255.255.255.0 
  profile av profile_http_pop3 
  action permit 
 rule name policy_sec_2 
  source-zone dmz 
  destination-zone untrust
  source-address 10.2.0.0 mask 255.255.255.0 
  profile av profile_ftp 
  action permit
