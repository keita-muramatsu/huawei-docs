Regulatory Domain Profile

Overview

A regulatory domain profile provides configurations including the country code, calibration channel set, and calibration bandwidth for APs.

The configuration takes effect only after the regulatory domain profile is applied to an AP group or a single AP.

Creating a Profile

  1. Enter the WLAN view.

    system-view
wlan

  2. Create a regulatory domain profile.

    regulatory-domain-profile name profile-name

Applying a Profile

  1. Enter the WLAN view.

    system-view
wlan

  2. Bind a regulatory domain profile to an AP group or a single AP.
    • Bind a regulatory domain profile to an AP group.
      ap-group name group-name
regulatory-domain-profile profile-name
    • Bind a regulatory domain profile to an AP.
      ap-id ap-id
regulatory-domain-profile profile-name
