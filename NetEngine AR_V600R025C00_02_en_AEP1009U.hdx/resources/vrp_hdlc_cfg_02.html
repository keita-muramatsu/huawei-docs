Overview of HDLC

Definition

High-Level Data Link Control (HDLC) is a bit-oriented link layer protocol that can transparently transmit any type of bit stream, without requiring data to be character sets.

  • Bit stream: Data is transmitted as bit streams.

  • Character set: Data is transmitted as character sets.

Purpose

HDLC stands out from other data link layer protocols with the following features:

  • HDLC operates in full-duplex mode, allowing continuous data transmission without needing acknowledgement. This results in highly efficient data link transmission.

  • HDLC assigns unique numbers to each frame and checks their integrity using cyclic redundancy check (CRC). This helps identify dropped or repeated frames, ensuring reliable transmission.

  • HDLC separates transmission control from processing, offering high flexibility and advanced control.

  • HDLC is independent of any character encoding set and can transparently transmit data.

  • HDLC supports zero-bit insertion, a simple technique for transparent data transmission that is easily implemented on hardware.
