Verifying the Configuration

Procedure

  • Run the display tunnel { tunnel-id | all | statistics } command to check tunnel information in the existing system.
  • Run the display tunnel-policy [ tnl-policy-name ] command to check information about tunnel policies in the existing system.
  • Run the display tunnel-policy tnl-policy-name subscriber statistics command to check the number of times that a specified tunnel policy is used by external services.
  • Run the display ip vpn-instance verbose [ vpn-instance-name ] command to check the tunnel policy applied to a VPN instance.
