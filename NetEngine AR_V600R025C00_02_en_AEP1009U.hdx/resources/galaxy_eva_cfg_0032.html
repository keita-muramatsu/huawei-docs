Configuring the Fault Mode Detection Function

Context

EVA automatically subscribes to and analyzes alarm data and internal data (KPI data for short) of related modules to detect faults on these modules.

EVA can detect faults based on the fault modes shown in Table 1, each representing a specific type of faults. You can enable or disable one or more fault modes based on service needs.

A prerequisite for EVA to detect faults based on these fault modes is that EVA can subscribe to the related alarm data or KPI data.

Procedure

  1. Enter the system view.

    system-view

  2. Enable or disable the fault mode detection function.

    • Enable the fault mode detection function.
      eva fault-detect fault-mode faultMode enable
    • Disable the fault mode detection function.
      eva fault-detect fault-mode faultMode disable

    The default status varies according to the fault mode. For details, run the display eva fault manager verbose command and check the DefaultStatus field in the command output.

Verifying the Configuration

  • Run the display eva fault manager [ verbose ] command to check the fault modes managed using EVA.
  • Run the display eva fault [ unrecovered | recovered ] [ faultMode ] [ beginTime endTime ] [ verbose ] command to check running information about the fault modes managed using EVA.
