Example for Configuring Ethernet Interface Backup Association with a Route Monitoring Group

Networking Requirements

On the network shown in Figure 1, the link DeviceA -> DeviceB -> DeviceD functions as the primary link to transmit services between HostA and HostB. The link DeviceA -> DeviceC -> DeviceD functions as the backup link.

The primary link status is required to be monitored in real time. When the primary link is faulty, services are transmitted on the backup link to reduce the impact of the primary link fault on service transmission.

Figure 1 Network diagram of association between interface backup and a route monitoring group

In this example, interface1 and interface2 represent 10GE0/0/1 and 10GE0/0/2, respectively.


Configuration Roadmap

The configuration roadmap is as follows:

  1. Assign an IP address to each interface.

  2. Configure IS-IS on the primary link DeviceA -> DeviceB -> DeviceD to ensure that there are reachable routes between the devices.
  3. Configure default routes on the backup link DeviceA -> DeviceC -> DeviceD to ensure that there are reachable routes between the devices.
  4. Create a route monitoring group and add the route on the primary link to the route monitoring group.

  5. Configure association between interface backup and the route monitoring group on the standby interfaces (10GE0/0/2) on DeviceA and DeviceD. When the route on the primary link is withdrawn or becomes inactive, the standby interface is started to implement a rapid active/standby interface switchover.

Procedure

  1. Configure interface IP addresses.
    # Assign an IP address to each interface. The following uses DeviceA as an example.
    <HUAWEI> system-view 
[HUAWEI] sysname DeviceA
[DeviceA] interface 10GE0/0/1
[DeviceA-10GE0/0/1] ip address 10.1.2.1 24
[DeviceA-10GE0/0/1] quit
[DeviceA] interface 10GE0/0/2
[DeviceA-10GE0/0/2] ip address 10.1.3.1 24
[DeviceA-10GE0/0/2] quit
  2. Configure IS-IS.
    # Set the IS-IS entity name to 10.0000.0000.0001.00 and the IS-IS level to 1 on DeviceA.
    [DeviceA] isis 1
[DeviceA-isis-1] is-level level-1 
[DeviceA-isis-1] network-entity 10.0000.0000.0001.00
[DeviceA-isis-1] quit
[DeviceA] interface 10GE0/0/1
[DeviceA-10GE0/0/1] isis enable 1

    # Set the IS-IS entity name to 10.0000.0000.0002.00 on DeviceB.

    [DeviceB] isis 1
[DeviceB-isis-1] network-entity 10.0000.0000.0002.00
[DeviceB-isis-1] quit
[DeviceB] interface 10GE0/0/1
[DeviceB-10GE0/0/1] isis enable 1
[DeviceB] interface 10GE0/0/2
[DeviceB-10GE0/0/2] isis enable 1

    # Set the IS-IS entity name to 10.0000.0000.0003.00 on DeviceD.

    [DeviceD] isis 1
[DeviceD-isis-1] network-entity 10.0000.0000.0003.00
[DeviceD-isis-1] quit
[DeviceD] interface 10GE0/0/1
[DeviceD-10GE0/0/1] isis enable 1
  3. Configure static routes on the link DeviceA -> DeviceC -> DeviceD.
    # On DeviceA, configure a static route to DeviceD.
    [DeviceA] ip route-static 10.1.5.0 255.255.255.0 10.1.3.2
    # On DeviceD, configure a static route to DeviceA.
    [DeviceD] ip route-static 10.1.3.0 255.255.255.0 10.1.5.1
  4. Configure a route monitoring group on DeviceA.
    [DeviceA] ip route-monitor-group rmg1
[DeviceA-route-monitor-group-rmg1] monitor enable
[DeviceA-route-monitor-group-rmg1] track ip route 10.1.4.0 24 down-weight 400
[DeviceA-route-monitor-group-rmg1] quit
  5. Configure association between interface backup and the route monitoring group on the standby interface 10GE0/0/2 of DeviceA. When the route monitoring group detects a fault on the primary link, traffic can be rapidly switched to the backup link.
    [DeviceA] interface 10GE0/0/2
[DeviceA-10GE0/0/2] standby track route-monitor-group rmg1 weight 300
[DeviceA-10GE0/0/2] quit

Configuration Scripts

  • DeviceA

    #
sysname DeviceA
#
ip route-monitor-group rmg1
 track ip route 10.1.4.0 255.255.255.0 down-weight 400
 monitor enable
#         
isis 1                
 is-level level-1                        
 network-entity 10.0000.0000.0001.00     
#
interface 10GE0/0/1
 ip address 10.1.2.1 255.255.255.0
 isis enable 1
#
interface 10GE0/0/2
 ip address 10.1.3.1 255.255.255.0
 standby track route-monitor-group rmg1 weight 300
#
ip route-static 10.1.5.0 255.255.255.0 10.1.3.2
#
return
