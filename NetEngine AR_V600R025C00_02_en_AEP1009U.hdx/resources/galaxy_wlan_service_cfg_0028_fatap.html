AP System Profile

Overview

An AP system profile allows you to configure AP system parameters and reference user blacklist and whitelist profiles.

Table 1 lists the functions that can be configured in an AP system profile.

Table 1 Functions that can be configured in an AP system profile

Function

Description

CLI-based Configuration Path

Configuring the offline management SSID function

After an AP goes offline unexpectedly, the WAC cannot manage or maintain the AP. After the offline management SSID function is enabled, a network administrator can use STelnet to wirelessly connect to the AP for troubleshooting, eliminating the need of connecting to the AP in wired mode.

"Configuring the Offline Management SSID Function" in CLI Configuration Guide > WLAN Configuration > SSID Management

Configuring AP login

You can configure the AP login mode and VTY user interface attributes in an AP system profile.

"Configuring AP Login" in CLI Configuration Guide > WLAN Configuration > AP Management

Configuring the management VLAN tagging function on an AP's wired interface

After an AP's wired interface is configured to add a management VLAN tag to CAPWAP packets, the AP adds the management VLAN tag to the CAPWAP packets.

"Configuring the Management VLAN Tagging Function on an AP's Wired Interface" in CLI Configuration Guide > WLAN Configuration > AP Management

Configuring PoE parameters of APs

PoE parameters include PoE power, parameters that are configured to allow high inrush current during power-on, and PoE mode used by the AP.

"Configuring the PoE Function of APs" in CLI Configuration Guide > WLAN Configuration > AP Management

Configuring AP indicators

However, blinking indicators of APs deployed in some indoor scenarios, such as hospitals and hotels, may affect people's nighttime rest. To address this, you can turn off AP indicators after APs are installed and run properly.

"Configuring AP Indicators" in CLI Configuration Guide > WLAN Configuration > AP Management

Configuring the alarm function on an AP

You can configure alarm thresholds on an AP to monitor the AP in real time. When the configured thresholds are exceeded, the AP generates alarms or logs to notify the WAC of the AP status.

"Configuring the Alarm Function on an AP" in CLI Configuration Guide > WLAN Configuration > AP Management

Configuring LLDP on an AP

LLDP helps the NMS obtain information such as the device topology, device interface status, and management address.

"Configuring LLDP on an AP" in CLI Configuration Guide > WLAN Configuration > AP Management

Configuring log backup on APs

Logs record user operations and system running information. After logs are backed up to a server, network administrators can summarize and analyze AP logs to learn about the operations performed on APs for fault location.

"Configuring Log Backup on APs" in CLI Configuration Guide > WLAN Configuration > AP Management

Configuring AP-offline service continuity

To improve user service reliability, you can configure AP-offline service continuity. Additionally, you can configure the function of allowing new STAs to access offline APs.

"Configuring AP-Offline Service Continuity" in CLI Configuration Guide > WLAN Configuration > WLAN Service Backup

Configuring the STA blacklist and whitelist

After a STA blacklist or whitelist is applied to an AP system profile, the STA blacklist or whitelist takes effect on all APs using the AP system profile.

"Configuring the STA Blacklist and Whitelist" in CLI Configuration Guide > WLAN Configuration > WLAN STA Management Configuration.

Configuring APs to directly report KPI information

To improve the efficiency of handling Wi-Fi network problems, you can report AP KPIs to a WMI server for fault cause analysis. In addition, centralized statistics help you better observe the change trends of APs and networks and identify possible AP or network problems in advance.

"Configuring the KPI Reporting Function" in CLI Configuration Guide > WLAN Configuration > WLAN O&M Monitoring Configuration.

Creating a Profile

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP system profile and enter its view.

    ap-system-profile name profile-name

    By default, the AP system profile default exists on the device.

Applying a Profile

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Enter the AP view or AP group view.
    • Enter the AP group view.
      ap-group name group-name
    • Enter the AP view.
      ap-id ap-id
  4. Bind the AP system profile to an AP group or a specific AP.

    ap-system-profile profile-name

    By default, the AP system profile default is bound to an AP group, but no AP system profile is bound to an AP.
