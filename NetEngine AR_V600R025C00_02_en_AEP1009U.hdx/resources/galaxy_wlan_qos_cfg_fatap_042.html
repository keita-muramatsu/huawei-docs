Example for Configuring Traffic Policing (Fat AP)

Networking Requirements

As shown in Figure 1, an enterprise wants to enable users to access the network through WLANs, meeting the basic mobile office requirements. To prevent STAs from maliciously occupying network resources and reduce network congestion, the administrator wants to limit the uplink rate of each STA on a VAP to 2 Mbit/s and the total uplink rate of all STAs on a VAP to 30 Mbit/s.

Figure 1 Network diagram of traffic policing

In this example, interface1 represents MultiGE0/0/0.

Configuration Roadmap

  1. Configure STA access services so that STAs can access the WLAN properly.
  2. Configure the uplink rate limits for a single STA and all STAs associated with a VAP in a traffic profile to implement traffic policing.

Procedure

  1. Check basic WLAN configurations.

    Item

    Command

    Data

    AP group to which an AP belongs

    display ap all

    AP group: built_in_ap

    All profiles bound to an AP

    display ap config-info ap-id 0

    VAP profile: wlan-vap
    • If an AP has different configurations from that in the AP group, the configuration on the AP takes precedence.
    • A new profile takes effect only after being bound to an AP or an AP group.

  2. Configure traffic policing.

    # Create the traffic profile wlan-traffic and set the uplink rate limit for each STA to 2 Mbit/s and the total uplink rate limit for all STAs on the VAP to 30 Mbit/s.
    <HUAWEI> system-view
[HUAWEI] sysname FAT AP
[FAT AP] wlan
[FAT AP-wlan] traffic-profile name wlan-traffic
[FAT AP-wlan-traffic-prof-wlan-traffic] rate-limit client up 2048
[FAT AP-wlan-traffic-prof-wlan-traffic] rate-limit vap up 30720
[FAT AP-wlan-traffic-prof-wlan-traffic] quit
    # Bind the traffic profile wlan-traffic to the VAP profile wlan-vap.
    [FAT AP-wlan] vap-profile name wlan-vap
[FAT AP-wlan-vap-prof-wlan-vap] traffic-profile wlan-traffic
Warning: This action may cause service interruption. Continue?[Y/N]y 
[FAT AP-wlan-vap-prof-wlan-vap] quit

Verifying the Configuration

Run the display traffic-profile name wlan-traffic command on the Fat AP to check the rate limit configuration in a specified traffic profile. The command output shows that the uplink rate limit of a single STA is 2048 kbit/s (2 Mbit/s) and the total uplink rate limit of all STAs on a VAP is 30720 kbit/s (30 Mbit/s).
