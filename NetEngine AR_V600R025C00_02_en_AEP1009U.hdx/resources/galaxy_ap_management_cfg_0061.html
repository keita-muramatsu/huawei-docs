Configuring the Rate for an AP Wired Interface

Context

You can configure the rate for an Ethernet interface working in either auto-negotiation or non-auto-negotiation mode.

  • In auto-negotiation mode, interfaces at both ends of a link negotiate the interface rate. If the negotiated interface rate is not the required value, you can manually set the interface rate.
  • In non-auto-negotiation mode, you must set the rate for interfaces so that the devices where the interfaces reside can communicate with each other.
    • Exercise caution when running the speed command. The default value for this command is recommended unless otherwise required. If this configuration is mandatory, do not run this command in the default profile to prevent the configuration from being delivered to all interfaces.
    • When configuring the interface rates of the devices at both ends, ensure that the interface rates are within the rate limit caused by AP's power consumption reduction. This is because the configuration may not take effect if the interface rate exceeds the limit when the AP works in low power consumption mode. To determine whether an AP is working in low power consumption mode, run the display ap power-workmode all command and check the value of the Power-workmode field.

      When the power supply is insufficient, the impact on the AP functions and performance varies depending on AP models. Check the power supply downgrade limit as follows: Visit Info-Finder, select a product series, and view hardware specifications in the hardware center. You can check the power supply downgrade limits at different power supply levels.

    • The speed command is available only on the FE, GE, multi-GE, and XGE interfaces on an AP but does not take effect on other types of interfaces.
    • After the speed command is run, the AP changes the working mode of the interface to non-auto-negotiation and changes the interface rate based on the configuration. During this process, the interface may go Down or Up. Therefore, the configuration delivery takes a long time.
    • After running the speed command to change the negotiation mode and rate of an AP wired interface, ensure that the remote interface works in full-duplex mode and has the same rate as the local interface; otherwise, communication is affected.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP wired port link profile and enter its view.

    port-link-profile name profile-name

    By default, the AP wired port link profile default exists on the device.

  4. Configure the rate of an AP wired interface in non-auto negotiation mode.

    speed { 100 | 1000 | 2500 | 5000 | 10000 }

    By default, an AP wired interface works in auto-negotiation mode, and its rate is negotiated with the peer interface.

  5. Return to the WLAN view.

    quit

  6. Create an AP wired port profile and enter its view.

    wired-port-profile name wired-port-profile-name

    By default, the AP wired port profile default exists on the device.

  7. Bind the AP wired port link profile to the AP wired port profile.

    port-link-profile profile-name

    By default, the AP wired port link profile default is bound to an AP wired port profile.

Follow-up Procedure

After the configuration is complete, bind the AP wired port profile to an AP group or a specific AP so that the configuration in the profile can take effect. For configuration details, see Binding an AP Wired Port Profile.
