Configuring STA Connectivity Check

Context

To locate network access faults of some STAs, you can configure the STA connectivity check function for an AP. The AP then randomly selects two of STAs that have associated with it for more than 20 seconds and encountered traffic exceptions (The STAs can obtain IP addresses and the default gateway address, but no uplink or downlink unicast traffic is successfully transmitted). The AP then detects network connectivity by pinging these two STAs and logs the result.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Enter the AP system profile view.

    ap-system-profile name profile-name

  4. Enable STA connectivity check.

    undo station connectivity-detect disable

    By default, STA connectivity check is enabled.
