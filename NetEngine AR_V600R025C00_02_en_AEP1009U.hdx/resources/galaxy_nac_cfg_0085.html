Maintaining NAC

Monitoring the NAC Running Status

In routine maintenance, you can run the following commands in any view to check the NAC running status.

Table 1 Monitoring the NAC running status

Operation

Command

Display access user information.

display access-user

NOTE:

If authentication triggered by any packets is not configured on the device, ARP packets with a source IP address of 0.0.0.0 can trigger MAC address authentication. In this case, however, the IP addresses of online users are empty in the display access-user command output. If the device receives an ARP packet with a source IP address other than 0.0.0.0 from an online user, it updates the user's IP address in the user entry to this source IP address. If an online user has an IP address and sends an ARP packet with a source IP address of 0.0.0.0, the device does not update the user's IP address in the user entry.

Display user statistics on the device.

display access-user statistics

Display statistics about users whose network access is controlled based on the user name.

display access-user user-name-table statistics { all | username username }

Display statistics about MAC address authentication users.

display mac-authen

Display information about MAC address authentication users in quiet state.

display mac-authen quiet-user

Display statistics about 802.1X users.

display dot1x

Display 802.1X authentication information.

display dot1x statistics

Display information about 802.1X users in quiet state.

display dot1x quiet-user

Display statistics about 802.1X Identity packets.

display access-user dot1x-identity statistics

Display statistics about NAC authentication requests.

display aaa statistics access-type-authenreq

Clearing NAC Statistics

The cleared statistics cannot be restored. Exercise caution when clearing statistics.

Table 2 Clearing NAC statistics

Operation

Command

Clear MAC address authentication statistics.

reset mac-authen statistics

Clear 802.1X authentication statistics.

reset dot1x statistics

Clear statistics about 802.1X Identity packets.

reset access-user dot1x-identity statistics

Clear statistics about NAC authentication requests.

reset aaa statistics access-type-authenreq
