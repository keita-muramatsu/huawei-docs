Understanding BGP4+ Route Acceptance

BGP4+ is used to transmit routing information between ASs. Route acceptance directly affects traffic forwarding.

A BGP4+ device may receive multiple routes to the same destination network from different peers. To control network traffic forwarding paths, BGP4+ needs to filter the received routes.

In addition, potential service attacks can result in the BGP4+ device receiving an excessively large number of routes from its peers, leading to significant device resource consumption. As such, regardless of whether malicious attacks or incorrect configurations result in the reception of numerous BGP4+ routes, the administrator must limit the device resources to be consumed during device operation based on the network planning and device capacity.

Filters can be used to filter the routes to be accepted by BGP4+. BGP4+ can filter the routes received from all peers or peer groups, or only those received from a specified peer or peer group. If multiple filtering policies are configured, BGP4+ accepts only those routes that match all the configured policies.
