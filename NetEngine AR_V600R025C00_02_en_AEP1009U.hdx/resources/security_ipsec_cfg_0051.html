Configuring Network Resource Push

Prerequisites

Network resource push takes effect only for template IPsec policies.

Context

When multiple branches are connected to the headquarters, network resources such as IP addresses and DNS server addresses can be centrally deployed on the headquarters gateway to simplify the configuration and maintenance of IPsec and other network resources on the gateways in the branches. When a branch gateway initiates IKEv2 negotiation and establishes an IPsec tunnel with the headquarters gateway, the headquarters gateway can push network resources to the branch gateway through IKEv2. The headquarters gateway can push network resources and differentiate network resources of different branches using the following methods:

  • Use an IP address pool: Network resources including IP addresses, domain names, and DNS server addresses can be configured on the headquarters gateway and pushed to the branches' gateways.

  • Use an IKE user table: For the IKE users in an IKE user table, IP addresses and DNS server addresses can be configured on the headquarters gateway and pushed to the branches' gateways.

The method of using an IKE user table takes precedence over the method of using a service scheme, and can push different network resources including IP addresses and DNS server addresses to different branches.

Procedure

  • Configure network resource push using a service scheme.
    1. Enter the system view.

      system-view

    2. Enter the IKE peer view.

      ike peer peer-name

    3. Reference a global address pool.

      ip-pool ip-pool-name

      By default, no global address pool is referenced by an IKE peer.

      ip-pool-name specifies a global address pool created using the ip-pool ip-pool-name command in the system view.

  • Configure network resource push using an IKE user table.
    1. Enter the system view.

      system-view

    2. Enter the IKE user table view.

      ike user-table user-table-id

    3. Enter the IKE user view.

      user user-name

    4. Configure the IP address to be allocated to an IKE user.

      ip-alloc ipv4-address mask ip-mask

      By default, the IP address to be allocated to an IKE user is not configured.

    5. Configure the DNS server address to be allocated to an IKE user.

      dns ipv4-address1 [ ipv4-address2 ]
quit

      By default, the DNS server address to be allocated to an IKE user is not configured.

    6. Return to the system view.

      quit

    7. Enter the IKE peer view.

      ike peer peer-name

    8. Reference an IKE user table.

      user-table user-table-id
