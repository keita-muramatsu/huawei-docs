Overview of Domain Group

Definition

A domain group is a set of domain names and can be referenced by multiple types of policies.

Purpose

A domain name is easier to remember than an IP address and is widely used on live networks. To control the traffic that uses domain names for communication, you need to configure a domain group. A device records the IP addresses corresponding to domain names in the domain group, so that the traffic destined for these IP addresses matches the domain group.
