Preparing the Development Environment

Requirements on Development Personnel

  1. Be familiar with gRPC development (you can learn about it at https://doc.oschina.net/grpc).
  2. Be familiar with GPB encoding (you can learn about it at https://developers.google.com/protocol-buffers).
  3. Be proficient in Python development. This chapter uses Python as an example.

Preparing the Development Environment

  1. Set up the Python development and runtime environment.
  2. Create an interconnection project that contains the Python interconnection module of the open-source gRPC framework.
