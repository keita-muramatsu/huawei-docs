Default VLAN

The default VLAN ID of an interface is called the PVID. Each interface has a PVID.

  • An access interface belongs to only one VLAN, which is also its default VLAN.
  • Hybrid and trunk interfaces belong to multiple VLANs but their default VLAN must be unique. You need to manually set the default VLAN for these interfaces.

After you configure the default VLAN for an interface, the interface processes frames as described in Adding and Removing VLAN Tags.
