Protocol Architecture

As shown in Figure 1, SSL is located between the application layer and transport layer. SSL can be divided into two layers: lower layer with the SSL record protocol, and upper layer with the SSL handshake protocol, SSL change cipher spec protocol, and SSL alert protocol.

Figure 1 SSL protocol stack

  • SSL record protocol: divides upper-layer data into fragments, computes and appends message authentication codes (MACs), encrypts fragments as records, and sends them to the receiver. Data transmission is implemented using the SSL record protocol.

  • SSL handshake protocol: used before application data is transmitted. This protocol is used to negotiate a cipher suite (including the encryption algorithm, key exchange algorithm, and MAC algorithm) for communication, verifying the identities of the server and client, and securely exchanging keys between the server and client.

  • SSL change cipher spec protocol: used by the client and server to notify each other that subsequent records will be protected under the newly negotiated cipher suite and key.

  • SSL alert protocol: used to report the alert information generated during the handshake or application data transmission process to the peer, so that the peer can handle the alert accordingly. An alert message conveys the alert severity and description.
