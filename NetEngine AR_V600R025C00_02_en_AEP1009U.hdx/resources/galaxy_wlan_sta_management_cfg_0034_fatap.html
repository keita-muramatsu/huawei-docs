Maintaining STA Steering Information

Context

After the dynamic load balancing or band steering function is enabled, STAs may be steered. STA steering statistics help maintenance personnel manage and maintain STAs.

Procedure

  • Run the display station steer-info { all | weak-rssi | non-best-load | unsteerable } command to check information about STAs, including the weak RSSI, non-optimal load, and steering inability.
  • Run the display station steering reject history { sta-mac mac | all | ap-id ap-id [ radio-id radio-id ] } command to check historical records of STA steering rejection.
  • Run the display station steer-statistics command to check STA steering statistics.
  • Run the reset station steer-statistics command to clear STA steering statistics.
  • Run the reset station steer-history command to clear historical STA steering information.

    The cleared records cannot be restored. Therefore, exercise caution when performing these operations.
