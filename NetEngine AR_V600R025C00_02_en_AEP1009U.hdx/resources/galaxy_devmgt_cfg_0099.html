Restoring Factory Settings

You can restore the configuration file to factory settings and clear all service configurations and data files as required.

This operation will restore the system configuration file to the factory settings and clear all service configurations and data files of the device. Exercise caution when performing this operation.

Restoring the Factory Settings of a Device in One-Click Mode

To restore the factory settings of a device using the CLI, including clearing all service configurations and data files, run the reset factory-configuration command in the user view. The device will restart after this operation is performed.

Restoring the Configuration File to Factory Settings by Pressing and Holding the RST button.

Press and hold the RST button for more than 5 seconds. The device will restore the default configuration and automatically restart after this operation is performed.

  • Only devices with the RST button support this operation.
  • This operation clears service configurations and data files and provides the same function as the reset factory-configuration command.
  • This operation does not delete the protected directory or the protected/$_default.cfg file.
  • If the protected/$_default.cfg file exists, performing this operation sets the $_default.cfg file as the configuration file for next startup. Otherwise, the configuration file for next startup is empty.
  • To disable the function of restoring factory settings by pressing and holding the PNP button, run the device pnp-button disable command.

Verifying the Configuration

After the factory settings are restored using the reset factory-configuration command, run the display factory-configuration reset-result command to check the restoration result.
