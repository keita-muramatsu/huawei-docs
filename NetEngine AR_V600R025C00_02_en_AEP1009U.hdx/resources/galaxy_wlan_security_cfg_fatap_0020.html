Configuring OWE Transition Authentication

Context

The OWE transition mode provides backward compatibility with STAs that do not support OWE authentication. That is, these STAs access the network in open authentication mode, while OWE-capable STAs access the network in OWE authentication mode.

In OWE transition mode, only the AES encryption mode is supported.

OWE authentication or its transition mode automatically enables the PMF function in mandatory mode. That is, the pmf { optional | mandatory } command configuration does not take effect in OWE authentication or its transition mode.

The OWE transition mode requires the configuration of two VAP profiles on the same radio. Ensure that the security policies of the VAP profiles are OWE and open, respectively, and the parameter transition-ssid is set the same as the SSID in the VAP profile with the security policy of open. The OWE transition mode takes effect only when a VAP profile on the same radio uses the same SSID as transition-ssid and the security policy of open and the corresponding VAP is enabled. If such effective conditions are not met, the device uses OWE authentication.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a security profile and enter its view.

    security-profile name profile-name

    By default, the security profile default exists in the system.

  4. Set the security policy to authentication in OWE transition mode.

    security enhanced-open aes transition-ssid ssid

    By default, no security policy is configured.
