Configuring the Alarm Function on an AP

Context

You can configure alarm thresholds on an AP to monitor the AP in real time. When the configured thresholds are exceeded, the AP generates alarms or logs to notify the WAC of the AP status.

The default alarm thresholds are recommended.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP system profile and enter its view.

    ap-system-profile name profile-name

    By default, the AP system profile default exists on the device.

  4. Configure a CPU usage alarm threshold for APs.

    cpu-usage threshold threshold-value

    By default, the CPU usage alarm threshold of APs is 90.

  5. Configure a memory usage alarm threshold for APs.

    memory-usage threshold threshold-value

    By default, the memory usage alarm threshold of APs is 80.

  6. Configure a disk usage alarm threshold for APs.

    disk-usage threshold threshold-value

    By default, the memory usage alarm threshold of APs is 95.

  7. Configure an upper temperature alarm threshold for APs.

    high-temperature [ ap-environment | cpu | np ] threshold threshold-value

    For the default upper temperature alarm threshold of each AP model, see the high-temperature threshold command.

  8. Configure a lower temperature alarm threshold for APs.

    low-temperature [ ap-environment | cpu | np ] threshold threshold-value

    For the default lower temperature alarm threshold of each AP model, see the low-temperature threshold command.

  9. Return to the WLAN view.

    quit

  10. Enter the AP view or AP group view.
    • Enter the AP group view.
      ap-group name group-name
    • Enter the AP view.
      ap-id ap-id
  11. Bind the AP system profile to an AP group or a single AP.

    ap-system-profile profile-name

    By default, the AP system profile default is bound to an AP group, but no AP system profile is bound to an AP.

Verifying the Configuration

  • Run the display ap-system-profile { name profile-name | all } command to check information about an AP system profile.
  • Run the display references ap-system-profile name profile-name command to check reference information about an AP system profile.
