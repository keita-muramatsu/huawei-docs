Example for Configuring IPv6 Addresses for Interfaces

Networking Requirements

On the network shown in Figure 1, DeviceA and DeviceB are connected through 10GE interfaces. IPv6 global unicast addresses are configured for the two devices as follows:

DeviceA: 2001:db8::1/64

DeviceB: 2001:db8::2/64

Figure 1 Configuring IPv6 addresses for interfaces

Configuration Roadmap

The configuration roadmap is as follows:

  1. Enable IPv6 forwarding on DeviceA.

  2. Configure an IPv6 global unicast address for DeviceA.

  3. Enable IPv6 forwarding on DeviceB.

  4. Configure an IPv6 global unicast address for DeviceB.

Procedure

  1. Configure global unicast addresses for interfaces, and enable DeviceA to send RA messages.

    # Configure DeviceA.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] undo portswitch
[DeviceA-10GE0/0/1] ipv6 enable
[DeviceA-10GE0/0/1] ipv6 address 2001:db8::1 64
[DeviceA-10GE0/0/1] ipv6 nd ra halt disable
[DeviceA-10GE0/0/1] quit

    # Configure DeviceB.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceB
[DeviceB] interface 10ge 0/0/1
[DeviceB-10GE0/0/1] undo portswitch
[DeviceB-10GE0/0/1] ipv6 enable
[DeviceB-10GE0/0/1] ipv6 address auto link-local
[DeviceB-10GE0/0/1] ipv6 address auto global local-identifier
[DeviceB-10GE0/0/1] quit

Configuration Scripts

  • DeviceA

    #
sysname DeviceA
#
interface 10GE0/0/1
ipv6 enable
 ipv6 address 2001:db8::1/64
 ipv6 nd ra halt disable
#
return

  • DeviceB

    #
sysname DeviceB
#
interface 10GE0/0/1
ipv6 enable
 ipv6 address auto link-local
 ipv6 address auto global local-identifier
#
return
