Example for Configuring a Script Assistant for Setting an Interface Description Based on LLDP Neighbor Changes

Networking Requirements

On the network shown in Figure 1, a user wants to use a script to automatically set an interface description based on the LLDP neighbor information when an LLDP neighbor is added to or deleted from DeviceA.

Figure 1 Network diagram for configuring an interface description based on LLDP neighbor changes

Configuration Roadmap

  1. Make the Python script port_description_lldp.py to set the interface description when the LLDP neighbor changes.

  2. The user remotely manages the device, uploads the Python script to DeviceA, and installs the port_description_lldp.py script.

  3. Configure a Python script assistant.

Procedure

  1. Configure IP addresses and routing protocols for interfaces on DeviceA, DeviceB, and DeviceC, as shown in Figure 1. For details, see Configuration Scripts.
  2. Make a Python script.

    # Make a Python script named port_description_lldp.py to implement the following functions:

    • Subscribe to LLDP neighbor information addition and deletion events.

    • Obtain the port whose LLDP neighbor changes through environment variables, and obtain the device name and port name of the LLDP neighbor of the port.

    • Set the combination of the device name and port name of an LLDP neighbor to the description of the local port.

    The following is an example of the Python script:

    # -*- coding: utf-8 -*-
import ops         # Import the ops module.
import sys         # Import the sys module.
import os         # Import the os module.
import re          # Import the re module. The regular expression is used.
# Subscription processing function
def ops_condition(_ops):
    # Detect the event that a neighbor is added or deleted.
    value1, err_str1 = _ops.event.subscribe("lldpChange", "lldp", "LLDP_INTERFACE_REM_CHANGE", [])
    return 0

# Work processing function
def ops_execute(_ops):
    # Obtain the environment variable, which indicates the parameter value when the event is triggered.
    key, value = _ops.environment.get("_para_action")
    inter, value = _ops.environment.get("_para_interfaceName")
    _ops.set_model_type("YANG")
    if key == "added":

      # Open the command line channel.
        handle, err_desp = _ops.cli.open() 
        neighbor, n11, n21 = _ops.cli.execute(handle,"display lldp neighbor interface " + inter)

        resultsys = re.search(r'System[\s]+name[\s:]*\S*', neighbor).group()
        sysname = re.split(':', resultsys)        

        resultport = re.search(r'Port\s+ID\s{2,}:*\S*', neighbor).group()
        port = re.split(':', resultport)

      # Enter the system view.
        result, n11, n21 = _ops.cli.execute(handle,"system-view")

        # Enter the interface view.
        result, n11, n21 = _ops.cli.execute(handle,"interface " + inter)

        # Set the interface description.
        result, n11, n21 = _ops.cli.execute(handle,"description " + "To-" + sysname[1] + "-" + port[1])

        # Close the command line channel.
        result = _ops.cli.close(handle)

    elif key == "deleted":
        handle, err_desp = _ops.cli.open() 

        # Enter the system view.
        result, n11, n21 = _ops.cli.execute(handle,"system-view")

        # Enter the interface view.
        result, n11, n21 = _ops.cli.execute(handle,"interface " + inter)

        # Set the interface description.
        result, n11, n21 = _ops.cli.execute(handle,"undo description")

        # Close the command line channel.
        result = _ops.cli.close(handle)

    else:
        return 1
    return 0

  3. Upload the script file to the device and install it.

    # Configure DeviceA as the SFTP client to download the Python script from the SFTP server.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] sftp 10.2.1.1
Trying 10.2.1.1 ... 
Press CTRL+K to abort

Enter password: 
sftp-client> get port_description_lldp.py
Info: Transfer file in binary mode.
Please wait for a while...
/    2053 bytes transferred
Info: Downloaded the file successfully.

    # Install the Python script on DeviceA.

    [DeviceA] quit
<DeviceA> ops install file port_description_lldp.py

  4. Configure a Python script assistant.

    # Configure a Python script assistant and register the CLI event in the script port_description_lldp.py. Wait for the event to be triggered.

    <DeviceA> system-view
[DeviceA] ops
[DeviceA-ops] script-assistant python port_description_lldp.py
[DeviceA-ops] quit

Verifying the Configuration

# After the preceding configurations are complete, for example, after neighbor information is added to the 10GE0/0/1 interface of DeviceA, the description of the interface is set as follows:

[DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] display this
#
interface 10ge 0/0/1
 description To-DeviceB-10GE0/0/1
#
return

# After the undo lldp enable command is run to disable LLDP on the 10GE0/0/1 interface of DeviceA, the description of the interface is deleted.

[DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] undo lldp enable
[DeviceA-10GE0/0/1] display this
#
interface 10ge 0/0/1
 undo lldp enable   
#
return
