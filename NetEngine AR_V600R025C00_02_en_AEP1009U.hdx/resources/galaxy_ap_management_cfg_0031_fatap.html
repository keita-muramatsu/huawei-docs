Configuring Wired Login to an AP

Prerequisites

Before configuring wired login to an AP, you have completed the following task:

  • Configuring the User Name and Password for AP Login

Context

You can log in to an AP through the console port, STelnet, Telnet, or SFTP.

  • To ensure AP security, you can disable these login modes unless necessary, which prevents wired login to the AP by unauthorized users.
  • If necessary, you can enable one or more of these wired login modes to log in to the AP.
  • By default, only strong encryption algorithms can be configured when a WAC functions as an STelnet client. When a WAC attempts to log in to an AP running an earlier version using STelnet, if the AP uses a weak encryption algorithm, the login fails. In this case, you can run the install feature-software WEAKEA command on the WAC to install the weak security algorithm/protocol feature package (WEAKEA) and verify that the encryption algorithms configured using the ssh client key-exchange command on the AP are the same as those configured using the ssh server key-exchange command on the AC. This ensures that the WAC can log in to the AP successfully. Using weak encryption algorithms generates security risks. APs that support strong encryption algorithms are recommended.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP system profile, and enter its view.

    ap-system-profile name profile-name

    By default, the AP system profile default exists on the device.

  4. Configure STelnet login.

    1. Enable the STelnet server function on an AP.
      undo stelnet server disable

      By default, the STelnet server function is enabled on an AP.

    2. Enable first-time authentication on the SSH client.
      ssh client first-time enable

      By default, first-time authentication on the SSH client is disabled.

      When an SSH client accesses an SSH server for the first time and the SSH server's public key is not configured on the SSH client, you can enable first-time authentication on the SSH client to allow the SSH client to access the SSH server.

  5. Optional: Enable AP login through the console port.

    undo console disable

    By default, AP login through the console port is enabled.

  6. Optional: Enable Telnet on an AP.

    telnet enable

    By default, Telnet is disabled on an AP.

    The Telnet protocol has security risks. You are advised to use the secure SSHv2 protocol.

  7. Optional: Enable the SFTP server function on an AP.

    undo sftp server disable

    By default, the SFTP server function is enabled on an AP.

  8. Return to the WLAN view.

    quit

  9. Enter the AP view or AP group view.
    • Enter the AP group view.
      ap-group name group-name
    • Enter the AP view.
      ap-id ap-id
  10. Bind the AP system profile to an AP group or a single AP.

    ap-system-profile profile-name

    By default, the AP system profile default is bound to an AP group, but no AP system profile is bound to an AP.

Verifying the Configuration

  • Run the display ap-system-profile { name profile-name | all } command to check information about an AP system profile.
  • Run the display references ap-system-profile name profile-name command to check reference information about an AP system profile.
