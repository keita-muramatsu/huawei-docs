Checking the Radio Status

Procedure

  • Check the radio mode of an AP.

    display ap radio-mode all

  • Check the radio status of an AP.

    display radio { all | ap-group ap-group-name | ap-id ap-id }

  • Manage radio traffic statistics.

    # Check radio traffic statistics.
    display ap traffic statistics wireless ap-id ap-id radio radio-id [ ssid ssid ]
    # Reset radio traffic statistics.
    system-view
wlan
reset ap traffic statistics wireless ap-id ap-id radio radio-id

  • Check environment information.

    # Check AP neighbor information.

    display ap neighbor ap-id ap-id [ radio radio ]

    # Check air interface environment information about an AP.

    display ap radio-environment ap-id ap-id [ radio radio-id ]

  • Manage channel switching records.

    # Check AP channel switching records.
    display channel switch-record { all | calibrate | ap-id ap-id radio radio-id | reason { unknown | dfs | configuration | unsupported | 3gpp-bs-notification | iot-notification | ap-sync } }
    # Reset AP channel switching records.
    reset channel switch-record all

  • Manage radio calibration statistics.

    # Clear radio calibration statistics.

    return
reset wlan calibrate statistics ap-id ap-id radio radio-id
