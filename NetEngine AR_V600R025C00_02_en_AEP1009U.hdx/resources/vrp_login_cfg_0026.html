Verifying the Configuration

Procedure

  • Run the display users [ all ] command to view information about all user interfaces.
  • Run the display user-interface console ui-number [ summary ] command to view information of the console user interface.
  • Run the display user-interface maximum-vty command to view the maximum number of VTY user interfaces.
  • Run the display user-interface vty ui-number1 [ summary ] command to view information of the VTY user interface.
  • Run the display vty mode command to view the VTY mode.
