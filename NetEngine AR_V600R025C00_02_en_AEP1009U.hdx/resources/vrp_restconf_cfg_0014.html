Query Parameters

Each RESTCONF operation allows a request URI to contain zero or more query parameters. You can specify query parameters as required.

  • Query parameters can be present in any sequence.
  • A request URI can contain multiple query parameters, and each parameter can be used only once.
  • The names and values of query parameters are case sensitive.
Table 1 RESTCONF query parameters

Query Parameter

Operation Method

Description

content

GET, HEAD

depth

GET, HEAD

Returns the subtree depth of the content.

fields

GET, HEAD

Requests a subset of the target resource content.

with-defaults

GET, HEAD

Controls the function to query default values.
