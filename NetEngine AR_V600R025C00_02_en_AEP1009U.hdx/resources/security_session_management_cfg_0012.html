Managing Sessions

Configuring a Session Whitelist

If no session whitelist is configured, session entries are established for traffic based on the configuration. After a session whitelist is configured, no session entry is created for the traffic matching the whitelist during service running.

  • Run the session whitelist acl { acl-number | acl-name } bypass { { spr | sac | sec-policy | tcpfpm } * | all or session whitelist ipv6 acl { acl-number | acl-name } bypass { { spr | sac | sec-policy } * | all } command in the system view to configure the session table whitelist.

Querying a Session Table

The session table is key to packet forwarding. If a service fault occurs, for example, traffic fails to be forwarded or is interrupted intermittently, run the following commands in any view to query the session table to locate the module or phase where the fault occurs.

Table 1 Querying a session table

Operation

Command

Check information about all sessions in the session table.

display session all [ verbose ]

display ipv6 session all [ verbose ]

Check the number of sessions.

display session number

display ipv6 session number

Check information about sessions based on the specified destination address or destination port number of packets.

display session destination destination-address [ destination-port ] [ verbose ]

display ipv6 session destination destination-address [ destination-port ] [ verbose ]

Check information about sessions based on the specified source address, source port number, destination address, or destination port number of packets.

display session source source-address [ source-port ] [ destination destination-address [ destination-port ] ] [ verbose ]

display ipv6 session source source-address [ source-port ] [ destination destination-address [ destination-port ] ] [ verbose ]

Check information about sessions based on the specified protocol number, protocol type, source address, source port number, destination address, or destination port number of packets.

display session { protocol { protocol-number | protocol-name } | flood-detect detect-type } [ source source-address [ source-port ] ] [ destination destination-address [ destination-port ] ] [ verbose ]

display ipv6 session protocol { protocol-number | icmpv6 | tcp | udp } [ source source-address [ source-port ] ] [ destination destination-address [ destination-port ] ] [ verbose ]

Check the information about sessions by specifying a service.

display session module { nat | sec-policy | sac | spr | saas } [ verbose ]

Check the number of session tables by specifying a service.

display session number module { nat | sec-policy | sac | spr | saas }

Display brief information about the NAT session table.

display session module nat brief

Clearing a Session Table

Because session resources in the system are limited and sessions do not age when traffic matches them, you may need to clear the session table to release session resources or perform routine maintenance.

  • Run the reset session all or reset ipv6 session all command in the user view to clear all sessions on the device.
