Example for Configuring Basic IPv6 IS-IS Functions

Networking Requirements

In Figure 1, Devices A, B, C, and D belong to the same AS. It is required that IPv6 IS-IS run on them to implement IPv6 interworking.

  • Devices A, B, and C belong to area 10, and DeviceD belongs to area 20.

  • DeviceA and DeviceB are Level-1 devices; DeviceC is a Level-1-2 device; DeviceD is a Level-2 device.

Figure 1 Network diagram of basic IPv6 IS-IS functions

In this example, interface 1, interface 2, and interface 3 represent 10GE 0/0/1, 10GE 0/0/2, and 10GE 0/0/3, respectively.


Configuration Roadmap

The configuration roadmap is as follows:

  1. Enable IPv6 on each device and configure an IPv6 address for each interface.

  2. Enable IS-IS, set a level, and set a NET for each device.

Procedure

  1. Enable IPv6 on each device and configure an IPv6 address for each interface.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] ipv6 enable
[DeviceA-10GE0/0/1] ipv6 address 2001:db8:1::2 64
[DeviceA-10GE0/0/1] quit

    The configurations of DeviceB, DeviceC, and DeviceD are similar to the configuration of DeviceA. For detailed configurations, see Configuration Scripts.

  2. Enable IS-IS, set a level, and set a NET for each device.

    # Configure DeviceA.

    [DeviceA] isis 1
[DeviceA-isis-1] is-level level-1
[DeviceA-isis-1] network-entity 10.0000.0000.0001.00
[DeviceA-isis-1] ipv6 enable
[DeviceA-isis-1] quit
[DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] isis ipv6 enable 1
[DeviceA-10GE0/0/1] quit

    # Configure DeviceB.

    [DeviceB] isis 1 
[DeviceB-isis-1] is-level level-1
[DeviceB-isis-1] network-entity 10.0000.0000.0002.00
[DeviceB-isis-1] ipv6 enable
[DeviceB-isis-1] quit
[DeviceB] interface 10ge 0/0/1
[DeviceB-10GE0/0/1] isis ipv6 enable 1
[DeviceB-10GE0/0/1] quit

    # Configure DeviceC.

    [DeviceC] isis 1
[DeviceC-isis-1] network-entity 10.0000.0000.0003.00
[DeviceC-isis-1] ipv6 enable
[DeviceC-isis-1] quit
[DeviceC] interface 10ge 0/0/1
[DeviceC-10GE0/0/1] isis ipv6 enable 1
[DeviceC-10GE0/0/1] quit
[DeviceC] interface 10ge 0/0/2
[DeviceC-10GE0/0/2] isis ipv6 enable 1
[DeviceC-10GE0/0/2] quit
[DeviceC] interface 10ge 0/0/3
[DeviceC-10GE0/0/3] isis ipv6 enable 1
[DeviceC-10GE0/0/3] isis circuit-level level-2
[DeviceC-10GE0/0/3] quit

    # Configure DeviceD.

    [DeviceD] isis 1 
[DeviceD-isis-1] is-level level-2
[DeviceD-isis-1] network-entity 20.0000.0000.0004.00
[DeviceD-isis-1] ipv6 enable
[DeviceD-isis-1] quit
[DeviceD] interface 10ge 0/0/1
[DeviceD-10GE0/0/1] isis ipv6 enable 1
[DeviceD-10GE0/0/1] quit
[DeviceD] interface 10ge 0/0/2
[DeviceD-10GE0/0/2] isis ipv6 enable 1
[DeviceD-10GE0/0/2] quit

Verifying the Configuration

# Check the IS-IS routing table of DeviceA. 

[DeviceA] display isis route

The command output shows that DeviceA has the routes to each network segment of the Level-1 area.

Configuration Scripts

  • DeviceA
    #
sysname DeviceA
#
isis 1
 is-level level-1
 ipv6 enable topology standard
 network-entity 10.0000.0000.0001.00
#
interface 10GE0/0/1
 ipv6 enable
 ipv6 address 2001:db8:1::2/64
 isis ipv6 enable 1
#
return
