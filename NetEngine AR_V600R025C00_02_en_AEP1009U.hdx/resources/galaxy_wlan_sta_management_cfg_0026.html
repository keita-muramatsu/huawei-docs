Configuring the Band Steering Function

Context

The band steering function enables an AP to preferentially steer STAs to the 5 GHz or 6 GHz frequency band. This reduces load and interference on the 2.4 GHz frequency band and therefore improves user experience.

To implement band steering, an AP must have the same SSID and security policy configured on different frequency bands.

To allow STAs to preferentially associate with the 5 GHz or 6 GHz radio and improve the access effect, configure higher power for the 5 GHz or 6 GHz radio than that for the 2.4 GHz radio.

Single-radio devices do not support the band steering function.

If the same VAP profile is bound to multiple radios of an AP, the band steering function takes effect as long as it is enabled for an SSID on any of these radios. For example, when the band steering function is enabled for the SSID test on the 2.4 GHz radio but disabled on the 5 GHz radio, the AP still preferentially steers STAs associated with the SSID to the 5 GHz radio.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a VAP profile view and enter its view.

    vap-profile name profile-name

  4. Enable the band steering function.

    undo band-steer disable

    By default, the band steering function is enabled.

  5. Return to the WLAN view.

    quit

  6. Create an RRM profile and enter its view.

    rrm-profile name profile-name

    By default, the RRM profile default exists in the system.

  7. (Optional) Configure low-band association suppression.
    1. Configure low-band association suppression so that STAs are steered to high-band radios for association.

      band-steer higher-band

      By default, low-band association suppression is disabled.

    2. Configure the maximum number of STA association rejections. (Note that deny-threshold cannot be set to 0. Otherwise, the band-steer higher-band command does not take effect.)

      band-steer deny-threshold { deny-threshold | always }

      By default, the maximum number of STA association rejections is 0.

  8. (Optional) Configure the device to preferentially steer STAs to the 6 GHz frequency band.

    sta-load-balance dynamic prefer 6g

    By default, STAs are steered to the 5 GHz or 6 GHz frequency band.

  9. (Optional) Configure immediate 6G steering for access STAs so that the device preferentially attempts to steer STAs to the 6 GHz radio immediately after they access the network.

    band-steer quick-prefer 6g

    By default, immediate 6G steering for access STAs is disabled.

  10. (Optional) Configure band steering parameters.
    1. Configure the start threshold for the number of access STAs during band steering.

      band-steer balance start-threshold start-threshold

      By default, the start threshold for the number of access STAs during band steering is 100.

    2. Configure the percentage threshold for access STAs on 5 GHz and 6 GHz radios during band steering.

      band-steer balance gap-threshold gap-threshold

      By default, the percentage threshold for access STAs on 5 GHz and 6 GHz radios during band steering is 90%.

    3. Configure the start SNR threshold for triggering band steering.

      band-steer snr-threshold snr-threshold

      By default, the start SNR threshold for triggering band steering is 20 dB.

    4. Configure the aging condition for STA band information.

      band-steer client-band-expire probe-counters

      By default, band information about a STA will be aged out when an AP has consecutively received Probe frames of the STA for more than 35 times on the same frequency band.

  11. Return to the WLAN view.

    quit

  12. (Optional) Configure MAC addresses of unsteerable STAs in smart roaming, AI roaming, band steering, and load balancing algorithms.

    station-unsteerable sta-mac sta-mac

    By default, no MAC addresses of unsteerable STAs are configured.

  13. Create a radio profile and enter its view.

    • Create a 2.4 GHz radio profile and enter its view.
      radio-2g-profile name profile-name
    • Create a 5 GHz radio profile and enter its view.
      radio-5g-profile name profile-name

  14. Bind the RRM profile.

    rrm-profile profile-name

    By default, the RRM profile default is bound to a radio profile.

Follow-up Procedure

Bind the radio profile and VAP profile to an AP group or a specific AP.
