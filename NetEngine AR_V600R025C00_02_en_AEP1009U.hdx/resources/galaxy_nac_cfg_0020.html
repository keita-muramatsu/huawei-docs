Configuring a MAC Access Profile

Context

The device uses MAC access profiles to uniformly manage the access configurations of MAC address authentication users. Before configuring MAC address authentication, you need to create a MAC access profile and then configure it. Select a proper authentication method based on the device, server, and security requirements. During MAC address authentication, you do not need to manually enter the user name and password, but you need to configure the user name format and password for MAC address authentication on the device.

When the device is connected to a ClearPass or an ISE server for MAC address authentication, you need to set the service-type value to 10 and the calling-station-id format to XX-XX-XX-XX-XX-XX in the RADIUS server template on the device.

Procedure

  1. Enter the system view.

    system-view

  2. Create a MAC access profile and enter the MAC access profile view.

    mac-access-profile name access-profile-name

    Before deleting a MAC access profile, ensure that it is not bound to any authentication profile.

  3. Configure the user name format for MAC address authentication.

    • The user name format configured for MAC address authentication must be supported by the authentication server.
    • A password must be configured when MAC address authentication is performed using AD or LDAP.
    • A password must be configured when MAC address authentication is enabled on a VLANIF interface, on an Eth-Trunk interface, or in a port group and the fixed user name format is configured for MAC address authentication.

      When MAC address authentication is enabled in a port group and the MAC address format is configured for MAC address authentication users, no password can be configured.

      When MAC address authentication is enabled on a VLANIF interface, a specific DHCP option cannot be configured as the user name for MAC address authentication.

    • After the weak password dictionary maintenance function is enabled, the passwords (which can be queried using the display security weak-password-dictionary command) defined in the weak password dictionary cannot be configured as the passwords of MAC address authentication users.

    Operation

    Command

    Configure a fixed user name for MAC address authentication.

    mac-authen username fixed username [ password cipher password ]

    Configure a MAC address as the user name for MAC address authentication.

    mac-authen username macaddress [ format { with-hyphen [ normal ] [ colon ] | without-hyphen } [ uppercase ] [ password cipher password ] ]

    Configure a specified DHCP option as the user name for MAC address authentication.

    mac-authen username dhcp-option 82 { circuit-id | remote-id } * [ separate separate ] [ format-hex ] password cipher password

  4. (Optional) Configure the authentication method for MAC address authentication.

    mac-authen authentication-method { chap | pap }

    By default, PAP authentication is used during MAC address authentication.

  5. (Optional) Configure the packet types that can trigger MAC address authentication.

    authentication trigger-condition { dhcp | arp | dhcpv6 | nd | any-l2-packet } *

    By default, DHCP, ARP, DHCPv6, and ND packets can trigger MAC address authentication.

  6. (Optional) Enable the device to send DHCP option information to the authentication server when MAC address authentication is triggered by DHCP packets.

    authentication trigger-condition dhcp dhcp-option option-code

    By default, the device does not send DHCP option information to the authentication server when MAC address authentication is triggered by DHCP packets.

  7. (Optional) Configure the MAC address segment for MAC address authentication.

    mac-authen permit mac-address mac-address mask { mask | mask-length }

    By default, no MAC address segment is configured for MAC address authentication.

    Only MAC address authentication users who go online through VLANIF interfaces support this function.

    A maximum of eight MAC address segments are allowed for MAC address authentication on a VLANIF interface.
