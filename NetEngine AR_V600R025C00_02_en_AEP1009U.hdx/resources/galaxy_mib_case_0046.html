Querying LLDP-EXT-DOT1-MIB Information

Description of MIB Objects

LLDP-EXT-DOT1-MIB allows you to query information about TLVs defined by IEEE 802.1, including whether the TLVs can be sent, and the VLAN IDs, VLAN names, protocol VLANs, and protocol types of local and remote ports. The OID of the root object is 1.0.8802.1.1.2.1.5.32962. For details, see LLDP-EXT-DOT1-MIB.

You can use the following objects to obtain extended LLDP information.

Table 1 Description of MIB objects

Object

OID

lldpXdot1ConfigPortVlanTxEnable

1.0.8802.1.1.2.1.5.32962.1.1.1.1.1

lldpXdot1LocPortVlanId

1.0.8802.1.1.2.1.5.32962.1.2.1.1.1

lldpXdot1RemPortVlanId

1.0.8802.1.1.2.1.5.32962.1.3.1.1.1

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.
  2. Perform the Walk operation on lldpXdot1ConfigPortVlanTxEnable to query whether TLVs defined by IEEE 802.1 can be sent through the local LLDP port. As shown in Querying whether TLVs defined by IEEE 802.1 can be sent through the local LLDP port, TLVs defined by IEEE 802.1 can be sent through the local LLDP port.
    Figure 1 Querying whether TLVs defined by IEEE 802.1 can be sent through the local LLDP port
  3. Perform the Walk operation on lldpXdot1LocPortVlanId to query the VLAN ID of the local LLDP port. As shown in Querying the VLAN ID of the local LLDP port, the VLAN ID of the local LLDP port is 100.
    Figure 2 Querying the VLAN ID of the local LLDP port
  4. Perform the Walk operation on lldpXdot1RemPortVlanId to query the VLAN ID of the remote LLDP port. As shown in Querying the VLAN ID of the remote LLDP port, the VLAN ID of the remote LLDP port is 100.
    Figure 3 Querying the VLAN ID of the remote LLDP port
