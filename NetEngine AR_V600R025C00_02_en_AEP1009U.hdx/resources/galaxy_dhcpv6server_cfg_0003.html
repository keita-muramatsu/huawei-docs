Configuring an IPv6 Address Pool

Context

A DHCPv6 server selects available IPv6 addresses from an address pool and assigns them to DHCPv6 clients. You need to create an IPv6 address pool and configure its attributes, including the address range, interval for updating configuration parameters, IPv6 addresses that cannot be automatically assigned to clients, and statically bound IPv6 addresses. IPv6 addresses can be dynamically assigned or statically bound to clients based on client requirements.

Procedure

  1. Enter the system view.

    system-view

  2. Create an IPv6 address pool and enter its view.

    dhcpv6 pool pool-name

    By default, no IPv6 address pool is created on a device.

  3. Run the following commands in the IPv6 address pool view to configure network prefixes.

    When functioning as a DHCPv6 server, the device can assign network parameters to clients in DHCPv6 stateful or stateless mode. In DHCPv6 stateful mode, the server automatically assigns IPv6 addresses, prefixes, and other network configuration parameters (such as DNS, NIS, and SNTP server addresses). In DHCPv6 stateless mode, the server assigns configuration parameters (such as DNS, NIS, and SNTP server addresses) but does not assign IPv6 addresses. IPv6 addresses of clients are automatically generated through route advertisement.

    • If the DHCPv6 server needs to automatically assign network parameters in DHCPv6 stateful mode, configure a network prefix and lifetime in the IPv6 address pool view.

      address prefix ipv6-prefix/ipv6-prefix-length [ eui-64 ] [ life-time { valid-lifetime | infinite } { preferred-lifetime | infinite } ] [ lock ]

      By default, neither a network prefix nor a lifetime is configured in the IPv6 address pool view.

    • If the DHCPv6 server needs to automatically assign network parameters in DHCPv6 stateless mode, configure a network prefix in the IPv6 address pool view.

      link-address ipv6-prefix/ipv6-prefix-length

      By default, no network prefix is configured in the IPv6 address pool view.

      A DHCPv6 server determines the network segment where clients need to be assigned network parameters from an address pool based on a configured network prefix.

  4. (Optional) Lock the IPv6 address pool.

    lock

    By default, no IPv6 address pool is locked on a device.

  5. (Optional) Bind an IPv6 address to a client DUID statically.

    static-bind address ipv6-address duid client-duid [ iaid iaid ] [ life-time { valid-lifetime | infinite } { preferred-lifetime | infinite } ]

    By default, no IPv6 address is statically bound to a client DUID in an address pool.

    To statically assign fixed IPv6 addresses to some specific clients, perform this step to specify the mapping between IPv6 addresses and client DUIDs. When such a client requests an IPv6 address from the DHCPv6 server, the device functioning as the DHCPv6 server assigns the specified IPv6 address to the client.

    The IPv6 address specified in this step can be assigned only to the client with a specified DUID.

  6. (Optional) Configure the range of IPv6 addresses that cannot be automatically assigned to clients from the IPv6 address pool.

    excluded-address start-ipv6-address [ to end-ipv6-address ]

    By default, all IPv6 addresses in an address pool can be automatically assigned to clients. If only one IPv6 address cannot be automatically assigned, specify only the start-ipv6-address parameter.

    If the interface address of the DHCPv6 server is in the range of the IPv6 address pool, you are advised to perform this step to prevent the DHCPv6 server from assigning the interface address.

  7. (Optional) Configure an interval for updating configuration parameters assigned to clients through stateless DHCPv6 address autoconfiguration.

    information-refresh time

    By default, the interval for updating configuration parameters in an IPv6 address pool is 86400s (24 hours).

  8. (Optional) Configure an IPv6 address for the AC.

    capwap-ac ipv6-address

    By default, no IPv6 address is configured for the AC in the IPv6 address pool view.

    In the AC+Fit AP scenario, the AC needs to establish connections with APs. The device functioning as a DHCPv6 server can specify the AC's IPv6 address for an AP, which then can connect to the specified AC. If the AC and AP are located on the same network segment, this step is optional because the AP sends a broadcast packet to automatically discover the AC. If the AC and AP are located on different network segments, this step is mandatory.

  9. (Optional) Configure the percentage of the lease renewal time in the preferred lifetime of an IPv6 address pool and the percentage of the rebinding time in the preferred lifetime.

    renew-time-percent renew-time-percent rebind-time-percent rebind-time-percent

    By default, the percentage of the lease renewal time in the preferred lifetime of an IPv6 address pool is 50%, and the percentage of the rebinding time in the preferred lifetime is 80%.

  10. (Optional) Configure an aging time for conflicting addresses in the IPv6 address pool.

    conflict-address expire-time expire-time

    By default, the aging time of conflicting addresses is 172800s (two days).
