License Fails to Be Activated

If an error message is displayed on a device where the license active file-name command is run to activate the license file, see Table1 Causes for license file activation failures and solutions for troubleshooting measures.

If the license file still cannot be activated, collect error information and contact technical support personnel.

Table 1 Causes for license file activation failures and solutions

Information Displayed on the Device

Possible Cause

Procedure

Error: Invalid format of the license file.

The format of the license file is invalid. The possible cause is that the file is modified. The system cannot activate the license file that has been manually modified, even if only the file name is modified.

Download the license file again. If the license file still cannot be activated after being downloaded again, contact Huawei technical support personnel.

Error: Invalid file name.

The file name of the license to be activated is incorrect.

Apply for or purchase a new license file.

Error: Failed to verify the license.

The license file fails to be verified.

Apply for or purchase a new license file.

Error: The ESN of the license file does not match with the device.

The ESN or version information of the license file does not match that of the device.

Try to restart the device. If the ESN of the license file is the same as that of the device after the restart, reload the license file. If the ESN of the license file is still different from that of the device, apply for a license file with the correct ESN and version information.

Error: The product type of the license file does not match with the device.

The product type of the license file does not match that of the device.

Apply for a license file with the same product type as the current device.

Error: The license file has expired.

The license file has expired.

Apply for a license file that has not expired.

Error: Failed to dispatch the license file.
The license file fails to be transmitted. The possible causes are as follows:
  • The disk space of the standby MPU is full.
  • The license file does not exist.
  • An active/standby switchover occurs when the license file is activated.
  • Delete unnecessary files on the standby MPU to release the disk space.
  • Ensure that the license file exists on the device.
  • Do not perform an active/standby switchover when the license file is activated. If an active/standby switchover occurs, activate the license file again after the switchover is completed.

Error: The license file has been activated.

The license file has been activated.

No further activation is required.

Error: Failed to activate the license.

The license file fails to be activated.

Contact technical support personnel.

Warning: No product feature is present in the license file.

  • Cause 1: The license file is for basic software functions, which contains only basic software quotation items. It has been built in the device and activated before delivery.

  • Cause 2: The control items that need to be activated in the license file are not supported on the current device.

  • For cause 1: The license file for basic software functions does not require manual activation.

  • For cause 2: Apply for a license file that contains the control items in the system. The license file can be activated only if at least one of the control items in the license file is supported by the device.

Warning: Save device.sys failed. Please save configuration before reboot.

The device.sys file fails to be saved.

Run the save command to save the device.sys file before the device is restarted. Activate the license file again after the restart.
