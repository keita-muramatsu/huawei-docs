Software Package Management Security

Overview

Software packages running on a device are classified into base and feature software packages. A software package may be tampered with before being uploaded to a device. Running such a software package on a device will cause the device to be controlled and attacked. The following security mechanisms can be used to secure the entire process from file transfer to the running of the software package:

  • Digital signatures are supported.

    When a software package is released, the software package is digitally signed and the digital signature information file is packed into the software package. When an NMS distributes the software package to an NE or such a software package is directly loaded onto the NE, the NMS verifies the digital signature offline. After verification is successful, the software package is considered complete and reliable. Otherwise, the software package is considered invalid.

  • The software package in the running state is protected as a system file. In this case, the package cannot be modified or deleted.

Before installing a software package, verify the integrity of the package. Integrity verification includes digital signature verification and protection mechanism verification. Either of the following integrity verification modes can be used:

  • Before the installation, manually verify the integrity of the software package.
  • When a feature software package is installed in in-service mode or when a software package that takes effect at the next startup is specified and the device is restarted, the integrity of the software package is automatically verified.

If the integrity verification of the software package fails, you are advised to restart the system instead of trying for multiple times.

Impact on the System

None

Procedure

  • Before the installation, manually verify the integrity of the software package. The following uses the software package XXX_V600R025C00.cc as an example to describe how to manually verify the software package.

    <HUAWEI> check software file-name XXX_V600R025C00.cc
Warning: Software file verification consumes CPU resources. Continue? [Y/N]:y

  • When a feature software package is installed in in-service mode or when a software package that takes effect at the next startup is specified and the device is restarted, the integrity of the software package is automatically verified.

Checking the Security Hardening Result

  • When the integrity of the software package is manually verified, the system will prompt a message:
    • If the verification is successful, the following message will be displayed:
      Info: The integrity check for the system software of the V600R025C00 version succeeds.
    • If the verification fails, the following message will be displayed:
      Error: Failed to check the integrity of the system software of the unknown version.
  • When the integrity of the software package is automatically verified, the system will prompt a message:
    • If the verification fails, the system refuses to start and displays a message "package verify failed" on the console port. In addition, the system restarts. If the verification fails for three consecutive times, the system rolls back to the previous startup software package.
