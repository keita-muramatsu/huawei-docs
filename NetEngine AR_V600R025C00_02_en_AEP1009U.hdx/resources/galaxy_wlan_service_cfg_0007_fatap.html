Radio Profile

Overview

Radio profiles are used to configure parameters for optimizing radios, and are categorized as 2.4 GHz or 5 GHz radio profiles, which take effect on 2.4 GHz radios and 5 GHz or 6 GHz radio profiles, respectively.

The configuration in a radio profile can take effect only after the profile is bound to an AP group or a specified AP.

Creating a Profile

  1. Enter the WLAN view.

    system-view
wlan

  2. Create a radio profile.

    # Create a 2.4 GHz radio profile.

    radio-2g-profile name profile-name

    # Create a 5 GHz radio profile.

    radio-5g-profile name profile-name

Applying a Profile

  1. Enter the WLAN view.

    system-view
wlan

  2. Bind a radio profile to an AP group or a single AP. Perform one of the following steps:
    • Bind a radio profile to an AP group.
      ap-group name group-name
radio-2g-profile profile-name radio { radio-id | all }
radio-5g-profile profile-name radio { radio-id | all }
    • Bind a radio profile to an AP.
      ap-id ap-id
radio-2g-profile profile-name radio { radio-id | all }
radio-5g-profile profile-name radio { radio-id | all }
    • Bind a radio profile to radios on APs in an AP group.
      ap-group name group-name
radio radio-id
radio-2g-profile profile-name
radio-5g-profile profile-name
    • Bind a radio profile to radios on an AP.
      ap-id ap-id
radio radio-id
radio-2g-profile profile-name
radio-5g-profile profile-name
