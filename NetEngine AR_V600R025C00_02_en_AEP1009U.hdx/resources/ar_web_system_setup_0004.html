System Restart

Context

  • If the device works improperly, try to rectify the fault. Do not restart the system frequently in case that services are affected.

  • If you must restart the system, select off-peak hours such as in the early morning in non-emergent cases.

  • Restarting the system may cause loss of temporary data. Before restarting the system, ensure that the configuration file has been saved.

  • You are advised to back up the current configuration file before restarting the system.

Procedure

  1. Choose System > Setup > Restart. The System Restart page is displayed, as shown in Figure 1.

    Figure 1 System Restart page

  2. Use either of the following methods to restart the system:

    • Click Save and Restart to save the configuration and restart the system.
    • Click Restart to restart the system without saving the configuration.
