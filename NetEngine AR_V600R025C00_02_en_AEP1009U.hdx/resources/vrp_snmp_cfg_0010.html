SMI

Structure of Management Information (SMI) is a set of rules used to name and define managed objects. It can define the ID, type, access level, and status of managed objects. At present, there are two SMI versions: SMIv1 and SMIv2.

The following standard data types are defined in SMI:

  • INTEGER

  • OCTER STRING

  • DisplayString

  • OBJECT IDENTIFIER

  • NULL

  • IpAddress

  • PhysAddress

  • Counter

  • Gauge

  • TimeTicks

  • SEQUENCE

  • SEQUENDEOF
