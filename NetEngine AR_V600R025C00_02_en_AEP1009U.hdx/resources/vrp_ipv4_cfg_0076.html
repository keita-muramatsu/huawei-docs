Example for Configuring a Loopback Interface Address as an Unnumbered Address

Networking Requirements

As shown in Figure 1, DeviceA and DeviceB are connected through serial interfaces. Loopback1 is configured on DeviceA and an IP address is assigned to it.

To conserve IP address resources, the customer wants to implement communication without assigning an IP address to Serial1/0/0 on DeviceA.

Figure 1 Network diagram of configuring a loopback interface address as an unnumbered address

Configuration Roadmap

The configuration roadmap is as follows:

  • Configure the serial interface on DeviceA to borrow the IP address of Loopback1.
  • Configure an IP address for the serial interface on DeviceB.

Procedure

  1. Configure Serial1/0/0:0 on DeviceA to borrow the IP address of Loopback1.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] interface serial 1/0/0:0
[DeviceA-Serial1/0/0:0] ip address unnumbered interface loopback 1
[DeviceA-Serial1/0/0:0] quit

  2. Configure the interface on DeviceB.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceB
[DeviceB] interface serial 1/0/0:0
[DeviceB-Serial1/0/0:0] ip address 10.1.1.2 30
[DeviceB-Serial1/0/0:0] quit

Configuration Scripts

  • DeviceA

    #
sysname DeviceA
#
interface Serial1/0/0:0
 link-protocol ppp
 ip address unnumbered interface LoopBack1
#
interface LoopBack1
 ip address 10.1.1.1 255.255.255.255
#
return

  • DeviceB

    #
sysname DeviceB
#
interface Serial1/0/0:0
 link-protocol ppp
 ip address 10.1.1.2 255.255.255.252
#
return
