Applying the Cellular Network Configuration

Context

To apply the cellular network configuration, you need to bind the cellular profile to the cellular interface and bind the APN profile to a cellular channel interface.

Procedure

  1. Enter the cellular interface view.

    interface cellular interface-number

  2. Bind a cellular profile.

    cellular-profile profile-name

    By default, no cellular profile is bound to a cellular interface.

  3. Bind an APN profile to a cellular channel interface.
    1. Enter the cellular channel interface view.

      interface cellular interface-number

    2. Bind an APN profile. To bind multiple APN profiles to the same cellular channel interface, repeat this step. The priority parameter specifies the priority of an APN profile. A larger value indicates a higher priority.

      apn-profile profile-name [ priority priority ]

      By default, no APN profile is bound to a cellular channel interface.

      Ensure that the APN profile bound to cellular channel interface 1 (for example, Cellular 2/0/0:1) is configured with correct information (such as the user name and password); otherwise, other cellular channel interfaces may fail to get IP addresses.

      After the APN information is configured, there may be future scenarios where you need to modify an APN profile. After you modify the configuration of an APN profile, if the dial-up connection function is enabled on the device, you need to restart the cellular channel interface for the modification to take effect. To do so, run the shutdown and undo shutdown commands or the restart command.
