Querying the Fan Speed

Description of MIB Objects

You can use hwEntityFanSpeed in hwFanStatusTable to obtain the percentage of the current fan speed to the full speed.

Object

OID

hwEntityFanSpeed

1.3.6.1.4.1.2011.5.25.31.1.1.10.1.5

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.
  2. Perform the Walk operation on hwEntityFanSpeed to query the fan speed. As shown in Figure 1, the current fan speed is 51% of the full speed.
