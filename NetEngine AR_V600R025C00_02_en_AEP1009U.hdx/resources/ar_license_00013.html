Rolling Back a License

Context

In case of incorrect entitlement issuing, you can roll back the issuing and issue the entitlement again.
  • For a commercial distribution contract, if the entitlement to roll back has been activated, you need to roll back the license before rolling back the entitlement.
  • For a non-commercial distribution contract, if the entitlement to roll back has been activated, a message indicating that an entitlement has been activated will pop up. Click OK. The entitlement can still be rolled back.
  • If multiple entitlements need to be rolled back simultaneously, the entitlements must belong to the same contract.
  • After an entitlement is rolled back, Undistributed will be displayed in Entitlement Status.

You can run the display license revoke-ticket command in any view to obtain the license revocation code.

Procedure

  • Enter search criteria and click Search.

    Path: Entitlement Management > My Entitlements > Distributed Entitlements

  • Select the entitlement to roll back and click Rolling Back Entitlement.

  • Click OK.
