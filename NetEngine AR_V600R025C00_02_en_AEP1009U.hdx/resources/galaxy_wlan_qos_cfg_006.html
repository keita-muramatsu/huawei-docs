Configuring EDCA Parameters

Prerequisites

Before performing the configuration, you have completed the following task:
  • Configure AP onboarding and STA access.

Context

Adjust WMM EDCA parameter settings as follows:
  • Manual adjustment: allows you to manually adjust EDCA parameter settings.
  • Dynamic adjustment: The dynamic EDCA parameter adjustment function detects the traffic volume of access categories (ACs) and flexibly adjusts physical channel contention parameters to reduce the probability of collisions. This greatly increases the overall throughput and improves user experience.

For APs running R024C00 or earlier, if dynamic EDCA parameter adjustment is configured when you manually adjust EDCA parameters, the dynamic adjustment function takes effect preferentially. To make manually adjusted EDCA configuration take effect, disable dynamic EDCA parameter adjustment (by using the undo dynamic-edca enable command) and the intelligent multimedia scheduling algorithm (by using the undo multimedia-air-optimize enable command).

For APs running R024C10 or later, if dynamic EDCA parameter adjustment is configured when you manually adjust EDCA parameters, the manual configuration takes effect preferentially.

For details about dynamic EDCA parameter adjustment, see Configuring Dynamic EDCA Adjustment for a Radio.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a radio profile and enter its view.

    • Create a 2.4 GHz radio profile and enter its view.
      radio-2g-profile name profile-name

    • Create a 5 GHz radio profile and enter its view.
      radio-5g-profile name profile-name

  4. Enable the WMM function.

    undo wmm disable

    By default, the WMM function is enabled.

    The 6 GHz frequency band is supported since 802.11ax. The WMM function on the 6 GHz frequency band cannot be disabled. That is, the wmm disable command does not take effect on the 6 GHz frequency band.

  5. Configure EDCA parameters and ACK policies for APs.

    wmm edca-ap { ac-vo | ac-vi | ac-be | ac-bk } { aifsn aifsn-value | ecw ecwmin ecwmin-value ecwmax ecwmax-value | txoplimit txoplimit-value | ack-policy { normal | noack } }*

  6. Bind the radio profile.

    Bind the radio profile to an AP group or a single AP so that the configuration in the profile can take effect. For details, see Radio Profile.

  7. Return to the WLAN view.

    quit

  8. Enable the WMM function of an SSID profile.

    When the WMM function is not configured in an SSID profile, the WMM configuration in effect is the same as that in the radio profile view; when the WMM function is configured in an SSID profile, the WMM configuration in the SSID profile takes effect.

    1. Create an SSID profile and enter its view.

      ssid-profile name profile-name

      By default, the SSID profile default exists on the device.

    2. Enable the WMM function in the SSID profile.

      wmm enable

      By default, the WMM configuration does not exist in an SSID profile.

    3. Bind the SSID profile.

      Bind the SSID profile to an AP group or a single AP so that the configuration in the profile can take effect. For details, see SSID Profile.

Verifying the Configuration

  • Run the display radio-5g-profile name profile-name or display radio-2g-profile name profile-name command to check the WMM EDCA parameter settings in a radio profile.
