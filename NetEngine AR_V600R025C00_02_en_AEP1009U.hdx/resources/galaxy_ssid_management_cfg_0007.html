Configuring an Offline Management SSID

Context

In most cases, APs are installed in unobtrusive or high positions. If an AP unexpectedly goes offline, maintenance personnel must connect to an Ethernet port on the AP to locate the fault, which is inconvenient.

The offline management SSID function addresses this issue. With this function, to locate and rectify the fault, all maintenance personnel need to do is associate a STA with the offline management SSID of an AP and connect the STA to the AP wirelessly using STelnet. In this way, there is no need to connect to the AP through an Ethernet cable. To configure the offline management SSID function, use either of the following methods:

  • Configuring the default offline management SSID: Enable the offline management SSID function. Then when an AP goes offline unexpectedly, the offline management SSID named hw_manage_xxxx is automatically created. Here, xxxx indicates the last 4 digits of the AP's MAC address.
  • Creating an offline management SSID: Create a VAP profile, and bind a new security profile with a high security level and a new SSID profile to the VAP profile. Configure the VAP as the offline management VAP. Then the SSID in the SSID profile is used as the offline management SSID, so the default offline management SSID will not be generated when an AP unexpectedly goes offline. After these configurations are completed, the default offline management SSID will not be generated when an AP goes offline unexpectedly.

Procedure

  • Configuring the default offline management SSID
    1. Enter the system view.

      system-view

    2. Enter the WLAN view.

      wlan

    3. Configure a login password for the offline management SSID.

      temporary-management psk psk

      By default, no login password is configured for the offline management SSID.

      For security purposes, change the password periodically.

    4. Create an AP system profile and enter its view.

      ap-system-profile name profile-name

      By default, the AP system profile default exists on the device.

    5. Enable the offline management SSID function.

      undo temporary-management disable

      By default, the offline management SSID function is enabled on APs.

    6. Return to the WLAN view.

      quit

    7. Enter the AP group view or AP view.

      • Enter the AP group view.
        ap-group name group-name
      • Enter the AP view.
        ap-id ap-id

    8. Bind the AP system profile to an AP group or a single AP.

      ap-system-profile profile-name

      By default, the AP system profile default is bound to an AP group, but no AP system profile is bound to an AP.

  • Creating an offline management SSID
    1. Enter the system view.

      system-view

    2. Enter the WLAN view.

      wlan

    3. Configure a security profile.

      1. Create a security profile and enter its view.
        security-profile name profile-name

        By default, the system provides the security profile default.

      2. Configure a security policy. For details, see "Configuring Security Policies" in WLAN Security Configuration.

        If the VAP in a VAP profile is configured as the offline management VAP, the security profile referenced by the VAP profile supports only the WPA3 SAE, WPA2-WPA3 PSK-SAE, and WPA/WPA2/WPA-WPA2 PSK security policies.

      3. Return to the WLAN view.
        quit

    4. Create a VAP profile view and enter its view.

      vap-profile name profile-name

    5. Bind a security profile to the VAP profile.

      security-profile profile-name

      By default, the security profile default is bound to a VAP profile.

    6. Configure the SSID generated by the VAP profile as the offline management SSID.

      temporary-management enable

    7. Return to the WLAN view.

      quit

    8. Create an AP system profile and enter its view.

      ap-system-profile name profile-name

      By default, the AP system profile default exists on the device.

    9. Enable the offline management SSID function.

      undo temporary-management disable

      By default, the offline management SSID function is enabled on APs.

    10. Configure a login password for the offline management SSID.

      temporary-management psk psk

      By default, no login password is configured, and the global login password is used.

      For security purposes, change the password periodically.

    11. Return to the WLAN view.

      quit

    12. Enter the AP group view or AP view.

      • Enter the AP group view.
        ap-group name group-name
      • Enter the AP view.
        ap-id ap-id

    13. Bind the AP system profile to an AP group or a single AP.

      ap-system-profile profile-name

      By default, the AP system profile default is bound to an AP group, but no AP system profile is bound to an AP.
