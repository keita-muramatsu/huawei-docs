Configuring an AD Server Template

Context

In an AD server template, you must specify the server type, IP address, and port number. The other parameters have default settings, for example, the Base DN. These default settings can be modified as needed.

  • The system time and time zone of the device must be the same as those on the AD server.

Procedure

  1. Enter the system view.

    system-view

  2. Create an AD server template and enter the AD server template view.

    ad-server template template-name

  3. Configure an AD server. You can specify an AD server using either of the following methods:

    One method is to specify the IP address of the AD server.

    ad-server authentication ip-address port [ secondary | third ] [ ldap-over-ssl | no-ssl ]

    The other method is to specify the URL of the AD server.

    ad-server authentication server-url url [ port ] [ ldap-over-ssl | no-ssl ]

    By default, no AD server is configured. Note the following when configuring an AD server:

    • port specifies the port number of the AD server. The default value is 88.
    • Before specifying a URL to configure an AD server, ensure that the DNS server has been configured. The first three IP addresses parsed by the DNS server are assigned to the primary, secondary, and tertiary AD servers respectively.

      After the FIPS mode is enabled, the no-ssl parameter cannot be used.

  4. (Optional) Configure the source IP address for communication between the device and AD server.

    ad-server source { loopback interface-number | ip-address ip-address | vlanif interface-number }

    By default, when the device sends packets to the AD server, the IP address of the outbound interface is used as the source IP address.

    If the specified loopback interface or VLANIF interface is not created or has no IP address configured, the IP address of the outbound interface is used as the source IP address.

  5. Configure the Base DN of the AD server.

    ad-server authentication base-dn base-dn

    By default, the Base DN is dc=my-domain,dc=com.

  6. Configure the administrator DN and password of the AD server.

    ad-server authentication manager manager password

    By default, no administrator DN and password are configured for an AD server.

    For security purposes, it is recommended that the password contain at least eight characters and at least three types of the following characters: uppercase letters, lowercase letters, digits, and special characters.

    If you run the ad-server authentication manager-anonymous enable command after the administrator DN and password of the AD server are set, the administrator DN and password settings will be automatically cleared, and the Base DN will also be deleted.

  7. (Optional) Configure the AD server to allow administrators to log in anonymously.

    An anonymous login does not require the user name and password, posing security risks. Determine whether to enable anonymous login after risk assessment.

    ad-server authentication manager-anonymous enable

    By default, administrators are not allowed to access the AD server anonymously.

    After this command is configured, if you run the ad-server authentication manager manager password command to configure the administrator DN and password of the AD server, the anonymous login configuration will be cleared.

  8. Set a host name for the AD server.

    ad-server authentication host-name host-name [ secondary | third ]

    By default, no host name is set for an AD server.

  9. Configure the LDAP port number of the AD server and the SSL-encrypted LDAP port number.

    ad-server authentication ldap-port port ldap-ssl-port port

    By default, the LDAP port number of the AD server is 389, and the SSL-encrypted LDAP port number is 636.

  10. (Optional) Enable user binding during AD authorization.

    ad-server authorization bind-user enable

    By default, user binding is required during AD authorization.

  11. (Optional) Configure the user attribute filter field value of the AD server.

    ad-server user-filter field

    By default, the user attribute filter field value used as a user name on an AD server is sAMAccountName.

  12. (Optional) Configure the group attribute filter field value of the AD server.

    ad-server group-filter field

    By default, the group attribute filter field value is ou.

  13. (Optional) Configure an administrator DN of the AD server to contain the Base DN.

    ad-server authentication manager-with-base-dn enable

    By default, an administrator DN contains the Base DN.

Verifying the Configuration

  • Run the display ad-server template [ name template-name ] command to check the AD server template configuration.
  • Run the test-aaa user-name user-password ad-template template-name command to test the connectivity between the device and server. For details about common fault information and troubleshooting methods, see Testing the Server Connectivity.
