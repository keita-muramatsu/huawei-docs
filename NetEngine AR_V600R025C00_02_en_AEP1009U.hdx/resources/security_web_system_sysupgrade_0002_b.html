Loading or Upgrading a Feature Package Locally

Context

For details about whether feature package loading is controlled by a license, see the License Usage Guide.

Integrated feature package: a feature software package (.cc) integrated in the system software package. For the same system software package, the feature package of the upgrade version (.ccx) exists with the integrated feature package. They can be upgraded and rolled back.

Independent feature package: a feature software package (.ccx) not integrated in the system software package. They can be installed, upgraded, and uninstalled.

Procedure

  1. Choose System > Device Upgrade. The System Upgrade page is displayed, as shown in Figure 1.

    Figure 1 System Upgrade page

  2. Check the feature packages supported by the system in the system upgrade file list and perform related operations.

    • Click Upload Feature Packages. In the dialog box shown in Figure 2, upload a feature package from the local PC and set it as Current feature package or Startup feature package.

      You can select a feature package in .ccx format to upload.

      Figure 2 Uploading a feature package
    • Click Package Management. In the dialog box shown in Figure 3, you can perform operations on the feature package in the flash memory of the device.
      Figure 3 Feature package management

      Operation

      Description

      Downloading a feature package

      Click to download the feature package file from the device flash.

      Configuring a feature package to take effect immediately or upon next startup

      Click to enable the feature package immediately or upon next startup.

      If changes to , the configuration is successful.

      Deleting a feature package

      Click to delete unnecessary feature packages whose Status is Not Running to save the storage space of the flash memory.
    • When both the Current File and Startup File columns are not empty, the Remove button is available in the Operation column. You can click Remove to uninstall an enabled feature package or the feature package to be enabled upon the next startup, as shown in Figure 4.
      Figure 4 Uninstalling a feature package
