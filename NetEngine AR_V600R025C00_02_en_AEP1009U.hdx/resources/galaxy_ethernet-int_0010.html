Configuring MEth Management Interface Attributes

Context

The MEth management interface is a special Ethernet interface used to log in to a device to perform configuration and management.

This function is available only for devices that support MEth interfaces. For details about whether the device supports MEth interfaces, see "Ports" in Get to Know the Product > Hardware Description > Chassis. If the information in "Ports" contains MGMT interfaces, the device supports MEth interfaces. If the information does not contain MGMT interfaces, the device does not support MEth interfaces.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the MEth management interface view.

    interface meth 0/0/0

    The working MEth management interface is displayed as the logical management interface MEth0/0/0. To check the status of a physical management interface or determine the working management interface if there are multiple MEth management interfaces, run the display interface meth status command.

  3. Configure an IP address for the MEth management interface.

    ip address ip-address { mask | mask-length } [ sub ][ tag tag-value ]

  4. (Optional) Disable auto-negotiation and set a working speed for the MEth management interface.

    negotiation disable
speed { 10 | 100 | 1000 }

    By default, an interface works in auto-negotiation mode and operates at its maximum supported rate.

    If interface hardware complies with auto-negotiation standards, it is recommended that Ethernet interfaces work in auto-negotiation mode.

    Manually setting interface rates usually complicates network planning and maintenance, and improper settings will affect or even interrupt the network communication.
