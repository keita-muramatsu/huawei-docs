Maintaining STUN

Clearing STUN Statistics

You can view STUN statistics to locate faults during routine maintenance. To view STUN statistics within a specific period, you need to clear the existing STUN statistics.

STUN statistics cannot be restored after they are cleared. Exercise caution when performing this operation.

Procedure

  • Run the reset stun statistics command in the user view to clear STUN statistics.
  • Run the display stun statistics command in any view to check STUN statistics.
