Configuring WAPI-PSK Authentication

Context

WAPI allows only robust security network association (RSNA), providing higher security than WEP or WPA/WPA2.

WAPI-PSK authentication applies to home networks or small-scale enterprise networks. No additional certificate system is required.

WAPI defines a dynamic key negotiation mechanism, but there are still security risks if a STA uses the same encryption key for a long time. Both the unicast session key (USK) and multicast session key (MSK) have a lifetime. The USK or MSK needs to be updated when its lifetime ends. To enhance security, WAPI provides the time-based key update mechanism.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a security profile and enter its view.

    security-profile name profile-name

    By default, the security profile default exists in the system.

  4. Set the security policy to WAPI-PSK authentication.

    security wapi psk { pass-phrase key-value | hex hex-value }

    By default, no security policy is configured.

  5. (Optional) Set the interval for updating a BK and the BK lifetime percentage.

    wapi { bk-threshold bk-threshold | bk-update-interval bk-update-interval }

    By default, the interval for updating a BK is 43200s, and the BK lifetime percentage is 70%.

  6. (Optional) Set the timeout period of a security association.

    wapi sa-timeout sa-time

    By default, the timeout period of a security association is 60 seconds.

  7. (Optional) Configure the WAPI USK or MSK update.

    wapi { usk | msk } key-update { disable | time-based }

    By default, USKs and MSKs are updated based on time.

  8. (Optional) Set the interval for updating a USK and the number of retransmissions of USK negotiation packets.

    wapi { usk-update-interval usk-interval | usk-retrans-count usk-count }

    By default, the interval for updating a USK is 86400s, and the number of retransmissions of USK negotiation packets is 3.

  9. (Optional) Set the interval for updating an MSK and number of retransmissions of MSK negotiation packets.

    wapi { msk-update-interval msk-update-interval | msk-retrans-count msk-retrans-count }

    By default, the interval for updating an MSK is 86400s, and the number of retransmissions of MSK negotiation packets is 3.
