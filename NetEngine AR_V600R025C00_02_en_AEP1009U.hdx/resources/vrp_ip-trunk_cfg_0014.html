Verifying the Configuration

After configuring an IP-Trunk interface, you can check the status and forwarding table of the IP-Trunk interface and information about its member interfaces.

Prerequisites

An IP-Trunk interface has been configured.

Procedure

  • Run the display interface ip-trunk [ trunk-id ] command to check the status of the IP-Trunk interface.
  • Run the display trunkmembership ip-trunk trunk-id command to check information about the member interfaces of the IP-Trunk interface, such as the member interface status and weights.
  • Run the display fwm trunk ifmstate interface interface-type interface-num command to check the management state table of IP-Trunk member interfaces.
  • Run the display fwm ip-trunk trunk-id local-id [ slot slot-id ] command to check IP-Trunk IDs in the forwarding and control planes.
  • Run the display fwm ip-trunk member trunk-id command to check IP-Trunk member interface information, such as the forwarding types of the member interfaces and the destination port number.
  • Run the display fwm ip-trunk status trunk-id command to check information about the IP-Trunk interface status, such as the IP-Trunk interface's Hash type and Trunk valid flag.
  • Run the display interface { interface-name | interface-type interface-number } forwarding-table command to check the forwarding table of the IP-Trunk interface.
