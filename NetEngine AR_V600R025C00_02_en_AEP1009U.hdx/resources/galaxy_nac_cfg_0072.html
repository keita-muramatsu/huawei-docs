Multi-mode Authentication Configuration Process

Pre-configuration Tasks

NAC only provides multiple network access control protocols for users. To implement user authentication and control users' network access rights, complete the following AAA configuration tasks before configuring NAC:

  • Configure the domain to which a user belongs and AAA schemes to be used by the user.
  • Configure the user name and password on the RADIUS or HWTACACS server if RADIUS or HWTACACS authentication is used.
  • Configure the user name and password manually on the access device if local authentication is used.

For details on how to configure the AAA client, see AAA Configuration.

Summary of Configuration Tasks

The following table lists the supported authentication modes and corresponding configuration tasks.

Multi-mode Authentication

Scenario

Configuration Task

MAC address bypass authentication

MAC address bypass authentication is recommended when an access device has both PCs and dumb terminals such as printers and fax machines connected. In this case, MAC address authentication can be performed for the terminals if 802.1X authentication fails.
Perform the following configurations in sequence:
  1. Configure MAC address authentication by referring to Configuring MAC Address Authentication.
  2. Configure 802.1X authentication by referring to Configuring 802.1X Authentication.
  3. Enable MAC address bypass authentication in the authentication profile.
  4. (Optional) Configuring NAC Extended Functions

MAC Address-Prioritized Portal Authentication

Users are geographically scattered, move frequently, and want to access the Internet again seamlessly upon successful one-time authentication.

In MAC address-prioritized Portal authentication, when the Portal server needs to authenticate a user terminal, the access device first sends the user terminal's MAC address to the Portal server for authentication. If the authentication fails, the Portal server pushes the Portal authentication page to the terminal. The user then enters the user name and password for authentication. The RADIUS server caches a terminal's MAC address during the first authentication for the terminal. If the terminal is disconnected and then connected to the network within the MAC address validity period, the RADIUS server searches for the MAC address of the terminal in the cache to authenticate the terminal.
Perform the following configurations in sequence:
  1. Configure MAC address authentication by referring to Configuring MAC Address Authentication.
  2. Configure Portal authentication by referring to Configuring Portal Authentication (Portal Server Using the Portal Protocol) or Configuring Portal Authentication (Portal Server Using HTTP or HTTPS).
  3. (Optional) Configuring NAC Extended Functions
