Configuring the AP Upgrade Mode

Context

Table 1 details AP upgrade modes.

Table 1 AP upgrade modes

Upgrade Mode

Function

Scenario

AC mode

An AP downloads the required upgrade file from a WAC.

Scenario where no file server is deployed on the network.

FTP mode

An AP downloads the required upgrade file from an FTP server.

Scenario that does not require high network security during file transfer. In FTP mode, data is transmitted in plaintext, which poses security risks.

SFTP mode

An AP downloads the required upgrade file from an SFTP server.

Scenario that requires high network security. In SFTP mode, data is encrypted, ensuring data integrity and privacy.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Configure the AP upgrade mode. Choose an appropriate upgrade mode based on the site requirements.

    By default, the AP upgrade mode is AC.

    • Set the AP upgrade mode to AC.
      ap update mode ac-mode
    • Set the AP upgrade mode to FTP.
      1. Set the AP upgrade mode to FTP.
        ap update mode ftp-mode
      2. Configure the FTP server.
        ap update ftp-server { ip-address server-ip-address | ipv6-address server-ipv6-address } [ port port ] ftp-username ftp-username ftp-password cipher ftp-password

        By default, no FTP server information is configured on the device.

        Ensure that the FTP server user name and unencrypted password configured on the WAC do not contain double quotation marks ("), which are not supported by APs currently. Otherwise, the FTP-based upgrade fails.

        The FTP server must support the REST field. Otherwise, the upgrade will fail. If the following information is displayed, the upgrade fails because the server does not support the REST field. In this case, replace the server.

        Error: Upgrade failed because the FTP server does not support the REST command.

        For security purposes, change the password periodically.

      3. Set the maximum number of APs that can be upgraded simultaneously in FTP mode.
        ap update ftp-server max-connect-number max-connect-number { ipv4 | ipv6 }

        By default, a maximum of 50 APs can be upgraded simultaneously in FTP mode.

        The WAC can function as an FTP server. Alternatively, use an external FTP server, which is recommended.
        • When an external FTP server is used, the maximum number of APs that can be upgraded simultaneously is the configured max-connect-number.

        • When a WAC is used as the FTP server, a maximum of 15 APs can be upgraded simultaneously even if the maximum number of APs that can be upgraded simultaneously is larger than 15.

          Before you configure the WAC as the FTP server, run the ap update ftp-server max-connect-number max-connect-number ipv4 command to set the maximum number of APs that can be upgraded simultaneously. The value of max-connect-number is an integer ranging from 1 to 15. During the upgrade, a maximum of 1 to 15 APs can be upgraded at a time until all APs are upgraded.

          If the configured number of APs to be upgraded simultaneously is larger than 15, an error message will be displayed after the first 15 APs are upgraded. The remaining APs cannot be automatically upgraded. You need to repeatedly run the command until all APs are upgraded.

          When the WAC is used as the FTP server, if n VTY users have logged in, the maximum number of APs that can be upgraded simultaneously decreases by n – 1.

        • When IPv4 and IPv6 FTP servers are both configured, set this parameter in both the two IP versions.
    • Set the AP upgrade mode to SFTP.
      1. Set the AP upgrade mode to SFTP.
        ap update mode sftp-mode
      2. Configure the SFTP server.
        ap update sftp-server { ip-address server-ip-address | ipv6-address server-ipv6-address } [ port port ] sftp-username sftp-username sftp-password cipher sftp-password

        By default, no SFTP server information is configured on the device.

        Ensure that the SFTP server user name and unencrypted password configured on the WAC do not contain double quotation marks ("), which are not supported by APs currently. Otherwise, the SFTP-based upgrade fails.

        For security purposes, change the password periodically.

      3. Set the maximum number of APs that can be upgraded simultaneously in SFTP mode.
        ap update sftp-server max-connect-number max-connect-number { ipv4 | ipv6 }

        By default, a maximum of 50 APs can be upgraded simultaneously in SFTP mode.

        The WAC can function as an SFTP server. Alternatively, use an external SFTP server, which is recommended.
        • When an external SFTP server is used, the maximum number of APs that can be upgraded simultaneously is the configured max-connect-number.

        • When a WAC is used as the SFTP server, a maximum of 15 APs can be upgraded simultaneously even if the configured max-connect-number is larger than 15.

          Before you configure the WAC as the SFTP server, run the ap update sftp-server max-connect-number max-connect-number ipv4 command to set the maximum number of APs that can be upgraded simultaneously. The value of max-connect-number is an integer ranging from 1 to 15. During the upgrade, a maximum of 1 to 15 APs can be upgraded at a time until all APs are upgraded.

          If max-connect-number is set larger than 15, an error message will be displayed after the first 15 APs are upgraded. The remaining APs cannot be automatically upgraded. You need to repeatedly run the command until all APs are upgraded.

          When the WAC is used as the SFTP server, if n VTY users have logged in, the maximum number of APs that can be upgraded simultaneously decreases by n – 1.

        • When IPv4 and IPv6 SFTP servers are both configured, set this parameter in both the two IP versions.

Verifying the Configuration

Run the display ap update configuration command to check the AP upgrade configuration.
