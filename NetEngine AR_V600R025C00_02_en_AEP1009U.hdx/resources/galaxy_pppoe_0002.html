Overview of PPPoE

Definition

PPP over Ethernet (PPPoE) is a link layer protocol that encapsulates Point-to-Point Protocol (PPP) frames into Ethernet frames. It enables multiple hosts on an Ethernet network to connect to a remote broadband access device.

Purpose

Using PPPoE, multiple hosts at a site can be connected to a remote access device that provides them with access control and accounting, with Ethernet providing the simple and cost-effective remote access function and PPP implementing identity authentication and accounting.

PPPoE allows a large number of hosts on an Ethernet network to connect to the Internet through a remote access device and controls each host. PPPoE can be used in various scenarios and provides high security as well as convenient accounting.
