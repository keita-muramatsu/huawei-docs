Maintaining Signature Database Update

Prerequisites

The signature database update-related configuration has been completed.

Procedure

  • Check whether the configuration for signature database update is correct.

    display update configuration

  • After the signature database is updated, check the running status of the ASE as well as signature database version information. Ensure that the signature database has been updated to the new version.

    display engine information
