Configuring IPv4 Application Identification on an Interface

Procedure

  1. Enter the system view.

    system-view

  2. Disable the bypass function for IPv4 traffic on the SA module.

    undo sa bypass

    By default, the bypass function is disabled for IPv4 traffic on the SA module.

  3. Enter the interface view.

    interface { interface-name | interface-type interface-number } 
undo portswitch

  4. Enable IPv4 application identification on the interface.

    sa enable

    To perform application identification for incoming IPv4 traffic on an interface, you must enable IPv4 application identification on the interface. Otherwise, the application identification configuration does not take effect, and the device cannot identify applications in IPv4 traffic.

  5. (Optional) Enable application traffic statistics collection on the interface.

    sa application-statistic enable

    To collect statistics on traffic entering an interface, you must enable application identification and application traffic statistics collection on the interface. Otherwise, the device cannot identify applications or collect statistics on application traffic.

  6. (Optional) Enable connection-based application traffic aggregation on the interface.

    sa aggregation-conn enable

    In SD-WAN scenarios, perform the following operations to aggregate connection-based application traffic on a tunnel interface so that traffic data can be reported through telemetry (if these operations are not performed, the device cannot identify applications based on connections or collect statistics on application traffic):

    • Run the sa enable command on the interface to enable application identification.
    • Run the tunnel-protocol sd-wan command to configure the SD-WAN tunnel encapsulation protocol.
    • Enable connection-based application traffic aggregation on the interface.

Follow-up Procedure

  • After enabling application identification on an interface, you need to reference applications in specific features so that service traffic can enter the application identification process. For details about how to reference applications in a specific feature, see the configuration guide of the feature.

    The Huawei Security Center (isecurity.huawei.com) provides the Application Identification file. With this file, you can check information about the predefined applications supported by a device, including the categories and descriptions. This information enables you to accurately reference applications in features.

    Run the display application [ pre-defined | name name ] command to check the name of the application to be referenced.

  • Run the display sa application-statistic { application application-name | top-n top-number | all } interface { interface-type interface-number | interface-name } [ inbound | outbound ] command to check application identification statistics on an interface.
  • Run the reset sa application-statistic { application application-name | all } interface { interface-type interface-number | interface-name } command to clear application identification statistics on an interface.
  • Run the display sa aggregation-conn statistics [ { { site site-id | connection connection-id } | application application-name } * ] command to check statistics about connection-based application traffic aggregation on an interface.
  • Run the display sa aggregation-conn session { all | { connection connection-id | application application-name } * } command to check session information about connection-based application traffic on an interface.
