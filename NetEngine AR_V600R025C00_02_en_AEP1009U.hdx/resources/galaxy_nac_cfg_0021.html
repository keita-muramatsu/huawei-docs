(Optional) Configuring Re-authentication for Online MAC Address Authentication Users

Context

If the administrator modifies parameters such as access rights and authorization attributes of an online user on the authentication server, the user needs to be re-authenticated to ensure user validity.

If re-authentication is configured for online MAC address authentication users, the device sends online users' authentication parameters that it has saved upon users' going online to the authentication server for re-authentication. If the authentication information of a user on the authentication server remains unchanged, the user remains online. If the information has been modified, the user is disconnected and needs to be re-authenticated.

MAC address authentication users who go online through VLANIF interfaces do not support re-authentication.

If the device is connected to a server for re-authentication and the server replies with a re-authentication reject message that disconnects an online user, it is recommended that you locate the cause of the re-authentication failure on the server or disable the re-authentication function on the device.

After periodic automatic re-authentication is configured, a large number of MAC address authentication logs will be generated.

The device re-authenticates MAC address authentication users using the following methods:
  • Re-authenticates the users periodically and automatically.
  • Re-authenticates a user with a specified MAC address.

Procedure

  • Configure periodic automatic re-authentication.
    1. Enter the system view.

      system-view

    2. Enter the MAC access profile view.

      mac-access-profile name access-profile-name

    3. Configure the device to re-authenticate online MAC address authentication users.

      mac-authen reauthenticate

      By default, the device does not re-authenticate online MAC address authentication users.

    4. (Optional) Configure the re-authentication period for online MAC address authentication users.

      mac-authen timer reauthenticate-period reauthenticate-period-value

      By default, the re-authentication period is 3600 seconds for online MAC address authentication users.

      • In most cases, the default re-authentication period is recommended. If many ACL rules need to be delivered during user authorization, to improve the device processing performance, you are advised to disable re-authentication or increase the re-authentication period.
      • When remote authentication and authorization are used, a short re-authentication period may lead to high CPU usage.
      • When many users need to be re-authenticated, to reduce the impact of re-authentication on the device performance, the actual re-authentication period may be longer than the configured re-authentication period.

  • Configure the device to re-authenticate a user once.
    1. Enter the system view.

      system-view

    2. Configure the device to re-authenticate a user with a specified MAC address once.

      mac-authen reauthenticate mac-address mac-address
