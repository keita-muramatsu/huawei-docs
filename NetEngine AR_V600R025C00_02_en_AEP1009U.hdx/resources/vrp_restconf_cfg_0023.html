Overview of Operation Methods

NETCONF defines configuration datastores and a set of Create, Retrieve, Update, Delete (CRUD) operations that can be used to access the datastores. It uses the YANG language to define the syntax and semantics of datastore content, configuration data, state data, RPC operations, and more.

RESTCONF uses HTTP methods to identify the CRUD operations defined in NETCONF for accessing YANG-defined data.

The following table describes the mappings between RESTCONF operations and NETCONF operations.
