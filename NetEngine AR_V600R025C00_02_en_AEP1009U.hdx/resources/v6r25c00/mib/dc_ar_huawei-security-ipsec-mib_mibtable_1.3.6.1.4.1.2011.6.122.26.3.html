hwIPSecTunnelStatsTable

This table specifies the status attributes for Huawei IPSec tunnel.

The indexes of the table are hwIPSecIfIndex,hwIPSecTunnelPolicyNum,hwIPSecTunnelIndex.

Creation Restriction

The entries in this table cannot be created.

Modification Restriction

No entry can be modified in this table.

Deletion Restriction

No entry can be deleted in this table.

Access Restriction

The row to which the device corresponds can be read in this table through an index only when the device has established IPSec tunnels. If the message "OID not increasing" is displayed during the Walk operation or the GetNext operation on hwIPSecTunnelStatsTable, disable the function of checking the ascending order of OIDs. If the NMS does not support this function, run the snmp-agent mib-view excluded v3view hwIPSecTunnelStatsTable command on the device to exclude this object.
