hwEntityStateTable

This table describes entity status, including the management status, operation status, backup status, alarm status, CPU usage and usage threshold, and memory usage and usage threshold.

The index of the table is entPhysicalIndex.

read-only

This object indicates the CPU usage of an entity. Generally, the overall CPU usage of the entity is calculated, without considering the number of CPUs on the entity.

This object indicates the CPU usage of an entity. Generally; the control-plane CPU usage of the entity is calculated; without considering the number of CPUs on the entity. read-write

The actually supported value range is 4..100

This object indicates the CPU usage threshold of an entity. When the CPU usage exceeds the threshold; a notification is sent. If there are multiple forwarding CPUs on a board; this object indicates the CPU usage threshold of the first forwarding CPU on the board.
