hwPMServerTable

After the performance statistics file is generated, the file is transmitted to the performance management server. The table is used to create a performance management server.

The index of the table is hwPMServerName.

Creation Restriction

A maximum of 32 servers used to save performance statistics files can be created. If the number exceeds the maximum number, the creation will fail.

Modification Restriction

The entries in this table can be modified.

Deletion Restriction

The entries in this table can be deleted.

Access Restriction

The entries in this table can be read.
