Functions Overview

The HUAWEI-PERFMGMT-MIB is used to provide performance management for NMS and record performance statistics and global statistics information. It provides the following functions: creating performance statistics task, managing statistics files upload, setting threshold alarm, querying current or historical statistics, resetting current statistics data, and querying global statistics.

For the performance statistics task, creation, modification, deletion, and query operation is supported. Statistic objects can be added to or delete from a statistic task. You can also configure the task name, statistic file type, sampling period, upload period, threshold switch, statistic file switch, and so on.

For file upload, you can configure the upload mode, retransmission times, target file server, and statistic files to be uploaded.

For threshold management, you can configure rules for the statistic objects.

For performance statistics, you can query historical and current statistics.

For global statistics, you can query detailed information about statistics period type, object type, and each index.
