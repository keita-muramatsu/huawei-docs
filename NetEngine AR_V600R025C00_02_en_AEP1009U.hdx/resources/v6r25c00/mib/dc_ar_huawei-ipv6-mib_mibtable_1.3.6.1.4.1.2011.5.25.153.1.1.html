hwIpv6IfTable

The IPv6 interfaces table contains information on the entity's internetwork-layer interfaces.

The index of the table is ipv6IfIndex.

Syntax

Max Access

Description

1.3.6.1.4.1.2011.5.25.153.1.1.1.1

hwIpv6IfDescr

OCTET STRING{(0,255)}

read-only

Interface name.

This object is implemented as defined in the corresponding MIB files.

1.3.6.1.4.1.2011.5.25.153.1.1.1.2

hwIpv6IfEnableFlag

INTEGER{enabled(1),disabled(2)}

read-write

This object identifies whether IPv6 is enabled on interface

or not. If IPv6 is enabled on interface, the value of

this object refers to 1,else refers to 2.

Some visual interfaces are readable but not writable; such as Virtual-Template interface.

Creation Restriction

The entries in this table cannot be created.

Modification Restriction

Only the leaf node hwIpv6IfEnableFlag can be modified.

Deletion Restriction

The entries in this table cannot be deleted.

Access Restriction

None.
