isisRouterTable

The set of hostnames and router ID.

The indexes of the table are isisSysInstance,isisRouterSysID,isisRouterLevel.

OID

Object

Syntax

Max Access

Description

Implemented Specifications

1.3.6.1.3.37.1.1.7.1.1

isisRouterSysID

OCTET STRING{(6,6)}

not-accessible

The System ID of the Router Peer.

This object is implemented as defined in the corresponding MIB files.

1.3.6.1.3.37.1.1.7.1.2

isisRouterLevel

INTEGER{none(0),area(1),domain(2)}

not-accessible

The level of this Intermediate System.

This object is implemented as defined in the corresponding MIB files.

1.3.6.1.3.37.1.1.7.1.3

isisRouterHostName

OCTET STRING{(0,255)}

read-only

The hostname listed in LSP, or NULL if none.

This object is implemented as defined in the corresponding MIB files.

1.3.6.1.3.37.1.1.7.1.4

isisRouterID

Unsigned32

read-only

The Router ID of the Peer found in LSP, or NULL if none.

This object is implemented as defined in the corresponding MIB files.
