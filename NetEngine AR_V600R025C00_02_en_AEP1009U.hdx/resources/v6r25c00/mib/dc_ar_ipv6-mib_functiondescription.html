Functions Overview

IPv6-MIB is defined in RFC 2465 to query and configure the IPv6 function. This MIB allows you to query IPv6 interface information, IPv6 statistics, IPv6 address prefixes, IPv6 address configurations, IPv6 routing tables, and MAC-IPv6 address mapping tables.
