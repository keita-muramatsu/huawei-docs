hwPatchStateTable

The statistics information of the patch area on each slot.

The index of the table is hwPatchSlotIndex.

OID

Object

Syntax

Max Access

Description

Implemented Specifications

1.3.6.1.4.1.2011.5.25.19.1.8.5.2.1.1

hwPatchNumMax

Unsigned32

read-only

The value of this object identifies the maximum number of patches.

At present; this object indicates the number of patched that have been loaded.
