hwNtpServiceSourceInterfaceVpnTable

The hwNtpServiceSourceInterfaceVpn table is used to specify the IPv4/IPv6 interface to send NTP messages with specified VPN. In case of no configuration for VPN, default VPN 0 will be considered.

In the unicast mode, if you want only one interface to receive the NTP response packets, specify NTP packets sent from all local interfaces to use the same source IP address.

In the broadcast and multicast modes, this command is invalid.

It is because the NTP service is enabled on the specified interface that actually is the source interface.

The indexes of the table are hwNtpServiceSourceInterfaceVpnName,hwNtpServiceSourceInterfaceVpnAddressType.

hwNtpServiceSourceInterfaceVpnAddressType

INTEGER{unknown(0),ipv4(1),ipv6(2),ipv4z(3),ipv6z(4),dns(16)}

not-accessible

The value of this object identifies the type of the source interface's IP address, that is, IPv4 or IPv6.

For IPv4 value is 1 and for IPv6 value is 2.

This object is implemented as defined in the corresponding MIB files.

hwNtpServiceSourceInterfaceVpnIfName

OCTET STRING{(1,63)}

read-write

Specifies the interface name used for sending out the packets.

If not configured, it will be wildcard.

This object is implemented as defined in the corresponding MIB files.

hwNtpServiceSourceInterfaceVpnRowStatus

INTEGER{active(1),notInService(2),notReady(3),createAndGo(4),createAndWait(5),destroy(6)}

read-create

Indicates the row status. It is used for the create, delete

and query operations. In the modify operation, this leaf is not set or issued.

Options:

1. createAndGo(4) -specified in the create operation

2. destroy(6) -specified in the delete operation

3. active(1) -always returned in the query operation

This object is implemented as defined in the corresponding MIB files.
