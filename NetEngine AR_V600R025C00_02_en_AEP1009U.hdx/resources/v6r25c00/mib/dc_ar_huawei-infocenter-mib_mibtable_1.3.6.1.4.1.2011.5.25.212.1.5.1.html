hwICLogFilterTable

The entries in this table can be created, modified, or deleted. The entries indicate that the log control status on the current channel. When the status of the log is off, the level control does not take effect.

The indexes of the table are hwICChannelIndex,IMPLIED hwICModuleName.

hwICLogFilterRowStatus

INTEGER{active(1),notInService(2),notReady(3),createAndGo(4),createAndWait(5),destroy(6)}

read-create

The status of this table entry.

The actually supported value range is active(1);createAndGo(4);destroy(6)

Creation Restriction

By default, this table has 10 default entries that correspond to the information output control of 10 channels. In this case, the module name is "default".

This table supports CreateAndGo only.

During entry creation in this table, you do not need to specify values for other objects except the index and row status. In this case, default values are assigned for those objects based on the default configurations of the channels.

Set operations on entries must comply with the SNMPv2 entry creation standard.

Modification Restriction

The entries in this table can be modified.

Deletion Restriction

However, if the alarm or debugging information about a module is inconsistent with the default configurations, deleting an entry restores log configurations to the default channel control information only.

Access Restriction

The entries in this table can be read.
