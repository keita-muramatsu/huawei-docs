hwSSHServerInfoTable

A table of configuration about the relation between the SSH server and the rsa peerkey.

The index of the table is hwSSHServerIndex.

Creation Restriction

An entry can be created in this table only when the row status is createAndGo, hwSSHServerIndex, hwSSHServerAssignKey, and hwSSHServerRowStatus are input, and an hwSSHServerAssignKey value already exists.

Modification Restriction

When the row status is Active, hwSSHServerAssignKey can be modified.

Deletion Restriction

The entries in this table can be deleted.

Access Restriction

The entries in this table can be read.
