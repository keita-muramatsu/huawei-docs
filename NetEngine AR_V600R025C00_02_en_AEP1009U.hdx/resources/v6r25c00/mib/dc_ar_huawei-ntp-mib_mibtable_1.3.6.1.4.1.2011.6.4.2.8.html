hwNtpMulticastClientTable

It is used for setting the local device to function as a multicast client.

When functioning as a multicast client, the local device listens for the NTP multicast packets sent by the server and synchronizes the local clock with the clock source.

The indexes of the table are hwNtpMulticastClientIfType,hwNtpMulticastClientIfNumber,hwNtpMulticastClientIp.

hwNtpMulticastClientIfType

INTEGER{loopback(1),vlanif(2)}

not-accessible

Indicates the interface type to configure NTP multicast client.

Options:

1. loopback(1) -indicates the loopback interface

2. vlanif(2) -indicates the VLAN interface

This object is implemented as defined in the corresponding MIB files.

1.3.6.1.4.1.2011.6.4.2.8.1.2

hwNtpMulticastClientIfNumber

Integer32{(0,2147483647)}

not-accessible

Indicates the interface ID to configure NTP multicast client. The interface ID and interface type (hwNtpMulticastClientIfType) together identify

the interface for receiving NTP multicast packets.

This object is implemented as defined in the corresponding MIB files.

1.3.6.1.4.1.2011.6.4.2.8.1.3

hwNtpMulticastClientIp

IpAddress

not-accessible

Indicates the IP address of the NTP multicast client. The IP address can only be a class-D address.

This object is implemented as defined in the corresponding MIB files.

1.3.6.1.4.1.2011.6.4.2.8.1.6

hwNtpMulticastClientRowStatus

INTEGER{active(1),notInService(2),notReady(3),createAndGo(4),createAndWait(5),destroy(6)}

read-create

Indicates the row status. It is used for the create, delete and query operations.

In the modify operation, this leaf is not set or issued.

Options:

1. createAndGo(4) -specified in the create operation

2. destroy(6) -specified in the delete operation

3. active(1) -always returned in the query operation

This object is implemented as defined in the corresponding MIB files.
