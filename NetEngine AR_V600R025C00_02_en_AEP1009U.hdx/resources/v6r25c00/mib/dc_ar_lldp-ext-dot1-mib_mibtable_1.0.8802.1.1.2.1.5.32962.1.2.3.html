lldpXdot1LocVlanNameTable

This table contains one or more rows per IEEE 802.1Q VLAN name information on the local system known to this agent.

The indexes of the table are lldpLocPortNum,lldpXdot1LocVlanId.

OID

Object

Syntax

Max Access

Implemented Specifications

1.0.8802.1.1.2.1.5.32962.1.2.3.1.1

lldpXdot1LocVlanId

Integer32{(1,4094)}

not-accessible

The integer value used to identify the IEEE 802.1Q

VLAN IDs with which the given port is compatible.

This object is implemented as defined in the corresponding MIB files.

1.0.8802.1.1.2.1.5.32962.1.2.3.1.2

lldpXdot1LocVlanName

OCTET STRING{(1,32)}

read-only

The string value used to identify VLAN name identified by the

Vlan Id associated with the given port on the local system.

This object should contain the value of the dot1QVLANStaticName

object (defined in IETF RFC 2674) identified with the given

lldpXdot1LocVlanId.

This object is implemented as defined in the corresponding MIB files.

Creation Restriction

The entries in this table cannot be created.

Modification Restriction

The entries in this table cannot be modified.

Deletion Restriction

The entries in this table cannot be deleted.

Access Restriction

The entries in this table can be read.
