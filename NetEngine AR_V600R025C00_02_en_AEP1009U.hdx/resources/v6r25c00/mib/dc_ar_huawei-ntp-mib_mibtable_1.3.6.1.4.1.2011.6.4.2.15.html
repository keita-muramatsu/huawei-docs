hwNtpUniServerTable

It is used for setting the NTP unicast server mode. This table provides a leaf for setting an IP address, which specifies a remote server to serve as the time server of the local device.

The indexes of the table are hwNtpUniServerVpnName,hwNtpUniServerAddressType,hwNtpUniServerAddress.

hwNtpUniServerAddressType

INTEGER{unknown(0),ipv4(1),ipv6(2),ipv4z(3),ipv6z(4),dns(16)}

not-accessible

The value of this object identifies the type of the remote server's IP address, that is, IPv4 or IPv6.

For IPv4 value is 1 and for IPv6 value is 2.

This object is implemented as defined in the corresponding MIB files.

hwNtpUniServerAddress

OCTET STRING{(0,255)}

not-accessible

Indicates the IP address of the remote server. The IP address is the address of the

host and cannot be a broadcast IP address, multicast IP address, IP address of the

clock source or IP address of an interface on the local device. (Supports both IPv4 and IPv6).

This object is implemented as defined in the corresponding MIB files.

1.3.6.1.4.1.2011.6.4.2.15.1.4

hwNtpUniServerVersion

Integer32{(1,4)}

read-write

Indicates the NTP protocol version.

Range: 1-4 for IPv4 server

4 for IPv6 server (IPv6 supports only version 4)

Default: 3 for IPv4 server

4 for IPv6 server

The protocol of a later version is compatible with an earlier version,

but an earlier version is not compatible with a later version.

This object is implemented as defined in the corresponding MIB files.

1.3.6.1.4.1.2011.6.4.2.15.1.5

hwNtpUniServerAuthKeyid

Unsigned32

read-write

Indicates the key ID used for sending packets to the remote server.

Range: 0-4294967295 for versions 1,2 and 3

Range: 0-65535 for version 4

0 indicates not configured.

The key ID identifies a key.

When the packets sent by the remote server need to be authenticated, you need

to set and issue this leaf.

This object is implemented as defined in the corresponding MIB files.

1.3.6.1.4.1.2011.6.4.2.15.1.6

hwNtpUniServerSourceIfType

INTEGER{tunnel(1),null(2),meth(3),vlanif(4),loopback(5),notConfigured(6),other(7)}

read-write

Indicates the interface type. It is recommended to set the source interface by leaf hwNtpUniServerSourceIfName.

Options:

1. tunnel(1) -indicates the tunnel interface

2. null(2) -indicates the NULL interface

3. meth(3) -indicates the MEth interface

4. vlanif(4) -indicates the VLAN interface

5. loopback(5) -indicates the loopback interface

6. notConfigured(6) -indicates that no source interface is configured

7. other(7) -indicates other interface which is not in the interface type and

interface number format or is not the type above

When this leaf is set to notConfigured(6), it indicates that no source interface is

configured in the case of the create operation, and that the source interface

is deleted in the case of the modify operation. When this leaf value is other(7), leaf hwNtpUniServerSourceIfName can be used

to indicates the source interface.

This object is implemented as defined in the corresponding MIB files.

1.3.6.1.4.1.2011.6.4.2.15.1.7

hwNtpUniServerSourceIfNumber

Integer32{(0,2147483647)}

read-write

Indicates the interface ID. The interface ID and interface type (hwNtpUniServerSourceIfType) together

identify the source interface for sending NTP unicast packets.

When the interface type (hwNtpUniServerSourceIfType) value is notConfigured(6) or other(7), this leaf value is 0.

This object is implemented as defined in the corresponding MIB files.

1.3.6.1.4.1.2011.6.4.2.15.1.8

hwNtpUniServerPreference

INTEGER{enable(1),disable(2)}

read-write

Indicates the server is the preferred server.

Options:

1. enable(1) -indicates that the server is preferred.

2. disable(2) -indicates that the server is not preferred.

Default: disable(2)

When multiple servers exist at the same stratum, the specified server is preferred

for synchronization.

This object is implemented as defined in the corresponding MIB files.

INTEGER{active(1),notInService(2),notReady(3),createAndGo(4),createAndWait(5),destroy(6)}

read-create

In the modify operation, this leaf is not set or issued.

3. active(1) -always returned in the query operation
