icmpMsgStatsTable

The table of system-wide per-version, per-message type ICMP counters.

The indexes of the table are icmpMsgStatsIPVersion,icmpMsgStatsType.

OID

Object

Syntax

Max Access

Description

Implemented Specifications

1.3.6.1.2.1.5.30.1.1

icmpMsgStatsIPVersion

INTEGER{unknown(0),ipv4(1),ipv6(2)}

not-accessible

The IP version of the statistics.

This object is implemented as defined in the corresponding MIB files.

1.3.6.1.2.1.5.30.1.2

icmpMsgStatsType

Integer32{(0,255)}

not-accessible

The ICMP type field of the message type being counted by

this row.

Note that ICMP message types are scoped by the address type

in use.

This object is implemented as defined in the corresponding MIB files.

1.3.6.1.2.1.5.30.1.3

icmpMsgStatsInPkts

Counter32

read-only

The number of input packets for this AF and type.

This object is implemented as defined in the corresponding MIB files.

1.3.6.1.2.1.5.30.1.4

icmpMsgStatsOutPkts

Counter32

read-only

The number of output packets for this AF and type.

This object is implemented as defined in the corresponding MIB files.

Creation Restriction

The entries in this table cannot be created.

Modification Restriction

The entries in this table cannot be modified.

Deletion Restriction

The entries in this table cannot be deleted.

Access Restriction

The entries in this table can be read.
