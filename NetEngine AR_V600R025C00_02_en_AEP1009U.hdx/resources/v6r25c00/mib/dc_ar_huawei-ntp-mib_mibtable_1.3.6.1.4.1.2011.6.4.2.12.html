hwNtpInInterfaceTable

It is used for enabling or disabling the NTP packet reception capability of an interface.

The indexes of the table are hwNtpInInterfaceType,hwNtpInInterfaceIfNumber.

OID

Object

Syntax

Max Access

Description

Implemented Specifications

1.3.6.1.4.1.2011.6.4.2.12.1.1

hwNtpInInterfaceType

INTEGER{invalid(0),loopback(1),vlanif(2)}

not-accessible

Indicates the interface type of the ingress interface.

Options:

1. invalid(0) -indicates the Invalid interface

2. loopback(1) -indicates the loopback interface

3. vlanif(2) -indicates the VLAN interface

This object is implemented as defined in the corresponding MIB files.

1.3.6.1.4.1.2011.6.4.2.12.1.2

hwNtpInInterfaceIfNumber

Integer32{(0,2147483647)}

not-accessible

Indicates the interface number of the ingress interface. The interface ID and interface type (hwNtpInInterfaceType) together identify the

interface for enabling or disabling NTP packets reception.

This object is implemented as defined in the corresponding MIB files.

1.3.6.1.4.1.2011.6.4.2.12.1.6

hwNtpInInterfaceAdminStatus

INTEGER{enabled(1),disabled(2)}

read-write

Enables or disables an ingress interface.

Options:

1. enabled(1) -indicates that the NTP IPv4 packet reception capability is enabled

2. disabled(2) -indicates that the NTP IPv4 packet reception capability is disabled

Default: enabled(1)

In the walk operation, only the disabled interfaces are displayed.

This object is implemented as defined in the corresponding MIB files.

1.3.6.1.4.1.2011.6.4.2.12.1.7

hwNtpInInterfaceAdminIPv6Status

INTEGER{enabled(1),disabled(2)}

read-write

Enables or disables an ingress interface.

Options:

1. enabled(1) -indicates that the NTP IPv6 packet reception capability is enabled

2. disabled(2) -indicates that the NTP IPv6 packet reception capability is disabled

Default: enabled(1)

In the walk operation, only the disabled interfaces are displayed.

This object is implemented as defined in the corresponding MIB files.
