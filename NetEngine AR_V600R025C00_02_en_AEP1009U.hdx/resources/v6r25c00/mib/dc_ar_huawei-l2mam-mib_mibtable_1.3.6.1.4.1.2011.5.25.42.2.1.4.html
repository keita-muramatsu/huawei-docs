hwMacLimitTable

A table containing the mac-address learning-limit rule information for device.

It can limit on ethernet interface,vlan,ethernet interface + vlan.

The indexes of the table are hwMacLimitPort,hwMacLimitVlanId,hwMacLimitVsiName.

hwMacLimitMaxMac

Integer32{(0,131072)}

read-create

The maximum mac address. When the value is '0',

the meaning is that there isn't limiting rule to

the mac-address number.

The actually supported access is accessible-for-notify

Creation Restriction

The entries in this table cannot be created.

Modification Restriction

The entries in this table cannot be modified.

Deletion Restriction

The entries in this table cannot be deleted.

Access Restriction

The entries in this table cannot be read.
