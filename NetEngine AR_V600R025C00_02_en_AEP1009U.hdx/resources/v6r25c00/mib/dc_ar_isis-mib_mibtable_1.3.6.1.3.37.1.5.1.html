isisSystemCounterTable

System wide counters for one instance of the IS-IS protocol on the system.

The indexes of the table are isisSysInstance,isisSysStatLevel.

OID

Object

Syntax

Max Access

Description

Implemented Specifications

1.3.6.1.3.37.1.5.1.1.1

isisSysStatLevel

INTEGER{level1IS(1),level2IS(2)}

not-accessible

The level that this entry describes.

This object is implemented as defined in the corresponding MIB files.

read-only

are silently dropped and not counted.
