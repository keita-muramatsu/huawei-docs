hwMstpInstanceTable

This table describes the attribute value, description, and operation restriction of configurable attributes of the MSTI.

The index of the table is hwMstpInstanceID.

hwMstpiRowStatus

INTEGER{active(1),notInService(2),notReady(3),createAndGo(4),createAndWait(5),destroy(6)}

read-create

This object indicates the row status of the MSTI table.

The value can be:

1: active

3: not ready

4: createAndGo

5: createAndGo

6: destroy

This object is implemented as defined in the corresponding MIB files.

Creation Restriction

The entries in this table can be created.

Modification Restriction

hwMstpiBridgePriority can be modified only when the value of hwMstpiRootType is normal (0). The modification of hwMstpiAdminMappedVlanListLow and hwMstpiAdminMappedVlanListHigh has impact on the value of hwMstpAdminMstpID of the VLAN in hwMstpVIDAllocationTable. After the active-region-configuration command is run in the mst-region mode, the MSTI configured in the VLAN becomes effective, and the value of hwMstpOperMstpID in hwMstpVIDAllocationTable changes into the corresponding value.

Deletion Restriction

To delete an instance ID, run the active region-configuration command in the mst-region mode.

Access Restriction

If no other MSTI is configured, this table accesses related information about the default MSTI0. To access the information about a new MSTI, run the active region-configuration command in the mst-region mode.
