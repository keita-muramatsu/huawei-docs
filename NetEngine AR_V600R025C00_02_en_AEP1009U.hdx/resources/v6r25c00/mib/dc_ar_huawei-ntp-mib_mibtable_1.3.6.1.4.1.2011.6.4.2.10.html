hwNtpBroadcastClientTable

It is used for setting the NTP broadcast client mode. When set to the broadcast client mode, the local device listens for NTP broadcast packets and synchronizes the local clock according to the received broadcast packets.

The indexes of the table are hwNtpBroadcastClientIfType,hwNtpBroadcastClientIfNumber.

hwNtpBroadcastClientIfType

INTEGER{loopback(1),vlanif(2)}

not-accessible

Indicates the interface type to configure NTP broadcast client.

Options:

1. loopback(1) -indicates the loopback interface

2. vlanif(2) -indicates the VLAN interface

This object is implemented as defined in the corresponding MIB files.

1.3.6.1.4.1.2011.6.4.2.10.1.2

hwNtpBroadcastClientIfNumber

Integer32{(0,2147483647)}

not-accessible

Indicates the interface ID to configure NTP broadcast client. The interface ID and interface type (hwNtpBroadcastClientIfType) together

identify the interface for receiving broadcast packets.

This object is implemented as defined in the corresponding MIB files.

hwNtpBroadcastClientRowStatus

INTEGER{active(1),notInService(2),notReady(3),createAndGo(4),createAndWait(5),destroy(6)}

read-create

Indicates the row status. It is used for the create, delete and query operations.

In the modify operation, this leaf is not set or issued.

Options:

1. createAndGo(4) -specified in the create operation

2. destroy(6) -specified in the delete operation

3. active(1) -always returned in the query operation

This object is implemented as defined in the corresponding MIB files.
