lldpLocPortTable

This table contains one or more rows per port information associated with the local system known to this agent.

The index of the table is lldpLocPortNum.

OID

Object

Syntax

Max Access

Description

Implemented Specifications

1.0.8802.1.1.2.1.3.7.1.1

lldpLocPortNum

Integer32{(1,4096)}

not-accessible

The index value used to identify the port component

(contained in the local chassis with the LLDP agent)

associated with this entry.

The value of this object is used as a port index to the

lldpLocPortTable.

This object is implemented as defined in the corresponding MIB files.

1.0.8802.1.1.2.1.3.7.1.2

lldpLocPortIdSubtype

INTEGER{interfaceAlias(1),portComponent(2),macAddress(3),networkAddress(4),interfaceName(5),agentCircuitId(6),local(7)}

read-only

The type of port identifier encoding used in the associated

'lldpLocPortId' object.

This object is implemented as defined in the corresponding MIB files.

1.0.8802.1.1.2.1.3.7.1.3

lldpLocPortId

OCTET STRING{(1,255)}

read-only

The string value used to identify the port component

associated with a given port in the local system.

This object is implemented as defined in the corresponding MIB files.

1.0.8802.1.1.2.1.3.7.1.4

lldpLocPortDesc

OCTET STRING{(0,255)}

read-only

The string value used to identify the IEEE 802 LAN station's port

description associated with the local system. If the local

agent supports IETF RFC 2863, lldpLocPortDesc object should

have the same value of ifDescr object.

This object is implemented as defined in the corresponding MIB files.

Creation Restriction

The entries in this table cannot be created.

Modification Restriction

The entries in this table cannot be modified.

Deletion Restriction

The entries in this table cannot be deleted.

Access Restriction

The entries in this table can be read.
