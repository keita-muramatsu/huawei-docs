lldpXdot1ConfigPortVlanTable

A table that controls selection of LLDP Port VLAN-ID TLVs to be transmitted on individual ports.

OID

Object

Syntax

Max Access

Description

Implemented Specifications

1.0.8802.1.1.2.1.5.32962.1.1.1.1.1

lldpXdot1ConfigPortVlanTxEnable

INTEGER{true(1),false(2)}

read-write

The lldpXdot1ConfigPortVlanTxEnable, which is defined as

a truth value and configured by the network management,

determines whether the IEEE 802.1 organizationally defined

port VLAN TLV transmission is allowed on a given LLDP

transmission capable port.

The value of this object must be restored from non-volatile

storage after a re-initialization of the management system.

This object is implemented as defined in the corresponding MIB files.

Creation Restriction

The entries in this table cannot be created.

Modification Restriction

The entries in this table can be modified.

Deletion Restriction

The entries in this table cannot be deleted.

Access Restriction

The entries in this table can be read.
