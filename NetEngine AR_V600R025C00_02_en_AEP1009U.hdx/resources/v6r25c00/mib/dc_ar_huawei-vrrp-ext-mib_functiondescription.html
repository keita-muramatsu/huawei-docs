Functions Overview

This MIB is defined by Huawei. The MIB provides the GET and SET operations on the information about VRRP tracking BFD, tracked interface, Admin-VRRP, and binding.

The updated MIB is used to enable the VRRP SS function, set the VRRP SS timer, and enable the capability of learning the interval for sending VRRP Hello packets.
