hwBgpPeerSessionExtTable

BGP Peer Session Table.

This table contains BGP peer session informations.

The indexes of the table are hwBgpPeerSessionExtVrfId,hwBgpPeerSessionExtRemoteAddrType,hwBgpPeerSessionExtRemoteAddr.

OID

Object

Syntax

Max Access

Description

Implemented Specifications

hwBgpPeerSessionExtVrfId

Unsigned32

not-accessible

The VPN instance Id of the remote BGP peer.

This object is implemented as defined in the corresponding MIB files.
