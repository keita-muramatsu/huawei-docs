hwSSHServerSessionTable

The object shows current session information of the SSH server which includes username, version information, retry times of online users currently.

The index of the table is hwSSHSessionIndex.

hwSSHSessionKeyType

INTEGER{keyTypeRSA(1),keyTypeDSA(2),keyTypeECC(3),keyTypeSM2(5),keyTypePKI(6),keyTypeRSASHA256(7),keyTypeRSASHA512(8),keyTypeED25519(9),keyTypeX509V3RSA2048SHA256(10),keyTypeX509V3ECDSASHA2(11),keyTypeSM2SM3(12)}

read-only

The object specifies the public key type of SSH session.

Options:

1.keyTypeRSA(1) -The public key type of SSH session is RSA.

2.keyTypeDSA(2) -The public key type of SSH session is DSA.

3.keyTypeECC(3) -The public key type of SSH session is ECC.

4.keyTypeSM2(5) -The public key type of SSH session is SM2.

5.keyTypePKI(6) -The public key type of SSH session is PKI.

6.keyTypeRSASHA256(7) -The public key type of SSH session is RSA_SHA2_256.

7.keyTypeRSASHA512(8) -The public key type of SSH session is RSA_SHA2_512.

8.keyTypeED25519(9) -The public key type of SSH session is ED25519.

9.keyTypeX509V3RSA2048SHA256(10) - The public key type of SSH session is X509V3_RSA2048_SHA256.

10.keyTypeX509V3ECDSASHA2(11) - The public key type of SSH session is X509V3_ECDSA_SHA2.

11.keyTypeSM2SM3(12) - The public key type of SSH session is SM2_SM3.

The actually supported value range is keyTypeRSA(1);keyTypeDSA(2);keyTypeECC(3);keyTypeSM2(5);keyTypePKI(6);keyTypeRSASHA256(7);keyTypeRSASHA512(8);keytypex509v3rsa2048sha256(10);keyTypeX509V3ECDSASHA2(11);keyTypeSM2SM3(12)
