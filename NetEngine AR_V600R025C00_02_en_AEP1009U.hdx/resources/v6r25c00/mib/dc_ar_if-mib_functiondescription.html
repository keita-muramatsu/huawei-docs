Functions Overview

This MIB describe the general table for network interface layer. It's a upgraded version of ifTable which defined in MIB-II, it is also a specification of RFC1573 extensions.

IF-MIB includes a bundle of configuration objects which are used for general interface management by network devices. These configuration objects are suitable for all kinds of network interface regardless of physical media and which protocol these interfaces use.

IF-MIB also defined some configuration objects which are used for special media and lower protocols(subnet layer or any more lower layers).

NMS can get statistical informations and set network features by this MIB.
