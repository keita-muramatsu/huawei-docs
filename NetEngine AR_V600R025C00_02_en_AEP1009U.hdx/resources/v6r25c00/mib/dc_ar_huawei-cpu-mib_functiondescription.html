Functions Overview

Each board needs one CPU to undertake all tasks.

CPU usage shows the consumption of the CPU resources during a specific period. CPU usage is calculated by using the following formula: CPU usage = (Total time - Idle time)/Total time

Idle time refers to the time when the CPU undertakes the idle task. The idle task is of a low priority and does not process any specific events. If the idle task can be scheduled, the CPU is considered idle.

In addition to the total CPU usage, you can collect statistics about CPU usage of each task. CPU usage of a task = Task duration/Total time
