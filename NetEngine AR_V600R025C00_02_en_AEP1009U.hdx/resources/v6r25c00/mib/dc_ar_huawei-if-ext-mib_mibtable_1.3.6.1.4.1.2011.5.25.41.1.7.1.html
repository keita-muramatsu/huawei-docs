1.3.6.1.4.1.2011.5.25.41.1.7.1.1.29

hwIfMonitorAllStatistics

Unsigned32

read-only

All statistics value

When the CRC rising alarm or the CRC alarm is cleared; this object indicates the total number of packets collected during the CRC interval.The value of this object keeps updating. Clearing statistics on all interfaces does not clear the value.

Creation Restriction

The entries in this table cannot be created.

Modification Restriction

Only hwIfMonitorCrcErrorThreshold and hwIfMonitorCrcErrorInterval can be modified.

Deletion Restriction

The entries in this table cannot be deleted.

Access Restriction

The entries in this table can be read.
