isisPacketCounterTable

Information about IS-IS protocol traffic at one level on one circuit in one direction

The indexes of the table are isisSysInstance,isisCircIndex,isisPacketCountLevel,isisPacketCountDirection.

OID

Object

Syntax

Max Access

Description

Implemented Specifications

1.3.6.1.3.37.1.5.3.1.1

isisPacketCountLevel

INTEGER{level1(1),level2(2)}

not-accessible

The level at which these PDU counts have been collected.

This object is implemented as defined in the corresponding MIB files.

1.3.6.1.3.37.1.5.3.1.2

isisPacketCountDirection

INTEGER{sending(1),receiving(2)}

not-accessible

Were we sending or receiving these PDUs?

This object is implemented as defined in the corresponding MIB files.

1.3.6.1.3.37.1.5.3.1.3

isisPacketCountIIHello

Counter32

read-only

The number of IS-IS Hello PDUs seen in this

direction at this level.

Point-to-Point IIH PDUs are counted at

Level 1 if the value of their Circuit Type

field is 1, and are counted at Level 2 otherwise.

This object is implemented as defined in the corresponding MIB files.

1.3.6.1.3.37.1.5.3.1.4

isisPacketCountISHello

Counter32

read-only

The number of ES-IS Hello PDUs seen in this

direction. ISH PDUs are counted at the

lowest enabled level: at L1 on L1 or L1L2

circuits, and at L2 otherwise.

This object is implemented as defined in the corresponding MIB files.

1.3.6.1.3.37.1.5.3.1.5

isisPacketCountESHello

Counter32

read-only

The number of ES Hello PDUs seen in this

direction. ESH PDUs are counted at the

lowest enabled level: at L1 on L1 or L1L2

circuits, and at L2 otherwise.

This object is implemented as defined in the corresponding MIB files.
