prefix-delegation

Function

The prefix-delegation command configures a delegated prefix in the address pool view.

The undo prefix-delegation command deletes the delegated prefix in the address pool view.

By default, no IPv6 delegated prefix is configured in the address pool view.

Format

prefix-delegation ipv6-prefix/ipv6-prefix-length assign-prefix-length [ life-time { valid-lifetime | infinite } { preferred-lifetime | infinite } ] [ lock ]

undo prefix-delegation ipv6-prefix/ipv6-prefix-length assign-prefix-length [ life-time { valid-lifetime | infinite } { preferred-lifetime | infinite } ] [ lock ]

undo prefix-delegation ipv6-prefix/ipv6-prefix-length

Parameters

Parameter Description Value
ipv6-prefix/ipv6-prefix-length

Specifies the address prefix bound to an IPv6 address pool and its length.

The value is a 32-digit hexadecimal number, in the format X:X::X:X/M.

The prefix length ranges from 1 to 128.
assign-prefix-length

Specifies the default prefix length.

The value is an integer ranging from 1 to 128. The value of assign-prefix-length must be greater than or equal to the value of ipv6-prefix-length, and the difference between them must be less than or equal to 16.
life-time

Indicates the lifetime of the address prefix bound to an IPv6 address pool.

-
valid-lifetime | infinite

Specifies the valid lifetime.

The valid lifetime can be set to infinite. If the preferred lifetime is set to infinite, the valid lifetime must be set to infinite.

The value ranges from 60 to 172799999, in seconds. The default value is 172800 seconds (two days).
preferred-lifetime | infinite

Specifies the preferred lifetime. The preferred lifetime cannot exceed the valid lifetime.

The preferred lifetime can be set to infinite. If the preferred lifetime is set to infinite, the valid lifetime must be set to infinite.

The value ranges from 60 to 172799999, in seconds. The default value is 86400 seconds (one day).
lock

Locks the address prefix.

-

Views

DHCP IPv6 address pool view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When the device functions as a DHCPv6 PD server, run this command to bind an IPv6 address prefix to an IPv6 address pool. The device can assign an appropriate IPv6 address prefix to a DHCPv6 PD client. The DHCPv6 PD client automatically subnets the delegated prefix into prefixes and assigns the prefixes to the links attached to hosts through RA messages. This implements automatic configuration of IPv6 addresses for hosts and hierarchical prefix delegation.

Precautions

Idle addresses or prefixes are assigned to DHCPv6 clients from the IPv6 address pool. Reserved addresses, conflicted addresses, and used addresses cannot be assigned to DHCPv6 clients. Reserved addresses include unspecified addresses, multicast addresses, loopback addresses, link-local addresses, NSAP addresses, and anycast addresses (defined in RFC 2526).

?All delegated prefixes cannot overlap.

?All delegated prefixes cannot overlap with the address prefix.

?All delegated prefixes cannot overlap with the prefix that is statically specified by a certain user.

?Deleting a prefix pool clears all prefix leases assigned from the prefix pool.

?Only one delegated prefix can be configured for an address pool.

Deleting a delegated prefix may cause the allocated client address information to be deleted or the DHCPv6 PD client to fail to renew the lease.

Example

# Configure the delegated prefix fc00:1::/30 for the DHCPv6 server address pool pool1, and set the prefix length to 42 and the lifetime to infinite. 
<HUAWEI> system-view
[HUAWEI] dhcpv6 pool pool1
[HUAWEI-dhcpv6-pool-pool1] prefix-delegation fc00:1::/30 42 life-time infinite infinite
