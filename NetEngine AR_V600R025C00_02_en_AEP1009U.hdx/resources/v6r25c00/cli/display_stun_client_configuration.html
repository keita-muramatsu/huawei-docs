display stun client configuration

Function

The display stun client configuration command displays the STUN client configuration.

Format

display stun client configuration

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run this command to view the STUN client configuration, such as the STUN server IP address, destination port number and VPN instance for the STUN client to access the STUN server, and whether authentication is enabled on the STUN client.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the STUN client configuration.
<HUAWEI> display stun client configuration
 STUN Client Configuration:
--------------------------------------------------------------
  Peer IP             : 1.1.1.1
  VPN-instance           : -
--------------------------------------------------------------
  Peer IP             : 1.1.1.2
  VPN-instance           : vpna
--------------------------------------------------------------
  Source-Port              : 4500
--------------------------------------------------------------
  Destination-Port         : 3478
--------------------------------------------------------------
  Authentication-mode Status    : Disable
--------------------------------------------------------------
Table 1 Description of the display stun client configuration command output
Item Description
STUN Client Configuration

STUN client configuration.
Peer IP

IP address of the STUN server.
VPN-instance

VPN instance used by the STUN client to access the STUN server.
Source-Port

Source port number of the STUN client.
Destination-Port

Destination port number for the STUN client to access the STUN server.
Authentication-mode Status

Whether authentication is enabled.

  • Disable.
  • Enable.

You can run the authentication-mode command to set this parameter.
