display adaptive-qos status

Function

The display adaptive-qos status command displays the current bandwidth of adaptive QoS.

This command is supported only on the AR8700 series, AR8100 series and AR6700-H series.

Format

display adaptive-qos status connection { connection-id | all }

Parameters

Parameter Description Value
all

Indicates all connections.

-
connection connection-id

Specifies a connection ID.

The value is an integer in the range from 1 to 4294967295.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

This command displays bandwidth information after adaptive QoS adjustment, improving maintainability.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the adaptive QoS bandwidth status.
<HUAWEI> display adaptive-qos status connection all
