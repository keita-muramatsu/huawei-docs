route loop-detect isis enable

Function

The route loop-detect isis enable command enables loop detection for routes imported into IS-IS.

The undo route loop-detect isis enable command disables loop detection for routes imported into IS-IS.

By default, loop detection is disabled for the routes imported into IS-IS.

Format

route loop-detect isis enable [ alarm-only ]

undo route loop-detect isis enable [ alarm-only ]

Parameters

Parameter Description Value
alarm-only

Indicates that only a loop alarm is reported and the cost of the looped route is not changed.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When an IS-IS process imports routes, routing loops may occur. To enable routing loop detection for routes imported to IS-IS, run the route loop-detect isis enable command. When a device detects that it imports a route advertised by itself, it advertises this route with a large cost to other devices. After learning the route, these devices preferentially select other paths, thereby preventing routing loops.

If alarm-only is configured, the device does not advertise a large link cost when detecting that it has imported a route advertised by itself. Instead, the device reports a loop detection alarm. If the cost is changed, traffic forwarding paths may change accordingly. If the network that has rigid requirements on the traffic forwarding paths, you can configure alarm-only to prevent cost changes. After alarm-only is configured, the cost is not increased. To prevent routing loops in this case, you need to properly plan configurations when handling related alarms.

Precautions

  • Before enabling loop detection, check whether non-Huawei devices exist on the network and ensure that IS-IS services are not affected when non-Huawei devices receive LSPs and private TLVs advertised by IS-IS.
  1. If the non-Huawei device cannot identify the TLV or sub-TLV carried in the packet, ensure that the non-Huawei device ignores the TLV or sub-TLV without affecting the processing of other TLVs.
  2. If the non-Huawei device uses the same private TLV type and the TLV values of the two functions conflict, do not configure this function.
  • After a routing loop is removed, the device cannot automatically exit the routing loop state or clear the alarm. Manual intervention is required. For example, after a route-policy or route tag is correctly configured, run the clear route loop-detect isis alarm-state command to exit the loop state and clear the alarm.
  • A single process supports routing loop detection for a maximum of 2000 imported routes. If more than 2000 routes are imported, routing loop detection is automatically disabled. The system checks the number of imported routes in the early morning every day. If the number of imported routes is less than 2000, the system automatically restores the loop routing detection function.
  • Summary routes and default routes do not support routing loop detection.
  • Routing loop detection is supported in the scenario where two IS-IS domains import routes from each other. If there are more than two IS-IS domains, routing loops cannot be detected.
  • After a routing loop is detected during route import between IS-IS processes, if the original route is withdrawn, a routing loop occurs. IS-IS then reports a routing loop alarm, but the loop cannot be removed. Manual intervention is required.
  • If the system IDs of the devices configured with IS-IS route import conflict in two IS-IS domains, a false routing loop alarm may be reported.
  • If the apply cost command is run in a route-policy when a large cost is advertised upon loop detection, this command does not take effect.
  • If an IS-IS process that imports routes also calculates routes with the same prefix and the latter routes and the routes imported to IS-IS work in load balancing mode across processes, routing loops cannot be detected.
  • If the alarm-only parameter is configured, loop self-healing is not supported.

Example

# Enable loop detection.
<HUAWEI> system-view
[HUAWEI] route loop-detect isis enable
