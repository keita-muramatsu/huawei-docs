display ip address-set

Function

The display ip address-set address command displays information about the address object or address group that contains a specified IPv4 address.

Format

display ip address-set { all | type { object | group } } [ slot slot-id cpu cpu-id ]

display ip address-set verbose address-set-name item [ slot slot-id cpu cpu-id ]

display ip address-set address ipv4-address

display ip address-set verbose address-set-name reference

Parameters

Parameter Description Value
all

Displays information about all address objects or address groups.

-
type

Specifies whether to view information about an address object or address group.

-
object

Displays information about all address objects.

-
group

Displays information about all address groups.

-
slot slot-id

Indicates the slot ID.

The value is an integer ranging from 0 to 16.
cpu cpu-id

Indicates the CPU ID.

The value is an integer ranging from 0 to 8.
address-set-name

Specifies a description of an address object or address group.

It must be the name of an existing address set.
item

Displays information about members of an address object or address group.

-
ipv4-address

Displays information about the address object or address group that contains a specified IPv4 address.

The value is in dotted decimal notation.
reference

Displays the reference information about the address object or address group.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To check the configuration of address objects or address groups, run the display ip address-set command.
