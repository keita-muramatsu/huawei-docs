display nqa results (NQA view)

Function

The display nqa results this command displays NQA test result statistics in a specified NQA test instance view.

Format

display nqa results [ this ]

Parameters

Parameter Description Value
this

Display result statistics of the current instance.

-

Views

NQA view

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

NQA test instances monitor the network operating status, output statistics, and effectively help reduce costs. NQA measures performance of various protocols on the network, allowing carriers to collect network operation indexes in real time.

The display nqa results this command can be used to query the test result of a specified NQA test instance in the corresponding test view. This allows you to learn information the test instance more comprehensively.

Prerequisites

NQA test instances are configured.

Precautions

The software jitter (the hardware-based enable command not configured) supports ms-level precision. The hardware jitter (the hardware-based enable command configured) supports ms- or µs-level precision, depending on the board capability.
