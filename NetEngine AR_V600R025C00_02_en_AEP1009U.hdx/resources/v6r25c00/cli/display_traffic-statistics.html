display traffic-statistics

Function

The display traffic-statistics command displays traffic statistics on an interface.

Format

display traffic-statistics interface { interface-type interface-number | interface-name } { inbound | outbound } [ rule-base ]

Parameters

Parameter Description Value
inbound

Displays packet statistics on the inbound interface.

-
outbound

Displays packet statistics on the outbound interface.

-
rule-base

Displays packet statistics based on rules.

-
interface interface-type interface-number

Displays packet statistics on a specified interface:

  • interface-type specifies the interface type.
  • interface-number specifies the interface number.

-
interface interface-name

Displays packet statistics on a specified interface. interface-name specifies the name of an interface.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

After ACL-based traffic statistics collection is configured on an interface, you can run the display traffic-statistics command to view packet statistics on the interface. When the traffic-statistics decap-process enable command is configured on a tunnel interface, statistics about GRE inner packets are queried.

Precautions

An ACL has been created, and the traffic-statistics command has been run on the interface to enable traffic statistics collection. For ACL rules, the number of packets matching the deny rule is not counted in the total number of packets, but the number of packets matching the permit rule is counted in the total number of packets.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display traffic statistics on an interface.
<HUAWEI> display traffic-statistics interface 10GE 0/0/1 inbound rule-base
-----------------------------------------------------------
*interface 10GE0/0/1              inbound IPv4 ACL 3000
Total Permit Matched: 5(Packets)
Total Deny   Matched: 0(Packets)
rule 5     Matched Packet   0(Packets)
rule 10    Matched Packet   5(Packets)
*interface 10GE0/0/1              inbound IPv6 ACL test
Total Permit Matched: 5(Packets)
Total Deny   Matched: 0(Packets)
rule 5     Matched Packet   5(Packets)
[HUAWEI] display traffic-statistics interface 10GE 0/0/1 outbound
-----------------------------------------------------------
*interface 10GE0/0/1              outbound IPv4 ACL 3001
Total Permit Matched: 5(Packets)
Total Deny   Matched: 0(Packets)
Table 1 Description of the display traffic-statistics command output
Item Description
Total Permit Matched

Total number of packets matching the ACL permit rule.
Total Deny Matched

Total number of packets that match the ACL deny rule.
Matched Packet

Number of packets matching rules.
