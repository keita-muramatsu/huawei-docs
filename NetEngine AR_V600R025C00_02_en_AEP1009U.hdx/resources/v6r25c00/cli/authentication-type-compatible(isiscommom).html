authentication-type-compatible

Function

The authentication-type-compatible command sets a compatible value of an IS-IS authentication type.

The undo authentication-type-compatible command cancels the configuration of the compatible value of an IS-IS authentication type.

By default, no compatible value is configured for an IS-IS authentication type.

Format

authentication-type-compatible hmac-sm3 auth-type-value

undo authentication-type-compatible hmac-sm3 [ auth-type-value ]

Parameters

Parameter Description Value
auth-type-value

Specifies the compatible value of an authentication type.

The value is 4.
hmac-sm3

Sets the encryption algorithm to HMAC-SM3.

-

Views

IS-IS view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In a scenario where a Huawei device interworks with a non-Huawei device, if the default values of the authentication type corresponding to the same authentication encryption algorithm on the two devices are different, IS-IS authentication fails. As a result, the two devices fail to establish a neighbor relationship or exchange packets. To prevent this problem, you can configure the same authentication type value for the two devices so that the they can implement IS-IS authentication normally and communicate with each other.

Precautions

The two ends that establish an IS-IS neighbor relationship must be configured with the same authentication type value. Otherwise, the neighbor relationship is interrupted even if the authentication encryption algorithms are the same.

Currently, the HMAC-SM3 encryption algorithm can be configured only in a keychain. The HMAC-SM3 encryption algorithm cannot be directly configured for IS-IS authentication.

Configuring a compatible value for an IS-IS authentication type does not immediately trigger the update of LSPs or Hello packets. That is, the newly configured compatible value is carried and verified only after the next update of LSPs or Hello packets.

Example

# Set the compatible value of the authentication type of the HMAC-SM3 algorithm to 4.
<HUAWEI> system-view
[HUAWEI] isis 1
[HUAWEI-isis-1] authentication-type-compatible hmac-sm3 4
