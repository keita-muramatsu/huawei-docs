multimedia-air-optimize downlink-slice-ratio

Function

The multimedia-air-optimize downlink-slice-ratio command configures the slicing ratio for voice and video services.

The undo multimedia-air-optimize downlink-slice-ratio command restores the default slicing ratio of voice and video services.

The default slicing ratio for voice and video services is medium.

Format

multimedia-air-optimize downlink-slice-ratio { voice | video } { low | medium | high | off | slice-ratio ratio-value }

undo multimedia-air-optimize downlink-slice-ratio

Parameters

Parameter Description Value
voice

Indicates voice packets.

-
video

Indicates video packets.

-
low

Sets the slicing ratio for voice or video services to low.

For specific values, refer to Table 1.

-
medium

Sets the slicing ratio for voice or video services to medium.

For specific values, refer to Table 1.

-
high

Sets the slicing ratio for voice or video services to high.

For specific values, refer to Table 1.

-
off

Specifies no slicing ratio for voice or video services.

-
slice-ratio ratio-value

Specifies a customized slicing ratio for voice or video services.

The value is an integer ranging from 0 to 100.

Views

RRM profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After the intelligent multimedia scheduling algorithm is enabled, you can run the multimedia-air-optimize downlink-slice-ratio command to configure the slicing ratios for voice and video services. When a specified slicing ratio is exceeded, voice or video delay optimization will be triggered, thereby ensuring better user experience of voice and video services upon the air interface congestion. You can customize the slicing ratios (specified by the parameter slice-ratio ratio-value) or use the fixed slicing ratios (low | medium | high), as listed in Table 1.

Table 1 Fixed slicing ratios for voice and video services

Parameter Video Voice
low Slicing ratio: 5% Slicing ratio: 5%
medium Slicing ratio: 15% Slicing ratio: 15%
high Slicing ratio: 30% Slicing ratio: 30%
off No slicing No slicing

This command is new in V600R022C10. In different AP version combinations, the multimedia-air-optimize downlink-slice-ratio command takes effect in different modes, as listed in the following table.

Table 2 How air interface slicing takes effect in different AP version combinations

New AP (V200R022C00 or Later) Old AP (Earlier Than V200R022C00)
Fixed slicing ratio parameters: take effect immediately.<br/>Customized slicing ratio parameters: take effect immediately. Fixed slicing ratio parameters: take effect immediately.<br/>Customized slicing ratio parameters: are converted to fixed slice ratio parameters and then delivered. The conversion rules are as follows:
  • 5% ≥ ratio-value > 0: low
  • 15% ≥ ratio-value > 5: medium
  • ratio-value > 15%: high
  • ratio-value = 0: off

Prerequisites

The intelligent multimedia scheduling algorithm has been enabled using the multimedia-air-optimize enable command.

Precautions

For the same type of packets (voice or video), the customized slicing ratio (specified by slice-ratio ratio-value) and fixed slicing ratio (specified by low | medium | high) are mutually exclusive.

If you run this command multiple times, only the latest configuration takes effect.

Example

# Set the slicing ratio for video services to low and that for voice services to high.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] rrm-profile name p1
[HUAWEI-wlan-rrm-prof-p1] multimedia-air-optimize enable
[HUAWEI-wlan-rrm-prof-p1] multimedia-air-optimize downlink-slice-ratio video low
[HUAWEI-wlan-rrm-prof-p1] multimedia-air-optimize downlink-slice-ratio voice high
