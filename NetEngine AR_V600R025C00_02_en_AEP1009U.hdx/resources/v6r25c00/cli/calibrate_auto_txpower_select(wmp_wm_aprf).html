calibrate auto-txpower-select

Function

The calibrate auto-txpower-select command enables or disables the TPC function.

The undo calibrate auto-txpower-select command restores the default TPC state.

By default, TPC is enabled in the AP group radio view, and this function of a single AP radio is not configured but is in the same state as that configured in the AP group to which the AP belongs.

Format

calibrate auto-txpower-select { enable | disable }

undo calibrate auto-txpower-select

Parameters

Parameter Description Value
enable

Enables the TPC function.

-
disable

Disables the TPC function.

-

Views

AP radio view, AP group radio view

Default Level

2: Configuration level

Usage Guidelines

TPC supports the following two power selection modes:

  • Automatic mode (TPC enabled): An AP automatically selects or adjusts the transmit power based on the WLAN radio environment, removing the need to manually specify AP power.
  • Fixed mode (TPC disabled): The transmit power must be manually specified.

    TPC must be enabled for APs that require radio calibration.

Example

# Disable the TPC function.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-group name default
[HUAWEI-wlan-ap-group-default] radio 0
[HUAWEI-wlan-ap-group-default-radio-0] calibrate auto-txpower-select disable
