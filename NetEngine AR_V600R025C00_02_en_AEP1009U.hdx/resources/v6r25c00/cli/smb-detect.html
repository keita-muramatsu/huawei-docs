smb-detect

Function

The smb-detect enable command enables SMB detection.

The smb-detect { direction { upload | download | both } | action { block | alert } } command configures the direction or action for SMB detection.

The smb-detect direction { upload | both | download } action { block | alert } command configures the direction and action for SMB detection.

The undo smb-detect enable command disables SMB detection.

The undo smb-detect { direction | action } command restores the default direction or action for SMB detection.

The undo smb-detect direction action command restores the default direction and action for SMB detection.

By default, SMB detection is enabled in both the upload and download directions, and the action is block.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

smb-detect enable

smb-detect { direction { upload | download | both } | action { block | alert } }

smb-detect direction { upload | download | both } action { block | alert }

undo smb-detect enable

undo smb-detect { direction | action }

undo smb-detect direction action

Parameters

Parameter Description Value
upload

The protocol transfer direction is upload.

-
download

The protocol transfer direction is download.

-
both

The protocol transmission direction is upload or download.

-
block

Set the action to Block. After detecting a virus, discard the packets and record a log.

-
alert

Set the action to alarm. After a virus is detected, the packets are permitted, but a log is recorded.

-

Views

Antivirus profile view

Default Level

2: Configuration level

Usage Guidelines

SMB detection is enabled by default. If it is disabled, SMB detection is not performed.

After the protocol detection direction is configured, the device detects only the files transferred through the specified protocol in the specified direction. If a malicious file is detected, the device performs the configured action.

Example

# Set the SMB detection direction to upload and the action to alert. 
<HUAWEI> system-view
[HUAWEI] profile type av name protocol_detect
[HUAWEI-profile-av-protocol_detect] smb-detect direction upload action alert
