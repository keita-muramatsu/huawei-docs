more

Function

The more command displays the contents of a specified file.

Format

more file-name [ offset ] [ hex ]

Parameters

Parameter Description Value
file-name

Specifies the name of a file.

The value is a string of case-sensitive characters in the format of [drive][path][file name]. If the file name is an absolute path name, the value is a string of 1 to 255 characters. If the file name is a relative path name, the value is a string of 1 to 128 characters. A maximum of eight levels of directories are supported.

An absolute path is in the format of drive[path][file name], and a relative path is in the format of [path][file name]. (A relative path is the root path of the current working path.)
offset

Specifies the offset of the file to be displayed.

The value is an integer ranging from 0 to 2147483647 in bytes.
hex

Displays the file content in hexadecimal format.

-

Views

User view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

You can run this command to view the content of a specified file. If the hex parameter is not specified, the system displays the file content in text format. If the hex parameter is specified, the system displays the file content in hexadecimal notation.

Example

# Display the content of the tmp.txt file in text format.
<HUAWEI> more tmp.txt
AppWizard has created this test application for you.
This file contains a summary of what you will find in each of the files that make up your test application.
# Display the file content in hexadecimal format.
<HUAWEI> more test.kpi hex
