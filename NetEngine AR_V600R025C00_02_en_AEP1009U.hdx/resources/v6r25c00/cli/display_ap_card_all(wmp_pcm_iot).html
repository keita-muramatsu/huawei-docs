display ap-card all

Function

The display ap-card all command displays brief information about cards on all the APs.

Format

display ap-card all

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

To query brief information about cards on all the APs, run the display ap-card all command.

Precautions

No result is displayed if a card does not support query.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display brief information about cards on all the APs.
<HUAWEI> display ap-card all

Wireless standard supported by a card. The value is a 10-byte ASCII character set, for example, RFID, ANT, Zigbee, BT4.0, and Weightless.

Baud rate used for communication between the card and AP.

Module ID of the card. The value is a 16-byte BCD character set.

Frame format of an extension interface.
