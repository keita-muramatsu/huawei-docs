user-interface vty acl

Function

The user-interface vty acl command restricts login through a user interface based on the ACL.

The undo user-interface vty acl command cancels restrictions on login through a user interface.

By default, login through a user interface is not restricted.

Format

user-interface vty ui-number acl [ ipv6 ] acl-number { inbound | outbound }

undo user-interface vty ui-number acl [ ipv6 ] { inbound | outbound }

Parameters

Parameter Description Value
ipv6

Specifies an ACL6 number.

-
acl-number

Specifies the number of an ACL.

The value is an integer that ranges from 3000 to 3031.
inbound

Restricts users with specified IP addresses or on a specified IP address segment from logging in to the device.

-
outbound

Restricts users who have logged in to the system from logging in to other devices.

-
vty ui-number

Specifies the number of a VTY user interface.

The value is an integer ranging from 0 to 4.

Views

AP system profile view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

You can run this command to restrict login through a user interface based on the source IP address, destination IP address, source port, or destination port and also determine whether to permit or deny the access.

Prerequisites

An ACL has been configured using the acl (system view) and rule commands.

If no rule is configured, login rights on the user interface are not restricted when this command is executed.

Follow-up Procedure

Run the commit command to deliver the configuration to APs and restart the APs to make the configuration take effect.

Precautions

After the configurations of the ACL take effect, all users on the user interface are restricted by the ACL.

Four types of ACLs can be configured on a user interface: inbound and outbound IPv4 ACLs and inbound and outbound IPv6 ACLs. Only one ACL takes effect for each type of ACL, and the latest configuration takes effect.

Example

# Restrict Telnet login to other devices on the VTY0 user interface.
<HUAWEI> system-view
[HUAWEI] acl 3001
[HUAWEI-acl-adv-3001] rule deny tcp source any destination-port eq telnet
[HUAWEI-acl-adv-3001] quit
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name example
[HUAWEI-wlan-ap-system-prof-example] user-interface vty 0 acl 3001 outbound
