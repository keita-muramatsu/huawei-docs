monitor enable(route-monitor-group6)

Function

The monitor enable command enables an IPv6 route monitoring group.

The undo monitor enable command disables an IPv6 route monitoring group.

By default, an IPv6 route monitoring group is disabled.

Format

monitor enable

undo monitor enable

Parameters

None

Views

IPv6 route monitoring group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

An IPv6 route monitoring group can be associated with service modules only after the IPv6 route monitoring group is enabled using the monitor enable command.

When a large number of routes are added to or deleted from an IPv6 route monitoring group, the fault weight of the IPv6 route monitoring group frequently changes. As a result, services associated with the IPv6 route monitoring group flap. In this case, you can run the undo monitor enable command to disable the association between the IPv6 route monitoring group and all service modules, and then run the monitor enable command to restore the association after the configuration is complete.

Configuration Impact

After you run the monitor enable command to enable an IPv6 route monitoring group, the status of the IPv6 route monitoring group takes effect immediately. If you add routes to or delete routes from an IPv6 route monitoring group, the fault weight of the IPv6 route monitoring group frequently changes. As a result, services associated with the IPv6 route monitoring group flap.

Example

# Enable the IPv6 route monitoring group named uplink.
<HUAWEI> system-view
[HUAWEI] ipv6 route-monitor-group uplink
[HUAWEI-route-monitor-group6-uplink] monitor enable
