display provision-ap parameter-list

Function

The display provision-ap parameter-list command displays parameters configured in the AP provisioning view.

Format

display provision-ap parameter-list

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

After configuring AP onboarding parameters in the AP provisioning view, you can run this command to check whether the parameters are correct and complete. If the parameters are correct, run the commit command to deliver the configuration.

If a hyphen (-) is displayed for a parameter in the command output, this parameter is not modified after the commit command is executed to deliver the configuration to the AP.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the configuration parameters in the AP provisioning view.
<HUAWEI> display provision-ap parameter-list
--------------------------------------------------------------------------------
AP mode                  : -                                                                                                        
AP address mode          : -                                                                                                   
IPv4 address             : -                                                                                                        
IPv4 mask address        : -                                                                                                        
IPv4 gateway address     : -                                                                                                        
IPv4 AC list             : -                                                                                                                                                                                                       
Management Vlan          : 2                                                                                                        
DTLS server-auth         : enable                                                                                                        
DTLS server-auth cn list : -                                                           
--------------------------------------------------------------------------------
Table 1 Description of the display provision-ap parameter-list command output
Item Description
AP mode

Running mode of an AP.
AP address mode

Mode in which an AP obtains an IP address.
IPv4 address

Static IPv4 address of an AP.
IPv4 mask address

Mask of the static IPv4 address of an AP.
IPv4 gateway address

IPv4 address of the AP's gateway.
IPv4 AC list

AC IPv4 address list for an AP.
Management Vlan

Management VLAN tag carried in the CAPWAP packets which are sent from an AP's wired interface.
DTLS server-auth

Whether the AP authenticates the AC.
DTLS server-auth cn list

CN field used by the AP to authenticate the AC certificate.
