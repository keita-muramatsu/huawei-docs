undo firewall blacklist dynamic item

Function

The undo firewall blacklist dynamic item command deletes a dynamic blacklist entry.

By default, this function is not configured.

Format

undo firewall blacklist dynamic item destination-ip { destination-ipv4-address | destination-ipv6-address } [ destination-port destination-port ] [ protocol { tcp | udp | icmp | protocol-num } ]

undo firewall blacklist dynamic item source-ip { source-ipv4-address | source-ipv6-address } [ source-port source-port ] [ protocol { tcp | udp | icmp | protocol-num } ]

undo firewall blacklist dynamic item

Parameters

Parameter Description Value
destination-port destination-port

Specifies the destination port.

You need configure the source or destination port only when the protocol type is set to TCP and UDP.

The value is an integer from 1 to 65535.
protocol protocol-num

Specifies the protocol number.

The value is an integer ranging from 1 to 255.
tcp

Indicates the TCP protocol.

-
udp

Indicates the UDP protocol.

-
icmp

Indicates ICMP.

-
source-ip source-ipv4-address

Specifies the source IPv4 address.

The value is in dotted decimal notation.
source-ip source-ipv6-address

Specifies a source IPv6 address.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.

dynamic

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Running the undo firewall blacklist dynamic item command will delete dynamic blacklist entries.

Example

# Delete all dynamic blacklists. 
<HUAWEI> system-view
[HUAWEI] undo firewall blacklist dynamic item
