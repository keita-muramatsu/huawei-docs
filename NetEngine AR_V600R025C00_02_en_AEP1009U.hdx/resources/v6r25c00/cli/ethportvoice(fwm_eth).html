voice-vlan enable

Function

The voice-vlan enable command configures the specified VLAN as a voice VLAN and enables the voice VLAN function.

The undo voice-vlan enable command disables the voice VLAN function.

By default, the voice VLAN function is disabled on an interface.

Format

voice-vlan vlanid enable [ include-untagged ]

undo voice-vlan [ vlanid ] enable

Parameters

Parameter Description Value
vlanid

Configures a specified VLAN as a voice VLAN.

The value is an integer that ranges from 2 to 4094.
include-untagged

Adds the voice VLAN ID to untagged packets.

When an interface receives untagged packets or packets tagged with VLAN 0, the interface determines whether to add the voice VLAN ID to the packets based on the OUI configured using the voice-vlan mac-address command. This parameter is mandatory when the voice packets sent by the IP phone are untagged or tagged with VLAN 0. In addition, the voice-vlan remark-mode command must be run to configure the mac-address mode.

-

Views

Interface group view, Layer 2 multi-GE interface view, 25GE-L2 view, Layer 2 10GE interface view, Layer 2 GE interface view, Layer 2 Eth-Trunk interface view, Layer 2 40GE interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After the voice VLAN function is enabled on the device, the device increases the priority of voice packets based on VLAN IDs or MAC addresses according to the mode configured using the voice-vlan remark-mode command to ensure that voice packets are preferentially sent.

Precautions

  • To ensure normal transmission of different services, assign different VLAN IDs to the voice VLAN and default VLAN on the interface.
  • Only one VLAN on an interface can be configured as a voice VLAN at a time.
  • When you run the voice-vlan enable command multiple times, only the latest configuration takes effect.

Example

# Configure VLAN 2 as a voice VLAN and enable the voice VLAN function on port group.
<HUAWEI> system-view
[HUAWEI] port-group group-member 10GE 0/0/1 to 10GE 0/0/5
[HUAWEI-port-group] voice-vlan 2 enable
