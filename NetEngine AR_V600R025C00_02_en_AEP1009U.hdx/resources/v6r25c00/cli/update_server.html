update server

Function

The update server command sets the parameters for connecting to the update server.

The undo update server command restores the default settings of the update server.

By default, the domain name of the update server is sec.huawei.com, the HTTPS port number is 443, and the initial CA certificate named default_ca.cer is used for the update service.

Format

update server { domain domain-name | ip ip-address } [ port port-number ]

update server ca-certificate certificate-file-name

undo update server

Parameters

Parameter Description Value
domain domain-name

Specifies the domain name of the update server.

The value is a string of 1 to 64 characters without spaces.

The value can contain only digits (0-9), letters (a-z and A-Z), hyphens (-), underscores (_), and periods (.). The value must contain periods (.), but cannot start or end with a period (.). Consecutive dots (.) are not allowed.
ip ip-address

Specifies the IP address of the update server.

The value is in dotted decimal notation.
port port-number

Specifies the port number of the update server.

The value is an integer from 1 to 65535.
ca-certificate certificate-file-name

Specifies the CA certificate used by the device to communicate with Huawei security center (sec.huawei.com) through HTTPS.

The value must be the name of an existing certificate.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

You can run this command to set the parameters for connecting to the update server.

The initial CA certificate is stored in the NVRAM. To use the initial CA certificate, run the pki import-certificate default_ca realm default command to load the initial CA certificate to the default realm first.

When you run the undo update server command, the CA certificate used for signature database update is restored to the initial CA certificate named default_ca.cer. In this case, ensure that the certificate already exists in the system. Otherwise, an exception may occur when the default system configuration is restored. If the certificate has been deleted, run the pki import-certificate default_ca realm default command to import the certificate again and name it default_ca.cer. Then, run the undo update server command.

Example

# Set the IP address of the update server to 10.1.1.1 and port number to 86.
<HUAWEI> system-view
[HUAWEI] update server ip 10.1.1.1 port 86
