netstream mpls-aware

Function

The netstream mpls-aware command configures the sampling mode for Multiprotocol Label Switching (MPLS) packets.

The undo netstream mpls-aware command restores the default setting.

By default, the device samples only inner information of MPLS packets.

Format

netstream mpls-aware { label-only | ip-only | label-and-ip } ip

netstream mpls-aware { label-only | ip-only | label-and-ip } ipv6

undo netstream mpls-aware [ label-only | ip-only | label-and-ip ] ip

undo netstream mpls-aware [ label-only | ip-only | label-and-ip ] ipv6

Parameters

Parameter Description Value
label-only

Indicates that only labels in the MPLS packets are sampled.

-
ip-only

Indicates that only the IP packets encapsulated in the MPLS packets are sampled.

-
label-and-ip

Indicates that both labels and IP packets encapsulated in the MPLS packets are sampled.

-
ip

IPv4 NetStream feature.

-
ipv6

Indicates the IPv6 flow statistics collection service.

-

Views

System view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

On an MPLS network, MPLS labels are important information that users are concerned about. The device can sample MPLS labels. If this command is not executed, the device samples only IP packets encapsulated in the MPLS packets.

Currently, only original flow statistics can be collected. Flexible flow statistics cannot be collected.

Precautions

When label-only is configured, only MPLS labels are collected, and inner IP information is not collected. As such, when the display netstream cache { ip | ipv6 } origin command is used to query flow table information, IP-related information is excluded; IP-related information in output packets is set to 0s.

Example

# Configure the device to sample only MPLS labels.
<HUAWEI> system-view
[HUAWEI] netstream mpls-aware label-only ip
