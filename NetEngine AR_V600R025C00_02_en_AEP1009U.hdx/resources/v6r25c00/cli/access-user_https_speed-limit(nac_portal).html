access-user https speed-limit

Function

The access-user https speed-limit command sets the rate limit for HTTPS packets sent to the CPU.

The undo access-user https speed-limit command restores the default rate limit for HTTPS packets sent to the CPU.

By default, the rate limit of HTTPS packets sent to the CPU varies according to the device.

Format

access-user https speed-limit value

undo access-user https speed-limit

Parameters

Parameter Description Value
value

Specifies the maximum rate.

The value is an integer ranging from 1 to 2000, in pps. The default value is 1.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

To prevent the CPU from being busy when the device processes too many HTTPS packets, run the access-user https speed-limit command to set the rate limit for HTTPS packets sent to the CPU. After this command is run, if the rate of HTTPS packets sent to the CPU exceeds the rate limit, the device discards the excess packets.

Example

# Set the rate limit of HTTPS packets sent to the CPU to 50 pps.
<HUAWEI> system-view
[HUAWEI] access-user https speed-limit 50
