interworking gateway qos-local-id

Function

The interworking gateway qos-local-id command configures a QoS local ID for the interworking gateway (IWG).

The undo interworking gateway qos-local-id command restores the default QoS local ID of the IWG.

By default, no QoS local ID is configured for the IWG at a site.

Format

interworking gateway qos-local-id id

undo interworking gateway qos-local-id [ id ]

Parameters

Parameter Description Value
id

Specifies a QoS local ID.

The value is an integer in the range from 1 to 255.

Views

Site view

Default Level

2: Configuration level

Usage Guidelines

When a CPE site connects to an IWG, you can run this command to configure a QoS local ID and bind an MQC policy to the corresponding SD-WAN tunnel interface to limit the rate of traffic matching the QoS local ID. In this way, traffic of a single CPE in a single VPN can be limited at the IWG site. If a QoS local ID is also configured on the SD-WAN tunnel interface, the QoS local ID configured using this command is used to match the MQC policy bound to the SD-WAN tunnel interface. The QoS local ID configured on the SD-WAN tunnel interface takes effect only after the MQC policy is executed.

Example

# Set the QoS local ID of the Internet gateway to 99.
<HUAWEI> system-view
[HUAWEI] evpn site 1
[HUAWEI-site-1] interworking gateway qos-local-id 99
