reset ap-card statistics

Function

The reset ap-card statistics command clears statistics on the packets received and sent by cards on APs.

Format

reset ap-card statistics { ap-id ap-id [ card { card-id | usb } ] | all }

Parameters

Parameter Description Value
ap-id ap-id

Specifies an AP ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
card card-id

Specifies the ID of an IoT card.

The value is an integer that ranges from 1 to 3.
usb

Specifies an IoT card of the USB type.

-
all

Specifies all cards on all APs.

-

Views

All views

Default Level

3: Management level

Usage Guidelines

Usage Scenario

You can run this command to clear statistics on the packets received and sent by cards on APs. Only statistics about IoT cards with the serial connection type can be cleared.

Precautions

The statistics cannot be restored after being cleared.

Example

# Clear statistics about the packets received and sent by all cards on all APs.
<HUAWEI> reset ap-card statistics all
