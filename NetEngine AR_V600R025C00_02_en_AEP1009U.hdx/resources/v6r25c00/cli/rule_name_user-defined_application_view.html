rule name (User-defined application view)

Function

The rule name command creates a user-defined application rule, and displays the user-defined application view.

The undo rule command deletes a user-defined application rule.

By default, no rule is configured for a new user-defined application.

Format

rule name rule-name

undo rule { name rule-name | all }

Parameters

Parameter Description Value
name rule-name

Specifies the rule name.

The value is a case-sensitive string of 1 to 32 characters. Enclose the name with double quotation marks ("") if the name contains spaces, for example, "user for test". If the name does not contain spaces, double quotation marks cannot be used.

The name cannot contain question marks (?), commas (,), or hyphens (-). In addition, the name cannot be any or all.
all

Deletes all rules.

-

Views

User-defined application view

Default Level

2: Configuration level

Usage Guidelines

If the name of the specified user-defined application rule does not exist, the system creates a user-defined application rule and displays the user-defined application rule view. If the name of the specified user-defined application rule exists, the system displays the user-defined application rule view.

The device supports 5-tuple-based (protocol + IP address + port), keyword-based (signature), and 5-tuple + keyword-based rule creation.

  • You can run the ip-address (user-defined application rule view)/ipv6-address (user-defined application rule view) command, port (user-defined application rule view) command, and protocol (user-defined application rule view) command to specify the 5-tuple of an application. After the configuration is complete and committed, the device attempts to use the 5-tuple of the first packet of the session to match traffic. If the traffic matches the 5-tuple, the traffic belongs to the application. If the traffic does not match the 5-tuple, the traffic does not belong to the application. When a user-defined application rule is configured in 5-tuple mode, each rule must contain at least one IP address or port number.
  • You can run the signature (user-defined application rule view) command to specify the keyword of an application.

    You can configure multiple rules for one user-defined application. These rules are logically ORed. Data flows or packets belong to the application once they match one of the rules. If the number of user-defined application rules on the device reaches the maximum value but the number of user-defined applications does not reach the maximum value, you can continue to configure user-defined applications but cannot configure user-defined application rules.

Example

# Create rule rule1 for user-defined application UD_myapp and access the rule view. 
<HUAWEI> system-view
[HUAWEI] sa
[HUAWEI-sa] user-defined-application name UD_myapp
[HUAWEI-sa-user-defined-application-UD_myapp] rule name myrule
