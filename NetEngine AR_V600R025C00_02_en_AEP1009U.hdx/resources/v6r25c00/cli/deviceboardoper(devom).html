device board (system view)

Function

The device board command creates a logical board of a specified type in a specific slot.

The undo device board command deletes the logical board configured in a specific slot without residual services.

By default, no logical board is configured on a device.

Format

device board slot-id board-type type

undo device board slot-id [ board-type type ]

Parameters

Parameter Description Value
slot-id

Specifies the slot ID.

You can enter a question mark (?) and select a value based on the prompt.
board-type type

Specifies the type of the logical board to be pre-configured.

The value is a string of 1 to 31 case-insensitive characters. It cannot contain spaces.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

  • Preconfiguration allows you to create logical components and configure services for them before the corresponding physical components are installed on a device. If a physical component is installed incorrectly or in a wrong position, pre-configured services will be retained and activated only when the physical component is correctly installed. If the physical component is removed, its service configurations are automatically deactivated and become offline configurations that can be modified.
  • Physical boards must be installed before service configuration, posing a higher requirement on the cooperation between NMS and hardware maintenance personnel. When desired physical boards are not ready, run the device board command to create logical boards and then configure services on them. This ensures that services can be automatically activated when physical boards are installed.

Prerequisites

The specified slot has no physical board or preconfigured logical board. If a logical board exists in the specified slot, you need to delete the logical board before running the device board command to create a new logical board.

Follow-up Procedure

After running the device board command to create a logical board, you can run the display device configuration command to view information about the logical board. After inserting a physical board of the same type, you can view the registration status of the physical board.

Precautions

  • After the physical board is in position, the system automatically creates the corresponding logical board. Therefore, if physical boards are in position, you can deploy services without creating logical boards.
  • The type of the logical board to be created must be supported by the physical device.
  • Only one logical board can be configured in a slot. Logical board replacement is not supported. To replace an existing logical board, you must delete the logical board first and then run the command to create a new logical board.
  • The active control board and plug-and-play board cannot be deleted manually by running the undo device board command.

Example

# Create the logical board named SIC-NR-102-V2 in slot 0.
<HUAWEI> system-view
[HUAWEI] device board 1 board-type SIC-NR-102-V2
