severity (User-defined IPS signature view)

Function

The severity command configures the severity of a user-defined signature.

The undo severity command cancels the severity of a user-defined signature.

The default severity of a user-defined signature is high.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

severity { high | information | low | medium }

undo severity

Parameters

Parameter Description Value
high

Indicates the high severity.

-
information

Indicates the information severity.

-
low

Indicates the low severity.

-
medium

Indicates the medium severity.

-

Views

User-defined IPS signature view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Threat severity describes the severity of consequences caused by attacks. Higher severity indicates severer consequences caused by attacks against the signature.

Precautions

After running this command, run the engine configuration commit command to commit the configuration for the configuration to take effect. You are advised to commit the configuration after all content security configurations are complete.

Example

# Configure user-defined signature 1, name it mysignature and set the severity to high. 
<HUAWEI> system-view
[HUAWEI] ips signature-id 1
[HUAWEI-ips-signature-1] name mysignature
[HUAWEI-ips-signature-1] severity high
