device voltage threshold

Function

The device voltage threshold command sets the voltage alarm threshold for a board (excluding the fan board).

The undo device voltage threshold command deletes the manually configured voltage alarm threshold of a board (excluding the fan board).

By default, the voltage threshold is set during board initialization.

This command is supported only on the AR8700 series.

Format

device voltage threshold slot slot-id sensor sensor-id low-major low-major-value low-fatal low-fatal-value high-major high-major-value high-fatal high-fatal-value

undo device voltage threshold slot slot-id sensor sensor-id

Parameters

Parameter Description Value
sensor sensor-id

Specifies a sensor ID.

The value is an integer. You can enter the question mark (?) and select the value as prompted.
low-major low-major-value

Specifies the major undervoltage threshold.

The value is an integer ranging from 80 to 120, in percentage.
low-fatal low-fatal-value

Specifies the percentage of the fatal undervoltage threshold of a specified board to the default fatal undervoltage threshold.

The value is an integer ranging from 80 to 120, in percentage.
high-major high-major-value

Specifies the major overvoltage threshold.

The value is an integer ranging from 80 to 120, in percentage.
high-fatal high-fatal-value

Specifies the fatal overvoltage threshold.

The value is an integer ranging from 80 to 120, in percentage.
slot slot-id

Specifies the slot ID.

The value is a character string. You can enter a question mark (?) and select a value as prompted. The value is a string of 1 to 29 case-insensitive characters. It cannot contain spaces.

Views

System view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

When environment conditions change, a user can use this command to adjust voltage alarm thresholds so that the system can detect board temperature changes accurately.

Precautions

If the device does not support voltage sensors, sensor information cannot be displayed using this command.

Example

# Set the major undervoltage threshold to 85% of the default major undervoltage threshold, the fatal undervoltage threshold to 80% of the default fatal undervoltage threshold voltage, the major overvoltage threshold to 105% of the default major overvoltage threshold voltage, and fatal overvoltage threshold to 110% of the default fatal overvoltage threshold voltage.
<HUAWEI> system-view
[HUAWEI] device voltage threshold slot 0 sensor 2  low-major 85 low-fatal 80 high-major 105 high-fatal 110
