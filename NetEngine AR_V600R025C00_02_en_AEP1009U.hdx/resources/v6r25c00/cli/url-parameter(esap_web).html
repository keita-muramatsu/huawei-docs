url-parameter

Function

The url-parameter command sets the parameters carried in a URL.

The undo url-parameter command deletes the parameters carried in a URL.

By default, a URL does not carry parameters.

Format

url-parameter { device-ip device-ip-value | device-mac device-mac-value | login-url url-key url | redirect-url redirect-url-value | sysname sysname-value | user-ipaddress user-ipaddress-value | user-mac user-mac-value | user-vlan user-vlan-value } *

Parameters

Parameter Description Value
device-ip device-ip-value

Specifies the device IP address carried in the URL and sets the parameter name displayed in the URL.

The value is a string of 1 to 16 case-sensitive characters. If the string is enclosed in double quotation marks (" "), it can contain spaces.
device-mac device-mac-value

Specifies the device MAC address carried in the URL and sets the parameter name displayed in the URL.

The value is a string of 1 to 16 case-sensitive characters. If the string is enclosed in double quotation marks (" "), it can contain spaces.
login-url url-key

Specifies the login URL of the access device:

url-key: identification keyword of the login URL sent to the Portal server during redirection.

url: URL specified on the access device.

url-key: The value is a string of 1 to 16 case-sensitive characters. If the character string is enclosed in double quotation marks (" "), it can contain spaces.

url: The value is a string of 1 to 247 case-sensitive characters. If the character string is enclosed in double quotation marks (" "), it can contain spaces.
redirect-url redirect-url-value

Specifies the original URL that a user accesses carried in the URL and sets the parameter name displayed in the URL.

The value is a string of 1 to 16 case-sensitive characters. If the string is enclosed in double quotation marks (" "), it can contain spaces.
sysname sysname-value

Specifies the system name of the access device carried in the URL and sets the parameter name displayed in the URL.

The value is a string of 1 to 16 case-sensitive characters. If the string is enclosed in double quotation marks (" "), it can contain spaces.
user-ipaddress user-ipaddress-value

Specifies the user IP address carried in the URL and sets the parameter name displayed in the URL.

The value is a string of 1 to 16 case-sensitive characters. If the string is enclosed in double quotation marks (" "), it can contain spaces.
user-mac user-mac-value

Specifies the access user's MAC address name carried in the URL and sets the parameter name displayed in the URL.

The value is a string of 1 to 16 case-sensitive characters. If the string is enclosed in double quotation marks (" "), it can contain spaces.
user-vlan user-vlan-value

Specifies the user VLAN name carried in the URL and sets the parameter name displayed in the URL.

This parameter applies only to wired access users.

The value is a string of 1 to 16 case-sensitive characters without Chinese characters. If the string is enclosed in double quotation marks (" "), it can contain spaces.
ap-ip ap-ip-value

Specifies the AP IP address carried in the URL and sets the parameter name displayed in the URL.

The value is a string of 1 to 16 case-sensitive characters. If the string is enclosed in double quotation marks (" "), it can contain spaces.
ap-mac ap-mac-value

Specifies the AP MAC address carried in the URL and sets the parameter name displayed in the URL.

The value is a string of 1 to 16 case-sensitive characters. If the string is enclosed in double quotation marks (" "), it can contain spaces.
ssid ssid-value

Specifies the SSID that users associate with carried in the URL and sets the parameter name displayed in the URL.

The value is a string of 1 to 16 case-sensitive characters. If the string is enclosed in double quotation marks (" "), it can contain spaces.
ap-group-name ap-group-name-value

Specifies the AP group name carried in the URL and sets the parameter name displayed in the URL.

The value is a string of 1 to 16 case-sensitive characters. It cannot contain the following characters: = ? &. If the string is enclosed in double quotation marks (" "), it can contain spaces.
ap-location ap-location-value

Specifies the AP location carried in the URL and configures the parameter name displayed in the URL.

This parameter takes effect only for Fit APs. Before configuring this parameter, run the location command to configure the AP installation location.

The value is a string of 1 to 16 case-sensitive characters. It cannot contain the following characters: = ? &. If the string is enclosed in double quotation marks (" "), it can contain spaces.
ap-name ap-name-value

Specifies the AP name carried in the URL and configures the parameter name displayed in the URL.

The value is a string of 1 to 16 case-sensitive characters. It cannot contain the following characters: = ? &. If the string is enclosed in double quotation marks (" "), it can contain spaces.

Views

URL template view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After a URL template is created using the url-template name command and a URL is configured using the url (URL template view) command in the URL template, you can run the url-parameter command to configure parameters carried in the URL. Then, when the user terminal accesses the Portal server according to the URL, the Portal server can obtain information about the user terminal according to the parameters in the URL. The Portal server provides different web authentication pages for different users based on the obtained user terminal information.

In addition, when a user accesses a website of a non-Portal server based on the pushed URL, the user terminal information carried in the URL also enables the website to provide different web access pages for different users.

When the device connects to iMaster NCE-Campus, you need to run the url-parameter set device-ip ip-address and url-parameter device-ip ac-ip commands in the URL template to send the device IP address to iMaster NCE-Campus. Otherwise, iMaster NCE-Campus cannot display the re-authentication page.

Precautions

  • The URL parameter name configured on the device must be the same as the parameter name supported by the server.
  • In wireless scenarios, the value of device-ip carried in a URL is the CAPWAP gateway address by default. In wired scenarios, the device cannot automatically obtain the device IP address. You can run the url-parameter set device-ip ip-addresscommand to specify the device IP address.
  • You are advised to configure the user-mac parameter in inter-AC roaming scenarios.

Example

# Configure the URL to carry the MAC address of the access user and the system name of the access device.
<HUAWEI> system-view
[HUAWEI] url-template name test
[HUAWEI-url-template-test] url-parameter user-mac umac sysname test
