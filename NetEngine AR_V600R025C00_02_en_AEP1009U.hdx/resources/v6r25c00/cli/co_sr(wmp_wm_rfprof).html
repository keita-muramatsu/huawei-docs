co-sr enable

Function

The co-sr enable command enables the Intelligent Coordinated Scheduling and Spatial Reuse (iCSSR) function.

The undo co-sr enable command disables the iCSSR function.

By default, the iCSSR function is disabled.

Format

co-sr enable

undo co-sr enable

Parameters

None

Views

RRM profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

On a high-density office network, you can run the co-sr enable command to enable the iCSSR function to improve the overall network throughput.

Precautions

This function is supported only by some AP models. You can visit Info-Finder, search for the target AP model, and search for multi-AP co-channel scheduling in Specifications Query to check whether the AP supports this function.

Example

# Enable the iCSSR function.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] rrm-profile name default
[HUAWEI-wlan-rrm-prof-default] co-sr enable
