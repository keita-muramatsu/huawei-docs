dot1q termination vid

Function

The dot1q termination vid command enables VLAN tag termination for single-tagged packets.

The undo dot1q termination vid command disables VLAN tag termination for single-tagged packets.

By default, VLAN tag termination for single-tagged packets is disabled on a sub-interface.

Format

dot1q termination vid low-pe-vid

undo dot1q termination vid low-pe-vid

Parameters

Parameter Description Value
vid low-pe-vid

Specifies the start VLAN ID in user packets.

The value is an integer ranging from 1 to 4094.

Views

10GE sub-interface view, 25GE sub-interface view, 40GE sub-interface view, Eth-Trunk sub-interface view, Ethernet sub-interface view, GE sub-interface view, Multi-GE sub-interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Inter-VLAN communication:

VLANs are widely used because they can separate users' Layer 2 packets. With the VLAN technology, a physical LAN is divided into multiple logical broadcast domains (VLANs). Hosts in the same VLAN can communicate with each other at Layer 2, but hosts in different VLANs cannot. The Layer 3 routing technology must be used to enable inter-VLAN communication. Currently, the following two methods can be used:

  • Through VLANIF interfaces on Layer 3 devices
  • Through Layer 3 Ethernet sub-interfaces on devices

    However, when a traditional Layer 3 Ethernet interface receives VLAN packets, the interface discards these packets as unauthorized packets. To enable inter-VLAN communication, you can create Ethernet sub-interfaces on Layer 3 Ethernet interfaces and deploy VLAN tag termination on these sub-interfaces, so that they can remove tags from VLAN packets.

Configuration Impact

After this command is run, the termination sub-interface processes packets as follows:

  • It removes the tags in received packets before forwarding these packets at Layer 3. Whether the forwarded packets carry tags is determined by the outbound interface.
  • It adds the VLAN information in packets received from the remote end to the packets to be sent, and then sends these packets.

The tag value of a user packet received by the sub-interface must be the value of low-pe-vid specified in this command. Otherwise, the packet is discarded.

After the dot1q termination vid command is configured on a sub-interface, the encapsulation dot1q-termination configuration is automatically generated on the sub-interface. Conversely, after the undo dot1q termination vid command is configured on the sub-interface, the encapsulation dot1q-termination configuration on the sub-interface is also deleted.

Precautions

On a main interface, the vid value of a dot1q VLAN tag termination sub-interface must be different from the pe-vid value of a QinQ VLAN tag termination sub-interface.

Example

# Configure Dot1q termination on 10GE 0/0/1.1, specify the VLAN range in the outer tag of user packets to be 100. 
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1.1
[HUAWEI-10GE0/0/1.1] dot1q termination vid 100
