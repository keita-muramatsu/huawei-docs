display ap optical-info

Function

The display ap optical-info command displays optical module information.

Format

display ap optical-info ap-id ap-id

Parameters

Parameter Description Value
ap-id ap-id

Displays optical module information of the AP with a specified ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

You can run this command to view optical module information on an AP, including the optical module type, output optical power, and receive optical power.

Prerequisites

The AP has been online. You can run the display ap command to check the AP status.

The AP supports optical modules. You can run the display ap-type command to view the AP model.

Precautions

Optical module query is supported only by the following models:

  • AirEngine X760 (excluding the AirEngine 5760-10 and AirEngine 6760-51EI)
  • AirEngine 6761-21, AirEngine 6761-21E, AirEngine 6761S-21, AirEngine 5761R-11, AirEngine 5761R-11E, AirEngine 5761RS-11, AirEngine 5761-11EI
  • AirEngine 5762-15HW
  • AirEngine 8771-X1T
  • AirEngine 9700D-S (including matching ORUs)
  • AirEngine series central APs
  • AirEngine 5561R-11E

If a copper module is inserted into an optical interface, diagnostic information command be displayed.
