work-mode

Function

The work-mode command sets the working mode of all specified AP radios (AP group radio view) or a specified radio on an AP (AP radio view) in an AP group.

The undo work-mode command restores the default working mode of all specified AP radios (AP group radio view) in an AP group, or restores the working mode of a specified radio on an AP (AP radio view) to the working mode configured in the AP group radio view.

By default, the working mode for all AP radios in an AP group is normal, and that for radios on a single AP is not configured but is the same as that configured in the AP group to which the AP belongs.

Format

work-mode { monitor | normal }

undo work-mode

Parameters

Parameter Description Value
monitor

Indicates the monitor mode.

-
normal

Indicates the normal mode.

-

Views

AP radio view, AP group radio view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

An AP radio can work in the following modes:

  • normal

    If no functions related to air scan are enabled on a radio, the radio only transmits common WLAN service data.

    If any function related to air scan is enabled on a radio, the radio provides the monitoring function in addition to transmitting common WLAN service data. WLAN services may encounter a transient increase in latency during a radio scanning period, which does not affect network access. However, if any latency-sensitive services (such as videoconferencing) are running, it is recommended that a separate radio be used for scanning.
  • monitor

    In this mode, the radio can only transmit WLAN services scanned by the air interface but cannot transmit common WLAN services.

Precautions

  • Changing the working mode of a radio interrupts services. STAs cannot associate with a radio working in monitor mode.
  • The configuration in the AP radio view has a higher priority than that in the AP group radio view.
  • The working channel and power of an AP radio working in monitor mode may change at any time. In this case, a hyphen (-) is displayed for the working channel and power of the radio.
  • The functions described in this section are configured only on the WAC. If an AP does not support the functions, the functions cannot take effect on the AP. For details about the functions supported by AP models, visit Info-Finder and query specifications.

Example

# Set the working mode of radio 0 in AP group office to monitor.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-group name office
[HUAWEI-wlan-ap-group-office] radio 0
[HUAWEI-wlan-ap-group-office-radio-0] work-mode monitor
Warning: Modify the work mode may cause business interruption, continue?[y/n]:y
