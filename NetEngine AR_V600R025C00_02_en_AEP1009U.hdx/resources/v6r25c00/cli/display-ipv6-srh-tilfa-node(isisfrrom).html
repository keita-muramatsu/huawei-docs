display isis srv6 ti-lfa-node

Function

The display isis srv6 ti-lfa-node command displays TI-LFA information on a specified node.

Format

display isis [ process-id ] srv6 ti-lfa-node [ ipv6 ] [ level-1 | level-2 ] [ systemid systemid ]

Parameters

Parameter Description Value
process-id

Displays TI-LFA information on nodes in a specified process.

If this parameter is not specified, TI-LFA information of all processes is displayed.

The value is an integer ranging from 1 to 4294967295.
ipv6

Displays IPv6 topology information.

-
level-1

Displays TI-LFA information on nodes in Level-1 areas.

-
level-2

Displays TI-LFA information on nodes in a Level-2 area.

If no level is specified, TI-LFA information of all area nodes is displayed.

-
systemid systemid

Specifies the system ID or pseudo node ID.

The value is a hexadecimal integer, in the format of XXXX.XXXX.XXXX.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

After IPv6 IS-IS TI-LFA FRR is configured on a device, run the display isis srv6 ti-lfa-node command to view TI-LFA information of a specific node or all nodes. The command output contains the P node's prefix, outbound interface name, next-hop IP address, P and Q nodes, and P-to-Q label stack.

The actual command output varies according to the device. The command output here is only an example.

Table 1 Description of the display isis srv6 ti-lfa-node command output
Item Description
DestNode

System ID of the destination node.
PriExitInterface

Outbound interface of the primary path.
PriNexthopAddr

Next-hop address of the primary path.
Protect

Protection type:

  • LINK: link protection.
  • LINKNODE: node protection.
PNode

System ID of the P node.
QNode

System ID of the Q node.
ExitInterface

Backup outbound interface.
NexthopAddr

Backup next-hop node.
SidStack (P->Q)

SID label stack from the P node to the Q node and label stack encapsulation mode.
ExtendPolicy

Extended policy, which determines whether the SRv6 TI-LFA result is calculated under the SRLG policy. If yes, the SRLG policy name is displayed. Otherwise, no information is displayed.
CompressMode

Compression mode.
FirstBlockLen

Length of the first block.
LastSidFlavor

Flavor type of the last SID.
