qos car (Interface View)

Function

The qos car command configures IP address-based traffic policing.

The undo qos car command deletes the IP address-based traffic policing configuration.

By default, IP address-based traffic policing is not configured on an interface.

Format

qos car { inbound | outbound } { destination-ip-address | source-ip-address } range start-ip-address to end-ip-address [ per-address ] [ time-range time-range-name ] cir cir-value [ pir pir-value ] [ cbs cbs-value pbs pbs-value ] [ green pass ] [ yellow { pass | discard } ] [ red { pass | discard } ]

undo qos car { inbound | outbound } { destination-ip-address | source-ip-address } range start-ip-address to end-ip-address

Specifies the name of a time range.

Specifies the committed information rate (CIR), in kbit/s by default.

The value is an integer in the range from 24 to 100000000.

Specifies the peak information rate (PIR), in kbit/s by default.

The value is an integer in the range from 24 to 100000000.
cbs cbs-value

Specifies the committed burst size (CBS), in bytes by default.

The value is an integer that ranges from 10000 to 4194304.
pbs pbs-value

Specifies the peak burst size (PBS), in bytes by default.

The value is an integer that ranges from 10000 to 4194304.
green

Specifies the packet color. By default, green packets and yellow packets are allowed to pass through, and red packets are discarded.

Specifies the packet color. By default, green packets and yellow packets are allowed to pass through, and red packets are discarded.

Usage Guidelines

Usage Scenario

  • Traffic policing controls traffic by monitoring the traffic rate and discarding excess traffic to limit the incoming or outgoing traffic within a proper range and protect network resources.

  • When data is transmitted from a high-speed link to a low-speed link, the bandwidth on the interface of the low-speed link is insufficient. As a result, a large number of packets are discarded. To solve this problem, you can configure traffic policing in the outbound direction on the interface of the high-speed link. The interface then discards the outgoing packets whose rate exceeds the traffic policing rate so that the rate of outgoing traffic is limited within a specified range. You can also configure traffic policing in the inbound direction on the interface of the low-speed link. The interface then discards the incoming packets whose rate exceeds the traffic policing rate.

  • You can configure the device to perform traffic policing for all or some service traffic on an interface as required. For example:

    Perform traffic policing for all service traffic on an interface.

    Perform traffic policing for the service traffic that matches a specified ACL rule.

    Perform traffic policing for the service traffic whose source and destination IP addresses are within a specified range.

    Traffic policing actions include allowing packets to pass through, discarding packets, and forwarding packets after changing priorities. By default, green packets and yellow packets are allowed to pass through, and red packets are discarded.

  • The packet color is determined by the cbs cbs-value and pbs pbs-value parameters in the qos car command.

    When the size of a packet is smaller than the CBS, the packet is colored green.

    When the size of a packet is greater than or equal to the CBS but smaller than the PBS, the packet is colored yellow.

    When the size of a packet is greater than or equal to the PBS, the packet is colored red.

  • This command applies to the following scenario:

    The qos car command can be run in the interface view to perform traffic policing for all incoming and outgoing packets on an interface.

Precautions

  • When the traffic policing rate is greater than the maximum rate of an interface, traffic policing does not take effect on the interface. Set the values of cir-value and pir-value to be smaller than the interface rate.
  • When the value of cbs-value is smaller than the number of bytes in a single packet of the deployed service, packets of the service are discarded.
  • To prevent packet color identification problems, you are advised to set the value of pbs-value to be greater than that of cbs-value.
  • Only the AR models with 2 GB memory (AR5710-S8T2S, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8P2X and AR5710-S10T1X2) support this function.

Example

# Configure traffic policing for packets with source IP addresses ranging from 1.1.1.1 to 1.1.1.4 in the inbound direction of 10GE0/0/0.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/0
[HUAWEI-10GE0/0/0] qos car inbound source-ip-address range 1.1.1.1 to 1.1.1.4 cir 100 cbs 10000 pbs 10000
