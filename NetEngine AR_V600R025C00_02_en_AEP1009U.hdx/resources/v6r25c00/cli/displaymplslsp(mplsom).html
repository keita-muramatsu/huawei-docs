display mpls lsp

Function

The display mpls lsp command displays information about LSPs.

The display mpls lsp compatible command displays information about LSPs.

Format

display mpls lsp [ outgoing-interface { interface-name | interface-type interface-number } ] [ lsr-role { ingress | transit | egress } ] [ verbose ]

display mpls lsp include ip-address mask-length

display mpls lsp exclude ip-address mask-length

display mpls lsp compatible [ outgoing-interface { interface-name | interface-type interface-number } ] [ lsr-role { ingress | transit | egress } ]

display mpls lsp compatible include ip-address mask-length

display mpls lsp compatible exclude ip-address mask-length

display mpls lsp include ip-address mask-length verbose

display mpls lsp exclude ip-address mask-length verbose

display mpls lsp nexthop nexthop [ lsr-role { ingress | transit | egress } ] [ verbose ]

Parameters

Parameter Description Value
outgoing-interface

Displays information about all LSPs with a specified outbound interface.

-
interface-name

Specified the name of an interface.

-
interface-type

Specifies an interface type.

-
interface-number

Specifies an interface number.

-
lsr-role

Displays information about all LSPs on the current LSR that plays a specified role.

-
ingress

Displays information about all LSPs on the current LSR that functions as the ingress.

-
transit

Displays information about all LSPs on the current LSR that functions as a transit node.

-
egress

Displays information about all LSPs on the current LSR that functions as the egress.

-
verbose

Displays detailed LSP information.

-
include

Includes the LSP information of specified FECs in the command output.

-
ip-address

Displays information about LSPs with a specified destination IP address.

The value is in dotted decimal notation.
mask-length

Mask length of an IP address.

The value is an integer ranging from 0 to 32.
exclude

Excludes the LSP information of specified FECs in the command output.

-
nexthop nexthop

Displays information about all LSPs with a specified next hop.

The value is in dotted decimal notation.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

If no parameter is configured, the display mpls lsp command displays information about all LSPs.

If BGP LSPs load-balance traffic, this command output contains only optimal outbound interface information of routes. To query all outbound interface information used in BGP LSP ECMP, query the BGP or IP routing table.

Table 1 Description of the display mpls lsp command output
Item Description
LSP Information

Indicates LSP information:

  • LDP LSP: created using LDP.
  • BGP LSP: created using BGP based on private IPv4 BGP routes.
  • L3VPN LSP: created using BGP based on received IPv4 VPN routes.
  • BGP IPv6 LSP: created using BGP based on private IPv6 routes.
  • EVPN L3VPN LSP: This type of LSP is established for the IP prefix routes received by EVPN through BGP.
No

LSP ID.
SessionID

Session ID of a CR-LSP.
IngressLsrID

Ingress LSR ID of a CR-LSP.
LocalLspID

Local LSP ID of a CR-LSP.
Tunnel-Interface

Tunnel interface name.
Type

LSP type. For LDP LSPs, the value can be:

  • Primary.
  • Backup.
  • Backup_RLFA.
  • RLFA.
  • Backup_TILFA.
Nexthop

Next-hop address.
In-Label

Value of the incoming label.
Out-Label

Value of the outgoing label.
In-Interface

Inbound interface information.
Out-Interface

Outbound interface.
LspIndex

LSP index.
Token

LSP token, guiding packet forwarding.
LsrType

Role of an LSR on an LSP:

  • Ingress.
  • Transit.
  • Egress.
Mpls-Mtu

Maximum transmission unit (MTU) of an LSP interface.
LspAge

LSP establishment time.
Entropy Label Flag

Whether the entropy label capability is enabled, which is the negotiation result of the ingress and egress of an RSVP-TE LSP.
Label Operation

Label operation type. The options are as follows:

  • PUSH.
  • SWAP.
  • POP.

This value is available only for non-CR-LSPs.
Flag after Out IF

Meaning of the flag after the outbound interface:

I flag: RLFA recursed LSP.

I* flag: Common and RLFA recursed LSP.
Flag after LDP FRR

Meaning of the flag after LDP FRR.

L flag: logical backup link.
VrfIndex

Index of a VPN instance. This value is available only for non-CR-LSPs.
OutSegmentIndex

OutSegment index.
Outgoing TunnelType

Type of the tunnel to which an LSP is iterated.
Outgoing TunnelID

ID of the tunnel to which the LSP is iterated.
Ingress-ELC

Whether the ingress delivers the entropy label after negotiating with the egress of an LDP LSP. The LSP has the capability enabled only after the entropy label is enabled for egress and the LSP.
FEC

Forwarding equivalence class, which is usually the destination address and mask of an LSP.
In/Out Label

Values of the incoming and outgoing labels.
In/Out IF

Name of the inbound/outbound interface.
Vrf Name

Name of a VPN instance.
