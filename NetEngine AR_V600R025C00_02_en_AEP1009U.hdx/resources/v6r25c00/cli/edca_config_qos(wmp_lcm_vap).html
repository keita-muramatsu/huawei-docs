wmm edca-client(SSID profile view)

Function

The wmm edca-client command configures EDCA parameters for STAs.

The undo wmm edca-client command restores the default EDCA parameter settings of STAs.

The following table lists the default EDCA parameter settings for STAs.

Format

wmm edca-client { ac-vo | ac-vi | ac-be | ac-bk } { aifsn aifsn-value | ecw ecwmin ecwmin-value ecwmax ecwmax-value | txoplimit txoplimit-value } *

undo wmm edca-client

Parameters

Parameter Description Value
ac-vo

Indicates AC_VO packets.

-
ac-vi

Indicates AC_VI packets.

-
ac-be

Indicates AC_BE packets.

-
ac-bk

Indicates AC_BK packets.

-
aifsn aifsn-value

Specifies the arbitration inter frame spacing number (AIFSN), which determines the channel idle time.

The value is an integer that ranges from 2 to 15.
ecw

Specifies the exponent form of the contention window.

-
ecwmin ecwmin-value

Specifies the exponent form of the minimum contention window. ecwmin-value and ecwmax-value determine the average backoff time.

The value is an integer that ranges from 0 to 15 and must be smaller than or equal to ecwmax-value.
ecwmax ecwmax-value

Specifies the exponent form of the maximum contention window. ecwmin-value and ecwmax-value determine the average backoff time.

The value is an integer that ranges from 0 to 15 and must be greater than or equal to ecwmin-value.
txoplimit txoplimit-value

Specifies the transmission opportunity limit (TXOPLimit), which determines the maximum duration in which a STA can occupy a channel. A larger TXOPLimit value indicates a longer duration to occupy a channel.

The value is an integer that ranges from 0 to 255, in 32 μs.

If the TXOPLimit value is 0, the STA can send only one data frame every time it occupies a channel.

Views

SSID profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

WMM classifies data packets into the following access categories: AC_VO, AC_VI, AC_BE, and AC_BK. Each access category has a set of EDCA parameters defined, which determine the capabilities of an access category to occupy a channel. You can set EDCA parameters for packets of different access categories to grant differentiated priorities to the packets and different capabilities to contend for channels.

Table 1 describes the EDCA parameters.

Table 1 EDCA parameter description

Parameter Description
Arbitration Inter Frame Spacing Number (AIFSN) In the DCF mechanism, the idle wait time is a fixed value. WMM provides different DIFS values for different ACs. A large AIFSN value means that the STA must wait for a long time and has a low priority.
Exponent form of CWmin (ECWmin) and Exponent form of CWmax (ECWmax) They together determine the average backoff time. A larger value indicates a longer average backoff time and a lower priority.
Transmission Opportunity Limit (TXOPLimit) A STA can occupy a channel after successful preemption. A larger value indicates a longer duration in which the STA can occupy a channel. If the TXOPLimit value is 0, the STA can only send one data frame every time it preempts a channel.

Table 2 Default EDCA parameter settings for STAs

Packet Type ECWmax ECWmin AIFSN TXOPLimit
AC_VO 3 2 2 47
AC_VI 4 3 2 94
AC_BE 10 4 3 0
AC_BK 10 4 7 0

Precautions

  • The EDCA parameters configured for the four AC queues take effect only after the WMM function is enabled using the undo wmm disable command.
  • To make manually adjusted EDCA configuration take effect, disable dynamic EDCA parameter adjustment (by using the undo dynamic-edca enable command) and the intelligent multimedia scheduling algorithm (by using the undo multimedia-air-optimize enable command).
  • By default, queues of AC_VO, AC_VI, AC_BE, and AC_BK are in descending order of priority. Priorities of the four queues are determined by their EDCA parameters. Therefore, modifying the EDCA parameters affects the priorities of the queues.
  • EDCA parameters must be configured properly. The scenarios for the reference EDCA parameter settings are as follows:
  1. Table 3 lists the reference configurations in voice scenarios.

    Table 3: Reference EDCA parameter settings and ACK policies in voice scenarios
Packet Type ECWmax ECWmin AIFSN TXOPLimit ACK Policy
AC_VO 4 2 2 0 normal
AC_VI 5 3 5 0 normal
AC_BE 10 6 5 0 normal
AC_BK 10 8 12 0 normal
  1. Table 4 lists the reference configurations in voice and video scenarios.

    Table 4: Reference EDCA parameter settings and ACK policies in voice and video scenarios
Packet Type ECWmax ECWmin AIFSN TXOPLimit ACK Policy
AC_VO 4 2 2 0 normal
AC_VI 5 3 5 0 normal
AC_BE 10 6 12 0 normal
AC_BK 10 8 12 0 normal
  1. In high-density scenarios, it is recommended that you run the dynamic-edca enable command to enable dynamic EDCA parameter adjustment.
  2. For other scenarios, the default settings are recommended.

Example

# Set EDCA parameters for AC_VO packets of STAs in SSID profile p1.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ssid-profile name p1
[HUAWEI-wlan-ssid-prof-p1] wmm edca-client ac-vo aifsn 7 ecw ecwmin 4 ecwmax 10 txoplimit 0
