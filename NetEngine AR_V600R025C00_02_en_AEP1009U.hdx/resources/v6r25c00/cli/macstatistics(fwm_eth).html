display fwm mac statistics slot chip

Function

The display fwm mac sync-info statistics command displays statistics about IPC messages and synchronization messages of the MAC module.

The display fwm mac table-info statistics command displays statistics about key information such as MAC address learning, aging, synchronization, and deletion.

The display fwm mac table-entry statistics command displays statistics about MAC forwarding entries of a chip.

Format

display fwm mac { table-entry | sync-info | table-info } statistics slot slotid chip chipid

Parameters

Parameter Description Value
slot slotid

Specifies a slot ID.

The value is a string of 1 to 23 case-sensitive characters, spaces not supported.
chip chipid

Specifies a chip ID.

The value is an integer ranging from 0 to 8.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

When a MAC address-related problem occurs on the device, you can run the display fwm mac sync-info statistics command to check MAC address communication statistics of a specified chip in a specified slot. The statistics help analyze the cause of the problem. Generally, this command is used to check the message sending status in configuration restoration and restart scenarios.

When MAC address learning fails, MAC addresses are not synchronized between cards, or MAC addresses fail to be deleted, you can run the display fwm mac table-info statistics command to check the corresponding statistics. The statistics help analyze the cause of the problem.

When a MAC address-related problem occurs on the device, you can run the display fwm mac table-entry statistics command to view statistics about MAC forwarding entries of a specified chip in a specified slot and check whether the number of MAC forwarding entries of the chip is the same as the number of software entries.
