mac-authen username fixed

Function

The mac-authen username fixed command configures the fixed user name format for MAC address authentication.

The undo mac-authen username command restores the default configuration.

By default, the MAC address without hyphens (-) is used as the user name and password for MAC address authentication.

Format

mac-authen username fixed user-name [ password cipher fixed-password ]

undo mac-authen username [ fixed user-name [ password cipher fixed-password ] ]

Parameters

Parameter Description Value
password

Specifies the password of the fixed user name for MAC address authentication.

-
cipher fixed-password

Specifies the password in ciphertext for MAC address authentication.

If no password is set when a fixed user name is used, the user can log in without a password. This brings a security risk and is not recommended.

The value is a string of 1 to 128 or 128 to 268 case-sensitive characters. If spaces are used, the string must be enclosed in double quotation marks (" ").
fixed user-name

Specifies a fixed user name for MAC address authentication.

The value is a string of 1 to 64 case-sensitive characters. If spaces are used, the string must be enclosed in double quotation marks (" ").

Views

MAC access profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When a fixed user name is used for MAC address authentication, the fixed user name and password configured by the administrator are used for authentication.

Precautions

  • When configuring the user name format for MAC address authentication, ensure that the authentication server supports the user name format.
  • A password must be configured when MAC address authentication is enabled on a VLANIF interface, on an Eth-Trunk interface, or in a port group and the fixed user name format is configured for MAC address authentication.
  • For security purposes, it is recommended that the password contain at least six characters and at least two types of the following: lowercase letters, uppercase letters, digits, and special characters.
  • After the weak password dictionary maintenance function is enabled, the passwords defined in the weak password dictionary cannot be used. To check the passwords defined in the weak password dictionary, run the display security weak-password-dictionary command.

Example

# Configure 123 as the fixed user name in the MAC access profile mac_access_profile.
<HUAWEI> system-view
[HUAWEI] mac-access-profile name mac_access_profile
[HUAWEI-mac-access-profile-mac_access_profile] mac-authen username fixed 123
