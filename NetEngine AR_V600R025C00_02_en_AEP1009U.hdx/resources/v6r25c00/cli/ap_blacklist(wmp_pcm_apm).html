ap blacklist

Function

The ap blacklist command adds an AP to an AP blacklist.

The undo ap blacklist command deletes an AP from an AP blacklist.

By default, no AP is in an AP blacklist.

Format

ap blacklist mac ap-mac1 [ to ap-mac2 ]

undo ap blacklist { mac ap-mac1 [ to ap-mac2 ] }

undo ap blacklist mac all

Parameters

Parameter Description Value
to ap-mac2

Specifies the end MAC address. This parameter is used when you want to add multiple MAC addresses to the blacklist. The value must be larger than ap-mac1. ap-mac1 and ap-mac2 identify a range.

The maximum number of MAC addresses that can be added to the blacklist in batches is 128.

The value is in H-H-H format. An H is a hexadecimal number of 4 digits.
mac ap-mac1

Specifies the AP MAC address.

The value is in H-H-H format. An H is a hexadecimal number of 4 digits.
all

Deletes all MAC addresses from the blacklist.

-

Views

WLAN view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If the MAC address of an AP is in the blacklist, the AP cannot go online. If the MAC address of an online AP added to the blacklist, the AP is brought offline.

Precautions

The AP blacklist and whitelist can be configured at the same time. However, the MAC address of an AP cannot be added to the AP blacklist and whitelist at the same time.

If the AP whitelist and blacklist are all configured, the system checks whether an AP is in the blacklist first.

Example

# Add the AP with the MAC address of 00e0-fc12-3456 to the AP blacklist.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap blacklist mac 00e0-fc12-3456
# Batch add APs with the MAC addresses ranging from 00e0-fc12-3456 to 00e0-fc12-3458 to the AP blacklist.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap blacklist mac 00e0-fc12-3456 to 00e0-fc12-3458
