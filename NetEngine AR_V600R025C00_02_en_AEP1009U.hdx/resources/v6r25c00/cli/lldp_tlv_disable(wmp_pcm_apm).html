lldp tlv-disable legacy-tlv power-capability

Function

The lldp tlv-disable legacy-tlv power-capability command configures an AP not to carry its supported working power in LLDPDUs.

The undo lldp tlv-disable legacy-tlv power-capability command configures an AP to carry its supported working power in LLDPDUs.

By default, LLDP packets sent by an AP carry the supported working power.

Format

lldp tlv-disable legacy-tlv power-capability

undo lldp tlv-disable legacy-tlv power-capability

Parameters

None

Views

AP wired port link profile view

Default Level

2: Configuration level

Usage Guidelines

When directly connected to a Huawei PoE switch, the AP can send its power capability to the switch through LLDP. If the total output power of a PoE switch exceeds the maximum threshold, the PoE switch can adjust the output power of the corresponding Ethernet port based on the working power of the AP. In this way, the output power can be reduced without affecting basic functions of the AP.

Example

# Disable an AP from sending LLDP packets carrying its supported working power.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] port-link-profile name port-link1
[HUAWEI-wlan-port-link-prof-port-link1] lldp tlv-disable legacy-tlv power-capability
