reset ap unauthorized record

Function

The reset ap unauthorized record command clears information about unauthenticated APs.

Format

reset ap unauthorized record

Parameters

None

Views

WLAN view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

You can clear the list of unauthenticated APs that have been removed or physically disconnected from the AC. This helps you collect statistics on and confirm unauthenticated APs.

Precautions

If an AP is physically connected to an AC and is in the unauthenticated state, the AP is added to the unauthenticated AP list after the reset ap unauthorized record command is executed.

Example

# Clear information about unauthenticated APs.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] reset ap unauthorized record
Warning: Clear unauthorized AP record, continue?[Y/N]:y
