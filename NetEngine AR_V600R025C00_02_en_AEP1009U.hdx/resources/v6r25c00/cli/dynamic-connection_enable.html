dynamic-connection enable

Function

The dynamic-connection enable command enables the dynamic connection establishment function.

The undo dynamic-connection enable command disables the dynamic connection establishment function.

By default, the dynamic connection establishment function is disabled on a device.

Format

dynamic-connection enable

undo dynamic-connection enable

Parameters

None

Views

Site view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In full-mesh networking, the number of connections at branch sites is limited, but only a few branches need to communicate with each other. In this case, the dynamic connection function can be enabled. However, due to the limited specifications of small models, tunnels cannot be established between some branches during peak hours, and traffic of these branches is still forwarded through the hub site.

Precautions

Before enabling the dynamic tunnel function, you must specify a hub site for forwarding traffic between spoke sites. Otherwise, this function does not take effect. Considering reliability and the importance of the hub site, you are advised to deploy dual gateways at the hub site or deploy multiple hub sites.

The hub site that forwards traffic between spoke sites refers to the redirect site specified on the controller in the full-mesh networking.

Such a hub site provides the following functions:

  • Forwards service traffic between spoke sites before direct tunnels are established.
  • Forwards service traffic between spoke sites when direct tunnels fail to be established due to the specification limitation or faults.

This function does not take effect to hub, RR, IWG, or gateway sites. This is because these sites are used to forward traffic or control channels and need to support route convergence. If such a site fails to establish tunnels, traffic needs to be switched to other hub sites, gateways, or IWG sites for forwarding. Therefore, these sites still need to establish tunnels before traffic transmission.

Example

# Enable the dynamic connection establishment function for a site.
<HUAWEI> system-view
[HUAWEI] evpn site 1
[HUAWEI-site-1] dynamic-connection enable
