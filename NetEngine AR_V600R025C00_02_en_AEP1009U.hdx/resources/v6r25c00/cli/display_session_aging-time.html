display session aging-time

Function

The display session aging-time command displays the aging time interval of entries in the session table.

Format

display session aging-time

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

This command displays the aging time session table.

Example

The actual command output varies according to the device. The command output here is only an example.

<HUAWEI> display session aging-time
