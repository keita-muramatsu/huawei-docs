export route-policy evpn

Function

The export route-policy evpn command associates the current VPN instance IPv4/IPv6 address family with an export route-policy to filter routes to be advertised to EVPN.

The undo export route-policy evpn command disassociates the current VPN instance IPv4/IPv6 address family from an export route-policy.

By default, the current VPN instance IPv4/IPv6 address family is not associated with any export route-policy.

Format

export route-policy policy-name [ add-ert-first ] evpn

undo export route-policy policy-name [ add-ert-first ] evpn

Parameters

Parameter Description Value
policy-name

Specifies the name of a route-policy.

The value is a string of 1 to 200 case-sensitive characters without spaces. The character string can contain spaces if it is enclosed with double quotation marks (").
add-ert-first

Adds export VPN targets to a VPN route before the route is sent to an EVPN instance based on an export route-policy.

-

Views

VPN instance IPv4 address family view, VPN instance IPv6 address family view, VPN instance view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

By default, the VPN instance IPv4/IPv6 address family adds all VPN targets in the export VPN target list to the routes to be advertised to EVPN. To more precisely control the routes to be advertised from the VPN instance IPv4/IPv6 address family to EVPN, run the export route-policy evpn command to associate the address family with an export route-policy and set attributes for eligible routes.

By default, export VPN targets are added to VPN routes after these routes are matched against an export route-policy. If the export route-policy contains VPN target-related filtering rules, it cannot apply to VPN routes. If you want to apply the VPN target-related filtering rules defined in an export route-policy to VPN routes, configure the add-ert-first parameter for the device to add export VPN targets to VPN routes before matching these routes against the export route-policy.

Prerequisites

An RD has been configured for the VPN instance IPv4/IPv6 address family using the route-distinguisher command.

Configuration Impact

The current VPN instance address family can be associated with only one import route-policy. If this command is run more than once, the latest configuration overrides the previous one.

The export route-policy command does not affect the export route-policy configured using the export route-policy command.

Precautions

If the specified route-policy does not exist, run the route-policy command to create the route-policy.

If the address family to which routes belong does not match that specified in the if-match clause of the referenced route-policy, the default behavior of the route-policy is permit. You can run the route-policy address-family mismatch-deny command to change the default behavior of the route-policy to deny.

After this command is run, the sending of VPN routes to the BGP EVPN address family may be affected.

Example

# Apply an export route-policy named policy-2 to the VPN instance named vrf1 to filter the routes advertised by the VPN instance IPv4 address family to EVPN.
<HUAWEI> system-view
[HUAWEI] route-policy policy-2 permit node 10
[HUAWEI-route-policy] quit
[HUAWEI] ip vpn-instance vrf1
[HUAWEI-vpn-instance-vrf1] ipv4-family
[HUAWEI-vpn-instance-vrf1-af-ipv4] route-distinguisher 100:1
[HUAWEI-vpn-instance-vrf1-af-ipv4] export route-policy policy-2 evpn
