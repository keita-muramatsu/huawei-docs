display license resource usage detail

Function

The display license resource usage detail command displays the license usage.

Format

display license resource usage detail

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

  • If centralized license control is enabled, you can run this command on the license server to view the usage of the license resource pool and the license usage on all license servers and license clients. You can also run this command on a license client to view the usage of the license resource pool and the license usage of the local AC.
  • If centralized license control is disabled, you can run this command to view the license usage of the local AC and backup AC.

Example

The actual command output varies according to the device. The command output here is only an example.

<HUAWEI> display license resource usage detail

Table 1 Description of the display license resource usage detail command output
Item Description
Remaining days

Remaining days of the backup license.
Used/Total resource

Resource usage ratio, that is, the ratio of the number of used licenses to the total number of license resources.
Total records

Number of statistics.
AC MAC

MAC address of the standby AC. Local AC indicates the local AC.
MAC

AC's MAC address.
License

Number of license resources loaded on the WAC.
Backup time

Time when the license is backed up.
Backup mode

Backup mode.

  • N+1.
  • HRP.
  • Dual-link.
Local License

Number of license resources loaded on the AC.
Current role

Role of the current AC.

  • server.
  • server (backup).
  • client.
Role

AC role.

  • server.
  • server (backup).
  • client.
State

State of the link between a license client and the license server.

  • normal: normal state.
  • fault: disconnected state.
Used

Number of license resources used on the AC.
Remain(days)

Number of remaining days during which the license resource pool is available after a license client is disconnected from the license server.
IP

IP address used by a license client to establish links.
