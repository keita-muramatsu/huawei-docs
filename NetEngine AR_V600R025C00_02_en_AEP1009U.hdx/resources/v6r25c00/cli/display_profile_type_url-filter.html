display profile type url-filter

Function

The display profile type url-filter command displays information about URL filtering profiles.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

display profile type url-filter

display profile type url-filter name name [ blacklist [ url url-text | host host-text ] | whitelist [ url url-text | host host-text ] ]

display profile type url-filter name name pre-defined [ category-id category-id | subcategory-id subcategory-id ]

Parameters

Parameter Description Value
name name

Displays information about a specified URL filtering profile.

The value is a string of characters and must be an existing URL filtering profile.
blacklist

Indicates the blacklist.

-
url url-text

Specifies a URL rule.

The value is a string of 4 to 255 and 6 to 255 case-sensitive characters, spaces not supported.
host host-text

Specifies a domain name rule.

The value is a string of 4 to 255 case-sensitive characters. If a rule contains spaces, use double quotation marks ("") to enclose the rule.

The value cannot contain the following special characters: /\#"?.
whitelist

Indicates the whitelist.

-
pre-defined

Indicates a predefined category.

-
category-id category-id

Specifies a category ID.

The value is an integer ranging from 1 to 100.
subcategory-id subcategory-id

Specifies a subcategory ID.

The value is an integer ranging from 101 to 60000.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To display information about URL filtering profiles, run the display profile type url-filter command.
