statistics enable (Layer 3 main interface view)

Function

The statistics enable command enables IPv4 and IPv6 traffic statistics collection on a Layer 3 main interface.

The undo statistics enable command disables IPv4 and IPv6 traffic statistics collection on a Layer 3 main interface.

By default, IPv4 or IPv6 traffic statistics collection is disabled on a Layer 3 main interface.

Format

statistics enable

undo statistics enable

Parameters

None

Views

10GE interface view, 25GE interface view, 40GE interface view, Cellular channel interface view, Eth-Trunk interface view, Ethernet interface view, Multi-GE interface view, GE optical interface view, GE electrical interface view, Cellular interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To check the network status or locate network faults, you can enable traffic statistics collection on Layer 3 main interfaces, so that statistics on incoming and outgoing traffic on these interfaces are collected.

To view the statistics, run the display this interface command in the interface view or the display interface command.

After the undo statistics enable command is run to disable traffic statistics collection on a Layer 3 main interface, traffic statistics on this interface are also cleared.

Precautions

  • Traffic statistics collection on Layer 3 main interfaces may affect the forwarding performance. For example, some interfaces may fail to forward packets at line speed when all interfaces are configured to forward packets at line speed. Therefore, use traffic statistics collection on Layer 3 main interfaces only when necessary.
  • Traffic statistics collection on Layer 3 main interfaces consumes ACL resources. If traffic statistics collection is enabled on too many Layer 3 main interfaces, other services may fail to obtain ACL resources.
  • Layer 3 main interfaces do not support error packet statistics collection, unicast and broadcast packet statistics collection, or bandwidth usage statistics collection.
  • The traffic statistics function of a cellular interface and a cellular channel interface can collect only IPv4 traffic statistics.

Example

# Enable traffic statistics collection on a Layer 3 main interface. 
<HUAWEI> system-view
[HUAWEI] interface 10GE0/0/1
[HUAWEI-10GE0/0/1] statistics enable
