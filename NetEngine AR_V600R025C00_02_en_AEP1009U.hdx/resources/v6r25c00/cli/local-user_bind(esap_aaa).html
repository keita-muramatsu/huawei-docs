local-user bind

Function

The local-user bind command specifies IPv4 or IPv6 trusted host addresses and masks for local administrators. A maximum of 15 IPv4 or IPv6 addresses can be specified.

The undo local-user bind command cancels the configuration.

By default, no trusted host IP address is configured.

Format

local-user username bind { ipv4-address netmask | ipv4-address ipv4-addr-mask | ipv6-address prefix-length | ipv6-addr-prefix }

undo local-user username bind { ipv4-address netmask | ipv4-address ipv4-addr-mask | ipv6-address prefix-length | ipv6-addr-prefix }

Parameters

Parameter Description Value
username

Specifies a user account, in the format of username@domainname. The username and domain name cannot contain the following characters: * ? \ ".

The value is a string of 1 to 253 case-sensitive characters. It cannot contain spaces.
ipv4-address

Specifies an IPv4 address.

The value is in dotted decimal notation.
netmask

Specifies the mask length of the specified IPv4 address.

The value is an integer that ranges from 1 to 32.
ipv4-addr-mask

Specifies the IPv4 address mask.

The value is in dotted decimal notation.
ipv6-address

Specifies an IPv6 address.

The value is a 128-bit hexadecimal number, in the format of X:X:X:X:X:X:X:X, with each X representing four hexadecimal numbers.
prefix-length

Specifies the prefix length of the IPv6 address.

The value is an integer ranging from 1 to 128.
ipv6-addr-prefix

Specifies the IPv6 address/prefix length (1-128).

The address is a 32-digit hexadecimal number in the format of X:X::X:X/M.

Views

AAA view

Default Level

3: Management level

Usage Guidelines

When creating a local administrator account, you can run this command to allow only users with specified IP addresses to log in using this account.

Example

# Specify an IP address range (10.156.0.0 to 10.156.255.255) for the local administrator admin to log in to the device. 
<HUAWEI> system-view
[HUAWEI] aaa
[HUAWEI-aaa] local-user admin bind 10.156.0.0 16
