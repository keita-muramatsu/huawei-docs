mac-address miss action discard

Function

The mac-address miss action discard command discards the packets that do not match MAC address entries in a VLAN.

The undo mac-address miss action discard command broadcasts the packets that do no match MAC address entries in a VLAN.

By default, the packets that do not match MAC address entries are broadcast in a VLAN.

Format

mac-address miss action discard

undo mac-address miss action discard

Parameters

None

Views

VLAN range view, VLAN view

Default Level

2: Configuration level

Usage Guidelines

After a DHCP user gets offline, its MAC address entries age out. If this user's packets are forwarded but cannot find a destination MAC address entry, the packets are broadcast to all interfaces in this VLAN. As a result, other users can obtain the packets, reducing data security. The mac-address miss action discard command reduces device loads and improves data security.

Example

# Enable the device to discard packets that do not match any MAC address entry in a VLAN.
<HUAWEI> system-view
[HUAWEI] vlan 100
[HUAWEI-vlan100] mac-address miss action discard
