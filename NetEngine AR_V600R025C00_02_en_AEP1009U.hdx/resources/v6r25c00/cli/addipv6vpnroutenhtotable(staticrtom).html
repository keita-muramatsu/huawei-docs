ipv6 route-static vpn-instance vpn-instance

Function

The ipv6 route-static vpn-instance vpn-instance command configures an IPv6 VPN static route with only a VPN instance specified for the next hop.

The undo ipv6 route-static vpn-instance vpn-instance command deletes an IPv6 VPN static route with only a VPN instance specified for the next hop.

By default, no IPv6 static routes are configured for an IPv6 address family-enabled VPN instance.

Format

ipv6 route-static vpn-instance srcvpn6-instance-name prefix prefix-length { vpn-instance dstvpn6-instance-name | public } [ preference preference-value | tag tag-value ] * [ description description-text ]

undo ipv6 route-static vpn-instance srcvpn6-instance-name prefix prefix-length { vpn-instance dstvpn6-instance-name | public }

Parameters

Parameter Description Value
srcvpn6-instance-name

Specifies the name of a source VPN instance.

The value is a string of 1 to 31 case-sensitive characters without spaces. The VPN instance name cannot be _public_. The character string can contain spaces if it is enclosed with double quotation marks (").
prefix

Specifies a destination IPv6 address.

The value is an IPv6 address ranging from :: to FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF.
prefix-length

Indicates the IPv6 mask length.

The value is an unsigned integer ranging from 0 to 128.
dstvpn6-instance-name

Specifies the name a destination VPN instance.

The value is a string of 1 to 31 case-sensitive characters without spaces. The VPN instance name cannot be _public_. The character string can contain spaces if it is enclosed with double quotation marks (").
public

Indicates the public network.

-
preference preference-value

Specifies the route preference.

The value is an integer ranging from 1 to 255. The default value is 60. A smaller value indicates a higher priority.
tag tag-value

Specifies the tag value of a static route. You can configure different tag values to classify static routes and implement different routing management policies.

The value is an integer ranging from 1 to 4294967295. The default value is 0.
description description-text

Indicates the description of a static route.

To view the descriptions of static routes, you can run the display this command in the system view or run the display current-configuration command.

The description keyword cannot be followed by other command parameters, such as bfd and preference. The content is only used as the description. For example, if ipv6 route-static 2001:db8:1::1 128 NULL0 description aa preference 10 is configured, aa preference 10 is used as the description.

The value is a string of 1 to 150 characters, spaces supported.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To configure static routes for a simple IPv6 VPN, run the ipv6 route-static vpn-instance command.

If the destination address and mask of a static route are all 0s, the static route is a default route.

Prerequisites

A VPN instance has been created using the ip vpn-instance command when you configure a static route for the VPN instance.

Before binding a static route to an NQA test instance, you need to create the NQA test instance.

Before binding a static route to an NQA group, you need to create the NQA group.

Follow-up Procedure

If a configured static route needs to be sent to the peer PE, import the static route into BGP running between the PEs.

Precautions

For static routes with the same prefix but different preferences, you can configure a static route with a specified next-hop IP address and a static route with only a VPN instance specified as the next hop; in addition, you can configure a static route with a specified outbound interface and a static route with only a VPN instance specified as the next hop; you can also configure multiple static routes with only VPN instances specified as next hops.

Example

# Configure for VPN instance vpn1 an IPv6 static route, with 2001:db8:1::2/128 as the destination address and VPN instance vpn2 as the next hop.
<HUAWEI> system-view
[HUAWEI] ip vpn-instance vpn1
[HUAWEI-vpn-instance-vpn1] ipv6-family
[HUAWEI-vpn-instance-vpn1-af-ipv6] quit
[HUAWEI] ip vpn-instance vpn2
[HUAWEI-vpn-instance-vpn2] ipv6-family
[HUAWEI-vpn-instance-vpn2-af-ipv6] quit
[HUAWEI] ipv6 route-static vpn-instance vpn1 2001:db8:1::2 128 vpn-instance vpn2
