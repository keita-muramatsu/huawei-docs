color

Function

The color command sets parameters of a WRED drop profile, including upper drop threshold, lower drop threshold, and maximum drop probability.

The undo color command restores the default settings of a WRED drop profile.

By default, the upper drop threshold, lower drop threshold, and maximum drop probability of a WRED drop profile are all 100.

Format

color blind low-limit low-limit-percentage high-limit high-limit-percentage discard-percentage discard-percentage

undo color blind

Parameters

Parameter Description Value
low-limit low-limit-percentage

Specifies the lower drop threshold. When the percentage of the packet count in a queue to the queue length reaches this value, packets start to be discarded.

The value is an integer that ranges from 0 to 100. The default value is 100. For the AR8000 series, AR6710-L26T2X4, AR6710-L50T2X4, AR6710-L14T2X4, and AR6710-H4T4X2Y7, the value must be 0, 12, 25, 37, 50, 62, 75, 87, or 100.
high-limit high-limit-percentage

Specifies the upper drop threshold. When the percentage of the packet count in a queue to the queue length reaches this value, all subsequent packets are discarded.

The value is an integer that ranges from low-limit-percentage to 100. The default value is 100. For the AR8000 series, AR6710-L26T2X4, AR6710-L50T2X4, AR6710-L14T2X4, and AR6710-H4T4X2Y7, the value must be 12, 25, 37, 50, 62, 75, 87, or 100.
discard-percentage discard-percentage

Specifies the maximum drop probability.

The value is an integer that ranges from 1 to 100. The default value is 100.
blind

Indicates WRED parameters for packets of all colors.

-

Views

Drop profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

  • When the queue length reaches the lower drop threshold, some packets are discarded.
  • When the queue length is between the lower drop threshold and the upper drop threshold, a longer queue linearly increases the drop probability until the maximum drop probability is reached.
  • When the queue length reaches the upper drop threshold, all subsequent packets in the queue are discarded. When congestion occurs, packets with the highest drop probability are discarded first.

Precautions

If you run the color command multiple times in the same drop profile view, only the latest configuration takes effect.

Example

# Configure WRED drop profile wred1 in which the lower drop threshold, upper drop threshold, and maximum drop probability are set to 75, 100, and 10 for packets of all colors.
<HUAWEI> system-view
[HUAWEI] drop-profile wred1
[HUAWEI-drop-wred1] color blind low-limit 75 high-limit 100 discard-percentage 10
