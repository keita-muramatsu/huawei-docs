tcpfpm enable

Function

The tcpfpm enable command enables the TCP FPM function.

The undo tcpfpm enable command disables the TCP FPM function.

By default, the TCP FPM function is disabled.

Format

tcpfpm enable

undo tcpfpm enable

Parameters

None

Views

Tunnel interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After the TCP FPM function is enabled, the device can collect network performance statistics of TCP applications, such as delay and packet loss rate. You can optimize the network based on the network performance.

Precautions

After the undo tcpfpm enable command is run, the display tcpfpm session all command can still display session data of the corresponding interface within the session aging period. You can run the display session aging-time command to view the session aging time.

Example

# Enable TCP FPM function.
<HUAWEI> system-view
[HUAWEI] interface Tunnel 0
[HUAWEI-Tunnel0] tcpfpm enable
