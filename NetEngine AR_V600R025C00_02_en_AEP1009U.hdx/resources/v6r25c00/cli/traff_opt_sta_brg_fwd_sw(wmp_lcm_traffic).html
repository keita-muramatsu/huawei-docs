traffic-optimize sta-bridge-forward disable

Function

The traffic-optimize sta-bridge-forward disable command disables an air interface from forwarding packets to bridging terminals.

The undo traffic-optimize sta-bridge-forward disable command enables an air interface to forward packets to bridging terminals.

By default, an air interface is enabled to forward packets to bridging terminals.

Format

traffic-optimize sta-bridge-forward disable

undo traffic-optimize sta-bridge-forward disable

Parameters

None

Views

Traffic profile view

Default Level

2: Configuration level

Usage Guidelines

Some terminals on the WLAN can provide bridging functions. The terminals associate with APs with their own MAC addresses and have multiple Layer 3 wired devices connected in the downlink direction. The connected Layer 3 wired devices can also obtain IP addresses and forward traffic through the APs. In this case, the APs consider that each associated terminal has multiple IP addresses. You can run this command to disable an air interface to forward packets to bridging terminals. This can reduce the number of packets transmitted on the air interface and improve the air interface performance.

Example

# Disable an air interface from forwarding packets to bridging terminals in the traffic profile p1.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] traffic-profile name p1
[HUAWEI-wlan-traffic-prof-p1] traffic-optimize sta-bridge-forward disable
