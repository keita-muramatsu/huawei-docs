standby timer delay

Function

The standby timer delay command sets the delay for switching traffic between the active and standby interfaces.

The undo standby timer delay command restores the default delay for switching traffic between the active and standby interfaces.

By default, the delay for switching traffic from the active interface to the standby interface is 0 seconds, and the delay for switching traffic from the standby interface to the active interface is 5 seconds.

Format

standby timer delay enable-delay disable-delay

undo standby timer delay [ enable-delay disable-delay ]

Parameters

Parameter Description Value
enable-delay

Specifies the delay for traffic to be switched from the active interface to the standby interface.

The value ranges from 0 to 65535, in seconds. The default value is 0.
disable-delay

Specifies the delay for traffic to be switched from the standby interface to the active interface.

The value ranges from 0 to 65535, in seconds. The default value is 5.

Usage Guidelines

Usage Scenario

When a device is upgraded or an active/standby switchover is performed, the interface status may become unstable. As a result, the active/standby switchover frequently occurs, which may cause network flapping. To prevent this problem, you can run the standby timer delay command to set the delay for active/standby interface switchover. After the active interface changes from up to down, the system does not switch services to the standby interface after the preset delay.

Prerequisites

The standby timer delay command can be run only after the standby track nqa command is run.

Precautions

The value of the switchover delay is very important. If the value is too small, network flapping may occur. If the value is too large, network traffic may be lost. Therefore, you need to set the delay based on the actual network environment.

On a network that does not have high requirements on data transmission, you can set a large switchover delay to prevent network flapping.

On a network that has high requirements on data transmission, you are advised to set the switchover delay to a small value to prevent data traffic loss.

Example

# In the scenario where interface backup is associated with NQA, set the delay for switching traffic to the standby interface to 5s, and the delay for switching traffic back to the active interface to 10s.
<HUAWEI> system-view
[HUAWEI] nqa test-instance user test
[HUAWEI-nqa-user-test] test-type icmp
[HUAWEI-nqa-user-test] quit
[HUAWEI] interface 10GE0/0/1
[HUAWEI-10GE0/0/1] standby track nqa user test
[HUAWEI-10GE0/0/1] standby timer delay 5 10
# In the scenario where interface backup is associated with a route monitoring group, set the delay for switching traffic to the standby interface to 5s, and the delay for switching traffic back to the active interface to 10s.
<HUAWEI> system-view
[HUAWEI] ip route-monitor-group test
[HUAWEI-route-monitor-group-test] monitor enable
[HUAWEI-route-monitor-group-test] quit
[HUAWEI] interface 10GE0/0/1
[HUAWEI-10GE0/0/1] standby track route-monitor-group test
[HUAWEI-10GE0/0/1] standby timer delay 5 10
