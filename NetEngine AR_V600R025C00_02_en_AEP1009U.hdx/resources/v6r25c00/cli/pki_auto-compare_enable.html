pki auto-compare enable

Function

The pki auto-compare enable command enables the automatic PKI verification function.

The undo auto-compare enable command disables the automatic PKI verification function.

By default, automatic verification is enabled.

Format

pki auto-compare enable

undo pki auto-compare enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

After PKI automatic reconciliation is enabled, the device compares PKI data of related services at a specified interval. You can run the display pki compare result command in the diagnostic view to check the PKI reconciliation result.

Example

# Enable automatic verification.
<HUAWEI> system-view
[HUAWEI] pki auto-compare enable
