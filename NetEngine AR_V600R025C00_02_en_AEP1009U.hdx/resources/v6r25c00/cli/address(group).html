address(group)

Function

The address command adds a member to an address group.

The undo address command deletes a member from an address group.

By default, this function is disabled.

Format

address [ id ] address-set address-set-name [ description description ]

undo address { id | all | address-set address-set-name }

Parameters

Parameter Description Value
id

Specifies a member ID.

The value is an integer ranging from 0 to 4095.
address-set address-set-name

Specifies an address object or an address group.

Only the address set whose type is group can contain another address set as an address set item.

The value is a string of 1 to 63 case-sensitive characters, spaces supported. If spaces are used, the string must be enclosed in double quotation marks (" ").
description description

Specifies an item description.

The value is a string of 1 to 63 characters, spaces supported.
all

Indicates all the members.

-

Views

Address group view

Default Level

2: Configuration level

Usage Guidelines

If the address command specifies an ID, and the address object or address group object corresponding to the ID exists, the new address information overwrites the original one.

Example

# Create two address groups and add set1 to set2. 
<HUAWEI> system-view
[HUAWEI] ip address-set set1 type group
[HUAWEI-group-address-set-set1] quit
[HUAWEI] ip address-set set2 type group
[HUAWEI-group-address-set-set2] address address-set set1
