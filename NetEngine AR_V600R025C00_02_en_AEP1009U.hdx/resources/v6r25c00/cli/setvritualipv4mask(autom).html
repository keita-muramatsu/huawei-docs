virtual-ipv4-address

Function

The virtual-ipv4-address command configures a virtual IP address for the net assistant function.

The undo virtual-ipv4-address command restores the default virtual IP address of the net assistant function.

By default, the virtual IP address is 10.231.10.253 and the mask is 255.255.255.0.

Format

virtual-ipv4-address ipv4-address virtual-ipv4-mask { ipv4-mask-num | ipv4-mask-address }

undo virtual-ipv4-address

Parameters

Parameter Description Value
ipv4-address

Specifies a virtual IP address.

The value is in dotted decimal notation.
virtual-ipv4-mask ipv4-mask-num

Specifies the mask length of a virtual IP address.

The value is an integer ranging from 0 to 32.
virtual-ipv4-mask ipv4-mask-address

Specifies the mask of a virtual IP address.

The value is in dotted decimal notation.

Views

Net-assistant view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

After the net assistant function is enabled, the system creates a virtual IP address (10.231.10.253) by default as the IP address for accessing WebMaster. You can also run this command to configure another virtual IP address as the IP address of WebMaster.

Precautions

After a new virtual IP address is configured using this command, the old virtual IP address cannot be used to access WebMaster.

Example

# Configure a virtual IP address and mask.
<HUAWEI> system-view
[HUAWEI] net-assistant
[HUAWEI-net-assistant] virtual-ipv4-address 192.168.1.1 virtual-ipv4-mask 255.255.255.0
