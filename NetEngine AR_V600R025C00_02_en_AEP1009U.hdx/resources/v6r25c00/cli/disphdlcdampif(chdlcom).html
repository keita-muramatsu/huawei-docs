display hdlc interface

Function

The display hdlc interface command displays HDLC link information on an interface.

Format

display hdlc interface [ { ifName | ifType ifNum } ]

Parameters

Parameter Description Value
ifName

Specifies the name of an interface.

-
ifType

Specifies the type of an interface.

-
ifNum

Specifies an interface number.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To check the HDLC link status of an interface, run the display hdlc interface command. The command output displays the interface name, HDLC link status, and remaining HDLC flapping dampening time.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display HDLC information of the specified pos0/0/0.
<HUAWEI> display hdlc interface pos0/0/0
-----------------------------------------------------------------------------------

Interface Name      HDLC State      Damping Reuse Time(sec)

-----------------------------------------------------------------------------------

Pos0/0/0             DOWN (damping)                                      5
# Display HDLC information.
<HUAWEI> display hdlc interface
-----------------------------------------------------------------
-----------------------------------------------------------------
Interface Name       HDLC State          Damping Reuse Time(sec)  
-----------------------------------------------------------------
Pos0/0/0             DOWN (damping)      177                       
Pos0/0/2             UP                  --                        
Pos0/0/3             DOWN                --
# Display HDLC information.
<HUAWEI> display hdlc interface
-----------------------------------------------------------------
-----------------------------------------------------------------
Interface Name       HDLC State          Damping Reuse Time(sec)  
-----------------------------------------------------------------
Serial0/0/6:0             DOWN (damping)      177
# Display HDLC information on Serial0/0/6:0.
<HUAWEI> display hdlc interface Serial0/0/6:0
-----------------------------------------------------------------------------------

Interface Name      HDLC State      Damping Reuse Time(sec)

-----------------------------------------------------------------------------------

Serial0/0/6:0             DOWN (damping)                                      5
Table 1 Description of the display hdlc interface command output
Item Description
Interface Name

Interface name.
HDLC State

HDLC link status:

  • UP: The HDLC link status is Up.
  • Down: The HDLC link status is Down.
  • -: Indicates the initial status value. The HDLC link status is not detected.
Damping Reuse Time(sec)

Remaining HDLC flapping dampening time, in seconds.
