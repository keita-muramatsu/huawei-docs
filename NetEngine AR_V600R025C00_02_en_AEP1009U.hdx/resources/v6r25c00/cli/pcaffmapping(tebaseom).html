attribute (Affinity attribute mapping view)

Function

The attribute command configures the mappings between affinity bit values and names.

The undo attribute command deletes the mappings between affinity bit values and names.

By default, no names are specified for affinity bits.

Format

attribute bit-name bit-sequence bit-number

undo attribute bit-name

Parameters

Parameter Description Value
bit-name

Specifies the name of an affinity bit.

The value is a string of 1 to 31 characters.
bit-sequence bit-number

Specifies the sequence number of an affinity bit.

The value is an integer ranging from 0 to 255. The value 0 indicates the least significant bit, whereas the value 255 indicates the most significant bit.

Views

Affinity attribute mapping view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Before configuring names for LSP affinity and link administrative group bits, mappings between affinity bits and names must be configured on each node that is used to select a path for a TE tunnel. To configure the mappings between affinity bit values and names, run the attribute command.

Prerequisites

An affinity name template has been created using the path-constraint affinity-mapping command.

Precautions

The mappings on each node must be the same to achieve semantic consistency during path computation.

The bit-number value ranges from 0 to 255. TE or SR Policy can reference only an affinity bit in the value range of 0 to 31. However, a Flex-Algo can reference any affinity bit in the value range of 0 to 255.

Example

# Name the third bit in an affinity yellow.
<HUAWEI> system-view
[HUAWEI] path-constraint affinity-mapping
[HUAWEI-pc-af-map] attribute yellow bit-sequence 3
