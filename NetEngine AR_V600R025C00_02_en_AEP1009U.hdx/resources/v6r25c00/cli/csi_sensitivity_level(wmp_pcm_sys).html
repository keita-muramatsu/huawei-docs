csi distance-sensitivity

Function

The csi distance-sensitivity command configures the distance sensing sensitivity level of the channel state information (CSI) sensing function for APs.

The undo csi distance-sensitivity command deletes the distance sensing sensitivity level of the CSI sensing function configured for APs.

By default, the distance sensing sensitivity level of the CSI sensing function is 100 in the AP system profile view, and not configured in the AP view. The configuration in the AP system profile takes effect.

Format

csi distance-sensitivity value

undo csi distance-sensitivity

Parameters

Parameter Description Value
distance-sensitivity value

Specifies the distance sensing sensitivity level. A larger value indicates a larger sensing range.

The value is an integer ranging from 0 to 100. The value 0 indicates the minimum sensing range, and the value 100 indicates the maximum sensing range.

Views

AP system profile view, AP view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The accuracy in sensing and identifying human is affected by the Wi-Fi signal strength in the collected CSI. Therefore, in different environments, a proper distance sensing sensitivity level needs to be configured based on characteristics such as the space structure and wall material.

  • In open scenarios, the recommended value is 100.
  • In non-open scenarios such as conference rooms, if concrete walls are used, the recommended distance sensing sensitivity level is 100. If partition walls are made of materials that Wi-Fi signals can easily penetrate, such as glass, thin wood, or gypsum board, the distance sensing sensitivity level needs to be adjusted using the CloudCampus APP based on the distance between the AP and walls and the signal attenuation of walls. For details, see the CloudCampus APP Usage Guide. This prevents incorrect detection caused by disturbances outside walls.
  • In V600R025C00 and later versions, APs support the configuration of the sensing distance range, which is recommended in scenarios such as square conference rooms to simplify the configuration. For details, see the network planning guide.

Precautions

Both the csi distance-sensitivity and csi distance-range commands can be used to limit the sensing range. If both of them are configured, the sensing range is limited by the configurations of both commands. The sensing range is the intersection of the two command configurations. You are advised to use the csi distance-range command to limit the sensing range.

Example

# Set the distance sensing sensitivity level of the CSI sensing function to 60 for APs at a single site.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name test
[HUAWEI-wlan-ap-system-prof-test] csi distance-sensitivity 60
