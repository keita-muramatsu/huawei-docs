dns server bind local-ip

Function

The dns server bind local-ip command configures a local IP address and a VPN instance to be bound to a DNS relay for communicating with a DNS client.

By default, no local IP address or VPN instance is bound to a DNS relay for communicating with a DNS client.

Format

dns server bind local-ip ip-address [ vpn-instance vpn-instance-name ]

undo dns server bind local-ip [ ip-address [ vpn-instance vpn-instance-name ] ]

Parameters

Parameter Description Value
ip-address

Specifies a local IP address to be bound to a DNS relay.

The value is in dotted decimal notation.
vpn-instance vpn-instance-name

Specifies the name of a VPN instance to be bound to a DNS relay.

The value is a string of 1 to 31 case-sensitive characters, spaces not supported. The VPN instance name cannot be _public_. If the character string is quoted by double quotation marks, the character string can contain spaces.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If no local IP address is bound to a DNS relay, security risks may exist. After the command is run to configure a local IP address to be bound to a DNS relay, the DNS relay processes only the DNS request packets and DNS response packets received from the configured local IP address. A maximum of 10 commands can be configured.

Precautions

This command takes effect immediately after being locally configured. Pay attention to the following points:

  • If no IPv6 address is configured, the client processes all IPv6 DNS request packets.
  • Ensure that the configured IPv6 address is the address of the local device (that is, this address is the address of a physical interface or logical interface on the device).
  • Ensure that the VPN specified for the configured IPv6 address is the VPN of the interface with the configured IPv6 address. If no VPN is specified, the configured IPv6 address belongs to the public network by default.

Example

# Configure a local IP address to be bound to a DNS relay.
<HUAWEI> system-view
[HUAWEI] dns server bind local-ip 10.1.1.1
