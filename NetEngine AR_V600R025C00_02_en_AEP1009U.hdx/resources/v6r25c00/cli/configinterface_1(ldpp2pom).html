mpls ldp timer hello-hold (Interface view)

Function

The mpls ldp timer hello-hold command sets the Hello hold timer value.

The undo mpls ldp timer hello-hold command restores the default Hello hold timer value.

By default, the link-Hello hold timer value is 15s, and the target-Hello hold timer value is 45s.

Format

mpls ldp timer hello-hold interval

undo mpls ldp timer hello-hold

Parameters

Parameter Description Value
interval

Specifies the Hello hold timer value.

The value is an integer ranging from 3 to 65535, in seconds. If the interval is set to 65535, it indicates that the LDP session never times out. In this case, the interval for sending Hello packets is 21845s (65535/3). If the mpls ldp timer hello-send command is run, the interval is the configured value.

Views

10GE sub-interface view, 10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE sub-interface view, 40GE interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, Ethernet sub-interface view, Ethernet interface view, GE optical interface view, GE interface view, GE electrical interface view, MP-group interface view, Multi-GE sub-interface view, Multi-GE interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

LDP peers that have established Hello adjacencies periodically send Hello messages to each other to indicate that they want to maintain the adjacency. If no Hello message is received after the link Hello hold timer expires, the Hello adjacency is torn down.

The default value is recommended. On a network with unstable links or a large number of packets, increase the value of the link Hello hold timer, preventing a local LDP session from being torn down and set up frequently.

Hello hold timers are classified into the following types:

  1. Link-Hello hold timer: maintains the local adjacency. The mpls ldp timer hello-hold command in the interface view sets a value of the timer.
  2. Target-Hello hold timer: maintains the remote adjacency. The mpls ldp timer hello-hold command in the remote MPLS LDP peer view sets a value of the timer.

    Note:

    The value of the timer that takes effect is the smaller one of the Hello holder timer values configured on both ends of an LDP session.

Prerequisites

MPLS LDP has been enabled on the associated interface.

Configuration Impact

After the mpls ldp timer hello-hold command is run, the Hello hold timer value is the smaller one of the Hello holder timer values configured on both ends of an LDP session.

Precautions

If the Hello hold timer value negotiated by the two ends of an LDP session is less than 9 seconds, the effective timer value is 9 seconds. It is recommended that the negotiated value of the Hello hold timer on both ends be greater than or equal to 15s. Otherwise, session flapping may occur during an active/standby switchover.

Example

# Set the link-Hello hold timer value to 60s. 
<HUAWEI> system-view
[HUAWEI] mpls
[HUAWEI-mpls] mpls ldp
[HUAWEI-mpls-ldp] quit
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] mpls
[HUAWEI-10GE0/0/1] mpls ldp
[HUAWEI-10GE0/0/1] mpls ldp timer hello-hold 60
