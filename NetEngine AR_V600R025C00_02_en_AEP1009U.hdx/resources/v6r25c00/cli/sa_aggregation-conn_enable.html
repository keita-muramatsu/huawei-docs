sa aggregation-conn enable

Function

The sa aggregation-conn enable command enables connection-based application traffic aggregation on an interface.

The undo sa aggregation-conn enable command disables connection-based application traffic aggregation on an interface.

By default, connection-based application traffic aggregation is disabled on an interface.

Format

sa aggregation-conn enable

undo sa aggregation-conn enable

Parameters

None

Views

Tunnel interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In the SD-WAN scenario, to aggregate connection-based application traffic on an interface so that traffic data can be reported through telemetry, you must enable connection-based application traffic aggregation on the interface. Otherwise, the device cannot identify applications based on connections and collect statistics on application traffic.

Prerequisites

  • The SD-WAN tunnel encapsulation protocol has been configured for a tunnel interface using The tunnel-protocol SD-WAN command in The tunnel interface view.
  • Application identification has been enabled using the sa enable command on The tunnel interface.

Precautions

To use telemetry to report application traffic aggregation statistics, you need to configure telemetry to subscribe to EVPN link application statistics.

Example

# Enable connection-based application traffic aggregation on an interface.
<HUAWEI> system-view
[HUAWEI] interface tunnel 1
[HUAWEI-tunnel1] tunnel-protocol sd-wan
[HUAWEI-tunnel1] sa enable
[HUAWEI-tunnel1] sa aggregation-conn enable
