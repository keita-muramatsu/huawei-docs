display remote-unit

Function

The display remote-unit command displays information about an RU.

Format

display remote-unit [ connect-interface { interface-name | interface-type interface-number } | name remote-unit-name ] [ verbose ]

display remote-unit { connect-interface { interface-name | interface-type interface-number } | name remote-unit-name } verbose realtime

Parameters

Parameter Description Value
connect-interface interface-name

Specifies the name of an interface.

The value is a string of 1 to 31 characters and must be set according to the device configuration.
connect-interface interface-type interface-number

Specifies the type and number of an interface.

The value a string of 1 to 31 characters and must be set according to the device configuration.
name remote-unit-name

Specifies the alias of an RU.

The value is a string of 1 to 32 case-sensitive characters. It cannot contain spaces.
verbose

Displays detailed information.

-
realtime

Displays real-time information.

-
realtime

Displays real-time information.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

This command can be used to check real-time information about an RU, including the ESN, alias, MAC address, device type, online duration, and firmware version of the RU.

Table 1 Description of the display remote-unit command output
Item Description
ESN

ESN of the RU.
Name

Alias of the RU. If the RU does not have an alias, a hyphen (-) is displayed.
ID

ID of the RU. If no ID is configured for the RU, a hyphen (-) is displayed.
Device mac

System MAC address of the RU.
Device type

Device type of an RU.
Item

Code of the RU.
Manufacture Date

Manufacturing date of the RU.
Up time

Online duration of the RU.
APP version

App firmware version.
APP Name

APP firmware type:

• APP: APP firmware.

• APP1: APP1 firmware. Only the S5751-L series RUs support this value.

• APP2: APP2 firmware. Only the S5731I-L series RUs support this value.
POE version

PoE firmware version.
POE Name

PoE firmware type:

• POE: PoE firmware. Only the S5751-L series RUs support this value.

• POE3: PoE3 firmware. Only the S5751-L series RUs support this value.

• POE5: PoE5 firmware. Only the S5751-L series RUs support this value.

• POE6: PoE6 firmware. Only the S5751-L series RUs support this value.

• POE7: PoE7 firmware. Only the S5751-L series RUs support this value.

• POE81: PoE81 firmware. Only the S5751-L series RUs support this value.

• POE82: PoE82 firmware. Only the S5751-L series RUs support this value.

• POE83: PoE83 firmware. Only the S5751-L series RUs support this value.
BIOS version

BIOS firmware version.
BIOS Name

BIOS firmware type:

• BIOS: BIOS firmware.

• BIOS1: BIOS1 firmware. Only the S5751-L series RUs support this value.
Connect interface

Access interface of the RU on the central device. If a physical interface is added to an Eth-Trunk, the Eth-Trunk interface is displayed.
Disk usage

Disk usage of the RU.
Disk space(MB)

Disk size of the RU.
Memory usage

Memory usage of the RU.
CPU usage

CPU usage of an RU. Only the S5751-L series RUs support the display of CPU usage.
Fan speed

Fan speed percentage of an RU. There are 10 levels ranging from 0% to 100%. Every 10% goes up a level. If the RU has no fan, a hyphen (-) is displayed.
Temperature

Current temperature of the RU.
Mac usage

MAC address usage of the RU.
Status

Status of the RU. The options are as follows:

• Unknown: The status is unknown.

• Idle: The RU is in the aging state.

• Normal: The RU is online.

• Upgrading: The RU is being upgraded.

• Configuring: The RU is being configured.

• Abnormal: The RU is online but the link is abnormal or exceeds the specifications.

• Offline: The RU is offline.

• BackupMisconf: The directly connected interface is incorrectly configured as a backup interface in scenarios with active and standby links.
Version match

Whether the firmware version of the RU matches that of the central device. The options are as follows:

YES: The firmware version of the RU matches that of the central device.

NO: The firmware version of the RU does not match that of the central device. (If the PoE firmware upgrade result is No Need Upgrade in the display remote-unit upgrade record command output and the versions of other types of firmware (BIOS and APP) are upgraded successfully or the same, it is normal and the RU can be used normally. For details, see the RU Firmware Upgrade Exception.).
Version support

Whether the RU supports the firmware of the central device:

• YES: compatible.

• NO: incompatible.
Authen Result

Authentication result of an RU:

• Success: Authentication is successful.

• Authenticating: Authentication is in progress.

• Fail: Authentication fails.

• -: Authentication is not performed.
Total: m, printed: n

The total number of entries is m, and the number of displayed RUs is n.
