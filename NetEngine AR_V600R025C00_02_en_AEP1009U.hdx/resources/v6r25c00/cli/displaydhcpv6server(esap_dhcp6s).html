display dhcpv6 server

Function

The display dhcpv6 server command displays the configuration of the interface enabled with the DHCPv6 server function.

Format

display dhcpv6 server [ interface { interface-name | interface-type interface-number } ]

Parameters

Parameter Description Value
interface interface-type interface-number

Displays information about the DHCPv6 server with a specified interface type and number.

-
interface interface-name

Displays information about the DHCPv6 server with a specified interface name.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To check the configuration of the interface enabled with the DHCPv6 server function, run the display dhcpv6 server command.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the configurations of all interfaces enabled with the DHCPv6 relay function.
<HUAWEI> display dhcpv6 server
 Interface                                DHCPv6 pool
 Vlanif100                                pool1
# Display information about the DHCPv6 server on a specified interface.
<HUAWEI> display dhcpv6 server interface Vlanif 100
 Interface               : Vlanif100
 DHCPv6 pool             : pool1
 Preference              : 0
 Allow-hint              : Disabled
 Rapid-commit            : Disabled
 Unicast                 : Disabled
Table 1 Description of the display dhcpv6 server command output
Item Description
Interface

Name of the interface enabled with the DHCPv6 server function.
DHCPv6 pool

Name of the IPv6 address pool configured on the interface.

This parameter is configured using the dhcpv6 server command.
Preference

Server priority carried in Advertise messages sent by the DHCPv6 server.

This parameter is configured using the dhcpv6 server (interface view) command.
Allow-hint

Whether the DHCPv6 server allocates addresses, prefixes, and prefix lengths based on the DHCPv6 client requests.

This parameter is configured using the dhcpv6 server (interface view) command.
Rapid-commit

Whether the server supports fast prefix allocation.

This parameter is configured using the dhcpv6 server (interface view) command.
Unicast

Whether unicast communication is performed between the client and server during address renewal.

This parameter is configured using the dhcpv6 server (interface view) command.
