display engine state

Function

The display engine state command displays the ASE status.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

display engine state [ slot slot-id cpu cpu-id ]

Parameters

Parameter Description Value
slot slot-id

Specifies the slot ID used by the application security service to process subcards.

The value is an integer, and the value range depends on the device configuration.
cpu cpu-id

Specifies the ID of a CPU.

The value is an integer, and the value range depends on the device configuration.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

This command is used to display the ASE status. The ASE status can be:

  1. When the ASE works normally, the message "The engine is working normally" is displayed.
  2. After the engine bypass command is delivered, the message "The engine is administratively bypassed" is displayed.
  3. After the engine stop command is delivered, the message "The engine is administratively stopped" is displayed.
  4. When the ASE engine detects that the system memory is insufficient, the message "The engine is overloaded" is displayed.
  5. When the engine restarts for multiple times in a short period of time, the minimum set mode is automatically used. In this case, some content security services are disabled and the message "The engine(mini-mode) is working normally" is displayed.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the ASE status.
<HUAWEI> display engine state
 Slot 0, CPU 0: The engine is administratively bypassed.
 The action is bypass when the engine is overloaded.
Table 1 Description of the display engine state command output
Item Description
Slot 0, CPU 0: The engine is working normally.

The ASE on CPU 0 in slot 0 works normally.
The action is bypass when the engine is overloaded

When the ASE is overloaded, traffic is bypassed.
