reach-max-sta

Function

The reach-max-sta command controls access of new STAs when the number of STAs connected to a VAP reaches the maximum value.

The undo reach-max-sta command restores the default configuration.

By default, when the number of access users reaches the maximum, automatic SSID hiding is enabled and the function of replacing low-priority STAs with high-priority STAs is disabled.

Format

reach-max-sta { hide-ssid disable | priority-replace }

undo reach-max-sta

Parameters

Parameter Description Value
hide-ssid

Automatically hides SSIDs.

-
disable

Disables the automatic SSID hiding function.

-
priority-replace

Enables the function of replacing low-priority STAs with high-priority STAs.

-

Views

SSID profile view

Default Level

2: Configuration level

Usage Guidelines

When the number of access users on a VAP reaches the maximum, two functions are available to control access of new users, including roaming users. The two functions are mutually exclusive.

  • Automatic SSID hiding: New users cannot search for the SSID of the VAP and are steered to connect to other VAPs.
  • Replacing low-priority users with high-priority users: If a new user is a VIP user, a common user is replaced to preferentially guarantee the access experience of the VIP user.

Example

# Disable automatic SSID hiding when the number of access users reaches the maximum.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ssid-profile name ssid1
[HUAWEI-wlan-ssid-prof-ssid1] reach-max-sta hide-ssid disable
