frame-format(E1 interface view)

Function

The frame-format command sets the frame format of an interface.

The undo frame-format command restores the default configuration.

By default, the frame format of an interface is non-CRC4.

This command is supported only on the AR8700 series, AR5710-S10T1X2, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series and AR6700-H series.

Format

frame-format { crc4 | no-crc4 }

undo frame-format [ crc4 ]

Parameters

Parameter Description Value
crc4

Sets the frame format to CRC4.

-
no-crc4

Sets the frame format of the interface to non-CRC4.

-

Views

E1 interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

A CE1 interface supports two frame formats: CRC4 and non-CRC4.

  • The CRC4 frame format is a multiframe formed by using the first bit of timeslot 0 and contains 16 consecutive PCM frames.
  • The non-CRC4 frame format is a basic frame format, which is also called a dual-frame format or an odd/even frame format.

    The CRC4 frame format supports 4-bit cyclic redundancy check (CRC) for physical frames, but the basic frame format does not.

Prerequisites

This command can be run only when the interface works in CE1 mode (configured through the using ce1 command).

Precautions

You can run this command only when the device supports E1 interfaces.

If the working mode of an interface is changed from CE1 to E1, the frame-format configuration on the interface is deleted.

Example

# Set the frame format of E1 0/0/0 to CRC4.
<HUAWEI> system-view
[HUAWEI] controller e1 0/0/0
[HUAWEI-E1 0/0/0] frame-format crc4
