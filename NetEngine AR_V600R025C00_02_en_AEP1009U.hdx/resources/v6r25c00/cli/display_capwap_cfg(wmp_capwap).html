display capwap configuration

Function

The display capwap configuration command displays the CAPWAP configuration.

Format

display capwap configuration

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run this command to query the CAPWAP heartbeat detection interval and number of detection times.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the CAPWAP configuration.
<HUAWEI> display capwap configuration
  ---------------------------------------------------------------                                                                   
  Source interface                                 : vlanif 100                                                                     
  Echo interval(seconds)                           : 25                                                                             
  Echo times                                       : 6
  Control priority(server to client)               : 6                                                                              
  Control priority(client to server)               : 5                                                                              
  Control-link DTLS encrypt                        : disable                                                                         
  DTLS PSK value                                   : ******                                                                         
  DTLS no-auth status                              : disable                                                                        
  DTLS cert-mandatory-match status                 : enable                                                                        
  DTLS version1.0 status                           : disable                                                                         
  DTLS cbc status                                  : disable                                                                         
  ---------------------------------------------------------------
Table 1 Description of the display capwap configuration command output
Item Description
Source interface

CAPWAP source interface.
Echo interval(seconds)

Interval for sending Keepalive packets.
Echo times

Number of times for sending Keepalive packets, which is used to determine whether the link is disconnected. If no response is received after the specified number of times, the link is considered disconnected.
Control priority(server to client)

Priority of CAPWAP management packets from a WAC to APs.

To configure the parameter, run the capwap control-link-priority local priority-value command.
Control priority(client to server)

Priority of CAPWAP management packets sent from APs to a WAC.

To configure the parameter, run the capwap control-link-priority remote priority-value command.
DTLS PSK value

PSK for DTLS encryption.
DTLS no-auth status

Whether to enable the function of establishing CAPWAP DTLS sessions in none authentication mode.
DTLS cert-mandatory-match status

Whether the function of establishing CAPWAP DTLS sessions through the initial certificate is enabled.
DTLS version1.0 status

Specifies whether DTLS 1.0 is compatible.
DTLS cbc status

Indicates whether the DTLS CBC encryption suite is compatible.
Control-link DTLS encrypt

Whether DTLS encryption for CAPWAP control tunnels is enabled.
