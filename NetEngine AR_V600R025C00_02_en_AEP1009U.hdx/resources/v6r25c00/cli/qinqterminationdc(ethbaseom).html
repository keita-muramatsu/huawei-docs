qinq termination pe-vid ce-vid(sub-interface view)

Function

The qinq termination pe-vid ce-vid command enables VLAN tag termination for double-tagged packets.

The undo qinq termination pe-vid ce-vid command disables VLAN tag termination for double-tagged packets.

By default, VLAN tag termination for double-tagged packets is disabled.

Format

qinq termination pe-vid pevid ce-vid cevid

undo qinq termination pe-vid pevid ce-vid cevid

Parameters

Parameter Description Value
pevid

Specifies the start VLAN ID in the outer VLAN tag.

The value is an integer ranging from 1 to 4094.
cevid

Specifies a start VLAN ID in an inner tag.

The value is an integer ranging from 1 to 4094.

Views

10GE sub-interface view, 25GE sub-interface view, 40GE sub-interface view, Eth-Trunk sub-interface view, Ethernet sub-interface view, GE sub-interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

  • Communication between VLANs:

    VLANs are widely used because they can separate users' Layer 2 packets. With the VLAN technology, a physical LAN is divided into multiple logical broadcast domains (VLANs). Hosts in the same VLAN can communicate with each other at Layer 2, but hosts in different VLANs cannot. The Layer 3 routing technology must be used to enable inter-VLAN communication.

    Currently, the following two methods can be used:
    • Through a VLANIF interface on a Layer 3 switch.
    • Through Layer 3 Ethernet interfaces on routers.

      However, traditional Layer 3 Ethernet interfaces do not support VLAN packets. When such an interface receives VLAN packets, it discards these packets as unauthorized packets. To enable inter-VLAN communication, you can create Ethernet sub-interfaces on Layer 3 Ethernet interfaces and deploy VLAN tag termination on these sub-interfaces, so that they can remove tags from VLAN packets.
  • Interconnection between LANs and WANs:

    Most LAN packets carry VLAN tags. Certain WAN protocols such as Point-to-Point Protocol (PPP) cannot identify VLAN packets. In this situation, before sending a VLAN packet from a LAN to a WAN, a device needs to record VLAN information in and removes VLAN tags from the packet.

    Based on the number of VLAN tags, VLAN packets are classified into dot1q packets (single-tagged packets) and QinQ packets (double-tagged packets). Accordingly, there are two VLAN tag termination modes:
    • Dot1q termination, which terminates tags carried in dot1q packets. To configure dot1q termination, run the dot1q termination vid command in the sub-interface view.
    • QinQ termination, which terminates tags carried in QinQ packets. To configure QinQ termination, run the qinq termination pe-vid ce-vid command.

Configuration Impact

After this command is run, the VLAN tag termination sub-interface processes packets as follows:

  • It removes the tags in received packets before forwarding these packets at Layer 3. Whether the forwarded packets carry tags is determined by the outbound interface.
  • It adds related VLAN information to packets before sending these packets.

After the qinq termination pe-vid ce-vid command is run on a sub-interface, the encapsulation qinq-termination command configuration is automatically generated on the sub-interface. After the undo qinq termination pe-vid ce-vid command is run on a sub-interface, the encapsulation qinq-termination command configuration is automatically deleted from the sub-interface.

Precautions

For sub-interfaces on the same main interface, the pe-vid value of one sub-interface must be different from the vid value for dot1q VLAN tag termination of another sub-interface.

Example

# Set the encapsulation mode on 10GE 0/0/1.1 to QinQ and allow packets with the outer VLAN ID of 100 and inner VLAN ID of 200 to pass through. 
<HUAWEI> system-view
[HUAWEI] interface 10GE0/0/1.1
[HUAWEI-10GE0/0/1.1] qinq termination pe-vid 100 ce-vid 200
