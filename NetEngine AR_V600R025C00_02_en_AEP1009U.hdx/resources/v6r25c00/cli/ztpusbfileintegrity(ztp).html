ztp usb-deployment file-integrity password

Function

The ztp usb-deployment file-integrity password command configures the password for verifying the USB-based deployment file.

The undo ztp usb-deployment file-integrity password command deletes the password for verifying the USB-based deployment file.

By default, no password for verifying the integrity of the USB-based deployment file is configured.

Format

ztp usb-deployment file-integrity password hmacpasswordval

ztp usb-deployment file-integrity password

undo ztp usb-deployment file-integrity password

Parameters

Parameter Description Value
hmacpasswordval

Specifies the file integrity check password for USB-based deployment.

If this parameter is not specified, you need to configure the integrity check password during command interaction.

The value is a string of case-sensitive characters without spaces or question marks (?). It is a string of 32 to 64 characters in plain text or a string of 148 to 188 characters in reversible cipher text. However, if the string is enclosed in double quotation marks (" "), it can contain spaces. The password consists of at least three types of the following: uppercase letters, lowercase letters, digits, and special characters.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To ensure the security of the deployment file, you can calculate a hash value for the deployment file based on the configured HMAC key before USB-based deployment and write the hash value to the HMAC field in the USB-based deployment intermediate file. During USB-based deployment, after the device downloads the deployment file, the device uses the integrity verification password configured using this command as the HMAC key to calculate the hash value of the deployment file. If this hash value is the same as the value of the HMAC field in the deployment intermediate file, the deployment file is complete and the deployment can be performed properly. If they are different, the deployment file is damaged and the deployment fails.

The integrity verification password configured on the device must be the same as the HMAC key set before the deployment.

After the weak password dictionary maintenance function is enabled, the passwords defined in the weak password dictionary cannot be used. You can run the display security weak-password-dictionary command to view the passwords.

Precautions

If the password parameter is not specified, you need to configure the integrity verification password during command interaction.

Example

# Configure the password for verifying the integrity of the USB-based deployment file.
<HUAWEI> system-view
[HUAWEI] ztp usb-deployment file-integrity password YsHsjx_202206yshsjxofficeufythdk
# Set the password for verifying the integrity of files in the USB flash drive (interactive command).
<HUAWEI> system-view
[HUAWEI] ztp usb-deployment file-integrity password
Please enter password:***************************************
Please confirm password:***************************************
