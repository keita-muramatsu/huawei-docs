priority

Function

The priority command configures a priority for a NETCONF connection instance.

The undo priority command deletes the priority of a NETCONF connection instance.

By default, no priority is configured for a NETCONF connection instance.

Format

priority priority-val

undo priority

Parameters

Parameter Description Value
priority priority-val

Specifies the priority of a NETCONF connection instance.

The value is of the enumerated type.

  • low: low priority.
  • medium: medium priority.
  • high: high priority.

Views

Endpoint view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

  • If the selection mode of a NETCONF connection instance is set to priority, the NETCONF connection instance with the specified priority is selected to establish a connection. You can run this command to specify a priority for a NETCONF connection instance.
  • Priorities are in the sequence of high > medium > low. If NETCONF connection instances have the same priority, they are selected based on VPN names, then IP addresses, and finally port numbers.
    • Priorities of VPN names: A public VPN has a higher priority than a private VPN. The priorities of private VPNs are sorted in the lexicographic order (ASCII code) of VPN names.
    • Priorities of IP addresses: An IPv4 address has a higher priority than an IPv6 address. IP addresses of the same type are sorted in ascending order.
    • Priorities of port numbers: Port numbers are sorted in ascending order.

Prerequisites

Before configuring a priority for a NETCONF connection instance, run the work-endpoint select-mode command in the callhome view to set the selection mode of the NETCONF connection instance to priority. Otherwise, the priority command cannot be delivered.

Precautions

If no priority is configured for a NETCONF connection instance, the instance has a low priority.

Example

# Set the priority of a NETCONF connection instance to medium.
<HUAWEI> system-view
[HUAWEI] netconf
[HUAWEI-netconf] callhome root
[HUAWEI-netconf-callhome-root] work-endpoint select-mode priority
[HUAWEI-netconf-callhome-root] endpoint huawei
[HUAWEI-netconf-callhome-root-endpoint-huawei] priority medium
