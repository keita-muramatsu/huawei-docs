cipher-suite (DTLS server view)

Function

The cipher-suite command configures a cipher suite for a DTLS server.

The undo cipher-suite command restores the default cipher suite for a DTLS server.

By default, a DTLS server uses cipher suites of ecdhe_rsa_aes128_gcm_sha256 and ecdhe_rsa_aes256_gcm_sha384.

Format

cipher-suite { ecdhe_rsa_aes128_gcm_sha256 | ecdhe_rsa_aes256_gcm_sha384 | rsa_aes_128_sha256 } *

undo cipher-suite

Parameters

Parameter Description Value
ecdhe_rsa_aes128_gcm_sha256

Indicates the ecdhe_rsa_aes128_gcm_sha256 cipher suite. This cipher suite uses the key exchange algorithm ECDHE RSA, 128-bit data encryption algorithm AES_GCM, and MAC algorithm SHA2-256.

-
ecdhe_rsa_aes256_gcm_sha384

Indicates the ecdhe_rsa_aes256_gcm_sha384 cipher suite. This cipher suite uses the key exchange algorithm ECDHE RSA, 256-bit data encryption algorithm AES_GCM, and MAC algorithm SHA2-384.

-
rsa_aes_128_sha256

Indicates the rsa_aes_128_sha256 cipher suite. This cipher suite uses the key exchange algorithm RSA, 128-bit data encryption algorithm AES_CBC, and MAC algorithm SHA2-256.

-

Views

DTLS server view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When the device functions as a DTLS server, it needs to be configured with a cipher suite.

A cipher suite consists of information such as data encryption algorithm, key exchange algorithm, and MAC algorithm. During a DTLS handshake, a DTLS client sends a Client Hello message to notify the supported DTLS protocol version and cipher suite to a DTLS server. The DTLS server determines the DTLS protocol version and cipher suite used for this communication and sends a Server Hello message to the DTLS client.

The cipher-suite command configures the cipher suite that the device can use when it functions as a DTLS server. The DTLS server then determines the cipher suite used for this communication based on the configured cipher suite and the cipher suite carried in the received Client Hello message.

Precautions

For security purposes, it is not recommended that you set the cipher suite to rsa_aes_128_sha256.

The rsa_aes_128_sha256 parameter in this command can be used only after the weak security algorithm/protocol feature package has been installed by running the install feature-software WEAKEA command.

When a device functioning as a DTLS server establishes a link with a NetEngine AR router running V300R019C00 or V300R019C10 and functioning as a DTLS client, you need to configure the rsa_aes_128_sha256 cipher suite.

Example

# Configure a cipher suite for a DTLS server.
<HUAWEI> system-view
[HUAWEI] dtls server
[HUAWEI-dtls-server] cipher-suite ecdhe_rsa_aes256_gcm_sha384
