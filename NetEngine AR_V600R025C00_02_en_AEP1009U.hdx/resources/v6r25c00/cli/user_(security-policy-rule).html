user (Security policy rule view)

Function

The user command configures UCL group and user information carried in packets as matching conditions of a security policy.

The undo user command deletes the UCL configuration and user information from a security policy.

By default, this function is not configured.

Format

user { ucl-group ucl-group-name | username username }

undo user { ucl-group ucl-group-name | username username }

undo user all

Parameters

Parameter Description Value
ucl-group ucl-group-name

Indicates the UCL group referenced by a security policy rule.

The value is a string of 1 to 759 case-sensitive characters and can contain spaces. If the value contains spaces, it is a string of 3 to 761 characters and must be enclosed in quotation marks. The UCL group name cannot be set to -, --, a, an, or any. The value cannot contain the following characters: / ? " @
username username

Indicates the user referenced by a security policy rule.

The value is a string of 1 to 64 case-sensitive characters. The value cannot start with @ and cannot contain the following characters: @ @ *?
all

Deletes all UCL groups and users referenced by the policy.

-

Views

Security policy rule view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The UCL group and user information carried in a data packet can be used as matching conditions of a security policy. When a security policy rule references multiple UCL groups and users, the packet is matched as long as the UCL group and user carried in the packet are the same as one of them.

Prerequisites

UCL groups and users carried in data packets can be used as matching conditions of security policies. Note that UCL groups and users must be created before being referenced in security policy rules.

Precautions

If a UCL group or user is referenced by a security policy, remove the reference relationship before deleting the UCL group or user. Otherwise, the UCL group or user cannot be deleted.

A maximum of 64 UCL groups and users can be configured in a security policy rule.

Example

# Set the UCL group of security policy rule test to test. 
<HUAWEI> system-view
[HUAWEI] ucl-group name test
[HUAWEI] security-policy
[HUAWEI-policy-security] rule name test
[HUAWEI-policy-security-rule-test] user ucl-group test
# Set the access user of security policy rule test to test. 
<HUAWEI> system-view
[HUAWEI] aaa
[HUAWEI-aaa] local-access-user test
[HUAWEI-aaa-access-user-test] quit
[HUAWEI-aaa] quit
[HUAWEI] security-policy
[HUAWEI-policy-security] rule name test
[HUAWEI-policy-security-rule-test] user username test
# Delete all UCL groups and users from security policy rule test. 
<HUAWEI> system-view
[HUAWEI] security-policy
[HUAWEI-policy-security] rule name test
[HUAWEI-policy-security-rule-test] undo user all
