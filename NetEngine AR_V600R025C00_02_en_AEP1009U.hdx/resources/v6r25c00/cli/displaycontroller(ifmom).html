display controller

Function

The display controller command displays the configuration and status of a control interface.

Format

display controller [ interface-type [ interface-number ] | interface-name ]

Parameters

Parameter Description Value
interface-type

Specifies the interface type.

-
interface-number

Specifies the number of an interface.

-
interface-name

Specifies an interface name.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

To monitor the status of or locate a fault on a control interface, run the display controller command.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the configuration and status of E1.
<HUAWEI> display controller e1 0/0/0
2021-06-22 13:18:54.915 
E1 0/0/0 current state : UP (ifindex: 16154)
Description: 
Last physical up time   : 2021-06-22 09:17:19

clock master , linecode hdb3 , loopback none
impedance 75 ohms
Alarm: none
