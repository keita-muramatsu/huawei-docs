source-interface(Web-auth-server template view)

Function

The source-interface command configures the IP address of a specified interface as the source IP address used by the device to communicate with the Portal server.

The undo source interface command deletes the source interface used by the device to communicate with the Portal server.

By default, no source interface is configured for the device to communicate with the Portal server.

Format

source-interface { interface-type interface-number | interface-name }

undo source-interface

Parameters

Parameter Description Value
interface-type interface-number

Specifies the IP address of an interface as the source IP address used by the device to communicate with the Portal server. In the preceding information:

interface-type specifies the interface type.

The interface type can only be set to loopback.

·interface-number specifies the interface number.

-
interface-name

Specifies the IP address of an interface as the source IP address used by the device to communicate with the Portal server. In the preceding information:

·interface-name specifies the name of an interface.

The interface name can only be a combination of the loopback type and interface number.

-

Views

Web-auth-server template view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To ensure normal communication between the device and Portal server, the source IP address used by the device to send Portal packets to the Portal server must be the same as the device IP address configured on the Portal server. By default, the device uses the IP address of the outbound interface sending packets to the Portal server as the source IP address. When there are multiple outbound interfaces and the outbound interface sending packets changes, the source IP address in the packets sent by the device to the Portal server becomes different from the device IP address configured on the Portal server. As a result, communication between the device and Portal server is interrupted. In this case, you can run the source-interface command to specify the IP address of the loopback interface as the source IP address used by the device to communicate with the Portal server.

Precautions

Ensure that the specified interface is a Layer 3 interface and has an IP address configured.

Example

# Configure the IP address of a specified interface as the source IP address used by the device to communicate with the Portal server.
<HUAWEI> system-view
[HUAWEI] interface loopback 1
[HUAWEI-LoopBack1] ip address 10.1.2.25 24
[HUAWEI-LoopBack1] quit
[HUAWEI] web-auth-server test
[HUAWEI-web-auth-server-test] source-interface loopback 1
