ip verify source-address

Function

The ip verify source-address command configures source address validity check on the packets received from an interface so that packets with invalid source address can be dropped.

The undo ip verify source-address command cancels the configuration.

By default, an interface does not perform source address validity check on the packets received.

Format

ip verify source-address

undo ip verify source-address

Parameters

None

Views

10GE sub-interface view, 10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE sub-interface view, 40GE interface view, Cellular interface view, Cellular channel interface view, Dialer interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, Ethernet sub-interface view, Ethernet interface view, GE optical interface view, GE sub-interface view, GE interface view, GE electrical interface view, IP-Trunk interface view, Loopback interface view, MP-group interface view, Multi-GE sub-interface view, Multi-GE interface view, POS interface view, Tunnel interface view, VLANIF interface view, Serial interface view, Management interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In the standard protocol, the range of the source IP address is specified as follows:

  • Broadcast addresses of class A, B, and C cannot be used as source addresses.
  • Class D addresses, that is, multicast addresses, cannot be used as source addresses.
  • Class E addresses are reserved and cannot be used as source addresses.
  • An all-F address cannot be used as the source address.
  • The 127-segment address cannot be used as the source address on the network outside the host.
  • If the destination address is all Fs, the all-0 address can be used as the source address. Otherwise, the all-0 address cannot be used as the source address.

    However, in actual service scenarios, these addresses may be used as source addresses. For example, class A, B, and C addresses may have 32-bit masks. In this case, class A, B, and C broadcast addresses are available. Therefore, by default, the source address check and filtering function is disabled on the device.

    This command is mainly used in attack defense scenarios. If a device is attacked by malicious packets with the source address being a broadcast or multicast address, you can run this command to filter out such packets to ensure device security.

Example

# Enable source address validity check on the packets received from the 10GE 0/0/1. 
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] undo portswitch
[HUAWEI-10GE0/0/1] ip verify source-address
