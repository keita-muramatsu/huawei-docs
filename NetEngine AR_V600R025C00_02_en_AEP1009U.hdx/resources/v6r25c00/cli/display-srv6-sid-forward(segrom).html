display segment-routing ipv6 local-sid forwarding (Public)

Function

The display segment-routing ipv6 local-sid forwarding command displays information about an SRv6 local SID table.

Format

display segment-routing ipv6 local-sid { end-x | end-op | end } [ sid ] forwarding

display segment-routing ipv6 local-sid end-x interface { interface-name | interface-type interface-number } [ nexthop nexthop-address ] forwarding

Parameters

Parameter Description Value
end-x

Indicates the End.X SID type.

-
end-op

Indicates End.OP SIDs.

-
end

Indicates the End SID type.

-
sid

Specifies an IPv6 SID value.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
interface interface-name

Specifies the name of an interface.

-
interface-type

Specifies the type of an interface.

-
interface-number

Specifies an interface number.

-
nexthop nexthop-address

Specifies a next-hop address.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

The display segment-routing ipv6 local-sid forwarding command displays information about an SRv6 local SID table, which includes End, End.X, and End.OP SIDs.

Precautions

IGP SRv6 cannot allocate End.X SIDs to VLANIF interfaces.
