peer keep-all-routes (BGP-LS address family view)

Function

The peer keep-all-routes command saves all the BGP-LS address family route updates received from a specified peer after the corresponding BGP-LS connection is established, even if these routes do not match the configured import policy.

The undo peer keep-all-routes command disables this function.

By default, only the BGP-LS address family route updates that are received from peers and match the configured import policy are saved.

Format

peer peerIpv4Addr keep-all-routes

peer peerIpv6Addr keep-all-routes

undo peer peerIpv4Addr keep-all-routes

undo peer peerIpv6Addr keep-all-routes

Parameters

Parameter Description Value
peerIpv4Addr

Specifies an IPv4 peer address.

The value is in dotted decimal notation.
peerIpv6Addr

Specifies the IPv6 address of a peer.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.

Views

BGP-LS address family view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After an import policy is changed for a BGP-LS address family peer, you can reset the peer connection for the new policy to take effect immediately. However, this will temporarily interrupt the peer connection. If a BGP-LS address family peer does not support route-refresh, you can run the peer keep-all-routes command to reserve all the routes of the peer. In this manner, the routing table can be refreshed without resetting the peer connection.

Implementation Procedure

If the peer or peer group specified in the peer keep-all-routes command does not exist, a message is displayed, indicating that the peer does not exist.

Precautions

If a device does not support route-refresh, this command needs to be run on both the device and its peers. If the peer keep-all-routes command is run on the device for the first time, the sessions between the device and its peers are reestablished.

If a device supports route-refresh, running this command does not result in reestablishment of the sessions between the device and its peers; however, the routing table cannot be refreshed on the device using the refresh bgp command.

The keep-all-routes command configuration in the BGP view does not take effect for peers in the BGP-LS address family.

Example

# Save all BGP-LS address family route updates received from the specified IPv6 peer.
<HUAWEI> system-view
[HUAWEI] bgp 100
[HUAWEI-bgp] peer 2001:DB8:1::1 as-number 100
[HUAWEI-bgp] link-state-family unicast
[HUAWEI-bgp-af-ls] peer 2001:DB8:1::1 enable
[HUAWEI-bgp-af-ls] peer 2001:DB8:1::1 keep-all-routes
# Save all BGP-LS address family route updates received from the specified IPv4 peer.
<HUAWEI> system-view
[HUAWEI] bgp 100
[HUAWEI-bgp] peer 10.1.1.1 as-number 100
[HUAWEI-bgp] link-state-family unicast
[HUAWEI-bgp-af-ls] peer 10.1.1.1 enable
[HUAWEI-bgp-af-ls] peer 10.1.1.1 keep-all-routes
