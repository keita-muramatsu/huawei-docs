qbss-load enable

Function

The qbss-load enable command enables the function of notifying STAs of AP load information.

The undo qbss-load enable command disables the function of notifying STAs of AP load information.

By default, the function of notifying STAs of AP load information is disabled.

Format

qbss-load enable

undo qbss-load enable

Parameters

None

Views

SSID profile view

Default Level

2: Configuration level

Usage Guidelines

After this command is executed, the AP notifies STAs of the AP load (such as the number of STAs associated with the AP radio and channel utilization) during STA association. The STA selects the optimal AP based on the load of each AP to improve air interface performance.

This command takes effect only when dynamic load balancing is disabled. If dynamic load balancing is enabled, the AP notifies STAs of the load status.

Modifying the configuration will cause STAs connected to the SSID to go offline and reconnect to the SSID. As a result, services on the STAs are interrupted.

Example

# Enable the function of notifying STAs of AP load information in the SSID profile ssid1.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ssid-profile name ssid1
[HUAWEI-wlan-ssid-prof-ssid1] qbss-load enable
