application-bandwidth-threshold

Function

The application-bandwidth-threshold command configures application bandwidth thresholds for a link.

The undo application-bandwidth-threshold command deletes application bandwidth thresholds for a link.

By default, no application bandwidth threshold is configured for a link.

Format

application-bandwidth-threshold lower-limit { percentage lower-limit-percentage | value lower-limit-value } upper-limit { percentage upper-limit-percentage | value upper-limit-value }

undo application-bandwidth-threshold [ lower-limit { percentage lower-limit-percentage | value lower-limit-value } upper-limit { percentage upper-limit-percentage | value upper-limit-value } ]

Parameters

Parameter Description Value
percentage lower-limit-percentage

Specifies the lower bandwidth threshold, in percentage.

The value is an integer ranging from 1 to 100.
percentage upper-limit-percentage

Specifies the upper bandwidth threshold, in percentage.

The value is an integer ranging from 1 to 100.
value upper-limit-value

Specifies the upper bandwidth threshold, in kbit/s.

The value is an integer ranging from 1 to 4294967295, in kbit/s.
value lower-limit-value

Specifies the lower bandwidth threshold, in kbit/s.

The value is an integer ranging from 1 to 4294967295, in kbit/s.
upper-limit

Specifies the upper bandwidth threshold, which can be a percentage or an absolute value.

lower-limit

Specifies the lower bandwidth threshold, which can be a percentage or an absolute value.

Views

Link view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

You can configure application bandwidth conditions to prevent application or link quality deterioration. When the bandwidth usage of a link reaches a certain threshold or the remaining bandwidth is lower than a certain threshold, new flows of some applications cannot be transmitted over this link.

If the application bandwidth thresholds are specified in percentage, the bandwidth base value is the outbound bandwidth configured using the bandwidth command in the TNP view.

The traffic steering behavior based on the link application bandwidth varies depending on the traffic steering mode:

  • Preferential occupation
  1. Upper bandwidth threshold: indicates the switchover threshold for traffic steering. When the application bandwidth usage of a link exceeds the upper application bandwidth threshold, the tunnel connection corresponding to the link does not meet the traffic steering conditions, and traffic is switched to the tunnel connection corresponding to another link that meets the conditions.
  2. Lower bandwidth threshold: indicates the switchback threshold for traffic steering. When the application bandwidth usage of a link falls below the lower application bandwidth threshold, the link meets the traffic steering conditions again. If the switchback function is configured, traffic is switched back to the tunnel connection corresponding to the link.
  • Load balancing
  1. When the application bandwidth usage of a link falls below the lower application bandwidth threshold, both existing and new flows can be transmitted over the link. (The existing and new flows are distinguished based on 5-tuple information. If the 5-tuple information remains unchanged, the flows are existing flows. Otherwise, the flows are new flows.)
  2. When the application bandwidth usage of a link is between the lower and upper application bandwidth thresholds, existing flows are still transmitted over the link, and new flows are switched to a low-priority link.
  3. When the application bandwidth usage of a link exceeds the upper application bandwidth threshold, both existing and new flows are switched to a low-priority link.

Precautions

When the lower and upper bandwidth thresholds are configured in an SPR policy profile and the link bandwidth thresholds are configured in the link configuration view, the smaller lower and upper bandwidth thresholds take effect as link switchover indicators.

When the upper bandwidth threshold is not configured in the SPR policy profile, the bandwidth value configured in the SPR configuration view is used as the upper bandwidth threshold.

When application bandwidth thresholds are configured for a link, link switchover is performed based on the lower and upper application bandwidth thresholds of the link. The application traffic is included in the total link traffic and therefore is affected by the link bandwidth thresholds and the bandwidth thresholds in the SPR policy profile.

Example

# Configure a policy profile and associate the policy profile with the Internet link. Set the lower application bandwidth threshold of the Internet link to 300 kbit/s and the upper application bandwidth threshold to 80% of the overall link bandwidth.

[HUAWEI-smart-policy-route] spr-policy node 1
[HUAWEI-smart-policy-route-spr-policy-node-1] link transport-network Internet id 99
[HUAWEI-smart-policy-route-spr-policy-node-1-link-tn-Internet] link-role master
[HUAWEI-smart-policy-route-spr-policy-node-1-link-tn-Internet] application-bandwidth-threshold lower-limit value 300 upper-limit percentage 80
