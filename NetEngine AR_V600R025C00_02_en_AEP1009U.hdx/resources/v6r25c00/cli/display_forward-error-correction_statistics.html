display forward-error-correction statistics

Function

The display forward-error-correction statistics command displays FEC statistics.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

display forward-error-correction statistics [ profile profile-name ]

Parameters

Parameter Description Value
profile profile-name

Specifies the name of an FEC parameter profile.

The value is a string of 1 to 31 case-sensitive characters, spaces not supported. However, when double quotation marks are used around the string, spaces are allowed in the string.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

When using FEC, you can run the display forward-error-correction statistics command to view FEC statistics.

Example

The actual command output varies according to the device. The command output here is only an example.
