collect system mac-address

Function

The collect system mac-address command configures the flexible flow statistics to be sent to the NSC to include the MAC address.

The undo collect system mac-address command restores the configuration.

By default, the flexible flow statistics to be sent to the NSC do not include the MAC address.

Format

collect system mac-address

undo collect system mac-address

Parameters

None

Views

IPv4 flexible flow statistics template view, IPv6 flexible flow statistics template view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

To obtain more flexible flow statistics, you can configure the exported flexible flow statistics to include the MAC address.

Prerequisites

Before running the collect system mac-address command, you need to create a flexible flow statistics template.

Precautions

If a flexible flow statistics template has been applied to an interface, the template cannot be modified or deleted.

Example

# Configure the flexible flow statistics template record1 to include the MAC address.
<HUAWEI> system-view
[HUAWEI] netstream record record1 ip
[HUAWEI-netstream-record-ipv4-record1] collect system mac-address
