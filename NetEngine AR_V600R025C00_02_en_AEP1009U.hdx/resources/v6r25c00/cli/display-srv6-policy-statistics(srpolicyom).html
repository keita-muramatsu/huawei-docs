display srv6-te policy statistics

Function

The display srv6-te policy statistics command displays SRv6 TE Policy statistics, including SRv6 TE Policy, candidate path, and segment list statistics.

Format

display srv6-te policy statistics

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

The display srv6-te policy statistics command displays SRv6 TE Policy statistics, including SRv6 TE Policy, candidate path, and segment list statistics.

This command displays the total numbers of candidate paths and segment lists as well as the numbers of up candidate paths and segment lists according to the sources of the candidate paths. This helps you determine whether the upper limit has been reached.

Example

The actual command output varies according to the device. The command output here is only an example.

# Query the statistics of the SRv6 TE policy.
<HUAWEI> display srv6-te policy statistics
Info: If service processing continues during the display, statistics may be inaccurate.
--------------------------------------------------
                                    Total      Up
--------------------------------------------------
Policy                             : 1         1
Candidate Path of Configuration    : 1         1
Candidate Path of BGP              : 0         0
Candidate Path of PCEP             : 0         0
Segment List of Configuration      : 1         1
Segment List of BGP                : 0         0
Segment List of PCEP               : 0         0
Segment-list CFG                   : 1         -
Table 1 Description of the display srv6-te policy statistics command output
Item Description
Total

Total numbers of SRv6 TE Policies, candidate paths, and segment lists.
Up

Numbers of up SRv6 TE Policies, candidate paths, and segment lists. If an SRv6 TE Policy flapping occurs, the value of this field may be greater than that of the Total field.
Policy

Number of SRv6 TE Policies.
Candidate Path of Configuration

Information about the candidate paths of locally configured SRv6 TE Policies.
Candidate Path of BGP

Candidate path information about an SRv6 TE Policy delivered by BGP.
Candidate Path of PCEP

Candidate path information about an SRv6 TE Policy delivered by PCEP.
Segment List of Configuration

Information about segment lists of the candidate paths of locally configured SRv6 TE Policies.
Segment List of BGP

Information about segment lists of the candidate paths of BGP-delivered SRv6 TE Policies.
Segment List of PCEP

Segment list of the candidate path of an SRv6 TE Policy delivered by PCEP.
Segment-list CFG

The total number of locally configured global segment lists.
