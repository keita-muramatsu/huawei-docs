ap file-transfer

Function

The ap file-transfer command configures basic file server information for APs.

The undo ap file-transfer command restores default basic file server information for APs.

By default, no file server information is configured for an AP.

Format

ap file-transfer ftp-server ip-address server-ip-address [ port ftp-port ] username username password cipher password [ max-connect-number max-connect-number ]

ap file-transfer ftp-server ipv6-address server-ipv6-address [ port ftp-port ] username username password cipher password [ max-connect-number max-connect-number ]

ap file-transfer sftp-server ip-address server-ip-address [ port sftp-port ] username username password cipher password [ max-connect-number max-connect-number ]

ap file-transfer sftp-server ipv6-address server-ipv6-address [ port sftp-port ] username username password cipher password [ max-connect-number max-connect-number ]

undo ap file-transfer ftp-server ip-address

undo ap file-transfer ftp-server ipv6-address

undo ap file-transfer sftp-server ip-address

undo ap file-transfer sftp-server ipv6-address

Parameters

Parameter Description Value
port sftp-port

Specifies a port number for the SFTP server.

If no port number is specified, the default port 22 is used.

The value is an integer ranging from 1 to 65535.
port ftp-port

Specifies a port number for the FTP server.

If no port number is specified, the default port 21 is used.

The value is an integer ranging from 1 to 65535.
username username

Specifies the user name for logging in to a file server.

The value is a string of 1 to 31 characters. It cannot contain question marks (?) and cannot start or end with double quotation marks (" ") or spaces.
password

Specifies the password for logging in to a file server.

Views

WLAN view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

You need to run this command when installing a container or module file to an AP on the AC. After the AC sends basic server information to the AP, the AP requests files from the server based on the information.

  • After running this command, you can perform the following operations:
    1. Run the install container public-key command to load the public key file of a container.
    2. Run the install container application-software command to install container image files in batches.
    3. Run the install module command to install module files in batches.
  • You can set both IPv4 and IPv6 servers, and only one server is allowed for each IP version.

Precautions

  • APs do not support double quotation marks ("). Therefore, ensure that these characters are not contained in the user name or unencrypted password of an FTP/SFTP server configured on the WAC. Otherwise, file loading will fail.
  • The WAC can function as the FTP/SFTP server. Alternatively, use an external FTP/SFTP server, which is recommended.
  • When an external FTP/SFTP server is used, the maximum number of APs that can have files loaded simultaneously is the configured value of max-connect-number.
  • When a WAC is used as the FTP/SFTP server, a maximum of 15 files can be loaded to an AP using FTP/SFTP simultaneously even if the configured value of max-connect-number is larger than 15.
  • When a WAC is used as the FTP/SFTP server, if n VTY users have logged in, the maximum number of APs that can be upgraded simultaneously decreases by n – 1.
  • When IPv4 and IPv6 FTP/SFTP servers are both configured, set the maximum number of APs that can have files loaded simultaneously in both the two IP versions.
  • SFTP is recommended because it is more secure than FTP.

Example

# Configure the IP address, user name, and password of the SFTP server.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap file-transfer sftp-server ip-address 192.168.1.100 username admin password cipher YsHsjx_202206
# Set the IPv6 address, user name, and password of the SFTP server.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap file-transfer sftp-server ipv6-address 2001:db8::1 username admin password cipher YsHsjx_202206
