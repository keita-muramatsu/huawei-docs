display nqa compatible ip-sla responder

Function

The display nqa compatible ip-sla responder command displays the status of IP-SLA reflection instances for NQA-compatible third-party devices or third-party NMS software.

Format

display nqa compatible ip-sla responder

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

After the function of responding to UDP tests performed by a third-party device or NMS software is configured, you can run this command to check the status of NQA-compatible IP-SLA reflection instances of the third-party device or NMS software. You can manually delete invalid reflection instances based on the query result. If the protocol status of the IP address is UP, the status is ACTIVE. If the protocol status of the IP address is DOWN or the IP address is deleted, the status is NOTINSERVICE.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the status of IP-SLA reflection instances compatible with third-party devices or third-party NMS software.
<HUAWEI> display nqa compatible ip-sla responder
Total Num : 1                 
-----------------------------------------------------------------------------------------------
Address : 1.1.1.1          Status : ACTIVE        IfName : 10GE0/0/1                             
Port    : 9876             ToS    : 100           VPN    : vpn1                                  
-----------------------------------------------------------------------------------------------
Table 1 Description of the display nqa compatible ip-sla responder command output
Item Description
Total Num

Number of current NQA reflection instances.
Address

IP address listened to by the NQA reflection instance.
Status

Status of an NQA reflection instance:

  • ACTIVE: available.
  • NOTINSERVICE: unavailable.
IfName

Name of the interface where the local address of the NQA reflection instance resides.
Port

Listening port number of the NQA reflection instance.
ToS

Service type listened to by the NQA reflection instance.
VPN

Name of the VPN instance to which the NQA reflection instance belongs.
