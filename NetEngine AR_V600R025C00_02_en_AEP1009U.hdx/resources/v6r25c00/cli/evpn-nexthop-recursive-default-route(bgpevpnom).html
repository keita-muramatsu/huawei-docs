nexthop recursive-lookup default-route (BGP-EVPN address family view)

Function

The nexthop recursive-lookup default-route command enables next-hop recursion to the default route.

The undo nexthop recursive-lookup default-route command restores the default configuration.

By default, next hop-based recursion to the default route is disabled.

Format

nexthop recursive-lookup default-route

undo nexthop recursive-lookup default-route

Parameters

None

Views

BGP-EVPN address family view

Default Level

2: Configuration level

Usage Guidelines

In an EVPN scenario, due to a configuration error or fault, the PE at one end may fail to recurse routes to the next hop due to route unreachability. As a result, services are interrupted. To prevent this problem, run the nexthop recursive-lookup default-route command on the PE and configure the remote PE to send a default route to the local PE. If the next hop of a specific route on the local PE is unreachable, the local PE can recurse the route to a correct forwarding path based on the default route, ensuring normal service running.

Example

# Enable next hop-based recursion to the default route.
<HUAWEI> system-view
[HUAWEI] bgp 100
[HUAWEI-bgp] l2vpn-family evpn
[HUAWEI-bgp-af-evpn] nexthop recursive-lookup default-route
