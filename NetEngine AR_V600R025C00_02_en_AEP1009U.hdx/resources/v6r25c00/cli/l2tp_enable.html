l2tp enable

Function

The l2tp enable command enables L2TP globally on a device.

The undo l2tp enable command disables L2TP.

By default, L2TP is disabled.

Format

l2tp enable

undo l2tp enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When users need to access resources in the headquarters through L2TP, you can deploy the L2TP service to implement dial-up access to the headquarters. You can enable L2TP before or after completing L2TP configurations.

Precautions

The L2TP function is available only after you run the l2tp enable command. If L2TP is disabled, the device does not provide the L2TP function even if the L2TP configuration is complete.

If L2TP connections have been established on the device, running the undo l2tp enable command will disconnect all connections. Therefore, exercise caution when running this command.

Example

# Enable L2TP.
<HUAWEI> system-view
[HUAWEI] l2tp enable
# Disable L2TP.
<HUAWEI> system-view
[HUAWEI] undo l2tp enable
