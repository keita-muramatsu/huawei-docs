nat address-group

Function

The nat address-group command configures an address pool.

The undo nat address-group command deletes an address pool.

By default, the address pool is not configured.

Format

nat address-group group-name [ group-number ]

undo nat address-group group-name

Parameters

Parameter Description Value
group-name

Name of an address pool.

The value is a string of 1 to 34 case-sensitive characters. It cannot be all, vsys, or all-systems.

If the name does not contain spaces, it is a string of 1 to 34 characters and cannot be enclosed in double quotation marks.

If the name contains spaces, it must be enclosed in double quotation marks, for example, "group for test". The name cannot start or end with a space. For example, " group for test " cannot be configured.

Double quotation marks cannot be used in the middle of the name. For example, group"for cannot be configured. The name cannot contain question marks (?) and can contain only digits.
group-number

Specifies the number of the address pool.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 63.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T and AR6710-L14T2X4:The value is an integer ranging from 0 to 127.

For the AR8700 series, AR8100 series and AR6700-H series:The value is an integer ranging from 0 to 2499.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

When an address pool is performing address translation, it cannot be deleted.

Example

# Configure the address pool nataddr whose address pool number is 1. 
<HUAWEI> system-view
[HUAWEI] nat address-group nataddr 1
[HUAWEI-address-group-nataddr]
