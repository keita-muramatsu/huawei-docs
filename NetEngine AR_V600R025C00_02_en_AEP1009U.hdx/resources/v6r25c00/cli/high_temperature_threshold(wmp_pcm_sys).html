high-temperature threshold (AP system profile view)

Function

The high-temperature threshold command sets an upper device, ambient, CPU, or NP temperature alarm threshold for APs.

The undo high-temperature threshold command restores the default upper device, ambient, CPU, or NP temperature alarm threshold of APs.

For the default upper temperature alarm threshold of APs, run the display ap-type command.

Format

high-temperature [ ap-environment | cpu | np ] threshold threshold-value

undo high-temperature [ ap-environment | cpu | np ] threshold

Parameters

Parameter Description Value
ap-environment

Indicates the ambient temperature.

-
cpu

Indicates the CPU temperature.

-
np

Indicates the NP chip temperature.

-
threshold-value

Specifies the upper temperature alarm threshold for APs.

The value is an integer that ranges from 20 to 110, in °C.

Views

AP system profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

You can run this command to set the upper temperature alarm threshold for APs. When an AP's temperature exceeds the upper threshold, the AP generates an alarm and a log, and notifies the WAC of the high temperature alarm.

The parameter ap-environment is supported only by the AirEngine 9700D-M and AirEngine 9700D-M1, and the parameters cpu and np are supported only by the AirEngine 9700D-M.

If none of ap-environment, cpu, and np is specified, this command sets an upper temperature alarm threshold for the AP device.

Precautions

This function is supported only by some AP models. You can visit Info-Finder, search for the target AP model, and search for configuring an upper temperature alarm threshold for APs in Specifications Query to check whether the AP supports this function.

Example

# Set the upper temperature alarm threshold for APs to 65°C.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name ap-system1
[HUAWEI-wlan-ap-system-prof-ap-system1] high-temperature threshold 65
