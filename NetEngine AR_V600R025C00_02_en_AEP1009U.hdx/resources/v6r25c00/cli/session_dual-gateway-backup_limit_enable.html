session dual-gateway-backup limit enable

Function

The session dual-gateway-backup limit enable command enables sessions backed up by dual gateways to be limited by the number of available sessions.

The undo session dual-gateway-backup limit enable command disables sessions backed up by dual gateways to be limited by the number of available sessions.

By default, sessions backed up by dual gateways are not limited by the number of available sessions.

Format

session dual-gateway-backup limit enable

undo session dual-gateway-backup limit enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After the session limit command is run, the number of sessions synchronized between the two ends is not limited by the session limit by default in a dual-gateway scenario. The actual number of established sessions may exceed the configured limit, with the maximum value being double the limit.

You can enable sessions backed up by dual gateways to be limited by the number of available sessions, which will cause the sessions backed up by dual gateways to be limited by the session limit. In this way, the maximum number of sessions that can be established is equal to the session limit.

Precautions

  1. If the ACL-based session limit function is configured, sessions backed up by dual gateways support only 5-tuple matching.
  2. After the configuration, the flow tables of the two gateways may become desynchronized.
  3. The limit function takes effect only for IPv4 sessions.

Example

# Enable sessions backed up by dual gateways to be limited by the number of available sessions.
<HUAWEI> system-view
[HUAWEI] session dual-gateway-backup limit enable
