memory-usage reliability

Function

The memory-usage reliability command sets thresholds for memory usage reliability.

The undo memory-usage reliability command restores the default thresholds for memory usage reliability.

The default notice, overload, and exception thresholds for memory usage reliability are 70, 85, and 95, respectively.

Format

memory-usage reliability notice-threshold notice-threshold-value overload-threshold overload-threshold-value exception-threshold exception-threshold-value [ slot slotId ]

undo memory-usage reliability [ notice-threshold notice-threshold-value overload-threshold overload-threshold-value exception-threshold exception-threshold-value ] [ slot slotId ]

Parameters

Parameter Description Value
overload-threshold overload-threshold-value

Specifies the overload threshold for memory usage reliability.

The value is an integer ranging from (notice-threshold-value + 5) to 95.
exception-threshold exception-threshold-value

Memory reliability exception threshold.

The value is an integer ranging from max(overload-threshold-value+5, 75) to 100.
slot slotId

Specifies the slot ID of a board.

The value depends on the device. You can enter a question mark (?) and select a value from the displayed value range.
notice-threshold notice-threshold-value

Specifies the notice threshold for memory usage reliability.

The value is an integer ranging from 5 to 90.

Views

System view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

You can run this command to configure memory usage reliability based on service deployment on the device. In this way, when the memory usage of the device is too high, the device can detect the high memory usage in a timely manner and release the memory to prevent unexpected board resets.

  • When the memory usage of a board is higher than the notice threshold and does not meet condition 1, the system notifies all components about the components whose memory usage is higher than 5% (for up to 10 components with the highest memory usage). When the memory usage of the board falls to 5% lower than the notice threshold, the system sends an alarm clearance message to all components.
  • When the memory usage of a board exceeds the overload threshold, the system reports the hwSystemMemoryOverload alarm. If condition 2 is met, an active/standby switchover is triggered. If neither condition 2 nor condition 1 is met, the system notifies all components about the components whose memory usage is higher than 5% (for up to 10 components with the highest memory usage). When the memory usage of the board falls to 5% lower than the overload threshold, the system triggers the hwSystemMemoryOverloadResume alarm and sends an alarm clearance message to all components.
  • When the memory usage of a board is higher than the exception threshold and is higher than or equal to 90%, the system determines whether condition 1 is met. If condition 1 is met, an active/standby switchover is triggered. If condition 1 is not met, the system checks whether the process with the highest memory usage supports independent restart. If so, the system restarts the process. If not, the system does not perform any operation. If the memory usage continues to increase, the board resets due to memory application failure.

    Note:

    Condition 1: The standby main control board is installed, the memory usage of the standby main control board is lower than the switchover threshold (configured using the memory-usage reliability slave-switch-over threshold <threshold-value> command), and the standby main control board has been running for more than one day.

    Condition 2: The memory usage difference between the active and standby main control boards is greater than 30%, and the standby main control board has been running for more than one day.

Prerequisites

Memory usage reliability has been enabled using the memory-usage reliability switch on command.

Precautions

If no board is specified, this command takes effect only on the main control board.

Example

# Set the notice threshold for memory usage reliability to 75, overload threshold to 88, and exception threshold to 96 for a specified slot.
<HUAWEI> system-view
[HUAWEI] memory-usage reliability switch on
[HUAWEI] memory-usage reliability notice-threshold 75 overload-threshold 88 exception-threshold 96 slot 0
# Set the default notice threshold for memory usage reliability to 75, overload threshold to 88, and exception threshold to 96 for the main control board.
<HUAWEI> system-view
[HUAWEI] memory-usage reliability switch on
[HUAWEI] memory-usage reliability notice-threshold 75 overload-threshold 88 exception-threshold 96
