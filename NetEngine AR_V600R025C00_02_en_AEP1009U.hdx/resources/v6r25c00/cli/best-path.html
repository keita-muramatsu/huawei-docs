best-path

Function

The best-path command enables the optimal path mode.

The undo best-path command disables the optimal path mode and restores the load balancing mode.

By default, the optimal path mode is disabled, and the load balancing mode is used.

Format

best-path

undo best-path

Parameters

None

Views

saas-policy-node view

Default Level

2: Configuration level

Usage Guidelines

The optimal path mode can be enabled for the traffic steering policy of SaaS application access.

Example

# Create policy node 1 and configure the optimal path mode.
<HUAWEI> system-view
[HUAWEI] saas-cloud-express
[HUAWEI-saas-cloud-express] saas-policy node 1
[HUAWEI-saas-cloud-express-saas-policy-node-1] best-path
