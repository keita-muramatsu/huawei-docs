binding service-map

Function

The binding service-map command binds a service profile to an SPR policy profile.

The undo binding service-map command unbinds a service profile from an SPR policy profile.

By default, no service profile is bound to an SPR policy profile.

Format

binding service-map name

undo binding service-map [ name ]

Parameters

Parameter Description Value
name

Specifies the name of a service profile.

The value is a string of 1 to 31 case-sensitive characters. If spaces are used, the string must be enclosed in double quotation marks (" ").

Views

SPR policy view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

You can define different service flows using ACLs or applications, configure matching rules in a service profile to classify traffic, and run this command to bind an SPR policy profile to a service profile to implement SPR for the classified service flows.

Prerequisites

SPR has been configured using the smart-policy-route command.

A service profile has been created using the service-map command in the smart-policy-route view.

An SPR policy profile has been created using the spr-policy command in the smart-policy-route view.

Precautions

A service profile has been created.

If a policy profile has been applied, you cannot unbind the service profile from the policy profile. To unbind the service profile from the policy profile, disable the policy profile first.

Example

# Create service profile map1 to match the ACL, create policy spr1, and bind the service profile map1 to the policy.
<HUAWEI> system-view
[HUAWEI] smart-policy-route
[HUAWEI-smart-policy-route] service-map map1
[HUAWEI-smart-policy-route-service-map-map1] quit
[HUAWEI-smart-policy-route] spr-policy node 1
[HUAWEI-smart-policy-route-spr-policy-node-1] binding service-map map1
