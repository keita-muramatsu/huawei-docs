nat enable

Function

The nat enable command enables the NAT function.

The undo nat enable command disables the NAT function.

By default, NAT is disabled on an interface.

Format

nat enable

undo nat enable

Parameters

None

Views

Cellular channel interface view, 25GE sub-interface view, 40GE sub-interface view, Cellular interface view, Multi-GE interface view, Multi-GE sub-interface view, POS interface view, 10GE interface view, 10GE sub-interface view, 25GE interface view, 40GE interface view, Serial interface view, Dialer interface view, Eth-Trunk interface view, Eth-Trunk sub-interface view, GE interface view, GE sub-interface view, Tunnel interface view, VLANIF interface view, IP-Trunk interface view, Ethernet interface view, Ethernet sub-interface view

Default Level

2: Configuration level

Usage Guidelines

You can run the nat enable command on an interface to enable the NAT function on the interface.

With NAT enabled on an interface, when the device receives a packet from this interface, the device searches for NAT information about the destination IP address in the packet and translates the destination IP address if a match is found; when the device sends a packet from this interface, the device searches for NAT information about the source IP address of the packet and translates the source IP address if a match is found.

Example

# Enable the NAT function on the 10GE0/0/1.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] undo portswitch
[HUAWEI-10GE0/0/1] nat enable
