display remote-unit port poe

Function

The display remote-unit port poe command displays PoE information about interfaces on an RU.

Format

display remote-unit port [ port-id ] poe [ { connect-interface { interface-name | interface-type interface-number } | name remote-unit-name } [ realtime ] ]

Parameters

Parameter Description Value
port-id

Specifies the index of an interface on an RU.

The value is an integer in the range from 1 to 34. port-id indicates the port ID of an RU, which may be different from the physical port number printed on the panel. For example, if the downlink port numbers are 1 to 8 and the uplink port numbers are 9 to 10 on the panel, set port-id to an integer in the range from 1 to 10 according to the actual port for connection. If the downlink port numbers are 1 to 8 and the uplink port numbers are 1 to 2 on the panel, set port-id to an integer in the range from 1 to 10 (1 to 8: downlink ports; 9: uplink port 1; 10: uplink port 2).
connect-interface { interface-name | interface-type interface-number }

Specifies the type and number of an interface. The interface type and number can be closely next to each other or separated by a space character.

The value must be set according to the device configuration.
name remote-unit-name

Specifies the alias of an RU.

The value is a string of 1 to 32 case-sensitive characters. It cannot contain spaces.
realtime

Displays real-time PoE information.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run the display remote-unit port poe realtime command to view real-time power supply information about interfaces on an RU, such as the current power, class of the PD connected to the interface, reference power of the PD, and power supply status.

Table 1 Description of the display remote-unit port poe command output
Item Description
ESN

ESN of an RU.
Name

Alias of an RU. This field displays a hyphen (-) if an RU is not configured with an alias.
Device type

Device type of an RU.
Connect interface

Interface for connecting an RU and the central device.
PD class

Class of the PD connected to the interface. When the power status is Detecting, "-" is displayed.
PD reference power(mW)

Reference power of an interface. When the power status is Detecting, "-" is displayed.
PD current power(mW)

Current output power of an interface.
PD peak power(mW)

Peak output power of an interface.
PD average power(mW)

Average output power of an interface.
Power-up mode

Power supply mode of an interface:

• af-inrush: PoE mode.

• at-inrush: PoE+ mode.

• bt-inrush: PoE++ mode.
Default power-up mode

Default power supply mode of an interface.
Force power

Whether forcible PoE power supply is enabled on an interface.

To configure the parameter, run the poe force-power port command.
Power ON/OFF

Whether the interface is powered on:

· on: The device is supplying power.

· off: No power is supplied.
Power status

Power supply status of an interface. The options are as follows:

· Test mode: indicates the test status.

· Detecting: indicates the detecting state.

· Disabled: The PoE function is disabled on the interface.

· Power-deny: The reference power is greater than the maximum output power of the interface.

· Classification overcurrent: hierarchical overcurrent.

· Unknown: The rating is unknown.

· Power overcurrent: The port experiences overcurrent.

· Power-on failed: The power-on fails.

· Power-ready: The power supply of the interface is ready.

· Powering: The system is being powered on.

· Powered: The power-on is complete.

· Overloaded: The power is overloaded.

· Time-range power-off: The interface is in the power-off time range.

· Unstable voltage: The interface voltage is unstable.

· Legacy disable: The interface is disabled from checking the compatibility of the PD.

· Class mismatch: The interface does not support PD classification.
Power-on delay(s)

Power supply delay of an interface, in seconds. If the value is 0, no delay occurs.

To configure this parameter, run the poe power-on delay port command.
Current(mA)

Output current of an interface.
Voltage(V)

Output voltage of an interface.
Insertion and removal status

Whether there are PD removal and insertion records on the interface:

· 0: initial value, which is meaningless. When the remote module is started with the PD, 0 is also displayed.

· 1: indicates that there is an insertion.

· 2: indicates that the board is removed.

· 3: indicates that the board is inserted or removed.
