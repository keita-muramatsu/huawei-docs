csi presence-aging-time

Function

The csi presence-aging-time command sets the human presence aging time of the CSI sensing function for APs.

The undo csi presence-aging-time command deletes the human presence aging time of the CSI sensing function configured for APs.

By default, the human presence aging time of the CSI sensing function is 600s in the AP system profile view. In the AP view, the human presence aging time is not configured by default, and the configuration in the AP system profile view is used.

Format

csi presence-aging-time time

undo csi presence-aging-time

Parameters

Parameter Description Value
time

Specifies the human presence aging time, that is, the duration during which the CSI sensing function detects no person after human presence is determined.

The value is an integer ranging from 1 to 65535, in seconds.

Views

AP view, AP system profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Human absence may be incorrectly determined when a person is stationary or slightly moving. As such, you can configure the human presence aging time to prevent frequent changes of the sensing result. In addition, the detection result in a long time is used, thereby reducing false detection.

Precautions

The minimum aging time that takes effect is restricted by the presence-to-absence delay specifications of the AP. For details, visit Info-Finder, search for the model of the target AP, and then query "Specifications of sensing delay in human presence detection."

If the person sensing distance range on exit (presence-leave-range leave-value) is greater than the person sensing distance range on entry (presence-enter-range enter-value) in the csi distance-range command configuration, the human presence aging time configured on the AP must be set to at least more than 10 minutes. If the aging time on the AP is too short, for example, 1 minute, when a person stays in the inner and outer circles of the detection range for more than 1 minute, the human absence state is determined, and human presence cannot be identified unless the person enters the inner circle again.

Example

# Set the human presence aging time of the CSI sensing function to 600s for APs.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name test
[HUAWEI-wlan-ap-system-prof-test] csi presence-aging-time 600
