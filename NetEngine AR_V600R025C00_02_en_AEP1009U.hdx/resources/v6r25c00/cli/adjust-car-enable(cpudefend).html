cpu-defend dynamic-adjust enable

Function

The cpu-defend dynamic-adjust enable command globally enables adaptive adjustment of the default CPCAR value for protocol packets sent in wired mode.

The undo cpu-defend dynamic-adjust enable command globally disables adaptive adjustment of the default CPCAR value for protocol packets sent in wired mode, and restores the default CPCAR value.

By default, adaptive adjustment of the default CPCAR value for protocol packets is enabled globally.

Format

cpu-defend dynamic-adjust enable

undo cpu-defend dynamic-adjust enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To fulfill the dynamic requirements of rate limiting on protocol packets that a fixed default CPCAR value cannot fulfill, you can use this command to enable adaptive adjustment of the default CPCAR value for protocol packets globally.

If adaptive adjustment of the default CPCAR value is enabled for a specific type of protocol packets, the device checks for packet loss of such protocol packets at a specified interval. When detecting a packet loss, the device dynamically adjusts the CPCAR value for the protocol packets based on the CPU usage. When the CPU usage is low, the device increases the CPCAR value, which however cannot exceed the maximum CPCAR value. When the CPU usage is high, the device reduces the CPCAR value, but the value cannot be smaller than the default one. If packet loss occurs due to congestion in the queue where the detected protocol packets reside, the device restores the default CPCAR value for the protocol packets. You can run the display cpu-defend dynamic-adjust history-record command to view the historical adaptive CPCAR adjustment records.

Precautions

This function takes effect only when the default CPCAR values for protocol packets are not manually changed.

After adaptive CPCAR adjustment for protocol packets is enabled globally, this function takes effect for all types of protocol packets that support this function.

Example

# Enable adaptive adjustment of the default CPCAR value for protocol packets globally.
<HUAWEI> system-view
[HUAWEI] cpu-defend dynamic-adjust enable
