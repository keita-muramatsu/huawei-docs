period-clock-mode

Function

The period-clock-mode ptp command sets the timing mode for calculating IFIT measurement periods and obtaining sampling timestamps to PTP and configures a UTC offset.

The period-clock-mode ntp command sets the timing mode for calculating IFIT measurement periods and obtaining sampling timestamps to NTP.

The undo period-clock-mode command restores the default timing mode for calculating IFIT measurement periods and obtaining sampling timestamps.

By default, the timing mode for calculating IFIT measurement periods and obtaining sampling timestamps is NTP.

Format

period-clock-mode { ptp current-leap current-leap-value [ { leap59 | leap61 } date utc-date ] | ntp }

undo period-clock-mode { ptp current-leap current-leap-value [ { leap59 | leap61 } date utc-date ] | ntp }

Parameters

Parameter Description Value
current-leap current-leap-value

Specifies the UTC offset for calculating IFIT measurement periods and obtaining sampling timestamps.

The value is an integer ranging from 1 to 255, in seconds.
leap59

Sets the leap second to 59 seconds.

-
leap61

Sets the leap second to 61 seconds.

-
date utc-date

Specifies the pre-configured date when the IFIT leap second is to be applied.

The value is a date ranging from 1970-01-01 to 2099-12-31.

Views

IFIT view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The same timing mode must be used for calculating IFIT measurement periods. When a device needs to interwork with a PTP-enabled device, you can run this command to set the timing mode for calculating IFIT measurement periods and obtaining sampling timestamps to PTP, and configure a UTC offset to convert Coordinated Universal Time (UTC) to International Atomic Time (TAI). The converted TAI time is used for both calculating IFIT measurement periods and obtaining IFIT sampling timestamps. Because the UTC offset involves irregular leap second adjustments, you can preconfigure the next leap second adjustment date and mode when configuring the offset.

Example

# Set the timing mode for calculating IFIT measurement periods and obtaining sampling timestamps to PTP, and set the UTC offset to 50 seconds.
<HUAWEI> system-view
[HUAWEI] ifit
[HUAWEI-ifit] period-clock-mode ptp current-leap 50
# Configure the IFIT calculation interval and sampling timestamp to use the NTP timing mode.
<HUAWEI> system-view
[HUAWEI] ifit
[HUAWEI-ifit] period-clock-mode ntp
# Set the timing mode for calculating IFIT measurement periods and obtaining sampling timestamps to PTP, set the UTC offset to 50 seconds, and configure the device to adjust the leap second to 59 seconds on January 1, 2026.
<HUAWEI> system-view
[HUAWEI] ifit
[HUAWEI-ifit] period-clock-mode ptp current-leap 50 leap59 date 2026-01-01
