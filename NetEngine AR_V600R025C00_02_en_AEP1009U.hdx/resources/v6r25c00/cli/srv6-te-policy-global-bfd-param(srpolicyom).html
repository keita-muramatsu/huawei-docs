srv6-te-policy bfd (Segment routing IPv6 view)

Function

The srv6-te-policy bfd command configures BFD parameters for an SRv6 TE Policy.

The undo srv6-te-policy bfd command deletes BFD parameters configured for an SRv6 TE Policy.

The srv6-te-policy bfd backup-path command configures BFD parameters for the backup path of an SRv6 TE Policy.

The undo srv6-te-policy bfd backup-path command deletes BFD parameters configured for the backup path of an SRv6 TE Policy.

The srv6-te-policy bfd switch-delay command configures a BFD switching delay for an SRv6 TE Policy.

The undo srv6-te-policy bfd switch-delay command deletes the BFD switching delay configured for an SRv6 TE Policy.

By default, the minimum interval at which BFD packets are sent for an SRv6 TE Policy is 10 ms, the local detection multiplier is 3, and delayed switching does not take effect.

Format

srv6-te-policy bfd { min-tx-interval tx-value | detect-multiplier detectmulti-value } *

srv6-te-policy bfd { min-tx-interval backup-tx-value | detect-multiplier backup-detectmulti-value } * backup-path

srv6-te-policy bfd switch-delay delay-interval

undo srv6-te-policy bfd { min-tx-interval [ tx-value ] | detect-multiplier [ detectmulti-value ] } *

undo srv6-te-policy bfd { min-tx-interval [ backup-tx-value ] | detect-multiplier [ backup-detectmulti-value ] } * backup-path

undo srv6-te-policy bfd switch-delay [ delay-interval ]

Parameters

Parameter Description Value
min-tx-interval tx-value

Specifies the minimum interval at which BFD packets are sent to the remote device.

The value is an integer ranging from 10 to 2000, in milliseconds. The default value is 10.
min-tx-interval backup-tx-value

Specifies the minimum interval at which BFD packets are sent to the peer end over the backup path of an SRv6 TE Policy.

The value is an integer ranging from 10 to 2000, in milliseconds. The default value is 0 ms.
detect-multiplier backup-detectmulti-value

Specifies a local detection multiplier for the backup path of an SRv6 TE Policy.

The value is an integer ranging from 3 to 50. The default value is 0.
detect-multiplier detectmulti-value

Specifies the local detect multiplier.

The value is an integer in the range 3 to 50. The default value is 3.
switch-delay delay-interval

Specifies a BFD switching delay.

The value is an integer ranging from 1 to 2592000, in seconds. The default value is 0s.

Views

Segment routing IPv6 view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The srv6-te-policy bfd command adjusts BFD parameters of an SRv6 TE Policy to meet different network requirements.

Precautions

The srv6-te-policy bfd command must be run together with the bfd and srv6-te-policy bfd enable commands. Otherwise, the srv6-te-policy bfd command configuration does not take effect.

If both the srv6-te-policy bfd and srv6-te-policy bfd backup-path commands are run to configure BFD parameters, the BFD parameters configured using the srv6-te-policy bfd backup-path command preferentially take effect for the backup candidate path.

Example

# Set the minimum interval at which BFD packets are sent to 300 ms for an SRv6 TE Policy.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] srv6-te-policy bfd min-tx-interval 300
# Set the BFD switching delay to 300s for an SRv6 TE Policy.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] srv6-te-policy bfd switch-delay 300
