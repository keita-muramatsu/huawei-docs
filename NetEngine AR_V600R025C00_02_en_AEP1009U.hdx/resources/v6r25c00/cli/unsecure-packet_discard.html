unsecure-packet discard

Function

The unsecure-packet discard enable command enables the function of discarding insecure packets.

The undo unsecure-packet discard enable command disables the function of discarding insecure packets.

By default, the device is disabled from discarding insecure packets.

Format

unsecure-packet discard enable

undo unsecure-packet discard enable

Parameters

None

Views

Site view

Default Level

2: Configuration level

Usage Guidelines

In SD-WAN scenarios, when the encryption function is enabled on the TNP or tunnel interface of a site, the forwarding process is performed even if unencrypted packets are received. To enhance security, you can enable the function of discarding insecure packets. Then the device discards received unencrypted packets.

Example

# Configure the function of discarding insecure packets.
<HUAWEI> system-view
[HUAWEI] evpn site 1
[HUAWEI-site-1] unsecure-packet discard enable
