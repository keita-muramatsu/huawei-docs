rule (User-defined IPS signature view)

Function

The rule name command creates a user-defined signature rule with the specified name.

The undo rule command deletes all user-defined signature rules or the specified user-defined signature rule.

By default, no rule is configured.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

rule name name

undo rule { name name | all }

Parameters

Parameter Description Value
name name

Specifies the name of a user-defined signature rule.

The value is a string of 1 to 32 case-sensitive characters. If the name contains spaces, the name must be enclosed with double quotation marks, for example, "user for test". If the name does not contain spaces, double quotation marks cannot be used.
all

Indicates all user-defined signature rules.

-

Views

User-defined IPS signature view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

You can configure a maximum of four rules for one user-defined signature.

You must configure the protocol before you create a user-defined signature rule. If you don't configure the protocol, the default protocol in the user-defined signature is TCP.

Precautions

After running this command, run the engine configuration commit command to commit the configuration for the configuration to take effect. You are advised to commit the configuration after all content security configurations are complete.

Example

# Create user-defined signature rule hello in user-defined signature 1. 
<HUAWEI> system-view
[HUAWEI] ips signature-id 1
[HUAWEI-ips-signature-1] protocol TCP
[HUAWEI-ips-signature-1] rule name hello
[HUAWEI-ips-signature-1-rule-hello]
