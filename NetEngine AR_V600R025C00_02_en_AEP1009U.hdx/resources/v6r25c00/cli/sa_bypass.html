sa bypass

Function

The sa bypass command enables the bypass function for IPv4 traffic on the SA module. In this case, application identification is not performed for IPv4 packets.

The undo sa bypass command disables the bypass function for IPv4 traffic on the SA module.

By default, the bypass function is disabled for IPv4 traffic on the SA module.

Format

sa bypass

undo sa bypass

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

After the bypass function is enabled for IPv4 traffic on the SA module, application identification is not performed for IPv4 packets.

Example

# Enable the bypass function for IPv4 traffic on the SA module.
<HUAWEI> system-view
[HUAWEI] sa bypass
