qos overhead layer map

Function

The qos overhead layer map command enables the function of counting the packet header length corresponding to the physical link during interface-based rate limiting based on the mapping between the tunnel interface and the physical interface.

By default, the packet header length corresponding to the physical link is not counted during interface-based rate limiting.

Format

qos overhead layer map interface { interface-name | interface-type interface-number }

undo qos overhead layer map [ interface { interface-name | interface-type interface-number } ]

Parameters

Parameter Description Value
interface-name

Specifies the interface name.

The value is a string of 1 to 64 case-sensitive characters. It cannot contain spaces.
interface-type

Specifies the interface type.

-
interface-number

Specifies the interface number.

The value is a string of 1 to 64 case-sensitive characters. It cannot contain spaces.
interface

Specifies an interface.

The interface can be a physical Ethernet interface, physical Ethernet sub-interface, cellular channel interface, dialer interface, Eth-Trunk sub-interface, Eth-Trunk interface, MP-group interface, or serial interface. (Select an interface based on the model.)

Views

Tunnel interface view

Default Level

2: Configuration level

Usage Guidelines

If this command is not configured, the actual rate of traffic passing through an interface may be greater than the rate limit on the interface. After this command is configured, the packet header length corresponding to the physical link is counted during rate limiting on a tunnel interface. This prevents the problem that the rate limit is inconsistent with the rate of traffic passing through the tunnel interface.

Example

# Configure the function of counting the packet header length corresponding to the physical link during interface-based rate limiting based on the mapping between the tunnel interface and the physical interface.
<HUAWEI> system-view
[HUAWEI] interface Tunnel 1
[HUAWEI-Tunnel1] qos overhead layer map interface 10GE 0/0/1
