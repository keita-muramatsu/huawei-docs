srv6-te-policy switch-delay

Function

The srv6-te-policy switch-delay delete-delay command is used to set the slow-cut time for all SRv6 TE policies.

The undo srv6-te-policy switch-delay command is used to restore the default.

By default, the switch-delay and the delete-delay of SRv6 TE Policies are 5000 and 20000 milliseconds,respectively.

Format

srv6-te-policy switch-delay switchDelay delete-delay deleteDelay

undo srv6-te-policy switch-delay

undo srv6-te-policy switch-delay switchDelay delete-delay deleteDelay

Parameters

Parameter Description Value
switchDelay

Specifies a switching delay for SRv6 TE Policies.

The value is an integer ranging from 0 to 600000, in milliseconds.
delete-delay deleteDelay

Specifies a deletion delay for SRv6 TE Policies.

The value is an integer ranging from 0 to 600000, in milliseconds.

Views

Segment routing IPv6 view

Default Level

2: Configuration level

Usage Guidelines

SRv6 TE Policies support make-before-break (MBB), allowing a forwarder to establish a new segment list before removing the original one during a segment list update. In the establishment process, traffic is still forwarded through the original segment list, preventing packet loss upon a segment list switchover. The srv6-te-policy switch-delay delete-delay command is used to set switchover and deletion delays for all SRv6 TE Policies.

In actual applications, if the traffic volume greatly differs on an upstream node and a downstream node, the forwarding entries may be inconsistent on the two nodes. When this is the case, traffic may be interrupted for a short time.

To prevent this issue, run the srv6-te-policy switch-delay delete-delay command on the headend of SRv6 TE Policy to adjust switchover and deletion delays based on service requirements. Then, after a new segment list is established, the system waits for the specified switching delay to expire before switching traffic to the new segment list. After the switchover is complete, the system waits for the specified deletion delay to expire before tearing down the original primary segment list.

Delayed deletion takes effect only for up segment lists (including backup segment lists) in an SRv6 TE Policy.

Example

# Set the switch delay and delete delay for SRv6 TE Policies.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] srv6-te-policy switch-delay 10000 delete-delay 10000
