display default-parameter mpls ldp

Function

The display default-parameter mpls ldp command displays default MPLS LDP configurations.

Format

display default-parameter mpls ldp

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To view default MPLS LDP configurations, run the display default-parameter mpls ldp command.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display default MPLS LDP configurations.
<HUAWEI> display default-parameter mpls ldp

Whether graceful deletion is enabled. The default value is "Off", indicating that graceful deletion is disabled.

Default value of the LDP session Reconnect timer, in seconds.

Label retention mode

Label distribution mode

Label advertisement

Default value of the local Hello hold timer, in seconds.
Remote hello-hold timer(sec)

Default value of the Keepalive hold timer of LDP local and remote sessions.
Backoff timer init(sec)

Duration timer(sec)
