display ipv6 route-monitor-group track-route

Function

The display ipv6 route-monitor-group track-route command displays information about all IPv6 route monitoring groups to which routes are added.

Format

display ipv6 route-monitor-group track-route [ vpn-instance vpn-instance-name ] destination mask-length

Parameters

Parameter Description Value
vpn-instance vpn-instance-name

Displays information about all IPv6 route monitoring groups to which the routes of a specified VPN instance are added. If vpn-instance <vpn-instance-name> is specified, information about all IPv6 route monitoring groups to which routes of the specified VPN instance are added is displayed. If vpn-instance <vpn-instance-name> is not specified, information about all IPv6 route monitoring groups to which public network routes are added is displayed.

The value is a string of 1 to 31 case-sensitive characters, spaces not supported. The VPN instance name cannot be _public_. If the character string is quoted by double quotation marks, the character string can contain spaces.
destination

Displays information about all IPv6 route monitoring groups to which routes with a specified destination address are added.

The value is a 32-bit hexadecimal string in format X:X:X:X:X:X:X:X.
mask-length

Displays information about all IPv6 route monitoring groups to which routes with a specified mask length are added.

It is an integer ranging from 0 to 128.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

All network-side routes to be monitored can be added to a route monitoring group. An IPv6 route monitoring group can be created using the ipv6 route-monitor-group command. After an IPv6 route monitoring group is created, you can run the track ipv6 route command to add routes to the IPv6 route monitoring group. A route can be added to multiple IPv6 route monitoring groups. Therefore, the display ipv6 route-monitor-group track-route command has the following functions:

  • Displays information about all IPv6 route monitoring groups to which routes are added.
  • After routes are added to the IPv6 route monitoring group, check whether the routes are successfully added to the IPv6 route monitoring group.
  • Displays whether routes are deleted from the IPv6 route monitoring group.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display information about all IPv6 route monitoring groups to which the route 2001:db8:1::1/64 is added.
<HUAWEI> display ipv6 route-monitor-group track-route 2001:db8:1::1 64
 Route monitor group      Total weight     State
 uplink                   600              Enabled
 downlink                 500              Enabled

Weight sum of route monitoring group.

  • Disabled.
