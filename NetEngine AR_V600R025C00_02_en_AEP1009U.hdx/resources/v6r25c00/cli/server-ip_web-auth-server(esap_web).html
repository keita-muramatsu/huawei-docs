server-ip (Web-auth-server template view)

Function

The server-ip command configures an IP address for a Portal server.

The undo server-ip command deletes the IP address of a Portal server.

By default, no IP address is configured for the Portal server.

Format

server-ip { ip-address } &<1-10>

undo server-ip { ip-address | all }

Parameters

Parameter Description Value
ip-address

Specifies the IPv4 address of a Portal server.

The value is in dotted decimal notation.
all

Deletes the IP addresses of all Portal servers.

-

Views

Web-auth-server template view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After creating a Portal server template on the device using the web-auth-server (system view) command, you need to configure parameters for the template.

You can run the server-ip command in the Portal server template view to configure an IP address for the Portal server. After receiving a Portal authentication request packet from a user, the device sends the packet to the Portal server for authentication based on the configured IP address. In addition, multiple IP addresses can be configured in a Portal server template. This allows Portal authentication users to access the same Portal authentication page based on multiple IP addresses, making the authentication process more flexible.

Precautions

  • After the IP address of a Portal server is configured in a Portal server template, the device allows users to access the IP address.
  • If multiple IP addresses are configured for a Portal server in the Portal server template, you are advised to run the url (Portal server template view) command to configure a URL for the Portal server. If no URL is configured, the device uses the first IP address as the URL by default, and the other IP addresses do not take effect.
  • The same server IP address cannot be configured in different Portal server templates.
  • When running the server-ip command to specify an IPv6 address, you must also specify an IPv4 address because the device does not support interaction using the IPv6 Portal protocol.

Example

# Set the IP address of the Portal server to 10.10.10.1 in the Portal server template test.
<HUAWEI> system-view
[HUAWEI] web-auth-server test
[HUAWEI-web-auth-server-test] server-ip 10.10.10.1
