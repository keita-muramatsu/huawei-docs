reset nat-policy counter

Function

The reset nat-policy counter command clears NAT policy rule counter information.

Format

reset nat-policy counter { all | rule rule-name }

Parameters

Parameter Description Value
all

Clears counter information about all NAT policy rules.

-
rule rule-name

Clears counter information about a specified NAT policy rule.

The value is a string of 1 to 63 case-sensitive characters without spaces. If spaces are used, the string must start and end with double quotation marks (").

Views

User view, User view of the virtual system

Default Level

2: Configuration level

Usage Guidelines

NAT policy rule counter information cannot be restored after being cleared. Exercise caution when using the reset nat-policy counter command.

Example

# Clear counter information about a NAT policy rule named abc.
<HUAWEI> reset nat-policy counter rule abc
