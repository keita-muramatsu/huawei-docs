alias(net-assistant device-granted view)

Function

The alias command sets an alias for a device.

The undo alias command deletes the device alias.

By default, no alias is configured.

Format

alias device-alias

undo alias

Parameters

Parameter Description Value
alias device-alias

Specifies the alias of the device to be approved.

The value is a string of 1 to 64 characters and can contain uppercase letters (A to Z), lowercase letters (a to z), digits (0 to 9), and underscores (_).

Views

Net-assistant device-granted view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

If multiple devices exist on a LAN, you can run this command to set aliases for the master device and member devices. The aliases can be displayed on WebMaster for users to memorize and distinguish the devices.

Precautions

Running this command does not affect the host name set by the sysname command.

Example

# Set an alias for the device with the MAC address 1111-2222-3333.
<HUAWEI> system-view
[HUAWEI] net-assistant
[HUAWEI-net-assistant] device
[HUAWEI-net-assistant-device] device-granted 1111-2222-3333 type lsw
[HUAWEI-net-assistant-device-device-granted-1111-2222-3333] alias huawei12
