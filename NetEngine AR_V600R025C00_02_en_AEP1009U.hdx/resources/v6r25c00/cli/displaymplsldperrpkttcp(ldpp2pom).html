display mpls ldp error packet tcp

Function

The display mpls ldp error packet tcp command displays the count and content of TCP error messages received by LDP.

Format

display mpls ldp error packet tcp [ peer peer-id ]

Parameters

Parameter Description Value
peer peer-id

Specifies a peer LSR ID. If this parameter is configured, information about messages sent by a specified peer is displayed.

The value is in dotted decimal notation.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To view statistics about and contents of TCP error messages that the LDP module receives, run the display mpls ldp error packet tcp command. The information helps diagnose faults.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the count and content of TCP error messages received by LDP.
<HUAWEI> display mpls ldp error packet tcp
