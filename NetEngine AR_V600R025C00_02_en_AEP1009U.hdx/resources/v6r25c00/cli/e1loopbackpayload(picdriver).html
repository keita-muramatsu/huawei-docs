loopback payload(E1/CE1 interface view)

Function

The loopback payload command configures a payload loopback mode for an interface.

The undo loopback payload command cancels the payload loopback mode configured for an interface.

By default, loopback detection is disabled.

This command is supported only on the AR8700 series, AR5710-S10T1X2, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series and AR6700-H series.

Format

loopback payload

undo loopback

undo loopback payload

Parameters

None

Views

E1/CE1 interface view, E1 interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In payload loopback mode, the valid payload is looped back in the output direction of the local device. Generally, TS0 is not involved in the loopback. This mode is mainly used to check interface or cable status and should be disabled in normal cases.

Precautions

You can run this command only when the device supports E1 interfaces.

The loopback and clock configurations on an interface are mutually exclusive.

Before running the loopback payload command, ensure that the current interface works in the default master clock mode (configured using the undo clock or clock master command).

Example

# Enable the payload loopback mode on E1 0/0/0.
<HUAWEI> system-view
[HUAWEI] controller E1 0/0/0
[HUAWEI-E1 0/0/0] loopback payload
