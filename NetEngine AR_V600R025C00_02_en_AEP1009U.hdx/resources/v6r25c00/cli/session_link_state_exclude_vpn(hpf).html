session link-state exclude vpn-instance

Function

The session link-state exclude vpn-instance command disables link stateful inspection for traffic bound to a specified VPN instance.

The undo session link-state exclude vpn-instance command unbinds the link stateful inspection function from a VPN instance and restores the link stateful inspection function of the VPN instance.

By default, no VPN instance is bound to link stateful inspection. If link stateful inspection is enabled, the device detects traffic of all VPN instances.

Format

session link-state exclude vpn-instance vpn-instance-name

undo session link-state exclude vpn-instance vpn-instance-name

Parameters

Parameter Description Value
vpn-instance-name

Specifies the name of a VPN instance.

The value is a string of 1 to 31 case-sensitive characters without spaces. The VPN instance name cannot be _public_. The character string can contain spaces if it is enclosed with double quotation marks (").

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In certain scenarios, when the link stateful inspection function is enabled, you can run the session link-state exclude vpn-instance command to disable the link stateful inspection function for the VPN instance if you do not want to perform stateful inspection on the traffic bound to the VPN instance.

Prerequisites

Run the ip vpn-instance command in the system view to create a VPN instance.

Example

# Configure a VPN instance, set the RD value, and disable stateful inspection for the traffic of vpna.
<HUAWEI> system-view
[HUAWEI] ip vpn-instance vpna
[HUAWEI-vpn-instance-vpna] ipv4-family
[HUAWEI-vpn-instance-vpna-af-ipv4] route-distinguisher 100:1
[HUAWEI-vpn-instance-vpna-af-ipv4] quit
[HUAWEI-vpn-instance-vpna] quit
[HUAWEI] session link-state exclude vpn-instance vpna
