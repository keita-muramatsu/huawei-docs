uac reach-access-threshold

Function

The uac reach-access-threshold command configures the action to be taken to control subsequent user access when the number of access users reaches the threshold.

The undo uac reach-access-threshold command disables SSID hiding or replaces SSIDs based on user priorities.

By default, SSID hiding and priority-based user replacement are disabled.

Format

uac reach-access-threshold { hide-ssid | priority-replace }

undo uac reach-access-threshold

Parameters

Parameter Description Value
hide-ssid

Indicates SSID hiding.

-
priority-replace

Indicates priority-based user replacement.

-

Views

RRM profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

With the user CAC function enabled, you can configure the action to be taken to control subsequent access users after the number of access users reaches the threshold. The following actions are supported:

  • Reject new STA access. This is the default action.
  • Reject new STA access and hide the SSID.
  • Allow access preemption by high-priority users.

Prerequisites

The user CAC function has been enabled using the uac { client-number | client-snr } enable command.

Precautions

  • When you run the undo uac { client-number | client-snr } enable command to disable user CAC, SSID hiding is automatically canceled.
  • The uac reach-access-threshold priority-replace command takes effect only when user CAC based on the number of users is enabled.

Example

# Enable SSID hiding.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] rrm-profile name test
[HUAWEI-wlan-rrm-prof-test] uac client-number enable
[HUAWEI-wlan-rrm-prof-test] uac reach-access-threshold hide-ssid
# Prohibit only new users from accessing the network.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] rrm-profile name test
[HUAWEI-wlan-rrm-prof-test] undo uac reach-access-threshold
# Replace access users based on priorities.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] rrm-profile name test
[HUAWEI-wlan-rrm-prof-test] uac client-number enable
[HUAWEI-wlan-rrm-prof-test] uac reach-access-threshold priority-replace
Info: This configuration only takes effective when uac client-number enabled.
