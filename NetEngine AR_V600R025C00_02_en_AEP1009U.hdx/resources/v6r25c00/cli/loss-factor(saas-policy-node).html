loss-factor(saas-policy-node view)

Function

The loss-factor command sets the packet loss rate weight for a SaaS policy node.

The undo loss-factor command deletes the packet loss rate weight of a SaaS policy node.

By default, no packet loss rate weight (%) is configured for a SaaS policy node.

Format

loss-factor value

undo loss-factor [ value ]

Parameters

Parameter Description Value
loss-factor value

Sets the packet loss rate weight (%).

The value is an integer ranging from 0 to 100.

Views

saas-policy-node view

Default Level

2: Configuration level

Usage Guidelines

By default, qualified links are selected for SaaS application access. During link evaluation, the QoE score of a link is calculated based on the packet loss rate base value, delay base value, packet loss rate weight, and NQA link detection result. The formula for calculating the link score is as follows: QoE = loss-factor x (loss-baseline/real-loss) + (100 – loss-factor) x (delay-baseline/real-delay).

The packet loss rate weight configured in the SaaS policy node view takes precedence over that configured in the SaaS cloud access view. If no packet loss rate weight is configured in the SaaS policy node view, the packet loss rate weight configured in the SaaS cloud access view is used.

Example

# Create SaaS policy node 1 and set the packet loss rate weight to 40%.
<HUAWEI> system-view
[HUAWEI] saas-cloud-express
[HUAWEI-saas-cloud-express] saas-policy node 1
[HUAWEI-saas-cloud-express-saas-policy-node-1] loss-factor 40
