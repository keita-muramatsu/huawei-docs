modem-event services-unavailable

Function

The modem-event services-unavailable command sets the service availability detection interval and the maximum number of automatic modem restart attempts or the maximum number of automatic SIM card switchover attempts.

The undo modem-event services-unavailable command restores the default configuration.

By default, the service availability detection interval is 3600s, the automatic recovery action is modem restart, and the number of restart attempts is 0, indicating that the number of restart attempts is unlimited.

Format

modem-event services-unavailable interval interval action { none | { modem-reboot | sim-switch } retry-times retry-times }

undo modem-event services-unavailable

Parameters

Parameter Description Value
interval interval

Specifies the service availability detection interval.

The value is an integer in the range from 60 to 3600, in seconds. The default value is 3600.
action

Specifies the automatic recovery action when no service is available.

-
none

Indicates that the automatic recovery action is null, that is, no action is taken.

-
modem-reboot

Indicates that the automatic recovery action is modem restart when no service is available.

-
sim-switch

Indicates that the automatic recovery action is SIM card switchover when no service is available.

-
retry-times retry-times

Specifies the maximum number of automatic recovery attempts.

The value is an integer in the range from 0 to 10. The default value is 0, indicating that the number of automatic recovery attempts is unlimited.

Views

Cellular template view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When the network environment is abnormal and no service is available, you can run the modem-event services-unavailable command to set the service availability detection interval and the maximum number of automatic modem restart attempts or the maximum number of automatic SIM card switchover attempts. When the service availability detection interval is reached, the device automatically restarts the modem or switches the SIM card based on the configuration.

When the service becomes available within the detection interval or the number of automatic restart attempts or automatic SIM card switchover attempts reaches the preset threshold, no automatic recovery action will be made.

You can run the display cellular command to check the current service status of the modem. When Current Service Status is Service available, the modem service is recovered.

Service availability detection will be performed only when automatic dial-up is enabled.

After automatic dial-up is enabled, the device sets the service availability detection interval to 3600s, the automatic recovery action to modem restart, and the number of restart attempts to 0 (the number of restart attempts is unlimited) by default. You can run the modem-event services-unavailable command to modify the service availability detection interval, automatic recovery action, and number of restart attempts.

To disable service availability detection, run the modem-event services-unavailable action none command.

Precautions

Only the AR5710-S8T2XE-LTE4EA-T, AR5710-S8T2X-LTE4EA, AR5710-S10T1X2, AR5710-S8T2XE-NRGL, AR5710-S8P2XE-NRGL, AR5710-S8T1XWE-NRGL, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8TWDSE-LTE4EA, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-H8T2TS1, AR5710-H8T2TS1-T, AR5710-H4T4N2X-LTE4EA, AR5710-H2T4N2X-NRGL, AR5710-H2T4PN2X-NRGL, AR6700 series, and AR8000 series support this command.

Example

# Set the service availability detection interval to 400s, the service recovery action to SIM card switchover, and the maximum number of switchover attempts to 7.
<HUAWEI> system-view
[HUAWEI] cellular-profile profileName
[HUAWEI-cellular-profile-profileName] modem-event services-unavailable interval 400 action sim-switch retry-times 7
# Set the service availability detection interval to 300s, the service recovery action to modem restart, and the maximum number of restart attempts to 7.
<HUAWEI> system-view
[HUAWEI] cellular-profile profileName
[HUAWEI-cellular-profile-profileName] modem-event services-unavailable interval 300 action modem-reboot retry-times 7
