display debugging wlan

Function

The display debugging wlan command displays the debugging status of WLAN modules.

Format

display debugging wlan { all | wcfg | wdbm | wdev | wess | wglb | wids | wlbm | wmap | wmng | wrfm | wsec | wsrv | wss | wsta | wvap }

Parameters

Parameter Description Value
all

Specifies all modules.

-
wcfg

Specifies the WCFG module.

-
wdbm

Specifies the WDBM module.

-
wdev

Specifies the WDEV module.

-
wess

Specifies the WESS module.

-
wglb

Specifies the WGLB module.

-
wids

Specifies the WIDS module.

-
wlbm

Specifies the WLBM module.

-
wmap

Specifies the WMAP module.

-
wmng

Specifies the WMNG module.

-
wrfm

Specifies the WRFM module.

-
wsec

Specifies the WSEC module.

-
wsrv

Specifies the WSRV module.

-
wss

Specifies the WSS module.

-
wsta

Specifies the WSTA module.

-
wvap

Specifies the WVAP module.

-

Views

User view

Default Level

1: Monitoring level

Usage Guidelines

You can run this command to check the debugging status of WLAN modules.
