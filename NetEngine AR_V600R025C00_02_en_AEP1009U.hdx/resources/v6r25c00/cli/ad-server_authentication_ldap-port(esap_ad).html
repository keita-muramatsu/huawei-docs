ad-server authentication ldap-port

Function

The ad-server authentication ldap-port command sets the LDAP port of an AD authentication server.

The undo ad-server authentication ldap-port command restores the default value.

By default, the LDAP port number of an AD authentication server is 389, and the LDAP SSL port number of an AD authentication server is 636.

Format

ad-server authentication ldap-port port ldap-ssl-port port

undo ad-server authentication ldap-port

Parameters

Parameter Description Value
port

Specifies the LDAP port number.

The value is an integer from 1 to 65535.
ldap-ssl-port port

Specifies the LDAP SSL port number.

The value is an integer from 1 to 65535.

Views

AD server template view

Default Level

3: Management level

Usage Guidelines

The port number must be consistent with those on the LDAP server.

Example

# Set the LDAP port of an AD authentication server to 3899, and set the LDAP SSL port of an AD authentication server to 3900. 
<HUAWEI> system-view
[HUAWEI] ad-server template temp1
[HUAWEI-ad-temp1] ad-server authentication ldap-port 3899 ldap-ssl-port 3900
