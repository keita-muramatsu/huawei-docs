learn-client-address disable(VAP profile view)

Function

The learn-client-address disable command disables STA IP address learning.

The undo learn-client-address disable command enables STA IP address learning.

By default, STA IP address learning is enabled.

Format

learn-client-address ipv4 disable

learn-client-address ipv6 disable

undo learn-client-address ipv4 disable

undo learn-client-address ipv6 disable

Parameters

Parameter Description Value
ipv6

Specifies an IPv6 address.

-
ipv4

Specifies the IPv4 address.

-

Views

VAP profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If a STA is associated with a STA address learning-enabled AP and obtains an IP address, the AP proactively reports the STA's IP address to the AC to maintain the IP address-MAC address binding entry of the STA. In addition, when a STA requests an IP address using DHCP, the AP can learn the IPv4 address of the STA gateway.

Prerequisites

Before enabling STA address learning, ensure that the ND trusted interface of the AP for the IPv6 address has been disabled using the undo nd trust port command.

Before disabling STA address learning, ensure that strict STA IPv4 address learning has been disabled using the undo learn-client-address dhcp-strict command and strict STA IPv6 address learning disabled using the undo learn-client-address dhcpv6-strict command.

Precautions

  • If a bridging device functions as a STA to connect to an AP enabled with STA IP address learning, the AP cannot learn IP addresses of STAs connected to the bridging device; therefore, the STAs cannot communicate with the network. In this case, disable STA address learning.
  • After you run the ipv6 address command to configure the IPv6 address of the gateway, an IPv6 prefix is automatically generated. You can use the ipv6 nd ra prefix command to configure more IPv6 prefixes, which is not recommended.
  • In offline management VAP scenarios, STA IP address learning does not take effect.
  • Before disabling STA IP address learning, run the undo learn-client-address conflict-uncheck command in the VAP profile view to enable STA address conflict check.
  • Disabling STA IP address learning will cause Portal authentication failures.
  • Gateway addresses of only the IPv4 type can be learned.
  • If no STA connected to an AP enabled with this function requests an IP address using DHCP, the AP cannot learn the gateway IP address.

Example

# Disable STA IPv4 address learning.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] vap-profile name vap1
[HUAWEI-wlan-vap-prof-vap1] learn-client-address ipv4 disable
