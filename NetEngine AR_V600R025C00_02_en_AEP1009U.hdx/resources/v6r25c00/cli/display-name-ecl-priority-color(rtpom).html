display ip extcommunity-list priority-color

Function

The display ip extcommunity-list priority-color command displays detailed configurations of priority-color extended community filters.

Format

display ip extcommunity-list priority-color [ priority-color-name ]

Parameters

Parameter Description Value
priority-color-name

Specifies the name of a priority-color extended community filter.

The value is a string of 1 to 51 case-sensitive characters. If spaces are used, the string must start and end with double quotation marks (").

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Extended community attributes are BGP-specific attributes. Priority-color extended community filters are mainly used to filter EVPN routes.

The display ip extcommunity-list priority-color command applies to the following scenarios:

  • A user wants to check detailed configurations of the existing priority-color extended community filters.
  • A user wants to check whether a priority-color extended community filter is deleted successfully after running the undo ip extcommunity-list priority-color command.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display detailed configurations of priority-color extended community filters.
<HUAWEI> display ip extcommunity-list priority-color
Named Extended Community Priority-color basic list: pri_bas
    index: 10            deny       4:400 5:500
Named Extended Community Priority-color advanced list: pri_adv
    index: 10            permit     2:200 4:400

Name of the basic priority-color extended community filter.
Named Extended Community Priority-color advanced list

Name of the advanced priority-color extended community filter.
deny

Matching mode, which is deny.

Matching mode, which is permit.
