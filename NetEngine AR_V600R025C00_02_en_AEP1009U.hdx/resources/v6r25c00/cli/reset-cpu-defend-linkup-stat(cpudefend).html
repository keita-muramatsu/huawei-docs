reset cpu-defend linkup statistics

Function

The reset cpu-defend linkup statistics command clears statistics about linkup.

Format

For AR8100 series, AR8700 series, AR6700-H series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5700-H series, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR5710-S8TWDSE-LTE4EA, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S10T1X2:

reset cpu-defend linkup statistics [ packet-type packet-type ] all

For AR8100 series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5700-H series, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR5710-S8TWDSE-LTE4EA, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S10T1X2:

reset cpu-defend linkup statistics [ packet-type packet-type ] slot slot-id

Parameters

Parameter Description Value
packet-type packet-type

Displays the configuration of rate limiting for packets of a specified type.

The options are as follows:

  • bgp
  • bgp4plus
  • ftp
  • isis
  • ospf
  • ospfv3
  • ssh
  • telnet
  • tftp
all

Indicates all boards.

-
slot slot-id

Displays the configuration of protocol association sessions in a specified slot.

NOTE:

This parameter is supported only on the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series and AR5710-S8P1XDSE-2LTE4EA.

The value must be set according to the device configuration.

Views

User view

Default Level

3: Management level

Usage Guidelines

To collect statistics about linkup within a period of time, you can run the reset cpu-defend linkup statistics command to clear the existing statistics, wait for a period of time, and then run the display cpu-defend linkup statistics command to view statistics about linkup.

Example

# Clear statistics about linkup on all devices.
<HUAWEI> reset cpu-defend linkup statistics packet-type telnet all
