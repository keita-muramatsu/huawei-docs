slave switchover(system view)

Function

The slave switchover command performs a manual active/standby board switchover.

This command is supported only on the AR8700 series and AR6700-H series.

Format

slave switchover [ slot slot-id ]

Parameters

Parameter Description Value
slot slot-id

Specifies the ID slot that becomes the active slot.

The value depends on the device. You can enter a question mark (?) and select a value from the displayed value range.

Views

System view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

Boards are usually deployed in 1:1 mode (one active and one standby) to improve device reliability. If the active board becomes faulty, the system automatically performs an active/standby board switchover. If the active board is abnormal, for example, if the CPU usage is high but not high enough to trigger an automatic active/standby board switchover, you can run the slave switchover command to perform a manual active/standby board switchover.

Prerequisites

The forcible active/standby board switchover function has been enabled using the slave switchover enable command.

Configuration Impact

After the slave switchover command is run, the original active board is reset and becomes the new standby board, and the original standby board becomes the new active board.

Follow-up Procedure

After running the slave switchover command, you can run the display switchover state command to check whether the active/standby switchover is successful.

Precautions

Before running the slave switchover command, you are advised to run the display switchover state command to check whether the active and standby boards meet switchover conditions.

Example

# Enable forcible active/standby board switchover and then perform a manual switchover.
<HUAWEI> system-view
[HUAWEI] slave switchover enable
[HUAWEI] slave switchover
Warning: This operation will switch the slave board to the master board. Continue? [Y/N]:y
Please wait...
Switching OK
This board has been switched slave successfully, and it will be reset
