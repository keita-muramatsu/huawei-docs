srv6-te-policy segment-list reverse-binding-sid switch-delay binding-sid delete-delay

Function

The srv6-te-policy segment-list reverse-binding-sid switch-delay binding-sid delete-delay command configures a switching delay for the reverse binding SID of an SRv6 TE Policy's segment list and a deletion delay for the forward binding SID of the SRv6 TE Policy's segment list.

The undo srv6-te-policy segment-list reverse-binding-sid switch-delay binding-sid delete-delay command restores the default switching delay for the reverse binding SID of an SRv6 TE Policy's segment list and the default deletion delay for the forward binding SID of the SRv6 TE Policy's segment list.

By default, the switching delay for the reverse binding SID of an SRv6 TE Policy's segment list is 5000 ms, and the deletion delay for the forward binding SID of the SRv6 TE Policy's segment list is 20000 ms.

Format

srv6-te-policy segment-list reverse-binding-sid switch-delay switchDelay binding-sid delete-delay deleteDelay

undo srv6-te-policy segment-list reverse-binding-sid switch-delay switchDelay binding-sid delete-delay deleteDelay

Parameters

Parameter Description Value
delete-delay deleteDelay

Specifies a deletion delay for the forward binding SID of an SRv6 TE Policy's segment list.

The value is an integer ranging from 0 to 600000, in milliseconds.
switch-delay switchDelay

Specifies a switching delay for the reverse binding SID of an SRv6 TE Policy's segment list.

The value is an integer ranging from 0 to 600000, in milliseconds.

Views

Segment routing IPv6 view

Default Level

2: Configuration level

Usage Guidelines

This command is used to adjust the switching delay for the reverse binding SID of an SRv6 TE Policy's segment list and the deletion delay for the forward binding SID of the SRv6 TE Policy's segment list.

In a scenario where BFD return packets enter a tunnel, if the binding SIDs of an SRv6 TE Policy's segment list are updated and the switching and deletion delays are set to 0 for the binding SIDs, BFD may be disconnected. As a result, the SRv6 TE Policy goes down, affecting traffic forwarding.

Example

# Set the switching delay for the reverse binding SID of an SRv6 TE Policy's segment list to 6000 ms and the deletion delay for the forward binding SID of the SRv6 TE Policy's segment list to 10000 ms.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] srv6-te-policy segment-list reverse-binding-sid switch-delay 6000 binding-sid delete-delay 10000
