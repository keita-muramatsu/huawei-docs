display av full-scan-mode

Function

The display av full-scan-mode command displays the maximum number of files and the maximum size of each file that can be concurrently detected by each ASE service process on each CPU.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

display av full-scan-mode { max-file-number | max-file-size }

Parameters

Parameter Description Value
max-file-number

Indicates the maximum number.

-
max-file-size

Indicates the maximum size of a single file.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run the display av full-scan-mode max-file-number command to check the maximum number of files that can be concurrently detected by each ASE service process on each CPU.

You can run the display av full-scan-mode max-file-size command to check the maximum size of a single file that can be detected by each ASE service process on each CPU.

The two parameters are configured using the av full-scan-mode { max-file-number max-number-value| max-file-size max-size-value} command.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the maximum number of files that can be detected concurrently by each ASE service process on each CPU.
<HUAWEI> display av full-scan-mode max-file-number
Info: Currently full scan mode max file number is: 500
# Display the maximum size of a single file detected by each ASE service process on each CPU.
<HUAWEI> display av full-scan-mode max-file-size
Info: Currently full scan mode max file size is: 2048
Table 1 Description of the display av full-scan-mode command output
Item Description
Info: Currently full scan mode max file number is

Maximum number of files that can be concurrently checked by each ASE service process on each CPU. This parameter is configured using the av full-scan-mode max-file-number command.
Info: Currently full scan mode max file size is

Maximum size of a single file detected by each ASE service process on each CPU. This parameter is configured using the av full-scan-mode max-file-size command.
