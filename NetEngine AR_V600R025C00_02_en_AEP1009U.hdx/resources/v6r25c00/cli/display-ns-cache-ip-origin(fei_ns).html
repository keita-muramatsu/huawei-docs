display netstream cache ip origin

Function

The display netstream cache ip origin command displays details about IPv4 original flow statistics on a device.

Format

display netstream cache ip origin [ [ top top-value [ sort-by { bytes | packets } ] ] | [ { inbound | outbound } | source interface { interface-name | interface-type interface-number } | source port port-number | source ip ip-address | destination interface { dst-interface-name | dst-interface-type dst-interface-number } | destination port dst-port-number | destination ip dst-ip-address | tos tos-num | protocol protocol-num | start-time start-time | end-time end-time ] * ] slot slot-id [ verbose ]

Parameters

Parameter Description Value
top top-value

Specifies the number of flows that need to be displayed in a certain order.

The value is an integer in the range from 1 to 200.
sort-by

Specifies the order in which flows are displayed. By default, data is sorted by byte.

-
bytes

Indicates that the flows are displayed in the order of bytes.

-
packets

Indicates that the flows are displayed in the order of packets.

-
inbound

Specifies incoming packets.

-
outbound

Specifies outgoing packets.

-
source

Specifies the source information of packets.

-
interface interface-type interface-number

Specifies the source interface of packets.

-
interface dst-interface-type dst-interface-number

Specifies the destination interface of packets.

-
interface-name

Specifies the name of the source interface of packets.

The value is a string of 1 to 63 case-sensitive characters. It cannot contain spaces.
port port-number

Specifies the source port number of packets.

The value is an integer ranging from 0 to 65535.
port dst-port-number

Specifies the destination port number of packets.

The value is an integer ranging from 0 to 65535.
ip ip-address

Specifies the source IPv4 address of packets.

The value is in dotted decimal notation.
ip dst-ip-address

Specifies the destination IPv4 address of packets.

The value is in dotted decimal notation.
destination

Specifies the destination information of packets.

-
dst-interface-name

Specifies the name of the destination interface of packets.

The value is a string of 1 to 63 case-sensitive characters. It cannot contain spaces.
tos tos-num

Specifies the ToS value of packets.

The value is an integer ranging from 0 to 255.
protocol protocol-num

Specifies the protocol type of packets.

The value is an integer ranging from 0 to 255.
start-time start-time

Indicates the time when a flow table is created.

The format is YYYY/MM/DD,HH:MM:SS. YYYY-MM-DD indicates year/month/day. YYYY ranges from 1970 to 2099, MM ranges from 1 to 12, and DD ranges from 1 to 31. HH:MM:SS indicates hour:minute:second. HH ranges from 0 to 23. MM and SS range from 0 to 59.
end-time end-time

Indicates the time when a flow table is updated.

The format is YYYY/MM/DD,HH:MM:SS. YYYY-MM-DD indicates year/month/day. YYYY ranges from 1970 to 2099, MM ranges from 1 to 12, and DD ranges from 1 to 31. HH:MM:SS indicates hour:minute:second. HH ranges from 0 to 23. MM and SS range from 0 to 59.
slot slot-id

Specifies a slot ID.

The value is a string of 1 to 31 case-sensitive characters without spaces.
verbose

Displays detailed information.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

This command displays real-time statistics on IPv4 original flows on the device.

Precautions

You need to run this command before the statistics are aged out. Otherwise, no information is displayed when you run this command.

Example
