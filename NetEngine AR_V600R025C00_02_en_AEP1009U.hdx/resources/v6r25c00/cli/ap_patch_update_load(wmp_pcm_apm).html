ap-patch update load

Function

The ap-patch update load command loads a patch to a specified AP.

The undo ap-patch update load command cancels patch upgrade for a specified AP.

Format

ap-patch update load { ap-mac ap-mac | ap-id ap-id } update-filename update-file-name [ next-startup ]

undo ap-patch update load { ap-mac ap-mac | ap-id ap-id }

Parameters

Parameter Description Value
ap-mac ap-mac

Specifies the AP's MAC address.

The AP's MAC address must already exist.
ap-id ap-id

Specifies the AP ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
update-filename update-file-name

Specifies the name of an AP patch file.

The value is a string of 1 to 255 case-sensitive characters. Ensure that the file name is the same as the actual patch file name, with a file name extension of .pat.
next-startup

Specifies the patch for next startup.

-

Views

WLAN view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

When you load the patch for multiple APs of a specified type, a version exception will lead to a long-time patch uninstallation. Therefore, before batch loading a patch, you can load the patch for a single AP for testing, helping to detect any exception in advance and ensuring the success of subsequent batch patch loading.

If the parameter next-startup is specified, the patch is loaded upon next startup. If this parameter is not specified, the patch is loaded immediately and is also used for next startup.

Prerequisites

When the AC-mode is used for the upgrade, the AP's patch file has been uploaded to the WAC. When the AP upgrade mode is set to ftp-mode or sftp-mode, the AP patch file must have been uploaded to the FTP or SFTP server.

Follow-up Procedure

You can run the display ap update status command to view the patch loading progress.

Precautions

If the AP version is earlier than V200R021C10, the patch is also uninstalled when you run the undo ap-patch update load command to cancel the AP patch upgrade. Running this command cancels the AP patch upgrade but does not uninstall the patch only when the AP version is V200R021C10 or later. To uninstall the patch, run the ap-patch delete command.

SFTP is recommended because it is more secure than FTP.

Example

# Load the patch file AirEngineX760_V600R022C00.pat to AP 0.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-patch update load ap-id 0 update-filename AirEngineX760_V600R022C00.pat
Info: The current upgrade mode is AC mode, which may affect performance and take a long time. The FTP or SFTP upgrade mode is recommended. Continue? [Y/N]: y
