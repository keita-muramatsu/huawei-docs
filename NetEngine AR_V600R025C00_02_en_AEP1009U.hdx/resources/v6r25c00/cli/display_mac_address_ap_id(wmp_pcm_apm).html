display mac-address ap-id

Function

The display mac-address ap-id command displays dynamic MAC address entries, secure dynamic MAC address entries, and sticky MAC address entries on an AP's wired interface.

Format

display mac-address ap-id ap-id interface-type interface-number

Parameters

Parameter Description Value
ap-id ap-id

Displays configuration information about the AP with a specified ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
interface-type

Displays MAC address entries on a specified outbound interface.

-
interface-number

Displays MAC address entries on a specified outbound interface.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run the display mac-address ap-id command to check all dynamic MAC address entries, secure dynamic MAC address entries, and sticky MAC address entries on an AP's wired interface, including MAC addresses and VLANs learned on a specified AP interface.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display dynamic MAC address entries, secure dynamic MAC address entries, and sticky MAC address entries on wired interfaces of AP 1.
<HUAWEI> display mac-address ap-id 1 ethernet 0
Total: 1 
---------------------------------------------------------- 
MAC Address    VLAN/VSI   Learned-From        Type       
----------------------------------------------------------
00e0-fc54-5a80 1/-        Ethernet0/0/0       dynamic 
----------------------------------------------------------
Table 1 Description of the display mac-address ap-id command output
Item Description
MAC Address

MAC address.
VLAN/VSI

ID of the VLAN or name of the VSI to which the device belongs.
Learned-From

Interface that learns a MAC address.
Type

Type of a MAC entry.
Total

Total count.
