poe priority

Function

The poe priority command sets the power priority of a PoE interface.

The undo poe priority command restores the default power priority of a PoE interface.

By default, the power supply priority of an interface is low.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA.

Format

poe priority { critical | high | low }

undo poe priority

Parameters

Parameter Description Value
critical

Indicates the highest priority.

-
high

Indicates the second highest priority.

-
low

Indicates the lowest priority.

-

Views

10GE interface view, 25GE interface view, GE interface view, Multi-GE interface view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When the output power of a device is insufficient, the device in automatic power management mode provides power for the interfaces of the higher power supply priorities first and cuts off power of the interfaces of the lower power supply priorities. If all the interfaces are of the same priority, the power supply priority of the interface with a smaller interface number is higher.

Precautions

  • This command is supported only on Layer 2 interfaces.
  • When the PoE priority of an interface is increased and the available PoE power is insufficient, PDs connected to some low-priority interfaces may be powered off.
  • When the PoE priority of an interface is lowered and the available PoE power is insufficient, PDs connected to the interface may be powered off.

Example

# Set the power supply priority of the interface to critical.
<HUAWEI> system-view
[HUAWEI] interface GE 1/0/1
[HUAWEI-GE1/0/1] poe priority critical
Warning: This operation may power off some PDs with a low priority. Continue?[Y/N]:y
# Set the power supply priority of the interface to low.
<HUAWEI> system-view
[HUAWEI] interface GE 1/0/1
[HUAWEI-GE1/0/1] poe priority low
Warning: This operation may power off the PD connected to this port. Continue? [Y/N]:y
