poe power

Function

The poe power command sets the maximum output power of an interface.

The undo poe power command restores the default maximum output power of an interface.

By default, the maximum output power of an interfaces is 90000mW.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA.

Format

poe power power-value

undo poe power

Parameters

Parameter Description Value
power-value

Specifies the maximum output power of an interface.

The value is an integer ranging from 0 to 90000, in mW.

Views

10GE interface view, 25GE interface view, GE interface view, Multi-GE interface view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The PD negotiation power may be different from the power required by some non-standard PDs or PDs that cannot be classified. You can run the poe power command to set the maximum output power of the interface, which prevents power overload for PDs and saves energy.

Generally, the maximum power required by a standard PD is 30000 mW. To be compatible with more PDs, the device provides a maximum interface power.

Precautions

This command is supported only on Layer 2 interfaces.

After the maximum output power is configured on an interface, the configured maximum output power takes effect when the PD is powered on next time.

Example

# Set the maximum output power on the interface to 20000 mW.
<HUAWEI> system-view
[HUAWEI] interface GE 1/0/1
[HUAWEI-GE1/0/1] poe power 20000
