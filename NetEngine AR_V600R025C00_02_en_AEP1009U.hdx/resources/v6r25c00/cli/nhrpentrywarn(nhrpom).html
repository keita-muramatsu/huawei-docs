nhrp capacity warning-threshold

Function

The nhrp capacity warning-threshold command sets the alarm threshold for the number of NHRP peer entries.

The undo nhrp capacity warning-threshold command restores the default alarm threshold for the number of NHRP peer entries.

By default, the alarm threshold for the number of NHRP peer entries is 90.

Format

nhrp capacity warning-threshold threshold-value

undo nhrp capacity warning-threshold [ threshold-value ]

Parameters

Parameter Description Value
warning-threshold threshold-value

Specifies an alarm threshold for NHRP peer entries.

The value is an integer ranging from 80 to 100.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

On a large DSVPN with hundreds or even thousands of spokes, the number of NHRP peer entries on the hub is huge. Setting an alarm threshold is a core preventive monitoring measure, helping administrators receive warnings before the number of peer entries approaches the device's processing capacity limit. NHRP peer entries consume key resources such as device memory. If the number of entries increases sharply—due to massive invalid registrations caused by factors such as misconfiguration, network attacks, or software defects—resources may be exhausted, causing device performance deterioration, disruption of existing tunnels, or even device breakdown. Threshold alarms are warnings against catastrophic faults. Normally, the number of NHRP peer entries should be the same as the number of online and successfully registered spokes (each spoke usually corresponds to one peer entry on the hub). If the number of NHRP peer entries increases rapidly and unexpectedly in a short period of time, issues such as network attacks or instability may exist. Threshold alarms help detect such exceptions quickly.

To set an alarm threshold for the number of NHRP peer entries, run the nhrp capacity warning-threshold command. When the number of NHRP peer entries reaches or exceeds the configured alarm threshold, an alarm is reported. When the number of NHRP peer entries falls below the alarm threshold, the reported alarm is cleared.

Prerequisites

NHRP has been enabled using the nhrp enable command.

Example

# Set the alarm threshold of NHRP peer entries to 95% of the specification.
<HUAWEI> system-view
[HUAWEI] nhrp enable
[HUAWEI] nhrp capacity warning-threshold 95
