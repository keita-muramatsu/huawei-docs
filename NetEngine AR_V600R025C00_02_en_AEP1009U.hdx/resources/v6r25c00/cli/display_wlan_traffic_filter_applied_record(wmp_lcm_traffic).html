display wlan traffic-filter applied-record

Function

The display wlan traffic-filter applied-record command displays applications of ACL-based packet filtering.

Format

display wlan traffic-filter applied-record

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

The display wlan traffic-filter applied-record command displays applications of ACL-based packet filtering on a device. The command output helps you check the packet filtering configuration and locate faults.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display applications of ACL-based packet filtering on the device.
<HUAWEI> display wlan traffic-filter applied-record
Total:2                                                                         
-------------------------------------------------------------------             
Traffic profile                     Direction  AppliedRecord                    
-------------------------------------------------------------------             
p1                                  inbound    IPv4 ACL 3000                         
p2                                  inbound    IPv6 ACL 3001                    
-------------------------------------------------------------------   
Total:2
------------------------------------------------------------------------
Wired port profile                  Direction  AppliedRecord
------------------------------------------------------------------------
fll                                 inbound    IPv4 ACL 3031
fll                                 outbound   IPv4 ACL 3000
------------------------------------------------------------------------
Table 1 Description of the display wlan traffic-filter applied-record command output
Item Description
Traffic profile

Traffic profile to which ACL-based packet filtering is applied.
Direction

Direction in which packet filtering is configured. The value can be:

  • inbound: indicates that packet filtering is performed in the inbound direction.
  • outbound: indicates that packet filtering is performed in the outbound direction.
AppliedRecord

Application records of ACL-based packet filtering.
Wired port profile

AP wired port profile to which packet filtering is applied.
Total

Applications to which ACL-based packet filtering is performed.
