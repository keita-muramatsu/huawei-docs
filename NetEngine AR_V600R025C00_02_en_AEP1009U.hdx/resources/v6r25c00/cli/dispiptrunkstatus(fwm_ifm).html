display fwm ip-trunk status

Function

The display fwm ip-trunk status command displays the status of an IP-Trunk interface.

Format

display fwm ip-trunk status trunk-id

Parameters

Parameter Description Value
trunk-id

Specifies the number of an IP-Trunk interface.

For the AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T and AR6710-L14T2X4:The value is an integer ranging from 0 to 15.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 7.

For the AR8700 series, AR8100 series and AR6700-H series:The value is an integer ranging from 0 to 63.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

After an IP-Trunk interface is configured, you can run this command to check the status of the IP-Trunk interface.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the status of an IP-Trunk interface.
<HUAWEI> display fwm ip-trunk status 3
TRUNK_STATUS table information:                                                                                                     
---------------------------------------                                                                                             
Slot 0                                                                                                                            
Hash type            : 1                                                                                                            
IfIndex              : 69                                                                                                           
Trunk state          : 0                                                                                                            
Trunk valid flag     : 1
Table 1 Description of the display fwm ip-trunk status command output
Item Description
Slot

Slot ID.
Hash type

Hash type. Available type values are as follows:

1: hash based on source and destination IP addresses.

2: hash based on source and destination MAC addresses.

4: hash based on the destination IP address.

5: hash based on the destination MAC address.

6: hash based on the source IP address.

7: hash based on the source MAC address.

8: enhanced hash.

9: elastic hash.

10: random hash.

11: round robin algorithm-based hash.

14: dynamic hash.
IfIndex

Interface index.
Trunk state

Interface status. The value 0 indicates down, and the value 1 indicates up.
Trunk valid flag

Whether the IP-Trunk interface is valid. The value 0 indicates that the IP-Trunk interface is invalid, and the value 1 indicates that the IP-Trunk interface is valid.
