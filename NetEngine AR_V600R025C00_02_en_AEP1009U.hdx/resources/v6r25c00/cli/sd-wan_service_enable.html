sd-wan service enable

Function

The sd-wan service enable command enables SD-WAN services on a tunnel interface.

The undo sd-wan service enable command disables SD-WAN services on a tunnel interface.

By default, SD-WAN services are disabled for a tunnel interface.

Format

sd-wan service enable

undo sd-wan service enable

Parameters

None

Views

Tunnel interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When configuring different VPN tunnel interfaces to carry services, you can run the sd-wan service enable command to enable SD-WAN services on the tunnel interfaces.

Prerequisites

Run the tunnel-protocol sd-wan command in the interface view to change the tunnel encapsulation protocol of the tunnel interface to SD-WAN.

Precautions

  1. This command can be used only on the tunnel interface whose tunnel encapsulation protocol is SD-WAN.
  2. If a VPN instance is bound to the tunnel interface, the VPN instance cannot be bound to other tunnel interfaces whose tunnel encapsulation protocol is SD-WAN.
  3. If no VPN instance is bound to the tunnel interface, this command can be run on only one tunnel interface whose tunnel encapsulation protocol is SD-WAN.

Example

# Enable SD-WAN services on Tunnel 0.
<HUAWEI> system-view
[HUAWEI] interface tunnel 0
[HUAWEI-Tunnel0] tunnel-protocol sd-wan
[HUAWEI-Tunnel0] sd-wan service enable
