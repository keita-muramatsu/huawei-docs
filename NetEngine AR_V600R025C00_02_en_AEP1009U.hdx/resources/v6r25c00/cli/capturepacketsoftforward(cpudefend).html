capture-packet soft-forward

Function

The capture-packet soft-forward command configures the device to obtain CPU-forwarded packets that match the specified ACL on the specified interface.

The capture-packet soft-forward drop command configures the device to obtain discarded CPU-forwarded packets that match the specified ACL on the specified interface.

By default, the device is not configured to obtain CPU-forwarded packets that match the specified ACL on the specified interface.

By default, the device is not configured to obtain discarded CPU-forwarded packets that match the specified ACL on the specified interface.

Format

capture-packet soft-forward [ acl { { acl-number2 | name acl-name } | ipv6 { acl-number2 | name acl-name } } ] { interface { interface-type interface-name | IfName } [ inbound | outbound ] } destination { file file-name | terminal } [ time-out timeoutvalue | packet-num packnumvalue | packet-len packlenthvalue | sample-rate samplerate-value ] *

capture-packet soft-forward drop [ acl { { acl-number2 | name acl-name } | ipv6 { acl-number2 | name acl-name } } ] [ interface { interface-type interface-name | IfName } ] destination { file file-name | terminal } [ time-out timeoutvalue | packet-num packnumvalue | packet-len packlenthvalue | sample-rate samplerate-value ] *

Parameters

Parameter Description Value
acl

Configures an ACL.

-
acl-number2

Obtains packets that match a specified ACL.

The value is an integer ranging from 2000 to 3999.
name acl-name

Creates an ACL with a name.

The value is a string of 1 to 32 case-sensitive characters without spaces. The value must start with a letter or digit, and cannot contain only digits.
ipv6

Configures an IPv6 address.

-
interface interface-type interface-name

Obtains packets on a specified interface.

  • interface-type specifies the interface type.
  • interface-name specifies the interface number.

-
interface-name

Obtains·packets·on·a·specified·interface.

-
IfName

Obtains packets on a specified interface.

-
inbound

Obtains incoming packets.

-
outbound

Obtains outgoing packets.

If inbound and outbound are not specified, the device obtains packets in both directions by default.

-
destination

Indicates the destination to which obtained packet information is sent.

-
file file-name

Saves obtained packet information to a file. The file name extension must be .cap.

The value is a string of 5 to 64 case-sensitive characters. It cannot contain spaces and paths. It cannot contain the following special characters: ~ ? * \ : / | < > [ ].
terminal

Displays information about the obtained packets on the terminal.

-
time-out timeoutvalue

Specifies the timeout period for obtaining packets. The device stops the packet capture instance when the timeout period expires.

The value is an integer that ranges from 1 to 86400, in seconds. The default value is 60 seconds.
packet-num packnumvalue

Specifies the number of packets to be obtained. The device stops the packet capture instance when the specified number of packets are obtained.

The value is an integer in the range from 1 to 5000. The default value is 100.
packet-len packlenthvalue

Specifies the length of obtained packets to be displayed on the terminal or stored on the storage medium.

The value is an integer ranging from 20 to 64, in bytes. The default value is 64 bytes. (After the packet capture feature package is installed, the value is in the range from 20 to 9500, and the default value is still 64 bytes.)
sample-rate samplerate-value

Specifies the sampling rate of packet capture.

The value is an integer in the range from 1 to 10000. The default value is 100.

Views

User view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

To obtain CPU-forwarded packets that match the specified ACL on the specified interface for analysis, run the capture-packet soft-forward command.

To obtain discarded CPU-forwarded packets that match the specified ACL on the specified interface for analysis, run the capture-packet soft-forward drop command.

Precautions

  • If the file for storing obtained packets is deleted during packet obtaining, the content of subsequent packets cannot be written into the file.
  • When the IPv4 ACL-based packet capture function is configured, the fragment flag cannot be matched.

Example

# Configure an instance for obtaining CPU-forwarded packets matching ACL 3000 on 10GE0/0/1, and save all the obtained packets to the file.
<HUAWEI> system-view
Enter system view, return user view with return command.                                                                            
[HUAWEI] acl 3000
[HUAWEI-acl4-advance-3000] rule permit ip source any
[HUAWEI-acl4-advance-3000] quit
[HUAWEI] quit
<HUAWEI> capture-packet soft-forward acl 3000 interface 10GE 0/0/1 inbound destination file capture.cap
# Configure an instance for obtaining the packets that need to be forwarded by the CPU, match ACL 3000, but are discarded on the CPU of 10GE0/0/1, and save all the obtained packets to the capture.cap file.
<HUAWEI> system-view
Enter system view, return user view with return command.                                                                            
[HUAWEI] acl 3000
[HUAWEI-acl4-advance-3000] rule permit ip source any
[HUAWEI-acl4-advance-3000] quit
[HUAWEI] quit
<HUAWEI> capture-packet soft-forward drop acl 3000 interface 10GE 0/0/1 destination file capture.cap
