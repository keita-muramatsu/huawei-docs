ble work mode

Function

The ble work mode command sets the Bluetooth working mode.

The undo ble work mode command restores the default Bluetooth working mode.

By default, when an AP has no external card or has one serial-port card in position, Bluetooth works in Bluetooth serial port mode. When a device has two serial-port cards in position, the Bluetooth serial port does not work after the AP is started.

Format

ble work mode { iot | console }

undo ble work mode

Parameters

Parameter Description Value
iot

Configures Bluetooth to work in IoT mode.

-
console

Configures Bluetooth to work in Bluetooth serial port mode.

-

Views

AP system profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Bluetooth can work in Bluetooth serial port mode and IoT mode. You can set only one working mode at a time. If IoT services, such as electronic shelf label (ESL), need to be deployed on a network, you can run this command to switch the Bluetooth working mode to IoT.

Precautions

For the AirEngine 6776-26HD and AirEngine 6776-58TI:

Mode No Card Only One Serial-Port Card Two Serial-Port Cards
IoT Bluetooth works in IoT mode.

1. Bluetooth works in IoT mode.

2. Either card1 or card2 can work.

1. Bluetooth works in IoT mode.

2. Only card1 can work.

Console Bluetooth works in Bluetooth serial port mode.

1. Bluetooth works in Bluetooth serial port mode.

2. Either card1 or card2 can work.

1. Bluetooth works in Bluetooth serial port mode.

2. Only card1 can work.

Default status Bluetooth works in Bluetooth serial port mode.

1. Bluetooth works in Bluetooth serial port mode.

2. Either card1 or card2 can work.

1. Bluetooth does not work.

2. Both card1 and card2 can work.

Example

# Enable the IoT function of the Bluetooth chip on APs in the AP system profile view.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name ap-system1
[HUAWEI-wlan-ap-system-prof-ap-system1] ble work mode iot
