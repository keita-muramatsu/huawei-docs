vht mcs-map (SSID profile view)

Function

The vht mcs-map command configures the maximum number of spatial streams and the maximum MCS value allowed by 802.11ac in an SSID profile.

The undo vht mcs-map command restores the default configuration.

By default, the maximum number of spatial streams and the maximum MCS value are not specified in the SSID profile.

Format

vht { tx | rx } mcs-map nss nss-value map mcs-value

undo vht { tx | rx } mcs-map

Parameters

Parameter Description Value
tx

Transmits data.

-
rx

Receives data.

-
nss nss-value

Specifies the maximum number of available spatial streams.

The value is an integer that ranges from 1 to 8.
map mcs-value

Specifies the maximum MCS value that can be negotiated for spatial streams.

The value is an integer that ranges from 7 to 9.

Views

SSID profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When an AP uses the 802.11ac protocol, the rate of the AP is configured based on the MCS index. A larger MCS value indicates a higher transmission rate.

  • When nss-value is greater than or equal to the maximum number of spatial streams supported by an AP, the maximum number of spatial streams supported by the AP is used.
  • When nss-value is smaller than the maximum number of spatial streams supported by an AP, the number of available spatial streams is the same as the specified nss-value and remaining spatial streams do not take effect.

    For example, if nss-value is set to 2 and the AP supports a maximum of 3 spatial streams, the AP can use a maximum of 2 spatial streams.

Precautions

This configuration takes effect only when an AP communicates with STAs using 802.11ac or 802.11ax.

Modifying the configuration may cause STAs to go offline and the performance to deteriorate.

Example

# In the SSID profile, set the maximum number of available spatial streams to 2 and the maximum MCS value to 8.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ssid-profile name ssid1
[HUAWEI-wlan-ssid-prof-ssid1] vht rx mcs-map nss 2 map 8
Info: "vht/he mcsmap" in the SSID profile and "vht rx mcsmap" in the 5G radio profile take effect in descending order.
