rts-cts-mode(Radio-5G-profile view)

Function

The rts-cts-mode command sets the request to send (RTS)-clear to send (CTS) operation mode in a radio profile.

The undo rts-cts-mode command restores the default RTS-CTS operation mode in a radio profile.

By default, the RTS-CTS operation mode is rts-cts.

Format

rts-cts-mode { disable | rts-cts }

undo rts-cts-mode

Parameters

Parameter Description Value
disable

Disables RTS-CTS.

-
rts-cts

Sets the RTS-CTS operation mode to rts-cts.

-

Views

5G radio profile view

Default Level

2: Configuration level

Usage Guidelines

In rts-cts mode, when an AP needs to send data to a STA, the AP sends an RTS packet to all STAs associated with it. After receiving the RTS packet, none of the devices within the AP's coverage area sends data within a specified period. After the destination STA receives the RTS packet, it returns a CTS packet. After receiving the CTS packet, none of the devices within the STA's coverage area sends data within a specified period. Using this mode to avoid conflicts requires two packets (RTS and CTS packets), increasing packet overhead.

Example

# Set the RTS-CTS operation mode to rts-cts in a 5G radio profile.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] radio-5g-profile name default
[HUAWEI-wlan-radio-5g-prof-default] rts-cts-mode rts-cts
