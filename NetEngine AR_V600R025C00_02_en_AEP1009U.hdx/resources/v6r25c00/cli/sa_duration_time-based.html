sa duration time-based

Function

The sa duration time-based command sets the SA lifetime in a P2MP policy.

The undo sa duration time-based command restores the default SA lifetime in a P2MP policy.

By default, the SA lifetime is 1440 minutes.

Format

sa duration time-based time-value

undo sa duration time-based [ time-value ]

Parameters

Parameter Description Value
time-value

Specifies the SA lifetime, in minutes.

The value is an integer in the range of 60 to 43200. The default value is 1440.

Views

IPSec P2MP policy view

Default Level

2: Configuration level

Usage Guidelines

To enable SAs to be updated in real time, run the sa duration time-based command to configure the SA lifetime. This reduces the risk of SA cracking and enhances security.

There are two types of lifetime: hard lifetime (hard timeout period) and soft lifetime (soft timeout period). Hard lifetime indicates the lifetime of an SA.

Soft lifetime indicates the time after which a new SA is negotiated to replace the existing SA before the hard lifetime of the existing SA is about to expire.

Before the existing SA is about to expire, a new SA needs to be negotiated. After the new SA is negotiated, a peer uses it to protect communication. If service traffic is being transmitted, the existing SA will be deleted immediately. If no service traffic is transmitted, the existing SA will be deleted after the hard lifetime expires.

Example

# Set the SA lifetime in the P2MP policy named aa to 60 minutes.
<HUAWEI> system-view
[HUAWEI] ipsec p2mp-policy aa
[HUAWEI-ipsec-p2mp-policy-aa] sa duration time-based 60
