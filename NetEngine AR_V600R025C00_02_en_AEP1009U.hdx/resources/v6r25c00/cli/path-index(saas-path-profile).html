path-index(saas-path-profile view)

Function

The path-index command specifies a path index in a SaaS path profile.

The undo path-index command deletes a specified path index from a SaaS path profile.

By default, no path index is specified in a SaaS path profile.

Format

path-index index

undo path-index index

Parameters

Parameter Description Value
path-index index

Specifies the path index in the SaaS path profile.

The value is an integer ranging from 1 to 20.

Views

saas-path-profile view

Default Level

2: Configuration level

Usage Guidelines

The list of paths that can be used for SaaS application access can be specified through indexes. The index values 1 to 10 indicate the indexes of DIA paths, and the index values 11 to 20 indicate the indexes of tunnel interfaces connected to the SIG. The two types of indexes cannot be specified together. If a local DIA path is specified on the local end, the specified peer DIA path index must also belong to the local DIA path index.

Example

# Specify path index 1 for the DIA outbound interface, create a SaaS path profile named profile1, enter the SaaS path profile view, and set the DIA path index to 1.
<HUAWEI> system-view
[HUAWEI] saas-cloud-express
[HUAWEI-saas-cloud-express] path-index 1 interface 10GE 0/0/1
[HUAWEI-saas-cloud-express] saas-path profile profile1
[HUAWEI-saas-cloud-express-saas-path-profile-profile1] path-index 1
