tunnel-protocol

Function

The tunnel-protocol command configures the tunnel mode on a tunnel interface.

The undo tunnel-protocol command restores the default setting.

By default, the tunnel interface is not configured with any tunnel mode.

Format

tunnel-protocol { ipv6-ipv4 | gre [ p2mp ] | none | ipsec | ipv4-ipv6 }

undo tunnel-protocol

Parameters

Parameter Description Value
ipv6-ipv4

Indicates the IPv6 over IPv4 manual tunnel mode. An IPv6 over IPv4 manual tunnel offers the point-to-point service.

-
gre

Specifies the GRE mode for the tunnel interface.

-
p2mp

Indicates the gre p2mp tunnel mode.

-
none

Indicates that a tunnel interface is not configured with any tunnel mode. A tunnel in this mode is not operative. To use the tunnel interface, select another tunnel mode.

-
ipsec

Configures IPsec as the encapsulation mode on the tunnel interface.

-
ipv4-ipv6

Indicates the IPv4 over IPv6 manual tunnel mode.

-

Views

Tunnel interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When configuring a GRE, IPv6 over IPv4, IPv4 over IPv6, or IPsec tunnel, you need to create a tunnel interface and run the tunnel-protocol command to configure the encapsulation mode of the tunnel interface.

You can select a tunnel mode based on the network topology and application scenario:

An IPv6 over IPv4 manual tunnel is manually configured on the border routers at both ends of the tunnel. The source and destination IPv4 addresses of the tunnel must be statically specified. Such a manual tunnel works in point-to-point mode and can be used for communication between IPv6 networks or between a border router and a host.

An IPv4 over IPv6 manual tunnel is manually configured on the border routers at both ends of the tunnel. The source and destination IPv6 addresses of the tunnel must be statically specified. Such a manual tunnel works in point-to-point mode and can be used for communication between IPv4 networks or between a border router and a host.

Precautions

Changing the tunnel encapsulation mode of a tunnel interface will delete existing parameter settings for the interface, including the source address or source interface, along with NHRP settings.

Example

# Configure the tunnel mode on Tunnel 10 as IPv6 over IPv4.
<HUAWEI> system-view
[HUAWEI] interface Tunnel 10
[HUAWEI-Tunnel10] tunnel-protocol ipv6-ipv4
# Configure the tunnel mode on Tunnel 10 as GRE.
<HUAWEI> system-view
[HUAWEI] interface Tunnel 10
[HUAWEI-Tunnel10] tunnel-protocol gre
