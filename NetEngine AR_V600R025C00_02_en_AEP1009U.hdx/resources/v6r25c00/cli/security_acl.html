security acl

Function

The security acl command specifies an ACL to be referenced in an IPsec policy or IPsec policy template.

The undo security acl command cancels the configuration.

By default, an IPsec policy or IPsec policy template does not reference an ACL.

Format

security acl acl-number

security acl ipv6 acl-number

undo security acl

Parameters

Parameter Description Value
acl acl-number

Specifies an ACL number.

The value is an integer that ranges from 3000 to 3999.
ipv6 acl-number

Specifies an IPv6 ACL.

The value is an integer that ranges from 3000 to 3999.

Views

IPsec policy template view, ISAKMP IPsec policy view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

This command is used to configure an ACL to specify the data flows to be protected by IPsec. If ip-pool or port-pool is empty in an ACL rule, the ACL rule takes effect but the matching conditions related to the address pool are ignored. The matching result of the ACL is determined by all the rules configured for the corresponding service. In real-world applications, you need to configure an advanced ACL to define the data flow to be protected and then reference the ACL in an IPsec policy to protect the data flow. When an IPsec policy is created using a template, defining the data flows to be protected by IPsec on the responder is optional.

  • If no data flow to be protected by IPsec is defined on the responder, the responder accepts the data flows to be protected by IPsec defined on the initiator.
  • If data flows to be protected by IPsec are defined on the responder, the data flows defined on the responder must mirror or include those defined on the initiator.

Precautions

When IPsec references an ACL, rules must be configured in the ACL view and must meet the following requirements. If the requirements are not met, IPsec fails to reference the ACL.

When a rule in a security ACL matches an address set, this ACL can only be applied to IKEv2, and an address set can contain a maximum of 255 IP addresses.

Example

# Reference ACL 3100 in an IPSec policy using the ISAKMP negotiation mode. 
<HUAWEI> system-view
[HUAWEI] acl number 3100
[HUAWEI-acl-adv-3100] rule permit tcp source 10.1.1.1 0.0.0.0 destination 10.1.1.2 0.0.0.0
[HUAWEI-acl-adv-3100] quit
[HUAWEI] ipsec policy policy1 100 isakmp
[HUAWEI-ipsec-policy-isakmp-policy1-100] security acl 3100
