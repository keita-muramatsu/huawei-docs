service disable

Function

The service disable command disables a device from proactively sending a NETCONF connection request to the NMS and establishing a NETCONF connection with the NMS.

The undo service disable command enables a device to proactively send a NETCONF connection request to the NMS and establish a NETCONF connection with the NMS.

By default, a device proactively sends a NETCONF connection request to the NMS and establishes a NETCONF connection with the NMS.

Format

service disable

undo service disable

Parameters

None

Views

Endpoint view

Default Level

3: Management level

Usage Guidelines

In cloud management scenarios where the device does not connect to the NMS, to prevent the device from frequently reconnecting to the registration center and reduce the pressure on the registration center, you can run the service disable command to disable the device from proactively sending a NETCONF connection request to the NMS and establishing a NETCONF connection with the NMS.

Example

# Disable a device from proactively sending a NETCONF connection request to the NMS and establishing a NETCONF connection with the NMS.
<HUAWEI> system-view
[HUAWEI] netconf
[HUAWEI-netconf] callhome root
[HUAWEI-netconf-callhome-root] endpoint huawei
[HUAWEI-netconf-callhome-root-endpoint-huawei] service disable
# Enable a device to proactively send a NETCONF connection request to the NMS and establish a NETCONF connection with the NMS after the device goes online.
<HUAWEI> system-view
[HUAWEI] netconf
[HUAWEI-netconf] callhome root
[HUAWEI-netconf-callhome-root] endpoint huawei
[HUAWEI-netconf-callhome-root-endpoint-huawei] undo service disable
