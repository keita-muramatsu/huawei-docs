dhcp client vendor-specific

Function

The dhcp client vendor-specific command configures a DHCP request packet to carry the Option 125 field.

The undo dhcp client vendor-specific command deletes the Option 125 field from DHCP request packets.

By default, a DHCP request packet does not carry the device name or software version.

Format

dhcp client vendor-specific [ vendor-specific ]

undo dhcp client vendor-specific

Parameters

Parameter Description Value
vendor-specific

Specifies the current device name and software version.

If vendor-specific is specified, the DHCP request packet carries the specified content. If vendor-specific is not specified, the DHCP request packet carries the default system software version and device name.

The value is a string of 1 to 128 characters. It cannot contain spaces.

Views

10GE sub-interface view, 10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE sub-interface view, 40GE interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, Ethernet sub-interface view, Ethernet interface view, GE sub-interface view, GE interface view, Multi-GE interface view, VLANIF interface view, Management interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In ZTP deployment scenarios, the DHCP server stores multiple versions of the same device model. After the dhcp client vendor-specific command is run, the DHCP client encapsulates the Option 125 field into Discover and Request packets to be sent. This solves the problem that the middleware cannot specify the version file.

Precautions

If vendor-specific is not specified, the Options field with the device name and version number is carried by default.

Example

# Set the vendor-specific suboption of Vlanif200 to "deviceA Vx00R024C00."
<HUAWEI> system-view
[HUAWEI] vlan 200
[HUAWEI] interface Vlanif200
[HUAWEI-Vlanif200] dhcp client vendor-specific deviceA Vx00R024C00
# Configure the vendor-specific suboption without a value for Vlanif200.
<HUAWEI> system-view
[HUAWEI] vlan 200
[HUAWEI] interface Vlanif200
[HUAWEI-Vlanif200] dhcp client vendor-specific
