encapsulation source-interface

Function

The encapsulation source-interface command configures a source interface for SRv6 encapsulation.

The undo encapsulation source-interface command deletes the source interface configured for SRv6 encapsulation.

By default, no source interface is configured for SRv6 encapsulation.

Format

encapsulation source-interface { intfname | interfaceType interfaceNum }

undo encapsulation source-interface { intfname | interfaceType interfaceNum }

Parameters

Parameter Description Value
intfname

Specifies the name of an interface.

-
interfaceType

Specifies an interface type. Only the loopback type is supported.

-
interfaceNum

Specifies an interface number.

-

Views

Segment routing IPv6 view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

IPv6 encapsulation is performed during SRv6 data forwarding. The source and destination addresses need to be encapsulated in the IPv6 header. This command is used to specify an interface for source address encapsulation. If multiple IPv6 global addresses exist on the interface, the smallest IPv6 global address on the interface is used as the encapsulation source address.

In unicast forwarding scenarios, SRv6 selects a source address in the following sequence: 1. encapsulation source-interface; 2. Default address ::

In ping and tracert scenarios, SRv6 selects a source address in the following sequence:

In a scenario where a public network route recurses to an SRv6 TE Policy: 1. encapsulation source-interface; 2. IPv6 router ID configured using the te ipv6-router-id command; 3. Minimum interface address configured on the device

In a scenario where a VPN route recurses to an SRv6 TE Policy: 1. encapsulation source-interface; 2. IPv6 router ID configured using the te ipv6-router-id command; 3. Default address ::

Precautions

  1. After the encapsulation source-interface command is run:
    • If no IPv6 global address has been configured for the specified interface, the default address :: is encapsulated as the source address. Once an IPv6 global address is configured for the interface for the first time, the encapsulated source address will be updated.
    • If an IPv6 global address has been configured for the specified interface, the encapsulated source address will not be updated no matter whether new addresses are configured for the interface. If the IPv6 global address being used for SRv6 encapsulation is deleted, an error message will be displayed.
  2. Both the encapsulation source-interface and encapsulation source-address commands are used to configure an SRv6 encapsulation source address. If both of them are run, the later configuration overrides the previous one. You can run either of them in actual deployments.

Example

# Configure an interface for SRv6 source address encapsulation.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] encapsulation source-interface LoopBack 2
