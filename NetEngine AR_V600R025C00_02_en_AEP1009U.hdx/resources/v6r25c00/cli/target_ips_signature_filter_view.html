target (ips signature filter view)

Function

The target command adds the IPS signature of the specified target to an IPS signature filter.

The undo target command deletes the specified target from the filtering condition.

By default, no target is specified in the IPS signature filter.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

target { both | client | server }

undo target

Parameters

Parameter Description Value
both

Adds signatures that detect packets to both clients and servers to a signature filter.

-
client

Adds signatures that detect packets to clients to a signature filter.

-
server

Adds signatures detecting packets to servers to a signature filter.

-

Views

IPS signature filter view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

For example, for TCP/UDP packets, the initiator is the client, whereas the destination of the TCP/UDP packets is the server.

Precautions

After running this command, run the engine configuration commit command to commit the configuration for the configuration to take effect. You are advised to commit the configuration after all content security configurations are complete.

Example

# Configure target server in IPS signature filter hello in IPS profile profile1. 
<HUAWEI> system-view
[HUAWEI] profile type ips name profile1
[HUAWEI-profile-ips-profile1] signature-set name hello
[HUAWEI-profile-ips-profile1-sigset-hello] target server
