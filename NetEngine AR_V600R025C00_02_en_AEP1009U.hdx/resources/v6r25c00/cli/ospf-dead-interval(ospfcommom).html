ospf timer dead

Function

The ospf timer dead command sets a dead interval for the OSPF neighbor in the instance to which an interface belongs.

The undo ospf timer dead command restores the default value.

By default, the dead interval of OSPF neighbors is 40s on a P2P or broadcast interface and is 120s on an NBMA or P2MP interface.

Format

ospf timer dead interval

undo ospf timer dead

Parameters

Parameter Description Value
interval

Specifies a dead interval for OSPF neighbors.

The value is an integer ranging from 1 to 235926000.

Setting a dead interval that is longer than 10s for OSPF neighbors is recommended. If the dead interval is less than 10s, the session may be terminated.

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If no Hello packet is received from a neighbor within a dead interval, the neighbor is considered invalid. The dead interval on OSPF interfaces must be greater than the transmission interval of Hello messages. In addition, the dead intervals of devices on the same network segment must be the same.

By default, the dead interval of OSPF neighbors is four times the transmission interval of Hello messages.

Precautions

  • OSPF does not support the configuration on null interfaces.
  • If the dead interval is less than 10s, the neighbor relationship may be interrupted. Therefore, if the configured dead interval is less than 10s, the following special processing is performed:
    • If the configured dead interval is less than or equal to 5s, the system automatically sets it to 10s.
    • If the configured dead interval is greater than 5s and less than 10s, the system automatically sets it to twice the configured value.
  • If the ospf timer hello command is run and the conservative parameter is specified to enable the conservative mode of the neighbor dead timer, and the configured neighbor dead interval is less than 10 seconds, the system determines whether the neighbor is invalid based on the configured value.

Example

# Set the dead interval on the interface to 60 seconds. 
<HUAWEI> system-view
[HUAWEI] interface 10GE0/0/0
[HUAWEI-10GE0/0/0] undo portswitch
[HUAWEI-10GE0/0/0] ospf timer dead 60
