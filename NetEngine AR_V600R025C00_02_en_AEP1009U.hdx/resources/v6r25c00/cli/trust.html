trust

Function

The trust command configures the device to perform priority mapping on packets based on a specified priority.

The undo trust command disables the device from performing priority mapping on packets based on a specified priority.

By default, the device does not trust any packet priority.

Format

trust { 8021p { inner | outer } | dscp }

undo trust

Parameters

Parameter Description Value
8021p

Maps packets based on the 802.1p priority.

-
inner

Maps packets based on the inner 802.1p priority.

-
outer

Maps packets based on the outer 802.1p priority.

-
dscp

Maps packets based on the DSCP priority.

-

Views

10GE interface view, 25GE interface view, 40GE interface view, Cellular channel interface view, Dialer interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, GE interface view, IP-Trunk interface view, MP-group interface view, Multi-GE interface view, POS interface view, Virtual serial interface view, Sub-interface view, Interface group view, Ethernet interface view, Ethernet sub-interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

A DiffServ domain defines the mapping between PHBs/colors and two types of priorities, namely, 802.1p priority and DSCP priority. When the DiffServ domain is bound to an interface, you can run the trust command to specify the priority to be mapped.

To set the same priority to be trusted on multiple interfaces, you can perform the configuration on a port group to reduce the workload.

Precautions

  • If the trust 8021p { inner | outer } command is configured:
    • For untagged packets, the trusted priority is the interface priority.
    • For single-tagged packets, the trusted priority is the priority of the tag.
  • If you run the trust command multiple times in the same interface view, only the latest configuration takes effect.
  • Layer 3 sub-interfaces do not support the trust 8021p inner command.
  • MP-group and serial interfaces support only the trust dscp command.
  • POS and IP-Trunk interfaces support only the trust dscp command.

The AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2XE, AR5710-S8T2X-LTE4EA, AR5710-S8T2XE-LTE4EA-T, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8T1XWE, AR5710-S8T2S, AR5710-S8T2XE-NRGL, AR5710-S8P2XE-NRGL, AR5710-S8T1XWE-NRGL, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8TWDSE-LTE4EA, AR5710I-RU-NRGL devices do not support this command on Layer 2 interfaces.

Example

# Configure 10GE0/0/1 to trust DSCP priorities.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] trust dscp
