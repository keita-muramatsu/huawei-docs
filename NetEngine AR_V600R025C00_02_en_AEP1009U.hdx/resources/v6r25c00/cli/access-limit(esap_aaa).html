access-limit

Function

The access-limit command sets the maximum number of connections that can be established for local access users.

The undo access-limit command restores the default setting.

By default, the maximum number of connections that can be established for local access users is 4294967295.

Format

access-limit max-number

undo access-limit

Parameters

Parameter Description Value
max-number

Indicates the maximum number of connections that can be created with a specified user name.

If this parameter is not specified, a user can establish a maximum of 4294967295 connections by default.

The value is an integer that ranges from 1 to 4294967295.

The actual number of access connections is determined by the smaller value between the max-number value configured using the command and the maximum number of access users of different types allowed by different device models.

Views

aaa-access-user view

Default Level

3: Management level

Usage Guidelines

The access-limit command sets the maximum number of connections that can be established for local access users.

Example

# Set the maximum number of connections that can be established for the local access user hello@163.net to 1000. 
<HUAWEI> system-view
[HUAWEI] aaa
[HUAWEI-aaa] local-access-user hello@163.net
[HUAWEI-aaa-access-user-hello@163.net] access-limit 1000
