scan-period

Function

The scan-period command sets the air scan period.

The undo scan-period command restores the default air scan period.

By default, the air scan period is 60 ms.

Format

scan-period period-time

undo scan-period

Parameters

Parameter Description Value
period-time

Specifies the air scan period.

The value is an integer ranging from 60 to 100, in milliseconds.

Views

air scan profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After the air scan period is configured using the scan-period command, an AP continuously scans surrounding radio signals in the configured period. After the period expires, the AP reports the collected information to an AC or server for data analysis such as radio calibration.

Precautions

A longer air scan period indicates more collected data and a more accurate data analysis result. However, a long air scan period may affect WLAN services. The default value is recommended.

Example

# Set the air scan period to 80 ms for APs.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] air-scan-profile name huawei
[HUAWEI-wlan-air-scan-prof-huawei] scan-period 80
