accept eula

Function

The accept eula command manually signs the EULA on a device.

This command is supported only on the AR6700-H series.

Format

accept eula

Parameters

None

Views

User view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

The EULA protocol is used to quickly agree on responsibilities between users and device vendors. When using the product, you need to run this command to manually sign the EULA to indicate that you accept the license agreement.

Precautions

  • When the device has been running for 10 minutes after startup, it checks the EULA signing status. If the EULA is not signed, the device reports an alarm to prompt the user to sign the EULA.
  • If the user does not sign the EULA after the device runs for 10 days, the system automatically signs the EULA. After the automatic signing, the alarm is still retained. The alarm can be cleared only after the user manually signs the EULA.
  • In the one-click factory setting restoration scenario, the EULA signing status information is not cleared.

Example

# Sign the EULA.
<HUAWEI> accept eula
Warning: Your use of the product is subject to the HUAWEI end user license agreement https://e.huawei.com/en/about/eula. Activation of the software command line interface will be evidence of your acceptance of this agreement. Are you sure you want to accept it? [Y/N]:y
Info: Operation succeeded.
