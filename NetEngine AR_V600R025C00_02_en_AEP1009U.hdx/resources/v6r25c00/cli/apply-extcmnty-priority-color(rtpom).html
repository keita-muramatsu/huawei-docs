apply extcommunity priority-color

Function

The apply extcommunity priority-color command sets priority-color extended community attribute values for EVPN routes.

The undo apply extcommunity priority-color command cancels the configuration.

By default, no priority-color extended community attribute values are set for EVPN routes.

Format

apply extcommunity priority-color { extCmntyValue } &<1-16> [ additive ]

undo apply extcommunity priority-color [ { extCmntyValue } &<1-16> ] [ additive ]

Parameters

Parameter Description Value
extCmntyValue

Specifies a priority-color extended community attribute value to be applied.

The value of the priority-color extended community attribute consists of two parts: priority and color value. The format is priority:color value, for example, 1:100. The priority value ranges from 0 to 15. The color value can be used to identify a site and ranges from 1 to 4294967295. The value is a string of 3 to 13 characters.
additive

Adds the specified values to the existing priority-color extended community attribute in routes.

-

Views

Route-policy view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In scenarios where an SD-WAN tunnel needs to be generated, to set priority-color extended community attribute values for EVPN routes, run the apply extcommunity priority-color command. After this command is run, an EVPN route advertised by the device carries the configured priority-color extended community attribute values, which identify the next-hop sites of the EVPN route. The priority-color extended community attribute is used to generate SD-WAN tunnel encapsulation information so that packets can be forwarded through the SD-WAN tunnel.

Before using this command, note the following:

  • Create a route-policy using the route-policy command.
  • A route-policy may consist of multiple nodes, and the relationship among these nodes is OR. The device matches routes against the nodes in a route-policy in order of node indexes. If a route matches one of the nodes, the route is considered to match this route-policy and will not be matched against the next node.
  • Each node consists of a set of if-match and apply clauses. The if-match clauses define filtering rules that are based on route attributes. The apply clauses specify actions. If a route matches a node, route attributes will be set for the route based on the defined apply clauses.

Configuration Impact

The apply extcommunity priority-color command takes effect only in BGP-EVPN export and import policies as well as BGP-VPN import and export policies.

After the apply extcommunity priority-color command is run, the priority-color extended community attribute values set in this command will be applied to the EVPN routes that match the specified filtering rules.

Example

# Add the values 1:100 and 2:200 to the priority-color extended community attribute of EVPN routes.
<HUAWEI> system-view
[HUAWEI] route-policy ma1 permit node 1
[HUAWEI-route-policy] apply extcommunity priority-color 1:100 2:200 additive
