vip-user per-packet-tpc disable

Function

The vip-user per-packet-tpc disable command disables per-packet power control for VIP users.

The undo vip-user per-packet-tpc disable command restores the default value of per-packet power control for VIP users.

By default, per-packet power control for VIP users is enabled.

Format

vip-user per-packet-tpc disable

undo vip-user per-packet-tpc disable

Parameters

None

Views

5G radio profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Enabling per-packet power control for VIP users can greatly improve the performance gains for VIP users in weak-coverage scenarios.

Precautions

This command takes effect only in a 5 GHz radio profile configured using the radio-5g-profile command and for AirEngine X776 series APs.

Example

# Disable per-packet power control for VIP users in the 5 GHz radio profile default.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] radio-5g-profile name default
[HUAWEI-wlan-radio-5g-prof-default] vip-user per-packet-tpc disable
