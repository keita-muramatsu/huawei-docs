server(TSM SSO view)

Function

The server command sets the IP address, port number, and shared key of the TSM SSO server.

The undo server command deletes the IP address, port number, and shared key of the TSM SSO server.

By default, the IP address, port number, and shared key of the TSM SSO server are not specified.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR5710-S8P1XDSE-2LTE4EA.

Format

server ip ip-address port port-num shared-key key [ source-ip source-ip-address ]

server ip ip-address port port-num shared-key key [ source-ip source-ip-address ] vpn-instance vpn-instance-name

undo server { ip ip-address port port-num | all }

undo server ip ip-address port port-num vpn-instance vpn-instance-name

Parameters

Parameter Description Value
port port-num

Configures the port number.

The value is an integer ranging from 1 to 65535.
shared-key key

Specifies the shared key, which must be the same as that on the TSM SSO server.
  • The value is a string of 8 to 32 case-sensitive non-ciphertext characters or a string of 128 to 148 case-sensitive ciphertext characters. Special characters such as exclamation mark (!), at sign (@), number sign (#), dollar sign ($), and percent (%) are supported. The system converts the character string into a ciphertext key and saves it in the configuration file. The length of the ciphertext is 128 to 148 bytes. If the string is enclosed in double quotation marks ("), spaces are allowed in the string.
  • To improve security, the non-ciphertext of the shared key must meet the minimum complexity requirement. That is, the shared key must contain three types of the following characters: uppercase letters (A to Z), lowercase letters (a to z), digits (0 to 9), and special characters (such as!, @, #, $, and %).
source-ip source-ip-address

Configures the source IP address used by the device to proactively access the TSM SSO server.

The value is in dotted decimal notation.
ip ip-address

Configures an IPv4 address.

The value is in dotted decimal notation.
vpn-instance vpn-instance-name

Specifies the name of the VPN instance to be bound to the TSM service.

The value must be an existing VPN instance name.
all

Indicates all TSM SSO server configurations.

-

Views

TSM SSO view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

A maximum of 20 TSM servers can be configured on a device. The device connects to the TSM servers from top to bottom according to the configuration sequence until the TSM servers are successfully connected.

Precautions

By default, the AES-256-GCM algorithm is used to encrypt packets between the device and the TSM SSO server. The algorithm cannot be changed.

Example

# Set the IP address of the TSM SSO server to 10.1.1.1, port number to 8445, shared key to YsHsjx_202206, and source IP address of the device to 10.2.0.1.
<HUAWEI> system-view
[HUAWEI] identity-management
[HUAWEI-identity-management] sso-tsm
[HUAWEI-identity-management-sso-tsm] local-server ip 10.2.1.1 port 8081
[HUAWEI-identity-management-sso-tsm] server ip 10.1.1.1 port 8445 shared-key YsHsjx_202206 source-ip 10.2.1.1
# Set the IP address of the TSM SSO server to 10.1.1.1, port number to 8445, shared key to YsHsjx_202206, and source IP address of the device to 10.2.0.1, as well as bind the VPN instance vpn1.
<HUAWEI> system-view
[HUAWEI] ip vpn-instance vpn1
[HUAWEI-vpn-instance-v1] quit
[HUAWEI] identity-management
[HUAWEI-identity-management] sso-tsm
[HUAWEI-identity-management-sso-tsm] local-server ip 10.2.1.1 port 8081
[HUAWEI-identity-management-sso-tsm] server ip 10.1.1.1 port 8445 shared-key YsHsjx_202206 source-ip 10.2.1.1 vpn-instance vpn1
