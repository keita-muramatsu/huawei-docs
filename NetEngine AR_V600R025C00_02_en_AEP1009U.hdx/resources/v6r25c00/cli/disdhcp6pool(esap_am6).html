display dhcpv6 pool

Function

The display dhcpv6 pool command displays the IPv6 address pool configurations.

Format

display dhcpv6 pool [ pool-name [ allocated { address | prefix } | binding [ duid ] | conflict address | ipv6-address | ipv6-prefix/ipv6-prefix-length ] ]

Parameters

Parameter Description Value
allocated

Indicates the allocated IPv6 addresses or IPv6 address prefixes in an IPv6 address pool.

-
address

Specifies an IPv6 address.

-
prefix

Specifies an IPv6 address prefix.

-
binding [ duid ]

Specifies the DUID bound to an IPv6 address pool.

The value is a string of an even number of characters ranging from 2 to 260 in hexadecimal notation.
conflict

Indicates conflicting IPv6 addresses in an IPv6 address pool.

-
ipv6-address

Specifies an IPv6 address in the IPv6 address pool.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
ipv6-prefix/ipv6-prefix-length

Specifies the IPv6 prefix in an IPv6 address pool.

The value is a 32-digit hexadecimal number, in the format X:X::X:X/M. The prefix length ranges from 16 to 128.
pool pool-name

Specified an IPv6 address pool name.

The value is a string of 1 to 31 characters. It cannot contain spaces. The value can be a combination of digits, letters, underscores (_), and periods (.).

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

The display dhcpv6 pool command applies to DHCPv6 servers. To query information about IPv6 address pool configurations and dynamic address assignment, run the display dhcpv6 pool command.

NISP domain name suffix allocated by the DHCPv6 server to a DHCPv6 client.

SNTP server address

SNTP server address configured for the IPv6 address pool.

To configure an SNTP server address, run the sntp-server command.
Domain name

Domain name suffix allocated by the DHCPv6 server to the DHCPv6 client.

You can configure the domain name suffix using the dns-domain-name command.
Vendor-specific option

Vendor-specific option.

To configure a vendor-specific option, run the vendor-specific and suboption commands.
Information refresh time

Time for updating configuration parameters assigned to clients through stateless DHCPv6 address autoconfiguration.

The value can be set using the information-refresh command.
Conflict-address expire-time

Aging time of conflicting addresses.

The value can be set using the conflict-address expire-time command.
Renew-time-percent

Percentage of the renewal time to the preferred lifetime.

The value can be set using the renew-time-percent rebind-time-percent command.
Rebind-time-percent

Percentage of the rebinding time to the preferred lifetime.

The value can be set using the renew-time-percent rebind-time-percent command.
Active normal clients

Number of DHCP clients.
Active pd clients

Number of DHCPv6 PD clients.
Logging

Whether the function of recording a log when the DHCPv6 or DHCPv6 PD server allocates an IPv6 address or prefix is enabled. The options are as follows:

  • Enable: The function is enabled.
  • Disable: The function is disabled.

To configure the function, run the logging command in the IPv6 address pool view.
VPN instance

Name of the VPN instance to which the IPv6 address pool belongs.
VPN match

Whether VPN matching is enabled for the IPv6 address pool.
Allocated Address

Address requested by the DHCPv6 client.
Expires at

Timeout period of the entry.
IA ID

IA identifier of the address or PD requested by the DHCPv6 client.
Conflict Address

Conflicting IPv6 address.
Detected time

Time when an IPv6 address conflict was detected.
Client

Link-local address of the DHCPv6 client.
DUID

DUID of the DHCPv6 client.
