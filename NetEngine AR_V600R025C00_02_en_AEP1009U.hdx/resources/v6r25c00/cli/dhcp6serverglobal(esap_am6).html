dhcpv6 server(system view)

Function

The dhcpv6 server command enables the DHCPv6 server or DHCPv6 PD server function in the system view.

The undo dhcpv6 server command disables the DHCPv6 serve or DHCPv6 PD server function in the system view.

By default, the DHCPv6 server or DHCPv6 PD server function is disabled in the system view.

Format

dhcpv6 server { allow-hint | preference preference-value | rapid-commit | unicast } *

undo dhcpv6 server { allow-hint | preference [ preference-value ] | rapid-commit | unicast } *

Parameters

Parameter Description Value
allow-hint

Indicates that the DHCPv6 server allocates addresses, prefixes, and prefix lengths based on the DHCPv6 client requests.

If the allow-hint parameter is specified, the server preferentially allocates addresses, prefixes, and prefix lengths based on the client requests. If the address, prefix, and prefix length requested by a client are not within the address pool or have been allocated to another client, the server ignores the client request and allocates another available address, prefix, and prefix length to the client.

-
preference preference-value

Specifies the server priority in the Advertise packet sent by the device. The DHCPv6 client selects the server with the highest priority based on the server priority in the Advertise packet to assign IPv6 addresses or prefixes.

The value is an integer ranging from 0 to 255.

The default value is 0. A larger value indicates a higher server priority.
rapid-commit

Indicates that the device supports fast address or prefix assignment, that is, two-message exchange.

-
unicast

Indicates unicast communication between the client and server during the address lease renewal process.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When the device functions as a DHCPv6 or DHCPv6 PD server, the DHCPv6 or DHCPv6 PD server function can be enabled in the system view or interface view. If the DHCPv6 or DHCPv6 PD server function is enabled in the interface view, the configuration information only takes effect on the interface and only one IPv6 address pool can be specified on an interface.

When a DHCPv6 or DHCPv6 PD server and clients reside on different links (that is, a DHCPv6 relay agent exists), only one IPv6 address pool can be specified on an interface. As such, If the DHCPv6 or DHCPv6 PD server function is enabled in the interface view, configuration parameters such as IPv6 addresses or prefixes can be assigned to the clients only in one network segment through the relay agent. To use the DHCPv6 relay agent to assign configuration parameters (such as IPv6 addresses or prefixes) to DHCPv6 clients in multiple network segments, enable the DHCPv6 or DHCPv6 PD server function in the system view.

The method of enabling the DHCPv6 or DHCPv6 PD server function in the interface view is affected by the physical interface status. If the interface status is down, the DHCPv6 or DHCPv6 PD server cannot successfully assign configuration parameters to clients through the DHCPv6 relay agent. If the DHCPv6 or DHCPv6 PD server function is enabled in the system view, configuration parameters such as IPv6 addresses can be assigned to clients through the DHCPv6 relay agent as long as one route between the DHCPv6 relay agent and DHCPv6 or DHCPv6 PD server is reachable. This improves the reliability of the configuration obtained by the clients. In addition, requiring no configuration on the interface reduces the administrator's maintenance workload.

  • When the device functions as the DHCPv6 server:
    • If a relay agent exists, the server selects the address pool that belongs to the same link scope with the network prefix (configured using the link-address or address prefix command) based on the first link-address field whose value is not 0 in the message. The link-address field identifies the link scope of DHCPv6 clients.
    • When the DHCPv6 server function is enabled in the system view, if no relay agent exists, the server cannot assign configuration parameters (including IPv6 addresses and DNS, NIS, and SNTP server addresses) to clients through DHCPv6. To resolve this issue, enable the DHCPv6 server function in the interface view.
  • When the device functions as the DHCPv6 PD server:
    • If a relay agent exists, the server selects the address pool that belongs to the same link scope with the network prefix (configured using the link-address command) based on the first link-address field whose value is not 0 in the message. The link-address field identifies the link scope of DHCPv6 clients.
    • If no relay agent exists, the DHCPv6 PD server function cannot be enabled in the system view but can be enabled using the dhcpv6 server command in the interface view.

Prerequisites

DHCP has been enabled using the dhcp enable command in the system view.

Precautions

If the dhcpv6 server command has been configured in the system view but the dhcpv6 server command configured in the interface view does not contain allow-hint, preference <preference-value>, rapid-commit, or unicast, the dhcpv6 server command configuration in the interface view takes effect based on the optional parameters of the dhcpv6 server command configured in the system view.

Example

# Enable the DHCPv6 server function in the system view and set the priority to 255. 
<HUAWEI> system-view
[HUAWEI] dhcp enable
[HUAWEI] dhcpv6 server preference 255
