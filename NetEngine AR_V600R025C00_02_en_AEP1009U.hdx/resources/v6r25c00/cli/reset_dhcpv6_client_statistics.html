reset dhcpv6 client statistics

Function

The reset dhcpv6 client statistics command clears DHCPv6 message statistics on the DHCPv6 client.

Format

reset dhcpv6 client statistics [ interface { interface-type interface-number | interface-name } ]

Parameters

Parameter Description Value
interface interface-type interface-number

Clears DHCPv6 message statistics on a specified interface.

-
interface-name

Clears DHCPv6 message statistics on a specified interface.

-

Views

User view

Default Level

2: Configuration level

Usage Guidelines

This command applies to the DHCPv6 client. Collecting statistics about the DHCPv6 messages sent and received within a specified period helps you locate DHCPv6 faults. Before collecting DHCPv6 message statistics, run the reset dhcpv6 client statistics [ interface <interface-type> <interface-number> ] command to clear existing DHCPv6 message statistics, and then run the display dhcpv6 client statistics [ interface <interface-type> <interface-number> ] command to view DHCPv6 message statistics on the DHCPv6 client.

Example

# Clear message statistics on the DHCPv6 client.
<HUAWEI> reset dhcpv6 client statistics
