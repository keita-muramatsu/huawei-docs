display ike sa

Function

The display ike sa command displays information about SAs established through IKE negotiation.

Format

display ike sa [ remote { ipv4-address | ipv6-address } ] [ slot slot-id cpu cpu-id ]

display ike sa [ slot slot-id cpu cpu-id ] [ remote-id-type { dn | esn | fqdn | ip | user-fqdn } ] remote-id remote-id

display ike sa verbose { remote { ipv4-address | ipv6-address } | connection-id connection-id | [ remote-id-type { dn | esn | fqdn | ip | user-fqdn } ] remote-id remote-id }

Parameters

Parameter Description Value
remote ipv4-address

Specifies a peer IPv4 address.

The value is in dotted decimal notation.
ipv6-address

Specifies a peer IPv6 address.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
slot slot-id

Displays information about the SA in a specified slot.

The value varies depending on device models.
cpu cpu-id

Displays information about the SA with a specified CPU ID.

The value varies depending on device models.
remote-id-type

Specifies a remote ID type.

-
dn

Indicates that the peer ID type is in distinguished name (DN) format.

-
esn

Indicates that the peer ID is in the equipment serial number (ESN) format.

-
fqdn

Specifies the remote ID type as a name.

-
ip

Indicates that the remote ID is in the IP address format.

-
user-fqdn

Specifies the remote ID type as a user domain name.

-
remote-id remote-id

Specifies the remote ID.

The value is a string of 1 to 255 case-sensitive characters and cannot contain spaces. When quotation marks are used around the string, spaces are allowed in the string.
verbose

Displays detailed information about an SA.

-
connection-id connection-id

Specifies the connection index of an SA.

The value is an integer in the range from 1 to 4294967295.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

The display ike sa command displays SA information, including the SA connection index, peer IP address, VPN instance name, SA phase, peer ID type, peer ID, and SA status.

Precautions

After an IPsec tunnel is established and the local ID or remote ID is changed, the display ike sa command does not display the latest local ID or remote ID until the IPsec tunnel is renegotiated.

Flag(s)

SA status:

  • RD-READY: The SA has been established.
  • ST--STAYALIVE: This end is the initiator of the tunnel negotiation.
  • RL-REPLACED: The SA has been replaced by a new one and will be deleted after a period of time.
  • FD--FADING: The SA has encountered a soft timeout and is still in use. The SA will be deleted after the hard timeout.
  • TO-TIMEOUT: The SA does not receive the heartbeat packet after the last heartbeat timer expires. If the SA does not receive the heartbeat packet after the next heartbeat timer expires, the SA is deleted.
  • HRT--HEARTBEAT: The local IKE SA sends heartbeat packets.
  • LKG--LAST KNOWN GOOD SEQ NO.: Last known sequence number.
  • BCK--BACKED UP: Backup state.
  • M-ACTIVE: The IPsec policy group is in the active state.
  • S-STANDBY: The IPsec policy group is in the slave state.
  • A-ALONE: The IPsec policy group is in the non-backup state.
  • NEG--NEGOTIATING: The SA is being negotiated.
  • Empty field: The IKE SA is being negotiated. This is caused by inconsistent parameter settings on both ends of the tunnel.
Phase

SA phase:

  • v2:1: v2 indicates the IKE version. 1 indicates that an IKE SA is established in this phase.
  • v2:2: v2 indicates the IKE version. 2 indicates the phase of negotiating security services. In this phase, an IPsec SA is established.
