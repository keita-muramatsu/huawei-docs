speed(Multi-GE interface view,10GE interface view)

Function

The speed command sets the rate for an Ethernet interface.

The undo speed command restores the default rate of an Ethernet interface.

By default, an Ethernet interface works at its highest rate.

Format

speed { 10000 | 5000 | 2500 | 1000 | 100 }

undo speed [ 10000 | 5000 | 2500 | 1000 | 100 ]

Parameters

Parameter Description Value
10000

Indicates the 10000M port speed mode.

-
5000

Indicates the 5000M port speed mode.

-
2500

Indicates the 2500M port speed mode.

-
1000

Indicates the 1000M port speed mode.

-
100

Indicates the 100M port speed mode.

-

Views

Layer 2 10GE interface view, 10GE interface view, Layer 2 multi-GE interface view, Multi-GE interface view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In non-auto negotiation mode, if interfaces on two connected devices work at different rates, use the speed command to change the rates of the interfaces to be the same so that the two devices can communicate.

Prerequisites

  • Before running the speed command, run the negotiation disable command to configure the electrical interface and the optical interface that has an O/E conversion module installed to work in non-auto-negotiation mode.
  • Before running the speed command, delete the serdes-mode configuration that does not match the rate on all interfaces in the interface group. Otherwise, the configuration cannot be delivered.

Precautions

  • This command is supported only when the device supports MultiGE electrical interfaces or 10G copper modules.
  • If you run the speed command on an interface that is physically up, the physical status of the interface becomes down and then up. Therefore, exercise caution when using this command.
  • Assume that the current module is replaced with a new module and the new module does not support the speed configuration after the interface rate takes effect. For example, if a GE copper module is replaced with a GE optical module, the optical interface does not support the speed configuration after it has the GE optical module installed. In this case, the configuration is lost and the interface goes up.

Example

# Configure 10GE0/0/1 to work at the rate of 100 Mbit/s in non-auto-negotiation mode when it has a 10GE copper module installed.
<HUAWEI> system-view
[HUAWEI] interface 10GE0/0/1
[HUAWEI-10GE0/0/1] negotiation disable
[HUAWEI-10GE0/0/1] speed 100
