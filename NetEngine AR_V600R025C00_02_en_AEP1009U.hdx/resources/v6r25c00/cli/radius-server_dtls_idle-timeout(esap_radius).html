radius-server dtls idle-timeout

Function

The radius-server dtls idle-timeout command sets the idle timeout period of DTLS sessions on the RADIUS server.

The undo radius-server dtls idle-timeout command restores the default value.

By default, the idle timeout period of a DTLS session is 60 seconds.

Format

radius-server dtls idle-timeout idle-timeout-value

undo radius-server dtls idle-timeout [ idle-timeout-value ]

Parameters

Parameter Description Value
idle-timeout-value

Specifies the idle timeout period of DTLS sessions.

The value is an integer that ranges from 60 to 600, in seconds. The default value is 60s.

Views

System view

Default Level

3: Management level

Usage Guidelines

When the device sends a request packet to the RADIUS server, DTLS negotiation is started. If the negotiation succeeds, a DTLS session is used for management. If the device does not send request packets to the RADIUS server for a long time, no user goes online but session resources are occupied. This reduces session resources on other RADIUS servers. In this case, you can run this command to delete DTLS sessions that exceed the idle timeout period to reduce resource waste.

Example

# Set the idle timeout period of DTLS sessions on the RADIUS server to 100 seconds.
<HUAWEI> system-view
[HUAWEI] radius-server dtls idle-timeout 100
