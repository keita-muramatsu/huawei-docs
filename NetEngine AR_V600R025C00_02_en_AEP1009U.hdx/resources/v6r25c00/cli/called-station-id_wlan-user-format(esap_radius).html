called-station-id wlan-user-format

Function

The called-station-id wlan-user-format command sets the encapsulation content of the Called-station-id (30) attribute in RADIUS packets.

The undo called-station-id wlan-user-format command restores the default configuration.

By default, the encapsulation content of the called-station-id (30) attribute is the AP's MAC address and SSID separated with a colon (:), in the format of ap-mac:ssid.

Format

called-station-id wlan-user-format { ap-mac | ac-mac | ac-ip | ap-name | ap-group-name | vlan-id } [ include-ssid [ delimiter delimiter ] ]

undo called-station-id wlan-user-format

Parameters

Parameter Description Value
ap-mac

Indicates that the encapsulation content of the called-station-id (30) attribute is the AP's MAC address.

-
ac-mac

Indicates that the encapsulation content of the called-station-id (30) attribute is the AC's MAC address.

-
ac-ip

Indicates that the encapsulation content of the called-station-id (30) attribute is the AC's IP address.

-
ap-name

Indicates that the encapsulation content of the called-station-id (30) attribute is the AP name.

-
ap-group-name

Indicates that the encapsulation content of the called-station-id (30) attribute is the name of the AP group to which the AP belongs.

-
vlan-id

Indicates that the encapsulation content of the called-station-id (30) attribute is the outer VLAN ID through which a user goes online.

-
include-ssid

Indicates that the SSID is encapsulated in the called-station-id (30) attribute.

If this parameter is not specified, no SSID is encapsulated.

-
delimiter delimiter

Identifiable characters are \ / < > : | @ ' % * + - & ! # ^ ~. The default value is :.

Length < 1 >. Identifiable characters are \ / < > : | @ ' % * + - & ! # ^ ~. The default value is :.

Views

RADIUS server template view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

The default encapsulation format of the MAC address in the called-station-id (30) attribute of RADIUS packets sent by wireless users is ap-mac:ssid. If the RADIUS server does not support the default format, run the called-station-id mac-format command to modify the called-station-id content and format in RADIUS packets.

Example

# Set the encapsulation content of the called-station-id (30) attribute in RADIUS packets to ap-group-name&ssid.
<HUAWEI> system-view
[HUAWEI] radius-server template test
[HUAWEI-radius-test] called-station-id wlan-user-format ap-group-name include-ssid delimiter &
