isis bgp-ls report router-capability ipv6-router-id

Function

The isis bgp-ls report router-capability ipv6-router-id command enables IS-IS to report the IPv6 router ID in the Router Capability TLV through BGP-LS.

The undo isis bgp-ls report router-capability ipv6-router-id command disables IS-IS from reporting the IPv6 router ID in the Router Capability TLV through BGP-LS.

By default, IS-IS is disabled from reporting the IPv6 router ID carried in the Router Capability TLV through BGP-LS.

Format

isis bgp-ls report router-capability ipv6-router-id

undo isis bgp-ls report router-capability ipv6-router-id

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

By default, IS-IS is enabled to report the IPv6 LSR ID carried in the IPv6 TE Router ID TLV through BGP-LS. If the IPv6 TE Router ID TLV is not advertised but the IPv6 router ID carried in the IPv6 Router ID sub-TLV of the Router Capability TLV is needed, run the isis bgp-ls report router-capability ipv6-router-id command. In normal cases, you are advised not to run this command. If different IS-IS processes have different IPv6 router IDs, the controller may fail to calculate paths.

Example

# Enable IS-IS to report the IPv6 router ID carried in the Router Capability TLV through BGP-LS.
<HUAWEI> system-view
[HUAWEI] isis bgp-ls report router-capability ipv6-router-id
