capwap double-stack enable

Function

The capwap double-stack enable command enables the IPv4/IPv6 dual stack function for CAPWAP links.

The undo capwap double-stack enable command restores the default CAPWAP link mode.

By default, the CAPWAP link works in IPv4 single-stack mode.

Format

capwap double-stack enable

undo capwap double-stack enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

  • When APs and ACs are deployed on an IPv6 network and use IPv6 addresses, you can run the capwap ipv6 enable command to enable the IPv6 function of CAPWAP links so that the ACs manage the APs through the IPv6 network.

  • When APs and ACs are deployed on an IPv4 + IPv6 network, you can run the capwap double-stack enable command to enable the dual-stack function of CAPWAP links so that the ACs manage the APs through the IPv4 and IPv6 networks.

  • When APs and ACs are deployed on an IPv4 network, run the undo capwap ipv6 enable or undo capwap double-stack enable command to disable the IPv6 function of CAPWAP links so that the ACs manage the APs through the IPv4 network.

Prerequisites

Before running the undo capwap double-stack enable command to switch the CAPWAP link to the IPv4 single-stack mode, delete the IPv6 source address and IPv6 source interface.

Example

# Enable the IPv4/IPv6 dual-stack function for CAPWAP links on the device.
<HUAWEI> system-view
[HUAWEI] capwap double-stack enable
