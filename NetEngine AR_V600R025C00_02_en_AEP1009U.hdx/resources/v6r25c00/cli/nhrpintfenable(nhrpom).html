nhrp enable (Tunnel interface view)

Function

The nhrp enable command enables Next Hop Resolution Protocol (NHRP).

The undo nhrp enable command disables NHRP.

By default, NHRP is not enabled.

Format

nhrp enable

undo nhrp enable

Parameters

None

Views

Tunnel interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

With the development of services, an enterprise often evolves into a headquarters-and-branch model distributed across different regions, with communication required between branches and the headquarters as well as between branches themselves. To reduce costs, an enterprise typically adopts a DSVPN solution to interconnect the headquarters with geographically dispersed branches. In DSVPN, NHRP is used to enable a source spoke to obtain the dynamic public address of a destination spoke over an NBMA network.

To deploy DSVPN on a tunnel interface, you need to run the nhrp enable command to enable NHRP on the interface first.

Prerequisites

NHRP must be enabled globally before it can be enabled on an interface. To enable NHRP on a tunnel interface, perform the following steps:

  1. Run the system-view command to enter the system view.
  2. Run the nhrp enable command to enable NHRP globally.
  3. Run the tunnel-protocol gre p2mp command to set the encapsulation mode of the tunnel interface to mGRE.
  4. Run the nhrp enable command to enable NHRP on the tunnel interface.

Precautions

Running the undo nhrp enable command will clear all NHRP configurations on the interface and interrupt the running NHRP service. To restore the NHRP service, you must re-configure the NHRP commands that have been deleted from the interface.

Example

# Enable NHRP globally and on a tunnel interface.
<HUAWEI> system-view
[HUAWEI] nhrp enable
[HUAWEI] interface tunnel 0
[HUAWEI-Tunnel0] tunnel-protocol gre p2mp
[HUAWEI-Tunnel0] nhrp enable
