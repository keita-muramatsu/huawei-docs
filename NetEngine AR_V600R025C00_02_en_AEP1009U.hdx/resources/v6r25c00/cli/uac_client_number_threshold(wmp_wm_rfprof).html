uac client-number threshold

Function

The uac client-number threshold command configures the user CAC thresholds based on the number of users.

The undo uac client-number threshold command, you can restore the default user CAC thresholds based on the number of users.

By default, the user CAC access and roaming thresholds based on the number of users are both 64.

Format

uac client-number threshold access access-threshold [ roam roam-threshold ]

undo uac client-number threshold

Parameters

Parameter Description Value
roam roam-threshold

Specifies the user CAC roaming threshold based on the number of users.

This threshold is the total number of users who can be associate with the AP, including all local access and reassociated roaming users. Ensure that the roaming threshold (roam-threshold) is greater than or equal to the access threshold (access-threshold).

The value is an integer that ranges from 1 to 1024. The default value is 64.
access access-threshold

Specifies the user CAC access threshold based on the number of users.

The value is an integer that ranges from 1 to 1024. The default value is 64.

Views

RRM profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

On WLANs where many users exist, such as WLANs in high density scenarios, users compete fiercely to occupy resources as the number of online users increases. As a result, network quality deteriorates. To ensure network access experience of online users, configure the user CAC function. The user CAC function allows an AP to control user access based on the number of online users or terminal SNR, ensuring the Internet access quality of online users.

Prerequisites

The user CAC function based on the number of STAs has been enabled using the uac client-number enable command.

Precautions

The user CAC access threshold is invalid for roaming users. Assume that the user CAC access threshold is 20 and the user CAC roaming threshold is 24. When there are already 20 access users, local users cannot connect to the network but the network allows for four roaming users.

Example

# Set the user CAC access and roaming thresholds based on the number of users to 50 and 60, respectively.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] rrm-profile name test
[HUAWEI-wlan-rrm-prof-test] uac client-number enable
[HUAWEI-wlan-rrm-prof-test] uac client-number threshold access 50 roam 60
