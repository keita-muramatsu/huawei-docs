reset wlan non-wifi-device

Function

The reset wlan non-wifi-device command clears information about non-Wi-Fi devices.

Format

reset wlan non-wifi-device { all | ap-id ap-id radio radio-id }

Parameters

Parameter Description Value
all

Clears information about the non-Wi-Fi devices detected by all APs.

-
ap-id ap-id

Clears information about the non-Wi-Fi devices detected by an AP with a specified ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
radio radio-id

Clears information about the non-Wi-Fi devices detected by an AP radio with a specified ID.

The value is an integer ranging from 0 to 4.

Views

All views

Default Level

3: Management level

Usage Guidelines

Usage Scenario

Before re-collecting information about detected non-Wi-Fi devices in a period, you can clear existing information.

Prerequisites

The spectrum analysis function has been enabled on a radio.

Configuration Impact

The cleared non-Wi-Fi device information cannot be restored. Exercise caution when you perform this operation. After the command is run, you can run the display wlan non-wifi-device history command to view related information.

Example

# Clear information about the non-Wi-Fi devices detected by all APs.
<HUAWEI> reset wlan non-wifi-device all
