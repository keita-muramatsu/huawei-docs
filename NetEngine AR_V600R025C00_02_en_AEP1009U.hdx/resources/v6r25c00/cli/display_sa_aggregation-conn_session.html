display sa aggregation-conn session

Function

The display sa aggregation-conn session command displays original flow table information based on connection application statistics.

Format

display sa aggregation-conn session [ ipv6 ] { all | { connection connection-id | application application-name } * }

Parameters

Parameter Description Value
ipv6

Displays IPv6 information.

-
all

Display all the flow table information based on connection application statistics.

-
connection connection-id

Specifies a connection ID.

The value is an integer in the range from 1 to 4294967295.
application application-name

Specifies the application name.

The value is a string of 1 to 32 characters and is case sensitive if it starts with UD_. If the string contains spaces, it must be enclosed in quotation marks.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

This command displays original flow table information based on connection application statistics, improving maintainability.
