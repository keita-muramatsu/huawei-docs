path verification (SRv6 TE Policy view)

Function

The path verification enable command enables SRv6 TE Policy fault detection.

The path verification specified-sid enable command enables enhanced SRv6 TE Policy fault detection.

The path verification disable command disables SRv6 TE Policy fault detection or enhanced SRv6 TE Policy fault detection.

The undo path verification command deletes the SRv6 TE Policy fault detection configuration so that the srv6-te-policy path verification configuration in the Segment Routing IPv6 view is inherited.

By default, the SRv6 TE policy path verification function is disabled.

Format

path verification { enable | disable }

path verification specified-sid enable

undo path verification [ { enable | disable } ]

undo path verification specified-sid enable

Parameters

Parameter Description Value
specified-sid

Specifies the SID of a segment list.

-

Views

SRv6 TE policy view

Default Level

2: Configuration level

Usage Guidelines

In the SRv6 TE Policy view, the path verification enable command can be run to enable fault detection, the path verification specified-sid enable command can be run to enable enhanced fault detection, and the path verification disable command can be run to disable fault detection.

If the SRv6 TE Policy view does not have fault detection configuration or the undo path verification command has been run in this view, the srv6-te-policy path verification command configuration in the SRv6 view is inherited.

After fault detection is enabled, the reachability of the SID in the segment list referenced by an SRv6 TE Policy is verified. If the topology route is reachable and the following conditions are met, the SID is considered reachable and the segment list is up. Otherwise, the segment list is down.

  • The SID is a local SID that serves as the first SID in the segment list, or the node where the SID resides is not overloaded.
  • The SID is not an inter-AS or binding SID.

After enhanced fault detection is enabled, only SIDs with the verification flag in the segment list are verified.

Example

# Enable fault detection enhancement for an SRv6 TE Policy.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] srv6-te policy p1 endpoint 2001:DB8:1::1 color 100
[HUAWEI-segment-routing-ipv6-policy-p1] path verification specified-sid enable
# Enable the path verification function of the SRv6 TE policy.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] srv6-te policy p1 endpoint 2001:DB8:1::1 color 100
[HUAWEI-segment-routing-ipv6-policy-p1] path verification enable
