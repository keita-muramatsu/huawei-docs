set transceiver

Function

The set transceiver command sets the alarm thresholds for the optical power of an optical module.

The undo set transceiver command deletes the alarm thresholds configured for the optical power of an optical module.

By default, no alarm threshold is configured for the optical power.

Format

set transceiver { rx-power | tx-power } { { low-threshold low-threshold-value } | { high-threshold high-threshold-value } } *

undo set transceiver { rx-power | tx-power } [ low-threshold [ low-threshold-value ] high-threshold [ high-threshold-value ] ]

undo set transceiver { rx-power | tx-power } low-threshold [ low-threshold-value ]

undo set transceiver { rx-power | tx-power } high-threshold [ high-threshold-value ]

Parameters

Parameter Description Value
rx-power

Indicates the receive power.

-
tx-power

Indicates the transmit power.

-
low-threshold low-threshold-value

Specifies the lower alarm threshold of the optical power.

The value ranges from -40 to 10, excluding boundary values. The value contains two decimal places.
high-threshold high-threshold-value

Specifies the upper alarm threshold of the optical power.

The value ranges from -40 to 10, excluding boundary values. The value contains two decimal places.

Views

Layer 2 10GE interface view, 10GE interface view, 25GE-L2 view, 25GE interface view, Layer 2 40GE interface view, 40GE interface view, GE optical interface view, GE interface view, GE electrical interface view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To set alarm thresholds for the optical power of an optical module, run this command.

Before the set transceiver command is run to configure alarm thresholds for an optical module, the optical module has fixed alarm thresholds. If this command is run more than once, the latest configuration overrides the previous ones.

Precautions

An optical module installed or pre-configured on an optical interface needs to support the configuration of the alarm thresholds for the optical power.

Example

# Set the lower alarm threshold of the receive optical power to -10.00 and the upper alarm threshold to 5.55.
<HUAWEI> system-view
[HUAWEI] interface 10GE0/0/1
[HUAWEI-10GE0/0/1] set transceiver rx-power low-threshold -10.00 high-threshold 5.55
