remote-ip auto-dod-request

Function

The remote-ip auto-dod-request command automatically triggers a request to a downstream node for a label mapping message associated with a remote LDP peer of a specified label switching router (LSR) ID in DoD mode.

The undo remote-ip auto-dod-request command restores the default setting.

By default, the function is disabled.

Format

remote-ip auto-dod-request

undo remote-ip auto-dod-request

Parameters

None

Views

Remote MPLS LDP peer view

Default Level

2: Configuration level

Usage Guidelines

Usually the devices at the edge of an MPLS network are low-end devices. On a large-scale network with a large number of remote peers, configure the DSLAMs in order to ensure the stable operation of the network and to save system resources. Run the remote-ip auto-dod-request command to configure the automatic triggering of a request to a downstream node for a label mapping message associated with a remote LDP peer of a specified LSR ID in DoD mode, which can save system resources.

NOTE:

  • Set up a remote LDP session before running the remote-ip auto-dod-request command.
  • Run the longest-match command to configure LDP over TE before running the remote-ip auto-dod-request command.
  • Run the mpls ldp advertisement dod command to create an LDP session with a downstream node in DoD mode before running the remote-ip auto-dod-request command.

Example

# Enable the automatic triggering of a request to a downstream node for a label mapping message associated with a remote LDP peer of a specified LSR ID in DoD mode.
<HUAWEI> system-view
[HUAWEI] mpls
[HUAWEI-mpls] mpls ldp
[HUAWEI-mpls-ldp] quit
[HUAWEI] mpls ldp remote-peer lsrc
[HUAWEI-mpls-ldp-remote-lsrc] remote-ip 4.4.4.4
[HUAWEI-mpls-ldp-remote-lsrc] remote-ip auto-dod-request
