ipsec policy (System view)

Function

The ipsec policy command creates an IPsec policy and displays the IPsec policy view.

The undo ipsec policy command deletes an IPsec policy.

By default, no IPsec policy is configured.

Format

ipsec policy policy-name seq-number [ isakmp [ template template-name ] ]

undo ipsec policy policy-name [ seq-number ]

Parameters

Parameter Description Value
policy-name

Specifies the name of an IPsec policy.

The value is a string of 1 to 15 case-sensitive characters. It cannot contain question marks (?) or spaces.
seq-number

Specifies the sequence number of an IPsec policy.

The value is an integer that ranges from 1 to 10000. A smaller value indicates a higher IPsec policy priority.
isakmp

Indicates that an ISAKMP IPsec policy is created.

-
template template-name

Indicates that an IPsec policy is created by referencing an IPsec policy template.

The value must be an existing IPsec policy template name.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

An IPsec policy is uniquely identified by its name and sequence number. Policies that share the same name but use different sequence numbers form an IPsec policy group.

Only one IPsec policy group can be applied to an interface, and an IPsec policy group can be applied to only one interface. When data is being sent from an interface, the interface matches the traffic against each IPsec policy in the IPsec policy group in ascending order of the sequence number. If the data flow matches an ACL referenced in a specific IPsec policy, the interface processes the data flow according to this IPsec policy. If no match is found in an IPsec policy, the interface continues to the next policy. If the data flow does not match the ACL of any policy in the group, the interface sends the data flow directly without performing IPsec protection.

Currently, IPsec uses IKE for dynamic parameter negotiation. IPsec policies can be configured in ISAKMP mode or using policy templates.

  • ISAKMP mode: All parameters to be negotiated are defined in an ISAKMP IPsec policy, and the negotiation initiator and responder must use the same IPsec parameter settings. The device can act as either the initiator or the responder.
  • Template mode: All parameters to be negotiated are defined in an IPsec policy template. Optional parameters that are not configured are determined by the initiator, and the responder accepts the parameters delivered by the initiator. Creating an IPsec policy using an IPsec policy template simplifies the configuration for establishing multiple IPsec tunnels. In addition, this mode is applicable to specific scenarios. For example, the peer IP address is not fixed or unknown and the remote end is allowed to initiate negotiation with the local end. Unlike ISAKMP-based policies, the ACLs that define the traffic flows to be protected are optional in template-based policies. If the responder does not have an ACL configured, it accepts the ACL proposed by the initiator to protect the traffic flows.

Follow-up Procedure

Define negotiated IPsec parameters in the IPsec policy view and run the ipsec policy command in interface view to bind the IPsec policy to an interface.

Precautions

  • The end where an IPsec policy template is configured can only function as the responder to receive negotiation requests.
  • One IPsec policy group can have only one IPsec policy template.
  • When creating an IPsec policy, you must specify the SA creation mode. If you have entered the IPsec policy view, you do not need to enter the SA creation mode.
  • Before modifying the negotiation mode of a created IPsec policy, delete the IPsec policy and create an IPsec policy again.

Example

# Set an IPsec policy using the ISAKMP negotiation mode. The IPsec policy name is policy2 and the sequence number is 2. 
<HUAWEI> system-view
[HUAWEI] ipsec policy policy2 2 isakmp
[HUAWEI-ipsec-policy-isakmp-policy2-2]
# Set an IPsec policy using the ISAKMP negotiation mode. The IPsec policy name is policy1 and the sequence number is 1. 
<HUAWEI> system-view
[HUAWEI] ipsec policy policy1 1 isakmp
[HUAWEI-ipsec-policy-isakmp-policy1-1]
