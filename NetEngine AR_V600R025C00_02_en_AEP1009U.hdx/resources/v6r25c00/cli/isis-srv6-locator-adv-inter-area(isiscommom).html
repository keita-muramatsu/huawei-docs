segment-routing ipv6 locator-inter-area disable

Function

The segment-routing ipv6 locator-inter-area disable command disables the Locator TLV from being advertised across areas.

The undo segment-routing ipv6 locator-inter-area disable command enables the Locator TLV to be advertised across areas.

By default, locator TLVs are advertised across ASs.

Format

segment-routing ipv6 locator-inter-area disable

undo segment-routing ipv6 locator-inter-area disable

Parameters

None

Views

IS-IS view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When locator routes leak between IS-IS levels or are imported between IS-IS processes, the Locator TLV is advertised in the target area by default. This behavior may affect path calculation of devices in the target area. To eliminate the impact, run this command.

Prerequisites

Before running the segment-routing ipv6 locator-inter-area disable command, you need to run the ipv6 enable command to enable IS-IS IPv6.

Precautions

This command takes effect only in inter-area locator route scenarios using algorithm 0 and does not take effect in Flex-Algo scenarios.

Example

# Disable the Locator TLV of IS-IS process 1 from being advertised across areas.
<HUAWEI> system-view
[HUAWEI] isis
[HUAWEI-isis-1] ipv6 enable
[HUAWEI-isis-1] segment-routing ipv6 locator-inter-area disable
