link-priority

Function

The link-priority command specifies the priority of a link.

The undo link-priority command restores the default priority of a link.

By default, the priority of a link is 8.

Format

link-priority priority-value

undo link-priority [ priority-value ]

Parameters

Parameter Description Value
priority-value

Specifies the priority of a link.

The value is an integer that ranges from 1 to 8. The default value is 8. A smaller value indicates a higher priority.

Views

Link view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

During traffic steering, SPR preferentially selects a link with a high priority. If no high-priority link meets service requirements, SPR selects a low-priority link.

Prerequisites

The primary and backup links have been configured using the link-role command.

Precautions

The priorities of the primary and backup links do not affect each other. SPR selects a link from the primary link group based on their priorities. If no primary link meets the requirements, SPR selects a link from the backup link group based on their priorities.

Example

# Associate policy profile spr1 with the Internet and set the link priority to 8.
<HUAWEI> system-view
[HUAWEI] smart-policy-route
[HUAWEI-smart-policy-route] spr-policy node 1
[HUAWEI-smart-policy-route-spr-policy-node-1] link transport-network Internet id 99
[HUAWEI-smart-policy-route-spr-policy-node-1-link-tn-Internet] link-role master
[HUAWEI-smart-policy-route-spr-policy-node-1-link-tn-Internet] link-priority 8
