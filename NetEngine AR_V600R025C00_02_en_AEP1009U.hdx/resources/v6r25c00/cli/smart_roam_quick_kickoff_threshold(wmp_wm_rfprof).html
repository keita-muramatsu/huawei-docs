smart-roam quick-kickoff-threshold

Function

The smart-roam quick-kickoff-threshold command sets the threshold for quickly disconnecting STAs.

The undo smart-roam quick-kickoff-threshold command restores the default threshold for quickly disconnecting STAs.

By default, the SNR-based threshold for quickly disconnecting STAs is 15 dB.

Format

smart-roam quick-kickoff-threshold snr snr-threshold

undo smart-roam quick-kickoff-threshold snr

Parameters

Parameter Description Value
snr snr-threshold

Specifies the SNR-based threshold for quickly disconnecting STAs.

The value is an integer that ranges from 5 to 45, in dB.

Views

RRM profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After the function of quickly disconnecting STAs is enabled and the threshold for quickly disconnecting STAs is set using this command, an AP obtains the SNR of a STA from data packets sent by the STA. When the SNR falls below the threshold, the AP disconnects the STA, so that the STA can reassociate with or roam to an AP with good signal quality.

  • A large threshold may cause STAs to go offline frequently.
  • A small threshold may disable STAs from roaming to an AP with stronger signals.

This command applies to scenarios that have high requirements on real-time transmission, such as voice and video services.

Prerequisites

The function of quickly disconnecting STAs has been enabled using the undo smart-roam quick-kickoff-threshold disable command.

Precautions

STAs may be forced to go offline through the smart roaming function or the function of quickly disconnecting STAs. If the SNR thresholds for the two functions are both configured, the function with a larger value is preferentially effective.

Example

# Set the threshold for quickly disconnecting STAs to 20 dB.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] rrm-profile name default
[HUAWEI-wlan-rrm-prof-default] undo smart-roam quick-kickoff-threshold disable
[HUAWEI-wlan-rrm-prof-default] smart-roam quick-kickoff-threshold snr 20
