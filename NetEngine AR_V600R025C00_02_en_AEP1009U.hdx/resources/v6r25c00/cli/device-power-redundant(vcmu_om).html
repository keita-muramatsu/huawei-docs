device power redundant

Function

The device power redundant command sets the power redundancy mode.

The undo device power redundant command restores the default N+1 power redundancy mode.

The default power redundancy mode of a device is module.

This command is supported only on the AR8700 series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series and AR6700-H series.

Format

device power redundant powermode

undo device power redundant [ powermode ]

Parameters

Parameter Description Value
powermode

Specifies the backup mode of power modules.

The value is an enumerated type and case sensitive. The options are as follows:

  • module: The power modules on the device work in N+1 power redundancy mode.
  • non: The power modules on the device work in N+0 power redundancy mode and no backup power module is available.

Views

System view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

You can run this command to set the power redundancy mode of the device.

The device supports the following power redundancy modes:

module: The power modules of the device work in N+1 backup mode. The number of remaining power supplies is 1. In N+1 backup mode, the system uses the power module with the highest power as the backup power module, and the other power modules work as the working power modules.

non: The power modules of the device work in N+0 backup mode and no backup power module is available. In this case, the number of working power supplies is greater than the number of remaining power supplies, and the number of remaining power supplies is 0. In N+0 backup mode, the system has no redundant power supply, and all power supplies are working.

Precautions

  1. This command takes effect immediately after being configured, and the configuration is not lost after the device is restarted.
  2. The N+1 backup mode supports only one backup power module, which can be removed or faulty. The non-backup mode maximizes the power supply but has low reliability. You need to select the most appropriate power module backup mode based on the number of available power modules and the rated power of the system.

Example

# Set the power redundancy mode to N+0.
<HUAWEI> system-view
[HUAWEI] device power redundant non
