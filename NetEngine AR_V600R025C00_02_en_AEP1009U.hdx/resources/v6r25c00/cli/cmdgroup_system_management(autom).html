system-management

Function

The system-management command displays the system management view.

By default, the system management view is not displayed.

Format

system-management

Parameters

None

Views

Net-assistant view

Default Level

3: Management level

Usage Guidelines

To configure network-wide user passwords and SSL policies, run this command to enter the system management view.

Example

# Enter the system management view.
<HUAWEI> system-view
[HUAWEI] net-assistant
[HUAWEI-net-assistant] system-management
