display mac-authen

Function

The display mac-authen command displays information about MAC address authentication.

Format

display mac-authen [ configuration ]

display mac-authen interface { interface-name | interface-type interface-number }

Parameters

Parameter Description Value
configuration

Displays global MAC address authentication information.

-
interface interface-type interface-number

Displays information about MAC address authentication on a specified interface.

The value is an integer.
interface-name

Specifies the name of an interface.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

You can run this command to view configuration results of all configuration commands in MAC address authentication. The command output helps you to check whether the MAC address authentication configuration is correct and isolate faults accordingly.

Follow-up Procedure

You can locate the fault according to the packet statistics that is displayed using the display mac-authen command. When the fault is rectified, run the reset mac-authen statistics command to clear the packet statistics. After a period of time, run the display mac-authen command again to check the packet statistics. If no error packet is found, the fault is rectified.

Table 1 Description of the display mac-authen command output
Item Description
Quiet period

Quiet timer value, during which the user waits for re-authentication after the maximum number of authentication failures is exceeded. The default value of the quiet timer is 60 seconds.
Authentication fail times before quiet

Maximum number of authentication failures before a MAC address authentication user enters the quiet state.
Authentication Success: m, Failure: n

Number of successful user authentications (m) and number of failed user authentications (n) on the interface, which indicate the user authentication result and are not the final user state.
Maximum users

Maximum number of online users allowed by the device.
Current users

Number of current online users.
Current users

Number of current online users on the interface.
Global default domain

Current authentication domain. By default, no authentication domain is specified for users. If you do not specify any domain for users, the default domain in the system is used.
MAC address authentication

Whether MAC address authentication is enabled on the interface.

-enabled.

-disabled.
MAC access profile

MAC access profile name.
Reauthentication

Whether re-authentication for MAC address authentication is enabled.

-enabled.

-disabled.
Username format

User name format for MAC address authentication.
Password type

Password display mode for MAC address authentication.
Online user(s) info

Online user information.

-UserId: ID of an online user.

-MAC/VLAN: MAC address and VLAN of an online user.

-AccessTime: access time of an online user.

-UserName: name of an online user.

-Total: total number of online users.

-printed: number of displayed online users.
interface state

Interface status.

-UP: The interface is enabled.

-DOWN: The interface is shut down.
Fixed password

Password for MAC address authentication.
m silent mac address(es) found, n printed

Numbers of successful authentications (m) and failed authentications (n) on the interface.
