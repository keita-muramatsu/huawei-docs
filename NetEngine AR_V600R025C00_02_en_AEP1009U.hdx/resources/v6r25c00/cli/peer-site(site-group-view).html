peer-site(Site group view)

Function

The peer-site command adds peer sites to a site group.

The undo peer-site command removes peer sites from a site group.

By default, a site group contains no peer site.

This command is supported only on the AR8700 series, AR8100 series and AR6700-H series.

Format

peer-site { site-id | all } [ bandwidth percentage bandwidth-value ]

undo peer-site { site-id | all } [ bandwidth percentage bandwidth-value ]

Parameters

Parameter Description Value
site-id

Specifies a site ID.

The value is an integer from 1 to 65535.
all

Adds all peer sites to a site group.

-
bandwidth

Sets the site bandwidth.

-
percentage bandwidth-value

Specifies the bandwidth percentage.

The value is an integer in the range from 1 to 100, in percentage. The default value is 100.

Views

Site group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In SD-WAN EVPN scenarios, connection-based QoS policies can be configured. After a site group is created, you can configure a peer site and its bandwidth percentage in the site group.

The outbound bandwidth limit of a connection-based QoS policy is equal to the inbound bandwidth of the peer site multiplied by the bandwidth percentage configured by the command.

Precautions

A transport network of a peer site can be bound to only one site group. If no transport network is specified, all transport networks of the peer site are bound to the site group. If the all parameter is specified, all peer sites are bound to the site group. This will overwrite the peer sites that have been bound to the site group.

If both peer sites and transport networks are specified for the first site group, and the same peer sites are specified for the second site group, the system binds all transport networks of the peer sites to the second site group. This results in a conflict with the configuration of the first site group. To prevent this, assign transport networks to the second site group that are different from those used in the first site group, and then bind peer sites to the second site group.

Example

# Configure a peer site in a site group named group1, with the site ID being 65535 and bandwidth percentage being 80%.
<HUAWEI> system-view
[HUAWEI] evpn site-group group1
[HUAWEI-site-group-group1] peer-site 65535 bandwidth percentage 80
