license trial

Function

The license trial command enables the trial use of a control item feature.

By default, the trial use of a control item feature is disabled.

Format

license trial disable

license trial enable

Parameters

Parameter Description Value
enable

Enables the control item trial function.

-
disable

Disables the control item trial function.

-

Views

User view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

The license trial enable command activates a trial license on a device to use features provided by the device for free in a short period of time.

Not all features support this function. You can run the display license trial command to check the range of trial licenses supported by the device.

Precautions

  • Trial use can be enabled twice for each R version. After this function is enabled, the device runs based on the maximum value of the control item specifications. The validity period is 90 days.
  • After the trial period ends, the controlled features become invalid immediately or after the device is restarted. You can continue to use these functions after purchasing and activating a permanent commercial license.
  • If an activated license file exists on the device, the trial function cannot be enabled.

Example

# Disable the control item trial function.
<HUAWEI> license trial disable
Warning: This operation will disable the license-controlled feature, after which the feature cannot be enabled again. Continue?  [Y/N]:y
Info: Operating, please wait for a moment...........done.
Info: Succeeded to perform this operation.
# Enable the control item trial function.
<HUAWEI> license trial enable
Warning: This operation will enable the license-controlled feature and can be used only after authorization. Please apply for a license before the feature expires. Continue? [Y/N]:y
Info: Operating, please wait for a moment...........done.
Info: Succeeded to perform this operation.
