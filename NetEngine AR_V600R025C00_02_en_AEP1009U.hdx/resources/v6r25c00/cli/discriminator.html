discriminator(MP-Group interface view)

Function

The discriminator command enables endpoint discriminator negotiation.

The undo discriminator command disables endpoint discriminator negotiation.

The discriminator strict-check command enables strict check for endpoint discriminator negotiation.

The undo discriminator strict-check command disables strict check for endpoint discriminator negotiation.

By default, endpoint discriminator negotiation is enabled, but strict check for endpoint discriminator negotiation is disabled.

Format

discriminator

discriminator strict-check

undo discriminator

undo discriminator strict-check

Parameters

None

Views

MP-group interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

An MP interface is typically configured with multiple PPP links. If the discriminator command is run and the negotiation of the first PPP link succeeds, the MP interface saves the received discriminator and uses it as the peer discriminator. During the negotiation of another PPP link for the MP interface, PPP compares the peer discriminator in the newly received negotiation packet with the saved peer discriminator to check whether the peer ends belong to the same MP interface. If the discriminators are different, the peer ends do not belong to the same MP interface, and the LCP negotiation of this PPP link fails.

Precautions

  • The undo discriminator command can take effect on an MP-group interface only after the shutdown and undo shutdown commands are run in sequence for the sub-channels of the MP-group interface.
  • After the discriminator command is run on the local device, the local and peer devices can successfully negotiate no matter whether endpoint discriminator negotiation is enabled on the peer device.
  • If the discriminator strict-check command is run on the local device, the local and peer devices can successfully negotiate only when endpoint discriminator negotiation is also enabled on the peer device.

Example

# Enable strict check for endpoint discriminator negotiation on a specified interface.
<HUAWEI> system-view
[HUAWEI] interface Mp-group 0/0/1
[HUAWEI-Mp-group0/0/1] discriminator strict-check
# Disable endpoint discriminator negotiation on a specified interface.
<HUAWEI> system-view
[HUAWEI] interface mp-group 0/0/1
[HUAWEI-Mp-group0/0/1] undo discriminator
