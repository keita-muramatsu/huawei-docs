negotiation-mode

Function

The negotiation-mode command sets the negotiation mode of an interface.

The undo negotiation-mode command restores the negotiation mode of an interface to auto-negotiation.

By default, an interface works in auto-negotiation mode.

Format

negotiation-mode { master | slave | auto | master-priority | slave-priority }

undo negotiation-mode [ { master | slave | auto | master-priority | slave-priority } ]

Parameters

Parameter Description Value
master

Sets the negotiation mode of an interface to master.

-
slave

Sets the negotiation mode of an interface to slave.

-
auto

Sets the negotiation mode of an interface to auto-negotiation.

-
master-priority

Sets the negotiation mode of an interface to master-priority.

-
slave-priority

Sets the negotiation mode of an interface to slave-priority.

-

Views

Layer 2 10GE interface view, 10GE interface view, 25GE-L2 view, 25GE interface view, GE optical interface view, GE interface view, GE electrical interface view, Layer 2 multi-GE interface view, Multi-GE interface view, Interface group view, Management interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

This command is used to set the working mode of the physical-layer clock on an interface.

Prerequisites

This command can be configured on management interfaces, electrical interfaces, optical interfaces pre-configured with 10G copper modules, and optical interfaces pre-configured with GE copper modules, and loopback cannot be configured on these interfaces.

Precautions

The negotiation modes of interconnected interfaces cannot both be set to master or slave. If the negotiation modes of interconnected interfaces are both set to master or slave, the interfaces go down. If the negotiation modes of interconnected interfaces are both set to master-priority or slave-priority, the interfaces do not go down but the effective negotiation modes may be different from the configured ones.

After the master or slave negotiation mode is set for a management interface, if the interface goes down or the rate is reduced to 100 Mbit/s, cancel the master or slave negotiation mode and then set the auto-negotiation mode again (by running the negotiation disable and undo negotiation disable commands in sequence).

Example

# Set the negotiation mode of 10GE0/0/1 to master.
<HUAWEI> system-view
[HUAWEI] interface 10GE0/0/1
[HUAWEI-10GE0/0/1] negotiation-mode master
