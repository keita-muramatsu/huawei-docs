sta arp-nd-proxy before-assoc

Function

The sta arp-nd-proxy before-assoc command enables the function of sending ARP/ND proxy packets for STAs before the STAs are successfully associated.

The undo sta arp-nd-proxy before-assoc command disables the function of sending ARP/ND proxy packets for STAs before the STAs are successfully associated.

By default, the function of sending ARP/ND proxy packets for STAs before the STAs are successfully associated is disabled.

Format

sta arp-nd-proxy before-assoc

undo sta arp-nd-proxy before-assoc

Parameters

None

Views

AP system profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If APs send ARP/ND proxy packets for STAs before the STAs succeed in authentication or key negotiation, the Layer 2 switches connected to the APs will learn the MAC addresses of the STAs. In this case, if an attack floods thousands of STA MAC addresses, the MAC address table on the switches will be seriously corrupted, bringing security risks. To avoid such risks, you can run the undo sta arp-nd-proxy before-assoc command to configure the APs to send ARP/ND proxy packets for STAs after the STAs succeed in authentication or key negotiation.

In scenarios without high security requirements, you can run the sta arp-nd-proxy before-assoc command to enable the function of sending ARP/ND proxy packets for STAs before the STAs are successfully associated, which improves link update efficiency.

Precautions

After the undo sta arp-nd-proxy before-assoc command is run, the device does not function as a proxy to send ARP/ND packets for STAs that go online in open or WEP mode.

Example

# Enable the function of sending ARP/ND proxy packets for STAs before the STAs are successfully associated.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name ap-system1
[HUAWEI-wlan-ap-system-prof-ap-system1] sta arp-nd-proxy before-assoc
