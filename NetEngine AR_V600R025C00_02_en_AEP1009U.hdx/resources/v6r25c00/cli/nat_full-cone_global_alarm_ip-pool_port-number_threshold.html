nat full-cone global alarm ip-pool port-number threshold

Function

The nat full-cone global alarm ip-pool port-number threshold command sets the threshold for the usage of the address pool port.

The undo nat full-cone global alarm ip-pool port-number threshold command restores the default value.

By default, the value is 80, in percentage.

Format

nat full-cone global alarm ip-pool port-number threshold threshold-value

undo nat full-cone global alarm ip-pool port-number threshold

Parameters

Parameter Description Value
threshold-value

Specifies the threshold for the port usage.

The value is an integer that ranges from 60 to 100. The default value is 80.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

In 3-tuple NAT scenarios, to monitor the port usage of an address pool, run the nat full-cone global alarm ip-pool port-number threshold trap enable command to enable the function of sending port usage alarms. When the port usage reaches the threshold, the device sends an alarm to the NMS.

For example, assume that the default minimal and maximal ports that can be allocated to each IP address in the address pool are 2048 and 65535, respectively. Then, the number of ports that can be allocated to each IP address is (65535 - 2048 + 1) = 63488. If there are 10 IP addresses in the address pool, the total number of allocatable ports is 634880 (63488 x 10). When the number of used ports in the address pool reaches 634880 x threshold-value, the device sends the alarm FULLCONE_1.3.6.1.4.1.2011.6.122.48.2.1 hwSecFullConeIpPoolPortUsageOverThreshold to the NMS, and sends the log FULLCONE/3/CPUIPPOOLPORTUSAGETRAP to the log server. When the port usage of the 3-tuple address pool falls below 7/8 of the threshold, that is, when the number of used ports in the address pool reaches 634880 x (threshold-value x 7/8), the device sends the clear alarm FULLCONE_1.3.6.1.4.1.2011.6.122.48.2.3 hwSecFullConeIpPoolPortUsageLessThreshold to the NMS, and sends the recovery log FULLCONE/3/CPUIPPOOLPORTUSAGENORMALTRAP to the log server.

Example

# Set the threshold for the usage of the address pool port to 90%.
<HUAWEI> system-view
[HUAWEI] nat full-cone global alarm ip-pool port-number threshold trap enable
[HUAWEI] nat full-cone global alarm ip-pool port-number threshold 90
