ipv6 address <dhcpv6-prefix>

Function

The ipv6 address dhcpv6-prefix command configures an IPv6 address bound to the DHCPv6 PD prefix for an interface.

The undo ipv6 address dhcpv6-prefix command deletes the IPv6 address bound to the DHCPv6 PD prefix for an interface.

By default, no IPv6 address bound to the DHCPv6 PD prefix is configured for an interface.

Format

ipv6 address dhcpv6-prefix { ipv6-address prefix-length | ipv6-address/prefix-length }

undo ipv6 address dhcpv6-prefix [ ipv6-address prefix-length | ipv6-address/prefix-length ]

Parameters

Parameter Description Value
dhcpv6-prefix

Specifies the prefix assigned to a DHCPv6 PD client.

The value is a string of 1 to 63 case-sensitive characters. The IPv6 address format is not supported.
ipv6-address

Specifies the IPv6 address.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.

A maximum of 16 global unicast addresses, including DHCPv6 PD prefix addresses, can be configured on an interface.
prefix-length

Specifies the prefix length of an IPv6 address.

The value is an integer ranging from 1 to 128.
ipv6-address/prefix-length

Specifies the IPv6 address and prefix length of an interface.

IPv6 address/IPv6 address prefix length.

Views

10GE sub-interface view, 10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE sub-interface view, 40GE interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, Ethernet sub-interface view, Ethernet interface view, GE optical interface view, GE sub-interface view, GE interface view, GE electrical interface view, IP-Trunk interface view, Multi-GE sub-interface view, Multi-GE interface view, POS interface view, VLANIF interface view, Management interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The device is required to function as a DHCPv6 PD client and obtain an IPv6 address prefix from the DHCPv6 PD server. You can run the ipv6 address dhcpv6-prefix { ipv6-address prefix-length | ipv6-address/prefix-length } command to configure an IPv6 address is bound to the DHCPv6 PD prefix.

Prerequisites

Before running the ipv6 address command to configure a DHCPv6 PD prefix address for an interface, you need to run the ipv6 enable command in the interface view to enable the IPv6 function on the interface.

Precautions

  • If the ipv6 address dhcpv6-prefix1 2001:db8:2::1/64 and ipv6 address dhcpv6-prefix1 2001:db8:2::2/64 commands are configured on interfaces A and B respectively, the network prefixes of interfaces A and B are the same. As a result, the configuration is successful but takes effect only on one interface. If the preceding case occurs, check whether any address conflict exists.
  • After this command is run on an interface, the IPv6 address is not immediately added to the interface. The device uses the obtained prefix and configured address to generate a new prefix address only after the DHCPv6 PD client function is enabled and the prefix is obtained. If the DHCPv6 PD client function is enabled but no prefix is obtained, the configuration does not take effect. In this case, no address is available on the interface.

Example

# Configure the IPv6 address bound to the DHCPv6 PD prefix for Vlanif1.
<HUAWEI> system-view
[HUAWEI] vlan 1
[HUAWEI-vlan1] quit
[HUAWEI] interface Vlanif 1
[HUAWEI-Vlanif1] ipv6 enable
[HUAWEI-Vlanif1] ipv6 address prefix1 2001:db8:1::1/64
