flag(POS interface view)

Function

The flag command sets the overhead byte of an interface.

The undo flag command restores the default configuration.

By default, the value of the overhead byte C2 is 22 for an interface, and J0 and J1 are empty strings.

This command is supported only on the AR8700 series, AR5710-S10T1X2, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series and AR6700-H series.

Format

flag j0 { 1byte-mode j0trace | 16byte-mode trace16 | 64byte-mode trace64 }

flag j1 { 1byte-mode j1trace | 16byte-mode trace16 | 64byte-mode trace64 }

flag c2 c2value

undo flag j0

undo flag j1

undo flag c2

undo flag

Parameters

Parameter Description Value
1byte-mode j1trace

Specifies a value for J1 in 1-byte mode.

The value is a string of 1 case-sensitive character. It cannot contain spaces.
1byte-mode j0trace

Specifies a value for J0 in 1-byte mode.

The value is a string of 1 case-sensitive character. It cannot contain spaces.
16byte-mode trace16

Specifies a value in 16-byte mode.

The value is a string of 1 to 15 case-sensitive characters. It cannot contain spaces.
64byte-mode trace64

Specifies a value in 64-byte mode.

The value is a string of 1 to 62 case-sensitive characters. It cannot contain spaces.
j1

Indicates the overhead byte J1.

-
c2

Indicates the overhead byte C2.

-
c2 c2value

Specifies a value in C2 mode.

The value is an integer that ranges from 1 to 255. The default value is 22.
j0

Indicates the overhead byte J0.

-

Views

POS interface view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Different vendors require different overhead bytes for POS interfaces. Ensure that the overhead bytes C2, J0, and J1 configured on the two devices are the same. Otherwise, the two devices cannot communicate with each other.

Precautions

You can run this command only when the device supports POS interfaces.

Example

# Set the value for J0 in 1-byte mode to a on POS 1/0/1.
<HUAWEI> system-view
[HUAWEI] interface Pos 1/0/1
[HUAWEI-Pos1/0/1] flag j0 1byte-mode a
