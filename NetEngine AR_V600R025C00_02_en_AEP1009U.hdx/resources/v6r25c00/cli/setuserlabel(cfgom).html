set configuration commit

Function

The set configuration commit command sets a user label for a configuration commit point.

The clear configuration commit command deletes the label of a specified configuration rollback point.

By default, no user label is set for configuration commit.

Format

set configuration commit commit-id label label-string

clear configuration commit commit-id label

Parameters

Parameter Description Value
commit-id

Specifies the ID of a configuration rollback point.

The id is a string of 1 to 20 characters and generated by the system automatically.
label label-string

Specifies a user label for a configuration rollback point.

The parameter value must be unique in the system and in one-to-one mappings with commit-id.

The value is a string of 1 to 256 case-sensitive characters. It can be any visible ASCII character except for the space. However, the string can contain spaces if it is enclosed with double quotation marks ("). The string cannot start with a digit or be a hyphen (-).

Views

User view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

  • When a configuration rollback point is generated, the system automatically allocates a rollback point ID to identify the rollback point. The rollback point ID is an integer, which is inconvenient for users to understand and remember. When the number of rollback points automatically generated by the system reaches the upper limit, the rollback points are overwritten one by one in sequence, to prevent important configurations from being overwritten, you can run this command to specify a user label for a configuration rollback point. This helps you understand and remember the configuration rollback point and prevents the configuration rollback point from being overwritten.
  • You can specify a user label when running the commit command to generate a configuration rollback point. After a configuration rollback point is generated, you can run the set configuration commit command to add a user label for the configuration rollback point. For consecutive configuration rollback points that already have labels, you cannot directly modify the labels. Instead, you need to run the clear configuration commit command to delete the existing labels and then run the set configuration commit command to configure labels.
  • You can run the clear configuration commit command to clear the user label for a configuration rollback point. For an aged configuration rollback point, running this command will delete the configuration rollback point corresponding to the user label.

Follow-up Procedure

You can run the display configuration commit list command to check label information of a configuration rollback point.

Precautions

This command is an overriding command.

The commit-id parameter applies only to common configuration rollback points. Scheduled configuration rollback points are not supported. The value ranges from 1000000001 to 1999999999.

Example

# Delete the user label named new_label for the configuration rollback point with the ID of 1000000002.
<HUAWEI> clear configuration commit 1000000002 label
# Set the label new_label for configuration commit ID 1000000002.
<HUAWEI> system-view
Enter system view, return user view with return command.
[HUAWEI] commit label old_label
[HUAWEI] return
<HUAWEI> clear configuration commit 1000000002 label
<HUAWEI> set configuration commit 1000000002 label new_label
