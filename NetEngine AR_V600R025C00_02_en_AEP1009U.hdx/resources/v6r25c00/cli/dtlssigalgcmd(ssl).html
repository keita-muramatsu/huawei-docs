signature algorithm-list(DTLS policy view)

Function

The signature algorithm-list command sets the signature algorithms supported during SSL handshakes.

The undo signature algorithm-list command restores the default signature algorithms supported during SSL handshakes.

By default, the configured signature algorithms are ed25519, ed448, ecdsa-secp256r1-sha256, ecdsa-secp384r1-sha384, ecdsa-secp521r1-sha512, rsa-pss-pss-sha256, rsa-pss-pss-sha384, rsa-pss-pss-sha512, rsa-pss-rsae-sha256, rsa-pss-rsae-sha384, and rsa-pss-rsae-sha512.

Format

signature algorithm-list { ecdsa-secp256r1-sha256 | ecdsa-secp384r1-sha384 | ecdsa-secp521r1-sha512 | ed25519 | ed448 | rsa-pss-pss-sha256 | rsa-pss-pss-sha384 | rsa-pss-pss-sha512 | rsa-pss-rsae-sha256 | rsa-pss-rsae-sha384 | rsa-pss-rsae-sha512 | rsa-pkcs1-sha256 | rsa-pkcs1-sha384 | rsa-pkcs1-sha512 | ecdsa-sha1 | ecdsa-sha224 | rsa-sha1 | rsa-sha224 | dsa-sha1 | dsa-sha224 | dsa-sha256 | dsa-sha384 | dsa-sha512 } *

undo signature algorithm-list

Default Level

Usage Guidelines

Usage Scenario

You can run this command to set the signature algorithm supported by the SSL handshake process.

For higher security, the ed25519, ed448, ecdsa-secp256r1-sha256, ecdsa-secp384r1-sha384, ecdsa-secp521r1-sha512, rsa-pss-pss-sha256, rsa-pss-pss-sha384, rsa-pss-pss-sha512, rsa-pss-rsae-sha256, rsa-pss-rsae-sha384, and rsa-pss-rsae-sha512 algorithms are recommended.

Precautions

The dsa-sha1, dsa-sha224, dsa-sha256, dsa-sha384, dsa-sha512, ecdsa-sha1, ecdsa-sha224, rsa-sha1 and rsa-sha224 parameters in this command are weak security algorithms and are not recommended. Run the install feature-software WEAKEA command to install the weak security algorithm/protocol feature package (WEAKEA).

Example

# Set the DTLS signature algorithm.
<HUAWEI> system-view
[HUAWEI] dtls policy a
[HUAWEI-dtls-policy-a] signature algorithm-list ed25519 ed448
