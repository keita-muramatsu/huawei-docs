backup-group

Function

The backup-group command configures two RUs in a backup group.

The undo backup-group command deletes a backup group with a specified ID.

By default, no backup group is configured.

Format

backup-group group-id remote-unit ru-id1 remote-unit ru-id2

undo backup-group group-id

Parameters

Parameter Description Value
remote-unit ru-id1

Indicates the ID of the first RU in a backup group.

The value is an integer ranging from 0 to 16777215.
remote-unit ru-id2

Indicates the ID of the second RU in a backup group.

The value is an integer ranging from 0 to 16777215.
backup-group group-id

Specifies the backup group ID.

The value is an integer ranging from 0 to 16777215.

Views

remote-unit view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When two RUs are connected to a central device, you can run the backup-group command to add them to a backup group so that the two RUs can back up each other.

Follow-up Procedure

After a backup group is configured, enter the remote-unit-N view of each RU and run the backup-group backup-port command to configure a backup interface.

Precautions

• Before configuring a backup group, ensure that the remote-unit N view exists and is not added to any other backup group.

• Before deleting a backup group, ensure that no backup interface is configured in the two remote-unit N views of the backup group.

Example

# Add RU 1 and RU 2 to backup group 3.
<HUAWEI> system-view
[HUAWEI] remote-unit
[HUAWEI-remote-unit] backup-group 3 remote-unit 1 remote-unit 2
