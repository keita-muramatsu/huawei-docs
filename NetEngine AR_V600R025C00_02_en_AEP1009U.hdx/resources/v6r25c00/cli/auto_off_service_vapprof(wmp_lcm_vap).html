auto-off service (VAP profile view)

Function

The auto-off service command enables the scheduled VAP auto-off function and sets the time range during which the VAP is disabled.

The undo auto-off service command disables the scheduled VAP auto-off function.

By default, the scheduled VAP auto-off function is disabled.

Format

auto-off service time-range time-range-name

undo auto-off service

Parameters

Parameter Description Value
time-range time-range-name

Specifies the name of a time range during which a VAP is disabled.

The value is a string of 1 to 32 characters and must start with a letter. To avoid confusion, do not use "all" as the name of a time range.

Views

VAP profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To prevent users from accessing the WLAN within a specified period, for example, from 01:00 to 05:00, run the auto-off service command to enable the scheduled VAP auto-off function.

Precautions

  • After running the undo service-mode disable command to enable the service mode of a VAP, run the auto-off service command to configure the scheduled VAP auto-off function. During the specified period, the VAP is disabled and cannot be enabled using the undo service-mode disable command. To enable the VAP, run the undo auto-off service command.

  • The scheduled VAP auto-off function takes effect only after the undo service-mode disable command is executed. After the service-mode disable command is run, the scheduled VAP auto-off function does not take effect.

  • You can run the auto-off service time-range time-range-namecommand to configure a periodic time range during which a VAP is disabled.

  • The scheduled VAP auto-off function enabled in the VAP profile view takes effect only on the APs using the VAP profile. The scheduled VAP auto-off function enabled in the radio profile view takes effect only on the APs using the radio profile.

Example

# Configure the scheduled VAP auto-off function in the VAP profile vap1, and configure the VAP to be disabled from 1:00:00 to 7:00:00.
<HUAWEI> system-view
[HUAWEI] time-range VAP 1:00 to 7:00 daily
[HUAWEI] wlan
[HUAWEI-wlan] vap-profile name vap1
[HUAWEI-wlan-vap-prof-vap1] auto-off service time-range VAP
