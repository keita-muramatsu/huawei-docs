destination-zone (NAT policy rule view)

Function

The destination-zone command specifies a destination security zone in a NAT policy rule.

The undo destination-zone command deletes a destination security zone specified in a NAT policy rule.

By default, the security zone in a NAT policy rule is set to any, and multiple security zones can be configured.

Format

destination-zone { destination-zone-name | any }

undo destination-zone { destination-zone-name | all }

Parameters

Parameter Description Value
destination-zone-name

Specifies the name of a destination security zone.

The value must be the name of an existing security zone. The value is a string of case-sensitive characters that cannot contain question marks (?), commas (,), or double quotation marks ("). If the name does not contain spaces, the value is a string of 1 to 32 characters. If the name contains spaces, the value is a string of 3 to 34 characters and must be enclosed with double quotation marks (""), for example, "user for test".
any

Indicates any destination security zone.

-
all

Deletes all destination security zones to which a policy rule applies.

-

Views

NAT policy rule view

Default Level

2: Configuration level

Usage Guidelines

Either a destination security zone or an outbound interface can be specified in a NAT policy rule.

Example

# Set the destination zone to untrust in a NAT policy rule named abc. 
<HUAWEI> system-view
[HUAWEI] nat-policy
[HUAWEI-policy-nat] rule name abc
[HUAWEI-policy-nat-rule-abc] destination-zone untrust
