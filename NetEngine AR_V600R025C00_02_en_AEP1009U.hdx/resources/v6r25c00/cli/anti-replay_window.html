anti-replay window

Function

The anti-replay window command sets the anti-replay window size for an IPsec tunnel.

The undo anti-replay window command restores the default anti-replay window size of an IPsec tunnel.

By default, the anti-replay window size of a single IPsec tunnel is not set. The global value is used.

Format

anti-replay window window-size

undo anti-replay window

Parameters

Parameter Description Value
window-size

Specifies the anti-replay window size of an IPsec tunnel.

The value can be 32, 64, 128, 256, 512, 1024, or 8192, in bits.

Views

IPsec profile view, IPsec policy template view, ISAKMP IPsec policy view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In some specific scenarios, for example, when network congestion occurs or packets experience QoS processing, the sequence of service data packets may be different from the normal sequence. Although these packets are not intended for replay attacks, the anti-replay detection considers them as replay packets and discards them. To prevent this problem, you can disable IPsec anti-replay or adjust the IPsec anti-replay window size to meet service requirements.

Prerequisites

The anti-replay function is enabled for the IPsec tunnel.

Precautions

When both the anti-replay window command and ipsec anti-replay window command are configured, the anti-replay window command configuration takes effect. When the anti-replay window command is not configured, the ipsec anti-replay window command configuration takes effect.

Example

# Set the IPsec anti-replay window size to 128 bits. 
<HUAWEI> system-view
[HUAWEI] ipsec policy poli 10 isakmp
[HUAWEI-ipsec-policy-isakmp-poli-10] anti-replay window 128
