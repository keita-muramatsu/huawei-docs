display isis spf-tree

Function

The display isis spf-tree command displays the topology of the SPT that is generated by IS-IS.

Format

display isis spf-tree [ systemid systemid ] [ [ level-1 | level-2 ] | ipv6 | verbose ] * [ process-id ]

display isis spf-tree [ systemid systemid [ path ] ] [ [ level-1 | level-2 ] | ipv6 | no-name ] * [ process-id ]

Parameters

Parameter Description Value
systemid systemid

Displays the system ID or pseudo node ID.

The value is in the format of XXXX.XXXX.XXXX[.XX].
level-1

Displays the SPT topology of Level-1.

-
level-2

Displays the SPT topology of Level-2.

-
ipv6

Displays the SPT topology of IPv6.

-
verbose

Displays detailed information of the SPT topology.

-
process-id

Specifies the ID of an IS-IS process.

The value is an integer ranging from 1 to 4294967295.
path

Displays information about the path to a specified node.

-
no-name

Indicates that the host name is not displayed when IS-IS information is displayed.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

When an error occurs in the route calculation, run the display isis spf-tree command to check whether the IS-IS topology information is correct.

The actual command output varies according to the device. The command output here is only an example.

Table 1 Description of the display isis spf-tree command output
Item Description
Distance

Distance between two nodes.
Distance-URT

Cost of the shortest path from the root node to the destination node, including the TE tunnel link.
IPv6-Distance-URT

Cost of the shortest path from the root node to the destination node in an IPv6 topology, including the TE tunnel link.
Flags
  • SPT: The node is in the tree.
  • Direct: The node is a directly connected node.
  • Shortcut: The node is connected to a shortcut link.
  • Oload: The node is in the Overload state.
  • Isolate: The node is not in the tree.
  • V6_Islt: The node is not in the IPv6 tree.
  • Del: The node will be deleted.
  • Remote: The node is connected to the tunnel.

Flags in Neighbors indicate the relationship between the neighbor and itself.

  • Parent: The neighbor is a parent node.
  • Child: The neighbor is a child node.
IPv4 Nexthops-URT

IPv4 next hop of the node in the unicast routing table.
IPv4 Nexthops

IPv4 next hop of the node in the unicast routing table.
SR Nexthops

Next hop of the node in the SR labeled routing table.
IPv6 Nexthops

IPv6 next hop of the node.
Cost

Cost of the link from the root node to this node.
SegmentRouting

Whether SR is enabled on the node.
SegmentRouting avoid-microloop Label Stack (Top -> Bottom)

Label values in the SR microloop avoidance label stack, which are displayed in the top-to-bottom order.
SRGB

SRGB information about the node.
NextHop

Next-hop address of a parent node.
IF

Name of the outbound interface.
PHPFlag

Penultimate hop popping (PHP) label.
PathSrgb

Minimum SRGB range on the path from the root node to this node.
MapFlag

Whether the SR next hop is used only in the mapping server scenario.
Neighbors

Information about all the neighbors of this node.
NBR

System ID of the next hop.
TYPE

Protection type.

  • LOOP-FREE: indicates LFA protection.
  • REMOTE-LOOP-FREE: indicates remote LFA protection.
  • TI-LOOP-FREE: indicates TI-LFA protection.
PROTECT

Protection:

  • LINK: indicates link protection.
  • NODE: indicates the node protection.
  • LINK-NODE: indicates the link and node protection.
ParentNode

ID of a parent node.
LinkSid

Link label.
