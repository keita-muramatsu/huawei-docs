firewall log host

Function

The firewall log host command configures a log host for session logs.

The undo firewall log host command cancels the configuration.

By default, the log host is not configured.

Format

firewall log host host-id { ip-address | ipv6-address } port [ vpn-instance vpn-instance-name ] [ secondary ] [ log-type { binary | syslog } ]

undo firewall log host host-id [ secondary ] [ log-type ]

Parameters

Parameter Description Value
host-id

ID of the log host.

The value is an integer ranging from 1 to 16.
ip-address

IP address of the log host.

The value is in dotted decimal notation.
ipv6-address

IPv6 address of the log host.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
port

Port number of the log host.

The value is an integer ranging from 1 to 65535.
vpn-instance vpn-instance-name

Name of the VPN instance to which the log host belongs. The VPN instance here indicates the one configured with the ip vpn-instance vpn-instance-name command for route isolation. In a virtual system scenario, this command does not allow binding a VPN instance with the same name as the virtual system.

The value is a string of 1 to 31 characters. If the string is enclosed in quotation marks ("), spaces are allowed in the string.
secondary

Log host that belongs to the secondary log host group.

-
log-type

Format of logs received by the session log server.

-
binary

Indicates that the format of logs received by the log server is binary.

-
syslog

Indicates that the format of logs received by the log server is syslog.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

You can configure two groups of log hosts on the device. Each group contains a maximum of 16 log hosts. The two groups can back up each other.

If multiple log hosts are configured, the device cyclically sends logs to log hosts 1 to 16 in turn based on the log host IDs by default. (Each log host receives different log packets.) If two groups of log hosts are configured, the device cyclically sends logs to log hosts in the two groups. That is, each log is sent to one log host in each group. The two log hosts back up each other.

log-type specifies the format of session logs received by a log host. When logs are sent, log packets in different formats can be constructed based on different log hosts. If log-type is not specified, the format of session logs sent to a log host is determined by the log output format configured using the firewall log session log-type command.

Example

# Configure the IPv6 log host. 
<HUAWEI> system-view
[HUAWEI] firewall log host 1 2001:db8:1::1 9002
[HUAWEI] firewall log host 2 2001:db8:1::2 9002
# Configure an IPv4 log host. 
<HUAWEI> system-view
[HUAWEI] firewall log host 1 10.10.10.1 9002
[HUAWEI] firewall log host 2 10.10.10.2 9002
