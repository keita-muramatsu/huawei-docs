forward performance mode

Function

The forward performance mode command sets the service performance mode.

For the AR5700 and AR6700 series, the default service performance mode is security mode.

For the AR8100 and AR8700 series, the default service performance mode is routing mode.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series and AR5710-S8P1XDSE-2LTE4EA.

Format

For AR5700-H series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T:

forward performance mode { routing | security | security-enhance }

For AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR5710-S8P1XDSE-2LTE4EA, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5710-S8TWDSE-LTE4EA, AR8100 series, AR8700 series:

forward performance mode { routing | security }

For AR6710-L14T2X4:

forward performance mode { security | security-enhance }

Parameters

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Application scenario of the routing mode: The system needs to ensure optimal route forwarding performance. If security functions such as IPS, antivirus, and URL filtering are not required, switch to this mode.

Application scenario of the security mode: The system switches to this mode when security functions such as IPS, antivirus, and URL filtering need to be enabled.

Application scenario of the enhanced security mode: The system needs to enable security functions such as IPS, antivirus, and URL filtering and ensure optimal secure forwarding performance.

After the service performance mode is switched, the device adjusts the number of forwarding cores based on the mode.

Precautions

  1. After the service performance mode is set for the AR8700 series and AR8100 series routers, the device needs to be restarted.
  2. If the service performance mode has not been set for the AR8700 and AR8100 series, the service performance mode is the default mode (routing mode) after the first restart when the configuration file is used for configuration restoration and the service performance mode in the configuration file is the security mode. The service performance mode becomes the security mode after the second restart.
  3. After setting the service performance mode on the AR8700 and AR8100 series, you need to save the configuration.
  4. This command can be executed only once every 10 minutes.

Example

# Set the service performance mode to routing for AR5700 and AR6700 series.
<HUAWEI> system-view
[HUAWEI] forward performance mode routing
Warning: This operation may cause traffic interruption, Continue? [Y/N]:y
Info: Performance mode is set successfully.
# Set the service performance mode to routing for AR8700 and AR8100 series.
<HUAWEI> system-view
[HUAWEI] forward performance mode routing
Info: Performance mode is set successfully. Please save current configuration. Restart the device for the setting to take effect.
