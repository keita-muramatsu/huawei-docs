device pnp-button disable

Function

The device pnp-button disable command disables the PNP button.

The undo device pnp-button disable command enables the PNP button.

By default, the PNP button is enabled.

Format

device pnp-button disable

undo device pnp-button disable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

To prevent the device from being reset or the saved user-defined configuration from being lost due to misoperations on the PNP button, run the device pnp-button disable command to disable the function of restoring factory settings by pressing and holding the PNP button and the function of resetting the device by pressing the PNP button.

To enable the function of restoring factory settings by pressing and holding the PNP button or the function of resetting the device by pressing the PNP button, run the undo device pnp-button disable command.

Example

# Enable the PNP button.
<HUAWEI> system-view
[HUAWEI] undo device pnp-button disable
# Disable the PNP button.
<HUAWEI> system-view
[HUAWEI] device pnp-button disable
