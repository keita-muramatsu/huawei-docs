saas-cloud-express

Function

The saas-cloud-express command configures SaaS application intelligent traffic steering and displays the SaaS cloud access view.

The undo saas-cloud-express command deletes the configuration of SaaS application intelligent traffic steering.

By default, SaaS application intelligent traffic steering is not configured.

Format

saas-cloud-express

undo saas-cloud-express

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

You can run this command to enter the SaaS cloud access view. After entering the SaaS cloud access view, you can configure SaaS application intelligent traffic steering.

Precautions

  • SaaS traffic steering can be applied only when user Internet access traffic matches the default route.
  • SaaS traffic steering is performed every 5 minutes. Generally, a link quality change affects the link selection result of users 5 minutes later.
  • For link selection between multiple DIA links, a link quality change affects only the link selection result of new users. The historical session path of existing users remains unchanged to prevent sessions of existing users from being interrupted due to link switchover.

Example

# Configure SaaS application intelligent traffic steering and enter the SaaS cloud access view.
<HUAWEI> system-view
[HUAWEI] saas-cloud-express
