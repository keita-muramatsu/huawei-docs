load-balance delay-differ

Function

The load-balance delay-differ command sets the acceptable delay difference between the load-balancing link and the optimal link in load balancing mode in a SaaS traffic steering policy.

The undo load-balance delay-differ command restores the default delay difference.

By default, the delay difference is 50 ms.

Format

load-balance delay-differ value

undo load-balance delay-differ [ value ]

Parameters

Parameter Description Value
delay-differ value

Sets the latency difference between the load-balancing link and the optimal link in load balancing mode in a SaaS traffic steering policy.

The value is an integer that ranges from 1 to 1000, in milliseconds.

Views

saas-policy-node view

Default Level

2: Configuration level

Usage Guidelines

If there are multiple ISP access links, multiple qualified links need to be selected for load balancing for SaaS application access to fully utilize link bandwidth. You can determine whether to add a link to the load balancing group by setting the delay difference between the link and the optimal link.

Example

# Set the delay difference to 40 ms.
<HUAWEI> system-view
[HUAWEI] saas-cloud-express
[HUAWEI-saas-cloud-express] saas-policy node 1
[HUAWEI-saas-cloud-express-saas-policy-node-1] load-balance delay-differ 40
