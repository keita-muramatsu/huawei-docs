wan-unit enable

Function

The wan-unit enable command enables WAN unit access management on a specified interface.

The undo wan-unit enable command disables WAN unit access management on a specified interface.

By default, WAN unit access management is disabled.

Format

wan-unit enable

undo wan-unit enable

Parameters

None

Views

10GE interface view, 25GE interface view, 40GE interface view, GE interface view, Multi-GE interface view, Cellular interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Before configuring a WAN unit to go online, you need to run this command to enable WAN unit access management on a specified interface. In addition, you need to run the dhcp select interface command in the interface view to enable interface address allocation so that the WAN unit can go online. Otherwise, the WAN unit on the interface cannot connect to the device.

Prerequisites

  1. A server SSL policy has been created using the ssl policy command in the system view.
  2. An SSL policy name for WAN unit access management has been configured using the wan-unit-manage ssl-policy command in the WAN unit management view.

Precautions

  • If the wan-unit-manage ssl-policy policy1 command has been run and the wan-unit enable command has been run in the interface view to enable WAN unit access management, the following operations are not supported:
    1. When you run the wan-unit-manage ssl-policy policy2 command, the system displays a message indicating that the configuration cannot be modified because the SSL policy policy1 has been bound.
    2. When you run the undo wan-unit-manage ssl-policy policy1 command, the system displays a message indicating that the SSL policy cannot be deleted because the SSL policy policy1 has been applied.
  • A WAN unit goes offline 1 minute after you run the shutdown command in the interface view.
  • RU-5G-related commands can be configured in the interface view only after WAN unit access management is enabled.

Example

# Enable WAN unit access management on 10GE1/0/1.
<HUAWEI> system-view
[HUAWEI] ssl policy policy1
[HUAWEI-ssl-policy-policy1] quit
[HUAWEI] wan-unit-manage
[HUAWEI-wan-unit-manage] wan-unit-manage ssl-policy policy1
[HUAWEI] quit
[HUAWEI] interface 10GE 1/0/1
[HUAWEI-10GE1/0/1] wan-unit enable
