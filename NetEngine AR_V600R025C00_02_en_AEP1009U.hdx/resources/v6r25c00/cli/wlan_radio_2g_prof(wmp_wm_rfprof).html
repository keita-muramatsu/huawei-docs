radio-2g-profile (WLAN view)

Function

The radio-2g-profile command creates a 2.4G radio profile and displays the 2.4G radio profile view, or displays the view of an existing 2.4G radio profile.

The undo radio-2g-profile command deletes a 2.4G radio profile.

By default, the system provides the 2.4G radio profile default.

Format

radio-2g-profile name profile-name

undo radio-2g-profile { name profile-name | all }

Parameters

Parameter Description Value
name profile-name

Specifies the name of a 2.4G radio profile.

The value is a string of 1 to 35 case-sensitive characters. The value cannot contain question marks (?) or spaces, and cannot start or end with double quotation marks (").
all

Deletes all 2.4G radio profiles.

-

Views

WLAN view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

You can use profiles to manage AP radio configurations. If multiple APs have different 2.4G radio parameters, you can bind different 2.4G radio profiles to radios of the corresponding AP and AP group.

Follow-up Procedure

Run the radio-2g-profile command to apply the 2.4G radio profile in the AP view, AP group view, AP radio view, or AP group radio view so that the 2.4G radio profile can take effect.

Precautions

  • The 2.4G radio profile named default cannot be deleted.
  • A 2.4G radio profile that has been bound cannot be deleted. To delete it, unbind it first.

Example

# Create the 2.4G radio profile radio-profile1 and display the 2.4G radio profile view.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] radio-2g-profile name radio-profile1
[HUAWEI-wlan-radio-2g-prof-radio-profile1]
