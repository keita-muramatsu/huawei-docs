ike initiator flow-check disable

Function

The ike initiator flow-check disable command disables the flow check function on the IKE negotiation initiator.

The undo ike initiator flow-check disable command enables the flow check function on the IKE negotiation initiator.

By default, flow check is enabled on the IKE negotiation initiator.

Format

ike initiator flow-check disable

undo ike initiator flow-check disable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

If ACLs on both ends of an IPsec tunnel mirror each other, an SA can be successfully established when any end initiates negotiation. If ACLs on both ends do not mirror each other, an SA can be successfully established only when the address range specified in the ACL rule of the initiator is included in that of the responder or when there are overlapping address ranges in the ACL rules on both ends.

After the flow check function is enabled on the initiator, the initiator sends the ACL that defines the traffic flows to be protected to the remote end during IKE negotiation. Upon receiving the negotiation response, the initiator compares the protected traffic flow range returned by the remote end with its own configured ACL to verify that the negotiation result is correct.

If the flow check function is disabled on the IKE negotiation initiator, the initiator does not check the negotiation result.

Example

# Enable the flow check function on the IKE negotiation initiator.
<HUAWEI> system-view
[HUAWEI] undo ike initiator flow-check disable
