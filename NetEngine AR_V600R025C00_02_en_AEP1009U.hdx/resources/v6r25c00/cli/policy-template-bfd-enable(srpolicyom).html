bfd enable (SR Policy template view)

Function

The bfd unaffiliated enable command enables U-BFD in an SR Policy attribute template.

The undo bfd unaffiliated enable command deletes the preceding configuration.

The bfd disable command disables BFD in an SR Policy attribute template.

The undo bfd disable command deletes the preceding configuration.

The bfd unaffiliated enable reverse-path binding-sid command enables the function to forward U-BFD return packets over a tunnel in an SR Policy attribute template.

The undo bfd unaffiliated enable reverse-path binding-sid command deletes the preceding configuration.

By default, the BFD function in an SR Policy attribute template is not enabled.

Format

bfd disable

bfd unaffiliated enable

bfd unaffiliated enable reverse-path binding-sid

undo bfd disable

undo bfd unaffiliated enable

undo bfd unaffiliated enable reverse-path binding-sid

Parameters

Parameter Description Value
unaffiliated

Enables U-BFD in an SR Policy attribute template.

-
binding-sid

Enables the function to forward BFD return traffic over the tunnel specified by a binding SID in an SR Policy attribute template.

-
disable

Disables the BFD function in an SR Policy attribute template.

-

Views

SR Policy template view

Default Level

2: Configuration level

Usage Guidelines

The bfd unaffiliated enable (SR Policy template view) command enables U-BFD in an SR Policy attribute template. The srv6-te-policy bfd unaffiliated enable (Segment Routing IPv6 view) command enables U-BFD for all SRv6 TE Policies globally in the Segment Routing IPv6 view. The bfd unaffiliated enable (SRv6 TE Policy view) command enables U-BFD for a single SRv6 TE Policy.

For the same SRv6 TE Policy, if both the srv6-te-policy bfd unaffiliated enable (Segment Routing IPv6 view) and bfd unaffiliated enable (SRv6 TE Policy view) commands are run and the template referenced by the primary path of the policy has BFD configurations, the bfd unaffiliated enable (SRv6 TE Policy view) command configuration has the highest priority. The bfd unaffiliated enable (SR Policy template view) command configuration has the second highest priority, followed by the srv6-te-policy bfd unaffiliated enable (Segment Routing IPv6 view) command configuration.

Example

# Enable U-BFD in an SR Policy attribute template.
<HUAWEI> system-view
[HUAWEI] segment-routing policy-template 1
[HUAWEI-sr-policy-template-1] bfd unaffiliated enable
