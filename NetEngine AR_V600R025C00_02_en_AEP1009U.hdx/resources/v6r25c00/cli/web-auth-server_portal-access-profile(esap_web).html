web-auth-server (Portal access profile view)

Function

The web-auth-server command configures a Portal server template used by a Portal access profile.

The undo web-auth-server command restores the default configuration.

By default, no Portal server template is bound to a Portal access profile.

Format

web-auth-server server-name [ bak-server-name ] [ layer3 ]

undo web-auth-server

Parameters

Parameter Description Value
server-name

Specifies the name of a Portal server template.

The value must be the name of an existing Portal server template.
bak-server-name

Specifies the name of the backup Portal server template.

The value must be the name of an existing Portal server template.
layer3

Indicates that Layer 3 authentication is used for Portal authentication.

-

Views

Portal access profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After a Portal server template is configured on the device, you need to bind the template to a Portal access profile. When a user using a Portal access profile attempts to access non-free network resources, the user is redirected to the authentication page of the Portal server for Portal authentication.

To improve Portal authentication reliability, you can bind the backup Portal server template to the Portal access profile. When the primary Portal server is disconnected, users are redirected to the backup Portal server for authentication. This function requires that the Portal server detection function be enabled using the server-detect command and heartbeat detection be enabled on the Portal server.

For wired users, Portal authentication is classified into Layer 2 Portal authentication and Layer 3 Portal authentication.

  • Layer 2 Portal authentication (default authentication mode): When there is no Layer 3 forwarding device between a user and the device, the device can learn the user's MAC address. In this case, MAC addresses can be used to identify users. You only need to configure Layer 2 Portal authentication.
  • Layer 3 Portal authentication (specified using layer3): If the device cannot obtain the MAC addresses of users regardless of whether there is a Layer 3 forwarding device between the users and the device, you need to configure Layer 3 Portal authentication because the users are uniquely identified using their IP addresses.

Prerequisites

A Portal server template has been created using the web-auth-server (system view) and server-ip (Portal server template view) commands, and the IP address of the Portal server has been configured in the template.

Precautions

  • After a Portal access profile is bound to an authentication profile, the Portal server template used by the Portal access profile cannot be deleted, but can be modified.
  • After a user goes online through external Portal authentication, if the ARP entry on the device is cleared (for example, if the IP address of the VLANIF interface bound to the Portal server template is deleted, the ARP entry of the user who goes online through the VLANIF interface is aged out). In this case, the user corresponding to the ARP entry cannot go online again after going offline. To solve this problem, perform redirection on the device again. That is, when the user enters the IP address of a non-Portal authentication page in the browser on the terminal, the device pushes the authentication page to the user.
  • Different types of interfaces support different Portal authentication modes. Layer 3 physical interfaces support only Layer 3 Portal authentication, Layer 2 physical interfaces support only Layer 2 Portal authentication, and VLANIF interfaces support both Layer 2 and Layer 3 Portal authentication.
  • The VLANIF interface corresponding to the super-VLAN does not support Portal authentication.

Example

# Bind the Portal access profile p1 to the Portal server templates server1 and server2 (server2 is the backup Portal server profile).
<HUAWEI> system-view
[HUAWEI] web-auth-server server1
[HUAWEI-web-auth-server-server1] server-ip 10.10.1.1
[HUAWEI-web-auth-server-server1] quit
[HUAWEI] web-auth-server server2
[HUAWEI-web-auth-server-server2] server-ip 10.10.2.1
[HUAWEI-web-auth-server-server2] quit
[HUAWEI] portal-access-profile name p1
[HUAWEI-portal-access-profile-p1] web-auth-server server1 server2
