igmp enable

Function

The igmp enable command enables IGMP on an interface.

The undo igmp enable command disables IGMP on an interface.

By default, the IGMP function is disabled on an interface.

Format

igmp enable

undo igmp enable

Parameters

None

Views

10GE sub-interface view, 10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE sub-interface view, 40GE interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, Ethernet sub-interface view, Ethernet interface view, GE optical interface view, GE sub-interface view, GE interface view, GE electrical interface view, Loopback interface view, Multi-GE sub-interface view, Multi-GE interface view, Tunnel interface view, VLANIF interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

On the network segment where users are connected to the IP multicast network, both the device and user hosts must run IGMP. A device can communicate with user hosts and process IGMP messages sent from user hosts only after IGMP is enabled on the interfaces connected to user network segments.

Prerequisites

The multicast routing function has been enabled using the multicast routing-enable command in the public network instance view or VPN instance view.

Configuration Impact

IGMP parameters that are configured on an interface take effect only after this command is run on the interface.

Precautions

During the upgrade in CFG mode, if the igmp enable command has been run on the interface connected to users, the device automatically enables the pim sm command to prevent traffic interruption.

Example

# Enable IGMP on 10GE 0/0/1 connected to a user host.
<HUAWEI> system-view
[HUAWEI] multicast routing-enable
[HUAWEI] pim
[HUAWEI-pim] quit
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] undo portswitch
[HUAWEI-10GE0/0/1] pim sm
[HUAWEI-10GE0/0/1] igmp enable
