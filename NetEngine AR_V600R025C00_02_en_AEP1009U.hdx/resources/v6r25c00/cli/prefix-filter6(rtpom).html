ip ipv6-prefix

Function

The ip ipv6-prefix command configures an IPv6 prefix list or one entry in the IPv6 prefix list.

The undo ip ipv6-prefix command deletes an IPv6 prefix list or one entry in the IPv6 prefix list.

By default, no IPv6 prefix list is configured.

Format

ip ipv6-prefix ipv6-prefix-name [ index index-number ] matchMode ipv6-address masklen [ match-network ] [ greater-equal greater-equal-value ] [ less-equal less-equal-value ]

undo ip ipv6-prefix ipv6-prefix-name [ index index-number ]

undo ip ipv6-prefix ipv6-prefix-name ipv6-address masklen [ match-network ] [ greater-equal greater-equal-value ] [ less-equal less-equal-value ]

Parameters

Parameter Description Value
ipv6-prefix-name

Specifies the name of the prefix list.

The value is a string of 1 to 169 case-sensitive characters. The character string can contain spaces if it is enclosed in double quotation marks ("").
index index-number

Specifies the sequence number of the entry in the IPv6 prefix list. By default, the sequence number increases with a step of 10 according to the configuration order, and the first number is 10.

The value is an integer in the range from 1 to 4294967295.
matchMode

Specifies the matching mode of the IP prefix list.

The value is of the enumerated type.

  • permit: indicates that the matching mode of IP prefix entries is permit. In permit mode, if the IPv6 address to be filtered is in the defined prefix range, the IPv6 address matches the route-policy and stops matching against the next entry. Otherwise, the IPv6 address continues to match against the next entry.
  • deny: indicates that the matching mode of the IP prefix list entry is deny. In deny mode, if the IPv6 address to be filtered is in the defined prefix range, the IPv6 address fails to match the route-policy and cannot match against the next entry. Otherwise, the IPv6 address continues to match against the next entry.
ipv6-address

Specifies the IPv6 prefix range in the form of an IPv6 address. If :: is specified, the address 0::0 is matched.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
masklen

Specifies the IPv6 prefix range using the mask length. If ::0 less-equal 128 is used, all the IPv6 addresses are matched.

The value is an integer ranging from 0 to 128.
match-network

Matches routes with specified network addresses. The match-network parameter can be configured only when the result of a bitwise AND operation on ipv6-address and the subnet mask is ::. For example, the ip ipv6-prefix prefix1 permit :: 96 command matches all routes with the prefix length of 96, whereas the ip ipv6-prefix prefix1 permit :: 96 match-network command matches all routes within the network address range from ::1 to ::FFFF:FFFF.

-
greater-equal greater-equal-value

A mask length range can be set to match the routes with the same prefix but different masks. That is, the mask length range specified in [ greater-equal greater-equal-value ] [ less-equal less-equal-value ] can be used to match such routes. greater-equal means "greater than or equal to", and less-equal means "less than or equal to".

The mask length range must meet the following condition: maskLen <= greater-equal-value <= less-equal-value <= 128.

  • If only greater-equal is set, the mask length range is from greater-equal-value to 128.
  • If only less-equal is set, the mask length range is from masklen to less-equal-value.
  • If greater-equal and less-equal are specified, the mask length range is from greater-equal-value to less-equal-value.
less-equal less-equal-value

A mask length range can be set to match the routes with the same prefix but different masks. That is, the mask length range specified in [ greater-equal greater-equal-value ] [ less-equal less-equal-value ] can be used to match such routes. greater-equal means "greater than or equal to", and less-equal means "less than or equal to".

The mask length range must meet the following condition: maskLen <= greater-equal-value <= less-equal-value <= 128.

  • If only greater-equal is set, the mask length range is from greater-equal-value to 128.
  • If only less-equal is set, the mask length range is from masklen to less-equal-value.
  • If greater-equal and less-equal are specified, the mask length range is from greater-equal-value to less-equal-value.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

This command is used to configure a prefix list, which can be used as a filter by various protocols or used with route-policies.

  • The ip ipv6-prefix command can be used with the following commands to filter the routes to be advertised globally based on the IPv6 prefix list:
  • filter-policy export (OSPFv3)
  • ipv6 filter-policy export (IS-IS)
  • filter-policy export (BGP)
  • The ip ipv6-prefix command can be used with the following commands to filter the routes to be received globally based on the IPv6 prefix list:
  • filter-policy import (OSPFv3)
  • ipv6 filter-policy import (IS-IS)
  • filter-policy import (BGP)
  • The ip ipv6-prefix command can be used with the following commands to configure a route-policy that is based on an IPv6 prefix list for a specific peer:
  • peer ipv6-prefix (BGP)
  • ipv6 import-route isis level-1 into level-2 filter-policy ipv6-prefix //Use an IPv6 prefix list to control the leaking of IS-IS Level-1 routes to the Level-2 area.
  • ipv6 import-route isis level-2 into level-1 filter-policy ipv6-prefix //Use an IPv6 prefix list to control the leaking of IS-IS Level-2 routes to the Level-1 area.
  • The ip ipv6-prefix command and the if-match ipv6 command can be used together in a route-policy to filter the routes to be received or sent based on an IPv6 prefix list.

    An IPv6 prefix list is used to filter IPv6 addresses. It can contain multiple entries, each specifying an address prefix range. The relationship between the entries is "OR". That is, if a route matches one of the entries, the route matches the prefix list; if a route does not match any of entries, the route fails to match the prefix list.

    A prefix range is determined by two parts: prefix-length and less-equal-value or greater-equal-value. If both the two parts are specified, routes are matched against the prefix list based on the prefix range specified by the two parts.

Precautions

An IPv6 prefix list in use cannot be deleted.

After a configuration is delivered, the device checks the validity of the parameters in the configuration and processes these parameters. After the processing, the generated IPv6 address is the result of the AND calculation between the specified ipv6-address and prefix-length. For example, if ipv6-address and prefix-length are set to 2001:db8::1 and 64, respectively, the generated configuration is 2001:db8:: 64, where 2001:db8:: is the result of the AND calculation between 2001:db8::1 and 0XFFFF:FFFF:FFFF:FFFF::.

If the ipv6-address in the generated configuration is :: (wildcard address), the configuration matches all IPv6 addresses.

The maximum number of IPv6 prefix lists is controlled by the PAF item SPEC_RES_RTP_MAX_IPV6_PREFIXLIST_NUM, which can be viewed using the display paf command. If the PAF value is 4294967295, the maximum number is 400000.

The maximum number of nodes in a single IPv6 prefix filter is controlled by the PAF item SPEC_RES_RTP_MAX_IPV6_PREFIXLISTNODE_NUM, which can be viewed using the display paf command.

The maximum number of nodes in all IPv6 prefix filters is controlled by the PAF item SPEC_RES_RTP_MAX_IPV6_PREFIXLISTNODE_TOTAL_NUM, which can be viewed using the display paf command.

Example

# Deny the routes with the IP prefix 2001:db8:D00::/32 and with the prefix longer than 32 bits.
<HUAWEI> system-view
[HUAWEI] ip ipv6-prefix abc deny 2001:db8:D00:: 32 less-equal 128
# Permit the routes with the mask length ranging from 32 to 64 bits.
<HUAWEI> system-view
[HUAWEI] ip ipv6-prefix abc permit :: 0 greater-equal 32 less-equal 64
