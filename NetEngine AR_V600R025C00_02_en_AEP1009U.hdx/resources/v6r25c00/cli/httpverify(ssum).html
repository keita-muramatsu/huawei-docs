http verify-server disable

Function

The http verify-server disable command disables the server certificate verification function before a device is connected to the HOUP for smart upgrade.

The undo smart-upgrade http verify-server disable command enables the server certificate verification function before a device is connected to the HOUP for smart upgrade.

By default, verify that the certificate function of the server is enabled.

Format

http verify-server disable

undo http verify-server disable

Parameters

None

Views

Smart upgrade view

Default Level

3: Management level

Usage Guidelines

During the smart upgrade, you can enable the server certificate verification function to verify the security of the connected server. When the certificate for smart upgrade is invalid or no certificate for smart upgrade is available, you can run the http verify-server disable command to temporarily disable the certificate verification function.

Although the certificate verification function is manually disabled, an SSL policy still needs to be bound to smart upgrade. Therefore, after certificate verification is disabled, you need to run the ssl policy command to create an SSL policy and then run the ssl-policy command to bind the SSL policy.

Example

# Disables the server certificate verification function before a device is connected to the HOUP for smart upgrade.
<HUAWEI> system-view
[HUAWEI] smart-upgrade
[HUAWEI-upgrade] http verify-server disable
