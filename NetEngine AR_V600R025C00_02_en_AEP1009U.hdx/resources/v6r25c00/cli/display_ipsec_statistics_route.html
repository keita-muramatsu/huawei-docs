display ipsec statistics route

Function

The display ipsec statistics route command displays IPsec route injection statistics.

Format

display ipsec statistics route [ slot slot-id cpu cpu-id ]

Parameters

Parameter Description Value
slot slot-id

Displays IPsec route injection statistics in a specified slot.

The value varies depending on device models.
cpu cpu-id

Displays IPsec route injection statistics on a specified CPU.

The value varies depending on device models.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

In an IPsec route injection scenario, you can run the display ipsec statistics route command to view IPsec route injection statistics for fault location.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display IPsec route injection statistics.
<HUAWEI> display ipsec statistics route

Route send to route module    add :2          del    :1
Route send to ipsec module    add :1          del    :0

  route not exist                         :0

Table 1 Description of the display ipsec statistics route command output
Item Description
route not exist

Number of routes that do not exist during route deletion.
IPsec route statistics information

IPsec route statistics.
Slot x, cpu y

Slot ID and CPU ID.
cpu not exist

Number of times the CPU does not exist during route addition.
Route add

Routes are added from the service module to control module:

  • send: indicates the number of routes sent by the service module.
  • receive: indicates the number of routes received by the control module.
Route del

Routes are deleted by the service module from the control module:

  • send: indicates the number of routes sent by the service module.
  • receive: indicates the number of routes received by the control module.
Route syn

Routes are synchronized by the service module with the control module:

  • send: indicates the number of routes sent by the service module.
  • receive: indicates the number of routes received by the control module.
  • add: indicates the number of routes added by the control module because routes do not exist.
  • del: indicates the number of routes deleted by the control module due to residual routing entries.
Route syn round

Number of times the service module synchronizes routes with the control module:

  • send: indicates the number of times the service module sends routes to the control module.
  • receive: indicates the number of times the control module receives routes from the service module.
Route send to route module

Routes are added to or deleted from the routing module:

  • add: indicates the number of added routes.
  • del: indicates the number of deleted routes.
Route send to ipsec module

Routes are added to or deleted from the IPsec module:

  • add: indicates the number of added routes.
  • del: indicates the number of deleted routes.
Route msg ipc send error

Number of times IPC fails to send routing information.
Route msg process error

Number of times the service module fails to process routing information.
add no memory

Number of failures to apply for memory during route addition.
dest addr equal with peer addr

Number of times the route destination address is consistent with the peer address specified in intelligent path selection during route addition.
same route same slot

Number of times the same slot has the same routes during route addition.
same route diff slot or interface down

Number of times boards in different slots have the same routes or have interfaces in Down state during route addition.
same route send by other slot

Number of the same routes that other service modules send to the control module during route deletion.
not delete state

Number of routes that do not exist in the routing table during route deletion.
vrf invalid

Number of times the VPN instance becomes invalid during route addition.
