engine enhanced-detection

Function

The engine enhanced-detection command configures the engine to work in enhanced detection mode.

The undo engine enhanced-detection command configures the engine to work in common detection mode.

By default, the engine works in enhanced detection mode for RTSP and works in common detection mode for protocols excluding RTSP.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

engine enhanced-detection [ protocol { rtsp | others } ]

undo engine enhanced-detection [ protocol { rtsp | others } ]

Parameters

Parameter Description Value
protocol

Indicates the protocol.

-
rtsp

Indicate the Real Time Streaming Protocol (RTSP).

-
others

Indicates a protocol other than RTSP.

-

Views

System view

Default Level

3: Management level

Usage Guidelines

After the enhanced detection mode is enabled, the detection capability of the device is enhanced, but the detection rate decreases. To increase the detection rate, disable the enhanced detection mode. After the enhanced detection mode is disabled, if the traffic corresponding to the current session does not generate threats, the system does not detect sessions with the same URI for a period of time.

Example

# Configure the engine to work in enhanced detection mode.
<HUAWEI> system-view
[HUAWEI] engine enhanced-detection
