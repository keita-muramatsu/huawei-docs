ikev2 fragmentation next-payload standard

Function

The ikev2 fragmentation next-payload standard command sets the next-payload field in subsequent IKEv2 fragments to 0.

The undo ikev2 fragmentation next-payload standard command restores the default configuration.

By default, the next-payload value in subsequent IKEv2 fragments is the same as that in the first fragment.

Format

ikev2 fragmentation next-payload standard

undo ikev2 fragmentation next-payload standard

Parameters

None

Views

IKE peer view

Default Level

2: Configuration level

Usage Guidelines

After IKEv2 packet fragmentation is enabled using the ikev2 fragmentation command, you can run the ikev2 fragmentation next-payload standard command to set the next-payload field in subsequent IKEv2 fragments in compliance with RFC standards.

The configurations on both ends of an IPsec tunnel must be the same. Otherwise, the interconnection may fail.

Example

# Set the value of the next-payload field in subsequent IKEv2 packet fragments to 0. 
<HUAWEI> system-view
[HUAWEI] ike peer test
[HUAWEI-ike-peer-test] ikev2 fragmentation next-payload standard
