display vap create-fail-record

Function

The display vap create-fail-record command displays records about VAP creation failures.

Format

display vap create-fail-record { ap-mac ap-mac | all }

Parameters

Parameter Description Value
ap-mac ap-mac

Displays records about VAP creation failures on an AP with the specified MAC address.

The AP's MAC address must exist.
all

Displays records about VAP creation failures on all APs.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run the display vap create-fail-record all command to check records about VAP creation failures.

Table: Reasons for VAP creation failures

The VAPs using WEP encryption on an AP cannot use the same key ID. - Check the configuration of the VAP profile or security profile.
Invalid WEP key index. - Check whether the security profile is configured correctly.
Preshared key is not configured. - Configure a pre-shared key.
Only one management VAP profile can be bound. - Delete the management VAP that has been configured.
WLAN ID(16) is used. Please undo first. WLAN ID 16 is used to set up a Mesh link. Select another WLAN ID or delete the Mesh configuration.
Only one temporary management vap-profile can be bound to an AP. - Delete the offline management VAP that has been configured.
The current country code does not support 5GHz frequency band. - Change the country code, or do not create a 5 GHz VAP.
The current country code does not support 2.4GHz frequency band. - Change the country code, or do not create a 2.4 GHz VAP.
The AP type does not support the wlan id. - Delete unused VAPs.
This AP type does not support Mesh function. - Replace the AP with a Mesh-capable AP.
The number of VAPs has reached the upper limit. - Delete excess VAPs.
The AP does not support 5GHz frequency band. - Replace the AP, or avoid creating a 5 GHz VAP.
The AP does not support 2.4GHz frequency band. - Replace the AP, or avoid creating a 2.4 GHz VAP.
The AP does not support 802.1X+WEP. - Replace the AP with one in compliance with 802.11ac Wave 2.
SFN roaming can be configured only on one VAP of each radio. - Create a VAP on another radio or delete the SFN roaming VAP on the current radio.
The AP does not support SFN. - Replace the AP with one supporting SFN roaming.
The 5G radio of the AP does not support SFN. - Replace the AP or change the 5 GHz radio configuration.
The number of VAPs has reached the card specific. - Reduce the number of VAPs on a card, or enable the AP to go online on another card of the switch and create VAPs.
The AP in this version does not support Navi-AC VAPs. - Upgrade the AP to V200R010C00 or later.
Unknown reason, error code is 0x%x. - Contact technical support personnel.
The number of Mesh VAPs has reached the upper limit. - Delete redundant Mesh VAPs.
The frequency band of this radio is inconsistent with that supported by the current country code. - Change the country code, or avoid creating a VAP on the same frequency band as the current radio.
The AP in this version does not support the Mesh configuration on radio 2. - Upgrade APs to V200R020C10 or later.
The AP does not support OWE. - Upgrade APs to V200R020C10 or later.
No security policy is configured. - Configure a security policy.
No PSK is configured. No WEP key is configured. Configure a WEP key.
Only the OWE and WPA3 security policy can be configured on the 6GHz frequency band. - Modify the security policy configuration of the VAP.
The current country code does not support 6GHz frequency band. - Change the country code, or avoid creating a 6 GHz VAP.

The 6G radio of the AP does not support SFN. - Replace the AP or change the 6 GHz radio configuration.
The AP in this version does not support 802.11r+PMF, 802.11r+WPA3, or 802.11r+WPA2-WPA3. - Upgrade the AP to R024C00SPC100 or later.
