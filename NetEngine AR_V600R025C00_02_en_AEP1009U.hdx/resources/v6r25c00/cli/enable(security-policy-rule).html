enable (Security policy rule view)

Function

The enable command enables the security policy rule.

The disable command disables the security policy rule.

By default, a security policy rule is enabled.

Format

enable

disable

Parameters

None

Views

Security policy rule view

Default Level

2: Configuration level

Usage Guidelines

A security policy rule takes effect only when it is enabled.

Example

# Enable security policy rule policy_sec in the security policy rule view. 
<HUAWEI> system-view
[HUAWEI] security-policy
[HUAWEI-policy-security] rule name policy_sec
[HUAWEI-policy-security-rule-policy_sec] enable
Info: The policy is enabled successfully.
# Disable security policy rule policy_sec in the security policy rule view. 
<HUAWEI> system-view
[HUAWEI] security-policy
[HUAWEI-policy-security] rule name policy_sec
[HUAWEI-policy-security-rule-policy_sec] disable
Warning: This command will invalidate the rule. Continue?[Y/N]y
Info: The policy is disabled successfully.
