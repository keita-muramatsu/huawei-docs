tcp-proxy batch-receive enable

Function

The tcp-proxy batch-receive enable command enables the batch packet receiving function when the TCP proxy stack sends packets to the CPU.

The undo tcp-proxy batch-receive enable command disables the batch packet receiving function when the TCP proxy stack sends packets to the CPU.

By default, the batch packet receiving function is disabled when the TCP proxy stack sends packets to the CPU.

Format

tcp-proxy batch-receive enable

undo tcp-proxy batch-receive enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

After the batch packet receiving function of the TCP proxy stack is enabled, the protocol stack attempts to aggregate multiple packets before sending them to the service app.

Example

# Enable the batch packet receiving function for the TCP proxy stack.
<HUAWEI> system-view
[HUAWEI] tcp-proxy batch-receive enable
