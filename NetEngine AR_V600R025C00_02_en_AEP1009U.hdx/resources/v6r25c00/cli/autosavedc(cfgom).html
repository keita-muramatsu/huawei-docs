configuration file auto-save

Function

The configuration file auto-save command enables a device to save configurations at scheduled time.

The undo configuration file auto-save command disables a device from saving configurations at scheduled time.

By default, the system does not save configurations at scheduled time.

Format

configuration file auto-save [ interval interval | delay delay-interval | cpu-limit cpu-usage ] *

configuration file auto-save { interval | delay | cpu-limit } default

undo configuration file auto-save

Parameters

Parameter Description Value
interval interval

Specifies the interval at which configurations are saved automatically.

The value is an integer ranging from 30 to 43200, in minutes. The default value is 30.
delay delay-interval

Specifies the delay time for backing up a configuration automatically after the configuration is changed.

The value is an integer ranging from 1 to 60, in minutes. The default value is 5.
cpu-limit cpu-usage

Specifies the maximum CPU usage.

The value is an integer ranging from 1 to 100. The default value is 50, indicating that the upper limit of the CPU usage is 50%.
default

Restores the default values for the parameters of the automatic save function.

-

Views

System view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

You can run commands to modify the current configurations of the device, but these configurations are temporary. If you want the configuration to take effect after the system restarts, save the current configuration to the configuration file for the next startup before restarting the system.

After the auto-save function is configured, the system automatically saves the current configuration to the configuration file for the next startup when the configuration is changed. If the configuration file for the next startup changes, the system automatically saves the current configuration. If there is no configuration file for next startup, the configuration is saved to vrpcfg.zip by default and specified as the configuration file for next startup. In addition, if the function of periodically saving the configuration file to the server is enabled, the configuration file is also uploaded to the server.

  • By specifying the cpu-limit parameter, you can set the upper limit of the CPU usage when the configuration is automatically saved. When the auto-save timer is triggered, the system cancels the auto-save operation if the system CPU usage is detected to be higher than the preset value.
  • The interval parameter specifies the interval at which configurations are automatically saved. The delay parameter specifies the delay after which configurations are automatically saved.
  • When both interval and delay are set, the parameter that is set earlier triggers the configuration saving. When the time specified by the other parameter arrives, the system checks the configuration again. If the configuration is not changed, the system does not save the configuration.
  • You can run the configuration file auto-save { interval | delay | cpu-limit} default command to restore the parameters of the auto-save function to the default values.

Configuration Impact

After the automatic configuration saving function is configured, the system automatically saves the current configurations to the configuration file for next startup when the current configurations are different from those in the configuration file for next startup and the time specified by interval or delay arrives, regardless of whether the save operation is manually performed.

Follow-up Procedure

Run the display saved-configuration configuration command, and view configuration information about the function of saving configurations periodically.

Precautions

In the following situations, the system cancels the scheduled configuration saving operation:

  • The configuration file is being written.
  • The device is being restored.
  • The CPU usage exceeds the preset threshold.

When the configuration file for next startup is specified, automatic saving is disabled and the disabling duration is 30 minutes.

When the configuration is changed or the configuration file for next startup is specified, the configuration sequence number is changed and the configuration is automatically saved to the configuration file for next startup.

When the automatic saving function is disabled, the configuration file auto-save delay default command cannot be used to enable the automatic saving function.

Example

# Configure the interval at which the system saves new configurations to be 60 minutes.
<HUAWEI> system-view
[HUAWEI] configuration file auto-save interval 60
# Configure the automatic saving function. If the system configuration changes and no more configuration change occurs within 3 minutes, automatic saving is triggered. If configuration change occurs again within the delay time, automatic saving is triggered another 3 minutes later. If the configuration is changed continuously, automatic saving cannot be triggered. The automatic saving function is forcibly triggered at an interval of 10 hours. The upper limit of CPU usage is 60%.
<HUAWEI> system-view
[HUAWEI] configuration file auto-save interval 600 delay 3 cpu-limit 60
