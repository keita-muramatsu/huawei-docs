authentication redirect-acl original-url enable

Function

The authentication redirect-acl original-url enable command enables the redirect URL to carry the original URL when users who have passed Portal authentication and match a redirect ACL are redirected for another Portal authentication.

The undo authentication redirect-acl original-url enable command disables the redirect URL from carrying the original URL when users who have passed Portal authentication and match a redirect ACL are redirected for another Portal authentication..

By default, a redirect URL does not carry the original URL when users who have passed Portal authentication and match a redirect ACL are redirected for another Portal authentication.

Format

authentication redirect-acl original-url enable

undo authentication redirect-acl original-url enable

Parameters

None

Views

Authentication profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

An administrator may need to redirect the users who have passed Portal authentication and match a redirect ACL to a specified web page for another Portal authentication. By default, the redirect URL does not carry the original URL accessed by users. After successful Portal authentication, the authentication server cannot obtain the original URL, causing the failure to access the original URL. To resolve this problem, run the authentication redirect-acl original-url enable command to configure the redirect URL to carry the original URL.

Precautions

Only the users who have passed Portal authentication and match a redirect ACL can be redirected to a specified web page for another Portal authentication.

Before this function takes effect, run the url-parameter command in the Portal server template view to configure the original URL parameters carried in the redirect URL.

Example

# Enable the device to carry the original URL in the redirect URL when users who have passed Portal authentication and match a redirect ACL are redirected for another Portal authentication.
<HUAWEI> system-view
[HUAWEI] authentication-profile name authen1
[HUAWEI-authen-profile-authen1] authentication redirect-acl original-url enable
