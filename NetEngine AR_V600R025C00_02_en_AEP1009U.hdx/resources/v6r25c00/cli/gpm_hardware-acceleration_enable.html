gpm hardware-acceleration enable

Function

The gpm hardware-acceleration enable command enables the hardware acceleration mode of the ASE and attempts to restart the ASE.

The undo gpm hardware-acceleration enable command disables the hardware acceleration mode of the ASE.

By default, the hardware acceleration mode of the ASE engine is enabled.

This command is supported only on the AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T and AR6710-L14T2X4.

Format

gpm hardware-acceleration enable

undo gpm hardware-acceleration enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To switch the work mode of the GPM module in the ASE, run this command.

Precautions

The work mode of the GPM module cannot be switched continuously within 600 seconds.

Example

# Enable the hardware acceleration mode.
<HUAWEI> system-view
[HUAWEI] gpm hardware-acceleration enable
This operation will switch the working mode of the generic pattern matching module in the engine and try to restart the engine. After performing this operation, ensure that the engine is running properly. Are you sure you want to perform this operation?[Y/N] Y
