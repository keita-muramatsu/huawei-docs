using (E1/CE1 interface view)

Function

The using command configures the working mode of an E1 interface.

The undo using command restores the default working mode of an E1 interface. When using this command, you need to wait for a certain period of time due to configuration deletion.

By default, an E1 interface works in channelized mode.

This command is supported only on the AR8700 series, AR5710-S10T1X2, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series and AR6700-H series.

Format

using e1

using ce1

undo using

Parameters

Parameter Description Value
ce1

Specifies the channelized mode or unchannelized mode.

-
e1

Specifies the clear channel mode.

-

Views

E1/CE1 interface view, E1 interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

An E1 interface can work in either of the following modes:

  • Clear channel mode: The E1 interface is not divided into timeslots. Instead, it can be used as a 2.048 Mbit/s synchronous serial interface.
  • Channelized or unchannelized mode: The E1 interface is physically divided into 32 timeslots. You can bundle 31 timeslots except timeslot 0 to form a synchronous serial interface with a transmission rate of N x 64 kbit/s.

    You can run this command to configure a working mode for an E1 interface.

Follow-up Procedure

If an E1 interface works in channelized or unchannelized mode, you can run the channel-set timeslot-list command to bundle the timeslots of a CE1 interface into a channel-set.

Precautions

Before changing the working mode of an E1 interface, note the following:

  • To switch an E1 interface from the channelized mode or unchannelized mode to the clear channel mode, delete the channelized configurations and run the using e1 command.
  • To switch an E1 interface from the clear channel mode to the channelized mode or unchannelized mode, delete the clear channel configurations and configurations under the synchronous serial interface (without the need to delete the synchronous serial interface), and run the using ce1 or undo using command.

Example

# Configure an E1 interface to work in clear channel mode.
<HUAWEI> system-view
[HUAWEI] controller e1 0/1/0
[HUAWEI-E1 0/1/0] using e1
