vrrp6 virtual-ip route-advertise disable

Function

The vrrp6 virtual-ip route-advertise disable command disables a dynamic routing protocol from advertising routes destined for the virtual IP address of a VRRP6 group.

The undo vrrp6 virtual-ip route-advertise disable command enables a dynamic routing protocol to advertise routes destined for the virtual IP address of a VRRP6 group.

By default, a dynamic routing protocol is enabled to advertise routes destined for the virtual IP address of a VRRP6 group.

Format

vrrp6 virtual-ip route-advertise disable { isis | ospf } *

undo vrrp6 virtual-ip route-advertise disable { isis | ospf } *

Parameters

Parameter Description Value
isis

Disables IS-IS from advertising routes destined for the virtual IP address of a VRRP6 group.

-
ospf

Disables OSPF from advertising routes destined for the virtual IP address of a VRRP6 group.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Direct routes destined for virtual IP addresses of a VRRP6 group can be imported to a dynamic routing protocol. By default, such routes can be advertised to neighbors through the protocol. On a live network, there may be a large number of routes destined for virtual IP addresses of VRRP6 groups; therefore, if a dynamic routing protocol imports and advertises these routes to neighbors, some devices on the network may be overloaded, and network performance may be impacted. In this situation, you can use the vrrp6 virtual-ip route-advertise disable command to disable a dynamic routing protocol from advertising such routes to the neighbors.

If you want to disable a specified dynamic routing protocol from advertising such routes, specify parameters as required:

  • If you specify isis, a device disables IS-IS from advertising routes destined for the virtual IP address of a VRRP6 group.
  • If you specify ospf, a device disables OSPF from advertising routes destined for the virtual IP address of a VRRP6 group.

Prerequisites

  • A virtual IP address has been configured for a VRRP6 group.
  • A dynamic routing protocol has imported routes destined for the virtual IP address of a VRRP6 group.

Precautions

Currently, this command is valid only for OSPF and IS-IS.

Example

# Disable IS-IS from advertising routes destined for the virtual IP address of a VRRP6 group.
<HUAWEI> system-view
[HUAWEI] vrrp6 virtual-ip route-advertise disable isis
