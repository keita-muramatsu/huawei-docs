web-redirection disable

Function

The web-redirection disable command disables Portal authentication redirection for IPv4 and IPv6 packets.

The undo web-redirection disable command enables Portal authentication redirection for IPv4 and IPv6 packets.

The web-redirection ipv6 disable command disables Portal authentication redirection for IPv6 packets.

The undo web-redirection ipv6 disable command enables Portal authentication redirection for IPv6 packets.

By default, the Portal authentication redirection function is enabled.

Format

web-redirection disable

web-redirection ipv6 disable

undo web-redirection disable

undo web-redirection ipv6 disable

Parameters

None

Views

Web-auth-server template view

Default Level

2: Configuration level

Usage Guidelines

The device redirects all unauthenticated users to the Portal authentication page when the users send HTTP access requests to external networks. However, in some special scenarios (for example, users need to manually enter the URL of the authentication page), you can run this command to disable the Portal authentication redirection function.

If only an IPv4 redirect URL is configured, you can disable Portal authentication redirection for IPv6 packets. Then Portal authentication redirection is not performed when terminals access the Internet using IPv6 addresses. This prevents Portal authentication failures in the following situation: A terminal using an IPv6 address for Internet access is redirected to an IPv4 URL and redirect packets carry the IPv6 address parameter. As a result, the Portal server does not obtain the IPv4 address of the terminal.

Example

# Disable Portal authentication redirection for IPv4 and IPv6 packets.
<HUAWEI> system-view
[HUAWEI] web-auth-server nac
[HUAWEI-web-auth-server-nac] web-redirection disable
