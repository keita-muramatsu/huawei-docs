observe-port (local observing port)

Function

The observe-port command configures a local observing port.

The undo observe-port command deletes a local observing port.

By default, no local observing port is configured.

Format

observe-port [ observe-port-index ] interface { interface-type interface-number | interface-name }

undo observe-port observe-port-index

Parameters

Parameter Description Value
observe-port-index

Specifies the index of the observing port.

The value must be 1.
interface interface-type interface-number

Specifies the type and number of the observing port.

  • interface-type specifies the type of the port.
  • interface-number specifies the number of the port.

The interface type can be Ethernet interface.
interface-name

Specifies an interface name.

The interface type can be Ethernet or Eth-Trunk interface.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When configuring local mirroring, you must specify the ports that are directly connected to monitoring devices as local observing ports.

If traffic of mirrored ports is copied to observing ports and exceeds the bandwidth of observing ports, congestion will occur or a large number of packets will be dropped, affecting the device forwarding performance. You can limit the rate at which interfaces send data to so that interfaces can send packets evenly.

Precautions

  • If the observe-port-index parameter is not specified when you configure an observing port, the index of the observing port is 1. Rate limiting configured on an observing port takes effect on all the mirrored traffic (including inbound and outbound mirrored traffic) received on the observing port.
  • To prevent service conflicts, it is recommended that no other services be configured on observing ports.
  • The services configured on an observing port take effect only for non-mirrored packets.
  • On the AR5710-H and AR6710-L, when the hardware-based forwarding mode is used, local port mirroring allows mirroring of only physical interfaces, Eth-Trunk interfaces, cellular interfaces, and dialer interfaces.

Example

# Configure 10GE0/0/1 as a local observing port and set the port index to 1.
<HUAWEI> system-view
[HUAWEI] observe-port 1 interface 10GE 0/0/1
