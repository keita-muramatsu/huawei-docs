display security-policy expired rule

Function

The display security-policy expired rule command displays security policy rules whose configured time range has expired permanently.

Format

display security-policy expired rule

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

The display security-policy expired rule command output is sorted from top to bottom based on the rule priority (except the default policy).

Example

The actual command output varies according to the device. The command output here is only an example.

# Display security policy rules that have expired permanently.
<HUAWEI> display security-policy expired rule
2023-07-21 09:41:28.764                                                                                                             
                                                                                                                                    
------------------------------------------------------------------------                                                            
RULE ID    RULE NAME            TIMERANGE            ACTION   HITS                                                                  
------------------------------------------------------------------------                                                            
2          test                 testsec              deny     0                                                                     
3          test2                testsec              -        0
Table 1 Description of the display security-policy expired rule command output
Item Description
RULE ID

Security policy rule ID.
RULE NAME

Name of a security policy rule.
TIMERANGE

Name of the referenced time range.
ACTION

Security policy action.
HITS

Security policy matching times.
