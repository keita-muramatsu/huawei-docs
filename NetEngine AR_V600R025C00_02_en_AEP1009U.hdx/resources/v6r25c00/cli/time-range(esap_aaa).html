time-range

Function

The time-range command sets the access time range for a local access user.

The undo time-range command deletes the access time range for a local access user.

By default, a local access user can access the network anytime.

Format

time-range time-name

undo time-range

Parameters

Parameter Description Value
time-name

Specifies the access time range of a local account. time-name specifies the name of the access time range.

The value is a string of 1 to 32 case-sensitive characters. It cannot contain spaces.

Views

aaa-access-user view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

After a local access user is created, the user account is always valid by default. You can run the time-range command to set the access time range for a local access account. After the configuration is complete, the account takes effect only within the access time range. This allows the administrator to control the time when users access network resources.

Prerequisites

The time range has been created using the time-range command.

Precautions

If you run the time-range and expire-date commands in the local user view multiple times, only the latest configuration takes effect. After the access time range of a local access user is changed, the access time range takes effect only when the user goes online again.

Example

# Set the access time range of the local access user hello@163.net to 9:00?18:00 from Monday to Friday. 
<HUAWEI> system-view
[HUAWEI] time-range huawei 9:00 to 18:00 working-day
[HUAWEI] aaa
[HUAWEI-aaa] local-access-user hello@163.net
[HUAWEI-aaa-access-user-hello@163.net] time-range huawei
