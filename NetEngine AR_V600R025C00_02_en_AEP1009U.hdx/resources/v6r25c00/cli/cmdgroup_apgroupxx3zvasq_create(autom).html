ap-group

Function

The ap-group command binds a WLAN to an AP group and creates the network-wide configuration for the binding relationship.

The undo ap-group command unbinds a WLAN from an AP group and deletes the network-wide configuration of the binding relationship.

By default, no WLAN is bound to an AP group.

Format

ap-group ap-group-paravalue

undo ap-group ap-group-paravalue

Parameters

Parameter Description Value
ap-group-paravalue

Specifies the name of an AP group.

The value is a string of 1 to 35 case-sensitive characters.

Views

Net-assistant wlan-ssid view

Default Level

3: Management level

Usage Guidelines

To create a WLAN, you can add APs to the same AP group and perform unified WLAN configuration in the AP group. This simplifies operations.

  • If the AP group does not exist, the command fails to be delivered.
  • If the AP group exists but has no member, this command can be configured successfully. The master device delivers the network-wide WLAN configuration to the WAC. After an AP is added to the AP group, the AP automatically obtains the WLAN configuration from the WAC.

Example

# Bind the WLAN huawei-wifi to the AP group default.
<HUAWEI> system-view
[HUAWEI] net-assistant
[HUAWEI-net-assistant] network
[HUAWEI-net-assistant-network] wlan-ssid huawei_wifi profile-name ssid123
[HUAWEI-net-assistant-network-wlan-ssid-huawei_wifi] ap-group default
