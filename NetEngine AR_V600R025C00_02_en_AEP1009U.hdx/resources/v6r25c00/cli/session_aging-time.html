session aging-time

Function

The session aging-time command sets the aging time interval for each entry in the session table.

The undo session aging-time command restores the default aging time interval of each entry in the session table.

The default aging time for sessions of different protocols is as follows:

TCP: 600s

UDP: 120s

ICMP: 20s

SAC cache: 7200s

DNS: 30s

HTTP: 120s

FTP: 120s

SIP: 1800s

RSTP: 60s

PPTP: 600s

Others: 120s

Format

session { { dns | ftp | http | icmp | tcp | udp | sip | rtsp | pptp | others | sac-cache } | { tcp | udp } user-define port-number } aging-time aging-time

undo session { all | { dns | ftp | http | icmp | tcp | udp | sip | rtsp | pptp | others | sac-cache } | { tcp | udp } user-define port-number } aging-time

Parameters

Parameter Description Value
dns

Sets the aging time interval of the DNS protocol.

-
ftp

Sets the aging time interval of the FTP control connection.

-
http

Sets the aging time interval of the HTTP connection.

-
icmp

Sets the aging time interval of the ICMP connection.

-
tcp

Sets the aging time interval of the TCP connection.

-
udp

Sets the aging time interval of the UDP connection.

-
sip

Sets the aging time interval of the SIP connection.

-
rtsp

Sets the aging time interval of the RTSP protocol.

-
pptp

Sets the aging time interval of the PPTP control connection.

-
others

Sets the aging time interval of others situation connection.

-
sac-cache

Aging time of the SAC identification result cache entries.

-
user-define port-number

Specifies the user-defined TCP or UDP port number and configures the aging time interval for all data connections with this port as the destination port. Give priority to user-defined port number aging time.

The value is an integer from 1 to 65535.
aging-time aging-time

Specifies the aging time interval value.

The value is an integer that ranges from 10 to 65535, in seconds.
all

Refers to the aging time of canceling all agreements.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

You can run the session aging-time command to set the session entry aging time or the cache entry aging time for different protocols or ports. If a session entry is not used within the specified aging time, the corresponding session becomes invalid. For example, the user with IP address 10.110.10.10 initiates a TCP connection through port 2000. If the TCP connection is not used within the aging time, the system deletes this connection.

Example

# Configure the aging time of SAC identification result cache entries.
<HUAWEI> system-view
[HUAWEI] session sac-cache aging-time 120
# Set the session aging time for all data connections with the user-defined UDP port as the destination port.
<HUAWEI> system-view
[HUAWEI] session udp user-define 1000 aging-time 60
# Set the session aging time of the DNS protocol.
<HUAWEI> system-view
[HUAWEI] session dns aging-time 60
