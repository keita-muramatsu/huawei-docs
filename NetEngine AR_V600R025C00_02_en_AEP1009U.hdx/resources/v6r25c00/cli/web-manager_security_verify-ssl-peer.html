web-manager security verify-ssl-peer

Function

The web-manager security verify-ssl-peer command enables bidirectional certificate authentication between the device and client.

The undo web-manager security verify-ssl-peer command disables bidirectional certificate authentication between the device and client.

By default, bidirectional certificate authentication is disabled.

Format

web-manager security verify-ssl-peer

undo web-manager security verify-ssl-peer

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Unidirectional certificate authentication is performed between the device and client. That is, the client authenticates the certificate of the device, but the device does not authenticate the certificate of the client.

After this command is executed, the client sends the client certificate to the device when the administrator logs in to the device through HTTPS. The device uses the CA certificate to verify the client certificate. The administrator login page is displayed only after the verification succeeds.

Before using this function, apply for a certificate, upload the obtained CA certificate to the device storage, and import the certificate to the memory for it to take effect. For details, see the pki import-certificate command. Import the obtained client certificate to the client browser.

In addition, you need to run the web-manager security ca-certificate command to configure the device to use the obtained CA certificate to verify the client certificate.

Example

# Enable bidirectional certificate authentication between the device and client.
<HUAWEI> system-view
[HUAWEI] web-manager security verify-ssl-peer
