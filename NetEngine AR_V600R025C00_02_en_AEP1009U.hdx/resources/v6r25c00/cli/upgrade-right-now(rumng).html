upgrade right-now

Function

The upgrade right-now command upgrades the firmware of a remote module immediately.

By default, the remote module firmware upgrade is disabled.

Format

upgrade right-now

Parameters

None

Views

remote-unit view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If the firmware version of an RU is different from that in the system software package or patch package of the central device, the central device does not automatically upgrade the firmware version of the RU. You can run the upgrade right-now command to upgrade the firmware of all RUs. After the upgrade right-now command is run, the system checks whether the firmware version of an RU is the same as that in the system software package or patch package of the central device. If not, the RU immediately loads the firmware package of the new version and restarts with new firmware.

Precautions

After the upgrade is successful, the connected RU restarts, interrupting services. Do not power off the RU during the upgrade. Otherwise, the RU may fail to start.

Example

# Enable firmware upgrade for a remote module.
<HUAWEI> system-view
[HUAWEI] remote-unit
[HUAWEI-remote-unit] upgrade right-now
Warning: After the upgrade is successful, the connected RUs will restart, causing service interruption. Do not power off the RUs during the upgrade. Otherwise, they may fail to start.
