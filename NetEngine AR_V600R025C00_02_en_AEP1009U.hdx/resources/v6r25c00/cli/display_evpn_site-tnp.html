display evpn site-tnp

Function

The display evpn site-tnp command displays SD-WAN EVPN site information.

Format

display evpn site-tnp { site-id [ tnp-id tnp-id ] | all }

Parameters

Parameter Description Value
site-id

Specifies a site ID.

The value is an integer from 1 to 65535.
tnp-id tnp-id

Specifies a TNP ID.

The value is an integer in the range from 1 to 4294967295.
all

Indicates all sites.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To check EVPN site information, run the display evpn site-tnp command. The command output helps improve maintainability.

Example

The actual command output varies according to the device. The command output here is only an example.
