display cpu-defend statistics

Function

The display cpu-defend statistics command displays statistics on packets sent to the CPU in wired mode.

Format

For AR8100 series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5700-H series, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR5710-S8TWDSE-LTE4EA, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S10T1X2:

display cpu-defend statistics [ packet-type packet-type ] all

display cpu-defend statistics [ packet-type packet-type ] slot slot-id

For AR8700 series, AR6700-H series:

display cpu-defend statistics [ packet-type packet-type ] mcu

Parameters

Parameter Description Value
packet-type packet-type

Displays statistics on the specified type of protocol packets. packet-type specifies the packet type.

  • If packet-type is specified, statistics on the specified type of protocol packets are displayed.
  • If packet-type is not specified, statistics on all protocol packets are displayed.

You can run the display cpu-defend configuration command to view the supported packet types and rate limits. The actual packet type is subject to the predictive query result.
all

Displays statistics about all slots.

NOTE:

This parameter is supported only on the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series and AR5710-S8P1XDSE-2LTE4EA.

-
slot slot-id

Specifies the ID of the device.

This parameter is supported only on the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series and AR5710-S8P1XDSE-2LTE4EA.

Displays the statistics of the MPU.

NOTE:

This parameter is supported only on the AR8700 series and AR6700-H series.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

The display cpu-defend statistics command displays statistics on packets sent to the CPU, including the number of forwarded and discarded packets. This helps the network administrator configure attack defense policies.

Precautions

When the ICMP fast reply function is enabled, statistics on ICMPv4 and ICMPv6 packets are not differentiated. The total number of ICMPv4 and ICMPv6 packets is recorded in the icmp field.
