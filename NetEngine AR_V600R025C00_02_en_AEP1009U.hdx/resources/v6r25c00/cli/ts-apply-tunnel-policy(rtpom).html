apply tunnel-policy

Function

The apply tunnel-policy command applies a tunnel policy to a tunnel selector.

The undo apply tunnel-policy command cancels the setting.

By default, no tunnel policy is configured for tunnel selector.

Format

apply tunnel-policy tunnel-policy-name

undo apply tunnel-policy

Parameters

Parameter Description Value
tunnel-policy-name

Name of the tunnel policy applied to the route.

The value is a string of 1 to 39 case-sensitive characters, spaces not supported.

Views

Tunnel-selector view

Default Level

2: Configuration level

Usage Guidelines

In L3VPN networking, VPNv4 routes and labeled BGP routes are transmitted over LSPs by default, and load balancing is not performed. To apply a tunnel policy to VPNv4 routes to select other types of tunnels or perform load balancing among tunnels, run this command. For example:

In inter-AS VPN Option B networking, an ASBR needs to apply a tunnel policy to VPNv4 routes learned from PEs.

On the VPN backbone network, an RR needs to apply a tunnel policy to the VPNv4 routes learned from PEs.

In inter-AS VPN Option C networking, a PE needs to apply a tunnel policy to received labeled BGP routes.

Example

# In the tunnel-selector view, apply policy 1 to the VPN routes that are filtered by the RD.
<HUAWEI> system-view
[HUAWEI] tunnel-policy policy1
[HUAWEI-tunnel-policy-policy1] tunnel select-seq ldp load-balance-number 2
[HUAWEI-tunnel-policy-policy1] quit
[HUAWEI] tunnel-selector tps permit node 10
[HUAWEI-tunnel-selector] apply tunnel-policy policy1
