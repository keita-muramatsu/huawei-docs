log-server

Function

The log-server command configures the log server IP address and port number in the AP system profile and enables log backup on the AP.

The undo log-server command restores the default log server IP address and port number in the AP system profile and disables log backup on the AP.

By default, the port number of the log server is 514, the log server IP address is not configured in an AP system profile, and log backup is disabled on an AP.

Format

log-server ip-address ip-address-value [ port port-value ]

log-server ipv6-address ipv6-address-value [ port port-value ]

undo log-server

Parameters

Parameter Description Value
port port-value

Specifies the port number of the log server.

The value is an integer in the range from 1 to 65535. The default port number is 514.
ipv6-address ipv6-address-value

Specifies the IPv6 address of the log server.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
ip-address ip-address-value

Specifies the IPv4 address of the log server.

The value is in dotted decimal notation.

Views

AP system profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

You can run this command to specify the IP address and port number of the log server in the AP system profile and enable log backup on the AP. After log backup is enabled, the AP automatically sends logs to the log server with the specified IP address.

Precautions

Modifying the attributes of an AP system profile changes configurations of all APs using this profile.

Example

# Set the IP address of the log server to 192.168.1.1 and port number to 2000, and enable log backup on the AP.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name ap-system1
[HUAWEI-wlan-ap-system-prof-ap-system1] log-server ip-address 192.168.1.1 port 2000
