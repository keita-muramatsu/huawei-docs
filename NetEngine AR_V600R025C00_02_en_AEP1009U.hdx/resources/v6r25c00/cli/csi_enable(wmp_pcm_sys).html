csi enable

Function

The csi enable command enables the CSI sensing function for APs in the AP system profile view.

The undo csi enable command disables the CSI sensing function for APs in the AP system profile view.

By default, the CSI sensing function is disabled for APs in the AP system profile view.

Format

csi enable

undo csi enable

Parameters

None

Views

AP system profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

CSI in Wi-Fi signals can reflect the motion status of objects in the space environment. When the locations of the Wi-Fi signal transmitter and receiver remain unchanged, the CSI is stable if there is no moving object in the space environment. When a person is moving, the CSI varies greatly with the signal reflection caused by the person's movement. Based on these characteristics, after this command is executed to enable the CSI sensing function for APs at a single site, the APs automatically send and receive Wi-Fi signals, and collects CSI data to sense and identify nearby people. After the data is uploaded to iMaster NCE-CampusInsight, the results of sensing and identifying human presence can be displayed on physical and digital maps, facilitating power control and energy saving. After iMaster NCE-CampusInsight is connected to a third-party building management system, more functions can be implemented, such as intelligent shutdown of electrical appliances and intrusion detection.

Precautions

  • To enable iMaster NCE-CampusInsight to obtain the results of human sensing and identification, you need to configure the WMI function so that APs can connect to iMaster NCE-CampusInsight, and run the collect-item csi-data enable command in the WMI profile view to enable the CSI data reporting function.

    For APs configured with the CSI sensing function, do not configure an energy-saving policy on iMaster NCE-Campus or iMaster NCE-CampusInsight. This is because executing the energy-saving policy will disable AP radios, causing the CSI sensing function to be unavailable.
  • If the CSI sensing function is configured for a specified AP using the csi { enable | disable } command in the AP view, the priority of the configuration in the AP view is higher than that of the csi enable command configuration in the AP system profile view.

Example

# Enable the CSI sensing function for APs in the AP system profile view.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name test
[HUAWEI-wlan-ap-system-prof-test] csi enable
