ppp ipcp dns

Function

The ppp ipcp dns command enables the device to provide the DNS server address for the peer.

The undo ppp ipcp dns command disables the device from providing the DNS server address for the peer.

By default, a device does not provide any DNS server address for the peer end.

Format

ppp ipcp dns { primary-dns-address [ secondary-dns-address ] | admit-any }

undo ppp ipcp dns { primary-dns-address [ secondary-dns-address ] | admit-any }

Parameters

Parameter Description Value
primary-dns-address

Specifies the IP address of the primary DNS server.

The value is in dotted decimal notation.
secondary-dns-address

Specifies the IP address of the secondary DNS server.

The value is in dotted decimal notation.
admit-any

Accepts any DNS address proposed by the peer.

-

Views

Dialer interface view, MP-group interface view, POS interface view, Serial interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

PPP link establishment involves multiple negotiation processes, including LCP negotiation and NCP negotiation. NCP negotiation supports IPCP, MPLSCP, and OSICP negotiation. During IPCP negotiation, the two devices negotiate IP addresses for their connected interfaces.

When a local device is connected to a peer device using PPP, the local device can assign a DNS server address to the peer device through negotiation. In this way, the peer device can directly access the network based on the specified domain name. You can also configure the device to accept any DNS server address from the peer end.

Prerequisites

PPP is configured as the link layer protocol of the interface.

Configuration Impact

If this command is run more than once, the latest configuration overrides the previous one. After the configuration, the new address is used for negotiation.

Precautions

After the configuration is complete, run the shutdown and undo shutdown commands in sequence in the corresponding interface view to restart the interface for the configuration to take effect.

Example

# Set the primary and secondary DNS server IP addresses to 10.1.1.1 and 10.1.1.2 on Dialer95, respectively.
<HUAWEI> system-view
[HUAWEI] interface Dialer 95
[HUAWEI-Dialer95] ppp ipcp dns 10.1.1.1 10.1.1.2
