iot-card iot-command

Function

The iot-card iot-command command transparently transmits a command to an IoT card for execution.

Format

iot-card { ap ap-id ap-id | ap-group ap-group-name } card { card-number | usb | ble } iot-command command

Parameters

Parameter Description Value
ap ap-id ap-id

Specifies an AP ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
ap-group ap-group-name

Specifies an AP group.

The AP group must exist.
card card-number

Specifies the ID of a card.

The value is an integer in the range of 1 to 3.
usb

Specifies an IoT card of the USB type.

-
ble

Specifies the built-in Bluetooth module.

-
command

Specifies the command to be transparently transmitted to the card.

The value is a string of 1 to 252 characters. It can contain spaces.

Views

WLAN view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

IoT cards support command execution. You can run this command to transparently transmit a command to be executed on an IoT card.

Prerequisites

You have obtained the commands that can be executed on IoT cards from the card vendor. If a command is not supported by an IoT card, this command may fail to be executed or the card may malfunction.

Example

# Transparently transmit a command to an IoT card in a specified AP group. (The following uses the IoT command exampleabc as an example. For specific commands, contact the IoT card vendor.)
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] iot-card ap-group default card  1 iot-command exampleabc
Warning: For IoT card commands, contact the card vendor. An incorrect command may fail to be executed or lead to a card function exception. Continue?
Info: Command commit completely. Success count: 3. Failure count: 0.
# Transparently transmit a command to an IoT card on a specified AP. (The following uses the IoT command exampleabc as an example. For specific commands, contact the IoT card vendor.)
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] iot-card ap ap-id 0 card 1 iot-command exampleabc
Warning: For IoT card commands, contact the card vendor. An incorrect command may fail to be executed or lead to a card function exception. Continue?
