server-detect

Function

The server-detect command enables the Portal server detection function.

The undo server-detect command disables the Portal server detection function.

By default, the Portal server detection function is disabled.

Format

server-detect [ interval interval-period | max-times times | critical-num critical-num | action { log | trap } * ] *

undo server-detect [ interval | max-times | critical-num | action { log | trap } * ]

Parameters

Parameter Description Value
interval interval-period

Specifies the detection interval of the Portal server.

The value is an integer ranging from 30 to 65535, in seconds. The default value is 60.
max-times times

Specifies the maximum number of detection failures of the Portal server.

The value is an integer that ranges from 1 to 255. The default value is 3.
critical-num critical-num

Specifies the minimum number of Portal servers in Up state.

The value is an integer that ranges from 0 to 32. The default value is 0.
action

Specifies the action taken when the number of detection failures of the Portal server exceeds the maximum.

-
log

Indicates that a log is sent when the number of detection failures of the Portal server exceeds the maximum.

-
trap

Indicates that an alarm is sent when the number of detection failures of the Portal server exceeds the maximum.

-

Views

Web-auth-server template view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In Portal application, if the communication is interrupted because a fault occurs on the network between the device and Portal server or a fault occurs on the Portal server, new Portal authentication users cannot go online. This brings great inconvenience to users.

After the Portal server detection function is enabled in the Portal server template, the device detects all the Portal servers configured in the Portal server template. If the number of times that the device fails to detect a Portal server exceeds the maximum value, the device changes the status of the Portal server from up to down. If the number of Portal servers in up state is less than or equal to the minimum value (specified by critical-num), the device performs the corresponding operation to allow the administrator to obtain the real-time Portal server status or ensure that users have certain network access rights.

Note:

The detection interval of the Portal server multiplied by the maximum number of detection failures must be not less than the keepalive heartbeat interval of the Portal server. It is recommended that the configured detection interval of the Portal server be greater than the keepalive heartbeat interval of the Portal server.

If the Portal server does not support detection, you do not need to configure this function.

You are advised to use the default value 0 of critical-num.

•If the number of Portal servers in up state is less than or equal to the minimum value (specified by critical-num), the Status field in the display portal-server state command output displays Abnormal. If the bypass function is configured, the bypass behavior is performed.

•If the number of Portal servers in up state is greater than the minimum value (specified by critical-num), the Status field in the display portal-server state command output displays normal.

•If there is only one Portal server and critical-num is set to 1, the number of Portal servers in up state is not greater than the minimum value 1 when the server status changes from down to up. In this case, the Status field in the display portal-server state command output still displays Abnormal. To restore the normal state, you need to set critical-num to the default value 0.

Precautions

The detection function is not supported for the Portal server that has the HACA protocol configured.

Example

# Enable the Portal server detection function in the Portal server template abc, and set the detection interval to 100 seconds, maximum number of detection failures to 5, and configure the device to send a log when the number of detection failures exceeds 5.
<HUAWEI> system-view
[HUAWEI] web-auth-server abc
[HUAWEI-web-auth-server-abc] server-detect interval 100 max-times 5 action log
