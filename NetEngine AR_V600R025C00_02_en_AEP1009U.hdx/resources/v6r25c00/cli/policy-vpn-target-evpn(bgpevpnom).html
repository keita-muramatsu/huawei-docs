policy vpn-target (BGP-EVPN address family view)

Function

The policy vpn-target command enables VPN target-based filtering for received VPN routes.

The undo policy vpn-target command cancels VPN target-based filtering for VPN routes. That is, all VPN routes are received.

By default, VPN target-based filtering is enabled for VPN routes.

Format

policy vpn-target

undo policy vpn-target

Parameters

None

Views

BGP-EVPN address family view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

By default, a device checks whether the export RTs of VPN routes match the import RTs of the local VPN instance. This means that a VPN instance must exist on the device.

  • Generally, VPN instances have been configured on PEs and do not need to be configured again.
  • In inter-AS VPN Option B/Option C scenarios, VPN instances are usually not configured on RRs or ASBRs. In this case, you can run the undo policy vpn-target command to disable the device from checking whether the export RTs of VPN routes match the import RTs of the local VPN instance. Alternatively, you can configure a VPN instance on the device and ensure that the import RTs of the VPN instance match the export RTs of the received VPN routes, so that the device does not discard these VPN routes.

After the undo policy vpn-target command is run, the device does not compare whether the export RT of a VPN route matches the import RT of the local VPN instance.

Configuration Impact

After the policy vpn-target command is run on a device, the device accepts a VPN route if an ERT carried in the VPN route matches the IRT of the local VPN instance, and then adds the VPN route to the VPN routing tables of the VPN instances of which the IRT matches the ERT of the VPN route.

Precautions

One of the following commands needs to be run in EVPN L3VPN scenarios:

  • segment-routing ipv6 traffic-engineer evpn, segment-routing ipv6 best-effort evpn (BGP-VPN instance address family view)
  • vn-id (VPN instance view)

Running the undo policy vpn-target command cancels VPN target-based filtering for VPN routes, which may cause the device to accept a large number of routes. Exercise caution when running this command.

If no VPN instance is configured on an RR or ASBR, run the undo policy vpn-target command to cancel VPN target-based filtering for received VPN routes. This prevents VPN routes from being discarded when no matching import RTs exist.

Example

# Configure a device to implement VPN target-based filtering for received EVPN routes. 
<HUAWEI> system-view
[HUAWEI] bgp 100
[HUAWEI-bgp] peer 10.1.1.9 as-number 100
[HUAWEI-bgp] l2vpn-family evpn
[HUAWEI-bgp-af-evpn] peer 10.1.1.9 enable
[HUAWEI-bgp-af-evpn] policy vpn-target
