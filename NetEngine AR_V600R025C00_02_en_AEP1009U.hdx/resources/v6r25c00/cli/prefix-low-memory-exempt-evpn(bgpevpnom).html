prefix low-memory exempt

Function

The prefix low-memory exempt command enables rejection exemption for key routes.

The undo prefix low-memory exempt command disables rejection exemption for key routes.

By default, rejection exemption is disabled for key routes.

Format

prefix low-memory exempt ip-prefix prefix-filter-name

prefix low-memory exempt ipv6-prefix prefix6-filter-name

undo prefix low-memory exempt ip-prefix prefix-filter-name

undo prefix low-memory exempt ipv6-prefix prefix6-filter-name

Parameters

Parameter Description Value
ipv6-prefix prefix6-filter-name

Specifies the name of an IPv6 prefix filter.

The name is a string of 1 to 169 case-sensitive characters, with spaces not supported. When double quotation marks are used around the string, spaces are allowed in the string.
ip-prefix prefix-filter-name

Specifies the name of an IP prefix filter.

The name is a string of 1 to 169 case-sensitive characters, with spaces not supported. When double quotation marks are used around the string, spaces are allowed in the string.

Views

BGP-EVPN address family view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When the memory of the device is in the danger state, BGP rejects new routes. To prevent impact on key services, run the prefix low-memory exempt command to configure a route filtering policy based on an IP prefix list or IPv6 prefix list to exempt rejected routes.

Precautions

To restore rejected routes after the prefix low-memory exempt command is run, run the refresh bgp command.

Example

# Enable rejection exemption for key routes. 
<HUAWEI> system-view
[HUAWEI] ip ip-prefix aa permit 1.1.1.1 32
[HUAWEI] bgp 100
[HUAWEI-bgp] l2vpn-family evpn
[HUAWEI-bgp-af-evpn] prefix low-memory exempt ip-prefix aa
# Enable rejection exemption for IPv6 key routes. 
<HUAWEI> system-view
[HUAWEI] ip ipv6-prefix bb permit 2001:DB8:1::1 128
[HUAWEI] bgp 100
[HUAWEI-bgp] l2vpn-family evpn
[HUAWEI-bgp-af-evpn] prefix low-memory exempt ipv6-prefix bb
