display ap port

Function

The display ap port command displays the port status and traffic information of APs.

Format

display ap port { all | ap-id ap-id | ap-mac ap-mac }

Parameters

Parameter Description Value
all

Displays the port status and traffic information of all APs.

-
ap-id ap-id

Displays running status of the AP with a specified ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
ap-mac ap-mac

Displays the port status and traffic statistics of the AP with a specified MAC address.

The AP's MAC address must exist.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run this command to check the port status and traffic information of online APs, which facilitates AP port maintenance and management.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the port status and traffic information of all APs.
<HUAWEI> display ap port all
-----------------------------------------------------------------------------------------------------------------------------------
AP-ID Port   Trunk ID    State Mode Speed Duplex TX-Packets       Tx-ErrorPackets  TX-Rate(Kbps) RX-Packets       RX-DropPackets   RX-Rate(Kbps)
-----------------------------------------------------------------------------------------------------------------------------------
0     GE0    0(active)   up    root 1000  full   9178             0                0             12857            0                1
......
-----------------------------------------------------------------------------------------------------------------------------------
Printed: 1
Table 1 Description of the display ap port command output
Item Description
AP-ID

AP ID.
Port

AP port.
Trunk ID

Whether the Eth-Trunk function is configured on the AC and whether the AP port is added to an Eth-Trunk.

  • The field outside the brackets indicates the configuration on the AC.
    • 0: The AC is configured to add AP ports to Eth-Trunk 0.
    • -: The AC is not configured to add AP ports to an Eth-Trunk.
  • The field in parentheses indicates the effective configuration on the AP.
    • -: The AP port does not support the Eth-Trunk function.
    • active: The AP interface has been added to an Eth-Trunk.
    • inactive: The AP interface is not added to an Eth-Trunk.

The entire field is described as follows:

  • 0(active): The AC is configured to add AP port to Eth-Trunk 0, and this configuration is in effect.
  • 0(inactive): The AC is configured to add AP ports to Eth-Trunk 0, but this configuration takes effect only after a restart. The current AP port is not in an Eth-Trunk.
  • 0(-): The AC is configured to add AP ports to Eth-Trunk 0, but the current AP port does not support the Eth-Trunk function.
  • -(-): The AC is not configured to add AP ports to an Eth-Trunk, and the current AP port does not support the Eth-Trunk function.
  • -(active): The AC is configured to remove AP ports from an Eth-Trunk, but this configuration takes effect only after a restart. The current AP port is still in an Eth-Trunk.
  • -(inactive): The AC is configured to remove AP ports from an Eth-Trunk, and this configuration is in effect.
State

Status of an AP port.

  • down: The interface is shut down.
  • up: The interface is enabled.
Mode

Actual working mode of an AP's wired interface.

  • root: root mode.
  • middle: middle mode.
  • endpoint: endpoint mode.
Speed

Rate of the AP port, in Mbit/s.
Duplex

Duplex type of an AP interface, including half duplex and full duplex.
TX-Packets

Number of data frames sent by an AP port.
Tx-ErrorPackets

Number of error data frames sent by an AP interface.
TX-Rate(Kbps)

Uplink rate of an AP port.
RX-Packets

Number of data frames received by an AP port.
RX-DropPackets

Number of data frames discarded in the received data frames on the AP interface.
RX-Rate(Kbps)

Downlink rate of an AP port.
Printed

Number of displayed records.
