nat full-cone global alarm ip-pool port-number threshold trap

Function

The nat full-cone global alarm ip-pool port-number threshold trap enable command enables the log and alarm function for the port usage of an address pool.

The undo nat full-cone global alarm ip-pool port-number threshold trap enable command disables the log and alarm function for the port usage of an address pool.

By default, the log and alarm functions for the port usage of an address pool are enabled.

Format

nat full-cone global alarm ip-pool port-number threshold trap enable

undo nat full-cone global alarm ip-pool port-number threshold trap enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

In a 3-tuple NAT scenario, you can enable the log and alarm functions for the port usage in an address pool. When the total port usage of the 3-tuple address pool reaches the configured threshold, the device sends an alarm to the NMS and sends a log to the log server. When the total port usage of the 3-tuple address pool falls below 7/8 of the configured threshold, the device sends a clear alarm to the NMS and sends a recovery log to the log server.

For example, assume that the default minimal and maximal ports that can be allocated to each IP address in the address pool are 2048 and 65535, respectively. Then, the number of ports that can be allocated to each IP address is (65535 - 2048 + 1) = 63488. If there are 10 IP addresses in the address pool, the total number of allocatable ports is 634880 (63488 x 10). When the number of used ports in the address pool reaches 634880 x threshold-value, the device sends the alarm FULLCONE_1.3.6.1.4.1.2011.6.122.48.2.1 hwSecFullConeIpPoolPortUsageOverThreshold to the NMS, and sends the log FULLCONE/3/CPUIPPOOLPORTUSAGETRAP to the log server. When the port usage of the 3-tuple address pool falls below 7/8 of the threshold, that is, when the number of used ports in the address pool reaches 634880 x (threshold-value x 7/8), the device sends the clear alarm FULLCONE_1.3.6.1.4.1.2011.6.122.48.2.3 hwSecFullConeIpPoolPortUsageLessThreshold to the NMS, and sends the recovery log FULLCONE/3/CPUIPPOOLPORTUSAGENORMALTRAP to the log server.

To set threshold-value, run the nat full-cone global alarm ip-pool port-number threshold command.

Example

# Enable the port usage alarm sending function for the address pool.
<HUAWEI> system-view
[HUAWEI] nat full-cone global alarm ip-pool port-number threshold trap enable
