sd-wan enable

Function

The sd-wan enable command enables SD-WAN for MVPN.

The undo sd-wan enable command disables SD-WAN for MVPN.

By default, SD-WAN is enabled for MVPN.

Format

sd-wan enable

undo sd-wan enable

Parameters

None

Views

VPN instance IPv4 address family MVPN view

Default Level

2: Configuration level

Usage Guidelines

SD-WAN supports multi-tenant, flexible networking and replication, centralized and simplified management, and flexible scheduling of multiple access modes. On an NG MVPN network, the underlay network reuses unicast SD-WAN. To enable multicast SD-WAN, run the sd-wan enable command.

Example

# Enable the multicast SD-WAN function.
<HUAWEI> system-view
[HUAWEI] multicast mvpn 1.1.1.1
[HUAWEI] ip vpn-instance mcast1
[HUAWEI-vpn-instance-mcast1] ipv4-family
[HUAWEI-vpn-instance-mcast1-af-ipv4] route-distinguisher 1:1
[HUAWEI-vpn-instance-mcast1-af-ipv4] multicast routing-enable
[HUAWEI-vpn-instance-mcast1-af-ipv4] mvpn
[HUAWEI-vpn-instance-mcast1-af-ipv4-mvpn] sd-wan enable
