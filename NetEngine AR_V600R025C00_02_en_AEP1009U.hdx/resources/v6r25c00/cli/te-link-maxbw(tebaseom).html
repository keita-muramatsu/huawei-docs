te bandwidth max-reservable-bandwidth

Function

The te bandwidth max-reservable-bandwidth command sets or modifies the maximum reservable bandwidth of a link.

The undo te bandwidth max-reservable-bandwidth command restores the default setting.

By default, the maximum reservable bandwidth is not set.

Format

te bandwidth max-reservable-bandwidth max-bw-value

undo te bandwidth max-reservable-bandwidth

undo te bandwidth max-reservable-bandwidth { max-bw-value | dynamic max-dynamic-bw-value }

Parameters

Parameter Description Value
max-bw-value

Specifies the bandwidth.

The value is an integer, in kbit/s. The value range varies according to the interface type.
dynamic max-dynamic-bw-value

Specifies the ratio of the maximum reservable bandwidth to the actual physical bandwidth of a specified link (%). When multiple tunnels are connected to the same interface and not all tunnels transmit traffic, the maximum reservable bandwidth configured on the link can be greater than the actual physical bandwidth. Such configuration ensures that all tunnels can pass through the link interface.

The value is an integer ranging from 1 to 1000, in percentage.

Views

10GE sub-interface view, 10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE sub-interface view, 40GE interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, Ethernet sub-interface view, Ethernet interface view, GE optical interface view, GE sub-interface view, GE electrical interface view, MP-group interface view, Tunnel interface view

Default Level

2: Configuration level

Usage Guidelines

In real-world situations, the command needs to be run only on the outbound interface of a link through which a TE tunnel passes.

The relationship among the CT0 bandwidth of a TE tunnel, interface BC0 bandwidth, and the maximum reservable bandwidth is as follows:

The CT0 bandwidth is less than or equal to BC0, and the BC0 bandwidth is less than or equal to the maximum reservable bandwidth.

Example

# Set the maximum reservable bandwidth to 10000 kbit/s.
<HUAWEI> system-view
[HUAWEI] te attribute enable
[HUAWEI] interface 10GE 0/0/0
[HUAWEI-10GE0/0/0] te bandwidth max-reservable-bandwidth 10000
