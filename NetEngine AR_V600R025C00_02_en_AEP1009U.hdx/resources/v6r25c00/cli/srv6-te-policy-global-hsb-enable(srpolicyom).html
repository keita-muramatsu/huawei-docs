srv6-te-policy backup hot-standby enable

Function

The srv6-te-policy backup hot-standby enable command enables HSB for all SRv6 TE Policies.

The undo srv6-te-policy backup hot-standby enable command disables HSB for all SRv6 TE Policies.

By default, HSB is disabled for all SRv6 TE Policies.

Format

srv6-te-policy backup hot-standby enable

undo srv6-te-policy backup hot-standby enable

Parameters

None

Views

Segment routing IPv6 view

Default Level

2: Configuration level

Usage Guidelines

SRv6 TE Policies are used to guide traffic over an SRv6 TE network. To improve SRv6 TE Policy reliability, you can run the srv6-te-policy backup hot-standby enable command to enable the HSB function for all SRv6 TE Policies.

If both the srv6-te-policy backup hot-standby enable (Segment Routing IPv6 view) and backup hot-standby enable (SRv6 TE Policy view) commands are run for an SRv6 TE Policy and the template referenced by the primary path of the policy contains HSB configurations, the backup hot-standby enable (SRv6 TE Policy view) command configuration has the highest priority, followed by the backup hot-standby enable (SR Policy template view) command configuration. The srv6-te-policy backup hot-standby enable (Segment Routing IPv6 view) command configuration has the lowest priority.

Example

# Enable HSB for all SRv6 TE Policies.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] srv6-te-policy backup hot-standby enable
