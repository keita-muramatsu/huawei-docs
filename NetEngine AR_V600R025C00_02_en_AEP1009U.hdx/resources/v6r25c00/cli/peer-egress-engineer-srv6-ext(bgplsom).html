peer egress-engineering srv6 static-sid

Function

The peer egress-engineering srv6 static-sid command configures a static End.X SID.

The undo peer egress-engineering srv6 static-sid command restores the default configuration.

By default, no static End.X SID is configured.

Format

peer peerIpv6Addr egress-engineering srv6 static-sid psp-usp-usd sid-value

undo peer peerIpv6Addr egress-engineering srv6 static-sid psp-usp-usd sid-value

Parameters

Parameter Description Value
peerIpv6Addr

Specifies the IPv6 address of a peer.

The value is a 32-digit hexadecimal string in format X:X:X:X:X:X:X:X.
psp-usp-usd

Specifies the PSP, USP, and USD flags.

-
sid-value

Specifies a static End.X SID.

The value is a 32-digit hexadecimal number in the format of X:X:X:X:X:X:X:X. The value range is the static SID range of the locator in the segment-routing ipv6 egress-engineering locator configuration.

Views

BGP view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

BGP EPE is an extension of BGP for segment routing and is used to implement source routing between ASs.

BGP EPE allocates BGP peer SIDs to inter-AS paths. The peer SIDs can be transmitted to the network controller through BGP LS extension. The controller orchestrates IGP SIDs and BGP peer SIDs to implement inter-AS forwarding over the optimal path.

After the peer egress-engineering srv6 static-sid command is run, the local device can specify a static End.X SID for the peer.

Prerequisites

The peer egress-engineering srv6 inherit-global-locator command must have been configured to inherit the global locator configuration.

Precautions

BGP EPE takes effect only after BGP-LS is enabled using the link-state-family unicast command and SRv6 is enabled using the segment-routing ipv6 command.

If a locator is configured on a peer, the locator configured on the peer is preferred. Otherwise, the global locator is used.

A locator and a static SID cannot be both configured on a peer. If they are both configured on a peer, the latest configuration overrides the previous one. A static SID uses a globally referenced locator, and the SID value must be globally unique.

Example

# Enable BGP EPE and configure static End.X SID (PSP, USP, USD).
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] locator c2 ipv6-prefix 2001:DB8:1:: 64 static 32
[HUAWEI-segment-routing-ipv6-locator] quit
[HUAWEI-segment-routing-ipv6] quit
[HUAWEI] bgp 100
[HUAWEI-bgp] segment-routing ipv6 egress-engineering locator c2
[HUAWEI-bgp] peer 2001:DB8:2::2 as-number 200
[HUAWEI-bgp] peer 2001:DB8:2::2 egress-engineering srv6 inherit-global-locator
[HUAWEI-bgp] peer 2001:DB8:2::2 egress-engineering srv6 static-sid psp-usp-usd 2001:DB8:1::1
