dns server bind local-ip ipv6

Function

The dns server bind local-ip ipv6 command configures a local IPv6 address and a VPN instance to be bound to a DNSv6 relay for communicating with a DNSv6 client.

By default, no local IPv6 address and VPN instance to be bound to a DNSv6 relay for communicating with a DNSv6 client are configured.

Format

dns server bind local-ip ipv6 ipv6-address [ vpn-instance vpn-instance-name ]

undo dns server bind local-ip ipv6 [ ipv6-address [ vpn-instance vpn-instance-name ] ]

Parameters

Parameter Description Value
ipv6-address

Specifies a local IPv6 address to be bound to a DNSv6 relay.

The value consists of 128 octets, which are classified into 8 groups. Each group contains 4 hexadecimal numbers in the format X:X:X:X:X:X:X:X.
vpn-instance vpn-instance-name

Specifies the name of a VPN instance to be bound to a DNSv6 relay.

The value is a string of 1 to 31 case-sensitive characters, spaces not supported. The VPN instance name cannot be _public_. If the character string is quoted by double quotation marks, the character string can contain spaces.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If no local IPv6 address is bound to a DNSv6 relay, security risks may exist. After the command is run to configure a local IPv6 address to be bound to a DNSv6 relay, the DNSv6 relay processes only the DNSv6 request packets received from the configured local IPv6 address. A maximum of 10 commands can be configured.

Precautions

This command takes effect immediately after being locally configured. Pay attention to the following points:

  • If no IPv6 address is configured, the client processes all IPv6 DNS request packets.
  • Ensure that the configured IPv6 address is the address of the local device (that is, this address is the address of a physical interface or logical interface on the device).
  • Ensure that the VPN specified for the configured IPv6 address is the VPN of the interface with the configured IPv6 address. If no VPN is specified, the configured IPv6 address belongs to the public network by default.

Example

# Configure a local IPv6 address to be bound to a DNSv6 relay.
<HUAWEI> system-view
[HUAWEI] dns server bind local-ip ipv6 2001:db8:1::1
