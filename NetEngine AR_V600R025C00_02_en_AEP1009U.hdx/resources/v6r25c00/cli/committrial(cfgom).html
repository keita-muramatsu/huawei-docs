commit trial (All views except the user view)

Function

The commit trial command enters the configuration trial run mode.

Format

commit [ trial [ time ] [ label label ] ] [ persist persistId ] [ description description ]

Parameters

Parameter Description Value
time

Specifies the timeout period for the trial running of a configuration.

The value is an integer ranging from 60 to 65535, in seconds. The default value is 600 seconds.
label label

Specifies a user label for a configuration rollback point.

The value is a string of 1 to 256 case-sensitive characters. It can be any visible ASCII character except for the space. However, the string can contain spaces if it is enclosed with double quotation marks (" "). The string cannot start with a digit or be a hyphen (-).
persist persistId

Specifies a persistence ID for a configuration trial run.

The value is a string of 1 to 256 case-sensitive characters. It can be any visible ASCII characters excluding spaces. If double quotation marks are used around the tag name, spaces are allowed in the tag name.
description description

Specifies information about a configuration rollback point.

The value is a string of 1 to 60 case-sensitive ASCII characters, spaces supported.

Views

All views

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If you are not sure about the configuration impact or want to observe the configuration effect, run the commit trial command to enter the configuration trial run mode. In this mode, users can perform trial run on new functions and services to ensure that the operation achieves the expected effect. After confirming that the configurations are correct, you can commit the configurations in trial run mode to ensure the security of operations on the live network and improve network reliability.

  • In configuration trial run mode, you can run the commit command to commit configurations for the configurations to take effect.
  • In configuration trial run mode, you can run the commit trial command again to refresh the trial run time.
  • If the trial running period of a configuration exceeds the specified timeout period, the system automatically rolls back the configuration to the state before the trial running. To make the configuration take effect, you need to enter the configuration trial run mode again, deliver the configuration again, and commit the configuration.
  • If the persist parameter is specified to enter the trial run mode, you can run the commit persist command in any session to commit the configuration in the trial run mode. If the persist parameter is not specified, you can run the commit command only in the current session to commit the configurations in the configuration trial run state.

Precautions

  • After you run the commit trial command to enter the configuration trial run mode, only the current user can modify the configuration during the trial run.
  • The trial running state does not terminate when the session ends. If the persist parameter is specified, you can run the abort trial persist command in a new session to terminate the session after re-login. If the persist parameter is not specified, you can log in again and run the abort trial session command in the new session to terminate the session.
  • During the configuration trial run, you can perform operations that do not cause system configuration changes, such as common query, maintenance, buildrun query, and manual configuration saving (automatic configuration saving is skipped during the trial run). If these operations cause configuration changes, the device will report a message indicating that the system is busy.
  • During the configuration trial run, you are not advised to perform operations that may trigger internal configurations, such as board insertion, board replacement, and patch installation. If a new board is installed during this period, the new board cannot complete the registration process.

Example

# Enter the configuration trial run mode.
<HUAWEI> system-view
[HUAWEI] commit trial
# Enter the configuration trial run mode and set the trial run timeout period to 120 seconds.
<HUAWEI> system-view
[HUAWEI] commit trial 120
# Enter the persistent configuration trial run mode.
<HUAWEI> system-view
[HUAWEI] commit trial persist abcd
# Commit the configurations delivered in the configuration trial run mode.
<HUAWEI> system-view
[HUAWEI] commit trial
Info: The system enters the trial configuration mode.
The system will revert to previous configuration if the trial configuration is not confirmed in 600 seconds.
[HUAWEI] sysname Device
[Device] commit         //in trial run mode
Warning: The trial configuration will be confirmed. Continue? [Y/N]:y
# Commit the configurations delivered in the persistent configuration trial run mode.
<HUAWEI> system-view
[HUAWEI] commit trial persist abcd
Info: The system enters the trial configuration mode.
The system will revert to previous configuration if the trial configuration is not confirmed in 600 seconds.
[HUAWEI] sysname Device
[Device] commit persist abcd
Warning: The trial configuration will be confirmed. Continue? [Y/N]:y
# Enter the configuration trial run mode and generate a configuration rollback point with a label.
<HUAWEI> system-view
[HUAWEI] commit trial label abc
# Enter the configuration trial run mode and generate a configuration rollback point that has a label with description.
<HUAWEI> system-view
[HUAWEI] commit trial label abc description abc
Table 1 Description of the commit trial (All views except the user view) command output
Item Description
Info

Prompt indicating that the device enters the configuration trial run mode.
Warning

Prompt asking the user to confirm the configurations in the configuration trial run mode.
