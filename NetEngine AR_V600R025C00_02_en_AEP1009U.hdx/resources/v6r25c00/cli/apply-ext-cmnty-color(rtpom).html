apply extcommunity color

Function

The apply extcommunity color command sets a color extended community attribute for BGP routes matching specified filtering rules.

The undo apply extcommunity color command cancels the configuration.

By default, no color extended community attribute is set for BGP routes matching specified filtering rules.

Format

apply extcommunity color color

undo apply extcommunity color

Parameters

Parameter Description Value
color

Specifies a color extended community attribute.

The value is in the format of color flag: color value. For example, the value can be set to 0:100. Currently, the color flag can only be 0, and the color value ranges from 0 to 4294967295.

Views

Route-policy view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After configuring filtering rules through if-match clauses, you can run the apply extcommunity color command to apply a color extended community attribute to the BGP routes matching the filtering rules.

Pay attention to the following points when using this command:

  • Run the route-policy command to enter the route-policy view.
  • A route-policy may consist of multiple nodes, and the relationship among these nodes is OR. The device matches routes against the nodes in a route-policy in order of node IDs. If a route matches one of the nodes, the route matches this route-policy and is no longer matched against other nodes.
  • Each node consists of a set of if-match and apply clauses. The if-match clauses define filtering rules based on route attributes. The apply clauses specify actions. If a route matches a node, the apply clauses set route attributes for the route.

Configuration Impact

After the apply extcommunity color command is run, the color extended community attribute specified in the command is set for BGP routes matching specified filtering rules.

Example

# Set a color extended community attribute for BGP routes matching specified filtering rules.
<HUAWEI> system-view
[HUAWEI] route-policy policy permit node 10
[HUAWEI-route-policy] apply extcommunity color 0:100
