application (Security policy rule view)

Function

The application command configures an application for a security policy rule.

The undo application command deletes an application from a security policy rule.

By default, this function is not configured.

Format

application { any | label label-name | app app-name | app-group app-group-name }

undo application { all | label label-name | app app-name | app-group app-group-name }

Parameters

Parameter Description Value
any

Indicates all applications to which a security policy rule applies.

-
app app-name

Indicates the application to which a security policy rule applies.

The value is a string of 1 to 32 case-insensitive characters.
app-group app-group-name

Indicates the application group to which a security policy rule applies.

The value is a string of 1 to 32 case-sensitive characters.
label label-name

Indicates an application label to which a security policy rule applies.

The value is a string of 1 to 32 case-insensitive characters.
all

Deletes all applications to which a security policy rule applies.

-

Views

Security policy rule view

Default Level

2: Configuration level

Usage Guidelines

Security policy rules can be applied to default applications or user-defined applications.

If an application is configured for a security policy rule, you need to run the sa enable command in the interface view to enable application identification for packets. Otherwise, the device cannot identify applications from traffic. As a result, the security policy rules applied to specified applications cannot be matched.

Example

# Set the application of security policy rule policy_sec to DNS. 
<HUAWEI> system-view
[HUAWEI] security-policy
[HUAWEI-policy-security] rule name policy_sec
[HUAWEI-policy-security-rule-policy_sec] application app DNS
