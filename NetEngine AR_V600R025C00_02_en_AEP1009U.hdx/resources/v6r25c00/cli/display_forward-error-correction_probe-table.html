display forward-error-correction probe-table

Function

The display forward-error-correction probe-table command displays information about the FEC probe table.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

display forward-error-correction probe-table tunnel-type sd-wan [ connection-id connection-id-value | vpn-instance vpn-instance-name | profile profile-name ] *

display forward-error-correction probe-table tunnel-type gre [ interface tunnel tunnel-id | profile profile-name ] *

Parameters

Parameter Description Value
connection-id connection-id-value

Specifies a connection ID.

The value is an integer ranging from 1 to 4294967295.
vpn-instance vpn-instance-name

Specifies the name of a VPN instance.

The value is a string of 1 to 31 case-sensitive characters without spaces. The VPN instance name cannot be _public_. If the character string is quoted by double quotation marks, the character string can contain spaces.
profile profile-name

Specifies the name of an FEC parameter profile.

The value is a string of 1 to 31 case-sensitive characters. If the string is enclosed in double quotation marks (" "), the string can contain spaces.
tunnel-type

Indicates the tunnel type.

-
gre

Indicates a GRE tunnel.

-
interface

Indicates an interface.

-
tunnel tunnel-id

Specifies the number of a tunnel interface.

The value is an integer ranging from 0 to 4095.
sd-wan

Indicates an SD-WAN tunnel.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Before FEC encoding, the local device sends a probe packet to detect whether the receive end has the decoding capability. FEC encoding is performed only when the receive end has the decoding capability. You can run this command to check the FEC probe table.

When the device receives traffic requiring FEC and does not found a matching encoding instance entry, a probe table is created. The probe interval is 200 ms before the probe succeeds. The aging time of a probe table is 10 minutes.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display information about the FEC probe table of GRE tunnels.
<HUAWEI> display forward-error-correction probe-table tunnel-type gre
No  Interface Profile    Peer-Ability  Version Status       Probe-Count
-------------------------------------------------------------------------
1   Tunnel10  data       FEC_YES       1       DISCOVERED   56
# Display information about the FEC probe table of SD-WAN tunnels.
<HUAWEI> display forward-error-correction probe-table tunnel-type sd-wan
No  Connection-ID VPN    Profile    Peer-Ability  Version Status      Probe-Count
-----------------------------------------------------------------------------------
1   1             vpna   data       FEC_YES       1       DISCOVERED  56
Table 1 Description of the display forward-error-correction probe-table command output
Item Description
No

ID.
Interface

GRE tunnel interface.
Profile

Name of an FEC parameter profile.
Peer-Ability

Whether the peer end supports FEC.

· FEC_YES: The peer end supports FEC.

· FEC_NO: The peer end does not support FEC.
Version

FEC version on the decoding side:

  • 0: No FEC version is detected.
  • Other values: latest FEC version supported by the decoding side. For example, 2 indicates that the decoding side supports FEC version 2.
Status

Probe status:

· NOT_DISCOVERED.

· DISCOVERED.

· DISCOVERING.
Probe-Count

Number of probe times.
Connection-ID

Link ID.
VPN

VPN instance.
