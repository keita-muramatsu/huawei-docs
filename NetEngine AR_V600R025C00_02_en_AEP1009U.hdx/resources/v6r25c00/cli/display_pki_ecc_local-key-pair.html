display pki ecc local-key-pair public

Function

The display pki ecc local-key-pair public command displays the ECC key pair and public key.

Format

display pki ecc local-key-pair [ name key-name ] public

Parameters

Parameter Description Value
name key-name

Specifies the name of the ECC key pair to be displayed. If this parameter is not specified, the system displays all ECC key pairs and public keys. If this parameter is specified, the system displays only the specified ECC key pair and public key.

The value is a string of 1 to 64 case-sensitive characters.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To view information about an ECC key pair and its public key, run the display pki ecc local-key-pair public command. The command output includes the time when the key pair was created, key pair name, whether the key can be exported, and public key of the key pair.
