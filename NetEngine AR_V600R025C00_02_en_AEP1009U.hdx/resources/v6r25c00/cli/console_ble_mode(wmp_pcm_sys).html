console ble-mode

Function

The console ble-mode command sets the mode of the Bluetooth console port function.

The undo console ble-mode command restores the default mode of the Bluetooth console port function.

By default, the Bluetooth console port mode is dynamic.

Format

console ble-mode { dynamic | persistent | disable }

undo console ble-mode

Parameters

Parameter Description Value
dynamic

Indicates the dynamic mode. In this mode, the Bluetooth console port function is enabled automatically when the link between a Fit AP and WAC is disconnected or is disabled when the link is normal.

-
persistent

Indicates the persistent mode, in which the Bluetooth console port function remains enabled.

-
disable

Disables the Bluetooth console port function.

-

Views

AP system profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When the Bluetooth console port function is enabled on an AP, you can connect a terminal to the AP through Bluetooth and use the CloudCampus APP to log in to the AP through the Bluetooth console port, facilitating fault diagnosis and debugging of the AP.

Precautions

Before using the Bluetooth console port function, run the undo console disable command to ensure that the function of logging in to an AP through the console port is enabled.

After you run the console ble-mode disable command to disable the Bluetooth console port function, if the AP restarts, the Bluetooth console port function is automatically enabled to facilitate fault diagnosis and debugging. This function is automatically disabled when the AP goes online successfully again.

Example

# Set the Bluetooth console port mode to persistent in the AP system profile system1.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name system1
[HUAWEI-wlan-ap-system-prof-system1] console ble-mode persistent
Warning: Bluetooth-based console port login cannot be used together with Bluetooth-based monitoring, Bluetooth-based tag locating, and Bluetooth-based transparent data transmission, Whether to continue? [Y/N]:y
