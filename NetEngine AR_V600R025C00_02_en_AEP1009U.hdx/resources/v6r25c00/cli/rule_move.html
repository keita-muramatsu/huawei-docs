rule move (NAT policy view)

Function

The rule move command allows you to move a NAT policy rule so that the priority of the NAT policy rule changes.

Format

rule move rule-name1 { { after | before } rule-name2 | up | down | top | bottom }

Parameters

Parameter Description Value
rule-name1

Specifies the name of a policy rule to be moved.

The value is a string of 1 to 63 case-sensitive characters without spaces. If spaces are used, the string must start and end with double quotation marks (").
after

Moves rule-name1 after rule-name2.

-
before

Moves rule-name1 before rule-name2.

-
rule-name2

Specifies the name of a reference NAT policy rule.

The value is a string of 1 to 63 case-sensitive characters without spaces. If spaces are used, the string must start and end with double quotation marks (").
up

Moves the rule before the upper one.

-
down

Moves the rule after the lower one.

-
top

Moves a rule to the top of all rules of the same type. Destination NAT rules are placed above source NAT rules. As such, when you move a source NAT rule to the top, it is placed following the last destination NAT rule.

-
bottom

Move a rule to the bottom (before the default policy).

-

Views

NAT policy View

Default Level

2: Configuration level

Usage Guidelines

The position of a NAT policy rule determines the priority of the rule. An earlier configured traffic policy rule has a higher priority. NAT policy rules are arranged in descending order by priority. The system matches traffic with policy rules in descending order by priority.

An administrator can run the rule move command to move a policy rule to change the rule priority.

Example

# Move a rule named nat_rule_2 before a rule named nat_rule_1 so that nat_rule_2 has a higher priority than nat_rule_1. 
<HUAWEI> system-view
[HUAWEI] nat-policy
[HUAWEI-policy-nat] rule name nat_rule_1
[HUAWEI-policy-nat-rule-nat_rule_1] quit
[HUAWEI-policy-nat] rule name nat_rule_2
[HUAWEI-policy-nat-rule-nat_rule_2] quit
[HUAWEI-policy-nat] rule move nat_rule_2 before nat_rule_1
