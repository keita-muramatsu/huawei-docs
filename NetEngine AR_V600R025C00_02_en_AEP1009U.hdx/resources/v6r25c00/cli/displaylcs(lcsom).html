display license

Function

The display license command displays information about an active license file.

Format

display license

display license verbose

Parameters

Parameter Description Value
verbose

Displays details about a license file.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

A license file determines whether some product features are available. To view information about an active license file, run the display license command. The information includes the name, version, valid time, and configuration items of the license file.

The encoding format used to display license information in the current version is UTF-8. To prevent garbled characters when you use a different terminal to log in to the device and Chinese characters are displayed, change the terminal's encoding format to UTF-8.

For example, if you use the PuTTY tool as the terminal, set its encoding format to UTF-8. After the encoding format is set to UTF-8, Chinese information about the license can be correctly displayed.

Precautions

In traditional mode, this command displays all activated licenses on the device.

In cloud mode, this command displays only the activated hardware RTUs on the device, not the activated service licenses.

Table 1 Description of the display license command output
Item Description
Active License

Name of the activated license file in the display license command output.
Active license

Name of the activated license file in the display license verbose command output.
License state

Status of a license file:

  • Normal: normal activated status.

    This state value indicates that a license file is working properly. If the status of the license file on the live network is not Normal, check the license file.

  • Trial: keepalive state. This means that the validity period of the License is extended with a grace period of 60 days.
    • A license file enters the Trial state if the ESN does not match the device.

      To continue to use a license file after the Trial state, apply for a license file matching the new ESN and activate it.

    • A temporary license file expires and enters the Trial state.

      To continue to use a license file after the Trial state, apply for a license file and activate it.

    • A license file is revoked and enters the Trial state.

      To continue to use a license file after the Trial state, apply for a license file based on the revocation code and activate it.

    • If you replace a device board but the new ESN does not match the license file, the license file enters the Trial state.

      To continue to use a license file after the Trial state, apply for a license file matching the new ESN and activate it.

  • Demo: trial state. It is used for function debugging, and the maximum validity period is 90 days.

    When you activate a temporary license file, it enters the Demo state. The Demo state exists only for a demo license file used for test and deployment.

    A license file in Demo state allows you to use functions properly within a specified period. Before the expiration of the license file in Demo state, replace it with a commercial license file.

  • Emergency: disaster recovery state.

    In the event of emergencies such as earthquakes, volcanic eruptions, and tsunamis, run the license emergency command to trigger a license file to enter the Emergency state. This state lasts for seven days, and a license file can enter the Emergency state three times.

  • Default: default state, indicating that no license is activated. This state applies when no license file is activated after device delivery, or when the license file is not reactivated after the grace period expires.

    If a license file enters the Default state, services will be interrupted.

    If you want to use services after a license file expires or becomes invalid, apply for a new license file and activate it.

Trial days

Grace (trial) period. If the license module enters the Trial state from Demo state, the license module is allowed to run based on the authorization strategy in Normal or Demo state before the grace period expires.

Item type

Type of a license control item:

  • Resource: license control item, indicating a resource control service license. The item name in the line is indented.
  • Function: license control item, indicating a function control service license. The item name in the line is indented.
  • --: license sales item. The item name in the line is not indented.
