rsa signature-padding

Function

The rsa signature-padding command configures a padding mode for the RSA signature.

The undo rsa signature-padding command restores the default padding mode for the RSA signature.

By default, the padding mode of the RSA signature is PSS (Huawei algorithm).

Format

rsa signature-padding { pkcs1 | pss [ sha2-256 ] }

undo rsa signature-padding

Parameters

Parameter Description Value
pkcs1

Sets the padding mode of the RSA signature to Public-Key Cryptography Standards 1 (PKCS1).

-
pss

Indicates that the padding mode of the RSA signature is Probabilistic Signature Scheme (PSS) of the SHA2-256 algorithm.

-
sha2-256

Indicates the PSS using the SHA2-256 algorithm.

-

Views

IKE peer view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If you run the rsa signature-padding pss command to set the padding mode of an RSA signature to pss, the PSS mode of the SHA2-256 algorithm is used if the sha2-256 parameter is specified, and the PSS mode of the Huawei algorithm is used if the sha2-256 parameter is not specified. When the device functions as the tunnel initiator, the PSS padding hash algorithm used by the device must be compatible with that used by the peer end. Otherwise, tunnel negotiation may fail.

Precautions

The pkcs1 parameter in this command can be configured only after the weak security algorithm or protocol feature software package (WEAKEA) is installed.

Example

# Set the padding mode of an RSA signature to PSS (Huawei algorithm). 
<HUAWEI> system-view
[HUAWEI] ike peer peer1
[HUAWEI-ike-peer-peer1] rsa signature-padding pss
