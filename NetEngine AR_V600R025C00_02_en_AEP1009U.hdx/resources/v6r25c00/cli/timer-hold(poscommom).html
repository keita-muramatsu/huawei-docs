timer hold

Function

The timer hold command sets a polling interval.

The undo timer hold command restores the default setting.

By default, the polling interval of the link layer protocol is 10 seconds on an interface.

Format

timer hold interval

undo timer hold

Parameters

Parameter Description Value
interval

Specifies a polling interval.

The value is an integer ranging from 0 to 32767, in seconds. The value 0 indicates the link detection is disabled.

Views

Dialer interface view, POS interface view, Serial interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

An interface periodically sends Keepalive packets to the peer. The polling interval refers to the interval at which the interface sends Keepalive packets.

If the local device does not receive any Keepalive packet from the peer within a specified polling interval, the Keepalive count increases by 1. If the device still fails to receive any Keepalive packet when the Keepalive count reaches 5, the link is considered faulty and the link status is set to Down.

In situations with significant network delay or congestion, you can increase the polling interval to reduce network flapping.

Precautions

The polling intervals of the devices at both ends of a link must be the same.

Example

# Set the polling interval on Dialer1 to 20 seconds.
<HUAWEI> system-view
[HUAWEI] interface Dialer1
[HUAWEI-Dialer1] timer hold 20
