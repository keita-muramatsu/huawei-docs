display l2tp tunnel

Function

The display l2tp tunnel command displays information about established L2TP tunnels.

Format

display l2tp tunnel { brief | all | tunnel-id tunnel-id | peer-name remote-name }

Parameters

Parameter Description Value
brief

Displays brief information.

-
all

Displays information about all tunnels.

-
tunnel-id tunnel-id

Specifies the ID of an L2TP tunnel.

The value is an integer ranging from 1 to 1024.
peer-name remote-name

Specifies the name of the remote L2TP tunnel.

The value is a string of 1 to 30 case-sensitive characters.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

After L2TP tunnels are established, you can run the display l2tp tunnel command to view L2TP tunnel information, including the total number of established L2TP tunnels, tunnel IDs, and tunnel addresses.

You can view detailed information about a specified L2TP tunnel based on the local ID of the L2TP tunnel or the remote tunnel name of the L2TP tunnel.

Prerequisites

L2TP tunnels are successfully established.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display brief information.
<HUAWEI> display l2tp tunnel brief
------------------------------------------------------------------------
Group Local-ID Remote-ID Remote-Address  Port  Sessions Remote-Name
1     1        1         1.1.1.3         1701  1        lns 
------------------------------------------------------------------------
Total Number of L2TP Tunnel: 1
------------------------------------------------------------------------
# Display information about the tunnel with ID 1.
<HUAWEI> display l2tp tunnel tunnel-id 1
------------------------------------------------------------------------
Local Info:
  Tunnel ID      : 1            Tunnel Name      : lac
  Negotiation IP : 1.1.1.2      Negotiation Port : 1701
  RWS            : 4            State            : UP
  Group Number   : 1            Nego Interface   : GE0/0/1
  Session Number : 1            Last Fail Reason : --
                                Last Fail Time   : --
Remote Info:
  Tunnel ID      : 2            Tunnel Name      : lns
  Tunnel IP      : 1.1.1.3      Tunnel Port      : 1701
  RWS            : 128
------------------------------------------------------------------------
Total Number of L2TP Tunnel: 1

Table 1 Description of the display l2tp tunnel command output
Item Description
Group

Number of the L2TP group used by the L2TP tunnel.
Group Number

Number of the L2TP group used by the L2TP tunnel.
Local-ID

Local tunnel ID of the L2TP tunnel.
Remote-ID

Remote tunnel ID of the L2TP tunnel.
Remote-Address

Remote IP address of the L2TP tunnel.
Port

Port number used by the remote end of the L2TP tunnel. Generally, the port number is 1701.
Sessions

Number of sessions carried on the L2TP tunnel.
Remote-Name

Remote tunnel name of the L2TP tunnel.
Total Number of L2TP Tunnel

Total number of L2TP tunnels.
Local Info

Local end information of the L2TP tunnel.
Tunnel ID

ID of the L2TP tunnel.
Tunnel Name

Name of the L2TP tunnel.
Tunnel IP

IP address of the L2TP tunnel.
Tunnel Port

Port number of the L2TP tunnel.
Negotiation IP

IP address used by the local end during L2TP tunnel negotiation.
Negotiation Port

Port number used by the local end during L2TP tunnel negotiation.
RWS

Size of the receive window.
State

L2TP tunnel status:

IDLE: The tunnel is idle.

Wait_CTL_REPLY: The L2TP tunnel has sent SCCRQ packets and is waiting to receive SCCRP packets.

UP: The L2TP tunnel is established.
Nego Interface

Name of the interface used by the local end during L2TP tunnel negotiation.
Session Number

Number of sessions that have been established on the L2TP tunnel.
Last Fail Reason

Cause of the last connection setup failure.

Tunnel is reset: The tunnel is reset.

Configuration is changed: The configuration is changed.

Received StopCCN from LNS: The LNS at the remote end disconnects the tunnel.

Packet error: Error L2TP packets are received.

Disconnected with LNS: The device is disconnected from the LNS server.
Last Fail Time

Time when the last connection fails to be set up.
Remote Info

Peer end information of an L2TP tunnel.
