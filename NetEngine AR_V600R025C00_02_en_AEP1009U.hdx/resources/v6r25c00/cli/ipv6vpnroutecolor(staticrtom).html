ipv6 route-static vpn-instance color

Function

The ipv6 route-static vpn-instance color command configures an IPv6 static route with a specified color value for a VPN instance.

The undo ipv6 route-static vpn-instance color command deletes the IPv6 static route with a specified color value configured for a VPN instance.

By default, no IPv6 static route with a specified color value is configured for a VPN instance.

Format

ipv6 route-static vpn-instance srcvpn6-instance-name prefix mask-length color color-value public vn-id vn-id-value [ preference preference-value | tag tag-value ] * [ description description-value ]

undo ipv6 route-static vpn-instance srcvpn6-instance-name prefix mask-length color color-value public

Parameters

Parameter Description Value
prefix

Specifies the destination IPv6 address.

The value is a 32-bit hexadecimal string in format X:X:X:X:X:X:X:X.
mask-length

Specifies an IPv6 prefix length.

It is an integer ranging from 0 to 128.
color color-value

Specifies the color value of a static route.

In an SD-WAN scenario, a VPN static route recurses to an SD-WAN tunnel based on the route's color value, triggering the establishment of the SD-WAN tunnel. The established SD-WAN tunnel can be used to carry VPN service traffic.

The value is an integer ranging from 1 to 4294967295.
public

Specifies a public network. Static VPN routes are recursed to public SD-WAN tunnels based on the color value.

-
vn-id vn-id-value

Specifies a virtual network identifier.

In an SD-WAN scenario, a virtual network identifier is used as a VPN instance ID and equals the value configured using the vn-id command in the VPN instance view at the remote end.

The value is an integer that ranges from 1 to 16777215.
preference preference-value

Priority of a static route.

The value is an integer that ranges from 1 to 255. The default value is 60. A smaller value indicates a higher preference.
tag tag-value

Specifies a tag value for the static route. The tag can be used by a routing policy to import desired static routes.

The value is an integer ranging from 1 to 4294967295. The default value is 0.
description description-value

Specifies the description of a static route.

You can run the display this (system view) and display current-configuration commands to view the description.

The description keyword cannot be followed by other command parameters such as preference. The content is used only as the description. For example, if ipv6 route-static vpn-instance vrf1 2001:DB8::1 128 color 100 public vn-id 100 description aa preference 10 is configured, aa preference 10 is used as the description.

The value is a string of 1 to 150 characters, spaces supported.
vpn-instance srcvpn6-instance-name

Specifies the name of a source VPN instance. The configured static routes are added to the routing table of the specified VPN instance.

The value is a string of 1 to 31 case-sensitive characters, spaces not supported. In addition, the VPN instance name must not be _public_. When double quotation marks are used around the string, spaces are allowed in the string.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In SD-WAN scenarios, static VPN routes are recursed to SD-WAN tunnels based on color values and trigger the creation of SD-WAN tunnels to carry VPN service traffic.

Prerequisites

A VPN instance has been created using the ip vpn-instance command when configuring a static route for the VPN instance.

Precautions

When configuring unicast static routes, pay attention to the following points:

  • If no priority is configured for a static route, the default priority 60 is used.
  • If both a static route with a specified color value and a static route with only a VPN instance specified as the next hop (no outbound interface or next hop address, that is, the Next-Table function is configured) are configured for the same destination address, and the two static routes have the same priority, the last configured static route takes effect, and the previous static route will be overwritten.
  • For static routes with the same prefix but different priorities, you can configure both a static route with a specified color value and a static route with only a VPN instance specified as the next hop.
  • After the static route configuration is saved and the device is restarted in CFG mode, the configuration file sequence may be different from that before the restart.

Example

# Configure a static route for the VPN instance named vpn1, with the destination address being 2001:DB8::1/128, color value being 100, and VN-ID being 100.
<HUAWEI> system-view
[HUAWEI] ip vpn-instance vpn1
[HUAWEI-vpn-instance-vpn1] ipv6-family
[HUAWEI-vpn-instance-vpn1-af-ipv6] quit
[HUAWEI-vpn-instance-vpn1] quit
[HUAWEI] ipv6 route-static vpn-instance vpn1 2001:DB8::1 128 color 100 public vn-id 100
