mode (Cellular template view)

Function

The mode command configures the mode in which the modem connects to the wireless network.

The undo mode command restores the default mode for the modem to connect to the wireless network.

By default, the modem uses the auto mode to connect to the wireless network.

Format

mode { auto | wcdma-only | lte-only | lte-wcdma | nr-only | nr-lte }

undo mode

Parameters

Parameter Description Value
auto

Configures a modem to automatically select a network to connect to.

-
lte-only

Configure a modem to select only an LTE network to connect to.

-
nr-only

Configure a modem to select only an NR network to connect to.

-
nr-lte

Configure a modem to select an NR or LTE network to connect to.

-
wcdma-only

Configure a modem to select only a WCDMA network to connect to.

-
lte-wcdma

Configure a modem to select an LTE or WCDMA network to connect to.

-

Views

Cellular template view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The modem can successfully access a wireless network only when the mode for connecting to the wireless network is the same as that provided by the carrier. If they are different, you can run the mode command to change the mode for the modem to connect to the wireless network to be the same as that provided by the carrier.

Precautions

  • Only devices that support the 5G function support the nr parameter.
  • Only devices that support the 4G function support the lte parameter.
  • Only devices that support the 3G function support the wcdma parameter.

Example

# Configure the modem to connect only to an LTE network.
<HUAWEI> system-view
[HUAWEI] cellular-profile profileName
[HUAWEI-cellular-profile-profileName] mode lte-only
# Restore the default mode for the modem to connect to the wireless network.
<HUAWEI> system-view
[HUAWEI] cellular-profile profileName
[HUAWEI-cellular-profile-profileName] undo mode
