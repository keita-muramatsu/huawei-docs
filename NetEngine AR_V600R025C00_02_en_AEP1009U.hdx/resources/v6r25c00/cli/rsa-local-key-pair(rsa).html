rsa local-key-pair

Function

The rsa local-key-pair create command generates a local RSA key pair.

The rsa local-key-pair destroy command deletes all local RSA key pairs.

By default, no local RSA key pair is configured.

Format

rsa local-key-pair create

rsa local-key-pair destroy

Parameters

None

Views

System view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

If the RSA key pair already exists, the system prompts you to confirm whether to replace the original key pair. The generated key pair is named Host_Server and Host.

After running the command to delete the key pair, you need to confirm whether to delete all local RSA key pairs.

Precautions

  • To ensure high security, you are advised to use the RSA key pair whose length is 3072 bits or longer. To create an RSA key pair whose length is less than 3072 bits, you need to run the install feature-software WEAKEA command to install the weak security algorithm/protocol feature package (WEAKEA).
  • After this command is run, the system prompts you to enter the length of the RSA key pair to be generated. Currently, the system supports the RSA key pair with the modulus length of 2048 bits, 3072 bits, or 4096 bits. If you press Enter without entering the key pair length, a 3072-bit RSA key pair is generated. If you do not perform any operation, the system does not generate any RSA key pair.
  • This command is an operation command and therefore is not saved in the profile.
  • If no local key pair is configured when you log in to the device through SSH for the first time, the system automatically generates a local key pair.
  • To ensure that the local key pair used after the system restarts remains unchanged, run the save command to save the key pair to the profile loaded for the next startup. If the profile is not saved, a new local key pair is generated after the system restarts. You need to use the new key pair to log in to the device.

Example

# Remove all local RSA keys on the server.
<HUAWEI> system-view
[HUAWEI] rsa local-key-pair destroy
Info: The name for the keys which will be destroyed is Host
Warning: Confirm to destroy these keys?
Please select [Y/N]:y
Info: RSA key pair deleted successfully.
# Configure a device to generate local host and server key pairs.
<HUAWEI> system-view
[HUAWEI] rsa local-key-pair create
The key name will be:Host 
The range of public key size is (2048, 4096). 
NOTE: Key pair generation will take a short while. 
Please input the modulus [default = 3072]:3072
