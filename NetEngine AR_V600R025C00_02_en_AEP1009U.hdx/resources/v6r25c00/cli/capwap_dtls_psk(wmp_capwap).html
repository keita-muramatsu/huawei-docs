capwap dtls psk

Function

The capwap dtls psk command configures a PSK used for DTLS encryption.

The undo capwap dtls psk command deletes the PSK used for DTLS encryption.

By default, no PSK used for DTLS encryption is configured.

Format

capwap dtls psk psk-value

undo capwap dtls psk

Parameters

Parameter Description Value
psk-value

Specifies the PSK used for DTLS encryption.

The value is string of 48, 68, 128, or 148 characters in ciphertext, for example, %+%##!!!!!!!!!"!!!!"!!!!*!!!!a4O4$.&PxR2^=y1\*r]BbOe+>J`k!2nB"e)!!!!!2jp5!!!!!!;!!!!wIJwJv2L/Pk=7SY&G#'IOcms2O[,R(YFxr$!!!!!%+%#. The value can also be a string of 8 to 32 characters in plaintext, for example, YsHsjx_202206. The value must contain at least two of the following: uppercase letters, lowercase letters, digits, and special characters, without question marks (?) or spaces. The value cannot start or end with double quotation marks (").

For security purposes, you are advised to periodically change the PSK.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

During CAPWAP tunnel establishment, a DTLS session is established between the client and server. If DTLS encryption for CAPWAP control tunnels is enabled on the device, the device encrypts management packets to be sent using DTLS. When the PSK mode for DTLS is used, you can run this command to configure a PSK for a DTLS session.

Follow-up Procedure

Run the capwap dtls control-link encrypt command to enable DTLS encryption for CAPWAP control tunnels.

Precautions

After the configuration is complete, the new PSK is automatically synchronized to online CAPWAP clients, but the original PSK still takes effect. The new PSK takes effect after the clients re-establishes links.

Example

# Set the pre-shared key for DTLS encryption to Test123321.
<HUAWEI> system-view
[HUAWEI] capwap dtls psk Test123321
