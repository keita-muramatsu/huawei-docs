ap-reset

Function

The ap-reset command resets an AP.

Format

ap-reset { all | ap-mac mac | ap-id ap-id-value | ap-group group | ap-type { type type-name | type-id type-id-value } | wait-rtu-validate }

Parameters

Parameter Description Value
all

Resets all APs.

-
ap-mac mac

Resets the AP with the specified MAC address.

The AP's MAC address must exist.
ap-id ap-id-value

Resets the AP with the specified AP ID.

The AP ID must exist.

The value is a string of 1 to 255 characters. When multiple APs are selected, use commas (,) to separate them or use hyphens (-) to indicate consecutive AP IDs. For example, the value 5,8,10-13,20 indicates the list of APs with IDs 5, 8, 10, 11, 12, 13, and 20.
ap-group group

Resets APs in the specified AP group.

The value is a string of 1 to 35 visible characters that can be Chinese characters or a combination of Chinese and English characters. It cannot contain question marks (?) or only contain double quotation marks ("). If the AP group name contains spaces,it must be enclosed with double quotation marks (" "), for example, "huawei name1". The double quotation mark (") before and after the AP group name occupies two characters together. The specified AP group must exist.

Only the command editor in UTF-8 encoding format can be used to edit Chinese characters.
ap-type

Resets APs of the specified type.

-
type type-name

Resets APs of the specified type name.

The value is a string of 1 to 31 case-sensitive characters without spaces.
type-id type-id-value

Resets APs of the specified type ID.

The value is an integer in the range from 0 to 1023.
wait-rtu-validate

Resets APs on which RTU licenses have been loaded but have not taken effect.

-

Views

WLAN view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After in-service upgrade of APs is complete, you can run this command to reset the APs. After the command is run, the APs restart with the upgraded software version. You can also run this command to restart an AP for other reasons.

Prerequisites

An AP exists on the WAC.

Example

# Reset the AP with the AP ID of 1.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-reset ap-id 1
Warning: Reset AP(s), continue?[Y/N]:y
