transport-network-port

Function

The transport-network-port command creates a TNP and displays the TNP view.

The undo transport-network-port command deletes a created TNP view.

By default, no TNP is created.

Format

transport-network-port transport-network-port-id [ type ipv6 ]

undo transport-network-port transport-network-port-id [ type ipv6 ]

Parameters

Parameter Description Value
transport-network-port-id

Specifies a TNP ID.

The value is an integer in the range from 1 to 4294967295.
type

Specifies the type of a TNP. The default value is Ipv4.

-
ipv6

Specifies the IPv6 type.

-

Views

Site view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To create local TNP information for a CPE in EVPN networking, run the transport-network-port command. A TNP is the interface through which a site is connected a TN. It is a logical interface and uniquely corresponds to a physical interface. TNP contains some key information such as the site ID, TNP ID, interface, transport network domain, routing domain, encapsulation type, and weight. TNPs are used to establish connections between sites.

Prerequisites

  • A site has been created using the evpn site command.

  • A system ID has been configured for the site using the system-id command.

  • The site type has been configured using the gateway command.

Configuration Impact

Deleting a TNP will delete the EVPN tunnels associated with the TNP.

Follow-up Procedure

  • Run the routing-domain command to configure a routing domain.
  • Run the transport-network command to configure a transport network.

Precautions

TNP information can be configured only when site information is complete (the site system ID and site attribute have been configured).

Example

# Create a TNP with the ID 1 at site 1.
<HUAWEI> system-view
[HUAWEI] evpn site 1
[HUAWEI] system-id 1.1.1.1
[HUAWEI-site-1] transport-network-port 1
