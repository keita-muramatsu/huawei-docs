vap-profile wlan radio-policy

Function

The vap-profile wlan radio-policy command binds a VAP profile to an AP or AP group and specifies the radio policy for the VAP profile to take effect.

The undo vap-profile wlan radio-policy command unbinds a VAP profile from an AP or AP group and deletes the radio policy based on which the VAP profile takes effect.

By default, no VAP profile is bound to an AP group or a specific AP, and no radio is specified for a VAP profile to take effect.

Format

vap-profile profile-name wlan wlan-id radio-policy { 2.4g | 5g | 6g | all }

undo vap-profile profile-name wlan wlan-id radio-policy { 2.4g | 5g | 6g | all }

Parameters

Parameter Description Value
profile-name

Specifies the name of a VAP profile.

The VAP profile name must exist. The value is a string of 1 to 35 characters.
wlan wlan-id

Specifies a VAP ID.

The value is an integer ranging from 1 to 16.

  • The WLAN ID in the offline management VAP configuration cannot be 13, 14, or the maximum WLAN ID supported by the current AP radio.
  • For some AP models, the maximum number of VAPs supported on each radio is smaller than 16. If the value of wlan-id exceeds the AP specifications, the configuration cannot take effect and the AP cannot generate radio signals.
radio-policy

Specifies the radio type policy.

-
2.4g

Specifies the 2.4 GHz radio type.

-
5g

Specifies the 5 GHz radio type.

-
6g

Specifies the 6 GHz radio type.

-
all

Specifies all radio types.

-

Views

AP group view, AP view

Default Level

2: Configuration level

Usage Guidelines

After creating a VAP profile, you need to bind it to a radio or specify the radio policy for the VAP profile to take effect. You can run the vap-profile (AP radio view or AP group radio view) or vap-profile (AP view or AP group view) command to bind a VAP profile to a radio, or run this command to specify the radio policy for the VAP profile to take effect.

If VAP profiles based on the radio and radio policy are both configured in the AP group view and AP view, the configuration takes effect in the following sequence: ap-id + radio-id > ap-id + radio policy > ap-group + radio-id > ap-group + radio-policy.

Example

# Create the VAP profile vap1 and specify the 2.4 GHz radio policy for the VAP profile in the AP group group1.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] vap-profile name vap1
[HUAWEI-wlan-vap-prof-vap1] quit
[HUAWEI-wlan] ap-group name group1
[HUAWEI-wlan-ap-group-group1] vap-profile vap1 wlan 1 radio-policy 2.4g
