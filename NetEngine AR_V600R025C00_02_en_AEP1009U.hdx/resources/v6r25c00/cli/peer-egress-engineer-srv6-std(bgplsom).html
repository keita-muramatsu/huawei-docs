peer egress-engineering srv6

Function

The peer egress-engineering srv6 inherit-global-locator command enables the BGP Egress Peer Engineering (EPE) function to inherit the global locator for SID allocation.

The undo peer egress-engineering srv6 inherit-global-locator command disables BGP EPE.

The peer egress-engineering srv6 locator command enables the BGP EPE function and uses a locator to allocate dynamic SIDs.

The undo peer egress-engineering srv6 locator command disables BGP EPE.

The peer egress-engineering srv6 static-sid command configures the static uncompressed End.X SID (PSP) and End.X SID (no flavor).

The undo peer egress-engineering srv6 static-sid command clears the configured static uncompressed End.X SID (PSP) and End.X SID (no flavor).

By default, BGP EPE is disabled.

Format

peer peerIpv6Addr egress-engineering srv6 inherit-global-locator

peer peerIpv6Addr egress-engineering srv6 locator locator-name

peer peerIpv6Addr egress-engineering srv6 static-sid { psp psp-sid | no-flavor no-flavor-sid } *

undo peer peerIpv6Addr egress-engineering srv6 inherit-global-locator

undo peer peerIpv6Addr egress-engineering srv6 locator locator-name

undo peer peerIpv6Addr egress-engineering srv6 static-sid { psp psp-sid | no-flavor no-flavor-sid } *

undo peer peerIpv6Addr egress-engineering srv6 static-sid

Parameters

Parameter Description Value
peerIpv6Addr

Specifies the IPv6 address of a peer.

The value is a 32-digit hexadecimal string in format X:X:X:X:X:X:X:X.
inherit-global-locator

Indicates that the global locator is used to allocate SIDs.

-
locator locator-name

Specifies the name of a SID locator. To configure a locator, run the locator command.

The value is a string of 1 to 31 characters.
static-sid

Indicates the static SID.

-
psp psp-sid

Specifies a static uncompressed End.X SID (PSP).

The value is a 32-digit hexadecimal number in the format of X:X:X:X:X:X:X:X. The value range is the static uncompressed SID range of the locator in the segment-routing ipv6 egress-engineering locator configuration.
no-flavor no-flavor-sid

Specifies a static uncompressed End.X SID (no flavor).

The value is a 32-digit hexadecimal number in the format of X:X:X:X:X:X:X:X. The value range is the static uncompressed SID range of the locator in the segment-routing ipv6 egress-engineering locator configuration.

Views

BGP view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

BGP is a dynamic routing protocol used between autonomous systems (ASs). BGP EPE is an extension of BGP for segment routing and is used to implement source routing between ASs. BGP EPE can allocate BGP peer SIDs to inter-AS paths. The peer SIDs can be transmitted to the network controller through BGP LS extension. The controller orchestrates IGP SIDs and BGP peer SIDs to implement inter-AS forwarding over the optimal path.

After the peer egress-engineering srv6 inherit-global-locator or peer egress-engineering srv6 locator command is run, the local device can allocate a peer node segment (peer-node SID) and a peer adjacency segment (peer-Adjacency SID) to a peer to configure a dynamic SID.

After the peer egress-engineering srv6 static-sid command is run, the local device can specify static End.X SIDs (PSP) and End.X SIDs (no flavor) for peers.

Prerequisites

To configure a static SID, run the link-state-family unicast command to enable BGP-LS and run the segment-routing ipv6 command to enable SRv6 so that the BGP EPE function can take effect.

Before configuring a static SID, run the peer egress-engineering srv6 inherit-global-locator command to inherit the global locator configuration.

Precautions

  1. If a locator is configured for a peer, this locator is preferred. Otherwise, the global locator is used.
  2. A locator and a static SID cannot be both configured for a peer. If both of them are configured, the latest configuration overrides the previous one. A static SID uses the globally referenced locator, and the SID value must be globally unique.
  3. A maximum of two locators can be specified in the peer egress-engineering srv6 locator command for the same peer. If more than two locators are specified, an error message is displayed.
  4. BGP EPE can report only BGP-LS link route information between directly connected devices. If devices are not directly connected, the correctness of the reported BGP-LS link route information cannot be ensured.

Example

# Enable BGP EPE and configure static non-compression End.X SIDs (PSP) and End.X SIDs (no flavor).
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] locator test ipv6-prefix 2001:db8:30:: 64 static 32
[HUAWEI-segment-routing-ipv6-locator] quit
[HUAWEI-segment-routing-ipv6] quit
[HUAWEI] bgp 100
[HUAWEI-bgp] segment-routing ipv6 egress-engineering locator test
[HUAWEI-bgp] peer 2001:db8:1::1 as-number 200
[HUAWEI-bgp] peer 2001:db8:1::1 egress-engineering srv6 inherit-global-locator
[HUAWEI-bgp] peer 2001:db8:1::1 egress-engineering srv6 static-sid psp 2001:db8:30::1 no-flavor 2001:db8:30::2
# Enable BGP EPE to inherit the global locator to allocate SIDs.
<HUAWEI> system-view
[HUAWEI] bgp 100
[HUAWEI-bgp] peer 2001:db8:1::1 as-number 200
[HUAWEI-bgp] peer 2001:db8:1::1 egress-engineering srv6 inherit-global-locator
# Enable BGP EPE and use a locator to allocate dynamic SIDs.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] locator test ipv6-prefix 2001:db8:30:: 64 static 32
[HUAWEI-segment-routing-ipv6-locator] quit
[HUAWEI-segment-routing-ipv6] quit
[HUAWEI] bgp 100
[HUAWEI-bgp] peer 2001:db8:1::1 as-number 200
[HUAWEI-bgp] peer 2001:db8:1::1 egress-engineering srv6 locator test
