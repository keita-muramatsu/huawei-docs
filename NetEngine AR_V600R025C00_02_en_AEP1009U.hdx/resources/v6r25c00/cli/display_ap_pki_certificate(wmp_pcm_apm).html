display ap pki certificate

Function

The display ap pki certificate command displays information about the CA or local certificate in a specified AP PKI realm.

Format

display ap pki certificate ap-id ap-id { ca | local } realm realm-name

Parameters

Parameter Description Value
ap-id ap-id

Specifies the AP ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
ca

Displays information about the CA certificate.

-
local

Displays information about the local certificate.

-
realm realm-name

Specifies the name of a realm.

The value is a string of 1 to 50 case-sensitive characters. It cannot contain spaces.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Run the display ap pki certificate command to check information about the CA and local certificates in a specified AP PKI realm.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display information about the CA certificate of the AP with the ID 0 in the PKI realm abc.
<HUAWEI> display ap pki certificate ap-id 0 ca realm abc

Table 1 Description of the display ap pki certificate command output
Item Description
Serial Number

Serial number of a certificate.
Validity

Validity period of a certificate.
Not Before

The certificate cannot be earlier than this time.
Not After

The certificate cannot be later than this time.
Total

Total count.
Issuer

Issuer of a certificate.
Subject

Subject of a certificate. The subject includes the following attributes:

C: country code of a PKI entity.

ST: name of the state or province to which a PKI entity belongs.

L: geographic area where a PKI entity is located.

O: organization to which a PKI entity belongs.

OU: department to which a PKI entity belongs.

CN: common name of a PKI entity.
