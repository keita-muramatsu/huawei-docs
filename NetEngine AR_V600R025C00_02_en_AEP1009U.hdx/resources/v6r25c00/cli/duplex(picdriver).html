duplex

Function

The duplex command configures a duplex mode for an Ethernet electrical interface.

The undo duplex command restores the default duplex mode of an Ethernet electrical interface.

By default, the electrical interface works in full-duplex mode.

Format

duplex half

duplex full

undo duplex [ half | full ]

Parameters

Parameter Description Value
full

Configures an Ethernet electrical interface to work in full duplex mode.

-
half

Configures an Ethernet electrical interface to work in half duplex mode.

-

Views

GE electrical interface view, Layer 2 multi-GE interface view, Multi-GE interface view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

On a large-scale Ethernet network, manually setting the interface rate and duplex mode, verifying device configurations, and checking Ethernet interface statistics are time-consuming. Therefore, it is recommended that the interface rate and duplex mode be manually set only when auto-negotiation of an Ethernet link fails or a problem occurs with auto-negotiation. When there is an auto-negotiation problem, you are advised to upgrade device software or hardware for the device to support the auto-negotiation mechanism defined in IEEE 802.3u/z.

Manually setting the interface rate and duplex mode usually complicates network planning and maintenance, and incorrect settings directly affect network communications. During network planning, you can run the duplex command to set the duplex mode of the local interface to be the same as the known peer duplex mode. However, once the duplex mode of the peer interface changes, the duplex mode of the local interface cannot change accordingly, adversely affecting the communication quality.

Prerequisites

Before configuring the duplex mode for an interface, configure the interface to work in non-auto-negotiation mode. If the interface is configured to work in half-duplex mode, configure the interface to work at the rate of 10 Mbit/s or 100 Mbit/s.

Precautions

  • The working modes of Ethernet interfaces at both ends of a link must be the same.
  • The duplex configuration depends on rate and negotiation configurations. If the rate configuration is canceled, the duplex configuration is restored to the default configuration. If the negotiation configuration is canceled, both the duplex and rate configurations are restored to their default configurations.
  • To ensure that the interfaces at both ends work properly, configure the same duplex mode for them.
  • The AR6710-L14T2X4 do not support this configuration.

Example

# Before configuring the duplex mode (half duplex or full duplex) of a GE electrical interface, configure the interface to work in non-auto-negotiation mode and set the rate to 10 Mbit/s or 100 Mbit/s.
<HUAWEI> system-view
Enter system view, return user view with return command.
Warning: The current device is single master board. Exercise caution when performing this operation.
[HUAWEI] interface GE0/0/1
[HUAWEI-GE0/0/1] negotiation disable
[HUAWEI-GE0/0/1] speed 100
Info: Set the same speed on the other end.
[HUAWEI-GE0/0/1] duplex half
Info: Set the same duplex mode on the other end.
