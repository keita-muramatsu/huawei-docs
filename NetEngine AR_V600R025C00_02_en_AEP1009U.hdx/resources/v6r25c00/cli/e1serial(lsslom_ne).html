channel-set timeslot-list (E1 interface view)

Function

The channel-set timeslot-list command bundles timeslots of a CE1 interface into a channel-set.

The undo channel-set command unbundles the timeslots of a CE1 interface from a channel-set.

By default, no timeslots of a CE1 interface are bundled into a channel-set.

This command is supported only on the AR8700 series, AR5710-S10T1X2, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series and AR6700-H series.

Format

channel-set set-number timeslot-list slot-list

undo channel-set [ set-number ]

Parameters

Parameter Description Value
set-number

Specifies the number of a channel-set that is formed by bundling timeslots of a CE1 interface.

The value is an integer ranging from 0 to 30.
slot-list

Specifies the number of a timeslot or range of timeslots to be bundled.

You can specify either a single timeslot or a range of timeslots. A comma (,) is used to separate timeslots, and a hyphen (-) is used to specify a timeslot range.

The value is an integer ranging from 1 to 31.

Views

E1 interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

A CE1 interface works in either of the following modes:

  • Channelized mode: The interface is physically divided into 32 timeslots. Timeslots 1 to 31 can be bundled into several channel-sets. Each channel-set functions as an interface whose logical features are the same as a synchronous serial interface. The interface serial command allows you to enter the view of the serial interface that is formed by bundling timeslots.
  • Clear channel mode: The interface is not divided into timeslots and does not support this command. Instead, it is used as a 2.048 Mbit/s serial interface.

Prerequisites

A CE1 interface has been configured to work in channelized mode using the using ce1 command.

Example

# Bundle timeslots 1, 10 to 15, and 18 of E1 0/1/0 into channel-set 1.
<HUAWEI> system-view
[HUAWEI] controller e1 0/1/0
[HUAWEI-E1 0/1/0] using ce1
[HUAWEI-E1 0/1/0] channel-set 1 timeslot-list 1,10-15,18
