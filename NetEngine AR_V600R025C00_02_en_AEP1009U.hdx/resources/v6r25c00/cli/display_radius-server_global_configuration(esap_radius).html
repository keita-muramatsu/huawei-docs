display radius-server global configuration

Function

The display radius-server global configuration command displays the global RADIUS server configuration.

Format

display radius-server global configuration

Parameters

None

Views

All views

Default Level

3: Management level

Usage Guidelines

After the global RADIUS configuration is complete or when RADIUS troubleshooting is performed, you can run this command to check whether the global RADIUS configuration is correct.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the global RADIUS configuration.
<HUAWEI> display radius-server global configuration
  ------------------------------------------------------------------------------
  RADIUS server state detected count                 : 2  
  RADIUS server state detected internal              : 5
  RADIUS server down detect cycle                    : 2
  RADIUS server max non-response interval(Sec)       : 3500                                                    
  RADIUS DTLS idle timeout(Sec)                      : 60
  ------------------------------------------------------------------------------
Table 1 Description of the display radius-server global configuration command output
Item Description
RADIUS server state detected count

Number of RADIUS server status detections.
RADIUS server state detected internal

RADIUS server status detection period.
RADIUS server down detect cycle

Number of times the RADIUS server detection period cycles.
RADIUS server max non-response interval(Sec)

Maximum period during which the RADIUS server does not respond.
RADIUS DTLS idle timeout(Sec)

Idle timeout period of a DTLS session.
