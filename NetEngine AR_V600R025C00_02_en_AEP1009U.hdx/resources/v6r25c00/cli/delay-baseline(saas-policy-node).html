delay-baseline(saas-policy-node view)

Function

The delay-baseline command sets the delay base value for a SaaS policy node.

The undo delay-baseline command deletes the delay base value for a SaaS policy node.

By default, no delay base value (ms) is configured for a SaaS policy node.

Format

delay-baseline value

undo delay-baseline [ value ]

Parameters

Parameter Description Value
delay-baseline value

Sets the delay base value (ms).

The value is an integer ranging from 1 to 1000, in seconds.

Views

saas-policy-node view

Default Level

2: Configuration level

Usage Guidelines

By default, qualified links are selected for SaaS application access. During link evaluation, the QoE score of a link is calculated based on the packet loss rate base value, delay base value, packet loss rate weight, and NQA link detection result. The delay base value configured in the SaaS policy node view takes precedence over that configured in the SaaS cloud access view. If no delay base value is configured in the SaaS policy node view, the delay base value in the SaaS cloud access view is used.

Example

# Create SaaS policy node 1 and set the delay base value to 90 ms.
<HUAWEI> system-view
[HUAWEI] saas-cloud-express
[HUAWEI-saas-cloud-express] saas-policy node 1
[HUAWEI-saas-cloud-express-saas-policy-node-1] delay-baseline 90
