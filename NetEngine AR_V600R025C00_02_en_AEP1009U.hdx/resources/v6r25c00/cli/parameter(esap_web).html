parameter

Function

The parameter command configures the characters in a URL.

The undo parameter command restores the default configuration.

By default, the start character of a URL parameter is a question mark (?), the assignment character is an equal sign (=), and the delimiter between different parameters is an ampersand (&).

Format

parameter { start-mark start-mark-value | assignment-mark assignment-mark-value | isolate-mark isolate-mark-value } *

undo parameter { start-mark start-mark-value | assignment-mark assignment-mark-value | isolate-mark isolate-mark-value } *

Parameters

Parameter Description Value
start-mark start-mark-value

Specifies the start character of a URL parameter.

The value is a string of 1 case-sensitive character and cannot be set to '"'. The default value is '?'.
assignment-mark assignment-mark-value

Specifies the assignment character of a URL parameter.

The value is a string of 1 case-sensitive character and cannot be set to '"'. The default value is '='.
isolate-mark isolate-mark-value

Specifies the delimiter between different parameters.

The value is a string of 1 case-sensitive character and cannot be set to '"'. The default value is '&'.

Views

URL template view

Default Level

2: Configuration level

Usage Guidelines

You can run the parameter command to modify the characters in a URL.

For example, when a user with IP address 10.1.1.11 and MAC address 00e0-fc02-0002 connects to an access device with the system name huawei, the access device redirects the user to http://10.1.1.1?user_mac=00e0-fc02-0002&user_ip=10.1.1.11&sysname=test for Portal authentication. By default, the start character of URL parameters is a question mark (?), the assignment character of URL parameters is an equal sign (=), and the delimiter between URL parameters is an ampersand (&). However, the device does not support question marks (?) in the url (URL template view) command configuration. To resolve this problem, replace the question mark (?) in the URL with another character in the url (URL template view) command configuration, and then run the parameter start-mark parameter-value command to specify this replacement character as the start character of URL parameters. In the following example, the replacement character is a number sign (#).

Alternatively, you can run the url command in the URL template view to set the URL to http://10.1.1.11, and run the url-parameter command to add parameters such as the user MAC address, user IP address, and device system name to the URL. In this case, the parameter command does not need to be configured.

Example

# Specify the number sign (#) as the start character of a URL parameter.
<HUAWEI> system-view
[HUAWEI] url-template name test
[HUAWEI-url-template-test] url http://10.1.1.1#user_mac=00e0-fc02-0002&user_ip=10.1.1.11&sysname=test
[HUAWEI-url-template-test] parameter start-mark #
