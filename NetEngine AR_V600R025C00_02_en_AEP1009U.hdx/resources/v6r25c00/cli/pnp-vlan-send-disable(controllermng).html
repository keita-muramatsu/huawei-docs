pnp startup-vlan send disable

Function

The pnp startup-vlan send disable command disables an interface from transmitting the PnP VLAN ID to a downstream device.

The undo pnp startup-vlan send disable command enables an interface to transmit the PnP VLAN ID to a downstream device.

By default, an interface is enabled to transmit the PnP VLAN ID to a downstream device.

Format

pnp startup-vlan send disable

undo pnp startup-vlan send disable

Parameters

None

Views

Layer 2 10GE interface view, 25GE-L2 view, Layer 2 40GE interface view, Layer 2 GE interface view, Layer 2 multi-GE interface view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

You can run this command to disable an interface from transmitting the PnP VLAN ID to a downstream device.

Example

# Disable an interface from transmitting the PnP VLAN ID to a downstream device.
<HUAWEI> system-view
[HUAWEI] interface 10GE0/0/2
[HUAWEI-10GE0/0/2] pnp startup-vlan send disable
