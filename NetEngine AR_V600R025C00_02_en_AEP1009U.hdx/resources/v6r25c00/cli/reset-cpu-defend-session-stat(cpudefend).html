reset cpu-defend session-car statistics

Function

The reset cpu-defend session-car statistics command clears session CAR statistics.

Format

For AR8100 series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5700-H series, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR5710-S8TWDSE-LTE4EA, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S10T1X2:

reset cpu-defend session-car statistics [ packet-type packet-type ] { all | slot slot-id }

For AR8700 series, AR6700-H series:

reset cpu-defend session-car statistics [ packet-type packet-type ] all

Parameters

Parameter Description Value
packet-type packet-type

Clears session CAR statistics on a specified packet type.

The options are as follows:

  • bgp
  • bgp4plus
  • ospf
  • ospfv3
all

Clears packet statistics for all cards.

-
slot slot-id

Clears session CAR statistics for a specified slot.

NOTE:

This parameter is supported only on the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series and AR5710-S8P1XDSE-2LTE4EA.

The value must be set according to the device configuration.

Views

User view

Default Level

3: Management level

Usage Guidelines

To collect session CAR statistics within a period of time, run the reset cpu-defend session-car statistics command to clear the existing statistics. After a period of time, run the display cpu-defend session-car statistics command to view session CAR statistics.

Example

# Clear all session CAR statistics on the device.
<HUAWEI> reset cpu-defend session-car statistics packet-type bgp all
