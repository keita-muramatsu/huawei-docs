poe anti-interference frequency(remote-unit view)

Function

The poe anti-interference frequency command configures the PoE anti-interference frequency.

The undo poe anti-interference frequency command restores the PoE anti-interference frequency to the default value 50 Hz.

The default PoE anti-interference frequency is 50 Hz.

Format

poe anti-interference frequency { 50 | 60 }

undo poe anti-interference frequency

Parameters

Parameter Description Value
50

Set the PoE anti-interference frequency to 50 Hz.

-
60

Set the PoE anti-interference frequency to 60 Hz.

-

Views

remote-unit view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To use the PoE function in countries or regions where the utility frequency is 60 Hz, run the poe anti-interference frequency 60 command to configure the PoE anti-interference frequency.

Follow-up Procedure

After configuring an RU on the central device, you need to run the commit command to deliver the configuration to the RU or bring the RU online again for the configuration to take effect.

You can run the display remote-unit commit configuration command to check the configurations that are successfully delivered to RUs, and run the display remote-unit commit result command to check configuration delivery results of RUs.

Example

# Set the PoE anti-interference frequency to 60 Hz.
<HUAWEI> system-view
[HUAWEI] remote-unit
[HUAWEI-remote-unit] poe anti-interference frequency 60
