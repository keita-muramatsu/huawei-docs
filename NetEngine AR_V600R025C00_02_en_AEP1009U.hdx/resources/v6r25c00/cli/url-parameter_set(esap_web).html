url-parameter set

Function

The url-parameter set command sets redirection parameters.

The undo url-parameter set command restores the default settings.

By default, the device automatically obtains redirection parameter values.

Format

url-parameter set device-mac mac-address

url-parameter set sysname sysname

url-parameter set device-ip ip-address

url-parameter set device-ip interface interface-type interface-number

undo url-parameter set device-ip

undo url-parameter set device-mac

undo url-parameter set sysname

Parameters

Parameter Description Value
sysname sysname

Specifies the value of the redirection parameter sysname.

The value is a string of 1 to 246 case-sensitive characters, with spaces supported.
device-ip ip-address

Specifies a specific IP address as the redirection parameter.

The value is in dotted decimal notation.
interface interface-type interface-number

Specifies an interface as the redirection parameter.

-
device-mac mac-address

Specifies the value of the redirection parameter device-mac.

The value is in H-H-H format. H is a hexadecimal number that contains one to four digits, such as 00e0 and fc01. If an H contains fewer than four digits, the leftmost digits are padded with 0s. For example, two 0s are added to e0 to form 00e0. The MAC address cannot be set to FFFF-FFFF-FFFF.

Views

URL template view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After running the url-parameter command to configure the parameters to be carried in a URL, you can run the url-parameter set command to set the parameter values. If a specific parameter is not specified in the url-parameter command, the URL does not carry this parameter even if the value of the parameter is set. When device-ip is set to the IP address of an interface and the interface does not have an IP address, the value of device-ip is the IP address of the CAPWAP gateway. If an interface IP address is specified, the URL carries the new IP address after the IP address is changed.

When the device connects to iMaster NCE-Campus, you need to run the url-parameter set device-ip ip-address and url-parameter device-ip ac-ip commands in the URL template to send the device IP address to iMaster NCE-Campus. Otherwise, iMaster NCE-Campus cannot display the re-authentication page.

Precautions

If the same parameter value is specified in multiple commands, the last configured command takes effect. If multiple commands among the url-parameter set device-ip ip-address, url-parameter set device-ip ipv6 ipv6–address, url-parameter set device-ip interface interface-type interface-number and url-parameter set device-ip ipv6 interface interface-type interface-number commands are configured, the last configured command takes effect.

Example

# Set the redirection parameter device-ip to 10.1.1.1.
<HUAWEI> system-view
[HUAWEI] url-template name test
[HUAWEI-url-template-test] url-parameter set device-ip 10.1.1.1
