linkup session

Function

The linkup session anti-attack ratio-threshold command sets the percentage threshold for triggering punishment on a single session in protocol association.

The undo linkup session anti-attack ratio-threshold command restores the default percentage threshold for triggering punishment on a single session in protocol association.

By default, the percentage threshold for triggering punishment is 50%.

Format

linkup session anti-attack ratio-threshold rate-value-percent

undo linkup session anti-attack ratio-threshold

Parameters

Parameter Description Value
anti-attack

Indicates attack defense.

-
ratio-threshold rate-value-percent

Specifies the percentage threshold for triggering punishment in protocol association, that is, the percentage of the CAR value of protocol association.

The value is an integer ranging from 1 to 100. The default value is 50.

Views

Attack defense policy view

Default Level

2: Configuration level

Usage Guidelines

The CAR value for protocol association is shared by sessions of the same protocol type. As a result, when the number of packets of a session increases greatly or the device receives a large number of attack flows matching this session, packets of other sessions of the same protocol may be discarded because the rate limit is exceeded, which affects data transmission and causes service interruption. In this case, you can configure this command to set the percentage threshold for triggering punishment on a single session to ensure services related to these protocol packets can run properly when attacks occur.

The protocol association function triggers punishment detection when the total packet rate of sessions exceeds 80% of the corresponding CAR value for protocol association. If the device detects that the packet rate of a single session exceeds the percentage threshold configured for triggering punishment using the linkup session command, the session is downgraded to be limited by the CAR value of CPCAR. After a period of time, the session joins protocol association again and is limited by the CAR value for protocol association.

The protocol association punishment function takes effect only when at least two sessions are established for a protocol. The punished session joins protocol association after 5 minutes. If the attack persists, the session is punished again.

Example

# In the attack defense policy named test, set the percentage threshold for triggering punishment by protocol association to 20%.
<HUAWEI> system-view
[HUAWEI] cpu-defend policy test
[HUAWEI-cpu-defend-policy-test] linkup session anti-attack ratio-threshold 20
