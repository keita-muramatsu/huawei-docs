force-push

Function

The force-push command enables a pushed URL template or pushed URL.

The undo force-push command disables a pushed URL template or pushed URL.

By default, the pushed URL template or URL is disabled.

Format

force-push { url-template template-name | url url-address }

undo force-push

Parameters

Parameter Description Value
url-template template-name

Specifies the name of a pushed URL template.

The value must be the name of an existing URL template.
url url-address

Specifies a pushed URL.

The value is a string of 1 to 247 case-sensitive characters, with question marks (?) not supported. If the string is enclosed in double quotation marks (" "), the string can contain spaces.

Views

AAA domain view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

When the web page push function is configured, the device redirects a successfully authenticated user to a specified web page when receiving the HTTP or HTTPS packet from the user who accesses web pages. With this function, the device can push advertisement pages to users, obtain user terminal information through the HTTP or HTTPS packets sent by the users, and apply the information to other services. Two methods are available to push web pages:

  1. Use a URL: The device pushes the URL corresponding to a web page.
  2. Use a URL template: The device pushes a URL template, which needs to be created first. The URL template contains the URL of the pushed web page and parameters in the URL.

Prerequisites

To ensure that the configuration takes effect, the URL configured using the url (URL template view) command in the URL template view cannot be a redirection URL.

Precautions

For HTTPS or HTTP packets, the web page push function takes effect only when it is used together with a redirect ACL. If a redirect ACL exists in the user table, a web page is pushed to users when the users' HTTPS or HTTP packets match the redirect ACL rule. Typically, you can authorize the Huawei extended RADIUS attribute HW-Redirect-ACL to users through the RADIUS server to implement a redirect ACL. Alternatively, you can run the redirect-acl command to configure a redirect ACL.

When a pushed URL is configured in a domain, the redirect ACL must also be used.

Example

# Push the URL template abc in the domain test.
<HUAWEI> system-view
[HUAWEI] url-template name abc
[HUAWEI-url-template-abc] quit
[HUAWEI] aaa
[HUAWEI-aaa] domain test
[HUAWEI-aaa-domain-test] force-push url-template abc
