lldp tlv-disable (AP wired port link profile view)

Function

The lldp tlv-disable command disables an AP's wired interface from advertising optional TLVs.

The undo lldp tlv-disable command configures the types of TLVs that an AP's wired interface can advertise.

By default, an AP's wired interface advertises all types of TLVs.

Format

lldp tlv-disable basic-tlv { all | management-address | port-description | system-capability | system-description | system-name }

lldp tlv-disable dot3-tlv power

undo lldp tlv-disable basic-tlv { all | management-address | port-description | system-capability | system-description | system-name }

undo lldp tlv-disable dot3-tlv power

Parameters

Parameter Description Value
all

Configures an AP's wired interface to advertise all optional TLVs contained in basic TLVs.

-
management-address

Advertises the Management-address TLV.

-
port-description

Advertises the Port Description TLV.

-
system-capability

Advertises the System Capabilities TLV.

-
system-description

Advertises the System Description TLV.

-
system-name

Advertises the System Name TLV.

-
dot3-tlv

Advertises the TLVs in the IEEE 802.3 format.

-
power

Configures an AP's wired interface to advertise the Power Via MDI TLV defined by IEEE 802.3 and negotiate the PoE power.

-
basic-tlv

Indicates basic TLVs to be advertised, including:

  • Management-address TLV.
  • Port Description TLV.
  • System Capabilities TLV.
  • System Description TLV.
  • System Name TLV.

-

Views

AP wired port link profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In LLDP, all device information is encapsulated in Link Layer Discovery Protocol data units (LLDPDUs), which are then sent to neighbors. An LLDPDU contains a variety of TLVs. In a TLV, T indicates the information type, L indicates the information length, and V indicates the value or the content to be sent.

Devices exchange LLDPDUs carrying TLVs to obtain neighbor information. The TLVs that can be encapsulated in an LLDPDU include basic TLVs and TLVs in the IEEE 802.3 format.

Basic TLVs are essential for managing network devices. The TLVs in the IEEE 802.3 format are defined by standardization organizations and other organizations, which are used to enhance network device management. You can determine whether to such TLVs in LLDPDUs.

Devices on both ends can have different TLV types configured. You only need to configure TLV types according to networking requirements.

Prerequisites

The LLDP function has been enabled in both the WLAN view and AP wired port link profile view.

Precautions

When the supported TLVs are basic TLVs:

  • If the parameter all is specified, this command cancels advertising all TLVs.
  • If the parameter all is not specified, this command cancels advertising TLVs of only the specified type. To cancel advertising multiple types of TLVs, run this command multiple times.

    This command can be configured when the Ethernet interface works in Layer 3 mode.

Example

# Disable an AP wired interface from advertising the Management-address TLV.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] port-link-profile name port-link1
[HUAWEI-wlan-port-link-prof-port-link1] lldp tlv-disable basic-tlv management-address
