ips signature-action

Function

The ips signature-action signature-id command modifies the action of a single predefined signature.

The ips signature-action command sets actions for predefined signatures in a batch.

The undo ips signature-action command restores the default actions of one or all predefined signatures, that is, actions in the IPS signature database.

The default action for the signature is defined in the intrusion prevention signature database.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

ips signature-action signature-id signature-id { allow | alert | block }

ips signature-action alert

undo ips signature-action [ signature-id signature-id ]

Parameters

Parameter Description Value
signature-id signature-id

Specifies the ID of a predefined signature.

The value is an integer that ranges from 1025 to 16777215.
allow

Indicates that the action of a predefined signature is allow.

-
alert

Indicates that the action of a predefined signature is alert.

-
block

Indicates that the action of a predefined signature is block.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Each predefined signature has a default action, which can be allow, alert, or block. If you want to modify the action of a predefined signature, run the ips signature-action command. You can configure the action of a signature with a specified ID or set the actions of all predefined signatures in a batch.

Precautions

This is a global command that takes effect for each profile.

Priority of the predefined signature actions: action set for a single signature > action set in batches > default action

The exception signature configured in the profile has a higher priority than that configured using the ips signature-action command.

After the IPS signature database is updated, if a predefined signature for which the status, action, or exception signature processing is configured does not exist in the updated IPS signature database, the device retains the related configuration but the configuration does not take effect. You can run the display ips-signature not-in-current-library command to view the configuration of such signatures.

After running this command, run the engine configuration commit command to commit the configuration for the configuration to take effect. You are advised to commit the configuration after all content security configurations are complete.

Example

# Change the action of predefined signature 284860 to block.
<HUAWEI> system-view
[HUAWEI] ips signature-action signature-id 284860 block
# Change the action of all predefined signatures to alert.
<HUAWEI> system-view
[HUAWEI] ips signature-action alert
