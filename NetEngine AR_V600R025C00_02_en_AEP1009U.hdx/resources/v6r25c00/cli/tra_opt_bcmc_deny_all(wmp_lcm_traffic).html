traffic-optimize bcmc deny all

Function

The traffic-optimize bcmc deny all command enables the function of forbidding an air interface to forward downstream broadcast or multicast packets.

The undo traffic-optimize bcmc deny all command is used to disable the function of forbidding an air interface to forward downstream broadcast or multicast packets.

By default, the function of forbidding an air interface to forward downstream broadcast or multicast packets is disabled.

Format

traffic-optimize bcmc deny all [ except mdns ]

undo traffic-optimize bcmc deny all

Parameters

Parameter Description Value
except

If this parameter is configured, mDNS packets are allowed to pass through when the air interface is forbidden to forward these broadcast or multicast packets.

-
mdns

If this parameter is configured, mDNS packets are allowed to pass through when the air interface is forbidden to forward these broadcast or multicast packets.

-

Views

Traffic profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

On an IP network, the ARP, ND, and DHCP protocols are the basic network protocols and serve as the basis for packet forwarding on the entire network. Broadcast or multicast packets of protocols other than these basic network protocols are not mandatory on an IP network. When no services rely on transmission of these broadcast or multicast packets on the network, you can run this command to forbid an air interface to forward these broadcast or multicast packets to improve the air interface performance.

Precautions

Before using the traffic-optimize bcmc deny all command to forbid an AP to forward downstream broadcast or multicast packets, run the undo learn-client-address { ipv4 | ipv6 } disable command to enable STA address learning and the traffic-optimize bcmc unicast-send { arp | nd | dhcp } * command to configure the function of converting broadcast or multicast packets to unicast packets on the air interface. Otherwise, the ARP, ND, and DHCP packets may fail to be forwarded.

Example

# Enable the function of forbidding an air interface to forward downstream broadcast or multicast packets in the traffic profile p1.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] traffic-profile name p1
[HUAWEI-wlan-traffic-prof-p1] traffic-optimize bcmc deny all
