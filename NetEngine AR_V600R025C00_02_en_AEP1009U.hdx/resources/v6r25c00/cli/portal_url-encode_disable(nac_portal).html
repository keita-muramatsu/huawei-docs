portal url-encode disable

Function

The portal url-encode disable command disables URL encoding and decoding.

The undo portal url-encode disable command enables URL encoding and decoding.

By default, URL encoding and decoding are enabled.

Format

portal url-encode disable

undo portal url-encode disable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To ensure web application security, data from untrustworthy sources must be encoded before being sent to clients. URL encoding is most commonly used in web applications. After the undo portal url-encode disable command is run to enable URL encoding and decoding, some special characters in redirect URLs are converted to secure formats (escape characters). In this way, the client does not regard the special characters as syntax symbols or instructions, preventing the expected semantics from being changed and preventing cross-site scripting attacks and various injection attacks.

Precautions

When the URL encoding and decoding function is enabled, some servers do not support escape characters in redirect URLs. When configuring special characters, check whether the servers support escape characters.

Example

# Disable URL encoding and decoding.
<HUAWEI> system-view
[HUAWEI] portal url-encode disable
