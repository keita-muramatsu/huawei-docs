display packet-replication instance

Function

The display packet-replication instance command displays packet replication instance information.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

display packet-replication instance { inbound | outbound } [ src-ip src-ip-address | dst-ip dst-ip-address | src-port src-port | dst-port dst-port | vpn-instance vpn-instance | protocol protocol-num ] * [ verbose ]

Parameters

Parameter Description Value
inbound

Specifies the inbound direction.

-
outbound

Indicates the outbound direction.

-
src-ip src-ip-address

Specifies the source IP address.

The value is in dotted decimal notation.
dst-ip dst-ip-address

Specifies a destination address.

The value is in dotted decimal notation.
src-port src-port

Specifies the source port.

The value is an integer ranging from 0 to 65535.
dst-port dst-port

Specifies the destination port number.

The value is an integer ranging from 0 to 65535.
vpn-instance vpn-instance

Specifies the name of a VPN instance.

The value is a string of 1 to 31 case-sensitive characters without spaces. The VPN instance name cannot be _public_. The character string can contain spaces if it is enclosed with double quotation marks (").
protocol protocol-num

Specifies a forwarding protocol.

The value is an integer in the range from 0 to 128. Common protocols include the following:

  • 4: IPinIP
  • 6: TCP
  • 17: UDP
  • 47: GRE
  • 50: ESP
  • 51: AH
verbose

Indicates the details.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run this command to view packet replication instance information. If no parameter is specified, the system displays information about all instances.
