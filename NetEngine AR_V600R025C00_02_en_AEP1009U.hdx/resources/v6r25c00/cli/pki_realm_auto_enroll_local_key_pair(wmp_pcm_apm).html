pki realm auto-enroll local-key-pair

Function

The pki realm auto-enroll local-key-pair command configures the RSA or ECC key pair used in an SCEP certificate request and the corresponding modulus.

The undo pki realm auto-enroll local-key-pair command deletes the RSA or ECC key pair used in an SCEP certificate request.

By default, no key pair used in an SCEP certificate request is configured.

Format

pki realm realm-name auto-enroll rsa local-key-pair rsa-modulus-size

pki realm realm-name auto-enroll ecc local-key-pair ecc-hostkey-length

undo pki realm realm-name auto-enroll rsa local-key-pair

undo pki realm realm-name auto-enroll ecc local-key-pair

Parameters

Parameter Description Value
rsa rsa-modulus-size

Specifies the modulus of an RSA key pair.

The value is an integer that can be 3072 or 4096, in bits.

A greater modulus indicates higher security. However, it takes a longer time to generate and use key pairs of a greater modulus.
realm realm-name

Specifies the name of a PKI realm.

The value is a string of 1 to 50 case-sensitive characters.
ecc ecc-hostkey-length

Specifies the modulus of an ECC key pair.

The value is an integer that can be 256, 384, or 521, in bits.

A greater modulus indicates higher security. However, it takes a longer time to generate and use key pairs of a greater modulus.

Views

AP PKI realm profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The PKI entity that requests a certificate from the CA using SCEP must contain a public key. Run this command to configure the ECC or RSA key pair.

Precautions

  • An RSA key pair can be referenced by only one PKI realm.
  • An ECC key pair can be referenced by only one PKI realm.
  • An ECC key pair and an RSA key pair cannot be configured on the same PKI realm. The latest configuration overrides the previous one.

Example

# Configure the ECC key pair used in an SCEP certificate request.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-pki-profile name default
[HUAWEI-wlan-ap-pki-prof-default] pki realm r1 auto-enroll ecc local-key-pair 256
# Configure an RSA key pair used in an SCEP certificate request.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-pki-profile name default
[HUAWEI-wlan-ap-pki-prof-default] pki realm r1 auto-enroll rsa local-key-pair 3072
