remote-unit macsec enable port(remote-unit view)

Function

The remote-unit macsec enable port command enables MACsec on an RU interface and configures the static CKN and CAK.

The undo remote-unit macsec enable port command disables MACsec on an RU interface and deletes the static CKN and CAK.

By default, MACsec is disabled on an RU interface, and no static CKN or CAK is configured.

Format

remote-unit { ru-id1 [ to ru-id2 ] } &<1-8> macsec enable ckn string-name cak string-key port { port-id1 [ to port-id2 ] } &<1-34>

undo remote-unit { ru-id1 [ to ru-id2 ] } &<1-8> macsec enable port { port-id1 [ to port-id2 ] } &<1-34>

Parameters

Parameter Description Value
ru-id2

Specifies the ID of the last RU configured in batches. The value must be greater than or equal to the value of ruid1.

The value is an integer ranging from 0 to 16777215.
ckn string-name

Specifies the secure Connectivity Association Key Name (CKN).

CKN. The value is a hexadecimal string of an even number (2 to 64) of characters (at least one digit and one letter).
cak string-key

Specifies the secure Connectivity Association Key (CAK).

CAK. The value is a hexadecimal string of an even number (32 to 64) of characters in plaintext (containing at least one digit and one letter and different from the CKN) or a ciphertext string of 148 to 188 characters starting and ending with %@%# or %+%#.
port port-id1

Specifies the index of an interface on an RU.

The value is an integer in the range from 1 to 34. If the specified interface index is larger than the largest one on the RU, the command is not issued to the RU. port-id indicates the port ID of an RU, which may be different from the physical port number printed on the panel. For example, if the downlink port numbers are 1 to 8 and the uplink port numbers are 9 to 10 on the panel, set port-id to an integer in the range from 1 to 10 according to the actual port for connection. If the downlink port numbers are 1 to 8 and the uplink port numbers are 1 to 2 on the panel, set port-id to an integer in the range from 1 to 10 (1 to 8: downlink ports; 9: uplink port 1; 10: uplink port 2).
port-id2

Specifies the index of an interface on an RU.

The value is an integer in the range from 1 to 34. If the specified interface index is larger than the largest one on the RU, the command is not issued to the RU. port-id indicates the port ID of an RU, which may be different from the physical port number printed on the panel. For example, if the downlink port numbers are 1 to 8 and the uplink port numbers are 9 to 10 on the panel, set port-id to an integer in the range from 1 to 10 according to the actual port for connection. If the downlink port numbers are 1 to 8 and the uplink port numbers are 1 to 2 on the panel, set port-id to an integer in the range from 1 to 10 (1 to 8: downlink ports; 9: uplink port 1; 10: uplink port 2).
remote-unit ru-id1

Specifies the ID of the first RU configured in batches.

The value is an integer ranging from 0 to 16777215.

Views

remote-unit view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The MACsec configuration can be delivered to RUs through the central device.

Precautions

After configuring an RU on the central device, you need to run the commit command to deliver the configuration to the RU or bring the RU online again for the configuration to take effect.

You can run the display remote-unit commit configuration command to check the configurations that are successfully delivered to RUs, and run the display remote-unit commit result command to check configuration delivery results of RUs.

Example

# Enable MACsec on interface 1 of RU 0, and configure the CKN and CAK.
<HUAWEI> system-view
[HUAWEI] remote-unit
[HUAWEI-remote-unit] remote-unit 0 macsec enable ckn f1c3b2a4d6d9a7c5b4e1ab56dc21ed79ac97be533671dcab2678ac55cf71aced cak ab2145369adcadef69512347adceb210 port 1
