hrp authentication-key

Function

The hrp authentication-key command configures the authentication key for packets transmitted between the heartbeat interfaces of the active and standby devices.

The undo hrp authentication-key command deletes the configured authentication key.

By default, no authentication key is configured on the active and standby devices.

Format

hrp authentication-key key

undo hrp authentication-key

Parameters

Parameter Description Value
key

Specifies the authentication key for packets transmitted between the heartbeat interfaces of the active and standby devices.
  • The value is a string of 8 to 16 characters or 128 characters. The value is case sensitive and can contain special characters except question marks (?). If the name contains spaces, use double quotation marks ("") to enclose the key. The system converts the character string into a 128-character ciphertext and saves it in the configuration file. If the value is a string of 128 characters, the character string must be encrypted.
  • To improve security, the key must meet the minimum complexity requirement. That is, the key must contain at least two types of the following characters: uppercase letters (A to Z), lowercase letters (a to z), digits (0 to 9), and special characters (such as!, @, #, $, and %).

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In hot standby networking, two devices send and receive HRP packets to notify each other of their own configuration and status information. The HRP packets include heartbeat packets, heartbeat link detection packets, configuration and entry backup packets, and configuration consistency check packets. To prevent malicious packet attacks and prevent data from being forged or tampered with, you can authenticate the active and standby devices by configuring the same authentication key before configuring active/standby.

The HRP/4/AUTHENTICATION_KEY log is recorded when the authentication keys of the active and standby devices are different.

Configuration Impact

After the authentication key is configured, the active and standby devices verify the authentication key to authenticate each other during the establishment of a hot standby relationship. The authentication mode is HMAC-SHA256. After the hot standby relationship is established, the key is used for identity authentication before any packets are exchanged between the heartbeat interfaces of the active and standby devices.

Example

# Set the authentication key for packets transmitted between master and backup devices heartbeat interfaces to YsHsjx_202206.
<HUAWEI> system-view
[HUAWEI] hrp authentication-key YsHsjx_202206
