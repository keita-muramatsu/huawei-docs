ppp timer negotiate

Function

The ppp timer negotiate command sets a timeout period for PPP negotiation.

The undo ppp timer negotiate command restores the default timeout period of PPP negotiation.

By default, the timeout period of PPP negotiation is 3 seconds.

Format

ppp timer negotiate seconds

undo ppp timer negotiate

Parameters

Parameter Description Value
seconds

Specifies a timeout period.

The value is an integer ranging from 1 to 10, in seconds.

Views

Dialer interface view, POS interface view, Serial interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

PPP is a link layer protocol used to transmit data over P2P links. PPP supports MRU negotiation. If the two ends of a PPP link are configured with the MTUs, you must enable PPP MRU negotiation for the two ends to negotiate the MTU and then exchange data.

Running the ppp timer negotiate command sets a timeout period of PPP negotiation. If PPP fails to receive a reply packet within the configured timeout period, it resends the packet.

Prerequisites

PPP has been configured as the link layer protocol of the interface.

Configuration Impact

If this command is run more than once, the latest configuration overrides the previous one. After the configuration completes, the negotiation timeout period changes.

Precautions

After the configuration is complete, run the shutdown and undo shutdown commands in sequence in the corresponding interface view to restart the interface for the configuration to take effect.

Example

# Set the timeout period of PPP negotiation on a Dialer interface to 5 seconds.
<HUAWEI> system-view
[HUAWEI] interface Dialer 95
[HUAWEI-Dialer95] ppp timer negotiate 5
