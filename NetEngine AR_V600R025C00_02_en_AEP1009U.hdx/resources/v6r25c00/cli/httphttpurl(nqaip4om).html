http-url (HTTP test instance)

Function

The http-url command sets a destination address URL for an NQA HTTP test instance.

The undo http-url command restores the default setting.

By default, no URL is configured.

Format

http-url ipv4 url [ proxy { ipv4 ipv4Address [ port port ] | url url } ]

undo http-url

undo http-url ipv4 url [ proxy { ipv4 ipv4Address [ port port ] | url url } ]

Parameters

Parameter Description Value
url url

Indicates that the proxy is in the URL format.

The value is a string of 8 to 230 characters in the format of http://hostname[:port]. The value of port is an integer ranging from 1 to 65535. The default port number is 80.
proxy

Sets the proxy.

-
ipv4 url

Specifies that the IP address type used by the current URL after domain name resolution is IPv4.

The value is a string of 8 to 230 characters in the format of protocol://hostname[:port][/path]. The value of port is an integer ranging from 1 to 65535. The default HTTP port number is 80, and the default HTTPS port number is 443.
ipv4 ipv4Address

Specifies the IPv4 address of an agent.

The value is in dotted decimal notation.
port port

Specifies the proxy port.

The value is an integer ranging from 1 to 65535. The default port number is 80.

Views

NQA view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

For an HTTP test instance, the server is specified by running the http-url command to configure a destination address for the NQA test instance. The protocol header configured in the http-url command can only be HTTP or HTTPS. The protocol header type is specified by the protocol configuration.

  • If protocol is set to HTTPS in the protocol command, only HTTPS addresses can be configured in the URL.
  • If protocol is set to HTTP in the protocol command, only HTTP addresses can be configured in the URL.

Prerequisites

Before configuring http-url, run the protocol command to specify the protocol header type in the URL. The default protocol header type is HTTPS.

Configuration Impact

  • If this command is not configured, the test instance cannot be started.
  • If the destination address has been configured for a test instance, running the http-url command again overrides the previous configuration.

Precautions

If you change the value of this parameter during the running of the test instance, the system prompts you whether to stop the test instance. Press "Y" or "N" as required.

  • If you enter Y, the current test instance is stopped and parameters are modified. After you submit the modification, the modified parameters take effect. To restart the test instance, run the start command.
  • If you enter N, the parameter modification fails and the current test instance continues to run.

Example

# Set the URL to be probed by the test instance named user test.
<HUAWEI> system-view
[HUAWEI] nqa test-instance user test
[HUAWEI-nqa-user-test] test-type http
[HUAWEI-nqa-user-test] http-url ipv4 https://huawei.com proxy url http://proxy.com
