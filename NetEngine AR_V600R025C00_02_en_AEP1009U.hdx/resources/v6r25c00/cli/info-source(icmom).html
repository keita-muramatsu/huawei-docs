info-center source channel

Function

The info-center source channel command sets rules for outputting information through information channels.

The undo info-center source channel command deletes the rules for outputting information through information channels.

The default configuration for logs, traps, and debugging information varies according to information channels. You can run the display info-center channel command to check the configuration of the default module of the corresponding channel.

Format

info-center source { module-name | default } channel { channel-number | channel-name } [ log { state { off | on } | level log-level } * | trap { state { off | on } | level trap-level } * | debug { state { off | on } | level dbg-level } * ] *

undo info-center source { module-name | default } channel { channel-number | channel-name } [ log { state | level } * | trap { state | level } * | debug { state | level } * ] *

Parameters

Parameter Description Value
module-name

Specifies the name of a module.

You can query all the currently supported modules in Log Reference. In this manual, the log format is simplified as module name/log severity/information keyword, such as INFO/4/FILE_DELETE. (INFO indicates the module name.).

The value is a string of 1 to 31 case-insensitive characters, spaces not supported.

Usage Guidelines

Usage Scenario

  • A default record for each information channel exists. The module name is default, and the module ID is 0xffffffff. The default configuration for logs, traps, and debugging information may vary according to information channels. You can run the display info-center channel command to check the default configuration. The default record is used if a module does not have any specific configuration record in the associated channel.
  • If a module generates a large number of logs, traps, or debugging information in a short period of time, you can suppress information by specifying the corresponding parameters. For example, you can specify the level severity parameter to filter out information of lower levels, or specify the state off parameter to disable the module from sending logs, traps, and debugging information.

Example:

  1. If the configuration record of the CLI module of the loghost channel does not exist on the device, the CLI module of the loghost channel uses the configuration of the default module of the channel. Run the display info-center channel [ <channel-number> | <channel-name> ] command and set channel-number to 2 or channel-name to loghost. The configuration of the default module of the loghost channel is as follows: The state for outputting logs is on and the allowed information level is informational; the state for outputting traps is on and the allowed information level is debugging; the state for outputting debugging information is off.
  2. Run the info-center source <module-name> channel <channel-name> log level <severitylog> trap state off debug state off command and set module-name to cli, channel-name to loghost, and severitylog to informational. The configuration of the CLI module of the loghost channel is changed as follows: The state for outputting logs is on and the allowed information level is informational; the state for outputting traps is off; the state for outputting debugging information is off. This means that the CLI module in the loghost direction records only logs with the severity of informational or higher, but does not record traps or debugging information.
  3. Run the info-center source <module-name> channel <channel-name> log level <severitylog> trap state off debug state off command again and set module-name to cli, channel-name to loghost, and severitylog to debugging. The configuration of the CLI module of the loghost channel is changed as follows: The state for outputting logs is on and the allowed information level is debugging; the state for outputting traps is off; the state for outputting debugging information is off. This means that the CLI module in the loghost direction records all logs, but does not record traps or debugging information.

Example

# Enable the log function of the CLI module in the SNMP agent channel and set the lowest level of output information to emergencies.
<HUAWEI> system-view
[HUAWEI] info-center source cli channel snmpagent log level emergencies
