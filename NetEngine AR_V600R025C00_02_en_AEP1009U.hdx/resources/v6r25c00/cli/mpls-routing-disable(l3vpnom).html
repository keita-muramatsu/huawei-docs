mpls routing-disable (VPN instance IPv4 address family view/VPN instance IPv6 address family view)

Function

The mpls routing-disable command disables the function to generate and advertise MPLS-encapsulated routes in an L3VPN scenario.

The undo mpls routing-disable command restores the function to generate and advertise MPLS-encapsulated routes in an L3VPN scenario.

In L3VPN service scenarios, the function to generate and advertise MPLS-encapsulated routes is enabled by default.

Format

mpls routing-disable

undo mpls routing-disable

Parameters

None

Views

VPN instance IPv4 address family view, VPN instance IPv6 address family view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In L3VPN service scenarios, MPLS route encapsulation is enabled by default. In some scenarios, however, the peer device may not want to receive MPLS-encapsulated routes from an instance. For example, a network migration project may involve both the SRv6 scenario and MPLS-SRv6 coexistence scenario. In the MPLS-SRv6 coexistence scenario, both IPv4 and IPv6 peers are configured in the BGP VPNv4 address family view. As a result, the local PE receives two copies of VPN routes from the remote PE, one carrying the MPLS VPN label and the other carrying the SRv6 SID. However, the IPv4 and IPv6 BGP peer configurations cannot be changed during SRv6 deployment. As a result, a PE receives two copies of routes, of which MPLS routes are useless. To prevent this situation, run this command to disable the function of generating and advertising MPLS-encapsulated routes.

Prerequisites

An RD has been configured using the route-distinguisher command.

Precautions

This configuration may interrupt services.

Example

# Disable the function to generate and advertise MPLS-encapsulated routes in the VPN instance IPv6 address family view.
<HUAWEI> system-view
[HUAWEI] ip vpn-instance vrf1
[HUAWEI-vpn-instance-vrf1] ipv6-family
[HUAWEI-vpn-instance-vrf1-af-ipv6] route-distinguisher 200:1
[HUAWEI-vpn-instance-vrf1-af-ipv6] mpls routing-disable
Warning: This operation may cause services to be interrupted. Continue? [Y/N]:Y
# Disable the function to generate and advertise MPLS-encapsulated routes in the VPN instance IPv4 address family view.
<HUAWEI> system-view
[HUAWEI] ip vpn-instance vrf1
[HUAWEI-vpn-instance-vrf1] ipv4-family
[HUAWEI-vpn-instance-vrf1-af-ipv4] route-distinguisher 100:1
[HUAWEI-vpn-instance-vrf1-af-ipv4] mpls routing-disable
Warning: This operation may cause services to be interrupted. Continue? [Y/N]:Y
