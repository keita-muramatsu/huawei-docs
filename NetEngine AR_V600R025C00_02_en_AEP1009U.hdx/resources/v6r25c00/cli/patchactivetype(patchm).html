patch active patch-type

Function

The patch active patch-type command activates a patch unit that requires secondary activation.

Format

patch active patch-type np-firmware

Parameters

Parameter Description Value
np-firmware

Specifies an NP patch.

-

Views

User view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

The patch active patch-type command activates a patch unit that requires secondary activation.

Prerequisites

The patch package has been loaded using the patch load PkgNameall run command.

Configuration Impact

After the patch load all run command is executed, some patch units are not activated. You need to run the patch active patch-type command to activate the patch units that require secondary activation.

Precautions

For patch units that require secondary activation, run this command to activate them.

Example

# Activate a patch unit that requires secondary activation.
<HUAWEI> patch active patch-type np-firmware
Info: Operating, please wait for a moment...done.
Info: Succeeded in activating the patch.
