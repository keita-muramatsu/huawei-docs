remote-unit macsec policy port(remote-unit view)

Function

The remote-unit macsec policy port command configures a MACsec security policy for RUs in a batch.

The undo remote-unit macsec policy port command restores the default MACsec security policy for RUs in a batch.

By default, the MACsec policy is must-secure for RUs.

Format

remote-unit { ru-id1 [ to ru-id2 ] } &<1-8> macsec policy { should-secure | must-secure } port { port-id1 [ to port-id2 ] } &<1-34>

undo remote-unit { ru-id1 [ to ru-id2 ] } &<1-8> macsec policy port { port-id1 [ to port-id2 ] } &<1-34>

Parameters

Parameter Description Value
ru-id2

Specifies the ID of the last RU configured in batches. The value must be greater than or equal to the value of ruid1.

The value is an integer ranging from 0 to 16777215.
should-secure

Indicates that traffic is not blocked before MKA negotiation succeeds.

-
must-secure

Indicates that traffic is blocked before MKA negotiation succeeds.

-
port port-id1

Specifies the index of an interface on an RU.

The value is an integer in the range from 1 to 34. If the specified interface index is larger than the largest one on the RU, the command is not issued to the RU. port-id indicates the port ID of an RU, which may be different from the physical port number printed on the panel. For example, if the downlink port numbers are 1 to 8 and the uplink port numbers are 9 to 10 on the panel, set port-id to an integer in the range from 1 to 10 according to the actual port for connection. If the downlink port numbers are 1 to 8 and the uplink port numbers are 1 to 2 on the panel, set port-id to an integer in the range from 1 to 10 (1 to 8: downlink ports; 9: uplink port 1; 10: uplink port 2).
port-id2

Specifies the index of an interface on an RU.

The value is an integer in the range from 1 to 34. If the specified interface index is larger than the largest one on the RU, the command is not issued to the RU. port-id indicates the port ID of an RU, which may be different from the physical port number printed on the panel. For example, if the downlink port numbers are 1 to 8 and the uplink port numbers are 9 to 10 on the panel, set port-id to an integer in the range from 1 to 10 according to the actual port for connection. If the downlink port numbers are 1 to 8 and the uplink port numbers are 1 to 2 on the panel, set port-id to an integer in the range from 1 to 10 (1 to 8: downlink ports; 9: uplink port 1; 10: uplink port 2).
remote-unit ru-id1

Specifies the ID of the first RU configured in batches.

The value is an integer in the range from 0 to 16777215.

Views

remote-unit view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The MACsec policy determines the plaintext packet bypass mode after MKA negotiation is started.

Security policy description:

• must-secure: Discards all plaintext packets after MKA negotiation is started. After the negotiation succeeds, packets are encrypted and decrypted normally.

• should-secure: Permits plaintext packets before MKA negotiation succeeds. After the negotiation succeeds, plaintext packets are discarded and packets are encrypted and decrypted normally.

Follow-up Procedure

After configuring an RU on the central device, you need to run the commit command to deliver the configuration to the RU or bring the RU online again for the configuration to take effect.

You can run the display remote-unit commit configuration command to check the configurations that are successfully delivered to RUs, and run the display remote-unit commit result command to check configuration delivery results of RUs.

Example

# Set the MACsec policy of port 1 on RU 1 to must-secure.
<HUAWEI> system-view
[HUAWEI] remote-unit
[HUAWEI-remote-unit] remote-unit 1 macsec policy must-secure port 1
