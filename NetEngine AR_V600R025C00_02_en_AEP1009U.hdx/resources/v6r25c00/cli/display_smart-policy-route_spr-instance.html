display smart-policy-route spr-instance

Function

The display smart-policy-route spr-instance command displays information about SPR instances on a device.

Format

display smart-policy-route spr-instance all

display smart-policy-route spr-instance { { dest-site site-id } | { vpn-instance vpn-instance-name } | { spr-policy node-index } } *

display smart-policy-route spr-instance { { ip prefix [ mask-length ] } | { vpn-instance vpn-instance-name } | { spr-policy node-index } } *

display smart-policy-route spr-instance { { ipv6 ipv6-prefix [ ipv6-mask-length ] } | { vpn-instance vpn-instance-name } | { spr-policy node-index } } *

Parameters

Parameter Description Value
dest-site site-id

Specifies the index of a site.

The value is an integer from 1 to 65535.
vpn-instance vpn-instance-name

Specifies the name of a VPN instance.

The value is a string of 1 to 31 case-sensitive characters. If spaces are used, the string must be enclosed in double quotation marks (" ").
spr-policy node-index

Specifies the index of a policy profile.

The value is an integer that ranges from 1 to 30000.
ip prefix mask-length

Specifies the destination IP address.

The prefix address is in dotted decimal notation.

The subnet mask length is an integer in the range from 0 to 32.
ipv6 ipv6-prefix ipv6-mask-length

Specifies the destination IPv6 address.

The prefix address is a 32-digit hexadecimal number in the format of X:X:X:X:X:X:X:X.

The mask length is an integer that ranges from 0 to 128.
all

Displays information about all SPR instances.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

After an SPR policy profile is configured and applied to a VPN, an SPR instance is generated for route selection when a remote site is created. You can run the display smart-policy-route spr-instance command to check the SPR instance generated on the device and the final route selection result.

When you specify the IP address and VPN to query the route selection result, the device searches for the next-hop site based on the IP address and VPN, and displays all SPR instances generated for the site and the final route selection result.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display SPR instance information generated on the device based on the destination IP address.
<HUAWEI> system-view
[HUAWEI] ip vpn-instance vpn1
[HUAWEI-vpn-instance-vpn1] return
<HUAWEI> display smart-policy-route spr-instance vpn-instance vpn1 ip 1.1.1.1 24
