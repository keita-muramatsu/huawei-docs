gre preempt

Function

The gre preempt enable command enables the preemption function for the primary and backup EoGRE tunnels.

The undo preempt enable command disables preemption of the primary and backup EoGRE tunnels.

The gre preempt delay command configures a preemption delay for the primary and backup EoGRE tunnels.

The undo gre preempt delay command restores the default preemption delay.

By default, EoGRE tunnel preemption is disabled.

After the preemption function is enabled, the default delay is 60s.

Format

gre preempt delay delay-time

gre preempt enable

undo gre preempt delay [ delay-time ]

undo gre preempt enable

Parameters

Parameter Description Value
delay-time

Specifies a preemption delay for the primary and backup EoGRE tunnels.

The value is an integer ranging from 0 to 3600, in seconds.

Views

VE interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In a scenario where primary and backup EoGRE tunnels are configured, the primary EoGRE tunnel is in the standby state due to a fault. By default, the primary EoGRE tunnel does not proactively switch to the forwarding state after the tunnel recovers. To enable the primary tunnel to switch to the forwarding state after the tunnel recovers, run the gre preempt enable command to enable preemption for the primary and backup EoGRE tunnels and set a preemption delay.

  • To prevent frequent switchovers between the primary and backup EoGRE tunnels caused by frequent Up/Down transitions of the tunnel interface bound to the VE interface after the primary tunnel recovers, run the gre preempt delay delay-timecommand to set a preemption delay.
  • If you want the primary tunnel to switch to the forwarding state immediately after it recovers, set the preemption delay to 0.

Prerequisites

A VE interface has been created using the interface command.

Precautions

Preemption of the primary and backup EoGRE tunnels takes effect only when a VE interface is bound to two tunnel interfaces.

Example

# Enable the preemption function for the primary and backup EoGRE tunnels.
<HUAWEI> system-view
[HUAWEI] interface virtual-ethernet 0/0/0
[HUAWEI-Virtual-Ethernet0/0/0] gre preempt enable
# Set the preemption delay of the primary and backup EoGRE tunnels to 70 seconds.
<HUAWEI> system-view
[HUAWEI] interface virtual-ethernet 0/0/0
[HUAWEI-Virtual-Ethernet0/0/0] gre preempt enable
[HUAWEI-Virtual-Ethernet0/0/0] gre preempt delay 70
