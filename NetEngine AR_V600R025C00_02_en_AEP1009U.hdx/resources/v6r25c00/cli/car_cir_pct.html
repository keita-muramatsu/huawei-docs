car cir pct

Function

The car cir pct command configures the base value of the interface bandwidth percentage in a traffic behavior.

The undo car command deletes the traffic policing action from a traffic behavior.

By default, traffic policing is not configured in a traffic behavior.

Format

car cir pct cir-percentage [ pir pct pir-percentage ] hierarchical-car [ cbs cbs-value pbs pbs-value ] share mode color-aware

car cir pct cir-percentage [ pir pct pir-percentage ] hierarchical-bandwidth [ cbs cbs-value pbs pbs-value | share | mode color-blind ] *

undo car

Parameters

Parameter Description Value
pir

Specifies a peak information rate (PIR).

-
pct cir-percentage

Specifies the percentage of the available committed information bandwidth, that is, the average percentage of traffic that can pass through.

The value is an integer that ranges from 1 to 100.
pct pir-percentage

Specifies the percentage of the available peak burst bandwidth, that is, the percentage of the peak burst traffic that can pass through instantaneously.

The value is an integer that ranges from 1 to 100.
hierarchical-car

Indicates traffic policing based on the upper layer.

-
cbs cbs-value

Specifies the committed burst size (CBS), which is the average volume of burst traffic that can pass through an interface.

The value is an integer that ranges from 10000 to 4194304.
pbs pbs-value

Specifies the peak burst size (PBS), which is the maximum volume of burst traffic that can pass through an interface.

The value is an integer that ranges from 10000 to 4194304.
share

Indicates the level-1 shared CAR. If a traffic behavior is bound to a traffic classifier that contains multiple matching rules, all traffic matching the traffic classifier is restricted by the level-1 shared CAR.

-
mode

Specifies the color mode for traffic policing.

-
color-aware

Specifies the color-aware mode. In color-aware mode, the original packet color affects the traffic policing action.

-
hierarchical-bandwidth

Indicates the bandwidth based on the upper layer.

-
color-blind

Specifies the color-blind mode. In color-blind mode, the original packet color does not affect the traffic policing action.

-

Views

Traffic behavior view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

  • The hierarchical-car parameter applies to hierarchical CAR HQoS on the inbound interface to specify CAR actions for parent and child traffic policies.
  • The hierarchical-bandwidth parameter applies to hierarchical CAR on the outbound interface, parent and child traffic policies, CBQ traffic policies, and common traffic policies, and specifies CAR actions for them.

Precautions

  • When hierarchical-car is specified, the base values of cir-percentage and pir-percentage are as follows:
    • In the parent traffic policy, their base values are both the CIR value (configured using the qos car inbound decap-process command) of the CAR action defined on an interface.
    • In the child traffic policy, their base values are both the CIR value of the CAR action defined in the parent traffic policy.
  • When hierarchical-bandwidth is specified and applied to parent and child traffic policies, you can configure hierarchical-bandwidth in both traffic policies, only in the child traffic policy, or only in the parent traffic policy. The base values of cir-percentage and pir-percentage are as follows:
    • In the parent traffic policy, their base values are the traffic shaping bandwidth value (configured using the qos lr command) defined on an interface. If the bandwidth value is not configured, the base value is the interface bandwidth.
    • In the child traffic policy, their base values are the subscriber queue bandwidth values defined in the parent traffic policy, that is, the values of cir-value and pir-value configured in the subscriber queue profile of the parent traffic policy using the user-queue command.
  • When hierarchical-bandwidth is specified and applied to a CBQ traffic policy or a common traffic policy, the base values of cir-percentage and pir-percentage are the traffic shaping bandwidth value (configured using the qos lr command) defined on an interface. If the bandwidth value is not configured, the base value is the interface bandwidth.
  • The default settings for green, yellow, and red packets are pass, pass, and discard, respectively.

Example

# Set the base value of the interface bandwidth percentage to the interface bandwidth in the traffic behavior tb1.
<HUAWEI> system-view
[HUAWEI] traffic behavior tb1
[HUAWEI-behavior-tb1] car cir pct 80 pir pct 80 hierarchical-bandwidth
