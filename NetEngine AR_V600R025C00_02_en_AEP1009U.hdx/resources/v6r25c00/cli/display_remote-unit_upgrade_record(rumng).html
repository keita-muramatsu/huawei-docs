display remote-unit upgrade

Function

The display remote-unit upgrade command displays upgrade information of an RU.

Format

display remote-unit upgrade record

Parameters

Parameter Description Value
record

Displays the upgrade records of an RU.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

An RU has three types of firmware: APP firmware (controlling the forwarding process, parsing XLDP packets, and processing configurations), PoE firmware, and BIOS firmware. All three types of firmware can be upgraded. System software packages or patches (containing firmware) of the central device can be used to upgrade RUs.

You can run this command to view the upgrade information about RUs. The information includes the firmware version of an RU connected to the central device, information about the RUs that fail to be upgraded and enter the cooldown period, information about RUs which have the firmware package of the new version successfully pre-loaded and wait to be reset, information about RUs that are being upgraded, and the upgrade progress in percentage. After the upgrade is complete, you can run this command to check upgrade records.

If an RU fails to be upgraded, it enters the cooldown period. You can upgrade it again only after the cooldown period ends.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display remote module upgrade records.
<HUAWEI> system-view
[HUAWEI] display remote-unit upgrade record
------------------------------------------------------------------------------- 
StartTime             ConnectInterface        Firmware   UpdateResult 
------------------------------------------------------------------------------- 
2021/12/25 03:25:54   10GE0/0/1   APP        Success 
2021/12/25 03:30:08   10GE0/0/1   APP        Success 
-------------------------------------------------------------------------------
Table 1 Description of the display remote-unit upgrade command output
Item Description
StartTime

Start time.
ConnectInterface

Interconnection interface.
Firmware

Indicates the firmware type. The value can be APP, POE, or BIOS.
UpdateResult

Upgrade result. Success indicates that the upgrade is successful. No Need Upgrade indicates that the upgrade is not required. Other values indicate that the upgrade fails.
