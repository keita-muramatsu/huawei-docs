ignore-lsa-check (OSPF view)

Function

The ignore-lsa-check command configures the device to ignore the specific check on TLVs in specified LSAs.

The undo ignore-lsa-check command cancels the configuration of ignoring the specific check on TLVs in specified LSAs.

By default, the device checks the Route Type field of the Type 1 TLV (Extended Prefix TLV) in Type 11 LSAs (AS-scoped Opaque LSAs) and Type 7 Prefix Opaque LSAs. If the Route Type field fails the check, all TLVs in the LSAs are no longer used for route calculation.

Format

ignore-lsa-check lsa-type lsa-type-value opaque-type opaque-type-value tlv tlv-value

undo ignore-lsa-check lsa-type lsa-type-value opaque-type opaque-type-value tlv tlv-value

Parameters

Parameter Description Value
opaque-type opaque-type-value

Specifies the Opaque LSA type value.

The value is 7.

  • 7: OSPFv2 Extended Prefix Opaque LSA
tlv tlv-value

Specifies the TLV type value.

The value is 1.

  • 1: OSPFv2 Extended Prefix TLV
lsa-type lsa-type-value

Specifies the LSA type value.

The value is 11.

  • 11: AS-scoped Opaque LSA

Views

OSPF view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Before applying LSAs, OSPF checks the validity of TLVs in them. To configure the device to ignore the specific check on TLVs in these LSAs or implement looser processing, you can run this command to modify the check conditions of the specified TLVs.

By default, the device checks the Route Type field of the Type 1 TLV (Extended Prefix TLV) in Type 11 LSAs (AS-scoped Opaque LSAs) and Type 7 Prefix Opaque LSAs. If the Route Type field fails the check, all TLVs in the LSAs are no longer used for route calculation. That is, if an LSA carries multiple TLVs and the check on the specified TLV fails, the other TLVs in the LSA cannot be used for route calculation either. After this command is run, other TLVs in the LSA can still be used for route calculation even if the Route Type field of the specified TLV fails the check.

Precautions

After this command is run, the OSPF LSA parsing results on the local device may be different from those on other devices. If the involved LSAs are used for route calculation, the route calculation results may be different, causing routing loops or black holes.

Before running this command, analyze the impact of the configuration on routes. This is to prevent routing loops or black holes caused by route calculation differences between devices.

Example

# Configure the device to ignore the specific check on the Type 1 TLV in Type 11 LSAs and Type 7 Opaque LSAs.
<HUAWEI> system-view
[HUAWEI] ospf 1
[HUAWEI-ospf-1] ignore-lsa-check lsa-type 11 opaque-type 7 tlv 1
