reset traffic-policy statistics

Function

The reset traffic-policy statistics command clears statistics on packets matching a traffic policy.

Format

For AR8100 series, AR8700 series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6700-H series, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5700-H series, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR5710-S8TWDSE-LTE4EA, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S10T1X2:

reset traffic-policy statistics interface { interface-type interface-number | interface-name } [ policy-name ] [ inbound | outbound ] [ classifier-base classifier-name ] [ preprocess | firstprocess | decapprocess ] [ history ]

For AR8100 series, AR8700 series, AR6700-H series:

reset traffic-policy statistics connection connection-id outbound [ classifier-base classifier-name ]

Parameters

Parameter Description Value
interface interface-type interface-number

Clears statistics on packets matching a traffic policy on a specified interface. If this parameter is not specified, statistics on packets of all interfaces are cleared.

  • interface-type specifies the interface type.
  • interface-number specifies the interface number.

The value varies depending on the device.
interface-name

Clears statistics on packets matching a traffic policy applied to a specified interface. If this parameter is not specified, flow-based traffic statistics on all interfaces are cleared.

-
policy-name

Clears statistics on packets matching a specified traffic policy.

The value is a string of 1 to 31 case-sensitive characters without spaces.
inbound

Clears traffic statistics in the inbound direction.

-
outbound

Clears traffic statistics in the outbound direction.

-
classifier-base classifier-name

Clears statistics on packets matching a specified traffic classifier.

The value is a string of 1 to 31 case-sensitive characters, starting with a letter or digit. It cannot contain spaces.
history

Clears historical packet statistics after a traffic policy is applied.

-
preprocess

Clears statistics on packets matching a preprocessing traffic policy.

-
firstprocess

Clears statistics on packets matching the preferential processing traffic policy.

-
decapprocess

Indicates post-decapsulation processing.

-
connection connection-id

Displays statistics about the traffic policy with a specified connection ID.

NOTE:

This parameter is supported only on the AR8700 series, AR8100 series and AR6700-H series.

The value is an integer in the range from 1 to 4294967295.

Views

All views

Default Level

3: Management level

Usage Guidelines

Usage Scenario

After this command is run, traffic statistics are cleared and cannot be restored.

To view traffic statistics, run the display traffic-policy statistics command.

Precautions

  • After the reset traffic-policy statistics command is run, traffic statistics are cleared and cannot be restored. Exercise caution when using the command.
  • Running the reset traffic-policy statistics history command does not affect the statistics queried using the display traffic-policy statistics command. Running the reset traffic-policy statistics command affects the historical statistics in a statistical period queried using the display traffic-policy statistics history command.
  • The reset traffic-policy statistics connection command is of the monitoring level, and other commands are of the management level.

Example

# Clear traffic statistics on an interface in the inbound direction to which a traffic policy has been applied.
<HUAWEI> reset traffic-policy statistics interface 10GE 0/0/1 inbound history
# Clear the flow-based traffic statistics of connection 12 in the outbound direction.
<HUAWEI> reset traffic-policy statistics connection 12 outbound
