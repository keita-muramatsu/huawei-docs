binding service-map fec-profile

Function

The binding service-map fec-profile command binds an FEC service profile and an FEC parameter profile to an FEC policy.

The undo binding service-map fec-profile command unbinds an FEC service profile and an FEC parameter profile from an FEC policy.

By default, no service profile or FEC parameter profile is bound to an FEC policy.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

binding service-map name fec-profile profile-name precedence precedence-value

undo binding service-map name [ fec-profile profile-name [ precedence precedence-value ] ]

Parameters

Parameter Description Value
fec-profile profile-name

Specifies the name of an FEC parameter profile.

The value is a string of 1 to 31 case-sensitive characters. If spaces are used, the string must be enclosed in double quotation marks (" ").
precedence precedence-value

Specifies the priority of the combination of the FEC service profile and FEC parameter profile.

The value is an integer ranging from 0 to 63. A smaller value indicates a higher priority.
service-map name

Specifies the name of an FEC service profile.

The value is a string of 1 to 31 case-sensitive characters. If spaces are used, the string must be enclosed in double quotation marks (" ").

Views

forward-error-correction-policy view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After creating an FEC policy, you need to bind an FEC service profile and FEC parameter profile to the FEC policy so that this policy is meaningful.

Prerequisites

  • An FEC service profile has been created using the service-map command.
  • An FEC parameter profile has been created using the fec profile command.
  • An FEC policy has been created using the fec policy command.

Precautions

  • After an FEC policy that has been bound to an FEC service profile and an FEC parameter profile is applied, you can change the binding in the FEC policy view.
  • An FEC parameter profile can be bound to different FEC policies.
  • In a single FEC policy, an FEC service profile can be bound to only one FEC parameter profile.

Example

# In the FEC policy named policy1, configure the device to use the FEC parameter profile prof1 to optimize packets matching the service profile map1.
<HUAWEI> system-view
[HUAWEI] acl 3000
[HUAWEI-acl4-advance-3000] quit
[HUAWEI] application-group name videos
[HUAWEI-application-group-videos] quit
[HUAWEI] forward-error-correction
[HUAWEI-forward-error-correction] service-map map1
[HUAWEI-forward-error-correction-service-map-map1] match acl 3000 application-group videos
[HUAWEI-forward-error-correction-service-map-map1] quit
[HUAWEI-forward-error-correction] fec profile prof1
[HUAWEI-forward-error-correction-profile-profile1] quit
[HUAWEI-forward-error-correction] fec policy policy1
[HUAWEI-forward-error-correction-policy-policy1] binding service-map map1 fec-profile prof1 precedence 10
