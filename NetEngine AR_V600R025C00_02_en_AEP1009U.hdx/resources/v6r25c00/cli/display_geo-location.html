display geo-location

Function

The display geo-location command displays information about regions, including region names, IP address members, and reference counts.

Format

display geo-location { all | type { pre-defined | unknown-zone | user-defined } | verbose geo-location-name }

Parameters

Parameter Description Value
all

Displays general information about all regions. In this case, IP address members cannot be queried.

-
type

Displays information about regions of the specified type.

-
pre-defined

Indicates a predefined region.

-
unknown-zone

Indicates an unknown region.

-
user-defined

Indicates a user-defined region.

-
verbose geo-location-name

Displays detailed information about a region.

If the region name does not contain spaces, the value is a string of 1 to 63 characters. If the region name contains spaces, it must be enclosed in double quotation marks (""), for example, "location for test".

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run the display geo-location command to view region information, including the region name, IP address members, and reference counts.
