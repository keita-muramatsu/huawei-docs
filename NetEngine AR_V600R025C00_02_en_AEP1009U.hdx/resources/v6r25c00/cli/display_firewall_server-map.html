display firewall server-map

Function

The display firewall server-map command displays information about the Server-map table.

Format

display firewall server-map [ slot slot-id cpu cpu-id ] [ aspf | nat-server | full-cone | static | dynamic | no-pat ] [ ip ip-address ]

Parameters

Parameter Description Value
slot slot-id

Specifies a slot ID.

The value is an integer, and the value range depends on the device configuration.
cpu cpu-id

Specifies a CPU ID.

The value is an integer, and the value range depends on the device configuration.
full-cone

Displays Server-map table entries that are generated in 3-tuple NAT mode.

-
aspf

Displays server mapping entries in ASPF mode.

-
nat-server

Displays server mapping entries generated in NAT Server mode.

-
no-pat

Displays server mapping entries generated in no-PAT mode.

-
static

Displays manually generated server mapping entries.

-
dynamic

Displays dynamically generated server mapping entries.

-
ip ip-address

Displays server mapping entries with a specified IP address.

The value is in dotted decimal notation.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

For user-defined ASPF, if no actual traffic exists, no server mapping entry is generated.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the server mapping table.
<HUAWEI> display firewall server-map
Current Total Server-map : 3
Slot: 0 CPU: 0
Type: ASPF,  10.1.1.1:4511[1.1.1.1:2051] -> 10.1.1.2:5005,  Zone:---
Protocol: udp(Appro: rtsp-rtcp),  Left-Time:00:00:08
Vpn: public -> public
Create Time: 2024-11-14 02:08:47

Type: Nat Server,  any -> 10.1.2.1:21[1.1.1.2:21],  Zone:---,  Protocol: tcp
VPN: public --> public

Type: Nat Server Reverse,  1.1.1.2[10.1.2.1] -> any,  Zone:---,  Protocol: tcp
VPN: public --> public,  counter: 1
Table 1 Description of the display firewall server-map command output
Item Description
Protocol: PROTOCOL

Protocol used by the entry. PROTOCOL indicates the transport-layer protocol, and APPRO indicates the application-layer protocol.

If no protocol is specified, any is displayed.
Vpn: SRCVPN -> DSTVPN

Source and destination VPN instances for NAT.
Create Time

Indicates the time when the server map entry is created. The value can be FullCone, ASPF, SA, STUN, or NO-PAT.
Zone: ZONE-NAME

For server mapping entries generated when NAT Server is enabled, the security zone of the global IP address of NAT Server is displayed.

For other types of server mapping entries, --- is displayed.
Left-Time: HH:MM:SS

Remaining lifetime of the entry.

For entries that do not age, --- is displayed.
TYPE

The following types of server mapping entries are available:

  • ASPF: Server mapping entries generated when ASPF is enabled to forward the traffic of multi-channel protocols.
  • NAT Server: Forward server mapping entries generated using the NAT Server mapping function.
  • NAT Server Reverse: Reverse server mapping entries generated using the NAT Server mapping function.
  • Unknown: unknown type.
SRCADDR -> DSTADDR

Source and destination IP addresses in the entry. If there is no specific source or destination, any is displayed.

The address format is x.x.x.x:portx[y.y.y.y:porty], where portx and porty are the source and destination port numbers. The address in the square brackets is the post-NAT IP address. If NAT is not implemented, no content is displayed in the square brackets. If the port is not required or not translated, :port is not displayed.
Hotversion

Indicates the version of the entry.
Slot

Indicates the CPU slot.
CPU

Indicates the ID of the CPU in use.
