measure count

Function

The measure count command configures an SPR data calculation mode.

The undo measure count command restores the default SPR data calculation mode.

By default, SPR uses the one-way data calculation mode.

Format

measure count { one-way | two-way-average }

undo measure count [ { one-way | two-way-average } ]

Parameters

Parameter Description Value
one-way

Indicates the one-way data calculation mode in which the forward tunnel data is used for calculation.

-
two-way-average

Indicates the two-way data calculation mode in which the forward and reverse tunnel data is used for calculation and the calculation result is the average value of the sum of the forward and reverse tunnel data.

-

Views

SRv6 smart policy route view

Default Level

2: Configuration level

Usage Guidelines

This command is used to configure a data calculation mode. In one-way data calculation mode, the forward tunnel data is used for calculation. In two-way data calculation mode, the forward and reverse tunnel data is used for calculation, with the calculation result being the average value of the sum of the forward and reverse tunnel data.

Example

# Specify the two-way data calculation mode.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] smart-policy-route
[HUAWEI-segment-routing-ipv6-spr] measure count two-way-average
