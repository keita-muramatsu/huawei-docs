display arp history

Function

The display arp history command displays historical information about ARP entry changes.

Format

display arp history

Parameters

None

Views

All views

Default Level

3: Management level

Usage Guidelines

Usage Scenario

To view historical information about ARP entry changes for ARP fault locating and rectification, run the display arp history command. ARP entry changes include the creation, deletion, and modification of ARP entries.

Precautions

  • Historical information about fake ARP entry changes cannot be queried using the display arp history command.
  • Information about changes in static ARP entries with the same IP address but different VPN instances cannot be queried using the display arp history command.

Example

The actual command output varies according to the device. The command output here is only an example.

<HUAWEI> display arp history

Table 1 Description of the display arp history command output
Item Description
Operate Flags

Operation type corresponding to an ARP entry change.

  • A indicates an ARP entry creation.
  • D indicates that an ARP entry deletion.
  • M indicates an ARP entry modification.
Reason Flags

Reason for an ARP entry change.
0 - Other

All the other reasons excluding those listed below.
1 - Packet

ARP entry creation or modification is triggered by a received ARP packet.
2 - Remote

ARP entry creation, modification, or deletion is triggered by ARP dual-device hot back information.
3 - Expire

ARP entry deletion is triggered by normal aging.
4 - PV Del

ARP entry deletion is triggered by PV deletion.
5 - Del IP

ARP entry deletion is triggered by interface IP address deletion.
6 - If Down

ARP entry deletion is triggered by the Down status of an interface.
7 - Reset

ARP entry deletion is triggered by the reset operation.
8 - If Del

ARP entry deletion is triggered by interface deletion.
9 - Mac Msg

ARP entry deletion is triggered by MAC association.
10 - PV Down

ARP entry deletion is triggered by PV Down messages.
11 - Check Fail

ARP entry deletion is triggered by an EUM authentication failure.
12 - CFG

ARP entry creation or modification is triggered by manual configuration of a static ARP entry.
13 - VPN Change

ARP entry deletion is triggered by an interface VPN binding change.
14 - Miss Msg

ARP entry modification is triggered by reporting of ARP Miss messages.
15 - VLAN Flush

ARP entry deletion is triggered by VLAN flush.
16 - VRRP

ARP entry deletion is triggered by a VRRP master/slave switchover.
17 - Multiport

ARP entry deletion is triggered by multi-port configuration.
18 - Local Ce

ARP entry deletion is triggered by IP address configuration on an Ethernet interface of a local CE.
19 - Rgm Msg

ARP entry deletion is triggered by VC channel Down.
20 - PV Discard

ARP entry deletion is triggered by receipt of PV Discard messages.
21 - Controller

ARP entry modification is triggered by the controller entry update.
22 - Sub VLAN Del

ARP entry deletion is triggered by sub-VLAN deletion.
23 - Dot1q Del

ARP entry deletion is triggered by Layer-3 dot1q sub-interface deletion.
24 - Port Link Change

ARP entry deletion is triggered by an interface link type change.
25 - Redirect

ARP entry creation or deletion is triggered by the change in redirection information.
26 - If Down Residual Del

Deletion of residual ARP entries is triggered by the Down status of interfaces during periodic checks.
27 - Expire Residual Del

Deletion of residual ARP entries is triggered by normal aging during periodic checks.
28 - BD Member Down

ARP entry deletion is triggered by the Down status of a BD member interface.
30 - DFS

ARP entry creation, modification, or deletion is triggered by DFS message.
31 - Gratuitous ARP

ARP entry creation, modification, or deletion is triggered by a received Gratuitous ARP packet.
35 - Role Change

Entry addition, update, or deletion triggered by role change.
OP/RE

Operation type/change cause.
IP ADDRESS

IP address corresponding to an ARP entry.
MAC ADDRESS

MAC address corresponding to an ARP entry.
INTERFACE

Interface type and number corresponding to an ARP entry.

If an interface is deleted or does not exist, the INTERFACE field is displayed as Unknown.
PE/CEVLAN

VLAN ID of an ARP entry.
SYSTEM-TIME

System time when the ARP entry is changed.
