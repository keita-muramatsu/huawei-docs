apply extcommunity-filter rt

Function

The apply extcommunity-filter rt command deletes a BGP extended community attribute based on a specified value in the extended community filter.

The undo apply extcommunity-filter command cancels the setting.

By default, BGP extended community attributes are not deleted.

Format

apply extcommunity-filter rt filter-name delete

undo apply extcommunity-filter rt [ filter-name [ delete ] ]

Parameters

Parameter Description Value
delete

Deletes an extended community attribute.

-
rt filter-name

Specifies the name of a VPN-Target extended community filter.

The value is a string of 1 to 51 case-sensitive characters. It cannot contain spaces.

Views

Route-policy view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The apply extcommunity command is used in VPN scenarios. BGP extended communities are classified into the following types:

  • VPN route target (RT) extended community
  • Source of origin (SoO) extended community

    The apply extcommunity-filter rt command can be used to delete a specified VPN target extended community attribute from the BGP routes that match a route-policy.

Prerequisites

A route-policy has been configured before you run the apply extcommunity-filter rt command.

Configuration Impact

After a route matches a route-policy, the specified extended community attribute of the BGP route is deleted.

Example

# Delete the specified BGP route VPN-Target extended community attribute 100.100:100 from the extended community filter.
<HUAWEI> system-view
[HUAWEI] ip extcommunity-filter basic test permit rt 100.100:100
[HUAWEI] route-policy te permit node 1
Info: New Sequence of this List
[HUAWEI-route-policy] apply extcommunity-filter rt test delete
