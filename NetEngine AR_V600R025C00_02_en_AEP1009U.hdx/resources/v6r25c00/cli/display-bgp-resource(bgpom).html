display bgp resource

Function

The display bgp resource command displays statistics about BGP specification information.

Format

display bgp resource

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

The display bgp resource command displays BGP resource specifications, including the total number of BGP peer sessions, the number of configured sessions, the maximum number of routes supported in each BGP address family, and the number of received routes in each address family.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display statistics about BGP specification information.
<HUAWEI> display bgp resource
  BGP Peer session support total number : 500
   Capacity Statistics     Used Number

   BGP Peer Session          5
   IBGP Peer Session         3
   EBGP Peer Session         2

  BGP Capacity Status               Current/Limit (Maximum number of routes instead of prefixes)

  IPv4 unicast route                0/4294967295
  IPv6 unicast route                0/4294967295
  VPNv4 route                       0/4294967295
  VPNv6 route                       0/4294967295
  EVPN route                        0/4294967295

Maximum number of BGP peer sessions that is supported.

BGP peer sessions.

BGP capacity status.

BGP peer session type.

Current number of configured BGP peer sessions.
IBGP Peer Session

IBGP peer sessions, including confederation IBGP and common IBGP peer sessions.
EBGP Peer Session

EBGP peer sessions, including confederation EBGP and common EBGP peer sessions.
