route-lowest-priority graceful-restart(BGP-EVPN address family view)

Function

The route-lowest-priority graceful-restart command enables the function of reducing the priorities of routes received from a peer in the GR state.

The undo route-lowest-priority graceful-restart command disables the function of reducing the priorities of routes received from a peer in the GR state.

By default, the function of reducing the priorities of routes learned from a peer in the GR state is disabled.

Format

route-lowest-priority graceful-restart

undo route-lowest-priority graceful-restart

Parameters

None

Views

BGP-EVPN address family view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When GR is enabled on the local device and the peer from which the optimal route is received restarts, the peer enters the GR state and the local device retains the routes received from that peer. In this situation, by default, the path selection rules remain unchanged and the retained routes continue to be preferred. As a result, traffic is not switched to other paths, leading to packet loss. To solve this problem, you can run the route-lowest-priority graceful-restart command on the local device to lower the priorities of routes received from a peer in GR state. After this command is configured, if routes are imported from the EVPN address family into a BGP VPN instance, the priorities of those imported routes are also reduced accordingly.

Precautions

This function takes effect only when GR is enabled on the local device and the peer is in the GR state.

Example

# Configure the function of reducing the priorities of the routes learned from a peer in the GR state.
<HUAWEI> system-view
[HUAWEI] bgp 100
[HUAWEI-bgp] l2vpn-family evpn
[HUAWEI-bgp-af-evpn] route-lowest-priority graceful-restart
