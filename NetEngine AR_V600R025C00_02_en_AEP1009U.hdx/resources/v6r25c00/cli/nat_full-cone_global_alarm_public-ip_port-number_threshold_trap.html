nat full-cone global alarm public-ip port-number threshold trap

Function

The nat full-cone global alarm public-ip port-number threshold trap enable command enables the function of sending logs and alarms when the port usage corresponding to a single public IP address in a NAT address pool reaches the threshold.

The undo nat full-cone global alarm public-ip port-number threshold trap enable command disables the function of sending logs and alarms when the port usage corresponding to a single public IP address in a NAT address pool reaches the threshold.

By default, the log and alarm functions for the port usage corresponding to a single public IP address in an address pool are enabled.

Format

nat full-cone global alarm public-ip port-number threshold trap enable

undo nat full-cone global alarm public-ip port-number threshold trap enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

In a 3-tuple NAT scenario, you can enable the alarm function for the port usage of an individual IP address in an address pool. When the port usage of a public IP address in a 3-tuple address pool reaches the configured threshold, the device sends an alarm to the NMS and sends a log to the log server. When the port usage of the public IP address in the 3-tuple address pool falls below 7/8 of the configured threshold, the device sends a clear alarm to the NMS and sends a recovery log to the log server.

For example, assume that the default minimal and maximal ports that can be allocated to each IP address in the address pool are 2048 and 65535, respectively. Then, the number of ports that can be allocated to each IP address is (65535 - 2048 + 1) = 63488. When the number of ports used by a public IP address in the address pool reaches 63488 x threshold-value, the device sends the log FULLCONE/3/CPUPUBLICIPPORTUSAGETRAP and the alarm FULLCONE_1.3.6.1.4.1.2011.6.122.48.2.2 hwSecFullConeIpPortUsageOverThreshold. When the port usage of the public IP address in the 3-tuple address pool falls below 7/8 of the threshold, that is, when the number of ports used by this public IP address reaches 63488 x (threshold-value x 7/8), the device sends the clear alarm FULLCONE_1.3.6.1.4.1.2011.6.122.48.2.4 hwSecFullConeIpPortUsageLessThreshold to the NMS, and sends the recovery log FULLCONE/3/CPUPUBLICIPPORTUSAGENORMALTRAP to the log server.

To set threshold-value, run the nat full-cone global alarm public-ip port-number threshold command.

Example

# Enable the function of sending logs and alarms when the port usage corresponding to a single public IP address in a NAT address pool reaches the threshold.
<HUAWEI> system-view
[HUAWEI] nat full-cone global alarm public-ip port-number threshold trap enable
