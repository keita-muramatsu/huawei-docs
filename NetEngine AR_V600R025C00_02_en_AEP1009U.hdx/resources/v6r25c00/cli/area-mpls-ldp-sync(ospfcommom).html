ldp-sync enable

Function

The ldp-sync enable command enables LDP-IGP synchronization on all IGP interfaces in an IGP process or instance.

The undo ldp-sync enable command disables LDP-IGP synchronization on all interfaces in an IGP process or instance.

LDP-IGP synchronization is disabled on all IGP interfaces by default.

Format

ldp-sync enable

undo ldp-sync enable

Parameters

None

Views

OSPF area view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

LDP-IGP synchronization is used to prevent LSP traffic loss on a network where both primary and backup links exist. The details are as follows:

  • When the primary link is normal and the LDP local session or LDP adjacency between nodes along the primary link fails, LSP traffic is switched from the primary link to the backup link, whereas the IGP still uses the primary link. As a result, the LSP traffic is discarded. After LDP-IGP synchronization is configured, if the LDP local session or LDP adjacency between nodes along the primary link fails, the IGP advertises the maximum cost for this link. In this way, both the route and LSP are switched to the backup link.
  • When the primary link recovers, the IGP switches its route back to the primary LSP earlier than LDP does because IGP convergence is faster than LDP convergence. As a result, LSP traffic is lost. After LDP-IGP synchronization is configured, if the primary link recovers, the IGP advertises the maximum cost for the primary link. In this way, the IGP route is switched back to the primary link only after the LSP is set up over the primary link.

    After the command is run in the OSPF area view, the following situations occur:
  • On a P2P network, LDP-IGP synchronization is enabled on all interfaces whose neighbors are up.
  • On a broadcast network, LDP-IGP synchronization is enabled on all interfaces whose neighbors are up between the DR and non-DR/BDR.

Follow-up Procedure

If necessary, run the ospf ldp-sync block command to block LDP-IGP synchronization on some IGP interfaces.

Precautions

LDP-IGP synchronization can be configured globally or on a specified interface. The system preferentially uses the configuration on the interface.

Before running this command, ensure that LDP is enabled on all IGP-enabled interfaces. Otherwise, services on LDP-disabled interfaces may be affected.

If LDP-IGP synchronization is enabled and the value of the hold-max-cost timer is not set, an IGP advertises the maximum cost of the link during the interruption of an LDP session or LDP adjacency. The cost can be restored only after the LDP session recovers. In a scenario where a backup link exists, after the primary link recovers, the LDP session attempts to be reestablished. Because the IGP advertises the maximum cost on the primary link, TCP connection establishment or LDP packets are sent to the peer end through the backup link. If the backup link fails to forward traffic or a security policy is configured, TCP connections may be established or LDP packets may be discarded. As a result, LDP sessions cannot be established, and IGP continuously advertises the maximum cost on the primary link. Therefore, when LDP-IGP synchronization is used, ensure that LDP packets are forwarded properly on the backup link. Otherwise, the backup link is always used.

In addition, when an IGP carries multiple types of services, including LDP services, LDP-IGP synchronization is enabled, and the hold-max-cost timer is not set, the IGP keeps advertising the maximum cost on the active link when the LDP session or LDP adjacency on the active link is interrupted, IGP route selection and other services may be affected. Therefore, when an IGP carries multiple types of services, including LDP services, you can set a proper value for the hold-max-cost timer to reduce the impact of the LDP session or LDP adjacency interruption on IGP route selection and other services.

Example

# Enable LDP and OSPF synchronization on an OSPF area.
<HUAWEI> system-view
[HUAWEI] ospf 100
[HUAWEI-ospf-100] area 2
[HUAWEI-ospf-100-area-0.0.0.2] ldp-sync enable
