display portal

Function

The display portal command displays the Portal authentication configuration.

Format

display portal

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

After configuring Portal authentication information, you can run this command to check the Portal authentication configuration. You can check whether the configuration is correct according to the command output.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the Portal authentication configuration on the device.
<HUAWEI> display portal
  Portal max-user number:1000                                                                                                       
  Quiet function is Enabled                                                                                                         
  Different-server is Disable                                                                                                       
  Parameter set : Quiet Period        60s   Quiet-times          10                                                                 
  User-defined HTTP redirection port number : -                                                                                     
  Logout packets resend : Resend-times 3  Timeout 5s                                                                                
  Portal Https Redirect : Disable                                                                                                   
  Portal Https Redirect SSL policy : -                                                                                              
  Portal Redirect Mode : 200-OK                                                                                                     
  Portal URL Encode : Enabled                                                                                                       
  Portal CnaAdaptive : Disable   

  AP ID: 0      Radio ID: 1      WLAN ID: 6
  web-auth-server layer2(direct)
Table 1 Description of the display portal command output
Item Description
Portal max-user number

Maximum number of Portal authentication users allowed to access the device.
Portal Https Redirect

Whether HTTPS redirection of Portal authentication is enabled:

Enable: HTTPS redirection of Portal authentication is enabled.

Disable: HTTPS redirection of Portal authentication is disabled.

To configure this parameter, run the authentication https-redirect enable command.
Portal Redirect Mode

Portal redirection mode:

JS: The function of inserting JavaScript scripts during Portal redirection is enabled.

302: 302 redirection of Portal authentication is enabled.

200-OK: 200 OK redirection of Portal authentication is enabled.

To configure this parameter, run the portal redirect-mode command.
Portal URL Encode

Whether the URL encoding and decoding function is enabled:

Disable: The function is disabled.

Enable: The function is enabled.

To configure this parameter, run the portal url-encode disable command.
Portal CnaAdaptive

CNA adaptive function for iOS terminals during Portal authentication:

Enable: The CNA adaptive function for iOS terminals is enabled.

Disable: The CNA adaptive function for iOS terminals is disabled.

To configure this parameter, run the portal captive-adaptive disable command.
Portal Https Redirect SSL policy

Name of the policy bound to HTTPS redirection.
Quiet function is Enabled or Quiet function is Disabled

Whether the quiet function is enabled for Portal authentication:

Enabled: The quiet function is enabled for Portal authentication.

Disabled: The quiet function is disabled for Portal authentication.

To configure this parameter, run the portal quiet-period command.
Different-server is Enabled or Different-server is Disabled

Whether the device processes user logout requests sent by a Portal server other than the one from which users go online:

Enabled: The device processes user logout requests sent by a Portal server other than the one from which users go online.

Disabled: The device does not process user logout requests sent by Portal servers other than the one from which users go online.

To configure this parameter, run the portal logout different-server enable command.
Parameter set

Parameter settings for the quiet function in Portal authentication:

Quiet Period: quiet period of Portal authentication. To set this parameter, run the portal timer quiet-period command.

Quiet-times: maximum number of authentication failures within 60 seconds before a Portal authentication user enters the quiet state. To set this parameter, run the portal quiet-times command.
User-defined HTTP redirection port number

User-defined destination port number of HTTP packets that trigger Portal redirection.

To configure this parameter, run the portal redirect-http-port command.
Logout packets resend

Configuration of the logout packet re-transmission function for Portal authentication users:

Resend-times: number of retransmissions of logout packets of Portal authentication users.

Timeout: interval for retransmitting logout packets of Portal authentication users.

To configure this parameter, run the portal logout resend timeout command.
