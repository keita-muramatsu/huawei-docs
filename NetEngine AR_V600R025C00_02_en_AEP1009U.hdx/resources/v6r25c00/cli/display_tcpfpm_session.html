display tcpfpm session

Function

The display tcpfpm session command displays TCP FPM statistics.

Format

display tcpfpm session { all | number }

Parameters

Parameter Description Value
all

Displays all TCP FPM statistics.

-
number

Indicates the number of sessions involved in TCP FPM statistics collection.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

This command can display TCP FPM statistics, including network delay and packet loss rate, which are the reference for network optimization.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the number of entries of which the TCP FPM statistics are displayed.
<HUAWEI> display tcpfpm session number
 TCP FPM session number : 2
# Display all TCP FPM statistics.
<HUAWEI> display tcpfpm session all
Index DstIP(Port)            SrcIP(Port)       Loss(%)  SND(ms)  CND(ms)  VpnName   Application
1     10.1.1.3(2053)         10.1.3.2(3351)    0        12       4        vpn1      FTP
Table 1 Description of the display tcpfpm session command output
Item Description
TCP FPM session number

Number of sessions involved in TCP FPM statistics collection.
Index

Index of a session involved in TCP FPM statistics collection.
DstIP(Port)

IP address and port number of the application server.
SrcIP(Port)

IP address and port number of the application client.
Loss(%)

Packet loss rate, in percentage.
SND(ms)

Network delay on the server, in milliseconds.
CND(ms)

Network delay on the client, in milliseconds.
VpnName

VPN instance name.
Application

Application type.
