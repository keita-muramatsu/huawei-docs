display srv6-te policy sid statistics

Function

The display srv6-te policy sid statistics command displays the numbers of End SIDs and End.X SIDs collected from the IS-IS LSDB.

Format

display srv6-te policy sid statistics [ isis process process-id { level-1 | level-2 | level-1-2 } ]

Parameters

Parameter Description Value
isis

Indicates IS-IS.

-
process process-id

Specifies an IS-IS process.

The value is an integer ranging from 1 to 4294967295.
level-1

Indicates IS-IS Level-1.

-
level-2

Indicates IS-IS Level-2.

-
level-1-2

Indicates IS-IS Level-1-2.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To check the numbers of End SIDs and End.X SIDs collected from the IS-IS LSDB, run the display srv6-te policy sid statistics command.

The numbers can be queried after fault detection is enabled or within one hour after fault detection is disabled.

Example

The actual command output varies according to the device. The command output here is only an example.

# Displays the number of SIDs received from IS-IS LSDB.
<HUAWEI> display srv6-te policy sid statistics
Total: End-x Sid : 2
       End   Sid : 6
-------------------------------------------
process      level      end      end-x
-------------------------------------------
  1          level-1    2          2
  2          level-1    2          0
  2          level-2    2          0
Table 1 Description of the display srv6-te policy sid statistics command output
Item Description
End-x Sid

Total number of End.X SIDs collected from the IS-IS LSDB.
End Sid

Total number of End SIDs collected from the IS-IS LSDB.
process

IS-IS process.
level

IS-IS level.
end

Number of End SIDs collected from the IS-IS LSDB.
end-x

Number of End.X SIDs collected from the IS-IS LSDB.
