adsl sra (VDSL interface)

Function

The adsl sra command enables or disables seamless rate adaptation on a VDSL interface.

The undo adsl sra command restores the default enabling status of seamless rate adaptation on a VDSL interface.

By default, seamless rate adaptation is disabled on a VDSL interface.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S10T1X2, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

adsl sra { off | on }

undo adsl sra [ on ]

Parameters

Parameter Description Value
off

Disables seamless rate adaptation on a VDSL interface.

-
on

Enables seamless rate adaptation on a VDSL interface.

-

Views

Ethernet interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When the external environment changes, to prevent line disconnection, you can use the bit exchange function to adjust bit distribution or the power among sub-channels without deactivating the line. The bit exchange function, however, cannot change the line rate. When the line environment becomes even worse, the bit exchange function alone cannot meet the requirement for the bit error rate. In this case, the only solution is re-negotiation and to activate the line at a lower rate. Similarly, when the line environment becomes better, the bit exchange function cannot increase the rate, wasting line resources.

Seamless rate adaptation solves the preceding problem. It dynamically adjusts the line rate without reactivating the line.

Precautions

  • Running this command will restart the interface, causing data frame loss or service interruption.
  • Seamless rate adaptation must be enabled on devices on both ends of a line, and takes effect only after the line is activated.

Example

# Enable seamless rate adaptation on VDSL interface 1/0/0.
<HUAWEI> system-view
[HUAWEI] interface Ethernet 1/0/0
[HUAWEI-Ethernet1/0/0] adsl sra on
Warning: This operation may cause the interface to restart. Are you sure to continue? [Y/N]:y
