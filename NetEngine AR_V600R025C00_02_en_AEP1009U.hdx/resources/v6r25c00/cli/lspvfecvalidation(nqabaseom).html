lspv echo-reply fec-validation

Function

The lspv echo-reply fec-validation ldp disable command disables LDP forwarding equivalence class (FEC) check on a label switched path verification (LSPV) responder.

The undo lspv echo-reply fec-validation ldp command enables an LSPV responder to check the LDP FEC.

By default, an LSPV response end is enabled to check the LDP FEC and SR-prefix FEC.

Format

lspv echo-reply fec-validation ldp disable

undo lspv echo-reply fec-validation ldp

Parameters

Parameter Description Value
ldp

Indicates the LDP type.

-
disable

Disables an LSPV response end from checking the LDP FEC or SR-prefix FEC.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

If FEC check is not required for LDP services in a detection scenario, run the lspv echo-reply fec-validation ldp disable command.

Example

# Disable an LSPV response end from checking the LDP FEC.
<HUAWEI> system-view
[HUAWEI] lspv echo-reply fec-validation ldp disable
