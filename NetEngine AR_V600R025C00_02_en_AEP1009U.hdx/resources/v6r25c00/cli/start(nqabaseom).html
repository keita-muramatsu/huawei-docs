start (NQA view)

Function

The start command sets the start mode and end mode for an NQA test instance.

The undo start command stops the running NQA test instance. If the start at or start delay command is run but does not take effect, running the undo start command will delete the previous configuration. The undo start command functions the same as the stop command.

By default, the test stops automatically after test packets are sent.

Format

start now

start now end at [ end-yyyy/mm/dd ] end-hh:mm:ss

start now end delay { seconds end-second | delay-hh:mm:ss }

start now end lifetime { seconds end-second | life-hh:mm:ss }

start at [ start-yyyy/mm/dd ] hh:mm:ss

start at [ start-yyyy/mm/dd ] hh:mm:ss end at [ end-yyyy/mm/dd ] end-hh:mm:ss

start at [ start-yyyy/mm/dd ] hh:mm:ss end delay { seconds end-second | delay-hh:mm:ss }

start at [ start-yyyy/mm/dd ] hh:mm:ss end lifetime { seconds end-second | life-hh:mm:ss }

start delay { seconds pause-second | pause-hh:mm:ss }

start delay { seconds pause-second | pause-hh:mm:ss } end at [ end-yyyy/mm/dd ] end-hh:mm:ss

start delay { seconds pause-second | pause-hh:mm:ss } end delay { seconds end-second | delay-hh:mm:ss }

start delay { seconds pause-second | pause-hh:mm:ss } end lifetime { seconds end-second | life-hh:mm:ss }

start daily hh:mm:ss to end-hh:mm:ss [ begin { start-yyyy/mm/dd | start-old-yyyy/mm/dd } ] [ end { end-yyyy/mm/dd | end-old-yyyy/mm/dd } ]

undo start

Usage Guidelines

Usage Scenario

To set the start and end time for an NQA test instance, run the start command.

The main application scenarios of the command are as follows:

  • To start and stop a test instance at the specified time, run the start at <yyyy/mm/dd> <hh:mm:ss> end at <yyyy/mm/dd> <hh:mm:ss> command.
  • To start a test instance at the specified time and stop it when a specified duration (in seconds) elapses, run the start at <yyyy/mm/dd> <hh:mm:ss> end lifetime seconds <second> command.
  • To start a test instance after a specified delay (in seconds) and stop it at the specified time, run the start delay seconds <second> end at <yyyy/mm/dd> <hh:mm:ss> command.
  • To start a test instance immediately and stop it when a specified duration (in seconds) elapses, run the start now end lifetime seconds <second> command.
  • To start and stop a test instance at specified time every day, run the start daily <hh:mm:ss> to <hh:mm:ss> command.

    Set a proper start mode for a test instance as needed.

Configuration Impact

If the start daily command is run more than once, the latest configuration overrides the previous one.

Precautions

If the number of running test instances reaches the maximum number allowed by the system, the start command fails.

For the same test instance, the start now command can be run again only after the previous test is complete.

In non-periodic test scenarios, if a large number of test instances are concurrently executed, you need to wait for a period of time before starting new test instances.

When a test instance is scheduled to run at a specified time every day, if the system time is changed to fall within the configured start-end time window, test packets are sent.

If the parameters start at <yyyy/mm/dd> <hh:mm:ss> and end at <yyyy/mm/dd> <hh:mm:ss> are specified, the test duration is the period between start time and end time. The end at parameter does not mean the time when the test instance execution ends.

Example

# Start the test instance 10 hours later.
<HUAWEI> system-view
[HUAWEI] nqa test-instance user test
[HUAWEI-nqa-user-test] test-type icmp
[HUAWEI-nqa-user-test] destination-address ipv4 10.1.1.1
[HUAWEI-nqa-user-test] start delay 10:00:00
# Start the test instance at a fixed time every day.
<HUAWEI> system-view
[HUAWEI] nqa test-instance user test
[HUAWEI-nqa-user-test] test-type icmp
[HUAWEI-nqa-user-test] destination-address ipv4 10.1.1.1
[HUAWEI-nqa-user-test] start daily 12:00:00 to 13:00:00 begin 2009/10/19 end 2010/10/20
# Start the current test instance immediately.
<HUAWEI> system-view
[HUAWEI] nqa test-instance user test
[HUAWEI-nqa-user-test] test-type icmp
[HUAWEI-nqa-user-test] destination-address ipv4 10.1.1.1
[HUAWEI-nqa-user-test] start now
# Start the test instance at 12:12:12.
<HUAWEI> system-view
[HUAWEI] nqa test-instance user test
[HUAWEI-nqa-user-test] test-type icmp
[HUAWEI-nqa-user-test] destination-address ipv4 10.1.1.1
[HUAWEI-nqa-user-test] start at 2009/10/19 12:12:12
