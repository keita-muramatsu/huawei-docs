path-constraint affinity-mapping

Function

The path-constraint affinity-mapping command configures a template used to map each affinity bit name and value.

The undo path-constraint affinity-mapping command deletes a template used to map each affinity bit name and value.

By default, no template is configured.

Format

path-constraint affinity-mapping

undo path-constraint affinity-mapping

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Hexadecimal numbers are set for affinities and administrative groups, which involves complex mathematical calculation and causes maintenance difficulties. To streamline the plan, configuration, and maintenance, using affinity and link administrative group names to configure affinity and link administrative group attributes facilitates data planning, configuration, and maintenance.

Before configuring names for affinity and link administrative group bits, configure mappings between affinity bits and names on each node that is used to select a path for a TE tunnel. The mapping template is used to manage the set of mappings. The path-constraint affinity-mapping command is used to configure the mapping template.

Example

# Configure an affinity name mapping template.
<HUAWEI> system-view
[HUAWEI] path-constraint affinity-mapping
