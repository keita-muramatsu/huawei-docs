packet-replication enhance enable

Function

The packet-replication enhance enable command enables the packet replication enhancement function.

The undo packet-replication enhance enable command disables the packet replication enhancement function.

By default, the packet replication enhancement function is disabled.

This command is supported only on the AR8700 series, AR8100 series and AR6700-H series.

Format

packet-replication enhance enable

undo packet-replication enhance enable

Parameters

None

Views

packet-replication view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Probe instances are used to detect whether the peer end supports packet replication, preventing function failures caused by capability mismatches between both ends. To improve the performance of packet replication probe instances, you can enable packet replication enhancement.

Follow-up Procedure

After the packet replication enhancement function is configured, run the save command to save the configuration and restart the device for the configuration to take effect.

Precautions

If the packet replication enhancement function is not configured on a device, and a configuration file having this function enabled is used for configuration recovery, the packet replication enhancement function is disabled after the first restart and is enabled after the second restart.

Example

# Enable the packet replication enhancement function.
<HUAWEI> system-view
[HUAWEI] packet-replication
[HUAWEI-packet-replication] packet-replication enhance enable
Info: The settings of the packet replication enhance function are modified successfully. Save the settings and restart the device for the modification to take effect.
