port-security

Function

The port-security enable command enables the port security function and configures the maximum number of MAC addresses that can be learned.

The undo port-security enable command disables the port security function or restores the default maximum number of MAC addresses that can be learned.

The port-security aging-time command configures the aging time of secure dynamic MAC addresses.

The undo port-security aging-time command restores the default aging time of secure dynamic MAC addresses.

The port-security mac-address command enables a user to manually configure a secure static MAC address entry.

The undo port-security mac-address command enables a user to manually delete a secure static MAC address entry.

The port-security protect-action command configures the protection action to be taken when the number of MAC addresses learned by an interface enabled with the port security function reaches the limit.

The undo port-security protect-action command restores the default protection action to be taken when the number of MAC addresses learned by an interface enabled with the port security function reaches the limit.

The port-security mac-address sticky command enables the sticky MAC function on an interface.

The undo port-security mac-address sticky command disables the sticky MAC function on an interface.

By default, the port security function is disabled.

By default, the sticky MAC function is disabled.

By default, secure dynamic MAC addresses on interfaces configured with the port security function are not aged out.

By default, the maximum number of MAC addresses that can be learned on an interface configured with the port security function is 1.

By default, the restrict action is taken when the number of MAC addresses learned by an interface configured with the port security function reaches the limit.

Format

port-security enable [ maximum max-number ]

port-security protect-action { protect | restrict | error-down }

port-security mac-address sticky

port-security aging-time time [ type { absolute | inactivity | force } ]

port-security mac-address mac-address vlan vlan-id

undo port-security enable [ maximum max-number ]

undo port-security protect-action

undo port-security mac-address sticky

undo port-security aging-time

undo port-security mac-address mac-address vlan vlan-id

Parameters

Parameter Description Value
maximum max-number

Specifies the maximum number of MAC addresses that can be learned.

The value is an integer ranging from 1 to 4096.
protect

Indicates that the packets with the source MAC address not contained in the MAC address table are discarded when the number of learned MAC addresses reaches the limit.

-
restrict

Indicates that the packets with the source MAC address not contained in the MAC address table are discarded and an alarm is generated when the number of learned MAC addresses reaches the limit.

-
error-down

Indicates that after an error Down event is generated on an interface, the interface is automatically shut down and cannot automatically restore and an alarm is generated.

-
mac-address mac-address

Specifies a secure static MAC address.

The value is in the H-H-H format, of which H indicates a hexadecimal number of four characters, such as 00e0 and fc01. If less than four characters are entered, the remaining characters are 0s. For example, e0 is displayed as 00e0.
aging-time time

Specifies the aging time of secure dynamic MAC address entries.

The value is an integer that ranges from 1 to 1440, in minutes.
type

Specifies the aging type of secure dynamic MAC address entries.

-
absolute

Specifies that the secure dynamic MAC address entries age out based on an absolute time.

-
inactivity

Specifies that the secure dynamic MAC address entries age out based on a relative time.

-
force

Indicates that secure dynamic MAC address entries are forcibly aged out based on an absolute time.

-
vlan vlan-id

Specifies a VLAN ID.

The value is an integer ranging from 1 to 4094.

Views

Layer 2 10GE interface view, 25GE-L2 view, Layer 2 40GE interface view, Layer 2 Eth-Trunk interface view, Layer 2 GE interface view, Layer 2 multi-GE interface view, VGE-L2 view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The port security function converts the dynamic MAC addresses learned on an interface into secure MAC addresses.

After port security is enabled on a device, the device converts dynamic MAC addresses learned by an interface into secure MAC addresses. In this case, dynamic MAC address entries that have been learned on the interface are deleted. When the number of MAC addresses learned again by the interface reaches the limit, the interface stops learning MAC addresses. If the source MAC address of a Layer 2 packet received by the interface does not exist in the MAC address entries, the interface considers the packet as an attack packet. Then, the packet is discarded, an alarm is reported, or the interface is shut down. This security function is not recommended for Layer 3 packets.

Prerequisites

You can configure the aging time of secure dynamic MAC addresses only after port security is enabled.

You can configure the maximum number of MAC addresses that can be learned only after port security is enabled.

You can configure the protection action to be taken when the number of MAC addresses learned by an interface enabled with port security reaches the limit only after port security is enabled.

You can manually configure a secure static MAC address entry only after port security is enabled.

You can enable the sticky MAC function only after port security is enabled.

Configuration Impact

After port security is enabled on an interface, the interface reserves only one secure MAC address by default. If the MAC address is not the one used for a remote management, the remote management is interrupted. As a result, the device cannot be accessed. You can change the maximum number of secure MAC addresses that an interface can learn to ensure that the remote managements of authorized users are not interrupted.

Precautions

The port security function and MAC address learning limit function cannot be configured on the same interface.

If the sticky MAC function is disabled, the maximum number of MAC addresses that can be learned by an interface limits the number of secure dynamic MAC addresses that can be learned by the interface. If the sticky MAC function is enabled, the maximum number of MAC addresses that can be learned by an interface limits the number of sticky MAC addresses that can be learned by the interface.

The maximum number of secure MAC addresses configured for port security is shared by the entire device. When the total number of secure MAC addresses configured on interfaces of the device reaches the maximum number of secure MAC addresses supported by the device, the maximum number of MAC addresses that can be learned on an interface cannot be configured for interfaces.

Example

# Set the protection action on 10GE0/0/1 to protect.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] port-security enable
[HUAWEI-10GE0/0/1] port-security protect-action protect
# Enable the sticky MAC function on 10GE0/0/1.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] port-security enable
[HUAWEI-10GE0/0/1] port-security mac-address sticky
# Enable port security on 10GE0/0/1.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] port-security enable
# Set the maximum number of MAC addresses that can be learned on 10GE 0/0/1 to 5.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] port-security enable maximum 5
# Configure a secure static MAC address for 10GE0/0/1.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] port-security enable
[HUAWEI-10GE0/0/1] port-security mac-address 1-1-1 vlan 1
# Set the aging time of secure dynamic MAC address entries to 6 minutes on 10GE0/0/1 and configure the MAC address entries to be aged out based on the absolute aging time.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] port-security aging-time 6 type absolute
