display ap file status

Function

The display ap file status command displays certificate loading information about APs.

Format

display ap file status { ap-id ap-id | ap-mac ap-mac }

display ap file status all [ succeed | fail ]

Parameters

Parameter Description Value
ap-id ap-id

Displays certificate loading information about the AP with a specified ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
ap-mac ap-mac

Displays certificate loading information about the AP with a specified MAC address.

The AP's MAC address must exist.
all

Displays certificate loading information about all APs.

-
succeed

Displays information about all APs on which certificates are successfully loaded.

-
fail

Displays information about all APs on which certificates fail to be loaded.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

You can run this command to check certificate loading information about APs.

Follow-up Procedure

AP Certificate Loading Status Cause Handling Suggestion
NA The signature database update function is disabled or no certificate needs to be loaded. If the signature database update function is disabled, check whether this function needs to be enabled. If no certificate needs to be loaded, no action is required.
normal A certificate file is successfully loaded. No action is required.
normal(The following files fail verification on the AP:local, ca, private-key, pki,apsa-sdb,ap-pki-file) The AP detects an invalid certificate file or an incorrect password. Check whether the certificate file and related configurations are correct.
unload A certificate file is updated on the AC but has not been delivered to the AP. Load the certificate file.
loading A certificate file is being loaded. No action is required.
loadfail(user canceled) Certificate file loading is canceled. Reload the certificate file.
loadfail(write flash error) The certificate file fails to be written to the flash memory of the AP. Ensure that the storage space of the AP is sufficient and reload the certificate file.
loadfail(file not exist) The certificate file does not exist on the AC. Load the certificate file to the AC and then reload the file to the AP.
loadfail(timeout) Certificate file transmission times out. Reload the certificate file.
loadfail(exception) An exception occurs during certificate file transmission. Reload the certificate or contact technical support personnel.
loadfail(file illegal) The certificate file is invalid. Load a valid certificate file.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display certificate loading information about all APs.
<HUAWEI> display ap file status all

5       00e0-fc44-4444    456        branchgroup4     NA
