ipsec authentication sha2 compatible enable

Function

The ipsec authentication sha2 compatible enable command enables SHA-2 to be compatible with earlier versions globally.

The undo ipsec authentication sha2 compatible enable command disables SHA-2 from being compatible with earlier versions globally.

By default, the SHA-2 algorithm is compatible with earlier software versions.

Format

ipsec authentication sha2 compatible enable

undo ipsec authentication sha2 compatible enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

When IPsec uses the SHA-2 algorithm, if the devices on both ends of an IPsec tunnel are from different vendors or run different software versions, they may use different encryption/decryption modes. In this situation, IPsec traffic between the devices will be interrupted. To solve this problem, you can run this command to enable SHA-2 to be compatible with earlier versions.

After the ipsec authentication sha2 compatible enable or undo ipsec authentication sha2 compatible enable command is run, the command takes effect only after the reset ike sa command is run.

Example

# Enable IPsec SHA-2 to be compatible with earlier versions globally.
<HUAWEI> system-view
[HUAWEI] ipsec authentication sha2 compatible enable
