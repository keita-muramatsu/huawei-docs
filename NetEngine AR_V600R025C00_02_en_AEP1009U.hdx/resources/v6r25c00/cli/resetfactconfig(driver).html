reset factory-configuration

Function

The reset factory-configuration command configures the device to restore factory settings after restart.

Format

reset factory-configuration

Parameters

None

Views

User view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

If a function exception occurs due to incorrect configurations or a device needs to retire or be migrated from a network, you can run the reset factory-configuration command to restore the factory settings of the device. After the command is run, the device restarts and clears its service configurations and data files, rolling back to its factory settings.

Precautions

This command restores the factory settings of the device. Exercise caution when running this command. You are advised to run this command under the guidance of technical support personnel.

After the reset factory-configuration command is run, the system asks whether you want to restart the device. After you enter y, the device is restarted, and service configurations and data files of the device are cleared. The files and configurations to be cleared are mainly as follows:

  • Configurations in the configuration file.
  • Configured BIOS password.
  • Configurations in the flash memory.
  • Database files in NETCONF.
  • Data files in the file system.
Note:
  • The system software package for next startup, patch, module, and license files are not cleared.
  • This operation does not delete the protected directory and the $\_default.cfg file in the protected directory.

Example

# Reset factory configuration.
<HUAWEI> reset factory-configuration
Warning: Running this command will reset factory configuration and restart the device. Continue? [Y/N]:Y
Info: Reset factory configuration successfully!
Info: The system is rebooting......
