display ifit

Function

The display ifit command displays the configurations of IFIT flows.

Format

display ifit dynamic [ flow-id flow-id ]

display ifit dynamic-hop [ flow-id flow-id ]

display ifit

display ifit { source src-ip-address [ destination dest-ip-address ] | destination dest-ip-address }

display ifit { source-ipv6 src-ipv6-address [ destination-ipv6 dest-ipv6-address ] | destination-ipv6 dest-ipv6-address }

display ifit srv6-segment-list [ segment-list-id ]

display ifit static [ instance instance-name ]

display ifit static [ flow-id flow-id ]

Parameters

Parameter Description Value
flow-id flow-id

Specifies an IFIT flow ID.

The value is an integer that ranges from 0 to 18446744073709551615.
dynamic-hop

Displays the configuration of dynamic IFIT flows on transit nodes or the egress.

-
source src-ip-address

Specifies the source IPv4 address of an IFIT flow.

The value is in dotted decimal notation.
destination dest-ip-address

Specifies the destination IPv4 address of an IFIT flow.

The value is in dotted decimal notation.
source-ipv6 src-ipv6-address

Specifies the source IPv6 address of an IFIT flow.

The value is a 32-digit hexadecimal number in format X:X:X:X:X:X:X:X.
destination-ipv6 dest-ipv6-address

Specifies the destination IPv6 address of an IFIT flow.

The value is a 32-digit hexadecimal number in format X:X:X:X:X:X:X:X.
srv6-segment-list segment-list-id

Specifies the ID of a segment list.

The value is an integer ranging from 0 to 4294967295.
static

Displays the configuration of static IFIT flows.

-
instance instance-name

Specifies the name of an IFIT instance.

The value is a string of 1 to 31 case-sensitive characters without spaces.
dynamic

Displays the ingress configuration of dynamic IFIT flows.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

After data such as the measurement type is specified in the IFIT measurement system, you can run this command to view detailed information such as the packet loss rate and delay.

Table 1 Description of the display ifit command output
Item Description
Flow Classification

IFIT flow type (application-level quality measurement):

  • static: static flow.
  • dynamic-hop: transit node of a dynamic flow.
  • dynamic: dynamic service flow.
Flow Classification

IFIT flow type (SRv6 TE Policy quality detection):

  • dynamic-hop: egress.
  • srv6-segment-list: SRv6 TE Policy instance.
Flow Id

IFIT flow ID.
Flow Type

IFIT flow direction type:

  • unidirectional: unidirectional flow.
Instance Id

IFIT instance ID.
Instance Name

IFIT instance name.
Instance Type

IFIT instance type. Currently, the value can only be instance, indicating an instance with Header Type being 9.
Source IP Address/Mask Length

Source IP address and mask.
Source Port

Source port.
Destination IP Address/Mask Length

Destination IP address and mask.
Destination Port

Destination port.
Protocol

Protocol type:

  • any: No protocol number is specified.
  • udp: The protocol type is UDP.
  • tcp: The protocol type is TCP.
Dscp

DSCP value.
Interface

Name of the interface to which the IFIT flow is bound.
vpn-instance

VPN instance to which the IFIT flow is bound.
Loss Measure

Packet loss measurement status:

  • enable: The function is enabled.
  • disable: The function is disabled.

This function is enabled by default and can be modified.
Measure Mode

Measurement mode:

  • trace: hop-by-hop measurement.
  • e2e: end-to-end measurement.
Delay Measure

Delay measurement status:

  • enable: The function is enabled.
  • disable: The function is disabled.

This function is enabled by default and can be modified.
Interval

Configured measurement interval, in seconds.
Color

Color of an SRv6 TE Policy.
Segment List Id

ID of the segment list referenced by an SRv6 TE Policy's candidate path.
Binding SID

Binding SID of an SRv6 TE Policy.
Reverse Binding SID

Reverse binding SID of an SRv6 TE Policy.
EndPoint

Destination address of an SRv6 TE Policy.
Direction

Flow direction:

  • transitInput: input of the transmission point.
  • transitOutput: output of the transmission point.
  • egress: downstream.
  • conversionOutput: egress conversion point.
