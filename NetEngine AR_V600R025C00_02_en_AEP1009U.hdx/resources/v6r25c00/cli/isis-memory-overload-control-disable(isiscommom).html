isis memory-overload control disable

Function

The isis memory-overload control disable command disables control on IS-IS memory overload.

The undo isis memory-overload control disable command enables control on IS-IS memory overload.

By default, control on IS-IS memory overload is enabled.

Format

isis memory-overload control disable

undo isis memory-overload control disable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When the system memory is overloaded, each module needs to take necessary measures to control the memory usage increase or even reduce the memory usage. In this case, the IS-IS module takes any of the following measures to improve IS-IS resilience: restrict the establishment of new neighbor relationships, set the Overload bit in LSPs to be sent and reject new LSPs from neighbors, restrict the installation of newly imported routes, or delete imported routes.

This command and its undo form are used to globally control whether IS-IS responds to the memory status changes notified by the system.

Precautions

To minimize the impact of memory overload on services, you are advised not to disable IS-IS memory overload control.

To have the memory overload control function take effect, you also need to run the memory-usage reliability switch on command to enable memory overload reliability function.

Example

# Disable IS-IS memory-overload control.
<HUAWEI> system-view
[HUAWEI] isis memory-overload control disable
