sync-rate

Function

The sync-rate command sets the rate at which the device sends query packets to the TSM SSO server to query online users.

The undo sync-rate command restores the rate at which query packets are sent to the default value (200 times per second).

By default, query packets are sent 200 times per second.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR5710-S8P1XDSE-2LTE4EA.

Format

sync-rate rate

undo sync-rate

Parameters

Parameter Description Value
rate

Specifies the rate at which query packets are sent.

The value is an integer in the range from 5 to 500, in times per second.

Views

TSM SSO view

Default Level

2: Configuration level

Usage Guidelines

After you run the server-sync enable (TSM SSO view) command to enable online user synchronization on the TSM SSO server, the device checks whether the corresponding online user exists on the TSM SSO server based on the source IP address when the traffic without online user entries passes through the device or the user ages. If a large number of IP addresses need to be queried at the same time, the TSM SSO server may be congested and the device performance deteriorates. Therefore, you can run the sync-rate command to limit the rate at which query packets are sent.

If the rate at which query packets are sent is set to a small value, users go online slowly, affecting user experience. Therefore, exercise caution when setting the rate. Generally, retain the default value.

Example

# Set the rate at which query packets are sent to 100 times per second.
<HUAWEI> system-view
[HUAWEI] identity-management
[HUAWEI-identity-management] sso-tsm
[HUAWEI-identity-management-sso-tsm] sync-rate 100
