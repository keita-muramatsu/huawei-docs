hrp checksum enable

Function

The hrp checksum enable command enables the function of checking the validity of packets exchanged between the active and standby devices over the heartbeat link.

The undo hrp checksum enable command disables the function of checking the validity of packets exchanged between the active and standby devices on the heartbeat link.

By default, the checksum function of the messages that the active and standby devices interact on the heartbeat link is turned on.

Format

hrp checksum enable

undo hrp checksum enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In hot standby networking, two devices send and receive heartbeat packets, heartbeat link detection packets, configuration and entry backup packets, and configuration consistency check packets (hereinafter referred to as HRP packets) through heartbeat interfaces to notify each other of their configurations and status. To prevent malicious packet attacks and ensure the integrity and correct reception of HRP packets, you can run the hrp checksum enable command to check the validity of HRP packets.

Configuration Impact

After the hrp checksum enable command is configured, the sender in two devices will calculate the checksum of the HRP message to be sent according to the verification algorithm set by the hrp authentication-key command during the data encapsulation process; the receiver in two devices will also calculate the checksum according to the verification algorithm set by their own hrp authentication-key command after receiving the HRP message, and check the calculated HRP message. Check whether the sum is the same as that of the sender. If the two are the same, it will be received normally. Otherwise, it will be rejected.

The hrp checksum enable command supports backup. After the hot standby status of two devices is established, you only need to configure the command on the master device.

Example

# Enable HRP packet validity check.
<HUAWEI> system-view
[HUAWEI] hrp checksum enable
