ap update sftp-server max-connect-number

Function

The ap update sftp-server max-connect-number command sets the maximum number of APs that can be upgraded simultaneously in SFTP mode.

The undo ap update sftp-server max-connect-number command restores the default maximum number of APs that can be upgraded simultaneously in SFTP mode.

By default, a maximum of 50 APs can be upgraded simultaneously in SFTP mode.

Format

ap update sftp-server max-connect-number max-connect-number ipv4

ap update sftp-server max-connect-number max-connect-number ipv6

undo ap update sftp-server max-connect-number ipv4

undo ap update sftp-server max-connect-number ipv6

Parameters

Parameter Description Value
max-connect-number

Specifies the maximum number of APs that can be upgraded simultaneously.

The value is an integer that ranges from 1 to 64.
ipv4

Specifies the maximum number of APs that can be upgraded simultaneously when an IPv4 SFTP server is deployed.

-
ipv6

Specifies the maximum number of APs that can be upgraded simultaneously when an IPv6 SFTP server is deployed.

-

Views

WLAN view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

When APs are upgraded in SFTP mode, you can configure the value of max-connect-numberto modify the maximum number of APs that can be upgraded simultaneously.

  • If the number of APs to be upgraded is equal to or smaller than max-connect-number, all APs can be upgraded simultaneously.

  • If the number of APs to be upgraded is larger than max-connect-number, only the specified number of APs can be upgraded simultaneously. After the specified number of APs are upgraded, the remaining APs are upgraded automatically, until all APs are upgraded. The number of APs that are upgraded at a time cannot exceed the value of max-connect-number.

Precautions

The WAC can function as the SFTP server. Alternatively, use an external SFTP server, which is recommended.

  • When an external SFTP server is used, the maximum number of APs that can be upgraded simultaneously is the configured value of max-connect-number.

  • When a WAC is used as the SFTP server, a maximum of 15 APs can be upgraded simultaneously even if the specified number is larger than 15.

    When a WAC functions as the SFTP server, run this command to set the maximum number of APs that can be upgraded simultaneously to an integer in the range of 1 to 15. During the upgrade, a maximum of 1 to 15 APs can be upgraded at a time until all APs are upgraded.

    If max-connect-number is set larger than 15, an error message will be displayed after the first 15 APs are upgraded. The remaining APs cannot be automatically upgraded. You have to repeat the command until all APs are upgraded.

    When a WAC is used as the SFTP server, if n VTY users have logged in, the maximum number of APs that can be upgraded simultaneously decreases by n – 1.

When IPv4 and IPv6 SFTP servers are both configured, set the parameter max-connect-number in both the two IP versions.

Example

# Set the maximum number of APs that can be upgraded simultaneously in SFTP mode to 10.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap update sftp-server max-connect-number 10 ipv4
