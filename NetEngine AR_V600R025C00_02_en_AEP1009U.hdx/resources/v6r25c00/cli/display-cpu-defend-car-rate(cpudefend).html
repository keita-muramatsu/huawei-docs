display cpu-defend rate

Function

The display cpu-defend rate command displays the rate of sending protocol packets to the CPU in wired mode.

Format

For AR8700 series, AR6700-H series:

display cpu-defend rate [ packet-type packet-type ] mcu

For AR8100 series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5700-H series, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR5710-S8TWDSE-LTE4EA, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S10T1X2:

display cpu-defend rate [ packet-type packet-type ] all

display cpu-defend rate [ packet-type packet-type ] slot slot-id

Usage Guidelines

Usage Scenario

You can run the display cpu-defend rate command to view the rate of sending protocol packets to the CPU when checking the configuration of an attack defense policy. In this way, you can determine which type of protocols may attack the CPU based on the rate.

To ensure normal operation of other services and protect the CPU, the rate of incremental protocol packets is calculated only in a specified period after you run the display cpu-defend rate command and displayed on the terminal. After you run this command, a message is displayed to wait for a while.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the rate of ARP request packets sent to the CPU on the main control board.
<HUAWEI> display cpu-defend rate packet-type arp-request mcu
Rate(PPS) on mcu :
---------------------------------------------------------------
PacketType                         Passed              Dropped 
---------------------------------------------------------------
arp-request                             0                    0
---------------------------------------------------------------
# Display the rate of ARP request packets sent to the CPU.
<HUAWEI> display cpu-defend rate packet-type arp-request slot 0
Rate(PPS) on slot 0 :                                                                                                               
---------------------------------------------------------------                                                                     
PacketType                         Passed              Dropped                                                                      
---------------------------------------------------------------                                                                     
arp-request                             0                    0                                                                      
---------------------------------------------------------------
Table 1 Description of the display cpu-defend rate command output
Item Description
Rate(PPS) on slot 0

Rate of packets on slot 0.
Rate(PPS) on mcu

Rate of packets to the CPU on the main control board.
PacketType

Packet type.
Passed

Number of forwarded packets within one second.
Dropped

Number of discarded packets within one second.
