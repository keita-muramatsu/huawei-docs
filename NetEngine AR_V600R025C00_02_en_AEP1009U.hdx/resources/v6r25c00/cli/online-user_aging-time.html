online-user aging-time (TSM SSO view)

Function

The online-user aging-time command sets the aging time of online TSM SSO users.

The undo online-user aging-time command restores the default setting.

By default, the aging time of TSM SSO online user entries is 1440 minutes.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR5710-S8P1XDSE-2LTE4EA.

Format

online-user aging-time aging-time

undo online-user aging-time

Parameters

Parameter Description Value
aging-time

Aging time of online users.

The value is an integer that ranges from 1 to 65535. The default value is 1440, in minutes.

Views

TSM SSO view

Default Level

2: Configuration level

Usage Guidelines

After a user is authenticated by the TSM SSO server when accessing the Internet, the TSM SSO server sends a TSM SSO message to the device. Multiple devices can receive the SSO message.

Each device parses TSM SSO messages, logs online users, and creates an online user entry. The default pre-aging time is 1440 minutes.

Within the aging time, the device updates the online user table based on the actual situation to save online user table space resources.

  • If a device does not receive user service traffic or TSM SSO messages, the entry corresponding to the user is deleted.
  • If a device receives user service traffic, the device updates the aging time of online user entries (default value: 1440 minutes).

Example

# Set the timeout period of online user entries to 10 minutes.
<HUAWEI> system-view
[HUAWEI] identity-management
[HUAWEI-identity-management] sso-tsm
[HUAWEI-identity-management-sso-tsm] online-user aging-time 10
