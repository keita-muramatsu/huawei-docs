ucl-group(aaa-access-user view)

Function

The ucl-group command binds a UCL group to a local access user.

The undo ucl-group command unbinds the UCL group from the local access user.

By default, no UCL group is bound to a local access user.

Format

ucl-group name group-name

undo ucl-group [ name group-name ]

Parameters

Parameter Description Value
name group-name

Specifies the name of a UCL group.

The UCL group must exist.

Views

aaa-access-user view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

After a local access user is created using the local-access-user command in the AAA view, you can run the ucl-group command to bind a UCL group to the local access user. You can then reference the UCL group in a security policy to implement the security policy.

Prerequisites

Before binding a local access user to a UCL group, ensure that the UCL group has been created using the ucl-group command in the system view.

Example

# Bind the UCL group abc to the local access user huawei. 
<HUAWEI> system-view
[HUAWEI] ucl-group name abc
[HUAWEI] aaa
[HUAWEI-aaa] local-access-user huawei
[HUAWEI-aaa-access-user-huawei] ucl-group name abc
