destination-address-exclude (NAT policy rule view)

Function

The destination-address-exclude command excludes specific destination addresses from a policy rule, so that the device does not match the traffic destined for these addresses with this policy.

The undo destination-address-exclude command deletes the destination addresses excluded from a policy rule.

By default, this function is not configured.

Format

For AR8700 series, AR6700-H series:

destination-address-exclude { address-set address-set-name &<1-6> | ipv4-address { ipv4-mask-length | mask mask-address | wildcard wildcard } | ipv6-address ipv6-prefix-length | range { ipv4-start-address ipv4-end-address | ipv6-start-address ipv6-end-address } }

undo destination-address-exclude { address-set address-set-name &<1-6> | ipv4-address { ipv4-mask-length | mask mask-address | wildcard wildcard } | ipv6-address ipv6-prefix-length | range { ipv4-start-address ipv4-end-address | ipv6-start-address ipv6-end-address } }

For AR8100 series, AR8700 series, AR6700-H series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5700-H series, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR5710-S8TWDSE-LTE4EA, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S10T1X2, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S:

destination-address-exclude { ipv4-address { ipv4-mask-length | mask mask-address | wildcard wildcard } | range ipv4-start-address ipv4-end-address }

undo destination-address-exclude { ipv4-address { ipv4-mask-length | mask mask-address | wildcard wildcard } | range ipv4-start-address ipv4-end-address }

Parameters

Parameter Description Value
address-set address-set-name

Specifies the name of an address or address group.

NOTE:

This parameter is supported only on the AR8700 series and AR6700-H series.

The address or address group must exist. A maximum of six addresses or address groups can be specified at a time. The value is a case-sensitive character string. The length of a name without spaces ranges from 1 to 32 characters. The length of a name with spaces ranges from 3 to 34 characters. If a name contains spaces, the name must be enclosed with quotation marks (for example, "user for test"). The name cannot contain any question marks (?), commas (,), or quotation marks (").
ipv4-address

Specifies an IPv4 address.

The value is in dotted decimal notation.
ipv4-mask-length

Specifies a mask for an IPv4 address.

The value is an integer that ranges from 1 to 32.
mask mask-address

Specifies a mask for an IPv4 address.

The value is in dotted decimal notation and digits 1 in its binary form can be inconsecutive, such as 255.0.255.0 (11111111 00000000 11111111 00000000). In the binary form, digits 1 are to be matched, whereas digits 0 are not. For example, 192.168.1.1/255.0.255.0 indicates that only IP addresses in the 192.*.1.* form are to be matched.
wildcard wildcard

Specifies the wildcard of an IPv4 address.

The value is in dotted decimal notation and digits 1 in its binary form can be inconsecutive, such as 0.255.0.255 (00000000 11111111 00000000 11111111). In the binary form, digits 0 are to be matched, whereas digits 1 are not. For example, 192.168.1.1/0.255.0.255 indicates that only IP addresses in the 192.*.1.* form are to be matched.
ipv6-address

Specifies an IPv6 address.

NOTE:

This parameter is supported only on the AR8700 series and AR6700-H series.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
ipv6-prefix-length

Specifies the prefix length of an IPv6 address.

NOTE:

This parameter is supported only on the AR8700 series and AR6700-H series.

The value is an integer ranging from 1 to 128.
range

Indicates the address range.

-
ipv4-start-address

Specifies the start address of an IPv4 address range.

The value is in dotted decimal notation.
ipv4-end-address

Specifies the end address of an IPv4 address range.

The value is in dotted decimal notation.
ipv6-start-address

Specifies the start address of an IPv6 address range.

NOTE:

This parameter is supported only on the AR8700 series and AR6700-H series.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
ipv6-end-address

Specifies the end address of an IPv6 address range.

NOTE:

This parameter is supported only on the AR8700 series and AR6700-H series.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.

Views

NAT policy rule view

Default Level

2: Configuration level

Usage Guidelines

When referencing destination addresses in a policy, you can run the destination-address-exclude command to exclude specific destination addresses. Traffic destined for the excluded addresses does not match the policy.

When configuring a NAT policy, you can reference destination addresses in the policy to implement IP address-based NAT. For example, two address segments Addr_group1 (address range is 10.1.1.40 to 10.1.1.50) and Addr_group2 (address range is 10.1.1.0/24) are available. NAT needs to be disabled for traffic destined for addresses in Addr_group1 but needs to be implemented for traffic destined for addresses in Addr_group2, and NATed traffic needs to be permitted. You can use configuration method 1 to assign different actions to different addresses. This method increases policies as well as policy maintenance workloads. Alternatively, you can use configuration method 2 to run the destination-address-exclude command to configure the policy. This method has the same effect as method 1 and does not need additional policies.

Method 1:

<huawei> system-view

[HUAWEI] nat-policy

[HUAWEI-policy-nat] rule name policy_1

[HUAWEI-policy-nat-rule-policy_1] destination-address range 10.1.1.40 10.1.1.50

[HUAWEI-policy-nat-rule-policy_1] action no-nat

[HUAWEI-policy-nat-rule-policy_1] quit

[HUAWEI-policy-nat] rule name policy_2

[HUAWEI-policy-nat-rule-policy_2] destination-address 10.1.1.0 24

[HUAWEI-policy-nat-rule-policy_2] action source-nat address-group group1

[HUAWEI-policy-nat-rule-policy_2] quit

Method 2:

<huawei> system-view

[HUAWEI] nat-policy

[HUAWEI-policy-nat] rule name policy_nat

[HUAWEI-policy-nat-rule-policy_nat] destination-address-exclude range 10.1.1.40 10.1.1.50

[HUAWEI-policy-nat-rule-policy_nat] destination-address 10.1.1.0 24

[HUAWEI-policy-nat-rule-policy_nat] action source-nat address-group group1

Example

# Exclude destination addresses 10.1.1.0/24 from the NAT policy rule. 
<HUAWEI> system-view
[HUAWEI] nat-policy
[HUAWEI-policy-nat] rule name policy_nat
[HUAWEI-policy-nat-rule-policy_nat] destination-address-exclude 10.1.1.0 24
