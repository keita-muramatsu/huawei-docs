he mcs-map (SSID profile view)

Function

The he mcs-map command configures the maximum number of 802.11ax spatial streams and the MCS value in an SSID profile.

The undo he mcs-map command restores the default maximum number of 802.11ax spatial streams and MCS value in an SSID profile.

By default, in an SSID profile, the number of spatial streams sent and received in 802.11ax is 8, and the MCS of the spatial streams is 11.

Format

he { tx | rx } mcs-map nss nss-value map mcs-value

undo he { tx | rx } mcs-map

Parameters

Parameter Description Value
tx

Transmits data.

-
rx

Receives data.

-
nss nss-value

Specifies the number of spatial streams.

The value is an integer that ranges from 1 to 8.
map mcs-value

Specifies the MCS value of the spatial streams.

The value is 7, 9, or 11.

Views

SSID profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The rate of an 802.11ax-compliant AP is configured based on the MCS index. A larger MCS value indicates a higher transmission rate.

  • When nss-value is greater than or equal to the number of spatial streams supported by an AP, the number of available spatial streams for the AP is the same as the AP capability and the maximum MCS value corresponding to all spatial streams of the AP is the same as mcs-value.
  • When nss-value is smaller than the number of spatial streams supported by an AP, the number of available spatial streams for the AP is the same as nss-value, and the maximum MCS value corresponding to the available spatial streams for the AP is same as mcs-value but does not take effect for remaining spatial streams.

    For example, if nss-value is set to 2 and an AP supports 3 spatial streams, the maximum number of available spatial streams for the AP is 2, and the corresponding MCS value is mcs-value.

Precautions

This configuration takes effect only when an AP communicates with STAs using 802.11ax.

Modifying the configuration may cause STAs to go offline and deteriorate performance.

Example

# Set the number of spatial streams to 4 and the MCS value of the spatial streams to 9 for receiving data in the SSID profile.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ssid-profile name ssid1
[HUAWEI-wlan-ssid-prof-ssid1] he rx mcs-map nss 4 map 9
Info: "vht/he mcsmap" in the SSID profile and "vht rx mcsmap" in the 5G radio profile take effect in descending order.              
Warning: This action may cause service interruption and performance degradation. Continue? [Y/N]:y
