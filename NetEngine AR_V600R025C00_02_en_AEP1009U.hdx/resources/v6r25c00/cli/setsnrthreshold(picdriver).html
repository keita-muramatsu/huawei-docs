set snr up-threshold

Function

The set snr up-threshold command configures the SNR threshold of an electrical interface on a PHY device.

The undo set snr up-threshold command restores the default SNR threshold of an electrical interface on a PHY device.

By default, the SNR value varies according to the PHY device and electrical interface. For details, see "Precautions."

Format

set snr up-threshold threshold-value

undo set snr up-threshold

undo set snr up-threshold [ threshold-value ]

Parameters

Parameter Description Value
threshold-value

Specifies the SNR threshold of an electrical interface on a device.

The value is an integer. The SNR value range varies according to the PHY device and electrical interface. For details, see "Precautions."

Views

Multi-GE interface view, Layer 2 multi-GE interface view, GE electrical interface view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If a Huawei device's electrical interface connected to a non-Huawei device goes down due to signal problems, network maintenance personnel can run this command to adjust the SNR value of the electrical interface, improving interface interconnection adaptability.

Precautions

You can run the display port phy-register command to check whether a device supports this function and view the default value and value range of the SNR. If the command output contains "snr up threshold...," the device supports this function. In addition, you can view the SNR value of the interface based on the information.

Example

# Configure the SNR threshold of an electrical interface on a device.
<HUAWEI> system-view
[HUAWEI] interface GE0/0/1
[HUAWEI-GE0/0/1] set snr up-threshold 30
