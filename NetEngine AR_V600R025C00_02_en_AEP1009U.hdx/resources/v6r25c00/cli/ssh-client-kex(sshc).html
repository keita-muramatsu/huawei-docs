ssh client key-exchange

Function

The ssh client key-exchange command configures a key exchange algorithm list on an SSH client.

The undo ssh client key-exchange command restores the default configuration.

By default, an SSH client uses the curve25519_sha256, dh_group16_sha512, and dh_group_exchange_sha256 key exchange algorithms.

Format

ssh client key-exchange { dh_group_exchange_sha256 | dh_group_exchange_sha1 | dh_group1_sha1 | ecdh_sha2_nistp256 | ecdh_sha2_nistp384 | ecdh_sha2_nistp521 | sm2_kep | dh_group14_sha1 | dh_group16_sha512 | curve25519_sha256 | sm2_sm3 } *

undo ssh client key-exchange

Usage Guidelines

Usage Scenario

The SSH server and client need to negotiate a key exchange algorithm for the packets transmitted between them. You can run this command to configure a key exchange algorithm list for the SSH client. The server compares the key exchange algorithm list sent by the client with its own key exchange algorithm list, and selects the first matched key exchange algorithm as the key exchange algorithm for packet transmission. If no algorithm on the client's list matches an algorithm on the server's list, the negotiation fails.

The algorithms are listed in descending order of security level: curve25519_sha256 > ecdh_sha2_nistp521 > ecdh_sha2_nistp384 > ecdh_sha2_nistp256 > dh_group16_sha512 > dh_group_exchange_sha256 > sm2_sm3 > sm2_kep > dh_group14_sha1 > dh_group_exchange_sha1 > dh_group1_sha1

This command applies to both IPv4 and IPv6.

Precautions

  • For security purposes, you are advised to use the curve25519_sha256, ecdh_sha2_nistp521, ecdh_sha2_nistp384, and ecdh_sha2_nistp256 key exchange algorithms.
  • The dh_group_exchange_sha1, dh_group1_sha1, and dh_group14_sha1 parameters in this command can be used only after the weak security algorithm/protocol feature package (WEAKEA) is installed using the install feature-software WEAKEA command.

Example

# Add the dh_group_exchange_sha256 algorithm to the key exchange algorithm list on the SSH client. 
<HUAWEI> system-view
[HUAWEI] ssh client key-exchange dh_group_exchange_sha256
