default match (SRv6 mapping policy TE class view)

Function

The default match command configures the mapping between the default TE-Class value and an SRv6 TE Policy, SPR policy, or native IP link.

The undo default match command deletes the mapping between the default TE-Class value and SRv6 TE Policy, SPR policy, or native IP link.

By default, the mapping between an SRv6 TE Policy, SPR policy, or native IP link in an SRv6 TE flow group and the default TE-Class value is not configured.

Format

default match spr-policy spr-name

default match { srv6-te-policy color color-value | native-ip }

undo default [ match spr-policy spr-name ]

undo default [ match { srv6-te-policy color color-value | native-ip } ]

Parameters

Parameter Description Value
srv6-te-policy

Steers traffic into an SRv6 TE Policy.

-
color color-value

Specifies the color of an SRv6 TE Policy.

The value is an integer ranging from 0 to 4294967295.
native-ip

Steers traffic to a native IP link.

-
spr-policy spr-name

Specifies the name of an SPR template.

The value is a string of 1 to 31 case-sensitive characters. The character string can contain spaces if it is enclosed with double quotation marks (").

Views

SRv6 mapping policy TE class view

Default Level

2: Configuration level

Usage Guidelines

  • The index te-class match spr-policy and default match spr-policy commands configure the mapping between SPR policies and TE-Class values.
  • The index te-class match native-ip and default match native-ip commands configure the mapping between native IP links and TE-Class values.
  • The index te-class match srv6-te-policy color and default match srv6-te-policy color commands configure the mapping between SRv6 TE Policies, colors, and TE-Class values.

    Each SRv6 TE Policy in an SRv6 TE flow group has its own color attribute. In an SRv6 TE flow group, TE-Class values and SRv6 TE Policies are associated using the color attribute. IP packets can then be steered into the specified SRv6 TE Policy based on their TE-Class values. If no SRv6 TE Policy matching a specified TE-Class value is found, the packets are steered into the SRv6 TE Policy specified using the default match command.

Example

# Configure the mapping between the color of an SRv6 TE Policy and the default TE-Class value in an SRv6 TE flow group.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] mapping-policy MapPolicy color 34
[HUAWEI-segment-routing-ipv6-mapping-policy-MapPolicy] match-type te-class
[HUAWEI-segment-routing-ipv6-mapping-policy-MapPolicy-te-class] default match srv6-te-policy color 8
