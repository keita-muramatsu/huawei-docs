portal auth-network

Function

The portal auth-network command configures a source subnet for Portal authentication.

The undo portal auth-network command restores the default value.

By default, the source subnet for Portal authentication is 0.0.0.0/0, indicating that Portal authentication is performed for users on all subnets.

Format

portal auth-network ip-address { mask-length | mask-address }

undo portal auth-network { ip-address { mask-length | mask-address } | all }

Parameters

Parameter Description Value
ip-address

Specifies the subnet address for Portal authentication.

The value is in dotted decimal notation.
mask-length

Specifies the mask length.

The value is an integer that ranges from 1 to 32.
mask-address

Specifies the mask of the address.

The value is in dotted decimal notation.
all

Deletes all Portal authentication subnets.

-

Views

Portal access profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After the source subnet for Portal authentication is configured, only packets of users on the source subnet can trigger Portal authentication. If a user does not perform Portal authentication before accessing an external network and the user packet does not match the authentication-free rule and the user is not on the source subnet, the device discards the user packet.

Precautions

If an authentication subnet is configured, only STAs with IP addresses on the authentication subnet can pass the authentication.

If access devices are not on the authentication subnet, Layer 2 Portal redirection succeeds, but Layer 3 Portal redirection fails.

Example

# Set the source authentication subnet to 10.1.1.0/24 in the Portal access profile p1.
<HUAWEI> system-view
[HUAWEI] portal-access-profile name p1
[HUAWEI-portal-access-profile-p1] portal auth-network 10.1.1.0 24
