sa(E1 interface view)

Function

The sa command sets the content of five outgoing sa-bits.

The undo sa command restores the default configuration.

By default, the content of the five outgoing sa-bits is 0.

This command is supported only on the AR8700 series, AR5710-S10T1X2, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series and AR6700-H series.

Format

sa sa4 sa5 sa6 sa7 sa8

undo sa [ sa4 sa5 sa6 sa7 sa8 ]

Parameters

Parameter Description Value
sa4

Sets the content of the outgoing sa4 bit.

The value is an integer ranging from 0 to 255.
sa5

Sets the content of the outgoing sa5 bit.

The value is an integer ranging from 0 to 255.
sa6

Sets the content of the outgoing sa6 bit.

The value is an integer ranging from 0 to 255.
sa7

Sets the content of the outgoing sa7 bit.

The value is an integer ranging from 0 to 255.
sa8

Sets the content of the outgoing sa8 bit.

The value is an integer ranging from 0 to 255.

Views

E1 interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When an interface works in CE1 mode, the sa4 to sa8 fields in an E1 frame can be used to transmit low-speed data. By default, the fields are set to 0. In some scenarios, the peer end verifies the received SA content. Therefore, the SA content supports configuration on the interface to ensure normal interconnection.

Prerequisites

This command can be run only when the interface works in CE1 mode (configured through the using ce1 command).

Precautions

You can run this command only when the device supports E1 interfaces.

  • By default, SA is set to 0. To configure it, collect the configuration of the remote device.
  • If the working mode of an interface is changed from CE1 to E1, the SA configuration on the interface is deleted.

Example

# Set the content of five outgoing sa-bits to 1, 2, 3, 4, and 5, respectively.
<HUAWEI> system-view
[HUAWEI] controller e1 0/0/0
[HUAWEI-E1 0/0/0] sa 1 2 3 4 5
