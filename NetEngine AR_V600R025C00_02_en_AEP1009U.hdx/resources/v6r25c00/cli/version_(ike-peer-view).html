version (IKE peer view)

Function

The version command sets the IKE version number of an IKE peer.

The undo version command cancels the configuration.

By default, the IKEv1 feature package is not loaded on the device, and only IKEv2 is enabled for IKE peers. After the IKEv1 feature package is loaded, both IKEv1 and IKEv2 are enabled for IKE peers by default.

Format

version { 1 | 2 }

undo version { 1 | 2 }

Parameters

Parameter Description Value
1

Indicates that the IKE version number is 1.

-
2

Indicates that the IKE version number is 2.

-

Views

IKE peer view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

IKEv1 and IKEv2 cannot be disabled simultaneously.

If IKEv1 and IKEv2 are enabled simultaneously, the initiator uses IKEv2, and the responder can use IKEv1 or IKEv2.

Prerequisites

By default, the device does not support this command, that is, SA negotiation through IKEv1 is not supported. To use this command, install the IKEv1 feature package.

Precautions

When an IKE proposal that uses the AES-GCM algorithm is referenced on an IKE peer, the IKE version of the IKE peer cannot be configured to support only IKEv1. When an IKE proposal that uses the SM4 algorithm is referenced on an IKE peer, the IKE version of the IKE peer cannot be configured to support only IKEv2.

Example

# Configure IKE peer peer1 to initiate negotiation using IKEv1. 
<HUAWEI> system-view
[HUAWEI] ike peer peer1
[HUAWEI-ike-peer-peer1] undo version 2
