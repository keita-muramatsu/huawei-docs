display ike statistics

Function

The display ike statistics command displays IKE statistics.

Format

display ike statistics { v1 | v2 } [ slot slot-id cpu cpu-id ]

Parameters

Parameter Description Value
v1

Displays IKEv1 running statistics.

By default, the device does not support this parameter, that is, SA negotiation through IKEv1 is not supported. To specify this parameter, install the IKEv1 feature package.

-
v2

Displays IKEv2 statistics.

-
slot slot-id

Displays IKE statistics on a specified CPU in a specified slot.

The value varies depending on device models.
cpu cpu-id

Displays IKE statistics on a specified CPU in a specified slot.

The value varies depending on device models.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

When a fault occurs on the IPsec tunnel that is established through IKE negotiation, you can check statistics about IKE peers, IKE SAs, and DPD packets to diagnose and locate the fault.
