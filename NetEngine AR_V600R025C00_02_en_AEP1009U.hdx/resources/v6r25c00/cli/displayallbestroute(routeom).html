display ip routing-table all-routes(all-views)

Function

The display ip routing-table all-routes command displays the IPv4 routes with a specified prefix in all mask address segments.

The display ipv6 routing-table all-routes command displays the IPv6 routes with a specified prefix in all mask address segments.

Format

display ip routing-table [ vpn-instance vpn-instance-name ] prefix [ mask | masklength4 ] all-routes

display ipv6 routing-table [ vpn-instance vpn-instance-name ] ipv6prefix [ masklength6 ] all-routes

Parameters

Parameter Description Value
vpn-instance vpn-instance-name

Specifies a VPN instance name.

The value is a string of 1 to 31 case-sensitive characters. It cannot contain spaces. The VPN instance name cannot be _public_. Spaces can be contained if the string is enclosed in double quotation marks (").
prefix

Specifies a destination IP address.

The value is in dotted decimal notation.
mask

Indicates the mask of an IP address.

The value is in dotted decimal notation.
masklength4

Specifies the address mask length.

The value is an integer ranging from 0 to 32.
ipv6

Indicates IPv6 information.

-
ipv6prefix

Specifies the IPv6 address prefix.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
masklength6

Specifies an IPv6 address mask length.

The value is an integer ranging from 0 to 128.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To query the routes with a specified prefix in all mask address segments, run this command. The prefix is the result of the AND operation between the prefix and the mask. If no mask is specified, the default mask length of IPv4 routes is 32, and the default mask length of IPv6 routes is 128.
