reset ips-signature statistics

Function

The reset ips-signature statistics command clears IPS signature statistics.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

reset ips-signature statistics { signature-id signature-id | all } { event | all } [ slot slot-id cpu cpu-id ]

Parameters

Parameter Description Value
signature-id signature-id

Specifies the ID of an IPS signature.

The value is an integer ranging from 1 to 16777215.

The value must be the ID of an existing IPS signature.
all

The first all parameter indicates all IPS signatures.

-
all

The second all parameter indicates all statistics.

-
event

Indicates the match count of an IPS signature.

-
slot slot-id

Specifies a slot ID.

The value varies depending on device models.
cpu cpu-id

Specifies the CPU ID.

The value varies depending on device models.

Views

User view

Default Level

3: Management level

Usage Guidelines

Signature statistics cannot be restored after being cleared. Exercise caution when running this command.

Example

# Clear the match count of the IPS signature whose ID is 54330.
<HUAWEI> reset ips-signature statistics signature-id 54330 event
# Clear all statistics of all signatures.
<HUAWEI> reset ips-signature statistics all all
