backup hot-standby (SRv6 TE Policy view)

Function

The backup hot-standby enable command enables hot standby (HSB) for an SRv6 TE Policy.

The undo backup hot-standby enable command deletes the preceding configuration.

The backup hot-standby disable command disables HSB for an SRv6 TE Policy.

The undo backup hot-standby disable command deletes the preceding configuration.

The undo backup hot-standby command deletes the HSB configuration of an SRv6 TE Policy and allows a device to inherit the configuration of the srv6-te-policy backup hot-standby enable command run in the Segment Routing IPv6 view.

By default, the configuration of the srv6-te-policy backup hot-standby enable command run in the Segment Routing IPv6 view is inherited directly.

Format

backup hot-standby { enable | disable }

undo backup hot-standby [ { enable | disable } ]

Parameters

Parameter Description Value
enable

Enables HSB for an SRv6 TE Policy.

-
disable

Disables HSB for an SRv6 TE Policy. After you run the backup hot-standby disable command, HSB path information about the SRv6 TE Policy is deleted.

-

Views

SRv6 TE policy view

Default Level

2: Configuration level

Usage Guidelines

To improve SRv6 TE Policy reliability, you are advised to configure the HSB function for implementing end-to-end protection.

The srv6-te-policy backup hot-standby enable command is used to enable HSB for all SRv6 TE Policies, whereas the backup hot-standby command is used to enable or disable HSB for a single SRv6 TE Policy. If both the srv6-te-policy backup hot-standby enable and backup hot-standby commands are run for an SRv6 TE Policy, the backup hot-standby command configuration takes precedence.

Example

# Disable HSB for an SRv6 TE Policy.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] srv6-te policy policy1 endpoint 2001:DB8:1::1 color 100
[HUAWEI-segment-routing-ipv6-policy-policy1] backup hot-standby disable
