packet-reassembly

Function

The packet-reassembly cache command sets the number of fragments cached when an MP-Group interface reassembles received fragments.

The undo packet-reassembly cache command restores the default value.

By default, a maximum of 512 fragments can be cached during MP-Group packet reassembly.

This command is supported only on the AR8700 series, AR5710-S10T1X2, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series and AR6700-H series.

Format

packet-reassembly cache cache-size

undo packet-reassembly cache [ cache-size ]

Parameters

Parameter Description Value
cache-size

Specifies the number of packet fragments to be cached.

The value is an integer that ranges from 64 to 1024. The default value is 512.
cache

Configures the number of packet fragments to be cached.

-

Views

MP-group interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

MP is bound with multiple channels. If the traffic contains large-sized packets that need to be fragmented and the traffic rate exceeds the bandwidth of the MP link, the receive end fails to reassemble the fragmented packets. You can run this command to adjust the number of packet fragments cached on the receive end to reduce reassembly failures.

Precautions

After the configuration, run the shutdown command followed by the undo shutdown command or run the restart command in the interface view to restart the interface for the configuration to take effect.

Example

# Configure the MP-Group interface to cache 200 packet fragments during reassembly of received packet fragments.
<HUAWEI> system-view
[HUAWEI] interface Mp-group 0/0/1
[HUAWEI-Mp-group0/0/1] packet-reassembly cache 200
