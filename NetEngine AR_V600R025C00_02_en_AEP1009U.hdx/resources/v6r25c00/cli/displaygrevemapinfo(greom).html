display tunnel mapping

Function

The display tunnel mapping configuration command displays configurations in EoGRE primary/backup scenarios.

The display tunnel mapping command allows you to view the binding between a tunnel interface and a VE interface.

Format

display tunnel mapping configuration

display tunnel mapping [ interface { { ifName | ifType ifNum } } ]

Parameters

Parameter Description Value
interface

Interface.

-
ifName

Specifies an interface name.

The value is a string of 1 to 63 case-sensitive characters, spaces not supported.
ifType

Specifies an interface type.

-
ifNum

Specifies an interface number.

-

Views

All views

Default Level

3: Management level

Usage Guidelines

After configuring active/standby EoGRE, you can run this command to view the following information:

  • Binding relationship between a VE interface and a tunnel interface
  • Whether preemption is enabled for the primary and backup EoGRE tunnels
  • Preemption delay

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the binding between a specified tunnel interface and a VE interface.
<HUAWEI> display  tunnel mapping  interface  Tunnel  1

-----------------------------------------------------------------------
Virtual-Ethernet0/0/1      Tunnel1        128          UP       Active 
-----------------------------------------------------------------------
Total:1

Table 1 Description of the display tunnel mapping command output
Item Description
Tunnel port

Tunnel interface bound to the VE interface.
Virtual-Ethernet Port

VE interface.
Priority

Priority of the tunnel interface bound to the VE interface.
Status

Status of the tunnel interface bound to the VE interface:

  • UP.
  • DOWN.
Role

Role of the tunnel interface bound to the VE interface:

Active: The tunnel interface bound to the VE interface is active.

Standby: The tunnel interface bound to the VE interface is inactive.

The EoGRE tunnel is working and can forward data only when the tunnel interface bound to the VE interface is up and the interface role is active.
Interface

Interface name.
Preempt

Whether preemption is enabled for the primary and backup EoGRE tunnels.

enable: The preemption function is enabled for the primary and backup EoGRE tunnels.

disable: The preemption function is disabled for the primary and backup EoGRE tunnels.
Preempt delay(sec)

Preemption delay of the primary and backup EoGRE tunnels, in seconds.
Icmp-detect

Whether ICMP packet-based heartbeat detection is enabled for a GRE tunnel.

enable: ICMP packet-based heartbeat detection is enabled for a GRE tunnel.

disable: ICMP packet-based heartbeat detection is disabled for a GRE tunnel.
Period(sec)

Timer period for the source end of the GRE tunnel to send ICMP packets, in seconds.
Retry times

Unreachability counter parameter.
Total

Total number of bindings.
