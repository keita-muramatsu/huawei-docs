ip route-static vpn-instance vpn-instance

Function

The ip route-static vpn-instance command configures an IPv4 static route for a VPN instance.

The undo ip route-static vpn-instance command deletes an IPv4 static route from a VPN instance.

By default, no IPv4 static routes are configured for a VPN instance.

Format

ip route-static vpn-instance vpn-source-name prefix { mask | mask-length } { public | vpn-instance vpn-destination-name } [ preference preference-value | tag tag-value ] * [ description description-value ]

undo ip route-static vpn-instance vpn-source-name prefix { mask | mask-length } { public | vpn-instance vpn-destination-name }

Parameters

Parameter Description Value
prefix

Specifies a destination IP address.

The value is in dotted decimal notation.
mask

Specifies the subnet mask of a destination address.

The value is in dotted decimal notation.
mask-length

Specifies the mask length of the destination address. Because a 32-bit mask should be composed of consecutive "1"s, a mask in dotted decimal notation can be presented by the mask length.

The value is an integer that ranges from 0 to 32.
public

Searches for a forwarding path on the public network.

-
vpn-instance vpn-destination-name

Specifies the name of the target VPN instance for forwarding path searching.

The value is a string of 1 to 31 case-sensitive characters without spaces. The VPN instance name cannot be _public_. The character string can contain spaces if it is enclosed with double quotation marks (").
vpn-instance vpn-source-name

Specifies the name of a source VPN instance. The configured static routes are added to the routing table of the specified VPN instance.

The value is a string of 1 to 31 case-sensitive characters without spaces. The VPN instance name cannot be _public_. The character string can contain spaces if it is enclosed with double quotation marks (").
preference preference-value

Specifies a preference value for the static route.

The value is an integer that ranges from 1 to 255. The default value is 60. A smaller value indicates a higher preference.
tag tag-value

Specifies the tag value of a route. You can configure different tag values to classify routes and implement different routing management policies.

The value is an unsigned integer ranging from 1 to 4294967295. The default value is 0.
description description-value

Specifies a description for the static route.

The value is a string of 1 to 150 case-sensitive characters.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In a simple IPv4 VPN, the ip route-static vpn-instance command can be used to configure static routes for this VPN.

If the destination address and mask of a static route are all 0s, the static route is a default route.

Prerequisites

A VPN instance has been created using the ip vpn-instance command when you configure a static route for the VPN instance.

Before binding a static route to an NQA test instance, you need to create the NQA test instance.

Before binding a static route to an NQA group, you need to create the NQA group.

Follow-up Procedure

If a configured static route needs to be sent to the peer PE, import the static route into BGP running between the PEs.

Precautions

For static routes with the same prefix but different preferences, you can configure a static route with a specified next-hop IP address and a static route with only a VPN instance specified as the next hop; in addition, you can configure a static route with a specified outbound interface and a static route with only a VPN instance specified as the next hop; you can also configure multiple static routes with only VPN instances specified as next hops.

Example

# Configure for VPN instance vpn1 a static route, with 10.1.1.1/32 as the destination address and VPN instance vpn2 as the next hop.
<HUAWEI> system-view
[HUAWEI] ip vpn-instance vpn1
[HUAWEI-vpn-instance-vpn1] ipv4-family
[HUAWEI-vpn-instance-vpn1-af-ipv4] quit
[HUAWEI-vpn-instance-vpn1] quit
[HUAWEI] ip vpn-instance vpn2
[HUAWEI-vpn-instance-vpn2] ipv4-family
[HUAWEI-vpn-instance-vpn2-af-ipv4] quit
[HUAWEI-vpn-instance-vpn2] quit
[HUAWEI] ip route-static vpn-instance vpn1 10.1.1.1 32 vpn-instance vpn2
