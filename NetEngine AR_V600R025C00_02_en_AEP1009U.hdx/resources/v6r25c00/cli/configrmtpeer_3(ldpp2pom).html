mpls ldp timer keepalive-hold

Function

The mpls ldp timer keepalive-hold command sets the Keepalive hold timer value.

The undo mpls ldp timer keepalive-hold command restores the default Keepalive hold timer value.

By default, the value of the Keepalive hold timer is 45s.

Format

mpls ldp timer keepalive-hold interval

undo mpls ldp timer keepalive-hold

Parameters

Parameter Description Value
interval

Specifies the Keepalive hold timer value.

The value is an integer ranging from 30 to 65535, in seconds.

Views

Remote MPLS LDP peer view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

LDP peers maintain LDP sessions using LDP PDUs transmitted over session connections. If a node does not receive any LDP PDU before the Keepalive hold timer times out, the node terminates the session by closing the connection.

The default value is recommended. On a network where the link status is unstable, you can increase the Keepalive hold timer value properly. This helps prevent LDP session flapping.

There are two types of Keepalive hold timers:

  • Keepalive hold timer of the local session: used to maintain the local LDP session. You can run the mpls ldp timer keepalive-hold command in the interface view to set a value for the timer.
  • Keepalive hold timer of the remote session: maintains the remote LDP session. The mpls ldp timer keepalive-hold command in the remote MPLS LDP peer view sets a value of the timer.

The timer value that takes effect is the smaller one of the Keepalive hold timer values configured on both ends of an LDP session.

Prerequisites

The remote LDP peer must be configured.

Implementation Procedure

After the mpls ldp timer keepalive-hold command is run, the system displays the following message:

Warning: All the related sessions will be deleted if the operation is performed. Continue? [Y/N]:y

To confirm to run the command, enter y.

Configuration Impact

After the mpls ldp timer keepalive-hold command is run, the Keepalive hold timer value that takes effect is the smaller one of the Keepalive hold timer values configured on both ends of an LDP session.

Precautions

You are advised to set the same Keepalive hold time for all links of a local LDP multi-link session. Otherwise, the LDP session or LSP may fail to be established.

If both local and remote LDP sessions exist, you are advised to set the same Keepalive hold time for all links and remote peers. Otherwise, LDP sessions or LSPs may fail to be established.

If multiple links and remote peers are configured with different Keepalive hold times, they can be bound to the same session. In this case, LDP establishes a session based on the configuration of the first adjacency discovery.

If the configured Keepalive hold time of all adjacencies (one or more) is the same and is different from the effective Keepalive hold time of the session, the session is reestablished and the Keepalive hold time is renegotiated. In other scenarios, changing the Keepalive hold time does not cause session reestablishment or renegotiate the Keepalive hold time.

If the negotiated value of the Keepalive hold timer on both ends of an LDP session is less than 9s, the value 9s takes effect. It is recommended that the negotiated value of the Keepalive hold timer on both ends be greater than or equal to 30s. Otherwise, session flapping may occur during an active/standby switchover.

Example

# Set the Keepalive hold timer value of the remote session to 40s.
<HUAWEI> system-view
[HUAWEI] mpls
[HUAWEI-mpls] mpls ldp
[HUAWEI-mpls-ldp] quit
[HUAWEI] mpls ldp remote-peer bji
[HUAWEI-mpls-ldp-remote-bji] mpls ldp timer keepalive-hold 40
Warning: MPLS LDP Keepalive Hold Timer will be modified, which may cause multi-link or local-remote adjacency configurations to become inconsistent and interrupt LDP sessions or LSPs.
Warning: All the related sessions will be deleted if the operation is performed. Continue? [Y/N]:y
