radius-server nas-port-id-format

Function

The radius-server nas-port-id-format command sets the format of the NAS port ID attribute.

The undo radius-server nas-port-id-format command restores the default format of the NAS port ID attribute.

By default, the new format of the NAS port ID attribute is used.

Format

radius-server nas-port-id-format new client-option82

radius-server nas-port-id-format old

radius-server nas-port-id-format new

radius-server nas-port-id-format vendor vendor-id

undo radius-server nas-port-id-format

Parameters

Parameter Description Value
old

Uses the old format of the NAS port ID.

-
new

Uses the new format of the NAS port ID.

-
vendor vendor-id

Uses the NAS port ID format that is customized by the vendor.

The value is 9.
client-option82

Uses the content of the Option82 field as the format of the NAS-Port-Id attribute.

-

Views

RADIUS server template view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

The NAS port format and the NAS port ID format are developed by Huawei, which are used to ensure connectivity and service cooperation among Huawei devices.

Prerequisites

The authentication trigger-condition dhcp dhcp-option command must be run in the MAC access profile view to send DHCP option information to the authentication server.

Precautions

  • Select the new parameter.

    For Ethernet access users, the NAS port ID format is slot=XX; subslot=XX; port=XXX; vlanid=XXXX; interfaceName=port. The slot value ranges from 0 to 15, the subslot value ranges from 0 to 15, and the port value ranges from 0 to 255. The value of vlanid ranges from 1 to 4094. interfaceName indicates the user access interface, including the interface type and number.

    For ADSL access users, the format of NAS port ID is slot=XX; subslot=X; port=X; vpi=XXX; vci=XXXXX; interfaceName=port, where slot ranges from 0 to 15, subslot ranges from 0 to 9, and port ranges from 0 to 9. The value of vpi ranges from 0 to 255, and the value of vci ranges from 0 to 65535. interfaceName specifies the access interface, including the interface type and number.
  • Select the new client-option82 parameter.

    When a DHCP user goes online, if the packet sent by the user contains the Option 82 field, the device encapsulates the Circuit ID suboption in the Option 82 field into the NAS-Port-Id (87) attribute of a RADIUS packet, and then sends the RADIUS packet to the RADIUS server, binding the user account to the access location. This prevents an account from being shared by multiple users. In this case, the format of the NAS-Port-Id (87) attribute is the same as that of the Circuit ID suboption in the Option 82 field. To configure the Circuit ID suboption format, run the dhcp option82 format command.

    Note:

    If DHCP packets do not contain Option 82, the format of the RADIUS attribute NAS-Port-Id (87) is new.

    If the new client-option82 parameter is selected, the device encapsulates the content of the first 128 bytes in the Circuit ID suboption of the Option 82 field into the NAS-Port-Id (87) attribute of a RADIUS packet. If the first 128 bytes contain 0, the device only encapsulates bytes before the first 0. If the first byte of the Circuit ID value is 0 or no Circuit ID value exists, the format of the NAS-Port-Id (87) attribute is new.
  • Select the old parameter.

    For Ethernet access users, the NAS port ID format is slot number (2 characters) + subslot number (2 bytes) + card number (3 bytes) + VLAN ID (9 characters).

    For ADSL access users, the NAS port ID format is port number (2 characters) + subslot number (2 bytes) + card number (3 bytes) + VPI (8 characters) + VCI (16 characters). The fields are prefixed with 0s if they contain fewer bytes than specified.
  • vendor vendor-id:

    The vendor-defined format is used for encapsulation. The value of vendor-id can only be 9. The format is interface type+interface number, indicating a user access interface. You can run the display access-user user-id user-id command to check the user access interface. The User access Interface field is displayed in the command output.

Example

# Set the format of the NAS port ID attribute to new. 
<HUAWEI> system-view
[HUAWEI] radius-server template template1
[HUAWEI-radius-template1] radius-server nas-port-id-format new
