smart-roam ai-mode disable

Function

The smart-roam ai-mode disable command disables AI roaming.

The undo smart-roam ai-mode disable command enables AI roaming.

By default, AI roaming is enabled.

Format

smart-roam ai-mode disable

undo smart-roam ai-mode disable

Parameters

Parameter Description Value
disable

Disables AI roaming.

-

Views

RRM profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In practice, the roaming process depends on multiple negotiations between APs and STAs. STAs of different vendors and models have different autonomous behaviors during the negotiation process. As a result, roaming experience cannot be effectively guaranteed. To address this issue, you can enable the AI roaming function. Then the system matches the identified terminal type with the corresponding terminal profile to obtain the behavior characteristics of the terminal during roaming and perform optimization during roaming negotiation. This improves the roaming sensitivity and success rate, enhancing the roaming experience of users.

Prerequisites

Smart roaming has been enabled using the undo smart-roam disable command. If the smart-roam disable command has been configured, AI roaming does not take effect even if it is enabled.

Follow-up Procedure

Run the smart-roam roam-threshold snr command to configure the smart roaming threshold. An AP disconnects STAs whose SNR or access rate is lower than the threshold.

Precautions

If the PMF function is enabled, the AI roaming function does not take effect.

Example

# Enable AI roaming.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] rrm-profile name default
[HUAWEI-wlan-rrm-prof-default] undo smart-roam disable
[HUAWEI-wlan-rrm-prof-default] undo smart-roam ai-mode disable
