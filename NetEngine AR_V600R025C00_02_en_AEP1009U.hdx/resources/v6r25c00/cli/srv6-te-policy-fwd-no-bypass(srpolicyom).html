forward no-bypass

Function

The forward no-bypass command disables local protection for packets forwarded over an SRv6 TE Policy.

The undo forward no-bypass command deletes the configuration that disables local protection for packets forwarded over an SRv6 TE Policy.

By default, local protection is disabled for packets forwarded over an SRv6 TE Policy.

Format

forward no-bypass

undo forward no-bypass

Parameters

None

Views

SRv6 TE policy view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If the segment lists of an SRv6 TE Policy's primary candidate path all fail and a local protection path (for example, a TI-LFA or TE FRR path) exists, data traffic is switched to the TI-LFA or TE FRR path for forwarding.

Precautions

The configuration that disables local protection for packets forwarded over an SRv6 TE Policy takes effect for BFD packets forwarded over the SRv6 TE Policy. After this configuration is performed, BFD packets are also not forwarded along the local protection path.

If both the forward no-bypass and bfd { no-bypass | bypass } commands are run in the SRv6 TE Policy view, the forward no-bypass command takes effect.

Example

# Disable local protection for packets forwarded over SRv6 TE Policy policy1.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] srv6-te policy policy1 endpoint 2001:DB8:1::1 color 100
[HUAWEI-segment-routing-ipv6-policy-policy1] forward no-bypass
