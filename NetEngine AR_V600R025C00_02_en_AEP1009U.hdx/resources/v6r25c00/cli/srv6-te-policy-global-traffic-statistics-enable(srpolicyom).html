srv6-te-policy traffic-statistics

Function

The srv6-te-policy traffic-statistics enable command enables traffic statistics collection for all SRv6 TE Policies.

The undo srv6-te-policy traffic-statistics enable command disables traffic statistics collection for all SRv6 TE Policies.

By default, the traffic statistics function of all SRv6 TE policies is disabled globally.

Format

srv6-te-policy traffic-statistics enable

undo srv6-te-policy traffic-statistics enable

Parameters

None

Views

Segment routing IPv6 view

Default Level

2: Configuration level

Usage Guidelines

After the srv6-te-policy traffic-statistics enable command is run in the segment routing IPv6 view, traffic statistics collection is enabled for all SRv6 TE Policies.

The rules for configurations to take effect are as follows:

  1. If the traffic-statistics {enable | disable} command is run in the SRv6 TE Policy view, the command configuration in the SRv6 TE Policy view takes effect.
  2. If the traffic-statistics {enable | disable} command is not run in the SRv6 TE Policy view, global configuration takes effect.

Example

# Enable the global traffic statistics function of the SRv6 TE policy.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] srv6-te-policy traffic-statistics enable
