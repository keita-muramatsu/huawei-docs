pki realm (AP PKI realm profile view)

Function

The pki realm command configures a name for an AP PKI realm and binds the CA certificate, local certificate, and private key files to the realm.

The undo pki realm command deletes the PKI realm configuration in an AP PKI realm profile.

By default, no PKI realm is configured.

Format

pki realm realm-name { { ca format { der | pkcs12 | pem } ca-file-name } | { local format { der | pkcs12 | pem } local-file-name [ private-key format { der | pkcs12 | pem } private-key-file-name password password ] } } *

undo pki realm realm-name

Parameters

Parameter Description Value
realm-name

Specifies the name of a PKI realm.

The value is a string of 1 to 50 case-sensitive characters. It cannot contain spaces.
ca

Specifies a CA certificate.

-
format

Specifies the file format.

-
der

Sets the file format to DER.

-
pkcs12

Sets the file format to PKCS12.

-
pem

Sets the file format to PEM.

-
ca-file-name

Specifies the name of the CA certificate to be imported.

The value is a string of 1 to 50 case-sensitive characters. It cannot contain spaces.
local

Indicates the local certificate.

-
local-file-name

Specifies the name of a local certificate file to be imported.

The value is a string of 1 to 50 case-sensitive characters. It cannot contain spaces.
private-key

Specifies a private key.

-
private-key-file-name

Specifies the name of the private key certificate to be imported.

The value is a string of 1 to 50 case-sensitive characters. It cannot contain spaces.
password password

Specifies the decryption password of a certificate file.

The value is a string of 6 to 32 plaintext characters or 128 to 148 ciphertext characters. It must contain at least two types of the following: lowercase letters (a to z), uppercase letters (A to Z), digits, and special characters.

Views

AP PKI realm profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

You can use this command to configure the name for an AP PKI realm on the WAC and configure the CA certificate, local certificate, and private key files to be bound to the AP PKI realm. You can import the corresponding files as required.

Precautions

A maximum of five PKI realms can be configured in an AP PKI realm profile, and private keys can be configured in a maximum of three PKI realms. To check information about an AP PKI realm profile, run the display ap-pki-profile command.

To ensure network security, it is recommended that the public key length and private key length of a certificate file be greater than or equal to 3072 bits.

To update a certificate file, run the load-file (WLAN view) command to manually load the certificate file in the AP PKI realm to the AP. The latest configuration overrides the previous one.

Example

# In the AP PKI realm profile default, set the PKI realm name to r1, and set the certificate files in the realm as follows: CA certificate file 1.txt in DER format, local certificate file 2.txt in PEM format, and private key file 3.txt in PEM format (private key decryption password: YsHsjx_202206).
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-pki-profile name default
[HUAWEI-wlan-ap-pki-prof-default] pki realm r1 ca format der 1.txt local format pem 2.txt private-key format pem 3.txt password YsHsjx_202206
