display netstream map

Function

The display netstream map command displays the mapping between 32-bit indexes allocated by the NetStream and 16-bit interface indexes.

Format

display netstream map

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Displays the mapping between 32-bit indexes allocated by the NetStream and 16-bit interface indexes.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the mapping between 32-bit indexes allocated by the NetStream and 16-bit interface indexes.
<HUAWEI> system-view
[HUAWEI] diagnose
[HUAWEI-diagnose] display netstream map
