network-slice (interface view)

Function

The network-slice command configures an affinity-based network slice ID for an interface.

The network-slice data-plane command configures a network slice ID for an interface.

The undo network-slice command deletes the network slice ID configured on an interface.

By default, no network slice ID is configured for an interface.

Format

network-slice slice-id

network-slice slice-id data-plane

undo network-slice slice-id data-plane

Parameters

Parameter Description Value
slice-id

Specifies the network slice ID of an interface.

The value is an integer ranging from 0 to 4294967295.
data-plane

Specifies the data-plane mode.

If the data-plane mode is specified, traffic is transmitted through the corresponding slice and shares the available interface bandwidth with other services. Therefore, bandwidth resources cannot be guaranteed.

-

Views

10GE sub-interface view, 10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE sub-interface view, 40GE interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, Ethernet sub-interface view, Ethernet interface view, GE optical interface view, GE sub-interface view, GE interface view, GE electrical interface view, Multi-GE sub-interface view, Multi-GE interface view, Tunnel interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Network slicing can logically divide a physical network into multiple network slices to flexibly and quickly meet diversified network requirements of various vertical industries.

Network slicing interfaces are classified into basic interfaces and slice interfaces. After a network slice ID is configured for an interface, the interface is a slice interface. When traffic is diverted to a basic interface, the local device searches for a slice interface with the same ID on the basic interface based on the network slice ID carried in the packet and forwards the packet through the corresponding slice interface.

Precautions

The rules for configuring a slice ID on an interface are as follows:

  1. Before configuring a network slice ID for an interface, you must configure a global network slice instance. When deleting a network slice, you must also specify the network slice ID.
  2. Before configuring a network slice ID with parameters on an interface, you must enable IPv6. When the interface functions as a base interface, you need to configure a global IPv6 address for the interface first. When the global IPv6 address is deleted from an interface, the network slice configuration is also deleted.
  3. The slice IDs configured using the network-slice data-plane command on the same main interface must be different.

Example

# Set the network slice ID without parameters on 10GE0/0/1 to 10.
<HUAWEI> system-view
[HUAWEI] network-slice instance 10
[HUAWEI-network-slice-instance-10] quit
[HUAWEI] interface 10GE0/0/1
[HUAWEI-10GE0/0/1] ipv6 enable
[HUAWEI-10GE0/0/1] ipv6 address 2001:DB8:1::1 96
[HUAWEI-10GE0/0/1] network-slice 10 data-plane
