nhrp entry

Function

The nhrp entry command adds static NHRP peer entries to the local NHRP mapping table.

The undo nhrp entry command deletes static NHRP peer entries from the local NHRP mapping table.

By default, no static NHRP peer entry is added to the local NHRP mapping table.

Format

nhrp entry protocol-address nbma-address [ register ]

undo nhrp entry protocol-address [ nbma-address [ register ] ]

Parameters

Parameter Description Value
protocol-address

Specifies the tunnel interface address of an NHRP peer device.

The value is in dotted decimal notation.
nbma-address

Specifies the NBMA address of the NHRP peer device.

The value is in dotted decimal notation.
register

Configures a spoke to register with the hub to generate NHRP peer entries on the hub.

-

Views

Tunnel interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When configuring DSVPN, you need to run this command to statically configure the mapping between the tunnel address and public address or between the tunnel address and domain name for the NHRP peer (hub node) on spoke nodes.

When a spoke node registers with the hub node, the hub node also generates the mapping between the tunnel address and public address for the spoke node. In this case, the spoke node and hub node can communicate with each other through the VPN tunnel.

Prerequisites

The following operations have been performed:

  • Run the interface tunnel command to create a tunnel interface and display the tunnel interface view.
  • Run the tunnel-protocol gre p2mp command to set the tunnel encapsulation mode to mGRE.

Configuration Impact

After the command is run on a spoke, the local NHRP peer entry on the spoke remains effective regardless of whether the hub receives the registration request. If the hub cannot receive data sent by the spoke using this entry, a data blackhole occurs.

Precautions

If multiple mGRE tunnels on a DSVPN have the same source, different identification keywords must be configured for the mGRE tunnels.

Example

# Configure an NHRP peer entry that maps the static network address 10.10.10.10 to the public network address 172.16.1.1.
<HUAWEI> system-view
[HUAWEI] nhrp enable
[HUAWEI] interface tunnel 0
[HUAWEI-Tunnel0] tunnel-protocol gre p2mp
[HUAWEI-Tunnel0] nhrp enable
[HUAWEI-Tunnel0] nhrp entry 10.10.10.10 172.16.1.1
