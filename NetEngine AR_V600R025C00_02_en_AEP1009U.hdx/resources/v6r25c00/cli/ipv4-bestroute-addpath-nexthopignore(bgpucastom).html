bestroute add-path nexthop-ignore(BGP-IPv4 unicast address family view)

Function

The bestroute add-path nexthop-ignore command allows routes with the same prefix and next hop to form Add-Path routes.

The undo bestroute add-path nexthop-ignore command cancels the configuration that allows routes with the same prefix and next hop to form Add-Path routes.

By default, routes with the same prefix and next hop do not form Add-Path routes.

Format

bestroute add-path nexthop-ignore

undo bestroute add-path nexthop-ignore

Parameters

None

Views

BGP-IPv4 unicast address family view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

During BGP route selection, BGP checks whether the next hops of routes are the same. Routes with different next hops can be used as Add-Path routes, whereas routes with the same next hop cannot be used as Add-Path routes.

The public network IPv4 unicast address family supports both labeled and non-labeled routes. When Add-Path routes are generated, both BEST and Add-Path routes must all be labeled routes or non-labeled routes. After the bestroute add-path nexthop-ignore command is run, routes with the same next hop can be used as Add-Path routes if either of the following conditions is met:

  • They are all labeled routes with the same next hop but different labels. The routes with the same next hop and same label cannot be used as Add-Path routes.
  • They are all non-labeled routes and carry the same next hop.

Prerequisites

BGP Add-Path has been enabled and the number of routes that a device can select has been configured using the bestroute add-path command.

The device has been enabled to advertise Add-Path routes to a specified peer using the peer capability-advertise add-path send command.

The number of routes to be advertised to a peer has been set using the peer advertise add-path command.

Precautions

Running the bestroute add-path nexthop-ignore command will change the conditions for generating Add-Path routes. Therefore, exercise caution when running this command.

Example

# Allow routes with the same prefix and next hop in the BGP-IPv4 unicast address family view to form Add-Path routes.
<HUAWEI> system-view
[HUAWEI] bgp 100
[HUAWEI-bgp] ipv4-family unicast
[HUAWEI-bgp-af-ipv4] bestroute add-path nexthop-ignore
