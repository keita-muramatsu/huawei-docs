password similar-to-name-check

Function

The password similar-to-name-check enable normal command enables common check on the similarity between the local administrator password and user name.

The password similar-to-name-check enable enhance command enables enhanced check on the similarity between the local administrator password and user name.

The undo password similar-to-name-check disable command enables common check on the similarity between the local administrator password and user name.

The undo password similar-to-name-check enable enhance command disables enhanced check on the similarity between the local administrator password and user name. (Only the enhanced check function is disabled, and the common check function is restored.).

The password similar-to-name-check disable command disables the function of checking the similarity between the local administrator password and user name. (Both the common check function and enhanced check function are disabled.).

By default, common check on the similarity between the local administrator password and user name is enabled.

Format

password similar-to-name-check disable

password similar-to-name-check enable enhance

password similar-to-name-check enable normal

undo password similar-to-name-check { disable | enable enhance }

Parameters

Parameter Description Value
enable

Enables the function of checking the similarity between the password and user name.

-
enhance

Enables enhanced check on the similarity between the password and user name.

-
normal

Enables common check on the similarity between the password and user name.

-
disable

Disables the function of checking the similarity between the password and user name.

-

Views

Local administrator password policy view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

To prevent accounts from being stolen due to simple passwords, the device supports the function of checking the similarity between the local administrator password and user name. The similarity check function is classified into common similarity check and enhanced similarity check.

  • After common similarity check is enabled:
    • The password cannot repeat the user name.
    • The password cannot reverse the user name.
  • After enhanced similarity check is enabled:
    • The password and user name cannot contain each other.
    • The spelled backwards of the password and user name cannot contain each other.

Precautions

After the password similar-to-name-check disable command is run to disable the function of checking the similarity between the local administrator password and user name, a simple password poses security risks. Exercise caution when running this command.

Example

# Enable common check on the similarity between the local administrator password and user name. 
<HUAWEI> system-view
[HUAWEI] aaa
[HUAWEI-aaa] local-aaa-user password policy administrator
[HUAWEI-aaa-lupp-admin] undo password similar-to-name-check disable
# Enable enhanced check on the similarity between the local administrator password and user name. 
<HUAWEI> system-view
[HUAWEI] aaa
[HUAWEI-aaa] local-aaa-user password policy administrator
[HUAWEI-aaa-lupp-admin] password similar-to-name-check enable enhance
