gre checksum

Function

The gre checksum command enables the checksum function on both ends of a GRE tunnel.

The undo gre checksum command disables the checksum function on both ends of a GRE tunnel.

By default, the checksum function is disabled on both ends of a GRE tunnel.

Format

gre checksum

undo gre checksum

Parameters

None

Views

Tunnel interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If the checksum function is enabled on both ends, the local end calculates a checksum based on the GRE header and payload information, and sends a packet containing the checksum to the remote end. After receiving the packet, the remote end also calculates a checksum and compares the result with the checksum carried in the packet. If they are the same, the remote end further processes the packet. Otherwise, it discards the packet.

You can enable the checksum function on both ends of a GRE tunnel as required.

If the checksum function is enabled only on the local end, the local end does not check the checksum for received packets but calculates a checksum for sent packets. If the checksum function is enabled only on the remote end, the local end checks the checksum for received packets but does not calculate a checksum for sent packets.

Prerequisites

A tunnel interface has been created using the interface tunnel command.

The tunnel encapsulation type has been set to GRE using the tunnel-protocol gre command.

Example

# Enable the checksum function on both ends of a GRE tunnel.
<HUAWEI> system-view
[HUAWEI] interface Tunnel 1
[HUAWEI-Tunnel1] tunnel-protocol gre
[HUAWEI-Tunnel1] gre checksum
