ipv6 nd direct-route preference

Function

The ipv6 nd direct-route preference command sets a priority of IPv6 NDP Vlink direct routes.

The undo ipv6 nd direct-route preference command restores the default priority.

By default, no priority is set for IPv6 NDP Vlink direct routes.

Format

ipv6 nd direct-route preference preference-value

undo ipv6 nd direct-route preference [ preference-value ]

Parameters

Parameter Description Value
preference-value

Set the priority of IPv6 NDP Vlink direct routes.

The value is an integer ranging from 0 to 255. A smaller value indicates a higher priority.

Views

10GE sub-interface view, 25GE sub-interface view, 40GE sub-interface view, Eth-Trunk sub-interface view, Ethernet sub-interface view, GE sub-interface view, Multi-GE sub-interface view, VLANIF interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

You can run the ipv6 nd direct-route preference command to change the preference value of IPv6 NDP Vlink direct routes advertised by an interface. If multiple such routes to the same destination exist, the device performs route selection based on their preference values, which can be configured using this command.

Prerequisites

  • If this function is to be enabled on a VLANIF interface, IPv6 has been enabled using the ipv6 enable command.
  • If this function is to be enabled on a 10GE or Eth-Trunk sub-interface, IPv6 has been enabled using the ipv6 enable command. In addition, the sub-interface has been enabled to terminate single-tagged packets using the dot1q termination vid command.

Precautions

You must run the ipv6 nd direct-route enable command in the system view or interface view to advertise IPv6 NDP Vlink direct routes. Otherwise, the route summarization function does not take effect.

Once the undo ipv6 enable command is run in the interface view to disable IPv6, the configuration of the ipv6 nd direct-route preference command is also deleted. Exercise caution when using the undo ipv6 enable command.

Example

# Set the priority of IPv6 NDP Vlink direct routes to 100 on a VLANIF interface.
<HUAWEI> system-view
[HUAWEI] vlan 200
[HUAWEI-Vlan200] quit
[HUAWEI] interface vlanif 200
[HUAWEI-Vlanif200] ipv6 enable
[HUAWEI-Vlanif200] ipv6 nd direct-route enable
[HUAWEI-Vlanif200] ipv6 nd direct-route preference 100
