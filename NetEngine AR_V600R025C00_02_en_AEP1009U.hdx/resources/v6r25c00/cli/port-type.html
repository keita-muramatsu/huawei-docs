port-type

Function

The port-type command sets the port type for an interface.

The undo port-type command deletes the set port type.

By default, no port type is set for an interface.

Format

port-type { uni | nni | ini }

undo port-type

Parameters

Parameter Description Value
uni

Indicates a user-side interface, which is a LAN-side interface.

-
nni

Indicates the transmission-side interface, which is a WAN-side interface.

-
ini

Indicates an interlink interface, which is an interface connecting one SD-WAN EVPN gateway to the other.

-

Views

10GE sub-interface view, 10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE sub-interface view, 40GE interface view, Cellular channel interface view, Dialer interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, Ethernet sub-interface view, Ethernet interface view, GE sub-interface view, GE interface view, Multi-GE sub-interface view, Multi-GE interface view, Tunnel interface view, VLANIF interface view

Default Level

2: Configuration level

Usage Guidelines

In SD-WAN EVPN dual-gateway networking, a device cannot identify the application information of packets whose forward and return paths are different. In this case, you need to run the port-type command to configure WAN-side, LAN-side, and interlink interfaces. If the request packet corresponding to a TCP response packet received from the WAN-side interfaces is not processed by the local device, the local device sends the packet to the peer device through the interlink interface. After processing the bidirectional packets, the peer device can determine the corresponding application information. This command is not required in non-dual-gateway scenarios.

Example

# Set the port type of an interface to uni.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] port-type uni
