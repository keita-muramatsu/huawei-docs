ssid-profile (WLAN view)

Function

The ssid-profile command is used to create an SSID profile and enter the SSID profile view, or enter the view of an existing SSID profile.

The undo ssid-profile command is used to delete an SSID profile.

By default, the system provides the SSID profile default.

Format

ssid-profile name profile-name

undo ssid-profile { name profile-name | all }

Parameters

Parameter Description Value
name profile-name

Specifies the name of an SSID profile.

The value is a string of 1 to 35 case-sensitive visible characters. It cannot contain question marks (?) or spaces, and cannot start or end with double quotation marks (").
all

Deletes all SSID profiles.

-

Views

WLAN view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

An SSID profile is mainly used to configure STA association and access parameters based on SSIDs, including the SSID name, STA association timeout period, non-HT STA access, and QoS CAR.

Follow-up Procedure

After you create an SSID profile, run the ssid-profile (VAP profile view) command in the VAP profile view to apply the SSID profile, and then run the vap-profile command in the AP group view, AP view, AP radio view, or AP group radio view to apply the VAP profile.

Precautions

· The SSID profile default cannot be deleted.

· The SSID profile that has been bound to a VAP profile cannot be deleted. To delete the SSID profile, unbind it from the VAP profile first.

· If a VAP profile has been bound to an AP group or a single AP, modifying the SSID profile will interrupt services.

Example

# Create an SSID profile ssid1 and enter the SSID profile view.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ssid-profile name ssid1
