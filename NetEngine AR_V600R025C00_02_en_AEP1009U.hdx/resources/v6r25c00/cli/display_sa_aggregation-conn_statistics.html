display sa aggregation-conn statistics

Function

The display sa aggregation-conn statistics command displays statistics about connection-based application traffic aggregation on an interface.

Format

display sa aggregation-conn statistics [ { { site site-id | connection connection-id } | application application-name } * ]

Parameters

Parameter Description Value
site site-id

Specify the site ID.

The value is an integer that ranges from 1 to 65535.
connection connection-id

Specify the connection ID.

The value is an integer that ranges from 1 to 4294967295.
application application-name

Specify the application name.

The value is a string of 1 to 32 characters and is case sensitive if it starts with UD_. If the string contains spaces, it must be enclosed in quotation marks.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

To check statistics about EVPN site connection-based application traffic aggregation on an interface, run this command. A maximum of the latest 10 statistics can be displayed, improving maintainability.

Prerequisites

Connection-based application traffic aggregation has been enabled on an interface using the sa aggregation-conn enable command.
