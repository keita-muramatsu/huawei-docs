ospfv3 cost

Function

The ospfv3 cost command sets a cost for an OSPFv3 interface.

The undo ospfv3 cost command restores the default cost.

By default, the cost of an OSPFv3 interface is calculated based on the interface bandwidth.

Format

ospfv3 cost value [ instance instanceId ]

undo ospfv3 cost [ value ] [ instance instanceId ]

Parameters

Parameter Description Value
value

Specifies the cost for running OSPFv3.

The value is an integer ranging from 1 to 65535.
instance instanceId

Specifies an interface instance ID.

The value is an integer ranging from 0 to 255.

Views

10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE interface view, Dialer interface view, Eth-Trunk interface view, Ethernet interface view, GE optical interface view, GE sub-interface view, GE electrical interface view, IP-Trunk interface view, MP-group interface view, POS interface view, VLANIF interface view, 40GE sub-interface view, 10GE sub-interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

OSPFv3 can automatically calculate the link cost for an interface based on the interface bandwidth. You can also set the link cost for the interface using the ospfv3 cost command.

When there are multiple routes with the same discovery protocol, cost, and destination address, these routes meet the conditions for load balancing. You can determine whether to perform load balancing by changing the interface cost based on networking requirements.

OSPFv3 supports co-existence of multiple cost association configurations. The cost of an interface is determined according to the following rules:

  1. In a process, if the stub device is configured to advertise the maximum cost, or neighbor relationship flapping suppression or the peer hold-max-cost function takes effect, the cost value is MAX-COST. (The MAX-COST value can be configured using the maximum-link-cost command. If MAX-COST is not configured, the default value 65535 is used.)
  2. (1) If no interface cost is configured, the cost-base value is the auto-cost calculated based on the bandwidth by default. If an interface cost is configured, the cost-base value is the configured cost value.

    (2) On the preceding basis, if BFD is associated with the cost, the cost is changed to the sum of the cost-base and incr-cost. The sum cannot exceed 65535.

Prerequisites

OSPFv3 has been enabled in the interface view using the ospfv3 area command.

Configuration Impact

The ospfv3 cost command cannot be run on null interfaces.

Precautions

If no cost is set for an OSPFv3 interface using the ospfv3 cost command, OSPFv3 automatically calculates its cost based on the interface bandwidth. The calculation formula is as follows: Cost of the interface = Bandwidth reference value/Interface bandwidth. The integer of the calculated result is the cost of the interface. If the calculated result is smaller than 1, the cost is 1. Changing the bandwidth reference value can change the cost of an interface.

Example

# Set the cost for instance 1 to run OSPFv3 to 33. 
<HUAWEI> system-view
[HUAWEI] ospfv3 1
[HUAWEI-ospfv3-1] quit
[HUAWEI] interface 10GE 0/0/0
[HUAWEI-10GE0/0/0] undo portswitch
[HUAWEI-10GE0/0/0] ipv6 enable
[HUAWEI-10GE0/0/0] ospfv3 1 area 0 instance 1
[HUAWEI-10GE0/0/0] ospfv3 cost 33 instance 1
