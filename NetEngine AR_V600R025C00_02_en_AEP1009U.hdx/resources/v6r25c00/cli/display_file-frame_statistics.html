display file-frame statistics

Function

The display file-frame statistics command displays file frame statistics.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

display file-frame statistics [ engine { av | sandbox | reputation | data-filter | file-block | cloud-sandbox | threat-feed } ] [ protocol { http | ftp | smtp | pop3 | imap | nfs | smb } ] [ slot slot-id cpu cpu-id ] [ verbose ]

Parameters

Parameter Description Value
engine

Specifies the engine type.

-
av

Indicates the antivirus engine.

-
sandbox

Indicates the sandbox.

-
reputation

Indicates file reputation.

-
data-filter

Indicates the data filtering engine.

-
file-block

Indicates the file blocking engine.

-
cloud-sandbox

Indicates the cloud sandbox engine.

-
threat-feed

Indicates the threat feed engine.

-
protocol

Specifies a protocol type.

-
http

Indicates the HTTP protocol.

-
ftp

Indicates the FTP protocol.

-
smtp

Indicates the SMTP protocol.

-
pop3

Indicates the POP3 protocol.

-
imap

Indicates the IMAP protocol.

-
nfs

Indicates the NFS protocol.

-
smb

Indicates the SMB protocol.

-
slot slot-id

Specifies a slot ID.

The value varies depending on device models.
cpu cpu-id

Specifies the CPU ID.

The value varies depending on device models.
verbose

Displays detailed file framework statistics.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

After you run the display file-frame statistics command to view the file frame statistics, you can run the reset file-frame statistics command to reset the statistics and collect statistics again. Cleared statistics cannot be restored. Exercise caution when you run this command.
