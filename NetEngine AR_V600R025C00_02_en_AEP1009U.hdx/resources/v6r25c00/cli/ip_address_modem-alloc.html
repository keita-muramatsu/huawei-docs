ip address modem-alloc

Function

The ip address modem-alloc command enables the automatic dial-up function to obtain an IP address.

The undo ip address modem-alloc command disables the automatic dial-up function.

By default, the automatic dial-up function is disabled on a device.

Format

ip address modem-alloc

undo ip address modem-alloc

Parameters

None

Views

10GE sub-interface view, 25GE sub-interface view, 40GE sub-interface view, Cellular channel interface view, GE sub-interface view, Multi-GE sub-interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When the device needs to obtain an IP address from the core network, you need to run this command to enable the automatic dial-up function.

Precautions

A dial-up can be performed and an IP address can be obtained only when the SIM card is in position.

Example

# Enable the automatic dial-up function on a cellular channel interface. 
<HUAWEI> system-view
[HUAWEI] interface cellular 1/0/0:1
[HUAWEI-Cellular1/0/0:1] ip address modem-alloc
# Enable the automatic dial-up function on a GE channel interface. 
<HUAWEI> system-view
[HUAWEI] interface GE 0/0/0.1
[HUAWEI-GE0/0/0.1] ip address modem-alloc
