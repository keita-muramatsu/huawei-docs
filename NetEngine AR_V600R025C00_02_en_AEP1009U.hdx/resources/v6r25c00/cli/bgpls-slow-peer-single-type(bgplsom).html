slow-peer single-group(BGP-LS address family view)

Function

The slow-peer single-group enable command enables hierarchical slow-peer switching.

The undo slow-peer single-group enable command restores the default hierarchical switchover type of slow peers.

The slow-peer single-group disable command disables hierarchical slow-peer switching.

The undo slow-peer single-group disable command restores the default hierarchical switchover type of slow peers.

The slow-peer single-group auto-process command enables a device to automatically determine whether to enable hierarchical slow-peer switching based on the memory type.

The undo slow-peer single-group auto-process command restores the default hierarchical switchover type of slow peers.

By default, BGP automatically determines whether to enable hierarchical slow-peer switching based on the device memory.

Format

slow-peer single-group { auto-process | enable | disable }

undo slow-peer single-group { auto-process | enable | disable }

Parameters

Parameter Description Value
auto-process

Indicates automatic processing (group switchover allowed or not allowed). The default value is auto-process.

-

Views

BGP-LS address family view

Default Level

2: Configuration level

Usage Guidelines

A slow update peer-group may contain multiple slow peers. If a network problem (congestion for example) occurs and slows down the speed at which the local device advertises routes to a slow peer, the speed at which the local device advertises routes to other peers in the slow update peer-group is also affected. To prevent this problem, you can enable hierarchical slow-peer switching, which allows the slowest peer in a slow update peer-group to be automatically switched to a new slow update peer-group. This new slow update peer-group consists of only this peer.

By default, BGP automatically determines whether to enable hierarchical slow-peer switching based on device memory. When the device memory is less than or equal to 4 GB, hierarchical slow-peer switching is disabled by default. In other cases, hierarchical slow-peer switching is enabled by default. By default, the device automatically checks whether a slower peer exists in the update peer-group, regardless of whether hierarchical slow-peer switching is enabled. If hierarchical slow-peer switching does not take effect and the device detects a slower peer, it records the SLOW_PEER_SINGLEGROUP log.

Example

# Enable hierarchical slow-peer switching.
<HUAWEI> system-view
[HUAWEI] bgp 100
[HUAWEI-bgp] link-state-family unicast
[HUAWEI-bgp-af-ls] slow-peer single-group enable
