capwap dtls cert-mandatory-match disable

Function

The capwap dtls cert-mandatory-match disable command disables the function of establishing CAPWAP DTLS sessions through the initial certificate.

The undo capwap dtls cert-mandatory-match disable command enables the function of establishing CAPWAP DTLS sessions through the initial certificate.

By default, the function of establishing CAPWAP DTLS sessions through the initial certificate is enabled.

Format

capwap dtls cert-mandatory-match disable

undo capwap dtls cert-mandatory-match disable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In deployment scenarios, when a CAPWAP server connects to a large number of CAPWAP clients, you can run the undo capwap dtls cert-mandatory-match disable command to import the default CA certificate to the default realm so that a secure channel can be established through DTLS negotiation and the encrypted DTLS PSK can be delivered to the clients. Afterwards, the CAPWAP clients can use the new PSK for negotiation and access the network.

During AP access deployment, no DTLS PSK is available on the AP side. As a result, DTLS negotiation fails and APs fail to go online. However, the workload of configuring DTLS PSKs locally for such a large number of APs will be huge. As such, you can run the undo capwap dtls cert-mandatory-match disable command to import the default CA certificate to the default realm so that a secure channel can be established through DTLS negotiation and the encrypted DTLS PSK can be delivered to the APs. Afterwards, the APs can use the new PSK for negotiation and access the network. (This function takes effect only for APs running V200R021C00 and later versions.)

Follow-up Procedure

After all CAPWAP clients successfully access a network, run the capwap dtls cert-mandatory-match disable command to disable the function of establishing CAPWAP DTLS sessions through the initial certificate.

Example

# Disable the function of establishing CAPWAP DTLS sessions through the initial certificate.
<HUAWEI> system-view
[HUAWEI] capwap dtls cert-mandatory-match disable
