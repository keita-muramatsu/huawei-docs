type (VAP profile view)

Function

The type command sets the type of a VAP.

The undo type command restores the default VAP type.

The default VAP type is service VAP.

Format

type service-backup ap-offline

type service-backup auth-server-down [ vap-auto-off delay-time ] radius-server template template-name [ reject-new-access ]

type service-backup distribute

undo type

Parameters

Parameter Description Value
service-backup

Sets the VAP type to backup service.

-
auth-server-down

Sets the VAP type to authentication-server-down backup service.

-
vap-auto-off delay-time

Specifies the delay after which the VAP is automatically disabled.

The value is an integer ranging from 10 to 86400, in seconds. The default value is 10.
radius-server

Specifies a RADIUS server.

-
template template-name

Specifies the name of a RADIUS server template.

The value is a string of 1 to 32 case-sensitive characters. It cannot contain spaces.
reject-new-access

Rejects new user access.

-
distribute

Sets the VAP type to distributed-AP backup service.

This parameter takes effect only for the backup AP in the zero-roaming distributed architecture.

-
ap-offline

Sets the VAP type to AP-offline backup service.

-

Views

VAP profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

  • If the type of a VAP is set to service, STAs connected to the VAP can only access network resources but not APs. Service VAPs are applicable to common WLAN deployment scenarios.
  • If the type of a VAP is set to AP-offline backup service, STAs can access the network through the backup service VAP after the AP goes offline. For example, on a headquarters-branch network, when APs at branches connect to the WAC at the headquarters through a WAN, the APs may go offline due to the WAN instability. In this case, you can configure a backup service VAP to allow new STAs to access the network if the APs go offline.
  • If the type of a VAP is set to authentication-server-down backup service, the VAP is automatically enabled to allow network access of STAs when the authentication server is inaccessible. If the authentication server recovers, you can configure the VAP auto-off function to automatically disable the VAP or manually disable it. If the authentication server is accessible but rejects user access, the backup VAP cannot be automatically enabled. You can manually enable it as required. To enable or disable this VAP, run the vap-service-backup auth-server-down command.

    If reject-new-access is specified, new STAs are denied access when the authentication server is down.
  • If the type of a VAP is set to distributed-AP backup service, the backup VAP continuously detects the signal output of the distributed VAP with the same SSID. If no signal from the distributed VAP with the same SSID is detected within 25 Beacon intervals, the backup VAP considers the distributed AP faulty and automatically releases signals to ensure that STAs can access the network. After the distributed VAP recovers, the signal of the backup VAP is shut down, and STAs are switched back to the distributed VAP.

Precautions

  • A VAP profile supports only one VAP type. After the VAP type is configured in the VAP profile view, the VAPs generated by the VAP profile use the configured VAP type. The new VAP type will overwrite the old one.
  • For an AP-offline backup service VAP:
    • Only the WPA3 SAE, WPA2-WPA3 PSK-SAE, open, WPA+PSK, WPA2+PSK and WPA-WPA2+PSK authentication modes are supported.
    • The data service forwarding mode can only be direct forwarding.
    • When the number of configured AP-offline backup service VAPs reaches the maximum number of VAPs on the AP, if the offline management VAP function is enabled, the offline management VAP does not take effect when the AP goes offline.
    • The AP-offline service continuity function and tunnel forwarding for mDNS packets cannot be configured on an AP-offline backup service VAP.
  • For an authentication-server-down backup service VAP:
    • Only the WPA3 SAE, WPA2-WPA3 PSK-SAE, open, WEP, WPA+PSK, WPA2+PSK and WPA-WPA2+PSK authentication modes are supported.
    • This VAP type is exclusive with the AP-offline backup service VAP.
  • For a distributed-AP backup service VAP:
    • Before configuring distributed AP backup, run the distribute-mode enable command to enable DAP network collaboration.
    • When a user switches between the distributed VAP and backup VAP, the process is similar to WLAN roaming, during which a few packets may be lost.

Example

# Create the VAP profile vap1 and set the VAP type to AP-offline backup service.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] vap-profile name vap1
[HUAWEI-wlan-vap-prof-vap1] type service-backup ap-offline
# Create the VAP profile vap1 and set the VAP type to authentication-server-down backup service.
<HUAWEI> system-view
[HUAWEI] radius-server template temp1
[HUAWEI-radius-temp1] wlan
[HUAWEI-wlan] vap-profile name vap1
[HUAWEI-wlan-vap-prof-vap1] type service-backup auth-server-down radius-server template temp1
