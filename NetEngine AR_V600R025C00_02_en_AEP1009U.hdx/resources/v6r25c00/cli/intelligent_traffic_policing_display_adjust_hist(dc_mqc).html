display itp adjustment-history interface

Function

The display itp adjustment-history interface command displays the dynamic rate limiting adjustment history of an intelligent traffic policing policy.

Format

display itp adjustment-history interface { interface-name | interface-type interface-number }

Parameters

Parameter Description Value
itp

Indicates intelligent traffic policing.

-
adjustment-history

Indicates the adjustment history.

-
interface interface-name

Specifies the name of an interface.

The value is a string of 1 to 32 case-sensitive characters. It cannot contain spaces.
interface interface-type interface-number

Specifies the type and number of an interface.

The value is a string of 1 to 63 case-sensitive characters. It cannot contain spaces.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

This command is used to check the adjustment history of an intelligent traffic policing policy. A maximum of 100 records can be saved in each traffic behavior.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the dynamic rate limiting adjustment history of an intelligent traffic policing policy.
<HUAWEI> display itp adjustment-history interface ge 0/0/0
Behavior: internet_b1 
---------------------------------------------------------------------------
Time                     Status         Low cir(Kbps)      Low pir(Kbps) 
---------------------------------------------------------------------------
2024-01-01:08-01-00      ACTIVE                 10000              45000                    
2024-01-01:08-01-15      SUPPRESS               10000              35000                  
Behavior: internet_b2 
---------------------------------------------------------------------------
Time                     Status         Low cir(Kbps)      Low pir(Kbps) 
---------------------------------------------------------------------------
2024-01-01:08-01-00      ACTIVE                 10000              45000                    
2024-01-01:08-01-15      INACTIVE               30000              50000
Table 1 Description of the display itp adjustment-history interface command output
Item Description
Time

Time when an intelligent traffic policing policy is adjusted.
Status

Status of an intelligent traffic policing policy after each adjustment. The status can be INACTIVE, ACTIVE, SUPPRESS, BINARY_DETECT, or ADDITIVE_DETECT.
Low cir (Kbps)

Committed information rate (CIR) of low-priority applications.
Low pir (Kbps)

Peak information rate (PIR) of low-priority applications.
Behavior

Traffic behavior to which an intelligent traffic policing policy belongs.
