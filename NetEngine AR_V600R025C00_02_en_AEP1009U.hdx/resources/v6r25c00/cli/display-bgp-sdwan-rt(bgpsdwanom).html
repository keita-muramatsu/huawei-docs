display bgp sd-wan routing-table peer

Function

The display bgp sd-wan routing-table peer command displays information about routes in the BGP IPv4 SD-WAN address family.

Format

display bgp sd-wan routing-table [ peer remoteIpv4Addr { advertised-routes | received-routes } ] [ sdwan-prefix ]

display bgp sd-wan routing-table peer remoteIpv4Addr { advertised-routes | received-routes } statistics

Parameters

Parameter Description Value
peer

Indicates a BGP peer.

-
remoteIpv4Addr

Specifies an IPv4 peer address.

The value is in dotted decimal notation.
advertised-routes

Displays routes advertised to the remote peer.

-
received-routes

Displays routes received from the remote peer.

-
sdwan-prefix

Displays information about the route with a specified SD-WAN prefix.

The value is a string of case-sensitive characters and cannot contain spaces. Its format is A-B-C-X.X.X.X, where A is the tunnel type, B is the local port ID, C is the SD-WAN site ID, and X.X.X.X is the SD-WAN node ID. For example, 200-1-2-10.2.2.2.
statistics

Statistics of routes.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To check information about desired SD-WAN routes, run the display bgp SD-WAN routing-table peer command with specified parameters.
