poe max-power

Function

The poe max-power command sets the maximum output power of a PoE board.

The undo poe max-power command restores the default maximum output power of a PoE board.

By default, the power is set to the maximum PoE output power of the device. The actual maximum PoE output power is also restricted by the power supply capability.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA.

Format

poe max-power power-value slot slot-id

poe max-power power-value

undo poe max-power [ power-value ] slot slot-id

undo poe max-power

Parameters

Parameter Description Value
power-value

Specifies the maximum output power.

The value is an integer ranging from 0 to 2880000, in mW.
slot slot-id

Specifies a slot ID.

The value must be set according to the device configuration.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

By default, the power of a board in a specified slot is dynamically adjusted according to the remaining device power, so the power allocated to every board varies. To ensure that the board provides PoE power stably when the total device power is insufficient, run the poe max-power command to allocate the fixed power to this board.

Precautions

  • If the configured maximum output power is lower than the total power required by PDs, lower-priority PDs will be powered off or cannot be powered on manually.
  • If the configured maximum output power of a card is higher than that supported by the card, the configuration fails.
  • The maximum output power of a card must be smaller than the remaining PoE power of the device. Otherwise, the PDs connected to other cards will be powered off or the configuration will be invalid.
  • The Power Max Value(mW) field in the display poe information command output shows the maximum PoE output power of the device.
  • The Total PoE Power(mW) field in the display poe-power command output shows the maximum PoE output power provided by the power module.

Example

# Set the maximum output power of a specified slot to 100000 mW.
<HUAWEI> system-view
[HUAWEI] poe max-power 100000 slot 0
