ip-address (User-defined application rule view)

Function

The ip-address command sets the IPv4 address in a user-defined application rule.

The undo ip-address command deletes the IPv4 address in a user-defined application rule.

By default, no IPv4 address is specified for a new user-defined application rule.

Format

ip-address ipv4-address [ ipv4-mask-address | masklength ] [ source | destination ]

undo ip-address { ipv4-address [ ipv4-mask-address | masklength ] [ source | destination ] | all }

Parameters

Parameter Description Value
ipv4-address

Specifies an IPv4 address.

The value is in dotted decimal notation.
ipv4-mask-address

Specifies a subnet mask.

The value is in dotted decimal notation.
masklength

Specifies the length of the prefix.

The value is an integer that ranges from 1 to 32.
source

Specifies the source IPv4 address.

-
destination

Specifies the destination IPv4 address.

-
all

Deletes all the IPv4 addresses.

-

Views

User-defined application rule view

Default Level

2: Configuration level

Usage Guidelines

You can configure a single IPv4 address for a user-defined application rule, or configure a network segment by specifying the subnet mask or mask length.

A user-defined application rule supports a maximum of four IPv4 and IPv6 addresses.

The relationships between source address conditions and between destination address conditions are both OR. However, the relationship between source and destination address conditions is AND. Specifically, if both the source and destination addresses are specified in a rule, a packet matches the rule only when the packet matches both the source and destination addresses.

After an IP address is configured, the application identification module matches network packets based on the configured transport-layer protocol and port, that is, 5-tuple. After the user-defined 5-tuple is configured and committed, the application identification module uses the 5-tuple of the first packet of the session for matching. If the 5-tuple of the traffic to be identified is determined, you can configure a user-defined 5-tuple to accelerate traffic identification.

If source and destination are not specified, the destination IP address is used for rule matching.

A 5-tuple rule must contain at least one IP address or port number.

Example

# Set the IPv4 address in user-defined application rule rule1 to 10.1.1.1. 
<HUAWEI> system-view
[HUAWEI] sa
[HUAWEI-sa] user-defined-application name UD_abc
[HUAWEI-sa-user-defined-app-UD_abc] rule name rule1
[HUAWEI-sa-user-defined-app-UD_abc-rule-rule1] ip-address 10.1.1.1
