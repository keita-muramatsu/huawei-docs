netstream ipv6

Function

The netstream ipv6 command enables IPv6 flow statistics collection on the inbound and outbound interfaces.

The undo netstream ipv6 command restores the default setting.

By default, statistics collection for flows is disabled on the inbound and outbound interfaces.

Format

netstream { inbound | outbound } ipv6

undo netstream { inbound | outbound } ipv6

Parameters

Parameter Description Value
inbound

Enables IPv6 flow statistics collection on the inbound interface.

-
outbound

Enables IPv6 flow statistics collection on the outbound interface.

-

Views

10GE interface view, 25GE interface view, 40GE interface view, Dialer interface view, Eth-Trunk interface view, Ethernet interface view, GE interface view, IP-Trunk interface view, Multi-GE interface view, POS interface view, Tunnel interface view, VLANIF interface view, Serial interface view, Sub-interface view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

To export IPv6 flow statistics, you must run the netstream ipv6 command to enable the IPv6 flow statistics collection function on the interface.

You can run the netstream ipv6 and netstream ip commands on an interface to collect statistics about IPv6 flows and IPv4 flows, respectively. There is no interference between the two commands.

Prerequisites

You have run the netstream sampler command on an interface before running the netstream ipv6 command on the interface.

Precautions

In the tunnel interface view, sampling can be configured only when the encapsulation mode is GRE or SD-WAN.

When PPP is configured on the serial interface, IPv6 sampling does not take effect.

Example

# Enable statistics collection for the incoming IPv6 flows on 10GE 0/0/1. 
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] netstream inbound ipv6
