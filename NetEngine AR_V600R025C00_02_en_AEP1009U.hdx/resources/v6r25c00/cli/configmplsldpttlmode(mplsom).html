mpls ldp ttl-mode

Function

The mpls ldp ttl-mode command configures a mode for MPLS LDP to process TTLs in packets.

The undo mpls ldp ttl-mode command restores the default mode for MPLS LDP to process TTLs in packets.

By default, MPLS LDP processes TTLs in packets in uniform mode.

Format

mpls ldp ttl-mode { pipe | uniform }

undo mpls ldp ttl-mode

Parameters

Parameter Description Value
pipe

Enables MPLS LDP to process TTLs in packets in pipe mode.

-
uniform

Enables MPLS LDP to process TTLs in packets in uniform mode.

-

Views

MPLS view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

MPLS LDP processes TTLs in MPLS packets in the following two modes:

  • Uniform mode

    After an IP packet reaches the ingress of an LSP, the IP TTL value is decremented by one and is mapped to its MPLS TTL field. The MPLS TTL value is decremented by one at each hop along the LSP. After the packet arrives at the egress, the MPLS TTL value is decremented by one and is compared with the IP TTL value. Then, the smaller value is mapped to the IP TTL field.
  • Pipe mode

    On the ingress, the IP TTL value is decremented by one and the MPLS TTL value is a fixed value. Then, the packet is processed in the standard TTL processing mode on the MPLS network. The IP TTL value is decremented by one on the egress. To summarize, the IP TTL value in a packet passing through an MPLS network is decremented by one only on the ingress and egress, regardless of how many hops exist between the ingress and egress.

If virtual circuit connectivity verification (VCCV) tracert is used in an MS-PW scenario, ensure that the TTL processing modes of all nodes on the LSP are the same; otherwise, the tracert operation fails.

Configuration Impact

If a node on an MPLS network processes TTLs in MPLS packets in pipe mode, the tracert and tracert lsp command output does not contain information about this node.

Precautions

The TTL processing mode on the ingress must be the same as that on the egress in an MPLS domain.

If the pipe mode is used, the label advertise non-null command must be run to enable the egress to allocate labels to the LSR at the penultimate hop because PHP is not supported.

Example

# Configure MPLS LDP to process TTLs in MPLS packets in pipe mode.
<HUAWEI> system-view
[HUAWEI] mpls
[HUAWEI-mpls] mpls ldp ttl-mode pipe
