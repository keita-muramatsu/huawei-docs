l2tp-auto-client

Function

The l2tp-auto-client command specifies the number of an L2TP group and enables the L2TP auto-dialup function on a dialer interface.

The undo l2tp-auto-client command disables the L2TP auto-dialup function on a dialer interface.

By default, the L2TP auto-dialup function is disabled on a dialer interface.

Format

l2tp-auto-client l2tp-group group-number

undo l2tp-auto-client l2tp-group [ group-number ]

Parameters

Parameter Description Value
l2tp-group group-number

Specifies the number of an L2TP group.

The value is an integer ranging from 1 to 1024.

Views

Dialer interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The branch functions as an L2TP client on which virtual PPP users are created. The virtual users automatically dial up to initiate L2TP connections to the LNS. No additional devices or configurations are required for branch users to access the headquarters resources through the L2TP client.

Prerequisites

The l2tp enable command has been run to enable L2TP globally.

Example

# Use L2TP group 1 to initiate a connection request.
<HUAWEI> system-view
[HUAWEI] l2tp-group 1
[HUAWEI-l2tp-group-1] quit
[HUAWEI] interface Dialer 1
[HUAWEI-Dialer1] l2tp-auto-client l2tp-group 1
