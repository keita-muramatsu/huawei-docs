dtls client

Function

The dtls client command creates and displays the DTLS client view.

The undo dtls client command deletes the created DTLS client view.

By default, no DTLS client view is created.

Format

dtls client

undo dtls client

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

When the device functions as a DTLS client, you need to run the dtls client command to enter the DTLS client view to perform configurations.

Example

# Configure the device as a DTLS client and enter the DTLS client view to configure connection information.
<HUAWEI> system-view
[HUAWEI] dtls client
[HUAWEI-dtls-client]
