pop3-detect enable

Function

The pop3-detect enable command enables POP3 detection.

The undo pop3-detect enable command disables POP3 detection.

By default, POP3 detection in the download direction is enabled and the action is alert.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

pop3-detect enable

undo pop3-detect enable

Parameters

None

Views

Antivirus profile view

Default Level

2: Configuration level

Usage Guidelines

POP3 detection is enabled by default. If it is disabled, detection on the POP3 protocol is not performed.

If malicious files are detected, the alert action is performed.

Example

# Disable POP3 detection. 
<HUAWEI> system-view
[HUAWEI] profile type av name protocol_detect
[HUAWEI-profile-av-protocol_detect] undo pop3-detect enable
