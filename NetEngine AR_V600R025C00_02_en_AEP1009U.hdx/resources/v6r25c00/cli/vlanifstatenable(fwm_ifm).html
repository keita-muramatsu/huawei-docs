statistics enable (VLANIF interface view)

Function

The statistics enable command enables traffic statistics collection on a VLANIF interface.

The undo statistics enable command disables traffic statistics collection on a VLANIF interface.

By default, traffic statistics collection is disabled on a VLANIF interface.

Format

statistics enable

undo statistics enable

Parameters

None

Views

VLANIF interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To check the network status or locate network faults, you can enable traffic statistics collection on a VLANIF interface to collect traffic statistics on the VLANIF interface.

Precautions

  • After traffic statistics collection is disabled on a VLANIF interface using the undo statistics enable command, the device stops collecting traffic statistics on the VLANIF interface and clears the collected traffic statistics.
  • Traffic statistics collection on a VLANIF interface occupies ACL resources in the system. If traffic statistics collection is enabled on too many VLANIF interfaces, other functions may fail to obtain ACL resources.
  • Traffic statistics collection on a VLANIF interface does not take effect for error packets, but takes effect for unicast, broadcast, and multicast packets.
  • Traffic statistics collection on a VLANIF interface does not take effect for packets sent by the device, such as ping packets.
  • Traffic statistics collection on a VLANIF interface does not take effect for MPLS packets.
  • After traffic statistics collection is enabled on a VLANIF interface, you can run the display interface vlanif command to view traffic statistics on the VLANIF interface.
  • The more VLANIF interfaces on which traffic statistics collection is configured, the higher the CPU usage of the device.

Example

# Enable traffic statistics collection on a VLANIF interface.
<HUAWEI> system-view
[HUAWEI] vlan 100
[HUAWEI] interface vlanif 100
[HUAWEI-Vlanif100] statistics enable
