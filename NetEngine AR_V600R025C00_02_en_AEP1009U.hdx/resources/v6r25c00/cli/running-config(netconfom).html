running-config query-mode

Function

The running-config query-mode command configures whether the NETCONF query result contains the system configuration.

By default, the NETCONF query result contains the system configuration.

Format

running-config query-mode mode-value

Parameters

Parameter Description Value
mode-value

Indicates whether the NETCONF query result carries the system configuration.

Enumerated type. The options are as follows:

  • include-system: The system configuration is included.
  • exclude-system: The system configuration is not included.

Views

NETCONF user interface view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

When NETCONF-based configuration query operations are performed on a device, system configurations that exist upon device startup cause the amount of data to be queried to be large and the efficiency of data query to be low. You can run the running-config query-mode command to specify that the query result does not contain the system configuration, reducing the amount of data to be queried and improving the data validity.

Precautions

  1. This command needs to be run before packets are delivered.
  2. After this command is run, if the user configuration is the same as the system configuration, the user configuration is not displayed in the get-config command output.

Example

# Configure the filtering function for querying device system configurations.
<HUAWEI> system-view
Enter system view, return user view with return command.
Warning: The slave board is not in position. Exercise caution when performing this operation.
[HUAWEI] netconf
[HUAWEI-netconf] running-config query-mode exclude-system
