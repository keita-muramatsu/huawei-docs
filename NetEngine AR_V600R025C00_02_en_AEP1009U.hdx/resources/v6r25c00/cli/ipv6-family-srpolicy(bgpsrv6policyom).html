ipv6-family sr-policy

Function

The ipv6-family sr-policy command enables the BGP IPv6 SR-Policy address family and displays the address family view.

The undo ipv6-family sr-policy command deletes all the configurations in the BGP IPv6 SR-Policy address family view.

By default, the BGP IPv6 SR-Policy address family is not enabled.

Format

ipv6-family sr-policy

undo ipv6-family sr-policy

Parameters

None

Views

BGP view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

SRv6 TE Policy is a tunneling technology developed based on SRv6. SRv6 TE Policy routes dynamically generated on the controller need to be advertised to forwarders through BGP extensions. This function is implemented using a newly defined SAFI (BGP IPv6 SR-Policy address family). After a BGP IPv6 SR-Policy address family peer relationship is established between the controller and forwarders, the controller can deliver SRv6 TE Policy routes to the forwarders.

After the forwarders select the optimal SRv6 TE Policy route, they do not advertise the route to EBGP peers by default. You can run the advertise ebgp enable command to configure the forwarders to advertise the SRv6 TE Policy route to EBGP peers. After an SRv6 TE Policy is created using an SRv6 TE Policy route, different types of routes, such as EVPN, L2VPN, VPNv4, VPNv6, and BGP public network routes, can be recursed to the SRv6 TE Policy through a tunnel policy.

Before performing configurations in the BGP IPv6 SR Policy address family, run the ipv6-family sr-policy command in the BGP view to enable the BGP IPv6 SR Policy address family and enter the address family view.

Configuration Impact

Deleting the address family where a BGP peer exists will tear down the BGP connection with the peer in another address family and trigger automatic renegotiation.

Example

# Enable the BGP IPv6 SR-Policy address family and display the address family view.
<HUAWEI> system-view
[HUAWEI] bgp 100
[HUAWEI-bgp] ipv6-family sr-policy
