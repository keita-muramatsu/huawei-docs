pki realm crl-filename

Function

The pki realm crl-filename command configures a name for an AP PKI realm and specifies the CRL file to be bound to the realm.

The undo pki realm crl-filename command deletes the CRL file configuration in an AP PKI realm profile.

By default, no PKI realm is configured.

Format

pki realm realm-name crl-filename crl-filename

undo pki realm realm-name crl-filename

Parameters

Parameter Description Value
realm-name

Specifies the name of a PKI realm.

The value is a string of 1 to 50 case-sensitive characters. It cannot contain spaces.
crl-filename crl-filename

Specifies the name of a CRL file to be imported.

The value is a string of 1 to 50 case-sensitive characters. It cannot contain spaces.

Views

AP PKI realm profile view

Default Level

2: Configuration level

Usage Guidelines

You can use this command to configure a CRL file to be imported to an AP PKI realm on the WAC. You can import the corresponding file as required.

Example

# Specify a CRL file to be bound to a PKI realm.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-pki-profile name default
[HUAWEI-wlan-ap-pki-prof-default] pki realm r1 crl-filename 1.txt
