display mpls label dynamic available

Function

The display mpls label dynamic available command displays information about labels available for transmitting dynamic services.

Format

display mpls label dynamic available [ [ label-from label ] label-number labelnum ]

Parameters

Parameter Description Value
label-from label

Specifies the start label value.

The value is an integer ranging from 16 to 1048575.
label-number labelnum

Specifies the number of the needed labels.

The value is an integer ranging from 0 to 1048560.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

You can run the display mpls label dynamic available command to view information about labels available for transmitting dynamic services.

Follow-up Procedure

Labels displayed in the command output can be allocated for dynamic services.

Precautions

When you run this command to query available labels, if label-number is set to 0, all available labels are queried.

If the value of label-from is not within the actual range of the label resource pool, the query starts from the minimum value in the actual range.

This command cyclically queries labels. If the largest label is queried before the number specified by label-number is reached, the system continues to query labels from the minimum number until all labels in the label resource pool are queried.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display information about labels available for transmitting dynamic services.
<HUAWEI> display mpls label dynamic available
Begin       End
32784       47999          
48120       331775         
524288      1048575

Item Description

The start label value.

The end label value.
