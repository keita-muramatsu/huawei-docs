ipv6 icmp disable (Interface view)

Function

The ipv6 icmp send disable command disables an interface from sending ICMPv6 messages.

The ipv6 icmp receive disable command disables an interface from receiving ICMPv6 messages.

The undo ipv6 icmp send disable command enables an interface to send ICMPv6 messages.

The undo ipv6 icmp receive disable command enables an interface to receive ICMPv6 messages.

The clear ipv6 icmp send disable command clears the configurations of the ipv6 icmp send disable and undo ipv6 icmp send disable commands.

The clear ipv6 icmp receive disable command clears the configurations of the ipv6 icmp receive disable and undo ipv6 icmp receive disable commands.

By default, an interface is enabled to send ICMPv6 messages.

Format

ipv6 icmp hop-limit-exceeded send disable

ipv6 icmp host-unreachable send disable

ipv6 icmp port-unreachable send disable

clear ipv6 icmp port-unreachable send disable

clear ipv6 icmp host-unreachable send disable

clear ipv6 icmp hop-limit-exceeded send disable

ipv6 icmp probe-echo-request { send | receive } disable

ipv6 icmp probe-echo-reply { send | receive } disable

clear ipv6 icmp probe-echo-request { send | receive } disable

clear ipv6 icmp probe-echo-reply { send | receive } disable

undo ipv6 icmp hop-limit-exceeded send disable

undo ipv6 icmp host-unreachable send disable

undo ipv6 icmp port-unreachable send disable

undo ipv6 icmp probe-echo-request { send | receive } disable

undo ipv6 icmp probe-echo-reply { send | receive } disable

Parameters

Parameter Description Value
host-unreachable

Indicates Destination Unreachable messages (type 1; code 3: address unreachable).

-
port-unreachable

Indicates Destination Unreachable messages (type 1; code 4: port unreachable).

-
hop-limit-exceeded

Indicates Time Exceeded messages (type 3; code 0: hop limit exceeded in transit).

-
probe-echo-request

Indicates Extended Echo Request messages (type 160; code 0).

-
receive

Enables a device to receive ICMPv6 messages.

-
probe-echo-reply

Indicates Extended Echo Reply messages (type 161; code 0: No Error; code 1: Malformed Query; code 2: No Such Interface; code 3: No Such Table Entry; code 4: Multiple Interfaces Satisfy Query).

-

Views

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In normal cases, routing devices can properly send or receive ICMPv6 messages. However, if network traffic is heavy and host unreachable or port unreachable events frequently occur, a device sends a large number of ICMPv6 messages. This burdens the network and deteriorates device performance. In addition, attackers usually use ICMPv6 error messages to probe the internal network topology. To improve network performance and security, run the ipv6 icmp send disable command to disable an interface from sending ICMPv6 messages and run the ipv6 icmp receive disable command to disable an interface from receiving ICMPv6 messages.

If you want to restore the default configuration and require the display this command output not to contain the ipv6 icmp send disable or undo ipv6 icmp send disable command configuration, run the clear ipv6 icmp send disable command.

Configuration Impact

After an interface is disabled from sending ICMPv6 messages, the interface counts only the number of discarded messages instead of the number of sent messages.

Precautions

When the network is normal, you can run the undo ipv6 icmp send disable command to enable the interface to process ICMPv6 messages.

The ipv6 icmp disable command takes effect for all interfaces if it is configured in the system view, and takes effect for a specified interface if it is configured in the view of the interface. If the command is configured in both the interface and system views, the configuration in the interface view takes effect.

Example

# Disable an interface from sending ICMPv6 Hop Limit Exceeded messages.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] undo portswitch
[HUAWEI-10GE0/0/1] ipv6 enable
[HUAWEI-10GE0/0/1] ipv6 icmp hop-limit-exceeded send disable
# Clear the configuration of sending ICMPv6 Hop Limit Exceeded messages on an interface.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] undo portswitch
[HUAWEI-10GE0/0/1] ipv6 enable
[HUAWEI-10GE0/0/1] clear ipv6 icmp hop-limit-exceeded send disable
# Enable an interface to send ICMPv6 Port Unreachable messages.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] undo portswitch
[HUAWEI-10GE0/0/1] ipv6 enable
[HUAWEI-10GE0/0/1] undo ipv6 icmp port-unreachable send disable
# Disable an interface from sending ICMPv6 Host Unreachable messages.
<HUAWEI> system-view
[HUAWEI] interface 10GE0/0/1
[HUAWEI-10GE0/0/1] undo portswitch
[HUAWEI-10GE0/0/1] ipv6 enable
[HUAWEI-10GE0/0/1] ipv6 icmp host-unreachable send disable
