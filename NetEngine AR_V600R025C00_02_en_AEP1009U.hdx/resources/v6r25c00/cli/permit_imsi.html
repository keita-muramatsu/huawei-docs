permit imsi

Function

The permit imsi command configures the IMSI of the SIM card that can be used for dial-up.

The undo permit imsi command cancels the configuration.

By default, a SIM card with any IMSI can be used for dial-up.

Format

permit imsi imsi

undo permit imsi imsi

Parameters

Parameter Description Value
imsi

International mobile subscriber identity (IMSI).

An IMSI consists of 14 to 15 digits.

Views

Cellular template view

Default Level

2: Configuration level

Usage Guidelines

To prevent unauthorized SIM cards from being used for dial-up, you can run the permit imsi command in the cellular profile. If the IMSI of the current SIM card is the same as the configured IMSI, the SIM card can be used for dial-up. Otherwise, the SIM card cannot be used for dial-up. If the permit imsi command is not configured, all SIM cards can be used for dial-up by default.

Example

# Configure the module to use the SIM card whose IMSI is 123456789012345.
<HUAWEI> system-view
[HUAWEI] cellular-profile test
[HUAWEI-cellular-profile-test] permit imsi 123456789012345
Warning: If the IMSI verification fails, the connection cannot be set up. Continue? [Y/N]:y
