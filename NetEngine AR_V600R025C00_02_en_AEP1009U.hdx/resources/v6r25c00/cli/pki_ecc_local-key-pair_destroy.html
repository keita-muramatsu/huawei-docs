pki ecc local-key-pair destroy

Function

The pki ecc local-key-pair destroy command deletes a specified ECC key pair.

Format

pki ecc local-key-pair destroy key-name

Parameters

Parameter Description Value
key-name

Specifies the name of the ECC key pair to be deleted.

The value must be the name of an existing key pair.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If an ECC key pair is leaked, damaged, unused, or lost, you are advised to run this command to delete the specified ECC key pair.

Prerequisites

An ECC key pair has been created using the pki ecc curve-name local-key-pair create command, or the ECC key pair has been imported to the device memory using the pki import ecc-key-pair command.

Precautions

  • The ECC key pair that is being created cannot be deleted.
  • The ECC key pair referenced by a PKI realm cannot be deleted. It can be deleted only after the reference relationship is canceled.

Example

# Delete ECC key pair abc. 
<HUAWEI> system-view
[HUAWEI] pki ecc curve-name prime256v1 local-key-pair create abc
Generating key-pairs...
Info: The name of the new key-pair will be: abc
Info: It will take a few seconds or more. Please wait a moment.
Generating key-pairs finished

[HUAWEI] pki ecc local-key-pair destroy abc
Warning: The name of the key pair to be deleted is abc.
Are you sure you want to delete the key pair? [Y/N]:Y
Info: It will take a few seconds or more to destroy key pairs. Please wait a moment.
Info: Delete ECC key pair success.
