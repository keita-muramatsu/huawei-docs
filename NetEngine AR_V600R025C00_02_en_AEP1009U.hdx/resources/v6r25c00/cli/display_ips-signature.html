display ips-signature

Function

The display ips-signature command displays information about an IPS signature.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

display ips-signature signature-id

display ips-signature [ { pre-defined | user-defined } [ associated ] ] [ os { windows | unix-like | android | ios | other | all } | severity { low | medium | high | information } * | state { disabled | enabled } | target { server | client | both } | category { category-name | all } | protocol { protocol-name | all } ] *

Parameters

Parameter Description Value
ips-signature signature-id

Specifies the ID of an IPS signature.

The value is an integer ranging from 1 to 16777215.

The IPS signature must already exist.
pre-defined

Displays information about a predefined signature.

-
associated

Displays information about an associated signature.

-
os

Displays signatures by operating system.
  • all: displays all signatures.
  • android indicates that signatures of the Android operating system are displayed.
  • ios: displays signatures for the iOS operating system.
  • unix indicates that signatures of the Unix operating system are displayed.
  • windows indicates that signatures with the Windows operating system are displayed.
  • other indicates that signatures of other operating systems are displayed.
windows

Displays signatures of the Windows operating system.

-
unix-like

Displays signatures of the UNIX operating system.

-
ios

Displays signatures of the iOS operating system.

-
other

Displays signatures of other operating systems.

-
severity

Displays signatures by severity.
  • information indicates that signatures with the threat level of Warning are displayed.
  • low indicates that signatures with a low threat level are displayed.
  • medium indicates that signatures with a medium threat level are displayed.
  • high indicates that signatures with a high threat level are displayed.
low

Displays signatures with low severity.

-
medium

Displays signatures with medium severity.

-
high

Displays signatures with high severity.

-
information

Displays signatures with informational severity.

-
state

Indicates the state of a predefined signature.
  • disabled
  • enabled
disabled

Displays the disabled predefined signatures.

-
enabled

Displays the enabled predefined signatures.

-
target

Displays signatures by target.
  • server indicates that signatures whose detection targets are servers are displayed.
  • client indicates that signatures whose detection targets are clients are displayed.
  • both indicates that signatures whose detection targets are servers and clients are displayed.
server

Displays signatures whose detection targets are servers.

-
client

Displays signatures of the detection targets (clients).

-
both

Displays signatures of the detection targets (servers and clients).

-
category category-name

Displays information about signatures in category category-name.

The value is a string of 1 to 21 case-sensitive characters, spaces not supported.
protocol protocol-name

Displays information about signatures of the protocol protocol-name.

The value is a string of 1 to 32 case-sensitive characters. It cannot contain spaces.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

If the IPS signature file is not loaded, predefined signatures are not displayed, the protocol cannot be specified, and the category must be set to all.
