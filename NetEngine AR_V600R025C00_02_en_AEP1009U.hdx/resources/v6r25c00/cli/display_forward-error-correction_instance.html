display forward-error-correction instance

Function

The display forward-error-correction instance command displays information about the FEC encoding and decoding instance table.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

display forward-error-correction instance encode brief tunnel-type sd-wan [ connection-id connection-id-value | vpn-instance vpn-instance-name | { profile profile-name | profile-id profile-id-value } ] *

display forward-error-correction instance encode details tunnel-type sd-wan connection-id connection-id-value [ vpn-instance vpn-instance-name ] { profile profile-name | profile-id profile-id-value }

display forward-error-correction instance encode brief tunnel-type gre [ interface tunnel tunnel-id | { profile profile-name | profile-id profile-id-value } ] *

display forward-error-correction instance encode details tunnel-type gre interface tunnel tunnel-id { profile profile-name | profile-id profile-id-value }

display forward-error-correction instance decode brief tunnel-type sd-wan [ connection-id connection-id-value | vpn-instance vpn-instance-name | profile-id profile-id-value ] *

display forward-error-correction instance decode details tunnel-type sd-wan connection-id connection-id-value [ vpn-instance vpn-instance-name ] profile-id profile-id-value

display forward-error-correction instance decode brief tunnel-type gre [ interface tunnel tunnel-id | profile-id profile-id-value ] *

display forward-error-correction instance decode details tunnel-type gre interface tunnel tunnel-id profile-id profile-id-value

Parameters

Parameter Description Value
connection-id connection-id-value

Specifies a connection ID.

The value is an integer in the range from 1 to 4294967295.
vpn-instance vpn-instance-name

Specifies the name of a VPN instance.

The value is a string of 1 to 31 case-sensitive characters without spaces. The VPN instance name cannot be _public_. The character string can contain spaces if it is enclosed with double quotation marks (").
profile profile-name

Specifies the name of an FEC parameter profile.

The value is a string of 1 to 31 case-sensitive characters. If spaces are used, the string must be enclosed in double quotation marks (" ").
profile-id profile-id-value

Specifies the ID of an FEC parameter profile.

The value is an integer that ranges from 0 to 31.
encode

Specifies an encoding entity.

-
details

Specifies details.

-
tunnel-type

Indicates the tunnel type.

-
sd-wan

Specifies an SD-WAN tunnel.

-
brief

Displays brief information.

-
gre

Specifies a GRE tunnel.

-
interface

Indicates an interface.

-
tunnel tunnel-id

Specifies the number of a tunnel interface.

The value is an integer ranging from 0 to 4095.
decode

Specifies a decoding entity.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run this command to view information about the FEC encoding and decoding instance table. If no parameter is specified, all information is displayed.
