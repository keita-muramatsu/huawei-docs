nat no-pat global alarm ip-pool threshold

Function

The nat no-pat global alarm ip-pool threshold command sets the alarm threshold of public IP address usage of the NO-PAT NAT address pool.

The undo nat no-pat global alarm ip-pool threshold command restores the default settings.

By default, the value is 80, in percentage.

Format

nat no-pat global alarm ip-pool threshold threshold-value

undo nat no-pat global alarm ip-pool threshold

Parameters

Parameter Description Value
threshold-value

Specifies the alarm threshold of the public IP address usage.

The value is an integer ranging from 60 to 100, in percentage. The default value is 80.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

In the NO-PAT NAT scenario, if you need to monitor the usage of public IP addresses in the address pool, run the nat no-pat global alarm ip-pool threshold trap enable command to enable alarm sending upon the public IP address usage of the address pool. When the public IP address usage of the address pool exceeds the threshold specified in the nat no-pat global alarm ip-pool threshold command, the device sends the hwSecTrapNopatAddrOverThreshold alarm to the NMS. After the public IP address usage of the address pool falls below the threshold, the device sends the hwSecTrapNopatAddrBelowThreshold alarm to the NMS.

Example

# Set the threshold of public IP address usage of the address pool to 85%.
<HUAWEI> system-view
[HUAWEI] nat no-pat global alarm ip-pool threshold trap enable
[HUAWEI] nat no-pat global alarm ip-pool threshold 85
