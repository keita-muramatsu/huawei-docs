egress-interface (NAT policy rule view)

Function

The egress-interface command specifies an outbound interface in a NAT policy rule.

The undo egress-interface command deletes an outbound d interface specified in a NAT policy rule.

By default, the outbound interface in a NAT policy rule is set to any, and multiple outbound interfaces can be configured.

Format

egress-interface { interface-type interface-number | interface-name }

undo egress-interface { interface-type interface-number | interface-name | all }

Parameters

Parameter Description Value
interface-type

Specifies the interface type.

The interface can be an Ethernet interface or its sub-interface, a cellular interface, or a cellular channel interface.
interface-number

Specifies the interface number.

-
interface-name

Specifies the interface name.

The value is a string of case-sensitive characters. It cannot contain spaces.
all

Specifies all interfaces.

-

Views

NAT policy rule view

Default Level

2: Configuration level

Usage Guidelines

Either a destination security zone or an outbound interface can be specified in a NAT policy rule. If both a destination security zone and an outbound interface are configured for a NAT policy rule, the latest configuration overrides the previous one.

Example

# Configure 10GE 0/0/2 as an outbound interface in a NAT policy rule named abc. 
<HUAWEI> system-view
[HUAWEI] nat-policy
[HUAWEI-policy-nat] rule name abc
[HUAWEI-policy-nat-rule-abc] egress-interface 10GE 0/0/2
