trust exp

Function

The trust exp command specifies the EXP priority to be mapped for packets.

By default, the device does not trust any packet priority.

Format

trust exp

Parameters

None

Views

10GE interface view, 25GE interface view, 40GE interface view, Cellular channel interface view, Eth-Trunk interface view, GE interface view, IP-Trunk interface view, MP-group interface view, Multi-GE interface view, POS interface view, Virtual serial interface view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

A DiffServ domain defines the mappings from EXP priorities to PHBs and colors. When the DiffServ domain is bound to an interface, you can run this command to specify the priority to be mapped for packets.

Precautions

  • This command and the trust { 8021p { inner | outer } | dscp } command can overwrite each other. If you run the trust exp or trust { 8021p { inner | outer } | dscp } command multiple times in the same interface view, only the latest configuration takes effect.
  • After an Ethernet interface is switched to Layer 2 mode using the portswitch command, the trust exp command cannot be configured.

Example

# Configure 10GE0/0/1 to trust EXP priorities.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] trust exp
