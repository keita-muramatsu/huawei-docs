display radio

Function

The display radio command displays AP radio information.

Format

display radio { all | ap-group ap-group-name | ap-id ap-id }

Parameters

Parameter Description Value
all

Displays radio information about all APs.

-
ap-group ap-group-name

Displays radio information about all APs in a specified AP group.

The value is a string of 1 to 35 visible characters that can be Chinese characters or a combination of Chinese and English characters. It cannot contain question marks (?) or only contain double quotation marks ("). If the AP group name contains spaces,it must be enclosed with double quotation marks (" "), for example, "huawei name1". The double quotation mark (") before and after the AP group name occupies two characters together. The specified AP group must exist.

Only the command editor in UTF-8 encoding format can be used to edit Chinese characters.
ap-id ap-id

Displays radio information about the AP with a specified ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run this command to view the current working status of AP radios.

Example

The actual command output varies according to the device. The command output here is only an example.

Table 1 Description of the display radio command output
Item Description
AP ID

AP ID.
Name

AP name.
RfID

Radio ID of an AP.
Band

Working frequency band of an AP radio.
Type

Protocol type of an AP radio.

  • b: 802.11b radio type.
  • bg: 802.11b/g radio type.
  • bgn: 802.11b/g/n radio type.
  • a: 802.11a radio type.
  • an: 802.11a/n radio type.
  • an11ac: 802.11a/n/ac radio type.
  • 11ax: 802.11b/g/n/ax radio type for a 2.4 GHz radio; 802.11a/n/ac/ax radio type for a 5 GHz radio; or 802.11ax radio type for a 6 GHz radio.
  • 11be: 802.11b/g/n/ax/be radio type for a 2.4 GHz radio; 802.11a/n/ac/ax/be radio type for a 5 GHz radio; or 802.11ax/be radio type for a 6 GHz radio.
ST

Working status of an AP radio.

  • CMD: The radio is disabled in command mode.
  • ERR: The radio is disabled due to an error.
  • CAL: The radio is disabled by radio calibration.
  • LPC: The radio is disabled due to low power consumption.
  • 3GPP: The radio is disabled dut to 3GPP restrictions.
CH/BW

Channel/Bandwidth of an AP radio.
CE/ME

Current power of an AP radio/Maximum power of an AP radio.

The value is calculated based on the typical gain of the antenna used by the AP.
STA

Number of STAs connected to an AP radio.
CU

Channel utilization.

When the working mode of an AP radio is the monitor mode, this parameter is displayed as -.

  • In the AC+central AP+RU networking:

RUs do not proactively report the channel utilization to the AC. To query the channel utilization of RUs, enable the RU data buffer function on the AC.

The ap data-collection enable command enables the AP data buffer function on the AC. After this command is executed, a large data buffer occupies the device memory and affects device performance. It is recommended that the undo ap data-collection enable command be executed to disable data buffer after the query.

  • In the AC+Fit AP networking:

A Fit AP periodically reports the channel utilization to the AC. Therefore, the AC does not need to query the channel utilization of APs.
CCI/TX/RX/NF

Co-channel interference ratio (%)/Transmit time ratio (%)/Receive time ratio (%)/Noise floor (dBm).
WM

Working mode of an AP radio.

  • normal: normal mode.
  • monitor: monitoring mode.
Total

Total count.
CE

Current power of a radio.
ME

Maximum power of an AP radio.
