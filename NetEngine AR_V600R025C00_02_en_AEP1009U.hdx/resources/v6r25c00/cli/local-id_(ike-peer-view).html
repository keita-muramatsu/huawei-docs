local-id (IKE peer view)

Function

The local-id command specifies the local ID for IKE negotiation.

The undo local-id command deletes the local ID for IKE negotiation.

By default, the local ID is not configured for IKE negotiation.

Format

local-id id

undo local-id

Parameters

Parameter Description Value
local-id id

Specifies the local ID used in IKE negotiation.

The value is a string of 1 to 255 case-sensitive characters. It cannot contain question marks.

Views

IKE peer view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When the local ID type of the IKE peer is set to FQDN or USER-FQDN, you can configure the local ID in the system view or IKE peer view.

When pre-shared key negotiation is used and the local ID type is set to IP, the device uses the IP address of the interface used to establish an IPsec tunnel as the local ID by default. If the interface used to establish an IPsec tunnel has multiple IP addresses (for example, primary and secondary IP addresses), the device uses the IP address configured using the tunnel local command as the local ID.

If the ID type is FQDN or USER-FQDN and the ID is configured using the ike local-name command, all IKE peers on the device use this ID for identity authentication. The ID configured using the local-id command takes precedence over the ID configured using the ike local-name command.

Precautions

When the ID type of an IKE peer is FQDN or USER-FQDN, the device can automatically obtain the host name HUAWEI as the ID for identity authentication. Alternatively, you can run the ike local-name or local-id command to specify the local ID used for IKE negotiation.

Example

# Set the local ID to be huawei in IKE negotiation. 
<HUAWEI> system-view
[HUAWEI] ike peer peer1
[HUAWEI-ike-peer-peer1] local-id huawei
