mmi-mode enable

Function

The mmi-mode enable command enters the machine-to-machine mode.

The mmi-mode enable matched upper-view command enters the machine-to-machine mode and enables intelligent rollback in this mode.

The undo mmi-mode enable command enters the man-to-machine mode.

By default, the current VTY user is in human-to-machine mode.

Format

mmi-mode enable [ matched upper-view ]

undo mmi-mode enable

Parameters

Parameter Description Value
matched

Command match.

-
upper-view

Intelligent rollback.

-

Views

User view

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

After you run the mmi-mode enable command to enter the machine-to-machine mode, the output information is not displayed on multiple screens.

After you run the mmi-mode enable command to enter the machine-to-machine mode, some important commands that you need to use with caution can be run directly. As a result, this command cannot be found in command lines or be obtained through any help mode. In the human-to-machine mode, users should use this command with caution.

Run the display vty mode command to query the current mode.

Precautions

After the mmi-mode enable command is run, intelligent rollback is not supported.

After the undo mmi-mode enable or mmi-mode enable matched upper-view command is run, whether the system supports intelligent rollback is determined by the terminal command forward matched upper-view command.

Example

# Enter the machine-to-machine mode.
<HUAWEI> mmi-mode enable
# Enter the machine-to-machine mode and enable intelligent rollback in this mode.
<HUAWEI> mmi-mode enable matched upper-view
