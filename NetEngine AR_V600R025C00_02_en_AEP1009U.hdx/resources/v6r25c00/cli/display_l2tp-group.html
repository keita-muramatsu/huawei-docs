display l2tp-group

Function

The display l2tp-group command displays L2TP groups and their configurations on the device.

Format

display l2tp-group { all | [ group-number ] }

Parameters

Parameter Description Value
all

Displays the configurations of all L2TP groups.

-
l2tp-group group-number

Displays the configuration of the specified L2TP group.

The value is an integer ranging from 1 to 1024.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run the display l2tp-group command to view the L2TP groups on the device and their detailed configurations.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the configurations of all L2TP groups.
<HUAWEI> display l2tp-group all
------------------------------------------------------------------------
Group Number      : 1
Tunnel Auth       : Yes
Local Name        : L2tpTunnel1
Hello Interval    : 60
LNS IP            : 1.1.1.1
LNS Host Name     : --
VPN Instance      : --
Interface Name    : Dialer1, Dialer2
------------------------------------------------------------------------
Group Number      : 2
Tunnel Auth       : No
Local Name        : L2tpTunnel2
Hello Interval    : 60
LNS IP            : 1.1.1.2 1.1.1.3
LNS Host Name     : huaweilns.com
VPN Instance      : vpn1
Interface Name    : Dialer3, Dialer4
------------------------------------------------------------------------                              
Number of L2TP groups: 2

Number of L2TP groups.
