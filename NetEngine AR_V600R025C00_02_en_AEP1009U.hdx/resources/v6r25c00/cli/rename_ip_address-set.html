rename ip address-set

Function

The rename ip address-set command renames an address object or address group.

Format

rename ip address-set address-set-name address-set address-set-new-name

Parameters

Parameter Description Value
address-set address-set-name

Specifies the original name of an address set.

The value must be the name of an existing address object or address group. The name is a string of 1 to 63 case-sensitive characters. If the name contains spaces, it must be enclosed with double quotation marks (""), for example, "user for test." The name cannot contain question marks (?). If the name does not contain spaces, it cannot contain double quotation marks (""). The name cannot be any or all.
address-set address-set-new-name

Specifies the new name of the address set.

The value is a string of 1 to 63 case-sensitive characters. It cannot contain spaces.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Ensure that the address set that is to be renamed exists. The new name becomes valid immediately after you run the rename ip address-set command.

Example

# Rename address set abc as newabc. 
<HUAWEI> system-view
[HUAWEI] ip address-set abc type object
[HUAWEI] rename ip address-set abc address-set newabc
