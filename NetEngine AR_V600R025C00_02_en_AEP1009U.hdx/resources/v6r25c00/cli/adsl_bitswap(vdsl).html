adsl bitswap (VDSL interface)

Function

The adsl bitswap command enables or disables bit exchange on a VDSL interface.

The undo adsl bitswap command restores the default enabling status of bit exchange on a VDSL interface.

By default, bit exchange is enabled on a VDSL interface.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S10T1X2, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

adsl bitswap { off | on }

undo adsl bitswap [ off ]

Parameters

Parameter Description Value
off

Disables bit exchange on a VDSL interface.

-
on

Enables bit exchange on a VDSL interface.

-

Views

Ethernet interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

During line activation, the signal-to-noise ratio (SNR) and the number of bits to be transmitted are independently calculated for each sub-channel. However, the SNR may change due to environment factors after the line is activated. For example, the SNRs of some sub-channels reduce, whereas the SNRs of some other sub-channels increase. After a long period of time, the line may be disconnected.

Bit exchange moves some bits from sub-channels with low SNRs that fail to transmit the specified number of bits to sub-channels with higher SNRs. It can also adjust the transmit power, decreasing it for sub-channels with higher SNRs and increasing it for those with lower SNRs, so as to increase the low SNRs. This dynamic adjustment reduces the bit error rate without triggering line renegotiation.

Precautions

  • Running this command will restart the interface, causing data frame loss or service interruption.
  • Bit exchange must be enabled on devices on both ends of a line, and takes effect only after the line is activated.

Example

# Disable bit exchange on VDSL interface 1/0/0.
<HUAWEI> system-view
[HUAWEI] interface Ethernet 1/0/0
[HUAWEI-Ethernet1/0/0] adsl bitswap off
Warning: This operation may cause the interface to restart. Are you sure to continue? [Y/N]:y
