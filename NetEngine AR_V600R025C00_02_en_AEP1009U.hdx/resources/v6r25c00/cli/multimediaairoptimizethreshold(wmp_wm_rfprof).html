multimedia-air-optimize threshold

Function

The multimedia-air-optimize threshold command sets a user packet threshold in the intelligent multimedia scheduling algorithm.

The undo multimedia-air-optimize threshold command restores the default user packet threshold.

By default, the packet rate threshold for video users is 100 pps, and that for voice users is 30 pps.

Format

multimedia-air-optimize threshold { voice voice-value | video video-value } *

undo multimedia-air-optimize threshold

Parameters

Parameter Description Value
voice voice-value

Specifies the packet threshold for voice users.

The value is an integer ranging from 10 to 1000.
video video-value

Specifies the packet threshold for video users.

The value is an integer ranging from 10 to 1000.

Views

RRM profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After the intelligent multimedia scheduling algorithm is enabled, the system uses algorithms to dynamically adjust EDCA parameters and ACK policies based on the number of access users, improving user experience of voice and video applications.

The larger value between the following two values is used to identify the number of users:

  • Number of voice/video users identified by SAC.
  • Number of voice/video users identified based on the user packet threshold. The threshold is configured using the multimedia-air-optimize threshold command. If the number of voice or video packets sent by a user through the internal statistics queue of a radio exceeds the configured threshold within a specified period (1 second), the user is considered a voice or video user.

Prerequisites

The intelligent multimedia scheduling algorithm has been enabled using the multimedia-air-optimize enable command.

Example

# Set the packet rate threshold for video users to 100 pps and that for voice users to 30 pps.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] rrm-profile name p1
[HUAWEI-wlan-rrm-prof-p1] multimedia-air-optimize threshold video 100 voice 30
