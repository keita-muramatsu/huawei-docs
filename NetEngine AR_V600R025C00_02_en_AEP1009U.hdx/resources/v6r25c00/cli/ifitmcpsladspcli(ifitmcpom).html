display ifit statistic-type

Function

The display ifit statistic-type command displays IFIT MCP calculation information.

Format

display ifit statistic-type { two-way-delay | one-way-loss } { srv6-segment-list segment-list-id | flow-id flowId }

Parameters

Parameter Description Value
two-way-delay

Displays two-way frame delay measurement results.

-
one-way-loss

Displays single-ended frame loss measurement results.

-
srv6-segment-list segment-list-id

Specifies the ID of a segment list.

The value is an integer ranging from 0 to 4294967295.
flow-id flowId

Specifies an IFIT flow ID.

The value is an integer ranging from 0 to 18446744073709551615.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

Raw performance statistics of IFIT MCP include packet loss and delay statistics, which help locate and diagnose network faults. You can run this command to view raw performance statistics of a specified instance on an MCP in the IFIT system to locate network faults.

Table 1 Description of the display ifit statistic-type command output
Item Description
Period

Period number.
Error-Info

Error codes of statistics.

0: The calculation result is normal, or packet loss or delay measurement is not enabled.

1: The ingress data is incomplete in the inter-board scenario.

2: The egress data is incomplete in the inter-board scenario.

3: The ingress measurement data is not reported, or period numbers do not match because clock signals are not synchronized.

4: The egress measurement data is not reported, or period numbers do not match because clock signals are not synchronized.

10: The reverse flow instance does not exist, the result in the reverse flow instance period is not calculated, or period IDs do not match because clock signals are not synchronized.

12: The reported data is incorrect. For example, the number of received packets at the egress is greater than that at the ingress. (If the current delay or packet loss data is incorrect, it is not used for calculation to prevent calculation errors.).

17: The delay and jitter cannot be calculated, for example, because the data of the previous period is not calculated.

20: The errorinfo is inconsistent on the ingress and egress.

21: Multi-delay is not calculated.

22: The first period is not calculated.
Local-Loss

Local packet loss.
Local-Loss-Ratio

Single-ended frame loss rate.
Remote-Loss

Remote packet loss.
Remote-Loss-Ratio

Far-end packet loss rate.
Delay

Two-way delay.
Jitter

Jitter.
