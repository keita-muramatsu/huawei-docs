ipv6 address ifid standard-compatible

Function

The ipv6 address ifid standard-compatible command configures the device to generate interface identifiers according to RFC standards.

The undo ipv6 address ifid standard-compatible command cancels the configuration of generating interface identifiers according to RFC standards.

By default, the device does not generate interface identifiers according to RFC standards.

Format

ipv6 address ifid standard-compatible

undo ipv6 address ifid standard-compatible

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The 64-bit interface identifier in an IPv6 address uniquely identifies an interface on a link. It is typically derived from the MAC address of the interface. For details about the generation mode, see the description of the ipv6 address eui-64 command.

If you want to generate interface identifiers according to RFC standards, run the ipv6 address ifid standard-compatible command. The address of the interface in RFC format is generated based on its MAC address according to the following rules:

  • For interfaces that support the PPP link protocol, the U bit (the seventh bit from the most significant bit) of the MAC address is set to 0.
  • For other interfaces, the U bit of the MAC address is reversed, and FFFE is filled in the middle.

For interfaces that are configured with the PPP link protocol, the new configuration takes effect after the shutdown and undo shutdown commands are run on the interfaces and PPP renegotiation is performed.

Precautions

Modifying the ipv6 address ifid standard-compatible configuration may cause the following addresses to change: automatically generated link-local addresses, global unicast addresses in EUI-64 format, IPv6 addresses bound to DHCPv6 PD prefixes, and global IPv6 addresses generated through stateless autoconfiguration. As a result, the IPv6 status of the interface may flap, causing traffic interruption.

Example

# Configure the device to generate interface identifiers according to RFC standards.
<HUAWEI> system-view
[HUAWEI] ipv6 address ifid standard-compatible
Warning: This operation will take a long time to modify all IPv6 interface addresses. This will change the IPv6 status of each interface. Continue? [Y/N]:y
