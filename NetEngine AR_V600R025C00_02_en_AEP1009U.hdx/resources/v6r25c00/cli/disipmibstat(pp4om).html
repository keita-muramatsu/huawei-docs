display ip statistics ip-mib

Function

The display ip statistics ip-mib command displays traffic statistics about some IP-MIB nodes.

Format

display ip statistics ip-mib

display ip statistics ip-mib interface { interface-name | interface-type interface-num }

Parameters

Parameter Description Value
interface interface-name

Displays IP-MIB traffic statistics on the interface with a specified name.

-
interface interface-type interface-num

Displays IP-MIB traffic statistics on the interface with a specified type and number.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

You can run this command to view statistics about received packets, sent packets, fragmented packets, and reassembled packets.

Precautions

If the number of received error packets is different from the expected number, check whether packets are discarded due to underlying CPCAR or software CAR on the device.

Table 1 Description of the display ip statistics ip-mib command output
Item Description
OutNoRoutes

Total number of packets that are sent locally but cannot be forwarded because no route is found.
InReceives

Statistics about all received IP packets in the system, including received error packets. A 64-bit value is supported.
InOctets

Total number of bytes of all received IP packets, including the bytes of input error packets. A 64-bit value is supported.
InHdrErrors

Total number of packets with incorrect IP headers, including packets with mismatched version numbers, format errors, hop count exceeding the limit, and errors detected during IP option processing. These packets do not include packets with the invalid destination address field in the IP header or IP packets whose payload length is different from the IP packet length.
InNoRoutes

Total number of packets for which no route is found.
InAddrErrors

Total number of received packets with the invalid destination address fields in the IP headers. The count includes packets with an invalid address (for example, ::0). For non-forwarding packets, the count includes the packets that are discarded because the destination address is not the local address.
InUnknownProtos

Total number of packets that are successfully received but have invalid protocol numbers.
InTruncatedPkts

Total number of received IP packets whose payload length is different from the IP packet length.
InForwDatagrams

Total number of input forwarded packets.
ReasmReqds

Total number of received packets that need to be reassembled on the interface.
ReasmOKs

Total number of packets that are successfully reassembled.
ReasmFails

Total number of packets that fail to be reassembled, such as timeout packets and error packets, detected by the IP reassembly algorithm.
InDiscards

Total number of packets discarded due to an internal error, for example, insufficient memory. This count does not include the packets that are discarded due to waiting for reassembly.
InDelivers

Total number of datagrams successfully sent to the IP protocol (including ICMP).
OutRequests

Total number of IP packets provided by the local IP protocol (including ICMP) for IP transmission.
OutForwDatagram

Total number of successfully forwarded IP packets whose destination address is not the local device.
OutDiscards

Total number of packets that cannot be forwarded due to internal reasons, for example, insufficient memory.
OutFragReqds

Total number of packets that need to be fragmented in the system.
OutFragOKs

Total number of IP packets that are successfully fragmented in the system.
OutFragFails

Total number of IP packets that fail to be fragmented in the system. The packets include IPv4 packets with the DF flag and IPv6 packets that are being forwarded but exceed the link MTU of the outbound interface.
OutFragCreates

Total number of generated IP packet fragments.
OutTransmits

Total number of IP packets forwarded by the lower layer.
OutOctets

Total number of bytes of IP packets forwarded by the lower layer.
InMcastPkts

Total number of received IP multicast packets.
InMcastOctets

Total number of bytes of received IP multicast packets.
OutMcastPkts

Total number of sent IP multicast packets.
OutMcastOctets

Total number of bytes of sent IP multicast packets.
InBcastPkts

Total number of received broadcast packets.
OutBcastPkts

Total number of sent broadcast packets.
OutForwDatagrams

Number of outgoing datagrams received and forwarded to the destination address.
