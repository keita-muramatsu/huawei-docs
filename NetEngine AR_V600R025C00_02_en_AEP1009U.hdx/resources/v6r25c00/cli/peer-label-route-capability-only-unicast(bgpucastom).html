peer label-route-capability-only (BGP-IPv6 unicast address family view)(IPv4)

Function

The peer label-route-capability-only command enables a device to send or receive labeled routes.

The undo peer label-route-capability-only command cancels the function of sending or receiving labeled routes.

The peer label-route-capability-only disable command disables a device from sending or receiving labeled routes.

The undo peer label-route-capability-only disable command cancels the configuration of disabling the device from sending or receiving labeled routes.

By default, the function of sending or receiving labeled routes is disabled.

Format

peer peerIpv4Addr label-route-capability-only

peer peerIpv4Addr label-route-capability-only disable

undo peer peerIpv4Addr label-route-capability-only

undo peer peerIpv4Addr label-route-capability-only disable

Parameters

Parameter Description Value
peerIpv4Addr

Specifies the IPv4 address of a BGP peer.

The value is in dotted decimal notation.

Views

BGP-IPv6 unicast address family view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

This command applies to 6PE scenarios where public network IPv6 labeled routes need to be exchanged with a specified peer.

  • In a 6PE scenario, after the peer label-route-capability command is run, peers negotiate the label capability and unicast capability and advertise labeled routes.
  • In a 6PE scenario, if peers do not need to negotiate the unicast capability, run the peer label-route-capability-only command to configure the peers to negotiate only the label capability and advertise labeled routes only to specified peers.

Prerequisites

A BGP peer relationship has been established using the peer as-number command.

Configuration Impact

If the command is run multiple times for the same peer or peer group, the latest configuration overwrites the previous one.

Precautions

When the capability of sending labeled routes is enabled or disabled, the BGP connection with the specified peer is automatically terminated, the capability of the peer is re-negotiated, and then the BGP connection is automatically re-established.

Example

# Enable a BGP peer to send labeled routes and enable the peers to negotiate only the label capability.
<HUAWEI> system-view
[HUAWEI] bgp 100
[HUAWEI-bgp] peer 10.1.1.2 as-number 100
[HUAWEI-bgp] ipv6-family unicast
[HUAWEI-bgp-af-ipv6] peer 10.1.1.2 enable
[HUAWEI-bgp-af-ipv6] peer 10.1.1.2 label-route-capability-only
