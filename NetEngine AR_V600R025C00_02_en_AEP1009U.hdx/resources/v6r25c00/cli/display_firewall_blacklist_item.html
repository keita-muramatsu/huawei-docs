display firewall blacklist item

Function

The display firewall blacklist item command displays information about blacklist entries on the CPU.

Format

display firewall blacklist item source-ip { source-ipv4-address | source-ipv6-address } [ source-port source-port ] [ protocol { tcp | udp | icmp | protocol-num } ]

display firewall blacklist item destination-ip { destination-ipv4-address | destination-ipv6-address } [ destination-port destination-port ] [ protocol { tcp | udp | icmp | protocol-num } ]

display firewall blacklist item

display firewall blacklist item slot slot_id cpu cpu-id

Parameters

Parameter Description Value
source-port source-port

Specifies the source port.

The value is an integer from 1 to 65535.
protocol protocol-num

Specifies the protocol number.

The value is an integer ranging from 1 to 255.
tcp

Indicates the TCP protocol.

-
udp

Indicates the UDP protocol.

-
icmp

Indicates ICMP.

-
destination-ip destination-ipv4-address

Specifies the destination IPv4 address.

The value is in dotted decimal notation.
destination-ip destination-ipv6-address

Specifies the destination IPv6 address.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
destination-port destination-port

Specifies the destination port number.

The value is an integer from 1 to 65535.
slot slot_id

Specifies a slot ID.

The value is an integer.
cpu cpu-id

Specifies the CPU ID.

The value is an integer.
source-ip source-ipv6-address

Specifies a source IPv6 address.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
source-ip source-ipv4-address

Specifies the source IPv4 address.

The value is in dotted decimal notation.

Views

All views, User view of the virtual system

Default Level

1: Monitoring level

Usage Guidelines

To display information about blacklist entries on the CPU, run the display firewall blacklist item command.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display blacklist entries on the CPU. 
<HUAWEI> display firewall blacklist item
 IP/port/protocol              Reason            Insert Time                   Age Time  HitTimes   Description     
--------------------------------------------------------------------------------------------------------------
 10.2.2.2 /any (src) /any/user   IPS Associate    2023-04-19 16:59:55    Permanent 5           Example
Table 1 Description of the display firewall blacklist item command output
Item Description
Reason

Type of a blacklist entry. Currently, the option is as follows:

-IPS Associate: indicates the blacklist entry for IPS association detection.
Insert Time

Date and time when the blacklist entry was generated.
Age Time

Aging time of the blacklist entry, in minutes. Permanent indicates that the blacklist entry is permanently valid.
HitTimes

Hit count of the blacklist entry.
Description

Description of a blacklist entry specified by a user.
IP

IP address.
port

Port number.
protocol

Protocol type.
