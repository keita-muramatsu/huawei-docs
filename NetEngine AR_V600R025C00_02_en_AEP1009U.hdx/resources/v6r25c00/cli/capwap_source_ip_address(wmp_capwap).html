capwap source

Function

The capwap source command configures the IP address used by a WAC to establish a CAPWAP tunnel as the WAC's source IP address.

The undo capwap source command disables a WAC from using an IP address as the source IP address.

By default, no source IP address is configured for a WAC.

Format

capwap source ip-address ip-address

capwap source ipv6-address ipv6-address

undo capwap source ip-address ip-address

undo capwap source ipv6-address ipv6-address

Parameters

Parameter Description Value
ip-address ip-address

Specifies the source IPv4 address of a WAC.

The value is in dotted decimal notation.
ipv6-address ipv6-address

Specifies the source IPv6 address of a WAC.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Each WAC must have a unique IP address or VLANIF interface specified. All APs managed by the WAC learn the specified IP address or the IP address of the interface to establish CAPWAP tunnels for communication with the WAC. This IP address or interface is called the source address or source interface, respectively. You can run this command to configure the WAC's source address.

In non-CAPWAP dual-stack scenarios, a unique IPv4 or IPv6 address must be specified as the WAC's source IP address. In a CAPWAP dual-stack scenario, an IPv4 and an IPv6 address must be specified as the WAC's source IP addresses so that APs with IPv4 and IPv6 addresses can both communicate with the WAC.

Prerequisites

A VRRP group has been created and assigned a virtual IP address using the vrrp vrid virtual-ip and vrrp6 vrid virtual-ip commands, or an IP address has been assigned to a VLANIF or loopback interface.

Precautions

If the source IP address has been configured, you cannot run the capwap source interface command to configure the AC source interface.

If the IP address of the source interface is used by other services, the IP address cannot be directly deleted. You need to remove the IP address from the corresponding service first. For example, if the source IP address is used as the communication address for wireless configuration synchronization, remove this IP address from the configuration of wireless configuration synchronization before deleting the source IP address.

A maximum of one IPv4 address and one IPv6 address can be configured for the CAPWAP source interface or as the source address.

The IP address configured as the CAPWAP source address cannot be modified or removed.

Running the undo capwap source ip-address ip-addressor undo capwap source ipv6-address ipv6-addresscommand will disconnect all Fit APs from the WAC. Exercise caution when running this command.

If secondary authentication for risky commands is enabled on the device (by running the configuration re-authentication enable command), you need to enter the login password for secondary authentication when running the undo capwap source ip-address ip-addressor undo capwap source ipv6-address ipv6-addresscommand for the command to take effect.

Upon the first configuration, the CAPWAP source interface or source address can be successfully configured only when all of the following security-related configurations exist: PSK for DTLS encryption, user name and password for logging in to an AP, and password for logging in to the global offline management VAP. If any of these configurations does not exist, the system prompts you to supplement related configurations first.

Example

# Cancel the WAC's source IPv4 address 192.168.1.1.
<HUAWEI> system-view
[HUAWEI] undo capwap source ip-address 192.168.1.1
Warning: This operation will disconnect the device on the source interface. Continue? [Y/N]:y
# Set the WAC's source IPv4 address to 192.168.1.1.
<HUAWEI> system-view
[HUAWEI] vlan batch 100
[HUAWEI] interface vlanif 100
[HUAWEI-Vlanif100] ip address 192.168.1.1 24
[HUAWEI-Vlanif100] quit
[HUAWEI] capwap source ip-address 192.168.1.1
