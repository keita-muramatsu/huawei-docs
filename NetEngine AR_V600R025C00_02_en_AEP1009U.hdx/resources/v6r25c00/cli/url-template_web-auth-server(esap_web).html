url-template (Web-auth-server template view)

Function

The url-template command binds a URL template to a Portal server template.

The undo url-template command unbinds a URL template from a Portal server template.

By default, no URL template is bound to a Portal server template.

Format

url-template url-template [ ciphered-parameter-name ciphered-parameter-name iv-parameter-name iv-parameter-name key cipher key-string ]

undo url-template

Parameters

Parameter Description Value
url-template

Specifies the name of a URL template.

The value must be the name of an existing URL template.
ciphered-parameter-name ciphered-parameter-name

Indicates the encrypted name of the URL template parameter.

The value is a string of 1 to 16 characters, with question marks (?) not supported. If the string is enclosed in double quotation marks ("), the string can contain spaces. When the AC transmits parameters to the Portal server, the value must be set to cpname.
iv-parameter-name iv-parameter-name

Configures the encryption vector name of the URL template parameter.

The value is a string of 1 to 16 characters, with question marks (?) not supported. If the string is enclosed in double quotation marks ("), the string can contain spaces. When the AC transmits parameters to the Portal server, the value must be set to iv-value.
cipher key-string

Configures the encryption key of the URL template parameter.

The value is a string of 1 to 16 characters in plaintext or a string of 128 characters in ciphertext, with question marks (?) not supported. If the string is enclosed in double quotation marks ("), the string can contain spaces. When the AC transmits parameters to the Portal server, the URL key must be the same as that configured on Agile Controller-Campus.

Views

Web-auth-server template view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After the parameters of a URL template are configured, the URL template must be bound to a Portal server template so that users can be authenticated on the Portal server corresponding to the redirect URL.

For security purposes, you can encrypt parameters of the URL template bound to the Portal server template.

Prerequisites

A URL template has been created using the url-template name command.

Precautions

  • If a URL template is bound to a Portal server template using this command and a redirect URL is configured for the Portal server using the url (Portal server template view) command, only the parameters in the URL template take effect.
  • To ensure that the configuration takes effect, ensure that the URL configured using the url (URL template view) command in the URL template view is not a pushed URL.
  • Parameter information in the URL template can be encrypted only when the device connects to Agile Controller-Campus or iMaster NCE-Campus.

Example

# Bind the URL template with the name abc, name cpname after encryption, encryption vector name iv-name, and encryption key YsHsjx_202206 to the Portal server template.
<HUAWEI> system-view
[HUAWEI] url-template name abc
[HUAWEI-url-template-abc] quit
[HUAWEI] web-auth-server test
[HUAWEI-web-auth-server-test] url-template abc ciphered-parameter-name cpname iv-parameter-name iv-name key cipher YsHsjx_202206
Warning: The shared-key complexity is low.
