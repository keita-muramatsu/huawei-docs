ppp ipcp default-route

Function

The ppp ipcp default-route command configures an interface to generate a default route with the destination address being all 0s and mask being 0 after IPCP negotiation succeeds.

The undo ppp ipcp default-route command deletes the default route with the destination address being all 0s and mask being 0 from an interface.

By default, no default route is specified.

Format

ppp ipcp default-route

undo ppp ipcp default-route

Parameters

None

Views

Dialer interface view, Serial interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In a scenario where a device connects to another device using PPP, to configure a default route to specify the default outbound interface for packets, run the ppp ipcp default-route command.

Prerequisites

The link layer protocol has been configured as PPP for the interface using the link-protocol ppp command.

Precautions

After the configuration is complete, run the restart command on the corresponding interface for the configuration to take effect.

You can restart an interface using any of the following methods:

  • Run the undo pppoe-client dialer and pppoe-client dialer commands in sequence to restart the dialer interface.
  • Run the shutdown and undo shutdown commands in sequence.
  • Run the restart command.

Example

# Configure the default route.
<HUAWEI> system-view
[HUAWEI] interface dialer 1
[HUAWEI--Dialer1] ppp ipcp default-route
