display bgp link-state unicast routing-table

Function

The display bgp link-state unicast routing-table command displays BGP-LS route information.

The display bgp link-state unicast routing-table time-range command displays BGP-LS routes that flap within the specified period.

Format

display bgp link-state unicast routing-table [ peer { ipv4-address | ipv6-address } { received-routes | advertised-routes } ] [ type { node | link | ipv4-prefix | ipv6-prefix | te-policy | srv6-sid } ]

display bgp link-state unicast routing-table [ peer { ipv4-address | ipv6-address } { received-routes | advertised-routes } ] time-range time-range-start time-range-end

Parameters

Parameter Description Value
peer ipv4-address

Specifies an IPv4 peer address.

The value is in dotted decimal notation.
ipv6-address

Specifies the IPv6 address of a peer to be displayed.

The value is a 32-bit hexadecimal string in format X:X:X:X:X:X:X:X.
received-routes

Displays BGP-LS routes received from the specified peer.

-
advertised-routes

Displays BGP-LS routes advertised to the specified peer.

-
type

Indicates route type information.

-
node

Displays node routes.

-
link

Indicates link routes.

-
ipv4-prefix

Displays IPv4 prefix routes.

-
ipv6-prefix

Indicates IPv6 prefix routes.

-
te-policy

Displays TE Policy routes.

-
srv6-sid

Displays SRv6-SID routes.

-
time-range time-range-start time-range-end

Displays BGP-LS routes that flap within the specified period. For example, when start-time is set to 0d0h5m0s and end-time is set to 0d0h10m0s, information about all BGP-LS routes whose lifetimes range from 5 to 10 minutes is displayed.

Both start-time and end-time are in the format of xxdxxhxxmxxs. d indicates the day, which is an integer ranging from 0 to 10000. h indicates the hour, which is an integer ranging from 0 to 23. m indicates the minute, which is an integer ranging from 0 to 59. s indicates the second, which is an integer ranging from 0 to 59.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To check BGP-LS route information, run the display bgp link-state unicast routing-table command. BGP-LS routes carry topology information and are classified into five types of routes that carry node, link, route prefix, TE Policy and SRv6-sid information, respectively. These routes collaborate in carrying topology information.
