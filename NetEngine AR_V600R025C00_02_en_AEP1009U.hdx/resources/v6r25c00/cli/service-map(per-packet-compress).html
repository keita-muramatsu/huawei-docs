service-map(per-packet-compress view)

Function

The service-map command creates a service profile and displays the service profile view, or displays the view of an existing service profile.

The undo service-map command deletes a specified service profile.

By default, no service profile is created in the system.

This command is supported only on the AR8700 series, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series and AR6700-H series.

Format

service-map service-map-name

undo service-map service-map-name

Parameters

Parameter Description Value
service-map-name

Specifies the name of a service profile.

The value is a string of 1 to 31 case-sensitive characters. If spaces are used, the string must be enclosed in double quotation marks (" ").

Views

Per-packet-compress view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

A service profile is used to match packets with common characteristics. You can bind a service profile to a compression policy to optimize different types of services.

Follow-up Procedure

Run the match command in the service profile view to bind an ACL or application group to match service traffic.

Example

# Create service profile map1 and display the service profile view.
<HUAWEI> system-view
[HUAWEI] per-packet-compress
[HUAWEI-per-packet-compress] service-map map1
[HUAWEI-per-packet-compress-service-map-map1]
