pki-realm (DTLS client view)

Function

The pki-realm command configures a PKI realm for a DTLS client.

The undo pki-realm command deletes the PKI realm configured for a DTLS client.

By default, there is a PKI realm named default on the device. This realm can be modified but cannot be deleted.

Format

pki-realm pki-realm-name

undo pki-realm

Parameters

Parameter Description Value
pki-realm-name

Specifies the PKI realm name.

The value is a string of 1 to 64 case-insensitive characters. It cannot contain spaces.

Views

DTLS client view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

A PKI realm is a set of identity information required by a PKI entity to enroll a certificate.

DTLS obtains the local CA certificate and local certificate based on the configuration in the PKI realm.

Prerequisites

A PKI realm name has been created using the pki-realm command.

Example

# Configure a PKI realm for the device that functions as a DTLS client.
<HUAWEI> system-view
[HUAWEI] pki realm dtls-realm
[HUAWEI-pki-realm-dtls-realm] quit
[HUAWEI] dtls client
[HUAWEI-dtls-client] pki-realm dtls-realm
