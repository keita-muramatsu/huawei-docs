poe mps

Function

The poe mps command configures the current amplitude, current hold time, and detection period to maintain compatibility with non-standard PDs.

By default, the current amplitude is 6.5 mA, the current hold time in a detection period is 1 ms, and the detection period is 360 ms.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA.

Format

poe mps imps imps-value tmps tmps-value tmpdo tmpdo-value

undo poe mps

Parameters

Parameter Description Value
tmps tmps-value

Current hold time.

The value is an integer that can be 1, 7, 10, or 30, in milliseconds. The default value is 1.
tmpdo tmpdo-value

Detection period.

The value is an integer that can be 360, 420, 480, or 540, in milliseconds. The default value is 360.
imps imps-value

Current amplitude.

The value is an integer that can be 20, 40, 45, or 65, in 0.1 mA. The default value is 65.

Views

10GE interface view, 25GE interface view, GE interface view, Multi-GE interface view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If a non-standard PD connected to an interface cannot be powered on because the current hold time is too short, you can run the poe mps command to maintain compatibility with the PD.

Run this command under the guidance of Huawei engineers.

Precautions

This command is mutually exclusive with the poe af-inrush enable, poe legacy enable, and poe power-on delay delay-time 13 ~ 22 commands.

(a) If there are mutually-exclusive configurations, the following message is displayed when you configure MPS:

Error: A configuration conflict occurs. Delete the "poe power-on delay" configuration on the interface.

(b) If you run the poe af-inrush enable command and the poe legacy enable, poe power-on delay delay-time 13 ~ 22, or MPS configuration exists, the following message is displayed:

Error: A configuration conflict occurs. Delete the "poe mps" configuration on the interface.

(c) If you run the poe legacy enable command and the poe af-inrush enable, poe power-on delay delay-time 13 ~ 22, or MPS configuration exists, the following message is displayed:

Error: A configuration conflict occurs. Delete the "poe mps" configuration on the interface.

(d) If you run the poe power-on delay 13 ~ 22 command and the poe af-inrush enable, poe legacy enable, or MPS configuration exists, the following message is displayed:

Error: A configuration conflict occurs. Delete the "poe mps" configuration on the interface.

Example

# Set MPS parameters for an interface.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] poe mps imps 40 tmps 7 tmpdo 420
