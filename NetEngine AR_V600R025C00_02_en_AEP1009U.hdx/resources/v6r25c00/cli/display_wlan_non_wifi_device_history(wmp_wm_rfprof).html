display wlan non-wifi-device history

Function

The display wlan non-wifi-device history command displays information about non-Wi-Fi devices in the historical list.

Format

display wlan non-wifi-device history { all | ap-id ap-id radio radio-id }

Parameters

Parameter Description Value
all

Displays information about all the non-Wi-Fi devices in the historical list.

-
ap-id ap-id

Displays information about the non-Wi-Fi devices detected by an AP with a specified ID in the historical list.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
radio radio-id

Displays information about the non-Wi-Fi devices detected by an AP radio with a specified ID in the historical list.

The value is an integer ranging from 0 to 4.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

If information about a non-Wi-Fi device is not detected within the aging time configured using the spectrum-analysis non-wifi-device aging-time command, the AC adds the device to the historical list.
