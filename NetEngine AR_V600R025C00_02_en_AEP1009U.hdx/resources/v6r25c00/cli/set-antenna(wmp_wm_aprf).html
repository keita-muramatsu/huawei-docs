antenna-gain

Function

The antenna-gain command configures the antenna gain for all AP radios in an AP group (AP group radio view) or a specified AP radio (AP radio view).

The undo antenna-gain command restores the default antenna gain of all specified radios in an AP group (AP group radio view), or restores the antenna gain of a specified radio on an AP (AP radio view) to the antenna gain configured in the AP group radio view.

By default, no antenna gain is configured. The antenna gain of a single AP radio depends on the configuration of the AP group to which the AP radio belongs. The antenna gain of AP group radios depends on the default antenna gain of each AP.

The default antenna gain of AP radios depends on AP models and working channels of radios. You can run the display ap-type { id type-id | type ap-type } command to check the default antenna gain of radios of various AP models.

Format

antenna-gain antenna-gain

undo antenna-gain

Parameters

Parameter Description Value
antenna-gain

Specifies the antenna gain.

The value is an integer ranging from –10 to +30, in dB.

Views

AP radio view, AP group radio view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The antenna gain is the ratio of the power density produced by an antenna to the power density that should be obtained at the same point if the power accepted by the antenna were radiated equally. It can measure the capability for an antenna to receive and send signals in a specified direction, which is one of the most important parameters to select a BTS antenna. Under the same condition, a higher antenna gain indicates a longer transmission distance.

Precautions

  • The antenna gain of an AP radio configured using the command must be the same as that of the antenna connected to the AP.
  • The antenna gain of an AP radio configured using the command takes effect only for external antennas. When an AP uses external antennas, configure the antenna gain for the AP radio to be consistent with the gain of the external antennas connected to the AP.
  • The maximum transmit power of a radio must comply with local laws and regulations. For details, see the WLAN Country Codes and Channels Compliance. You can obtain this table at Huawei technical support website.
  • The configuration in the AP radio view has a higher priority than that in the AP group radio view.
  • When the antenna gain of an AP is not an integer, the AC rounds the value off and delivers the integer antenna gain. For example, if the 2.4 GHz antenna gain of an AP is 2.5 dB, the 2.4 GHz antenna gain of 3 dB is displayed on the AC.

Example

# Set the antenna gain to 4 for radio 0 of AP 0.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-id 0
[HUAWEI-wlan-ap-0] radio 0
[HUAWEI-wlan-ap-0-radio-0] antenna-gain 4
