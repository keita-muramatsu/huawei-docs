display smart-policy-route service-map

Function

The display smart-policy-route service-map command displays the configuration of an SPR service profile.

Format

display smart-policy-route service-map all

display smart-policy-route service-map name

Parameters

Parameter Description Value
name

Specifies the name of a service profile.

The value is a string of 1 to 31 case-sensitive characters. If spaces are used, the string must be enclosed in double quotation marks (" ").
all

Queries information about all SPR service profiles.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

After configuring an SPR service profile, you can run the display smart-policy-route service-map command to check information about the service profile.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the SPR service profile configuration on the device.
<HUAWEI> display smart-policy-route service-map all
--------------------------------------------------------------------------------
Service Map Info:
  ServiceMapID       :  1
  ServiceMapName     :  map1
  Match content:
    MatchType : OnlyAcl           AclName : 3998
--------------------------------------------------------------------------------
Service Map Info:
  ServiceMapID       :  3
  ServiceMapName     :  ICMP
  Match content:
    MatchType : AclAndApplication  AclName : 3000      Application: icmp
    MatchType : OnlyAppGroup       AppGroup : abc
--------------------------------------------------------------------------------
Number of Service Map: 2
--------------------------------------------------------------------------------
Table 1 Description of the display smart-policy-route service-map command output
Item Description
Service Map Info

Information about the created service profile.
ServiceMapID

Index of the created service profile.
ServiceMapName

Name of the created service profile.
Match content

Traffic classification content in the service profile.
MatchType

Service traffic matching type.

-OnlyAcl: Traffic is matched against only the ACL.

-OnlyIPv6Acl: Traffic is matched against only the IPv6 ACL.

-OnlyApplication: Traffic is matched against only the application name.

-OnlyAppGroup: Traffic is matched against only the application group name.

-AclAndApplication: Traffic is matched against the ACL and application name.

-AclAndAppGroup: Traffic is matched against the ACL and application group name.

-IPv6AclAndApplication: Traffic is matched against the IPv6 ACL and application name.

-IPv6AclAndAppGroup: Traffic is matched against the IPv6 ACL and application group name.
AclName

Name of the matched ACL.
AppGroup

Name of the matched application group.
Number of Service Map

Number of service profiles.
Application

Name of a matched application.
