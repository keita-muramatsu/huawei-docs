display bgp link-state unicast routing-table peer-node-sid

Function

The display bgp link-state unicast routing-table peer-node-sid command displays the SRv6 BGP peer node SIDs of BGP-LS SRv6 SID routes.

Format

display bgp link-state unicast routing-table [ peer { peerIpv4Addr | peerIpv6Addr } { advertised-routes | received-routes } ] prefix peer-node-sid

Parameters

Parameter Description Value
peer peerIpv4Addr

Specifies an IPv4 peer address.

The value is in dotted decimal notation.
peer peerIpv6Addr

Specifies an IPv6 peer address.

The value is a 32-digit hexadecimal number in format X:X:X:X:X:X:X:X.
advertised-routes

Displays BGP-LS routes advertised to a specified peer.

-
received-routes

Displays BGP-LS routes received from a specified peer.

-
prefix

Specifies a BGP-LS route prefix.

The BGP-LS route prefix format is complex. To facilitate your query, run the display bgp link-state unicast routing-table command to check all BGP-LS routes, and copy the prefix of the route whose information is to be queried when specifying prefix.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To view SRv6 BGP peer node SID information about BGP-LS SRv6 SID routes, run the display bgp link-state unicast routing-table peer-node-sid command.
