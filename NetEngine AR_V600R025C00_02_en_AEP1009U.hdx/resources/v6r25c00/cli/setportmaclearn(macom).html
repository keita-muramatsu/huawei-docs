mac-address learning (Layer 2 interface view)

Function

The mac-address learning disable command disables MAC address learning.

The undo mac-address learning disable command enables MAC address learning.

The mac-address learning priority command sets a MAC address learning priority on an interface.

The undo mac-address learning priority command restores the default MAC address learning priority on an interface.

By default, MAC address learning is enabled, the MAC address learning priority is 0.

Format

mac-address learning disable [ action { discard | forward } ]

mac-address learning priority priority-id

undo mac-address learning disable

undo mac-address learning priority

Parameters

Parameter Description Value
action

Indicates an action that a Layer 2 interface takes when MAC address learning is disabled on the Layer 2 interface.

By default, a Layer 2 interface takes the forward action when MAC address learning is disabled on the Layer 2 interface.

This parameter indicates whether packets are forwarded when a Layer 2 interface does not need to learn MAC addresses.

-
discard

Indicates that a Layer 2 interface discards packets with a newly learned MAC address after MAC address learning is disabled on the Layer 2 interface.

-
forward

Indicates that a Layer 2 interface forwards packets with a newly learned MAC address but does not record MAC address entries after MAC address learning is disabled on the Layer 2 interface.

-
priority-id

Specifies a MAC address learning priority on an interface.

The value is an integer that ranges from 0 to 3. A larger value indicates a higher priority.

Views

Layer 2 10GE interface view, 25GE-L2 view, Layer 2 40GE interface view, Layer 2 Eth-Trunk interface view, Layer 2 GE interface view, Layer 2 multi-GE interface view, VGE-L2 view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

If a network is stable, MAC address learning can be disabled on an interface or in a VLAN to save space of the MAC address table.

After MAC address learning is disabled by running the mac-address learning disable command, a device will not learn new addresses from the specified interface.

After MAC address learning is enabled, a device can receive Ethernet frames from other devices, parse the source MAC address of each frame, locate the interface that receives each frame, and add new entries to the MAC address table. After that, when receiving an Ethernet frame destined for the MAC address contained in the MAC address table, the device can search the MAC address table to locate the corresponding outbound interface. This reduces broadcast traffic.

If the uplink interface of a device is connected to a server and the downlink interface is connected to a user, to prevent an unauthorized user from forging the MAC address of the server to access the device, you can increase the MAC address learning priority of the server-side interface. After different priorities are set for interfaces, if different interfaces learn the same MAC address entry, the MAC address entry learned by the interface with a higher priority overwrites the MAC address entry learned by the interface with a lower priority. This ensures that the device does not learn the MAC address of the bogus server from other interfaces and only authorized users can access the server and use network resources.

You can run the undo mac-address learning priority allow-flapping command to forbid MAC address flapping between interfaces with the same priority. The mac-address learning priority and undo mac-address learning priority allow-flapping commands can both be used to improve network security. The differences between the two commands are as follows:

  • The undo mac-address learning priority allow-flapping command prevents MAC address flapping between interfaces with the same priority. After this command is executed, the network device can learn forged MAC address after being powered off, and cannot learn correct MAC addresses after being powered on.
  • After the mac-address learning priority command is executed, the network device can learn forged MAC address after being powered off, but can still learn correct MAC addresses after being powered on.

Example

# Disable MAC address learning on the interface.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] mac-address learning disable
# Set the MAC address learning priority on the interface to 3.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] mac-address learning priority 3
