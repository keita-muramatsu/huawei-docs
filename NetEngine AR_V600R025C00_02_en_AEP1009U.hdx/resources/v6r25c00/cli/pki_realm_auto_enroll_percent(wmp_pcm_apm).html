pki realm auto-enroll percent

Function

The pki realm auto-enroll percent command configures the percentage threshold for the validity period of SCEP certificate renewal.

The default value of percent is 100, indicating that the system automatically requests a new certificate when the existing one is about to expire.

Format

pki realm realm-name auto-enroll percent percent

Parameters

Parameter Description Value
realm-name

Specifies the name of a PKI realm.

The value is a string of 1 to 50 case-sensitive characters.
percent

Specifies the percentage of the certificate's validity period after which a new certificate is requested automatically.

The value is an integer ranging from 10 to 100.

Views

AP PKI realm profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After the automatic certificate renewal function is configured, the device automatically applies for and updates the certificate using SCEP when the certificate is about to expire, has expired, or reaches the specified percentage.

Precautions

After this command is run, the device checks whether the certificate has expired every 60 minutes. If the certificate has expired, the device renews it.

Example

# Configure the percentage threshold for the validity period of certificate renewal.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-pki-profile name default
[HUAWEI-wlan-ap-pki-prof-default] pki realm r1 auto-enroll percent 50
