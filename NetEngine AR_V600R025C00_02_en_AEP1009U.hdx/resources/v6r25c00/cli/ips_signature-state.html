ips signature-state

Function

The ips signature-state command configures the state of predefined signatures.

The undo ips signature-state command restores the state of all predefined signatures to their state in the IPS signature database.

By default, all predefined signatures are in the state in the IPS signature database.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

ips signature-state [ signature-id signature-id ] { enabled | disabled }

undo ips signature-state

Parameters

Parameter Description Value
signature-id signature-id

Specifies the ID of a predefined signature.

The value is an integer that ranges from 1025 to 16777215.
enabled

Enables the specified predefined signature.

-
disabled

Disables the specified predefined signature.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

You can enable certain signatures that are disabled in the IPS signature database to improve the threat detection rate, or disable certain signatures that are enabled in the IPS signature database to reduce resource consumption and improve threat detection performance.

If signature-id is specified, the pre-defined signature with the specified ID is enabled or disabled. If no ID is specified, all predefined signatures are enabled or disabled.

Follow-up Procedure

After the state of a predefined signature is changed, run engine configuration commit to commit the change to apply it.

After the state of a predefined signature is changed and committed, run display ips signature-state to check whether the state change takes effect.

Precautions

After the IPS signature database is updated, if a predefined signature for which the status, action, or exception signature processing is configured does not exist in the updated IPS signature database, the device retains the related configuration but the configuration does not take effect. You can run the display ips-signature not-in-current-library command to view the configuration of such signatures.

After running this command, run the engine configuration commit command to commit the configuration for the configuration to take effect. You are advised to commit the configuration after all content security configurations are complete.

Example

# Enable all predefined signatures, disable predefined signature 12345, and then commit the changes.
<HUAWEI> system-view
[HUAWEI] ips signature-state enabled
[HUAWEI] ips signature-state signature-id 12345 disabled
