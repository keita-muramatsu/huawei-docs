legacy-station disable

Function

The legacy-station disable command denies access of non-HT STAs.

The undo legacy-station disable command permits access of non-HT STAs.

By default, access of non-HT STAs is permitted.

Format

legacy-station [ only-dot11b ] disable

undo legacy-station disable

Parameters

Parameter Description Value
only-dot11b

Denies access of 802.11b-only STAs.

-

Views

SSID profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Non-HT STAs comply with only 802.11a/b/g and support data transmission rates far smaller than those in compliance with 802.11n or later standards. Access of such STAs will reduce the data transmission rates of STAs in compliance with 802.11n or later standards. To prevent this, you can run the legacy-station [ only-dot11b ] disable command to configure the device to deny access of all non-HT STAs or 802.11b-only ones.

Configuration Impact

After the legacy-station disable command is run, non-HT STAs supporting only 802.11a/b/g cannot access the WLAN.

After the legacy-station only-dot11b disable command is run, non-HT STAs supporting only 802.11b cannot access the WLAN.

After the device is configured to deny access of non-HT STAs, services may be interrupted.

Precautions

The legacy-station disable command configuration for denying access of 802.11a/b/g non-HT STAs does not take effect if any of the following configurations is performed on the device:

  • Disabling the WMM function by using the wmm disable command in a 2.4 GHz radio profile, 5 GHz radio profile, or SSID profile
  • Configuring WPA/WPA2 PSK authentication and TKIP encryption by using the security { wpa | wpa2 | wpa-wpa2 } psk { pass-phrase pass-phrase-key-value| hex hex-key-value} tkip command in a security profile
  • Configuring WPA/WPA2 802.1X authentication/encryption and TKIP encryption by using the security { wpa | wpa2 | wpa-wpa2 } dot1x tkip command in a security profile
  • Setting the radio type to 802.11b or 802.11g by using the radio-type { dot11b | dot11g } command in a 2.4 GHz radio profile or SSID profile
  • Setting the radio type to 802.11a by using the radio-type dot11a command in a 5 GHz radio profile or SSID profile

The legacy-station only-dot11b disable command configuration for denying access of 802.11b-only non-HT STAs does not take effect if the radio type is set to 802.11b by using the radio-type dot11b command in a 2.4 GHz radio profile or SSID profile on the device.

Example

# Configure the device to deny access of non-HT STAs.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ssid-profile name ssid1
[HUAWEI-wlan-ssid-prof-ssid1] legacy-station disable
Warning:  If the wmm disable command, TKIP, WEP, or radio type of 802.11a/b/g is configured, the function of denying access of legacy STAs cannot take effect.
