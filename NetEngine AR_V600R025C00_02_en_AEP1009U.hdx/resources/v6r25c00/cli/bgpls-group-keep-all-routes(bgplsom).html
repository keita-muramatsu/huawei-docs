peer keep-all-routes (BGP-LS address family view)(group)

Function

The peer keep-all-routes command saves all the BGP-LS address family route updates received from a specified BGP-LS address family peer group after corresponding BGP-LS connections are established, even if these routes do not match the configured import policy.

The undo peer keep-all-routes command disables this function.

By default, only the BGP-LS address family route updates that are received from peers and match the configured import policy are saved.

Format

peer peerGroupName keep-all-routes

undo peer peerGroupName keep-all-routes

Parameters

Parameter Description Value
peerGroupName

Specifies the name of a peer group.

The name is a string of 1 to 47 case-sensitive characters, with spaces not supported. When double quotation marks are used around the string, spaces are allowed in the string.

Views

BGP-LS address family view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After an import BGP policy is changed, you can reset corresponding BGP connections for the new policy to take effect immediately. This, however, interrupts the BGP connections temporarily. If a device's peers do not support route-refresh, you can run the peer keep-all-routes command on the device to retain all the routes received from the peers so that the device can refresh its routing table without resetting the BGP connections with the peers.

Implementation Procedure

If the peer or peer group specified in the peer keep-all-routes command does not exist, a message is displayed, indicating that the peer does not exist.

Precautions

If a device does not support route-refresh, this command needs to be run on both the device and its peers. If the peer keep-all-routes command is run on the device for the first time, the sessions between the device and its peers are reestablished.

If a device supports route-refresh, running this command does not result in reestablishment of the sessions between the device and its peers; however, the routing table cannot be refreshed on the device using the refresh bgp command.

The keep-all-routes command configuration in the BGP view does not take effect for peer groups in the BGP-LS address family.

Example

# Save all BGP-LS address family route updates received from a peer group.
<HUAWEI> system-view
[HUAWEI] bgp 100
[HUAWEI-bgp] group test internal
[HUAWEI-bgp] link-state-family unicast
[HUAWEI-bgp-af-ls] peer test enable
[HUAWEI-bgp-af-ls] peer test keep-all-routes
