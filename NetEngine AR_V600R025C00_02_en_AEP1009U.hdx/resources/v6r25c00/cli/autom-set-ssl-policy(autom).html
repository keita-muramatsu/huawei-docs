ssl-policy(net-assistant system-management view)

Function

The ssl-policy command configures an SSL policy for the net assistant function.

The undo ssl-policy command cancels the SSL policy configured for the net assistant function.

By default, no SSL policy is configured.

Format

ssl-policy sslPolicyName

undo ssl-policy

Parameters

Parameter Description Value
sslPolicyName

Specifies the name of an SSL policy.

The value is a string of 1 to 23 characters that can contain case-insensitive letters, underscores (_), and digits.

Views

Net-assistant system-management view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

After the net assistant function is enabled, an HTTPS channel needs to be established between the master device and member devices for data transmission. You can run this command to configure an SSL policy for the HTTPS channel of the net assistant function.

Prerequisites

  • An SSL policy has been created and the SSL policy view is displayed using the ssl policy command in the system view.
  • A certificate has been bound using the certificate load command in the SSL policy view or a PKI certificate has been bound.

Precautions

  • If the configured SSL policy name does not exist, the configuration fails and an error message is displayed.
  • Only one SSL policy can be configured for the net assistant function, and the latest configured SSL policy takes effect.

Example

# Configure an SSL policy named policy1 for the net assistant function.
<HUAWEI> system-view
[HUAWEI] net-assistant
[HUAWEI-net-assistant] system-management
[HUAWEI-net-assistant-system-management] ssl-policy policy1
