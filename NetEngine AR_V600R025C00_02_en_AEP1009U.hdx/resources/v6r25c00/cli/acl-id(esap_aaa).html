acl-id

Function

The acl-id command binds an ACL to a service scheme.

The undo acl-id command unbinds an ACL from a service scheme.

By default, no ACL is bound to a service scheme.

Format

acl-id aclv4-number

undo acl-id { aclv4-number | all }

Parameters

Parameter Description Value
aclv4-number

Specifies the number of an IPv4 ACL bound to a service scheme.

The value is an integer that ranges from 3000 to 3999 for wired users.
all

Deletes the numbers of all ACLs bound to a service scheme.

-

Views

Service scheme view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

After creating a service scheme using the service-scheme (AAA view) command, you can run the acl-id command to bind an ACL to the service scheme. The user assigned with the service scheme will have the ACL rules.

Prerequisites

An ACL must have been created using the acl (system view) or acl name command.

Precautions

In a scenario where local ACL-based authorization is performed on an access user, if the delivered ACL rule contains a source IP address, the IP address that takes effect is the user's IP address.

For example, if the referenced ACL rule is as follows:

rule 5 permit ip source 192.168.1.1 0

The actual address of the user is 120.1.1.1.

The IP address that takes effect in the rule is the actual address 120.1.1.1 of the user.

Example

# Bind ACL 3001 to the service scheme huawei.
<HUAWEI> system-view
[HUAWEI] acl 3001
[HUAWEI-acl-adv-3001] quit
[HUAWEI] aaa
[HUAWEI-aaa] service-scheme huawei
[HUAWEI-aaa-service-huawei] acl-id 3001
