nhrp shortcut

Function

The nhrp shortcut command enables the NHRP shortcut function.

The undo nhrp shortcut command disables the NHRP shortcut function.

By default, the NHRP shortcut function is disabled.

Format

nhrp shortcut

undo nhrp shortcut

Parameters

None

Views

Tunnel interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In a DSVPN shortcut scenario, when the hub node forwards traffic between spoke nodes within the same DSVPN, it sends an NHRP redirect packet to the source spoke node. In this case, the NHRP shortcut function must be enabled on spoke nodes. After receiving the NHRP redirect packet from the hub node, a spoke node sends an NHRP address resolution request to the destination spoke node to establish a tunnel for direct communication with the destination spoke node.

Prerequisites

The following operations have been performed:

  • Run the interface tunnel command to create a tunnel interface and display the tunnel interface view.
  • Run the tunnel-protocol gre p2mp command to set the tunnel encapsulation mode to mGRE.

Precautions

The NHRP shortcut function must work with the NHRP redirect function. Therefore, the NHRP redirect function must be enabled on the hub using the nhrp redirect command.

Example

# Enable the NHRP shortcut function on Tunnel 0.
<HUAWEI> system-view
[HUAWEI] nhrp enable
[HUAWEI] interface tunnel 0
[HUAWEI-Tunnel0] tunnel-protocol gre p2mp
[HUAWEI-Tunnel0] nhrp enable
[HUAWEI-Tunnel0] nhrp shortcut
