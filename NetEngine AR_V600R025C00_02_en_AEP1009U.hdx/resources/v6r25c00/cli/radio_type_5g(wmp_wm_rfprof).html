radio-type(Radio-5G-profile view)

Function

The radio-type command sets the radio type in a 5 GHz radio profile.

The undo radio-type command restores the default radio type in a 5 GHz radio profile.

By default, the radio type in a 5G radio profile is dot11be.

Format

radio-type { dot11a | dot11n | dot11ac | dot11ax | dot11be }

undo radio-type

Parameters

Parameter Description Value
dot11a

Specifies the 802.11a radio type.

-
dot11n

Specifies the 802.11n radio type, which is backward compatible.

-
dot11ac

Specifies the 802.11ac radio type, which is backward compatible.

-
dot11ax

Specifies the 802.11ax radio type, which is backward compatible.

-
dot11be

Specifies the 802.11be radio type, which is backward compatible.

-

Views

5G radio profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In most cases, the default radio type is used and does not need to be modified. If the default radio mode cannot meet requirements or a fault needs to be located, configure the radio type as required.

Precautions

Modifying the radio type may interrupt STA services. Exercise caution when you run the command.

When the radio type is set to dot11a, the function of denying access of non-HT STAs becomes invalid.

If the configured radio type is not supported by an AP, the actual radio type supported by the AP takes effect. For example, if you set the 802.11ac radio type for an 802.11n AP, the radio type that actually takes effect on the AP is 802.11n.

Example

# Set the radio type to dot11n in a 5G radio profile.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] radio-5g-profile name default
[HUAWEI-wlan-radio-5g-prof-default] radio-type dot11n
Warning: This action may cause service interruption. Continue? [Y/N]:y
