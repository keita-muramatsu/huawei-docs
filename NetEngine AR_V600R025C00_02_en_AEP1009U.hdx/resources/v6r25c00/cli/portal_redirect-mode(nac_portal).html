portal redirect-mode

Function

The portal redirect-mode command configures the redirection mode for Portal authentication.

The undo portal redirect-mode command restores the default redirection mode for Portal authentication.

By default, the device uses 200 OK redirection.

Format

portal redirect-mode { redirect-302 | redirect-200 | redirect-js }

undo portal redirect-mode

Parameters

Parameter Description Value
redirect-302

Specifies the redirection mode as 302 redirection.

-
redirect-200

Specifies the redirection mode as 200 OK redirection.

-
redirect-js

Specifies the redirection mode as JavaScript redirection.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

  1. 200 and 302 are HTTP status codes. The two status codes correspond to different redirection modes. For redirection in 200 OK mode, the URL information is in the URL field of the HTTP packet. In 302 redirection mode, the URL is in the Location field of the HTTP packet. By default, the device uses 200 OK redirection. Some applications need to use 302 redirection. In this case, you need to enable 302 redirection.
  2. In Portal authentication scenarios, the device redirects HTTP/HTTPS requests from clients to the Portal server before users are successfully authenticated. To prevent the server from being overloaded by a large number of HTTP/HTTPS requests sent by the client application software and affect the display of the Portal login page, you can enable the function of inserting JavaScript scripts during Portal redirection. A user uses the browser on the client to send an HTTP/HTTPS request packet to access a page. The HTTP/HTTPS response packet of the device carries a JavaScript script. The browser parses the JavaScript script, redirects the user, and performs Portal authentication.

Example

# Enable JavaScript redirection for Portal authentication.
<HUAWEI> system-view
[HUAWEI] portal redirect-mode redirect-js
# Enable 302 redirection for Portal authentication.
<HUAWEI> system-view
[HUAWEI] portal redirect-mode redirect-302
