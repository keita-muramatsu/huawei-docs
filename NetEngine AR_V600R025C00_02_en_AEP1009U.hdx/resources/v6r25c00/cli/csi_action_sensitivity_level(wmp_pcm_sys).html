csi action-sensitivity-level

Function

The csi action-sensitivity-level command configures the action sensing sensitivity level of the channel state information (CSI) sensing function for APs.

The undo csi action-sensitivity-level command deletes the action sensitivity level of the CSI sensing function configured for APs.

By default, the action sensitivity level of the CSI sensing function is high in the AP system profile, and not configured in the AP view. The configuration in the AP system profile takes effect.

Format

csi action-sensitivity-level level-value

undo csi action-sensitivity-level

Parameters

Parameter Description Value
action-sensitivity-level level-value

Specifies the action sensing sensitivity level. By adjusting the sensitivity level, you can determine whether to detect breaths and micro-motions.
The value is of the enumerated type:
  • high: high sensitivity level. Motions, micro-motions, and breaths can be detected.
  • low: low sensitivity level. Breath detection is disabled. Detection is not performed when the human body is stationary or only hands move.

Views

AP system profile view, AP view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In conference room scenarios, there may be breath-like environment interference, such as wind-blown curtains and disturbances outside glass walls. In this case, you are advised to set the action sensing sensitivity level to low and disable breath detection to prevent continuous misjudgments as human breaths.

Precautions

The motion sensing sensitivity level of a specified AP configured using the csi action-sensitivity-level command in the AP view takes precedence over that configured using the csi action-sensitivity-level command in the AP system profile view.

Example

# Set the action detection sensitivity level of the CSI sensing function to low for APs at a single site.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name test
[HUAWEI-wlan-ap-system-prof-test] csi action-sensitivity-level low
