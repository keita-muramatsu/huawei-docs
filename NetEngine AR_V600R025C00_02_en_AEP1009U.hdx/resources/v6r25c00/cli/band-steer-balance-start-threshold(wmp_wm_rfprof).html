band-steer balance start-threshold

Function

The band-steer balance start-threshold command sets the start threshold for the number of access STAs during band steering.

The undo band-steer balance start-threshold command restores the default start threshold for the number of access STAs during band steering.

By default, the start threshold for the number of access STAs during band steering is 100.

Format

band-steer balance start-threshold start-threshold

undo band-steer balance start-threshold

Parameters

Parameter Description Value
start-threshold

Specifies the start threshold for the number of access STAs during band steering.

The value is an integer that ranges from 0 to 100.

Views

RRM profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After the band steering function is configured on a multi-radio AP, the AP instructs STAs that support multiple frequency bands to preferentially connect to a 5 GHz or 6 GHz radio.

When a STA requests to connect to an AP radio, the AP enabled with band steering will collect statistics about access STAs on each radio.

  1. Check whether the number of access STAs on the AP exceeds the start threshold (configured using the band-steer balance start-threshold command). If not, the STA can preferentially connect to the 5 GHz or 6 GHz radio.
  2. If the number of access STAs exceeds the value specified by the start threshold, the AP calculates the percentage of access STAs on 5 GHz and 6 GHz radios using the formula: (number of access STAs on 5 GHz and 6 GHz radios/total number of access STAs) x 100%. If the percentage exceeds the percentage threshold for access STAs on 5 GHz and 6 GHz radios configured using the band-steer balance gap-threshold command, the STA proactively selects a frequency band.

Precautions

In most cases, you are advised to use the default values of the start threshold for the number of access STAs and the percentage threshold for access STAs on 5 GHz and 6 GHz radios. If the two thresholds are set low, the AP may allow STAs to freely select the access frequency band when the number of STAs on 5 GHz or 6 GHz radios is small. As a result, the 5G/6G-prior access mechanism does not take effect, and the 5 GHz and 6 GHz band utilization cannot be maximized.

Example

# Set the start threshold for the number of access STAs to 90 in the RRM profile default.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] rrm-profile name default
[HUAWEI-wlan-rrm-prof-default] band-steer balance start-threshold 90
