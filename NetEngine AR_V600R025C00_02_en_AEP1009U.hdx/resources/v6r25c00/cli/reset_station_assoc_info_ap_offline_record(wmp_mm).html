reset station assoc-info ap-offline-record

Function

The reset station assoc-info ap-offline-record command clears information about STAs that go online on offline APs.

Format

reset station assoc-info ap-offline-record { all | ap-id ap-id [ radio radio ] }

Parameters

Parameter Description Value
all

Clears information about all STAs that go online on offline APs on the WAC.

-
ap-id ap-id

Clears information about STAs that go online on the offline AP with a specified ID on the WAC.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
radio radio

Clears information about STAs that go online on a specified radio of an offline AP.

The value is an integer ranging from 0 to 4.

Views

All views

Default Level

3: Management level

Usage Guidelines

Usage Scenario

To collect statistics about STAs that go online on offline APs within a specified period, run this command to clear existing STA information so that the WAC can collect statistics again.

Prerequisites

The offline APs have been enabled to allow access of new STAs using the keep-service enable allow new-access command.

Configuration Impact

Information about STAs who go online on offline APs cannot be restored. Exercise caution when running this command.

Example

# Clear information about all STAs that go online on offline APs on the WAC.
<HUAWEI> reset station assoc-info ap-offline-record all
