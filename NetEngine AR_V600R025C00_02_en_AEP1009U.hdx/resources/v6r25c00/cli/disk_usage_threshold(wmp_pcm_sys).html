disk-usage threshold

Function

The disk-usage threshold command configures the disk usage alarm threshold for APs.

The undo disk-usage threshold command restores the default disk usage alarm threshold for APs.

By default, the memory usage alarm threshold of an AP is 95.

Format

disk-usage threshold threshold-value

undo disk-usage threshold

Parameters

Parameter Description Value
threshold-value

Species the disk usage alarm threshold of an AP.

The value is an integer ranging from 6 to 100.

Views

AP system profile view

Default Level

2: Configuration level

Usage Guidelines

You can run the disk-usage threshold command to set the disk usage alarm threshold of APs. The corresponding alarm clear threshold equals to the configured alarm threshold minus 5. The configuration is delivered to all APs using the AP system profile.

  • When the disk usage of an AP exceeds the alarm threshold, the AP sends an alarm message to the AC, and the AC displays the alarm information.
  • When the disk usage of an AP falls below the alarm clear threshold, the AP sends a clear alarm message to the AC, and the AC displays the alarm clear information.

Example

# Set the disk usage alarm threshold to 60.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name ap-system1
[HUAWEI-wlan-ap-system-prof-ap-system1] disk-usage threshold 60
