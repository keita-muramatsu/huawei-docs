traffic-remark(Traffic profile view)

Function

The traffic-remark command configures ACL-based priority re-marking in a traffic profile.

The undo traffic-remark command cancels ACL-based priority re-marking in a traffic profile.

By default, ACL-based priority re-marking is not configured in a traffic profile.

Format

traffic-remark { inbound | outbound } ipv4 acl { acl-number | name acl-name } l2 acl { acl-number-l2 | name acl-name-l2 } { dot11e dot11e-value | dscp dscp-value }

traffic-remark { inbound | outbound } l2 acl { acl-number-l2 | name acl-name-l2 } { dot11e dot11e-value | dscp dscp-value }

traffic-remark { inbound | outbound } ipv4 acl { acl-number | name acl-name } { dot11e dot11e-value | dscp dscp-value }

traffic-remark { inbound | outbound } ipv6 acl acl-number-ipv6 { dscp dscp-value | dot11e dot11e-value }

undo traffic-remark { inbound | outbound } ipv4 acl { acl-number | name acl-name } l2 acl { acl-number-l2 | name acl-name-l2 }

undo traffic-remark { inbound | outbound } l2 acl { acl-number-l2 | name acl-name-l2 }

undo traffic-remark { inbound | outbound } ipv4 acl { acl-number | name acl-name }

undo traffic-remark { inbound | outbound } ipv6 acl acl-number-ipv6

Parameters

Parameter Description Value
inbound

Configures packet priority re-marking in the inbound direction.

-
outbound

Configures packet priority re-marking in the outbound direction.

-
ipv4

Re-marks the priority of IPv4 packets.

-
acl acl-number-ipv6

Specifies the number of the ACL.

The value is an integer that ranges from 3000 to 3031 for IPv6 ACLs.
acl acl-number

Specifies the number of the ACL.

The value is an integer that ranges from 3000 to 3031 for IPv4 ACLs.
acl acl-number-l2

Specifies a Layer 2 ACL number.

The value is an integer that ranges from 4000 to 4031 for Layer 2 ACLs.
name acl-name

Filters packets based on a specified named ACL. acl-name specifies the name of the ACL.

The ACL name must exist.
name acl-name-l2

Re-marks packets based on the named Layer 2 ACL. The parameter acl-name-l2 specifies the name of an ACL.

The ACL name must exist.
l2

Re-marks the priority of Layer 2 packets.

-
dot11e dot11e-value

Re-marks the 802.11e priority of packets.

The value is an integer that ranges from 0 to 7. A larger value indicates a higher priority.
dscp dscp-value

Re-marks the DSCP priority of packets.

The value is an integer that ranges from 0 to 63. A larger value indicates a higher priority.
ipv6

Re-marks the priority of IPv6 packets.

-

Views

Traffic profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To re-mark priorities of wireless packets based on ACLs to provide differentiated services, run the traffic-remark command.

Prerequisites

An ACL rule has been created before this command is run.

**- acl number

  • acl ipv6 number
  • acl name
  • acl ipv6 name**

Precautions

You can specify an empty ACL (numbered ACL) in the traffic-remark command, and configure this ACL later.

You can configure a maximum of eight ACL-based packet re-marking rules in the same direction. The sequence in which ACL rules takes effect follows the rule configuration sequence. To change the current packet re-marking rules, delete all the related configurations and reconfigure ACL-based packet re-marking.

When the traffic-remark command and the traffic-filter (traffic profile view) command are used simultaneously and the same ACL rule is associated:

  • If the deny action is configured in the ACL rule, the traffic-remark command does not take effect.
  • If the permit action is configured in the ACL rule, the command that is configured first takes effect.

    To configure the traffic-remark command, ensure that the device has been enabled to process IPv6 services of STAs using the sta-ipv6-service enable command.

Example

# Create the traffic profile p1 and configure 802.11e priority re-marking for IPv4 packets based on ACL t1(3000) in the inbound direction.
<HUAWEI> system-view
[HUAWEI] acl name t1 number 3000
[HUAWEI-acl4-advance-t1] rule 5 permit ip source 192.168.0.2 0
[HUAWEI-acl4-advance-t1] quit
[HUAWEI] wlan
[HUAWEI-wlan] traffic-profile name p1
[HUAWEI-wlan-traffic-prof-p1] traffic-remark inbound ipv4 acl name t1 dot11e 7
[HUAWEI-wlan-traffic-prof-p1] quit
# Create the traffic profiles p1 and p2, and configure ACL-based 802.11e priority re-marking for IPv4 and IPv6 packets in the inbound direction.
<HUAWEI> system-view
[HUAWEI] acl 3000
[HUAWEI-acl4-advance-3000] rule 5 permit ip source 192.168.0.2 0
[HUAWEI-acl4-advance-3000] quit
[HUAWEI] wlan
[HUAWEI-wlan] sta-ipv6-service enable
[HUAWEI-wlan] traffic-profile name p1
[HUAWEI-wlan-traffic-prof-p1] traffic-remark inbound ipv4 acl 3000 dot11e 7
[HUAWEI-wlan-traffic-prof-p1] quit
[HUAWEI-wlan] traffic-profile name p2
[HUAWEI-wlan-traffic-prof-p2] traffic-remark inbound ipv6 acl 3000 dot11e 7
