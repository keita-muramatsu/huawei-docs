igp metric (SRv6 TE Policy view)

Function

The igp metric command sets an IGP metric for an SRv6 TE Policy.

The undo igp metric command restores the default configuration.

By default, the SRv6 TE Policy metric is equal to the IGP metric minus 1.

Format

igp metric absolute absoluteValue

undo igp metric [ absolute absoluteValue ]

Parameters

Parameter Description Value
absolute absoluteValue

Specifies the absolute metric mode.

The absoluteValue is an integer ranging from 1 to 65535.

Views

SRv6 TE policy view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

This command configures an IGP metric for an SRv6 TE Policy.

You can specify the absolute metric used by an SRv6 TE Policy during path computation or BGP route selection in a scenario where the SRv6 TE Policy inherits the IGP cost.

Precautions

When a metric is configured for an SRv6 TE Policy for BGP route selection, only an absolute metric is supported. A relative metric does not take effect for BGP route selection.

Example

# Set the metric of an SRv6 TE Policy to the absolute value 10 during SPF calculation.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] srv6-te policy a1 endpoint 2001:DB8:1::2 color 1
[HUAWEI-segment-routing-ipv6-policy-a1] igp metric absolute 10
