dhcp server option alarm enable

Function

The dhcp server option alarm enable command enables the option alarm function for the interface address pool on a DHCPv4 server.

The undo dhcp server option alarm enable command disables the option alarm function for the interface address pool on a DHCPv4 server.

By default, the option alarm function is disabled for the interface address pool on a DHCPv4 server.

Format

dhcp server option alarm enable

undo dhcp server option alarm enable

Parameters

None

Views

10GE sub-interface view, 10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE sub-interface view, 40GE interface view, Cellular interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, Ethernet sub-interface view, Ethernet interface view, GE sub-interface view, GE interface view, Multi-GE interface view, VLANIF interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When a device functions as a DHCPv4 server, to learn the device information carried in the Discover message sent by a DHCPv4 client, enable the option alarm function for the interface address pool on the DHCPv4 server so that the hwDhcpv4ServerRcvClientVendorInfo alarm can be generated and reported to the NMS. The information includes Option 12 (host name), Option 60 (vendor class identifier), and Option 125 (device name and software version).

Prerequisites

The DHCPv4 server function based on the interface address pool has been enabled using the dhcp select interface command.

Example

# Enable the option alarm function for the interface address pool on a DHCPv4 server.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] ip address 10.1.1.1 24
[HUAWEI-10GE0/0/1] dhcp select interface
[HUAWEI-10GE0/0/1] dhcp server option alarm enable
