display ap power-workmode

Function

The display ap power-workmode command displays the current power mode of an AP.

Format

display ap power-workmode { all | ap-id ap-id | ap-mac ap-mac | ap-group ap-group }

Parameters

Parameter Description Value
all

Displays the current power mode of all APs.

-
ap-id ap-id

Displays the power mode of the AP with a specified ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
ap-mac ap-mac

Displays the current power mode of the AP with a specified MAC address.

The AP's MAC address must exist.
ap-group ap-group

Displays the current power mode of the APs in a specified AP group.

The value is a string of 1 to 35 visible characters that can be Chinese characters or a combination of Chinese and English characters. It cannot contain question marks (?) or only contain double quotation marks ("). If the AP group name contains spaces,it must be enclosed with double quotation marks (" "), for example, "huawei name1". The double quotation mark (") before and after the AP group name occupies two characters together. The specified AP group must exist.

Only the command editor in UTF-8 encoding format can be used to edit Chinese characters.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

When an AP is supplied with DC or PoE power, the AP may work in low-power mode if the power fails to meet requirements. You can run this command to view the current power mode of an AP and verify that the current power mode meets the requirements of all AP functions.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the current power mode of all APs.
<HUAWEI> display ap power-workmode all
Total: 1
-----------------------------------------------------------------------------------------------------------------------------------
ID     MAC              Name    Group     Power-workmode     Decided by
-----------------------------------------------------------------------------------------------------------------------------------
0      00e0-fc76-e360   ap_1    default   AT(Limited)        LLDP 
-----------------------------------------------------------------------------------------------------------------------------------
Table 1 Description of the display ap power-workmode command output
Item Description
ID

AP ID.
MAC

MAC address of an AP.
Name

AP name.
Group

AP group to which an AP is added.
Power-workmode

Current power mode of an AP.

  • The power mode of an AP can be AF, AT, BT60, or BT90, which presents 802.3af, 802.3at, 802.3bt Class 6, and 802.3bt Class 8, respectively.
  • The working mode of an AP can be Normal, Limited, or Insufficient. In Normal mode, functions of the AP are unrestricted. In Limited mode, functions of the AP are partially restricted. In Insufficient mode, the AP restarts due to insufficient power supply, and you are not advised to use the AP in this mode.

Limited: For impact on AP services by insufficient power supply, contact technical support personnel.

Insufficient: Check the power supply capability of the PSE or contact technical support personnel.

If the value of the Power-workmode field is AF(Insufficient) and the AP restarts for 10 consecutive times in a short period of time, the possible cause is that the power supply of the AP is insufficient. After the eleventh restart, the AP enters the AF power mode. One hour later, the AP restarts again and enters the original power mode. During this period, you can check whether the PSE power supply is stable or replace the PSE power supply.
Decided by

Factor that determines the power mode of an AP.

  • LLDP: determined by the LLDP negotiation result.
  • Hardware detect: determined by the hardware detection result.
  • AP capability: determined by the maximum capability of the AP.
  • Configuration: determined by the configuration using the power force work-mode command.
Total

Total number of APs.
