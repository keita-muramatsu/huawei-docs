display srv6-te policy ifit

Function

The display srv6-te policy ifit command displays detailed SLA information about SRv6 TE Policies.

Format

display srv6-te policy ifit [ endpoint ipv6-address color color-value | policy-name name-value | binding-sid sid-value ]

Parameters

Parameter Description Value
endpoint ipv6-address

Specifies the endpoint of an SRv6 TE Policy.

The value is a 32-digit hexadecimal string in format X:X:X:X:X:X:X:X.
color color-value

Specifies a color value for an SRv6 TE Policy.

The value is an integer ranging from 0 to 4294967295.
policy-name name-value

Specifies the name of an SRv6 TE Policy.

The value is a string of 1 to 255 case-sensitive characters. If the string is enclosed in double quotation marks ("), spaces are allowed in the string.
binding-sid sid-value

Specifies a binding SID.

The value is a 32-digit hexadecimal string in format X:X:X:X:X:X:X:X.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

The display srv6-te policy ifit command displays detailed SLA information about SRv6 TE Policies.

SID stack of a segment list referenced by an SRv6 TE Policy's candidate path.

SID flag:

  • V: verification flag.
Candidate-path Count

Number of candidate paths configured for an SRv6 TE Policy.
Candidate-path Preference

Preference of an SRv6 TE Policy's candidate path.
Path State

Status of an SRv6 TE Policy's candidate path.

  • Inactive (Invalid).
  • Inactive (Valid).
  • Active.
  • Inactive (Wait BFD).
  • Inactive (BFD Down).
  • Inactive (Delay Delete).
  • Active (Wait Delay Delete).
  • Inactive (Delay Switch).
  • Inactive (Wait Switch).
Path Type

Type of an SRv6 TE Policy's candidate path. The value can be Primary, Backup, or empty. If the value is empty, the path is not preferentially selected.
Protocol-Origin

Protocol origin of an SRv6 TE Policy's candidate path:

  • PCEP(10).
  • BGP(20).
  • Configuration(30).
Originator

Originator of an SRv6 TE Policy's candidate path. The value is in the format of <ASN, node-address>, where:

  • ASN indicates the AS number. If the candidate path is statically configured, the value is 0. If the candidate path is delivered by BGP, the value is the ASN delivered by BGP.
  • If the candidate path is statically configured, the node-address value is fixed at 0.0.0.0. If the candidate path is delivered by BGP, the node-address value is the BGP-delivered router-ID of the BGP peer.
Discriminator

Discriminator of an SRv6 TE Policy's candidate path. For a statically configured candidate path, the discriminator is the same as the preference. For a BGP-delivered candidate path, the discriminator is the same as the discriminator carried in the BGP-delivered TLV.
Segment-List Count

Number of segment lists, including valid and invalid ones, referenced by an SRv6 TE Policy's candidate path.
Segment-List

Name of a segment list of an SRv6 TE Policy's candidate path.
Segment-List ID

ID of the segment list referenced by an SRv6 TE Policy's candidate path.
XcIndex

Forwarding path index allocated to the segment list of an SRv6 TE Policy's candidate path. Only the segment list of the preferred path has XcIndex.
List State

Status of the segment list of an SRv6 TE Policy's candidate path.

  • Up.
  • Down (Valid).
  • Down (Invalid).
  • Down (Overrun).
  • Down (Wait BFD).
  • Down (BFD Down).
  • Down (Delay Delete).
  • Down (Delay Switch).
  • Up (Wait Delay Delete).
  • Down (Wait SID State).
  • Down (SID Stack Down).

Latest five measurement results.

Latest IFIT Update Period

ID of the period in which the latest IFIT update message was received.
