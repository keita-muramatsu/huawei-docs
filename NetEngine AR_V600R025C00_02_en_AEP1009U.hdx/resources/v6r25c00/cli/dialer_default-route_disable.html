dialer default-route disable

Function

The undo dialer default-route disable command enables the device to generate a default route with the next-hop address being the gateway address of a specified sub-interface.

The dialer default-route disable command disables the device from generating a default route with the next-hop address being the gateway address of the specified sub-interface.

By default, the device generates a default route with the next-hop address being the gateway address of a specified sub-interface.

Format

dialer default-route disable

undo dialer default-route disable

Parameters

None

Views

10GE sub-interface view, 25GE sub-interface view, 40GE sub-interface view, GE sub-interface view, Multi-GE sub-interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After RU dial-up succeeds, the channel interface generates a default route by default. After this command is run, the default route is not generated.

Precautions

After running this command, run the shutdown and undo shutdown commands on the sub-interface for the configuration to take effect after a dial-up is triggered.

Example

# Disable the function of generating a default route with the next-hop address being the gateway address of a specified sub-interface on the GE channel interface.
<HUAWEI> system-view
[HUAWEI] interface GE 0/0/0.1
[HUAWEI-GE0/0/0.1] dialer default-route disable
