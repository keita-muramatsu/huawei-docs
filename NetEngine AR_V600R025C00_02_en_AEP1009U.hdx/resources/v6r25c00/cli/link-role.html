link-role

Function

The link-role command specifies the role of a link.

The undo link-role command deletes the role of a link.

By default, no role is configured for a link, and the link does not participate in SPR.

Format

link-role { master | backup }

undo link-role [ master | backup ]

Parameters

Parameter Description Value
master

Configures a link as the primary link.

-
backup

Configures a link as the backup link.

-

Views

Link view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

SPR preferentially uses a link in the primary link group. If the links in the primary link group do not meet service requirements, SPR selects a link from the backup link group.

Prerequisites

SPR has been configured using the smart-policy-route command.

An SPR policy profile has been created using the spr-policy command in the smart-policy-route view.

Links have been associated with a service using the link transport-network command in the SPR policy view.

Example

# Configure the MPLS link as the primary link and the Internet link as the backup link for policy profile spr1.
<HUAWEI> system-view
[HUAWEI] smart-policy-route
[HUAWEI-smart-policy-route] spr-policy node 1
[HUAWEI-smart-policy-route-spr-policy-node-1] link transport-network MPLS id 99
[HUAWEI-smart-policy-route-spr-policy-node-1-link-tn-MPLS] link-role master
[HUAWEI-smart-policy-route-spr-policy-node-1-link-tn-MPLS] quit
[HUAWEI-smart-policy-route-spr-policy-node-1] link transport-network Internet id 98
[HUAWEI-smart-policy-route-spr-policy-node-1-link-tn-Internet] link-role backup
