ip host forward check dest-mac

Function

The ip host forward check dest-mac disable command disables a device from checking whether the destination MAC address of an IPv4 host packet is the same as the local MAC address before forwarding the packet.

The undo ip host forward check dest-mac disable command enables a device to check whether the destination MAC address of an IPv4 host packet is the same as the local MAC address before forwarding the packet.

By default, the forwarding check policy for IPv4 host packets is enabled.

Format

ip host forward check dest-mac disable

undo ip host forward check dest-mac disable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

By default, the forwarding check policy for IPv4 host packets is enabled. If the destination MAC address of an IPv4 host packet does not match the local MAC address, the packet is discarded.

To disable a device from checking whether the destination MAC address of an IPv4 host packet is the same as the local MAC address before forwarding the packet, run the ip host forward check dest-mac disable command.

Configuration Impact

This command affects whether the forwarding check policy for IPv4 host packets takes effect.

Example

# Enable a device to check whether the destination MAC address of an IPv4 host packet is the same as the local MAC address before forwarding the packet.
<HUAWEI> system-view
[HUAWEI] undo ip host forward check dest-mac disable
# Disable a device from checking whether the destination MAC address of an IPv4 host packet is the same as the local MAC address before forwarding the packet.
<HUAWEI> system-view
[HUAWEI] ip host forward check dest-mac disable
