rule (DNS resolution policy view)

Function

The rule command configures a DNS resolution rule.

The undo rule command deletes a DNS resolution rule.

By default, no DNS resolution rule is configured.

Format

rule rule-id [ if-match name name ] { permit | deny | spoofing { ip-address | ipv6-address } * }

rule rule-id [ if-match name name ] { permit | deny | spoofing { ip-address | ipv6-address } * | { dns-group group-name } }

undo rule rule-id

Parameters

Parameter Description Value
if-match

Specifies the domain name matching the DNS resolution rule.

-
name name

Specifies the domain name matching the DNS resolution rule.

If this parameter is not configured, the DNS resolution rule matches all domain names.

The value is a string of 1 to 255 case-insensitive characters. It can contain digits (0 to 9), letters, hyphens (-), underscores (_), periods (.), and asterisks (*), and cannot contain spaces.

* is a wildcard and can only be used once at the beginning of the domain name. For example, *.example.com indicates that all host names with the suffix example.com are matched.
permit

Allows the domain name resolution request matching the DNS resolution rule.

-
deny

Rejects the domain name resolution request matching the DNS resolution rule.

-
spoofing ip-address

Specified the IP address of the spoofing response to the domain name resolution request matching the DNS resolution rule.

A spoofing response uses the configured IP address as the domain name resolution result to respond to the domain name resolution request. The IP address may be directed to the local homepage (providing resources such as website navigation, local videos, and applications).

The value is in dotted decimal notation.
spoofing ipv6-address

Specified the IP address of the spoofing response to the domain name resolution request matching the DNS resolution rule.

A spoofing response uses the configured IP address as the domain name resolution result to respond to the domain name resolution request. The IP address may be directed to the local homepage (providing resources such as website navigation, local videos, and applications).

The value is a 32-bit hexadecimal string in format X:X:X:X:X:X:X:X.
rule rule-id

Specifies the DNS resolution rule ID. A smaller value indicates a higher rule priority.

The value is an integer that ranges from 0 to 127.
dns-group group-name

Specifies the name of a DNS group.

The value is a string of 1 to 32 case-sensitive characters. It cannot contain spaces.

Views

DNS resolution policy view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After the DNS resolution policy function is enabled using the dns resolve policy enable command, you need to configure a resolution rule in the DNS resolution policy view to implement domain name resolution, resolution prohibition, and spoofing response for a specified domain name. The administrator can run this command to configure a DNS resolution rule.

Precautions

  • Only one global rule (matching all domain names) can be configured.

  • If the rule ID specified in rule-id already exists and the rule matches the specified domain name, the new rule overwrites the original rule no matter whether the new and original rules conflict with each other.

  • If the specified rule-id does not exist, create a rule using the specified rule-id and determine the rule insertion position based on the rule size.

Example

# Add a rule with rule-id as 0 to the DNS resolution policy, and configure address spoofing based on the DNS resolution request for www.huawei.com with the spoofing response address 192.168.1.1.
<HUAWEI> system-view
[HUAWEI] dns resolve policy
[HUAWEI-dns-resolve-policy] rule 0 if-match name www.huawei.com spoofing 192.168.1.1
