display ap-type

Function

The display ap-type command displays AP type information.

Format

display ap-type { all | id type-id | type ap-type }

Parameters

Parameter Description Value
all

Displays all supported AP types.

-
id type-id

Specifies the AP type ID.

The value is an integer in the range from 0 to 1023.
type ap-type

Specifies the AP type name.

The value is a string of 1 to 31 case-sensitive characters without spaces.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run this command to view all AP types supported by the device and information about an AP of the specified type.

Example

The actual command output varies according to the device. The command output here is only an example.

Item Description
ID

ID of an AP.

AP type.

The support for AP types depends on device models. For the mapping between AP types and IDs, see the "AP Type Names and IDs" sheet in the Quick Reference for WLAN AP Version Mapping and Models.

AP type configuration method.

  • default: The AP type is registered during initialization.
  • configure(init): AP type that is added using a command. When an AP type is added, the value of this field is init.
  • configure(normal): The AP type is added using a command, and the AC has synchronized AP type information from the AP.

Antenna gain

Antenna gain of the radio, in dB.

When the antenna gain of an AP is not an integer, the AC rounds the value off and delivers the integer antenna gain. For example, if the 2.4 GHz antenna gain of an AP is 2.5 dB, the 2.4 GHz antenna gain is displayed as 3 dB on the AC.
Frequency switching

Whether radio switching is supported.
Frequency fast switching

Whether fast radio switching without the need of a restart is supported.
Dual-5G high/low band support

Working frequency band of the 5 GHz radio.

  • Low band (36-64): The 5 GHz radio works at a low frequency band.
  • High band (100-165): The 5 GHz radio works at a high frequency band.
  • All band (36-165): The 5 GHz radio works at any frequency band.

Maximum number of STAs supported by the AP type.
Outdoor

Whether the AP is an outdoor AP.
BLE

Whether the Bluetooth function is supported.

Number of IoT cards.

Optical module

Whether external antennas are supported.
