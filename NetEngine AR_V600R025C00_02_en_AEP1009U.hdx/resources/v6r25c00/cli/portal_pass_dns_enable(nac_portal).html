portal pass dns enable

Function

The portal pass dns enable command enables the device to permit DNS packets during Portal authentication.

The undo portal pass dns enable command restores the default configuration.

By default, the device does not permit DNS packets during Portal authentication.

Format

portal pass dns enable

undo portal pass dns enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If you use a domain name to access the network, run the portal pass dns enable command to permit DNS packets destined for the DNS server. However, after this command is run, all DNS packets are permitted. You are advised to configure the DNS server IP address as an authentication-free IP address by running the free-rule command.

Precautions

This function is supported only by wireless users.

Example

# Enable the device to permit DNS packets during Portal authentication.
<HUAWEI> system-view
[HUAWEI] portal pass dns enable
Warning: This command will open the DNS port. Continue? [Y/N]:y
