ad-server template

Function

The ad-server template command creates an AD server template and displays the corresponding view.

The undo ad-server template command deletes an existing AD server template.

By default, no AD server template is configured.

Format

ad-server template template-name

undo ad-server template template-name

Parameters

Parameter Description Value
template-name

Specifies the name of an AD server template.

The value is a string of 1 to 32 case-sensitive characters. It cannot contain spaces and cannot be set to - or --. It can contain only letters, digits, underscores (_), hyphens (-), and periods (.).

Views

System view

Default Level

3: Management level

Usage Guidelines

You can run the ad-server template command to configure the AD server template in the AD server template view.

If you modify the configurations of the server, and the user is connecting the server for authentication, the system will inform you of an operation failure.

Example

# Create AD server template temp1 and access the corresponding AD server template view. 
<HUAWEI> system-view
[HUAWEI] ad-server template temp1
[HUAWEI-ad-temp1]
