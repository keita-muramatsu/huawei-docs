ppp chap password

Function

The ppp chap password command configures an interface to use the default CHAP password for CHAP authentication.

The undo ppp chap password command deletes the configured password.

By default, a password is in ciphertext format.

Format

ppp chap password { simple password2 | cipher { password1 | password2 } }

undo ppp chap password

Parameters

Parameter Description Value
simple password2

Specifies a simple password with which the local Device is authenticated by the peer in CHAP mode. The password is stored in plaintext in the configuration file.

The value is a string of 1 to 128 case-sensitive characters. It cannot contain spaces.
cipher password1

Specifies a ciphertext password with which the local Device is authenticated by the peer in CHAP mode. The password is input in encrypt text but stored in cipher text in the configuration file.

The value is a string of 1 to 268 case-sensitive characters, spaces not supported.
cipher password2

Specifies a ciphertext password with which the local Device is authenticated by the peer in CHAP mode. The password is input in simple text but stored in cipher text in the configuration file.

The value is a string of 1 to 128 case-sensitive characters. It cannot contain spaces.

Views

Dialer interface view, POS interface view, Serial interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The devices on both ends of a PPP link must complete the authentication phase before entering the network-layer protocol phase during the PPP link establishment in most cases. There are two major PPP authentication modes: CHAP and PAP. In unidirectional CHAP authentication, one end functions as the authenticator, and the other end as the authenticatee. In bidirectional CHAP authentication, both ends function as the authenticator as well as the authenticatee. In practice, only unidirectional CHAP authentication is adopted.

Unidirectional CHAP authentication can be implemented when the authenticator is configured with a user name or is not configured with any user name. This command is used to specify a password for the local end to be authenticated by the peer end in CHAP mode when the authenticator is not configured with any user name. During authentication, the authenticator sends a Challenge packet to the authenticatee. Based on the password configured on its interface and the Challenge packet, the authenticatee calculates a value using an encryption algorithm. Then the authenticatee sends its host name and the calculated value in a response packet to the authenticator. It is recommended that you specify the cipher parameter to save the password in ciphertext. When configuring CHAP authentication, you should configure the password on the local device in accordance with the user password on the peer. That is, you must configure the user name and password in the AAA view on the local device according to the user name and password of the peer.

Prerequisites

Interfaces are connected, and physical parameters of the interfaces are configured so that the physical layer status of the interfaces is Up.

PPP has been configured as the link layer protocol of the interface.

Configuration Impact

If this command is run more than once, the latest configuration overrides the previous one. After the configuration, the configured password is used for authentication.

After the simple mode is specified, the password is stored in the configuration file in plaintext mode, which has a high security risk.

Precautions

After the configuration is complete, you must run the shutdown and undo shutdown commands in sequence in the corresponding interface view for the configuration to take effect.

During configuration restoration in CFG mode, ciphertext data is re-encrypted, causing the post-encryption data to be different. In this case, you can run the display configuration rollback result command to check the ciphertext configuration differences before and after the restoration, which does not affect service functions.

Example

# Set the password to YsHsjx_202206 in ciphertext when CHAP authentication is configured for the local device through the Dialer interface.
<HUAWEI> system-view
[HUAWEI] interface Dialer 95
[HUAWEI-Dialer95] ppp chap password cipher YsHsjx_202206
