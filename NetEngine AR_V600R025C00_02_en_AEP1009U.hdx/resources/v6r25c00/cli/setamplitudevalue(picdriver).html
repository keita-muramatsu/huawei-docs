amplitude

Function

The amplitude command adjusts the step values and voltage amplitude parameters of an electrical interface.

The undo amplitude command cancels the adjustment of step values and voltage amplitude parameters and restores the default parameters of PHY chips.

By default, PHY chips use the default parameters.

Format

amplitude step value1 value2 value3 value4 value5 value6 value7 value8

amplitude voltage volValue1 volValue2

undo amplitude step

undo amplitude voltage

Parameters

Parameter Description Value
voltage volValue1 volValue2

Specifies the coarse and fine adjustment values of the voltage amplitude for an electrical interface.

  • volValue1: coarse adjustment value.
  • volValue2: fine adjustment value.

Either of volValue1 and volValue2 is an integer ranging from 0 to 4294967295.
step value1 value2 value3 value4 value5 value6 value7 value8

Specifies the step values 1 to 8 of an electrical interface.

Each of value1 to value8 is an integer ranging from 0 to 4294967295.

Views

GE electrical interface view, Interface group view, Multi-GE interface view, Layer 2 multi-GE interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When a GE electrical interface on a Huawei device connects to a non-Huawei device and signals are unstable, you can run this command to adjust the line-side transmit parameters of the electrical interface, improving the non-standard adaptability of the interface.

Precautions

  1. This command is supported only on electrical interfaces. If you run this command on a GE optical interface, the following message is displayed:

    Error: The specified interface does not support this command.
  2. This command can be delivered on some PHY chip models of electrical interfaces, but the function does not take effect.

Example

# Configure step parameters for GE1/0/1. 
<HUAWEI> system-view
Enter system view, return user view with return command.
[HUAWEI] interface GE1/0/1
[HUAWEI-GE1/0/1] amplitude step 100 200 300 400 500 600 700 800
