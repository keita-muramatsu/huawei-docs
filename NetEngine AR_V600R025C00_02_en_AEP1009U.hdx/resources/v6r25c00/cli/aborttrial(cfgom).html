abort trial(All views except the user view)

Function

The abort trial command disables the configuration trial run mode.

Format

abort trial [ { session sessionid | persist persistId } ]

Parameters

Parameter Description Value
session sessionid

Specifies the session ID in the configuration trial mode.

The value is an integer ranging from 0 to 65535.
persist persistId

Specifies the persistence flag in the configuration trial mode.

The value is a string of 1 to 256 case-sensitive characters. It can be any visible ASCII character except for the space. However, the string can contain spaces if it is enclosed with double quotation marks (" "). The string cannot start with a digit or be a hyphen (-).

Views

All views

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

You can run the commit trial command to enter the configuration trial run mode to trial run new functions and services. This ensures that the operation achieves the expected effect, thereby ensuring the security of operations on the live network and improving network reliability. If the configuration does not meet expectations, you can run the abort trial command to disable the trial running mode. Then the system rolls back to the state before the trial running.

  • To cancel the configuration trial run initiated by a session, specify the session parameter.
  • To cancel the persistent configuration trial run mode, specify the persistId parameter.

Prerequisites

Run the commit trial command to enter the configuration trial run mode.

Configuration Impact

After the configuration trial run mode is disabled, the system rolls back to the state before the trial running.

Example

# Cancel the configuration trial run mode.
<HUAWEI> system-view
[HUAWEI] commit trial 120
Committing..done. 
Info: The system enters the trial configuration mode.
The system will revert to previous configuration if the trial configuration is not confirmed in 120 seconds.
[HUAWEI] sysname Device
[Device] abort trial
Warning: The trial configuration will be rolled back. Continue? [Y/N]:Y
[HUAWEI]
# Cancel the configuration trial run mode for a specified session.
<HUAWEI> system-view
[HUAWEI] commit trial
Info: The system enters the trial configuration mode.
The system will revert to previous configuration if the trial configuration is not confirmed in 600 seconds.
[HUAWEI] sysname Device
[Device] abort trial session ?
  392  Session in trial configuration mode

[Device] abort trial session 392
Warning: The trial configuration will be rolled back. Continue? [Y/N]:Y
Info: The trial configuration rollback succeeded.
[HUAWEI]
# Cancel the persistent configuration trial run mode.
<HUAWEI> system-view
[HUAWEI] commit trial persist abcd
Info: The system enters the trial configuration mode.
The system will revert to previous configuration if the trial configuration is not confirmed in 600 seconds.
[HUAWEI] sysname Device
[Device] abort trial persist abcd
Warning: The trial configuration will be rolled back. Continue? [Y/N]:Y
Info: The trial configuration rollback succeeded.
[HUAWEI]
