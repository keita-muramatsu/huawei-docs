wmm (SSID profile view)

Function

The wmm disable command disables the WMM function in an SSID profile.

The wmm enable command enables the WMM function in an SSID profile.

The undo wmm command restores the default WMM configuration in an SSID profile.

By default, the WMM configuration does not exist in an SSID profile.

Format

wmm enable

wmm disable

undo wmm

Parameters

None

Views

SSID profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The WMM function can be enabled or disabled in both the SSID profile view and radio profile view. By default, the WMM configuration does not exist in an SSID profile. When the WMM function is not configured in an SSID profile, the WMM configuration in effect is the same as that in the radio profile view; when the WMM function is configured in an SSID profile, the WMM configuration in the SSID profile takes effect.

In most cases, it is recommended that the WMM function be enabled to ensure performance of Wi-Fi 4, 5, 6, and 7 STAs. You can disable the WMM function in the SSID profile view only when the delay is long occasionally because specific STAs do not respond to A-MPDU negotiation.

Precautions

  • The configurations cause users to go offline and then go online again, interrupting services temporarily.
  • 802.11be, 802.11ax, 802.11ac, and 802.11n STAs must support the WMM function. If the WMM function is disabled in an SSID profile, 802.11be, 802.11ax, 802.11ac, and 802.11n are unavailable. As a result, STAs can connect to the SSID only through 802.11a/b/g.
  • If the WMM function is disabled, the function of denying access of non-HT STAs fails to take effect.

Example

# Enable the WMM function in the SSID profile default.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ssid-profile name default
[HUAWEI-wlan-ssid-prof-default] wmm enable
