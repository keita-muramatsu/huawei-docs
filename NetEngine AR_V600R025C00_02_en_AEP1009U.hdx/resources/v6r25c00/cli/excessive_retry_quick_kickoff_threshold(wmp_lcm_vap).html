excessive-retry quick-kickoff-threshold

Function

The excessive-retry quick-kickoff-threshold command configures the excessive retransmission thresholds for disconnecting STAs, including the threshold of the excessive retransmission count and the retransmission duration threshold.

The undo excessive-retry quick-kickoff-threshold command restores the default excessive retransmission thresholds for disconnecting STAs, including the threshold of the excessive retransmission count and the retransmission duration threshold.

By default, the threshold of the excessive retransmission count for quickly disconnecting STAs is 512, and the retransmission duration threshold for quickly disconnecting STAs is 8.

Format

excessive-retry quick-kickoff-threshold { count count | duration duration }

undo excessive-retry quick-kickoff-threshold { count | duration }

Parameters

Parameter Description Value
count count

Specifies the threshold of the excessive retransmission count.

The value is an integer ranging from 64 to 1024.
duration duration

Specifies the retransmission duration threshold, in seconds.

The value is an integer ranging from 3 to 60.

Views

SSID profile view

Default Level

2: Configuration level

Usage Guidelines

After the excessive retransmission thresholds for quickly disconnecting STA are configured, an AP can disconnect STAs that meet the thresholds. In this way, the STAs can reassociate with the WLAN.

Example

# Set the threshold of the excessive retransmission count for quickly disconnecting STAs to 1024.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ssid-profile name ssid1
[HUAWEI-wlan-ssid-prof-ssid1] excessive-retry quick-kickoff-threshold count 1024
