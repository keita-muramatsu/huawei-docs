display qos car apply-state

Function

The display qos car apply-state command displays the application status of IP address-based traffic policing on an interface.

Format

display qos car apply-state [ interface { interface-type interface-number | interface-name } ] [ inbound | outbound ]

Parameters

Parameter Description Value
interface interface-type interface-number

Specifies the type and number of the interface.

  • interface-type indicates the type of the interface.
  • interface-number indicates the number of the interface.

The interface can be a physical Ethernet interface, a physical Ethernet sub-interface, a cellular channel interface, a dialer interface, an Eth-Trunk sub-interface, an Eth-Trunk interface, an IP-Trunk interface, an MP-group interface, a POS interface, a serial interface, a tunnel interface, or a VLANIF interface.
interface interface-name

Specifies a port name.

The value is a string of 1 to 63 characters.
inbound

Indicates the inbound direction.

-
outbound

Indicates the outbound direction.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

  • You can run this command to view the application status of IP address-based traffic policing on all interfaces or a specified interface. The command output helps you learn about the application of IP address-based traffic policing and locate faults.

Precautions

  • Only the AR models with 2 GB memory (AR5710-S8T2S, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8P2X and AR5710-S10T1X2) support this function.

Example

The actual command output varies according to the device. The command output here is only an example.

<HUAWEI> display qos car apply-state interface 10GE0/0/0 inbound
