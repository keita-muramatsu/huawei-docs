tcp ipv6 adjust-mss

Function

The tcp ipv6 adjust-mss command configures the MSS of TCP6 packets on an interface.

The undo tcp ipv6 adjust-mss command deletes the configured MSS of TCP6 packets on an interface.

By default, the MSS of TCP6 packets is not configured on an interface.

Format

tcp ipv6 adjust-mss mss-value

undo tcp ipv6 adjust-mss [ mss-value ]

Parameters

Parameter Description Value
mss-value

Specifies the MSS of TCP6 packets on an interface.

The value is an integer ranging from 128 to 9500, in bytes.

Views

10GE sub-interface view, 10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE interface view, Dialer interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, Ethernet sub-interface view, Ethernet interface view, GE sub-interface view, Loopback interface view, Tunnel interface view, VLANIF interface view, GE optical interface view, GE electrical interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The MSS is an option defined in the TCP protocol and refers to the maximum length of TCP packets that can be received by a device. When setting up a TCP connection, the local and peer devices negotiate an MSS value to determine the maximum data length of TCP packets. If the length of TCP packets sent from the peer device exceeds the MSS value, the packets are fragmented.

Precautions

  • To prevent TCP6 packets from being fragmented, you must configure a proper MSS based on the MTU. The MTU is an option used to determine whether IP packets will be fragmented. If the size of an IP packet sent by a peer device exceeds the MTU, the IP packet will be fragmented. To properly transmit a packet, ensure that the MSS value plus the lengths of all the headers (such as TCP6 and IP headers) does not exceed the MTU. For example, the default MTU of an Ethernet interface is 1500 bytes. To ensure that packets are not fragmented, the maximum MSS value is 1440 bytes [1500 ? 20 (minimum length of the TCP header) ? 40 (minimum length of the IP header)]. You are advised to set the MSS to a value ranging from 1220 bytes to 1440 bytes.
  • The tcp ipv6 adjust-mss command takes effect on the local device functioning as a TCP client or server. When another device functions as a client to negotiate the MSS through the local device, it modifies the negotiation result based on the MSS configured on the local device. Moreover, the local device changes the MSS of packets to the MSS configured using the tcp ipv6 adjust-mss command only when the MSS received by the local device is greater than the MSS configured using the tcp ipv6 adjust-mss command.
  • If the tcp ipv6 adjust-mss command is run multiple times in the same interface view, only the latest configuration takes effect.
  • If the tcp ipv6 adjust-mss command is run on a dialer interface, the protocol type configured on the interface is not checked.

Example

# Set the MSS of TCP6 packets on an interface to 1200 bytes. 
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] tcp ipv6 adjust-mss 1200
