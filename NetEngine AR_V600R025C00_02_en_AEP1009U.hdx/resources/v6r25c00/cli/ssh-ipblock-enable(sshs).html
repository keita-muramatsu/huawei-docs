ssh server ip-block disable

Function

The ssh server ip-block disable command disables an SSH server from locking client IP addresses.

The undo ssh server ip-block disable command enables an SSH server to lock client IP addresses.

By default, an SSH server is enabled to lock client IP addresses.

Format

ssh server ip-block disable

undo ssh server ip-block disable

Parameters

None

Views

System view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

  • If the client IP address locking function is enabled on the SSH server, the locked client IP address cannot be authenticated. In addition, the locked client IP address is displayed in the display ssh server ip-block list command output.
  • If the client IP address locking function is disabled on the SSH server, the locked client IP address records are deleted from the display ssh server ip-block list command output and new client IP addresses that fail to be authenticated are not displayed in the command output.

Precautions

Disabling this function poses security risks to the system. Therefore, you are advised not to disable the IP address locking function.

Example

# Enable the client IP address locking function on an SSH server.
<HUAWEI> system-view
[HUAWEI] undo ssh server ip-block disable
