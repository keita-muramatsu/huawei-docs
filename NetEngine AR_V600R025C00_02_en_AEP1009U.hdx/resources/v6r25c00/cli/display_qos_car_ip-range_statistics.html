display qos car ip-range statistics

Function

The display qos car ip-range statistics command displays statistics about traffic policing based on an IP address range on an interface.

Format

display qos car ip-range statistics interface { interface-type interface-num | interface-name } { inbound | outbound }

Parameters

Parameter Description Value
inbound

Indicates the inbound policy.

-
outbound

Indicates the outbound policy.

-
interface interface-type interface-num

Specifies the interface type and number.

The value is a string of case-sensitive characters. It cannot contain spaces.
interface interface-name

Specifies an interface name.

The value is a string of case-sensitive characters. It cannot contain spaces.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

This command is used to view statistics about IP address-based traffic policing on a specified interface. The command output helps you learn statistics about IP address-based traffic policing and locate faults.

Precautions

  • Only the AR models with 2 GB memory (AR5710-S8T2S, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8P2X and AR5710-S10T1X2) support this function.
