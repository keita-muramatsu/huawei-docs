hrp track interface

Function

The hrp track interface command enables an HRP group to monitor the interface status.

The undo hrp track interface command disables an HRP group from monitoring the interface status.

By default, HRP groups do not monitor interfaces.

Format

hrp track interface { interface-type interface-number | interface-name }

undo hrp track interface { interface-type interface-number | interface-name }

Parameters

Parameter Description Value
interface-type

Specifies an interface type.

The interface type can be Ethernet or Eth-Trunk.
interface-number

Specifies an interface number.

-
interface-name

Specifies an interface name.

The value is a string of case-sensitive characters. It cannot contain spaces.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When a VRRP group is configured, HRP automatically monitors the interface corresponding to the VRRP group. You do not need to run this command. In the networking where the devices connect to routers in upstream and downstream directions, the routers cannot transparently transmit VRRP multicast packets. Therefore, interfaces cannot be monitored by configuring a VRRP group. In this case, you need to run the hrp track interface command to enable HRP to monitor the status of service interfaces.

Configuration Impact

If the interface monitored by HRP is faulty, the priority of the local device decreases (the fault indicator increases by 2). If an Eth-Trunk interface is monitored, the member interfaces of the Eth-Trunk interface are also monitored by default. For details, see the hrp track trunk-member enable command.

Precautions

An HRP group does not monitor any sub-interface. There is no limit on the number of monitored Ethernet and Eth-Trunk interfaces.

The hrp track interface command enables an HRP group to monitor the physical status, not protocol status, of interfaces. Therefore, you only need to run the hrp track command on the main interface with multiple sub-interfaces.

Example

# Configure an HRP group to monitor 10GE0/0/1.
<HUAWEI> system-view
[HUAWEI] hrp track interface 10GE 0/0/1
