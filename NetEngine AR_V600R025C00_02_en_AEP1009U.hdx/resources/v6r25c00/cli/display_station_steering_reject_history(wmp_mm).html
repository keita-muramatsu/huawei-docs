display station steering reject history

Function

The display station steering reject history command displays historical records of STA steering rejection.

Format

display station steering reject history { sta-mac mac | all | ap-id ap-id-value [ radio-id radio-id-value ] }

Parameters

Parameter Description Value
sta-mac mac

Displays steering rejection records of the STAs with a specified MAC address.

The value is in H-H-H format. H is a hexadecimal number that contains one to four digits, such as 00e0 and fc01. If an H contains fewer than four digits, the leftmost digits are padded with 0s. For example, two 0s are added to e0 to form 00e0.
all

Displays steering rejection records of all STAs.

-
ap-id ap-id-value

Displays steering rejection records of all STAs on an AP with a specified ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
radio-id radio-id-value

Displays steering rejection records of all STAs on a specified radio.

The value is an integer ranging from 0 to 4.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

After the load balancing, band steering, or smart roaming function is enabled, STAs are steered. You can run this command to check historical information about STA steering rejection.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display historical steering rejection records of all STAs.
<HUAWEI> display station steering reject history all
Total: 4
--------------------------------------------------------------------------------------------- 
Time                     Sta             AP ID     Radio ID     Reason
---------------------------------------------------------------------------------------------
2019-01-11/15:56:49      00e0-fc12-3456  1         2            The STA is in the delay-offline list.
2019-01-11/15:48:49      00e0-fc12-3456  2         1            The STA is protected against ping-pong handovers.
2019-01-11/15:43:49      00e0-fc12-3456  3         2            No proper roaming target is found.
2019-01-11/15:43:29      00e0-fc12-3456  4         1            The STA is within the steering protection interval.
---------------------------------------------------------------------------------------------
Table 1 Description of the display station steering reject history command output
Item Description
Time

Time when a STA is triggered to steer.
Sta

MAC address of a STA.
AP ID

AP ID.
Radio ID

Radio ID.
Reason

Reason for steering rejection.

  • The STA has delay-sensitive services.
  • The AGV cannot be steered.
  • The STA is in the delay-offline list.
  • No proper roaming target is found.
  • The STA is within the steering protection interval.
  • The online duration of the STA does not meet the roaming condition.
  • BTM steering cannot be performed, and deauthentication steering is disabled.
  • The STA is in the unsteerable STA list.
  • The STA is protected against ping-pong handovers.

Total.
