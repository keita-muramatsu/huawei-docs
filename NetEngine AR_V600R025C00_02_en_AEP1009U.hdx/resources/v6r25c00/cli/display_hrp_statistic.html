display hrp statistic

Function

The display hrp statistic command displays statistics on HRP backup packets.

Format

display hrp statistic

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

If the hot standby relationship fails to be established or session information or configuration commands fail to be backed up between the active and standby devices, run the display hrp statistic command to view packet statistics on the backup channel. Pay attention to the packets sent and received by each module to determine the packet loss point.

If the number of packets to be sent and received in the backup channel is small or even 0, you are advised to run the display cpu-usage command to check whether the CPU usage is high.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display statistics on HRP backup packets.
<HUAWEI> display hrp statistic
 HRP statistic information :
Module statistic information (ctrl-plane):
Module               Sent                Received
Configuration        2                   2
cpu_table            2                   2
AR_MS                2                   2

Module statistic information (SLOT/CPU:0/0):
Module               Sent                Received
SLA                  1641                0
SESSION              1641                0
heartbeat            1641                0
Table 1 Description of the display hrp statistic command output
Item Description
Module statistic information (ctrl-plane):

Statistics on backup packets sent and received by each feature module on the control plane.
Module statistic information (SLOT/CPU:*/*)

Statistics on backup packets sent and received by each feature module on the data plane CPU. 5/0 indicates the slot ID/CPU ID of the service board.
Module

Module name. The options are as follows:

  • Configuration: number of configuration backup packets.
  • cpu_table: number of cpu_table data packets.
  • BATCH: number of packets for batch data backup.
  • PKI: number of packets on the PKI module.
  • VRRP: number of packets on the VRRP module.
  • FLOW4: number of session backup packets.
  • heartbeat: number of heartbeat packets.
  • escape: number of escape packets.
  • AM: number of AM module packets.
  • AR_MS: number of AR_MS module packets.
  • SLA: number of SLA module packets.
  • SESSION: number of SESSION module packets.
Sent

Number of sent packets.
received

Received packets count.
