ssh server hmac

Function

The ssh server hmac command configures HMAC authentication algorithms on an SSH server.

The undo ssh server hmac command restores the default HMAC authentication algorithms on the SSH server.

By default, the SSH server uses the HMAC algorithms SHA2_512_ETM, SHA2_256_ETM, SHA2_512, and SHA2_256.

When a device starts with factory settings, the SSH server uses the HMAC algorithm SHA2_512 or SHA2_256.

Format

ssh server hmac { md5 | md5_96 | sha1 | sha1_96 | sha2_256 | sha2_256_96 | sha2_512 | sm3 | sha2_256_etm | sha2_512_etm } *

undo ssh server hmac

Parameters

Parameter Description Value
md5

Specifies an HMAC MD5 authentication algorithm.

-

-
sha1

Specifies an HMAC SHA1 authentication algorithm.

-
sha1_96

Specifies an HMAC SHA1_96 authentication algorithm.

-

Specifies an HMAC SHA2_256 authentication algorithm. This algorithm is recommended.

-

-

Views

System view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

  • The SSH server and client need to negotiate an authentication algorithm for the packets transmitted between them. You can run the ssh server hmac command to configure an authentication algorithm for the SSH server. After the SSH server receives a packet from the client, the server matches the client's authentication algorithm list against its local list and selects the first matched authentication algorithm as the authentication algorithm for packet transmission. If no authentication algorithm matches, the negotiation fails.
  • The authentication algorithms are listed in descending order of security level: sha2_512_etm > sha2_256_etm > sha2_512 > sha2_256 > sm3 > sha2_256_96 > sha1 > sha1_96 > md5 > md5_96

Precautions

  • For security purposes, you are advised to use the following HMAC algorithms: sha2_512_etm, sha2_256_etm, sha2_512, and sha2_256.
  • This command applies to both IPv4 and IPv6.
  • The algorithms specified by md5, md5_96, sha1, sha1_96, and sha2_256_96 parameters in this command can be used only after the weak security algorithm/protocol feature package (WEAKEA) is installed using the install feature-software WEAKEA command.

Example

# Configure HMAC SHA2_256. 
<HUAWEI> system-view
[HUAWEI] ssh server hmac sha2_256
