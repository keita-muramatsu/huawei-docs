wait-to-restore-period

Function

The wait-to-restore-period command configures an SPR switchback WTR period.

The undo wait-to-restore-period command deletes the configured SPR switchback WTR period.

By default, the SPR switchback WTR period is 6 seconds.

Format

wait-to-restore-period time-value

undo wait-to-restore-period [ time-value ]

Parameters

Parameter Description Value
time-value

Specifies a switchback WTR period.

The value is an integer ranging from 1 to 259200, in seconds.

Views

SRv6 SPR policy view

Default Level

2: Configuration level

Usage Guidelines

If traffic is switched from an abnormal high-priority link to a low-priority link, SPR immediately switches traffic back to the high-priority link when this link recovers. If key services are being transmitted over the low-priority link in this case, the switchback causes traffic loss. After an SPR switchback WTR period is set, the device does not switch traffic back to the high-priority link when detecting that the link recovers. This ensures the reliable transmission of key services over the low-priority link during this period.

After an SPR switchback WTR period is set, the device starts the timer when the high-priority link recovers after a traffic switchover to the low-priority link through SPR. If the high-priority link remains normal within the configured switchback period, SPR switches traffic from the low-priority link back to the high-priority link after the switchback period expires. If the device detects that the high-priority link does not meet traffic forwarding requirements at a certain moment within the configured switchback WTR period, it restarts the timer when detecting that the high-priority link recovers next time.

Example

# Configure an SPR switchback WTR period.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] smart-policy-route
[HUAWEI-segment-routing-ipv6-spr] spr-policy spr1
[HUAWEI-segment-routing-ipv6-spr-policy-spr1] wait-to-restore-period 3
