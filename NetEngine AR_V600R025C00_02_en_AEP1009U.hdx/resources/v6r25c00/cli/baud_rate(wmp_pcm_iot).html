baud-rate

Function

The baud-rate command configures the baud rate used by an AP to communicate with an IoT card.

The undo baud-rate command restores the default baud rate used by an AP to communicate with an IoT card.

By default, no baud rate is configured, and an AP can automatically adapt to the baud rate.

Format

baud-rate { 9600 | 19200 | 38400 | 57600 | 115200 | 921600 }

undo baud-rate

Parameters

Parameter Description Value
9600

Sets the baud rate to 9600 bit/s.

9600
19200

Sets the baud rate to 19200 bit/s.

19200
38400

Sets the baud rate to 38400 bit/s.

38400
57600

Sets the baud rate to 57600 bit/s.

57600
115200

Sets the baud rate to 115200 bit/s.

115200
921600

Sets the baud rate to 921600 bit/s.

921600

Views

AP IoT-card view, AP Group IoT-card view

Default Level

2: Configuration level

Usage Guidelines

In most cases, an AP can adjust the baud rate adaptively with an IoT card. However, for some special cards, such as a card with an RS485 port, the AP does not support baud rate adaptation. In this case, set this parameter to the same as the baud rate of the card.

Example

# Set the baud rate used by APs in an AP group to communicate with IoT cards to 9600 bit/s.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-group name default
[HUAWEI-wlan-ap-group-default] card 1
[HUAWEI-wlan-ap-group-default-card-1] baud-rate 9600
# Set the baud rate used by an AP to communicate with an IoT card to 9600 bit/s.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-id 0 type-id 128 ap-mac 00e0-fc11-1111
[HUAWEI-wlan-ap-0] card 1
[HUAWEI-wlan-ap-0-card-1] baud-rate 9600
