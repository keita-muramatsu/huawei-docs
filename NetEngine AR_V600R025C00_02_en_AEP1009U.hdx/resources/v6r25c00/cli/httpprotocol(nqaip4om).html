protocol (HTTP test instance)

Function

The protocol command sets the probe protocol type for an HTTP NQA test instance.

The undo protocol command restores the default configuration.

The default probe protocol type is HTTPS.

Format

protocol { http | https }

undo protocol

undo protocol { http | https }

Parameters

Parameter Description Value
http

Sets the detection protocol type to HTTP.

-
https

Sets the detection protocol type to HTTPS.

-

Views

NQA view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To specify the protocol header type of the destination URL for an NQA HTTP test instance, run the protocol command.

  • If the protocol header type is set to HTTP using the protocol command, the URL protocol header in the http-url command must be HTTP, and no SSL policy can be configured.
  • If the protocol header type is set to HTTPS using the protocol command, the URL protocol header in the http-url command must be HTTPS, and an SSL policy must be configured.

Precautions

  1. Changing the protocol type will clear the configurations of the http-url and ssl-policy commands.
  2. If you change the value of this parameter during the running of a test instance, the system prompts you whether to stop the test instance. Press "Y" or "N" as required.
  • If you enter Y, the current test instance is stopped and parameters are modified. After you submit the modification, the modified parameters take effect. To restart the test instance, run the start command.
  • If you enter N, the parameter modification fails and the current test instance continues to run.

Example

# Set the probe protocol to HTTPS for the test instance named user test.
<HUAWEI> system-view
[HUAWEI] nqa test-instance user test
[HUAWEI-nqa-user-test] test-type http
[HUAWEI-nqa-user-test] protocol https
