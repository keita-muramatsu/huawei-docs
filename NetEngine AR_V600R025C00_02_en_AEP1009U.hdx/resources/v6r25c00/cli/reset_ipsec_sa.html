reset ipsec sa

Function

The reset ipsec sa command deletes IPsec SAs.

Format

reset ipsec sa [ remote { ipv4-address | ipv6-address } | policy policy-name [ seq-number ] | profile profile-name | parameters destination-address { ah | esp } spi | slot slot-id cpu cpu-id ]

Parameters

Parameter Description Value
remote ipv4-address

Specifies the IPv4 address of the remote end.

The value is in dotted decimal notation.
ipv6-address

Specifies the IPv6 address of the remote end.

The value is in colon hexadecimal notation.
policy policy-name

Specifies the name of an IPSec policy.

The security policy must have been configured.
seq-number

Specifies the sequence number of an IPsec policy.

If sequence-number is not specified, all the IPsec policies in the IPsec policy group with the specified name are used.

The value must be an existing IPsec policy sequence number.
profile profile-name

Specifies the name of an IPsec profile.

If profile is not specified, IPsec SAs established using all IPsec profiles are deleted.

The value must be an existing IPsec profile name.
parameters destination-address

Specifies the destination address that uniquely identifies an IPsec SA.

If no parameter is specified, IPsec SAs established using any security protocol are deleted.

The value is in dotted decimal notation.
ah

Specifies the security protocol as AH.

-
esp

Specifies the security protocol as ESP.

-
spi

Specifies the security parameter index (SPI).

The value is an integer that ranges from 256 to 4294967295.
slot slot-id

Deletes IPsec SAs with the specified slot ID.

The value varies depending on device models.
cpu cpu-id

Deletes IPsec SAs with the specified CPU ID.

The value varies depending on device models.

Views

User view

Default Level

2: Configuration level

Usage Guidelines

When you run the reset ipsec sa command to delete IPsec SAs, note the following points:

  • If no parameter is specified, all IPsec SAs are deleted.
  • If parameters is specified, the IPsec SAs in two directions are deleted simultaneously.
  • To delete IPsec SAs established through IKE negotiation, you must run the reset ipsec sa and reset ike sa commands in sequence. Otherwise, IPsec SAs established through IKE negotiation fail to be deleted. After the IPsec SAs are deleted, IKE peers re-negotiate IPsec SAs only when packets trigger IKE negotiation.

Example

# Delete the IPsec SA with remote IP address 10.1.1.2.
<HUAWEI> reset ipsec sa remote 10.1.1.2
# Delete all the IPsec SAs.
<HUAWEI> reset ipsec sa
# Delete the IPsec SA whose remote IP address is 10.1.1.2, security protocol is AH, and SPI is 10000.
<HUAWEI> reset ipsec sa parameters 10.1.1.2 ah 10000
# Delete the IPsec SA with IPsec policy name policy1 and sequence number 10.
<HUAWEI> system-view
[HUAWEI] ipsec policy policy1 10 isakmp
[HUAWEI-ipsec-policy-isakmp-policy1-10] return
<HUAWEI> reset ipsec sa policy policy1 10
# Delete all the IPsec SAs in IPsec policy group policy1.
<HUAWEI> system-view
[HUAWEI] ipsec policy policy1 10 isakmp
[HUAWEI-ipsec-policy-isakmp-policy1-10] return
<HUAWEI> reset ipsec sa policy policy1
# Delete the IPsec SA established through IPsec profile profile1.
<HUAWEI> system-view
[HUAWEI] ipsec profile profile1
[HUAWEI-ipsec-profile-profile1] return
<HUAWEI> reset ipsec sa profile profile1
