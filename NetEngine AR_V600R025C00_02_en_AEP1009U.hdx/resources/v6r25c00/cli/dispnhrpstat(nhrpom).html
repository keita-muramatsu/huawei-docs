display nhrp statistics

Function

The display nhrp statistics command displays NHRP packet statistics.

Format

display nhrp statistics interface { interface-name | interface-type interface-number }

Parameters

Parameter Description Value
interface-type

Type of an interface.

-
interface-number

Number of an interface.

-
interface interface-name

Name of an interface.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

When you locate DSVPN faults, to determine whether a device has sent or received NHRP packets, run the display nhrp statistics command to view statistics about sent and received NHRP packets. This configuration helps quickly locate a fault.

Example

The actual command output varies according to the device. The command output here is only an example.
