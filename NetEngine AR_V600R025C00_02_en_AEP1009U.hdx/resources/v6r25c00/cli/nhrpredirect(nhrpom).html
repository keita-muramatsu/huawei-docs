nhrp redirect

Function

The nhrp redirect command enables the NHRP redirect function.

The undo nhrp redirect command disables the NHRP redirect function.

By default, the NHRP redirect function is disabled.

Format

nhrp redirect

undo nhrp redirect

Parameters

None

Views

Tunnel interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In a DSVPN shortcut scenario, you need to enable the NHRP redirect function on the hub node. Then, when the hub node forwards traffic between spoke nodes, it sends an NHRP redirect packet to the source spoke node. After receiving this packet, the source spoke node sends an NHRP address resolution request to the destination spoke node to establish a tunnel for direct communication.

Prerequisites

The following operations have been performed:

  • Run the interface tunnel command to create a tunnel interface and display the tunnel interface view.
  • Run the tunnel-protocol gre p2mp command to set the tunnel encapsulation mode to mGRE.

Configuration Impact

After you run this command on the hub, it takes effect no matter the NHRP shortcut function is enabled on a spoke or not. When you disable the NHRP shortcut function on spoke, the hub sends an NHRP Redirect packet whenever a data packet is received, this cause the wasting of CPU and network resources. Enabling the NHRP shortcut function on a spoke solves this problem.

Example

# Enable the NHRP redirect function on Tunnel 0.
<HUAWEI> system-view
[HUAWEI] nhrp enable
[HUAWEI] interface tunnel 0
[HUAWEI-Tunnel0] tunnel-protocol gre p2mp
[HUAWEI-Tunnel0] nhrp enable
[HUAWEI-Tunnel0] nhrp redirect
