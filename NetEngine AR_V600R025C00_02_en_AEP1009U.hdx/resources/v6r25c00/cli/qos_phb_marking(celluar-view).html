qos phb marking(Cellular channel interface view)

Function

The qos phb marking command enables mapping between PHBs and DSCP or 802.1p priorities in the outbound direction.

The undo qos phb marking command disables mapping between PHBs and DSCP or 802.1p priorities in the outbound direction.

By default, mapping from PHBs to 802.1p priorities is disabled and mapping from PHBs to DSCP priorities is disabled for outgoing packets.

Format

qos phb marking dscp enable

qos phb marking 8021p enable

undo qos phb marking dscp enable

undo qos phb marking 8021p enable

Parameters

None

Views

Cellular channel interface view

Default Level

2: Configuration level

Usage Guidelines

Generally, the undo qos phb marking dscp enable command is used on an edge node of the DiffServ domain to disable the mapping between PHBs and dscp priorities. When the downstream device needs to use dscp priorities in packets, run the qos phb marking dscp enable command to enable mapping between PHBs and dscp priorities in the outbound direction.

Generally, the undo qos phb marking 8021p enable command is used on an edge node of the DiffServ domain to disable the mapping between PHBs and 802.1p priorities. When the downstream device needs to use 802.1p priorities in packets, run the qos phb marking 8021p disable command to enable mapping between PHBs and 802.1p priorities in the outbound direction.

Example

# Enable mapping between PHBs and 802.1p priorities for outgoing packets on Cellular 1/0/1:1.
<HUAWEI> system-view
[HUAWEI] interface Cellular 1/0/1:1
[HUAWEI-Cellular1/0/1:1] qos phb marking 8021p enable
# Enable mapping between PHBs and DSCP priorities for outgoing packets on Cellular 1/0/1:1.
<HUAWEI> system-view
[HUAWEI] interface Cellular 1/0/1:1
[HUAWEI-Cellular1/0/1:1] qos phb marking dscp enable
