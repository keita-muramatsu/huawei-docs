ssh server cipher

Function

The ssh server cipher command configures encryption algorithms on an SSH server.

The undo ssh server cipher command restores the default encryption algorithms on the SSH server.

By default, the SSH server uses the AES256_GCM, AES128_GCM, AES256_CTR, AES192_CTR and AES128_CTR encryption algorithms.

Format

ssh server cipher { des_cbc | 3des_cbc | aes128_cbc | aes192_cbc | aes256_cbc | aes128_ctr | aes256_ctr | arcfour128 | arcfour256 | blowfish_cbc | aes128_gcm | aes256_gcm | aes192_ctr | sm4_cbc | sm4_gcm | sm4_ctr } *

undo ssh server cipher

Views

Default Level

Usage Guidelines

Usage Scenario

  • The SSH server and client need to negotiate an encryption algorithm for the packets transmitted between them. You can run the ssh server cipher command to configure an encryption algorithm for the SSH server. After the SSH server receives a packet from the client, the server matches the encryption algorithm list of the client against its local list and selects the first matched encryption algorithm. If no encryption algorithm matches, the negotiation fails.
  • The encryption algorithms are listed in descending order of security level: aes256_gcm > aes128_gcm > aes256_ctr > aes192_ctr > aes128_ctr > sm4_gcm > sm4_ctr > sm4_cbc > aes256_cbc > aes192_cbc > aes128_cbc > arcfour256 > arcfour128 > blowfish_cbc > 3des_cbc > des_cbc

Precautions

  • For security purposes, you are advised to use the following encryption algorithms: aes256_gcm, aes128_gcm, aes256_ctr, aes192_ctr, and aes128_ctr.
  • This command applies to both IPv4 and IPv6.
  • Parameters des_cbc, 3des_cbc, aes128_cbc, aes256_cbc, arcfour128, arcfour256, blowfish_cbc, aes192_cbc, and sm4_cbc in the command can be used only after the weak security algorithm/protocol feature package (WEAKEA) is installed using the install feature-software WEAKEA command.

Example

# Configure the encryption algorithms in aes256_ctr mode. 
<HUAWEI> system-view
[HUAWEI] ssh server cipher aes256_ctr
