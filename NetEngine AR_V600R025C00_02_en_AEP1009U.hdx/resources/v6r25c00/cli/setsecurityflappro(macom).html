port-security static-flapping protect

Function

The port-security static-flapping protect command enables static MAC address flapping detection.

The undo port-security static-flapping protect command disables static MAC address flapping detection.

By default, static MAC address flapping detection is disabled.

Format

port-security static-flapping protect

undo port-security static-flapping protect

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Assume that a static MAC address is configured on interface B of a device through the mac-address static command or that a secure MAC address is learned on this interface, thereby enabling a user to access the device. When the user is disconnected from interface B and then connected to interface A, interface A will receive packets whose source MAC address matches the static MAC address entry of interface B. The device considers this as static MAC address flapping and discards the packets. As a result, the user cannot access the device.

To configure the device to report an alarm when static MAC address flapping occurs, enable the static MAC address flapping detection function on the device and the port security function on interface A. In this way, interface A will perform port security protection actions like reporting an alarm when static MAC address flapping occurs.

Example

# Enable static MAC address flapping detection.
<HUAWEI> system-view
[HUAWEI] port-security static-flapping protect
