single-pdn mode enable

Function

The single-pdn mode enable command enables the single PDN mode.

The undo single-pdn mode enable command disables the single PDN mode.

By default, the single PDN mode is disabled.

Format

single-pdn mode enable

undo single-pdn mode enable

Parameters

None

Views

Cellular template view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When a modem establishes multiple PDN connections with the core network, you can run this command to enable the single PDN mode to reduce the network latency and improve the data transmission speed.

Precautions

This command takes effect only for RUs and NRGL modules.

After this command is configured, you need to manually restart the module for the configuration to take effect.

When the single-PDN mode is enabled, the system automatically exits the single-PDN mode after the dial-up fails and self-healing is triggered.

Example

# Enable the single PDN mode.
<HUAWEI> system-view
[HUAWEI] cellular-profile net
[HUAWEI-cellular-profile-net] single-pdn mode enable
