fragment-threshold

Function

The fragment-threshold command configures the size of MP packet fragments.

The undo fragment-threshold command disables MP fragmentation.

By default, MP fragmentation is disabled.

Format

fragment-threshold threshold

undo fragment-threshold

Parameters

Parameter Description Value
threshold

Specifies a fragmentation mode.

The value is an integer ranging from 0 to 3.

  • 0 indicates that the fragment size is 128 bytes.
  • 1 indicates that the fragment size is 256 bytes.
  • 2 indicates that the fragment size is 512 bytes.
  • 3 indicates that packets are not fragmented.

Views

MP-group interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To improve bandwidth usage on an MP link, configure MP fragmentation and set a proper size for MP packet fragments.

Example

# Set the size of MP packet fragments to 512 bytes on MP-Group 0/0/1.
<HUAWEI> system-view
[HUAWEI] interface mp-group 0/0/1
[HUAWEI-Mp-group0/0/1] fragment-threshold 2
