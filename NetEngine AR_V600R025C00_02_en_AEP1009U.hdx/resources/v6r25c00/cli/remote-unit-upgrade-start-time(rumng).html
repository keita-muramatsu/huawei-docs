upgrade start-time

Function

The upgrade start-time command configures an RU to restart with firmware of the new version at a specified time.

The undo upgrade start-time command disables an RU from restarting with firmware of the new version at a specified time.

By default, no time is configured for upgrading the firmware of a remote module.

Format

upgrade start-time startTime

undo upgrade start-time

Parameters

Parameter Description Value
startTime

Specifies the date when RUs restart with firmware of the new version.

The value is in the format of HH:MM:SS. HH:MM:SS indicates the hour:minute:second.

The value of HH ranges from 0 to 23; the value of MM and SS ranges from 0 to 59.

Views

remote-unit view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After you run this command, RUs restart at the specified time and then upgrade their firmware. The firmware upgrade of an RU consists of two steps:

  1. The RU loads firmware of the new version. In this step, the central device sends the firmware package of the new version to the RU.
  2. The RU restarts to make firmware of the new version take effect.

    This command configures the restart time in Step 2.

Precautions

If an RU is connected to another central switch before restarting to use the firmware of the new version, the RU may be upgraded to the expected version one day later. In this case, you are advised to manually check the upgrade.

Example

# Configure RUs to restart with firmware of the new version at midnight.
<HUAWEI> system-view
[HUAWEI] remote-unit
[HUAWEI-remote-unit] upgrade start-time 00:00:00
