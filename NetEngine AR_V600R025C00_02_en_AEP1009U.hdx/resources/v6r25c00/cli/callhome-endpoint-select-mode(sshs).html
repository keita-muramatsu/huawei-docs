work-endpoint select-mode

Function

The work-endpoint select-mode command configures a NETCONF connection instance selection mode.

The undo work-endpoint select-mode command restores the default NETCONF connection instance selection mode.

By default, a NETCONF connection instance uses the default mode. That is, NETCONF connection instances are selected in the order in which they are created.

Format

work-endpoint select-mode selectMode

undo work-endpoint select-mode

Parameters

Parameter Description Value
selectMode

Specifies a NETCONF connection instance selection mode.

Enumerated type. The values are as follows:

  • default: default mode.
  • priority: priority mode.

Views

Callhome template view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

  • When configuring proactive NETCONF registration, run the endpoint command to create a NETCONF connection instance. You can configure one or more NETCONF connection instances.
  • To select NETCONF connection instances in a specified priority order to establish a NETCONF connection, you can run this command to set the NETCONF connection instance selection mode to priority. In this way, the device first initiates a connection with the instance with the highest priority. If the connection with the instance with the highest priority fails, the device attempts to establish a connection with the instance with the second highest priority, and so on. If the current connection is not of the highest priority, the device continuously attempts to establish a connection with an instance with a higher priority.
  • Priorities are in the sequence of high > medium > low. If NETCONF connection instances have the same priority, they are selected based on VPN names, then IP addresses, and finally port numbers.
    • Priorities of VPN names: A public VPN has a higher priority than a private VPN. The priorities of private VPNs are sorted in the lexicographic order (ASCII code) of VPN names.
    • Priorities of IP addresses: An IPv4 address has a higher priority than an IPv6 address. IP addresses of the same type are sorted in ascending order.
    • Priorities of port numbers: Port numbers are sorted in ascending order.

Follow-up Procedure

  • You can run the link-detect interval command to configure a link detection interval.
  • You can run the priority command in the NETCONF connection instance view to configure a priority for the NETCONF connection instance.

Precautions

  • In priority mode, if a NETCONF connection is established and there is a NETCONF connection instance with a higher priority than the current one, the device disconnects the current connection and establishes a connection with the NETCONF connection instance with a higher priority.
  • If a priority is configured for any NETCONF connection instance, the NETCONF connection instance selection mode cannot be set to default.

Example

# Set the NETCONF connection instance selection mode to priority mode.
<HUAWEI> system-view
[HUAWEI] netconf
[HUAWEI-netconf] callhome root
[HUAWEI-netconf-callhome-root] work-endpoint select-mode priority
