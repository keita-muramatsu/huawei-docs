nd trust port (VAP profile view)

Function

The nd trust port command enables the ND trusted interface on an AP.

The undo nd trust port command disables the ND trusted interface on an AP.

By default, the ND trusted port is disabled on an AP in the VAP profile view.

Format

nd trust port

undo nd trust port

Parameters

None

Views

VAP profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If a bogus ND server exists at the user side, STAs may be unable to communicate due to obtaining incorrect IPv6 addresses or incorrect network parameters. After the undo nd trust port command is executed in the VAP profile view, an AP discards the ND OFFER, ACK, and NAK packets sent by the bogus ND server and reports to the AC about the IPv6 address of the unauthorized ND server.

Prerequisites

The function of processing STA IPv6 services has been enabled using the sta-ipv6-service enable command.

Before enabling the ND trusted interface on an AP, ensure that STA IPv6 address learning has been disabled using the learn-client-address ipv6 disable command.

Example

# Enable the ND trusted interface in the VAP profile.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] vap-profile name abc
[HUAWEI-wlan-vap-prof-abc] nd trust port
