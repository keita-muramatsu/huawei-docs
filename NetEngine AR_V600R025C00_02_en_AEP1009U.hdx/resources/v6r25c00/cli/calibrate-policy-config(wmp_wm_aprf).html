calibrate policy

Function

The calibrate policy command creates a radio calibration policy.

The undo calibrate policy command deletes a radio calibration policy.

By default, no radio calibration policy is created.

Format

calibrate policy non-wifi

undo calibrate policy non-wifi

Parameters

Parameter Description Value
non-wifi

Sets the radio calibration policy to non-Wi-Fi.

-

Views

WLAN view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The non-Wi-Fi radio calibration policy is supported. When non-Wi-Fi interference occurs on a network, the device immediately takes actions to avoid interference.

To exclude interference of rogue neighbors from radio calibration, run the calibrate reference rogue-ap-interference disable command.

Radio calibration triggers channel changes, during which some STAs may go offline and then go online again. In this case, to ensure service experience, it is recommended that radio calibration be performed when no service is running and policies that frequently trigger radio calibration be disabled. To check such policies, run the display channel switch-record calibrate command.

Precautions

The non-Wi-Fi policy is supported only by APs that support spectrum analysis.

Example

# Set the radio calibration policy to non-wifi.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] calibrate policy non-wifi
