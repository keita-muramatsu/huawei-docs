display health report

Function

The display health report command displays the device health diagnosis report provided by EVA.

Format

display health report

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

The running status of a device is affected by multiple factors. EVA collects and analyzes data such as alarms to evaluate the health status of hardware modules (such as interfaces, fans, and power supplies), resource usage (such as CPU usage and memory usage), and networks (such as packet loss), so as to determine the overall health status of the device.

EVA uses health levels to measure the health status of a device. There are three health levels:

  • Health: No fault or exception occurs on the device.
  • Subhealth: The device may have some faults or exceptions.
  • Fault: The device has faults or exceptions.

EVA automatically enables the health diagnosis function to evaluate the health status of a device in real time. You can run the display health report command to view the device health diagnosis report provided by EVA.
