display access-user authentication-mode

Function

The display access-user authentication-mode command displays information about users using a specified authentication mode.

Format

display access-user authentication-mode { ad | ldap | hwtacacs | radius | local | all | none }

Parameters

Parameter Description Value
ad

Displays information about AD authentication users.

-
ldap

Displays information about LDAP authentication users.

-
hwtacacs

Displays information about HWTACACS authentication users.

-
radius

Displays information about RADIUS authentication users.

-
local

Displays information about local authentication users.

-
all

Displays information about all users.

-
none

Displays information about users whose AAA scheme is non-authentication.

-
authentication-mode

Displays information about users using a specified authentication mode.

-

Views

All views

Default Level

3: Management level

Usage Guidelines

Administrators can use this command to view information about users using a specified authentication mode.

Example

The actual command output varies according to the device. The command output here is only an example.
