ip address ppp-negotiate

Function

The ip address ppp-negotiate command enables IP address negotiation on an interface.

The undo ip address ppp-negotiate command disables IP address negotiation on an interface.

By default, IP address negotiation is disabled on interfaces.

Format

ip address ppp-negotiate

undo ip address ppp-negotiate

Parameters

None

Views

Dialer interface view, MP-group interface view, POS interface view, Serial interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To enable IP address negotiation on an interface, run the ip address ppp-negotiate command. This command applies only to PPP-encapsulated interfaces. After IP address negotiation is enabled on an interface, the access server can assign an IP address to the interface.

Prerequisites

An IP address to be assigned to the client has been specified on the server.

Configuration Impact

After IP address negotiation is enabled on an interface, you do not need to configure an IP address for the interface, and the interface can obtain an IP address through negotiation. In addition, you cannot configure a secondary IP address for the interface.

Precautions

When configuring IP address negotiation on an interface, note the following:

  • If the interface has been assigned an IP address, the IP address is deleted.
  • PPP supports IP address negotiation. Therefore, enable IP address negotiation on an interface only when the interface is encapsulated with PPP. When the PPP protocol status goes Down, the IP address obtained through negotiation is deleted.
  • If you configure IP address negotiation on an interface that already has IP address negotiation configured, the IP address obtained through the original negotiation is deleted and a new IP address is obtained through negotiation.
  • After the IP address obtained through negotiation is deleted, the interface is addressless.

Example

# Enable IP address negotiation on MP-Group 0/0/1. 
<HUAWEI> system-view
[HUAWEI] interface mp-group 0/0/1
[HUAWEI-Mp-group0/0/1] ip address ppp-negotiate
