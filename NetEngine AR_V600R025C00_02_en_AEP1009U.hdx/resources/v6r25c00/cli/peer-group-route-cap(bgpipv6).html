peer label-route-capability (BGP-IPv6 unicast address family view) (group)

Function

The peer label-route-capability command enables the function of sending or receiving labeled routes.

The undo peer label-route-capability command restores the default configuration.

By default, the function of sending or receiving labeled routes is disabled.

Format

peer group-name label-route-capability

undo peer group-name label-route-capability

Parameters

Parameter Description Value
group-name

Specifies the name of a peer group.

The name is a string of 1 to 47 case-sensitive characters, with spaces not supported. When double quotation marks are used around the string, spaces are allowed in the string.

Views

BGP-IPv6 unicast address family view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

This command applies to 6PE scenarios where labeled IPv6 routes need to be exchanged with a specified peer group.

  • In a 6PE scenario, after the peer label-route-capability command is run, peers negotiate the label capability and unicast capability and advertise labeled routes.
  • In a 6PE scenario, if peers do not need to negotiate the unicast capability, run the peer label-route-capability-only command to enable the peers to negotiate only the label capability and advertise labeled routes only to a specified peer group.

Prerequisites

The peer as-number command has been run to establish a peer relationship with the peer group.

Configuration Impact

If the peer label-route-capability command is run multiple times, the latest configuration overwrites the previous one.

Precautions

When the device is enabled to send labeled routes to a specified peer group or disabled from sending labeled routes to a specified peer group, the BGP connections with the peer group are automatically disconnected, the peer capability is renegotiated, and then the BGP connections are automatically re-established.

The peer label-route-capability and peer prefix-sid commands are mutually exclusive.

Example

# Enable the device to send labeled routes to a BGP peer group named test.
<HUAWEI> system-view
[HUAWEI] bgp 100
[HUAWEI-bgp] group test internal
[HUAWEI-bgp] ipv6-family unicast
[HUAWEI-bgp-af-ipv6] peer test enable
[HUAWEI-bgp-af-ipv6] peer test label-route-capability
