password alert original (Local administrator password policy view)

Function

The password alert original command enables the device to prompt users to change the initial passwords.

The undo password alert original command disables the device from prompting users to change the initial passwords.

By default, the function of prompting users to change the initial passwords is enabled.

Format

password alert original

undo password alert original

Parameters

None

Views

Local administrator password policy view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

For security purposes, enable the function of prompting users to change the initial passwords. When a user logs in to a device with this function enabled:

  • If the login password of the user is the initial password, the device displays a message asking the user whether to change the password and then performs operations based on the user's selection.
  • If the user selects Y, the user needs to enter the old password, and then enter a new password and confirm it. The password can be successfully changed only when the old password is correct, the new password meets the password length and complexity requirements, and the new password and the confirm password are the same. After the password is changed, the user can log in to the device successfully.
  • If the user selects N or fails to change the password, the device does not allow the user to log in.
  • If the login password entered by the user is not the initial password, the device does not display any message and the user can successfully log in to the device.

    After the undo password alert original command is run, the function of prompting users to change the initial passwords does not take effect, which poses security risks.

Precautions

This function takes effect only for Telnet users, HTTP users, SSH users, and terminal users.

Some clients do not support password change upon the first login. As a result, the login fails. In this case, you need to disable this function. To disable this function only for specific administrators, run the local-user password-force-change disable command.

Example

# Enable the function of prompting users to change the initial passwords. 
<HUAWEI> system-view
[HUAWEI] aaa
[HUAWEI-aaa] local-aaa-user password policy administrator
[HUAWEI-aaa-lupp-admin] password alert original
