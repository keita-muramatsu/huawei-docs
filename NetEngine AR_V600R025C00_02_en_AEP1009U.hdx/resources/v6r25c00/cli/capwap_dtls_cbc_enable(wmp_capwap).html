capwap dtls cbc enable

Function

The capwap dtls cbc enable command enables a CAPWAP DTLS server to establish a DTLS session with a DTLS client running an earlier version using the CBC cipher suite.

The undo capwap dtls cbc enable command disables a CAPWAP DTLS server from establishing a DTLS session with a DTLS client running an earlier version using the CBC cipher suite.

By default, CAPWAP DTLS compatibility with the CBC cipher suite is disabled.

Format

capwap dtls cbc enable

undo capwap dtls cbc enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In versions earlier than V200R021C00, CAPWAP clients support only the DTLS CBC encryption suite, which poses security risks. To establish CAPWAP DTLS sessions with these clients, run this command to enable compatibility with earlier versions.

Precautions

This function can be used only after the weak security algorithm/protocol feature package (WEAKEA) is installed. To load the package, run the install feature-software WEAKEA command.

After this function is enabled, the TLS1_TXT_PSK_WITH_AES_256_CBC_SHA cipher suite is used to set up DTLS sessions with CAPWAP DTLS clients running versions earlier than V200R021C00, which poses security risks.

After this function is disabled, CAPWAP links established based on earlier DTLS versions are disconnected, which may interrupt services.

This function is not supported in FIPS mode.

Example

# Enable CAPWAP DTLS compatibility with the CBC cipher suite.
<HUAWEI> install feature-software WEAKEA
<HUAWEI> system-view
[HUAWEI] capwap dtls cbc enable
