display srv6-te policy last-down-reason

Function

The display srv6-te policy last-down-reason command displays records about events where SRv6 TE Policies or segment lists in SRv6 TE Policies go down.

Format

display srv6-te policy last-down-reason [ endpoint endpoint-ip color color-value | policy-name name-value | binding-sid binding-sid ]

display srv6-te policy last-down-reason brief

Parameters

Parameter Description Value
endpoint endpoint-ip

Specifies the endpoint of an SRv6 TE Policy.

The value is a 32-digit hexadecimal string in format X:X:X:X:X:X:X:X.
color color-value

Specifies a color value for an SRv6 TE Policy.

The value is an integer ranging from 0 to 4294967295.
policy-name name-value

Specifies the name of an SRv6 TE Policy.

The value is a string of 1 to 255 case-sensitive characters. If the string is enclosed in double quotation marks ("), spaces are allowed in the string.
binding-sid binding-sid

Specifies a binding SID.

The value is a 32-digit hexadecimal string in format X:X:X:X:X:X:X:X.
brief

Displays brief information of records about events where SRv6 TE Policies or segment lists in SRv6 TE Policies go down.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

The display srv6-te policy last-down-reason command displays records about events where SRv6 TE Policies or segment lists in SRv6 TE Policies go down. The command output helps locate faults.

The display srv6-te policy last-down-reason brief command displays brief information of records about events where SRv6 TE Policies or segment lists in SRv6 TE Policies go down. The command output helps locate faults.

You can view a maximum of 50000 segment list down records and a maximum of 256 segment list down records of each SRv6 TE Policy.

Table 1 Description of the display srv6-te policy last-down-reason command output
Item Description
Policy Name

Name of an SRv6 TE Policy.
Color

Color value of an SRv6 TE Policy.
Endpoint

Destination address of an SRv6 TE Policy.
TunnelId

Tunnel ID of an SRv6 TE Policy.
Up Time

Time when an SRv6 TE Policy went up. The following information shows the time when the segment list went up.
Down Time

Time when an SRv6 TE Policy went down. The following information shows the time when the segment list went down.
Down Reason

The first Down Reason field displays the reason why the SRv6 TE Policy goes Down. The options are as follows:

  • Admin Down (Administratively Down).
  • No Active Path (No valid candidate path exists, or no segment list exists under the candidate path.).
  • Token Overrun (Forwarding resource threshold-crossing).

The second Down Reason field displays the reason why the segment list goes Down. The value in parentheses indicates the first SID that is detected Down in the segment list. The options are as follows:

  • Delete (The segment list is deleted.).
  • SID Unreachable (If the fault detection status of the segment list is Down, the first SID that is detected Down in the segment list is marked.).
  • Token Overrun (Forwarding resource threshold-crossing).
  • Path Deactive (The candidate path is not preferred.).
  • BFD Detect Down (BFD fails.).
  • Weight Invalid (An invalid weight value is configured for the segment list.).
Segment-List ID

ID of the segment list referenced by an SRv6 TE Policy's candidate path.
Segment-List Name

Name of the segment list referenced by an SRv6 TE Policy's candidate path. If no segment list is referenced, this field is empty.
Segment-List

SID stack of the segment list referenced by an SRv6 TE Policy's candidate path.
Preference

Preference of an SRv6 TE Policy's candidate path.
Discriminator

ID of an SRv6 TE Policy's candidate path.
Network Slice ID

Effective network slice ID of the segment list of an SRv6 TE Policy's candidate path.
PMTU

MTU of the segment list of an SRv6 TE Policy's candidate path.
Binding SID

Binding SID of an SRv6 TE Policy.
Weight

Load balancing weight of a segment list.
