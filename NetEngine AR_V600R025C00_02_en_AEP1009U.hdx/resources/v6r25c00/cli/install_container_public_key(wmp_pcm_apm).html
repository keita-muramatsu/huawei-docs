install container public-key

Function

The install container public-key command imports a container public key to an AP.

The undo install container public-key command cancels the import of a container public key on an AP.

Format

install container public-key { ap-id ap-id | ap-group ap-group | all } public-key public-key-name fingerprint fingerprint-key

undo install container public-key { ap-id ap-id | ap-group ap-group | all }

Parameters

Parameter Description Value
ap-id ap-id

Specifies an AP ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
ap-group ap-group

Specifies an AP group.

The value is a string of 1 to 35 case-sensitive characters.
all

Indicates all APs.

-
public-key public-key-name

Specifies the name of a public key.

The value is a string of 1 to 35 case-sensitive characters without spaces.
fingerprint fingerprint-key

Specifies a fingerprint key.

The value is a string of 1 to 63 case-sensitive characters. It cannot contain spaces.

Views

WLAN view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

For the description file and application configuration file of an image software package, public keys must be installed for signature verification.

Prerequisites

  1. A container image file and a public key file have been provided by Huawei's partners.
  2. A file download server has been configured using the ap file-transfer command.

Precautions

The public key files of different vendors are different. Only one public key file can be imported to an AP.

Example

# Import a public key to a container.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] install container public-key ap-id 1 public-key 4.txt fingerprint 1652C1AA2AC09172521572E7F359D9A17DE5BFD5
Info: Operating, please wait for a moment......done.
# Cancel the import of a container public key.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] undo install container public-key  ap-id 1
Info: Operating, please wait for a moment......done.
Info: The import of public key is canceled successfully.
