display mpls ldp peer

Function

The display mpls ldp peer command displays information about LDP peers.

Format

display mpls ldp peer [ all ]

display mpls ldp peer { verbose | peer-id }

display mpls ldp peer all verbose

Parameters

Parameter Description Value
all

Displays information about all LDP peers.

-
verbose

Displays details about LDP peers.

-
peer-id

Displays information about a specified LDP peer. The parameter is defined by using the mpls lsr-id command.

The value is in dotted decimal notation.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

If an LDP LSP fails to be established between local and remote interfaces, run the display mpls ldp peer command to check the interface status from the DiscoverySource field.

You can also run the display mpls ldp peer command to view information about packets sent by the peer.

The system supports coexistent local and remote LDP peers. The display mpls ldp peer command also displays information about local and remote LDP peers.

You can specify a parameter to view information about a specified LDP peer.

Prerequisites

MPLS and MPLS LDP have been enabled globally using the mpls ldp command in the system view.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display information about LDP peers.
<HUAWEI> display mpls ldp peer
LDP Peer Information in Public network
 An asterisk (*) before a peer means the peer is being deleted.
 -------------------------------------------------------------------------------
 PeerID                 TransportAddress               DiscoverySource
 -------------------------------------------------------------------------------
 10.1.1.2:0              10.1.1.2                        10GE0/0/0
 10.1.2.1:0              10.1.2.1                        Remote Peer : RTC
 -------------------------------------------------------------------------------
 TOTAL: 2 Peer(s) Found.
# Display detailed information about LDP peers.
<HUAWEI> display mpls ldp peer verbose

Table 1 Description of the display mpls ldp peer command output
Item Description
Peer LDP ID

Value of an LDP identifier in the form of LSR ID:Label space. The label space value can be:

  • 0: per-platform label space.
  • Non-0: per-interface label space.
Peer Max PDU Length

Maximum PDU length of an LDP peer.
Peer Transport Address

Transport address of an LDP peer for initiating a TCP connection for an LDP session.
Peer Loop Detection

Whether loop detection negotiation of an LDP peer is enabled:

  • On: Loop detection negotiation is enabled.
  • Off: Loop detection negotiation is disabled.
Peer Path Vector Limit

Upper limit of the Path Vector for an LDP peer.

The value of this field is not empty only when the value of Peer Loop Detection is On.
Peer FT Flag

GR FT flag of an LDP peer, which can be set only after an Initialization message containing an FT TLV is received:

  • On: LDP GR is enabled.
  • Off: LDP GR is disabled.
Peer Keepalive Timer

Configured value of the Keepalive timer for an LDP peer.
Peer Type

Type of an LDP peer:

  • Local.
  • Remote.
  • Local&Remote.
Peer Label Advertisement Mode

Label advertisement mode of an LDP peer:

  • Downstream Unsolicited.
  • Downstream On Demand.
Peer Discovery Source

Discovery source of an LDP peer:

  • Interface name: the source that discovers the local LDP peer.
  • Remote LDP peer name: the source that discovers the remote LDP peer.
PeerID

Value of an LDP identifier in the form of LSR ID:Label space. The label space value can be:

  • 0: per-platform label space.
  • Non-0: per-interface label space.
TransportAddress

Transport address of an LDP peer for initiating a TCP connection for an LDP session.
DiscoverySource

Discovery source of an LDP peer:

  • Interface name: the source that discovers the local LDP peer.
  • Remote LDP peer name: the source that discovers the remote LDP peer.
Recovery Timer

Recovery time of an LDP peer.

The value of this field is not null only when LDP GR is enabled, that is, the value of Peer FT Flag is On.
Reconnect Timer

Timeout period of the Reconnect timer for an LDP peer.

The value of this field is not null only when LDP GR is enabled, that is, the value of Peer FT Flag is On.
Distributed ID

ID of an LDP distributed instance.
