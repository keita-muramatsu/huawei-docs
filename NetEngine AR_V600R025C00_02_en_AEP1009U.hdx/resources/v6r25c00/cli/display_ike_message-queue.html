display ike message-queue

Function

The display ike message-queue command displays the statistics of the IKE process queue.

Format

display ike message-queue [ slot slot-id cpu cpu-id ]

Parameters

Parameter Description Value
slot slot-id

Specifies a slot ID.

The value varies depending on device models.
cpu cpu-id

Specifies the CPU ID.

The value varies depending on device models.

Views

User view

Default Level

1: Monitoring level

Usage Guidelines

The display ike message-queue command displays the statistics of the IKE process queue.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display statistics about messages of IKE process queue.
