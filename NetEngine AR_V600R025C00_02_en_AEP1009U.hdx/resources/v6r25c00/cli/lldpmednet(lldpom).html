lldp tlv-enable med-tlv network-policy

Function

The lldp tlv-enable med-tlv network-policy command configures MED Network Policy TLV that can be advertised by an interface.

The undo lldp tlv-enable med-tlv network-policy command configures MED Network Policy TLV that cannot be advertised by an interface.

Although the interface does not advertise MED Network Policy TLV, MED Network Policy TLV is still enabled by default.

Format

lldp tlv-enable med-tlv network-policy

lldp tlv-enable med-tlv network-policy voice-vlan vlan vlan-id { [ cos medCos ] | [ dscp medDscp ] } *

lldp tlv-enable med-tlv network-policy voice-vlan untagged

lldp tlv-enable med-tlv network-policy voice-vlan 8021p { [ cos medCos ] | [ dscp medDscp ] } *

undo lldp tlv-enable med-tlv network-policy

undo lldp tlv-enable med-tlv network-policy voice-vlan vlan vlan-id { [ cos medCos ] | [ dscp medDscp ] } *

undo lldp tlv-enable med-tlv network-policy voice-vlan { { vlan [ vlan-id ] } | { cos [ medCos ] } | { dscp [ medDscp ] } }

undo lldp tlv-enable med-tlv network-policy voice-vlan untagged

undo lldp tlv-enable med-tlv network-policy voice-vlan 8021p { [ cos medCos ] | [ dscp medDscp ] } *

Parameters

Parameter Description Value
network-policy

Advertises MED Network Policy TLV.

-
voice-vlan

Encapsulates the voice VLAN ID when advertising Network Policy TLV.

-
vlan vlan-id

Specifies the VLAN ID of Voice VLAN.

The value is an integer in the range from 1 to 4094.
cos medCos

Specifies the CoS priority.

The CoS priority is the PRI (Priority) field in an 802.1Q VLAN frame. This field is 3 bits long and ensures that high-priority data packets are forwarded first when congestion occurs.

The value is an integer ranging from 0 to 7. The default value is 5. A larger value indicates a higher priority.
dscp medDscp

Specifies the DSCP priority.

The DSCP value is indicated by the 6 bits in the ToS field in the IPv4 packet header. DSCP is used in the DiffServ model to provide QoS guarantee on an IP network. The operations performed by the traffic controller on the gateway are determined only by these six bits.

The value is an integer ranging from 0 to 63. The default value is 46.
untagged

Configures voice devices to send untagged voice data packets.

-
8021p

Configure the voice traffic sent by the terminal to carry the 802.1p priority VLAN.

-

Usage Guidelines

Usage Scenario

A TLV is the basic information unit of an LLDPDU. In a TLV, T indicates the information type, L indicates the information length, and V indicates the value or the content to be sent. A device encapsulates information about its main capabilities, management address, device ID, and interface ID into TLVs, encapsulates multiple TLVs into an LLDPDU, and encapsulates an LLDPDU into an LLDP packet. A device exchanges information with neighbors using LLDP packets. During the process of exchanging LLDP packets between devices, the LLDPDU encapsulated in an LLDP packet carries various TLVs as needed. A device sends its status information and receives neighbor status information based on these different TLVs.

TLVs that can be encapsulated into an LLDPDU include basic TLVs, TLVs defined by IEEE 802.1, TLVs defined by IEEE 802.3, and MED TLVs.

  • Basic TLVs implement basic LLDP functions. In addition to optional management-address, port-description, system-capability, system-description, and system-name TLVs, basic TLVs include four mandatory TLVs that must be encapsulated into an LLDPDU to be advertised.
  • TLVs defined by IEEE 802.1, TLVs defined by IEEE 802.3, and MED TLVs are optional TLVs used to enhance the LLDP function. Determine whether to encapsulate these TLVs into LLDPDUs for advertisement as needed.

Prerequisites

  1. LLDP has been enabled globally using the lldp enable command in the system view.
  2. LLDP has been enabled on the interface using the undo lldp disable command in the interface view.
  3. The MED Capabilities TLV has been enabled on the interface using the lldp tlv-enable med-tlv capability command in the interface view.

Precautions

  • You can specify the MED Network Policy TLV only after specifying the MED Capabilities TLV. To disable the MED Capabilities TLV, first disable the MED Network Policy TLV.
  • You can specify the MED Network Policy TLV only on a Layer 2 interface.

Example

# Configure 10GE 0/0/2 to advertise the MED Network Policy TLV. 
<HUAWEI> system-view
[HUAWEI] lldp enable
[HUAWEI] interface 10GE 0/0/2
[HUAWEI-10GE0/0/2] lldp tlv-enable med-tlv capability
[HUAWEI-10GE0/0/2] lldp tlv-enable med-tlv network-policy
