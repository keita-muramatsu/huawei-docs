ospf cost

Function

The ospf cost command sets a cost for an OSPF interface.

The undo ospf cost command restores the default cost.

By default, the cost of an OSPF interface is calculated using the following formula: Interface cost = Bandwidth reference value/Interface bandwidth, in which the bandwidth reference value can be changed using the bandwidth-reference command.

Format

ospf cost value

undo ospf cost

Parameters

Parameter Description Value
value

Specifies the cost of an OSPF interface.

The value is an integer ranging from 1 to 65535.

Views

10GE sub-interface view, 10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE interface view, Cellular channel interface view, Dialer interface view, Eth-Trunk interface view, Ethernet interface view, GE optical interface view, GE sub-interface view, GE electrical interface view, IP-Trunk interface view, Loopback interface view, MP-group interface view, Multi-GE sub-interface view, Multi-GE interface view, POS interface view, Tunnel interface view, 40GE sub-interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

OSPF can automatically calculate the link cost for an interface based on the bandwidth of the interface. You can also set a link cost for the interface using the ospf cost command. When there are multiple routes with the same discovery protocol, cost, and destination address, these routes meet the conditions for load balancing. You can determine whether to perform load balancing by changing the interface cost based on networking requirements.

If no cost is set for an OSPF interface using the ospf cost command, OSPF automatically calculates a cost for the interface based on the interface bandwidth. It is calculated as follows: Interface cost = Bandwidth reference value/Interface bandwidth. The resulting integer is used as the interface cost. If the result is smaller than 1, the cost is 1. Changing the bandwidth reference value can change the interface cost.

By default, the bandwidth reference value in OSPF is 100 Mbit/s. With the formula 100000000/Bandwidth, the default cost of an Ethernet (100 Mbit/s) interface is 1. The bandwidth of a trunk interface is the sum of all member interfaces, and the member interfaces are variable. Therefore, the trunk interface does not have a default interface cost.

OSPF supports co-existence of multiple cost association configurations. The cost of an interface is determined according to the following rules:

  1. If the stub device is configured to advertise the maximum cost in a process, ldp-sync is configured in the area, or neighbor relationship flapping suppression or the peer hold-max-cost function takes effect, the cost value is MAX-COST. (The MAX-COST value can be configured using the maximum-link-cost command. If MAX-COST is not configured, the default value 65535 is used.)
  2. (1) If no interface cost is configured, the cost-base value is the auto-cost calculated based on the bandwidth by default. If an interface cost is configured, the cost-base value is the configured cost value.

    (2) On the preceding basis, if BFD is associated with the cost, the cost is changed to the sum of the cost-base and incr-cost. The sum cannot exceed 65535.

Precautions

The ospf cost command cannot run on null interfaces.

Example

# Set the cost of an interface that runs OSPF to 65. 
<HUAWEI> system-view
[HUAWEI] interface 10GE0/0/0
[HUAWEI-10GE0/0/0] undo portswitch
[HUAWEI-10GE0/0/0] ospf cost 65
