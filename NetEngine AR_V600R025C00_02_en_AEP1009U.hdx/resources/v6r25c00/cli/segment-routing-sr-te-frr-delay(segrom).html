sr-te frr delay

Function

The sr-te frr delay command configures a TE FRR delay.

The undo sr-te frr delay command restores the default configuration.

By default, TE FRR is not delayed.

Format

sr-te frr delay delay-time

undo sr-te frr delay [ delay-time ]

Parameters

Parameter Description Value
delay-time

Specifies a TE-FRR delay.

The value is an integer ranging from 1 to 600000, in milliseconds.

Views

Segment routing IPv6 view

Default Level

2: Configuration level

Usage Guidelines

The sr-te frr delay command configures a TE FRR delay. During this period, you can run this command to prevent packet loss caused by traffic forwarding based on the local End.X SID. This means that the device skips the current label and attempts to use the next label to guide traffic forwarding. This command applies to the following scenarios:

  1. The outbound interface associated with the local static End.X SID is Down, and the TE FRR flag is set.
  2. When the status of the outbound interface associated with the local static End.X SID changes from Down to Up and a TE FRR delay is configured, the TE FRR flag is set during the delay. After the delay expires, the TE FRR flag is deleted.
  3. When a dynamic End.X SID is generated and a TE FRR delay is configured, the TE FRR flag is set during the delay. After the delay expires, the TE FRR flag is deleted.
  4. When a new direct locator route is generated, the TE FRR flag is set during the delay. When the delay expires, the TE FRR flag is deleted.

Example

# Configure a TE FRR delay.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] sr-te frr delay 1000
