saas-network-assessment delay-baseline

Function

The saas-network-assessment delay-baseline command configures the base delay value in SaaS traffic steering evaluation parameters.

The undo saas-network-assessment delay-baseline command restores the default base delay value in SaaS traffic steering evaluation parameters.

By default, the delay base value in SaaS traffic steering evaluation parameters is 100 ms.

Format

saas-network-assessment delay-baseline value

undo saas-network-assessment delay-baseline [ value ]

Parameters

Parameter Description Value
delay-baseline value

Specifies the base delay value (ms) in SaaS traffic steering evaluation parameters.

The value is an integer ranging from 1 to 1000. The default value is 100.

Views

saas-cloud-express view

Default Level

2: Configuration level

Usage Guidelines

By default, qualified links are selected for SaaS application access. During link evaluation, the QoE score of a link is calculated based on the packet loss rate base value, delay base value, packet loss rate weight, and NQA link detection result.

Example

# Set the base delay value in SaaS traffic steering evaluation parameters to 90 ms.
<HUAWEI> system-view
[HUAWEI] saas-cloud-express
[HUAWEI-saas-cloud-express] saas-network-assessment delay-baseline 90
