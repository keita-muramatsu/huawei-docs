radio-mode

Function

The radio-mode command sets the radio working mode of an AP.

The undo radio-mode command restores the default radio working mode of an AP.

By default, no radio mode is configured on an AP, and the AP uses the default radio mode.

Format

radio-mode { 2radio-standard | 2radio-2g-enhanced | 2radio-5g-enhanced | 2radio-independent-scan | 3radio | 4radio | 4radio-independent-scan | 5radio }

undo radio-mode

Parameters

Parameter Description Value
2radio-standard

Specifies the standard dual-radio mode.

-
2radio-2g-enhanced

Specifies the 2G enhanced dual-radio mode.

The 2G radio in this mode provides a larger capacity than that in standard dual-radio mode.

-
2radio-5g-enhanced

Specifies the 5G enhanced dual-radio mode.

The 5G radio in this mode provides a larger capacity than that in standard dual-radio mode.

-
2radio-independent-scan

Specifies the dual-radio+independent scanning radio mode.

-
3radio

Specifies the triple-radio mode.

Ensure that the third radio of the AP has WLAN service configuration. Otherwise, this radio fails to work.

-
4radio

Specifies the quad-radio mode.

-
4radio-independent-scan

Specifies the quad-radio + independent scanning mode.

-
5radio

Specifies the penta-radio mode.

-

Views

AP system profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The radio-mode command sets the radio mode of an AP. Radio modes supported by APs vary depending on AP models. To check the radio modes supported by a specified AP model, run the display ap-type command and check the Radio mode field in the command output. If an AP does not support the configured radio mode, it works in the default radio mode.

  • In high-bandwidth scenarios, you are advised to use the 2radio-standard (2.4 GHz + 5 GHz) or 3radio (2.4 GHz + 5 GHz + 6 GHz) mode based on the frequency bands supported by the device model and local laws and regulations. In this mode, the AP can provide ultra-high throughput.

  • In high-concurrency scenarios, you are advised to use the 3radio, 4radio, or 5radio mode with dual 5 GHz or 6 GHz radios based on the frequency bands supported by the device model and local laws and regulations. In this mode, the AP allows for access of more STAs, improving the WLAN capacity.

  • In strong-interference scenarios, you are advised to use the 2radio-independent-scan or 4radio-independent-scan mode. In this mode, an AP can use an independent radio to scan the air interface without affecting performance, facilitating WLAN quality monitoring and optimization in real time.

  • Switching the radio mode of an AP will cause the AP to restart.

  • For an AirEngine 6760-X1 or AirEngine 6760-X1E, load the RTU license to switch to the triple-radio mode or dual-radio + independent scanning mode. For an AirEngine 5760-51, load the RTU license to switch to the dual-radio + independent scanning mode.

  • The independent radio scanning function applies only to the 5 GHz radios of the AirEngine 8760-X1-PRO, AirEngine 8760R-X1, AirEngine 8760R-X1E, AirEngine 6760-X1, AirEngine 6760-X1E, and AirEngine 5760-51. The radio scanning function on the 2.4 GHz frequency band can be implemented only through a service radio. In V200R021C10 and later versions, the independent radio scanning function of the AirEngine 6761-21, AirEngine 6761-21E and AirEngine 6761S-21 is effective for both the 2.4 GHz and 5 GHz frequency bands. (In V200R021C00, this function applies only to the 5 GHz frequency band.)

  • The AirEngine 6761-21, AirEngine 6761-21E, and AirEngine 6761S-21 have a dedicated radio for scanning and can perform radio scanning even in 2radio-standard mode.

  • After the radio mode of an AirEngine 6760-51EI is switched to the 2G enhanced dual-radio mode, the 2.4 GHz radio provides four spatial streams and the 5 GHz radio becomes unavailable. After the radio mode is switched to the 5G enhanced dual-radio mode, the 5 GHz radio provides four spatial streams and the 2.4 GHz radio becomes unavailable.

  • The independent radio scanning function of an AirEngine 8776-X7F-T is available only on the 5 GHz frequency band and 6 GHz low-band channels (1 to 93). For other frequency bands or channels, the independent radio scanning function can be implemented only through a service radio.

Precautions

This function is supported only by some AP models. You can visit Info-Finder, search for the target AP model, and search for MIMO Spatial Stream in Specifications Query to learn about the radio mode combinations supported by the AP. Alternatively, you can run the display ap-type command to check the radio modes supported by the AP based on the Radio mode field.

Example

# Set the radio mode of the AP to standard dual-radio mode.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name default
[HUAWEI-wlan-ap-system-prof-default] radio-mode 2radio-standard
Warning: Modifying the radio mode may reset the AP. Continue?[Y/N]y
