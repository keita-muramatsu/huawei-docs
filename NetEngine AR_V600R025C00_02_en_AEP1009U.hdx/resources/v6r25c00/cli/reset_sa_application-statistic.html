reset sa application-statistic

Function

The reset sa application-statistic command deletes statistics on application protocol packets.

Format

reset sa application-statistic { application application-name | all } interface { interface-type interface-number | interface-name }

Parameters

Parameter Description Value
application application-name

Clears statistics on packets of a specified application.

The value is a string of 1 to 32 characters and is case sensitive if it starts with UD_. If the string contains spaces, it must be enclosed in quotation marks.
all

Clear statistics on packets of all application protocols.

-
interface interface-name

Clears statistics on packets on a specified interface. interface-name specifies the interface name.

-
interface interface-type interface-number

Clears application identification statistics on a specified interface.

  • interface-type indicates the interface type.
  • interface-number indicates the interface number.

-

Views

User view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

The display sa application-statistic command displays all the previous statistics on SA application protocol packets. Before recollecting statistics, run the reset sa application-statistic command to delete the original statistics.

Prerequisites

The sa application-statistic enable command is run on an interface to enable application identification statistics function.

Precautions

The cleared packet statistics cannot be restored. Exercise caution when you use the command.

Example

# Delete statistics on packets of all application protocols on 10GE0/0/1.
<HUAWEI> reset sa application-statistic all interface 10GE 0/0/1
