default action

Function

The default action command sets the default action for a URL filtering profile.

The undo default action command sets the default action for a URL filtering profile to allow.

By default, the default action for a URL filtering profile is allow.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

default action { allow | block | alert }

undo default action

Parameters

Parameter Description Value
allow

Sets the default action to allow.

-
block

Sets the default action to block.

-
alert

Sets the default action to alert.

-

Views

URL filtering profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If the URL does not match any rule, the default action takes effect.

If the default action is set to block, the device blocks the request and reports a log when the URL of the request does not match any URL whitelist, URL blacklist, or URL category.

If the default action is set to alert, the device permits the request and reports a log when the URL of the request does not match any URL whitelist, URL blacklist, or URL category.

Precautions

If block or alert is selected, configure the remote query function and activate the remote query license. Otherwise, service traffic may not match any category. As a result, normal services are blocked or a large number of service logs are generated.

After running this command, run the engine configuration commit command to commit the configuration for the configuration to take effect. You are advised to commit the configuration after all content security configurations are complete.

Example

# Set the default action for the URL filtering profile profile_development to block in the URL filtering profile view. 
<HUAWEI> system-view
[HUAWEI] profile type url-filter name profile_development
[HUAWEI-profile-url-filter-profile_development] default action block
