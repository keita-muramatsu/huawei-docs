portal-access-profile (Authentication profile view)

Function

The portal-access-profile command binds a Portal access profile to an authentication profile.

The undo portal-access-profile command unbinds a Portal access profile from an authentication profile.

By default, no Portal access profile is bound to an authentication profile.

Format

portal-access-profile access-profile-name

undo portal-access-profile

Parameters

Parameter Description Value
access-profile-name

Specifies the name of a Portal access profile.

The value is a string of 1 to 31 case-sensitive characters without spaces.

Views

Authentication profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The authentication type used by an authentication profile is determined by the access profile bound to the authentication profile. After an authentication profile is bound to a Portal access profile, Portal authentication is enabled in the authentication profile. After the authentication profile is applied to a VAP profile, Portal authentication can be performed on online users.

Prerequisites

A Portal access profile has been created using the portal-access-profile (system view) command.

Follow-up Procedure

Run the authentication-profile command to apply the authentication profile to a VAP profile.

Precautions

  • An authentication profile can have a maximum of one Portal access profile bound.
  • If VLAN-based authorization for users who are in pre-connection state or fail the authentication has been configured in the authentication profile view, the configuration will not take effect after Portal authentication is configured.
  • This function is mutually exclusive with the authentication no-ip-check command.

Example

# Bind the authentication profile portal_authen_profile1 to the Portal access profile portal_access_profile.
<HUAWEI> system-view
[HUAWEI] web-auth-server webauth1
[HUAWEI-web-auth-server-webauth1] quit
[HUAWEI] portal-access-profile name portal_access_profile
[HUAWEI-portal-access-profile-portal_access_profile] web-auth-server webauth1
[HUAWEI-portal-access-profile-portal_access_profile] quit
[HUAWEI] authentication-profile name portal_authen_profile1
[HUAWEI-authen-profile-portal_authen_profile1] portal-access-profile portal_access_profile
