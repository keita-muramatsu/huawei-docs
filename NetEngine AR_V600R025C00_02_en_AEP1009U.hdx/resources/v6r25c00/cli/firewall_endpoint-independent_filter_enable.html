firewall endpoint-independent filter enable

Function

The firewall endpoint-independent filter enable command enables the endpoint-independent filtering function.

The undo firewall endpoint-independent filter enable command disables the endpoint-independent filtering function.

By default, the endpoint-independent filtering function is enabled.

Format

firewall endpoint-independent filter enable

undo firewall endpoint-independent filter enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

This command takes effect only for 3-tuple NAT.

When the endpoint-independent filtering function is enabled, the device searches for a destination server mapping entry of 3-tuple NAT that matches the packet sent by an Internet user to communicate with an intranet user. If a match is found, the device translates the destination address of the packet based on the matching entry and forwards the packet, without matching the packet against any interzone security policy. If this function is disabled, the device searches for a matching interzone security policy and determines whether to forward or discard the packet accordingly.

You can choose to enable endpoint-independent filtering or configure interzone security policies based on the site requirements.

Example

# Enable the endpoint-independent filtering function.
<HUAWEI> system-view
[HUAWEI] firewall endpoint-independent filter enable
