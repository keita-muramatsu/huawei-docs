display mpls ldp troubleshooting

Function

The display mpls ldp troubleshooting command displays device information when an LDP session is disconnected on a device.

Format

display mpls ldp troubleshooting

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

If an LDP session on a device is disconnected, run the display mpls ldp troubleshooting command to check the device information for troubleshooting.

Example

The actual command output varies according to the device. The command output here is only an example.

<HUAWEI> display mpls ldp troubleshooting

Table 1 Description of the display mpls ldp troubleshooting command output
Item Description
Session Troubleshooting

Troubleshooting information for an LDP session disconnection.
Total counts

Total number of entries.
Sequence

Entry sequence number.
Time

Date and time when the information was recorded.
Event Description

Event description. The parameters in the description are described as follows:

  • CpuUsage: indicates the CPU usage.
  • LocalAddress: indicates the local IP address.
  • PeerAddress: indicates the peer IP address.
  • PingResult: indicates the number of successful ping operations and the number of timeout ping operations.
  • TracertResult: indicates the tracert result, including the TTL of the packet, route path information, and arrival time.
  • Route: indicates route information, including the IGP type, process ID, cost value, next-hop address, session duration, interface, and active/standby status.
