display aaa

Function

The display aaa command displays information about normal logout, abnormal logout, and login failures.

Format

display aaa { offline-record | online-fail-record | abnormal-offline-record } username user-name [ time start-time end-time [ date start-date end-date ] ]

display aaa { offline-record | online-fail-record | abnormal-offline-record } username user-name [ time start-time end-time [ date start-date end-date ] ] brief

display aaa { offline-record | online-fail-record | abnormal-offline-record } access-slot slot-number brief

display aaa { offline-record | online-fail-record | abnormal-offline-record } { all | reverse-order } brief

display aaa { offline-record | online-fail-record | abnormal-offline-record } { ip-address ip-address [ vpn-instance vpn-instance-name ] | ipv6-address ipv6-address } [ brief ]

display aaa { offline-record | online-fail-record | abnormal-offline-record } mac-address mac-address brief

display aaa { offline-record | online-fail-record | abnormal-offline-record } { all | reverse-order | statistics }

display aaa { offline-record | online-fail-record | abnormal-offline-record } time start-time end-time [ date start-date end-date ] brief

display aaa { offline-record | online-fail-record | abnormal-offline-record } time start-time end-time [ date start-date end-date ]

display aaa { offline-record | online-fail-record | abnormal-offline-record } access-slot slot-number

display aaa { offline-record | online-fail-record | abnormal-offline-record } domain domain-name brief

display aaa { offline-record | online-fail-record | abnormal-offline-record } domain domain-name

display aaa { offline-record | online-fail-record | abnormal-offline-record } mac-address mac-address

Parameters

Parameter Description Value
offline-record

Displays normal logout records.

-
online-fail-record

Displays login failure records.

-
abnormal-offline-record

Displays abnormal logout records.

-
username user-name

Displays the records of a specified user.

The value is a string of 1 to 253 case-sensitive characters. It can contain spaces and Chinese characters.
time end-time

Specifies a time range.

The format is HH:MM:SS, indicating hour:minute:second.
start-time

Start time.

The format is HH:MM:SS, indicating hour:minute:second.
date end-date

Specifies a date.

The value is in the format of YYYY/MM/DD. YYYY/MM/DD indicates year/month/day. YYYY ranges from 2000 to 2099, MM ranges from 1 to 12, and DD ranges from 1 to 31.
start-date

Specifies the start date.

The value is in the format of YYYY/MM/DD. YYYY/MM/DD indicates year/month/day. YYYY ranges from 2000 to 2099, MM ranges from 1 to 12, and DD ranges from 1 to 31.
brief

Displays brief records.

-
access-slot slot-number

Specifies the slot ID of an interface board.

The value is an integer. The value range depends on the model of the device.
all

Displays all records.

-
reverse-order

Displays the records in a sequence reverse to the sequence in which they were generated. That is, the latest records are displayed first.

The value is a string of 1 to 253 case-sensitive characters. It can contain spaces and Chinese characters.
ip-address ip-address

Specifies an IP address.

The value is in dotted decimal notation.
vpn-instance vpn-instance-name

Specifies a VPN instance.

The value is a string of 1 to 31 case-sensitive characters. The character string can contain spaces if it is enclosed with double quotation marks (").
ipv6-address ipv6-address

Displays information about the user with a specified IPv6 address.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
mac-address mac-address

Specifies a MAC address.

The value is in H-H-H format. H is a 4-digit hexadecimal number, such as 00e0 and fc01. If an H contains fewer than 4 digits, the left-most digits are padded with zeros. For example, e0 is displayed as 00e0. The MAC address cannot be set to FFFF-FFFF-FFFF.
statistics

Displays statistics.

-
domain domain-name

Specifies the domain name.

The value is a string of 1 to 64 case-insensitive characters, excluding spaces, *, ?, and ".

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

This command allows you to view information about normal user logouts, abnormal logouts, and login failures based on the domain name, interface, IP address, VPN instance, MAC address, or slot ID.

Precautions

If the character string of a user name contains spaces (for example, a b), you can run the display aaa { offline-record | abnormal-offline-record | online-fail-record } username "a b" command to view information about normal user logouts, unexpected user logouts, and user login failures.

If the character string of a user name contains both spaces and double quotation marks (""), the user name cannot be used to view records. In this case, you can run the display aaa { offline-record | abnormal-offline-record | online-fail-record } all brief | include username command to view the IP address or MAC address of the user. Then you can specify the user IP address or MAC address to view information about normal logouts, unexpected logouts, and login failures of the user.
