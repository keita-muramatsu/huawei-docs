if-match app-group

Function

The if-match app-group command creates a matching rule based on a user-defined application group in a traffic classifier.

The undo if-match app-group command deletes a matching rule based on a user-defined application group from a traffic classifier.

By default, no matching rules based on user-defined application groups are configured in a traffic classifier.

Format

if-match app-group app-group-name [ time-range time-name ]

undo if-match app-group app-group-name

Parameters

Parameter Description Value
app-group-name

Specifies the name of a user-defined application group.

The value is a string of 1 to 32 case-sensitive characters, spaces not supported.
time-range time-name

Specifies the time range during which the matching rule takes effect. time-name specifies the name of the time range. If no time range is specified, the configuration takes effect at any time.

The value is a string of 1 to 32 case-sensitive characters, starting with an upper-case or a lower-case letter (A to Z or a to z). It cannot contain spaces. To avoid confusion, do not use the word all as the name of a time range.

Views

Traffic classifier view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

You can run the if-match app-group command to configure a matching rule based on a user-defined application group in a traffic classifier. This ensures that the device processes packets matching the same traffic classifier identically.

You can also add time-range command to define the time range and flexibly configure the time a matching rule takes effect. If the specified time range does not exist, the matching rule does not take effect.

Prerequisites

An application group has been created by running the application-group name command in the system view.

Precautions

  • The if-match app-group command does not support IPv6. The AND mode cannot be used to match IPv6 rules.
  • This function takes effect only when application identification is enabled.
  • In AND mode of a traffic classifier, only one application protocol group can be configured.
  • When the same configuration is delivered, the configuration with a time range has a higher priority. Only one configuration is displayed for the same application group.

Example

# Create a matching rule based on the user-defined application group Group1 in the traffic classifier class1.
<HUAWEI> system-view
[HUAWEI] application-group name Group1
[HUAWEI-application-group-Group1] quit
[HUAWEI] traffic classifier class1
[HUAWEI-classifier-class1] if-match app-group Group1
