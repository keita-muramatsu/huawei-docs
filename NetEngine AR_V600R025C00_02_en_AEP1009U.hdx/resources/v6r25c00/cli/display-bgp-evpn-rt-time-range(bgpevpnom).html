display bgp evpn all routing-table time-range

Function

The display bgp evpn all routing-table time-range command displays information about EVPN routes that flapped within a specified period.

Format

display bgp evpn all routing-table time-range time-range-start time-range-end

Parameters

Parameter Description Value
time-range-start

Specifies the start time.

The value is in the format of <0-10000>d<0-23>h<0-59>m<0-59>s.
time-range-end

Specifies the end time.

The value is in the format of <0-10000>d<0-23>h<0-59>m<0-59>s.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To view information about EVPN routes that flapped within a specified period, run the display bgp evpn all routing-table time-range command.

For example, if service traffic becomes abnormal within a certain period, run this command to check whether any route flapping occurs. If CPU usage soars high within a certain period, you can run this command to check whether a large number of routes flap within the period. The command output helps you locate the related routes.
