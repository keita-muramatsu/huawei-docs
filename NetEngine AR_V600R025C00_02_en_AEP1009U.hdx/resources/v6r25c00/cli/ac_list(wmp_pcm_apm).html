ac-list (AP view/AP provisioning view)

Function

The ac-list command configures a WAC IPv4 address list for APs.

The undo ac-list command restores the default WAC IPv4 address list for APs.

By default, no WAC IPv4 address list is configured.

Format

ac-list { ipv4-address } &<1-4>

undo ac-list

Parameters

Parameter Description Value
ipv4-address

Specifies the IPv4 address of a WAC.

The value is in dotted decimal notation.

Views

AP provisioning view, AP view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

You can run this command to statically configure a WAC IPv4 address list for APs.

In addition to the static configuration, APs can dynamically obtain a WAC IP address list through DHCP or DNS. When an AP goes online, it sends Discovery Request unicast packets to all WACs' IP addresses that are statically or dynamically obtained. After receiving the Discovery Request packets, the WACs respond to the AP with a Discovery Response packet. Based on WAC information such as the AP management capability, maximum number of access STAs, and IP address, the AP selects one WAC to establish a CAPWAP tunnel. If the AP does not have the WAC IP address list or receives no response to the Discovery Request packet, the AP broadcasts Discovery Request packets to discover WACs on the same network segment.

Follow-up Procedure

Run the commit command to deliver the configuration to APs and restart the APs to make the configuration take effect.

Precautions

After the configuration is delivered, restart the APs to make the configuration take effect.

To prevent the APs from using the configuration delivered using the commit command, run the undo ac-list command in the AP provisioning view.

Example

# Specify the WAC's IPv4 address for the AP in the AP provisioning view.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] provision-ap
[HUAWEI-wlan-provision-ap] ac-list 192.168.10.1
# Specify the WAC's IPv4 address for the AP in the AP view.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-id 0
[HUAWEI-wlan-ap-0] ac-list 192.168.10.1
Warning: The incorrect configuration will cause the AP to go out of management. This operation will deliver parameter setting and may cause reboot of AP(s). Continue?[Y/N]:y
