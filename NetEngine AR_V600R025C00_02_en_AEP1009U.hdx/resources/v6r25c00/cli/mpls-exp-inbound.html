mpls-exp-inbound

Function

The mpls-exp-inbound command maps EXP values of upstream MPLS packets to the corresponding CoSs and colors the packets.

The undo mpls-exp-inbound command restores the default mappings between EXP values of upstream MPLS packets to CoSs.

By default, the mappings from EXP values to CoSs and colors are shown in Table 1 in Usage Scenario.

Format

mpls-exp-inbound exp-value phb service-class [ color ]

undo mpls-exp-inbound [ exp-value ]

Parameters

Parameter Description Value
exp-value

Integer EXP value no less than 0 and no more than 7.

The value is an integer that ranges from 0 to 7.
phb service-class

Specifies the service class.

The value can be:

  • be
  • af1
  • af2
  • af3
  • af4
  • ef
  • cs6
  • cs7
color

Specifies the packet color.

The value can be:

  • green
  • yellow
  • red

Views

DiffServ domain view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To perform QoS scheduling for MPLS packets that come from the upstream device and carry EXP values, run the mpls-exp-inbound command to configure mappings from EXP values of MPLS packets to internal CoSs and color the packets.

Table 1 Default mappings between EXP values and internal CoSs

EXP Service Color
0 be green
1 af1 green
2 af2 green
3 af3 green
4 af4 green
5 ef green
6 cs6 green
7 cs7 green

Precautions

The color is used only to identify packet loss during congestion avoidance and does not affect the mapping between PHBs and queues.

The priorities of the matched packets are changed to PHBs and the packets are colored. If the mappings between EXP values and PHBs are not specified, the default mapping is used.

If the exp-value parameter is not specified when the undo mpls-exp-inbound command is run, all mappings between EXP values and PHBs are restored to the default values.

Example

# Map the EXP value 2 of the upstream MPLS packets to the corresponding CoS AF1 and color the packets green.
<HUAWEI> system-view
[HUAWEI] diffserv domain d1
[HUAWEI-dsdomain-d1] mpls-exp-inbound 2 phb af1 green
