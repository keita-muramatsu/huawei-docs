address(object)

Function

The address command adds a member to an address object.

The undo address command deletes a member from an address object.

By default, this function is disabled.

Format

For AR8100 series, AR8700 series, AR6700-H series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5700-H series, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR5710-S8TWDSE-LTE4EA, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S10T1X2, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S:

address [ id ] { ipv4-address { wildcard { 0 | wildcard } | mask { mask-address | mask-len } } | range start-ipv4-address end-ipv4-address } [ description description ]

undo address { id | all }

undo address { ipv4-address { wildcard { 0 | wildcard } | mask { mask-address | mask-len } } | range start-ipv4-address end-ipv4-address } [ description description ]

For AR8100 series, AR8700 series, AR6700-H series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5700-H series, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR5710-S8TWDSE-LTE4EA, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5710-S28T2S2XE4, AR5710-S52T2XE4:

address [ id ] { ipv6-address ipv6-prefix-length | range start-ipv6-address end-ipv6-address } [ description description ]

Parameters

Parameter Description Value
id

Specifies a member ID.

The value is an integer ranging from 0 to 4095.
ipv4-address

Specifies the IPv4 address.

The value is in dotted decimal notation.
wildcard wildcard

Specifies the wildcard.

The value is in dotted decimal notation and digits 1 in its binary form can be inconsecutive, such as 0.255.0.255 (00000000 11111111 00000000 11111111). In the binary form, digits 0 are to be matched, whereas digits 1 are not. For example, 192.168.1.1/0.255.0.255 indicates that only IP addresses in the 192.*.1.* form are to be matched.
0

Indicates a wildcard. The value 0 indicates a host.

-
mask mask-address

Specifies a mask.

The value is in dotted decimal notation and digits 1 in its binary form can be inconsecutive, such as 255.0.255.0 (11111111 00000000 11111111 00000000). In the binary form, digits 1 are to be matched, whereas digits 0 are not. For example, 192.168.1.1/255.0.255.0 indicates that only IP addresses in the 192.*.1.* form are to be matched.
mask mask-len

Specifies the length of the prefix.

The value is an integer that ranges from 1 to 32.
range

Indicates the IP address range of an address set.

-
start-ipv4-address

Specifies the start IPv4 address of the address set.

The value is in dotted decimal notation.
end-ipv4-address

Specifies the end IPv4 address of the address set.

The value is in dotted decimal notation.
description description

Specifies an item description.

The value is a string of 1 to 63 characters, spaces supported.
ipv6-address

Indicates the IPv6 address.

NOTE:

This parameter is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

The value is in colon hexadecimal notation.

The value is in hexadecimal notation. It consists of four groups separated by colons (:). The group of all zeros can be represented by ::.
ipv6-prefix-length

Matches the prefix length of an IPv6 address.

NOTE:

This parameter is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

The value is an integer ranging from 1 to 128.
start-ipv6-address

Specifies the start IPv6 address.

NOTE:

This parameter is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

The value is in colon hexadecimal notation.

The value is in hexadecimal notation. It consists of four groups separated by colons (:). The group of all zeros can be represented by ::.
end-ipv6-address

Specifies the end IPv6 address.

NOTE:

This parameter is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Specifies the end IPv6 address of a member.

Views

Address view

Default Level

2: Configuration level

Usage Guidelines

If the address command specifies an ID, and the address object or address group object corresponding to the ID exists, the new address information overwrites the original one.

Example

# Configure the IP address range of the address set addr whose type is object. 
<HUAWEI> system-view
[HUAWEI] ip address-set addr type object
[HUAWEI-object-address-set-addr] address 10 range 10.1.1.1 10.1.1.20
