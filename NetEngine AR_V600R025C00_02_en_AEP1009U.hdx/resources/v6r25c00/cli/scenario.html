scenario

Function

The scenario command configures the remote end access type in an IPsec policy template.

The undo scenario command cancels the configuration.

By default, the remote end access type in an IPsec policy template is point-to-multipoint.

Format

scenario { point-to-point | point-to-multi-point [ branch-access | ikev1-user-access | ikev2-user-access ] * }

undo scenario

Parameters

Parameter Description Value
point-to-point

Indicates that the remote end access type in an IPsec policy template is point-to-point.

-
point-to-multi-point

Indicates that the remote end access type in an IPsec policy template is point-to-multipoint.

-
branch-access

Indicates that the remote end access type in an IPsec policy template is permitting branch access.

-
ikev1-user-access

Sets the peer end access type to allowing IKEv1 user access in the IPsec policy template.

By default, the device does not support this parameter, that is, SA negotiation through IKEv1 is not supported. To specify this parameter, install the IKEv1 feature package.

-
ikev2-user-access

Indicates that the remote end access type in an IPsec policy template is permitting IKEv2 user access.

-

Views

IPsec policy template view

Default Level

2: Configuration level

Usage Guidelines

This command is used to configure the remote end access type in an IPsec policy template.

If you specify the point-to-multi-point parameter to set the remote access type of the IPsec policy template to point-to-multipoint and do not specify other parameters following the point-to-multi-point parameter, branches are allowed access by default.

Example

# Configure the remote end access type in IPsec policy template policy1 to point-to-point. 
<HUAWEI> system-view
[HUAWEI] ipsec policy-template policy1 1
[HUAWEI-ipsec-policy-templet-policy1-1] scenario point-to-point
