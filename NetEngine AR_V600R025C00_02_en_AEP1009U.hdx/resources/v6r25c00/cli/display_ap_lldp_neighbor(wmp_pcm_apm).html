display ap lldp neighbor

Function

The display ap lldp neighbor command displays LLDP neighbor information on a specified AP.

Format

display ap lldp neighbor { ap-id ap-id [ interface interface-type interface-number ] | brief }

Parameters

Parameter Description Value
ap-id ap-id

Displays LLDP neighbor information about the AP with a specified ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
interface interface-type interface-number

Displays LLDP neighbor information on a specified AP interface.

  • interface-type specifies the interface type.
  • interface-number specifies the interface number.

-
brief

Displays brief LLDP neighbor information about APs.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

You can run this command to view LLDP neighbor information on a specified AP, including the number of LLDP neighbors, device ID, interface ID, system name system description, and management address of each neighbor. The LLDP neighbor information is reported by an AP to the connected WAC.

If no parameter is specified, LLDP neighbor information about all AP interfaces is displayed.

Prerequisites

Run the lldp report enable command in the AP system profile view to enable the AP to report LLDP neighbor information.
