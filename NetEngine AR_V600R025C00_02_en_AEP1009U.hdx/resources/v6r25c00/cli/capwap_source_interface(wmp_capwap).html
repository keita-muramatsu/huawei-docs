capwap source interface

Function

The capwap source interface command configures the interface used by the CAPWAP server to establish a CAPWAP tunnel as the source interface of the CAPWAP server.

The undo capwap source interface command disables the CAPWAP server from using an interface as the source interface.

By default, no source interface is configured for a CAPWAP server.

Format

capwap source interface loopback loopback-number

capwap source interface vlanif vlan-id

undo capwap source interface { loopback loopback-number | vlanif vlan-id }

Parameters

Parameter Description Value
vlanif vlan-id

Configures a VLANIF interface as the source interface.

The value is an integer ranging from 1 to 4094.
loopback loopback-number

Configures a loopback interface as the source interface.

The value is an integer in the range from 0 to 1023.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Each WAC requires the configuration of one or two IP addresses, VLANIF interfaces, or loopback interfaces. In this manner, APs managed by the WAC can learn the specified IP address or the IP address of the specified interface to set up a CAPWAP tunnel with the WAC. This specified IP address or interface is called the source address or source interface. You can run this command to configure the WAC source interface.

Upon the first configuration, the CAPWAP source interface or source address can be successfully configured only when all of the following configurations exist: PSK used for DTLS encryption, PSK for DTLS encryption of inter-AC tunnels, the user name and password for AP login, and the global login password for the offline management VAP. If any of these configurations does not exist, the system prompts you to supplement related configurations first.

Prerequisites

An IP address has been assigned to the specified loopback or VLANIF interface.

Precautions

If the IP address of the source interface is used by another service, the IP address cannot be deleted. You need to remove the IP address from the corresponding service first.

If the IP address of a loopback or VLANIF interface is dynamically obtained, the interface cannot be used as the CAPWAP source interface.

A maximum of eight source interfaces can be configured.

If a loopback or VLANIF interface has been configured as the CAPWAP source interface, the following changes are not allowed on the interface:

  • Deleting or changing any IP address on the interface
  • Deleting the loopback or VLANIF interface

Executing the undo capwap source interface command will disconnect all CAPWAP clients from the CAPWAP server. Therefore, exercise caution when running this command.

After secondary authentication for risky commands is enabled using the configuration re-authentication enable command, you must enter the login password for secondary authentication before running the undo capwap source interface command.

Upon the first configuration, the CAPWAP source interface or source address can be successfully configured only when all of the following security-related configurations exist: PSK for DTLS encryption, user name and password for logging in to an AP, and password for logging in to the global offline management VAP. If any of these configurations does not exist, the system prompts you to supplement related configurations first.

Example

# Cancel the configuration of the loopback interface as the source interface of the CAPWAP server.
<HUAWEI> system-view
[HUAWEI] undo capwap source interface loopback 20
Warning: This operation will disconnect the device on the source interface. Continue? [Y/N]:y
# Configure a VLANIF interface as the source interface of the CAPWAP server.
<HUAWEI> system-view
[HUAWEI] interface vlanif 100
[HUAWEI-Vlanif100] ip address 192.168.1.1 24
[HUAWEI-Vlanif100] quit
[HUAWEI] capwap source interface vlanif 100
# Cancel the configuration of the VLANIF interface as the source interface of the CAPWAP server.
<HUAWEI> system-view
[HUAWEI] undo capwap source interface vlanif 100
Warning: This operation will disconnect the device on the source interface. Continue? [Y/N]:y
# Configure a loopback interface as the source interface.
<HUAWEI> system-view
[HUAWEI] interface loopback 20
[HUAWEI-LoopBack20] ip address 192.168.1.1 24
[HUAWEI-LoopBack20] quit
[HUAWEI] capwap source interface loopback 20
# Configure a VLANIF interface bound to a VPN instance as the source interface of the CAPWAP server.
<HUAWEI> system-view
[HUAWEI] ip vpn-instance instance1
[HUAWEI-vpn-instance-instance1] ipv4-family
[HUAWEI-vpn-instance-instance1-af-ipv4] quit
[HUAWEI-vpn-instance-instance1] quit
[HUAWEI] interface vlanif 100
[HUAWEI-Vlanif100] ip binding vpn-instance instance1
[HUAWEI-Vlanif100] ip address 192.168.1.1 24
[HUAWEI-Vlanif100] quit
[HUAWEI] capwap source interface vlanif 100
