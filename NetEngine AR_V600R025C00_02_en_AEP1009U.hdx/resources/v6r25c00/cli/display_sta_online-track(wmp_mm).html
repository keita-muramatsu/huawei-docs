display station online-track

Function

The display station online-track command displays STA online time information.

Format

display station online-track sta-mac-address

Parameters

Parameter Description Value
sta-mac-address

Displays the online time of the STA with a specified MAC address.

The value is in H-H-H format. H is a hexadecimal number that contains one to four digits, such as 00e0 and fc01. If an H contains fewer than four digits, the leftmost digits are padded with 0s. For example, two 0s are added to e0 to form 00e0.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run this command to view STA online time information.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the online time of a specified STA.
<HUAWEI> display station online-track 00e0-fc11-1111
Total cost: 2590ms

Table 1 Description of the display station online-track command output
Item Description

Total duration of all events.
Event

Event type. The values are as follows:

  • Association: STA association.
  • Auth: STA authentication.
  • WPA: WPA key negotiation.
  • DHCP: STAs obtaining IP addresses through DHCP.
Event Start(hh:mm:ss)

Start time of an event.
Event End(hh:mm:ss)

End time of an event.

Time consumed by an event.
