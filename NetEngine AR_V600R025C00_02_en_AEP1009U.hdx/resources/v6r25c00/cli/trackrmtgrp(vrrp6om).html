vrrp6 vrid track ipv6 route-monitor-group failure-ratio

Function

The vrrp6 vrid track ipv6 route-monitor-group failure-ratio command configures a VRRP6 group to track a route monitoring group.

The undo vrrp6 vrid track ipv6 route-monitor-group command disables a VRRP6 group from tracking a route monitoring group.

By default, a VRRP6 group is not configured to track a route monitoring group.

Format

vrrp6 vrid virtual-router-id track ipv6 route-monitor-group route-monitor-group-name failure-ratio failure-ratio-value [ link | reduced priority-value ]

undo vrrp6 vrid virtual-router-id track ipv6 route-monitor-group [ route-monitor-group-name [ failure-ratio failure-ratio-value [ link | reduced priority-value ] ] ]

Parameters

Parameter Description Value
route-monitor-group-name

Specifies the name of a route monitoring group tracked by a VRRP6 group.

The value is a string of 1 to 31 case-sensitive characters, spaces not supported.
failure-ratio failure-ratio-value

Specifies a link failure ratio threshold for a route monitoring group.

When the link failure ratio of a route monitoring group is greater than or equal to the threshold, the status of the route monitoring group changes to Down.

The value is an integer ranging from 1 to 100.
link

Configures a VRRP6 group to track a route monitoring group in link mode.

In this mode, if the tracked route monitoring group goes down, the VRRP6 group directly changes to the initial state and sends a VRRP6 Advertisement packet with a priority of 0 to the peer device, triggering the peer device to preempt the Master state.

-
reduced priority-value

Indicates that a VRRP6 group tracks a route monitoring group in normal mode. The device reduces the VRRP6 group's priority when the route monitoring group goes down.

The value is an integer ranging from 1 to 255.

The smallest priority can be set to 1. The priority 0 is reserved for special use. When a backup device receives a VRRP6 Advertisement packet carrying a priority of 0, the backup device immediately preempts the master role.

If the tracked route monitoring group goes down when the VRRP group tracks the route monitoring group in normal mode (the link parameter is not specified) and priority-value is not specified, the priority of the VRRP group decreases by 10.
vrid virtual-router-id

Specifies the ID of a VRRP6 group.

The value is an integer ranging from 1 to 255.

Default Level

Usage Guidelines

Usage Scenario

To prevent the loss of service traffic resulting from the withdrawal or deactivation of an uplink IPv6 route, configure a VRRP6 group to track the uplink route so that a master/backup switchover can be triggered in a timely manner. Note that a VRRP6 group can track only one VRRP6-disabled route. This means that the configuration workload is very heavy if there are many such routes to track. To reduce the configuration workload, you can add multiple VRRP6-disabled routes to a route monitoring group, and then enable a VRRP6 group to track the route monitoring group. When the failure rate of IPv6 routes within the route monitoring group reaches a specified threshold, the VRRP6 group performs a master/backup switchover to ensure reliable service transmission.

Prerequisites

The following configurations have been performed:

  • A VRRP6 group has been created by running the vrrp6 vrid command.
  • An IPv6 route monitoring group has been created using the ipv6 route-monitor-group command.

Precautions

  1. The configuration of VRRP6 tracking route monitoring groups in link mode is mutually exclusive with other configurations that directly affect the VRRP6 status. If they are configured at the same time, an error message is displayed.
  2. A VRRP6 group can track three IPv6 route monitoring groups in two modes at the same time.
    • A VRRP6 group can track a maximum of two route monitoring groups in normal mode. When the link failure ratio reaches the value specified by failure-ratio failure-ratio-value, the local priority decreases. After that, if the local priority is lower than the peer priority, the peer device becomes the master device.
  • A VRRP6 group can track one route monitoring group in link mode. When the link failure ratio reaches the value specified by failure-ratio failure-ratio-value, the local end changes to the Initialize state and sends a VRRP Advertisement packet with the priority of 0 to the peer end to trigger the peer end to become the master device.

Example

# Configure VRRP6 group 2 to track route monitoring group 2 in link mode, and set the threshold for the link failure rate to 90%. 
<HUAWEI> system-view
[HUAWEI] ipv6 route-monitor-group 2
[HUAWEI-route-monitor-group-2] quit
[HUAWEI] interface Eth-Trunk2
[HUAWEI-Eth-Trunk2] ipv6 enable
[HUAWEI-Eth-Trunk2] ipv6 address 2001:db8:1::1 64
[HUAWEI-Eth-Trunk2] vrrp6 vrid 2 virtual-ip FE80::2 link-local
[HUAWEI-Eth-Trunk2] vrrp6 vrid 2 virtual-ip 2001:db8:1::2
[HUAWEI-Eth-Trunk2] vrrp6 vrid 2 track ipv6 route-monitor-group 2 failure-ratio 90 link
# Configure VRRP6 group 1 to track route monitoring group 1 in normal mode, and set the threshold for the link failure rate to 80% and the priority to be reduced by 20. 
<HUAWEI> system-view
[HUAWEI] ipv6 route-monitor-group 1
[HUAWEI-route-monitor-group-1] quit
[HUAWEI] interface Eth-Trunk1
[HUAWEI-Eth-Trunk1] ipv6 enable
[HUAWEI-Eth-Trunk1] ipv6 address 2001:db8:1::1 64
[HUAWEI-Eth-Trunk1] vrrp6 vrid 1 virtual-ip FE80::2 link-local
[HUAWEI-Eth-Trunk1] vrrp6 vrid 1 virtual-ip 2001:db8:1::2
[HUAWEI-Eth-Trunk1] vrrp6 vrid 1 track ipv6 route-monitor-group 1 failure-ratio 80 reduced 20
