suppress-switch-trap enable

Function

The suppress-switch-trap enable command enables the SPR switchover alarm suppression function.

The undo suppress-switch-trap enable command disables the SPR switchover alarm suppression function.

By default, the SPR switchover alarm suppression function is disabled.

Format

suppress-switch-trap enable

undo suppress-switch-trap enable

Parameters

None

Views

Smart-policy-route view

Default Level

2: Configuration level

Usage Guidelines

If SPR switchover alarms are frequently reported, you can enable the SPR switchover alarm suppression function to suppress the alarms. After this function is enabled, if the total number of SPR switchover alarms generated within 30 seconds is greater than the SPR switchover alarm suppression threshold, SPR switchover alarms are reported based on the SPR instance and switchover cause.

Example

# Enable the SPR switchover alarm suppression function.
<HUAWEI> system-view
[HUAWEI] smart-policy-route
[HUAWEI-smart-policy-route] suppress-switch-trap enable
