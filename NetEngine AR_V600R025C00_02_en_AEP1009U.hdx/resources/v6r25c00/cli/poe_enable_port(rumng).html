poe enable port

Function

The poe enable port command sets the power supply mode for an interface on an RU.

The undo poe enable port command restores the default power supply mode of a PoE interface on an RU.

By default, interfaces supporting the PoE++ mode on devices provide power in PoE++ mode. That is, the power supply mode is bt-inrush, interfaces not supporting the PoE++ mode on devices provide power in at-inrush mode.

Format

poe { at-inrush | af-inrush } enable port port-id

undo poe { at-inrush | af-inrush } enable port port-id

Parameters

Parameter Description Value
at-inrush

The power supply mode of the RU interface is PoE+.

-
af-inrush

The power supply standard of the RU interface is 802.3af.

-
port-id

Indicates the port index of an RU.

The value is an integer ranging from 1 to 32. If the entered interface index is greater than the actual index of the downstream interface on the RU, the interface index is not delivered to the RU.

Views

remote-unit N view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To power on PDs requiring the standard power supply mode, you can run the poe at-inrush enable command. This command configures PoE interfaces to work in PoE+ power supply mode. Some non-IEEE-standard PDs do not support high-current power supply, and instead only support low-current power supply. To ensure these PDs can be successfully powered on, you can run the poe af-inrush enable command to configure PoE interfaces on RUs to work in 802.3af power supply mode.

Follow-up Procedure

After configuring an RU on the central device, you need to run the commit command to deliver the configuration to the RU or bring the RU online again for the configuration to take effect.

You can run the display remote-unit commit configuration command to check the configurations that are successfully delivered to RUs, and run the display remote-unit commit result command to check configuration delivery results of RUs.

Example

# Set the power supply mode of interface 1 of RU 0 to PoE+.
<HUAWEI> system-view
[HUAWEI] remote-unit 0
[HUAWEI-remote-unit-0] poe at-inrush enable port 1
