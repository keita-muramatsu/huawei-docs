remote end-op

Function

The remote end-op command configures a remote End.OP SID with a specified mask length.

The undo remote end-op command deletes a specified remote End.OP SID.

By default, a remote End.OP SID is not configured.

Format

remote end-op op-sid prefix-length

undo remote end-op op-sid [ prefix-length ]

Parameters

Parameter Description Value
op-sid

Remote End.OP SID.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
prefix-length

Length of the prefix.

The value is an integer that ranges from 1 to 128.

Views

Segment routing IPv6 view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

This command is used to manually configure a remote End.OP SID and specify the mask length in the Segment Routing IPv6 view. In this command, the end-op value is the same as that configured on the remote SRv6 device and can be queried using the display segment-routing ipv6 local-sid forwarding end-op command, and the prefix length is the same as that configured for the remote SRv6 locator.

On a network with an SRv6 TE Policy deployed, if data forwarding over the SRv6 TE Policy fails, the control plane (responsible for SRv6 TE Policy establishment) cannot detect this failure, complicating network maintenance. SRv6 TE Policy ping/tracert can be used to detect such failures and quickly locate faulty nodes. SRv6 TE Policy ping checks network connectivity and host reachability, and SRv6 TE Policy tracert locates faulty nodes in addition to checking network connectivity and host reachability.

You can run the remote end-op command or specify an End.OP SID to enable the device to initiate a ping/tracert test. Note that if the last SID of an SRv6 TE Policy's segment list is an End.X SID or binding SID, the remote end-op command configuration does not take effect. In this case, you need to specify an End.OP SID when running the ping srv6-te policy or tracert srv6-te policy command.

Precautions

Pay attention to the following points during the configuration:

  1. Multiple remote End.OP SIDs can be configured at the same time. The maximum number of remote End.OP SIDs can be customized. By default, the maximum number is 4096.
  2. The prefix and mask length of the configured SIDs cannot conflict with each other.

Example

# Configure a remote End.OP SID.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] remote end-op 2001:DB8:1::80 96
