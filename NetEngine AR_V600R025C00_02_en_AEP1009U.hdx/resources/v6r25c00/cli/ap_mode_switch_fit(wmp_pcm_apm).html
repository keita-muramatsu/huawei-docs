ap mode-switch fit

Function

The ap mode-switch fit command switches the working mode of an AP to Fit.

Format

ap mode-switch fit ap-mac ap-mac

Parameters

Parameter Description Value
ap-mac ap-mac

Specifies the MAC address of an AP whose working mode is to be switched to Fit.

The AP's MAC address must already exist.

Views

WLAN view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If the working mode of a Fit AP is switched to the Fat or cloud mode, the AP cannot be managed by the device. In this case, you can run the display ap non-fit-mode all command to check the Fat APs and cloud APs detected on the network and determine whether the AP's working mode is incorrectly switched based on AP information. If so, run the ap mode-switch fit command to switch the working mode of the AP to Fit.

Precautions

After an AP is switched to the Fit mode, the AP restarts.

Example

# Switch the working mode of a specified AP to Fit.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap mode-switch fit ap-mac 00e0-fc76-e360
