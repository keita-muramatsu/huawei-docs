session link-state check

Function

The session link-state check command enables IPv4 link stateful inspection.

The undo session link-state check command disables IPv4 link stateful inspection.

By default, link stateful inspection is disabled.

Format

session link-state [ icmp | tcp ] check

undo session link-state [ icmp | tcp ] check

Parameters

Parameter Description Value
icmp

Indicate the ICMP flow.

-
tcp

Indicate the TCP flow.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The link stateful inspection function is used to check the link status of subsequent ICMP and TCP packets in the networking environment where the incoming and outgoing paths are consistent.

The device can enable or disable link stateful inspection for one type of data flow, which does not affect the other type of data flow. The details are as follows:

  1. To inspect the TCP link status, enable firewall session link-state tcp check.
  2. To inspect the ICMP link status, enable firewall session link-state icmp check.

    After the firewall session link-state check command is run, the TCP and ICMP link status is inspected.

If session link-state check is not configured, a session table is created for traffic to perform corresponding services. After the configuration is complete, the device performs stateful inspection on data traffic of the corresponding service and creates a session table based on the stateful inspection result.

Link stateful inspection is performed only for traffic related to application identification, NAT, smart policy routing, and security policies. The link stateful inspection is performed and the session table is created only when the smart policy routing mode is load balancing or the path selection mode is symmetric.

Precautions

  1. You are advised to disable link stateful inspection in the networking where the incoming and outgoing paths of packets are inconsistent.
  2. Only services that support session establishment support this function.
  3. In an SD-WAN dual-gateway scenario, TCP SYN and ICMP REQ packets are forcibly redirected.

Example

# Enable the IPv4 link stateful inspection function. In this case, the device conducts stateful inspection on both ICMP and TCP flows simultaneously.
<HUAWEI> system-view
[HUAWEI] session link-state check
