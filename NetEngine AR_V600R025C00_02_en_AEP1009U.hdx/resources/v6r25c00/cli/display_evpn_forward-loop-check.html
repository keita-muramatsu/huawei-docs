display evpn forward-loop-check info

Function

The display evpn forward-loop-check info command displays Layer 3 forwarding loop detection information in SD-WAN scenarios.

Format

display evpn forward-loop-check info

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

To check packet forwarding loop detection information about EVPN sites within a specified period, run this command. The command output helps diagnose and locate faults.

Prerequisites

Forwarding loop detection has been enabled using the forward-loop-check enable command.

Precautions

The system can record a maximum of 20 pieces of loop detection information. When the number of historical records reaches the upper limit, new loop detection information overwrites the earliest one.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display loop detection information recorded in the system.
<HUAWEI> system-view
[HUAWEI] display evpn forward-loop-check info
