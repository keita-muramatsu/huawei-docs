display ipsec p2mp-sa

Function

The display ipsec p2mp-sa command displays SA information of P2MP policies.

Format

display ipsec p2mp-sa { local | peer [ site site-id [ system-id system-id ] ] }

Parameters

Parameter Description Value
local

Indicates a local site.

-
peer

Indicates a remote site.

-
site site-id

Specifies a site ID.

The value is an integer from 1 to 65535.
system-id system-id

Specifies a system ID.

The value is in dotted decimal notation.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

To check the local or remote P2MP SA configuration during fault diagnosis, run the display ipsec p2mp-sa command.

Precautions

In a tunnel optimization scenario, SA information is generated when IPsec P2MP policies are configured on a tunnel interface or a P2MP SA is configured on a TNP.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display information about local SAs that are not established through DH exchange.
