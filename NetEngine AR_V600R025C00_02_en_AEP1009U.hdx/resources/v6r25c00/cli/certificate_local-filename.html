certificate local-filename

Function

The certificate local-filename command specifies the file name of the certificate used on the local end.

The undo certificate local-filename command cancels the certificate configuration.

By default, no local certificate is configured.

Format

certificate local-filename filename

undo certificate local-filename

Parameters

Parameter Description Value
local-filename filename

Specifies the file name of a local certificate.

The value must be the name of an existing certificate.

Views

IKE peer view

Default Level

2: Configuration level

Usage Guidelines

When RSA signature authentication (rsa-signature) or ECDSA signature authentication (ecdsa-signature) is configured, you can set the local certificate to be used on the local end by specifying the corresponding file name in offline mode.

Example

# Specify the certificate file1.cer. 
<HUAWEI> system-view
[HUAWEI] ike peer a
[HUAWEI-ike-peer-a] certificate local-filename file1.cer
