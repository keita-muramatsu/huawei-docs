portal logout different-server enable

Function

The portal logout different-server enable command enables a device to process user logout requests sent by a Portal server other than the one from which users go online.

The undo portal logout different-server enable command restores the default configuration.

By default, the device does not process user logout requests sent by Portal servers other than the one from which users log in.

Format

portal logout different-server enable

undo portal logout different-server enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In a scenario where Portal server load balancing is configured, by default, a device does not process user logout requests sent by Portal servers other than the one from which users log in and returns ACK messages only to the Portal server from which users log in. Users in arrears then can still stay online. To solve the preceding problem, run the portal logout different-server enable command to enable the device to process user logout requests sent by Portal servers other than the one from which users log in. After receiving a user logout request from a Portal server other than the one from which users log in, the device starts the user logout process and returns an ACK message to the Portal server, ensuring that users go offline normally.

Precautions

The user logout requests that a device can process must be sent by Portal servers bound to an access interface. These servers include all the Portal servers configured in the primary and secondary Portal server templates bound to the interface.

Example

# Enable the device to process user logout requests sent by a Portal server other than the one from which users go online.
<HUAWEI> system-view
[HUAWEI] portal logout different-server enable
