upgrade scheduled

Function

The upgrade scheduled command upgrades a software package at a specified time.

The cancel upgrade scheduled command cancels a scheduled upgrade task.

By default, no software package is upgraded.

Format

upgrade scheduled scheduled-time scheduled-time-val recheck-new-version

upgrade scheduled scheduled-time scheduled-time-val { system-software | patch | feature-software { feature-name } &<1-9> } *

cancel upgrade scheduled

Parameters

Parameter Description Value
recheck-new-version

Checks the new version.

The value is a keyword. If this parameter is specified, the new version is checked before upgrading a non-specified software package.
scheduled-time scheduled-time-val

Specifies the upgrade time.

The value is a string of 1 to 31 characters. The time format is yyyy-mm-ddThh:mm:ss. This parameter specifies the local system time of the device.
system-software

Specifies a basic software package.

The value is a keyword.

  • If this parameter is specified, the basic software package is upgraded when the specified software package is upgraded.
  • If this parameter is not specified, the basic software package is not upgraded when the specified software package is upgraded.
patch

Specifies a patch package.

The value is a keyword.

  • If this parameter is specified, the patch package is upgraded when the specified software package is upgraded.
  • If this parameter is not specified, the patch package is not upgraded when the specified software package is upgraded.
feature-software feature-name

Specifies the names of features for which feature packages are to be upgraded.

The value is a string of 1 to 127 case-sensitive characters. It cannot contain spaces.

  • If this parameter is specified, the feature package is upgraded to the target version when the specified software package is upgraded.
  • If this parameter is not specified, the feature package is not upgraded to the target version when the specified software package is upgraded.
cancel

Cancels the configured scheduled task.

The value is a keyword.

Views

Smart upgrade view

Default Level

3: Management level

Usage Guidelines

For a one-off scheduled upgrade task, you need to run the check new-version command to check the new version, run the display smart-upgrade information command to check the software package to be upgraded, and run the upgrade scheduled command to specify the upgrade time. If recheck-new-version is specified, the system checks the new version and upgrades all recommended upgrade software packages. If recheck-new-version is not specified, the device is upgraded based on the specified software package.

During smart upgrade, if a scheduled upgrade task has been created using the upgrade scheduled command, you can run the cancel upgrade scheduled command to cancel the scheduled upgrade task before the system time reaches the specified time. If the system time is later than the specified time, the scheduled task cannot be canceled.

Example

# Upgrade the basic software package and patch package at 15:25:30 on September 26, 2024.
<HUAWEI> system-view
[HUAWEI] smart-upgrade
[HUAWEI-smart-upgrade] upgrade scheduled scheduled-time 2024-09-26T15:25:30 system-software patch
# Cancel the created scheduled upgrade task.
<HUAWEI> system-view
[HUAWEI] smart-upgrade
[HUAWEI-smart-upgrade] cancel upgrade scheduled
# Check the new version and upgrade the software package at 15:25:30 on September 26, 2024.
<HUAWEI> system-view
[HUAWEI] smart-upgrade
[HUAWEI-smart-upgrade] upgrade scheduled scheduled-time 2024-09-26T15:25:30 recheck-new-version
# Upgrade feature packages feature1 and feature2 at 15:25:30 on September 26, 2024.
<HUAWEI> system-view
[HUAWEI] smart-upgrade
[HUAWEI-smart-upgrade] upgrade scheduled scheduled-time 2024-09-26T15:25:30 feature-software feature1 feature2
