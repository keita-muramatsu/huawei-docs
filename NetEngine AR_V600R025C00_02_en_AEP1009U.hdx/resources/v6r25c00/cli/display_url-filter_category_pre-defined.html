display url-filter category pre-defined

Function

The display url-filter category pre-defined command displays the URL category list.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

display url-filter category pre-defined [ category-id category-id-value | subcategory-id subcategory-id-value ]

Parameters

Parameter Description Value
category-id category-id-value

Specifies the ID of a predefined URL category.

The value is an integer ranging from 1 to 100.
subcategory-id subcategory-id-value

Specifies the ID of a predefined URL subcategory.

The value is an integer ranging from 101 to 60000.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To view the URL category list, run the display url-filter category pre-defined command.
