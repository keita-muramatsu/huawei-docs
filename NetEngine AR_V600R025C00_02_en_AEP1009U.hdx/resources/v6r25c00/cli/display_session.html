display session

Function

The display session command displays the session table information.

Format

display session all [ verbose ]

display session number

display session destination destination-address [ destination-port ] [ verbose ]

display session source source-address [ source-port ] [ destination destination-address [ destination-port ] ] [ verbose ]

display session { protocol { protocol-number | icmp | tcp | udp } | flood-detect detect-type } [ source source-address [ source-port ] ] [ destination destination-address [ destination-port ] ] [ verbose ]

display session module { nat | sec-policy | sac | spr | saas } [ verbose ]

display session number module { nat | sec-policy | sac | spr | saas }

display session module nat brief

Parameters

Parameter Description Value
verbose

Displays detailed information about session entries.

-
number

Displays the number of session entries.

-
destination destination-address

Displays session entries with a specified destination IP address.

The value is in dotted decimal notation.
destination-port

Displays session entries with a specified destination port number.

The value is an integer from 1 to 65535.
source source-address

Displays session entries with a specified source IP address.

The value is in dotted decimal notation.
source source-port

Displays session entries with a specified source IP address and a source port number.

The value is an integer from 1 to 65535.
protocol protocol-number

Displays session entries with a specified protocol number.

The value is an integer ranging from 1 to 255.
flood-detect detect-type

Displays session entries of a specified flood attack.

The value is of the enumerated type. Currently, tcp is available, indicating that the number of TCP special packets in the same flow exceeds 20.
module

Specifies the session table information of different services.

-
nat

Displays the NAT session table information.

-
sec-policy

Displays the session table information of the security policy service.

-
sac

Displays the SAC session table information.

-
spr

Displays the session table information about the intelligent policy routing service.

-
saas

Displays the SaaS session table information.

-
brief

Displays brief information about the NAT session table.

-
all

Displays all session entries.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

You can run this command to check the session table information.

Precautions

For AR8100 series, AR8700 series, AR6700-H series, AR5700-S series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4:

When the number of sessions on the device is large, it takes a long time to display all session information. Therefore, you are advised to filter session information.

For AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T:

  • If the number of sessions on the device is large, it takes a long time to print all session information. You are advised to filter the session information.
  • The hardware session table differentiates the direction (LAN-to-WAN and WAN-to-LAN). Generally, one session occupies two hardware session entries.
