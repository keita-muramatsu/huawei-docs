display poe-power

Function

The display poe-power command displays information about the PoE power supply.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA.

Format

display poe-power

display poe-power slot slot-id

Parameters

Parameter Description Value
slot slot-id

Displays PoE power supply information of a specified box-shaped device.

The value is a string of 1 to 9 characters.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

The display poe-power displays information including the available total PoE power, percentage of the reserved power, and power alarm threshold.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the PoE power supply information of a box-shaped device.
<HUAWEI> display poe-power
Slot  0                                                                                                                             
  Total PoE Power(mW)             : 717250                                                                                          
  Reserved PoE Power Percent      : 20 %                                                                                            
  PoE Power Threshold Percent     : 90 %                                                                                            
  Available Power(mW)             : 573800                                                                                          
  Consumed Power(mW)              : 0                                                                                               
    Power  1                                                                                                                        
      Power Value(mW)         : 1000000                                                                                             
      Supported PoE           : YES                                                                                                 
      Supported Mode          : Balance                                                                                             
    Power  2                                                                                                                        
      Power Value(mW)         : -                                                                                                   
      Supported PoE           : -                                                                                                   
      Supported Mode          : -
Table 1 Description of the display poe-power command output
Item Description
Total PoE Power(mW)

PoE power that the system can provide.
PoE Power Threshold Percent

Alarm threshold percentage of PoE power consumption.

To set the threshold percentage, run the poe power-threshold command.
Reserved PoE Power Percent

Reserved PoE power percentage.

To set the percentage, run the poe power-reserved command.
Power Value(mW)

The power supply can provide power.
Available Power(mW)

PoE power that the PDs can use.
Consumed Power(mW)

PoE power that the PDs have used.
Supported PoE

Whether the power module supports PoE power supply.
Supported Mode

Current equalization or non-current equalization power mode.
