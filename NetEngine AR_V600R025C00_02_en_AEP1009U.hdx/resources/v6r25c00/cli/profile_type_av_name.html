profile type av

Function

The profile type av command creates an antivirus profile and displays the antivirus profile view.

The undo profile type av command deletes all or specified user-defined antivirus profiles.

By default, the device has an antivirus profile named default.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

profile type av name name

undo profile type av name name

undo profile type av all

Parameters

Parameter Description Value
name name

Specifies the name of an antivirus profile.

Specifies the name of the profile. The value is a string of 1 to 32 characters. If the name contains spaces, it must be enclosed in double quotation marks (""), for example, "user for test". The name cannot contain question marks (?), commas (,), or hyphens (-).
all

Specifies all antivirus profiles.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

The antivirus function accurately identifies files transmitted through specified protocols and takes predefined response measures on identified virus-infected files. In this way, virus-infected files are processed before they enter the protected network, which effectively protects network security and prevents virus-infected files from entering the protected network through the gateway.

To use the antivirus function, you need to create an antivirus profile and reference the antivirus profile in the security policy.

The profile type av name command creates an antivirus profile and displays the antivirus profile view. In this view, you can configure protocol detection, application exception, and virus exception.

Example

# Create an antivirus profile named profile1.
<HUAWEI> system-view
[HUAWEI] profile type av name profile1
[HUAWEI-profile-av-profile1]
