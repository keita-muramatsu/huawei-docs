mpls ldp (Interface view)

Function

The mpls ldp command enables LDP on an interface.

The undo mpls ldp command disables LDP on an interface.

By default, LDP is not enabled on an interface.

Format

mpls ldp

undo mpls ldp

Parameters

None

Views

10GE sub-interface view, 10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE sub-interface view, 40GE interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, Ethernet sub-interface view, Ethernet interface view, GE optical interface view, GE interface view, GE electrical interface view, MP-group interface view, Multi-GE sub-interface view, Multi-GE interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

On a network where MPLS LDP services need to be deployed, after enabling MPLS LDP globally on a node, you need to enable MPLS LDP on the interface of the node before performing other LDP configurations.

Prerequisites

MPLS LDP has been enabled on the node to which the interface belongs.

Configuration Impact

Running the undo mpls ldp command in the interface view causes the deletion of all MPLS LDP configurations on the interface.

Follow-up Procedure

Perform other MPLS LDP configurations.

Precautions

  1. When the cost value of a link is adjusted and the outbound interface of the route is switched to a physical interface that is not enabled with LDP, LDP LSPs may be deleted in batches. To prevent this issue, enable MPLS LDP on all the outbound interfaces of the route.
  2. LDP is not enabled on an interface of the backup path. When the primary path fails and traffic is switched to the backup path, the LDP or mLDP LSP is deleted and traffic is interrupted. To prevent this issue, enable MPLS LDP on the interface of the backup path.
  3. The system controls the number of LDP-enabled interfaces to prevent service loss or system breakdown when the number of LDP-enabled interfaces exceeds the upper limit. When the number of LDP-enabled interfaces exceeds the total LDP specification and the number of IGP-enabled interfaces exceeds the total IGP specification, an alarm is generated.

    Note:

    The total LDP specification varies according to products. For details, contact technical support.

Example

# Enable LDP on an interface. 
<HUAWEI> system-view
[HUAWEI] mpls
[HUAWEI-mpls] quit
[HUAWEI] mpls ldp
[HUAWEI-mpls-ldp] quit
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] mpls
[HUAWEI-10GE0/0/1] mpls ldp
