logging

Function

The logging command enables the function of recording a log when the DHCPv6 or DHCPv6 PD server allocates an IPv6 address or prefix in the IPv6 address pool view.

The undo logging command disables the function of recording a log when the DHCPv6 or DHCPv6 PD server allocates an IPv6 address or prefix in the IPv6 address pool view.

By default, the function of recording a log when the DHCPv6 or DHCPv6 PD server allocates an IPv6 address or prefix is disabled.

Format

logging [ allocation-address-success | allocation-prefix-success | detect-address-conflict | release-address-success | release-prefix-success | renew-address-success | renew-prefix-success ] *

undo logging [ allocation-address-success | allocation-prefix-success | detect-address-conflict | release-address-success | release-prefix-success | renew-address-success | renew-prefix-success ] *

Parameters

Parameter Description Value
allocation-address-success

Displays a log when an IPv6 address is successfully allocated.

-
allocation-prefix-success

Displays a log when an IPv6 prefix is successfully allocated.

-
detect-address-conflict

Displays a log when an IPv6 address conflict is detected.

-
release-address-success

Displays a log when an IPv6 address is released.

-
release-prefix-success

Displays a log when an IPv6 prefix is released.

-
renew-address-success

Displays a log when an IPv6 address is renewed successfully.

-
renew-prefix-success

Displays a log when an IPv6 prefix is successfully renewed.

-

Views

DHCP IPv6 address pool view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

This command is used on DHCPv6 or DHCPv6 PD servers. After the logging command is configured, the server records a log if an IPv6 address or prefix is allocated, renewed, or released, or an IPv6 address or prefix conflict is detected, facilitating routine maintenance and fault locating.

You can run the display dhcpv6 pool command to check the status of the log recording function on the server.

Prerequisites

An IPv6 address pool has been created using the dhcpv6 pool command.

Precautions

  • After the log recording function is enabled, the server frequently records logs if a large number of clients request IPv6 addresses or prefixes. This may deteriorate device performance.
  • IPv6 address allocation logs are recorded in the AM6 module. To view logs, you must enable the information center function. The default configuration of the log output function varies according to the log level and output direction. For details, see "Information Center Configuration" in Configuration Guide > Device Management Configuration.

    For example, the level of the logs generated when IPv6 addresses in an address pool are successfully assigned, IPv6 addresses are successfully renewed, and IPv6 addresses are released is informational. These logs are not recorded in the logbuffer by default. You can run the info-center source AM6 channel 4 log level informational command to change the level of the address pool logs to be output to the logbuffer. Then, you can run the display logbuffer command to view these logs.

Example

# Enable the function of recording a log when the server allocates an IPv6 address or prefix in the IPv6 address pool pool1. 
<HUAWEI> system-view
[HUAWEI] dhcpv6 pool pool1
[HUAWEI-dhcpv6-pool-pool1] logging
