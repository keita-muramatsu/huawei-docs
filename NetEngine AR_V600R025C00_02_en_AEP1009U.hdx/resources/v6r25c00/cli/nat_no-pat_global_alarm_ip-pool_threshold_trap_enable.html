nat no-pat global alarm ip-pool threshold trap enable

Function

The nat no-pat global alarm ip-pool threshold trap enable command enables the function of sending an alarm when the usage of public IP addresses in a No-PAT address pool reaches the alarm threshold.

The undo nat no-pat global alarm ip-pool threshold trap enable command disables the function of sending an alarm when the usage of public IP addresses in a No-PAT address pool reaches the alarm threshold.

By default, the function of sending an alarm when the usage of public IP addresses in a No-PAT address pool reaches the alarm threshold is disabled.

Format

nat no-pat global alarm ip-pool threshold trap enable

undo nat no-pat global alarm ip-pool threshold trap enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

In the NO-PAT NAT scenario, if you need to monitor the usage of public IP addresses in the address pool, run the nat no-pat global alarm ip-pool threshold trap enable command to enable alarm sending upon the public IP address usage of the address pool. When the public IP address usage of the address pool exceeds the threshold specified in the nat no-pat global alarm ip-pool threshold command, the device sends the hwSecTrapNopatAddrOverThreshold alarm to the NMS. After the public IP address usage of the address pool falls below the threshold, the device sends the hwSecTrapNopatAddrBelowThreshold alarm to the NMS.

Example

# Enable the function of sending an alarm when the usage of public IP addresses in a No-PAT address pool reaches the alarm threshold.
<HUAWEI> system-view
[HUAWEI] nat no-pat global alarm ip-pool threshold trap enable
