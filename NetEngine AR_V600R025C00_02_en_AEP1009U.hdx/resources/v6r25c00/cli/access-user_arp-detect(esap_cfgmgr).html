access-user arp-detect

Function

The access-user arp-detect command configures the source IP address and source MAC address of offline detection packets in a specified VLAN.

The undo access-user arp-detect command deletes the source IP address and source MAC address of offline detection packets from a specified VLAN.

By default, the source IP address and source MAC address are not specified for offline detection packets in a VLAN.

Format

access-user arp-detect vlan vlan-id ip-address ip-address mac-address mac-address

undo access-user arp-detect vlan vlan-id ip-address ip-address mac-address mac-address

Parameters

Parameter Description Value
ip-address ip-address

Specifies the source IP address of offline detection packets.

The value is in dotted decimal notation and can be 0.0.0.0, 255.255.255.255, or another valid IP address.
mac-address mac-address

Specifies the source MAC address of offline detection packets.

The value is a unicast MAC address. It is in the format of H-H-H, in which H is a hexadecimal number of 1 to 4 digits.
vlan vlan-id

Specifies a VLAN ID.

The value is an integer ranging from 1 to 4094.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The device sends an ARP probe packet to check the user online status. If the user does not respond within a detection period, the device considers that the user is offline.

If the VLAN to which the user belongs does not have a VLANIF interface or the VLANIF interface does not have an IP address, the device sends an ARP probe packet using 0.0.0.0 as the source IP address. If a user cannot respond to an ARP probe packet with the source IP address 0.0.0.0, you can specify the source IP address for the ARP probe packet.

You are advised to specify the user gateway IP address and MAC address as the source IP address and source MAC address of ARP probe packets sent by the device.

Precautions

  • This function takes effect only for wired users.
  • For online users on a physical interface, this command takes effect only after the users go online again or the device re-authenticates the users.
  • Priority of the source IP address used by offline detection packets:
    • IP address of the VLANIF interface corresponding to the VLAN to which the user belongs, which is on the same network segment as the user
    • Source IP address of offline detection packets in the VLAN specified by the access-user arp-detect vlan vlan-id ip-address ip-address mac-address mac-address command
    • Source address of offline detection packets calculated based on the access-user arp-detect fallback ip-address { mask | mask-length } command
    • Default source IP address of offline detection packets specified by the access-user arp-detect default ip-address ip-address command

Example

# Set the source IP address and MAC address of offline detection packets for users in VLAN 10 to 192.168.1.1 and 00e0-fc12-3456 respectively.
<HUAWEI> system-view
[HUAWEI] access-user arp-detect vlan 10 ip-address 192.168.1.1 mac-address 00e0-fc12-3456
