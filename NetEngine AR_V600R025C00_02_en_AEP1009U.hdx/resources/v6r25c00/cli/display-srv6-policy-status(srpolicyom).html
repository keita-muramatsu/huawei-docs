display srv6-te policy status

Function

The display srv6-te policy status command displays the reason why the SRv6 TE policy cannot be Up.

Format

display srv6-te policy status { endpoint endpoint-ip color color-value | policy-name name-value | binding-sid binding-sid }

Parameters

Parameter Description Value
endpoint endpoint-ip

Specifies the endpoint of an SRv6 TE Policy.

The value is a 32-digit hexadecimal string in format X:X:X:X:X:X:X:X.
color color-value

Specifies a color value for an SRv6 TE Policy.

The value is an integer ranging from 0 to 4294967295.
policy-name name-value

Specifies the name of an SRv6 TE Policy.

The value is a string of 1 to 255 case-sensitive characters. If the string is enclosed in double quotation marks ("), spaces are allowed in the string.
binding-sid binding-sid

Specifies a binding SID.

The value is a 32-digit hexadecimal string in format X:X:X:X:X:X:X:X.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To check SRv6 TE Policy status for determining the reason why an SRv6 TE Policy cannot go up, run the display srv6-te policy status command. The command output facilitates troubleshooting.

Example

The actual command output varies according to the device. The command output here is only an example.

# According to the policy name, check whether the SRv6 TE policy is up and why the SRv6 TE policy cannot be up.
<HUAWEI> display srv6-te policy status policy-name aaaa
Policy Endpoint                           : 2001:DB8:1::1
Policy Color                              : 1
Policy State                              : Up
  Check Admin Status                      : Pass
  Check Endpoint & Color                  : Pass
  Check Policy Not Reach Limit            : Pass
  Check Segment List Exist                : Pass
  Check Segment List Valid                : Pass
  Check Segment List Not Reach Limit      : Pass
  Check Candidate Path Valid              : Pass
Table 1 Description of the display srv6-te policy status command output
Item Description
Policy State

SRv6 TE Policy status:

  • Up.
  • Down (Init).
  • Down (Overrun).
  • Down (BFD down).
  • Down (Shutdown).
  • Down (Delay Delete).
Policy Endpoint

Endpoint of an SRv6 TE Policy.
Policy Color

Color of an SRv6 TE Policy.
Check Admin Status

Check whether the shutdown command is configured in the SRv6 TE Policy view. If the shutdown command is configured, the field value is Fail. If the shutdown command is not configured, the field value is Pass.
Check Endpoint & Color

Whether an endpoint and color exist in the SRv6 TE Policy. If yes, "Pass" is displayed. If no, "Fail" is displayed. If the result of the previous check item is Fail, the value of this field is displayed as "-".
Check Policy Not Reach Limit

Whether SRv6 TE Policies fail to go up because the number of SRv6 TE Policies exceeds the upper limit. If yes, "Fail" is displayed. If no, "Pass" is displayed. If the result of the previous check item is Fail, the value of this field is displayed as "-".
Check Segment List Exist

Whether the candidate path of an SRv6 TE Policy has a valid segment list. If yes, "Pass" is displayed. If no, "Fail" is displayed. If the result of the previous check item is Fail, the value of this field is displayed as "-".
Check Segment List Valid

Whether the SRv6 TE Policy has a valid segment list. If yes, "Pass" is displayed. If no, "Fail" is displayed. If the result of the previous check item is Fail, the value of this field is displayed as "-".
Check Segment List Not Reach Limit

Whether the SRv6 TE Policy is down because the number of segment lists referenced by candidate paths of the SRv6 TE policy exceeds the limit. If the number does not exceed the limit but the policy is down, "Pass" is displayed. Otherwise, "Fail" is displayed. If the result of the previous check item is Fail, the value of this field is displayed as "-".
Check Candidate Path Valid

Whether an up candidate path exists in the SRv6 TE Policy. If yes, "Pass" is displayed. If no, "Fail" is displayed. If the result of the previous check item is Fail, the value of this field is displayed as "-".
