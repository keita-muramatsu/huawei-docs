routing-mode

Function

The routing-mode command sets the traffic steering mode in an SPR policy.

The undo routing-mode command restores the default traffic steering mode in an SPR policy.

By default, the traffic steering mode in an SPR policy is preferential occupation.

Format

routing-mode { path-prefer | load-balance }

undo routing-mode [ path-prefer | load-balance ]

Parameters

Parameter Description Value
path-prefer

Selects a single link for the packets matching the SPR policy.

-
load-balance

Load balances the packets matching the SPR policy among links with the same priority.

-

Views

SPR policy view

Default Level

2: Configuration level

Usage Guidelines

When multiple links are used for branch site interconnection, different applications have different requirements on link quality. To fully utilize bandwidth while ensuring service experience, you can configure SPR load balancing to improve bandwidth utilization.

Example

# Set the traffic steering mode of the spr1 policy to load balancing.
<HUAWEI> system-view
[HUAWEI] smart-policy-route
[HUAWEI-smart-policy-route] spr-policy node 1
[HUAWEI-smart-policy-route-spr-policy-node-1] routing-mode load-balance
