dhcpv6 client request option-list

Function

The dhcpv6 client request option-list command configures a list of request options that the Option 6 field in the Request packets sent by the DHCPv6 client carries besides the default options.

The undo dhcpv6 client request option-list command deletes the request options carried in the Option 6 field of the request packets sent by the DHCPv6 client except the default options.

By default, the Option 6 field in DHCPv6 request packets sent by a DHCPv6 client carries only the default request options.

Format

dhcpv6 client request option-list option-code &<1-2>

undo dhcpv6 client request option-list option-code &<1-2>

Parameters

Parameter Description Value
option-code

Specifies a list of request options except the default options carried in the Option 6 field.

The options are as follows:

  • 17
  • 59

Views

10GE sub-interface view, 10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE sub-interface view, 40GE interface view, Dialer interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, Ethernet sub-interface view, Ethernet interface view, GE sub-interface view, GE interface view, Multi-GE interface view, VLANIF interface view, Management interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The Option 6 field in the request packets sent by the DHCPv6 client is used to set the request option list. A DHCPv6 client uses this option to specify the network configuration parameters to be obtained from a DHCPv6 server. In addition to the default options, you can run the dhcpv6 client request option-list command to configure the Option 6 field to carry request options other than the default options based on network requirements.

Prerequisites

IPv6 has been enabled on the interface using the ipv6 enable command in the interface view.

Example

# On 10GE 0/0/1, configure the Option 6 field in the request packets sent by the DHCPv6 client to carry Option 17. 
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] undo portswitch
[HUAWEI-10GE0/0/1] ipv6 enable
[HUAWEI-10GE0/0/1] dhcpv6 client request option-list 17
