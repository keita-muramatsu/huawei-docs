temporary-management disable (AP system profile view)

Function

The temporary-management disable command disables management SSID for offline APs.

The undo temporary-management disable command enables management SSID for offline APs.

By default, management SSID is enabled for offline APs.

Format

temporary-management disable

undo temporary-management disable

Parameters

None

Views

AP system profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

  • APs are often installed in hidden places or at high positions. When an AP becomes faulty, it is inconvenient to connect to the AP through a console port or network cable to troubleshoot faults.
  • After the offline management VAP function is configured, if an AP goes offline unexpectedly, maintenance personnel only need to set the IP address of a STA to 169.254.2.x/24 (except 169.254.2.1; 169.254.2.100 recommended). After the STA associates with the offline management VAP, maintenance personnel can connect the STA to the AP in STelnet mode to locate and rectify faults, saving the need to connect to the AP through the console port or a network cable.
  • Configure the default offline management SSID: After the offline management SSID function is enabled using this command, the AP automatically creates an offline management SSID when it goes offline unexpectedly. This SSID is named hw_manage_xxxx. xxxx indicates the last 4 digits of the AP's MAC address.
  • Create a new offline management SSID: Any STA can use the default SSID and password to log in to an AP, which poses security risks. To improve security of the offline management SSID, you can bind a security profile of a high security level to the VAP profile, and set a new SSID and password. Additionally, you can run the temporary-management enable command in the VAP profile view and the undo temporary-management disable command in the AP system profile view, respectively, to configure the SSID generated in the VAP profile as the offline management SSID. The default offline management SSID will not be created.

Precautions

  • The offline management SSID takes effect only when an AP goes offline unexpectedly.
  • Before using the offline management SSID function, ensure that the STelnet service has been enabled on the AP.
  • The central AP does not have radios and therefore does not generate an offline management SSID.
  • The offline management SSID conflicts with service holding upon link disconnection. If the two functions are configured at the same time, service holding upon link disconnection does not take effect.
  • STA address learning does not take effect in offline management SSID scenarios.

Example

# Enable management SSID for offline APs.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name apsys1
[HUAWEI-wlan-ap-system-prof-apsys1] undo temporary-management disable
