display system resource acl

Function

The display system resource acl command displays CPU ACL resource information on a specified device.

Format

display system resource acl [ slot slot-id ]

Parameters

Parameter Description Value
slot slot-id

Displays CPU ACL resource information on a specified device.

The value is a string of 1 to 31 case-sensitive characters without spaces.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

The display system resource acl command displays CPU ACL resource information, which helps you learn about the resource usage of the device. If slot-id is not specified, all CPU ACL resource usages in different stages on the device are displayed.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display CPU ACL resource information on a specified device.
<HUAWEI> system-view
[HUAWEI] display system resource acl
--------------------------------------------------------------------------------                                                    
Slot  Chip Resource Stage              Total     Used     Free                                                                      
--------------------------------------------------------------------------------                                                    
0     0    Rules    Ingress+Egress     65536        6    65530                                                                      
0     0    Meters   Ingress+Egress     32768        0    32768                                                                      
--------------------------------------------------------------------------------
Table 1 Description of the display system resource acl command output
Item Description
Slot

Device ID.
Chip

Chip ID.
Resource

The ACL resource type is displayed. (The resource type supported by different devices depends on the device display.).

  • Rules: rule resources.
  • Meters: CAR resources.
Stage

Stage during the packet forwarding process (the supported packet forwarding stages depend on the device):

  • Pre-Ingress: inbound direction before MAC address table lookup.
  • Ingress: inbound direction.
  • Egress: outbound direction.
  • Ingress+Egress: inbound and outbound directions.
Total

Total number of resources. The number of resources differs according to device models.
Used

Number of used resources.
Free

Number of remaining resources.
