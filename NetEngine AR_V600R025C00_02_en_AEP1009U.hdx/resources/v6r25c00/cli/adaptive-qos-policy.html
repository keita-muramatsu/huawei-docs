adaptive-qos-policy

Function

The adaptive-qos-policy command applies an adaptive QoS policy to a site group.

The undo adaptive-qos-policy command cancels the application of an adaptive QoS policy to a site group.

By default, no adaptive QoS policy is applied to a site group.

This command is supported only on the AR8700 series, AR8100 series and AR6700-H series.

Format

adaptive-qos-policy policy-name

undo adaptive-qos-policy policy-name

Parameters

Parameter Description Value
adaptive-qos-policy policy-name

Specifies the name of an adaptive QoS policy.

The value is a string of 1 to 31 case-sensitive characters. If spaces are used, the string must be enclosed in double quotation marks (" ").

Views

Site group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When the SD-WAN headquarters sends data to branches, an adaptive QoS policy can dynamically adjust the bandwidth of the traffic sent from the headquarters to branches based on the network congestion status, reducing network congestion.

Prerequisites

An adaptive QoS policy has been created by running the adaptive-qos policy command.

Example

# Create an adaptive QoS policy named aqos1 and apply the policy to site group 10.
<HUAWEI> system-view
[HUAWEI] adaptive-qos policy aqos1
[HUAWEI-adaptive-qos-aqos1] quit
[HUAWEI] evpn site-group 10
[HUAWEI-evpn-site-group-10] adaptive-qos-policy aqos1
