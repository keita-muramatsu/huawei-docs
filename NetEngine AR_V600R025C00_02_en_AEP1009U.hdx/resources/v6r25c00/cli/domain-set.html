domain-set

Function

The domain-set command creates a domain group and displays its view.

The undo domain-set command deletes domain groups.

By default, this function is not configured.

Format

domain-set name domain-set-name

undo domain-set { name domain-set-name | all }

Parameters

Parameter Description Value
name domain-set-name

Specifies the name of a domain group.

The value is a string of 1 to 128 case-sensitive characters, spaces not supported. If spaces are used, the string must be enclosed in double quotation marks (" "). The name cannot be set to any or all.
all

Indicates all domain groups.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

A domain group referenced by a policy cannot be deleted.

When an IP address corresponds to multiple domain names, a maximum of 128 domain names can be queried for the IP address. If the domain name in the policy is not among the 128 queried domain names, the policy cannot be matched. You are advised to configure multiple domain names with the same IP address in the same policy.

Example

# Create domain group set1. 
<HUAWEI> system-view
[HUAWEI] domain-set name set1
[HUAWEI-domain-set-set1]
