fastpass users

Function

The fastpass users command configures the VIP FastPass function on APs.

The undo fastpass command restores the default status of the VIP FastPass function on APs.

By default, the VIP FastPass function is enabled, the number of FastPass users is 5, the FastPass scheduling period is 20 ms, and the percentage of FastPass users in the scheduling period is 25%.

Format

fastpass users value [ period period-value ratio ratio-value ]

undo fastpass

Parameters

Parameter Description Value
value

Specifies the number of FastPass users.

The value is an integer that ranges from 0 to 10. When this parameter is set to 0, the VIP FastPass function is disabled. The default value is 5.
period period-value

Specifies the FastPass scheduling period.

The value is of enumerated type, which can be 20, 40, 60, 80, or 100, in milliseconds. The default value is 20.
ratio ratio-value

Specifies the percentage of FastPass users in the scheduling period.

The value is an integer that ranges from 5 to 75, in percentage. The default value is 25.

Views

2.4G radio profile view, 5G radio profile view

Default Level

2: Configuration level

Usage Guidelines

In wireless scenarios, co-channel preemption and interference severely affect air interface performance. When one or more common users run bandwidth-extensive services (such as download, HD video playing, and file upload), the AP air interface environment is congested. If greedy STAs with non-standard preemption capabilities are involved, VIP users may fail in the contention for channel resources on the air interface. This ultimately affects service experience of other wireless users, especially VIP users. As such, the VIP FastPass function is introduced to improve VIP user experience on the air interface. This function enables APs to provide deterministic air interface preemption capabilities for VIP users.

Specifically, in a zero-roaming distributed scenario, when the 2.4 GHz frequency band experiences severe interference and the channel utilization exceeds 60%, you can configure the VIP FastPass function to prevent packet loss and frame freezing, thereby preferentially ensuring user experience of key services on the intranet. In the case of channel utilization higher than 60%, you are advised to set the number of FastPass users to 10, the FastPass scheduling period to 60 ms, and the percentage of FastPass users to 75%.

Example

# Set the number of FastPass users to 4 in the 2.4 GHz radio profile default.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] radio-2g-profile name default
[HUAWEI-wlan-radio-2g-prof-default] fastpass users 4
Info: The settings of the period and ratio parameters take effect only on DAPs.
