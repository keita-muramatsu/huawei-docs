reflect change-path-attribute (BGP IPv6 SR-Policy address family view)

Function

The reflect change-path-attribute command enables an RR to modify route attributes of BGP routes through an export policy.

The undo reflect change-path-attribute command disables an RR from modifying route attributes of BGP routes through an export policy.

By default, an RR is disabled from modifying route attributes of BGP routes through an export policy.

Format

reflect change-path-attribute

undo reflect change-path-attribute

Parameters

None

Views

BGP IPv6 SR-Policy address family view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

According to the standard protocol, the RR cannot modify the route attributes through the export policy because such configuration may cause routing loops. Therefore, by default, an RR is disabled from modifying route attributes using an export policy.

To replan network traffic, you can run the reflect change-path-attribute command to enable the RR to modify route attributes using an export policy. After the reflect change-path-attribute command is run on an RR, the configuration of modifying route attributes using an export policy takes effect immediately. The following configurations can take effect:

apply as-path: used to change the AS_Path attribute of BGP routes.

apply comm-filter delete: used to delete the community attributes of BGP routes.

apply community: used to modify the community attributes of BGP routes.

apply cost: used to change the MED values of BGP routes.

apply ip-address next-hop: used to change the next hop of a BGP route.

apply ipv6 next-hop: used to change the next hop of a BGP4+ route.

apply local-preference: used to modify the local preference of BGP routes.

apply origin: used to modify the Origin attribute of BGP routes.

apply extcommunity: used to modify the VPN targets of BGP routes.

apply extcommunity soo: used to modify the SoO extended community attributes of BGP routes.

If the undo reflect change-path-attribute command is run, the preceding configurations on the RR do not take effect.

Precautions

If an export policy has been configured on the RR, the configurations of the policy do not take effect before the reflect change-path-attribute command is run. After the reflect change-path-attribute command is run, these configurations may take effect, which may affect BGP route selection. Therefore, exercise caution when running the reflect change-path-attribute command.

Note:

After the reflect change-path-attribute command is run on an RR, the peer route-policy export command takes precedence over the peer next-hop-invariable and peer next-hop-local commands.

Example

# Enable an RR to modify path attributes of BGP routes through an export policy.
<HUAWEI> system-view
[HUAWEI] bgp 100
[HUAWEI-bgp] ipv6-family sr-policy
[HUAWEI-bgp-af-ipv6-srpolicy] reflect change-path-attribute
