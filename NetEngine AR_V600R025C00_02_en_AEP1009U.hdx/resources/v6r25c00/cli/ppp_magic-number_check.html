ppp magic-number check

Function

The ppp magic-number check command enables the PPP magic number check function.

The undo ppp magic-number check command disables the PPP magic number check function.

By default, the PPP magic number check function is disabled.

Format

ppp magic-number check

undo ppp magic-number check

Parameters

None

Views

Dialer interface view, POS interface view, Serial interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

On a network where two devices are connected over intermediate transmission devices, if the two devices are incorrectly connected, the transmission devices will adjust the incorrect connections. However, the two devices are not aware of this adjustment because their interfaces do not become Down or Up, and consequently, LCP renegotiation between the two devices is not triggered. PPP-enabled interfaces learn host routes only during the LCP negotiation, the adjusted two interfaces, therefore, still learn the original host routes, causing a packet transmission error.

To allow a device to promptly be aware of the link status change, run the ppp magic-number check command to enable the PPP magic number check function. When the local device finds that the magic number carried in the Echo Reply packet from the remote device is inconsistent with that learned before, the local device will count the errors. After error statistics on an interface reach a specific threshold, the interface becomes Down, triggering an LCP renegotiation, during which, the interface re-learns the peer's host route.

Prerequisites

PPP is configured as the link layer protocol of the interface.

Precautions

After running this command, you need to run the shutdown and undo shutdown commands in sequence or run the restart command in the interface view for the configuration to take effect.

The ppp magic-number check command can be configured or deleted when there are online users.

Example

# Enable the magic number check function on Dialer95.
<HUAWEI> system-view
[HUAWEI] interface Dialer 95
[HUAWEI-Dialer95] ppp magic-number check
