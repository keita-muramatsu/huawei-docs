ftp-detect

Function

The ftp-detect enable command enables FTP detection.

The ftp-detect { direction { upload | download | both } | action { block | alert } } command sets the direction or action for FTP detection.

The ftp-detect direction { upload | both | download } action { block | alert } command configures the direction and action for FTP detection.

The undo ftp-detect enable command disables FTP detection.

The undo ftp-detect { direction | action } command configures the direction for FTP detection or restores the default direction or action for FTP detection.

The undo ftp-detect direction action command restores the default direction and action for FTP detection.

By default, FTP detection is enabled in both the upload and download directions, and the action is block.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

ftp-detect enable

ftp-detect { direction { upload | download | both } | action { block | alert } }

ftp-detect direction { upload | download | both } action { block | alert }

undo ftp-detect direction action

undo ftp-detect enable

undo ftp-detect { direction | action }

Parameters

Parameter Description Value
upload

The protocol transfer direction is upload.

-
download

The protocol transfer direction is download.

-
both

The protocol transmission direction is upload or download.

-
block

Set the action to Block. After detecting a virus, discard the packets and record a log.

-
alert

Set the action to alarm. After a virus is detected, the packets are permitted, but a log is recorded.

-

Views

Antivirus profile view

Default Level

2: Configuration level

Usage Guidelines

FTP detection is enabled by default. If it is disabled, FTP detection is not performed.

After the protocol detection direction is configured, the device detects only the files transferred in the specified direction. If malicious files are detected, the device takes the configured action.

Example

# Set the direction of FTP detection to upload and the action to alert. 
<HUAWEI> system-view
[HUAWEI] profile type av name protocol_detect
[HUAWEI-profile-av-protocol_detect] ftp-detect direction upload action alert
