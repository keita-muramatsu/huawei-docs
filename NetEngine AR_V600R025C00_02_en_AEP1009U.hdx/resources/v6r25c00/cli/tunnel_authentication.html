tunnel authentication

Function

The tunnel authentication command enables L2TP tunnel authentication.

The undo tunnel authentication command disables L2TP tunnel authentication.

By default, L2TP tunnel authentication is enabled.

Format

tunnel authentication

undo tunnel authentication

Parameters

None

Views

L2TP group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

For security purposes, tunnel authentication is enabled for L2TP by default. To test network connectivity or receive a connection request sent by an unknown remote end, you can disable tunnel authentication. You are advised to enable the L2TP tunnel authentication function.

Tunnel authentication can be initiated by either the L2TP client or the LNS. As long as one end is enabled with tunnel authentication, tunnel authentication is performed during tunnel establishment. A tunnel can be established only when the authentication keys on both ends are the same and are not empty. Otherwise, the tunnel is automatically disconnected and fails to be established. If tunnel authentication is disabled on both ends of a tunnel, the tunnel authentication key does not take effect.

Follow-up Procedure

Run the tunnel password command to configure the tunnel authentication key. The same authentication key must be configured on the L2TP client and LNS.

Precautions

By default, L2TP tunnel authentication is enabled, but the tunnel authentication key is not configured. When the default configuration is used to establish an L2TP connection, the tunnel authentication fails and the L2TP tunnel cannot be established.

If an L2TP connection has been established in an L2TP group, running the undo tunnel authentication command to disable L2TP tunnel authentication will disconnect the L2TP tunnel and session. Therefore, exercise caution when running this command.

Example

# Disable tunnel authentication.
<HUAWEI> system-view
[HUAWEI] l2tp-group 1
[HUAWEI-l2tp-group-1] undo tunnel authentication
Warning: This operation may cause traffic interruption, Continue? [Y/N]:
