user-queue

Function

The user-queue command sets QoS parameters of a subscriber queue in a subscriber queue profile.

The undo user-queue command deletes a specified subscriber queue from a subscriber queue profile.

By default, QoS parameters are configured for a subscriber queue in a subscriber queue profile.

Format

For AR8100 series, AR6700-H series, AR8700 series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5700-H series, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR5710-S8TWDSE-LTE4EA, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S:

user-queue user-name { pq | drr weight weight-value } { cir cir-value [ cbs cbs-value ] [ pir pir-value [ pbs pbs-value ] ] | cir-percentage cir-percentage-value [ cbs cbs-value ] [ pir-percentage pir-percentage-value [ pbs pbs-value ] ] }

For AR8100 series, AR6700-H series, AR8700 series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L14T2X4, AR5700-H series, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR5710-S8TWDSE-LTE4EA, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S:

For AR6710-L14T2X4:

user-queue user-name { pq | drr weight weight-value } { cir cir-value [ cbs cbs-value ] | cir-percentage cir-percentage-value [ cbs cbs-value ] }

Parameters

Parameter Description Value
user-name

Specifies the name of a subscriber queue.

The value is a string of 1 to 31 case-sensitive characters. It must start with a letter or digit.
pq

Specifies PQ scheduling.

-
drr

Specifies WDRR scheduling.

-
weight weight-value

Specifies the WDRR weight.

The value is an integer ranging from 1 to 100.
cir cir-value

Specifies the CIR. It cannot exceed the interface bandwidth.

The value is an integer that ranges from 64 to 100000000, in kbit/s.
cbs cbs-value

Specifies the CBS.

The value is an integer ranging from 0 to 4194304, in bytes. By default, the CBS value is 25 times the CIR value.
pir pir-value

Specifies the PIR. It cannot exceed the interface bandwidth.

The value is an integer that ranges from 64 to 100000000, in kbit/s. If pir pir-value is not specified for the SQ profile, the value of pir-value is the same as that of cir-value.
pbs pbs-value

Specifies the PBS.

The value is an integer that ranges from 0 to 4194304, in bytes. By default, the PBS value is 25 times the PIR value.
cir-percentage cir-percentage-value

Specifies the CIR percentage.

The value is an integer ranging from 1 to 100.
pir-percentage pir-percentage-value

Specifies the PIR percentage of a subscriber queue.

The value is an integer ranging from 1 to 100.

Views

Qos user profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The QoS parameters that can be configured in a subscriber queue profile include the scheduling mode and shaping parameters of subscriber queues.

Precautions

  • In each traffic policy, a maximum of four subscriber queues using PQ scheduling can be configured.

Example

# Set QoS parameters for the subscriber queue named user1 in the subscriber queue profile named p1.
<HUAWEI> system-view
[HUAWEI] qos-user-profile p1
[HUAWEI-qos-user-profile-p1] user-queue user1 drr weight 30 cir 200
