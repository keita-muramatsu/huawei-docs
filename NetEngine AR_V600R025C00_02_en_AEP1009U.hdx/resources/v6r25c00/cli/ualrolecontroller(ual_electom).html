ual role controller

Function

The ual role controller command configures the master role.

The undo ual role controller command cancels the master role.

By default, a device is a common NE.

Format

ual role controller

undo ual role controller

Parameters

None

Views

System view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

Based on the constrained application protocol (CoAP), the Ubiquitous Autonomy Link (UAL) protocol implements autonomous network configuration, connection, and diagnosis using key technologies such as management device election and network element (NE) discovery.

Two roles are available for devices on a network running the UAL protocol:

Master: After NEs are powered on, the NE having the master election capability can be elected as the master device. The master device uses the UAL protocol to implement automated network management.

Member: network device managed by the master device.

Precautions

  • After the ual role controller command is run on a device, if the device is elected as the master device, a Virtual-Meth0 interface and a virtual IPv4 address are dynamically created.
  • If the device has been discovered by the master device and the system MAC address of the device changes due to user configuration or environment changes, you need to manually delete the device corresponding to the old MAC address and manage the device corresponding to the new MAC address.

Example

# Configure the master role.
<HUAWEI> system-view
[HUAWEI] ual role controller
