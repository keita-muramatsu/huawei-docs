evpn ext-udp enable

Function

The evpn ext-udp enable command enables the function of adding a UDP header to packets in an SD-WAN tunnel.

The undo evpn ext-udp enable command disables the function of adding a UDP header to packets in an SD-WAN tunnel.

By default, the function of adding a UDP header to packets in an SD-WAN tunnel is disabled

Format

evpn ext-udp enable

undo evpn ext-udp enable

Parameters

None

Views

Site view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In SD-WAN non-encryption scenarios, the use of EVPN GRE extension headers does not comply with common network standards. As a result, packets cannot be identified and may be out of order in some network environments. To ensure that other network devices can correctly identify packets, run the evpn ext-udp enable command to enable the function of adding a UDP header to packets in an SD-WAN tunnel.

Precautions

· This function can be configured at both ends or at only one end. Regardless of the deployment approach, the remote device must support the function to ensure proper operation. If this function is configured on a single end, only the end with this function configured append the additional proprietary header (UDP + 0x000000FE) to packets.

· If the evpn ext-udp enable command is run only on the transmit end, the receive end processes packets with both the source and destination port numbers being 4755 by default.

· After this function is enabled, the overlay MTU is reduced by 12 bytes, regardless of whether encryption is applied. This impacts packet fragmentation on the overlay network.

Example

# Enable the function of adding a UDP header to packets in an SD-WAN tunnel.
<HUAWEI> system-view
[HUAWEI] evpn site 1
[HUAWEI-site-1] evpn ext-udp enable
