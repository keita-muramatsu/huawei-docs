nat pat alarm enhance enable

Function

The nat pat alarm enhance enable command enables the enhanced alarm function for NAT in PAT mode.

The undo nat pat alarm enhance enable command disables the enhanced alarm function for NAT in PAT mode.

By default, the enhanced alarm function is disabled for NAT in PAT mode.

Format

nat pat alarm enhance enable

undo nat pat alarm enhance enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

When the address pool mode of source NAT is PAT, you can run the nat pat alarm enhance enable command to enable the enhanced alarm function to accurately monitor the usage of address pool resources for the same destination IP address, port number, and protocol. The alarm information contains the destination IP address, port number, and protocol. When this function is enabled, the device checks for IP address allocation failures at the interval of 10 seconds. If the number of times an IP address fails to be allocated in a certain period of time reaches the threshold (1000 by default), the device sends the hwSecTrapNatPatToDstIPConflictOverThreshold alarm to the NMS. If the device does not detect any allocation failures of this IP address in the following period of time, the device sends the clear alarm hwSecTrapNatPatToDstIPConflictClear to the NMS. A device can collect statistics about a maximum of 1024 IP addresses. For each PAT address pool, address allocation failures can be monitored for a maximum of 10 IP addresses.

Example

# Enable the enhanced alarm function for NAT in PAT mode.
<HUAWEI> system-view
[HUAWEI] nat pat alarm enhance enable
