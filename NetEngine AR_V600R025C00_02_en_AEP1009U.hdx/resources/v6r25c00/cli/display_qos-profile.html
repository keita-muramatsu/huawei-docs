display qos-profile

Function

The display qos-profile command displays information about a configured QoS profile.

Format

display qos-profile name profile-name

display qos-profile all

Parameters

Parameter Description Value
all

Displays all QoS profiles.

-
name profile-name

Displays a specified QoS profile.

The value must be the name of an existing profile on the device.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

This command displays the configuration of a specified QoS profile or all QoS profiles. The command output helps you learn about the current configuration of each parameter in the QoS profile, check whether the configuration is correct, and locate faults.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display information about a created profile.
<HUAWEI> system-view
[HUAWEI] qos-profile demo
[HUAWEI-qos-profile-demo] quit
[HUAWEI] display qos-profile name demo
