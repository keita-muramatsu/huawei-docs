authentication roam pre-authen mac-authen enable

Function

The authentication roam pre-authen mac-authen enable command enables MAC address authentication for roaming users.

The undo authentication roam pre-authen mac-authen enable command disables MAC address authentication for roaming users.

By default, MAC address authentication is disabled for roaming users.

Format

authentication roam pre-authen mac-authen enable

undo authentication roam pre-authen mac-authen enable

Parameters

None

Views

Authentication profile view

Default Level

2: Configuration level

Usage Guidelines

For a user configured with authentication event authorization information, if the user accesses the network through MAC address authentication and roams, MAC address authentication is triggered. In this case, MAC address authentication may fail, and the user enters the pre-connection state and does not have the original access rights. The default value is recommended.

Example

# Enable MAC address authentication for roaming users.
<HUAWEI> system-view
[HUAWEI] authentication-profile name test
[HUAWEI-authen-profile-test] authentication roam pre-authen mac-authen enable
