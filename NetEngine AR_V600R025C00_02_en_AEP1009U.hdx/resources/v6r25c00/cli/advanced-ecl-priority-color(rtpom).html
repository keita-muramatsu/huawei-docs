ip extcommunity-list priority-color advanced

Function

The ip extcommunity-list priority-color advanced command configures an advanced priority-color extended community filter.

The undo ip extcommunity-list priority-color advanced command deletes a specified advanced priority-color extended community filter.

By default, no advanced priority-color extended community filter is configured.

Format

ip extcommunity-list priority-color advanced advanced-extcomm-filter-name [ index index-value ] matchMode regular

undo ip extcommunity-list priority-color advanced advanced-extcomm-filter-name [ index index-value ] [ matchMode regular ]

Parameters

Parameter Description Value
advanced-extcomm-filter-name

Specifies the name of an advanced priority-color extended community filter.

The value is a string of 1 to 51 case-sensitive characters. It cannot be comprised of only digits. If spaces are used, the string must start and end with double quotation marks (").
index index-value

Specifies the index of an advanced priority-color extended community filter.

The value is an integer ranging from 1 to 4294967295.
matchMode

Specifies a matching mode for an advanced priority-color extended community filter.

The value is an enumerated type:

  • permit: sets the matching mode of the priority-color extended community filter to permit.
  • deny: sets the matching mode of the priority-color extended community filter to deny.
regular

Specifies a regular expression for matching the priority-color extended community attribute.

The value is a string of 1 to 1024 characters and can contain spaces.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In scenarios where an SD-WAN tunnel needs to be established based on BGP EVPN routes, you can set the priority-color extended community attribute for EVPN routes to identify the next-hop sites of the EVPN routes. The priority-color extended community attribute is used to generate SD-WAN tunnel encapsulation information so that a device can forward packets through the SD-WAN tunnel.

To configure an advanced priority-color extended community filter, run the ip extcommunity-list priority-color advanced command. The filter can be used as a filtering rule of a route-policy. For example, the if-match extcommunity-list priority-color aaa command configures a filtering rule that is based on the priority-color extended community filter named aaa.

Only values of the priority-color extended community attribute can be specified as matching conditions in a basic priority-color extended community filter, whereas regular expressions can be specified as matching conditions in an advanced priority-color extended community filter.

To check detailed configurations of priority-color extended community filters, run the display ip extcommunity-filter priority-color command.

Precautions

The default action of a Priority-Color extended community filter is deny. That is, if a route is not permitted by a filtering rule, the route cannot pass the filtering of the filter. If all the filtering rules in a filter are in deny mode, no route can pass the filter. To prevent this problem, configure a filtering rule in permit mode after configuring one or more filtering rules in deny mode. This allows other routes to pass the filter.

A basic Priority-Color extended community filter and an advanced one cannot both be configured.

Regular expression matching is CPU computing-intensive. When a large number of regular expressions are configured in a route-policy to match route attributes and the corresponding route attributes are long, the route-policy processing performance deteriorates. To improve the route-policy processing performance, decrease the number of regular expressions or use non-regular expression matching commands.

A maximum of 65535 advanced Priority-Color extended community filters are supported.

A single advanced Priority-Color extended community filter supports a maximum of 65535 nodes.

All advanced Priority-Color extended community filters support a maximum of 65535 nodes.

Example

# Configure an advanced priority-color extended community filter named aaa.
<HUAWEI> system-view
[HUAWEI] ip extcommunity-list priority-color advanced aaa permit ^1:100 2:200$
