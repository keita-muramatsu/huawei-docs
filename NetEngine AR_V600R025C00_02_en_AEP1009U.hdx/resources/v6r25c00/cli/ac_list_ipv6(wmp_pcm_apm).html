ac-list ipv6 (AP view/AP provisioning view)

Function

The ac-list ipv6 command configures a WAC IPv6 address list for APs.

The undo ac-list ipv6 command restores the default WAC IPv6 address list for APs.

By default, no WAC IPv6 address list is configured.

Format

ac-list ipv6 { ipv6-address } &<1-4>

undo ac-list ipv6

Parameters

Parameter Description Value
ipv6-address

Specifies the IPv6 address of a WAC.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.

Views

AP provisioning view, AP view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

You can run this command to statically configure a WAC IPv6 address list for APs.

In addition to the static configuration, APs can dynamically obtain a WAC IP address list through DHCP or DNS. When an AP goes online, it sends Discovery Request unicast packets to all WACs' IP addresses that are statically or dynamically obtained. After receiving the Discovery Request packets, the WACs respond to the AP with a Discovery Response packet. Based on WAC information such as the AP management capability, maximum number of access STAs, and IP address, the AP selects one WAC to establish a CAPWAP tunnel. If the AP does not have the WAC IP address list or receives no response to the Discovery Request packet, the AP broadcasts Discovery Request packets to discover WACs on the same network segment.

Follow-up Procedure

After running this command in the AP provisioning view, run the commit command to deliver the configuration to the AP. The configuration takes effect only after the AP restarts.

Precautions

After you run this command in the AP view to deliver the configuration, restart the AP for the configuration to take effect.

Example

# Configure the WAC's IPv6 address for the AP in the AP view.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-id 0
[HUAWEI-wlan-ap-0] ac-list ipv6 2001:db8:1::1
Warning: The incorrect configuration will cause the AP to go out of management. This operation will deliver parameter setting and may cause reboot of AP(s). Continue?[Y/N]:y
# Configure the WAC's IPv6 address for the AP in the AP provisioning view.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] provision-ap
[HUAWEI-wlan-provision-ap] ac-list ipv6 2001:db8:1::1
