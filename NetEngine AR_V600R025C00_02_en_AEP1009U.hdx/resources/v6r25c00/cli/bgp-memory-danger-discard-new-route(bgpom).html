bgp memory-usage danger-threshold

Function

The bgp memory-usage danger-threshold command configures a mode for BGP to process newly received routes when the device memory is in the danger state.

The undo bgp memory-usage danger-threshold command restores the default setting.

By default, BGP does not discard new routes when the memory is in the danger state.

Format

bgp memory-usage danger-threshold discard new-route

bgp memory-usage danger-threshold discard new-route include { vrf-import-route | vrf-export-route } *

undo bgp memory-usage danger-threshold discard new-route

undo bgp memory-usage danger-threshold discard new-route include { vrf-import-route | vrf-export-route } *

Parameters

Parameter Description Value
discard

Configures the device to slow down the reception of new routes from peers when the device memory is in the warning state and discard the routes newly received from peers when the device memory in the danger state.

-
new-route

Indicates the routes newly received from peers.

-
include

Include.

-
vrf-import-route

Indicates the routes newly leaked from VPN address families to a VPN instance.

-
vrf-export-route

Indicates the routes newly advertised from a VPN instance to VPN address families.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The memory warning state refers to the state when the memory usage of a device exceeds the warning threshold (also called the notification threshold). The default threshold is 70. You can set the threshold by setting notice-threshold notice-threshold-value in the memory-usage reliability command.

The memory danger state refers to the state when the memory usage of the device exceeds the danger threshold (also called the overload threshold). The default threshold is 85. You can set the threshold by setting overload-threshold overload-threshold-value in the memory-usage reliability command.

You can run the bgp memory-usage danger-threshold discard new-route command to slow down BGP route learning when the memory is in the warning state and to discard the routes newly received from IPv4 and IPv6 peers when the memory is in the danger state and the memory usage of the BGP component ranks in the top 3. The update and withdrawal of existing routes are not affected by this command.

You can run the bgp memory-usage danger-threshold discard new-route include vrf-import-route command to configure the device to discard the routes newly received from IPv4 and IPv6 peers and the routes newly leaked from the VPNv4 address family to VPN instances when the memory is in the danger state and the memory usage of the BGP component ranks in the top 3. The update and withdrawal of existing routes are not affected by this command.

You can run the bgp memory-usage danger-threshold discard new-route include vrf-export-route command to configure the device to discard the routes newly received from IPv4 and IPv6 peers and the routes advertised from VPN instances to the VPNv4 address family when the memory is in the danger state and the memory usage of the BGP component ranks in the top 3. The update and withdrawal of existing routes are not affected by this command.

Precautions

If the bgp memory-usage danger-threshold discard new-route command is run and the device memory enters the danger state, the device cannot learn the routes newly sent by peers, which may affect related services. Therefore, exercise caution when running this command.

If the bgp memory-usage danger-threshold discard new-route include vrf-import-route command is run and the device memory enters the danger state, the device cannot learn the routes newly sent by peers or newly leaked routes, which may affect related services. Therefore, exercise caution when running this command.

If the bgp memory-usage danger-threshold discard new-route include vrf-export-route command is run and the device memory enters the danger state, the device cannot learn the routes newly sent by peers or the routes newly advertised by VPN instances to VPN address families, which may affect related services. Therefore, exercise caution when running this command.

Example

# Enable BGP to discard newly received routes when the memory of the device is in danger state.
<HUAWEI> system-view
[HUAWEI] bgp memory-usage danger-threshold discard new-route
