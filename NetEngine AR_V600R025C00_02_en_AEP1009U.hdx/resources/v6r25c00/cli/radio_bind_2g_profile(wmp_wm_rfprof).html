radio-2g-profile(AP view/AP group view)

Function

The radio-2g-profile command binds a 2.4G radio profile to a radio.

The undo radio-2g-profile command unbinds a 2.4G radio profile from a radio.

By default, no 2.4G radio profile is applied in the AP view or AP radio view, and the 2.4G radio profile default is applied in the AP group view and AP group radio view.

Format

radio-2g-profile profile-name radio { radio-id | all }

undo radio-2g-profile radio { radio-id | all }

Parameters

Parameter Description Value
profile-name

Specifies the name of a 2.4G radio profile.

The 2.4G radio profile must exist.
radio radio-id

Specifies a radio ID. This command is supported only in the AP view or AP group view.

The value is an integer ranging from 0 to 4.
all

Specifies all radios. This command is supported only in the AP view or AP group view.

-

Views

AP group view, AP view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After you create a 2.4G radio profile using the radio-2g-profile name command, bind it to a 2.4G radio so that the created radio profile can take effect.

Precautions

After a 2.4G radio profile is applied in the AP group view or AP view, the parameter settings in the profile take effect on all 2.4G radios in the AP group or the 2.4G radio of the AP.

The configuration in the AP view and AP radio view has a higher priority than that in the AP group view and AP group radio view.

Example

# Create the 2.4G radio profile radio-profile1 and apply the radio profile to the AP group group1.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] radio-2g-profile name radio-profile1
[HUAWEI-wlan-radio-2g-prof-radio-profile1] quit
[HUAWEI-wlan] ap-group name group1
[HUAWEI-wlan-ap-group-group1] radio-2g-profile radio-profile1 radio 0
