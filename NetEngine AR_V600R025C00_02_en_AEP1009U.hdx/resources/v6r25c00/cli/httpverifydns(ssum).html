http verify-dns enable

Function

The http verify-dns enable command enables CN/SAN verification when the device connects to the HOUP during smart upgrade.

The undo http verify-dns enable command disables CN/SAN verification when the device connects to the HOUP during smart upgrade.

By default, CN/SAN verification is disabled.

Format

http verify-dns enable

undo http verify-dns enable

Parameters

None

Views

Smart upgrade view

Default Level

3: Management level

Usage Guidelines

When a device uses HTTPS to connect to the HOUP during smart upgrade and the HTTPS connection is bound to an SSL policy, you can enable CN/SAN verification to ensure the security and validity of the connection.

Example

# Enable CN/SAN verification when the device connects to the HOUP during smart upgrade.
<HUAWEI> system-view
[HUAWEI] smart-upgrade
[HUAWEI-smart-upgrade] http verify-dns enable
Info: The configuration is successful.
# Disable CN/SAN verification when the device connects to the HOUP during smart upgrade.
<HUAWEI> system-view
[HUAWEI] smart-upgrade
[HUAWEI-smart-upgrade] undo http verify-dns enable
Warning: This operation will disable verification on the peer certificate CN/SAN, which has security risks. Continue? [Y/N]:y
Info: The configuration is canceled successfully.
