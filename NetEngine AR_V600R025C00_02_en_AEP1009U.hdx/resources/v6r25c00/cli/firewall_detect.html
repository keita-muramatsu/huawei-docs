firewall detect

Function

The firewall detect command configures the global ASPF/ALG function.

The undo firewall detect command cancels the ASPF/ALG configuration.

By default, the ASPF/ALG function is disabled.

Format

firewall detect protocol

firewall detect ipv6 ipv6-protocol

undo firewall detect protocol

undo firewall detect ipv6 ipv6-protocol

Parameters

Parameter Description Value
protocol

Specifies one of the protocols supported by IPv4 ASPF/ALG.

The options are as follows:

  • ftp
  • sip
  • pptp
  • rtsp
  • dns
ipv6 ipv6-protocol

Specifies one of the protocols supported by IPv6 ASPF/ALG.

The value can be:

  • ftp
  • rtsp
  • sip

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The global SIP ASPF/ALG function configured using the firewall detect sip command takes effect only for UDP-based SIP traffic.

Example

# Enable the IPv4 ASPF/ALG function to filter out FTP packets. 
<HUAWEI> system-view
[HUAWEI] firewall detect ftp
