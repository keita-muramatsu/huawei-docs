display ap traffic statistics wireless

Function

The display ap traffic statistics wireless command displays packet statistics on a specified AP radio.

Format

display ap traffic statistics wireless ap-id ap-id radio radio-id [ ssid ssid ]

Parameters

Parameter Description Value
ap-id ap-id

Specifies an AP name.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
radio radio-id

Specifies the radio ID.

The value is an integer that ranges from 0 to 2.
ssid ssid

Specifies the SSID that STAs associate with.

The value is a string of 1 to 32 characters. It can contain spaces.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run this command to view packet statistics on a specified AP radio.

For APs running V200R019C10:

  • After an AP performs self-healing, packet statistics on the AP radios are cleared.
  • The following items in the command output are displayed as 0 because the corresponding functions are not supported:
  • Wireless error frames(RX)
  • Wireless physical layer error frames(RX)
  • Wireless MIC error frames(RX)
  • Wireless port PLR(%)
  • Wireless port PLR of the last 5min(%)
  • Wireless retransmitted rate(%)
  • Wireless retransmitted rate of the last 5min(%)
  • WMM AC_BE retry ratio(%)
  • WMM AC_BK retry ratio(%)
  • WMM AC_VI retry ratio(%)
  • WMM AC_VO retry ratio(%)
  • WMM AC_BE PLR(%)
  • WMM AC_BK PLR(%)
  • WMM AC_VI PLR(%)
  • WMM AC_VO PLR(%)
