capwap ipv6 enable

Function

The capwap ipv6 enable command enables the IPv6 function for CAPWAP links.

The undo capwap ipv6 enable command restores the default CAPWAP link mode.

By default, the CAPWAP link works in IPv4 single-stack mode.

Format

capwap ipv6 enable

undo capwap ipv6 enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

  • When APs and WACs are deployed on an IPv6 network and use IPv6 addresses, you can run the capwap ipv6 enable command to enable the IPv6 function of CAPWAP links so that the WACs manage the APs through the IPv6 network.

  • When APs and WACs are deployed on an IPv4 + IPv6 network, you can run the capwap double-stack enable command to enable the dual-stack function of CAPWAP links so that the WACs manage the APs through the IPv4 and IPv6 networks.

  • When APs and ACs are deployed on an IPv4 network, run the undo capwap ipv6 enable or undo capwap double-stack enable command to disable the IPv6 function of CAPWAP links so that the ACs manage the APs through the IPv4 network.

Prerequisites

No source interface or source address is configured on the AC.

The dual-link command related to the IPv4 address is not configured on the AC.

Example

# Enable the IPv6 function for CAPWAP links on the device.
<HUAWEI> system-view
[HUAWEI] capwap ipv6 enable
