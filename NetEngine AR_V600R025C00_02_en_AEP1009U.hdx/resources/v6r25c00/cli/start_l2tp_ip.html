start l2tp ip

Function

The start l2tp ip command specifies the trigger condition for initiating a call when the local end functions as an L2TP client.

The undo start l2tp ip command deletes the specified trigger condition.

By default, no trigger condition is configured on the device.

Format

start l2tp ip ip-address &<1-5>

undo start l2tp ip [ ip-address ] &<1-5>

Parameters

Parameter Description Value
ip ip-address

Specifies the IP address of an LNS. You can specify a maximum of five LNS IP addresses to configure them to work in active/standby mode. The IP address configured first has a higher priority.

The value is in dotted decimal notation.

Views

L2TP group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Using the start l2tp ip command, you can trigger an L2TP connection request. The connection request is set up based on the IP address of the specified LNS server. Multiple LNS IP addresses can be configured for backup. The IP address configured earlier has a higher priority. After establishing an L2TP tunnel with an LNS, the L2TP client does not attempt to establish connections with other LNSs.

If all attempts to set up an L2TP connection with an IP address fail and the start l2tp host command is configured for the L2TP group, the device attempts to set up an L2TP connection based on the domain name of the specified LNS server.

The L2TP client automatically dials up. If all attempts to set up an L2TP connection fail, the L2TP client attempts to set up a new L2TP connection at a specified interval until the L2TP connection is set up successfully.

Precautions

If both the start l2tp ip and start l2tp host commands are configured, the start l2tp ip command has a higher priority.

If an L2TP connection has been established based on an IP address in the L2TP group, deleting the trigger condition of the IP address will disconnect the L2TP connection. Therefore, exercise caution when running this command.

Example

# Set up an L2TP connection with the LNS with the IP address 1.1.1.1 at the headquarters.
<HUAWEI> system-view
[HUAWEI] l2tp-group 1
[HUAWEI-l2tp-group-1] start l2tp ip 1.1.1.1
