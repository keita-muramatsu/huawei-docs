ignore-check-tlv lsp

Function

The ignore-check-tlv lsp command configures the device to ignore the content of specified TLVs in LSPs.

The undo ignore-check-tlv lsp command cancels the configuration of ignoring the content of specified TLVs in LSPs.

By default, no TLV in LSPs is ignored.

Format

ignore-check-tlv lsp [ system-id lspIdStr | lsp-id lspIdStr ] tlv tlv-type1

ignore-check-tlv lsp [ system-id lspIdStr | lsp-id lspIdStr ] tlv tlv-type2 sub-tlv sub-tlv-type2

ignore-check-tlv lsp [ system-id lspIdStr | lsp-id lspIdStr ] tlv tlv-type3 sub-tlv sub-tlv-type3 sub-sub-tlv sub-sub-tlv-type3 [ force-ignore ]

undo ignore-check-tlv lsp [ system-id lspIdStr | lsp-id lspIdStr ] tlv tlv-type1

undo ignore-check-tlv lsp [ system-id lspIdStr | lsp-id lspIdStr ] tlv tlv-type2 sub-tlv sub-tlv-type2

undo ignore-check-tlv lsp [ system-id lspIdStr | lsp-id lspIdStr ] tlv tlv-type3 sub-tlv sub-tlv-type3 sub-sub-tlv sub-sub-tlv-type3 [ force-ignore ]

Parameters

Parameter Description Value
system-id lspIdStr

Specifies an IS-IS system ID.

The value is a string of 14 characters in the format of ####.####.####, for example, 0050.0500.5004.
lsp-id lspIdStr

Specifies the ID of an LSP.

The value is a string of 20 characters in the format of ####.####.####.##-##, for example, 0050.0500.5004.00-00.
tlv tlv-type3 sub-tlv sub-tlv-type3 sub-sub-tlv sub-sub-tlv-type3

Specifies the main TLV type, sub-TLV type, and sub-sub-TLV type.

The value is an integer ranging from 1 to 255. For details about the configurable value range, see the command help.
tlv tlv-type1

Specifies the main TLV type.

The value is an integer ranging from 1 to 255. For details about the configurable value range, see the command help.
tlv tlv-type2 sub-tlv sub-tlv-type2

Specifies the main TLV type and sub-TLV type.

The value is an integer ranging from 1 to 255. For details about the configurable value range, see the command help.
force-ignore

Ignores the content in a TLV even if its content can be normally parsed.

-

Views

IS-IS view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In interworking with another device:

  • If the peer end sends an IS-IS LSP with a non-compliant main TLV, the local device discards the entire IS-IS LSP by default. As a result, the LSP cannot be used for route calculation, leading to service interruptions. If you do not want the local device to discard an entire LSP that carries an incorrect main TLV, run this command to ignore check on the content of the main TLV.
  • If the peer sends a TLV with a non-compliant sub-TLV, the local device discards the entire TLV by default. As a result, the content of other sub-TLVs in the TLV cannot be parsed, leading to service interruptions. If you do not want the local device to discard an entire TLV that carries an incorrect sub-TLV, run this command to ignore check on the content of the sub-TLV.
  • If the peer end sends a sub-TLV with a non-compliant sub-sub-TLV, the local device discards the entire sub-TLV by default. As a result, the content of other sub-sub-TLVs in the sub-TLV cannot be parsed, leading to service interruptions. If you do not want the local device to discard an entire sub-TLV that carries an incorrect sub-sub-TLV, run this command to ignore check on the content of the sub-sub-TLV.

This function affects how the local device parses received LSPs but leaves the original LSP message content unchanged.

Configuration Impact

You are advised to configure this command the same way on all devices on your network. If the configurations of the devices are inconsistent, they may parse the TLV attributes of IS-IS packets differently, possibly leading to errors. For example, the local device might calculate routing and forwarding entries differently than other devices, potentially causing routing loops.

Precautions

  • A maximum of 10 rules of ignoring TLV check can be configured for a single process.
  • If both the ignore-receive-lsp command and the ignore-check-tlv command are configured and their configurations overlap, the ignore-receive-lsp command configuration takes effect.
  • After the configuration is canceled, the saved LSPs are not re-parsed unless they are updated or a neighbor restart triggers LSDB resynchronization.

Example

# Configure the device to ignore the content of specified TLVs in IS-IS LSPs.
<HUAWEI> system-view
[HUAWEI] isis 1
[HUAWEI-isis-1] ignore-check-tlv lsp tlv 7
[HUAWEI-isis-1] ignore-check-tlv lsp tlv 238 sub-tlv 4
[HUAWEI-isis-1] ignore-check-tlv lsp tlv 27 sub-tlv 5 sub-sub-tlv 1 force-ignore
