firewall log session multi-host-mode concurrent

Function

The firewall log session multi-host-mode concurrent command enables the function of sending session logs concurrently.

The undo firewall log session multi-host-mode concurrent command disables the function of sending session logs concurrently.

By default, the log concurrency function is disabled. The device cyclically sends logs to multiple log servers one by one.

Format

firewall log session multi-host-mode concurrent

undo firewall log session multi-host-mode concurrent

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

After the log concurrency function is enabled, the device sends each log to all log hosts (including the log hosts in the backup group).

Example

# Enable the log concurrent sending function. 
<HUAWEI> system-view
[HUAWEI] firewall log session multi-host-mode concurrent
