auto create ap-type

Function

The auto create ap-type command imports AP types.

Format

auto create ap-type { type-id type-id | type type | all }

Parameters

Parameter Description Value
type-id type-id

Automatically imports the AP type with a specified ID.

The value is an integer ranging from 0 to 1023.
type type

Automatically imports the AP type with specified description.

The value is a string of 1 to 31 characters. It cannot contain question marks (?), and cannot start or end with double quotation marks (" ").
all

Automatically imports the types of all APs.

-

Views

WLAN view

Default Level

2: Configuration level

Usage Guidelines

If a new AP model cannot connect to the WAC, you can check whether the AP type has been created. To list the undefined AP types, run the display ap-type undefined record command. Then, run the auto create ap-type command to automatically import the AP types of these APs.

The WAC does not support the configuration for types of central APs running later versions and matching RUs.

Table Description of the auto create ap-type command output

Item Description
AP type AP type.
Type ID Index of an AP type.
Reason Reason why an AP type fails to be automatically imported, which can be:
  • This AP type already exists.
  • This type ID already exists.
  • Reached the maximum specifications of the AP type.

Example

# Configure the WAC to automatically import the types of all APs.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] auto create ap-type all
Info: 1 succeeded, 3 failed.
List of AP types that failed to be added:
Total : 3

----------------------------------------------------------------------------
