display dtls client connection

Function

The display dtls client connection command displays DTLS client connection information.

Format

display dtls client connection [ system-id system-id ]

Parameters

Parameter Description Value
system-id system-id

Specifies a system ID.

The value is in dotted decimal notation.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

After a DTLS client connection is configured when data is transmitted using DTLS, you can run the display dtls client connection command to check DTLS client connection information.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display DTLS client connection information.
<HUAWEI> system-view
[HUAWEI] display dtls client connection
 Dtls client total: 1                                                
 -----------------------------------------------------------------------
 Pki-realm(current): default(default)  
 Cipher-suite:       ecdhe_rsa_aes256_gcm_sha384
                     ecdhe_rsa_aes128_gcm_sha256
 -----------------------------------------------------------------------
 SystemId: 1.1.1.1 total:1                                              
  Peer:      10.1.1.2:15000                                             
  Vpn:       --                                                         
  Status:    close                                                      
  DetectResult: up         DetectStatistic(send/receive): 0/0           
 -----------------------------------------------------------------------
Table 1 Description of the display dtls client connection command output
Item Description
Dtls client total

Number of clients configured based on the system ID.
SystemId

System ID, which identifies a device.
Peer

Peer IP address and port.
Vpn

Local VPN instance name.
Status

Status of registration with the server:

  • close: The DTLS connection is closed.
  • init: The DTLS connection is being initializing.
  • registering: The client is registering with the server.
DetectResult

Client detection state (up/down).
DetectStatistic(send/receive)

Detection statistics (sent/received packets).
Cipher-suite

Cipher suite configured for the client.
total

Number of peers configured in the current system ID.
Pki-realm(current)

PKI realm (current).
