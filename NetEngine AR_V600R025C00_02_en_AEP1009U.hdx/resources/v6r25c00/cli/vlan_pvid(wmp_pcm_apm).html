vlan pvid(AP wired port profile view)

Function

The vlan pvid command configures a PVID for an AP's wired interface.

The undo vlan pvid command deletes the PVID of an AP's wired interface.

By default, the PVID of an AP's wired interface is 1.

Format

vlan pvid vlan-id

undo vlan pvid

Parameters

Parameter Description Value
vlan-id

Specifies the PVID of an AP wired interface.

The value is an integer ranging from 1 to 4094.

Views

AP wired port profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

An AP's wired interface may receive untagged frames from a peer device. In this case, the AP must add a tag to the received untagged frames. To meet this requirement, run this command to configure the PVID for the AP's wired interface. When the interface receives untagged frames, it tags the frames with the PVID.

Precautions

Eth-Trunk member interfaces do not support the PVID configuration.

The PVID of an AP's wired interface can be configured in the following scenarios:

  • When the AP's wired interface works in root mode and the management-vlan vlan-idcommand has been executed to configure CAPWAP packets sent from the AP wired interface to carry the management VLAN tag, the PVID must be the same as the management-vlan value.
  • When the AP's wired interface works in endpoint mode, the PVID can be directly configured.
  • When the AP's wired interface works in middle mode, the PVID cannot be configured.

Example

# Set the PVID of an AP's wired interface to VLAN 10.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] wired-port-profile name wired-port1
[HUAWEI-wlan-wired-port-wired-port1] mode endpoint
Warning: If the AP goes online through a wired port, the incorrect port mode configuration will cause the AP to go out of management. This fault can be recovered only by modifying the configuration on the AP. Continue? [Y/N]:y                                      
Warning: This action will take effect after resetting fit AP.                                                                       
[HUAWEI-wlan-wired-port-wired-port1] vlan pvid 10
Warning: If the AP goes online through a wired port, the incorrect port configuration will cause the AP to go out of management. This fault can be recovered only by modifying the configuration on the AP. Continue? [Y/N]:y
[HUAWEI-wlan-wired-port-wired-port1] quit
