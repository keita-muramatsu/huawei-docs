hrp interface

Function

The hrp interface command specifies the heartbeat interface.

The undo hrp interface command deletes the heartbeat interface configuration.

By default, the HRP heartbeat interface is not set on the active and standby devices.

Format

hrp interface { interface-type interface-number | interface-name } remote { ipv4-address | ipv6-address } [ heartbeat-only ]

undo hrp interface { interface-type interface-number | interface-name }

Parameters

Parameter Description Value
interface-type

Specifies an interface type.

The interface type can be layer-3 Ethernet and its subinterface, layer-3 Eth-Trunk and its subinterface, or VLANIF.
interface-number

Specifies an interface number.

-
interface-name

Specifies an interface name.

-
remote ipv4-address

Specifies the IPv4 address of the peer heartbeat interface.

The value is in dotted decimal notation. Only the primary IP address of an interface can be used.
remote ipv6-address

Specifies the IPv6 address of the peer heartbeat interface.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
heartbeat-only

Configures the heartbeat interface only to transmit the control negotiation packets of HRP, but not back up connection status.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

In hot standby networking, two devices notify each other of their status through HRP heartbeat packets, link detection packets, and data packets. These packets need to be sent to the peer end through the heartbeat interface.

Example

# Configure 10GE0/0/1 as the heartbeat interface.
<HUAWEI> system-view
[HUAWEI] hrp interface 10GE 0/0/1 remote 10.1.1.1
