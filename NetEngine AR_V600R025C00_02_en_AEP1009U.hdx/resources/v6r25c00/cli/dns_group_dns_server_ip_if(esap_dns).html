dns server (DNS group view)

Function

The dns server command configures a DNS server address and source interface in a DNS group.

The undo dns server command deletes the DNS server address and source interface configured in a DNS group.

By default, no DNS server address or source interface is configured in a DNS group.

Format

dns server server-address [ source-interface { interface-type interface-number | interface-name } ]

undo dns server server-address [ source-interface { interface-type interface-number | interface-name } ]

Parameters

Parameter Description Value
server-address

Specifies an IPv4 address for a DNS server.

The value is in dotted decimal notation.
source-interface

Indicates the source interface for DNS users.

-
interface-type

Specifies an interface type.

Enumerated type. Set the value according to the device configuration.
interface-number

Specifies an interface number.

The value is a string of 1 to 255 characters.
interface-name

Specifies an interface name.

The value is a string of 1 to 255 characters.

Views

DNS group view

Default Level

2: Configuration level

Usage Guidelines

To configure a DNS server address and source interface in a DNS group, run this command.

Example

# Configure a DNS server address and source interface in a DNS group.
<HUAWEI> system-view
[HUAWEI] dns group test
[HUAWEI-dns-group-test] dns server 10.1.1.1 source-interface 10GE 0/0/1
