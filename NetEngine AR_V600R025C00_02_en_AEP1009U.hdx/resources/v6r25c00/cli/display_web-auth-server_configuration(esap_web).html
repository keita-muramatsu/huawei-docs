display web-auth-server configuration

Function

The display web-auth-server configuration command displays the Portal server configuration.

Format

display web-auth-server configuration

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

After a Portal server template is configured, you can run this command to check the Portal server configuration.

Example

The actual command output varies according to the device. The command output here is only an example.

Table 1 Description of the display web-auth-server configuration command output
Item Description
Listening port

Listening port of Portal protocol packets.

To configure this parameter, run the web-auth-server listening-port command.
Portal

Portal protocol version.

·version 1, version 2, version 3: Versions 3, 2, and 1 are supported.

·version 2, version 3: Both versions 2 and 3 are supported.

·version 3: Version 3 is supported.

To configure this parameter, run the web-auth-server version command.
Include reply message

Whether the packets sent from the device to the Portal server carry authentication response information.

•enabled.

•disabled.

To configure this parameter, run the web-auth-server reply-message command.
Server-Source

Local gateway address used by the device to receive and respond to packets sent by the Portal server in Portal authentication.

To configure this parameter, run the web-auth-server server-source (system view) command.
Web-auth-server Name

Name of the Portal server template.

To configure this parameter, run the web-auth-server (system view) command.
Web-auth-server Index

Index of the Portal service index profile.
IP-address

IPv4 address of the Portal server.

To configure this parameter, run the server-ip (Portal server template view) command.
IPv6 Address

IPv6 address of the Portal server.
Shared-key

Shared key.

To configure this parameter, run the shared-key (Portal server template view) command.
Source-IP

IP address used for communication with the Portal server.

To configure this parameter, run the source-ip (Portal server template view) command.
Port / PortFlag

·Port: port number of the server.

·PortFlag: whether to always use the server port to send packets.

To configure this parameter, run the port (Portal server profile view) command.
URL

URL of the Portal server.

To configure this parameter, run the url (Portal server template view) command.
URL Template

URL template bound to the Portal server template.

To configure this parameter, run the url-template (Portal server template view) command.
URL Template ParaName

Name of the encrypted URL parameter.

To configure this parameter, run the url-template (Portal server template view) command.
URL Template IVName

Initialization vector used for encrypting URL parameters.

To configure this parameter, run the url-template (Portal server template view) command.
URL Template Key

Key used for encrypting URL parameters.

To configure this parameter, run the url-template (Portal server template view) command.
Redirection

Portal authentication redirection status:

•Disable: IPv4 and IPv6 packet authentication redirection is disabled.

•Enable: IPv4 and IPv6 packet authentication redirection is enabled.

•IPv6 Disable: IPv6 packet authentication redirection is disabled.

To configure this function, run the web-redirection [ ipv6 ] disable (Portal server profile view) command.
Sync

User information synchronization.

To configure this parameter, run the user-sync command.
Sync Seconds

Interval for synchronizing user information.

To configure this parameter, run the user-sync command.
Sync Max-times

Maximum number of times that user information fails to be synchronized.

To configure this parameter, run the user-sync command.
Detect

Portal server detection.

To configure this parameter, run the server-detect command.
Detect Max-times

Maximum number of detection failures of the Portal server.

To configure this parameter, run the server-detect command.
Detect Critical-num

Minimum number of servers in the Up state.

To configure this parameter, run the server-detect command.
Detect Action

Action taken after the number of detection failures of the Portal server exceeds the maximum.

·log: A log is sent when the number of detection failures of the Portal server exceeds the maximum.

·trap: An alarm is sent when the number of detection failures of the Portal server exceeds the maximum.

To configure this parameter, run the server-detect command.
Detect Type

Mode in which the device detects the Portal server:

·portal: Portal-based Portal server detection.

·http: HTTP-based Portal server detection.

To configure this parameter, run the server-detect type command.
Detect Seconds

Detection interval of the Portal server.

To configure this parameter, run the server-detect command.
VPN Instance

VPN instance.
Bound Portal profile

Portal access profile to which the Portal server template is bound.

To configure this parameter, run the web-auth-server (Portal access profile view) command.
Http Get-method

Whether to submit the user name and password to the device using the GET method:

·disable: The user name and password are not submitted to the device using the GET method.

·enable: The user name and password are submitted to the device using the GET method.

To configure this function, run the http get-method enable command.
Protocol

Protocol used in Portal authentication.

•Portal.

•http.

To configure this parameter, run the protocol command.
Password Encrypt

Encoding mode of a password.

·none: The password is not encoded.

·uam: The password is encoded in ASCII mode.

To configure this parameter, run the protocol command.
Password ParseKey

Keyword for identifying a user password.

To configure this parameter, run the http-method post command.
Cmd ParseKey

Identification keyword of the command.

To configure this parameter, run the http-method post command.
Username ParseKey

Identification keyword of the user name.

To configure this parameter, run the http-method post command.
MAC Address ParseKey

Identification keyword of the user MAC address.

To configure this parameter, run the http-method post command.
IP Address ParseKey

Identification keyword of the user IP address.

To configure this parameter, run the http-method post command.
Initial URL ParseKey

Identification keyword of the URL for initial login.

To configure this parameter, run the http-method post command.
Login Cmd

Identification keyword for user login.

To configure this parameter, run the http-method post command.
Login Success

The login is successful.
Login Fail

The user fails to log in.
Logout Cmd

User logout identification keyword.

To configure this parameter, run the http-method post command.
Logout Success

The user is deregistered successfully.
Logout Fail

The user fails to be deregistered.
Reply Type

Redirection response type.

·redirect initial URL: A user is redirected to the initial login URL after a successful login.

·redirect login URL: A user is redirected to the login URL after a login failure.

·message: Message to be displayed.

·redirect URL: Redirection to a specified URL.

To configure this parameter, run the http-method post command.
Redirect URL

Redirect URL.

To configure this parameter, run the http-method post command.
Message

Displayed message.

To configure this parameter, run the http-method post command.
