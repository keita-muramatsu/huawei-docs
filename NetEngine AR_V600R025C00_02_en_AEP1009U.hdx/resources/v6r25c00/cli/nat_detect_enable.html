nat detect enable

Function

The nat detect enable command enables NAT detection for TNPs.

The undo nat detect enable command disables NAT detection for TNPs.

By default, NAT detection is disabled for TNPs.

Format

nat detect enable

undo nat detect enable

Parameters

None

Views

TNP view

Default Level

2: Configuration level

Usage Guidelines

In the SD-WAN Solution, branch CPEs can access the network through the Internet. NAT devices are often deployed on the Internet. After the packet sent by a branch CPE passes through a NAT device, the IP address of the packet changes. To obtain the real address of the packet after the packet traverses the NAT device, run the nat detect enable command to enable the STUN client function on the CPE. A STUN client exchanges STUN packets with a STUN server to detect whether a NAT device is deployed. If a NAT device is deployed, the STUN client sends BGP packets carrying pre-NAT and post-NAT IP addresses and port numbers of the packets to other CPEs. These CPEs then use the pre-NAT and post-NAT IP addresses and port numbers to send STUN binding request packets to each other. After receiving STUN binding response packets, the CPEs determine the IP addresses that are reachable to each other.

Example

# Enable the NAT detection function for a TNP.
<HUAWEI> system-view
[HUAWEI] evpn site 1
[HUAWEI-site-1] system-id 1.1.1.1
[HUAWEI-site-1] transport-network-port 1
[HUAWEI-site-1-transport-network-port-1] nat detect enable
