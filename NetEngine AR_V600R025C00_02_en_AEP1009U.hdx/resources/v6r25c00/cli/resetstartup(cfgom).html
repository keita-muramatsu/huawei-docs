reset saved-configuration

Function

The reset saved-configuration command clears the configuration file for next startup.

Format

reset saved-configuration

Parameters

None

Views

User view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

If the original configuration file cannot meet new environment requirements and the device needs to be reconfigured, you can run this command to clear the configuration file to be loaded for the next startup and reconfigure the device.

Configuration Impact

  • If you run this command and then restart the device, the device starts with empty configurations.
  • Before clearing the configuration file, the system compares the configuration files used for the current startup and the next startup. You can run the display startup command to query the configuration files used for the current startup and the next startup. The rules for clearing configuration files are as follows:
    • If the configuration files used for the current startup and the next startup are the same, running this command clears both the configuration files, and the default configuration file will be used for the next startup.
    • If the configuration files used for the current startup and the next startup are different, running this command clears the configuration file for next startup, but the current configuration file remains unchanged.
    • If the current startup configuration file is empty and the configuration file for next startup is not empty, running this command clears the configuration file for next startup.
    • If the configuration file for next startup is empty and the current startup configuration file is not empty, after this command is executed, the system reports an error and does not clear any configuration file.

Precautions

  • Exercise caution when running this command, and you are advised to follow the instructions of the technical support personnel when you run this command.
  • After secondary authentication for risky commands is enabled using the configuration re-authentication enable command, you must enter the login password for secondary authentication before running the reset saved-configuration command.
  • When upgrading the system software package of a device, you need to specify the system software package for next startup first. In this case, the device automatically specifies the configuration file for next startup. You can run this command to clear the configuration.

Example

# Clear the configuration files used at the startup from the storage device.
<HUAWEI> reset saved-configuration
Warning: The action will delete the saved configuration on the device.
The configuration will be erased to reconfigure.Continue? [Y/N]:n


<HUAWEI> reset saved-configuration
Warning: The action will delete the saved configuration on the device.
The configuration will be erased to reconfigure.Continue? [Y/N]:y
Warning: Now clearing the configuration on the device.
Info: Succeeded in clearing the configuration on the device.
