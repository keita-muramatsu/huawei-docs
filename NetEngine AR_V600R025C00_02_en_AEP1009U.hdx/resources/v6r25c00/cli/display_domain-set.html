display domain-set

Function

The display domain-set command displays domain group information.

Format

display domain-set { all | verbose { domain-set-name [ domain domain-name ] | ip-address { ipv4-address | ipv6-address } [ policy-match ] } } [ slot slot-id cpu cpu-id ]

Parameters

Parameter Description Value
all

Indicates the information about all domain groups.

-
verbose domain-set-name

Indicates detailed information about a domain group.

The value is a string of 1 to 128 case-sensitive characters. If the value contains spaces, it must be enclosed in double quotation marks (""), for example, "domain for test."
domain domain-name

Indicates detailed information about a domain name in the specified domain group.

The value is a string of 1 to 255 case-sensitive characters. It cannot contain spaces.
ip-address ipv4-address

Specifies an IPv4 address.

The value is an IPv4 address in dotted decimal notation.
ip-address ipv6-address

Specifies an IPv6 address.

The value is an IPv6 address.
policy-match

Displays information about the domain names that can be matched by the policy.

-
slot slot-id

Specifies the slot ID.

The value is an integer, and the value range depends on the device configuration.
cpu cpu-id

Specifies the ID of a CPU.

The value is an integer ranging from 0 to 8.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To check the information of domain groups, run the display domain-set command.

Example

The actual command output varies according to the device. The command output here is only an example.

[HUAWEI-domain-set-test] add domain test
