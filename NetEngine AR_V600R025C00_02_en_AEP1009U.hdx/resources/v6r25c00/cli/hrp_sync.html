hrp sync

Function

The hrp sync command synchronizes status entries of one device to the other device in the hot standby networking.

Format

hrp sync connection-status

Parameters

Parameter Description Value
connection-status

Immediately backs up status entries.

-

Views

User view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

In general, after a dual-device hot standby relationship is established, the newly added status entries that support backup of one device are automatically synchronized to the other device. However, before the dual-device hot standby relationship is established, the status entries that already exist on the two devices are not automatically backed up. In this case, you can run the hrp sync command to perform a manual batch backup.

Configuration Impact

The hrp sync command synchronizes status entries of one device to the other device in the hot standby networking.

Example

# Synchronize the connection-status on an active device to the standby device.
<HUAWEI> hrp sync connection-status
