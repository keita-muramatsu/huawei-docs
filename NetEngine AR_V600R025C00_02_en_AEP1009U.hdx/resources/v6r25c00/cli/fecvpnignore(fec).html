fec-instance ignore-vpn enable

Function

The fec-instance ignore-vpn enable command enables the function of ignoring VPN instances in an FEC instance.

The undo fec-instance ignore-vpn enable command disables the function of ignoring VPN instances in an FEC instance.

By default, the function of ignoring VPN instances in an FEC instance is disabled.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

fec-instance ignore-vpn enable

undo fec-instance ignore-vpn enable

Parameters

None

Views

forward-error-correction view

Default Level

2: Configuration level

Usage Guidelines

In an SD-WAN scenario, an FEC instance is generated for each link in multiple VPN instances. When the number of SD-WAN EVPN links or VPN instances is large, the number of FEC instances may reach the upper limit, causing the FEC function to fail for some links or VPNs. In this case, you can enable the function of ignoring VPN instances in an FEC instance. After this function is enabled, the traffic from multiple VPN instances to the same link is aggregated and optimized, reducing the FEC instance resource usage.

Example

# Enable the function of ignoring VPN instances in an FEC instance.
<HUAWEI> system-view
[HUAWEI] forward-error-correction
[HUAWEI-forward-error-correction] fec-instance ignore-vpn enable
