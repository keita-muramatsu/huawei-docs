reset security-policy counter

Function

The reset security-policy counter command clears the match count of a specified or all security policy rules. Match count refers to the number of times a security policy rule is matched.

Format

reset security-policy counter { all | rule rule-name }

Parameters

Parameter Description Value
all

Indicates all security policy rules.

-
rule rule-name

Specifies the name of a security policy rule.

The value is a string of 1 to 63 case-sensitive characters, spaces supported.

Views

User view, User view of the virtual system

Default Level

2: Configuration level

Usage Guidelines

To clear the match count of a specified or all security policy rules, run the reset security-policy counter command.

Example

# Clear the match count of security policy rule policy_sec.
<HUAWEI> reset security-policy counter rule policy_sec
