stp eth-trunk cost

Function

The stp eth-trunk cost command configures the path cost for all Eth-Trunk interfaces in the current process.

The undo stp eth-trunk cost command restores the default path cost for all Eth-Trunk interfaces in the current process.

By default, no path cost is configured for an Eth-Trunk interface. The path cost of the Eth-Trunk interface on each spanning tree is the path cost corresponding to the interface rate.

Format

stp eth-trunk cost costvalue

undo stp eth-trunk cost [ costvalue ]

Parameters

Parameter Description Value
cost costvalue

Specifies the path cost of an Eth-Trunk interface.

The value is an integer ranging from 1 to 200000000.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The path cost of an interface is a key factor for spanning tree calculation. After this command is run, the path cost of the Eth-Trunk interface is the configured value.

After the path cost of an Eth-Trunk interface is configured, the spanning tree network does not flap even if the bandwidth of the Eth-Trunk interface changes due to an interface being mistakenly removed from the Eth-Trunk interface.

Prerequisites

A path cost calculation standard has been set using the stp pathcost-standard command. By default, the IEEE 802.1T is used to calculate the path cost.

Configuration Impact

After the path cost of an Eth-Trunk interface is configured, the spanning tree is recalculated.

Precautions

  1. After the stp eth-trunk cost command is run, the path cost of all Eth-Trunk interfaces in the current process is adjusted and the spanning tree is recalculated.
  2. If the stp cost command is run on a port, the cost configured on the port takes effect.

Example

# Set the path cost of an Eth-Trunk interface in the default process to 200.
<HUAWEI> system-view
[HUAWEI] stp eth-trunk cost 200
Warning: The path cost of all Eth-Trunk interfaces in the current process will be set to the configured value and spanning tree will be recalculated.
