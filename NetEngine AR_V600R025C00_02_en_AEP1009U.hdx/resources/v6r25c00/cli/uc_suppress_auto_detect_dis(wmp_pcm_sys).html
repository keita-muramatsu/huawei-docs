unicast-suppression auto-detect disable (AP system profile view)

Function

The unicast-suppression auto-detect disable command disables intelligent flow control for unknown unicast packets.

The undo unicast-suppression auto-detect disable command enables intelligent flow control for unknown unicast packets.

By default, intelligent flow control for unknown unicast packets is enabled.

Format

unicast-suppression auto-detect disable

undo unicast-suppression auto-detect disable

Parameters

None

Views

AP system profile view

Default Level

2: Configuration level

Usage Guidelines

If there are a large number of unknown unicast packets, the CPU will become busy, reducing buffer resources for incoming packet queues. You can run this command to enable intelligent flow control for unknown unicast packets. When the number of unknown unicast packets reduces to the specified threshold, the device automatically enables rate limiting for the unknown unicast packets according to the pre-configured rate limit value. This function takes effect for traffic in both the inbound and outbound directions on the air interface and wired interfaces of an AP.

Example

# Enable intelligent flow control for unknown unicast packets.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name system1
[HUAWEI-wlan-ap-system-prof-system1] undo unicast-suppression auto-detect disable
