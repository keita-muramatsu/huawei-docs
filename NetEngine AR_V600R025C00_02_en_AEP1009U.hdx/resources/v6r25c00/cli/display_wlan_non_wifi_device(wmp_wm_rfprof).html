display wlan non-wifi-device

Function

The display wlan non-wifi-device command displays information about detected non-Wi-Fi devices.

Format

display wlan non-wifi-device { all | ap-id ap-id radio radio-id }

Parameters

Parameter Description Value
all

Displays information about the non-Wi-Fi devices detected by all APs.

-
ap-id ap-id

Displays information about the non-Wi-Fi devices detected by a specified AP ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
radio radio-id

Displays information about the non-Wi-Fi devices detected by a specified AP radio.

The value is an integer ranging from 0 to 4.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

After the function of reporting spectrum data is enabled on an AP radio using the spectrum-report enable command, you can run the display wlan non-wifi-device command to check information about detected non-Wi-Fi devices.
