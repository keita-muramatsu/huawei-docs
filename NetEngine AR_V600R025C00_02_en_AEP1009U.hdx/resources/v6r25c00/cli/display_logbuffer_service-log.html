display logbuffer service-log

Function

The display logbuffer service-log command is used to display the service logs information recorded by the log buffer.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

display logbuffer service-log [ slot slot-id | module module-name | starttime start-time [ endtime end-time ] | level { severity | level } | size size ]

Parameters

Parameter Description Value
slot slot-id

Specifies the slot number.

The value is an integer, and the value range depends on the device configuration.
module module-name

Specifies the name of a module.

The value is a string of 1 to 31 case-sensitive characters without spaces.
starttime start-time

Specify the query start time, only show the logs after this time.

The value is in the format of YYYY/MM/DD,HH:MM:SS. YYYY-MM-DD indicates the year/month/day. The value of YYYY ranges from 1970 to 9999; the value of MM ranges from 1 to 12; the value of DD ranges from 1 to 31. HH:MM:SS indicates the hour:minute:second. The value of HH ranges from 0 to 23; the value of MM and SS ranges from 0 to 59.
endtime end-time

Specify the query end time, only the logs before this time will be displayed.

The value is in the format of YYYY/MM/DD,HH:MM:SS. YYYY-MM-DD indicates the year/month/day. The value of YYYY ranges from 1970 to 9999; the value of MM ranges from 1 to 12; the value of DD ranges from 1 to 31. HH:MM:SS indicates the hour:minute:second. The value of HH ranges from 0 to 23; the value of MM and SS ranges from 0 to 59.
level level

Displays the severity level of the specified information.

The value is an integer ranging from 0 to 7.
level severity

The name of the information level.

The options are as follows:

  • alert
  • critical
  • debugging
  • emergencies
  • error
  • informational
  • notification
  • warning
size size

Displays the number of information items in the specified log buffer.

The value is an integer that ranges from 1 to 10240.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run this command to view recent service log information.

The number of logs displayed using the display logbuffer service-log command depends on the number of logs specified to be displayed using the info-center logbuffer command. If the actual number of logs is less than the specified number of logs to be displayed, information about the actual number of logs is displayed.

Example

The actual command output varies according to the device. The command output here is only an example.

# Displays information in the service log buffer.
<HUAWEI> display logbuffer service-log
Logging buffer configuration and contents : enabled
Allowed max buffer size : 10240
Actual buffer size : 512
Channel number : 4 , Channel name : logbuffer
Dropped messages : 0
Overwritten messages : 0
Current messages : 1

Channel ID.

Name of the channel.
