timer ldp-sync hold-max-cost (IS-IS view)

Function

The timer ldp-sync hold-max-cost command sets the period for an IGP process or instance to advertise the maximum link cost on the local device.

The undo timer ldp-sync hold-max-cost command restores the default period.

By default, an IGP permanently advertises the maximum cost 16777214 on the local device before an LDP session and LDP adjacency are reestablished.

Format

timer ldp-sync hold-max-cost infinite

timer ldp-sync hold-max-cost interval

undo timer ldp-sync hold-max-cost

Parameters

Parameter Description Value
interval

Specifies the period during which IS-IS keeps advertising the maximum cost.

The value is an integer ranging from 0 to 65535, in seconds.
infinite

Indicates that IS-IS keeps advertising the maximum cost before an LDP session and an LDP adjacency are reestablished.

-

Views

IS-IS view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After LDP-IGP synchronization is enabled on a network with active and standby links, if the active link fails, LDP and IGP traffic is switched to the standby link,

  • When the primary link recovers, LDP-IGP synchronization notifies the local node of the maximum cost of the primary link. To enable traffic to be forwarded through the backup link before the LSP of the primary link is established, run the mpls ldp backup-link command.
  • If the LDP session or LDP adjacency on the primary link fails when both the primary and backup links are normal, the IGP protocol is still normal. In this case, LDP-IGP synchronization notifies the local node of the maximum cost of the primary link so that IGP and LDP can simultaneously switch traffic to the backup link within a certain period.

    Using the timer ldp-sync hold-max-cost command, you can set the interval for advertising the maximum cost.

    If an IGP carries only LDP services, configure infinite to ensure that the IGP route selection is consistent with the LDP LSP selection.

    If an IGP carries multiple types of LDP services, you can set the intervalparameter to prevent the interruption of the LDP session or LDP adjacency on the primary link from affecting IGP route selection and other services.

Configuration Impact

If an LDP session or LDP adjacency is unable to go Up, configuring infinite affects IS-IS route selection because the interface keeps advertising the maximum cost.

Example

# Allow IS-IS to keep advertising the maximum cost by sending link state PDUs until the LDP session and an LDP adjacency are reestablished.
<HUAWEI> system-view
[HUAWEI] isis 100
[HUAWEI-isis-100] timer ldp-sync hold-max-cost infinite
