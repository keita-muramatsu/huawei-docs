auto-link aggregation

Function

The auto-link aggregation open command enables Eth-Trunk auto-negotiation.

The auto-link aggregation lock command locks the Eth-Trunk auto-negotiation result.

The undo auto-link aggregation command disables Eth-Trunk auto-negotiation.

By default, Eth-Trunk auto-negotiation is disabled.

Format

auto-link aggregation open

auto-link aggregation lock

undo auto-link aggregation

Parameters

None

Views

System view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

Eth-Trunk uses link aggregation technology to bundle multiple independent physical interfaces into a logical interface, increasing link bandwidth. The physical links back up each other. If an active link fails, traffic is switched to another available member link, improving link reliability.

The auto-link aggregation open command enables Eth-Trunk auto-negotiation. After the function is enabled, devices exchange LLDP packets carrying auto-negotiation capabilities. Based on the neighbor information, the devices automatically negotiate interface information and generate Eth-Trunk configurations. No manual Eth-Trunk configuration is required.

The auto-link aggregation lock command locks the Eth-Trunk auto-negotiation configuration, preventing the device from continuing Eth-Trunk auto-negotiation.

Configuration Impact

After the auto-link aggregation open command is run, the auto-link aggregation command configuration is automatically generated in the interface view if interface negotiation succeeds. The command configuration indicates that the current interface is generated through auto-negotiation and is not manually configured.

Precautions

You can enable Eth-Trunk auto-negotiation using either of the following modes:

  • Run the auto-link eth-trunk-mode command on the master device to deliver the network-wide configuration. The configuration is automatically delivered to all member devices and takes effect on them.
  • Log in to each device one by one and run the auto-link aggregation command in the system view. Here, the device can function as the master device or a member device.

Between the network-wide configuration and the configuration of a single device, only the one applied last to a device takes effect.

Example

# Enable Eth-Trunk auto-negotiation.
<HUAWEI> system-view
[HUAWEI] auto-link aggregation open
# Lock the Eth-Trunk auto-negotiation result.
<HUAWEI> system-view
[HUAWEI] auto-link aggregation lock
