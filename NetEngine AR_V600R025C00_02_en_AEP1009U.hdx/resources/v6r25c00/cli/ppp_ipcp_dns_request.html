ppp ipcp dns request

Function

The ppp ipcp dns request command enables a device to apply for a DNS server address from the peer.

The undo ppp ipcp dns request command disables a device from applying for a DNS server address from the peer.

By default, a device does not apply for a DNS server address from the peer.

Format

ppp ipcp dns request

undo ppp ipcp dns request

Parameters

None

Views

Dialer interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If a device connected to a peer device through PPP attempts to access the Internet based on a specified domain name, the peer device needs to assign a DNS server address to the device. By default, a device is not enabled to apply for the DNS server address. To enable this function, run the ppp ipcp dns request command.

Prerequisites

PPP is configured as the link layer protocol of the interface.

Precautions

After the configuration, you must restart the corresponding interface for the configuration to take effect.

You can restart an interface in any of the following ways:

Run the undo pppoe-client dialer and pppoe-client dialer commands in sequence to restart the dialer interface.

Run the shutdown and undo shutdown commands in sequence.

Run the restart command.

Example

# Enable a device to apply for the DNS server address from its peer.
<HUAWEI> system-view
[HUAWEI] interface dialer 1
[HUAWEI--Dialer1] ppp ipcp dns request
