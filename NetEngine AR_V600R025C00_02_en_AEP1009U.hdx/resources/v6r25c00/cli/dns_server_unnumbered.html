dns server unnumbered

Function

The dns server unnumbered command configures the device to borrow the DNS server IP address obtained from a specified interface as the local DNS server IP address.

The undo dns server unnumbered command deletes the interface for obtaining the DNS server IP address.

By default, the DNS server IP address obtained by an interface cannot be directly used.

Format

dns server unnumbered interface { interface-type interface-num | interface-name }

dns server ipv6 unnumbered interface { interface-type interface-num | interface-name }

undo dns server unnumbered interface { interface-type interface-num | interface-name }

undo dns server ipv6 unnumbered interface { interface-type interface-num | interface-name }

Parameters

Parameter Description Value
interface-type

Specifies the type of an interface.

-
interface-num

Specifies an interface number.

-
interface-name

Specifies the name of an interface.

-
ipv6

Specifies the IPv6 address of a DNS server.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In addition to specifying the IP address of the DNS server using a command, the device can also obtain the DNS server address from an interface. However, the DNS server IP address obtained by the device from an interface cannot be directly used. You must run the dns server unnumbered interface { interface-type interface-num | interface-name} command to specify the interface for obtaining the DNS server IP address. After the command is run, the DNS server IP address obtained from the specified interface can be used by the device.

Precautions

  • After the device is restarted or the DNS process is restarted independently, the location of the dynamically obtained DNS server IP address in the DNS server IP address group changes. The reason for the change is that the static IP address is restored and the dynamic IP address is obtained by triggering services again.
  • When the number of static addresses reaches the upper limit, the dns server unnumbered interface command does not record the pushed dynamic addresses to the available DNS server address group. After the static address is deleted, the available space is cleared. To make the pushed dynamic address take effect, you need to delete and configure the dns server unnumbered interface command. Otherwise, the dynamic address still does not take effect.

Example

# Configure the device to obtain the DNS server IP address from 10GE 0/0/1.
<HUAWEI> system-view
[HUAWEI] dns server unnumbered interface 10GE 0/0/1
