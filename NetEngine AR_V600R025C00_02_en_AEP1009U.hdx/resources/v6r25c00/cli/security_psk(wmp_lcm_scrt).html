security psk

Function

The security psk command configures WPA/WPA2 pre-shared key (PSK) authentication and encryption.

By default, no security policy is configured. To restore the default security policy, run the undo security command.

Format

security { wpa | wpa2 | wpa-wpa2 } psk { pass-phrase pass-phrase-key-value | hex hex-key-value } { aes | tkip | aes-tkip }

security wpa-wpa2 psk { pass-phrase pass-phrase-key-value | hex hex-key-value } tkip aes

security { wpa | wpa2 | wpa-wpa2 } ppsk { aes | tkip | aes-tkip }

security wpa-wpa2 ppsk tkip aes

Parameters

Parameter Description Value
wpa

Configures WPA authentication.

-
wpa2

Configures WPA2 authentication.

-
wpa-wpa2

Configures WPA-WPA2 authentication. STAs can be authenticated using WPA or WPA2.

-
psk

Configures PSK authentication.

-
pass-phrase pass-phrase-key-value

Specifies the key phrase.

Displays the user password in ciphertext.

The value is a string of 8 to 63 ASCII characters, or 48, 68, 88, 108, 128, 148, 168, or 188 characters in ciphertext.

The question mark (?) is supported, which you can enter by pressing Ctrl+Q and then enter the symbol.

A password cannot contain the space and double quotation mark (") at the same time. When the password contains a space, enclose the string with double quotation marks (") when entering the value. For example, if the password is YsHsjx 202206, enter "YsHsjx 202206".

For security purposes, you are advised to configure a key that contains at least two of the following: digits, lowercase letters, uppercase letters, and special characters.
hex hex-key-value

The value is a hexadecimal number.

Displays the user password in ciphertext.

The parameter hex does not support password complexity check, so pass-phrase is recommended.

The value is a string of 64 hexadecimal characters, or 108 or 188 characters in ciphertext.

The question mark (?) is supported, which you can enter by pressing Ctrl+Q and then enter the symbol.

A password cannot contain the space and double quotation mark (") at the same time. When the password contains a space, enclose the string with double quotation marks (") when entering the value. For example, if the password is YsHsjx 202206, enter "YsHsjx 202206".

For security purposes, you are advised to configure a key that contains at least two of the following: digits, lowercase letters, uppercase letters, and special characters.
aes

Configures AES encryption.

-
tkip

Configures TKIP encryption.

-
aes-tkip

Configures AES-TKIP encryption. After passing the authentication, STAs can use the AES or TKIP algorithm for data encryption.

-
ppsk

Configures PPSK authentication.

-

Views

Security profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

WPA/WPA2 authentication is classified into WPA/WPA2-PSK authentication and WPA/WPA2 802.1X authentication, which are also called WPA/WPA2-Personal and WPA/WPA2-Enterprise, respectively. 802.1X authentication is of high security and is applicable to enterprise networks.

To access a WLAN device using WPA or WPA2 PSK authentication, run this command. If multiple types of user terminals support different authentication and encryption modes, you can configure the hybrid mode.

If different PSKs need to be configured for different terminals on a network, you can configure PPSK authentication.

The security wpa-wpa2 psk { pass-phrase | hex } key-value tkip aes command indicates that WPA and WPA2 use TKIP and AES for data encryption, respectively.

Follow-up Procedure

If PPSK authentication is used, run the ppsk-user command to configure a PPSK user.

Precautions

  • AES is recommended, because it is more secure than TKIP and AES-TKIP.
  • If the key is in hexadecimal notation, you can enter hexadecimal characters without entering 0x.
  • If a security profile is bound to multiple VAP profiles, it may take a few minutes to configure WPA/WPA2 PSK authentication and encryption in the security profile.
  • Upon the command execution, the system displays the prompt message only when the security profile has been bound to other profiles.
  • If PSK authentication and TKIP or AES-TKIP encryption for WPA/WPA2 is configured, the access of non-HT STAs fails to be denied.
  • If the password is changed to one starting or ending with a space on the device (example: huawei123abc ), some terminals (such as terminals running Windows 7) may filter out the space when you change the password on the terminals. This will lead to an association failure. Therefore, it is not recommended that a password starting or ending with a space be set on the device. If such a password has been configured on the device, delete the existing SSID on a terminal, reassociate the terminal with the SSID, and enter the password. For detailed terminal types, refer to the Test Report on Terminal Compatibility.
  • The key cannot have $@$@, ^#^#, %$%$, %@%@, or @$@$ as the prefix or suffix. If the key is a string of 24 characters, it cannot end with two exclamation marks (!!) or a pound sign (#).

Example

# Configure WPA2 PSK authentication and the authentication key.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] security-profile name p1
[HUAWEI-wlan-sec-prof-p1] security wpa2 psk pass-phrase YsHsjx_202206 aes
# Configure WPA PSK authentication and the authentication key.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] security-profile name p1
[HUAWEI-wlan-sec-prof-p1] security wpa psk pass-phrase YsHsjx_202206 aes
# Configure WPA-WPA2 PSK authentication and hybrid encryption.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] security-profile name p1
[HUAWEI-wlan-sec-prof-p1] security wpa-wpa2 psk pass-phrase YsHsjx_202206 aes-tkip
Warning:  If the wmm disable command, TKIP, or radio type of 802.11a/b/g is configured, the function of denying access of legacy STAs cannot take effect.
# Configure WPA-WPA2 PPSK authentication and hybrid encryption.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan-view] security-profile name p1
[HUAWEI-wlan-sec-prof-p1] security wpa-wpa2 ppsk aes-tkip
