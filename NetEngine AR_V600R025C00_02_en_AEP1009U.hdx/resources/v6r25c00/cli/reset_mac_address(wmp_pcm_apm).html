reset mac-address (All views)

Function

The reset mac-address command clears all dynamic MAC address entries, secure dynamic MAC address entries, and sticky MAC address entries on an AP's wired interface.

Format

reset mac-address ap-id ap-id interface-type interface-number

Parameters

Parameter Description Value
ap-id ap-id

Clears all dynamic MAC address entries, secure dynamic MAC address entries, and sticky MAC address entries on wired interfaces of the AP with a specified ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
interface-type interface-number

Clears all dynamic MAC address entries, secure dynamic MAC address entries, and sticky MAC address entries on a specified interface.

  • interface-type specifies the type of the outbound interface.
  • interface-number specifies the number of the outbound interface.

The following types of outbound interfaces are supported:

  • Eth-Trunk
  • Ethernet
  • Gigabitethernet
  • MultiGE
  • XGigabitethernet

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run the reset mac-address command to clear all dynamic MAC address entries on an AP's wired interface. If port security and sticky MAC are enabled, this command clears secure dynamic MAC address entries and sticky MAC address entries.

Example

# Clear dynamic MAC address entries, secure dynamic MAC address entries, and sticky MAC address entries on a wired interface of AP 0.
<HUAWEI> reset mac-address ap-id 0 eth-trunk 0
