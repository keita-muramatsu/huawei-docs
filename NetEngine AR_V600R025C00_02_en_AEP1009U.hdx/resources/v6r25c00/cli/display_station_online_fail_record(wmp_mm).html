display station online-fail-record

Function

The display station online-fail-record command displays records of STAs' failures to go online.

Format

display station online-fail-record { all | ap-id ap-id | sta-mac sta-mac-address }

Parameters

Parameter Description Value
all

Displays online failure records of all STAs.

-
ap-id ap-id

Displays online failure records of STAs on the AP with a specified ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
sta-mac sta-mac-address

Displays online failure records of the STA with the specified MAC address.

The STA's MAC address must exist.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

If a STA fails to go online, you can run this command to check the failure reason, which helps locate the fault.

After the number of STA online failure records reaches the maximum that can be stored, new records overwrite existing ones.

For the reasons and handling suggestions for STAs' failures to go online, see "Common Causes and Error Codes of Access Authentication Failures" in the AR Router Troubleshooting Guide.

A maximum of three records can be saved for each STA.
