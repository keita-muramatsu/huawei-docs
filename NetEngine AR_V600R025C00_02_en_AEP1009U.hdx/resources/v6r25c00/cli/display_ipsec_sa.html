display ipsec sa

Function

The display ipsec sa command displays information about IPsec SAs.

Format

display ipsec sa [ [ brief ] [ slot slot-id cpu cpu-id ] | policy policy-name [ seq-number ] | profile profile-name | remote { ipv4-address | ipv6-address } ]

display ipsec sa [ flow-source { ipv4-address | ipv6-address } | flow-destination { ipv4-address | ipv6-address } ] *

Parameters

Parameter Description Value
brief

Displays brief information about IPsec SAs.

-
slot slot-id

Specifies a slot ID.

The value varies depending on device models.
cpu cpu-id

Specifies the CPU ID.

The value varies depending on device models.
policy policy-name

Specifies the name of an IPsec policy.

The value must be the name of an existing IPsec policy.
seq-number

Specifies the sequence number of an IPsec policy.

The value must be the sequence number of an existing IPsec policy.
profile profile-name

Specifies the name of an IPsec profile.

The value is a string of 1 to 32 case-sensitive characters. It cannot contain spaces.
remote ipv4-address

Specifies a peer IPv4 address.

The value is in dotted decimal notation.
remote ipv6-address

Specifies a peer IPv6 address.

The value is in colon hexadecimal notation.
flow-source ipv4-address

Specifies the source IPv4 address of encrypted data flows.

The value is in dotted decimal notation.
flow-source ipv6-address

Specifies the source IPv6 address of encrypted data flows.

The value is in colon hexadecimal notation.
flow-destination ipv4-address

Specifies the destination IPv4 address of encrypted data flows.

The value is in dotted decimal notation.
flow-destination ipv6-address

Specifies the destination IPv6 address of encrypted data flows.

The value is in colon hexadecimal notation.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

If no parameter is specified, detailed information about all SAs is displayed.

Specify the duration parameter to view the global SA lifetime, which can be time-based or traffic-based.

Table 1 Description of the display ipsec sa command output
Item Description
ipsec sa information

IPsec SA configuration information.
IPsec policy name

Name of an IPsec policy.
IPsec profile

Name of an IPsec profile.
Sequence number

Sequence number of an IPsec policy.
Acl group

ACL group referenced by an IPsec policy.
Acl rule

Rule number of an ACL.
Mode

IPsec policy creation mode:

  • template: indicates that an IPsec policy is established using an IPsec policy template.
  • isakmp: indicates that an IPsec policy is established using ISAKMP.
Connection ID

Connection index of an SA.
Encapsulation mode

Encapsulation mode configured in an IPsec proposal.

  • Tunnel: indicates the tunnel mode.
  • Transport: indicates the transport mode.
Tunnel local

Local IP address and UDP port number of an IPsec tunnel.
Tunnel remote

Remote IP address and UDP port number of IPsec tunnel.
Holding time

Period during which an IPsec tunnel has existed.
Flow source

Source address segment of the data flow sent by the local end, and the protocol number and port number of the ACL.
Flow destination

Destination address segment of the data flow sent by the local end and the protocol number and port number of the ACL.
Flow dscp

DSCP value of the data flow sent by the local end.
Flow vpn

VPN information of data flows.
Flow-vrf check

Whether to check the VPN instance in a data flow during IPsec encryption and decryption:

  • Enable.
  • Disable.
Outbound ESP SAs

Information about the IPsec SA that uses ESP in the outbound direction.
SA remaining soft duration (kilobytes/sec)

Remaining soft lifetime of an IPsec SA, in kilobytes or seconds.
SA remaining hard duration (kilobytes/sec)

Remaining hard lifetime of an IPsec SA, in kilobytes or seconds.
SA encrypted packets (number/kilobytes)

Number of packets that are finally successfully encrypted by the IPsec SA.
SA decrypted packets (number/kilobytes)

Number of packets that are successfully decrypted by IPsec SAs.
Max sent sequence-number

Maximum sequence number of the sent packet. The sequence number increases during communication and is used for anti-replay.
Max received sequence-number

Maximum sequence number of the received packet.
UDP encapsulation used for NAT traversal

Whether NAT traversal is enabled:

  • Y: enabled.
  • N: disabled.
Inbound ESP SAs

Information about the IPsec SA that uses ESP in the inbound direction.
Anti-replay

Whether the anti-replay function is enabled for an IPsec tunnel:

  • Enable: The function is enabled.
  • disable: The function is disabled.
Anti-replay window size

Size of the IPsec anti-replay window. This parameter takes effect when the anti-replay function is enabled.
Src address

Local IP address of an IPsec tunnel.
Dst address

Peer IP address of an IPsec tunnel.
SPI

SPI of an SA.
VPN

VPN instance to which an IPsec tunnel belongs.
Protocol

Security protocol used by an IPsec SA:

  • AH: The AH protocol is used.
  • AH-ESP: Both AH and ESP are used.
  • ESP: The ESP protocol is used.
Algorithm

Authentication and encryption algorithms used by a security protocol. A indicates the authentication algorithm, and E indicates the encryption algorithm.
Number of IPsec SA

Number of IPsec SAs.
Total number of IPsec SA in all CPU

Total number of SAs on all CPUs.
Interface

Interface to which an IPsec policy is applied.
Proposal

Name of an IPsec proposal referenced by an IPsec policy.
