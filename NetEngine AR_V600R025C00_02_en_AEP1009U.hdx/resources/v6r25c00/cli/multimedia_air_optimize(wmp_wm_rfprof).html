multimedia-air-optimize enable

Function

The multimedia-air-optimize enable command enables the intelligent multimedia scheduling algorithm.

The undo multimedia-air-optimize enable command disables the intelligent multimedia scheduling algorithm.

By default, the intelligent multimedia scheduling algorithm is disabled.

Format

multimedia-air-optimize enable

undo multimedia-air-optimize enable

Parameters

None

Views

RRM profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When the intelligent multimedia scheduling algorithm is enabled, the system optimizes the air interface traffic in the following aspects:

  • Delay guarantee for downlink video and voice services on a single AP

    The system periodically calculates the air interface delay of downlink voice and video services. When detecting the delay exceeding the guaranteed delay, the system triggers delay optimization for video and voice services. You can configure the guaranteed delay for video and voice services using the multimedia-air-optimize downlink-delay-guarantee command. After delay optimization is triggered for voice and video services, the system tries its best to ensure that the service delay for these services does not exceed the guaranteed delay. In addition, the system restricts the video and voice services of low-speed STAs. Low-speed STAs typically have low transmission efficiency and occupy air interface resources for a long time, increasing the overall delay of video and voice services. Therefore, the transmission opportunity for such STAs needs to be reduced.

  • Preferential scheduling for downlink video and voice services on a single AP

    During software scheduling, VI/VO services are preferentially scheduled. That is, each time the scheduler queries queue information, if the total packet sending time of the current VI/VO queue does not exceed the threshold, the services in the video/voice queue are preferentially scheduled. The threshold is calculated based on the slicing ratio for VI/VO services configured using the multimedia-air-optimize downlink-slice-ratio command.

  • Uplink congestion control for a single AP

    When a STA has heavy-traffic services of the AC_BE or AC_BK type in the uplink direction, packets are frequently sent, and it takes a long time to send each packet. This significantly increases the delay of downlink key services on the AP. If key services in the downlink direction are affected, the system considers performing congestion control on heavy-traffic services of the AC_BE or AC_BK type. The multimedia-air-optimize congestion-control tcp-window-tuning disable command is involved for AP's uplink congestion control. After the undo multimedia-air-optimize congestion-control tcp-window-tuning disable command is executed, the TCP window adjustment function is enabled for voice and video services. If the delay of voice or video services reaches the threshold and the packet transmission duration of heavy-traffic TCP background services in the uplink direction reaches the threshold within the unit time (1s), the receiver window (RWND) in TCP ACK packets can be dynamically adjusted. This process takes about 5s to 10s. After the adjustment, the uplink data volume sent by STAs is reduced, thereby ensuring user experience of voice and video services.

  • WMM parameter adjustment based on the number of access users

    After the intelligent multimedia scheduling algorithm is enabled, the system dynamically adjusts WMM parameters based on the number of access users, improving voice and video service experience.

    The number of access users is determined based on the larger value of the following:

    • Number of voice/video users identified by SAC applications
    • Number of voice/video users identified based on the user packet threshold configured using the multimedia-air-optimize threshold command If the number of voice or video packets sent by a user through the internal statistics queue of a radio within the unit time (1 second) exceeds the threshold, the user is considered a voice or video user.

Prerequisites

The traffic has been identified as VI/VO traffic in one of the following ways:

  • Priority carried by the traffic
  • Manually adjusted priority mapping
  • DFI function

Ensure that the WMM function is enabled (default state). To enable the WMM function, run the undo wmm disable command.

Example

# Enable the intelligent multimedia scheduling algorithm in RRM profile p1.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] rrm-profile name p1
[HUAWEI-wlan-rrm-prof-p1] multimedia-air-optimize enable
