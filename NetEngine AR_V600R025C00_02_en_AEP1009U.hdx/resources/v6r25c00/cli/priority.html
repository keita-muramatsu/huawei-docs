priority

Function

The priority command configures the priority for an SPR policy profile.

The undo priority command restores the default priority for an SPR policy profile.

By default,the priority of an SPR policy profile is the same as the node index.

Format

priority priority-value

undo priority [ priority-value ]

Parameters

Parameter Description Value
priority-value

Specifies the priority of a policy profile.

The value is an integer in the range from 1 to 65535. A smaller value indicates a higher priority.

Views

SPR policy view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

SPR policy profiles are delivered based on the node sequence. The node index cannot be dynamically modified. To modify the SPR policy profile delivery sequence, you must delete all SPR policy profiles and then deliver them in the specified sequence. This results in heavy communication traffic and a low delivery speed. To solve this problem, SPR provides the function of configuring the priority for a policy profile on the CLI. That is, you can run this command in the policy profile view to change the policy profile delivery sequence without deleting all policy profiles.

Prerequisites

SPR has been configured using the smart-policy-route command.

A policy profile has been created using the spr-policy command in SPR.

Precautions

If there are multiple policy profiles with the same priority, the policy profile with a smaller index value takes effect preferentially.

Example

# Set the priority of node 1 in the policy profile to 10.
<HUAWEI> system-view
[HUAWEI] smart-policy-route
[HUAWEI-smart-policy-route] spr-policy node 1
[HUAWEI-smart-policy-route-spr-policy-node-1] priority 10
