lldp dot3-tlv power

Function

The lldp dot3-tlv power command specifies the format of the Power-via-MDI TLV advertised by an interface.

By default, the Power Via MDI TLV is sent in the 802.1ab format. If there is a neighbor, the format is adapted according to the packet format of the neighbor.

Format

lldp dot3-tlv power { 802.1ab force | 802.3at }

lldp dot3-tlv power 802.1ab

Parameters

Parameter Description Value
802.1ab

Indicates that the 802.3 Power via MDI TLV advertised by an interface conforms to 802.1ab.

-
802.3at

Indicates that the 802.3 Power via MDI TLV advertised by an interface conforms to 802.3at.

-
force

Indicates that the 802.3 Power via MDI TLV advertised by an interface conforms to 802.1ab.

-

Views

Layer 2 10GE interface view, 10GE interface view, 25GE-L2 view, 25GE interface view, Layer 2 40GE interface view, 40GE interface view, Ethernet interface view, Layer 2 GE interface view, GE optical interface view, GE sub-interface view, GE interface view, GE electrical interface view, Layer 2 multi-GE interface view, Multi-GE interface view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The 802.3 Power via MDI TLV has the following formats:

Format defined in 802.1ab: [ TLV type | TLV information string length | 802.3 OUI | MDI power support | PSE power pair | power class ]

Format defined in 802.3at: [ TLV type | TLV information string length | 802.3 OUI | MDI power support | PSE power pair | power class | type/source/priority | PD requested power value | PSE allocated power value ]

Based on 802.1ab, 802.3at extends three fields: type/source/priority, PD requested power value, and PSE allocated power value.

If a PD requires high power but the power of the power supply device is insufficient, you can forcibly specify the format defined in 802.1ab for the 802.3 Power-via-MDI TLV advertised by an interface to reduce the power required by the PD.

Prerequisites

  1. LLDP has been enabled globally using the lldp enable command in the system view.
  2. LLDP has been enabled on the interface using the undo lldp disable command in the interface view.

Precautions

When selecting the standard to advertise 802.3 Power via MDI TLVs, pay attention to whether the neighboring device supports the standard. The standard configured on the local device must be the same as that configured on the neighboring device. You are advised to retain the default configuration, that is, sending Power-via-MDI TLVs in compliance with 802.1ab first. The device can adapt to the format of Power-via-MDI TLVs based on the peer.

Example

# Configure an interface to advertise 802.3 Power-via-MDI TLVs in compliance with 802.3at. 
<HUAWEI> system-view
[HUAWEI] lldp enable
[HUAWEI] interface 10GE0/0/1
[HUAWEI-10GE0/0/1] undo lldp disable
[HUAWEI-10GE0/0/1] lldp dot3-tlv power 802.3at
