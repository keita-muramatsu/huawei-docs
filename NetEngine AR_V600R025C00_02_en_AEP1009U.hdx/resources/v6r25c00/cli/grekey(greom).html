gre key

Function

The gre key command sets the key number of a GRE tunnel.

The undo gre key command deletes the key number of a GRE tunnel.

By default, the GRE key number is not configured.

Format

gre key { simple key-number-simple | [ cipher ] key-number-cipher }

undo gre key

Parameters

Parameter Description Value
simple key-number-simple

Specifies a simple integer that identifies both ends of a tunnel. The specified keyword is saved in non-ciphertext in the configuration file.

The value is an integer ranging from 0 to 4294967295.
cipher

Indicates that a ciphertext key is displayed.

-
key-number-cipher

Specifies the key for identifying both ends of a tunnel.

You can enter a simple keyword that is an integer ranging from 0 to 4294967295 or a ciphertext string of 32 characters or 48 to 128 characters.

Views

Tunnel interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

You can configure the identification keys at both ends of a GRE tunnel to identify the traffic in the tunnel. This prevents the device from incorrectly identifying and receiving packets from other sources.

Prerequisites

The encapsulation mode of a tunnel has been configured as GRE using the tunnel-protocol gre command.

Configuration Impact

If the gre key command is run more than once, the latest configuration overrides the previous one.

Follow-up Procedure

  • Configure the same key number on the peer end of the GRE tunnel.
  • Bind specific services to the GRE tunnel.

Precautions

If the gre key command is run, the transmit and receive ends will authenticate the key number of packets. The authentication is successful only if the Key field settings on both endpoints of the tunnel are consistent. Otherwise, the packets are dropped. Therefore, if you specify the key number on both ends of a tunnel, set the same value for both ends. You can also specify no key number on both ends.

If multiple mGRE tunnel interfaces use the same source address or source interface, you must configure a unique identification keyword for each mGRE tunnel.

If mGRE and GRE tunnel interfaces use the same source address or source interface, you must configure a unique identification keyword for each tunnel.

Example

# Configure the GRE key number on both ends of the tunnel.
<HUAWEI> system-view
[HUAWEI] interface tunnel 100
[HUAWEI-Tunnel100] tunnel-protocol gre
[HUAWEI-Tunnel100] gre key cipher 1024256
