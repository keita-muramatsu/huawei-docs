ap ip version

Function

The ap ip version command configures the IP address version for an AP to go online.

The undo ap ip version command restores the default IP address version for an AP to go online.

By default, the IP address version for an AP to go online can be IPv4 or IPv6.

Format

ap ip version { all | ipv4 | ipv6 }

undo ap ip version

Parameters

Parameter Description Value
all

Specifies the IP address version for an AP to go online as IPv4 or IPv6.

-
ipv4

Specifies the IP address version for an AP to go online as IPv4.

-
ipv6

Specifies the IP address version for an AP to go online as IPv6.

-

Views

AP group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If APs with both IPv4 and IPv6 addresses are deployed in a CAPWAP dual-stack scenario, you are advised to classify AP groups based on the area. Run this command to specify the IP address version of the APs based on the AP group to avoid APs with both IPv4 and IPv6 addresses from being classified into the same area. If such a problem occurs, band steering, smart roaming, and load balancing services are affected.

After the IP address version for an AP to go online is specified, APs with IP addresses of the other type cannot go online.

Precautions

If an AP has gone online, modifying this configuration will cause the AP whose version does not match the specified IP version to go offline.

Example

# Set the IP version of APs in the AP group group1 to IPv4.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-group name group1
[HUAWEI-wlan-ap-group-group1] ap ip version ipv4
Warning: This operation may cause AP offline, Whether to continue? [Y/N]:y
