upload

Function

The upload command is used to upload a local file to a remote server with a specified URL.

Format

upload file-url local-file file-path [ [ ssl-policy policy-name [ ssl-verify peer [ verify-dns ] ] | verify-dns ] | user-name name-value password password-value | vpn-instance vpn-name | source-ip ip-address ] *

Parameters

Parameter Description Value
file-url

Specifies the URL of the remote server.

The value is a string of 1 to 255 characters.
local-file file-path

Specifies the path of the local file.

The value is a string of 1 to 255 characters.
ssl-policy policy-name

Specifies an SSL policy name.

The value is a string of 1 to 23 characters. If an initial certificate is loaded to the PKI realm to which the specified SSL policy is bound, the certificate is delivered in interactive mode.
ssl-verify

Specifies the SSL verify mode.

-
peer

Specifies the SSL peer verify mode.

-
verify-dns

Enable CN/SAN verification.

-
user-name name-value

Specifies the user name for server authentication.

The value is a string of 1 to 127 characters.
password password-value

Specifies the server authentication password.

The value is a string of 1 to 127 characters.
vpn-instance vpn-name

Specifies a VPN name.

The value is a string of 1 to 31 characters.
source-ip ip-address

Specifies the source address of a device. The value can be an IPv4 or IPv6 address.

IPv4 addresses are in dotted decimal notation.

IPv6 addresses are in colon hexadecimal notation.

Views

User view

Default Level

3: Management level

Usage Guidelines

  • The download command can be used to upload log files on the device to the corresponding server. The server can analyze the running status of the device based on the log files. When running this command, you need to specify a valid file path. If no SSL policy name is specified, the SSL policy name in the HTTP view is used.
  • If verify-dns is specified, the CN/SAN field verification of the server certificate is enabled.

Example

# Specify the source IPv6 address and upload the file in the local path to the remote server whose URL is https://[2001:db8:1::1]:443/new.log. The file test.log can be renamed new.log.
<HUAWEI> upload https://[2001:db8:1::1]:443/new.log local-file cfcard:/test.log ssl-policy test source-ip 2001:db8:1::2
# Upload a file from the local path to the remote server at https://10.1.1.1:443/new.log. The test.log file can be renamed new.log.
<HUAWEI> upload https://10.1.1.1:443/new.log local-file cfcard:/test.log ssl-policy test
# The initial certificate is loaded to the PKI realm to which the specified SSL policy is bound. Upload the file from the local path to the remote server whose URL is https://10.1.1.1:443/new.log. The test.log file can be renamed new.log.
<HUAWEI> upload https://10.1.1.1:443/new.log local-file cfcard:/test.log ssl-policy a
Warning: A preset certificate is loaded to the PKI domain bound to the specified SSL policy. The current operation has security risks. Continue? [Y/N]:Y
