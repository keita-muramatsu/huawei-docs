reset bgp vpnv6 dampening

Function

The reset bgp dampening command clears BGP VPNv6 route dampening information and releases dampened routes.

Format

reset bgp vpnv6 dampening

reset bgp vpnv6 dampening ipv6-address [ ipv6-mask-length ]

Parameters

Parameter Description Value
vpnv6

Clears route dampening information of BGP VPNv6 routes and releases suppressed routes.

-
ipv6-address

Indicates the IPv6 address.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
ipv6-mask-length

Specifies the network mask length.

The value is an integer that ranges from 0 to 128.

Views

User view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Route dampening can be used to suppress unstable routes. In most cases, BGP is deployed on complex networks where routes change frequently. To reduce the impact of frequent route flapping, BGP adopts route dampening to suppress unstable routes.

The reset bgp dampening command is used to clear the dampening information about specified BGP VPNv6 routes and release specified suppressed routes. If no IP address is specified in the command, the dampening information about all the BGP VPNv6 routes is cleared, and all suppressed routes are released.

Prerequisites

You can use display bgp routing-table dampened command to view information about suppressed routes.

Configuration Impact

After this command is run, the suppressed routes are released. If routes still change frequently, route flapping may occur, consuming a large number of bandwidth and CPU resources.

If ipv6-address ipv6-mask-length is not specified, running the reset bgp ipv6 dampening command clears IPv6 route dampening information in the entire BGP routing table.

Example

# Clear route dampening information of BGP VPNv6 routes and release suppressed routes.
<HUAWEI> reset bgp vpnv6 dampening 2001:DB8:1::1
