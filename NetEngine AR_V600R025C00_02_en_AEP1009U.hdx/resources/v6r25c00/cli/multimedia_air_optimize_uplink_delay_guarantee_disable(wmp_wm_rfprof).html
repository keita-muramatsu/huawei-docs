multimedia-air-optimize uplink-delay-guarantee disable

Function

The multimedia-air-optimize uplink-delay-guarantee disable command disables the delay guarantee function for uplink services.

The undo multimedia-air-optimize uplink-delay-guarantee disable command enables the delay guarantee function for uplink services.

By default, the delay guarantee function is enabled for uplink services.

Format

multimedia-air-optimize uplink-delay-guarantee disable

undo multimedia-air-optimize uplink-delay-guarantee disable

Parameters

None

Views

RRM profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If users have requirements on the air interface delay of uplink services, you can run this command to enable the delay guarantee function for uplink services. Then, the system will monitor the air interface delay of uplink services on the network in real time. When detecting that the current delay exceeds the configured guaranteed delay, the system triggers delay optimization for the corresponding service, trying its best to ensure that the optimized delay does not exceed the guaranteed delay.

The uplink services with a user priority of 5 or higher detected by the system are mainly voice services and non-buffered video streaming services, such as network video conferencing.

Prerequisites

The intelligent multimedia scheduling algorithm has been enabled using the multimedia-air-optimize enable command.

Example

# Enable the delay guarantee function for uplink services.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] rrm-profile name p1
[HUAWEI-wlan-rrm-prof-p1] multimedia-air-optimize enable
[HUAWEI-wlan-rrm-prof-p1] undo multimedia-air-optimize uplink-delay-guarantee disable
