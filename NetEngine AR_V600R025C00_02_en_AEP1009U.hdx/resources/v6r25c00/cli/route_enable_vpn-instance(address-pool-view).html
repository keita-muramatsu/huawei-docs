route enable vpn-instance (NAT instance address pool view)

Function

The route enable vpn-instance command generates OPRs for the addresses in a NAT address pool in a specified VPN.

The undo route enable vpn-instance command deletes the OPRs generated for the addresses in a NAT address pool in a specified VPN.

By default, the device does not generate OPRs for the addresses in a NAT address pool in other VPNs.

Format

route enable vpn-instance vpn-instance-name

undo route enable vpn-instance vpn-instance-name

Parameters

Parameter Description Value
vpn-instance-name

-

The value is a string of 1 to 31 case-sensitive characters without spaces. The VPN instance name cannot be _public_. The character string can contain spaces if it is enclosed with double quotation marks (").

Views

NAT instance address pool view

Default Level

2: Configuration level

Usage Guidelines

You can run the route enable vpn-instance command to configure a device to generate OPRs for addresses in a NAT address pool in a specified VPN. Blackhole routes in a maximum of four VPNs can be generated.

Example

# Configure the device to generate OPRs for addresses in a NAT address pool in the VPN instance vpna.
<HUAWEI> system-view
[HUAWEI] ip vpn-instance vpna
[HUAWEI-vpn-instance-vpna] ipv4-family
[HUAWEI-vpn-instance-vpna-af-ipv4] quit
[HUAWEI-vpn-instance-vpna] ipv6-family
[HUAWEI-vpn-instance-vpna-af-ipv6] quit
[HUAWEI-vpn-instance-vpna] quit
[HUAWEI] nat address-group nataddr 1
[HUAWEI-address-group-nataddr] route enable vpn-instance vpna
