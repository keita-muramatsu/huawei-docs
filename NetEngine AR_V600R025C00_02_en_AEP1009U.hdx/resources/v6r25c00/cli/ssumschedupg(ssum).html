upgrade-time

Function

The upgrade-time command configures a scheduled smart upgrade policy,

The undo upgrade-time command cancels the scheduled smart upgrade policy.

No scheduled smart upgrade policy is configured.

Format

upgrade-time { weekly week-day week-day-value | monthly month-day month-day-value | yearly date start-day-value } time action-time-value

undo upgrade-time

Parameters

Parameter Description Value
week-day week-day-value

Specifies a weekly device upgrade and the day of the week to trigger upgrade.

The value is an integer ranging from 1 to 7.
month-day month-day-value

Specifies a monthly device upgrade and the day of the month to trigger upgrade.

The value is an integer ranging from 1 to 31. If the specified date does not exist in a month, the month is skipped.
date start-day-value

Specifies a yearly device upgrade.

The value is in the MM-DD format. MM specifies the month, which is an integer ranging from 1 to 12. DD specifies the date, which is an integer ranging from 1 to 31.
action-time-value

Specifies the device upgrade time.

The value is in HH-MM format. HH is an integer ranging from 0 to 23. MM is an integer ranging from 0 to 59.

Views

Smart upgrade view

Default Level

3: Management level

Usage Guidelines

During smart upgrade, you can run this command to set the period to upgrade device, and the device will trigger the upgrade operation at the specified time, obtain the version from the HOUP and perform the upgrade task.

Example

# Perform the upgrade at 23:00 every Sunday.
<HUAWEI> system-view
[HUAWEI] smart-upgrade
[HUAWEI-smart-upgrade] upgrade-time weekly week-day 7 time 23:00
