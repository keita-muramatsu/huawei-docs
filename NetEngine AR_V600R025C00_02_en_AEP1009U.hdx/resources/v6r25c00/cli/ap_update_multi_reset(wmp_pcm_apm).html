ap update multi-reset

Function

The ap update multi-reset command resets APs in batches.

The undo ap update multi-reset partition command cancels the AP reset by channel-based partition.

Format

ap update multi-reset ap-type type-id [ ap-group group-name | { ap-id ap-id } &<1-10> ]

ap update multi-reset ap-group group-name [ { ap-id ap-id } &<1-10> ]

ap update multi-reset partition { all | partition-id partition-id }

undo ap update multi-reset partition

Parameters

Parameter Description Value
ap-group group-name

Resets APs in the specified AP group.

The value is a string of 1 to 35 visible characters that can be Chinese characters or a combination of Chinese and English characters. It cannot contain question marks (?) or only contain double quotation marks ("). If the AP group name contains spaces,it must be enclosed with double quotation marks (" "), for example, "huawei name1". The double quotation mark (") before and after the AP group name occupies two characters together. The specified AP group must exist.

Only the command editor in UTF-8 encoding format can be used to edit Chinese characters.
ap-id ap-id

Resets the AP with a specified ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
all

Resets APs in all channel-based partitions.

-
partition-id partition-id

Resets APs in the specified channel-based partition.

The value is an integer ranging from 0 to 255.
ap-type type-id

Resets APs with a specified type ID.

The value is an integer in the range from 0 to 1023.

Views

WLAN view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

This command resets APs in batches and can be used only after APs are upgraded in batches.

The ap update multi-reset ap-type type-id[ ap-group group-name| { ap-id ap-id} &<1-10> ] command is used to batch reset APs online by AP type. - If ap-group group-nameis specified, only APs of the specified type and in the specified AP group are reset.

  • If ap-id ap-idis specified, only APs of the specified type and with the specified AP ID are reset.
  • If neither ap-group group-namenor ap-id ap-idis specified, all APs of the specified type are reset.

    If the type of APs specified by ap-group group-nameor ap-id ap-idis different from the specified ap-type type-id, the APs cannot be reset.

The ap update multi-reset ap-group group-name[ { ap-id ap-id} &<1-10> ] command is used to batch reset APs by AP group.

  • If ap-id ap-idis specified, only APs with the specified AP ID in the specified AP group are reset.
  • If ap-id ap-idis not specified, all APs in the specified AP group are reset.
  • If APs specified by ap-id ap-idare not in the specified AP group, the APs cannot be reset.

The ap update multi-reset partition { all | partition-id partition-id} command is used to batch reset APs by channel-based partition. To perform an in-service upgrade for all APs on the network, you can divide APs into different partitions based on channels and reset the APs by partition in sequence after loading the target version files to all APs. This prevents network service interruption caused by resetting a large number of APs. During the reset of APs in a channel-based partition, their surrounding APs automatically fill coverage holes to ensure service continuity. Therefore, do not deploy only one AP for coverage at a site.

If an upgrade exception occurs when the ap update multi-reset partition all command is used to reset all RUs by channel-based partition, you can run the undo ap update multi-reset partition command to cancel the subsequent AP reset by channel-based partition.

Precautions

The AP reset by channel-based partition (in a multi-batch, scattered upgrade) is not supported by the following models:

  • AirEngine 5761-10W, AirEngine 5761S-10W, and AirEngine 5761-10WD
  • AirEngine X762 series APs (except the AirEngine 5762-12SW and AirEngine 5762S-12SW)

Example

# Reset APs with the type ID of 127 and based on AP IDs in batches. A maximum of 10 APs can be specified.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap update multi-reset ap-type 127 ap-id 0
Warning: Reset the APs in batches to make the upgrade take effect. Continue? [Y/N]:y
# Reset APs with specified IDs in the AP group group1 in batches. A maximum of 10 APs can be specified.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap update multi-reset ap-group group1 ap-id 0
Warning: Reset the APs in batches to make the upgrade take effect. Continue? [Y/N]:y
# Reset all APs with the type ID of 127 in batches.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap update multi-reset ap-type 127
Warning: Reset the APs in batches to make the upgrade take effect. Continue? [Y/N]:y
# Reset APs with the type ID of 127 in AP group group1 in batches.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap update multi-reset ap-type 127 ap-group group1
Warning: Reset the APs in batches to make the upgrade take effect. Continue? [Y/N]:y
# Reset all APs in the AP group group1 in batches.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap update multi-reset ap-group group1
Warning: Reset the APs in batches to make the upgrade take effect. Continue? [Y/N]:y
