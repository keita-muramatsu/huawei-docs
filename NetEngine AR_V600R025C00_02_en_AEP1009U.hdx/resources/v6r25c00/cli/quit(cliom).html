quit

Function

The quit command quits the current view command and displays the previous view.

Format

quit

Parameters

None

Views

All views

Default Level

0: Visit level

Usage Guidelines

Usage Scenario

The views are listed as follows in ascending order by the level:

  • User view
  • System view
  • Routing protocol view, interface view, or VPN group view

You can run the quit command to return from the current command view to a lower-level command view.

Configuration Impact

Run the quit command in the user view to log out of the system.

Precautions

If a configuration is not committed on the CLI, an interactive confirmation message is displayed after the quit command is run in the system view. If you enter Y, the uncommitted configuration is committed. If you enter N, the uncommitted configuration is deleted. If you enter C, the operation of exiting the system view is canceled.

Example

# Return from the system view to the user view.
<HUAWEI> system-view
Enter system view, return user view with return command.
[HUAWEI] sysname huawei
[HUAWEI] quit
Warning: Uncommitted configurations found, commit them before exiting? [Y(yes)/N(no)/C(cancel)]:Y
<HUAWEI>
# Return to the system view from the interface view.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] quit
[HUAWEI] quit
