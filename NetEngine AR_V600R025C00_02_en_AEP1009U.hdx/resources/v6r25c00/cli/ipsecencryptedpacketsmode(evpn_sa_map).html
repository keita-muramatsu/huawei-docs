ipsec-p2mp-policy encrypted-packets

Function

The ipsec-p2mp-policy encrypted-packets command configures the forwarding mode of encrypted packets.

The undo ipsec-p2mp-policy encrypted-packets command restores the default forwarding mode of encrypted packets.

By default, the forwarding mode of encrypted packets is the decryption-first mode.

Format

ipsec-p2mp-policy encrypted-packets { decryption-precedence | routing-precedence }

undo ipsec-p2mp-policy encrypted-packets [ decryption-precedence | routing-precedence ]

Parameters

Parameter Description Value
decryption-precedence

Specifies the decryption-first mode.

-
routing-precedence

Specifies the routing-first mode.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In most cases, you can retain the default forwarding mode of encrypted packets. If a device has an SD-WAN tunnel and requires loopback, you need to run the ipsec-p2mp-policy encrypted-packets routing-precedence command to configure the routing-first mode for forwarding encrypted packets. Loopback in this scenario refers to the process where an SD-WAN tunnel's outbound interface routes packets out and back to the same device for further forwarding.

Precautions

The device performance in routing-first mode is slightly lower compared to decryption-first mode.

Example

# Set the forwarding mode of SD-WAN encrypted packets to the routing-first mode.
<HUAWEI> system-view
[HUAWEI] ipsec-p2mp-policy encrypted-packets routing-precedence
