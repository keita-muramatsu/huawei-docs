display ips signature-action

Function

The display ips signature-action command displays the configuration of predefined signatures.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

display ips signature-action

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

This command is used to check the actions of predefined signatures.

Example

The actual command output varies according to the device. The command output here is only an example.

# View the configuration of all predefined signature
<HUAWEI> display ips signature-action
 --------------------------------------------------------------------
  Global    : alert                                                   
  Count     : 2                                                       
  Committed : committed                                               
 --------------------------------------------------------------------
  Signature-ID    Configured-Action    Default-Action    Committed      
 --------------------------------------------------------------------
  284860          block               alert            committed   
  284601          allow               alert            committed
Table 1 Description of the display ips signature-action command output
Item Description
Global

Actions of all predefined signatures, including:

  • non-configured: indicates that no action is configured for a signature.
  • alert: indicates that the action of each predefined signature is alert.
Count

Number of single signatures whose actions are modified.
Committed

Whether the actions configured for predefined signatures are committed:

  • committed.
  • not committed.
Signature-ID

ID of a predefined signature.
Configured-Action

Predefined signature actions, including:

  • allow.
  • alert.
  • block.
Default-Action

Action in the intrusion prevention signature database. The options are as follows:

  • allow: The action of the pre-defined signature is permit.
  • alert: The action of the pre-defined signature is alert.
  • block: The action of the pre-defined signature is block.
