display mvpn sdwan

Function

The display mvpn sdwan command displays SD-WAN information about MVPN services.

Format

display mvpn { all-instance | vpn-instance vpn-instance-name } sdwan [ grpAddr | srcAddr ] *

Parameters

Parameter Description Value
all-instance

Displays SD-WAN information in all instances.

-
vpn-instance vpn-instance-name

Displays SD-WAN information in a VPN instance.

The value is a string of 1 to 31 case-sensitive characters without spaces. The VPN instance name cannot be _public_. The character string can contain spaces if it is enclosed with double quotation marks (").
grpAddr

Displays SD-WAN information of a specified multicast group in a VPN instance.

The value is in dotted decimal notation and ranges from 224.0.1.0 to 239.255.255.255.
srcAddr

Displays SD-WAN information of a specified multicast source in a VPN instance.

The value is in dotted decimal notation.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

After an MVPN SD-WAN is configured, to determine whether the MVPN SD-WAN is working normally based on SD-WAN information of MVPN services, run the display mvpn sdwan command. If the display mvpn sdwan command is run on the root node of a tunnel, information about the root node and all leaf nodes of the tunnel is displayed. If the display mvpn sdwan command is run on a leaf node of a tunnel, information about the root node and leaf node of the tunnel is displayed.

Precautions

If no SD-WAN is established, no output is displayed after the display mvpn sdwan command is run.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display SD-WAN information of a VPN instance on the leaf node.
<HUAWEI> display mvpn vpn-instance VPNA sdwan
MVPN local SD-WAN information for VPN-Instance: VPNA
Tunnel type: SD-WAN
Tunnel state: --
Root: (10.1.1.1, 225.1.1.1, SD-WAN Site 1)
Leaf:
  0: SD-WAN Site 2 (local)
# Display SD-WAN information of a VPN instance on the root node.
<HUAWEI> display mvpn vpn-instance VPNA sdwan
MVPN local SD-WAN information for VPN-Instance: VPNA
Tunnel type: SD-WAN
Tunnel state: --
Root: (10.1.1.1, 225.1.1.1, SD-WAN Site 1) (local)
Leaf:
  0: SD-WAN Site 2
