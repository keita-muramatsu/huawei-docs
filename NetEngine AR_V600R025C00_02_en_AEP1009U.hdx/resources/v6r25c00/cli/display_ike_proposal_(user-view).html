display ike proposal (User view)

Function

The display ike proposal command displays the IKE proposal configuration.

Format

display ike proposal [ number proposal-number | default ] slot slot-id cpu cpu-id

Parameters

Parameter Description Value
number proposal-number

Specifies the number of an IKE proposal. A smaller IKE proposal number indicates a higher priority.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer that ranges from 1 to 32 for 2G models and from 1 to 64 for 4G models.

For the AR8700 series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series and AR6700-H series:The value is an integer ranging from 1 to 1024.
default

Displays a default IKE proposal information.

-
slot slot-id

Specifies a slot ID.

The value varies depending on device models.
cpu cpu-id

Specifies the CPU ID.

The value varies depending on device models.

Views

User view

Default Level

1: Monitoring level

Usage Guidelines

IKE proposals are displayed in ascending order of IKE proposal number.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the configuration of all IKE proposals.
<HUAWEI> display ike proposal slot 0 cpu 0

Number of IKE Proposals: 2

-------------------------------------------

   Integrity Algorithm        : HMAC-SHA2-256
   Prf Algorithm              : HMAC-SHA2-256 
-------------------------------------------

-------------------------------------------

Table 1 Description of the display ike proposal (User view) command output
Item Description
Number of IKE Proposals

Number of the IKE proposal.
IKE Proposal

Number of an IKE proposal, indicating the priority of the IKE proposal.
Authentication Method

Authentication method used in the IKE proposal:

  • PRE_SHARED: pre-shared key authentication.
  • RSA-SIGNATURE: RSA signature authentication.
  • SM2-DIGITAL-ENVELOPE: SM2 digital envelope authentication.
Authentication Algorithm

Authentication algorithm used by the IKE proposal. Only IKEv1 is supported.
Encryption Algorithm

Encryption algorithm used in the IKE proposal:

  • DES: 56-bit DES-CBC encryption algorithm.
  • 3DES: 168-bit 3DES-CBC encryption algorithm.
  • AES-128: 128-bit AES algorithm in CBC mode.
  • AES-192: 192-bit AES algorithm in CBC mode.
  • AES-256: 256-bit AES algorithm in CBC mode.
  • SM4: SM4 algorithm.
  • AES-GCM-128: 128-bit AES algorithm in GCM mode.
  • AES-GCM-192: 192-bit AES algorithm in GCM mode.
  • AES-GCM-256: 256-bit AES algorithm in GCM mode.
Diffie-Hellman Group

DH group in the IKE proposal:

  • MODP-768: 768-bit Diffie-Hellman group.
  • MODP-1024: 1024-bit Diffie-Hellman group.
  • MODP-1536: 1536-bit Diffie-Hellman group.
  • MODP-2048: 2048-bit Diffie-Hellman group.
  • MODP-3072: 3072-bit Diffie-Hellman group.
  • MODP-4096: 4096-bit Diffie-Hellman group.
  • MODP-8192: 8192-bit Diffie-Hellman group.
  • ECP-256: 256-bit ECP Diffie-Hellman group.
  • ECP-384: 384-bit ECP Diffie-Hellman group.
  • ECP-521: 521-bit ECP Diffie-Hellman group.
  • MODP-2048-WITH-256-SUBGROUP: 2048-bit Diffie-Hellman group that includes a 256-bit sub-group.
SA Duration(Seconds)

IKE SA lifetime.
Integrity Algorithm

Integrity algorithm in the IKE proposal:

  • AES-XCBC-96: AES-XCBC-96 algorithm.
  • HMAC-MD5-96: HMAC-MD5-96 algorithm.
  • HMAC-SHA1-96: HMAC-SHA1-96 algorithm.
  • HMAC-SHA2-256: HMAC-SHA2-256 algorithm.
  • HMAC-SHA2-384: HMAC-SHA2-384 algorithm.
  • HMAC-SHA2-512: HMAC-SHA2-512 algorithm.
Prf Algorithm

Algorithm used to generate a pseudo random number in the IKE proposal:

  • AES-XCBC-128: AES-XCBC-128 algorithm.
  • HMAC-MD5: HMAC-MD5 algorithm.
  • HMAC-SHA1: HMAC-SHA1 algorithm.
  • HMAC-SHA2-256: HMAC-SHA2-256 algorithm.
  • HMAC-SHA2-384: HMAC-SHA2-384 algorithm.
  • HMAC-SHA2-512: HMAC-SHA2-512 algorithm.
