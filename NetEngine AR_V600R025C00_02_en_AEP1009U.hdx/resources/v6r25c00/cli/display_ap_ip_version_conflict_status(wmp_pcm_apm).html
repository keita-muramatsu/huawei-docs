display ap ip-version-conflict status

Function

The display ap ip-version-conflict status command displays whether the IP address version of an AP is consistent with that of the standby AC and another third-party server.

Format

display ap ip-version-conflict status { all | backup-ac | log-server | wmi-server | spectrum-server }

Parameters

Parameter Description Value
all

Displays whether the IP address version of an AP is consistent with that of the standby AC and another third-party server.

-
backup-ac

Displays whether the IP address version of an AP is consistent with that of the standby AC.

-
log-server

Displays whether the IP address version of an AP is consistent with that of the log server.

-
wmi-server

Displays whether the IP address version of an AP is consistent with those of the standby AC, log server, and WMI server.

-
spectrum-server

Displays whether the IP address version of an AP is consistent with that of the spectrum analysis server to which the AP directly reports data.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

APs and WACs support CAPWAP dual-stack communication. However, when APs interwork with external NEs, only one IP address version is supported.

  • An AP uses the same IP address but cannot use IP addresses of different versions to communicate with active and standby WACs (in dual-link or N+1 backup mode).
  • An AP uses the same IP address to communicate with the log server, spectrum analysis server, and WMI server. If multiple APs need to use IP protocols of different versions to connect to the same third-party server, the server must support both IPv4 and IPv6.

You can run the display ap ip-version-conflict status command to check whether the IP version of APs is consistent with that of the standby WAC and third-party servers.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display whether the IP address version of an AP is consistent with that of the backup AC and another third-party server.
<HUAWEI> display ap ip-version-conflict status all
Total: 1
AP ID  AP MAC          AP IP          Backup-ac  Log-server  WMI-server  Spectrum-server
------------------------------------------------------------------------------------------
1      00e0-fc11-1111  192.168.1.1    match      -           match       -              
------------------------------------------------------------------------------------------
Table 1 Description of the display ap ip-version-conflict status command output
Item Description
AP ID

AP ID.
AP MAC

MAC address of an AP.
AP IP

IP address of an AP.
Backup-ac/Log-server/WMI-server/Spectrum-server

Whether the IP address version of an AP is consistent with that of the standby AC, log server, WMI server, or spectrum analysis server.

  • match: consistent.
  • mismatch: not consistent.
  • -:

    -When Backup-ac or Log-server is displayed as -, the standby AC or log server is not configured.

    • When WMI-server is displayed as -, the WMI server is not configured or the AP does not support WMI.
    • When Spectrum-server is displayed as -, the spectrum analysis server is not configured or the AP is configured to report data through the AC.
Total

Total count.
