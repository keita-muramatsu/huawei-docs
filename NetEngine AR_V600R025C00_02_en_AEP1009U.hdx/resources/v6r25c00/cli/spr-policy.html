spr-policy

Function

The spr-policy command creates an SPR policy profile and displays the SPR policy profile view, or displays the view of an existing SPR policy profile.

The undo spr-policy command deletes an SPR policy profile.

By default,no policy profile is configured in SPR.

Format

spr-policy node node-index

undo spr-policy node node-index

Parameters

Parameter Description Value
node node-index

Specifies the node index of a policy profile. When a policy profile is used, the policy profile with a higher priority takes effect preferentially. When multiple policy profiles have the same priority, the policy profile with a smaller node index takes effect preferentially.

The value is an integer that ranges from 1 to 30000.

Views

Smart-policy-route view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

You need to associate service flows that need to be forwarded based on SPR with a service profile, and set the link group, service delay threshold, packet loss rate threshold, and CMI threshold in the service profile. SPR matches the service profile to classify traffic, and implements intelligent traffic steering for service flows based on the parameters configured in the policy profile.

Prerequisites

SPR has been configured using the smart-policy-route command.

Example

# Create policy profile policy1, and enter the policy profile view.
<HUAWEI> system-view
[HUAWEI] smart-policy-route
[HUAWEI-smart-policy-route] spr-policy node 1
[HUAWEI-smart-policy-route-spr-policy-node-1]
