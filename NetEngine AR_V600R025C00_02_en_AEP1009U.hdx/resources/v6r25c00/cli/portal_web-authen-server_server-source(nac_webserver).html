portal web-authen-server server-source

Function

The portal web-authen-server server-source command configures the local gateway address used by the device to receive and respond to packets from terminals when the Portal interconnection function of the HTTP or HTTPS protocol is enabled.

The undo portal web-authen-server server-source command restores the default configuration.

By default, the device does not receive or respond to all packets from terminals in the Portal interconnection function of the HTTP or HTTPS protocol.

Format

portal web-authen-server server-source all-interface

portal web-authen-server server-source ip-address ip-address

undo portal web-authen-server server-source all-interface

undo portal web-authen-server server-source ip-address

Parameters

Parameter Description Value
ip-address ip-address

Specifies the local gateway address used by the device to receive and respond to the packets sent by the Portal server.

The value is in dotted decimal notation.
all-interface

Sets the IPv4 address to 0.0.0.0. That is, the device can receive and respond to all packets from the terminal.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If the device connects to a Portal server that supports only HTTP/HTTPS, run the portal web-authen-server command on the device to enable the Portal interconnection function of HTTP/HTTPS. To use the Portal interconnection function, run the portal web-authen-server server-source command to configure the local gateway address for the device to receive and respond to packets from terminals.

Precautions

· After the portal web-authen-server server-source all-interface command is run, the device receives all packets from terminals, which increases system security risks. Therefore, you are not advised to run this command.

· After the portal web-authen-server server-source all-interface command is run, the system clears all configurations of the portal web-authen-server server-source ip-address ip-address command.

· If the portal web-authen-server server-source all-interface command has been run on the device, the portal web-authen-server server-source ip-address ip-address command configured later will fail to be delivered.

Example

# In the Portal interconnection function, specify the gateway address used by the device to receive and respond to the packets sent by the Portal server.
<HUAWEI> system-view
[HUAWEI] portal web-authen-server server-source ip-address 10.1.1.1
# In the Portal interconnection function, specify any IP address as the gateway address for the device to receive and respond to packets sent by the Portal server.
<HUAWEI> system-view
[HUAWEI] portal web-authen-server server-source all-interface
