ap update multi-load

Function

The ap update multi-load command upgrades APs in batches.

The undo ap update multi-load command cancels the batch AP upgrade.

Format

ap update multi-load ap-type type-id [ ap-group group-name | { ap-id ap-id } &<1-10> ]

ap update multi-load ap-group group-name [ { ap-id ap-id } &<1-10> ]

undo ap update multi-load ap-type type-id [ ap-group group-name | { ap-id ap-id } &<1-10> ]

undo ap update multi-load ap-group group-name [ { ap-id ap-id } &<1-10> ]

Parameters

Parameter Description Value
ap-group group-name

Specifies an AP group.

The value is a string of 1 to 35 visible characters that can be Chinese characters or a combination of Chinese and English characters. It cannot contain question marks (?) or only contain double quotation marks ("). If the AP group name contains spaces,it must be enclosed with double quotation marks (" "), for example, "huawei name1". The double quotation mark (") before and after the AP group name occupies two characters together. The specified AP group must exist.

Only the command editor in UTF-8 encoding format can be used to edit Chinese characters.
ap-id ap-id

Specifies the AP ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
ap-type type-id

Specifies the AP type ID.

The value is an integer in the range from 0 to 1023.

Views

WLAN view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

The ap update multi-load ap-type type-id[ ap-group group-name| { ap-id ap-id} &<1-10> ] command is used to batch upgrade APs online by AP type.

  • If ap-group group-nameis specified, only APs of the specified type and in the specified AP group are upgraded.
  • If ap-id ap-idis specified, only APs of the specified type and with the specified AP ID are upgraded.
  • If neither ap-group group-namenor ap-id ap-idis specified, all APs of the specified type are upgraded. If the type of APs specified by ap-group group-nameor ap-id ap-idis different from the specified ap-type type-id, the APs cannot be upgraded.

The ap update multi-load ap-group group-name[ { ap-id ap-id} &<1-10> ] command is used to batch upgrade APs online by AP group.

  • If ap-id ap-idis specified, only APs with the specified AP ID in the specified AP group are upgraded.
  • If ap-id ap-idis not specified, all APs in the specified AP group are upgraded.
  • If APs specified by ap-id ap-idare not in the specified AP group, the APs cannot be upgraded.

Prerequisites

The AP upgrade file has been specified using the ap update update-filename command.

Follow-up Procedure

Run the ap update multi-reset command to reset APs in batches to make the AP upgrade take effect.

Precautions

You can run the undo ap update multi-load command to cancel the batch AP upgrade. However, if the AP system software is written to the flash memory during the AP upgrade, the AP upgrade cannot be canceled. You can run the display ap update status all command to check the AP upgrade progress.

SFTP is recommended because it is more secure than FTP.

Example

# Upgrade APs with the AP type ID of 127 in batches.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap update multi-load ap-type 127
# Cancel the batch upgrade of all APs with the AP type ID of 127 in the AP group named group1.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] undo ap update multi-load ap-type 127 ap-group group1
# Upgrade APs with specified IDs in the AP group named group1 in batches. A maximum of 10 APs can be specified.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap update multi-load ap-group group1 ap-id 0
# Cancel the batch upgrade of APs with specified IDs in the AP group named group1 based on the AP group name and ID. A maximum of 10 APs can be specified.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] undo ap update multi-load ap-group group1 ap-id 0
# Upgrade all APs in the AP group named group1 in batches.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap update multi-load ap-group group1
# Cancel the batch upgrade of all APs with the AP type ID of 127.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] undo ap update multi-load ap-type 127
# Upgrade APs with the AP type ID of 127 and based on AP IDs in batches. A maximum of 10 APs can be specified.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap update multi-load ap-type 127 ap-id 0
# Cancel the batch upgrade of APs with the AP type ID of 127 and based on AP IDs in batches. A maximum of 10 APs can be specified.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] undo ap update multi-load ap-type 127 ap-id 0
# Upgrade APs with the AP type ID of 127 in the AP group named group1 in batches.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap update multi-load ap-type 127 ap-group group1
# Cancel the batch upgrade for all APs in the AP group named group1.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] undo ap update multi-load ap-group group1
