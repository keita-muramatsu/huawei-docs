poe power auto-neg enable

Function

The poe power auto-neg enable command enables power auto-negotiation on an interface.

The undo poe power auto-neg enable command disables power auto-negotiation on an interface.

By default, power auto-negotiation is disabled on an interface.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA.

Format

poe power auto-neg enable

undo poe power auto-neg enable

Parameters

None

Views

10GE interface view, 25GE interface view, GE interface view, Multi-GE interface view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Some APs support both IEEE 802.3at and 802.3af. The device can supply power to these APs in accordance with IEEE 802.3af (the maximum output power is 15.4 W). When the APs connected to the device support both power supply standards, enable power auto-negotiation on the interfaces connected to these APs. When the total available power of the device is less than 30 W and the device detects that the current power supply standard of an AP is IEEE 802.3at, the device can send an LLDP packet to the AP to enable the AP to set its power supply standard to IEEE 802.3af. Power auto-negotiation changes only the power supply standard of APs but not that of the interfaces to which the APs are connected.

You can enable power auto-negotiation on interfaces connected to APs to change the power supply standards of the APs, reduce the power consumption of the APs, and enable the device to supply power to more APs when the rated output power of the device is fixed.

Precautions

  1. This command is supported only on Layer 2 interfaces.
  2. This command is mutually exclusive with the lldp dot3-tlv power 802.1ab force and lldp dot3-tlv power 802.3at commands.

Example

# Enable power auto-negotiation on an interface.
<HUAWEI> system-view
[HUAWEI] interface GE 1/0/1
[HUAWEI-GE1/0/1] poe power auto-neg enable
Warning: This operation will enable PoE power auto-negotiation of the port, which will change the power-up mode of the PD connected to the port from AT to AF(or BT to AF) in case of insufficient power. Continue?[Y/N]:y
