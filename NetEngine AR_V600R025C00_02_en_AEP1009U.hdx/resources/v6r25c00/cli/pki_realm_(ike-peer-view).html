pki realm (IKE peer view)

Function

The pki realm command binds a public key infrastructure (PKI) realm to an IKE peer.

The encryption-certificate pki realm command configures a PKI encryption realm for an IKE peer.

The signature-certificate pki realm command configures a PKI signature realm for an IKE peer.

The undo pki realm command unbinds a PKI realm from an IKE peer.

The undo encryption-certificate pki realm command deletes the PKI encryption realm configured for an IKE peer.

The undo signature-certificate pki realm command deletes the PKI signature realm configured for an IKE peer.

By default, no PKI realm is bound to an IKE peer.

Format

[ encryption-certificate | signature-certificate ] pki realm realm-name

undo pki realm

undo encryption-certificate pki realm

undo signature-certificate pki realm

Parameters

Parameter Description Value
realm realm-name

Specifies the name of a PKI realm.

The PKI realm must already exist.

Views

IKE peer view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

A PKI realm is a set of configuration information required by a PKI entity to enroll a certificate.

After a PKI realm is specified on an IKE peer, the IKE peer can obtain the local CA certificate and local certificate based on the configuration in the PKI realm.

In digital envelope authentication scenarios, you need to configure the PKI encryption realm where the encryption certificate resides and the PKI signature realm where the signature certificate resides on the IKE peer.

The encryption certificate used for digital envelope authentication needs to be imported to the device using the pki import-certificate local realm realm-name { der | pkcs12 | pem } filename file-name no-check-same-name command. The no-check-same-name parameter allows the device to import the encryption certificate and signature certificate with the same issuer and subject names. In addition, the CA certificate needs to be imported to the PKI signature realm.

Prerequisites

A PKI realm has been created using the pki realm command in the system view. And the CA certificate and local certificate have been imported in the PKI realm.

Example

# Bind the PKI realm test to the IKE peer. 
<HUAWEI> system-view
[HUAWEI] pki realm test
[HUAWEI-pki-realm-test] quit
[HUAWEI] ike peer huawei
[HUAWEI-ike-peer-huawei] pki realm test
