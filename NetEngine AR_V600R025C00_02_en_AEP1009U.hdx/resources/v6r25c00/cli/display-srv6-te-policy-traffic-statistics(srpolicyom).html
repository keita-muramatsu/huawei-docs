display srv6-te policy traffic-statistics

Function

The display srv6-te policy traffic-statistics command is used to query the SRv6 TE Policy traffic statistics count.

Format

display srv6-te policy traffic-statistics [ endpoint endpoint-ip color color-value | policy-name name-value | binding-sid binding-sid ]

Parameters

Parameter Description Value
endpoint endpoint-ip

Specifies the endpoint of an SRv6 TE Policy.

The value is a 32-digit hexadecimal string in format X:X:X:X:X:X:X:X.
color color-value

Specifies a color value for an SRv6 TE Policy.

The value is an integer ranging from 0 to 4294967295.
policy-name name-value

Specifies the name of an SRv6 TE Policy.

The value is a string of 1 to 255 case-sensitive characters. If the string is enclosed in double quotation marks ("), spaces are allowed in the string.
binding-sid binding-sid

Specifies a binding SID.

The value is a 32-digit hexadecimal string in format X:X:X:X:X:X:X:X.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

The display srv6-te policy traffic-statistics command is used to query the SRv6 TE Policy traffic statistics count.

Table 1 Description of the display srv6-te policy traffic-statistics command output
Item Description
Policy Name

Name of an SRv6 TE Policy.
Color

Color value of an SRv6 TE Policy.
Endpoint

Endpoint of an SRv6 TE Policy.
TunnelId

Tunnel ID of an SRv6 TE Policy.
Binding SID

Binding SID.
Last -- seconds output rate

The output rate of traffic in the most recent period.
Realtime -- seconds output rate

Traffic rate during the two collection periods.
Primary Candidate-path

If the primary path exists, details and traffic statistics are displayed.
Preference

Path priority.
Discriminator

Discriminator of an SRv6 TE Policy's primary path. In the static configuration candidate path scenario, the value of the Discriminator is the same as that of the preference. In the case of BGP sends an SRv6 TE Policy, the value is the Discriminator in the BGP TLV.
Protocol-Origin

Protocol origin of a candidate path configured for an SRv6 TE Policy.

  • 10: delivered by PCEP.
  • 20: delivered by BGP.
  • 30: locally configured.
Originator

Originator of an SRv6 TE Policy's primary path. The value is in the <ASN, node-address> format, where ASN indicates an AS number.

  • The value of ASN in the static configuration scenario is 0. In the case of BGP sends an SRv6 TE Policy, the ASN is the AS number carried in the BGP TLV.
  • The value of node-address in the static configuration scenario is fixed to 0.0.0.0. When BGP sends an SRv6 TE Policy, the node-address is the router ID of the BGP neighbor.
Segment-List ID

ID of a segment list configured for an SRv6 TE Policy's candidate path.
Segment-List Name

Name of the segment list referenced by the candidate path of the SRv6 TE Policy. If no, the "-" is displayed.
Backup Candidate-path

If the Backup path exists, details and traffic statistics are displayed.
Output

Numbers of output bytes and packets.
