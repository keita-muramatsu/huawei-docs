color-flag (IFIT-native-ip view)

Function

The color-flag command configures a color bit for packet loss and delay measurement.

The undo color-flag command restores the default color bit for packet loss and delay measurement.

By default, bit 0 in the Flags field is used as the color bit.

Format

color-flag { tos-bit { bit3 | bit4 | bit5 | bit6 | bit7 } | flags-bit0 }

undo color-flag { tos-bit { bit3 | bit4 | bit5 | bit6 | bit7 } | flags-bit0 }

Parameters

Parameter Description Value
tos-bit

Indicates the ToS coloring bit.

-
bit3

Specifies the third bit in the ToS field.

-
bit4

Specifies the fourth bit in the ToS field.

-
bit5

Specifies the fifth bit in the ToS field.

-
bit6

Specifies the sixth bit in the ToS field.

-
bit7

Specifies the seventh bit in the ToS field.

-
flags-bit0

Indicates Bit 0 in the Flags field.

-

Views

IFIT-native-ip view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The packet loss and delay measurement of native-IP IFIT is implemented by marking the IP header. Either the ToS or Flags field in the IPv4 header can be used as the color bit to uniquely identify service packets with a specific characteristic. You can run this command to flexibly adjust the color bit used for packet loss and delay measurement.

Precautions

  • When you modify a color bit, the system displays a message indicating that the color bit must be unique across the network. Otherwise, the statistics will be abnormal.
  • The ToS field is easily occupied by other services. Therefore, you are advised to use the 0th bit of the Flags field as the color bit by default.

Example

# Set the packet loss and delay measurement flag to ToS Bit3.
<HUAWEI> system-view
[HUAWEI] ifit
[HUAWEI-ifit] flow-learning native-ip
[HUAWEI-ifit-native-ip] color-flag tos-bit bit3
