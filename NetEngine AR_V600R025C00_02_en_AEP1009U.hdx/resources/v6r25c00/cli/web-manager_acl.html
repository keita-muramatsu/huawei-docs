web-manager acl

Function

The web-manager acl command specifies an ACL for the Web server.

The undo web-manager acl command cancels the specified ACL of the Web server.

By default, no ACL is specified for the web server.

Format

web-manager acl { acl-number | acl-name }

web-manager ipv6 acl { acl6-number | acl6-name }

undo web-manager [ ipv6 ] acl

Parameters

Parameter Description Value
acl-number

Applies a basic or advanced ACL.

The value is an integer. The value of a basic ACL ranges from 2000 to 2999, and the value of an advanced ACL ranges from 3000 to 3999.
acl-name

Specifies the name of an ACL4.

The value is a string of 1 to 32 case-sensitive characters. It cannot contain spaces.
acl6-number

Applies a basic or advanced ACL6.

The value is an integer ranging from 2000 to 3999.
acl6-name

Specifies the name of an ACL6.

The value is a string of 1 to 32 case-sensitive characters. It cannot contain spaces.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

This command is used to configure an access control policy for the web server. When a rule is matched, the device performs the action specified in the rule. If the action is permit, the device can access the web server. If the action is deny, the device cannot access the web server. If no rule is matched, the access to the web server is not allowed.

Precautions

If no rule is configured in the ACL, the web access traffic is not limited after this command is run.

Example

# Apply ACL 2000 to the web server.
<HUAWEI> system-view
[HUAWEI] acl 2000
[HUAWEI-acl4-basic-2000] quit
[HUAWEI] web-manager acl 2000
