port mode

Function

The port mode command configures the rate mode of an optical interface.

The undo port mode command restores the default rate mode of an optical interface.

By default, an optical interface works at the rate of the installed medium that supports rate auto-sensing. If a medium that does not support rate auto-sensing is installed on an optical interface, the interface does not go up.

Format

port mode 10G

undo port mode [ 10G ]

Parameters

Parameter Description Value
10G

Sets the rate mode of a 25GE optical interface to 10G.

Before running the port mode 10G command, ensure that a specific medium has been installed or the 25GE medium has been pre-configured on the optical interface, and that the interface is down. For details about the supported media, see "Usage Guidelines.".

After the port mode 10G command is run, running the clear configuration interface command does not clear the configuration when a transmission medium is installed on the interface, but it clears the configuration when no transmission medium is installed on the interface.

-

Views

Layer 2 10GE interface view, 10GE interface view, 25GE-L2 view, 25GE interface view, GE optical interface view, GE interface view, GE electrical interface view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To improve the application scenarios of a device, most optical interfaces on the device support multiple rate modes. The rate mode of an optical interface is automatically adapted based on the rate of the installed medium. For example, an optical interface supports two rate modes: mand n. If a medium with a rate of mis installed on the optical interface, the rate mode of the optical interface is m. If a medium with a rate of nis installed on the optical interface, the rate mode of the optical interface is automatically switched to n. (Note: mand nindicate the interface rates.)

However, optical interfaces on some devices cannot all work in auto-sensing mode. If a medium that does not support rate auto-sensing is installed on an optical interface, the interface cannot go up or work properly.

In this case, you can run this command to change the interface rate mode to match the medium rate so that the interface can work properly.

Precautions

  • The remote interface must be configured to work in the same rate mode as the local interface.
  • The port mode 10GE command takes effect only on 25GE interfaces that support SFP-25G-ESR optical modules and have them installed.

Example

# Set the rate mode of 25GE0/0/1 to 10G.
<HUAWEI> system-view
[HUAWEI] interface 25ge 0/0/1
[HUAWEI-25GE0/0/1] port mode 10G
