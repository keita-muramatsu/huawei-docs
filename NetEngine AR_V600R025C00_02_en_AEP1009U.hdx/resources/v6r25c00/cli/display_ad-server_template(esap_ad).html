display ad-server template

Function

The display ad-server template command displays the configurations of AD server templates.

Format

display ad-server template [ name template-name ]

Parameters

Parameter Description Value
name template-name

Displays the configuration of a specified AD server template. If this parameter is not specified, the configurations of all AD server templates are displayed.

The value is a string of 1 to 32 case-sensitive characters. It cannot contain spaces.

Views

All views

Default Level

3: Management level

Usage Guidelines

This command displays the configurations of AD server templates, which helps locate AD server faults.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the configuration of the AD server template temp.
<HUAWEI> display ad-server template name temp

Table 1 Description of the display ad-server template command output
Item Description
Server-template-name

Name of an AD server template.
Base DN

Base DN of an AD server.
Administrator anonymous bind

Whether to allow the administrator to access an AD server anonymously:

  • Yes: allows the administrator to access the AD server anonymously.
  • No: prohibits the administrator from accessing the AD server anonymously.
Manager DN

Administrator Base DN for accessing an AD server.
Manager password

Administrator password for accessing an AD server.
Primary-authentication-server

IP address of the primary AD server.
Primary-authentication-server host name

Name of the primary AD server.
Secondary-authentication-server

IP address of the secondary AD server.
Secondary-authentication-server host name

Name of the secondary AD server.
Third-authentication-server

IP address of the tertiary AD server.
Third-authentication-server host name

Name of the tertiary AD server.
Authentication-Server-URL

URL of the AD server.
AD-server Ldap port

LDAP port of an AD server.
Bind manager with Base DN

Whether to attach the Base DN to the administrator DN:

  • Yes: attaches the Base DN to the administrator DN.
  • No: does not attach the Base DN to the administrator DN.
Bind user when authorization

Whether to perform user binding during AD authorization.
