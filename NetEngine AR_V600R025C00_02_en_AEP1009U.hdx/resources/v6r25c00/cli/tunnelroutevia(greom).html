tunnel route-via

Function

The tunnel route-via command specifies an outbound interface for an mGRE tunnel route.

The undo tunnel route-via command restores the default configuration.

By default, no outbound interface is specified for an mGRE tunnel.

Format

tunnel route-via { interface-type interface-num | interface-name } { mandatory | preferred }

undo tunnel route-via { interface-type interface-num | interface-name } { mandatory | preferred }

Parameters

Parameter Description Value
interface-type

Specifies the type of an mGRE tunnel's outbound interface.

The value is a string of 1 to 63 case-sensitive characters, spaces not supported.
interface-num

Specifies the number of an mGRE tunnel's outbound interface.

The value is a string of 1 to 63 case-sensitive characters, spaces not supported.
interface-name

Specifies the name of an mGRE tunnel's outbound interface.

The value is a string of 1 to 63 case-sensitive characters, spaces not supported.
mandatory

Configures packets to be strictly sent through the specified outbound interface. If the outbound interfaces of a route to the destination address of a GRE tunnel do not contain the specified outbound interface, the tunnel interface is down. The mGRE tunnel status is not affected by this command.

The value is a string of case-insensitive characters. It cannot contain spaces.
preferred

Configures packets to be preferentially sent through the specified outbound interface. If the outbound interfaces of a route to the destination address of a GRE tunnel do not contain the specified outbound interface, another interface can be selected to send packets, and the tunnel can go up. The mGRE tunnel status is not affected by this command.

The value is a string of case-insensitive characters. It cannot contain spaces.

Views

Tunnel interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

For an mGRE tunnel, if the equal-cost route from the spoke or hub to the peer GRE destination address has multiple physical links and you need to specify a physical outbound interface for GRE packets, run the tunnel route-via command in the mGRE tunnel interface view. Then, all GRE packets encapsulated with the mGRE tunnel header are sent through this outbound interface.

Prerequisites

To specify an outbound interface for an mGRE tunnel, run the tunnel-protocol gre p2mp command.

Example

# Configure an interface as the outbound interface of an mGRE tunnel.
<HUAWEI> system-view
[HUAWEI] interface Tunnel 0
[HUAWEI-Tunnel0] tunnel-protocol gre p2mp
[HUAWEI-Tunnel0] tunnel route-via 10GE0/0/1 mandatory
