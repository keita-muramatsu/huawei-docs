display fwm eth information component

Function

The display fwm eth information component command displays hash entries on the forwarding management module.

Format

display fwm eth information component fwmd slot slotid portsec interface { interfaceName | interfaceType interfaceNum }

display fwm eth information component fwmd slot slotid records mstp state-arbitration

display fwm eth information component fwmd slot slotid records mac avltree avltreeType avltreeTypeIndex [ avlNode avlNodeIndex ]

display fwm eth information component fwmd slot slotid records mac learn-mode slfaction interface { interfaceName | interfaceType interfaceNum }

display fwm eth information component fwmd slot slotid trunkport interface { interfaceName | interfaceType interfaceNum }

display fwm eth information component fwmd slot slotid records pvid operation

display fwm eth information component fwmd slot slotid records mac external-operation

display fwm eth information component fwmd slot slotid records oda download

display fwm eth information component fwmd slot slotid records mac-arbitrate vlan vlanid mac-address macaddress

display fwm eth information component fwmd slot slotid mtlkdwlink

display fwm eth information component fwmd slot slotid records age tableId

Parameters

Parameter Description Value
portsec

Port security change.

-
interface

Specifies a port.

-
interfaceName

Specifies a port name.

The value is a string of 1 to 64 case-sensitive characters. It cannot contain spaces.
interfaceType

Specifies a port type.

-
interfaceNum

Specifies the index of a port.

The value is a string of 1 to 64 case-sensitive characters. It cannot contain spaces.
fwmd

Indicates the orch layer.

-
slot slotid

Specifies a slot ID.

The value is a string of 1 to 31 case-sensitive characters without spaces.
records

Record.

-
mstp

Multiple Spanning Tree Protocol.

-
state-arbitration

Status arbitration.

-
mac

Specifies a MAC address.

-
avltree

AVL tree.

-
avltreeType avltreeTypeIndex

AVL tree type.

The value is a string of 1 to 15 case-sensitive characters. It cannot contain spaces.
avlNode avlNodeIndex

AVL tree node.

The value is a string of 1 to 15 case-sensitive characters. It cannot contain spaces.
learn-mode

Indicates the learning mode.

-
slfaction

Soft learning action.

-
trunkport

Eth-Trunk interface.

-
pvid

Default VLAN of an interface.

-
operation

Specifies the operation type.

The value is a string of 1 to 15 case-sensitive characters. It cannot contain spaces.
external-operation

External operation.

-
mac-address macaddress

Displays information about a specified MAC address entry.

The value is in the H-H-H format. Each H is a hexadecimal number that contains one to four digits, such as 00e0 and fc01. If an H contains fewer than four digits, the leftmost digits are padded with 0s. For example, two 0s are added to e0 to form 00e0.
oda

Open data layer abstraction.

-
download

Indicates that packets are sent to chips.

-
mac-arbitrate

MAC arbitration.

-
vlan vlanid

VLAN ID.

The value is an integer ranging from 1 to 4094.
mtlkdwlink

Indicates the Monitor Link downlink.

-
age

Indicates the aging record table.

-
tableId

Table ID.

The value is a string of 1 to 15 case-sensitive characters. It cannot contain spaces.

Views

All views

Default Level

3: Management level

Usage Guidelines

  • If a port security problem occurs on the device, you can run the display fwm eth information component fwmd slot portsec interface command to check the port security configuration of a specified interface on a specified card, which helps analyze the cause of the problem.
  • If the MSTP status of an interface on the device is incorrect, you can run the display fwm eth information component fwmd slot records mstp state-arbitration command to check MSTP arbitration table information, which helps analyze the cause of the problem.
  • If MAC address entries on the device are incorrect, you can run the display fwm eth information component fwmd slot records mac avltree avltreeType command to check information stored in the AVL tree corresponding to the MAC address entries, which helps analyze the cause of the problem.
  • If an interface on the device has a MAC address learning problem or does not learn MAC addresses, you can run the display fwm eth information component fwmd slot records mac learn-mode slfaction interface command to check the MAC address learning arbitration data of the specified interface on the specified card, which helps analyze the cause of the problem.
  • If a Layer 2 service problem occurs on an Eth-Trunk interface of the device, you can run the display fwm eth information component fwmd slot trunkport interface command to check the entry information cached in the ETH field of each member interface of the Eth-Trunk interface, which helps analyze the cause of the problem.
  • If untagged packets are incorrectly forwarded on the device, you can run the display fwm eth information component fwmd slot records pvid command to check information about PVID delivery changes on a specified card, which helps analyze the cause of the problem.
  • If an NAC authentication problem occurs on the device, you can run the display fwm eth information component fwmd slot records mac external-operation command to check detailed information about NAC MAC address delivery on a specified card, which helps analyze the cause of the problem.
  • If a Layer 2 service function problem occurs on the device, you can run the display fwm eth information component fwmd slot records oda download command to check statistics about delivered hardware entries, which helps analyze the cause of the problem.
  • To obtain the coexistence status of the same MAC address entry on the device, you can run the display fwm eth information component fwmd slot records mac-arbitrate vlan mac-address command to check the specific coexistence type and priority of the specified MAC address entry.
  • If a Monitor Link-related problem occurs on the device, you can run the display fwm eth information component fwmd slot mtlkdwlink command to check the Monitor Link switchover information on a specified card, which helps analyze the cause of the problem.
  • If a Layer 2 service function problem occurs on the device and the corresponding service entry is not delivered, you can run the display fwm eth information component fwmd slot records age command to check whether there is aging information for the specified entry, which helps analyze the cause of the problem.
