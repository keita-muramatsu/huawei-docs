dns-rule name (User-defined application view)

Function

The dns-rule name command configures a user-defined domain name rule.

The undo dns-rule command deletes a user-defined domain name rule.

By default, no domain name rule is configured for a new user-defined application.

Format

dns-rule name rule-name protocol { tcp | udp | any } domain plain-string [ { port-equal port [ next-port ] | port-range start-port end-port } ] [ priority priority ] [ description description ] *

undo dns-rule [ name rule-name | all ]

Parameters

Parameter Description Value
protocol tcp

Sets the transport layer protocol to TCP.

-
protocol udp

Sets the transport layer protocol to UDP.

-
protocol any

Indicates the TCP or UDP protocol.

-
domain plain-string

Only characters in 0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ.-* are allowed. Consecutive asterisks (*) are not allowed. The number of asterisks (*) cannot be greater than 3. At least one segment of consecutive characters is greater than or equal to 3.

The value is a string of 3 to 127 case-sensitive characters, spaces not supported.
port-equal port

Specifies a single port number.

The value is an integer from 1 to 65535.
port-equal port next-port

Configures one or two ports.

The value is an integer from 1 to 65535.
port-range start-port end-port

Specifies a port range.

The value is an integer ranging from 1 to 65535. The end port number must be greater than the start port number.
priority priority

Specifies a priority.

The value is an integer ranging from 1 to 60000.
description description

Specifies the description of a domain name rule for a user-defined application.

The value is a string of 1 to 128 case-sensitive characters. It cannot contain spaces. The character string can contain spaces if it is enclosed in double quotation marks (").
name rule-name

Specifies the rule name.

The value is a string of 1 to 31 characters. If the name contains spaces, enclose it with double quotation marks (""), for example, "user for test".
all

Indicates all user-defined domain name rules.

-

Views

User-defined application view

Default Level

2: Configuration level

Usage Guidelines

You can configure one rule or multiple rules that form an OR relationship. If a data flow or packet matches a rule, this flow or packet belongs to the corresponding application. You can specify a single port number, two port numbers, or a port range to filter ports. A maximum of eight DNS rules with the same domain name can be configured.

Example

# Configure a user-defined domain name rule in which the transport layer protocol is TCP and the pattern string is www.example.com. 
<HUAWEI> system-view
[HUAWEI] sa
[HUAWEI-sa] user-defined-application name UD_abc
[HUAWEI-sa-user-defined-app-UD_abc] dns-rule name app protocol tcp domain www.example.com
