per-packet-compress

Function

The per-packet-compress command configures per-packet compression and displays the per-packet compression configuration view.

The undo per-packet-compress command deletes the per-packet compression configuration.

By default, per-packet compression is not configured.

This command is supported only on the AR8700 series, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series and AR6700-H series.

Format

per-packet-compress

undo per-packet-compress

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Before configuring per-packet compression, run the per-packet-compress command to enter the per-packet compression configuration view.

Precautions

If the per-packet compression configuration view already exists, the per-packet compression configuration view is directly displayed after you run the per-packet-compress command.

Example

# Configure per-packet compression and display the per-packet compression configuration view.
<HUAWEI> system-view
[HUAWEI] per-packet-compress
[HUAWEI-per-packet-compress]
