keep-service enable(AP system profile view)

Function

The keep-service enable command enables AP-offline service continuity.

The keep-service disable command disables AP-offline service continuity.

The undo keep-service command restores the default status of AP-offline service continuity.

By default, AP-offline service continuity is enabled, and new STA access to offline APs is not allowed.

Format

keep-service enable [ allow new-access [ no-auth ] ]

keep-service disable

undo keep-service

Parameters

Parameter Description Value
allow

Enables offline APs to allow access of new STAs.

-
new-access

Enables offline APs to allow access of new STAs.

-
no-auth

Allows Portal or MAC address authentication users to access the network without authentication.

-

Views

AP system profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In direct forwarding mode, you can enable the AP-offline service continuity function. In this way, when the CAPWAP link between an AP and AC is disconnected, the AP can continue to provide WLAN services, preventing service interruption and improving forwarding reliability.

The AP-offline service continuity function controls whether new STAs are allowed to go online. For high-security authentication modes such as MAC address authentication and Portal authentication, no-auth must be configured to enable STAs to go online without authentication upon CAPWAP link disconnection. Therefore, this function can be enabled in scenarios with low security requirements.

Precautions

The AP-offline service continuity function can be configured in the VAP profile view or AP system profile view. When this function is configured in both the view, the configuration in the VAP profile view takes precedence over that in the AP system profile view.

After the AP-offline service continuity function is enabled, the display access-user command cannot display information about NAC STAs that are online before the CAPWAP link is disconnected. To display information about such STAs, run the display station command.

The function of allowing new STAs to access offline APs is applicable to scenarios where service data is forwarded in direct mode and the STA authentication mode is Portal, MAC address, open, WPA/WPA2-PSK, WPA3-SAE, OWE, or OWE transition mode.

Example

# Enable AP-offline service continuity in the AP system profile ap-system1 and allow new STA access to offline APs.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name ap-system1
[HUAWEI-wlan-ap-system-prof-ap-system1] keep-service enable allow new-access
