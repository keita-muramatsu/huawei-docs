deny-broadcast-probe enable

Function

The deny-broadcast-probe enable command enables an AP to deny broadcast Probe Request frames.

The undo deny-broadcast-probe enable command disables an AP from denying broadcast Probe Request frames.

By default, an AP responds to broadcast Probe Request frames.

Format

deny-broadcast-probe enable

undo deny-broadcast-probe enable

Parameters

None

Views

SSID profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In a high-density wireless environment, if too many Probe Response frames occupy a large number of wireless resources, you can enable an AP to deny broadcast Probe Request frames. This reduces the wireless resource usage of Probe Response frames and improves channel efficiency.

Precautions

Enabling an AP to deny broadcast Probe Request frames may reduce channel scanning efficiency of some STAs.

Example

# Enable an AP to deny broadcast Probe Request frames.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ssid-profile name ssid1
[HUAWEI-wlan-ssid-prof-ssid1] deny-broadcast-probe enable
