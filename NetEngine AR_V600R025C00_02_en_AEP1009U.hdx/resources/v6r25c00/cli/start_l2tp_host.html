start l2tp host

Function

The start l2tp host command specifies a domain name as the trigger condition for the L2TP client to initiate a call.

The undo start host command deletes a specified trigger condition.

By default, no domain name is configured as a trigger condition on the device.

Format

start l2tp host host-name

undo start l2tp host [ host-name ]

Parameters

Parameter Description Value
host host-name

Specifies the domain name of an LNS.

The value is a string of 1 to 255 case-sensitive characters. It cannot contain spaces. The character string can contain spaces if it is enclosed with double quotation marks (").

Views

L2TP group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Using the start l2tp host command, you can trigger an L2TP connection request based on the domain name of the specified LNS server.

Precautions

If both the start l2tp ip and start l2tp host commands are configured, the start l2tp ip command has a higher priority. The device attempts to establish an L2TP connection based on a domain name only when it fails to establish an L2TP connection based on an IP address.

If an L2TP connection has been established based on the domain name in an L2TP group, running the start l2tp host command to change the domain name will disconnect the L2TP tunnel and session. Therefore, exercise caution when running this command.

Example

# Specify a domain name as the trigger condition for initiating a call.
<HUAWEI> system-view
[HUAWEI] l2tp-group 1
[HUAWEI-l2tp-group-1] start l2tp host huaweilns
Warning: This operation may cause traffic interruption, Continue? [Y/N]:
