ipv4 force-fragment enable

Function

The ipv4 force-fragment enable command enables forcible fragmentation.

The undo ipv4 force-fragment command disables forcible fragmentation.

By default, forcible fragmentation is disabled.

Format

ipv4 force-fragment enable

undo ipv4 force-fragment

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When the length of a packet to be sent is greater than the MTU and the DF flag in the IP packet is set to 1 (no fragmentation), the router discards the packet and sends an ICMP packet to the upstream device if forcible fragmentation is disabled. If forcible fragmentation is enabled, the router fragments the packet before forwarding it.

Precautions

After NP offloading is enabled for IPv4/IPv6 basic forwarding, this command does not take effect.

Example

# Enable forcible fragmentation.
<HUAWEI> system-view
[HUAWEI] ipv4 force-fragment enable
