display system tcam service

Function

The display system tcam service brief command displays the group index and rule count occupied by different services.

Format

display system tcam service { cpcar slot slot-id | service-name slot slot-id [ chip chip-id ] }

display system tcam service brief [ slot slot-id ]

Parameters

Parameter Description Value
cpcar

Specifies the CPCAR service.

-
slot slot-id

Specifies a slot ID.

The value is an integer. You can enter the question mark (?) and select the value as prompted.
service-name

Indicates the service type.

The values are as follows:

  • brief
  • cpcar
  • free-rule
  • nac-base-auth
  • nac-redirect-acl-ipv4
  • nac-redirect-acl-ipv6
  • trans-vlan-mac-en
  • cpuhash-espseq-ipv4
  • cpuhash-espseq-ipv6
  • special-ipv4
  • special-ipv6
chip chip-id

Specifies a chip ID.

The value is an integer. It must be the ID of an available chip.
brief

Displays the group index and rule count occupied by different services.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

To view the group index and rule count occupied by different services on a chip in a slot, run this command.

This command cannot be used to view the group index and rule count occupied by the MQC service. Currently, information about the CPCAR, NAC Free Rule, NAC Base Auth, and Trans VLAN MAC EN services can be viewed.

Precautions

For the AR5700-H series, AR6710-L8T3TS1X2, and AR6710-L8T3TS1X2-T, in hardware forwarding mode, you can run this command to view the group index and rule count used by the MQC service.
