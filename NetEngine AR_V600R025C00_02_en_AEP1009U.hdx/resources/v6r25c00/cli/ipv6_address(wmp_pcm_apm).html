ipv6-address (AP view/AP provisioning view)

Function

The ipv6-address command configures a static IPv6 address and gateway address for an AP.

The undo ipv6-address command restores the default static IPv6 address and gateway address of an AP.

By default, no static IPv6 address or gateway address is configured for an AP.

Format

ipv6-address { ipv6-address prefix-length | ipv6-address-with-prefix } [ gateway gateway ]

undo ipv6-address

Parameters

Parameter Description Value
ipv6-address

Specifies a static IPv6 address for an AP.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
prefix-length

Specifies the prefix length of the IPv6 address.

The value is an integer ranging from 1 to 128.
ipv6-address-with-prefix

Specifies an IPv6 address with a prefix.

The value is a 32-digit hexadecimal number in the format of X:X:X:X:X:X:X:X/M.
gateway gateway

Specifies the egress gateway for AP routes.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.

Views

AP provisioning view, AP view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To configure an AP to go online using a specified IPv6 address, configure a static IPv6 address for the AP.

Prerequisites

The AP has been configured to obtain an IP address in static mode using the address-mode (AP provisioning view) command.

Follow-up Procedure

After running this command in the AP provisioning view, run the commit command to deliver the configuration to the AP. The configuration takes effect only after the AP restarts.

Precautions

Ensure that there are reachable routes between the configured IPv6 address and the AC source address for an AP to go online. Otherwise, the AP may fail to go online.

If the AP and AC are connected through a Layer 3 network, the egress gateway for AP routes must be configured.

An AP cannot be configured with a static IPv4 address and a static IPv6 address simultaneously. If an IP address has been configured in the AP view and the IP version is different from that configured in the AP provisioning view, delete the configuration in the AP view first.

Example

# Set the static IPv6 address of an AP to 2001:db8:1::1/7 in the AP view.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-id 0
[HUAWEI-wlan-ap-0] address-mode static
Warning: The incorrect configuration will cause the AP to go out of management. This operation will deliver parameter setting and may cause reboot of AP(s). Continue?[Y/N]:y
[HUAWEI-wlan-ap-0] ipv6-address 2001:db8:1::1/7
Warning: The incorrect configuration will cause the AP to go out of management. This operation will deliver parameter setting and may cause reboot of AP(s). Continue?[Y/N]:y
# Set the static IPv6 address of the AP to 2001:db8:1::1/7 in the AP provisioning view.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] provision-ap
[HUAWEI-wlan-provision-ap] address-mode static
[HUAWEI-wlan-provision-ap] ipv6-address 2001:db8:1::1/7
