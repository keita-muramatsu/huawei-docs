encapsulation source-address

Function

The encapsulation source-address command configures a source address for SRv6 encapsulation.

The undo encapsulation source-address command deletes the source address configured for SRv6 encapsulation.

By default, no source address is configured for SRv6 encapsulation.

Format

encapsulation source-address ipv6-address

undo encapsulation source-address [ ipv6-address ]

Parameters

Parameter Description Value
ipv6-address

Specifies an IPv6 address.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.

Views

Segment routing IPv6 view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

IPv6 encapsulation is performed during SRv6 data forwarding. The source and destination addresses need to be encapsulated in the IPv6 header. This command is used to configure the source address to be encapsulated.

In unicast forwarding scenarios, SRv6 selects a source address in the following sequence:

  1. encapsulation source-address
  2. Default address ::

    In ping and tracert scenarios, SRv6 selects a source address in the following sequence:
  • In a scenario where a public network route recurses to an SRv6 TE Policy:
  1. encapsulation source-address
  2. IPv6 router ID configured using the te ipv6-router-id command
  3. Minimum interface address configured on the device
  • In a scenario where a VPN route recurses to an SRv6 TE Policy:
  1. encapsulation source-address
  2. IPv6 router ID configured using the te ipv6-router-id command
  3. Default address ::

Precautions

If the encapsulation source-address command is not run, downstream devices fail to forward SRv6 packets, causing an end-to-end service forwarding failure. In a scenario where public network services recurse to an SRv6 TE Policy, if the te ipv6-router-id command is run on a device or an IPv6 address is configured on an interface, the ping&tracert operation can succeed but service forwarding fails. In a scenario where VPN services recurse to an SRv6 TE Policy, if the te ipv6-router-id command is run on a device, the ping&tracert operation can succeed but service forwarding fails.

Example

# Configure a source address for SRv6 encapsulation.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] encapsulation source-address 2001:db8:66::66
