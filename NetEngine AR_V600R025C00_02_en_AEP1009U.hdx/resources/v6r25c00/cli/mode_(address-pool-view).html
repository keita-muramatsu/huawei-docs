mode (NAT instance address pool view)

Function

The mode command configures the NAT mode of the address pool.

By default, the NAT mode of the address pool is pat.

Format

mode pat

mode { no-pat { global | local } | full-cone { global | local } [ no-reverse ] }

Parameters

Parameter Description Value
pat

Indicates the PAT mode.

-
no-pat

Indicates the No-PAT mode.

-
global

Indicates the global 3-tuple or No-PAT mode. The generated server mapping entry does not contain security zone parameters and is not restricted by interzone relationships.

-
local

Indicates the local 3-tuple or No-PAT mode. The generated server mapping entry contains security zone parameters and is restricted by interzone relationships.

-
full-cone

Indicates the 3-tuple NAT mode.

-
no-reverse

Indicates that the reverse server mapping table is not generated.

-

Views

NAT instance address pool view

Default Level

2: Configuration level

Usage Guidelines

After the mode is configured, all the address segments in the address pool share the same mode.

Example

# Configure the NAT mode of the address pool to be PAT mode.
<HUAWEI> system-view
[HUAWEI] nat address-group nataddr 1
[HUAWEI-address-group-nataddr] mode pat
# Configure the NAT mode of the address pool to be global full cone mode.
<HUAWEI> system-view
[HUAWEI] nat address-group nataddr 1
[HUAWEI-address-group-nataddr] mode full-cone global
