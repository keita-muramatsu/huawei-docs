display ike peer (All views)

Function

The display ike peer command displays the IKE peer configuration.

Format

display ike peer [ brief | name peer-name ]

Parameters

Parameter Description Value
brief

Displays brief information about the IKE peer.

-
name peer-name

Displays detailed information about the IKE peer with a specified name.

The value must be an existing IKE peer name.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

The display ike peer command output contains the following information:

  • Name of the IKE peer
  • Negotiation mode
  • Authentication key
  • IKE proposal
  • Type of the local ID
  • IP address of the IKE peer
  • Name of the IKE peer
  • Whether NAT traversal is enabled

Example

The actual command output varies according to the device. The command output here is only an example.

# Display brief configuration of the IKE peer.
<HUAWEI> display ike peer brief

---------------------------------------------------------------------------

---------------------------------------------------------------------------
1                v2     main            11         IP
peer1            v2     main            12         IP
huawei           v2     main            13         IP

Table 1 Description of the display ike peer (All views) command output
Item Description
Current ike peer number / Number of IKE peers

Number of IKE peers that have been configured.
Peer name

Name of the IKE peer.
Version / IKE version

IKE version supported by an IKE peer:

  • v2: IKEv2 is enabled.
Proposal

Name of the referenced IKE proposal.
Id-type / Local ID type

Local ID type in IKE negotiation.
RemoteAddr / Remote IP

IP address of the remote IKE peer.

If the remote domain name is configured, it will be displayed next to the IP address, for example, 1.1.1.1(www.huawei.com).
IP pool number

Number of IP address pools referenced by an IKE peer.
IKE user-table

IKE user table referenced by an IKE peer.
IKE negotiate compatible

IPsec proposal of the IKE peer accepted by the local end.
VPN instance

Name of a VPN instance.
VPN instance bound to the SA

Name of the VPN instance bound to the IPsec tunnel.
Remote ID type

Remote ID type in IKE negotiation.
Remote ID

Remote ID in IKE negotiation.
Authentic IP address

IP address used for IKE negotiation authentication before NAT translation.
Pre-shared-key

Pre-shared key used for authentication. When an IKE proposal referenced by an IKE peer uses pre-shared key authentication, the pre-shared key is used for identity authentication.
Local ID

Local ID used in IKE negotiation.
Local ID Certificate Preference

Whether the device preferentially obtains the local ID from a field in a certificate when IKE uses certificate negotiation.
certificate local-filename

Local certificate name.
certificate peer-filename

Peer certificate name.
certificate peer-name

Peer name in the specified certificate.
PKI realm

PKI realm bound to the IKE peer.
Inband OCSP

Whether IKEv2 is used to transmit Online Certificate Status Protocol (OCSP) requests and responses.
Inband CRL

Whether IKEv2 is used to transmit certificate revocation list (CRL) requests and responses.
cert-request empty-payload

Whether the certificate request payload is empty.
NAT-traversal

Whether NAT traversal is enabled.
Ip-pool name

Global address pool referenced by an IKE peer.
Ikev2 Redirect Group

Load balancing group referenced by an IKE peer.
Ikev2 Redirect Period

IKEv2 redirection phase:

  • Ike_Auth: IKEv2 redirection is performed in the authentication phase.
  • Ike_Init: IKEv2 redirection is performed in the initialization phase.
Re-authentication interval(s)

IKEv2 re-authentication interval.
DSCP

DSCP value of IKE packets of an IKE peer.
DPD

Whether the DPD function is enabled.
DPD type

DPD mode of an IKE peer.

  • on-demand: DPD is performed on demand.
  • periodic: DPD is performed periodically.
DPD retry-limit

Number of times that an IKE peer can retransmit DPD packets.
DPD retransmit-interval(s)

Interval at which an IKE peer retransmits DPD packets.
DPD idle-time(s)

DPD idle time of an IKE peer.
DPD packet receive if-related

Whether the function of checking whether the interface that receives DPD packets is the interface that establishes an IPsec SA.
Soft-expire buffer before hard-expire(s)

Soft timeout buffer time before hard timeout of the IPsec SA.
RSA encryption-padding

Padding mode of RSA encryption.
RSA signature-padding

Padding mode of an RSA signature.
Certificate-access-policy

Name of the certificate access policy referenced to the IKE peer.
Certificate-check

Whether validity verification on certificates of all IKE peers is enabled.
validate-certificate whitelist

Whether the PKI certificate whitelist function is enabled.
whitelist-fuzzy-match

Whether fuzzy match of the PKI certificate whitelist is enabled.
IKEv2 Local ID Reflect

Whether the local ID of the responder is used as the remote ID carried in the IKE packets sent by the initiator during IKEv2 negotiation.
IKEv2 fragmentation

Whether IKEv2 packet fragmentation is enabled.
IKEv2 fragmentation MTU

MTU of an IKEv2 fragment.
IKEv2 authentication signature-hash

Certificate signature algorithm used by IKEv2.
