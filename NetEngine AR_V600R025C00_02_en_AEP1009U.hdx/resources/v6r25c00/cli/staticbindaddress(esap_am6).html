static-bind address

Function

The static-bind address command statically binds an IPv6 address to a client DUID in the DHCPv6 address pool view.

The undo static-bind address command unbinds an IPv6 address from a client DUID in the DHCPv6 address pool view.

By default, no IPv6 address is bound to a client DUID.

Format

static-bind address ipv6-address duid client-duid [ iaid iaid-value ] [ life-time { valid-lifetime | infinite } { preferred-lifetime | infinite } ]

undo static-bind address ipv6-address [ duid client-duid [ iaid iaid-value ] [ life-time { valid-lifetime | infinite } { preferred-lifetime | infinite } ] ]

Parameters

Parameter Description Value
ipv6-address

Specifies an IPv6 address to be statically bound to a client DUID.

The value is a 128-bit hexadecimal number, in the format of X:X:X:X:X:X:X:X, with each X representing four hexadecimal numbers.
duid client-duid

Configures a DHCPv6 client DUID to be statically bound to the IPv6 address.

The value is a string of an even number of characters ranging from 2 to 260 in hexadecimal notation.
iaid iaid-value

Specifies an IA ID. A DUID can be associated with a maximum of three IA IDs, including IA IDs that are statically configured and dynamically obtained from clients.

The value is an integer ranging from 1 to 4294967295.
life-time

Indicates the lifetime of the bound entries.

-
valid-lifetime

Specifies the valid lifetime of the bound entries.

The value is an integer ranging from 60 to 172799999, in seconds. The default value is 172800 seconds (two days).
infinite

Sets the valid lifetime to infinite.

-
preferred-lifetime

Specifies the preferred lifetime of the bound entries.

The value is an integer ranging from 60 to 172799999, in seconds. The default value is 86400 seconds (one day).

Views

DHCP IPv6 address pool view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

This command is used on DHCPv6 servers. If some special clients need to be statically assigned fixed IPv6 addresses, you can bind the IPv6 addresses to the DUIDs of these clients in the IPv6 address pool of the DHCPv6 server. When receiving a request for an IPv6 address from a special client, the DHCPv6 server assigns the fixed IPv6 address bound to the client DUID to this client.

Prerequisites

  1. An address pool has been created using the dhcpv6 pool command.
  2. An IPv6 address prefix has been bound to the address pool using the address prefix command.

Precautions

  1. If the statically assigned IPv6 address has been used and the configured client DUID is different from the DUID used by the online client or they are the same but the IAIDs are different, the system displays a message indicating that the IPv6 address will be reclaimed. When Y/N is displayed, you can perform selection as follows:

    Y: continues the configuration and reclaims the related address.

    N: terminates the command.

  2. If an IPv6 address has been assigned to the client with the statically configured IAID and is different from the configured address, the system displays a message indicating that the assigned IPv6 address will be reclaimed. When Y/N is displayed, you can perform selection as follows:

    Y: continues the configuration and reclaims the related address.

    N: terminates the command.

Example

# Bind the IPv6 address fc00:1::2 with the client with DUID abcdef in address pool pool1 and set the lifetime to infinite. 
<HUAWEI> system-view
[HUAWEI] dhcpv6 pool pool1
[HUAWEI-dhcpv6-pool-pool1] address prefix fc00:1::/64
[HUAWEI-dhcpv6-pool-pool1] static-bind address fc00:1::2 duid abcdef life-time infinite infinite
