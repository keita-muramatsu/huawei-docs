display ap radio-environment

Function

The display ap radio-environment command displays air interface environment information about AP radios.

Format

display ap radio-environment ap-id ap-id [ radio radio-id ]

Parameters

Parameter Description Value
ap-id ap-id

Displays air interface environment information about radios of the AP with a specified AP ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
radio radio-id

Displays air interface environment information about the AP radio with a specified radio ID.

The value is an integer ranging from 0 to 4.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

When the wireless network access experience is poor, you can run this command to check the air interface environment information, including the noise floor, signal to interference plus noise ratio (SINR), co-channel interference, and adjacent-channel interference. In addition, you can view the specific Wi-Fi interference source in the list. After this command is executed, the air scan of AP radios is automatically enabled, and the AP starts to scan the air interface environment of radios. When you run this command again, you can view the air scan result.

Precautions

The result of the air interface scanning is not displayed during the first query. Therefore, you need to run this command again.

After AP radio scanning is enabled using this command, the air interface performance of an AP is affected. If this command is not executed again within 5 minutes, AP radio scanning is automatically disabled.

If the parameter radio radio-id is not specified, air interface information about all radios on the AP is displayed.

In the scanning result, the channel utilization, co-channel interference, and adjacent-channel interference are calculated with the impact of non-Wi-Fi interference. However, non-Wi-Fi interference devices are not displayed in the interference source list.
