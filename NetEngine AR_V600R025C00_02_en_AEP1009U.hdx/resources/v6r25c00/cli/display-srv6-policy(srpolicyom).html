display srv6-te policy

Function

The display srv6-te policy command displays detailed SRv6 TE Policy information.

The display srv6-te policy brief command displays brief SRv6 TE Policy information.

Format

display srv6-te policy [ endpoint ipv6-address color color-value | policy-name name-value | binding-sid sid-value ]

display srv6-te policy brief

display srv6-te policy { endpoint ipv6-address | color color-value }

Parameters

Parameter Description Value
endpoint ipv6-address

Specifies the destination address of an SRv6 TE Policy.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
color color-value

Specifies a color value for an SRv6 TE Policy.

The value is an integer ranging from 0 to 4294967295.
policy-name name-value

Specifies the name of an SRv6 TE Policy.

The value is a string of 1 to 255 case-sensitive characters. If the string is enclosed in double quotation marks ("), spaces are allowed in the string.
binding-sid sid-value

Specifies a binding SID.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

The display srv6-te policy command displays detailed SRv6 TE Policy information.

The display srv6-te policy brief command displays brief SRv6 TE Policy information.

Policy Name

SRv6 TE Policy name.

SRv6 TE Policy status:

  • Up.

  • Down (Overrun).
  • Down (BFD down).
  • Down (Shutdown).
  • Down (Delay Delete): If an SRv6 TE Policy has only one candidate path and the candidate path has only one segment list, deleting the candidate path or segment list causes the SRv6 TE Policy to enter this state, so that services no longer recurse to the SRv6 TE Policy.

Color value of an SRv6 TE Policy.
Endpoint

Destination address of an SRv6 TE Policy.
TunnelId

SRv6 TE Policy ID.
TunnelType

Tunnel type of an SRv6 TE Policy.
DelayTimerRemain

Remaining time of the delayed deletion/switchover timer after the segment list of an SRv6 TE Policy's candidate path is deleted.
State Change Time

Time when the status of an SRv6 TE Policy changed.
Admin State

Whether the shutdown command is run for an SRv6 TE Policy. If the command is run, the SRv6 TE Policy is Down. Otherwise, the SRv6 TE Policy is Up.
Traffic Statistics

Whether SRv6 TE Policy traffic statistics collection is enabled.
Backup Hot-Standby

Whether SRv6 TE Policy backup hot-standby is enabled.

  • Enable.
  • Disable.
BFD

Whether BFD is enabled for an SRv6 TE Policy:

  • UBFD Enable (Nobypass).
  • UBFD Enable (Reverse Path BSID).
  • UBFD Enable (Reverse Path BSID, Nobypass).
  • UBFD Enable (Reverse Path BSID, Nobypass Primary Path).
  • UBFD Enable (Reverse Path BSID, Nobypass Backup Path).
  • Disable.
BFD State

BFD status of the segment list of an SRv6 TE Policy's candidate path:

  • -.
  • Down.
  • Up.
  • Up(Delay Switch).
  • Unknown.
  • Admin Down.
  • Select Board Fail.
  • Path Inactive.
  • Overrun.
  • -(No Reverse BSID).
BFD Delay Remain

Remaining time of the switchback delay timer when BFD detects that the path goes Up after BFD for the segment list of an SRv6 TE Policy's candidate path goes Down.
Interface Index

Interface index of an SRv6 TE Policy. Only an SRv6 TE Policy configured with IGP shortcut has an interface index.
Interface Name

Name of an SRv6 TE Policy interface. Only an SRv6 TE Policy configured with IGP shortcut has an interface name.
Interface State

Interface state of an SRv6 TE Policy. Only an SRv6 TE Policy configured with IGP shortcut has an interface state.

-Up.

-Down(Policy Down).

Activity metric of an SRv6 TE Policy.

Metric source of an SRv6 TE Policy.

Number of candidate paths configured for an SRv6 TE Policy.
Candidate-path Preference

Preference of an SRv6 TE Policy's candidate path.

Path name.
Path State

Status of an SRv6 TE Policy's candidate path:

  • Inactive (Invalid).
  • Inactive (Valid).
  • Active.
  • Inactive (Wait BFD).
  • Inactive (BFD Down).
  • Inactive (Delay Delete).
  • Active (Wait Delay Delete).
  • Inactive (Delay Switch).
  • Inactive (Wait Switch).
Path Type

Candidate path type of an SRv6 TE Policy. The value can be primary, backup, or empty. If the value is empty, the path is not preferentially selected.
Path Verification

Flag indicating whether path fault detection is enabled:

  • Enable.
  • Disable.
  • Specified SID Enable.
Protocol-Origin

Protocol origin of an SRv6 TE Policy's candidate path:

  • BGP(20).
  • Configuration(30).
Originator

Originator of an SRv6 TE Policy's candidate path. The value is in the format of <ASN, node-address>, where:

  • ASN indicates the AS number. If the candidate path is statically configured, the value is 0. If the candidate path is delivered by BGP, the value is the ASN delivered by BGP.
  • If the candidate path is statically configured, the node-address value is fixed at 0.0.0.0. If the candidate path is delivered by BGP, the node-address value is the BGP-delivered router-id value of the BGP peer.
Discriminator

Discriminator of an SRv6 TE Policy's candidate path. For a statically configured candidate path, the discriminator is the same as the preference. For a BGP-delivered candidate path, the discriminator is the same as the discriminator carried in the BGP-delivered TLV.
Binding SID

Binding SID of an SRv6 TE Policy.

In the command output, the information in the brackets following the binding SID indicates the encapsulation mode of the binding SID, the reduce mode, and whether the binding SID is preferentially selected.

Available encapsulation mode values are as follows:

  • -.
  • Invalid.
  • Insert.
  • Encaps.
  • Insert&Encaps.

If the effective Reduce mode calculated for the binding SID is Enabled, "Reduce" is displayed in the brackets following the SID value. Otherwise, "Reduce" is not displayed.

If the binding SID is preferentially selected, "Preferred" is displayed in the brackets. Otherwise, "Preferred" is not displayed.
SID

SID flag:
