information(Smart upgrade view)

Function

The information telephone command sets the phone number and email address of the maintenance personnel for smart upgrade.

The undo information command deletes the phone number and email address of the maintenance personnel for smart upgrade.

By default, no contact phone number or email address is configured for smart upgrade.

Format

information telephone phone-value email email-value retention-period month

undo information

Parameters

Parameter Description Value
email email-value

The email of the user receiving the HOUP upgrade result.

The value is a string of case-sensitive characters in plaintext or ciphertext. It cannot contain spaces. The plaintext string is 1 to 128 characters long, and the ciphertext string is 1 to 392 characters long. The cipher text is delivered during buildrun configuration restoration.
retention-period month

Retention period of phone number and email in the device.

The value is an integer ranging from 1 to 180, in months.
telephone phone-value

The phone number of the user receiving the HOUP upgrade result.

The value is a string of case-sensitive characters in plaintext or ciphertext. It cannot contain spaces. The plaintext string is 1 to 21 characters long, and the ciphertext string is 1 to 392 characters long. The cipher text is delivered during buildrun configuration restoration.

Views

Smart upgrade view

Default Level

3: Management level

Usage Guidelines

You can run this command to configure the phone number and email address of the maintenance personnel who receive smart upgrade results. After the intelligent upgrade is complete, the HOUP platform sends the upgrade result to the maintenance personnel.

To ensure the information security of maintenance personnel, you can configure the information retention period on the device. When the validity period expires, the maintenance personnel will receive an expiration alarm. The configured phone number and email address will become invalid and cannot receive the upgrade result. To continue receiving the upgrade result, you need to reconfigure the contact information of the maintenance personnel. To delete related data, run the undo information command to delete the configuration and run the delete command to delete the backup configuration file.

The contact information is used only for emergency contact in case of a version upgrade failure.

To ensure the security of user information transmission, the device can connect to the HOUP platform only when the SSL policy is configured (secure connection is used). Otherwise, user information transmission is not triggered.

Example

# Configure the phone number and email address with one month retention period for smart upgrade.
<HUAWEI> system-view
[HUAWEI] smart-upgrade
[HUAWEI-smart-upgrade] information telephone 111111111 email abcd@huawei.com retention-period 1
