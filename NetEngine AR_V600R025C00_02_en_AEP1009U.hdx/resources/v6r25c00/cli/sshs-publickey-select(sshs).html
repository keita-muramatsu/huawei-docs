ssh server publickey

Function

The ssh server publickey command enables the public key algorithm function of the SSH server.

The undo ssh server publickey command restores public key algorithms of the SSH server to default values.

By default, the ECC, RSA_SHA2_512, and RSA_SHA2_256 public key algorithms are enabled.

When the device starts with factory settings, the RSA_SHA2_512 and RSA_SHA2_256 public key algorithms are enabled.

Format

ssh server publickey { dsa | ecc | rsa | sm2 | x509v3-ssh-rsa | rsa_sha2_256 | rsa_sha2_512 | x509v3-rsa2048-sha256 | x509v3-ecdsa-sha2 | sm2-sm3 } *

undo ssh server publickey

Parameters

Parameter Description Value
dsa

Indicates the DSA algorithm.

Specifies the ECC algorithm that indicates a type of algorithm, including ecdsa-sha2-nistp521, ecdsa-sha2-nistp384, and ecdsa-sha2-nistp256.

-

Indicates the RSA algorithm.

-

Indicates the SM2 algorithm.

-

Indicates the X509-SSH-RSA algorithm.

-

-

-

-
x509v3-ecdsa-sha2

Specifies the X509V3-ECDSA-SHA2 public key algorithm that indicates a type of algorithm, including x509v3-ecdsa-sha2-nistp521, x509v3-ecdsa-sha2-nistp384, and x509v3-ecdsa-sha2-nistp256.

-

Views

System view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

  • This command enables you to use a more secure public key algorithm when logging in to the device, while rejects other public key algorithms, thereby improving device security.
  • To allow a public key algorithm and reject other public key algorithms, run the ssh server publickey command and specify the specific public key algorithm in the command. For example, after the ssh server publickey dsa command is run, the DSA algorithm is allowed but other algorithms are rejected. If this command is run multiple times, the latest configuration takes effect.
  • If the public key algorithm specified on the SSH server is X509V3-SSH-RSA or X509V3-RSA2048-SHA256, run the ssh server assign pki <pki-keyname> command to bind the PKI realm.
  • The algorithms are listed in descending order of security level: ecc > x509v3-ecdsa-sha2 > rsa_sha2_512 > rsa_sha2_256 > sm2-sm3 > sm2 > x509v3-rsa2048-sha256 > x509v3-ssh-rsa > rsa > dsa

Precautions

  • For security purposes, you are advised not to use the RSA algorithm with a key length of less than 3072 bits for SSH user authentication. You are advised to use ECC, RSA_SHA2_256, or RSA_SHA2_512, which is more secure.
  • A public key algorithm can be used for login only after it is enabled on both the client and server.
  • The undo ssh server publickey command restores all the public key algorithms of the SSH server to default settings, with no parameters.
  • If the authentication mode of SSH users is set to public key authentication using the ssh user command, the public key algorithm must be the same as that enabled in this command; otherwise, users cannot log in to the device. For example, if the ssh server publickey ecc command is run, you need to run the ssh user <user-name> authentication-type { ecc | password-ecc | all } command to set the authentication mode of SSH users to ECC, Password-ECC, or ALL.
  • This command takes effect for both IPv4 and IPv6 clients.
  • The dsa, rsa, and x509v3-ssh-rsa parameters in this command can be used only after the weak security algorithm/protocol feature package (WEAKEA) is installed using the install feature-software WEAKEA command.

Example

# Allow using of the ECC algorithm and deny other algorithms. 
<HUAWEI> system-view
[HUAWEI] ssh server publickey ecc
# Allow using of the SM2 algorithm and deny other algorithms. 
<HUAWEI> system-view
[HUAWEI] ssh server publickey sm2
# Allow using of the x509v3-ssh-rsa algorithm and deny other algorithms. 
<HUAWEI> system-view
[HUAWEI] ssh server publickey x509v3-ssh-rsa
