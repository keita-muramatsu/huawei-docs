band lte

Function

The band lte command configures the working frequency band for a modem to connect to an LTE network.

The undo band lte command restores the default working frequency band for a modem to connect to an LTE network.

By default, the modem automatically selects the working frequency band for connecting to an LTE network.

Format

band lte { band1 | band2 | band3 | band4 | band5 | band7 | band8 | band18 | band19 | band20 | band26 | band28 | band32 | band34 | band38 | band39 | band40 | band41 | band42 | band43 | band66 } *

undo band lte

Usage Guidelines

Usage Scenario

LTE networks operated by network carriers usually provide multiple frequency bands for users to access. If a modem is connected to a LTE network and the LTE network frequency band changes, the modem automatically adjusts the working frequency band to adapt to the network environment change. This affects LTE link stability.

If the frequency band of a LTE network is fixed, you can run the band lte command to set the frequency band in which a modem connected to the LTE network operates. This prevents frequency band changes caused by frequency interference and ensures LTE link stability.

Precautions

  • This command is valid only when the modem is installed.
  • You need to confirm the frequency band of the LTE network in your area with network carriers who operate LTE networks to set the most suitable working frequency band.
  • Run the display cellular or display ru-cellular command and check the Bands supported field to determine the working frequency band supported by the device.

Example

# Manually set the working frequency band for the modem to connect to an LTE network to band1.
<HUAWEI> system-view
[HUAWEI] cellular-profile profileName
[HUAWEI-cellular-profile-profileName] band lte band1
# Restore the default working frequency band for a modem to connect to an LTE network.
<HUAWEI> system-view
[HUAWEI] cellular-profile profileName
[HUAWEI-cellular-profile-profileName] undo band lte
