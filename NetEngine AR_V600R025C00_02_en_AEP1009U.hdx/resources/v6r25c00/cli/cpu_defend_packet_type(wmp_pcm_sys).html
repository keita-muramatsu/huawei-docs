cpu-defend packet-type(AP system profile view)

Function

The cpu-defend packet-type command sets the rate limit for packets to be sent by an AP to the CPU.

The undo cpu-defend packet-type command restores the default rate limit for packets to be sent by an AP to the CPU.

By default, an AP does not limit the rate of packets to be sent to the CPU.

Format

cpu-defend packet-type packet-type rate-limit rate-value { wired | wireless }

undo cpu-defend packet-type packet-type rate-limit { wired | wireless }

Parameters

Parameter Description Value
packet-type

Specifies the protocol type of packets.

The value is a string of 1 to 36 case-sensitive characters, spaces not supported.
rate-limit rate-value

Specifies the rate limit. rate-value specifies the rate limit of protocol packets.

The value of rate-value is an integer that ranges from 1 to 4294967295, in pps.
wired

Indicates wired packets.

-
wireless

Indicates wireless packets.

-

Views

AP system profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If an AP receives attack packets of a certain protocol or a large number of normal packets to be sent to the CPU, you can limit the rate of packets of this protocol in the AP system profile. In this way, the rate of packets of this protocol is limited within a small range, reducing the impact on the CPU to process normal services.

Precautions

If you run the cpu-defend packet-type command multiple times with the same packet-type value, only the latest configuration takes effect.

Example

# Set the protocol type of ARP reply packets to wired and the rate limit to 1260 pps.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name ap-system1
[HUAWEI-wlan-ap-system-prof-ap-system1] cpu-defend packet-type arp-reply rate-limit 1260 wired
