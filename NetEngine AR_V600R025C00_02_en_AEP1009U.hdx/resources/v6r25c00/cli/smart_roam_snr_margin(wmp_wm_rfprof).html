smart-roam snr-margin

Function

The smart-roam snr-margin command sets the difference thresholds for triggering STA roaming steering.

The undo smart-roam snr-margin command restores the default difference thresholds for triggering STA roaming steering.

By default, the upper and lower difference thresholds for triggering STA roaming steering are 12 dB and 10 dB, respectively.

Format

smart-roam snr-margin high-level-margin high-level-margin low-level-margin low-level-margin

undo smart-roam snr-margin

Parameters

Parameter Description Value
high-level-margin high-level-margin

Specifies the upper RSSI difference threshold for triggering STA roaming steering.

The value is an integer ranging from 10 to 20, in dB.
low-level-margin low-level-margin

Specifies the lower RSSI difference threshold for triggering STA roaming steering.

The value is an integer ranging from 3 to 15, in dB.

Views

RRM profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In smart roaming and AI roaming scenarios, you can configure the thresholds for determining whether to steer STA roaming. When determining whether to steer a STA to a neighboring AP, the AP compares the RSSIs of the STA on the neighboring AP with that on the local AP, which are reported by the STA through coordinated measurement. If the RSSI difference is higher than a specified threshold, that is, the STA has a significantly increased RSSI after associating with the neighboring AP, the AP steers the STA to roam to the neighboring AP.

In smart roaming scenarios, the parameters low-level-margin and high-level-margin are used to determine whether to steer sticky STAs and common STAs, respectively, to roam to neighboring APs. In most cases, you are advised to set high-level-margin larger than low-level-margin so that sticky STAs can roam to neighboring APs with better experience as soon as possible.

In AI roaming scenarios based on coordinated measurement, only high-level-margin is used to determine whether to steer STAs to neighboring APs.

The default difference thresholds are recommended. If APs are deployed close to each other and the transmit power is high, increase the two difference thresholds.

Prerequisites

Smart roaming has been enabled.

Example

# Set the upper and lower RSSI difference thresholds for triggering STA roaming steering to 10 and 6, respectively.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] rrm-profile name default
[HUAWEI-wlan-rrm-prof-default] undo smart-roam disable
[HUAWEI-wlan-rrm-prof-default] smart-roam snr-margin high-level-margin 10 low-level-margin 6
