vpn-instance(L2TP group view)

Function

The vpn-instance command specifies the VPN instance to which the IP address used by an L2TP group to establish an L2TP connection belongs.

The undo vpn-instance command deletes the VPN instance to which the IP address used by an L2TP group to establish an L2TP connection belongs.

By default, the IP address used by an L2TP group to establish an L2TP connection does not belong to any VPN instance.

Format

vpn-instance vpn-instance-name

undo vpn-instance [ vpn-instance-name ]

Parameters

Parameter Description Value
vpn-instance vpn-instance-name

Indicates the VPN instance to which the IP address used by an L2TP connection belongs.

A route to the LNS exists in the routing table of the VPN instance.

The value is a string of 1 to 31 case-sensitive characters. The character string can contain spaces if it is enclosed with double quotation marks (").

Views

L2TP group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When an L2TP tunnel is established, no VPN instance is specified by default. In this case, the system can attempt to establish an L2TP tunnel on the public network interface. If you want to establish an L2TP tunnel on the interface of a specified VPN, you can configure vpn-instance to limit the VPN for the interface used for establishing an L2TP tunnel.

Precautions

If an L2TP connection has been established in an L2TP group, running the vpn-instance command to modify the VPN instance will disconnect the L2TP tunnel and session. Therefore, exercise caution when running this command.

Example

# Configure the IP address used by an L2TP group to establish an L2TP connection to belong to VPN1.
<HUAWEI> system-view
[HUAWEI] ip vpn-instance vpn1
[HUAWEI-vpn-instance-vpn1] quit
[HUAWEI] l2tp-group 1
[HUAWEI-l2tp-group-1] vpn-instance vpn1
Warning: This operation may cause traffic interruption, Continue? [Y/N]:
