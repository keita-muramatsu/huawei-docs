ap-granted-mode

Function

The ap-granted-mode command set an AP approval mode.

The undo ap-granted-mode command restores the default manual AP approval mode.

By default, the AP approval mode is manual.

Format

ap-granted-mode { auto | manual }

undo ap-granted-mode

Parameters

Parameter Description Value
auto

Specifies the auto AP approval mode.

-
manual

Specifies the manual AP approval mode.

-

Views

Net-assistant network view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

If many APs connect to the network at different time, it is difficult to approve the APs one by one. In this case, you can run this command to enable automatic AP approval. After this function is enabled, when an AP is discovered by the master device, the master device automatically approves the AP without the need to approve the AP through the CLI or WebMaster.

Precautions

When you run a command to configure the approval mode of an AP, the configuration can be successful if the WAC role is not specified on the entire network. However, this function is enabled only after the WAC role is specified.

Example

# Restore the default manual AP approval mode.
<HUAWEI> system-view
[HUAWEI] net-assistant
[HUAWEI-net-assistant] network
[HUAWEI-net-assistant-network] undo ap-granted-mode
# Set the AP approval mode to manual.
<HUAWEI> system-view
[HUAWEI] net-assistant
[HUAWEI-net-assistant] network
[HUAWEI-net-assistant-network] ap-granted-mode manual
# Set the AP approval mode to auto.
<HUAWEI> system-view
[HUAWEI] net-assistant
[HUAWEI-net-assistant] network
[HUAWEI-net-assistant-network] ap-granted-mode auto
