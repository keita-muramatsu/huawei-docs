segment-list delete-hold

Function

The segment-list delete-hold enable command enables the Delete-Hold function for the segment lists of an SRv6 TE Policy.

The undo segment-list delete-hold enable command deletes the preceding configuration.

The segment-list delete-hold disable command disables the Delete-Hold function for the segment lists of an SRv6 TE Policy.

The undo segment-list delete-hold disable command deletes the preceding configuration.

By default, the srv6-te-policy segment-list delete-hold enable command configuration in the Segment Routing IPv6 view is directly inherited.

Format

segment-list delete-hold { enable | disable }

undo segment-list delete-hold { enable | disable }

Parameters

None

Views

SRv6 TE policy view

Default Level

2: Configuration level

Usage Guidelines

The srv6-te-policy segment-list delete-hold enable (Segment Routing IPv6 view) command globally enables the Delete-Hold function for the segment lists of all SRv6 TE Policies. The segment-list delete-hold (SRv6 TE Policy view) command configures the Delete-Hold function for the segment lists of a single SRv6 TE Policy.

If both the srv6-te-policy segment-list delete-hold enable and segment-list delete-hold commands are run for an SRv6 TE Policy, the segment-list delete-hold command configuration in the SRv6 TE Policy view takes precedence.

Example

# Enable the Delete-Hold function for segment lists.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] srv6-te policy policy1 endpoint 2001:DB8:1::1 color 200
[HUAWEI-segment-routing-ipv6-policy-policy1] segment-list delete-hold enable
