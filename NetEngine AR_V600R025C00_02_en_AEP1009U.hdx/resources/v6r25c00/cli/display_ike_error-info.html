display ike error-info

Function

The display ike error-info command displays information about the failure to establish an IPsec tunnel through IKE negotiation.

Format

display ike error-info [ verbose ] [ peer { ipv4-address | ipv6-address } ] [ slot slot-id cpu cpu-id ]

Parameters

Parameter Description Value
verbose

Displays details about the failure to establish an IPsec tunnel through IKE negotiation.

-
peer ipv6-address

Displays information about the failure to establish an IPsec tunnel through IKE negotiation with a specified peer IP address.

The value is in colon-separated hexadecimal notation.
peer ipv4-address

Displays information about the failure to establish an IPsec tunnel through IKE negotiation with a specified peer IP address.

The value is in dotted decimal notation.
slot slot-id

Displays information about the failure to establish an IPsec tunnel through IKE negotiation with a specified slot ID.

The value varies depending on device models.
cpu cpu-id

Displays information about the failure to establish an IPsec tunnel through IKE negotiation with a specified CPU ID.

The value varies depending on device models.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

The command displays information about the latest 200 failures to establish an IPsec tunnel through IKE negotiation.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display details about the failure to establish an IPsec tunnel through IKE negotiation.
<HUAWEI> display ike error-info verbose

  current info Num :1
  Slot 0, cpu 0 ike error information:
  current ike Error-info number :1
  ----------------------------------------------------------------------------------------------
  Peer       : 10.1.1.1
  Port       : 500
  version    : v1
  Reason     : phase1 proposal encryption algorithm mismatch
  Detail     : phase1 proposal encryption algorithm mismatch 
  Error-time : xxxx-xx-xx xx:xx:xx
