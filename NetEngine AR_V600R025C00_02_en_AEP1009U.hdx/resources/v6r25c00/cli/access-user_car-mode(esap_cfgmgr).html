access-user car-mode

Function

The access-user car-mode command configures the CAR mode for user access.

The undo access-user car-mode command restores the default setting.

By default, the CAR mode for user access is default.

Format

access-user car-mode { default | dtls { dot1x | mac-authen | portal | https-portal } * }

access-user car-mode dtls { dot1x | mac-authen | portal | https-portal } * { wired | wireless }

undo access-user car-mode

Parameters

Parameter Description Value
default

Specifies the default CAR mode in scenarios where authorization or accounting is not performed on users.

When this mode is specified, the system restores the default rate limits.
dtls

Specifies the CAR mode in the RADIUS over DTLS scenario.

Specifies the CAR mode in the RADIUS over DTLS scenario.
dot1x

Views

System view

Default Level

2: Configuration level

Usage Guidelines

By default, the CAR mode for user access is default. This mode applies to scenarios where user authentication is performed but user authorization or accounting is not performed. In this mode, users can be quickly authenticated and go online.

In the RADIUS over DTLS scenario, you are advised to specify the dtls parameter to configure the CAR mode for different access user types. This configuration also affects the user rate limit in non-RADIUS over DTLS scenarios. Therefore, this configuration is not recommended in non-RADIUS over DTLS scenarios.

After the CAR mode for user access is configured, you can run the display cpu-defend configuration command to query the rate limits of packets.

Example

# Set the CAR mode for 802.1X authentication users in the RADIUS over DTLS scenario.
<HUAWEI> system-view
[HUAWEI] access-user car-mode dtls dot1x
