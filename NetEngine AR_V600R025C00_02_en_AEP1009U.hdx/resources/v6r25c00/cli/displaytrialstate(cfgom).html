display configuration trial status

Function

The display configuration trial status command displays the trial run status of system configurations.

Format

display configuration trial status

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

You can run this command to check whether the system is in the configuration trial run status and the execution status of the trial run.

If the configuration trial run function carries the persistence flag, the output of this command contains the persistence flag.

Example

The actual command output varies according to the device. The command output here is only an example.

# Query the configuration trial run status when the system is not in the configuration trial run mode.
<HUAWEI> system-view
[HUAWEI] display configuration trial status
Trial status: INACTIVE 
Trial time left (sec): 0
# Query the configuration trial run status when the system is in configuration trial run mode and no persistency flag is specified.
<HUAWEI> system-view
[HUAWEI] display configuration trial status
2025-04-24 19:04:27.308
Trial status: ACTIVE
Trial time left (sec): 593
Session id: 4674
# Query the configuration trial run status when the system is in the configuration trial run mode and the persistency flag is specified.
<HUAWEI> system-view
[HUAWEI] display configuration trial status
2025-04-24 19:16:33.427
Trial status: ACTIVE
Persist id: 32
Trial time left (sec): 594
Session id: 4674
Table 1 Description of the display configuration trial status command output
Item Description
Trial status

Trial running status of a system configuration. The value can be:

  • INACTIVE: The configuration is not in the trial running status.
  • ACTIVE: The configuration is in the trial running status.
  • CANCELING: The trial run of the configuration is being canceled.
  • WAITCANCEL: The trial run of the configuration is waiting to be canceled.
Trial time left (sec)

Remaining time of a trial run.
Session id

ID of the session where the configuration trial run is performed.
Persist id

Persistency mark.
