reset pppoe-client session

Function

The reset pppoe-client session command resets a PPPoE session and re-initiates a connection later.

Format

reset pppoe-client session { all | dialer number }

Parameters

Parameter Description Value
all

Resets all PPPoE sessions.

-
dialer number

Resets the PPPoE session corresponding to a specified dialer interface.

For the AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S and AR5710-S10T1X2:The value is an integer that ranges from 0 to 31.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR8700 series, AR8100 series and AR6700-H series:The value is an integer in the range from 0 to 1023.

Views

User view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

After the PPP link is set up, the modified PPP negotiation parameters cannot take effect immediately and can take effect only after the session is cleared and set up again.

By default, a PPPoE session works in permanently online mode. If you run the reset pppoe-client session command to terminate a PPPoE session, the device automatically re-establishes a PPPoE session 16 seconds later.

Precautions

  • Resetting all PPPoE sessions will delete all online PPPoE users. Resetting the PPPoE session corresponding to a specified dialer interface will delete all PPPoE users who dial in through the specified dialer interface.

Example

# Reset the PPPoE connection that is set up through dialer interface 1.
<HUAWEI> reset pppoe-client session dialer 1
