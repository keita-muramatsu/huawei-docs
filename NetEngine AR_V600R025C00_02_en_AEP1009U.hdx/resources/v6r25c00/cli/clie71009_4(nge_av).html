exception av-signature-name

Function

The exception av-signature-name command adds a virus exception.

The undo exception av-signature-name command deletes a virus exception.

By default, no exception signature is configured.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

exception av-signature-name STRING

exception av-signature-name STRING action { allow | block-source-ip [ timeout time ] }

undo exception av-signature-name STRING

undo exception av-signature-name all

undo exception av-signature-name STRING action

undo exception av-signature-name STRING action block-source-ip timeout

Parameters

Parameter Description Value
av-signature-name STRING

Specifies the name of an exception virus signature.

The value is a string of case-sensitive characters. If the name cannot contain spaces, the value is a string of 8 to 128 characters. The name can contain only letters, digits, hyphens (-), underscores (_), periods (.), at signs (@), and backslashes (\).
allow

Indicates that the response mode of the exception virus is permit.

-
block-source-ip

Set the response action of the exception virus to isolate the source IP address and block the current flow. The source IP address is added to the blacklist.

-
timeout time

Specifies the timeout period for isolating the source IP address. The blacklist becomes invalid after this period expires.

The value is an integer ranging from 1 to 30, in minutes. The default value is 5 minutes.
all

Deletes all exception signatures.

-

Views

Antivirus profile view

Default Level

2: Configuration level

Usage Guidelines

The files with an exception virus are permitted if no action is specified for the exception virus.

If the action is set to block-source-ip, you need to enable the firewall blacklist function first.

If the action is set to block-source-ip, the device adds the source IP address of the traffic matching the exception virus to the dynamic blacklist and performs different actions based on the protocol type.

  • Take the block action for HTTP and SMB traffic.
  • For FTP traffic, the device blocks the traffic in proxy mode, and blocks the traffic in stream mode based on the actual blocking situation.
  • For SMTP, POP3, and IMAP traffic, if the protocol action is set to declare or delete attachment, the device deletes the attachment. If the protocol action is set to alert, the device only sends logs.
  • For NFS traffic, the device sends logs.

Example

# Create an antivirus profile named av_exception and add the virus exception Win32.Trojan.Reptile.b to the profile. 
<HUAWEI> system-view
[HUAWEI] profile type av name av_exception
[HUAWEI-profile-av-av_exception] exception av-signature-name Win32.Trojan.Reptile.b
# Enable the blacklist function, create an antivirus profile named av_exception, add the virus exception Win32.Trojan.Reptile.b to the profile, isolate the source IP address, and set the blacklist timeout interval to 10 minutes. 
<HUAWEI> system-view
[HUAWEI] firewall blacklist enable
[HUAWEI] profile type av name av_exception
[HUAWEI-profile-av-av_exception] exception av-signature-name Win32.Trojan.Reptile.b action block-source-ip timeout 10
