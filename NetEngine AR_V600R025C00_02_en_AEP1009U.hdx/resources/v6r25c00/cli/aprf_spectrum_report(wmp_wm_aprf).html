spectrum-report enable

Function

The spectrum-report enable command enables an AP radio to report spectrum analysis data.

The undo spectrum-report enable command disables an AP radio from reporting spectrum analysis data.

By default, AP radios are disabled from reporting spectrum analysis data.

Format

spectrum-report enable

undo spectrum-report enable

Parameters

None

Views

AP radio view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After an AP radio is enabled to report spectrum analysis data, the AP encapsulates collected data using UDP and sends the data to a spectrum server. The spectrum server analyzes the received data and then displays information about radios of non-Wi-Fi devices in charts.

Prerequisites

The spectrum analysis function has been enabled on a radio using the spectrum-analysis enable command.

Follow-up Procedure

The IP address and port number of the spectrum server have been specified using the spectrum-analysis server command in the spectrum analysis profile view.

Example

# Enable radio 0 on AP 0 to report spectrum analysis data.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-id 0
[HUAWEI-wlan-ap-0] radio 0
[HUAWEI-wlan-ap-0-radio-0] spectrum-report enable
