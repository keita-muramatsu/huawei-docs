diffserv-mode (VPN instance IPv6 address family view)

Function

The diffserv-mode command configures the MPLS DiffServ mode to provide end-to-end QoS assurance.

The undo diffserv-mode command restores the default MPLS DiffServ mode.

By default, the MPLS DiffServ mode is uniform.

Format

diffserv-mode uniform

diffserv-mode pipe mpls-exp exp-value

diffserv-mode short-pipe mpls-exp exp-value

undo diffserv-mode uniform

undo diffserv-mode pipe mpls-exp exp-value

undo diffserv-mode short-pipe mpls-exp exp-value

undo diffserv-mode

Parameters

Parameter Description Value
pipe

Sets the MPLS DiffServ mode to pipe.

-
mpls-exp exp-value

Sets the EXP value when the DiffServ mode of an MPLS network is pipe or short pipe.

The value is an integer ranging from 0 to 7.
short-pipe

Sets the MPLS DiffServ mode to short pipe.

-
uniform

Sets the MPLS DiffServ mode to uniform.

-

Views

VPN instance IPv6 address family view

Default Level

2: Configuration level

Usage Guidelines

When configuring the DiffServ mode:

If you want to differentiate service priorities on an MPLS network, configure the uniform mode.

If you do not want to differentiate service priorities on an MPLS network, configure the pipe or short pipe mode.

Example

# Set the MPLS DiffServ mode to pipe and the EXP value to 6 in the VPN instance IPv6 address family view.
<HUAWEI> system-view
[HUAWEI] ip vpn-instance vpna
[HUAWEI-vpn-instance-vpna] ipv6-family
[HUAWEI-vpn-instance-vpna-af-ipv6] diffserv-mode pipe mpls-exp 6
