display mpls label all summary

Function

The display mpls label all summary command displays allocation information about all MPLS labels.

Format

display mpls label all summary

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

After an MPLS session is established, the system collects statistics about label usage, including the allocation range and protocol type. You can run the display mpls label all summary command to view information about label space allocation and protocol type.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display allocation information about MPLS labels.
<HUAWEI> display mpls label all summary
TableType      MinValue    MaxValue    AvailableNum
Reserved              0          15              16
Static               16        2047            2028
Dynamic            2048       16383           14327
Table 1 Description of the display mpls label all summary command output
Item Description
TableType

Label type.

  • Reserved: Reserved label.
  • Static: Static tags, manually configured tags.
  • Dynamic: Dynamic tags, randomly assigned tags during business creation.
MinValue

Minimum label value.
MaxValue

Maximum label value.
AvailableNum

Number of labels that can be allocated.
