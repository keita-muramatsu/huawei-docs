engine ssl-acceleration disable

Function

The engine ssl-acceleration disable command disables SSL hardware acceleration.

The undo engine ssl-acceleration disable command enables SSL hardware acceleration.

By default, SSL hardware acceleration is enabled.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

engine ssl-acceleration disable

undo engine ssl-acceleration disable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

By default, SSL hardware acceleration is enabled on the device. After the function is enabled, the SSL handshake efficiency is improved.

If the hardware acceleration function fails, run the engine ssl-acceleration disable command to disable SSL hardware acceleration to ensure that the SSL-related functions can still run properly.

Example

# Disable SSL hardware acceleration.
<HUAWEI> system-view
[HUAWEI] engine ssl-acceleration disable
Warning: After SSL acceleration is disabled, the engine will restart and the SSL performance of related services will deteriorate. Continue? [Y/N]:y
