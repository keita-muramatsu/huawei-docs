ap log module

Function

The ap log module command enables APs to report logs of the module with a specified ID to a WMI server.

The undo ap log module command disables log reporting.

By default, APs do not report logs of any module to a WMI server.

Format

ap log module mid mid [ name name ]

undo ap log module { mid mid | all }

Parameters

Parameter Description Value
mid mid

Specifies the ID of a log module.

The value ranges from 00010000 to ffff0000 in hexadecimal notation. Set the value to the ID of a log module registered with the information center.

Description:

You can enter mid? to obtain the predefined ID of a log module and the log module name. You can run the display info-center statistics command on an AP to query more log module IDs.
name name

Specifies the name of a log module. The value must correspond to the value of mid.

The value is a string of 1 to 24 characters.
all

Indicates all log modules.

-

Views

WMI profile view

Default Level

2: Configuration level

Usage Guidelines

If APs need to report logs to a WMI server, specify the ID of a module whose logs are to be reported and enable the log report function. Otherwise, the APs do not report logs of this module.

To enable APs to report logs of multiple modules, run this command repeatedly to specify multiple module IDs.

Example

# Enable APs to report logs of the module C1480000.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] wmi-server name abc
[HUAWEI-wlan-wmi-server-prof-abc] ap log module mid c1480000
