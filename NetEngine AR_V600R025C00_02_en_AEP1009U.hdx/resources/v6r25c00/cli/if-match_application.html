if-match application

Function

The if-match application command configures a matching rule in a traffic classifier based on application protocols.

The undo if-match application command deletes a matching rule in a traffic classifier based on application protocols.

By default, a matching rule based on application protocols is not configured in a traffic classifier.

Format

if-match application application-name [ time-range time-name ]

undo if-match application application-name

Parameters

Parameter Description Value
application-name

Specifies the name of an application protocol. To query the name of an application protocol, run the display application command.

The value is a string of 1 to 32 case-sensitive characters, spaces not supported.
time-range time-name

Specifies the time range during which the matching rule takes effect. time-name specifies the name of the time range. If no time range is specified, the configuration takes effect at any time.

The value is a string of 1 to 32 case-sensitive characters, starting with an upper-case or a lower-case letter (A to Z or a to z). It cannot contain spaces. To avoid confusion, do not use the word all as the name of a time range.

Views

Traffic classifier view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

You can run the if-match application command to classify packets based on their application protocols. Application protocol packets matching the same traffic classifier are processed in the same way.

You can run the time-range command in the system view to set a time range in which a matching rule takes effect. If the time range specified for a matching rule has not been configured, the rule does not take effect.

Precautions

  • The if-match application command does not support IPv6. The AND mode cannot be used to match IPv6 rules.
  • This function takes effect only when application identification is enabled.
  • In AND mode of a traffic classifier, only one application protocol can be configured.
  • When the same configurations are delivered, the configuration with a time range has a higher priority. Only one configuration is displayed for the same application.
  • You can run the display application command in the system view to query the configuration.

Example

# Define the traffic classifier class1 to match packets of the SA application protocol 91farm.
<HUAWEI> system-view
[HUAWEI] traffic classifier class1
[HUAWEI-classifier-class1] if-match application 91farm
