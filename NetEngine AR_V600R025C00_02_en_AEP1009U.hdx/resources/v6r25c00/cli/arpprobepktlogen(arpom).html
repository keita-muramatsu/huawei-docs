arp probe packet log enable

Function

The arp probe packet log enable command enables a device to log the received ARP probe packets whose destination IP address is the same as the local interface IP address.

The undo arp probe packet log enable command disables a device from logging the received ARP probe packets whose destination IP address is the same as the local interface IP address.

By default, a device does not log the received ARP probe packets whose destination IP address is the same as the local interface IP address.

Format

arp probe packet log enable

undo arp probe packet log enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

An ARP probe packet is a special ARP request packet whose source IP address is 0 and destination IP address is the IP address to be probed.

Huawei devices do not proactively send ARP probe packets but do receive them. If the destination IP address of a received ARP probe packet is the same as the local interface IP address, the receiver does not determine that this is an address conflict. Such packets are not logged by default in order to reduce the false reporting of conflict alarm logs and to improve maintenance efficiency.

Example

# Enable a device to log the received ARP probe packets whose destination IP address is the same as the local interface IP address.
<HUAWEI> system-view
[HUAWEI] arp probe packet log enable
