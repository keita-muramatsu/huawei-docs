ad-server authentication manager

Function

The ad-server authentication manager command configures the administrator DN and password of an AD authentication server.

The undo ad-server authentication manager command deletes the administrator DN and password of an AD authentication server.

By default, the administrator DN and password of an AD authentication server are not configured.

Format

ad-server authentication manager manager password

undo ad-server authentication manager

Parameters

Parameter Description Value
manager

Specifies the administrator DN of an AD authentication server.

If manager-dn does not contain spaces, the value is a string of 1 to 180 characters. If manager-dn contains spaces, it must be enclosed in double quotation marks (""), for example, "cn=test manager,cn=users". The value is a string of 3 to 182 characters and cannot contain only spaces.

This parameter must be set together with the ad-server authentication manager-with-base-dn enable command. For example, the Base DN of the administrator is example.com, and the account is stored in the users group. The administrator DN is then configured as follows:

When the ad-server authentication manager-with-base-dn enable command is configured, manager-dn is cn=administrator,cn=users.

When the undo ad-server authentication manager-with-base-dn enable command is configured, manager-dn is cn=administrator,cn=users,dc=example,dc=com.

Multiple languages are supported, including ASCII characters such as English and non-ASCII characters such as Chinese, German, and French.

The encoding format used by the client of an access user must be the same as that used by the device. Otherwise, the user may fail to go online or the user name may be displayed as garbled characters.

After the encoding format is converted, the user names of the original online users with the user name of non-ASCII characters may be displayed as garbled characters.
password

Specifies the administrator password of an AD authentication server.

The value is a string of 1 to 31 characters in plain text or a string of 148 characters in cipher text. The plain text cannot contain & or ". The system saves this string to the configuration file in cipher text. If the string consists of 1 to 16 characters, the length of the converted ciphertext is 128 bytes. If the string consists of 17 to 31 characters, the length of the converted ciphertext is 148 bytes.

Views

AD server template view

Default Level

3: Management level

Usage Guidelines

To configure the DN and password of an AD administrator, run the ad-server authentication manager command. If the ad-server authentication manager-anonymous enable command has been executed to allow anonymous access to the AD server, the configuration will be deleted after ad-server authentication manager is run.

Example

# Set the DN of the AD administrator to cn=manager and password to YsHsjx_202206. 
<HUAWEI> system-view
[HUAWEI] ad-server template temp1
[HUAWEI-ad-temp1] ad-server authentication manager cn=manager YsHsjx_202206
