spectrum-analysis server

Function

The spectrum-analysis server command specifies the IP address and port number of a spectrum server.

The undo spectrum-analysis server command deletes the specified IP address and port number of a spectrum server.

By default, no spectrum server is configured.

Format

spectrum-analysis server { ip-address ip-address | ipv6-address ipv6-address } port port-num [ via-ac ac-port ac-port-num ]

undo spectrum-analysis server

Parameters

Parameter Description Value
ip-address ip-address

Specifies the IPv4 address of a spectrum server.

The value is in dotted decimal notation.
ipv6-address ipv6-address

Specifies the IPv6 address of a spectrum server.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
port port-num

Specifies the UDP port number of a spectrum server.

The value is an integer ranging from 1 to 65535.
via-ac

Configures the AP to report spectrum data to the spectrum server via the AC.

-
ac-port ac-port-num

Specifies the port number used by the AC to receive spectrum data (in UDP packets) from the AP.

The value is an integer ranging from 5000 to 65535.

Views

AP system profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After collecting the spectrum data, an AP encapsulates the collected data into UDP packets and sends the packets to the spectrum server. The spectrum server draws a spectrum and displays the spectrum information of the detected non-Wi-Fi devices to users through images.

  • If the AP uploads the collected data directly to the spectrum server, you do not need to configure the via-ac ac-port ac-port-number command.
  • If the AP uploads the collected data to the spectrum server via the AC, configure the via-ac ac-port ac-port-number command.
  • If no spectrum server is available, you can view the spectrum on the web system of a WAC. In this case, specify a valid IP address and port number for the spectrum server, which do not take effect, and configure the via-ac ac-port ac-port-number command.
  • When APs upload the collected data directly to the spectrum server, ensure that the IP protocol version used by the APs to communicate with the spectrum server is the same as that used by the APs to go online on the WAC. Otherwise, the spectrum analysis function does not take effect.

Follow-up Procedure

Run the spectrum-report enable command in the AP radio view to enable spectrum data reporting on AP radios.

Example

# Set the IP address and port number of a spectrum server to 10.137.43.4 and 27371, respectively.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name ap-system1
[HUAWEI-wlan-ap-system-prof-ap-system1] spectrum-analysis server ip-address 10.137.43.4 port 27371
