evpn-site-group peer-site multi-group disable(system view)

Function

The evpn-site-group peer-site multi-group disable command disables the function of binding a site to multiple site groups.

The undo evpn-site-group peer-site multi-group disable command enables the function of binding a site to multiple site groups.

By default, a site can be bound to multiple site groups.

This command is supported only on the AR8700 series, AR8100 series and AR6700-H series.

Format

evpn-site-group peer-site multi-group disable

undo evpn-site-group peer-site multi-group disable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

In the scenario where the SD-WAN HQ sends data to branches, you can run the undo evpn-site-group peer-site multi-group disable command to configure the same peer site and different source TNPs for different site groups, and enable connection-based QoS to implement differentiated rate limiting in advance. This prevents network congestion and random packet loss, ensuring lossless transmission of key application traffic.

Example

# Disable the function of binding a site to multiple site groups.
<HUAWEI> system-view
[HUAWEI] evpn-site-group peer-site multi-group disable
