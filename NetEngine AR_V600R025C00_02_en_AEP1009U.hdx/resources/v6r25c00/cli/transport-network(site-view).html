transport-network (Site view)

Function

The transport-network command creates a transport network domain.

The undo transport-network command deletes a transport network domain.

By default, no transport network domain is created.

Format

transport-network transport-network-id name transport-network-name [ priority priority ]

undo transport-network transport-network-id [ name transport-network-name ] [ priority priority ]

Parameters

Parameter Description Value
transport-network-id

Specifies a TN ID.

The value is an integer in the range from 1 to 4294967295.
name transport-network-name

Specifies a TN name.

The value is a string of 1 to 31 case-sensitive characters. If spaces are used, the string must be enclosed in double quotation marks (" ").
priority priority

Specifies a priority.

The value is an integer ranging from 1 to 255.

Views

Site view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To create a transport network domain at a site, run the transport-network command so that a TNP can select the transport network domain that it belongs to. At a site, TNPs in the same transport network domain preferentially establish connections. If the transport network domains of TNPs are different, TNPs in the same routing domain establish connections.

Prerequisites

Site information has been configured using the evpn site command.

Precautions

  • Ensure that the mapping between transport network IDs and transport network names configured on all site devices in EVPN networking is the same.
  • A maximum of 32 transport networks can be configured.
  • Transport networks cannot be modified after being configured.

Example

# Create a transport network domain named MPLS1 with ID 1 at site 1.
<HUAWEI> system-view
[HUAWEI] evpn site 1
[HUAWEI-site-1] transport-network 1 name MPLS1
