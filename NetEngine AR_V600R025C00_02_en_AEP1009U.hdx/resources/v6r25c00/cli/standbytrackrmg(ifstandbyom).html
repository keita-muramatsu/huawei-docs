standby track route-monitor-group

Function

The standby track route-monitor-group command configures association between interface backup and a route monitoring group.

The undo standby track route-monitor-group command cancels the association between interface backup and a route monitoring group.

By default, interface backup is not associated with a route monitoring group on an interface.

Format

standby track route-monitor-group group-name [ weight weight-num ]

undo standby track route-monitor-group [ group-name [ weight weight-num ] ]

Parameters

Parameter Description Value
group-name

Specifies the name of a route monitoring group.

The value is a string of 1 to 31 case-sensitive characters, spaces not supported.

The character string can contain spaces if it is enclosed in double quotation marks (").
weight weight-num

Sets the backup interface's up status recovery weight.

The value is an integer ranging from 1 to 1000, in seconds.

Views

10GE sub-interface view, 10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE sub-interface view, 40GE interface view, Cellular channel interface view, Dialer interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, Ethernet sub-interface view, Ethernet interface view, GE optical interface view, GE sub-interface view, GE electrical interface view, IP-Trunk interface view, MP-group interface view, Multi-GE sub-interface view, Multi-GE interface view, POS interface view, Tunnel interface view, Serial interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To prevent service interruption caused by link faults, you can create a dynamic route monitoring group and configure association between interface backup and the route monitoring group to monitor the status of routes on the primary link. When no valid route is available on all monitored network segments, the backup link is used to transmit services temporarily.

Prerequisites

A route monitoring group has been created using the ip route-monitor-group command.

Precautions

Each interface can be associated with only one route monitoring group, and cannot be associated with NQA test instances at the same time.

A maximum of 255 interfaces can be associated with route monitoring groups.

If no weight is configured for the association between interface backup and a route monitoring group, the backup interface goes up only when all routes in the route monitoring group are unavailable.

The backup interface goes up based on the route status only after the monitor enable command is run for the route monitoring group.

After the association between interface backup and a route monitoring group is configured, if the route status is not obtained, the backup interface remains physically down.

After the association between interface backup and a route monitoring group is configured, the interface remains physically down during the warmup delay.

Example

# Associate 10GE0/0/1 with route monitoring group group1 and set the weight value to 100 for the backup interface to automatically go up.
<HUAWEI> system-view
[HUAWEI] ip route-monitor-group group1
[HUAWEI-route-monitor-group-group1] track ip route 10.1.1.1 255.255.255.0 down-weight 100
[HUAWEI-route-monitor-group-group1] monitor enable
[HUAWEI-route-monitor-group-group1] quit
[HUAWEI] interface 10GE0/0/1
[HUAWEI-10GE0/0/1] standby track route-monitor-group group1 weight 100
