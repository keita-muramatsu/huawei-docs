rate-limit

Function

The rate-limit command configures the rate limit for upstream and downstream packets of all STAs or each STA on a VAP.

The undo rate-limit command restores the default rate limit for upstream and downstream packets of all STAs or each STA on a VAP.

By default, the rate limit for upstream and downstream packets of all STAs on a VAP is 4294967295 kbit/s, and the rate limit for upstream and downstream packets of each STA on a VAP is 4294967295 kbit/s.

Format

rate-limit { client | vap } { up | down } rate-value

undo rate-limit { client | vap } { up | down }

Parameters

Parameter Description Value
client

Specifies each STA on a VAP.

-
vap

Specifies all STAs on a VAP.

-
up

Enables rate limiting for upstream packets on a VAP.

-
down

Enables rate limiting for downstream packets on a VAP.

-
rate-value

Specifies the rate limit of packets.

The value is an integer that ranges from 64 to 4294967295, in kbit/s.

The value 4294967295 indicates that the packet rate is not limited.

Views

Traffic profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To limit the rate of upstream and downstream packets of all STAs or each STA on a VAP to protect network bandwidth resources, run the rate-limit command.

Precautions

The limited rate does not take effect for STAs that go online before the rate-limit command is configured. To make this configuration take effect for such a STA, enable the STA to go online again.

The rate limit configured for each STA on a VAP does not take effect for multicast packets.

Example

# Set the rate limit for upstream packets to 4294967295 kbit/s for all STAs on a VAP in the traffic profile p1.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] traffic-profile name p1
[HUAWEI-wlan-traffic-prof-p1] rate-limit vap up 4294967295
