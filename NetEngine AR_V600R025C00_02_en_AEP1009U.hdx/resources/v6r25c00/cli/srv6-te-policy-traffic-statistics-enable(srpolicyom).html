traffic-statistics (SRv6 TE Policy view)

Function

The traffic-statistics enable command enables SRv6 TE Policy-based traffic statistics collection.

The traffic-statistics disable command disables SRv6 TE Policy-based traffic statistics collection.

The undo traffic-statistics enable command disables SRv6 TE Policy-based traffic statistics collection.

The undo traffic-statistics disable command enables SRv6 TE Policy-based traffic statistics collection.

By default, the SRv6 TE policy traffic statistics function is disabled.

Format

traffic-statistics { enable | disable }

undo traffic-statistics [ { enable | disable } ]

Parameters

Parameter Description Value
enable

Enable.

-
disable

Disable.

-

Views

SRv6 TE policy view

Default Level

2: Configuration level

Usage Guidelines

After the traffic-statistics enable command is run for an SRv6 TE Policy, traffic statistics collection is enabled. To disable this function, run the traffic-statistics disable command.

The undo traffic-statistics command deletes SRv6 TE Policy traffic statistics so that the srv6-te-policy traffic-statistics command configuration in the Segment Routing IPv6 view can be inherited.

Example

# Enable the traffic statistics function of the SRv6 TE policy.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] srv6-te policy p1 endpoint 2001:DB8:1::1 color 100
[HUAWEI-segment-routing-ipv6-policy-p1] traffic-statistics enable
