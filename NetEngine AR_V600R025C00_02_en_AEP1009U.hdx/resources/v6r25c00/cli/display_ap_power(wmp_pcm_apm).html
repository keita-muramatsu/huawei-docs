display ap power

Function

The display ap power command displays AP power supply information.

Format

display ap power ap-id ap-id

Parameters

Parameter Description Value
ap-id ap-id

Displays power supply information about the AP with a specified ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run this command to check the power supply information about an AP, including the power supply mode, rated voltage, and rated power.

Power supply information can be queried only for the AirEngine 9700D-M and AirEngine 9700D-S.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display power supply information about an AP.
<HUAWEI> display ap power ap-id 0
---------------------------------------------------------------------------------------
PowerNo   Present   Mode   State    Voltage(V)   Power(W)
---------------------------------------------------------------------------------------
PWRI      YES       AC     Normal   56           1000
---------------------------------------------------------------------------------------
Table 1 Description of the display ap power command output
Item Description
PowerNo

Number of a power module.
Present

Whether a power module is in position.

  • YES: The power module is in position.
  • NO: The power module is not in position.
Mode

Power supply mode of a power module.

  • DC: direct current power supply.
  • AC: alternating current power supply.
State

Power supply status.

  • Normal: There is current output.
  • Abnormal: No current is output.
Voltage(V)

Rated voltage of a power module (V).
Power(W)

Rated power of a power module (W).
