port-security mac-address sticky

Function

The port-security mac-address sticky command adds a sticky MAC address entry.

The undo port-security mac-address sticky command deletes a sticky MAC address entry.

Format

port-security mac-address sticky mac-address vlan vlan-id

undo port-security mac-address sticky mac-address vlan vlan-id

Parameters

Parameter Description Value
vlan vlan-id

Specifies a VLAN ID.

The value is an integer ranging from 1 to 4094.
sticky mac-address

Specifies a sticky MAC address.

The format is H-H-H. H is a hexadecimal number ranging from 1 to 4, for example, 00e0 and fc01. If an H contains fewer than 4 digits, the left-most digits are padded with zeros. For example, e0 is displayed as 00e0.

Views

Layer 2 10GE interface view, 25GE-L2 view, Layer 2 40GE interface view, Layer 2 Eth-Trunk interface view, Layer 2 GE interface view, Layer 2 multi-GE interface view, VGE-L2 view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Port security is a security function that converts dynamic MAC addresses learned by an interface into secure MAC addresses.

After port security is enabled on an interface, the switch converts dynamic MAC addresses learned by the interface into secure MAC addresses. In this case, the dynamic MAC address entries learned by the interface are deleted. When the number of MAC addresses learned by the interface reaches the upper limit, the interface no longer learns new MAC addresses. If the source MAC address of a packet received by an interface does not exist in the MAC address entries, the interface considers the packet as an attack packet and discards the packet, reports an alarm, or shuts down the interface.

Prerequisites

You can manually add a sticky MAC address entry only after the sticky MAC function is enabled.

Example

# Manually add a sticky MAC address entry with the MAC address 1-1-3 and the VLAN ID 10 on 10GE0/0/1.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] port-security enable
[HUAWEI-10GE0/0/1] port-security mac-address sticky
[HUAWEI-10GE0/0/1] port-security mac-address sticky 1-1-3 vlan 10
