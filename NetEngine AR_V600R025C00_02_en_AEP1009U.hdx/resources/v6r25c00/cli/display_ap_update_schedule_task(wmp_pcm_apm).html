display ap update schedule-task (all views)

Function

The display ap update schedule-task command displays information about scheduled AP upgrade tasks.

Format

display ap update schedule-task

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run this command to view information about scheduled AP upgrade tasks, and run the undo ap update schedule-task { all | task-id task-id} command to delete the completed or unnecessary scheduled tasks.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display information about scheduled AP upgrade tasks.
<HUAWEI> display ap update schedule-task
-------------------------------------------------------------------------------------
 Task-ID  Task-State  Start-Time        Stop-Time         AP-Type  AP-Group
-------------------------------------------------------------------------------------
 1        IDLE        2020/01/01 11:11  2020/01/02 11:12  125      -
-------------------------------------------------------------------------------------
Table 1 Description of the display ap update schedule-task (all views) command output
Item Description
Task-ID

Index of a scheduled upgrade task.
Task-State

Status of a scheduled upgrade task.

  • DEAD: The start time of the scheduled upgrade task configured by the user is earlier than the system time, or the task stops unexpectedly.
  • DONE: The task has been executed.
  • IDLE: The task is not activated.
  • OVERTIME: The task waiting times out.
  • RUNNING: The task is being executed.
  • WAITING: The start time of the task arrives, but another task is being executed.
Start-Time

Start time of a scheduled upgrade task.
Stop-Time

End time of a scheduled upgrade task.
AP-Type

Type of the AP to be upgraded at a scheduled time.
AP-Group

AP group to which the AP to be upgraded belongs.
