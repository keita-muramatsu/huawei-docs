ad-server authorization bind-user enable

Function

The ad-server authorization bind-user enable command configures user binding during AD authorization.

The undo ad-server authorization bind-user enable command cancels user binding during AD authorization.

By default, user binding is performed during AD authorization.

Format

ad-server authorization bind-user enable

undo ad-server authorization bind-user enable

Parameters

None

Views

AD server template view

Default Level

3: Management level

Usage Guidelines

By default, user binding is performed during AD authorization. During the authorization, the device sends the user names and passwords of authenticated users to the AD server for re-authentication. If a user name has the same password on an authentication server and an AD server, user binding is required. If a user name has different passwords on an authentication server and an AD server, run the undo ad-server authorization bind-user enable command to cancel user binding; otherwise, user authentication will fail on the AD server and authorization fails.

Example

# Cancel user binding during AD authorization. 
<HUAWEI> system-view
[HUAWEI] ad-server template temp1
[HUAWEI-ad-temp1] undo ad-server authorization bind-user enable
