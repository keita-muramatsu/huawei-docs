firewall log session aging enable

Function

The firewall log session aging enable command enables the function of sending aging session logs to the log host.

The undo firewall log session aging enable command disables the function of sending aging session logs to the log host.

By default, the function of sending aging session logs to the log host is enabled.

Format

firewall log session aging enable

undo firewall log session aging enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

To enable the function of sending aging session logs to the log host, run the firewall log session aging enable command.

Example

# Enable the function of sending aging session logs to the log host. 
<HUAWEI> system-view
[HUAWEI] firewall log session aging enable
