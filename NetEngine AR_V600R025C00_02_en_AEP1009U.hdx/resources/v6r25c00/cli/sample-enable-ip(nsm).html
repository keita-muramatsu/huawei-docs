netstream ip

Function

The netstream ip command enables IPv4 traffic statistics collection on the inbound and outbound interfaces.

The undo netstream ip command restores the default configuration.

By default, traffic statistics collection is disabled on the inbound and outbound interfaces.

Format

netstream { inbound | outbound } ip

undo netstream { inbound | outbound } ip

Parameters

Parameter Description Value
inbound

Enables IPv4 traffic statistics collection on the inbound interface.

-
outbound

Enables IPv4 traffic statistics collection on the outbound interface.

-

Views

10GE interface view, 40GE interface view, Cellular channel interface view, Dialer interface view, Eth-Trunk interface view, Ethernet interface view, GE interface view, IP-Trunk interface view, MP-group interface view, POS interface view, Tunnel interface view, VLANIF interface view, Serial interface view, Sub-interface view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

To export IPv4 traffic statistics, you must run the netstream ip command to enable the NetStream function on an interface.

After you run the netstream ip command to configure IPv4 traffic statistics collection and run the netstream ipv6 command to configure IPv6 traffic statistics collection on an interface, the statistics about two types of traffic can be collected independently.

Prerequisites

Before running the netstream ip command on an interface, you need to run the netstream sampler command on the interface.

Precautions

IPv4 sampling can be configured only in GRE and SD-WAN tunnel encapsulation modes in the tunnel interface view.

Example

# Enable IPv4 traffic statistics collection in the inbound direction of 10GE 0/0/1. 
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] netstream inbound ip
