display smart-upgrade information

Function

The display smart-upgrade information command displays the smart upgrade configuration, upgrade version, upgrade status, and local information.

Format

display smart-upgrade information

Parameters

None

Views

All views

Default Level

3: Management level

Usage Guidelines

If the smart upgrade function is enabled on a device, you can run this command to check information about smart upgrade on the device.

Example

The actual command output varies according to the device. The command output here is only an example.
