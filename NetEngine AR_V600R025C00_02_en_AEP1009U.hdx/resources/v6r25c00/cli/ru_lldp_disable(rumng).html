lldp(remote-unit N view)

Function

The lldp disable command disables LLDP for an RU.

The lldp enable command enables LLDP for an RU.

The undo lldp command cancels the current configuration and uses the configuration in the global RU view.

By default, LLDP is not configured for a single RU, and the configuration in the global RU view is used.

Format

lldp disable

lldp enable

undo lldp

Parameters

Parameter Description Value
enable

Enables LLDP on a downlink interface of the RU.

-
disable

Disables LLDP on a downlink interface of the RU.

-

Views

remote-unit N view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After an RU is delivered, its downlink interface receives LLDP packets and notifies the central device of the LLDP packets. The central device then records the interface for connecting the LLDP neighbor to the RU. To configure the function of recording the RU interfaces connected to LLDP neighbors for an RU, you can run the lldp disable or lldp enable command in the remote-unit-N view. The configuration of a single RU takes precedence over the configuration in the global RU view. If no configuration is performed for a single RU, the configuration in the global RU view is used.

Follow-up Procedure

After running this command for a single RU, run the commit command for the configuration to take effect. You can run the display remote-unit commit configuration command to check the configurations that are successfully delivered to RUs, and run the display remote-unit commit result command to check configuration delivery results of RUs.

Precautions

If LLDP is enabled or disabled on an RU, the configuration in the single RU view is used. If no configuration is performed for a single RU, the configuration in the global RU view is used.

This command is available only for S5751-L series RUs.

Example

# Disable LLDP on an RU.
<HUAWEI> system-view
[HUAWEI] remote-unit 0
[HUAWEI-remote-unit-0] bind interface 10GE0/0/1
[HUAWEI-remote-unit-0] lldp disable
