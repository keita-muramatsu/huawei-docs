plmn select

Function

The plmn select command selects the Public Land Mobile Network (PLMN) in automatic or manual mode.

The undo plmn select command restores the default configuration.

By default, a modem automatically selects a PLMN.

Format

plmn select manual mcc mnc [ fail-over-auto ]

undo plmn select manual

Parameters

Parameter Description Value
mcc

Specifies a mobile country code (MCC).

The value is an integer ranging from 0 to 999.
mnc

Specifies a mobile network code (MNC).

The value is an integer ranging from 0 to 999.
fail-over-auto

Indicates that a modem automatically selects a PLMN when manual PLMN selection fails.

-
select

Selects a PLMN.

-
manual

Indicates that the PLMN of a modem is manually specified. The mcc and mnc parameters must be specified.

-

Views

Cellular template view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

For a cellular network, you can manually select a PLMN for a modem or configure a modem to automatically select a PLMN. You can run the display cellular command to query the network selection result.

Precautions

This command takes effect only when both the modem and SIM card are installed.

If the PLMN is manually selected, run the undo plmn select manual command to configure the modem to automatically select a PLMN. If automatic selection of the PLMN has been enabled, no operation will be performed when the undo plmn select manual command is executed.

On models with an LTE modem, if the fail-over-auto field is not configured and the manually selected PLMN is not within the range specified by plmn search, the original PLMN is used for network access.

On the MIC-LTE4CN-V2 and MIC-LTE4EA-V2 cards, if the fail-over-auto field is not configured and the manually selected PLMN is not within the range specified by plmn search, the original PLMN is used for network access.

Example

# Manually select a PLMN.
<HUAWEI> system-view
[HUAWEI] cellular-profile net
[HUAWEI-cellular-profile-net] plmn select manual 460 03
# Configure a modem to automatically select a PLMN.
<HUAWEI> system-view
[HUAWEI] cellular-profile net
[HUAWEI-cellular-profile-net] undo plmn select manual
