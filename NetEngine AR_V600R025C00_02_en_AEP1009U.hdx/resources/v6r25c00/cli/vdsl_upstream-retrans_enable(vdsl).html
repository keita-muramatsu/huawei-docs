vdsl upstream-retrans enable (VDSL interface)

Function

The vdsl upstream-retrans enable command enables the upstream retransmission function on a VDSL interface.

The undo vdsl upstream-retrans enable command disables the upstream retransmission function on a VDSL interface.

By default, the upstream retransmission function is enabled on a VDSL interface.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S10T1X2, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

vdsl upstream-retrans enable

undo vdsl upstream-retrans enable

Parameters

None

Views

Ethernet interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

By default, the upstream retransmission function is enabled on a VDSL interface of the device functioning as a CPE to enhance link reliability. When the device is restarted, it sends a Dying Gasp message to the DSLAM. If the DSLAM is incapable of receiving a Dying Gasp message during upstream retransmission, you can run the undo vdsl upstream-retrans enable command to disable the upstream retransmission function on the VDSL interface. In this case, the DSLAM can properly respond the Dying Gasp message.

Precautions

Running this command will restart the interface, causing data frame loss or service interruption.

Example

# Disable the upstream retransmission function on VDSL interface 1/0/0.
<HUAWEI> system-view
[HUAWEI] interface Ethernet 1/0/0
[HUAWEI-Ethernet1/0/0] undo vdsl upstream-retrans enable
Warning: This operation may cause the interface to restart. Are you sure to continue? [Y/N]:y
