cipher-suite exclude

Function

The cipher-suite exclude key-exchange rsa command excludes the RSA key exchange algorithm from the cipher suite list.

The undo cipher-suite exclude key-exchange rsa command enables the device to support the RSA key exchange algorithm in the cipher suite list.

The cipher-suite exclude key-exchange dhe command excludes the DHE key exchange algorithm from the cipher suite list.

The undo cipher-suite exclude key-exchange dhe command enables the device to support the DHE key exchange algorithm in the cipher suite list.

The cipher-suite exclude cipher mode cbc command excludes CBC-encrypted algorithms from the cipher suite list.

The undo cipher-suite exclude cipher mode cbc command enables the device to support CBC-encrypted algorithms in the cipher suite list.

The cipher-suite exclude hmac sha1 command excludes the SHA1 digest algorithm from a cipher suite list.

The undo cipher-suite exclude hmac sha1 command enables the device to support the SHA1 digest algorithm in the cipher suite list.

By default, RSA key exchange algorithm, CBC mode algorithm and HMAC-SHA1 algorithm are not supported in an SSL cipher suite bound to an SSL policy.

Format

cipher-suite exclude key-exchange { rsa | dhe } *

cipher-suite exclude cipher mode cbc

cipher-suite exclude hmac sha1

undo cipher-suite exclude key-exchange { rsa | dhe } *

undo cipher-suite exclude cipher mode [ cbc ]

undo cipher-suite exclude hmac [ sha1 ]

undo cipher-suite exclude key-exchange

Usage Guidelines

Usage Scenario

During authentication between the client and server, an encryption algorithm list is provided for SSL algorithm negotiation. You can run this command to exclude the RSA/CBC/SHA1/DHE key exchange algorithm from an SSL policy to enhance security.

Prerequisites

An SSL policy has been created using the ssl policy command.

Precautions

  • After you run this command to exclude the RSA/CBC/SHA1/DHE key exchange algorithm from an SSL policy, the RSA/CBC/SHA1/DHE encryption algorithm configured in the SSL policy cipher suite does not take effect.
  • RSA algorithms include tls1_ck_rsa_with_aes_256_sha, tls1_ck_rsa_with_aes_128_sha, tls12_ck_rsa_aes_128_cbc_sha, tls12_ck_rsa_aes_256_cbc_sha256, tls12_ck_rsa_with_aes_128_gcm_sha256, and tls12_ck_rsa_with_aes_256_gcm_sha384.
  • CBC algorithms include tls12_ck_rsa_aes_128_cbc_sha, tls12_ck_rsa_aes_256_cbc_sha256, tls12_ck_dhe_dss_aes_256_cbc_sha, tls12_ck_dhe_rsa_aes_256_cbc_sha, tls12_ck_dhe_dss_aes_128_cbc_sha256, tls12_ck_dhe_rsa_aes_128_cbc_sha, tls12_ck_dhe_dss_aes_256_cbc_sha, tls12_ck_dhe_rsa_aes_256_cbc_sha, tls12_ck_dhe_dss_aes_128_cbc_sha256, tls12_ck_dhe_rsa_aes_128_cbc_sha256, tls12_ck_dhe_dss_aes_256_cbc_sha256, and tls12_ck_dhe_rsa_aes_256_cbc_sha256.
  • SHA1 algorithms include tls1_ck_rsa_with_aes_256_sha, tls1_ck_rsa_with_aes_128_sha, tls1_ck_dhe_rsa_with_aes_256_sha, tls1_ck_dhe_dss_with_aes_256_sha, tls1_ck_dhe_rsa_with_aes_128_sha, tls1_ck_dhe_dss_with_aes_128_sha, tls12_ck_rsa_aes_128_cbc_sha, tls12_ck_dhe_dss_aes_256_cbc_sha, tls12_ck_dhe_rsa_aes_256_cbc_sha, tls12_ck_dhe_rsa_aes_128_cbc_sha, tls12_ck_dhe_dss_aes_256_cbc_sha, and tls12_ck_dhe_rsa_aes_256_cbc_sha.
  • DHE algorithms include tls1_ck_dhe_rsa_with_aes_256_sha, tls1_ck_dhe_dss_with_aes_256_sha, tls1_ck_dhe_rsa_with_aes_128_sha, tls1_ck_dhe_dss_with_aes_128_sha, tls12_ck_dhe_dss_aes_256_cbc_sha, tls12_ck_dhe_rsa_aes_256_cbc_sha, tls12_ck_dhe_dss_aes_128_cbc_sha256, tls12_ck_dhe_rsa_aes_128_cbc_sha, tls12_ck_dhe_dss_aes_256_cbc_sha, tls12_ck_dhe_rsa_aes_256_cbc_sha, tls12_ck_dhe_dss_aes_128_cbc_sha256, tls12_ck_dhe_rsa_aes_128_cbc_sha256, tls12_ck_dhe_dss_aes_256_cbc_sha256, tls12_ck_dhe_rsa_aes_256_cbc_sha256, tls12_ck_dhe_rsa_with_aes_128_gcm_sha256, tls12_ck_dhe_rsa_with_aes_256_gcm_sha384, tls12_ck_dhe_dss_with_aes_128_gcm_sha256, and tls12_ck_dhe_dss_with_aes_256_gcm_sha384.

Example

# Exclude the CBC encryption mode algorithm from the SSL cipher suite bound to an SSL policy.
<HUAWEI> system-view
[HUAWEI] ssl policy abc
[HUAWEI-ssl-policy-abc] cipher-suite exclude cipher mode cbc
# Exclude the DHE key exchange algorithm from the SSL cipher suite bound to an SSL policy.
<HUAWEI> system-view
[HUAWEI] ssl policy abc
[HUAWEI-ssl-policy-abc] cipher-suite exclude key-exchange dhe
# Exclude the RSA key exchange algorithm from the SSL cipher suite bound to an SSL policy.
<HUAWEI> system-view
[HUAWEI] ssl policy abc
[HUAWEI-ssl-policy-abc] cipher-suite exclude key-exchange rsa
# Exclude the SHA1 algorithm from the SSL cipher suite bound to an SSL policy.
<HUAWEI> system-view
[HUAWEI] ssl policy abc
[HUAWEI-ssl-policy-abc] cipher-suite exclude hmac sha1
