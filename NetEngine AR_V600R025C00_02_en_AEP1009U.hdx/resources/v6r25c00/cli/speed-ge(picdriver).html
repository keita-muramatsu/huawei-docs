speed(GE interface view)

Function

The speed command configures an Ethernet interface to work at a specified rate.

The undo speed command restores the default rate of an Ethernet interface.

By default, an Ethernet interface works at its highest rate.

Format

speed { 1000 | 100 | 10 }

undo speed [ 1000 | 100 | 10 ]

Parameters

Parameter Description Value
1000

Indicates the 1000 Mbit/s rate mode.

-
100

Indicates the 100 Mbit/s rate mode.

-
10

Indicates the 10 Mbit/s rate mode.

-

Views

Layer 2 10GE interface view, 10GE interface view, GE optical interface view, GE interface view, GE electrical interface view, Layer 2 multi-GE interface view, Multi-GE interface view, Interface group view, Management interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In non-auto negotiation mode, if interfaces on two connected devices work at different rates, use the speed command to change the rates of the interfaces to be the same so that the two devices can communicate.

Prerequisites

Before running the speed command on an electrical interface or an optical interface with an optical-to-electrical conversion module installed, run the negotiation disable command to disable the auto-negotiation mode.

Precautions

  • Electrical interfaces and optical interfaces that have copper modules installed support the speed command.
  • If a GE optical interface has a GE variable-rate optical module installed, only the speed 100 command can be configured.
  • GE optical interfaces that have non-Huawei-certified GE optical modules installed support the speed 100 command.
  • If an optical interface has a copper module installed, the speed 10 command cannot be configured.
  • If you run the speed command on an interface that is physically up, the physical status of the interface becomes down and then up. Exercise caution when doing this.
  • Assume that the current module is replaced with a new module and the new module does not support the speed configuration after the interface rate takes effect. For example, if a GE copper module is replaced with a Huawei-certified GE non-variable-rate optical module, the optical interface does not support the speed configuration after it has the Huawei-certified GE non-variable-rate optical module installed. In this case, the configuration is lost and the interface goes up.

Example

# Configure 10GE0/0/1 to work at 1000 Mbit/s when a GE optical/electrical module is inserted.
<HUAWEI> system-view
[HUAWEI] interface 10ge 0/0/1
[HUAWEI-10GE0/0/1] speed 1000
