update local location-sdb

Function

The update local location-sdb command enables manual update of the local location signature database.

Format

update local location-sdb file file-name

Parameters

Parameter Description Value
file file-name

Specifies the update file. You must upload the update files to the device memory using FTP or SFTP before the update.

The absolute path of a file is a string of 1 to 64 characters without spaces.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

If the device cannot connect to the network, download the update files from the security center (isecurity.huawei.com) to a PC and upload the files to the device memory using FTP or SFTP. Then run the update local command to update the databases.

Example

# Manually update the location signature database using the file flash:/location_H30071000_2018082200.zip.
<HUAWEI> system-view
[HUAWEI] update local location-sdb file flash:/location_H30071000_2018082200.zip
