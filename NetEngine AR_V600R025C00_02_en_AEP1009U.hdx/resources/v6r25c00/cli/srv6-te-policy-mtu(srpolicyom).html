mtu (SRv6 TE policy view)

Function

The mtu command configures an MTU for an SRv6 TE Policy.

The undo mtu command deletes the MTU configuration.

By default, no MTU is configured for an SRv6 TE Policy.

Format

mtu mtu-value

undo mtu [ mtu-value ]

Parameters

Parameter Description Value
mtu-value

Specifies an MTU for an SRv6 TE Policy.

The value is an integer ranging from 1280 to 9600, in bytes.

Views

SRv6 TE policy view

Default Level

2: Configuration level

Usage Guidelines

After an MTU is configured for an SRv6 TE Policy, if no path MTU is configured for the segment list referenced by the candidate path of the SRv6 TE Policy, the MTU of the SRv6 TE Policy is used as the path MTU of the segment list. The actual MTU of a forwarding path is the minimum MTU among the physical outbound interfaces of all devices on the path. In service planning, ensure that the MTU to be configured for an SRv6 TE Policy is not greater than the actual MTU of the forwarding path.

Example

# Configure an MTU for an SRv6 TE Policy.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] srv6-te policy p1 endpoint 2001:DB8:10::1 color 1
[HUAWEI-segment-routing-ipv6-policy-p1] mtu 2000
