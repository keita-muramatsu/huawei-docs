collect-item (WMI profile view)

Function

The collect-item command configures whether APs report collected data to a WMI server and specifies the data collection interval.

The undo collect-item command restores the default configuration for APs to report collected data to a WMI server and restores the default data collection interval.

The following table lists the default status and data collection interval for an AP to report data to the WMI server. The default values are recommended.

Format

collect-item application-statistics-data { interval app-interval | disable }

collect-item cpcar-data { interval cpcar-interval | disable }

collect-item device-data { interval device-interval | disable }

collect-item interface-data { interval interface-interval | disable }

collect-item log-data { interval log-interval | disable }

collect-item neighbor-device-data { interval neighbor-interval | disable }

collect-item radio-data { interval radio-interval | disable }

collect-item ssid-data { interval ssid-interval | disable }

collect-item terminal-data { interval terminal-interval | disable }

collect-item location-data { interval location-interval | enable }

collect-item dns-data { interval dns-interval | enable }

collect-item non-wifi-data { interval non-wifi-interval | enable }

collect-item terminal-dhcp-option-data { interval term-pk-interval | enable }

collect-item terminal-http-ua-data { interval term-pk-interval | enable }

collect-item terminal-mdns-data { interval term-pk-interval | enable }

collect-item { flow-learning | lldp-data } disable

collect-item { spectrum-data | csi-data } enable

collect-item ai-roam-data { disable | interval ai-roam-interval }

undo collect-item { application-statistics-data | cpcar-data | ssid-data | radio-data | device-data | dns-data | interface-data | log-data | neighbor-device-data | non-wifi-data | terminal-data | terminal-dhcp-option-data | terminal-http-ua-data | terminal-mdns-data | location-data }

undo collect-item { flow-learning | lldp-data } disable

undo collect-item { spectrum-data | csi-data } enable

undo collect-item ai-roam-data

The value is an integer that ranges from 5 to 1800, in seconds.

Specifies the interval for collecting radio data of neighboring wireless devices around an AP.

The value is an integer that ranges from 5 to 1800, in seconds.

Specifies the interval for collecting STA packets (including DHCP option, HTTP, and mDNS packets).

The value is an integer that ranges from 5 to 1800, in seconds.

The value is an integer that ranges from 5 to 1800, in seconds.

Usage Guidelines

Usage Scenario

You can run this command to configure APs to report collected data to a WMI server and set the data collection interval based on user requirements. You can run this command multiple times to configure APs to report different types of data to a WMI server.

Data Type Default Status Default Collection Interval (Unit: Second)
Site guest data Enabled 300
CPCAR data Enabled 300
Device monitoring data Enabled 10
Interface monitoring data Enabled 60
Log data Enabled 300
Neighboring device data Enabled 60
Radio monitoring data Enabled 10
SSID monitoring data Enabled 60
STA data Enabled 10

Service information in the mDNS packets sent by STAs Disabled 300
DNS information Disabled 60

GNSS location data Disabled 3600
AI roaming data Enabled 300

Precautions

For APs that can only transparently report collected information, the collection interval is fixed at 5 minutes, and is unconfigurable.

Example

# Set the interval for collecting device monitoring data to 500 seconds.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] wmi-server name abc
[HUAWEI-wlan-wmi-server-prof-abc] collect-item device-data interval 500
