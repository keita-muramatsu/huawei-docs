mac-address update arp enable

Function

The mac-address update arp enable command enables the MAC address-triggered ARP entry update function. That is, the device is enabled to update outbound interfaces in ARP entries when outbound interfaces in MAC address entries change.

The undo mac-address update arp enable command disables the MAC address-triggered ARP entry update function.

By default, the MAC address-triggered ARP entry update function is enabled.

Format

mac-address update arp enable

undo mac-address update arp enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

On an Ethernet network, MAC address entries are used to guide Layer 2 data forwarding, and ARP entries are used to guide communication between devices on different network segments based on the mappings between IP addresses and MAC addresses.

The outbound interface in a MAC address entry is updated by packets, whereas the outbound interface in an ARP entry is updated after the aging time expires. As a result, the outbound interfaces in MAC address entries may be different from those in ARP entries. That is, the outbound interfaces in MAC address entries are updated, but the outbound interfaces in ARP entries are not updated in time. To address this issue, you can enable the MAC address-triggered ARP entry update function to update the outbound interfaces in ARP entries when the outbound interfaces in MAC address entries are updated.

After MAC address-triggered ARP entry update is enabled, if the VM location changes and a MAC address entry on the gateway is updated upon receipt of Layer 2 user traffic:

  • If an ARP entry exists but the outbound interface in the MAC address entry is different from that in the ARP entry, the device updates the ARP entry and outbound interface information based on the MAC address entry, accelerating Layer 3 traffic convergence.
  • If no ARP entry exists, the device searches the broadcast suppression table based on the MAC address entry and initiates an ARP probe again to update the ARP entry and outbound interface information, accelerating Layer 3 traffic convergence.

Precautions

  • This command takes effect only for dynamic ARP entries. Static ARP entries are not updated when the corresponding MAC address entries change.
  • After the MAC address-triggered ARP entry update function is enabled, the device updates an ARP entry only if the outbound interface in the corresponding MAC address entry changes.
  • If MAC address flapping occurs more than 10 times, the device disables the MAC address-triggered ARP entry update function. After MAC address flapping is eliminated, the device automatically enables the MAC address-triggered ARP entry update function.

Example

# Enable the MAC address-triggered ARP entry update function.
<HUAWEI> system-view
[HUAWEI] mac-address update arp enable
