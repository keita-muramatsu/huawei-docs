apn-profile default-bearer

Function

The apn-profile default-bearer command configures the default APN for a wireless network.

The undo apn-profile default-bearer command deletes the default APN of a wireless network.

By default, no default APN is configured.

Format

apn-profile default-bearer apn-name [ user username password password authentication-mode { pap | chap } ] sim-id sim-id

undo apn-profile default-bearer sim-id sim-id

Parameters

Parameter Description Value
apn-name

Specifies an APN.

The value is a string of 1 to 99 case-sensitive characters, spaces not supported. The value can contain letters (a to z or A to Z), digits, dots (.), and hyphens (-), and must start and end with a letter or digit.
user username

Specifies the user name provided by a carrier for accessing an external PDN.

The value of symbolic-name is a string of 1 to 64 characters, and when quotation marks are used around the string, spaces are allowed in the string.
password password

Specifies the password provided by a carrier for accessing an external PDN.

The value is a string of 1 to 64 characters in plaintext or a string of 128 to 188 characters in ciphertext.
authentication-mode

Specifies the authentication mode.

-
pap

Specifies the PAP authentication mode.

-
chap

Specifies the CHAP authentication mode.

-
sim-id sim-id

Specifies the ID of the SIM card to which the APN profile is to be bound.

The value is 1 or 2.

Views

Cellular template view

Default Level

2: Configuration level

Usage Guidelines

For LTE networks, some carriers need to configure APNs that are different from those used by normal services to complete network attach. In dual-card single-standby scenarios, if the two SIM cards need to connect to different carriers' networks through different default APNs, you can run the apn-profile default-bearer sim-id command to bind different default APNs to the IDs of the SIM cards, so that the corresponding default APN is delivered to the modem during a SIM card switchover. If the default APN is configured and no APN profile is bound to a cellular interface, the cellular interface uses the default APN to establish a dial-up connection.

In normal service scenarios, you are advised to configure an APN profile instead of the default APN. This command is used only for special carrier networks.

You can run the undo apn-profile default-bearer sim-id command to delete the default APN configured for a wireless network.

Example

# Configure the default APN.
<HUAWEI> system-view
[HUAWEI] cellular-profile profileName
[HUAWEI-cellular-profile-profileName] apn-profile default-bearer apnName user huawei password YsHsjx_202206 authentication-mode chap sim-id 1
