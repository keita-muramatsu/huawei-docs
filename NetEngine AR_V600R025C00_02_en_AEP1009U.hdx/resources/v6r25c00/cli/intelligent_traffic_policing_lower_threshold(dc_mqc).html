service-lower-threshold

Function

The service-lower-threshold command configures the lower bandwidth threshold for low-priority services.

The undo service-lower-threshold command deletes the lower bandwidth threshold for low-priority services.

By default, the threshold in percentage is 10%.

Format

service-lower-threshold { bandwidth | pct percentage }

undo service-lower-threshold { bandwidth | pct percentage }

Parameters

Parameter Description Value
bandwidth

Specifies the minimum bandwidth for low-priority services.

The value is an integer that ranges from 1 to 10000000, in kbit/s.
pct percentage

Specifies the percentage of the minimum service bandwidth to the interface rate limit bandwidth.

The value is an integer ranging from 1 to 100.
service-lower-threshold

Specifies the bandwidth for low-priority services.

-

Views

itp view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The intelligent traffic policing algorithm is used to automatically suppress the bandwidth of low-priority services when network congestion occurs, ensuring the experience of high-priority services. When the bandwidth of low-priority services is suppressed, the bandwidth CIR is suppressed to the lower limit of the service bandwidth, and only the bandwidth within the lower bandwidth threshold is guaranteed for the traffic of low-priority services.

Prerequisites

You have entered the intelligent traffic policing view.

Implementation Procedure

In the intelligent traffic policing view, the lower bandwidth threshold for services is configurable. If the lower bandwidth threshold is not configured, 10% of the CIR of the statically configured Internet access bandwidth (CAR of the parent traffic policy for low-priority services) is used as the lower bandwidth threshold for low-priority services.

Precautions

If this parameter is not configured, the default value of this parameter is used by default when the intelligent traffic policing policy is applied. If this parameter is deleted when the intelligent traffic policing policy is applied to an interface, the default value of this parameter is restored, and the policy on the interface is executed again.

The value of this parameter is compared with the CIR of the CAR for low-priority services. The lower bandwidth threshold for services is set to the smaller value of the two values. If the parameter is set to a percentage, the corresponding value is calculated first and then used for comparison.

Example

# Set the lower bandwidth threshold for low-priority services to 10000 kbit/s for intelligent traffic policing.
<HUAWEI> system-view
[HUAWEI] itp policy p1
[HUAWEI-itp-p1] service-lower-threshold 10000
