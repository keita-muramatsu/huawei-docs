qos car outbound

Function

The qos car outbound command applies a QoS CAR profile to an interface in the outbound direction to police traffic on the interface.

The undo qos car outbound command unbinds a QoS CAR profile from an interface in the outbound direction.

By default, no QoS CAR profile is applied to an interface.

Format

qos car outbound car-name

undo qos car outbound

Parameters

Parameter Description Value
car-name

Specifies the name of a QoS CAR profile.

The value is a string of 1 to 31 case-sensitive characters, spaces not supported.

Views

10GE interface view, Cellular channel interface view, Dialer interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, GE interface view, IP-Trunk interface view, MP-group interface view, POS interface view, Tunnel interface view, Virtual serial interface view, Sub-interface view, Interface group view, Ethernet interface view, Ethernet sub-interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After a QoS CAR profile is created, you can run the qos car outbound command to apply the QoS CAR profile to an interface in the outbound direction to police traffic leaving the interface.

Prerequisites

A QoS CAR profile has been created using the qos car command.

Example

# Apply a QoS CAR profile named car1 to police traffic in the outbound direction of Tunnel1.
<HUAWEI> system-view
[HUAWEI] interface Tunnel1
[HUAWEI-Tunnel1] qos car outbound car1
