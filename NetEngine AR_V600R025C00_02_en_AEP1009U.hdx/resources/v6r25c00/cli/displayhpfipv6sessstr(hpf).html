display ipv6 session

Function

The display ipv6 session command displays information about the IPv6 session table.

Format

display ipv6 session all [ verbose ]

display ipv6 session destination destination-address [ destination-port ] [ verbose ]

display ipv6 session source source-address [ source-port ] [ destination destination-address [ destination-port ] ] [ verbose ]

display ipv6 session protocol { protocol-number | icmpv6 | tcp | udp } [ source source-address [ source-port ] ] [ destination destination-address [ destination-port ] ] [ verbose ]

Parameters

Parameter Description Value
verbose

Displays detailed information about session entries.

-
destination destination-address

Displays the session table with the specified destination IPv6 address.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
destination-port

Displays session entries with a specified destination port number.

The value is an integer from 1 to 65535.
source source-address

Displays the session table with the specified source IPv6 address.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
source source-port

Displays session entries with a specified source IP address and a source port number.

The value is an integer from 1 to 65535.
protocol protocol-number

Displays session entries with a specified protocol number.

The value is an integer ranging from 1 to 255.
icmpv6

Displays information about the session table with the protocol number being ICMPv6.

-
tcp

Displays information about the session table with the protocol number being TCP.

-
udp

Displays information about the session table with the protocol number being UDP.

-
all

Displays the information about all IPv6 session tables.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

You can run this command to view information about the IPv6 session table on the device.

Precautions

If the number of IPv6 sessions on the device is large, it takes a long time to print all session information. You are advised to filter the session information.
