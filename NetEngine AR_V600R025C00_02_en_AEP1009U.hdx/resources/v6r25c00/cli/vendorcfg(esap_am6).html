vendor-specific

Function

The vendor-specific command configures vendor-specific options for an IPv6 address pool and displays the vendor-specific view.

The undo vendor-specific command deletes the vendor-specific options configured for an IPv6 address pool.

By default, no vendor-specific option is configured.

Format

vendor-specific vendorId

undo vendor-specific vendorId

Parameters

Parameter Description Value
vendorId

Specifies the vendor ID, which is assigned by the IANA. The vendor ID of Huawei is 2011.

The value is an integer in the range from 1 to 4294967295.

Views

DHCP IPv6 address pool view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

This command is used on DHCP servers. You can use the vendor-specific command to enter the vendor-specific mode. In this mode, you can configure vendor-specific DHCPv6 options. The vendor-specific options can carry additional information. For example, in the DHCPv6 device automatic deployment scenario, the vendor-specific options can carry the TFTP server name, address, and configuration file name of the device.

Precautions

A maximum of eight vendor-specific options can be configured for an IPv6 address pool.

Example

# Configure Huawei-specific options for the IPv6 address pool pool1. 
<HUAWEI> system-view
[HUAWEI] dhcpv6 pool pool1
[HUAWEI-dhcpv6-pool-pool1] vendor-specific 2011
