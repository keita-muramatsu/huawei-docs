update force online

Function

The update force online command forcibly configures the immediate updates of the databases.

Format

Usage Guidelines

Usage Scenario

When you run the update online command to update the signature database immediately, the update fails if the system memory is insufficient. In this case, you can run the update force online command to forcibly update the signature database immediately. After the update force online command is run, the ASE engine does not take effect in a short period of time and all ASE-related session tables are reset. Therefore, exercise caution when running this command.

Example

# Forcibly update the SA signature database immediately.
<HUAWEI> system-view
[HUAWEI] update force online sa-sdb
