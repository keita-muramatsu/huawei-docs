netstream ip cache log log-directory

Function

The netstream ip cache log log-directory command configures a local path for storing NetStream logs.

The undo netstream ip cache log log-directory command cancels the configuration.

By default, no local path is configured for storing NetStream logs.

Format

netstream ip cache log log-directory log-directory

undo netstream ip cache log log-directory log-directory

Parameters

Parameter Description Value
log-directory log-directory

Specifies the local path for storing the NetStream flow table.

The value is a string of 1 to 32 case-sensitive characters. It cannot contain spaces.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

You can run this command to set the local path for storing NetStream IPv4 flow table logs.

Precautions

  1. The function of storing logs locally takes effect only when both the netstream ip cache log log-directory and netstream ip cache log enable commands are configured.
  2. Logs can be stored only in a USB flash drive path but not a flash path. Currently, only usb0 and usb1 are supported.
  3. The digit in the name of a NetStream log is in the range from 1 to 9999. That is, when the log name is netstreamdata9999.db, no new storage data file can be generated, logs cannot be updated, and storage logs will be lost.

Example

# Configure a local path for storing NetStream logs.
<HUAWEI> system-view
[HUAWEI] netstream ip cache log log-directory usb0:
