trap-threshold crc-statistics

Function

The trap-threshold crc-statistics command sets the alarm threshold for CRC error packets, interval for collecting statistics on CRC error packets, and number of CRC statistics alarm periods.

The undo trap-threshold crc-statistics command restores the default alarm threshold for CRC error packets, default interval for collecting statistics on CRC error packets, and default number of CRC statistics alarm periods.

By default, the alarm threshold for CRC error packets is 3, the interval for collecting statistics on CRC error packets is 10 seconds, and the number of CRC statistics alarm periods is 1.

Format

trap-threshold crc-statistics threshold-value interval interval-value [ repeat-time repeat-value ]

undo trap-threshold crc-statistics [ threshold-value interval interval-value [ repeat-time [ repeat-value ] ] ]

Parameters

Parameter Description Value
threshold-value

Specifies the alarm threshold for CRC error packets.

The value is an integer ranging from 1 to 65535.
interval interval-value

Specifies the interval for collecting statistics on CRC error packets.

The value is an integer ranging from 10 to 65535, in seconds.
repeat-time repeat-value

Specifies the number of CRC statistics alarm periods.

The value is an integer ranging from 1 to 10.

Views

Layer 2 10GE interface view, 10GE interface view, 25GE-L2 view, 25GE interface view, Layer 2 40GE interface view, 40GE interface view, GE optical interface view, GE electrical interface view, Layer 2 multi-GE interface view, Multi-GE interface view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The system generates a CRC error alarm when the following conditions are met:

  • When the alarm threshold for CRC error packets is smaller than 3, the interface receives CRC error packets in at least 1s multiplied by the specified threshold within the statistics collection interval. If the alarm threshold for CRC error packets is greater than or equal to 3, the interface receives CRC error packets in at least three 1s within the statistics collection interval.
  • The total number of CRC error packets received by the interface within the statistics collection interval is greater than the alarm threshold for CRC error packets.
  • The preceding two conditions are met in at least the interval multiplied by the number of consecutive CRC statistics alarm periods.

The system generates a CRC error clear alarm when the following condition is met:

  • The number of CRC error packets received by the interface within the statistics collection interval is 0.

Precautions

In scenarios where the alarm threshold for CRC error packets is configured using this command, if the port crc-statistics trigger error-down command is also configured, when a CRC error alarm is generated, the interface enters the Error-Down state and then the alarm is cleared.

Example

# Set the alarm threshold for CRC error packets on 10GE0/0/1 to 10 and the alarm interval to 30 seconds.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] trap-threshold crc-statistics 10 interval 30
