service (NAT policy rule view)

Function

The service command specifies a service in a NAT policy rule.

The undo service command removes a service from a NAT policy rule.

By default, no service is configured in a NAT policy rule.

Format

For AR8700 series, AR6700-H series:

service { service-name &<1-6> | any }

undo service { service-name &<1-6> | all }

For AR8100 series, AR8700 series, AR6700-H series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5700-H series, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR5710-S8TWDSE-LTE4EA, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S10T1X2, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S:

service any

undo service all

Parameters

Parameter Description Value
service-name

Specifies the name of a service or service group.

NOTE:

This parameter is supported only on the AR8700 series and AR6700-H series.

The value must be the name of an existing service or service group. A maximum of six services or service groups can be configured or removed at a time. The value is a string of 1 to 63 case-sensitive characters. If the name contains spaces, use double quotation marks ("") to enclose the name, for example, "user for test". The name cannot contain question marks (?), commas (,), or double quotation marks (").
any

Indicates any service to which a security policy rule applies.

-
all

Removes all services from the NAT policy rule.

-

Views

NAT policy rule view

Default Level

2: Configuration level

Usage Guidelines

Run the service command to specify a service in a NAT policy rule.

Example

# Specify a service named h323 in a NAT policy rule named abc. 
<HUAWEI> system-view
[HUAWEI] nat-policy
[HUAWEI-policy-nat] rule name abc
[HUAWEI-policy-nat-rule-abc] service h323
# Specify service any in a NAT policy rule named abc. 
<HUAWEI> system-view
[HUAWEI] nat-policy
[HUAWEI-policy-nat] rule name abc
[HUAWEI-policy-nat-rule-abc] service any
