hole-punching retry-times

Function

The hole-punching retry-times command sets the number of STUN hole punching retries and retry interval.

The undo hole-punching retry-times command restores the default number of STUN hole punching retries and retry interval.

By default, the number of STUN hole punching retries is 8 and the retry interval is 5 seconds.

Format

hole-punching retry-times count interval period

undo hole-punching retry-times [ count interval period ]

Parameters

Parameter Description Value
interval period

Specifies the STUN hole punching retry interval.

The value is an integer that ranges from 1 to 10, in seconds. The default value is 5.
retry-times count

Specifies the maximum number of STUN hole punching retries.

The value is an integer that ranges from 1 to 10. The default value is 8.

Views

STUN client view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

A data channel that supports NAT traversal is established between STUN clients. You can configure the number of hole punching retries and retry interval.

Precautions

For STUN hole punching between sites, the number of hole punching retries and retry interval must be the same at both ends. Otherwise, hole punching may fail, causing EVPN connection setup failures.

Example

# Set the number of STUN hole punching retries to 5 and the retry interval to 3 seconds.
<HUAWEI> system-view
[HUAWEI] stun client
[HUAWEI-stun-client] hole-punching retry-times 5 interval 3
