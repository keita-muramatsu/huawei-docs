reset stun statistics

Function

The reset stun statistics command clears STUN statistics.

Format

reset stun statistics

Parameters

None

Views

User view

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

To collect the STUN statistics within a specified period for STUN fault location, run the reset stun statistics command to clear historical statistics and then run the display stun statistics command to view STUN statistics.

Precautions

STUN statistics cannot be restored after you clear them. Therefore, exercise caution when you run this command.

Example

# Clear STUN statistics.
<HUAWEI> reset stun statistics
