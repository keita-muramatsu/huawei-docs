display nat-policy rule

Function

The display nat-policy rule command displays NAT policy rule configurations.

Format

display nat-policy rule [ verbose ] { source-zone { source-zone-name | any } | destination-zone { destination-zone-name | any } | { source { source-ipv4-address | source-ipv6-address | any } | destination { destination-ipv4-address | destination-ipv6-address | any } } | protocol { { tcp | udp } [ source-port source-port | destination-port destination-port ] * | icmp | protocol-number | any } } *

display nat-policy rule { all [ slot slot-id cpu cpu-id ] | name rule-name }

Parameters

Parameter Description Value
verbose

Indicates detailed information about a NAT policy rule.

-
source-zone source-zone-name

Specifies the source zone of a NAT policy rule.

The value is a string of 1 to 32 case-sensitive characters, spaces not supported. When quotation marks are used around the string, spaces are allowed in the string.
any

Indicates any source security zone, destination security zone, source address, destination address, or protocol in a NAT policy rule.

-
destination-zone destination-zone-name

Specifies the destination zone of a NAT policy rule.

The value is a string of 1 to 32 case-sensitive characters, spaces not supported. When quotation marks are used around the string, spaces are allowed in the string.
source source-ipv4-address

Specifies the source address configured in a NAT policy rule.

The value is in dotted decimal notation.
destination destination-ipv4-address

Specifies the destination address configured in a NAT policy rule.

The value is in dotted decimal notation.
protocol

Indicates a connection protocol.

-
tcp

Indicates the Transmission Control Protocol (TCP).

-
udp

Indicates the User Datagram Protocol (UDP).

-
source-port source-port

Specifies the source port configured in a NAT policy rule.

The value is an integer ranging from 0 to 65535.
destination-port destination-port

Specifies the destination port configured in a NAT policy rule.

The value is an integer ranging from 0 to 65535.
icmp

Indicates the Internet Control Message Protocol (ICMP).

-
protocol-number

Specifies an IP-layer protocol number, except 1-ICMP, 6-TCP, and 17-UDP.

The value is an integer ranging from 0 to 255.
all

Displays the configurations of all NAT policy rules.

-
slot-id

-

The value is an integer.
cpu-id

-

The value is an integer.
name rule-name

Displays the configurations of a specified NAT policy rule.

The value is a string of 1 to 63 case-sensitive characters without spaces. If spaces are used, the string must start and end with double quotation marks (").

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To check the NAT policy rule configurations, run the display nat-policy command.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the configurations of all NAT policy rules.
<HUAWEI> display nat-policy rule all
Total:3
RULE ID  RULE NAME        STATE     ACTION  HITS   
-----------------------------------------------------
1        test             disable   no-nat     0    
2        abc              enable    source-nat 5    
0        default          enable    no-nat     0    
----------------------------------------------------
# Display the configuration of a NAT policy rule named abc.
<HUAWEI> display nat-policy rule name abc
  (3 times matched)    
  rule name abc            
    source-zone trust      
    destination-zone trust   
    action source-nat address-group abc
# Display the configuration of the NAT policy rule with the source security zone being Trust.
<HUAWEI> display nat-policy rule source-zone trust
Total:3
RULE ID  RULE NAME                  STATE        ACTION       HITS   
-----------------------------------------------------------------------
1        test                       disable      no-nat          0    
2        abc                        enable       source-nat      5    
0        default                    enable       no-nat          0    
----------------------------------------------------------------------
Table 1 Description of the display nat-policy rule command output
Item Description
RULE ID

ID of the NAT policy rule.
RULE NAME

Name of a NAT policy rule.
STATE

NAT policy rule status:

  • enable.
  • disable.
ACTION

NAT policy rule action:

  • source-nat: indicates that source NAT is performed.
  • destination-nat: indicates that destination NAT is performed.
  • source-nat/destination-nat: indicates that both source NAT and destination NAT are performed.
  • no-nat: indicates that NAT is not performed.
HITS

Number of times traffic matches a NAT policy rule.
Total

Total number of NAT policy rules.
