poe power-on delay port

Function

The poe power-on delay port command sets the power supply delay for an interface on an RU.

The undo poe power-on delay port command restores the default power supply delay for an interface on an RU.

By default, the power supply delay for an interface on an RU is 0, which indicates no delay.

Format

poe power-on delay delay-time port port-id

undo poe power-on delay port port-id

Parameters

Parameter Description Value
delay-time

Specifies the power supply delay for an interface on an RU.

The value is an integer in the range from 1 to 60, in seconds. The default value is 0, indicating no delay.
port-id

Specifies the index of an interface on an RU.

The value is an integer ranging from 1 to 32.

Views

remote-unit N view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

The holding current of a non-standard PD is insufficient in the moment it is powered on. So, an RU assumes that the PD has been disconnected and powers it off.

To solve this problem, you can set the power supply delay for RU interfaces on the central device. When the delay expires, the RUs detect the holding current to ensure that non-standard PDs can be properly powered on.

Follow-up Procedure

After configuring an RU on the central device, you need to run the commit command to deliver the configuration to the RU or bring the RU online again for the configuration to take effect.

You can run the display remote-unit commit configuration command to check the configurations that are successfully delivered to RUs, and run the display remote-unit commit result command to check configuration delivery results of RUs.

Precautions

If a PD is connected to an interface configured with a power supply delay, do not replace the PD within the delay. Otherwise, the new PD cannot work properly.

Example

# Set the power supply delay of interface 1 on RU 0 to 5 seconds.
<HUAWEI> system-view
[HUAWEI] remote-unit 0
[HUAWEI-remote-unit-0] poe power-on delay 5 port 1
