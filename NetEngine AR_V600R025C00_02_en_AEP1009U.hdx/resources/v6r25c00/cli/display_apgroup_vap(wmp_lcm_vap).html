display vap

Function

The display vap command displays information about service VAPs.

Format

display vap { ap-group ap-group-name | ap-id ap-id [ radio radio-id ] } [ ssid ssid ]

display vap { all | ssid ssid }

Parameters

Parameter Description Value
ap-group ap-group-name

Displays information about all service VAPs in a specified AP group.

The value is a string of 1 to 35 case-sensitive characters, spaces supported.
ap-id ap-id

Displays information about service VAPs on the AP with a specified ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
radio radio-id

Displays information about service VAPs of a specified AP radio.

The value is an integer ranging from 0 to 4.
ssid ssid

Displays information about service VAPs of a specified SSID.

The value is a string of 1 to 32 characters. It can contain spaces.
all

Displays information about all service VAPs.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run this command to view information about service VAPs.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display information about all service VAPs.
<HUAWEI> display vap all
WID : WLAN ID
Total: 1
