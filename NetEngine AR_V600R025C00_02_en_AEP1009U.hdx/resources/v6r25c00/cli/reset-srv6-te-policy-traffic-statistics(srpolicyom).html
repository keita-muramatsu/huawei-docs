reset srv6-te policy traffic-statistics

Function

The reset srv6-te policy traffic-statistics command is used to clear the statistics of the SRv6 TE Policy traffic statistics.

Format

reset srv6-te policy traffic-statistics [ endpoint endpoint-ip color color-value | policy-name name-value | binding-sid binding-sid ]

Parameters

Parameter Description Value
endpoint endpoint-ip

Specifies the endpoint of an SRv6 TE Policy.

The value is a 32-digit hexadecimal string in format X:X:X:X:X:X:X:X.
color color-value

Specifies a color value for an SRv6 TE Policy.

The value is an integer ranging from 0 to 4294967295.
policy-name name-value

Specifies the name of an SRv6 TE Policy.

The value is a string of 1 to 255 case-sensitive characters. If the string is enclosed in double quotation marks ("), spaces are allowed in the string.
binding-sid binding-sid

Specifies a binding SID.

The value is a 32-digit hexadecimal string in format X:X:X:X:X:X:X:X.

Views

User view

Default Level

2: Configuration level

Usage Guidelines

reset srv6-te policy traffic-statistics used to clear the SRv6 TE Policy traffic statistics count in the user view.

Example

# Clear the traffic statistics information of the SRv6 TE Policy.
<HUAWEI> reset srv6-te policy traffic-statistics
