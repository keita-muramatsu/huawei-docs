md5-password

Function

The md5-password command sets the password used to establish a TCP connection when an LDP session is being established. The password must be the same as that on the peer.

The undo md5-password command restores the default configuration.

By default, MD5 authentication is not performed during the establishment of an LDP session.

Format

md5-password plain peer-lsr-id password-plain

md5-password cipher peer-lsr-id password-cipher

undo md5-password peer-lsr-id

Parameters

Parameter Description Value
peer-lsr-id

Specifies the LSR ID of a peer. The LSR ID is used to identify the peer LSR.

The value is in dotted decimal notation.
password-plain

Password character string.

Description.

  • The password must contain uppercase letters, lowercase letters, digits, and special characters.
  • To prevent high security risks, you are advised to select the ciphertext mode. To ensure device security, change the password periodically.

This parameter supports only the plaintext input mode. The value is a string of 1 to 255 characters. The character string cannot contain spaces by default, but can contain spaces if the string is enclosed by double quotation marks ("").
cipher

Displays the password in ciphertext.

-
password-cipher

Specifies an authentication password.

In plaintext input mode, the value is a string of 1 to 255 characters. In ciphertext input mode, the value is a string of 20 to 432 characters. The character string cannot contain spaces by default, but can contain spaces if the string is enclosed by double quotation marks ("").
plain

Displays the password in plaintext.

If you select the plaintext mode when configuring a password, the password is saved in plaintext in the configuration file. This mode has high security risk. The ciphertext mode is recommended. To improve device security, change the password periodically.

-

Views

MPLS-LDP view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

MD5 authentication can be configured for a TCP connection over which an LDP session is established, improving security. Note that the peers of an LDP session can be configured with different authentication modes (simple text or ciphertext mode), but must be configured with a single password.

LDP MD5 authentication generates a unique digest for an information segment to prevent LDP packets from being modified. LDP MD5 authentication is stricter than common checksum verification for TCP connections.

Prerequisites

MPLS LDP has been enabled globally using the mpls ldp command in the system view.

Precautions

  • MD5 authentication and keychain authentication are mutually exclusive with each other on a peer.
  • If the passwords on both ends of a session are the same, the session is not re-established. If the passwords are different, the session is disconnected due to timeout. As a result, the LSP is deleted. If the MD5 configuration needs to be modified, perform the modification on both ends. Failure to do so will cause the session to be reestablished when the session Keepalive timer expires.
  • As the MD5 algorithm is insecure, you are advised to use a more secure authentication mode.
  • This command can be used only after the weak security algorithm function is enabled. If the weak security algorithm function has been disabled, an error message will be displayed when you configure a weak security algorithm. You can run the install feature-software WEAKEA command to enable the weak security algorithm function.

Example

# Configure the local node to perform MD5 authentication when it establishes an LDP session with its peer.
<HUAWEI> system-view
[HUAWEI] mpls
[HUAWEI-mpls] quit
[HUAWEI] mpls ldp
[HUAWEI-mpls-ldp] md5-password cipher 2.2.2.2 YsHsjx_202206
