ssh server-source -a

Function

The ssh server-source -a command specifies a source IPv4 address for an SSH server.

The undo ssh server-source -a command cancels the configuration.

By default, no source IPv4 address is specified for an SSH server.

Format

ssh server-source -a ip-address [ -vpn-instance vpnName ]

undo ssh server-source -a ip-address [ -vpn-instance vpnName ]

Parameters

Parameter Description Value
-vpn-instance vpnName

Specifies a VPN instance for listening to the source IPv4 address of the SSH server.

The value is a string of 1 to 31 case-sensitive characters without spaces. The VPN instance name cannot be _public_. If the character string is quoted by double quotation marks, the character string can contain spaces.
-a ip-address

Specifies the source IPv4 address of an SSH server.

The value is in dotted decimal notation.

Views

System view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

To improve system security, an SSH server does not receive login requests from any interface by default. To authorize users to log in to the SSH server, run the ssh server-source -a command to specify the source IPv4 address of the SSH server.

Prerequisites

Before specifying a VPN instance for an SSH server, ensure that the VPN instance has been created. Otherwise, the command cannot be executed.

Configuration Impact

After a source IPv4 address is specified for an SSH server, the system allows SFTP, STelnet, SCP, and SNETCONF users to log in to the SSH server only using the specified source IPv4 address, and denies access of SFTP, STelnet, SCP, and SNETCONF users using other addresses. SFTP, STelnet, SCP, and SNETCONF users who have logged in to the server are not affected. Only SFTP, STelnet, SCP, and SNETCONF users who log in to the server after the configuration are restricted.

Precautions

  • After a source IPv4 address is specified for an SSH server, to ensure that authorized SFTP, STelnet, SCP, and SNETCONF users can successfully log in to the SSH server, ensure that the SFTP, STelnet, SCP, and SNETCONF users can ping the specified source IPv4 address.
  • The configuration takes effect upon the next login. You can determine whether to continue the operation as prompted.
  • If a source IPv4 address is bound to a VPN instance, the VPN instance cannot be deleted. The VPN instance can be deleted only after the source IPv4 address is deleted.
  • A maximum of five source IPv4 addresses can be specified using the ssh server-source -a command.

Example

# Configure a source IPv4 address for the SSH server.
<HUAWEI> system-view
[HUAWEI] ssh server-source -a 10.1.1.1
Warning: SSH server source configuration will take effect in the next login. Continue? [Y/N]:Y
[HUAWEI]
