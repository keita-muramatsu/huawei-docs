service protocol (Security policy rule view)

Function

The service protocol command references the TCP/UDP/SCTP port or Internet-layer protocols in the security policy.

The undo service protocol command cancels the reference of the TCP/UDP/SCTP port or protocol in the security policy.

By default, this function is not configured.

Format

service protocol protocol-number

service protocol icmpv6 [ icmpv6-type { icmpv6-name | icmpv6-type-number { icmpv6-code-number [ to icmpv6-code-number ] } &<1-64> } ]

service protocol icmp [ icmp-type { icmp-name | icmp-type-number { icmp-code-number [ to icmp-code-number ] } &<1-64> } ]

service protocol sctp

service protocol { udp | tcp } [ source-port { source-port | start-source-port to end-source-port } &<1-64> | destination-port { destination-port | start-destination-port to end-destination-port } &<1-64> ] *

undo service protocol protocol-number

undo service protocol icmpv6 [ icmpv6-type { icmpv6-name | icmpv6-type-number { icmpv6-code-number [ to icmpv6-code-number ] } &<1-64> } ]

undo service protocol icmp [ icmp-type { icmp-name | icmp-type-number { icmp-code-number [ to icmp-code-number ] } &<1-64> } ]

undo service protocol sctp

undo service protocol { udp | tcp } [ source-port { source-port | start-source-port to end-source-port } &<1-64> | destination-port { destination-port | start-destination-port to end-destination-port } &<1-64> ] *

Parameters

Parameter Description Value
protocol-number

Specifies the IP-layer protocol number.

The value is an integer ranging from 0 to 255.
icmpv6

Indicates ICMPv6.

-
icmpv6-type

Indicates the ICMPv6 packet type and message code.

-
icmpv6-name

Specifies the ICMPv6 packet type name.

The value is a string of 1 to 32 case-sensitive characters. It cannot contain spaces.
icmpv6-type-number

Specifies the ICMPv6 packet type number.

The value is an integer ranging from 0 to 255.
icmpv6-code-number

Specifies the ICMPv6 packet message code.

The value is an integer ranging from 0 to 255.
icmp

Indicates ICMP.

-
icmp-type

Indicates the ICMP packet type and message code.

-
icmp-name

Specifies the ICMP packet type name.

The value is a string of 1 to 32 case-sensitive characters. It cannot contain spaces.
icmp-type-number

Specifies the ICMP packet type number.

The value is an integer ranging from 0 to 255.
icmp-code-number

Specifies the ICMP packet type number.

The value is an integer ranging from 0 to 255.
udp

Indicates UDP.

-
tcp

Indicates TCP.

-
sctp

Indicates SCTP.

-
source-port source-port

Specifies a source port.

The value is an integer ranging from 0 to 65535.
start-source-port

Specifies the start source port or source port range.

The value is an integer ranging from 0 to 65535.
end-source-port

Specifies the end source port or source port range.

The value is an integer ranging from 0 to 65535.
destination-port destination-port

Indicates the destination port.

The value is an integer ranging from 0 to 65535. A maximum number of 64 destination ports or destination port segments can be added to or deleted from a security policy rule at a time.
start-destination-port

Specifies a start destination port number.

The value is an integer ranging from 0 to 65535.
end-destination-port

Specifies the destination port or destination port range.

The value is an integer ranging from 0 to 65535.

Views

Security policy rule view

Default Level

2: Configuration level

Usage Guidelines

If there are not many ports, you can run the service protocol command to reference the port or protocol directly in the security policy.

Example

# Reference UDP source port 1024 in the security policy as the policy matching condition. 
<HUAWEI> system-view
[HUAWEI] security-policy
[HUAWEI-policy-security] rule name policy_sec
[HUAWEI-policy-security-rule-policy_sec] service protocol udp source-port 1024
# Reference ICMP packet type host-redirect in the security policy. host-redirect packet type number is 5 and message code 1. 
<HUAWEI> system-view
[HUAWEI] security-policy
[HUAWEI-policy-security] rule name policy_sec
[HUAWEI-policy-security-rule-policy_sec] service protocol icmp icmp-type 5 1
