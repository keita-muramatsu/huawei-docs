auto-link aggregation (Interface view)

Function

The auto-link aggregation command indicates that an Eth-Trunk interface is generated through auto-negotiation.

By default, the direction control function does not exist.

Format

auto-link aggregation

undo auto-link aggregation

Parameters

None

Views

Eth-Trunk interface view, Layer 2 Eth-Trunk interface view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

Eth-Trunk uses link aggregation technology to bundle multiple independent physical interfaces into a logical interface, increasing link bandwidth. The physical links back up each other. If an active link fails, traffic is switched to another available member link, improving link reliability.

The auto-link aggregation command indicates that an Eth-Trunk interface is generated through auto-negotiation and is not manually configured.

Prerequisites

This command cannot be directly configured on a device. The command configuration is automatically generated in the interface view only when interface negotiation succeeds after the auto-link aggregation open command is run in the system view.

Example

# Enable Eth-Trunk auto-negotiation.
<HUAWEI> system-view
[HUAWEI] auto-link aggregation  open
[HUAWEI] interface Eth-Trunk 1
[HUAWEI-Eth-Trunk1] display this
#
interface Eth-Trunk1
 mode lacp-static
 lacp mixed-rate link enable
 auto-link aggregation
#
return
