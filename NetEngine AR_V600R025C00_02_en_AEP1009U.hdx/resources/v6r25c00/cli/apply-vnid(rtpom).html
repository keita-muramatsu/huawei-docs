apply vn-id

Function

The apply vn-id command sets a VN-ID for EVPN routes.

The undo apply vn-id command cancels the configuration.

By default, the VN-ID set using the vn-id command is used as the VN-ID of EVPN routes.

Format

apply vn-id vn-id

undo apply vn-id [ vn-id ]

Parameters

Parameter Description Value
vn-id

Specifies a VN-ID for EVPN routes.

The value is an integer ranging from 1 to 16777215.

Views

Route-policy view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The apply vn-id command applies to scenarios where an SD-WAN tunnel needs to be established, a Hub-PE and Hub-CE are deployed, and the Hub-CE is used to provide the firewall function. In this case, some traffic needs to be diverted to the Hub-CE after reaching the Hub-PE. To meet this requirement, mutual route import between VPN instances needs to be implemented. Specifically, two VPN instances named VPN-OUT and VPN-IN are planned on the Hub-PE. VPN-IN is created on CPE1 and the Hub-PE, and VPN-OUT is created on the Hub-PE and CPE2. Since the VPN instances have different VN-IDs, you need to run the apply vn-id command on the RR to change the VN-ID of the EVPN routes that the RR reflects to the Hub-PE to be the same as the VN-ID of VPN-OUT to ensure cross-VPN interworking. In this way, traffic can be routed through the Hub-CE.

To cancel the VN-ID specified in a route-policy, run the undo apply vn-id command. However, the VN-ID that has been set for EVPN routes before this configuration is performed will not be canceled.

Precautions

The apply vn-id command takes effect only in BGP-EVPN export and import policies as well as BGP-VPN import and export policies.

Example

# Define an apply clause with the VN-ID set to 100.
<HUAWEI> system-view
[HUAWEI] route-policy ma1 permit node 1
[HUAWEI-route-policy] apply vn-id 100
