display bgp sr-policy ipv6 update-peer-group

Function

The display bgp sr-policy ipv6 update-peer-group command displays information about update peer-groups.

Format

display bgp sr-policy ipv6 update-peer-group [ index index-value ]

Parameters

Parameter Description Value
index index-value

Specifies the index value of an update peer-group for displaying details about the update peer-group.

The value is an integer ranging from 0 to 65535.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

The display bgp sr-policy ipv6 update-peer-group command displays information about BGP update peer-groups or displays detailed information about a BGP update peer-group with a specified index.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display information about a BGP update peer-group in the BGP IPv6 SR-Policy address family.
<HUAWEI> display bgp sr-policy ipv6 update-peer-group

  The IPv6 Sr-Policy instance's update peer group number : 1
  Keep buffer update peer group number : 0
  BGP Version : 4

  Group ID : 1
  Group Type : internal
  Addr Family : IPv6-SR-POLICY
  AdvMinTimeVal : 15
  Total Peers : 1
  Leader Peer : 2001:DB8:1::1
  Peers List : 2001:DB8:1::1
# Display information about a BGP update peer-group with a specified index in the BGP IPv6 SR-Policy address family.
<HUAWEI> display bgp sr-policy ipv6 update-peer-group index 1

  The IPv6 Sr-Policy instance's update peer group number : 1
  Keep buffer update peer group number : 0
  BGP Version : 4
