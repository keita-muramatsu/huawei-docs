ipv6 address auto global

Function

The ipv6 address auto global command enables a device to generate a global IPv6 address through stateless autoconfiguration.

The undo ipv6 address auto global command disables a device from generating a global IPv6 address through stateless autoconfiguration.

The ipv6 address auto global default command enables a device to use the source IPv6 address in an RA message as the next hop address of a default route.

The undo ipv6 address auto global default command disables a device from using the source IPv6 address in an RA message as the next hop address of a default route.

By default, a device does not generate a global IPv6 address through stateless autoconfiguration or use the source IPv6 address in an RA message as the next hop address of a default route.

Format

ipv6 address auto global [ local-identifier ] [ default ]

undo ipv6 address auto global [ local-identifier ] [ default ]

Parameters

Parameter Description Value
local-identifier

Indicates that the interface identifier of the link-local address is used to generate the global address.

-
default

Indicates that the default route is learned.

-

Views

10GE sub-interface view, 10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE sub-interface view, 40GE interface view, Dialer interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, Ethernet sub-interface view, Ethernet interface view, GE optical interface view, GE sub-interface view, GE electrical interface view, IP-Trunk interface view, Multi-GE sub-interface view, Multi-GE interface view, POS interface view, VLANIF interface view, Serial interface view, Management interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After the ipv6 address auto global command is run, the device automatically generates an IPv6 global unicast address on the interface that receives an RA message. The generated IPv6 address contains the prefix of the RA message and the interface identifier of the device. If a device does not receive RA messages, the device can only automatically configure a link-local address to communicate with local nodes.

  • If local-identifier is not specified, the device uses EUI-64 to generate an interface identifier. The interface identifier and the prefix of an RA message form a global address.
  • If local-identifier is specified, the interface identifier of the link-local address and the prefix of an RA message form a global address.

A link-local address can also be manually configured or dynamically generated. If the global address is dynamically generated, the EUI-64 generation mode is also used. In this case, the result is the same regardless of whether the local-identifier parameter is configured. If the global address is manually configured, the interface identifier of the global address is obtained from the link-local address configuration, which is different from the result when the local-identifier parameter is not configured. You can plan the IP address as required.

After the ipv6 address auto global default command is run, the device generates an IPv6 address after receiving an RA message, learns the source IPv6 address in the RA message, and uses the source IPv6 address as the next hop address of the default IPv6 route.

Prerequisites

The IPv6 function has been enabled on the interface using the ipv6 enable command in the interface view.

Precautions

After the ipv6 address auto global command is run, if an interface has been configured with an IPv6 address, the interface automatically generates a new IPv6 address after receiving an RA message. The original IPv6 address is not deleted. If the interface stops sending RA messages and the validity period of the automatically generated IPv6 address expires, the automatically generated IPv6 address is deleted and the interface uses the original IPv6 address.

A maximum of three default routes can be learned from RA messages and cannot be overwritten. Extra default routes will be discarded. If multiple default routes have the same priority, messages are forwarded through the default routes in load balancing mode.

Example

# Enable 10GE0/0/1 to generate a global IPv6 address through stateless autoconfiguration.
<HUAWEI> system-view
[HUAWEI] interface 10GE0/0/1
[HUAWEI-10GE0/0/1] undo portswitch
[HUAWEI-10GE0/0/1] ipv6 enable
[HUAWEI-10GE0/0/1] ipv6 address auto global local-identifier
