dpd version (IKE peer view)

Function

The dpd version command configures the version of DPD packets sent by the local end to a specific IKE peer when SM digital envelope authentication is used during IKEv1 negotiation.

The undo dpd version command restores the default version of DPD packets.

By default, the version of DPD packets is not specified for an IKE peer.

Format

dpd version { 1.0 | 1.1 }

undo dpd version

Parameters

Parameter Description Value
1.0

Sets the version of DPD packets to 1.0.

-
1.1

Sets the version of DPD packets to 1.1.

-

Views

IKE peer view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

This command takes effect only when SM digital envelope authentication is used during IKEv1 negotiation. Both ends of an IPsec tunnel must send DPD packets of the same version. If not, they cannot identify the DPD packets sent by each other.

Precautions

  • By default, the device does not support this command, that is, SA negotiation through IKEv1 is not supported. To use this command, install the IKEv1 feature package.
  • If the dpd version command is configured for an IKE peer, the local end sends DPD packets of the version specified in this command to that peer. If only the ike dpd version command is configured globally, the local end sends DPD packets of the version specified in that command.
  • If the peer end is the initiator, the version of DPD packets used by the peer end has a higher priority than that of the local end. In this way, the local end sends DPD packets of the same version as those received from the peer end.

Example

# Set the version of DPD packets to 1.1 for an IKE peer. 
<HUAWEI> system-view
[HUAWEI] ike peer huawei
[HUAWEI-ike-peer-huawei] dpd version 1.1
