learn-client-address conflict-uncheck

Function

The learn-client-address conflict-uncheck command disables STA address conflict check.

The undo learn-client-address conflict-uncheck command enables STA address conflict check.

By default, STA address conflict check is enabled.

Format

learn-client-address { ipv4 | ipv6 } conflict-uncheck

undo learn-client-address { ipv4 | ipv6 } conflict-uncheck

Parameters

Parameter Description Value
ipv4

Configures STA IPv4 address conflict check.

-
ipv6

Configures STA IPv6 address conflict check.

-

Views

VAP profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

IP address conflicts on a network will cause frequent route flapping, affecting user services. Therefore, it is recommended that the STA address conflict check function be enabled in most cases to prevent STA IP address conflicts. In headquarters-branch scenarios, each branch has independent private addresses planned. Different branches may have the same or overlapped IP address segment. To prevent STAs' failures to go online due to IP address conflicts, disable the STA address conflict check function in the VAP profile.

Prerequisites

STA IP address learning has been enabled using the undo learn-client-address { ipv4 | ipv6 } disable command before you want to disable the STA address conflict check function.

Precautions

Disabling STA address conflict check takes effect only in direct forwarding scenarios.

When an authentication profile is bound to a VAP profile, to configure the same or overlapping IP network segment for different branches, run the authentication no-ip-check command in the authentication profile view and thelearn-client-address conflict-uncheck command in the VAP profile to disable STA address conflict check.

Example

# Disable STA IPv4 address conflict check in the VAP profile vap1.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] vap-profile name vap1
[HUAWEI-wlan-vap-prof-vap1] learn-client-address ipv4 conflict-uncheck
