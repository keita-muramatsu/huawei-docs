management-server

Function

The management-server command configures a host computer.

The undo management-server command deletes the host computer configuration.

By default, no host computer is configured.

Format

management-server { domain domain-name | server-ip server-ip } server-port server-port [ ext-channel ]

undo management-server { domain domain-name | server-ip server-ip } [ server-port server-port ]

undo management-server ext-channel

Parameters

Parameter Description Value
domain domain-name

Specifies the domain name of a host computer.

The value is a string of 1 to 63 case-insensitive characters without spaces. The value contains letters, digits, underscores (_), and dots (.).
server-ip server-ip

Specifies the IP address of a host computer.

The value is in dotted decimal notation.
server-port server-port

Specifies the port number of a host computer.

The value is an integer ranging from 1 to 65535.
ext-channel

Specifies an extension channel.

-

Views

iot-profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

An AP functions as a server or client to communicate with a host computer in bidirectional mode. When the AP reports data (transparently transmitted by Huawei APs to the host computer, and is not parsed or collected) to the host computer, the AP functions as a client and the host computer functions as a server. When the AP receives data from the host computer, the AP functions as a server and the host computer functions as a client. You must configure the domain name or IP address and the port number of at least one host computer. Otherwise, data reported by APs will be discarded.

Precautions

  • You can configure multiple host computers. You can configure a maximum of four host computers for a card of the common type. If four host computers have been configured, you must delete a host computer so that you can add a new host computer. You can configure only one host computer for a card of the cas-edu type.
  • When multiple host computers are configured, the device automatically selects one available host computer for link establishment but does not establish links with multiple host computers.
  • After the card type is set to container by using the card connect-type container command, the system delivers host computer address information to the container for the address to take effect. When multiple host computers are configured, the container uses only the first host computer address for communication.

Example

# Configure the IP address and port number of a host computer.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] iot-profile name profile1
[HUAWEI-wlan-iot-prof-profile1] management-server server-ip 10.1.1.2 server-port 3000
