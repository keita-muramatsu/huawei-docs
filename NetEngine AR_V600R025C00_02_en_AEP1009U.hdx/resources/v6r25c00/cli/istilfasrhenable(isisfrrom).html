ti-lfa (IS-IS IPv6 FRR view)

Function

The ti-lfa command enables IPv6 IS-IS topology independent-loop free alternate (TI-LFA).

The undo ti-lfa command disables IPv6 IS-IS TI-LFA.

By default, IPv6 IS-IS TI-LFA is disabled.

Format

ti-lfa [ level-1 | level-2 | level-1-2 ]

undo ti-lfa [ level-1 | level-2 | level-1-2 ]

Parameters

Parameter Description Value
level-1

Enables or disables IPv6 IS-IS Level-1 TI-LFA.

-
level-2

Enables or disables IPv6 IS-IS Level-2 TI-LFA.

-
level-1-2

Enables or disables IPv6 IS-IS Level-1-2 TI-LFA.

If no level is specified, IS-IS Level-1-2 TI-LFA is enabled by default.

-

Views

IS-IS IPv6 FRR view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In some LFA or remote LFA scenarios, the P space and Q space neither intersect nor have directly connected neighbors. If a link or node fails, no backup path can be computed, causing traffic loss and failing to meet reliability requirements.

To meet the reliability requirements of network services, you can configure TI-LFA to pre-compute a backup link. If a fault occurs, traffic can be quickly switched to the backup link before route convergence in the control plane. The TI-LFA algorithm is used for backup link computation through the following process: By excluding the primary next hop or primary link, this algorithm re-computes a post-convergence Shortest Path Tree (SPT) (also called a post-convergence tree) and then elects P and Q nodes along the tree. Based on the P and Q node information (for details, see the IPv6 TI-LFA FRR description), a backup tunnel label stack is formed. Traffic is forwarded to the Q node through the tunnel. After receiving the traffic, the Q node re-searches the SRv6 label forwarding table according to the labels in the packet header in order to further forward the traffic.

Prerequisites

Segment Routing IPv6 forwarding has been enabled using the segment-routing ipv6 command.

FRR has been enabled and the IPv6 FRR view has been displayed using the ipv6 frr command, and IPv6 IS-IS LFA has been enabled using the loop-free-alternate command.

Precautions

The level specified in the ti-lfa command depends on the level configured in the loop-free-alternate command. TI-LFA configured using the ti-lfa command can take effect in a level-specific IS-IS area only after the level-specific LFA is enabled.

Example

# Enable IPv6 IS-IS Level-2 TI-LFA.
<HUAWEI> system-view
[HUAWEI] isis 1
[HUAWEI-isis-1] ipv6 enable
[HUAWEI-isis-1] cost-style wide
[HUAWEI-isis-1] ipv6 frr
[HUAWEI-isis-1-ipv6-frr] loop-free-alternate level-2
[HUAWEI-isis-1-ipv6-frr] ti-lfa level-2
