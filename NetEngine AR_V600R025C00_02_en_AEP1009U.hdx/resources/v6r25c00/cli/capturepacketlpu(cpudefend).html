capture-packet interface

Function

The capture-packet interface command configures an instance for obtaining hardware-forwarded packets.

The undo capture-packet command deletes an instance for obtaining hardware-forwarded packets.

By default, no instance for obtaining hardware-forwarded packets is configured.

capture-index

Deletes the packet capture instance with a specified index.

The value is an integer ranging from 1 to 8.

User view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

If an exception occurs in the hardware-forwarded traffic on the device, for example, the traffic status does not match the traffic model, you are advised to configure the device to obtain hardware-forwarded packets and then analyze the packets, so as to handle the unauthorized packets in a timely manner and ensure normal transmission of network data.

When configuring packet capture, set parameters based on the traffic volume on the target interface. If a large number of packets are forwarded on the interface, set the timeout period to a small value and the number of packets to obtain to a large value. If a small number of packets are forwarded on the interface, set the timeout period to a large value and the number of packets to obtain to a small value.

Precautions

  • Only the AR5710-H and AR6710-L8 support this command. After the command is delivered to other devices, the devices do not switch to the hardware forwarding mode.
  • The function of obtaining hardware-forwarded packets may affect device performance. Exercise caution when configuring this function.
  • Parameters such as time (timeout period) and number (number of packets to obtain) can be set for a packet obtaining instance. Packet obtaining ends when any of the conditions is met.
  • If the file for storing obtained packets is deleted during packet obtaining, contents of subsequent packets cannot be written into the file.
  • When the IPv4 ACL-based packet capture function is configured, the fragment flag cannot be matched.
  • When obtaining packets based on ACLs, ensure that ACL resources are sufficient. If ACLs fail to be applied, packets cannot be obtained in either the inbound or outbound direction.

Example

# Obtain packets on 10GE0/0/1 matching ACL 2000 and save obtained packet information in the capture.cap file.
[HUAWEI] acl 2000
[HUAWEI-acl4-basic-2000] rule permit
[HUAWEI-acl4-basic-2000] quit
[HUAWEI] quit
<HUAWEI> capture-packet interface 10GE 0/0/1 acl 2000 destination file capture.cap
