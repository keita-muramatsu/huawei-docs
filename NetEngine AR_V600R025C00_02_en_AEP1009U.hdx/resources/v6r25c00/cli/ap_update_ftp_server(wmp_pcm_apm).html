ap update ftp-server

Function

The ap update ftp-server command configures basic FTP information, including the FTP server IP address, FTP server user name and password.

The undo ap update ftp-server command restores default FTP settings.

By default, basic FTP information is not configured.

Format

ap update ftp-server ip-address server-ip-address [ port port ] ftp-username ftp-username ftp-password cipher ftp-password

ap update ftp-server ipv6-address server-ipv6-address [ port port ] ftp-username ftp-username ftp-password cipher ftp-password

undo ap update ftp-server ip-address

undo ap update ftp-server ipv6-address

Parameters

Parameter Description Value
port port

Specifies a port number for the FTP server.

If no port number is specified, the default port 21 is used.

The value is an integer ranging from 1 to 65535.
ftp-username ftp-username

Specifies the user name for logging in to the FTP server.

The value is a string of 1 to 31 characters. It cannot contain question marks (?) and cannot start or end with double quotation marks (" ") or spaces.
ftp-password

Specifies the password for logging in to the FTP server.

-
ftp-password

Specifies the password for the FTP server.

To ensure device security, change the password periodically.

The value can also be a string of 1 to 128 characters in plaintext, such as YsHsjx_202206.
cipher

Specifies the password in ciphertext.

-
ipv6-address server-ipv6-address

Specifies an IPv6 address for the FTP server.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
ip-address server-ip-address

Specifies an IPv4 address for the FTP server.

The value is in dotted decimal notation.

Views

WLAN view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

  • This configuration is required when FTP is used for the automatic or online upgrade. In the automatic or online upgrade mode, the WAC sends basic FTP information to APs, which then request the FTP server for upgrade based on FTP information.
  • After running this command, you can perform the following operations:
  1. Run the ap update mode command to set the upgrade mode to ftp-mode.
  2. Run the ap update multi-load command to upgrade APs in batches.
  • Both IPv4 and IPv6 FTP servers are supported, and at most one FTP server can be configured for each IP version.

Precautions

  • It is recommended that you use an external FTP server to upgrade APs. If the WAC functions as the FTP server, a maximum of 21 APs can be upgraded simultaneously. If there are n login VTY users, the maximum number of APs that can be upgraded simultaneously is subtracted by n – 1.

  • APs do not support double quotation marks ("). Ensure that the FTP server user name and unencrypted password configured on the WAC do not contain the preceding characters. Otherwise, the FTP upgrade fails.

  • When the FTP port number is specified, the upgrade is applicable only to APs running V200R020C10 or later. For APs running earlier versions, the FTP upgrade fails.

  • The FTP server must support the REST field. Otherwise, the upgrade will fail. If the following information is displayed, the upgrade fails because the server does not support the REST field. In this case, replace the server.

    Error: Upgrade failed because the FTP server does not support the REST command.

SFTP is recommended because it is more secure than FTP.

Example

# Set the IPv6 address, user name, and password of the FTP server.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap update ftp-server ipv6-address 2001:db8::1 ftp-username admin ftp-password cipher YsHsjx_202206
