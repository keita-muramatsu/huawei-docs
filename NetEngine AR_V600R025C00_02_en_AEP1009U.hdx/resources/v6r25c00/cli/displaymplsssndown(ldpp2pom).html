display mpls ldp event session-down

Function

The display mpls ldp event session-down command displays the time and reason when an LDP session went Down.

Format

display mpls ldp event session-down [ peer-id ]

display mpls ldp event session-down [ peer-id ] verbose

Parameters

Parameter Description Value
peer-id

Specifies the peer ID. If this parameter is specified, information about a specified peer is displayed.

The value is in dotted decimal notation.
verbose

Displays detailed information about LDP session down.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

The display mpls ldp event session-down command displays the time and reason when an LDP session went Down.

Table 1 Description of the display mpls ldp event session-down command output
Item Description
Down Date

Date when the LDP session went Down, in the format of YYYY-MM-DD.
Down Time

Time when the LDP session went Down, in the format of HH:MM:SS.
PeerID

Peer address.
IpFamily

IP address family information.
Socket ID

TCP socket ID.
Socket Flow Ctrl State

Socket flow control status:

  • TRUE: The socket is in the flow control state.
  • FALSE: The socket is not in the flow control state.
Peer Transport Address

Peer transport address used to establish the LDP session.
Local Transport Address

Local transport address used to establish the LDP session.
Flag

Session ID:

  • R: remote peer.
  • L: local peer (local session).
  • B: Both of local and remote peer, local and remote coexistence session.
  • G: Graceful Restart Session.
Reason

Reason for the session going down:

  • Hello hold timer expire: The LDP Hello hold timer expires.
  • Keepalive timer expire: The LDP Keepalive timer expires.
  • Reset MPLS LDP: The reset mpls ldp command is run.
  • Undo MPLS LDP: MPLS LDP is disabled.
  • Undo MPLS LDP remote peer: The remote LDP peer is deleted.
  • Config GR: LDP GR is configured.
  • Modify keepalive timer: The Keepalive timer of the session is modified.
  • Config transport address: The transport address of the session is changed.
  • Modify MPLS LDP LSR-ID: The LSR ID of the session is modified.
  • Receive notification: A Notification message is received.
  • Session role changed: The session role changes.
  • Error message was received from a peer: An error notification message is received from the neighbor.
  • Socket error was received: Socket error information is received.
  • IGP delete the RLFA IID: The IGP deletes the RLFA IID.
  • Cannot send or receive LDP packets successfully: LDP packets fail to be sent or received.
  • Cannot set the socket option for LDP successfully: LDP fails to set the socket option.
  • LDP received a socket close message: LDP receives a socket close message.
  • Ti-lfa remote peer disable: The configuration for automatically establishing a remote session in the TI-LFA scenario where PQ nodes overlap is modified.
  • Other: Others.
Sub Reason

Sub-reason for the session Down event:

When the value of Reason is Receive notification, a specific value is displayed. The options are as follows:

  • Bad LDP Identifier.
  • Bad Protocol Version.
  • Bad PDU Length.
  • Bad Message Length.
  • Bad TLV Length.
  • Malformed TLV Value.
  • Hold Timer Expired.
  • Shutdown.
  • Session Rejected/No Hello.
  • Session Rejected/Parameters Advertisement Mode.
  • Session Rejected/Parameters Max PDU Length.
  • Session Rejected/Parameters Label Range.
  • KeepAlive Timer Expired.
  • Session Rejected/Bad KeepAlive Time.
  • Internal Error.
  • IGP delete the RLFA IID.

When Reason is set to Cannot send or receive LDP packets successfully, a specific value is displayed. The options are as follows:

  • Stacked numerous LDP packets to be processed.
  • Cannot receive packets successfully.
  • Cannot send packets successfully.

When Reason is set to Cannot set the socket option for LDP successfully or LDP received a socket close message, the specific error code is displayed.

For other Reason values, "-" is displayed.
Duration Time

Time elapsed since the LDP session was established.
TOTAL

The total number of records.
