routing-domain (TNP view)

Function

The routing-domain command configures the routing domain to which a TNP belongs.

The undo routing-domain command deletes the routing domain to which a TNP belongs.

By default, no routing domain is configured for a TNP.

Format

routing-domain routing-domain-name

undo routing-domain [ routing-domain-name ]

Parameters

Parameter Description Value
routing-domain-name

Specifies the name of a routing domain.

The value is a string of 1 to 31 case-sensitive characters. If spaces are used, the string must be enclosed in double quotation marks (" ").

Views

TNP view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To configure the routing domain to which a TNP of a CPE belongs, run the routing-domain command.

Prerequisites

A routing domain has been created in the site view.

Precautions

When a TNP is bound to an interface, the routing domain to which the TNP belongs cannot be modified. To modify the routing domain, run the undo source-interface command to unbind the TNP from the interface first.

Example

# Set the routing domain to which a TNP belongs to MPLS.
<HUAWEI> system-view
[HUAWEI] evpn site 1
[HUAWEI-site-1] system-id 1.1.1.1
[HUAWEI-site-1] routing-domain 2 name MPLS
[HUAWEI-site-1] transport-network-port 1
[HUAWEI-site-1-transport-network-port-1] routing-domain MPLS
