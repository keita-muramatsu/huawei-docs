statistics enable (dialer-interface)

Function

The statistics enable command enables traffic statistics collection on a dialer interface.

The undo statistics enable command disables traffic statistics collection on a dialer interface.

By default, traffic statistics collection is disabled on a dialer interface.

Format

statistics enable

undo statistics enable

Parameters

None

Views

Dialer interface view

Default Level

2: Configuration level

Usage Guidelines

To check the network status or locate network faults, you can enable traffic statistics collection on a dialer interface to collect statistics on traffic passing through the dialer interface.

Example

# Enable traffic statistics collection on the dialer interface.
<HUAWEI> system-view
[HUAWEI] interface Dialer 0
[HUAWEI-Dialer0] statistics enable
