display remote-unit port transceiver

Function

The display remote-unit port transceiver command displays information about an optical module on a remote interface.

Format

display remote-unit port [ port-id ] transceiver [ connect-interface { interface-name | interface-type interface-number } | name remote-unit-name ]

display remote-unit port [ port-id ] transceiver { connect-interface { interface-name | interface-type interface-number } | name remote-unit-name } realtime

Parameters

Parameter Description Value
port-id

Specifies the index of an interface on an RU.

The value is an integer in the range from 1 to 34. port-id indicates the port ID of an RU, which may be different from the physical port number printed on the panel. For example, if the downlink port numbers are 1 to 8 and the uplink port numbers are 9 to 10 on the panel, set port-id to an integer in the range from 1 to 10 according to the actual port for connection. If the downlink port numbers are 1 to 8 and the uplink port numbers are 1 to 2 on the panel, set port-id to an integer in the range from 1 to 10 (1 to 8: downlink ports; 9: uplink port 1; 10: uplink port 2).
connect-interface interface-name

Specifies the name of an interface.

The value is a string of 1 to 31 characters and must be set according to the device configuration.
connect-interface interface-type interface-number

Specifies the type and number of an interface. The interface type and number can be closely next to each other or separated by a space character.

The value ranges from 1 to 31 and must be set according to the device configuration.
name remote-unit-name

Specifies the alias of an RU.

The value is a string of 1 to 32 case-sensitive characters. It cannot contain spaces.
realtime

Queries real-time information.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run this command to view real-time information about the remote optical module.

Table 1 Description of the display remote-unit port transceiver command output
Item Description
ESN

ESN of an RU.
Name

Alias of an RU. If the RU does not have an alias, a hyphen (-) is displayed.
Device type

Device type of an RU.
Connect interface

Interconnection interface through which the RU is bound to the central device.
Common information

General information.
Transceiver type

Indicates the optical module type.
Transfer distance(m)

Indicates the transmission distance of optical waves.

OM1 optical fibers refer to traditional 62.5/125 μm multi-mode optical fibers.

OM2 optical fibers refer to traditional 50/125 μm multi-mode optical fibers.

OM3 optical fibers are new-generation multi-mode optical fibers. Compared with OM1 and OM2 optical fibers, OM3 optical fibers support a longer transmission distance.

When the GPS optical module is used, this parameter indicates the maximum length of the antenna between the GPS module and the signal receiver.

The device displays only the maximum transmission distances supported by different optical fibers of an optical module.
Digital diagnostic monitoring

Whether diagnostic information about the optical module is monitored.
Vendor name

Indicates the manufacturer name of the optical module.
Manufacture information

Manufacturing Information.
Manu. serial Number

Indicates the production serial number of the optical module.
Manufacturing date

Indicates the production date of the optical module.
Diagnostic information

Diagnostic information.
Temperature(Celsius)

Indicates the current temperature of the optical module.
Temp High Threshold(Celsius)

Upper temperature threshold of the optical module.
Temp Low Threshold(Celsius)

Lower temperature threshold of the optical module.
