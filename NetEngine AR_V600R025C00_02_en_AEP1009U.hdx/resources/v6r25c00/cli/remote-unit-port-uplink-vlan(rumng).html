remote-unit port uplink vlan

Function

The remote-unit port uplink vlan command configures the VLANs that are allowed to pass through the uplink interfaces of remote modules in batches.

The undo remote-unit port uplink vlan command deletes the VLANs that are allowed to pass through the uplink interfaces of remote modules in batches.

By default, the uplink interfaces of remote modules allow packets from VLAN 1 to pass through.

Format

remote-unit { ru-id1 [ to ru-id2 ] } &<1-8> port uplink { tagged | untagged } vlan { vlan-id1 [ to vlan-id2 ] } &<1-10>

undo remote-unit { ru-id1 [ to ru-id2 ] } &<1-8> port uplink { tagged | untagged } { vlan { vlan-id1 [ to vlan-id2 ] } &<1-10> | all }

Parameters

Parameter Description Value
ru-id1

Specifies the ID of the first RU configured in batches.

The value is an integer ranging from 0 to 16777215.
to vlan-id2

Specifies the ID of the last VLAN. The value must be greater than or equal to the value of vlan-id1.

The value is an integer ranging from 1 to 4094.
to ru-id2

Specifies the ID of the last RU configured in batches. The value must be greater than or equal to the value of ruid1.

The value is an integer ranging from 0 to 16777215.
tagged

Configures the uplink interfaces to forward packets of the specified VLANs in tagged mode.

-
untagged

Configures the uplink interfaces to forward packets of the specified VLANs in untagged mode.

-
vlan-id1

Specifies the ID of the first VLAN.

The value is an integer ranging from 1 to 4094.
all

Deletes all allowed VLANs from the uplink interfaces on the specified RUs.

-

Views

remote-unit view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

An RU can connect to different types of terminals using its downlink interfaces and distinguish terminal services by joining its downlink interfaces to different VLANs. You can run the remote-unit port uplink vlan command to configure allowed VLANs for uplink interfaces on RUs in batches so that different service VLANs can be assigned to different terminals.

An RU saves the VLAN configuration delivered by the central device to it in its flash memory and forwards traffic based on this VLAN configuration after being powered on. After the RU goes online on the central device, the central device synchronizes the latest VLAN configuration to the RU's flash memory.

Prerequisites

You have run the vlan mode manual command to configure the manual VLAN mode for the remote module.

Follow-up Procedure

After configuring the VLAN mode and port VLAN for an RU, you need to run the commit command to deliver the configuration or bring the RU online again for the configuration to take effect.

You can run the display remote-unit commit configuration command to check the configurations that are successfully delivered to RUs, and run the display remote-unit commit result command to check configuration delivery results of RUs.

Example

# Configure uplink interfaces of remote modules 0 to 4 to allow packets from VLAN 2 to pass through in tagged mode.
<HUAWEI> system-view
[HUAWEI] remote-unit
[HUAWEI] remote-unit 0 to 4 port uplink tagged vlan 2
