ap-patch update multi-load

Function

The ap-patch update multi-load command batch loads the patch for APs.

The undo ap-patch update multi-load command batch uninstalls the patch for APs.

Format

ap-patch update multi-load ap-type type-id [ ap-group group-name | { ap-id ap-id } &<1-10> ] [ next-startup ]

ap-patch update multi-load ap-group group-name [ { ap-id ap-id } &<1-10> ] [ next-startup ]

undo ap-patch update multi-load ap-type type-id [ ap-group group-name | { ap-id ap-id } &<1-10> ]

undo ap-patch update multi-load ap-group group-name [ { ap-id ap-id } &<1-10> ]

Parameters

Parameter Description Value
ap-group group-name

Specifies an AP group.

The value is a string of 1 to 35 visible characters that can be Chinese characters or a combination of Chinese and English characters. It cannot contain question marks (?) or only contain double quotation marks ("). If the AP group name contains spaces,it must be enclosed with double quotation marks (" "), for example, "huawei name1". The double quotation mark (") before and after the AP group name occupies two characters together. The specified AP group must exist.

Only the command editor in UTF-8 encoding format can be used to edit Chinese characters.
ap-id ap-id

Specifies the AP ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
next-startup

Specifies the patch for next startup.

-
ap-type type-id

Specifies the AP type ID.

The AP type ID must exist.

Views

WLAN view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

The ap-patch update multi-load ap-type type-id[ ap-group group-name| { ap-id ap-id} &<1-10> ] [ next-startup ] command is used to perform an online batch load of patches for APs by AP type.

  • When the parameter ap-group group-nameis specified, the patch is loaded only for APs of a specified type in the specified AP group.
  • When the parameter ap-id ap-idis specified, the patch is loaded only for the AP of the specified type with a specified AP ID.
  • If neither ap-group group-namenor ap-id ap-idis specified, the patch is loaded for all APs of the specified type.
  • If the type of APs specified by ap-group group-nameor ap-id ap-idis different from the specified ap-type type-id, the patch is not loaded for APs.
  • If the parameter next-startup is specified, the patch is loaded upon next startup. If this parameter is not specified, the patch is loaded immediately and is also used for next startup.

The ap-patch update multi-load ap-group group-name[ { ap-id ap-id} &<1-10> ] [ next-startup ] command is used to perform an online batch load of patches for APs by AP group.

  • When the parameter ap-id ap-idis specified, the patch is loaded only for the AP with a specified AP ID in the specified AP group.
  • When the parameterap-id ap-idis not specified, the patch is loaded for all APs in the specified AP group.
  • If the AP specified by ap-id ap-idis not in the specified AP group, the patch is not loaded for the AP.
  • If the parameter next-startup is specified, the patch is loaded upon next startup. If this parameter is not specified, the patch is loaded immediately and is also used for next startup.

Prerequisites

The patch file for batch loading has been configured using the ap-patch update update-filename command.

Follow-up Procedure

You can run the display ap update status command to view the patch loading progress.

Precautions

If the AP version is earlier than V200R021C10, the patch is also uninstalled when you run the undo ap-patch update multi-load command to cancel the AP patch upgrade. Running this command cancels the AP patch upgrade but does not uninstall the patch only when the AP version is V200R021C10 or later. To uninstall the patch, run the ap-patch delete command.

SFTP is recommended because it is more secure than FTP.

Example

# Load patches to all APs with type-id of 56 online in batches.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-patch update multi-load ap-type 56
Info: The current upgrade mode is AC mode, which may affect performance and take a long time. The FTP or SFTP upgrade mode is recommended. Continue? [Y/N]: y
# Load patches to all APs in the AP group group1.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-patch update multi-load ap-group group1
Info: The current upgrade mode is AC mode, which may affect performance and take a long time. The FTP or SFTP upgrade mode is recommended. Continue? [Y/N]: y
