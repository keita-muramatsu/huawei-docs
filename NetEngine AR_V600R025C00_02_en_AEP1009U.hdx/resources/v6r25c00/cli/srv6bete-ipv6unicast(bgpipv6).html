segment-routing ipv6 (BGP-IPv6 unicast address family view)

Function

The segment-routing ipv6 best-effort command enables public network routes to recurse to SRv6 BE based on SIDs carried in routes.

The segment-routing ipv6 traffic-engineer command enables a device to recurse public network routes to SRv6 TE Policy/SRv6 TE Flow Group based on SIDs carried in the routes.

The segment-routing ipv6 traffic-engineer best-effort command enables the device to preferentially recurse routes to SRv6 TE Policy/SRv6 TE Flow Group. If an SRv6 TE Policy fails, services can use SRv6 BE as the best-effort path.

The undo segment-routing ipv6 command restores the default configuration.

By default, this function of recursing public network routes based on the SIDs carried in the routes is disabled.

Format

segment-routing ipv6 { best-effort | traffic-engineer } *

undo segment-routing ipv6 { best-effort | traffic-engineer } *

Parameters

None

Views

BGP-IPv6 unicast address family view

Default Level

2: Configuration level

Usage Guidelines

In a public network IPv6 over SRv6 scenario, the segment-routing ipv6 command enables a device to recurse public network routes to SRv6 BE or SRv6 TE Policies based on the SID attributes carried in the routes.

If both best-effort and traffic-engineer are configured, SRv6 BE can be used as the best-effort path when an SRv6 TE Policy fails.

If the prefix-sid attribute is not configured, routes can be recursed to SRv6 TE Policies or SRv6 TE Flow Groups. The SRv6 TE Policies or SRv6 TE Flow Groups must have the USD capability.

Example

# Enable the device to recurse public network routes to SRv6 BE paths based on the SIDs carried in the routes.
<HUAWEI> system-view
[HUAWEI] bgp 100
[HUAWEI-bgp] ipv6-family unicast
[HUAWEI-bgp-af-ipv6] segment-routing ipv6 best-effort
# Enable public network routes to recurse to SRv6 TE Policies based on the SID attributes carried in routes.
<HUAWEI> system-view
[HUAWEI] bgp 100
[HUAWEI-bgp] ipv6-family unicast
[HUAWEI-bgp-af-ipv6] segment-routing ipv6 traffic-engineer
