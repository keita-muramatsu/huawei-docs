ip-address (AP view/AP provisioning view)

Function

The ip-address command configures a static IPv4 address and gateway address for an AP.

The undo ip-address command restores the default static IPv4 address and gateway address of an AP.

By default, no static IPv4 address or gateway address is configured for an AP.

Format

ip-address ipv4-address { mask | mask-length } [ gateway gateway ]

undo ip-address

Parameters

Parameter Description Value
ipv4-address

Specifies a static IPv4 address for an AP.

The value is in dotted decimal notation.
mask

Specifies an IPv4 address mask for an AP.

The value is in dotted decimal notation.
mask-length

Specifies the mask length of an AP's IPv4 address.

The value is an integer ranging from 0 to 32.
gateway gateway

Specifies the egress gateway for AP routes.

The value is in dotted decimal notation.

Views

AP provisioning view, AP view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To configure an AP to go online using a specified IPv4 address, configure a static IPv4 address for the AP.

Prerequisites

The AP has been configured to obtain an IP address in static mode using the address-mode (AP provisioning view) command.

Follow-up Procedure

After running this command in the AP provisioning view, run the commit command to deliver the configuration to the AP. The configuration takes effect only after the AP restarts.

Precautions

Ensure that there are reachable routes between the IPv4 address configured for an AP and the WAC source address. Otherwise, the AP may fail to go online.

CAPWAP packets between the central AP and RUs in versions earlier than V200R019C10 are forwarded at Layer 2 and are independent of IP addresses on an agile distributed WLAN. Therefore, the configuration of an IP address does not affect the RU going online. Ensure that a route is reachable between the IP address of the RU and the central AP source address. Otherwise, services involving IP addresses may be affected, for example, STelnet.

If the AP and WAC are connected through a Layer 3 network, the egress gateway for AP routes must be configured.

An AP cannot be configured with both IPv4 and IPv6 static IP addresses.

The undo ip-address command in the AP provisioning view disables the WAC from delivering this parameter setting to APs after the configuration is delivered using the commit command.

Example

# Set the static IPv4 address of the AP to 10.1.1.1/24.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] provision-ap
[HUAWEI-wlan-provision-ap] address-mode static
[HUAWEI-wlan-provision-ap] ip-address 10.1.1.1 24
# Set the static IPv4 address of the AP to 10.1.1.1/24.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-id 0
[HUAWEI-wlan-ap-0] address-mode static
