traffic-optimize bcmc unicast-send

Function

The traffic-optimize bcmc unicast-send command enables the function of converting broadcast or multicast packets to unicast packets on an air interface.

The undo traffic-optimize bcmc unicast-send (with parameters specified) command cancels the configuration of converting broadcast or multicast packets to unicast packets on an air interface.

The undo traffic-optimize bcmc unicast-send (without parameters specified) command restores the default configuration.

By default, the broadcast/multicast-to-unicast conversion function is enabled for ARP, ND, and DHCP packets on the air interface.

Format

traffic-optimize bcmc unicast-send { arp | nd | dhcp } *

undo traffic-optimize bcmc unicast-send { arp | nd | dhcp } *

undo traffic-optimize bcmc unicast-send

Parameters

Parameter Description Value
arp

Specifies the ARP packets.

-
nd

Specifies the ND packets.

-
dhcp

Specifies the DHCP packets.

-

Views

Traffic profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If broadcast or multicast packets are sent when the air interface is busy, the air interface performance deteriorates. Converting broadcast or multicast protocol packets into unicast packets can reduce the number of broadcast or multicast packets on the air interface. This improves air interface performance at the price of increased CPU usage.

Prerequisites

STA address learning has been enabled using the undo learn-client-address { ipv4 | ipv6 } disable command.

Precautions

If the STAs are virtual machines (VMs), run the **undo traffic-optimize bcmc unicast-send { arp | nd | dhcp } *** command to disable the multicast-to-unicast conversion function for protocol packets. Otherwise, the VMs cannot communicate properly.

If the STAs are bridge devices, run the undo traffic-optimize bcmc unicast-send { arp | nd | dhcp } * command to disable the multicast-to-unicast conversion function for protocol packets. Otherwise, the STAs connected to the bridge devices cannot communicate properly.

Example

# Configure the function of converting broadcast or multicast DHCP packets to unicast packets on an air interface in traffic profile p1.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] traffic-profile name p1
[HUAWEI-wlan-traffic-prof-p1] traffic-optimize bcmc unicast-send dhcp
