esn

Function

The esn command adds ESNs to an ESN blacklist or whitelist.

The undo esn command deletes an ESN from an ESN blacklist or whitelist.

By default, no ESN is configured in the ESN blacklist or whitelist.

Format

esn esn

undo esn esn

Parameters

Parameter Description Value
esn

Specifies an ESN.

The value is a string of 1 to 64 case-sensitive characters.

Views

ens-list view

Default Level

2: Configuration level

Usage Guidelines

The ESN list is classified into the blacklist and whitelist. When the ESN whitelist is configured, the devices with the ESNs that are not in the whitelist are not allowed to access the network. When the ESN blacklist is configured, the devices with the ESNs that are in the blacklist are not allowed to access the network. To add an ESN to a blacklist or whitelist, run this command.

Example

# Add ESN 2102353UNW1212291054 to the ESN whitelist list1.
<HUAWEI> system-view
[HUAWEI] dtls esn-list list1 type whitelist
[HUAWEI-dtls-esn-list-list1] esn 2102353UNW1212291054
