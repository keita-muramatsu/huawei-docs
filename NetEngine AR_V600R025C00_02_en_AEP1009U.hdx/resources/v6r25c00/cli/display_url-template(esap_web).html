display url-template

Function

The display url-template command displays information about the configured URL template.

Format

display url-template { all | name template-name }

Parameters

Parameter Description Value
all

Indicates all URL templates.

-
name template-name

Specifies the name of a URL template.

The value is a string of case-sensitive characters. It cannot contain spaces.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

After a URL template is configured, you can run the display url-template command to view information about the URL template.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the configuration of the URL template example.
<HUAWEI> display url-template name example
  Name : example
  URL  :
    1. push-only http:\\example.com ssid exampleSSID
  Start mark      : ?
  Assignment mark : =
  Isolate mark    : &
  User VLAN       :
  Login URL Key   : logiurl 
  Login URL       : http:\\example.com
  Device IP Value : 10.1.1.1 
  Device MAC Value: 00e0-fc78-9abc  
  Sysname Text    : TestAC
