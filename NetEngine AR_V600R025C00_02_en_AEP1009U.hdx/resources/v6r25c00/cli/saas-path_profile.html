saas-path profile

Function

The saas-path profile command defines a SaaS path profile and displays the SaaS path profile view, or displays the view of an existing SaaS path profile.

The undo saas-path profile command deletes a specified SaaS path profile.

By default, no SaaS path profile is created.

Format

saas-path profile profile-name

undo saas-path profile profile-name

Parameters

Parameter Description Value
profile profile-name

Specifies the name of a path profile.

The value is a string of 1 to 15 case-sensitive characters. It can contain spaces.

Views

saas-cloud-express view

Default Level

2: Configuration level

Usage Guidelines

This command is used to define a SaaS path profile and enter the SaaS path profile view, or enter the view of an existing SaaS path profile. The list of paths that can be selected for SaaS application access can be configured.

Example

# Create a SaaS path profile named profile1 and enter the SaaS path profile view.
<HUAWEI> system-view
[HUAWEI] saas-cloud-express
[HUAWEI-saas-cloud-express] saas-path profile profile1
