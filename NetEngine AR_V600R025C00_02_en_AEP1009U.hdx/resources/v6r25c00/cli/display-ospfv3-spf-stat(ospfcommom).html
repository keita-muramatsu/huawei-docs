display ospfv3 spf-statistics

Function

The display ospfv3 spf-statistics command displays OSPFv3 route calculation statistics.

Format

display ospfv3 [ process-id ] spf-statistics [ verbose ]

display ospfv3 process-id spf-statistics area area-id spt [ verbose ]

Parameters

Parameter Description Value
process-id

Specifies an OSPFv3 process ID.

The value is an integer ranging from 1 to 4294967295.
verbose

Displays the detailed statistics.

-
area area-id

Specifies the ID of an OSPFv3 area.

The value is an integer ranging from 0 to 4294967295.
spt

Displays information about the SPT component.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

The display ospfv3 spf-statistics command displays OSPFv3 route calculation statistics, which includes the time and cause of the route calculation and the number of changed routes. The command output helps you troubleshoot OSPFv3 faults.

Table 1 Description of the display ospfv3 spf-statistics command output
Item Description
Date

Date when route calculation occurs.
Time

Time when the route calculation was triggered.
Nodes

Number of nodes (updated or deleted) affected by the current SPF calculation.
Count

Number of reasons for the SPF calculation.
FirstTriggerReason

First cause of the SPF calculation.
RouterId

Router ID.
InterfaceInfo

If the cause is link-related, the value is Linkdata. Otherwise, the value is --.
Routing table change statistics

Statistics about routing table changes.
Intra

Intra-area route.
Inter

Number of inter-area routes in the routing table which are changed because of route calculation.
External

External route.
Reason

Trigger reason:

  • Other: The route calculation is triggered by a cause that is neither a topology change nor an LSA change.
  • Topo: The route calculation is triggered by a topology change.
  • LSA: The route calculation is triggered by an LSA change.
Deleted

Number of nodes deleted in the current SPF calculation.
The reason of calculation is

List of causes that cause route calculation. A maximum of eight causes can be displayed.
NO.

Number of the reason that causes the SPF calculation. The value ranges from 1 to 8.
TriggerReason

Cause of the SPF calculation.
Index

Index of statistics.
Updated

Number of updated nodes in the SPF calculation.
