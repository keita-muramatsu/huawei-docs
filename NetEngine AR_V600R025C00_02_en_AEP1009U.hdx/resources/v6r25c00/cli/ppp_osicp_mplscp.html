ppp osicp mplscp

Function

The ppp osicp command enables or disables negotiation between two devices before OSICP go Up on both devices.

The ppp mplscp command enables or disables negotiation between two devices before MPLSCP go Up on both devices.

By default, two devices must negotiate so that OSICP and MPLSCP can go Up.

Format

ppp { osicp | mplscp } { enable | disable }

Parameters

Parameter Description Value
enable

Enables a local device to negotiate with a peer device before OSICP and MPLSCP go Up.

-
disable

Disables a local device from negotiating with a peer device before OSICP and MPLSCP go Up.

-

Views

MP-group interface view, POS interface view, Serial interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When the default OSICP and MPLSCP configurations differ on devices that are to communicate, run the ppp osicp mplscp command as follows to ensure consistent configurations on both devices:

  • If OSICP and MPLSCP are configured to go Up without negotiation on the peer device, run the ppp { osicp | mplscp } disable command on the local device.
  • If OSICP and MPLSCP are configured to go Up only after negotiation on the peer device, run the ppp { osicp | mplscp } enable command on the local device. Alternatively, use the default configuration on the local device.

Precautions

Run the shutdown and undo shutdown command in the interface view to make the configuration take effect.

Example

# Disable serial 0/0/0:2 from negotiating with a peer device and allow OSICP to directly go Up.
<HUAWEI> system-view
[HUAWEI] interface serial 0/0/0:2
[HUAWEI-Serial0/0/0:2] ppp osicp disable
[HUAWEI-Serial0/0/0:2] shutdown
[HUAWEI-Serial0/0/0:2] undo shutdown
