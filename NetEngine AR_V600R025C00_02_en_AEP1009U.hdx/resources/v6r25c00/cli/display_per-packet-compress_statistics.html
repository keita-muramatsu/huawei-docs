display per-packet-compress statistics

Function

The display per-packet-compress statistics command displays statistics about the per-packet compression function.

This command is supported only on the AR8700 series, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series and AR6700-H series.

Format

display per-packet-compress statistics

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

When per-packet compression is used, you can run the display per-packet-compress statistics command to view statistics about per-packet compression.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display compression statistics on the device.
<HUAWEI> display per-packet-compress statistics
Compress:
    Input                                        : 1234 packets, 121056 bytes
    Success                                      : 998 packets, 120056 bytes
        After compress                           : 100000 bytes
    Total fail                                   : 236 packets
        Too short                                : 201 packets
        OverSize                                 : 19 packets
        Exceed original size                     : 30 packets
        Process error                            : 5 packets
    Total reduction rate                        : 16.7%
    Last 300 seconds reduction rate : 50%
Uncompress:
    Input                                           : 1234 packets, 2533 bytes
    Success                                        : 998 packets, 2000 bytes
        After uncompress                         : 10000 bytes
    Total fail                                      : 236 packets
        OverSize                                   : 19 packets
        Process error                             : 236 packets
Table 1 Description of the display per-packet-compress statistics command output
Item Description
Input

Number of input packets and bytes.
Success

Number of packets and bytes that are successfully compressed or decompressed.
After compress

Number of bytes after compression.
After uncompress

Number of bytes after decompression.
Total fail

Number of packets that fail to be compressed or decompressed.
Total reduction rate

Traffic volume reduction rate, in percentage.

Total reduction rate = (Success - After compress)/Input.
Too short

Number of packets that fail to be compressed because the packets are too short.
OverSize

Number of packets whose length exceeds the upper limit.
Exceed original size

Number of packets that fail to be compressed because the packet size increases after compression.
Process error

Packet error.
Last 300 seconds reduction rate

Traffic volume reduction rate in the last 300 seconds, in percentage.
Compress

Compression encoding statistics.
Uncompress

Decompression statistics.
