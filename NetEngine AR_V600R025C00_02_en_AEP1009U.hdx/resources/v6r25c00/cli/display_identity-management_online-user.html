display identity-management online-user

Function

The display identity-management online-user command displays information about online users.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR5710-S8P1XDSE-2LTE4EA.

Format

display identity-management online-user [ verbose ] [ ipv4-range start-ipv4-address end-ipv4-address | ipv6-range start-ipv6-address end-ipv6-address | user user-name | security-group security-group-name ] all-vpn-instance

Parameters

Parameter Description Value
verbose

Indicates the details.

-
ipv4-range start-ipv4-address end-ipv4-address

Displays information about online users in the specified IPv4 address range. If start-ipv4-address and end-ipv4-address are the same, information about the online user with the specified IPv4 address is displayed.

The value is in dotted decimal notation.
ipv6-range start-ipv6-address end-ipv6-address

Displays information about online users in a specified IPv6 address range. If start-ipv6-address and end-ipv6-address are the same, information about the online user with the specified IPv6 address is displayed.

The value is in hexadecimal notation.
user user-name

Displays information about the online user with the specified login name.

The value is a string of 1 to 759 or 3 to 761 case-sensitive characters without spaces.
security-group security-group-name

Displays information about online users in a specified security group.

The value is a string of 1 to 759 or 3 to 761 case-sensitive characters without spaces.
all-vpn-instance

Displays data of online users in all VPN instances, including data of online users who go online through the local server that is not bound to any VPN instance.

-

Views

Vsys Portal authentication view, Portal authentication view, Vsys RADIUS SSO view, RADIUS SSO view, Vsys TSM SSO view, TSM SSO view, User view, Vsys identity management view, Identity Management View, System view, User view of the virtual system, System view of the virtual system

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

You can run this command to view information about online users for identity and access management. When the user table information is queried, if the user table uses non-UTF-8 characters, *** is displayed.

Precautions

Currently, the following attributes are not supported:

  • MAC
  • VLAN ID
  • IMSI
  • IMEI
  • MSISDN
  • User Defined
