shared-key(Web-auth-server template view)

Function

The shared-key command configures the shared key used by the device to exchange information with the Portal server.

The undo shared-key command deletes the configured shared key.

By default, no shared key is configured for the device to exchange information with the Portal server.

Format

shared-key cipher key-string

undo shared-key

Parameters

Parameter Description Value
cipher key-string

Specifies the Portal shared key.

The value is a string of 1 to 255 case-sensitive characters in plaintext or a string of 128 to 428 case-sensitive characters in ciphertext. The string can contain spaces if it is enclosed in double quotation marks (").

Views

Web-auth-server template view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After a shared key is configured using the shared-key command, the Portal packet exchanged between the device and Portal server carries an authenticator generated according to the shared key. The authenticator is used by the receiver to verify the received Portal packets. This effectively improves the security of information exchange between the device and Portal authentication server.

Precautions

To improve security, it is recommended that the password contain at least two types of the following characters: lowercase letters, uppercase letters, digits, and special characters. In addition, the password must contain at least 16 characters.

Example

# Set the shared key for exchanging information with the Portal server to YsHsjx_202206 in the Portal server template test.
<HUAWEI> system-view
[HUAWEI] web-auth-server test
[HUAWEI-web-auth-server-test] shared-key cipher YsHsjx_202206
Warning: The shared-key complexity is low. It is recommended that the password contain at least sixteen characters and be a combination of at least two of the following categories: Uppercase letters <A-Z>; Lowercase letters <a-z>; Numerals <0-9>; Symbols (all characters not defined as letters or numerals), such as !, $, #, and %.
