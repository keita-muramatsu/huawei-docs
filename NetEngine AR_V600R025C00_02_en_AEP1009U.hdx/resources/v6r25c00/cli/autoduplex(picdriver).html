duplex auto

Function

The duplex auto command configures the auto-negotiation duplex mode of an Ethernet electrical interface.

The undo duplex auto command restores the default auto-negotiation duplex mode of an Ethernet electrical interface.

By default, Ethernet electrical interfaces on both ends can negotiate to any duplex mode they support.

Format

duplex auto { full | half }

undo duplex auto

Parameters

Parameter Description Value
full

Sets the duplex mode of an Ethernet electrical interface to full-duplex in auto-negotiation mode.

-
half

Sets the duplex mode of an Ethernet electrical interface to half-duplex in auto-negotiation mode.

-

Views

GE electrical interface view, Layer 2 multi-GE interface view, Multi-GE interface view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After you run the undo negotiation disable command to configure an Ethernet interface to work in auto-negotiation mode, the duplex mode of the interface is negotiated with the peer interface. The negotiated duplex mode, however, may not meet the actual requirement. For example, if the interfaces of two connected devices support full-duplex and half-duplex but work in half-duplex mode after auto-negotiation, you can run the duplex auto command to configure the interfaces to work in full-duplex mode based on the actual requirement.

Prerequisites

The serdes-mode configuration has been deleted from all MultiGE interfaces in a MultiGE interface group if the duplex auto command is configured on MultiGE interfaces.

Precautions

By default, an Ethernet interface works in auto-negotiation mode, which is recommended. If the negotiation succeeds, the two interfaces work at the same duplex mode and speed. The settings of the SPEED and DUPLEX parameters and auto-negotiation mode must be the same at the local and peer ends. Otherwise, negotiation may fail. The interface auto-negotiation mode, duplex mode and speed support depend on the device.

In auto-negotiation mode, a GE electrical interface that works at a rate of 1000 Mbit/s supports the full-duplex mode. If the duplex mode is changed to half-duplex, the GE electrical interface works at a maximum rate of 100 Mbit/s.

The AR6710-L14T2X4 do not support this configuration.

Example

# Configure the duplex auto-negotiation capability of the GE electrical port to half.
<HUAWEI> system-view
[HUAWEI] interface GE 0/0/1
[HUAWEI-GE0/0/1] duplex auto half
