ipv6 route-monitor-group

Function

The ipv6 route-monitor-group command creates an IPv6 route monitoring group and displays the IPv6 route monitoring group view, or directly displays the IPv6 route monitoring group view of an existing IPv6 route monitoring group.

The undo ipv6 route-monitor-group command deletes an IPv6 route monitoring group.

By default, no IPv6 route monitoring group is created.

Format

ipv6 route-monitor-group group-name

undo ipv6 route-monitor-group group-name

Parameters

Parameter Description Value
group-name

Specifies the name of an IPv6 route monitoring group.

The value is a string of 1 to 31 case-sensitive characters. If spaces are used, the string must be enclosed in double quotation marks (" ").

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

All monitored routes of the same type on the network side can be added to a route monitoring group. Each route monitoring group is identified by a unique name. An IPv6 route monitoring group has been created using the ipv6 route-monitor-group command.

A route monitoring group can monitor a certain number of route sets. Each route in the set has a certain fault weight. The fault weight reflects the link quality. A larger fault weight indicates a more important link. You can measure the fault weight of a route based on parameters such as the link bandwidth, rate, and cost.

  • When a route in the route set becomes inactive, the fault weight of the route monitoring group increases.
  • When a route in the route set becomes active, the fault weight of the route monitoring group decreases.

Follow-up Procedure

After an IPv6 route monitoring group is created, you can run the track ipv6 route command to add routes to the IPv6 route monitoring group. After routes are added to a route monitoring group, you can run the monitor enable (IPv6 route monitoring group view) command to enable the route monitoring group.

In actual applications, you can associate the status of a service module with that of a route monitoring group. This prevents traffic overload and forwarding failures when the network-side active link fails, improving user experience.

Precautions

A maximum of 255 IPv6 route monitoring groups can be created.

An IPv6 route monitoring group in use cannot be deleted.

Example

# Create an IPv6 route monitoring group named uplink.
<HUAWEI> system-view
[HUAWEI] ipv6 route-monitor-group uplink
