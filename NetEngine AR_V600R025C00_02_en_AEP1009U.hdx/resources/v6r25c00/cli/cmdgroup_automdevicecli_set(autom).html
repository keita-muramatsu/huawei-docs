role(net-assistant device-granted view)

Function

The role command configures a role for an approved device.

The undo role command deletes the role of an approved device.

By default, no role is configured for an approved device.

Format

role { wan-gw | service-gw | lc | wac } *

undo role

Parameters

Parameter Description Value
wan-gw

Configures the device as an egress gateway.

-
service-gw

Configures the device as a service gateway.

-
lc

Configures the device as the master device.

-
wac

Configures the device as a wireless access controller.

-

Views

Net-assistant device-granted view

Default Level

3: Management level

Usage Guidelines

On a LAN that supports the net assistant function, the master device delivers configurations to other devices based on their roles. For example, the master device delivers WLAN configurations to the WAC. You can run this command to configure a role for a device.

Example

# Set the role of an approved device to wan-gw.
<HUAWEI> system-view
[HUAWEI] net-assistant
[HUAWEI-net-assistant] device
[HUAWEI-net-assistant-device] device-granted 00e0-fc12-3456 type lsw
[HUAWEI-net-assistant-device-device-granted-00e0-fc12-3456] role wan-gw
