srv6-te-policy color priority

Function

The srv6-te-policy color priority command specifies an SRv6 TE Policy for SPR.

The undo srv6-te-policy color priority command deletes the SRv6 TE Policy specified for SPR.

By default, no SPR policy is created.

Format

srv6-te-policy color color-value priority priority-value

undo srv6-te-policy color color-value [ priority priority-value ]

Parameters

Parameter Description Value
color-value

Specifies the color of an SPR policy.

The value is an integer ranging from 0 to 4294967295.
priority-value

Specifies the priority of an SPR policy.

The value is an integer ranging from 1 to 8.

Views

SRv6 SPR policy view

Default Level

2: Configuration level

Usage Guidelines

The srv6-te-policy color priority command specifies an SRv6 TE Policy for SPR. A smaller value indicates a higher priority. A maximum of eight SRv6 TE Policies can be specified. If the specified SRv6 TE Policies have the same priority, they work in load-balancing mode. After an SRv6 TE Policy is preferentially selected, traffic specified by the SPR policy can be forwarded over the SRv6 TE Policy.

Example

# Specify the SRv6 TE Policy for an SPR path to reference.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] smart-policy-route
[HUAWEI-segment-routing-ipv6-spr] spr-policy spr1
[HUAWEI-segment-routing-ipv6-spr-policy-spr1] srv6-te-policy color 1 priority 1
