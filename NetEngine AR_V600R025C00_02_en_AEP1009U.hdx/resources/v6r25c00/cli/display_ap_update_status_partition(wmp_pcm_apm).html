display ap update status partition

Function

The display ap update status partition command displays information about channel-based partitions.

Format

display ap update status partition { all | partition-id partition-id }

Parameters

Parameter Description Value
all

Displays information about all channel groups.

-
partition-id partition-id

Displays information about a specified channel group.

The value is an integer ranging from 0 to 255.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

The display ap update status partition command displays only information about APs to be upgraded, which refer to the APs whose target version files have been loaded to the backup partition and are waiting for a reset.

Precautions

The AP reset by channel-based partition (in a multi-batch, scattered upgrade) is not supported by the following models:

  • AirEngine 5761-10W, AirEngine 5761S-10W, and AirEngine 5761-10WD
  • AirEngine X762 series APs (except the AirEngine 5762-12SW and AirEngine 5762S-12SW)
