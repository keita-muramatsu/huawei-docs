te metric

Function

The te metric command sets a TE metric value for links.

The undo te metric command deletes the TE metric value.

By default, an IGP metric value is used as the TE metric value for links.

Format

te metric metric-value

undo te metric

undo te metric metric-value

Parameters

Parameter Description Value
metric-value

Sets a TE metric value for links.

The bd-id value is an integer ranging from 1 to 16777215.

Views

10GE sub-interface view, 10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE sub-interface view, 40GE interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, Ethernet sub-interface view, Ethernet interface view, GE optical interface view, GE sub-interface view, GE electrical interface view, MP-group interface view, Tunnel interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If the metric type of a tunnel is TE, you can run the te metric value command on the outbound interfaces of the ingress and transit nodes to change the TE metric of the link. This affects CSPF calculation and adjusts CR-LSP establishment.

Configuration Impact

After a TE metric value is configured for a TE link, an IGP floods the TE metric value to other nodes. CSPF preferentially selects the link with the smallest metric value during path calculation.

Example

# Set the TE metric value to 20.
<HUAWEI> system-view
[HUAWEI] te attribute enable
[HUAWEI] interface 10GE 0/0/0
[HUAWEI-10GE0/0/0] te metric 20
