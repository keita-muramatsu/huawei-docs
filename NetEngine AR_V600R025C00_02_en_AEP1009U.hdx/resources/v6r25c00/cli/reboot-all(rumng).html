reboot all

Function

The reboot all command resets an RU.

By default, an RU is not reset.

Format

reboot all

Parameters

None

Views

remote-unit view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

  • You can run this command to reset a faulty RU.
  • If an RU fails to be upgraded and enters the cooldown period, you can run the reboot command to end the cooldown period.

Precautions

  • The RU cannot be reset because it fails to be authenticated or is not authenticated.
  • If the RU communication is abnormal, the reset fails.
  • Configurations are not stored on RUs. After an RU starts, it goes online on the central switch and is authenticated successfully. Configurations are delivered to the RU and take effect. For example, if interface isolation is configured and the RU is restarted, traffic can be forwarded between the interfaces of the RU. After the configuration is delivered, the interfaces of the RU enter the isolated state.

Example

# Reset all RUs.
<HUAWEI> system-view
[HUAWEI] remote-unit
[HUAWEI-remote-unit] reboot all
