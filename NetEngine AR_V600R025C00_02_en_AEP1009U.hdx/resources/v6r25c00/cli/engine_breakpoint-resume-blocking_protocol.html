engine breakpoint-resume-blocking protocol

Function

The engine breakpoint-resume-blocking protocol command enables the resumable transfer blocking function.

The undo engine breakpoint-resume-blocking protocol command disables the resumable transfer blocking function.

By default, the resumable transfer blocking function is enabled for all protocols.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

engine breakpoint-resume-blocking protocol { all | http | ftp | smb }

undo engine breakpoint-resume-blocking protocol { all | http | ftp | smb }

Usage Guidelines

The resumable transfer mechanism is a data transmission technology. It is mainly used to resume the data transmission from the point where the transmission is suspended due to network interruption or other reasons during file download or upload. This mechanism improves the efficiency of data transmission, especially when large files are processed.

However, this mechanism will adversely affect content security detection. Generally, when content security detection is performed for a file, a complete file needs to be obtained from network traffic. When resumable transfer occurs, because the file is not transferred from the beginning, the content security detection engine cannot extract the complete file for detection, resulting in missing detection.

For example, in a common scenario where a client attempts to download a file, if the content security detection engine detects a threat in the file and blocks the file, the client usually will try again. During file blocking, some file content may have been downloaded to the client. The client retries multiple times to trigger resumable transfer. In this case, even if the content security detection engine detects a threat in the file, the client may finally successfully download the file.

This is where malicious file blocking during resumable transfer comes in. Currently, this function is applicable to HTTP, FTP, and SMB.

Example

# Enable the resumable transfer blocking function for HTTP.
<HUAWEI> system-view
[HUAWEI] engine breakpoint-resume-blocking protocol http
