display eva fault manager

Function

The display eva fault manager command displays the fault modes managed by EVA.

Format

display eva fault manager [ mode faultMode ]

display eva fault manager [ mode faultMode ] verbose

Parameters

Parameter Description Value
mode faultMode

Name of a fault mode.

The value is a string of 1 to 63 case-insensitive characters.
verbose

Displays details about the fault mode.

-

Views

All views

Default Level

3: Management level

Usage Guidelines

Usage Scenario

You can run this command to view the administrative status or detailed information about fault modes managed by EVA.

Example
