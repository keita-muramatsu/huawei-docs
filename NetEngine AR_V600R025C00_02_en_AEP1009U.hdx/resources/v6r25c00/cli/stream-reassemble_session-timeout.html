stream-reassemble session-timeout

Function

The stream-reassemble session-timeout command set the timeout time for out-of-sequence TCP packet inspection.

The undo stream-reassemble session-timeout command restores the default setting.

By default, the timeout time for out-of-sequence TCP packet inspection is 10s.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

stream-reassemble session-timeout session-timeout

undo stream-reassemble session-timeout

Parameters

Parameter Description Value
session-timeout

Indicates the timeout interval.

The value is an integer ranging from 0 to 1200, in seconds.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

If the value of session-timeout is 0, TCP out-of-order packet detection is disabled.

When the value of session-timeout is greater than 0 and the TCP out-of-order time is less than or equal to the value of session-timeout, the device attempts to reassemble traffic. If the TCP out-of-order time is greater than the value of session-timeout and service priority is configured (using the engine overload action bypass command), the ASE engine does not perform content security detection on the traffic, service transmission is preferentially guaranteed.

Example

# Set the timeout time for out-of-sequence TCP packet inspection to 20s.
<HUAWEI> system-view
[HUAWEI] stream-reassemble session-timeout 20
