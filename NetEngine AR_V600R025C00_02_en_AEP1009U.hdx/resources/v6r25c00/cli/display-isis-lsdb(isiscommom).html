display isis lsdb

Function

The display isis lsdb command displays the LSDB information of IS-IS.

Format

display isis lsdb [ verbose [ no-name ] | { level-1 | level-2 } | { local | lspid | is-name isname } ] * [ process-id | { vpn-instance vpn-instance-name } ]

display isis process-id lsdb [ { level-1 | level-2 } | verbose [ no-name ] | { is-name isname | local | lspid } ] *

display isis lsdb [ no-name | { level-1 | level-2 } | { local | lspid | is-name isname } ] * [ process-id | { vpn-instance vpn-instance-name } ]

display isis process-id lsdb [ { level-1 | level-2 } | no-name | { is-name isname | local | lspid } ] *

Parameters

Parameter Description Value
verbose

Displays detailed LSDB information.

-
no-name

Displays detailed information about the LSDB, without the alias information.

-
level-1

Displays the Level-1 LSDB.

-
level-2

Displays the Level-2 LSDB.

-
local

Displays information about the local database.

-
lspid

Specifies an LSP ID.

The value is a string of 16 to 20 characters in the format of ####.####.####.##-##, for example, 0050.0500.5004.00-00.
is-name isname

Specifies a dynamic hostname.

The value is a string and it has two values:

  • symbolic-name: the length is from 1 to 64.
  • symbolic-name.XX-XX: the length is from 1 to 70.

When quotation marks are used around the string, spaces are allowed in the string.
process-id

Specifies the ID of an IS-IS process.

The value is an integer ranging from 1 to 4294967295.
vpn-instance vpn-instance-name

Specifies an IS-IS multi-instance process of a VPN instance.

The value is a string of 1 to 31 case-sensitive characters without spaces. The VPN instance name cannot be _public_. If the character string is quoted by double quotation marks, the character string can contain spaces.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To view the LSDB information of IS-IS, run the display isis lsdb command. If no level is specified, information about Level-1 and Level-2 LSDBs is displayed.

If verbose is specified, you can view detailed information about the IS-IS LSDB, including the multi-topology (MT) ID, MT neighbor ID, and IPv6 prefix.

Example

The actual command output varies according to the device. The command output here is only an example.

Table 1 Description of the display isis lsdb command output
Item Description
*(In TLV)

Leaked route.
*(By LSPID)

Self-LSP, which is generated by the local device.
LSPID

ID of an LSP.

The LSPID 0000.0000.0001.00-00 is used as an example. If the asterisk (*) follows the LSP ID, it indicates that this LSP is generated by the local device. 0000.0000.0001 indicates the source ID, which is the system ID of the device that generates the LSP. The two digits 00 following the source ID indicate the pseudonode ID. If the two digits are not 0s, the device that generates the LSP is the DIS. The last two digits 00 indicate the fragment ID. If the value is 0, the packet is not fragmented. If the value is not 0, the packet is fragmented.
Seq Num

LSP sequence number.
Checksum

LSP checksum.
HoldTime

Holdtime of an LSP.
Length

LSP length.
ATT/P/OL
  • ATT: attach bit;
  • P: partition bit;
  • OL: indicates the overload bit.
SOURCE

Source node system ID.
NLPID

Network protocol supported.
IPV6

Information about IPv6 routes within the domain.
AREA ADDR

Area address.
INTF ADDR

Interface address.
INTF ADDR V6

Interface IPv6 address.
Lan-SRv6-X-Sid

SRv6 adjacency SID on a broadcast network.
+IP-Extended

Extended IPv4 routing information, which carries TE-related information.
Router Cap

Device capability information.
Segment Routing IPv6 Cap

Information about IPv6 segment routing capabilities.
Segment Routing MSD

Maximum SRv6 SID depth.
SRv6 Locator

SRv6 locator TLV information.
SRv6 End Sid

SRv6 SID value.
Total LSP(s)

LSP quantity.
Redistribute List

Redistribute list.

Redistribute List 6501.0102.0000 | 0x1e01010100000003.

The first ID is the system ID of the IS-IS that advertises the route.

The second ID is the ID carried by the imported route, which depends on the routing protocol that generates the route. If the routing protocol is OSPF, the ID is the router ID and process ID of OSPF. If the routing protocol is BGP, the ID is the instance ID of BGP and a four-byte random number.
NBR ID

System ID of a neighbor.
Algorithm

Prefix label algorithm.
Flag

Flag of the prefix label.

  • R: indicates the penetration flag. If R is set, it indicates that the prefix SID is leaked between levels or imported from other protocols.
  • N: indicates the node label. When N is set, it indicates that the prefix corresponding to the Prefix-Sid can identify the device and is a node label.
  • P: indicates the no-PHP flag. When the P flag is set to 1, it indicates that the label cannot be popped out on the penultimate hop.
  • E: indicates an explicit null label. If E is set, the penultimate hop must use an explicit null label to replace the actual label.
  • V: value flag. When V is set, it indicates that the Prefix-Sid corresponds to an absolute label value instead of an offset value.
  • L: indicates the local flag. When L is set, it indicates that the prefix SID has a local flag.
D

Leaking direction. This flag is set when the IS-IS Router Capability TLV in a Level-2 area is leaked to a Level-1 area.
S

Flood flag:

  • 0: The IS-IS Router Capability TLV is not flooded between level-specific areas.
  • 1: The IS-IS Router Capability TLV is flooded within a whole domain.
COST

Route cost.
Function

SRv6 instruction type.
Max-SL

Maximum value of the SL field carried in the segment list of a packet that a local node can receive.
Max-End-Pop

Maximum number of SIDs in a segment list.
Max-H-Ins

Maximum number of SIDs that can be added to segment list information when a node performs an H.insert operation.
Max-H-Encap

Maximum number of SIDs that can be contained in a segment list when the H.Encap operation is performed.
Max-End-D

Maximum number of SIDs contained in a segment list when the End.DX6 and End.DT6 functions are used.
MT

Topology ID:

  • 0: indicates the IPv4 topology and standard IPv6 topology.
  • 2: IPv6 topology.
Block-Len

Length of a block segment in an SRv6 SID.
NodeID-Len

Length of node ID in SRv6 SID.
Func-Len

The length of function in SRv6 SID.
Args-Len

Length of arguments in SRv6 SID.
Metric

Cost value or cost value in the FAPM TLV.
C

Compression·flag.
Flavor

Flavor type of the SID.
