peer enable (BGP-EVPN address family view) (IPv4)

Function

The peer enable command enables a BGP device to exchange routes with a specified peer in the address family view.

The undo peer enable command disables a BGP device from exchanging routes with a specified peer.

By default, only the peer in the BGP IPv4 unicast address family view is automatically enabled.

Format

peer ipv4-address enable

undo peer ipv4-address enable

Parameters

Parameter Description Value
ipv4-address

Specifies the IPv4 address of a peer.

It is in dotted decimal notation.

Views

BGP-EVPN address family view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

By default, route exchange is automatically enabled only between peers in the BGP-IPv4 unicast address family. That is, after the peer as-number command is run in the BGP view, the system automatically configures the peer enable command. In other address family views, however, a peer must be enabled manually.

Configuration Impact

Once a BGP peer of a specified address family is enabled or disabled, for example, running the peer enable or undo peer enable command in the EVPN address family view, the BGP connection to the peer in another address family is disconnected and re-negotiated.

Precautions

If the device has established peer relationships with a peer in other address families, running the peer enable command may disconnect and re-establish all peer relationships with the peer, causing route flapping. Therefore, exercise caution when running this command. When you run this command in this case, the following warning is displayed:

Warning: This operation will reset the peer session. Continue? [Y/N]:

Enter y if you confirm to execute this command.

By default, the routes that are learned from IBGP peers in the EVPN address family and leaked into BGP VPN instances are advertised to IBGP peers in the VPN instances, potentially causing routing loops. It is advised to configure loop prevention mechanisms such as SoO to prevent loops.

By default, the routes learned from IBGP peers in the BGP-VPN instance IPv4 address family or BGP-VPN instance IPv6 address family and reported to EVPN are advertised to EVPN IBGP peers.

Example

# Enable a device to exchange routing information with a specified peer in the BGP-EVPN address family view. 
<HUAWEI> system-view
[HUAWEI] bgp 100
[HUAWEI-bgp] peer 1.1.1.9 as-number 100
[HUAWEI-bgp] l2vpn-family evpn
[HUAWEI-bgp-af-evpn] peer 1.1.1.9 enable
