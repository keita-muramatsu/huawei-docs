pppoe-client dialer

Function

The pppoe-client dialer command specifies a dialer interface for a PPPoE session.

The undo pppoe-client dialer command deletes the mapping between a PPPoE session and a dialer interface.

By default, no dialer interface is specified for a PPPoE session.

Format

pppoe-client dialer number bundle-number bundle-number [ ppp-max-payload value | service-name name ] *

undo pppoe-client dialer number [ bundle-number bundle-number [ ppp-max-payload value | service-name name ] * ]

Parameters

Parameter Description Value
bundle-number bundle-number

Specifies the number of the dialer bundle corresponding to the PPPoE session. The number of a dialer bundle uniquely identifies a PPPoE session.

The value is an integer ranging from 1 to 255.
ppp-max-payload value

Specifies the maximum MTU during PPP negotiation of PPPoE session establishment.

The value is an integer that ranges from 64 to 2000. By default, the maximum MTU during PPP negotiation of PPPoE session establishment is 1500 bytes.
service-name name

Specifies the value of the Service-Name field in packets sent by the PPPoE client at the Discovery stage.

If multiple PPPoE servers exist on the link of a specified interface, you can specify a PPPoE server to be connected using this parameter. The value of service-name is provided by a carrier. If there is only one PPPoE server on the link of the specified interface, you do not need to specify this parameter.

The value is a string of 1 to 128 case-sensitive characters, excluding question marks (?).

By default, this parameter is not specified, indicating that the device attempts to set up a session with the first reachable PPPoE server on the link.
dialer number

Specifies the number of the dialer interface corresponding to the PPPoE session.

For the AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S and AR5710-S10T1X2:The value is an integer that ranges from 0 to 31.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR8700 series, AR8100 series and AR6700-H series:The value is an integer in the range from 0 to 1023.

Views

10GE sub-interface view, 10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE sub-interface view, 40GE interface view, GE sub-interface view, GE interface view, Multi-GE sub-interface view, Multi-GE interface view, Ethernet interface view, Ethernet sub-interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The device functions as a PPPoE client to connect to LAN users, and the PPPoE server is a carrier's device. It is not necessary for all hosts on the LAN to have the PPPoE client dial-up software installed; instead, they share the same account and establish PPPoE sessions with the PPPoE server through the device. This command is used to enable the PPPoE client function on an Ethernet interface or Ethernet sub-interface. Multiple PPPoE sessions can be configured on an Ethernet interface or Ethernet sub-interface.

Precautions

After being bound to an Ethernet interface for PPPoE session setup, a dialer interface and a dialer bundle cannot be bound to any other interface.

If specified, the value of service-name must be the same as that provided by the carrier. Otherwise, the device cannot connect to the carrier network.

Example

# Set up a PPPoE session on 10GE0/0/1.
<HUAWEI> system-view
[HUAWEI] interface Dialer 1
[HUAWEI-Dialer1] quit
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] pppoe-client dialer 1 bundle-number 1
