lldp tlv-disable legacy-tlv four-pair-power (AP wired port link profile view)

Function

The lldp tlv-disable legacy-tlv four-pair-power command disables an AP's wired interface from advertising Cisco proprietary TLVs.

The undo lldp tlv-disable legacy-tlv four-pair-power command configures an AP's wired interface to advertise Cisco proprietary TLVs.

By default, an AP wired interface advertises Cisco proprietary TLVs.

Format

lldp tlv-disable legacy-tlv four-pair-power

undo lldp tlv-disable legacy-tlv four-pair-power

Parameters

None

Views

AP wired port link profile view

Default Level

2: Configuration level

Usage Guidelines

Some Cisco switches use proprietary LLDP TLVs to negotiate UPoE power supply. If such a switch is used to provide power for UPoE-capable APs, enable UPoE on the AP's wired interface connected to the switch so that the AP's wired interface advertises Cisco proprietary TLVs to negotiate the UPoE power supply mode, otherwise, LLDP negotiation fails and the Cisco switch does not provide UPoE power supply. As a result, the input power of the AP is insufficient and the AP cannot work properly.

Example

# Disable an AP wired interface from advertising Cisco proprietary TLVs.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] port-link-profile name port-link1
[HUAWEI-wlan-port-link-prof-port-link1] lldp tlv-disable legacy-tlv four-pair-power
