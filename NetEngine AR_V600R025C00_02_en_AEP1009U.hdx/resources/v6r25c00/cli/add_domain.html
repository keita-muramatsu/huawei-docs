add domain

Function

The add domain command adds members to a domain group.

The undo add domain command deletes members from a domain group.

The undo domain all command deletes all members from a domain group.

By default, this function is not configured.

Format

add domain domain-name

undo add domain domain-name

undo domain all

Parameters

Parameter Description Value
domain domain-name

Specifies a domain member.

The value is a string of 1 to 255 case-insensitive characters. The following characters are not supported: @\:*"<>|#='&. The value cannot contain consecutive periods (.) or end with a period (.).

If the entered domain name contains the wildcard * (only the wildcard * is supported and other wildcards are not supported), the length of the domain name ranges from 5 to 255 characters. The value can contain only one wildcard * and must start with *. Only two to four periods (.) are allowed. The format must be *.X.X, *.X.X.X, or *.X.X.X.X. The length of each segment between two periods cannot exceed 63 characters.

  • Correct example:
    • www.test.com
    • *.test.com
    • *.test.test1.com
  • Incorrect example:
    • www.test.com.
    • test.*.com
    • *..test
    • *.test.com.
all

Indicates all domain names.

-

Views

Domain group view

Default Level

2: Configuration level

Usage Guidelines

If a DNS server is configured, after you run the add domain command to add a domain name to a domain group, the device proactively requests the domain name IP address from the DNS server and binds the domain name IP address to the domain group. At the same time, a timer is triggered to send an IP address update request so that the IP address corresponding to the domain name can be updated in time.

If domain-name is a domain name containing the wildcard (*), the device cannot learn the mapping between domain names and IP addresses from the DNS server.

Example

# Delete all domain names in domain group set1. 
<HUAWEI> system-view
[HUAWEI] domain-set name set1
[HUAWEI-domain-set-set1] undo domain all
# Create domain group set1 and add example.com to set1. 
<HUAWEI> system-view
[HUAWEI] domain-set name set1
[HUAWEI-domain-set-set1] add domain example.com
