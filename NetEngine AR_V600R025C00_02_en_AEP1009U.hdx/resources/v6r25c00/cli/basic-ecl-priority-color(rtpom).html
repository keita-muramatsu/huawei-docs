ip extcommunity-list priority-color basic

Function

The ip extcommunity-list priority-color basic command configures a basic priority-color extended community filter.

The undo ip extcommunity-list priority-color basic command deletes a specified basic priority-color extended community filter.

By default, no basic priority-color extended community filter is configured.

Format

ip extcommunity-list priority-color basic basic-extcomm-filter-name [ index index-value ] matchMode { priority-color-value } &<1-16>

undo ip extcommunity-list priority-color basic basic-extcomm-filter-name [ index index-value ] [ matchMode { priority-color-value } &<1-16> ]

Parameters

Parameter Description Value
basic-extcomm-filter-name

Specifies the name of a basic priority-color extended community filter.

The value is a string of 1 to 51 case-sensitive characters. It cannot be comprised of only digits. If spaces are used, the string must start and end with double quotation marks (").
index index-value

Specifies the index of a basic priority-color extended community filter.

The value is an integer ranging from 1 to 4294967295.
matchMode

Specifies a matching mode for a basic priority-color extended community filter.

The value is an enumerated type:

  • permit: sets the matching mode of the priority-color extended community filter to permit.
  • deny: sets the matching mode of the priority-color extended community filter to deny.
priority-color-value

Specifies priority-color extended community attribute values for a basic priority-color extended community filter.

The value of the priority-color extended community attribute consists of the priority and color value, in the format of priority:color value, for example, 1:100. The value of the priority ranges from 0 to 15. The color value can be used to identify a site, and ranges from 1 to 4294967295.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In scenarios where an SD-WAN tunnel needs to be established based on BGP EVPN routes, you can set the priority-color extended community attribute for EVPN routes to identify the next-hop sites of the EVPN routes. The priority-color extended community attribute is used to generate SD-WAN tunnel encapsulation information so that a device can forward packets through the SD-WAN tunnel.

To configure a basic priority-color extended community filter, run the ip extcommunity-list priority-color basic command. The filter can be used as a filtering rule of a route-policy. For example, the if-match extcommunity-list priority-color aaa command configures a filtering rule that is based on the priority-color extended community filter named aaa.

Only values of the priority-color extended community attribute can be specified as matching conditions in a basic priority-color extended community filter, whereas regular expressions can be specified as matching conditions in an advanced priority-color extended community filter.

The relationship between the matching conditions in a priority-color extended community filter is OR.

For example, the priority-color extended community filter configurations in the following formats indicate the same filtering result:

Format 1:

ip extcommunity-list priority-color basic 1 permit 1:100 2:200 3:300

The relationship among 1:100, 2:200, and 3:300 is OR.

Format 2:

ip extcommunity-list priority-color basic 1 permit 1:100

ip extcommunity-list priority-color basic 1 permit 2:200 3:300

The relationship among 1:100, 2:200, and 3:300 is OR.

In the preceding configurations, at least one of the specified priority-color extended community attribute values must belong to the priority-color extended community list carried in routes so that the routes can match the filter.

To check detailed configurations of priority-color extended community filters, run the display ip extcommunity-filter priority-color command.

Precautions

The default action of a Priority-Color extended community filter is deny. That is, if a route is not permitted by a filtering rule, the route cannot pass the filtering of the filter. If all the filtering rules in a filter are in deny mode, no route can pass the filter. To prevent this problem, configure a filtering rule in permit mode after configuring one or more filtering rules in deny mode. This allows other routes to pass the filter.

A basic Priority-Color extended community filter and an advanced one cannot both be configured.

A maximum of 65535 basic Priority-Color extended community filters are supported.

A single basic Priority-Color extended community filter supports a maximum of 65535 nodes.

All basic Priority-Color extended community filters support a maximum of 65535 nodes.

Example

# Configure a basic priority-color extended community filter named aa.
<HUAWEI> system-view
[HUAWEI] ip extcommunity-list priority-color basic aa permit 1:100 2:200
