display srv6-te flow-group last-down-reason

Function

The display srv6-te flow-group last-down-reason command displays records about events where SRv6 TE Flow groups go down.

Format

display srv6-te flow-group last-down-reason [ endpoint ipv6-addr color color-value ]

display srv6-te flow-group last-down-reason endpoint ipv6-addr

Parameters

Parameter Description Value
endpoint ipv6-addr

Specifies the endpoint of an SRv6 TE flow group.

The value is a 32-bit hexadecimal string in format X:X:X:X:X:X:X:X.
color color-value

Specifies the color of an SRv6 TE flow group.

The value is an integer ranging from 0 to 4294967295.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

The display srv6-te flow-group last-down-reason command displays records about events where SRv6 TE Flow groups go down.
