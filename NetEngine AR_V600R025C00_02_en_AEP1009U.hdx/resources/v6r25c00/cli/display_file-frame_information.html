display file-frame information

Function

The display file-frame information command displays file framework resource information.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

display file-frame information [ slot slot-id cpu cpu-id ]

Parameters

Parameter Description Value
slot slot-id

Specifies a slot ID.

The value is an integer. The value displayed on the device is used.
cpu cpu-id

Specifies the CPU ID.

The value is an integer. The value displayed on the device is used.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

This command displays file framework resource information.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display file framework resource information.
<HUAWEI> display file-frame information
File frame information on slot x cpu y:
  File frame configrations :
----------------------------------------------------------------------------
    Max decompression depth    :          3
    File frame detect timeout  :          4
    File frame restore timeout :         10
----------------------------------------------------------------------------
Table 1 Description of the display file-frame information command output
Item Description
File frame configrations

File framework configuration information.
File frame detect timeout

Timeout interval for checking the file framework.
File frame restore timeout

Timeout interval for restoring the file framework.
File frame information on slot x cpu y

File framework information.
Max decompression depth

Maximum number of layers that can be decompressed.
