display portal user-logout

Function

The display portal user-logout command displays temporary logout entries of Portal authentication users.

Format

display portal user-logout [ ip-address ip-address [ vpn-instance vpn-instance ] ]

Parameters

Parameter Description Value
ip-address ip-address

Displays temporary logout entries of the Portal authentication user with a specified IP address.

The value is in dotted decimal notation.
vpn-instance vpn-instance

Specifies a VPN instance name.

The value is a string of 1 to 31 case-sensitive characters.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

After a Portal authentication user goes offline, the device sends a logout request packet to the Portal server. If the device does not receive an ACK packet from the Portal server, the device records the temporary entry of the offline user. You can run the display portal user-logout command to check temporary logout entries of Portal authentication users.

If ip-address ip-addressis not specified, temporary logout entries of all Portal authentication users are displayed.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display temporary logout entries of all Portal authentication users.
<HUAWEI> display portal user-logout
 --------------------------------------------------------------                                                                     
 UserIP           Vrf      Resend Times TableID                                                                                     
 --------------------------------------------------------------                                                                     
 192.168.111.100  0        3            0                                                                                           
 --------------------------------------------------------------                                                                     
 Total: 1, printed: 1
Table 1 Description of the display portal user-logout command output
Item Description
UserIP

IP address of a Portal authentication user.
Vrf

VPN instance to which Portal authentication users belong.
Resend Times

Number of times logout packets are retransmitted.

To set this parameter, run the portal logout resend timeout command.
TableID

Index of a temporary logout entry.
Total: m, printed: n

Total number (m) of temporary logout entries and number (n) of printed entries.
