display security-profile

Function

The display security-profile command displays configuration and reference information about a security profile.

Format

display security-profile { name profile-name | all }

Parameters

Parameter Description Value
name profile-name

Displays information about a specified security profile.

The security profile name must exist.
all

Displays information about all security profiles.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run this command to view configuration and reference information about a security profile.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display information about all security profiles.
<HUAWEI> display security-profile all
Total: 2

Item Description
Profile name

Name of the security profile.
Reference

Number of times the security profile is applied.
Security policy

Security policy. The system security policies are as follows:

  • Open system: WEP open system.
  • WPA 802.1x: WPA-802.1X.
  • WPA2 802.1x: WPA2-802.1X.
  • WPA-WPA2 802.1x: WPA-WPA2-802.1X.
  • WPA PSK.
  • WPA2 PSK.
  • WPA-WPA2 PSK.
  • WPA PPSK.
  • WPA2 PPSK.
  • WPA-WPA2 PPSK.
  • WPA3 SAE.
  • WPA3 802.1x: WPA3-802.1X.
  • WPA2-WPA3 PSK-SAE.
  • WAPI PSK.
  • WAPI certificate.
  • OWE.
  • -: No security policy.

To configure this parameter, run the security dot1x, security psk, security wpa2-wpa3 psk-sae, security wpa3 sae, security wpa3 dot1x, security enhanced-open aes, or security wapi command.
Encryption

Encryption mode. The following encryption modes are supported: GCMP256, TKIP, AES, AES-TKIP, SM4, and GCM-SM4. The WAPI encryption mode is fixed to SM4 or GCM-SM4, the hybrid WPA3-SAE+WPA2-WPA3 encryption mode is fixed to AES, and the WPA3-802.1X encryption mode is fixed to GCMP256, and the OWE encryption mode is fixed to AES.

To configure this parameter, run the security dot1x, security wpa2-wpa3 psk-sae, security wpa3 sae, security wpa3 dot1x, security enhanced-open aes, or security psk command.
Key key-id

Key ID.
Key negotiation

Key negotiation.
Default key ID

Default key ID.
PTK update

Whether periodic PTK update is enabled during WPA/WPA2/WPA-WPA2/WPA3 encryption.

  • enable: The function is enabled.
  • disable: The function is disabled.

To configure this parameter, run the wpa ptk-update enable command.
PTK update interval(s)

PTK update interval during WPA/WPA2/WPA-WPA2/WPA3 encryption. The value is an integer, in seconds.

To configure this parameter, run the wpa ptk-update ptk-update-interval command.
Unicast time out kick sta

Whether the device disconnects STAs when it does not receive the last unicast key negotiation packet from the STAs.

To configure this parameter, run the wpa unicast-key-negotiation time-out kick-sta enable command.
Group key negotiation

Whether WPA key negotiation for multicast traffic is enabled.

To configure this parameter, run the wpa group-key-negotiation disable command.

Name of the CA certificate file.

Name of the ASU certificate file.

Name of the AC certificate file.

Name of the AC private key file.
AC local key pair name

Name of the local key pair on the AC.
Authentication server IP

IP address of the ASU certificate server.
WAI timeout(s)

Timeout period of a security association.

To configure this parameter, run the wapi sa-timeout command.
BK update interval(s)

Interval for updating the BK.
BK lifetime threshold(%)

BK lifecycle threshold.
USK update method

USK update mode.

To configure this parameter, run the wapi key-update command.
USK update interval(s)

Interval for updating the USK.
USK negotiate retrans count

Number of retransmissions of USK negotiation packets.
MSK update method

MSK update mode.

To configure this parameter, run the wapi key-update command.
MSK update interval(s)

Interval for updating the MSK.
MSK negotiate retrans count

Number of retransmissions of MSK negotiation packets.
Cert auth retrans count

Number of retransmissions of certificate authentication packets.
PMF

Whether the Protected Management Frame (PMF) function of a VAP is enabled.

  • disable: This function is disabled.
  • optional: This function is enabled in optional mode.
  • mandatory: This function is forcibly enabled.

This field is displayed only when the authentication and encryption mode is WPA2-AES, WPA3, or OWE.

To configure this parameter when the authentication mode is WPA2-AES, run the pmf command. When the authentication mode is WPA3, this parameter is unconfigurable. The value of this parameter is fixed at mandatory when the authentication mode is WPA3-SAE or WPA3-802.1X or optional when the authentication mode is WPA2-WPA3. When the authentication mode is OWE or its transition mode, the value of this parameter is fixed at mandatory.

PKI Domain.
