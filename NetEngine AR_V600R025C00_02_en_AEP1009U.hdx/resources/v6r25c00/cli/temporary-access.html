temporary-access

Function

The temporary-access command configures a temporary access identity of a user, including the temporary user name and UCL group name.

The undo temporary-access command deletes a temporary access identity of a user.

By default, no escape policy is configured.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR5710-S8P1XDSE-2LTE4EA.

Format

temporary-access username user-name ucl-group group-name

undo temporary-access username user-name ucl-group group-name

Parameters

Parameter Description Value
ucl-group group-name

Specifies the name of a UCL group. The UCL group name must exist and only security groups are supported.

The value is a case-sensitive string. If the security group name does not contain spaces, the length is 1 to 253 bytes. If the security group name contains spaces, the length is 3 to 255 bytes and the security group name must be enclosed in double quotation marks (""), for example, "security group for test".
username user-name

Specifies a user name.

The value is a string of 1 to 128 characters if the user name does not contain spaces. If the user name contains spaces, the value is a string of 3 to 130 characters and must be enclosed in double quotation marks (""), for example, "user for test."

Views

Identity Management View

Default Level

2: Configuration level

Usage Guidelines

After a temporary access identity is configured for a user, if the user in the IP address set configured for TSM SSO cannot obtain the user identity from the TSM server, the user goes online using the configured temporary access identity.

If a local access user with the same name as the temporary user name is configured on the device, the device uses the configured temporary identity instead of the UCL group relationship configured for the local access user.

Example

# Configure an escape policy.
<HUAWEI> system-view
[HUAWEI] ucl-group name g1 type security
[HUAWEI] identity-management
[HUAWEI-identity-management] temporary-access username u1 ucl-group g1
