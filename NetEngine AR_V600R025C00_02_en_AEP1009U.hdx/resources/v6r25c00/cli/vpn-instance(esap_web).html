vpn-instance

Function

The vpn-instance command configures a VPN instance used by the device to communicate with the Portal server.

The undo vpn-instance command restores the default configuration.

By default, no VPN instance is configured for the device to communicate with the Portal server.

Format

vpn-instance vpn-instance-name

undo vpn-instance

Parameters

Parameter Description Value
vpn-instance-name

Specifies a VPN instance name.

The value is a string of 1 to 31 case-sensitive characters. The VPN instance name cannot be _public_. The character string can contain spaces if it is enclosed with double quotation marks (").

Views

Web-auth-server template view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

A VPN implements interconnection within the same department and between different departments in an enterprise. To apply Portal authentication to a VPN, run the vpn-instance command to bind a Portal server template to a VPN instance.

Prerequisites

A VPN instance has been created using the ip vpn-instance command, and a Portal server template has been created using the web-auth-server command.

Example

# Configure the VPN instance named vpn1 in the Portal server template abc.
<HUAWEI> system-view
[HUAWEI] ip vpn-instance vpn1
[HUAWEI-vpn-instance-vpn1] ipv4-family
[HUAWEI-vpn-instance-vpn1-af-ipv4] quit
[HUAWEI-vpn-instance-vpn1] quit
[HUAWEI] web-auth-server abc
[HUAWEI-web-auth-server-abc] vpn-instance vpn1
