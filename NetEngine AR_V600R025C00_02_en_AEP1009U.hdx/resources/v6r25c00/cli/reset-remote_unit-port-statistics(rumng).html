reset remote-unit port statistics

Function

The reset remote-unit port statistics command clears the statistics on interfaces of an RU.

Format

reset remote-unit port [ portid ] statistics [ connect-interface { interface-name | interface-type interface-number } | name remote-unit-name ]

Parameters

Parameter Description Value
portid

Specifies the port index of a remote module.

The value is an integer in the range from 1 to 34. If the specified interface index is larger than the largest one on the RU, the command is not issued to the RU. port-id indicates the port ID of an RU, which may be different from the physical port number printed on the panel. For example, if the downlink port numbers are 1 to 8 and the uplink port numbers are 9 to 10 on the panel, set port-id to an integer in the range from 1 to 10 according to the actual port for connection. If the downlink port numbers are 1 to 8 and the uplink port numbers are 1 to 2 on the panel, set port-id to an integer in the range from 1 to 10 (1 to 8: downlink ports; 9: uplink port 1; 10: uplink port 2).
connect-interface interface-name

Specifies the name of an interface.

The value is a string of 1 to 31 characters and must be set according to the device configuration.
connect-interface interface-type interface-number

Specifies the type and number of an interface. You can enter a space between the interface type and the interface number.

The value must be set according to the device configuration.
name remote-unit-name

Specifies the alias of a remote module.

The value is a string of 1 to 32 case-sensitive characters. It cannot contain spaces.

Views

User view

Default Level

2: Configuration level

Usage Guidelines

Packet statistics on RU interfaces can be collected. Before querying the traffic statistics on an interface within a certain period, run this command to clear the statistics on the interface. Then run the display remote-unit port statistics command to view new statistics.

Example

# Clear statistics on the interfaces of all RUs.
<HUAWEI> reset remote-unit port statistics
Info: This operation will take several seconds. Please wait...
# Clear statistics on interface 1 of the RU connected to 10GE0/0/1.
<HUAWEI> reset remote-unit port 1 statistics connect-interface 10GE 0/0/1
Info: This operation will take several seconds. Please wait...
