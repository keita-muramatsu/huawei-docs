path-index(SIG path index)

Function

The path-index sig-tunnel command specifies the SIG path index.

The undo path-index sig-tunnel command deletes the specified SIG path index.

By default, no SIG path index is specified.

Format

path-index index sig-tunnel tunnel-number [ track nqa nqa-admin-name nqa-test-name ] [ backup-tunnel backup-tunnel-number [ track nqa backup-nqa-admin-name backup-nqa-test-name ] ]

undo path-index index [ sig-tunnel tunnel-number [ track nqa nqa-admin-name nqa-test-name ] [ backup-tunnel backup-tunnel-number [ track nqa backup-nqa-admin-name backup-nqa-test-name ] ] ]

Parameters

Parameter Description Value
sig-tunnel tunnel-number

Specifies the number of a SIG tunnel.

The value is an integer ranging from 0 to 4095.
track nqa backup-nqa-admin-name

Specifies the administrator name of an NQA test instance.

The value is a string of 1 to 32 characters, excluding question marks (?), en dashes (-), a single or consecutive quotation marks (").
track nqa backup-nqa-test-name

Specifies the name of an NQA test instance.

The value is a string of 1 to 32 characters, excluding question marks (?), en dashes (-), a single or consecutive quotation marks (").
track nqa nqa-admin-name

Specifies the administrator name of an NQA test instance.

The value is a string of 1 to 32 characters, excluding question marks (?), en dashes (-), a single or consecutive quotation marks (").
track nqa nqa-test-name

Specifies the name of an NQA test instance.

The value is a string of 1 to 32 characters, excluding question marks (?), en dashes (-), a single or consecutive quotation marks (").
backup-tunnel backup-tunnel-number

Specifies the ID of the backup SIG tunnel.

The value is an integer ranging from 0 to 4095.
path-index index

Specifies the index of a SIG path.

The value is an integer ranging from 11 to 20.

Views

saas-cloud-express view

Default Level

2: Configuration level

Usage Guidelines

SaaS applications can be accessed through multiple local ISP links or through a secure web gateway (SWG), also known as a secure Internet gateway (SIG). This command is used to specify a SIG path index when SaaS applications are accessed through the SIG. For the path, track nqa is used to detect link connectivity. When the link is normal, the path can be selected for SaaS traffic steering. When the link is disconnected, the path is not selected for SaaS traffic steering.

Example

# Configure interface Tunnel1 on the router and set the path index of the interface to 11.
<HUAWEI> system-view
[HUAWEI] interface Tunnel 1
[HUAWEI-Tunnel1] tunnel-protocol gre
[HUAWEI-Tunnel1] quit
[HUAWEI] saas-cloud-express
[HUAWEI-saas-cloud-express] path-index 11 sig-tunnel 1
