session-car enable

Function

The session-car enable command enables the session CAR function.

The undo session-car enable command disables the session CAR function.

By default, the session CAR function is disabled for all protocols.

Format

session-car packet-type enable

undo session-car packet-type enable

Parameters

Parameter Description Value
packet-type

Specifies the packet type.

The value can be bgp, bgp4plus, ospf, or ospfv3.

Views

Attack defense policy view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When session packets are sent to the CPU through protocol association, if the number of protocol packets of a session is too large and the rate of packets of the same protocol exceeds the protocol association CAR for the protocol, it will affect the sending of packets of other sessions. As a result, packets are discarded and protocol flapping occurs. Session CAR takes effect for specified protocol packets only after you run this command to configure the session CAR function for the protocol packets and a connection is established. The protocol packets of a new connection are assigned to an independent queue, implementing CAR for a single session.

Precautions

The session CAR function relies on the protocol association function, so you must run the application-apperceive enable command to enable protocol association first. Otherwise, session CAR cannot be enabled.

Example

# Enable the session CAR function for BGP packets.
<HUAWEI> system-view
[HUAWEI] cpu-defend policy test
[HUAWEI-cpu-defend-policy-test] session-car bgp enable
