ztp usb-deployment enable

Function

The ztp usb-deployment enable command enables USB-based deployment for a configured device.

The undo ztp usb-deployment enable command disables USB-based deployment for a configured device.

By default, USB-based deployment is disabled for a device with configurations.

Format

ztp usb-deployment enable

undo ztp usb-deployment enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

By default, USB-based deployment can be performed on a device with empty configuration. You can run this command to enable USB-based deployment for a device with configurations.

Precautions

  1. After USB-based deployment is enabled, the system attempts to perform USB-based deployment within 30 seconds.
  2. If the USB-based deployment fails, the system attempts to deploy the device again 30 seconds later.
  3. If USB-based deployment is disabled during the waiting period, after the waiting period ends, USB-based deployment is not performed.
  4. If you disable USB-based deployment and then enable USB-based deployment during the waiting period, USB-based deployment will be performed after the waiting period ends.
  5. USB-based deployment can be performed only when this function is enabled and the current configuration file of the device exists.

Example

# Enable the USB-based deployment capability for a configured device.
<HUAWEI> system-view
[HUAWEI] ztp usb-deployment enable
