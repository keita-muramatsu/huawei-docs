ospf memory-overload control disable

Function

The ospf memory-overload control disable command disables OSPF memory overload control.

The undo ospf memory-overload control disable command restores the default configuration.

By default, OSPF memory overload control is enabled.

Format

ospf memory-overload control disable

undo ospf memory-overload control disable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When the system memory is overloaded, each module needs to take necessary measures to control the memory usage. Upon receiving a memory overload notification from the system, the OSPF module no longer imports new routes and starts to control neighbor relationship establishment based on the memory overload condition to enhance OSPF resilience. In this case, new neighbor relationships cannot be established. For existing neighbor relationships, if they are in the Full state, they will be retained; if they are in a non-Full state, they are not reestablished until the memory recovers from overload.

Precautions

This command takes effect for both OSPF and OSPFv3.

When the memory is overloaded, if you run the undo ospf memory-overload control disable command to enable the memory overload control function of OSPF, OSPF does not enter the memory overload state until the memory overload message changes next time.

The memory overload control function requires the memory overload reliability function to be enabled using the memory-usage reliability switch on command.

Example

# Disable OSPF memory overload control.
<HUAWEI> system-view
[HUAWEI] ospf memory-overload control disable
