security wapi

Function

The security wapi command configures the WAPI authentication mode.

By default, no security policy is configured. To restore the default security policy, run the undo security command.

Format

security wapi psk { pass-phrase key-value | hex hex-value } [ gcm-sm4 ]

security wapi certificate [ gcm-sm4 ]

Parameters

Parameter Description Value
pass-phrase key-value

Specifies the key phrase.

Displays the user password in ciphertext.

In pass-phrase mode, the value is a string of 8 to 63 characters in plaintext, or 48, 68, 88, 108, 128, 148, 168, or 188 characters in ciphertext.

A password cannot contain the space and double quotation mark (") at the same time. When the password contains a space, enclose the string with double quotation marks (") when entering the value. For example, if the password is YsHsjx 202206, enter "YsHsjx 202206".

For security purposes, you are advised to configure a key that contains at least two of the following: digits, lowercase letters, uppercase letters, and special characters.
hex hex-value

Displays the user password in cipher text. The value is a hexadecimal number.

The hex does not support password complexity check. You are advised to use pass-phrase.

In hex mode, the value is a string of 8 to 32 hexadecimal numbers, in which the length of the string must be an even, or a string of 48, 68, 128, or 148 characters in ciphertext.

A password cannot contain the space and double quotation mark (") at the same time. When the password contains a space, enclose the string with double quotation marks (") when entering the value. For example, if the password is YsHsjx 202206, enter "YsHsjx 202206".

For security purposes, you are advised to configure a key that contains at least two of the following: digits, lowercase letters, uppercase letters, and special characters.
gcm-sm4

Specifies the WAPI-GCM-SM4 cipher suite.

-
certificate

Configures WAPI certificate authentication.

-
psk

Configures WAPI pre-shared key authentication.

-

Views

Security profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

WAPI supports two authentication modes: certificate authentication and PSK authentication. When PSK authentication is used, a PSK must be configured.

  • If WAPI authentication is specified as a security policy in a security profile, you can run this command to configure the WAPI authentication mode.
  • This command determines the WAPI authentication and key management mode. When certificate authentication and key management are configured, authentication involves identity authentication and key negotiation, and the authentication server and certificate need to be configured. When PSK authentication is configured, a PSK needs to be configured, and STAs also need to know the PSK. In this case, authentication only involves key negotiation.

Precautions

Upon the command execution, the system displays the prompt message only when the security profile has been bound to other profiles.

If the password is changed to one starting or ending with a space on the device (example: huawei123abc ), some terminals (such as terminals running Windows 7) may filter out the space when you change the password on the terminals. This will lead to an association failure. Therefore, it is not recommended that a password starting or ending with a space be set on the device. If such a password has been configured on the device, delete the existing SSID on a terminal, reassociate the terminal with the SSID, and enter the password. For detailed terminal types, refer to the Test Report on Terminal Compatibility.

For security purposes, you are advised to configure a value that contains at least two of the following: digits, lowercase letters, uppercase letters, and special characters.

The key cannot have $@$@, ^#^#, %$%$, %@%@, or @$@$ as the prefix or suffix. If the key is a string of 24 characters, it cannot end with two exclamation marks (!!) or a pound sign (#).

Example

# Configure the WAPI-PSK mode that supports the GCM-SM4 encryption algorithm.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan-view] security-profile name p1
[HUAWEI-wlan-sec-prof-p1] security wapi psk pass-phrase YsHsjx_202206 gcm-sm4
Warning: This configuration may cause STAs that do not support GCM-SM4 to fail to access the network. Continue? [Y/N]:Y
# Set the authentication mode to pre-shared key authentication and specify the key.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] security-profile name p1
[HUAWEI-wlan-sec-prof-p1] security wapi psk pass-phrase YsHsjx_202206
