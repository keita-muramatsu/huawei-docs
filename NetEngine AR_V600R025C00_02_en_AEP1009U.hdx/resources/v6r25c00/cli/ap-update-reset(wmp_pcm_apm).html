ap update reset

Function

The ap update reset command restarts and upgrades a specified AP.

Format

ap update reset { ap-mac ap-mac-value | ap-id ap-id-value }

Parameters

Parameter Description Value
ap-mac ap-mac-value

Specifies the MAC address of the AP to be restarted and upgraded.

The value is in H-H-H format. H is a hexadecimal number that contains one to four digits, such as 00e0 and fc01. If an H contains fewer than four digits, the leftmost digits are padded with 0s. For example, two 0s are added to e0 to form 00e0.
ap-id ap-id-value

Specifies the ID of the AP to be restarted and upgraded.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.

Views

WLAN view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

After an AP has been upgraded, run this command to restart it to make the AP upgrade take effect.

Prerequisites

The AP is in normal or vmiss state.

The ap update load { ap-mac ap-mac| ap-id ap-id} update-filename update-file-namecommand has been executed to configure the AP upgrade, and the display ap update status command has been executed to verify that the Update Status field in the command output is succeed(need reset).

Example

# Restart the AP with the ID 1, which has been upgraded.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap update load ap-id 1 update-filename AirEngineX776-V600R025C00.cc
[HUAWEI-wlan] ap update reset ap-id 1
Warning: Reset the AP to make the upgrade take effect. Continue?[Y/N]:y
