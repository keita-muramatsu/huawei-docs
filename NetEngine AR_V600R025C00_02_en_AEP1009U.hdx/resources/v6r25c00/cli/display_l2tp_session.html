display l2tp session

Function

The display l2tp session command displays information about L2TP sessions established on the device.

Format

display l2tp session { brief | all | session-id session-id | destination-ip dest-ip-addr | source-ip src-ip-addr }

Parameters

Parameter Description Value
brief

Displays brief information.

-
all

Displays information about all tunnels.

-
session-id session-id

Specifies the local session ID of an L2TP session.

The value is an integer ranging from 1 to 1024.
destination-ip dest-ip-addr

Specifies the peer IP address of an L2TP tunnel.

The value is in dotted decimal notation.
source-ip src-ip-addr

Specifies the local IP address of an L2TP tunnel.

The value is in dotted decimal notation.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

After an L2TP session is established, you can run the display l2tp session command to view L2TP session information, including the total number of established L2TP sessions, session IDs, and information about the local end and remote end.

Prerequisites

The L2TP session is successfully established.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display information about session 1.
<HUAWEI> display l2tp session session-id 1
------------------------------------------------------------------------
Local Info:
  Session ID     : 1            Tunnel Name      : lac
  Negotiation IP : 1.1.1.3      Negotiation Port : 1701
  State          : UP           Interface        : Dialer1
  Tunnel ID      : 1            Nego Interface   : GE0/0/1
  Group Number   : 1            Last Fail Reason : --
                                Last Fail Time   : --
Remote Info:
  Session ID     : 1            Tunnel Name      : lns
  Tunnel IP      : 1.1.1.4      Tunnel Port      : 1701
  Tunnel ID      : 2
------------------------------------------------------------------------

------------------------------------------------------------------------
