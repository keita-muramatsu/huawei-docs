report-sta-info enable

Function

The report-sta-info enable command enables an AC to report information about STA traffic statistics and online duration on APs.

The undo report-sta-info enable command disables an AC from reporting information about STA traffic statistics and online duration on APs.

By default, an AC is disabled from reporting information about STA traffic statistics and online duration on APs.

Format

report-sta-info enable

undo report-sta-info enable

Parameters

None

Views

WLAN view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

You can run this command to enable a WAC to report information about STA traffic statistics and online duration on APs. The STA traffic statistics include the WAC's MAC address, WAC name, APs' MAC addresses, AP names, radio IDs, SSID, user names, STAs' MAC addresses, and STA's going-offline reason. With this function, the WAC logs STA traffic statistics and the STAs' online duration on APs when STAs go offline or roam within the WAC.

Precautions

Enabling this function will generate a large number of logs. If there are a large number of STAs, log files may overwrite each other due to limited storage space, which affects fault locating. If this function must be enabled, you are advised to configure a log server to report logs.

Example

# Enable an AC to report information about STA traffic statistics and online duration on APs.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] report-sta-info enable
Warning: This operation will generate a large number of logs, which may overwrite other logs. 
Configuring a log server is recommended. Continue?[Y/N]:y
