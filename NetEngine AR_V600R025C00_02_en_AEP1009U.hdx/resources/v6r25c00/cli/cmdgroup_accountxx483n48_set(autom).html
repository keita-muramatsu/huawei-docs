user(net-assistant system-management view)

Function

The user command configures a network-wide username and password.

The undo user command deletes the network-wide username and password.

By default, no network-wide username or password is configured.

Format

user name-paravalue password [ password-paravalue ]

undo user name-paravalue

Parameters

Parameter Description Value
name-paravalue

Specifies a network-wide username.

The value is a string of 6 to 32 case-insensitive characters, spaces not supported.
password password-paravalue

Specifies a network-wide password.

The value is a string of 8 to 128 characters in plaintext or 32 to 268 characters in ciphertext. The password cannot be the same as the username or the username in reverse order. The password must contain uppercase letters, lowercase letters, digits, and special characters.

Special characters do not include question marks (?) and spaces.

Views

Net-assistant system-management view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

  • You can run this command on the master device to configure a network-wide username and password. After a member device is approved, the username and password are delivered to the member device.
  • The member device uses the username and password to create a local administrator username and password, sets the user level to 3, and sets the user access type to SSH, HTTP, or terminal. For member devices running V600, the function of forcibly changing the password (configured when the user is created) upon the first login of the administrator is disabled. If a user with the same name exists, the password and user level are delivered in overwriting mode, and the user access type is delivered in incremental mode. For member devices running V300 or V200, if a user with the same name exists, the password, user level, and user access type are delivered in overwriting mode.

Precautions

If the command is run more than once, the latest configuration overrides the previous one.

When the configuration is modified or deleted, the previous username and password are recorded as historical user information. A maximum of two historical users are allowed.

When the master device attempts to establish a connection with a member device, the current user and historical users are used for user authentication. If all the three users fail the authentication, the connection fails to be established.

Example

# Configure a network-wide username huawei and password YsHsjx_202206.
<HUAWEI> system-view
[HUAWEI] net-assistant
[HUAWEI-net-assistant] system-management
[HUAWEI-net-assistant-system-management] user huawei password YsHsjx_202206
