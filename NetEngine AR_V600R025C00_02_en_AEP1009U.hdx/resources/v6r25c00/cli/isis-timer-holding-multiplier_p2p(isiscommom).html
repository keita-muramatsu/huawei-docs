isis timer holding-multiplier

Function

The isis timer holding-multiplier command sets the IS-IS holdtime to be a multiple of the interval at which Hello packets are sent.

The undo isis timer holding-multiplier command restores the default value.

By default, the holdtime is three times the interval at which Hello packets are sent.

Format

isis timer holding-multiplier number

undo isis timer holding-multiplier [ number ]

Parameters

Parameter Description Value
number

Sets the holdtime of a neighbor to a multiple of the interval at which Hello packets are sent.

The value is an integer ranging from 3 to 1000. The default value is 3.

Views

10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE interface view, Cellular channel interface view, Eth-Trunk sub-interface view, Ethernet interface view, GE optical interface view, GE interface view, GE electrical interface view, IP-Trunk interface view, Loopback interface view, MP-group interface view, POS interface view, Tunnel interface view, VLANIF interface view, 40GE sub-interface view, 10GE sub-interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Devices at both ends of a link establish a neighbor relationship by sending Hello packets to each other. After the neighbor relationship is established, both devices need to send Hello packets at a specified interval to maintain the neighbor relationship. If a device does not receive any Hello packet from its neighbor within a specified period of time, the device considers the neighbor to be Down. The specified time period is known as the neighbor holdtime.

For example, if you run the isis timer hello 20 command to set the interval for sending Hello packets to 20s on the local device, and then run the isis timer holding-multiplier 4 command, the holdtime is 80s (4\ x 20 = 80). If the interval for sending Hello packets is changed using the isis timer hello command, the holdtime will be changed accordingly.

Configuration Impact

A high number value delays the local device's detection of a neighbor failure, slowing IS-IS route convergence. A very low number causes frequent up-and-down changes in neighbor connections when Hello packets are lost due to network delays or errors, resulting in unstable IS-IS routes. Therefore, exercise caution when setting the value of number. You are advised to set the same interval for sending Hello packets and the same neighbor holdtime across all devices on the IS-IS network. This ensures consistent detection of link failures and faster IS-IS route convergence.

To detect IS-IS neighbors more sensitively and stabilize neighbor relationships, IS-IS also supports maintaining neighbor relationships through LSPs by default. If an LSP is received within the keepalive time, the neighbor does not go Down immediately but continues to extend the keepalive period. Specific delay time = Neighbor's keepalive time - Remaining keepalive time upon receiving an LSP

Precautions

If a broadcast interface is emulated as a P2P interface using the isis circuit-type command or an emulated P2P interface is restored to the broadcast interface using the undo isis circuit-type command, the multiplier of the neighbor holdtime relative to the interval for sending Hello packets is restored to the default value.

When you run the isis timer hello command to set the interval for sending Hello packets and specify the conservative parameter, if the holdtime of an IS-IS neighbor is less than 20, the neighbor relationship is disconnected without delay after the holdtime expires. If conservative is not specified and the holdtime of an IS-IS neighbor relationship is less than 20, the holdtime is delayed to 20s after the holdtime expires. After the holdtime expires, the neighbor relationship is disconnected.

Example

# Set the holdtime to 6 times the interval at which Hello packets are sent on an interface. 
<HUAWEI> system-view
[HUAWEI] isis 1
[HUAWEI-isis-1] quit
[HUAWEI] interface 10GE0/0/0
[HUAWEI-10GE0/0/0] undo portswitch
[HUAWEI-10GE0/0/0] isis enable 1
[HUAWEI-10GE0/0/0] isis circuit-type p2p
[HUAWEI-10GE0/0/0] isis timer holding-multiplier 6
