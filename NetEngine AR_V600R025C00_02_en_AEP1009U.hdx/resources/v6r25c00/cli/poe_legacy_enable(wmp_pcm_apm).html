poe legacy enable (AP wired port link profile view)

Function

The poe legacy enable command enables an AP to check compatibility of PDs.

The undo poe legacy enable command disables an AP from checking compatibility of the PD.

By default, an AP does not check compatibility of PDs.

Format

poe legacy enable

undo poe legacy enable

Parameters

None

Views

AP wired port link profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When compatibility check is enabled, an AP (PSE) can detect and provide power for the PDs that do not comply with IEEE 802.3af or 802.3at. If compatibility check is disabled, the AP does not identify or provide power for these PDs.

Precautions

This function is supported only by some AP models. You can visit Info-Finder, search for the target AP model, and search for PoE power output in Specifications Query to check whether the AP supports this function.

Example

# Enable an AP to check compatibility of PDs.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] port-link-profile name port-link1
[HUAWEI-wlan-port-link-prof-port-link1] poe legacy enable
