pnp startup-vlan

Function

The pnp startup-vlan command configures a wired PnP VLAN ID, that is, the PnP VLAN used by wired devices.

The undo pnp startup-vlan command deletes the wired PnP VLAN ID.

By default, no wired PnP VLAN ID is configured.

Format

pnp startup-vlan vlan-id

undo pnp startup-vlan [ vlan-id ]

Parameters

Parameter Description Value
vlan-id

Specifies a VLAN ID.

The value is an integer ranging from 1 to 4094.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

There are two types of PnP VLANs: wired and wireless PnP VLANs. The switch obtains the IP address of iMaster NCE-Campus and the IP address of itself through the wired PnP VLAN. If an AP is connected to a switch, the switch automatically changes the PVID of interface connected to the AP to the wireless PnP VLAN ID. PnP VLAN negotiation involves both wired and wireless PnP VLANs. If only the wired PnP VLAN is configured and no wireless PnP VLAN is configured, the interface connected to the AP is added to the wired PnP VLAN. The priority of the PnP VLAN transmitted to the downstream device is as follows: Statically configured wireless PnP VLAN > Statically configured wired PnP VLAN > wireless PnP VLAN learned from the upstream device > Wired PnP VLAN learned from the upstream device.

Precautions

· If a management VLAN has been configured for the switch using iMaster NCE-Campus or a command, the switch uses this management VLAN to send requests to the DHCP server. Even if the requests fail, the switch will not use the PnP VLAN to send requests to the DHCP server. Therefore, ensure that the switch can communicate with the DHCP server in this management VLAN, so that the switch can go online properly.

· The wired PnP VLAN must have been created.

· The wired PnP VLAN and wireless PnP VLAN can be the same or different.

· If only the wired PnP VLAN is configured and no wireless PnP VLAN is configured through the pnp wireless startup-vlan command, the interface connected to the AP is added to the wired PnP VLAN. The priority of the PnP VLAN transmitted to the downstream device is as follows: Statically configured wireless PnP VLAN > Statically configured wired PnP VLAN > wireless PnP VLAN learned from the upstream device > Wired PnP VLAN learned from the upstream device.

Example

# Configure PnP VLAN 10.
<HUAWEI> system-view
[HUAWEI] vlan 10
[HUAWEI-vlan10] quit
[HUAWEI] pnp startup-vlan 10
