display version (ASE)

Function

The display version command displays the version of a specified engine or signature database.

Format

For AR8100 series, AR8700 series, AR6700-H series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5700-H series, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR5710-S8TWDSE-LTE4EA, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5710-S28T2S2XE4, AR5710-S52T2XE4:

display version { ips-sdb | av-sdb | sa-sdb }

For AR5710-S10T1X2, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S:

display version sa-sdb

Parameters

Parameter Description Value
ips-sdb

Indicates the version of the IPS signature database.

NOTE:

This parameter is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

-
sa-sdb

Indicates the version of the service awareness signature database.

-
av-sdb

Indicates the version of the AV signature database.

NOTE:

This parameter is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

This command is used to display the version of a specified engine or signature database.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the version of the SA signature database.
<HUAWEI> display version sa-sdb
2020-11-26 05:13:23.174                                                                                                             
SA SDB Update Information List:                                                                                                     
----------------------------------------------------------------                                                                    
  Current Version:                                                                                                                  
    Signature Database Version    : 2020052300                                                                                      
    Signature Database Size(byte) : 3987114                                                                                         
    Update Time                   : 03:52:36 2020/11/26                                                                             
    Issue Time of the Update File : 14:34:56 2020/11/28                                                                             
                                                                                                                                    
  Backup Version:                                                                                                                   
    Signature Database Version    :                                                                                                 
    Signature Database Size(byte) : 0                                                                                               
    Update Time                   : 00:00:00 0000/00/00                                                                             
    Issue Time of the Update File : 00:00:00 0000/00/00                                                                             
----------------------------------------------------------------
Table 1 Description of the display version (ASE) command output
Item Description
SA SDB Update Information List

Information about the application signature database.
Update Time

Date and time when the database was upgraded to this version.
Current Version

Current version information about the engine or signature database.
Signature Database Version

Version of the signature database or engine.
Signature Database Size(byte)

Size of the signature database or engine.
Issue Time of the Update File

Date and time when the upgrade file was released. You can determine the version of the upgrade package based on this date and time.
Backup Version

Version of the signature database for rollbacks.
