update host source

Function

The update host source command specifies the source IP address and VPN instance of online update request packets.

The undo update host source command deletes the specified source IP address and VPN instance of online update request packets.

By default, this command is not configured. The system searches for a route based on the IP address of the update server and uses the IP address of the outbound interface as the source address of update request packets.

Format

update host source { ip ip-address [ vpn-instance vpn-instance ] | interface { interface-type interface-number | interface-name } }

undo update host source [ ip | interface ]

Parameters

Parameter Description Value
ip ip-address

Specifies the source IP address of upgrade request packets.

The value is in dotted decimal notation.
vpn-instance vpn-instance

Specifies the vpn-instance.

The value is a string of 1 to 31 characters.
interface

Specify the interface for online upgrade.

-
interface-type

Specifies the type of the interface for online upgrade.

The value is a string of 1 to 63 case-sensitive characters. Spaces are not supported.
interface-number

Specifies the number of the interface for online upgrade.

The value is a string of 1 to 63 case-sensitive characters. Spaces are not supported.
interface-name

Specifies the name of the interface for online upgrade.

The value is a string of 1 to 63 characters.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Generally, this command is optional. If the administrator does not configure this command, the system searches for a route based on the IP address of the update server and uses the IP address of the outbound interface as the source IP address of update request packets. The source IP address of update request packets cannot be the address of a loopback interface.

If an interface has multiple IP addresses, you are advised to run the update host source ip ip-address command to configure a source IP address of online update request packets and ensure that the device can receive response packets. Otherwise, the online update may fail.

If the device connects to the Internet through a VPN instance, the update host source command must be run to ensure that the device can receive response packets. Otherwise, the update may fail. In addition, the following requirements must be met:

  • When configuring the update host source interface { interface-typeinterface-number| interface-name} command, you must bind the interface to the desired VPN instance.
  • When configuring the update host source ip ip-addresscommand, you must specify vpn-instance vpn-instance.

Prerequisites

You cannot specify a Layer 2 interface in the update host source interface command. Before specifying an interface for online upgrade, ensure that the interface is a Layer 3 interface.

Precautions

When both update host source interface { interface-type interface-number| interface-name} and update host source ip ip-address[ vpn-instance vpn-instance] are configured, the system preferentially uses ip-addressas the source address of upgrade request packets. That is, the update host source interface interface-type interface-numbercommand does not take effect.

After the update host source command is used to specify a source IP address or source interface, the source address of the request packets sent by the device to the Huawei Security Center during signature database update or to the remote query scheduling center during remote URL query is the specified source IP address or IP address of the specified source interface.

If both the update host source interface { interface-type interface-number| interface-name} and update host source ip ip-address[ vpn-instance vpn-instance] commands are run, the system preferentially uses the IP address specified by ip-addressas the source address of update request packets. In this case, the update host source interface interface-type interface-numbercommand does not take effect.

Example

# Set the source IP address of online update request packets to 10.1.1.1.
<HUAWEI> system-view
[HUAWEI] update host source ip 10.1.1.1
