display portal-access-profile configuration

Function

The display portal-access-profile configuration command displays the configuration of a Portal access profile.

Format

display portal-access-profile configuration [ name access-profile-name ]

Parameters

Parameter Description Value
name access-profile-name

Displays the configuration of a specified Portal access profile.

If name is not specified, all Portal access profiles configured on the device are displayed. If name is specified, detailed configuration of the specified Portal access profile is displayed.

The value is a string of 1 to 31 case-sensitive characters without spaces.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

After configuring a Portal access profile, you can run this command to check whether the configuration is correct.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the Portal access profile ab configured on the device.
<HUAWEI> display portal-access-profile configuration name ab

  Portal timer offline-detect length: 300

  Web-auth-server Name              : demo                                                                                          
  Layer                             : Layer two portal                                                                              
  Bound authentication profile      : -

Table 1 Description of the display portal-access-profile configuration command output
Item Description
Profile name

Name of a Portal access profile.
Service-scheme name

Network access rights assigned to users based on the service scheme when the Portal server is Down.

To set this parameter, run the authentication event portal-server-down action authorize command.
Re-auth

Whether the device is enabled to re-authenticate users when the Portal server changes from Down to Up.

To set this parameter, run the authentication event portal-server-up action re-authen command.
Network IP Num

Number of source subnets for Portal authentication.

To set this parameter, run the portal auth-network command.
Network IP List

Source subnet for Portal authentication.

To set this parameter, run the portal auth-network command.
Web-auth-server Name

Portal server template used by the Portal access profile.

To set this parameter, run the web-auth-server (Portal access profile view) command.
Bound authentication profile

Authentication profile bound to the Portal access profile.

To set this parameter, run the portal-access-profile (authentication profile view) command.
Ucl-group name

Network access rights assigned to users based on the UCL group when the Portal server is Down.
ID

ID of a Portal access profile.
Portal-access-profile Name

Name of a Portal access profile.
