authentication roam-accounting enable

Function

The authentication roam-accounting enable command enables the function of immediately sending accounting packets when a STA roams.

The undo authentication roam-accounting enable command disables the function of immediately sending accounting packets when a STA roams.

By default, the function of immediately sending accounting packets when a STA roams is enabled.

Format

authentication roam-accounting enable

undo authentication roam-accounting enable

Parameters

None

Views

Authentication profile view

Default Level

2: Configuration level

Usage Guidelines

By default, the device immediately sends accounting packets to the accounting server during user roaming, terminal information update, and address update. Some accounting servers may not require the accounting packets. In this case, a large number of accounting packets occupy device resources. You can run the undo authentication roam-accounting enable command to disable the device from immediately sending accounting packets during roaming, reducing device resource consumption. After roaming ends, the device sends accounting packets again, which does not affect the accounting function.

In this command:

  • roam-accounting: indicates that accounting packets are immediately sent during roaming.
  • After the undo authentication roam-accounting enable command is run, the device does not send the terminal information immediately after obtaining the terminal information. Instead, the device sends the terminal information after the real-time accounting timer expires.

Example

# Disable the function of immediately sending accounting packets when a STA roams.
<HUAWEI> system-view
[HUAWEI] authentication-profile name test
[HUAWEI-authen-profile-test] undo authentication roam-accounting enable
