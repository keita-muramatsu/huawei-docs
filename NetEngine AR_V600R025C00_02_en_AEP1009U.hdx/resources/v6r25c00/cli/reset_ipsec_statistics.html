reset ipsec statistics

Function

The reset ipsec statistics command clears IPsec packet statistics.

The reset ipsec statistics service command clears statistics on the advertisement and subscription events exchanged between IPsec and NHRP modules.

Format

reset ipsec statistics [ policy-name policy-name [ seq-number ] | profile-name profile-name ] [ slot slot-id cpu cpu-id ]

reset ipsec statistics service

Parameters

Parameter Description Value
policy-name policy-name

Clears IPsec statistics about the IPsec policy with a specified name.

This parameter is available only in the public system.

The value must be an existing IPsec policy group name.
seq-number

Clears IPsec statistics about the IPsec policy with a specified sequence number.

This parameter is available only in the public system.

The value must be an existing IPsec policy sequence number.
profile-name profile-name

Clears IPsec statistics about the IPsec profile with a specified name.

This parameter is available only in the public system.

The value must be an existing IPsec profile name.
slot slot-id

Clears IPsec statistics with the specified slot ID.

The value varies depending on device models.
cpu cpu-id

Clears IPsec statistics with the specified CPU ID.

The value varies depending on device models.
service

Clears statistics about advertisement and subscription events exchanged between IPsec and NHRP modules.

-

Views

User view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Before collecting statistics about IPSec packets within a given period of time, run this command to delete existing statistics.

Precautions

  • If parameters are not specified, statistics about all IPSec packets are deleted.
  • The deleted statistics about IPSec packets cannot be restored. Exercise caution when you run this command.

Example

# Delete statistics about IPsec packets of IPsec policy policy1.
<HUAWEI> reset ipsec statistics policy-name policy1
# Clear statistics on the release and subscription events exchanged between the IPsec and NHRP modules.
<HUAWEI> reset ipsec statistics service
# Delete statistics about all IPsec packets.
<HUAWEI> reset ipsec statistics
