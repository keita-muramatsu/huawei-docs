display bgp link-state unicast routing-table srv6-endx-sid

Function

The display bgp link-state unicast routing-table srv6-endx-sid command displays SRv6 End.X SIDs and SRv6 LAN End.X SIDs carried in BGP-LS link routes.

Format

display bgp link-state unicast routing-table [ peer { peerIpv4Addr | peerIpv6Addr } { received-routes | advertised-routes } ] prefix srv6-endx-sid

Parameters

Parameter Description Value
peer peerIpv6Addr

Specifies the IPv6 address of a peer.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
peer peerIpv4Addr

Specifies the IPv4 peer address to be advertised.

The value is in dotted decimal notation.
received-routes

Displays BGP-LS routes received from a specified peer.

-
advertised-routes

Displays BGP-LS routes advertised to a specified peer.

-
prefix

Specifies a BGP-LS network address.

The BGP-LS network address format is complex. Therefore, you are advised to run the display bgp link-state unicast routing-table command to display all BGP-LS routes and copy the route information as a prefix.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To check SRv6 End.X SIDs and SRv6 LAN End.X SIDs carried in BGP-LS link routes, run the display bgp link-state unicast routing-table srv6-endx-sid command.
