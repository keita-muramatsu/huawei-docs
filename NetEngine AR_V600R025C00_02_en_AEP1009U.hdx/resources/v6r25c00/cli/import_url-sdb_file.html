import url-sdb file

Function

The import url-sdb file command loads the initial URL category database.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

import url-sdb file file-name

Parameters

Parameter Description Value
file file-name

Specifies an initial database file name that contains the absolute path.

The value is a string of 10 to 63 case-sensitive characters, spaces not supported.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

If no initial URL category database is loaded on the device or the initial URL category database needs to be updated, you can manually load the initial URL category database .

If there is no initial URL category database on the local device, log in to the security center platform (isecurity.huawei.com) to download it. On the home page of the website, choose Signature Update > Signature Update. Select information, such as the product model and version number. On the Initial URL tab, download the latest initial URL category database. Upload the initial URL category database to the device.

If the initial URL category database cannot be loaded, contact technical support personnel.

Example

# Load an initial URL category database.
<HUAWEI> system-view
[HUAWEI] import url-sdb file flash:/url.sdb
