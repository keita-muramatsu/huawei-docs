country-code(net-assistant network view)

Function

The country-code command configures a country code for APs on the entire network.

The undo country-code command restores the default country code CN for APs on the entire network.

By default, the country code is CN on the entire network.

Format

country-code country-code-value

undo country-code

Parameters

Parameter Description Value
country-code-value

Specifies a country code.

The value is an enumerated string. For details about the value range, see the Usage Guidelines.

Views

Net-assistant network view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

You can run this command to configure a country code for APs on the entire network, so that the radio attributes (such as power and channel specifications) of APs can meet the requirements of different countries or regions.

Configuration Impact

Changing the country code will interrupt services.

Example

# Set the country code of APs in the network to CN.
<HUAWEI> system-view
[HUAWEI] net-assistant
[HUAWEI-net-assistant] network
[HUAWEI-net-assistant-network] country-code CN
