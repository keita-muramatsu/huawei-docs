session-car

Function

The session-car command configures the committed information rate (CIR) and peak information rate (PIR) for connection establishment of protocol packets.

The undo session-car command restores the default session CAR values for connection establishment of protocol packets.

By default, the CIR for establishing connections of each protocol is 2 pps; the PIR for establishing BGP connections is 4608 pps, and the PIR for establishing connections of other protocols is 1536 pps.

Format

session-car packet-type cir cir-value [ pir pir-value ]

undo session-car packet-type cir

Parameters

Parameter Description Value
packet-type

Indicates the protocol type.

The value can be bgp, bgp4plus, ospf, or ospfv3.
cir cir-value

Specifies the CIR. The value is an integer ranging from 2 to 100, in pps.

The value is an integer ranging from 2 to 100, in pps. The default value is 2.
pir pir-value

Specifies the PIR. The value is an integer ranging from 1000 to 10000, in pps.

The value is an integer ranging from 1000 to 10000, in pps. The default value is 4608 for BGP and 1536 for other protocols.

Views

Attack defense policy view

Default Level

2: Configuration level

Usage Guidelines

The protocol association CAR is shared by multiple sessions. When a session has a large number of protocol packets, protocol packets of other sessions may be affected. That is, the rate limit for protocol association is exceeded and excess protocol packets are discarded, affecting data transmission and causing protocol flapping.

In this case, you can run this command to enable the session CAR function, so that CAR can be implemented independently for each protocol session without excessively affecting other sessions. After the session CAR function is enabled, when a new protocol connection is established, the system applies the CIR and PIR configured for session CAR to packets sent to the CPU. The session CAR can be set as required.

Example

# In the attack defense policy named test, set the CIR and PIR for BGP packets sent to the CPU to 5 pps and 2000 pps, respectively.
<HUAWEI> system-view
[HUAWEI] cpu-defend policy test
[HUAWEI-cpu-defend-policy-test] session-car bgp cir 5 pir 2000
