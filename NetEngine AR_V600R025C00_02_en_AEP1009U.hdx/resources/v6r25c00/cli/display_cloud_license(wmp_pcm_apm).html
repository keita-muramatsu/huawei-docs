display cloud license

Function

The display cloud license command displays license resources delivered from iMaster NCE-Campus to the WAC.

Format

display cloud license

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

The display cloud license command displays license resources delivered from iMaster NCE-Campus to the AC.

A license is used to control the number of APs that can be managed by iMaster NCE-Campus and the service duration. You need to purchase a license from the service provider and import the license to iMaster NCE-Campus. After an AC goes online, iMaster NCE-Campus converts license resources into the expiration date and delivers the date to the AC. If the AC is out of management by iMaster NCE-Campus, AP entries and license resources on the AC are still available, and the AC can still manage and configure Fit APs.

You can query only the expiration date of the license on the AC. To query the number of license resources, log in to iMaster NCE-Campus to view license information.

Precautions

Only cloud ACs support this command.

Table 1 Description of the display cloud license command output
Item Description
License type

License type.

  • Common AP: common license for ACs and APs (trial license).
  • Indoor AP: license for indoor APs.
  • Outdoor AP: license for outdoor APs.
  • Indoor AP-S: license for indoor AP models ending with -S.
  • Outdoor AP-S: license for outdoor AP models ending with -S.
  • Indoor AP-EC: license for indoor AP models ending with EC.
  • Outdoor AP-EC: license for outdoor AP models ending with EC.
  • Indoor Wi-Fi 6 AP: license for Wi-Fi 6 series indoor APs.
  • Outdoor Wi-Fi 6 AP: license for Wi-Fi 6 series outdoor APs.
  • Wi-Fi 7 AP: license for Wi-Fi 7 series APs.
  • Agile distributed AP: license for central APs (applicable to central APs).
  • Security: not supported in the current version. A hyphen (-) is displayed.
Expire time

License expiration date. If a hyphen (-) is displayed, the resource does not exist. If permanent is displayed, the license takes effect permanently.
Remaining days

Remaining days of the AP license.
Total

Total count.
