http-detect

Function

The http-detect enable command enables HTTP detection.

The http-detect { direction { upload | download | both } | action { block | alert } } command sets the direction or action for HTTP detection.

The http-detect direction { upload | both | download } action { block | alert } command sets the direction and action for HTTP detection.

The undo http-detect enable command disables HTTP detection.

The undo http-detect { direction | action } command restores the direction or action of HTTP detection to the default value.

The undo http-detect direction action command restores the direction and action of HTTP detection to the default values.

By default, HTTP detection is enabled in both the upload and download directions, and the action is block.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

http-detect enable

http-detect { direction { upload | download | both } | action { block | alert } }

http-detect direction { upload | download | both } action { block | alert }

undo http-detect enable

undo http-detect { direction | action }

undo http-detect direction action

Parameters

Parameter Description Value
upload

The protocol transfer direction is upload.

-
download

The protocol transfer direction is download.

-
both

The protocol transmission direction is upload or download.

-
block

Set the action to Block. After detecting a virus, discard the packets and record a log.

-
alert

Set the action to alarm. After detecting a virus, permit the packets and record a log.

-

Views

Antivirus profile view

Default Level

2: Configuration level

Usage Guidelines

HTTP detection is enabled by default. If it is disabled, HTTP detection is not performed.

After the protocol detection direction is configured, the device detects only the files transferred through the specified protocol in the specified direction. If a malicious file is detected, the device performs the configured action.

Example

# Set the direction of HTTP detection to upload and the action to alert. 
<HUAWEI> system-view
[HUAWEI] profile type av name protocol_detect
[HUAWEI-profile-av-protocol_detect] http-detect direction upload action alert
