fec-policy

Function

The fec-policy command applies an FEC policy to an interface.

The undo fec-policy command deletes an FEC policy from to an interface.

By default, no FEC policy is applied to an interface.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

fec-policy name

undo fec-policy name

Parameters

Parameter Description Value
fec-policy name

Specifies the name of an FEC policy.

The value is a string of 1 to 31 case-sensitive characters. If spaces are used, the string must be enclosed in double quotation marks (" ").

Views

Tunnel interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When packet loss occurs on the network, you can apply an FEC policy to an EVPN or GRE tunnel interface to implement packet loss concealment. Traffic will match the service profile in the FEC policy in the outbound direction of the interface and be encoded based on the settings in the FEC parameter profile. After an FEC policy is configured, FEC decoding will be performed on the FEC-encoded traffic in the inbound direction of the interface to recover the lost packets.

Precautions

When an FEC policy is applied to a tunnel interface, the system checks whether the tunnel type is SD-WAN or GRE. After the FEC policy is applied to a tunnel interface, the tunnel type cannot be changed.

Example

# In the FEC policy named policy1, configure the device to use the FEC parameter profile prof1 to optimize packets matching the service profile map1. Then, apply the FEC policy to a tunnel interface.
<HUAWEI> system-view
[HUAWEI] forward-error-correction
[HUAWEI-forward-error-correction] service-map map1
[HUAWEI-forward-error-correction-service-map-map1] quit
[HUAWEI-forward-error-correction] fec profile prof1
[HUAWEI-forward-error-correction-profile-profile1] quit
[HUAWEI-forward-error-correction] fec policy policy1
[HUAWEI-forward-error-correction-policy-policy1] binding service-map map1 fec-profile prof1 precedence 1
[HUAWEI-forward-error-correction-policy-policy1] quit
[HUAWEI-forward-error-correction] quit
[HUAWEI] interface Tunnel 10
[HUAWEI-Tunnel10] tunnel-protocol sd-wan
[HUAWEI-Tunnel10] fec-policy policy1
