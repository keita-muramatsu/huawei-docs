ipv6-address (User-defined application rule view)

Function

The ipv6-address command sets the IPv6 address in a user-defined application rule.

The undo ipv6-address command deletes the IPv6 address in a user-defined application rule.

By default, no IPv6 address is specified for a new user-defined application rule.

Format

ipv6-address ipv6-address [ ipv6-prefix ] [ source | destination ]

undo ipv6-address { ipv6-address [ ipv6-prefix ] [ source | destination ] | all }

Parameters

Parameter Description Value
ipv6-address

Specifies an IPv6 address.

The value is in colon hexadecimal notation.
ipv6-prefix

Specifies a prefix length.

The value is an integer ranging from 1 to 128.
source

Specifies the source IPv6 address.

-
destination

Indicates the destination IPv6 address.

-
all

Deletes all the IPv6 addresses.

-

Views

User-defined application rule view

Default Level

2: Configuration level

Usage Guidelines

The IPv6 address in a user-defined application rule can be a single address or a network segment by specifying the prefix length.

A user-defined application rule supports a maximum of four IPv4 and IPv6 addresses.

The relationship between source address conditions is OR. The relationship between destination address conditions is also OR. However, the relationship between source address conditions and destination address conditions is AND. That is, if both the source and destination addresses are specified in a rule, a packet matches the rule only when the packet matches both the source and destination addresses.

After an IP address is configured, the application identification module matches network packets based on the configured transport-layer protocol and port, that is, 5-tuple. After the user-defined 5-tuple is configured and committed, the application identification module uses the 5-tuple of the first packet of the session for matching. If the 5-tuple of the traffic to be identified is determined, you can configure a user-defined 5-tuple to accelerate traffic identification.

A 5-tuple rule must contain at least one IP address or port number.

Example

# Set the IPv6 address in user-defined application rule rule1 to 2001:db8:1::1 and the prefix length to 100. 
<HUAWEI> system-view
[HUAWEI] sa
[HUAWEI-sa] user-defined-application name UD_abc
[HUAWEI-sa-user-defined-app-UD_abc] rule name rule1
[HUAWEI-sa-user-defined-app-UD_abc-rule-rule1] ipv6-address 2001:db8:1::1 100
