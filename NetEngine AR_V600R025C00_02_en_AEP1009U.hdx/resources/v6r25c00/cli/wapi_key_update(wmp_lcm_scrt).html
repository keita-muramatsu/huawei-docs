wapi key-update

Function

The wapi key-update command sets the USK and MSK update mode for WAPI.

The undo wapi key-update command restores the default USK and MSK update mode.

By default, the USK and MSK are updated based on time.

Format

wapi { usk | msk } key-update { disable | time-based }

undo wapi { usk | msk } key-update

Parameters

Parameter Description Value
usk

Indicates USK update.

-
msk

Indicates MSK update.

-
disable

Disables key update.

-
time-based

Indicates time-based update.

Run the wapi msk and wapi usk commands to set the intervals for updating an MSK and a USK respectively.

-

Views

Security profile view

Default Level

2: Configuration level

Usage Guidelines

· To improve WLAN security, update keys in a timely manner.

· After this command is run, the USK and MSK update modes are changed. Note that a long interval for updating the USK and MSK cannot ensure key security.

· If the update mode is set to Disable, the keys will not be updated.

Example

# Set the unicast key update mode to time-based.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] security-profile name p1
[HUAWEI-wlan-sec-prof-p1] wapi usk key-update time-based
