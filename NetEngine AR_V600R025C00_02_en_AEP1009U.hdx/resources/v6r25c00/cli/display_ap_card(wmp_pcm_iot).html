display ap card

Function

The display ap card command displays details about AP cards.

Format

display ap ap-id card { all | card-number | usb | ble }

Parameters

Parameter Description Value
ap-id

Specifies the AP ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
all

Specifies all AP cards.

-
card-number

Specifies the ID of an IoT card.

The value is an integer that ranges from 1 to 3.
usb

Specifies the USB interface on an IoT card.

-
ble

Specifies the built-in Bluetooth module.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run the display ap card command to view details about AP cards.

Table 1 Description of the display ap card command output
Item Description
Card

ID of a card.
Card connect type

Connection type between the IoT card and AP.
Card type

Card model. The value is a 12-byte ASCII character set, for example, TOEAPV1.2.
Card serial number

Module ID of a card. The value is a 16-byte BCD character set.
Card IP

IP address of a card.
Card MAC

MAC address of a card.
Card bandwidth

Bandwidth of a card.
IOT card status

Card status.

  • present: A card is installed in the slot.
  • absent: No card is installed in the slot.
IOT mcx switch

Whether an MCX interface on the Wi-Fi 7 DAP is enabled.

  • auto: automatically enabled or disabled based on the in-position detection status.
  • enable: enabled.
  • disable: disabled.
IOT mcx status

In-position detection status of an MCX interface on the Wi-Fi 7 DAP.

  • absent: not in position.
  • present: in position.
Power status

Power-on status of a card.

  • on: The card is powered on.
  • off: The card is not powered on.
Connected status

Whether the actual connection type of a card matches the current initialized connection type of the device.
Physical connection type

Connection type between an IoT card and the AP.
Support card information

Whether card information can be queried.
Protocol version

Protocol version. The current version number is 1.
Wireless standard

Wireless standard supported by a card. The value is a 10-byte ASCII character set, for example, RFID, ANT, Zigbee, BT4.0, and Weightless.
Frequency

Card frequency. The value is an 8-byte ASCII character set, for example, 2.4G, 900M, 2.4/5G, or any value from 433M to 915M.
Vendor name

Vendor code of a card. The value is an 8-byte ASCII character set, for example, ENJOYOR.
Hardware version

Hardware version of a card. The value is a 2-byte ASCII character set. The value is fixed in the following pattern: VA for the first version, VB for the second version, VC for the third version, and so on.
Firmware version

Firmware version of a card. The value is a 4-byte number, for example, 00.01.00.01.
Baud-rate

Baud rate for serial communication on an IoT card slot.
Frame-version

Frame format of an extension interface.
Antenna status

Whether the IoT card uses the built-in or external antenna.

  • External: external antenna.
  • Internal: built-in antenna.
Central frequency

Center frequency of a card.
Connect server status

Connection status between a card and the server.
Server name

Name of the server connected to a card.
Subnet mask

Subnet mask length.
Gateway address

Gateway IP address.
USB status

Actual working status of the USB function on the AP.
