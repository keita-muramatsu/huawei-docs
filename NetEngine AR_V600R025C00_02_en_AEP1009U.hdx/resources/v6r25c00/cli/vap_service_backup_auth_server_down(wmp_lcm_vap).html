vap-service-backup auth-server-down (WLAN view)

Function

The vap-service-backup auth-server-down command enables or disables an authentication-server-down backup service VAP.

Format

vap-service-backup auth-server-down { inactive | active } [ vap-profile profile-name ]

Parameters

Parameter Description Value
inactive

Manually disables an authentication-server-down backup service VAP.

-
active

Manually enables an authentication-server-down backup service VAP.

-
vap-profile profile-name

Specifies the name of a VAP profile. If this parameter is not specified, VAPs of this type on all referenced radios are enabled.

The VAP profile must exist.

Views

WLAN view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

If an authentication-server-down backup service VAP is not automatically disabled after the authentication server is restored, the administrator can manually disable this VAP. When the authentication server rejects access of STAs, the administrator can manually enable the authentication-server-down backup service VAP to enable the STAs to enter the survival state.

Precautions

After an authentication-server-down backup service VAP is manually disabled, STAs associated with this VAP go offline.

Example

# Manually enable an authentication-server-down backup service VAP.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] vap-service-backup auth-server-down active vap-profile vap1
