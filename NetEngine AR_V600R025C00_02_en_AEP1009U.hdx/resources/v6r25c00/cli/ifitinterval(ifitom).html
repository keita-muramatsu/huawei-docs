interval (IFIT)

Function

The interval command configures a measurement interval for an IFIT instance.

The undo interval command restores the default measurement interval of an IFIT instance.

The default measurement period of an IFIT instance is 30 seconds.

Format

interval interval-value

undo interval [ interval-value ]

Parameters

Parameter Description Value
interval-value

Specifies a measurement interval for an IFIT instance.

The value is an integer that can be 10, 30, 60, or 300, in seconds.

Views

IFIT-instance view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The measurement period for an IFIT instance is the period between starting to count the number of packets or bytes and recording the send and receive timestamps.

You can run this command to change the measurement interval for an IFIT instance, taking into account factors such as clock synchronization deviation, maximum transmission delay, and device performance.

Prerequisites

An IFIT instance has been created.

Example

# Set the measurement period to 60 seconds for an IFIT instance named abc.
<HUAWEI> system-view
[HUAWEI] ifit
[HUAWEI-ifit] node-id 1
[HUAWEI-ifit] instance abc
[HUAWEI-ifit-instance-abc] interval 60
