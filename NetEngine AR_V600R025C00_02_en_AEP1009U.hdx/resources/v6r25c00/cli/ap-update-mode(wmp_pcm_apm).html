ap update mode

Function

The ap update mode command configures the AP upgrade mode.

The undo ap update mode command restores the default AP upgrade mode.

The default upgrade mode is ac-mode.

Format

ap update mode { ftp-mode | ac-mode | sftp-mode }

undo ap update mode

Parameters

Parameter Description Value
ftp-mode

After the AC delivers the FTP configuration to an AP using the ap update ftp-server command, the AP downloads the upgrade version file from the FTP server.

-
ac-mode

Specifies the AP upgrade mode in which APs download the upgrade version file from the AC.

-
sftp-mode

After the AC delivers the SFTP configuration to the AP using the ap update sftp-server command, the AP downloads the upgrade version file from the SFTP server.

-

Views

WLAN view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

  • During automatic upgrade and online upgrade, the AP upgrade mode needs to be preset.
  • Then, you can run the ap update multi-load command for upgrade.
  • Before upgrading APs or loading patches in batches in AC mode, you are advised to disable the security engine. Otherwise, the system memory may become insufficient.
  • In automatic upgrade during AP onboarding, if APs of multiple models (AP types) are to be automatically upgraded, FTP or SFTP is recommended for upgrade. If automatic AP upgrade in AC mode is used, APs of only one model can be upgraded at a time. When APs of other models go online and trigger automatic upgrade in this case, they will fail to be upgraded. These APs cannot go online until automatic upgrade for the APs of the specified model is complete.

Precautions

SFTP is recommended because it is more secure than FTP.

Example

# Set the AP upgrade mode to sftp-mode.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap update mode sftp-mode
