modem-event icmp-unreachable

Function

The modem-event icmp-unreachable command configures the device to send ICMP packets to check whether the DNS server is reachable when traffic is abnormal. If the DNS server is unreachable, the modem is restarted to restore the link. The upstream and downstream traffic of the modem is detected every 1 minute. If traffic is transmitted only in one direction and traffic in the other direction does not increase for 10 minutes, the modem is restarted.

The undo modem-event icmp-unreachable command restores the default configuration.

By default, the device is configured to send ICMP packets to check whether the DNS server is reachable when traffic is abnormal. If the DNS server is unreachable, the device restarts the modem to restore the link. The upstream and downstream traffic of the module is checked every minute. Only the traffic in one direction is detected. The traffic in the other direction does not increase. The modem is restarted for 10 minutes. The default number of restart attempts is 3.

Format

modem-event icmp-unreachable action { none | modem-reboot retry-times retry-times }

undo modem-event icmp-unreachable

Parameters

Parameter Description Value
none

Indicates that the automatic recovery action is null, that is, no action is taken.

-
modem-reboot

Indicates that the automatic recovery action is restart.

-
retry-times retry-times

Specifies the maximum number of automatic recovery attempts.

The value is an integer ranging from 0 to 10. The value 0 indicates that the number of times is unlimited.
action

Specifies the automatic recovery action.

-

Views

Cellular template view

Default Level

2: Configuration level

Usage Guidelines

To enable the device to automatically recover from link receiving exceptions, run the modem-event icmp-unreachable command to configure the device to send ICMP packets to check whether the DNS server is reachable when traffic is abnormal. If the DNS server is unreachable, restart the modem to recover the link. If you do not want the link to automatically recover from a receiving exception, run the modem-event icmp-unreachable action none command.

Example

# Enable the device to send ICMP packets to check whether the DNS server is reachable when traffic is abnormal and restart the modem if the DNS server is unreachable, and set the maximum number of restart attempts to 5.
<HUAWEI> system-view
[HUAWEI] cellular-profile profileName
[HUAWEI-cellular-profile-profileName] modem-event icmp-unreachable action modem-reboot retry-times 5
