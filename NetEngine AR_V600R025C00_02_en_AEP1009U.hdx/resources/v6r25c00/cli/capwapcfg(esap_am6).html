capwap-ac

Function

The capwap-ac command configures an IPv6 address for the AC in the IPv6 address pool view.

The undo capwap-ac command deletes the AC IPv6 address configured in the IPv6 address pool view.

By default, no IPv6 address is configured for the AC in the IPv6 address pool view.

Format

capwap-ac ipv6-address

undo capwap-ac ipv6-address

Parameters

Parameter Description Value
ipv6-address

Specifies the IPv6 address of the AC.

The value is a 128-bit hexadecimal number, in the format of X:X:X:X:X:X:X:X, with each X representing four hexadecimal numbers.

Views

DHCP IPv6 address pool view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In the AC+Fit AP scenario, the AC needs to establish connections with APs. The device functioning as a DHCPv6 server can specify the AC's IPv6 address for an AP, which then can connect to the specified AC. The device uses Option 52 to carry the AC address.

If the AC and AP are located in the same network segment, the AP sends a broadcast packet to automatically discover the AC. In this case, the configuration of the capwap-ac command is optional. If the AC and AP are located in different network segments, you must configure the capwap-ac command.

Prerequisites

An IPv6 address pool has been created using the dhcpv6 pool command.

Precautions

You can run the capwap-ac command multiple times to configure multiple AC IPv6 addresses. The AC IPv6 address configured first takes precedence over the AC IPv6 address configured later.

Example

# Set the AC's IPv6 address to fc00:1::1 in the address pool pool1 of the DHCPv6 server. 
<HUAWEI> system-view
[HUAWEI] dhcpv6 pool pool1
[HUAWEI-dhcpv6-pool-pool1] capwap-ac fc00:1::1
