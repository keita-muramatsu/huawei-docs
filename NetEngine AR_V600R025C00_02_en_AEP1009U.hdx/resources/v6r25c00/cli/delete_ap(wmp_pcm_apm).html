undo ap

Function

The undo ap command deletes an AP.

Format

undo ap { ap-id ap-id | ap-mac ap-mac | ap-group ap-group | all }

Parameters

Parameter Description Value
ap-id ap-id

Deletes APs with the specified IDs in a batch.

The value is a string of 1 to 255 case-sensitive characters without spaces. When multiple APs are selected, use commas (,) or hyphens (-) to separate AP IDs. For example, 5,8,10-13,20 indicates the list of APs with IDs 5, 8, 10, 11, 12, 13, and 20.
ap-mac ap-mac

Deletes the AP with a specified MAC address.

The AP's MAC address must exist.
ap-group ap-group

Deletes the APs in a specified AP group.

The value is a string of 1 to 35 visible characters that can be Chinese characters or a combination of Chinese and English characters. It cannot contain question marks (?) or only contain double quotation marks ("). If the AP group name contains spaces,it must be enclosed with double quotation marks (" "), for example, "huawei name1". The double quotation mark (") before and after the AP group name occupies two characters together. The specified AP group must exist.

Only the command editor in UTF-8 encoding format can be used to edit Chinese characters.
all

Deletes all APs.

-

Views

WLAN view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If you do not want a Fit AP to go online on the WAC, run this command to delete the Fit AP from the WAC. After the AP is deleted, the Fit AP goes offline from the WAC.

Configuration Impact

Deleting an AP will interrupt services of STAs connected to the AP.

Precautions

APs in the unauth state cannot be deleted.

Running the undo ap all command disconnects all Fit APs from the WAC. Therefore, exercise caution when running this command.

If secondary authentication for dangerous commands has been enabled on the device (using the configuration re-authentication enable command), the undo ap all command takes effect only after the login password is entered for secondary authentication.

Example

# Delete the AP with the AP ID of 0.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] undo ap ap-id 0
Warning: Deleting the AP will interrupt user services. Continue?[Y/N]:y
# Delete all APs.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] undo ap all
Warning: Deleting the AP will interrupt user services. Continue?[Y/N]:y
Info: Delete AP(s) completely. Success count: 0. Failure count: 0.
