exception ips-signature-id

Function

The exception ips-signature-id command configures the processing function of IPS exception signatures.

The undo exception command deletes the exception signature configuration.

By default, no exception signature is configured.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

exception ips-signature-id ips-signature-id [ action { alert | allow | block | { block-source-ip | block-destination-ip } [ timeout timeout ] } ]

undo exception { ips-signature-id ips-signature-id | all }

Parameters

Parameter Description Value
ips-signature-id ips-signature-id

Specifies the ID of an IPS signature.

The value is an integer ranging from 1 to 16777215.
action

Specifies the action.

-
alert

Indicates that the device generates an alarm when a packet matches an exception IPS signature.

-
allow

Indicates that the device permits a packet when a packet matches an exception IPS signature.

The default action for the exception signature is allow.
block

Indicates that the device denies a packet when a packet matches an exception IPS signature.

-
block-source-ip

Indicates that the device blacklists the source IP address and denies the packets destined from or for the specified IP address.

-
block-destination-ip

Isolates the destination IP address and blocks the current flow. The destination IP address is added to the blacklist.

-
timeout timeout

Specifies the lifetime of a blacklist entry. The blacklist entry ceases to take effect after the lifetime ends.

The value is an integer that ranges from 0 to 65535, in minutes. The default value is 5. The value 0 indicates that the blacklist is valid permanently.
all

Indicates all signatures.

-

Views

Intrusion prevention profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

You can separately configure a response action for an exception signature. The security policy preferentially takes response actions in exception signatures.

If no action is specified when an exception signature is created, the default action is allow.

You can run the display firewall blacklist item command to view the blacklist entry added due to IPS attacks. The entry content corresponds to the Reason field whose value is IPS Attack in the command output.

After the IPS signature database is updated, if a predefined signature for which the status, action, or exception signature is configured does not exist in the IPS signature database, the device retains the related configuration but the configuration does not take effect. You can run the display ips-signature not-in-current-library command to view the configuration of such signatures.

Precautions

After running this command, run the engine configuration commit command to commit the configuration for the configuration to take effect. You are advised to commit the configuration after all content security configurations are complete.

Example

# In IPS profile profile1, add the IPS signature with ID 2012 to the exception signature, and set the action to alert.
<HUAWEI> system-view
[HUAWEI] profile type ips name profile1
[HUAWEI-profile-ips-profile1] exception ips-signature-id 2012 action alert
