dtls cert-authenticate disable (DTLS authentication view)

Function

The dtls cert-authenticate disable command disables DTLS certificate validity verification.

The undo dtls cert-authenticate disable command enables DTLS certificate validity verification.

By default, DTLS certificate validity verification is enabled on a device.

Format

dtls cert-authenticate disable

undo dtls cert-authenticate disable

Parameters

None

Views

DTLS authentication view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After the undo dtls cert-authenticate disable command is run, the device verifies whether the DTLS peer's certificate is a match and whether the certificate is valid.

After the dtls cert-authenticate disable command is run, the device verifies only the integrity of the peer's certificate.

Precautions

  1. If this function is disabled, the DTLS client or server does not verifies the validity of the peer device's certificate, which may cause security risks. Therefore, you are advised to enable this function.
  2. After certificate validity verification is disabled, the device still checks the integrity of the peer device's certificate, that is, whether the peer device has a certificate.

Example

# Enable DTLS certificate validity check.
<HUAWEI> system-view
[HUAWEI] dtls authentication
[HUAWEI-dtls authentication] undo dtls cert-authenticate disable
