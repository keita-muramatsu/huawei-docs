signature

Function

The signature command configures a user-defined application signature.

The undo signature command deletes a user-defined application signature.

By default, no signature is configured for a new user-defined application.

Format

signature context { flow | packet } direction { request | response | both } { plain-string plain-string | regular-expression regular-expression } [ field field-name ]

undo signature

Parameters

Parameter Description Value
flow

Indicates flow-based matching.

-
packet

Indicates packet-based matching.

-
direction

Indicates the detection direction.

-
request

Indicates that the detection direction is the request direction.

-
response

Indicates that the detection direction is the response direction.

-
both

Indicates that the detection direction is both directions.

-
plain-string plain-string

Specifies a plain-text string.

The value is a string of 3 to 128 case-sensitive characters. Question marks are not supported. If the keyword contains any space, the value is a string of 5 to 128 characters and must be enclosed with double quotation marks (""). If the keyword contains quotation marks, replace the quotation marks with \x22, for example, to set keyword abc"d, enter abc\x22d.
regular-expression regular-expression

Specifies a regular expression.

The value is a string of 3 to 128 case-insensitive characters. Question marks are not supported. If the regular expression contains spaces, the regular expression must be enclosed in double quotation marks (""). In this case, the length ranges from 5 to 128 characters. If the regular expression contains double quotation marks, the double quotation marks must be escaped to \x22. For example, if the regular expression is abc"d, you need to enter abc\x22d.
field field-name

Specifies the field name.

The value is a string of 1 to 256 case-sensitive characters without spaces.
context

Indicates signature context.

-

Views

User-defined application rule view

Default Level

2: Configuration level

Usage Guidelines

You can configure only one signature for each user-defined application rule.

Example

# Configure regular expression GET.ab{3}c for the signature in user-defined application rule rule1, configure flow-based matching mode, and set the detection direction to request. 
<HUAWEI> system-view
[HUAWEI] sa
[HUAWEI-sa] user-defined-application name UD_abc
[HUAWEI-sa-user-defined-app-UD_abc] rule name rule1
[HUAWEI-sa-user-defined-app-UD_abc-rule-rule1] protocol tcp
[HUAWEI-sa-user-defined-app-UD_abc-rule-rule1] signature context flow direction request regular-expression GET.ab{3}c field HTTP.Body
