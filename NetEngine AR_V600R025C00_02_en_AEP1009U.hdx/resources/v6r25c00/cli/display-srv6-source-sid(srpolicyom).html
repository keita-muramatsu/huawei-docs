display srv6-te policy source-sid

Function

The display srv6-te policy source-sid command displays details about the End and End.X SIDs collected from the IS-IS LSDB after fault detection is enabled for one or more SRv6 TE Policies. The details include the IS-IS process and level information about the SIDs.

Format

display srv6-te policy source-sid [ sid-value | end | end-x ]

Parameters

Parameter Description Value
sid-value

Specifies the SID value.

The value is a 32-bit hexadecimal string in format X:X:X:X:X:X:X:X.
end

Specifies the End SID.

-
end-x

Specifies the End.X SID.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To check details about the End and End.X SIDs collected from the IS-IS LSDB after fault detection is enabled for one or more SRv6 TE Policies, run the display srv6-te policy source-sid command. The details include the IS-IS process and level information about the SIDs.

SID details can be queried after fault detection is enabled or within one hour after fault detection is disabled.

Example

The actual command output varies according to the device. The command output here is only an example.

<HUAWEI> display srv6-te policy source-sid

Table 1 Description of the display srv6-te policy source-sid command output
Item Description
SID

End and End.X SIDs collected from the IS-IS LSDB.
FuncType

Type of an SID collected from the IS-IS LSDB.
Topology

Type of the topology to which an SID collected from the IS-IS LSDB belongs.
Overload

Overload flag of an SID collected from the IS-IS LSDB.
S-Flag

Set flag of a SID.
B-Flag

Backup flag of the SID collected from the IS-IS LSDB.
Producer

Protocol, process, and level information about an SID collected from the IS-IS LSDB.
Node

System ID of the IS-IS process to which an SID collected from the IS-IS LSDB belongs.
Local

System ID of the IS-IS process to which the local interface bound to an End.X SID belongs, or IPv6 address of the local interface bound to the SID when the link type is P2P and IS-IS IPv6 link attributes are enabled.
Peer

System ID of the IS-IS process to which the directly connected interface bound to an End.X SID belongs, or IPv6 address of the interface directly connected to the interface bound to the SID when the link type is P2P and IS-IS IPv6 link attributes are enabled.
