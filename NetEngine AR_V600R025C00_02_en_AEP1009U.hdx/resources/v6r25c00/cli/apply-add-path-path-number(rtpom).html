apply add-path path-number

Function

The apply add-path path-number command sets the number of BGP Add-Path routes that can be preferentially selected.

The undo apply add-path path-number command cancels the configuration.

By default, the maximum number of BGP Add-Path routes that can be preferentially selected is not set.

Format

apply add-path path-number path-number-value

undo apply add-path path-number [ path-number-value ]

Parameters

Parameter Description Value
path-number-value

Specifies the number of preferred routes.

The value is an integer ranging from 2 to 64.

Views

Route-policy view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After the filtering conditions specified by if-match clauses are met, you can run the apply add-path path-number command to change the number of optimal BGP Add-Path routes.

To enter the route-policy view, run the route-policy command.

A route-policy can consist of multiple nodes. The relationship between different nodes is OR. Based on the serial number of the node, the system checks the nodes one by one. If a route matches any of the nodes, the route matches the policy and is no longer matched against other nodes.

Each node may consist of a group of if-match and apply clauses. An if-match clause defines matching rules. The matching objects are some attributes of the routing information. The relationship between multiple if-match clauses for different attributes of a node is AND. A route can pass the filtering only when all the matching conditions specified by the if-match clauses are met. The relationship between multiple if-match clauses for the same attribute is OR, the system checks the if-match clauses in sequence. If a route matches one of the if-match clauses, the route matches the route-policy and is no longer matched against other if-match clauses. For example, in node 10, the if-match community-filter 1 and if-match as-path-filter 1 commands are used to filter routes based on different attributes. The relationship between the two commands is AND. In node 20, if-match community-filter 1 and if-match community-filter 2 are used to filter routes based on communities. The relationship between if-match community-filter 1 and if-match community-filter 2 is OR. An apply clause specifies actions, that is, the clause configures some attributes of the routing information after a route passes the filtering.

Prerequisites

A route-policy must have been configured using the route-policy command before you run the apply add-path path-number command.

Configuration Impact

If the apply add-path path-number command is not run, the number of BGP Add-Path routes is controlled by the peer advertise add-path command. If the apply add-path path-number command is run for a route-policy and the route-policy is applied to BGP, the number of BGP Add-Path routes is controlled by the apply add-path path-number command.

Example

# Set the number of BGP Add-Path routes that can be preferentially selected to 2.
<HUAWEI> system-view
[HUAWEI] route-policy policy permit node 10
[HUAWEI-route-policy] apply add-path path-number 2
