ppp pap local-user

Function

The ppp pap local-user command is used to configure the user name and password sent from the local device to the remote device during PAP authentication.

The undo ppp pap local-user command is used to delete the configured user name and password.

By default, when being authenticated by the remote device in PAP mode, the local device sends a request without carrying any username or password to the remote device.

Format

ppp pap local-user user-name password { simple password2 | cipher { password1 | password2 } }

undo ppp pap local-user

Parameters

Parameter Description Value
user-name

Specifies the user name for PAP authentication. A user name cannot contain an at sign (@). If a user name contains a domain name with an @, you must configure AAA in the domain.

The value is a string of 1 to 253 case-insensitive characters.
password

Specifies a password.

-
simple password1

Specifies a simple password with which the local Device is authenticated by the peer in PAP mode. The password is stored in plain text in the configuration file.

The value is a string of 1 to 16 case-sensitive characters, spaces not supported.
cipher password1

Specifies a ciphertext password with which the local Device is authenticated by the peer in PAP mode. The password is input in simple or encrypt text but stored in cipher text in the configuration file.

The value is a string of 1 to 16 case-sensitive characters, spaces not supported.
cipher password2

Specifies a ciphertext password with which the local Device is authenticated by the peer in PAP mode. The password is input in encrypt text but stored in cipher text in the configuration file.

When being input in ciphertext, the password must be a string of case-sensitive characters. If the system root key is not set, the length of the string must be 48. If the system root key is set, the length of the string can be 108 or 128.

A 24-character or 32-character ciphertext password configured in an earlier version is also supported in this version.

Views

Dialer interface view, POS interface view, Serial interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

PAP is a two-way handshake authentication protocol. When a link is established, you need to configure the local device to send its PAP user name and password to the remote device. After the link establishment phase is complete, the authenticatee repeatedly sends the user name and password to the authenticator until it is authenticated or the link is terminated. During PAP authentication, the authenticatee first sends its user name and password to the authenticator. The authenticator checks whether the received user name and password are correct according to the local user table, and then sends a response (either approval or denial) to the authenticatee.

Note that PAP is an insecure protocol. In PAP authentication, passwords are sent over links in plain text. After a PPP link is established, the authenticatee repeatedly sends the user name and password until the authentication finishes. This authentication way cannot prevent malicious attacks. It is recommended that you select cipher to save the password in ciphertext. When the local device is authenticated by the remote device in PAP mode, the local device sends the user name and password that are the same as those configured on the remote device. By default, passwords are in plain text.

Prerequisites

PPP has been configured as the link layer protocol of the interface.

PAP authentication has been configured for the authenticator.

Configuration Impact

If the ppp pap local-user command is run more than once, the latest configuration overrides the previous one.

Precautions

After the configuration, you must run the shutdown and undo shutdown commands in the corresponding interface view for the configuration to take effect.

PAP is not a secure protocol. You are advised to use CHAP for authentication.

Example

# Set the user name and password sent by the local device to the remote device in PAP authentication to Huawei and YsHsjx_202206, respectively, through the dialer interface.
<HUAWEI> system-view
[HUAWEI] interface Dialer 95
[HUAWEI-Dialer 95] ppp pap local-user Huawei password cipher YsHsjx_202206
