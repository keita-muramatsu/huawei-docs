te link administrative group

Function

The te link administrative group command sets a value for the link administrative group on an interface.

The undo te link administrative group command deletes the configuration.

By default, the value of the link administrative group is 0x0.

Format

te link administrative group group-value

undo te link administrative group

undo te link administrative group group-value

Parameters

Parameter Description Value
group-value

Sets a value for the link administrative group.

The value is a hexadecimal integer. The value range is 0x0 to 0xFFFFFFFF. Each of the 32 bits represents an attribute.

Views

10GE sub-interface view, 10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE sub-interface view, 40GE interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, Ethernet sub-interface view, Ethernet interface view, GE optical interface view, GE sub-interface view, GE electrical interface view, MP-group interface view, Tunnel interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The link administrative group is a 32-bit vector representing a set of link attributes. It works with the affinity attribute for the system to determine the link that is used to set up a TE tunnel.

Configuration Impact

If the value of the link administrative group is changed using the command, the new value takes effect only for new LSPs, not for existing LSPs that have been set up before the new value is set.

Precautions

This command needs to be run only on the outbound interface of a link through which a TE tunnel passes.

There are two methods of configuring the link administrative group attribute. One is to directly configure the value of the link administrative group attribute through the te link administrative group <group-value> command, and the other is to specify a name for the link administrative group attribute and convert it into a value through the te link administrative group name { <name-string> } &<1-32> command. The two methods are mutually exclusive. Before modifying the configuration, you need to delete the existing configuration.

Example

# Set the value of the link administrative group to 0x0101.
<HUAWEI> system-view
[HUAWEI] te attribute enable
[HUAWEI] interface 10GE 0/0/0
[HUAWEI-10GE0/0/0] te link administrative group 101
