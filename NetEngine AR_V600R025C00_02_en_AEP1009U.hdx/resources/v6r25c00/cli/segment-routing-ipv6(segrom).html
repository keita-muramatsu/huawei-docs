segment-routing ipv6 (System view)

Function

The segment-routing ipv6 command enables SRv6 and displays its view.

The undo segment-routing ipv6 command disables SRv6.

By default, this function is disabled.

Format

segment-routing ipv6

undo segment-routing ipv6

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Segment Routing IPv6 (SRv6) is designed to forward IPv6 data packets on a network through source routing. SRv6 implements hop-by-hop forwarding based on the IPv6 forwarding plane. In SRv6, the ingress adds a Segment Routing header (SRH) into IPv6 packets and encapsulates an explicit IPv6 address stack into the SRH. Each SRv6 endpoint node then copies the next SID to be processed in the address stack (namely, SID of the next SRv6 node) to the IPv6 Destination Address (DA) field.

The segment-routing ipv6 command is used to enable SRv6. After running the segment-routing ipv6 command, you can configure an IPv6 SID in the SRv6 view so that an IPv6 local SID entry can be generated.

Precautions

Before running the undo segment-routing ipv6 command, ensure that all processes with Segment Routing IPv6 enabled have been disabled. Otherwise, the command fails to be executed.

Example

# Enable SRv6.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
