display sd-wan routing-table

Function

The display sd-wan routing-table command displays SD-WAN route information on a device.

Format

display sd-wan { ip | ipv6 } routing-table [ all-vpn-instance | vpn-instance vpn-instance-name ] [ dest-site site-id ]

display sd-wan ip routing-table [ vpn-instance vpn-instance-name ] [ prefix [ mask-length ] ]

display sd-wan ipv6 routing-table [ vpn-instance vpn-instance-name ] [ ipv6-prefix [ ipv6-mask-length ] ]

Parameters

Parameter Description Value
ip

Displays IP route information.

-
ipv6

Displays IPv6 route information.

-
all-vpn-instance

Displays the route information of all VPN instances.

-
vpn-instance vpn-instance-name

Specifies the name of a VPN instance.

The value is a string of 1 to 31 case-sensitive characters. If spaces are used, the string must be enclosed in double quotation marks (" ").
dest-site site-id

Specifies a destination site ID.

The value is an integer from 1 to 65535.
prefix

Specifies the destination IP address.

The value is in dotted decimal notation.
mask-length

Specifies the mask length of the IP address.

The value is an integer ranging from 0 to 32.
ipv6-prefix

Specifies the destination IPv6 address.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
ipv6-mask-length

Specifies the mask length of the IPv6 address.

The value is an integer ranging from 0 to 128.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

In SD-WAN scenarios, you can run this command to query SD-WAN overlay route information on a device.

Example

The actual command output varies according to the device. The command output here is only an example.
