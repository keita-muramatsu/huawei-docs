file-frame timeout

Function

The file-frame timeout command configures the file frame detection and restoration time thresholds.

The undo file-frame timeout command restores the default file frame detection and restoration time.

By default, the file framework restoration time threshold is 10 seconds, and the file framework detection time threshold is 4 seconds.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

file-frame { restore timeout restore-time | detect timeout detect-time }

undo file-frame { restore | detect } timeout

Parameters

Parameter Description Value
timeout restore-time

Timeout interval for restoring the file framework.

The value is an integer ranging from 1 to 60, in seconds.
timeout detect-time

Timeout interval for checking the file framework.

The value is an integer from 2 to 20, in seconds.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

The device allows you to configure the file restoration time and detection time thresholds of the file framework. When the restoration time and detection time exceed the thresholds, the device does not perform detection but directly permits the traffic.

Example

# Set the detection timeout period of the configuration file framework to 5 seconds.
<HUAWEI> system-view
[HUAWEI] file-frame detect timeout 5
[HUAWEI] file-frame restore timeout 5
