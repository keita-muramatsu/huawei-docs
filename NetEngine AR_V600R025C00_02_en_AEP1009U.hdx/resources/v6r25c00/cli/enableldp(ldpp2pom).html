mpls ldp

Function

The mpls ldp command enables LDP on the local node and displays the LDP view.

The undo mpls ldp command deletes all LDP configurations.

By default, LDP is not enabled on a node.

Format

mpls ldp

undo mpls ldp

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

On a network where MPLS LDP needs to be deployed, you must run this command to enable MPLS LDP globally and create an LDP public network instance.

You can perform other LDP configurations only after this command is run.

Prerequisites

MPLS has been enabled globally using the mpls command in the system view.

Follow-up Procedure

You can perform other LDP-related configurations.

Precautions

Running the undo mpls ldp command in the system view causes all MPLS LDP configurations in the system view and the interface view to be deleted.

After the configuration re-authentication enable command is configured, you need to enter the password and pass the authentication before running the undo mpls ldp command to make the configuration take effect.

Example

# Enable LDP globally.
<HUAWEI> system-view
[HUAWEI] mpls
[HUAWEI-mpls] quit
[HUAWEI] mpls ldp
