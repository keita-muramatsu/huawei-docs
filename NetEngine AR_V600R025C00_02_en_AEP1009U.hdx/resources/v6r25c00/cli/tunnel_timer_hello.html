tunnel timer hello

Function

The tunnel timer hello command sets the interval for sending Hello packets.

The undo tunnel timer hello command restores the default interval.

By default, Hello packets are sent every 60 seconds.

Format

tunnel timer hello interval

undo tunnel timer hello [ interval ]

Parameters

Parameter Description Value
hello interval

Specifies the interval for sending Hello packets.

The value is an integer ranging from 0 to 100000, in seconds. The default value is 60. If the value is 0, no Hello packet is sent.

Views

L2TP group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

L2TP uses Hello packets to check tunnel connectivity. The L2TP client and LNS can periodically send Hello packets to each other. If no response is received within a period of time, the L2TP client and LNS retransmit Hello packets. If packets are retransmitted for more than five times, the L2TP tunnel is disconnected.

When the network is unstable, you can reduce the interval for sending Hello packets to detect the L2TP tunnel status in time. Otherwise, you can increase the interval. You can set different intervals for sending Hello packets on the L2TP client and LNS.

Configuration Impact

Hello packets are sent periodically, which increases the network load. The smaller the interval, the heavier the network load.

Example

# Set the interval for sending Hello packets to 99 seconds.
<HUAWEI> system-view
[HUAWEI] l2tp-group 1
[HUAWEI-l2tp-group-1] tunnel timer hello 99
