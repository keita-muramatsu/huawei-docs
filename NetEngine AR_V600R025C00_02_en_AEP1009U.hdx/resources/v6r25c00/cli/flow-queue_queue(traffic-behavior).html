flow-queue queue (traffic behavior view)

Function

The flow-queue queue command binds a flow queue profile to a traffic behavior.

The undo flow-queue queue command unbinds a flow queue profile from a traffic behavior.

By default, no flow queue profile is bound to a traffic behavior.

Format

flow-queue flow-queue-name queue queue-name

undo flow-queue

Parameters

Parameter Description Value
flow-queue-name

Specifies the name of a flow queue profile.

The value is a string of 1 to 31 case-sensitive characters without spaces.
queue-name

Specifies the name of a flow queue.

The value is a string of 1 to 31 case-sensitive characters without spaces.

Views

Traffic behavior view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

You can bind a flow queue profile to a traffic behavior, so that packets matching certain rules are placed into the corresponding flow queue for differentiated processing.

Prerequisites

The flow queue profile must be created and the QoS parameters of a flow queue must be configured in the flow queue profile.

Precautions

For the AR6710-L14T2X4, if CBQ is configured and a flow queue profile is referenced by a traffic behavior, it is recommended that the number of CB pairs for DRR be less than or equal to 3. When parent and child traffic policies are configured, it is recommended that the number of CB pairs for DRR in the flow queue profile referenced by each child traffic policy be less than or equal to 3.

For the AR8700 series, if CBQ is configured and a flow queue profile is referenced by a traffic behavior, it is recommended that the number of CB pairs for DRR be less than or equal to 7. When parent and child traffic policies are configured, it is recommended that the number of CB pairs for DRR in the flow queue profile referenced by each child traffic policy be less than or equal to 7.

Example

# Bind the flow queue profile named service to the flow queue named data in traffic behavior tb1.
<HUAWEI> system-view
[HUAWEI] flow-queue service
[HUAWEI-queue-service] queue data drr weight 10 shaping cir-shaping-percentage 10
[HUAWEI-flow-queue-service] quit
[HUAWEI] traffic behavior tb1
[HUAWEI-behavior-tb1] flow-queue service queue data
