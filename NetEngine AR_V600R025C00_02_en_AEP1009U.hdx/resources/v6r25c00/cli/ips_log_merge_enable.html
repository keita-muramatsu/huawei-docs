ips log merge enable

Function

The ips log merge enable command enables the IPS log aggregation function.

The undo ips log merge enable command disables the IPS log aggregation function.

By default, the system enables the IPS log aggregation function.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

ips log merge enable

undo ips log merge enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After the IPS log merging function is enabled, when multiple same IPS logs are generated, the system merges these logs into one and then outputs the merged log.

If both the attack forensic data collection (enabled using the collect-attack-evidence enable command) and log merging functions are enabled, the log merging function does not take effect.

Precautions

After running this command, run the engine configuration commit command to commit the configuration for the configuration to take effect. You are advised to commit the configuration after all content security configurations are complete.

Example

# Disable the IPS log aggregation function.
<HUAWEI> system-view
[HUAWEI] undo ips log merge enable
