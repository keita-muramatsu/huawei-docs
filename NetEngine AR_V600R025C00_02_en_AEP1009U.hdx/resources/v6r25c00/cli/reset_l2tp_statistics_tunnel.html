reset l2tp statistics tunnel

Function

The reset l2tp statistics tunnel command resets L2TP packet statistics.

Format

reset l2tp statistics tunnel { all | tunnel-id tunnel-id }

Parameters

Parameter Description Value
all

Indicates all tunnels.

-
tunnel-id tunnel-id

Specifies the local tunnel ID of an L2TP tunnel.

The value is an integer ranging from 1 to 1024.

Views

User view

Default Level

3: Management level

Usage Guidelines

Before viewing L2TP packet statistics within a period of time, run the reset l2tp statistics tunnel command to clear the existing statistics.

Example

# Reset L2TP packet statistics on the device.
<HUAWEI> reset l2tp statistics tunnel all
