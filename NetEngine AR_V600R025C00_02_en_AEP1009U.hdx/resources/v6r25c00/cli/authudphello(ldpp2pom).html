authentication udp-remote key-chain

Function

The authentication udp-remote key-chain command enables LDP to perform keychain authentication for Targeted Hello messages.

The undo authentication udp-remote key-chain command restores the default configuration.

By default, keychain authentication is not performed for LDP Targeted Hello messages.

Format

authentication udp-remote key-chain peer peer-id name keychain-name

undo authentication udp-remote key-chain peer peer-id [ name keychain-name ]

Parameters

Parameter Description Value
name keychain-name

Specifies a keychain name. The parameter is specified in the keychain command.

The value is a string of 1 to 47 case-insensitive characters, It cannot contain question marks (?). If spaces are used, the string must start and end with double quotation marks (&quot;).
peer peer-id

Specifies the ID of an LDP peer enabled with LDP keychain authentication. The parameter is specified in the mpls lsr-id command.

The value is in dotted decimal notation.

Views

MPLS-LDP view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

A remote LDP peer relationship can be established across multiple devices. To enhance the security of Hello message sending and receiving and prevent the establishment of unauthorized peer relationships, you can configure Targeted Hello keychain authentication to improve network security.

Prerequisites

MPLS and MPLS LDP have been enabled globally.

Keychain authentication has been configured globally.

Configuration Impact

After keychain authentication is configured, a peer is authenticated using the specified keychain. If the authentication fails, the LDP session cannot be established.

Precautions

You are advised to use a more secure encryption algorithm. For details, see the algorithm command in the key-ID view.

Example

# Configure Targeted Hello keychain authentication for peer 2.2.2.2 through the keychain named kc1.
<HUAWEI> system-view
[HUAWEI] keychain kc1 mode absolute
[HUAWEI-keychain-kc1] receive-tolerance 100
[HUAWEI-keychain-kc1] key-id 1
[HUAWEI-keychain-kc1-keyid-1] algorithm sm3
[HUAWEI-keychain-kc1-keyid-1] key-string cipher YsHsjx_202206
[HUAWEI-keychain-kc1-keyid-1] send-time 14:30 2017-10-10 to 14:50 2017-10-10
[HUAWEI-keychain-kc1-keyid-1] receive-time 14:40 2017-10-10 to 14:50 2017-10-10
[HUAWEI-keychain-kc1-keyid-1] default send-key-id
[HUAWEI-keychain-kc1-keyid-1] quit
[HUAWEI-keychain-kc1] quit
[HUAWEI] mpls
[HUAWEI-mpls] mpls ldp
[HUAWEI-mpls-ldp] authentication udp-remote key-chain peer 2.2.2.2 name kc1
