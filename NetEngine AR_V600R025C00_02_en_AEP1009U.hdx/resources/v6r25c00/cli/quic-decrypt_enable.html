quic decrypt enable

Function

The quic decrypt enable command enables QUIC decryption.

The undo quic decrypt enable command disables QUIC decryption.

By default, QUIC decryption is disabled.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

quic decrypt enable

undo quic decrypt enable

Parameters

None

Views

SA view

Default Level

2: Configuration level

Usage Guidelines

A device can identify QUIC applications and perform other content security detection and processing based on QUIC and applications only after QUIC decryption is enabled. QUIC decryption involves decrypting QUIC Initial packets to extract the TLS handshake information contained within them.

Example

# Enable QUIC decryption.
<HUAWEI> system-view
[HUAWEI] sa
[HUAWEI-sa] quic decrypt enable
