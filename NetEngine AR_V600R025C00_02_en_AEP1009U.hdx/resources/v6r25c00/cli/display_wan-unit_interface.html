display wan-unit interface

Function

The display wan-unit interface command displays information about the WAN unit connected to the device.

Format

display wan-unit { all | interface { interface-name | ifType ifNum } }

Parameters

Parameter Description Value
all

Indicates all interfaces enabled with the WAN unit function.

-
interface interface-name

Specifies the name of an interface.

The value is a string of 1 to 63 case-sensitive characters. It cannot contain spaces.
interface ifType ifNum

Specifies the interface type and number.

The value depends on the device. You can enter a question mark (?) and select a value from the displayed value range.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

After configuring the WAN unit function on a device and connecting a device to the WAN unit, you can run this command to check information about the WAN unit connected to the device.

Precautions

When you view information about all WAN units, the command output is displayed in ascending order of WAN unit indexes.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display information about the WAN unit connected to 10GE0/0/1.
<HUAWEI> display wan-unit interface 10GE0/0/1
-------------------------------------------------------------------------------                                                     
Interface               : 10GE0/0/1                                                                                     
Status                  : Online                                                                                                    
Type                    : RU-201                                                                                                    
ESN                     : 28Z7S23808000070                                                                                          
Version                 : 3.0.0.1(H3520SP3C1623)                                                                                    
IP                      : 192.168.0.10                                                                                              
Time                    : 2024-02-05 09:56:31                                                                                       
-------------------------------------------------------------------------------
# Display information about the WAN unit connected to the device.
<HUAWEI> display wan-unit all
--------------------------------------------------------------------------------------------                                  
WanUnitIndex  Interface        Status     Type       IP                 Time                                                 
--------------------------------------------------------------------------------------------                                  
 1            10GE0/0/1        Online     RU-201     192.168.0.10       2024-02-05 09:56:31                                  
--------------------------------------------------------------------------------------------

Time when the WAN unit goes online and offline.
