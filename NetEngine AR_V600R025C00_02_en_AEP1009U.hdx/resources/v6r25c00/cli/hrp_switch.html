hrp switch

Function

The hrp switch command triggers a device switchover when the two devices in hot standby work properly.

The undo hrp switch command restores the default state.

Format

hrp switch { active | standby }

undo hrp switch

Parameters

Parameter Description Value
active

Switches the state of the device to active.

-
standby

Switches the state of the device to standby.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In addition to the active/standby switchover triggered by fault events, you can run the hrp switch command to forcibly perform the active/standby switchover. The forcible active/standby switchover method is used to check whether the link of the standby device is normal during device maintenance. It is not recommended to use this method in other cases.

Configuration Impact

When the status of the dual-device system is normal, the fault coefficient and robustness coefficient are the same. For example, in normal cases, the priorities of DeviceA (active device) and DeviceB (standby device) are both 0:2. After this command is run on DeviceA or DeviceB, the impact is as follows:

  • After the hrp switch standby command is executed on DeviceA, the priority of DeviceA changes to 1:2 and the priority of DeviceB remains 0:2. DeviceA becomes the standby device, and DeviceB becomes the active device.
  • After the hrp switch active command is executed on DeviceB, the priority of DeviceA changes to 1:2, and the priority of DeviceB remains 0:2. DeviceA becomes the standby device, and DeviceB becomes the active device.
  • After the hrp switch active command is executed on DeviceA, the priority of DeviceA remains 0:2 and the priority of DeviceB changes to 1:2. The roles of DeviceA and DeviceB do not change. (You are not advised to run the hrp switch active command on the active device.)
  • After the hrp switch standby command is executed on DeviceB, the priority of DeviceA remains 0:2 and the priority of DeviceB changes to 1:2. The roles of DeviceA and DeviceB do not change. (You are not advised to run the hrp switch standby command on the standby device.)

Precautions

  • When the dual-device system status is abnormal, the manual switchover cannot be performed using this command. For example, if an interface on the active device goes down, the active device becomes the standby one. In this case, you cannot run the hrp switch active command on the device to switch it to the active one.
  • After performing a forcible active/standby switchover, run the undo hrp switch command immediately to restore the device to the normal state.
  • The command configuration takes effect only once and is not saved into the configuration file.

Example

# Switch the state of the device to standby.
<HUAWEI> system-view
[HUAWEI] hrp switch standby
