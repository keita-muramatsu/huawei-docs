standby track nqa

Function

The standby track nqa command associates interface backup with NQA.

The undo standby track nqa command cancels association between interface backup and NQA.

By default, association between interface backup and NQA is not configured on an interface.

Format

standby track nqa admin-name test-name

undo standby track nqa admin-name test-name

Parameters

Parameter Description Value
admin-name

Specifies the administrator of an NQA test instance.

The value is a string of 1 to 32 case-sensitive characters. It cannot contain spaces.
test-name

Specifies the name of a test instance.

The value is a string of 1 to 32 case-sensitive characters. It cannot contain spaces.

Views

10GE sub-interface view, 10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE sub-interface view, 40GE interface view, Cellular interface view, Cellular channel interface view, Dialer interface view, Ethernet sub-interface view, Ethernet interface view, GE optical interface view, GE sub-interface view, GE electrical interface view, MP-group interface view, Multi-GE sub-interface view, Multi-GE interface view, Tunnel interface view, Serial interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

NQA is a real-time network performance detection and measurement technology. To monitor the network status in real time, configure association between interface backup and NQA to implement fast switching when the primary link is faulty, ensuring non-stop service transmission. Create an NQA test instance on the local router to detect connectivity for the primary link. When the primary link is working properly, backup links do not forward data. When the NQA test instance detects a fault on the primary link, the standby interface with the highest priority starts to transmit services.

You need to configure association between interface backup and NQA on the standby interface. It is easy to configure and there are various detection result items. However, the response is slow.

Prerequisites

An NQA ICMP test instance is successfully configured.

Precautions

When the NQA test instance associated with the standby interface detects the path of the standby interface, the standby interface alternates between up and down.

Example

# Configure association between interface backup and NQA on a standby interface. Set the administrator name of the NQA test instance to user and the test instance name to test.
<HUAWEI> system-view
[HUAWEI] nqa test-instance user test
[HUAWEI-nqa-user-test] test-type icmp
[HUAWEI-nqa-user-test] quit
[HUAWEI] interface 10GE0/0/1
[HUAWEI-10GE0/0/1] standby track nqa user test
