display version location-sdb

Function

The display version location-sdb command displays the version of the region signature database.

Format

For AR8100 series, AR8700 series, AR6700-H series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5700-H series, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR5710-S8TWDSE-LTE4EA, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S10T1X2, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S:

display version location-sdb

For AR8700 series, AR6700-H series:

display version location-sdb slave-board

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

This command displays the version of the region signature database.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the version of the region signature database.
<HUAWEI> display version location-sdb

Table 1 Description of the display version location-sdb command output
Item Description
Location SDB Update Information List

Information about the region identification signature database.
Update Time

Date and time when the database was upgraded to this version.
Current Version

Current version information about the engine or signature database.
Signature Database Version

Version of the signature database or engine.
Signature Database Size(byte)

Size of the signature database or engine.
Issue Time of the Update File

Date and time when the upgrade file was released. You can determine the version of the upgrade package based on this date and time.
Backup Version

Version of the signature database for rollbacks.
