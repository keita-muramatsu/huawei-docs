csi presence-re-enter-delay

Function

The csi presence-re-enter-delay command sets the person re-entry delay in CSI sensing for APs.

The undo csi presence-re-enter-delay command deletes the configured person re-entry delay in CSI sensing for APs.

By default, the person re-entry delay in CSI sensing is 0s in the AP system profile view. In the AP view, the person re-entry delay in CSI sensing is not configured by default, and the configuration in the AP system profile view is used.

Format

csi presence-re-enter-delay delay-time

undo csi presence-re-enter-delay

Parameters

Parameter Description Value
delay-time

Specifies the person re-entry delay, that is, the delay for re-detecting a person after the human presence state is aged as human absence.

The value is an integer ranging from 0 to 600, in seconds.

Views

AP view, AP system profile view

Default Level

2: Configuration level

Usage Guidelines

In energy-saving scenarios such as hotels, when no human presence is detected and energy-saving actions are triggered, large actions with precise event sequences (such as closing motorized curtains) may be executed. In such cases, the person re-entry delay can be configured to suppress false detection and false alarms caused by the execution of these energy-saving actions.

Example

# Set the person re-entry delay in CSI sensing for APs to 60s.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name test
[HUAWEI-wlan-ap-system-prof-test] csi presence-re-enter-delay 60
