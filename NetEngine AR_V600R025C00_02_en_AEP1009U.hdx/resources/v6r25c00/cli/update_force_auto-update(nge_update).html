update force auto-update ips-sdb enable

Function

The update force auto-update ips-sdb enable command enables forcible automatic update of the IPS signature database.

By default, this function is disabled.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

update force auto-update ips-sdb enable

undo update force auto-update ips-sdb enable

Parameters

Parameter Description Value
ips-sdb

Indicates the IPS signature database.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

During the IPS signature database update, if the engine version change is detected, the device automatically restarts the engine process to complete the update. If the upgrade fails, you can run this command to forcibly perform an automatic upgrade.

Example

# Enable forcible automatic online update of the IPS signature database.
<HUAWEI> system-view
[HUAWEI] update force auto-update ips-sdb enable
