peer upe (BGP-VPNv6 address family view)

Function

The peer upe command specifies a BGP peer as the UPE of HoVPN.

The undo peer upe command cancels the configuration.

By default, no BGP peer is specified as the UPE of HoVPN.

Format

peer peerIpv4Addr upe

undo peer peerIpv4Addr upe

Parameters

Parameter Description Value
peerIpv4Addr

Specifies the IPv4 address of a peer.

The value is in dotted decimal notation.

Views

BGP-VPNv6 address family view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In hierarchy of VPN (HoVPN), multiple PEs function as different roles to form a hierarchical architecture. These PEs provide functions of a single PE. HoVPN thereby lowers the performance requirements on PEs. After you run the peer upe command on an SPE to specify a BGP peer as the UPE on an HoVPN, the SPE advertises only default routes or summary routes to the UPE. In this manner, the UPE only needs to maintain local VPN routes, and all remote routes are replaced by the default routes or summary routes. This reduces the burden on the UPE. In addition, for the routes it receives from the UPE, the SPE can change the next hops to itself and then reflect the routes to the connected NPE.

Prerequisites

A peer has been created and the BGP-VPNv6 address family view has been enabled using the peer as-number command.

Precautions

You can configure the SPE to advertise a default route to the UPE in either of the following modes:

Route filtering mode: You can configure the default static route and routing policy to enable the SPE to send the default route to the UPE.

Command control mode: You can run the peer default-originate vpn-instance command to enable the SPE to automatically generate the default route and send it to the UPE.

Example

# Specify the peer 1.1.1.1 as the UPE.
<HUAWEI> system-view
[HUAWEI] bgp 100
[HUAWEI-bgp] peer 1.1.1.1 as-number 100
[HUAWEI-bgp] ipv6-family vpnv6
[HUAWEI-bgp-af-vpnv6] peer 1.1.1.1 enable
[HUAWEI-bgp-af-vpnv6] peer 1.1.1.1 upe
