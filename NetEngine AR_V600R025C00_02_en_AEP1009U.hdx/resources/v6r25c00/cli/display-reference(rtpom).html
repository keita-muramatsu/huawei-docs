display reference-by route-policy

Function

The display reference-by route-policy command displays references of IP prefix filters or ACL filters by route-policies.

Format

display ip ip-prefix pfname reference-by route-policy

display ip ipv6-prefix pfname reference-by route-policy

display acl { aclNum | name aclName } reference-by route-policy

display acl ipv6 { aclNum | name aclName } reference-by route-policy

Parameters

Parameter Description Value
pfname

Specifies the name of an IP prefix list filter.

The value is a string of 1 to 169 characters.
ip

Indicates IP information.

-
ipv6-prefix

Specifies an IPv6 prefix list.

-
acl

Indicates ACL status and configuration information.

-
aclNum

Specifies an ACL filter.

The value is an integer ranging from 2000 to 2999.
name

Specifies a named ACL.

-
name

Specifies a named ACL6.

-
aclName

Specifies the name of an ACL filter.

The value is a string of 1 to 64 characters.
ipv6

Indicates IPv6 information.

-
ip-prefix

Specifies an IP prefix list.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Using the display reference-by route-policy command, you can check references of IP prefix filters or ACL filters by route-policies.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display reference information about a specified IPv6 prefix list filter.
<HUAWEI> system-view
[HUAWEI] display ip ipv6-prefix prefix2 reference-by route-policy
Route Policy: aa
Policy  Node: 1 2 3 5
# Display reference information about a specified IPv4 prefix list filter.
<HUAWEI> system-view
[HUAWEI] display ip ip-prefix prefix1 reference-by route-policy
Route Policy: aa
Policy  Node: 1 2 3 5
# Display reference information about a specified ACL filter.
<HUAWEI> system-view
[HUAWEI] display acl 2001 reference-by route-policy
Route Policy: aa
Policy  Node: 1 2 3 5
