display vdsl interface

Function

The display vdsl interface command displays the status of a VDSL interface.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S10T1X2, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

display vdsl interface { interface-type interface-number | interface-name }

display vdsl all interface

Parameters

Parameter Description Value
all

Indicates all VDSL interfaces.

-
interface interface-type interface-number

Queries the status of a specified interface:

  • interface-type specifies the interface type.
  • interface-number specifies the interface number.

-
interface interface-name

Queries the status of a specified interface. interface-name specifies the name of the interface.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run the display vdsl interface command to view information about a VDSL interface, including whether the VDSL interface has successfully negotiated with the DSLAM, line status, performance statistics, and whether bit exchange, seamless rate adaptation, or trellis coding is enabled.
