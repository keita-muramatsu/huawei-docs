ssl renegotiation enable

Function

The ssl renegotiation enable command enables SSL renegotiation.

The undo ssl renegotiation enable command disables SSL renegotiation.

By default, the SSL renegotiation function is disabled.

Format

ssl renegotiation enable

undo ssl renegotiation enable

Parameters

None

Views

SSL policy view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

When SSL is used for data transmission, you can enable the SSL renegotiation function to periodically update the key and algorithm without interrupting the connection, improving communication security. The key and algorithm are updated at an interval of one hour or when the data size reaches 1 GB.

Prerequisites

The ssl policy command has been used in the system view to create an SSL policy.

Precautions

The SSL renegotiation function is enabled on both the server and client.

Example

# Enable SSL renegotiation.
<HUAWEI> system-view
[HUAWEI] ssl policy abc
[HUAWEI-ssl-policy-abc] ssl renegotiation enable
