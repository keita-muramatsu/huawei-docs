match

Function

The match command binds an SPR service profile to an ACL, application, or application group.

The undo match command unbinds an SPR service profile from an ACL, application, or application group.

By default,an SPR service profile is not bound to an ACL, application, or application group.

Format

match acl { acl-number | acl-name }

match application-group application-group-name

match acl { acl-number | acl-name } application-group application-group-name

match application application-name

match acl { acl-number | acl-name } application application-name

match ipv6 acl { acl-number | acl-name }

match ipv6 acl { acl-number | acl-name } application application-name

match ipv6 acl { acl-number | acl-name } application-group application-group-name

undo match acl { acl-number | acl-name }

undo match application-group application-group-name

undo match acl { acl-number | acl-name } application-group application-group-name

undo match application application-name

undo match acl { acl-number | acl-name } application application-name

undo match ipv6 acl { acl-number | acl-name }

undo match ipv6 acl { acl-number | acl-name } application application-name

undo match ipv6 acl { acl-number | acl-name } application-group application-group-name

Parameters

Parameter Description Value
acl-number

Specifies the number of an ACL.

The value is an integer in the range from 2000 to 3999.

The number of a basic ACL is in the range from 2000 to 2999, and the number of an advanced ACL is in the range from 3000 to 3999.
acl-name

Specifies the name of an ACL.

The value is a string of 1 to 32 case-sensitive characters. It cannot contain spaces and must start with a letter (a to z or A to Z).
application-group application-group-name

Specifies the name of an application group.

The value is a string of 1 to 32 case-sensitive characters, spaces not supported. When quotation marks are used around the string, spaces are allowed in the string.
acl

Specifies the name or number of an ACL.

-
application application-name

Specifies the name of an application.

The value is a string of 1 to 32 case-insensitive characters. It cannot contain spaces. If the string is enclosed in quotation marks, spaces are allowed in the string.
ipv6

Specifies the name or number of an IPv6 ACL.

-

Views

Service profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Service flows can be matched through ACLs or application identification. You can run this command to bind an SPR service profile to an ACL or application to implement SPR based on the ACL or application.

Prerequisites

SPR has been configured using the smart-policy-route command.

An SPR service profile has been created using the service-map command.

The ACL number specified by acl-number or ACL name specified by acl-name has been configured. You can run the display acl command to check whether the ACL used to match service traffic already exists. If not, run the acl or acl name command to create an ACL that needs to be bound to the SPR service profile.

The application name specified by application-name has been configured. You can run the display application command to check whether an application exists. If the application does not exist, run the add application command to create the application to be bound to the service profile in SPR.

The application group name specified by application-group-name has been configured. You can run the display application-group command to check whether an application group exists. If the application group does not exist, run the application-group name command to create the application group to be bound to the service profile in SPR.

Precautions

When you run the undo match command, the ACL number, ACL name, and application group name specified by acl-number, acl-name, and application-group-name must have been bound to the SPR service profile.

If you run this command multiple times, all the configurations take effect.

Example

# Configure policy profile spr1 to match the SA application baidu.
<HUAWEI> system-view
[HUAWEI] smart-policy-route
[HUAWEI-smart-policy-route] service-map spr1
[HUAWEI-smart-policy-route-service-map-spr1] match application baidu
