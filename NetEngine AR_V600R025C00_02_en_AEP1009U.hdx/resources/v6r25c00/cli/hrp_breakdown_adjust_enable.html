hrp breakdown adjust enable

Function

The hrp breakdown adjust enable command enables the function of automatically adjusting the OSPF, OSPFv3, or BGP cost value after the standby device assumes the active role when the active and standby devices are disconnected unexpectedly.

The undo breakdown hrp adjust enable command disables the function of automatically adjusting the OSPF, OSPFv3, or BGP cost value after the standby device assumes the active role when the active and standby devices are disconnected unexpectedly.

By default, the function of automatically adjusting the OSPF, OSPFv3, or BGP cost value after the standby device assumes the active role when the active and standby devices are disconnected unexpectedly is enabled, and the cost value of the dynamic route advertised by the standby device automatically increases by 1.

Format

hrp breakdown adjust { ospf-cost | ospfv3-cost | bgp-cost } enable [ add [ add-cost ] ]

undo hrp breakdown adjust { ospf-cost | ospfv3-cost | bgp-cost } enable

Parameters

Parameter Description Value
ospf-cost

Indicates adjusting the OSPF cost value.

-
ospfv3-cost

Indicates adjusting the OSPFv3 cost value.

-
bgp-cost

Indicates adjusting the BGP cost value.

-
add add-cost

Indicates the added cost value.

The value is an integer from 1 to 65535.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After this function is enabled, the cost value of dynamic routes (OSPF, OSPFv3, and BGP) automatically increases by the value of add-cost after the standby device assumes the active role when the active and standby devices are disconnected unexpectedly. This prevents the two devices from advertising the same cost value.

Precautions

You can run the hrp adjust enable command to enable the device to adjust the cost value of dynamic routes based on the active/standby priority in normal cases to affect route selection. The hrp breakdown adjust enable command is used when the active and standby devices are disconnected unexpectedly. Because the status of the peer device cannot be obtained, the standby device B assumes the active role, and the active device A is also in the active state. To prevent the active and standby devices from advertising the same cost value, the cost value of the dynamic route advertised by the standby device B automatically increases by the value of add-cost.

Example

# Enable the breakdown cost adjustment function for OSPF routes.
<HUAWEI> system-view
[HUAWEI] hrp breakdown adjust ospf-cost enable
