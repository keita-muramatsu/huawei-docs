hrp track trunk-member enable

Function

The hrp track trunk-member enable command enables the HRP module to monitor the status of Trunk members.

The undo hrp track trunk-member enable command disables the HRP module to monitor the status of Trunk members.

By default, HRP is enabled to monitor the status of trunk member interfaces.

Format

hrp track trunk-member enable

undo hrp track trunk-member enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

After HRP is enabled to monitor the status of trunk member interfaces: If the VRRP group is configured on the Eth-Trunk interface or Eth-Trunk sub-interface, when a member interface of the Eth-Trunk interface is faulty, an HRP active/standby switchover is triggered even if the Eth-Trunk interface is still up. If the hrp track interface Eth-Trunk command is configured in the system view, when a member interface of the Eth-Trunk interface is faulty, an HRP active/standby switchover is triggered even if the Eth-Trunk interface is still up.

The HRP module is disabled from monitoring the status of the Eth-Trunk member interfaces. In the preceding situations, an HRP active/standby switchover is not triggered as long as the Eth-Trunk interface is up.

In addition, after HRP is enabled to monitor the status of trunk member interfaces, member interfaces cannot be directly added to the Eth-trunk interface.

Example

# Disable the HRP module to monitor the status of Trunk members.
<HUAWEI> system-view
[HUAWEI] undo hrp track trunk-member enable
