esp encryption-algorithm (IPsec proposal view)

Function

The esp encryption-algorithm command configures the ESP encryption algorithm.

The undo esp encryption-algorithm command configures ESP not to encrypt packets.

By default, the ESP encryption algorithm is AES-256-GCM-128.

Format

esp encryption-algorithm { des | 3des | aes-128 | aes-192 | aes-256 | aes-128-gcm-128 | aes-128-gmac | aes-192-gcm-128 | aes-192-gmac | aes-256-gcm-128 | aes-256-gmac | sm4 } *

undo esp encryption-algorithm

Parameters

Parameter Description Value
des

Indicates that the Data Encryption Standard (DES) algorithm in Cipher Block Chaining (CBC) mode is used and the key length is 56 bits.

-
3des

Indicates that the Triple DES (3DES) algorithm in CBC mode is used and the key length is 168 bits.

-
aes-128

Indicates that the Advanced Encryption Standard (AES) algorithm in CBC mode is used and the key length is 128 bits.

-
aes-192

Indicates that the AES algorithm in CBC mode is used and the key length is 192 bits.

-
aes-256

Indicates that the AES algorithm in CBC mode is used and the key length is 256 bits.

-
aes-128-gcm-128

Indicates that the AES algorithm using the 128-bit Integrity Check Value (ICV) in Galois Counter Mode (GCM) mode is used and the key length is 128 bits.

-
aes-128-gmac

Indicates that the AES algorithm in Galois Message Authentication Code (GMAC) mode is used and the key length is 128 bits.

-
aes-192-gcm-128

Indicates that the AES algorithm using the 128-bit ICV in GCM mode is used and the key length is 192 bits.

-
aes-192-gmac

Indicates that the AES algorithm in GMAC mode is used and the key length is 192 bits.

-
aes-256-gcm-128

Indicates that the AES algorithm using the 128-bit ICV in GCM mode is used and the key length is 256 bits.

-
aes-256-gmac

Indicates that the AES algorithm in GMAC mode is used and the key length is 256 bits.

-
sm4

Indicates that the SM4 algorithm defined by China's National Password Administration is used and the key length is 128 bits.

-

Views

IPsec proposal view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

ESP allows authenticating and encrypting packets at the same time, or only authenticating or encrypting packets. The ESP authentication and encryption algorithms cannot be both empty.

Prerequisites

esp or ah-esp has been specified in the transform command.

Precautions

The IPsec proposals referenced in IPsec policies on two ends of an IPsec tunnel must use the same ESP encryption algorithm.

The undo esp encryption-algorithm command does not restore the default encryption algorithm. Instead, it sets the encryption algorithm to null, which means that no encryption is performed. The undo esp encryption-algorithm command takes effect only when an encryption algorithm is used.

To improve the success rate of IKE negotiation, the device supports multiple encryption algorithms. During IKE negotiation, the device negotiates an encryption algorithm with the peer end in descending order of security level. The security levels of encryption algorithms that can be referenced in IPsec proposals are listed as follows: SM4 > AES-256-GCM-128 > AES-192-GCM-128 > AES-128-GCM-128 > AES-256-GMAC > AES-192-GMAC > AES-128-GMAC > AES-256 > AES-192 > AES-128 > 3DES > DES.

When a GCM or GMAC algorithm is used, the esp authentication-algorithm command does not take effect because the algorithm also provides authentication assurance.

SM4 can meet the high confidentiality and security requirements, but takes a comparatively long time for processing. To meet general security requirements, the AES-256-GCM-128, AES-192-GCM-128, AES-128-GCM-128, AES-256-GMAC, AES-192-GMAC, and AES-128-GMAC encryption algorithms are recommended. The 3DES, DES, and AES-CBC algorithms are not recommended.

You can specify parameters 3des, des, aes-128, aes-192, and aes-256 in this command only after the weak security algorithm/protocol feature package (WEAKEA) is installed using the install feature-software WEAKEA command.

You can specify the sm4 parameter in this command only after the IKEv1 feature package is installed.

If the IKEv1 feature package has been installed, AES algorithms in CBC mode can also be used.

Example

# Set the encryption algorithm used by ESP in the IPsec proposal newprop1 to AES-128-GCM-128. 
<HUAWEI> system-view
[HUAWEI] ipsec proposal newprop1
[HUAWEI-ipsec-proposal-newprop1] transform esp
[HUAWEI-ipsec-proposal-newprop1] esp encryption-algorithm aes-128-gcm-128
