display hrp interface

Function

The display hrp interface command displays the status of the heartbeat interface.

Format

display hrp interface

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

After hot standby is configured, you can run the display hrp interface command to check the status of heart interface.

Precautions

You can view status information of heart interface only after running the hrp enable command to enable hot standby.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the heartbeat interfaces status.
<HUAWEI> display hrp interface
10GE0/0/2 : running
10GE0/0/1 : ready
Table 1 Description of the display hrp interface command output
Item Description
10GE0/0/2 : running

A heartbeat interface works in one of the following statuses:

  • running: indicates the currently used heartbeat interface.
  • ready: indicates a standby heartbeat interface. The device supports a maximum of 16 heartbeat interfaces. If there are multiple heartbeat interfaces, the device uses one of them to send heartbeat packets, and the others are standby. If the currently used heartbeat interface is faulty, a standby one is used. The configuration sequence determines the priorities of the heartbeat interfaces.
  • invalid: indicates that the interface is unavailable. It is possible that the interface does not have IP addresses or has been switched to the Layer 2 mode.
  • down: indicates that the interface is down.
  • negotiation failed: indicates that the negotiation with the peer device on the active/standby status fails. The possible cause is that the software version of the local device is inconsistent with that of the peer device, the configuration of the local or peer device is incorrect, the peer heartbeat interface is Down, the HRP source or destination port number is changed, or the underlying link is disconnected.
