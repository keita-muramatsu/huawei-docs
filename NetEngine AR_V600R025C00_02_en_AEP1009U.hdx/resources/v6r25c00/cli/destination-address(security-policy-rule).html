destination-address (Security policy rule view)

Function

The destination-address command sets the destination addresses to which a security policy rule applies.

The undo destination-address command deletes the destination addresses to which a security policy rule applies.

By default, this function is not configured.

Format

For AR8100 series, AR8700 series, AR6700-H series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5700-H series, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR5710-S8TWDSE-LTE4EA, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S10T1X2, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S:

destination-address { address-set address-set-name &<1-6> | ipv4-address { ipv4-mask-length | mask mask-address | wildcard wildcard } | range ipv4-start-address ipv4-end-address | domain-set domain-set-name &<1-6> | any }

destination-address geo-location geo-location-name

destination-address { ipv6-address ipv6-prefix-length | range ipv6-start-address ipv6-end-address }

undo destination-address { address-set address-set-name &<1-6> | ipv4-address { ipv4-mask-length | mask mask-address | wildcard wildcard } | range ipv4-start-address ipv4-end-address | domain-set domain-set-name &<1-6> | all }

undo destination-address geo-location geo-location-name

undo destination-address { ipv6-address ipv6-prefix-length | range ipv6-start-address ipv6-end-address }

For AR5700-H series, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR5710-S8TWDSE-LTE4EA, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S10T1X2, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S:

destination-address none

Parameters

Parameter Description Value
address-set address-set-name

Specifies the name of an address or address group.

The value is a string of 1 to 63 case-sensitive characters.
ipv4-address

Specifies an IPv4 address.

The value is in dotted decimal notation.
ipv4-mask-length

Specifies a mask for an IPv4 address.

The value is an integer that ranges from 1 to 32.
mask mask-address

Specifies a mask for an IPv4 address.

The value is in dotted decimal notation.
wildcard wildcard

Specifies the wildcard of an IPv4 address.

The value is in dotted decimal notation.
range

Indicates the address range.

-
ipv4-start-address

Specifies the start address of an IPv4 address range.

The value is in dotted decimal notation.
ipv4-end-address

Specifies the end address of an IPv4 address range.

The value is in dotted decimal notation.
domain-set domain-set-name

Specifies the name of a domain group.

The value must be the name of an existing domain group. A maximum of six domain groups can be referenced at a time. When an IP address corresponds to multiple domain names, a maximum of 128 domain names can be queried for the IP address. If the domain name in the policy rule is not among the 128 queried domain names, the policy cannot be matched. You are advised to configure multiple domain names of the same IP address in the same policy rule.
any

Indicates any destination address.

-
geo-location geo-location-name

Indicates the name of a geolocation.

The value is a string of 1 to 63 case-sensitive characters.
ipv6-address

Specifies an IPv6 address.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
ipv6-prefix-length

Specifies the prefix length of an IPv6 address.

The value is an integer ranging from 1 to 128.
ipv6-start-address

Specifies the start address of an IPv6 address range.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
ipv6-end-address

Specifies the end address of an IPv6 address range.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
all

Deletes all destination addresses to which a security policy rule applies.

-
none

Clears the destination address condition.

NOTE:

This parameter is supported only on the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA.

-

Views

Security policy rule view

Default Level

2: Configuration level

Usage Guidelines

If a packet matches any IP address, the packet matches the condition.

If the destination address condition is set to none, the rule does not take effect.

When the mandatory condition verification function of a security policy is enabled (using the security-policy required-object check enable command), a new rule does not take effect if any of the source address, destination address, and service is not configured or is set to none. For a created rule, after the source address, destination address, or service condition is cleared, the condition is set to none. As a result, the rule becomes invalid.

Before referencing the geo-location <geo-location-name> parameter, you need to load the geolocation database. You are advised to download the latest geolocation database and run the update local location-sdb file file-name command to load it.

Example

# Set the destination address in the security policy rule view. 
<HUAWEI> system-view
[HUAWEI] security-policy
[HUAWEI-policy-security] rule name policy_sec
[HUAWEI-policy-security-rule-policy_sec] destination-address 10.1.1.0 24
