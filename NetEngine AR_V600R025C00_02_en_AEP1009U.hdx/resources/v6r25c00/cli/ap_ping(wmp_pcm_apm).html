ap-ping

Function

The ap-ping command configures a specified AP to ping a network device and displays the returned result.

Format

ap-ping ap-id ap-id [ -c count | -s packetsize | -m time | -t timeout ] * host

Parameters

Parameter Description Value
ap-id ap-id

Specifies the ID of an AP used to ping other network devices.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
-c count

Specifies the number of ICMP Echo Request packets to be sent.

The value is an integer that ranges from 1 to 10. The default value is 4.
-s packetsize

Specifies the length of an Echo Request packet excluding the IP header and ICMP header.

The value is an integer that ranges from 20 to 8100, in bytes. The default value is 56 bytes.
-m time

Specifies the time to wait before sending the next ICMP Request packet.

The value is an integer that ranges from 1 to 5000, in milliseconds. The default value is 2000 ms.
-t timeout

Specifies the timeout period for an ICMP Echo Response packet.

The value is an integer that ranges from 0 to 10000, in milliseconds. The default value is 2000 ms.
host

Specifies the domain name or IP address of the destination host.

The value is a string of 1 to 20 characters.

Views

WLAN view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

· You can run this command to check the connectivity between an AP and a network device by pinging the network device from the AP.

· Before running this command, ensure that the AP is online and has been configured with an IP address.

Precautions

  • This command may take a long time. Parameters such as the waiting time affect the command execution time.
  • Only one AP can perform the ping operation at a time.

Example

# Configure the AP with the ID of 19 to perform a ping operation.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-ping ap-id 19 10.1.1.1
Warning: This operation maybe takes several minutes, continue?[Y/N]:y
Info: Run command "display ap-ping status" to view the result.
