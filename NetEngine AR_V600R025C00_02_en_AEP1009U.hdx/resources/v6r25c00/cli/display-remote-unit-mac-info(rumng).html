display remote-unit mac-address

Function

The display remote-unit mac-address command displays detailed information about a specified MAC address learned by an RU.

Format

display remote-unit { connect-interface { interface-name | interface-type interface-number } | name remote-unit-name } mac-address address

Parameters

Parameter Description Value
connect-interface interface-name

Specifies the name of an interface.

The value is a string of 1 to 31 characters and must be set according to the device configuration.
connect-interface interface-type interface-number

Specifies the type and number of an interface. The interface type and number can be closely next to each other or separated by a space character.

The value ranges from 1 to 32, depending on the device configuration.
name remote-unit-name

Specifies the alias of an RU.

The value is a string of 1 to 32 case-sensitive characters. It cannot contain spaces.
mac-address address

Specifies a MAC address learned by an RU.

The value is a character string in the format of X-X-X.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run this command to view information about a specified MAC address entry learned by an RU, including the MAC address, VLAN to which the outbound interface belongs, outbound interface corresponding to the MAC address, and MAC address type.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display information about the entry with the MAC address 00e0-fc55-0374 learned by the RU connected to 10GE0/0/1 on the central device.
<HUAWEI> display remote-unit connect-interface 10GE0/0/1 mac-address 00e0-fc55-0374
-----------------------------------------------------------                                                                         
MAC Address          VLAN     Learned-From         Type                                                                             
-----------------------------------------------------------                                                                         
00e0-fc55-0374       1        GE1                  dynamic                                                                          
-----------------------------------------------------------

Item Description

Learned MAC address.
VLAN
