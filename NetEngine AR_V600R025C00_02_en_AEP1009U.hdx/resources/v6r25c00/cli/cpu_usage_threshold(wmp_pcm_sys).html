cpu-usage threshold

Function

The cpu-usage threshold command configures a CPU usage alarm threshold for APs.

The undo cpu-usage threshold command restores the default CPU usage alarm threshold for APs.

By default, the CPU usage alarm threshold of APs is 90.

Format

cpu-usage threshold threshold-value

undo cpu-usage threshold

Parameters

Parameter Description Value
threshold-value

Specifies the CPU usage alarm threshold of APs.

The value is an integer ranging from 50 to 100. The default value is 90.

Views

AP system profile view

Default Level

2: Configuration level

Usage Guidelines

You can run the cpu-usage threshold command to configure the CPU usage alarm threshold in the AP system profile view. The configuration is delivered to all APs using the profile.

  • When the CPU usage of an AP exceeds the alarm threshold, the AP sends an alarm to the AC, where alarm information is displayed.
  • When the CPU usage of an AP falls below the alarm threshold, the AP sends a clear alarm to the AC, where alarm clearance information is displayed.

Example

# Set the CPU usage alarm threshold to 60.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name ap-system1
[HUAWEI-wlan-ap-system-prof-ap-system1] cpu-usage threshold 60
