work-mode

Function

The work-mode command configures an IFIT working mode in tunnel-level measurement scenarios and enters the IFIT working mode view.

The undo work-mode command deletes the configured IFIT working mode in tunnel-level measurement scenarios.

By default, no IFIT working mode is configured in tunnel-level measurement scenarios.

Format

work-mode mcp

work-mode dcp

work-mode auto

undo work-mode [ mcp | dcp | auto ]

Parameters

Parameter Description Value
dcp

Indicates the DCP mode, that is, the device is configured as a Data Collecting Point (DCP).

-
auto

Indicates the auto mode, that is, automatic data measurement is performed.

-
mcp

Indicates the MCP mode, that is, the device is configured as a Measurement Control Point (MCP).

-

Views

IFIT view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To measure the packet loss and delay of services in tunnel-level IFIT measurement scenarios, run this command to configure an IFIT working mode. In MCP mode, the node is used for data aggregation and calculation. In DCP mode, the node is used for data collection. In auto mode, the node can be used for both data collection and calculation. The IFIT working mode has the following limitations:

  • IFITMCP calculation can be performed only when a device in auto mode interworks with a device in auto mode.
  • IFITMCP calculation can be performed only when a device in MCP mode interworks with a device in DCP mode.

Prerequisites

IFIT has been enabled globally.

Precautions

IFIT local computing has high requirements on device performance and is affected by the CPU processing capability, number of boards, and CPCAR value. As such, IFIT local computing must be deployed on high-performance devices with four or more cores, and the CPCAR value must be adjusted. If IFIT local computing is deployed on low-performance devices, local results cannot be calculated.

In AUTO mode, only the measurement data of the ingress is collected. When you run the display ifit statistic-type command to query the statistical result, the remote statistics may be displayed as -, meaning that the result cannot be used as a reference.

Example

# Set the IFIT working mode to MCP in tunnel-level measurement scenarios.
<HUAWEI> system-view
[HUAWEI] ifit
[HUAWEI-ifit] work-mode mcp
