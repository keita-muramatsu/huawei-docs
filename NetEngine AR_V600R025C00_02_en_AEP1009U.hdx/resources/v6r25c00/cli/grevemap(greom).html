map interface (Tunnel interface view)

Function

The map interface command binds a VE interface to a tunnel interface.

The undo map interface command unbinds a specified interface from a tunnel interface.

By default, no interface is bound to a GRE tunnel.

Format

map interface { ifName | ifType ifNum } [ priority priority-value ]

undo map interface { ifName | ifType ifNum } [ priority priority-value ]

Parameters

Parameter Description Value
ifName

Specifies the name of an interface to be bound.

The value is a string of 1 to 63 case-sensitive characters. It cannot contain spaces.
ifType

Specifies the type of the interface to be bound.

-
ifNum

Specifies the number of the interface to be bound.

-
priority priority-value

Specifies the priority of a VE interface bound to a tunnel interface.

The value is an integer ranging from 0 to 255.

A larger value indicates a higher priority.

Views

Tunnel interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Ethernet packets need to be transparently transmitted over another network layer protocol (such as IPv4) through GRE. In this case, you can configure Ethernet over GRE and run the map interface command to bind a VE interface to the tunnel interface view. In this manner, Ethernet packets can be forwarded through the tunnel interface and transparently transmitted through the GRE tunnel.

To deploy the EoGRE master/backup solution, specify priority priority-value to configure a priority for binding a VE interface to a tunnel interface.The tunnel corresponding to the tunnel interface with a higher priority becomes the primary tunnel.

Prerequisites

A tunnel interface has been created using the interface tunnel command.

The encapsulation mode of the tunnel has been set to GRE by running the tunnel-protocol gre command.

A VE interface has been created using the interface Virtual-Ethernet command.

Precautions

In primary/backup EoGRE scenarios:

  • A VE interface can be bound to a maximum of two tunnel interfaces, and only one tunnel interface takes effect at a time.
  • When a VE interface is bound to two tunnel interfaces, the priorities of the two tunnel interfaces must be different. When a VE interface is bound to the second tunnel interface and the priority used by the VE interface is the same as that used by the first tunnel interface, the device reports an error.
  • A tunnel interface can be bound to only one VE interface.

Example

# Bind a VE interface to the tunnel interface and set the priority of the tunnel interface.
<HUAWEI> system-view
[HUAWEI] interface Virtual-Ethernet 0/0/1
[HUAWEI-Virtual-Ethernet0/0/1] quit
[HUAWEI] interface Tunnel 1
[HUAWEI-Tunnel1] tunnel-protocol gre
[HUAWEI-Tunnel1] map interface virtual-ethernet 0/0/1 priority 120
