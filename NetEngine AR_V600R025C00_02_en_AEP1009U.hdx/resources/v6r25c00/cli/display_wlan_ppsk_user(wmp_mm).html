display wlan ppsk-user

Function

The display wlan ppsk-user command displays the PPSK user configuration.

Format

display wlan ppsk-user { all | mac | ssid | cache }

Parameters

Parameter Description Value
all

Displays detailed information about all PPSK users.

-
mac

Displays information about PPSK users bound to MAC addresses.

-
ssid

Displays information about PPSK users connected to SSIDs.

-
cache

Displays information about PPSK users in the cache. Information about PPSK users who have connected to the network is saved to the cache. You can specify this parameter to check the configuration of these users.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

After configuring PPSK users, you can run this command to check the configuration and detailed online information about the PPSK users. The command output can help you locate and rectify faults related to the PPSK users.
