dfs smart-selection disable

Function

The dfs smart-selection disable command disables the DFS smart selection function.

The undo dfs smart-selection disable command restores the DFS smart selection function.

By default, the DFS smart selection function is enabled.

Format

dfs smart-selection disable

undo dfs smart-selection disable

Parameters

None

Views

RRM profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After the DFS smart selection function is enabled, an AP operating on the 5 GHz frequency band detects radar signals. When a radar channel is detected, the AP automatically switches to another channel to prevent radar interference.

When an AP switches its operating channel upon detecting radar signals, it randomly selects a channel (a calibration channel preferentially) allowed by the country code. If the selected channel is the same as or adjacent to the operating channels of surrounding 5 GHz radios, severe interference will occur, deteriorating network access experience. In this case, the DFS smart selection function (enabled by default) allows the AP to switch to a 5 GHz channel with the minimum interference.

After the dfs smart-selection disable command is executed, the DFS smart selection function is disabled, affecting user experience. Configure this function as required.

Precautions

The DFS smart selection function can take effect only when air scan is enabled.

Example

# Disable DFS smart selection.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] rrm-profile name default
[HUAWEI-wlan-rrm-prof-default] dfs smart-selection disable
