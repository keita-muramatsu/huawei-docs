mpls (Interface view)

Function

The mpls command enables MPLS on an interface.

The undo mpls command disables MPLS on an interface.

By default, MPLS is not enabled on an interface.

Format

mpls

undo mpls

Parameters

None

Views

10GE sub-interface view, 10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE sub-interface view, 40GE interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, Ethernet sub-interface view, Ethernet interface view, GE optical interface view, GE sub-interface view, GE interface view, GE electrical interface view, MP-group interface view, Multi-GE sub-interface view, Multi-GE interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

On a network where MPLS services need to be deployed, after enabling MPLS globally on a node, you need to enable MPLS on the interface of the node before performing other MPLS configurations.

Prerequisites

MPLS has been enabled globally using the mpls command in the system view.

Follow-up Procedure

Perform other MPLS configurations.

Precautions

Running the undo mpls command in the interface view causes the deletion of all MPLS configurations on the interface.

Example

# Enable MPLS on an interface. 
<HUAWEI> system-view
[HUAWEI] mpls
[HUAWEI-mpls] quit
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] mpls
