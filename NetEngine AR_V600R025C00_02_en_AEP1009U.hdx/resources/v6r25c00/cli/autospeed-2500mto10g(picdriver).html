speed auto(25GE interface view)

Function

The speed auto command configures the negotiation rate capability set of an interface in auto-negotiation mode.

The undo speed auto command restores the default negotiation rate capability set of an interface in auto-negotiation mode.

By default, the auto-negotiation rate range includes all configurable rates.

Format

speed auto { 2500 | 5000 | 10000 } *

undo speed auto [ 2500 | 5000 | 10000 ] *

Parameters

Parameter Description Value
2500

Indicates the 2500M port speed mode.

-
5000

Indicates the 5000M port speed mode.

-
10000

Indicates the 10000M port speed mode.

-

Views

25GE-L2 view, 25GE interface view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In auto-negotiation mode, the rate of an interface is negotiated with the peer interface, but the negotiated rate may not meet the actual requirement. You can run the command to set the negotiated rate.

Prerequisites

Run the undo negotiation disable command to configure the Ethernet interface to work in auto-negotiation mode.

Precautions

  • This command can be run only when the device supports 10GE copper modules.
  • If you run the speed auto command on an interface that is physically up, the physical status of the interface becomes down and then up. Therefore, exercise caution when using this command.

Example

# When a 10GE copper module is installed on a 25GE interface, configure the negotiation rate capability set of the interface in auto-negotiation mode to 2500, 5000, and 10000.
<HUAWEI> system-view
Enter system view, return user view with return command.
[HUAWEI] interface 25GE0/0/0
[HUAWEI-25GE0/0/0] speed auto 2500 5000 10000
