display remote-unit macsec statistics

Function

The display remote-unit macsec statistics command displays statistics about data packets protected by MACsec on an RU.

Format

display remote-unit macsec statistics port [ port-id ] { connect-interface { interface-name | interface-type interface-number } | name remote-unit-name }

Parameters

Parameter Description Value
connect-interface interface-name

Name of an interface.

-
interface-type

Specifies an interface type.

-
interface-number

Specifies an interface number.

-
name remote-unit-name

Specifies the RU name.

The value is a string of 1 to 32 case-sensitive characters. It cannot contain spaces.
port port-id

Port index of the remote module.

The value is an integer in the range from 1 to 34. If the specified interface index is larger than the largest one on the RU, the command is not issued to the RU. port-id indicates the port ID of an RU, which may be different from the physical port number printed on the panel. For example, if the downlink port numbers are 1 to 8 and the uplink port numbers are 9 to 10 on the panel, set port-id to an integer in the range from 1 to 10 according to the actual port for connection. If the downlink port numbers are 1 to 8 and the uplink port numbers are 1 to 2 on the panel, set port-id to an integer in the range from 1 to 10 (1 to 8: downlink ports; 9: uplink port 1; 10: uplink port 2).

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

This command displays MACsec statistics about RUs, which help you locate problems in routine maintenance.

Number of packets failing the replay check.

Number of packets failing the ICV check.
Notag

Number of discarded packets without MACsec tags.

Number of packets that are discarded because no SA is matched.

Number of sent packets protected by MACsec.

Number of encrypted bytes.
