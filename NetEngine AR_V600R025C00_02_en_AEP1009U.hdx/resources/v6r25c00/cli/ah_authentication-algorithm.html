ah authentication-algorithm

Function

The ah authentication-algorithm command configures the AH authentication algorithm.

The undo ah authentication-algorithm command restores the default AH authentication algorithm.

By default, the AH authentication algorithm is SHA2-256.

Format

ah authentication-algorithm { md5 | sha1 | sha2-256 | sha2-384 | sha2-512 | sm3 } *

undo ah authentication-algorithm

Parameters

Parameter Description Value
md5

Uses the message digest algorithm 5 (MD5) authentication algorithm.

-
sha1

Uses the Secure Hash Algorithm 1 (SHA-1) authentication algorithm.

-
sha2-256

Uses the SHA2-256 authentication algorithm.

-
sha2-384

Uses the SHA2-384 authentication algorithm.

-
sha2-512

Uses the SHA2-512 authentication algorithm.

-
sm3

Uses the SM3 authentication algorithm.

-

Views

IPsec proposal view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

AH does not provide the encryption function and only authenticates packets.

To improve the negotiation success rate of IPsec proposals, the device supports multiple authentication algorithms. During IKE negotiation, the system selects algorithms in descending order of security level. The authentication algorithms used in an IPsec proposal are listed in descending order of security level: sm3 > sha2-512 > sha2-384 > sha2-256 > sha1 > md5.

Prerequisites

ah or ah-esp has been specified in the transform command.

Precautions

The IPsec proposals referenced in IPsec policies on two ends of an IPsec tunnel must use the same AH authentication algorithm.

SM3 can meet the high confidentiality and security requirements, but takes a comparatively long time for processing. To meet general security requirements, using SHA2-256, SHA2-384, or SHA2-512 is recommended. MD5 and SHA1 are not recommended because they are not secure enough.

You can specify the md5 and sha1 parameters in this command only after the weak security algorithm/protocol feature package (WEAKEA) is installed using the install feature-software WEAKEA command.

You can specify the sm3 parameter in this command only after the IKEv1 feature package is installed.

Example

# Specify the SHA2-256 algorithm for the AH protocol in the IPsec proposal newprop1. 
<HUAWEI> system-view
[HUAWEI] ipsec proposal newprop1
[HUAWEI-ipsec-proposal-newprop1] transform ah
[HUAWEI-ipsec-proposal-newprop1] ah authentication-algorithm sha2-256
