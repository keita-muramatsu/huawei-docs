reset per-packet-compress statistics

Function

The reset per-packet-compress statistics command clears statistics about the per-packet compression function.

This command is supported only on the AR8700 series, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series and AR6700-H series.

Format

reset per-packet-compress statistics

Parameters

None

Views

User view

Default Level

3: Management level

Usage Guidelines

After this command is run, statistics about per-packet compression are cleared and cannot be restored.

To view statistics about per-packet compression, run the display per-packet-compress statistics command.

Example

# Clear historical statistics about per-packet compression.
<HUAWEI> reset per-packet-compress statistics
