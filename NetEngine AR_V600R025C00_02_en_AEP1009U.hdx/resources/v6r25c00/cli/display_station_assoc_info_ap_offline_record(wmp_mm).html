display station assoc-info ap-offline-record(all views)

Function

The display station assoc-info ap-offline-record command displays information about STAs that go online on offline APs.

Format

display station assoc-info ap-offline-record { all | ap-id ap-id [ radio radio-id ] }

Parameters

Parameter Description Value
all

Displays information about STAs that go online on all offline APs.

-
ap-id ap-id

Displays information about STAs that go online on an offline AP with a specified ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
radio radio-id

Displays information about STAs that go online on a specified radio of an offline AP.

The value is an integer ranging from 0 to 4.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

When link faults occur between the AC and APs, the APs in fault state allow access of new STAs and log STA information. When the faulty links recover and are re-established, the APs disconnect these STAs and send STA information to the AC. To check information about the STAs that connect to the APs in fault state, run the display station assoc-info ap-offline-record command on the AC.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display information about STAs that go online on all offline APs.
<HUAWEI> display station assoc-info ap-offline-record all
Offline Station information list: 
Total: 1 
------------------------------------------------------------------------------
STA MAC          AP ID    AP name   Radio ID  SSID
------------------------------------------------------------------------------
00e0-fc12-3456   1        ap1       0         SSID_MYWLAN
------------------------------------------------------------------------------

Item Description
Offline Station information list

Offline STA information list.

MAC address of a STA.
AP ID

ID of the AP to which a STA connects.
AP name

Name of the AP to which a STA connects.
Radio ID

Radio to which a STA connects.
SSID

SSID to which the STA connects.

Total count.
