sync-address

Function

The sync-address command sets the source IP address range to be synchronized for online users on the TSM SSO server. Only the users whose source IP addresses are in the specified range can be queried and synchronized.

The undo sync-address command deletes the configured source IP address range.

By default, no source IP address range to be synchronized is specified for online users on the TSM SSO server.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR5710-S8P1XDSE-2LTE4EA.

Format

sync-address address-set address-set-name

undo sync-address address-set address-set-name

Parameters

Parameter Description Value
address-set address-set-name

Specifies an address set as the matching condition of the IP addresses to be synchronized. address-set-name specifies the name of the address set.

The name is a string of 1 to 63 case-sensitive characters. If the name contains spaces, it must be enclosed with double quotation marks (""), for example, "user for test."

The name cannot contain question marks (?). If the name does not contain spaces, it cannot contain double quotation marks (""). The name cannot be any or all.

Views

TSM SSO view

Default Level

2: Configuration level

Usage Guidelines

The specified source IP address range must be the same as the IP address range of users who log in to the device through TSM SSO. Generally, the IP address range is the IP address range configured in Terminal IP Address List when the device is added to the TSM SSO server as the online behavior management device.

A maximum of six address set objects can be configured. Address groups cannot be configured.

Example

# Set the source IP address range to be synchronized for online users on the TSM SSO server to address set test.
<HUAWEI> system-view
[HUAWEI] ip address-set test type object
[HUAWEI-object-address-set-test] quit
[HUAWEI] identity-management
[HUAWEI-identity-management] sso-tsm
[HUAWEI-identity-management-sso-tsm] sync-address address-set test
