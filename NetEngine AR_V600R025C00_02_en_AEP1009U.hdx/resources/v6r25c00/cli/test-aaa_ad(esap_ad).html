test-aaa ad-template

Function

The test-aaa ad-template command tests the connectivity between the device and AD server to check whether the AD server can authenticate users properly.

Format

test-aaa user-name user-password ad-template template-name

Parameters

Parameter Description Value
user-name

Specifies a user name.

The value is a string of 1 to 253 case-insensitive characters. When the user name contains spaces, it must be enclosed in double quotation marks ("").
user-password

Specifies a user password.

The value is a string of 1 to 128 case-sensitive characters. It cannot contain spaces.
ad-template template-name

Specifies the name of an AD server template.

The AD server template must exist.

Views

All views

Default Level

3: Management level

Usage Guidelines

Usage Scenario

This command tests the service reachability from an access device to a server. The device sends an authentication request packet to the server. If the server returns an authentication success packet, the device and server can communicate with each other. If the server's response times out, the device and server cannot communicate with each other.

Prerequisites

An authentication server template or accounting server template has been created, an authentication server or accounting server has been specified in the authentication server template or accounting server template, and the authentication server or accounting server has been configured.

Follow-up Procedure

If the test result indicates that the user fails to be authenticated by using authentication server or the accounting server fails to charge the user, check whether the configuration of the authentication server template and the authentication server is correct, and check the connectivity between the device and the authentication server.

Precautions

Before running this command, you only need to create a server template and configure an authentication server.

When the user name is enclosed in double quotation marks (" "), the double quotation marks (" ") are sent to the AD server as a part of the user name during AD server detection.

Example

# Test whether the user user1 can be authenticated using the template huawei.
<HUAWEI> test-aaa user1 YsHsjx_202206 ad-template huawei
