peer low-memory exempt(BGP-VPN instance IPv4 address family view) (group)

Function

The peer low-memory exempt command configures the device to exempt a peer group when the memory of the device is in danger state and BGP escape starts.

The undo peer low-memory exempt command restores the default configuration.

By default, a peer group is not exempted.

Format

peer groupName low-memory exempt

undo peer groupName low-memory exempt

Parameters

Parameter Description Value
groupName

Specifies the name of a peer group.

The name is a string of 1 to 47 case-sensitive characters, with spaces not supported. When double quotation marks are used around the string, spaces are allowed in the string.

Views

BGP-VPN instance IPv4 address family view, BGP-VPN instance IPv6 address family view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After the BGP escape function upon a memory exception is enabled using the bgp memory-usage danger-threshold escape timeout command, the BGP peer is disconnected after the device memory stays in the danger state for a certain period of time. To prevent key services from being affected, you can run this command to exempt a peer group from disconnection.

Precautions

If disconnection exemption is enabled for a peer that has been disconnected, the device immediately attempts to reconnect to the peer. Accordingly, during the peer disconnection period, if disconnection exemption is disabled for the peer, the device immediately disconnects the peer.

Example

# In the BGP-VPN instance IPv4 address family view, configure the device to exempt the peer group test when the memory of the device is in danger state and BGP escape starts. 
<HUAWEI> system-view
[HUAWEI] ip vpn-instance vrf
[HUAWEI-vpn-instance-vrf] ipv4-family
[HUAWEI-vpn-instance-vrf-af-ipv4] route-distinguisher 100:1
[HUAWEI-vpn-instance-vrf-af-ipv4] quit
[HUAWEI-vpn-instance-vrf] quit
[HUAWEI] bgp 100
[HUAWEI-bgp] ipv4-family vpn-instance vrf
[HUAWEI-bgp-vrf] group test internal
[HUAWEI-bgp-vrf] peer test low-memory exempt
