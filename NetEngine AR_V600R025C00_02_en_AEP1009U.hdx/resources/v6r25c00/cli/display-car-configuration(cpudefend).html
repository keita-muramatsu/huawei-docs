display cpu-defend configuration

Function

The display cpu-defend configuration command displays the CAR configuration in wired mode.

Format

For AR8700 series, AR6700-H series:

display cpu-defend configuration [ packet-type packet-type ] mcu

For AR8100 series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5700-H series, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR5710-S8TWDSE-LTE4EA, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S10T1X2:

display cpu-defend configuration [ packet-type packet-type ] slot slot-id

display cpu-defend configuration [ packet-type packet-type ] all

Usage Guidelines

Usage Scenario

You can run this command to view the rate limits of protocol packets sent to the CPU. By default, the rate limits of protocol packets in the default policy are displayed.

After the device is initialized, for protocols displayed as disabled in the command output, you need to deliver the corresponding service configuration to change their status to enabled so that the CPU sending and rate limiting functions take effect for them.

Item Description

Rate limit for packets by default, in pps.
