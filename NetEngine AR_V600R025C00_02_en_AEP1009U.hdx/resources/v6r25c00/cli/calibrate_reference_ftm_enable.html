calibrate reference ftm-data enable

Function

The calibrate reference ftm-data enable command enables FTM data–based radio calibration.

The undo calibrate reference ftm-data enable command disables FTM data–based radio calibration.

By default, FTM data–based radio calibration is disabled.

Format

calibrate reference ftm-data enable

undo calibrate reference ftm-data enable

Parameters

None

Views

WLAN view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After an AC manages FTM-capable APs, you are advised to enable this function to improve the algorithm precision of radio calibration.

Prerequisites

The FTM function has been enabled for at least one SSID on the radio to be measured. This function is not supported by AR models and is not recommended.

Precautions

FTM data–based radio calibration take effect only on 5 GHz radios with the 80 MHz bandwidth.

In indoor multi-partition and cross-room coverage scenarios, if AirEngine XX76 and AirEngine XX73 series APs are deployed on the same network, FTM data–based radio calibration is not recommended.

Example

# Enable FTM data–based radio calibration.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] calibrate reference ftm-data enable
