signature-set

Function

The signature-set name command creates an IPS signature filter and displays its view.

The undo signature-set command deletes an IPS signature filter.

By default, no IPS signature filter is created.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

signature-set name name

undo signature-set { name name | all }

Parameters

Parameter Description Value
name name

Specifies the name of an IPS signature filter.

Specifies the name of an IPS signature filter. The value is a string of 1 to 32 characters. If the name contains spaces, enclose it with double quotation marks (""), for example, "user for test". The name cannot contain question marks (?), commas (,), or hyphens (-).
all

Deletes all IPS signature filters.

-

Views

Intrusion prevention profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The signature filter is a set of conditions for filtering signatures, based on the network and service status. The device can only defend against attacks corresponding to the signatures filtered out by the signature filter, preventing key attacks from being overwhelmed by large numbers of attack logs.

Precautions

After running this command, run the engine configuration commit command to commit the configuration for the configuration to take effect. You are advised to commit the configuration after all content security configurations are complete.

Example

# Create IPS signature filter hello in IPS profile profile1.
<HUAWEI> system-view
[HUAWEI] profile type ips name profile1
[HUAWEI-profile-ips-profile1] signature-set name hello
[HUAWEI-profile-ips-profile1-sigset-hello]
