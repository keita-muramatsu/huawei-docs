super

Function

The super command switches a user from the current privilege level to a specified one.

By default, privilege escalation is not performed on users.

Format

super [ user-level ]

Parameters

Parameter Description Value
user-level

Specifies the user privilege level.

The value is an integer that ranges from 0 to 3. A larger value indicates a higher user privilege level.

Views

User view

Default Level

0: Visit level

Usage Guidelines

Usage Scenario

The user privilege level refers to the classification of login users. The value ranges from 0 to 3, corresponding to the command privilege level. That is, after logging in to the system, a user can use only the commands whose privilege levels are equal to or lower than the user privilege level.

The user login mode can be Telnet, SSH, or terminal using AAA authentication.

To prevent unauthorized access, when a user is switched from a lower privilege level to a higher one, the user needs to enter the authentication password of the higher privilege level. You can run the super password command to set the authentication password for increasing a user privilege level.

If the entered target user privilege level is lower than or equal to the current one, the system sets the entered user privilege level to the target one and displays a message. If the entered target user privilege level is higher than the current one, the system prompts the user to enter the authentication password.

The password entered by a user is not displayed on the screen. If the user enters the correct password within three attempts, the user is switched to a higher privilege level. Otherwise, the user privilege level remains unchanged.

Precautions

The password is a string of 8 to 16 characters.

The password must contain at least two types of the following characters: uppercase letters, lowercase letters, digits, and special characters.

Special characters include ` ~ ! @ # $ % ^ & * ( ) - _ = + \ | [ { } ] ; : '" , < . > / ? and spaces.

The entered password is the password specified using the super password command for switching the user privilege level.

Example

# Log in as a local administrator and switch to the privilege level 1.
<HUAWEI> super 1
Now user privilege is 1 level, and only those commands whose level is equal to or less than this level can be used.
