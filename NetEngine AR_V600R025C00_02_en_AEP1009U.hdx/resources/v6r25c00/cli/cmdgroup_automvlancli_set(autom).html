wpa-type(net-assistant wlan-ssid view)

Function

The wpa-type command configures a network-wide WLAN security policy.

The undo wpa-type command deletes the network-wide WLAN security policy.

By default, no security policy is configured for a WLAN.

Format

wpa-type { wpa | wpa2 | wpa-wpa2 | wpa3 | wpa2-wpa3 } psk psk-paravalue

undo wpa-type

Parameters

Parameter Description Value
wpa

Specifies the WPA security policy.

-
wpa2

Specifies the WPA2 security policy.

-
wpa-wpa2

Specifies the WPA-WPA2 security policy.

-
wpa3

Specifies the WPA3 security policy.

-
wpa2-wpa3

Specifies the WPA2-WPA3 security policy.

-
psk psk-paravalue

Specifies the password for PSK authentication.

The value is a string of 8 to 63 ASCII characters, or 128, 148, 168, or 188 ciphertext characters.

The question mark (?) is supported, which you can enter by pressing Ctrl+Q.

A password cannot contain the space and double quotation mark (") at the same time. When the password contains a space, add the double quotation mark (") to the beginning and end of the string when entering the password. For example, if the password is YsHsjx 202206, enter "YsHsjx 202206".

For security purposes, you are advised to configure a key that contains at least two of the following: digits, lowercase letters, uppercase letters, and special characters.

Views

Net-assistant wlan-ssid view

Default Level

3: Management level

Usage Guidelines

To protect data transmitted by authorized users on WLANs, you can run this command to configure a network-wide WLAN security policy. If there are multiple types of terminals that support different security policies, you can configure a hybrid mode, such as WPA-WPA2 or WPA2-WPA3, to facilitate access of these terminals and facilitate network management.

Example

# Set the security policy to WPA-WPA2 and the key to YsHsjx_202206 for the WLAN huawei_wifi.
<HUAWEI> system-view
[HUAWEI] net-assistant
[HUAWEI-net-assistant] network
[HUAWEI-net-assistant-network] wlan-ssid huawei_wifi profile-name ssid123
[HUAWEI-net-assistant-network-wlan-ssid-huawei_wifi] wpa-type wpa-wpa2 psk YsHsjx_202206
