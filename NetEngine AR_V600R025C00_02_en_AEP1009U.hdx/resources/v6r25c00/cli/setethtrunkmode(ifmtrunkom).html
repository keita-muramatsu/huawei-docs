mode (Eth-Trunk interface view)

Function

The mode command configures or changes the working mode of an Eth-Trunk interface.

The undo mode command restores the default working mode of an Eth-Trunk interface.

By default, an Eth-Trunk interface works in manual load balancing mode.

Format

mode { lacp-static | manual load-balance }

undo mode

Parameters

Parameter Description Value
lacp-static

Specifies the working mode of an Eth-Trunk interface as static LACP.

-
manual

Specifies the working mode of an Eth-Trunk interface as manual.

-
load-balance

Indicates the manual load balancing mode.

-

Views

Layer 2 Eth-Trunk interface view, Eth-Trunk interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Currently, a device allows Eth-Trunk interfaces to work in the following modes:

  • Static LACP mode

    If the two devices to be directly connected over an Eth-Trunk link both support LACP, you can run the mode lacp-static command to create Eth-Trunk interfaces in static LACP mode. This mode can implement both load balancing and redundancy backup. In static LACP mode, you must manually create an Eth-Trunk interface and add member interfaces to the Eth-Trunk interface. Unlike link aggregation in manual load-balancing mode, active interfaces are selected based on LACPDUs in this mode. That is, after a group of interfaces are added to an Eth-Trunk interface, the devices at both ends determine active and inactive interfaces through LACP packets.
  • Manual load balancing mode

    If one of the devices at the two ends of an Eth-Trunk link does not support LACP, you can run the mode manual load-balance command to configure the Eth-Trunk interface to work in manual load balancing mode. In addition, you can add multiple member interfaces to increase the bandwidth between the two devices and improve reliability. The manual load balancing mode is a basic link aggregation mode. In this mode, you must manually create an Eth-Trunk interface, add interfaces to the Eth-Trunk interface, and specify active member interfaces. LACP is not involved in this process. In manual load balancing mode, all active member interfaces forward data and load-balance traffic. In manual load balancing mode, traffic can be evenly distributed among all the member interfaces. You can also set different weights for the member interfaces so that uneven load balancing can be carried out. This means that interfaces with greater weights transmit more traffic. If an active link fails, the remaining active links in the LAG share the traffic evenly or based on weights.

Precautions

If an Eth-Trunk interface does not work in manual load balancing mode, ensure that the Eth-Trunk interface does not have any member interface before changing the working mode of the Eth-Trunk interface.

When changing the working mode of an Eth-Trunk from manual mode to LACP mode, pay attention to the following points:

  • If an Eth-Trunk interface has member interfaces, the protection time for mode switching is 90 seconds.
  • During the mode switching, if the peer device does not switch the mode, the status of the local interface is the same as that before the switching.
  • After the mode switching protection time expires, if the peer end does not switch the mode, the negotiation on the local interface fails, and the protocol status of the Eth-Trunk interface goes Down. As a result, services are affected.

Example

# Change Eth-Trunk 1 and configure it to work in static LACP mode.
<HUAWEI> system-view
[HUAWEI] interface eth-trunk 1
[HUAWEI-Eth-Trunk1] mode lacp-static
