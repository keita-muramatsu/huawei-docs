cable-snr-test

Function

The cable-snr-test command tests the quality of a network cable connected to an Ethernet interface and displays the test result.

Format

cable-snr-test

Parameters

None

Views

Multi-GE interface view, Layer 2 multi-GE interface view, GE electrical interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If a network cable is faulty, the interface goes down, or the interface rate is abnormal even if the interface is up. You can run this command to check whether the network cable is faulty.

Precautions

  • This command checks real-time quality of the network cable on an interface, and the network cable quality changes with the external environment.
  • An interface that is down or in loopback detection mode does not support the network cable quality check.
  • After the interface goes up, wait several minutes before running this command. Otherwise, the command fails to be delivered.

Example

# Check the quality of the Ethernet cable connected to an Ethernet interface and display the check result.
<HUAWEI> system-view
[HUAWEI] interface GE0/0/0
[HUAWEI-GE0/0/0] cable-snr-test
Info: The current network cable is of good quality.
SNR Low Threshold : 24.0dB
Pair A : 28.0dB (OK)
Pair B : 27.9dB (OK)
Pair C : 27.8dB (OK)
Pair D : 28.1dB (OK)
Info: This command detects real-time data on the quality of the interface cable, which changes with the external environment.
Table 1 Description of the cable-snr-test command output
Item Description
Info: The current network cable is of good quality.

Current quality of a network cable.
SNR Low Threshold

Minimum SNR for determining whether the network cable quality is good. If the SNR of the network cable is greater than or equal to the value of SNR Low Threshold, the network cable quality is good. The displayed result is for reference only. You are advised to use a network cable analyzer to perform an accurate test.
Pair X

SNR of pair X. If the SNR is greater than or equal to the value of SNR Low Threshold, the network cable quality is good. If the SNR is less than the value of SNR Low Threshold, the network cable quality is poor and packet loss may occur. In this case, you are advised to replace the network cable with a network cable of good quality.
