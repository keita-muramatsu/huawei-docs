sa soft-duration (ISAKMP IPSec policy view)

Function

The sa soft-duration buffer command sets the soft timeout buffer time or traffic of an IPsec SA in an IPsec policy.

The undo sa soft-duration buffer command cancels the configuration.

By default, no soft timeout buffer time or traffic is configured for an IPsec SA in an IPsec policy.

Format

sa soft-duration { time-based buffer seconds | traffic-based buffer kilobytes }

undo sa soft-duration { time-based buffer | traffic-based buffer }

Parameters

Parameter Description Value
time-based

Indicates the soft timeout buffer time.

-
buffer seconds

Specifies the soft timeout buffer time of an IPsec SA.

The value is an integer ranging from 10 to 36000, in seconds.
buffer kilobytes

Specifies the soft timeout buffer traffic of an IPsec SA.

The value is an integer ranging from 7200 to 4187103, in KB.
traffic-based

Indicates the soft timeout buffer traffic.

-

Views

ISAKMP IPsec policy view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Before the hard lifetime expires, a new IPsec SA is negotiated to replace the original IPsec SA. The time from the establishment of the original IPsec SA to the negotiation of the new IPsec SA is the soft lifetime.

You can configure the soft timeout buffer time or traffic volume to adjust the time for IPsec SA renegotiation. The values of the soft timeout and soft timeout traffic are as follows:

  • After the soft timeout is configured, if the hard timeout minus the soft timeout is greater than 10 seconds, the system uses the hard timeout minus the soft timeout as the soft timeout. Otherwise, the system uses the default soft timeout.
  • After the soft lifetime is configured, if the hard lifetime minus the soft lifetime is greater than 7200 KB, the system uses the hard lifetime minus the soft lifetime as the soft lifetime. Otherwise, the system uses the default soft lifetime.

    The soft timeout buffer time and traffic volume of an IPsec SA can be configured globally or in an IPsec policy. The global configuration takes effect for all IPsec policies, and the configuration in an IPsec policy takes effect only for the specified IPsec policy.

Precautions

If the soft timeout buffer time/traffic volume is configured both globally and in the IPsec policy view, the soft timeout buffer time/traffic volume configured in the IPsec policy view takes effect.

When IKEv1 is used for negotiation:

  • After the IPsec SA soft lifetime expires, the responder cannot initiate IPsec SA renegotiation.
  • After the IKE SA has been deleted and the IPsec SA soft lifetime expires, the initiator cannot initiate IPsec SA renegotiation.

    When IKEv2 is used for negotiation:
  • After the ike negotiate compatible command is run in the IKE peer view on the responder, the responder cannot initiate IPsec SA renegotiation after the IPsec SA soft lifetime expires.
  • After the encapsulation-mode auto command is run in the IPsec proposal view on the responder and the IPsec SA soft lifetime expires, the responder cannot initiate IPsec SA renegotiation.
  • After the IKE SA has been deleted and the IPsec SA soft lifetime expires, the initiator or responder cannot initiate IPsec SA renegotiation.

Example

# Set the soft timeout buffer traffic of an IPsec SA to 10000 KB in the IPsec policy example. 
<HUAWEI> system-view
[HUAWEI] ipsec policy example 1 isakmp
[HUAWEI-ipsec-policy-isakmp-example-1] sa soft-duration traffic-based buffer 10000
# Set the soft timeout buffer time of an IPsec SA to 600s in the IPsec policy example. 
<HUAWEI> system-view
[HUAWEI] ipsec policy example 1 isakmp
[HUAWEI-ipsec-policy-isakmp-example-1] sa soft-duration time-based buffer 600
