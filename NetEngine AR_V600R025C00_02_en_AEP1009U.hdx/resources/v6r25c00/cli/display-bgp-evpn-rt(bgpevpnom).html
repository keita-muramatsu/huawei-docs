display bgp evpn routing-table (peer)

Function

The display bgp evpn routing-table command displays information about BGP EVPN routes.

Format

display bgp evpn all routing-table [ peer ip-address { advertised-routes | received-routes } ] prefix-route

display bgp evpn route-distinguisher route-distinguisher routing-table prefix-route

display bgp evpn all routing-table [ peer ip-address { advertised-routes | received-routes } ]

display bgp evpn all routing-table extcommunity { rt extcommunity } &<1-33>

display bgp evpn all routing-table extcommunity { rt extcommunity } &<1-33> match-any

display bgp evpn all routing-table prefix-route extcommunity { rt extcommunity } &<1-33>

display bgp evpn all routing-table prefix-route extcommunity { rt extcommunity } &<1-33> match-any

display bgp evpn route-distinguisher route-distinguisher routing-table prefix-route extcommunity { rt extcommunity } &<1-33>

display bgp evpn route-distinguisher route-distinguisher routing-table prefix-route extcommunity { rt extcommunity } &<1-33> match-any

display bgp evpn all routing-table [ peer ipv6-address { advertised-routes | received-routes } ] prefix-route

display bgp evpn all routing-table [ peer ipv6-address { advertised-routes | received-routes } ]

Parameters

Parameter Description Value
peer ip-address

Specifies a peer IP address.

The value is in dotted decimal notation.
advertised-routes

Specifies the routes to be advertised to a specified peer.

-
received-routes

Displays the routes received from the specified peer.

-
prefix-route

Displays information about IP prefix routes.

-
all

Displays EVPN routes of all EVPN instances.

-
route-distinguisher route-distinguisher

Displays information about BGP EVPN routes with a specified RD.

The RD formats are as follows:

  • 2-byte AS number:4-byte user-defined number, for example, 1:3. The AS number ranges from 0 to 65535, and the user-defined number ranges from 0 to 4294967295. The AS number and user-defined number cannot both be 0s. That is, an RD cannot be 0:0.
  • Integer 4-byte AS number:2-byte user-defined number, for example, 65537:3. The AS number ranges from 65536 to 4294967295, and the user-defined number ranges from 0 to 65535.
  • 4-byte AS number in dotted notation:2-byte user-defined number, for example, 0.0:3 or 0.1:0. Generally, a 4-byte AS number in dotted notation is in the format of x.y, where x and y are both integers in the range of 0 to 65535. The user-defined number ranges from 0 to 65535. The AS number and user-defined number cannot both be 0s. That is, an RD cannot be 0.0:0.
  • 4-byte IP address:2-byte user-defined number, for example, 192.168.122.15:1. The IP address ranges from 0.0.0.0 to 255.255.255.255, and the user-defined number ranges from 0 to 65535.
extcommunity

Displays the routes with the specified extended community attribute.

-
rt extcommunity

Specifies the extended community attribute of the VPN-Target type.

The options are as follows:

  • as-number:nn
  • 4as-number:nn
  • ipv4-address:nn

Note that:

  1. as-number specifies an AS number, which is an integer ranging from 0 to 65535.
  2. 4as-number specifies a 4-byte AS number, which can be:
  • Integer, ranging from 65536 to 4294967295
  • x.y, where x and y are integers that both range from 0 to 65535

3. ipv4-address specifies an IPv4 address in dotted decimal notation.

4. nn specifies an integer. For as-number and 4as-number, the values both range from 0 to 4294967295. For ipv4-address, the value ranges from 0 to 65535.
match-any

Displays information about the routes that match any of the specified extended community attributes.

-
ipv6-address

Specifies the peer IPv6 address.

The value is a 32-bit hexadecimal string in format X:X:X:X:X:X:X:X.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To check the EVPN routing table on an EVPN-capable device, run the display bgp evpn routing-table command. You can specify different parameters in the command to check information about specified routes.

Example

The actual command output varies according to the device. The command output here is only an example.

Table 1 Description of the display bgp evpn routing-table (peer) command output
Item Description
Local AS number

Local AS number.
BGP Local router ID

Router ID of the local device.
Status codes

* indicates that the route is valid.

> indicates that the route is preferred.

d indicates that the route is dampened.

x indicates that the route is a best-external route.

a indicates that the route is an Add-Path route.

h indicates that the route is a historical route. Specifically, the route used to be in the BGP routing table, but is now unreachable.

i indicates that the route is an internal route.

s indicates that the route is suppressed. Specifically, the route is not advertised to peers (including IBGP and EBGP peers), but can be installed into the local IP routing table.

S indicates the state to which entries sent by a peer transition after the device learns that the peer is in the GR state.
Origin

Origin attribute of a BGP route, which can be of any of the following three types:

  • i: indicates that the Origin attribute is IGP. For example, the route is advertised from an IGP to the BGP routing table through the network command.
  • e: indicates that the Origin attribute is EGP. For example, the route information is obtained through EGP.
  • ?: indicates that the Origin attribute is Incomplete. This means that the origin of the route cannot be determined. For example, the route is imported by BGP using the import-route command.
EVPN address family

EVPN address family.
Number of Ip Prefix Routes

Number of IP prefix routes.
Route Distinguisher

RD of a route.
NextHop

Next hop information about routes.
Network

Route network information, which varies according to EVPN route types.

  • Network(ESI/EthTagId) format for A-D routes: ESI indicates the identifier of an Ethernet link segment. EthTagId indicates the Ethernet tag ID, that is, the BD tag set when an EVPN instance is bound to a BD. If the BD tag is not set, the value is 0.
  • Network(EthTagId/IpPrefix/IpPrefixLen) format for IP prefix routes: EthTagId indicates the Ethernet tag ID, that is, the BD tag set when an EVPN instance is bound to a BD. If the BD tag is not set, the value is 0. IpPrefix indicates the route address, and IpPrefixLen the mask length.
  • Network(EthTagId/IpAddrLen/OriginalIp) format for inclusive multicast routes: EthTagId indicates the Ethernet tag ID, that is, the BD tag set when an EVPN instance is bound to a BD. If the BD tag is not set, the value is 0. IpAddrLen indicates the route length, and OriginalIp the original IP address.
  • Network(EthTagId/MacAddrLen/MacAddr/IpAddrLen/IpAddr) format for MAC routes: EthTagId indicates the Ethernet tag ID, that is, the BD tag set when an EVPN instance is bound to a BD. If the BD tag is not set, the value is 0. MacAddrLen indicates the MAC address length, MacAddr the MAC address, IpAddrLen the IP address length, and IpAddr the IP address.
  • Network(ESI/IpAddrLen/OriginalIp) format for ES routes: ESI indicates the identifier of an Ethernet link segment, IpAddrLen the IP address length, and OriginalIp the original IP address.
