session whitelist ipv6 bypass

Function

The session whitelist ipv6 bypass command configures a whitelist so that no session table is created for IPv6 traffic that matches the whitelist.

The undo session whitelist ipv6 bypass command cancels the whitelist configuration.

By default, no whitelist is specified. A session table is created for IPv6 traffic based on the configuration.

Format

session whitelist ipv6 acl { acl-number | acl-name } bypass { { spr | sac | sec-policy } * | all }

undo session whitelist ipv6 acl { acl-number | acl-name } bypass { { spr | sac | sec-policy } * | all }

Parameters

Parameter Description Value
spr

Disables smart policy routing from being performed on IPv6 traffic matching an ACL.

-
sac

Disables application identification from being performed on IPv6 traffic matching an ACL.

-
sec-policy

Disables security policy from being performed on IPv6 traffic matching an ACL.

-
all

Disables smart policy routing, application identification, or security policy services from being performed on IPv6 traffic matching an ACL.

-
acl acl-number

Specifies the number of an IPv6 ACL.

The value is an integer that ranges from 2000 to 2999 or from 3000 to 3999.
acl acl-name

Specifies a named IPv6 ACL.

The value is a string of 1 to 32 case-sensitive characters. It cannot contain spaces and starts with a letter (a to z or A to Z).

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If session whitelist ipv6 bypass is not configured, a session table is created for IPv6 traffic based on the configuration. After the configuration, no session table is created for the IPv6 traffic that matches the policy.

A session table can be created for IPv6 traffic only when application identification, smart policy routing, or security policies is enabled or application traffic aggregation is enabled for a link. A session table is created only when the smart policy routing mode is load balancing or the path selection mode is symmetric.

Prerequisites

An IPv6 ACL and IPv6 ACL rules have been created.

Precautions

After the session whitelist bypass spr or session whitelist bypass all command is run, no session table is created for the traffic that matches the smart policy routing (SPR) rule, but packets are still forwarded according to the SPR result.

Example

# Configure an IPv6 session whitelist.
<HUAWEI> system-view
[HUAWEI] acl ipv6 3000
[HUAWEI-acl6-advance-3000] rule 5 permit ipv6 source 2001:db8:1::1
[HUAWEI-acl6-advance-3000] quit
[HUAWEI] session whitelist ipv6 acl 3000 bypass all
