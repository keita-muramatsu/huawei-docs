display ipv6 route-monitor-group

Function

The display ipv6 route-monitor-group command displays information about an IPv6 route monitoring group.

Format

display ipv6 route-monitor-group [ group-name ]

Parameters

Parameter Description Value
group-name

Displays information about a specified IPv6 route monitoring group.

If group-name is specified, only detailed information about the specified IPv6 route monitoring group is displayed. If group-name is not specified, brief information about all IPv6 route monitoring groups is displayed.

The value is a string of 1 to 31 case-sensitive characters. If spaces are used, the string must be enclosed in double quotation marks (" ").

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

After an IPv6 route monitoring group is configured, you can run the display ipv6 route-monitor-group command to check information about the IPv6 route monitoring group, such as the status, fault weight, and routes bound to the IPv6 route monitoring group.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display information about the IPv6 route monitoring group named uplink.
<HUAWEI> display ipv6 route-monitor-group uplink
route monitor group uplink
 Weight sum   : 20
 State        : Enabled
-------------------------------------------------------
 route monitor group tracking route number : 1
-------------------------------------------------------
 VPN name     : _public_
 Destination  : 2.2.2.2
 Mask         : 255.255.255.255
 Down weight  : 10
# Display information about all IPv6 route monitoring groups.
<HUAWEI> display ipv6 route-monitor-group
Route monitor group number : 2
Route monitor group      Total weight     State
uplink                   20               Enabled
downlink                 20               Enabled
Table 1 Description of the display ipv6 route-monitor-group command output
Item Description
route monitor group tracking route number

Number of routes in the route monitoring group.
Weight sum

Weight sum of route monitoring group.
State

Status of the route monitoring group:

  • Enabled.
  • Disabled.
VPN name

VPN instance to which the route belongs. _public_ indicates a public instance.
Destination

Destination IP address of the route.
Mask

Mask of the IP address.
Down weight

Weight of a route.
Route monitor group number

Number of route monitoring groups.
Route monitor group

Name of the route monitoring group.

Weight sum of route monitoring group.
