enable snmp trap updown

Function

The enable snmp trap updown command enables the device to generate an alarm and send a trap message to the NMS when the link or protocol status of an interface changes.

The undo enable snmp trap updown command disables the device from generating an alarm and sending a trap message to the NMS when the link or protocol status of an interface changes.

By default, the device generates an alarm and sends a trap message to the NMS when the link or protocol status of an interface changes.

Format

enable snmp trap updown

undo enable snmp trap updown

Parameters

None

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To enable the device to generate an alarm and send a trap message to the NMS when the link or protocol status of an interface changes, run the enable snmp trap updown command. This allows the NMS to monitor the interface status in real time.

Configuration Impact

By default, the device automatically sends a trap message to the NMS when the link or protocol status of an interface changes. If the interface flaps, frequently sending trap messages to the NMS increases the processing load on the NMS. To resolve this problem, run the undo enable snmp trap updown command to disable the device from sending trap messages when the protocol status of the interface changes.

After the undo enable snmp trap updown command is run, the following alarms are suppressed:

  • linkdown
  • ipv6IfStateChange

After the undo enable snmp trap updown command is run, the following logs are suppressed:

  • TRUNK_MEM_LINKDOWN
  • TRUNK_MEM_LINKUP

Precautions

Before enabling the device to send trap messages to the NMS, you must run the snmp-agent trap enable command on the device to enable trap message reporting.

Example

# Disable the device from generating an alarm and sending a trap message when the link or protocol status of an interface changes. 
<HUAWEI> system-view
[HUAWEI] interface 10GE0/0/0
[HUAWEI-10GE0/0/0] undo enable snmp trap updown
