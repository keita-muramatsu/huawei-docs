display nat server

Function

The display nat server command displays NAT Server information.

Format

display nat server [ name nat-server-name | global-ip global-ip | inside-ip inside-ip ]

Parameters

Parameter Description Value
name nat-server-name

Specifies the name of NAT Server.

The value is a string of 1 to 255 case-sensitive characters and cannot contain spaces. When quotation marks are used around the string, spaces are allowed in the string.
global-ip global-ip

Specifies the public IP address.

The value is in dotted decimal notation.
inside-ip inside-ip

Specifies a private IP address.

The value is in dotted decimal notation.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To display the configuration of NAT Server, run the display nat server command.
