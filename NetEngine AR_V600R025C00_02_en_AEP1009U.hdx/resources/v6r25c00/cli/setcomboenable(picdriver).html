combo enable

Function

The combo enable command configures the working mode of a combo interface.

The undo combo enable command restores the default working mode of a combo interface.

By default, a combo interface works in auto-sensing mode.

Format

combo enable fiber

combo enable copper

combo enable auto

undo combo enable [ { fiber | copper | auto } ]

Parameters

Parameter Description Value
copper

Sets the working mode of a combo interface to electrical.

-
auto

Sets the working mode of a combo interface to auto-sensing.

-
fiber

Sets the working mode of a combo interface to optical.

-

Views

GE optical interface view, GE electrical interface view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

A combo interface consists of a GE electrical interface and a GE optical interface on the panel. When one interface works, the other interface is disabled. You can use the electrical or optical interface based on the remote interface type. In addition, the electrical and optical interfaces share one interface view. When you enable the electrical or optical interface, configure the interface attributes (such as the rate and duplex mode) in the same interface view.

Precautions

This command is applicable only to combo interfaces.

If a combo interface is configured to work in a different mode from the remote interface, the two interfaces cannot communicate.

The electrical and optical interfaces of a combo interface are multiplexed. The optical interface of a combo interface cannot have a copper module installed.

If only an optical module is installed on a combo interface in auto-sensing mode and no network cable is connected, the optical interface goes up about 30s later.

If the electrical interface of a combo interface in auto-sensing mode changes from up to down (including interface down caused by intermittent link down), the electrical interface with the present optical module switches to the optical mode.

Example

# Configure the combo interface to work in optical mode.
<HUAWEI> system-view
[HUAWEI] interface GE 0/0/1
[HUAWEI-GE0/0/1] combo enable fiber
