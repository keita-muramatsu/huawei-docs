display isis traffic-eng advertisements

Function

The display isis traffic-eng advertisements command displays Traffic Engineering (TE) information advertised the last time.

Format

display isis traffic-eng advertisements [ local | lspId ] [ level-1 | level-2 | level-1-2 ] [ process-id | { vpn-instance vpn-instance-name } ]

display isis process-id traffic-eng advertisements [ local | lspId ] [ level-1 | level-2 | level-1-2 ]

Parameters

Parameter Description Value
local

Displays TE information advertised by the local router.

-
lspId

Displays TE information carried in the LSP with a specified LSP ID.

The value is a string of 16 to 20 characters in the format of ####.####.####.##-##, for example, 0050.0500.5004.00-00.
level-1

Displays TE information in a Level-1 link state database (LSDB).

-
level-2

Displays TE information in a Level-2 link state database (LSDB).

-
level-1-2

Displays TE information in Level-1 and Level-2 link state database (LSDB).

-
process-id

Specifies an IS-IS process ID.

The value is an integer ranging from 1 to 4294967295.
vpn-instance vpn-instance-name

Specifies an IS-IS multi-instance process of a VPN instance.

The value is a string of 1 to 31 case-sensitive characters. It cannot contain spaces. The VPN instance name cannot be _public_. If the character string is quoted by double quotation marks, the character string can contain spaces.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

In TE, you need to check the advertised TE information to ensure the correctness of the advertised IS-IS TE information.

When level-1-2 is specified in the command, TE information in the Level-1 or Level-2 LSDB is displayed based on the type of the local node. That is, if the local node is of Level-1, TE information in the Level-1 LSDB is displayed. If the local node is of Level-2, TE information in the Level-2 LSDB is displayed. If the local node is of Level-1-2, TE information in Level-1 and Level-2 LSDBs is displayed.

If Level-1 or Level-2 is not specified, TE information in Level-1 and Level-2 LSDBs is displayed.
