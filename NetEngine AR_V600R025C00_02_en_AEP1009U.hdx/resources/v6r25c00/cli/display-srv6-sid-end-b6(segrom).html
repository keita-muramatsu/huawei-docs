display segment-routing ipv6 local-sid end-b6 forwarding

Function

The display segment-routing ipv6 local-sid end-b6 forwarding command displays SRv6 End.B6 local SID table information.

Format

display segment-routing ipv6 local-sid end-b6 [ sid-value ] forwarding

Parameters

Parameter Description Value
end-b6 sid-value

Specifies an End.B6 SID value.

The value is a 32-digit hexadecimal string in format X:X:X:X:X:X:X:X.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

This command displays information about the SRv6 End.B6 local SID table. You can view all information or a specified SID.

Example

The actual command output varies according to the device. The command output here is only an example.

# Displays information about the SRv6 End.B6 local SID table.
<HUAWEI> display segment-routing ipv6 local-sid end-b6 forwarding
