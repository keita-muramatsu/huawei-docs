compress enable

Function

The compress enable command enables the compression function.

The undo compress enable command disables the compression function.

By default, the compression function is disabled.

This command is supported only on the AR8700 series, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series and AR6700-H series.

Format

compress enable

undo compress enable

Parameters

None

Views

Per-packet-compress view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When the link bandwidth is insufficient and the expansion cost is high, you can enable the compression function to reduce the bandwidth consumption on the link.

Follow-up Procedure

Run the compress policy command to create a per-packet compression policy, run the service-map command to specify the traffic to be compressed, and run the compress-policy command to apply the compression policy to an interface.

Precautions

The data compression feature is available only after a license is activated. The decompression function must be configured on the peer end.

Example

# Enable the compression function.
<HUAWEI> system-view
[HUAWEI] per-packet-compress
[HUAWEI-per-packet-compress] compress enable
