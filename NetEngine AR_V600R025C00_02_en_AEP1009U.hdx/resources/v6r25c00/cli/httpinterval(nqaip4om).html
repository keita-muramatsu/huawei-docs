interval (HTTP test instance)

Function

The interval command sets the interval at which NQA HTTP test packets are sent.

The undo interval command restores the default setting.

By default, the interval is 4 seconds.

Format

interval seconds interval

undo interval

undo interval seconds interval

Parameters

Parameter Description Value
seconds interval

Specifies the interval at which test packets are sent, in seconds.

The value is an integer that ranges from 1 to 60, in seconds.

Views

NQA view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If you run the probe-count command to configure probes to be sent multiple times for an NQA test instance, you can evaluate network quality more accurately based on statistics. The interval at which probes are sent is configured using the interval command.

  • If the network quality is poor, you need to increase the interval for sending packets. Otherwise, the network performance deteriorates.
  • If the network quality is good, you can reduce the interval for sending test packets to reduce the time spent on waiting for the test instance to end.

Configuration Impact

  • The packet sending interval must be greater than or equal to the test timeout period set by the timeout command.
  • If the interval at which packets are sent has been set, running the interval command again overrides the previous configuration.

Precautions

If you change the packet sending interval during the running of the test instance, the system prompts you whether to stop the test instance. Press "Y" or "N" as required.

  • If you enter Y, the current test instance is stopped and parameters are modified. After you submit the modification, the modified parameters take effect. To restart the test instance, run the start command.
  • If you enter N, the parameter modification fails and the current test instance continues to run.

Example

# Set the interval at which test packets of the test instance named user test are sent to 30 seconds.
<HUAWEI> system-view
[HUAWEI] nqa test-instance user test
[HUAWEI-nqa-user-test] test-type http
[HUAWEI-nqa-user-test] interval seconds 30
