wan-quality-analysis detect interval

Function

The wan-quality-analysis detect interval command sets the WAN quality analysis detection interval.

The undo wan-quality-analysis detect interval command restores the default WAN quality analysis detection interval.

By default, the WAN quality analysis detection interval is 1000 ms.

Format

wan-quality-analysis detect interval interval-time

undo wan-quality-analysis detect interval [ interval-time ]

Parameters

Parameter Description Value
interval-time

Specifies the WAN quality analysis detection interval, in milliseconds.

The value is an integer ranging from 10 to 10000. The default value is 1000.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To change the WAN quality analysis detection interval, run the wan-quality-analysis detect interval command.

Precautions

The WAN quality analysis detection interval must be an integer multiple of 10 and must be less than or equal to the EVPN link quality calculation interval.

Example

# Set the WAN quality analysis detection interval to 200 ms.
<HUAWEI> system-view
[HUAWEI] wan-quality-analysis detect interval 200
