ip-pool

Function

The ip-pool command specifies an IP address pool referenced by an IKE peer.

The undo ip-pool command deletes an IP address pool referenced by an IKE peer.

By default, an IKE peer does not reference any IP address pool.

Format

ip-pool ip-pool-name

undo ip-pool

Parameters

Parameter Description Value
ip-pool-name

Specifies the name of an IP address pool.

The value is a string of 1 to 64 case-insensitive characters. It cannot contain spaces.

Views

IKE peer view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When multiple branches need to access the headquarters, the customer wants to deploy network resources including the domain name, DNS server address, and IP addresses on headquarters gateway. The headquarters gateway pushes network resource information to branch gateways to simplify configuration and maintenance of network resources on them. In this case, run the ip-pool command to specify a global address pool referenced by an IKE peer. After a branch gateway initiates IKEv2 negotiation and establishes an IPsec tunnel with the headquarters gateway, the headquarters gateway pushes network resource information to this branch gateway through IKEv2.

Prerequisites

A global address pool has been created by running the ip pool command in system view.

Example

# Set the global address pool pool1 for the IKE peer. 
<HUAWEI> system-view
[HUAWEI] ip pool pool1
[HUAWEI-ip-pool-pool1] quit
[HUAWEI] ike peer peer1
[HUAWEI-ike-peer-peer1] ip-pool pool1
