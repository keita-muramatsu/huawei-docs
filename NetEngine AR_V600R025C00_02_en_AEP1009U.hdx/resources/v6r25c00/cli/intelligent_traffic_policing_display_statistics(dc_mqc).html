display itp statistics interface

Function

The display itp statistics interface command displays statistics about the traffic rate of an interface, CAR of the parent traffic policy, and CAR of the child traffic policy for high-priority services during each detection, and the number of lost packets for CAR of the child traffic policy for high-priority services and CAR of the child traffic policy for low-priority services.

Format

display itp statistics interface { interface-name | interface-type interface-number }

Parameters

Parameter Description Value
itp

Indicates intelligent traffic policing.

-
statistics

Displays statistics.

-
interface interface-name

Specifies an interface name.

The value is a string of 1 to 32 case-sensitive characters. It cannot contain spaces.
interface interface-type interface-number

Specifies the type and number of an interface.

The value is a string of 1 to 63 case-sensitive characters. It cannot contain spaces.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

This command is used to check statistics about the average traffic rate and total number of lost packets within a detection period on an interface, high-priority queues, and low-priority queues after an intelligent traffic policing policy is applied to the interface. A maximum of 100 records can be saved in each traffic behavior.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display statistics about the traffic rate of an interface, CAR of the parent traffic policy, and CAR of the child traffic policy for high-priority services during each detection, and the number of lost packets for CAR of the child traffic policy for high-priority services and CAR of the child traffic policy for low-priority services. (The statistics are recorded once per second in the ACTIVE, BINARY_DETECT, and ADDITIVE_DETECT states, and are recorded once per detection period in other states.)

Table 1 Description of the display itp statistics interface command output
Item Description
Time

Time when statistics are generated.
Status

Status of the intelligent traffic policing policy when statistics are read. The status can be INACTIVE, ACTIVE, SUPPRESS, BINARY_DETECT, or ADDITIVE_DETECT.
Interface rate

Rate of the interface within the second during statistics collection.
Behavior

Traffic behavior containing an intelligent traffic policing policy.
Behavior rate (Kbps)

Rate of the CAR to which the current traffic behavior belongs within the second during statistics collection.
High rate (Kbps)

Rate of high-priority applications within the second during statistics collection.
High loss (Packets)

Number of lost packets of high-priority applications within the second during statistics collection.
Low loss (Packets)

Number of lost packets of low-priority applications within the second during statistics collection.
