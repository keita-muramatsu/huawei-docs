evpn ext-udp

Function

The evpn ext-udp command sets the port number in the UDP header to be encapsulated.

The undo evpn ext-udp command restores the default port number in the UDP header to be encapsulated.

By default, both destination-port and source-port are 4755.

Format

evpn ext-udp { destination-port dest-port-number | source-port src-port-number } *

undo evpn ext-udp { destination-port dest-port-number | source-port src-port-number } *

Parameters

Parameter Description Value
destination-port dest-port-number

Specifies the destination port number.

The value is an integer ranging from 1024 to 65535.
source-port src-port-number

Specifies the source port number.

The value is an integer ranging from 1024 to 65535.

Views

Site view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In SD-WAN scenarios, the use of EVPN GRE extension headers does not comply with common network standards. As a result, packets cannot be identified and may be out of order in some network environments. You can run this command to configure the destination and source port numbers for the UDP header to be added to packets in an SD-WAN tunnel so that other network devices can correctly identify packets.

Prerequisites

The function of adding a UDP header to packets in an SD-WAN tunnel has been enabled using the evpn ext-udp enable command.

Precautions

If you want to change the port number, ensure that the port numbers at both ends are the same. Otherwise, packets cannot be identified.

Example

# Set the destination port number 2000 and source port number 3000 for the UDP header to be added.
<HUAWEI> system-view
[HUAWEI] evpn site 1
[HUAWEI-site-1] evpn ext-udp enable
[HUAWEI-site-1] evpn ext-udp destination-port 2000 source-port 3000
