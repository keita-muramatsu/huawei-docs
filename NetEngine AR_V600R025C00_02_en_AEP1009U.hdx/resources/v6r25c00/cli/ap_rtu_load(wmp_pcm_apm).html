ap rtu load

Function

The ap rtu load command unzips a right-to-use (RTU) license package and automatically delivers the unzipped RTU licenses to the corresponding APs.

Format

ap rtu load filename filename

Parameters

Parameter Description Value
filename filename

Specifies the name of an RTU license file.

The value is a string of 1 to 64 case-sensitive characters. The file must be a .zip package and have the same name as the existing RTU license file.

Views

WLAN view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

RTU is an authorization mode for selling hardware capabilities in installments, such as the number of spatial streams, capacity, and ports. An RTU license cannot be migrated after being bound to a device. As a part of hardware value, RTU licenses have the same lifecycle and the same entitlement as the hardware. The quantities of spatial streams, antennas, and service ports have always been the indicators for a WLAN in the industry, among which the number of spatial streams is the most basic indicator. RTU licensing allows basic Wi-Fi 6 and Wi-Fi 7 AP models to support features such as dual-band, triple-radio, and independent scanning radio.

After applying for RTU licenses in batches, you will obtain an RTU license package. You need to manually upload the RTU license package to the WAC, and then run this command to unzip the package and automatically deliver the RTU licenses to the corresponding APs.

Prerequisites

An RTU license package has been manually uploaded to the WAC.

Configuration Impact

Executing this command will unzip the RTU license package locally on the device, with a list of RTU license files generated.

Follow-up Procedure

Manually restart the APs to which the RTU license files have been delivered so that these RTU licenses can take effect.

Precautions

To ensure that RTU-granted functions work properly, license files in the RTU license package must meet the following requirements:

  • License files are .dat files downloaded from the Electronic Software Delivery Platform (ESDP).
  • The name of a license file (including the file name extension) cannot exceed 64 characters.

The following models do not support RTU licenses:

  • AirEngine X76X series APs (excluding the AirEngine 5760-51, AirEngine 6760-X1, and AirEngine 6760-X1E)
  • Central AP + RU

Example

# Unzip an RTU license package and automatically deliver the unzipped RTU license files to the corresponding APs.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap rtu load filename rtu.zip
Info: Operating, please wait for a moment......done. 
Info: Valid license file(s):2048, invalid license file(s):0
Warning: After the RTU file is downloaded to the AP, restart the AP to make RTU take effect.
