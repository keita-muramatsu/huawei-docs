suppress-flapping interface disable

Function

The suppress-flapping interface disable command disables LDP interface flapping suppression.

The undo suppress-flapping interface disable command restores the default configuration.

By default, LDP interface flapping suppression is enabled.

Format

suppress-flapping interface disable

undo suppress-flapping interface disable

Parameters

None

Views

MPLS-LDP view

Default Level

2: Configuration level

Usage Guidelines

If LDP interface flapping suppression is disabled and an interface frequently flaps, LDP frequently sends Address and Address Withdraw messages to all LDP sessions. If there are a large number of sessions, the CPU usage of the device increases, causing protocol flapping. Configuring LDP interface flapping suppression can reduce the risk of protocol flapping. To disable LDP interface flapping suppression, run the suppress-flapping interface disable command.

Example

# Disable LDP interface flapping suppression.
<HUAWEI> system-view
[HUAWEI] mpls
[HUAWEI-mpls] mpls ldp
[HUAWEI-mpls-ldp] suppress-flapping interface disable
