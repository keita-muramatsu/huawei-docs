stun server listening-port

Function

The stun server listening-port command configures a checked UDP port number for the STUN server.

The undo stun server listening-port command restores the default checked UDP port number for the STUN server.

By default, the STUN server checks UDP port 3478.

Format

stun server listening-port port-number

undo stun server listening-port [ port-number ]

Parameters

Parameter Description Value
port-number

Specifies the checked UDP port number for the STUN server.

The value is an integer in the range from 1024 to 65535.

Views

STUN server view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After the stun server enable command is run, if the STUN service is unavailable because the checked UDP port number for the STUN server has been used by another service, run the stun server listening-port command to modify the checked port number.

Precautions

The configured UDP port number cannot be used by other services. Otherwise, the STUN server may fail to process STUN messages.

Example

# Configure the STUN server to check UDP port 3480.
<HUAWEI> system-view
[HUAWEI] stun server
[HUAWEI-stun-server] stun server listening-port 3480
