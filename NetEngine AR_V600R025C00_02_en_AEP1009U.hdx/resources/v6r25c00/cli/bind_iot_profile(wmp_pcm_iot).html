iot-profile (IoT card interface view)

Function

The iot-profile command binds an IoT profile to an IoT card interface, and configures the source port number for the IoT card interface.

The undo iot-profile command unbinds an IoT profile from an IoT card interface.

By default, no IoT profile is bound to an IoT card interface.

Format

iot-profile profile-name config-agent { tcp | udp } [ port port ] [ ext-port ext-port ]

undo iot-profile

Parameters

Parameter Description Value
profile-name

Specifies the name of an IoT profile.

The value is a string of 1 to 35 case-insensitive characters. It cannot contain question marks (?) or spaces, and cannot start or end with double quotation marks (" ").
config-agent

Configures an agent.

-
tcp

Configures an AP to communicate with a host computer using TCP.

-
udp

Configures the AP to communicate with the host computer using UDP.

-
port port

Specifies the source port for the first channel.

The value is an integer ranging from 1025 to 55535. By default, the port number is a random port number in the range of 49152 to 65535.

A port number within the range from 50200 to 50202 is recommended. If another port number is used, a port conflict may occur, which generates an alarm.
ext-port ext-port

Specifies the source port for the extended channel.

The value is an integer ranging from 1025 to 55535. By default, the port number is a random port number in the range of 49152 to 65535.

A port number within the range from 50200 to 50202 is recommended. If another port number is used, a port conflict may occur, which generates an alarm.

Views

AP IoT-card view, AP Group IoT-card view

Default Level

2: Configuration level

Usage Guidelines

You can run this command to bind an IoT profile, configure the communication protocol between an AP and a host computer, and configure the source port number for the IoT card interface.

Example

# Bind the IoT profile profile1 to an IoT card interface and set the local UDP port number on the IoT card interface to 50200.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-group name default
[HUAWEI-wlan-ap-group-default] card 1
[HUAWEI-wlan-ap-group-default-card-1] iot-profile profile1 config-agent udp port 50200
