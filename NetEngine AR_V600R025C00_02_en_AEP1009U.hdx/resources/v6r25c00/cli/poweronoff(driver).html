power { on | off }

Function

The power on command powers on a specified board.

The power off command powers off a specified board.

Format

power { on | off } slot slot-id

Parameters

Parameter Description Value
slot slot-id

Specifies the slot ID of a board.

You can enter a question mark (?) and select a value based on the prompt.

Views

System view, User view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

When services are idle on the board, run the power off command to power off the board without affecting services. This ensures stable system operation and saves energy.

Precautions

After a board is powered off, you can run the power on command to manually power on the board or run the reboot command to restart the switch so that the board can be powered on automatically. A board will be powered off in either of the following situations:

  • When services are idle, users run the power off command to manually power off a board.
  • A board is automatically powered off when it is not supported by the switch.
  • If a board is powered off before the device is upgraded, the board will be powered on and registered automatically after the device is upgraded and restarted. It takes about 10 to 20 minutes for the board to be registered successfully because version verification and synchronization need to be performed on this board based on the MPU version.

Example

# Power off the board in slot 0.
<HUAWEI> power off slot 0
Warning: The system will automatically collect logs of the board in slot 0 and the board will be powered off. Continue? [Y/N]:y
