encryption-method

Function

The encryption-method command configures a data encryption algorithm for a WLAN.

The undo encryption-method command deletes the data encryption algorithm of a WLAN.

By default, no encryption algorithm is configured for a WLAN. After the wpa-type command is executed, the default encryption algorithm AES is automatically generated.

Format

encryption-method { tkip | aes | aes-tkip }

undo encryption-method

Parameters

Parameter Description Value
tkip

Configures TKIP encryption.

-
aes

Configures AES encryption.

-
aes-tkip

Configures AES-TKIP encryption. After passing the authentication, STAs can use the AES or TKIP algorithm for data encryption.

-

Views

Net-assistant wlan-ssid view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

To protect the data transmitted by authorized users on a WLAN, you can run this command to configure a data encryption algorithm for the WLAN.

Prerequisites

A security policy has been configured for the WLAN using the wpa-type command.

Example

# Configure TKIP as the encryption algorithm of the WLAN named huawei_wifi.
<HUAWEI> system-view
[HUAWEI] net-assistant
[HUAWEI-net-assistant] network
[HUAWEI-net-assistant-network] wlan-ssid huawei_wifi profile-name ssid123
[HUAWEI-net-assistant-vnetwork-wlan-ssid-huawei_wifi] wpa-type wpa-wpa2 psk YsHsjx_202206
[HUAWEI-net-assistant-vnetwork-wlan-ssid-huawei_wifi] encryption-method tkip
