switch-back enable

Function

The switch-back enable command enables the switchback function in an SPR policy.

The undo switch-back enable command disables the switchback function in an SPR policy.

By default, the switchback function is enabled in an SPR policy.

Format

switch-back enable

undo switch-back enable

Parameters

None

Views

SPR policy view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After SPR switches traffic from a high-priority link to a low-priority link, SPR needs to switch traffic back from the low-priority link to the high-priority link if the high-priority link recovers. If important services are transmitted over the low-priority link, the switchback will cause traffic loss. To prevent this, you can run the undo switch-back enable command to disable the switchback function.

Prerequisites

A smart policy route has been created using the smart-policy-route command.

A policy profile has been created using the spr-policy command in the smart-policy-route view.

Example

# Enable switchback for policy spr1.
<HUAWEI> system-view
[HUAWEI] smart-policy-route
[HUAWEI-smart-policy-route] spr-policy node 1
[HUAWEI-smart-policy-route-spr-policy-node-1] switch-back enable
