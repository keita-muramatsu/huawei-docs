display remote-unit backup-group

Function

The display remote-unit backup-group command displays the status of an RU backup group or the status of the uplink interface in an RU backup group.

Format

display remote-unit backup-group

display remote-unit backup-group group-id

Parameters

Parameter Description Value
group-id

Specifies the backup group ID.

The value ranges from 0 to 16777215. Set the value according to the device configuration.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

You can run this command to view the backup group ID, status, and uplink interface status of an RU.

Precautions

If the RU status is BackupMisconf, the interconnection interface is incorrectly configured as a backup port. In this case, perform the following operations:

  • Enter the remote-unit N view of the RU in the BackupMisconf state and run the undo backup-group backup-port uplink command to cancel the backup port configuration.
  • Run the reboot command to restart the RU.

Table 1 Description of the display remote-unit backup-group command output
Item Description
ESN

ESN of an RU.
Name

Alias of an RU. This field displays a hyphen (-) if an RU is not configured with an alias.
Device type

Device type of an RU.
Connect interface

Access interface of the RU on the central device. If a physical interface is added to an Eth-Trunk, the Eth-Trunk interface is displayed.
Interface

RU interface name.
Role

RU interface attribute (master or backup).
State

RU interface status.
NeighborInterface

Interface of the central device for connecting to an uplink interface of the RU.
GroupId

RU backup group ID.
ID

ID of the RU. If no ID is configured for the RU, a hyphen (-) is displayed.
Type

Device type of an RU.
Status

Status of the RU. The options are as follows:

• Unknown: The status is unknown.

• Idle: The RU is in the aging state.

• Normal: The RU is online.

• Upgrading: The RU is being upgraded.

• Configuring: The RU is being configured.

• Abnormal: The RU is online but the link is abnormal or exceeds the specifications.

• Offline: The RU is offline.
