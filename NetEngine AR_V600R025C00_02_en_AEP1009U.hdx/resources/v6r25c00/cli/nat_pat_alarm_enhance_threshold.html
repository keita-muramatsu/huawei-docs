nat pat alarm enhance threshold

Function

The nat pat alarm enhance threshold command configures the enhanced alarm threshold for NAT in PAT mode.

The undo nat pat alarm enhance threshold command restores the default enhanced alarm threshold for NAT in PAT mode.

By default, the enhanced alarm threshold for NAT in PAT mode is 1000.

Format

nat pat alarm enhance threshold threshold-value

undo nat pat alarm enhance threshold

Parameters

Parameter Description Value
threshold-value

Specifies the threshold for the number of IP address allocation failures. If the number of IP address allocation failures reaches the threshold, an enhanced alarm for NAT in PAT mode is sent to the NMS.

The value is an integer ranging from 1 to 100000.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

When the address pool mode of source NAT is PAT, you can run the nat pat alarm enhance enable command to enable the enhanced alarm function to monitor the usage of address pool resources more accurately. When this function is enabled, the device checks for IP address allocation failures at the interval of 10 seconds. If the number of times an IP address fails to be allocated within an interval reaches the threshold, the device sends the hwSecTrapNatPatToDstIPConflictOverThreshold alarm to the NMS. You can run the nat pat alarm enhance threshold command to configure the alarm threshold.

Example

# Set the enhanced alarm threshold for NAT in PAT mode to 2000.
<HUAWEI> system-view
[HUAWEI] nat pat alarm enhance enable
[HUAWEI] nat pat alarm enhance threshold 2000
