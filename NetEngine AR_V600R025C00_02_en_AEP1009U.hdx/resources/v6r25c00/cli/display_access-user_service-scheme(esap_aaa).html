display access-user service-scheme

Function

The display access-user service-scheme command displays information about users who are granted a specified service scheme.

Format

display access-user service-scheme service-scheme-name

Parameters

Parameter Description Value
service-scheme-name

Displays information about users assigned with a specified service scheme.

The service scheme name must exist. It cannot contain the following characters \ / : < > | * " ? and cannot be - or --.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Administrators can run this command to view information about users who are granted a specified service scheme.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display information about users who are granted the service scheme huawei.
<HUAWEI> display access-user service-scheme huawei
 ------------------------------------------------------------------------------

 ------------------------------------------------------------------------------ 
 Total: 1, printed: 1
