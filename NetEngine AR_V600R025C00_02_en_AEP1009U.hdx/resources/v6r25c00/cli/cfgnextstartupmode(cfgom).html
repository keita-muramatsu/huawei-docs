configuration next-startup-mode

Function

The configuration next-startup-mode cfg command specifies the configuration file to be loaded at the next startup and configures the device to start by running commands in a configuration file.

The configuration next-startup-mode default command restores the default configuration file to be loaded at the next startup.

By default, a device starts up by loading the database file.

Format

configuration next-startup-mode { cfg | default }

Parameters

Parameter Description Value
cfg

Configures the device to start with the file for next startup in text mode.

-
default

Configures the device to start with the file for next startup in default mode.

-

Views

User view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

  • A device can start in either of the following modes using the configuration file for next startup:
    • CFG: indicates the CFG startup mode. The system starts based on the command configurations configured in the configuration file. If the configuration file contains a large number of command configurations, the startup process may take a long time.
    • DB: indicates the database startup mode. The system starts based on the database file. In this mode, commands do not need to be run one by one, which achieves quick startup. During DB startup, the system checks whether the version of the database file matches the version of the basic system software package and whether the content of the database file is the same as that of the configuration file to be loaded for the next startup. If the version does not match or the file content is inconsistent, the device starts in CFG mode even if the DB mode is configured.
  • You can run the configuration next-startup-mode cfg command to configure the device to start with configurations in a file.
  • When the configuration next-startup-mode default command is executed, the device is restored to the default startup mode (loading the database file).

Precautions

  • A device starts in DB mode. However, the system checks whether the database file version is the same as the basic software package version and whether the database file is the same as the configuration file to be loaded at the next startup. If they are inconsistent, even if the database file is configured to be preferentially loaded, the device starts in CFG mode.
  • The configuration of the configuration next-startup-mode cfg command becomes invalid after the device is restarted, and the device is restored to start by loading the database file by default.

Example

# Configure the device to start by loading a database file by default.
<HUAWEI> configuration next-startup-mode default
# Configure the device to preferentially start by running commands in the configuration file.
<HUAWEI> configuration next-startup-mode cfg
