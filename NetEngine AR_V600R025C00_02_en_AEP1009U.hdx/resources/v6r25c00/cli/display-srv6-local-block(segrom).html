display segment-routing ipv6 local-block sid-reserve

Function

The display segment-routing ipv6 local-block sid-reserve command displays the idle range that can be reserved for BSIDs in the specified locator.

Format

display segment-routing ipv6 [ locator locator-name ] local-block sid-reserve number-value

display segment-routing ipv6 locator locator-name local-block sid-reserve [ begin-value begin-val ] [ number-value ]

Parameters

Parameter Description Value
locator locator-name

Specifies a locator name.

The value is a string of 1 to 31 case-sensitive characters. The character string can contain spaces if it is enclosed with double quotation marks (").
number-value

Specifies the number of SIDs reserved for BSIDs in a local block. Only the reserved range that is greater than or equal to the value of number value is displayed.

The value is an integer ranging from 1 to 200000.
begin-value begin-val

Specifies the begin value of the SRLB.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

The display segment-routing ipv6 local-block sid-reserve command displays the idle range that can be reserved for BSIDs in the specified locator. If a begin value is specified, you can view the idle range starting with the specified value.
