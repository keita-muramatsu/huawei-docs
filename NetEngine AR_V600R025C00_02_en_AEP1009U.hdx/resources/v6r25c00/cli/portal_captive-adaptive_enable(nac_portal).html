portal captive-adaptive enable

Function

The portal captive-adaptive enable command enables the CNA adaptive function for iOS terminals.

The undo portal captive-adaptive enable command disables the CNA adaptive function for iOS terminals.

By default, the CNA adaptive function is disabled for iOS terminals.

Format

portal captive-adaptive enable

undo portal captive-adaptive enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Since wireless Internet access is provided in many places, users require fast and convenient authentication by using applications on mobile terminals, without entering user names and passwords. In this case, mobile terminals need to automatically display the application-based Portal authentication page, and the applications need to communicate with the back-end server. Therefore, mobile terminals must be connected to WLANs during authentication.

iOS terminals such as iPhones, iPads, and iMac computers provide the Captive Network Assistant (CNA) function. This function automatically detects the network connection status after iOS terminals are connected to WLANs. If the network is disconnected, the iOS terminals display a page prompting users to enter their user names and passwords. If users do not enter their user names and passwords, their iOS terminals are automatically disconnected from the WLANs. As a result, users cannot use applications on iOS terminals for authentication.

To solve the problem, enable the CNA adaptive function so that iOS terminals are redirected to the application-based Portal authentication page when they connect to WLANs. Users can click the link on the page to start specified applications for Portal authentication. If users do not start applications to perform authentication, the iOS terminals are not disconnected from the WLANs automatically and users can still access authentication-free resources on the WLANs.

Example

# Enable the CNA adaptive function for iOS terminals.
<HUAWEI> system-view
[HUAWEI] portal captive-adaptive enable
