display tunnel

Function

The display tunnel command displays information about tunnels.

Format

display tunnel all

display tunnel tunnel-id

Parameters

Parameter Description Value
all

Displays information about all tunnels.

-
tunnel-id

Displays information about a tunnel with the specified ID.

The value is a string of 1 to 20 characters.

The value consists of three parts: 4-byte VPN index, 1-byte tunnel type, and 4-byte tunnel ID, for example, 0x000000000300000001.

If the specified tunnel ID does not exist, no information is displayed.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

The display tunnel all command displays the tunnels that are managed by the TNLM module and the tunnel IDs, tunnel types, and destination IP addresses of these tunnels.

If you run the display tunnel command with the tunnel-id parameter specified, the command output displays information about the tunnel with the specified tunnel ID.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display information about an SD-WAN tunnel.
<HUAWEI> display tunnel 0x3800000015
Tunnel ID:       0x000000003800000015            
Type:            sd-wan              
Name:            SD-WAN                          
Destination:     0.0.0.0                                 
Instance ID:     0               
MTU:             160             
Cost:            19              
Status:          UP              
Color/Priority:  1/0 2/1 3/2 4/3 5/4 6/5 7/6 8/7 9/8 10/9 11/10 12/11 13/12 14/13 15/14
# Display information about a tunnel.
<HUAWEI> display tunnel 00000000050000004e
Tunnel ID:       0x00000000050000004e            
Type:            gre                 
Name:            Tunnel1                         
Destination:     2.2.2.2                                 
Instance ID:     0               
Cost:            0               
Status:          DOWN            
Out Interface:   Tunnel1                                                                 
  NextHop:       0.0.0.0
# Display information about all tunnels.
<HUAWEI> display tunnel all
Tunnel ID            Type                Destination                             Status
----------------------------------------------------------------------------------------
0x00000000050000004e gre                 2.2.2.2                                 DOWN

Outbound interface.

  • flex-algo-lsp.

  • gre.
  • ds-lite.
  • srv6teflowgroup.
  • srtepolicygroup.

The command output varies according to the tunnel type.

The supported tunnel types depend on the actual situation.
Destination

Destination IP address of a tunnel.
Status

Tunnel status.
Name

Tunnel name.

Tunnel cost.
Color/Priority

Color and priority of an SD-WAN tunnel, which identify the site information of the SD-WAN tunnel.
