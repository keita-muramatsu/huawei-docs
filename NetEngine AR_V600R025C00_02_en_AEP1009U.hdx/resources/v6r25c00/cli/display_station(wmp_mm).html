display station

Function

The display station command displays access information about STAs.

Format

display station { ap-group ap-group-value | ap-id ap-id-value | ssid ssid-value | sta-mac sta-mac-address | vlan vlan-id | all }

Parameters

Parameter Description Value
ap-group ap-group-value

Displays STA access information about a specified AP group.

The value is a string of 1 to 35 visible characters that can be Chinese characters or a combination of Chinese and English characters. It cannot contain question marks (?) or only contain double quotation marks ("). If the AP group name contains spaces,it must be enclosed with double quotation marks (" "), for example, "huawei name1". The double quotation mark (") before and after the AP group name occupies two characters together. The specified AP group must exist.

Only the command editor in UTF-8 encoding format can be used to edit Chinese characters.
ap-id ap-id-value

Displays STA access information about the AP with a specified ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
ssid ssid-value

Displays STA access information on a specified SSID.

The value is a string of 1 to 32 characters. It can contain spaces.
sta-mac sta-mac-address

Displays access information about a STA with the specified MAC address.

The value is in H-H-H format. H is a hexadecimal number that contains one to four digits, such as 00e0 and fc01. If an H contains fewer than four digits, the leftmost digits are padded with 0s. For example, two 0s are added to e0 to form 00e0.
vlan vlan-id

Displays STA access information in a specified VLAN.

The value is an integer ranging from 1 to 4094.
all

Displays access information about all STAs.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run the display station command to view access information about STAs.

Capabilities of a STA displayed in the display station sta-mac sta-mac-address command output are negotiated between the STA and AP and are affected by both their capabilities, which may be different from the actual STA capabilities.
