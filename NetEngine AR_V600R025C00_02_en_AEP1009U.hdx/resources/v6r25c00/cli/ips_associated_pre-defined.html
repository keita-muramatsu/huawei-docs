ips associated pre-defined

Function

The ips associated pre-defined command configures check items for predefined associated signatures.

The undo ips associated pre-defined command restores the check items of predefined associated signatures to default values.

By default, no configuration is performed.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

ips associated pre-defined signature-id signature-id { threshold threshold | interval interval | block-time block-time | correlateby { source | destination | source-destination } } *

undo ips associated pre-defined { signature-id signature-id | all }

Parameters

Parameter Description Value
signature-id signature-id

Indicates the ID of a predefined associated signature.

The value is an integer that ranges from 1025 to 16777215.
threshold threshold

Specifies the threshold on the number of times the associated signature is detected.

The value is an integer in the range from 1 to 2000. The default value is 30.
interval interval

Indicates the statistical time range. That is, if the number of times that a predefined associated signature is detected exceeds the value of threshold-value within the specified time range, the predefined associated signature is matched.

The value is an integer in the range from 1 to 7200, in seconds. The default value is 60s.
block-time block-time

Time when an IP address is added to the blacklist if the signature action is block. In addition, for the same correlation event, an event log is reported only once within the specified time range.

The value is an integer in the range from 1 to 1000, in minutes. The default value is 5.
correlateby

Indicates the association mode.

By default, the association mode is source-destination.
source

Indicates the number of times associated signatures are matched for the same source IP address.

-
destination

Indicates the number of times associated signatures are matched for the same destination IP address.

-
source-destination

Indicates the number of times associated signatures are matched for the same source and destination IP addresses.

-
all

Restores the check items of all predefined associated signatures to default values.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When the check items of predefined associated signatures cannot meet actual requirements, you can run this command to modify the check items of predefined associated signatures. After the IPS signature database is updated, if the configured predefined associated signatures do not exist in the updated IPS signature database, the related configuration is retained but does not take effect. You can run the display ips-signature not-in-current-library command to view the configured signatures that are not in the signature database.

Precautions

After running this command, run the engine configuration commit command to commit the configuration for the configuration to take effect. You are advised to commit the configuration after all content security configurations are complete.

Example

# Configure check items for predefined associated signatures.
<HUAWEI> system-view
[HUAWEI] ips associated pre-defined signature-id 16042 threshold 20 interval 30 block-time 120 correlateby source-destination
