negotiation disable

Function

The negotiation disable command configures an interface to work in non-auto-negotiation mode.

The undo negotiation disable command configures an interface to work in auto-negotiation mode.

By default, the negotiation mode of an interface is related to the installed medium. For details, see "Usage Guidelines."

Format

negotiation disable

undo negotiation disable

Parameters

None

Views

Layer 2 10GE interface view, 10GE interface view, 25GE-L2 view, 25GE interface view, 40GE interface view, GE optical interface view, GE interface view, GE electrical interface view, Layer 2 multi-GE interface view, Multi-GE interface view, Interface group view, Management interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The earliest Ethernet interfaces worked in 10M half-duplex mode and required mechanisms such as Carrier Sense Multiple Access (CSMA)/Collision Detection (CD) to ensure system stability. As Ethernet technology develops, Ethernet interfaces can work in 100M and 1000M full-duplex mode. This greatly improves Ethernet performance. Auto-negotiation technology allows new Ethernet to be compatible with earlier Ethernet. In auto-negotiation mode, interfaces on both ends of a link negotiate their operating parameters, including the duplex mode and rate. If the negotiation succeeds, the two interfaces work at the same operating parameters.

Precautions

  • If you run the negotiation disable command on an interface that is physically up, the physical status of the interface becomes down and then up. Exercise caution when using this command.
  • If no medium is installed on an interface, the interface works in non-auto-negotiation mode by default and does not support the negotiation disable or undo negotiation disable command.
  • If a 10GE or GE copper transceiver is installed on an interface, the interface works in auto-negotiation mode by default and supports the negotiation disable command.
  • If a GE optical module is installed on an interface, the interface works in auto-negotiation mode by default and supports the negotiation disable command.
  • If a 10GE optical module is installed on an interface, the interface works in non-auto-negotiation mode by default and does not support the negotiation disable or undo negotiation disable command.
  • This configuration is not supported on interfaces that have 10GE high-speed cables installed. If a high-speed cable of another rate is installed on an interface, the interface supports this configuration based on the hardware capability. You can run the display interface command on the interface to check the value of the Negotiation field. If the value of the Negotiation field is - or DISABLE, the interface works in non-auto-negotiation mode by default and does not support the negotiation disable command. If the value of the Negotiation field is ENABLE, the interface works in auto-negotiation mode by default and supports the negotiation disable command.
  • When you disable auto-negotiation on an interface, if you remove and then install a single optical fiber on the interface, the interface may be up and the remote interface may be down. You can run the shutdown and undo shutdown commands on the remote interface to make the remote interface go up.
  • If a medium that does not support auto-negotiation is installed on an interface, the existing auto-negotiation configuration is cleared.

Example

# Configure 10GE 0/0/1 to work in non-auto-negotiation mode.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] negotiation disable
