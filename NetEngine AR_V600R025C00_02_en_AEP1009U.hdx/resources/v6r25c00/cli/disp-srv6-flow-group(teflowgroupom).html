display srv6-te flow-group

Function

The display srv6-te flow-group command displays details about SRv6 TE Flow Groups.

Format

display srv6-te flow-group [ dynamic | [ endpoint ipv6-addr ] color color-value ]

display srv6-te flow-group endpoint ipv6-addr

display srv6-te flow-group dynamic endpoint ipv6-addr

Parameters

Parameter Description Value
dynamic

Specifies a dynamic group.

-
endpoint ipv6-addr

Specifies the endpoint of an SRv6 TE flow group.

The value is a 32-bit hexadecimal string in format X:X:X:X:X:X:X:X.
color color-value

Specifies the color of an SRv6 TE flow group.

The value is an integer ranging from 0 to 4294967295.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

The display srv6-te flow-group command displays detailed information about SRv6 TE flow groups.
