authentication-profile (VAP profile view)

Function

The authentication-profile command binds an authentication profile to a VAP profile.

The undo authentication-profile command restores the default setting.

By default, no authentication profile is applied to a VAP profile.

Format

authentication-profile profile-name

undo authentication-profile

Parameters

Parameter Description Value
profile-name

Specifies the name of an authentication profile.

The specified authentication profile must exist.

Views

VAP profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

An authentication profile uniformly manages NAC configuration. The authentication profile is bound to the VAP profile view to enable NAC, implementing access control on users in the VAP profile view. The user authentication type in the VAP profile view is determined by the access profile bound to the authentication profile.

Prerequisites

An authentication profile has been created using the authentication-profile command in the system view.

Precautions

In a roaming scenario, if VAPs on the HAP and FAP use different authentication profiles, the two authentication profiles must use the same authentication-server bypass policy.

Modifying the authentication profile bound to a VAP causes online users on the VAP to go offline and interrupts services.

Example

# Bind the authentication profile m1 to the VAP profile vap1.
<HUAWEI> system-view
[HUAWEI] authentication-profile name m1
[HUAWEI-authen-profile-m1] quit
[HUAWEI] wlan
[HUAWEI-wlan] vap-profile name vap1
[HUAWEI-wlan-vap-prof-vap1] authentication-profile m1
