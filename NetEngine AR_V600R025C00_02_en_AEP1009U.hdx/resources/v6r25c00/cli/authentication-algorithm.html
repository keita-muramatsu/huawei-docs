authentication-algorithm

Function

The authentication-algorithm command configures an authentication algorithm for IKEv1 negotiation.

The undo authentication-algorithm command restores the default configuration.

By default, the SHA2-256 authentication algorithm is used for IKEv1 negotiation.

Format

authentication-algorithm { md5 | sha1 | sha2-256 | sha2-384 | sha2-512 | sm3 } *

undo authentication-algorithm

Parameters

Parameter Description Value
md5

Uses the MD5 algorithm.

-
sha1

Uses the sha1 algorithm.

-
sha2-256

Uses the sha2-256 algorithm.

-
sha2-384

Uses the sha2-384 algorithm.

-
sha2-512

Uses the sha2-512 algorithm.

-
sm3

Uses the sm3 algorithm.

-

Views

IKE proposal view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

An authentication algorithm is required for IKEv1 negotiation. If multiple authentication algorithms are configured, the system selects the algorithms in descending order of security level. Authentication algorithms that can be used for IKEv1 negotiation include the following (listed in descending order of security level): sm3 > sha2-512 > sha2-384 > sha2-256 > sha1 > md5.

Precautions

SM3 can meet the high confidentiality and security requirements, but it takes a comparatively long time for processing. Authentication algorithms sha2-256, sha2-384, and sha2-512 are recommended for security purpose. md5 and sha1 are less secure and therefore not recommended.

The md5 and sha1 parameters in this command can be configured only after the install feature-software WEAKEA command is configured to install the weak security algorithm or protocol feature software package (WEAKEA).

Example

# Specify the sha2-384 for IKE proposal 10. 
<HUAWEI> system-view
[HUAWEI] ike proposal 10
[HUAWEI-ike-proposal-10] authentication-algorithm sha2-384
