ipsec profile (Tunnel interface view)

Function

The ipsec profile command applies an IPsec profile to a tunnel interface.

The undo ipsec profile command unbinds the IPsec profile from a tunnel interface.

By default, no IPsec profile is applied to a tunnel interface.

Format

ipsec profile profile-name [ shared ]

undo ipsec profile

Parameters

Parameter Description Value
profile profile-name

Specifies the name of an IPsec profile.

The value is an existing IPsec profile name.
shared

Indicates that tunnel interfaces share a physical interface.

This parameter can be configured only for mGRE tunnel interfaces.

-

Views

Tunnel interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To apply an IPsec profile to a tunnel interface, run the ipsec profile command.

Prerequisites

  • An IPsec profile has been created using the ipsec profile command in the system view.
  • A tunnel interface has been created using the interface tunnel command, and the encapsulation mode of the tunnel interface has been set to GRE, IPsec, or mGRE (using the tunnel-protocol command) based on the actual situation.
  • If the shared parameter needs to be configured, the encapsulation mode of the tunnel interface must be set to mGRE (using the tunnel-protocol gre p2mp command).
  • If the shared parameter needs to be configured, the source interface of the tunnel interface must be specified (using the source command).

Precautions

  • A tunnel interface can have only one IPsec profile applied. Before applying another IPsec profile to the tunnel interface, run the undo ipsec profile command to unbind the existing IPsec profile from the tunnel interface.
  • If the shared parameter is not specified:

    An IPsec profile can be applied to only one tunnel interface. Before applying the IPsec profile to another interface, unbind the IPsec profile from the tunnel interface.
  • If the shared parameter is specified:

    An IPsec profile can be applied to a maximum of 64 tunnel interfaces. Only one tunnel can be negotiated based on physical interfaces. No IPsec policy can be bound to physical interfaces where an IPsec profile is applied in shared mode.
  • If multiple mGRE tunnel interfaces share the same source interface, they must apply the same IPsec profile and have the shared parameter configured. Otherwise, the two ends cannot establish an IPsec tunnel.

Example

# Bind the IPsec profile profile1 to Tunnel1. 
<HUAWEI> system-view
[HUAWEI] interface tunnel 1
[HUAWEI-Tunnel1] tunnel-protocol ipsec
[HUAWEI-Tunnel1] source 10.1.1.1
[HUAWEI-Tunnel1] ipsec profile profile1
# Apply the IPsec profile profile2 to Tunnel2 and specify the shared parameter. Multiple tunnel interfaces share the same physical interface and IPsec profile. 
<HUAWEI> system-view
[HUAWEI] interface tunnel 2
[HUAWEI-Tunnel2] tunnel-protocol gre p2mp
[HUAWEI-Tunnel2] source 10GE0/0/2
[HUAWEI-Tunnel2] ipsec profile profile2 shared
