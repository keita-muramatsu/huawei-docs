capwap dtls version1.0 enable

Function

The capwap dtls version1.0 enable command enables the CAPWAP DTLS server to establish DTLS 1.0 sessions with DTLS clients running earlier versions.

The undo capwap dtls version1.0 enable command disables the CAPWAP DTLS server from establishing DTLS 1.0 sessions with DTLS clients running earlier versions.

By default, CAPWAP DTLS compatibility with DTLS 1.0 is disabled.

Format

capwap dtls version1.0 enable

undo capwap dtls version1.0 enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In versions earlier than V200R021C00, CAPWAP clients support only the DTLS 1.0 version, which poses security risks. To establish CAPWAP DTLS sessions with these clients, run this command to enable compatibility with earlier versions.

Precautions

This function can be used only after the weak security algorithm/protocol feature package (WEAKEA) is installed. To load the package, run the install feature-software WEAKEA command.

After this function is enabled, the DTLS 1.0 version is used to set up DTLS sessions with CAPWAP DTLS clients running versions earlier than V200R021C00, which poses security risks.

After this function is disabled, CAPWAP links established based on earlier DTLS versions are disconnected, which may interrupt services.

This function is not supported in FIPS mode.

Example

# Enable CAPWAP DTLS compatibility with DTLS 1.0.
<HUAWEI> install feature-software WEAKEA
<HUAWEI> system-view
[HUAWEI] capwap dtls version1.0 enable
