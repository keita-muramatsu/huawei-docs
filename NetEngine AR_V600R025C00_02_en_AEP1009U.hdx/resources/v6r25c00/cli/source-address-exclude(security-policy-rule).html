source-address-exclude (Security policy rule view)

Function

The source-address-exclude command excludes specific source addresses from a policy rule, so that the device does not match the traffic from these addresses with this policy.

The undo source-address-exclude command deletes the source addresses excluded from a security policy rule.

By default, this function is not configured.

Format

For AR8100 series, AR8700 series, AR6700-H series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5700-H series, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR5710-S8TWDSE-LTE4EA, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S10T1X2, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S:

source-address-exclude { address-set address-set-name &<1-6> | ipv4-address { ipv4-mask-length | mask mask-address | wildcard wildcard } | range ipv4-start-address ipv4-end-address }

undo source-address-exclude { address-set address-set-name &<1-6> | ipv4-address { ipv4-mask-length | mask mask-address | wildcard wildcard } | range ipv4-start-address ipv4-end-address }

For AR8100 series, AR8700 series, AR6700-H series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5700-H series, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR5710-S8TWDSE-LTE4EA, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5710-S28T2S2XE4, AR5710-S52T2XE4:

Parameters

Parameter Description Value
address-set address-set-name

Specifies the name of an address or address group.

The value is a string of 1 to 63 case-sensitive characters. It cannot contain spaces.
ipv4-address

Specifies an IPv4 address.

The value is in dotted decimal notation.
ipv4-mask-length

Specifies a mask for an IPv4 address.

The value is an integer that ranges from 1 to 32.
mask mask-address

Specifies a mask for an IPv4 address.

The value is in dotted decimal notation.
wildcard wildcard

Specifies the wildcard of an IPv4 address.

The value is in dotted decimal notation. The binary format supports discontinuous 1s, for example, 0.255.0.255 (00000000 11111111 00000000 11111111). Only digits 0 in the binary format are matched, but not digits 1. For example, 192.168.1.1/0.255.0.255 indicates that IP addresses in 192.*.1.* format are matched.
range

Indicates the address range.

Views

Security policy rule view

Default Level

2: Configuration level

Usage Guidelines

When referencing source addresses in a policy, you can run the source-address-exclude command to exclude specific source addresses. Traffic from the excluded addresses does not match the policy.

Example

# Exclude source addresses 10.1.1.0/24 from the security policy rule. 
<HUAWEI> system-view
[HUAWEI] security-policy
[HUAWEI-policy-security] rule name policy_sec
[HUAWEI-policy-security-rule-policy_sec] source-address-exclude 10.1.1.0 24
