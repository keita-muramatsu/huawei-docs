nat server

Function

The nat server command configures the NAT Server function. With this function, users can access the internal server with the private IP address specified by host-address and the port specified by host-port through the public IP address specified by global-address or the IP address of the interface specified by global-port and the port specified by global-port.

The undo nat server command deletes the NAT Server function.

By default, the NAT server is not configured.

Format

nat server name name { route | nat-disable }

nat server name [ vpn-instance vpn-instance-name1 ] [ zone zone-name ] [ protocol protocol-type ] global global-address [ global-address-end ] inside host-address [ host-address-end ] [ no-reverse ] [ vpn-instance vpn-instance-name2 ] [ route ] [ nat-disable ] [ description description ]

nat server name [ vpn-instance vpn-instance-name1 ] [ zone zone-name ] protocol protocol-type global global-address [ global-address-end ] global-port [ global-port-end ] inside host-address [ host-address-end ] host-port [ host-port-end ] [ no-reverse ] [ vpn-instance vpn-instance-name2 ] [ route ] [ nat-disable ] [ description description ]

nat server name [ zone zone-name ] [ protocol protocol-type ] global interface { interface-name | interface-type interface-num } inside host-address [ no-reverse ] [ vpn-instance vpn-instance-name2 ] [ nat-disable ] [ description description ]

nat server name [ zone zone-name ] protocol protocol-type global interface { interface-name | interface-type interface-num } global-port [ global-port-end ] inside host-address host-port [ host-port-end ] [ no-reverse ] [ vpn-instance vpn-instance-name2 ] [ nat-disable ] [ description description ]

undo nat server { name name [ route | nat-disable ] | all }

Parameters

Parameter Description Value
name

Specifies the name of NAT Server.

The value is a string of 1 to 255 case-sensitive characters. The value can contain only digits. The value cannot be all, vsys, all-systems, name, global, protocol, vpn-instance, or zone, and cannot be prefixed with n, na, nam, or name. The value must start with a letter or digit.
name

Specifies the name of NAT Server.

vpn-instance vpn-instance-name1

Specifies the name of a VPN instance.

It must be the name of an existing VPN instance. The value is a string of 1 to 31 characters.
vpn-instance vpn-instance-name2

Specifies the name of a VPN instance.

It must be the name of an existing VPN instance. The value is a string of 1 to 31 characters.
zone zone-name

Specifies the name of a security zone.

If the name does not contain spaces, the value is a string of 1 to 32 characters. If the name contains spaces, it must be enclosed in double quotation marks, for example, "group for test". The name cannot contain question marks (?) or hyphens (-).
protocol protocol-type

Specifies a protocol type or number. The global-port, global-port-end, host-port, and host-port-end parameters can be configured only when this parameter (TCP, UDP, or SCTP) is configured.

The value can be 1, 6, 17, 41, 47, 50, 51 or 132 if it is entered in the format of an integer. The value can be tcp, udp, sctp, or icmp if it is entered in the format of a name.
global global-address

Specifies a public IP address.

The value is in decimal dotted notation:256. Various models support different configurable IP address segments.
global-address-end

Specifies an IP address segment. The value of global-address-end must be greater than that of global-address.

The value is in dotted decimal notation.
global-port

Specifies the number of a public port that an intranet server uses to provide services.

The value can be a protocol type or an integer ranging from 0 to 65535.

If global-port is set to 0 and host-port is specified, the private port number is translated into a public port number the same as host-port. For example, global-port is set to 0 and host-port is set to 1, the private port number is translated into 1.
global-port-end

Specifies the number of a public port that an intranet server uses to provide services. global-port-end and global-port are used to define a port range. global-port-end must be greater than global-port.

The value is an integer from 1 to 65535.
inside host-address

Specifies the private address of an intranet server.

The value is in dotted decimal notation.
host-address-end

host-address and host-address-end are used to define an IP address range. host-address-end must be greater than global-address. If global-address-end is specified, host-address-end must also be specified. Each private address is mapped to a single public address. If private addresses outnumber public addresses, excess private addresses cannot be translated into public addresses. If global-port-end is specified, host-address-end must also be specified. Each private port is mapped to a single public port. If private ports outnumber public ports, excess private ports cannot be translated into public ports.

The value is in dotted decimal notation.
host-port

Specifies the number of a private port that an intranet server uses to provide services.

The value can be a protocol type or an integer in the range from 0 to 65535.

When the protocol is SCTP, the value of host-port must be the same as that of global-port.

If the internal port number specified by host-port is 0 and the external port number specified by global-port is also configured, the internal port number will be translated into the external port number by default. For example, if the internal port number is set to 0 and the external port number is set to 1, the internal port number will be translated into 1.
host-port-end

Specifies the number of a private port that an intranet server uses to provide services. host-port-end and host-port are used to define a port range. host-port-end must be greater than host-port.

The value is an integer ranging from 1 to 65535.
no-reverse

Disables the system from creating a reverse entry. If this parameter is not specified, both a server mapping entry and its reverse entry are created.

Delivers an OPR to prevent routing loops.

By default, no OPRs are delivered.
nat-disable

Reserves the NAT server configuration. However, the NAT server does not take effect.

The NAT server function is enabled by default.
description description

Specifies the description of NAT Server.

The value is a string of 1 to 128 characters.
interface-name

Specifies an interface name.

interface-type

Specifies an interface type.

The value is a string of 1 to 255 case-sensitive characters. It cannot contain spaces.
interface-num

Specifies an interface number.

The value is a string of case-sensitive characters. It cannot contain spaces.

Usage Guidelines

Usage Scenario

You can run this command to configure intranet servers to provide services to external network users. The intranet servers can be located on common private networks, which can be WWW, FTP, Telnet, and POP3 servers.

When multiple NAT Server configurations with the same public and private IP addresses exist on the device, the system preferentially matches the NAT Server configuration with more accurate conditions. Assume that a device has the following two NAT Server configurations:

[HUAWEI] nat server test1 global 10.10.1.1 inside 192.168.1.2

[HUAWEI] nat server test2 protocol tcp global 10.10.1.1 888 inside 192.168.1.2 444

When receiving a packet destined for 10.10.1.1, the device searches the server mapping table and preferentially matches the more accurate NAT Server configuration, that is, the second NAT Server configuration. If the second NAT Server configuration is successfully matched, the device translates the destination IP address and port number of the packet and then forwards the packet. If the second NAT Server configuration fails to be matched, the first NAT Server configuration is matched, and the device translates the destination IP address of the packet and forwards it.

When a user on the Internet sends a request packet destined for the public address (specified by global) in the NAT Server configuration, the device forwards the packet to the connected router according to the default route, as the device has no session entry matching the packet. When receiving the packet, the router forwards the packet back to the device according to the routing table. As a result, the packet is indefinitely forwarded between the device and router, causing a routing loop.

To resolve this problem, specify the route parameter to configure an open programming route (OPR). Similar to a blackhole route, an OPR can prevent routing loops and can be imported and advertised by dynamic routing protocols such as OSPF. The upstream and downstream routers can receive routes to public IP addresses.

If the public address (specified by global) in the NAT Server configuration and the public address of the WAN interface are on different network segments, you must configure a blackhole route. If the public address (specified by global) in the NAT Server configuration and the public address of the WAN interface are on the same network segment, you are advised to configure a blackhole route.

If the nat server command has been run but no route is configured, you can run the nat server name route command without changing the original configuration to configure a route. This meets users' requirements for flexible route configuration.

Precautions

  1. Port numbers can be configured for NAT Server only when the protocol type is TCP, UDP, or SCTP.
  2. When the protocol type is SCTP, the configured public port number must be the same as the private port number.
  3. The undo nat server all command deletes all NAT Server configurations in the local system.

Example

# Configure two NAT Servers named for_web and for_ftp to specify the WWW server IP address as 192.168.10.10 and FTP server IP address as 192.168.10.11, so that users can access the WWW server through http://10.110.10.10:8080 and the FTP server through ftp://10.110.10.10. 
<HUAWEI> system-view
[HUAWEI] nat server for_web protocol tcp global 10.110.10.10 8080 inside 192.168.10.10 www
[HUAWEI] nat server for_ftp protocol tcp global 10.110.10.10 ftp inside 192.168.10.11 ftp
