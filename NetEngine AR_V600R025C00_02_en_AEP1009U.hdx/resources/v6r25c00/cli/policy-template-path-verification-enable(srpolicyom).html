path verification (SR Policy template view)

Function

The path verification enable command enables the fault detection function in an SR Policy attribute template.

The path verification specified-sid enable command enables the enhanced fault detection function in an SR Policy attribute template.

The path verification disable command disables the fault detection function in an SR Policy attribute template.

The undo path verification enable command disables the fault detection function in an SR Policy attribute template.

The undo path verification specified-sid enable command disables the enhanced fault detection function in an SR Policy attribute template.

The undo path verification disable command enables the fault detection function in an SR Policy attribute template.

By default, the fault detection function in an SR Policy attribute template is not enabled.

Format

path verification { enable | disable }

path verification specified-sid enable

undo path verification [ { enable | disable } ]

undo path verification specified-sid enable

Parameters

Parameter Description Value
enable

Enables the fault detection function in an SR Policy attribute template.

-
disable

Disables the fault detection function in an SR Policy attribute template.

-

Views

SR Policy template view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The path verification enable (SR Policy template view) command enables the fault detection function in an SR Policy attribute template, the srv6-te-policy path verification enable (Segment Routing IPv6 view) command globally enables the fault detection function for all SRv6 TE Policies in the Segment Routing IPv6 view, and the path verification enable (SRv6 TE Policy view) command enables the fault detection function for a single SRv6 TE Policy.

For the same path, if the srv6-te-policy path verification enable (Segment Routing IPv6 view) and path verification enable (SRv6 TE Policy view) commands are both run and the template referenced by the path has fault detection configurations, the path verification enable (SRv6 TE Policy view) command configuration has the highest priority. The path verification enable (SR Policy template view) command configuration has the second highest priority, followed by the srv6-te-policy path verification enable (Segment Routing IPv6 view) command configuration.

The path verification specified-sid enable (SR Policy template view) command enables the enhanced fault detection function in an SR Policy attribute template.

Precautions

Modifying the enabling configuration of fault detection takes effect only for SRv6 TE Policies and may interrupt SRv6 TE Policy services. Exercise caution when performing this operation.

Example

# Enable the enhanced fault detection function in an SR Policy attribute template.
<HUAWEI> system-view
[HUAWEI] segment-routing policy-template 1
[HUAWEI-sr-policy-template-1] path verification specified-sid enable
# Enable the fault detection function in an SR Policy attribute template.
<HUAWEI> system-view
[HUAWEI] segment-routing policy-template 1
[HUAWEI-sr-policy-template-1] path verification enable
