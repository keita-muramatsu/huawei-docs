utmost-power

Function

The utmost-power disable command disables radios from sending packets at maximum power.

The utmost-power enable command enables radios to send packets at maximum power.

The undo utmost-power command restores the auto-sensing mode for a radio to send packets.

By default, radios send packets in adaptive mode.

Format

utmost-power { disable | enable }

undo utmost-power

Parameters

Parameter Description Value
disable

Disables the function.

-
enable

Enables this function.

-

Views

2.4G radio profile view, 5G radio profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

This command is valid for all country codes. You can run the utmost-power enable command to enable radios to send packets at the maximum power or run the utmost-power disable command to enable radios to send packets at the power regulated by the country code. After you run the undo utmost-power command to restore the adaptive mode, radios send packets at the maximum power if the country code is CN or at the power regulated by other country codes

Precautions

Radios of only 802.11ac and 802.11ax APs can send packets at the maximum power.

This function may cause AP radios to exceed the laws and regulations of the local country or region. Therefore, ensure that you have obtained permission from the local administrative department before using this function.

For APs running R024C00 or later, this function takes effect only on the 2.4 GHz and 5 GHz radios, but not on 6 GHz radios.

If the maximum transmit power is used and the transmit power of a radio is specified using the eirp command, the actual maximum transmit power of the radio does not exceed the value specified using the eirp command.

Example

# Disable radios from sending packets at maximum power.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] radio-2g-profile name default
[HUAWEI-wlan-radio-2g-prof-default] utmost-power disable
