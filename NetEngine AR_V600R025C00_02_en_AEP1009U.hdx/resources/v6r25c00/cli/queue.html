queue

Function

The queue command sets QoS parameters of a flow queue in a flow queue profile.

The undo queue command deletes a specified flow queue from a flow queue profile.

By default, QoS parameters are not configured for a flow queue in a flow queue profile.

Flow queue view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The QoS parameters that can be configured in a flow queue profile include the scheduling mode, shaping parameters, drop policy, and queue length.

Precautions

  • In each traffic policy, a maximum of four flow queues using PQ scheduling can be configured.
  • The queue-length command sets the maximum length of a queue in a traffic behavior. The queue length affects the effects of queue-based traffic shaping, congestion management, and congestion avoidance.
  • When the number of packets in a queue reaches the maximum number of packets supported in the queue or the total number of bytes in a queue reaches the maximum number of bytes supported in the queue, the queue does not accept received packets but discards the packets. The longer the queue length is, the more packets can be buffered, but a longer delay is introduced. If the queue length is set to a small value, fewer packets can be buffered and packets are likely to be discarded.
  • You are advised to use the default value 64 for the queue length configured based on packets. You are advised not to set the queue length to a value less than 16. If the length is set to the maximum value 1024, it is recommended that the number of queues be less than or equal to 3.
  • For the AR6710-L14T2X4, traffic shaping parameters of bucket P cannot be configured.

Example

# Set QoS parameters of a flow queue in a flow queue profile.
<HUAWEI> system-view
[HUAWEI] drop-profile test
[HUAWEI-drop-test] quit
[HUAWEI] flow-queue test
[HUAWEI-flow-queue-template-test] queue data drr weight 50 shaping 6000 pbs 1000 drop-profile test
