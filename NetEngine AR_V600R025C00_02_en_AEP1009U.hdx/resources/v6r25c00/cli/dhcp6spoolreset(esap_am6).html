reset dhcpv6 pool

Function

The reset dhcpv6 pool command clears the IPv6 address pool configured on the device.

Format

reset dhcpv6 pool pool-name [ allocated { address | prefix } | binding [ duid ] | conflict address | start-ipv6-address [ to end-ipv6-address ] | ipv6-prefix/ipv6-prefix-length ]

Parameters

Parameter Description Value
allocated

Deletes IPv6 addresses or IPv6 address prefixes that have been assigned.

-
address

Specifies an IPv6 address.

-
prefix

Specifies an IPv6 address prefix.

-
binding [ duid ]

Deletes an IPv6 address with a specified DUID.

The value is a string of an even number of characters ranging from 2 to 260 in hexadecimal notation.
conflict

Resets the conflicting IPv6 addresses in the IPv6 address pool.

-
start-ipv6-address [ to end-ipv6-address ]

Specifies the IPv6 address range in the IPv6 address pool to be reset. If only one IPv6 address is specified, only this address is reset.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
ipv6-prefix/ipv6-prefix-length

Specifies the IPv6 prefix in the IPv6 address pool to be reset.

The value is a 32-digit hexadecimal number, in the format X:X::X:X/M.

The prefix length ranges from 1 to 128.
pool pool-name

Specified an IPv6 address pool name.

The value is a string of 1 to 31 characters. It cannot contain spaces. The value can be a combination of digits, letters, underscores (_), and periods (.).

Views

User view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The reset dhcpv6 pool command resets the address pool status. If an IPv6 address conflict occurs, set the IPv6 address pool to idle using the reset dhcpv6 pool command.

Precautions

If a user's IPv6 address is within the IPv6 address range specified using the command, the user cannot continue to use the IPv6 address. In this case, the user needs to send an IPv6 address application request again.

The address pool status cannot be restored after this command is run. Therefore, exercise caution when running this command.

Example

# Set the status of all conflicting IPv6 addresses in the address pool mypool to idle.
<HUAWEI> reset dhcpv6 pool mypool conflict address
