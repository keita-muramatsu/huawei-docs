path-index(DIA path index)

Function

The path-index interface command specifies a DIA path index.

The undo path-index interface command deletes a specified DIA path index.

By default, no DIA path index is specified.

Format

path-index index interface { interface-name | interface-type interface-number } [ next-hop-address ] [ track nqa nqa-admin-name nqa-test-name ]

undo path-index index [ interface { interface-name | interface-type interface-number } [ next-hop-address ] [ track nqa nqa-admin-name nqa-test-name ] ]

Parameters

Parameter Description Value
interface interface-name

Specifies an interface name.

The value is a string of 1 to 63 case-insensitive characters. It cannot contain spaces.
interface interface-type

Specifies an interface type.

-
interface interface-number

Specifies the interface number.

The value is a string of 1 to 63 characters. It cannot contain spaces.
next-hop-address

Specifies the next-hop IPv4 address of the outbound interface.

The value is in dotted decimal notation.
track nqa nqa-admin-name

Specifies the administrator name of an NQA test instance.

The value is a string of 1 to 32 characters, excluding question marks (?), en dashes (-), a single or consecutive quotation marks (").
track nqa nqa-test-name

Specifies the name of an NQA test instance.

The value is a string of 1 to 32 characters, excluding question marks (?), en dashes (-), a single or consecutive quotation marks (").
path-index index

Specifies a DIA path index.

The value is an integer ranging from 1 to 10.

Views

saas-cloud-express view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

This command is used to specify a unique path index for the local SaaS access link.

For the path, track nqa is used to detect link connectivity. When the link is normal, the path can be selected for SaaS traffic steering. When the link is disconnected, the path is not selected for SaaS traffic steering.

Precautions

When configuring an Ethernet link, you must specify the next-hop IP address of the outbound interface. Otherwise, packets cannot be forwarded.

Example

# Set the path index of the DIA outbound interface 10GE 0/0/1 to 1.
<HUAWEI> system-view
[HUAWEI] saas-cloud-express
[HUAWEI-saas-cloud-express] path-index 1 interface 10GE 0/0/1
