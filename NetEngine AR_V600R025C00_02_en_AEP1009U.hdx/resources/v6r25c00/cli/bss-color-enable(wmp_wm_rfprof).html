bss-color enable

Function

The bss-color enable command enables the BSS coloring function.

The undo bss-color enable command disables the BSS coloring function.

By default, the BSS coloring function is disabled.

Format

bss-color enable

undo bss-color enable

Parameters

None

Views

RRM profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In high-density scenarios, the 802.11ax protocol introduces the BSS coloring mechanism to improve system performance and channel usage efficiency. When detecting 802.11ax signals, STAs can identify the signals from the overlapping basic service set (OBSS) based on the BSS color bit or MAC address, determine air interface conflicts, and perform interference management according to related information. The BSS coloring function enables a device to distinguish between the transmissions on the local and neighboring networks. Then, it can adaptively adjust the power and the sensitivity threshold to allow dynamic adjustment of the transmit power and the signal detection threshold to increase spatial reuse efficiency and minimize co-channel interference.

Precautions

Disabling the BSS coloring function will automatically disable the spatial reuse (SR) function.

The BSS coloring function does not take effect when the radio scanning function is enabled on an AP.

Example

# Disable the BSS coloring function.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] rrm-profile name default
[HUAWEI-wlan-rrm-prof-default] undo bss-color enable
Warning: The spatial reuse function will become invalid when BSS color function is disable. Continue? [Y/N]y
