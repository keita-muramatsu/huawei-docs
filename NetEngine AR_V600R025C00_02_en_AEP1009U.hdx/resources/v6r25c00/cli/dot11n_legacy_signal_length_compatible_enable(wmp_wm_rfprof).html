dot11n legacy-signal-length-compatible enable

Function

The dot11n legacy-signal-length-compatible enable command enables the L-SIG field length compatibility function of the 802.11n protocol.

The undo dot11n legacy-signal-length-compatible enable command disables the L-SIG field length compatibility function of the 802.11n protocol.

By default, the L-SIG field length compatibility function of the 802.11n protocol is disabled.

Format

dot11n legacy-signal-length-compatible enable

undo dot11n legacy-signal-length-compatible enable

Parameters

None

Views

2.4G radio profile view, 5G radio profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

On a Wi-Fi network, if 802.11n STAs encounter severe packet loss, the possible cause is that the length of the L-SIG field sent by the STAs does not comply with the 802.11n protocol. In this case, you can run this command to enable the L-SIG field length compatibility function of the 802.11n protocol.

Precautions

To enable this function, you need to run the radio-type command to configure the radio type first. However, the radio type cannot be set to dot11ax. Therefore, exercise caution when running this command.

Example

# Enable the L-SIG field length compatibility function of the 802.11n protocol in the 2.4 GHz radio profile default.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] radio-2g-profile name default
[HUAWEI-wlan-radio-2g-prof-default] dot11n legacy-signal-length-compatible enable
