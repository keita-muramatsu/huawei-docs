ifit loss-measure enable

Function

The ifit loss-measure enable command enables IFIT-based packet loss measurement for an SRv6 TE Policy.

The undo ifit loss-measure enable command disables IFIT-based packet loss measurement for an SRv6 TE Policy.

By default, IFIT-based packet loss measurement is disabled for an SRv6 TE Policy.

Format

ifit loss-measure enable

undo ifit loss-measure enable

Parameters

None

Views

SRv6 TE policy view

Default Level

2: Configuration level

Usage Guidelines

After IFIT-based packet loss measurement is enabled for an SRv6 TE Policy with available candidate paths, the device detects the packet loss rate change of traffic in real time in order to perform traffic optimization.

Example

# Enable IFIT-based packet loss measurement for an SRv6 TE Policy.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] srv6-te policy p1 endpoint 2001:DB8:2::2 color 1
[HUAWEI-segment-routing-ipv6-policy-p1] ifit loss-measure enable
