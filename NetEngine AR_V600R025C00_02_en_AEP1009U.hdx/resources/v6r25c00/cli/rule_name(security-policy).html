rule name (Security policy view)

Function

The rule name command creates a security policy rule and displays the security policy rule view.

The undo rule command deletes a security policy rule.

By default, this function is not configured.

Format

rule name rule-name

undo rule { name rule-name | id rule-id | all }

Parameters

Parameter Description Value
name rule-name

Specifies the name of a security policy rule.

The value is a case-sensitive character string. The length of a name ranges from 1 to 63 characters. If a name contains spaces, the name must be enclosed with quotation marks (for example, "user for test"). The name cannot contain any question marks (?) or quotation marks (").
id rule-id

Specifies the ID of the security policy rule to be deleted.

You can run the display security-policy rule all command to view the ID of rules to be deleted.

The value is an integer in the range from 1 to 2000.
all

Indicates all security policy rules.

-

Views

Security policy view

Default Level

2: Configuration level

Usage Guidelines

To create a security policy rule, run the rule name command.

Example

# Create security policy rule policy_sec. 
<HUAWEI> system-view
[HUAWEI] security-policy
[HUAWEI-policy-security] rule name policy_sec
[HUAWEI-policy-security-rule-policy_sec]
