probe-response-retry

Function

The probe-response-retry command sets the number of times Probe Response packets are retransmitted.

The undo probe-response-retry command restores the default number of times Probe Response packets are retransmitted.

By default, the number of Probe Response packet retransmissions is 1.

Format

probe-response-retry retry-time

undo probe-response-retry

Parameters

Parameter Description Value
probe-response-retry retry-time

Specifies the number of times Probe Response packets are retransmitted.

The value is an integer that ranges from 0 to 3.

If the value is 0, Probe Response packets are not retransmitted.

Views

SSID profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In a high-density wireless environment, if too many Probe Response frames are transmitted, they occupy a large number of wireless resources. To reduce wireless resource occupation of the frames, you can run this command to set a small number of Probe Response packet retransmissions or forbid the retransmissions.

Precautions

A small number of retransmissions of Probe Response frames may reduce the channel scan efficiency of some STAs while a large number of retransmissions of Probe Response frames may lower the wireless network performance.

The configuration of retry-time in effect varies for different types of frames depending on AP models, as described in the following table.

Value of retry-time Number of Frame Retransmissions on AirEngine XX73 Series APs Number of Frame Retransmission on Other Series APs
0 Probe Response frame: 0; management frame: 0; data frame: 16 Probe Response frame: 0; management frame: 3; data frame: 32
1 Probe Response frame: 1; management frame: 3; data frame: 32 Probe Response frame: 1; management frame: 3; data frame: 32
2 Probe Response frame: 2; management frame: 12; data frame: 70 Probe Response frame: 2; management frame: 3; data frame: 32
3 Probe Response frame: 2; management frame: 12; data frame: 70 Probe Response frame: 3; management frame: 3; data frame: 32

Example

# Set the number of times Probe Response packets are retransmitted to 0.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ssid-profile name ssid1
[HUAWEI-wlan-ssid-prof-ssid1] probe-response-retry 0
