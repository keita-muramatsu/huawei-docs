record out-interface(ICMP test instance)

Function

The record out-interface command enables an NQA ICMP test instance to record outbound interface and SD-WAN site information in the result table.

The undo record out-interface command disables an NQA ICMP test instance from recording outbound interface and SD-WAN site information in the result table.

By default, the function of recording outbound interface and SD-WAN site information in the result table is disabled.

Format

record out-interface

undo record out-interface

Parameters

None

Views

NQA view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In an SD-WAN scenario, you can run the record out-interface command to enable an NQA ICMP test instance to record SD-WAN site and outbound interface information of probe packets in the result table.

Precautions

  1. The outbound interface displayed in the result table is obtained through table lookup in the forwarding plane when the test instance ends. The outbound interface is not the actual outbound interface of probe packets.
  2. In non-SD-WAN scenarios, if the outbound interface of a route is not displayed as an interface type, the outbound interface cannot be displayed.

Example

# Enable an NQA ICMP test instance to record outbound interface and SD-WAN site information of probe packets in the result table.
<HUAWEI> system-view
[HUAWEI] nqa test-instance user test
[HUAWEI-nqa-user-test] test-type icmp
[HUAWEI-nqa-user-test] record out-interface
