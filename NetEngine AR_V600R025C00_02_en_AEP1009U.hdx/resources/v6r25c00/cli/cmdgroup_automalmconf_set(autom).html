alarm-synchronization

Function

The alarm-synchronization enable command enables periodic alarm synchronization.

The undo alarm-synchronization enable command disables periodic alarm synchronization.

The alarm-synchronization interval command sets an interval for periodic alarm synchronization.

The undo alarm-synchronization interval command restores the default interval for periodic alarm synchronization.

By default, the periodic alarm synchronization function is enabled. The interval for periodic alarm synchronization is automatically adjusted based on the number of approved member devices that support alarm management. The adjustment rules are as follows:

If the number of member devices is less than or equal to 50, the synchronization interval is 5 minutes.

If the number of member devices is greater than 50 but less than or equal to 100, the synchronization interval is adjusted to 10 minutes.

If the number of member devices is greater than 100 but less than or equal to 200, the synchronization interval is extended to 20 minutes.

If the number of member devices exceeds 200, the synchronization interval is set to 30 minutes.

Format

alarm-synchronization enable

alarm-synchronization interval interval-paravalue

undo alarm-synchronization enable

undo alarm-synchronization interval

Parameters

Parameter Description Value
interval interval-paravalue

Specifies an interval for periodic alarm synchronization.

The value is an integer ranging from 5 to 50000, in minutes.
enable

Enables periodic alarm synchronization.

-

Views

Net-assistant view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

To enable periodic alarm synchronization and change the interval for periodic alarm synchronization, run this command. This enables the master device to periodically obtain critical and major active alarms from member devices. The obtained alarms are displayed on WebMaster.

Precautions

  • The alarm management function is not supported by the following devices, and the master device cannot obtain active alarms of member devices of these models: AirEngine5776-26, AirEngine6776-56TP, AirEngine6776-57T, AirEngine5773-23HW, AirEngine5773-23H, AirEngine5773-22P, AirEngine5773-21, AirEngine5773H-21, AirEngine6776I-X6TH, AirEngine6776I-X7TH, AirEngine6776-58TI (AirEngine6776-58T), AirEngine5576-26, AirEngine6576-56TP, AirEngine6576-57T, AirEngine5573-21, AirEngine3573-21, AirEngine5773-25HW, AirEngine5773-23WP, AirEngine5573-23HW, AirEngine5573-23H, AirEngine5773-23W, AirEngine6776I-X6ETH, AirEngine5573-23W, AirEngine5576I-X6EH, AirEngine6776-X6H, AirEngnie6776-X6ETH, AirEngine5776-56T, AirEngine5776I-X6H, AirEngine5776I-X7H, AirEngine5776I-X6EH, AirEngine6776-58TI-K, AirEngine6776I-X6ETH-K, AirEngine5776-57T, and AirEngine5776-57.
  • It is recommended that the interval for periodic alarm synchronization be greater than or equal to the default interval to prevent high CPU usage.
    • If the number of member devices is less than or equal to 50, the interval must be greater than or equal to 5 minutes.
    • If the number of member devices is greater than 50 and less than or equal to 100, the interval must be greater than or equal to 10 minutes.
    • If the number of member devices is greater than 100 and less than or equal to 200, the interval must be greater than or equal to 20 minutes.
    • If the number of member devices is greater than 200, the interval must be greater than or equal to 30 minutes.

Example

# Disable periodic alarm synchronization.
<HUAWEI> system-view
[HUAWEI] net-assistant
[HUAWEI-net-assistant] undo alarm-synchronization enable
# Change the interval for periodic alarm synchronization to 20 minutes.
<HUAWEI> system-view
[HUAWEI] net-assistant
[HUAWEI-net-assistant] alarm-synchronization interval 20
