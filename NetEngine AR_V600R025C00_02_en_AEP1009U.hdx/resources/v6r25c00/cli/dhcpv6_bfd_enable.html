dhcpv6 bfd enable

Function

The dhcpv6 bfd enable command enables dynamic BFD for DHCPv6.

The undo dhcpv6 bfd enable command disables dynamic BFD for DHCPv6.

By default, dynamic BFD for DHCPv6 is disabled.

Format

dhcpv6 bfd enable

undo dhcpv6 bfd enable

Parameters

None

Views

10GE sub-interface view, 10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE sub-interface view, 40GE interface view, Dialer interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, Eth-Trunk interface view, GE optical interface view, GE sub-interface view, GE interface view, GE electrical interface view, Multi-GE interface view, VLANIF interface view, Sub-interface view, Management interface view, Ethernet interface view, Ethernet sub-interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Dynamic BFD for DHCPv6 helps you quickly detect link faults between DHCPv6 clients and servers. After dynamic BFD for DHCPv6 is enabled on a DHCPv6 client, once the link connecting to a DHCPv6 server fails, the client can quickly detect the fault and release the current IP address. Subsequently, the client periodically attempts to apply for a new IP address from the server until it obtains a new IP address after the link recovers.

In VRRP hot standby scenarios, this function takes effect when the links connected to master and backup devices in the VRRP group all fail.

Prerequisites

The IPv6 function has been enabled on the interface using the ipv6 enable command.

Precautions

  • BFD must be enabled globally for the configuration to take effect.
  • When the DHCPv6 PD client function is enabled on an interface, you need to run the ipv6 address <dhcpv6-prefix> command on the interface to bind an IPv6 address with a DHCPv6 PD prefix to this interface.
  • Only U-BFD Echo is supported.
  • In a VRRP dual-device hot backup scenario, the BFD detection interval must be greater than the VRRP master/backup switchover time.
  • If a DHCPv6 client and DHCPv6 server are connected through a Layer 3 device (for example, DHCPv6 relay agent), dynamic BFD for DHCPv6 does not take effect.

Example

# Enable dynamic BFD for DHCPv6 on 10GE0/0/1 in the DHCPv6 client scenario.
<HUAWEI> system-view
[HUAWEI] bfd
[HUAWEI-bfd] quit
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] undo portswitch
[HUAWEI-10GE0/0/1] ipv6 enable
[HUAWEI-10GE0/0/1] ipv6 address auto link-local
[HUAWEI-10GE0/0/1] ipv6 address auto dhcp
[HUAWEI-10GE0/0/1] dhcpv6 bfd enable
# Enable dynamic BFD for DHCPv6 on 10GE0/0/1 in the DHCPv6 PD client scenario.
<HUAWEI> system-view
[HUAWEI] bfd
[HUAWEI-bfd] quit
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] undo portswitch
[HUAWEI-10GE0/0/1] ipv6 enable
[HUAWEI-10GE0/0/1] ipv6 address auto link-local
[HUAWEI-10GE0/0/1] dhcpv6 client pd prefix1
[HUAWEI-10GE0/0/1] ipv6 address prefix1 2001:db8:1::1/64
[HUAWEI-10GE0/0/1] dhcpv6 bfd enable
