display hwtacacs-server template

Function

The display hwtacacs-server template command displays the configuration of an HWTACACS server template.

The display hwtacacs-server template verbose command displays HWTACACS authentication, accounting, and authorization statistics.

Format

display hwtacacs-server template name template-name [ verbose ]

display hwtacacs-server template

Parameters

Parameter Description Value
verbose

Displays statistics about the HWTACACS server template.

-
name template-name

Displays the configuration of a specified HWTACACS server template.

The HWTACACS server template must already exist.

Views

All views

Default Level

3: Management level

Usage Guidelines

Usage Scenario

You can run this command to view the configuration of an HWTACACS server template to check whether the configuration is correct.

If verbose is specified, you can view HWTACACS authentication, accounting, and authorization statistics. The statistics help administrators understand the interaction between modules and locate faults. You can run the reset hwtacacs-server statistics { all | accounting | authentication | authorization } command to clear HWTACACS authentication, accounting, and authorization statistics. In the HWTACACS server template, the IP address of the authentication server, authorization server, or accounting server must have been configured so that the corresponding statistics can be viewed.

Precautions

The device determines whether its communication with the HWTACACS server is normal based on the response timeout mechanism of HWTACACS request packets, and always marks the status of the last HWTACACS server as Up.
