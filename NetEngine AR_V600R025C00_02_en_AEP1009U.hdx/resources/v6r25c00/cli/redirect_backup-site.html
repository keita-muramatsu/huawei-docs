redirect backup-site

Function

The redirect backup-site command configures an action of redirecting packets to a backup site in a traffic behavior.

The undo redirect backup-site command deletes an action of redirecting packets to a backup site from a traffic behavior.

By default, an action of redirecting packets to a backup site is not configured in a traffic behavior.

Format

redirect backup-site siteid

undo redirect backup-site

Parameters

Parameter Description Value
backup-site siteid

Specifies the ID of a backup site.

The value is an integer ranging from 1 to 65535.

Views

Traffic behavior view

Default Level

2: Configuration level

Usage Guidelines

  • In SD-WAN scenarios, you can configure both the primary and backup sites for redirection. When the connection status of the primary site is down, service traffic can be redirected to the backup site to ensure successful forwarding.

Example

# Configure an action of redirecting traffic to backup site 1 in the traffic behavior tb1.
<HUAWEI> system-view
Enter system view, return user view with return command. 
[HUAWEI] traffic behavior tb1
[HUAWEI-behavior-tb1] redirect site 12345
[HUAWEI-behavior-tb1] redirect backup-site 1
