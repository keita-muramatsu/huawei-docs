display pppoe-client session

Function

The display pppoe-client session command displays the PPPoE session status and statistics on a PPPoE client.

Format

display pppoe-client session { packet | summary } [ dialer number ]

Parameters

Parameter Description Value
packet

Displays packet statistics of PPPoE sessions.

-
summary

Displays brief information about PPPoE sessions.

-
dialer number

Displays statistics about a specified PPPoE session. If no PPPoE session is specified, statistics about all PPPoE sessions are displayed.

For the AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S and AR5710-S10T1X2:The value is an integer that ranges from 0 to 31.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR8700 series, AR8100 series and AR6700-H series:The value is an integer in the range from 0 to 1023.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

When monitoring PPPoE sessions, you can run this command to obtain the status and statistics of PPPoE sessions. The command output helps you diagnose PPPoE faults.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display brief information about PPPoE sessions on the PPPoE client.
<HUAWEI> display pppoe-client session summary
-----------------------------------------------------------------------------------------
PPPoE Client Session(summary):
ID    Dialer   Bundle    Intf       Client-MAC       Server-MAC        State    AC-Name
1     1        1         GE0/0/0    00e0-fc03-0201   00e0-fccd-0680    UP       DUALFW_V500e0fc030203
-----------------------------------------------------------------------------------------
# Display packet statistics about all PPPoE sessions on the PPPoE client.
<HUAWEI> display pppoe-client session packet
--------------------------------------------------------------------------------
PPPoE Client Session(packet):
ID     InP        InO        InD         OutP       OutO       OutD
1      36         758          0             50          1222          0
--------------------------------------------------------------------------------
Table 1 Description of the display pppoe-client session command output
Item Description
PPPoE Client Session(summary)

Indicates the table of brief information about PPPoE sessions.
PPPoE Client Session(packet)

Indicates the table of packet statistics of all PPPoE sessions.
ID

PPPoE session ID.
Dialer

Number of the dialer interface for PPPoE dial-up.
Bundle

Indicates the dialer bundle corresponding to a PPPoE session.
Intf

Physical interface corresponding to PPPoE dial-up.
Client-MAC

MAC address of the PPPoE client.
Server-MAC

MAC address of the PPPoE server.
State

Status of a PPPoE session. The options are as follows:

IDLE: The session is idle.

PADI: The PPPoE session is at the Discovery stage and a PADI packet has been sent.

PADR: The PPPoE session is at the Discovery stage and a PADR packet has been sent.

UP: The PPPoE session has been established.
AC-Name

Name of the access concentrator corresponding to PPPoE dial-up.
InP

In Packets: number of received packets.
InO

In Octets: number of received bytes.
InD

In Discards: number of incoming packets that are discarded.
OutP

Out Packets: number of sent packets.
OutO

Out Octets: number of sent bytes.
OutD

Out Discard: number of outgoing packets that are discarded.
