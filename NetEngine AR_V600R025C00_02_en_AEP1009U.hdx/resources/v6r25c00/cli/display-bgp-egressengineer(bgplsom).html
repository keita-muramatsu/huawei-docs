display bgp egress-engineering

Function

The display bgp egress-engineering command displays BGP EPE information.

Format

display bgp egress-engineering

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

BGP EPE allocates BGP peer SIDs to inter-AS paths. BGP-LS advertises the BGP peer SIDs to the network controller. The controller uses the explicit paths to orchestrate IGP SIDs and BGP peer SIDs to implement inter-AS optimal path forwarding.

To view peer-node SIDs and peer-Adj SIDs, run the display bgp egress-engineering command.
