display hrp history-information

Function

The display hrp history-information command displays historical information about the hot standby status changes, including the Up/Down of the heartbeat link and the role change of the active/standby device.

Format

display hrp history-information

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

The display hrp state command displays only the last status change information, while the display hrp history-information command displays historical status change information, allowing you to learn the causes of status changes.

Precautions

After you run the undo hrp enable command to disable hot standby, historical status change information still exists and is not deleted.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display historical status changes of hot standby.
<HUAWEI> display hrp history-information
 2020-05-11 16:25:23 The HRP link changes to up. local device ID is xx-xx-xx-xx-xx-xx, peer device ID is xx-xx-xx-xx-xx-xx.
 2020-05-11 16:25:22 The HRP link changes to down due to "The peer device noticate". local device ID is xx-xx-xx-xx-xx-xx, peer device ID is xx-xx-xx-xx-xx-xx.
 2020-05-11 16:08:11 The HRP core state changed due to "Prefered role changed". (old_state = load sharing (secondary), new_state = standby, local_fault_indicator = 2, local_robustness_indicator = 10, peer_fault_indicator = 2, peer_robustness_indicator = 10)
 2020-05-11 16:08:07 The HRP interface changed from Eth-Trunk500 to Eth-Trunk1006.
