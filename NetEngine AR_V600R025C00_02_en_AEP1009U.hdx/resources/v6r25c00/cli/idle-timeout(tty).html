idle-timeout (user interface view)

Function

The idle-timeout command sets a timeout period to disconnect from the user interface. If no command is entered within the specified period, the system tears down the current connection.

The undo idle-timeout command restores the default timeout period.

By default, the timeout period of the console user interface is 5 minutes and the timeout period of the VTY user interface is 10 minutes.

Format

idle-timeout minutes [ seconds ]

undo idle-timeout

Parameters

Parameter Description Value
minutes

Specifies the time period in seconds to disconnect from the user interface view.

The value is an integer ranging from 0 to 35791, in minutes. The default value is 10.
seconds

Specifies the time period in seconds to disconnect from the user interface view.

The value is an integer that ranges from 0 to 59, in seconds. The default value is 0.

Views

CONSOLE-type user interface view, VTY-type user interface view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

You can run the idle-timeout 0 0 command to disable the timeout disconnection function of the VTY. If this function is disabled and an administrator does not close an operation interface due to negligence, non-administrator users may perform unauthorized operations.

If the VTY timeout disconnection function is disabled, other users may fail to obtain idle connections.

Example

# Set the timeout period of the console user interface to 1.5 minutes.
<HUAWEI> system-view
[HUAWEI] user-interface console 0
[HUAWEI-ui-console0] idle-timeout 1 30
# Set the timeout period of vty user interface view to 1 minute and 30 seconds.
<HUAWEI> system-view
[HUAWEI] user-interface vty 0 4
[HUAWEI-ui-vty0-4] idle-timeout 1 30
