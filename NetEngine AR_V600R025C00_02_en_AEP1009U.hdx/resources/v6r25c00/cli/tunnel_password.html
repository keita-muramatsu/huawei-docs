tunnel password

Function

The tunnel password command specifies the password for tunnel authentication.

The undo tunnel password command cancels the password for tunnel authentication.

By default, tunnel authentication is enabled and the tunnel password is empty.

Format

tunnel password cipher password

undo tunnel password [ cipher [ password ] ]

Parameters

Parameter Description Value
cipher password

Specifies the password for tunnel authentication.

The value is a string of case-sensitive characters. The value is a plaintext string of 1 to 16 characters or a ciphertext string of 128 to 432 characters.

Views

L2TP group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

You can determine whether to enable tunnel authentication before creating a tunnel connection. After tunnel authentication is enabled, run the tunnel password command to configure a password for tunnel authentication. To ensure channel security, you are advised to enable tunnel authentication.

Prerequisites

You have run the l2tp-group command to create an L2TP group and enter the L2TP group view.

You have run the tunnel authentication command to enable tunnel authentication. By default, tunnel authentication is enabled.

Precautions

If tunnel authentication is enabled on the L2TP client or LNS, the same configuration must be performed on the peer end. In addition, the tunnel authentication passwords configured on the two ends must be the same.

If an L2TP connection has been established in the L2TP group, running the tunnel password command to change the tunnel authentication password will disconnect the L2TP tunnel and session. Therefore, exercise caution when running this command.

Example

# Set the password for tunnel authentication to YsHsjx_202206.
<HUAWEI> system-view
[HUAWEI] l2tp-group 1
[HUAWEI-l2tp-group-1] tunnel password cipher YsHsjx_202206
Warning: This operation may cause traffic interruption, Continue? [Y/N]:
