display ipv6 nd anti-attack record

Function

The display ipv6 nd anti-attack record command displays detailed information about ND messages discarded due to rate limiting.

Format

display ipv6 nd anti-attack record { all | { interface-name | interface-type interface-num } }

Parameters

Parameter Description Value
all

Displays all ND message attack records.

-
interface-name

Displays all ND message attack records on a specified interface.

-
interface-type interface-num

Displays all ND message attack records on a specified interface.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run the display ipv6 nd anti-attack record command to view detailed information about ND messages discarded due to rate limiting, thereby obtaining information about the attack source. For example, you can configure a rate at which a device processes ND messages so that the device processes only the specified number of ND messages within a specified period and discards excess ND messages. To view records about discarded ND messages, run the display ipv6 nd anti-attack record command.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display ND message attack records on a specified interface.
<HUAWEI> display ipv6 nd anti-attack record 10ge 0/0/1

Dropped Reason

Reason for message discarding:

·Validate MAC fail: The ND message is discarded because the source link address or destination link address is different from the source MAC address in the Layer 2 header.

·Source MAC attack check: The ND message is discarded on the VR due to punishment based on the source MAC address.

·Interface ndmiss attack limit: The ND Miss message is discarded on the interface due to rate limiting.

·Interface source ip attack limit: The ND message is discarded on the interface due to rate limiting based on the source IPv6 address.

·Interface packet attack limit: The ND message is discarded on the interface due to rate limiting.

·VR source mac attack limit: The ND message is discarded on the VR due to rate limiting based on the source MAC address.

·VR source ip attack limit: The ND message is discarded on the VR due to rate limiting based on the source IPv6 address.

·VR destination ip attack limit: The ND message is discarded on the VR due to rate limiting based on the destination IPv6 address.

·VR target ip attack limit: The ND message is discarded on the VR due to rate limiting based on the target IPv6 address.

·VR packet attack limit: The ND message is discarded on the VR due to rate limiting.

·LR ndmiss attack limit: The ND Miss message is discarded on the LR due to rate limiting.

·LR packet attack limit: The ND message is discarded on the LR due to rate limiting.
