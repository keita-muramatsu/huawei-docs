qos phb marking

Function

The qos phb marking command enables mapping between PHBs and DSCP or 802.1p priorities in the outbound direction.

The undo qos phb marking command disables mapping between PHBs and DSCP or 802.1p priorities in the outbound direction.

By default, mapping from PHBs to 802.1p priorities is disabled and mapping from PHBs to DSCP priorities is disabled for outgoing packets.

Format

qos phb marking dscp enable

qos phb marking 8021p enable

undo qos phb marking dscp enable

undo qos phb marking 8021p enable

Parameters

None

Views

10GE interface view, 25GE interface view, 40GE interface view, Dialer interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, GE interface view, IP-Trunk interface view, MP-group interface view, Multi-GE interface view, POS interface view, Virtual serial interface view, Sub-interface view, Interface group view, Ethernet interface view, Ethernet sub-interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

  • Generally, the mapping between PHBs and DSCP priorities is disabled on the device that functions as the edge node of the DS domain. When the downstream device needs to use the DSCP priority of packets, you can run the qos phb marking dscp enable command to enable mapping from PHBs to DSCP priorities for outgoing packets.
  • Generally, the mapping between PHBs and 802.1p priorities is disabled on the device that functions as the edge node of the DS domain. When the downstream device needs to use the 802.1p priority of packets, you can run the qos phb marking 8021p enable command to enable mapping from PHBs to 802.1p priorities for outgoing packets.
  • MP-group interfaces and virtual serial interfaces do not support the qos phb marking 8021p enable command.
  • POS and IP-Trunk interfaces do not support the qos phb marking 8021p enable command.

Precautions

The AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2XE, AR5710-S8T2X-LTE4EA, AR5710-S8T2XE-LTE4EA-T, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8T1XWE, AR5710-S8T2S, AR5710-S8T2XE-NRGL, AR5710-S8P2XE-NRGL, AR5710-S8T1XWE-NRGL, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8TWDSE-LTE4EA, AR5710I-RU-NRGL devices do not support this command on Layer 2 interfaces.

Example

# Enable mapping from PHBs to 802.1p priorities for outgoing packets on 10GE0/0/1.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] qos phb marking 8021p enable
# Enable mapping between PHBs and DSCP priorities for outgoing packets on 10GE0/0/1.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] qos phb marking dscp enable
