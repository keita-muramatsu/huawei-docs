download scheduled

Function

The download scheduled command downloads a specified software package at a specified time.

The cancel download scheduled command cancels a scheduled download task.

By default, no software package is downloaded.

Format

download scheduled scheduled-time scheduled-time-val { system-software | patch | feature-software { feature-name } &<1-9> } *

cancel download scheduled

Parameters

Parameter Description Value
system-software

Specifies a basic software package.

The value is a keyword.

  • If this parameter is specified, the basic software package of the new version is downloaded from the HOUP platform.
  • If this parameter is not specified, the basic software package of the new version is not downloaded from the HOUP platform.
patch

Specifies a patch package.

The value is a keyword.

  • If this parameter is specified, the patch package of the new version is downloaded from the HOUP platform.
  • If this parameter is not specified, the patch package of the new version is not downloaded from the HOUP platform.
feature-software feature-name

Specifies the names of features for which feature packages are to be downloaded.

The value is a string of 1 to 127 case-sensitive characters. It cannot contain spaces.

  • If this parameter is specified, the feature package of the new version is downloaded from the HOUP platform.
  • If this parameter is not specified, the feature package of the new version is not downloaded from the HOUP platform.
cancel

Cancels a scheduled task.

The value is a keyword.
scheduled-time scheduled-time-val

Specifies the download time.

The value is a string of 1 to 31 characters. The time format is yyyy-mm-ddThh:mm:ss. This parameter specifies the local system time of the device.

Views

Smart upgrade view

Default Level

3: Management level

Usage Guidelines

The download function in smart upgrade supports two download modes: scheduled download and manual download. In the scheduled download scenario, run the check new-version command to trigger the device to check the software package to be upgraded, run the display smart-upgrade information command to check the software package to be upgraded, run the download scheduled command to specify the download time, and select the system package, patch package, or feature package to be downloaded.

If a scheduled download task has been created using the download scheduled command, you can run the cancel download scheduled command to cancel the scheduled download task before the system time reaches the specified time. If the system time is later than the specified time, the scheduled task cannot be canceled.

Example

# Download the basic software package, patch package, and feature packages feature1 and feature2 at 12:14:16 on September 12, 2024.
<HUAWEI> system-view
[HUAWEI] smart-upgrade
[HUAWEI-smart-upgrade] download scheduled scheduled-time 2024-09-12T12:14:16 system-software patch feature-software feature1 feature2
# Download the basic software package at 12:14:16 on September 12, 2024.
<HUAWEI> system-view
[HUAWEI] smart-upgrade
[HUAWEI-smart-upgrade] download scheduled scheduled-time 2024-09-12T12:14:16 system-software
# Cancel the created scheduled download task.
<HUAWEI> system-view
[HUAWEI] smart-upgrade
[HUAWEI-smart-upgrade] cancel download scheduled
