key-exchange

Function

The key-exchange command configures the key exchange algorithm for a P2MP policy.

The undo key-exchange command deletes the key exchange algorithm of a P2MP policy.

By default, no key exchange algorithm is configured for a P2MP policy.

Format

key-exchange { dh-group19 | dh-group20 | dh-group21 } [ strict ]

undo key-exchange { { dh-group19 | dh-group20 | dh-group21 } [ strict ] }

Parameters

Parameter Description Value
dh-group19

Indicates that the key exchange algorithm uses DH-GROUP19, that is, a 256-bit Elliptic Curve Groups modulo a Prime (ECP) DH group is used during negotiation.

-
dh-group20

Indicates that the key exchange algorithm uses DH-GROUP20, that is, a 384-bit ECP DH group is used during negotiation.

-
dh-group21

Indicates that the key exchange algorithm uses DH-GROUP21, that is, a 512-bit ECP DH group is used during negotiation.

-
strict

Indicates that the DH group used for negotiation is in strict mode. If this parameter is not specified, the DH group is in loose mode.

-

Views

IPSec P2MP policy view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To ensure secure communication on the network, you are advised to run the key-exchange command to configure the key exchange algorithm for a P2MP policy.

Configuration Impact

If a P2MP policy is enabled on a TNP or tunnel interface, modifying or deleting the key exchange algorithm will interrupt traffic.

Precautions

The configurations of the DH groups used by the key exchange algorithms on both ends of an IPsec tunnel must be the same. In strict mode, if the configurations of the DH groups used by the key exchange algorithms on both ends of an IPsec tunnel are different, the tunnel cannot be established.

Example

# Configure the key exchange algorithm for a P2MP policy and set the DH group to DH-GROUP21.
<HUAWEI> system-view
[HUAWEI] ipsec p2mp-policy aa
[HUAWEI-ipsec-p2mp-policy-aa] key-exchange dh-group21
