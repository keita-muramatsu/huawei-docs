ifit egress mapping-color-flag enable

Function

The ifit egress mapping-color-flag enable command enables color bit switching in the outbound direction on an interface in the scenario where native-IP IFIT interworks with application-level IFIT.

The undo ifit egress mapping-color-flag enable command disables color bit switching in the outbound direction on an interface in the scenario where native-IP IFIT interworks with application-level IFIT.

By default, color bit switching in the outbound direction is disabled on an interface in the scenario where native-IP IFIT interworks with application-level IFIT.

Format

ifit egress mapping-color-flag enable

undo ifit egress mapping-color-flag enable

Parameters

None

Views

Layer 2 10GE interface view, 10GE interface view, 25GE-L2 view, 25GE interface view, Layer 2 40GE interface view, 40GE interface view, Layer 2 Eth-Trunk interface view, Eth-Trunk interface view, Ethernet interface view, Layer 2 GE interface view, GE optical interface view, GE sub-interface view, GE electrical interface view, Layer 2 multi-GE interface view, Multi-GE interface view

Default Level

2: Configuration level

Usage Guidelines

To implement performance measurement in the scenario where native-IP IFIT interworks with application-level IFIT, color bit switching needs to be performed for packets in the outbound direction. You can run this command to enable color bit switching in the outbound direction on an interface in the preceding interworking scenario, implementing conversion from application-level IFIT to native-IP IFIT.

Example

# Enable color bit switching in the outbound direction on an interface in the scenario where native-IP IFIT interworks with application-level IFIT.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] ifit egress mapping-color-flag enable
