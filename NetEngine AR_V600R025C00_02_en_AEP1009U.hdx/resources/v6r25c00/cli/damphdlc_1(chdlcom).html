hdlc dampening level

Function

The hdlc dampening level command configures an HDLC link dampening level.

The undo hdlc dampening level command restores the HDLC link dampening default level.

By default, the HDLC link dampening level is light.

Format

hdlc dampening level { light | middle | heavy | manual { half-life-period half-life-period-para suppress-threshold suppress-para reuse-threshold reuse-para max-suppress-time max-suppress-time-para } }

undo hdlc dampening level { light | middle | heavy | manual [ half-life-period half-life-period-para suppress-threshold suppress-para reuse-threshold reuse-para max-suppress-time max-suppress-time-para ] }

Parameters

Parameter Description Value
light

Specifies that the HDLC link dampening level is light.

-
middle

Specifies that the HDLC link dampening level is middle.

-
heavy

Specifies that the HDLC link dampening level is heavy.

-
manual

Specifies that the HDLC link dampening level is manually set.

-
half-life-period half-life-period-para

Specifies half-life of the HDLC link dampening.

The value is an integer ranging from 1 to 60, in seconds.
suppress-threshold suppress-para

Specifies the suppression value of the HDLC link dampening.

The value is an integer ranging from 2 to 20000.
reuse-threshold reuse-para

Specifies the reuse value of the HDLC link dampening.

The value is an integer ranging from 1 to 19999.
max-suppress-time max-suppress-time-para

Specifies the maximum suppression time of the HDLC link dampening.

The value is an integer ranging from 2 to 255, in seconds.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Optical fiber flapping on a physical interface causes HDLC link to alternate between Up and Down frequently. This results in the link or network layers unstable. To prevent frequent HDLC link flapping from causing flapping of the link and network layers, configure the HDLC link dampening function.

This function enables HDLC link dampening on an interface. Therefore, if the HDLC link flapping occurs, stability of the link or network layers can be guaranteed. When the HDLC dampening function is enabled, run the hdlc dampening level command to configure a light, middle, or heavy PPP link dampening level based on the dampening requirements, or configure the dampening level manually.

  • light: If a light HDLC link dampening is configured, dampening procedure will only be triggered when the HDLC link flaps frequently and rapidly.
  • middle: If a middle HDLC link dampening is configured, intensity of the HDLC link dampening is between the light and heavy.
  • heavy: If a heavy HDLC link dampening is configured, dampening will be triggered even if flapping of the link is not severe. That is, the link is vulnerable to dampening.
  • manual: If HDLC link dampening is manually configured, you can configure HDLC link dampening level based on sensitivity of flapping.

Example

# Set the HDLC link dampening level to middle.
<HUAWEI> system-view
[HUAWEI] hdlc dampening level middle
