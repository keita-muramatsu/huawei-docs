display engine breakpoint-resume-blocking cache

Function

The display engine breakpoint-resume-blocking cache command displays information about the resumable transfer cache table.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

display engine breakpoint-resume-blocking cache

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

After the resumable transfer blocking function is enabled, the device records the resumable transfer connection information in the cache table to block these connections.

You can run this command to view information about the resumable transfer cache table.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display information about the resumable transfer cache table.
<HUAWEI> display engine breakpoint-resume-blocking cache
Breakpoint-resume-blocking cache on slot 0 cpu 0
total entry num available:1024     current num:1
connection:1.1.1.1:0->2.2.2.2:80 app:HTTP ttl:60 left-time:45 file:a.exe hit:8 module:IPS
Table 1 Description of the display engine breakpoint-resume-blocking cache command output
Item Description
total entry num available

Maximum number of cache entries on a single CPU.
current num

Number of cache entries on the current CPU.
connection

Connection information.
app

Application-layer protocol.
ttl

Node aging time.
left-time

Remaining aging time.
file

file path.
hit

Hit count.
module

Module.
