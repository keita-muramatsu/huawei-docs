lldp disable(remote-unit view)

Function

The lldp disable command disables LLDP for RUs.

The undo lldp disable command enables LLDP for RUs.

By default, LLDP is enabled for RUs.

Format

lldp disable

undo lldp disable

Parameters

None

Views

remote-unit view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After an RU is delivered, its downlink interface receives LLDP packets and notifies the central device of the LLDP packets. The central device then records the interface for connecting the LLDP neighbor to the RU. To configure the function of recording the RU interfaces connected to LLDP neighbors for an RU, you can run the lldp disable or lldp enable command in the remote-unit-N view. The configuration of a single RU takes precedence over the configuration in the global RU view. If no configuration is performed for a single RU, the configuration in the global RU view is used.

Follow-up Procedure

After running this command, run the commit all command for the configuration to take effect.

Precautions

If LLDP is enabled or disabled on an RU, the configuration in the single RU view is used. If no configuration is performed for a single RU, the configuration in the global RU view is used.

When the configuration is delivered to the global RU view, the configuration is delivered only to S5751-L series RUs. Other RUs do not support LLDP.

Example

# Disable LLDP for an RU.
<HUAWEI> system-view
[HUAWEI] remote-unit
[HUAWEI-remote-unit] lldp disable
