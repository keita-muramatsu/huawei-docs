system login information disable

Function

The system login information disable command disables the display of all login information after a successful login.

The undo system login information disable command enables the display of all login information after a successful login.

By default, all login information is displayed.

Format

system login information disable

undo system login information disable

Parameters

None

Views

System view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

After a user successfully logs in to the device, login information is displayed, including the number of online users, current login time, first login information, and last login information.

If you do not want the login information to be displayed, run the system login information disable command to disable the display of login information.

If you want the login information to be displayed, you can run the undo system login information disable command to restore the display of login information.

Precautions

The system login information disable command disables only the display of login information, but does not disable user interaction (for example, the system asks the user whether to change the password).

The system login information disable command does not disable the risk warning function on the SSH server. To disable the risk warning function, run the ssh server security-banner disable command.

Example

# Restore the display of login information.
<HUAWEI> system-view
[HUAWEI] undo system login information disable
# Disable the display of login information.
<HUAWEI> system-view
[HUAWEI] system login information disable
