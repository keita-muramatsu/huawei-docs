traffic-policy decap-process enable

Function

The traffic-policy decap-process enable command enables the decapsulation traffic policy function on a tunnel interface.

The undo traffic-policy decap-process enable command disables the decapsulation traffic policy function on a tunnel interface.

By default, the decapsulation traffic policy function is disabled on a tunnel interface.

Format

traffic-policy decap-process enable

undo traffic-policy decap-process enable

Parameters

None

Views

Tunnel interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

With the proliferation of users and service types on networks, it becomes ever-more critical to offer differentiated services to users. You can configure hierarchical scheduling in the inbound direction of a tunnel interface to differentiate both services and users, implementing refined QoS. After you configure MQC for the decapsulation service on a physical interface that receives traffic and enable a decapsulation traffic policy on the tunnel interface, the decapsulation traffic policy configured on the physical interface is implemented when traffic passes through the tunnel interface. In this way, hierarchical scheduling is implemented on the tunnel interface.

Prerequisites

  • This function needs to be used in SD-WAN EVPN scenarios.
  • A decapsulation traffic policy has been applied to the inbound interface of traffic using the traffic-policy inbound decap-process command.

Precautions

  • When hierarchical scheduling is configured on a tunnel interface, the qos car inbound decap-process, traffic-policy inbound decap-process, and traffic-policy decap-process enable commands must be used together. Otherwise, hierarchical scheduling does not take effect.
  • The traffic-policy decap-process enable command takes effect only in SD-WAN EVPN scenarios. Other protocols can be configured but do not take effect.

Example

# Enable the decapsulation traffic policy function on Tunnel 1.
<HUAWEI> system-view
[HUAWEI] interface tunnel 1
[HUAWEI-Tunnel1] tunnel-protocol sd-wan
[HUAWEI-Tunnel1] traffic-policy decap-process enable
