netstream sampler ipv6 (interface view)

Function

The netstream sampler ipv6 command configures IPv6 packet sampling on an interface.

The undo netstream sampler ipv6 command restores the default configuration.

By default, IPv6 packet sampling is not configured on an interface.

Format

netstream sampler ipv6 fix-packets packet-number { inbound | outbound }

undo netstream sampler ipv6 fix-packets packet-number { inbound | outbound }

Parameters

Parameter Description Value
inbound

Samples incoming traffic on an interface.

-
outbound

Samples outgoing traffic on an interface.

-
fix-packets packet-number

Specifies the number of packets between two sampled packets in packet-based regular sampling. In this mode, one packet is sampled every packet-number packets.

The value is an integer in the range from 1 to 32768 and must be 2^n (n = 0, 1, 2...).

Views

10GE interface view, 25GE interface view, 40GE interface view, Dialer interface view, Eth-Trunk interface view, Ethernet interface view, GE interface view, IP-Trunk interface view, Multi-GE interface view, POS interface view, Tunnel interface view, VLANIF interface view, Serial interface view, Sub-interface view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

If NetStream is enabled on an interface, the system records NetStream-related information in a specific interface information table. If each packet on an interface is collected and counted, forwarding performance of the interface (especially high-speed interfaces) greatly deteriorates. To learn about the traffic characteristics of an interface and at the same time minimize the impact of packet statistics collection on interface forwarding performance, enable NetStream sampling on the interface. The lower the sampling rate, the less the impact on the device performance.

Precautions

After NetStream is configured in inbound or outbound direction and a sampling interval is configured, flow sampling will be performed based on the configuration.

If you run the netstream sampler command multiple times in the same view, only the latest configuration takes effect.

In the tunnel interface view, the sampling rate can be configured only when the encapsulation mode is GRE or SD-WAN.

It is recommended that NetStream sampling be configured on a service interface. For example, if a sub-interface is a service interface, configure NetStream sampling on this sub-interface. If NetStream sampling is configured on a main interface, sampling may be incomplete.

When PPP is configured on the serial interface, IPv6 sampling does not take effect.

Example

# Configure IPv6 packet-based regular sampling on an interface in the inbound direction and set the sampling rate to 1. 
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] netstream sampler ipv6 fix-packets 1 inbound
# Configure IPv6 packet-based regular sampling on an interface in the outbound direction and set the sampling rate to 1. 
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] netstream sampler ipv6 fix-packets 1 outbound
