oui

Function

The oui command configures an organizationally unique identifier (OUI) for STAs in the whitelist.

The undo oui command deletes the OUI of a specified STA or all STAs in the whitelist.

By default, no OUI is configured for STAs in the whitelist.

Format

oui oui [ description description ]

undo oui { oui | all }

Parameters

Parameter Description Value
oui oui

Specifies the OUI of STAs in the whitelist.

The value is in the format of xx-xx-xx, where x is a 1-digit hexadecimal number.

For example, 00-e0-fc indicates a STA whose MAC address starts with 00-e0-fc.
description description

Specifies the OUI description of STAs in the whitelist.

The value is a string of 1 to 80 characters and can contain spaces.
all

Deletes an authorized OUI table.

-

Views

STA whitelist profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After the whitelist function is enabled, only STAs in the whitelist can connect to the WLAN. In some scenarios, all STAs with a specified OUI need to be added to the whitelist. You can run this command to implement OUI-based fuzzy match by adding all STAs with a specified OUI to the whitelist.

Precautions

Both MAC addresses and OUIs can be configured in a STA whitelist profile. The total number of MAC addresses and OUIs cannot exceed the maximum number of MAC addresses supported by the whitelist profile.

Example

# Configure the OUI 00-e0-fc for STAs in the whitelist profile sta-whitelist-profile1.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] sta-whitelist-profile name sta-whitelist-profile1
[HUAWEI-wlan-whitelist-prof-sta-whitelist-profile1] oui 00-e0-fc
