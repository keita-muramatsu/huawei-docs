isis ipv6 enable

Function

The isis ipv6 enable command enables IS-IS IPv6 on an interface and specifies the ID of the IS-IS process to be associated with the interface.

The undo isis ipv6 enable command disables IS-IS IPv6 from an interface and disassociates the interface from a specified IS-IS process.

By default, IS-IS IPv6 is disabled on an interface.

Format

isis ipv6 enable

isis ipv6 enable process-id

undo isis ipv6 enable

undo isis ipv6 enable process-id

Parameters

Parameter Description Value
process-id

Specifies an IS-IS process ID.

The value is an integer ranging from 1 to 4294967295. The default value is 1.

Views

10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, Ethernet interface view, GE optical interface view, GE electrical interface view, IP-Trunk interface view, Loopback interface view, MP-group interface view, POS interface view, Tunnel interface view, VLANIF interface view, 40GE sub-interface view, 10GE sub-interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After completing the configuration of an IS-IS process in the system view, to ensure that IS-IS runs properly in IPv6, enable IS-IS IPv6 on the interface that runs IS-IS and associate the interface with the IS-IS process using the isis ipv6 enable command.

Prerequisites

The following steps have been performed:

  • An IS-IS process has been configured using the isis command, and a network entity title (NET) has been configured for the IS-IS process using the network-entity command.
  • IPv6 has been enabled for the IS-IS process using the ipv6 enable (IS-IS) command in the IS-IS view.
  • IPv6 has been enabled for each interface that needs to run an IS-IS process using the ipv6 enable command, and an IPv6 address has been configured for each of the interfaces.

    The IPv6 function has been configured so that IPv6-related configurations can be performed.

Example

# Create IS-IS process 1, enable IPv6, and activate IPv6 for the process on 10GE 0/0/1. 
<HUAWEI> system-view
[HUAWEI] isis 1
[HUAWEI-isis-1] network-entity 10.0001.1010.1020.1030.00
[HUAWEI-isis-1] ipv6 enable
[HUAWEI-isis-1] quit
[HUAWEI] interface 10GE0/0/1
[HUAWEI-10GE0/0/1] undo portswitch
[HUAWEI-10GE0/0/1] ipv6 enable
[HUAWEI-10GE0/0/1] ipv6 address 2001:db8:1::1/64
[HUAWEI-10GE0/0/1] undo portswitch
[HUAWEI-10GE0/0/1] isis ipv6 enable 1
