default-action

Function

The default-action command specifies the default action to be taken on packets when no link meets conditions in the SPR policy.

The undo default-action command restores the default action to be taken on packets when no link meets conditions in the SPR policy.

By default, packets matching the SPR policy are allowed to pass through when no link is available.

Format

default-action { discard | forward }

undo default-action

Parameters

Parameter Description Value
discard

Denies packets if these packets match the SPR policy and no link is available.

-
forward

Allows packets to pass through if these packets match the SPR policy and no link is available.

-

Views

SPR policy view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If no link in an SPR policy meets the requirements, you can configure the device to forward or discard the packets matching the SPR policy based on actual service requirements.

If the default action is set to discard, packets matching the SPR policy are discarded when no link meets the requirements.

If the default action is set to forward, the device selects a link with the optimal CMI from all links in the current policy to forward packets. If no link is available in the policy, the device randomly selects a link that is not specified in the policy to forward packets.

Prerequisites

A smart policy route has been created using the smart-policy-route command.

A policy profile has been created using the spr-policy command in the smart-policy-route view.

Example

# Set the default action to discard in policy spr1.
<HUAWEI> system-view
[HUAWEI] smart-policy-route
[HUAWEI-smart-policy-route] spr-policy node 1
[HUAWEI-smart-policy-route-spr-policy-node-1] default-action discard
