apply-label explicit-null (BGP-IPv6 unicast address family view)

Function

The apply-label explicit-null command enables IPv6 provider edge (6PE) routes to share the explicit null label.

The undo apply-label explicit-null command disables 6PE routes from sharing the explicit null label.

By default, the function is disabled.

Format

apply-label explicit-null

undo apply-label explicit-null

Parameters

None

Views

BGP-IPv6 unicast address family view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

By default, a 6PE device applies for a label for each 6PE route. If a large number of routes need to be sent, label resources on the 6PE device may be wasted. If label resources are insufficient, IPv6 routes cannot be advertised.

To save label resources on a 6PE device and prevent IPv6 routes from failing to be advertised due to insufficient label resources, run the apply-label explicit-null command on the 6PE device.

Configuration Impact

After the apply-label explicit-null command is run on a 6PE device, all the IPv6 routes sent by the 6PE device to its peer share the explicit null label.

Precautions

After a 6PE peer relationship is established, running the apply-label explicit-null or undo apply-label explicit-null command causes temporary packet loss.

Example

# Enable 6PE routes to share the explicit null label in the BGP-IPv6 unicast address family view.
<HUAWEI> system-view
[HUAWEI] bgp 100
[HUAWEI-bgp] ipv6-family unicast
[HUAWEI-bgp-af-ipv6] apply-label explicit-null
