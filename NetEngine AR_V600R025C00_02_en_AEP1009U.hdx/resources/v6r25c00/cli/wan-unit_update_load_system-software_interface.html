wan-unit update load system-software interface

Function

The wan-unit update load system-software interface command upgrades the system software of a specified WAN unit.

Format

wan-unit update load system-software interface { interface-name | ifType ifNum } file-name ip-address ip-address username username password password

Parameters

Parameter Description Value
file-name

Specifies the name of the system software package.

The value is a string of 1 to 127 case-sensitive characters, spaces not supported.
ip-address ip-address

Specifies the IP address of the SFTP server.

The value is in dotted decimal notation.
username username

Specifies the username for logging in to the SFTP server.

The value is a string of 1 to 63 case-sensitive characters. It cannot contain spaces.
password password

Specifies the password for logging in to the SFTP server.

The value is a string of 8 to 128 case-sensitive characters. It can contain letters and digits. If the string is enclosed in double quotation marks (" "), it can contain spaces.
interface interface-name

Specifies the name of the interface connecting to the RU.

The value is a string of 1 to 63 case-sensitive characters. It cannot contain spaces.
interface ifType ifNum

Specifies the type and number of the interface connecting to the RU.

The value depends on the device. You can enter a question mark (?) and select a value from the displayed value range.

Views

User view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

During routine device maintenance, you can run this command to configure SFTP server parameters and obtain the system software from the SFTP server to upgrade the system software of a specified WAN unit.

Precautions

  • During the upgrade of the WAN unit, do not remove or insert the Ethernet cable, and ensure that the WAN unit is not powered off. Otherwise, the upgrade fails and the WAN unit may be unavailable.
  • During the system software upgrade, the WAN unit automatically restarts, which interrupts services on the WAN unit for a short period of time. Therefore, exercise caution when performing this operation.
  • An unregistered WAN unit cannot be upgraded.
  • A WAN unit that is being restarted cannot be upgraded.
  • The upgrade status of the WAN unit can be:
    • Idle
    • Upgrading
    • Updated
    • Failed
  • The upgrade status of the WAN unit changes to Idle 5 minutes after the WAN unit is upgraded successfully or fails to be upgraded.
  • If the WAN unit remains in Upgrading state for more than 30 minutes, the upgrade fails and the upgrade status will change to Idle.
  • If the upgrade status of the WAN unit is Upgrading or Failed, the upgrade cannot be performed again before the upgrade status changes to Idle.

Example

# Upgrade the system software of the WAN unit connected to 10GE1/0/1.
<HUAWEI> wan-unit update load system-software interface 10GE1/0/1 file.Bin ip-address 192.168.0.10 username user password YsHsjx_202206
Warning: This operation will update the WAN unit system software. After the operation is successful, the WAN unit automatically restarts. Continue? [Y/N]:
