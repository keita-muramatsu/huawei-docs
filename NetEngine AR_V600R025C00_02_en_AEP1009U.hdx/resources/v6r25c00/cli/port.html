port (User-defined application rule view)

Function

The port command specifies a port in a user-defined application rule.

The undo port command deletes the port in a user-defined application rule.

By default, no port number is specified for a new user-defined application rule.

Format

port port [ end-port ] [ source | destination ]

undo port { port [ end-port ] [ source | destination ] | all }

Parameters

Parameter Description Value
port

Specifies the port number of a user-defined application rule.

The value is an integer ranging from 1 to 65535.
end-port

Specifies the end port number of a user-defined application rule.

The value is an integer ranging from 1 to 65535.
source

Indicates the source port.

-
destination

Indicates the destination port.

-
all

Deletes all port numbers.

-

Views

User-defined application rule view

Default Level

2: Configuration level

Usage Guidelines

A user-defined application rule supports a maximum of four port numbers and port ranges. The configured ports cannot overlap.

If end-port is specified, the port range is specified. The value of end-port minus the value of port ranges from 1 to 127. That is, a port range contains 2 to 128 ports. If the source and destination parameters are not specified, the destination port number is used for rule matching.

The relationship between source and destination port conditions is OR, but the relationship between source and destination port conditions is AND. That is, if both the source port and destination port are specified in a rule, a packet matches the rule only when the packet matches both the source port and destination port.

After the port is configured, the application identification module matches network packets based on the configured transport-layer protocol and IP address, that is, 5-tuple. After the user-defined 5-tuple is configured and committed, the application identification module uses the 5-tuple of the first packet of the session for matching. If the 5-tuple of the traffic to be identified is determined, you can configure a user-defined 5-tuple to accelerate traffic identification.

If source and destination are not specified, the destination port is used for rule matching.

A 5-tuple rule must contain at least one IP address or port number.

Example

# Set the port in user-defined application rule rule1 to 80. 
<HUAWEI> system-view
[HUAWEI] sa
[HUAWEI-sa] user-defined-application name UD_abc
[HUAWEI-sa-user-defined-app-UD_abc] rule name rule1
[HUAWEI-sa-user-defined-app-UD_abc-rule-rule1] port 80
