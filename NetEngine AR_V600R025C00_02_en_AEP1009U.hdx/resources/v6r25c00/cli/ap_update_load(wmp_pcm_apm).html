ap update load

Function

The ap update load command upgrades a specified AP.

The undo ap update load command cancels AP upgrade.

Format

ap update load { ap-mac ap-mac | ap-id ap-id } update-filename filename

undo ap update load { ap-mac ap-mac | ap-id ap-id }

Parameters

Parameter Description Value
ap-mac ap-mac

Specifies the MAC address of the AP to be upgraded.

The value is in H-H-H format. H is a hexadecimal number that contains one to four digits, such as 00e0 and fc01. If an H contains fewer than four digits, the leftmost digits are padded with 0s. For example, two 0s are added to e0 to form 00e0.
ap-id ap-id

Specifies the ID of the AP to be upgraded.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
update-filename filename

Specifies the AP upgrade file.

The upgrade file name must already exist.

Views

WLAN view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

When APs are upgraded in batches based on AP types, if the new version fails, the version rollback takes a long period. Therefore, you can update a single AP to check whether faults occur on the version, ensuring successful upgrades in batches. This ensures that the subsequent batch upgrade is successful.

Prerequisites

When the AC mode is used, the AP upgrade file has been uploaded to the WAC. If the FTP or SFTP mode is used, the AP upgrade file has been uploaded to the FTP server or SFTP server.

The AP is in normal or vmiss state.

Follow-up Procedure

Run the ap update reset { ap-mac ap-mac| ap-id ap-id} command to restart the AP to make the AP upgrade take effect.

Precautions

The undo ap update load { ap-mac ap-mac| ap-id ap-id} command can cancel the upgrade for a specified AP. However, if the AP system software has been written to the flash memory during the upgrade, the upgrade cannot be canceled. To check the AP upgrade progress, run the display ap update status ap-id ap-idcommand.

SFTP is recommended because it is more secure than FTP.

Example

# Upgrade AP 0 using the upgrade file AirEngineX760-V600R022C00.cc.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap update load ap-id 0 update-filename AirEngineX760-V600R022C00.cc
Info: The current upgrade mode is AC mode, which may affect performance and take a long time. The FTP or SFTP upgrade mode is recommended. Continue? [Y/N]:y
