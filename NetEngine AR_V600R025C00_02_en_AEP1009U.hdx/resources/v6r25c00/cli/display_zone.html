display zone

Function

The display zone command displays the information on a security zone.

Format

display zone [ zone-name ] [ interface | priority ]

Parameters

Parameter Description Value
zone-name

Specifies the name of a security zone.

The security zone must exist.
interface

Displays the interfaces in the specified security zone.

-
priority

Displays the priority of the specified security zone.

-

Views

All views, User view of the virtual system

Default Level

1: Monitoring level

Usage Guidelines

If no security zone is specified, you can view the information on all security zones.

If the parameter interface or priority is not specified, all the information on the configuration is displayed.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the dmz zone. 
<HUAWEI> display zone dmz
dmz
 priority is 50
 interface of the zone is (1):
    10GE0/0/1
#
Table 1 Description of the display zone command output
Item Description
priority

The priority of the security zone.
interface of the zone is (1)

Interfaces in the security zone.
