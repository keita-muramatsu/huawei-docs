band-steer higher-band

Function

The band-steer higher-band command configures low-band association suppression for STAs.

The undo band-steer higher-band command restores the default configuration.

By default, low-band association suppression for STAs is disabled.

Format

band-steer higher-band

undo band-steer higher-band

Parameters

None

Views

RRM profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Run the band-steer higher-band command to configure low-band association suppression for STAs so that STAs are steered to high-band radios for association. When a STA attempts to associate with an AP radio enabled with the band steering function, if the frequency band supported by the STA is higher than the frequency band of the target AP radio, the AP rejects the association request of the STA.

Precautions

The band-steer higher-band command must be used together with the band-steer deny-threshold command. If deny-threshold in the band-steer deny-threshold command is set to 0, the band-steer higher-band command configuration does not take effect.

After the band-steer higher-band command is executed, STA association is suppressed, which may cause association failures. Therefore, exercise caution when running this command.

Example

# Configure low-band association suppression for STAs in the RRM profile test.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] rrm-profile name test
[HUAWEI-wlan-rrm-prof-huawei] band-steer higher-band
