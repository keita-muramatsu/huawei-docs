traffic-hold bandwidth-ignore enable

Function

The traffic-hold bandwidth-ignore enable command enables the function of ignoring bandwidth conditions for traffic in an SPR policy profile.

The undo traffic-hold bandwidth-ignore enable command disables the function of ignoring bandwidth conditions for traffic in an SPR policy profile.

By default, the function of ignoring bandwidth conditions for traffic is disabled in an SPR policy profile.

Format

traffic-hold bandwidth-ignore enable

undo traffic-hold bandwidth-ignore enable

Parameters

None

Views

SPR policy view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When the traffic steering mode is set to load balancing, if bandwidth conditions are configured and the traffic rate exceeds the upper bandwidth threshold, all traffic on the link is switched to another link. After the function of ignoring bandwidth conditions for traffic is enabled, existing traffic is still transmitted over the original link when the traffic rate exceeds the upper bandwidth threshold, preventing network flapping.

Prerequisites

The traffic steering mode has been set to load balancing using the routing-mode command in the SPR policy view.

Example

# Enable the function of ignoring bandwidth conditions for traffic in a policy profile.
<HUAWEI> system-view
[HUAWEI] smart-policy-route
[HUAWEI-smart-policy-route] spr-policy node 1
[HUAWEI-smart-policy-route-spr-policy-node-1] routing-mode load-balance
[HUAWEI-smart-policy-route-spr-policy-node-1] traffic-hold bandwidth-ignore enable
