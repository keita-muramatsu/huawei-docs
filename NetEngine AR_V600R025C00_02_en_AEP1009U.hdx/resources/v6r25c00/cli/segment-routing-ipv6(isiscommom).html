segment-routing ipv6 locator (IS-IS view)

Function

The segment-routing ipv6 locator command enables the IS-IS SRv6 function.

The undo segment-routing ipv6 locator command disables the IS-IS SRv6 function.

By default, the IS-IS SRv6 function is disabled.

Format

segment-routing ipv6 locator locator-name

segment-routing ipv6 locator locator-name auto-sid-disable

undo segment-routing ipv6 locator locator-name

undo segment-routing ipv6 locator locator-name auto-sid-disable

Parameters

Parameter Description Value
locator-name

Specifies the name of a SID locator., which is configured through the locator command.

After you configure the locator-name parameter, IS-IS allows static End and End.X SIDs to be imported from the configured locator-name.

The value is a string of 1 to 31 case-sensitive characters. The character string can contain spaces if it is enclosed with double quotation marks (").
auto-sid-disable

Disables the dynamic assignment of End and End.X SIDs.

If the auto-sid-disable parameter is configured to disable the dynamic assignment of End and End.X SIDs, static End and End.X SIDs are imported from a specified locator.

If the auto-sid-disable parameter is not configured, End and End.X SIDs can be dynamically assigned. If static End and End.X SIDs exist, the static SIDs are used. If no static SIDs exist, dynamically assigned End and End.X SIDs are used.

-

Views

IS-IS view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In SRv6 scenarios, after SRv6 is enabled for IS-IS, End and End.X SIDs are preferentially generated based on the specified locator. The SRv6 SIDs generated by IS-IS are added to the local SID table and also advertised to neighbors through IS-IS LSPs.

Different parameter combinations in this command have different functions. Specifically:

segment-routing ipv6 locator locator-name: enables IS-IS SRv6 and dynamic SID allocation. SIDs must be allocated within the locator range.

segment-routing ipv6 locator locator-name auto-sid-disable: enables IS-IS SRv6 and disables dynamic SID allocation so that SIDs are statically allocated within the locator range.

undo segment-routing ipv6 locator locator-name [ auto-sid-disable ]: deletes all dynamic and static SIDs allocated by IS-IS in the specified locator. In this case, the auto-sid-disable parameter is optional. The configuration effect is the same regardless of whether this parameter is configured.

If a static opcode is configured when allocating an SRv6 SID, it is preferentially used for static SID generation. If no static opcode is configured, opcodes are dynamically assigned. The process of allocating SRv6 SIDs through IS-IS is as follows:

Configure a locator in the Segment Routing IPv6 view, and run the segment-routing ipv6 locator command in the IS-IS process view to enable SRv6 and reference the locator.

IS-IS allocates an End SID to each locator within the dynamic segment range based on the locator configuration. Three SRv6 flavors — penultimate segment POP of the SRH (PSP), ultimate segment pop of the SRH (USP), and ultimate segment decapsulation (USD) — are combined. By default, SIDs of the no-flavor, PSP, and PSP-USP-USD types are allocated to locators.

Configure IPv6 addresses for interfaces and enable IS-IS IPv6. IS-IS allocates End.X SIDs within the dynamic segment range based on locator configurations to the interfaces. By default, SIDs of the no-flavor and PSP types are allocated.

In an IS-IS process, dynamic and static End or End.X SIDs can be advertised for a maximum of two locators for algorithm 0. If End or End.X SIDs have been advertised for two locators for algorithm 0, the auto-sid-disable parameter needs to be configured for the newly referenced locator for algorithm 0. In this case, neither static nor dynamic SIDs can be configured or advertised for this locator, and the locator can only be used by other protocols (such as VPN) for routing purposes. For each of the other algorithms, End or End.X SIDs can be advertised for only one locator.

Prerequisites

Before running the segment-routing ipv6 locator command, complete the following tasks:

  • Run the ipv6 enable command to enable IS-IS IPv6.
  • Run the cost-style command to set the IS-IS cost type to wide, compatible, or wide-compatible.

Precautions

After the undo segment-routing ipv6 locator command is configured, IS-IS does not support the assignment and advertisement of SRv6 SIDs.

Example

# Enable IS-IS to import static End and End.X SIDs from a specified locator.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] locator test1 ipv6-prefix 2001:DB8:100:: 64 static 32
[HUAWEI-segment-routing-ipv6-locator] quit
[HUAWEI-segment-routing-ipv6] quit
[HUAWEI] isis 1
[HUAWEI-isis-1] ipv6 enable
[HUAWEI-isis-1] cost-style wide
[HUAWEI-isis-1] segment-routing ipv6 locator test1 auto-sid-disable
