eth-trunk (AP wired port profile view)

Function

The eth-trunk command adds an AP interface to an Eth-Trunk.

The undo eth-trunk command deletes an AP interface from an Eth-Trunk.

By default, an AP interface is not added to any Eth-Trunk.

Format

eth-trunk trunk-id

undo eth-trunk

Parameters

Parameter Description Value
trunk-id

Specifies the number of an Eth-Trunk interface.

The value is 0 or 1.

Views

AP wired port profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To improve connection reliability and increase interface bandwidth, you can run this command to bind multiple interfaces into an Eth-Trunk.

Prerequisites

Physical interfaces to be added to an Eth-Trunk cannot have other configurations. If there are any configurations, clear them first. The configurations to be cleared do not include the interface status, description, LLDP function, or CRC alarm configuration.

Precautions

  • After the configuration, you need to restart the AP to make the configured Eth-Trunk on AP wired interfaces take effect.

  • This command is not supported by an AP with only one physical uplink network interface.

  • The Eth-Trunk function is not supported by downlink interfaces on an AP.

  • The PVID and user isolation configurations are not supported by Eth-Trunk member interfaces.

  • For an AP that has gone online, configure the Eth-Trunk function before connecting physical cables. Otherwise, a loop may be generated, causing the AP to go offline.

  • For an AP that has not gone online, connect physical cables and then configure the Eth-Trunk function in the following sequence:

    1. Before the AP goes online, connect multiple physical cables between the AP and local device. By default, the interfaces on the local device are enabled and are not configured with the Eth-Trunk function.
    2. Run the shutdown command in the interface view on the local device to shut down interfaces. Among the interfaces connected to the same AP, reserve only one enabled for the AP to go online.
    3. Configure the AP to go online, and configure the Eth-Trunk function on AP wired interfaces. After the AP is restarted, the Eth-Trunk configuration takes effect.
    4. Configure an Eth-Trunk on the local device and run the undo shutdown command in the interface view to enable the interfaces that have been shut down.

  • For an AP that supports only one Eth-Trunk, the configuration takes effect only when the Eth-Trunk ID is set to 0.

  • If a member interface of an Eth-Trunk is connected to a peer end, the peer interface directly connected to the local interface must also be a member interface of the Eth-Trunk.

  • An Eth-Trunk cannot be added to another Eth-Trunk as a member interface.

  • Do not configure any member interface of an Eth-Trunk as an observing port. If this cannot be avoided, ensure that the bandwidth of service traffic on this member interface and the bandwidth of the mirrored traffic do not exceed the bandwidth limit of the interface.

  • An Ethernet interface can be added to only one Eth-Trunk. To add the Ethernet interface in an Eth-Trunk to another Eth-Trunk, delete it from the original Eth-Trunk first.

  • After an interface is added to an Eth-Trunk, MAC address entries and ARP entries are learned based on the Eth-Trunk but not based on member interfaces.

Example

# Add an AP interface to Eth-Trunk 0.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] wired-port-profile name wired-port1
[HUAWEI-wlan-wired-port-wired-port1] eth-trunk 0
