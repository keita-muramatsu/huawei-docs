sta-ipv6-service enable

Function

The sta-ipv6-service enable command enables the function of processing STA IPv6 services.

The undo sta-ipv6-service enable command disables the function of processing STA IPv6 services.

By default, the function of processing STA IPv6 services is disabled.

Format

sta-ipv6-service enable

undo sta-ipv6-service enable

Parameters

None

Views

WLAN view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Currently, IPv4 WLANs are widely deployed. If many IPv6 packets exist on an IPv4 WLAN, the performance of the WLAN is affected, and the CPU processing capability of devices will also be degraded. To improve performance of an IPv4-only network, you can disable devices from processing IPv6 packets of STAs.

Precautions

After the function of processing STA IPv6 services is disabled, the following situations occur:

  • The WAC and APs do not process wireless IPv6 packets.

  • IPv6 functions on the wireless side, such as IPv6 address learning, are disabled even if they are enabled in the default settings.

Running the ipv6 enable command in the interface view only enables the IPv6 function on the wired-side interface. However, this command configuration cannot enable the WLAN module to process STA IPv6 services. To enable the WLAN module to process IPv6 services of STAs, you need to run the sta-ipv6-service enable command in the WLAN view.

APs running V600R023C10 do not allow IPv6 functions to be enabled. Therefore, IPv6 forwarding cannot be disabled. When the WAC is connected to these APs, the following situations occur:

In direct forwarding scenarios, the WAC forwards IPv6 packets regardless of whether IPv6 is enabled.

In tunnel forwarding scenarios, the WAC discards IPv6 packets.

Example

# Enable the function of processing STA IPv6 services.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] sta-ipv6-service enable
