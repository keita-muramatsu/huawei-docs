ppp chap user

Function

The ppp chap user command configures a local user name.

The undo ppp chap user command deletes the configured local user name.

By default, the local user name is empty.

Format

ppp chap user user-name

undo ppp chap user

Parameters

Parameter Description Value
user-name

Specifies a local user name configured for the peer.

The value is a string of 1 to 253 characters.

Views

Dialer interface view, POS interface view, Serial interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The devices on both ends of a PPP link must complete the authentication phase before entering the network-layer protocol phase during the PPP link establishment in most cases. There are two major PPP authentication modes: CHAP and PAP. In unidirectional CHAP authentication, one end functions as the authenticator, and the other end as the authenticatee. In bidirectional CHAP authentication, both ends function as the authenticator as well as the authenticatee. In practice, only unidirectional CHAP authentication is adopted. Unidirectional CHAP authentication can be implemented when the authenticator is configured with a user name or is not configured with any user name.

This command is used to specify a user name for the local end to be authenticated by the peer end in CHAP mode. During authentication, the authenticator sends a Challenge packet to the authenticatee. Based on the password configured on its interface and the Challenge packet, the authenticatee calculates a value using an encryption algorithm. Then the authenticatee sends its host name and the calculated value in a response packet to the authenticator.

Prerequisites

Interfaces are connected, and physical parameters of the interfaces are configured so that the physical layer status of the interfaces is Up.

PPP has been configured as the link layer protocol of the interface.

The authentication mode is CHAP.

Configuration Impact

If the ppp authentication-mode command is run more than once, the latest configuration overrides the previous one. After the configuration, the local Device authenticates the remote Device as configured.

Precautions

In CHAP authentication mode, the username and password on the local end must be the same as those on the peer end.

After the configuration, you must run the shutdown and undo shutdown commands in the corresponding interface view for the configuration to take effect.

Example

# Set the local user name to Test123 for CHAP authentication on Dialer95.
<HUAWEI> system-view
[HUAWEI] interface Dialer 95
[HUAWEI-Dialer95] ppp chap user Test123
