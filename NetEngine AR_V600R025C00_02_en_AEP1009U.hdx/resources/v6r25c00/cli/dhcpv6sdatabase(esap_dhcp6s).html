dhcpv6 server database

Function

The dhcpv6 server database command enables the function of saving DHCPv6 data.

The undo dhcpv6 server database command disables the function of saving DHCPv6 data.

By default, the function of saving DHCPv6 data is disabled.

Format

dhcpv6 server database { enable | write-delay interval }

undo dhcpv6 server database { enable | write-delay [ interval ] }

Parameters

Parameter Description Value
enable

Enables the function of saving and restoring DHCPv6 data.

-
write-delay interval

Specifies the interval at which DHCPv6 data is saved.

The value is an integer ranging from 300 to 86400, in seconds. The default value is 86400s.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When the device functions as a DHCPv6 or DHCPv6 PD server, you can run the dhcpv6 server database command to enable the device to save DHCPv6 data. This avoids data loss caused by device faults. The system generates a dhcpv6s.txt file and saves it in the dhcp folder in the flash memory. DHCPv6 data includes the last saved time, address pool names, client DUIDs, IAIDs, addresses and prefixes bound to client DUIDs and IAIDs, conflicting addresses, and conflict detection time.

The system automatically saves current DHCPv6 data at the specified interval, and previous data files are overwritten. The interval can be set using the write-delay interval parameter.

Precautions

If the DHCPv6 client requests lease renewal when the device (functioning as the DHCPv6 server) restarts, the device may not receive the renewal request packet. As a result, the client fails to renew the lease.

Example

# Enable the device to save DHCPv6 to a storage device and automatically restore the data, and set the interval at which DHCPv6 data is saved to 3600 seconds.
<HUAWEI> system-view
[HUAWEI] dhcpv6 server database enable
[HUAWEI] dhcpv6 server database write-delay 3600
