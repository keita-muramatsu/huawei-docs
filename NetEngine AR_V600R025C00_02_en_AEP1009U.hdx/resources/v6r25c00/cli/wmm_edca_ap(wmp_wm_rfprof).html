wmm edca-ap

Function

The wmm edca-ap command configures EDCA parameters and ACK policies for an AP.

The undo wmm edca-ap command restores the default EDCA parameters and ACK policies for an AP.

For details about the default EDCA parameters and ACK policies on APs, see the description in Usage Scenario.

Format

wmm edca-ap { ac-be | ac-bk | ac-vi | ac-vo } { aifsn aifsn-value | ecw ecwmin ecwmin-value ecwmax ecwmax-value | txoplimit txoplimit-value | ack-policy { normal | noack } } *

undo wmm edca-ap

Parameters

Parameter Description Value
ac-be

Indicates AC_BE packets.

-
ac-bk

Indicates AC_BK packets.

-
ac-vi

Indicates AC_VI packets.

-
ac-vo

Indicates AC_VO packets.

-
aifsn aifsn-value

Specifies the arbitration inter frame spacing number (AIFSN), which determines the channel idle time.

The value is an integer ranging from 1 to 15.
ecw

Specifies the ECW parameters.

-
ecwmin ecwmin-value

Specifies the exponent form of the minimum contention window. ecwmin-value and ecwmax-value determine the average backoff time.

The value is an integer ranging from 0 to 15.
ecwmax ecwmax-value

Specifies the exponent form of the maximum contention window. ecwmin-value and ecwmax-value determine the average backoff time.

The value is an integer ranging from 0 to 15.
txoplimit txoplimit-value

Specifies the transmission opportunity limit, that is, the maximum duration in which a STA can occupy a channel after a successful contention. A larger value indicates a longer during for a STA to occupy a channel at a time.

The value is an integer ranging from 0 to 255, in the unit of 32 microseconds.
ack-policy

Specifies an ACK policy.

  • normal: During 802.11 packet exchange, the receiver must return an ACK packet each time it receives a packet from the sender.
  • noack: The receiver does not need to send an ACK packet when it receives a packet from the sender. Configure this parameter only in the good air interface environment. Otherwise, severe packet loss occurs.

-

Usage Guidelines

Usage Scenario

WMM classifies data packets into four access categories (ACs): AC_VO, AC_VI, AC_BE, and AC_BK. A set of EDCA parameters is set for each AC queue. These parameters determine the capabilities of a queue to occupy a channel. You can set EDCA parameters for packets of different ACs to provide different priorities to the packets. In this way, STAs have different capabilities to compete for channels and provide differentiated services.

Default EDCA parameter settings and ACK policies for APs

Packet Type ECWmax ECWmin AIFSN TXOPLimit ACK Policy
AC_VO 3 2 1 47 normal
AC_VI 4 3 1 94 normal
AC_BE 6 4 3 0 normal
AC_BK 10 4 7 0 normal

Precautions

  • The EDCA parameters configured for the four AC queues take effect only after the WMM function is enabled. By default, the WMM function is enabled in a 2.4 GHz or 5 GHz radio profile.
  • To make manually adjusted EDCA configuration take effect, disable dynamic EDCA parameter adjustment (by using the undo dynamic-edca enable command) and the intelligent multimedia scheduling algorithm (by using the undo multimedia-air-optimize enable command).
  • By default, queues of AC_VO, AC_VI, AC_BE, and AC_BK are in descending order of priority. Priorities of the four queues are determined by their EDCA parameters. Therefore, modifying the EDCA parameters affects the priorities of the queues.
  • EDCA parameters must be configured properly. The scenarios for the reference EDCA parameter settings are as follows:
  1. Table 3 lists the reference configurations in voice scenarios.

    Table 3: Reference EDCA parameter settings and ACK policies in voice scenarios
Packet Type ECWmax ECWmin AIFSN TXOPLimit ACK Policy
AC_VO 4 2 2 0 normal
AC_VI 5 3 5 0 normal
AC_BE 10 6 5 0 normal
AC_BK 10 8 12 0 normal
  1. Table 4 lists the reference configurations in voice and video scenarios.

    Table 4: Reference EDCA parameter settings and ACK policies in voice and video scenarios
Packet Type ECWmax ECWmin AIFSN TXOPLimit ACK Policy
AC_VO 4 2 2 0 normal
AC_VI 5 3 5 0 normal
AC_BE 10 6 12 0 normal
AC_BK 10 8 12 0 normal
  1. In high-density scenarios, it is recommended that you run the dynamic-edca enable command to enable dynamic EDCA parameter adjustment.
  2. For other scenarios, the default settings are recommended.

Example

# Configure EDCA parameters and ACK policies for AC_VO packets in 5G radio profile default.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] radio-5g-profile name default
[HUAWEI-wlan-radio-5g-prof-default] wmm edca-ap ac-vo aifsn 7 ecw ecwmin 4 ecwmax 10 txoplimit 0 ack-policy normal
