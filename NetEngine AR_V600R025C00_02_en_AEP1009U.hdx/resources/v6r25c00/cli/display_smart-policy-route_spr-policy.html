display smart-policy-route spr-policy

Function

The display smart-policy-route spr-policy command displays the configuration of an SPR policy profile.

Format

display smart-policy-route spr-policy all

display smart-policy-route spr-policy node-index

Parameters

Parameter Description Value
node-index

Specifies the node index of a policy profile.

The value is an integer that ranges from 1 to 30000.
all

Queries information about all SPR policy profiles.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

After configuring an SPR service profile, you can run the display smart-policy-route spr-policy command to check information about the policy profile configured on the device.

Example

Item Description

Whether switchback is enabled.

Default action to be taken on packets when no link in the policy meets requirements.

To configure this parameter, run the default-action command.
RoutingMode

Traffic steering mode of an SPR policy. For details about the configuration, see routing-mode.
TimeRange

Name of a time range.

To configure this parameter, run the time-range command.
TimeRangeStatus

Whether the time range is active.

-active.

-inactive.
Replication

Whether packet replication is enabled in an SPR instance.

Policy threshold information.
Loss

Packet loss rate threshold of a policy, in ‰.

To configure this parameter, run the loss-threshold command.

Delay threshold of a policy, in milliseconds.

To configure this parameter, run the delay-threshold command.

Jitter threshold of a policy, in milliseconds.

To configure this parameter, run the jitter-threshold command.

CMI threshold of a service in the SPR.

To configure this parameter, run the cmi-threshold command.

Information about the service profile bound to the policy profile.
ServiceMapID

Index of the service profile bound to the policy profile.
ServiceMapName

Name of the service profile bound to the policy.

To configure this parameter, run the service-map and binding service-map commands.
Match content

Traffic classification content of the service profile bound to the policy profile.
MatchType

Service traffic matching type.

-OnlyAcl: Traffic is matched against only the ACL.

-OnlyIPv6Acl: Traffic is matched against only the IPv6 ACL.

-OnlyApplication: Traffic is matched against only the application name.

-OnlyAppGroup: Traffic is matched against only the application group name.

-AclAndApplication: Traffic is matched against the ACL and application name.

-AclAndAppGroup: Traffic is matched against the ACL and application group name.

-IPv6AclAndApplication: Traffic is matched against the IPv6 ACL and application name.

-IPv6AclAndAppGroup: Traffic is matched against the IPv6 ACL and application group name.
AppGroup

AclName

Information about the primary transport network.
TNId

Index of a transport network.
TNName

Name of a transport network.

Priority

Priority of a link.

For details about the configuration commands, see link-priority.
Backup TransportNetwork

Information about the secondary transport network.
