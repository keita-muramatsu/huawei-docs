check file-digest digest-algorithm

Function

The check file-digest digest-algorithm command checks the consistency between the digest value of the input file and the input digest value.

Format

check file-digest digest-algorithm { sha256 | md5 } digestValue fileName

Parameters

Parameter Description Value
sha256

Uses the SHA-256 digest algorithm to compare file digest values.

-
md5

Uses the MD5 algorithm to compare file digest values.

-
digestValue

This parameter specifies the digest value of the file to be verified.

The value is a string of 1 to 64 case-sensitive characters, spaces not supported.
fileName

Name of the file to be verified.

The value is a character string in the [ <drive> ][ <path> ][ <file-name> ] format. An absolute path name is a string of 1 to 255 characters. A relative path name is a string of 1 to 128 characters. Up to eight levels of directories are supported.

An absolute path name is in the [ <drive> ][ <path> ][ <file-name> ] format. A relative path name is in the [ <path> ][ <file-name> ] format. Relative paths can be relative to the root directory (current storage directory) or the current working directory. If a path starts with a slash (/), it is relative to the root directory.

Views

User view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

You can run this command to check whether the digest value of a file on the device is the same as the existing digest value.

A digest value, also called a hash value, is a unique character string consisting of short random letters and digits. It is used to verify file integrity and prevent files from being tampered with.

Precautions

This command cannot be used together with the file-digest digest-algorithm command. Only one user is allowed to run this command at a time.

Example

# Use the SHA256 algorithm to check whether the digest value of the flash:/test.txt file is the same as the specified digest value.
<HUAWEI> check file-digest digest-algorithm sha256 f2ca1bb6c7e907d06dafe4687e579fce76b37e4e93b7605022da52e6ccc26fd2 flash:/test.txt
Info: The system is executing the task...done.
Info: Verification completed. The digest value of flash:/test.txt is the same as the input digest value.
