reset bgp vpnv6 flap-info

Function

The reset bgp vpnv6 flap-info command clears statistics about BGP VPNv6 route flapping.

Format

reset bgp vpnv6 flap-info [ regexp regexpText | as-path-filter { as-path-filter-num | as-path-filter-name } | ipv6-address [ ipv6-mask-length ] ]

reset bgp vpnv6 peerIpv4Addr flap-info

Parameters

Parameter Description Value
regexp regexpText

Specifies the AS_Path regular expression.

The value is a string of 1 to 80 case-sensitive characters, spaces supported.
as-path-filter as-path-filter-name

Clears route flapping statistics based on a specified AS_Path filter.

The value is a string of 1 to 51 case-sensitive characters. If spaces are used, the string must start and end with double quotation marks (").
as-path-filter as-path-filter-num

Clears route flapping statistics based on a specified AS_Path filter.

The value is an integer ranging from 1 to 256.
ipv6-address

Specifies the network address of an IPv6 peer.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
ipv6-mask-length

Specifies the network mask length that is used to filter the BGP IPv6 routes. If neither of the mask nor mask length is specified, the address is considered as a classful address.

It is an integer ranging from 0 to 128.
peerIpv4Addr

Specifies the IPv4 address of a peer.

The value is in dotted decimal notation.

Views

User view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The process of adding a route to and then deleting the route from a routing table is called route flapping.

When route flapping occurs, a device sends an Update message to its peers. The devices that receive the Update message need to recalculate routes and modify routing tables. Frequent route flapping consumes lots of bandwidth and CPU resources and even seriously affects network operations.

To clear flapping statistics about BGP VPNv6 routes so that the device can re-collect them, run the reset bgp vpnv6 flap-info command. The command output helps you monitor route changes and locate network faults.

Prerequisites

You can run the display bgp vpnv6 all routing-table flap-info command to view statistics about BGP route flapping, including the specific flapping routes.

If there are a large number of flapping routes, define as-path-filter or regexp and then clear statistics about the matched flapping routes.

Configuration Impact

After the reset bgp vpnv6 flap-info command is run, the flapping statistics of routes are cleared and the previous statistics cannot be displayed.

Follow-up Procedure

After clearing the flapping statistics of BGP routes, you can run the display bgp vpnv6 all routing-table flap-info command again to view the flapping statistics of BGP routes. The statistics help locate faults.

Example

# Clear the flapping statistics about the routes that match AS_Path filter 10.
<HUAWEI> reset bgp vpnv6 flap-info as-path-filter 10
# Clear the flapping statistics of BGP VPNv6 routes.
<HUAWEI> reset bgp vpnv6 1.1.1.1 flap-info
