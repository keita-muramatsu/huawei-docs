color-policy

Function

The color-policy command creates a coloring policy.

The undo color-policy command restores the default coloring policy.

The color-policy based command configures a coloring policy based on other parameters.

The undo color-policy based command restores the default coloring policy based on other parameters.

By default, there is a policy for coloring connections based on the TNP with a smaller site ID.

Format

color-policy based-site-id { smaller | larger }

color-policy based { transport-network-priority { smaller | larger } | bandwidth { smaller | larger } | { hub | spoke } } *

undo color-policy based-site-id [ { smaller | larger } ]

undo color-policy based [ { transport-network-priority { smaller | larger } | bandwidth { smaller | larger } | { hub | spoke } } * ]

Parameters

Parameter Description Value
smaller

Configures a policy for coloring connections based on the TNP with a smaller site ID.

-
larger

Configures a policy for coloring connections based on the TNP with a larger site ID.

-
based

Configures a coloring rule.

-
transport-network-priority

Configures a policy for coloring connections based on transport network priorities.

-
bandwidth

Configures a policy for coloring connections based on bandwidth.

-
hub

Configures a policy for preferentially coloring connections of the hub site.

-
spoke

Prioritize non-hub.

-
based-site-id

Configures a policy for coloring connections based on site IDs.

-

Views

Site view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

During the creation of an EVPN connection, if the source and destination TNPs belong to different transport networks, you need to implement a coloring policy on the connection to determine the transport network attributes of the connection. To ensure that the coloring results of the EVPN connection created between two devices are the same, ensure that the coloring policy configurations on the entire network are the same.

Prerequisites

A site has been created using the evpn site command.

Precautions

When you run the color-policy based command, the parameters that are configured earlier take effect first.

Example

# Create a policy for coloring connections based on the TNP with a larger site ID at site 1.
<HUAWEI> system-view
[HUAWEI] evpn site 1
[HUAWEI-site-1] color-policy based-site-id larger
