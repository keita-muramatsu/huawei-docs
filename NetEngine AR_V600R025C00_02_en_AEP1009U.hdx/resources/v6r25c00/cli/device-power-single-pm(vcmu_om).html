device power single-pm input-power

Function

The device power single-pm input-power command sets the input power of a power module.

The undo device power single-pm input-power command restores the actual input power of a power module to the rated power of the power module.

By default, the actual input power of a power module is the rated power of the power module. After the main control board starts, you can run the display device power command to view the rated power of the power module.

This command is supported only on the AR8700 series and AR6700-H series.

Format

device power single-pm input-power power-value

undo device power single-pm input-power [ undo-power-value ]

Parameters

Parameter Description Value
input-power power-value

Specifies the input power to be configured for a power module.

The value is an integer that ranges from the minimum configurable power to the minimum rated power of a single PSU, in W.
input-power undo-power-value

Specifies the configured input power of a power module.

The value is an integer, in W. It specifies the manually configured input power of the current power module.

Views

System view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

By default, the power management module checks that power modules supply power to boards based on their rated power. When the maximum output power supplied by the power cabinet is less than the rated power of a power module, this power module may not supply sufficient power to boards. In this situation, the boards that are powered on may restart or power off. To resolve this problem, run this command to configure the input power of the power module and allow the power management module to check that power modules supply power to the boards based on their configured input power.

This command applies to the following scenarios:

  • A device is installed for the first time. If the maximum output power supplied by the power cabinet is less than the rated power of a power module, run this command to configure the input power of this power module after the main control board starts. Based on the rated power of each board, calculate the number of boards to which the configured input power can be allocated. Then install boards based on the calculation results.
  • Additional boards need to be installed on a device. If the maximum output power supplied by the power cabinet is less than the rated power of a power module, run this command to configure the input power of this power module. Based on the rated power of each board, calculate the number of boards to which the remaining part of the configured input power can be allocated. Then install boards based on the calculation results.

Configuration Impact

When the maximum output power supplied by the power cabinet is greater than or equal to the rated power of a power module, you do not need to run this command. If you have run this command, the power management module still checks that power modules supply power to boards based on their rated power.

When the maximum output power provided by the power cabinet is lower than the rated power required by the power module, you must run this command. After this command is run, the power management module checks that power modules supply power to boards based on the configured input power so that the boards work stably.

Follow-up Procedure

After running this command, you can run the display device power command to view the configured input power and the power-on status of the boards.

Precautions

The configured input power cannot be smaller than the sum of the rated maximum power consumption of the inserted boards.

Example

# Configure the input power of a power module.
<HUAWEI> system-view
[HUAWEI] device power single-pm input-power 1500
Warning: This command maybe result in the new insert boards can not power on. Continue? [Y/N]:y
