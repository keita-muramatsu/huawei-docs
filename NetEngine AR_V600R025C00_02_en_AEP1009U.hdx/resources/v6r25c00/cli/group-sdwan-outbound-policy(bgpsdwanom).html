peer route-policy export (BGP IPv4 SD-WAN address family view)(group)

Function

The peer route-policy export command applies a route-policy to filter routes to be advertised to peers in a peer group.

The undo peer route-policy export command cancels the application.

By default, no route-policy is specified for the routes to be advertised to a specified peer group.

Format

peer peerGroupName route-policy policy-name export

undo peer peerGroupName route-policy policy-name export

Parameters

Parameter Description Value
peerGroupName

Specifies the name of a peer group.

The value is a string of 1 to 47 case-sensitive characters. If spaces are used, the string must start and end with double quotation marks (").
policy-name

Specifies the name of a route-policy.

The value is a string of 1 to 200 case-sensitive characters and cannot contain spaces.

Views

BGP IPv4 SD-WAN address family view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After a route-policy is created, you can run the peer route-policy export command to apply the route-policy to peers in a specified peer group so that route advertisement to the peer group can be controlled. To be specific, only the desired routes will be advertised to peers in the peer group. In this manner, route management is implemented, the scale of the routing table is reduced, and fewer system resources are consumed.

Precautions

After the peer route-policy export command is run, only the routes that match the route-policy are advertised. Replacing or modifying the route-policy may cause a large number of routes to match the route-policy and be advertised.

If route-policy route-policy-nameis specified in this command, the following items can be matched: the AS_Path filter, AS_Path length, community filter, number of community attributes, route cost, VPN-Target extended community filter, IPv4 route next-hop address ACL, IPv6 route next-hop address ACL, IPv4 route next-hop address prefix list, IPv6 route next-hop address prefix list, route preference, routing protocol type, route type, and route tag. The following items can be set: the AS_Path attribute, BGP community attribute, BGP route MED, BGP route VPN-Target extended community attribute, BGP route color extended community attribute, BGP route local preference, BGP route origin, and BGP route PreVal.

If the referenced policy contains unsupported attribute matching or behavior setting, unexpected results may occur.

By default, an RR is disabled from modifying route attributes through an export policy. To enable the RR to modify route attributes through an export policy, run the reflect change-path-attribute command.

Example

# Apply a route-policy to routes to be advertised to peers in a peer group.
<HUAWEI> system-view
[HUAWEI] route-policy test-policy permit node 10
[HUAWEI-route-policy] quit
[HUAWEI] bgp 100
[HUAWEI-bgp] group test
[HUAWEI-bgp] ipv4-family sd-wan
[HUAWEI-bgp-af-ipv4-sdwan] peer test enable
[HUAWEI-bgp-af-ipv4-sdwan] peer test route-policy test-policy export
