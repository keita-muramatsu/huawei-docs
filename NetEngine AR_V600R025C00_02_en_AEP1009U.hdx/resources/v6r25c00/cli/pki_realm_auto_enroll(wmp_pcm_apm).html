pki realm auto-enroll

Function

The pki realm auto-enroll command configures the parameters for automatic AP certificate update, including the PKI entity common name, CA server URL and name, percentage of the certificate's validity period, and reference and secret values of the message authentication code.

The undo pki realm auto-enroll command restores the default parameter settings for automatic AP certificate update, including the PKI entity common name, CA server URL and name, percentage of the certificate's validity period, and reference and secret values of the message authentication code.

By default, automatic certificate update is not configured.

Format

pki realm realm-name auto-enroll common-name name

pki realm realm-name auto-enroll url url ca-id id

pki realm realm-name auto-enroll percent percent message-authentication-code reference-value secret-value

undo pki realm realm-name auto-enroll common-name

undo pki realm realm-name auto-enroll url

undo pki realm realm-name auto-enroll percent

Parameters

Parameter Description Value
common-name name

Specifies the common name of an entity.

The value is a string of 1 to 64 case-sensitive characters.
realm realm-name

Specifies the name of a PKI realm.

The value is a string of 1 to 50 case-sensitive characters.
url url

Specifies the URL of the CA server.

The value is a string of 1 to 128 case-sensitive characters.
ca-id id

Specifies the CA issuer ID.

The value is a string of 1 to 64 case-sensitive characters.
percent percent

Specifies the percentage of the certificate's validity period.

The value is an integer ranging from 10 to 100.
message-authentication-code reference-value

Specifies the reference value of the message authentication code.

The value is a string of 1 to 128 case-sensitive characters.
secret-value

Specifies the secret value of the message authentication code.

The value is a string of case-sensitive characters, question marks (?) not supported. The value is a string of 1 to 128 characters in plain text and a string of 128 to 268 characters in cipher text.

Views

AP PKI realm profile view

Default Level

2: Configuration level

Usage Guidelines

On an AC, you can configure automatic certificate update parameters for APs in a PKI realm. These parameters include the server information, validity period percentage, and reference and secret values of the message authentication code.

If no certificate is available in the realm, an AP automatically applies for a certificate from the server and updates the certificate automatically.

If a certificate exists in the realm, the certificate is automatically updated when the percentage of the certificate's validity period reaches the threshold.

Example

# Configure the parameters for automatic certificate update, including the PKI entity common name, CA server URL and name, percentage of the certificate's validity period, and reference and secret values of the message authentication code.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-pki-profile name default
[HUAWEI-wlan-ap-pki-prof-default] pki realm r1 auto-enroll common-name test
[HUAWEI-wlan-ap-pki-prof-default] pki realm r1 auto-enroll url https://10.3.0.1:80/certsrv/mscep ca-id ca_root
[HUAWEI-wlan-ap-pki-prof-default] pki realm r1 auto-enroll percent 50 message-authentication-code 1234 test
