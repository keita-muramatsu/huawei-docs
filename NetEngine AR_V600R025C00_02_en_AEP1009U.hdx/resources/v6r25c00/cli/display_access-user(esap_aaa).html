display access-user

Function

The display access-user command displays information about online users (including access users and administrators).

Format

display access-user [ domain domain-name | ip-address ip-address | interface [ interface-name | interface-type interface-number ] [ vlan vlan-id ] | access-slot slot-id ] [ detail ]

display access-user ipv6-address ipv6-address [ detail ]

display access-user access-type admin [ terminal | ftp | ssh | telnet | http ] [ username user-name ]

display access-user ip-address ip-address vpn-instance vpn-instance-name [ detail ]

display access-user option82 { remote-id remote-id-text | circuit-id circuit-id-text }

display access-user { wired | wireless } [ detail ]

Parameters

Parameter Description Value
domain domain-name

Displays information about users in a specified domain.

The value is a string of 1 to 64 case-sensitive characters. It cannot contain spaces.
ip-address ip-address

Displays information about the user with a specified IP address.

The value is in dotted decimal notation.
interface interface-type interface-number

Specifies the interface type and number.

-
interface-name

Specifies an interface name.

The value must be an existing interface name and is a string of 0 to 256 characters.
vlan vlan-id

Specifies a user VLAN.

The value is an integer ranging from 1 to 4094.
access-slot slot-id

Specifies a slot ID.

The value is an integer.
detail

Displays detailed information.

-
detail

Displays detailed information about a VPN instance.

-
ipv6-address ipv6-address

Displays information about the user with a specified IPv6 address.

The value is a 32-digit hexadecimal number, in the format of X:X:X:X:X:X:X:X.
access-type

Displays information about users using a specified authentication mode.

-
admin

Displays information about the administrators using the specified authentication mode.

-
terminal

Indicates terminal users.

-
ftp

Indicates FTP users.

-
ssh

Indicates SSH users.

-
telnet

Indicates Telnet users.

-
http

Indicates HTTP authentication users.

-
username user-name

Displays information about the user with a user name.

The value must be an existing user name and is case sensitive.
vpn-instance vpn-instance-name

Indicates the name of the VPN instance that the specified IP address belongs to.

The VPN instance must exist.
option82

-

Option 82.
remote-id remote-id-text

Displays information about MAC address authentication users with a specified remote ID as the user name.

The value is a string of 1 to 255 characters. It can contain spaces. The value must be existing remote-id information.
circuit-id circuit-id-text

Displays information about MAC address authentication users with the specified circuit ID as the user name.

The value is a string of 1 to 255 characters. It can contain spaces. The value must be existing circuit-id information.
wired

Displays information about wired users.

-
wireless

Displays wireless user information.

-

Views

All views

Default Level

3: Management level

Usage Guidelines

Usage Scenario

This command displays information about user sessions on the device.

Precautions

If the character string of the user name contains spaces (for example, a b), you can run the display access-user username "a b" command to view online user information.

If the character string of the user name contains both spaces and quotation marks (" ") you cannot use the user name to view online user information.

To view VPN user entries based on user IP addresses, specify the vpn-instance vpn-instance-name parameter to specify the VPN instance to which the IP addresses belong.

When interface is specified, the connection information of online wired users on the interface is displayed.
