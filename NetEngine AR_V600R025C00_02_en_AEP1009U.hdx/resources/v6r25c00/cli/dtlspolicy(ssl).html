dtls policy

Function

The dtls policy command creates a DTLS policy and displays the Datagram Transport Level Security (DTLS) policy view. If the DTLS policy to be created already exists, running this command presents you the view of the DTLS policy.

The undo dtls policy command deletes a DTLS policy.

By default, no DTLS policies are created.

Format

dtls policy policyName

undo dtls policy policyName

Parameters

Parameter Description Value
policyName

Specifies the name of a DTLS policy.

The value is a string of 1 to 23 case-insensitive characters, containing letters, digits, and underscores (_), spaces not supported.

Views

System view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

You can run this command to enter the DTLS policy view and configure DTLS services.

Precautions

  • A maximum of 128 DTLS policies can be configured.
  • The DTLS policy name cannot be the same as the SSL policy name.

Example

# Create a DTLS policy named policy1 and enter the view of the DTLS policy.
<HUAWEI> system-view
[HUAWEI] dtls policy policy1
