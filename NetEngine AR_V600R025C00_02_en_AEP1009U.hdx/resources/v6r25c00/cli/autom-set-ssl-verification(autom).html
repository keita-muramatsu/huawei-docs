ssl-verify-peer enable

Function

The ssl-verify-peer enable command enables the peer SSL verification mode for the net assistant function. In this mode, the master device verifies the SSL certificates of member devices.

The undo ssl-verify-peer command disables the peer SSL verification mode for the net assistant function. In this mode, the master device does not verify the SSL certificates of member devices.

By default, the net assistant function does not perform SSL verification on the peer end.

Format

ssl-verify-peer enable

undo ssl-verify-peer enable

Parameters

None

Views

Net-assistant system-management view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

After the HTTPS client is granted an SSL digital certificate by a server, the client can be configured through this command to verify the validity of the server. This prevents the client from accessing invalid servers, enhancing security. In the net assistant scenario, the master device functions as the client, and the member device functions as the server. When the peer verification mode takes effect, the master device verifies the validity of the SSL certificate of the member device.

Configuration Impact

After you run this command to enable the peer SSL verification mode for the net assistant function, the master device verifies the SSL certificates of member devices to authenticate the member devices. The master device uses the CA certificate in the PKI domain of the specified SSL policy to verify the local certificate sent by a member device, and then uses the obtained ESN of the member device to verify the CN field in the local certificate sent by the member device. In this way, the identity of the member device is authenticated.

Precautions

This command takes effect only after an SSL policy is configured using the ssl-policy command in the system management view of the net assistant view.

Example

# Configure the net assistant function to perform SSL verification on the server.
<HUAWEI> system-view
[HUAWEI] net-assistant
[HUAWEI-net-assistant] system-management
[HUAWEI-net-assistant-system-management] ssl-policy a
[HUAWEI-net-assistant-system-management] ssl-verify-peer enable
