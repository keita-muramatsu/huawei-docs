load-balance source-ip-based

Function

The load-balance source-ip-based command enables source IP address-based traffic steering in load balancing mode in a SaaS traffic steering policy.

The undo load-balance source-ip-based command disables source IP address-based traffic steering in load balancing mode in a SaaS traffic steering policy.

By default, 5-tuple-based traffic steering is used in load balancing mode, and source IP address-based traffic steering is disabled.

Format

load-balance source-ip-based

undo load-balance source-ip-based

Parameters

None

Views

saas-policy-node view

Default Level

2: Configuration level

Usage Guidelines

To use the local source IP address for traffic steering, run the load-balance source-ip-based command to enable source IP address-based traffic steering.

Example

# Enable source IP address-based traffic steering in load balancing mode.
<HUAWEI> system-view
[HUAWEI] saas-cloud-express
[HUAWEI-saas-cloud-express] saas-policy node 1
[HUAWEI-saas-cloud-express-saas-policy-node-1] load-balance source-ip-based
