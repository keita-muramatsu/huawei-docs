pki realm auto-enroll fingerprint

Function

The PKI realm auto-enroll fingerprint command configures the digital fingerprint used for CA certificate authentication.

The undo pki realm auto-enroll fingerprint command deletes the digital fingerprint used for CA certificate authentication.

By default, no digital CA certificate fingerprint used in CA certificate authentication is configured.

Format

pki realm realm-name auto-enroll fingerprint { md5 | sha1 | sha256 } fingerprint

undo pki realm realm-name auto-enroll fingerprint

Parameters

Parameter Description Value
realm-name

Specifies the name of a PKI realm.

The value is a string of 1 to 50 case-sensitive characters.
fingerprint

Specifies the digital fingerprint value.

This value needs to be obtained from the CA server offline. For example, from a CA server running Windows Server 2008, you can obtain the digital fingerprint at http://host:port/certsrv/mscep_admin/, in which host indicates the server's IP address and port indicates the port number.

The value is a string of 32, 40, or 64 case-sensitive characters, without spaces.
md5

Sets the digital fingerprint algorithm to MD5.

-
sha1

Sets the digital fingerprint algorithm to SHA1.

-
sha256

Sets the digital fingerprint algorithm to SHA256.

-

Views

AP PKI realm profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When obtaining a CA certificate, the device calculates the digital fingerprint of the CA certificate using an algorithm, and compares the calculated fingerprint with the local one. If the two values are the same, the device accepts the CA certificate. During certificate verification, the device uses the public key of the CA certificate to verify the digital signature. If the signature can be decrypted using the public key, the verification is successful.

Precautions

You can configure only one algorithm for the digital fingerprint. The new configuration overwrites the previous one.

The MD5 and SHA1 algorithms have a low security level. SHA256 is recommended.

Example

# Configure the digital CA certificate fingerprint used in CA certificate authentication.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-pki-profile name default
[HUAWEI-wlan-ap-pki-prof-default] pki realm r1 auto-enroll fingerprint sha256 e71add0744360e91186b828412d279e06dcc15a4ab4bb3d13842820396b526a0
