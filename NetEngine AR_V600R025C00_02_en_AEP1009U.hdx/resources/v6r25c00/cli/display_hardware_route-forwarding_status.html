display hardware route-forwarding status

Function

The display hardware route-forwarding status command displays the hardware-based routing and forwarding status.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

display hardware route-forwarding status

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

After the hardware-based routing and forwarding mode is configured, the software forwarding mode may be automatically switched.

Possible causes:

  1. Hardware route resources are insufficient.
  2. Configure value-added services.

    To check the status of the hardware-based routing and forwarding mode, run the display fe slot fe-id forward-mode command.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the hardware-based routing and forwarding status.
<HUAWEI> display hardware route-forwarding status
Config status: Enable
Effective status: Disable
# Display the hardware-based routing and forwarding status.
<HUAWEI> display hardware route-forwarding status
Config status: Enable
Effective status: Disable
Session service status: Enable
Hardware forward session num: 2
Table 1 Description of the display hardware route-forwarding status command output
Item Description
Config status

Hardware-based routing status configured using the command.
Effective status

Hardware-based routing status that actually takes effect.
Session service status

Session service status. If NAT is configured on the device, the value is Enable.
Hardware forward session num

Number of hardware-based forwarding sessions.
