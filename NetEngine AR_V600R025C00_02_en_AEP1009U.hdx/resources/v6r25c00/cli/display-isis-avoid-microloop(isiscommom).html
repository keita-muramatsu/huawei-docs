display isis avoid-microloop information

Function

The display isis avoid-microloop information command displays node microloop avoidance information.

Format

display isis [ process-id ] avoid-microloop information [ ipv6 ] [ level-1 | level-2 ] [ systemid systemid ]

Parameters

Parameter Description Value
process-id

Specifies the ID of a process whose microloop avoidance information is to be displayed.

If this parameter is not configured, microloop avoidance information of all processes is displayed.

The value is an integer ranging from 1 to 4294967295.
ipv6

Displays microloop avoidance information in IPv6 topology.

-
level-1

Displays microloop avoidance information on nodes in Level-1 areas.

-
level-2

Displays microloop avoidance information on nodes in Level-2 areas.

If no level is specified, microloop avoidance information of nodes in all areas is displayed.

-
systemid systemid

Specifies the system ID or pseudo node ID.

The value is a hexadecimal integer, in the format of XXXX.XXXX.XXXX.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

After SR microloop avoidance is configured, you can run the display isis avoid-microloop information command to view information about microloop avoidance on a node, including the microloop avoidance type, failure cause, entry time, exit time, microloop avoidance outbound interface, and microloop avoidance label stack.
