display security-policy rule

Function

The display security-policy rule command displays configuration information about all security policy rules, a specific security policy rule, or the security policy rules that match the security zone and 5-tuple filtering conditions. If 5-tuple filtering conditions are specified, only the address, address object, address group, ISP address set, protocol, service object, and service group configurations referenced in security policies can be filtered.

Format

display security-policy rule [ verbose ] { source-zone { source-zone-name | any } | destination-zone { destination-zone-name | any } | source { source-ipv4-address | source-ipv6-address | any } | destination { destination-ipv4-address | destination-ipv6-address | any } | protocol { { tcp | udp } [ source-port source-port | destination-port destination-port ] * | icmp | protocol-number | any } } *

display security-policy rule verbose match-ip { match-ipv4-address | match-ipv6-address }

display security-policy rule all [ include regular-expression | slot slot-id cpu cpu-id ]

display security-policy rule name rule-name

display security-policy rule verbose all

display security-policy rule name rule-name verbose

Parameters

Parameter Description Value
include regular-expression

Displays the configuration of the security policy that contains the string in a regular expression. The string is case-sensitive.

The value is a string of 1 to 128 case-sensitive characters and supports spaces.
slot slot-id

Specifies the slot ID.

The value is an integer ranging from 1 to 8.
cpu cpu-id

Specifies the ID of a CPU.

The value is an integer ranging from 1 to 8.
name rule-name

Specifies the name of a security policy rule.

The value is a string of 1 to 63 case-sensitive characters.
verbose

Indicate detailed information about the rule.

-
source-zone source-zone-name

Specifies the source zone of a security policy rule.

The value is a string of 1 to 32 case-sensitive characters, spaces supported.
any

Indicates any source security zone, destination security zone, source address, destination address, or protocol in a security policy rule.

-
destination-zone destination-zone-name

Specifies the destination zone of a security policy rule.

The value is a string of 1 to 32 case-sensitive characters, spaces supported.
source source-ipv4-address

Specifies the source IPv4 address configured in a security policy rule.

The value is in dotted decimal notation.
source source-ipv6-address

Specifies the source IPv6 address configured in a security policy rule.

The value is a 32-digit hexadecimal string in format X:X:X:X:X:X:X:X.
destination destination-ipv4-address

Specifies the destination IPv4 address configured in a security policy rule.

The value is in dotted decimal notation.
destination destination-ipv6-address

Specifies the destination IPv6 address configured in a security policy rule.

The value is a 32-digit hexadecimal string in format X:X:X:X:X:X:X:X.
protocol protocol-number

Specifies an IP-layer protocol number, except 1-ICMP, 6-TCP, and 17-UDP.

The value is an integer ranging from 0 to 255.
tcp

Indicates the TCP protocol.

-
udp

Indicates the UDP protocol.

-
source-port source-port

Specifies the source port configured in a security policy rule.

The value is an integer ranging from 1 to 65535.
destination-port destination-port

Specifies the destination port configured in a security policy rule.

The value is an integer ranging from 1 to 65535.
icmp

Indicates ICMP.

match-ipv4-address

Check the security policy that matches the IPv4 address.

match-ipv6-address

Check the security policy that matches the IPv6 address.

all

Indicates all security policy rules.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

  • The display security-policy rule command output displays rules in priority descending order, excluding default policies.
  • To filter security policies by IP address, run the display security-policy rule verbose match-ip { <match-ipv4-address> | <match-ipv6-address> } command.
  • You can enter an IPv4 or IPv6 address to query the security policies that can be matched by the source or destination address. Only the addresses, address objects, address groups, and ISP address sets referenced in security policies can be queried.
  • If either the source or destination address in the matching conditions of the matched security policy is not any, the security policy is directly displayed.
  • If both the source and destination addresses in the matching conditions of the matched security policy are any, the system queries the outbound interface of the route based on the IP address, obtains the security zone corresponding to the interface, and uses the security zone to match the security policy. If the security zone is matched, the security policy is displayed. If the security zone is not matched, the security policy is not displayed.

Example

The actual command output varies according to the device. The command output here is only an example.

<HUAWEI> display security-policy rule verbose match-ip 1.1.1.1
 (0 times matched)

  source-address 1.1.1.0 mask 255.255.255.0
  action permit

 (0 times matched)

  destination-address range 1.1.1.1 1.1.1.10
  action permit

 (0 times matched)
 rule name 3
  source-zone trust
  destination-zone untrust
  action permit
