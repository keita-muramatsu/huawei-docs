arp static

Function

The arp static command configures a static Address Resolution Protocol (ARP) entry.

The undo arp static command deletes a static ARP entry.

By default, no static ARP entry is configured.

Format

arp static ip-address mac-address

arp static ip-address mac-address vpn-instance vpn-instance-name

arp static ip-address mac-address { vlan vlan-id [ interface { interface-name | interface-type interface-number } ] | interface { interface-name | interface-type interface-number } }

arp static ip-address mac-address vlan vlan-id cevlan cevid interface { interface-name | interface-type interface-number }

undo arp static ip-address [ mac-address ]

undo arp static ip-address [ mac-address ] vpn-instance vpn-instance-name

undo arp static ip-address [ mac-address ] { vlan vlan-id [ interface { interface-name | interface-type interface-number } ] | interface { interface-name | interface-type interface-number } }

undo arp static vpn-instance vpn-instance-name

undo arp static all

undo arp static ip-address [ mac-address ] vlan vlan-id cevlan cevid interface { interface-name | interface-type interface-number }

Parameters

Parameter Description Value
ip-address

Specifies the IP address of a static ARP entry.

The value is in dotted decimal notation.
mac-address

Specifies the MAC address of a static ARP entry.

The value is in H-H-H format. H is a hexadecimal number that contains one to four digits, such as 00e0 and fc01. If an H contains fewer than four digits, the leftmost digits are padded with 0s. For example, two 0s are added to e0 to form 00e0.
vpn-instance vpn-instance-name

Specifies the VPN instance name of a static ARP entry.

The value is a string of 1 to 31 characters.
vlan vlan-id

Specifies the outer VLAN ID corresponding to a static ARP entry.

The value is an integer ranging from 1 to 4094.
interface interface-name

Specifies the name of the outbound interface of static ARP packets.

-
interface interface-type interface-number

Specifies the outbound interface of a static ARP packet.

cevlan cevid

Specifies the inner VLAN ID corresponding to a static ARP entry.

The value is an integer ranging from 1 to 4094.
all

Indicates that all static ARP entries are deleted.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

For security or management purposes, you need to manually specify the mapping between IP and MAC addresses. In this case, you can run this command to configure the fixed mapping between IP and MAC addresses in the ARP mapping entry.

The mapping between IP and MAC addresses in a static ARP entry is fixed. The mapping cannot be dynamically adjusted by a host and routing device. Static ARP entries remain valid when the routing device works normally.

You can configure static ARP entries in either of the following situations:

  • A gateway is enabled to forward packets with destination IP addresses not on the local network segment.
  • When you need to filter out some packets with invalid destination IP addresses, you can bind these invalid addresses to a nonexistent MAC address.

Configuration Impact

After a static ARP entry is configured, the ARP entry cannot be dynamically learned.

Precautions

  • The IP address specified by ip-address must be on the same network segment as the IP address of the outbound interface specified by interface.
  • When configuring static ARP on a QinQ or dot1q VLAN tag termination sub-interface, you must specify an outbound interface. Otherwise, traffic cannot be forwarded. In this case, the termination sub-interface does not learn the outbound interface of packets.

Example

# Configure a static ARP entry with the IP address 10.0.0.1 mapped to the MAC address aa-fcc-12.
<HUAWEI> system-view
[HUAWEI] arp static 10.0.0.1 00e0-fc12-3456
# Configure a static ARP entry with the IP address 1.1.1.1 mapped to the MAC address 00e0-fc12-3456, outer VLAN ID as 100, and inner VLAN ID as 200.
<HUAWEI> system-view
[HUAWEI] arp static 1.1.1.1 00e0-fc12-3456 vlan 100 cevlan 200 interface 10GE 0/0/1.1
