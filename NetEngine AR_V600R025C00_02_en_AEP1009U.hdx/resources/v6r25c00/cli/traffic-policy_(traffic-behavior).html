traffic-policy (traffic behavior view)

Function

The traffic-policy command binds a child traffic policy to a traffic behavior.

The undo traffic-policy command unbinds a child traffic policy from a traffic behavior.

By default, no child traffic policy is bound to a traffic behavior.

Format

traffic-policy policy-name

undo traffic-policy

Parameters

Parameter Description Value
policy-name

Specifies the name of a traffic policy.

The value is a string of 1 to 31 case-sensitive characters. It cannot contain spaces.

Views

Traffic behavior view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

A child traffic policy can be bound to a traffic behavior in a traffic policy. This simplifies the configuration of flow-based queue scheduling and traffic shaping.

Precautions

A child traffic policy configured in a traffic behavior of a parent traffic policy cannot be its own parent traffic policy.

Example

# Configure a child traffic policy in the traffic behavior view.
<HUAWEI> system-view
[HUAWEI] traffic policy tp-son
[HUAWEI-trafficpolicy-tp-son] quit
[HUAWEI] traffic behavior tb1
[HUAWEI-behavior-tb1] traffic-policy tp-son
