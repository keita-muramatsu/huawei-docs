suppression-period

Function

The suppression-period command configures the bandwidth suppression period of low-priority services for the intelligent traffic policing algorithm.

The undo suppression-period command deletes the bandwidth suppression period of low-priority services for the intelligent traffic policing algorithm.

By default, the bandwidth suppression period is 60 seconds.

Format

suppression-period period-value

undo suppression-period period-value

Parameters

Parameter Description Value
suppression-period period-value

Specifies the suppression period of low-priority services.

The value is an integer that ranges from 5 to 3600, in seconds.

Views

itp view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The intelligent traffic policing algorithm needs to suppress the bandwidth of low-priority services. The suppression period indicates that the bandwidth of low-priority services is continuously suppressed within this period to ensure the experience of high-priority services. This parameter is configurable. If this parameter is not configured, the default value of 60 seconds is used.

Prerequisites

You have entered the intelligent traffic policing view.

Precautions

If this parameter is not configured, the default value of this parameter is used by default when the intelligent traffic policing policy is applied. If this parameter is deleted when the intelligent traffic policing policy is applied to an interface, the default value of this parameter is restored, and the policy on the interface is executed again.

Example

# Set the bandwidth suppression period to 90 seconds.
<HUAWEI> system-view
[HUAWEI] itp policy p1
[HUAWEI-itp-p1] suppression-period 90
