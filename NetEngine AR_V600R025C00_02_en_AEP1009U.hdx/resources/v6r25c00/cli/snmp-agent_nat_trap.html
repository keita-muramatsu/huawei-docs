snmp-agent nat trap

Function

The snmp-agent nat trap command sets the threshold and statistics collection interval for port conflict alarms during NAPT.

The undo snmp-agent nat trap command restores the default threshold and statistics collection interval for port conflict alarms during NAPT.

By default, the value of interval is 5, in minutes.

By default, the value of threshold is 80, in percentage.

Format

snmp-agent nat trap { interval interval | threshold threshold }

undo snmp-agent nat trap [ interval | threshold ]

Parameters

Parameter Description Value
interval interval

Specifies the statistics collection interval.

The value is an integer ranging from 1 to 10080, in minutes. The default value is 5.
threshold threshold

Specifies the alarm threshold.

The value is an integer ranging from 1 to 100, in percentage. The default value is 80.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

This command only changes the threshold and statistics collection interval but cannot disable the function. During NAPT, if the ratio of the number of device port conflicts to the total number of port allocations is greater than or equal to the threshold, alarm NAT_1.3.6.1.4.1.2011.6.122.18.3.2.1 hwSecTrapNatOverThreshold is sent. If the ratio falls below the threshold, alarm NAT_1.3.6.1.4.1.2011.6.122.18.3.2.2 hwSecTrapNatBelowThreshold is sent. If the ratio is greater than or lower than the threshold for a long time, the device does not send alarms repeatedly.

Example

# Set the port conflict alarm threshold to 50.
<HUAWEI> system-view
[HUAWEI] snmp-agent nat trap threshold 50
