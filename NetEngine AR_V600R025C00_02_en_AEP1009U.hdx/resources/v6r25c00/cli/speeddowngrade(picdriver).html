speed downgrade enable

Function

The speed downgrade enable command enables rate decrease auto-negotiation on an interface.

The undo speed downgrade enable command disables rate decrease auto-negotiation on an interface.

By default, rate decrease auto-negotiation is disabled on an interface.

Format

speed downgrade enable

undo speed downgrade enable

Parameters

None

Views

Layer 2 10GE interface view, 10GE interface view, 25GE-L2 view, 25GE interface view, GE optical interface view, GE electrical interface view, Layer 2 multi-GE interface view, Multi-GE interface view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Assume that the network cables connected to the interfaces at both ends of a link support either 1000 Mbit/s or 100 Mbit/s. After you run this command to configure rate decrease auto-negotiation on the interfaces, they can decrease the negotiated rate to 1000 Mbit/s or 100 Mbit/s to ensure normal running even though they support a maximum rate of 2500 Mbit/s.

Prerequisites

The two interconnected interfaces work in auto-negotiation mode. If an interface works in non-auto-negotiation mode, run the undo negotiation disable command in the interface view to configure the interface to work in auto-negotiation mode.

Precautions

  • This command can be run only on electrical interfaces or optical interfaces that support copper modules and have them installed.
  • If the network cable is of poor quality, an interface will take a long time to go up after rate decrease auto-negotiation is configured for it. You are advised to replace the network cable.
  • After rate decrease auto-negotiation is configured for an interface, if the network cable is continuously removed and then inserted or the shutdown and undo shutdown commands are run repeatedly on the interface before the interface goes up, the interface's rate may automatically decrease. In this case, you can remove and then insert the network cable after the interface goes up, or run the shutdown and undo shutdown commands on the peer interface to restore the interface rate.

Example

# Enable rate decrease auto-negotiation on MultiGE1/0/1.
<HUAWEI> system-view
[HUAWEI] interface MultiGE1/0/1
[HUAWEI-MultiGE1/0/1] speed downgrade enable
