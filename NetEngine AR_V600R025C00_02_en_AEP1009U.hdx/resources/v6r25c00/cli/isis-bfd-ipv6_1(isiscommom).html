isis ipv6 bfd enable

Function

The isis ipv6 bfd enable command enables IPv6 BFD on an IS-IS interface to establish IPv6 BFD sessions using default parameter values.

The undo isis ipv6 bfd enable command disables IPv6 BFD from an IS-IS interface.

By default, IPv6 BFD is disabled.

Format

isis ipv6 bfd enable

undo isis ipv6 bfd enable

Parameters

None

Views

10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE sub-interface view, 40GE interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, Ethernet interface view, GE optical interface view, GE electrical interface view, IP-Trunk interface view, MP-group interface view, POS interface view, Tunnel interface view, VLANIF interface view, 10GE sub-interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

BFD can provide millisecond-level fault detection, help IS-IS to detect the faults that occur on neighboring devices or links more quickly, and instruct IS-IS to recalculate routes for correct packet forwarding. The isis ipv6 bfd enable command can be used to enable IPv6 BFD on an IS-IS interface to establish IPv6 BFD sessions using default parameters.

Prerequisites

BFD has been enabled globally, and an IS-IS process has been configured on a specified interface.

Configuration Impact

After the isis ipv6 bfd enable command is run on an interface, the interface is enabled to establish BFD sessions using default parameter values for fast link fault detection.

Precautions

If BFD is not enabled globally, you can set IPv6 BFD parameters on an interface, but the interface cannot establish an IPv6 BFD session.

The priority of IPv6 BFD configured on an interface is higher than that of IPv6 BFD configured in a process. If IPv6 BFD is enabled on an interface, IPv6 BFD sessions are established using the BFD parameters set on the interface.

If the isis ipv6 bfd block, isis ipv6 bfd enable, isis ipv6 bfd static, and isis ipv6 bfd track session-name commands are all run, only the last configured command takes effect.

Example

# Enable IPv6 BFD on 10GE0/0/7.
<HUAWEI> system-view
[HUAWEI] isis 1
[HUAWEI-isis-1] ipv6 enable
[HUAWEI-isis-1] quit
[HUAWEI] interface 10GE0/0/7
[HUAWEI-10GE0/0/7] undo portswitch
[HUAWEI-10GE0/0/7] ipv6 enable
[HUAWEI-10GE0/0/7] isis ipv6 enable 1
[HUAWEI-10GE0/0/7] isis ipv6 bfd enable
