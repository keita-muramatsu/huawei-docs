bgp yang-mode enable

Function

The bgp yang-mode enable command enables the YANG management mode for BGP VPN instances and BGP multi-instance VPN instances.

The undo bgp yang-mode enable command disables the YANG management mode for BGP VPN instances and BGP multi-instance VPN instances.

By default, the YANG management mode of BGP and BGP multi-instance VPN instances is disabled.

Format

bgp yang-mode enable

undo bgp yang-mode enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To configure and manage BGP private network instances and BGP multi-instance private network instances in huawei-bgp.yang, you need to enable the YANG-based management mode of the BGP private network instances on the device or globally enable the leaf node (/bgp:bgp/bgp:global/bgp:yang-enable) through the YANG model file.

Precautions

Running the bgp yang-mode enable command changes the configurations of BGP VPN instances and corresponding peers (and peer groups).

A command (command a for example) that supports the BGP-VPN instance view and the BGP-VPN instance IPv4 address family view can be run in either view before the bgp yang-mode enable command is run but can be run only in the former view after the bgp yang-mode enable command is run. If command a has been run in the BGP-VPN instance IPv4 address family view when the bgp yang-mode enable command is run, the configuration of command a will be automatically switched to the BGP-VPN instance view, which does not interrupt the network. However, if you roll back the configuration from the BGP-VPN instance view to the BGP-VPN instance IPv4 address family view, the configuration is deleted and then delivered, causing a network interruption. Therefore, exercise caution when using the configuration rollback function in this scenario. If the bgp yang-mode enable command configuration is removed, command a's configuration that has been automatically switched to the BGP-VPN instance view remains unchanged, and command a can be run in either view.

A command (command a for example) that supports the BGP-VPN instance view and the BGP-VPN instance IPv6 address family view can be run in either view before the bgp yang-mode enable command is run but can be run only in the former view after the bgp yang-mode enable command is run. If command a has been run in the BGP-VPN instance IPv6 address family view when the bgp yang-mode enable command is run, the configuration of command a will be automatically switched to the BGP-VPN instance view, which does not interrupt the network. However, if you roll back the configuration from the BGP-VPN instance view to the BGP-VPN instance IPv6 address family view, the configuration is deleted and then delivered, causing a network interruption. Therefore, exercise caution when using the configuration rollback function in this scenario. If the bgp yang-mode enable command configuration is removed, command a's configuration that has been automatically switched to the BGP-VPN instance view remains unchanged, and command a can be run in either view.

If the bgp yang-mode enable command is run, the as-number command configurations in the BGP-VPN instance IPv4 address family view and BGP-VPN instance IPv6 address family view are converted into the as-number ipv4 and as-number ipv6 command configurations in the BGP-VPN instance view.

If the BGP-VPN instance IPv4 address family view and BGP-VPN instance IPv6 address family view of the same VPN instance have the same peer group name, running the bgp yang-mode enable command renames the peer group in the BGP-VPN instance IPv6 address family view.

Example

# Enable the YANG management mode of BGP.
<HUAWEI> system-view
[HUAWEI] bgp yang-mode enable
Warning: All the configurations of the BGP VPN instance and its peers and peer groups will be changed to configurations that can be delivered using the YANG model. Continue? [Y/N]:Y
[HUAWEI]
