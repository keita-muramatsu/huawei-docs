wmi-server (AP system profile view)

Function

The wmi-server command binds a WMI profile to an AP system profile.

The undo wmi-server command unbinds a WMI profile from an AP system profile.

By default, no WMI profile is bound to an AP system profile.

Format

wmi-server profile-name index index

undo wmi-server index index

Parameters

Parameter Description Value
profile-name

Specifies the name of a WMI profile.

The value is a string of 1 to 35 case-sensitive characters without spaces.
index index

Specifies an index.

The value is 1 or 2.

To report KPI information to iMaster NCE-Campus, specify index 1. To report KPI information to iMaster NCE-CampusInsight, specify index 2.

Views

AP system profile view

Default Level

2: Configuration level

Usage Guidelines

After the configuration in a WMI profile is complete, bind the WMI profile to an AP system profile to make the configuration take effect.

Do not reference two WMI profiles with the same destination address and port number at the same time to avoid waste of destination server resources.

Example

# Bind the WMI profile abc to the AP system profile.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name apsys
[HUAWEI-wlan-ap-system-prof-apsys] wmi-server abc index 1
