dot11r enable

Function

The dot11r enable command enables 802.11r.

The undo dot11r enable command disables 802.11r.

By default, the 802.11r function is disabled.

Format

dot11r enable [ over-the-ds ]

undo dot11r enable

Parameters

Parameter Description Value
over-the-ds

Enables 802.11r roaming in over-the-DS mode. If this parameter is not specified, 802.11r roaming in over-the-air mode is enabled.

-

Views

SSID profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

During roaming, STAs need to be re-authenticated or negotiate keys. Therefore, services are interrupted for a short period of time. You can enable 802.11r to reduce the number of information exchanges during STA roaming, reducing the delay.

Precautions

  • Security policies supported by 802.11r include open system, WPA2+PSK+AES, WPA2+PPSK+AES, WPA2+802.1X+AES, WPA2-WPA3+802.1X+AES, WPA2-WPA3+PSK-SAE, WPA3+802.1X+AES, and WPA3+SAE.
  • Over-the-DS 802.11r roaming across WACs is not supported.
  • When 802.1X authentication is used for 802.11r, enabling 802.1X reauthentication may cause some STAs to go offline and online again during reauthentication due to compatibility issues.
  • Some STAs may be incompatible with the 802.11r roaming function, and fail to roam. It is not recommended that the 802.11r roaming function be enabled.

Example

# Enable 802.11r.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ssid-profile name ssid1
[HUAWEI-wlan-ssid-prof-ssid1] dot11r enable
