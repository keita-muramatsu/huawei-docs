web-auth-server version

Function

The web-auth-server version command sets the Portal protocol version supported by the device.

The undo web-auth-server version command restores the default configuration.

By default, the device supports V1, V2, and V3.

Format

web-auth-server version v3 [ v2 [ v1 ] ]

undo web-auth-server version

Parameters

Parameter Description Value
v2

Indicates that Portal V2.0 is supported. Currently, V2.0 is mainly used.

-
v1

Indicates that Portal V1.0 is supported.

-
v3

Indicates that Portal V3.0 is supported.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Currently, the Portal protocol has three versions: V1, V2, and V3. When the device exchanges information with the Portal server, ensure that the device and Portal server use the same Portal protocol version to ensure normal communication. You can run this command to configure the Portal protocol version supported by the device.

Note:

Currently, the common Portal protocol version is V2.

To ensure normal communication, you are advised to use the default configuration of the device. That is, the device supports all the three versions.

Before using V3 for interconnection, ensure that the Portal server vendor supports Portal V3. Otherwise, the interconnection fails. For details about the differences between Portal V3 and other versions, see Portal protocol standards.

Example

# Configure the device to support only Portal V3.
<HUAWEI> system-view
[HUAWEI] web-auth-server version v3
