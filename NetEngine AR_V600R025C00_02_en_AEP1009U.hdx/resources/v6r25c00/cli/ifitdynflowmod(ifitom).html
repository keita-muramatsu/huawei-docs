dynamic flow

Function

The dynamic flow command configures dynamic IFIT flow learning.

The reset dynamic flow command clears the learned IFIT dynamic flow.

Format

dynamic flow source src-ip-address [ src-mask-length ] destination dest-ip-address [ dest-mask-length ] vpn-instance vpn-name interface { ifType ifNum | ifName } { protocol { { tcp | udp | protocol-tcp | protocol-udp } [ source-port src-port-number ] [ destination-port dest-port-number ] | { protocol-number | protocol-number2 | protocol-number3 } } } { measure-mode { e2e | trace } | delay-measure { enable | disable } | interval interval-value | { loss-measure-enable | loss-measure-disable } } *

reset dynamic flow source src-ip-address [ src-mask-length ] destination dest-ip-address [ dest-mask-length ] vpn-instance vpn-name interface { ifType ifNum | ifName } { protocol { { tcp | udp | protocol-tcp | protocol-udp } [ source-port src-port-number ] [ destination-port dest-port-number ] | { protocol-number | protocol-number2 | protocol-number3 } } }

dynamic flow source-ipv6 src-ipv6-address [ src6-mask-length ] destination-ipv6 dest-ipv6-address [ dest6-mask-length ] vpn-instance vpn-name interface { ifType ifNum | ifName } { protocol { { tcp | udp | protocol-tcp | protocol-udp } [ source-port src-port-number ] [ destination-port dest-port-number ] | { protocol-number | protocol-number2 | protocol-number3 } } } { measure-mode { e2e | trace } | delay-measure { enable | disable } | interval interval-value | { loss-measure-enable | loss-measure-disable } } *

reset dynamic flow source-ipv6 src-ipv6-address [ src6-mask-length ] destination-ipv6 dest-ipv6-address [ dest6-mask-length ] vpn-instance vpn-name interface { ifType ifNum | ifName } [ protocol { { tcp | udp | protocol-tcp | protocol-udp } [ source-port src-port-number ] [ destination-port dest-port-number ] | { protocol-number | protocol-number2 | protocol-number3 } } ]

Parameters

Parameter Description Value
src-mask-length

Specifies a subnet mask length for a source IPv4 address.

The value is an integer that ranges from 1 to 32.
destination dest-ip-address

Specifies a destination IPv4 address.

The value is in dotted decimal notation.
dest-mask-length

Specifies a subnet mask length for a destination IPv4 address.

The value is an integer that ranges from 1 to 32.
vpn-instance vpn-name

Specifies the name of a VPN instance.

The value is a string of 1 to 31 case-sensitive characters without spaces. The VPN instance name cannot be _public_. If the character string is quoted by double quotation marks, the character string can contain spaces.
interface ifType ifNum

Specifies an interface.

The value is a string of 1 to 63 case-sensitive characters. It cannot contain spaces.
protocol

Specifies a protocol type.
  • tcp: TCP protocol
  • udp: UDP protocol
protocol-tcp

Indicates that the protocol type of the target flow is TCP.

The value is 6.
protocol-udp

Specifies a UDP number for a target flow.

The value is 17.
source-port src-port-number

Specifies the source port.

The value is an integer ranging from 1 to 65535.
destination-port dest-port-number

Specifies the destination port number.

The value is an integer ranging from 1 to 65535.
protocol-number

Specifies a port number.

The value is an integer ranging from 0 to 5.
protocol-number2

Specifies a port number.

The value is an integer ranging from 18 to 254.
protocol-number3

Specifies a port number.

The value is an integer ranging from 7 to 16.
measure-mode

Specifies the measurement mode.

  • e2e: specifies end-to-end measurement.
  • trace: specifies hop-by-hop measurement.

-
delay-measure

Enables or disables delay measurement.

  • enable: The function is enabled.
  • disable: The function is disabled.

-
interval interval-value

Specifies an interval.

The value is an integer that can be 10, 30, 60, or 300, in seconds. The default value is 30.
loss-measure-enable

Enables packet loss measurement.

-
loss-measure-disable

Disables packet loss measurement.

-
source src-ip-address

Specifies a source IPv4 address.

The value is in dotted decimal notation.
source-ipv6 src-ipv6-address

Indicates source IPv6 address.

The value is a 32-digit hexadecimal number in the format X:X:X:X:X:X:X:X.
src6-mask-length

Specifies a subnet mask length for a source IPv6 address.

The value is an integer ranging from 1 to 128.
destination-ipv6 dest-ipv6-address

Indicates destination IPv6 address.

The value is a 32-digit hexadecimal number in the format X:X:X:X:X:X:X:X.
dest6-mask-length

Specifies a subnet mask length for a destination IPv6 address.

The value is an integer ranging from 1 to 128.

Views

IFIT view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Dynamic IFIT flows are generated when traffic carrying the IFIT header is received. The ingress can automatically learn dynamic IFIT flows. In this case, you can run the dynamic flow command to modify the parameters of learned dynamic IFIT flows. If the learned dynamic IFIT flows are no longer needed, you can run the reset dynamic flow command to clear the dynamic IFIT flows.

Prerequisites

The VPN instance address family has been configured, the interface has been bound to the VPN instance, and dynamic flows have been created.

Example

# Modify the parameters of learned dynamic IFIT flows.
<HUAWEI> system-view
[HUAWEI] ifit
[HUAWEI-ifit] dynamic flow source 10.1.1.1 destination 10.2.2.2 vpn-instance vpn1 interface 10GE 0/0/0 protocol tcp source-port 10 destination-port 20 interval 10
