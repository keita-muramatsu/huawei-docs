avoid-microloop frr-protected

Function

The avoid-microloop frr-protected command enables IS-IS anti-microloop.

The undo avoid-microloop frr-protected command disables IS-IS anti-microloop.

By default, IS-IS anti-microloop is disabled.

Format

avoid-microloop frr-protected

undo avoid-microloop frr-protected

Parameters

None

Views

IS-IS view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After IS-IS TI-LFA FRR is enabled, if the primary link fails, traffic is switched to the backup link. When routes converge again, traffic is switched from the backup link to the new primary link. During the switchover to the new primary link, a loop may occur on the network and lasts for a short period of time. To prevent this problem, run the avoid-microloop frr-protected command to enable IS-IS microloop avoidance. This function delays switching to the new primary next hop, preventing loops.

Prerequisites

You have created an IS-IS process and entered the IS-IS view using the isis command.

Precautions

This command can be used in both IPv4 and IPv6 scenarios.

Example

# Enable IS-IS anti-microloop.
<HUAWEI> system-view
[HUAWEI] isis
[HUAWEI-isis-1] avoid-microloop frr-protected
