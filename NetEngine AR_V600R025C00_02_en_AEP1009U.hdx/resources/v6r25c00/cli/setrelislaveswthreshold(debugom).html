memory-usage reliability slave-switch-over

Function

The memory-usage reliability slave-switch-over command sets the memory usage threshold of the standby main control board for a preferential active/standby switchover.

The undo memory-usage reliability slave-switch-over command restores the default memory usage threshold of the standby main control board for a preferential active/standby switchover.

By default, the memory usage threshold of the standby main control board for a preferential active/standby switchover is 70.

This command is supported only on the AR8700 series and AR6700-H series.

Format

memory-usage reliability slave-switch-over threshold threshold-value

undo memory-usage reliability slave-switch-over [ threshold threshold-value ]

Parameters

Parameter Description Value
threshold threshold-value

Specifies the memory usage threshold.

The value is an integer ranging from 50 to 100.

Views

System view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

When the memory usage of the active main control board reaches the exception threshold for memory usage reliability, the system checks the memory usage of the standby main control board and whether the standby main control board has been running for more than one day (based on the registration time of the standby main control board).

  • If the standby main control board has been running for more than one day and the memory usage of the standby main control board is lower than the threshold configured using this command, the active main control board is reset to trigger an active/standby switchover. The reset code 0x01010135 is displayed.
  • If the standby main control board has been running for less than one day or the memory usage of the standby main control board is higher than or equal to the threshold configured using this command, the active main control board starts the independent process reset process to restart the process with the highest memory usage. Only processes with the independent process reset capability can be reset independently.

Example

# Set the memory usage threshold of the standby main control board for a preferential active/standby switchover to 60.
<HUAWEI> system-view
[HUAWEI] memory-usage reliability slave-switch-over threshold 60
