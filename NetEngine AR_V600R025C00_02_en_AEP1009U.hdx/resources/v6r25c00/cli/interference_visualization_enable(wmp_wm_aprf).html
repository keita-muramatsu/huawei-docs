interference-visualization enable

Function

The interference-visualization enable command enables interference visualization on AP radios.

The undo interference-visualization enable command disables interference visualization on AP radios.

By default, interference visualization is disabled on AP radios.

Format

interference-visualization enable

undo interference-visualization enable

Parameters

None

Views

AP radio view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When an AP is connected to an analyzer, you can enable interference visualization on radios of co-channel APs so that packet transmission information on the co-channel APs can be displayed on the analyzer, thereby showing air interface interference behavior.

Prerequisites

KPI reporting has been configured, and the ap log module mid ffdc0000 command has been configured in the WMI profile view to report logs of the module to the analyzer.

Precautions

  • Interference visualization can be enabled on a maximum of 20 AP radios. To view information about all AP radios enabled with interference visualization, run the display interference-visualization configuration command.
  • This function is supported only by some AP models. You can visit Info-Finder, search for the target AP model, and search for interference visualization in Specifications Query to check whether the AP supports this function.

Example

# Enable interference visualization on radio 1 of AP 1.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-id 1
[HUAWEI-wlan-ap-1] radio 1
[HUAWEI-wlan-ap-1-radio-1] interference-visualization enable
