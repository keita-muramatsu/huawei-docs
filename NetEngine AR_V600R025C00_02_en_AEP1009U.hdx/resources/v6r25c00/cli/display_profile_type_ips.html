display profile type ips

Function

The display profile type ips command displays the configuration of an IPS profile.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

display profile type ips [ name name [ signature-set-name signature-set-name | exception-signature-id exception-signature-id ] ]

Parameters

Parameter Description Value
name name

Displays the information about the specified IPS profile.

The value is a string of case-sensitive characters. The value contains 1 to 32 characters. If the name contains spaces, enclose the name with double quotation marks, for example, "user for test". The name cannot contain question marks (?), commas (,), double quotation marks ("), or hyphens (-).

The configuration file must exist.
signature-set-name signature-set-name

Specifies the name of a signature filter.

The value is a string of case-sensitive characters. The value contains 1 to 32 characters. If the name contains spaces, enclose the name with double quotation marks, for example, "user for test". The name cannot contain question marks (?), commas (,), double quotation marks ("), or hyphens (-).

The signature filter must exist.
exception-signature-id exception-signature-id

Specifies the ID of an exception signature.

The value is an integer ranging from 1 to 16777215.

The value must be the ID of an existing exception signature.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

The device has multiple default security profiles for different application scenarios. The default security profiles can be displayed, cloned, or referenced in security policies, but cannot be modified or deleted.
