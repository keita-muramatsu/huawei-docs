net-assistant enable

Function

The net-assistant enable command enables the net assistant function.

The undo net-assistant enable command disables the net assistant function.

By default, the net assistant function is disabled.

Format

net-assistant enable

undo net-assistant enable

Parameters

None

Views

Net-assistant view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

To use the net assistant function, run this command to enable the function.

Precautions

  • After the ual role controller command is run and the master device is elected, the device that is elected as the master device triggers the net-assistant enable command to enable the net assistant function. The net-assistant enable command cannot be delivered on a non-master device.
  • After the undo ual role controller command is run to cancel the master role, the undo net-assistant enable command is triggered to disable the net assistant function. If the master role is not canceled, the undo net-assistant enable command cannot be delivered.
  • After the net assistant function is enabled, this command can be delivered repeatedly without affecting the function.
  • After the net assistant function is disabled, other configurations in the net assistant view are not deleted.

Example

# Enable the net assistant function.
<HUAWEI> system-view
[HUAWEI] ual role controller
[HUAWEI] net-assistant
[HUAWEI-net-assistant] net-assistant enable
