http ssl-policy

Function

The http ssl-policy command binds an SSL policy to smart upgrade.

The undo http ssl-policy command unbinds an SSL policy from smart upgrade.

By default, no SSL policy is bound to smart upgrade.

Format

http ssl-policy policy-name

undo http ssl-policy

Parameters

Parameter Description Value
policy-name

SSL policy name.

The value is a string of 1 to 23 case-insensitive characters, spaces not supported.

Views

Smart upgrade view

Default Level

3: Management level

Usage Guidelines

In smart upgrade, you need to run the http ssl-http command to bind an SSL policy. A device where smart upgrade is to be enabled is connected to the HOUP through HTTPS. Therefore, an SSL policy must be bound to smart upgrade for the device to establish an HTTPS connection with the HOUP before smart upgrade is enabled on the device.

Example

# Bind the SSL policy abc.
<HUAWEI> system-view
[HUAWEI] smart-upgrade
[HUAWEI-smart-upgrade] http ssl-policy abc
