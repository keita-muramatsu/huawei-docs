firewall log session nat enable

Function

The firewall log session nat enable command enables the function of sending logs only for NAT sessions.

The undo firewall log session nat enable command disables the function of sending logs only for NAT sessions.

By default, the device is disabled from sending logs only for NAT sessions.

Format

firewall log session nat enable

undo firewall log session nat enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

When sending session logs, the device sends logs only for IPv4 sessions on which NAT has been performed.

Example

# Enable the global session logging function and the function of sending NAT session logs. 
<HUAWEI> system-view
[HUAWEI] firewall log session nat enable
