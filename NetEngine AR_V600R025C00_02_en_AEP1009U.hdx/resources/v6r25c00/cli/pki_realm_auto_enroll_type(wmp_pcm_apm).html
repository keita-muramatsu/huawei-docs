pki realm auto-enroll type

Function

The pki realm auto-enroll type command configures the protocol type used for automatic AP certificate enrollment.

The undo pki realm auto-enroll type command restores the default protocol type used for automatic AP certificate enrollment.

By default, the CMPv2 protocol is used to automatically renew AP certificates.

Format

pki realm realm-name auto-enroll type { cmpv2 | scep }

undo pki realm realm-name auto-enroll type

Parameters

Parameter Description Value
realm-name

Specifies the name of a PKI realm.

The value is a string of 1 to 50 case-sensitive characters.
cmpv2

Indicates the CMPv2 protocol.

-
scep

Indicates the SCEP protocol.

-

Views

AP PKI realm profile view

Default Level

2: Configuration level

Usage Guidelines

This command configures the protocol that the AC uses to automatically renew the AP certificate in a PKI realm. If SCEP is used, an AP downloads the CA certificate from the CA server using SCEP. If CMPv2 is used, an AP downloads the CA certificate from the CMPv2 server using CMPv2.

Example

# Configure SCEP for automatic certificate enrollment.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-pki-profile name default
[HUAWEI-wlan-ap-pki-prof-default] pki realm r1 auto-enroll type scep
