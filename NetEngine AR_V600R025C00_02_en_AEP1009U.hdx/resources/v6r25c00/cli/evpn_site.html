evpn site

Function

The evpn site command creates a site and displays the site view.

The undo evpn site command deletes a created site.

By default, no site view is created on the device.

Format

evpn site site-id [ site-type { cpe | rr | rr-cpe } ]

undo evpn site site-id [ site-type { cpe | rr | rr-cpe } ]

Parameters

Parameter Description Value
site-id

Specifies a site ID.

The value is an integer from 1 to 65535.
site-type

Specifies a site type, which defaults to CPE.

-
cpe

Specifies a CPE site.

-
rr

Specifies an RR site.

-
rr-cpe

Specifies an RR-CPE site.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Site types are RR, CPE, and RR-CPE. A CPE site is a common user network access device. It registers with an RR and is managed by the RR. An RR site reflects bottom-layer transport network information and routing information between CPEs. An RR-CPE site provides both the CPE and RR functions.

Configuration Impact

The mode in which EVPN connections are established varies according to the site type.

Follow-up Procedure

  • Run the system-id command to configure a system ID for the site.
  • Run the gateway command to configure a single gateway or dual gateways for the site.

Precautions

Ensure that the local site IDs configured for devices on the EVPN network are different. Otherwise, network disconnections will occur.

Example

# Create a local site with site ID 3 and site type RR.
<HUAWEI> system-view
[HUAWEI] evpn site 3 site-type RR
