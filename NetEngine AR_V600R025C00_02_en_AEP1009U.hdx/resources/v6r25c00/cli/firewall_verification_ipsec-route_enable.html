firewall verification ipsec-route enable

Function

The firewall verification ipsec-route enable command enables IPsec route verification.

The undo firewall verification ipsec-route enable command disables IPsec route verification.

By default, IPsec route verification is enabled.

Format

firewall verification ipsec-route enable

undo firewall verification ipsec-route enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

IPsec route verification takes effect only for the following IPsec types:

  • ISAKMP IPsec policies
  • Template IPsec policies

    When the IPsec route injection function is enabled and routes are added or deleted in batches, routes between different processes or between processes and the database may be inconsistent, affecting IPsec services. The IPsec route verification function can be enabled to prevent route inconsistency.

Example

# Enable IPsec OPR route verification.
<HUAWEI> system-view
[HUAWEI] firewall verification ipsec-route enable
