ipsec sa global-soft-duration

Function

The ipsec sa global-soft-duration buffer command sets the global soft timeout buffer time or traffic volume for an IPsec SA.

The undo ipsec sa global-soft-duration buffer command deletes the global soft timeout buffer time or traffic volume of an IPsec SA.

By default, the global soft timeout buffer time or traffic volume is not configured for an IPsec SA.

Format

ipsec sa global-soft-duration { time-based buffer seconds | traffic-based buffer kilobytes }

undo ipsec sa global-soft-duration { time-based | traffic-based } buffer

Parameters

Parameter Description Value
time-based

Indicates the soft timeout buffer time.

-
buffer seconds

Specifies the global time-based soft timeout buffer for an IPsec SA.

The value is an integer that ranges from 10s to 36000s.
buffer kilobytes

Specifies the global traffic-based soft timeout buffer for an IPsec SA.

The value is an integer that ranges from 7200 to 4187103 KB.
traffic-based

Indicates the soft timeout buffer traffic.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Before the hard lifetime expires, a new IPsec SA is negotiated to replace the old one. The period from the time the old IPsec SA is established to the time the new IPsec SA is negotiated is the soft lifetime. The administrator can configure the soft timeout buffer time or soft timeout buffer traffic to adjust the time for IPsec SA renegotiation. The values of soft timeout and soft timeout traffic are as follows:

  • After the soft timeout cache time is configured, if the difference between the hard timeout and soft timeout cache time is greater than 10s, the system uses the difference between the hard timeout and soft timeout cache time plus a random number as the soft timeout. Otherwise, the system uses the default value as the soft timeout.
  • After the soft timeout cache traffic is configured, if the hard timeout value minus the soft timeout cache traffic is greater than 7200 KB, the system uses the difference between the hard timeout traffic and soft timeout cache traffic as the soft timeout traffic. Otherwise, the system uses the default value as the soft timeout traffic.

    The soft timeout buffer time and traffic of an IPsec SA can be configured globally or in an IPsec policy. The global configuration takes effect for all IPsec policies, whereas the configuration in an IPsec policy takes effect only for the specified IPsec policy.

Precautions

If the soft timeout buffer time or traffic of an IPsec SA is configured globally and in an IPsec policy, the soft timeout buffer time or traffic configured in the IPsec policy is valid.

During IKEv1 negotiation:

  • The responder cannot initiate IPsec SA renegotiation after the IPsec SA soft lifetime expires.
  • The initiator cannot initiate IPsec SA renegotiation when its IKE SA is deleted and the IPsec SA soft lifetime expires.

    During IKEv2 negotiation:
  • If the responder runs the ike negotiate compatible command in the IKE peer view, it cannot initiate IPsec SA renegotiation after the IPsec SA soft lifetime expires.
  • If the responder runs the encapsulation-mode auto command in the IPsec proposal view, it cannot initiate IPsec SA renegotiation after the IPsec SA soft lifetime expires.
  • The initiator or responder cannot initiate IPsec SA renegotiation when the IKE SA is deleted and the IPsec SA soft lifetime expires.

Example

# Set the global soft timeout for the IPsec SA to 10000 KB on the device that serves as one end of the IPsec VPN tunnel. 
<HUAWEI> system-view
[HUAWEI] ipsec sa global-soft-duration traffic-based buffer 10000
# Set the global soft timeout buffer time for the IPsec SA to 600s on the device, which serves as one end of the IPsec VPN tunnel. 
<HUAWEI> system-view
[HUAWEI] ipsec sa global-soft-duration time-based buffer 600
