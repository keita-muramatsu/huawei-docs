engine action-mode warning

Function

The engine action-mode warning command sets the global threat handling action of the ASE to alert.

By default, no global threat handling action is configured for the ASE. Threat handling actions are configured by each service function.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

engine action-mode warning

undo engine action-mode warning

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

After the engine action-mode warning command is run, the global threat handling action of the ASE is set to alert. In this case, even if the content security service detects a threat in the service traffic, the service traffic cannot be blocked and only related logs are generated.

Example

# Set the ASE threat handling action to alert.
<HUAWEI> system-view
[HUAWEI] engine action-mode warning
