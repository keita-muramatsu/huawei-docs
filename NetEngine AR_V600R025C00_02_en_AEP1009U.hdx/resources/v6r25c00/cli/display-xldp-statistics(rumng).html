display xldp statistics

Function

The display xldp statistics command displays statistics about XLDP packets sent and received by a device.

Format

display xldp statistics [ interface { interface-name | interface-type interface-number } ]

Parameters

Parameter Description Value
interface interface-name | interface-type interface-number

Specifies the type and number of the interface that sends and receives XLDP packets.

  • interface-type specifies the interface type.
  • interface-number specifies the interface number.

If no interface is specified, statistics about XLDP packets on all interfaces are displayed.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To display the XLDP packet statistics within a specified period of time, you need to run the reset xldp statistics command to clear the existing statistics first, and then run the display xldp statistics command to view new statistics.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display statistics about XLDP packets sent and received by all interfaces.
<HUAWEI> display xldp statistics
Statistics for GE0/0/1: 
Transmitted frames total      : 27664 
  Hello frames                : 27664 
  Channel frames              : 0 
Received frames total         : 0 
  Hello frames                : 0 
  Channel ACK frames          : 0
Table 1 Description of the display xldp statistics command output
Item Description
Statistics for x

Statistics about XLDP packets sent and received by interface x.
Transmitted frames total

Number of sent XLDP packets.
Hello frames

Number of heartbeat packets.
Channel frames

Indicates the number of packets in a channel.
Channel ACK frames

Number of ACK packets in a channel.
Received frames total

Number of received XLDP packets.
