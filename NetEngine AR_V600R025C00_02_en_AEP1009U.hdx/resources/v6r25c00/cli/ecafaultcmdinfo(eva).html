display eva fault

Function

The display eva fault command displays running information about fault modes managed by EVA.

Format

display eva fault [ unrecovered | recovered ] [ faultMode ] [ beginTime endTime ]

display eva fault [ unrecovered | recovered ] [ faultMode ] [ beginTime endTime ] verbose

Parameters

Parameter Description Value
unrecovered

Indicates the information about unresolved faults.

-
recovered

Indicates the information about resolved faults.

-
faultMode

Indicates the name of a fault mode.

The value is a string of 1 to 63 case-insensitive characters.
beginTime

Indicates the start time for querying fault data. The time is the local time in the 24-hour format.

The format is in YYYY/MM/DD plus HH:MM:SS or YYYY-MM-DD plus HH:MM:SS.

YYYY/MM/DD indicates year/month/day, and YYYY-MM-DD indicates year-month-day. YYYY ranges from 1970 to 9999, MM ranges from 1 to 12, and DD ranges from 1 to 31.

HH:MM:SS indicates hour:minute:second. HH ranges from 0 to 23, and MM and SS range from 0 to 59.
endTime

Indicates the end time for querying fault data. The time is the local time in the 24-hour format.

The format is in YYYY/MM/DD plus HH:MM:SS or YYYY-MM-DD plus HH:MM:SS.

YYYY/MM/DD indicates year/month/day, and YYYY-MM-DD indicates year-month-day. YYYY ranges from 1970 to 9999, MM ranges from 1 to 12, and DD ranges from 1 to 31.

HH:MM:SS indicates hour:minute:second. HH ranges from 0 to 23, and MM and SS range from 0 to 59.
verbose

Specifies the faulty instance details.

-

Views

All views

Default Level

3: Management level

Usage Guidelines

EVA can manage device faults in a unified manner. You can run this command to view running information about fault modes managed by EVA, such as power supply fault modes.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display detailed information about the generation and recovery of fault mode instances managed by the EVA.
<HUAWEI> display eva fault verbose
2023-12-06 13:58:20
Total:   1
---------------------------------------------------------------------------------
Name                : power-abnormal
OccurTime           : 2024-02-07 14:28:10
RecoverTime         : -
TriggerCause        : hwPowerFail
KeyObject           : EntPhysicalIndex:1, EntPhysicalName:EvaTestEnt, EntityTrap
                      FaultID:136704, EntityPhysicalIndex:1, EntityOperStatus:1
ActionExecuteResult : -
-------------------------------------------------------------------------------
# Display running information about fault modes managed by the EVA.
<HUAWEI> display eva fault
2023-09-11 09:46:55.711
Total: 1
--------------------------------------------------------------------------------------------
OccurTime             RecoverTime           Name            Object
--------------------------------------------------------------------------------------------
2023-09-07 16:42:30   -                     power-abnormal  slot:0 
--------------------------------------------------------------------------------------------
Table 1 Description of the display eva fault command output
Item Description
Name

Fault mode.
OccurTime

Time when the fault occurred.
RecoverTime

Time when the fault is cleared.

  • -: indicates that the fault is not rectified.
  • useless: indicates that the recovery time of the fault cannot be obtained.
  • offline: indicates that the recovery time of the fault will not be obtained since the optical module goes offline.
TriggerCause

Trigger reason.
KeyObject

Key parameters of a fault alarm.
ActionExecuteResult

Execution result of the action triggered by the fault.
Object

Object where the fault occurs.
Total

Total number of records.
