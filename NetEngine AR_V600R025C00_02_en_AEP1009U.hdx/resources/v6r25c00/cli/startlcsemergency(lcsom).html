license emergency

Function

The license emergency command enables the emergency state of a global trotter license (GTL) file.

Format

license emergency

Parameters

None

Views

User view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

To limit the bearing capability of a device in different running states, the configuration data specifications of the device are classified into three types: maximum configuration, authorized configuration, and minimum configuration.

  • In maximum configuration, license resource and function items are configured based on the maximum system specifications.
  • In authorized configuration, the software functions and resources are configured based on the contract or special authorization. The authorized configuration depends on feature authorization of license files.
  • The minimum configuration is the default configuration when no activated license file exists in the system.

After the license emergency command is run, the device enters the GTL license emergency state, that is, the license disaster recovery state. This is a protection mechanism that ensures that customers' services are not affected when natural disasters such as earthquakes and volcanoes occur. In this state, the control over the license resource and function items of the device is canceled, and the license resource and function items run with the maximum specifications. After the emergency state expires, the use of resource and function items is subject to the license control.

In addition, you can run the license emergency command to temporarily expand the capacity of license resource and function items in emergency scenarios.

Precautions

Pay attention to the following points after enabling the Emergency state:

  • The Emergency state cannot be manually canceled. You can exit the Emergency state by activating a new license file.
  • The Emergency state can only be enabled three times for each license, and the license can keep in Emergency state for seven days each time.
  • The next operation can be performed only after the previous Emergency state ends.

Example

# Enable the emergency state of a GTL file.
<HUAWEI> license emergency
Warning: This operation will cause LCS into the EMERGENCY state. Continue? [Y/N]:y
Info: The emergency has been started. You can stop it only by activating a new license file.
