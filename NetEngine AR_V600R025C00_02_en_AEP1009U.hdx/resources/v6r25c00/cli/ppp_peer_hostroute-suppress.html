ppp peer hostroute-suppress

Function

The ppp peer hostroute-suppress command enables the suppression of adding the peer host route to the local routing table of direct routes.

The undo ppp peer hostroute-suppress command disables the suppression of adding the peer host route to the local routing table of direct routes.

By default, the local routing table of direct routes contains the host route of the peer end.

Format

ppp peer hostroute-suppress

undo ppp peer hostroute-suppress

Parameters

None

Views

Dialer interface view, MP-group interface view, POS interface view, Serial interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

A PPP link does not strictly require that the peer and local routes exist on the same network segment. If the two ends of a PPP link reside on different network segments, one end automatically adds the host route of the other end to the local routing table of direct routes. However, when one end is configured with an incorrect IP address, the other end automatically adds the incorrect peer host route to the local routing table and advertises the incorrect routing information across the network. To resolve this problem, run the ppp peer hostroute-suppress command to enable the suppression of adding the peer host route to the local routing table of direct routes.

Prerequisites

PPP has been configured as the link layer protocol of the interface.

Configuration Impact

Running the ppp peer hostroute-suppress command prevents the route of the directly-connected host from being added to the local routing table of direct routes.

Precautions

After the configuration, you must run the shutdown and undo shutdown commands in the corresponding interface view for the configuration to take effect.

Example

# Enable the suppression of adding the peer host route to the local routing table of direct routes, and then restart the dialer interface.
<HUAWEI> system-view
[HUAWEI] interface Dialer 95
[HUAWEI-Dialer95] ppp peer hostroute-suppress
[HUAWEI-Dialer95] shutdown
[HUAWEI-Dialer95] undo shutdown
