display ikev2 statistics

Function

The display ikev2 statistics command displays statistics about IKEv2 negotiation for an IPsec tunnel.

Format

display ikev2 statistics { error | packet | sa | modecfg | notify-info } [ slot slot-id cpu cpu-id ]

Parameters

Parameter Description Value
error

Displays error statistics about IPsec tunnels established through IKEv2 negotiation.

-
packet

Displays packet statistics about IPsec tunnels established through IKEv2 negotiation.

-
sa

Displays SA statistics about IPsec tunnels established through IKEv2 negotiation.

-
modecfg

Displays modecfg statistics about IPsec tunnels established through IKEv2 negotiation.

-
notify-info

Displays statistics about notification messages related to IPsec tunnels established through IKEv2 negotiation.

-
slot slot-id

Displays IKE statistics in a specified slot.

The value varies depending on device models.
cpu cpu-id

Displays IKE statistics on a specified CPU.

The value varies depending on device models.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

You can run this command to view statistics about errors, packets, SAs, modecfg, and notification messages related to IPsec tunnels established through IKEv2 negotiation.

Example

The actual command output varies according to the device. The command output here is only an example.
