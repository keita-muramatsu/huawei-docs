display configuration changes

Function

The display configuration changes command displays the differences between device configurations.

Format

display configuration commit changes [ at commit-id | since commit-id | last number-of-commits ]

display configuration changes [ running file file-name | file file-name running ]

display configuration changes { running label label | label label running }

display configuration changes start-time startTime [ end-time endTime ]

Parameters

Parameter Description Value
at commit-id

Displays configuration changes at a configuration rollback point.

The id is a string of 1 to 20 characters and generated by the system automatically.
since commit-id

Displays configuration changes since the specified configuration rollback point was generated.

The id is a string of 1 to 20 characters and generated by the system automatically.
last number-of-commits

Specifies the number of the latest configuration rollback points. Configuration changes in these rollback points are displayed.

The value is an integer ranging from 1 to 80.
running

Displays the running configuration, that is, the configuration data in the running/ database.

-
file file-name

Specifies a configuration file.

The name is a string of 5 to 64 characters in the format of .zip, .cfg, or .dat.
label label

Specifies a user label for a configuration rollback point.

The value is a string of 1 to 256 characters.
start-time startTime

Specifies the start time for querying configuration differences.

The value is in the format of YYYY/MM/DD,HH:MM:SS.

YYYY-MM-DD indicate year/month/day. The value of YYYY ranges from 1970 to 9999, the value of MM ranges from 1 to 12, and the value of DD ranges from 1 to 31.

HH:MM:SS indicates hour:minute:second. The value of HH ranges from 0 to 23. The values of MM and SS range from 0 to 59.
end-time endTime

Specifies the end time for querying configuration differences.

The value is in the format of YYYY/MM/DD,HH:MM:SS.

YYYY-MM-DD indicate year/month/day. The value of YYYY ranges from 1970 to 9999, the value of MM ranges from 1 to 12, and the value of DD ranges from 1 to 31.

HH:MM:SS indicates hour:minute:second. The value of HH ranges from 0 to 23. The values of MM and SS range from 0 to 59.

Views

All views

Default Level

3: Management level

Usage Guidelines

Usage Scenario

  • If a misoperation is performed on a device or some configurations fail due to a configuration fault, you can run the display configuration commit changes command to view the configuration differences between configuration rollback points before restoring the system to a historical state.
  • The display configuration changes running file command displays the difference between the current configuration file and a specified configuration file.
  • The display configuration changes file file-namerunning command displays the difference between a specified configuration file and the current configuration file.
  • The display configuration changes running label command displays the difference between the current configuration and the configuration of a specified user label.
  • The display configuration changes label labelrunning command displays the difference between the configuration of a specified user label and the current running configuration.
  • The display configuration changes start-time startTime[ end-time endTime] command displays the differences between device configurations within a specified period.
  • Configuration differences can only be compared between the current running configuration file and the configuration file. During command execution, the first specified configuration is called the source configuration, and the later specified configuration is called the target configuration. If the source configuration is different from the target configuration, the following information is displayed:
  • A command added in the target configuration is prefixed with the plus sign (+) compared with the source configuration.
  • A command that is deleted from the target configuration is prefixed with a hyphen (-).
  • If a command in the source configuration is modified in the target configuration, the command prefixed with a hyphen (-) is displayed first, and then the command prefixed with a plus sign (+) is displayed.

Precautions

  • When the configuration difference comparison command is being executed, if repeated commands exist in the same view, the current command fails to be executed.

    The specified configuration file specified by file-name must exist on the device.
  • When the display configuration changes start-time startTime[ end-time endTime] command is executed, the system queries the configuration at the rollback point that is later than startTime and closest to startTime and the configuration at the rollback point that is earlier than endTime and closest to endTime, and then compares the configurations of the rollback points. If endTime is not specified, the system queries the configurations at the rollback point that is later than and closest to startTime and compares the configurations with the current running configurations.
  • When you run the display configuration changes start-time startTime[ end-time endTime] command to check the differences between configurations at the rollback points in a specified period, the value of endTime must be later than that of startTime.
  • When you repeatedly run the *display configuration changes start-time startTime[ end-time endTime]command to check the differences between configurations at the rollback points in a specified period, the configuration changes displayed for the same period may be different because the rollback points may be aged.

Commit changes of commitId

Specifies the label of the configuration rollback point. "by XXXX" indicates the user name. If the user name is displayed as "-", no user name is available.
