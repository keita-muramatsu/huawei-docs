display portal-server state

Function

The display portal-server state command displays the Portal server status.

Format

display portal-server state [ web-auth-server server-name ]

Parameters

Parameter Description Value
web-auth-server server-name

Displays the status of the Portal server configured in a specified Portal server template.

If this parameter is not specified, the status of all Portal servers is displayed.

The Portal server template name must exist.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

When external Portal authentication is used, you can run the display portal-server state command to check the Portal server status.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the status of the Portal server configured in the Portal server template abc.
<HUAWEI> display portal-server state web-auth-server abc
  Web-auth-server     :    abc                      
  Total-servers       :    4                                                    
  Live-servers        :    1                                                    
  Critical-num        :    0                                                    
  Status              :    Normal                                               
  Ip-address               Status                                               
  192.168.2.1              UP                                                   
  192.168.2.2              DOWN                                                 
  192.168.2.3              DOWN                                                 
  192.168.2.4              DOWN
Table 1 Description of the display portal-server state command output
Item Description
Web-auth-server

Name of the Portal server template.
Total-servers

Number of configured Portal servers.
Live-servers

Number of Portal servers in Up state.
Critical-num

Minimum number of Portal servers in Up state. If the number of Portal servers in Up state is less than the minimum value, the bypass function is enabled for the corresponding Portal server template.
Status

Status of the Portal server:

  • Normal: indicates the normal state. When the number of servers in Up state is greater than the value of Critical-num, Status is Normal. If the server-ip server-ip-address &<1-10> command is not run in the Portal server template view to configure an IP address for the Portal server, Status is Normal.
  • Abnormal: indicates the abnormal state. If the number of servers in Up state is less than or equal to Critical-num, Status is Abnormal.
Status

Whether the Portal server specified by the server IP address is reachable:

  • UP: reachable.
  • DOWN: unreachable.
Ip-address

IP address of the server.
