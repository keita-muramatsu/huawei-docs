isis cost (interface view)

Function

The isis cost command sets a link cost for an IS-IS interface.

The undo isis cost command restores the default link cost.

By default, the link cost of IS-IS interfaces is 10.

Format

isis cost cost [ level-1 | level-2 ]

undo isis cost [ cost ] [ level-1 | level-2 ]

Parameters

Parameter Description Value
cost cost

Specifies a link cost for the SPF calculation.
  • The value is an integer. The value range depends on the cost style.
  • If the cost style is narrow, narrow-compatible, or compatible, the value ranges from 1 to 63.
  • If the cost style is wide or wide-compatible, the value ranges from 1 to 16777214.
  • maximum: indicates that the maximum cost 16777215 is used. This value can be set only when the cost style is wide or wide-compatible.
  • The minimum value varies according to the interface type. For loopback interfaces, the minimum value is 0. For other types of interfaces, the minimum value is 1.

This parameter can be configured only when the IS-IS cost style is wide or wide-compatible. After the cost of an interface is set to 16777215, the neighbor TLV generated on the link of the interface cannot be used for route calculation; instead, it can only be used to transmit TE information.

The cost style is configured using the cost-style command.
level-1

Sets the link cost value for the Level-1 interface.

-
level-2

Sets the link cost value for the Level-2 interface.

If Level-1 or Level-2 is not specified in the command, the link cost is set for Level-1 and Level-2 interfaces by default.

-

Views

10GE sub-interface view, 10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE interface view, Cellular channel interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, Ethernet interface view, GE optical interface view, GE sub-interface view, GE electrical interface view, IP-Trunk interface view, Loopback interface view, MP-group interface view, POS interface view, Tunnel interface view, VLANIF interface view, 40GE sub-interface view, Ethernet sub-interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

On a large-scale network, there may be multiple valid routes to the same destination. IS-IS uses the SPF algorithm to calculate an optimal route and transmits traffic over the optimal route, which causes the following problems:

  • All traffic is forwarded through the optimal path, which may cause load imbalance.
  • If the optimal path on the network is intermittently disconnected, traffic is still forwarded along the optimal path before convergence, causing traffic loss.

    To solve the preceding problem, run the isis cost command to set different link costs for interfaces so that traffic can be forwarded along different physical links.

Prerequisites

IS-IS has been enabled on the interface using the isis enable command in the interface view.

Configuration Impact

If the link cost is changed, routes of the entire network are recalculated, and the traffic forwarding path changes accordingly.

Precautions

If both the isis cost and circuit-cost commands are run, the link cost set using the isis cost command preferentially takes effect on the interface.

IS-IS provides multiple cost adjustment modes. If more than one mode is configured, they take effect based on the following rules:

  1. If automatic interface cost calculation (auto-cost), association between link quality and the cost, neighbor relationship flapping suppression, LDP-cost association (ldp-sync), peer hold-cost, hold-max-cost, IS-IS overload, association between BFD and the cost, association between remaining bandwidth and the cost, and association between soft reset and the cost are all configured, the maximum cost among the preceding functions prevails.
  2. If the association between the link group and the cost is configured along with the functions mentioned in rule 1, the cost configured for the link group plus the one obtained in rule 1 is used as the final cost.
  3. If the reverse cost function is configured, the cost configured for it prevails.

Example

# Set the link cost of the Level-2 link on 10GE 0/0/0 to 5.
<HUAWEI> system-view
[HUAWEI] isis 1
[HUAWEI-isis-1] quit
[HUAWEI] interface 10GE 0/0/0
[HUAWEI-10GE0/0/0] isis enable
[HUAWEI-10GE0/0/0] isis cost 5 level-2
