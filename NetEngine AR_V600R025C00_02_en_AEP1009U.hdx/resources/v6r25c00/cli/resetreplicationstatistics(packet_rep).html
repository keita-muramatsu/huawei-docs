reset packet-replication statistics

Function

The reset packet-replication statistics command clears packet replication statistics.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

reset packet-replication statistics

Parameters

None

Views

User view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

Before collecting packet replication statistics within a certain period, you need to run this command to clear the existing statistics.

To view packet replication statistics, run the display packet-replication statistics command.

Precautions

After this command is run, packet replication statistics are cleared and cannot be restored. Exercise caution before running this command.

Example

# Clear the historical packet replication statistics.
<HUAWEI> reset packet-replication statistics
