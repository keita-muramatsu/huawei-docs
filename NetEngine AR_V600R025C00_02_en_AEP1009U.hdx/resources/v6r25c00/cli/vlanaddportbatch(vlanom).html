port (VLAN view)

Function

The port command sets a default VLAN for interfaces and adds interfaces to the VLAN.

The undo port command deletes the interfaces from the default VLAN and restores the default VLAN ID.

By default, the VLAN ID of all interfaces is 1.

Format

port interface-type { interface-number1 [ to interface-number2 ] } &<1-10>

port interface-name

undo port interface-type { interface-number1 [ to interface-number2 ] } &<1-10>

undo port interface-name

Parameters

Parameter Description Value
interface-type

Specifies an interface type.

-
interface-number1

Specifies the start number of an interface.

-
to interface-number2

Specifies the end number of an interface.

-
interface-name

Specifies the name of an interface.

-

Views

VLAN view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Frames sent from user hosts are untagged and those received by an interface from a remote device may also be untagged. However, a switching device only processes and forwards tagged Ethernet frames. Therefore, the switching device must add tags to the untagged frames received by an interface. To achieve this, you must configure a default VLAN on an interface. The interface then adds the default VLAN tag to a received untagged frame.

After a default VLAN is configured on an interface:

  • The interface adds the default VLAN tag to a received untagged packet if the link type of the interface is access or hybrid.
  • When the interface receives a tagged packet:
    • For an access interface, the interface forwards the packet if its VLAN ID is the same as the default VLAN ID of the interface; the interface discards the packet if its VLAN ID is different from the default VLAN ID of the interface.
    • For a hybrid interface, the interface forwards the packet if its VLAN ID is within the interface's permitted range of VLAN IDs; the interface discards the packet if its VLAN ID is not within the interface's permitted range of VLAN IDs.
  • When the interface sends a tagged packet:
    • For an access interface, the interface removes the VLAN tag from the packet and then sends the packet.
    • For a hybrid interface, the interface sends this packet directly if the VLAN is tagged; the interface removes the VLAN tag of the packet and then sends the packet if the VLAN is untagged.

Prerequisites

The link type of the interface has been configured as access or hybrid using the port link-type command.

Precautions

The command has the same function as the port default vlan command in the interface view.

Before you specify an interface range, note that:

  1. Interfaces in the range specified using to must have the same type.
  2. The interfaces in the range must exist.
  3. If you run this command multiple times, all configurations take effect.
  4. The interface to be added to a VLAN must be a Layer 2 interface. If the interface is a Layer 3 interface, switch the interface mode from Layer 3 to Layer 2.
  5. This command cannot be configured on physical interfaces that are added to an Eth-Trunk interface.

Example

# Add 10GE 0/0/1 and 10GE 0/0/2 to VLAN 3.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] portswitch
[HUAWEI-10GE0/0/1] port link-type access
[HUAWEI-10GE0/0/1] quit
[HUAWEI] interface 10GE 0/0/2
[HUAWEI-10GE0/0/2] portswitch
[HUAWEI-10GE0/0/2] port link-type access
[HUAWEI-10GE0/0/2] quit
[HUAWEI] vlan 3
[HUAWEI-vlan3] port 10GE 0/0/1 to 0/0/2
