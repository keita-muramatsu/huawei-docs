keepalive (Tunnel interface view)

Function

The keepalive command enables the Keepalive function for a GRE tunnel.

The undo keepalive command disables the Keepalive function for a GRE tunnel.

By default, the Keepalive function is disabled for a GRE tunnel.

Format

keepalive [ period period [ retry-times retry-times ] ]

undo keepalive [ period period [ retry-times retry-times ] ]

Parameters

Parameter Description Value
period period

Specifies the interval for sending Keepalive messages.

The value is an integer ranging from 1 to 32767, in seconds. The default value is 5.
retry-times retry-times

Specifies the count of the unreachable counter.

The value is an integer that ranges from 1 to 255. The default value is 3.

Views

Tunnel interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The Keepalive function of a GRE tunnel prevents a service module from selecting a GRE tunnel that is unreachable to the peer end, preventing data loss. This is because if the Keepalive function is disabled, the local tunnel interface may be up even if the peer end of the GRE tunnel is unreachable. After the Keepalive function is enabled on the local end, if the peer end of the GRE tunnel is unreachable, the local tunnel interface is set to down.

After the Keepalive function is enabled, the source end of the GRE tunnel periodically sends Keepalive packets. Each time a Keepalive packet is sent, the unreachable counter value increments by 1. If no response packet is received when the counter value reaches the preset retry-times value, the peer end is considered unreachable.

After the keepalive command is run, the Keepalive function of the GRE tunnel takes effect immediately. After the undo keepalive command is run, the function becomes invalid immediately.

Prerequisites

A tunnel interface has been created using the interface tunnel command.

The tunnel encapsulation type has been set to GRE using the tunnel-protocol gre command.

Configuration Impact

If the keepalive command is run more than once, the latest configuration overrides the previous one.

Follow-up Procedure

After configuring the Keepalive function, you can run the display keepalive packets count command to check the numbers of Keepalive messages and Keepalive response messages sent and received by a GRE tunnel interface.

Precautions

GRE over IPsec scenario:

If IPsec is applied to a tunnel interface, Keepalive packets are not encrypted. If the peer device has a security policy that requires packets to be encrypted, Keepalive packets may be discarded.

If IPsec is applied to a physical interface, Keepalive packets are encrypted.

Example

# Enable the Keepalive function for a GRE tunnel and retain the default parameter values.
<HUAWEI> system-view
[HUAWEI] interface tunnel 100
[HUAWEI-Tunnel100] tunnel-protocol gre
[HUAWEI-Tunnel100] keepalive
# Enable the Keepalive function for a GRE tunnel. Set the Keepalive packet sending interval to 12s and configure the unreachable counter to use the default setting.
<HUAWEI> system-view
[HUAWEI] interface tunnel 100
[HUAWEI-Tunnel100] tunnel-protocol gre
[HUAWEI-Tunnel100] keepalive period 12
# Enable the Keepalive function for a GRE tunnel. Set the Keepalive packet sending interval to 12s and retry-times to 4.
<HUAWEI> system-view
[HUAWEI] interface tunnel 100
[HUAWEI-Tunnel100] tunnel-protocol gre
[HUAWEI-Tunnel100] keepalive period 12 retry-times 4
