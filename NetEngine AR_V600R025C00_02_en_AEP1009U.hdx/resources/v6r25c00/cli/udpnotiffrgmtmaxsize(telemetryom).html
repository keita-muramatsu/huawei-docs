protocol udp ietf-netconf-udp-notif fragment-max-size

Function

The protocol udp ietf-netconf-udp-notif fragment-max-size command sets the maximum length of a UDP fragment in draft-ietf-netconf-udp-notif-08 format.

The undo protocol udp ietf-netconf-udp-notif fragment-max-size command cancels the configuration and restores the length of a UDP packet to the default maximum value 65535.

By default, UDP packets in draft-ietf-netconf-udp-notif-08 format are not fragmented, and the length of a UDP packet is set to 65535 bytes.

Format

protocol udp ietf-netconf-udp-notif fragment-max-size fragment-max-size-value

undo protocol udp ietf-netconf-udp-notif fragment-max-size [ fragment-max-size-value ]

Parameters

Parameter Description Value
fragment-max-size fragment-max-size-value

Specifies the size of a UDP fragment.

The value is an integer in the range from 1000 to 65535, in bytes.

Views

Telemetry view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

In a scenario where telemetry data sampling is performed and ietf-netconf-udp-notif is used to send protocol packets to the CPU, if the UDP packet size is too large, you can set the size of UDP fragments. After the configuration, if the size of a UDP packet exceeds the value of fragment-max-size-value, the UDP packet is fragmented before being sent. The target collector needs to support UDP packet fragmentation.

Precautions

The fragmentation function takes effect only for UDP packets in draft-ietf-netconf-udp-notif-08 format. Therefore, you need to run the protocol udp message-header ietf-netconf-udp-notif command to switch the format of the UDP header.

If the configured fragment size is greater than 65472, the fragment size 65472 is used.

Example

# Set the length of a UDP packet fragment to 1500 bytes when Telemetry uses the UDP packet header in draft-ietf-netconf-udp-notif-08 format.
<HUAWEI> system-view
[HUAWEI] telemetry
[HUAWEI-telemetry] protocol udp ietf-netconf-udp-notif fragment-max-size 1500
