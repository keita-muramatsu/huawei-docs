configuration exclusive by-user-name

Function

The configuration exclusive by-user-name command configures the function of locking system configurations by users who are allowed to modify configurations.

The undo configuration exclusive by-user-name command configures the function of unlocking system configurations for users who are allowed to modify configurations.

By default, system configurations are not locked by users.

Format

configuration exclusive by-user-name user-name

undo configuration exclusive by-user-name user-name

Parameters

Parameter Description Value
user-name

Specifies the name of a user.

The name is a string of 1 to 253 characters.

Views

System view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

The device supports multi-user access and management. When multiple users manage a device, you can lock the device for a specified user name, so that only users who log in to the device using this user name can modify device configurations. These users can be controller users or other types of users.

If a non-controller user logs in to the device and modifies device configurations in a scenario where the controller is deployed, the configurations delivered by the controller may be different from those on the device. To prevent this situation, you can run this command to lock the system configurations for controller users.

Configuration Impact

Once the system configurations are locked using a specified user name, only the user using this user name to log in can deliver configurations. Other users can view, edit, maintain, or save the configurations after login, but cannot deliver configurations. If other users need to deliver the configurations, the undo configuration exclusive by-user-name command must be run to unlock the configurations. The user-name parameter in the command must be the name of the user who locks the configurations.

Precautions

  • Only users of the management level can lock and unlock the configuration. The system configuration can be locked by only one user at a time.
  • The user who locks the system configuration using this command does not need to be the same as the user specified by user-name in the configuration exclusive by-user-name user-name command. user-name can be any valid user name.
  • The name of the user who unlocks the configuration can be any valid user name.
  • This command is used to lock the system configuration based on the user name. Only the same user name can be used to unlock the system configuration. After the user logs out, the system configuration is not automatically unlocked. The configuration exclusive command is used to lock the system configuration based on the session. The system configuration can be unlocked only by the current session. After the session is logged out, the system configuration is automatically unlocked.

Example

# Enable user huawei456 to lock the system configuration.
<HUAWEI> system-view
[HUAWEI] configuration exclusive by-user-name huawei456
