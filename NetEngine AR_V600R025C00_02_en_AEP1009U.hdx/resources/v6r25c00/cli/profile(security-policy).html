profile (Security policy rule view)

Function

The profile command configures a security policy rule to reference a security profile.

The undo profile command cancels the reference of a security profile in a security policy rule.

By default, this function is not configured.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

profile { av | ips | url-filter } profile-name

undo profile all

undo profile { av | ips | url-filter }

Parameters

Parameter Description Value
av

Indicates the antivirus profile.

-
ips

Indicates the IPS profile.

-
url-filter

Indicates URL filtering profile.

-
profile-name

Specifies the name of a security profile.

The value is a string of 1 to 32 case-sensitive characters. If the name contains spaces, it must be enclosed in double quotation marks (""), for example, "profile for test".
profile

Configures the profile.

-
all

Indicate all profiles.

-

Views

Security policy rule view

Default Level

2: Configuration level

Usage Guidelines

The security profile is referenced in the security policy rule to inspect the content of the traffic that matches the security policy rule (the action is permit). To inspect the content of the traffic that matches a security policy rule, reference a security profile in the security policy rule.

The security profile referenced using the profile command takes effect only after the corresponding license is activated.

Example

# Reference IPS profile profile_ips in security policy rule policy_sec. 
<HUAWEI> system-view
[HUAWEI] profile type ips name profile_ips
[HUAWEI-profile-ips-profile_ips] quit
[HUAWEI] security-policy
[HUAWEI-policy-security] rule name policy_sec
[HUAWEI-policy-security-rule-policy_sec] profile ips profile_ips
