led blink-time

Function

The led blink-time command configures the indicator blinking function on an AP.

The undo led blink-time command cancels the indicator blinking configuration on an AP.

By default, the indicator blinking function is disabled on an AP.

Format

led blink-time blink-time { ap-id ap-id | ap-mac ap-mac }

undo led blink-time { ap-id ap-id | ap-mac ap-mac | all }

Parameters

Parameter Description Value
blink-time blink-time

Specifies the indicator blinking time of an AP.

The value is an integer that ranges from 1 to 86400, in seconds.
ap-id ap-id

Specifies the AP ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
ap-mac ap-mac

Specifies the MAC address of an AP.

The value is in H-H-H format. An H is a hexadecimal number of 4 digits.
all

Cancels the indicator blinking configuration of all APs.

-

Views

WLAN view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To locate an AP, run this command on the AC to configure the AP indicator to blink.

When this function is enabled, the SYS indicator blinks red if an AP runs V200R019C10 or later and blinks orange and green alternatively if the AP runs V200R019C00 or earlier.

Precautions

Offline APs cannot be located by configuring the AP indicator to blink.

The configuration using this command takes precedence over that using the led off command. That is, if AP indicators are configured to blink during the indicator turn-off period, the indicator turn-off operation takes effect after the indicator blinking is complete.

Example

# Configure the indicator of the AP with the MAC address 00e0-fc12-3456 to blink for 300 seconds.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] led blink-time 300 ap-mac 00e0-fc12-3456
