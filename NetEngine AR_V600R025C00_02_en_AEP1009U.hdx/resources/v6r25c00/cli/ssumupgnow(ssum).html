upgrade right-now

Function

The upgrade right-now command triggers one-click upgrade.

By default, the system software is upgraded to the latest version.

Format

upgrade right-now [ system-software ] [ patch ] [ feature-software { feature-name } &<1-9> ]

Parameters

Parameter Description Value
system-software

Specifies the basic software package to be upgraded.

The value is a keyword.

  • If this parameter is specified, the basic software package is upgraded during immediate upgrade.
  • If this parameter is specified, the basic software package is not upgraded during immediate upgrade.
patch

Specifies the patch software package to be upgraded.

The value is a keyword.

  • If this parameter is specified, the patch software package is upgraded during immediate upgrade.
  • If this parameter is specified, the patch software package is not upgraded during immediate upgrade.
feature-software feature-name

Specifies the name of the feature package to be upgraded immediately.

The value is a string of 1 to 127 case-sensitive characters, without spaces.

Views

Smart upgrade view

Default Level

3: Management level

Usage Guidelines

To manually trigger smart upgrade, you can run this command to perform the upgrade immediately.

Example

# Immediately upgrade the basic software package, patch software package, and feature package. The feature names are feature1 and feature2.
<HUAWEI> system-view
[HUAWEI] smart-upgrade
[HUAWEI-smart-upgrade] upgrade right-now system-software patch feature-software feature1 feature2
