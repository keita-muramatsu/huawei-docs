ap update schedule-task

Function

The ap update schedule-task command configures a scheduled AP upgrade task.

The undo ap update schedule-task command deletes a scheduled AP upgrade task.

By default, no scheduled AP upgrade task is configured.

Format

ap update schedule-task task-id task-id start-time start-time start-date stop-time stop-time stop-date ap-type type-id [ ap-group group-name | { ap-id ap-id-value } &<1-10> ]

ap update schedule-task task-id task-id start-time start-time start-date stop-time stop-time stop-date ap-group group-name

undo ap update schedule-task { all | task-id task-id }

Parameters

Parameter Description Value
task-id task-id

Specifies the index of an upgrade task.

The value is an integer that ranges from 0 to 31.
start-time start-time

Specifies the start time of the upgrade task.

The value is in HH:MM format. The value ranges from 00:00 to 23:59.
start-date

Specifies the start date of the upgrade task.

The value is in YYYY/MM/DD format. The value ranges from 2000-01-01 to 2050-12-31.
stop-time stop-time

Specifies the end time of the upgrade task.

The value is in HH:MM format. The value ranges from 00:00 to 23:59.
stop-date

Specifies the end date of an upgrade task.

The value is in YYYY/MM/DD format. The value ranges from 2000-01-01 to 2050-12-31.

stop-time stop-date must be later than start-time start-date.
ap-type type-id

Specifies the AP type ID.

The value is an integer ranging from 0 to 255.

You can run the display ap-type all command to check the device types of all APs.
ap-group group-name

Specifies an AP group.

The value is a string of 1 to 35 characters, which can be Chinese characters or Chinese + English characters. It cannot contain question marks (?) or slashes (/), and cannot start or end with spaces or double quotation marks (" "). If the AP group name contains spaces, the input name must start and end with a quotation mark ("), for example, "huawei name1". The quotation marks at the beginning and end of the AP group name occupy two characters in total.

You can only use a command editor of the UTF-8 encoding format to edit Chinese characters.
ap-id ap-id-value

Specifies the AP ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
all

Indicates all upgrade tasks.

-

Views

WLAN view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

You can configure a scheduled AP upgrade task to upgrade APs in a specified period. For example, you can upgrade APs during off-peak hours.

If ap-group group-nameis specified, only APs in the specified AP group are upgraded as scheduled. Similarly, if ap-type type-idor ap-id ap-idis specified, only the APs matching the specified parameters are upgraded as scheduled.

After the scheduled upgrade task is complete, the configuration is not automatically deleted. To delete the task, run the undo ap update schedule-task { all | task-id task-id} command.

Prerequisites

The AP upgrade file has been specified using the ap update update-filename command.

Configuration Impact

After scheduled upgrade tasks are configured, automatic upgrade cannot be performed if not all tasks are in the DONE, OVERTIME, or DEAD state. To perform automatic upgrade, you need to delete all the scheduled upgrade tasks that are not in DONE, OVERTIME, or DEAD state. To check the status of scheduled AP upgrade tasks, run the display ap update schedule-task command.

Precautions

  • For scheduled upgrade tasks with the same start time, the task with a smaller task-id task-idvalue is executed first.
  • During the scheduled AP upgrade task, if the time for task B is reached before task A is completed, task B waits until task A is completed. The subsequent scheduled upgrade tasks wait in sequence until the previous task is completed.
  • When the time specified by stop-time stop-time stop-date is reached, ongoing upgrade tasks continue until the upgrade is completed and those tasks waiting in queues stop.
  • After all APs in a scheduled upgrade task are upgraded, the APs automatically restart in batches. The APs that fail to be upgraded do not restart.
  • After a scheduled AP upgrade task is configured, if the AP group or all APs in the task are deleted, the task fails to be executed, but upgrade failure information is not recorded.
  • If an AP is being automatically upgraded when you configure a scheduled upgrade task, the AP continues to be upgraded until the upgrade is complete. APs that have not started automatic upgrade will not be automatically upgraded.
  • If the system time is changed during the configuration of a scheduled upgrade task, the following impacts may occur:
  • If the system time is changed before the upgrade task starts, the start time and end time of the scheduled upgrade are subject to the new system time. For example, the system time is 1:00, the start time of the scheduled update is 3:00, and the end time of the scheduled update is 4:00. After the system time is changed to 2:00 at 1:05, the start time of the scheduled update is still 3:00, and the end time of the scheduled update is still 4:00.
  • If the system time is changed after the scheduled AP upgrade task starts, the start time and end time of the scheduled upgrade are subject to the system time before the change.

Example

# Configure APs with ap-type as 144 to perform the scheduled upgrade from 01:00 to 04:00 on May 20, 2022.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap update schedule-task task-id 1 start-time 1:00 2022/5/20 stop-time 4:00 2022/5/20 ap-type 144
