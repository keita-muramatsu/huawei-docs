display device voltage

Function

The display device voltage command displays the voltage of a device.

This command is supported only on the AR8700 series.

Format

display device voltage [ slot slot-id ]

Parameters

Parameter Description Value
slot slot-id

Specifies the slot ID.

The value is a character string. You can enter a question mark (?) and select a value as prompted. The value is a string of 1 to 49 case-insensitive characters. It cannot contain spaces.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

In routine maintenance, you can run this command to check the device voltage.

Precautions

If the device does not support the voltage sensor, this command output is empty.
