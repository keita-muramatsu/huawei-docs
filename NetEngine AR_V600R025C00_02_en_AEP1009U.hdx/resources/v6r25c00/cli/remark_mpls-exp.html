remark mpls-exp

Function

The remark mpls-exp command configures an action of re-marking the EXP priority in MPLS packets in a traffic behavior.

The undo remark mpls-exp command deletes an action of re-marking the EXP priority in MPLS packets in a traffic behavior.

By default, an action of re-marking the EXP priority in MPLS packets is not configured in a traffic behavior.

Format

remark mpls-exp mpls-exp-value

undo remark mpls-exp [ mpls-exp-value ]

Parameters

Parameter Description Value
mpls-exp-value

Specifies the EXP priority of MPLS packets.

The value is an integer that ranges from 0 to 7. A larger value indicates a higher priority in VLAN packets.

Views

Traffic behavior view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To provide differentiated services based on EXP priorities in MPLS packets, run the remark mpls-exp command to configure an action of re-marking the EXP priority in MPLS packets.

Follow-up Procedure

Run the traffic policy command to create a traffic policy and run the classifier behavior command in the traffic policy view to bind a traffic classifier to the traffic behavior configured with an action of re-marking the EXP priority in MPLS packets.

Precautions

When a traffic policy containing remark mpls-exp is applied to the outbound direction of an interface, QoS processing of packets on the current device is not affected, but QoS processing of packets on the downstream device is affected.

If both the trust command and a traffic policy containing remark mpls-exp are configured on the same interface, the remark mpls-exp command configuration in the traffic policy takes precedence over the trust command configuration, and the priorities of packets are not affected by the trust command configuration.

If you run the remark mpls-exp command in the same traffic behavior view multiple times, only the latest configuration takes effect.

Example

# Re-mark the EXP priority in MPLS packets with 4 in the traffic behavior b1.
<HUAWEI> system-view
[HUAWEI] traffic behavior b1
[HUAWEI-behavior-b1] remark mpls-exp 4
