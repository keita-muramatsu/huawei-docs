poe power-reserved

Function

The poe power-reserved command sets the percentage of the reserved PoE power against the total PoE power.

The undo poe power-reserved command restores the default percentage of the reserved PoE power against the total PoE power.

By default, the percentage of the reserved PoE power is 20%.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA.

Format

poe power-reserved reserved-value

poe power-reserved reserved-value slot slot-id

undo poe power-reserved [ reserved-value ]

undo poe power-reserved [ reserved-value ] slot slot-id

Parameters

Parameter Description Value
reserved-value

Specifies the percentage of the reserved PoE power against the total PoE power.

The value is an integer ranging from 0 to 100, in percentage.

The default value is 20.
slot slot-id

Specifies the ID of a box-shaped device.

The value is a string of 1 to 9 characters.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The device dynamically allocates power to each interface based on the actual power consumption of each interface. The power consumption of each PD keeps changing during operation. The system periodically calculates whether the total power required by all connected PDs exceeds the upper limit of the available PoE power. If the total power required by all connected PDs exceeds the upper limit, the system automatically powers off the PD connected to the interface with a lower priority. If the interfaces have the same priority, the system powers off the PD connected to the interface with a larger number to ensure normal operation of other devices.

Sometimes, the power consumption increases sharply, and the remaining power of the system cannot support the surge. Before the system detects that the total power consumption exceeds the threshold, it cuts off the power supply to the interface with a lower priority, the PoE power supply may be powered off due to overload protection.

Run the poe power-reserved command to set a proper reserved power. When there is a burst increase in power consumption, the reserved power can support the burst increase in power consumption. This ensures that the system has time to power off interfaces of low priority to ensure stable running of other devices.

Precautions

  • The reserved power should not be set greater than 20%. If the reserved PoE power is greater than 20% of the total PoE power, the power capacity of the device is affected.
  • To set the maximum output power of a board, run the poe max-power command. In this case, the board calculates the reserved power based on the set maximum output power. If the maximum output power is not set, the available PoE power is the power provided by the PoE power module.

Example

# Set the percentage of reserved PoE power to the total PoE power to 30%.
<HUAWEI> system-view
[HUAWEI] poe power-reserved 30
Warning: The power for new PDs may be insufficient after this operation is performed. Continue?[Y/N]:y
