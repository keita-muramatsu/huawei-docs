binding service-map(per-packet-compress-policy view)

Function

The binding service-map command binds a specified service profile to a compression policy.

The undo binding service-map command unbinds a service profile from a compression policy.

By default, no service profile is bound to a compression policy.

This command is supported only on the AR8700 series, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series and AR6700-H series.

Format

binding service-map service-map-name precedence precedence-value

undo binding service-map service-map-name precedence precedence-value

Parameters

Parameter Description Value
precedence precedence-value

Specifies the priority of a service profile. A smaller value indicates a higher priority.

The value is an integer ranging from 0 to 65535.
service-map service-map-name

Specifies the name of a service profile.

The value is a string of 1 to 31 case-sensitive characters. If spaces are used, the string must be enclosed in double quotation marks (" ").

Views

Per-packet-compress-policy view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

You can define different service flows using ACLs or application groups, configure matching rules in a service profile for traffic classification, and run this command to bind a compression policy to the service profile to compress the specified service flows.

Prerequisites

A service profile has been created using the service-map command.

Example

# Create a service profile named map1, and bind an ACL to the service profile. Create a compression policy named comp1, and bind map1 to the compression policy.
<HUAWEI> system-view
[HUAWEI] acl 3000
[HUAWEI-acl4-advance-3000] quit
[HUAWEI] per-packet-compress
[HUAWEI-per-packet-compress] service-map map1
[HUAWEI-per-packet-compress-service-map-map1] match acl 3000
[HUAWEI-per-packet-compress-service-map-map1] quit
[HUAWEI-per-packet-compress] compress policy comp1
[HUAWEI-per-packet-compress-policy-comp1] binding service-map map1 precedence 10
