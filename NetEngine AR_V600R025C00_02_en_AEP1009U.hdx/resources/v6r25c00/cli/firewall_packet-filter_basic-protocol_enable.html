firewall packet-filter basic-protocol enable

Function

The firewall packet-filter basic-protocol enable command enables the security policy control function for BFD unicast packets, LDP packets, BGP packets, DHCP unicast packets, DHCPv6 unicast packets, and OSPF unicast packets.

The undo firewall packet-filter basic-protocol enable command disables the security policy control function for BFD unicast packets, LDP packets, BGP packets, DHCP unicast packets, DHCPv6 unicast packets, and OSPF unicast packets.

By default, the security policy control function is enabled for the preceding protocol packets.

Format

firewall packet-filter basic-protocol enable

undo firewall packet-filter basic-protocol enable

Parameters

None

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After this function is enabled, the forwarding of these packets is controlled by security policies. You can configure security policies or default packet filtering rules to control the forwarding of these packets.

After this function is disabled, the security policy does not match the source and destination IP addresses, packet format, and packet content of packets destined for the following destination port numbers. Instead, the packets are directly skipped, even if a security policy rule with the deny action is configured. Therefore, you are advised not to disable this function.

This function takes effect only for the packets destined for and sent from the device. Multicast packets are directly forwarded without being controlled by the firewall packet-filter basic-protocol enable command or security policies. For unicast packets, the protocol packets controlled by security policies are as follows:

IPv4:

OSPF (protocol number: 89), BGP (TCP port number: 179), DHCP (UDP port number: 67 and 68), LDP (TCP port number: 646), and BFD (UDP port number: 3784 and 4784)

IPv6:

OSPF (protocol number: 89), BGP (TCP port number: 179), DHCPv6 (UDP port number: 546 and 547), LDP (TCP port number: 646), and BFD (UDP port number: 3784 and 4784)

Example

# Enable security policy control for basic protocols.
<HUAWEI> system-view
[HUAWEI] firewall packet-filter basic-protocol enable
