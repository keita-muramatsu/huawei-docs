nat gratuitous-arp send

Function

The nat gratuitous-arp send command configures the device to send gratuitous ARP packets.

Format

nat gratuitous-arp send

Parameters

None

Views

10GE sub-interface view, 10GE interface view, 40GE sub-interface view, 40GE interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, GE sub-interface view, GE interface view, VLANIF interface view

Default Level

2: Configuration level

Usage Guidelines

If a peer device does not receive any gratuitous ARP packets from the device, you can run the nat gratuitous-arp send command to configure the device to send gratuitous ARP packets to the peer. The nat gratuitous-arp send command takes effect only once after being executed.

Example

# Configure the device to send gratuitous ARP packets.
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] nat gratuitous-arp send
