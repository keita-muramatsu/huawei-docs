display firewall log

Function

The display firewall log command displays the configuration and statistics of session logs.

Format

display firewall log statistic [ verbose ] [ host host-id [ secondary ] ]

display firewall log configuration [ host host-id [ secondary ] ]

Parameters

Parameter Description Value
verbose

Displays details on statistics about session logs, packet discard logs, and service logs.

-
host host-id

ID of the log host.

The value is an integer ranging from 1 to 16.
secondary

Specifies that the log server belongs to the second group of log hosts.

-
configuration

Displays the configuration of logs.

-
statistic

Displays statistics about session logs, packet discard logs, and service logs.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

To display the configuration and statistics of logs, run the display firewall log command.

Precautions

The vsys parameter in this command cannot be configured in the vsys view.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the configuration of session logs. 
<HUAWEI> display firewall log configuration
 Session  log state:   Enable
 Session  log type:  Binary 
 Log send-type:  default
 Log source:  10.10.10.1:1617 
 Session global log: Enable
 Session aged log:  Enable
 Log host  1: 192.168.2.1:9002
 Log host  3: 192.168.3.1:2555
 Binary nat-nopat:  Disable
 Session filter:    Disable/NAT
Table 1 Description of the display firewall log command output
Item Description
Session log state

Status of session logging function.

  • Enable.
  • Disable.
Session log type

Session log type.
Session aged log

Status of session aging log sending, which can be:

  • Enable.
  • Disable.
Session filter

Function of sending NATed logs.

  • Enable: indicates that the function is enabled.
  • Disable: indicates that the function is disabled.
Session global log

Status of the function of recording session logs globally.

  • Enable.
  • Disable.
Log send-type

Mode for sending session logs.

  • default: Concurrent log sending is disabled.
  • concurrent: Concurrent log sending is enabled.
Log source

Source IP address and port for sending logs.
Log host

Log server IP.
binary nat-nopat

Status of binary NO-PAT session log sending, which can be:

  • Enable.
  • Disable.
Total send packets

Total number of packets sent to the log server.
Total send Items

Total number of sessions sent to the log server.
Total send Items during last minute

Total number of sessions sent to the log server in the last minute.
Acl 3000 send items

Total number of sent sessions about ACL3000 reported to the log server.

If the function of collecting ACL-based statistics on sent and discarded session logs is configured, the ACL information is displayed. Otherwise, the ACL information is not displayed.
Acl 3000 drop items

Total number of discarded sessions about ACL3000 reported to the log server.
