station connectivity-detect disable

Function

The station connectivity-detect disable command disables STA connectivity check on an AP.

The undo station connectivity-detect disable command enables STA connectivity check on an AP.

By default, STA connectivity check is enabled on an AP.

Format

station connectivity-detect disable

undo station connectivity-detect disable

Parameters

None

Views

AP system profile view

Default Level

2: Configuration level

Usage Guidelines

To locate network access faults of some STAs, the AP has STA connectivity check enabled by default. The AP randomly selects two of STAs that have associated with the AP for more than 20 seconds and encountered traffic exceptions (The STAs can obtain IP addresses and the default gateway, but has no uplink or downlink unicast traffic). The AP then detects network connectivity by pinging these two STAs and records the result in the log.

Example

# Disable STA connectivity check.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name default
[HUAWEI-wlan-ap-system-prof-default] station connectivity-detect disable
