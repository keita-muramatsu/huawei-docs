eva fault-detect fault-mode

Function

The eva fault-detect fault-mode command enables or disables the fault mode detection function.

The undo eva fault-detect fault-mode command restores the default configuration of the fault mode detection function.

By default, the default status varies according to the fault mode. For details, run the display eva fault manager verbose command and check the DefaultStatus field in the command output.

Format

eva fault-detect fault-mode faultMode { disable | enable }

undo eva fault-detect fault-mode faultMode { disable | enable }

Parameters

Parameter Description Value
faultMode

Specifies the fault mode name.

The value is a string of 1 to 63 characters.

  • board-abnormal: indicates that the board temperature is abnormal.
  • power-abnormal: indicates that the power supply is abnormal.
  • np-drop: indicates the NP packet loss fault mode.
  • fan-abnormal: indicates the fan fault mode.
  • board-channel-abnormal: indicates that the board channel is abnormal.
  • board-temperature-abnormal: indicates that the board temperature is abnormal.
  • board-unregister-long-time: The specified board is not registered for a long time.
  • card-abnormal: indicates the subcard fault mode.
  • chassis-abnormal: indicates that the entire chassis is abnormal.
  • file-system-abnormal: specifies the file system exception fault mode.
  • filehandle-usage-exceeded: specifies the file handle overload fault mode.
  • flow-control-deadlock: specifies the flow control deadlock fault mode.
  • inbound-port-traffic: indicates the fault mode of traffic congestion in the inbound direction of an interface.
  • local-port-fault: indicates the fault mode of the local port.
  • network-cables-poor-signal: indicates that the network cable signal quality is poor.
  • optical-module-abnormal: indicates that the optical module is abnormal.
  • outbound-port-traffic: indicates the fault mode of traffic congestion in the outbound direction of an interface.
  • peer-port-fault: specifies the fault mode of the peer port.
  • port-abnormal: indicates the abnormal fault mode of a port.
  • port-crc-error: CRC error packets on a port.
  • port-half-duplex: indicates the half-duplex fault mode of a port.
  • pre-fec-threshold-exceeded: specifies the pre-FEC BER threshold-crossing fault mode.
  • optical-link-dirty: indicates that the optical link is dirty.
  • optical-link-loose: indicates that the optical link is loose.
  • optical-module-rx-abnormal: indicates the fault mode where the optical module receives optical signals abnormally.
  • main-optical-fiber-fault: indicates the pattern of the main optical fiber fault.
  • optical-module-life-warning: indicates the pattern of the optical module lifespan warning fault.
disable

Disables the function.

-
enable

Enables the function.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

EVA automatically subscribes to and analyzes alarm data and internal data (KPI data for short) of related modules to detect faults on these modules. EVA can detect faults based on the fault modes, each representing a specific type of faults. You can run the eva fault-detect fault-mode command to enable or disable a specific fault mode based on service requirements.

Example

# Disable the power-abnormal fault mode detection function.
<HUAWEI> system-view
[HUAWEI] eva fault-detect fault-mode power-abnormal disable
