server-detect type

Function

The server-detect type command sets the mode in which the device detects the Portal server.

The undo server-detect type command restores the default mode in which the device detects the Portal server.

By default, the device detects the Portal server in Portal mode.

Format

server-detect type { portal | http }

undo server-detect type

Parameters

Parameter Description Value
portal

Sets the mode in which the device detects the Portal server to Portal.

-
http

Sets the mode in which the device detects the Portal server to HTTP.

-

Views

Web-auth-server template view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In Portal-based Portal server detection: The Portal server periodically sends Portal heartbeat packets to the access device. If the access device receives Portal heartbeat packets or other authentication packets from the Portal server within the detection period specified using the server-detect interval interval-period command, the detection is successful and the access device considers that the Portal server is reachable and in up state. Otherwise, the detection fails. When the number of consecutive detection failures exceeds the maximum value (specified using the server-detect max-times times command), the access device changes the status of the Portal server from up to down.

In HTTP-based Portal server detection: The access device periodically sends HTTP packets to the Portal server at an interval of 10s and expects a response from the Portal server. If the access device receives a response within the detection period (specified using the server-detect interval interval-period command), the detection is successful. Otherwise, the detection fails. When the number of consecutive detection failures exceeds the maximum value (specified using the server-detect max-times times command), the access device changes the status of the Portal server from up to down.

In Portal-based Portal server detection, the Portal server must use the Portal protocol and support the function of sending Portal heartbeat packets. If the Portal server does not meet the conditions for Portal-based server detection, you can configure HTTP-based server detection. After detecting that the server is down, the device can perform server down authorization for new access users in a timely manner.

Precautions

HTTP-based Portal server detection applies to wired scenarios of MAC+Portal address.

Example

# Set the mode in which the device detects the Portal server to HTTP.
<HUAWEI> system-view
[HUAWEI] web-auth-server abc
[HUAWEI-web-auth-server-abc] server-detect type http
