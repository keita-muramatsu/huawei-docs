mpls-exp-outbound

Function

The mpls-exp-outbound command configures the EXP value corresponding to the class of service and color of a downstream MPLS packets in the current domain.

The undo mpls-exp-outbound command restores the default mapping from the class of service to the EXP value.

By default, the mappings from internal CoSs and colors to EXP values are shown in Table 1 in Usage Scenario.

Format

mpls-exp-outbound service-class color map exp-value

undo mpls-exp-outbound [ service-class color ]

Parameters

Parameter Description Value
service-class

Specifies the service class.

The value can be:

  • be
  • af1
  • af2
  • af3
  • af4
  • ef
  • cs6
  • cs7
color

Specifies the packet color.

The value can be:

  • green
  • yellow
  • red
map exp-value

Specifies the EXP value.

The value is an integer that ranges from 0 to 7.

Views

DiffServ domain view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

For packets leaving the DS domain, you need to run this command to configure the mapping between the internal class of service and color of the MPLS packet and the EXP value of the packet.

Table 1 Default mappings between EXP values and internal class of service

Service Color EXP
be green/yellow/red 0
af1 green/yellow/red 1
af2 green/yellow/red 2
af3 green/yellow/red 3
af4 green/yellow/red 4
ef green/yellow/red 5
cs6 green/yellow/red 6
cs7 green/yellow/red 7

Precautions

If service-class and color are not specified in the undo mpls-exp-outbound command, all the default mappings from PHBs and colors to EXP values are restored.

Example

# Set the EXP value of the downstream MPLS packets with the CoS being AF1 and color being green to 5.
<HUAWEI> system-view
[HUAWEI] diffserv domain d1
[HUAWEI-dsdomain-d1] mpls-exp-outbound af1 green map 5
