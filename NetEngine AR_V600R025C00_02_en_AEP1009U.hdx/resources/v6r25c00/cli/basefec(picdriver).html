fec mode base-r

Function

The fec mode base-r command enables the Base-R FEC function on an interface.

The undo fec mode base-r command restores the default FEC function on an interface.

By default, the Base-R FEC status depends on the medium type and auto-negotiation status.

Format

fec mode base-r

undo fec mode base-r

Parameters

None

Views

25GE-L2 view, 25GE interface view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Base-R FEC is a bit error correction mode. In this mode, error correction information is added to data packets at the transmit end, and the error correction information is used at the receive end to correct bit errors generated during data packet transmission. You can enable the Base-R FEC function to improve signal quality.

You can run the display interface command in any view or the display this interface command in the interface view to check the FEC status on the interface.

When two interfaces are connected, ensure that the FEC status on both ends of the link is the same. One end must be Base-R FEC, and the other end must also be Base-R FEC.

Precautions

  • If this function is enabled on one end of a link, it must also be enabled on the other end of the link, and the FEC modes at both ends must be the same.
  • This command cannot be used together with the loopback internal command.
  • FEC configuration is mutually exclusive with auto-negotiation and interface rate configuration.
  • When interfaces are interconnected using 25GE media, you are advised to enable the FEC function on both ends of the physical link to reduce its transmission bit error rate. If this is not done, error packets may be generated.
  • A 25GE interface supports this command only when a supported 25GE medium is installed or pre-configured on the interface.

Example

# Enable the Base-R FEC function on 25GE0/0/1.
<HUAWEI> system-view
[HUAWEI] interface 25ge 0/0/1
[HUAWEI-25GE0/0/1] fec mode base-r
