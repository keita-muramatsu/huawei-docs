url (URL template view)

Function

The url command configures a redirect URL or pushed URL for the Portal server.

The undo url command cancels the redirect URL or pushed URL of the Portal server.

By default, no redirect URL or pushed URL is configured for the Portal server.

Format

url [ push-only | redirect-only ] url-string

url [ push-only | redirect-only ] url-string ssid ssid

undo url [ push-only | redirect-only ]

undo url [ push-only | redirect-only ] ssid ssid

Parameters

Parameter Description Value
push-only url-string

Specifies the URL to be pushed.

The value is a string of case-sensitive characters. It can contain spaces.
redirect-only url-string

Specifies the redirect URL of the Portal server.

The value is a string of case-sensitive characters. It can contain spaces.
ssid ssid

Specifies the SSID associated with a specified user.

This parameter applies only to wireless access users. The SSID of the user must be the same as that configured on the device. Otherwise, the URL cannot be pushed to the user.

The value is a string of 1 to 32 characters. It can contain spaces.

Views

URL template view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After a URL template is created using the url-template name command, you can run this command to configure the redirect URL or pushed URL of the Portal server. The differences between the redirect URL and pushed URL of the Portal server are as follows:

Redirect URL: When a user without network access permission attempts to access the network, the access device that has Portal authentication enabled redirects the user to the redirect URL for authentication.

Pushed URL: URL of the web page that the access device pushes to an authenticated user. That is, the user's web access request is redirected to the specified URL, and then the user can access network resources.

Precautions

If push-only and redirect-only are not specified, the configured URL can be used as both the redirect URL and pushed URL of the Portal server. You can run the force-push command to configure the pushed URL function or run the url-template (Portal server template view) command to bind a URL template to the Portal server template to implement the redirect URL function.

Example

# Set the redirect URL of the Portal server to http://10.1.1.1.
<HUAWEI> system-view
[HUAWEI] url-template name test
[HUAWEI-url-template-test] url http://10.1.1.1
