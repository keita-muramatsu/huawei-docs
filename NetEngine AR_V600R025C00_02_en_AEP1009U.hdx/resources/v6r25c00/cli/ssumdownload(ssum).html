download software

Function

The download software command downloads a version software.

By default, the software package required for the upgrade is downloaded.

Format

download software [ version software-version ]

download software [ system-software ] [ patch ] [ feature-software { feature-name } &<1-9> ]

Parameters

Parameter Description Value
version software-version

Specifies the software package version.

  • If this parameter is specified, the software package of the specified version is downloaded from the HOUP platform.
  • If this parameter is not specified, all software packages (basic software packages, patch packages, and feature packages) are downloaded from the HOUP platform.

The value is a string of 1 to 63 case-sensitive characters, spaces not supported.
system-software

Specifies the basic software package.

  • If this parameter is specified, the basic software package of the new version is downloaded from the HOUP platform.
  • If this parameter is not specified, the basic software package of the new version is not downloaded from the HOUP platform.

The value is a keyword.
patch

Specifies the patch software package.

  • If this parameter is specified, the patch software package of the new version is downloaded from the HOUP platform.
  • If this parameter is not specified, the patch software package of the new version is not downloaded from the HOUP platform.

The value is a keyword.
feature-software feature-name

Specifies the feature package list.

  • If this parameter is specified, all specified feature packages are downloaded from the HOUP platform.
  • If this parameter is not specified, the feature packages are not downloaded from the HOUP platform.

The value is a string of 1 to 127 case-sensitive characters. It cannot contain spaces.

Views

Smart upgrade view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

Smart upgrade supports two modes: scheduled smart upgrade and manual smart upgrade. If the scheduled upgrade time has not arrived or you need to manually trigger smart upgrade, run the check new-version command to check whether the new system software is available. If it is available, run the download software command to download the software to the local PC for future upgrade. This is to improve upgrade efficiency. After the software is downloaded, you can trigger the upgrade according to the scheduled upgrade policy or run the upgrade right-now command to upgrade the system immediately.

If you want to download the feature package to be installed from the HOUP, you are advised to run the display smart-upgrade information command to query the version number of the feature package. The queried version number is used as the value of the version <software-version> parameter.

Ensure that an SSL policy has been configured before running this command. For details, see Configuration Guide > System Management Configuration > Upgrade Maintenance Configuration > Configuring Smart Upgrade.

Follow-up Procedure

If you run the download software version <software-version> command to download a feature package that has not been installed from the HOUP platform, you can run the install feature-software command in the user view to install the feature package.

If you run the download software system-software patch feature-software <feature-name> command in the user view to download a basic software package, patch package, or feature package that has not been installed from the HOUP platform, you can perform the following operations in the user view:

  • Run the startup system-software command to specify the next-startup basic software package.
  • Run the install feature-software command to install the feature package.
  • Run the patch load all run command to install the patch package.

Precautions

This command will connect the device to the Internet.
