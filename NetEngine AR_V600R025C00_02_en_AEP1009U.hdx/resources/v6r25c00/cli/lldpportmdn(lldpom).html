lldp mdn

Function

The lldp mdn enable command enables MDN on an interface.

The lldp mdn disable command disables MDN on an interface.

The undo lldp mdn command restores the MDN configuration on an interface to be the same as the global MDN configuration.

By default, the value is the same as the global MDN configuration.

Format

lldp mdn enable

lldp mdn disable

lldp mdn enable { rx | txrx }

undo lldp mdn enable

undo lldp mdn disable

undo lldp mdn enable { rx | txrx }

Parameters

Parameter Description Value
disable

Disables MDN.

-
enable

Enables MDN.

-
rx

Indicates that MDN works in Rx mode. In this mode, the device can only receive non-standard discovery protocol packets from neighbors.

-
txrx

Indicates that MDN works in Tx and Rx mode. In this mode, the device can send non-standard discovery protocol packets to and receive non-standard discovery protocol packets from neighbors.

-

Views

Layer 2 10GE interface view, 10GE interface view, 25GE-L2 view, 25GE interface view, Layer 2 40GE interface view, 40GE interface view, Ethernet interface view, Layer 2 GE interface view, GE optical interface view, GE sub-interface view, GE interface view, GE electrical interface view, Layer 2 multi-GE interface view, Multi-GE interface view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If the neighbor node uses a non-standard discovery protocol of another vendor instead of LLDP, run the lldp mdn enable txrx command to enable MDN globally to ensure that the local device can establish a neighbor relationship with the neighbor node. If you want the local device to discover only its neighbors, run the lldp mdn enable rx command.

After MDN is enabled, the TLVs that can be encapsulated include Device ID, Port ID, Capabilities, Platform, Native VLAN, Voice VLAN, and Power Available TLVs.

Prerequisites

LLDP has been enabled globally using the lldp enable command in the system view.

Configuration Impact

After MDN is disabled on an interface, the interface cannot receive non-standard discovery protocol packets. As a result, the device cannot discover MDN neighbors, affecting the drawing of the network topology.

Precautions

The lldp mdn enable command is used to be compatible with earlier versions. It is no longer recommended for use. After the lldp mdn enable command is run, the lldp mdn enable rx command takes effect.

After the lldp mdn disable command is run to disable MDN on an interface, you can run the undo lldp mdn disable or lldp mdn enable command on the interface to enable MDN again. The differences between the undo lldp mdn disable and lldp mdn enable commands are as follows:

After the undo lldp mdn disable command is run on an interface, the MDN function on the interface adopts the global configuration policy.

After the lldp mdn enable command is run on an interface, the MDN function on the interface adopts the configuration policy of the interface.

After MDN is enabled globally, all interfaces on the device can receive non-standard discovery protocol packets sent by neighbors and identify neighbors based on source MAC addresses and port names of the packets. This increases the consumption of system resources and affects the normal running of user services. You can run the lldp mdn disable command on a specified interface to disable MDN on the interface.

The MDN function adopts the most accurate matching principle.

If MDN is configured both globally and on an interface, the configuration policy on the interface takes effect.

If MDN is not configured on an interface, the global configuration policy takes effect.

If MDN is not configured globally, the MDN configuration on the interface takes effect.

If MDN is configured both globally and on an interface and the undo lldp mdn enable command is run on the interface, the global configuration policy takes effect on the interface and MDN is still enabled. To completely disable MDN on the interface, run the lldp mdn disable command on the interface.

Example

# Enable MDN on an interface. 
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] lldp mdn enable txrx
# Disable MDN on an interface 
<HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/1
[HUAWEI-10GE0/0/1] undo lldp mdn enable txrx
