ap lldp disable

Function

The ap lldp disable command disables LLDP in the WLAN view.

The undo ap lldp disable command enables LLDP in the WLAN view.

By default, LLDP is enabled in the WLAN view.

Format

ap lldp disable

undo ap lldp disable

Parameters

None

Views

WLAN view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

LLDP is a Layer 2 discovery protocol defined in the IEEE 802.1ab standard. Using LLDP, the AC or NMS can obtain Layer 2 information about the connected APs, including APs' interfaces and connections with other devices. Additionally, the AC or NMS can obtain details about network topology information and interface changes. To view the Layer 2 link status between APs, and between APs and switch or analyze the network topology, enable WLAN LLDP.

Precautions

WLAN LLDP can be enabled globally or in the AP wired port link profile view.

  • An AP can send and receive LLDPDUs only after LLDP is enabled in both the WLAN view and the AP wired port link profile view.
  • After LLDP is disabled in the WLAN view, the commands for enabling and disabling LLDP on the AP wired port link profile view do not take effect.

Example

# Disable LLDP in the WLAN view.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap lldp disable
