port combination-mode interface

Function

The port combination-mode interface command changes the working mode of an interface.

The undo port combination-mode interface command restores the default working mode of an interface.

By default, the working mode of an interface is not changed.

Format

port combination-mode 10GE interface { { interface-name1 | interface-type1 interface-number1 } [ to { interface-name2 | interface-type2 interface-number2 } ] } &<1-12>

undo port combination-mode 10GE interface { { interface-name1 | interface-type1 interface-number1 } [ to { interface-name2 | interface-type2 interface-number2 } ] } &<1-12>

Parameters

Parameter Description Value
10GE

Changes the working mode of a 2.5GE/10GE multiplexing interface from 2.5GE to 10GE.

-
{ interface-name1 | interface-type1 interface-number1 } [ to { interface-name2 | interface-type2 interface-number2 } ]

Specifies the interface whose working mode is to be switched:

  • interface-name: specifies the interface name, in the format of interface-typeinterface-number.
  • interface-type: specifies the interface type. interface-type1 and interface-type2 must be of the same type.
  • interface-number: specifies the interface number. interface-number2 must be greater than interface-number1.
  • to: indicates the interface range, covering all interfaces between two given numbers.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Some devices have multiplexing interfaces, meaning that only one type of interface takes effect at a time. For example, an interface on a device supports m/nrate mode multiplexing and works at the mrate by default. In this case, the interface working at the nrate cannot be queried on the device. For such devices, if interfaces working at the nrate are required, you can run this command to change the interface working mode. (Note: mand nindicate the interface rates.)

Precautions

  • After an interface is added to an Eth-Trunk interface, the working rate of the interface cannot be changed using this command. To change the working rate of the interface, remove it from the Eth-Trunk interface first.
  • After a sub-interface is created on an interface, the working rate of the interface cannot be changed using this command. To change the working rate of the interface, remove the sub-interface first.
  • Only the AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T1XWE, AR5710-S10T1X2, and AR5710-S8T2XE support this command.

Example

# Switch the working mode of MultiGE0/0/0 and MultiGE0/0/1 to 10GE.
<HUAWEI> system-view
[HUAWEI] port combination-mode 10GE interface MultiGE0/0/0 to MultiGE0/0/1
