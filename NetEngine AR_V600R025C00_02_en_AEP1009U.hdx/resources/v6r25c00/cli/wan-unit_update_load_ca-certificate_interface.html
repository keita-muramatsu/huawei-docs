wan-unit update load ca-certificate interface

Function

The wan-unit update load ca-certificate interface command upgrades the CA certificate of a specified WAN unit.

Format

wan-unit update load ca-certificate interface { interface-name | ifType ifNum } file-name ip-address ip-address username username password password

Parameters

Parameter Description Value
file-name

Name of the CA certificate.

The value is a string of 1 to 127 case-sensitive characters, spaces not supported.
ip-address ip-address

Specifies the IP address of the SFTP server.

The value is in dotted decimal notation.
username username

Specifies the username for logging in to the SFTP server.

The value is a string of 1 to 63 case-sensitive characters. It cannot contain spaces.
password password

Specifies the password for logging in to the SFTP server.

The value is a string of 8 to 128 case-sensitive characters. It can contain letters and digits. If the string is enclosed in double quotation marks (" "), it can contain spaces.
interface interface-name

Specifies the name of the interface connecting to the RU.

The value is a string of 1 to 63 case-sensitive characters. It cannot contain spaces.
interface ifType ifNum

Specifies the type and number of the interface connecting to the RU.

The value depends on the device. You can enter a question mark (?) and select a value from the displayed value range.

Views

User view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

During routine device maintenance, you can run this command to configure SFTP server parameters and obtain a CA certificate from the SFTP server to upgrade the CA certificate of a specified WAN unit.

Follow-up Procedure

After running the CA certificate upgrade command, you need to run the reset wan-unit interface command to restart the WAN unit connected to the specified interface for the upgraded CA certificate to take effect.

Precautions

  • During the upgrade of the WAN unit, do not remove or insert the Ethernet cable, and ensure that the WAN unit is not powered off. Otherwise, the upgrade fails and the WAN unit may be unavailable.
  • After the CA certificate is downloaded to the WAN unit, the CA certificate is not updated immediately. The new certificate is loaded upon the next startup.
  • Currently, no method is available to notify users of the expiration of the WAN unit certificate. You need to identify the expiration in advance.
  • An unregistered WAN unit cannot be upgraded.
  • A WAN unit that is being restarted cannot be upgraded.
  • The upgrade status of the WAN unit can be:
    • Idle
    • Upgrading
    • Updated
    • Failed
  • The upgrade status of the WAN unit changes to Idle 5 minutes after the WAN unit is upgraded successfully or fails to be upgraded.
  • If the upgrade status of the WAN unit is Upgrading or Failed, the upgrade cannot be performed again before the upgrade status changes to Idle.

Example

# Upgrade the CA certificate of the WAN unit on 10GE1/0/1.
<HUAWEI> wan-unit update load ca-certificate interface 10GE1/0/1 ca.pem ip-address 192.168.0.10 username user password YsHsjx_202206
Warning: This operation will update the CA certificates. After the operation is successful, manually reboot the WAN unit for the CA certificate to take effect. Continue? [Y/N]
