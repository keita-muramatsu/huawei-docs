address-mode (AP view/AP provisioning view)

Function

The address-mode command sets the mode in which an AP obtains an IP address.

The undo address-mode command restores the default mode in which an AP obtains an IP address.

By default, the mode in which an AP obtains an IP address is not configured.

Format

address-mode { dhcp | static }

address-mode slaac

undo address-mode

Parameters

Parameter Description Value
dhcp

Indicates the DHCP IP address allocation mode. The AP functions as a DHCP client and is assigned an IP address by the DHCP server.

-
static

Indicates the static IP address allocation mode. The AP must be configured with a static IP address.

-
slaac

Indicates that an IP address is obtained in stateless address autoconfiguration (SLAAC) mode. Only IPv6 addresses can be obtained through SLAAC.

-

Views

AP provisioning view, AP view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

You can run the address-mode command to configure an AP to obtain an IP address in DHCP, static, or SLAAC mode.

Follow-up Procedure

After running this command in the AP provisioning view, run the commit command to deliver the configuration to the AP. The configuration takes effect only after the AP restarts.

Precautions

After the configuration is delivered, restart the APs to make the configuration take effect.

To prevent the APs from using the configuration delivered using the commit command, run the undo address-mode command in the AP provisioning view.

Example

# Configure an AP to obtain an IP address in DHCP mode in the AP provisioning view.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] provision-ap
[HUAWEI-wlan-provision-ap] address-mode dhcp
# Configure an AP to obtain an IP address in DHCP mode in the AP view.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-id 0
[HUAWEI-wlan-ap-0] address-mode dhcp
Warning: The incorrect configuration will cause the AP to go out of management. This operation will deliver parameter setting and may cause reboot of AP(s). Continue?[Y/N]:y
