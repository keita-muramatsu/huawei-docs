vap-profile(AP view/AP group view)

Function

The vap-profile command binds a VAP profile to a radio.

The undo vap-profile command unbinds a VAP profile from a radio.

By default, no VAP profile is applied to a radio.

Format

vap-profile profile-name wlan wlan-id radio { radio-id | all } [ service-vlan vlan-id vlan-id-value ]

undo vap-profile profile-name wlan wlan-id radio { radio-id | all }

Parameters

Parameter Description Value
profile-name

Specifies the name of a VAP profile.

The VAP profile must exist.
wlan wlan-id

Specifies a VAP ID.

The value is an integer ranging from 1 to 16.

  • The WLAN ID for the Mesh service is 16.
  • The WLAN ID for the offline management VAP configuration is 15 or an integer ranging from 1 to 12.
radio

Specifies a radio.

-
radio-id

Specifies a radio ID.

The value is an integer ranging from 0 to 4.
all

Specifies all radios.

-
service-vlan

Specifies a service VLAN.

-
vlan-id vlan-id-value

Specifies a VLAN ID.

The VLAN ID must exist.

Views

AP group view, AP view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After you create a VAP profile using the vap-profile (WLAN view) command, bind it to a radio so that the VAP profile can take effect.

In some scenarios, users want to configure one VAP for all APs. However, APs use different service VLANs. To simplify the configuration, you can use the service-vlan parameter to define a service VLAN when binding the VAP profile. The priority of the user-defined service VLAN is higher than that of the service VLAN configured using the service-vlan command.

Follow-up Procedure

Run the vap-profile command in the AP group view, AP view, AP radio view, or AP group radio view to apply the VAP profile so that the VAP profile can take effect.

Precautions

After a VAP profile is applied to a radio, parameter settings in the VAP profile take effect on the radio using the VAP profile.

Example

# Create the VAP profile vap1 and apply the VAP profile to the AP group group1.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] vap-profile name vap1
[HUAWEI-wlan-vap-prof-vap1] quit
[HUAWEI-wlan] ap-group name group1
[HUAWEI-wlan-ap-group-group1] vap-profile vap1 wlan 1 radio 0
