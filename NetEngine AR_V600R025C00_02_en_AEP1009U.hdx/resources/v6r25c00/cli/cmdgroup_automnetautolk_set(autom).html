auto-link eth-trunk-mode(Net-assistant network view)

Function

The auto-link eth-trunk-mode command configures network-wide Eth-Trunk auto-negotiation.

The undo auto-link eth-trunk-mode command restores the default setting of network-wide Eth-Trunk auto-negotiation.

By default, network-wide Eth-Trunk auto-negotiation is disabled.

Format

auto-link eth-trunk-mode { close | open | lock }

undo auto-link eth-trunk-mode

Parameters

Parameter Description Value
close

Disables Eth-Trunk auto-negotiation.

-
open

Enables Eth-Trunk auto-negotiation.

-
lock

Locks Eth-Trunk auto-negotiation.

-

Views

Net-assistant network view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

Eth-Trunk increases the link bandwidth by bundling a group of physical interfaces into a single logical interface, without needing to upgrade hardware. Eth-Trunk also greatly improves link reliability through link backup.

After the auto-negotiation function is enabled using the command, devices exchange LLDP packets carrying auto-negotiation capabilities. Based on the neighbor information, the devices automatically negotiate interface information and generate Eth-Trunk configurations. No manual Eth-Trunk configuration is required.

  • If the open parameter is specified, network-wide Eth-Trunk auto-negotiation is enabled.
  • If the lock parameter is specified, network-wide Eth-Trunk auto-negotiation is locked. In this case, no new physical interface can be added to the Eth-Trunk interface.
  • If the close parameter is specified, network-wide Eth-Trunk auto-negotiation is disabled. In this case, physical interfaces on all devices on the network cannot be added to the Eth-Trunk interface.

Precautions

After network-wide Eth-Trunk auto-negotiation is enabled on the master device, the configuration is automatically delivered to all member devices and takes effect on them.

Example

# Lock Eth-Trunk auto-negotiation.
<HUAWEI> system-view
[HUAWEI] net-assistant
[HUAWEI-net-assistant] network
[HUAWEI-net-assistant-network] auto-link eth-trunk-mode lock
