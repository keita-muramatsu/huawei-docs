user-sync (Web-auth-server template view)

Function

The user-sync command enables Portal authentication user information synchronization.

The undo user-sync command disables Portal authentication user information synchronization.

By default, Portal authentication user information synchronization is disabled.

Format

user-sync [ interval interval-period | max-times times ] *

undo user-sync

Parameters

Parameter Description Value
interval interval-period

Specifies the user information synchronization interval.

The value is an integer ranging from 30 to 65535, in seconds. The default value is 300s.
max-times times

Specifies the maximum number of user information synchronization failures.

The value is an integer that ranges from 2 to 255. The default value is 3.

Views

Web-auth-server template view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In Portal authentication, if communication between the device and Portal server is interrupted due to a network failure or Portal server failure, online Portal authentication users cannot go offline as expected. As a result, user information on the device may be different from that on the Portal server, causing inaccurate accounting.

After you run the user-sync command to enable user information synchronization on the device, user information on the device is synchronized with that on the Portal server to ensure user information consistency.

During user information synchronization, if information about a user exists on the device but does not exist on the server, the device does not disconnect the user immediately. Instead, the device disconnects the user only when the number of user information synchronization failures reaches the maximum.

Precautions

For users who go online during the Portal bypass period, the Portal server does not have their entries. When user information is synchronized after the Portal server goes Up, the device does not disconnect these users even if the synchronization fails. Portal authentication is performed for these users when they go online next time, ensuring consistent user experience.

The value of interval-period*times configured on the device must be greater than the interval at which the Portal server sends synchronization packets. Otherwise, the device may disconnect users when it cannot receive synchronization packets from the Portal server after the maximum number of synchronization failures is reached.

When running the user-sync command, ensure that the Portal server supports this function. Otherwise, users will be disconnected.

Example

# Enable user information synchronization in the Portal server template abc, and set the user information synchronization interval to 100 seconds and the maximum number of user information synchronization failures to 5.
<HUAWEI> system-view
[HUAWEI] web-auth-server abc
[HUAWEI-web-auth-server-abc] user-sync interval 100 max-times 5
