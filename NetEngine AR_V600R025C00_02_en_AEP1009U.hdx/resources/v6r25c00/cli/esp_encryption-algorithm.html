esp encryption-algorithm

Function

The esp encryption-algorithm command configures an encryption algorithm for a P2MP policy.

The undo esp encryption-algorithm command restores the default encryption algorithm.

By default, the encryption algorithm is AES-256-GCM.

Format

esp encryption-algorithm { aes-128 | aes-256 | aes-128-gcm | aes-256-gcm | sm4 }

undo esp encryption-algorithm [ aes-128 | aes-256 | aes-128-gcm | aes-256-gcm | sm4 ]

Parameters

Parameter Description Value
aes-128

Indicates the AES-128 algorithm.

-
aes-256

Indicates the AES-256 algorithm.

-
aes-128-gcm

Indicates the AES-128-GCM algorithm.

-
aes-256-gcm

Indicates the AES-256-GCM algorithm.

-
sm4

Indicates the SM4 algorithm.

-

Views

IPSec P2MP policy view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To configure an encryption algorithm for a P2MP policy, run the esp encryption-algorithm command. After entering the P2MP policy view, you can configure an encryption algorithm.

Precautions

To restore the default encryption algorithm, run the undo esp encryption-algorithm command.

Example

# Configure encryption algorithm AES-128 for a P2MP policy.
<HUAWEI> system-view
[HUAWEI] ipsec p2mp-policy aa
[HUAWEI-ipsec-p2mp-policy-aa] esp encryption-algorithm aes-128
