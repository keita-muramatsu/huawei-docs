display license emergency

Function

The display license emergency command is used to view information about emergency mode.

Format

display license emergency

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

To check information about the emergency mode, run the display license emergency command. The information includes the emergency mode activation status, remaining usage times, remaining usage days, list of control items that support the emergency mode, and activation values.

In emergency mode, the device runs with the maximum specifications of existing dynamic resource and function items. This mode can be considered as a temporary mode when license control items are not under restriction.

The emergency mode can be enabled up to three times, lasting for a maximum of seven days each time, for each version.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display running information about the emergency mode.
<HUAWEI> display license emergency
 License emergency status          : Enable
 Remain times                      : 2
 Remain days                       : 6

 Feature-name        Value     Description
 ------------------------------------------------------------
 *****TO***          20        *** Function License

Remain times

Residual activation number.
Remain days

The remaining number of days of emergency mode activation.
