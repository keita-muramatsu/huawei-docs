calibrate reference data-analysis(AP radio view/AP group radio view)

Function

The calibrate reference data-analysis disable command disables the big data-based calibration function on the radio interfaces of APs and AP groups.

The calibrate reference data-analysis enable command enables the big data-based calibration function on the radio interfaces of APs and AP groups.

The undo calibrate reference data-analysis command restores the default state of the big data-based calibration function on the radio interfaces of APs and AP groups.

By default, the big data-based calibration function is enabled in the AP group radio view, but is not configured in the AP radio view.

Format

calibrate reference data-analysis { enable | disable }

undo calibrate reference data-analysis

Parameters

Parameter Description Value
enable

Enables the big data-based calibration function.

-
disable

Disables the big data-based calibration function.

-

Views

AP radio view, AP group radio view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After big data-based calibration is enabled, the device performs calculation based on the variations in interference and load according to Big Data information obtained from iMaster NCE-CampusInsight. This function helps better avoid interference and improve network capacity. If the big data-based calibration function is disabled, radio calibration is performed based only on the locally collected data.

Precautions

Big data-based calibration takes effect on an AP only when the following configurations are performed:

• Configure the function of reporting KPIs to the Big Data analyzer.

• Enable radio calibration.

• Enable the global big data-based calibration function by using the undo calibrate reference data-analysis command in the WLAN view.

• Enable the big data-based calibration function on the AP. (If the big data-based calibration function is not configured on a single AP, the configuration of the AP group takes effect.)

Example

# Enable the big data-based calibration function.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-group name default
[HUAWEI-wlan-ap-group-ap-group1] radio 0
[HUAWEI-wlan-ap-group-ap-group1-radio-0] calibrate reference data-analysis enable
