isis hello padding-mtu

Function

The isis hello padding-mtu command enables an interface to send Hello packets with the padding field.

The undo isis hello padding-mtu command restores the default setting.

By default, P2P interfaces exchange Hello packets with the padding field and set the length of the Hello packets to that of locally generated LSPs before establishing neighbor relationships with each other. After neighbor relationships are established, the P2P interfaces exchange small Hello packets (without the padding field). By default, broadcast interfaces exchange Hello packets with the padding field and set the length of the Hello packets to their IPv4 MTU values.

Format

isis hello padding-mtu { ipv4 | ipv6 }

undo isis hello padding-mtu [ ipv4 | ipv6 ]

Parameters

Parameter Description Value
ipv4

Indicates that the Hello packets sent by IS-IS carry the padding field and that the length of the Hello packets is set to the IPv4 MTU value of the interface.

-
ipv6

Indicates that the Hello packets sent by IS-IS carry the padding field and that the length of the Hello packets is set to the IPv6 MTU value of the interface.

-

Views

10GE sub-interface view, 10GE interface view, 25GE sub-interface view, 25GE interface view, 40GE interface view, Cellular channel interface view, Eth-Trunk sub-interface view, Eth-Trunk interface view, Ethernet interface view, GE optical interface view, GE sub-interface view, GE electrical interface view, IP-Trunk interface view, Loopback interface view, MP-group interface view, POS interface view, Tunnel interface view, VLANIF interface view, 40GE sub-interface view, Ethernet sub-interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

By default, P2P and broadcast interfaces send IS-IS Hello packets based on the following rules:

  • P2P interfaces: P2P interfaces send Hello packets with the padding field and set the length of the Hello packets to that of locally generated LSPs before establishing neighbor relationships with each other. After neighbor relationships are established, the P2P interfaces send small Hello packets without the padding field.
  • Broadcast interfaces: Broadcast interfaces send Hello packets with the padding field and set the length of the Hello packets to their IPv4 MTU values.

P2P interfaces send Hello packets with the padding field and set the length of the Hello packets to that of locally generated LSPs before establishing neighbor relationships with each other and send Hello packets without the padding field after neighbor relationships are established. Consequently, the MTU values of the two ends may be different, causing packet forwarding failures and service interruptions. The isis hello padding mtu command can be run on a P2P interface to set the length of Hello packets to the MTU value of the interface. This prevents the problem that the MTU values of two P2P interfaces are different but an IS-IS neighbor relationship can be established between them. The isis isis hello padding-mtu ipv6 command can be run on a broadcast interface to set the length of Hello packets to the IPv6 MTU value of the interface.

Precautions

The isis hello padding-mtu and isis small-hello commands are mutually exclusive.

When running the isis hello padding-mtu command on an interface, ensure that the configuration meets the requirements of all service traffic. Otherwise, when IS-IS uses this interface as the outbound interface for route calculation, service traffic may be interrupted.

Example

# Configure the interface to send Hello packets with the padding field and set the length of the Hello packets to the IPv6 MTU value of the interface during IS-IS neighbor relationship establishment.
<HUAWEI> system-view
[HUAWEI] isis 1
[HUAWEI-isis-1] ipv6 enable
[HUAWEI-isis-1] quit
[HUAWEI] interface 10GE0/0/1
[HUAWEI-10GE0/0/1] undo portswitch
[HUAWEI-10GE0/0/1] ipv6 enable
[HUAWEI-10GE0/0/1] isis ipv6 enable 1
[HUAWEI-10GE0/0/1] isis hello padding-mtu ipv6
# Configure the interface to send Hello packets with the padding field and set the length of the Hello packets to the IPv4 MTU value of the interface during IS-IS neighbor relationship establishment.
<HUAWEI> system-view
[HUAWEI] isis 1
[HUAWEI-isis-1] quit
[HUAWEI] interface 10GE0/0/1
[HUAWEI-10GE0/0/1] undo portswitch
[HUAWEI-10GE0/0/1] isis enable 1
[HUAWEI-10GE0/0/1] isis hello padding-mtu ipv4
