traffic-optimize broadcast-suppression disable (AP system profile view)

Function

The traffic-optimize broadcast-suppression disable command disables rate limit for multicast and broadcast packets on an AP.

The undo traffic-optimize broadcast-suppression disable command enables rate limit for multicast and broadcast packets on an AP.

By default, rate limiting for multicast and broadcast packets is enabled on an AP.

Format

traffic-optimize broadcast-suppression { all | arp | igmp | nd | dhcp | dhcpv6 | mdns | other-broadcast | other-multicast } disable

undo traffic-optimize broadcast-suppression { all | arp | igmp | nd | dhcp | dhcpv6 | mdns | other-broadcast | other-multicast } disable

Parameters

Parameter Description Value
all

Enables or disables rate limiting for ARP/IGMP/ND/DHCP/DHCPv6/mDNS multicast packets.

-
arp

Enables or disables rate limiting for ARP broadcast packets.

-
igmp

Enables or disables rate limiting for IGMP multicast packets.

-
nd

Enables or disables rate limiting for ND broadcast packets.

-
dhcp

Enables or disables rate limiting for DHCP broadcast packets.

-
dhcpv6

Enables or disables rate limiting for DHCPv6 broadcast packets.

-
mdns

Enables or disables rate limiting for mDNS multicast packets.

-
other-broadcast

Enables or disables rate limiting for broadcast packets other than ARP, DHCP, DHCPv6, and ND packets.

-
other-multicast

Enables or disables rate limiting for multicast packets other than IGMP and mDNS packets.

-

Views

AP system profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When the number of packets increases, more network resources are occupied, affecting network services. To ensure normal running of network services, you can limit the rates of some protocol packets (such as DHCP and ARP packets) on an AP within a proper range.

You can run the traffic-optimize broadcast-suppression rate-threshold (AP system profile view) command to configure the rate threshold of multicast and broadcast packets on an AP. The configured threshold overrides the default threshold.

Precautions

If rate limiting for multicast packets is enabled on an AP, multicast services may be affected. As such, it is recommended that the traffic-optimize broadcast-suppression rate-threshold (AP system profile view) command be executed to adjust the rate threshold for multicast packets.

Rate limiting for multicast and broadcast packets takes effect only for incoming traffic on an AP's wired interface. The rate limit threshold for multicast and broadcast packets applies to the inbound direction on all the wired interfaces of an AP. That is, the rate of multicast and broadcast packets is limited only when the total number of multicast and broadcast packets in the inbound direction of all the wired interfaces of the AP per second exceeds the threshold.

Example

# Enable rate limiting for ARP broadcast packets in the AP system profile system1.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name system1
[HUAWEI-wlan-ap-system-prof-system1] undo traffic-optimize broadcast-suppression arp disable
