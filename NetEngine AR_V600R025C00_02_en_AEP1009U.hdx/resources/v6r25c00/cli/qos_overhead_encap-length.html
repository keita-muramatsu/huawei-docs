qos overhead encap-length

Function

The qos overhead encap-length command configures the tunnel encapsulation length of packets on a tunnel interface.

The undo qos overhead encap-length command deletes the tunnel encapsulation length of packets configured on a tunnel interface.

By default, no tunnel encapsulation length of packets is configured on a tunnel interface.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

qos overhead encap-length encap-length-value

undo qos overhead encap-length

Parameters

Parameter Description Value
encap-length-value

The value of the length (Unit:Bytes).

The value is an integer that ranges from 1 to 255.

Views

Tunnel interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The qos overhead encap-length command is used to configure the tunnel encapsulation length of packets on a tunnel interface. When the device performs QoS rate limiting and traffic statistics collection on tunnel-encapsulated packets on a physical interface, the calculated packet length does not include the tunnel encapsulation length. That is, the device subtracts the tunnel encapsulation length specified by encap-length from the packet length, and then performs QoS rate limiting and traffic statistics collection on packets.

Precautions

For details about the tunnel protocol of the tunnel interface, see the tunnel section.

If the configured tunnel encapsulation length exceeds the actual encapsulation length of packets, this function does not take effect. That is, the device still includes the tunnel encapsulation length of packets on the tunnel interface when performing QoS rate limiting and traffic statistics collection on packets on a physical interface.

Example

# Set the tunnel encapsulation length of packets on a tunnel interface to 20 bytes.
<HUAWEI> system-view
[HUAWEI] interface Tunnel 1
[HUAWEI-Tunnel1] qos overhead encap-length 20
