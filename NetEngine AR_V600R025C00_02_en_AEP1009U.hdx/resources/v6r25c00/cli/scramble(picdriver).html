scramble(POS interface view)

Function

The scramble command enables the payload scrambling function on a POS interface.

The undo scramble command disables the payload scrambling function on a POS interface.

By default, the payload scrambling function is enabled on a POS interface.

This command is supported only on the AR8700 series, AR5710-S10T1X2, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series and AR6700-H series.

Format

scramble

undo scramble

Parameters

None

Views

POS interface view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To facilitate the extraction of line clock signals at the receive end and prevent clock signals from being interfered by consecutive 1s or 0s, you can run this command to enable the payload scrambling function on a POS interface.

Precautions

You can run this command only when the device supports POS interfaces.

Example

# Disable the payload scrambling function on POS 1/0/1.
<HUAWEI> system-view
[HUAWEI] interface Pos 1/0/1
[HUAWEI-Pos1/0/1] undo scramble
