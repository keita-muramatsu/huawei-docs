file-type (Antivirus profile view)

Function

The file-type command configures a file detection type.

The undo file-type command disables file type detection.

By default, the "OFFICE", "PE", "ELF", "SCRIPT", "EICAR", "EML", "FLASH", "PDF", "RTF", "MACOS", "JAR", "APK", "ARCHIVE" file is detected.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

file-type av { items file-type-name &<1-18> | all }

undo file-type av { items file-type-name &<1-18> | all }

undo file-type av

Parameters

Parameter Description Value
items file-type-name

Options for configuring the file type.

Enumerated type.
all

The detection type of the configuration file is full file detection.

All file detection types of antivirus are "OFFICE", "PE", "ELF", "SCRIPT", "EICAR", "EML", "FLASH", "PDF", "RTF", "MACOS", "JAR", "APK","ARCHIVE", "WEB", "IMAGE", "VIDEO", "AUDIO", and "OTHER".
av

File type configuration for antivirus detection.

-

Views

Antivirus profile view

Default Level

2: Configuration level

Usage Guidelines

To configure the detection of a specified file type, run the file-type command.

To restore the file detection type to the default supported file type, run the undo file-type command.

Example

# Configure the AV file detection type to support images. 
<HUAWEI> system-view
[HUAWEI] profile type av name protocol_detect
[HUAWEI-profile-av-protocol_detect] file-type av items image
