display evpn connection

Function

The display evpn connection command displays SD-WAN EVPN site connection information.

Format

display evpn connection { all | connection-id }

display evpn connection [ site site-id ] [ local | extended ] [ status { up | down } ]

Parameters

Parameter Description Value
all

Indicates all connections.

-
connection-id

Specifies a connection ID.

The value is an integer ranging from 1 to 4294967295.
site site-id

Specifies a site ID.

The value is an integer ranging from 1 to 65535.
local

Indicates local connections.

-
extended

Indicates extended connections.

-
status

Indicates the connection status.

-
up

Indicates that the connection state is up.

-
down

Indicates that the connection state is down.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To check EVPN site connection information, run the display evpn connection command. The command output helps improve maintainability.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display information about up connections at EVPN sites.
<HUAWEI> display evpn connection status up

Table 1 Description of the display evpn connection command output
Item Description
Connection ID

Connection index.
Site ID

Remote site ID.
Source IP

Encapsulated source IP address.
Source TNP

Source TNP ID.
Destination IP

Encapsulated destination IP address. If NAT is enabled, this field displays a post-NAT IP address.
Destination TNP

Destination TNP ID.
Status

Connectivity check result:

  • Up: The connection is available.
  • Down: The connection is unavailable.
BSID

Binding segment identification.

Number of connections.
