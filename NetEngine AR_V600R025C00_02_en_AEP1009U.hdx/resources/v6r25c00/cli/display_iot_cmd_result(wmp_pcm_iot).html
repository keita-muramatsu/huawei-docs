display iot-card iot-command-result

Function

The display iot-card iot-command-result command displays the execution results of commands transparently transmitted by the device to IoT cards.

Format

display iot-card iot-command-result all

display iot-card iot-command-result ap ap-id ap-id card { card-number | usb | ble }

Parameters

Parameter Description Value
ap ap-id ap-id

Displays command execution results on cards of the AP with a specified ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
card card-number

Specifies the ID of an IoT card.

The value is an integer that ranges from 1 to 3.
usb

Specifies the USB interface on an IoT card.

-
ble

Specifies the built-in Bluetooth module.

-
all

Displays command execution results on all cards of all APs.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

After the device transparently transmits a command to a card, you can run this command to check the command execution result on the card.

Precautions

This command displays only the last execution result. To view more information, log in to the AP and run the display diagnose/pssp/iot-card/iot-command-result/history command in the diagnostic view.

Table 1 Description of the display iot-card iot-command-result command output
Item Description
Total

Total number of command execution results.
Fail

Number of commands that fail to be executed.
AP-ID

ID of the AP where a card resides.
Card Response

Response of a card.

The response is defined by the card vendor. For details, contact the card vendor.
Card

Card ID.
Time

Time when an AP transparently transmitted a command to a card.
Command

Content of a command transparently transmitted to a card.
Transparent transmission result

Execution result of a command on an IoT card:

  • Success: The command has been successfully executed.
  • Waiting: The card is waiting for a response from the AP.
  • Fail: The command fails to be transmitted to the card. The failure reasons are as follows:
    • Card does not support this command: The card does not support this command.
    • Card is not installed: The card is not properly installed.
    • Time Out: The response of the card times out. Check the version of the card. If the card version does not support transparent transmission of commands, the command execution times out.
    • Card is busy: The card is executing another command.
    • Other reason: A system error occurs.
Success

Number of commands that are successfully executed.
Waiting

Number of command execution results that a card is waiting for from an AP.
