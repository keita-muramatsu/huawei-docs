index sid ipv6

Function

The index sid ipv6 command specifies a next-hop SID. Different SIDs are organized by index in ascending order to form a SID stack. In addition, you can specify whether to perform path verification on the SID.

The undo index sid ipv6 command deletes a SID from a SID stack.

By default, no SID stack is configured for the segment list.

Format

index index sid ipv6 ipv6address

index index sid ipv6 ipv6address verification

undo index index [ sid ipv6 ipv6address ]

undo index index sid ipv6 ipv6address verification

Parameters

Parameter Description Value
index

Specifies an index.

The value is an integer ranging from 0 to 4294967295.
ipv6address

Specifies an SRv6 SID.

The value is a 32-bit hexadecimal string in format X:X:X:X:X:X:X:X.
verification

Indicates SID verification.

-

Views

SRv6 segment list view

Default Level

2: Configuration level

Usage Guidelines

This command is used to plan the path of an SRv6 TE Policy. You can run the command multiple times. The system generates a stack of SIDs that are organized by index in ascending order. If a candidate path in the SRv6 TE Policy is preferentially selected, traffic is forwarded using the SID stack of the candidate path.

The verification keyword specifies whether to perform path verification for a SID. If the SID does not carry the verification flag, the SID is skipped during path verification. SIDs and binding SIDs that are not in the local domain should not carry the verification keyword.

Example

# Configure a SID stack for the segment list.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] segment-list abc
[HUAWEI-segment-routing-ipv6-segment-list-abc] index 1 sid ipv6 2001:DB8:100:: verification
[HUAWEI-segment-routing-ipv6-segment-list-abc] index 2 sid ipv6 2001:DB8:200::
