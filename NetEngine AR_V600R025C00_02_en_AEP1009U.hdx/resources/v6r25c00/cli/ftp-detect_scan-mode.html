ftp-detect scan-mode

Function

The ftp-detect scan-mode command sets the detection mode for file transfer protocols in an antivirus profile.

The undo ftp-detect scan-mode command restores the default detection mode (flow detection mode).

By default, the FTP detection mode of the antivirus detection engine is flow detection.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

ftp-detect scan-mode { proxy | flow }

undo ftp-detect scan-mode

Parameters

Parameter Description Value
proxy

Indicates that the detection mode of the antivirus engine is proxy.

-
flow

Indicates that the detection mode of the antivirus engine is flow detection.

-

Views

Antivirus profile view

Default Level

2: Configuration level

Usage Guidelines

In proxy mode, the blocking effect of malicious files is better, but more performance is consumed. After the proxy mode is enabled, the device performance is greatly affected. Therefore, you are advised not to enable the proxy mode.

In flow mode, the blocking effect of malicious files is reduced, but the performance overhead is lower.

Example

# Create a profile named av_scanmode and set the FTP detection mode to flow detection in the profile. 
<HUAWEI> system-view
[HUAWEI] profile type av name av_scanmode
[HUAWEI-profile-av-av_scanmode] ftp-detect scan-mode flow
