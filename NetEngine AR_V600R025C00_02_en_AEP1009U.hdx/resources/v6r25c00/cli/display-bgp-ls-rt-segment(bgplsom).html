display bgp link-state unicast routing-table segment-list

Function

The display bgp link-state unicast routing-table segment-list command displays the SID list of the BGP-LS routes with the specified prefix.

Format

display bgp link-state unicast routing-table [ peer ipv4-address { received-routes | advertised-routes } ] bgp-ls-prefix segment-list

Parameters

Parameter Description Value
peer ipv4-address

Specifies an IPv4 peer address.

The value is in dotted decimal notation.
received-routes

Displays BGP-LS routes received from the specified peer.

-
advertised-routes

Displays BGP-LS routes advertised to the specified peer.

-
bgp-ls-prefix

Specifies a BGP-LS route prefix.

For details about BGP-LS route prefix formats, see "BGP-LS" in Feature Description - IP Routing - BGP.

The BGP-LS route prefix format is complex. To facilitate your query, run the display bgp link-state unicast routing-table command to check all BGP-LS routes, and copy the prefix of the route whose information is to be queried when specifying prefix.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

BGP-LS routes carry topology information and are classified into four types of routes that carry node, link, route prefix, and TE Policy information, respectively. These routes collaborate in carrying topology information. For details about BGP-LS route prefix formats, see "BGP-LS" in Feature Description - IP Routing - BGP.
