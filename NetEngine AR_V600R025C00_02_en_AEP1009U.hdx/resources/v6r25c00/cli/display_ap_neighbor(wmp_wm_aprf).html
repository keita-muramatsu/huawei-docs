display ap neighbor

Function

The display ap neighbor command displays information about neighbors of a radio, including authorized and unauthorized neighbors.

Format

display ap neighbor ap-id ap-id [ radio radio ]

Parameters

Parameter Description Value
ap-id ap-id

Specifies the AP ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
radio radio

Specifies the radio ID of an AP.

The value is an integer ranging from 0 to 4.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

APs' neighbor information reflects the APs' positions and neighbor relationships, helping you plan the network.

If a neighboring AP is an authorized one, the system displays the RSSI of signals received from the neighboring AP as well as the path loss.<br /> If a neighboring AP is an unauthorized one, the system displays only the RSSI of signals received from the neighboring AP.

Prerequisites

Radio calibration has been enabled using the calibrate enable command.

Precautions

Neighbor information can be queried only before the aging time (32 hours) expires. Neighbor information is not displayed for radios working in monitor mode.
