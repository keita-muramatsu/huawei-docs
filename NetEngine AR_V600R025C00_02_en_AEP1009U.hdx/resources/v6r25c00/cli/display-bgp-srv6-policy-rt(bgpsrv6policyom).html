display bgp sr-policy ipv6 routing-table(all-views)

Function

The display bgp sr-policy ipv6 routing-table command displays information about routes in the BGP IPv6 SR-Policy address family.

The display bgp sr-policy ipv6 routing-table time-range command displays information about routes that flap in the BGP IPv6 SR-Policy address family within the specified period.

Format

display bgp sr-policy ipv6 routing-table [ peer remoteIpv6Addr { advertised-routes | received-routes } ] [ sr-policy-prefix [ segment-list ] ]

display bgp sr-policy ipv6 routing-table peer remoteIpv6Addr { advertised-routes | received-routes } statistics

display bgp sr-policy ipv6 routing-table [ peer remoteIpv6Addr { advertised-routes | received-routes } ] time-range time-range-start time-range-end

Parameters

Parameter Description Value
peer remoteIpv6Addr

IPv6 peer address.

The value is a 32-bit hexadecimal string in format X:X:X:X:X:X:X:X.
advertised-routes

Displays the routes advertised to a specified peer.

-
received-routes

Displays the routes received from a specified peer.

-
sr-policy-prefix

The prefix of IPv6 SR-Policy routes.

The value is a string case-sensitive characters. It cannot contain spaces.
segment-list

Displays detailed information about the Segment-list attribute of IPv6 SR-Policy routes with a specified prefix.

-
statistics

Displays statistics about routes advertised to or received from a specified peer.

-
time-range time-range-start time-range-end

Displays information about routes that flap within the specified period in the BGP IPv6 SR-Policy address family. For example, the value 0d0h5m0s of start-time indicates 5 minutes before the current time, and the value 0d0h10m0s of end-time indicates 10 minutes before the current time; the command output displays information about all routes with the Keepalive time ranging from 5 minutes to 10 minutes in the BGP IPv6 SR-Policy address family.

Both start-time and end-time are in the format of xxdxxhxxmxxs. d indicates the day, which is an integer ranging from 0 to 10000. h indicates the hour, which is an integer ranging from 0 to 23. m indicates the minute, which is an integer ranging from 0 to 59. s indicates the second, which is an integer ranging from 0 to 59.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

The display bgp sr-policy ipv6 routing-table statistics command displays statistics about routes in a BGP IPv6 SR-Policy address family.

To check information about desired routes, you can specify parameters as required.

Tunnel type.
Tunnel Encaps Attribute

Tunnel Encaps Attribute of the BGP IPv6 SR-Policy route:

  • Tunnel Type: indicates the tunnel type.
  • Binding SID: BSID. The backup path of each IPv6 SR-Policy tunnel corresponds to a BSID. Multiple backup paths of an IPv6 SR-Policy tunnel have the same BSID.
  • Preference: indicates the priority of the backup path.
  • Segment List: SID list.
  • Weight: indicates the weight of the path for load balancing.
  • Segment: network segment.
  • type: indicates the segment type.
  • SID: value of an SRv6 SID.
Binding SID

Bound SID.
Not advertised to any peer yet

The route has not advertised to any peer yet.
Received routes total

Number of routes received from peers.
Segment-list information of route

Detailed information about the Segment-list attribute of the IPv6 SR Policy routes with the specified prefix.
From

IP address of the device that sends the route.
Origin

Origin of the route:

  • IGP: indicates that the Origin attribute of the route that is added to the BGP routing table using the network (BGP) command is IGP.
  • EGP: indicates that the Origin attribute of the route message obtained through EGP is EGP.
  • Incomplete: indicates that the origin of the route cannot be identified. For example, the origin of the route imported by BGP using the import-route (BGP) command is Incomplete.
valid

The BGP route is a valid route.
internal

The BGP route is an internal route.
best
