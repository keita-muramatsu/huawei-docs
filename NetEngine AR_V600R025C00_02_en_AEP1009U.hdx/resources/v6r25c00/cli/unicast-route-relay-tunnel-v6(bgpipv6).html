unicast-route recursive-lookup tunnel-v6 (BGP-IPv6 unicast address family view)

Function

The unicast-route recursive-lookup tunnel-v6 command enables BGP IPv6 unicast routes to recurse to the tunnels that match the specified tunnel policy.

The undo unicast-route recursive-lookup tunnel-v6 command restores the default configuration.

By default, the device recurses the IPv6 unicast routes received from BGP IPv6 peers to outbound interfaces and next hops, but not to tunnels.

Format

unicast-route recursive-lookup tunnel-v6 tunnel-selector tunnel-selector-name

undo unicast-route recursive-lookup tunnel-v6 tunnel-selector tunnel-selector-name

undo unicast-route recursive-lookup tunnel-v6

Parameters

Parameter Description Value
tunnel-selector tunnel-selector-name

Specifies the name of a tunnel selector.

The value is a string of 1 to 40 case-sensitive characters, spaces not supported.

The character string can contain spaces if it is enclosed in double quotation marks (" ").

Views

BGP-IPv6 unicast address family view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

By default, IPv6 unicast routes received from BGP IPv6 peers can be recursed only to outbound interfaces and next hops, but not to tunnels. After this command is run, the IPv6 unicast routes received from BGP IPv6 peers carry the corresponding tunnel policy and are preferentially recursed to tunnels. If no tunnel is available, the IPv6 unicast routes can be recursed to outbound interfaces and next hops.

Precautions

If this command is run more than once, the latest configuration overrides the previous one.

Example

# Enable the device to recurse BGP IPv6 unicast routes to tunnels.
<HUAWEI> system-view
[HUAWEI] tunnel-selector tnl1 permit node 10
[HUAWEI-tunnel-selector] quit
[HUAWEI] bgp 100
[HUAWEI-bgp] ipv6-family unicast
[HUAWEI-bgp-af-ipv6] unicast-route recursive-lookup tunnel-v6 tunnel-selector tnl1
