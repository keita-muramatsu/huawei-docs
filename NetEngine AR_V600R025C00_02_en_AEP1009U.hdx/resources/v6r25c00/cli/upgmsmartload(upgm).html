smart-load

Function

The smart-load command flexibly downloads software packages supported by the local device from the package pool on a specified server.

Format

smart-load { ftp | sftp } { server-ip server-ipv4 | server-ipv6 server-ipv6 } [ port-id port-id ] username username filename filename [ vpn-instance vpn-instance ]

Parameters

Parameter Description Value
ftp

Sets up a connection in FTP mode.

The value is an unsigned integer.
sftp

Sets up a connection in SFTP mode.

The value is an unsigned integer.
server-ip server-ipv4

Indicates the remote IPv4 address or host name specified by the FTP/SFTP user.

The value is a string of 1 to 255 characters. It cannot contain spaces.
server-ipv6 server-ipv6

Indicates the remote IPv6 address or host name specified by the FTP/SFTP user.

The value is a string of 1 to 255 characters. It cannot contain spaces.
port-id port-id

Specifies the port number.

The value is an unsigned integer ranging from 1 to 65535. If this parameter is not specified, the default value is 21 for FTP and 22 for SFTP.
username username

Specifies a username.

The value is a string of 1 to 255 characters. It cannot contain spaces.
filename filename

Indicates the file name.

The value is a string of 1 to 255 characters. It cannot contain spaces.
vpn-instance vpn-instance

Specifies a VPN instance.

The value is a string of 1 to 31 characters. It cannot contain spaces.

Views

User view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

The smart-load function is supported to download software packages on demand, solving the lifecycle evolution problem caused by insufficient flash memory space.

When you need to switch the software version, run this command to download the software package from the specified package pool file to the local device.

Precautions

  1. Enter the password immediately after the command is executed to avoid command execution failure due to timeout.
  2. When a .zip package pool file is specified in the command, the software package that matches the device information in the package pool is downloaded to the device. For details, see the command output.
  3. If the software package in the specified .zip package pool file has the same name as the existing software package on the device and is the same file, the system does not download the .zip package pool file again and displays a message indicating that the download is successful.
  4. If the software package in the specified .zip package pool file has the same name as the existing software package on the device but is not the same file, and the name of the software package is different from that of the current or next startup software package, the .zip file is downloaded and overwrites the old software package.
  5. If the software package in the specified .zip package pool file has the same name as the current or next startup software package but is not the same file, the download fails and the message "The operation is invalid, because the entered software package name is invalid." is displayed.
  6. SFTP is recommended because it is more secure than FTP.

Example

# Obtain the system software package from the server to the device.
<HUAWEI> smart-load sftp server-ip xx.xx.xx.xx username testname filename commonPkgPool.zip
Enter Password:
Info: Operating, please wait for a moment.............done.
Info: The following files are downloaded successfully: commonCcPkg.cc.
