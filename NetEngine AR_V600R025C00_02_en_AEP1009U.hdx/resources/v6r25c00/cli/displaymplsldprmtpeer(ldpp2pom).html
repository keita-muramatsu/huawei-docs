display mpls ldp remote-peer

Function

The display mpls ldp remote-peer command displays information about a remote LDP peer.

Format

display mpls ldp remote-peer [ remote-peer-name | peer-id peer-id ]

Parameters

Parameter Description Value
remote-peer-name

Specifies the name of a remote LDP peer. The name is defined using the mpls ldp remote-peer command.

The name is a string of 1 to 32 case-sensitive characters, spaces not supported. When double quotation marks are used around the string, spaces are allowed in the string.
peer-id peer-id

Displays information about the LDP remote peer of a specified peer ID.

The value is in dotted decimal notation.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

Remote LDP peers are used to set up remote LDP sessions to transmit VPN services.

To view information about configured remote LDP peers, run the display mpls ldp remote-peer command.

Prerequisites

A remote LDP peer has been configured.

Table 1 Description of the display mpls ldp remote-peer command output
Item Description
LDP ID

Local LDP ID.
Remote Peer Name

Name of a remote LDP peer.
Remote Peer IP

IP address of the remote LDP peer.
Entity Status

Status of a remote LDP peer:

  • Active.
  • Inactive.
Description

Remote peer description.
Transport Address

Transport address, which is used to establish an LDP session with the remote LDP peer.
Configured Keepalive Hold Timer

Value of the configured Keepalive hold timer.
Configured Keepalive Send Timer

Configured value of the Keepalive send timer.
Configured Hello Hold Timer

Configured value of the Hello hold timer.
Configured Hello Send Timer

Configured value of the Hello send timer.
Configured Delay Timer

Value of the configured delay timer.
Hello Packet sent/received

Number of Hello messages sent and received by the remote peer.
Negotiated Hello Hold Timer

Value of the effective Hello hold timer.
Label Advertisement Mode

Label advertisement mode:

  • Downstream Unsolicited.
  • Downstream On Demand.
Auto-config

Describes how the LDP remote session is enabled:

  • ----: The remote LDP peer is manually configured.
  • L2VPN: After an L2VPN is configured, the remote LDP peer is automatically configured.
  • Session-Protect: The remote LDP peer is triggered by LDP session protection.
  • RLFA: The remote LDP session is triggered by Remote LFA.
  • Auto Accept: The remote LDP session is automatically established after a local device receives Targeted Hello messages.
  • Ti-lfa: The remote LDP peer is triggered in the TI-LFA scenario where PQ nodes overlap.
Manual-config

Whether manual configuration is effective:

  • effective: Indicates that manual configuration is effective.
  • ineffective: Indicates that manual configuration is ineffective.
  • ----: Indicates that a remote LDP session is automatically created.
Session-Protect effect

Whether LDP session protection takes effect:

  • YES.
  • NO.
Session-Protect Duration

Duration when LDP session protection remains effective.
Session-Protect Remain

Remaining time when LDP session protection remains effective.
TOTAL

Total number of remote peers.
