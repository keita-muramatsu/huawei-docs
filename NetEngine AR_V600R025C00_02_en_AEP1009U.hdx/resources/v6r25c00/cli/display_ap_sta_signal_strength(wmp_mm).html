display ap sta-signal strength

Function

The display ap sta-signal strength command displays the average signal strength of STAs connected to a specified AP.

Format

display ap sta-signal strength ap-id ap-id [ radio radio-id ]

Parameters

Parameter Description Value
ap-id ap-id

Displays the average signal strength of STAs connected to the AP with a specified ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
radio radio-id

Displays the average signal strength of STAs on a specified AP radio.

The value is an integer ranging from 0 to 4.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can run this command to view the average signal strength of STAs connected to a specified AP.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the average signal strength of STAs connected to an AP.
<HUAWEI> display ap sta-signal strength ap-id 1
Station signal strength(dBm): 0
Table 1 Description of the display ap sta-signal strength command output
Item Description
Station signal strength(dBm)

Average signal strength of STAs.
