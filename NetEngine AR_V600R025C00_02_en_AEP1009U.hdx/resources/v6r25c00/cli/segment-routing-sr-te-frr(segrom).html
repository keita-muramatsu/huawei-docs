sr-te frr enable

Function

The sr-te frr enable command enables protection during SRv6 forwarding.

The undo sr-te frr enable command disables protection during SRv6 forwarding.

By default, protection during SRv6 forwarding is disabled.

By default, protection during SRv6 forwarding is disabled.

Format

sr-te frr enable

undo sr-te frr enable

Parameters

None

Views

Segment routing IPv6 view

Default Level

2: Configuration level

Usage Guidelines

The sr-te frr enable command enables protection during SRv6 forwarding. After this function is enabled, if the SL value is greater than 0 and the packet has an SRH, the SL value is decremented by 1 and the next-layer SRv6 SID is used as the destination address in any of the following scenarios:

• No matching FIB query is found, triggering a FIB-MISS event.

• The IPv6 destination address of the packet is the address of a directly connected neighbor, the outbound interface is down, and the protection provided by TI-LFA FRR is not node protection.

• A matching End.X SID is found in the local SID table, and the outbound interface is down.

• The route queried from the routing table is a NULL0 route.

Example

# Enable protection for SRv6 forwarding.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] sr-te frr enable
