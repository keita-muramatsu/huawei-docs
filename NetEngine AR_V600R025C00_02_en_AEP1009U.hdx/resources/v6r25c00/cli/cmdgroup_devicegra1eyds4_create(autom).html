device-granted

Function

The device-granted command approves a member device.

The undo device-granted command removes a member device from the approval list.

By default, no member device is approved.

Format

device-granted mac-addr type type-paravalue

undo device-granted mac-addr

Parameters

Parameter Description Value
mac-addr

Specifies the MAC address of the member device to be approved.

The value is in H-H-H format. Each H is a hexadecimal number of 4 digits.
type type-paravalue

Specifies the type of the member device to be approved.

The value is of the enumeration type:

  • lsw: LSW switch
  • ar: AR router
  • ap: AP
  • wac: WAC
  • unknown: unknown (for example, a third-party device)
  • fw: firewall

Views

Net-assistant device view

Default Level

3: Management level

Usage Guidelines

After a management channel is established between the master device and a member device, you can run this command to approve the member device so that the master device can manage the member device.

Example

# Approve the member device with the MAC address of 00e0-fc12-3456 and the device type of LSW.
<HUAWEI> system-view
[HUAWEI] net-assistant
[HUAWEI-net-assistant] device
[HUAWEI-net-assistant-device] device-granted 00e0-fc12-3456 type lsw
