segment-list (SRv6 candidate path view)

Function

The segment-list command configures a segment list to be referenced by an SRv6 TE Policy's candidate path.

The undo segment-list command deletes the segment list referenced by an SRv6 TE Policy's candidate path.

By default, no segment list is referenced by an SRv6 TE Policy's candidate path.

Format

segment-list list-name [ weight weight-value | path-mtu mtu-value | binding-sid binding-sid-value | reverse-binding-sid reverse-binding-sid-value ] *

undo segment-list list-name [ weight weight-value | path-mtu mtu-value | binding-sid binding-sid-value | reverse-binding-sid reverse-binding-sid-value ] *

Parameters

Parameter Description Value
list-name

Specifies the name of the segment list.

The value is a string of 1 to 31 case-sensitive characters. The character string can contain spaces if it is enclosed with double quotation marks (").
weight weight-value

Weight value of the segment list.

If the weight configured for a segment list of a candidate path is less than the average weight, the segment list does not forward traffic. (Average weight = Sum of weights configured for all segment lists of a candidate path/Maximum number of segment lists that can be used by the involved device for load balancing).

For example, if a maximum of M segment lists can be used by a device for load balancing and a candidate path has a total of N segment lists, the average weight of the N segment lists is calculated as follows: (Weight 1 + Weight 2 + ... + Weight N)/M = X. Segment lists whose weights are less than X do not forward traffic.

The value is an integer ranging from 0 to 4294967295. The default value is 1.
path-mtu mtu-value

Specifies the MTU of the segment list.

The value is an integer that ranges from 1280 to 9600.
binding-sid binding-sid-value

Specifies a binding SID.

The value is a 32-digit hexadecimal number in format X:X:X:X:X:X:X:X.
reverse-binding-sid reverse-binding-sid-value

Specifies a reverse binding SID.

The value is a 32-digit hexadecimal number in format X:X:X:X:X:X:X:X.

Views

SRv6 candidate path view

Default Level

2: Configuration level

Usage Guidelines

After configuring a candidate path for an SRv6 TE Policy, you can configure a segment list for the candidate path. If the candidate path is preferentially selected, traffic is forwarded over the segment list of the candidate path. If the weight of the segment list is set to 0, the segment list goes down and cannot be used for traffic forwarding.

Example

# Configure a candidate path to reference a segment list.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] segment-list s1
[HUAWEI-segment-routing-ipv6-segment-list-s1] quit
[HUAWEI-segment-routing-ipv6] srv6-te policy p2 endpoint 2001:DB8:10::10 color 100
[HUAWEI-segment-routing-ipv6-policy-p2] candidate-path preference 200
[HUAWEI-segment-routing-ipv6-policy-p2-path] segment-list s1 weight 1 path-mtu 1280
