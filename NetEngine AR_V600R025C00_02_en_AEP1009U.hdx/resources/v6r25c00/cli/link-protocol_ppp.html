link-protocol ppp

Function

The link-protocol ppp command configures PPP as the link layer protocol of an interface.

By default, the link layer protocol of a dialer interface is PPP.

Format

link-protocol ppp

Parameters

None

Views

Dialer interface view, POS interface view, Serial interface view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The P2P connection is a simple form of Wide Area Network (WAN) connections. PPP supports point-to-point data transmission over full duplex synchronous connections. It is widely used because it provides user authentication, supports synchronous and asynchronous communication, and can be easily extended.

Prerequisites

Interfaces are connected, and physical parameters of the interfaces are configured so that the physical layer status of the interfaces is Up.

Example

# Configure PPP as the link layer protocol of Dialer95.
<HUAWEI> system-view
[HUAWEI] interface Dialer 95
[HUAWEI-Dialer95] link-protocol ppp
# Configure PPP as the link layer protocol for Serial 0/0/0:2.
<HUAWEI> system-view
[HUAWEI] interface serial 0/0/0:2
[HUAWEI-serial0/0/0:2] link-protocol ppp
