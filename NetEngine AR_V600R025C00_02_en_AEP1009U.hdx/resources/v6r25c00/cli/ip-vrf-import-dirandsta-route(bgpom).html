import-route (BGP-VPN instance IPv4 address family view) (Non-IGP)

Function

The import-route command configures BGP to import routes from other protocols.

The undo import-route command cancels the configuration.

By default, BGP does not import routes from other protocols.

Format

import-route { static | direct | op-route } [ [ med med ] | [ route-policy route-policy-name ] ] *

import-route direct exclude vlink [ [ med med ] | [ route-policy route-policy-name ] ] *

undo import-route { static | direct | op-route }

Parameters

Parameter Description Value
static

Imports static routes.

-
direct

Imports direct routes.

-
op-route

Imports OP-routes.

-
med med

Specifies a MED value for imported routes.

The value is an integer ranging from 0 to 4294967295.
route-policy route-policy-name

Specifies the route-policy used to filter routes and modify route attributes when these routes are imported from other protocols.

The value is a string of 1 to 200 case-sensitive characters without spaces. The character string can contain spaces if it is enclosed with double quotation marks (").
exclude

Indicates that routes of a specified type are not imported.

-
vlink

Indicates Vlink direct routes.

-

Views

BGP-VPN instance IPv4 address family view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

BGP can import routes in import-route or network mode.

  • The import-route command imports routes of a specified protocol, such as RIP routes, OSPF routes, IS-IS routes, static routes, or direct routes, into the BGP routing table.
  • The network command imports a route with the specified prefix and mask to the BGP routing table. Using the network command to import routes is more accurate than using the import-route command.

    Description:

    When the import-route static command is used to import static routes, only active routes can be imported.

    If a large number of Vlink direct routes exist in the imported direct routes and these Vlink direct routes do not need to be advertised to peers, importing all these routes to the BGP routing table consumes device resources. To solve this problem, run the import-route direct exclude vlink command to disable the device from importing Vlink direct routes.

Prerequisites

If you want to import both the routes of other protocols and the default route, run the default-route imported command first.

Precautions

If the routes to be imported from the IP routing table are load balancing routes, only the first route in the routing table is imported.

If the same route is imported between different protocols, the loop prevention attribute of the route may be lost, posing routing loop risks. To prevent this problem, you are advised to specify a route-policy for the route import.

After the import-route command is run, a large number of routes may be imported from other protocols. To prevent unnecessary routes from being imported, set the route-policy parameter in this command.

If route-policy route-policy-nameis configured in the command, the following items can be matched: the AS_Path filter, VPN-Target extended community filter, outbound interface, IP route destination address ACL, IP route destination address prefix list, IP route next-hop address ACL list, IP route next-hop address prefix list, route cost, route type, route tag, MPLS label, IPv6 route next-hop address ACL list, IPv6 route next-hop address prefix list, route preference, route modulo attribute, and number of community attributes. The following items can be set: the AS_Path attribute, BGP community attribute, BGP route local preference, BGP route origin, BGP route MED, MPLS label, BGP route PreVal, BGP route SoO extended community attribute, BGP route color extended community attribute, BGP Large-community attribute, and number of times the most recent AS number is appended to routes. By default, the VPN-Target extended community attribute applied to a route-policy does not take effect unless you run the bgp route-policy-effective apply extcommunity rt command.

If the referenced policy contains unsupported attribute matching or behavior setting, unexpected results may occur.

Example

# Import static routes.
<HUAWEI> system-view
[HUAWEI] ip vpn-instance vpn1
[HUAWEI-vpn-instance-vpn1] ipv4-family
[HUAWEI-vpn-instance-vpn1-af-ipv4] route-distinguisher 100:1
[HUAWEI-vpn-instance-vpn1-af-ipv4] quit
[HUAWEI-vpn-instance-vpn1] quit
[HUAWEI] bgp 100
[HUAWEI-bgp] ipv4-family vpn-instance vpn1
[HUAWEI-bgp-vpn1] import-route static
