local-server

Function

The local-server command configures the IP address and port number of the local server.

The undo local-server command deletes the IP address and port number of the local server.

By default, no IP address or port number is configured for the local server.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR5710-S8P1XDSE-2LTE4EA.

Format

local-server ip ip-address port port-number

local-server ip ip-address port port-number vpn-instance vpn-instance-name

undo local-server { ip ip-address port port-number | all }

undo local-server ip ip-address port port-number vpn-instance vpn-instance-name

Parameters

Parameter Description Value
port port-number

Specifies the port number used by the device to proactively access the TSM SSO server.

The value is an integer from 1 to 65535.
ip ip-address

Specifies the IP address used by the device to proactively access the TSM SSO server.

The value is in dotted decimal notation.
vpn-instance vpn-instance-name

Specifies the name of a VPN instance bound to a local service.

The value must be an existing VPN instance name.
all

Indicates all local servers.

-

Views

TSM SSO view

Default Level

2: Configuration level

Usage Guidelines

The device IP address configured on the TSM SSO server must be the same as this IP address.

Example

# Set the IP address of the local server to 192.168.1.1 and port number to 8888, and bind the local server to the VPN instance vpn1.
<HUAWEI> system-view
[HUAWEI] ip vpn-instance vpn1
[HUAWEI-vpn-instance-v1] quit
[HUAWEI] identity-management
[HUAWEI-identity-management] sso-tsm
[HUAWEI-identity-management-sso-tsm] local-server ip 192.168.1.1 port 8888 vpn-instance vpn1
# Set the IP address of the local server to 192.168.1.1 and the port number to 8888.
<HUAWEI> system-view
[HUAWEI] identity-management
[HUAWEI-identity-management] sso-tsm
[HUAWEI-identity-management-sso-tsm] local-server ip 192.168.1.1 port 8888
