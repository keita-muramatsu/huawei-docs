csi distance-range

Function

The csi distance-range command sets the CSI sensing distance range for APs.

The undo csi distance-range command deletes the CSI sensing distance range configured for APs.

By default, the person sensing distance ranges on entry and exit are both 100 decimeters in an AP system profile. In the AP view, the person sensing distance ranges are not configured by default and the configurations in the AP system profile are used.

Format

csi distance-range presence-enter-range enter-value presence-leave-range leave-value

undo csi distance-range

Parameters

Parameter Description Value
presence-leave-range leave-value

Specifies the person sensing distance range on exit.

The value is an integer ranging from 0 to 100, in decimeters. The value 0 indicates the minimum CSI sensing range, and the value 100 indicates the maximum CSI sensing range.
presence-enter-range enter-value

Specifies the person sensing distance range on entry.

The value is an integer ranging from 0 to 100, in decimeters. The value 0 indicates the minimum CSI sensing range, and the value 100 indicates the maximum CSI sensing range.

Views

AP view, AP system profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If the CSI sensing distance range needs to be limited in specific scenarios, for example, in conference rooms, hotel rooms, and other scenarios with non-concrete partitions, you can set the CSI sensing distance range for APs, that is, the maximum sensing distances. This prevents false detection of moving objects outside the target area.

The maximum CSI sensing ranges are restricted by an AP's ranging capability, which may have measurement errors. In addition, the AP installation height needs to be considered. For details, see the Scenario-based WLAN Planning Design for CSI Sensing (Wi-Fi 7).

Precautions

If the configured maximum sensing distance exceeds an AP's maximum capability, the AP's capability takes effect. You can query the CSI sensing distance of an AP model on Info-Finder to confirm the specifications.

Both the csi distance-sensitivity and csi distance-range commands can be used to limit the sensing range. If both of them are configured, the sensing range is limited by the configurations of both commands. The sensing range is the intersection of the two command configurations. You are advised to use the csi distance-range command to limit the detection range.

If the person sensing distance range on exit (presence-leave-range leave-value) is greater than the person sensing distance range on entry (presence-enter-range enter-value), the human presence aging time configured on the AP using the csi presence-aging-time command must be set to at least more than 10 minutes. If the aging time on the AP is too short, for example, 1 minute, when a person stays in the inner and outer circles of the detection range for more than 1 minute, the human absence state is determined, and human presence cannot be identified unless the person enters the inner circle again.

Example

# Set the person sensing distance ranges on entry and exit both to 60 decimeters for APs.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name test
[HUAWEI-wlan-ap-system-prof-test] csi distance-range presence-enter-range 60 presence-leave-range 60
