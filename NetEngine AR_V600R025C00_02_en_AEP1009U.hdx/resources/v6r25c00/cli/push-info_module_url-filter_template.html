push-info module url-filter template

Function

The push-info module url-filter template command configures the language of the URL filtering push page.

The undo push-info module url-filter template command restores the default configuration.

By default, the language of the URL filtering push page is English.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

push-info module url-filter template language

undo push-info module url-filter template

Parameters

Parameter Description Value
template language

Specifies the language of the URL filtering push page.

The options are as follows:

  • arabic
  • bengali
  • english
  • french
  • german
  • hindi
  • indonesian
  • portuguese
  • russian
  • spanish

Views

System view

Default Level

2: Configuration level

Usage Guidelines

The device has 10 built-in language templates. To change the language of the URL filtering push page, run the push-info module url-filter template command.

Example

# Set the language of the URL filtering push page to Spanish.
<HUAWEI> system-view
[HUAWEI] push-info module url-filter template spanish
