display profile type av

Function

The display profile type av command displays information about an antivirus profile.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

display profile type av [ name name [ protocol | exception av-signature-name ] ]

Parameters

Parameter Description Value
name name

Specifies the name of an antivirus profile.

The value is a string of case-sensitive characters and must be an existing antivirus profile.
protocol

Displays the protocol type.

-
exception

Indicates a virus exception.

-
av-signature-name

Indicates the name of an exception virus.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

To display information about an antivirus profile,run the display profile type av command.
