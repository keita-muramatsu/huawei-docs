dns proxy enable

Function

The dns proxy enable command enables the DNS proxy function.

The undo dns proxy enable command disables the DNS proxy function.

By default, the DNS proxy function is disabled. In the factory configuration file, the DNS proxy function is enabled.

Format

dns proxy enable

dns proxy ipv6 enable

undo dns proxy enable

undo dns proxy ipv6 enable

Parameters

Parameter Description Value
ipv6

Configures the DNS IPv6 function.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The DNS proxy function is enabled on the device to forward DNS request and reply packets between the DNS client and DNS server. The DNS client on the LAN uses the DNS proxy as the DNS server and sends DNS request packets to the DNS proxy. The DNS proxy forwards the request packet to the real DNS server and returns the response packet from the DNS server to the DNS client. In this manner, domain name resolution is implemented. The device functions as a DNS proxy to provide the DNS server function for enterprise users. Users do not need to directly interact with the DNS server, which simplifies route deployment and improves DNS server performance and security.

Precautions

Before running this command, you are advised to run the dns server bind local-ip ip-addresscommand in the system view to configure the IP address used by the DNS proxy to communicate with the DNS client, reducing security risks.

Example

# Disable the DNS proxy function.
<HUAWEI> system-view
[HUAWEI] undo dns proxy enable
# Enable DNSv6 proxy.
<HUAWEI> system-view
[HUAWEI] dns proxy ipv6 enable
# Enable the DNS proxy function.
<HUAWEI> system-view
[HUAWEI] dns proxy enable
# Disable DNSv6 proxy.
<HUAWEI> system-view
[HUAWEI] undo dns proxy ipv6 enable
