profile type ips

Function

The profile type ips name command creates an IPS profile and displays the IPS profile view.

The undo profile type ips command deletes all or specified IPS profiles.

By default, there is an IPS profile named default on the device.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

profile type ips name name

undo profile type ips { all | name name }

Parameters

Parameter Description Value
name name

Specifies the name of an IPS profile.

The value is a string of case-sensitive characters. The value contains 1 to 32 characters. If the name contains spaces, enclose the name with double quotation marks, for example, "user for test". The name cannot contain question marks (?), commas (,), or hyphens (-).
all

Deletes all IPS profiles.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Intrusion prevention is a security mechanism, which detects intrusions by analyzing network traffic and aborts intrusions through configured response methods.

Follow-up Procedure

After creating an IPS profile, you need to configure a signature filter (using the signature-set name command) in the IPS profile view and configure an exception signature as required (using the exception ips-signature-id command).

After an IPS profile is configured, you need to reference the profile in a security policy for the profile to take effect.

Precautions

After running this command, run the engine configuration commit command to commit the configuration for the configuration to take effect. You are advised to commit the configuration after all content security configurations are complete.

Example

# Create IPS profile profile1. 
<HUAWEI> system-view
[HUAWEI] profile type ips name profile1
[HUAWEI-profile-ips-profile1]
