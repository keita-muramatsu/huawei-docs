display web-server agent http-table

Function

The display web-server agent http-table command displays temporary entries when HTTP or HTTPS is used for authentication.

Format

display web-server agent http-table { all | ip-address ip-address }

Parameters

Parameter Description Value
all

Displays brief information about all entries.

-
ip-address ip-address

Displays information about the entry with a specified user IP address.

The value is in dotted decimal notation.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

When the device connects to the Portal server using HTTP or HTTPS, you can run this command to view temporary entry information, including the user IP address, UDP port number, HTTP or HTTPS request packet mode, user name, and user MAC address.

Example

The actual command output varies according to the device. The command output here is only an example.
