ipv6-family

Function

The ipv6-family command configures a BGP IPv6 address family and displays the BGP IPv6 address family view.

The undo ipv6-family command deletes the configured BGP IPv6 address family and all configurations in the view.

By default, no BGP IPv6 address family is configured for BGP.

Format

ipv6-family unicast

ipv6-family

undo ipv6-family [ unicast ]

Parameters

Parameter Description Value
unicast

Displays the unicast address family view.

-

Views

BGP view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If no parameter is specified, the IPv6 unicast address family view is displayed by default. Similarly, if you run the undo ipv6-family command without specifying any parameter, the configurations of the IPv6 unicast address family are deleted.

Configuration Impact

If no parameter is specified in the undo ipv6-family command, the configuration of the IPv6 unicast address family is deleted.

If a BGP peer exists in the address family, after this address family is deleted, the BGP connections with the peer in other address families are disconnected and automatic renegotiation is triggered.

Example

# Enter the BGP-IPv6 unicast address family view.
<HUAWEI> system-view
[HUAWEI] bgp 100
[HUAWEI-bgp] ipv6-family unicast
[HUAWEI-bgp-af-ipv6]
