distribute-mode enable

Function

The distribute-mode enable command enables the DAP network collaboration function in the zero-roaming distributed Wi-Fi 6 solution or the 1T1R mode in the zero-roaming distributed Wi-Fi 7 solution.

The undo distribute-mode enable command restores the default setting of the DAP network collaboration function or the 1T1R mode.

By default, the DAP network collaboration function is disabled in the zero-roaming distributed Wi-Fi 6 solution, and the 1T1R mode is disabled (that is, 2T2R is used) in the zero-roaming distributed Wi-Fi 7 solution.

Format

distribute-mode enable

undo distribute-mode enable

Parameters

None

Views

AP system profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

In the zero-roaming distributed Wi-Fi 6 solution, this command is used to enable the DAP network collaboration function. After an extranet AP or backup AP is connected to a DAP, you can run this command to enable the DAP network collaboration function. In this way, the extranet AP or backup AP can share the ORUs and AUs connected to the DAP, thereby achieving the backup solution or the integrated deployment of the intranet and extranet within the same coverage area.

In the zero-roaming distributed Wi-Fi 7 solution, this command is used to enable the 1T1R mode. In ward scenarios where one AU is installed in each room, you need to enable the 1T1R mode. In conference and other scenarios where two AUs are deployed in each room, you are advised to disable the 1T1R mode to improve the rate.

Precautions

In the zero-roaming distributed Wi-Fi 6 solution:

  • When configuring a backup solution, you also need to run the type service-backup distribute command to set the VAP type of the backup AP to distributed-AP backup service.
  • Network collaboration functions (including intranet and extranet collaboration, and DAP backup) are supported only by the AirEngine 6760-X1E and AirEngine 6761-21E with external antennas.
  • After the DAP network collaboration function is configured on an AirEngine 6760-X1E, the AP can go online only through the 10GE/PoE_IN interface (with a negotiated rate of 1 Gbit/s) and the AP wired interfaces, IoT interface, and USB interface cannot be used.
  • There is no constraint on the wire sequence mapping between RF ports (Wi-Fi0 to Wi-Fi3) on the DAP and RF ports (2.4G&5G_A to 2.4G&5G_D) on the extranet AP. Note that Wi-Fi0 must connect to the extranet AP.

In the zero-roaming distributed Wi-Fi 7 solution:

  • This function is supported by both intranet and extranet APs of Wi-Fi 7 DAPs.
  • If the enabling status of the 1T1R mode of APs in the same ASFN roaming domain is different, the 1T1R mode is used.

Example

# Enable the DAP network collaboration function.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name system1
[HUAWEI-wlan-ap-system-prof-system1] distribute-mode enable
