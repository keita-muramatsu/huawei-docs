ipv6 bgp-ls enable

Function

The ipv6 bgp-ls enable command enables IS-IS IPv6 topology advertisement.

The undo ipv6 bgp-ls enable command disables IS-IS IPv6 topology advertisement.

By default, IS-IS IPv6 topology advertisement is disabled.

Format

ipv6 bgp-ls enable [ level-1 | level-2 | level-1-2 ] [ exclude-prefix ]

undo ipv6 bgp-ls enable [ level-1 | level-2 | level-1-2 ] [ exclude-prefix ]

Parameters

Parameter Description Value
level-1

Enables IS-IS Level-1 topology advertisement to BGP.

-
level-2

Enables IS-IS Level-2 topology advertisement to BGP.

-
level-1-2

Enables IS-IS Level-1 and Level-2 topology advertisement to BGP.

If no level is specified in the command, both Level-1 and Level-2 topologies are advertised to BGP.

-
exclude-prefix

Ignores IPv4 or IPv6 prefixes.

-

Views

IS-IS view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The IS-IS IPv6 topology is advertised to BGP-LS. BGP advertises the topology to the controller, and the path is planned based on the IS-IS topology on the controller.

Topology information includes IPv6 node information, link information ,prefix information and SRv6 SID.

Precautions

  • To enable the attribute information about each link to be separately reported to the controller through BGP-LS, run the ipv6 advertise link attributes command. Alternatively, configure a global address on the corresponding interface.
  • The ipv6 bgp-ls enable command reports data, including but not limited to the following data:
    • Node information, including systemId, IPv4 LsrId, IPv6 LsrId, AdminIp, SRGB, and SRv6 capability information (not differentiated between IPv4 and IPv6)
    • IPv6 link information, including systemId, local IPv6 interface address and index, peer IPv6 interface address and index, IPv6 delay, and End.X
    • IPv6 prefix information, including the prefix mask, metric, and tag
    • End SID information, including the SID, flag, and algorithm
    • Slice information, including the slice type and maximum bandwidth of the slice interface
    • Locator information, including the locator prefix, mask length, priority, and algorithm
  • Conditions for reporting IPv4 LSR IDs using BGP-LS
    • Conditions for reporting local IPv4 LSR IDs using BGP-LS (both conditions a and b must be met):

      a. The bgp-ls enable or ipv6 bgp-ls enable command is run in the IS-IS process.

      b. TE is enabled for the IS-IS process using the traffic-eng command.
    • Conditions for reporting remote IPv4 LSR IDs using BGP-LS (both conditions a and b must be met):

      a. The bgp-ls enable or ipv6 bgp-ls enable command is run in the IS-IS process.

      b. The LSP 134 TLV (Traffic Engineering router ID TLV) received from the remote end carries valid LSR IDs.
  • Conditions for reporting IPv6 LSR IDs using BGP-LS
    • Conditions for reporting local IPv6 LSR IDs using BGP-LS (both conditions a and b, conditions a and c, or conditions a and d are met):

      a. The bgp-ls enable or ipv6 bgp-ls enable command is run in the IS-IS process.

      b. The te ipv6-router-id ipv6Addrcommand is run globally, and the ipv6 traffic-eng command is run in the IS-IS process.

      c. The isis bgp-ls report router-capability ipv6-router-id command is run in the system view. The loopback interface of the IS-IS process has a 128-bit host address, and the isis ipv6 suppress-reachability command is not run on this interface (the smallest address is used for reporting).

      d. The isis bgp-ls report router-capability ipv6-router-id command is run in the system view. A non-loopback interface of the IS-IS process has an address, and the isis ipv6 suppress-reachability command is not run on this interface (the smallest address is used for reporting).
    • Conditions for reporting remote IPv6 LSR IDs using BGP-LS (both conditions a and b, or conditions a and c are met):

      a. The bgp-ls enable or ipv6 bgp-ls enable command is run in the IS-IS process.

      b. The LSP 140 TLV (IPv6 TE Router ID TLV) received from the remote end carries valid IPv6 LSR IDs.

      c. The isis bgp-ls report router-capability ipv6-router-id command is run in the system view, and the 12 sub-TLV (IPv6 Router ID sub TLV) of the LSP 242 TLV (Router Capability TLV) received from the remote end carries valid IPv6 router IDs.

Example

# Enable IS-IS IPv6 topology advertisement and filter all route prefixes.
<HUAWEI> system-view
[HUAWEI] isis 1
[HUAWEI-isis-1] ipv6 enable
[HUAWEI-isis-1] ipv6 bgp-ls enable exclude-prefix
# Enable IS-IS IPv6 topology advertisement.
<HUAWEI> system-view
[HUAWEI] isis 1
[HUAWEI-isis-1] ipv6 enable
[HUAWEI-isis-1] ipv6 bgp-ls enable
