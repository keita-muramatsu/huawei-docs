srv6-te-policy locator

Function

The srv6-te-policy locator command associates an SRv6 TE Policy with a maximum of two SRv6 locators, with binding SIDs being specified for the SRv6 TE Policy in the ranges of the locators.

The undo srv6-te-policy locator command restores the default configuration.

By default, SRv6 TE policy is not associated with a locator.

Format

srv6-te-policy locator locator-name

undo srv6-te-policy locator [ locator-name ]

Parameters

Parameter Description Value
locator-name

Specifies SRv6 locator.

The value is a string of 1 to 31 case-sensitive characters. When double quotation marks are used around the string, spaces are allowed in the string.

Views

Segment routing IPv6 view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After configuring the Binding SID for the SRv6 TE Policy, you can use the Binding SID for path stitching. The Binding SID needs to be configured within the Locator network segment.

You can use this command to associate an SRv6 TE Policy with an SRv6 locator and specify a binding SID for the SRv6 TE Policy.

Precautions

Running the undo srv6-te-policy locator command reclaims all dynamic SRv6 TE Policy binding SIDs within the locator range. Exercise caution when running this command.

Example

# Configure an SRv6 TE Policy to associate with a locator in Segment Routing IPv6.
<HUAWEI> system-view
[HUAWEI] segment-routing ipv6
[HUAWEI-segment-routing-ipv6] locator test1 ipv6-prefix 2001:DB8:1:: 64 static 32
[HUAWEI-segment-routing-ipv6-locator] quit
[HUAWEI-segment-routing-ipv6] srv6-te-policy locator test1
