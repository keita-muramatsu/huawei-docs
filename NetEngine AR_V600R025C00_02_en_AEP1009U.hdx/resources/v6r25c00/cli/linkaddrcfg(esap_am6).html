link-address

Function

The link-address command configures the network prefix in the IPv6 address pool view.

The undo link-address command deletes the network prefix configured in the IPv6 address pool view.

By default, no network prefix is configured in the IPv6 address pool view.

Format

link-address ipv6-prefix/ipv6-prefix-length

undo link-address ipv6-prefix/ipv6-prefix-length

Parameters

Parameter Description Value
ipv6-prefix/ipv6-prefix-length

Specifies the network prefix and prefix length.

ipv6-prefix: The total length of the value is 128 bits. The string is divided into eight groups, each of which consists of four hexadecimal digits. The value is in the format of X:X:X:X:X:X:X:X.

ipv6-prefix-length: The value is an integer ranging from 1 to 128.

Views

DHCP IPv6 address pool view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If a DHCPv6 client needs to request network configuration information (such as the DNS server address) except the IPv6 address from the DHCPv6 server and the address prefix is not configured in the address pool, you can run the link-address command to configure the network prefix in the IPv6 address pool view.

When the device functions as a DHCPv6 or DHCPv6 PD server, it may have multiple IPv6 address pools configured. After the DHCPv6 or DHCPv6 PD server receives a DHCPv6 request message, it selects an IPv6 address pool based on the following rules:

  • When the device functions as the DHCPv6 server:

    • If a relay agent exists, the server selects the address pool that belongs to the same link scope with the network prefix (configured using the link-address or address prefix command) based on the first link-address field whose value is not 0 in the message. The link-address field identifies the link scope of DHCPv6 clients.
    • If no relay agent exists, the device functioning as a DHCPv6 server can only assign network parameters to clients in DHCPv6 stateless mode. In this mode, the DHCPv6 server assigns network parameters (such as DNS, NIS, and SNTP server addresses) but does not assign IPv6 addresses. IPv6 addresses of clients are automatically generated through route advertisement. To enable the DHCPv6 server to assign network parameters in DHCPv6 stateful mode, enable the DHCPv6 server function using the dhcpv6 server command in the interface view.

  • When the device functions as the DHCPv6 PD server:

    • If a relay agent exists, the server selects the address pool that belongs to the same link scope with the network prefix (configured using the link-address command) based on the first link-address field whose value is not 0 in the message. The link-address field identifies the link scope of DHCPv6 clients.
    • If no relay agent exists, the DHCPv6 PD server function cannot be enabled in the system view but can be enabled using the dhcpv6 server command in the interface view.

Prerequisites

An address pool has been created using the dhcpv6 pool command.

Precautions

Idle addresses or prefixes are assigned to DHCPv6 clients from the IPv6 address pool. Reserved addresses, conflicted addresses, and used addresses cannot be assigned to DHCPv6 clients. Reserved addresses include unspecified addresses, multicast addresses, loopback addresses, link-local addresses, NSAP addresses, and anycast addresses (defined in RFC 2526).

Example

# Bind the network prefix fc00:1::/64 to the DHCPv6 server address pool pool1. 
<HUAWEI> system-view
[HUAWEI] dhcpv6 pool pool1
[HUAWEI-dhcpv6-pool-pool1] link-address fc00:1::/64
