display update configuration

Function

The display update configuration command displays the update configuration.

Format

display update configuration

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

This command displays the upgrade configuration.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display the current update configuration.
<HUAWEI> display update configuration
Update Configuration Information:
------------------------------------------------------------                                                                       
  Update Server               : sec.huawei.com                                                                                      
  Update Port                 : 443                                                                                                 
  Update Certificate          : default_ca.cer
  SA-SDB:
    Schedule Update            : Enable
    Schedule Update Frequency  : Daily
    Schedule Update Time       : 03:35
------------------------------------------------------------

Table 1 Description of the display update configuration command output
Item Description
Update Server

Address of the upgrade server. The default domain name is sec.huawei.com.
Update Port

Port number of the update server.
Update Certificate

Name of the CA certificate used for service upgrade.
Schedule Update

Whether the scheduled upgrade function is enabled. It includes the following two states:

  • Enable: indicates that the scheduled update function is enabled.
  • Disable: indicates that the scheduled update function is disabled.
Schedule Update Frequency

Interval of the scheduled update:

  • Weekly: indicates that the update is performed weekly.
  • Daily: indicates that the update is performed daily.
  • Hourly: indicates that the upgrade is performed hourly.
Schedule Update Time

Specific time of the scheduled upgrade.
IPS-SDB

Update configuration of the IPS signature database.
AV-SDB

Update configuration of the antivirus signature database.
SA-SDB

Upgrade configuration of the SA signature database.
