net-assistant

Function

The net-assistant command displays the net assistant view.

By default, the net assistant view is not displayed.

Format

net-assistant

Parameters

None

Views

System view

Default Level

3: Management level

Usage Guidelines

The net assistant function allows for centralized management and maintenance of LAN devices through one management device. It provides automated, visualized, and batch O&M management capabilities, making the entire network visible, manageable, and controllable.

Before configuring the net assistant function, run the net-assistant command to enter the net assistant view and run the net-assistant enable command to enable the net assistant function.

Example

# Enter the net assistant view.
<HUAWEI> system-view
[HUAWEI] net-assistant
