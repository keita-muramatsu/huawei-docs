display station statistics

Function

The display station statistics command displays statistics information about STAs.

Format

display station statistics [ sta-mac sta-mac-address | ap-id ap-id ]

Parameters

Parameter Description Value
sta-mac sta-mac-address

Displays statistics about the STA with a specified MAC address.

The value is in H-H-H format. H is a hexadecimal number that contains one to four digits, such as 00e0 and fc01. If an H contains fewer than four digits, the leftmost digits are padded with 0s. For example, two 0s are added to e0 to form 00e0.
ap-id ap-id

Displays STA statistics on the AP with a specified ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

You can run the display station statistics command to view statistics information about STAs.

  • If no parameter is specified, statistics information about all STAs associated with an AC is displayed.
  • If ap-id is specified, the number of STAs associated with, disassociated from, and reassociated with the AP is displayed.
  • If sta-mac is specified, the number of packets and packet transmission rate between the STA and an AP are displayed.

Prerequisites

  • To view statistics information about a specified STA, ensure that the STA has been associated with an AP.
  • To view statistics information about STAs associated with a specified AP, ensure that the AP has been added to the AC and is in normal state.
