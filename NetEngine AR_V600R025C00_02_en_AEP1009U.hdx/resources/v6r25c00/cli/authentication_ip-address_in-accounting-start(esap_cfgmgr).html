authentication ip-address in-accounting-start

Function

The authentication ip-address in-accounting-start command disables the device from sending Accounting-Start packets that do not carry users' IP addresses.

The undo authentication ip-address in-accounting-start command enables the device to send Accounting-Start packets that do not carry users' IP addresses.

By default, the device sends Accounting-Start packets that do not carry users' IP addresses.

Format

authentication ip-address in-accounting-start [ ipv4 | ipv6 ]

undo authentication ip-address in-accounting-start [ ipv4 | ipv6 ]

Parameters

Parameter Description Value
ipv4

Indicates that the device sends an Accounting-Start packet only after learning the user's IPv4 address.

-
ipv6

Indicates that the device sends an Accounting-Start packet only after learning a user's IPv6 non-link-local address.

-

Views

Authentication profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The device reports access information and basic network information (IP address) of users through Accounting-Start packets. Therefore, the device needs to support Accounting-Start packets that carry users' IP addresses.

Precautions

If the authentication ip-address in-accounting-start command is run and there are online users, running the undo authentication ip-address in-accounting-start command causes the users to go offline.

Example

# Enable the function of carrying users' IP addresses in Accounting-Start packets.
<HUAWEI> system-view
[HUAWEI] authentication-profile name test
[HUAWEI-authen-profile-test] authentication ip-address in-accounting-start
