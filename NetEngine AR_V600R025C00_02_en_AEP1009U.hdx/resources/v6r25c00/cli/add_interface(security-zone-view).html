add interface (Security zone view)

Function

The add interface command adds interfaces to security zones.

The undo add interface command cancels the above configuration.

By default, no interface is added to a security zone.

Format

add interface { interface-name | interface-type { interface-number | interface-number.subinterface-number } }

undo add interface { interface-name | interface-type { interface-number | interface-number.subinterface-number } }

Parameters

Parameter Description Value
interface-name

Specifies an interface name.

It is equivalent to the interface type + interface number, excluding spaces.
interface-type

Specifies the type of an interface.

The interface can be an Ethernet interface or its sub-interface, Eth-Trunk interface or its sub-interface, tunnel interface, VLANIF interface, dialer interface, POS interface, IP-Trunk interface, or serial interface. Loopback interfaces and NULL interfaces do not need to be added to security zones.
interface-number

Specifies the number of an interface.

The interface must exist.
interface-number.subinterface-number

Specifies the sub-interface number.

The sub-interface must exist.

Views

Security zone view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

Except the Local zone, all the other security zones should be bound with specific interfaces for use, that is, you need to add either physical interfaces or logic interfaces to those zones.

The add interface command can be used repeatedly to add interfaces to security zones. A security zone can contain up to 4096 interfaces.

Precautions

For Ethernet interfaces/sub-interfaces and Eth-Trunk interfaces/sub-interfaces, only Layer 3 interfaces/sub-interfaces can be added to security zones. Adding Layer 2 interfaces/sub-interfaces does not take effect.

Example

# Enter the trust zone view and add the interface 10GE0/0/1 to the trust zone.
<HUAWEI> system-view
[HUAWEI] firewall zone trust
[HUAWEI-zone-trust] add interface 10GE 0/0/1
