collect diagnostic information (User view)

Function

The collect diagnostic information command collects system logs, one-click diagnosis command output, and KPI information and saves them into a compressed package.

Format

collect diagnostic information [ slot slot-id [ cpu cpu-id ] ] [ file-type { { logtype } &<1-5> | all } ] [ { all-time | start-time starttime [ end-time endtime ] } ] [ out-file outfile ] [ force ]

Parameters

Parameter Description Value
slot slot-id

Specifies a slot ID.

The value is a string of 1 to 31 case-sensitive characters. It cannot contain spaces.
cpu cpu-id

Specifies the CPU ID.

The value is a string of 1 to 31 case-sensitive characters without spaces.
file-type all

Collects all types of information, including the one-click diagnosis command output, diagnosis logs, user logs, and KPI information.

-
file-type logtype

Specifies the type of information to be collected.

Enumerated type. The following types of logs can be collected:

cmd-diag-info: one-click diagnosis command output, that is, the output of the display diagnostic-information command.

diag-log: diagnostic logs.

user-log: user logs.

kpi: KPI information.

If no log type is specified, diagnostic logs, user logs, and KPI information are collected by default.
all-time

Collects logs generated in all time periods.

-
start-time starttime

Specifies the start time.

If you specify only the start time, the system collects all the system information generated from the start time to the current time.

The value is in the format of YYYY/MM/DD,HH:MM:SS.

YYYY/MM/DD indicates year/month/day. The value of YYYY ranges from 1970 to 2100. The value of MM ranges from 1 to 12. The value of DD ranges from 1 to 31.

HH:MM:SS indicates hour:minute:second. The value of HH ranges from 0 to 23. The values of MM and SS range from 0 to 59.
end-time endtime

Specifies the end time.

The time must be later than the specified start time. The collection end time cannot be specified separately.

The value is in the format of YYYY/MM/DD,HH:MM:SS.

YYYY/MM/DD indicates year/month/day. The value of YYYY ranges from 1970 to 2100. The value of MM ranges from 1 to 12. The value of DD ranges from 1 to 31.

HH:MM:SS indicates hour:minute:second. The value of HH ranges from 0 to 23. The values of MM and SS range from 0 to 59.
out-file outfile

Specifies the path and name of the compressed file package.

The value is a string of 1 to 255 case-sensitive characters without spaces.

The length of the file package name (including the timestamp and file name extension) cannot exceed 128 bytes. If the length exceeds 128 bytes, the command fails to be executed.
force

Indicates forcible collection.

If the force parameter is not specified, the system checks whether the CPU usage, memory usage, and disk size exceed the thresholds before collecting logs. If any of the indicators exceeds the threshold, the command fails to be executed. The requirements are as follows: The CPU usage must be less than the overload threshold minus 20%, the memory usage must be less than the overload threshold minus 20 MB, and the disk space must be greater than twice the total size of information to be collected.

-

Views

User view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

If a system fault occurs, for troubleshooting purposes, you can run this command to collect system logs, one-click diagnosis command output, and performance indicator information and save them into a compressed package. When running this command, you can specify the board, log type, time range, and directory or file name of the compressed package.

Table 1 Log collection scope

Enumerated Values of file-type Collection Scope Collection Content File Name Storage Path
all All types of information. One-click diagnostic command output, diagnostic logs, user logs, and KPI information. - -
cmd-diag-info One-click diagnostic logs Output of the display diagnostic-information command.

If the slot parameter is not specified, the file name is diagnostic-information.txt.

If the slot parameter is specified, the file name is diagnostic-information_slot-id.txt.

-
user-log User logs. User logs and security logs generated by the device.

log.log and log_XXX_XXX.log.zip: user operation logs.

security.log and security_XXX_XXX.log.zip: security logs.

log.log and log_XXX_XXX.log.zip: flash:/logfile/.

security.log and security_XXX_XXX.log.zip: flash:/logfile/security/.

diag-log Diagnostic logs. Diagnostic logs generated by the device.

diaglog.log and diaglog_XXX_XXX.log.zip: diagnostic logs.

pads.pads and pads_XXX_XXX.pads.zip: maintenance logs.

Private logs.

diaglog.log and diaglog_XXX_XXX.log.zip: flash:/logfile/.

pads.pads, pads_XXX_XXX.pads.zip: flash:/logfile/pads/.

Private logs: The storage path cannot be viewed.

kpi KPI information. KPI statistics of the device, such as the CPU and memory usage.

cpu.csv and cpu.zip: KPI statistics such as the CPU usage and memory usage

iface.csv and iface.zip: information about incoming and outgoing interfaces.

kpi.dat and kpi.dat.zip: data other than the preceding two types.

cpu.csv, cpu.zip: flash:/key_kpi.

iface.csv and iface.zip: flash:/key_kpi.

kpi.dat and kpi.dat.zip: flash:/full_kpi.

Precautions

  • If another user is collecting the information, an error is reported when you run this command. In this case, try again later.
  • Log files whose name length exceeds 64 bytes are not collected.
  • If the start time and end time for log collection are not specified, all private logs are collected, and other logs in the last three days are collected. As a type of O&M logs, private logs are generated and recorded by each service during running. All private logs are collected regardless of whether a time range is specified.
  • If the path and name of the log file package are not specified, the diagnostic_information_host name_timestamp.zip file is generated in the flash memory.
  • If only the name of the log file package is specified, the package is saved in the current path (you can run the dir command to view the directory). If only the path of the log file package is specified, the diagnostic_information_host name_timestamp.zip file is generated in the specified path.
  • If the diagnostic_information directory exists in the directory where the log file package is stored, the diagnostic_information directory is deleted after the command is executed.
  • Only one compressed log file package is stored on the device. Each time you run this command, the system deletes the previously generated compressed package.

Example

# Collect system information of all slots and save the information to a specified directory.
<HUAWEI> collect diagnostic information out-file logfile/
# Collect system information of a specified slot to the default directory.
<HUAWEI> collect diagnostic information slot 0 cpu 0
# Collect diagnostic logs of a specified slot.
<HUAWEI> collect diagnostic information slot 0 cpu 0 file-type diag-log
# Collect system information of a specified slot and a specified time range to a specified file.
<HUAWEI> collect diagnostic information slot 0 start-time 2025/02/27,00:00:00 end-time 2025/02/27,08:00:00 out-file logfile/aaa.zip
