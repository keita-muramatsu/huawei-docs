display switchover state(All views)

Function

The display switchover state command displays the active/standby board switchover status.

This command is supported only on the AR8700 series and AR6700-H series.

Format

display switchover state

Parameters

None

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

Before performing an active/standby switchover, use this command to check the backup status of the active and standby boards to determine whether to perform the switchover. You can perform an active/standby switchover only when the boards are in the Ready state.

Example

The actual command output varies according to the device. The command output here is only an example.

# Display whether the current device meets the conditions for active/standby board switchover.
<HUAWEI> display switchover state
   Chassis           :  Single
   Switchover State  :  Ready
   Switchover Policy :  Board Switchover
   MainBoard         :  9
   SlaveBoard        :  10
Table 1 Description of the display switchover state(All views) command output
Item Description
Chassis

Chassis type. This is a user-defined field, indicating whether the device is a single-chassis or multi-chassis system.

Single indicates that the device is a single-chassis system.

Multiple indicates that the device is a multi-chassis system.
Switchover State

Switchover status of the active/standby board: The options are as follows:

  • Ready: The switchover can be implemented.
  • No slave: There is no standby board.
  • BatchBackup: The device is performing a batch backup, which is related to the HA status.
  • Hardware check fault: The hardware status is incorrect.
  • MBUS fault on slave board: The MBUS status of the standby board is incorrect.
  • IBC Link Error: The inter-board communication link is abnormal.
  • Cpu core status fault on slave board: The CPU core status of the standby board is faulty.
  • PIC control-bus fault on slave board: The PIC control bus of the standby board is faulty.
  • Hard bad on slave board: The active/standby status register on the standby board is faulty.
  • The FULLIN signal is abnormal on slave board: The FULLIN signal of the standby board is abnormal.
  • SATA fault on slave board: The SATA of the standby board is faulty.
  • Fwm cold status is not OK: FWM batch backup does not end.
  • The clock status of the slave board is abnormal: The clock status of the standby main control board is abnormal.
  • The PCIe fault occurs on the slave board and subcard: The PCIe link between the standby main control board and the subcard is abnormal.
  • Slave SFU configuration is not ready: The configuration of the standby SFU is not ready.
Switchover Policy

Switching policy:

  • Board Switchover: indicates the board-level switchover.
  • Process Switchover: indicates the process-level switchover.
MainBoard

ID of the active board.
SlaveBoard

ID of the standby board.
