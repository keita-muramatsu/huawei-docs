csi motion-detection-threshold

Function

The csi motion-detection-threshold command sets the motion detection threshold of the CSI sensing function for APs.

The undo csi motion-detection-threshold command deletes the motion detection threshold of the CSI sensing function configured for APs.

By default, the motion detection threshold of the CSI sensing function is 0 in the AP system profile view. In the AP view, the motion detection threshold is not configured by default, and the configuration in the AP system profile is used.

Format

csi motion-detection-threshold threshold-value

undo csi motion-detection-threshold

Parameters

Parameter Description Value
motion-detection-threshold threshold-value

Specifies the motion detection threshold. When the detection value of a motion is less than the threshold, the motion is ignored. A larger detection value of a motion indicates a larger motion degree.

The value is an integer ranging from 0 to 100.

Views

AP view, AP system profile view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If micro-motions cannot be eliminated in the environment, you can adjust the motion detection threshold to shield micro-motions.

Precautions

Increasing the motion detection threshold may also cause failures in detecting micro-motions of human bodies. Set the threshold properly based on the actual scenario.

Example

# Set the motion detection threshold of the CSI sensing function to 10 for APs.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name test
[HUAWEI-wlan-ap-system-prof-test] csi motion-detection-threshold 10
