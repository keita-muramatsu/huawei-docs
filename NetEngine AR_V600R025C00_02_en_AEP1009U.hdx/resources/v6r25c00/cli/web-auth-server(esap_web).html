web-auth-server

Function

The web-auth-server command creates a Portal server template or displays the Portal server template view.

The undo web-auth-server command deletes a Portal server template.

By default, no Portal server template is created.

Format

web-auth-server server-name

undo web-auth-server server-name

Parameters

Parameter Description Value
server-name

Specifies the name of a Portal server.

The value is a string of 1 to 31 case-sensitive characters. It cannot contain spaces. It cannot be set to - or -- and cannot contain the following characters: / \ : * ? "< > | @ ' %.

Note

The value of server-name cannot be listening-port, reply-message, version or server-source and cannot be the first or several characters of listening-port, reply-message, version or server-source.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When an unauthenticated user attempts to access the Internet, the device redirects the user to a specific site (a Portal website). The user then can access resources in the site for free. When a user needs to access non-free network resources, the user must be authenticated on the Portal website. The user is granted rights only after the user passes the authentication. The process is as follows:

  1. When an unauthenticated user enters an Internet address in the address box of the Internet Explorer to access the network, the device redirects the HTTP request to the Portal authentication page of the Portal server.
  2. The user enters authentication information on the authentication home page or in the authentication dialog box and submits the information. The Portal server sends the user authentication information to the device.
  3. After receiving user authentication information from the Portal server, the device sends the information to the authentication server for authentication and accounting.
  4. After the user passes the authentication, if no security policy is applied to the user, the device allows the user to access the Internet.

    After you run the web-auth-server command to create a Portal server template on the device, you can run other commands to configure routes between the device and the Portal server.

Follow-up Procedure

You can run the following commands to configure attributes of the Portal server template as required.

· Run the server-ip (Portal server template view) command to configure an IP address for the Portal server.

· Run the url (Portal server template view) command to configure the URL of the Portal server.

· Run the port (Portal server template view) command to configure the destination port number used by the device to send packets to the Portal server.

· Run the shared-key (Portal server template view) command to configure the shared key used by the device to exchange information with the Portal server.

Precautions

To prevent authentication failures caused by Portal server faults, you are advised to back up the Portal server.

If Portal authentication is enabled on the device, you need to configure the local gateway address used by the device to receive and respond to the packets sent by the Portal server. You can use either of the following methods to configure the address:

· Run the web-auth-server server-source all-interface command in the system view.

· Run the server-source ip-address ip-address command in the Portal server template view.

Example

# Create the Portal server template test.
<HUAWEI> system-view
[HUAWEI] web-auth-server test
