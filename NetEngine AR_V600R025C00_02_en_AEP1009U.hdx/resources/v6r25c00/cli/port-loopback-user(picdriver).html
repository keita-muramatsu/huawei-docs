loopback loop-mode (user view and system view)

Function

The loopback loop-mode command sets the loopback mode of an interface.

The undo loopback loop-mode command restores the default loopback mode of an interface.

By default, no loopback mode is configured for an interface.

Format

loopback { interface-type interface-number | interface-name } loop-mode { internal | external } [ timeout timeout-value ]

undo loopback { interface-type interface-number | interface-name } loop-mode [ { internal | external } [ timeout timeout-value ] ]

Parameters

Parameter Description Value
interface-type interface-number | interface-name

Specifies the interface where the loopback mode is to be configured. The parameters are as follows:

  • interface-type: specifies the interface type.
  • interface-number: specifies the interface number.
  • interface-name: specifies the interface name, in the format of interface-typeinterface-number.

-
internal

Sets the loopback mode of the interface to internal loopback.

-
external

Sets the loopback mode of the interface to external loopback.

-
timeout timeout-value

Specifies the loopback timeout period of an interface.

The value is an integer ranging from 5 to 3600, in seconds.

Views

System view, User view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

The loopback mode is set on an interface only when some special functions are tested. Do not enable the loopback function when the system works normally.

  • External loopback: indicates that signal flows are transmitted to outside NEs and signals sent from the peer are received to check whether the peer functions properly.
  • Internal loopback: indicates that test packets sent by an interface are sent back to itself to check whether the interface functions properly.

Prerequisites

The serdes-mode configuration has been deleted from all MultiGE interfaces in a MultiGE interface group if the command is configured on MultiGE interfaces.

Precautions

Only one loopback mode can be set for an interface at a time. If you set another loopback mode for the interface that has a loopback mode set, the latest setting takes effect.

If no license is configured for a board, interfaces on the board are unavailable. This causes a failure to set the loopback mode for the interfaces.

Example

# Configure external loopback detection on an interface and set the loopback timeout period to 60 seconds.
<HUAWEI> loopback 10GE 0/0/1 loop-mode external timeout 60
Warning: Ensure that the port is not in default VLAN 1 to avoid traffic loops. And this operation will cause other service configurations of the port to become ineffective. Continue? [Y/N]:y
