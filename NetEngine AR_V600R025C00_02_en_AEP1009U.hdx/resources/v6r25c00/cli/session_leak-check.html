session leak-check

Function

The session leak-check enable command enables the session leak check function. The auto-recover option determines whether to enable the automatic recovery function.

The undo session leak-check enable command disables session table leak check.

By default, session table leakage check and automatic recovery are disabled.

Format

session leak-check [ auto-recover ] enable

undo session leak-check enable

Parameters

Parameter Description Value
auto-recover

Enables the automatic recovery function.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If the session resources are exhausted for a long time, you are advised to enable the session table leakage check and automatic recovery functions. After the automatic recovery function is enabled, level-1 self-healing is triggered to restore flow table resources by quickly aging leaked entries, and level-2 self-healing is triggered to restore flow table resources by restarting the device.

Leaked entries: entries that are not deleted after eight times the aging time of the flow table.

Condition for triggering level-1 self-healing: The number of leaked entries is greater than 50% of the flow table specification.

Unrecoverable entries: entries that are not aged after three level-1 self-healing operations.

Condition for triggering level-2 self-healing: The number of unrecoverable entries is greater than 50% of the flow table specifications.

Precautions

After the session leak-check auto-recover enable command is configured to enable the automatic recovery function, when level-1 self-healing is triggered, flow table resources are restored by quickly aging entries. When level-2 self-healing is triggered, flow table resources are restored by restarting the device.

Example

# Enable session table leak check and automatic recovery.
<HUAWEI> system-view
[HUAWEI] session leak-check auto-recover enable
Warning: If the automatic recovery function is enabled, the device will restart when level 2 self-healing is triggered. Continue? [Y/N]:y
# Enable the session table leak check function.
<HUAWEI> system-view
[HUAWEI] session leak-check enable
