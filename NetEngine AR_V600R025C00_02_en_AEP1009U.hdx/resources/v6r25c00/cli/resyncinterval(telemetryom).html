resync-interval

Function

The resync-interval command configures the full data reporting period for a subscription.

The undo resync-interval command cancels the configuration.

By default, the full data reporting period is not configured.

Format

resync-interval interval

undo resync-interval interval

Parameters

Parameter Description Value
interval

Specifies the full data reporting period.

The value is an integer that ranges from 60 to 10080, in minutes.

Views

Subscription view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

After this command is run, the device periodically reports full data at the specified interval and uses the time when the connection is successfully established as the anchor point. Only incremental data is reported. Each time after full data is reported, the packet sequence number snId starts from 0. After the configuration is deleted, periodic full data reporting is stopped, the task status is not affected, and incremental data is reported.

Precautions

The full data reporting period applies only to OnChange+sampling. If a non-zero sampling interval is configured using the sample-interval command, the full data reporting period cannot be configured.

Example

# Set the full data reporting period to 60 minutes.
<HUAWEI> system-view
[HUAWEI] telemetry
[HUAWEI-telemetry] subscription sub1
[HUAWEI-telemetry-subscription-sub1] resync-interval 60
