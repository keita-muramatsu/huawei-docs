display sa application-statistic

Function

The display sa application-statistic command displays application identification statistics on an interface.

Format

display sa application-statistic { application application-name | top-n top-number | all } interface { interface-type interface-number | interface-name } [ inbound | outbound ]

Parameters

Parameter Description Value
application application-name

Displays statistics on packets of a specified application.

The value is a string of 1 to 32 characters and is case sensitive if it starts with UD_. If the string contains spaces, it must be enclosed in quotation marks.
top-n top-number

Displays statistics on packets with the largest number of bytes of the first Nth application protocols.

The value is an integer ranging from 1 to 20.
all

Displays statistics on packets of all application protocols.

-
interface interface-type interface-number

Displays statistics about application protocol packets on a specified interface. In the preceding information:

  • interface-type indicates the interface type.
  • interface-number indicates the number of an interface.

-
interface interface-name

Displays statistics on packets of an application protocol on a specified interface. interface-name specifies the interface name.

-
inbound

Displays packet statistics on the inbound interface.

-
outbound

Displays packet statistics on the outbound interface.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

After application identification is enabled on an interface, run the display sa application-statistic command to view statistics on packets of different application protocols.

Prerequisites

Application identification and application traffic statistics collection have been enabled using the sa enable and sa application-statistic enable commands on an interface, respectively.

Precautions

If there is no packet of an application protocol on an interface, statistics are empty.

Example

The actual command output varies according to the device. The command output here is only an example.

# Displays application identification statistics on an interface.
<HUAWEI> display sa application-statistic all interface 10ge 0/0/1
Protocol                            Direction         Packets                Bytes       Rate(bps)
------------------------------------------------------------------------------------------------------

                                     Outbound               0                    0               0
DTLS                                  Inbound              35                15615               0
                                     Outbound              30                19805               0
ICMP                                  Inbound             836                90288              11
                                     Outbound             836                90288              11
------------------------------------------------------------------------------------------------------
Table 1 Description of the display sa application-statistic command output
Item Description
Protocol

Application protocol.
Direction
  • Inbound: indicates the statistics on incoming packets.
  • Outbound: indicates the statistics on outgoing packets.

Rate of forwarded packets on an interface, in bps.
