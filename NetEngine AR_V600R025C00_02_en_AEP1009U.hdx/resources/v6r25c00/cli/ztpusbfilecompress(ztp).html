ztp usb-deployment file-compress password

Function

The ztp usb-deployment file-compress password command configures the password for decompressing the deployment file.

The undo ztp usb-deployment file-compress password command deletes the password for decompressing the deployment file.

By default, no password is configured for compressing the USB-based deployment file.

Format

ztp usb-deployment file-compress password filepasswordval

ztp usb-deployment file-compress password

undo ztp usb-deployment file-compress password

Parameters

Parameter Description Value
filepasswordval

Password for decompressing a USB deployment file.

If this parameter is not specified, you need to configure the password for decompressing the compressed file during command interaction.

The value is a string of case-sensitive characters without spaces or question marks (?). It is a string of 8 to 20 characters in plain text or a string of 128 to 148 characters in reversible cipher text. However, if the string is enclosed in double quotation marks (" "), it can contain spaces. The password consists of at least three types of the following: uppercase letters, lowercase letters, digits, and special characters.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

To ensure the security of the deployment file, you can compress the deployment file into a .zip file based on the specified password before the deployment. During USB-based deployment, the device downloads the deployment file and uses the password configured by this command to decompress the deployment file.

The password for decompressing the deployment file configured on the device must be the same as the password specified before the deployment.

Precautions

Before the deployment, you must use the vendor's device to compress the deployment file.

Before the deployment, the compressed deployment file is named in the format of name_nametype.zip, where name indicates the name of the decompressed file and nametype indicates the type of the decompressed file. The file name extension must be .zip.

Each deployment file is compressed into a .zip file. Multiple deployment files cannot be compressed into the same .zip file.

After the weak password dictionary maintenance function is enabled, the passwords defined in the weak password dictionary cannot be used. You can run the display security weak-password-dictionary command to view the passwords.

If the password parameter is not specified, you need to configure the password for compressing files during command interaction.

Example

# Configure the file compression password for USB-based deployment.
<HUAWEI> system-view
[HUAWEI] ztp usb-deployment file-compress password YsHsjx_202206
# Configure a password for compressing the USB-based deployment file (interactive naming).
<HUAWEI> system-view
[HUAWEI] ztp usb-deployment file-compress password
Please enter password:*********
Please confirm password:*********
