tunnel-protocol sd-wan

Function

The tunnel-protocol sd-wan command configures an SD-WAN tunnel encapsulation protocol for a tunnel interface.

The undo tunnel-protocol sd-wan command deletes the SD-WAN tunnel encapsulation protocol of a tunnel interface.

By default, the tunnel protocol of a tunnel interface is none, that is, no encapsulation is performed on a tunnel interface.

Format

tunnel-protocol sd-wan

undo tunnel-protocol sd-wan

Parameters

None

Views

Tunnel interface view

Default Level

2: Configuration level

Usage Guidelines

After creating a tunnel interface using the interface tunnel command, run the tunnel-protocol command to configure the SD-WAN tunnel encapsulation mode for the tunnel interface.

In an SD-WAN scenario, after the SD-WAN tunnel encapsulation mode is configured for a tunnel interface, the tunnel interface functions as the service interface of an SD-WAN tunnel and processes services (such as SA statistics collection and MQC policies).

Example

# Configure the SD-WAN tunnel encapsulation protocol for Tunnel 0.
<HUAWEI> system-view
[HUAWEI] interface tunnel 0
[HUAWEI-Tunnel0] tunnel-protocol sd-wan
