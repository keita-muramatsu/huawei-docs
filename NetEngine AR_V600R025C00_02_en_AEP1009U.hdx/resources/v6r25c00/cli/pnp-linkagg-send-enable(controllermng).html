pnp startup-link-aggregation send enable

Function

The pnp startup-link-aggregation send enable command enables the function of transmitting the flag indicating whether to establish an Eth-Trunk to a downstream device.

The undo pnp startup-link-aggregation send enable command disables the function of transmitting the flag indicating whether to establish an Eth-Trunk to a downstream device.

By default, a device does not inform its downstream device of the need to establish an Eth-Trunk.

Format

pnp startup-link-aggregation send enable

undo pnp startup-link-aggregation send enable

Parameters

None

Views

Eth-Trunk interface view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

If a new downstream device is connected to an upstream device through links and this function is enabled on the upstream device, the downstream device adds the links into an Eth-Trunk and sets the Eth-Trunk mode based on whether the Eth-Trunk mode of the upstream device is LACP during PnP VLAN negotiation with the upstream device.

The auto-negotiated Eth-Trunk can only be Eth-Trunk0, which is reserved on iMaster NCE-Campus and cannot be used by other services.

After this command is configured on Eth-Trunk0, Eth-Trunk0 cannot function as an uplink interface for Eth-Trunk auto-negotiation.

After this command is run on an Eth-Trunk interface, the Eth-Trunk interface cannot function as a PnP uplink interface for VLAN auto-negotiation.

Precautions

When the uplink interface of the downstream device is added to Eth-Trunk 0 through negotiation, the following configuration is allowed on the physical interface:

  • Run the trust dscp command to configure DSCP priority mapping for packets.
  • Layer 2 interface configuration, such as the port link-type trunk command.

Example

# Configure PnP link aggregation.
<HUAWEI> system-view
[HUAWEI] interface Eth-Trunk1
[HUAWEI-Eth-Trunk1] portswitch
[HUAWEI-Eth-Trunk1] pnp startup-link-aggregation send enable
