category (ips signature filter view)

Function

The category command adds the Intrusion Prevention System (IPS) signature of the specified category to an IPS signature filter.

The undo category command deletes the IPS signature of the specified category from an IPS signature filter.

By default, no configuration is performed.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR8100 series, AR5710-S8P1XDSE-2LTE4EA and AR6700-H series.

Format

category { category-name &<1-100> | all }

undo category { category-name &<1-100> | all }

Parameters

Parameter Description Value
category-name

Specifies the category name. You can configure 1 to 100 parameters in one command.

The value is of the enumerated type and is case-insensitive. Select a value according to the command help.
all

Indicates all categories.

-

Views

IPS signature filter view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The category command adds IPS signatures of a specified category to an IPS signature filter. Signatures of a maximum of 100 categories can be added to an IPS signature filter at a time. To add signatures of more categories to the signature filter, run this command consecutively.

The signature categories are dynamically generated based on the IPS signature database file. That is, the signature category varies according to the IPS signature database file. After the IPS signature database is updated, you are advised to check the signature category changes and update the configuration as required.

Precautions

If no IPS signature database file is loaded, only the option all can be selected.

After running this command, run the engine configuration commit command to commit the configuration for the configuration to take effect. You are advised to commit the configuration after all content security configurations are complete.

Example

# Configure category Remote-File-Inclusion for IPS signature filter hello in IPS profile profile1. 
<HUAWEI> system-view
[HUAWEI] profile type ips name profile1
[HUAWEI-profile-ips-profile1] signature-set name hello
[HUAWEI-profile-ips-profile1-sigset-hello] category Remote-File-Inclusion
