poe power-on delay

Function

The poe power-on delay command sets the PoE power supply delay on an interface.

The undo poe power-on delay command restores the default PoE power supply delay on an interface.

The default PoE power supply delay is 0, indicating no delay.

This command is supported only on the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA.

Format

poe power-on delay delaytimes

undo poe power-on delay

Parameters

Parameter Description Value
delaytimes

Specifies the PoE power supply delay.

The value is an integer ranging from 0 to 60, in seconds.

Views

10GE interface view, 25GE interface view, GE interface view, Multi-GE interface view, Interface group view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

The holding current of a PD is insufficient in the moment it is powered on. So, the device assumes that the PD has been disconnected and powers it off. IEEE standards require a powered-on PD to maintain a current value of more than 10 mA for at least 75 ms in each 325 ms duration. Otherwise, the device assumes that the PD has been disconnected and powers it off.

To solve this problem, you can set the power supply delay for interfaces on the PoE device. When the delay expires, the device detects the holding current to ensure that non-standard PDs can be properly powered on.

Precautions

This command is supported only on Layer 2 interfaces.

If a PD is connected to an interface configured with a power supply delay, do not replace the PD within the delay. Otherwise, the new PD cannot work properly.

Example

# Set the PoE power supply delay to 5 seconds on the interface.
<HUAWEI> system-view
[HUAWEI] interface GE 1/0/1
[HUAWEI-GE1/0/1] poe power-on delay 5
Warning: Do not replace the PD with another device in 5 seconds since the PD was connected, because this operation will cause the ne
wly connected device to work abnormally. Continue? [Y/N]:y
