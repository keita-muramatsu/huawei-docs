pki set certificate warning-period

Function

The pki set certificate warning-period command configures the pre-expiration and post-expiration warning interval for CA and local certificates.

The undo pki set certificate warning-period command restores the default pre-expiration and post-expiration warning interval for CA and local certificates.

By default, the pre-expiration and post-expiration warning interval for CA and local certificates is 24 hours.

Format

pki set certificate warning-period hour

undo pki set certificate warning-period

Parameters

Parameter Description Value
hour

Specifies the pre-expiration and post-expiration warning interval for CA and local certificates.

The value is an integer ranging from 1 to 24, in hours.

Views

AP system profile view

Default Level

2: Configuration level

Usage Guidelines

You can run this command to modify the pre-expiration and post-expiration warning interval for CA and local certificates.

  1. The default pre-expiration warning period for CA and local certificates is 90 days. Upon detecting that the CA or local certificate will expire in less than 90 days, the device generates an alarm at an interval specified by the parameter hour.
  2. After the CA or local certificate expires, the device generates an alarm at an interval specified by the parameter hour by default.

Example

# Set the pre-expiration and post-expiration warning interval for CA and local certificates to 5 hours.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-system-profile name ap-system1
[HUAWEI-wlan-ap-system-prof-ap-system1] pki set certificate warning-period 5
