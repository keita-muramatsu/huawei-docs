header

Function

The header login information command sets the header information displayed when the terminal connection is activated during user login.

The header login file command sets the file content displayed when the terminal connection is activated during user login.

The header shell information command sets the header information displayed when a user successfully logs in to the device and establishes a session.

The header shell file command sets the file content displayed when a user successfully logs in to the device and establishes a session.

The undo header login command deletes the header information displayed when users log in.

The undo header shell command deletes the file content displayed when a user successfully logs in to the device and establishes a session.

By default, no title is displayed if a user logs in.

Format

header login information loginText

header login file loginFile

header shell information shellText

header shell file shellFile

undo header login

undo header shell

Parameters

Parameter Description Value
login

Displays the title when the terminal connection is activated during the login to the device.

-
file loginFile

Specifies the file name used in the title.

The value is a string of 1 to 64 case-sensitive characters. It cannot contain spaces.
file shellFile

Specifies the file name used in the title.

The value is a string of 1 to 64 case-sensitive characters. It cannot contain spaces.
shell

Displays the title when a session is set up after the successful login to the device.

-
information loginText

Specifies the title information.

The value is a string of 1 to 3002 characters. It can contain spaces.
information shellText

Specifies the title information.

The value is a string of 1 to 3002 characters. It can contain spaces.

Views

System view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

  • To provide some prompts or warnings to users, you can run this command to configure such information as titles on the device. When a user logs in to the device, the configured titles will be displayed.

  • You can directly define title information by specifying the information <loginText> parameter, or configure the content of a specified file as title information by specifying the file <loginFile> parameter.

  • When a terminal connection is activated and a user attempts to log in, the terminal displays the title configured using the header login command. If the user successfully logs in, the terminal displays the title configured using the header shell command.

Configuration Impact

If you run the header command several times, the last configuration overrides the previous configuration.

After the login title is configured, any user that logs in to the system can view the title.

Precautions

  • The title text must start and end with the same letter.
  • To enter the interactive mode, enter the start delimiter to enter the text editing mode. After the end delimiter is entered, the system automatically exits the interaction process.
  • If you do not need to enter the interactive mode, you only need to press Enter after the same letter is displayed at the beginning and end of the text.

Example

# Set the file of the title to header-file.txt, in which the contents are Hello Welcome.
<HUAWEI> system-view
[HUAWEI] header login file flash:/header-file.txt
# Set the session creation title to Hello Welcome by using the character h as the start and end characters.
<HUAWEI> system-view
[HUAWEI] header shell information hHello Welcomeh
