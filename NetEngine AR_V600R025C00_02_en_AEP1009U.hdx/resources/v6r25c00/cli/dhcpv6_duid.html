dhcpv6 duid

Function

The dhcpv6 duid command configures a unique identifier DUID for the DHCPv6 device.

By default, the device generates a DUID based on the link-layer (LL) address.

Format

dhcpv6 duid { ll | llt | duid }

Parameters

Parameter Description Value
ll

Configures the device to generate a DUID based on the link-layer address (MAC address).

-
llt

Configures the device to generate a DUID based on the link-layer address (MAC address) plus time.

-
duid

Specifies the DUID of the device.

The value is a hexadecimal string with an even number of 8 to 28 case-insensitive characters, including digits (0-9), uppercase letters (A-F), and lowercase letters (a-f).

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

A DUID uniquely identifies a DHCPv6 device. Each server or client has a unique DUID. Servers use DUIDs to identify clients and clients use DUIDs to identify servers. After this command is executed, the generated DUID is saved to the storage device:/dhcp/dhcp-duid.txt file. The display dhcpv6 duid command can be run to query the DUID of a device.

Precautions

  • The DUIT must be globally unique and fixed.

Example

# Configure the device to generate a DUID based on the link-layer address.
<HUAWEI> system-view
[HUAWEI] dhcpv6 duid ll
Warning: The DHCP identifier should be globally unique and stable. Continue to change it? [Y/N]:y
