display ip vpn-instance

Function

The display ip vpn-instance command displays VPN instance information.

Format

display ip vpn-instance [ vpn-instance-name ]

display ip vpn-instance verbose

display ip vpn-instance interface

display ip vpn-instance verbose vpn-instance-name

display ip vpn-instance vpn-instance-name interface

display ip vpn-instance [ vpn-instance-name ] tunnel-info

Parameters

Parameter Description Value
vpn-instance-name

Specifies the name of a VPN instance.

The value is a string of 1 to 31 case-sensitive characters without spaces. The VPN instance name cannot be _public_. If the character string is quoted by double quotation marks, the character string can contain spaces.
verbose

Displays detailed information about a VPN instance.

-
interface

Displays information about the interface bound to the VPN instance.

-
tunnel-info

Displays information about the LSP associated with the VPN instance.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

Usage Scenario

To check the configurations of a VPN instance, including its bound interfaces and associated LSPs, run the display ip vpn-instance command. VPN instances support both IPv4 and IPv6 address families. After the display ip vpn-instance command is run, information about each address family of a VPN instance is displayed separately.

If vpn-instance-name is not specified, information about all configured VPN instances is displayed.

If interface is specified, all interfaces bound to a specified VPN instance are displayed.

If tunnel-info is specified, information about the LSPs to which remotely leaked routes in the current VPN instance address family recurse, that is, information about the LSPs between PE peers, is displayed. If a non-LSP tunnel is used between PEs, this field is not displayed.

Table 1 Description of the display ip vpn-instance command output
Item Description
Total VPN-Instances configured

Total number of VPN instances locally configured.
Total IPv4 VPN-Instances configured

Total number of locally configured VPN instances for which the IPv4 address family is enabled.
Total IPv6 VPN-Instances configured

Total number of locally configured VPN instances for which IPv6 address families are enabled.
VPN-Instance Name

VPN instance name.
VPN-Instance Name and ID

Name and ID of the VPN instance. The ID is allocated by the system and is easy to find.
ID

ID of a tunnel used in the VPN instance address family.
Interfaces

Interface bound to the VPN instance. This field is displayed only after the ip binding vpn-instance command is configured on the interface.
Address family

Address family enabled for the VPN instance:

  • No information is displayed if no address family is enabled.
  • ipv4 is displayed if only the IPv4 address family is enabled.
  • ipv6 is displayed if only the IPv6 address family is enabled.
  • ipv4 ipv6 is displayed if both the IPv4 and IPv6 address families are enabled.
Address family ipv4

Information about the IPv4 address family enabled for the VPN instance.
Address family ipv6

Information about the IPv6 address family enabled for the VPN instance.
Create date

Time when the VPN instance is created.
Up time

Period during which the VPN instance maintains in the up state.
Vrf Status

VPN status:

  • UP.
  • DOWN.
Route Distinguisher

RD of the VPN instance IPv4 address family or IPv6 address family.
Export VPN Targets

List of the export route targets.
Export Route Policy

Export route-policy applied to the IPv4 or IPv6 address family of the VPN instance. This field is displayed only after the export route-policy command is run in the VPN instance IPv4 or IPv6 address family view.
Import VPN Targets

List of import route targets (IRTs).
Import Route Policy

Import route-policy applied to the IPv4 or IPv6 address family of the VPN instance. This field is displayed only after the import route-policy command is run in the VPN instance IPv4 or IPv6 address family view.
Label Policy

Label policy:

  • label per route indicates that each route in a VPN instance is assigned a label. By default, a VPN instance assigns labels in this mode.
Per-Instance Label

Label value used when all VPN routes in the VPN instance IPv4 or IPv6 address family share the same label. This field is displayed only after the apply-label per-instance command is run in the VPN instance IPv4 or IPv6 address family view.
IP FRR Enable

IP FRR is enabled for the address family.
The diffserv-mode Information is

DiffServ mode, in which resources such as bandwidth are allocated in real time. The DiffServ mode can be:

  • uniform.
  • pipe.
The ttl-mode Information is

TTL processing mode. The value can be uniform or pipe.
Tunnel ID

ID of the tunnel corresponding to the next hop address of the route learned by the VPN instance from the peer PE.
Tunnel Name

Name of a tunnel.
Tunnel Policy

Tunnel policy applied to the VPN instance.
Tunnel Type

Tunnel type:

  • 1: LDP.
  • 52: SRV6TE POLICY.
  • 56: SDWAN.

The supported tunnel types vary according to the device.
Maximum Routes Limit

Maximum number of prefixes supported by the current address family. This field is displayed only after the prefix limit command is run in the VPN instance IPv4 or IPv6 address family view.
Threshold Routes Limit

Percentage of the maximum number of prefixes specified in the current address family. When the percentage is reached, an alarm is generated. This field is displayed only after the prefix limit command is run in the VPN instance IPv4 or IPv6 address family view.
Local-cross disable

Local route leaking is disabled in an L3VPN service scenario. By default, this field is not displayed in the output of the local-cross unicast disable command run in the VPN instance IPv4/IPv6 address family view.
RD

Route identifier of the VPN-IPv4 address family or VPN-IPv6 address family.
Nexthop Address

Next-hop address of the route learned by the VPN instance from the peer PE.
IID

IID value.
Color

Color.
