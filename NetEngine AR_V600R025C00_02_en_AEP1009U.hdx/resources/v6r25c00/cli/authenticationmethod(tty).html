authentication-mode (User interface view)

Function

The authentication-mode command sets the authentication mode for the login to the user interface view.

The undo authentication-mode command restores the default authentication mode.

By default, no authentication mode is set.

Format

authentication-mode aaa

authentication-mode password

undo authentication-mode

Parameters

Parameter Description Value
password

Specifies the password authentication mode for the login to the user interface view.

-
aaa

Specifies the AAA authentication mode for the login to the user interface view.

-

Views

CONSOLE-type user interface view, VTY-type user interface view

Default Level

3: Management level

Usage Guidelines

Usage Scenario

  • An authentication mode must be configured for the user interface login. Otherwise, users cannot log in to the device.
  • If AAA authentication is configured, the level of the commands that a user can run depends on the priority of the AAA user.
  • If password authentication is configured, the level of commands that a user can use depends on the level of the user interface to which the user logs in. The user interface level can be changed using the user privilege level command.

Precautions

  • After setting the authentication mode to password for a user interface, you can run the set authentication password command to change the authentication password of the user interface.
  • After you set the authentication mode to AAA for a user interface, the password set for the user interface is automatically cleared.
  • When you change the authentication mode for a user interface from password to AAA, the system prompts you to enter the old password.
  • If the AAA authentication mode is used, the AAA user name and password must exist. Otherwise, the user cannot log in. If the AAA user does not exist, you can run the local-user command to create a local user and set the login password.
  • When the undo authentication-mode command is used to delete an authentication mode of a user interface, the system prompts you to confirm the delete operation.
  • The password authentication mode is not secure, and you are advised to use the AAA authentication mode.
  • To log in to the device through SSH, you must configure the AAA authentication mode.
  • This command does not support the password authentication mode in the VTY user interface view.

Example

# In the vty user interface view, set the authentication mode to aaa.
<HUAWEI> system-view
[HUAWEI] user-interface vty 0 4
[HUAWEI-ui-vty0-4] authentication-mode aaa
# Delete the user interface authentication mode.
<HUAWEI> system-view
[HUAWEI] user-interface console 0
[HUAWEI-ui-console0] undo authentication-mode
Warning: After authentication-mode is deleted, users must configure a new password if users login through the user-interface ui-console0 or configure an authentication mode for current user-interface before next time login. Otherwise, users cannot login. Continue?: [Y/N]:y
# In the console user interface view, set the authentication mode to aaa.
<HUAWEI> system-view
[HUAWEI] user-interface console 0
[HUAWEI-ui-console0] authentication-mode aaa
