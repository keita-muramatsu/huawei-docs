ztp domain-type

Function

The ztp domain-type command presets the domain name of the registration query center on the device.

The undo ztp domain-type command deletes the preset domain name of the registration query center.

By default, the registration query center domain name register.naas.huawei.com is preset.

Format

ztp domain-type registration-center domain domainvalue [ port portvalue ]

undo ztp domain-type registration-center domain domainvalue

Parameters

Parameter Description Value
registration-center

Specifies the preset domain name type as registration query center.

-
domain domainvalue

Specifies the domain name of the corresponding device type.

The value is a string of 1 to 63 characters, including letters, digits, periods (.), hyphens (-), and underscores (_). Spaces are not supported.
port portvalue

Specifies the port number.

The value is 10020.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

This command applies only to the ZTP deployment process. You can load this command to the default configuration file to preset the domain name of the registration query center. During the deployment through the registration query center, the domain name preset through the command is obtained and parsed to obtain the address of the registration query center so that the device can communicate with the registration query center.

Precautions

If a domain name already exists on the device, you need to clear the original configuration and then deliver a new one. Otherwise, an error message will be displayed.

Example

# Set the domain name of the registration query center to register.naas.huawei.com and port number to 10020.
<HUAWEI> system-view
[HUAWEI] ztp domain-type registration-center domain register.naas.huawei.com port 10020
