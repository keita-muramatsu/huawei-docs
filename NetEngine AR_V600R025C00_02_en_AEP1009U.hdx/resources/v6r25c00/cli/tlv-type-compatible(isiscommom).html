tlv-type-compatible standard mirror-sid

Function

The tlv-type-compatible standard mirror-sid command changes the type value of Mirror SID Function in the packets to be sent from 40 to 74 to comply with the protocol standard and configures the device to consider both the type values 40 and 74 of Mirror SID Function in received packets valid.

The undo tlv-type-compatible standard mirror-sid command restores the type value of Mirror SID Function to 40 and configures the device to consider only the type value 40 of Mirror SID Function in received packets valid.

By default, the type value of Mirror SID Function is 40.

Format

tlv-type-compatible standard mirror-sid

undo tlv-type-compatible standard mirror-sid

Parameters

None

Views

IS-IS view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

By default, the type value of Mirror SID Function is 40 on Huawei devices and is 74 on some other vendors' devices. A type value inconsistency may cause mirror SID identification failures, leading to packet loss and adversely affecting services. When a Huawei device needs to communicate with a non-Huawei device and they have different type values of Mirror SID Function, you can run the tlv-type-compatible standard mirror-sid command on the Huawei device to change its type value of Mirror SID Function.

Precautions

After the command is run, the type value advertised by the IS-IS process is 74, and the local device considers that both the type values 40 and 74 of Mirror SID Function in received packets valid. You need to determine whether the devices that are not configured with this command support the type value 74 as they will receive the type value 74 from the local device.

Example

# Set the type value of Mirror SID Function to 74 in an IS-IS process.
<HUAWEI> system-view
[HUAWEI] isis 1
[HUAWEI-isis-1] tlv-type-compatible standard mirror-sid
