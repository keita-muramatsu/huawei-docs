web-manager server-source

Function

The web-manager server-source -i command specifies the source interface of the web server.

The undo web-manager server-source -i command cancels the source interface configuration of the web server.

The web-manager server-source all-interface command specifies all valid interfaces as the source interface of the web server.

The undo web-manager server-source all-interface command cancels the configuration of specifying all valid interfaces as the source interface of the web server.

By default, no source interface is specified for the web server.

Format

web-manager server-source -i { interface-name | interface-type interface-num }

web-manager server-source all-interface

undo web-manager server-source all-interface

undo web-manager server-source -i { interface-name | interface-type interface-num }

Parameters

Parameter Description Value
interface-name

Specifies the name of the source interface of the web server.

-
interface-type

Specifies the source interface type of the web server.

-
interface-num

Specifies the source interface number of the web server.

The value is a string of 1 to 63 characters.
all-interface

Specifies all the interfaces that are configured with IP addresses on the device.

-
-i

Specifies an interface.

-

Views

System view

Default Level

2: Configuration level

Usage Guidelines

The priority of the web-manager server-source all-interface command is higher than that of the web-manager server-source -i command. After the web-manager server-source all-interface command is configured, the undo web-manager server-source -i command configured later does not take effect.

Note:

If the web-manager server-source all-interface command is not run, disabling the source interface of the current web server will disconnect the web service of the interface.

Example

# Configure VLANIF 1 as the source interface for the web server.
<HUAWEI> system-view
Enter system view, return user view with return command.
[HUAWEI] web-manager server-source -i Vlanif 1
Warning: Web server source configuration will take effect in the next login. Do you want to continue?  [Y/N]:Y
Info: Succeeded in setting the source interface of the Web server to Vlanif1.
# Configure the management interface MEth 0/0/0 as the source interface of the web server.
<HUAWEI> system-view
Enter system view, return user view with return command.                        
[HUAWEI] web-manager server-source -i MEth0/0/0
Warning: Web server source configuration will take effect in the next login. Do you want to continue?  [Y/N]:Y
Info: Succeeded in setting the source interface of the Web server to MEth0/0/0.
