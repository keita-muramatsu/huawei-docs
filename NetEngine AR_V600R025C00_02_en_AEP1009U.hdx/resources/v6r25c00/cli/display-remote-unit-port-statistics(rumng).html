display remote-unit port statistics

Function

The display remote-unit port statistics command displays traffic statistics about an interface on an RU.

Format

display remote-unit port [ port-id ] statistics [ connect-interface { interface-name | interface-type interface-number } | name remote-unit-name ]

display remote-unit port [ port-id ] statistics { connect-interface { interface-name | interface-type interface-number } | name remote-unit-name } realtime

Parameters

Parameter Description Value
connect-interface interface-name

Specifies the name of an interface.

The value is a string of 1 to 31 characters and must be set according to the device configuration.
connect-interface interface-type interface-number

Specifies the type and number of an interface. The interface type and number can be closely next to each other or separated by a space character.

The value ranges from 1 to 32, depending on the device configuration.
name remote-unit-name

Specifies the alias of an RU.

The value is a string of 1 to 32 case-sensitive characters. It cannot contain spaces.
port port-id

Specifies the index of an interface on an RU.

The value is an integer in the range from 1 to 34. port-id indicates the port ID of an RU, which may be different from the physical port number printed on the panel. For example, if the downlink port numbers are 1 to 8 and the uplink port numbers are 9 to 10 on the panel, set port-id to an integer in the range from 1 to 10 according to the actual port for connection. If the downlink port numbers are 1 to 8 and the uplink port numbers are 1 to 2 on the panel, set port-id to an integer in the range from 1 to 10 (1 to 8: downlink ports; 9: uplink port 1; 10: uplink port 2).
realtime

Queries real-time information.

-

Views

All views

Default Level

1: Monitoring level

Usage Guidelines

You can view the running status and statistics of an interface on a remote module, including the physical status, basic configuration, and packet forwarding on the interface. When you need to collect traffic statistics or diagnose faults on an interface in real time, or the information about the remote module reported at an interval of 60s cannot support fault locating, run this command.

Table 1 Description of the display remote-unit port statistics command output
Item Description
ESN

ESN of an RU.
Name

Alias of an RU. If the RU does not have an alias, a hyphen (-) is displayed.
Device type

Device type of an RU.
Connect interface

Interconnection interface through which the RU is bound to the central device.
Input rate

Rate of packets on the inbound interface.
Input

Total number of received packets.

Description:

· Packets with the length greater than the jumbo frame length on the interface and correct CRC values are counted in jumbo frame statistics and are not counted in Input frame statistics.

· The remote module can forward a maximum of 10240-byte packets. Packets exceeding 10240 bytes cannot be forwarded.
Input bandwidth utilization threshold

Indicates the threshold of the input bandwidth usage.
Output rate

Rate of packets on the outbound interface.
Output

Total number of sent packets.
Output bandwidth utilization threshold

Indicates the threshold of the output bandwidth usage.
Total Error

Total number of error packets detected by the interface during physical layer detection.
Late Collisions

Number of delayed collision frames. A delayed collision frame indicates that the first 512 bits of a frame have been sent and the frame is delayed to be sent because a collision is detected.
Last 60 seconds input utility rate

Inbound bandwidth usage within the last 60 seconds.
Last 60 seconds output utility rate

Outbound bandwidth usage within the last 60 seconds.
GEn current state

Physical status of the GEn interface on an RU.

· DOWN: The physical layer of the interface is faulty. The possible cause is that no terminal is connected to the interface or the interface is shut down.

· Up: The physical layer of the interface is up.
Speed

Current speed of the interface.

· In auto-negotiation mode, the interface rate after auto-negotiation with the terminal is displayed.

· In non-auto-negotiation mode, you can run the speed command to set this parameter.
Duplex

Duplex mode of the interface.

· Full: full-duplex mode.

· Half: half-duplex mode.
Negotiation

Auto-negotiation status of the interface. To configure the auto-negotiation mode for an interface, run the negotiation auto port command.

• Enable: Auto-negotiation is enabled for the interface.

• Disable: Auto-negotiation is disabled for the interface.
Mode

Working mode of the interface.

· Copper: electrical interface mode.

· Fiber: optical interface mode.
Unicast

Number of unicast packets received or sent by the interface.
Multicast

Number of multicast packets received or sent by the interface.
Broadcast

Number of broadcast packets received or sent by the interface.
Jumbo

The value of this field in the outbound direction of an interface includes:

· Number of Sent Ethernet Frames with Length Greater Than 1518 Bytes and Correct FCS Values.

The value of this field in the inbound direction of an interface includes:

· Number of received Ethernet frames with length ranging from 1519 bytes to the maximum jumbo frame size and correct FCS values.

· Number of received VLAN packets with length ranging from 1519 bytes to the maximum jumbo frame size and correct FCS values.

· The packets whose length is greater than the maximum jumbo frame length are also counted in the jumbo statistics.
Discard

Number of packets discarded by an interface during physical layer detection. A possible cause can be interface congestion.

Currently, this item is not supported, and the value is displayed as 0.
Frames

Number of packets with the incorrect 802.3 length received by the interface.

Currently, this item is not supported, and the value is displayed as 0.
Pause

Indicates the number of pause frames.
CRC

Number of packets longer than 63 bytes and with incorrect FCS values.
Giants

Number of received packets with length exceeding the maximum jumbo frame size.

Currently, this item is not supported, and the statistical value is 0. Jumbo statistics are collected.
Runts

Number of undersized frames with correct CRC values received by the interface. Undersized frames are the frames that are shorter than 64 bytes and have the correct format and valid CRC field.

Packets with incorrect CRC values and the length shorter than 64 bytes are also counted in Runts.
DropEvents

Number of received packets that are discarded due to GBP full or Back Pressure.
Alignments

Number of received frames with alignment errors.

Currently, this item is not supported, and the statistical value is 0.
Symbols

Number of packets with coding errors received by the interface.
Ignoreds

Number of received MAC control frames whose OpCode is not PAUSE.

If the remote interface receives Ignoreds packets, the packets are counted as Ignoreds packets and are counted repeatedly in the unicast, multicast, or broadcast entries corresponding to the packets. Indicates the total number of incoming packets on the interface. The repeated statistics are deducted, which is correct.
Collisions

Number of collision frames. A collision frame is a packet that stops sending when a collision is detected during transmission.
Deferreds

Number of delayed packets. A delayed packet refers to a packet that is delayed to be sent because a conflict is detected before the packet is sent.
