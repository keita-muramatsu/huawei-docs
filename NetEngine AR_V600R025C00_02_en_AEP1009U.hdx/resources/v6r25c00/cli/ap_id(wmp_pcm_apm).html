ap-id (WLAN view)

Function

The ap-id command adds an AP offline or displays the AP view.

By default, no AP is added offline.

Format

ap-id ap-id

ap-id ap-id [ type-id type-id | ap-type ap-type ] { ap-mac ap-mac | ap-sn ap-sn }

ap-id ap-id [ type-id type-id | ap-type ap-type ] { ap-mac ap-mac ap-sn ap-sn }

Parameters

Parameter Description Value
ap-id

Specifies the AP ID.

For the AR5710-S8TWDSE-LTE4EA, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5700-H series, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T and AR5710-S8P1XDSE-2LTE4EA:The value is an integer ranging from 0 to 127.

For the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4 and AR6700-H series:The value is an integer in the range from 0 to 1023.

For the AR8700 series and AR8100 series:The value is an integer that ranges from 0 to 2047.
type-id type-id

Specifies the AP type ID.

The value is an integer ranging from 0 to 1023.
ap-type ap-type

Specifies the AP type.

The value is a string of 1 to 31 characters.
ap-mac ap-mac

Specifies the MAC address of an AP.

The value is in H-H-H format. An H is a hexadecimal number of 4 digits.
ap-sn ap-sn

Specifies the SN of an AP.

The value is a string of 1 to 31 case-insensitive characters, and can contain only letters and digits.

Views

WLAN view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

After an AP is successfully added to an AC, you can configure parameters for the AP offline. When the AP goes online, it uses the configured parameters.

You can run the undo ap command to delete an AP.

Precautions

To add an AP, you must enter the MAC address, SN, or MAC address+SN of the AP. In MAC address authentication mode, enter the MAC address of the AP. In SN authentication mode, enter the SN of the AP.

To enter the AP view, you only need to enter the AP ID.

Example

# Add an AP with the ID of 11, type ID of 19, and MAC address of 00e0-fc11-1111.
<HUAWEI> system-view
[HUAWEI] wlan
[HUAWEI-wlan] ap-id 11 type-id 19 ap-mac 00e0-fc11-1111
