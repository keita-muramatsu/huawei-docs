update schedule

Function

The update schedule command sets scheduled update time for the signature database.

By default, the device randomly selects a time from 00:00 to 07:59 as the scheduled time for updating all signature databases every day.

Usage Guidelines

Usage Scenario

Using the update schedule command, you can set a time for the scheduled online update of all signature databases.

To set the time for the scheduled online update of all signature databases (the update interval can be set to once a day or once a week), run the update schedule { daily | weekly { mon | tue | wed | thu | fri | sat | sun } } time command.

To configure the time for the scheduled online update of a specified signature database (the update interval can be set to once an hour, once a day, or once a week), add the signature database name keyword to the configuration command. For example, run the update schedule sa-sdb { daily | weekly { mon | tue | wed | thu | fri | sat | sun } } time command to set the time for the scheduled online update of the service awareness signature database.

Example

# Configure a scheduled update of signature databases at 02:00 every Wednesday.
<HUAWEI> system-view
[HUAWEI] update schedule weekly wed 02:00
# Configure a scheduled update of signature database at 03:00 every day.
<HUAWEI> system-view
[HUAWEI] update schedule daily 03:00
