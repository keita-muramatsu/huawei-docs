access-user arp-detect fallback

Function

The access-user arp-detect fallback command configures an IP address required for calculating the source address of offline detection packets.

The undo access-user arp-detect fallback command deletes the IP address configured for calculating the source address of offline detection packets.

By default, no IP address is configured for the device to calculate the source address of offline detection packets.

Format

access-user arp-detect fallback ip-address ip-mask

access-user arp-detect fallback ip-address mask-length

undo access-user arp-detect fallback

Parameters

Parameter Description Value
ip-address

Specifies the IP address required for calculating the source address of offline detection packets.

The value is in dotted decimal notation.
ip-mask

Specifies a subnet mask of an IP address.

The value is in dotted decimal notation.
mask-length

Specifies the mask length of an IP address.

The value is an integer ranging from 0 to 32.

Views

System view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

When the device does not function as a gateway, the device can use the source address that is on the same network segment as the client for detection. This address is calculated by the device based on the client network segment and the IP address specified in the command. The source IP address is obtained by performing the AND operation on the IP address specified in the command and the inverse mask, and then adding the client IP address segment. For example, if the client network segment is 192.168.1.0/24 and access-user arp-detect fallback 0.0.0.11 24 is specified, the calculated source address of detection packets is 192.168.1.11. The calculated IP address must be excluded from the address pool of the DHCP server to prevent the client from being assigned this IP address.

Precautions

The following source IP addresses used in offline detection packets are listed in descending order of priority:

  • IP address of the VLANIF interface corresponding to the VLAN to which the user belongs, which is on the same network segment as the user
  • Source IP address of offline detection packets in the VLAN specified using the access-user arp-detect vlan command
  • Source IP address calculated using the access-user arp-detect fallback ip-address command
  • Default source IP address configured using the access-user arp-detect default ip-address command

For online users on physical interfaces, this command takes effect only after the users go online again or are re-authenticated by the device.

Example

# Set the IP address required for calculating the source address of offline detection packets to 0.0.0.11.
<HUAWEI> system-view
[HUAWEI] access-user arp-detect fallback 0.0.0.11 24
