suboption

Function

The suboption command configures a vendor-specific DHCPv6 suboption.

The undo suboption command deletes a vendor-specific DHCPv6 suboption.

By default, no vendor-specific DHCPv6 suboption is configured in the system.

Format

suboption suboption-code { address { ipv6-address } &<1-4> | ascii ascii-string | hex hex-string }

undo suboption suboption-code [ address { ipv6-address } &<1-4> | ascii ascii-string | hex hex-string ]

Parameters

Parameter Description Value
suboption-code

Specifies the code of a vendor-specific DHCPv6 suboption.

The value is an integer from 1 to 65535.
address ipv6-address

Specifies the IPv6 address type for a vendor-specific DHCPv6 suboption.

The value is a 128-bit hexadecimal number, in the format of X:X:X:X:X:X:X:X, with each X representing four hexadecimal numbers.
ascii ascii-string

Specifies the ASCII string type for a vendor-specific DHCPv6 suboption.

The value is a string of 1 to 255 characters.
hex hex-string

Specifies the hexadecimal string type for a vendor-specific DHCPv6 suboption.

The value ranges from 2 to 128 in hexadecimal notation.

Views

Vendor-specific sub-option view

Default Level

2: Configuration level

Usage Guidelines

Usage Scenario

This command is used on DHCPv6 servers. You can use the vendor-specific command to enter the vendor-specific mode. In this mode, you can configure vendor-specific DHCPv6 options. The vendor-specific options can carry additional information. For example, in the DHCPv6 device automatic deployment scenario, the vendor-specific options can carry the TFTP server name, address, and configuration file name of the device.

You can use the suboption command to configure a vendor-specific DHCPv6 suboption.

Precautions

A maximum of 16 vendor-specific suboptions can be configured in each vendor-specific view.

Example

# Set Huawei-specific suboption 10 to fc00:1::5 in the IPv6 address pool pool1. 
<HUAWEI> system-view
[HUAWEI] dhcpv6 pool pool1
[HUAWEI-dhcpv6-pool-pool1] vendor-specific 2011
[HUAWEI-dhcpv6-pool-pool1-vs-2011] suboption 10 address fc00:1::5
