CONFIGURATION/2/STARTUP_NOT_SYN_clear

Message

CONFIGURATION/2/STARTUP_NOT_SYN_clear: The file for next startup on the active main control board is the same as that on the standy main control board.

This log is supported only on AR6700-H series, AR8700 series.

Parameters

None

Possible Causes

  • Cause 1:The next startup files of the master and slave main control boards became consistent.

Procedure

This trap is informational only, and no action is required.
