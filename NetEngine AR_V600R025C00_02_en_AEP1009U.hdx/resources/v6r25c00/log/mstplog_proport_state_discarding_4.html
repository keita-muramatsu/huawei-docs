MSTP/4/MSTPLOG_PROPORT_STATE_DISCARDING

Message

MSTP/4/MSTPLOG_PROPORT_STATE_DISCARDING: The MSTP process's port has been set to discarding state. (ProcessID=[ProcessID], InstanceID=[InstanceID], PortID=[PortID], IfIndex=[IfIndex], PortName=[PortName], PwName=[PwName], LastDiscardingTime=[LastDiscardingTime], PreSuppNum=[PreSuppNum])

Description

The port in the MSTP process entered the discarding state.

Parameters

Parameter Name Parameter Meaning

ProcessID

Indicates the MSTP process ID.

InstanceID

Indicates the instance ID.

PortID

Indicates ID of the port in the MSTP process.

IfIndex

Indicates the interface index.

PortName

Indicates the port name.

PwName

Indicates the PW name.

LastDiscardingTime

Last time when the status changed to Discarding.

PreSuppNum

Number of times that records were suppressed previously.

Possible Causes

The network topology changed.

Procedure

1. Check whether new physical links enabled with STP are added to the physical devices in the network topology.

  • If a new STP-enabled physical link is added, go to Step 2.
  • If no new STP-enabled physical link is added, go to Step 3.

2. Check whether the new physical link is the required one.

  • If the physical link is required, go to Step 3.
  • If the physical link is not required, go to Step 4.

3. Run the display stp command to check whether each port complies with the protocol calculation result.

  • If each port complies with the protocol calculation result, no action is required.
  • If the calculation result of each port does not comply with the protocol, go to Step 5.

4. Deploy the network topology correctly and check whether the fault is rectified. If the alarm persists, go to Step 5.

5. Collect log and configuration information, and contact technical support personnel.
