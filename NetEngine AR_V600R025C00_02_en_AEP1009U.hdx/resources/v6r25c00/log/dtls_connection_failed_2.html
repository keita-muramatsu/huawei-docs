SDWAN-EVPN/2/DTLS_CONNECTION_FAILED

Message

SDWAN-EVPN/2/DTLS_CONNECTION_FAILED: The dtls connection failed. (Role=[Role],IpAddress=[IpAddress],Port=[Port],Vpn-Instance=[Vpn-Instance],Reason=[Reason],Errcode=[Errcode])

Description

The DTLS connection is abnormal.

Parameters

Parameter Name Parameter Meaning

Role

DTLS role:

  • server: DTLS server.
  • client: DTLS client.

IpAddress

Peer IP address of a DTLS connection.

Port

Peer port of the DTLS connection.

Vpn-Instance

Name of the VPN instance to which the DTLS connection belongs.

Reason

Cause of the DTLS connection failure.

Errcode

Error code.

Possible Causes

1. Failed to obtain the certificate.

Error code 45: The certificate does not exist.

2. Failed to create the socket.

Error code 27: Failed to obtain the original socket.

Error code 29: Failed to set the socket VPN.

Error code 30: Failed to set the socket port to be reusable.

Error code 31: Failed to set the socket address to be reusable.

Error code 33: Failed to set the sending timeout interval for the socket.

Error code 34: Failed to set the receiving timeout interval for the socket.

Error code 35: Failed to set the socket IOCTRL.

Error code 36: Connection failed because the destination address is unreachable.

Error code 37: Failed to bind the socket.

Error code 38: Failed to convert the address to a socket address.

3. Failed to verify the certificate.

Error code 2: The certificate of one of the certificate authorities (CAs) cannot be found in the signature hierarchy, and the CA is not trusted by the local application.

Error code 4: Failed to decrypt the certificate signature.

Error code 6: Failed to read the public key in the certificate.

Error code 7: The signature of the certificate is invalid.

Error code 9: The certificate is not yet valid: the notBefore date is after the current time.

Error code 10: The certificate has expired.

Error code 13: The notBefore field of the certificate contains an invalid time.

Error code 14: The notAfter field of the certificate contains an invalid time.

Error code 18: The passed certificate is self signed and the same certificate cannot be found in the list of trusted certificates.

Error code 19: The certificate chain could be built up using the untrusted certificates but the root could not be found locally.

Error code 20: The issuer certificate could not be found: this occurs if the issuer certificate of an untrusted certificate cannot be found.

Error code 23: The certificate has been revoked by the issuer.

Error code 24: The CA certificate is invalid. Either it is not a CA or its extensions are not consistent with the supplied purpose.

Error code 25: The pathlength parameter has been exceeded.

Error code 26: The supplied certificate cannot be used for the specified purpose.

Error code 27: The root CA is not marked as trusted for the specified purpose.

Error code 28: The root CA is marked to reject the specified purpose.

Error code 29: The current candidate issuer certificate was rejected because its subject name did not match the issuer name of the current certificate..

Error code 31: The current candidate issuer certificate was rejected because its issuer name and serial number was present and did not match the authority key identifier of the current certificate.

Error code 32: The current candidate issuer certificate was rejected because its keyUsage extension does not permit certificate signing.

Error code 38: The proxy path length exceeds the limit.

4. Other reasons:

Error code 2: Failed to apply for internal memory.

Error code 3: Failed to encode the DTLS message to be sent.

Error code 4: Failed to obtain msgid.

Error code 5: The client failed to obtain EVPN information.

Error code 6: The client failed to query the registered server information.

Error code 7: When the DTLS message is sent, the length is abnormal.

Error code 8: When a DTLS message is sent, the message is empty.

Error code 9: The type of the DTLS message is incorrect.

Error code 10: The length of the DTLS message does not match the actual content.

Error code 11: The type of the received DTLS message is incorrect.

Error code 12: The peer address is invalid.

Error code 13: The peer port is invalid.

Error code 16: The received DTLS message fails to be verified.

Error code 17: Failed to decode the received dtls message.

Error code 21: SSL write failed when the DTLS server processes messages.

Error code 25: Failed to write the DTLS queue.

Error code 46: Failed to read the certificate.

Error code 47: Failed to load the certificate.

5. ESN authentication failed.

Error code 18: ESN authentication failed.

Procedure

1. Failed to obtain the certificate. The local certificate and CA certificate used by the device do not exist or do not match.

2. Failed to create the socket. Check whether there is a route from the local device to the peer address.

3. Certificate verification failed: The local certificate used by the device cannot be verified by the CA certificate of the peer end. Check whether the certificates on both ends match.

4. Other causes: Collect trap, log, and configuration information, and contact technical support personnel.

5. ESN authentication failed: Check whether the ESN of the peer device is in the ESN blacklist or not in the ESN whitelist.
