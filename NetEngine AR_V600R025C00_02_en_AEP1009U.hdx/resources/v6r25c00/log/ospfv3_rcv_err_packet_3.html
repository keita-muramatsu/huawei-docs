OSPFV3/3/OSPFV3_RCV_ERR_PACKET

Message

OSPFV3/3/OSPFV3_RCV_ERR_PACKET: OSPFv3 received error packet and dropped it. (ProcessId=[ProcessId], PktType=[PktType], ErrPktCnt=[ErrPktCnt], LocalComp=[LocalComp], PeerComp=[PeerComp], IfName=[IfName], AreaId=[AreaId], ErrPktReason=[ErrPktReason])

Description

An interface discarded the received error packets.

Parameters

Parameter Name Parameter Meaning

ProcessId

Process ID

PktType
  • 0: invalid packet
  • 1: Hello packet
  • 2: DD packet
  • 3: LSR packet
  • 4: LSU packet
  • 5: LSA packet

ErrPktCnt

Number of error packets.

LocalComp

CID of the local component.

PeerComp

CID of a peer component

IfName

Interface name.

AreaId

ID of an area

ErrPktReason

Cause of a packet error.

Possible Causes

Cause 1: The packet content is incorrect during network transmission.

Cause 2: Packets were modified when the device delivered or sent packets.

Procedure

  • This log message is informational only, and no action is required.
