WLAN/4/hwApNotSupportCountryCodeTrap_active

Message

WLAN/4/hwApNotSupportCountryCodeTrap_active: AP not support configured country code notify. (APMAC=[hwWlanApMac], APName=[hwWlanApName], APLockCountryCode=[hwWlanApCfgCountryCode], APID=[hwWlanApId], ConfigCountryCode=[hwWlanAcCfgCountryCode])

Description

The AP does not support the country code configured on the device. Only APs running V200R020C10 and earlier versions can report this alarm. For versions later than V200R020C10, you can run the display ap all | include cmiss command to view APs whose country codes do not match the country code configuration.

Parameters

Parameter Name Parameter Meaning

hwWlanApMac

MAC address of an AP.

hwWlanApName

Name of an AP.

hwWlanApCfgCountryCode

Country code locked on the AP. If the AP supports multiple country codes, a hyphen (-) is displayed.

hwWlanApId

AP ID.

hwWlanAcCfgCountryCode

Country code configured for the AP.

Possible Causes

A country code not supported by the AP is configured on the device.

Procedure

1. Run the display regulatory-domain-profile and display ap run-info commands to check whether the country code configured on the device is the same as that supported by the AP.

  • If so, go to Step 3.
  • If not, go to Step 2.

2. Run the country-code country-code command to set the country code to be the same as that supported by the AP.

  • If the alarm persists, go to Step 4.
  • If the alarm is cleared, go to Step 5.

3. Collect alarm, log, and configuration information, and contact technical support personnel.

4. End.
