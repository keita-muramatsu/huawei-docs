DEVM/5/hwInputRateChangeOverThresholdNotice

Message

DEVM/5/hwInputRateChangeOverThresholdNotice: The input rate change ratio exceeded the threshold. (IfIndex=[IfIndex], InterfaceName=[InterfaceName], ThresholdPercent=[ThresholdPercent], CurrentStatisticalPeriodRate=[CurrentStatisticalPeriodRate], LastStatisticalPeriodRate=[LastStatisticalPeriodRate])

Description

The rate change rate in the inbound direction exceeded the threshold.

Parameters

Parameter Name Parameter Meaning

IfIndex

Port index.

InterfaceName

Port name

ThresholdPercent

Configured rate change threshold in the inbound direction

CurrentStatisticalPeriodRate

Rate in the current statistical period, in bit/s.

LastStatisticalPeriodRate

Rate in the last statistical period, in bit/s.

Possible Causes

The rate change rate in the inbound direction exceeded the threshold.

Procedure

1. View the alarm information on the NMS and determine the board and port number where the alarm is generated.

2. Analyze whether the service traffic changes greatly.

3. Collect alarm, log, and configuration information, and contact technical support personnel.
