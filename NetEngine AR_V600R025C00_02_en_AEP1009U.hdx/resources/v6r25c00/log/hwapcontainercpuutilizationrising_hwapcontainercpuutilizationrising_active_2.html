WLAN/2/hwAPContainerCpuUtilizationRising_active

Message

WLAN/2/hwAPContainerCpuUtilizationRising_active: AP Container CPU utilization exceeded the pre-alarm threshold. (APMAC=[APMAC], APName=[APName], APID=[APID], ApApplicationName=[ApApplicationName], ApContainerCpuThreshold=[ApContainerCpuThreshold], ApContainerCpuCurrent=[ApContainerCpuCurrent])

Description

The CPU usage of the AP container exceeds the alarm threshold.

Parameters

Parameter Name Parameter Meaning

APMAC

MAC address of an AP.

APName

Name of an AP.

APID

AP ID.

ApApplicationName

Container name

ApContainerCpuThreshold

Alarm value.

ApContainerCpuCurrent

Current value.

Possible Causes

An exception occurred on the container or an application in the container. As a result, the CPU usage of the container exceeded 90% for 120 consecutive seconds.

Procedure

1. Run the display ap container public-key status { ap-id ap-id | all} command to check the container status.

2. Collect trap, log, and configuration information, as well as container status information collected in Step 1, and contact technical support personnel.

3. End.
