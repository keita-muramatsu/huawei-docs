PIM/6/GRP_MASK_UNSUPPORTED

Message

PIM/6/GRP_MASK_UNSUPPORTED: In VPN instance [vpn-instance-name], because the length of the mask of the group address [group-address]/[group-address-mask] is unsupported, the [message-type-name] message received from the interface [interface-name] was ignored.

Description

The group address contained in a PIM message was ignored, because the mask length of the group address was not supported by PIM.

Parameters

Parameter Name Parameter Meaning

vpn-instance-name

Indicates the name of a VPN instance.

group-address

Indicates the group address.

group-address-mask

Indicates the mask length of group address.

message-type-name

Indicates the message type. The value can be:

  • PIM Join/Prune message
  • PIM SM Assert message
  • PIM SM Register-Stop message
  • PIM SSM Assert message

interface-name

Indicates the name of an interface.

Possible Causes

The PIM-SM-enabled interface receives a PIM message, the mask length of the group address contained in which is not supported by PIM.

Procedure

  • This log message is informational only, and no action is required.
