LCS/1/hwGtlNearDeadline_active

Message

LCS/1/hwGtlNearDeadline_active: License is near deadline, remaining [hwGtlRemainTime] day (s). Apply for a new license file from Huawei before the grace period expires. Otherwise, relevant service functions may be unavailable or the configuration may become ineffective. (FeatureName=[hwGtlFeatureName], ChassisIDorSlotID=[hwGtlChassisID])

Description

The license file is about to expire. Apply for a new license file from Huawei before the grace period expires. Otherwise, related service functions may be unavailable or the configuration may become invalid.

Parameters

Parameter Name Parameter Meaning

hwGtlFeatureName

Name of the feature in the grace period.

hwGtlRemainTime

Time when the feature can remain in the grace period.

hwGtlChassisID

Description of a subrack or board.

Possible Causes

  • Cause 1: License file expires.
  • Cause 2: License file has been revoked.
  • Cause 3: ESN mismatches.
  • Cause 4: The V/R version does not match.

Procedure

1. Apply for a new license file from Huawei before the grace period expires. For details, see the License Usage Guide of the corresponding product.

2. Upload the license file to the device.

3. Run the license active <filename> command in the user view to activate the license file.
