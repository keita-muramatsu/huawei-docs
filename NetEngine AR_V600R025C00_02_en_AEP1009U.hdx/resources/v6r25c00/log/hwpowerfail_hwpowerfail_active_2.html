VCMU/2/hwPowerFail_active

Message

VCMU/2/hwPowerFail_active: A power module experienced a partial failure. (EntPhysicalIndex=[EntPhysicalIndex], EntPhysicalName=[EntPhysicalName], EntityTrapFaultID=[EntityTrapFaultID], EntityOperStatus=[EntityOperStatus], Reason=[ReasonDsp])

Description

A power module experienced a partial failure.

Parameters

Parameter Name Parameter Meaning

EntPhysicalIndex

Entity index.

EntPhysicalName

Entity name.

EntityTrapFaultID

Fault ID.

EntityOperStatus

Alarm status information.

ReasonDsp

Alarm cause.

Possible Causes

  • Cause 1: Communication failed between power and MPU.
  • Cause 2: Airflow direction is abnormal.
  • Cause 3: The fan inside a power module fails.
  • Cause 4: The power supply switch failed.
  • Cause 5: The current slight share.
  • Cause 6: The power module runs an earlier version.
  • Cause 7: Power Partial Failure.
  • Cause 8: The power module was present but the output was abnormal.
  • Cause 9: Two CAN bus connections were abnormal, and communication with the power module was interrupted.
  • Cause 10: The fan module in the power module run at full speed.
  • Cause 11: The EEPROM module in a power module was faulty.
  • Cause 12: The power module is protected and cannot work properly.
  • Cause 13: The power id address conflict.
  • Cause 14: The current of the power is not average.
  • Cause 15: The current exceed the max value.
  • Cause 16: Phase missing occurred on the power module
  • Cause 17: The input A cable did not match the PM.
  • Cause 18: The input B cable did not match the PM.

Procedure

  • Cause 1: Communication failed between power and MPU.

    1. Remove and reinstall the power module. If the fault persists, go to step 2.

    2. Replace the power module. If the fault persists, go to step 3.

    3. Collect trap, log, and configuration information, and contact technical support personnel.

  • Cause 2: Airflow direction is abnormal.

    1. Replace the power module. If the fault persists, go to step 2.

    2. Collect alarm, log, and configuration information, and contact technical support personnel.

  • Cause 3: The fan inside a power module fails.

    1. Power off the faulty power module and replace it. If the fault persists, go to step 2.

    2. Collect alarm, log, and configuration information, and contact technical support personnel.

  • Cause 4: The power supply switch failed.

    1. Manually turn on the power switch of the backplane. If the fault persists, go to step 2.

    2. Collect alarm, log, and configuration information, and contact technical support personnel.

  • Cause 5: The current slight share.

    1. Reduce the length of the network cable to reduce the power consumption of the board. If the fault persists, go to step 2.

    2. If other power modules are not powered on, power on them. If the fault persists, go to Step 3.

    3. Replace the power modules. Then, check whether the alarm is cleared.

  • Cause 6: The power module runs an earlier version.

    1. Run the upgrade device power command in the diagnostic view to upgrade the power module.

  • Cause 7: Power Partial Failure.

    1. Replace the power module. If the fault persists, go to step 2.

    2. Collect alarm, log, and configuration information, and contact technical support personnel.

  • Cause 8: The power module was present but the output was abnormal.

    1. Replace the power module. If the fault persists, go to step 2.

    2. Collect alarm, log, and configuration information, and contact technical support personnel.

  • Cause 9: Two CAN bus connections were abnormal, and communication with the power module was interrupted.

    1. Remove and reinstall the power module. If the fault persists, go to step 2.

    2. Replace the power module. If the fault persists, go to step 3.

    3. Collect trap, log, and configuration information, and contact technical support personnel.

  • Cause 10: The fan module in the power module run at full speed.

    1. Reduce the device temperature. After the power module temperature decreases, the fan speed automatically decreases. If the problem persists, go to step 2.

    2. Collect alarm, log, and configuration information, and contact technical support personnel.

  • Cause 11: The EEPROM module in a power module was faulty.

    1. Replace the power module. If the fault persists, go to step 2.

    2. Collect alarm, log, and configuration information, and contact technical support personnel.

  • Cause 12: The power module is protected and cannot work properly.

    1. Replace the power module. If the fault persists, go to step 2.

    2. Collect alarm, log, and configuration information, and contact technical support personnel.

  • Cause 13: The power id address conflict.

    1. Power off the faulty power module and replace it.

    2. If the alarm persists, collect alarm, log, and configuration information, and contact technical support personnel.

  • Cause 14: The current of the power is not average.

    1. If the faulty PM module is just inserted, check whether the PM module is properly inserted, whether there are bent pins, and whether the PM module connector is faulty.

    • If so, go to step 2.
    • If not, go to step 3.

    2. Perform the following operations according to the actual situation.

    • If the PM module is not securely installed, install it properly.
    • If the backplane has bent pins, do not insert the new PM into the faulty slot and contact Huawei technical support personnel.
    • If only the PM module connector is faulty, replace the PM module.
    • If the PM module is not newly inserted, go to step 3.

    3. Collect alarm, log, and configuration information, and contact technical support engineers.

  • Cause 15: The current exceed the max value.

    1. Check whether the PM module is properly installed.

    If so, go to step 3.

    If not, go to step 2.

    2. Securely insert the faulty PM and check whether the alarm is cleared.

    If so, go to step 7.

    If not, go to step 3.

    3. Check whether there are bent pins.

    If so, go to step 6.

    If not, go to step 4.

    4. Check whether the PM connector is faulty.

    If so, go to step 5.

    If not, go to step 6.

    5. Replace the PM and check whether the alarm is cleared.

    If so, go to step 7.

    If not, go to step 4.

    6. Collect trap, log, and configuration information, and contact technical support personnel.

    7. End.

  • Cause 16: Phase missing occurred on the power module

    1. Power off the PM and replace the PM. After the new PM is registered, check whether the alarm is cleared.

    • If so, go to Step 3.
    • If not, go to Step 2.

    2. Collect trap, log, and configuration information, and contact technical support personnel.

    3. End.

  • Cause 17: The input A cable did not match the PM.

    1. Power off the PM, replace the input A cable, and power on the PM again. After the PM is registered, wait about 2 minutes and check whether the alarm is cleared.

    • If so, go to Step 3.
    • If not, go to Step 2.

    2. Collect alarm, log, and configuration information, and contact technical support.

    3. End.

  • Cause 18: The input B cable did not match the PM.

    1. Power off the PM, replace the input B cable, and power on the PM again. After the PM is registered, wait about 2 minutes and check whether the alarm is cleared.

    • If so, go to Step 3.
    • If not, go to Step 2.

    2. Collect alarm, log, and configuration information, and contact technical support.

    3. End.
