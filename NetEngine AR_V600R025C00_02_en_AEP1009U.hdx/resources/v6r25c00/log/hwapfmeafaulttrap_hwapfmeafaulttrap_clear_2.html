WLAN/2/hwApFmeaFaultTrap_clear

Message

WLAN/2/hwApFmeaFaultTrap_clear: AP FMEA fault clear. (APMAC=[APMAC], APName=[APName], FaultID=[FaultID], Index=[Index], FaultInfo=[FaultInfo], APID=[APID])

Parameters

Parameter Name Parameter Meaning

APMAC

MAC address of the AP generating the hardware fault alarm.

APName

Name of the AP generating the hardware fault alarm.

FaultID

Index of the AP fault.

Index

Port number of the AP.

FaultInfo

Description of the AP fault.

APID

AP ID.

Possible Causes

The AP hardware fault is rectified.

Procedure

This message is informational only, and no action is required.
