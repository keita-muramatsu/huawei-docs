LDP/4/hwMplsLdpMultiLinkConfigInconsistent_active

Message

LDP/4/hwMplsLdpMultiLinkConfigInconsistent_active: MPLS LDP multi-link or local-remote adjacencys configurations are inconsistent, LDP Session or LSP maybe interrupts. (VrfName=[VrfName], PeerLsrId=[PeerLsrId], LocalLsrId=[LocalLsrId], ConfigIfName=[ConfigIfName], ConfigRmtPeerIp=[ConfigRmtPeerIp], ConfigType=[ConfigType], EffectKa=[EffectKa], EffectTa=[EffectTa], EffectLam=[EffectLam])

Description

This object indicates that MPLS LDP multi-link (including local and remote coexistence sessions) configurations are inconsistent.

Parameters

Parameter Name Parameter Meaning

VrfName

VRF name of LDP session exists.

PeerLsrId

LDP session ID.

LocalLsrId

Local LSR ID.

ConfigIfName

Configure the current interface name.

ConfigRmtPeerIp

Configure the IP address of the remote session.

ConfigType

Configuration inconsistent type.

EffectKa

KeepAlive value used by the LDP session.

EffectTa

LDP transport addresses used by the session.

EffectLam

Peer use label advertisement mode.

Possible Causes

When LDP sessions are configured with multiple links or local-remote adjacencies, link parameters may be inconsistent.

Procedure

1. If ConfigType in the alarm information is Keepalive Hold Timer, check whether the keepalive-hold timer configurations in the session's interface or remote-peer views are consistent.

  • If they are inconsistent, modify the keepalive-hold timer configurations in the interface or remote-peer views to make the configurations consistent. Then, go to Step 5.
  • If they are the same, go to Step 6.

2. If ConfigType in the alarm information is Transport Address, check whether the transport-address configurations in the session's interface views are consistent.

  • If they are inconsistent, modify the transport-address configurations in the interface views to make them consistent. Then, go to Step 5.
  • If they are the same, go to Step 6.

3. If ConfigType in the alarm information is Label Advertisement Mode, check whether the advertisement configurations in the session's interface or remote-peer views are consistent.

  • If they are inconsistent, modify the advertisement configurations in the interface or remote-peer views to make the configurations consistent. Then, go to Step 5.
  • If they are the same, go to Step 6.

4. If ConfigType in the alarm information is Local LSR ID, check whether the local-lsr-id configurations in the session's interface or remote-peer views are consistent.

  • If they are inconsistent, modify the local-lsr-id configurations in the interface or remote-peer views to make the configurations consistent. Then, go to Step 5.
  • If they are the same, go to Step 6.

5. Check whether the alarm is cleared.

  • If so, go to Step 7.
  • If not, go to Step 6.

6. Collect alarm and configuration information, and contact technical support engineers.

7. End.
