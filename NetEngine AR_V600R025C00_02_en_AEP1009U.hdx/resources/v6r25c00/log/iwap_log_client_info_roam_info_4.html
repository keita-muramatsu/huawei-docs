WLAN/4/IWAP_LOG_CLIENT_INFO_ROAM_INFO

Message

WLAN/4/IWAP_LOG_CLIENT_INFO_ROAM_INFO: IWAP_CLIENT_INFO_ROAM_INFO. (ACMAC=[ACMAC],ACNAME=[ACNAME],CurrentAPMAC=[CurrentAPMAC],CurrentAPNAME=[CurrentAPNAME],CurrentRSSI(dBm)=[CurrentRSSI],APMAC=[APMAC],APNAME=[APNAME],RADIO=[RADIO],BAND=[BAND],SSID=[SSID],ACCESSTYPE=[ACCESS-TYPE],USER=[USER],MAC=[MAC],TIME=[TIME],ZONE=UTC[ZONE],DAYLIGHT=[DAYLIGHT],ERRCODE=[ERRCODE],RESULT=[RESULT],OnlineTime(s)=[OnlineTime],UpPacketNum=[UpPacketNum],UpByte=[UpByte],DownPacketNum=[DownPacketNum],DownByte=[DownByte],RSSI(dBm)=[RSSI])

Description

A user roamed.

Parameters

Parameter Name Parameter Meaning

ACMAC

AC's MAC address.

ACNAME

AC name.

CurrentAPMAC

MAC address of the AP to which the STA roams.

CurrentAPNAME

Name of the AP to which the STA roams.

CurrentRSSI

RSSI of the AP from which a STA roams.

APMAC

MAC address of an AP.

APNAME

AP name.

RADIO

Radio ID.

BAND

Operating frequency band of the radio.

SSID

SSID.

ACCESS-TYPE

STA authentication mode.

USER

Username.

MAC

MAC address of the STA.

TIME

System time.

ZONE

Time zone.

DAYLIGHT

Whether the daylight saving time (DST) is used.

  • true: DST is used.
  • false: DST is not used.

ERRCODE

Failure/state error code.

RESULT

Result.

OnlineTime

Online time of the STA.

UpPacketNum

Number of uplink packets of the STA.

UpByte

Number of bytes in the uplink packets of the STA.

DownPacketNum

Number of downlink packets of the STA.

DownByte

Number of bytes in the downlink packets of the STA.

RSSI

RSSI of the AP to which the STA roams.

Possible Causes

  • A user roamed between different APs.

Procedure

This message is informational only, and no action is required.
