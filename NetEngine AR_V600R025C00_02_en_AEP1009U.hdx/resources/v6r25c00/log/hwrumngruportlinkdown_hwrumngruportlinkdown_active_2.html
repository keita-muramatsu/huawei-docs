RUMNG/2/hwRuMngRuPortLinkDown_active

Message

RUMNG/2/hwRuMngRuPortLinkDown_active: Interface on remote unit turned into DOWN state. (RemoteUnitEsn=[RemoteUnitEsn], InterfaceName=[InterfaceName], AdminStatus=[AdminStatus], OperStatus=[OperStatus])

Description

The interface of the RU went Down.

Parameters

Parameter Name Parameter Meaning

RemoteUnitEsn

ESN of the remote module.

InterfaceName

Name of the RU's interface.

AdminStatus

Administrative status:

1: Up. The link fault is rectified or the undo shutdown command is run.

2: Down. The link is faulty or the interface is shut down.

OperStatus

Operating status, that is, the link layer protocol status of the interface:

·1: Up

·2: Down

Possible Causes

  • Cause 1: The cable is loose.
  • Cause 2: The RU's interface is shut down.

Procedure

  • Cause 1: The cable is loose.

    Check whether the cable is loose.

  • Cause 2: The RU's interface is shut down.

    The RU's interface is manually shut down. No action is required.
