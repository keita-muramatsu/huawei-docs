CM/3/USERSPECFULL

Message

CM/3/USERSPECFULL: The number of access users reaches the upper limit on the device.

Description

The number of access users exceeded the system specification.

Parameters

None

Possible Causes

The number of access users exceeded the system specification.

Procedure

1. Run the display access-user command to check whether the access users are normal.

  • If so, replace the device with a device with higher performance.
  • If not, plan the network properly.

2. Collect log information and contact technical support.
