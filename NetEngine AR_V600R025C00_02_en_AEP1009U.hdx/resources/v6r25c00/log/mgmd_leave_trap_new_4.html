IGMP/4/MGMD_LEAVE_TRAP_NEW

Message

IGMP/4/MGMD_LEAVE_TRAP_NEW: Interface receives an IGMP or MLD Leave message or corresponding group timer on this interface expires. (Interface=[InterfaceName], InterfaceIndex=[InterfaceIndex], SrcAddrType=[SrcAddrType], SrcStr=[SrcAddr], GrpAddrType=[GrpAddrType], GrpStr=[GrpAddr], InstanceName=[InstanceName])

Description

An IGMPv1, IGMPv2, or MLDv1 Leave message was received.

Parameters

Parameter Name Parameter Meaning

InterfaceName

Interface name.

InterfaceIndex

Interface index.

SrcAddrType

Source address family of the IGMP Leave message.

SrcAddr

Source address of an IGMP Leave message.

GrpAddrType

Group address family of the IGMP Leave message.

GrpAddr

Group address of an IGMP Leave message.

InstanceName

VPN instance name.

Possible Causes

IGMPv1, IGMPv2, or MLDv1 Leave messages are received by the interface, or the timer of the corresponding multicast group expires.

Procedure

  • This message is informational only, and no action is required.
