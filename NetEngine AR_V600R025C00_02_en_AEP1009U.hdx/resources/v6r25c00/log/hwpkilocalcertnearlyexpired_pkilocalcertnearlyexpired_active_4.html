PKI/4/hwPKILocalCertNearlyExpired_active

Message

PKI/4/hwPKILocalCertNearlyExpired_active: The local certificate is nearly expired. (LocalCertIssuer=[issuer], LocalCertSubject=[subject], LocalCertStartTime=[start-time], LocalCertFinishTime=[finish-time])

Description

The local certificate is about to expire.

Parameters

Parameter Name Parameter Meaning

issuer

Issuer of the local certificate.

subject

Subject of the local certificate.

start-time

Time when the local certificate takes effect.

finish-time

Expiration time of the local certificate.

Possible Causes

The local certificate is about to expire. The local certificate expiration time is less than the certificate expired prewarning time configured by the pki set-certificate expire-prewarning command.

Procedure

1. Check whether the device time is correct.

2. If the time is correct, obtain a new local certificate as soon as possible.
