AAA/6/REMOTEACCOUNT_LOCK

Message

AAA/6/REMOTEACCOUNT_LOCK: Remote account [account] has been locked. (OperatorName=[operateUserName],UserIp=[OperatorIPAddress])

Description

The remote account has been locked.

Parameters

Parameter Name Parameter Meaning

account

Specifies the remote account name.

operateUserName

Operation user name.

OperatorIPAddress

IP address of the operator.

Possible Causes

After the remote-aaa-user authen-fail command is run to enable the account locking function for AAA remote authentication failures, if the user uses AAA remote authentication (RADIUS or HWTACACS) and the number of consecutive incorrect user names or passwords reaches the upper limit within the configured retry time, the account is locked.

Procedure

1. If the account is locked by mistake or needs to be enabled immediately, run the remote-user authen-fail unblock command to unlock the account.

2. If the account is not locked due to incorrect operations, the administrator can further check whether an unauthorized user cracks the account or password and enhance account protection on the RADIUS or HWTACACS server.
