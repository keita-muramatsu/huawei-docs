OSPFV3/6/OSPFV3_BAD_LSA

Message

OSPFV3/6/OSPFV3_BAD_LSA: OSPFv3 Received bad LSA. (ErrorType=[ErrType], ErrorInformation=[ErrInfo], ProcessId=[ProcessId], InterfaceName=[IfName], LsaType=[LsaType], AdvertisingRouter=[AdvRtr], LinkStateId=[LSID], Count=[Counter], AreaId=[AreaId], ErrorCode=[ErrCode])

Description

OSPFv3 received an incorrect LSA.

Parameters

Parameter Name Parameter Meaning

ErrType

Packet error type.

ErrInfo

Key error information of the packet.

ProcessId

Process ID.

IfName

Interface name.

LsaType

LSA type.

AdvRtr

LSA advertising device.

LSID

Link state.

Counter

Number of error packets. The value is cleared each time a log is printed. That is, the number of packets of this error type between the last log printing and the current log printing is counted.

AreaId

Area ID.

ErrCode

Error code:

  • 8: The checksum authentication fails.
  • 15: The packet type is invalid.
  • 16: The LSA type is invalid.
  • 22: An LSA with the total length less than the header length is received.
  • 64: The LSA length fails to be verified.
  • 67: The number of LSAs in the buffer reaches the upper limit.

Possible Causes

This log is generated when an incorrect LSA is received, for example, the checksum of the LSA is incorrect.

Procedure

Collect log and configuration information, and contact technical support personnel.
