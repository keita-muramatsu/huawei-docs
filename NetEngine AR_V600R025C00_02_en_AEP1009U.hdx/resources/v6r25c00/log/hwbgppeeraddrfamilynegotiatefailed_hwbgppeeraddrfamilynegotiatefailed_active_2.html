BGP/2/hwBgpPeerAddrFamilyNegotiateFailed_active

Message

BGP/2/hwBgpPeerAddrFamilyNegotiateFailed_active: The address family capability of the BGP peer negotiate Failed. (BGP instance=[InstanceName], VPN instance=[VpnInstance],Afi=[AddrFamilyAfi], Safi=[AddrFamilySafi], PeerRemoteAddress=[PeerAddress])

Description

Failed to negotiate the address family capability for establishing a BGP peer relationship.

Parameters

Parameter Name Parameter Meaning

InstanceName

BGP instance name: "-" indicates the default BGP instance, and other values indicate multi-instance.

VpnInstance

Name of a VPN instance.

AddrFamilyAfi

Address family:

  • 1: ipv4

AddrFamilySafi

Sub-address family:

  • 74: sdwan

PeerAddress

Peer address.

Possible Causes

The address family negotiation has been successful, but the address family negotiation fails when the BGP peer relationship is established.

Procedure

1. Check whether the peer relationship fails to be established due to its own configuration.

  • If yes, go to Step 2.
  • If no, go to Step 3.

2. Cancel the configuration that causes the failure to establish the peer relationship.

3. Check whether the BGP connection is reset.

  • If the BGP connection is not reset, go to Step 4.
  • If the BGP connection is reset, wait for a while and check whether the connection is restored. If the connection is not restored, go to Step 4.

4. Collect alarm and configuration information, and contact technical support personnel.
