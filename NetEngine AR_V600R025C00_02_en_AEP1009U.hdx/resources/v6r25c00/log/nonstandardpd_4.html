POE/4/NONSTANDARDPD

Message

POE/4/NONSTANDARDPD: An invalid or non-standard PD is connected to the interface. (Interface=[Interface])

This log is supported only on AR5710-S52T2XE4, AR5710-S8T2X-LTE4EA, AR5710-S8T2X, AR5710-S8P2X, AR5710-S8T2S, AR5710-S10T1X2, AR5710-S8TWDSE-LTE4EA, AR5710-S28T2S2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE-NRGL, AR5710-S8T2XE-LTE4EA-T, AR5710-S8T1XWE, AR5710-S8T2XE.

Description

The interface is connected to a non-standard PD or non-PD device.

Parameters

Parameter Name Parameter Meaning

Interface

Interface name

Possible Causes

The interface is connected to a non-standard PD or non-PD device.

Procedure

For a non-PD device, remove the connection directly.

If a non-standard PD is not powered on, run the poe legacy enable command in the corresponding interface view to enable the interface to check compatibility of the PD.
