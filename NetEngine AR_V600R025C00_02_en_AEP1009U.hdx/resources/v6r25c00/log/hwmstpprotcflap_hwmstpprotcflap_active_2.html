MSTP/2/hwMstpProTcFlap_active

Message

MSTP/2/hwMstpProTcFlap_active: The local device proactively detected that its STP topology was flapping. (ProcessID=[process-id], InstanceID=[instance-id])

Description

STP topology was flapping in the device.

Parameters

Parameter Name Parameter Meaning

process-id

MSTP process ID

instance-id

Multiple spanning tree instance (MSTI) ID

Possible Causes

The local device proactively detected that its STP topology was flapping 5 times in 30 hellotime interval, then detect topo change again in 60s, trigger alarm.

Procedure

1. Check whether a STP port went Up or Down, the command is display alarm history, check the information the interface status changes.

  • If the operation is proper, check the network links state, the command is display this interface in interface view.
  • If the operation is not proper, go to Step 2.

2. Collect alarm and configuration information, and contact technical support personnel.
