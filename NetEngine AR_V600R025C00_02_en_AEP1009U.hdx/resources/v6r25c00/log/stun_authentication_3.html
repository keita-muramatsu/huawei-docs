NAT-STUN/3/STUN_AUTHENTICATION

Message

NAT-STUN/3/STUN_AUTHENTICATION: The nat stun [StunRole] authentication failed. (Username = [Username], AuthenticationIp = [AuthenticationIp], Stage = [Stage])

Description

The STUN server or client fails to be authenticated.

Parameters

Parameter Name Parameter Meaning

StunRole

STUN Role:

  • server: STUN server.
  • client: STUN client.

Username

Authentication user name.

AuthenticationIp

Authentication IP address.

Stage

STUN phase:

  • detect: indicates the STUN detection phase.

Possible Causes

The authentication user name or password of the STUN server does not match that of the client.

Procedure

1. Run the authentication-mode command on the STUN server and client to ensure that the same authentication user name and password are configured on the STUN server and client.

2. Collect alarm, log, and configuration information, and contact technical support personnel.
