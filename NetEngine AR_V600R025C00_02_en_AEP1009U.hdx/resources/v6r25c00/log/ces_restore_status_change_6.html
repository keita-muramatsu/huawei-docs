CES/6/CES_RESTORE_STATUS_CHANGE

Message

CES/6/CES_RESTORE_STATUS_CHANGE: CES Traditional Components Config Restore Status Changed. (AppName=[AppName],CurrentStatus=[CurrentStatus])

Description

The system records the configuration restoration status change of a service component deployed on CES.

Parameters

Parameter Name Parameter Meaning

AppName

Component name

CurrentStatus

Component configuration restoration status

Possible Causes

When the configuration restoration status of a service component deployed on CES changes, a log is recorded.

Procedure

This message is informational only, and no action is required.

Parent Topic: CES Log
