LACP/2/hwLacpTotalLinkLoss_clear

Message

LACP/2/hwLacpTotalLinkLoss_clear: Link bandwidth lost totally is resumed. (TrunkIndex=[TrunkIndex], TrunkIfIndex=[TrunkIfIndex], TrunkId=[TrunkId], TrunkName=[TrunkName], Reason=[ReasonCode])

Parameters

Parameter Name Parameter Meaning

TrunkIndex

Index of a trunk

TrunkIfIndex

Index of a trunk interface

TrunkId

ID of a trunk interface

TrunkName

Name of a trunk interface

ReasonCode

Reason why all the link bandwidths were lost or resumed.

Possible Causes

  • Cause 1:The trap hwLacpTotalLinkLoss was generated when no interface was selected. When the fault was rectified, the trap hwLacpTotalLinkLossResume was generated.
  • Cause 2:Link is selected.

Procedure

  • This alarm message is informational only, and no action is required.
