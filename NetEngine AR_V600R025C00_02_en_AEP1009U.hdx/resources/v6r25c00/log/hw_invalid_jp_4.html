PIM/4/HW_INVALID_JP

Message

PIM/4/HW_INVALID_JP: PIM receives an Invalid Join/Prune message. (GroupMappingOrigin=[GroupMappingOrigin], GroupMappingAddrType=[GroupMappingAddrType], GrpAddr=[GrpAddr], GrpPfxLen=[GrpPfxLen], GroupMappingRPAddrType=[GroupMappingRPAddrType], RPAddr=[RPAddr], GroupMappingPimMode=[GroupMappingPimMode], InvJPAddrType=[InvJPAddrType], InvJPOriginAddr=[InvJPOriginAddr], InvJPGrpAddr=[InvJPGrpAddr], InvJPRpAddr=[InvJPRpAddr], NbrIfIndex=[NbrIfIndex], NbrAddrType=[NbrAddrType], NbrAddr=[NbrAddr], NbrUpTime=[NbrUpTime], NbrName=[NbrName], PimInstanceID=[PimInstanceID], PimInstanceName=[PimInstanceName])

Description

PIM received invalid Join/Prune messages.

Parameters

Parameter Name Parameter Meaning

GroupMappingOrigin

RP type

GroupMappingAddrType

Group address type

GrpAddr

Group address in the Join/Prune message

GrpPfxLen

Mask length of the multicast group address

GroupMappingRPAddrType

RP address type

RPAddr

RP address

GroupMappingPimMode

Current PIM mode

InvJPAddrType

Address type of the invalid Join/Prune messages

InvJPOriginAddr

Source address of the invalid Join/Prune messages

InvJPGrpAddr

Group address of the invalid Join/Prune messages

InvJPRpAddr

RP address of the invalid Join/Prune messages

NbrIfIndex

Index of the neighboring interface

NbrAddrType

Address type of the neighboring interface

NbrAddr

Address of the neighboring interface

NbrUpTime

Lifetime of the neighbor relationship

NbrName

Name of the neighboring interface

PimInstanceID

VPN instance ID

PimInstanceName

VPN instance name

Possible Causes

PIM received invalid Join/Prune messages.

Procedure

Check whether the SSM range on the local device is the same as that on the device that sends J/P messages.

  • If the SSM ranges are the same, ensure that the RP configuration of the group on the local device is the same as that on the device that sends the Join or Prune message.
  • If the SSM ranges are different, run the ssm-policy command to configure the same SSM range.
