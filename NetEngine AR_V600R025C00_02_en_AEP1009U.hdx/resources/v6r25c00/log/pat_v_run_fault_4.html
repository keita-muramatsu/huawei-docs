DEVM/4/PAT_V_RUN_FAULT

Message

DEVM/4/PAT_V_RUN_FAULT: Patch unit [PatchUnitName] run failed. (Module=[ModuleName],Type=V)

Description

The class V patch unit fails to be loaded.

Parameters

Parameter Name Parameter Meaning

PatchUnitName

Name of a patch unit

ModuleName

Module name

Possible Causes

Cause 1: The patch file is abnormal.

Cause 2: An exception occurs when the patch unit is copied to the flash memory.

Procedure

  • Run the collect diagnostic information command in the diagnostic view to collect diagnostic information about the operating system and contact technical support personnel.
