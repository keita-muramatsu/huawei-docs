IAE/4/FILE_BREAKPOINT

Message

IAE/4/FILE_BREAKPOINT: Resumable file transfer was detected. (SyslogId=[syslog-id], VSys="[vsys-name]", Policy="[policy-name]", SrcIp=[source-ip], DstIp=[destination-ip], SrcPort=[source-port], DstPort=[destination-port], SrcZone=[source-zone], DstZone=[destination-zone], User="[user-name]", UserGroup="[group-name]", Protocol=[protocol], Application="[application-name]", FileName="[file-name]", CacheModule="[module-name]", EventNum=[event-number], Action=[action])

This log is supported only on AR5710-S52T2XE4, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L50T2X4-T, AR6700-H series, AR6710-L8T3TS1X2, AR6710-L50T2X4, AR8100 series, AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S28T2S2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR6710-L14T2X4, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE-NRGL, AR6710-L26T2X4-T, AR5700-H series, AR5710-S8T2XE-LTE4EA-T, AR5710-S8T1XWE, AR5710-S8T2XE.

Description

After a malicious file transmitted on the network is blocked by the device, a resumable download may be triggered when the file is transferred again. If resumable downloads are triggered for multiple retries, the client may successfully download the file. After resumable download is configured, a malicious file in this scenario is blocked to prevent it from being undetected. The log describes the event details.

Parameters

Parameter Name Parameter Meaning

syslog-id

Sequence number of a log.

vsys-name

The value is fixed to Public.

policy-name

Name of a security policy.

source-ip

Source IP address of the packet or the session that carries the packet.

By default, the source IP address of the detected packet is displayed.

destination-ip

Destination IP address of the packet or the session that carries the packet.

By default, the destination IP address of the detected packet is displayed.

source-port

Source port of the packet.

destination-port

Destination port of the packet.

source-zone

Source security zone of packets.

destination-zone

Destination security zone of packets.

user-name

User name.

If a user or security group matching condition is configured in a security policy that references a content security detection profile, this log is generated when this security policy is matched and a threat is detected. This parameter is recorded in the log.

group-name

User group.

protocol

Protocol to which the packet belongs.

application-name

Application to which the packet belongs.

file-name

File name.

module-name

Cached module.

If a content security detection module (such as IPS or antivirus) detects a threat during the first file transfer, the module records the resumable transfer connection information in the cache table. After the file in resumable transfer mode reaches the device, the device performs cache information matching. If a match is found, these connections are blocked. You can also check the cached module based on the module field in the display engine breakpoint-resume-blocking cache command output.

event-number

Match count.

action

Action.

Possible Causes

The resumable transfer blocking function blocks malicious files in resumable transfer mode.

Procedure

View malicious file connection information and adjust related security configurations if necessary.
