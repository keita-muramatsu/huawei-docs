AM/4/IPRENEWFAIL

Message

AM/4/IPRENEWFAIL: Failed to renew an IP address. (PoolName=[PoolName], ClientId=[ClientId], IpAddress=[IpAddress], Reason=[Reason], UserType=[UserType])

Description

An IP address fails to be renewed.

Parameters

Parameter Name Parameter Meaning

PoolName

Name of an address pool.

ClientId

Client ID.

IpAddress

IP address whose lease fails to be renewed.

Reason

Cause of the lease renewal failure. The options are as follows: - Bad requested IP address: The IP address to be renewed is different from the IP address allocated by the address pool to the client. - Without the client's lease: There is no lease for the client. - Pool is locked: The address pool is locked.

UserType

User type of the client.

Possible Causes

1. The IP address to be renewed is different from the IP address assigned to the client from the address pool.

2. No lease record of the client's IP address exist.

3. The address pool is locked.

Procedure

1. If no lease record of the client's IP address exist, the DHCP server releases the original IP address of the client, and the client needs to re-initiates an address application request.

2. If the address pool is locked, check the reason why the administrator locks the address pool, and run the undo lock command in the address pool view to unlock the address pool.
