PKI/3/hwPKIRequestCertFailCmp_active

Message

PKI/3/hwPKIRequestCertFailCmp_active: Requesting certificate through CMPv2 failed. (hwCMPUrl=[cmpurl], hwCMPName=[cmpname], CmpSessionName=[sessionname]).

Description

The local certificate fails to be applied for using CMPv2.

Parameters

Parameter Name Parameter Meaning

cmpurl

URL of the CMPv2 server.

cmpname

Name of a CA.

sessionname

Name of a CMPv2 session.

Possible Causes

  • There is no reachable route between the device and CMPv2 server.
  • The PKI configurations of the device and CMPv2 server are incorrect.
  • The CMPv2 server is faulty.

Procedure

1. Run the ping command to check whether the route between the device and CMPv2 server is reachable. If the route is unreachable, check the route and link to ensure that the route between the two devices is reachable.

2. Check whether the PKI configurations of the device and CMPv2 server are correct, such as the CMPv2 server URL and CA name. If the configuration is incorrect, correct it.

3. Check whether the CMPv2 server is running properly. If the CMPv2 server is abnormal, ensure that the CMPv2 server is normal.

4. Collect alarm and configuration information, and contact technical support personnel.
