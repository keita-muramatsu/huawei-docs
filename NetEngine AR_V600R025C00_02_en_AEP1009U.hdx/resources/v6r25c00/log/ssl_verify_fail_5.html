SSL/5/SSL_VERIFY_FAIL

Message

SSL/5/SSL_VERIFY_FAIL: SSL certificate verification failed. (FailReason = [FailReason], ErrorCode = [ErrorCode], AppCid = [AppCid], VerifyMode = [VerifyMode])

Description

Failed to verify the SSL session certificate.

Parameters

Parameter Name Parameter Meaning

FailReason

Authentication failure cause. The options are as follows:

  • The certificate ID was incorrect.
  • The current system UTC was beyond the validity period of the certificate.
  • The current system UTC was beyond the validity period of the CRL.

ErrorCode

Error code of an authentication failure.

AppCid

Component ID.

VerifyMode

Authentication mode.

Possible Causes

Cause 1: The certificate ID was incorrect.

Cause 2: The UTC time of the current system is beyond the validity period of the certificate.

Cause 3: The current UTC time of the system is beyond the validity period of the CRL.

Procedure

1. The troubleshooting procedures for different causes are as follows:

Cause 1:

Use a certificate with a correct ID.

Cause 2:

Correct the system time and regenerate a certificate to ensure that the UTC time of the system is within the validity period of the certificate.

Cause 3:

Correct the system time and regenerate a CRL to ensure that the UTC time of the system is within the validity period of the CRL.

2. Collect alarm, log, and configuration information, and contact technical support personnel.
