OSPF/4/OSPF_ABNORMAL_EXIT_GRHELPER

Message

OSPF/4/OSPF_ABNORMAL_EXIT_GRHELPER: OSPF-INFO: OSPF exited GR helper abnormally. (ProcessId=[ProcessId], RouterId=[RouterId], IpAddress=[IpAddress], AddressLessIndex=[AddressLessIndex], NbrRtrId=[NbrRtrId], NbrRestartHelperStatus=[NbrRestartHelperStatus], NbrRestartHelperAge=[NbrRestartHelperAge], NbrRestartHelperExitReason=[NbrRestartHelperExitReason], AreaId=[AreaId])

Description

The OSPF process of the local device abnormally exited GR helper mode.

Parameters

Parameter Name Parameter Meaning

ProcessId

Process ID of the local device.

RouterId

Router ID of the local device.

IpAddress

IP address of the neighbor.

AddressLessIndex

Index of the neighboring interface.

NbrRtrId

Router ID of the neighbor.

NbrRestartHelperStatus

Helper status of the neighbor:

  • 0: Normal
  • 1: Restarter
  • 2: Helper

NbrRestartHelperAge

Remaining time for completing GR on the local end.

NbrRestartHelperExitReason

Reasons that the local end exited from the helper status after the neighbor was restarted:

  • 0: NONE
  • 1: SUCCESS
  • 2: GRACE PERIOD EXPIRE
  • 3: RECV FLUSH GRACELSA
  • 4: RECV CHG LSA
  • 5: RECV 1WAY HELLO
  • 6: POLICY CHECK FAIL
  • 7: NBR RESET
  • 8: IF CHANGE
  • 9: PROC CHANGE
  • 10: GRACE LSA NOT FOUND

AreaId

Area ID.

Possible Causes

See the description of the NbrRestartHelperExitReason parameter.

Procedure

Contact contact technical support personnel.
