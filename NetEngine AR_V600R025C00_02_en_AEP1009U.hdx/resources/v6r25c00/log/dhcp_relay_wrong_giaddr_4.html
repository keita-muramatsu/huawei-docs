DHCP/4/DHCP_RELAY_WRONG_GIADDR

Message

DHCP/4/DHCP_RELAY_WRONG_GIADDR: DHCP relay receive a dhcp packet with wrong giaddr address. (InterfaceName=[interfacename])

Description

The Giaddr field in the DHCP packet received by the DHCP relay agent is incorrect.

Parameters

Parameter Name Parameter Meaning

interfacename

Interface name.

Possible Causes

The DHCP packet is processed by another DHCP relay agent on the network. As a result, the Giaddr field in the DHCP packet is different from that on the interface configured on the DHCP relay function.

Procedure

Locate other DHCP relay agents on the network based on the interface name and the Giaddr field in the log. Check the network and ensure that the DHCP relay configuration is correct.
