PPPOEC/3/L2TPC_SESSION_DOWN

Message

PPPOEC/3/L2TPC_SESSION_DOWN: The L2TP client session is down. (SessionID=[SessionID], TunnelID=[TunnelID], TunnelIP=[TunnelIP], PeerSessionID=[PeerSessionID], PeerTunnelID=[PeerTunnelID], PeerTunnelIP=[PeerTunnelIP], IfName=[IfName], Reason=[Reason])

Description

The L2TP client session was terminated.

Parameters

Parameter Name Parameter Meaning

SessionID

Local session ID of the L2TP tunnel.

TunnelID

L2TP tunnel ID on the local end.

TunnelIP

Local IP address of the L2TP tunnel.

PeerSessionID

Remote session ID of the L2TP tunnel.

PeerTunnelID

L2TP tunnel ID on the remote end.

PeerTunnelIP

Remote IP address of the L2TP tunnel.

IfName

Name of an interface.

Reason

Reason for terminating the session.

Possible Causes

1. PPP negotiation or authentication fails. If it is the case, the value of the Reason field is LCP/NCP down.

2. The L2TP session is reset. If it is the case, the value of the Reason field is Session is reset.

3. The L2TP configuration is changed. If it is the case, the value of the Reason field is Configuration is changed.

4. The remote end disconnects the L2TP session. If it is the case, the value of the Reason field is Received CDN from LNS.

5. Error L2TP packets are received. If it is the case, the value of the Reason field is Packet error.

6. The L2TP configuration on the dialer interface is deleted. If it is the case, the value of the Reason field is Session is deleted.

Procedure

1. Check the l2tp-auto-client and l2tp-group configurations on the dialer interface.

2. Check whether the PPP user name and password configured on the dialer interface are the same as those on the LNS.

3. Run the display l2tp session command to check the session status.

4. Collect trap, log, and configuration information, and contact technical support.
