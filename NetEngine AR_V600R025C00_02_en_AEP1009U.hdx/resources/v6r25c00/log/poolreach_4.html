CGN/4/POOLREACH

Message

CGN/4/POOLREACH: NAT port number allocated from IP pool reaches the threshold.(Pool Number=[pool-number], Current Port Usage=[port-usage], Threshold=[threshold-value], Slot ID=[slot-id], CPU ID=[cpu-id])

Description

The total port usage of the address pool reached the threshold.

Parameters

Parameter Name Parameter Meaning

pool-number

Address pool ID.

port-usage

Port usage of the address pool.

threshold-value

Threshold of the address-pool port usage.

slot-id

Slot ID.

cpu-id

CPU ID.

Possible Causes

The total port usage of the address pool reached the threshold.

Procedure

Expand the capacity when the CGN/5/IPRESTORE log failed to be reported in a long period of time after this log was reported.
