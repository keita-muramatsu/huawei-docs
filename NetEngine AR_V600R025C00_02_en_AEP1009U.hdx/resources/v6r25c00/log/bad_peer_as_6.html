BGP/6/BAD_PEER_AS

Message

BGP/6/BAD_PEER_AS: The AS number received from the peer is different from expected AS number. (VpnInstance=[VpnInstance], Peer=[peer-address], SourceInterface=[SourceInterface], Expected-as=[remote-as], Received-as=[local-as])

Description

The AS number configured for the BGP peer was different from the AS number carried in the Open message received from the peer.

Parameters

Parameter Name Parameter Meaning

VpnInstance

VPN instance.

peer-address

Address of a neighbor.

SourceInterface

Source interface.

remote-as

AS number configured for the BGP peer.

local-as

AS number carried in the Open message sent by the BGP peer.

Possible Causes

The AS number configured for the BGP peer was different from the actual AS number of the peer. The interval for recording logs is the interval for establishing a peer relationship. Currently, the default interval for establishing a peer relationship is 10s. You can run the peer timer connect-retry command to change the interval for establishing a peer relationship.

Procedure

  • Reconfigure the AS number of the BGP peer to be the same as the AS number carried in the Open message received from the peer.
