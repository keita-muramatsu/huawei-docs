SYSDIAG/3/DISK_MOUNT_FAIL

Message

SYSDIAG/3/DISK_MOUNT_FAIL: Failed to mount the disk. (DiskType=[DiskType], DiskSN=[DiskSN], DiskSlot=[DiskSlot])

Description

Failed to mount the disk.

Parameters

Parameter Name Parameter Meaning

DiskType

Disk type.

DiskSN

Serial number of the disk.

DiskSlot

ID of the board where the disk is located.

Possible Causes

Failed to insert the disk or run the corresponding command to bring the disk online.

Procedure

Reinsert the disk or run the corresponding command to bring the disk online again.
