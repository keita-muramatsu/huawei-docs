VRRP6/4/vrrp6NewMaster

Message

VRRP6/4/vrrp6NewMaster: The VRRP status changed to master. (ifIndex=[ifIndex], VrId=[VrId], MasterIPAddress=[MasterIpAddress], sysName=[sysName], ifName=[ifName], ChangeReason=[ChangeReason])

Description

The status of a device was changed to master.

Parameters

Parameter Name Parameter Meaning

ifIndex

Index of the interface where VRRP6 is configured

VrId

VRID of the VRRP6 backup group

MasterIpAddress

IP address of the master device in the VRRP6 backup group

sysName

System name

ifName

Name of the interface where VRRP6 is configured

ChangeReason

VRRP6 status change reason

Possible Causes

The status of a router was changed to master.

Procedure

This log message is informational only, and no action is required.
