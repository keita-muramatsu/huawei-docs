CM/4/hwNacMaxUserAlarm_active

Message

CM/4/hwNacMaxUserAlarm_active: The number of NAC users reached the maximum. (Slot=[Slot], User-num=[User-num], Threshold=[Threshold]%, Process Name=[ProcessName])

Description

The percentage of successfully authenticated NAC users reached the upper alarm threshold.

Parameters

Parameter Name Parameter Meaning

Slot

Slot ID.

User-num

Current number of NAC authentication users.

Threshold

Percentage of NAC authentication users against the maximum number of users.

ProcessName

Process name.

Possible Causes

The percentage of successfully authenticated NAC users reached the upper alarm threshold.

Procedure

1. Run the display authentication user-alarm configuration command in any view to check the upper threshold for the number of NAC authentication users configured on the device. Analyze the number of users, properly plan the network, and run the authentication user-alarm percentage command to adjust the threshold. If the fault persists, go to Step 2.

2. Collect log information and contact technical support personnel.
