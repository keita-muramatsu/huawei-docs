ISIS/6/ISIS_RCV_OTHER_PURGED_LSP

Message

ISIS/6/ISIS_RCV_OTHER_PURGED_LSP: ISIS [ProcessId] received a purged LSP. (Level=[Level], PduLspId=[PduLspId], RemainTime = [RemainTime], CheckSum = [CheckSum], SeqNum = [SeqNum], LocalDbRemainTime = [LocalDbRemainTime], LocalDbCheckSum = [LocalDbCheckSum], LocalDbSeqNum = [LocalDbSeqNum], Interface=[Interface], NbrSystem=[NbrSystem], SrcSystem=[SrcSystem], SrcDynName=[SrcDynName], SrcNbrSystem=[SrcNbrSystem])

Description

The IS-IS system received an LSP with the remaining time being 0 from another system.

Parameters

Parameter Name Parameter Meaning

ProcessId

Indicates the IS-IS process ID.

Level

Indicates the IS-IS level.

PduLspId

Indicates the ID of the purged LSP.

RemainTime

The remain life time of the purged LSP

CheckSum

The checksum of the purged LSP

SeqNum

The sequence number of the purged LSP

LocalDbRemainTime

The remain life time of the local DB LSP

LocalDbCheckSum

The checksum life time of the local DB LSP

LocalDbSeqNum

The sequence number of the local DB LSP

Interface

Indicates the interface that receives the purged LSP.

NbrSystem

Indicates the system ID of a neighbor.

SrcSystem

Indicates the system ID of the device that sends the purged LSP.

SrcDynName

Indicates the dynamic hostname of the device that sends the purged LSP.

SrcNbrSystem

Indicates the neighbor system ID of the device that sends the purged LSP.

Possible Causes

The IS-IS system received a purged LSP from another system.

Procedure

1. Check whether SrcSystem is available in the log.

  • If yes, check the system ID of the device that sends the LSP and go to step 3.

If the alarm is not generated, go to step 2.

2. View the NbrSystem field in the log, find the peer device, download the log, and check whether the LSP is sent by this device.

If the alarm is generated, go to step 3.

  • If no, go to Step 4.

3. Check whether the LSP is cleared on the source device.

  • If yes, this log message is informational only, and no action is required.
  • If no, go to Step 4.

4. Check the source devices that generate the LSPs with the remaining time being 0 one by one, and go to step 3.

5. Collect log and configuration information, and contact Huawei technical support personnel.

6. End.
