SSH/5/SSHS_REKEY_FAIL

Message

SSH/5/SSHS_REKEY_FAIL: SSH server key renegotiation is failed. (SessionID=[SessionID], FailedReason=[FailedReason], RekeyReason=[RekeyReason], UserAddress=[UserAddress], LocalAddress=[LocalAddress], VPNInstanceName=[VPNInstanceName])

Description

The SSH server and client failed to renegotiate the key.

Parameters

Parameter Name Parameter Meaning

SessionID

SSH session ID.

FailedReason

Cause of the key renegotiation failure of the SSH session.

RekeyReason

Reason why the SSH session renegotiates the key.

UserAddress

IP address of the SSH client.

LocalAddress

IP address of the SSH server.

VPNInstanceName

VPN instance name.

Possible Causes

Cause 1: The client does not support the requested encryption algorithm.

Cause 2: The client does not respond.

Procedure

  • Collect log and configuration information, and contact technical support personnel.
