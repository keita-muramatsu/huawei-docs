AM6/6/PREFRENEWOK

Message

AM6/6/PREFRENEWOK: An IPv6 prefix was renewed. (PoolName=[PoolName], ClientId=[ClientId], Prefix=[Prefix], StartTime=[StartTime], RenewTime=[RenewTime], LeaseTime=[LeaseTime], EndTime=[EndTime], UserType=[UserType], UserMac=[UserMac])

Description

The IPv6 prefix was successfully renewed.

Parameters

Parameter Name Parameter Meaning

PoolName

Name of an address pool.

ClientId

Client ID.

Prefix

Prefix address.

StartTime

IPv6 prefix allocation time.

RenewTime

IPv6 prefix renewal time.

LeaseTime

Lease.

EndTime

Lease end time.

UserType

User type.

UserMac

User MAC address.

Possible Causes

The client successfully renewed the IPv6 prefix.

Procedure

This message is informational only, and no action is required.
