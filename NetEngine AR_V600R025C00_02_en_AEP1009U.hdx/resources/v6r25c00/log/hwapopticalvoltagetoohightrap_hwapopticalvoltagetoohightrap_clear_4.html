WLAN/4/hwApOpticalVoltageTooHighTrap_clear

Message

WLAN/4/hwApOpticalVoltageTooHighTrap_clear: The voltage of the AP's optical module falls below the upper threshold. (APMAC=[APMAC], APName=[APName], ApIfIndex=[ApIfIndex], Ap Optical Voltage=[ApOpticalVoltage], ApEntityPhysicalName=[ApEntityPhysicalName], APID=[APID])

Parameters

Parameter Name Parameter Meaning

APMAC

MAC address of an AP.

APName

Name of an AP.

ApIfIndex

Index of the AP interface on which an optical module is installed.

ApOpticalVoltage

Voltage of an AP's optical module.

ApEntityPhysicalName

Name of the AP port where the optical module is located.

APID

AP ID.

Possible Causes

The high voltage of an AP's optical module is restored.

Procedure

1. This message is informational only, and no action is required.
