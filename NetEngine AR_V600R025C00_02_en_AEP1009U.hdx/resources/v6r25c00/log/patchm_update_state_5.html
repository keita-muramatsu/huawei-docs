PATCH/5/PATCHM_UPDATE_STATE

Message

PATCH/5/PATCHM_UPDATE_STATE: The patch with slot [PatchSlotIndex], patch index [PatchIndex], version [PatchVersion] and type [PatchType] has updated to the state [PatchState], sessionid [SessionId].

Description

The patch is updated to the new state.

Parameters

Parameter Name Parameter Meaning

PatchSlotIndex

Slot index of a system-level event. The value is fixed at 128.

PatchIndex

Patch index.

PatchVersion

Patch version number.

PatchType

Patch type.

PatchState

Patch status.

SessionId

Session ID

Possible Causes

The current patch status changes.

Services are not affected.

Procedure

  • This message is informational only, and no action is required.
