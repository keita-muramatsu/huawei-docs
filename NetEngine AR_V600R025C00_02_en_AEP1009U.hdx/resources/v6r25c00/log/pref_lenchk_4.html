DHCP/4/PREF_LENCHK

Message

DHCP/4/PREF_LENCHK: The delegated prefix is too small to allocate all of its interfaces. (InterfaceName=[InterfaceName], PrefixName=[PrefixName], Prefix=[Prefix], PrefixLength=[PrefixLength], RequiredPrefixLength=[RequiredPrefixLength], ServeDuid=[ServeDuid])

Description

The length of the IPv6 prefix bound to an interface is shorter than the length of the IPv6 prefix obtained by a DHCPv6 PD client. The interface cannot generate the global unicast IPv6 address based on the bound IPv6 prefix.

Parameters

Parameter Name Parameter Meaning

InterfaceName

Interface name.

PrefixName

Prefix name.

Prefix

Obtained prefix.

PrefixLength

Length of the obtained prefix.

RequiredPrefixLength

Required prefix length.

ServeDuid

Server DUID.

Possible Causes

The length of the IPv6 prefix bound to the interface is shorter than the length of the IPv6 prefix obtained by the DHCPv6 PD client.

Procedure

Run the prefix-delegation <ipv6-prefix>/<ipv6-prefix-length> <assign-prefix-length> command to adjust the prefix length bound to the IPv6 address pool.
