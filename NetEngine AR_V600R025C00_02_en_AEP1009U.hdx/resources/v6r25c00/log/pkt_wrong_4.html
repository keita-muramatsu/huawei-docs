BGP/4/PKT_WRONG

Message

BGP/4/PKT_WRONG: An invalid message was received from the peer. (PacketType=[pkt-type], Peer=[peer-address], SourceInterface=[SourceInterface], VpnInstance=[VpnInstance], Reason=[reason])

Description

A device received an error message from its peer.

Parameters

Parameter Name Parameter Meaning

pkt-type

Message type

peer-address

IP address of a peer

SourceInterface

Source interface

VpnInstance

Name of a VPN instance

reason

Reason why the received message is invalid: UNKNOWN AFI (indicates an unknown address family)

Possible Causes

The message sent by the peer was invalid or the configuration of the local device was incorrect.

Procedure

1. Run the display current-configuration command to check whether the configuration of the local device is correct. If the configuration of the local device is incorrect, correct the configuration.

2. If the fault persists, contact technical support personnel.
