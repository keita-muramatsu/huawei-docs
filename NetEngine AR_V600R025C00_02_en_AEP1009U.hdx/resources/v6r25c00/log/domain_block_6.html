AAA/6/DOMAIN_BLOCK

Message

AAA/6/DOMAIN_BLOCK: The [domain] domain is changed from active to blocked because the current time is within the blocking period.

Description

The current time is within the block time range, so the domain changes from the activated state to the blocked state.

Parameters

Parameter Name Parameter Meaning

domain

Domain name.

Possible Causes

The current time is within the block time range configured using the state block time-range command, so the domain changes from the activated state to the blocked state.

Procedure

1. To use the domain, the administrator can use either of the following methods to activate the domain:

  • Run the time-range command to change the time range during which the domain is blocked.
  • Run the undo state block time-range command to delete the block time range configuration.

2. When the block time expires, the domain automatically changes from the blocked state to the activated state.
