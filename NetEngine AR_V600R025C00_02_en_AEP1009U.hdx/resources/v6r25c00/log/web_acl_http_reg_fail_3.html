WEB/3/WEB_ACL_HTTP_REG_FAIL

Message

WEB/3/WEB_ACL_HTTP_REG_FAIL: Failed to enable the external Portal server connection function. (Protocol=[Protocol], Port=[Port], SSL_Policy=[SSL_Policy])

Description

Failed to enable the Portal interconnection service.

Parameters

Parameter Name Parameter Meaning

Protocol

Protocol type

Port

Port number

SSL_Policy

SSL policy

Possible Causes

Failed to start the Portal interconnection service because initialization is not complete.

Procedure

Run the portal web-authen-server command on the device to enable the Portal interconnection function of the HTTP/HTTPS protocol.
