SYSTEM/1/hwSystemMemoryOvLoadAlarm_active

Message

SYSTEM/1/hwSystemMemoryOvLoadAlarm_active: The memory usage exceeds the reliability overload threshold. (TrapSeverity=[TrapSeverity], EventType=[EventType], PhysicalIndex=[PhysicalIndex], PhysicalName=[PhysicalName], UsageValue=[UsageValue], Unit=[Unit], UsageThreshold=[UsageThreshold])

Description

The memory usage is continuously sampled. In a sampling period (number of continuous overload times x sampling interval), if the memory usage sampled each time is greater than the memory resilience overload threshold, this alarm is generated.

Parameters

Parameter Name Parameter Meaning

TrapSeverity

Alarm severity.

EventType

Alarm type.

PhysicalIndex

Index of the physical entity.

PhysicalName

Entity name.

UsageValue

Utilization.

Unit

Unit.

UsageThreshold

Threshold

Possible Causes

The memory usage exceeded the pre-set reliability overload threshold.

Procedure

1. Run the display memory slot <slotid> command to check the memory usage. Run the display current-configuration include-default | include memory-usage reliability command to check the memory resilience configuration. The value of overload-threshold in the command output indicates the memory resilience overload threshold. Compare the memory usage with the memory resilience overload threshold.

2. Delete unnecessary services and configurations to reduce memory usage. Then, check whether the alarm is cleared.

  • If the alarm is no longer generated, the problem is resolved.
  • If the alarm persists, go to Step 3.

3. Collect log files and contact technical support engineers.
