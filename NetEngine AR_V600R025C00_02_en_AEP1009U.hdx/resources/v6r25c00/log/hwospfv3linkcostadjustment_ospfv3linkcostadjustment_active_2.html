OSPFV3/2/hwospfv3LinkCostAdjustment_active

Message

OSPFV3/2/hwospfv3LinkCostAdjustment_active: An OSPFv3 link cost adjustment event occurs. (ProcessId=[hwOspfv3ProcessId], AreaId=[hwOspfv3AreaIdIndex], InterfaceIndex=[hwOspfv3IfIndex], InstanceId=[hwOspfv3IfInstId], InterfaceName=[hwOspfv3IfName], Event=[hwOspfv3CostAdjustReason], OriginalCost=[hwOspfv3OriginalCost], AdjustedCost=[hwOspfv3AdjustedCost])

Description

An OSPFv3 link cost adjustment event occurred.

Parameters

Parameter Name Parameter Meaning

hwOspfv3ProcessId

OSPFv3 process ID

hwOspfv3AreaIdIndex

OSPFv3 area ID

hwOspfv3IfIndex

Interface index.

hwOspfv3IfInstId

ID of an OSPFv3 instance.

hwOspfv3IfName

Interface name

hwOspfv3CostAdjustReason

Reason for OSPFv3 to adjust the link cost:

  • 1: OSPFv3 adjusted the link cost due to a BFD fault on the link.
  • 2. OSPFv3 adjusted the link cost due to link quality deterioration.

hwOspfv3OriginalCost

Original cost.

hwOspfv3AdjustedCost

Link cost adjusted by OSPFv3. The actual cost of an OSPFv3 link is the maximum cost among all cost adjustment causes.

Possible Causes

  • Cause 1: The link BFD fault causes OSPFv3 to adjust the link cost. The actual cost of the OSPFv3 link is the largest cost adjusted due to all the reasons.
  • Cause 2: The link quality deteriorates causes OSPFv3 to adjust the link cost. The actual cost of the OSPFv3 link is the largest cost adjusted due to all the reasons.

Procedure

  • Cause 1: The link BFD fault causes OSPFv3 to adjust the link cost. The actual cost of the OSPFv3 link is the largest cost adjusted due to all the reasons.

    1. Run the display ospfv3 bfd session and display bfd session commands to check the BFD session status of the corresponding interface.

    • If the BFD session remains Down, rectify the BFD fault according to the handling procedure of 1.3.6.1.4.1.2011.5.25.38.3.13 hwBfdIPv6SessDown.
    • If the BFD session is Up, go to Step 2.

    2. Collect log and configuration information, and contact technical support personnel.

    3. End.

  • Cause 2: The link quality deteriorates causes OSPFv3 to adjust the link cost. The actual cost of the OSPFv3 link is the largest cost adjusted due to all the reasons.

    1. Use display interface interfacename to check the link quality of the interface.

    • If the quality is low, check the link and solve the problem of low link quality.
    • If the quality is not low, go to Step 2.

    2. Collect log and configuration information, and contact technical support personnel.

    3. End.
