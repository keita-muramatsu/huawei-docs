INFO/6/SUPPRESS_LOGINFO

Message

INFO/6/SUPPRESS_LOGINFO: Log [FeatureName]/[LogName] is suppressed [SuppNumber] in last [SuppPeriod] seconds, Source=[Source].

Description

A large number of logs with the same name and source generated within the suppression period are recorded.

Parameters

Parameter Name Parameter Meaning

FeatureName

Feature name.

LogName

Log name.

SuppNumber

Number of suppressed logs.

SuppPeriod

Suppression period.

Source

Log source.

Possible Causes

A large number of logs are reported by services. This log is generated if the number of logs with the same name and source within the suppression period exceeds the upper limit.

Procedure

  • Find the handling procedure of the corresponding log according to the feature and name of the suppressed log.
