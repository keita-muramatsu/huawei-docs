ISIS/4/ISIS_LSDB_THRESHOLD_REACH_CLEAR

Message

ISIS/4/ISIS_LSDB_THRESHOLD_REACH_CLEAR: The number of LSP has been less than the lower threshold value. (SysInstance=[IsisSysInstance], LsdbMaxLimit=[IsisLsdbMaxLimit], LsdbUpperThreshold=[IsisLsdbUpperThreshold], LsdbLowerThreshold=[IsisLsdbLowerThreshold], LsdbTotal=[IsisLsdbTotal])

Description

The proportion of the number of LSPs to the maximum number of LSPs in the LSDB fell below the clear alarm threshold.

Parameters

Parameter Name Parameter Meaning

IsisSysInstance

IS-IS process ID

IsisLsdbMaxLimit

Maximum number of LSPs allowed in the IS-IS LSDB

IsisLsdbUpperThreshold

Upper alarm threshold

IsisLsdbLowerThreshold

Lower alarm threshold

IsisLsdbTotal

Number of LSPs in the IS-IS LSDB

Possible Causes

The proportion of LSPs in the IS-IS LSDB to the maximum number of LSPs allowed fell below the lower alarm threshold.

Procedure

This trap message is informational only, and no action is required.
