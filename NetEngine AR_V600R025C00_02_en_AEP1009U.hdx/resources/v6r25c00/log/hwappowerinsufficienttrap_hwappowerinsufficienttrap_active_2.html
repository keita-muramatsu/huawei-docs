WLAN/2/hwApPowerInsufficientTrap_active

Message

WLAN/2/hwApPowerInsufficientTrap_active: AP power supply is insufficient. (APMAC=[APMAC], APName=[APName], PowerWorkMode=[PowerWorkMode], ExpectPowerWorkMode=[ExpectPowerWorkMode], APID=[APID], Impact=[Impact])

Description

The AP power supply was insufficient.

Parameters

Parameter Name Parameter Meaning

APMAC

MAC address of an AP.

APName

Name of an AP.

PowerWorkMode

Actual power supply mode of an AP.

ExpectPowerWorkMode

Expected power supply mode of an AP.

APID

AP ID.

Impact

Impact of insufficient AP power supply.

Possible Causes

The AP power supply was insufficient.

Procedure

1. Run the lldp enable command in the interface view to enable LLDP. In this way, the peer power supply device can identify the power supply standard of the local device and supply power as required.

  • If the alarm persists, go to Step 2.
  • If the alarm is not generated, go to Step 4.

2. Check the peer power supply device and ensure that the power supply standard meets the AP's power supply requirements.

  • If the alarm persists, go to Step 3.
  • If the alarm is not generated, go to Step 4.

3. Run the power force work-mode { af | at | bt60 | bt90 } command in the AP system profile view to adjust the AP power supply mode.

4. Collect trap, log, and configuration information, and contact technical support.

5. End.
