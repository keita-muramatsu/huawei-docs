SSHS/6/SSHS_CREATE_KEY

Message

SSHS/6/SSHS_CREATE_KEY: SSH server automatically generate key pair successfully. (KeyType=[keyType], KeySize=[keySize])

Description

When a device functions as an SSH server and a client uses the public key algorithm of this type to log in to the device for the first time, the device automatically generates a host key pair of this type.

Parameters

Parameter Name Parameter Meaning

keyType

Key type

keySize

Key length

Possible Causes

When a device functions as an SSH server and a client uses the public key algorithm of this type to log in to the device for the first time, the device automatically generates a host key pair of this type.

Procedure

This message is informational only, and no action is required.
