SSH/5/SSHC_DISCONNECT

Message

SSH/5/SSHC_DISCONNECT: Remote SSH server connection is down. (ServiceType=[ServiceType], IPAddress=[IpAddress], VPNInstanceName=[VpnInstance], Reason=[Reason])

Description

The remote SSH server is disconnected.

Parameters

Parameter Name Parameter Meaning

ServiceType

SSH server type.

IpAddress

Address of the SSH server.

VpnInstance

Name of the accessed VPN.

Reason

Cause of the SSH server disconnection.

  • SSHC received disconnect message: The SSH client receives a disconnection message.
  • CLI send disconnect request: The CLI sends a disconnection request.
  • No version string is received: No version information is received.
  • Current keepalive count has reached the maximum value: The current keepalive count reaches the maximum value.
  • Failed to negotiate the encryption algorithm: Failed to negotiate the encryption algorithm.
  • Smpoi connect request is not yet received: No Smpoi connection request is received.

Possible Causes

The client fails to connect to the remote server.

Procedure

1. This message is informational only, and no action is required.
