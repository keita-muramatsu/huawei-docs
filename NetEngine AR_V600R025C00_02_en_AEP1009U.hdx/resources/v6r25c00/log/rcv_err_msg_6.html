GRESM/6/RCV_ERR_MSG

Message

GRESM/6/RCV_ERR_MSG: Received wrong messages in last minute. (MsgType=[MsgType], CompType=[CompType], CompPid=[CompPid], ErrMsgReason=[ErrMsgReason], MsgNum=[MsgNum])

Description

Incorrect messages were received in the last minute.

Parameters

Parameter Name Parameter Meaning

MsgType

Indicates the type of the message.

CompType

Indicates the type of the component.

CompPid

Indicates the PID of the component.

ErrMsgReason

Indicates the reason why the device received incorrect messages.

MsgNum

Indicates the number of incorrect messages received by the device.

Possible Causes

Cause 1: Incorrect message interfaces were used.

Cause 2: The time sequence of messages was incorrect.

Procedure

  • If the problem is due to the first cause, perform the following operation:

Collect configurations and log messages, and then Collect log information and configuration information, and then contact technical support personnel.

  • If the problem is due to the second cause,

GRESM will start message retransmission, and the system will recover.
