GMDB/2/hwNDBResThresholdExceed_active

Message

GMDB/2/hwNDBResThresholdExceed_active: The usage of NDB resources reached the threshold. (Slot=[hwNDBSlot], CPU=[hwNDBCpu], Threshold=[hwNDBThreshold], Current=[hwNDBCurrent], ReasonId=[hwNDBReasonId], Description=[hwNDBReason])

Description

The NDB resource usage exceeded the alarm threshold.

Parameters

Parameter Name Parameter Meaning

hwNDBSlot

Slot information.

hwNDBCpu

Processor ID.

hwNDBThreshold

Alarm threshold.

hwNDBCurrent

Current usage.

hwNDBReasonId

Alarm cause ID.

hwNDBReason

Alarm cause.

Possible Causes

  • Cause 1: The block memory usage exceeded the threshold
  • Cause 2: The usage of client asynchronous messages exceeded the threshold
  • Cause 3: The usage of subscription messages exceeded the threshold
  • Cause 4: The usage of client connections exceeded the threshold
  • Cause 5: The usage of client objects exceeded the threshold
  • Cause 6: The memory usage of the server tablespace exceeds the threshold
  • Cause 7: The memory usage of subscription messages exceeded the threshold
  • Cause 8: The heap memory usage exceeded the threshold
  • Cause 32: The usage of client asynchronous messages in the YANG DB exceeded the threshold
  • Cause 34: The usage of client connections in the YANG DB exceeded the threshold
  • Cause 36: The memory usage of the server tablespace in the YANG DB exceeds the threshold

Procedure

  • Cause 1: The block memory usage exceeded the threshold

    1. You are advised to migrate services on the board where the alarm is generated and manually reset the board.

    2. Collect alarm, log, and configuration information, and contact technical support personnel.

  • Cause 2: The usage of client asynchronous messages exceeded the threshold

    1. Reduce unnecessary forwarding, user access services, and configurations.

    • If the alarm is no longer generated, the problem is resolved.
    • If the alarm persists, go to Step 2.

    2. Collect alarm, log, and configuration information, and contact technical support personnel.

  • Cause 3: The usage of subscription messages exceeded the threshold
