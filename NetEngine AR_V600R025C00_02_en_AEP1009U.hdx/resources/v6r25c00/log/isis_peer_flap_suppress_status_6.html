ISIS/6/ISIS_PEER_FLAP_SUPPRESS_STATUS

Message

ISIS/6/ISIS_PEER_FLAP_SUPPRESS_STATUS: The status of peer flapping suppress is changed. (isisSysInstance=[isisSysInstance], isisCircIndex=[isisCircIndex], isisCircIfIndex=[isisCircIfIndex], ifIndex=[ifIndex], ifName=[ifName], SuppressStatus=[hwIsisPeerFlappingSuppressStatus], Reason=[Reason])

Description

The status of IS-IS neighbor relationship flapping suppression changed on the local interface.

Parameters

Parameter Name Parameter Meaning

isisSysInstance

IS-IS instance ID

isisCircIndex

Index allocated to an IS-IS interface.

isisCircIfIndex

IS-IS interface IF index

ifIndex

IF index of an interface.

ifName

Interface name

hwIsisPeerFlappingSuppressStatus

Suppression status are as follows:

  • None: IS-IS neighbor relationship flapping suppression is not started yet.
  • Hold-down: IS-IS neighbor relationship flapping suppression works in Hold-down mode.
  • Hold-max-cost: IS-IS neighbor relationship flapping suppression works in Hold-max-cost mode.

Reason

Suppression causes are as follows:

  • The suppression exits because the hold-max-cost timer expires.
  • The suppression exits because the hold-down timer expires.
  • A configuration change occurs.
  • A manual operation is performed to exit from flapping suppression.
  • The neighbor relationship frequently flaps.
  • The Hold-down mode exits, and then the Hold-max-cost mode takes effect.

Possible Causes

IS-IS neighbor relationship flapping suppression started, or the interface exited from the suppression.

Procedure

1. Run the display isis last-peer-change command to check whether the interface frequently flaps and whether the cause is correct.

  • If yes, this message is informational only, and no action is required.
  • If no, go to Step 2.

2. Run the reset isis suppress-flapping peer command to forcibly exit neighbor relationship flapping suppression.

3. End.
