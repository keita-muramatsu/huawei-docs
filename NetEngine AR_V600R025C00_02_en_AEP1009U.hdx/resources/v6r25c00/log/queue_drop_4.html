Possible Causes

The CPCAR value for packets sent to the CPU is too large. As a result, a large number of packets are sent to the CPU.

Procedure

Run the display cpu-defend configuration command to check whether the CPCAR values for protocol packets are set properly. You are advised to use the default values.
