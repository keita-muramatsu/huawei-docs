NTP/4/NTP_SYSTIME_CHANGE

Message

NTP/4/NTP_SYSTIME_CHANGE: The local time is changed with NTP. (NTPSourceIP=[SourceIp], VpnName=[VpnName], BeforeTime=[BeforeTime], AfterTime=[AfterTime])

Description

The local system clock changes due to NTP.

Parameters

Parameter Name Parameter Meaning

SourceIp

Indicates the IP address of the server to which the local NTP clock is synchronized.

VpnName

Indicates the NTP instance associated with the peer end that is synchronized with the local NTP clock.

BeforeTime

Indicates the system time before the system clock is changed due to NTP synchronization.

AfterTime

Indicates the system time after the system clock is changed due to NTP synchronization.

Possible Causes

After the peer system clock specified by NTP changes, local NTP time synchronization results in the system clock change.

Procedure

This message is informational only, and no action is required.
