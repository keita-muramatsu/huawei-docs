TELNET/5/TELNET_USER_LOGIN_MAX_VTY_FAIL

Message

TELNET/5/TELNET_USER_LOGIN_MAX_VTY_FAIL: User failed to login. (ServiceType=[ServiceType], UserAddress=[UserAddress], LocalAddress=[LocalAddress], FailedReason=[FailedReason], VpnInstanceName=[VPNInstanceName])

Description

Telnet users fail to log in.

Parameters

Parameter Name Parameter Meaning

ServiceType

Telnet server type.

UserAddress

IP address of the client.

LocalAddress

IP address of the server.

FailedReason

Cause of the login failure.

VPNInstanceName

VPN name.

Possible Causes

All VTY channels are occupied.

Procedure

1. Run the display user-interface maximum-vty command to check whether the number of configured VTY user interfaces reaches the maximum.

  • If the maximum number of VTY channels is not set, run the user-interface maximum-vty command to set a large number of VTY channels.
  • If the maximum value has been configured, wait until the logged-in user logs out.
