CM/3/ALLOCUSERFAIL

Message

CM/3/ALLOCUSERFAIL: The number of [User] users reaches the upper limit. (UserIP:[UserIP],Mac:[Mac],Interface:[Interface])

Description

The number of NAC users exceeds the specification on the interface.

Parameters

Parameter Name Parameter Meaning

User

User name.

UserIP

IP address of a user.

Mac

MAC address of a user.

Interface

Number of the interface through which the user goes online.

Possible Causes

The number of NAC users who go online through the interface exceeded the specification on the interface.

Procedure

1. Run the display access-user interface command to check whether the NAC users are normal.

  • If so, replace the device with one of higher performance.
  • If not, re-plan the network.

2. Collect log information and contact technical support.
