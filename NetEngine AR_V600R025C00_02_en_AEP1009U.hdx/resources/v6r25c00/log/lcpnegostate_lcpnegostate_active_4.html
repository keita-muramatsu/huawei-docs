PPP/4/LCPNEGOSTATE_active

Message

PPP/4/LCPNEGOSTATE_active: LCP negotiation failed on the local interface. (IfName=[ifName], hwPppNegotiationFailReason=[hwPppNegotiationFailReason])

Description

LCP negotiation fails on the interface.

Parameters

Parameter Name Parameter Meaning

ifName

Interface name

hwPppNegotiationFailReason

Cause of the negotiation failure.

Possible Causes

Cause1: The parameter configurations on the local and remote interfaces were different.

Cause2: Network congestion occurred or network quality deteriorated.

Procedure

Cause 1:

1. Run the display this command in the interface view to check whether the parameter settings of the peer interface are the same as those of the local interface.

  • If they are consistent, go to Step 3.
  • If they are inconsistent, go to Step 2.

2. Modify the configurations to ensure that the parameters of the two interfaces are consistent. Then, check whether the alarm is cleared.

  • If so, go to Step 6.
  • If not, go to Step 3.

3. Check whether the physical link is properly connected.

  • If so, go to Step 5.
  • If not, go to Step 4.

4. Rectify the faulty physical link and check whether the alarm is cleared.

  • If so, go to Step 6.
  • If not, go to Step 5.

5. Collect alarm, log, and configuration information, and contact technical support personnel.

6. End.

Cause 2:

Collect alarm, log, and configuration information, and contact technical support personnel.
