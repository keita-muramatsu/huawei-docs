ISIS/6/IS_REMOTE_SYS_ID_CONFLICT

Message

ISIS/6/IS_REMOTE_SYS_ID_CONFLICT: ISIS-INFO: The system IDs of two remote ISs may conflicted. (InstanceId = [InstanceId], Level = [Level], ConflictSystemId = [SystemId], DynamicName = [DynamicName], TheOtherDynamicName = [OtherDynamicName], OneIPAddress = [LocalIPAdd], TheOtherIPAddress= [ConfIPAdd])

Description

The IS-IS system IDs of two remote IS systems conflicted.

Parameters

Parameter Name Parameter Meaning

InstanceId

ID of an IS-IS process

Level

IS-IS Level

SystemId

Conflicting system ID

DynamicName

Dynamic hostname of one device with the conflicting system ID

OtherDynamicName

Dynamic hostname of the other device with the conflicting system ID

LocalIPAdd

Interface IP address of one device with the conflicting system ID

ConfIPAdd

Interface IP address of the other device with the conflicting system ID

Possible Causes

The system IDs of two remote IS systems conflicted on an IS-IS network.

Procedure

  • Locate the devices with the conflicting system ID based on the TheOtherDynamicName field and change the system ID of one device to ensure that the system IDs of the devices in the topology are different.
  • Run the undo isis system-id auto-recover disable command on the device where a system ID conflict occurs to enable the device to automatically change its local system ID if a system ID conflict occurs on the network.
