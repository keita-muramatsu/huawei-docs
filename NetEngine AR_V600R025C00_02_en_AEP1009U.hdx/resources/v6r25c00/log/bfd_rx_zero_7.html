BFD/7/BFD_RX_ZERO

Message

BFD/7/BFD_RX_ZERO: BFD session receives a message with the Required Min RX Interval of 0 for the first time. (LocalDiscriminitor=[LocalDiscriminitor], RemoteDiscriminitor=[RemoteDiscriminitor])

Description

During the BFD session negotiation, the device receives a BFD packet with the MinRXInterval field of 0 from the peer and stops the BFD session negotiation.

Parameters

Parameter Name Parameter Meaning

LocalDiscriminitor

Local discriminator of a BFD session

RemoteDiscriminitor

Remote discriminator of a BFD session

Possible Causes

The peer device is abnormal and sends a BFD packet with the MinRXInterval field set to 0 to stop the BFD session negotiation.

Procedure

  • This log message is informational only, and no action is required.
