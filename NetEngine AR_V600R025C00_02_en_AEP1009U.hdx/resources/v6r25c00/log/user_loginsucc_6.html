IDM/6/USER_LOGINSUCC

Message

IDM/6/USER_LOGINSUCC: User login succeeded. (User Name=[user-name], Vsys=[vsys-name], Source IP=[source-ip-address], Logon Time=[logon-time], Authentication Mode=[authentication-mode]).

This log is supported only on AR5710-S52T2XE4, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L50T2X4-T, AR6710-L8T3TS1X2, AR6710-L50T2X4, AR5710-S8TWDSE-LTE4EA, AR5710-S28T2S2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR6710-L14T2X4, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE-NRGL, AR6710-L26T2X4-T, AR5700-H series, AR5710-S8T2XE-LTE4EA-T, AR5710-S8T1XWE, AR5710-S8T2XE.

Description

A log is generated when an Internet access user logs in successfully.

Parameters

Parameter Name Parameter Meaning

user-name

Login name of an Internet access user.

vsys-name

Virtual system name

source-ip-address

Source IP address of an Internet access user

logon-time

Online duration of an Internet access user

authentication-mode

Authentication mode of Internet access users. This field has the following values:

RADIUS SSO Authentication: RADIUS SSO authentication

TSM SSO Authentication: TSM SSO authentication

Local Authentication: Local authentication

Exempt Authentication: Authentication exemption

Unknown Authentication: Unknown authentication mode

Server Authentication: Server authentication

AD SSO Authentication: AD SSO authentication

Possible Causes

The Internet access user succeeds in logging in.

Procedure

This log message is informational only, and no action is required.
