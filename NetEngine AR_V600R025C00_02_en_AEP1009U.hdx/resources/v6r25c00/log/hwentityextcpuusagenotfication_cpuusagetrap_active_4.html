FWD/4/hwEntityExtCpuUsageNotfication_active

Message

FWD/4/hwEntityExtCpuUsageNotfication_active: The CPU usage exceeds the threshold value. (forwarding type=[hwCpuUsageTrapType], slot id=[hwCpuUsageTrapSlot], CPU id=[hwCpuUsageTrapCpu], current CPU usage=[hwCpuUsageCurrentUsage], threshold=[hwCpuUsageThreashold])

Description

The CPU usage exceeds the alarm threshold.

Parameters

Parameter Name Parameter Meaning

hwCpuUsageTrapType

Forwarding type.

hwCpuUsageTrapSlot

Slot ID.

hwCpuUsageTrapCpu

CPU No.

hwCpuUsageCurrentUsage

Current CPU usage.

hwCpuUsageThreashold

CPU usage alarm threshold.

Possible Causes

The forwarding CPU usage on the board exceeds the alarm threshold.

Procedure

1. Check whether the incoming and outgoing traffic on all the interfaces of the board where the alarm is generated reaches the forwarding performance.

2. Check whether the alarm threshold is too low.
