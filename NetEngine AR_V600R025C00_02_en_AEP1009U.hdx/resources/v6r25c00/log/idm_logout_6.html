IDM/6/IDM_LOGOUT

Message

IDM/6/IDM_LOGOUT: The user logged out. (User Name=[user-name], Vsys=[vsys-name], Source IP=[source-ip-address], Logon Time=[logon-time], Logout Time=[logout-time], Logout Reason=[Logout-Reason]).

This log is supported only on AR5710-S52T2XE4, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L50T2X4-T, AR6710-L8T3TS1X2, AR6710-L50T2X4, AR5710-S8TWDSE-LTE4EA, AR5710-S28T2S2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR6710-L14T2X4, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE-NRGL, AR6710-L26T2X4-T, AR5700-H series, AR5710-S8T2XE-LTE4EA-T, AR5710-S8T1XWE, AR5710-S8T2XE.

Description

A log is generated when an Internet access user goes offline.

Parameters

Parameter Name Parameter Meaning

user-name

Login name of an Internet access user.

vsys-name

Virtual system name.

source-ip-address

Source IP address of an Internet access user

logon-time

Online duration of an Internet access user

logout-time

Time when an Internet access user goes offline.

Logout-Reason

Reason why an Internet access user goes offline. Possible causes are as follows:

  • The administrator manually forces the user to go offline
  • The user does not have service packets for a long time, and the user entry ages
  • The RADIUS accounting stop packet is received
  • The TSM SSO logout packet is received
  • User IP addresses conflict
  • The user proactively logs out on the portal page

Possible Causes

Cause 1: The administrator manually forces the user to go offline.

Cause 2: The user does not have service packets for a long time, and the user entry ages.

Cause 3: The RADIUS accounting stop packet is received.

Cause 4: The TSM SSO logout packet is received.

Cause 5: User IP addresses conflict.

Cause 6: The user proactively logs out on the portal page.

Procedure

This log message is informational only, and no action is required.
