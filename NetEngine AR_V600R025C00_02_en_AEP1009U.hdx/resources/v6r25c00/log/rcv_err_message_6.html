OSPF/6/RCV_ERR_MESSAGE

Message

OSPF/6/RCV_ERR_MESSAGE: OSPF-INFO: The received error message was discarded. (ProcessId=[ProcessId], MsgType=[MsgType], ErrMsgCnt=[ErrMsgCnt], LocalComp=[LocalComp], PeerComp=[PeerComp])

Description

An interface discarded the received error messages.

Parameters

Parameter Name Parameter Meaning

ProcessId

Process ID

MsgType
  • 0: NONE
  • 1: IF
  • 2: NBR
  • 3: DR
  • 4: GR
  • 5: RTCAP
  • 6: FA
  • 7: SHAMLINK
  • 8: LOCLINK
  • 9: LINKLSA
  • 10: RTRLSA
  • 11: NETLSA
  • 12: TYPE3LSA
  • 13: TYPE4LSA
  • 14: TYPE5LSA
  • 15: TYPE7LSA
  • 16: TELSA
  • 17: SPTNODE

ErrMsgCnt

Count of error messages

LocalComp

CID of the local component

PeerComp

CID of the peer component

Possible Causes

Cause 1: Message errors occurred during transmission on the network.

Cause 2: Messages were rewritten when being delivered or sent.

Procedure

This log message is informational only, and no action is required.
