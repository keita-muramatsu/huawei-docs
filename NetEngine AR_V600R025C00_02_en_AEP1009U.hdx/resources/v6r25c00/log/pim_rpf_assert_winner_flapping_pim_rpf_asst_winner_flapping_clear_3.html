PIM/3/PIM_RPF_ASSERT_WINNER_FLAPPING_clear

Message

PIM/3/PIM_RPF_ASSERT_WINNER_FLAPPING_clear: The flapping of the assert winner is clear. (AddressFamily=[AddressFamily], SrcAddr=[SrcAddr], GrpAddr=[GrpAddr], InterfaceName=[InterfaceName], CurrentAssertWinnerAddr=[CurrentAssertWinnerAddr], InstanceName=[InstanceName], ReasonType=[ReasonType])

Parameters

Parameter Name Parameter Meaning

AddressFamily

Address family.

SrcAddr

Multicast source address.

GrpAddr

Multicast group address.

InterfaceName

Interface name.

CurrentAssertWinnerAddr

Current assert winner address.

InstanceName

Instance name.

ReasonType

Reason for alarm clear:

  • 1: Incoming interface changed;
  • 2: Entry is deleted;
  • 3: Assert winner flapping restored.

Possible Causes

The Assert state of the upstream interface of the upstream device is restored to stable

Procedure

The trap is informational only, and no action is required.
