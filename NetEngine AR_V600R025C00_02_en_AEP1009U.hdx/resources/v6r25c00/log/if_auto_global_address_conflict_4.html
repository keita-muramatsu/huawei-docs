IFNET/4/IF_AUTO_GLOBAL_ADDRESS_CONFLICT

Message

IFNET/4/IF_AUTO_GLOBAL_ADDRESS_CONFLICT: The auto global address conflicts with an existing IPv6 address. (Interface=[ifName],IPv6Address=[ipv6Addr],PrefixLength=[prefixLen])

Description

The automatically generated global unicast address conflicts with an existing IPv6 address.

Parameters

Parameter Name Parameter Meaning

ifName

Interface name

ipv6Addr

IPv6 address

prefixLen

IPv6 address prefix length

Possible Causes

An IPv6 address that is the same as or on the same network segment as the automatically generated address already exists on the device.

Procedure

Modify the configured automatically generated global unicast address so that the global unicast address does not conflict with other addresses.
