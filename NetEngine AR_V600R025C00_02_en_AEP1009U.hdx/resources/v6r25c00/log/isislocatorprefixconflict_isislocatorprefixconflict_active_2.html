ISIS/2/isisLocatorPrefixConflict_active

Message

ISIS/2/isisLocatorPrefixConflict_active: A locator prefix conflict was detected between the local device and another device. (SysInstance=[hwisisSysInstance], MtId=[hwisisMtId], Level=[hwisisSysLevelIndex], PrefixAddress=[hwisisIpv6PrefixAddress], PrefixAddressMask=[hwisisIpv6PrefixAddressMask], ConflictSystemId=[hwIsisConflictSystemID], LocalFlexAlgorithm=[hwisisLocalFlexAlgorithm], RemoteFlexAlgorithm=[hwisisRemoteFlexAlgorithm], ConflictHostName=[hwIsisHostName])

Description

Conflicting locator prefixes were detected between the local device and other devices.

Parameters

Parameter Name Parameter Meaning

hwisisSysInstance

IS-IS process ID

hwisisMtId

IS-IS multi-topology ID.

hwisisSysLevelIndex

IS-IS Level.

hwisisIpv6PrefixAddress

IPv6 prefix address.

hwisisIpv6PrefixAddressMask

Indicates the mask of the IPv6 prefix address.

hwIsisConflictSystemID

Indicates the conflicting IS-IS system ID.

hwisisLocalFlexAlgorithm

Indicats the local flexible algorithm.

hwisisRemoteFlexAlgorithm

Indicates the remote flexible algorithm.

hwIsisHostName

Conflicting dynamic hostname of the IS-IS system.

Possible Causes

The same Locator prefix is configured on different devices.

Procedure

1. Run the display isis route-source ipv6 command to check the source of the conflicting locator based on information in the alarm, such as the conflicting prefix and system ID.

2. Check which device is incorrectly configured.

  • If the peer device is incorrectly configured, run the segment-routing ipv6 command on the peer device to enter the SRv6 view and modify the locator configuration.
  • If the local device is incorrectly configured, run the segment-routing ipv6 command on the local device to enter the SRv6 view and modify the locator configuration.

3. End.
