SSHC/5/TCP_PORT_FORWARD

Message

SSHC/5/TCP_PORT_FORWARD: Indicates the SSH port forwarding channel record. (Operation=[OperType], ServerHost=[ServerHost], ServerPort=[ServerPort], ServerUsername=[ServerUserName], ServerForwardingPort=[ServerForwardingPort], ForwardHost=[ForwardHost], ForwardPort=[ForwardPort], VpnName=[VpnName])

Description

This log records the creation and destruction of the port forwarding channel on the SSH client.

Parameters

Parameter Name Parameter Meaning

OperType

SSH port forwarding channel:

1: created

2: destroyed

ServerHost

IP address of the SSH server.

ServerPort

Server port connected to the SSH client.

ServerUserName

User name for logging in to the server using SSH.

ServerForwardingPort

Server port associated with the SSH client forwarding port.

ForwardHost

IP address of the remote host that receives the packets forwarded by the SSH client.

ForwardPort

Port of the remote host that receives the packets forwarded by the SSH client.

VpnName

VPN name.

Possible Causes

A user triggers the creation and destruction of the SSH port forwarding channel.

Procedure

This message is informational only, and no action is required.
