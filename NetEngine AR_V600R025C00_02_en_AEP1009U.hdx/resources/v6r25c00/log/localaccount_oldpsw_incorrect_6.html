AAA/6/LOCALACCOUNT_OLDPSW_INCORRECT

Message

AAA/6/LOCALACCOUNT_OLDPSW_INCORRECT: User password login: Local account [account] entered the incorrect old password.UserIp=[userip].

Description

The old password entered by the local user is incorrect.

Parameters

Parameter Name Parameter Meaning

account

Name of the local account whose old password is incorrectly entered.

userip

Local account address.

Possible Causes

The old password fails to be verified during user login.

Procedure

This message is informational only, and no action is required.
