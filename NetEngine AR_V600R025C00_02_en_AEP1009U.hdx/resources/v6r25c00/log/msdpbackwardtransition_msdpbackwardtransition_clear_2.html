MSDP/2/msdpBackwardTransition_clear

Message

MSDP/2/msdpBackwardTransition_clear: MSDP peer enter the established state. (RemoteAddr=[RemoteAddr], FsmEstablishedTransitions=[EstablishedTransitions], InstanceName=[InstanceName])

Parameters

Parameter Name Parameter Meaning

RemoteAddr

MSDP peer address

EstablishedTransitions

Count of changes to the established state

InstanceName

Instance name

Possible Causes

The msdpBackwardTransition alarm was cleared when a device and its peer established the MSDP peer relationship.

Procedure

This alarm message indicates a normal situation, and no action is required.
