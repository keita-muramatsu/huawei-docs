EAP/4/hwMacQuietMaxUserAlarm_active

Message

EAP/4/hwMacQuietMaxUserAlarm_active: The number of mac quiet users reached the maximum. (Spec of User Num=[SpecofUserNum], Current Threshold=[CurrentThreshold], Lower Threshold=[LowerThreshold], Upper Threshold=[UpperThreshold], Process Name=[ProcessName])

Description

The number of MAC address authentication users in quiet state reached the maximum value.

Parameters

Parameter Name Parameter Meaning

SpecofUserNum

Indicates the specification of MAC address authentication users in quiet state.

CurrentThreshold

Indicates the percentage of MAC address authentication users in quiet state to the total number of percentage of MAC address authentication users.

LowerThreshold

Indicates the lower alarm threshold for the percentage of MAC address authentication users in quiet state.

UpperThreshold

Indicates the upper alarm threshold for the percentage of MAC address authentication users in quiet state.

ProcessName

Indicates the process name.

Possible Causes

The percentage of current MAC address authentication users in quiet state to the total MAC address authentication users in quiet state exceeded the upper alarm threshold.

Procedure

This message is displayed, and no action is required.
