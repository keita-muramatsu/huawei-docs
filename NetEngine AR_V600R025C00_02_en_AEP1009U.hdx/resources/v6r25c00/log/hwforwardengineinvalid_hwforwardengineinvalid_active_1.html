FWM-FRAME/1/hwForwardEngineInvalid_active

Message

FWM-FRAME/1/hwForwardEngineInvalid_active: The forwarding engine completely failed. (EntPhysicalIndex=[EntPhysicalIndex], EntPhysicalName=[EntPhysicalName], EntityType=[EntityType], EntityTrapFaultID=[EntityTrapFaultID], Reason=[Reason])

Description

The forwarding engine fails.

Parameters

Parameter Name Parameter Meaning

EntPhysicalIndex

Entity index.

EntPhysicalName

Entity name.

EntityType

Entity type.

EntityTrapFaultID

Fault code.

Reason

Alarm cause.

Possible Causes

  • Cause 1: The coprocessor failed.
  • Cause 2: The PCIE interface of the forwarding chip failed.
  • Cause 3: The Die connectivity of the forwarding chip was abnormal.
  • Cause 4: The port between LSW and Coprocessor is Down.
  • Cause 5: CRC error packets are generated on the port between LSW and Coprocessor.

Procedure

1. Collect alarm, log, and configuration information, and contact technical support personnel.
