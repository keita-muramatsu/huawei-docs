DEVM/3/hwEntityFileSystemFdAlarm_active

Message

DEVM/3/hwEntityFileSystemFdAlarm_active: The file handle of the process is overloaded. (EntityPhysicalIndex=[EntityPhysicalIndex], PhysicalName=[entPhysicalName], ProcessName=[ProcessName])

Description

The file handle of the process is overloaded.

Parameters

Parameter Name Parameter Meaning

EntityPhysicalIndex

Physical entity index.

entPhysicalName

Physical entity name.

ProcessName

Process name.

Possible Causes

The file handle of the process may leak.

Procedure

Collect alarm, log, and configuration information and contact technical support engineers.
