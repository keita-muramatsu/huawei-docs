AM/4/IPALLOCFAIL

Message

AM/4/IPALLOCFAIL: Failed to allocate an IP address. (PoolName=[PoolName], ClientId=[ClientId], Reason=[Reason], UserType=[UserType])

Description

The DHCP server failed to assign an IP address to the client.

Parameters

Parameter Name Parameter Meaning

PoolName

Name of an address pool.

ClientId

Client ID.

Reason

Cause.

UserType

User type.

Possible Causes

1. No IP address is available in the address pool.

2. The address pool is locked.

3. A system error occurs.

Procedure

Cause 1: No IP address is available in the address pool.

Run the network <ip-address> [ mask { <mask> | <mask-length> } ] command in the address pool view or run the ip address <ip-address> { <mask> | <mask-length> } command in the interface view to adjust the <mask> or <mask-length> value to expand the range of available IP addresses in the address pool.

Cause 2: The address pool is locked.

Check the reason why the administrator locks the address pool, and run the undo lock command in the address pool view to unlock the address pool.

Cause 3: A system error occurs.

Collect log and configuration information, and contact technical support personnel. You can run the display diagnostic-information command to collect diagnostic information of the device.
