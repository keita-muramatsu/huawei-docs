IKE/4/DYNA_PEER_MAX

Message

IKE/4/DYNA_PEER_MAX: The number of dynamic peers has reached the maximum value.

Description

When a remote device connects to a device in the headquarters, the device in the headquarters dynamically creates an IKE peer for the remote device. When a device initiates an IPsec tunnel negotiation with a remote device, the local device dynamically creates an IKE peer.

This log indicates that the number of IKE peers dynamically created on the local device has reached the maximum value.

Parameters

None

Possible Causes

The number of dynamically created IKE peers has reached the maximum value.

Procedure

1. Check the IPsec VPN tunnels that the local device has set up with remote peers and delete unnecessary tunnels (if any).
