PSSP_KMS/5/MK_CHANGE

Message

PSSP_KMS/5/MK_CHANGE: The system master key changed. (Operate type = [type], Change result = [result], detail = [detail])

Description

The system master key is changed.

Parameters

Parameter Name Parameter Meaning

type

Type of the system master key change operation:

  • Auto: The system automatically updates the master key.
  • Manual: The master key is set using commands.

result

Result of changing the system master key:

  • Success: The key is changed successfully.
  • Fail: The key fails to be changed.

detail

Details of changing the system master key:

  • Set master key less than 3 minutes. The time between two key settings is less than 3 minutes.
  • Generate master key failed. Failed to generate the key.
  • Backup update master key failed. The standby main control board fails to update the key.
  • Send msg to daemon failed. Notify the daemon process of the message sending failure.
  • Active master key failed. Failed to activate the key.
  • Change master key unknown error. Unknown error.
  • Clear master key failed. Failed to clear the key.
  • Clear master key success. The key is cleared successfully.
  • Change master key success. The key is changed successfully.

Possible Causes

The system master key is changed.

Procedure

If the key is successfully changed, this message is informational only, and no action is required. If the interval for setting the key is more than 3 minutes or the key failed to be changed, contact technical support.
