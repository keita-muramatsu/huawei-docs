WLAN/4/hwApVapStaFullTrap_clear

Message

WLAN/4/hwApVapStaFullTrap_clear: VAP has the max number of stations notify restore. (APMAC=[APMAC], APName=[APName], RADIOID=[RADIOID], WLANID=[WLANID], FailCause=[FailCause], CurrentNum=[CurrentNum], APID=[APID])

Parameters

Parameter Name Parameter Meaning

APMAC

MAC address of an AP.

APName

Name of an AP.

RADIOID

Radio ID.

WLANID

WLAN ID reporting the alarm.

FailCause

Cause of the STA authentication failure.

CurrentNum

Number of STAs associated with the AP.

APID

AP ID.

Possible Causes

The number of STAs is smaller than the maximum number.

Procedure

This message is informational only, and no action is required.
