IGMP/2/hwMgmdGMPBoardLimit_clear

Message

IGMP/2/hwMgmdGMPBoardLimit_clear: The new report message can be processed because the IGMP or MLD group memberships on the board falls below the upper limit. (AddressFamily=[AddressFamily], SlotName=[SlotName], LimitCount=[LimitCount])

Parameters

Parameter Name Parameter Meaning

AddressFamily

Address family:

  • 1: IPv4 address family.
  • 2: IPv6 address family.

SlotName

Slot name of a board.

LimitCount

Maximum number of IGMP/MLD entries allowed on a board.

Possible Causes

Entry delete

Procedure

  • This message is informational only, and no action is required.
