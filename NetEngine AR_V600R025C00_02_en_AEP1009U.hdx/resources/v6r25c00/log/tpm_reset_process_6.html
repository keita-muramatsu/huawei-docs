TPM/6/TPM_RESET_PROCESS

Message

TPM/6/TPM_RESET_PROCESS: The process dynamic integrity measurement exception is rectified. (Process ID=[Pid], Process Name=[ProcName], Repair Type=[Type], Result=[Result])

Description

Process restart information is restarted.

Parameters

Parameter Name Parameter Meaning

Pid

Process ID.

ProcName

Process name.

Type

Repair type.

  • reset-process: The process is restarted.

Result

Repair result:

  • failed: The security repair fails.
  • succeed: The security repair is successful.

Possible Causes

The northbound YANG interface delivers packets for restarting a specified process.

Procedure

This message is informational only, and no action is required.
