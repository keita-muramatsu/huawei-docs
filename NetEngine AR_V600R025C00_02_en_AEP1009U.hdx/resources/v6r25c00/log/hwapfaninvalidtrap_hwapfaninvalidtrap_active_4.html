WLAN/4/hwApFanInvalidTrap_active

Message

WLAN/4/hwApFanInvalidTrap_active: All functions of the fan module failed. (APMAC=[APMAC], APName=[APName], ApFanIndex=[ApFanIndex], ApEntityPhysicalName=[ApEntityPhysicalName], APID=[APID])

Description

The fan was faulty.

Parameters

Parameter Name Parameter Meaning

APMAC

MAC address of an AP.

APName

Name of an AP.

ApFanIndex

Fan interface index of an AP.

ApEntityPhysicalName

Interface name of an AP.

APID

AP ID.

Possible Causes

Fans are faulty.

Procedure

1. Run the display device fan command to check the fan status. Check whether the fan module is registered and whether the fan speed is zero.

  • If the fan module is not registered, remove and install it.
  • If the rotating speed of a fan is zero, replace the fan.

2. If the fault persists, contact technical support.
