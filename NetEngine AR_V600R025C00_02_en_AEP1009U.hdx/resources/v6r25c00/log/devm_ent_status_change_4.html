DEVM/4/DEVM_ENT_STATUS_CHANGE

Message

DEVM/4/DEVM_ENT_STATUS_CHANGE: Entity status has changed. (EntityName= [EntityName],EntityType = [EntityType],Status = [Status])

Description

A physical entity status changed.

Parameters

Parameter Name Parameter Meaning

EntityName

Name of a physical entity.

EntityType

Type of a physical entity.

Values: 1-MPU; 2-LPU; 3-SFU; 4-PIC.

Status

Status of a physical entity.

Values: 12-in position; 3-offline; 8-registered; 9-unregistered

Possible Causes

The status of the physical entity changed.

Procedure

This is an event notification and does not affect service functions. No action is required.
