NQA/4/NQA_TESTRESULTCHANGE

Message

NQA/4/NQA_TESTRESULTCHANGE: NQA entry test result changed. (OwnerIndex=[OwnerIndex],TestName=[TestName],ResultIndex=[ResultIndex],HopIndex=[HopIndex],TestType=[TestType],SourceIP=[SourceIP],SourceIfName=[SourceIfName],DestinationIP=[DestinationIP],LastResult=[LastResult],CurrentResult=[CurrentResult],ChangeToFailTimes=[ChangeToFailTimes],ChangeToSuccessTimes=[ChangeToSuccessTimes],ChangeToNoResultTimes=[ChangeToNoResultTimes],ChangeToNegotiateFailTimes=[ChangeToNegotiateFailTimes],ChangeToAbnormalTimes=[ChangeToAbnormalTimes],FailTimes=[FailTimes],SuccessTimes=[SuccessTimes],NoResultTimes=[NoResultTimes],NegotiateFailTimes=[NegotiateFailTimes],AbnormalTimes=[AbnormalTimes])

Description

1. Records are triggered when result status, including no result, negotiation failure, fail, abnormal, and success, changes.

2. Information based on the test instance records:

(1) Test instance type

(2) Source IP address

(3) Source interface

(4) Destination IP Address

(5) Test results before and after the result changes.

(The test results include 0: no result; 1: success; 2: fail; 3: negotiation failure; 5: abnormal; 255: init.)

(6) Number of times that the test result changes to fail.

(7) Number of times that the test result changes to success.

(8) Number of times that the test result changes to no result.

(9) Number of times that the test result changes to negotiation failure.

(10) Number of times that the test result changes to abnormal.

(11) Number of times that the test result is fail.

(12) Number of times that the test result is success.

(13) Number of times that the test result is no result.

(14) Number of times that the test result is negotiation failure.

(15) Number of times that the test result is abnormal.

Parameters

Parameter Name Parameter Meaning

OwnerIndex

Administrator of a test instance

TestName

Name of the test instance

ResultIndex

Result index

HopIndex

Hop index

TestType

Test instance type

SourceIP

Source IP address

SourceIfName

Source interface name

DestinationIP

Destination IP address

LastResult

Last test result

CurrentResult

Current test result

ChangeToFailTimes

Number of times that the test result is changed to Fail

ChangeToSuccessTimes

Number of times that the test result changes to Success

ChangeToNoResultTimes

Number of times that the test result is changed to No result

ChangeToNegotiateFailTimes

Number of times that the test result is changed to Negotiation failed

ChangeToAbnormalTimes

Number of times that the test result is changed to Abnormal

FailTimes

Number of times that the result is Fail

SuccessTimes

Number of times that the result is Success

NoResultTimes

Number of times that the result is No result

NegotiateFailTimes

Number of negotiation failures

AbnormalTimes

Number of abnormal results

Possible Causes

The probe result status of the test instance changed.

Procedure

No action is required. This is a normal log.
