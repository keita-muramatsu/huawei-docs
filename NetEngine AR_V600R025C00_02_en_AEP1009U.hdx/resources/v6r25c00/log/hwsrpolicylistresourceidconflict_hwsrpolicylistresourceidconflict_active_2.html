SRPOLICY/2/hwSrPolicyListResourceIdConflict_active

Message

SRPOLICY/2/hwSrPolicyListResourceIdConflict_active: The alarm indicating that the resource ID to be used as the identifier of an SR Policy's segment list fails to be allocated is generated. (hwSrPolicyEndpoint=[SrPolicyEndpoint], hwSrPolicyColor=[SrPolicyColor], hwSrListId=[SegmentListId], hwSrPolicyListResourceId=[ResourceId], hwSrPolicyListResourceIdType=[ResourceIdType], hwSrPolicyListResourceIdFailReason=[ResourceIdFailReason], hwSrPolicyConflictState=[ConflictState])

Description

A resource ID used to identify the segment list of an SR Policy's candidate path failed to be allocated.

Parameters

Parameter Name Parameter Meaning

SrPolicyEndpoint

Endpoint of an SR Policy.

SrPolicyColor

Color of an SR Policy.

SegmentListId

SR Policy candidate path segment list ID.

ResourceId

Resource ID to be allocated to the segment list of an SR Policy's candidate path.

ResourceIdType

Type of the resource ID to be allocated to the segment list of an SR Policy's candidate path.

ResourceIdFailReason

Reason why a resource ID failed to be allocated to the segment list of an SR Policy's candidate path.

ConflictState

Current conflict status.

Possible Causes

1. No available resource pool.

2. The resource ID in different SR Policy's segment lists are the same.

3. The resource ID in the segment list of the SR Policy is the same as the Binding SID of the SR Policy.

4. The resource ID in the segment list of the SR Policy is used by non-SR Policy services.

Procedure

1. On the alarmed device, run the display alarm active command to query resource ID conflict information.

2. Check whether there is an available resource pool. If so, allocate a new resource ID to the segment list of the corresponding SR Policy's candidate path. If not, configure a resource pool.

3. If the alarm persists, collect alarm and configuration information and contact technical support.
