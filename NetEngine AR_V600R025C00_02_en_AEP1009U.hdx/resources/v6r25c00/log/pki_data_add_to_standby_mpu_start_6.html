PKI/6/PKI_DATA_ADD_TO_STANDBY_MPU_START

Message

PKI/6/PKI_DATA_ADD_TO_STANDBY_MPU_START: Backing up [data_type_desp] [data_name] to the standby MPU. (Slot=[slot_id])

This log is supported only on AR6700-H series, AR8700 series.

Description

The new data starts to be backed up to the standby system control board in real time.

Parameters

Parameter Name Parameter Meaning

data_type_desp

PKI data type description. The value can be certificate, CRL, key pair, or whitelist.

data_name

Name of PKI data, such as the certificate name and key pair name.

slot_id

Slot ID.

Possible Causes

The new data starts to be backed up to the standby system control board in real time.

Procedure

No action is required for the normal running information.
