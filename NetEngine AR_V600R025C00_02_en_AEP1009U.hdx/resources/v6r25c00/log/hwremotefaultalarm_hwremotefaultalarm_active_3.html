DEVM/3/hwRemoteFaultAlarm_active

Message

DEVM/3/hwRemoteFaultAlarm_active: The remote fault alarm has occurred. (IfIndex=[hwPhysicalPortIfIndex], IfName=[hwPhysicalPortName])

Description

A remote fault alarm was generated.

Parameters

Parameter Name Parameter Meaning

hwPhysicalPortIfIndex

Index of a physical interface

hwPhysicalPortName

Name of a physical interface

Possible Causes

If the transmit link from the local end to the remote end is faulty, for example, the transmit optical fiber at the local end is removed, causing the remote end to fail to receive signals, this alarm is reported at the local end (a device with 10GE ports or ports of higher rates).

Procedure

1. Check whether the transmit optical fiber is faulty. If yes, replace the optical fiber and check whether the alarm is cleared.

If yes, no further action is required.

If no, go to Step 2.

2. Check whether the local and remote optical modules are faulty. If yes, replace the optical modules and check whether the alarm is cleared.

If yes, no further action is required.

If no, go to Step 3.

3. Check whether the remote board is faulty. If yes, replace the board and check whether the alarm is cleared.

If yes, no further action is required.

If no, go to Step 4.

4. Collect alarm, log, and configuration information, and contact Huawei technical support personnel.

5. End.
