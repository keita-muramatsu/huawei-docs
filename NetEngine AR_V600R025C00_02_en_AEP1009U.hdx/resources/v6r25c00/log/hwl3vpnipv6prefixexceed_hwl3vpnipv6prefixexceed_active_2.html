RM/2/hwL3vpnIpv6PrefixExceed_active

Message

RM/2/hwL3vpnIpv6PrefixExceed_active: The number of IPv6 prefixes in the VPN instance exceeded the maximum value. (VpnInstanceName=[VpnInstanceName], PrefixCount=[PrefixCount], MaxValue=[MaxValue])

Description

The number of IPv6 route prefixes in a VPN instance exceeded the maximum number that is allowed.

Parameters

Parameter Name Parameter Meaning

VpnInstanceName

Name of a VPN instance

PrefixCount

Current number of IPv6 route prefixes in the VPN instance

MaxValue

Maximum number of IPv6 route prefixes in the VPN instance

Possible Causes

Cause1: A large number of IPv6 routes were added to the routing table.

Cause2: The maximum number of IPv6 route prefixes in the VPN instance was reduced.

Procedure

1. Run the display ipv6 routing-table vpn-instance <vpn-instance-name> statistics command to check the total number of VPN route prefixes and the number of routes that each protocol has added to the IPv6 routing table. Run the display ipv6 routing-table limit command to check the total number of existing VPN route prefixes and the configured limit on the number of route prefixes. Then check whether the number of configured VPN route prefixes exceeds the maximum value.

  • If yes, go to Step 2.
  • If no, go to Step 3.

2. Run the prefix limit <number> { alert-percent | simply-alert } command to reconfigure the maximum number of route prefixes or delete unnecessary VPN routes. Then, check whether the alarm persists.

  • If yes, go to Step 3.
  • If no, go to Step 4.

3. Collect alarm and configuration information, and contact technical support.

4. End.
