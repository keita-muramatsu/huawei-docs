AAA/6/LOCALACCOUNT_MODIFY_PASSWORD_LOCK

Message

AAA/6/LOCALACCOUNT_MODIFY_PASSWORD_LOCK: The password of local account [account] cannot be changed.

Description

A local user is not allowed to change the user password.

Parameters

Parameter Name Parameter Meaning

account

Name of a local account.

Possible Causes

  • If the number of times that a user enters incorrect old passwords reaches the upper limit within the retry interval, the user account is locked. During the lockout duration, the user cannot change the password.
  • The administrator manually sets the user status to block.

Procedure

1. Ask the administrator to unlock the account.

2. The account is automatically unlocked after the lockout duration expires.
