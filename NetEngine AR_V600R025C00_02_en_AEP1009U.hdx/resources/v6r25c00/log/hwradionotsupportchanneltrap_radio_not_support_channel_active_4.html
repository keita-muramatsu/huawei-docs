WLAN/4/hwRadioNotSupportChannelTrap_active

Message

WLAN/4/hwRadioNotSupportChannelTrap_active: AP not support configured channel notify. (APMAC=[hwWlanRadioInfoApMac], RadioID=[hwWlanRadioID], APName=[hwWlanRadioInfoApName], CONFIGURED BANDWIDTH=[hwWlanRadioMngChannelBandwidth], CONFIGURED CHANNEL1=[hwWlanRadioMngChannel], CONFIGURED CHANNEL2=[hwWlanRadioMngSecondChannel], ACTUAL BANDWIDTH=[hwWlanRadioActualChannelBandwidth], ACTUAL CHANNEL1=[hwWlanRadioActualChannel], ACTUAL CHANNEL2=[hwWlanRadioSecondActualChannel], REASON=[hwWlanRadioChannelChangedReasonStr], APID=[hwWlanRadioInfoApId])

Description

An AP does not support the configured channels.

Parameters

Parameter Name Parameter Meaning

hwWlanRadioInfoApMac

MAC address of an AP.

hwWlanRadioID

Radio ID.

hwWlanRadioInfoApName

Name of an AP.

hwWlanRadioMngChannelBandwidth

Configured bandwidth.

hwWlanRadioMngChannel

Configured channel.

hwWlanRadioMngSecondChannel

Configured second channel.

hwWlanRadioActualChannelBandwidth

Actual bandwidth.

hwWlanRadioActualChannel

Actual channel.

hwWlanRadioSecondActualChannel

Actual second channel.

hwWlanRadioChannelChangedReasonStr

Reason of the alarm.

hwWlanRadioInfoApId

AP ID.

Possible Causes

The AP does not support the channels delivered by the AC.

Procedure

1. Check whether the AP goes online on a Mesh network.

  • If so, the AP does not support channel delivery. Go to Step 4.
  • If not, go to Step 2.

2. Check the channel supported by the AP. Modify the channel configuration for the AP by running the channel { 20mhz | 40mhz-minus | 40mhz-plus | 80mhz | 160mhz | 320mhz } channel command. Then, check whether the alarm persists.

  • If so, go to Step 3.
  • If not, go to Step 4.

3. Collect trap, log, and configuration information, and contact technical support.

4. End.
