FULLCONE/3/hwSecFullConeIpPoolPortUsageOverThreshold_clear

Message

FULLCONE/3/hwSecFullConeIpPoolPortUsageOverThreshold_clear: The usage of ip pool port on slot [hwSecFullConeTrapSlot] CPU [hwSecFullConeTrapCPU], IpPoolIndex [hwSecFullConeTrapIpPoolIndex], usage [hwSecFullConeIpPoolPortUsageTrap] normal, threshold value [hwSecFullConeIpPoolPortUsageThresholdTrap].

Parameters

Parameter Name Parameter Meaning

hwSecFullConeTrapSlot

Slot ID.

hwSecFullConeTrapCPU

CPU ID.

hwSecFullConeTrapIpPoolIndex

ID of an address pool.

hwSecFullConeIpPoolPortUsageTrap

Port usage of the 3-tuple NAT address pool on a CPU.

hwSecFullConeIpPoolPortUsageThresholdTrap

Alarm threshold for the port usage of a 3-tuple NAT address pool.

Possible Causes

The port usage of the full cone NAT address pool on a CPU of the device was lower than the threshold.

Procedure

This message is informational only, and no action is required.
