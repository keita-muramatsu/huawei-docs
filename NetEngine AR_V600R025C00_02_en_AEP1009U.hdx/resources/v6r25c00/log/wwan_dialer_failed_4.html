WWAN/4/WWAN_DIALER_FAILED

Message

WWAN/4/WWAN_DIALER_FAILED: Dialup failed. (Interface=[interface-name], SIM-id=[sim-id], APN=[apn-name], Reason=[fail-reason])

Description

Dial-up failed. (The log information includes the interface name, SIM card ID, APN, and AT command execution result.)

Parameters

Parameter Name Parameter Meaning

interface-name

Cellular interface name.

sim-id

SIM card number.

apn-name

Access point name.

fail-reason

Cause of the dial-up failure.

Possible Causes

Cause 1: Failed to obtain the IP address.

Cause 2: The AT command fails to be executed.

Cause 3: The dialup timed out.

Procedure

Cause 1: Failed to obtain the IP address.

1. Check whether the configurations are correct. If the configurations are correct, go to step 2.

2. Collect alarm, log, and configuration information, and contact technical support personnel.

Cause 2: The AT command fails to be executed.

1. Collect alarm, log, and configuration information, and contact technical support personnel.

Cause 3: The dialup timed out.

1. The dial-up timeout may be caused by the unstable wireless network. Adjust the antenna and wait for the automatic dial-up retry. If the dial-up still times out after 1 minute, go to step 2.

2. Check whether the configurations are correct. If the configurations are correct, go to step 3.

3. Collect alarm, log, and configuration information, and contact technical support personnel.
