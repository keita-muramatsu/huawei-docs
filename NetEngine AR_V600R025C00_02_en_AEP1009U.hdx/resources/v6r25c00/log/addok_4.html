BLACKLIST/4/ADDOK

Message

BLACKLIST/4/ADDOK: A blacklist entry was added. (SyslogId=[syslog-id], IpVersion=[ip-version], SrcIp=[source-ip-address], DstIp=[destination-ip-address], SrcPort=[source-port], DstPort=[destination-port], Protocol=[protocol], User=[user-name], VSysId=[vsys-id], VSys=[vsys], Reason=[reason], Timeout=[timeout] min)

Description

A blacklist entry was added.

Parameters

Parameter Name Parameter Meaning

syslog-id

Log ID.

ip-version

IP address version, either IPv4 or IPv6.

source-ip-address

Source IP address.

destination-ip-address

Destination IP address.

source-port

Source port.

destination-port

Destination port.

protocol

Protocol.

user-name

User name.

vsys-id

Virtual system ID.

vsys

Virtual system name.

reason

Reason for adding a blacklist entry. Currently, only IPS Associate is supported, indicating IPS correlation detection.

timeout

Blacklist timeout time.

Possible Causes

Cause 1: The administrator manually creates a blacklist. Cause 2: The device automatically generates a blacklist.

Procedure

This log message is informational only, and no action is required.
