EAP/6/EAPOL_USER_QUIETTABLE_ADD

Message

EAP/6/EAPOL_USER_QUIETTABLE_ADD: The user is added to quiet-table. (MAC Address:[MAC])

Description

The 802.1X authentication user is added to the quiet table.

Parameters

Parameter Name Parameter Meaning

MAC

MAC address of an 802.1X authentication user.

Possible Causes

After the quiet function is enabled, the number of authentication failures of an 802.1X authentication user within the quiet period exceeds the specified value.

The difference between the configured quiet period and the actual quiet period does not exceed 15 seconds.

Procedure

This message is informational only, and no action is required.
