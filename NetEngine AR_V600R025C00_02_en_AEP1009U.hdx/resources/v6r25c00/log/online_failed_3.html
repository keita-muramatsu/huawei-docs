CONTROLLERMNG/3/ONLINE_FAILED

Message

CONTROLLERMNG/3/ONLINE_FAILED: Online failed. (ErrorCode=[ErrorCode], Reason=[Reason], ControllerIP=[ControllerIP])

Description

The device failed to register with the controller.

Parameters

Parameter Name Parameter Meaning

ErrorCode

Error code

Reason

Error cause

ControllerIP

Controller IP address

Possible Causes

1. Failed to obtain the controller IP address.

2. The controller IP address was deleted.

3. The controller IP address was changed.

4. Obtaining the SSH or NETCONF connection setup result timed out.

5. Failed to set up a NETCONF connection.

6. The NETCONF connection was torn down.

7. The controller failed to verify device information.

8. Failed to set up an SSH connection.

Procedure

Cause 1: Failed to obtain the controller IP address.

Check whether peer-ip is configured in the Callhome view.

Cause 2: The controller IP address was deleted.

Check whether peer-ip is configured in the Callhome view.

Cause 3: The controller IP address was changed.

Check whether the peer IP address configured in the Callhome view is the same as the actual controller IP address.

Cause 4: Obtaining the SSH or NETCONF connection setup result timed out.

Check whether the SSH or NETCONF session status is normal.

Cause 5: Failed to set up a NETCONF connection.

Check whether the NETCONF session status is normal.

Cause 6: The NETCONF connection was torn down.

Check the NETCONF configuration and session status.

Cause 7: The controller failed to verify device information.

Locate the fault based on the reason information.

1. Check whether the device ESN has been imported to the controller.

2. If the ESN has been imported, check whether the imported ESN is correct.

3. Check whether the controller authorizes the device.

4. Check whether the device type matches the ESN rule.

Cause 8: Failed to set up an SSH connection.

Rectify the fault based on the reason information.
