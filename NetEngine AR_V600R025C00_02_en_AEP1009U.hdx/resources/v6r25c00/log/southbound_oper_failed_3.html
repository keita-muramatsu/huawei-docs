NETCONFC/3/SOUTHBOUND_OPER_FAILED

Message

NETCONFC/3/SOUTHBOUND_OPER_FAILED: Failed to configure access point. (User-name=[user-name], Source-address=[source-address], Dest-address=[dest-address], Session-id=[session-id], APId=[APId], MsgID = [MsgID], packCount= [packCount], packSeq= [packSeq], app-name = [app-name], Operation=[operation], Reason=[reason])

Description

Failed to configure the access point.

Parameters

Parameter Name Parameter Meaning

user-name

User name of the current NETCONF session.

source-address

Source IP address of the current NETCONF session.

dest-address

Destination IP address of the current NETCONF session.

session-id

Session ID.

APId

Access point ID.

MsgID

Message ID.

packCount

Number of fragments.

packSeq

Sequence number of a fragment.

app-name

Service name.

operation

User operation and its parameters.

reason

Cause of the access point configuration failure.

  • AP configuration failed: The access point configuration fails to be executed.

Possible Causes

Failed to configure the access point.

Procedure

  • Re-deliver the configuration or check whether the configuration is mutually exclusive and dependent. For details, contact technical support personnel.
