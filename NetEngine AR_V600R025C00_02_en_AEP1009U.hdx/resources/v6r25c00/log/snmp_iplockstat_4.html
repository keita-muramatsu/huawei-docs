SNMP/4/SNMP_IPLOCKSTAT

Message

SNMP/4/SNMP_IPLOCKSTAT: In the last 5 minutes, [NUM] IP addresses were locked. (IPList=[IPList])

Description

The list of IP addresses locked in the last 5 minutes was recorded.

Parameters

Parameter Name Parameter Meaning

NUM

Number of locked IP addresses.

IPList

List of locked IP addresses. If a large number of locked IP addresses cannot be completely displayed in one log, they are displayed in multiple logs.

Possible Causes

When the number of locked IP addresses exceeds three, locking logs are not separately recorded for newly locked IP addresses. Instead, a combined log is recorded every 5 minutes. The list of IP addresses locked within 5 minutes is recorded in the combined log.

Procedure

1. Check whether the community string corresponding to the source IP address or the SNMPv3 user name and password are correct.

2. Check whether the source IP address in the IP address list recorded in the log is valid.
