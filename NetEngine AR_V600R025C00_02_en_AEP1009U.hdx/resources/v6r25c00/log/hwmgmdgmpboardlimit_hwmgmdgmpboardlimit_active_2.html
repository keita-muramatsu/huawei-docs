IGMP/2/hwMgmdGMPBoardLimit_active

Message

IGMP/2/hwMgmdGMPBoardLimit_active: Membership report message is discarded because the IGMP or MLD group membership limitation on the board is exceeded. (AddressFamily=[AddressFamily], SlotName=[SlotName], LimitCount=[LimitCount])

Description

The IGMP/MLD Report message was discarded because the number of IGMP/MLD group memberships exceeded the upper limit.

Parameters

Parameter Name Parameter Meaning

AddressFamily

Address family:

  • 1: IPv4 address family.
  • 2: IPv6 address family.

SlotName

Slot name of a board.

LimitCount

Maximum number of IGMP/MLD entries allowed on a board.

Possible Causes

Entry create

Procedure

  • This message is informational only, and no action is required.
