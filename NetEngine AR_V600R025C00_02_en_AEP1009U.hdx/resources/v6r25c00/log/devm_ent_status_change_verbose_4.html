DRIVER/4/DEVM_ENT_STATUS_CHANGE_VERBOSE

Message

DRIVER/4/DEVM_ENT_STATUS_CHANGE_VERBOSE: Entity status has changed. (EntityName=[EntityName],Position=[Position],EntityType=[EntityType],Status=[Status],Esn=[Esn],Model=[Model],OnlineState=[OnlineState],RegisterState=[RegisterState],PowerState=[PowerState],Role=[Role],Event=[Event])

Description

Detailed information about the physical entity status change event.

Parameters

Parameter Name Parameter Meaning

EntityName

Name of a physical entity.

Position

Location

EntityType

Entity type

Status

Alarm status

Esn

Electronic label No.

Model

Electronic label type

OnlineState

Online status

RegisterState

Registration status

PowerState

Power supply status

Role

Active/standby role

Event

Triggering event

Possible Causes

The status of the physical entity changed.

Procedure

This is an event notification and does not affect service functions. No action is required.
