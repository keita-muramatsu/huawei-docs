LACP/3/OPTICAL_FIBER_MISCONNECT

Message

LACP/3/OPTICAL_FIBER_MISCONNECT: The member of the LACP mode Eth-Trunk interface received an abnormal LACPDU, which may be caused by optical fiber misconnection or changed packet. (TrunkName=Eth-trunk[TrunkId], PortName=[PortName], LocalSysPri=[LocalSysPri], PDUSysPri=[PDUSysPri], LocalSysId=[LocalSysId], PDUSysId=[PDUSysId], LocalPortKey=[LocalPortKey], PDUPortKey=[PDUPortKey], LocalPortPri=[LocalPortPri], PDUPortPri=[PDUPortPri], LocalPortNumber=[LocalPortNumber], PDUPortNumber=[PDUPortNumber], LocalPortState=[LocalPortState], PDUPortState=[PDUPortState])

Description

The parameters carried in an LACPDU received by the member interface of an Eth-Trunk interface in static LACP mode differed from those saved on the member interface.

Parameters

Parameter Name Parameter Meaning

TrunkId

Name of an Eth-Trunk interface in static LACP mode

PortName

Name of the member interface of the Eth-Trunk interface in static LACP mode

LocalSysPri

Local system priority

PDUSysPri

Local system priority in the received LACPDU

LocalSysId

Local system MAC address

PDUSysId

Local system MAC address in the received LACPDU

LocalPortKey

Local interface key value

PDUPortKey

Local interface key value in the received LACPDU

LocalPortPri

Local interface priority

PDUPortPri

Local interface priority in the received LACPDU

LocalPortNumber

Local port number

PDUPortNumber

Local port number in the received LACPDU

LocalPortState

Local interface status

PDUPortState

Local interface status in the received LACPDU

Possible Causes

The optical fiber was incorrectly connected or the LACPDU was changed.

Procedure

1. Check whether the interface information in the log is the same as that in the LACPDU.

  • If they are the same, go to Step 3.
  • If they are different, go to Step 2.

2. Connect the optical fiber correctly between Eth-Trunk member interfaces.

3. Collect log information and configuration information, and then contact technical support personnel.
