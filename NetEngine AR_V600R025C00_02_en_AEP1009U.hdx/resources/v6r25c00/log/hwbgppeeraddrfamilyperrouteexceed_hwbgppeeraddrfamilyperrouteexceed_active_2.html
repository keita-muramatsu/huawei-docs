BGP/2/hwBgpPeerAddrFamilyPerRouteExceed_active

Message

BGP/2/hwBgpPeerAddrFamilyPerRouteExceed_active: The routes number of the specified type received from peers in a BGP address family reached the maximum value. (Address Family=[AddressFamily], RouteType=[RouteType], MaxRouteNumber=[RouteLimitNum], BGP instance name=[InstanceName])

Description

The routes number of the specified type received from peers in a BGP address family reached the maximum value.

Parameters

Parameter Name Parameter Meaning

AddressFamily

Address family.

RouteType

Route type.

RouteLimitNum

The maximum route number.

InstanceName

BGP instance name. "-" indicates the default BGP instance, and other values indicate multiple instances.

Possible Causes

The routes number of the specified type received from peers in a BGP address family reached the maximum value.

Procedure

1. Reduce the routes number of specified type sent by the peer end. Then, check whether the alarm is cleared. That is, check whether the matching clear alarm (hwBgpPeerAddrFamilyPerRouteExceedClear) is generated. - If the clear alarm is generated, go to Step 3. - If the clear alarm is not generated, go to Step 2. 2. Collect alarm information and configuration information, and then contact technical support personnel. 3. End.
