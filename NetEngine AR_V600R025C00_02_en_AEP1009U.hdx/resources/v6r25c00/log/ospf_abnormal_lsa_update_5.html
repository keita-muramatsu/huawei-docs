OSPF/5/OSPF_ABNORMAL_LSA_UPDATE

Message

OSPF/5/OSPF_ABNORMAL_LSA_UPDATE: LSAs change frequently now. (ProcessId=[ProcessId], AdvertiseRouterId=[AdvertiseRouterId], TotalCount=[TotalCount], BeginTime=[BeginTime], EndTime=[EndTime], RouterLsaCount=[RouterLsaCount], NetworkLsaCount=[NetworkLsaCount], S-NetLsaCount=[S-NetLsaCount], S-ASBRLsaCount=[S-ASBRLsaCount], Type-7LsaCount=[Type7LsaCount], Opq-9LsaCount=[Opq-9LsaCount], Opq-10LsaCount=[Opq-10LsaCount])

Description

LSAs were updated frequently.

Parameters

Parameter Name Parameter Meaning

ProcessId

OSPF process ID.

AdvertiseRouterId

Advertising device.

TotalCount

Total number of LSAs.

BeginTime

Time when counters were set.

EndTime

Time when counters were stopped.

RouterLsaCount

Count of Type 1 LSAs.

NetworkLsaCount

Count of Type 2 LSAs.

S-NetLsaCount

Count of Type 3 LSAs.

S-ASBRLsaCount

Count of Type 4 LSAs.

Type7LsaCount

Count of Type 7 LSAs.

Opq-9LsaCount

Count of Type 9 LSAs.

Opq-10LsaCount

Count of Type 10 LSAs.

Possible Causes

The device counts the number of updated LSAs (excluding ASE LSAs and Type 11 LSAs) by the node that advertised the LSAs. The device outputs historical records every hour and selects the top 10 LSAs that were most frequently updated. If the total number of updated LSAs exceeds 100, this log is generated.

Procedure

  • This log message is informational only, and no action is required.
