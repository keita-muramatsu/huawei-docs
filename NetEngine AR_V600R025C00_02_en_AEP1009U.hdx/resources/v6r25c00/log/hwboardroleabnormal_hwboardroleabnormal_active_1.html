SYSTEM/1/hwBoardRoleAbnormal_active

Message

SYSTEM/1/hwBoardRoleAbnormal_active: The board hardware is faulty, and the active/standby role is abnormal. (Physical index=[PhysicalIndex], Entity name=[PhysicalName])

Description

The board hardware is faulty, and the active/standby role is abnormal.

Parameters

Parameter Name Parameter Meaning

PhysicalIndex

Physical index.

PhysicalName

Entity name.

Possible Causes

1. The board hardware is faulty.

2. The board is not securely inserted or in poor contact.

Procedure

1. Restart the board whose hardware active/standby role is abnormal. You can view the ID of the board to be restarted in the alarm description. After the board is started, wait for 60s and check whether the alarm is generated again.

  • If so, go to Step 2.
  • If not, go to Step 6.

2. Restart the device. After the device is started, wait for 60s and check whether the alarm is generated again.

  • If so, go to Step 3.
  • If not, go to Step 6.

3. Replace the board whose hardware active/standby role is abnormal and check whether the alarm is generated again.

  • If so, go to Step 4.
  • If not, go to Step 6.

4. Replace the board with another main control board and check whether the alarm is generated again.

  • If so, go to Step 5.
  • If not, go to Step 6.

5. Collect alarms and logs, and contact technical support engineers.

6. End.
