SUM/4/hwSmartUpgradeUserDataRetentionPeriodHasExpired_active

Message

SUM/4/hwSmartUpgradeUserDataRetentionPeriodHasExpired_active: Your personal information has expired, if you continue to accept the results of the smart upgrade, please re-enter the phone and email.

Description

The retention period of the intelligent update user data has expired.

Parameters

None

Possible Causes

The retention period of user data has expired.

Procedure

1. Run the information telephone command to reconfigure the phone number and email address. Then check whether the alarm is cleared.

· If so, go to Step 3.

· If not, go to Step 2.

2. Collect alarm, log, and configuration information, and contact technical support personnel.

3. End.
