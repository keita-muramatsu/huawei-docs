WLAN/2/hwApNumReachMaxTrap_active

Message

WLAN/2/hwApNumReachMaxTrap_active: The number of online APs reaches the maximum specifications.

Description

The number of online APs reached the maximum specifications.

Parameters

None

Possible Causes

The number of online APs reaches the maximum specification.

Procedure

1. Determine whether the WAC capacity needs to be expanded based on the number of connected APs.

  • If so, go to Step 2.
  • If not, no action is required. Go to Step 4.

2. Replace the WAC with a WAC model that supports a larger number of APs. Then, check whether the alarm persists.

  • If so, go to Step 3.
  • If not, go to Step 4.

3. Collect trap, log, and configuration information, and contact technical support.

4. End.
