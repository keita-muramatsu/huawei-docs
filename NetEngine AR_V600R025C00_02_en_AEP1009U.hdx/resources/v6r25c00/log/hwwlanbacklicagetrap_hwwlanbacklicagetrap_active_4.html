WLAN/4/hwWlanBackLicAgeTrap_active

Message

WLAN/4/hwWlanBackLicAgeTrap_active: Backup license is aging. (ACMAC=[ACMAC], Backup license number=[BackupLicenseNumber], Origin=[Origin], Last backup time=[LastBackupTime])

Description

Backup licenses aged out.

Parameters

Parameter Name Parameter Meaning

ACMAC

MAC address of the AC.

BackupLicenseNumber

Number of backup licenses.

Origin

Source of the backup license.

LastBackupTime

Last backup time.

Possible Causes

Cause 1: The link between the active and standby ACs is disconnected in the VRRP networking.

Cause 2: No AP is online on the backup AC in the dual-link or N+1 networking.

Procedure

1. Determine the current networking type.

  • If VRRP networking is used, go to Step 2.
  • If dual-link or N+1 networking is used, go to Step 3.

2. If the current networking is VRRP, perform the following operations:

a. Check whether VRRP is correctly configured on the master and backup ACs.

b. Check whether the VRRP channel is normal.

3. If the current network is a dual-link or N+1 network, perform the following operations:

  • Check whether the dual-link or N+1 configuration is complete.
  • Check whether there are online APs on the standby AC. If an AP is online on the standby AC, check whether the network between the AP and the current AC is normal.

4. Collect alarm, log, and configuration information, and contact technical support personnel.

5. End.
