DEVM/3/hwDeviceReboot_active

Message

DEVM/3/hwDeviceReboot_active: The device has been reset. (PhysicalName=[PhysicalName], ResetInfo=[ResetInfo])

Description

The device restarts. (This alarm is reported only when the device is registered with the controller.)

Parameters

Parameter Name Parameter Meaning

PhysicalName

Physical information about a device.

ResetInfo

Device restart information.

Possible Causes

This alarm is generated after a device restarts or an active/standby switchover is performed and the device registers with the controller.

Procedure

1. Check whether the device restarts properly.

  • If the restart information is "Reboot board from command", the device is restarted normally.
  • If the restart information is not "Reboot board from command", the device restarts unexpectedly. Go to step 2.

2. Collect alarm, log, and configuration information, and contact technical support.
