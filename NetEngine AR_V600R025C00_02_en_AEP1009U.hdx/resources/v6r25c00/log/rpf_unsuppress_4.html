PIM/4/RPF_UNSUPPRESS

Message

PIM/4/RPF_UNSUPPRESS: In the VPN instance '[vpn-instance-name]', the rpf route to source ([source-address]) process was unsuppressed,and CpuUsage = [CpuUsage].

Description

The RPF route to the multicast source is unsuppressed.

Parameters

Parameter Name Parameter Meaning

vpn-instance-name

VPN instance name.

source-address

source address.

CpuUsage

CPU usage.

Possible Causes

The route does not change frequently.

Procedure

This log message indicates a normal situation, and no action is required.
