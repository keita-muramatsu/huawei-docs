OSPFV3/3/OSPFV3_NBR_DOWN_REASON

Message

OSPFV3/3/OSPFV3_NBR_DOWN_REASON: Neighbor state left full or changed to Down. (ProcessId=[ProcessId], NeighborRouterId=[NbrRouterId], NeighborIp=[NbrIp], NeighborAreaId=[NbrAreaId], NeighborInterface=[IfName], NeighborDownImmediate reason=[NbrImmReason], NeighborDownPrimeReason=[NbrPriReason], CpuUsage=[CpuUsage], VpnName=[VPNName], InterfaceMTU=[IfMTU], LocalIp=[LocalIp],SystemInfo=[SystemInfo])

Description

Neighbor state leaves full or changed to Down.

Parameters

Parameter Name Parameter Meaning

ProcessId

Indicates OSPFv3 process ID.

NbrRouterId

Indicates neighbor router id.

NbrIp

Indicates neighbor ip address.

NbrAreaId

Indicates neighbor area id.

IfName

Indicates interface name.

NbrImmReason

Indicates immediate reason for neighbor down.

NbrPriReason

Indicates primary reason for neighbor down.

CpuUsage

CPU usage.

VPNName

VPN instance name.

IfMTU

Interface MTU.

LocalIp

Local interface ip address.

SystemInfo

System information

Possible Causes

Neighbor state change because OSPFv3 packet impact or some action impact.

Procedure

  • This log message is informational only, and no action is required.
