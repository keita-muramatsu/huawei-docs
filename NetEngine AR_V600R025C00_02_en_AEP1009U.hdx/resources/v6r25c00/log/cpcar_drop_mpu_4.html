CPUDEFEND/4/CPCAR_DROP_MPU

Message

CPUDEFEND/4/CPCAR_DROP_MPU: Rate of packets to cpu exceeded the CPCAR limit on the MPU. (Protocol=[Protocol], PPS/CBS=[CIR]/[CBS], ExceededPacketCount=[ExceededPacketCount])

Description

The rate of packets sent to the CPU exceeds the CPCAR limit.

Parameters

Parameter Name Parameter Meaning

Protocol

Protocol type.

CIR

Committed information rate (CIR).

CBS

Committed burst size (CBS).

ExceededPacketCount

Number of excess packets.

Possible Causes

The rate of packets sent to the CPU exceeds the CPCAR limit. As a result, some packets are discarded.

Procedure

Limit the rate of packets sent to the CPU within the CPCAR limit or run the car packet-type command to set proper CPCAR values.
