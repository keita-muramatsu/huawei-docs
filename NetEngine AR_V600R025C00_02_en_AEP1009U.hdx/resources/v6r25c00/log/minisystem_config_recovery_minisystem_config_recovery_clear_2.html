CFG/2/MINISYSTEM_CONFIG_RECOVERY_clear

Message

CFG/2/MINISYSTEM_CONFIG_RECOVERY_clear: The system does not restore based on the minimum system configuration.

Parameters

None

Possible Causes

The device does not restart with the minimum system configuration.

Procedure

This trap message is informational only, and no action is required.
