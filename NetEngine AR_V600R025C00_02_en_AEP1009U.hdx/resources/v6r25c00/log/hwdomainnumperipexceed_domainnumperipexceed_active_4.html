POLICY/4/hwDomainNumPerIpExceed_active

Message

POLICY/4/hwDomainNumPerIpExceed_active: There are multiple domain names corresponding to the same IP address, which exceeds the threshold of domain names specification supported by the policy. (Vsys=[hwDomainSetVsysId], IP=[hwDomainSetIp], current=[hwDomainCurNumPerIp], max=[hwDomainMaxNumPerIp], threshold=[hwDomainSetThreshold])

Description

Multiple domain names correspond to the same IP address and the alarm threshold is exceeded.

Parameters

Parameter Name Parameter Meaning

hwDomainSetVsysId

Virtual system ID

hwDomainSetIp

IP address

hwDomainCurNumPerIp

Number of domain names corresponding to the same IP address.

hwDomainMaxNumPerIp

Maximum number of domain names corresponding to the same IP address when a policy references a domain group for matching.

hwDomainSetThreshold

Alarm threshold.

Possible Causes

There are multiple domain names corresponding to the same IP address, which exceeds the threshold of domain names specification supported by the policy.

Procedure

Analyze the mapping between IP addresses and domain names on the device and clear the domain name-IP address mapping entries that have low priorities or have expired.
