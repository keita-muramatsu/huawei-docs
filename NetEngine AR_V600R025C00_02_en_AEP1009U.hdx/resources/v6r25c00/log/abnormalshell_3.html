HIPS/3/ABNORMALSHELL

Message

HIPS/3/ABNORMALSHELL: The abnormal shell behavior has been detected. (eventCategory=[event-category], eventType=[event-type], level=[level], occurTime=[occur-time], result=[result], path=[shell-path], operationType=[operation-type], cmdline=[cmdline], type=[attribute-type], from=[old-attribute], to=[new-attribute], slot=[slot], card=[card], cpu=[cpu], barcode=[barcode])

Description

Abnormal shell behavior is detected. After intruding the system, an attacker may tamper with and copy the existing shell of the device to bypass the security detection system on the device before establishing a reverse shell so as to facilitate the establishment of a reverse shell control channel.

Parameters

Parameter Name Parameter Meaning

event-category

Event category:

1016: NE intrusion alarm

event-type

Event type. The options are as follows:

  • Shell file tampering

level

Event level.

occur-time

Event date.

result

Operation Result

shell-path

Shell file path.

operation-type

Operation Type

cmdline

Command line.

attribute-type

Attribute change type.

old-attribute

Old attribute.

new-attribute

New attribute.

slot

Slot ID

card

Subcard ID.

cpu

CPU ID.

barcode

Board uniquely identified by the barcode.

Possible Causes

Abnormal shell behaviors occur, such as shell copy, shell file attribute modification, and shell file content modification.

Procedure

Isolate the device from the network immediately and submit log information to Huawei engineers for analysis.
