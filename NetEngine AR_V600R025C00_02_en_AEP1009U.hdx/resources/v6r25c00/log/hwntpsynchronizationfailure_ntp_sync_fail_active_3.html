NTP/3/hwNtpSynchronizationFailure_active

Message

NTP/3/hwNtpSynchronizationFailure_active: NTP synchronization state changed. (State = [state], SynchronizationSourceAddress = [source])

Description

NTP time synchronization fails.

Parameters

Parameter Name Parameter Meaning

state

NTP state

source

Synchronization source

Possible Causes

  • Cause 1: Peer become unreachable.
  • Cause 2: Peer was deleated by configuration.
  • Cause 3: Peer went to unsynch state
  • Cause 4: Peer source is unslectable

Procedure

  • Cause 1: Peer become unreachable.

    1. Run the ping command to check whether the peer end is reachable.

    • Y=>3.
    • N=>2.

    2. Configure the route correctly, and check whether the alarm is cleared.

    • Y=>4.
    • N=>3.

    3. Collect alarm, log, and configuration information, and contact technical support personnel.

    4. End.

  • Cause 2: Peer was deleated by configuration.

    1. Check whether the peer configuration on the local device is correct.

    • Y=>3.
    • N=>2.

    2. Reconfigure the associated peer configuration on the device and check whether the alarm is cleared.

    • Y=>4.
    • N=>3.

    3. Collect alarm, log, and configuration information, and contact technical support personnel.

    4. the procedure ends.

  • Cause 3: Peer went to unsynch state

    1. Check whether the peer clock is in the synchronized state.

    • Y=>3.
    • N=>2.

    2. Set the peer clock status to synchronized, and check whether the alarm is cleared.

    • Y=>4.
    • N=>3.

    3. Collect alarm, log, and configuration information, and contact technical support personnel.

    4. End.

  • Cause 4: Peer source is unslectable

    1. Check whether the offset, delay, and precision of the peer clock source are within the acceptable range.

    • Y=>3.
    • N=>2.

    2. Reconfigure the offset of the peer clock source. Ensure that the delay and precision are within the acceptable range. Then, check whether the alarm is cleared.

    • Y=>4.
    • N=>3.

    3. Collect alarm, log, and configuration information, and contact technical support personnel.

    4. End.
