BGP/4/hwBgpPacketSendFailed_clear

Message

BGP/4/hwBgpPacketSendFailed_clear: The alarm indicating that the BGP peer cannot send packets for a long time is cleared. (BGP instance=[InstanceName], VPN instance=[VpnInstance], BgpPeerRemoteAddr=[PeerAddress], InterfaceName=[InterfaceName])

Parameters

Parameter Name Parameter Meaning

InstanceName

BGP instance name: "-" indicates the default BGP instance, and other values indicate multiple instances.

VpnInstance

Name of a VPN instance.

PeerAddress

Peer address.

InterfaceName

Name of the local interface.

Possible Causes

  • Cause 1:The BGP peer relationship is interrupted
  • Cause 2:Update or Keepalve messages are sent successfully
  • Cause 3:The timer send-hold 0 or peer {Ipv4Address | Ipv6Address} timer send-hold 0 command is run

Procedure

  • Cause 1:The BGP peer relationship is interrupted

    1. Check whether the hwBgpBackwardTransition or hwBgpUnnumberedBackwardTransition alarm is generated.

    • If yes, go to Step 3.
    • If no, go to step 2.

    2. Collect alarm and configuration information, and contact technical support personnel.

    3. End.

  • Cause 2:Update or Keepalve messages are sent successfully

    This message is informational only, and no action is required.

  • Cause 3:The timer send-hold 0 or peer {Ipv4Address | Ipv6Address} timer send-hold 0 command is run

    This message is informational only, and no action is required.
