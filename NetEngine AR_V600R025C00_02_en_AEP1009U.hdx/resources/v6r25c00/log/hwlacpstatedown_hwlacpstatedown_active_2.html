LACP/2/hwLacpStateDown_active

Message

LACP/2/hwLacpStateDown_active: The LACP status of the member port changes to down. (TrunkIndex=[TrunkIndex],PortIfIndex=[PortIfIndex],TrunkId=[TrunkId],TrunkName=[TrunkName],PortName=[PortName],Reason=[ReasonCode])

Description

The LACP status of the member interface is Down.

Parameters

Parameter Name Parameter Meaning

TrunkIndex

Trunk index

PortIfIndex

Index of a member port

TrunkId

Trunk interface ID

TrunkName

Trunk interface name

PortName

Member Port Name

ReasonCode

Cause of the alarm

Possible Causes

  • Cause 1: LACP negotiation fails.

Procedure

  • Cause 1: LACP negotiation fails.

    1. Run the display this command in the interface view to check whether the interfaces at both ends are shut down.

    • If the interface is shut down, run the undo shutdown command to enable the interface. Then, check whether the alarm is cleared. If the alarm persists, go to Step 2.
    • If the interface is not shut down, go to Step 2.

    2. Check whether the physical connection is normal. For example, check whether the network cable or optical module is loose or disconnected.

    • If the physical link is abnormal, reconnect the physical link and check whether the alarm is cleared. If the alarm persists, go to Step 3.
    • If the physical link is working properly, go to Step 3.

    3. Run the display interface eth-trunk command in the system view to check whether an interface on the local or peer device is removed from the Eth-Trunk.

    • If the interface is removed from the Eth-Trunk abnormally, run the eth-trunk command in the member interface view or run the trunkport command in the Eth-Trunk interface view to add the interface to the Eth-Trunk again. Then, check whether the alarm is cleared. If the alarm persists, go to Step 4.
    • If the interface is removed from the Eth-Trunk, go to step 4.

    4. Collect alarm, log, and configuration information, and contact technical support personnel.
