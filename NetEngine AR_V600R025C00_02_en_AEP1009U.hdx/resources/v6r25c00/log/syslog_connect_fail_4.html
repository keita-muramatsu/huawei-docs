INFO/4/SYSLOG_CONNECT_FAIL

Message

INFO/4/SYSLOG_CONNECT_FAIL: Failed to connect the loghost over TLS. (PeerIP=[PeerIP], FailReason=[FailReason], SocketHandle=[SocketHandle], VpnName=[VpnName])

Description

The Syslog server fails to connect to the peer end.

Parameters

Parameter Name Parameter Meaning

PeerIP

Peer IP address.

FailReason

Failure cause.

SocketHandle

Handle used by the socket connection.

VpnName

VPN name.

Possible Causes

Cause 1: The certificate signature uses the DSA or ECDSA algorithm, but the signature is incorrect.

Cause 2: The algorithm in the Hello message received by the client from the server cannot be identified.

Cause 3: The peer end sends an incorrect packet.

Cause 4: The content in the extension field is not supported.

Procedure

Cause 1:

Check whether the certificate is normal and whether the signature is tampered with.

Cause 2:

Check whether the client supports the algorithm selected by the server.

Cause 3:

Ensure that the contents sent by the peer end are correct.

Cause 4:

This message is informational only, and no action is required.

Other causes:

Collect alarm, log, and configuration information, and contact technical support personnel.
