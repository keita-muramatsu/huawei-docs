ISIS/6/ISIS_BFD_SYNC_STATE_CHANGE

Message

ISIS/6/ISIS_BFD_SYNC_STATE_CHANGE: The BFD incr-cost state of the interface in IS-IS [InstanceID] changed. (IfName=[IfName], Level=[Level], MTID=[MtId], AddressFamily=[AddressFamily], Sync-state=[SyncState], ChangeReason=[ChangeReason])

Description

The IS-IS interface entered or exited the BFD association state.

Parameters

Parameter Name Parameter Meaning

InstanceID

IS-IS process ID

IfName

Indicates the interface name.

Level

Interface level.

MtId

Interface topology ID.

AddressFamily

Address family in the view for BMP to monitor a specific peer.

SyncState

Association status.

ChangeReason

Cause of the BFD association status change.

Possible Causes

An IS-IS interface enters the BFD association state due to the following reasons:

Cause 1: The BFD session went Down.

An IS-IS interface quits the BFD association state because of the following reasons:

Cause 1: The BFD session is Up.

Cause 2: The BFD session was deleted.

Cause 3: After the neighbor protocol went Down, the neighbor was deleted.

Cause 4: The BFD association configuration was deleted.

Cause 5: The IS-IS neighbor status changed from one to multiple.

Cause 6: The interface went Down.

Procedure

1. This log message is informational only, and no action is required.
