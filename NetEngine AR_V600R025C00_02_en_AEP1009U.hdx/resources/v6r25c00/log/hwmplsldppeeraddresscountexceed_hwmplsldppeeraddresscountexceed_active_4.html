LDP/4/hwMplsLdpPeerAddressCountExceed_active

Message

LDP/4/hwMplsLdpPeerAddressCountExceed_active: The peer address count reaches the upper limit. (PeerLsrId=[PeerLsrId], VrfName=[VrfName], AddressTotalCount=[AddressTotalCount])

Description

When the number of address messages received by a single peer exceeds the upper limit, an alarm is generated, indicating that the number of addresses received by the system exceeds the upper limit. In this case, you need to limit the number of addresses to prevent services from being affected.

Parameters

Parameter Name Parameter Meaning

PeerLsrId

LDP peer ID

VrfName

Index of the VRF to which the LDP peer belongs

AddressTotalCount

Number of addresses supported by the system

Possible Causes

The number of peer address has reached the upper limit.

Procedure

1. You can modify the configuration to reduce unnecessary LDP-enabled interfaces on the peer interface to prevent services from being affected.

  • If the alarm is cleared, go to Step 3.
  • If the alarm persists, go to Step 2.

2. Collect alarm and configuration information, and contact technical support personnel.

3. End.
