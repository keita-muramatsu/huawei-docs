CM/5/USER_OFFLINERESULT

Message

CM/5/USER_OFFLINERESULT: USER_INFO_OFFLINE. ([userInfo])

Description

The user goes offline.

Parameters

Parameter Name Parameter Meaning

userInfo

USER_INFO_OFFLINE: A user goes offline.

DEVICEMAC/ACMAC: device MAC address.

DEVICENAME/ACNAME: device name.

USER: user name. Only letters, digits, and special characters can be displayed for the user name.

MAC: user MAC address.

IPADDRESS/IpAddress: user IPv4 address.

Ipv6Address: user IPv6 address.

TIME: system time.

ZONE: time zone.

DAYLIGHT: whether the DST is used.

SESSIONTIME: online duration of a user.

ERRCODE: error code indicating that a user is offline.

RESULT: user offline result.

AUTHENPLACE: user authentication location.

CIBID: CIB ID.

EXTENDINFO: signal strength of offline users.

INTERFACE: access interface.

ACCESS TYPE: access type. If the user fails to go online, the access type is recorded as None.

VPNNAME: VPN name of a user.

Portal TYPE: Portal authentication type.

SelectRDSIP: RADIUS server that fails to authenticate users. It indicates the IP address of the intermediate RADIUS server (which has been selected but not in use). The value - indicates that the authentication mode is not RADIUS or no intermediate RADIUS server is available.

SeclectERRCODE: error code of a RADIUS server that fails to authenticate users. It indicates the reason why the intermediate RADIUS server is not used. The value - indicates that the authentication mode is not RADIUS or only one RADIUS server is available. Otherwise, the value is 205.

RDSIP: IP address of the RADIUS server.

AUTHID: ID of the user in the log sent to the analyzer.

Possible Causes

The user goes offline.

Procedure

If the user goes offline unexpectedly, locate the fault according to the cause or contact technical support. If the user goes offline normally, no action is required.
