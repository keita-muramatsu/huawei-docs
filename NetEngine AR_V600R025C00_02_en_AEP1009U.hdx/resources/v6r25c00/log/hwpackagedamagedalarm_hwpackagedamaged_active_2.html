PKGM/2/hwPackageDamagedAlarm_active

Message

PKGM/2/hwPackageDamagedAlarm_active: The software package is damaged. (PhysicalName=[PhysicalName],PackageName=[PackageName])

Description

The software package was damaged.

Parameters

Parameter Name Parameter Meaning

PhysicalName

Entity name.

PackageName

Software package name

Possible Causes

  • Cause 1: The storage medium is faulty, causing a damage to the software package.
  • Cause 2: The storage medium is faulty, causing a damage to the software package.

Procedure

  • Cause 1: The storage medium is faulty, causing a damage to the software package.

    1. Determine whether the software package of the master or slave main control board is damaged based on PhysicalName and PhysicalIndex in the alarm.

    • If the software package of the master main control board is damaged, go to Step 3.
    • If the software package of the slave main control board is damaged, go to Step 2.

    2. Run the reset slot <slot-id> command to reset the slave main control board. After the slave main control board is reset, the damaged software package is automatically repaired. Check whether the alarm is cleared.

    • If so, go to Step 5.
    • If not, go to Step 4.

    3. Run the slave switchover command to perform an active/standby switchover. The original master main control board synchronizes the software package from the new master main control board to repair the damaged software package. Then check whether the alarm is cleared.

    • If so, go to Step 5.
    • If not, go to Step 4.

    4. Collect alarm, log, and configuration information, and contact technical support personnel.

    5. End.

  • Cause 2: The storage medium is faulty, causing a damage to the software package.

    1. Run the reboot command to restart the device. After the device is restarted, check whether the alarm is cleared.

    • If so, go to Step 3.
    • If not, go to Step 2.

    2. Collect alarm and log information, and contact technical support personnel.

    3. End.
