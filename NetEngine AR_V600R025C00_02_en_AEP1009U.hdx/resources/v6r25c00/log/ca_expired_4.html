PKI/4/CA_EXPIRED

Message

PKI/4/CA_EXPIRED: CA certificate ([subject_name]) has expired for [day] days.

Description

The CA certificate has expired.

Parameters

Parameter Name Parameter Meaning

subject_name

Subject name of the CA certificate.

day

Number of days after the CA certificate expires.

Possible Causes

  • Failed to automatically update the certificate.
  • The certificate is not manually updated.

Procedure

  • Applying for a certificate online using CMPv2
  • If the automatic certificate update function is configured, the device is automatically triggered to update the certificate through CMPv2 when the certificate is about to expire or has expired.

Ensure that the link between the device and the CA server is reachable, the PKI configuration is correct, and the CA server functions properly.

  • If the automatic certificate update function is not configured, you need to run the pki cmp keyupdate-request session command in the system view to manually update the certificate for CMPv2.

Ensure that the link between the device and the CA server is reachable, the PKI configuration is correct, and the CA server functions properly.

  • Applying for a certificate in offline mode

1. You need to send the certificate application file to the CA server through the web page, disk, or email to obtain the CA certificate and local certificate.

2. Run the pki delete-certificate command in the system view to delete the old CA and local certificates from the device memory.

3. Upload the obtained CA certificate and local certificate to the storage medium of the device through SFTP or other methods, and run the pki import-certificate command in the system view to import the CA certificate and local certificate to the memory of the device.
