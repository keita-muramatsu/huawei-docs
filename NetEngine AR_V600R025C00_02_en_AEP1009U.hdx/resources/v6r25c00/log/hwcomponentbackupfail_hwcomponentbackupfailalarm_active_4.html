SYSTEM/4/hwComponentBackupFail_active

Message

SYSTEM/4/hwComponentBackupFail_active: Data backup between the active and standby components failed. (ComponentName=[ComponentName], Process ID=[PID], Block ID=[BlockID])

This log is supported only on AR6700-H series, AR8700 series.

Description

HA notifies the application that the standby component goes online. After detecting the fault, the application backs up data between the active and standby components. If the backup fails, an alarm is reported.

Parameters

Parameter Name Parameter Meaning

ComponentName

Component Name

PID

Process ID

BlockID

Block ID

Possible Causes

Data backup between the active and standby components failed.

Procedure

1. Run the reset slot command to restart the slave main control board.

2. After the slave main control board is restarted, check whether the alarm is cleared.

  • If yes, go to Step 4.
  • If no, go to Step 3.

3. Collect alarm and configuration information, and contact technical support personnel.

4. End.
