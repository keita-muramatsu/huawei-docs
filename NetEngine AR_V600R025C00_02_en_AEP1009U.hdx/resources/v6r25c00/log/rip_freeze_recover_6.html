RIP/6/RIP_FREEZE_RECOVER

Message

RIP/6/RIP_FREEZE_RECOVER: The number of routes on RIP process [PROCESSID] reached below the threshold limit, and thus the process has recovered from the suspension state and resumed processing the packets.

Description

When the number of routes in a RIP process reached below the threshold limit, the RIP process has recovered from the suspension state and resumed processing packets.

Parameters

Parameter Name Parameter Meaning

PROCESSID

ID of a RIP process

Possible Causes

Cause 1: The number of routes in a RIP process reached below the threshold limit.

Procedure

1. This log message is informational only, and no action is required.
