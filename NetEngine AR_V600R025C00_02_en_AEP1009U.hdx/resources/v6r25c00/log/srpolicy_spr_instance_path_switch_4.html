SRPOLICY/4/SRPOLICY_SPR_INSTANCE_PATH_SWITCH

Message

SRPOLICY/4/SRPOLICY_SPR_INSTANCE_PATH_SWITCH: The SPR instance path changed. (InstanceEndpoint=[InstanceEndpoint],SprPolicyName=[SprPolicyName],PreviousSrPolicyColor=[PreviousSrPolicyColor],CurrentSrPolicyColor=[CurrentSrPolicyColor],SwitchReason=[SwitchReason])

Description

The path of the SPR instance changed.

Parameters

Parameter Name Parameter Meaning

InstanceEndpoint

Destination address of the SPR instance

SprPolicyName

SPR policy name

PreviousSrPolicyColor

Color of an SR Policy before a switchover

CurrentSrPolicyColor

Color of an SR Policy after switching

SwitchReason

Reason for switchover

Possible Causes

1. Configurations are changed. The original primary path does not exist in the new SPR policy.

2. The path status changes.

3. The path is switched.

4. Traffic is switched back to the original path.

5. Other causes.

Procedure

Check the reason why the path of the SPR instance is switched.
