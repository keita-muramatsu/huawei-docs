ISIS/3/IS_CFG_ERR

Message

ISIS/3/IS_CFG_ERR: ISIS-INFO: The component configuration failed. (Comp=[Comp], MsgType=[MsgType], OperCode=[OperCode], ClassId=[ClassId], ErrCode=[ErrCode], Reason=[Reason])

Description

The component failed to be configured.

Parameters

Parameter Name Parameter Meaning

Comp

Peer component name and ID

MsgType

Message type

OperCode

Operation code

ClassId

Class ID

ErrCode

Error code

Reason

Reason why the component failed to be configured

Possible Causes

Cause 1: Failed to apply for memory for a configuration response message.

Cause 2: Failed to parse a configuration message.

Cause 3: Failed to set a configuration response message.

Cause 4: Failed to send a configuration response message.

Procedure

Collect log information and configuration information, and then contact technical support personnel.
