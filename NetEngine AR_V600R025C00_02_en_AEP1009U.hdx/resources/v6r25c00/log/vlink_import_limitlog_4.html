RM/4/VLINK_IMPORT_LIMITLOG

Message

RM/4/VLINK_IMPORT_LIMITLOG: The number of the import vlink items exceeded the maximum number. (CurVlinkImportNumber=[CurNumber], Max VlinkImportNumber=[MaxNumber]).

Description

The number of Vlink routes imported between VPN and public network instances exceeded the maximum number.

Parameters

Parameter Name Parameter Meaning

CurNumber

Number of existing imported Vlink routes

MaxNumber

Maximum number of imported VLINK routes

Possible Causes

The number of imported Vlink routes exceeded the maximum number.

Procedure

1. Adjust the route-policy that controls Vlink route import between VPN and public network instances as required.

2. Delete unneeded configurations of Vlink route import between VPN and public network instances and check whether the problem persists.

  • If the problem persists, go to 3.
  • If the problem is resolved, go to 4.

3. Collect log information and configuration information, and then contact technical support personnel.

4. End.
