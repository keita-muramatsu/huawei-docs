UPDATE/3/CPU_FAIL

Message

UPDATE/3/CPU_FAIL: The signature database update failed. (SyslogId=[syslog-id], User=[username], IP=[ip-address], Module=[module], Slot=[slot-id], CPU=[cpu-id], Status=[status], Duration(s)=[duration], Reason=[reason], Suggestion=[suggestion])

Description

Failed to update the signature database.

Parameters

Parameter Name Parameter Meaning

syslog-id

Sequence number of a log.

username

Name of the user who performs the upgrade.

SystemTimer is displayed for scheduled upgrade. If the system fails to obtain the user name, ** is displayed.

ip-address

IP address of the user who performs the upgrade.

If the system fails to obtain the user IP address, "**" is displayed.

module

Module to be upgraded.

slot-id

ID of the slot where the engine resides.

cpu-id

ID of the CPU where the engine resides.

status

Upgrade mode. The value can be:

  • local-update: local update
  • rollback: version rollback
  • restore: restoration of the default version
  • apply: installation of the downloaded version

duration

Upgrade duration, in seconds.

reason

Cause of the signature database update failure. The value can be:

  • The engine is busy.
  • The update package is invalid.
  • The compilation failed.
  • The engine is in compilation.
  • The engine is abnormal.
  • The system memory is insufficient.

suggestion

Handling suggestion for the signature database update failure. The value can be:

  • Please check the engine status.
  • Download the upgrade file again again.
  • Use the valid SDB upgrade package.
  • Try again later.
  • Contact customer service engineers.
  • Try again later.

Possible Causes

The reason field in the log records the possible causes of this log.

Procedure

Rectify the fault as prompted. If the fault persists, contact technical support engineers.
