HPP/1/hwIPv6SessLeakEntryNumberThresholdExceed_clear

Message

HPP/1/hwIPv6SessLeakEntryNumberThresholdExceed_clear: The number of IPv6 session leak entries falls below the threshold. (Current entries=[hwSessionCurEntryNum], Leak entries=[hwSessionLeakEntryNum], Unrecoverable entries=[hwSessionUnrecEntryNum], Session specification=[hwSessionSpecification], Current usage=[hwSessionLeakUsage]%, Threshold=[hwSessionLeakThreshold]%)

Parameters

Parameter Name Parameter Meaning

hwSessionCurEntryNum

Number of current entries

hwSessionLeakEntryNum

Number of leaked entries

hwSessionUnrecEntryNum

Number of unrecoverable entries

hwSessionSpecification

Flow Table Specifications

hwSessionLeakUsage

Ratio of the number of leaked session entries to the maximum number of session entries

hwSessionLeakThreshold

Alarm threshold for leaked session entries

Possible Causes

The number of IPv6 session leak entries fell below the threshold.

Procedure

This message is informational only, and no action is required.
