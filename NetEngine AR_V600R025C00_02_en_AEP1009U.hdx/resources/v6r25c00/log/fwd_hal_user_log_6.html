FE/6/FWD_HAL_USER_LOG

Message

FE/6/FWD_HAL_USER_LOG: Description. (Slot=[SlotId], FE=[FeId], Module=[ModuleName], Description=[Str])

Description

Event-level user log information is recorded when the number of cause alarms increases sharply.

Parameters

Parameter Name Parameter Meaning

SlotId

Slot ID.

FeId

Chip ID

ModuleName

Module name

Str

Displayed string

Possible Causes

Event-level user log information is recorded when the number of cause alarms increases sharply.

Procedure

Analyze FeId and CauseId to determine the alarm type.
