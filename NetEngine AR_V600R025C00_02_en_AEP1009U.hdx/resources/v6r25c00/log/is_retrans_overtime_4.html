ISIS/4/IS_RETRANS_OVERTIME

Message

ISIS/4/IS_RETRANS_OVERTIME: ISIS-INFO: Send message over 3 times. (MsgType=[MsgType], MsgSubType=[MsgSubType], PeerComp=[PeerComp], LocalComp=[LocalComp], ProcessId=[ProcessId], RetransNum=[RetransNum])

Description

No response was received after three retransmissions.

Parameters

Parameter Name Parameter Meaning

MsgType

Message type

MsgSubType

Message sub-type

PeerComp

Peer component name and ID

LocalComp

Local component name and ID

ProcessId

Process ID, The value is 0 if the CU communication is not based on a process. Otherwise, the value is the process ID.

RetransNum

Number of retransmissions

Possible Causes

  • The message channel was busy, and as a result the message retransmitted for three times or the responses were all discarded.
  • The peer component did not respond for a long period of time.

Procedure

  • This log message is informational only, and no action is required.
