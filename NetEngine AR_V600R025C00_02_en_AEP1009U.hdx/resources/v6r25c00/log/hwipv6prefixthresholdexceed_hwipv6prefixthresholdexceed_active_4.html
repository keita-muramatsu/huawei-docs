RM/4/hwIpv6PrefixThresholdExceed_active

Message

RM/4/hwIpv6PrefixThresholdExceed_active: The number of IPv6 prefixes exceeded the threshold. (PrefixCount=[PrefixCount], MaxValue=[MaxValue], ThresholdLowerLimit=[ThresholdLowerLimit], ThresholdUpperLimit=[ThresholdUpperLimit])

Description

The number of IPv6 route prefixes exceeded the alarm threshold.

Parameters

Parameter Name Parameter Meaning

PrefixCount

Indicates the number of IPv6 route prefixes in the routing table.

MaxValue

Indicates the maximum number of IPv6 route prefixes supported by the device.

ThresholdLowerLimit

Indicates the lower threshold of IPv6 route prefixes.

ThresholdUpperLimit

Indicates the upper threshold of IPv6 route prefixes.

Possible Causes

The number of IPv6 prefixes exceeded the threshold of the routing table.

Procedure

1. Run the display current-configuration command to check whether the ipv6 prefix-limit system threshold-alarm command is run and the alarm threshold is too small.

  • If yes, go to Step 2.
  • If no, go to Step 3.

2. Run the ipv6 prefix-limit system threshold-alarm upper-limit <upper-limit-value> lower-limit <lower-limit-value> command to increase the value of <upper-limit-value>.

3. Run the display ipv6 routing-table statistics command to check the total number of IPv6 public network route prefixes and run the display ipv6 routing-table all-vpn-instance statistics command to check the total number of VPN route prefixes. In addition, check the number of routes that each routing protocol adds to each IPv6 routing table.

Determine whether the routes are required by services or are generated due to incorrect configurations.

  • If the routes are generated due to incorrect configurations, go to Step 4.
  • If the routes are required by services, go to Step 5.

4. Adjust the configurations to delete unnecessary routes so that the number of route prefixes falls below the lower-limit <lower-limit-value> configured using the ipv6 prefix-limit system threshold-alarm command, and then check whether the RM_1.3.6.1.4.1.2011.5.25.145.11.4 hwIpv6PrefixThresholdExceedClear alarm is generated.

  • If no, go to Step 5.
  • If yes, go to Step 6.

5. Collect alarm and configuration information, and contact technical support personnel.

6. End.
