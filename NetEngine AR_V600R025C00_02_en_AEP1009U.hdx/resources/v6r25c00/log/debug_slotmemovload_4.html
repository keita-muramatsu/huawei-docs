DEBUG/4/DEBUG_SLOTMEMOVLOAD

Message

DEBUG/4/DEBUG_SLOTMEMOVLOAD: The memory usage of board exceeded the threshold. (Usage=[Usage]%, Threshold=[Threshold]%)

Description

The card memory is overloaded.

Parameters

Parameter Name Parameter Meaning

Usage

Memory usage.

Threshold

Memory usage threshold.

Possible Causes

The memory usage is too high.

Procedure

1. Locate the cause of the high memory usage. If necessary, delete unnecessary services and configurations to reduce the memory usage. Check whether the log is generated.

  • If the log is not generated, the fault is rectified.
  • If the log persists, go to Step 2.

2. Collect log and configuration information, and contact technical support personnel.
