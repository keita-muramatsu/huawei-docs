POE/4/POECHIPFAULT

Message

POE/4/POECHIPFAULT: PoE chip fault. (SlotID=[SlotID], ChipID=[ChipID])

This log is supported only on AR5710-S52T2XE4, AR5710-S8T2X-LTE4EA, AR5710-S8T2X, AR5710-S8P2X, AR5710-S8T2S, AR5710-S10T1X2, AR5710-S8TWDSE-LTE4EA, AR5710-S28T2S2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE-NRGL, AR5710-S8T2XE-LTE4EA-T, AR5710-S8T1XWE, AR5710-S8T2XE.

Description

The PoE chip is faulty.

Parameters

Parameter Name Parameter Meaning

SlotID

Slot ID.

ChipID

Chip ID.

Possible Causes

The PoE chip is faulty.

Procedure

1. Run the reset poe {all chips | chip <chip-id>} slot <slot-id> command to reset the PoE chip and check whether the log message persists.

  • If yes, go to Step 2.
  • If no, no further action is required.

2. Collect log and configuration information, and contact technical support personnel. You can run the display diagnostic-information command to collect device diagnostic information.
