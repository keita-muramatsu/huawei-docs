VCMU/1/hwBrdTempFatalAlarm_active

Message

VCMU/1/hwBrdTempFatalAlarm_active: The board temperature exceeded the fatal alarm threshold. (EntPhysicalIndex=[EntPhysicalIndex], EntPhysicalName=[EntPhysicalName], EntityThresholdType=[EntityThresholdType], EntityThresholdCritical=[EntityThresholdCritical], EntityThresholdCurrent=[EntityThresholdCurrent], EntityTrapFaultID=[EntityTrapFaultID],Reason=[ReasonDsp])

Description

A major alarm was generated for the board or subcard temperature.

Parameters

Parameter Name Parameter Meaning

EntPhysicalIndex

Indicates the entity index.

EntPhysicalName

Entity

EntityThresholdType

Entity Threshold Type

EntityThresholdCritical

Entity temperature threshold

EntityThresholdCurrent

Current temperature.

EntityTrapFaultID

Fault ID

ReasonDsp

Possible cause of the alarm.

Possible Causes

  • Cause 1: The board temperature was extremely high.
  • Cause 2: The card temperature was extremely high.

Procedure

1. Check whether the air filter of the fan is blocked.

  • If so, clean the air filter.
  • If not, go to Step 2.

2. Check whether the ambient temperature is too high.

  • If so, lower the ambient temperature.
  • If not, go to step 3.

3. Check whether the fan is faulty.

  • If so, rectify the fan fault.
  • If not, go to Step 4.

4. Check whether filler panels are installed in vacant slots.

  • If so, go to Step 5.
  • If not, insert filler panels in vacant slots.

5. If an overtemperature alarm or historical alarm is generated, collect alarm, log, and configuration information, and contact technical support personnel.
