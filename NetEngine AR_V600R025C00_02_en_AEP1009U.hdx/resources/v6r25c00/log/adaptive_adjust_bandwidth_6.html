SDWAN-EVPN/6/ADAPTIVE_ADJUST_BANDWIDTH

Message

SDWAN-EVPN/6/ADAPTIVE_ADJUST_BANDWIDTH: The Connection [ConnectionID] has adjusted adaptive-qos bandwidth. (ShapeRate=[ShapeRate], Throughput=[Throughput], Adapt=[Adapt], WanLoss=[WanLoss], Weight=[Weight])

This log is supported only on AR6700-H series, AR8100 series, AR8700 series.

Description

The EVPN link bandwidth was dynamically adjusted using an adaptive QoS policy.

Parameters

Parameter Name Parameter Meaning

ConnectionID

Link index.

ShapeRate

Traffic shaping rate (kbit/s).

Throughput

Throughput (kbit/s).

Adapt

Tunnel bandwidth adjustment mode.

  • Up: The bandwidth is adjusted upwards.
  • Down: The bandwidth is adjusted downwards.

WanLoss

Packet loss rate on the WAN (‰).

Weight

Service queue weight.

Possible Causes

The EVPN link bandwidth was dynamically adjusted based on the network congestion status using an adaptive QoS policy.

Procedure

This message is informational only, and no action is required.
