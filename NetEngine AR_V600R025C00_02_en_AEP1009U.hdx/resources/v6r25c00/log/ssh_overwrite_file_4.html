SSHS/4/SSH_OVERWRITE_FILE

Message

SSHS/4/SSH_OVERWRITE_FILE: When deciding whether to overwrite the file [FileName], the user chose [Option].

Description

When the client uploads a file to the server, if a file with the same name as the file to be uploaded exists on the server, the file on the server is overwritten.

Parameters

Parameter Name Parameter Meaning

FileName

File name.

Option

The user selects Y or N.

Possible Causes

When the client uploads a file to the server, if a file with the same name as the file to be uploaded exists on the server, the file on the server is overwritten.

Procedure

  • This message is informational only, and no action is required.
