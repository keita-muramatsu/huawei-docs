ISIS/6/ISIS_SYS_ID_CONFLICT

Message

ISIS/6/ISIS_SYS_ID_CONFLICT: System ID may conflict. (hwisisSysInstance=[hwisisSysInstance], hwisisSysLevelIndex=[hwisisSysLevelIndex], OwnSystemId=[OwnSystemId], sysProcIndexofDyname=[sysProcIndexofDyname], OwnDynamicName=[OwnDynamicName], AdjSystemId=[AdjSystemId], AdjDynamicName=[AdjDynamicName], LocalIP=[hwIsisLocalIP], AdjIP=[hwIsisAdjIP], RemoteIP=[hwIsisRemoteIP])

Description

IS-IS detected conflicting system IDs.

Parameters

Parameter Name Parameter Meaning

hwisisSysInstance

Number of the IS-IS process

hwisisSysLevelIndex

Level of the IS-IS process

OwnSystemId

System ID of the local IS-IS process

sysProcIndexofDyname

Index of the IS-IS process

OwnDynamicName

Dynamic name of the local IS-IS process

AdjSystemId

System ID of the IS-IS neighbor

AdjDynamicName

Dynamic name of the IS-IS neighbor

hwIsisLocalIP

Local IP address

hwIsisAdjIP

IP address of a neighbor

hwIsisRemoteIP

IP address of the remote device with the conflicting system ID

Possible Causes

Two IS-IS routers in the topology have the same system ID.

Procedure

  • Modify the conflicting system ID to ensure that the system IDs of devices in the topology are unique.
  • Run the undo isis system-id auto-recover disable command on the device where a system ID conflict occurs to enable the device to automatically change the local system ID when a system ID conflict occurs on the network.
