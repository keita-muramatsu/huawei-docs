QOS/4/hwXQoSPacketsDropInterfaceAlarm_active

Message

QOS/4/hwXQoSPacketsDropInterfaceAlarm_active: The interface has packets dropped. (Interface=[hwXQoSPacketsDropInterfaceAlarmIfName], QueueId=[hwXQoSPacketsDropInterfaceAlarmQueueId], SlotId=[hwXQoSPacketsDropInterfaceAlarmSlotId], Discard Packets=[hwXQoSPacketsDropInterfaceAlarmPackets], Discard Bytes=[hwXQoSPacketsDropInterfaceAlarmBytes] Bytes)

Description

The interface has packets dropped.

Parameters

Parameter Name Parameter Meaning

hwXQoSPacketsDropInterfaceAlarmIfName

interface name

hwXQoSPacketsDropInterfaceAlarmQueueId

Queue Index

hwXQoSPacketsDropInterfaceAlarmSlotId

Slot Id

hwXQoSPacketsDropInterfaceAlarmPackets

Discard Packets

hwXQoSPacketsDropInterfaceAlarmBytes

Discard Bytes

Possible Causes

Outbound traffic exceeds the interface bandwidth.

Procedure

1. Increase the interface bandwidth in the outbound direction.

2. If the problem persists, collect alarm and configuration information, and contact technical support personnel.
