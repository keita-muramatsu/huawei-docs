L3VPN/2/hwVpnRouteLabelNumReachMaximum_active

Message

L3VPN/2/hwVpnRouteLabelNumReachMaximum_active: The number of vpn route labels reached the maximum value. (Afi=[AddrFamilyAfi], Safi=[AddrFamilySafi], MaxValue=[MaxValue])

Description

The number of VPN route labels reached the upper limit.

Parameters

Parameter Name Parameter Meaning

AddrFamilyAfi

Address family

AddrFamilySafi

Sub address family

MaxValue

VPN route label limit number

Possible Causes

The number of VPN route labels reached the upper limit.

Procedure

1. Run the display paf | include PRIVATE_LSP_NUM command to check the maximum value set for VPN route labels.

2. Run the display gresm resource statistics command to check the current number of VPN route labels.

3. Delete redundant VPN routes or modify the label allocation mode. Then, check whether the alarm persists.

If the alarm persists, go to step 4.

If the alarm is cleared, go to step 5.

4. Collect alarm and configuration information, and contact technical support personnel.

5. End.
