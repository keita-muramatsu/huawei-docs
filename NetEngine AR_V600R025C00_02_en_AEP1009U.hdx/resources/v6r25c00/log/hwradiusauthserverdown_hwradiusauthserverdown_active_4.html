AAA/4/hwRadiusAuthServerDown_active

Message

AAA/4/hwRadiusAuthServerDown_active: The communication with the RADIUS authentication server fails. (IpAddress=[IpAddress], Vpn-Instance=[Vpn-Instance])

Description

The communication with the RADIUS authentication server fails.

Parameters

Parameter Name Parameter Meaning

IpAddress

Indicates the IP address of the RADIUS authentication server

Vpn-Instance

Indicates the VPN instance on the RADIUS authentication server

Possible Causes

The server did not respond to the request of the device within the timeout period.

Procedure

1.Run the ping command to check whether the RADIUS server is reachable.

a.If so, go to Step 3.

b.If not, go to Step 2.

2.Run the display interface command to check whether the interface is Up.

a.If so, go to Step 3.

b.If not, verify that the physical link is connected properly.

3.Run the display current-configuration command to check whether the RADIUS server is correctly configured.

a.If so, go to Step 4.

b.If not, modify configurations on the RADIUS server.

4.Collect the alarm information, log information, and configuration information, and then contact the Huawei technical support personnel.
