IPS/4/BOTNET

Message

IPS/4/BOTNET: A botnet was detected. (SyslogId=[syslog-id], VSys="[vsys-name]", Policy="[policy-name]", SrcIp=[source-ip], DstIp=[destination-ip], SrcPort=[source-port], DstPort=[destination-port], SrcZone=[source-zone], DstZone=[destination-zone], User="[user-name]", Protocol=[protocol], Application="[application-name]", Profile="[profile-name]", SignName="[signature-name]", SignId=[signature-id], EventNum=[event-number], Target=[target], Severity=[severity], Os=[operating-system], Category=[category], Role=[role], SrcLocation="[source-location]", DstLocation="[destination-location]", Action=[action], Extend="[extend]", UserGroup="[group-name]")

This log is supported only on AR5710-S52T2XE4, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L50T2X4-T, AR6700-H series, AR6710-L8T3TS1X2, AR6710-L50T2X4, AR8100 series, AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S28T2S2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR6710-L14T2X4, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE-NRGL, AR6710-L26T2X4-T, AR5700-H series, AR5710-S8T2XE-LTE4EA-T, AR5710-S8T1XWE, AR5710-S8T2XE.

Description

The IPS detected an active botnet packet on the network. The log describes the detailed information about the event.

Parameters

Parameter Name Parameter Meaning

syslog-id

Sequence number of a log.

vsys-name

The value is fixed to Public.

policy-name

Name of a security policy.

source-ip

Source IP address of the packet or the session that carries the packet.

By default, the source IP address of the detected packet is displayed.

destination-ip

Destination IP address of the packet or the session that carries the packet.

By default, the destination IP address of the detected packet is displayed.

source-port

Source port of packets. For ICMP packets, the value of this field is 0.

destination-port

Destination port of packets. For ICMP packets, the value of this field is 0.

source-zone

Source security zone of packets.

destination-zone

Destination security zone of packets.

user-name

User name.

If a user or security group matching condition is configured in a security policy that references an IPS profile, a log is generated when the security policy is matched and a threat is detected. The log records the user field.

protocol

Protocol of the packet detected by the signature.

application-name

Application to which the packet belongs.

profile-name

Name of a configuration file.

signature-name

Name of a signature.

signature-id

ID of a signature.

event-number

This field is introduced for log merging. Whether to merge logs depends on the merging frequency and log merging conditions. If logs are not merged, the value is 1.

target

Object attacked by the packets detected by the signature. The options are as follows:

  • server: The attack object is a server.
  • client: The attack object is a client.
  • both: The attack objects are the server and client.

severity

Severity of the attack caused by the packets detected by the signature. The options are as follows:

  • information
  • low
  • medium
  • high

operating-system

Operating system attacked by the packets detected by the signature. The options are as follows:

  • all
  • android
  • ios
  • unix-like
  • windows
  • other

category

Threat category to which the packet attack feature detected by the signature belongs.

role

Role of the communicating parties on the botnet. The details are as follows:

  • 0: packets in which the roles of the two communication parties are unclear.
  • 1: packets from a zombie host to a control terminal.
  • 2: packets from a control terminal to a zombie host.
  • 3: packets from a C&C server to a zombie host.
  • 4: packets from a zombie host to a C&C server.
  • 5: packets from a control terminal to a C&C server.
  • 6: packets from a C&C server to a control terminal.
  • 7: attack packets from a zombie host to the victim.

source-location

Geographical location of the source address (dynamic identification).

This field is reserved and is not supported in the current version. This field is left empty.

destination-location

Geographical location of the destination address (dynamic identification).

This field is reserved and is not supported in the current version. This field is left empty.

action

Signature action. The options are as follows:

  • alert
  • block

extend

Extended field.

If the HTTP request header contains the X-Forwarded-For field, the device records the X-Forwarded-For information in this field.

If DNS traffic matches a signature with the block action and the redirection function is configured, the device records the redirection IP address in this field.

group-name

User group.

Possible Causes

The packet matches the Botnet signature.

Procedure

This log message is informational only, and no action is required.
