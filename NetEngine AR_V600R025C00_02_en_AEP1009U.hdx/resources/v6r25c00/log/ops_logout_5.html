OPS/5/OPS_LOGOUT

Message

OPS/5/OPS_LOGOUT: The OPS connection was disconnected. (ServiceType=[ServiceType], Reason=[Reason], UserName=[UserName], SourceAddress=[SourceAddress], DestAddress=[DestAddress], VpnName=[VpnName], AssistantName=[AssistantName])

Description

The OPS connection is torn down.

Parameters

Parameter Name Parameter Meaning

ServiceType

Service type.

Reason

Reason why the OPS connection is torn down.

UserName

User name.

Operation triggered by OPS scheduling. The value is _OPS_.

SourceAddress

Source IP Address

DestAddress

Destination IP Address

VpnName

VPN instance name

AssistantName

Assistant name.

Logs triggered by the maintenance assistant. The value is the maintenance assistant name.

For logs triggered in other modes, the value is _OPS_.

Possible Causes

The script execution is complete or the OPS connection is torn down.

Procedure

1. This message is informational only, and no action is required.
