DHCP/5/RELEASE

Message

DHCP/5/RELEASE: The DHCP client released address successfully. (Client InterfaceName=[clientinterfacename], LeaseIpAddress=[leaseipaddress], ClientMacAddress=[clientmacaddress], OnlineDuration=[onlineduration], LeaseDuration=[leaseduration], Reason=[Reason])

Description

The device functions as a DHCP client and releases an IP address successfully.

Parameters

Parameter Name Parameter Meaning

clientinterfacename

Interface name of the DHCP client.

leaseipaddress

Leased IP address.

clientmacaddress

MAC address of the client.

onlineduration

Online duration.

leaseduration

Lease.

Reason

Reasons for releasing an IP address. The options are as follows:

  • Rejected by the user
  • Released by the user
  • MAC address changed by the user
  • Incorrect DHCP user parameter settings
  • Interface Down
  • DHCP client disabled
  • Gateway detection period timeout
  • Upper limit for retransmission reached
  • Failure to bind the lease to the interface
  • Lease expired
  • Physical interface Down
  • Interface lease failure state
  • Invalid lease
  • Invalid client released
  • Undefined

Possible Causes

The device functions as a DHCP client and successfully releases an IP address.

Procedure

This message is informational only, and no action is required.
