SYSTEM/2/hwStorageUtilizationRisingAlarm_clear

Message

SYSTEM/2/hwStorageUtilizationRisingAlarm_clear: The storage usage falls below the pre-set clear threshold. (TrapSeverity=[TrapSeverity], ProbableCause=[ProbableCause], EventType=[EventType], PhysicalIndex=[PhysicalIndex], PhysicalName=[PhysicalName], RelativeResource=[RelativeResource], UsageType=[UsageType], SubIndex=[SubIndex], UsageValue=[UsageValue], Unit=[Unit], UsageThreshold=[UsageThreshold])

Parameters

Parameter Name Parameter Meaning

TrapSeverity

Indicates the alarm severity. 1 indicates cleared, 2 indicates indeterminate, 3 indicates critical, 4 indicates major, 5 indicates minor, and 6 indicates warning.

ProbableCause

Alarm cause.

EventType

Indicates the alarm type. 3 indicates qualityOfServiceAlarm.

PhysicalIndex

Physical index.

PhysicalName

Name of an entity.

RelativeResource

Name of a resource.

UsageType

Overload type. 1 indicates the CPU, 2 indicates the memory, 3 indicates the disk, 4 indicates the flash memory, 5 indicates the CF card, and 6 indicates the physical memory.

SubIndex

Entity sub-index.

UsageValue

Usage.

Unit

Indicates the unit. The value 1 indicates percentage.

UsageThreshold

Threshold.

Possible Causes

  • Cause 75264:The memory usage fell below the pre-set overload threshold.
  • Cause 75265:The storage usage of the storage medium fell below the default overload threshold.
  • Cause 75269:The fault was rectified when the memory usage of one process exceeded the pre-set overload threshold. The max memory size is 3G for one process.
  • Cause 75274:The fault was rectified the message memory usage exceeded the overload threshold.

Procedure

This message is informational only, and no action is required.
