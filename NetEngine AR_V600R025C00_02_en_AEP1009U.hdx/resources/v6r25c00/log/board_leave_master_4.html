HAF/4/BOARD_LEAVE_MASTER

Message

HAF/4/BOARD_LEAVE_MASTER: Board leave master state. (EntityPhysicalIndex=[EntityPhysicalIndex], EntPhysicalIndex=[EntPhysicalIndex], EntPhysicalName=[EntPhysicalName], EntityType=[EntityType], EntityTrapFaultID=[EntityTrapFaultID],Reason=Master/Slave Board Switchover.)

This log is supported only on AR6700-H series, AR8700 series.

Description

The active main control board is not in the master state.

Parameters

Parameter Name Parameter Meaning

EntityPhysicalIndex

Entity index

EntPhysicalIndex

Entity index

EntPhysicalName

Entity name.

EntityType

Entity type

EntityTrapFaultID

Fault Code

Possible Causes

An active/standby switchover is performed.

Procedure

Perform an active/standby switchover. No action is required.
