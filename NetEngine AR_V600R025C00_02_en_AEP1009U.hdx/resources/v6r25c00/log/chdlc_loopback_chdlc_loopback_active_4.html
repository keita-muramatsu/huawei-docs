HDLC/4/CHDLC_LOOPBACK_active

Message

HDLC/4/CHDLC_LOOPBACK_active: Interface loopback is detected. (InterfaceIndex=[InterfaceIndex], InterfaceName=[InterfaceName])

Description

The interface detected a loop.

Parameters

Parameter Name Parameter Meaning

InterfaceIndex

Index of an interface on which a trap is generated

InterfaceName

Type and number of an interface on which a trap is

generated

Possible Causes

  • Cause 1: The loopback { local | remote } command was run in the interface view.
  • Cause 2: A loop exists.

Procedure

  • Cause 1: The loopback { local | remote } command was run in the interface view.

    1. Run the display this command in the interface view. Check whether the local loopback function is enabled on the interface.

    • If the function is enabled, go to Step 3.
    • If the function is disabled, go to Step 2.

    2. Run the display this command in the view of the remote interface directly connected to the local interface. Check whether the loopback function is enabled on the remote interface.

    • If the function is enabled, go to Step 3.
    • If the function is disabled, go to Step 4.

    3. Run the undo loopback command in the interface view to disable loopback on the interface. After a minute, check whether the trap is cleared.

    • If the trap persists, go to Step 4.
    • If the trap is cleared, go to step 5.

    4. Collect alarm information and configuration information, and then contact technical support personnel.

    5. End.

  • Cause 2: A loop exists.

    1. Check physical connections based on the networking diagram. Check whether there is a loop.

    • If a loop exists, go to Step 2.
    • If there is no loop, go to Step 3.

    2. Re-connect the physical connections to remove the loop. After a minute, check whether the trap is cleared.

    • If the trap persists, go to Step 3.
    • If the trap is cleared, go to Step 4.

    3. Collect alarm information and configuration information, and then contact technical support personnel.

    4. End.
