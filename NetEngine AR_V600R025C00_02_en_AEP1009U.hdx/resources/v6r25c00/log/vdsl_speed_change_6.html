VDSL/6/VDSL_SPEED_CHANGE

Message

VDSL/6/VDSL_SPEED_CHANGE: The port speed of the VDSL interface is changed. (IfIndex=[IfIndex],InterfaceName=[InterfaceName],OldSpeed=[OldSpeed],NewSpeed=[NewSpeed])

This log is supported only on AR5710-S52T2XE4, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L50T2X4-T, AR6700-H series, AR6710-L8T3TS1X2, AR6710-L50T2X4, AR8100 series, AR5710-S10T1X2, AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S28T2S2XE4, AR6710-L14T2X4, AR5710-S8P1XDSE-2LTE4EA, AR6710-L26T2X4-T.

Description

The interface rate changes.

Parameters

Parameter Name Parameter Meaning

IfIndex

Interface index.

InterfaceName

Interface name.

OldSpeed

Rate before change, in bps.

NewSpeed

Rate after change, in bps.

Possible Causes

The rate negotiated between the VDSL interface and the DSLAM changes.

Procedure

This message is informational only, and no action is required.
