WLAN/4/hwRadioReachMaxUserPhySpecTrap_active

Message

WLAN/4/hwRadioReachMaxUserPhySpecTrap_active: RADIO reach the max number of stations notify. (APMAC=[APMAC], RADIOID=[RADIOID], APID=[APID], APName=[APName], StaNum=[StaNum], MaxStaNum=[MaxStaNum])

Description

The number of access STAs on a radio reached the maximum number of access STAs supported by the radio.

Parameters

Parameter Name Parameter Meaning

APMAC

MAC address of an AP.

RADIOID

Radio ID.

APID

AP ID.

APName

Name of an AP.

StaNum

Number of current access users.

MaxStaNum

Maximum number of access STAs supported by a radio.

Possible Causes

The number of access STAs reached the maximum physical specifications supported by a radio.

Procedure

1. Replace the AP with an AP model that supports a larger number of access STAs, or add APs for capacity expansion.

  • If the alarm persists, go to Step 2.
  • If the alarm is cleared, go to Step 3.

2. Collect alarm, log, and configuration information, and contact technical support personnel.

3. End.
