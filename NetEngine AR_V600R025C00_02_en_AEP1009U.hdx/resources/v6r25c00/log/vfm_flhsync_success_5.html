VFS/5/VFM_FLHSYNC_SUCCESS

Message

VFS/5/VFM_FLHSYNC_SUCCESS: Succeeded to copy file by hwFlhSyncTable with FlhSyncIndex [FlhSyncIndex], FlhSyncSrcFile [FlhSyncSrcFile], FlhSyncDstFile [FlhSyncDstFile].

Description

This log indicates that the file is successfully copied through hwFlhSyncTable in HUAWEI-FLASH-MAN-MIB.

Parameters

Parameter Name Parameter Meaning

FlhSyncIndex

Index of the file to be copied.

FlhSyncSrcFile

Source file.

FlhSyncDstFile

Target file.

Possible Causes

This log is generated when a file is successfully copied through MIB.

Procedure

  • This message is informational only, and no action is required.
