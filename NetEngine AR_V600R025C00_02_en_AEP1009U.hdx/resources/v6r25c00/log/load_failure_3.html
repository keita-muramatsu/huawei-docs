LOCATION/3/LOAD_FAILURE

Message

LOCATION/3/LOAD_FAILURE: Failed to load the region identification signature database. (SyslogId=[syslog-id], Module=[module], LoadVersion=[load-version], Duration(s)=[duration], Reason=[reason], Suggestion=[suggestion])

Description

Failed to load the region signature database.

Parameters

Parameter Name Parameter Meaning

syslog-id

Sequence number of a log.

module

Module to be upgraded.

load-version

Version number of the loaded module.

duration

Loading duration, in seconds.

reason

Cause of the loading failure. The options are as follows:

1. The content of the specified file is invalid.

2. The target version is in use.

3. The free space of the storage card is insufficient.

4. The file to be updated does not exist.

suggestion

Handling suggestion for the loading failure. The options are as follows:

1. Use the valid update file.

2. Please use the other version file.

3. Please ensure that the storage card has enough space for the update.

4. Please contact Huawei technical support personnel.

Possible Causes

The possible cause is displayed in the reason field in the log.

Procedure

If the problem persists, contact technical support personnel.
