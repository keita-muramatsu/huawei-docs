AM/4/hwDhcpv4ServerRcvClientVendorInfo_active

Message

AM/4/hwDhcpv4ServerRcvClientVendorInfo_active: The DHCP server receives the vendor information carried by the client. (PoolName=[PoolName], VpnName=[VpnName], VlanId=[VlanId], UserMAC=[UserMAC], Option12=[Option12], Option60=[Option60], Option125=[Option125])

Description

The DHCP server received the vendor information carried in request packets from the DHCP client.

Parameters

Parameter Name Parameter Meaning

PoolName

Name of an address pool.

VpnName

VPN name.

VlanId

VLAN ID.

UserMAC

MAC address of the user.

Option12

DHCPv4 client's hostname option.

Option60

Vendor category option, which identifies the DHCPv4 client's type and configuration.

Option125

Device name and software version of the DHCP client.

Possible Causes

When the device functions as a DHCPv4 server, the option alarm function needs to be enabled for the interface address pool of the server. In this manner, when the DHCPv4 client sends a Discover message, the device generates an alarm and reports the information carried in request packets of the client to the NMS. The information includes Option 12 (host name), Option 60 (vendor class identifier), and Option 125 (device name and software version).

Procedure

This message is informational only, and no action is required.
