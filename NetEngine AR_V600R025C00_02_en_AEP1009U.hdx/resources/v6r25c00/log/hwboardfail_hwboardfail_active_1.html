DEVM/1/hwBoardFail_active

Message

DEVM/1/hwBoardFail_active: The board partially failed. (EntPhysicalIndex=[EntPhysicalIndex], EntPhysicalName=[EntPhysicalName], EntityType=[EntityType], EntityTrapFaultID=[EntityTrapFaultID], Reason=[Reason])

Description

The card experienced a partial failure.

Parameters

Parameter Name Parameter Meaning

EntPhysicalIndex

Entity index.

EntPhysicalName

Entity name.

EntityType

Actual NE type

1: MPU

2: LPU

3: SFU

4: PIC

5: CFX_CARD

6: OFC

EntityTrapFaultID

Fault ID.

Procedure

  • Cause 1: Power supply abnormal.

    1. Run the display device command to check whether the faulty board is registered. If the faulty board is registered and services are running properly, go to step 3.

    2. Run the power off command to power off the card, and then run the power on command to power on the card. If the fault persists, go to step 3.

    3. Collect trap, log, and configuration information, and contact technical support personnel.
