PIM/6/SRC_MASK_UNSUPPORTED

Message

PIM/6/SRC_MASK_UNSUPPORTED: In VPN instance [vpn-instance-name], the length of the mask of the source address [source-address]/[source-address-mask] in the Join/Prune message was unsupported, so this source was ignored.

Description

The source address contained in the Join/Prune message was ignored, because PIM-SM did not support the mask length of the source address.

Parameters

Parameter Name Parameter Meaning

vpn-instance-name

Indicates the name of a VPN instance.

source-address

Indicates the source address.

source-address-mask

Indicates the mask length of source address.

Possible Causes

The PIM-SM-enabled interface receives a Join/Prune message, the mask length of the source address contained in which is not supported by PIM-SM.

Procedure

  • If this fault occurs occasionally, this log message can be ignored.
  • If the fault frequently occurs, check the packet source, record this log message, and then contact technical support personnel.
