DRIVER/4/WBoardStsChanged

Message

DRIVER/4/WBoardStsChanged: Slot [BoardSlotID] [BoardType] [StatusChanged].

Description

The board status changed [BoardSlotID] [BoardType] [StatusChanged].

Parameters

Parameter Name Parameter Meaning

BoardSlotID

Slot number

BoardType

Board type

StatusChanged

Status change description

Possible Causes

The board status changes. For example, the board is registered, removed and then inserted, or powered off and on.

Procedure

Check whether the status change is as expected. If yes, no action is required. If no, rectify the fault by referring to the board troubleshooting procedure in the DEVM module.
