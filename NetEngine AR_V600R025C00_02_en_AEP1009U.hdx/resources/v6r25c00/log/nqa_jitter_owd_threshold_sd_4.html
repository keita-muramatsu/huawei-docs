NQA/4/NQA_JITTER_OWD_THRESHOLD_SD

Message

NQA/4/NQA_JITTER_OWD_THRESHOLD_SD: The OWD-SD of the NQA entry exceeded the configured threshold. (OwnerIndex=[OwnerIndex], TestName=[TestName], TargetAddressType=[TargetAddressType], TargetAddress=[TargetAddress], Threshold=[Threshold], Index=[Index], RttMax=[RttMax], MaxDelaySD=[MaxDelaySD], MaxDelayDS=[MaxDelayDS], OWDOverThresholdsSD=[OWDOverThresholdsSD])

Description

This trap was generated when the one-way delay from the source to the destination exceeded the threshold and the test instance ended.

Parameters

Parameter Name Parameter Meaning

OwnerIndex

Administrator of an NQA test instance

TestName

Name of the NQA test instance

TargetAddressType

Destination address type

TargetAddress

Destination address

Threshold

User-configured threshold

Index

Result table index

RttMax

Maximum RTT

MaxDelaySD

Maximum unidirectional delay from the source to the destination

MaxDelayDS

Maximum unidirectional delay from the destination to the source

OWDOverThresholdsSD

Number of times that one-way delay from the source to the destination exceeded the threshold

Possible Causes

Cause 1: The threshold was too small.

Cause 2: The network was busy.

Procedure

1. Run the display cpu-usage command in the system view to check whether the CPU is overloaded.

  • If so, go to Step 3.
  • If no, go to Step 2.

2. Run the display this command in the NQA test view to obtain the current threshold. Then run the threshold owd-sd command in the NQA test view to change the threshold as required (20 ms is recommended). Restart the test instance and check whether the alarm is cleared.

  • If yes, go to Step 4.
  • If no, go to Step 3.

3. Collect alarm and configuration information, and contact technical support personnel.

4. End.
