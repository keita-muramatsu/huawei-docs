DHCP/5/RENEW

Message

DHCP/5/RENEW: The IP address lease is successfully renewed. (Client InterfaceName=[clientinterfacename], ServerId=[serverid], AcquiredIpAddress=[acquiredipaddress], Mask=[mask], Gateway=[gateway], StaticRoute=[staticroute], LeaseDuration=[leaseduration], DNSServer=[DNSserver], DNSDomain=[DNSdomain], CloudManagementURL=[cloudManagementURL], Option43=[Option43])

Description

The device functions as a DHCP client, and the IP address lease is successfully updated.

Parameters

Parameter Name Parameter Meaning

clientinterfacename

Name of the interface on the DHCP client.

serverid

serverid: IP address of the DHCP server.

acquiredipaddress

acquiredipaddress: IP address assigned to the DHCP client.

mask

mask: network mask.

gateway

gateway: gateway address.

staticroute

staticroute: static route.

leaseduration

leaseduration: lease duration.

DNSserver

DNSserver: DNS server.

DNSdomain

DNSdomain: DNS domain name.

cloudManagementURL

cloudManagementURL: URL of iMaster NCE-Campus.

Option43

Option43: DHCP Option 43 information.

Possible Causes

The device functions as a DHCP client, and the IP address lease is successfully updated.

Procedure

This message is informational only, and no action is required.
