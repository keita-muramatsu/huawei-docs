SEGR/4/SRV6_LOCAL_SID_ROUTE_CONFLICT_active

Message

SEGR/4/SRV6_LOCAL_SID_ROUTE_CONFLICT_active: Conflict between an SRv6 local SID and a route. (SID=[LocalSID]/[PrefixLength])

Description

An SRv6 local SID conflicts with a route.

Parameters

Parameter Name Parameter Meaning

LocalSID

Local SID.

PrefixLength

Mask length of local SID.

Possible Causes

There was a conflict between the SRv6 local SID and route.

Procedure

1. Run the display alarm active command to check the reported error SID and mask.

2. Run the display segment-routing ipv6 local-sid forwarding command to check the local SID configuration.

3. Run the display ipv6 routing-table [ vpn-instance vpn-instance-name ] command to view the routing information on the device.

4. Check whether the query results in Steps 2 and 3 conflict.

  • If yes, go to Step 5.
  • If no, go to Step 6.

5. Check whether the routing and local SID configurations are proper. If no, modify them and go to Step 7.

6. Collect alarm and configuration information, and contact technical support personnel.

7. End.
