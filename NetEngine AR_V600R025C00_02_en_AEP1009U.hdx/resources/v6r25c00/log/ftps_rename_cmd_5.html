FTPS/5/FTPS_RENAME_CMD

Message

FTPS/5/FTPS_RENAME_CMD: The [command_name] command is executed on the client side. (FromFileName=[FromFileName], ToFileName=[ToFileName], UserName=[UserName], UserAddress=[UserAddress], LocalAddress=[LocalAddress], VPNInstanceName=[VPNInstanceName], ClientDataPort=[ClientDataPort], Result=[Result])

Description

Run the rename command on the FTP client. The renaming succeeds or fails.

Parameters

Parameter Name Parameter Meaning

command_name

Indicates the command name.

FromFileName

Indicates the original file name.

ToFileName

Name of a new file.

UserName

Indicates the user name of the client.

UserAddress

Indicates the IP address of the client.

LocalAddress

Indicates the IP address of the server.

VPNInstanceName

Indicates the name of a VPN instance.

ClientDataPort

Indicates the data port of the client.

Result

Indicates the renaming result on the FTP server.

Possible Causes

Run the rename command on the FTP client to rename the file.

Procedure

-· Check whether the new path name is valid.

-· Check whether you have the permission on the new path.

-· Check whether the source file exists.

-· Check whether the connection is disconnected.
