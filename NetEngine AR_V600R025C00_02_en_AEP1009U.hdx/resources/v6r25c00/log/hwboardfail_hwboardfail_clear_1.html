DEVM/1/hwBoardFail_clear

Message

DEVM/1/hwBoardFail_clear: The board resumed from partial failure. (EntPhysicalIndex=[EntPhysicalIndex], EntPhysicalName=[EntPhysicalName], EntityType=[EntityType], EntityTrapFaultID=[EntityTrapFaultID], Reason=[Reason])

Parameters

Parameter Name Parameter Meaning

EntPhysicalIndex

Entity index.

EntPhysicalName

Entity name.

EntityType

Actual NE type

1: MPU

2: LPU

3: SFU

4: PIC

5: CFX_CARD

6: OFC

EntityTrapFaultID

Fault ID.

Reason

Alarm cause.

Possible Causes

The board recovered from a partial failure.

Procedure

1. This alarm is informational only, and no action is required.
