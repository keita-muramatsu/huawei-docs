CLI/4/UNLOCK_ERROR_FAIL

Message

CLI/4/UNLOCK_ERROR_FAIL: Failed to unlock the user-interface. (Task=[Task], RemoteIp=[RemoteIp], VpnName=[VpnName], User=[User], Reason=[Reason], LocalIp=[LocalIp].)

Description

The user interface fails to be unlocked.

Parameters

Parameter Name Parameter Meaning

Task

Index corresponding to the user channel type.

RemoteIp

IP address for login. If you log in using the console port, the value is **.

VpnName

Name of the VPN to which the login interface belongs.

User

User name for login. If a user logs in to the system in password authentication mode and user information cannot be obtained, the user name is displayed as **.

Reason

Cause of the unlocking failure.

LocalIp

Local IP address.

Possible Causes

This log is recorded when a user enters the password to unlock the user interface after the user interface is locked through a password using the lock command.

Procedure

1. This message is informational only, and no action is required.
