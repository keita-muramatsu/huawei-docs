TRUNK/5/TRUNK_MEM_NUMBER_CHANGE

Message

TRUNK/5/TRUNK_MEM_NUMBER_CHANGE: The number of active trunk members changed. (TrunkName=[TrunkName], PortName=[PortName], ActiveTrunkMemNum=[TrunkMemNumber], Reason=[Reason])

Description

The number of active trunk member interfaces changed.

Parameters

Parameter Name Parameter Meaning

TrunkName

Name of the trunk interface

PortName

Name of a trunk member interface

TrunkMemNumber

Number of active member interfaces

Reason

Reason

Possible Causes

Cause 1: A trunk member interface went Up. Cause 2: A trunk member interface went Down.

Procedure

  • Cause 1: The member interface changed from Down to Up.
  • This log message is informational only, and no action is required.
  • Cause 2: The member interface changed from Up to Down.
  • If the status of a member interface changes from Up to Down, check whether the member interface has generated a 1.3.6.1.6.3.1.1.5.3 linkdown alarm. The alarm cause is also the cause of this event.
