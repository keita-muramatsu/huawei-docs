PIM/5/NO_PIM_IFPARA

Message

PIM/5/NO_PIM_IFPARA: In VPN instance "[vpn-instance-name]", no PIM parameter was found on the interface [interface-name] ([interface-address]).

Description

PIM parameters cannot be found on the interface.

Parameters

Parameter Name Parameter Meaning

vpn-instance-name

Name of a VPN instance.

interface-name

Interface name.

interface-address

Interface address.

Possible Causes

PIM parameters on the interface cannot be found.

Procedure

Collect log and configuration information, and contact technical support personnel.
