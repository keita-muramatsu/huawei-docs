PKI/4/OCSP_IMPORT_ERR

Message

PKI/4/OCSP_IMPORT_ERR: Importing OCSP certificate file ([file_name]) failed.

Description

Failed to import the OCSP certificate.

Parameters

Parameter Name Parameter Meaning

file_name

OCSP certificate file name.

Possible Causes

  • The certificate file does not exist.
  • The certificate file name is invalid.
  • The certificate format is incorrect.
  • The certificate storage path is incorrect.
  • The same certificate already exists on the device.

Procedure

1. Run the display pki certificate filename file-name command to check whether the certificate exists.

  • If not, upload the certificate to the storage medium of the device through SFTP or other methods.
  • If yes, go to Step 2.

2. Check whether the name of the imported certificate file complies with the device specifications.

  • If not, change the certificate file name based on the device requirements.
  • If yes, go to Step 3.

3. Run the pki import-certificate ocsp command to check whether the certificate format is correct.

  • If not, select the correct certificate format when importing the certificate.
  • If yes, go to Step 4.

4. Run the dir and display pki credential-storage-path commands in the user view to check whether the certificate storage path is the same as the default storage path of the certificate.

  • If not, save the certificate to the default save path.
  • If yes, go to Step 5.

5. Run the display pki certificate ocsp command to check whether the same certificate has been loaded to the device or whether the same issuer and subject certificates exist on the device.

  • If yes, run the pki delete-certificate command in the system view to delete the certificate.
  • If not, go to Step 6.

6. Collect related information and contact technical support personnel.
