ND/4/hwSlotNDThresholdExceed_clear

Message

ND/4/hwSlotNDThresholdExceed_clear: The number of ND entries was restored to the threshold of slot. (entPhysicalIndex=[entPhysicalIndex], Slotname=[slotname], Threshold=[Threshold], Number of dynamic ND entries=[DynEntries], Number of static ND entries=[StatEntries], Number of remote ND entries=[RemoteEntries]).

Parameters

Parameter Name Parameter Meaning

entPhysicalIndex

Index of the board that reports the alarm.

slotname

Name of the board that reports the alarm.

Threshold

Alarm threshold.

DynEntries

Number of dynamic ND entries on the board that reports the alarm.

StatEntries

Number of static ND entries on the board that reports the alarm.

RemoteEntries

Number of remote ND entries on the board that reports the alarm.

Possible Causes

Dynamic ND entries aged, or ND entries were manually deleted from the board, or ND entries received delete message from remote.

Procedure

This trap message is informational only, and no action is required.
