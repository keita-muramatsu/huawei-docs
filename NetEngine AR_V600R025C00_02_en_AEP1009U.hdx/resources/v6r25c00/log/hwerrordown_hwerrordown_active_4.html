ERROR-DOWN/4/hwErrordown_active

Message

ERROR-DOWN/4/hwErrordown_active: Error-down occurred. (Ifindex=[IfIndex], Ifname=[IfName], Cause=[Cause])

Description

The alarm was generated when an errordown event occurred.

Parameters

Parameter Name Parameter Meaning

IfIndex

Index of an interface

IfName

Interface name

Cause

Cause of the errordown event

Possible Causes

  • Cause 1: bpdu-protection: The STP edge interface receives BPDUs.
  • Cause 2: monitor-link: The uplink link in the Monitor Link group is Down.
  • Cause 3: auto-defend: The number of packets sent to the CPU for processing reaches the threshold.

Procedure

  • Cause 1: bpdu-protection: The STP edge interface receives BPDUs.

    1. Check whether the port should be planned as an edge port.

    • If not, go to Step 2.
    • If so, go to Step 3.

    2. Run the undo stp edged-port and undo shutdown commands to delete the edge port configuration. Check whether the alarm exists. If the alarm persists, go to Step 3.

    3. Collect alarm information and contact technical support engineers.

  • Cause 2: monitor-link: The uplink link in the Monitor Link group is Down.

    1. For how to handle the alarm when the upstream link of the Monitor Link group went Down, see IFNET_1.3.6.1.6.3.1.1.5.3 linkdown.

  • Cause 3: auto-defend: The number of packets sent to the CPU for processing reaches the threshold.

    1. Identify the attack source and prevent the attacks. After the fault is rectified, run the shutdown and undo shutdown commands in the interface view to restore the service interface state.
