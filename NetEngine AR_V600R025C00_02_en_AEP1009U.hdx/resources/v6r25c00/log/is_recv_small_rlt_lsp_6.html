ISIS/6/IS_RECV_SMALL_RLT_LSP

Message

ISIS/6/IS_RECV_SMALL_RLT_LSP: ISIS receive LSP with small Remaining Lifetime. (isisSysInstance=[isisSysInstance], isisSysLevelIndex=[isisSysLevelIndex], isisCircIndex=[isisCircIndex], isisCircIfIndex=[isisCircIfIndex], ifIndex=[ifIndex], ifName=[ifName], isisAdjSysID=[hwIsisAdjSysID], isisPduLspId=[isisPduLspId], isisRemainingLifetime=[hwIsisRemainingLifetime])

Description

This object indicates that the Remaining Lifetime of a received LSP is less than 60s.

Parameters

Parameter Name Parameter Meaning

isisSysInstance

ID of an IS-IS process

isisSysLevelIndex

IS-IS level

isisCircIndex

Index of the interface that received the LSP

isisCircIfIndex

Index of the interface that received the LSP

ifIndex

Interface index

ifName

Name of the interface that received the LSP

hwIsisAdjSysID

System ID of the neighbor that sent the LSP

isisPduLspId

LSP ID

hwIsisRemainingLifetime

Remaining Lifetime of the LSP

Possible Causes

A new LSP generated by another device is received, and the Remaining Lifetime value of the LSP is not 0 and less than 60 seconds.

Procedure

1. Check the value of hwIsisRemainingLifetime in the reported alarm information to determine whether the value of Remaining Lifetime is not 0 and less than 60 seconds.

  • If yes, run the display this command in the IS-IS view on the neighbor to check whether Remaining Lifetime was manually adjusted using the lsp-remaining-lifetime refresh timer command and whether the result is as expected.
  • If yes, this message is informational only and no action is required. In this case, go to Step 3.
  • If the Remaining Lifetime value is changed but the result is not as expected, run the lsp-remaining-lifetime refresh timer command in the IS-IS view of the neighbor to change the value.
  • If no, go to Step 2.

2. Collect alarm and configuration information, and contact technical support personnel.

3. End.
