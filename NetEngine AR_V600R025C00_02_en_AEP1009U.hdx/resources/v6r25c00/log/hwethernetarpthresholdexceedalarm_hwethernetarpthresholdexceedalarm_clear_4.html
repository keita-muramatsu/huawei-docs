ARP/4/hwEthernetARPThresholdExceedAlarm_clear

Message

ARP/4/hwEthernetARPThresholdExceedAlarm_clear: The number of ARP entries was restored to the threshold. (entPhysicalIndex=[entPhysicalIndex], Slot name=[slotname], Threshold=[Threshold], Number of dynamic ARP entries=[DynEntries], Number of static ARP entries=[StatEntries])

Parameters

Parameter Name Parameter Meaning

entPhysicalIndex

Indicates the index of the physical entity.

slotname

Indicates the board name.

Threshold

Indicates the alarm threshold.

DynEntries

Indicates the number of dynamic ARP entries.

StatEntries

Indicates the number of static ARP entries.

Possible Causes

The number of ARP entries on the device fell below the upper threshold.

Procedure

1. This alarm message is informational only, and no action is required.
