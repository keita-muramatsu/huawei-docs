CLI/5/SYSTEMINITFAILED

Message

CLI/5/SYSTEMINITFAILED: Initialize the system device information. (Information="[Information]", Result=[Result].)

Description

Command matching fails for system initialization.

Parameters

Parameter Name Parameter Meaning

Information

Command matched for system initialization.

Result

Command matching result for system initialization.

Possible Causes

The command fails to be matched during device initialization.

Procedure

1. This message is informational only, and no action is required.
