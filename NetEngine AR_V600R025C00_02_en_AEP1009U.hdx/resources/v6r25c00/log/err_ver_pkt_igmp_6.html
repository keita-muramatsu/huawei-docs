IGMP/6/ERR_VER_PKT_IGMP

Message

IGMP/6/ERR_VER_PKT_IGMP: In the VPN instance, the received IGMP Query packet is ignored because the IGMP version of the packet is different from that configured on the interface. (VPNName=[VPNName], IfName=[IfName], IfAddr=[IfAddr], SrcAddr=[SrcAddr], RcvVersion=[RcvVersion], IfVersion=[IfVersion])

Description

The version of IGMP configured on the interface was different from that of the received IGMP Query packet.

Parameters

Parameter Name Parameter Meaning

VPNName

Name of a VPN instance

IfName

Name of an interface

IfAddr

Interface address

SrcAddr

Source address

RcvVersion

Version of the received IGMP Query packet

IfVersion

Version of IGMP configured on the interface, which can be one of the following:

  • IGMPv1
  • IGMPv2
  • IGMPv3

Possible Causes

The IGMP Query packet was invalid or its version of IGMP was higher than that configured on the interface.

Procedure

  • This log message is informational only, and no action is required.
