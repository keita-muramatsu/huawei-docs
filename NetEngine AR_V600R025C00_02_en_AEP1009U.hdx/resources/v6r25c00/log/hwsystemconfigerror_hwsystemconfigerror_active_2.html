SYSTEM/2/hwSystemConfigError_active

Message

SYSTEM/2/hwSystemConfigError_active: A system configuration error occurs. ( EntityTrapFaultID = [EntityTrapFaultID])

Description

The system configuration is incorrect.

Parameters

Parameter Name Parameter Meaning

EntityTrapFaultID

Fault code

Possible Causes

  • Cause 144128: The version in the PAF file is inconsistent with that of the startup software package.
  • Cause 144129: The boards and subcards were installed in incorrect slots.
  • Cause 144130: The software versions on the master and slave control boards are inconsistent.
  • Cause 144133: The memory size of the system master main control board was inconsistent with that of the system slave main control board.

Procedure

  • Cause 144128: The version in the PAF file is inconsistent with that of the startup software package.

    The PAF version is inconsistent with the version of the startup system software package.

    1. Manually change the PAF version to be the same as the version of the startup system software package. Run the startup paf command to set the PAF as the next startup PAF, and then run the reboot command to restart the device.

    • If the alarm is cleared, go to Step 3.
    • If the alarm persists, go to Step 2.

    2. Collect alarm and configuration information, and contact technical support personnel.

    3. End.

  • Cause 144129: The boards and subcards were installed in incorrect slots.

    1. Check whether the boards and subcards of the device are inserted into the correct slots.

    • If so, go to Step 3.
    • If not, go to Step 2.

    2. Replace the faulty board or subcard so that the boards or subcards are installed in supported slots. Then, check whether the alarm is cleared.

    • If so, go to Step 4.
    • If not, go to Step 3.

    3. Collect alarm, log, and configuration information, and contact technical support personnel.

    4. End.

  • Cause 144130: The software versions on the master and slave control boards are inconsistent.

    The versions of the active and standby boards are inconsistent.

    1. Run the startup system-software command to change the version of the standby board to be the same as that of the active board, and then run the reset slot command to reset the standby board.

    • If the alarm is cleared, go to Step 3.
    • If the alarm persists, go to Step 2.

    2. Collect alarm and configuration information, and contact technical support personnel.

    3. End.

  • Cause 144133: The memory size of the system master main control board was inconsistent with that of the system slave main control board.

    The memory of the active board is inconsistent with that of the standby board.

    • Contact technical support engineers to replace the memory module and ensure that the memory of the active board is the same as that of the standby board.
