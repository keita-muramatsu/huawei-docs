CPUDEFEND/4/STRACK_SRCIP

Message

CPUDEFEND/4/STRACK_SRCIP: Attack occurred. (Interface=[Interface], SourceIp=[SourceIP], CVLAN=[CVLAN], PVLAN=[PVLAN], EndTime=[EndTime], TotalPackets=[TotalPackets], SourceIpv6=[SourceIPv6])

Description

The system detected attacks from a user with a specified source IP address.

Parameters

Parameter Name Parameter Meaning

Interface

Interface index

SourceIP

Source IP address.

CVLAN

Inner VLAN of attack packets sent by a user.

PVLAN

Outer VLAN of attack packets sent by a user.

EndTime

Time when the last attack packet is received.

TotalPackets

Number of received attack packets.

SourceIPv6

Source IPv6 address.

Possible Causes

Cause 1: The rate at which packets were sent by a user (a source IP address) to the CPU exceeded the alarm threshold.

Procedure

Cause 1: The rate at which packets were sent by a user (a source IP address) to the CPU exceeded the alarm threshold.

1. Run the display auto-defend attack-source command to check the possible attack source and determine whether the system is abnormal according to the growth rate of packets in entries.

  • If so, go to Step 2.
  • If not, no action is required.

2. Collect alarm, log, and configuration information, and contact technical support personnel.
