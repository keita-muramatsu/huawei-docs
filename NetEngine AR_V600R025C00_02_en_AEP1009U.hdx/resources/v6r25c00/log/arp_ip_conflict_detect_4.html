ARP/4/ARP_IP_CONFLICT_DETECT

Message

ARP/4/ARP_IP_CONFLICT_DETECT: Detected an IP address collision. (IpAddress=[IpAddr], Local MacAddress=[LocalMacAddr], Local InterfaceName=[LocalIfName], Local VLAN=[LocalPVid], Local INNER-VLAN=[LocalCVid], Received MacAddress=[RcvMacAddr], Received InterfaceName=[RcvIfName], Received VLAN=[RcvPVid], Received INNER-VLAN=[RcvCVid], Collision Type=[type])

Description

The device checked that the source IP address of ARP packets conflicted with the IP address in the local ARP entry.

Parameters

Parameter Name Parameter Meaning

IpAddr

IP Address

LocalMacAddr

Local MAC Address

LocalIfName

Local Interface Name

LocalPVid

Local VLAN ID

LocalCVid

Local inner VLAN ID

RcvMacAddr

MAC address of the received packet

RcvIfName

Name of the interface that receives packets

RcvPVid

VLAN ID of the received packet

RcvCVid

Inner VLAN ID of the received packet

type

Conflict Type

Possible Causes

The device could find the source IP address carried in a non-gratuitous ARP packet among its local ARP entries, but could not find the source MAC address carried in that packet among its local ARP entries.

Procedure

Check the devices with the same IP address on the network. Change the interface IP addresses based on the IP address plan to resolve the IP address conflict.
