ISIS/6/IS_PURGE_CALCULATE_DELAY_COUNT

Message

ISIS/6/IS_PURGE_CALCULATE_DELAY_COUNT: ISIS-INFO: The statistics about the suppression times of the updated LSP of the IS that sent the non-pseudo node purge LSP with fragment number 0 were recorded. (InstanceId = [InstanceId], Level = [Level], SuppressedLocalPurgeCount = [LocalCount], SuppressedReceivePurgeCount = [RecCount], LogPeriod = [LogPeriod])

Description

The number of times that purge LSP-triggered route calculations were delayed was recorded.

Parameters

Parameter Name Parameter Meaning

InstanceId

ID of an IS-IS process

Level

IS-IS Level

LocalCount

Number of times that local purge LSP-triggered route calculations are delayed

RecCount

Number of times that received purge LSP-triggered route calculations are delayed

LogPeriod

Interval at which logs are generated

Possible Causes

Purge LSP-triggered route calculations were delayed.

Procedure

1. Check whether either of the following inequalities is met:

SuppressedLocalPurgeCount > 100 SuppressedReceivePurgeCount > 100

  • If either of the preceding inequalities is met, go to Step 2.
  • If neither of the preceding inequalities is met, go to Step 4.

2. Check whether a device or link failure exists on the network.

  • If a device or link failure exists, rectify the failure.
  • If no device or link failure exists, go to Step 3.

3. Check whether the delay period configured using the timer purge-zero-lsp route-calculate-delay <delay-interval> command is too long. If it is too long, reduce it and check whether the problem is resolved.

  • If the problem persists, go to Step 5.
  • If the problem is resolved, go to Step 6.

4. This log is informational only, and no action is required.

5. Collect log information and configuration information, and then contact technical support personnel.

6. End.
