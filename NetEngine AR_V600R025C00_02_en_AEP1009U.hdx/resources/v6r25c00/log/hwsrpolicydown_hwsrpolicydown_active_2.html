SRPOLICY/2/hwSrPolicyDown_active

Message

SRPOLICY/2/hwSrPolicyDown_active: The SR Policy went down. (hwSrPolicyEndpoint=[SrPolicyEndpoint], hwSrPolicyColor=[SrPolicyColor], hwSrPolicyDownReason=[DownReason])

Description

The SR Policy went down.

Parameters

Parameter Name Parameter Meaning

SrPolicyEndpoint

Endpoint

SrPolicyColor

Color value

DownReason

Down Reason

Possible Causes

  • Cause 1: The SR Policy was manually shut down.
  • Cause 2: No candidate path was available.

Procedure

  • Cause 1: The SR Policy was manually shut down.

    Enable the SR Policy function.

  • Cause 2: No candidate path was available.

    1. Check links.

    2. Configure a candidate path with valid segment lists for the SR Policy.
