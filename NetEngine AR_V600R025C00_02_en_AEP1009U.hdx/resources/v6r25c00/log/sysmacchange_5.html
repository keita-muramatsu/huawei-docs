DRIVER/5/SYSMACCHANGE

Message

DRIVER/5/SYSMACCHANGE: System mac-address changed. (CurMac=[curmac], PreMac=[premac])

Description

The system MAC address was switched.

Parameters

Parameter Name Parameter Meaning

curmac

Current system MAC address.

premac

Original system MAC address.

Possible Causes

After MAC address switching is configured, if a member device leaves the system, the system MAC address may be switched.

Procedure

1. Run the display system mac-address command to check whether MAC address switching is configured.

  • If so, go to Step 2.
  • If not, go to Step 3.

2. Check whether an active/standby switchover is performed or a device exits.

3. This message is informational only. No action is required.
