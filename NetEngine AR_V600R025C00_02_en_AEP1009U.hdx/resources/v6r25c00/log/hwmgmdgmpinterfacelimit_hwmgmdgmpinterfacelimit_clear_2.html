IGMP/2/hwMgmdGMPInterfaceLimit_clear

Message

IGMP/2/hwMgmdGMPInterfaceLimit_clear: The new Report message can be processed because the number of IGMP or MLD group memberships on the interface falls below the upper limit. (AddressFamily=[AddressFamily], SrcAddr=[SrcAddr], GrpAddr=[GrpAddr], Ifindex=[IfIndex], CurrentCount=[CurrentCount], Ifname=[IfName], InstanceName=[InstanceName])

Parameters

Parameter Name Parameter Meaning

AddressFamily

Address family:

  • 1: IPv4 family.
  • 2: IPv6 family.

SrcAddr

Source address.

GrpAddr

Group address.

IfIndex

interface index.

CurrentCount

Limit on the number of IGMP entries on the device.

IfName

Name of the interface.

InstanceName

Name of the instance where the number of IGMP entries on the interface exceeded the limit.

Possible Causes

  • Cause 1:Entry delete
  • Cause 2:Configuration change

Procedure

  • This trap message is informational only, and no action is required.
