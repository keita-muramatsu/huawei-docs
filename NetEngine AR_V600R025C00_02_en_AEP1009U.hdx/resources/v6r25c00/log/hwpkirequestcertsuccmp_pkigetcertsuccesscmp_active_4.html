PKI/4/hwPKIRequestCertSucCmp_active

Message

PKI/4/hwPKIRequestCertSucCmp_active: Requesting certificate through CMPv2 succeeded. (hwCMPUrl=[cmpurl], hwCMPName=[cmpname], CmpSessionName=[sessionname]).

Description

The local certificate is successfully applied for using CMPv2.

Parameters

Parameter Name Parameter Meaning

cmpurl

URL of the CMP server.

cmpname

Name of the CMP server.

sessionname

Name of a CMP session.

Possible Causes

Applying certificate through CMPv2 succeeded.

Procedure

1. This message is informational only, and no action is required.
