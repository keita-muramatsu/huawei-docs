MSDP/6/PEER_NTFDWN

Message

MSDP/6/PEER_NTFDWN: In the VPN instance, a session with the peer was closed because a Notification TLV was received from this peer. (VPNName=[VPNName], PeerAddr=[PeerAddr], CpuUsage=[CpuUsage], RecvMsgCount=[RecvMsgCount], SendMsgCount=[SendMsgCount], LastAliveTime=[LastAliveTime])

Description

In the VPN instance, the session with the peer was closed because a Notification TLV was received from this peer.

Parameters

Parameter Name Parameter Meaning

VPNName

Name of the VPN instance

PeerAddr

IP address of the peer

CpuUsage

CPU usage

RecvMsgCount

Number of messages received

SendMsgCount

Number of messages sent

LastAliveTime

Time when the last message was received

Possible Causes

In the VPN instance, the session with the peer was closed because a Notification TLV was received from this peer.

Procedure

  • This log message is informational only, and no action is required.
