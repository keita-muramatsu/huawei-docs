PIM/4/UPSTRMNBR_ERR

Message

PIM/4/UPSTRMNBR_ERR: In VPN instance "[vpn-instance-name]", in the PIM-SSM module, the upstream neighbor could not be found though the upstream ([source-address], [group-address]) was in Joined state.

Description

An (S, G) Join message was sent to the upstream direction, but no upstream neighbor was found on a PIM-SSM network.

Parameters

Parameter Name Parameter Meaning

vpn-instance-name

Indicates the name of a VPN instance.

source-address

Indicates a multicast source address.

group-address

Indicates a multicast group address.

Possible Causes

The unicast routing information used to implement multicast routing was incomplete or incorrect.

Procedure

1. Check whether the unicast routing information is complete and correct.

  • If the unicast routing information is complete and correct, go to Step 2.
  • If the unicast routing information is incomplete or incorrect, check unicast routing configurations.

2. Check whether PIM is enabled on the interfaces that connect the local and peer devices.

  • If PIM is enabled on both the interfaces, go to Step 3.
  • If PIM is not enabled on any of the interfaces, enable PIM.

3. Collect log information and configuration information, and then contact technical support personnel.
