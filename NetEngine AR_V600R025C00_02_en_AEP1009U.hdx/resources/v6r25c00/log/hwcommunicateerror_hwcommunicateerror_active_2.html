DEVM/2/hwCommunicateError_active

Message

DEVM/2/hwCommunicateError_active: The communication channel failed. (hwEntityPhysicalIndex=[hwEntityPhysicalIndex], entPhysicalName=[entPhysicalName], hwEntityTrapEntType=[hwEntityTrapEntType], hwEntityTrapFaultID=[hwEntityTrapFaultID], hwEntityCommunicateType=[hwEntityCommunicateType], hwEntityTrapReasonDescr=[hwEntityTrapReasonDescr])

Description

The control channel between physical entities is faulty.

Parameters

Parameter Name Parameter Meaning

hwEntityPhysicalIndex

Physical entity index

entPhysicalName

Physical entity name

hwEntityTrapEntType

Physical Entity Type

hwEntityTrapFaultID

Fault Code

hwEntityCommunicateType

Communication Type

hwEntityTrapReasonDescr

Problem Description

Possible Causes

  • Cause 1:

    1.Manual board reset ,unplug or power off

    2.The control channel between MPU and the board is abnormal

    3.The physical link from cpu to local switch is abnormal

  • Cause 2: The internal manage communication channel is subhealthy
  • Cause 3: CRC error packets are generated on the XFI interface

Procedure

  • Cause 1:

    1.Manual board reset ,unplug or power off

    2.The control channel between MPU and the board is abnormal

    3.The physical link from cpu to local switch is abnormal

    1. Check the alarm information and board registration information of the same type. Check whether the board is removed, restarted, or powered off at the time when the alarm is reported. If any of the preceding events occurs, the link will go Down. After the board is registered, the alarm will be cleared.

    2. If the board is not removed, restarted, or powered off and the alarm cannot be cleared for a long time or the alarm is repeatedly generated, inter-board link communication is abnormal. In this case, collect alarm, log, and configuration information, and contact technical support personnel.

  • Cause 2: The internal manage communication channel is subhealthy

    Collect alarm, log, and configuration information, and contact technical support personnel.

  • Cause 3: CRC error packets are generated on the XFI interface

    Collect trap, log, and configuration information, and contact technical support personnel.
