RUMNG/2/hwRuPhyStatAbnormal_active

Message

RUMNG/2/hwRuPhyStatAbnormal_active: Remote unit PHY chip is abnormal. (RemoteUnitEsn=[RemoteUnitEsn])

Description

The PHY chip of the RU is abnormal.

Parameters

Parameter Name Parameter Meaning

RemoteUnitEsn

ESN of the RU.

Possible Causes

PHY chip failed

Procedure

If the interface corresponding to the abnormal PHY chip is in Link Up state, the device automatically resets. After the reset, check whether the interface can send and receive packets normally.

(1) If not, the PHY chip is faulty. Replace the device.

(2) If so, go to Step 4.

2. If the interface corresponding to the abnormal PHY chip is in LINK DOWN state, the device does not automatically reset.

1) If you do not use this interface, no action is required.

2) If you need to use this interface, go to Step 3.

3. Run the reboot command to reset the device. After the device is reset, check whether the interface can send and receive packets normally.

(1) If not, the PHY chip is faulty. Replace the device.

(2) If so, go to Step 4.

4. End.
