LCS/3/hwGtlItemmismatch_active

Message

LCS/3/hwGtlItemmismatch_active: The license item or serial number mismatched with the main chassis or board. (ChassisIDorSlotID=[hwGtlChassisID])

Description

The license control item or serial number of the specified chassis is inconsistent with that of the active MPU of the master chassis.

Parameters

Parameter Name Parameter Meaning

hwGtlChassisID

Description of the current chassis or board ID.

Possible Causes

The license item or serial number of the chassis mismatched with that of the main chassis.

Procedure

1. Apply for a license file that matches the active MPU of the master chassis. For details, see the License Usage Guide of the corresponding product.

2. Upload the license file to the device.

3. Run the license active <filename> command in the user view to activate the license file.
