UPDATE/3/LOAD_FAIL

Message

UPDATE/3/LOAD_FAIL: Failed to load the signature database. (SyslogId=[syslog-id], Module=[module], Slot=[slot-id], CPU=[cpu-id], LoadVersion=[load-version], Duration(s)=[duration], Reason=[reason])

Description

Failed to load the signature database.

Parameters

Parameter Name Parameter Meaning

syslog-id

Sequence number of a log.

module

Module to be upgraded.

slot-id

ID of the slot where the engine resides.

cpu-id

ID of the CPU where the engine resides.

load-version

Version number of the loaded module.

duration

Loading duration, in seconds.

reason

Cause of the failure to load the signature database. The possible causes are as follows:

  • The engine is busy.
  • The update package is invalid.
  • The compilation failed.
  • The engine is in compilation.
  • The engine is abnormal.
  • The memory is insufficient.
  • The update service is not activated.
  • The update service of components expires.
  • The free space of the storage card is insufficient.
  • Failed to parse the signature database.
  • No SDB version is available for loading.

Possible Causes

The reason field in the log records the possible causes of this log.

Procedure

If the signature database fails to be loaded, perform the following operations:

  • 1. Check the engine status.
  • 2. Use a valid signature database file to perform the update again.
  • 3. Use a valid signature database file to update the signature database again.
  • 4. Try again later.
  • 5. Contact maintenance personnel.
  • 6. Perform the upgrade again later or run the forcible upgrade command to perform the upgrade.
  • 7. Purchase the signature database update service.
  • 8. Update the expiration time of the signature database update service.
  • 9. Delete invalid files from the flash memory.
  • 10. Use a valid signature database file for the update.
  • 11. Update the signature database file again.

If the fault persists, contact technical support engineers.
