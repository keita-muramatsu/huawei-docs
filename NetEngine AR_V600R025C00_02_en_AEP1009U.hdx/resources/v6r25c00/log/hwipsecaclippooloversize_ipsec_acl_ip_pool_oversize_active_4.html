IPSEC/4/hwIPsecAclIpPoolOversize_active

Message

IPSEC/4/hwIPsecAclIpPoolOversize_active: The IPSec policy references an ACL that contains an IP address pool with more than 32 configured addresses. (Virtual system name=[vsys], ACL number=[acl-num], ACL version=[acl-ver], ACL rule number=[rule-id], Wrong IP pool=[pool-type])

Description

An IP address pool with more than 32 IP addresses exists in the ACL rule referenced by an IPsec policy.

Parameters

Parameter Name Parameter Meaning

vsys

Name of the virtual system to which the ACL belongs.

acl-num

Sequence number of the ACL.

acl-ver

IP version of the ACL.

rule-id

ACL rule ID.

pool-type

Type of the address pool where the problem occurs.

Possible Causes

The IP address pool referenced by the IPsec policy's ACL rule should not be configured with more than 32 addresses; IP addresses exceeding this limit will not take effect.

Procedure

Delete the excess IP addresses from the IP address pool.
