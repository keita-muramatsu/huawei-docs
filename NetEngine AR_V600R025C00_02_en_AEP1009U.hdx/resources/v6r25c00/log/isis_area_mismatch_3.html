ISIS/3/ISIS_AREA_MISMATCH

Message

ISIS/3/ISIS_AREA_MISMATCH: IS-IS received a level-1 Hello PDU whose area address is different from the local area address. (isisSysInstance=[isisSysInstance], isisSysLevelIndex=[isisSysLevelIndex], isisCircIndex=[isisCircIndex], isisCircIfIndex=[isisCircIfIndex], isisPduFragment=[isisPduFragment], ifIndex=[ifIndex], IfName=[IfName])

Description

The area address contained in a received Level-1 Hello message is different from any local Level-1 area address.

Parameters

Parameter Name Parameter Meaning

isisSysInstance

ID of an IS-IS process

isisSysLevelIndex

IS-IS level

isisCircIndex

Circuit index of an interface

isisCircIfIndex

IfIndex of an interface

isisPduFragment

64-byte PDU header

ifIndex

IfIndex of an interface

IfName

Interface name

Possible Causes

Cause 1: The configuration was incorrect.

Cause 2: The area address field was rewritten.

Procedure

1. According to the IS-IS packet format defined in ISO10589, find the [isisPduFragment] field (in hexadecimal notation) in the command output to check the system ID of the source device.Run the display this command in the IS-IS view on the source device to check whether the area address of the source device is the same as that of the local device.

  • If the alarm is generated, go to step 3.
  • If the alarm is not generated, go to step 2.

2. (Exercise caution when running the undo network-entity command.) Run the network-entity command in the IS-IS view of the device to configure a new IS-IS area address that is the same as the area address of the local device.Check whether the fault is rectified.

  • If yes, go to Step 4.
  • If not, go to step 3.

3. Collect log and configuration information, and contact Huawei technical support personnel.

4. End.
