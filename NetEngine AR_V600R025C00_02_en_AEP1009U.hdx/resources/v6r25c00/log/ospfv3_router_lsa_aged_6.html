OSPFV3/6/OSPFV3_ROUTER_LSA_AGED

Message

OSPFV3/6/OSPFV3_ROUTER_LSA_AGED: An OSPFv3 Router-LSA is aged. (RouterId=[RouterId], ProcessId=[ProcessId], LsdbAreaId=[LsdbAreaId], LsdbLsid=[LsdbLsid], LsdbRouterId=[LsdbRouterId], LsdbSeqNum=[LsdbSeqNum], NbrRouterId=[NbrRouterId], IfName=[IfName])

Description

The Router LSA in the LSDB has reached the maximum aging time. The possible cause is that the OSPFv3 interface goes Down.

Parameters

Parameter Name Parameter Meaning

RouterId

ID of the local router

ProcessId

Process ID of the local device.

LsdbAreaId

Area ID of the LSA.

LsdbLsid

LS ID of the LSDB.

LsdbRouterId

Router ID of the LSDB.

LsdbSeqNum

Sequence number of the LSA.

NbrRouterId

Router ID of the neighbor that sends the aged LSA.

IfName

Name of the local interface that received the aged LSA.

Possible Causes

Cause 1: The status of the physical interface switched between Up and Down.

Cause 2: The status of the neighbor changed.

Procedure

1. This trap message is informational only, and no action is required.
