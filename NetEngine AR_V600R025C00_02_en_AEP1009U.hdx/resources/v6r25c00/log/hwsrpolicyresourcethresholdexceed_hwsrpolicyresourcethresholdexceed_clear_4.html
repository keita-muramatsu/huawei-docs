SRPOLICY/4/hwSrPolicyResourceThresholdExceed_clear

Message

SRPOLICY/4/hwSrPolicyResourceThresholdExceed_clear: The number of used SR Policy resources fell below the lower threshold. (hwSrPolicyResourceType=[SrPolicyResourceType], hwResourceCurrentCount=[ResourceCurrentCount], hwResourceThresholdUpperLimit=[ResourceThresholdUpperLimit], hwResourceThresholdLowerLimit=[ResourceThresholdLowerLimit], hwResourceTotalCount=[ResourceTotalCount])

Parameters

Parameter Name Parameter Meaning

SrPolicyResourceType

SR Policy resource type

  • srv6TePolicy(0)
  • srv6TePolicySegmentList(1)
  • srMplsTePolicy(3)
  • srMplsTePolicySegmentList(4)
  • srv6TePolicyGroup(5)

ResourceCurrentCount

Number of currently used SR Policy resources

ResourceThresholdUpperLimit

Upper threshold for the number of used SR Policy resources

ResourceThresholdLowerLimit

Lower threshold for the number of used SR Policy resources

ResourceTotalCount

Maximum number of SR Policy resources that can be used

Possible Causes

The total number of used SR Policy resources falls below the threshold.

Procedure

The alarm is cleared, and no action is required.
