IDM/4/USER_LOGINFAIL

Message

IDM/4/USER_LOGINFAIL: User login failed. (User Name=[user-name], Vsys=[vsys-name], Source IP=[source-ip-address], Logon Time=[logon-time], Authentication Mode=[authentication-mode], Failed Reason=[failed-reason]).

This log is supported only on AR5710-S52T2XE4, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L50T2X4-T, AR6710-L8T3TS1X2, AR6710-L50T2X4, AR5710-S8TWDSE-LTE4EA, AR5710-S28T2S2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR6710-L14T2X4, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE-NRGL, AR6710-L26T2X4-T, AR5700-H series, AR5710-S8T2XE-LTE4EA-T, AR5710-S8T1XWE, AR5710-S8T2XE.

Description

Login failures of Internet access users are logged.

Parameters

Parameter Name Parameter Meaning

user-name

Login name of an Internet access user

vsys-name

Virtual system name

source-ip-address

Source IP address of an Internet access user

logon-time

Online duration of an Internet access user

authentication-mode

Authentication mode of Internet access users. This field has the following values:

RADIUS SSO Authentication: RADIUS SSO authentication

TSM SSO Authentication: TSM SSO authentication

Local Authentication: Local authentication

Exempt Authentication: Authentication exemption

Unknown Authentication: Unknown authentication mode

Server Authentication: Server authentication

AD SSO Authentication: AD SSO authentication

failed-reason

Specifies the cause for the login failure. The possible causes are as follows:

Failed to apply for resources: indicates that the resource application fails.

Failed to insert the user entry: indicates that the entry fails to be inserted.

The IP/MAC binding conditions do not match: indicates that the IP/MAC address binding condition is not matched.

Authentication failed: indicates that the authentication fails.

The account is locked: indicates that the account is locked.

The password has expired: indicates that the password has expired.

An SSL VPN user with the same IP address already exists: indicates that an SSL VPN user with the same IP address already exists.

The account has expired: indicates that the account has expired.

Possible Causes

  • Cause 1: Failed to apply for resources.
  • Cause 2: Failed to insert the entry.
  • Cause 3: The IP/MAC address binding conditions are not matched.
  • Cause 4: The authentication fails.
  • Cause 5: The account is locked.
  • Cause 6: The password has expired.
  • Cause 7: An SSL VPN user with the same IP address already exists.
  • Cause 8: The account has expired.

Procedure

  • Cause 1: Check whether the number of Internet access users exceeds the product specification.
  • Cause 2: Collect alarm, log, and configuration information, and contact technical support personnel.
  • Cause 7: Check whether an SSL VPN user with the same IP address exists.
