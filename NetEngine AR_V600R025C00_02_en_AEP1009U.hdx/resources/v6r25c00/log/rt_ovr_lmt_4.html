BGP/4/RT_OVR_LMT

Message

BGP/4/RT_OVR_LMT: Failed to update the route, because the number of routes reached the upper limit. (LimitValue=[limit-value], LimitType=[limit-type], VpnInstance=[VpnInstance], Address Family=[addrFamily])

Description

Failed to update the routes in the address family because the number of routes reached the maximum value.

Parameters

Parameter Name Parameter Meaning

limit-value

Limit on the number of routes.

limit-type

Type of routes whose quantity is limited.

VpnInstance

Name of a VPN instance.

addrFamily

Address family information:

  • IPv4-unicast: IPv4 unicast address family
  • IPv4-multicast: IPv4 multicast address family
  • VPNv4: IPv4 VPN address family.
  • IPv6-unicast: IPv6 unicast address family
  • VPNv6: IPv6 VPN address family.
  • IPv4-flow: IPv4 flow address family

Possible Causes

Failed to add BGP routes to the routing table because the number of routes in the routing table exceeded the maximum value.

Procedure

1. Check the topology and configuration of the network, and check whether excessive routes are caused by the requirements of actual applications or incorrect topology configuration.

  • If the excessive routes are caused by the requirements of actual applications, expand the number of routes. If the alarm is not cleared, go to Step 2.
  • If the excessive routes are caused by incorrect topology configuration, reconfigure the topology. If the alarm is not cleared, go to Step 2.

2. Collect log information and configuration information, and then contact technical support personnel.
