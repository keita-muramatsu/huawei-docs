RUMNG/4/hwRuPortOpticalPowerAbnormal_active

Message

RUMNG/4/hwRuPortOpticalPowerAbnormal_active: Remote unit optical module power is abnormal. (RemoteUnitEsn=[RemoteUnitEsn], InterfaceName=[InterfaceName], ReasonDescription=[ReasonDescription])

Description

The optical module power of the RU is abnormal.

Parameters

Parameter Name Parameter Meaning

RemoteUnitEsn

ESN of the RU.

InterfaceName

Port number of the RU.

ReasonDescription

Cause of the abnormal optical module power:

·Rx power is too low: The receive optical power of the optical module is too low.

·Rx power is too high: The receive optical power of the optical module is too high.

·Tx power is too low: The transmit optical power of the optical module is too low.

·Tx power is too high: The transmit optical power of the optical module is too high.

Possible Causes

  • Cause 1: The transmit optical power of the optical module is too high. Error code: 136193
  • Cause 2: The transmit optical power of the transceiver is too low. Error code: 136194
  • Cause 3: The received optical power of the transceiver is too high. Error code: 136195
  • Cause 4: The received optical power of the transceiver is too low. Error code: 136196

Procedure

  • Cause 1: The transmit optical power of the optical module is too high. Error code: 136193

    Run the display remote-unit port [ port-id ] transceiver { connect-interface interface-type interface-number | name remote-unit-name } realtime command on the central device to check whether the transmit optical power Tx Power of the local interface is within the allowed range.

    · If so, services are not affected. Collect alarm, log, and configuration information, and contact technical support.

    · If not, go to Step 2.

    2. Add an optical attenuator to ensure that the optical power at the receive end is within the allowed range. Then, check whether the alarm is cleared.

    · If so, no further action is required.

    · If not, go to Step 3.

    3. Replace the optical module and check whether the alarm is cleared.

    · If so, no further action is required.

    · If not, collect alarm, log, and configuration information, and contact technical support.

  • Cause 2: The transmit optical power of the transceiver is too low. Error code: 136194

    Run the display remote-unit port [ port-id ] transceiver { connect-interface interface-type interface-number | name remote-unit-name } realtime command in the system view to check whether the transmit optical power Tx Power of the local interface is within the allowed range.

    • If so, services are not affected. Collect alarm, log, and configuration information, and contact technical support.
    • If not, go to Step 2.

    2. Replace the optical module and check whether the alarm is cleared.

    • If so, no further action is required.
    • If not, collect alarm, log, and configuration information, and contact technical support.
  • Cause 3: The received optical power of the transceiver is too high. Error code: 136195

    The receive optical power of the optical module was too high. Error code: 136195.

    1. Run the display remote-unit port [ port-id ] transceiver { connect-interface interface-type interface-number | name remote-unit-name } realtime command in the system view to check whether the receive optical power Rx Power of the local interface is within the allowed range.

    • If so, collect alarm, log, and configuration information, and contact technical support.
    • If not, go to Step 2.

    2. Check whether an alarm is generated at the peer end indicating that the transmit optical power is too high. If so, clear the alarm at the peer end first.

    3. Check whether the peer optical module matches the local optical module. If not, replace the peer optical module.

    4. Add an optical attenuator at the local end. It is recommended that the optical attenuator be increased by -5 dBm.

    5. If the alarm persists after the preceding operations are performed, collect alarm, log, and configuration information, and contact technical support.

  • Cause 4: The received optical power of the transceiver is too low. Error code: 136196

    Run the display remote-unit port [ port-id ] transceiver { connect-interface interface-type interface-number | name remote-unit-name } realtime command in the system view to check whether the receive optical power (Rx Power) of the local interface is within the allowed range.

    • If so, collect alarm, log, and configuration information, and contact technical support.
    • If not, go to Step 2.

    2. Check whether the peer interface is physically Up and no alarm indicating that the transmit optical power is too low is generated.

    • If so, perform an external loopback test on the local interface. If the interface goes Up, perform a loopback test level by level until the node or faulty segment where the Down event is generated is found. Then, check whether a clear alarm is generated. If no clear alarm is generated, go to Step 3.
    • If not, go to Step 3.

    3. Check whether the physical status of the peer interface is Down and whether an interface Down alarm is generated. If so, rectify the fault on the peer interface.

    • If so, recover the peer port. Then, check whether a clear alarm is generated. If no clear alarm is generated, go to Step 4.
    • If not, go to Step 4.

    4. Test whether the optical fiber is faulty.

    • If so, replace the optical fiber and check whether the alarm is cleared. If the alarm is not cleared, go to Step 6.
    • If not, go to Step 5.

    5. Replace the optical module on the local port and check whether the alarm is cleared.

    • If so, no further action is required.
    • If not, go to Step 6.

    6. Collect alarm, log, and configuration information, and contact technical support.
