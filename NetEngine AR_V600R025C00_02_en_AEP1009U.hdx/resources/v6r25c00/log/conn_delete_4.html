SDWAN-EVPN/4/CONN_DELETE

Message

SDWAN-EVPN/4/CONN_DELETE: The Connection [ConnectionID] has been deleted. (SrcSiteID=[SrcSiteID],SrcTNPID=[SrcTNPID],DestSiteID=[DestSiteID],DestTNPID=[DestTNPID],Reason=[Reason])

Description

The EVPN connection was deleted.

Parameters

Parameter Name Parameter Meaning

ConnectionID

Connection ID.

SrcSiteID

ID of the source site.

SrcTNPID

Source TNP ID.

DestSiteID

ID of the destination site.

DestTNPID

Destination TNP ID.

Reason

Reason for deleting a connection.

Possible Causes

1. The tunnel routes of the site were deleted.

2. The DH groups of devices at both ends did not match.

3. The DH group was modified.

4. The TNP was deleted.

5. The TNP went down.

6. The TNP weight was modified.

7. The connection was reset by a user.

8. The connection connectivity check timed out.

9. The connection aged out.

10. It was preempted by a connection of a site with a higher priority.

11. Redundant connections were deleted.

Procedure

1. Run the display evpn site-tnp command to check site information.

2. Run the display dtls client connection command to check DTLS information.

3. Run the display bgp evpn all routing-table command to check EVPN route information.

4. Collect alarm, log, and configuration information, and contact technical support.
