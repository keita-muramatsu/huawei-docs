SNMP/4/SNMP_BLACKLIST

Message

SNMP/4/SNMP_BLACKLIST: User [UserOrIP] = [IPAddr_UserName] blocked.

Description

The user name or IP address was listed in the blocklist.

Parameters

Parameter Name Parameter Meaning

UserOrIP

User: user name blocklist

IPAddr_UserName

IP address

Possible Causes

Cause 1: The SNMP version is incorrect.

Cause 2: The SNMP packet is too long.

Cause 3: PDU decoding is incorrect.

Cause 4: The ACL rule filters out the connection request.

Cause 5: The storage space of the buffer is insufficient and cannot process the connection request from the NMS.

Cause 6: The community name or user name is incorrect.

Cause 7: The authentication parameter or authentication parameter is incorrect.

Cause 8: The trap fails to be sent because the VB is missing or the VB packet is too small.

Cause 9: No response to the Inform message is received.

Cause 10: The Set, Get, GetNext, or GetBulk operation performed by the SNMP agent fails.

Procedure

  • Cause 1: The SNMP version is incorrect.

Check the SNMP version used by the device.

  • Cause 2: The SNMP packet is too long.

Increase the maximum length of packets that can be processed by the SNMP agent.

  • Cause 3: PDU decoding is incorrect.

This message is informational only, and no action is required.

  • Cause 4: The ACL rule filters out the connection request.

Check whether any ACL rule is applied to the community name and user name.

  • Cause 5: The storage space of the buffer is insufficient and cannot process the connection request from the NMS.

Increase the storage space of the buffer.

  • Cause 6: The community name or user name is incorrect.

Check whether the configured community name or user name is correct. If not, correct it.

  • Cause 7: The authentication parameter or authentication parameter is incorrect.

Check whether the user name and password are correct and enter the correct user name and password.

  • Cause 8: The trap fails to be sent because the VB is missing or the VB packet is too small.

Add the missing VB or increase the VB packet length.

  • Cause 9: No response to the Inform message is received.

This message is informational only, and no action is required.

  • Cause 10: The Set, Get, GetNext, or GetBulk operation performed by the SNMP agent failed.

This message is informational only, and no action is required.
