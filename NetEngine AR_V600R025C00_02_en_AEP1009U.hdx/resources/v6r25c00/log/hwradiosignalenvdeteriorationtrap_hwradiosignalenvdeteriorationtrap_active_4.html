WLAN/4/hwRadioSignalEnvDeteriorationTrap_active

Message

WLAN/4/hwRadioSignalEnvDeteriorationTrap_active: Radio signal environment deteriorates. (APMAC=[APMAC], RadioID=[RadioID], APName=[APName], PER=[PER]%, RetransmissionRate=[RetransmissionRate]%, APID=[APID], NoiseFloor=[NoiseFloor]dBm, Reason=[EnvDetReason], BadChannel=[BadChannel], InterferenceRate=[InterferenceRate])

Description

The radio signal environment deteriorated.

Parameters

Parameter Name Parameter Meaning

APMAC

MAC address of an AP.

RadioID

Radio ID.

APName

Name of an AP.

PER

Packet error rate on the wireless side.

RetransmissionRate

Current retransmission rate of the radio.

APID

AP ID.

NoiseFloor

Noise floor value detected in the current environment.

EnvDetReason

Reason of the noise floor.

BadChannel

Deteriorated channel.

InterferenceRate

Interference rate.

Possible Causes

1. The radio signal environment deteriorates. The AP automatically switches the frequency band and sends a message to the AC, which will update related attributes.

2. The AC switches the radio.

3. The AP detects that the number of Beacon Miss events reaches the threshold and notifies the AC.

Procedure

1. Run the display ap neighbor command to view neighbor information of a radio to check whether there are co-channel or adjacent-channel APs near the radio.

  • If so, run the channel command to reconfigure a channel or power for this radio to avoid the signal interference. Then go to Step 2.
  • If not, go to Step 3.

2. Check whether a radio signal environment restoration alarm is generated.

  • If so, go to Step 6.
  • If not, go to Step 3.

3. Check whether there are devices that interfere with the radio signal or make noises.

  • If so, remove these devices and then go to Step 4.
  • If not, go to Step 5.

4. Check whether a radio signal environment restoration alarm is generated.

  • If so, go to Step 6.
  • If not, go to Step 5.

5. Collect trap, log, and configuration information, and contact technical support personnel.

6. End.
