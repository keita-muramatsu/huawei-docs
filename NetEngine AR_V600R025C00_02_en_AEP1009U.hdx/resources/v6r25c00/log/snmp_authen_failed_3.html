SNMP/3/SNMP_AUTHEN_FAILED

Message

SNMP/3/SNMP_AUTHEN_FAILED: Failed to login through SNMP. (Version=[Version], UserName=[UserName], IP=[Ip], VPNName=[VpnName], RequestID=[RequestID], PDUType=[PduType], Reason=[Reason])

Description

The SNMP agent rejects the NMS login because the packet or context name is incorrect.

Parameters

Parameter Name Parameter Meaning

Version

Version number.

UserName

User name.

Ip

IP address of the NMS.

VpnName

Name of the VPN to which the IP address belongs.

RequestID

Packet ID.

PduType

Packet type.

Reason

Description of the cause of an error.

Possible Causes

Cause 1: The packet size is too large.

Cause 2: PDU decoding is incorrect.

Cause 3: The version is incorrect.

Cause 4: The context name is incorrect.

Cause 5: The buffer is full and the NMS request fails to be processed.

Cause 6: The community name is incorrect.

Cause 7: The security level of the USM user is incorrect.

Procedure

  • Cause 1: The packet size was too large.

Increase the maximum packet length that the SNMP agent can process.

  • Cause 2: The PDU decoding was incorrect.

This message is informational only, and no action is required.

  • Cause 3: The version was incorrect.

Check the SNMP version used on the device.

  • Cause 4: The context name was incorrect.

Set the context to null when the NMS delivers the packet.

  • Cause 5: The buffer was full, and the NMS request failed to be processed.

Increase the buffer space.

  • Cause 6: The community name was incorrect.

Configure a correct community name.

  • Cause 7: The security level of the USM user was incorrect.

Configure a security level that matches the configuration used for establishing a connection with the NMS.
