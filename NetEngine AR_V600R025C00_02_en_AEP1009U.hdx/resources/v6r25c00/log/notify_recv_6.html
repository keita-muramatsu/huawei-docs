BGP/6/NOTIFY_RECV

Message

BGP/6/NOTIFY_RECV: The router received a NOTIFICATION from the peer. (Peer=[peer-address], SourceInterface=[SourceInterface], ErrorCode=[error-code], SubErrorCode=[sub-error-code], NotifyInfo=[notify-info],VpnInstance=[VpnInstance], ErrorData=[error-data])

Description

A device received a NOTIFICATION message from its BGP peer.

Parameters

Parameter Name Parameter Meaning

peer-address

IP address of a peer

SourceInterface

Source interface

error-code

Error code carried in a NOTIFICATION message

sub-error-code

Error subcode carried in a NOTIFICATION message

notify-info

Notification packet information

VpnInstance

Name of a VPN instance

error-data

Summary of error data contained in a NOTIFICATION message

Possible Causes

A device received a NOTIFICATION message containing information about an error code, an error subcode, and error contents from its BGP peer.

Procedure

1. Find out the reason why the BGP peer connection is interrupted and check whether the reset bgp command is used.

  • If the command is run, wait for the reestablishment of the BGP connection.
  • If the command is not run, go to Step 2.

2. Collect information based on the error code and error subcode.

3. Collect log information and configuration information, and then contact technical support personnel.
