BGP/2/hwBgpDynamicPeerSessionExceed_clear

Message

BGP/2/hwBgpDynamicPeerSessionExceed_clear: The number of BGP dynamic peer sessions decreased below the maximum number. (MaximumNumber=[MaximumNumber], CurrentNumber=[CurrentNumber])

Parameters

Parameter Name Parameter Meaning

MaximumNumber

Maximum number of BGP dynamic peer sessions.

CurrentNumber

Current number of BGP dynamic peer sessions.

Possible Causes

The number of BGP dynamic peer sessions fell below the upper limit.

Procedure

This trap message is informational only, and no action is required.
