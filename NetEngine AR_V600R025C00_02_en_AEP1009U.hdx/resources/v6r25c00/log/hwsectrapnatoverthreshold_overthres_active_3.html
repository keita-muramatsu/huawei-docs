NAT/3/hwSecTrapNatOverThreshold_active

Message

NAT/3/hwSecTrapNatOverThreshold_active: The nat conflict rate of pool [hwNatTrapPoolName] in [hwNatTrapVsysName] system is [hwNatTrapThreshold], exceeded the upper threshold [hwNatTrapCfgThreshold], slot [hwNatTrapSlotID] cpu [hwNatTrapCpuID].

Description

The NAT port conflict rate exceeded the threshold.

Parameters

Parameter Name Parameter Meaning

hwNatTrapPoolName

Address pool name

hwNatTrapVsysName

System name

hwNatTrapThreshold

Port conflict rate.

hwNatTrapCfgThreshold

Conflict rate threshold.

hwNatTrapSlotID

Slot ID.

hwNatTrapCpuID

CPU ID.

Possible Causes

The number of ports to be NATed exceeds the number of available ports in the address pool.

Procedure

Add IP addresses to the address pool.

Run the display firewall statistics system discard command in the user view to check whether the value of NAT port alloc fail packets discarded increases rapidly.

Increase the number of addresses in the address pool based on the increase rate of packet loss, enter the nat address-group view, and configure an address segment by specifying a section.
