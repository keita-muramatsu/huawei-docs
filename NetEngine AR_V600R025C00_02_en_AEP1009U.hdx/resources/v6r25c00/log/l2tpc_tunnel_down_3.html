PPPOEC/3/L2TPC_TUNNEL_DOWN

Message

PPPOEC/3/L2TPC_TUNNEL_DOWN: The L2TP client tunnel is down. (TunnelID=[TunnelID], GroupNumber=[GroupNumber], TunnelName=[TunnelName], PeerID=[PeerID], PeerName=[PeerName], PeerIP=[PeerIP], Reason=[Reason])

Description

The L2TP client has disconnected the tunnel.

Parameters

Parameter Name Parameter Meaning

TunnelID

L2TP tunnel ID on the local end.

GroupNumber

L2TP group number.

TunnelName

L2TP tunnel name on the local end.

PeerID

L2TP tunnel ID on the remote end.

PeerName

L2TP tunnel name on the remote end.

PeerIP

Remote IP address of the L2TP tunnel.

Reason

Cause of the tunnel disconnection.

Possible Causes

1. The L2TP tunnel is reset. If it is the case, the value of the Reason field is Tunnel is reset.

2. The L2TP group configuration is changed. If it is the case, the value of the Reason field is Configuration is changed.

3. The remote end disconnects the L2TP tunnel. If it is the case, the value of the Reason field is Received StopCCN from LNS.

4. Error L2TP packets are received. If it is the case, the value of the Reason field is Packet error.

5. The connection with the LNS server is torn down. If it is the case, the value of the Reason field is Disconnected with LNS.

Procedure

1. Check the L2TP group configuration. The password must be the same as that configured on the LNS.

2. Run the display interface [Interface] command to check the link status. If a VPN instance is configured for the L2TP group, check whether the specified one is the same as the VPN instance of the interface.

3. Run the ping command to check whether the LNS is reachable.

4. Run the display l2tp tunnel command to check the tunnel status.

5. Collect trap, log, and configuration information, and contact technical support.
