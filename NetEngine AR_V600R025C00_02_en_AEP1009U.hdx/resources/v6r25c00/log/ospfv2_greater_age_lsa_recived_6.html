OSPF/6/OSPFV2_GREATER_AGE_LSA_RECIVED

Message

OSPF/6/OSPFV2_GREATER_AGE_LSA_RECIVED: OSPF receive LSA with greater Lsa-Age. (ProcessId=[ProcessId], AreaId=[AreaId], IfIndex=[IfIndex], NbrIPaddress=[NbrIpAddress], IfName=[IfName], NbrRtrId=[NbrRtrId], LsaId=[LsaId], LsaAge=[LsaAge])

Description

This object indicates that the aging time of a received LSA is greater than 1800s.

Parameters

Parameter Name Parameter Meaning

ProcessId

ID of an OSPF process

AreaId

Area ID

IfIndex

Interface index

NbrIpAddress

IP address of a neighbor

IfName

Interface name

NbrRtrId

Router ID of a neighbor

LsaId

LSA ID

LsaAge

Aging time of the LSA

Possible Causes

This object indicates that the aging time of a received LSA is greater than 1800s.

Procedure

1. Run the display ospf lsdb command to check whether the age time of the LSA (value of the Age field) is normal (less than 1800s).

  • If the age time of the LSA is abnormal, go to Step 2.
  • If the age time of the LSA is normal, go to Step 3.

2. Check whether it was changed manually.

  • If the age time of the LSA was manually adjusted, ignore this log message and go to Step 4.
  • If the age time of the LSA was not manually adjusted, go to Step 3.

3. Collect alarm and configuration information, and contact technical support personnel.

4. End.
