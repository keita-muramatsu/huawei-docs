BFD/4/STACHG_DWNTOUP

Message

BFD/4/STACHG_DWNTOUP: BFD session changed from Down to Up. (SlotNumber=[SlotNumber], Discriminator=[Discriminator], Applications=[Applications], BindInterfaceName=[BindInterfaceName], ProcessPST=[ProcessPST])

Description

The status of a BFD session configured with the WTR timer in a slot changed from Down to Up.

Parameters

Parameter Name Parameter Meaning

SlotNumber

Number of the slot where the BFD session status changes.

Discriminator

Discriminator of a session whose status changes.

Applications

Application that is bound to the BFD session.

BindInterfaceName

Name of the bound interface.

ProcessPST

Flag bit of the PST that is modified.

Possible Causes

When the WTR function was configured for the static BFD session and the session went Up after negotiation, BFD reported a BFD session Up event to the application only after the WTR timer expired.

Procedure

1. The log message is informative only, and no action is required.
