PIM/2/hwPimNeighborLoss_clear

Message

PIM/2/hwPimNeighborLoss_clear: PIM neighbor add. (NbrIntIndex=[NbrIntIndex], NbrAddrType=[NbrAddrType], NbrAddr=[NbrAddr], NbrExpiryTime=[NbrExpiryTime], InstanceID=[InstanceID], InstanceName=[InstanceName])

Parameters

Parameter Name Parameter Meaning

NbrIntIndex

Index of the interface where the neighbor relationship is established.

NbrAddrType

Address type of the neighbor:

  • 0: MIB_ADDRESSTYPE_UNKNOWN
  • 1: MIB_ADDRESSTYPE_IPV4
  • 2: MIB_ADDRESSTYPE_IPV6
  • 3: MIB_ADDRESSTYPE_IPV4Z
  • 4: MIB_ADDRESSTYPE_IPV6Z
  • 16: MIB_ADDRESSTYPE_DNS
  • 17: MIB_ADDRESSTYPE_MAX

NbrAddr

Neighbor address.

NbrExpiryTime

Time when the neighbor relationship has been timed out (in centiseconds)

InstanceID

Instance index.

InstanceName

Instance name.

Possible Causes

The PIM interface receives Hello packets again

Procedure

The trap is informational only, and no action is required.
