RIP/6/RIP_ADD_RTE_FAILED

Message

RIP/6/RIP_ADD_RTE_FAILED: Because of unsuccessful validation, routes not added to database. (Destination=[DestinationIP], Interface=[Interface], ProcessId=[ProcessID]).

Description

Failed to add routes to the database due to unsuccessful validation.

Parameters

Parameter Name Parameter Meaning

DestinationIP

Indicates the destination IP address.

Interface

Indicates the interface name.

ProcessID

Indicates the process ID.

Possible Causes

Failed to add routes to the database due to unsuccessful validation.

Procedure

1. Run the display diagnostic-information command, save the command output.

2. Collect log information and configuration information, and then contact technical support personnel.
