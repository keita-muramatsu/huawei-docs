SDWAN-EVPN/2/hwSiteCpeMaxExceed_active

Message

SDWAN-EVPN/2/hwSiteCpeMaxExceed_active: The number of sites or CPEs has reached 100% of the maximum number. (LocalSiteId=[LocalSiteId], RemoteSiteLimit=[RemoteSiteLimit], RemoteSiteNumber=[RemoteSiteNumber], RemoteCPELimit=[RemoteCPELimit], RemoteCPENumber=[RemoteCPENumber])

This log is supported only on AR6700-H series, AR6710-L8T3TS1X2, AR8100 series, AR6710-L8T3TS1X2-T, AR8700 series.

Description

The number of sites or CPEs has reached the upper limit.

Parameters

Parameter Name Parameter Meaning

LocalSiteId

Local site ID.

RemoteSiteLimit

Maximum number of sites supported by the current device.

RemoteSiteNumber

Number of sites connected to the device.

RemoteCPELimit

Maximum number of CPEs supported by the current device.

RemoteCPENumber

Number of CPEs connected to the device.

Possible Causes

The number of sites or CPEs connected to the device exceeds the upper limit.

Procedure

The number of sites or CPEs connected to the device should be reduced.
