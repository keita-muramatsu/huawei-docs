IAE/4/GPM_FAILED_TO_LOAD_DATABASE

Message

IAE/4/GPM_FAILED_TO_LOAD_DATABASE: Failed to load the database for GPM (General Pattern Match). (SlotId=[slot-id], CpuId=[cpu-id], Method="[gpm-method]", Detail="[detail]")

This log is supported only on AR5710-S52T2XE4, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L50T2X4-T, AR6710-L8T3TS1X2, AR6710-L50T2X4, AR5710-S8TWDSE-LTE4EA, AR5710-S28T2S2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR6710-L14T2X4, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE-NRGL, AR6710-L26T2X4-T, AR5700-H series, AR5710-S8T2XE-LTE4EA-T, AR5710-S8T1XWE, AR5710-S8T2XE.

Description

The GPM database fails to be loaded.

Parameters

Parameter Name Parameter Meaning

slot-id

Indicate the slot ID.

cpu-id

Indicates the CPU ID.

gpm-method

Indicates the pattern matching method. For example, HW indicates hardware-based pattern matching.

detail

Indicates log details.

Possible Causes

When the database is loaded in hardware-based pattern matching mode, a matching task is ongoing. As a result, the hardware interface returns a failure message.

Procedure

  • Run the undo gpm hardware-acceleration enable command to switch to software-based pattern matching.
  • To continue to use hardware-based pattern matching, restart the device.
