LDP/2/hwMplsLdpLastLocalAdjDown_clear

Message

LDP/2/hwMplsLdpLastLocalAdjDown_clear: A local adjacency is established. (VrfName=[VrfName], PeerLsrId=[PeerLsrId])

Parameters

Parameter Name Parameter Meaning

VrfName

Index of the VRF to which the LDP peer belongs

PeerLsrId

LDP peer ID

Possible Causes

A local adjacency is added to the peer.

Procedure

This trap message is informational only, and no action is required.
