NTP/4/hwNtpClientPathLimitExceed_active

Message

NTP/4/hwNtpClientPathLimitExceed_active: NTP client number reached the limit. (Current client number=[currentnum])

Description

NTP client number reached the limit.

Parameters

Parameter Name Parameter Meaning

currentnum

Current client number.

Possible Causes

NTP client number limit reached.

Procedure

1. Reduce the number of NTP clients and check whether the alarm is cleared.

  • Y=>3.
  • N=>2.

2. Collect alarm, log, and configuration information, and contact technical support personnel.

3. End.
