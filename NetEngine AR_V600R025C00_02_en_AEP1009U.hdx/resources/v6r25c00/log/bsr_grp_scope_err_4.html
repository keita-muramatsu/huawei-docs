PIM/4/BSR_GRP_SCOPE_ERR

Message

PIM/4/BSR_GRP_SCOPE_ERR: In VPN instance "[vpn-instance-name]", the BSR packet received from [bsr-address] and with wrong group [group-address]'s scope was ignored.

Description

A received BSR packet was ignored because the packet contained an incorrect group address scope.

Parameters

Parameter Name Parameter Meaning

vpn-instance-name

Indicates the name of a VPN instance.

bsr-address

Indicates the address of the BSR.

group-address

Indicates the address of a group.

Possible Causes

A received BSR packet contained an incorrect group address scope.

Procedure

1. If this fault occurs occasionally, this log message can be ignored.

2. If the fault frequently occurs, check the packet source, record this log message, and then contact technical support personnel.
