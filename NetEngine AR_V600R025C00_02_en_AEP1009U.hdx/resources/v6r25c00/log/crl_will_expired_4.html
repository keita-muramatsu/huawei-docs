PKI/4/CRL_WILL_EXPIRED

Message

PKI/4/CRL_WILL_EXPIRED: CRL ([issuer_name]) will expire in [hours] hours.

Description

The CRL is about to expire.

Parameters

Parameter Name Parameter Meaning

issuer_name

Name of the issuer of the CRL.

hours

Number of hours that the CRL can still be used.

Possible Causes

The CRL in the memory is about to expire.

Procedure

  • Automatic CRL update

1. Check whether the link between the device and CRL server is normal.

If not, ensure that the link between the two ends is working properly.

2. Check whether automatic CRL update is enabled.

If not, run the crl auto-update enable command in the PKI realm view.

3. Check whether the CRL-related PKI configuration is correct, such as the URL of the CRL distribution point (CDP) and CRL update mode.

If not, modify the configuration.

  • Manual CRL update

1. Select a manual CRL update method based on the service modes provided by the CA and supported by the device.

2. Run the pki import-crl command in the system view to import the CRL to the device memory.
