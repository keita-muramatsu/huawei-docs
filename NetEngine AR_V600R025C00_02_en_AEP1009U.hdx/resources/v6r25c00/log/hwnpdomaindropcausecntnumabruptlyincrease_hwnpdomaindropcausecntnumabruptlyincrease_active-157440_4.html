FWM-FRAME/4/hwNPDomainDropCauseCntNumabruptlyIncrease_clear-157440

Message

FWM-FRAME/4/hwNPDomainDropCauseCntNumabruptlyIncrease_clear: The key drop cause count falls below the preset threshold. (EntityPhysicalIndex=[EntityPhysicalIndex], EntPhysicalName=[EntPhysicalName], EntityTrapFaultID=[1], LpuSlotId=[LpuSlotId], LpuFeId=[LpuFeId], DropCauseId=[DropCauseId]).

Parameters

Parameter Name Parameter Meaning

EntityPhysicalIndex

Index of a physical entity.

EntPhysicalName

Name of a physical entity.

LpuSlotId

Slot number of the board.

LpuFeId

Component ID.

DropCauseId

Cause ID discarded by the NP.

EntityTrapFaultID

Fault code.

HelpInfo

Help information that facilitates fault locating.

Possible Causes

The alarm is cleared when the packet loss rate corresponding to Cause within a consecutive of 10 periods (5s a period) is lower than 1.5 times of the packet loss rate within the previous three periods and the value is less than 1500 pps.

Procedure

This message is informational only, and no action is required.
