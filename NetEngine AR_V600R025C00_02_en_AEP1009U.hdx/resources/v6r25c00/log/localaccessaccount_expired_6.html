AAA/6/LOCALACCESSACCOUNT_EXPIRED

Message

AAA/6/LOCALACCESSACCOUNT_EXPIRED: The local access account becomes invalid because the current time is not within the expiry date specified by user. (Account=[account])

Description

The local access account is invalid because the current time is not within the validity period set by the user.

Parameters

Parameter Name Parameter Meaning

account

Name of the local access account.

Possible Causes

The account is invalid because the current time is later than the expiration date configured using the expire-date command.

Procedure

To allow the user to use the account for authentication, you can use either of the following methods to make the account take effect:

  • Run the expire-date command to change the expiration date of the account.
  • Run the undo expire-date command to delete the expiration date configuration so that the account is always valid.
