IFNET/4/COLLISION_CNT_EXCEED

Message

IFNET/4/COLLISION_CNT_EXCEED: Collision count reached maximum value for IPv6 CGA address [STRING1] on interface [STRING2].

Description

The IPv6 CGA address conflict detection count reached the maximum number allowed by an interface.

Parameters

Parameter Name Parameter Meaning

STRING1

IPv6 CGA address.

STRING2

Name of an interface with the IPv6 CGA address.

Possible Causes

The IPv6 CGA address conflict detection count reached the maximum number allowed by the interface.

Procedure

  • Configure a different IP address, for example, a different IP prefix or different key.
