TTY/4/TTY_LOGINFAILED

Message

TTY/4/TTY_LOGINFAILED: Failed to login. (Ip=[IpAddress],UserName=[UserName],Times=[Times],AccessType=[AccessType],VpnName=[VpnName])

Description

The user fails to log in.

Parameters

Parameter Name Parameter Meaning

IpAddress

IP address of a user.

UserName

User name. If a user logs in to the system in password authentication mode and user information cannot be obtained, ** is displayed.

Times

Time when a user fails to log in.

AccessType

User login type.

VpnName

VPN name of a user.

Possible Causes

The login user name or password is incorrect, or the number of login users reaches the upper limit.

Procedure

1. Check whether the user name and password are correct.

  • If not, enter the correct user name and password.
  • If so, go to Step 2.

2. Collect log and configuration information, and contact technical support personnel.
