FWD/1/hwInnerPortLinkDown_active

Message

FWD/1/hwInnerPortLinkDown_active: The link of the internal communication interface went down. (slot Id: [hwInnerPortSlotId], cpu Id: [hwInnerPortCpuId], port Id: [hwInnerPortPortId]).

Description

The link status of the internal communication interface went Down.

Parameters

Parameter Name Parameter Meaning

hwInnerPortSlotId

Slot ID.

hwInnerPortCpuId

CPU No.

hwInnerPortPortId

Port number

Possible Causes

The link of the internal communication interface went down.

Procedure

Restart or replace the service board.
