SRPOLICY/2/hwSrPolicyResourceTotalCountExceed_active

Message

SRPOLICY/2/hwSrPolicyResourceTotalCountExceed_active: The total number of SR Policy resources reached the maximum number of SR Policy resources that can be used. (hwSrPolicyResourceType=[SrPolicyResourceType], hwResourceCurrentCount=[ResourceCurrentCount], hwResourceTotalCount=[ResourceTotalCount])

Description

The total number of SR Policy resources exceeded the maximum number of SR Policy resources that can be used.

Parameters

Parameter Name Parameter Meaning

SrPolicyResourceType

SR Policy resource type

  • srv6TePolicy(0)
  • srv6TePolicySegmentList(1)
  • srMplsTePolicy(3)
  • srMplsTePolicySegmentList(4)
  • srv6TePolicyGroup(5)

ResourceCurrentCount

Number of currently used SR Policy resources

ResourceTotalCount

Maximum number of SR Policy resources that can be used

Possible Causes

The total number of SR Policy resources of the specified type reached the maximum number of SR Policy resources that can be used.

Procedure

Check the threshold-crossing information of specific SR Policy resources based on SrPolicyResourceType.
