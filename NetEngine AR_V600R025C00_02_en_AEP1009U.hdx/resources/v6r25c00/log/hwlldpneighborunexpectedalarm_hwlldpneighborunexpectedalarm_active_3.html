LLDP/3/hwlldpNeighborUnexpectedAlarm_active

Message

LLDP/3/hwlldpNeighborUnexpectedAlarm_active: The neighbor information of LLDP packet is not as expected. (Interface=[interfaceName], RemoteChassisType=[chassisSubType], RemoteChassisId=[chassisId], RemotePortIdType=[portIdSubType], RemotePortId=[portId], Reason=[lldpReasonString])

Description

This alarm is reported when the neighbor information carried in the LLDP packet received by an interface is the same as that of the current interface.

Parameters

Parameter Name Parameter Meaning

interfaceName

Name of the interface

chassisSubType

Chassis type of the LLDP neighbor.

chassisId

Chassis ID of an LLDP neighbor.

portIdSubType

Interface ID type of an LLDP neighbor.

portId

Interface ID of an LLDP neighbor.

lldpReasonString

Cause of the LLDP neighbor exception.

Possible Causes

  • Cause 1: Local loopback is configured on the port.
  • Cause 2: A self-loop occurs on the network connected to the port.

Procedure

  • Cause 1: Local loopback is configured on the port.

    1. Check whether local loopback is configured on the port where the log is generated.

    • If so, go to Step 2.
    • If not, go to Step 3.

    2. Delete the local loopback configuration, and check whether the alarm is cleared. If the alarm persists, go to Step 3.

    3. Collect alarm and configuration information, and contact technical support personnel.

  • Cause 2: A self-loop occurs on the network connected to the port.

    1. Check the networking of the network connected to the port and check whether a self-loop occurs on the hub.

    • If so, go to Step 2.
    • If not, go to Step 3.

    2. Remove the self-looped network cable, and check whether the alarm is cleared. If the alarm persists, go to Step 3.

    3. Collect alarm and configuration information, and contact technical support personnel.
