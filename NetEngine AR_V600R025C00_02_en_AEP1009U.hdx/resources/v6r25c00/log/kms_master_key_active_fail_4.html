PSSP_KMS/4/KMS_MASTER_KEY_ACTIVE_FAIL

Message

PSSP_KMS/4/KMS_MASTER_KEY_ACTIVE_FAIL: The system master key actives unsuccessfully.

Description

The system master key fails to be activated.

Parameters

None

Possible Causes

The system master key fails to be activated.

Procedure

Check whether the boards in the system are running properly. Collect information and contact software engineers.
