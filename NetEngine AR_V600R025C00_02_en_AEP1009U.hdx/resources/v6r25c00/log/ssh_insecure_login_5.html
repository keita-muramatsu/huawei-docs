SSH/5/SSH_INSECURE_LOGIN

Message

SSH/5/SSH_INSECURE_LOGIN: SSH server login is insecure. (ServiceType=[ServiceType], UserName=[UserName], IPAddress=[IPAddress], VPNInstanceName=[VPNInstanceName], Reason=[Reason])

Description

A user successfully logged in to the SSH server using an insecure algorithm or a key pair of an insecure length.

Parameters

Parameter Name Parameter Meaning

ServiceType

Protocol type.

UserName

User name.

IPAddress

IP address of the client.

VPNInstanceName

Name of a VPN instance.

Reason

Reason for insecure login. The options are as follows:

-·SSH·server·connection·is·established·with·one·of·the·following·insecure·cipher·algorithms:·des_cbc,·3des_cbc,·arcfour128,·arcfour256,·aes128_cbc,·aes192_cbc,·aes256_cbc,·md5,·md5_96,·sha1,·sha1_96·and·sha2_256_96:·The SSH server uses one of the following insecure encryption algorithms to establish a connection: des_cbc, 3des_cbc, arcfour128, arcfour256, aes128_cbc, aes192_cbc, aes256_cbc, md5, md5_96, sha1, sha1_96, and sha2_256_96.

-·SSH·server·connection·is·established·with·one·of·the·following·insecure·HMAC·algorithms:·md5,·md5_96,·sha1,·sha1_96·and·sha2_256_96: The SSH server uses one of the following insecure HMAC-based authentication algorithms to establish a connection: md5, md5_96, sha1, sha1_96, and sha2_256_96.

-·Length·of·identity·key·(RSA,·DSA)·is·less·than·2048·bits: The RSA or DSA key pair length is less than 2048 bits.

Possible Causes

Cause 1: The SSH server connection was established using one of the following insecure encryption algorithms: des_cbc, 3des_cbc, arcfour128, arcfour256, aes128_cbc, aes192_cbc, aes256_cbc, md5, md5_96, sha1, sha1_96, and sha2_256_96.

Cause 2: The SSH server connection was established using one of the following insecure HMAC-based authentication algorithms: md5, md5_96, sha1, sha1_96, and sha2_256_96.

Cause 3: The RSA or DSA key pair length was less than 2048 bits.

Procedure

Cause 1: Use a secure encryption algorithm, such as aes128_ctr and aes256_ctr.

Cause 2: Use a secure HMAC-based authentication algorithm, such as sha2_256.

Cause 3: Set the length of the RSA or DSA key pair to 2048 bits.
