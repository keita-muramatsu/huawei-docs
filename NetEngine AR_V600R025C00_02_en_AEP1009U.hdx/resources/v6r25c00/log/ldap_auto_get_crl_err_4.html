PKI/4/LDAP_AUTO_GET_CRL_ERR

Message

PKI/4/LDAP_AUTO_GET_CRL_ERR: Realm [realm_name] failed to obtain CRL through LDAP. The reason for failure is:[reason_for_failure].

Description

The CRL fails to be automatically or immediately updated in the domain through LDAP.

Parameters

Parameter Name Parameter Meaning

realm_name

PKI domain name.

reason_for_failure

Failure cause:

Cause 1: Failed to connect to the server or the response is insuccess. (Failed to connect to the server or the server failed to respond to the request.)

Cause 2: The response's group data length is invalid. (The data length of the content returned by the server is invalid.)

Cause 3: Failed to save the file to device. (Failed to save the file to the device.)

Possible Causes

  • The link between the device and CRL server is disconnected.
  • The CRL server does not function properly.
  • The PKI configuration on the device is incorrect.

Procedure

1. Run the ping command to check whether the link between the device and CRL server is reachable.

  • If the route is unreachable, ensure that the interface and IP address are correctly configured.
  • If the route is reachable, go to Step 2.

2. Check whether the CRL server is functioning properly.

  • If the CRL service is abnormal, ensure that the CRL service has been enabled on the CRL server and is working properly.
  • If so, go to Step 3.

3. Check whether the PKI configuration of the device is correct, such as the URL of the CRL distribution point and CRL update mode.

  • If the configuration is incorrect, modify the configuration.
  • If so, go to Step 4.

4. Collect related information and contact technical support personnel.
