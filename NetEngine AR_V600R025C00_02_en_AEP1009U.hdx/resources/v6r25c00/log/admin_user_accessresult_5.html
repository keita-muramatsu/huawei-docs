CM/5/ADMIN_USER_ACCESSRESULT

Message

CM/5/ADMIN_USER_ACCESSRESULT: USER_INFO_AUTHENTICATION. ([info])

Description

A user is authenticated.

Parameters

Parameter Name Parameter Meaning

info

USER_INFO_AUTHENTICATION: administrator authentication.

DEVICEMAC: MAC address of the device.

DEVICENAME: device name.

USER: user name.

MAC: indicates the MAC address of a user.

IPADDRESS: indicates the IP address of a user.

TIME: indicates the system time.

ZONE: indicates the time zone.

ERRCODE: error code of a user authentication failure.

RESULT: user authentication result.

UclGroupName: UCL group name.

UclGroupId: indicates the ID of a UCL group.

AUTHENPLACE: user authentication location.

CIB_ID: CIB ID.

INTERFACE: access interface.

ACCESS_TYPE: access type.

VLAN: vlan id.

VPNNAME: indicates the VPN name of a user.

SelectRDSIP: RADIUS server that fails to be authenticated.

IP address of the intermediate RADIUS server (which has been selected but not in use). The value - indicates that the authentication mode is not RADIUS or no intermediate RADIUS server is available.

SeclectERRCODE: error code of a RADIUS authentication failure.

Reason why the intermediate RADIUS server is not used. The value - indicates that the authentication mode is not RADIUS or only one RADIUS server is available. Otherwise, the value is 205.

RDSIP: IP address of the RADIUS server.

AuthFailType: indicates the access type of the user who fails to be authenticated.

If the authentication is successful, None is displayed. If the authentication fails, the failure cause is displayed. In other scenarios (for example, if the user is in pre-connection state), this field is not displayed.

This field is not supported in user login and authorization logs.

AUTHID: ID of the user for sending logs to the analyzer.

Possible Causes

A user initiates authentication, pre-authentication, or user group authorization information modification.

Procedure

If user authentication fails, locate the fault or contact technical support. If user authentication is successful, no action is required.
