SSL/2/hwSSLCertificateExpiredEarlyWarning_active

Message

SSL/2/hwSSLCertificateExpiredEarlyWarning_active: The SSL certificate will expire. (CertificateName=[hwSSLCertificateName], CertificateType=[hwSSLCertificateType], BeginTime=[hwSSLCertificateBeginTime], EndTime=[hwSSLCertificateEndTime])

Description

This alarm is generated 90 days before the SSL certificate expires.

Parameters

Parameter Name Parameter Meaning

hwSSLCertificateName

The name of the Certificate File

hwSSLCertificateType

The type of the Certificate File

hwSSLCertificateBeginTime

The begin time of the Certificate File

hwSSLCertificateEndTime

The end time of the Certificate File

Possible Causes

The SSL certificate is about to expire

Procedure

1. Upload the valid certificate to the security path of the device based on the type of the certificate that is about to expire.

2. After the upload is complete, if the trust certificate is about to expire, run the trusted-ca load command to replace the certificate as follows:

  • Command for loading an ASN1 trusted-CA file for the SSL policy: trusted-ca load asn1-ca filename
  • Command for loading a PEM trusted-CA file for the SSL policy: trusted-ca load pem-ca filename
  • Command for loading a PFX trusted-CA file for the SSL policy: trusted-ca load pfx-ca filename auth-code cipher password

3. If the identity certificate is about to expire, run the certificate load command to replace the certificate as follows:

  • Command for loading a PEM certificate for the SSL policy: certificate load pem-cert filename key-pair dsa key-file filename auth-code cipher password
  • Command for loading a PFX certificate for the SSL policy: certificate load pfx-cert filename key-pair rsa key-file filename auth-code cipher password
  • Command for loading a PEM certificate chain for the SSL policy: certificate load pem-chain filename key-pair rsa key-file filename auth-code cipher password
