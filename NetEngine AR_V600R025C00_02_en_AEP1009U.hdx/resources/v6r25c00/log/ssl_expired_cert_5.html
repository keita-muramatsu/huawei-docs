SSL/5/SSL_EXPIRED_CERT

Message

SSL/5/SSL_EXPIRED_CERT: SSL certificate expired. (CertFileName = [CertFileName], CertType = [CertType], CertValidityPeriod = [CertValidityPeriod], CurrentSystemTime = [CurrentSystemTime])

Description

The SSL certificate has expired.

Parameters

Parameter Name Parameter Meaning

CertFileName

Certificate name.

CertType

Certificate type.

CertValidityPeriod

Certificate validity period.

CurrentSystemTime

Current time.

Possible Causes

Cause 1: The current system time is incorrect and is not within the validity period of the certificate.

Cause 2: The current system time is correct, but the end time of the certificate validity period arrives.

Cause 3: The current system time is correct, but the start time of the certificate validity period has not arrived.

Procedure

Correct the system time and regenerate a certificate to ensure that the system time is within the validity period of the certificate.
