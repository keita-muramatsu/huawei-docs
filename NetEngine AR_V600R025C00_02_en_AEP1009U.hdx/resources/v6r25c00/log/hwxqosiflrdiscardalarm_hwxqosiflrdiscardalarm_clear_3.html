QOS/3/hwXQOSIfLrDiscardAlarm_clear

Message

QOS/3/hwXQOSIfLrDiscardAlarm_clear: The outgoing traffic on the interface recovered from congestion.(Interface=[hwXQoSIfLrCfgIfName], CIR=[hwXQoSIfLrCir] kbps, alarm threshold=[hwXQoSTrapThreshold] of the percentage)

Parameters

Parameter Name Parameter Meaning

hwXQoSIfLrCfgIfName

Name of the interface configured with traffic shaping.

hwXQoSIfLrCir

CIR.

hwXQoSTrapThreshold

Alarm threshold.

Possible Causes

The rate of outgoing traffic on an interface is smaller than the alarm threshold for the CIR.

Procedure

1. This message is informational only and no action is required.
