ARP/4/REPEAT_REQUEST

Message

ARP/4/REPEAT_REQUEST: Receiving ARP request packets for learned entries exceed 30 times within 3 minutes. (Received IpAddress=[IpAddress], Received MacAddress=[MacAddress], Local InterfaceName=[LocalIfName], Received VLAN=[RecvPeVlan], Received INNER-VLAN=[RecvCeVlan], Received InterfaceName=[RecvIfName])

Description

The device received more than 30 ARP request packets from the same user within 3 minutes to request the local interface IP address.

Parameters

Parameter Name Parameter Meaning

IpAddress

Source IP address of packets.

MacAddress

Source MAC address of packets.

LocalIfName

Local Interface Name

RecvPeVlan

VLAN ID of the received packet

RecvCeVlan

Inner VLAN ID of the received packet

RecvIfName

Name of the interface that receives packets

Possible Causes

The device learned the ARP entry of the user and received more than 30 ARP request packets from the user within 3 minutes to request the local interface IP address. The possible causes are as follows:

1. The peer device frequently sent keepalive packets in a short period.

2. The peer device did not receive the response packet from the local device.

Procedure

  • Cause 1: The peer device frequently sent keepalive packets in a short period.

Check whether this situation is normal based on the interface, VLAN, and IP address information in the log.

  • Cause 2: The peer device did not receive the response packet from the local device.

Check whether the configuration and status of the link between the transmit end and receive end are normal based on the interface, VLAN, and IP address information in the log. If the configuration and status are normal, collect related log and configuration information and contact technical support personnel.
