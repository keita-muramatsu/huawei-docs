HRP/2/VRRP_PEER_DOWN

Message

HRP/2/VRRP_PEER_DOWN: The VRRP link went down. (Interface=[interface-name], VrId=[virtual-router-ID], InetType=[vrrp-protocol-type]).

Description

The link between the service interfaces of the active and standby devices is faulty. As a result, the standby device cannot receive VRRP advertisement packets from the interface of the active device.

Parameters

Parameter Name Parameter Meaning

interface-name

Interface name.

virtual-router-ID

ID of a VRRP group.

vrrp-protocol-type

VRRP protocol type. The value can be VRRP4 or VRRP6.

Possible Causes

  • The service interface on the master or backup device goes Down.
  • The switch connected to the service interfaces of the active and standby devices is faulty.

Procedure

1. Check whether the service interface on the master device is Down.

2. Check whether the switches connected to the service interfaces of the active and standby devices are faulty.
