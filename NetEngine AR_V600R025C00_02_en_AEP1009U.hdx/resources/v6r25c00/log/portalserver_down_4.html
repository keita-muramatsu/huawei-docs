WEB/4/PORTALSERVER_DOWN

Message

WEB/4/PORTALSERVER_DOWN: The portal server is down. (IP=[IPADDR])

Description

The communication with the Portal server is interrupted.

Parameters

Parameter Name Parameter Meaning

IPADDR

IP address of the Portal server.

Possible Causes

The device detects that the Portal server status changes from Up to Down.

Procedure

1. Run the display portal-server state command to check whether the deployed Portal server works normally and whether the Portal service can be used normally.

  • If the Portal server is normal, check the network connection between the Portal server and the device. If the network is disconnected, restore it.
  • If the Portal server is abnormal, restore the Portal server as soon as possible.

2. Collect log information and contact technical support personnel.
