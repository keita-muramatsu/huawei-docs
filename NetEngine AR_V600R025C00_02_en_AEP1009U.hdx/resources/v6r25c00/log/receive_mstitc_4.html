MSTP/4/RECEIVE_MSTITC

Message

MSTP/4/RECEIVE_MSTITC: MSTP received BPDU with TC, MSTP process [ProcessID] instance [InstanceID], port name is [PortName], pwName is [PwName]. (VlanId=[VlanId], SrcMac=[SrcMac])

Description

The MSTP MSTI received the BPDU with a TC flag.

Parameters

Parameter Name Parameter Meaning

ProcessID

Indicates the ID of an MSTP instance.

InstanceID

Indicates the ID of an instance.

PortName

Indicates the name of a port.

PwName

Indicates the name of a PW port.

VlanId

Indicates the VLAN ID.

SrcMac

Indicates the source MAC address.

Possible Causes

MSTP received the BPDU with the TC flag.

Procedure

  • This log message is informational only, and no action is required.
