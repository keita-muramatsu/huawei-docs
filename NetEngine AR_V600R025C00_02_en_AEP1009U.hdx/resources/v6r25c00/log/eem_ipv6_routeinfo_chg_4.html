RM/4/EEM_IPV6_ROUTEINFO_CHG

Message

RM/4/EEM_IPV6_ROUTEINFO_CHG: The routing item changed. (detectorId=[DetectorId], vrfId=[VrfId], network=[Network], mask=[Mask], type=[Type], protocol=[Protocol], nexthop=[Nexthop], interface=[Interface], perference=[Perf], cost=[Cost])

Description

Routes changed in the RM module, and this object is used for the OPS to collect log information rather than recording logs.

Parameters

Parameter Name Parameter Meaning

DetectorId

Route change event subscription ID

VrfId

VPN instance ID

Network

Destination IP address of a route

Mask

Route mask

Type

Route change type

Protocol

Type of a routing protocol

Nexthop

Next hop IP address of a route

Interface

Outbound interface of a route

Perf

Route priority

Cost

Route cost

Possible Causes

Route change events were subscribed, and routes changed.

Procedure

This log message is informational only, and no action is required.
