ISIS/2/isisAdjAfDown_clear

Message

ISIS/2/isisAdjAfDown_clear: One address family of an IS-IS dual-stack neighbor is restored. (SysInstance=[hwisisSysInstance], SysLevel=[hwisisSysLevelIndex], IfIndex=[ifIndex], IfName=[ifName], AdjSysID=[hwIsisAdjSysID], AddressFamily=[hwIsisAddressFamily], Reason=[hwIsisAdjAfDownReason])

Parameters

Parameter Name Parameter Meaning

hwisisSysInstance

ID of an IS-IS process.

hwisisSysLevelIndex

Neighbor type.

ifIndex

Interface index.

ifName

Name of the interface

hwIsisAdjSysID

Neighbor system ID.

hwIsisAddressFamily

Address family.

hwIsisAdjAfDownReason

Cause of the alarm.

  • The neighbor went full down
  • The neighbor went full init
  • The neighbor went full up
  • The neighbor went up newly, but the protocol is changed
  • The neighbor state is not change, but the protocol is changed

Possible Causes

The two address families of the IS-IS dual-stack neighbor are in the same state.

Procedure

This message is informational only, and no action is required.
