HIPS/6/POLICYACTIVATEFINISH

Message

HIPS/6/POLICYACTIVATEFINISH: The policy file activation has been finished. (TaskId=[task-id],Result=[result])

Description

The HIPS policy file activation result is reported.

Parameters

Parameter Name Parameter Meaning

task-id

Task ID.

result

Policy file activation result.

Possible Causes

The NMS delivers a new policy file, and the HIPS activation result is reported.

Procedure

This log message is informational only, and no action is required.
