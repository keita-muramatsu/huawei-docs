WEBM/4/IMPORTFAIL

Message

WEBM/4/IMPORTFAIL: The user failed to import the configuration into the system on the web UI. (Ip=[ip-address], User=[user-name], Vrf=[virtual-system], File Name=[file-name])

Description

Importing files into the virtual system on the web UI failed.

Parameters

Parameter Name Parameter Meaning

ip-address

IP address of a user.

user-name

User name.

virtual-system

The public field is displayed.

file-name

File name.

Possible Causes

Importing files into the virtual system on the web UI failed.

Procedure

Check whether the format of the file to be imported is correct.
