OSPFV3/1/ospfv3RouteLoopDetected_clear

Message

OSPFV3/1/ospfv3RouteLoopDetected_clear: The OSPFv3 routing loop is cleared. (LoopType=[LoopType], DetectProtocolAttr=[DetectProtocolAttr], RedistributeID1=[RedistributeID1], RedistributeID2=[RedistributeID2])

Parameters

Parameter Name Parameter Meaning

LoopType

Routing loop detection type.

DetectProtocolAttr

Information about the loop detection protocol.

RedistributeID1

Re-advertise device ID 1.

RedistributeID2

Re-advertise device ID 2.

Possible Causes

The alarm for the OSPFv3 routing loop detected by the device is cleared.

Procedure

This message is informational only, and no action is required.
