BGP/2/bgpBackwardTransition_clear

Message

BGP/2/bgpBackwardTransition_clear: The BGP FSM enters the Established state. (BgpPeerRemoteAddr=[PeerIpv4Ipv6Addr], BgpPeerLastError=[PeerLastError], BgpPeerState=[PeerState], LocalIfName=[LocalIfName], Reason=[Reason], Description=[Description])

Parameters

Parameter Name Parameter Meaning

PeerIpv4Ipv6Addr

Peer address. For an IPv4 peer, this MIB object reports an IPv4 peer address. For an IPv6 peer, this MIB object reports the router ID of the IPv6 peer. To view the address of an IPv6 peer, query the hwBgpBackwardTransition alarm.

This alarm and the hwBgpBackwardTransition alarm are reported at the same time when a BGP peer relationship is established or interrupted.

PeerLastError

Error code returned when the peer was disconnected last time.

The value of this parameter is displayed in the format of [ErrorCode][ErrorSubCode], where [ErrorCode] indicates an error code and [ErrorSubCode] indicates an error subcode.For example, in the value 35, 3 indicates an error code and 5 indicates an error subcode.The value 0 indicates that no error occurs.For the meanings and possible causes of error codes, see the NOTIFICATION packet in BGP Principles - BGP Packet Format. The NOTIFICATION packet is used to process various errors in the BGP process.

PeerState

Peer status:

  • 1: indicates that the status is Down.
  • 6: indicates that the status is Up.

LocalIfName

Local interface name.

Reason

Cause of the peer disconnection.

  • Configuration lead peer down: The peer is disconnected due to the configuration.
  • Receive notification: A Notification message is received.
  • Receive error packet: An error packet is received.
  • Hold timer expire: The Hold timer expires.
  • Remote peer not reachable: The remote peer is unreachable.
  • Direct connect-interface down: The directly connected interface is Down.
  • Route limit: The number of routes reaches the upper limit.
  • System memory overloaded: The system memory is overloaded.

Description

Description of a neighbor.

Possible Causes

  • Cause 8:Alarm clear
  • Cause 10:The peer is deleted

Procedure

  • This message is informational only, and no action is required.
