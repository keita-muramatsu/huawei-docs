ARP/4/ARP_SEC_SPEED_LIMIT

Message

ARP/4/ARP_SEC_SPEED_LIMIT: Packet speed exceeded the configured speed limit. (IfIndex=[IfIndex], SuppressValue=[SupValue], CurrentValue=[CurValue], SuppressType=[SupType], SourceIP=[SrcIp], DestinationIP=[DstIp], VpnInstance name=[VpnName])

Description

The transmit rate of ARP packets exceeded the configured rate limit.

Parameters

Parameter Name Parameter Meaning

IfIndex

Interface index.

SupValue

Rate limit of ARP packets or ARP Miss messages.

CurValue

Type of packets that are suppressed: ARP packets or ARP Miss messages.

SupType

Type of packets that are suppressed: ARP packets or ARP Miss messages.

SrcIp

Source IP addresses of ARP packets or ARP Miss messages.

DstIp

Destination IP addresses of ARP packets or ARP Miss messages.

VpnName

VPN instances that ARP packets or ARP Miss messages belong to.

Possible Causes

Cause 1: The transmit rate of ARP packets exceeded the configured rate limit.

Cause 2: The transmit rate of ARP Miss messages exceeded the configured rate limit.

Procedure

  • Cause 1: The rate at which ARP packets are sent exceeds the configured rate limit.

1. Run the display arp anti-attack rate-limit command to check the rate limit configured for ARP packets on the device.

2. Run the arp anti-attack rate-limit destination-ip maximum <maximum> command to reconfigure the rate limit (it must be greater than the value obtained in Step 1 but cannot exceed 65536) for ARP packets. Then, check whether the alarm is cleared.

  • If yes, go to Step 4.
  • If no, go to Step 3.

3. Collect log and configuration information, and contact technical support engineers.

4. End.

  • Cause 2: The rate at which ARP Miss messages are sent exceeds the configured rate limit.

1. Run the display arp miss anti-attack rate-limit command to check the rate limit configured for ARP Miss messages on the device.

2. Run the arp miss anti-attack rate-limit source-ip maximum <maximum> command to reconfigure the rate limit (it must be greater than the value obtained in Step 1 but cannot exceed 65536) for ARP Miss messages. Then, check whether the alarm is cleared.

  • If yes, go to Step 4.
  • If no, go to Step 3.

3. Collect log and configuration information, and contact technical support engineers.

4. End.
