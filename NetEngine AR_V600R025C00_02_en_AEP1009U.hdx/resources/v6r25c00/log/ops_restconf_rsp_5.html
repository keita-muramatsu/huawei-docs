OPS/5/OPS_RESTCONF_RSP

Message

OPS/5/OPS_RESTCONF_RSP: OPS operation information. (UserName=[UserName], SourceAddress=[SourceAddress], DestAddress=[DestAddress], VpnName=[VpnName], SessionId=[SessionId], StatusCode=[StatusCode], ReplyBody=[ReplyBody], AssistantName=[AssistantName])

Description

OPS RESTful API response information.

Parameters

Parameter Name Parameter Meaning

UserName

User name.

Operation triggered by OPS scheduling. The value is _OPS_.

SourceAddress

Source IP address.

DestAddress

Destination IP address.

VpnName

Name of the VPN instance to which the session belongs.

SessionId

Session flag.

StatusCode

Status code.

ReplyBody

Returned message body.

AssistantName

Assistant name.

Logs triggered by the maintenance assistant. The value is the maintenance assistant name.

Logs triggered by packets delivered by the HTTP client. The value is empty.

For logs triggered in other modes, the value is _OPS_.

Possible Causes

Perform OPS RESTful API operations.

Procedure

This message is informational only, and no action is required.
