RUMNG/4/hwRuMngOffline

Message

RUMNG/4/hwRuMngOffline: The remote-unit is offline. (RemoteUnitEsn=[RemoteUnitEsn], ConnectInterface=[ConnectInterface], Reason=[Reason])

Description

The RU goes offline.

Parameters

Parameter Name Parameter Meaning

RemoteUnitEsn

ESN of the RU.

ConnectInterface

Interconnection port.

Reason

Disconnection reason. The options are as follows:

  • Unknown: The RU goes offline due to unknown reasons.
  • No heartbeat: The RU goes offline since no heartbeat is detected. Check whether the RU's link is faulty.
  • Port down: The RU goes offline because the port is Down. Check why the port is Down.
  • Multi-RU on port: A port is connected to multiple RUs. As a result, the RUs go offline. You need to check whether a port is connected to multiple RUs.
  • Manual: The RU goes offline after it is manually restarted.
  • Upgrade: The RU goes offline after it is upgraded and restarted.

Possible Causes

Determine the RU disconnection reason based on the Reason field.

Procedure

  • Unknown: Collect alarm and configuration information, and contact technical support personnel.
  • No heartbeat: The RU goes offline since no heartbeat is detected. Check whether the RU's link or the RU is faulty, and contact technical support personnel.
  • Port down: The RU goes offline because the port is Down. Check why the port is Down.
  • Multi-RU on port: A port is connected to multiple RUs. As a result, the RUs go offline. Check whether a port is connected to multiple RUs. An Eth-Trunk interface can connect to only one online RU.
  • Manual: The RU goes offline after it is manually restarted. This is a normal situation, and no action is required.
  • Upgrade: The RU goes offline after it is upgraded and restarted. This is a normal situation, and no action is required.
