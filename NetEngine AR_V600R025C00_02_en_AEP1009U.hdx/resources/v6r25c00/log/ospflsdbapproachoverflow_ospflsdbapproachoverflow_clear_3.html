OSPF/3/ospfLsdbApproachOverflow_clear

Message

OSPF/3/ospfLsdbApproachOverflow_clear: The number of AS-external LSAs in the LSDB of an OSPF process is leaving the configured maximum number. (hwOspfv2ProcessIdIndex=[hwOspfv2ProcessIdIndex], hwOspfv2Threshold=[hwOspfv2Threshold])

Parameters

Parameter Name Parameter Meaning

hwOspfv2ProcessIdIndex

Indicates the OSPF process ID.

hwOspfv2Threshold

Indicates 90% of the maximum number of external routes allowed in the OSPF LSDB.

Possible Causes

The number of external routes in the OSPF LSDB fell below 90% of the maximum number allowed.

Procedure

  • This trap message is informational only, and no action is required.
