HRP/1/hwHrpDeviceID_clear

Message

HRP/1/hwHrpDeviceID_clear: The heartbeat status of the high availability system is restored. (HRP link changes to=[trap-link-state], Local device ID is=[trap-local-id], peer device ID is=[trap-peer-id])

Parameters

Parameter Name Parameter Meaning

trap-link-state

Connection status of hot standby.

trap-local-id

MAC address of the management network port on the local device.

trap-peer-id

MAC address of the management network port on the remote device.

Possible Causes

  • Cause 1:Manually disable the hot standby function.
  • Cause 2:The link between the heartbeat interfaces of the active and standby devices recovers.
  • Cause 3:The active or standby device recovers and can send and receive heartbeat packets.
  • Cause 4:In dual-device hot backup of chassis-shaped devices, after an active/standby main control board switchover occurs on one device, the link on the management plane of the two devices recovers.

Procedure

This message is informational only, and no action is required.
