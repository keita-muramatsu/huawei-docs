WLAN/4/hwWlanApPKILocalCertNearlyExpiredTrap_active

Message

WLAN/4/hwWlanApPKILocalCertNearlyExpiredTrap_active: The local certificate is about to expire. (APMAC=[APMAC], APName=[APName], APID=[APID], LocalCertIssuer=[LocalCertIssuer], LocalCertSubject=[LocalCertSubject], LocalCertStartTime=[LocalCertStartTime], LocalCertFinishTime=[LocalCertFinishTime])

Description

The local certificate is about to expire.

Parameters

Parameter Name Parameter Meaning

APMAC

MAC address of an AP.

APName

Name of an AP.

APID

AP ID.

LocalCertIssuer

Issuer of a local certificate.

LocalCertSubject

Subject of a local certificate.

LocalCertStartTime

Start time of the validity period of a local certificate.

LocalCertFinishTime

Expiration time of the local certificate.

Possible Causes

The local certificate is about to expire. The expiration time of the local certificate is earlier than the pre-warning time configured using the pki set-certificate expire-prewarning command.

Procedure

1. Run the display clock command to check whether the device time is correct.

If not, run the clock datetime command in the user view to change the device time.

2. If the time is correct, apply for a new local certificate immediately.
