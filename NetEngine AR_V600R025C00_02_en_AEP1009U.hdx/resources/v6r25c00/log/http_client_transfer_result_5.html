HTTPC/5/HTTP_CLIENT_TRANSFER_RESULT

Message

HTTPC/5/HTTP_CLIENT_TRANSFER_RESULT: HTTP client file transfer is finished. (operation-type=[OperType], file-url=[FileUrl], transfer-status=[TransStaus], error-tag=[ErrTag], error-message=[ErrMsg])

Description

The file transfer on the HTTP client is complete.

Parameters

Parameter Name Parameter Meaning

OperType

Operation type:

2: Download

FileUrl

File link.

TransStaus

Transfer status:

2: Failed

3: Canceled

4: Successful

ErrTag

Error code. When the transfer is successful, the error code is 0.

ErrMsg

Error message. When the error code is 0, the error message is empty.

Possible Causes

The HTTP client is triggered to download a file through YANG packets.

Procedure

1. If the download is successful, this message is informational only, and no action is required.

2. If the download fails and the value of ErrTag is not 0, the possible causes are as follows:

  • 56: The user does not have the read and write permissions on the file. Check whether the user has the read and write permissions on the file in the specified download path.
  • 59: The user cancels the file download. Check whether the download is canceled.
  • 61: The network is disconnected. Check whether the client can access the HTTP server.
  • 72: The disk space is insufficient. Check whether the disk space in the specified download path is greater than the size of the file to be downloaded.
  • 73: SSL certificate authentication fails. Check whether the certificate in the bound SSL policy has an authentication relationship with the peer end.
  • If other errors occur, collect log information and contact technical support personnel.
