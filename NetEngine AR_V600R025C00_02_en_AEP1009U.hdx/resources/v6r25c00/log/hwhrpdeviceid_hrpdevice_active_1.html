HRP/1/hwHrpDeviceID_active

Message

HRP/1/hwHrpDeviceID_active: The heartbeat status of the high availability system is abnormal. (HRP link changes to=[trap-link-state], Local device ID is=[trap-local-id], peer device ID is=[trap-peer-id])

Description

The heartbeat status of hot standby is abnormal.

Parameters

Parameter Name Parameter Meaning

trap-link-state

Connection status of hot standby.

trap-local-id

MAC address of the management network port on the local device.

trap-peer-id

MAC address of the management network port on the remote device.

Possible Causes

  • Cause 1: Manually disable the hot standby function.
  • Cause 2: The link between the heartbeat interfaces of the active and standby devices is interrupted.
  • Cause 3: The master device or the backup device fails to send and receive heartbeat packets.
  • Cause 4: In dual-device hot backup of chassis-shaped devices, an active/standby main control board switchover occurs on one device.

Procedure

  • Cause 1: Manually disable the hot standby function.

    Check whether hot standby is correctly configured on the active and standby devices.

    Check whether the authentication keys configured using the hrp authentication-key command are the same. Run the display current-configuration | include hrp command to check whether the remote IP address and heartbeat interface of the peer end are correct and whether hrp enable is enabled.

  • Cause 2: The link between the heartbeat interfaces of the active and standby devices is interrupted.

    Run the ping command to check whether the link between the heartbeat interfaces of the active and standby devices is normal.

  • Cause 3: The master device or the backup device fails to send and receive heartbeat packets.

    Check whether the status of the active and standby devices is normal.

    Run the display hrp state command to check whether the hot standby status is the expected active/standby status, fault coefficient, and robustness variable.

  • Cause 4: In dual-device hot backup of chassis-shaped devices, an active/standby main control board switchover occurs on one device.

    In normal cases, no action is required. After the HA switchover is complete, the HA system is established and the alarm is automatically cleared.
