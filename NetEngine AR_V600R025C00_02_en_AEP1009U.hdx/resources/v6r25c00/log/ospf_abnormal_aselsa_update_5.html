OSPF/5/OSPF_ABNORMAL_ASELSA_UPDATE

Message

OSPF/5/OSPF_ABNORMAL_ASELSA_UPDATE: ASELSA changes frequently now. (ProcessId=[ProcessId], AdvertiseRouterId=[AdvertiseRouterId], ASELsaCount=[ASELsaCount], BeginTime=[BeginTime], EndTime=[EndTime])

Description

Frequency of ASELSA update.

Parameters

Parameter Name Parameter Meaning

ProcessId

OSPF process ID.

AdvertiseRouterId

Declare a device.

ASELsaCount

Count of ASELSA.

BeginTime

Time when counters are set.

EndTime

Time when counters are stopped.

Possible Causes

The number of ASE LSA updates is counted based on the ASE LSA advertisement device, and a historical record is generated every hour. If the number of ASE LSA updates exceeds 1000, this log is generated.

Procedure

  • This log message is informational only, and no action is required.
