CONFIGURATION/4/B2S_BACKUP_FAILED

Message

CONFIGURATION/4/B2S_BACKUP_FAILED: Failed to transfer the configuration file to server [server-ip] through [transport-type] when automatically backing up the configuration.

Description

The configuration data fails to be transferred when the configuration data is backed up to the server.

Parameters

Parameter Name Parameter Meaning

server-ip

Server address.

transport-type

Data transfer mode.

Possible Causes

Cause 1: The server is unreachable.

Cause 2: The user does not exist or the password is incorrect.

Cause 3: The server path does not exist.

Cause 4: The server is unreachable due to network problems during transfer.

Procedure

1. The handling methods for different causes are as follows:

  • Cause 1: Run the ping command to check whether the server is reachable. Ensure that the server is reachable.
  • Cause 2: Use the device as the client and run commands to access the server to check whether the user name and password are correct. Ensure that the user name and password are correct.
  • Cause 3: Check the server configuration and ensure that the server parameters are correctly configured.
  • Cause 4: A single transfer failure does not need to be handled because it may be related to the network status. If the problem occurs for multiple times, check the link status between the device and the server.

2. Collect log and configuration information, and contact technical support personnel.
