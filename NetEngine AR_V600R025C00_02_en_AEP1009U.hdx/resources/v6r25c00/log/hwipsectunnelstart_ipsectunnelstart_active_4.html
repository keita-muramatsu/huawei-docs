IPSEC/4/hwIPSecTunnelStart_active

Message

IPSEC/4/hwIPSecTunnelStart_active: The IPSec tunnel is established. (Ifindex=[Ifindex], SeqNum=[SeqNum], TunnelIndex=[TunnelIndex], RuleNum=[RuleNum], DstIP=[DstIP], InsideIP=[InsideIP], RemotePort=[RemotePort], CpuID=[CpuID], SrcIP=[SrcIP], FlowInfo=[FlowInfo], LifeSize=[LifeSize], LifeTime=[LifeTime], VsysName=[vsys-name], InterfaceName=[InterfaceName], SlotID=[SlotID], Role=[Role])

Description

An IPsec tunnel is established.

Parameters

Parameter Name Parameter Meaning

Ifindex

Interface index.

SeqNum

Policy ID.

TunnelIndex

Tunnel index.

RuleNum

Rule ID.

DstIP

IP address of the remote end of the tunnel.

InsideIP

IP address of the remote intranet of the tunnel.

RemotePort

Remote port number of the tunnel.

CpuID

CPU ID.

SrcIP

Local IP address of the tunnel.

FlowInfo

Data flow information of the tunnel, including the source address, destination address, ACL port number, ACL protocol number, and DSCP.

LifeSize

Tunnel lifetime, in kilobytes.

LifeTime

Tunnel lifetime, in seconds.

vsys-name

The value is fixed to Public.

InterfaceName

Interface name.

SlotID

Slot ID.

Role

Role of the device during SA negotiation:

  • Initiator: The device functions as the initiator of SA negotiation.
  • Responder: The device functions as the responder in SA negotiation.

Possible Causes

The IPsec tunnel is successfully established

Procedure

This message is informational only, and no action is required.
