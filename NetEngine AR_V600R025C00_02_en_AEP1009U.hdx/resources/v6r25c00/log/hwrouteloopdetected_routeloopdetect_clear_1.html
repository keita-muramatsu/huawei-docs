ISIS/1/hwRouteLoopDetected_clear

Message

ISIS/1/hwRouteLoopDetected_clear: The routing loop is cleared. (LoopType=[loopType], DetectProtocol=[detectProtocol], DetectProtocolAttr=[detectProtocolAttr], RedistributeID1=[redistributeID1], RedistributeID2=[redistributeID2])

Parameters

Parameter Name Parameter Meaning

loopType

Loop detection type.

detectProtocol

Type of the protocol that detects a routing loop.

detectProtocolAttr

Information about the loop detection protocol.IS-IS and OSPF are the address family and protocol process ID. BGP is an address family or sub-address family.

redistributeID1

Redistribution device ID 1. In IS-IS, it is the system ID of the process. In OSPF, it is the router ID and instance ID of the process. In BGP, it is the BGP instance ID and a 4-byte random number.

redistributeID2

Redistribution device ID 2. In IS-IS, it is the system ID of the process. In OSPF, it is the router ID and instance ID of the process. In BGP, it is the BGP instance ID and a 4-byte random number.

Possible Causes

The alarm for the routing loop detected by the device is cleared.

Procedure

This trap message is informational only, and no action is required.
