AM/4/IPPOOL_BACKUPERR

Message

AM/4/IPPOOL_BACKUPERR: Received wrong backup data. (PoolName=[PoolName], BackUpData=[BackUpData], Reason=[Reason])

Description

The backup data of the IP address pool was incorrect.

Parameters

Parameter Name Parameter Meaning

PoolName

Name of an IP address pool.

BackUpData

Backup data of the IP address pool.

Reason

Cause of the IP address pool data backup error.

Possible Causes

The IP address pool configurations on the active and standby devices were inconsistent.

Procedure

1. Run the display ip pool command to check whether the IP address pool configurations on the active and standby devices are consistent.

  • If the configurations are consistent, go to step 3.
  • If the configurations are inconsistent, go to step 2.

2. Change the IP address pool configuration on the standby device to be the same as that on the active device.

3. Collect log and configuration information, and contact technical support personnel. Device diagnostic information can be collected through the display diagnostic-information command.
