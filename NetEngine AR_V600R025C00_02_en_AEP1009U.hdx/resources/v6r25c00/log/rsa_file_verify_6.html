RSA/6/RSA_FILE_VERIFY

Message

RSA/6/RSA_FILE_VERIFY: Failed the key integrity check. (Details=[details])

Description

Failed to verify the key integrity.

Parameters

Parameter Name Parameter Meaning

details

Details about the key that fails to be verified.

Possible Causes

The key file is damaged or tampered with.

Procedure

Run the following command to regenerate the required key based on the type of the key that fails the verification and log information:

Run the following command as required to generate a local key pair:

  • rsa local-key-pair create
  • dsa local-key-pair create
  • ecc local-key-pair create

Run the following command as required to generate a key pair:

  • rsa key-pair label
  • dsa key-pair label
  • ecc key-pair label
