PIM/4/PIM_RCV_ERR_PKT

Message

PIM/4/PIM_RCV_ERR_PKT: PIM received an error packet and dropped it. Records the interface name, source address, and invalidity type of the last packet. (VrfName=[VrfName], PktType=[PktType], ErrPktCnt=[ErrPktCnt], LastPktIfName=[LastPktIfName], LastPktSrcAddr=[LastPktSrcAddr], LastPktInvType=[LastPktInvType])

Description

PIM discarded the received error packets.

Parameters

Parameter Name Parameter Meaning

VrfName

Instance name

PktType

Packet type

ErrPktCnt

Count of error packets

LastPktIfName

Interface name of the last received error packet

LastPktSrcAddr

Source address of the last received error packet

LastPktInvType

Error type of the last received error packet

Possible Causes

PIM discarded the received error packets.

Procedure

  • This log message is informational only, and no action is required.
