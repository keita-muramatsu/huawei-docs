SYSTEM/4/HAF_HEARTBEAT_RESUME

Message

SYSTEM/4/HAF_HEARTBEAT_RESUME: The heartbeat connection between the board and main control board was restored. (EntityPhysicalIndex=[EntityPhysicalIndex],PhysicalIndex=[PhysicalIndex],PhysicalName=[PhysicalName])

Description

The heartbeat between the board and the main control board recovered.

Parameters

Parameter Name Parameter Meaning

EntityPhysicalIndex

Heartbeat index.

PhysicalIndex

Physical index.

PhysicalName

Entity name.

Possible Causes

The main control board received heartbeat messages from the board.

Procedure

This message is informational only, and no action is required.
