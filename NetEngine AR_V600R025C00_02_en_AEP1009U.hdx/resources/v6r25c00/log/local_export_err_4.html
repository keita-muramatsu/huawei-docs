PKI/4/LOCAL_EXPORT_ERR

Message

PKI/4/LOCAL_EXPORT_ERR: Exporting local certificate file ([file-name]) failed.

Description

Failed to export the local certificate file.

Parameters

Parameter Name Parameter Meaning

file-name

Name of the local certificate file.

Possible Causes

  • The local certificate does not exist.
  • The storage space of the device is full.
  • The private key file name is not specified when the local certificate is exported.
  • The private key password entered for exporting the local certificate does not meet requirements.

Procedure

1. Run the display pki certificate local command to check whether the local certificate exists.

  • If not, obtain it from the CA or apply for a local certificate.
  • If yes, go to step 2.

2. Run the dir command to check whether the storage space of the device is full.

  • If yes, clear the storage space and delete unnecessary files.
  • If not, go to step 3.

3. Check whether the private key file name and private key password are required when the local certificate is exported.

  • If yes, enter them as required.
  • If not, go to step 4.

4. Collect related information and contact technical support personnel.
