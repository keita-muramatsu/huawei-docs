BGP/4/PKT_RAW_OUT

Message

BGP/4/PKT_RAW_OUT: BGP received an invalid message, and the invalid content ranged from [MIN] to [MAX] bytes. (VpnInstance=[VpnInstance], Peer=[peer-address], PacketType=[pkt-type], PacketContent=[pkt-content], SourceInterface=[SourceInterface])

Description

BGP received an invalid message with the length of invalid contents being in a specified range.

Parameters

Parameter Name Parameter Meaning

MIN

Beginning of the invalid contents

MAX

End of the invalid contents

VpnInstance

Name of a VPN instance

peer-address

IP address of a peer

pkt-type

Message type:

  • OPEN: indicates an Open message.
  • UPDATE: indicates an Update message.
  • NOTIFICATION: indicates a Notification message.
  • KEEPALIVE: indicates a Keepalive message.
  • ROUTE-REFRESH: indicates a Route-Refresh message.

pkt-content

Contents of an invalid message

SourceInterface

Source interface.

Possible Causes

An invalid message was received.

Procedure

Collect log information and configuration information, and then contact technical support personnel.
