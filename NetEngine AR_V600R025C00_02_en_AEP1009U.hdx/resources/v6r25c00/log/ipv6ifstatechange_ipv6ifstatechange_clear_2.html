IPV6/2/ipv6IfStateChange_clear

Message

IPV6/2/ipv6IfStateChange_clear: The IPv6 status changes. (ifName=[ipv6IfDescr], AdminStatus=[ipv6IfAdminStatus], OperStatus=[ipv6IfOperStatus], Reason=[Reason])

Parameters

Parameter Name Parameter Meaning

ipv6IfDescr

Indicates the interface name.

ipv6IfAdminStatus

Indicates the administrative status of an interface.

ipv6IfOperStatus

Indicates the current status of an interface.

Reason

Indicates the alarm cause.

Possible Causes

  • Cause 3:The IPv6 address is available
  • Cause 6:IPv6 is disabled or the interface is deleted

Procedure

  • Cause 3:The IPv6 address is available

    This alarm message is informational only, and no action is required.

  • Cause 6:IPv6 is disabled or the interface is deleted

    Generally do nothing because the interface is deleted or disabled IPv6 by user.
