FWM-ETH/4/hwVlanMacLimitOverThreshold_active

Message

FWM-ETH/4/hwVlanMacLimitOverThreshold_active: MAC address learning reached the limit. (Vlan=[VlanId],MacLimitMaxMac=[MacLimitMaxMac])

Description

The number of learned MAC addresses reaches the alarm threshold.

Parameters

Parameter Name Parameter Meaning

VlanId

VLAN ID.

MacLimitMaxMac

Maximum number of MAC addresses that can be learned.

Possible Causes

The number of learned dynamic MAC addresses exceeded the maximum size of the MAC address table.

Procedure

  • Delete unnecessary MAC addresses or run the mac-address limit command in the VLAN view to increase the upper threshold.
