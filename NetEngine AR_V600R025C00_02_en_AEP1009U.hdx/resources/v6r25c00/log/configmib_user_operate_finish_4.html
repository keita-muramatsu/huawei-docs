CONFIGURATION/4/CONFIGMIB_USER_OPERATE_FINISH

Message

CONFIGURATION/4/CONFIGMIB_USER_OPERATE_FINISH: Configuration was copied. (OperationIndex=[hwCfgOperateIndex], OperationType=[hwCfgOperateType], OperationResultIndex=[hwCfgOperateResultIndex], OptTime=[hwCfgOperateTime], OptState=[hwCfgOperateState], OptEndTime=[hwCfgOperateEndTime])

Description

The COPY operation is configured.

Parameters

Parameter Name Parameter Meaning

hwCfgOperateIndex

Index of the MIB table hwCfgOperateEntry, which specifies the MIB table to which hwCfgOperateType belongs.

hwCfgOperateType

Operation type.

hwCfgOperateResultIndex

Index of the MIB table hwCfgOperateResultEntry, which specifies the MIB table to which hwCfgOperateTime, hwCfgOperateState and hwCfgOperateEndTime belong.

hwCfgOperateTime

Operation time.

hwCfgOperateState

Operation status.

hwCfgOperateEndTime

End time of an operation.

Possible Causes

After a user uses hwCfgOperateEntry in huawei-config-man-mib to operate the device to process the configuration file, a trap is sent to notify the NMS user that the operation is complete and an event log is recorded.

Procedure

  • This message is informational only, and no action is required.
