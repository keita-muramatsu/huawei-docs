POE/6/PDPWROFF

Message

POE/6/PDPWROFF: PD on the interface is powered off. (Interface=[Interface], Reason=[Reason])

This log is supported only on AR5710-S52T2XE4, AR5710-S8T2X-LTE4EA, AR5710-S8T2X, AR5710-S8P2X, AR5710-S8T2S, AR5710-S10T1X2, AR5710-S8TWDSE-LTE4EA, AR5710-S28T2S2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE-NRGL, AR5710-S8T2XE-LTE4EA-T, AR5710-S8T1XWE, AR5710-S8T2XE.

Description

The PD connected to the interface is powered off.

Parameters

Parameter Name Parameter Meaning

Interface

Interface name

Reason

Power-off cause

Possible Causes

Cause 1: The PoE function is disabled on the interface.

Cause 2: The configured maximum power of the interface is less than the current power consumption.

Cause 3: The interface is in the power-off time range.

Cause 4: The interface mode is switched.

Cause 5: The power of the PD connected to the interface is too high.

Cause 6: The current of the PD connected to the interface is too high.

Cause 7: The inrush current exceeds the PSE threshold.

Cause 8: The PD connected to the interface is disconnected. The inrush current exceeds the PD threshold. The MPS current is too low.

Cause 9: The system power is insufficient.

Cause 10: The device fails to obtain the power supply status of the interface.

Cause 11: The interface is faulty.

Cause 12: Other causes.

Procedure

  • Cause 1: The PoE function is disabled on the interface.

1. Run the display this command in the corresponding interface view to check whether the undo poe enable command is configured.

  • If this command is configured and you need to power on the PD again, run the poe enable command in the corresponding interface view to enable the PoE function.
  • If this command is not configured, contact technical support personnel.
  • Cause 2: The configured maximum power of the interface is less than the current power consumption.

1. Run the display this command in the corresponding interface view to check whether the poe power port-max-power command is configured.

  • If this command is configured and you need to power on the PD again, run the undo poe power command in the corresponding interface view to restore the default maximum output power of the interface.
  • If this command is not configured, contact technical support personnel.
  • Cause 3: The interface is in the power-off time range.

1. Run the display this command in the interface view to check whether the poe power-off time-range time-range-name configuration exists in the interface view.

  • If this command is configured and you need to power on the PD again, run the undo poe power-off time-range command in the corresponding interface view to delete the configured PoE power-off time range.
  • If this command is not configured, contact technical support personnel.
  • Cause 4: The interface mode is switched.

1. The power supply mode of the interface is switched, and no action is required.

  • Cause 5: The power of the PD connected to the interface is too high.

1. The power of the PD connected to the interface is too high. Run the display poe power, display poe power-state, and display poe information commands in any view, collect the command output, and contact technical support personnel.

  • Cause 6: The current of the PD connected to the interface is too high.

1. The current of the PD connected to the interface is too high. Run the display poe power, display poe power-state, and display poe information commands in any view, collect the command output, and contact technical support personnel.

  • Cause 7: The inrush current exceeds the PSE threshold.

1. Run the poe legacy enable command in the interface view to allow high inrush current during power-on.

  • If the fault persists, run the display poe power, display poe power-state, and display poe information commands in any view, collect the command output, and contact technical support personnel.
  • Cause 8: The PD connected to the interface is disconnected. The inrush current exceeds the PD threshold. The MPS current is too low.

1. To rectify the fault, perform the following steps:

  • Check whether the PD is disconnected. If so, reconnect the PD. If not, go to the next step.
  • Run the poe af-inrush enable command in the interface view to change the power supply standard of the interface from 802.3at to 802.3af. Then, check whether the fault is rectified. If the fault persists, go to the next step.
  • Run the poe power-on delay delay-time command in the interface view to set the power supply delay on the interface. Then, check whether the fault is rectified. If the fault persists, go to the next step.
  • Run the display poe power, display poe power-state, and display poe information commands in any view, collect the command output, and contact technical support personnel.
  • Cause 9: The system power is insufficient.

1. To rectify the fault, perform the following steps:

  • Run the display poe information command in any view to check the PoE running information, especially the Total Power Consumption(mw) field in the command output. If the load is too high, the system automatically powers off low-priority PDs. Reduce the number of PDs. If the fault persists, go to the next step.
  • Run the display poe-power command in any view to check the PoE running information. Check whether the value of the Reserved PoE Power Percent field in the command output is too large. The default value is 20%. If the percentage of the reserved PoE power against the available PoE power is too high, run the poe power-reserved power-reserved command in the system view to set a smaller percentage. If the fault persists, contact technical support personnel.
  • Cause 10: The device fails to obtain the power supply status of the interface.

1. Run the display poe power, display poe power-state, and display poe information commands in any view, collect the command output, and contact technical support personnel.

  • Cause 11: The interface is faulty.

1. Run the display poe power, display poe power-state, and display poe information commands in any view, collect the command output, and contact technical support personnel.

  • Cause 12: Other causes.

1. Run the display poe power, display poe power-state, and display poe information commands in any view, collect the command output, and contact technical support personnel.
