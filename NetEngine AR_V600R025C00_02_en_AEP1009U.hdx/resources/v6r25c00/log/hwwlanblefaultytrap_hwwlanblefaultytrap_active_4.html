WLAN/4/hwWlanBLEFaultyTrap_active

Message

WLAN/4/hwWlanBLEFaultyTrap_active: The AP's internal BLE module fails. (APMAC=[APMAC], APName=[APName], APID=[APID])

Description

The built-in Bluetooth module of an AP is faulty.

Parameters

Parameter Name Parameter Meaning

APMAC

MAC address of an AP.

APName

Name of an AP.

APID

AP ID.

Possible Causes

The system did not detect heartbeat messages from the AP's built-in Bluetooth module for 32 seconds.

Procedure

1. Check whether the AP's built-in Bluetooth module is working properly.

  • If not, go to Step 2.
  • If so, go to Step 3.

2. Ensure that the AP's built-in Bluetooth module works properly. Then, check whether the alarm persists.

  • If so, go to Step 3.
  • If not, go to Step 4.

3. Collect trap, log, and configuration information, and contact technical support.

4. End.
