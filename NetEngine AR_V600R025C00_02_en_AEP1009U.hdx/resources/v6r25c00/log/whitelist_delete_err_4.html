PKI/4/WHITELIST_DELETE_ERR

Message

PKI/4/WHITELIST_DELETE_ERR: Deleting whitelist ([file-name]) failed.

Description

Failed to delete certificate whitelist files.

Parameters

Parameter Name Parameter Meaning

file-name

Specifies the name of a certificate whitelist file.

Possible Causes

The certificate whitelist does not exist.

Procedure

1. Run the display pki whitelist all command to check whether the certificate whitelist exists.

  • If no, the device is running properly and no action is required.
  • If yes, go to step 2.

2. Collect related information and contact technical support personnel.
