SRPOLICY/2/hwSrPolicyListResourceIdConflict_clear

Message

SRPOLICY/2/hwSrPolicyListResourceIdConflict_clear: The alarm indicating that the resource ID to be used as the identifier of an SR Policy's segment list fails to be allocated is cleared. (hwSrPolicyEndpoint=[SrPolicyEndpoint], hwSrPolicyColor=[SrPolicyColor], hwSrListId=[SegmentListId], hwSrPolicyListResourceId=[ResourceId], hwSrPolicyListResourceIdType=[ResourceIdType], hwSrPolicyListResourceIdFailReason=[ResourceIdFailReason], hwSrPolicyConflictState=[ConflictState])

Parameters

Parameter Name Parameter Meaning

SrPolicyEndpoint

Endpoint of an SR Policy.

SrPolicyColor

Color of an SR Policy.

SegmentListId

SR Policy candidate path segment list ID.

ResourceId

Resource ID to be allocated to the segment list of an SR Policy's candidate path.

ResourceIdType

Type of the resource ID to be allocated to the segment list of an SR Policy's candidate path.

ResourceIdFailReason

Reason why a resource ID failed to be allocated to the segment list of an SR Policy's candidate path.

ConflictState

Current conflict status.

Possible Causes

1. The resource ID that failed to be allocated is deleted.

2. The SR Policy's segment list that failed to allocate the resource ID is deleted.

3. The resource ID changes from allocation failure to allocation success.

Procedure

This message is informational only, and no action is required.
