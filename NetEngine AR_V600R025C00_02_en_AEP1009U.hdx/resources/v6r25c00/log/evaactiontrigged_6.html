EVA/6/EVAACTIONTRIGGED

Message

EVA/6/EVAACTIONTRIGGED: Execute action of script successfully. (ActionType=[ActionType],ScriptName=[ScriptName])

Description

Succeeded in triggering the script action.

Parameters

Parameter Name Parameter Meaning

ActionType

Action type or action.

ScriptName

Script name.

Possible Causes

After the policy in the EVA script is met, the action of the policy is performed.

Procedure

This message is informational only, and no action is required.
