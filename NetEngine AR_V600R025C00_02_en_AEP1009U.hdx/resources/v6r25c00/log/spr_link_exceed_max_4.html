SPR/4/SPR_LINK_EXCEED_MAX

Message

SPR/4/SPR_LINK_EXCEED_MAX: The links' number of spr instance have exceeded max. (DestSiteIndex = [DestSiteIndex], PolicyIndex = [PolicyIndex], LinkRole = [LinkRole], MaxNumber = [MaxNumber])

Description

The number of links in the SPR instance exceeded the maximum value.

Parameters

Parameter Name Parameter Meaning

DestSiteIndex

Index of the destination site.

PolicyIndex

Index of an SPR policy.

LinkRole

Link role.

MaxNumber

Maximum number of links.

Possible Causes

The number of links dynamically added to the SPR instance exceeded the maximum value.

Procedure

1. Run the display smart-policy-route spr-policy command to check the link configuration of the SPR policy. If the configuration is incorrect, run the link transport-network command to modify the configuration.

2. Run the display evpn connection command to check EVPN connection information of the device. If the EVPN connection configuration is incorrect, run the transport-network-port command to modify the configuration.
