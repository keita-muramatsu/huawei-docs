OSPFV3/6/OSPFV3_BFD_SYNC_COST

Message

OSPFV3/6/OSPFV3_BFD_SYNC_COST: The interface of OSPFV3 [ProcessId] BFD sync-state changed. (IfName=[IfName], Sync-state=[SyncState], changeReason=[ChangeReason])

Description

The status of association between an OSPFv3 interface and BFD changed.

Parameters

Parameter Name Parameter Meaning

ProcessId

OSPFv3 Process ID.

IfName

Interface name.

SyncState

Linkage status.

ChangeReason

The reason why the interface linkage status changes.

Possible Causes

0: BFD Down

1: The BFD session is up, and the association state exits.

2: The BFD session is unknown, and the association state exits.

3: The BFD session is deleted, and the association state exits.

4: The neighbor is deleted due to the down status of the neighbor's protocol, and the association state exits.

5: The cost value associated with BFD is deleted, the association state exits, and the neighbor is deleted.

6: Over a broadcast link, there used to be one neighbor, and now there are multiple neighbors, the association state exits, and the neighbor is deleted.

Procedure

This log message is informational only, and no action is required.
