HRP/5/HRPLINK_UP

Message

HRP/5/HRPLINK_UP: HRP link changes to up.

Description

The HRP heartbeat link went Up.

Parameters

None

Possible Causes

  • In dual-device hot backup networking, the master and backup devices establish the dual-system status for the first time.
  • In dual-device hot backup networking, the heartbeat link recovers from a fault.

Procedure

This trap message is informational only, and no action is required.
