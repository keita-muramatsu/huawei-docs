TTY/4/AUTHORITY_CHANGE

Message

TTY/4/AUTHORITY_CHANGE: The authentication mode was changed to password authentication and the user privilege level was changed to the highest level on [InterfaceName] at the first user login. (IpAddress=[IPAdress])

Description

During the first login, the authentication mode on the user interface changes to password authentication and the user level changes to the display level.

Parameters

Parameter Name Parameter Meaning

InterfaceName

Type and number of a user interface.

IPAdress

IP address of a user.

Possible Causes

This log is generated when a user is required to configure user interface attributes during first login and the attributes such as the user permission on the user interface are changed.

Procedure

1. This message is informational only, and no action is required.
