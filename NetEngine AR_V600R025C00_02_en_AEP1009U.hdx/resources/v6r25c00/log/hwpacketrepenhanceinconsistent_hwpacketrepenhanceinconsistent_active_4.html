PKT-REP/4/hwPacketRepEnhanceInconsistent_active

Message

PKT-REP/4/hwPacketRepEnhanceInconsistent_active: The configuration of the packet replication enhance function is inconsistent with the actual effective state. (slot=[SlotId], CPU=[CpuId], ConfigState=[ConfigState], CurrentState=[CurrentState])

This log is supported only on AR5710-S52T2XE4, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L50T2X4-T, AR6700-H series, AR6710-L8T3TS1X2, AR6710-L50T2X4, AR8100 series, AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S28T2S2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR6710-L14T2X4, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE-NRGL, AR6710-L26T2X4-T, AR5700-H series, AR5710-S8T2XE-LTE4EA-T, AR5710-S8T1XWE, AR5710-S8T2XE.

Description

The configuration status of the packet replication enhancement function is inconsistent with the effective status.

Parameters

Parameter Name Parameter Meaning

SlotId

Slot ID.

CpuId

CPU ID.

ConfigState

Configuration status of packet replication enhancement.

CurrentState

Effective status of packet replication enhancement.

Possible Causes

After the packet replication enhance function settings are completed, the device needs to be restarted for the changes to take effect. If the device is not restarted, the alarm will be generated.

Procedure

After the packet replication enhancement function is configured, save the configuration and restart the device.
