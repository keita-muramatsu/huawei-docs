FM/4/TARGET_DEL

Message

FM/4/TARGET_DEL: Target host [IPAddress] was deleted.

Description

The target host was deleted.

Parameters

Parameter Name Parameter Meaning

IPAddress

IP address of the target host

Possible Causes

A target host is deleted.

Procedure

  • This message is informational only, and no action is required.
