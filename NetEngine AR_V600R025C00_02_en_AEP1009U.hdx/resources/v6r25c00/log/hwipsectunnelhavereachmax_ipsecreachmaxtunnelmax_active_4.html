IPSEC/4/hwIPSecTunnelHaveReachMax_active

Message

IPSEC/4/hwIPSecTunnelHaveReachMax_active: Current counts of ipsec tunnel has been reached max CPU limit or license limit, please check it at once.

Description

The number of IPsec tunnels has reached the limit of a single CPU or license.

Parameters

None

Possible Causes

The number of IPsec tunnels has reached the limit.

Procedure

Delete unnecessary IPsec tunnels.

Expand the CPU capacity or apply for a new license.
