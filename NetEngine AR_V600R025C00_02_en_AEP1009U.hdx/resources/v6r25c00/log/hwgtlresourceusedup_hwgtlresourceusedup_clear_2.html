LCS/2/hwGtlResourceUsedUp_clear

Message

LCS/2/hwGtlResourceUsedUp_clear: The alarm indicating that resources item [hwGtlResourceItem] are nearly exhausted was cleared. (ItemDescription=[hwGtlItemDescription])

Parameters

Parameter Name Parameter Meaning

hwGtlResourceItem

Resource item in a license file.

hwGtlItemDescription

Control item description in a license file.

Possible Causes

The usage of an active resource item (not an interface resource item) in the license file fell below the threshold.

Procedure

  • This alarm is informational only, and no action is required.
