OSPFV3/2/ospfv3NbrStateChange_clear

Message

OSPFV3/2/ospfv3NbrStateChange_clear: The status of the non-virtual neighbor has changed. (RouterId=[RouterId], NbrIfIndex=[NbrIfIndex], NbrIfInstId=[NbrIfInstId], NbrRtrId=[NbrRtrId], NbrState=[NbrState], IfName=[IfName], Reason=[NbrStateChangeReason], SubReason=[SubReason])

Parameters

Parameter Name Parameter Meaning

RouterId

Router ID

NbrIfIndex

Indicates the IP address of the neighbor.

NbrIfInstId

Indicates the interface index.

NbrRtrId

It identifies the router ID of a neighbor.

NbrState

Indicates the neighbor status. The trap is a service restoration trap only when the value of Full. Otherwise, it is a fault trap.

  • 1: Down
  • 2: Attempt
  • 3: Init
  • 4: 2-Way
  • 5: ExStart
  • 6: Exchange
  • 7: Loading
  • 8: Full

IfName

Indicates the interface name.

NbrStateChangeReason

Indicates the reason why the neighbor status changes.

SubReason

Indicates the detailed reason.

Possible Causes

The status of the non-virtual neighbor has changed.

Procedure

1. This trap message is informational only, and no action is required.
