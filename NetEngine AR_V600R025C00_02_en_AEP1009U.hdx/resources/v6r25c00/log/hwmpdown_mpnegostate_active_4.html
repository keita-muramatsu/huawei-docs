PPP/4/hwMpDown_active

Message

PPP/4/hwMpDown_active: The number of available member links in the MP-Group fell below the lower threshold and the MP-Group went Down. (IfIndex=[IfIndex], IfName=[IfName])

Description

The number of available MP-group member interfaces is less than the minimum number of activated links.

Parameters

Parameter Name Parameter Meaning

IfIndex

Interface index

IfName

Interface name

Possible Causes

The number of available member links in the MP-Group fell below the lower threshold.

Procedure

1. Run the display ppp mp command to check the number of available member links in an MP-group interface based on the Bundle Multilink field.

  • If the number of available member links does not reach the minimum number of active links, go to Step 2.
  • If the number of available member links has reached the minimum number of active links, go to Step 3.

2. Add serial interfaces whose links are Up to the MP-group interface on the local and peer ends. After the serial interfaces are added to the MP-group interface, the number of member interfaces must be greater than or equal to the value configured using the ppp mp threshold-least command. Check whether the alarm is cleared.

  • If the alarm is cleared, go to Step 4.
  • If the alarm persists, go to Step 3.

3. Collect alarm, log, and configuration information, and contact technical support personnel.

4. End.
