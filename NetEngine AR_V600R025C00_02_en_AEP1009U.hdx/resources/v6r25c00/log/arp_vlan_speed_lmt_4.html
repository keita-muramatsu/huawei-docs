ARP/4/ARP_VLAN_SPEED_LMT

Message

ARP/4/ARP_VLAN_SPEED_LMT: The VLAN's ARP packet speed exceeded the configured speed limit value. (SuppressValue=[SpeedLmtValue], Vlan=[VlanId])

Description

The rate of ARP packets in a VLAN exceeded the rate limit configured in the VLAN.

Parameters

Parameter Name Parameter Meaning

SpeedLmtValue

Rate limit configured for ARP packets in a VLAN.

VlanId

VLAN in which ARP packet rate limiting is configured.

Possible Causes

The rate of sending ARP packets in a specified VLAN exceeded the configured rate limit.

Procedure

  • Run the display arp anti-attack rate-limit command to check the rate limit of ARP packets in a VLAN.
  • Run the arp anti-attack rate-limit <limit> command to reconfigure the VLAN-based ARP packet rate limit (the value must be greater than the value queried in Step 1 but cannot exceed 65536). Then check whether the log is generated again.
  • If so, go to Step 3.
  • If no, go to Step 4.
  • Collect log and configuration information, and contact technical support personnel.
  • End.
