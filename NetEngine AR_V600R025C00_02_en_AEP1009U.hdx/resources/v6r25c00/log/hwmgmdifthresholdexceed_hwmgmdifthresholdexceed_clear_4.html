IGMP/4/hwMgmdIfThresholdExceed_clear

Message

IGMP/4/hwMgmdIfThresholdExceed_clear: The number of IGMP or MLD entries on the interface fell below the lower threshold. (AddressFamily=[AddressFamily], Ifindex=[IfIndex], CurrentCount=[CurrentCount], ThresholdCount=[ThresholdCount], Ifname=[IfName], InstanceName=[InstanceName])

Parameters

Parameter Name Parameter Meaning

AddressFamily

Address family:

  • 1: IPv4 family.
  • 2: IPv6 family.

IfIndex

interface index.

CurrentCount

Number of IGMP/MLD entries on the current interface. The IGMP/MLD entries that are newly added are not included.

ThresholdCount

Threshold at which the alarm is generated .

IfName

Name of the interface.

InstanceName

Instance of which the number of created (S, G) entries on the device reaches the specified limit.

Possible Causes

  • Cause 1:Entry delete
  • Cause 2:Configuration change

Procedure

  • This trap message is informational only, and no action is required.
