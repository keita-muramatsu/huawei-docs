HPP/4/HOST_KPI_ABNORMAL

Message

HPP/4/HOST_KPI_ABNORMAL: The number of discarded packets on the host changed suddenly. (SlotID=[SlotID],CpuID=[CpuID],CurrentValue=[CurrentValue],PreviousValue=[PreviousValue])

Description

The number of discarded packets on the host changes abruptly.

Parameters

Parameter Name Parameter Meaning

SlotID

Slot ID.

CpuID

CPU ID.

CurrentValue

Number of newly discarded packets in the current period.

PreviousValue

Average number of newly discarded packets in the last three periods.

Possible Causes

Packets are discarded due to sudden service changes.

Procedure

Determine the cause based on the packet statistics.
