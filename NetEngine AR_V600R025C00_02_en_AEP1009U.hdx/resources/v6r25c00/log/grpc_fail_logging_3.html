TELEMETRY/3/GRPC_FAIL_LOGGING

Message

TELEMETRY/3/GRPC_FAIL_LOGGING: The user failed to log in to GRPC. (UserName=[userName], IpAddress=[ipaddress], Port=[port], VpnName=[vpnName], Reason=[reason], LocalIpAddress=[localIpaddress], LocalPort=[localPort])

Description

The dynamic subscription user fails to log in.

Parameters

Parameter Name Parameter Meaning

userName

User name for login.

ipaddress

IP address for login.

port

Port number for login.

vpnName

VPN instance name.

reason

Cause of the login failure.

localIpaddress

IP address of the device.

localPort

Port number of the device.

Possible Causes

The login user fails to be authenticated.

Procedure

1. Check whether the user name and password for login are correct.

2. Collect log and configuration information, and contact technical support personnel.
