LACP/2/hwLacpPartialLinkLoss_active

Message

LACP/2/hwLacpPartialLinkLoss_active: Link bandwidth lost partly. (TrunkIndex=[TrunkIndex], TrunkIfIndex=[TrunkIfIndex], TrunkId=[TrunkId], TrunkName=[TrunkName], Reason=[ReasonCode])

Description

Part of the bandwidth of a link was lost.

Parameters

Parameter Name Parameter Meaning

TrunkIndex

Index of a trunk

TrunkIfIndex

Index of a trunk interface

TrunkId

ID of a trunk interface

TrunkName

Name of a trunk interface

ReasonCode

Reason why part of the bandwidth of a link was lost or resumed.

Possible Causes

The number of the Eth-trunk member links that can be selected is smaller than the lower threshold value.

Procedure

1. Run the display interface brief command to check whether the interface is Down.

  • If yes, go to Step 2.
  • If not, go to Step 4.

2. Run the undo shutdown command and check whether the alarm is cleared.

  • If yes, go to Step 10.
  • If not, go to Step 3.

3. Check whether the physical link fails.

  • If yes, go to Step 7.
  • If not, go to Step 4.

4. Run the display eth-trunk [ <trunk-id> [ interface <interface-type> <interface-number> | verbose ] ] command to check whether the link aggregation group has member interfaces.

  • If yes, go to Step 5.
  • If not, go to Step 8.

5. Run the display eth-trunk <trunk-id> command to check whether the lower threshold for the number of trunk member links in the Up state is configured for the LAG and whether the number of trunk member links that can be negotiated successfully is smaller than the lower threshold.

  • If yes, go to Step 6.
  • If not, go to Step 9.

6. Run the least active-linknumber <link-number> command in the Eth-Trunk interface view to correctly configure the minimum number of trunk member links in the Up state. Then, check whether the alarm is cleared.

  • If yes, go to Step 10.
  • If not, go to Step 9.

7. Repair the physical link and check whether the alarm is cleared.

  • If yes, go to Step 10.
  • If not, go to Step 4.

8. Run the eth-trunk <trunk-id> command in the interface view to add the current Ethernet interface to the Eth-Trunk interface as required. Then, check whether this alarm is cleared.

  • If yes, go to Step 10.
  • If not, go to Step 5.

9. Collect alarm and configuration information, and contact technical support personnel.

10. End.
