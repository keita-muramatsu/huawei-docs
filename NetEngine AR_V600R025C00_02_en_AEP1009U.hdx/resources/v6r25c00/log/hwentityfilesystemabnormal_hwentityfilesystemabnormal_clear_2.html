DEVM/2/hwEntityFileSystemAbnormal_clear

Message

DEVM/2/hwEntityFileSystemAbnormal_clear: The file system fault alarm is cleared. (EntityPhysicalIndex=[EntityPhysicalIndex],PhysicalName=[entPhysicalName],EntityTrapFaultID=[EntityTrapFaultID],EntityTrapReasonDescr=[EntityTrapReasonDescr])

Parameters

Parameter Name Parameter Meaning

EntityPhysicalIndex

Index of an physical entity.

entPhysicalName

Name of a physical entity.

EntityTrapFaultID

Fault ID.

EntityTrapReasonDescr

Alarm cause.

Possible Causes

The fault that the file system is read-only is rectified.

Procedure

No action is required.
