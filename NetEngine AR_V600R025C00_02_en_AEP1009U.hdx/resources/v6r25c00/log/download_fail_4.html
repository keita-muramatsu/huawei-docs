UPDATE/4/DOWNLOAD_FAIL

Message

UPDATE/4/DOWNLOAD_FAIL: Failed to download the new version. (SyslogId=[syslog-id], User=[username], IP=[ip-address], Module=[module], Status=[status], Duration(s)=[duration], Reason=[reason], Suggestion=[suggestion])

Description

Failed to download the new version.

Parameters

Parameter Name Parameter Meaning

syslog-id

Sequence number of a log.

username

Name of the user who performs the upgrade.

SystemTimer is displayed for scheduled upgrade. If the system fails to obtain the user name, ** is displayed.

ip-address

IP address of the user who performs the upgrade.

If the system fails to obtain the user IP address, "**" is displayed.

module

Module to be upgraded.

status

Upgrade mode. The options are as follows:

  • manual-update: indicates the manual upgrade.
  • auto-update: indicates automatic update.

duration

Indicates the time used for downloading the signature database, in seconds.

reason

Cause of the signature database download failure. Possible causes are as follows:

  • Failed to perform DNS resolution.
  • Connecting to the security server failed.
  • The update service of components expires.
  • The update service is not activated.
  • Failed to verify the update file.
  • Disconnected from the update server.
  • Online update init error.
  • The free space of the storage card is insufficient.
  • The storage card is not in position or formatted.
  • No signature database is available.
  • The free space of the storage card on the standby MPU is insufficient.
  • Failed to copy the update file to the storage card of the standby MPU.
  • Failed to perform DNS of the download server.
  • Connecting to the download server failed.

suggestion

Handling suggestions for signature database download failures. Suggestions are as follows:

  • Check the Internet settings and try again later.
  • Check the Internet settings and try again later.
  • Update the upgrade service.
  • Purchase the upgrade service.
  • Download the upgrade file again.
  • Check the network condition.
  • Check in-service upgrade configuration.
  • Ensure that the storage card has sufficient space for the upgrade.
  • Ensure the storage card is in position and formatted.
  • Contact customer service engineers.
  • Ensure that the storage card of the standby MPU has sufficient space to store the upgrade file.
  • Ensure that the storage card of the standby MPU has sufficient space to store the upgrade file.
  • Please check the DNS server configuration.
  • Please check the Internet connection, and try again later.

Possible Causes

The reason field in the log records the possible causes of this log.

Procedure

Rectify the fault as prompted. If the fault persists, contact technical support engineers.
