UPDATE/4/RETRY

Message

UPDATE/4/RETRY: The memory was insufficient, and the update would be performed in one hour. (SyslogId=[syslog-id], User=[username], IP=[ip-address], Module=[module], Pre-UpdateVersion=[pre-update-version], UpdateVersion=[update-version], Status=[status], Duration(s)=[duration])

Description

When the system automatically installs the signature database, the update fails due to insufficient system memory. The update module will retry the update one hour later.

Parameters

Parameter Name Parameter Meaning

syslog-id

Sequence number of a log.

username

Name of the user who performs the upgrade.

SystemTimer is displayed for scheduled upgrade. If the system fails to obtain the user name, ** is displayed.

ip-address

IP address of the user who performs the upgrade.

If the system fails to obtain the user IP address, "**" is displayed.

module

Module to be upgraded.

pre-update-version

Version number of the module before the upgrade.

update-version

Version number of the module after the upgrade.

status

Indicates the upgrade mode. The options are as follows:

apply: Install the downloaded version.

duration

Upgrade duration, in seconds.

Possible Causes

When the system automatically installs the signature database, the update fails due to insufficient system memory. The update module will retry the update one hour later.

Procedure

Wait until the upgrade is complete or stop the upgrade and then run the forcible upgrade command to perform the upgrade.
