BGP/6/PEER_STATE_CHG

Message

BGP/6/PEER_STATE_CHG: The state of the peer changed after receiving an event. (PrevState=[prev-state], CurrState=[curr-state], InputEvent=[input-event], Peer=[peer-address], SourceInterface=[SourceInterface], VpnInstance=[VpnInstance])

Description

The peer status changed.

Parameters

Parameter Name Parameter Meaning

prev-state

Original status. The details are as follows:

  • IDLE: BGP denies any connection request. This is the initial state of BGP.
  • CONNECT: BGP is waiting for the TCP connection to be established before performing subsequent operations.
  • ACTIVE: BGP attempts to establish a TCP connection. This is the intermediate state of BGP.
  • OPENSENT: BGP is waiting for an Open message from the peer.
  • OPENCONFIRM: BGP is waiting for a Notification or Keepalive message.
  • ESTABLISHED: BGP peers can exchange Update, Notification, and Keepalive messages.

curr-state

Current status. The details are as follows:

  • IDLE: BGP denies any connection request. This is the initial state of BGP.
  • CONNECT: BGP is waiting for the TCP connection to be established before performing subsequent operations.
  • ACTIVE: BGP attempts to establish a TCP connection. This is the intermediate state of BGP.
  • OPENSENT: BGP is waiting for an Open message from the peer.
  • OPENCONFIRM: BGP is waiting for a Notification or Keepalive message.
  • ESTABLISHED: BGP peers can exchange Update, Notification, and Keepalive messages.

input-event

Input event. The details are as follows:

  • START: A connection is created.
  • STOP: The connection is stopped.
  • IH_TIMER: The idleholdtimer expires.
  • CR_TIMER: The connectretrytimer times out.
  • OD_TIMER: The Opendelaytimer times out.
  • HOLD_TIMER: The holdtimer expires.
  • KA_TIMER: The keepalivetimer times out.
  • TCP_SUCCEED: A TCP connection is successfully established.
  • TCP_FAIL: The TCP connection fails to be established.
  • TCP_INCOMING: A TCP connection establishment request is received.
  • RECV_OPEN: An Open message is received.
  • RECV_KA: Keepalive messages are received.
  • RECV_UPDATE: indicates that an Update message is received.
  • RECV_RR: indicates that a RouteRefresh message is received.
  • RECV_NOTIF: A Notification packet is received.
  • RECV_NOTIF_VER: A BGP version error notification is received.
  • RECV_HEAD_ERR: A BGP message with an incorrect header is received.
  • RECV_OPEN_ERR: An Open message is received incorrectly.
  • RECV_UPDATE_ERR: The Update message is received incorrectly.
  • RECV_RR_ERR: indicates that an error RouteRefesh message is received.
  • OPEN_COLLION_DUMP: The conflicting connection is closed.
  • LINK_UNREACHABLE_DETECTED: The link is unreachable.

peer-address

IP address of the peer.

SourceInterface

Source interface.

VpnInstance

Name of a VPN instance.

Possible Causes

The peer status changed.

Procedure

This log message is informational only, and no action is required.
