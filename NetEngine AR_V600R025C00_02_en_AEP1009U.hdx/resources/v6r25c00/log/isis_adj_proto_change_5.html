ISIS/5/ISIS_ADJ_PROTO_CHANGE

Message

ISIS/5/ISIS_ADJ_PROTO_CHANGE: The protocol of IS-IS adjacency changes. (InstanceID=[InstanceID], IfName=[IfName], SystemID=[SystemID], OldState=[OldState], NewState=[NewState], ChangeReason=[ChangeReason])

Description

IS-IS neighbors support protocol changes.

Parameters

Parameter Name Parameter Meaning

InstanceID

ID of an IS-IS process.

IfName

Interface name.

SystemID

System ID.

OldState

Original status of the IS-IS neighbor:

  • IPv4
  • IPv6
  • IPv4, IPv6

NewState

Current status of an IS-IS neighbor:

  • IPv4
  • IPv6
  • IPv4, IPv6

ChangeReason

Reason why the protocol supported by the IS-IS neighbor changes:

  • The received IIH packet does not support IPv4.
  • The received IIH packet does not support IPv6.
  • The received IIH packet does not carry a link-local address.
  • The link-local address in the received IIH packet is invalid.
  • The received IIH packet supports both IPv4 and IPv6.
  • The BFD session is Down.
  • BFD is associated with the cost, and the BFD session is still Down.

Possible Causes

The protocol status of an IS-IS neighbor changes due to the following reasons:

1. The received IIH packet does not support IPv4.

2. The received IIH packet does not support IPv6.

3. The received IIH packet does not carry a link-local address.

4. The link-local address in the received IIH packet is invalid.

5. The received IIH packet supports both IPv4 and IPv6.

6. The BFD session went Down.

7. The BFD session is associated with the cost, and the BFD session is still Down.

Procedure

Check whether the neighbor change complies with the configuration. If not, collect log and configuration information, and contact Huawei technical support personnel.
