WLAN/4/WLAN_LOG_USER_WLAN_STA_INFO_ONLINE_FAIL

Message

WLAN/4/WLAN_LOG_USER_WLAN_STA_INFO_ONLINE_FAIL: WLAN_STA_INFO_ONLINE_FAIL. (ACMAC=[ACMAC],ACNAME=[ACNAME],APMAC=[APMAC],APNAME=[APNAME],APIP=[APIP],RADIO=[RADIO],BAND=[BAND],SSID=[SSID],USER=[USER],MAC=[MAC],TIME=[TIME],ZONE=UTC[ZONE],DAYLIGHT=[DAYLIGHT],RESULT=[RESULT])

Description

A STA failed to go online.

Parameters

Parameter Name Parameter Meaning

ACMAC

AC's MAC address.

ACNAME

AC's system name.

APMAC

MAC address of an AP.

APNAME

AP's system name.

APIP

AP's IP address.

RADIO

Radio ID.

BAND

Operating frequency band of a radio.

SSID

SSID.

USER

User name.

MAC

User's MAC address.

TIME

System time.

ZONE

Time zone.

DAYLIGHT

Whether the daylight saving time (DST) is used.

RESULT

Reason why the STA fails to go online.

Possible Causes

A STA failed to go online.

Procedure

Rectify the fault based on the handling suggestions for different reasons.

Reason why a STA fails to go online

Handling suggestion
