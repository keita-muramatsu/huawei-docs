AAA/4/RDAUTHDOWN

Message

AAA/4/RDAUTHDOWN: Communication with the RADIUS authentication server (IP:[IP]) is interrupted!

Description

The communication of the RADIUS authentication server is interrupted.

Parameters

Parameter Name Parameter Meaning

IP

IP address and VPN instance name of the RADIUS authentication server.

Possible Causes

The communication of the RADIUS authentication server is interrupted.

Procedure

1. Check whether the authentication server is shut down.

  • If the user shuts down the authentication server, no action is required.
  • If the authentication server is not shut down, go to Step 2.

2. Check whether the links are normal.

  • If not, recover the link.
  • If so, go to Step 3.

3. Check whether the authentication client is added to the RADIUS authentication server and whether the shared key is correct.

  • If not, perform correct configuration.
  • If so, go to Step 4.

4. Collect logs and configuration information, and contact technical support. To collect device diagnostic information, run the display diagnostic-information command.
