FTPS/4/FTPS_IP_BLOCK_CLIENT

Message

FTPS/4/FTPS_IP_BLOCK_CLIENT: FTP client IP blocked due to authentication failure in last [LogIntervalTime] [LogTimeFormat]. (IpAddress=[IpAddress], VpnName=[VpnName], BlockCount=[BlockCount])

Description

The IP address of the FTP client is locked because the authentication fails within the specified period.

Parameters

Parameter Name Parameter Meaning

LogIntervalTime

Indicates the time range.

LogTimeFormat

Indicates the time format, in the format of hour/minute/second.

IpAddress

Indicates the IP address of the locked client.

VpnName

Indicates the name of the VPN instance to which the locked client belongs.

BlockCount

Indicates the number of times that the client IP address is locked due to authentication failures within a specified period.

Possible Causes

The IP address of the FTP client is locked because the FTP client fails to be authenticated for multiple times.

By default, if the login fails for six consecutive times within 5 minutes, the account will be locked for 5 minutes.

Procedure

Run the display ftp server ip-block list command to check the IP address of the client that is locked due to FTP authentication failures. If the IP address needs to be used for login, run the activate ftp server ip-block ip-address command to unlock the IP address.
