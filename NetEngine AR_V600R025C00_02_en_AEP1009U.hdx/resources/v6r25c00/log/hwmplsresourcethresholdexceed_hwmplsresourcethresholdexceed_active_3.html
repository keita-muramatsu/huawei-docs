MPLS_LSPM/3/hwMplsResourceThresholdExceed_active

Message

MPLS_LSPM/3/hwMplsResourceThresholdExceed_active: The number of used MPLS resources exceeded the threshold. (hwMplsResourceType=[MplsResourceType], hwMplsResourceCurrentCount=[ResourceCurrentCount], hwMplsResourceThreshold=[ResourceThreshold], hwMplsResourceTotalCount=[ResourceTotalCount])

Description

The proportion of used MPLS resources to all MPLS resources supported by a device reached the upper alarm threshold.

Parameters

Parameter Name Parameter Meaning

MplsResourceType

Type of MPLS resource.

  • LDP XC Resource (1)
  • MLDP Tree Resource (5)
  • MLDP Branch Resource (6)
  • LDP Remote Peer Resource (7)
  • LDP OutSegment Resource (8)
  • LDP Interface Resource (10)

ResourceCurrentCount

Number of available MPLS resources

ResourceThreshold

Upper alarm threshold for MPLS resource usage

ResourceTotalCount

Maximum number of MPLS resources supported by a device

Possible Causes

The number of MPLS resources of a specific type reached the upper threshold.

Procedure

1. Check the hwMplsResourceType field to determine the resource type.

2. Check hwMplsResourceThreshold.

  • If you want to adjust the alarm threshold, go to Step 3.
  • If you want to reduce the configurations that use related resources, go to Step 4.

3. Run the display this include-default command in the MPLS view to check the alarm threshold configuration command and adjust the alarm threshold using the corresponding command. Then check whether the alarm is cleared.

  • If yes, go to Step 6.
  • If no, go to Step 4.

4. Reduce the configurations that use related resources, or reduce the configurations or messages that trigger the creation of related resources to decrease the usage of MPLS resources. Then check whether the alarm is cleared.

  • If yes, go to Step 6.
  • If no, go to Step 5.

5. Collect alarm and configuration information, and contact technical support.

6. End.
