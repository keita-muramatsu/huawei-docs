RUMNG/4/RU_BACKUP_STATUES_CHANGE

Message

RUMNG/4/RU_BACKUP_STATUES_CHANGE: The status of the remote unit backup port changes. (ESN=[RemoteUnitEsn], Port=[PortName], Status=[Status])

Description

The forwarding status of the backup port on the RU changed.

Parameters

Parameter Name Parameter Meaning

RemoteUnitEsn

ESN of an RU.

PortName

Name of an RU interface.

Status

Forwarding status of the backup port on the RU. The value Active indicates that the backup port is enabled to forward packets, and the value Inactive indicates that the backup port is disabled from forwarding packets.

Possible Causes

RU 1 and RU 2 are added to the same backup group.

(1) When the central device is disconnected from an RU, the backup port needs to be enabled for both RU 1 and RU 2.

(2) When the connection between the central device and RU recovers, the backup port needs to be disabled for both RU 1 and RU 2.

Procedure

This message is informational only, and no action is required.
