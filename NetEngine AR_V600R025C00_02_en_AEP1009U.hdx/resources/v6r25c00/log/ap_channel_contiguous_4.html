WLAN/4/AP_CHANNEL_CONTIGUOUS

Message

WLAN/4/AP_CHANNEL_CONTIGUOUS: When the two 5G radios work on neighboring channels, user experience is affected. (MAC=[MAC], ApID=[ApID], Sysname=[Sysname], Reason=[Reason])

Description

AP radios work on adjacent channels, leading to poor user experience.

Parameters

Parameter Name Parameter Meaning

MAC

MAC address of an AP.

ApID

AP ID.

Sysname

AP name.

Reason

Reason.

Currently, only the reason "available channels not enough" is supported, indicating that available calibration channels are insufficient.

Possible Causes

For an AP that supports two or more 5 GHz radios, if the number of calibration channels on the 5 GHz frequency band is smaller than 3, the spacing between calibration channels will be less than one operating bandwidth. This will lead to poor user experience due to high interference.

Procedure

1. Run the display current-configuration command to check whether DCA and DBS are enabled on the target AP.

The following information in the command output indicates that DCA and DBS are enabled:

calibrate auto-channel-select enable

calibrate auto-bandwidth-select enable

  • If so, go to Step 2.
  • If not, go to Step 3.

2. Run the dca-channel 5g channel-set channel-value command to add a calibration channel set for the 5 GHz radios of the target AP.

Configure at least three calibration channels for an AP that supports dual 5 GHz radios and at least five calibration channels for an AP that supports triple 5 GHz radios.

3. Run the channel { 20mhz | 40mhz-minus | 40mhz-plus | 80mhz | 160mhz } channel command to manually adjust the channel and bandwidth of the target AP to prevent radios from using adjacent channels.

4. Check whether the log persists.

  • If so, go to Step 5.
  • If not, go to Step 6.

5. Collect trap, log, and configuration information, and contact technical support.

6. End.
