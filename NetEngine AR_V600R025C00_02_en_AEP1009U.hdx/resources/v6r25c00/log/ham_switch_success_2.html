SYSTEM/2/HAM_SWITCH_SUCCESS

Message

SYSTEM/2/HAM_SWITCH_SUCCESS: Succeeded to run slave switch. (SlaveSwitchIndex=[SlaveSwitchIndex], ChassisNum=[ChassisNum], SlaveSwitchSrc=[SlaveSwitchSrc], SlaveSwitchDst=[SlaveSwitchDst])

This log is supported only on AR6700-H series, AR8700 series.

Description

The active/standby switchover is successful.

Parameters

Parameter Name Parameter Meaning

SlaveSwitchIndex

Index of the active/standby switchover.

ChassisNum

Chassis ID.

SlaveSwitchSrc

Source end of the active/standby switchover.

SlaveSwitchDst

Destination end of the active/standby switchover.

Possible Causes

This log is generated when the active/standby switchover is successful.

Procedure

  • This message is informational only, and no action is required.
