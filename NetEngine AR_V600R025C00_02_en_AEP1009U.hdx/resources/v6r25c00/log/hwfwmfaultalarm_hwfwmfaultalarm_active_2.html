FEI/2/hwFwmFaultAlarm_active

Message

FEI/2/hwFwmFaultAlarm_active: The forwarding manage module partially failed. (Slot=[hwFwmFaultSlotStr], Cpu=[hwFwmFaultCpuStr], Reason=[hwFwmFaultReasonId], Description=[hwFwmFaultReasonDescription])

Description

Some functions of the forwarding management module failed.

Parameters

Parameter Name Parameter Meaning

hwFwmFaultSlotStr

Slot ID.

hwFwmFaultCpuStr

CPU ID.

hwFwmFaultReasonId

Alarm cause ID.

hwFwmFaultReasonDescription

Alarm cause.

Possible Causes

  • Cause 1: IPv4 FIB async db operation no response for 5mins.
  • Cause 2: IPv6 FIB async db operation no response for 5mins.

Procedure

Collect alarm, log, and configuration information, and contact technical support personnel.
