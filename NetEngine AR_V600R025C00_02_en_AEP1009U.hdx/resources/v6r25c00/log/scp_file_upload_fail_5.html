SSH/5/SCP_FILE_UPLOAD_FAIL

Message

SSH/5/SCP_FILE_UPLOAD_FAIL: The SCP server failed to receive the file [filename] from a client. (UserName=[username], UserAddress=[UserAddress], LocalAddress=[LocalAddress], VpnInstanceName=[VPNInstanceName], Transfer length=[length])

Description

The SCP server failed to receive files from the SCP client.

Parameters

Parameter Name Parameter Meaning

filename

File name.

username

User name.

UserAddress

IP address of a user.

LocalAddress

Local IP address.

VPNInstanceName

Name of a VPN instance.

length

File length.

Possible Causes

When the SCP client requested to upload a file to the SCP server, the file failed to be uploaded. The SCP server recorded this log.

Procedure

  • This message is informational only, and no action is required.
