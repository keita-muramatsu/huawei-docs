VTY/3/hwVtyExceed_active

Message

VTY/3/hwVtyExceed_active: The number of available VTY channels is lower than the threshold. (currentLoginVTYs=[hwCurrentVty], totalVTYs=[hwMaxVty])

Description

The number of available VTY channels is lower than the threshold.

Parameters

Parameter Name Parameter Meaning

hwCurrentVty

Number of VTY channels in use.

hwMaxVty

Total number of VTY channels.

Possible Causes

The number of available VTY channels is lower than the threshold.

Procedure

1. Increase the number of available VTY channels to a value greater than the threshold: Run the user-interface maximum-vty <number> command to increase the maximum number of VTY channels in the system. Increase the difference between first-ui-number and last-ui-number when running the user-interface vty first-ui-number [ last-ui-number ] command. Configure an authentication mode in the new VTY user interface view.

  • If the alarm is cleared, go to step 5.
  • If the alarm persists, go to step 2.

2. Log out users to increase the number of available VTY channels to a value greater than the threshold.

  • If the alarm is cleared, go to step 5.
  • If the alarm persists, go to step 3.

3. Run the user-interface vty available-vty-threshold command to reduce the alarm threshold for the number of available VTY channels.

  • If the alarm is cleared, go to step 5.
  • If the alarm persists, go to step 4.

4. Collect log and configuration information, and contact technical support personnel.

5. End.
