INFO/5/ALL_DBG_SWITCH_OFF

Message

INFO/5/ALL_DBG_SWITCH_OFF: All debug switches turned off for timeout. (TimerLength=[TimerLength])

Description

The timer expires, and all debugging functions are disabled.

Parameters

Parameter Name Parameter Meaning

TimerLength

Timeout interval of the timer, in minutes.

Possible Causes

The debugging function is controlled by a timer. When the timer expires, all debugging functions are disabled.

Procedure

  • Run the debugging timeout 0 command in the user view. The debugging function never times out. After the debugging is complete, manually disable the debugging function.
