FEI/2/hwBoardResThresholdExceed_active

Message

FEI/2/hwBoardResThresholdExceed_active: The number of forwarding resources reaches the alarm threshold. (Slot=[hwFwdResLackSlotStr],Threshold=[hwFwdResThreshold],Reason=[hwFwdResLackReasonId],Description=[hwReasonDescription])

Description

The remaining forwarding resources on the device were used up, and the amount of forwarding resources exceeded the alarm threshold.

Parameters

Parameter Name Parameter Meaning

hwFwdResLackSlotStr

Location of the alarm entity.

hwFwdResThreshold

Alarm threshold for forwarding resources.

hwFwdResLackReasonId

Alarm cause ID.

hwReasonDescription

Alarm cause.
