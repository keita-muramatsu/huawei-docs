WLAN/4/WLAN_RFM_INFO_RADAR_INFO

Message

WLAN/4/WLAN_RFM_INFO_RADAR_INFO: Detected radar. (ACMAC=[ACMAC], APMAC=[APMAC], APName=[APName], RadioID=[RadioID], CurrentChannel=[CurrentChannel], PreviousChannel=[PreviousChannel], CurrentSecondChannel=[CurrentSecondChannel], PreviousSecondChannel=[PreviousSecondChannel])

Description

An AP detected radar signals.

Parameters

Parameter Name Parameter Meaning

ACMAC

AC's MAC address.

APMAC

MAC address of the AP.

APName

AP name.

RadioID

Radio ID.

CurrentChannel

Current actual channel.

PreviousChannel

Channel used before channel switching.

CurrentSecondChannel

Current second channel.

PreviousSecondChannel

Second channel before channel switching.

Possible Causes

The AP detected radar signals on its working channel, and the dynamic frequency selection (DFS) mechanism triggers channel switching.

Procedure

This message is informational only and no action is required.
