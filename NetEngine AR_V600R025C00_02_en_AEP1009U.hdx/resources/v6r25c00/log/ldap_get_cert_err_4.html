PKI/4/LDAP_GET_CERT_ERR

Message

PKI/4/LDAP_GET_CERT_ERR: Realm [realm_name] failed to obtain CRL through LDAP. The reason for failure is:[reason_for_failure].

Description

Failed to manually obtain the certificate.

Parameters

Parameter Name Parameter Meaning

realm_name

Certificate file name.

reason_for_failure

Failure reason:

Cause 1: Failed to connect to the LDAP server, or the LDAP server failed to respond to the request.

Cause 2: The data length of the content returned by the LDAP server is invalid.

Cause 3: Failed to save the file to device.

Possible Causes

  • The link between the device and certificate server is disconnected.
  • The certificate server is not working properly.
  • The LDAP configuration of the device is incorrect.

Procedure

1. Run the ping command to check whether the link between the device and certificate server is reachable.

  • If not, ensure that the interface and IP address are correctly configured.
  • If yes, go to Step 2.

2. Check whether the certificate server functions properly.

  • If not, ensure that the certificate service of the certificate server has been enabled and is running properly.
  • If yes, go to Step 3.

3. Check whether the LDAP configuration of the device is correct, such as the URL, LDAP attribute value, user name, and password.

  • If not, modify the configuration.
  • If yes, go to Step 4.

4. Collect related information and contact technical support personnel.
