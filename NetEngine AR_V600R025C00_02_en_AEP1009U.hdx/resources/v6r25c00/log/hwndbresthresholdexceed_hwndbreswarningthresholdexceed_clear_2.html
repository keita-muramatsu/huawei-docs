GMDB/2/hwNDBResThresholdExceed_clear

Message

GMDB/2/hwNDBResThresholdExceed_clear: The usage of NDB resources is less than the threshold. (Slot=[hwNDBSlot], CPU=[hwNDBCpu], Threshold=[hwNDBThreshold], Current=[hwNDBCurrent], ReasonId=[hwNDBReasonId], Description=[hwNDBReason])

Parameters

Parameter Name Parameter Meaning

hwNDBSlot

Slot information.

hwNDBCpu

Processor ID.

hwNDBThreshold

Alarm threshold.

hwNDBCurrent

Current usage.

hwNDBReasonId

Alarm cause ID.

hwNDBReason

Alarm cause.

Possible Causes

The number of NDB resources is less than the threshold

Procedure

This trap message is informational only, and no action is required.
