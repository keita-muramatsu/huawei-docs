ERROR-DOWN/4/hwErrordown_clear

Message

ERROR-DOWN/4/hwErrordown_clear: Error-down recovered. (Ifindex=[IfIndex], Ifname=[IfName], Cause=[Cause], RecoverType=[RecoveryType])

Parameters

Parameter Name Parameter Meaning

IfIndex

Index of an interface

IfName

Interface name

Cause

Cause of the errordown event

RecoveryType

Alarm clearance type. The value is auto recovery or Null. The alarm clearance type triggered by restarting an interface is auto recovery.

Possible Causes

  • Cause 1:bpdu-protection fault recovery.
  • Cause 2:monitor-link fault recovery.
  • Cause 3:auto-defend fault recovery.

Procedure

This trap message is informational only, and no action is required.
