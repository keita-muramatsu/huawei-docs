BFD/4/STACHG_TOUP

Message

BFD/4/STACHG_TOUP: BFD session changed to Up. (SlotNumber=[SlotNumber], Discriminator=[Discriminator], FormerStatus=[FormerStatus], Applications=[Applications], BindInterfaceName=[BindInterfaceName], ProcessPST=[ProcessPST], TunnelName=[TunnelName], PeerIp=[PeerIp], EvplId=[EvplId])

Description

The BFD session went Up.

Parameters

Parameter Name Parameter Meaning

SlotNumber

Number of the slot where the BFD session status changes.

Discriminator

Discriminator of a session whose status changes.

FormerStatus

Other status. The value can be AdminDown, Down, or Init.

Applications

Application that is bound to the BFD session.

BindInterfaceName

Name of the bound interface.

ProcessPST

Flag bit of the PST that is modified.

TunnelName

Name of the tunnel.

PeerIp

Destination IP address of the BFD session.

EvplId

ID of an EVPL instance.

Possible Causes

Cause 1: A BFD session was created. That is, the BFD session changed from Init to Up.

Cause 2: The undo shutdown command was run to restore the BFD session. That is, the BFD session changed from AdmDown to Up.

Cause 3: The BFD session changed from Down to Up.

Procedure

This log message is informational only, and no action is required.
