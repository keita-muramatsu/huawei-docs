URL/4/FILTER

Message

URL/4/FILTER: The URL filtering policy was matched. (SyslogId=[syslog-id], VSys="[vsys-name]", Policy="[policy-name]", SrcIp=[source-ip-address], DstIp=[destination-ip-address], SrcPort=[source-port], DstPort=[destination-port], SrcZone=[source-zone], DstZone=[destination-zone], User="[user-name]", Protocol=[protocol], Application="[application-name]", Profile="[profile-name]", Type=[type], EventNum=[event-number], Category="[category]", SubCategory="[sub-category]", Page="[page]", Host="[host]", Referer="[refererhost]", Item="[item]", Action=[action], UserGroup="[group-name]")

This log is supported only on AR5710-S52T2XE4, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L50T2X4-T, AR6700-H series, AR6710-L8T3TS1X2, AR6710-L50T2X4, AR8100 series, AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S28T2S2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR6710-L14T2X4, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE-NRGL, AR6710-L26T2X4-T, AR5700-H series, AR5710-S8T2XE-LTE4EA-T, AR5710-S8T1XWE, AR5710-S8T2XE.

Description

URL filtering logs are generated when URLs are matched.

Parameters

Parameter Name Parameter Meaning

syslog-id

Sequence number of a log.

vsys-name

The value is fixed to Public.

policy-name

Name of a security policy.

source-ip-address

Source IP address of packets.

destination-ip-address

Destination IP address of packets.

source-port

Source port of packets.

destination-port

Destination port of packets.

source-zone

Source security zone of packets.

destination-zone

Destination security zone of packets.

user-name

User name.

If a user or security group matching condition is configured in a security policy that references a URL filtering profile, a log is generated when the security policy and URL rule are matched. The log records the user field.

protocol

Protocol name.

application-name

Application to which the packet belongs.

profile-name

Name of a configuration file.

type

Type of the matched rule defined in a URL filtering profile. The values are as follows:

  • Whitelist
  • Blacklist
  • Predefined
  • User-defined
  • Threat feed
  • Safe search
  • Timeout or default action

event-number

Number of merged events.

category

The value User-defined indicates that a user-defined URL category is matched. Other values indicate the name of the matched predefined URL category.

sub-category

When the value of the category field is User-defined, this field indicates the name of the matched user-defined URL category.

In other cases, this field indicates the subcategory of the matched predefined URL category.

page

Page field in the URL. For security purposes, the value of the page field is replaced with an asterisk (*).

host

Destination host name.

refererhost

Domain name in the Referer field in an HTTP request. If the Referer field information is not obtained, the value is empty.

item

Matched user-defined rules, including whitelist rules and blacklist rules.

This parameter is empty when a predefined rule, timeout action, or default action is matched.

action

Response action of the URL filtering profile. The options are as follows:

Allow: yes

Alert: alarm

Block: The interface is blocked

group-name

User group.

Possible Causes

URL filtering logs are generated when URLs are matched.

Procedure

This log message is informational only, and no action is required.
