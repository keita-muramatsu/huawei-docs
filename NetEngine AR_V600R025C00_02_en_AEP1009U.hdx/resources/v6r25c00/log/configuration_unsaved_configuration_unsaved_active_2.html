CONFIGURATION/2/CONFIGURATION_UNSAVED_active

Message

CONFIGURATION/2/CONFIGURATION_UNSAVED_active: Configuration changes are not saved within the specified time.

Description

Configuration changes were not saved within the specified period of time.

Parameters

None

Possible Causes

Configuration changes are not saved within the specified time.

Procedure

1. Run the save command to save configurations to the configuration file that takes effect upon the next startup.

2. Run the clear alarm alarm-name CONFIGURATION_UNSAVED command in the diagnostic view to clear the alarm.

3. Collect alarm, log, and configuration information, and contact technical support personnel.
