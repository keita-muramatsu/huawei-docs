GRESM/6/ALLOC_FREE_RES

Message

GRESM/6/ALLOC_FREE_RES: User occupied resource, but resource is not occupied in GRESM side, GRESM alloc resource to user. (ResourceType=[ResourceType], CompPid=[CompPid], CompType=[CompType])

Description

When a resource user applies for or releases resources from the GRESM, the GRESM records the resource usage. During the running of the system, the resources saved by the resource user and the GRESM may be inconsistent. During data smoothing or verification, if the GRESM finds that the resource is not occupied and the resource user occupies the resource, the GRESM allocates the resource to the resource user.

Parameters

Parameter Name Parameter Meaning

ResourceType

Resource type.

CompPid

PID of a component.

CompType

Component type.

Possible Causes

An exception occurs during component interaction. As a result, resource information recorded between components is inconsistent.

Procedure

  • This message is informational only, and no action is required.
