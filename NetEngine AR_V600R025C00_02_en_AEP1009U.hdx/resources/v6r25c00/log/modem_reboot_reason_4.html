WWAN/4/MODEM_REBOOT_REASON

Message

WWAN/4/MODEM_REBOOT_REASON: Modem reboot. (Interface=[interface-name], Reason=[reboot-reason])

Description

A modem is reset.

Parameters

Parameter Name Parameter Meaning

interface-name

Interface name.

reboot-reason

Description of the reset reason.

Possible Causes

Cause 1: The module fails to be initialized.

Cause 2: The module feature changes.

Cause 3: The module information fails to be obtained cyclically.

Cause 4: No service is automatically started.

Cause 5: The PS domain fails to be attached.

Cause 6: The number of dialup failures reaches the maximum.

Cause 7: Only uplink traffic is available for a long time and ICMP detection fails.

Cause 8: The number of ICMP detection failures reaches a specified value.

Cause 9: The module is restarted using a command.

Cause 10: The chip restarts unexpectedly.

Cause 11: The SIM card is switched.

Cause 12: The module is offline for a long time and restarts.

Cause 13: The SIM card is offline for a long time.

Procedure

Cause 1: The module fails to be initialized.

1. Collect alarm, log, and configuration information, and contact technical support personnel.

Cause 2: The module feature changes.

1. This message is informational only, and no action is required.

Cause 3: The module information fails to be obtained cyclically.

1. Collect alarm, log, and configuration information, and contact technical support personnel.

Cause 4: No service is automatically started.

1. Check whether the carrier network is normal. If so, go to step 2.

2. Check whether the configuration information is correct. If so, go to step 3.

3. Collect alarm, log, and configuration information, and contact technical support.

Cause 5: The PS domain fails to be attached.

1. Check whether the configuration information is correct. If so, go to step 2.

2. Collect alarm, log, and configuration information, and contact technical support.

Cause 6: The number of dialup failures reaches the maximum.

1. Check whether the configuration information is correct. If so, go to step 2.

2. Collect alarm, log, and configuration information, and contact technical support.

Cause 7: Only uplink traffic is available for a long time and ICMP detection fails.

1. Check whether the carrier network is normal. If so, go to step 2.

2. Collect alarm, log, and configuration information, and contact technical support.

Cause 8: The number of ICMP detection failures reaches a specified value.

1. Check whether the carrier network is normal. If so, go to step 2.

2. Collect alarm, log, and configuration information, and contact technical support.

Cause 9: The module is restarted using a command.

1. This message is informational only, and no action is required.

Cause 10: The chip restarts unexpectedly.

1. Collect alarm, log, and configuration information, and contact technical support personnel.

Cause 11: The SIM card is switched.

1. This message is informational only, and no action is required.

Cause 12: The module is offline for a long time and restarts.

1. This message is informational only, and no action is required.

Cause 13: The SIM card is offline for a long time.

1. This message is informational only, and no action is required.
