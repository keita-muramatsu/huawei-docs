AUTOM/6/NET_ASSISTANT_DEVACCOUNT_MODIFY_UNLOCK

Message

AUTOM/6/NET_ASSISTANT_DEVACCOUNT_MODIFY_UNLOCK: The operation to modify the password of net-assistant device account has been unlocked. (MacAddress=[macAddress], UserName=[userName])

Description

The lockout of the user password change operation on the net assistant device was removed.

Parameters

Parameter Name Parameter Meaning

macAddress

MAC address.

userName

User name.

Possible Causes

When the network-wide user name was the same as the login user name of the current session, the user command (net assistant device approval view) was run to change the dedicated network-wide password of the approved device. The old password failed to be entered for three consecutive times within 5 minutes, and the password was locked for 5 minutes and could not be changed. After 5 minutes, the lockout was removed and the password could be changed again. This log was recorded.

Procedure

This message is informational only, and no action is required.
