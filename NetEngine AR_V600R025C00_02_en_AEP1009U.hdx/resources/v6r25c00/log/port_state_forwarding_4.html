MSTP/4/PORT_STATE_FORWARDING

Message

MSTP/4/PORT_STATE_FORWARDING: The port has been set to forwarding state. (InstanceID=[InstanceID], PortIndex=[PortIndex], IfIndex=[IfIndex], PortName=[PortName], PwName=[PwName])

Description

The STP status of an interface changed to forwarding.

Parameters

Parameter Name Parameter Meaning

InstanceID

Instance ID.

PortIndex

MSTP port index.

IfIndex

Port index.

PortName

Port name.

PwName

PW name.

Possible Causes

The network topology changed.

Procedure

1. Check the physical devices in the network topology to see whether new physical links enabled with the spanning tree protocol are added.

  • If a new STP-enabled physical link is added, go to Step 2.
  • If no new STP-enabled physical link is added, go to Step 3.

2. Check whether the new physical link is the required one.

  • If the physical link is required, go to Step 3.
  • If the physical link is not required, go to Step 4.

3. Run the display stp command to check whether each port complies with the protocol calculation result.

  • If each port complies with the protocol calculation result, the alarm is cleared.
  • If the calculation result of a port does not comply with the protocol, go to Step 5.

4. Correctly deploy the network topology and check whether the alarm is cleared. If the alarm persists, go to Step 5.

5. Collect alarm and configuration information, and contact technical support personnel.
