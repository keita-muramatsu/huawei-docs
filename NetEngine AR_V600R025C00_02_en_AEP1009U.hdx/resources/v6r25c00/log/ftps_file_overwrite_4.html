FTPS/4/FTPS_FILE_OVERWRITE

Message

FTPS/4/FTPS_FILE_OVERWRITE: The file [fileName] was overwritten. (UserName=[UserName], UserAddress=[UserAddress], LocalAddress=[LocalAddress], VpnInstanceName=[VpnInstanceName])

Description

The file on the FTP server is overwritten.

Parameters

Parameter Name Parameter Meaning

fileName

Name of the file on the server.

UserName

User name.

UserAddress

IP address of a user.

LocalAddress

Local IP address.

VpnInstanceName

Name of a VPN instance.

Possible Causes

When a user uploads a file to the FTP server, the newly uploaded file overwrites the original file on the server.

Procedure

1. This message is informational only, and no action is required.
