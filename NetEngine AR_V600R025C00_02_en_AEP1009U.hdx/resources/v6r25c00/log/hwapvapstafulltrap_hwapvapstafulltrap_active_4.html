WLAN/4/hwApVapStaFullTrap_active

Message

WLAN/4/hwApVapStaFullTrap_active: VAP has the max number of stations notify. (APMAC=[APMAC], APName=[APName], RADIOID=[RADIOID], WLANID=[WLANID], FailCause=[FailCause], PermitNum=[PermitNum], APID=[APID])

Description

No STAs can be added to a VAP.

Parameters

Parameter Name Parameter Meaning

APMAC

MAC address of an AP.

APName

Name of an AP.

RADIOID

Radio ID.

WLANID

WLAN ID reporting the alarm.

FailCause

Cause of the STA authentication failure.

PermitNum

Number of STAs that can be associated with an AP.

APID

AP ID.

Possible Causes

The number of STAs connected to the VAP has reached the upper limit. New STAs cannot connect to the VAP.

Procedure

1. Check whether the maximum number of STAs that can be associated with a single VAP on the SSID is properly set.

  • If so, go to Step 3.
  • If not, go to Step 2.

2. Run the max-sta-number max-sta-number command in the SSID profile view to change the maximum number of STAs that can be associated with a single VAP to a proper value. Then, check whether the alarm persists.

  • If so, go to Step 3.
  • If not, go to Step 5.

3. The VAP cannot provide WLAN services to STAs. Associate new STAs to another VAP. Then, check whether the alarm persists.

  • If so, go to Step 4.
  • If not, go to Step 5.

4. Collect trap, log, and configuration information, and contact technical support.

5. End.
