ISIS/4/BKF_DC_TUPLE_EXCEED

Message

ISIS/4/BKF_DC_TUPLE_EXCEED: DC_TUPLE_EXCEED (D): (tableType=[tableTypeId],[tableType], tupleCount=[tupleCount], tupleCountMax=[tupleCountMax])

Description

The number of tuples in the DC exceeds the upper limit.

Parameters

Parameter Name Parameter Meaning

tableTypeId

Table type ID.

tableType

Table type.

tupleCount

Number of tuples.

tupleCountMax

Maximum number of tuples.

Possible Causes

The number of tuples in the DC exceeds the preset upper limit.

Procedure

Extend the number of tuples.
