PATCH/5/PATCHM_RUNNING_PATCH_CHANGE

Message

PATCH/5/PATCHM_RUNNING_PATCH_CHANGE: The current running patch is changed. (PatchName=[PatchName],PatchState=[PatchState])

Description

The version of the system software package is changed, which triggers the change of the running patch.

Parameters

Parameter Name Parameter Meaning

PatchName

Patch package name.

PatchState

Patch status.

Possible Causes

The version of the system software package is changed, which triggers the change of the running patch.

Procedure

This message is informational only, and no action is required.
