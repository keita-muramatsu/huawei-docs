INFO/6/SUPPRESS_SECLOG

Message

INFO/6/SUPPRESS_SECLOG: Last service log message repeated [repeat_num] [log_id].

Description

Duplicate security service logs are generated in the system.

Parameters

Parameter Name Parameter Meaning

repeat_num

Number of times that the last security service log message is repeated.

log_id

Log ID.

Possible Causes

Two or more consecutive duplicate security service logs are generated in the system. Consecutive duplicate security service logs refer to the logs with the same ID and parameter content.

Procedure

This log is informational only and no action is required.
