BFD/5/DELSESS

Message

BFD/5/DELSESS: The BFD session was deleted. (Discriminator=[Discriminator], Result=[Result], Applications=[Applications], BindIFName=[BindIFName], SourceIp=[SourceIp], PeerIp=[PeerIp])

Description

A BFD session was deleted.

Parameters

Parameter Name Parameter Meaning

Discriminator

Local discriminator of a session

Result

Whether a BFD session is deleted:

  • Succeeded
  • Failed

Applications

Application bound to a BFD session

BindIFName

Name of an interface bound to a BFD session

SourceIp

Source IP address

PeerIp

Destination IP address

Possible Causes

Cause 1: The BFD session was manually deleted.

Cause 2: When the dynamic BFD session was in the DetectDown or NeighborDown state, APP instructed BFD to delete the session.

Procedure

1. Perform either of the following operations:

  • If the deleted BFD session is a static session, no further action is required.
  • If the deleted BFD session is a dynamic session, go to Step 2.

2. Run the ping <ip-address> command to check whether the link detected by the BFD session fails to forward packets.

  • If so, go to Step 4.
  • If not, go to Step 3.

3. Collect log information and configuration information, and then contact technical support personnel.

4. End.
