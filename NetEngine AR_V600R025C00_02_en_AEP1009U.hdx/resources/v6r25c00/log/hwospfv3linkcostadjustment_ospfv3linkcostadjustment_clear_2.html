OSPFV3/2/hwospfv3LinkCostAdjustment_clear

Message

OSPFV3/2/hwospfv3LinkCostAdjustment_clear: An OSPFv3 link cost adjustment event is cleared. (ProcessId=[hwOspfv3ProcessId], AreaId=[hwOspfv3AreaIdIndex], InterfaceIndex=[hwOspfv3IfIndex], InstanceId=[hwOspfv3IfInstId], InterfaceName=[hwOspfv3IfName], Event=[hwOspfv3CostAdjustReason], OriginalCost=[hwOspfv3OriginalCost], AdjustedCost=[hwOspfv3AdjustedCost])

Parameters

Parameter Name Parameter Meaning

hwOspfv3ProcessId

OSPFv3 process ID

hwOspfv3AreaIdIndex

OSPFv3 area ID

hwOspfv3IfIndex

Interface index.

hwOspfv3IfInstId

ID of an OSPFv3 instance.

hwOspfv3IfName

Interface name

hwOspfv3CostAdjustReason

Reason for OSPFv3 to adjust the link cost:

  • 1: OSPFv3 adjusted the link cost due to a BFD fault on the link.
  • 2. OSPFv3 adjusted the link cost due to link quality deterioration.

hwOspfv3OriginalCost

Original cost.

hwOspfv3AdjustedCost

Link cost adjusted by OSPFv3. The actual cost of an OSPFv3 link is the maximum cost among all cost adjustment causes.

Possible Causes

  • Cause 1:The link BFD fault recovery.
  • Cause 2:The link quality status is restored.

Procedure

This message is informational only, and no action is required.
