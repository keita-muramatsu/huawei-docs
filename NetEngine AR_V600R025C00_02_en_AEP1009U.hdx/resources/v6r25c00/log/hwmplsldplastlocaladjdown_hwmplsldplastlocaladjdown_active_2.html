LDP/2/hwMplsLdpLastLocalAdjDown_active

Message

LDP/2/hwMplsLdpLastLocalAdjDown_active: The last local adjacency in the local-and-remote LDP session went Down because the Hello Hold timer expired. (VrfName=[VrfName], PeerLsrId=[PeerLsrId], IfName=[IfName])

Description

When local and remote LDP sessions coexist, the Hello hold timer of the last local adjacency times out and goes down.

Parameters

Parameter Name Parameter Meaning

VrfName

Index of the VRF to which the LDP peer belongs

PeerLsrId

LDP peer ID

IfName

Name of the physical interface that discovers the neighbor

Possible Causes

The last local adjacency in the local-and-remote LDP session went Down because the Hello Hold timer expired.

Procedure

1. By adding local adjacencies, you can change the peer status to prevent services from being affected.

  • If the alarm is cleared, go to Step 3.
  • If the alarm persists, go to Step 2.

2. Collect alarm and configuration information, and contact technical support engineers.

3. End.
