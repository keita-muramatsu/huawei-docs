TCP/4/SOCKET_TCP6_RCV_KC_AUTHEN_FAIL

Message

TCP/4/SOCKET_TCP6_RCV_KC_AUTHEN_FAIL: Receive TCP6 KeyChain authentication failed. (tcpConnLocalAddress=[tcpConnLocalAddress], tcpConnLocalPort=[tcpConnLocalPort], tcpConnRemAddress=[tcpConnRemAddress], tcpConnRemPort=[tcpConnRemPort], hwTCPProtocol=[hwTCPProtocol], hwTCPVrfName=[hwTCPVrfName])

Description

Keychain authentication failed on the packets received for TCP6 connection setup.

Parameters

Parameter Name Parameter Meaning

tcpConnLocalAddress

IPv6 address of the local end of a TCP6 connection

tcpConnLocalPort

Port number of the local end of the TCP6 connection

tcpConnRemAddress

Destination IPv6 address of the TCP6 connection

tcpConnRemPort

Port number of the peer end of the TCP6 connection

hwTCPProtocol

Name of an upper layer application protocol

hwTCPVrfName

Name of virtual routing and forwarding (VRF)

Possible Causes

Keychain authentication failed on the packets received for TCP6 connection setup.

Procedure

1. Run the display current-configuration command on both ends of the TCP6 connection to check whether keychain authentication is configured.

  • If keychain authentication is configured on one end, configure keychain authentication on the other end. Then, check whether the log is cleared.
  • Yes: Go to Step 3.
  • No: Go to Step 2.
  • If keychain authentication has been configured on both ends, go to Step 2.

2. Collect trap, log, and configuration information, and contact technical support personnel.

3. End.
