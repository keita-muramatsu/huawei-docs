MPLS_LSPM/4/hwMplsDynamicLabelThresholdExceed_active

Message

MPLS_LSPM/4/hwMplsDynamicLabelThresholdExceed_active: The dynamic label usage exceeds the threshold, which will affect the creation of BGP/LDP/RSVPTE/MPLS VPNs. (hwMplsDynamicLabelTotalCount=[DynamicLabelTotalCount], hwMplsDynamicLabelCurrentCount=[DynamicLabelCurrentCount], hwMplsDynamicLabelThresholdUpperLimit=[DynamicLabelThresholdUpperLimit], hwMplsDynamicLabelThresholdLowerLimit=[DynamicLabelThresholdLowerLimit])

Description

Dynamic label usage reached the upper threshold. The creation of BGP, LDP, RSVP TE, or MPLS VPN will be affected.

Parameters

Parameter Name Parameter Meaning

DynamicLabelTotalCount

Indicates the total number of dynamic labels.

DynamicLabelCurrentCount

Indicates the number of used dynamic labels.

DynamicLabelThresholdUpperLimit

Indicates the upper limit of dynamic label usage.

DynamicLabelThresholdLowerLimit

Indicates the lower limit of dynamic label usage.

Possible Causes

A great number of LSPs are established, and dynamic label usage reaches the upper threshold.

Procedure

1. Run the display mpls lsp statistics command to view statistics about LSPs. Re-plan the services and delete unwanted LSPs that use dynamic labels. Then check whether MPLS_LSPM_1.3.6.1.4.1.2011.5.25.121.2.1.68 hwMplsDynamicLabelThresholdExceedClear is generated.

  • If this clear alarm is generated, go to step 3.
  • If this clear alarm is not generated, go to step 2.

2. Collect alarm information and configuration information, and then contact technical support personnel.

3. End.
