BGP/6/SLOW_PEER_SINGLEGROUP

Message

BGP/6/SLOW_PEER_SINGLEGROUP: Message sending to the slow peer is too slow, and message sending to other peers in the group is affected. (bgpIndex=[bgpIndex], VpnInstance=[VpnInstance], Address Family=[addrFamily], Peer=[peer-address], Group ID=[groupID], TimeCost=[time], Flag=[Flag], SourceInterface=[SourceInterface])

Description

Message sending to a slow peer is too slow, and the message sending to other slow peers in the same group is affected.

Parameters

Parameter Name Parameter Meaning

bgpIndex

Index of a BGP instance. In the case of a non-multi-instance, the value is 0. In the case of a multi-instance, the value is a multi-instance index.

VpnInstance

Name of a VPN instance.

addrFamily

Address family.

peer-address

Address of a neighbor.

groupID

ID of an update peer-group.

time

Time taken to send messages, in seconds.

Flag

Peer status.

SourceInterface

Source interface.

Possible Causes

If the time taken to send messages to a peer is greater than or equal to the absolute time threshold for detecting slower peers to implement hierarchical slow-peer switching and all the other peers in the slow update peer-group have received messages from the device, message sending to other slow peers in the same group is suppressed.

Procedure

When the maximum number of slow peer groups that can be automatically switched to a single-peer update peer-group is reached, the system prompts you to perform manual intervention.
