OSPF/3/ospfVirtNbrStateChange_clear

Message

OSPF/3/ospfVirtNbrStateChange_clear: The status of the virtual neighbor changes. (VirtNbrArea=[VirtNbrArea], VirtNbrRtrId=[VirtNbrRtrId], ProcessId=[ProcessId], RouterId=[RouterId], VirtNbrState=[VirtNbrState], InstanceName=[InstanceName])

Parameters

Parameter Name Parameter Meaning

VirtNbrArea

Indicates the area ID.

VirtNbrRtrId

Indicates the router ID of the neighbor on the virtual link.

ProcessId

Indicates the process ID.

RouterId

Indicates the ID of the local router.

VirtNbrState

Indicates the status of a virtual neighbor. The trap is a service restoration trap only when the value of Full. Otherwise, it is a fault trap.

  • 1: Down
  • 2: Attempt
  • 3: Init
  • 4: 2-Way
  • 5: ExStart
  • 6: Exchange
  • 7: Loading
  • 8: Full

InstanceName

Indicates the instance name.

Possible Causes

The alarm was cleared.

Procedure

  • If the possible causes are appeared, this trap message is informational only, and no action is required.
