BGP/2/hwBgpBackwardTransition_clear

Message

BGP/2/hwBgpBackwardTransition_clear: The BGP FSM enters the Established state. (BgpPeerRemoteAddr=[PeerIpv4Ipv6Addr], InstanceId=[InstanceId], BgpPeerLastError=[PeerLastError], BgpPeerState=[PeerState], LocalIfName=[LocalIfName], Reason=[Reason], Description=[Description])

Parameters

Parameter Name Parameter Meaning

PeerIpv4Ipv6Addr

Peer address. For an IPv4 peer, this MIB object reports an IPv4 peer address. For an IPv6 peer, this MIB object reports an IPv6 peer address.

This alarm and the bgpBackwardTransition alarm are reported at the same time when a BGP peer relationship is established or interrupted.

InstanceId

Instance ID.

PeerLastError

Error code returned when the peer was disconnected last time.

The value of this parameter is displayed in the format of [ErrorCode][ErrorSubCode], where [ErrorCode] indicates an error code and [ErrorSubCode] indicates an error subcode.For example, in the value 35, 3 indicates an error code and 5 indicates an error subcode.For details about error codes, see "BGP Packet Format" in BGP Principles.The value 0 indicates that no error occurs.

PeerState

Peer status:

  • 1: indicates that the status is Down.
  • 6: indicates that the status is Up.

LocalIfName

Local interface name.

Reason

Cause of the peer disconnection.

  • Configuration lead peer down: The peer is disconnected due to the configuration.
  • Receive notification: A Notification message is received.
  • Receive error packet: An error packet is received.
  • Hold timer expire: The Hold timer expires.
  • Remote peer not reachable: The remote peer is unreachable.
  • Direct connect-interface down: The directly connected interface is Down.
  • Route limit: The number of routes reaches the upper limit.
  • System memory overloaded: The system memory is overloaded.

Description

Description of a neighbor.

Possible Causes

  • Cause 8:Alarm clear
  • Cause 10:The peer is deleted

Procedure

  • This message is informational only, and no action is required.
