FEI/4/hwMflpVlanLoopPeriodicTrap

Message

FEI/4/hwMflpVlanLoopPeriodicTrap: MAC flapping detected, VlanId = [VlanId], Original-Port = [IfNameA], Flapping port 1 = [IfNameB], port 2 = [IfNameC]. [AlarmReason].

Description

MAC address flapping occurs in the VLAN.

Parameters

Parameter Name Parameter Meaning

VlanId

VLAN ID.

IfNameA

Port before failover.

IfNameB

Port 1 after failover.

IfNameC

Port 2 after failover.

AlarmReason

Alarm cause.

Possible Causes

By default, when a user MAC address is learned from different interfaces for more than 10 times, a flapping alarm is generated.

You can run the mac-address flapping detection [ security-level { low | middle | high } ] command to set the security level of MAC address flapping detection.

Procedure

  • Configure the interface to enter the Error-Down state when MAC address flapping occurs or eliminate network loops.
