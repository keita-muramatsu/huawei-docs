SPM/7/SOFT_EWM_STATUS_CHANGE

Message

SPM/7/SOFT_EWM_STATUS_CHANGE: The status of the electronic software warranty information changed. (Version = [Version], EOS date = [EosDate], status = [Status])

Description

Record the version number, EOS time, and status of the electronic warranty of the software.

Parameters

Parameter Name Parameter Meaning

Version

Version number.

EosDate

EOS time.

Status

Electronic warranty status of the software.

Possible Causes

Record the version number, EOS time, and status of the electronic warranty of the software.

Procedure

This message is informational only, and no action is required.
