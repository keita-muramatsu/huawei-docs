ISIS/3/IS_LSDB_OVERFLOW

Message

ISIS/3/IS_LSDB_OVERFLOW: ISIS [ProcessId] Level-[level] LSDB was overflow.

Description

The LSDB of an IS-IS process overflowed. The imported routes are not advertised.

Parameters

Parameter Name Parameter Meaning

ProcessId

ID of an IS-IS process

level

IS-IS level

Possible Causes

The LSDB of an IS-IS process overflowed.

Procedure

  • Configure virtual systems or delete some routes, and then run the reset isis all command to restart all IS-IS processes.
