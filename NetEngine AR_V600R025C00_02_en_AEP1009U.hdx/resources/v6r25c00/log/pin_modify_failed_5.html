WWAN/5/PIN_MODIFY_FAILED

Message

WWAN/5/PIN_MODIFY_FAILED: Failed to modify the PIN. (Interface=[Interface], SIMID=[SIMID])

Description

The PIN failed to be changed.

Parameters

Parameter Name Parameter Meaning

Interface

Cellular interface name.

SIMID

SIM card ID.

Possible Causes

Cause 1: The current PIN is incorrect.

Cause 2: The two new passwords entered are different.

Procedure

Cause 1: The current PIN is incorrect.

1. Verify the PIN again.

2. End.

Cause 2: The two new passwords entered are different.

1. Enter the new PIN again.

2. End.
