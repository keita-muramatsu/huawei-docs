SRPOLICY/2/hwSrPolicyCandiPathDown_active

Message

SRPOLICY/2/hwSrPolicyCandiPathDown_active: The SR Policy's candidate path went down. (hwSrPolicyEndpoint=[SrPolicyEndpoint],hwSrPolicyColor=[SrPolicyColor],hwProtocolOrigin=[ProtocolOrigin],hwNodeAddress=[NodeAddress],hwASN=[ASN],hwDiscriminator=[Discriminator],hwPreference=[Preference],hwCandipathDownReason=[DownReason])

Description

The candidate path of the SR Policy went Down.

Parameters

Parameter Name Parameter Meaning

SrPolicyEndpoint

Destination address

SrPolicyColor

Color

ProtocolOrigin

Protocol source

NodeAddress

Node addresses

ASN

AS number

Discriminator

Discriminator

Preference

Priority

DownReason

Cause of the down event

Possible Causes

  • Cause 1: BFD went Down.
  • Cause 2: The candidate path became invalid.

Procedure

  • Cause 1: BFD went Down.

    Check the cause of the BFD Down event.

  • Cause 2: The candidate path became invalid.

    1. Check the link.

    2. Configure a valid segment list for the candidate path.
