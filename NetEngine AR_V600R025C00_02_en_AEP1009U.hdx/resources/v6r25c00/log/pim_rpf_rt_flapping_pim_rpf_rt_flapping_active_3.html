PIM/3/PIM_RPF_RT_FLAPPING_active

Message

PIM/3/PIM_RPF_RT_FLAPPING_active: The RPF route is flapping. (AddressFamily=[AddressFamily], SrcAddr=[SrcAddr], InstanceName=[InstanceName])

Description

The RPF route flapped.

Parameters

Parameter Name Parameter Meaning

AddressFamily

Address family.

SrcAddr

Multicast source address.

InstanceName

Instance name.

Possible Causes

The route flapped

Procedure

1. Run the display ip routing-table or display ipv6 routing-table command to check whether the unicast route from the local device to the neighbor works properly.

  • If the route works properly, go to Step 2.
  • If the route works improperly, rectify the routing fault to clear the alarm.

2. Collect alarm and configuration information, and then contact technical support personnel.
