WLAN/2/hwAPIoTServerStartFailTrap_active

Message

WLAN/2/hwAPIoTServerStartFailTrap_active: Failed to start the server used by the IoT card. (Cause: The TCP/UDP port is occupied.) (APMAC=[APMAC], APName=[APName], ApIotCardId=[ApIotCardId], Port=[Port], APID=[APID])

Description

Failed to start the server module on an AP for receiving IoT card data.

Parameters

Parameter Name Parameter Meaning

APMAC

MAC address of an AP.

APName

Name of an AP.

ApIotCardId

Card slot ID of an AP.

Port

UDP port number.

APID

AP ID.

Possible Causes

The port used by the server module on the AP for receiving IoT card data was occupied.

Procedure

1. Run the iot-profile (IoT card interface view) command to change the port number.

2. End.
