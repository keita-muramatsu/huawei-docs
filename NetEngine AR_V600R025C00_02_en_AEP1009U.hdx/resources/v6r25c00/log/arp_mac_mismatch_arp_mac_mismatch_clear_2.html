ARP/2/ARP_MAC_MISMATCH_clear

Message

ARP/2/ARP_MAC_MISMATCH_clear: The MAC of static ARP set by user is equal to the actual MAC address. (StaticIP=[StaticIP], VPNInstance=[VPNInstance], StaticMAC=[StaticMAC])

Parameters

Parameter Name Parameter Meaning

StaticIP

Indicates the IP address specified in a static ARP entry.

VPNInstance

Indicates the VPN specified in a static ARP entry.

StaticMAC

Indicates the MAC address specified in a static ARP entry.

Possible Causes

1.The local MAC address became the same as the remote MAC address after static ARP was reconfigured on the local end.

2.The MAC address of the remote interface became the same as that in the static configuration after the peer board was replaced.

3.The local device did not receive any ARP packet whose MAC address is different from that in the static ARP entry within 30 minutes.

Procedure

1. Reconfigure the static ARP MAC address of the local end to be consistent with the MAC address of the peer end.

2. Replace the peer board to ensure that the MAC address of the local port is the same as the static MAC address.
