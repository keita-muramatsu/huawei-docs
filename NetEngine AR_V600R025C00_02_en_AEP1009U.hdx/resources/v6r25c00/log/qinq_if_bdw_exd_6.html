L2-MULTICAST/6/QINQ_IF_BDW_EXD

Message

L2-MULTICAST/6/QINQ_IF_BDW_EXD: The bandwidth of multicast groups reached the upper limit. (IfName=[IfName], ConfiguredValue=[ConfiguredValue], CurrentMulticastGroup=[CurrentMulticastGroup], PE-Vid=[PE-Vid], CE-Vid=[CE-Vid])

Description

The bandwidth of multicast groups on the sub-interface for QinQ VLAN tag termination reached the upper limit.

Parameters

Parameter Name Parameter Meaning

IfName

Name of the sub-interface for QinQ VLAN tag termination

ConfiguredValue

Upper limit of the bandwidth of multicast groups on the sub-interface

CurrentMulticastGroup

Multicast group address of the denied Join message

PE-Vid

Outer VLAN ID

CE-Vid

Inner VLAN ID

Possible Causes

The bandwidth of multicast groups on the sub-interface for QinQ VLAN tag termination reached the upper limit.

Procedure

This log message is informational only, and no action is required.
