ISIS/4/ISIS_REMOTE_LINK_LOCAL_CHANGE

Message

ISIS/4/ISIS_REMOTE_LINK_LOCAL_CHANGE: The IPv6 link-local address in the IS-IS Hello packet received from the neighbor changed. (InstanceID=[InstanceID], IfName=[IfName], Level=[Level], OldAddress=[OldAddress], NewAddress=[NewAddress])

Description

When the IS-IS IPv6 neighbor relationship is Up, the link-local address of the neighbor in the received Hello packet is changed.

Parameters

Parameter Name Parameter Meaning

InstanceID

ID of an IS-IS process.

IfName

Interface name.

Level

IS-IS level.

OldAddress

Old link-local address.

NewAddress

New link-local address.

Possible Causes

When the IS-IS IPv6 neighbor relationship is Up, the link-local address of the neighbor in the received Hello packet is changed.

The link-local address of the neighbor is changed proactively or tampered with during Hello packet transmission.

Procedure

1. Run the display isis peer command on the neighbor to locate the interface on which the neighbor relationship is established.

2. Run the display this command in the interface view to check the link-local address of the interface. If the displayed link-local address is the same as the new link-local address reported in the log, no action is required. Otherwise, collect log and configuration information and contact technical support personnel.
