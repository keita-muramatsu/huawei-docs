WLAN/4/AP_WIRELESS_PORT_DOWN_clear

Message

WLAN/4/AP_WIRELESS_PORT_DOWN_clear: AP radio down is recovered notify. (APMAC=[APMAC], RadioID=[RadioID], APName=[APName], CauseId=[CauseId], CauseStr=[CauseStr], APID=[APID])

Parameters

Parameter Name Parameter Meaning

APMAC

MAC address of an AP.

RadioID

Radio ID.

APName

Name of an AP.

CauseId

ID of the radio disconnection cause.

CauseStr

Reason why a radio was disconnected or recovered.

•Radio disabled due to command execution: A radio shutdown command is delivered.

•Radio disabled due to an error: An error occurs.

•Radio disabled due to calibration: Radio calibration is performed.

•Radio disabled due to low power consumption: The power consumption is low.

•Radio disabled due to 3GPP base station notification: The 3GPP base station sends a radio shutdown instruction.

•Radio enabled due to command execution: A command to open the radio is delivered.

•Radio enabled upon error restoration: The error is eliminated.

•Radio enabled upon calibration completion: Radio calibration is completed.

•Radio enabled upon lower power consumption recovered: The power consumption is restored.

•Radio enabled due to 3GPP base station notification: The 3GPP base station sends an instruction to open the radio.

APID

AP ID.

Possible Causes

  • Cause 1:A command to open the radio is delivered.
  • Cause 3:The error is eliminated.
  • Cause 5:Radio calibration is completed.
  • Cause 7:The power consumption is restored.
  • Cause 9:The 3GPP base station sends an instruction to open the radio.

Procedure

No action is required.
