PIM/2/PIM_SRC_PER_GRP_NUM_LIMIT_active

Message

PIM/2/PIM_SRC_PER_GRP_NUM_LIMIT_active: At least one multicast group's multicast source number reached the upper limit. (AddressFamily=[AddressFamily], InstanceName=[InstanceName], LimitCount=[LimitCount])

Description

The number of multicast sources corresponding to at least one multicast group reaches the upper limit.

Parameters

Parameter Name Parameter Meaning

AddressFamily

Address family.

InstanceName

Name of a VPN instance.

LimitCount

Maximum number of multicast sources corresponding to a single multicast group.

Possible Causes

  • Cause 1: Entry create
  • Cause 2: Configuration change

Procedure

  • Cause 1: Entry create

    1. Run the display this command in the PIM instance view to check whether the limit of one-group-multiple-source is too small.

    • If yes, go to Step 2.
    • If no, go to Step 3.

    2. Run the source-per-group limit command to adjust the limit of one-group-multiple-source. Then, check whether the fault is rectified.

    • If yes, go to Step 4.
    • If no, go to Step 3.

    3. Collect alarm and configuration information, and contact technical support personnel.

    4. End.

  • Cause 2: Configuration change

    Same as Cause 1.
