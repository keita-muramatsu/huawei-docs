DEBUG/4/HAF_CPUOVLOAD_FAULT

Message

DEBUG/4/HAF_CPUOVLOAD_FAULT: The CPU is overloaded and certain messages are lost. As a result, information about CPU usage of the process (ID=[ProcessID]) cannot be collected.

Description

The CPU is overloaded. When the top 3 CPU usage is obtained, internal messages are lost. As a result, the recorded content is incomplete.

Parameters

Parameter Name Parameter Meaning

ProcessID

Process ID.

Possible Causes

Internal messages are lost.

Procedure

  • Collect log and configuration information, and contact technical support personnel.
