NETCONF/5/NCA_CAPABILITY_CHANGE

Message

NETCONF/5/NCA_CAPABILITY_CHANGE: The capability set that the NETCONF server supports changed. (Server=[Server], UserName=[UserName], SessionId=[SessionId], IpAddress=[IpAddress], AddedCapability=[AddedCapability], DeletedCapability=[DeletedCapability], ModifiedCapability=[ModifiedCapability])

Description

The capability set supported by the NETCONF server changed.

Parameters

Parameter Name Parameter Meaning

Server
  • true: The capability set change is not triggered by a user.
  • false: The capability set is changed due to user triggering.

UserName

User name of a NETCONF session.

SessionId

NETCONF session ID.

IpAddress

IP address of a NETCONF session.

AddedCapability

Add capability.

DeletedCapability

Delete capability.

ModifiedCapability

Modify capability.

Possible Causes

Patch installation may cause the capability set to change.

Procedure

  • This message is informational only, and no action is required.
