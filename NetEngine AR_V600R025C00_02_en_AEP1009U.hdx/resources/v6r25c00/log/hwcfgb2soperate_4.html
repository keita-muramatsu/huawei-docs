CONFIGURATION/4/hwCfgB2SOperate

Message

CONFIGURATION/4/hwCfgB2SOperate: Begin to back up the current configuration to the server.

Description

The current configuration file is backed up to the server.

Parameters

None

Possible Causes

The device starts to back up the configuration file to the server at the specified time.

Procedure

  • This message is informational only, and no action is required.
