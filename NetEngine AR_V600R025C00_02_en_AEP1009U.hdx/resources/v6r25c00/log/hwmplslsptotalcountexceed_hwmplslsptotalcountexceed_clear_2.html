MPLS_LSPM/2/hwMplsLspTotalCountExceed_clear

Message

MPLS_LSPM/2/hwMplsLspTotalCountExceed_clear: The lsp count falls from the upper limit. (hwMplsLspProtocol=[LspProtocol])

Parameters

Parameter Name Parameter Meaning

LspProtocol

LSP protocol type:

1: MPLS LSP

Possible Causes

The number of LSPs of hwMplsLspProtocol type fell below 95% of the upper limit.

Procedure

This alarm message is informational only, and no action is required.
