CM/5/ADMIN_USER_OFFLINERESULT

Message

CM/5/ADMIN_USER_OFFLINERESULT: USER_INFO_OFFLINE. ([info])

Description

A user goes offline.

Parameters

Parameter Name Parameter Meaning

info

USER_INFO_OFFLINE: The wired user is offline.

DEVICEMAC: MAC address of the device.

DEVICENAME: device name.

USER: user name. The user name can be displayed only as a combination of letters, digits, and special characters. Other languages such as Chinese are not supported.

MAC: MAC address of a user.

IPADDRESS: IP address of a user. If no IP address is available when the user is offline, "-" is displayed.

TIME: system time.

ZONE: time zone.

DAYLIGHT: whether DST is used.

ERRCODE: error code indicating that a user goes offline.

RESULT: user offline result.

AUTHENPLACE: user authentication location.

CIB ID: CIB ID.

EXTENDINFO: signal strength of offline users.

INTERFACE: access interface. For administrators, this field is not recorded. For other users, if the user access interface is invalid, this field is not recorded.

ACCESS TYPE: access type. If a user fails to go online, the access type is recorded as None.

VPNNAME: VPN name of a user.

SelectRDSIP: RADIUS server that fails to be authenticated.

IP address of the intermediate RADIUS server (which has been selected but not in use). The value - indicates that the authentication mode is not RADIUS or no intermediate RADIUS server is available.

SeclectERRCODE: error code of a RADIUS authentication failure.

Reason why the intermediate RADIUS server is not used. The value - indicates that the authentication mode is not RADIUS or only one RADIUS server is available. Otherwise, the value is 205.

RDSIP: IP address of the RADIUS server.

AuthFailType: access type of users who fail to be authenticated.

If the authentication is successful, None is displayed. If the authentication fails, the failure cause is displayed. In other scenarios (for example, if the user is in pre-connection state), this field is not displayed.

This field is not supported in user login and authorization logs.

AUTHID: ID of a user in the log sent to the analyzer.

Possible Causes

A user goes offline.

Procedure

If the user is disconnected unexpectedly, locate the fault or contact technical support. If the user proactively goes offline, no action is required.
