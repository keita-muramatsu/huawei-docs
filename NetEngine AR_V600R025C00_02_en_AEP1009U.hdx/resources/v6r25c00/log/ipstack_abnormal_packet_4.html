LDM/4/IPSTACK_ABNORMAL_PACKET

Message

LDM/4/IPSTACK_ABNORMAL_PACKET: Statistics of dropped malformed packets and flood packets in [Interval] minutes. (DropType=[DropType],DropCount=[DropCount],InterfaceName=[InterfaceName],DetailInfo=[DetailInfo])

Description

Statistics on abnormal packets for attack defense

Parameters

Parameter Name Parameter Meaning

Interval

Period for collecting statistics on discarded attack packets, in minutes.

DropType

Type of discarded attack packets

DropCount

Number of discarded attack packets within a period

InterfaceName

Inbound interface of the first attack packet

DetailInfo

Attack packet characteristics

Possible Causes

Analyze possible attack types and impacts in attack scenarios.

Procedure

Develop mitigations based on attack types.
