LCS/2/hwGtlResourceUsedUp_active

Message

LCS/2/hwGtlResourceUsedUp_active: Resource item [hwGtlResourceItem] is nearly used up. (ItemDescription=[hwGtlItemDescription])

Description

The resources of an active resource item in a license file were almost used up.

Parameters

Parameter Name Parameter Meaning

hwGtlResourceItem

Resource item in a license file.

hwGtlItemDescription

Control item description in a license file.

Possible Causes

The usage of an active resource item (not an interface resource item) in the license file exceeded the upper threshold.

Procedure

1. Apply for a license file with higher specifications from Huawei. For details, see the License Usage Guide of the corresponding product.

2. Upload the license file to the device.

3. The license active <filename> command is run in the user view to activate a license file.

4. To disable the function of reporting the alarm indicating insufficient license resources, run the set license threshold alarm disable command.
