IGMP/4/hwMgmdBoardLimitThresholdExceed_active

Message

IGMP/4/hwMgmdBoardLimitThresholdExceed_active: IGMP or MLD total entries count on the board reached the upper threshold. (AddressFamily=[AddressFamily], SlotName=[SlotName], CurrentCount=[CurrentCount], LimitCount=[LimitCount], Threshold=[Threshold]%)

Description

The number of IGMP/MLD entries on the board reached the upper threshold.

Parameters

Parameter Name Parameter Meaning

AddressFamily

Address family:

  • 1: IPv4 address family.
  • 2: IPv6 address family.

SlotName

Slot name of a board.

CurrentCount

Total number of IGMP/MLD entries on the current board. The IGMP/MLD entries that are newly added are not included.

LimitCount

Maximum number of IGMP/MLD entries allowed on a board.

Threshold

Alarm threshold.

Possible Causes

Entry create

Procedure

  • This message is informational only, and no action is required.
