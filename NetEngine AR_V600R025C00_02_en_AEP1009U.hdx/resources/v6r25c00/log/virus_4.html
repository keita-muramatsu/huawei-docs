AV/4/VIRUS

Message

AV/4/VIRUS: A virus was detected. (SyslogId=[syslog-id], VSys="[vsys-name]", Policy="[policy-name]", SrcIp=[source-ip-address], DstIp=[destination-ip-address], SrcPort=[source-port], DstPort=[destination-port], SrcZone=[source-zone], DstZone=[destination-zone], User="[user-name]", Protocol=[protocol], Application="[application-name]", Profile="[profile-name]", EventNum=[event-number], SignatureId=[signature-id], VirusName="[virus-name]", DetectionType="[detection-type]", Direction=[direction], FileName="[file-name]", FileType="[file-type]", Action=[action], Hash="[hash]", Severity="[severity]", Extend="[extend]", UserGroup="[group-name]")

This log is supported only on AR5710-S52T2XE4, AR6710-L8T3TS1X2-T, AR6710-L26T2X4, AR6710-L50T2X4-T, AR6700-H series, AR6710-L8T3TS1X2, AR6710-L50T2X4, AR8100 series, AR5710-S8TWDSE-LTE4EA, AR8700 series, AR5710-S28T2S2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL, AR6710-L14T2X4, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE-NRGL, AR6710-L26T2X4-T, AR5700-H series, AR5710-S8T2XE-LTE4EA-T, AR5710-S8T1XWE, AR5710-S8T2XE.

Description

Viruses are detected during virus detection.

Parameters

Parameter Name Parameter Meaning

syslog-id

Log sequence number.

vsys-name

The value is fixed to Public.

policy-name

Name of a security policy.

source-ip-address

Source IP address.

destination-ip-address

Destination IP address.

source-port

Source port.

destination-port

Destination port.

source-zone

Source security zone.

destination-zone

Destination security zone.

user-name

User name.

If a user or security group matching condition is configured in a security policy that references an antivirus profile, a log is generated when the security policy is matched and a virus is detected. The log records the user field.

protocol

Protocol.

application-name

Application to which the packet belongs.

profile-name

Name of a configuration file.

event-number

Number of events.

signature-id

Virus signature sequence number.

virus-name

Virus name.

detection-type

Detection type.

direction

Transfer direction.

file-name

File name.

file-type

File type.

action

Action.

hash

Hash value of a file.

severity

Severity.

extend

Extended field.

group-name

User group.

Possible Causes

Viruses are detected during virus scanning.

Procedure

The system has automatically processed the alarm. No manual operation is required.
