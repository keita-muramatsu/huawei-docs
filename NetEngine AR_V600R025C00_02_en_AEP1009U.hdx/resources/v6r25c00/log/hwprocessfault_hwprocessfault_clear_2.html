SEM/2/hwProcessFault_clear

Message

SEM/2/hwProcessFault_clear: The process fault is rectified. (Slot=[SlotId], ProcessName=[ProcessName], ProcessId=[ProcessId], ProcessFaultReason=[FaultReason])

Parameters

Parameter Name Parameter Meaning

SlotId

ID of the slot where the faulty process resides.

ProcessName

Name of the faulty process.

ProcessId

ID of the faulty process.

FaultReason

Reason for the process fault.

Possible Causes

  • Cause 1:The process fault is rectified.
  • Cause 2:The process startup fault is rectified.

Procedure

This message is informational only, and no action is required.
