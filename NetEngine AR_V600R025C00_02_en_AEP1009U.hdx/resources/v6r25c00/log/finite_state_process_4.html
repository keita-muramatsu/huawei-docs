FIPS/4/FINITE_STATE_PROCESS

Message

FIPS/4/FINITE_STATE_PROCESS: FIPS finite state has been switched. (previous state=[prestate], current state=[state], slot=[slot], cpu=[cpu])

Description

The system detects that the status of the FIPS finite state machine changes.

Parameters

Parameter Name Parameter Meaning

prestate

FIPS status before the change:

  • Power on: The device is powered on.
  • Powerup Self Test: The device performs self-check after startup.
  • Mode Init: The FIPS mode is initialized.
  • None Fips: The system is not in FIPS mode.
  • Ready: The system is ready.
  • Condition Self Test: The system performs condition self-check.
  • Crypto Officer States: The system is in the crypto officer state.
  • Software Error: The system receives a software error report.
  • Fatal Error: A fatal error occurs in the system.

state

FIPS status after the change:

  • Power on: The device is powered on.
  • Powerup Self Test: The device performs self-check after startup.
  • Mode Init: The FIPS mode is initialized.
  • None Fips: The system is not in FIPS mode.
  • Ready: The system is ready.
  • Condition Self Test: The system performs condition self-check.
  • Crypto Officer States: The system is in the crypto officer state.
  • Software Error: The system receives a software error report.
  • Fatal Error: A fatal error occurs in the system.

slot

Slot ID.

cpu

CPU ID

Possible Causes

After the system is started, the FIPS state machine switches to the Power on and Powerup Self Test states in sequence. After the Powerup Self Test is passed, the FIPS state machine switches to the Mode Init state. If the self-check fails, the FIPS state machine directly switches to the Fatal Error state. When the system is in non-FIPS mode, the state machine switches from the Mode Init state to the None Fips state, and then the state machine status does not change. When the system is in FIPS mode, the state machine switches to the Ready state. Condition Self Test is temporarily triggered by a scheduled task or service. If the self-check is successful, the FIPS state machine returns to the Ready state. If the self-check fails, the FIPS state machine records a software error and attempts to rectify the fault. If the rectification is successful, the FIPS state machine returns to the Ready state. If the rectification fails, the FIPS state machine switches to the Fatal Error state.

Procedure

This message is informational only, and no action is required.
