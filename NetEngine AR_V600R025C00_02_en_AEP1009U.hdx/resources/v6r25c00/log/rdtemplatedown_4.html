AAA/4/RDTEMPLATEDOWN

Message

AAA/4/RDTEMPLATEDOWN: Communication with the RADIUS Server template (name: [name]) is interrupted!

Description

The RADIUS server template goes down.

Parameters

Parameter Name Parameter Meaning

name

Name of a RADIUS server template.

Possible Causes

All authentication servers in the RADIUS server template are disconnected, and the template state changes to down.

  • The link between the device and RADIUS server is disconnected.
  • The shared key is changed on the device or RADIUS server.
  • The RADIUS server is abnormal.

Procedure

1. Check whether communication between the device and RADIUS authentication server is interrupted.

  • Ping the RADIUS authentication server from the device to check whether the link is normal.
  • Run the test-aaa command to check whether the service between the device and RADIUS server is normal.

2. Run the display radius-server configuration command to check whether the shared key configured on the device is the same as that on the RADIUS server.

3. If the fault persists, collect logs and configuration information, and contact technical support.
