SUM/6/SSUM_VERSION_NEED_UPGRADE

Message

SUM/6/SSUM_VERSION_NEED_UPGRADE: The software package has a new version and can be upgraded.

Description

An event log is generated when the software package can be upgraded.

Parameters

None

Possible Causes

The software package has a new version and can be upgraded.

Procedure

A message is displayed, indicating that the software package has an upgrade version and the upgrade can be performed.
