PKI/4/KEY_DESTROY_FAILED

Message

PKI/4/KEY_DESTROY_FAILED: Deleting [key_type] local key pair [key_name] failed.

Description

Failed to destroy the key pair.

Parameters

Parameter Name Parameter Meaning

key_type

Key pair type.

key_name

Key pair name.

Possible Causes

  • The key pair does not exist.
  • The key pair is being used by a service.

Procedure

1. Check whether the key pair exists on the device. For example, run the display pki rsa local-key-pair public command to view information about the RSA key pair.

  • If not, check whether other key pairs need to be deleted.
  • If yes, go to step 2.

2. Check whether the key pair is being used by services. For example, check whether the key pair is being used by a PKI realm.

  • If yes, cancel the use of the key pair.
  • If not, go to step 3.

3. Collect related information and contact technical support personnel.
