PKI/2/hwPKICrlInvalid_active

Message

PKI/2/hwPKICrlInvalid_active: The crl is invalid. (CrlIssuer=[issuer], CrlStartTime=[start-time], CrlFinishTime=[finish-time])

Description

The CRL is invalid.

Parameters

Parameter Name Parameter Meaning

issuer

Issuer of the CRL.

start-time

Time when the CRL starts to take effect.

finish-time

Time when the CRL expires.

Possible Causes

Indicates that the current system time is out of the CRL validity period.

Procedure

1. Run the display clock command to check whether the device time is correct.

If not, run the clock datetime command in the user view to change the device time.

2. Obtain a new CRL. For details, see "Checking the Local Certificate Status" in PKI Configuration.
