PKI/4/WHITELIST_IMPORT_ERR

Message

PKI/4/WHITELIST_IMPORT_ERR: Importing whitelist ([file-name]) failed.

Description

Failed to import the certificate whitelist.

Parameters

Parameter Name Parameter Meaning

file-name

Name of a certificate whitelist file.

Possible Causes

1. The certificate whitelist file is invalid.

2. The number of imported certificate whitelist files exceeds the upper limit (10).

3. The total number of CNs in the certificate whitelist file of the device reaches the upper limit (40,000).

4. The imported certificate whitelist file contains too many CNs.

Procedure

  • The certificate whitelist file is invalid. The certificate whitelist file is in XML format and uses the 7-bit ASCII coding mode. Confirm and modify the content.
  • The number of imported certificate whitelist files exceeds the upper limit.

Check whether the certificate whitelist file in the device memory is required. If not, run the pki delete whitelist command to delete the unnecessary certificate whitelist file.

  • The total number of CNs in the certificate whitelist file of the device reaches the upper limit.

Check whether the common name in the certificate whitelist file in the device memory is required. If the common name is not required, perform the following steps:

1. Save the certificate whitelist file in the storage card of the device to the PC through TFTP.

2. Delete unnecessary common names from the certificate whitelist file.

3. Run the pki delete whitelist command to delete the certificate whitelist file.

4. Upload the modified certificate whitelist file from the PC to the storage card of the device through TFTP.

5. Run the pki import whitelist command to import the certificate whitelist file to the device memory.

  • The imported certificate whitelist file contains too many CNs.

The total number of CNs in the imported certificate whitelist file and in the certificate whitelist file in the device memory exceeds the upper limit. Check whether the CNs in the certificate whitelist file are required. If they are not required, perform the following steps:

  • Delete unnecessary common names from the imported certificate whitelist file.

1. Delete unnecessary common names from the imported certificate whitelist file.

2. Upload the modified certificate whitelist file from the PC to the storage card of the device through TFTP.

3. Run the pki import whitelist command to import the certificate whitelist file to the device memory.

  • Delete unnecessary common names from the certificate whitelist file in the device memory.

1. Save the certificate whitelist file in the storage card of the device to the PC through TFTP.

2. Delete unnecessary common names from the certificate whitelist file.

3. Run the pki delete whitelist command to delete the certificate whitelist file.

4. Upload the modified certificate whitelist file from the PC to the storage card of the device through TFTP.

5. Run the pki import whitelist command to import the certificate whitelist file to the device memory.
