TRUSTEM/2/hwTrustemCertificateExpiredAlarm_active

Message

TRUSTEM/2/hwTrustemCertificateExpiredAlarm_active: The trustem certificate already expired. (PhysicalIndex=[PhysicalIndex], PhysicalName=[PhysicalName], CertificateName=[hwTrustemCertificateName], CertificateType=[hwTrustemCertificateType], BeginTime=[hwTrustemCertificateBeginTime], EndTime=[hwTrustemCertificateEndTime])

Description

This alarm is generated when the trustem certificate expires.

Parameters

Parameter Name Parameter Meaning

PhysicalIndex

Physical index

PhysicalName

Name of an entity

hwTrustemCertificateName

The name of the Certificate File

hwTrustemCertificateType

The type of the Certificate File

hwTrustemCertificateBeginTime

The begin time of the Certificate File

hwTrustemCertificateEndTime

The end time of the Certificate File

Possible Causes

The trustem certificate has expired.

Procedure

1. Check whether the trusted certificate can be replaced.

  • If yes, go to step 2.
  • If not, go to step 3.

2. Replace the certificate with a valid one.

  • If the alarm is cleared, go to step 4.
  • If the alarm persists, go to Step 3.

3. Collect log and configuration information, and contact Huawei technical support personnel.

4. End.
