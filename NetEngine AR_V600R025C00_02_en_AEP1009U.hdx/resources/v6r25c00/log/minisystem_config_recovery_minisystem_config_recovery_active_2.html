CFG/2/MINISYSTEM_CONFIG_RECOVERY_active

Message

CFG/2/MINISYSTEM_CONFIG_RECOVERY_active: The system use mini-system configurations to recovery.

Description

The system uses the minimum system configuration for restoration.

Parameters

None

Possible Causes

The system use mini-system configurations to recovery.

Procedure

After the device fault is rectified, restore the device from the minimum system. After the device starts, run the display startup command to check whether the restored file is mini-system. If yes, the device is restored using the minimum system configuration.

1. If you want the system to start with the minimum system software, this log message is informational only and no action is required.

2. If you do not want to start the system using the minimum system software, do not run the startup saved-configuration mini-system command in the system view. Instead, you can run the reset saved-configuration mini-system command in the diagnostic view to clear the mini-system configuration file.
