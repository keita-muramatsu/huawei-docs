SYSTEM/2/hwPatchInstallFail_clear

Message

SYSTEM/2/hwPatchInstallFail_clear: The patch-operation failure alarm is cleared. (SlotIndex=[SlotIndex], PatchIndex=[PatchIndex], PackageName=[PackageName], PackageVersion=[PackageVersion], FailReason=[FailReason], PhysicalName=[PhysicalName])

Parameters

Parameter Name Parameter Meaning

SlotIndex

Indicates the index of the board where the patch file is located.

PatchIndex

Indicates the index of a patch file.

PackageName

Name of the patch file.

PackageVersion

Version of the patch file.

FailReason

Indicates the failure cause of the patch installation.

PhysicalName

Indicates the name of the entity where the patch file is located. When the value of SlotIndex is 128, PhysicalName is the system device, indicating that the device reports an alarm.

Possible Causes

  • Cause 6:The patch package was deleted.
  • Cause 7:The patch package installation succeeded.

Procedure

This trap message is informational only, and no action is required.
