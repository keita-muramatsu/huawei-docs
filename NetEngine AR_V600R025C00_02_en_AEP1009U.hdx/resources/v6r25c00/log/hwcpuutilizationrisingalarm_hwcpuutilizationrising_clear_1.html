SYSTEM/1/hwCPUUtilizationRisingAlarm_clear

Message

SYSTEM/1/hwCPUUtilizationRisingAlarm_clear: The CPU usage falls below the pre-set clear threshold. (TrapSeverity=[TrapSeverity],ProbableCause=[ProbableCause], EventType=[EventType],PhysicalIndex=[PhysicalIndex],PhysicalName=[PhysicalName],RelativeResource=[RelativeResource],UsageType=[UsageType],SubIndex=[SubIndex],CpuUsage=[CpuUsage],Unit=[Unit],CpuUsageThreshold=[CpuUsageThreshold])

Parameters

Parameter Name Parameter Meaning

TrapSeverity

Indicates the alarm severity. 1 indicates cleared, 2 indicates indeterminate, 3 indicates critical, 4 indicates major, 5 indicates minor, and 6 indicates warning.

ProbableCause

Alarm cause

EventType

Indicates the alarm type. 3 indicates qualityOfServiceAlarm.

PhysicalIndex

Physical index

PhysicalName

Entity name

RelativeResource

Relevant resource name

UsageType

Indicates the overload type. 1 indicates the CPU, 2 indicates the memory, 3 indicates the disk, 4 indicates the flash memory, and 6 indicates the physical memory.

SubIndex

Entity sub-index

CpuUsage

CPU usage

Unit

Indicates the unit. The value 1 indicates percentage.

CpuUsageThreshold

Overload threshold

Possible Causes

  • Cause 74299:The CPU usage fell below the pre-set overload threshold.
  • Cause 74300:The forwarded traffic falls below the CPU processing capability.

Procedure

This trap message is informational only, and no action is required.
