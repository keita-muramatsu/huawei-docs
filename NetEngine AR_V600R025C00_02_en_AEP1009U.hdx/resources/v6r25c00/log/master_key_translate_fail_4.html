MK/4/MASTER_KEY_TRANSLATE_FAIL

Message

MK/4/MASTER_KEY_TRANSLATE_FAIL: The system master key translates unsuccessfully.

Description

Failed to translate the master key.

Parameters

None

Possible Causes

Failed to translate the master key.

Procedure

Check whether the boards in the system are running properly. Collect information and contact software engineers.
