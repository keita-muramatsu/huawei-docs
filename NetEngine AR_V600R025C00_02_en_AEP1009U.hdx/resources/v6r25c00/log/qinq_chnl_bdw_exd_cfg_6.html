L2-MULTICAST/6/QINQ_CHNL_BDW_EXD_CFG

Message

L2-MULTICAST/6/QINQ_CHNL_BDW_EXD_CFG: The bandwidth of multicast groups has already exceeded the limit configured. (ChannelName=[ChannelName], IfName=[IfName], ConfiguredValue=[ConfiguredValue], StatisticsValue=[StatisticsValue])

Description

The bandwidth of multicast groups in the channel on the sub-interface for QinQ VLAN tag termination exceeded the upper limit.

Parameters

Parameter Name Parameter Meaning

ChannelName

Name of the channel

IfName

Name of a QinQ sub-interface

ConfiguredValue

Upper limit of the bandwidth for a multicast group on the QinQ sub-interface

StatisticsValue

Number of multicast groups in the channel on the QinQ sub-interface

Possible Causes

The bandwidth of multicast groups in the channel on the sub-interface for QinQ VLAN tag termination exceeded the upper limit.

Procedure

This log message is informational only, and no action is required.
