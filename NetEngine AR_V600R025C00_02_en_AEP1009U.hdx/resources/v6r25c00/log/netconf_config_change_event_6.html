CONFIGURATION/6/NETCONF_CONFIG_CHANGE_EVENT

Message

CONFIGURATION/6/NETCONF_CONFIG_CHANGE_EVENT: The configuration changed. (Internal change =[isInner], User name =[username], Session ID =[ssnId], Command source address =[srcAddress], Storage type =[datastoreType], Terminal type =[termninalType])

Description

The system configuration is changed.

Parameters

Parameter Name Parameter Meaning

isInner

Indicates whether the change is an internal change.

  • True: internal change, indicating that the configuration is changed in the system and the change is not caused by user operations.
  • False: non-internal change, indicating that the change is caused by user operations.

username

Name of the user who initiates the configuration change.

  • When a user performs operations through an NMS, this field is displayed as SNMP_User.

ssnId

ID of the session that initiates the configuration change.

srcAddress

Source address that initiates the configuration change.

datastoreType

Types of the storage warehouse where the configuration change occurs:

  • running: RDB change
  • candidate: CDB change
  • startup: startup configuration file change

termninalType

Type of the terminal that initiates the change.

  • 0: CLI.
  • 1: SNMP.
  • 2: NETCONF.
  • 7: MML.
  • 65535: internal change, for example, loading a board to a device.

Possible Causes

A user or the system modifies the running configuration or the file for the next startup.

Procedure

This message is informational only, and no action is required.
