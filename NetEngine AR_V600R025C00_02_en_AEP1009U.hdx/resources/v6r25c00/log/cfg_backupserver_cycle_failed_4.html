CONFIGURATION/4/CFG_BACKUPSERVER_CYCLE_FAILED

Message

CONFIGURATION/4/CFG_BACKUPSERVER_CYCLE_FAILED: Failed to upload the current configuration to the backup server because the system is busy.

Description

The configuration file cannot be generated.

Parameters

None

Possible Causes

The system is busy. For example, the system is performing other configuration operations. As a result, the configuration file cannot be generated.

Procedure

Contact maintenance personnel.
