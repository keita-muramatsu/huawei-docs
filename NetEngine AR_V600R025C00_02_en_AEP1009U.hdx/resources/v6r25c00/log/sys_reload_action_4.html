SYSTEM/4/SYS_RELOAD_ACTION

Message

SYSTEM/4/SYS_RELOAD_ACTION: The board was reboot. (ReloadIndex=[ReloadIndex], ReloadImage=[ReloadImage], ReloadCfg=[ReloadCfg], ReloadReason=[ReloadReason], ReloadTime=[ReloadTime], ReloadAction=[ReloadAction], ReloadPaf=[ReloadPaf], ReloadLicense=[ReloadLicense], ReloadPatch=[ReloadPatch]).

Description

Indicates a board restart notification.

Parameters

Parameter Name Parameter Meaning

ReloadIndex

Index of the device to be restarted.

ReloadImage

Index of the image file used for the next startup.

ReloadCfg

Index of the configuration file used for the next startup.

ReloadReason

Cause of the restart (for example, loading a cold patch and restarting the device for the patch to take effect)

ReloadTime

Restart time. For example, # 0x07 0xDB 0x01 0x03 0x08 0x32 0x01 0x01 indicates 2011-01-03 08:50:11.

ReloadAction

Restart action value.

ReloadPaf

Index of the PAF file used for the next startup.

ReloadLicense

Index of the license file used for the next startup.

ReloadPatch

Index of the patch file used for the next startup.

Possible Causes

The board is restarted.

Procedure

1. Check whether the cause of the board restart is normal.

  • If so, go to Step 4.
  • If not, go to Step 2.

2. Run the display device command to check whether the board status is normal.

  • If so, go to Step 4.
  • If not, go to Step 3.

3. Collect alarm, log, and configuration information, and contact technical support personnel.

4. End.
