PKI/6/CERT_REPLACE_OK

Message

PKI/6/CERT_REPLACE_OK: Successfully replaced certificate. (Type=[type],Realm=[realm],OldName=[old_name],NewName=[new_name])

Description

The certificate is replaced successfully.

Parameters

Parameter Name Parameter Meaning

type

Certificate type.

realm

Domain name.

old_name

Name of the old certificate.

new_name

Name of the new certificate.

Possible Causes

The old certificate is manually replaced with the new one.

Procedure

This message is informational only, and no action is required.
