VRRP6/3/VRRP6_DOUBLE_MASTER_ERR

Message

VRRP6/3/VRRP6_DOUBLE_MASTER_ERR: VRRP detected double masters. (IfIndex=[IfIndex], IfName=[IfName], VrId=[VrId], PeerIp=[SrcIpAddr], PeerPriority=[PeerPriority])

Description

VRRP6 detected two master devices.

Parameters

Parameter Name Parameter Meaning

IfIndex

Index of the interface where a VRRP6 group resides

IfName

Name of the interface where a VRRP6 group resides

VrId

ID of a VRRP6 group

SrcIpAddr

Primary IP address of the interface where the peer VRRP6 group resides

PeerPriority

Priority of the peer VRRP6 group

Possible Causes

The possible causes are as follows:

  • The local device does not send VRRP6 Advertisement packets.
  • The link load is heavy, causing the local device to discard VRRP6 Advertisement packets.

Procedure

1. Run the debugging vrrp6 command to check the reason why VRRP6 packets are not sent.

2. Run the display cpu-defend statistics command to check whether the link is overloaded.

3. End.
