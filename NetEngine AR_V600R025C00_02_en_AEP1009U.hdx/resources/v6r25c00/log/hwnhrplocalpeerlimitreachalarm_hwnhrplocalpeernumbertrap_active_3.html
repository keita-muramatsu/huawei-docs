NHRP/3/hwNHRPLocalPeerLimitReachAlarm_active

Message

NHRP/3/hwNHRPLocalPeerLimitReachAlarm_active: The number of NHRP local peers reached the alarm limit. (LimitValue=[NhrpLocalPeerLimit], CurrentNumber=[NhrpLocalPeerNumber])

Description

The number of local NHRP entries reached the specification.

Parameters

Parameter Name Parameter Meaning

NhrpLocalPeerLimit

Threshold of local NHRP entries

NhrpLocalPeerNumber

Number of local NHRP entries

Possible Causes

The number of local NHRP entries exceeded the specification.

Procedure

1. View the alarm information. In the alarm information, hwNHRPLocalPeerLimit indicates the current threshold, and hwNHRPLocalPeerCnt indicates the number of local entries. Check whether hwNHRPLocalPeerLimit is set properly.

  • If yes, go to step 3.
  • If no, go to step 2.

2. Run the nhrp capacity warning-threshold command to reset the threshold, and then check whether the alarm is cleared.

  • If yes, go to step 5.
  • If no, go to step 3.

3. Run the reset nhrp peer command to delete unnecessary dynamic tunnels, and then check whether the alarm is cleared.

  • If yes, go to step 5.
  • If no, go to step 4.

4. Collect alarm, log, and configuration information, and contact technical support personnel.

5. End.
