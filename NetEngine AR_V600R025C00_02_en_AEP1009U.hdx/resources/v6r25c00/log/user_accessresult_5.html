CM/5/USER_ACCESSRESULT

Message

CM/5/USER_ACCESSRESULT: USER_INFO_AUTHENTICATION. ([userInfo])

Description

User authentication is being performed.

Parameters

Parameter Name Parameter Meaning

userInfo

USER_INFO_AUTHENTICATION: user authentication.

DEVICEMAC/ACMAC: device MAC address.

DEVICENAME/ACNAME: device name.

APMAC: AP MAC address.

APNAME: AP name.

SSID: SSID.

RADIOID: radio ID.

WLANID: WLAN ID.

USER: user name.

MAC: user MAC address.

IPADDRESS: user IP address.

IPV6ADDRESS: user IPv6 address.

TIME: system time.

ZONE: time zone.

DAYLIGHT: whether the DST is used.

ERRCODE: error code of a user authentication failure.

RESULT: user authentication result.

UclGroupName: UCL group name.

UclGroupId: UCL group ID.

AUTHENPLACE: user authentication location.

CIB ID: CIB ID.

INTERFACE: access interface.

ACCESS TYPE: access type.

VLAN: VLAN ID.

VPNNAME: VPN name of a user.

Portal TYPE: Portal authentication type.

SelectRDSIP: RADIUS server that fails to authenticate users. It indicates the IP address of the intermediate RADIUS server (which has been selected but not in use). The value - indicates that the authentication mode is not RADIUS or no intermediate RADIUS server is available.

SeclectERRCODE: error code of a RADIUS server that fails to authenticate users. It indicates the reason why the intermediate RADIUS server is not used. The value - indicates that the authentication mode is not RADIUS or only one RADIUS server is available. Otherwise, the value is 205.

RDSIP: IP address of the RADIUS server.

AuthFailType: access type of users who fail to be authenticated. If the authentication is successful, None is displayed. If the authentication fails, the failure cause is displayed. In other scenarios (for example, if the user is in pre-connection state), this field is not displayed. This field is not supported in user login and authorization logs.

AUTHID: ID of the user in the log sent to the analyzer.

AUTHPROTOCOL: user authentication mode. If the authentication mode is chap, the value is CHAP. If the authentication mode is eap, the value is EAP. If the authentication mode is pap, the value is PAP. Otherwise, the value is -.

Tried HACA Server IP: IP address of the HACA server that attempts to perform authentication.

HACA Server IP: IP address of the HACA server that accepts or denies the authentication request.

Possible Causes

The user initiates authentication, pre-authentication, or user group authorization information modification.

Procedure

If user authentication fails, locate the fault based on the cause or contact technical support. If the authentication is successful, no action is required.
