SDWAN-EVPN/6/EVPN_FORWARD_LOOP

Message

SDWAN-EVPN/6/EVPN_FORWARD_LOOP: The session has entered the loop state. (SourceIP=[SourceIP],DestinationIP=[DestinationIP],SourcePort=[SourcePort],DestinationPort=[DestinationPort],Protocol=[Protocol],VpnName=[VpnName])

Description

The session entered the loop state.

Parameters

Parameter Name Parameter Meaning

SourceIP

Source address.

DestinationIP

Destination address.

SourcePort

Source port.

DestinationPort

Destination port.

Protocol

Protocol ID.

VpnName

VPN instance.

Possible Causes

When a loop occurs on the SD-WAN network, traffic is forwarded between sites and TTL resources are exhausted, causing packet loss.

Procedure

Check the network configuration based on the session information in the log and remove the loop.
