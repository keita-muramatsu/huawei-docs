VCMU/2/hwFanInvalid_active

Message

VCMU/2/hwFanInvalid_active: A fan module experienced a complete failure. (EntPhysicalIndex=[EntPhysicalIndex], EntPhysicalName=[EntPhysicalName], EntityTrapFaultID=[EntityTrapFaultID], EntityOperStatus=[EntityOperStatus], Reason=[ReasonDsp])

Description

A fan module experienced a complete failure.

Parameters

Parameter Name Parameter Meaning

EntPhysicalIndex

Indicates the entity index.

EntPhysicalName

Entity

EntityTrapFaultID

Fault ID

EntityOperStatus

Alarm status information

ReasonDsp

Possible cause of the alarm.

Possible Causes

  • Cause 1: Fan communicate with MPU is failed.
  • Cause 2: The fans in the fan module failed.
  • Cause 3: The fan was not present.
  • Cause 4: This fan module is not recommended because it may cause insufficient heat dissipation.
  • Cause 5: The fan type is mismatch with the device.
  • Cause 6: The fan power supply is abnormal.
  • Cause 7: The speed difference between the two fans in the fan assembly is too large

Procedure

  • Cause 1: Fan communicate with MPU is failed.

    1. Remove and insert the fan.

    • If the alarm is cleared, go to step 3.
    • If the alarm persists, go to Step 2.

    2. Collect alarm, log, and configuration information, and contact technical support personnel.

    3. End.

  • Cause 2: The fans in the fan module failed.

    1. Replace the fan.

    • If the alarm is cleared, go to step 3.
    • If the alarm persists, go to Step 2.

    2. Collect alarm, log, and configuration information, and contact technical support personnel.

    3. End.

  • Cause 3: The fan was not present.

    1. Insert the fan.

    2. End.

  • Cause 4: This fan module is not recommended because it may cause insufficient heat dissipation.

    1. Replace the fan with the recommended one.

    2. End.

  • Cause 5: The fan type is mismatch with the device.

    1. Replace the fan to match the device.

    2. End.

  • Cause 6: The fan power supply is abnormal.

    1. Replace the fan.

    • If the alarm is cleared, go to step 3.
    • If the alarm persists, go to Step 2.

    2. Collect alarm, log, and configuration information, and contact technical support personnel.

    3. End.

  • Cause 7: The speed difference between the two fans in the fan assembly is too large

    1. Replace the fan.

    • If the alarm is cleared, go to step 3.
    • If the alarm persists, go to Step 2.

    2. Collect alarm, log, and configuration information, and contact technical support personnel.

    3. End.
