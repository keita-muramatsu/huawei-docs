RUMNG/4/RuUpdCancel

Message

RUMNG/4/RuUpdCancel: The remote-unit firmware update canceled. (Type=[Type], ESN=[RemoteUnitEsn], Interface=[InterfaceName], Firmware=[Firmware], Reason=[ReasonString])

Description

The firmware update of the RU is canceled.

Parameters

Parameter Name Parameter Meaning

Type

Model of the RU.

RemoteUnitEsn

ESN of the RU.

InterfaceName

Interconnection port of the RU.

Firmware

Firmware type.

ReasonString

Reason for cancellation.

Possible Causes

1. The RU went offline.

2. The RU fails to be authenticated.

3. The RU upgrade is prohibited.

Procedure

This message is informational only, and no action is required.
