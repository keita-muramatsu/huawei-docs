CONFIGURATION/6/RUNNING_CFG_CHANGE_VERBOSE

Message

CONFIGURATION/6/RUNNING_CFG_CHANGE_VERBOSE: Recorded command information. (Task=[Task], User=[User], CfgBaselineTime=[CfgBaselineTime], Command="[Command]")

Description

The running configuration of the device changes.

Parameters

Parameter Name Parameter Meaning

Task

Relative index of a channel type. The value is _SYSTEM_.

User

Login user name. The value is _SYSTEM_.

CfgBaselineTime

Baseline time of system configurations.

Command

Change information of a configuration command.

Possible Causes

After the running configuration of the system is modified through the NETCONF terminal, the configuration is not modified within 1 minute.

Procedure

This message is informational only, and no action is required.
