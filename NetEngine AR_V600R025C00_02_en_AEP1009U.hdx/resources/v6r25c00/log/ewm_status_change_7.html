EWM/7/EWM_STATUS_CHANGE

Message

EWM/7/EWM_STATUS_CHANGE: The status of the electronic hardware warranty information changed. (Serial number = [ESN], start time = [StartDate], warranty period = [Month], status = [Status])

Description

The ESN, start date, warranty period, and status of the electronic hardware warranty were recorded.

Parameters

Parameter Name Parameter Meaning

ESN

Serial number.

StartDate

Start date of the electronic hardware warranty.

Month

Warranty period, in months.

Status

Status of the electronic hardware warranty.

Possible Causes

The ESN, start date, warranty period, and status of the electronic hardware warranty were recorded.

Procedure

This message is informational only, and no action is required.
