SNMP/5/ADD_SNMP_USM_USER

Message

SNMP/5/ADD_SNMP_USM_USER: SNMPv3 usm user was created. (OperatorName=[operateUserName],IPAddress=[ipAddress],NewUserName=[userName],VpnName=[vpnName])

Description

An SNMPv3 USM user is added.

Parameters

Parameter Name Parameter Meaning

operateUserName

Operator name

ipAddress

Operator IP address

userName

Name of a user.

vpnName

VPN instance name

Possible Causes

An SNMPv3 USM user is added successfully.

Procedure

Check whether the user is added as expected.

  • If the result is as expected, no action is required.
  • If this is a misoperation, delete the user.
