OPS/4/OPS_LOG_USERDEFINED_WARNING

Message

OPS/4/OPS_LOG_USERDEFINED_WARNING: OPS records user-defined warning operation information. (content="[content]", user="[userName]", session=[sessionId], assistant="[assistantName]")

Description

Logs with a user-defined level of warning.

Parameters

Parameter Name Parameter Meaning

content

User-defined log content.

userName

Name of the user who records the log.

Operation triggered by OPS scheduling. The value is _OPS_.

sessionId

ID of the session that records the log, which is used to distinguish multiple session records.

assistantName

Name of the maintenance assistant that records logs.

Logs triggered by the maintenance assistant. The value is the maintenance assistant name.

For logs triggered in other modes, the value is _OPS_.

Possible Causes

You can use the programmable interface provided by the OPS to record user-defined logs. For example, you can invoke the _ops.syslog() interface in the script assistant to record logs.

Procedure

1. This message is informational only, and no action is required.
