WLAN/4/WLAN_LOG_USER_WLAN_STA_INFO_AP_ASSOCIATE

Message

WLAN/4/WLAN_LOG_USER_WLAN_STA_INFO_AP_ASSOCIATE: WLAN_STA_INFO_AP_ASSOCIATE. (ACMAC=[ACMAC],ACNAME=[ACNAME],APMAC=[APMAC],APNAME=[APNAME],APIP=[APIP],RADIO=[RADIO],BAND=[BAND],SSID=[SSID],ACCESS_TYPE=[ACCESS_TYPE],USER=[USER],MAC=[MAC],ASSOCDURATION=[ASSOCDURATION],TIME=[TIME],ZONE_UTC=UTC[ZONE_UTC],DAYLIGHT=[DAYLIGHT],ERRCODE=[ERRCODE],RESULT=[RESULT])

Description

A user is associated with an AP.

Parameters

Parameter Name Parameter Meaning

ACMAC

AC's MAC address.

ACNAME

AC's system name.

APMAC

MAC address of an AP.

APNAME

AP's system name.

APIP

AP's IP address.

RADIO

Radio ID.

BAND

Operating frequency band of a radio.

SSID

SSID.

ACCESS_TYPE

User authentication mode.

USER

User name.

MAC

MAC address of the user.

ASSOCDURATION

Association time, in us.

TIME

System time.

ZONE_UTC

Time zone.

DAYLIGHT

Whether the daylight saving time (DST) is used.

  • true: The DST is used.
  • false: The DST is not used.

ERRCODE

Failure/state error code.

RESULT

Indicates the login success or failure cause of a user.

  • Success: The user goes online successfully.
  • FailType is Reason code, a user has gone offline unexpectedly: The user goes offline unexpectedly.
  • FailType is Reason code, assoc timeout: User association fails.
  • FailType is Reason code, other reason: Other reasons cause the user online failure.
  • FailType is Status code, the STA does not support the basic rate set required by the AP: The basic rate set of the user does not match with that of the AP.
  • FailType is Status code, ap reach max user: The number of users associated with the AP reaches the upper limit.
  • FailType is Status code, encryption mode error: The authentication algorithm is not supported when the user sends authentication requests.
  • FailType is Status code, STA WMM capability mismatch: The user WMM capability does not match with that of the AP.
  • FailType is Status code, STA ESS capability mismatch: The network type flag carried by the user is not ESS.
  • FailType is Status code, STA SST capability mismatch: The user does not support short slot time.
  • FailType is Status code, STA spectrum capability mismatch: In the 802.11h only mode, the user does not support dynamic frequency selection.
  • FailType is Status code, STA of 802.11b is forbidden to access: The access of 802.11b STAs is rejected.
  • FailType is Status code, other reason: Other reasons cause the user online failure.
  • FailType is AC code, exceeded the maximum number of access users to the AC: The number of users associated with the device exceeds the upper limit. The error code is predefined on the AC.
  • FailType is AC code, assoc global whitelist isn't match: The user is not in the global user whitelist.
  • FailType is AC code, assoc global blacklist match: The user is in the global user blacklist.
  • FailType is AC code, assoc vap whitelist isn't match: The user is not in the VAP whitelist.
  • FailType is AC code, assoc vap blacklist match: The user is in the VAP blacklist.
  • FailType is AC code, assoc dynamic blacklist match: The user is in the dynamic user blacklist.
  • FailType is AC code, refused by load balance: The association failure is caused by the load balancing function.
  • FailType is AC code, refused by association element error: The length of association messages is incorrect, causing an association failure.
  • FailType is AC code, inconsistent security policies for SSIDs before and after STA roaming: The user security policy check fails, so roaming is rejected.
  • FailType is AC code, refused by roam check fail(state): The user state is not stable, so roaming is rejected.
  • FailType is AC code, refused by roam check fail(others): Other user information check fails, so roaming is rejected.
  • FailType is AC code, refused by vap reach max user(AC): The number of users associated with VAPs on the device reaches the upper limit.
  • FailType is AC code, inter-network roaming not allowed in the current configuration: Layer 3 Roaming is disabled.

Possible Causes

A user is associated with an AP.

Procedure

This message is informational only, and no action is required.
