PKGM/2/hwOnBoardFirmwareDamaged_active

Message

PKGM/2/hwOnBoardFirmwareDamaged_active: The onboard firmware is damaged. (PhysicalIndex=[PhysicalIndex], PhysicalName=[PhysicalName])

Description

The on-board firmware is damaged.

Parameters

Parameter Name Parameter Meaning

PhysicalIndex

Physical index [0,0xffffffff].

PhysicalName

Entity name.

Possible Causes

The board firmware is damaged.

Procedure

1. Remove the board that reports the alarm. The alarm is cleared.

· If yes, return the device to the factory for repair.

· If no, go to step 2.

2. Collect trap, log, and configuraiton information and contact technical support personnel.

3. the procedure ends.
