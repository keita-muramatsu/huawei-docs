SNMP/4/SNMP_MIB_SET_FAILED

Message

SNMP/4/SNMP_MIB_SET_FAILED: MIB node set failure. (UserName=[UserName], SourceIP=[SourceIP], DestIP=[DestIP], Version=[Version], RequestId=[RequestId], ErrorStatus=[ErrorStatus], ErrorIndex=[ErrorIndex], [OIDName], VPN=[VPN])

Description

Failed to perform the Set operation on the MIB object.

Parameters

Parameter Name Parameter Meaning

UserName

User name.

SourceIP

Source IP address.

DestIP

Destination IP address.

Version

Version information.

RequestId

Request ID

ErrorStatus

Error status information. The options are as follows:

  • 0: noError
  • 1: tooBig
  • 2: noSuchName
  • 3: badValue
  • 4: readOnly
  • 5: genError
  • 6: noAccess
  • 7: wrongType
  • 8: wrongLength
  • 9: wrongEncoding
  • 10: wrongValue
  • 11: noCreation
  • 12: inconsistentValue
  • 13: resourceUnavailable
  • 14: commitFailed
  • 15: undoFailed
  • 16: authorizationError
  • 17: notWritable
  • 18: inconsistentName

ErrorIndex

Index of the bound variable that failed to be set. The log file records all variables required by the NMS. For example, when the fifth variable fails to be set, the value of ErrorIndex is 5.

OIDName

OID value of an object in the Set request. For an object of the character string type, the value is displayed in hexadecimal notation. For an object of the password type, the value is displayed as ******. If there are too many objects in the Set request and the objects cannot be completely displayed in one log, the objects are displayed in multiple Set logs. If the length of an OID character string exceeds 512 bytes or the length of an OID+value character string exceeds 1024 bytes, the string is truncated when being displayed in logs.

VPN

Indicates the name of a VPN instance.

Possible Causes

The Set operation failed to be performed on the MIB object.

Procedure

  • This message is informational only, and no action is required.
