DHCP/5/DHCP_V6_C_RELEASE

Message

DHCP/5/DHCP_V6_C_RELEASE: The DHCPv6 client released address successfully. (Client InterfaceName=[ClientInterfaceName], Lease IpAddress=[LeaseIpAddress], Client MacAddress=[ClientMacAddress], LeaseDuration=[LeaseDuration], DNS Domain=[DNSDomain], CapwapAc=[CapwapAc], Reason=[Reason], OnlineDuration=[OnlineDuration])

Description

The device functions as a DHCPv6 client and successfully releases an IPv6 address.

Parameters

Parameter Name Parameter Meaning

ClientInterfaceName

Name of an interface on the DHCPv6 client.

LeaseIpAddress

IPv6 address released by the DHCPv6 client.

ClientMacAddress

MAC address of the DHCPv6 client.

LeaseDuration

Lease time.

DNSDomain

DNS domain name.

CapwapAc

CAPWAP source address.

Reason

Reason for releasing the address. The options are as follows:

  • Received a response to a release packet
  • Client closed by an external application
  • BFD detected a fault
  • Received a response to a confirm packet
  • IPv6 address released by an external application
  • Interface down
  • Retransmission duration of confirm packets reached the maximum
  • Received a response to a decline packet
  • Retransmission duration of decline packets reached the maximum
  • State machine restarted

OnlineDuration

Online duration.

Possible Causes

The device functions as a DHCPv6 client and successfully releases an IPv6 address.

Procedure

This message is informational only, and no action is required.
