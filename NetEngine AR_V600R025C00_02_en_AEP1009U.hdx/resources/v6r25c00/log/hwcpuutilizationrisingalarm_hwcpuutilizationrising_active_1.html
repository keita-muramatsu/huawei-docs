SYSTEM/1/hwCPUUtilizationRisingAlarm_active

Message

SYSTEM/1/hwCPUUtilizationRisingAlarm_active: The CPU usage exceeded the pre-set overload threshold. (TrapSeverity=[TrapSeverity],ProbableCause=[ProbableCause],EventType=[EventType],PhysicalIndex=[PhysicalIndex],PhysicalName=[PhysicalName],RelativeResource=[RelativeResource],UsageType=[UsageType],SubIndex=[SubIndex],CpuUsage=[CpuUsage],Unit=[Unit],CpuUsageThreshold=[CpuUsageThreshold])

Description

The device continuously samples the CPU usage. This alarm is generated when the CPU usage sampled every time is greater than the overload threshold in a sampling period (number of consecutive CPU overload times x sampling interval).

Parameters

Parameter Name Parameter Meaning

TrapSeverity

Indicates the alarm severity. 1 indicates cleared, 2 indicates indeterminate, 3 indicates critical, 4 indicates major, 5 indicates minor, and 6 indicates warning.

ProbableCause

Alarm cause

EventType

Indicates the alarm type. 3 indicates qualityOfServiceAlarm.

PhysicalIndex

Physical index

PhysicalName

Entity name

RelativeResource

Relevant resource name

UsageType

Indicates the overload type. 1 indicates the CPU, 2 indicates the memory, 3 indicates the disk, 4 indicates the flash memory, and 6 indicates the physical memory.

SubIndex

Entity sub-index

CpuUsage

CPU usage

Unit

Indicates the unit. The value 1 indicates percentage.

CpuUsageThreshold

Overload threshold

Possible Causes

  • Cause 74299: The CPU usage exceeded the pre-set overload threshold.
  • Cause 74300: CPU usage of the data plane includes the CPU usage of basic forwarding services and other data plane services.

Procedure

  • Cause 74299: The CPU usage exceeded the pre-set overload threshold.

    1. Run the display cpu-usage command to check the CPU usage and its overload threshold.

    • If CPU usage exceeds the overload threshold, go to Step 2.
    • If CPU usage is below the overload threshold, go to Step 4.

    2. Delete unnecessary services and configurations to reduce CPU usage, and then check whether the alarm is cleared.

    • If the clear alarm is generated, the fault is rectified.
    • If this alarm persists, go to Step 3.

    3. Run the set cpu-usage threshold command to adjust the overload threshold, and then check whether the alarm is cleared.

    • If the clear alarm is generated, the fault is rectified.
    • If this alarm persists, go to Step 4.

    4. Collect the alarm information, log information, and configuration information, and contact Huawei technical support engineers.

  • Cause 74300: CPU usage of the data plane includes the CPU usage of basic forwarding services and other data plane services.

    Check the service usage in the display cpu-usage command output and perform capacity expansion based on service requirements.
