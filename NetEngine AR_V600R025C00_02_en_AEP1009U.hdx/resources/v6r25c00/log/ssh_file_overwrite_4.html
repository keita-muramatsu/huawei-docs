SSHS/4/SSH_FILE_OVERWRITE

Message

SSHS/4/SSH_FILE_OVERWRITE: The file [FileName] was overwritten by [SshService] client. (UserName=[UserName], UserAddress=[UserAddress], LocalAddress=[LocalAddress], VPNInstanceName=[VpnName])

Description

When the client uploads a file to the server, if a file with the same name as the file to be uploaded exists on the server, the file on the server is overwritten.

Parameters

Parameter Name Parameter Meaning

FileName

File name.

SshService

Supported protocol types:

  • SCP
  • SFTP

UserName

User name.

UserAddress

IP address of a user.

LocalAddress

Local IP address.

VpnName

Name of a VPN instance.

Possible Causes

When the client uploads a file to the server, if a file with the same name as the file to be uploaded exists on the server, the file on the server is overwritten.

Procedure

  • This message is informational only, and no action is required.
