TTY/4/SETPASS_FAIL_FIRSTLOGIN

Message

TTY/4/SETPASS_FAIL_FIRSTLOGIN: Failed to set password when login firstly.

Description

The password fails to be set upon the first login.

Parameters

None

Possible Causes

During the first login, if the password entered by the user does not meet the complexity check requirements, the password fails to be set and the log is recorded.

Procedure

1. Check whether the password meets the complexity requirements.

  • If so, go to step 2.
  • If not, enter a password that meets the complexity requirements.If the password still fails to be set, go to step 2.

2. Collect log and configuration information, and contact technical support personnel.
