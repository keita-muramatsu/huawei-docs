CM/3/CM_ADDUCLGROUPIPFAIL

Message

CM/3/CM_ADDUCLGROUPIPFAIL: Add ucl-group ip failed. ([STRING])

Description

Failed to add IP addresses to the UCL group.

Parameters

Parameter Name Parameter Meaning

STRING

Failure cause.

Possible Causes

Adding IP addresses to a UCL group for dynamic or static user authorization fails in any of the following situations:

&bull; The board does not support the function of adding IP addresses to a UCL group.

&bull; Static UCL group resources are insufficient.

&bull; The number of UCL group IDs on the board or device exceeds the upper limit.

Procedure

1. Check whether the board supports the function of adding IP addresses to a UCL group.

&bull; If so, go to step 2.

&bull; If not, replace the board.

2. Check whether the authorized UCL group is correct.

&bull; If so, replace the board or device with one of higher performance.

&bull; If not, plan the UCL group properly.

3. Collect logs and configuration information, and contact technical support.
