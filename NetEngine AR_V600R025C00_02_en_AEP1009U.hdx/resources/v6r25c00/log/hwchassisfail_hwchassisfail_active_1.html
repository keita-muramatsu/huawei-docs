DEVM/1/hwChassisFail_active

Message

DEVM/1/hwChassisFail_active: The chassis partially failed. (EntPhysicalIndex=[EntPhysicalIndex], EntPhysicalName=[EntPhysicalName], EntityTrapFaultID=[EntityTrapFaultID], Reason=[Reason])

Description

A chassis experienced a partial failure.

Parameters

Parameter Name Parameter Meaning

EntPhysicalIndex

Physical entity index.

EntPhysicalName

Entity name.

EntityTrapFaultID

Fault ID.

Reason

Alarm cause.

Possible Causes

  • Cause 1: Different SFUs were installed in the same chassis.
  • Cause 2: The system power or the power of the backup power supply is insufficient.
  • Cause 3: No SFU is present in the chassis.
  • Cause 4: No LPU is present in the chassis.
  • Cause 5: No CMU is present in the chassis.
  • Cause 6: The power module types are inconsistent.
  • Cause 7: Failed to obtain slot information of the power supply.
  • Cause 8: There is two or more fans not detected.
  • Cause 9: The number of detected SFUs does not meet requirements.
  • Cause 10: The fan module types are inconsistent.

Procedure

  • Cause 1: Different SFUs were installed in the same chassis.

    1. Install the correct SFU. If the fault persists, go to Step 2.

    2. Collect alarm, log, and configuration information, and contact technical support.

  • Cause 2: The system power or the power of the backup power supply is insufficient.

    1. Add a power module or change the backup mode of power modules. For details, see "Power Supply System" in Hardware Description. If the fault persists, go to Step 2.

    2. Collect alarm, log, and configuration information, and contact technical support.

  • Cause 3: No SFU is present in the chassis.

    1. Install an SFU. If the fault persists, go to Step 2.

    2. Collect alarm, log, and configuration information, and contact technical support.

  • Cause 4: No LPU is present in the chassis.

    1. Install an LPU. If the fault persists, go to Step 2.

    2. Collect alarm, log, and configuration information, and contact technical support.

  • Cause 5: No CMU is present in the chassis.

    1. Install a CMU. If the fault persists, go to Step 2.

    2. Collect alarm, log, and configuration information, and contact technical support.

  • Cause 6: The power module types are inconsistent.

    1. Power modules with fans or without fans are installed in all power slots of the switch. If the fault persists, go to Step 2.

    2. A DC or AC power module is installed in all power slots of a switch. If the fault persists, go to Step 3.

    3. Collect alarm, log, and configuration information, and contact technical support personnel.

  • Cause 7: Failed to obtain slot information of the power supply.

    1. Install the power module in another slot or replace the power module. If the fault persists, go to Step 2.

    2. Collect alarm, log, and configuration information, and contact technical support.

  • Cause 8: There is two or more fans not detected.

    1. Install all the fans. If the fault persists, go to Step 2.

    2. Collect alarm, log, and configuration information, and contact technical support.

  • Cause 9: The number of detected SFUs does not meet requirements.

    1. Install an SFU. If the fault persists, go to Step 2.

    2. Collect alarm, log, and configuration information, and contact technical support.

  • Cause 10: The fan module types are inconsistent.

    1. Fans of the same model are installed in all fan slots on the switch. If the fault persists, go to Step 2.

    2. Collect alarm, log, and configuration information, and contact technical support personnel.
