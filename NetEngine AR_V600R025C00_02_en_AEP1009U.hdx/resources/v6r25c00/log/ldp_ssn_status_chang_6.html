LDP/6/LDP_SSN_STATUS_CHANG

Message

LDP/6/LDP_SSN_STATUS_CHANG: The LDP session was not established successfully. (LocalLsrId=[LocalLsrId], PeerLsrId=[PeerLsrId], LocalTransportAddress=[LocalTransportAddress], PeerTransportAddress=[PeerTransportAddress], CreateSessionTime=[CreateSessionTime], TcpUpTime=[TcpUpTime], RecvInitMsgTime=[RecvInitMsgTime], VrfName=[VrfName], SessionType=[SessionType], DiscoverySource=[DiscoverySourceIndex], TCPConnSocket=[TcpFD], TCPLsnSocket=[LsFD], Reason=[Reason])

Description

The LDP session failed to establish.

Parameters

Parameter Name Parameter Meaning

LocalLsrId

The local LSR ID of LDP session.

PeerLsrId

The LSR ID of LDP peer.

LocalTransportAddress

Local transmission address.

PeerTransportAddress

Peer transmission address.

CreateSessionTime

Time when a session is created.

TcpUpTime

Time when the TCP connection went up.

RecvInitMsgTime

Time when the initialization message is received.

VrfName

Name of a VRF instance.

SessionType

LDP session type.

DiscoverySourceIndex

Discovery source of an LDP peer.

TcpFD

SocketFD of a TCP connection.

LsFD

SocketFD for TCP listening.

Reason

Cause of the session setup failure.

Possible Causes

LDP session negotiation failed or the timer establishing by LDP session overtimed.

Procedure

Check whether the configuration is frequently modified.

  • If yes, stop such operation. After 2 minutes, check whether the session is up. If the session is still not up, collect trap and configuration information and contact technical support personnel.
  • If no, collect alarm and configuration information, and contact technical support personnel.
