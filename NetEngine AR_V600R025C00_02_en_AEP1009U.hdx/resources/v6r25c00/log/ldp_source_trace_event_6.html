LDP/6/LDP_SOURCE_TRACE_EVENT

Message

LDP/6/LDP_SOURCE_TRACE_EVENT: Source tracing for packet loss on the LDP LSP was performed. (ComponentName = [ComponentName], Inlabel = [Inlabel], Info = [Statistic_info])

Description

Source tracing for packet loss on the LDP LSP was performed, which was recorded in a log.

Parameters

Parameter Name Parameter Meaning

ComponentName

Component Name

Inlabel

Label Value

Statistic_info

Statistic info of source tracing for packet loss. This Parameter include item: SrcMac, DstMac, FeiPid, Sn.

Possible Causes

The local device received a request for source tracing for packet loss on the LDP LSP.

Procedure

No need to deal with.
