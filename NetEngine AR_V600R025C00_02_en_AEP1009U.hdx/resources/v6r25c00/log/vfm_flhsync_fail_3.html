VFS/3/VFM_FLHSYNC_FAIL

Message

VFS/3/VFM_FLHSYNC_FAIL: Failed to copy file by hwFlhSyncTable with FlhSyncIndex [FlhSyncIndex], FlhSyncSrcFile [FlhSyncSrcFile], FlhSyncDstFile [FlhSyncDstFile].

Description

This log is generated when a file fails to be copied through hwFlhSyncTable in HUAWEI-FLASH-MAN-MIB.

Parameters

Parameter Name Parameter Meaning

FlhSyncIndex

Index of the file to be copied.

FlhSyncSrcFile

Source file.

FlhSyncDstFile

Target file.

Possible Causes

This log is generated when a file fails to be copied through MIB.

Procedure

1. Run the dir command to check whether the source file path exists.

  • If so, go to Step 2.
  • If the system displays a message indicating that the file cannot be found, go to Step 3.

2. Run the dir command to check the available space of the target path.

  • If the remaining space is less than the size of the source file, run the delete /unreserved command to delete unnecessary files and clear the environment to ensure sufficient space. Then, go to Step 4.
  • If the available space is greater than the size of the source file, go to Step 4.

3. The source path is misspelled. Change it to a correct path.

4. Copy the file again and check whether the alarm is cleared.

  • If so, go to Step 6.
  • If not, go to Step 5.

5. Collect alarm and log information, and contact technical support personnel.

6. End.
