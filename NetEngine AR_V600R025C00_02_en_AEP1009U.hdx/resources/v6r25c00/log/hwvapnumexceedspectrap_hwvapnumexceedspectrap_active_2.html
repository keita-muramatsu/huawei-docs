WLAN/2/hwVapNumExceedSpecTrap_active

Message

WLAN/2/hwVapNumExceedSpecTrap_active: The number of VAP instances has exceeded the maximum. (Vap = [Vap])

Description

The number of VAP instances exceeded the system specifications.

Parameters

Parameter Name Parameter Meaning

Vap

Maximum number of VAPs.

Possible Causes

The number of VAP instances exceeds the maximum number defined in the specifications.

Procedure

1. Run the display vap all command to check all VAPs on the device.

2. Run the display ap by-ssid ssid command to check information about the AP group with the specified SSID on the device.

3. Run the ap-group name group-name command to enter the AP group view.

4. Run the undo vap-profile profile-name wlan wlan-id { radio { radio-id | all } } command to delete unnecessary VAPs.

  • If the alarm persists, go to Step 5.
  • If the alarm is not generated, go to Step 6.

5. Collect trap, log, and configuration information, and contact technical support personnel.

6. End.
