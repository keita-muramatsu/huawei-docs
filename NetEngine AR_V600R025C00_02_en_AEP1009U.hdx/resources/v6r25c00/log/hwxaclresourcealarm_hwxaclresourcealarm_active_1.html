QOS/1/hwXACLResourceAlarm_active

Message

QOS/1/hwXACLResourceAlarm_active: The service failed to be delivered because ACL resources were insufficient. (SlotID=[hwXACLResourceAlarmSlotid], ServiceType=[hwXACLResourceAlarmServiceType], ServiceName=[hwXACLResourceAlarmServiceName], View=[hwXACLResourceAlarmApplyType], InterfaceName=[hwXACLResourceAlarmInterfaceName], Direction=[hwXACLResourceAlarmDirection], ServiceParam1=[hwXACLResourceAlarmServiceParam1], ServiceParam2=[hwXACLResourceAlarmServiceParam2], ServiceParam3=[hwXACLResourceAlarmServiceParam3], FailReason=[hwXACLResourceAlarmACLFailReason])

Description

The service failed to be delivered because ACL resources were insufficient.

Parameters

Parameter Name Parameter Meaning

hwXACLResourceAlarmSlotid

Device slot ID

hwXACLResourceAlarmServiceType

ACL service type: "MQC Service", "SACL Service", "Common ACL Service"

hwXACLResourceAlarmServiceName

ACL service name

hwXACLResourceAlarmApplyType

View: "Interface", "Vlan", "VlanIf", "Global"

hwXACLResourceAlarmInterfaceName

Interface name

hwXACLResourceAlarmDirection

Packet processing phases: "Inbound", "Outbound"

hwXACLResourceAlarmServiceParam1

Parameter 1: view value

hwXACLResourceAlarmServiceParam2

Parameter 2: protocol name and policy name

hwXACLResourceAlarmServiceParam3

Parameter 3: other service parameters

hwXACLResourceAlarmACLFailReason

Fail reason: "Group resource full", "Entry resource full"

Possible Causes

The service failed to be delivered because ACL group or entry resources were insufficient.

Procedure

Collect alarm, log, and configuration information, and contact technical support personnel.
