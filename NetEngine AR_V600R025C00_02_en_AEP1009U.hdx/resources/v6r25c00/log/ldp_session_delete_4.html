LDP/4/LDP_SESSION_DELETE

Message

LDP/4/LDP_SESSION_DELETE: The session was deleted. (PeerID=[PeerID], CPU Usage=[Usage]%, RouteStatus=[STATUS])

Description

The LDP session was deleted.

Parameters

Parameter Name Parameter Meaning

PeerID

The ID of LDP peer.

Usage

The current CPU usage.

STATUS

The status of route which used by LDP session.

Possible Causes

  • The Hello Hold timer of the LDP session expired.
  • The Keepalive Hold timer of the LDP session expired.
  • The reset mpls ldp command was run.
  • GR was enabled for the LDP session.
  • The value of the Keepalive Hold timer was changed.
  • The transport address of the LDP session was changed.
  • An LSR ID of the LDP session was changed.
  • A Notification message was received to instruct the local LSR to reestablish the LDP session.
  • LDP failed to establish an LDP session for a long time.
  • An incorrect protocol message was received.
  • An incorrect socket was received.
  • The LDP session was deleted.
  • The configuration of dynamic LDP advertisement capability was changed.

Procedure

1. Collect the trap information, log information, and configuration information, and Collect log information and configuration information, and then contact technical support personnel.
