WLAN/4/hwApOpticalInvalidTrap_active

Message

WLAN/4/hwApOpticalInvalidTrap_active: The optical transceiver does not work normally. (APMAC=[APMAC], APName=[APName], ApIfIndex=[ApIfIndex], ApEntityPhysicalName=[ApEntityPhysicalName], hwWlanApOpticalFaultID=[hwWlanApOpticalFaultID], APID=[APID], hwWlanApOpticalFaultReason=[hwWlanApOpticalFaultReason])

Description

An AP's optical module failed to work properly.

Parameters

Parameter Name Parameter Meaning

APMAC

MAC address of an AP.

APName

Name of an AP.

ApIfIndex

AP interface index.

ApEntityPhysicalName

Interface name of an AP.

hwWlanApOpticalFaultID

Fault ID of an AP's optical module.

APID

AP ID.

hwWlanApOpticalFaultReason

Reason for the AP's optical module fault.

Possible Causes

The rate of the optical module does not match the interface rate.

Procedure

1. Run the display ap port all command in any view to check the AP interface rate.

2. Replace the faulty optical module with an optical module whose rate matches the AP interface.
