NETCONF/3/NCA_SYNC_OP_FILE_TRANSFER_FAIL

Message

NETCONF/3/NCA_SYNC_OP_FILE_TRANSFER_FAIL: Failed to transfer synchronization operation file to target server. (File=[File], Target address=[Targetaddress], VPN Instance=[VPNInstance], Reason=[Reason].)

Description

NETCONF synchronization fails when files are transferred to or saved on the server. Any error that occurs during file transfer is logged.

Parameters

Parameter Name Parameter Meaning

File

File name.

Targetaddress

Destination IP address.

VPNInstance

VPN instance name.

Reason

Indicates the cause of the file transfer failure.

  • Source file error: The source file is incorrect.
  • Target server information error: The target server information is incorrect.
  • The specified target server is not reachable: The specified target server is unreachable.
  • The specified user is deleted in the target server: The specified user has been deleted from the target server.
  • The specified port is modified in the target server: The specified port has been changed on the target server.
  • The specified file transfer to the target server timed out: File transfer times out. Processing the file times out when the file is transferred to the target server.
  • The specified local path or filename is invalid: The specified local path or file name is invalid.
  • Failed to open file: The file fails to be opened.
  • Local file open permission is not available: The user does not have the permission to open the local file.
  • Local file not found or file is renamed: No local file is found or the file name has been updated.
  • Failed to transfer file: The file fails to be transferred.
  • Target server return error after file transfer is started: The target server returns an error when file transfer is started.
  • An application schema model is being updated: The schema application module is being upgraded.
  • Unrecognized host or wrong IP address: The host is unknown or the IP address is incorrect.
  • Destination server is not reachable: The target server is unreachable.
  • Destination server is not in service: The target server is not in the service range.
  • Authentication failed: Authentication failed.
  • Username or password authentication error: The username or password is incorrect.
  • SFTP client key exchange error: An error occurred during key exchange on the SFTP client.

Possible Causes

Cause 1: The source file is incorrect.

Cause 2: The target server information is incorrect.

  • The specified target server is unreachable.
  • The specified user has been deleted from the target server.
  • On the target server, the specified port has been changed.

Cause 3: The file transfer times out. The file transfer to the target server times out.

Cause 4: The specified local path or file name is invalid.

Cause 5: Failed to open the file.

  • You do not have the permission to open the local file.
  • The local file is not found or the file name has been updated.

Cause 6: Failed to transfer the file.

  • The target server returns an error when file transfer is started.
  • The Schema application module is being upgraded.

Cause 7: The host is unknown or the IP address is incorrect.

  • The target server is unreachable.
  • The target server is not in the service range.

Cause 8: Authentication failed.

  • The user name or password is incorrect.
  • An error occurs in key exchange on the SFTP client.

Procedure

Cause 1: Ensure that the source file exists.

Cause 2: Check whether the target server is shut down, whether the user is deleted, or whether the port number is changed.

For cause 3: Ensure that the connection to the target server is normal.

Cause 4: Ensure that the source file name in the request is the same as the local file name.

Cause 5: Check whether the authorization source file is modified.

Cause 6:

  • Check whether the target server is shut down.
  • Ensure that file transfer and synchronization are complete after the patch upgrade is complete.

Cause 7: The destination IP address is valid.

Cause 8: Check whether the user name, password, or SFTP key exchange parameters are valid.
