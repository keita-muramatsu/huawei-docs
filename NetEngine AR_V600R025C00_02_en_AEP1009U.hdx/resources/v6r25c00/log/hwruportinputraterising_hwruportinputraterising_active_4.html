RUMNG/4/hwRuPortInputRateRising_active

Message

RUMNG/4/hwRuPortInputRateRising_active: Remote unit interface input flow bandwidth usage exceeded the trap threshold. (RemoteUnitEsn=[RemoteUnitEsn], InterfaceName=[InterfaceName], BandWidthUsage=[BandWidthUsage], TrapThreshold=[TrapThreshold])

Description

The bandwidth usage of incoming traffic on the interface of the RU exceeded the alarm threshold.

Parameters

Parameter Name Parameter Meaning

RemoteUnitEsn

ESN of the RU.

InterfaceName

Port number of the RU.

BandWidthUsage

Bandwidth usage.

TrapThreshold

Bandwidth usage alarm threshold. The default value is 80.

Possible Causes

Too much traffic sent to the current interface

Procedure

Run the display remote-unit port statistics command to check the number and type of packets on the interface to determine whether a fault such as a loop causes abnormal packet sending and receiving.

  • If so, go to Step 2.
  • If not, go to Step 3.

2. Locate the cause of the abnormal packets and eliminate the impact of the abnormal packets. Then, check whether the alarm is cleared.

  • If so, go to Step 6.
  • If not, go to Step 3.

3. You can perform the following operations to expand the capacity:

  • Migrate some services to other idle devices.

4. Perform either of the preceding operations and check whether the alarm is cleared.

  • If so, go to Step 6.
  • If not, go to Step 5.

5. Collect alarm and configuration information, and contact technical support.

6. End.
