DHCP/5/REQIP

Message

DHCP/5/REQIP: The DHCP client acquired IP address successfully. (Client InterfaceName=[ClientInterfaceName], ServerId=[ServerId], Acquired IpAddress=[AcquiredIpAddress], Mask=[Mask], Gateway=[Gateway], Static Route=[StaticRoute], Lease Duration=[LeaseDuration], DNS Server=[DNSServer], DNS Domain=[DNSDomain], Cloud management URL=[CloudmanagementURL], Option43=[Option43])

Description

The device functions as a DHCP client and successfully obtains an IP address from the DHCP server.

Parameters

Parameter Name Parameter Meaning

ClientInterfaceName

Name of the interface on the DHCP client.

ServerId

IP address of the DHCP server.

AcquiredIpAddress

IP address assigned to the DHCP client.

Mask

Network mask.

Gateway

Gateway address.

StaticRoute

Static route.

LeaseDuration

Lease time.

DNSServer

DNS server.

DNSDomain

DNS domain name.

CloudmanagementURL

URL of iMaster NCE-Campus.

Option43

DHCP Option 43 information.

Possible Causes

The device functions as a DHCP client and successfully obtains an IP address from the DHCP server.

Procedure

This message is informational only, and no action is required.
