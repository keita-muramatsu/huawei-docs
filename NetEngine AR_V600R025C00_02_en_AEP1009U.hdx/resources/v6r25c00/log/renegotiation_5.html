SSL/5/RENEGOTIATION

Message

SSL/5/RENEGOTIATION: SSL renegotiation started. (AppCid=[AppCid], PolicyId=[PolicyId], VerifyMode=[VerifyMode], RenegotiationReason=[RenegotiationReason], Result=[Result])

Description

SSL initiates renegotiation.

Parameters

Parameter Name Parameter Meaning

AppCid

Component ID.

PolicyId

SSL policy ID.

VerifyMode

Authentication mode.

RenegotiationReason

Renegotiation cause.

Result

Renegotiation result.

Possible Causes

The SSL renegotiation is successfully initiated.

Cause 1: When the SSL connection is not TLS1.3, the processed data volume reaches 1 GB.

Cause 2: The SSL connection is not TLS1.3, and the connection duration exceeds 1 hour.

Cause 3: When the SSL connection is not TLS1.3, the interval between the last renegotiation and the last renegotiation exceeds 1 hour.

SSL-initiated renegotiation fails.

Cause 1: The SSL connection is disconnected.

Cause 2: The peer end does not support renegotiation.

Procedure

  • 1. If renegotiation fails, run the display tcp status command to check whether the SSL connection is disconnected.

If the SSL connection is disconnected, reconnect the SSL connection and go to step 3.

If the SSL connection is not disconnected, go to step 2.

  • 2. Check whether the renegotiation function is enabled on the peer end.
  • 3. Collect log and configuration information, and contact technical support personnel.
