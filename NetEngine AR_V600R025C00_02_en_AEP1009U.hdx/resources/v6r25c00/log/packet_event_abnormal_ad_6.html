AAA/6/PACKET_EVENT_ABNORMAL_AD

Message

AAA/6/PACKET_EVENT_ABNORMAL_AD: AD packet record ([INFO])

Description

Invalid packet detection log.

Parameters

Parameter Name Parameter Meaning

INFO

DeviceMac: device MAC address

DeviceIP: device IP address

ServerIP: indicates the server IP address.

Port: port number.

ResultCode: result code.

Msg: status and packet size

Possible Causes

Invalid AD packets were detected.

Procedure

This message is informational only and no action is required.
