SYSTEM/1/hwSystemMemoryOvLoadAlarm_clear

Message

SYSTEM/1/hwSystemMemoryOvLoadAlarm_clear: The memory usage falls below the reliability clear threshold. (TrapSeverity=[TrapSeverity], EventType=[EventType], PhysicalIndex=[PhysicalIndex], PhysicalName=[PhysicalName], UsageValue=[UsageValue], Unit=[Unit], UsageThreshold=[UsageThreshold])

Parameters

Parameter Name Parameter Meaning

TrapSeverity

Alarm severity.

EventType

Alarm type.

PhysicalIndex

Index of the physical entity.

PhysicalName

Entity name.

UsageValue

Utilization.

Unit

Unit.

UsageThreshold

Threshold

Possible Causes

The memory usage of the board is lower than the value of Memory Resilience overload Threshold minus 4.

Run the display current-configuration include-default | include memory-usage reliability command to view the memory resilience configuration. The value of overload-threshold is the memory resilience overload threshold.

Procedure

This message is informational only, and no action is required.
