FTPS/3/hwFtpLoginFailed_clear

Message

FTPS/3/hwFtpLoginFailed_clear: The ftp user login-failed alarm was cleared.

Parameters

None

Possible Causes

The FTP user login-failed alarm was cleared.

Procedure

  • This alarm message indicates a normal situation, and no action is required.
