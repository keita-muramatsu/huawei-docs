OSPFV3/5/OSPFV3_ABNORMAL_LSA_UPDATE

Message

OSPFV3/5/OSPFV3_ABNORMAL_LSA_UPDATE: LSAs change frequently now. (ProcessId=[ProcessId], AdvertiseRouterId=[AdvertiseRouterId], TotalCount=[TotalCount], BeginTime=[BeginTime], EndTime=[EndTime], LinkLsaCount=[LinkLsaCount], RouterLsaCount=[RouterLsaCount], NetworkLsaCount=[NetworkLsaCount], Intra-Area-PrefixLsaCount=[Intra-Area-PrefixLsaCount], Inter-Area-PrefixLsaCount=[Inter-Area-PrefixLsaCount], Inter-Area-RouterLsaCount=[Inter-Area-RouterLsaCount], NSSA-externalLsaCount=[NSSA-externalLsaCount], GraceLsaCount=[GraceLsaCount], UnknownLsaCount=[UnknownLsaCount])

Description

Frequency of LSA update.

Parameters

Parameter Name Parameter Meaning

ProcessId

OSPFv3 process ID.

AdvertiseRouterId

Declare a device.

TotalCount

Total number of LSA.

BeginTime

Time when counters are set.

EndTime

Time when counters are stopped.

LinkLsaCount

Count of link LSA.

RouterLsaCount

Count of router LSA

NetworkLsaCount

Count of network LSA.

Intra-Area-PrefixLsaCount

Count of Intra-Area-Prefix LSA.

Inter-Area-PrefixLsaCount

Count of Inter-Area-Prefix LSA.

Inter-Area-RouterLsaCount

Count of router LSA.

Count of Inter-Area-RouterR LSA.

NSSA-externalLsaCount

Count of NSSA-external LSA.

GraceLsaCount

Count of Grace LSA.

UnknownLsaCount

Count of Unknown LSA.

Possible Causes

The device counts the number of updated LSAs (including only Link LSAs, Router LSAs, Network LSAs, Intra-Area-Prefix LSAs, Inter-Area-Prefix LSAs, Inter-Area-Router LSAs, NSSA LSAs, Grace LSAs, and unknown LSAs) by the node that advertised the LSAs. The device outputs historical records every hour and selects the top 10 LSAs that were most frequently updated. If the total number of updated LSAs exceeds 100, this log is generated.

Procedure

  • This log message is informational only, and no action is required.
