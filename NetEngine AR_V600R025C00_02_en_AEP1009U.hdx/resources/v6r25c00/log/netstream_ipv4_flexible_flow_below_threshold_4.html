Description

The number of used NetStream IPv4 flexible flows fell below the threshold.

Parameters

Parameter Name Parameter Meaning

Percentage of used flow resources.

Threshold.

Possible Causes

The number of used NetStream IPv4 flexible flows fell below the threshold.

This message is informational only, and no action is required.
