ND/4/ADDR_DUPLICATE

Message

ND/4/ADDR_DUPLICATE: Received a [PktType] packet with a duplicate IP address [TgtIpv6Address] from the interface [TgtInterfaceName]. (ReceiveIfName=[LocInterfaceName], SourceMacAddress=[SrcMacAddress], DestinationMACAddress=[DstMacAddress], SourceAddress=[SrcIpv6Address], DestinationAddress=[DstIpv6Address], PE-VLAN=[PeVLAN], CE-VLAN=[CeVLAN], SelfMacRecv=[SelfLoop], Attempted=[DadAttempts])

Description

The specified address conflict detection on the interface failed.

Parameters

Parameter Name Parameter Meaning

PktType

Type of the ND packet received due to a conflict.

-TESTDocMETRIC-0619-2

TgtIpv6Address

Conflicting IPv6 address.

TgtInterfaceName

Name of the interface generating the alarm.

LocInterfaceName

Name of the local interface that receives the alarm.

SrcMacAddress

Source MAC address of the ND packet received when a conflict occurs.

DstMacAddress

Destination MAC address of the ND packet received when a conflict occurs.

SrcIpv6Address

Source IPv6 address of the ND packet received when a conflict occurs.

DstIpv6Address

Destination IPv6 address of the ND packet received when a conflict occurs.

PeVLAN

Outer VLAN ID of the received ND packet when a conflict occurs.

CeVLAN

Inner VLAN ID of the received ND packet when a conflict occurs.

SelfLoop

Self-loop flag of the ND packet received when a conflict occurs.

DadAttempts

Number of ND packet detection times.

Possible Causes

The IPv6 address configured on the interface has been used by another node.

Procedure

Configure an IPv6 address that does not conflict with the IPv6 addresses of other nodes for the interface.
