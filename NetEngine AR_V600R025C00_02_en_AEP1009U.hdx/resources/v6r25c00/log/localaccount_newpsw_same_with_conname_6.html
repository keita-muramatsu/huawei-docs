AAA/6/LOCALACCOUNT_NEWPSW_SAME_WITH_CONNAME

Message

AAA/6/LOCALACCOUNT_NEWPSW_SAME_WITH_CONNAME: User password login: Local account [account] entered the new password is same as the user name or inverted user name.UserIp=[userip].

Description

The new password entered by a local user is the same as the user name or the user name in reverse order.

Parameters

Parameter Name Parameter Meaning

account

Name of a local account.

userip

Local account address.

Possible Causes

The password changed by the user is used recently.

Procedure

This message is informational only, and no action is required.
