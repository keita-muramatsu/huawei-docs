LCS_1.3.6.1.4.1.2011.5.25.142.2.37 hwGtlTrialResFeatureDisable

The trial time of resource items is over.

The trial period of the resource ends.

Impact on the System

The system will not be affected.

Possible Causes

Cause 1: The trial period of the resource item expires.

Cause 2: The trial function of the resource item is manually disabled.

Cause 3: A new license file is activated in the current system.

Procedure

1. Run the more command to check whether a license file that contains trial resource control items is applied for in the current system.

  • If so, go to step 3.
  • If not, go to step 2.

2. Apply for a license file and activate it. Then, check whether the alarm is cleared.

  • If so, go to step 4.
  • If not, go to step 3.

3. Collect trap, log, and configuration information, and contact technical support personnel.

4. End.
