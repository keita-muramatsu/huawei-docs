Impact on the System

The configuration database fails to be restored. As a result, the configuration information of the existing services is lost.

Possible Causes

  • Cause 0: The configuration database file was lost or damaged.

Procedure

  • Cause 0: The configuration database file was lost or damaged.

    1. Run the display configuration recover-result command to check the command lines that fail to be restored. Check whether the format of the command lines in the configuration file is correct or whether the command lines are executed in an incorrect view.

    • If yes, go to step 2.
    • If the current configuration is correct, go to step 5.

    2. Reconfigure the commands that fail to be restored.

    • If the alarm persists, go to step 4.
    • If the alarm is not generated, go to step 5.

    3. Run the display startup command to check whether the current startup version is as expected.

    • If the current startup version does not meet the expectation, delete XX.cc, upload the correct basic software package, and complete the upgrade within the operation time window. If the current startup version is normal, directly upgrade the version within the operation time window.
    • If the upgrade fails, go to step 4.
    • If the upgrade is successful, go to step 2.

    4. Collect log and configuration information, and contact technical support personnel.

    5. End.
