Impact on the System

When this alarm is generated, the CPCAR is used when the packet rate exceeds the threshold.

Possible Causes

The rate of packets of a certain protocol that has established connections exceeds 80% of the configured rate, and the rate of packets sent to the CPU through a specific connection exceeds the threshold.

Procedure

Cause 1: The number of protocol packets sent to the CPU exceeded the configured threshold.

1. Run the display cpu-defend linkup statistics all command to check the type of the protocol whose rate exceeds the threshold and determine which link is abnormal together with the display cpu-defend linkup configuration all command output.

  • If the status is abnormal, go to step 2.
  • If no exception occurs, no action is required.

2. Collect alarm, log, and configuration information and contact Huawei technical support personnel.

Cause 1: The number of protocol packets sent to the CPU exceeded the configured threshold.

2. Configure a filter for the user in the cpu-defend policy template to prevent the link packets from being sent to the CPU. Then, check whether the fault is rectified. If the fault persists, go to step 3.

3. Collect alarm, log, and configuration information and contact Huawei technical support personnel.
