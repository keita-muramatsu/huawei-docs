DEVM_1.3.6.1.4.1.2011.5.25.219.2.2.38 hwAllLpuSfuFail

Trap Buffer Description

All installed LPUs and SFUs were not registered for a long time.

All installed LPUs and SFUs fail to register for a long time.Only a single chassis is supported.This alarm is triggered when only one system control board is configured.When two system control boards are configured, the active system control board is reset.
