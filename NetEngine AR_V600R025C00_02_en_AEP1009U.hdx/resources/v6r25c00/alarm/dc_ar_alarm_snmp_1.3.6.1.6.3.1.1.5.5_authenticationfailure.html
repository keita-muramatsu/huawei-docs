SNMP_1.3.6.1.6.3.1.1.5.5 authenticationFailure

Trap Buffer Description

Failed to login through SNMP. (IPAddressType=[IPAddressType], IPAddress=[IPAddress], ReasonInfo=[ReasonInfo])

When the SNMP agent receives a protocol message with an authentication error, the authenticationFailure trap is generated. All SNMP executors must have the capability of generating this trap. The snmpEnableAuthenTraps object indicates whether the capability is enabled.

Impact on the System

An incorrect community name or SNMPv3 user name is used to connect to the device. This does not affect services.

Possible Causes

Cause 1: The community name or user name is incorrect.

Cause 2: The authentication password or encryption password is incorrect.

Procedure

1. SNMPv1 and SNMPv2c: If a community name is configured for the SNMP agent, use the correct community name for login.

2. SNMPv3: If a USM user is configured for the SNMP agent, use the correct user name and password to log in.
