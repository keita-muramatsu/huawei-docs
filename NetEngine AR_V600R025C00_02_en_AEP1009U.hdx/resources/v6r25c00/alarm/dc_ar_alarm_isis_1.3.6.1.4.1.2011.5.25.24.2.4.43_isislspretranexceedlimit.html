ISIS_1.3.6.1.4.1.2011.5.25.24.2.4.43 hwIsisLspRetranExceedLimit

Trap Buffer Description

The number of IS-IS LSP retransmissions on an interface exceeds the limit. (SysInstance=[hwisisSysInstance], InterfaceName=[hwIsisIfName])

The device reports an alarm when the number of IS-IS LSP retransmissions on an interface exceeds the alarm threshold (10). The alarm displays information about a maximum of three such interfaces.

Impact on the System

This alarm is generated when the number of times that packets are retransmitted on the interface exceeds the alarm threshold. The possible cause is that the network is busy. Route synchronization and convergence may be slowed down.

Possible Causes

The number of IS-IS LSP retransmissions on an interface exceeds the limit.

Procedure

1. Run the display lldp neighbor brief command to check the peer device of the interface in the alarm information. Run the display isis lsdb command on the peer device to check the LSPs whose sequence numbers on the local and peer devices are different.

2. Collect alarm and configuration information, and contact technical support personnel.

3. End.
