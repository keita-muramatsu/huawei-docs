Impact on the System

The system will not be affected.

Possible Causes

Cause 1: A neighbor is found.

Cause 2: A neighbor is deleted.

Cause 3: A neighbor is discarded because of insufficient space.

Cause 4: A neighbor is aged.

Procedure

Cause 1: A new neighbor was discovered.

1. Check whether LLDP is enabled for the new neighbor.

  • If so, the message is informational only, and no action is required.
  • If not, go to Step 2.

2. Collect log and configuration information, and contact technical support personnel.

Cause 2: A neighbor was deleted.

1. Check whether LLDP is disabled for the new neighbor.

  • If so, run the lldp enable command in the system view of the neighboring device to enable LLDP.
  • If not, go to Step 2.

2. Check whether a link fault has occurred between the local and neighboring devices.

  • If so, rectify the link fault.
  • If not, go to Step 3.

3. Collect log and configuration information, and contact technical support personnel.

Cause 3: The number of neighbors has reached the upper limit.

1. Check whether the number of neighbors that can be saved on the local device has reached the upper limit.

  • If so, the message is informational only, and no action is required.
  • If not, go to Step 2.

2. Collect log and configuration information, and contact technical support personnel.

Cause 4: A neighbor was aged because the aging period expired.

1. Check whether neighboring node information saved on the local device times out.

  • If so, the message is informational only, and no action is required.
  • If not, go to Step 2.

2. Check whether the interface connecting the local and neighboring devices has been shut down.

  • If so, run the undo shutdown command on the interface to set the interface to up.
  • If not, go to Step 3.

3. Check the CPU usage to determine whether the link between the local and neighboring devices is congested.

  • If so, disable irrelevant communication traffic to eliminate link congestion.
  • If not, go to Step 4.

4. Collect log and configuration information, and contact technical support personnel.

During the splitting of the local interface (regardless of the up or down state), a new interface is generated and the old interface is deleted. In this case, it is normal if this log is generated.
