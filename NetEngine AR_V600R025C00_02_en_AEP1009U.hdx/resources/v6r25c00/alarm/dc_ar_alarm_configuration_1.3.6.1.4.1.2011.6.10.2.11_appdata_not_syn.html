CONFIGURATION_1.3.6.1.4.1.2011.6.10.2.11 hwCfgAppDataInconsistent

Trap Buffer Description

Inconsistency between application configuration data and master main board configuration data.

The data in the service process database is inconsistent with that in the central database.

Impact on the System

If the data in the service process database is inconsistent with that in the central database, the host behavior may be inconsistent with the operator's expectation. As a result, related services cannot be executed.

Possible Causes

This alarm was automatically generated because the data in the service process database was detected inconsistent with that in the central database after data consistency verification was enabled.

Procedure

1. Run the display configuration records appdata-diff command in the diagnostic view to check the IDs of the slots where consistency differences exist.

2. Based on the slot number obtained in step 1, run the reset slot <slot-id> command to reset the board in the slot corresponding to the process and resynchronize the data in the service process database. Check whether the alarm is cleared.

  • If the reset is successful, no further action is required.
  • If the reset fails, go to step 3.

3. Collect alarm, log, and configuration information, and contact technical support personnel.
