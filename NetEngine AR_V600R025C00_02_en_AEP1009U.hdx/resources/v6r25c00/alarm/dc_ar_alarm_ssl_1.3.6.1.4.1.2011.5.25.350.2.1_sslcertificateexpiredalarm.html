SSL_1.3.6.1.4.1.2011.5.25.350.2.1 hwSSLCertificateExpired

Trap Buffer Description

The certificate already expired. (CertificateName=[hwSSLCertificateName], CertificateType=[hwSSLCertificateType], BeginTime=[hwSSLCertificateBeginTime], EndTime=[hwSSLCertificateEndTime])

This alarm is generated when the SSL certificate expires.

Impact on the System

Users cannot pass SSL security authentication.

Possible Causes

The SSL certificate has expired.

Procedure

1. Upload the valid certificate file to the security path of the device based on the type of the expired certificate.

2. After the upload is complete, if the trust certificate is about to expire, run the trusted-ca load command to replace the certificate as follows:

  • Command for loading an ASN1 trusted-CA file for an SSL policy: trusted-ca load asn1-ca filename
  • Command for loading a PEM trusted-CA file for an SSL policy: trusted-ca load pem-ca filename
  • Command for loading a PFX trusted-CA file for an SSL policy: trusted-ca load pfx-ca filename auth-code cipher password

3. If the identity certificate is about to expire, run the certificate load command to replace the certificate as follows.

  • Command for loading a PEM certificate for an SSL policy: certificate load pem-cert filename key-pair dsa key-file filename auth-code cipher password
  • Command for loading a PFX certificate for an SSL policy: certificate load pfx-cert filename key-pair rsa key-file filename auth-code cipher password
  • Command for loading a PEM certificate chain for an SSL policy: certificate load pem-chain filename key-pair rsa key-file filename auth-code cipher password
