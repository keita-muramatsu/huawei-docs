Impact on the System

IP addresses may fail to be allocated.

Possible Causes

The number of access users increased and the usage of the address pool exceeded the threshold.

Procedure

  • Add allocatable IP addresses to the address pool by reducing the mask length. To reduce the mask length, run the ip address <ip-address> { <mask> | <mask-length> } command in the interface view or run the network <ip-address> [ mask { <mask> | <mask-length> } ] command in the global address pool view.
  • If an IP address segment is configured in the address pool, add allocatable IP addresses to the address pool by increasing the range of the IP address segment. To increase the range of the IP address segment, run the dhcp server ip-range <start-ip-address> <end-ip-address> command in the interface view or run the section <section-id> <start-address> [ <end-address> ] command in the global address pool view.
