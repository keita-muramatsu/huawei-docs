Impact on the System

After the alarm function is enabled, if a large number of sessions flap, the CPU usage is high. In normal cases, there is no impact.

Possible Causes

Cause 1: A BFD session was created. That is, the BFD session changed from Init to Up. Cause 2: The undo shutdown command was run to restore the BFD session. That is, the BFD session changed from AdmDown to Up.

Cause 3: The BFD session changed from Down to Up.

Procedure

The log message is informative only, and no action is required.
