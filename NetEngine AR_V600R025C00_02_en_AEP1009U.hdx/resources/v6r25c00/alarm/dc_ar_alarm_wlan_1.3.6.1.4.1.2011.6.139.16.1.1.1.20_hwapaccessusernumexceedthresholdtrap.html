Impact on the System

After the number of access users reaches the CAC threshold, an alarm is generated, indicating that the number of users on the radio has reached the upper limit and new users cannot access the radio. The system has other radios that can provide services. Generally, this alarm does not affect users unless the number of users exceeds the total load of the system.

Possible Causes

The number of users associated with the AP radio has reached the upper limit and new users are associating with the AP radio.

Procedure

1. Run the uac client-number threshold access access-threshold [ roam roam-threshold ] command in the RRM profile view to set a larger upper limit on the number of STAs. Check whether the alarm persists.

If so, go to Step 2.

If not, go to Step 3.

2. Collect trap, log, and configuration information, and contact technical support.

3. End.
