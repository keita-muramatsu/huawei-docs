Impact on the System

  • Cause 1: The digital signature of the system software package failed to be verified.

    Services are not affected.

  • Cause 2: The digital signature of the patch package failed to be verified.

    Services are not affected.

  • Cause 3: The digital signature of the feature package failed to be verified.

    Services are not affected.

  • Cause 4: The digital signature of the system software package failed to be verified at the startup stage.

    The upgrade fails. Roll back to the source version.

  • Cause 5: The digital signature of the patch package failed to be verified at the startup stage.

    The patch package is not loaded.

Possible Causes

  • Cause 1: The digital signature of the system software package failed to be verified.
  • Cause 2: The digital signature of the patch package failed to be verified.
  • Cause 3: The digital signature of the feature package failed to be verified.
  • Cause 4: The digital signature of the system software package failed to be verified at the startup stage.
  • Cause 5: The digital signature of the patch package failed to be verified at the startup stage.

Procedure

  • Cause 1: The digital signature of the system software package failed to be verified.

    1. The digital signature verification of the running software package has expired. The software package is uninstalled.

    2. The digital signature verification of the system software package for next startup expires. Reconfigure the system software package for next startup.

  • Cause 2: The digital signature of the patch package failed to be verified.

    1. Run the clear alarm active command in the alarm management view to manually clear the alarm.

    2. If the digital signature of the current patch package expires, run the patch delete all command in the user view to uninstall the patch package.

    3. If the digital signature of the patch package for next startup expires, run the startup patch all command in the user view to reset the patch package for next startup.

    4. Run the display alarm active verbose command in the user view to check whether the alarm is cleared.

    If so, go to Step 6.

    If not, go to Step 5.

    5. Collect log files and contact technical engineers.

    6. End.

  • Cause 3: The digital signature of the feature package failed to be verified.

    If the digital signature verification of the running (next startup) feature package has expired:

    1. Uninstall the feature package.

    2. Clear the feature package for the next startup.

    3. Specify another feature package for next startup.

    4. Upgrade the feature package.

  • Cause 4: The digital signature of the system software package failed to be verified at the startup stage.

    1. After the device is started, reset the software package for next startup. Then, check whether the alarm is cleared.

    • If so, go to Step 3.
    • If not, go to Step 2.

    2. Collect alarm, log, and configuration information and contact technical engineers.

    3. End.

  • Cause 5: The digital signature of the patch package failed to be verified at the startup stage.

    1. After the device is started, run the patch delete all command to delete the current and next-startup patch packages. Then, check whether the alarm is cleared.

    • If so, go to Step 3.
    • If not, go to Step 2.

    2. Collect alarm, log, and configuration information and contact technical engineers.

    3. End.
