ISIS_1.3.6.1.3.37.2.0.15 isisOrigLSPBuffSizeMismatch

Trap Buffer Description

The size of the local buffer for originating IS-IS LSPs is smaller than the size of the received LSP. (isisSysInstance=[isisSysInstance], isisSysLevelIndex=[isisSysLevelIndex], isisCircIndex=[isisCircIndex], isisCircIfIndex=[isisCircIfIndex], isisPduLspId=[isisPduLspId], isisPduOriginatingBufferSize=[isisPduOriginatingBufferSize], ifIndex=[ifIndex], IfName=[IfName])

The size of received LSPs was greater than that of the local buffer for locally generated LSPs.

Impact on the System

Routes cannot be learned, and traffic forwarding is affected.

Possible Causes

The size of LSPs generated on the source device was greater than that of LSPs generated on the local device.

Procedure

1. Locate the source device that generated the LSP based on the value of the isisPduLspId field in the output. Check whether the size of the LSP generated by IS-IS on the source device is greater than the size of the LSP generated by IS-IS on the local device.

  • If yes, go to Step 2.
  • If no, go to Step 3.

2. Run the lsp-length originate <max-size> command in the IS-IS process of the source device to change the size of the LSP generated by IS-IS and ensure that the size of the LSP generated by the source device is less than or equal to the size of the local LSP buffer.

  • If yes, go to Step 4.
  • If no, go to Step 3.

3. Collect log and configuration information, and contact technical support personnel.

4. End.
