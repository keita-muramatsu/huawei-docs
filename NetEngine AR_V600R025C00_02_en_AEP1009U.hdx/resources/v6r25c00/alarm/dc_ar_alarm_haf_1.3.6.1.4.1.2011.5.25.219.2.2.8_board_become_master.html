HAF_1.3.6.1.4.1.2011.5.25.219.2.2.8 hwBoardBecomeMaster

Trap Buffer Description

Board changed to the master state. (EntityPhysicalIndex=[EntityPhysicalIndex], EntPhysicalIndex=[EntPhysicalIndex], EntPhysicalName=[EntPhysicalName], EntityType=[EntityType], EntityTrapFaultID=[EntityTrapFaultID],Reason=Master/Slave Board Switchover.)

The backup main control board becomes the master main control board.

This alarm is supported only on AR6700-H series, AR8700 series.

Impact on the System

If no active/standby switchover is performed, the original master main control board may be faulty.

Possible Causes

A active/standby switchover is performed or the master main control board is faulty.

Procedure

1. Check whether an active/standby switchover is performed.

  • If so, no action is required.
  • If not, go to Step 2.

2. Run the display device [ slot ] command to check whether the original master main control board is registered successfully.

  • If so, go to Step 4.
  • If not, go to step 3.

3. Remove and install the original master main control board. Wait until the main control board starts successfully and check whether the main control board is registered successfully.

  • If so, go to Step 4.
  • If not, go to Step 5.

4. Check whether the original master main control board is faulty. You can perform an active/standby switchover again to check whether the switchover is successful.

  • If so, go to Step 6.
  • If not, go to Step 5.

5. Collect alarm, log, and configuration information, and contact technical support personnel.

6. End.
