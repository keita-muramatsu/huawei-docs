FWM-ETH_1.3.6.1.4.1.2011.5.25.315.3.2 hwPortVlanSecureMacAlarm

Trap Buffer Description

Interface receive insecure MAC address. (IfIndex=[Interface], InterfaceName=[InterfaceName], MacAddr=[MacAddr], VLAN=[VLAN], Action=[Status](1:restrict;2:protect;3:error-down))

Possible Causes

The interface received a packet whose source MAC address is not a secure MAC address.

Procedure

Run the port-security enable [ maximum max-number ] command in the interface view to increase the maximum number of MAC addresses that can be learned on the interface so that valid MAC addresses can be learned.
