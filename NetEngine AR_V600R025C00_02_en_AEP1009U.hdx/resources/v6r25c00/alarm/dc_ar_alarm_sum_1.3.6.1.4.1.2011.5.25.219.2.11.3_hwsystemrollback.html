SUM_1.3.6.1.4.1.2011.5.25.219.2.11.3 hwSystemRollback

Trap Buffer Description

System rollback. (FileName=[SoftwareName], Version=[Version], Reason=[FailReason])

The system fails to start , and the software rolls back to the old version.

Impact on the System

  • Cause 1: Rollback occurs on the system.

    The system software supports only the service features of the current version after the startup succeeds.

  • Cause 2: The system starts from the backup area

    After the system software is started from the backup area, the user cannot add or delete files on the backup area, and cannot set the next startup package as a file on the backup area

Possible Causes

  • Cause 1: Rollback occurs on the system.
  • Cause 2: The system starts from the backup area

Procedure

  • Cause 1: Rollback occurs on the system.

    1. Run the dir command to check the file system.

    If the storage medium is unavailable, the storage medium is damaged. Go to step 2.

    If the storage medium is available, system software is faulty and cannot start the system. Go to step 3.

    2. Check the storage medium saved in the system software.

    If the storage medium is an SD card or a USB disk, replace it and restart the upgrade. If the upgrade fails, go to step 3.

    If the storage medium is flash, record the device type and number, collect alarm information and configuration information, and then contact technical support personnel.

    3. Collect operation results, alarm information, and configuration information, and then contact technical support personnel.

  • Cause 2: The system starts from the backup area

    1. Run the display startup command in the user view to view information about the system software and configuration files started by the current device. The display shows that the storage path of the system software or configuration file used for this startup is the backup area, indicating that the system starts from the backup area. .

    2. After starting from the standby area, the user cannot select the files in the standby area to set the next startup. Please format the root directory of the main area. After the main area is repaired, copy the system software to the main area directory and perform the upgrade. If the upgrade still fails, go to step 3

    3. Collect operation results, alarm information, and configuration information, and then contact technical support personnel.
