Trap Buffer Parameters

Parameter Description

PeerLsrId

Peer LSR ID.

VrfName

VRF for an LDP session.

SessionType

LDP session type: - Local - Remote - Local and remote

IfName

Name of the physical interface.

SubReason

Detailed reason for the LDP session down event.

If an LDP session goes down because an error packet is received, the detailed error type is displayed. If an LDP session goes down because a Notify message is received, the detailed Notify type is displayed. Examples of typical error causes:

  • A packet with an incorrect LDP ID was received (1).
  • A packet with an incorrect version number was received (2).
  • A packet with an incorrect PDU length was received (3).
  • A packet with an incorrect message length was received (5).
  • A packet with an incorrect TLV was received (7).
  • A hello timeout notification message was received (9).
  • A shutdown notification message was received (10).
  • A keepalive timeout notification message was received (20).
  • IGP deleted RLFA IID (1056968430).

If an LDP session goes down because a socket error is received, the detailed error cause or error code is displayed. The following are examples of typical error causes:

  • TCP connection reset (54)
  • TCP connection timeout (60)

If an LDP session goes down because LDP packets fail to be sent or received, the detailed cause is displayed. The following are examples of typical causes:

  • A large number of LDP packets are not processed.
  • Failed to receive the packet.
  • Failed to send the packet.

If an LDP session goes down because LDP fails to set the socket option or LDP receives a socket close message, a detailed error code is displayed.

If the LDP session goes down due to other causes, the value of this field is 0.

Impact on the System

  • Cause 0: The LDP session went Up.

    Services are not affected.

  • Cause 1: The LDP session went Up.

    There is no impact on the system.

  • Cause 2: The configure of MPLS LDP is deleted.

    All the services based on this LDP session will be interrupted.

  • Cause 3: The undo ti-lfa remote-peer disable command was run in the global MPLS LDP view.

    There is no impact on the system.

  • Cause 25: The LDP session was deleted.

    Services are not affected.

Possible Causes

  • Cause 0: The LDP session went Up.
  • Cause 1: The LDP session went Up.
  • Cause 2: The configure of MPLS LDP is deleted.
  • Cause 3: The undo ti-lfa remote-peer disable command was run in the global MPLS LDP view.
  • Cause 25: The LDP session was deleted.

Procedure

  • Cause 0: The LDP session went Up.

    This trap message is informational only, and no action is required.

  • Cause 1: The LDP session went Up.

    This trap message is informational only, and no action is required.

  • Cause 2: The configure of MPLS LDP is deleted.

    Reconfigure LDP.

  • Cause 3: The undo ti-lfa remote-peer disable command was run in the global MPLS LDP view.

    This trap message is informational only, and no action is required.

  • Cause 25: The LDP session was deleted.

    This trap message is informational only, and no action is required.
