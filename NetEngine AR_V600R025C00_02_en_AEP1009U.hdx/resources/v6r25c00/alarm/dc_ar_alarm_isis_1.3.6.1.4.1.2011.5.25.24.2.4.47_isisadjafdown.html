ISIS_1.3.6.1.4.1.2011.5.25.24.2.4.47 hwIsisAdjAfDown

Trap Buffer Description

One address family of the IS-IS dual-stack neighbor is down. (SysInstance=[hwisisSysInstance], SysLevel=[hwisisSysLevelIndex], IfIndex=[ifIndex], IfName=[ifName], AdjSysID=[hwIsisAdjSysID], AddressFamily=[hwIsisAddressFamily], Reason=[hwIsisAdjAfDownReason])

An alarm is reported when the states of the two address families of an IS-IS dual-stack neighbor are inconsistent.

Impact on the System

IS-IS services related to the address family neighbor are interrupted, and traffic cannot be forwarded.

Possible Causes

An address family of an IS-IS dual-stack neighbor changes from up to down, causing the states of the two address families of the IS-IS dual-stack neighbor to be inconsistent.

Procedure

1. Run the display isis peer verbose command to check whether the states of the two address families of an IS-IS dual-stack neighbor are consistent based on the Adj Protocol field.

  • If yes, go to Step 4.
  • If no, go to Step 2.

2. Run the ping or ping ipv6 command to check whether the IP address of the peer interface can be pinged.

  • If yes, go to Step 3.
  • If no, rectify the link fault.

3. Check whether the IS-IS process is enabled on the interface.

  • If yes, go to Step 4.
  • If no, run the isis enable command to enable the IS-IS process and check whether the alarm is cleared.
  • If yes, no further action is required.
  • If no, go to step 4.

4. Collect log and configuration information, and contact technical support personnel.
