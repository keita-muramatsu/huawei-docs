ARP_1.3.6.1.4.1.2011.5.25.123.2.6 hwEthernetARPIPConflictEvent

Trap Buffer Description

Detected an IP address collision. (IpAddress=[IpAddr], Local MacAddress=[LocalMacAddr], Local InterfaceName=[LocalIfName], Local VLAN=[LocalPVid], Local INNER-VLAN=[LocalCVid], Received MacAddress=[RcvMacAddr], Received InterfaceName=[RcvIfName], Received VLAN=[RcvPVid], Received INNER-VLAN=[RcvCVid], Collision Type=[type])

The device checked that the source IP address of ARP packets conflicted with the IP address in the local ARP entry.

Impact on the System

If this alarm is generated, conflicting IP addresses exist on the network. If the conflict is not eliminated in a timely manner, faults such as route flapping and service or traffic interruption may occur.

Possible Causes

The device could find the source IP address carried in a non-gratuitous ARP packet among its local ARP entries, but could not find the source MAC address carried in that packet among its local ARP entries.

Procedure

Check the devices with the same IP address on the network. Change the interface IP addresses based on the IP address plan to resolve the IP address conflict.
