Procedure

  • Cause 1: Over-input-voltage occurred on the power module

    1. Check whether the external power supply is normal. If the external power supply is abnormal, repair the external circuit.

    2. If the alarm persists, replace the power module.

  • Cause 2: Under-input-voltage occurred on the power module.

    1. Check whether the external power supply is normal. If the external power supply is abnormal, repair the external circuit.

    2. If the alarm persists, replace the power module.

  • Cause 3: The power module supply failed.

    1. Check whether the fan of the power module is blocked by the air filter. If the fan is blocked, clean the air filter.

    2. Check whether the ambient temperature is normal. If the ambient temperature is high, improve the ventilation environment.

    3. Check whether the power supply is normal. If the power supply is abnormal, repair the external power supply circuit.

    4. If the alarm persists, replace the power module.

  • Cause 4: Over-temperature occurred on the power module.

    1. Check whether the fan of the power module is blocked by the air filter. If the fan is blocked, clean the air filter.

    2. Check whether the ambient temperature is normal. If the ambient temperature is high, improve the ventilation environment.

    3. Check whether the power supply is normal. If the power supply is abnormal, repair the external power supply circuit.

    4. If the alarm persists, replace the power module.

  • Cause 5: The power module was installed but not powered on.

    1. Power on the power supply. If the fault persists, go to step 2.

    2. Collect alarm, log, and configuration information, and contact technical support personnel.

  • Cause 6: The output of the power module failed.

    1. Check whether the external power supply is normal. If the external power supply is abnormal, repair the external circuit.

    2. If the alarm persists, replace the power module.

  • Cause 7: Over-output-voltage occurred on the power module.

    1. Check whether the external power supply is normal. If the external power supply is abnormal, repair the external circuit.

    2. If the alarm persists, replace the power module.

  • Cause 8: The power was not present.

    1. Check whether the power module is properly installed. If not, remove and reinstall the power module. If the fault persists, go to step 2.

    2. Collect alarm, log, and configuration information, and contact technical support personnel.

  • Cause 9: The actual power exceeded the rated power.

    1. Check whether the power supply is a standard power supply.

    • If not, go to Step 2.
    • If so, go to Step 3.

    2. Replace the power supply with a standard one.

    • If the alarm is cleared, go to Step 4.
    • If the alarm persists, go to Step 3.

    3. Collect alarm, log, and configuration information, and contact technical support personnel.

    4. End.

  • Cause 10: The power module is in overtemperature protection state.

    1. Power on the power supply. If the fault persists, go to step 2.

    2. Collect alarm, log, and configuration information, and contact technical support personnel.

  • Cause 11: The power backplane cable was not installed properly.

    1. Remove and then insert the power cable.

    2. Collect alarm, log, and configuration information and contact technical support personnel.

  • Cause 12: The power type does not match the type of the backplane.

    1. Check the power supply type and replace the power supply to ensure that the power supply matches the backplane type.

    • If the alarm is cleared, go to step 3.
    • If the alarm persists, go to step 2.

    2. Collect alarm, log, and configuration information, and contact technical support personnel.

    3. End.

  • Cause 13: The A plane power supply on the power module is faulty.

    1. Check whether the external power supply is normal. Then, check whether the alarm is cleared.

    • If not, go to Step 2.
    • If so, go to Step 3.

    2. Rectify the fault in the external power supply channel. Then, check whether the alarm is cleared.

    • If so, go to Step 5.
    • If not, go to Step 3.

    3. Replace the power supply. Then, check whether the alarm is cleared.

    • If so, go to Step 5.
    • If not, go to Step 4.

    4. Collect alarm, log, and configuration information, and contact technical support personnel.

    5. End.

    2. Replace the non-power components in the power supply slots with power modules that match the device.

    • If the alarm is cleared, go to Step 4.
    • If the alarm persists, go to step 3.

    3. Collect trap, log, and configuration information, and contact technical support personnel.

    4. End.
