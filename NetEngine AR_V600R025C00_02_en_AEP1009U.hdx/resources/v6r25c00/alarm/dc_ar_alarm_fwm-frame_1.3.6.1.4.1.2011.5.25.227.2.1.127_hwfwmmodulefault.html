Impact on the System

  • Cause 1: The forwarding module startup failed.

    The forwarding module does not function properly.

  • Cause 2: The forwading module startup ondemand failed.

    The forwarding module does not function properly.

  • Cause 3: The loopback heartbeat function of the subcard fails.

    The loopback heartbeat function of the subcard is abnormal.

Possible Causes

  • Cause 1: The forwarding module startup failed.
  • Cause 2: The forwading module startup ondemand failed.
  • Cause 3: The loopback heartbeat function of the subcard fails.

Procedure

  • Cause 1: The forwarding module startup failed.

    Collect alarm, log, and configuration information, and contact technical support personnel.

  • Cause 2: The forwading module startup ondemand failed.

    1. Re-deliver the configuration to start the module. After the module is restarted, check whether the alarm is cleared.

    • If so, go to Step 3.
    • If not, go to Step 2.

    2. Collect alarm, log, and configuration information, and contact technical support personnel.

    3. End.

  • Cause 3: The loopback heartbeat function of the subcard fails.

    Collect alarm, log, and configuration information, and contact technical support personnel.
