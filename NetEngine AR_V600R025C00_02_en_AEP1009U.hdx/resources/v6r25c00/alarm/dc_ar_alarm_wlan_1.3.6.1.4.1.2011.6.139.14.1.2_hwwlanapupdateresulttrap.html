Impact on the System

Services will not be affected after the successful upgrade.

APs and AP-based services cannot work properly after the failed automatic upgrade.

APs cannot be upgraded to a new version after the failed online upgrade. However, existing services are not affected.

Possible Causes

AP upgrade finished or failed.

Procedure

1. Check the upgrade result in the alarm parameters.

• If AP upgrade succeeded, go to Step 10.

• If AP upgrade failed, go to Step 2.

2. Run the display ap update configuration command to check the configured AP upgrade mode.

• If the FTP upgrade mode is used, go to Step 3.

• If the protocol transmission mode is used, go to Step 6.

3. Run the display ap update configuration command to check whether the FTP upgrade is correctly configured.

• If not, run the ap update ftp-server command to modify the configuration. Then go to Step 8.

• If so, go to Step 4.

4. Check whether upgrade files exist on the FTP server.

• If not, store the correct files on the FTP server. Then go to Step 8.

• If so, go to Step 5.

5. Check whether the network between the AP and the FTP server is normal.

• If not, rectify the network fault, and perform the upgrade again. Then go to Step 8.

• If so, go to Step 7.

6. Run the dir command to check whether there is an upgrade file in the flash memory on the AC.

• If not, load correct files to the AC. Then go to Step 8.

• If so, go to Step 7.

7. Check whether upgrade files are correct.

• If not, reload or store these files, and perform the upgrade again. Then go to Step 8.

• Correct. =>9

8. Check whether the upgrade is successful.

• If so, go to Step 10.

• If not, go to Step 9.

9. Collect trap, log, and configuration information, and contact technical support.

10. End.
