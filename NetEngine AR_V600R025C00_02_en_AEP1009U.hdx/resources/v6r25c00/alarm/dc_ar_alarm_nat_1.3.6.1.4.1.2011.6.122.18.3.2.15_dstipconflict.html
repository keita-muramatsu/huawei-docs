Impact on the System

Packets were discarded due to port conflicts.

Possible Causes

The NAT address pool is in PAT mode, and the number of ports to be translated for users' access to the same service (with the same destination address, port number, and protocol) through the device is greater than the number of available ports in the address pool.

Procedure

Add IP addresses to the address pool.

Run the display firewall statistics system discard command in the user view to check whether the number of packets discarded due to port conflicts (NAT port alloc fail packets discarded) increases rapidly.

Increase the number of addresses in the address pool based on the increase rate of packet loss, enter the address pool view (using the nat address-group command), and configure an address segment (using the section command).

Run the display nat port conflict command in the diagnostic view to check information about conflicting 5-tuple.
