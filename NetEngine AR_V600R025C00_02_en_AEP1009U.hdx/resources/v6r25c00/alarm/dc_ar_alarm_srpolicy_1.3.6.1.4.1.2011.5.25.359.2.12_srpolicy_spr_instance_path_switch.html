Impact on the System

This user is notified that the path of an SPR instance is switched.

Possible Causes

1. Configurations are changed. The original primary path does not exist in the new SPR policy.

2. The path status changes.

3. The path is switched.

4. Traffic is switched back to the original path.

5. Other causes.

Procedure

Check the reason why the path of the SPR instance is switched.
