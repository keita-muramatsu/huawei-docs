Trap Buffer Description

IS-IS LSP at this node is overloaded start. (SysInstance=[hwisisSysInstance])

The number of IS-IS LSP fragments on the node reached the upper limit, and the information carried in the LSP was incomplete.

Impact on the System

When LSPs are overloaded, a node cannot create new LSP fragments. As a result, LSDB synchronization cannot be maintained, and route calculation fails. When calculating routes, other nodes on the network exclude the node where the LSP is overloaded. As a result, traffic fails to be forwarded.

Possible Causes

The number of IS-IS LSP fragments on this node has reached the upper limit, and no more routing information could be saved. Therefore, the route information carried by LSP fragments is incomplete.

Procedure

1. Run the display isis lsdb command to view the IS-IS LSDB and check whether the number of LSP fragments reaches the upper limit (256).

2. If the number of LSP fragments reaches the upper limit, modify the configuration to reduce the number of IS-IS routing information to be saved. When the number of remaining LSP fragments is greater than or equal to 4, the alarm is automatically cleared.

3. If the number of LSP fragments cannot be reduced, collect log and configuration information, and contact technical support personnel.
