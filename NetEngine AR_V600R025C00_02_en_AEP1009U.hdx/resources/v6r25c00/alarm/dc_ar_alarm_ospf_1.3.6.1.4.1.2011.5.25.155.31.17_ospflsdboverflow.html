OSPF_1.3.6.1.4.1.2011.5.25.155.31.17 hwOspfv2LsdbOverflow

Trap Buffer Description

The number of AS-external LSAs in the LSDB of an OSPF process reaches the configured maximum number. (hwOspfv2ProcessIdIndex=[hwOspfv2ProcessIdIndex], hwOspfv2MaxLimit=[hwOspfv2MaxLimit])

The number of external routes in the OSPF LSDB exceeded the maximum number allowed.

Impact on the System

The network stability may be adversely affected.

Possible Causes

The number of external routes in the OSPF LSDB exceeded the maximum number allowed.

Procedure

1. Run the display ospf brief command. If OSPF is in LSDB overflow status is displayed in the command output, the OSPF LSDB in the current OSPF process is overloaded. If OSPF LSDB is approaching overflow limit is displayed in the command output, the number of external routes in the OSPF LSDB has reached or exceeded 90% of the maximum number.

  • If the OSPF LSDB is overloaded, go to Step 2.
  • If the OSPF LSDB is not overloaded, this trap message is informational only and no action is required.

2. Perform the following operations as required:

  • If a change in the maximum number is allowed, run the lsdb-overflow-limit <number> command to increase it.
  • If a change in the maximum number is not allowed, go to Step 3.

3. Contact technical support personnel.

4. End.
