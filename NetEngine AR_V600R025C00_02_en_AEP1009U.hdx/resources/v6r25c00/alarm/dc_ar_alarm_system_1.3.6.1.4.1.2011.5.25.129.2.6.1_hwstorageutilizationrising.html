SYSTEM_1.3.6.1.4.1.2011.5.25.129.2.6.1 hwStorageUtilizationRisingAlarm

Trap Buffer Description

The storage usage exceeded the pre-set overload threshold. (TrapSeverity=[TrapSeverity], ProbableCause=[ProbableCause], EventType=[EventType], PhysicalIndex=[PhysicalIndex], PhysicalName=[PhysicalName], RelativeResource=[RelativeResource], UsageType=[UsageType], SubIndex=[SubIndex], UsageValue=[UsageValue], Unit=[Unit], UsageThreshold=[UsageThreshold])

The continuously samples the storage medium usage, such as the memory usage and storage medium usage. In a sampling period (number of consecutive overload times x sampling interval), this alarm is generated if the usage of each sampling is greater than the overload threshold.

Impact on the System

  • Cause 75264: The memory usage exceeded the pre-set overload threshold.

    If the service fails to apply for memory, the system automatically restarts.

  • Cause 75265: The storage usage exceeded the pre-set overload threshold.

    If the storage medium space is insufficient, the log function and software upgrade are affected.

  • Cause 75269: The memory usage of one process exceeded the pre-set overload threshold. The max memory size is 3G for one process.

    1. If the service fails to apply for memory, the system automatically restarts.

    2. If the storage medium space is insufficient, the log function and software upgrade are affected.

  • Cause 75274: The message memory usage exceeded the overload threshold.

    1. If the service fails to apply for memory, the system automatically restarts.

    2. If the storage medium space is insufficient, the log function and software upgrade are affected.

Possible Causes

  • Cause 75264: The memory usage exceeded the pre-set overload threshold.
  • Cause 75265: The storage usage exceeded the pre-set overload threshold.
  • Cause 75269: The memory usage of one process exceeded the pre-set overload threshold. The max memory size is 3G for one process.
  • Cause 75274: The message memory usage exceeded the overload threshold.

Procedure

  • Cause 75264: The memory usage exceeded the pre-set overload threshold.

    1. Run the display system memory statistics command to check the memory usage (calculated by System Used/System Total). Run the display memory threshold command to check the overload threshold.

    • If the memory usage is higher than the overload threshold, go to Step 2.
    • If the memory usage is lower than the overload threshold, go to Step 4.

    2. Delete unnecessary services and configurations to reduce the memory usage. Then, check whether the alarm is cleared. When deleting service configurations, submit the configurations in small batches (3 to 5 records at a time).

    • If no alarm is generated, the fault is rectified.
    • If the alarm persists, go to Step 3.

    3. Run the set memory threshold command to adjust the overload threshold and check whether the alarm is cleared.

    • If no alarm is generated, the fault is rectified.
    • If the alarm persists, go to Step 4.

    4. Collect alarm, log, and configuration information, and contact technical support engineers.

  • Cause 75265: The storage usage exceeded the pre-set overload threshold.

    1. In the user view, run the cd command to enter the corresponding storage medium directory, and then run the dir command to check the storage space usage of the storage medium.

    • If the storage space usage of the storage medium is higher than the overload threshold, go to Step 2.
    • If the storage space usage of the storage medium is lower than the overload threshold, go to Step 3.

    2. Run the display startup command in the user view to check the configured startup system software and startup patch package in use,

    Delete unnecessary files from the storage medium to reduce the storage space usage of the storage medium. Then, check whether the alarm is cleared.

    • If no alarm is generated, the fault is rectified.
    • If the alarm persists, go to Step 3.

    3. Collect alarm, log, and configuration information, and contact technical support engineers.

  • Cause 75269: The memory usage of one process exceeded the pre-set overload threshold. The max memory size is 3G for one process.

    1. Run the display system memory statistics [ slot <slotid> [ cpu <cpuID> ] ] command to check which process uses the most memory.

    2. Delete unnecessary services and configurations based on the memory usage queried in step 1. Wait for 1 minute and check whether the alarm is cleared.

    • If the alarm is cleared, go to step 4.
    • If the alarm persists, go to step 3.

    3. Collect alarm, log, and configuration information, and contact technical support engineers.

    4. End.

  • Cause 75274: The message memory usage exceeded the overload threshold.

    1. Delete unnecessary services and configurations. Wait for 1 minute and check whether the alarm is cleared.

    • If the alarm is cleared, go to Step 3.
    • If the alarm persists, go to Step 2.

    2. Collect alarm, log, and configuration information and contact technical support personnel.

    3. End.
