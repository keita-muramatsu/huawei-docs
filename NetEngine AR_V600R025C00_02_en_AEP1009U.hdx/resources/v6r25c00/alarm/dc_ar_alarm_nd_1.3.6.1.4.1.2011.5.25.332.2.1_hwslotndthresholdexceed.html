Impact on the System

The board may fail to learn new ND entries any more after the number of ND entries on a board exceeds the threshold.

Possible Causes

The number of ND entries has exceeded 80% of the threshold value.

Procedure

1. Check whether ND entries on the board are valid. Valid entries need to be reserved.

2. If the entries are invalid and dynamic, run the reset ipv6 neighbors command to delete them. If the entries are invalid and static, run the undo ipv6 neighbor command to delete them. Remote entries need to be deleted by the remote device.

3. If invalid entries are still continuously sent to the CPU, run the ipv6 nd neighbor-limit command to limit the number of entries learned by the interface.
