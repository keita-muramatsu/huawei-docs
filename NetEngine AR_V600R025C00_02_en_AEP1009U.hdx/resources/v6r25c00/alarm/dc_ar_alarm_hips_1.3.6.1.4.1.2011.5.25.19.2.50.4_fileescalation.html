HIPS_1.3.6.1.4.1.2011.5.25.19.2.50.4 hwHipsFilePrivilegeEscalated

Trap Buffer Description

The file privilege has been escalated. (eventCategory=[event-category], eventType=[event-type], level=[level], occurTime=[occur-time], result=[result], path=[path], method=[method], slot=[slot], card=[card], cpu=[cpu], barcode=[barcode])

A file privilege escalation event occurs on the device. After an attacker intrudes a device, the attacker modifies the SUID/SGID bit of the executable file for persistent permission. Even if the attacker logs in to the device as a common user, the attacker can run high-risk commands.
