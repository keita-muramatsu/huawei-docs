CONFIGURATION_1.3.6.1.4.1.2011.6.10.2.25 hwCfgBackupFailure

Trap Buffer Description

Configuration backup failed in the system. (reason=[cause])

The system configuration fails to be backed up.

This alarm is supported only on AR6700-H series, AR8700 series.

Impact on the System

Data cannot be synchronized between the active and standby boards, and the rollback point files on the active and standby boards are inconsistent.

Possible Causes

Insufficient backup board space, fallback point backup failed.

Procedure

1. Run the delete command to delete unnecessary files from the home directory on the slave main control board to release space on the slave main control board. Then, run the reset slot <slotId> command to reset the slave main control board to trigger configuration backup.

If yes, go to Step 3.

If the operation fails, go to step 2.

2. Collect log and configuration information, and contact technical support personnel.

3. End
