Impact on the System

The router cannot manage the RU.

Possible Causes

Cause 1:

The RU is reset.

Cause 2:

The RU is powered off.

Cause 3:

The heartbeat of the TCP connection between the router and RU times out.

Procedure

1. Check whether the external power supply of the RU is normal.

  • If so, go to Step 2.
  • If not, check that the external cables are properly connected and the PoE adapter works properly. Then, restore the power supply to the RU.

2. Check whether the TCP connection between the router and RU is normal.

  • If so, go to Step 3.
  • If not, check whether the configuration is correct. If the configuration is incorrect, go to Step 3. Then, check whether the CPU usage of the router and RU is too high. If an alarm indicating high CPU usage is generated, clear the alarm.

3. Collect trap, log, and configuration information, and contact technical support personnel.

4. the procedure ends.
