LDP_1.3.6.1.2.1.10.166.4.0.1 Session-Retry

Trap Buffer Description

The number of session initialization messages exceeds the mplsLdpEntityInitSessionThreshold. (PeerLdpId=[PeerLdpId],EntityIndex=[EntityIndex],Times=[InitSessionThreshold])

mplsLdpEntityInitSessionThreshol was not zero and the sequence number of an Initialization message exceeded mplsLdpEntityInitSessionThreshold.

Impact on the System

The session cannot be set up. The original services or newly added ones that depend on the session are interrupted.

Possible Causes

  • Cause 1: The local end no longer supports the DoD mode but the peer supports DoD mode, leading to label advertisement mode inconsistency. Cause 2: Keepalive time negotiation fails because the Keepalive time value on the peer end is set to 0. In this version, the minimum value is 30.This means the log is displayed when the peer Keepalive time is 0s.

Procedure

1. Check whether both ends are Huawei devices.

If so, go to Step 2.

If not, go to Step 3.

2. Check whether the label advertisement modes configured on both ends are the same. Run the display mpls ldp peer <peer-id> command to check neighbors. The value of <peer-id> must be the same as the value of the PeerLdpId field in the alarm information.

Check whether the mpls ldp advertisement dod/du command configurations on the interfaces corresponding to Peer Discovery Source in the command output are the same as those on the remote peer. If they are different, configure them to be the same. Then run the display mpls ldp session <peer-id> command to check the session status.

If the status of the neighbor is Operational, go to Step 4. Otherwise, go to Step 5.

3. Check whether the Keepalive protection time configured on the peer device is 0.

  • If so, change the value to a non-zero value.
  • If not, go to Step 5.

4. The session has gone Up again. This indicates that the fault is caused by inconsistent label advertisement modes. No further action is required.

5. Collect log and configuration information, and contact technical support personnel.
