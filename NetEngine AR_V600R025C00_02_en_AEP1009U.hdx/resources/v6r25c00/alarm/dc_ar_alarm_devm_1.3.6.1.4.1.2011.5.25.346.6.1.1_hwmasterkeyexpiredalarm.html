DEVM_1.3.6.1.4.1.2011.5.25.346.6.1.1 hwMasterKeyExpiredAlarm

The user master key expired.

The customer master key expires.

Impact on the System

If the system master key is manually set by a user, only this alarm is reported after the master key expires. The master key does not become invalid, which may cause key leakage.

Possible Causes

The MasterKey usage of the user exceeds the expiration time of the key.

Procedure

1. The display master-key configuration command is used to query the type of the master key in the current system.

  • If the master key is manually set, go to Step 2.
  • If the master key is automatically updated, go to Step 3.

2. Run the set master-key command to reconfigure the customer master key.

3. Collect alarm, log, and configuration information, and contact technical support personnel.

4. End.
