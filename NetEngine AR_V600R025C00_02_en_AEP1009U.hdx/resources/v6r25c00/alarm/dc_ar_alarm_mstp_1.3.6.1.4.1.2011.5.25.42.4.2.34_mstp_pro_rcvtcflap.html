Impact on the System

STP topology flapping occurs.

Possible Causes

The local device received many TC BPDUs from neighbors.

Procedure

1. Check the STP port state of the neighbour is flapping, check hwMstpiPortStateForwarding and hwMstpiPortStateDiscarding alarms are in alarm history.

  • If the operation is proper, go to Step 2.
  • If the operation is not proper, check the neighbours' stp state, and neighbours of neighbours stp port state by check hwMstpiPortStateForwarding or hwMstpiPortStateDiscarding alarms are in alarm history, find which device's stp is flapping, go to Step 2.

2. Run the command display this interface to check STP ports went Up or Down frequently.

  • If the operation is proper, check the network links state.
  • If the operation is not proper, go to Step 3.

3. Collect alarm and configuration information, and contact technical support personnel.
