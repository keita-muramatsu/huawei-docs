HPP_1.3.6.1.4.1.2011.5.25.227.2.1.76 hwAclGroupExceed

Trap Buffer Description

The number of acl group resource is full. (Current usage=[Usage]%, Threshold=[Threshold]%)

When the number of ACL rule groups reaches the upper limit, the device generates an alarm.

Impact on the System

Services are affected.

Possible Causes

The number of acl groups in the current device is 100% of the number of specifications.

Procedure

Check whether the service configuration exceeds the specifications.

If yes, delete unnecessary ACL rule groups from the device.

If not, collect alarm, log, and configuration information, and contact technical support personnel.
