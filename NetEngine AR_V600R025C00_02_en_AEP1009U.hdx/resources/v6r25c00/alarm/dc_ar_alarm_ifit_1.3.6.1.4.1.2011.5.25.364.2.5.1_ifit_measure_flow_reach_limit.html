IFIT_1.3.6.1.4.1.2011.5.25.364.2.5.1 hwIfitMeasureFlowNumExceedAlarm

Trap Buffer Description

The number of IFIT entire system measurement flows reaches the upper limit. (Node=[NodeType], FlowType=[FlowType], UpperLimit=[UpperLimit])

The number of IFIT measurement flows on the IFIT-enabled device reached the upper limit.

Trap Buffer Parameters

Parameter Description

NodeType

Flow node type for IFIT measurement (The supported node types depend on the device.)

  • ingress: indicates the ingress.
  • transit: indicates a transit node.
  • egress: indicates the egress.
  • -: indicates that the node type is not distinguished.

FlowType

IFIT measurement flow type (The supported flow types depend on the device.)

  • SRv6 TE Policy: SRv6 TE Policy flow
  • static: statically configured flows
  • -: Flow types are not distinguished.

UpperLimit

Indicates the upper limit for the number of IFIT measurement flows on the IFIT-enabled device.

Impact on the System

Measurement flows cannot be created on the IFIT-capable device.

Possible Causes

The number of IFIT measurement flows reaches the upper limit.

Procedure

1. On the NMS, check whether the number of measurement flows on the IFIT device reaches the upper limit. Delete redundant IFIT measurement flows and check whether the alarm is cleared.

2. If the alarm persists, contact technical support engineers.
