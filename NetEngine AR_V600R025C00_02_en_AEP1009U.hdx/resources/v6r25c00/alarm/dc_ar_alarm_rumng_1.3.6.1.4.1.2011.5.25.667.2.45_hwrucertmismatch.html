RUMNG_1.3.6.1.4.1.2011.5.25.667.2.45 hwRuCertMisMatch

Trap Buffer Description

Remote unit certificate version does not match the central device. (RemoteUnitEsn=[RemoteUnitEsn])

The certificate version of an RU does not match that of the central device.

Impact on the System

1. Run the display remote-unit verbose command in the user view on the central device to check RU information. The command output shows that Version match is NO and Authen Result is Fail.

2. Configurations cannot be delivered to the RU, such as restarting the RU, configuring port isolation, and adding an RU interface to a VLAN.

Possible Causes

The RU certificate version does not match the central device.

Procedure

Upgrade the firmware of the RU. For details, see "RU Authentication Failure" in the Configuration Guide > Intelligent Simplified Campus Network Configuration.
