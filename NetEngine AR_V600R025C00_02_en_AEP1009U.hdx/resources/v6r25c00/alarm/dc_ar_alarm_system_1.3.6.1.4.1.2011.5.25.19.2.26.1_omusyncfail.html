SYSTEM_1.3.6.1.4.1.2011.5.25.19.2.26.1 hwOMUSyncFailAlarm

Trap Buffer Description

Data failed to be synchronized from the master OMU to the slave OMU. (Reason=The OMU data of [BoardName] synchronization timed out. [Action])

The active OMU fails to synchronize data to the standby OMU.

This alarm is supported only on AR6700-H series, AR8700 series.

Impact on the System

Possible Causes

The OMU data synchronization timed out.

Procedure

1. Run the display device command to view the name of the standby OMU, and then run the reset slot command to restart the standby OMU.

2.After the standby OMU restarts, check whether the alarm is cleared.

  • If the alarm persists, go to Step 3.
  • If the alarm is cleared, go to Step 4.

3.Collect alarm and configuration information and contact technical support engineers.

4. End
