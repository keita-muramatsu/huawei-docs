Impact on the System

The container and applications in the container cannot run properly.

Possible Causes

An exception occurred on the container or an application in the container. As a result, the CPU usage of the container exceeded 90% for 120 consecutive seconds.

Procedure

1. Run the display ap container public-key status { ap-id ap-id | all} command to check the container status.

2. Collect trap, log, and configuration information, as well as container status information collected in Step 1, and contact technical support personnel.

3. End.
