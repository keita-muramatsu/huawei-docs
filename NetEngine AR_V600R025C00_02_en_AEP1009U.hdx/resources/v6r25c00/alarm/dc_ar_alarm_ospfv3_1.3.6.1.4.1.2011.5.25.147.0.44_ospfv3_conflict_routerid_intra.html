Impact on the System

If router IDs are the same, router LSAs are refreshed frequently, causing route flapping.

Possible Causes

At least two indirectly connected devices in an area have the same router ID. As a result, router LSAs are refreshed frequently and route flapping occurs.

Procedure

1. Check whether the router ID in the alarm is the same as the OSPFv3 router ID of another device on the network.

  • If they are the same, go to Step 2.
  • If they are different, go to Step 3.

2. Run the undo ospfv3 router-id auto-recover disable command to enable the automatic detection and recovery function. After a new router ID is selected, check whether the alarm is cleared.

  • If yes, no further action is required.

− If no, go to Step 3.

3. Collect log and configuration information, and contact technical support.
