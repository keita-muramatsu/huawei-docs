Impact on the System

If the alarm persists, all PDs may be powered off due to insufficient power supply.

Possible Causes

The total power consumption of all the PDs is greater than or equal to the alarm threshold.

Procedure

1. Run the stelnet ip-address command to log in to the AP and run the display poe-power command on the AP to check the power supply capability of the AP. Then plan the network.

2. If the system stays in alarm state, run the poe disable command in the AP wired port link profile to power off some PDs to ensure system reliability. Check whether the alarm is cleared.

If so, go to Step 3.

If not, power off the PD.

3. End.
