SYSTEM_1.3.6.1.4.1.2011.5.25.31.2.0.21 hwEntityExtHardDiskFull

Trap Buffer Description

The disk partition usage exceeded the pre-set overload threshold. (DiskType=[DiskType], DiskSN=[DiskSN], DiskUsage=[DiskUsage], DiskUsageThreshold=[DiskUsageThreshold])

The system continuously samples the disk partition usage.In a sampling period (number of consecutive overload times x sampling interval), if the usage of each sampling is greater than the overload threshold, this alarm is generated.

Impact on the System

If the disk partition usage is high for a long period of time, services cannot be processed in time, and the system performance is affected.

The system performance, for example, time taken to process user operations, neighbor status, and route convergence performance, will be affected.

Possible Causes

The disk partition usage exceeded the pre-set overload threshold.

Procedure

1. Run the display disk partition command to check the disk partition usage and overload threshold.

  • If the disk partition usage is higher than the overload threshold, go to Step 2.
  • If the disk partition usage is lower than the overload threshold, go to Step 3.

2. Delete unnecessary services and configurations to reduce the disk partition usage. Then, check whether the alarm is cleared.

  • If the alarm is no longer generated, the problem is resolved.
  • If the alarm persists, go to Step 3.

3. Collect alarm, log, and configuration information, and contact technical support personnel.
