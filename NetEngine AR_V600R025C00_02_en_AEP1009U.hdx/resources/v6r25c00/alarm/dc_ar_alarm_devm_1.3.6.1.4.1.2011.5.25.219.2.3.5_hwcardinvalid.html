Impact on the System

  • Cause 1: The card failed to be registered.

    The subcard fails, and services are interrupted.

  • Cause 2: The card was powered off.

    The subcard fails, and services are interrupted.

  • Cause 3: The EPLD logic of the card was faulty.

    The subcard fails, and services are interrupted.

  • Cause 6: The current QL firmware version is inconsistent with the software firmware version.

    Subcard firmware upgrade is affected.

Possible Causes

  • Cause 1: The card failed to be registered.
  • Cause 2: The card was powered off.
  • Cause 3: The EPLD logic of the card was faulty.
  • Cause 5: The clock on the card failed.
  • Cause 6: The current QL firmware version is inconsistent with the software firmware version.

Procedure

  • Cause 1: The card failed to be registered.

    1. Remove and then insert the subcard. If the fault persists, go to Step 2.

    2. Replace the faulty subcard. If the fault persists, go to Step 3.

    3. Collect alarm, log, and configuration information, and contact technical support personnel.

  • Cause 2: The card was powered off.

    1. Run the display device power system command to check whether the power is sufficient. If the power is insufficient, go to Step 2. If the power is sufficient, go to Step 3.

    2. Add a power module. If the fault persists, go to Step 3.

    3. Replace the subcard. If the fault persists, go to Step 4.

    4. Collect alarm, log, and configuration information, and contact technical support personnel.

  • Cause 3: The EPLD logic of the card was faulty.

    1. Run the corresponding command to power off the subcard, and then run the corresponding command to power on the subcard. If the fault persists, go to Step 2.

    2. Replace the subcard. If the fault persists, go to Step 3.

    3. Collect alarm, log, and configuration information, and contact technical support personnel.

  • Cause 5: The clock on the card failed.

    1. Power off and then power on the subcard. Check whether the subcard can be registered or whether the alarm is cleared after the subcard is registered.

    • If so, the fault is rectified.
    • If not, go to step 2.

    2. Replace the subcard and check whether the alarm is cleared.

    • If so, the fault is rectified.
    • If not, go to step 3.

    3. Collect alarm, log, and configuration information, and contact technical support personnel.

  • Cause 6: The current QL firmware version is inconsistent with the software firmware version.

    Recovery measures:

    1. Trigger the QL firmware upgrade again and check whether the fault is rectified. If no, go to step 2.

    2. The subcard is reset using a hot patch, and the device is reset using a cold patch.

    3. End.
