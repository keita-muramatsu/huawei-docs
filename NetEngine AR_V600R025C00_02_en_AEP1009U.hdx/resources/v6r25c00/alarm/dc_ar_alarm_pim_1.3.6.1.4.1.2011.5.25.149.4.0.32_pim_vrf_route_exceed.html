Impact on the System

If the number of PIM SM entries reaches the upper limit, new PIM SM entries cannot be created.

Possible Causes

  • Cause 1: New entries were added. As a result, the number of PIM-SM entries in the VPN instance reached the upper limit.
  • Cause 2: Due to a configuration change, the number of PIM-SM entries in the VPN instance reached the upper limit.

Procedure

  • Cause 1: New entries were added. As a result, the number of PIM-SM entries in the VPN instance reached the upper limit.

    1. Collect alarm and configuration information, and contact technical support personnel.

  • Cause 2: Due to a configuration change, the number of PIM-SM entries in the VPN instance reached the upper limit.

    The same as Cause 1.
