Impact on the System

The configured NAC service does not take effect.

Possible Causes

Because the forwarding resources are full, the configured NAC function does not take effect.

Procedure

1. Run the display system tcam resource acl command in the diagnostic view to check whether the device has available ACL resources. If so, collect alarm and configuration information and contact technical support personnel. If not, go to step 2.

2. Clear and reserve ACL resources. For example, delete unnecessary authentication-free rules and server IP addresses configured in the Portal server template. Go to step 3.

3. Disable the failed NAC configuration displayed in the alarm, perform the configuration again, and check whether the configuration takes effect. If the fault persists, collect alarm and configuration information and contact technical support personnel.
