Impact on the System

When the alarm is generated, new entries can still be created, but the specified limit may be reached.

Possible Causes

  • Cause 1: Entry create
  • Cause 2: Configuration change

Procedure

  • Cause 1: Entry create

    1. Run the display igmp interface command to check whether the value of igmp access-limit is set to a small number.

    • If the value of igmp access-limit is set to a small number, go to Step 2.
    • If the value of igmp access-limit is not set to a small number, go to Step 3.

    2. Run the igmp access-limit command to adjust the entry limit and check whether the fault is rectified.

    • If the fault is rectified, go to Step 4.
    • If the fault is not rectified, go to Step 3.

    3. Collect alarm information and configuration information, and then contact technical support personnel.

    4. End.

  • Cause 2: Configuration change

    The same as Cause 1.
