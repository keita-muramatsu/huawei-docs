OSPF_1.3.6.1.2.1.14.16.2.7 ospfVirtIfAuthFailure

Trap Buffer Description

A packet is received on a virtual interface from a router whose authentication key or authentication type conflicts with the local authentication key or authentication type. (VirtIfAreaId=[VirtIfAreaId], VirtIfNeighbor=[VirtIfNeighbor], ProcessId=[ProcessId], RouterId=[RouterId], ConfigErrorType=[ConfigErrorType], PacketType=[PacketType], InstanceName=[InstanceName])

The virtual interface authentication failed.

Impact on the System

This trap message is generated after the virtual link interface receives a packet indicating authentication parameters are incorrectly configured.

Possible Causes

The virtual interface authentication failed.

Procedure

1. Run the display current-configuration configuration ospf command to check whether the virtual link authentication configurations on both ends are consistent.

  • If the authentication configurations are consistent, go to Step 4.
  • If the authentication configurations are inconsistent, go to Step 2.

2. Perform the following operations based on the networking:

  • If the configurations on both ends can be changed to be consistent, go to Step 3.
  • If the configurations on both ends cannot be changed to be consistent, go to Step 4.

3. If plaintext authentication is configured, change the authentication passwords to be the consistent. If ciphertext authentication is configured, reconfigure the authentication on both ends as required. Check whether the alarm is cleared.

  • If the alarm is cleared, go to Step 5.
  • If the alarm persists, go to Step 4.

4. Collect alarm, log, and configuration information about the device, and contact technical support engineers.

5. End.
