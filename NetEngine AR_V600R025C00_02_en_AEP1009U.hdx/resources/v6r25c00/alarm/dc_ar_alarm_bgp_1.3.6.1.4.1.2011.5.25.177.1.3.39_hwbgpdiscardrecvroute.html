Impact on the System

BGP services are interrupted.

Possible Causes

BGP discard received routes.

Procedure

1. Check the cause for route discarding in the alarm.

  • If the cause is "System memory exceed", go to Step 2.
  • If the cause is not "System memory exceed", go to Step 5.

2. Check the memory usage.

  • If the memory usage of the process where the BGP component resides is high, go to Step 3.
  • If the memory usage of the process where the BGP component resides is low, go to Step 5.

3. Check whether BGP memory change messages exist in diagnostic logs.

  • If the diagnostic logs include a message that the SSP component sends to the device to notify that the BNM component's memory usage ranks in the top 3, go to Step 4.
  • If the preceding message does not exist, go to Step 5.

4. Delete the services and configurations that BGP does not need in order to reduce memory usage. Then, check whether the alarm is cleared.

  • If the alarm is cleared, the problem is resolved.
  • If the alarm persists, go to Step 5.

5. Collect alarm and configuration information, and contact technical support personnel.
