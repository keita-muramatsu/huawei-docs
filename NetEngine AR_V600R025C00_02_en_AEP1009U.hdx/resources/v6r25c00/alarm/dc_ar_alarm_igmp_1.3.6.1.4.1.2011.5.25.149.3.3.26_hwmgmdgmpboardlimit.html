IGMP_1.3.6.1.4.1.2011.5.25.149.3.3.26 hwMgmdGMPBoardLimit

Trap Buffer Description

Membership report message is discarded because the IGMP or MLD group membership limitation on the board is exceeded. (AddressFamily=[AddressFamily], SlotName=[SlotName], LimitCount=[LimitCount])

The IGMP/MLD Report message was discarded because the number of IGMP/MLD group memberships exceeded the upper limit.
