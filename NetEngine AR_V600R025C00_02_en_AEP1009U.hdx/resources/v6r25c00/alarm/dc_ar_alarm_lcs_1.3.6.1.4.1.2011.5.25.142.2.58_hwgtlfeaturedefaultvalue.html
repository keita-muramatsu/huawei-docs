Impact on the System

  • Cause 0: License file expires.

    After the license file expires, all the control items activated by the license are restored to the default values.

  • Cause 1: License file has been revoked.

    After the license file expires, all the control items activated by the license are restored to the default values.

  • Cause 2: ESN mismatches.

    After the license file expires, all the control items activated by the license are restored to the default values.

  • Cause 3: The specified license feature expires.

    After the license expires, the control items of the license are restored to the default values.

Possible Causes

  • Cause 0: License file expires.
  • Cause 1: License file has been revoked.
  • Cause 2: ESN mismatches.
  • Cause 3: The specified license feature expires.

Procedure

1. Apply for a new valid license file from Huawei. For details, see the License Usage Guide of the corresponding product.

2. Upload the license file to the device.

3. Run the license active <filename> command in the user view to activate the license file.
