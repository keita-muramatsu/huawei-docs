Impact on the System

WLAN services will be interrupted after a period of time. This alarm is generated only on the AC in cloud management scenarios.

Possible Causes

1.The AC fails to be managed by iMaster NCE-Campus.

2.The license expires.

3.License resources do not exist.

Procedure

1. Check the network and check whether the AC communicates with iMaster NCE-Campus properly and is online.

If so, go to Step 2.

If not, check the configuration used by the AC to register with iMaster NCE-Campus and ensure that the AC is online.

2. Check the expiration time of the license.

Run the display cloud license command and check the value of the Expire time field of the corresponding AP type in the command output.

If the value is -, the corresponding license resource does not exist. Go to Step 3.

If the license has expired, purchase a new license and load it on iMaster NCE-Campus.

If the licence is within the validity period, contact technical support.

3. Check whether any AP of the corresponding type needs to be managed.

If so, purchase a license and load it on iMaster NCE-Campus.

If not, no action is required.

4. End.
