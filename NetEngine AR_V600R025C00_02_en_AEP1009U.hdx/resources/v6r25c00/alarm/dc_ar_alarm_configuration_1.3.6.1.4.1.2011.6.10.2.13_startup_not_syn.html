CONFIGURATION_1.3.6.1.4.1.2011.6.10.2.13 hwNextStartupFileInconsistent

Trap Buffer Description

The file for next startup on the active main control board is different from that on the standy main control board.

The next startup files of the master and slave main control boards became inconsistent.

This alarm is supported only on AR6700-H series, AR8700 series.

Impact on the System

The current running environment will not be affected.

However, if the device is restarted and a master/slave main control board switchover occurs, some configurations may be lost or not deleted as expected.

Possible Causes

  • Cause 1: The next startup files on the master and slave main control boards were inconsistent.

Procedure

  • Cause 1: The next startup files on the master and slave main control boards were inconsistent.

    1. Run the save [ <configuration-file> ] command to save the configurations to the next startup file.

    2. Check whether the alarm is cleared.

    • If the alarm is cleared, the processing ends.
    • If the alarm persists, go to Step 3.

    3. Collect log information and configuration information, and then contact technical support personnel.
