Impact on the System

The CPU is too busy processing attack packets that some normal packets are not processed in a timely manner or even dropped.

Possible Causes

The number of packets sent from a user (MAC+VLAN) to the CPU exceeded the alarm threshold.

Procedure

Cause 1: The number of packets sent from a user (MAC+VLAN) to the CPU exceeded the alarm threshold.

1. Run the display auto-defend attack-source command to check potential attack sources and determine whether the packet transmission rate is abnormal.

  • If so, go to Step 2.
  • If not, no action is required.

2. Configure a filter for the user in the cpu-defend policy template to prevent the user's packets from being sent to the CPU. Check whether the fault is rectified. If the fault persists or the device does not support the filter function, go to Step 3.

3. Collect alarm, log, and configuration information, and contact technical support personnel.
