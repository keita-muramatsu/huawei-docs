Impact on the System

  • Cause 1: Write protection is triggered for the file system, and the home partition is read-only.

    The file cannot be modified or written.

  • Cause 2: The file system is suspended and cannot be read or written.

    The file cannot be read or written properly.

  • Cause 3: Write protection is triggered for the file system, and the logfile partition is read-only.

    The file cannot be modified or written.

  • Cause 5: The file system is corrupted and the home partition cannot be mounted.

    Files in the original home partition are lost, and the device starts from the standby partition.

  • Cause 6: The MBR partition table of SATA is damaged.

    The system disk cannot mount partitions.

  • Cause 7: Write protection is triggered for the file system, and the system partition is read-only.

    The file cannot be modified or written.

Possible Causes

  • Cause 1: Write protection is triggered for the file system, and the home partition is read-only.
  • Cause 2: The file system is suspended and cannot be read or written.
  • Cause 3: Write protection is triggered for the file system, and the logfile partition is read-only.
  • Cause 5: The file system is corrupted and the home partition cannot be mounted.
  • Cause 6: The MBR partition table of SATA is damaged.
  • Cause 7: Write protection is triggered for the file system, and the system partition is read-only.

Procedure

  • Cause 1: Write protection is triggered for the file system, and the home partition is read-only.

    1. Resetting the System

    2. If the alarm persists after the system is reset, you are advised to back up the data.

  • Cause 2: The file system is suspended and cannot be read or written.

    1. Resetting the System

    2. If the alarm persists after the system is reset, you are advised to back up the data.

  • Cause 3: Write protection is triggered for the file system, and the logfile partition is read-only.

    1. Resetting the System

    2. If the alarm persists after the system is reset, you are advised to back up the data.

  • Cause 5: The file system is corrupted and the home partition cannot be mounted.

    1. Run the format disk partition home command to format the home partition.

    2. If the alarm persists after the home partition is formatted: Collect alarm, log, and configuration information, and contact technical support engineers.

  • Cause 6: The MBR partition table of SATA is damaged.

    1. Resetting the System

    2. If the alarm persists after the system is reset, you are advised to back up the data.

  • Cause 7: Write protection is triggered for the file system, and the system partition is read-only.

    1. Resetting the System

    2. If the alarm persists after the system is reset, you are advised to back up the data.
