Impact on the System

If two routers are configured with the same ID, the router LSA will constantly be updated, which causes route flapping.

Possible Causes

At least two indirectly connected devices in an area have the same router ID. As a result, router LSAs are refreshed frequently, and route flapping occurs.

Procedure

1. Run the ospf [ <process-id> ] router-id <router-id> command to change the router ID of the device and check whether the fault is rectified.

  • If yes, no further action is required.
  • If no, go to Step 2.

2. Collect log and configuration information, and contact technical support personnel.
