Trap Buffer Parameters

Parameter Description

LogIndex

Index of a log.

SrcCmd

Command delivery mode for triggering configuration changes. The options are as follows:

  • 1: command line agent.
  • 2: network configuration protocol agent.
  • 3: SNMP agent.
  • 4: others.

SrcData

Source of the configuration change.

  • 1: Configuration file clearing
  • 2: Saving, deleting, renaming, or moving a configuration file
  • 3: SNMP/CLI/NETCONF configuration operation
  • 4: Configuration restoration
  • 5: FTP upload or download
  • 6: Hot swap.

DestData

Configuration change object.

  • 1: existing startup file specified as the startup file for the next startup
  • 2: running configuration
  • 3: startup configuration file
  • 4: local file, which is not a configuration file
  • 5: FTP
  • 6: hot swap.

TerUser

Terminal user when the configuration changes. When configuration changes are triggered by automatic saving, the user name is displayed as _SYSTEM_.

SrcAddr

Source address.

ConfigChangeId

Sequence number of the configuration change. After the device is restarted in CFG mode, the sequence number in the log is not cleared and will be recorded again in CFG mode.

LogTime

Configuration change time. It refers to the number of ticks since the system is started.

CfgBaselineTime

Baseline time configured on the device. When the configuration changes (for example, the system restarts), the system updates the time.

Impact on the System

Services are not affected.

Possible Causes

Cause 1: The save command is executed to save the configuration file.

Cause 2: The configuration file for next startup is specified.

Cause 3: The configuration file for next startup is cleared.

Procedure

This log is generated when the configuration file is changed. This log is informational only, and no action is required.
