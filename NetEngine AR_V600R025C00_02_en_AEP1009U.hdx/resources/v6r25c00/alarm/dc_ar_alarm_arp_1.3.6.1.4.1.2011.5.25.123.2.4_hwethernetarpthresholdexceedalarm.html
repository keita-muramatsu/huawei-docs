Impact on the System

If this alarm is displayed, the number of ARP entries on the device is great.

If the number continuously increases, system resources become insufficient and no new ARP entries can be learned.

As a result, service interruption may occur.

After the alarm is generated, do not power off or reset the device; otherwise, resources will be reassigned, and services will be affected.

Possible Causes

The number of ARP entries on the device exceeded the upper threshold.

Procedure

1. Run the display arp statistics command to view statistics about ARP entries on the device. Check whether the number of static ARP entries is greater than the number of dynamic ARP entries or vice versa based on the network planning and service deployment.

  • If the number of dynamic ARP entries is greater than the number of static ARP entries, go to Step 2.
  • If the number of static ARP entries is greater than the number of dynamic ARP entries, go to Step 3.

2. Run the display arp command to determine the interfaces that have a large number of ARP entries. For such interfaces, run the display arp interface command to check whether the ARP entries are needed.

  • If the ARP entries are needed, go to Step 5.
  • If some ARP entries are not needed and clearing them does not affect services, run the reset arp all or reset arp interface command to manually clear the ARP entries. Then, go to Step 4.

3. Run the display current-configuration command to check whether the static ARP entries are needed.

  • If the ARP entries are needed, go to Step 5.
  • If some ARP entries are not needed and deleting them does not affect services, run the undo arp static command to delete the specified static ARP entries. Then, go to Step 4.

4. Run the display arp statistics command to check whether the total number of ARP entries on the device keeps increasing.

  • If the total number of ARP entries does not keep increasing, go to Step 6.
  • If the total number of ARP entries keeps increasing, go to Step 5.

5. Collect alarm and configuration information, and contact technical support personnel.

6. End.
