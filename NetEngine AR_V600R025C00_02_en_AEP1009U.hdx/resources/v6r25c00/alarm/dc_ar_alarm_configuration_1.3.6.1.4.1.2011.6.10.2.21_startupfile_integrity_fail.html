Impact on the System

The configuration in the system may be incorrect or unavailable.

Possible Causes

Cause 1: The startup configuration file on the device is modified.

Cause 2: The startup configuration file is from another device.

Procedure

Possible cause 1:

1. Check whether the configuration in the current startup configuration file is correct and available.

  • If the configuration is correct and available, manually clear the alarm.
  • If you are not sure whether the configuration is correct and available, use another configuration file to restart the system or go to step 2.

2. Collect log and configuration information, and contact technical support personnel.

Possible cause 2:

1. Check whether the configuration in the next startup file is correct and available.

  • If you want the configuration of the next startup file to be the same as the current system configuration, run the save command to clear the alarm.
  • If you cannot determine whether the configuration is correct and available, use another configuration file to specify it as the next startup file or go to Step 2.

2. Collect log and configuration information, and contact technical support personnel.

Possible cause 3:

1. Check whether the PAF file for the next startup is correct and available.

  • If the PAF file is correct and available, manually clear the alarm. However, this alarm will be reported in the next detection.
  • If you cannot determine whether the PAF file is correct and available, use another PAF file to specify it as the next startup file or go to Step 2.

2. Collect log and configuration information, and contact technical support personnel.
