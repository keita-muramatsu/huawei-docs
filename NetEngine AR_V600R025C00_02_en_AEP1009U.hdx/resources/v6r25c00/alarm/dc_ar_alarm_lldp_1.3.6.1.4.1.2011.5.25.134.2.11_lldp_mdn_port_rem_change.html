Impact on the System

The system will not be affected.

Possible Causes

Cause 1: An MDN neighbor was added.

Cause 2: The MDN neighbor was deleted.

Cause 3: The number of MDN neighbors reached the upper limit.

Cause 4: The MDN neighbor was aged because the aging time expired.

Procedure

  • Cause 1: An MDN neighbor was added.

1. Check whether a new MDN neighbor is connected.

  • If yes, the alarm is informational only, and no action is required.
  • If not, go to Step 2.

2. Collect log and configuration information, and contact Huawei technical support personnel.

  • Cause 2: The MDN neighbor was deleted.

1. Check whether the MDN neighbor relationship is torn down.

  • If yes, the alarm is informational only, and no action is required.
  • If not, go to Step 2.

2. Check whether the link between the MDN neighbor and the local device is faulty.

  • If so, rectify the fault on the link between the MDN neighbor and the local device.
  • If not, go to Step 3.

3. Collect log and configuration information, and contact Huawei technical support personnel.

  • Cause 3: The number of MDN neighbors reached the upper limit.

1. Check whether the number of MDN neighbors that can be saved on the local device reaches the upper limit.

  • If yes, the alarm is informational only, and no action is required.
  • If not, go to Step 2.

2. Collect log and configuration information, and contact Huawei technical support personnel.

  • Cause 4: The MDN neighbor was aged because the aging time expired.

1. Check whether the MDN neighbor information saved on the local device times out.

  • If yes, the alarm is informational only, and no action is required.
  • If not, go to Step 2.

2. Check whether the interface that directly connects the MDN neighbor to the local device is shut down.

  • If so, run the undo shutdown command on the interface to set the interface to Up.
  • If not, go to Step 3.

3. Check CPU resource consumption to determine whether the link between the MDN neighbor and local device is congested.

  • If yes, disable irrelevant communication traffic to eliminate link congestion.
  • If no, go to Step 4.

4. Collect log and configuration information, and contact Huawei technical support personnel.
