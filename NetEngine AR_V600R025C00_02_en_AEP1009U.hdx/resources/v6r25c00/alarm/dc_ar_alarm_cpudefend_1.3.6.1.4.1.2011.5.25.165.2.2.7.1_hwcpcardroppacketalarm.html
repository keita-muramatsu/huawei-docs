CPUDEFEND_1.3.6.1.4.1.2011.5.25.165.2.2.7.1 hwCpcarDropPacketAlarm

Trap Buffer Description

Rate of packets to cpu exceeded the CPCAR limit in slot [SlotId]. (Protocol=[Protocol], PPS/CBS=[Cir]/[Cbs], ExceededPacketCount=[DropPacketNum])

Packets of the protocol in the specified slot are dropped because the packet rate exceeds the CPCAR values set for the protocol.

Impact on the System

Packets of the protocol in the specified slot are dropped because the packet rate exceeds the CPCAR values set for the protocol.

Possible Causes

The protocol packet rate in the specified slot exceeds the CPCAR values set for the protocol.

Procedure

  • Increase the CPCAR values for the protocol. Check whether the alarm is cleared.
  • Collect alarm, log, and configuration information, and contact technical support personnel.
