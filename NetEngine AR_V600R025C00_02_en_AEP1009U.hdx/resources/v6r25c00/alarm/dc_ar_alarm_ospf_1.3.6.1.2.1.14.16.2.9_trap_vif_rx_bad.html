OSPF_1.3.6.1.2.1.14.16.2.9 ospfVirtIfRxBadPacket

Impact on the System

This alarm is generated when the interface on the virtual link receives an error packet that cannot be processed. The interface discards the packet, which may cause the neighbor to go Down.

Possible Causes

The virtual interface received error packets.

Procedure

1. Run the display ospf error command to check the contents of the error packet. If this alarm is displayed, it indicates that the packet that cannot be parsed is received. In this case, collect the information about the error packet.

2. Collect trap, log, and configuration information, and contact technical support personnel.

3. End.
