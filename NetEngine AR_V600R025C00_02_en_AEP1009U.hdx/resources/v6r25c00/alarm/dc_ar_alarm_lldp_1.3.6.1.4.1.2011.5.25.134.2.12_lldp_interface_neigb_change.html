Impact on the System

The system will not be affected.

Possible Causes

Cause 1: A new neighbor was discovered.

Cause 2: The neighbor relationship was deleted.

Cause 3: A neighbor was aged because the aging period expired.

Procedure

Cause 1: A neighbor was added to the interface.

1. Run the display lldp neighbor command to check whether LLDP is enabled on the new neighbor.

  • If yes, the alarm information is informational only, and no action is required.
  • If no, go to Step 2.

2. Collect log and configuration information, and contact technical support personnel.

Cause 2: The neighbor relationship of the interface was deleted.

1. Run the display lldp neighbor command to check whether LLDP is disabled on the neighbor.

  • If yes, run the lldp enable command in the system view on the neighbor to enable LLDP.
  • If no, go to Step 2.

2. Run the display interface brief command to check whether a link fault occurs between the neighbor and local device.

  • If yes, rectify the link fault between the neighbor and the local device.
  • If no, go to Step 3.

3. Collect log and configuration information, and contact technical support personnel.

Cause 3: The neighbor was aged because the aging time expired.

1. Run the display lldp statistics command to check whether the neighbor node information saved on the local device times out.

  • If yes, the log information is informational only, and no action is required.
  • If no, go to Step 2.

2. Check whether the interface that directly connects the neighbor to the local device is shut down.

  • If yes, run the undo shutdown command on the directly connected interface to set the interface status to Up.
  • If no, go to Step 3.

3. Run the display health command to check the CPU usage and check whether the link between the neighbor and local device is congested.

  • If yes, disable irrelevant communication traffic to eliminate link congestion.
  • If no, go to Step 4.

4. Collect log and configuration information, and contact technical support personnel.
