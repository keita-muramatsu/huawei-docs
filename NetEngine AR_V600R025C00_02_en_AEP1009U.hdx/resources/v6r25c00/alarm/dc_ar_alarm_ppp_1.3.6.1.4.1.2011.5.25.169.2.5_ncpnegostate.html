Impact on the System

When this alarm is generated, IP data packets fail to be forwarded.

Possible Causes

Cause 1: The configuration in the interface is incorrect.

Cause 2: The network quality is bad.

Procedure

Cause 1:

1. Run the display this command in the interface view to check whether the parameter settings of the peer interface are the same as those of the local interface.

  • If they are consistent, go to Step 5.
  • If they are inconsistent, go to Step 2.

2. Modify the configuration to ensure that the parameters of the two interfaces are consistent. Then, check whether the alarm is cleared.

  • If the alarm is cleared, go to Step 6.
  • If the alarm persists, go to Step 3.

3. Check whether the physical link is properly connected.

  • If so, go to Step 5.
  • If not, go to Step 4.

4. Rectify the faulty physical link, and then check whether the alarm is cleared.

  • If the alarm is cleared, go to Step 6.
  • If the alarm persists, go to Step 5.

5. Collect alarm, log, and configuration information, and contact technical support personnel.

6. End.
