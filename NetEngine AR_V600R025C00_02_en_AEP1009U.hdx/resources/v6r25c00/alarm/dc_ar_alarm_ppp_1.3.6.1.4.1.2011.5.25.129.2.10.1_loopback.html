PPP_1.3.6.1.4.1.2011.5.25.129.2.10.1 hwPppLoopbackDetect

Trap Buffer Description

Interface loopback is detected. (IfIndex=[IfIndex], HwBaseTrapSeverity=[HwBaseTrapSeverity], HwBaseTrapProbableCause=[HwBaseTrapProbableCause], HwBaseTrapEventType=[HwBaseTrapEventType], IfName=[IfName])

This alarm indicates that a loop is detected during PPP negotiation.

PPP_1.3.6.1.4.1.2011.5.25.129.2.10.2 hwPppLoopbackDetResume

Trap Buffer Parameters

Index of the interface where the alarm is generated.

Alarm severity.

Possible causes of the alarm.

Event type alarm.

Name of the interface generating the alarm.

VB Parameters

None

Impact on the System

The protocol status of the PPP link cannot go Up.

Possible Causes

Cause 1: There was a loop in the network.

Cause 2: Users configured the loopback { local | remote } command on the interface.

Procedure

Cause 1:

1. Check the networking diagram and physical link connections to see whether a loop exists on the network.

  • If so, go to Step 2.
  • If not, go to Step 3.

2. Adjust the networking diagram and physical link connections to clear loops on the network. Wait for 1 minute and check whether the alarm is generated again.

  • If so, go to Step 3.
  • If not, go to Step 4.

3. Collect alarm, log, and configuration information, and contact technical support personnel.

4. End.

Cause 2:

1. Run the display this command in the interface view to check whether local loopback is configured on the interface.

  • If so, go to Step 3.
  • If not, go to Step 2.

2. Run the display this command in the view of the directly connected interface on the peer device to check whether remote loopback is configured on the interface.

  • If so, go to Step 3.
  • If not, go to Step 4.

3. Run the undo loopback command in the interface view to disable the loopback function on the interface. Wait for 1 minute and check whether the alarm is generated again.

  • If so, go to Step 4.
  • If not, go to Step 5.

4. Collect alarm, log, and configuration information, and contact technical support personnel.

5. End.
