NQA_1.3.6.1.4.1.2011.5.25.111.6.17 nqaJitterStatsOWDThresholdNotificationSD

Trap Buffer Description

The OWD-SD of the NQA entry exceeded the configured threshold. (OwnerIndex=[OwnerIndex], TestName=[TestName], TargetAddressType=[TargetAddressType], TargetAddress=[TargetAddress], Threshold=[Threshold], Index=[Index], RttMax=[RttMax], MaxDelaySD=[MaxDelaySD], MaxDelayDS=[MaxDelayDS], OWDOverThresholdsSD=[OWDOverThresholdsSD])

This trap was generated when the one-way delay from the source to the destination exceeded the threshold and the test instance ended.

Impact on the System

The system will not be affected.

Possible Causes

Cause 1: The threshold was too small.

Cause 2: The network was busy.

Procedure

1. Run the display cpu-usage command in the system view to check whether the CPU is overloaded.

  • If so, go to Step 3.
  • If no, go to Step 2.

2. Run the display this command in the NQA test view to obtain the current threshold. Then run the threshold owd-sd command in the NQA test view to change the threshold as required (20 ms is recommended). Restart the test instance and check whether the alarm is cleared.

  • If yes, go to Step 4.
  • If no, go to Step 3.

3. Collect alarm and configuration information, and contact technical support personnel.

4. End.
