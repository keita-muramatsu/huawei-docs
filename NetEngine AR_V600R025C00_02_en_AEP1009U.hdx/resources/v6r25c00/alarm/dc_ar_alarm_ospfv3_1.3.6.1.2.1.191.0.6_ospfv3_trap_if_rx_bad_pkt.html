OSPFV3_1.3.6.1.2.1.191.0.6 ifrxbadpacket

Trap Buffer Description

An OSPFV3 packet that is received on a non-virtual interface cannot be parsed. (RouterId=[RouterId], IfIndex=[IfIndex], IfInstId=[IfInstId], IfState=[IfState], PacketSrc=[PacketSrc], PacketType=[PacketType])

An OSPFv3 packet that cannot be parsed was received from a non-virtual interface. The possible cause is that the local end was attacked, or the local device was not connected with a non-Huawei device successfully.

Impact on the System

This trap message is generated when a common interface receives a packet that cannot be parsed and discards this packet, which may change the neighbor status to Down.

Possible Causes

An incorrect packet that was sent by the peer non-virtual interface was received.

Procedure

1. Run the display ospfv3 error [ packet ] command to check the error packet content. If this alarm is generated, the device has received an unparsable packet. Record error packet information.

2. Collect log and configuration information, and contact technical support.

3. End.
