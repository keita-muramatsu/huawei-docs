IPSEC_1.3.6.1.4.1.2011.6.122.26.6.9 hwIPSecTunnelreachMax

Trap Buffer Description

Current counts of ipsec tunnel will reach max CPU limit or license limit, please check it.

The number of IPsec tunnels reaches 80% of the maximum number allowed by a single CPU or license.

Impact on the System

If the number of IPsec tunnels reaches the upper limit, new IPsec tunnels cannot be created.

Possible Causes

The number of IPsec tunnels has reached 80% of the license threshold or of the threshold supported by a single CPU.

Procedure

1. Run the display ipsec statistics tunnel-number command to check whether the number of IPsec tunnels is too large.

2. Expand the CPU capacity or apply for a new license in a timely manner.

3. End.
