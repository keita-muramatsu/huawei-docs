ARP_1.3.6.1.4.1.2011.5.25.123.2.38 hwEthernetARPMACMismatch

Trap Buffer Description

The MAC of static ARP set by user is unequal to the actual MAC address. (StaticIP=[StaticIP], VPNInstance=[VPNInstance], StaticMAC=[StaticMAC], DynamicMAC=[DynamicMAC])

The MAC address configured in a static ARP entry is different from the actual MAC address.
