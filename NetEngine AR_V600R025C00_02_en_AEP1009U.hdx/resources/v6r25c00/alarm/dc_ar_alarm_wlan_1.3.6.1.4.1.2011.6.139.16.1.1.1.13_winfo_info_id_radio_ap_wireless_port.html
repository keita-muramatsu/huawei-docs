Impact on the System

Services on the STAs are interrupted.

Possible Causes

  • Cause 0: A radio shutdown command is delivered.
  • Cause 2: An error occurs.
  • Cause 4: Radio calibration is performed.
  • Cause 6: The power consumption is low.
  • Cause 8: The 3GPP base station sends a radio shutdown instruction.

Procedure

  • Cause 0: A radio shutdown command is delivered.

    No action is required.

  • Cause 2: An error occurs.

    Collect alarm, log, and configuration information, and contact technical support personnel.

  • Cause 4: Radio calibration is performed.

    No action is required.

  • Cause 6: The power consumption is low.

    Check whether the power of the PoE switch connected to the AP is sufficient.

  • Cause 8: The 3GPP base station sends a radio shutdown instruction.

    No action is required.
