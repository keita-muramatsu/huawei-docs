Impact on the System

Constant route flapping may occur.

Possible Causes

Two indirectly connected devices in an area were configured with the same IP address, and one of the devices functioned as the DR and advertised network LSAs.

Procedure

1. Check the InterfaceName parameter in the alarm to determine the local interface where the IP address conflict occurs. Then, go to Step 2.

2. Change the local IP address that conflicts with the remote IP address. Then, check whether the conflict is resolved. If the conflict persists, go to Step 4. If you want to change the remote IP address, go to Step 3.

3. Check the interface with the same IP address in the area according to the InterfaceIpAddress in the alarm.

  • If the remote conflicting interface is located, change its IP address. Then, check whether the conflict is resolved. If the conflict persists, go to Step 4. If the conflict is resolved, go to Step 5.
  • If no remote conflicting interface is located, go to Step 4.

4. Collect log and configuration information, and contact technical support.

5. End.
