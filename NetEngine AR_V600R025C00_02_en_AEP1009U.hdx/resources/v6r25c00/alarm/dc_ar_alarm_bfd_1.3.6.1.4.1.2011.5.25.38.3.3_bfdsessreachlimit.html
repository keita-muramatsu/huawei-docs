BFD_1.3.6.1.4.1.2011.5.25.38.3.3 hwBfdSessReachLimit

Trap Buffer Description

The session number in all the IO boards has reached the limit, the new session can not be created. (TotalSessionLimit=[TotalSessionLimit])

The number of established BFD sessions on all boards reached the PAF upper limit, and no more sessions can be established.

Impact on the System

After the number of BFD sessions reaches the upper limit, new BFD sessions cannot be created.

After this alarm is reported, the power-off or reset operation may cause resource reallocation and affect services. Therefore, you are not advised to perform the power-off or reset operation.

Possible Causes

New BFD configurations were still committed when the number of global BFD sessions reached the upper limit.

Procedure

1. Stop configuring a new BFD session.

2. Run the undo bfd <session> command to delete redundant or useless BFD sessions.

3. Collect log and configuration information, and contact technical support personnel.

4. End.
