Impact on the System

After the trap function is enabled, if a large number of BFD sessions flap, the CPU usage will increase. There is no adverse impact on the system.

Possible Causes

Cause 1: The BFD session was successfully created, and the session state changed from Init to Up.

Cause 2: The BFD session was restored using the undo shutdown command, and the session state changed from AdmDown to Up.

Cause 3: The BFD session state changed from Down to Up.

Procedure

This log message is informational only, and no action is required.
