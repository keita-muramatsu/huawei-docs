CONFIGURATION_1.3.6.1.4.1.2011.6.10.2.5 hwCfgB2STransferFail

Trap Buffer Description

Failed to transfer the configuration file to (index=[hwCfgBackupIndex]) server [hwCfgBackupServerIp] through [hwCfgBackupProtocol] when automatically backing up the configuration.

The configuration file fails to be backed up to the server.

Impact on the System

If this alarm is generated multiple times, the configuration may be incorrect or the link may be faulty. As a result, the configuration file cannot be backed up to the server.

Possible Causes

  • The server is unreachable. The password is incorrect. The user name does not exist. The server path does not exist.

Procedure

1. Run the ping command to check whether the server is reachable.

  • If the ping fails, check the routing configurations between the device and the server.
  • If the server can be pinged, go to Step 2.

2. Configure the device as the client and to access the server using ftp or sftp to check whether the password is correct.

  • If the access to the server fails, the password is incorrect. Run the configuration file auto-save backup-to-server command to configure a correct password.
  • If the access to the server succeeds, the password is correct. In this case, go to Step 3.

3. Check the user name configuration on the server.

  • If the user name configuration is incorrect, reconfigure it.
  • If the user name configuration is correct, go to Step 4.

4. Check the path configuration on the server.

  • If the path configuration is incorrect, reconfigure it.
  • If the path configuration is correct, go to Step 5.

5. Collect log and configuration information, and contact technical support.
