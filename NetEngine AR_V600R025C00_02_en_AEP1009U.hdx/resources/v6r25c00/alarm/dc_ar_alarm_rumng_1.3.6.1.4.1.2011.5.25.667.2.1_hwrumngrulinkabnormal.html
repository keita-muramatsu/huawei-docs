Impact on the System

Traffic forwarding between the central device and RUs may be abnormal.

Possible Causes

  • Cause 1: The port connected to the remote unit is not added to the same Eth-Trunk
  • Cause 2: The timeout of receiving XLDPPDU
  • Cause 3: The port link of the remote unit is faulty
  • Cause 4: The ports of the remote unit are connected to different devices
  • Cause 5: XLDP is not enabled on the other interface connected to the RU.

Procedure

  • Cause 1: The port connected to the remote unit is not added to the same Eth-Trunk

    Run the display this interface command to check whether the interconnection interfaces of the central device are added to the same Eth-Trunk. If not, run the trunkport interface-type { interface-number1 [ to interface-number2 ] } &<1-16> [ mode { active | passive } ] command to add the two interfaces to the same Eth-Trunk.

  • Cause 2: The timeout of receiving XLDPPDU

    Run the display xldp statistics command to check the number of sent and received XLDP packets on the interconnection interface of the central device. In the command output, Transmitted frames total indicates the number of sent XLDP packets, and Received frames total indicates the number of received XLDP packets. If the count remains unchanged, XLDP packets are not processed. In this case, check the link status.

  • Cause 3: The port link of the remote unit is faulty

    Run the display this interface command in the interconnection interface view of the central device to check whether the interface is up. If the interface is down, check whether the cable connection or optical module parameters at both ends are consistent.

  • Cause 4: The ports of the remote unit are connected to different devices

    Check the connection between the RU and the central device. Check whether the uplink interfaces of the same RU are connected to different central devices.

  • Cause 5: XLDP is not enabled on the other interface connected to the RU.

    Run the display this command in the interconnection interface view of the central device to check whether XLDP is enabled. If not, run the xldp enable command to enable XLDP.
