Impact on the System

The authentication profile that failed to be bound to the interface cannot take effect.

Possible Causes

Because the forwarding resources are full, the authentication template bound to the port cannot take effect normally.

Procedure

1. Run the display system tcam resource acl command in the diagnostic view to check whether the device has available ACL resources. If so, collect alarm and configuration information and contact technical support personnel. If not, go to step 2.

2. Clear ACL resources and reserve ACL resources for user access configuration and login. For example, reduce the ACLs authorized for user login and disable redundant configurations that occupy ACL resources. Go to step 3.

3. Disable the authentication configuration on the interface, reconfigure the authentication profile, and check whether the configuration takes effect. If the fault persists, collect alarm and configuration information and contact technical support personnel.
