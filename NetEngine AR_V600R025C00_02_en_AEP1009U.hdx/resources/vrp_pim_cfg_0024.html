Understanding PIM-SM BSR Administrative Domains

A PIM-SM network can be divided into multiple BSR administrative domains and a global domain for fine-grained network management. In this way, the management pressure of a single BSR can be effectively reduced, and private group addresses can be used to provide dedicated services for users in a specific domain.

Each BSR administrative domain maintains one BSR, which serves multicast groups within a specific range. The global domain also maintains one BSR, which serves the other multicast groups.

This section describes the relationship between a BSR administrative domain and the global domain in terms of the domain space, multicast group address range, and multicast functions.

  • Domain space: As shown in Figure 1, devices in different BSR administrative domains with the same multicast group addresses do not overlap. One device cannot belong to multiple BSR administrative domains. BSR administrative domains are independent of and isolated from each other. Each BSR administrative domain manages the multicast groups within a specific group address range. Multicast packets within this range can be transmitted only within this administrative domain and cannot cross its boundary.

    The global domain contains all the devices on the PIM-SM network. The multicast packets that do not belong to any BSR administrative domain can be transmitted on the entire PIM network.

    Figure 1 Domain space of BSR administrative domains

  • Multicast group address range: Each BSR administrative domain serves multicast groups within a specific address range. The address ranges of multicast groups served by different BSR administrative domains can overlap. The addresses in the multicast group address range are valid only in the local BSR administrative domain and are equivalent to private multicast group addresses. As shown in Figure 2, the multicast group address range of the domain BSR1 overlaps with that of the domain BSR3. The multicast groups that do not belong to any BSR administrative domain belong to the global domain. That is, the group address range of the global domain is G – G1 – G2.

    Figure 2 Address ranges of BSR administrative domains

  • Multicast functions: As shown in Figure 1, the global domain and each BSR administrative domain have their own C-RP and BSR devices. These devices function only in the local domain. That is, BSR and RP elections in one administrative domain are independent of those in another administrative domain.

    Each BSR administrative domain has a boundary. Multicast information for each BSR administrative domain, such as the C-RP Advertisement message and BSR Bootstrap message information, can be transmitted only within the domain. Multicast messages for the global domain can be transmitted throughout the entire global domain and traverse any BSR administrative domain.
