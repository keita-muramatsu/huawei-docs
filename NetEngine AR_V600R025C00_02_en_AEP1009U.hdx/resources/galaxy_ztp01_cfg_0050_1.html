Example for Configuring Streamlined USB-based Deployment

Networking Requirements

A new network needs to be deployed. DeviceA and DeviceB are two unconfigured devices, and the customer requires that they automatically complete deployment after they are powered on to reduce labor costs and deployment time. Table 1 lists information about DeviceA and DeviceB.

Configuration Roadmap

The configuration roadmap is as follows:

  1. Log in to iMaster NCE-Campus and set parameters for streamlined USB-based deployment. The controller automatically generates the intermediate file USB_AR_V600.INI and deployment configuration file ZTP_V600.INI.
  2. Save the intermediate file USB_AR_V600.INI and deployment configuration file ZTP_V600.INI to the root directory of the USB flash drive.
  3. Insert the USB flash drive into the devices and power them on.

  2. Save the intermediate file USB_AR_V600.INI and deployment configuration file ZTP_V600.INI to the root directory of the USB flash drive.
  3. Insert the USB flash drive to DeviceA and power on the device.
  4. Observe the USB indicator on the device to determine the USB-based deployment progress.
    • Blinking green: USB-based deployment is in progress.
    • Steady green: USB-based deployment succeeds. If there is no deployment configuration file, deployment will be repeatedly performed. In this case, the indicator is also steady green.
    • Steady red: USB-based deployment fails.
    • Off: No USB flash drive is connected, or the indicator fails.
  5. If the USB indicator on DeviceA is steady green, DeviceA is successfully deployed. In this case, remove the USB flash drive and insert it to DeviceB. Then power on DeviceB to start automatic deployment.
