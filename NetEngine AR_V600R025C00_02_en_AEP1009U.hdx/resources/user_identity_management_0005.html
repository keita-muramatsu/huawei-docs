Identity Management Fundamentals

The rising popularity of the mobile office leads to frequently changing user IP addresses. As such, management and control based on users, instead of traditionally based on IP addresses, is required. As shown in Figure 1, the identity management function of the device identifies the source IP addresses of service access traffic as users to control users' resource access permissions.

User authentication here refers to both of the following scenarios: the device functions as an authentication point to authenticate users; the device does not function as an authentication point and directly obtains the authentication result from other authentication systems. Currently, the device can obtain the mappings between users and IP addresses only through TSM SSO and then implement user identity-based policy control.

Figure 1 Basic process of identity management

Figure 1 shows two key factors of identity management:

  1. After a user is authenticated, the device records the mapping between the IP address and user name to the online user table. When the IP address changes, the device needs to re-authenticate the user and update the mapping between the IP address and the user so that the user permissions are dynamically controlled.
  2. The device configures users in policies as matching conditions to implement user-based access control.

The preceding describes the basic process of identity management. In addition to obtaining the user corresponding to the IP address, the device can obtain the organizational structure of the user and control user permissions based on the organizational structure.
