Configuring Automatic Radio Calibration

Context

To enable an AP to transmit and receive radio signals properly, you need to configure radio parameters based on the actual network environment to ensure user experience on the WLAN.

With the radio calibration algorithm, the WAC can automatically adjust basic radio parameters listed in the following table based on the air interface environment data detected by APs.

Item

Description

Operating frequency band

For some AP models, some radios support switching between different frequency bands, but a radio can operate on only one frequency band at a time. You can configure the operating frequency band for AP radios based on the frequency bands supported by STAs.

Operating bandwidth and channel
  • To prevent signal interference and improve WLAN quality, the radio calibration algorithm plans non-overlapping working channels for neighboring APs.
  • Operating channels supported by radios vary depending on country codes. To comply with laws and regulations in local countries or regions, you can configure different operating channels for radios under different country codes. (For details about the channels supported in different countries or regions, see WLAN Country Codes and Channels Compliance.) When automatic radio calibration is used, the radio calibration algorithm automatically plans working channels for APs within the range allowed by laws and regulations based on the country code.

Antenna gain
  • The antenna gain is the ratio of the power density produced by an antenna to the power density that should be obtained at the same point if the power accepted by the antenna is radiated equally. The gain of an antenna can be used to measure the antenna's capability of receiving and sending signals in a specific direction, which is also used for selecting base station antennas. Under the same condition, a higher antenna gain indicates a longer signal propagation distance.
  • The antenna gain of an AP radio configured using the command must be consistent with the gain of the antenna connected to the AP.

Transmit power
  • Configure the transmit power and antenna gain for radios based on the actual network environment, so that radios can provide the required signal strength and improve WLAN signal quality.
  • The maximum transmit power of a radio must comply with local laws and regulations. For details, see WLAN Country Codes and Channels Compliance.

Radio mode

For a triple-radio AP, you can flexibly configure its radio mode based on the application scenario.

  • In large-bandwidth scenarios, the dual-radio mode is recommended. In this mode, an AP can provide high throughput.
  • In high-concurrency scenarios, the triple-radio mode is recommended. In this mode, an AP allows for access of more STAs, improving the WLAN capacity.
  • In high-interference scenarios, the dual-radio + independent scanning radio mode is recommended. In this mode, an AP can use an independent radio to scan the air interface without affecting performance, facilitating WLAN quality monitoring and optimization in real time.
Before radio calibration is triggered, you can configure radio calibration parameters based on the current radio environment to achieve a better calibration effect.
  • Enabling DFS smart selection: When an AP switches its operating channel upon detecting radar signals, it randomly selects a channel (a calibration channel preferentially) allowed by the country code. If the selected channel is the same as or adjacent to the operating channels of surrounding 5 GHz radios, severe interference will occur, deteriorating network access experience. In this case, the DFS smart selection function (enabled by default) allows the AP to switch to a 5 GHz channel with the minimum interference.
  • Configuring the noise floor threshold for triggering radio calibration: This parameter can be used to determine whether the environment noise is normal. When detecting a noise floor value higher than the threshold, an AP reports a high noise floor message to the AC. The AC then performs radio calibration to avoid channels with high noise floor values to improve user experience.
  • Configuring TPC for radio calibration: When radio calibration is enabled, the TPC coverage threshold varies according to the deployment scenario, distance, or height of APs. To ensure the optimal coverage effect, adjust the TPC coverage threshold based on the actual AP deployment situations. A larger threshold indicates a wider transmit power range that can be adjusted through TPC.

    The TPC coverage threshold is the critical value an AP uses during radio calibration to determine whether to adjust its transmit power. Physically, it represents the minimum signal strength of neighboring APs that can be received by an AP.

    This threshold is used to balance coverage and interference control.

    1. RSSI ≥ threshold:

    The AP considers that the current transmit power is too high, which may cause co-channel interference. As such, the AP automatically reduces the transmit power.

    2. RSSI < threshold:

    The AP considers that the coverage is insufficient and properly increases the transmit power to expand the coverage.

    The default value is recommended for coverage testing. Properly configuring this parameter helps achieve an optimal balance of coverage, signal quality, and interference control.

  • Configuring the maximum and minimum transmit power values for radio calibration:

    After radio calibration is enabled, an AP uses the TPC algorithm to calculate the transmit power to be adjusted based on detected neighbor AP information. If the transmit power calculated using the TPC algorithm is too large, signal interference between APs may occur. If the transmit power calculated using the TPC algorithm is too small, radio coverage requirements may not be met.

    You can adjust the maximum and minimum calibration power values using the calibrate max-tx-power and calibrate min-tx-power commands, respectively. This ensures that the valid power after radio calibration is between the two values.

It is recommended that radio calibration be performed during off-peak hours.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Configure the mode for triggering radio calibration.

    # Configure automatic radio calibration.

    calibrate enable auto [ interval interval-value [ start-time start-time ] ]

    # Configure scheduled radio calibration.

    calibrate enable schedule time { time-value | time-range time-range-name }

    By default, the mode for triggering radio calibration is auto, the radio calibration interval is 1440 minutes, and the start time for radio calibration is 03:00:00.

  4. Configure global radio calibration parameters.

    • Configure the radio calibration sensitivity.
      calibrate sensitivity [ 2.4g | 5g | 6g ] { high | medium | low | insensitivity | custom-percent custom-percent }

      By default, the radio calibration sensitivity of the device is medium.

    • Disable the device from considering rogue interference calibration.
      calibrate reference rogue-ap-interference disable

      By default, rogue interference calibration is considered during radio calibration.

  5. Enter the AP group radio view or AP radio view.

    • Enter the AP group radio view.
      ap-group name group-name
radio radio-id
    • Enter the AP radio view.
      ap-id ap-id
radio radio-id

  6. Enable the radio.

    radio enable

    By default, radios of all APs in the AP group radio view are enabled, and the radio state in the AP radio view is the same as that in the AP group radio view.

    A radio can work only after being enabled. When radios of all APs are disabled in the AP group radio view, to enable radios on a single AP in the AP radio view, run the radio enable command in the corresponding AP radio view.

  7. (Optional) Configure the operating frequency band for a radio.

    frequency { 2.4g | 5g | 6g }

    By default, radio 0 in the AP group radio view operates on the 2.4 GHz frequency band, radio 1 on the 5 GHz frequency band, and radios 2, 3, and 4 on the 6 GHz frequency band. If radio 2, 3, or 4 does not support the 6 GHz frequency band, it operates on the default frequency band. There is no default value of the operating frequency band for radios in the AP radio view. The configuration in the AP group radio view is used.

    If the configured frequency band is not supported by an AP, the default frequency band takes effect.

  8. Enable the DCA function.

    calibrate auto-channel-select enable

    By default, the DCA function is enabled on radios in an AP group. If this function is not configured for radios on a single AP, the configuration in the AP group takes effect.

  9. Enable the DBS function.

    calibrate auto-bandwidth-select enable

    By default, the DBS function is disabled on radios in an AP group. If this function is not configured for radios on a single AP, the configuration in the AP group takes effect.

  10. Enable the TPC function.

    calibrate auto-txpower-select enable

    By default, the TPC function is enabled on radios in an AP group. If this function is not configured for radios on a single AP, the configuration in the AP group takes effect.

  11. Configure the antenna gain for the radio.

    antenna-gain antenna-gain

    By default, no antenna gain is configured. The antenna gain of a single AP radio depends on the configuration of the AP group to which the AP radio belongs. The antenna gain of AP group radios depends on the default antenna gain of each AP. The default antenna gain of AP radios depends on AP types and working channels of AP radios. To check the default antenna gains of radios on different AP types, run the display ap-type { id type-id | type ap-type } command.

  12. Configure 3D radio calibration.

    calibrate reference 3d-data enable

    By default, 3D radio calibration is disabled in the AP group radio view but not configured in the AP radio view.

  13. Configure a radio calibration policy.

    return
system-view
wlan
calibrate policy non-wifi

    By default, no radio calibration policy is configured.

    The non-wifi mode is supported only by APs that support spectrum analysis.

  14. (Optional) Enable the inherited calibration function.

    calibrate channel-inherit enable

    By default, inherited calibration is disabled.

    To exclude the radios that meet the network requirements from radio calibration, run this command to enable the inherited calibration function. When the operating channel of a radio meets the current network requirements, the radio retains or inherits the previous calibration result of the radio calibration algorithm. In this way, the operating channel of the radio is not changed during the next radio calibration.

  15. FTM data–based radio calibration take effect only on 5 GHz radios with 80 MHz bandwidth.

  16. Configure the radio mode.
    1. Enter the AP system profile view.

      ap-system-profile name profile-name

    2. Configure the radio mode.

      radio-mode { 2radio-standard | 2radio-2g-enhanced | 2radio-5g-enhanced | 2radio-independent-scan | 3radio | 4radio | 4radio-independent-scan | 5radio }

      By default, no radio mode is configured on an AP, and the default radio mode of the AP is used.

      Switching the radio mode will cause an AP to restart.

      To check the radio modes supported by APs, run the display ap-type command. If the radio mode delivered by the WAC is not supported by an AP, the default mode supported by the AP is delivered.

    3. Return to the WLAN view.

      quit

  17. Configure an RRM profile.
    1. Create an RRM profile and enter its view.

      rrm-profile name profile-name

      By default, the RRM profile default exists in the system.

    2. (Optional) Configure the transmit power range for radio calibration.

      calibrate max-tx-power { 2g-power | radio-5g 5g-power | radio-6g 6g-power }
calibrate min-tx-power { 2g-power | radio-5g 5g-power | radio-6g 6g-power }

      By default, the maximum power is 127 dBm, and the minimum power is 9 dBm for a 2.4 GHz radio or 12 dBm for a 5 GHz radio or 6 GHz radio.

    3. (Optional) Enable DFS smart selection.

      undo dfs smart-selection disable

      By default, the DFS smart selection function is enabled.

    4. (Optional) Configure the delay in switching back the DFS channel.

      dfs recover-delay recover-delay-interval

      By default, the delay in switching back the DFS channel is 0 minutes. That is, the channel is switched back to the manually planned channel when the legitimate aging time (30 minutes) expires.

    5. (Optional) Configure the TPC coverage threshold.

      calibrate tpc threshold threshold

      The default TPC coverage threshold is –60 dBm.

    6. (Optional) Configure the interference threshold of a calibration group.

      calibrate grouping interference-threshold threshold

      The default interference threshold of a calibration group is –127 dBm.

    7. (Optional) Configure the noise floor threshold for triggering radio calibration.

      calibrate noise-floor-threshold threshold

      The default noise floor threshold for triggering radio calibration is –75 dBm.

    8. Return to the WLAN view.

      quit

  18. Create a radio profile and enter its view.

    • Create a 2.4 GHz radio profile and enter its view.
      radio-2g-profile name profile-name

      By default, the 2.4 GHz radio profile default exists in the system.

    • Create a 5 GHz radio profile and enter its view.
      radio-5g-profile name profile-name

      By default, the 5 GHz radio profile default exists in the system.

  19. Bind the RRM profile.

    rrm-profile profile-name

    By default, the RRM profile default is bound to a radio profile.
