Example for Configuring USB-based Deployment (Configured Device Scenario)

Networking Requirements

A new network needs to be deployed. DeviceA has been configured, and the customer requires that it automatically completes upgrade after it is powered on to reduce labor costs and deployment time. The system software software_file.cc is required for upgrading DeviceA.

Configuration Roadmap

The configuration roadmap is as follows:

  1. Make the intermediate file usb.ini to enable the device to obtain its system software according to the intermediate file.
  2. Save the intermediate file to the root directory of the USB flash drive and system software to the directory specified by the DIRECTORY field in the intermediate file.
  3. Power on the device and enable USB-based deployment.
  4. Insert the USB flash drive into the device to complete the deployment process.

Precautions

The file system format of a USB flash drive must be FAT32 or EXT4, and its port must support USB 2.0 or later.

The following uses Windows as an example to describe how to check the file system format of a USB flash drive:

  • After inserting the USB flash drive, open This PC, right-click the USB flash drive, and choose Properties from the shortcut menu.
  • In the displayed dialog box, check File system, which indicates the format of the USB flash drive.

If the file system format of the USB flash drive does not meet the requirements, perform the following steps to change the file system format of the USB flash drive to FAT32:

  • After inserting the USB flash drive, open This PC, right-click the USB flash drive, and choose Format from the shortcut menu.
  • In the dialog box that is displayed, set File system to FAT32, select Quick format, and click OK.

Procedure

  1. Make the intermediate file usb.ini according to the file format requirements in Intermediate File in the INI Format. The file format is as follows:

    ;BEGIN USB
[GLOBAL CONFIG]
*TIME_SN=20200526120159
*DEVICE_TYPE_NUM=1

[DEVICE_TYPE_1 DESCRIPTION]
DEVICE_TYPE=
ESN=
MAC=
UNAME=
VRPVER=
SPACE_CLEAR=
DIRECTORY=
ACTIVE_DELAYTIME=
ACTIVE_INTIME=
*FILETYPENUM=1
*FILENAME_1=software_file.cc
*TYPE_1=SOFTWARE
*EFFECTIVE_MODE_1=0
ISBATCHPROCESS_1=
SHA256_1=
HMAC_1=
COMPRESS_ENCRYTION_1=
;END USB CONFIG

  2. Save the intermediate file and system software to the root directory of the USB flash drive.
  3. Power on the device and enable USB-based deployment.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] ztp usb-deployment enable

  4. Insert the USB flash drive into DeviceA.
  5. Observe the USB indicator on the device to determine the USB-based deployment progress.
    • Blinking green: USB-based deployment is in progress.
    • Steady green: USB-based deployment succeeds. If there is no deployment configuration file, deployment will be repeatedly performed. In this case, the indicator is also steady green.
    • Steady red: USB-based deployment fails.
    • Off: No USB flash drive is connected, or the indicator fails.
  6. If the USB indicator on DeviceA is steady green, the deployment is complete.
  7. You are advised to disable the USB-based deployment function after the deployment is complete. Otherwise, an unnecessary upgrade will be triggered if a USB flash drive is inserted into the device by mistake, causing service interruption.

    [DeviceA] undo ztp usb-deployment enable
