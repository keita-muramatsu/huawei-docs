Checking Configuration Results

Procedure

  • Check the radio calibration progress.

    display calibrate status

  • Check the global configuration of radio calibration.

    display wlan calibrate global configuration

  • Check the regulatory domain profile configuration.

    # Check a regulatory domain profile.
    display regulatory-domain-profile { all | name profile-name }
    # Check reference information about a regulatory domain profile.
    display references regulatory-domain-profile name profile-name

  • Check the radio profile configuration.

    # Check a 2.4 GHz radio profile.
    display radio-2g-profile { all | name profile-name }
    # Check reference information about a 2.4 GHz radio profile.
    display references radio-2g-profile name profile-name
    # Check a 5 GHz radio profile.
    display radio-5g-profile { all | name profile-name }
    # Check reference information about a 5 GHz radio profile.
    display references radio-5g-profile name profile-name

  • Check the RRM profile configuration.

    # Check an RRM profile.
    display rrm-profile { all | name profile-name }
    # Check reference information about an RRM profile.
    display references rrm-profile name profile-name

  • Check the air scan profile configuration.

    # Check an air scan profile.
    display air-scan-profile { all | name profile-name }
    # Check reference information about an air scan profile.
    display references air-scan-profile name profile-name

  • Check the calibration channels and bandwidth.

    display wlan calibrate channel-set ap-group { name ap-group-name | all }
