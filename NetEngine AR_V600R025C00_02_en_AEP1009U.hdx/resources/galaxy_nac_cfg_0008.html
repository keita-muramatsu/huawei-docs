Default Settings for NAC

Table 1 describes the default settings for NAC.

Table 1 Default settings for NAC

Parameter

Default Setting

MAC access profile

The device has a built-in MAC access profile named mac_access_profile.

This profile can be applied and modified but cannot be deleted.

User name and password of a MAC address authentication user

User names and passwords used for MAC address authentication are MAC addresses without hyphens (-) or colons (:).

802.1X access profile

The device has a built-in 802.1X access profile named dot1x_access_profile.

This profile can be applied and modified but cannot be deleted.

Authentication mode of 802.1X users

The authentication mode of 802.1X users is eap. That is, the Extensible Authentication Protocol (EAP) relay authentication mode is used.

Portal access profile

The device has a built-in Portal access profile named portal_access_profile.

This profile can be applied and modified but cannot be deleted.

Authentication profile

The device has built-in authentication profiles, named default_authen_profile, mac_authen_profile, dot1xmac_authen_profile, portal_authen_profile, multi_authen_profile and dot1x_authen_profile.

These profiles can be applied and modified but cannot be deleted.
