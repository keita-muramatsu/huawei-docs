Configuring Rate Limiting for Multicast Packets on a VAP

Prerequisites

Before performing the configuration, you have completed the following task:
  • Configure AP onboarding and STA access.

Context

When an increasing number of multicast packets are transmitted on a WLAN, more network resources are occupied and services are affected.

To ensure the normal running of WLAN services, you can set the upper threshold of multicast traffic based on the traffic profile. When the traffic volume of multicast packets reaches the threshold, the system discards excess multicast packets to control the traffic volume in a proper range.

Wireless traffic suppression takes effect only for incoming traffic on the AP's air interface.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a traffic profile and enter its view.

    traffic-profile name profile-name

  4. Configure the maximum volume of multicast traffic allowed in the traffic profile.

    traffic-optimize multicast-suppression packets packets-rate

    By default, multicast traffic is not suppressed in a traffic profile.

  5. Bind the traffic profile.

    Bind the traffic profile to an AP group or a single AP so that the configuration in the traffic profile can take effect. For details, see Traffic Profile.

Verifying the Configuration

  • Run the display traffic-profile { all | name profile-name } command to check the rate limiting configuration for multicast packets in a traffic profile.
