Example for Configuring VPN FRR for EVPN L3VPNv6 over SRv6 BE

Networking Requirements

On the network shown in Figure 1:

  • PE1, PE2, and PE3 are in the same AS. IS-IS must be configured on these devices to achieve IPv6 network connectivity.

  • PE1, PE2, and PE3 are Level-2 devices that belong to IS-IS process 1.

A bidirectional SRv6 BE path must be deployed between PE1 and PE2 as well as between PE1 and PE3 to carry EVPN L3VPNv6 services. In addition, to improve network reliability, it is required that VPN FRR be configured on PE1.

Figure 1 Network diagram of VPN FRR for EVPN L3VPNv6 over SRv6 BE

In this example, interface1, interface2, and interface3 represent 10GE0/0/1, 10GE0/0/2, and 10GE0/0/3, respectively.


Precautions

Note the following during the configuration:

  • In VPN FRR scenarios, traffic is switched back to the primary path once it has recovered. Because the time at which nodes undergo IGP convergence differs, packet loss may occur during the switchback. To resolve this problem, run the route-select delay delay-value command to configure a route selection delay so that traffic is switched back only after forwarding entries are updated on the devices along the primary path. The required delay depends on various factors, such as the number of routes on the devices. Set delay-value as needed.

Configuration Roadmap

The configuration roadmap is as follows:

  1. Enable IPv6 forwarding and configure an IPv6 address for each PE interface.

  2. Enable IS-IS, configure an IS-IS level, and specify a network entity title (NET) on each PE.

  3. Configure an IPv6 VPN instance on each PE, and connect each PE to a CE.

  4. Establish an EBGP peer relationship between each PE and its connected CE.

  5. Establish a BGP EVPN peer relationship between PE1 and PE2 and another one between PE1 and PE3.

  6. Configure SRv6 on each PE, and enable IS-IS SRv6.

  7. Enable VPN FRR on PE1 and configure BFD to detect peer locator reachability and speed up VPN FRR switching.

Procedure

  1. Enable IPv6 forwarding and configure an IPv6 address for each interface. The following example uses the configuration of PE1. The configurations of other devices are similar to the configuration of PE1.

    <HUAWEI> system-view
[HUAWEI] sysname PE1
[PE1] interface 10GE 0/0/1
[PE1-10GE0/0/1] ipv6 enable
[PE1-10GE0/0/1] ipv6 address 2001:db8:10::1 96
[PE1-10GE0/0/1] quit
[PE1] interface 10GE 0/0/2
[PE1-10GE0/0/2] ipv6 enable
[PE1-10GE0/0/2] ipv6 address 2001:db8:30::1 96
[PE1-10GE0/0/2] quit
[PE1] interface LoopBack 1
[PE1-LoopBack1] ipv6 enable
[PE1-LoopBack1] ipv6 address 2001:db8:1::1 128
[PE1-LoopBack1] quit

  2. Configure IS-IS.

    # Configure PE1.

    [PE1] isis 1
[PE1-isis-1] is-level level-2
[PE1-isis-1] cost-style wide
[PE1-isis-1] network-entity 10.0000.0000.0001.00
[PE1-isis-1] ipv6 enable topology ipv6
[PE1-isis-1] quit
[PE1] interface 10GE 0/0/1
[PE1-10GE0/0/1] isis ipv6 enable 1
[PE1-10GE0/0/1] quit
[PE1] interface 10GE 0/0/2
[PE1-10GE0/0/2] isis ipv6 enable 1
[PE1-10GE0/0/2] quit
[PE1] interface loopback1
[PE1-LoopBack1] isis ipv6 enable 1
[PE1-LoopBack1] quit

    # Configure PE2.

    [PE2] isis 1
[PE2-isis-1] is-level level-2
[PE2-isis-1] cost-style wide
[PE2-isis-1] network-entity 10.0000.0000.0002.00
[PE2-isis-1] ipv6 enable topology ipv6
[PE2-isis-1] quit
[PE2] interface 10GE 0/0/1
[PE2-10GE0/0/1] isis ipv6 enable 1
[PE2-10GE0/0/1] quit
[PE2] interface loopback1
[PE2-LoopBack1] isis ipv6 enable 1
[PE2-LoopBack1] quit

    # Configure PE3.

    [PE3] isis 1
[PE3-isis-1] is-level level-2
[PE3-isis-1] cost-style wide
[PE3-isis-1] network-entity 10.0000.0000.0004.00
[PE3-isis-1] ipv6 enable topology ipv6
[PE3-isis-1] quit
[PE3] interface 10GE 0/0/1
[PE3-10GE0/0/1] isis ipv6 enable 1
[PE3-10GE0/0/1] quit
[PE3] interface loopback1
[PE3-LoopBack1] isis ipv6 enable 1
[PE3-LoopBack1] quit

  3. Configure an IPv6 L3VPN instance on each PE and bind it to an access-side interface.

    # Configure PE1.

    [PE1] ip vpn-instance vpna
[PE1-vpn-instance-vpna] ipv6-family
[PE1-vpn-instance-vpna-af-ipv6] route-distinguisher 100:1
[PE1-vpn-instance-vpna-af-ipv6] vpn-target 111:1 evpn
[PE1-vpn-instance-vpna-af-ipv6] quit
[PE1-vpn-instance-vpna] quit
[PE1] interface 10GE 0/0/3
[PE1-10GE0/0/3] ip binding vpn-instance vpna

[PE1-10GE0/0/3] ipv6 address 2001:DB8:11::1 64
[PE1-10GE0/0/3] quit

    # Configure PE2.

    [PE2] ip vpn-instance vpna
[PE2-vpn-instance-vpna] ipv6-family
[PE2-vpn-instance-vpna-af-ipv6] route-distinguisher 200:1
[PE2-vpn-instance-vpna-af-ipv6] vpn-target 111:1 evpn
[PE2-vpn-instance-vpna-af-ipv6] quit
[PE2-vpn-instance-vpna] quit
[PE2] interface 10GE 0/0/2
[PE2-10GE0/0/2] ip binding vpn-instance vpna
[PE2-10GE0/0/2] ipv6 enable
[PE2-10GE0/0/2] ipv6 address 2001:DB8:22::1 64
[PE2-10GE0/0/2] quit

    # Configure PE3.

    [PE3] ip vpn-instance vpna
[PE3-vpn-instance-vpna] ipv6-family
[PE3-vpn-instance-vpna-af-ipv6] route-distinguisher 300:1
[PE3-vpn-instance-vpna-af-ipv6] vpn-target 111:1 evpn
[PE3-vpn-instance-vpna-af-ipv6] quit
[PE3-vpn-instance-vpna] quit
[PE3] interface 10GE 0/0/2
[PE3-10GE0/0/2] ip binding vpn-instance vpna
[PE3-10GE0/0/2] ipv6 enable
[PE3-10GE0/0/2] ipv6 address 2001:DB8:33::1 64
[PE3-10GE0/0/2] quit

  4. Establish an EBGP peer relationship between each PE and its connected CE.

    # Configure CE1.

    [CE1] interface LoopBack1
[CE1-LoopBack1] ipv6 enable
[CE1-LoopBack1] ipv6 address 2001:DB8:111::1 128
[CE1-LoopBack1] quit               
[CE1] bgp 65410   
[CE1-bgp] router-id 10.11.1.1    
[CE1-bgp] peer 2001:DB8:11::1 as-number 100
[CE1-bgp] ipv6-family unicast
[CE1-bgp-af-ipv6] import-route direct
[CE1-bgp-af-ipv6] peer 2001:DB8:11::1 enable
[CE1-bgp-af-ipv6] quit
[CE1-bgp] quit

    # Configure PE1.

    [PE1] bgp 100
[PE1-bgp] router-id 1.1.1.1
[PE1-bgp] ipv6-family vpn-instance vpna
[PE1-bgp-6-vpna] peer 2001:DB8:11::2 as-number 65410
[PE1-bgp-6-vpna] import-route direct
[PE1-bgp-6-vpna] quit
[PE1-bgp] quit

    # Configure CE2.

    [CE2] interface LoopBack1
[CE2-LoopBack1] ipv6 enable
[CE2-LoopBack1] ipv6 address 2001:DB8:222::2 128
[CE2-LoopBack1] quit               
[CE2] bgp 65420   
[CE2-bgp] router-id 10.12.1.1    
[CE2-bgp] peer 2001:DB8:22::1 as-number 100
[CE2-bgp] peer 2001:DB8:33::1 as-number 100
[CE2-bgp] ipv6-family unicast
[CE2-bgp-af-ipv6] import-route direct
[CE2-bgp-af-ipv6] peer 2001:DB8:22::1 enable
[CE2-bgp-af-ipv6] peer 2001:DB8:33::1 enable
[CE2-bgp-af-ipv6] quit
[CE2-bgp] quit

    # Configure PE2.

    [PE2] bgp 100
[PE2-bgp] router-id 2.2.2.2
[PE2-bgp] ipv6-family vpn-instance vpna
[PE2-bgp-6-vpna] peer 2001:DB8:22::2 as-number 65420
[PE2-bgp-6-vpna] import-route direct
[PE2-bgp-6-vpna] quit
[PE2-bgp] quit

    # Configure PE3.

    [PE3] bgp 100
[PE3-bgp] router-id 3.3.3.3
[PE3-bgp] ipv6-family vpn-instance vpna
[PE3-bgp-6-vpna] peer 2001:DB8:33::2 as-number 65420
[PE3-bgp-6-vpna] import-route direct
[PE3-bgp-6-vpna] quit
[PE3-bgp] quit

If the Established state is displayed in the command output, the BGP peer relationship has been established successfully.

  5. Establish a BGP EVPN peer relationship between PE1 and PE2 and another one between PE1 and PE3.

    # Configure PE1.

    [PE1] bgp 100
[PE1-bgp] peer 2001:DB8:2::2 as-number 100
[PE1-bgp] peer 2001:DB8:2::2 connect-interface loopback 1
[PE1-bgp] peer 2001:DB8:3::3 as-number 100
[PE1-bgp] peer 2001:DB8:3::3 connect-interface loopback 1
[PE1-bgp] l2vpn-family evpn
[PE1-bgp-af-evpn] peer 2001:DB8:2::2 enable
[PE1-bgp-af-evpn] peer 2001:DB8:3::3 enable
[PE1-bgp-af-evpn] quit
[PE1-bgp] quit

    # Configure PE2.

    [PE2] bgp 100
[PE2-bgp] peer 2001:DB8:1::1 as-number 100
[PE2-bgp] peer 2001:DB8:1::1 connect-interface loopback 1
[PE2-bgp] l2vpn-family evpn
[PE2-bgp-af-evpn] peer 2001:DB8:1::1 enable
[PE2-bgp-af-evpn] quit
[PE2-bgp] quit

    # Configure PE3.

    [PE3] bgp 100
[PE3-bgp] peer 2001:DB8:1::1 as-number 100
[PE3-bgp] peer 2001:DB8:1::1 connect-interface loopback 1
[PE3-bgp] l2vpn-family evpn
[PE3-bgp-af-evpn] peer 2001:DB8:1::1 enable
[PE3-bgp-af-evpn] quit
[PE3-bgp] quit

  6. Establish an SRv6 BE path between PE1 and PE2 and another one between PE1 and PE3.

    # Configure PE1.

    [PE1] segment-routing ipv6
[PE1-segment-routing-ipv6] encapsulation source-address 2001:DB8:1::1
[PE1-segment-routing-ipv6] locator as1 ipv6-prefix 2001:DB8:110:: 64 static 32
[PE1-segment-routing-ipv6-locator] quit
[PE1-segment-routing-ipv6] quit
[PE1] isis 1
[PE1-isis-1] segment-routing ipv6 locator as1 auto-sid-disable
[PE1-isis-1] quit
[PE1] bgp 100
[PE1-bgp] l2vpn-family evpn
[PE1-bgp-af-evpn] peer 2001:DB8:2::2 advertise encap-type srv6
[PE1-bgp-af-evpn] peer 2001:DB8:3::3 advertise encap-type srv6
[PE1-bgp-af-evpn] quit
[PE1-bgp] ipv6-family vpn-instance vpna
[PE1-bgp-6-vpna] advertise l2vpn evpn
[PE1-bgp-6-vpna] segment-routing ipv6 locator as1 evpn
[PE1-bgp-6-vpna] segment-routing ipv6 best-effort evpn
[PE1-bgp-6-vpna] quit
[PE1-bgp] quit

    # Configure PE2.

    [PE2] segment-routing ipv6
[PE2-segment-routing-ipv6] encapsulation source-address 2001:DB8:2::2
[PE2-segment-routing-ipv6] locator as1 ipv6-prefix 2001:DB8:120:: 64 static 32
[PE2-segment-routing-ipv6-locator] quit
[PE2-segment-routing-ipv6] quit
[PE2] isis 1
[PE2-isis-1] segment-routing ipv6 locator as1 auto-sid-disable
[PE2-isis-1] quit
[PE2] bgp 100
[PE2-bgp] l2vpn-family evpn
[PE2-bgp-af-evpn] peer 2001:DB8:1::1 advertise encap-type srv6
[PE2-bgp-af-evpn] quit
[PE2-bgp] ipv6-family vpn-instance vpna
[PE2-bgp-6-vpna] advertise l2vpn evpn
[PE2-bgp-6-vpna] segment-routing ipv6 locator as1 evpn
[PE2-bgp-6-vpna] segment-routing ipv6 best-effort evpn
[PE2-bgp-6-vpna] quit
[PE2-bgp] quit

    # Configure PE3.

    [PE3] segment-routing ipv6
[PE3-segment-routing-ipv6] encapsulation source-address 2001:DB8:3::3
[PE3-segment-routing-ipv6] locator as1 ipv6-prefix 2001:DB8:130:: 64 static 32
[PE3-segment-routing-ipv6-locator] quit
[PE3-segment-routing-ipv6] quit
[PE3] isis 1
[PE3-isis-1] segment-routing ipv6 locator as1 auto-sid-disable
[PE3-isis-1] quit
[PE3] bgp 100
[PE3-bgp] l2vpn-family evpn
[PE3-bgp-af-evpn] peer 2001:DB8:1::1 advertise encap-type srv6

[PE3-bgp-6-vpna] advertise l2vpn evpn
[PE3-bgp-6-vpna] segment-routing ipv6 locator as1 evpn
[PE3-bgp-6-vpna] segment-routing ipv6 best-effort evpn
[PE3-bgp-6-vpna] quit
[PE3-bgp] quit

  7. Configure VPN FRR.

    Configure VPN FRR and use BFD to detect locator route reachability. If the specified locator route is unreachable, VPN FRR is performed, triggering traffic switching.

    # Configure PE1.

    [PE1] ip vpn-instance vpna
[PE1-vpn-instance-vpna] ipv6-family
[PE1-vpn-instance-vpna-af-ipv6] vpn frr
[PE1-vpn-instance-vpna-af-ipv6] quit
[PE1-vpn-instance-vpna] quit
[PE1] bgp 100
[PE1-bgp] ipv6-family vpn-instance vpna
[PE1-bgp-6-vpna] route-select delay 300
[PE1-bgp-6-vpna] quit
[PE1-bgp] quit
[PE1] bfd
[PE1-bfd] quit
[PE1] bfd pe1tope2 bind peer-ipv6 2001:DB8:120::
[PE1-bfd-session-pe1tope2] discriminator local 100
[PE1-bfd-session-pe1tope2] discriminator remote 200
[PE1-bfd-session-pe1tope2] quit

    # Configure PE2.

    [PE2] bfd
[PE2-bfd] quit
[PE2] bfd pe2tope1 bind peer-ipv6 2001:DB8:110::
[PE2-bfd-session-pe2tope1] discriminator local 200
[PE2-bfd-session-pe2tope1] discriminator remote 100
[PE2-bfd-session-pe2tope1] quit
