Default Settings for Signature Database Update

Table 1 describes the default settings for signature database update.

Table 1 Default settings for signature database update

Parameter

Default Setting

Connection parameters for online signature database update
  • Domain name of the Huawei intelligent security center: sec.huawei.com
  • Protocol type: HTTPS (cannot be changed)
  • Port number: 443
  • The device uses the initial CA certificate to communicate with the Huawei intelligent security center.

Automatic online signature database update

Automatic online update is enabled for the IPS and antivirus signature databases. Automatic online update is disabled for the SA signature database.

Default interval for automatic online signature database update

The device randomly selects a time from 00:00 to 07:59 as the scheduled time for updating all signature databases every day.
