Configuring a Device to Add Option 82 to DHCP Messages

Prerequisites

STA address learning has been enabled on the device using the undo learn-client-address { ipv4 | ipv6 } disable command.

Context

After going online, a STA obtains an IP address through DHCP. When the DHCP Request message from the STA reaches an AP, the AP adds the Option 82 field to the message and sends the message to the DHCP server. The Option 82 field carries the MAC address of the associated AP. Therefore, the DHCP server knows the AP on which the STA goes online.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a VAP profile view and enter its view.

    vap-profile name profile-name

  4. Enable an AP to add the Option 82 field to DHCP messages sent from STAs.

    dhcp option82 insert enable

    By default, the function of adding the Option 82 field to DHCP messages sent from STAs is disabled.

  5. Configure the format of the Option 82 field added to DHCP messages sent from STAs.

    dhcp option82 { circuit-id | remote-id } format ap-mac [ mac-format { normal | compact | hex | colon } ] [ user-defined user-defined-text ]
dhcp option82 { circuit-id | remote-id } format ap-mac-ssid [ mac-format { normal | compact | colon } ] [ user-defined user-defined-text ]
dhcp option82 { circuit-id | remote-id } format { ap-name | ap-name-ssid | ap-location | ap-location-ssid } [ user-defined user-defined-text ]
dhcp option82 { circuit-id | remote-id } format user-defined user-defined-text

    By default, the format of the Option 82 field added to DHCP messages sent from STAs is ap-mac.

  6. Configure the field separator for Option 82 in DHCP messages sent from STAs.

    dhcp option82 { circuit-id | remote-id } pattern semicolon

    By default, the colon (:) is used as the field delimiter for Option 82 in DHCP messages sent from STAs.
