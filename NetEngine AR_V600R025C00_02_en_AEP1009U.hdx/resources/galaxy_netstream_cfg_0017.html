Verifying the Configuration

Procedure

  • Run the display netstream cache ip origin [ [ top top-value [ sort-by { bytes | packets } ] ] | [ { inbound | outbound } | source interface { interface-name | interface-type interface-number } | source port port-number | source ip ip-address | destination interface { dst-interface-name | dst-interface-type dst-interface-number } | destination port dst-port-number | destination ip dst-ip-address | tos tos-num | protocol protocol-num | start-time start-time | end-time end-time ] * ] slot slot-id [ verbose ] command to check detailed IPv4 original flow statistics.

    You need to run this command before the statistics age out. Otherwise, no information is displayed in the command output.

  • Run the display netstream cache ipv6 origin [ [ top top-value [ sort-by { bytes | packets } ] ] | [ { inbound | outbound } | source interface { interface-name | interface-type interface-number } | source port port-number | source ipv6 ipv6-address | destination interface { dst-interface-name | dst-interface-type dst-interface-number } | destination port dst-port-number | destination ipv6 dst-ipv6-address | tos tos-num | protocol protocol-num | flowlabel flowlabel-num | start-time start-time | end-time end-time ] * ] slot slot-id [ verbose ] command to check detailed IPv6 original flow statistics.

    You need to run this command before the statistics age out. Otherwise, no information is displayed in the command output.

  • Run the display netstream cache ip record record-name [ [ top top-value [ sort-by { bytes | packets } ] ] | [ { inbound | outbound } | source interface { interface-name | interface-type interface-number } | source port port-number | source ip ip-address | destination interface { dst-interface-name | dst-interface-type dst-interface-number } | destination port dst-port-number | destination ip dst-ip-address | tos tos-num | protocol protocol-num | start-time start-time | end-time end-time ] * ] slot slot-id [ verbose ] command to check detailed IPv4 flexible flow statistics.

    You need to run this command before the statistics age out. Otherwise, no information is displayed in the command output.

  • Run the display netstream cache ipv6 record record-name [ [ top top-value [ sort-by { bytes | packets } ] ] | [ { inbound | outbound } | source interface { interface-name | interface-type interface-number } | source port port-number | source ipv6 ipv6-address | destination interface { dst-interface-name | dst-interface-type dst-interface-number } | destination port dst-port-number | destination ipv6 dst-ipv6-address | tos tos-num | protocol protocol-num | flowlabel flowlabel-num | start-time start-time | end-time end-time ] * ] slot slot-id [ verbose ] command to check detailed IPv6 flexible flow statistics.

    You need to run this command before the statistics age out. Otherwise, no information is displayed in the command output.

  • Run the display netstream statistics { ip | ipv6 } slot slot-id command to check flow statistics.
  • Run the display netstream { all | global | interface { interface-name | interface-type interface-number } } command to check the NetStream configuration.
