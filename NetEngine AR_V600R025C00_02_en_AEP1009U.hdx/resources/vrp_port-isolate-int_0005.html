Example for Enabling Layer 2 Port Isolation

Networking Requirements

In Figure 1, PC1, PC2, and PC3 all belong to VLAN 10. PC1 and PC2 are allowed to communicate with PC3, but are not allowed to communicate with each other.

Figure 1 Network diagram for enabling Layer 2 port isolation

In this example, interface 1, interface 2, and interface 3 represent 10GE 0/0/1, 10GE 0/0/2, and 10GE 0/0/3, respectively.


Configuration Roadmap

The configuration roadmap is as follows:

  1. Add the interfaces to the specified VLAN.

  2. Enable port isolation.

Precautions

Determine whether to switch the interface working mode to Layer 2 based on the current interface working mode.

Procedure

  1. Create VLAN 10 and add interfaces to VLAN 10.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] vlan 10
[DeviceA-vlan10] quit
[DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] portswitch
[DeviceA-10GE0/0/1] port link-type access
[DeviceA-10GE0/0/1] port default vlan 10
[DeviceA-10GE0/0/1] quit
[DeviceA] interface 10ge 0/0/2
[DeviceA-10GE0/0/2] portswitch
[DeviceA-10GE0/0/2] port link-type access
[DeviceA-10GE0/0/2] port default vlan 10
[DeviceA-10GE0/0/2] quit
[DeviceA] interface 10ge 0/0/3
[DeviceA-10GE0/0/3] portswitch
[DeviceA-10GE0/0/3] port link-type access
[DeviceA-10GE0/0/3] port default vlan 10
[DeviceA-10GE0/0/3] quit

  2. Enable Layer 2 port isolation.

    # Enable Layer 2 port isolation for 10GE 0/0/1.

    [DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] port-isolate enable group 1
[DeviceA-10GE0/0/1] quit

    # Enable Layer 2 port isolation for 10GE 0/0/2.

    [DeviceA] interface 10ge 0/0/2
[DeviceA-10GE0/0/2] port-isolate enable group 1
[DeviceA-10GE0/0/2] quit

Verifying the Configuration

  • PC1 cannot communicate with PC2.
  • PC1 and PC3 can communicate with each other.
  • PC2 and PC3 can communicate with each other.

Configuration Scripts

DeviceA

#
sysname DeviceA
#
vlan batch 10
#
interface 10GE0/0/1
 portswitch
 port link-type access
 port default vlan 10 
 port-isolate enable group 1
#
interface 10GE0/0/2
 portswitch
 port link-type access
 port default vlan 10 
 port-isolate enable group 1
#
interface 10GE0/0/3
 portswitch
 port link-type access
 port default vlan 10 
#
return
