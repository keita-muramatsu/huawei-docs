Log Format Description

Log Output Format

The output format of an actual device log is <Int_16>Time Host %%ddModule/Severity/Brief(l):CID=Z-alarmID=F;Desc.

The log format in this document is simplified to Module/Severity/Brief/Desc (module name/log level/digest/log details).

Log Field Description

Field

Field Meaning

Description

<Int_16>

Leading character

Is added to the log information to be sent to a log host and is not added to the log information saved on the local device.

Time

Timestamp

Time when information is output.

The system supports the configuration of the information output time format.

Host

Host name

The default value is HUAWEI.

%%

Huawei identifier

The log is output by a Huawei device.

dd

Version number

Version of the log format.

Module

Module name

Name of the module that outputs information.

Severity

Log level

Level of log information.

Brief

Brief description

Brief description that further describes the information.

(l)

Information type

Type of the information.

l: operation or key event log

s: security log

D: diagnostic log

d: debugging log

t: trap

M: O&M log

L: lifecycle log

CID=Z-alarmID=F

Internal system component ID and alarm ID

Internal system component ID and alarm ID of the log.

Z: indicates the internal system component ID.

F: indicates the alarm ID. Only logs generated by alarms have the alarm ID.

Desc

Detailed information

Content of the information output by each module. Each module adds a description before generating a log to describe log details.

Example

2020-08-18 18:08:56 HUAWEI %%01CLI/5/LOGIN(l):CID=2160731923;VTY0 login from 192.168.0.1 succeed.

The preceding information indicates that the log was generated at 18:08:56 on August 18, 2020, the host name is HUAWEI, the log was generated by the CLI module, the log level is 5, the component ID is 2160731923, and the log indicates that the user with the IP address 192.168.0.1 successfully logged in to the system through VTY0.
