Configuring the Buffer Size

Context

If the device's current buffer cannot meet requirements, you can manually divide the buffer.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the interface view.

    interface { interface-type interface-number | interface-name }

  3. Configure the queue-level service buffer for outbound queues.

    For the AR8100, AR6700-H, and AR6710-L14T2X4:

    qos buffer queue queue-index shared-threshold static packets packets-value

    By default, the queue-level service buffer is not manually configured for queues.

    For the AR8700 series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, and AR6710-L50T2X4-T:

    qos buffer queue queue-index shared-threshold static { bytes | kbytes | mbytes } bytes-value

    By default, the queue-level service buffer is not manually configured for queues.

    For the AR5700 series, AR6710-L8T3TS1X2, and AR6710-L8T3TS1X2-T:

    qos buffer queue queue-index shared-threshold static { { bytes | kbytes | mbytes } bytes-value | packets packets-value } *

    By default, the queue-level service buffer is not manually configured for queues.

    For the AR6710-L14T2X4, AR8100 series and AR8700 series, you need to restart the device after configuring the qos buffer queue command.
