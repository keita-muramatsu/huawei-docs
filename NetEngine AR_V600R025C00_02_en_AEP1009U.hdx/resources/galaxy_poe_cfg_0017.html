Example for Configuring PoE

Networking Requirements

As shown in Figure 1, PoE interfaces on DeviceA connect to IP phone1, IP phone2, AP1, and AP2. DeviceA needs to provide power for these devices.
  • IP phone1, IP phone2, and AP2 use 15 W, 20 W, and 15 W power, respectively. You need to set a proper maximum output power for each involved interface to ensure sufficient but safe power supply to the connected device.
  • As the priority of network services for IP phone1 is high, you need to configure the highest power supply priority for IP phone1. In addition, AP1 has heavy traffic and needs to be configured with the second highest power supply priority.
Figure 1 Configuring the PoE function

Interfaces 1 through 4 in this example are GE0/0/1, GE0/0/2, GE0/0/3, and GE0/0/4, respectively.

The interfaces in this example are only examples. You can configure PoE-capable interfaces based on the actual situation.


Procedure

  1. Set the maximum output power of GE0/0/1, GE0/0/2, and GE0/0/3 to 15 W, 20 W, and 15 W, respectively.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] interface ge 0/0/1
[DeviceA-GE0/0/1] poe power 15000
Warning: This operation may power off the PD connected to this port. Continue? [Y/N]:y
[DeviceA-GE0/0/1] quit
[DeviceA] interface ge 0/0/2
[DeviceA-GE0/0/2] poe power 20000
Warning: This operation may power off the PD connected to this port. Continue? [Y/N]:y
[DeviceA-GE0/0/2] quit
[DeviceA] interface ge 0/0/3
[DeviceA-GE0/0/3] poe power 15000
Warning: This operation may power off the PD connected to this port. Continue? [Y/N]:y
[DeviceA-GE0/0/3] quit

  2. Set the power supply priority of GE0/0/1 to Critical.

    [DeviceA] interface ge 0/0/1
[DeviceA-GE0/0/1] poe priority critical
Warning: This operation may power off some PDs with lower priority. Continue? [Y/N]:y
[DeviceA-GE0/0/1] quit

  3. Set the power supply priority of GE0/0/4 to High.

    [DeviceA] interface ge 0/0/4
[DeviceA-GE0/0/4] poe priority high
Warning: This operation may power off some PDs with lower priority. Continue? [Y/N]:y
[DeviceA-GE0/0/4] quit

Verifying the Configuration

# Display the power supply status of the PoE interfaces on the device.

[DeviceA] display poe power-state slot 1
----------------------------------------------------------------------------------------
PortName               PowerOn/Off  Enabled    Priority   Status
----------------------------------------------------------------------------------------
GE0/0/1                on           enable     critical   powering
GE0/0/2                on           enable     low        powering
GE0/0/3                on           enable     low        powering
GE0/0/4                on           enable     high       powering
...

Configuration Scripts

DeviceA

#
sysname DeviceA
#
interface GE 0/0/1
 poe priority critical
 poe power 15000
#
interface GE 0/0/2
 poe power 20000
#
interface GE 0/0/3
 poe power 15000
#
interface GE 0/0/4
 poe priority high
#
return
