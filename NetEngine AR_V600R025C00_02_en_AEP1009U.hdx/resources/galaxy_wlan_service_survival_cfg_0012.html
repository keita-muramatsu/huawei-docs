Configuring AP-Offline Service Continuity

Context

To improve user service reliability, you can configure AP-offline service continuity. Additionally, you can configure the function of allowing new STAs to access offline APs.

  • The AP-offline service continuity function applies only to direct forwarding scenarios.

  • The function of allowing new STAs to access offline APs is applicable to scenarios where service data is forwarded in direct mode and the STA authentication mode is Portal, MAC address, open, WPA/WPA2-PSK, WPA3-SAE, OWE, or OWE transition mode.

  • The AP-offline service continuity function conflicts with the offline management VAP function. If both functions are configured, the offline management VAP does not take effect.
  • The AP-offline service continuity function conflicts with the backup VAP function. If both functions are configured, the AP-offline service continuity function does not take effect.
  • The AP-offline service continuity function can be configured in the VAP profile view or AP system profile view. When this function is configured in both the view, the configuration in the VAP profile view takes precedence over that in the AP system profile view.

Procedure

  • Configure global AP-offline service continuity.
    1. Enter the system view.

      system-view

    2. Enter the WLAN view.

      wlan

    3. Create an AP system profile and enter its view.

      ap-system-profile name profile-name

      By default, the AP system profile default exists in the system.

    4. Enable AP-offline service continuity.

      • Enable AP-offline service continuity, without allowing new STAs to access offline APs.
        keep-service enable

        By default, AP-offline service continuity is enabled, and new STA access to offline APs is not allowed.

      • Enable the function of allowing new STAs to access offline APs. This function can be enabled in scenarios that do not require high security.
        keep-service enable allow new-access [ no-auth ]

        By default, AP-offline service continuity is disabled, and new STA access to offline APs is not allowed.

    5. Return to the WLAN view.

      quit

    6. Enter the AP group view or AP view.

      • Enter the AP group view.
        ap-group name group-name

        By default, the AP group default exists on the device.

      • Enter the AP view.
        ap-id ap-id

    7. Bind the AP system profile to the AP group or AP.

      ap-system-profile profile-name

      By default, the AP system profile default is bound to an AP group, but no AP system profile is bound to an AP.

  • Configure AP-offline service continuity on a VAP.
    1. Enter the system view.

      system-view

    2. Enter the WLAN view.

      wlan

    3. Create a VAP profile and enter its view.

      vap-profile name profile-name

      By default, the VAP profile default exists on the device.

    4. Enable AP-offline service continuity.

      • Enable AP-offline service continuity.
        keep-service enable

        By default, AP-offline service continuity is disabled, and new STA access to offline APs is not allowed.

      • Enable the function of allowing new STAs to access offline APs. This function can be enabled in scenarios that do not require high security.
        keep-service enable allow new-access [ no-auth ]

        By default, AP-offline service continuity is disabled, and new STA access to offline APs is not allowed.

    5. Return to the WLAN view.

      quit

    6. Bind the VAP profile.

      For details, see Binding a VAP Profile.
