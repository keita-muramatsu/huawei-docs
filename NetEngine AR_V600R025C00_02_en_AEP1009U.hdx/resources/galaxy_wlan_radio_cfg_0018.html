Configuring MU-MIMO

Context

The carrier sense multiple access with collision avoidance (CSMA/CA) mechanism used by the WLAN allows only one STA to occupy the entire channel to communicate with an AP at a time. During this period, other STAs cannot communicate with the AP. After downlink multi-user multiple-input multiple-output (MU-MIMO) scheduling is enabled, multiple STAs supporting MU-MIMO can form an MU group to simultaneously receive downlink data from the same air interface channel, improving channel efficiency and overall downlink throughput.

As shown in Figure 1, before MU-MIMO is enabled, when the AP communicates with STA_1, other STAs such as STA_2 cannot communicate with the AP. After MU-MIMO is enabled, the AP can communicate with multiple STAs at the same time, improving channel efficiency.

Figure 1 Communication before and after MU-MIMO is enabled

The MU-MIMO function is supported from 802.11ac Wave 2.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an SSID profile and enter its view.

    ssid-profile name profile-name

    By default, the SSID profile default exists in the system.

  4. Enable the beamforming function.

    undo beamforming disable

    By default, the beamforming function is enabled. Ensure that MU-MIMO is enabled so that this configuration can take effect. To disable beamforming, run the mu-mimo disable command to disable MU-MIMO first.

  5. Enable downlink MU-MIMO scheduling.

    undo mu-mimo disable

    By default, downlink MU-MIMO scheduling is enabled. Before enabling downlink MU-MIMO scheduling, run the undo beamforming disable command to enable beamforming.

    In VR scenarios, disabling downlink MU-MIMO scheduling is recommended.

  6. (Optional) Enable the MU-MIMO optimization function.

    mu-mimo optimize enable

    By default, the MU-MIMO optimization function is disabled.

    In an environment with less interference, you can enable the MU-MIMO optimization function to meet requirements for high downlink throughput of APs.

  7. Enable the OFDMA function.
    1. Enable the downlink (DL) OFDMA function.

      undo ofdma downlink disable

      By default, the DL OFDMA function is enabled.

    2. Enable the uplink (UL) OFDMA function.

      undo ofdma uplink disable

      By default, the UL OFDMA function is enabled.

  8. Exit the SSID profile view.

    quit

  9. Create a VAP profile view and enter its view.

    vap-profile name profile-name

  10. Bind the SSID profile to the VAP profile.

    ssid-profile profile-name

    By default, the SSID profile default is bound to a VAP profile.
