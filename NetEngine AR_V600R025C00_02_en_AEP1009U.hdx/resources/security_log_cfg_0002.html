Overview of Logs

Definition

Logs are the information generated during the running process of the device, which record the operating condition of each function module and the running status of each service on the network.

Purpose

As more and more services are deployed on the network, network service maintenance becomes more and more complex. Therefore, it is important for administrators to quickly locate the cause of faults or the source of historical operations. Huawei devices can record session logs/service logs/system logs. By viewing these logs, the administrators can learn about the running status of the device, and be familiar with the service status and security condition on the network in real time. In addition, the administrators can review the information and locate faults by viewing logs.
