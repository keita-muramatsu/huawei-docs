Enabling the PoE Function

Context

Before using an AP to supply power to power devices (PDs) connected to its interfaces, ensure that the PoE function is enabled on the interfaces.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP wired port link profile and enter its view.

    port-link-profile name profile-name

    By default, the AP wired port link profile default exists on the device.

  4. Enable the PoE function on the AP's interfaces.

    undo poe disable

    By default, the PoE function is enabled on an AP's interfaces.
