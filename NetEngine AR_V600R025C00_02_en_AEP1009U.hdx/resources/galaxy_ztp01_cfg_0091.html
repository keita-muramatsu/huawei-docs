Configuring a DHCP Server

Context

The DHCP server uses Option parameters to transmit network configurations to the client to implement automatic configuration during ZTP.

If the device and DHCP server are on different network segments, you need to configure a DHCP relay agent to forward DHCP packets exchanged between them.

The DHCP server does not support authentication and may be spoofed. You are advised to use a trusted DHCP server for deployment on a secure network.

Procedure

  1. Configure the DHCP server.
  2. (Optional) Configure the DHCP relay agent.

    If a third-party device is used as the DHCP server, see the operation guide of the third-party DHCP server and DHCP relay agent.
