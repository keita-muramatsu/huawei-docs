Checking the Status of an RU

Context

You can run related commands on the central device to check the status of each RU, which facilitates fault locating.

Procedure

Operation

Command

Display RU information.

display remote-unit [ connect-interface { interface-name | interface-type interface-number } | name remote-unit-name | verbose ]

Display the detailed real-time information about an RU.

display remote-unit { connect-interface { interface-name | interface-type interface-number } | name remote-unit-name } verbose realtime

Display brief information about an RU interface.

display remote-unit port [ connect-interface { interface-name | interface-type interface-number } | name remote-unit-name ] brief

Display real-time information about an RU interface.

display remote-unit port { connect-interface { interface-name | interface-type interface-number } | name remote-unit-name } realtime

Display detailed information about a specified MAC address learned by an RU.

display remote-unit { connect-interface { interface-name | interface-type interface-number } | name remote-unit-name } mac-address address

Display the configurations successfully delivered to RUs.

display remote-unit commit configuration

Display configuration delivery results of RUs.

display remote-unit commit result

Display VLAN information about all interfaces on an RU.

display remote-unit vlan [ connect-interface { interface-name | interface-type interface-number } | name remote-unit-name ]

Display information about a specified VLAN on a certain RU.

display remote-unit vlan { connect-interface { interface-name | interface-type interface-number } | name remote-unit-name } vlan vlan-id

Display the global PoE power supply status of an RU.

display remote-unit poe [ connect-interface { interface-name | interface-type interface-number } | name remote-unit-name ]

Display the global real-time PoE power supply status of an RU.

display remote-unit poe { connect-interface { interface-name | interface-type interface-number } | name remote-unit-name } realtime

Display PoE running information about an RU interface.

display remote-unit port [ port-id ] poe [ connect-interface { interface-name | interface-type interface-number } | name remote-unit-name ]

Display real-time PoE information of an RU interface.

display remote-unit port [ port-id ] poe { connect-interface { interface-name | interface-type interface-number } | name remote-unit-name } realtime

Display traffic statistics about an RU interface.

display remote-unit port [ port-id ] statistics [ connect-interface { interface-name | interface-type interface-number } | name remote-unit-name ]

Display real-time traffic statistics about an RU interface.

display remote-unit port [ port-id ] statistics { connect-interface { interface-name | interface-type interface-number } | name remote-unit-name } realtime

Display RU upgrade information.

display remote-unit upgrade { record | information }

Display information about the optical module on an RU interface.

display remote-unit port [ port-id ] transceiver [ connect-interface { interface-name | interface-type interface-number } | name remote-unit-name ]

Display real-time information about the optical module on an RU interface.

display remote-unit port [ port-id ] transceiver { connect-interface { interface-name | interface-type interface-number } | name remote-unit-name } realtime

Display statistics about MACsec-protected data packets on RUs.

display remote-unit macsec statistics port [ port-id ] { connect-interface { interface-name | interface-type interface-number } | name remote-unit-name }

Display MKA session information about RUs.

display remote-unit macsec mka port [ port-id ] { connect-interface { interface-name | interface-type interface-number } | name remote-unit-name } [ verbose ]
