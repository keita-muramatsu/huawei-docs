Example for Configuring MSDP-based Static RPs

Networking Requirements

On the network shown in Figure 1, an MSDP peer relationship is established between RPs in PIM-SM domains to share multicast sources. This allows hosts to receive data from multicast sources in another PIM-SM domain.

Figure 1 Network diagram of configuring PIM-SM inter-domain multicast

In this example, interfaces 1 through 3 represent 10GE0/0/1, 10GE0/0/2, and 10GE0/0/3, respectively.


Configuration Roadmap

The configuration roadmap is as follows:

  1. Enable the multicast function, configure interface IP addresses on devices, and configure OSPF in each PIM-SM domain for intra-domain interconnection.

  2. Enable PIM-SM on each involved interface and enable IGMP on interfaces connected to hosts.

  3. Configure static RPs on DeviceA and DeviceB.

  4. Configure MSDP peers on Loopback1 interfaces of DeviceA and DeviceB. According to the RPF rule, SA messages sent by the source RP are accepted.

Procedure

  1. Enable the multicast function, configure interface IP addresses, masks, and loopback interfaces in each PIM-SM domain, and configure OSPF for interworking.

    # Configure DeviceA. The configuration of DeviceB is similar to the configuration of DeviceA. For detailed configurations, see Configuration Scripts.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] multicast routing-enable
[DeviceA] interface 10GE0/0/1 
[DeviceA-10GE0/0/1] ip address 192.168.1.1 24
[DeviceA-10GE0/0/1] quit
[DeviceA] interface 10GE 0/0/2
[DeviceA-10GE0/0/2] ip address 192.168.2.1 24
[DeviceA-10GE0/0/2] quit
[DeviceA] interface loopback 0
[DeviceA-LoopBack0] ip address 1.1.1.1 255.255.255.255
[DeviceA-LoopBack0] quit
[DeviceA] interface loopback 1
[DeviceA-LoopBack1] ip address 3.3.3.3 255.255.255.255
[DeviceA-LoopBack1] quit
[DeviceA] ospf 1
[DeviceA-ospf-1] area 0.0.0.0
[DeviceA-ospf-1-area-0.0.0.0] network 1.1.1.1 0.0.0.0
[DeviceA-ospf-1-area-0.0.0.0] network 3.3.3.3 0.0.0.0
[DeviceA-ospf-1-area-0.0.0.0] network 192.168.1.0 0.0.0.255
[DeviceA-ospf-1-area-0.0.0.0] network 192.168.2.0 0.0.0.255
[DeviceA-ospf-1-area-0.0.0.0] quit
[DeviceA-ospf-1] quit

  2. Configure PIM-SM.

    # Enable PIM-SM on all involved interfaces and enable IGMP on interfaces connected to hosts. The configurations of other devices are similar to the configuration of DeviceA. For detailed configurations, see Configuration Scripts.

    [DeviceA] interface 10GE 0/0/1
[DeviceA-10GE0/0/1] pim sm
[DeviceA-10GE0/0/1] igmp enable
[DeviceA-10GE0/0/1] quit
[DeviceA] interface 10GE 0/0/2
[DeviceA-10GE0/0/2] pim sm
[DeviceA-10GE0/0/2] pim bsr-boundary
[DeviceA-10GE0/0/2] quit

  3. Configure Loopback0 interfaces and static RPs.

    # Configure static RPs on DeviceA and DeviceB. The configuration of DeviceB is similar to the configuration of DeviceA. For detailed configurations, see Configuration Scripts.

    [DeviceA] interface loopback 0
[DeviceA-LoopBack1] pim sm
[DeviceA-LoopBack1] quit
[DeviceA] pim
[DeviceA-pim] static-rp 1.1.1.1
[DeviceA-pim] quit

  4. Configure Loopback1 interfaces and MSDP peers.

    # Configure an MSDP peer on the Loopback1 interface of DeviceA.

    [DeviceA] interface loopback 1
[DeviceA-LoopBack0] pim sm
[DeviceA-LoopBack0] quit
[DeviceA] msdp
[DeviceA-msdp] originating-rp loopback1
[DeviceA-msdp] peer 4.4.4.4 connect-interface loopback1
[DeviceA-msdp] quit

    # Configure an MSDP peer on the Loopback1 interface of DeviceB.

    [DeviceB] interface loopback 1
[DeviceB-LoopBack0] ip address 4.4.4.4 255.255.255.255
[DeviceB-LoopBack0] pim sm
[DeviceB-LoopBack0] quit
[DeviceB] msdp
[DeviceB-msdp] originating-rp loopback1
[DeviceB-msdp] peer 3.3.3.3 connect-interface loopback1
[DeviceB-msdp] quit

Configuration Scripts

  • DeviceA

    #
sysname DeviceA
#
multicast routing-enable
#
interface 10GE0/0/1
 ip address 192.168.1.1 255.255.255.0
 pim sm
#
interface 10GE0/0/2
 ip address 192.168.2.1 255.255.255.0
 pim bsr-boundary
 pim sm
#
interface LoopBack0
 ip address 1.1.1.1 255.255.255.255
 pim sm
#
interface LoopBack1
 ip address 3.3.3.3 255.255.255.255
 pim sm
#
ospf 1
 area 0.0.0.0
  network 1.1.1.1 0.0.0.0
  network 3.3.3.3 0.0.0.0
  network 192.168.1.0 0.0.0.255
  network 192.168.2.0 0.0.0.255
#
pim
 static-rp 1.1.1.1
#
msdp
 originating-rp LoopBack1
 peer 4.4.4.4 connect-interface LoopBack1
#
return

  • DeviceB

    #
sysname DeviceB
#
multicast routing-enable
#
interface 10GE0/0/1
 ip address 192.168.2.2 255.255.255.0
 pim bsr-boundary
 pim sm
#
interface 10GE0/0/2
 ip address 10.1.2.5 255.255.255.0
 pim sm
#
interface 10GE0/0/3
 ip address 192.168.5.1 255.255.255.0
 pim sm
 igmp enable
#
interface LoopBack0
 ip address 2.2.2.2 255.255.255.255
 pim sm
#
interface LoopBack1
 ip address 4.4.4.4 255.255.255.255
 pim sm
#
ospf 1
 area 0.0.0.0
  network 2.2.2.2 0.0.0.0
  network 4.4.4.4 0.0.0.0
  network 192.168.2.0 0.0.0.255
  network 10.1.2.0 0.0.0.255
  network 192.168.5.0 0.0.0.255
#
pim
 static-rp 2.2.2.2
#
msdp
 originating-rp LoopBack1
 peer 3.3.3.3 connect-interface LoopBack1
#
return
