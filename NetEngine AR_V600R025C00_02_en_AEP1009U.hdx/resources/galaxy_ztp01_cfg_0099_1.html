Preparing Deployment Files

MASTERKEY File

Deployment files need to be prepared before SZTP. The device supports the following types of deployment files: system software, configuration file, patch file, and master key file. Among the deployment files, a configuration file can be manually compiled or copied from other devices, while other deployment files such as the system software package need to be downloaded from Huawei technical support website.

The configuration file name is a string of 5 to 64 characters and suffixed with .zip or .cfg. The configuration file is used for the next startup.

You can obtain a configuration file from other devices in either of the following ways:

  • Saving the configuration file: Run the save shareable-configuration command on the device that provides the configuration file to save the configuration file, and then export the configuration file using SFTP or other methods.
  • Changing the system master key: Run the set master-key command to change the system master key, save the configuration file, and export the configuration file using SFTP or other methods.

All passwords in the configuration file obtained are encrypted to ensure security. In addition, to enable the device to decrypt the ciphertext in the configuration file during deployment, you need to provide a MASTERKEY file in which corresponding passwords are provided.

To ensure security, you are advised to export a configuration file from another device instead of compiling it manually. You are advised to use the method of saving a configuration file. If you use the method of changing the system master key, the system master key of the device that provides the configuration file may be disclosed.

Ensure that the configuration file for deployment contains the console port password or an AAA user name that can be used to log in to the device remotely. Otherwise, the configuration file cannot be successfully set, causing a deployment to fail.

The MASTERKEY file name contains 5 to 64 characters and is suffixed with .ini. The password in the MASTERKEY file is used to decrypt the ciphertext in the configuration file so that the device can identify the ciphertext at next startup.

The following is a format example of such a file. For details about the fields included in this file, see Table 1.

[BEGIN]
EXPORTCFG=
SET_MASTER= 
[END]
Table 1 Fields in the MASTERKEY file

Field

Mandatory or Not

Description

Value Range

[BEGIN]

Yes

Start field of the MASTERKEY file.

-

EXPORTCFG

Depending on the configuration file obtaining method:

  • This field is mandatory when the configuration file is obtained by saving the configuration file on another device.
  • The field is optional when the configuration file is obtained by changing the system master key.

Password used for saving the configuration file.
  • If the password parameter is not specified when the save shareable-configuration command is executed to save the configuration file, leave the EXPORTCFG field empty.
  • If the password parameter is specified when the save shareable-configuration command is executed to save the configuration file, set the EXPORTCFG field to a value that is the same as the password entered in interactive mode.

SET_MASTER
  • This field is optional when the configuration file is obtained by saving the configuration file on another device.
  • The field is mandatory when the configuration file is obtained by changing the system master key.

System master key.

The value must be the same as the master key of the device that provides the configuration file.

NOTE:

For security purposes, after the deployment is complete, the device uses the random master key instead of the master key specified by the SET_MASTER field. You are advised to clear the file containing this field immediately after the deployment is complete. Otherwise, the system master key of the device that provides the configuration file may be disclosed.

[END]

Yes

End field of the MASTERKEY file.

-

Procedure

  1. Obtain the configuration file from another device.
    • Obtaining a configuration file through saving the configuration file on another device
    1. Save the configuration file on another device that has been deployed.

      save shareable-configuration configuration-file [ password ]

      If the password parameter is not specified, the configuration file uses the default key information. If the password parameter is specified, the device generates key information in the configuration file based on the password entered in interactive mode.

    2. Export the configuration file using SFTP.

      For details, see "Backing Up the Configuration File to an SFTP Server or Client" in the CLI Configuration Guide > Basic Configuration > Configuration File Management.

    3. Create a .txt file and change the file name to ***.ini, for example, masterkey.ini.

      [BEGIN]
EXPORTCFG= 
[END]

    4. Set the EXPORTCFG field in the masterkey.ini file.

      • If the password parameter is not specified for saving the configuration file, leave the EXPORTCFG field empty.
      • If the password parameter is specified for saving the configuration file, set the EXPORTCFG field to a value that is the same as that of password.

    • Obtaining the configuration file through changing the system master key
    1. Change the system master key.

      <HUAWEI> set master-key
Enter the user password:       //Enter the current user password instead of the current system master key.
Warning: This operation will automatically save configurations. Are you sure you want to perform it? [Y/N]:y 
Do you want to enter the master key? (If you enter Y, you need to manually enter the master key and automatic key update stops. If you enter N, the system  automatically generates a master key. If you enter D, the system will change the current master key to the default master key.) [Y/N/D]:y 
Info: Enter a new master key:   // Enter the system master key.
Info: Confirm the new master key:
Warning: Keep the new master key well.

      For details, see "System Master Key Configuration" in CLI Configuration Guide > User Access and Authentication Configuration.

    2. Export the configuration file using SFTP.

      For details, see "Backing Up the Configuration File to an SFTP Server or Client" in the CLI Configuration Guide > Basic Configuration > Configuration File Management.

    3. Create a .txt file and change the file name to ***.ini, for example, masterkey.ini.

      [BEGIN]
SET_MASTER= 
[END]

    4. Set the SET_MASTER field in the masterkey.ini file.

      The value of the SET_MASTER field must be the same as the master key of the device that provides the configuration file.

      For security purposes, after the deployment is complete, the device uses the random master key instead of the master key specified by the SET_MASTER field. You are advised to clear the file containing this field immediately after the deployment is complete. Otherwise, the system master key of the device that provides the configuration file may be disclosed.

  2. Download other deployment files.
