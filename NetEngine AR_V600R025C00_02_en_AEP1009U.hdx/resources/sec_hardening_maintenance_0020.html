Patch Management Security

Overview

A patch file running on a device may have been tampered with before being uploaded to the device. If the device runs the tampered patch file, the device is controlled and attacked. The following security mechanisms can be used to secure the entire process from file transfer to the running of the patch file:

  • Digital signatures are supported.

    When a patch file is released, a digital signature is added to the patch file and the digital signature information file is packed into the patch file. When an NMS distributes the patch file to an NE or directly loads the patch file onto the NE, the digital signature is verified. The patch file is complete and reliable only if the verification is passed. Otherwise, the patch file is invalid.

  • The path file in the running state is protected as a system file. In this case, the path file cannot be modified or deleted.

Before installing a patch file, verify the integrity of the patch file. Integrity verification includes digital signature verification and protection mechanism verification. Integrity verification can be performed in either of the following ways:

  • Before the installation, manually verify the integrity of the patch file.
  • When a patch file is installed in in-service mode or when a patch file that takes effect at the next startup is specified and the device is restarted, the device automatically verifies the integrity of the patch file.

If the integrity verification of the patch file fails, you are advised to restart the system instead of trying for multiple times.

Impact on the System

None

Procedure

  • Before the installation, manually verify the integrity of the patch file. The following uses the patch file XXX_V600R025C00SPH001.PAT as an example.

    <HUAWEI> check software file-name XXX_V600R025C00SPH001.PAT
Warning: Software file verification consumes CPU resources. Continue?  [Y/N]:y

    If the verification is successful, the following message is displayed:

    Info: The integrity check for the patch software of the XXX_V600R025C00SPH001 version succeeds.

    If the verification fails, the following message is displayed:

    Error: Failed to check the integrity of the patch software of the unknown version.

  • When a patch file is installed in in-service mode or when a patch file that takes effect at the next startup is specified and the device is restarted, the integrity of the patch file is automatically verified.

Checking the Security Hardening Result

  • When the integrity of a patch file is manually verified, the system will prompt a message:
    • If the verification is successful, the following message is displayed:
      Info: The integrity check for the patch software of the XXX_V600R025C00SPH001 version succeeds.
    • If the verification fails, the following message is displayed:
      Error: Failed to check the integrity of the patch software of the unknown version.
  • When the integrity of the patch file is automatically verified:
    • If the verification is successful, the patch file is successfully installed and the system is successfully started.
    • If the verification fails, the patch file fails to be installed.
