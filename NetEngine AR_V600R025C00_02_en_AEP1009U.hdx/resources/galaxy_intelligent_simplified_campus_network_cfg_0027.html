Performing an Internal Loopback Test on RU Interfaces

Context

When traffic forwarding on an RU is abnormal, you can perform an internal loopback test on the RU interfaces to check whether the internal forwarding chip of the RU works properly.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the single RU view.

    remote-unit { id | connect-interface interface-type interface-number | name remote-unit-name }

  3. Perform an internal loopback test on the RU interfaces.

    loopbacktest internal port port-id

Verifying the Configuration

Run the display loopbacktest port port-id { connect-interface { interface-type interface-number } | name remote-unit-name } command to check information about the loopback test on an RU interface.
