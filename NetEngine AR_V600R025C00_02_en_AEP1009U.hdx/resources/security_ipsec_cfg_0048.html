Configuring IPsec Mask Filtering

Prerequisites

IPsec mask filtering takes effect only for template IPsec policies.

Context

When a branch is connected to the headquarters, if the data flow range of a branch is wide, traffic of other branches may be incorrectly diverted to this branch. In this case, you can configure the IPsec mask filtering function to check and restrict the access of IPsec-protected flow information. After this function is configured, the device checks the source and destination IP address masks of the remote end. If the masks are greater than or equal to the configured values, subsequent negotiation continues. Otherwise, IPsec SA negotiation fails.

Procedure

  1. Enter the system view.

    system-view

  2. Configure the IPsec mask filtering function.

    ipsec netmask { source source-mask | [ source source-mask ] destination destination-mask }

    By default, the IPsec mask filtering function is not configured.
