Querying the Power Module Status

Description of MIB Objects

You can use hwEntityPwrState in hwPwrStatusTable to obtain all the power module status.

Object

OID

hwEntityPwrState

1.3.6.1.4.1.2011.5.25.31.1.1.18.1.6

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.
  2. Perform the Walk operation on hwEntityPwrState to query the power module status. As shown in Figure 1, the power module status is supply, indicating that the power module is normal. The first digit in the index value indicates the slot number of the power module, and the second digit indicates the serial number of the power module.
