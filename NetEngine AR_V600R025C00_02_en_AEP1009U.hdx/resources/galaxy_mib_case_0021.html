Querying Voltage Information

Description of MIB Objects

You can obtain the voltage information of entities through hwEntityVoltage in hwEntityStateTable.

Object

OID

entPhysicalName

1.3.6.1.2.1.47.1.1.1.1.7

entPhysicalClass

1.3.6.1.2.1.47.1.1.1.1.5

hwEntityVoltage

1.3.6.1.4.1.2011.5.25.31.1.1.1.1.13

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.
  2. Perform the SNMP Walk operation on entPhysicalClass to obtain the indexes and types of all entities. Find the entities of the type 9 from the Walk operation results. The value 9 indicates that the entity type is card.
    Figure 1 Querying the entity type through entPhysicalClass

    As shown in Figure 1, the value 17104897 indicates the entity index, and the value 9 indicates the entity type.

  3. Perform the SNMP Get operation on hwEntityVoltage based on card indexes to obtain voltage information of these cards.
    Figure 2 Querying voltage information based on the card index

    As shown in Figure 2, the voltage of the card with the index 17104897 is 5240, in mW.
