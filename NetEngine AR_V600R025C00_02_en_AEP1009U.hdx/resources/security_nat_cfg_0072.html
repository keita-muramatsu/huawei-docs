Maintaining NAT

Managing NAT Rules

Table 1 Managing NAT rules

Operation

Command

Rename a NAT rule.

rule rename old-name new-name

Move a NAT rule to change its priority.

rule move rule-name1 { { after | before } rule-name2 | up | down | top | bottom }

Clone a NAT rule.

rule copy rule-name new-rule-name

Enable or disable the current NAT rule.

rule name rule-name

enable / disable

Configuring NAT Alarm Functions

Table 2 Configuring NAT alarm functions

Operation

Command

Set the statistics collection interval and threshold for port conflict alarms during NAPT.

snmp-agent nat trap { interval interval | threshold threshold }

Enable the enhanced alarm function for PAT address pools.

nat pat alarm enhance enable

Set the enhanced alarm threshold for PAT address pools.

nat pat alarm enhance threshold threshold-value

Enable the alarm function for the usage of public IP addresses in a No-PAT address pool.

nat no-pat global alarm ip-pool threshold trap enable

Set an alarm threshold for the usage of public IP addresses in a No-PAT address pool.

nat no-pat global alarm ip-pool threshold threshold-value

Table 3 Configuring the NAT address pool statistics collection function

Operation

Command

display nat resource usage address-group { name group-name | id group-id } [ verbose | global-ip ip-address ]

reset nat-policy counter { all | rule rule-name }
