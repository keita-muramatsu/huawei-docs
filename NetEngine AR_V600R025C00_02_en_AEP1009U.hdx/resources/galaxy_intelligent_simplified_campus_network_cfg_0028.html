Restarting an RU

Context

If an RU is working abnormally, you can restart the RU. If an RU fails to be upgraded and enters the cooldown period, you can restart the RU to end the cooldown period.

Restarting an RU interrupts services. Therefore, restart an RU at a proper time.

Procedure

  • Restarting all RUs
    1. Enter the system view.
      system-view
    2. Enter the global RU view.
      remote-unit
    3. Restart all RUs.
      reboot all
  • Restarting a single RU
    1. Enter the system view.
      system-view
    2. Enter the single RU view.
      remote-unit { id | connect-interface interface-type interface-number | name remote-unit-name }
    3. Restart the specified RU.
      reboot

Verifying the Configuration

Run the display remote-unit connect record command to check RU onboarding and disconnection records.
