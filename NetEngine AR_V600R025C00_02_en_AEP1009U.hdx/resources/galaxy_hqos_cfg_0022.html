Configuring a Child Traffic Policy

Context

A traffic policy configured for an FQ through MQC is a child traffic policy. For details about a child traffic policy, see Parent and Child Traffic Policy Configuration Model

Procedure

  1. Enter the system view.

    system-view

  2. Configure a traffic classifier to differentiate services.
    1. Create a traffic classifier and enter the traffic classifier view.

      traffic classifier classifier-name [ type { and | or } ]

    2. Select proper traffic classification rules as required. For details, see "Configuring a Traffic Classifier" in MQC Configuration.
    3. Exit the traffic classifier view.

      quit

  3. Configure a traffic behavior.

    1. Create a traffic behavior and enter the traffic behavior view.
      traffic behavior behavior-name
    2. Reference an FQ profile in the traffic behavior.
      flow-queue flow-queue-name queue queue-name

      When configuring this command, set flow-queue-name and queue-name to the names of the FQ profile and FQ configured in Configuring an FQ or SQ Profile, respectively.

    3. (Optional) Configure the CAR action of the child traffic policy.
      The CIR and PIR of the CAR action can be set to absolute values or values in percentage, but only one value format can be configured. Use either of the following methods to perform the configuration:
      • Set the absolute values of the CIR and PIR.
        car { cir cir-value [ kbps | mbps | gbps ] [ pir pir-value [ kbps | mbps | gbps ] ] } [ cbs cbs-value [ bytes | kbytes | mbytes ] pbs pbs-value [ bytes | kbytes | mbytes ] ] [ share ] [ mode color-blind ] [ green pass [ remark-8021p 8021p-value | remark-dscp dscp-value ] | yellow { discard | pass [ remark-8021p 8021p-value | remark-dscp dscp-value ] } | red { discard | pass [ remark-8021p 8021p-value | remark-dscp dscp-value ] } ]*
      • Set the values of the CIR and PIR in percentage.
        car cir pct cir-percentage [ pir pct pir-percentage ] hierarchical-bandwidth [ cbs cbs-value pbs pbs-value | share | mode color-blind ]*

        cir-percentage and pir-percentage specify the CIR bandwidth percentage and PIR bandwidth percentage, respectively. Their base values are the SQ bandwidth values defined in the upper-level parent traffic policy, that is, the values of cir cir-value and pir pir-value configured in the SQ profile of the parent traffic policy using the user-queue command.

    4. Exit the traffic behavior view.
      quit

  4. Configure an FQ traffic policy.
    1. Create a traffic policy and enter the traffic policy view.

      traffic policy policy-name

    2. Bind a traffic classifier to a traffic behavior in the traffic policy.

      classifier classifier-name behavior behavior-name [ precedence precedence-value ]

Example

# Configure an FQ traffic policy.

  1. Create traffic classifiers data and voice to classify services based on DSCP values (DSCP values 15 and 46 for data and voice services, respectively).
    <HUAWEI> system-view
[HUAWEI] traffic classifier data
[HUAWEI-classifier-data] if-match dscp 15
[HUAWEI-classifier-data] quit
[HUAWEI] traffic classifier voice
[HUAWEI-classifier-voice] if-match dscp 46
[HUAWEI-classifier-voice] quit
  2. Create traffic behaviors data and voice and reference the FQ profile fq1 in the traffic behaviors.
    [HUAWEI] traffic behavior data
[HUAWEI-behavior-data] flow-queue fq1 queue data
[HUAWEI-behavior-data] quit
[HUAWEI] traffic behavior voice
[HUAWEI-behavior-voice] flow-queue fq1 queue voice
[HUAWEI-behavior-voice] quit
  3. Create a traffic policy named sub-policy1 and bind traffic classifiers to traffic behaviors in the traffic policy.
    [HUAWEI] traffic policy sub-policy1
[HUAWEI-trafficpolicy-sub-policy1] classifier data behavior data
[HUAWEI-trafficpolicy-sub-policy1] classifier voice behavior voice
