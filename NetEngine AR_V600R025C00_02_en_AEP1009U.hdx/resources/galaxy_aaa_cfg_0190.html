Increasing User Privilege Levels

Context

After a user logs in to the system, the user can use only the commands at the same or lower privilege level than the user privilege level. If the current user privilege level is low but the commands of which the privilege level is higher than the user privilege level need to be run, you can increase the user privilege level to a higher level. When a user is switched from a lower privilege level to a higher level, the device requires the user to enter the authentication password for the higher privilege level to authenticate the user identity, preventing access from unauthorized users.

  • This function applies only to local administrators who log in to the device through Telnet, STelnet, or console port and use AAA authentication.
  • The device uses the user name, password, and privilege level to control the rights of users to operate the device. If you run the super command to increase the user privilege level, the method of using the user name, password, and privilege level for rights control becomes ineffective. Any user can obtain operation rights at a high privilege level as long as the user knows the authentication password for the high privilege level, which may cause unauthorized operations on the device. Therefore, you are advised not to use the super command to increase the user privilege level.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the AAA view.

    aaa

  3. Configure the authentication password for increasing the user privilege level.

    super password [ level level ] [ cipher cipher-password ]

    By default, no authentication password is configured for increasing the user privilege level.

  4. (Optional) In the password policy view of the local administrator, configure the complexity check function for the authentication password required for increasing the user privilege level.

    1. Enable the password policy for local administrators and enter the local administrator password policy view.
      local-aaa-user password policy administrator

      By default, the password policy for local administrators is enabled.

    2. Configure the complexity check function for the authentication password required for increasing the user privilege level.
      undo super password complexity-check disable

      By default, the password complexity check function is enabled.

      After this function is enabled, the password must contain at least two types of the following characters: uppercase letters, lowercase letters, digits, and special characters. To ensure device security, you are advised not to disable password complexity check.

  5. Return to the user view.

    return

  6. Increase the user privilege level.

    super [ user-level ]

    If the entered target privilege level is higher than the current user privilege level, that is, the user is switched from a lower privilege level to a higher privilege level, enter the authentication password as prompted. If the password is correct, the user is switched to a higher privilege level. If incorrect passwords are entered three consecutive times, the system returns to the user view and keeps the user privilege level unchanged.

    If the entered target privilege level is lower than or equal to the current user privilege level, the system sets the entered privilege level to the target one and displays a message.
