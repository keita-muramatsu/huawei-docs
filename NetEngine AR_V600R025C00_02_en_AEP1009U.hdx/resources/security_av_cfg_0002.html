Overview of Antivirus

Definition

Viruses are a type of malicious code that spreads through mails or file sharing protocols, infecting or attaching to application programs or files. Viruses perform various types of harmful activities on infected hosts, posing serious threats that not only affect hosts, but also the network. Viruses may exhaust a host's resources, occupy network bandwidth, control host permissions, steal data, and even corrupt the hardware.

Antivirus is a security mechanism that is designed to prevent, detect and process viruses and any other kinds of malware. It effectively prevents data corruption, permission change, and system crashes caused by virus files, ensuring network security.

Purpose

With the continuous development of network technologies, enterprise users frequently transfer, download, and share files over the network, facing unprecedented virus threats.

As shown in Figure 1, intranet users frequently access and download files from the Internet, and the server deployed on the intranet frequently receives files uploaded by Internet users. After the device configured with the antivirus function is deployed at the ingress of the enterprise network, the device only allows secure files to be transferred to the intranet. It blocks detected virus files or generates alerts on the virus files.

Figure 1 Schematic diagram of antivirus

Benefits

With a large and continuously-updated virus signature database, the antivirus function can effectively detect and process malware and spyware files, ensuing network security.

The antivirus function configured on the device and the antivirus software installed on user hosts are mutually complementary. Because they are deployed on different locations and use different signature databases, they can be used together to secure user hosts and the network.
