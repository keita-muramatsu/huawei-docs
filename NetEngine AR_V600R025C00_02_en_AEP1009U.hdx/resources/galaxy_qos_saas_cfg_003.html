SaaS Traffic Steering Mode

There are two SaaS traffic steering modes: optimal path mode and load balancing mode. The following describes the concept of the optimal path before introducing the two modes.

During SaaS traffic steering, the device gives a quality of experience (QoE) score to each link, and the link with the highest score is the optimal path. The formula for calculating the link score is as follows: QoE = loss-factor x (loss-baseline/real-loss) + (100 – loss-factor) x (delay-baseline/real-delay). Table 1 describes the variables in the formula.

Table 1 Variables for calculating the link score

Variable Name

Description

Obtaining Method

QoE

Indicates the QoE score of a link.

The value is obtained through calculation.

loss-factor

Indicates the weight of the packet loss rate. The value is an integer in the range from 0 to 100.

The value is configured using a command.

loss-baseline

Indicates the base value of the packet loss rate. The value is an integer in the range from 0 to 100.

The value is configured using a command.

real-loss

Indicates the actual packet loss rate. The value is an integer in the range from 0 to 100.

The value is obtained through NQA detection.

delay-baseline

Indicates the base value of the delay. The value is an integer in the range from 1 to 1000, in milliseconds.

The value is configured using a command.

real-delay

Indicates the actual delay. The value range depends on the actual result, in milliseconds.

The value is obtained through NQA detection.
  • In optimal path mode, the device selects the optimal path to forward service data.
  • In load balancing mode, the device adds the links whose packet loss rate and delay are within the acceptable range to the load balancing group based on the optimal path. The device uses the links in the load balancing group to forward service data.
