Understanding Session Logs

The device can output session information. The conditions for triggering session logs are as follows:

  • After performing NAT for a packet, the device sets up a session for it. Currently, the device can output only IPv4 NAT session logs after the sessions age out.

    Session aging logs are sent only when device sessions are disconnected, and failed sessions that have zero sent and received packets are filtered out. Session aging logs provide information about the session start and end time, and packet sending and receiving statistics.

  • When the size of a log packet reaches 1400 bytes or the time from when the last packet was sent to the log server reaches 1s, the device sends the log to the log server.

Session logs can be in binary or syslog format. Session logs in different formats are sent to different log servers. For details, see Table 1.
