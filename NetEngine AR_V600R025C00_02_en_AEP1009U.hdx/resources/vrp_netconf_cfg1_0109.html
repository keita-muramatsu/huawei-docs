Commit-description

The commit-description capability enables a user to edit a description when a device performs an <edit-config> operation. The description helps configuration rollback.

A description is carried in the <commit-description> parameter of the <edit-config> operation. The YANG model defines the capability in the huawei-ietf-netconf-ext.yang file.

  • RPC request
    <?xml version="1.0" encoding="UTF-8"?>
<rpc xmlns="urn:ietf:params:xml:ns:netconf:base:1.0" message-id="1712545242243">
  <edit-config>
    <target>
      <running />
    </target>
    <config>
      <system xmlns="urn:huawei:yang:huawei-system">
        <system-info>
          <sys-name>huawei</sys-name>
        </system-info>
      </system>
    </config>
  <commit-description xmlns="urn:huawei:yang:huawei-ietf-netconf-ext">commitDescTest</commit-description>
  </edit-config>
</rpc>
  • RPC reply
    <?xml version="1.0" encoding="UTF-8"?>
<rpc-reply xmlns="urn:ietf:params:xml:ns:netconf:base:1.0" xmlns:nc-ext="urn:huawei:yang:huawei-ietf-netconf-ext" message-id="1712545242243" nc-ext:flow-id="67" nc-ext:flow-id-time="2024-04-19T09:29:55Z">
  <ok />
</rpc-reply>
