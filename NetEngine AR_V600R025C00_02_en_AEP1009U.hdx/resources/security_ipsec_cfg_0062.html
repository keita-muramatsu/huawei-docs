Configuring the IPsec SA Lifetime

Prerequisites

The IPsec SA lifetime takes effect only for the following IPsec types:

  • ACL-based IPsec (involving ISAKMP IPsec policies and template IPsec policies)
  • Route-based IPsec (involving IPsec profiles)

Context

When an IPsec SA is established using dynamic IKE negotiation, you can configure the IPsec SA lifetime to update the IPsec SA in real time, reducing the risk of cracking the IPsec SA and improving tunnel security.

The configured IPsec SA lifetime applies only to the new IPsec SAs established through negotiation. Before an IPsec SA is about to expire, IKE will negotiate a new IPsec SA for the remote end. The remote end uses the new IPsec SA to protect IPsec communication immediately after the new IPsec SA has been negotiated. If service traffic is being transmitted, the existing IPsec SA will be deleted immediately. If no service traffic is transmitted, the existing IPsec SA will be deleted after 10s or the hard lifetime expires.

The IPsec SA lifetime can be measured by time or traffic.

  • The time-based lifetime indicates the lifetime of an IPsec SA.
  • The traffic-based lifetime indicates the maximum amount of traffic that an IPsec SA can process.

If both the time-based lifetime and traffic-based lifetime are set for an IPsec SA, the IPsec SA becomes invalid when either lifetime expires. You are advised to set the traffic-based lifetime based on the total amount of IPsec traffic that the device forwards within 1 hour.

The IPsec SA lifetime can also be classified into hard lifetime and soft lifetime.

  • The hard lifetime (hard timeout period) indicates the lifetime of an IPsec SA or the maximum amount of traffic that an IPsec SA can process. During negotiation between two devices, the actual IPsec SA lifetime is the smaller of the two hard lifetime values configured on the two devices.
  • The soft lifetime (soft timeout period) indicates the time after which a new IPsec SA is negotiated to replace the existing IPsec SA before the hard lifetime of the existing IPsec SA is about to expire or indicates the maximum amount of traffic that an IPsec SA can process before a new IPsec SA is negotiated.

The IPsec SA lifetime can be configured globally or based on a specific IPsec policy or IPsec profile. If no IPsec SA lifetime is configured for a specific IPsec policy or IPsec profile, the global IPsec SA lifetime is used. If both the global IPsec SA lifetime and IPsec SA lifetime for a specific IPsec policy or IPsec profile are configured, the IPsec SA lifetime configured for a specific IPsec policy or IPsec profile takes effect. The soft timeout buffer time or soft timeout buffer traffic of an IPsec SA cannot be configured in a template IPsec policy or an IPsec profile. In this situation, only the global settings or default settings can be used.

Procedure

  • Set the global IPsec SA lifetime.
    1. Enter the system view.

      system-view

    2. Set the global IPsec SA hard lifetime.

      ipsec sa global-duration { time-based interval | traffic-based size }

      For the default settings, see Table 3.

    3. Set the global IPsec SA soft timeout buffer time or soft timeout buffer traffic.

      ipsec sa global-soft-duration { time-based buffer seconds | traffic-based buffer kilobytes }

      By default, the global IPsec SA soft timeout buffer time or soft timeout buffer traffic is not configured.

      If the value that equals the hard lifetime minus the configured soft timeout buffer time is larger than 10s, this value is used as the soft lifetime. Otherwise, the default soft lifetime is used. If the value that equals the hard lifetime minus the configured soft timeout buffer traffic is larger than 7200 Kbytes, this value is used as the soft lifetime. Otherwise, the default soft lifetime is used.

  • Configure the IPsec SA lifetime in a specific IPsec policy.
    1. Enter the system view.

      system-view

    2. Enter the ISAKMP or template IPsec policy view.

      # Enter the ISAKMP IPsec policy view.

      ipsec policy policy-name seq-number isakmp

      # Enter the template IPsec policy view.

      ipsec policy-template template-name seq-number

    3. Configure the IPsec SA hard lifetime in the IPsec policy.

      sa duration { time-based seconds | traffic-based kilobytes }

      By default, the global IPsec SA hard lifetime is used, and no IPsec SA hard lifetime is configured in an IPsec policy.

    4. Set the IPsec SA soft timeout buffer time or soft timeout buffer traffic in the IPsec policy.

      sa soft-duration { time-based buffer seconds | traffic-based buffer kilobytes }

      By default, the IPsec SA soft timeout buffer time or soft timeout buffer traffic is not configured in an IPsec policy.

      If the value that equals the hard lifetime minus the configured soft timeout buffer time is larger than 10s, this value is used as the soft lifetime. Otherwise, the default soft lifetime is used. If the value that equals the hard lifetime minus the configured soft timeout buffer traffic is larger than 7200 Kbytes, this value is used as the soft lifetime. Otherwise, the default soft lifetime is used.

    5. Optional: Configure the device to delete the original IPsec SA after the hard lifetime expires during IPsec SA re-negotiation.

      sa keep-holding-to hard-duration

      By default, during IPsec SA re-negotiation, the device deletes the original IPsec SA immediately after using the new IPsec SA to transmit data.

      After a new IPsec SA is negotiated, if the peer device still uses the original IPsec SA to transmit data while the local device deletes the original IPsec SA immediately after using the new IPsec SA to transmit data, the IPsec SAs on the two devices will be different. This will cause IPsec traffic interruption. In this case, it is recommended to perform this step on the local device.

      This function takes effect only for IPsec SAs established through IKEv1 negotiation.

  • Set the IPsec SA lifetime in an IPsec profile.
    1. Enter the system view.

      system-view

    2. Enter the IPsec profile view.

      ipsec profile profile-name

    3. Set the IPsec SA lifetime in the IPsec profile.

      sa duration { time-based seconds | traffic-based kilobytes }

      By default, the global IPsec SA hard lifetime is used, and no IPsec SA hard lifetime is configured in an IPsec profile.
