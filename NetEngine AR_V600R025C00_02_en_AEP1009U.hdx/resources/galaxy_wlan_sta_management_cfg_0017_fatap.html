Configuring an SSID Profile

Context

An SSID identifies a WLAN. When you search for available wireless networks on a STA, the displayed WLAN names are SSIDs. You can customize an SSID name and set other parameters in an SSID profile. The configuration in the SSID profile can take effect only after the profile is bound to a VAP profile.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an SSID profile and enter its view.

    ssid-profile name profile-name

  4. Configure the SSID name.

    ssid ssid

  5. (Optional) Configure the transmit rate of management frames.
    • Configure the rate at which 2.4 GHz management frames are sent.
      beacon-2g-rate beacon-2g-rate

      By default, the transmit rate of 2.4 GHz management frames is 5.5 Mbit/s.

    • Configure the rate at which 5 GHz management frames are sent.
      beacon-5g-rate beacon-5g-rate

      By default, the transmit rate of 5 GHz management frames is 6 Mbit/s.

    • Configure the rate at which 6 GHz management frames are sent.
      beacon-6g-rate beacon-6g-rate

      By default, the transmit rate of 6 GHz management frames is 6 Mbit/s.

  6. (Optional) Set the maximum number of successfully associated STAs on a VAP.

    max-sta-number max-sta-number

    By default, a VAP allows for a maximum of 64 successfully associated STAs.

  7. (Optional) Enable the function of preventing STAs from entering the power-saving mode.

    active-dull-client enable

    By default, the function of preventing STAs from entering the power-saving mode is disabled.

  8. (Optional) Enable the function of forcibly preventing STAs from entering the power-saving mode.

    active-dull-client force enable

    By default, the function of forcibly preventing STAs from entering the power-saving mode is disabled.

  9. (Optional) Enable Beacon frames to carry AP names.

    advertise-ap-name enable

    By default, Beacon frames do not carry AP names.

  10. (Optional) Enable SSID hiding in Beacon frames.

    ssid-hide enable

    By default, SSID hiding in Beacon frames is disabled.

  11. (Optional) Configure the number of 802.11ac spatial streams and the MCS value.

    vht { tx | rx } mcs-map nss nss-value map mcs-value

    By default, the number of 802.11ac spatial streams and the MCS value are not configured in an SSID profile. This configuration takes effect only when an AP communicates with STAs using 802.11ac or 802.11ax.

  12. (Optional) Configure the number of 802.11ax spatial streams and the MCS value.

    he { tx | rx } mcs-map nss nss-value map mcs-value

    By default, in an SSID profile, the maximum number of 802.11ax spatial streams for receiving and sending data is 8, and the MCS value is 11. This configuration takes effect only when an AP communicates with STAs using 802.11ax.

  13. (Optional) Configure the association aging time of STAs.

    association-timeout time

    By default, the association aging time of STAs is 5 minutes.

  14. (Optional) Configure the DTIM interval.

    dtim-interval dtim-interval

    By default, the DTIM interval is 1.

  15. (Optional) Configure the excessive retransmission thresholds for quickly disconnecting STAs.

    excessive-retry quick-kickoff-threshold { count count | duration duration }

    By default, the maximum number of excessive retransmissions is 512, and the maximum retransmission duration is 8 seconds.

  16. (Optional) Disable the 802.11k protocol.

    dot11k disable

    By default, the 802.11k protocol is enabled.

    Some outdated STAs on the network may be incompatible with the 802.11k protocol. In this case, perform this step to disable the 802.11k function.

  17. (Optional) Disable the 802.11v BSS transition function.

    dot11v bss-transition disable

    By default, the 802.11v BSS transition function is enabled.

    Some outdated STAs on the network may be incompatible with 802.11v BSS transition. In this case, perform this step to disable the 802.11v BSS transition function.

  18. Return to the WLAN view.

    quit

  19. Create a VAP profile view and enter its view.

    vap-profile name profile-name

  20. Bind the SSID profile to the VAP profile.

    ssid-profile profile-name

    By default, the SSID profile default is bound to a VAP profile.

    After an SSID profile is bound to a VAP profile, parameter settings in the SSID profile take effect on all APs using the VAP profile.
