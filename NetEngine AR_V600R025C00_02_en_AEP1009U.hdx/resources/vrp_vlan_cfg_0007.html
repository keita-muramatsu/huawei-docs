Adding and Removing VLAN Tags

Interfaces process data frames as tagged or untagged based on their interface types and default VLANs. Table 1 describes how access, trunk, and hybrid interfaces process data frames.

To improve the efficiency of data frame processing, all data frames inside a device carry VLAN tags so that the device can process them in a unified manner.

Table 1 Data frame processing modes of different interfaces

Interface Type

Processing a Received Frame

Processing a Frame to Be Sent

Access interface
Checks whether the received frame carries a VLAN tag:
  • Tags the frame with its PVID if the frame does not carry a VLAN tag.
  • Accepts the frame only when the frame carries a VLAN tag with the same VLAN ID as the PVID. Otherwise, the frame is discarded.

Removes the PVID tag from the frame before sending it.

Trunk interface

Checks whether the received frame carries a VLAN tag:

  • Tags the frame with its PVID if the frame does not carry a VLAN tag. The interface accepts this frame if the PVID carried is specified in the allowed VLAN ID list. Otherwise, the frame is discarded.
  • Accepts the frame if it carries a tag with a VLAN ID specified in the allowed VLAN ID list. Otherwise, the frame is discarded.

Checks the VLAN tag of the frame to be sent:

  • If the VLAN ID in the tagged frame is the same as the PVID of the interface and the VLAN is allowed, the interface removes the VLAN tag from the frame before sending it.
  • If the VLAN ID in the tagged frame is different from the PVID of the interface and the VLAN ID is allowed, the interface sends the frame without removing the carried tag. If the VLAN ID in the tagged frame is denied, the interface discards the frame.

Hybrid interface

Checks whether the received frame carries a VLAN tag:

  • Tags the frame with its PVID if the frame does not carry a VLAN tag. The interface accepts this frame if the PVID carried is specified in the allowed VLAN ID list. Otherwise, the frame is discarded.
  • Accepts the frame if it carries a tag with a VLAN ID specified in the allowed VLAN ID list. Otherwise, the frame is discarded.
NOTE:

Trunk and hybrid interfaces process received frames in the same manner.

Checks whether the interface allows the frame to pass through:

  • If so, the interface sends the frame. You can configure whether or not the frame is sent VLAN-tagged.
  • If not, the frame is discarded.
