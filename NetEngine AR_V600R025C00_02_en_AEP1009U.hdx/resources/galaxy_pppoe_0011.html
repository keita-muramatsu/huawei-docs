Enabling the PPPoE Client Function on an Interface

Context

You need to bind a dialer interface to a physical interface to implement the PPPoE client function.

Before enabling the PPPoE client function on an interface for it to establish a PPPoE session, you need to create a dialer interface for the session and create a dialer bundle that uniquely corresponds to the session on the interface.

The device supports auto dial-up: When the physical link is up, the device immediately initiates a PPPoE call and establishes a PPPoE session. The PPPoE session exists permanently unless it is deleted.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the interface view.

    interface interface-type interface-number

  3. Create a dialer bundle for a PPPoE session, and bind the interface to the specified dialer interface and the dialer bundle.

    pppoe-client dialer number bundle-number bundle-number [ ppp-max-payload value | service-name name ] *

    An Ethernet interface can be configured with multiple PPPoE sessions. That is, an Ethernet interface can be associated with multiple dialer bundles. However, a dialer bundle or a dialer interface can be associated with only one Ethernet interface.

    One PPPoE session corresponds to only one dialer bundle. If the dialer bundle of a dialer interface has been associated with an Ethernet interface for PPPoE, the dialer bundle cannot be associated with any other interface. This means that a dialer bundle associated with an Ethernet interface cannot be associated with the interface with which it needs to be associated.

  4. Return to the system view.

    quit

  5. Configure a static route to ensure PPPoE client and PPPoE server are mutually reachable.

    Configure an IPv4 static route.

    ip route-static ip-address { mask | mask-length } { interface-name | interface-type interface-number }

    Configure an IPv6 static route.

    ipv6 route-static dest-ipv6-address prefix-length { interface-name | interface-type interface-number }
