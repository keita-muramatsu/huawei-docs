Configuring Per-Packet Power Control for VIP Users

Prerequisites

Before performing the configuration, you have completed the following tasks:
  • Configure AP onboarding and STA access.
  • Configure VIP users. For details, see "(Optional) Configuring VIP Users" in CLI Configuration Guide > AAA Configuration.

Context

Enabling per-packet power control for VIP users can greatly improve the performance gains for VIP users in weak coverage scenarios.

This function takes effect only in a 5 GHz profile and for AirEngine X776 series APs.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a 5 GHz radio profile and enter its view.

    radio-5g-profile name profile-name

  4. Enable per-packet power control for VIP users.

    undo vip-user per-packet-tpc disable

    By default, per-packet power control for VIP users is enabled.

  5. Bind the radio profile.

    Bind the radio profile to an AP group or a single AP so that the configuration in the profile can take effect. For details, see Radio Profile.
