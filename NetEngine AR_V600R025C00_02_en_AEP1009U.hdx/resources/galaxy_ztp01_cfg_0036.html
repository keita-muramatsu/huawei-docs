Starting USB-based Deployment

Context

USB-based deployment can be performed for unconfigured devices and devices with a configuration file.

  • If a device starts with empty configuration, deployment directly starts. You can skip steps 1, 2, and 3.
  • If a device needs to be deployed with a configuration file, you need to enable the USB-based deployment function for the device in advance.

The intermediate file in Python format applies only to USB-based deployment of unconfigured devices.

Procedure

  1. Perform the following steps based on whether the device is an unconfigured device.

    • For an unconfigured device, enable the ZTP function.
      set ztp enable

      By default, the ZTP function is enabled on a device. After an unconfigured device is powered on and starts, the ZTP process is automatically executed. Therefore, you do not need to perform this step.

      To disable an unconfigured device from running the ZTP process upon startup, run the set ztp disable command on the device.

      This command does not take effect for USB-based deployment on a device with a configuration file.

    • For a device with a configuration file, enable the USB-based deployment function.
      1. Enter the system view.
        system-view
      2. Enable the USB-based deployment function for a device with a configuration file.
        ztp usb-deployment enable
        By default, the USB-based deployment function is not enabled for a device with a configuration file.
        • This command takes effect only when a USB flash drive is inserted into the device that has a configuration file.
        • It is recommended that you run the undo ztp usb-deployment enable command to disable the USB-based deployment function for the configured device after the deployment is complete. Otherwise, an unnecessary upgrade will be triggered if a USB flash drive is inserted into the device by mistake, causing service interruption.
      3. Exit the system view.
        quit

  2. (Optional) Restart the unconfigured device.

    reboot fast

  3. Insert the USB flash drive into the device to start deployment.
