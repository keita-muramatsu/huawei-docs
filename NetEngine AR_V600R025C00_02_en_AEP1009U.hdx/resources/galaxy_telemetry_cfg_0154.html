Obtaining and Saving .proto Files and Tools

Procedure

  1. Obtain .proto files.

    The method of downloading .proto files is similar to that of downloading device system software packages.

    1. Visit the Huawei enterprise technical support website (https://support.huawei.com/enterprise) or Huawei carrier technical support website (https://support.huawei.com/carrier), and search for the required device model and version.
    2. Open the software download page and obtain .proto files of the required version.

    Obtain the following .proto files: huawei-grpc-dialout.proto, huawei-cpu-memory.proto for interconnection adaptation, and huawei-telemetry.proto.

  2. Obtain the required tool.

    Obtain the Python compiler tool protoc to generate Python code for serializing and deserializing data defined in .proto files.

    Download the tool from https://github.com/protocolbuffers/protobuf/releases.

    For example, download protoc-33.2-win64.zip to the local PC.

  3. Install Python packages.

    1. Install the Python protobuf package.
      pip install protobuf
    2. Install the Python package for gRPC.
      pip install grpcio
pip install grpcio-tools googleapis-common-protos
