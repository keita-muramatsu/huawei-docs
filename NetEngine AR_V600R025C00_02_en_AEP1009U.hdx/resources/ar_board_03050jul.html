This button is used to reset the device.

Table 5 Ports on the SPU-700H
Port Connector Type Description Available Components
GE combo interface

GE electrical interface: RJ45

GE optical interface: SFP

A GE combo interface consists of an optical Ethernet interface and an electrical Ethernet interface on the panel. The two interfaces have only one internal forwarding interface. The electrical and optical interfaces are multiplexed, and only either of them can work at a time. When either of the Ethernet interfaces is working, the other interface is shut down.

The GE electrical interface (10/100/1000 Mbit/s auto-sensing) transmits and receives service traffic at 10 Mbit/s, 100 Mbit/s, or 1000 Mbit/s.

  • Standards compliance: IEEE 802.3, IEEE 802.3u, and IEEE 802.3ab
  • Working mode: full-duplex (10/100/1000 Mbit/s auto-sensing)
  • Maximum transmission distance: 100 m

The GE optical interface (100/1000 Mbit/s auto-sensing) transmits and receives service traffic at 100 Mbit/s or 1000 Mbit/s.

NOTE:

1. By default, a combo interface works as an electrical interface. You can run the combo enable fiber command to configure the combo interface to work as an optical interface.

2. All WAN-side GE interfaces can be switched to LAN-side interfaces.

GE electrical interface:

Ethernet cable

GE optical interface:

  • FE SFP&eSFP optical modules
  • GE eSFP optical modules
  • GPON&EPON optical modules
10GE optical interface LC/PC

A 10GE optical interface (1/10 Gbit/s auto-sensing) transmits and receives service data at 1000 Mbit/s or 10 Gbit/s.

  • Optical interface attributes: determined by the optical module used.
  • Standards compliance: IEEE 802.3ae
NOTE:

All WAN-side 10GE interfaces can be switched to LAN-side interfaces.
  • GE eSFP optical modules
  • GE SFP copper modules
  • 10GE SFP+ optical modules
  • GPON&EPON optical modules
  • 10GE SFP+ copper modules (supported in V600R023C10 and later versions)
40GE optical interface QSFP+

Transmits and receives services at 40 Gbit/s.

NOTE:

All WAN-side 40GE interfaces can be switched to LAN-side interfaces.

Functions and Features

Table 6 Functions and features of the SPU-700H
Functions and Features Description
Basic function The service processing unit (SPU) is the service processing center of the entire system. It provides high-speed non-blocking data channels to forward services between service modules.
Hot swapping Hot swapping is not supported.
Restrictions and remarks If the SPU fails, the functions of the entire device are unavailable.
