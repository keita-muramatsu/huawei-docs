Configuring the Source Address of User Status Detection Packets

Context

The device sends an ARP probe packet to check the status of a user. If the user does not respond within a detection period, the device determines that the user is offline.

  • This function takes effect only for wired users.
  • In normal situations, after a device sends an ARP probe packet with the default source IP address, online clients will immediately respond with ARP reply packets. If clients are online but do not respond with ARP reply packets, the device logs them out. To resolve this problem, use either of the following methods:
    • Run the access-user arp-detect vlan vlan-id ip-address ip-address mac-address mac-address command to specify the VLAN ID, source IP address, and source MAC address of ARP probe packets.
    • Run the authentication timer handshake-period handshake-period command to increase the handshake period. The device can identify the gratuitous ARP packets sent by clients, but these packets are sent at irregular intervals. To ensure that the device can detect the ARP packets sent by the clients that do not respond to ARP probe packets immediately, increase the handshake period properly.

Procedure

  1. Enter the system view.

    system-view

  2. Configure the source address of user status detection packets.

    • Configure the default source IP address of user status detection packets.

      access-user arp-detect default ip-address ip-address

      By default, the default source IP address of user status detection packets is 0.0.0.0.

    • Configure the source IP address and source MAC address of user status detection packets in a VLAN.
      access-user arp-detect vlan vlan-id ip-address ip-address mac-address mac-address

      By default, the source IP address and source MAC address of user status detection packets are not specified in a VLAN.

      You are advised to set the user gateway IP address and MAC address as the source IP address and source MAC address of user status detection packets.

    • Configure the IP address required for calculating the source address of user status detection packets.

      access-user arp-detect fallback ip-address { ip-mask | mask-length }

      By default, no IP address is configured for calculating the source address of user status detection packets.

    The following source IP addresses used by user status detection packets are listed in descending order of priority:

    1. IP address of the VLANIF interface corresponding to the VLAN to which the user belongs, which is on the same network segment as the user
    2. Source IP address configured using the access-user arp-detect vlan vlan-id ip-address ip-address mac-address mac-address command in a VLAN
    3. Source address calculated based on the IP address configured using the access-user arp-detect fallback ip-address { mask | mask-length } command
    4. Default source IP address configured using the access-user arp-detect default ip-address ip-address command

  3. (Optional) Configure the delay in sending user status detection packets.

    access-user arp-detect delay interval-value

    By default, the delay in sending user status detection packets is 10s.
