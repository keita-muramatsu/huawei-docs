Overview of STUN

Definition

The Session Traversal Utilities for NAT (STUN) protocol defined by Request For Comments (RFC) is used to discover NAT devices located along the path between two devices and to allow packets to traverse the NAT devices.

Purpose

NAT is widely deployed to mitigate the exhaustion of IPv4 addresses. It also protects against attacks from external networks by dropping some packets sent from external networks to the internal network. However, it is not suitable for point-to-point (P2P) communication, such as a P2P network, since it cannot enable two P2P communicating parties to initiate access, thereby affecting the normal running of P2P applications.

STUN technology is developed to overcome this NAT traversal problem. It provides a tool for network devices to discover their post-NAT IP addresses and port numbers and to use this information to establish P2P data channels for communication.

Benefits

  • Packets can traverse NAT devices with unchanged network structure and NAT device configurations.

  • Security authentication and message integrity check enhance the security and reliability of NAT traversal.
