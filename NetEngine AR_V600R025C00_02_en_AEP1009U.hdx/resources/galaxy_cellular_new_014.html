Example for Configuring Access to Data and Voice Services Through Two Cellular Channel Interfaces

Networking Requirements

A remote branch of an enterprise has no access to the wired WAN access service. The branch requires data service communication with the headquarters through the Internet, and also requires voice service communication with the headquarters.

In Figure 1, to meet service requirements, the branch uses DeviceA and binds two cellular channel interfaces to different APNs—one used for data service communication and the other used for voice service communication. The network to be accessed needs to be automatically selected.

The carrier provides the following information:

  • APN for data service access: data (user name: 5g-example; password: YsHsjx_202206; authentication mode: CHAP)
  • APN for voice service access: voice
Figure 1 Network diagram for configuring two APNs for data and voice services

Configuration Roadmap

The configuration roadmap is as follows:

  1. Configure a network connection mode.
  2. Configure APN profiles and bind them to cellular channel interfaces.
  3. Enable the dial-up function on the cellular channel interfaces. Then configure a default route and a static route, with their outbound interfaces being the cellular channel interfaces for data and voice services respectively.

Procedure

  1. Create a cellular profile, set the network connection mode to auto, and apply the profile to a cellular interface.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] cellular-profile 5g
[DeviceA-cellular-profile-5g] mode auto
[DeviceA-cellular-profile-5g] quit
[DeviceA] interface cellular 2/0/0
[DeviceA-Cellular2/0/0] cellular-profile 5g
[DeviceA-Cellular2/0/0] quit

  2. Configure APN profiles.

    # Configure an APN profile named datanet for data service network access.

    [DeviceA] apn-profile datanet
[DeviceA-apn-profile-datanet] user name 5g-example password YsHsjx_202206 authentication-mode chap
[DeviceA-apn-profile-datanet] apn data
[DeviceA-apn-profile-datanet] quit

    # Configure an APN profile named voicenet for voice service network access.

    [DeviceA] apn-profile voicenet
[DeviceA-apn-profile-voicenet] apn voice
[DeviceA-apn-profile-voicenet] quit

  3. Configure dial-up on the cellular channel interfaces and bind the corresponding APN profiles to them.

    # Bind the APN profile datanet to cellular channel interface 1 and configure auto dial-up.

    [DeviceA] interface cellular 2/0/0:1
[DeviceA-Cellular2/0/0:1] apn-profile datanet
[DeviceA-Cellular2/0/0:1] ip address modem-alloc
[DeviceA-Cellular2/0/0:1] quit

    # Bind the APN profile voicenet to cellular channel interface 2 and configure auto dial-up.

    [DeviceA] interface cellular 2/0/0:2
[DeviceA-Cellular2/0/0:2] apn-profile voicenet
[DeviceA-Cellular2/0/0:2] ip address modem-alloc
[DeviceA-Cellular2/0/0:2] quit

  4. Configure static routes.

    # Assume that DeviceA needs to exchange voice services with the peer network segment 10.1.2.0/24. Configure static routes. The data service is sent through the default route, with the outbound interface being Cellular2/0/0:1. The voice service is sent through another static route, with the outbound interface being Cellular2/0/0:2.

    [DeviceA] ip route-static 0.0.0.0 0 cellular 2/0/0:1
[DeviceA] ip route-static 10.1.2.0 255.255.255.0 cellular 2/0/0:2

Verifying the Configuration

# After the configuration is complete, the device can exchange data and voice services with corresponding networks simultaneously.
