Configuring HDLC as the Encapsulation Protocol of an Interface

Configure HDLC as the link layer encapsulation protocol of an interface.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the interface view.

    interface interface-type interface-number

    Only POS and serial interfaces support HDLC.

  3. Configure HDLC as the link layer encapsulation protocol of the interface.

    link-protocol hdlc

  4. (Optional) After a POS interface is configured with HDLC and added to an IP-Trunk, you can configure the IP-Trunk to implement functions such as link backup and load balancing.

    For details, see Configuring an IP-Trunk Interface.
