Example for Configuring a DHCPv6 PD Server

Networking Requirements

On the network shown in Figure 1, DeviceA is required to function as a DHCPv6 PD server and assign an IPv6 address prefix to the DHCPv6 PD client. To meet this requirement, configure DeviceA as a DHCPv6 PD server to assign IPv6 addresses and other network configuration parameters to users. This facilitates unified management and implements hierarchical IPv6 deployment. The DHCPv6 PD client and server are located on the same link.

Figure 1 Network diagram of configuring the DHCPv6 PD server

In this example, Interface1 represents 10GE0/0/1.


Configuration Roadmap

The configuration roadmap is as follows:

  1. Enable IPv6 on the interface to implement IPv6 communication.

  2. Enable the DHCPv6 PD server function so that the device can assign an IPv6 address prefix through DHCPv6.

Precautions

To enable a device to process STA IPv6 services in wireless scenarios, run the sta-ipv6-service enable command in the WLAN view.

Procedure

  1. Enable DHCP.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] dhcp enable

  2. Configure a DHCPv6 PD server.

    [DeviceA] dhcpv6 pool pool1 
[DeviceA-dhcpv6-pool-pool1] prefix-delegation fc00:1::/60 63  
[DeviceA-dhcpv6-pool-pool1] quit

  3. Configure the IPv6 function on the interface.

    [DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] undo portswitch
[DeviceA-10GE0/0/1] ipv6 enable
[DeviceA-10GE0/0/1] ipv6 address fc00:1::1/64

  4. Enable the DHCPv6 PD server function on the interface.

    [DeviceA-10GE0/0/1] dhcpv6 server pool1

  5. Configure the M and O flags in RA messages so that the DHCPv6 PD client can learn the route to the IPv6 gateway through the messages.

    [DeviceA-10GE0/0/1] ipv6 nd ra halt disable
[DeviceA-10GE0/0/1] ipv6 nd autoconfig managed-address-flag
[DeviceA-10GE0/0/1] ipv6 nd autoconfig other-flag
[DeviceA-10GE0/0/1] quit
[DeviceA] quit

  6. Configure an IPv6 static route to the network segment (fc00:1::) where the hosts reside, with the next-hop IPv6 address being the peer interface's IPv6 global unicast address (FC00:3::865B:12FF:FE36:595B).

    [DeviceA] ipv6 route-static fc00:1:: 64 FC00:3::865B:12FF:FE36:595B

  7. Verify the configuration.

    # Run the display dhcpv6 pool command on DeviceA to check information about the DHCPv6 address pool.

    <DeviceA> display dhcpv6 pool pool1
DHCPv6 pool: pool1
-------------------------------------------------------------------------------
  Prefix delegation: 
    FC00:1::/60 63
    Lifetime valid 172800 seconds, preferred 86400 seconds
    0 in use
-------------------------------------------------------------------------------
  Information refresh time    : 86400(s)
  Conflict-address expire-time: 172800(s)
  Renew-time-percent          : 50
  Rebind-time-percent         : 80
  Active normal clients       : 0
  Active pd clients           : 0
  Logging                     : Disable
  VPN instance                : _public_
  VPN match                   : Enable

    # Run the display dhcpv6 server command on DeviceA to check information about the DHCPv6 server.

    <DeviceA> display dhcpv6 server
  Interface                                DHCPv6 pool                           
  10GE0/0/1                                pool1
