Configuring the Device to Allow High Inrush Current During Power-On

Context

High inrush current is generated when a non-standard PD is powered on. In this case, the AP cuts off the power of the PD to protect itself. If the PSE is required to provide power for the PD, the PSE must allow high inrush current.

If high inrush current is allowed, the self-protection function of the AP is disabled. This may damage components of the PD.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP system profile and enter its view.

    ap-system-profile name profile-name

    By default, the AP system profile default exists on the device.

  4. Configure the device to allow high inrush current during power-on.

    poe high-inrush enable

    By default, APs do not allow high inrush current during power-on.
