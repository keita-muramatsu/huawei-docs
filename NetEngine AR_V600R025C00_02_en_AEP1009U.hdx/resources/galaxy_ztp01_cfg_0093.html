Verifying Registration Query Center-based Deployment

Context

During ZTP, you can perform the following operations to check whether ZTP is complete:

  • Configure a Syslog server to upload user logs recorded during the ZTP process to the NMS.
  • Check the device management status on the controller.

After ZTP is completed, you can log in to the device to view the deployment result.

Procedure

  1. After the ZTP process is completed, log in to the device to check the NETCONF connection status between the device and iMaster NCE-Campus.

    display netconf session

Follow-up Procedure

If deployment fails, analyze ZTP logs on the device to determine the cause. ZTP logs are saved in the file named ztp_YYYYMMDDHHMMSS.log in the flash:/ directory. If the Syslog server is configured on the device, you can also view the error cause on the NMS.
