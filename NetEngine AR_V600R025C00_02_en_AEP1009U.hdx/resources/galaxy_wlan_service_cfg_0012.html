Security Profile

Overview

A security profile allows you to configure a WLAN security policy to authenticate STAs and encrypt STA packets, securing both the WLAN and STAs.

After configuring a security profile, you need to bind it to a VAP profile so that STAs attempting to access the WLAN are authenticated based on the security policy configured in the VAP profile. For details, see "Configuring a Security Policy" in CLI Configuration Guide > WLAN Configuration > WLAN Security Configuration.

Creating a Profile

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a security profile and enter its view.

    security-profile name profile-name

    By default, the security profile default exists in the system.

Applying a Profile

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a VAP profile and enter its view.

    vap-profile name profile-name

    By default, the VAP profile default exists in the system.

  4. Bind a security profile to the VAP profile.

    security-profile profile-name

    By default, the security profile default is bound to a VAP profile.

  5. Return to the WLAN view.

    quit

  6. Bind the VAP profile. Perform any of the following operations as required:
    • Bind the VAP profile to an AP group.
      ap-group name group-name
vap-profile profile-name wlan wlan-id radio { radio-id | all } [ service-vlan vlan-id vlan-id ]

      By default, no VAP profile is bound to a radio.

    • Bind the VAP profile to an AP.
      ap-id ap-id
vap-profile profile-name wlan wlan-id radio { radio-id | all } [ service-vlan vlan-id vlan-id ]

      By default, no VAP profile is bound to a radio.

    • Apply a VAP profile in the AP group view and specify the radio on which the VAP profile takes effect.
      ap-group name group-name
vap-profile profile-name wlan wlan-id radio-policy { 2.4g | 5g | 6g | all }

      By default, no VAP profile is bound to an AP group or a specific AP, and no radio is specified for a VAP profile to take effect.

    • Apply a VAP profile in the AP view and specify the radio on which the VAP profile takes effect.
      ap-id ap-id
vap-profile profile-name wlan wlan-id radio-policy { 2.4g | 5g | 6g | all }

      By default, no VAP profile is bound to an AP group or a specific AP, and no radio is specified for a VAP profile to take effect.

    • Bind the VAP profile to radios on APs in an AP group.
      ap-group name group-name
radio radio-id
vap-profile profile-name wlan wlan-id [ service-vlan vlan-id vlan-id ]

      By default, no VAP profile is bound to a radio.

    • Bind the VAP profile to radios on an AP.
      ap-id ap-id
radio radio-id
vap-profile profile-name wlan wlan-id [ service-vlan vlan-id vlan-id ]

      By default, no VAP profile is bound to a radio.

    • Bind the VAP profile to all AP groups in the WLAN view.
      ap-group all vap-profile profile-name wlan wlan-id radio { radio-id | all }

      By default, no VAP profile is bound to radios of APs in an AP group.
