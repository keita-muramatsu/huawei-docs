Configuring the Output of System Logs

Context

The device can output the information generated when each function module is running to the log server, log buffer, log file, console, and terminal through the information center. For details about how to output logs, see "Configuring Log Output" in CLI Configuration Guide > System Management Configuration > Information Management Configuration, as shown in Table 1.
