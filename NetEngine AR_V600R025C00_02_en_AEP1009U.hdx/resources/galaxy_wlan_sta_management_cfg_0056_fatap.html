Configuring Preferential Access of VIP Users

Prerequisites

Before configuring preferential access of VIP users, ensure that basic service coverage and user access authentication have been configured on the user network by completing the following tasks:
  • Configure basic WLAN STA access functions.
  • Configure NAC.
  • Configure VIP users. For details, see "(Optional) Configuring VIP Users" in CLI Configuration Guide > AAA Configuration.

Context

In some high-density scenarios such as exhibition halls and stadiums, a large number of STAs may connect to a single radio or VAP if the number of access STAs on the radio or VAP is not limited. These STAs operate on the same channel, and concurrent services and air interface contention may occur, degrading user experience.

Therefore, the number of access STAs on a radio or VAP usually needs to be limited in these scenarios. Once the number of access STAs on the radio or VAP reaches the maximum, new STAs are not allowed to access the network. This, however, causes VIP users to fail to access the network, affecting VIP user experience.

In this case, preferential access of VIP users can be configured to allow VIP users to access the network and disconnect online non-VIP users when the number of access users reaches the threshold. This ensures access experience of VIP users.

Figure 1 Network diagram of preferential access of VIP users

Preferential access of VIP users can be configured based on a radio or VAP. You can configure either of the two modes or both.

When configuring preferential access of VIP users, pay attention to the following:
  • Preferential access of VIP users is not supported in Portal authentication scenarios.
  • Offline APs do not support preferential access of VIP users.
  • When the number of access users reaches the maximum, preferential access of VIP users no longer takes effect.
  • If the number of users reaches the threshold, Huawei IdeaHub series are regarded as VIP users and will replace non-VIP users who have accessed the network. Huawei IdeaHub series include Huawei Vision includes IdeaHub S, IdeaHub Pro, IdeaHub Enterprise, and IdeaHub NEO. The earliest version is 21.0.0.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Configure preferential access of VIP users based on the number of CAC users or VAPs. You can perform either or both of the following steps:
    • Configuring preferential access of VIP users based on the number of CAC users
      1. Create an RRM profile and enter its view.
        rrm-profile name profile-name
      2. Enable CAC based on the number of users.
        uac client-number enable

        By default, the CAC function is disabled.

      3. Configure the user CAC access threshold based on the number of STAs.
        uac client-number threshold access access-threshold

        By default, the user CAC access threshold based on the number of users is 64.

      4. Enable the function of replacing existing users with new ones based on priorities when the number of access users reaches the user CAC access threshold based on the number of users.
        uac reach-access-threshold priority-replace

        By default, after the number of access users reaches the threshold, the SSID is not hidden, and existing access users are not replaced based on priorities.

      5. Apply an RRM profile. For details, see Applying a Profile.
    • Configuring preferential access of VIP users based on VAPs
      1. Create an SSID profile and enter its view.
        ssid-profile name profile-name
      2. Set the maximum number of STAs that can be associated with a single VAP.
        max-sta-number max-sta-number

        By default, a VAP allows for a maximum of 64 successfully associated STAs.

      3. Enable the function of replacing existing STAs with new STAs based on priorities when the number of access STAs on a VAP reaches the maximum.
        reach-max-sta priority-replace

        By default, automatic SSID hiding is enabled and the function of replacing low-priority STAs with high-priority STAs is disabled when the number of access STAs reaches the maximum.

      4. Return to the WLAN view.
        quit
      5. Create a VAP profile and enter its view.
        vap-profile name profile-name
      6. Bind an SSID profile to the VAP profile.
        ssid-profile profile-name
      7. Apply a VAP profile. For details, see Applying a Profile.

Verifying the Configuration

  • Run the display rrm-profile name profile-name command to check information about an RRM profile.
  • Run the display references rrm-profile name profile-name command to check reference information about an RRM profile.
  • Run the display vap-profile { all | name profile-name } command to check the configuration and reference information about a VAP profile.
  • Run the display references vap-profile name profile-name command to check reference information about a VAP profile.
  • Run the display ssid-profile { all | name profile-name} command to check configuration and reference information about an SSID profile.
  • Run the display references ssid-profile name profile-name command to check reference information about an SSID profile.
