(Optional) Binding an IPv6 Address Pool to a VPN

Context

If a DHCPv6 server and client are located on different VPNs or the DHCPv6 server needs to assign IPv6 addresses to clients on different VPNs, bind IPv6 address pools to VPNs. The same network segment can be configured for IPv6 address pools belonging to different VPNs. This improves IPv6 address utilization, prevents IPv6 address conflicts, and allows DHCPv6 clients in different VPNs to be assigned the same IPv6 address.

After receiving a request message from a DHCPv6 client, the DHCPv6 server selects an IPv6 address pool in the following sequence:

  1. The server preferentially checks the IPv6 address pool bound to the corresponding interface. If the VPN information of this address pool is the same as that of the client, the server uses the IPv6 address pool to assign IPv6 addresses.
  2. If the VPN information is different, the server globally selects an IPv6 address pool that belongs to the same link scope and VPN based on the link scope and VPN information of the client.
  3. If no IPv6 address pool with the same VPN information can be found globally, the server selects an IPv6 address from the IPv6 address pool for which VPN check is disabled using the vpn-instance match disable command based on the link scope of the client.
  • The VPN information of the DHCPv6 client is carried in Option 68. If the request message does not carry this option, the VPN configuration of the DHCPv6 server's interface that receives the request message is used.
  • The VPN instance bound to an IPv6 address pool must be the same as that bound to a DHCPv6 relay agent. Specifically, the VPN instance must be the same as the VPN instance configured using the dhcpv6 relay destination ipv6-address vpn-instance vpn-instance-name command in the interface view or the VPN instance configured using the vpn-instance vpn-instance-name command in the DHCPv6 server group view on the DHCPv6 relay agent.

Procedure

  1. Enter the system view.

    system-view

  2. Create an IPv6 address pool and enter its view.

    dhcpv6 pool pool-name

    By default, no IPv6 address pool is created on a device.

  3. Enable VPN check for the IPv6 address pool.

    undo vpn-instance match disable

    By default, VPN check is enabled for an IPv6 address pool.

  4. Bind a VPN instance to the IPv6 address pool.

    vpn-instance vpn-name

    By default, no VPN instance is bound to any IPv6 address pool.
