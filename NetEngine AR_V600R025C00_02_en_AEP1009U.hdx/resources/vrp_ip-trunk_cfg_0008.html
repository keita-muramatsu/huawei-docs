Configuring an IP-Trunk Interface

An IP-Trunk interface is a type of trunk interface that supports link backup and traffic load balancing.

Application Scenarios

To enhance link communication capabilities, you can bundle multiple POS interfaces into an IP-Trunk interface. The total bandwidth of an IP-Trunk interface is the combined bandwidth of all its member interfaces. Configuring an IP-Trunk interface effectively increases the interface bandwidth.

An IP-Trunk interface enables load balancing by distributing traffic across multiple links, preventing a single link from being overloaded with traffic to the same destination.

An IP-Trunk interface improves link reliability. If a member link of the IP-Trunk interface fails, traffic is automatically switched to another available link, improving overall IP-Trunk link reliability.

The encapsulation protocol running on IP-Trunk member interfaces can only be HDLC. The fundamentals of IP-Trunk are similar to those of Eth-Trunk. For details, see Understanding Eth-Trunk.

Prerequisites

Before configuring an IP-Trunk interface, you have completed the following task:

  • Power on the device and ensure that the self-check is successful.

    Creating an IP-Trunk Interface and Adding Interfaces to the IP-Trunk Interface
    Create an IP-Trunk interface and add interfaces to the IP-Trunk interface.
    (Optional) Setting the Lower Threshold for the Number of Up IP-Trunk Member Interfaces
    The lower threshold for the number of up member interfaces specifies the minimum number of member interfaces required to be in the up state for the bundled IP-Trunk interface to remain up. When the number of member interfaces in the up state falls below the specified lower threshold, the IP-Trunk interface goes down. Conversely, when the number of member interfaces in the up state reaches the lower threshold, the IP-Trunk interface goes up.
    (Optional) Configuring a Trap Message Sending Method for IP-Trunk Member Interfaces
    You can configure IP-Trunk member interfaces to send trap messages through a private message information base (MIB).
    (Optional) Resetting Statistics on an IP-Trunk Interface
    You can reset the existing statistics on an interface before re-collecting traffic statistics on the interface.
    Verifying the Configuration
    After configuring an IP-Trunk interface, you can check the status and forwarding table of the IP-Trunk interface and information about its member interfaces.
