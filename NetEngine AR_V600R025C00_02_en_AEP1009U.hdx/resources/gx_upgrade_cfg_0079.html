Example for Configuring Smart Upgrade

Networking Requirements

When a large number of devices need to be upgraded to the recommended version, you can configure smart upgrade to implement fast upgrade.

As shown in Figure 1, DeviceA, DeviceB, and DeviceC reside on the public network and can communicate with the HOUP through the Internet.

The configurations of DeviceA, DeviceB, and DeviceC are similar. This section uses DeviceA as an example.

Figure 1 Network diagram for upgrading a new device

Configuration Roadmap

  1. Import the initial CA certificate to the default domain.
  2. Configure the device to communicate with the HOUP server.
  3. Execute the smart upgrade task.

Configuration Precautions

  • The basic software package contains the initial certificate HOUP_Actalis_CA.cer. When loading the basic software package, the device automatically saves the certificate to the flash:/pki/public directory.
  • If the certificate does not exist or has expired, perform the following operations to obtain or update the certificate:
    1. Download the certificate: Click https://houp.huawei.com/download/public/houp.huawei.com.zip to download the certificate.
    2. Upload the certificate: Upload the certificate to the flash:/pki/public directory of the device through FTP or SFTP. For details, see Managing Files Using FTP/Managing Files Using SFTP. SFTP is recommended because it is more secure than FTP.

Procedure

  1. Import the initial CA certificate to the default domain.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] pki import-certificate ca realm default pem filename HOUP_Actalis_CA.cer

  2. Configure the device to communicate with the HOUP server.

    # Load an SSL policy.

    [DeviceA] ssl policy policy1
[DeviceA-ssl-policy-policy1] pki-domain default //Bind the name of the PKI realm to which the initial certificate is loaded to the SSL policy.
[DeviceA-ssl-policy-policy1] quit

    # In the smart upgrade view, configure the URL of the server and bind the SSL policy.

    [DeviceA] smart-upgrade
[DeviceA-smart-upgrade] http url https://houp.huawei.com
[DeviceA-smart-upgrade] http ssl-policy policy1
[DeviceA-smart-upgrade] quit

Verifying the Configuration

# Wait several minutes until the device restart is complete. Then run the display version command to check the current system version. If the version is new, the upgrade has succeeded.

Configuration Scripts

#
sysname DeviceA
#
ssl policy policy1
 pki-domain default
# 
smart-upgrade
 http url https://houp.huawei.com
 http ssl-policy policy1
#
return
