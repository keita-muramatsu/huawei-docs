(Optional) Configuring Proprietary RADIUS Attributes

Context

The content or format of some proprietary RADIUS attributes of Huawei or other vendors can be configured.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the RADIUS server template view.

    radius-server template template-name

  3. Configure Huawei proprietary RADIUS attributes.

    • Configure the format of Huawei proprietary RADIUS attribute 26-158 (HW-DHCP-Option).
      radius-server hw-dhcp-option-format { new | old }

      By default, the format of Huawei proprietary RADIUS attribute 26-158 (HW-DHCP-Option) is old.

    • Configure the device to delete specified information from the URL contained in the Huawei RADIUS attribute 26-156 (HW-Portal-URL).
      radius-attribute cut hw-portal-url key-words [ end mark ]

      By default, the device does not process the URL contained in the Huawei RADIUS attribute 26-156 (HW-Portal-URL).

    • Configure the device to contain the AP's IP address in Huawei proprietary RADIUS attribute 26-141 (HW-AP-Information).
      radius-server hw-ap-info-format include-ap-ip

      By default, the device does not contain the AP's IP address in Huawei proprietary RADIUS attribute 26-141 (HW-AP-Information).

  4. Configure proprietary RADIUS attributes of other vendors.

    Enable the RADIUS packets sent by the device to carry the Cisco proprietary attribute cisco-avpair:audit-session-id.
    radius-attribute auth-session-id enable

    By default, the RADIUS packets sent by the device do not carry the Cisco proprietary attribute cisco-avpair:audit-session-id.
