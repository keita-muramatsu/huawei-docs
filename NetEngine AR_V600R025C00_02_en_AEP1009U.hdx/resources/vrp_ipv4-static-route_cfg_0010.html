Understanding IPv4 Static Route Selection Rules

IPv4 static route selection rules are as follows:

  1. In accordance with the longest match rule, a route with the longest matching prefix and mask is preferred.
  2. If routes have the same prefix and mask, the route with the smallest preference value is preferred.
  3. If the IPv4 static routes have the same prefix, mask, and preference, they perform load balancing by default.
  4. After recursion depth-based route selection is enabled for IPv4 static routes, the route with the minimum recursion depth is preferred. Route recursion means that a device finds a directly connected outbound interface based on a next-hop IP address carried in a route. Recursion depth is the number of route lookups involved during route recursion. A smaller number of recursive route lookups indicates a smaller recursion depth. If static routes have the same prefix but different recursion depths, the route with the minimum recursion depth is more stable.
  5. If recursive routes have the same recursion depth and a device is configured to compare costs of inherited routes, a recursive route with the smallest cost is preferred. By default, a device does not compare costs of inherited routes for static route selection.
