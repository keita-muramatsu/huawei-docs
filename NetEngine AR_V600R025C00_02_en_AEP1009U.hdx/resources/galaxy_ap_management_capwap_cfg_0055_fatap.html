(Optional) Adjusting CAPWAP Heartbeat Detection Parameters

Context

In CAPWAP heartbeat detection, an AP and a WAC periodically exchange Echo and Keepalive packets to determine whether the control and data tunnels are working properly, respectively. If one end of a tunnel does not receive any response from the other end after sending detection packets (Echo or Keepalive, depending on the tunnel type) for a specified number of times, the device considers that the tunnel is disconnected and needs to be re-established.
  • The CAPWAP heartbeat detection interval refers to the interval for sending Echo or Keepalive packets.
  • The number of CAPWAP heartbeat detection times refers to the number of times Echo or Keepalive packets are sent.

Radio traffic statistics packets are sent and received together with Echo packets.

Exercise caution when changing the CAPWAP heartbeat detection interval and the number of CAPWAP heartbeat detection times. The default values are recommended.

Procedure

  1. Enter the system view.

    system-view

  2. Configure the CAPWAP heartbeat detection interval and the number of detection times.

    capwap echo { interval interval-value | times times-value } *

    By default, the CAPWAP heartbeat detection interval is 25 seconds and the number of CAPWAP heartbeat detection times is 6.
