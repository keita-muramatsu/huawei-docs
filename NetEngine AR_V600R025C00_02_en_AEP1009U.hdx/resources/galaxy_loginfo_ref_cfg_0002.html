How to Search for a Log in This Document

You are advised to learn Log Format Description in advance and use the following tips to quickly search for a log:

  • A brief description uniquely identifies a log. You are advised to search for the brief description of a log in this document to quickly find the description and handling procedure of the log.
  • Do not search for logs with variable information, such as the log generation time, interface number, process ID, and device name.

This document describes logs that can be directly displayed on the command line interface (CLI) or viewed by running the display logbuffer [ starttime starttime-value [ endtime endtime-value ] | level { severity | level } | size value ] * command.
