Protocol Category

The device supports two categories of SSL protocols: TLS and DTLS

  • Transport Layer Security (TLS): a security protocol that provides data encryption, identity authentication, and integrity protection for TCP connections during Internet communications.

  • Datagram Transport Layer Security (DTLS): an adaptation of TLS. It provides similar security functions as TLS for unreliable UDP-based transmission. While preserving TLS's core encryption and authentication functions, DTLS effectively addresses packet loss, out-of-order packets, and packet size limitations in UDP transmission by adding explicit sequence numbers, an Epoch field, and a fragment control mechanism.

Fragment transmission

Data fragments are processed at the TCP transport layer.

Fragment transmission is supported. The implementation is as follows:

  • Send: Large messages (such as handshake messages) are split into multiple fragments, and each fragment is encrypted and transmitted independently.
  • Receive: Fragments are reassembled based on the Epoch field and sequence number and sorted based on the fragment offset.

Replay attack prevention
