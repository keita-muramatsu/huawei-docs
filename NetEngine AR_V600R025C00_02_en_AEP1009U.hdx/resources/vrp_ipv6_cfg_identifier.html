(Optional) Configuring the Interface Identifier Generation Mode

Context

The 64-bit interface identifier in an IPv6 address uniquely identifies an interface on a link. It is typically derived from the MAC address of the interface. Both the MAC address and the interface identifier in EUI-64 format contain a Universal/Local (U/L) bit, which indicates whether the address is universally or locally managed. Although the bit is semantically the same for the MAC address and interface identifier, its binary values have opposite meanings:

  • The meaning of the U/L bit in the MAC address is as follows:
    • 0: The address is universally managed.
    • 1: The address is locally managed.
  • The meaning of the U/L bit in the interface identifier is as follows:
    • 0: The address is locally managed.
    • 1: The address is universally managed.

If you want the meaning of the U/L bit in the interface identifier to be the same as that in the source MAC address, configure the interface identifier generation mode so that the device generates interface identifiers according to RFC standards.

Procedure

  1. Enter the system view.

    system-view

  2. Configure the device to generate interface identifiers according to RFC standards.

    ipv6 address ifid standard-compatible
