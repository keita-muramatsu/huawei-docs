License Alarms Are Generated on a Device

If a license alarm is generated on a device, refer to Table1 Procedure for handling a license alarm on a device.

Table 1 Procedure for handling a license alarm on a device

Major Information About the License Alarm

Possible Cause

Procedure

LCS/1/hwGtlNearDeadline

The license file is about to expire.

Apply for a new license file before the grace period expires.

LCS/1/hwGtlDefaultValue

The license file has expired.

After the license file expires, all default control items activated by the license are restored to default values. You need to apply for a new license file.

LCS/1/hwGtlInitial

The license file is improperly activated or the current license file has been initialized. As a result, some functions on the live network may become invalid or improper.
Check whether service functions on the live network are invalid or improper.
  • If service functions on the live network are proper and valid, you can manually clear the alarm or try to restart the device to clear the alarm.
  • If service functions on the live network are invalid or improper, you can collect alarm and configuration information, contact technical support personnel, and activate a new license file.

LCS/2/hwGtlFunctionInactive

The license control items are not activated. As a result, service functions may not be operational.

Run the display license command to check the license activation status and detailed information about the license file in the current system and then activate the license file.

LCS/2/hwGtlFeatureFunInactive
The license control items are not activated.
  • The license file is not loaded.
  • The license file has been uploaded to the device but is not activated.
  • The license file has been activated but does not contain the corresponding control items.
  • Check whether a license file has been uploaded to the device. If not, upload and activate the license file.
  • If the activated license file does not contain the corresponding control items, apply to Huawei for a license file containing the corresponding control items and activate the license file.

LCS/3/hwGtlItemMismatch

The license control items are different from those of the current device.

Apply for a license file matching the current device.
