STA Blacklist Profile

Overview

A STA blacklist profile contains MAC addresses of STAs that are forbidden to connect to a WLAN. To forbid only a few STAs to connect to the WLAN, configure a STA blacklist profile and bind it to an AP system profile or a VAP profile.

When the STA blacklist profile is bound to different types of profiles, their effective scopes are different.
  • AP system profile: The STA blacklist profile takes effect based on the AP. If an AP uses the AP system profile, the STA blacklist profile takes effect on all STAs connected to the AP (including all its VAPs).
  • VAP profile: The STA blacklist profile takes effect based on the VAP. If the STA blacklist profile is applied to an AP, the STA blacklist profile applies only to STAs connected to the corresponding VAPs.

After configuring a STA blacklist profile, you need to bind it to an AP system profile or a VAP profile. For details, see "Configuring the STA Blacklist and Whitelist" in CLI Configuration Guide > WLAN Configuration > WLAN STA Management Configuration.

Creating a Profile

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a STA blacklist profile and enter its view.

    sta-blacklist-profile name profile-name

    By default, no STA blacklist profile is created.

Applying a Profile

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Bind the STA blacklist profile to an AP system profile or VAP profile.

    • Bind a STA blacklist profile to an AP system profile.
      ap-system-profile name profile-name
sta-access-mode blacklist profile-name

      By default, no STA blacklist profile is bound to an AP system profile.

    • Bind a STA blacklist profile to a VAP profile.
      vap-profile name profile-name
sta-access-mode blacklist profile-name

      By default, no STA blacklist profile is bound to a VAP profile.

      For detailed configuration, see Applying a Profile.
