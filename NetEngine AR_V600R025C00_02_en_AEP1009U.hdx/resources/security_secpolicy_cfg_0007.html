Security Policy Exceptions

There are circumstances in which traffic is not controlled by security policies even if both the inbound and outbound interfaces are Layer 3 interfaces added to security zones:

  • Security policies control only unicast packets but not broadcast or multicast packets.

  • The protocols listed in the following table are network interconnection protocols. For security purposes, unicast packets of these protocols are controlled by security policies by default. To enable the device to quickly access the network, you can run the undo firewall packet-filter basic-protocol enable command to disable security policies from controlling the unicast packets of these protocols.

    OSPF
