Global Service Parameters of SPR

Switchover Period

The device periodically obtains the link detection result based on the interval at which link quality data is updated, and uses the detection result to determine whether the link meets service requirements. If the link does not meet service requirements, SPR starts the switchover timer. If SPR obtains a detection result indicating that the link meets service requirements before the switchover timer expires, SPR resets the timer. If SPR obtains no detection result indicating that the link meets service requirements upon expiration of the switchover timer, SPR triggers a link switchover.

Set the switchover period based on service characteristics. For example, voice services have high requirements on real-time performance, so a short switchover period should be set for such services.

Switchback Period

If the quality of a high-priority link does not meet service requirements, services are switched to a low-priority link. If the switchback function is enabled, the switchback period is configured, and the quality detection result of the high-quality link meets service requirements, the switchback timer starts. If SPR obtains a detection result indicating that the high-quality link does not meet service requirements before the switchback timer expires, SPR resets the timer. If each detection result obtained by SPR indicates that the high-priority link meets service requirements upon expiration of the switchback timer, SPR triggers a link switchback.

If the switchback period is not configured, the switchback action is triggered immediately by default. This is not advised if important services are transmitted over the low-priority link, as traffic loss will occur upon the switchback.

Flapping Suppression Period

When a network is unstable, frequent link switchovers triggered by SPR can degrade service experience. To address this problem, SPR provides the link flapping suppression function.

The flapping suppression function is disabled by default, and the flapping suppression period is configurable. After services are switched to another link, the flapping suppression timer starts. Services will then not be switched again until the timer expires.

When the flapping suppression timer expires:

  • If SPR still does not obtain detection results indicating that the link meets service requirements within the switchover period, SPR performs another link switchover.
  • If detection results obtained by SPR indicate that the link meets service requirements within the switchover period, SPR keeps traffic on the link.
