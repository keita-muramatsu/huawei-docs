Checking the MPLS QoS Configuration

Procedure

  • Run the display diffserv domain [ brief | name ds-domain-name ] command to check the DiffServ domain configuration.
  • Run the display qos configuration interface [ interface-type interface-number ] command to check all QoS configurations on an interface.
