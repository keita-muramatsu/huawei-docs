DELETE

The DELETE method is used to delete the target data and returns the specific state. If the DELETE request succeeds, a "204 No Content" status-line is returned.

If the target data resource represents a configuration leaf-list or list data node, it must be a single YANG leaf-list or list instance. The server cannot use the DELETE method to delete more than one such instance.

Delete the instance named test.

  • Request

Host: X.X.X.X
Accept: application/yang-data+xml
Content-Type: application/yang-data+xml
Content-Length: 0
Authorization: Basic YXBpLWFkbWluOkFkbWluQDEyMw==

  • Response

    HTTP/1.1 204 No Content
Date: Wed, 18 Apr 2022 12:00:00 GMT
Content-Type: application/yang-data+xml
Content-Length: 0
