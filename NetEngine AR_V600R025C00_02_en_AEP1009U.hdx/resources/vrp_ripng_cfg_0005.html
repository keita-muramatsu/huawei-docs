Timers

RIPng has four timers: Update, Age, Garbage-Collect, and Suppress. Their functions and implementation principles are as follows:

  • Update timer: This timer triggers the sending of Update messages every 30 seconds, and synchronizes RIPng routes on the network.

  • Age timer: If a RIPng device does not receive any Update message from its neighbor before a route expires, it considers the route unreachable.

  • Garbage-Collect timer: If no Update message of an unreachable route is received within the Age timer, the corresponding route is deleted from the routing table.

  • Suppress timer: If a RIPng device receives an Update message with cost 16 from a neighbor, the route enters the suppressed state, and the Suppress timer is initiated.

The following describes how these timers relate to one another.

  • The advertisement of RIPng update information is controlled by the Update timer. By default, RIPng update information is sent every 30 seconds.
  • Each routing entry is associated with two timers: Age timer and Garbage-Collect timer. When a route is learned and added to the routing table, the Age timer is initialized. If no Update message is received from the neighbor for 180 seconds, the cost of the route is set to 16, and the Garbage-Collect timer is initialized. If no Update message is received within a further 120 seconds, the Garbage-Collect timer expires and the entry is deleted.
  • By default, the Suppress timer of RIPng is disabled. If this timer is enabled manually, it starts after the system receives a route with a cost greater than 16 from a neighbor.
