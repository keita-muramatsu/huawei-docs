Configuring Rate Limiting for STAs

Prerequisites

Before performing the configuration, you have completed the following task:
  • Configure AP onboarding and STA access.

Context

To protect network bandwidth resources and reduce network congestion, you can configure a rate limit for upstream and downstream packets of all STAs or each STA on a VAP to limit the rate of traffic entering the WLAN.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a traffic profile and enter its view.

    traffic-profile name profile-name

  4. The rate limit of upstream and downstream packets is configured for all STAs or each STA on a VAP.

    rate-limit { client | vap } { up | down } rate-value

    By default, the rate limit for upstream and downstream packets of all STAs on a VAP is 4294967295 kbit/s, and that of each STA is 4294967295 kbit/s. When rate limiting is configured for each STA in a VAP, rate limiting does not take effect for multicast packets.

  5. Bind the traffic profile.

    Bind the traffic profile to an AP group or a single AP so that the configuration in the traffic profile can take effect. For details, see Traffic Profile.

Verifying the Configuration

Run the display traffic-profile name profile-name command to check the STA rate limiting configuration in a traffic profile.
