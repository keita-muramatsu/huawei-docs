Configuring a Power Redundancy Mode

Context

You can configure the power redundancy mode of a device according to your power supply requirements. To save energy, shut down redundant power modules when stable power is supplied to the system.

A device supports the following power redundancy modes:

  • Module (N+1): N power modules supply power for the device, and one power module works as a backup for any of the other power modules.

  • Non (N+0): N power modules supply power for the device, and no power module works as a backup.

Only the AR8100 series, AR8700 series, AR6700-H series, AR6710-L26T2X4-T, AR6710-L50T2X4-T, AR6710-L26T2X4, and AR6710-L50T2X4 support this function.

Procedure

  1. Enter the system view.

    system-view

  2. Configure a power redundancy mode.

    device power redundant powermode

    The default power redundancy mode of a device is Module.

Verifying the Configuration

Run the display device power system to check the Power Redundant field in the command output.
