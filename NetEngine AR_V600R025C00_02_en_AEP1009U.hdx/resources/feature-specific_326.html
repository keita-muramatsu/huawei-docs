Example for Configuring Queue Scheduling HQoS in CBQ Mode

Networking Requirements

In Figure 1, there are multiple types of users on the network. Each type of users has voice, video, and data services. A minimum assured bandwidth is configured for each user type, and the interface bandwidth needs to be shared to maximize its usage. Traffic from users of type user1 (VIP) must be preferentially transmitted. There are no differentiated services requirements for services. In this example, interface 1 represents 10GE 0/0/1.


Configuration Roadmap

The configuration roadmap is as follows:

  1. Assign an IP address to 10GE 0/0/1 (where HQoS will be applied) on DeviceA.
  2. Configure an SQ profile on DeviceA and set scheduling and shaping parameters for different users.
  3. Configure a traffic policy in CBQ mode on DeviceA and reference the SQ profile in a traffic behavior.
  4. Apply the traffic policy in CBQ mode to the outbound interface 10GE 0/0/1 of DeviceA.

Procedure

  1. Configure 10GE 0/0/1 on DeviceA.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] undo portswitch
[DeviceA-10GE0/0/1] ip address 192.168.3.1 24
[DeviceA-10GE0/0/1] quit

  2. Configure an SQ profile on DeviceA.

    [DeviceA] qos-user-profile uq1  
[DeviceA-qos-user-profile-uq1] user-queue user1 drr weight 30 cir 50000 cbs 1000000   
[DeviceA-qos-user-profile-uq1] user-queue user2 drr weight 10 cir 30000 cbs 750000  
[DeviceA-qos-user-profile-uq1] user-queue user3 drr weight 10 cir 20000 cbs 500000  
[DeviceA-qos-user-profile-uq1] quit

  3. Configure an SQ traffic policy on DeviceA.

    [DeviceA] acl 2001
[DeviceA-acl4-basic-2001] rule permit source 10.10.10.0 24
[DeviceA-acl4-basic-2001] quit
[DeviceA] acl 2002
[DeviceA-acl4-basic-2002] rule permit source 10.10.20.0 24
[DeviceA-acl4-basic-2002] quit
[DeviceA] acl 2003
[DeviceA-acl4-basic-2003] rule permit source 10.10.30.0 24
[DeviceA-acl4-basic-2003] quit
[DeviceA] traffic classifier user1 
[DeviceA-classifier-user1] if-match acl 2001 
[DeviceA-classifier-user1] quit 
[DeviceA] traffic classifier user2 
[DeviceA-classifier-user2] if-match acl 2002 
[DeviceA-classifier-user2] quit
[DeviceA] traffic classifier user3 
[DeviceA-classifier-user3] if-match acl 2003
[DeviceA-classifier-user3] quit
[DeviceA] traffic behavior user1
[DeviceA-behavior-user1] qos-user-profile uq1 user-queue user1
[DeviceA-behavior-user1] quit
[DeviceA] traffic behavior user2
[DeviceA-behavior-user2] qos-user-profile uq1 user-queue user2                      
[DeviceA-behavior-user2] quit
[DeviceA] traffic behavior user3
[DeviceA-behavior-user3] qos-user-profile uq1 user-queue user3                     
[DeviceA-behavior-user3] quit
[DeviceA] traffic policy user-cbq-policy
[DeviceA-trafficpolicy-user-cbq-policy] classifier user1 behavior user1
[DeviceA-trafficpolicy-user-cbq-policy] classifier user2 behavior user2
[DeviceA-trafficpolicy-user-cbq-policy] classifier user3 behavior user3
[DeviceA-trafficpolicy-user-cbq-policy] quit

  4. Apply the traffic policy in CBQ mode to the outbound interface of DeviceA.

    [DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] qos queue-scheduling enable   //Run this command if the queue capability is disabled on the device interface.
[DeviceA-10GE0/0/1] traffic-policy user-cbq-policy outbound
[DeviceA-10GE0/0/1] quit
