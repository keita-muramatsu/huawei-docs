Configuring the Function of Quickly Disconnecting STAs

Context

When configuring smart roaming, it is recommended that the function of quickly disconnecting STAs also be configured. This function enables an AP to disconnect a STA whose SNR reaches the threshold for disconnecting STAs before it completes smart roaming. In this manner, the STA can associate with an AP with better signals.

If the uplink signal strength of a STA received by an AP is low, the STA is far away from the AP. If the STA continues to associate with the weak-signal AP, severe retransmission occurs, wasting air interface resources. To prevent a single STA from affecting the throughput of an AP, forcibly disconnect the STA so that it can associate with an AP with better signal quality.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an RRM profile and enter its view.

    rrm-profile name profile-name

    By default, the RRM profile default exists on the device.

  4. Enable the function of quickly disconnecting STAs.

    undo smart-roam quick-kickoff-threshold disable

    By default, the function of quickly disconnecting STAs is enabled.

  5. (Optional) Configure the threshold for quickly disconnecting STAs.

    smart-roam quick-kickoff-threshold snr snr-threshold

    By default, the SNR-based threshold for quickly disconnecting STAs is 15 dB.

    The SNR refers to the ratio of signal power to noise power. The noise floor is –95 dBm. In most cases, the signal strength required by network planning is less than or equal to –65 dBm.

    For example, if the threshold is set to 10 dB, the device disconnects STAs when the signal strength of STAs is lower than –85 dBm. If the threshold is set to 30 dB, the device disconnects STAs when the signal strength of STAs is lower than –65 dBm. If the threshold is set large, STAs, especially those sensitive to signal strength, are likely to go offline. Therefore, the threshold needs to be slightly adjusted based on the site requirements.

  6. (Optional) Configure the PN observation threshold for quickly disconnecting STAs.

    smart-roam quick-kickoff-snr p-n criteria observe-time observe-value qualify-time qualify-value

    By default, the number of PN observation times is 6, and the number of times the criteria are met is 4.

  7. Bind the RRM profile.

    The configuration in an RRM profile can take effect only after the profile is bound to a radio profile and then the radio profile is bound to an AP group or a specific AP. For details, see RRM Profile.

Verifying the Configuration

Run the display rrm-profile name profile-name command to check the settings of smart roaming parameters.
