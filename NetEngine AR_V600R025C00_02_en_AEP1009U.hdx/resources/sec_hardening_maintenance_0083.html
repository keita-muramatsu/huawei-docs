System Log Security

Overview

Logs record such device information as user operations and device running status, and are stored on devices as log files. Logs help network administrators monitor device running status and diagnose network faults.

Log security is ensured through access mode-specific authentication and socket security. You can log in to a device to view its logs. For details about device login security configuration, see the corresponding security hardening policies. If logs need to be output to a log host, you are advised to use TLS encryption.

Impact on the System

None

Procedure

  1. Enter the system view.

    system-view

  2. Configure an SSL policy and enter its view.

    ssl policy policy-name

    For details about how to configure an SSL policy, see "SSL Configuration" in CLI Configuration Guide > Security Configuration.

  3. Exit the SSL policy view.

    quit

  4. Apply the SSL policy to output logs to log hosts.

    • Configure the device to output logs to an IPv4 log host.
      info-center loghost ipv4-address [ { local-time | utc } | channel { channel-number | channel-name } | { public-net | vpn-instance vpn-instance-name } | source-ip source-ip-address | facility local-num | level level-num | port server-port | transport { udp | tcp  { [ version rfc6587 ] [ ssl-policy policy-name [ [ security ] | [ verify-dns-name dns-name ] ] * ] } } | brief ] *

    • Configure the device to output logs to an IPv6 log host.
      info-center loghost ipv6 ipv6-address [ { local-time | utc } | channel { channel-number | channel-name } | { public-net | vpn-instance vpn-instance-name } | source-ip source-ipv6-address | facility local-num | level level-num | port server-port | transport { udp | tcp  { [ version rfc6587 ][ ssl-policy policy-name [ [ security ] | [ verify-dns-name dns-name ] ] * ] } } | brief ] *

    • Configure the device to output logs to a log host with the specified domain name.
      info-center loghost domain domain-name [ { local-time | utc } | channel { channel-number | channel-name } | { public-net | vpn-instance vpn-instance-name } | source-ip source-ip-address | facility local-num | level level-num | port server-port | transport { udp | tcp  { [ version rfc6587 ] [ ssl-policy policy-name [ [ security ] | [ verify-dns-name dns-name ] ] * ] } } | brief ] *
    • Configure the device to output logs to a log host in HTTP mode.
      info-center loghost url url-str [ { public-net | vpn-instance VPN-Ins-name } ] token token-str [ { local-time | utc } | channel { channel-number | channel-name } | facility local-num | level level-num | [ ssl-policy policy-name [ [ security ] | [ verify-dns-name dns-name ] ] * ] | brief ] *

      For details about how to configure the device to output logs to a log host, see "Information Management Configuration" in CLI Configuration Guide > System Management Configuration.

Verifying the Security Hardening Result

Run the display ssl policy command to check the SSL policy configuration.
