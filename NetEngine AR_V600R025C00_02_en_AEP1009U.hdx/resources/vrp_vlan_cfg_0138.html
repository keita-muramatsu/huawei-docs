Configuring a VLAN Pool

Context

A VLAN pool is a set of VLANs that is used to simplify network deployment. After a user is successfully authenticated, the authentication server authorizes a VLAN pool to the user. The device selects a VLAN from the VLAN pool based on a certain algorithm and assigns it to the user.

Procedure

  1. Enter the system view.

    system-view

  2. Create a batch of VLANs.

    vlan batch { vlan-id1 [ to vlan-id2 ] } &<1-10>

  3. Create a VLAN pool and enter the VLAN pool view.

    vlan pool pool-name

  4. Add specified VLANs to the VLAN pool.

    vlan { start-vlan-id [ to end-vlan-id ] } &<1-10>

  5. (Optional) Configure the VLAN assignment algorithm in the VLAN pool.

    assignment { even | hash }

    By default, the VLAN assignment algorithm in a VLAN pool is hash.

Verifying the Configuration

Run the display vlan pool command in any view to check the VLAN pool configuration.

Follow-up Procedure

On the RADIUS server, configure the standard RADIUS attribute Tunnel-Private-Group-ID for authenticated users to add the users to a specified VLAN pool.
