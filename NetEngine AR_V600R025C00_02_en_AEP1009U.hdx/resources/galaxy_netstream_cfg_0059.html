(Optional) Configuring the Function of Storing NetStream Logs

Context

You can configure the function of storing NetStream IPv4 flow table logs to save information about aging flow entries to the local device.

Procedure

  1. Enter the system view.

    system-view

  2. Configure a local path for storing NetStream logs.

    netstream ip cache log log-directory log-directory

    By default, no local path is configured for storing NetStream logs.

    • Logs can be stored only in a USB flash drive path.
    • The digit in the name of a NetStream log is in the range from 1 to 9999. That is, when the log name is netstreamdata9999.db, no new storage data file can be generated, logs cannot be updated, and storage logs will be lost.

  3. Configure the size of the memory for storing NetStream logs locally.

    netstream ip cache log size size

    By default, the size of the memory for storing NetStream logs locally is 100 MB.

    When the memory of storing NetStream logs locally reaches the upper limit, the earliest logs are overwritten with the latest logs.

  4. Enable the function of storing NetStream logs locally.

    netstream ip cache log enable

    By default, the function of storing NetStream logs locally is disabled.

    The function of storing logs locally takes effect only when both the netstream ip cache log log-directory and netstream ip cache log size commands are configured.
