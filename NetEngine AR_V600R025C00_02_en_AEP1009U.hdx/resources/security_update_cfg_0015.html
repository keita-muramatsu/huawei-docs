Restoring the Signature Database to the Preconfigured Version

Prerequisites

The preconfigured version of the signature database is stored in the flash:/default-sdb/ directory of the device.

Context

The software package of the device contains the preconfigured IPS signature database, SA signature database, and geolocation database. If an exception occurs during a signature database update, you can restore the signature database to the preconfigured version and perform the update again. After the signature database is restored to the preconfigured version, the previously downloaded signature database file is deleted from the device.

If the preconfigured version does not exist on the device, you cannot restore the signature database to the preconfigured version. In this case, you can obtain the signature database file matching the current software version of the device from the Huawei Intelligent Security Center and manually upload the file to the flash:/default-sdb/ directory of the device. You can then restore the signature database to the preconfigured version. The manually uploaded signature database file must be named according to the following convention:

  • IPS signature database: ips-sdb.zip
  • SA signature database: sa-sdb.zip
  • Geolocation database: location-sdb.zip

Procedure

  1. Enter the system view.

    system-view

  2. Restore the signature database to the preconfigured version.

    update restore sdb-default { ips-sdb | sa-sdb }
update restore sdb-default location-sdb

    For the AR5700 series, only the AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S and AR5710-S10T1X2 do not support the ips-sdb parameter.

  3. Optional: Forcibly restore the signature database to the preconfigured version.

    update force restore sdb-default { ips-sdb | sa-sdb }

    For the AR5700 series, only the AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S and AR5710-S10T1X2 do not support the ips-sdb parameter.

    If the system memory is insufficient, you cannot restore the signature database to the preconfigured version. In this case, you can perform this step to forcibly restore the signature database to the preconfigured version.
    • After you run this command, the signature database files corresponding to the rollback version and download version of the signature database will be deleted.
    • After the command is executed, the ASE does not take effect in a short period of time and all ASE-related session entries are reset. Exercise caution when running this command.

Verifying the Configuration

Run the display version { ips-sdb | sa-sdb| location-sdb }* command to check the version of the current signature database on the device, so as to determine whether the signature database has been restored to the preconfigured version.

Follow-up Procedure

If you need to update the signature database again, complete the operations in Preparations for Signature Database Update first.
