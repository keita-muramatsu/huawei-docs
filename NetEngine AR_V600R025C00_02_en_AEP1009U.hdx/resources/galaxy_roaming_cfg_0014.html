Maintaining Roaming

Context

After STAs roam, you can view the STA roaming statistics on the WAC, including the number of online STAs, number of online roaming STAs, and WAC description. During the roaming process of a STA, the WAC records the STA's roaming track (that is, information about the APs to which the STA has connected).

Procedure

  • Run the display station roam-statistics [ ap-id ap-id ] command to check roaming statistics.
  • Run the display station roam-track sta-mac mac-address command to check the roaming track of a specified STA.
