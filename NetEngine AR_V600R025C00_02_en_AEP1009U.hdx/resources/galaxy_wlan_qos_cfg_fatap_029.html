Configuring ACL-based Packet Re-marking on the Wireless Side

Prerequisites

Before performing the configuration, you have completed the following tasks:

  • Configure AP onboarding and STA access.

  • Create an ACL rule.

Context

ACL-based priority re-marking can be configured to remark the priorities of wireless packets matching ACL rules, thereby providing differentiated services.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a traffic profile and enter its view.

    traffic-profile name profile-name

  4. Configure ACL-based packet re-marking in a traffic profile.

    traffic-remark { inbound | outbound } ipv4 acl { acl-number | acl-number-user | name acl-name } { dot11e dot11e-value | dscp dscp-value }

    Or

    traffic-remark { inbound | outbound } l2 acl { acl-number-l2 | name acl-name-l2 } { dot11e dot11e-value | dscp dscp-value }

    Or

    traffic-remark { inbound | outbound } ipv4 acl { acl-number | acl-number-user | name acl-name } l2 acl { acl-number-l2 | name acl-name-l2 } { dot11e dot11e-value | dscp dscp-value }

    Or

    traffic-remark { inbound | outbound } ipv6 acl acl-number-ipv6 { dscp dscp-value | dot11e dot11e-value }

    By default, ACL-based priority re-marking is not configured in a traffic profile.

  5. Bind the traffic profile.

    Bind the traffic profile to an AP group or a single AP so that the configuration in the traffic profile can take effect. For details, see Traffic Profile.

Verifying the Configuration

Run the display wlan traffic-remark applied-record command to check information about all ACL-based packet re-marking applications on the device.

Run the display traffic-profile { all | name profile-name } command to check the configuration of ACL-based packet re-marking.

Run the display ap service-config acl ipv6 ap-id ap-id command to check the ACL configuration on a specified AP.
