Configuring Association Between Interface Backup and NQA

Prerequisites

Before configuring association between interface backup and NQA, you have completed the following tasks:

  • Configure routing protocols on the primary and backup links to ensure connectivity at the network layer.

  • Configure an ICMP NQA test instance on the local device (DeviceA) to monitor the connectivity of the primary link. For detailed configurations, see Configuring an ICMP Test.

    Interface backup can only be associated with an ICMP NQA test instance.

Procedure

  1. Enter the system view.

    system-view

  2. (Optional) Associate the IPv4 static route of the primary link with the NQA test instance or set route priorities for the primary and backup links.

    ip route-static ip-address { mask | mask-length } { interface-name | interface-type interface-number } [ nexthop-address ] [ preference preference | tag tag ] * track nqa admin-name test-name [ description text ]

    • If the primary and backup links use dynamic routes, skip Step 2.

    • If the primary and backup links use static routes, perform Step 2 to configure association between the NQA test instance of the primary link and the static route or set a higher for the backup link than the primary link.

      When the primary link is faulty, traffic loss may occur. This is because there is no convergence mechanism for static routes, meaning that routes cannot be switched quickly enough. To ensure the switchover of data traffic, set a higher route preference value for the backup link than for the primary link; alternatively, configure NQA for static routes. When the NQA test instance detects that the route on the primary link is unreachable, it deletes the corresponding static route from the routing table. For detailed configurations, see Configuring NQA for IPv4 Static Route.

  3. Enter the backup interface view.

    interface interface-type interface-number

  4. Configure association between interface backup and NQA

    standby track nqa admin-name test-name

    A backup interface can be associated with only one NQA test instance, but an NQA test instance can be associated with multiple backup interfaces.

  5. (Optional) Set a delay for switching to a backup interface.

    standby timer delay enable-delay disable-delay

Verifying the Configuration

Run the display standby state command to check the interface backup status and the NQA test instance status.
