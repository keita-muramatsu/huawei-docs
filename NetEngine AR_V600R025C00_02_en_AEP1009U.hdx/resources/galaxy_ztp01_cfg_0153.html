Introduction to the Intermediate File in Python Format

The intermediate file in Python format (known as a Python script) is used to download deployment files. The file name must be ***.py. The file name must comply with the basic naming rules, that is, the file name can contain only lowercase letters, digits, and underscores (_), for example, ztp_script.py. In USB-based deployment, the file name must be ztp_script.py. In intermediate file-based deployment, the file name can be customized. For details about the file example and the script content that needs to be modified, see the following sections.

The Python script can invoke the script defined using open programmability system (OPS) APIs. The invoked script defines automatic service deployment upon device startup. To configure more service functions for ZTP, edit the Python script by referring to the file example and "Writing an OPS API-based Script" in CLI Configuration Guide > System Management Configuration.
