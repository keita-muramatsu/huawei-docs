Example for Configuring a Device as an IPv6 DNS Relay Agent

Networking Requirements

In Figure 1, a user host needs to use a domain name to access the network, and the domain name needs to be resolved by the DNS server (with the IPv6 address 2001:db8:3::2). To meet these requirements, configure DeviceA as a DNS relay agent. In this way, the user host is unaware of a DNS server address change, reducing maintenance costs.

Figure 1 Network diagram of configuring a DNS relay agent

In this example, Interface1 and Interface2 represent 10GE0/0/1 and 10GE0/0/2, respectively.


Procedure

  1. Configure IPv6 addresses for 10GE0/0/1 and 10GE0/0/2 on DeviceA.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] undo portswitch 
[DeviceA-10GE0/0/1] ipv6 enable
[DeviceA-10GE0/0/1] ipv6 address 2001:DB8:2::1/64
[DeviceA-10GE0/0/1] quit 
[DeviceA] interface 10ge 0/0/2
[DeviceA-10GE0/0/2] undo portswitch
[DeviceA-10GE0/0/2] ipv6 enable
[DeviceA-10GE0/0/2] ipv6 address 2001:db8:3::1/64
[DeviceA-10GE0/0/2] quit

  2. Configure DNS relay.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] dns relay ipv6 enable
[DeviceA] dns resolve
[DeviceA] dns server ipv6 2001:db8:3::2

  3. Configure an IPv6 address for the DNS relay agent to communicate with a user host. The IPv6 address 2001:db8:3::1 is an address on DeviceA, and there are reachable routes between this address and the DNS server and between this address and the user host.

    [DeviceA] dns server bind local-ip ipv6 2001:db8:3::1

  4. On a user host, set the IPv6 address of the DNS server to 2001:db8:3::1 (IPv6 address of the DNS relay agent).

Verifying the Configuration

# Run the display current-configuration command on DeviceA to check the DNS relay configuration.

[DeviceA] display current-configuration | include dns 
 dns resolve                                                                    
 dns server ipv6 2001:db8:3::2                                                             
 dns relay ipv6 enable
 dns server bind local-ip ipv6 2001:db8:3::1

Configuration Scripts

DeviceA

sysname DeviceA
#

 ipv6 enable
