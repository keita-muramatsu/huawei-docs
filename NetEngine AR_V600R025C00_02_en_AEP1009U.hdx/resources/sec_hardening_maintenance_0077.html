Storm Suppression Security

Overview

When a Layer 2 Ethernet interface on a device receives broadcast, unknown multicast, or unknown unicast packets, the device forwards these packets to other Layer 2 Ethernet interfaces in the same VLAN if the outbound interfaces cannot be determined based on the destination MAC addresses of these packets. As a result, a broadcast storm may be generated, degrading forwarding performance of the device.

Storm suppression is a security technology used to control broadcast, unknown multicast, and unknown unicast packets and prevent broadcast storms caused by these packets.

Storm suppression includes traffic suppression and storm control.
  • Traffic suppression limits the rate of broadcast, unknown multicast, and unknown unicast packets through threshold setting. When traffic exceeds the set threshold, the system discards excessive traffic, limiting the traffic rate to a reasonable range. Note that traffic suppression can also block outgoing traffic on interfaces.
  • Storm control interrupts broadcast, unknown multicast, and unknown unicast packets by blocking these packets or disabling related interfaces. Storm control can also control the average rate of packets by suppressing them. When traffic exceeds the specified threshold, the system performs a predefined storm control action.

Currently, the device supports only traffic suppression.

Impact on the System

None

Procedure

  1. Enter the system view.

    system-view

  2. Enter the interface view.

    interface interface-type interface-number

  3. Change the interface working mode from Layer 3 to Layer 2.

    portswitch

    Determine whether to perform this step based on the actual interface working mode.

  4. Configure traffic suppression on an interface in the inbound direction.

    storm suppression { broadcast | multicast | unknown-unicast } { percent-value | cir cir-value [ gbps | kbps | mbps ] [ cbs cbs-value [ bytes | kbytes | mbytes ] ] | packets packets-per-second }

    If traffic suppression is configured for packets of the same type on an interface in the inbound direction for multiple times (with percent-value and cir cir-value specified), only the latest configuration takes effect.

  5. Configure traffic suppression on an interface in the outbound direction.

    storm suppression { broadcast | multicast | unknown-unicast } block outbound

Verifying the Security Hardening Result

Run the display storm suppression { broadcast | multicast | unknown-unicast } [ interface interface-type interface-number ] command to check the configured and actual traffic suppression thresholds on an interface in the inbound direction.
