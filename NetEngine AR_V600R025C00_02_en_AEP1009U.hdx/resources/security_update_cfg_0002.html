Overview of Signature Database Update

Definition

A signature database stores the behavior, virus, and application/protocol features of most identified attacks. It is an important part of the security protection system for a device. The device analyzes the passing data flows based on these features, and then processes the traffic based on the analysis result. You can use the signature database update function to update the signature database file stored on the device to a new version.

Purpose

As intrusion methods, viruses, and applications/protocols continue to emerge and evolve, it is necessary to periodically update the signature database so that the device can quickly identify new applications/protocols as well as detect and defend against new intrusion methods and virus files. Keeping the signature database up to date can significantly improve the dynamic security protection capability of the device.

The Huawei Intelligent Security Center (https://isecurity.huawei.com/) periodically releases the latest signature database. For details, see the signature database update notice (https://isecurity.huawei.com/security/signature/announcement).
