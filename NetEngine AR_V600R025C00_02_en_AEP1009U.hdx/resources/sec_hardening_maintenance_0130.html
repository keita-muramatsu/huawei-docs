SD-WAN EVPN Security

Overview

In an SD-WAN EVPN scenario, you need to configure an IPsec point-to-multipoint (P2MP) policy to encrypt data for secure data communication.

Impact on the System

None

Procedure

  1. Enter the system view.

    system-view

  2. Configure a P2MP policy.

    ipsec p2mp-policy policy-name

    By default, no P2MP policy is configured.

  3. Return to the system view.

    quit

  4. Create a tunnel interface and enter the tunnel interface view.

    interface tunnel interface-number

  5. Configure the SD-WAN tunnel encapsulation protocol for the tunnel interface.

    tunnel-protocol sd-wan

    By default, the SD-WAN tunnel encapsulation protocol is not configured for a tunnel interface.

  6. Enable SD-WAN services on the tunnel interface.

    sd-wan service enable

    By default, SD-WAN services are disabled on a tunnel interface.

  7. Bind a P2MP policy to the tunnel interface.

    ipsec-p2mp-policy policy-name

    By default, no P2MP policy is bound to a tunnel interface.

Verifying the Security Hardening Result

Run the display ipsec p2mp-sa { local | peer [ site site-id [ system-id system-id]]} command to check SA information of a P2MP policy.
