Configuring AI Roaming

Prerequisites

Before configuring AI roaming, complete the following tasks:

  • Configure intra-WAC roaming.
  • Configuring Smart Roaming

Context

The AI roaming function depends on neighbor scanning. If the Mesh service is configured on a radio, the AI roaming function does not take effect on the radio. If the radio supports independent radio scanning, this function on the radio is not affected.

If the PMF function is enabled, the AI roaming function does not take effect.

The roaming steering function based on coordinated measurement requires Layer 2 network connectivity between APs.

APs must support independent radio scanning to perform roaming steering based on coordinated measurement. For APs that do not support independent radio scanning, after the AI roaming function is enabled, the STA profiling mechanism is used to perform personalized roaming steering for STAs based on the triggering logic of smart roaming.

To reduce roaming latency and improve roaming efficiency for 802.1X users, it is recommended that you also configure the 802.11r roaming function when enabling AI roaming.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. (Optional) Enable independent radio scanning on APs. This step is required only for APs that support independent radio scanning.
    1. Create an AP system profile and enter its view.

      ap-system-profile name profile-name

      By default, the AP system profile default exists on the device.

    2. Enable independent radio scanning on APs.

      radio-mode { 2radio-independent-scan | 4radio-independent-scan }

      By default, no radio mode is configured in an AP system profile, and the default radio mode of the specific AP is used.

      This command is valid only for APs that support independent radio scanning.

    3. Return to the WLAN view.

      quit

    4. Bind the AP system profile.

      The configuration takes effect only after the AP system profile is applied to APs or AP groups. For details, see AP System Profile.

  4. Configure the air scan function.
    1. Create an air scan profile and enter its view.

      air-scan-profile name profile-name

      By default, the air scan profile default exists in the system.

    2. Enable the air scan function.

      undo scan-disable

      By default, the air scan function is enabled.

    3. Configure an air scan channel set that contains all channels supported by the country code of an AP.

      scan-channel-set country-channel

      By default, an air scan channel set contains all channels supported by the country code of an AP.

      In AI roaming scenarios, APs perform air scan on these channels (switched at an interval of 200 ms) to implement coordinated measurement.

    4. Return to the WLAN view.

      quit

  5. Create an RRM profile and enter its view.

    rrm-profile name profile-name

    By default, the RRM profile default exists on the device.

  6. Enable AI roaming.

    undo smart-roam ai-mode disable

    By default, AI roaming is enabled.

  7. (Optional) Configure the RSSI difference thresholds for triggering STA roaming steering.

    smart-roam snr-margin high-level-margin high-level-margin low-level-margin low-level-margin

    By default, the upper and lower RSSI difference thresholds for triggering STA roaming steering are 12 dB and 10 dB, respectively.

    In AI roaming scenarios based on coordinated measurement, only high-level-margin is used to determine whether to steer STAs to neighboring APs.

  8. Return to the WLAN view.

    quit

  9. Apply the air scan profile and RRM profile.

    The configuration in an air scan profile can take effect only after the profile is bound to a radio profile and then the radio profile is bound to an AP group or a specific AP. For details, see Air Scan Profile.

    The configuration in an RRM profile can take effect only after the profile is bound to a radio profile and then the radio profile is bound to an AP group or a specific AP. For details, see RRM Profile.

  10. (Optional) Configure 802.11k and 802.11v functions.

    1. Create an SSID profile and enter its view.
      ssid-profile name profile-name

      By default, the SSID profile default exists on the device.

    2. Enable the 802.11k protocol.
      undo dot11k disable

      By default, the 802.11k protocol is enabled.

      Do not disable the 802.11k protocol unless necessary. If some outdated STAs on the network do not support the 802.11k protocol, you can disable this function.

    3. Enable the 802.11v BSS transition function.
      undo dot11v bss-transition disable

      By default, the 802.11v BSS transition function is enabled.

      Do not disable the 802.11v BSS transition function unless necessary. If some outdated STAs on the network do not support 802.11v BSS transition, you can disable this function.

    4. Return to the WLAN view.
      quit
    5. Bind the SSID profile.

      The configuration in an SSID profile can take effect only after the profile is bound to a VAP profile and then the VAP profile is bound to an AP group or a specific AP. For details, see SSID Profile.

  11. (Optional) Configure interconnection between APs and CampusInsight to implement the AI roaming data reporting function.

    For details, see Configuring APs to Directly Report KPI Information. The reported collected information includes terminal data (terminal-data) and AI roaming data (ai-roam-data).

  12. (Optional) Configure MAC addresses of unsteerable STAs in smart roaming, AI roaming, band steering, and load balancing algorithms.

    station-unsteerable sta-mac sta-mac

    By default, no MAC addresses of unsteerable STAs are configured.

Verifying the Configuration

  • Run the display rrm-profile name profile-name command to check the settings of smart roaming parameters.
  • Run the display radio-2g-profile name profile-name command to check the RRM profile bound to a 2.4 GHz radio profile.
  • Run the display radio-5g-profile name profile-name command to check the RRM profile bound to a 5 GHz radio profile.
  • Run the display station neighbor sta-mac mac-address command to check the neighbor list of a STA.
  • Run the display station steer-history command to check historical STA steering information.
  • Run the display station steer-statistics command to check STA steering statistics.
