Default ZTP Settings

The default ZTP settings are classified into settings for a device that starts with empty configuration and those for a device that starts with configurations.

  • When a device is powered on and starts with empty configuration, it automatically starts the ZTP process by default.
  • When a device is powered on and starts with configurations, ZTP is not supported by default, and the device starts using the configuration file.
