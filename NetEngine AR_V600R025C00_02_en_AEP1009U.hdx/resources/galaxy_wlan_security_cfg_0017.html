Configuring the User Isolation Function

Context

The user isolation function prevents users from sending packets to each other. That is, users cannot directly communicate with each other after this function is enabled. This function improves user communication security and centralizes user traffic at the gateway for forwarding, facilitating user management.

To isolate users accessing a network in wireless mode, configure user isolation in a traffic profile. To isolate users accessing a network through an AP's wired interface, configure user isolation in the AP wired port profile.

Configuring User Isolation in a Traffic Profile

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a traffic profile, and enter its view.

    traffic-profile name profile-name

    By default, the system provides the traffic profile default.

  4. Enable the user isolation function in the traffic profile.

    user-isolate { l2 | all }

    By default, user isolation is disabled in a traffic profile.

  5. Return to the WLAN view.

    quit

  6. Create a VAP profile and enter its view.

    vap-profile name profile-name

  7. Bind the traffic profile to the VAP profile.

    traffic-profile name profile-name

    By default, the traffic profile default is bound to a VAP profile.

  8. Apply the VAP profile by referring to Binding a VAP Profile to make the configuration take effect.

Configuring User Isolation in an AP Wired Port Profile

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP wired port profile and enter its view.

    wired-port-profile name profile-name

    By default, the system provides the AP wired port profile default.

  4. Enable the user isolation function in the AP wired port profile.

    user-isolate { l2 | all }

    By default, user isolation is disabled in an AP wired port profile.

  5. Return to the WLAN view.

    quit

  6. Bind the AP wired port profile to an AP group or AP.

    For the configuration procedure, see Binding an AP Wired Port Profile.

Verifying the Configuration

  • Run the display traffic-profile { all | name profile-name } command to check the user isolation configuration in a traffic profile.
  • Run the display wired-port-profile { all | name profile-name } command to check the user isolation configuration in an AP wired port profile.
  • Run the display ap wired-port interface-type interface-number ap-id ap-id command to check the user isolation configuration on an AP's wired interface.
