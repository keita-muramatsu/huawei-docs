ASE Configuration

The ASE described in this document is supported by the basic software package. By default, the basic software package contains the capability and cannot be uninstalled. This feature can be upgraded. To upgrade this feature, log in to Huawei technical support website, search for the corresponding product and version in the software download area, and download the ASE feature package. For details about how to install and upgrade the feature package, see "Upgrade Maintenance Configuration" in CLI Configuration Guide > System Management Configuration.
