Defense Against ARP Flood Attacks

Overview

In an ARP flood attack, a large number of ARP messages are broadcast on the network, preventing the gateway from processing other services due to CPU overload. Processing these ARP messages consumes considerable amounts of bandwidth, leading to network congestion and affecting network communication.

To defend against this kind of attack, configure the following functions on a device:

  • ARP entry limiting

    A device limits the number of ARP entries that an interface can learn. This prevents an ARP entry overflow, thereby improving ARP entry security.

  • Rate limiting on ARP messages

    A device counts the number of received ARP messages in a specified period. If that number exceeds the limit, the device does not process excess ARP messages. This function prevents an ARP entry overflow.

  • Rate limiting on ARP Miss messages

    A device counts the number of received ARP Miss messages in a specified period. If that number exceeds the limit, the device does not process excess ARP Miss messages, relieving the burden on the CPU.

Impact on the System

Setting an ARP entry or rate limit that is too small adversely affects ARP functions.

Procedure

  • Configure ARP entry limiting.

    Configure the maximum number of ARP entries that a specified interface can learn.
    <HUAWEI> system-view
[HUAWEI] interface vlanif 10
[HUAWEI-Vlanif10] arp limit 20
[HUAWEI-Vlanif10] quit

  • Configure rate limiting on ARP messages.

    Configure the device to limit the rate of ARP messages (number of ARP messages that can be processed per second) globally.
    <HUAWEI> system-view
[HUAWEI] arp anti-attack rate-limit 1000  //This command can be run globally, in a VLAN, or on an interface as required.

  • Configure rate limiting on ARP Miss messages.

    Configure the device to limit the rate of ARP Miss messages (number of ARP Miss messages that can be processed per second) on an interface.
    <HUAWEI> system-view
[HUAWEI] interface 10GE 0/0/0
[HUAWEI-10GE0/0/1] arp miss anti-attack rate-limit 1000  //This command can be run globally based on source IP addresses, on an interface, or in a VLAN as required.
[HUAWEI-10GE0/0/1] quit

Verifying the Security Hardening Result

  • Run the display arp limit [ interface { interface-name | interface-type interface-number } ] [ vlan vlan-id ] command to check the configuration of ARP entry limiting.
  • Run the display arp anti-attack rate-limit command to check the configuration of rate limiting on ARP messages.
  • Run the display arp anti-attack record command to check detailed information about ARP messages discarded because the rate of ARP messages exceeds the limit.
  • Run the display arp miss anti-attack rate-limit command to check the configuration of rate limiting on ARP Miss messages.
  • Run the display arp miss anti-attack record command to check detailed information about ARP Miss messages discarded because the rate of ARP Miss messages exceeds the limit.
