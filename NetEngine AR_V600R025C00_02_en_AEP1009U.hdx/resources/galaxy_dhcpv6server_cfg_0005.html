(Optional) Configuring User-Defined Options for an IPv6 Address Pool

Context

DHCPv6 provides various options. To use these options, add them to the attribute list of the DHCPv6 server manually. When a DHCPv6 client requests an IPv6 address from the DHCPv6 server where vendor-specific options have been configured, the server returns a DHCPv6 message containing the options to the client.

Procedure

  1. Enter the system view.

    system-view

  2. Create an IPv6 address pool and enter its view.

    dhcpv6 pool pool-name

    By default, no IPv6 address pool is created on a device.

  3. Configure vendor-specific options for the IPv6 address pool and enter the vendor-specific view.

    vendor-specific vendor-id

    By default, no vendor-specific option is configured. A maximum of eight vendor-specific options can be configured for an IPv6 address pool.

    vendor-id specifies the identifier of a vendor, which is assigned by the IANA. The vendor ID of Huawei is 2011.

  4. Configure a vendor-specific DHCPv6 suboption in the vendor-specific view.

    suboption suboption-code { address ipv6-address &<1-4> | ascii ascii-string  | hex hex-string }

    By default, no vendor-specific DHCPv6 suboption is configured in the system. A maximum of 16 vendor-specific suboptions can be configured in each vendor-specific view.
