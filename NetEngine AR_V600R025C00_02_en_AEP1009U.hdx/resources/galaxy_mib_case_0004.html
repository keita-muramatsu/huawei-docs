Commonly Used MIB Objects

This section describes commonly used MIB objects.

The following tables describe OIDs of commonly used objects. You can query common information through the MIB objects.

Table 1 Device status monitoring

Object

OID

Description

MIB

hwEntityCpuUsage

1.3.6.1.4.1.2011.5.25.31.1.1.1.1.5

Indicates the CPU usage of the entity.

The value is in the range from 0 to 100.

The default value is 0.

HUAWEI-ENTITY-EXTENT-MIB

hwEntityMemUsage

1.3.6.1.4.1.2011.5.25.31.1.1.1.1.7

Indicates the memory usage of the device. The value is in the range from 0 to 100. The default value is 0.

HUAWEI-ENTITY-EXTENT-MIB

hwEntityTemperature

1.3.6.1.4.1.2011.5.25.31.1.1.1.1.11

Indicates the entity temperature.

HUAWEI-ENTITY-EXTENT-MIB

entPhysicalSerialNum

1.3.6.1.2.1.47.1.1.1.1.11

Indicates the entity serial number. The default value is 1.
