Upgrading an RU

Context

An RU has the following types of firmware: APP firmware (performs operations such as controlling the forwarding process, parsing XLDP packets, and processing configurations), PoE firmware (implements the PoE function), and BIOS firmware (verifies and starts the APP firmware). All three types of firmware can be upgraded. System software packages or patches (containing firmware) of the central device can be used to upgrade RUs. If the firmware version of an RU is different from the firmware package version in the software or patch package of the central device, the RU's firmware requires an upgrade. By default, the RU upgrade function is disabled on the central device. If the firmware of RUs needs to be upgraded, you can enable the RU upgrade function on the central device. You can also specify the time for RUs to restart with firmware of the new version.

After the upgrade is successful, the RU will restart, during which services will be interrupted. As such, properly plan the upgrade time.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the global RU view.

    remote-unit

  3. Upgrade RUs.

    • Run the following command to upgrade RUs immediately. After this command is run, RUs load firmware of the new version and restart immediately.
      upgrade right-now
    • Run the following command to set the time for RUs to restart with firmware of the new version. After this command is run, RUs immediately load firmware of the new version and restart at the specified time.
      upgrade start-time hh:mm:ss
    • Run the following command to set the RU deployment end time. The firmware of the RUs that go online before the specified time will be automatically upgraded, and automatic RU firmware upgrade is disabled after the specified time.
      upgrade cutoff-time yyyy/mm/dd hh:mm:ss

  4. (Optional) If an RU fails to be upgraded and enters the cooldown period, it can be upgraded again only after the cooldown period ends. You can use the forcible upgrade function to upgrade the RU, no matter whether the cooldown period has ended or not.
    1. Enter the single RU view.

      remote-unit { id | connect-interface interface-type interface-number | name remote-unit-name }

    2. Forcibly upgrade the firmware of an RU in the cooldown period as required.

      upgrade { app | bios | poe | bios1 | app1 | app2 | poe3 | poe5 | poe6 | poe7 | poe81 | poe82 | poe83 } force

      During the BIOS firmware upgrade of RUs, do not power off or disconnect the RUs. Otherwise, the RUs cannot be started.

Verifying the Configuration

Run the display remote-unit upgrade { record | information } command to check the upgrade information.
