Understanding Gratuitous ARP Message Discarding

In a gratuitous ARP message, the source and destination IP addresses are both the local IP address, the source MAC address is the local MAC address, and the destination MAC address is a broadcast address. A user host broadcasts a gratuitous ARP message upon connecting to a network. The host uses this message to notify other devices of its MAC address and to check whether its IP address conflicts with other IP addresses in the broadcast domain. If the host's MAC address is changed, the host sends a gratuitous ARP message to notify all other user hosts of the change before the ARP entry ages out.

Any user host can send gratuitous ARP messages without authentication. This causes the following issues:
  • If a large number of gratuitous ARP messages are broadcast on the network, a device cannot process valid ARP messages due to CPU overload.
  • If a device receives bogus gratuitous ARP messages, it updates ARP entries incorrectly, leading to communication interruptions of authorized users.

To address the preceding issues, enable gratuitous ARP message discarding on the device.

If gratuitous ARP message discarding is enabled on the device, other hosts on the network cannot update their ARP entries when a host uses a new MAC address to connect to the network. Consequently, other hosts cannot communicate with this host.
