Configuring a BGP4+ Large-Community Attribute

Prerequisites

Before configuring the BGP4+ Large-Community attribute, you have completed the following task:

  • Configure basic BGP4+ functions.

Context

The Large-Community attribute can completely represent a 2-byte or 4-byte AS number, and has two 4-byte LocalData fields, allowing the administrator to flexibly use route-policies. As an enhancement to community attributes, Large-Community can be used together with community attributes.

Procedure

  1. Enter the system view.

    system-view

  2. Create a route-policy node and enter the route-policy view.

    route-policy route-policy-name { deny | permit } node node

  3. (Optional) Configure an if-match clause for the route-policy. The community attributes of routes can be added or modified only if the routes match specified if-match clauses.

    For details about the configuration, see (Optional) Configuring an if-match Clause.

  4. Configure the Large-Community attribute for BGP4+ routes.

    apply large-community { aa:bb:cc } &<1-16> { additive | overwrite | delete }

    or

    apply large-community-list large-community-list-name { additive | overwrite | delete }

  5. Exit the route-policy view.

    quit

  6. Enter the BGP view.

    bgp as-number

  7. Enter the BGP-IPv6 unicast address family view.

    ipv6-family unicast

  8. Configure an export route-policy.

    peer { ipv6-address | group-name | ipv4-address } route-policy route-policy-name export

  9. Enable the device to advertise Large-Community attributes to the specified peer or peer group.

    peer { ipv6-address | group-name | ipv4-address } advertise-large-community

    By default, the device does not advertise Large-Community attributes to its peers or peer groups.
