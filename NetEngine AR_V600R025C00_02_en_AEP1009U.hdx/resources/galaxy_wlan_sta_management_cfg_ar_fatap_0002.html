Example for Configuring WLAN Band Steering (5G-Prior Access) (Fat AP)

Networking Requirements

A Fat AP supports both 2.4 GHz and 5 GHz frequency bands. Users access the network through a WLAN. To relieve the pressure on the 2.4 GHz frequency band, STAs need to connect to the 5 GHz frequency band. For details about the basic networking example, see Example for Configuring STA Access to a WLAN (Fat AP).

Precautions

  • Use the AP that supports both 2.4 GHz and 5 GHz frequency bands, and configure the same SSID and security policy on the 2.4 GHz and 5 GHz radios.
  • To allow STAs to preferentially associate with the 5 GHz radio and achieve better access effect, configure larger power for the 5 GHz radio than the 2.4 GHz radio.

Configuration Roadmap

  1. Configure STA access services so that STAs can access the WLAN properly.
  2. Configure the band steering function and proper band steering parameters so that STAs can preferentially access the 5 GHz radio.

Procedure

  1. Bind the VAP profile to the AP with the ID 0.

    # Create the SSID profile wlan-net and set the SSID name to wlan-net.
    <HUAWEI> system-view
[HUAWEI] sysname FAT AP
[FAT AP] wlan
[FAT AP-wlan] ssid-profile name wlan-net
[FAT AP-wlan-ssid-prof-wlan-net] ssid wlan-net
[FAT AP-wlan-ssid-prof-wlan-net] quit
    # Create the VAP profile wlan-net and bind the SSID profile to the VAP profile.
    [FAT AP-wlan] vap-profile name wlan-net
[FAT AP-wlan-vap-prof-wlan-net] ssid-profile wlan-net
[FAT AP-wlan-vap-prof-wlan-net] quit
    # Bind the VAP profile wlan-net to radios 0 and 1 of the AP with the ID 0.
    [FAT AP-wlan] ap-id 0
[FAT AP-wlan-ap-0] vap-profile wlan-net wlan 1 radio 0
Warning: This operation will delete radio0's VAP in active state and make users offline, continue? [Y/N]:y
[FAT AP-wlan-ap-0] vap-profile wlan-net wlan 1 radio 1
Warning: This operation will delete radio1's VAP in active state and make users offline, continue? [Y/N]:y
[FAT AP-wlan-ap-0] quit

  2. Configure the band steering function.

    # Enable the band steering function in the VAP profile wlan-net. By default, the band steering function is enabled.

    When band steering is enabled on any radio of the AP, the function takes effect on the SSID of the AP. If different VAP profiles are applied to two radios of the AP, you only need to enable the band steering function in the VAP profile of one radio.

    [FAT AP-wlan] vap-profile name wlan-net
[FAT AP-wlan-vap-prof-wlan-net] undo band-steer disable
[FAT AP-wlan-vap-prof-wlan-net] quit

    # Create the RRM profile wlan-rrm and configure load balancing between radios in the profile to prevent a heavy load on a single radio. Set the start threshold for load balancing between radios to 15 and the load difference threshold to 25%.

    [FAT AP-wlan] rrm-profile name wlan-rrm
[FAT AP-wlan-rrm-prof-wlan-rrm] band-steer balance start-threshold 15
[FAT AP-wlan-rrm-prof-wlan-rrm] band-steer balance gap-threshold 25
[FAT AP-wlan-rrm-prof-wlan-rrm] quit
    # Create the 2.4 GHz radio profile wlan-radio2g and bind the RRM profile wlan-rrm to the 2.4 GHz radio profile.

    If different RRM profiles are bound to the 2.4 GHz and 5 GHz radio profiles and configured with different band steering parameters, parameter settings in the 2.4 GHz radio profile preferentially take effect.

    [FAT AP-wlan] radio-2g-profile name wlan-radio2g
[FAT AP-wlan-radio-2g-prof-wlan-radio2g] rrm-profile wlan-rrm
Warning: This action may cause service interruption. Continue? [Y/N]:y
[FAT AP-wlan-radio-2g-prof-wlan-radio2g] quit

    # Bind the 2.4 GHz radio profile wlan-radio2g to the AP with the ID 0.

    [FAT AP-wlan] ap-id 0 
[FAT AP-wlan-ap-0] radio-2g-profile wlan-radio2g radio 0
Warning: This action may cause service interruption. Continue? [Y/N]:y
[FAT AP-wlan-ap-0] quit

    # Create the 5 GHz radio profile wlan-radio5g and bind the RRM profile wlan-rrm to the 5 GHz radio profile.

    [FAT AP-wlan] radio-5g-profile name wlan-radio5g
[FAT AP-wlan-radio-5g-prof-wlan-radio2g] rrm-profile wlan-rrm
Warning: This action may cause service interruption. Continue? [Y/N]:y
[FAT AP-wlan-radio-5g-prof-wlan-radio2g] quit

    # Bind the 5 GHz radio profile wlan-radio5g to the AP with the ID 0.

    [FAT AP-wlan] ap-id 0
[FAT AP-wlan-ap-0] radio-5g-profile wlan-radio5g radio 1
Warning: This action may cause service interruption. Continue? [Y/N]:y
[FAT AP-wlan-ap-0] quit

Verifying the Configuration

# Run the display vap-profile name wlan-net command on the Fat AP. The command output shows that the band steering function is enabled in the VAP profile.

[FAT AP-wlan] display vap-profile name wlan-net
--------------------------------------------------------------------------------
...
Band steer                                      : enable
...
--------------------------------------------------------------------------------

# Run the display rrm-profile name wlan-rrm command on the Fat AP to check the band steering configuration.

[FAT AP-wlan] display rrm-profile name wlan-rrm

Band balance gap threshold(%)                          : 25
...
------------------------------------------------------------

Configuration Scripts

  • FAT AP

    #
sysname FAT AP
#
wlan
 ssid-profile name wlan-net
  ssid wlan-net
 vap-profile name wlan-net
  ssid-profile wlan-net
 rrm-profile name wlan-rrm
  band-steer balance gap-threshold 25
  band-steer balance start-threshold 15
 radio-2g-profile name wlan-radio2g
  rrm-profile wlan-rrm
 radio-5g-profile name wlan-radio5g
  rrm-profile wlan-rrm
 ap-group name built_in_ap
 ap-id 0 type-id 15 ap-mac 00e0-fc55-4400 ap-sn 102428757953
  ap-name built_in_ap
  ap-group built_in_ap
  regulatory-domain-profile name default
  radio 0
   radio-2g-profile wlan-radio2g
   vap-profile wlan-net wlan 1
  radio 1
   radio-5g-profile wlan-radio5g
   vap-profile wlan-net wlan 1
#
return
