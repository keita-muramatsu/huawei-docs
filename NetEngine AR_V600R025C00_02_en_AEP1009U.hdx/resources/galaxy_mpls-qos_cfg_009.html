Applying a DiffServ Domain

Context

You can bind a DiffServ domain to the inbound or outbound interface of packets so that the device can perform mapping between external priorities and PHBs/colors according to the mappings defined in the DiffServ domain.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the interface view.

    interface interface-type interface-number

  3. Apply a DiffServ domain.

    trust upstream ds-domain-name

    By default, the default domain is applied to an interface.
