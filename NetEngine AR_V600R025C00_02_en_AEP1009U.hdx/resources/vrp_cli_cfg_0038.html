Example for Checking System Diagnosis Information

Networking Requirements

Querying system diagnosis information is critical to ensuring system stability and traceability, and can be used to handle device exceptions or faults and record the system status before configuration changes. For a single device, you can perform the configuration restoration operations as instructed in this section. If multiple devices are deployed on a network and have been interconnected with the controller, you are advised to query system diagnosis information on the controller for more efficient device management.

On the network shown in Figure 1, a user logs in to a device to collect its diagnostic information.

Figure 1 Collecting system diagnosis information

Configuration Roadmap

  1. Use STelnet to log in to the device.
  2. Collect system diagnosis information.
  3. Use SFTP to upload the collected packages to the PC and contact technical support.

Procedure

  1. Log in to the device. For details, see Example for Configuring STelnet Login for IPv4 Users (Local AAA Authentication).
  2. Collect system diagnosis information. Select one of the following methods based on the requirements:

    • Collect diagnostic logs, user logs, and KPI information generated in the last three days. (The actual command output varies depending on the device. The following command output is only an example.)
      <HUAWEI> collect diagnostic information 
Info: Operating, please wait for a moment....done.
Info: System is collecting fan log.............................................................................................done.
Info: System is uploading CANBUS log, please wait..............................................................................The task end.
Info: System is collecting diag-log from slot X cpu X, .......................................................................done.
Info: System is collecting user-log from slot X cpu X, ....................................................................done.
Info: System is collecting kpi from slot X cpu X, ............................................................done.
Info: System is compressing collected logs to flash:/diagnostic_information_HUAWEI_20250909131045.zip...done.
    • Collect all the diagnostic logs, user logs, and KPI information generated. (The actual command output varies depending on the device. The following command output is only an example.)
      <HUAWEI> collect diagnostic information all-time
Info: Operating, please wait for a moment....done.
Info: System is collecting fan log.............................................................................................done.
Info: System is uploading CANBUS log, please wait..............................................................................The task end.
Info: System is collecting diag-log from  slot X cpu X, ...............................................................done.
Info: System is collecting user-log from slot X cpu X, ...............................................................done.
Info: System is collecting kpi from slot X cpu X, ..............................................................................done.
Info: System is compressing collected logs to flash:/diagnostic_information_HUAWEI_20250909131045.zip...done.
    • Collect the diagnostic logs, user logs, and KPI information generated within a specified period. (The actual command output varies depending on the device. The following command output is only an example.)
      <HUAWEI> collect diagnostic information start-time 2025/08/09,00:00:00 end-time 2025/09/09,00:00:00 
Info: Operating, please wait for a moment....done.
Info: System is collecting fan log.............................................................................................done.
Info: System is uploading CANBUS log, please wait..............................................................................The task end.
Info: System is collecting diag-log from slot X cpu X, .............................................................................done.
Info: System is collecting user-log from slot X cpu X, ..............................................................................done.
Info: System is collecting kpi from slot X cpu X, ....................................................................................done.
Info: System is compressing collected logs to flash:/diagnostic_information_HUAWEI_20250909131045.zip...done.
    • Collect diagnostic and user logs generated in the last three days. (The actual command output varies depending on the device. The following command output is only an example.)
      <HUAWEI> collect diagnostic information file-type diag-log user-log 
Info: Operating, please wait for a moment....done.
Info: System is collecting fan log.............................................................................................done.
Info: System is uploading CANBUS log, please wait..................................................................................The task end.
Info: System is collecting diag-log from slot X cpu X, .............................................................................done.
Info: System is collecting user-log from slot X cpu X, ..............................................................................done.
Info: System is compressing collected logs to flash:/diagnostic_information_HUAWEI_20250909132247.zip...done.

  3. Export the generated diagnostic_information_hostname_timestamp.zip file from the device through FTP, SFTP, or SCP. For details, see Configuration Examples for File System Management.
  4. Contact technical support.
