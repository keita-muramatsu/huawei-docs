Restoring the Factory Defaults of an AP

Context

You can delete the current and historical user configurations and restore the factory defaults of APs.

When the configuration on an AP is incorrect or deleted, you can restore the factory defaults of the AP.

Restoring the factory defaults of an AP will reset the AP and restore all the default AP configurations.

Procedure

  • Run the ap manufacturer-config { ap-mac ap-mac | ap-id ap-id } command in the WLAN view to restore the factory defaults of an AP.
