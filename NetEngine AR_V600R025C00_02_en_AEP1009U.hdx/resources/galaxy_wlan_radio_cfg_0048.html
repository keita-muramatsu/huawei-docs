Clearing Information About Non-Wi-Fi Devices on a WAC

Context

Before re-collecting information about detected non-Wi-Fi devices in a period, you can clear existing information.

The cleared non-Wi-Fi device information cannot be restored. Exercise caution when you perform this operation.

Procedure

  • Run the reset wlan non-wifi-device { all | ap-id ap-id radio radio-id } command to clear non-Wi-Fi device information.
  • Run the reset wlan non-wifi-device history { all | ap-id ap-id radio radio-id } command to clear information about non-Wi-Fi devices in the historical list.
