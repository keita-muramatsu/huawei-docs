Binding a VAP Profile

Context

After the configuration in a VAP profile is complete, you need to bind the VAP profile to an AP group, AP, AP radio, or AP group radio, so that the configuration in the VAP profile can be automatically delivered to APs and take effect. After a VAP profile is bound to an AP group or a specific AP, the parameter settings in the profile take effect on all radios of the AP group or the specific AP. After the VAP profile is bound to an AP group radio or AP radio, the parameter settings in the VAP profile take effect on the specified radio of all APs in the AP group or the specific AP.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Bind a VAP profile. Perform any of the following operations as required:
    • Bind a VAP profile to an AP group.
      ap-group name group-name
vap-profile profile-name wlan wlan-id radio { radio-id | all } [ service-vlan vlan-id vlan-id ]

      By default, no VAP profile is bound to a radio.

    • Bind a VAP profile to an AP.
      ap-id ap-id
vap-profile profile-name wlan wlan-id radio { radio-id | all } [ service-vlan vlan-id vlan-id ]

      By default, no VAP profile is bound to a radio.

    • Apply a VAP profile in the AP group view and specify the radio on which the VAP profile takes effect.
      ap-group name group-name
vap-profile profile-name wlan wlan-id radio-policy { 2.4g | 5g | 6g | all }

      By default, no VAP profile is bound to an AP group or a specific AP, and no radio is specified for a VAP profile to take effect.

    • Apply a VAP profile in the AP view and specify the radio on which the VAP profile takes effect.
      ap-id ap-id
vap-profile profile-name wlan wlan-id radio-policy { 2.4g | 5g | 6g | all }

      By default, no VAP profile is bound to an AP group or a specific AP, and no radio is specified for a VAP profile to take effect.

    • Bind a VAP profile to radios on APs in an AP group.
      ap-group name group-name
radio radio-id
vap-profile profile-name wlan wlan-id [ service-vlan vlan-id vlan-id ]

      By default, no VAP profile is bound to a radio.

    • Bind a VAP profile to radios on an AP.
      ap-id ap-id
radio radio-id
vap-profile profile-name wlan wlan-id [ service-vlan vlan-id vlan-id ]

      By default, no VAP profile is bound to a radio.

    • Bind the VAP profile to all AP groups in the WLAN view.
      ap-group all vap-profile profile-name wlan wlan-id radio { radio-id | all }

      By default, no VAP profile is bound to radios of APs in an AP group.
