Example for IPv4 over IPv6 Tunnel

Networking Requirements

As shown in Figure 1, PC1 and PC2 on two IPv4 networks connect to an IPv6 network through DeviceA and DeviceB, respectively. An IPv4 over IPv6 tunnel needs to be established between DeviceA and DeviceB to enable PC1 and PC2 to communicate with each other.

Figure 1 Networking diagram of an IPv4 over IPv6 tunnel

In this example, interface 1 and interface 2 represent 10GE 0/0/1 and 10GE 0/0/2, respectively.


Configuration Roadmap

The configuration roadmap is as follows:

  1. Configure IP addresses for physical interfaces.
  2. Configure loopback interfaces.
  3. Create tunnel interfaces for the IPv4 over IPv6 tunnel, configure IP addresses for the tunnel interfaces, and configure the source interface and destination address of the tunnel.
  4. Configure static routes for the tunnel.

Procedure

  1. Configure IPv6 addresses for the interfaces connected to the IPv6 network.

    # Configure DeviceA.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] ipv6 enable
[DeviceA-10GE0/0/1] ipv6 address 2001:db8:100::1 64
[DeviceA-10GE0/0/1] quit

    # Configure DeviceB.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceB
[DeviceB] interface 10ge 0/0/1
[DeviceB-10GE0/0/1] ipv6 enable
[DeviceB-10GE0/0/1] ipv6 address 2001:db8:100::2 64
[DeviceB-10GE0/0/1] quit

  2. Configure IPv4 addresses for the interfaces connected to the IPv4 network.

    # Configure DeviceA.

    [DeviceA] interface 10ge 0/0/2
[DeviceA-10GE0/0/2] ip address 10.1.1.2 255.255.255.0
[DeviceA-10GE0/0/2] quit

    # Configure DeviceB.

    [DeviceB] interface 10ge 0/0/2
[DeviceB-10GE0/0/2] ip address 10.1.2.2 255.255.255.0
[DeviceB-10GE0/0/2] quit

  3. Configure loopback interfaces.

    # Configure DeviceA.

    [DeviceA] interface LoopBack 1
[DeviceA-LoopBack1] ipv6 enable
[DeviceA-LoopBack1] ipv6 address 2001:db8:200::1 64
[DeviceA-LoopBack1] quit

    # Configure DeviceB.

    [DeviceB] interface LoopBack 1
[DeviceB-LoopBack1] ipv6 enable
[DeviceB-LoopBack1] ipv6 address 2001:db8:300::2 64
[DeviceB-LoopBack1] quit

  4. Create tunnel interfaces, configure IP addresses for the tunnel interfaces, and configure the source interface and destination address of the tunnel.

    # Configure DeviceA.

    [DeviceA] interface tunnel 1
[DeviceA-Tunnel1] tunnel-protocol ipv4-ipv6
[DeviceA-Tunnel1] ip address 192.168.1.1 255.255.255.0
[DeviceA-Tunnel1] source LoopBack 1
[DeviceA-Tunnel1] destination 2001:db8:300::2
[DeviceA-Tunnel1] quit

    # Configure DeviceB.

    [DeviceB] interface tunnel 1
[DeviceB-Tunnel1] tunnel-protocol ipv4-ipv6
[DeviceB-Tunnel1] ip address 192.168.1.2 255.255.255.0
[DeviceB-Tunnel1] source LoopBack 1
[DeviceB-Tunnel1] destination 2001:db8:200::1
[DeviceB-Tunnel1] quit

  5. Configure routes for forwarding packets along the IPv4 over IPv6 tunnel.

    # Configure DeviceA.

    [DeviceA] ipv6 route-static 2001:db8:300::2 64 10ge 0/0/1 2001:db8:100::2
[DeviceA] ospf 1
[DeviceA-ospf-1] area 0
[DeviceA-ospf-1-area-0.0.0.0] network 192.168.1.0 0.0.0.255
[DeviceA-ospf-1-area-0.0.0.0] network 10.1.1.0 0.0.0.255
[DeviceA-ospf-1-area-0.0.0.0] quit

    # Configure DeviceB.

    [DeviceB] ipv6 route-static 2001:db8:200::1 64 10ge 0/0/1 2001:db8:100::1
[DeviceB] ospf 1
[DeviceB-ospf-1] area 0
[DeviceB-ospf-1-area-0.0.0.0] network 192.168.1.0 0.0.0.255
[DeviceB-ospf-1-area-0.0.0.0] network 10.1.2.0 0.0.0.255
[DeviceB-ospf-1-area-0.0.0.0] quit

Configuration Scripts

  • DeviceA

    #
sysname DeviceA
#
interface 10GE0/0/1
 ipv6 enable
 ipv6 address 2001:DB8:100::1/64
#
interface 10GE0/0/2
 ip address 10.1.1.2 255.255.255.0
#
interface LoopBack1
 ipv6 enable
 ipv6 address 2001:DB8:200::1/64
#
interface Tunnel1
 ip address 192.168.1.1 255.255.255.0
 tunnel-protocol ipv4-ipv6
 source LoopBack1
 destination 2001:DB8:300::2
#                                                                              
ospf 1
 area 0.0.0.0
  network 192.168.1.0 0.0.0.255
  network 10.1.1.0 0.0.0.255
#
ipv6 route-static 2001:DB8:300:: 64 10GE0/0/1 2001:DB8:100::2
#
return
