Querying Global IPsec Statistics

Description of MIB Objects

You can use the following objects to query global IPsec statistics.

Table 1 Description of MIB objects

Object

OID

hwIPSecGlobalTotal

1.3.6.1.4.1.2011.6.122.26.1.1

hwIPSecGlobalPacketInput

1.3.6.1.4.1.2011.6.122.26.1.2

hwIPSecGlobalPacketOutput

1.3.6.1.4.1.2011.6.122.26.1.3

hwIPSecGlobalByteInput

1.3.6.1.4.1.2011.6.122.26.1.4

hwIPSecGlobalByteOutput

1.3.6.1.4.1.2011.6.122.26.1.5

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.

  2. Perform a walk operation on hwIPSecGlobalTotal to query the total number of established IPsec tunnels. As shown in Figure 1, the total number of established IPsec tunnels is 0.

    Figure 1 Query result of hwIPSecGlobalTotal

  3. Perform a walk operation on hwIPSecGlobalPacketInput to query the number of IPsec packets received by the device. As shown in Figure 2, the number of IPsec packets received by the device is 0.

    Figure 2 Query result of hwIPSecGlobalPacketInput

  4. Perform a walk operation on hwIPSecGlobalPacketOutput to query the number of IPsec packets sent by the device. As shown in Figure 3, the number of IPsec packets sent by the device is 0.

    Figure 3 Query result of hwIPSecGlobalPacketOutput

  5. Perform a walk operation on hwIPSecGlobalByteInput to query the number of bytes in IPsec packets received by the device. As shown in Figure 4, the number of bytes in IPsec packets received by the device is 0.

    Figure 4 Query result of hwIPSecGlobalByteInput
  6. Perform a walk operation on hwIPSecGlobalByteOutput to query the number of bytes in IPsec packets sent by the device. As shown in Figure 5, the number of bytes in IPsec packets sent by the device is 0.
    Figure 5 Query result of hwIPSecGlobalByteOutput
