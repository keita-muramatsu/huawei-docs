Configuring an Address Group

Procedure

  1. Enter the system view.

    system-view

  2. Create an address group and access its view.

    ip address-set address-set-name type group

    address-set-name cannot be set to any or all. You need to specify the type parameter when creating an address group. After an address group is created and its view is displayed, you do not need to specify this parameter.

  3. Add an address object or address group.

    address [ id ] address-set address-set-name [ description description ]

    You can run this command repeatedly to add multiple address objects or sub-address groups to an address group.

  4. Optional: Configure a description for the address group.

    description description

    The proper description helps you maintain and manage address groups.

  5. Delete unreferenced address objects, address groups, or all unreferenced address sets, including all address objects and address groups.

    undo ip address-set unreferenced { object | group | all }

Verifying the Configuration

  • Run the display ip address-set type group command in any view to check information about all address groups.
  • Run the display ip address-set verbose address-set-name { item | reference } command in any view to check detailed information about a specified address group.
  • Run the display ip address-set address { ipv4-address | ipv6-address } command in any view to check information about the address object or address group that contains a specified IP address.
