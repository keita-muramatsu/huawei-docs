Applying the Security Profile Configuration

Context

After a WLAN security policy is configured in a security profile, the security profile needs to be bound to a VAP profile in order to take effect. Note that each VAP profile can have only one security profile bound. In this manner, STAs can access the WLAN through an SSID only after they are successfully authenticated based on the security policy configured in the VAP.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a VAP profile and enter its view.

    vap-profile name profile-name

    By default, the VAP profile default exists in the system.

  4. Bind a security profile to the VAP profile.

    security-profile profile-name

    By default, the security profile default is bound to a VAP profile.
