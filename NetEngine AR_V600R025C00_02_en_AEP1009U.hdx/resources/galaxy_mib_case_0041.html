Querying the LLDP Configuration

Description of MIB Objects

You can use the following objects to obtain the local LLDP configuration.

Object

OID

lldpMessageTxInterval

1.0.8802.1.1.2.1.1.1

lldpMessageTxHoldMultiplier

1.0.8802.1.1.2.1.1.2

lldpReinitDelay

1.0.8802.1.1.2.1.1.3

lldpTxDelay

1.0.8802.1.1.2.1.1.4

lldpNotificationInterval

1.0.8802.1.1.2.1.1.5

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.

  2. Perform the Walk operation on lldpMessageTxInterval to query the LLDP packet sending interval. As shown in Figure 1, the LLDP packet sending interval is 100.

    Figure 1 Querying the LLDP packet sending interval

  3. Perform the Walk operation on lldpMessageTxHoldMultiplier to query the hold time multiplier of LLDP information on neighbors. As shown in Figure 2, the hold time multiplier of LLDP information on neighbors is 8.

    Figure 2 Querying the hold time multiplier of LLDP information on neighbors

  4. Perform the Walk operation on lldpReinitDelay to query the delay in LLDP initialization. As shown in Figure 3, the delay in LLDP initialization is 8.

    Figure 3 Querying the delay in LLDP initialization

  5. Perform the Walk operation on lldpTxDelay to query the delay for sending LLDP packets. As shown in Figure 4, the delay for sending LLDP packets is 10.

    Figure 4 Querying the delay for sending LLDP packets

  6. Perform the Walk operation on lldpNotificationInterval to query the delay for sending neighbor information change alarms to the NMS. As shown in Figure 5, the delay for sending neighbor information change alarms to the NMS is 8.

    Figure 5 Querying the delay for sending neighbor information change alarms to the NMS
