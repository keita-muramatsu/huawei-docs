Keeping Users Online Upon the Change of the Access Port Type or Access VLAN

Context

After a user passes access authentication, you can change the access port type or access VLAN of the user through the RADIUS server. For example, you can assign VLANs to clients through the RADIUS server for network planning and deployment. After the deployment is complete, to reduce the impact of link faults and device restarts on the network and to implement rapid network recovery, you can change the user access VLAN to the authorized VLAN. In this case, you can enable the function of keeping users online upon the change of the access port type or access VLAN in order to modify the port or VLAN configuration.

Procedure

  1. Enter the system view.

    system-view

  2. Enable the function of keeping users online upon the change of the access port type or access VLAN.

    authentication port-vlan-modify user-online

    By default, the function of keeping users online upon the change of the access port type or access VLAN is disabled.
