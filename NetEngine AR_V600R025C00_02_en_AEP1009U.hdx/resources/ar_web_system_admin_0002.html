Administrator

Procedure

  1. Choose System > Administrator > Administrator. The Administrator List page is then displayed.
  2. Click Create. The Add Administrator dialog box is displayed, as shown in Figure 1.

    Figure 1 Add Administrator dialog box

  3. Set parameters. Table 1 lists the parameters.

    If the operation succeeds, the new administrator account is displayed in the administrator list.

    Repeat the preceding steps to create other administrator accounts.

    Table 1 Parameters for configuring an administrator

    Parameter

    Description

    Name

    User name of an administrator account.

    The user name must be unique.

    Password/Confirm Password

    Password of the administrator account.

    • The password is mandatory when local authentication is used.

    User Level

    User level of the administrator account. The options are as follows:

    • 0: guest
    • 1: monitoring administrator
    • 2: configuration administrator
    • 3: system administrator

    Role

    Role of the administrator account. Select a created administrator role.

    NOTE:

    If User Level is configured, Role cannot be configured.

    Trusted Host

    Trusted host of the web administrator account.

    • Enter one IP address per line. Both IPv4 and IPv6 addresses can be entered. Use carriage return characters to separate lines.
    • You can add a maximum of 15 trusted host IP addresses for each account.
    • Administrators using different IP addresses are not allowed to log in to the device web system, but they can log in to the device through the console port.

    Advanced Settings

    Access Type

    Service type of the administrator. The options include Web(HTTP/HTTPS), Telnet, SSH, Console, and FTP.

    NOTE:

    • If FTP is used, the system automatically generates an FTP directory for the administrator.

    • There are security risks if the service type is Telnet or FTP. Therefore, you are advised to set the service type to SSH.

    SSH Authentication

    SSH authentication mode of the administrator. The options are as follows:

    • RSA: indicates the RSA authentication mode.
    • PASSWORD-RSA: indicates that authentication succeeds when the administrator passes both RSA and password authentication.
    • PASSWORD: indicates the password authentication mode, which is the default mode.
    • ALL: indicates that authentication succeeds when the administrator passes either RSA or password authentication.

    This parameter is mandatory when an SSH authentication account is created.

    RSA Key

    This parameter can be set when SSH Authentication is set to RSA, PASSWORD-RSA, or ALL.

    Select a created RSA key. To create one, perform the following operations:
    1. Click Manage RSA Key
    2. Click Add.
    3. Enter a name in the Public Key Name text box.
    4. Enter a key in the Key text box for an RSA peer. The key is generated by an SSH client, and you can copy and paste the key in the Key text box.
    5. Click OK.
    6. Click Close.

    By default, an administrator account created using the web system supports the web service type.

    The administrator service type and enabled service on the device determine the login method. For example, if an administrator wants to log in using HTTPS through the management interface, the management interface must enable the HTTPS access control, the administrator account must support HTTPS, and the device must enable HTTPS.

  4. Click OK.

Follow-up Procedure

You can click the name of an administrator account to modify its settings.

To change the password of an administrator, enter the current administrator account password in the Enter the current administrator password dialog box that is displayed and then click Confirm.

For administrators created on the web system, you are advised to modify or delete them on the web system to prevent the mixed use of the web system and CLI.
