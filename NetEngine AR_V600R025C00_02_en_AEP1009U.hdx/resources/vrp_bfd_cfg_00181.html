Configuring a Multicast BFD Session with Automatically Negotiated Discriminators

Context

To quickly monitor link connectivity between interfaces without Layer 3 attributes (for example, without IP addresses), you can configure a multicast BFD session with automatically negotiated discriminators. After a multicast BFD session is configured, multicast BFD packets are sent using the IP layer. If the link is reachable, the remote interface receives the multicast BFD packets and forwards them to the BFD module. In this manner, the BFD module detects that the link is normal. The peer IP address of the multicast BFD session is the well-known multicast address Default-IP (224.0.0.107 to 224.0.0.250) configured for the BFD module. Any interface that receives packets from this IP address sends the packets to the BFD module for forwarding.

Procedure

  1. Enable BFD globally.
    1. Enter the system view.

      system-view

    2. Enable BFD globally and enter the global BFD view.

      bfd

  2. Create a BFD session.
    1. Enter the system view.

      system-view

    2. Create a multicast BFD session with automatically negotiated discriminators.

      bfd session-name bind peer-ip default-ip interface { interface-name | interface-type interface-number }[ source-ip source-ip ] auto

Verifying the Configuration

Run the display bfd session { all for-ipv6 | discriminator discr-value | dynamic | peer-ipv6 peer-ipv6 [ vpn-instance vpn-instance-name ] | peer-ip default-ip | static for-ipv6 | static-auto } [ verbose ] command to check BFD session information.
