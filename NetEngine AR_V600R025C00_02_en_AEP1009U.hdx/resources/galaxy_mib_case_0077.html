Querying the IP Addresses of All Interfaces

Description of MIB Objects

You can use ipAdEntAddr in ipAddrTable to obtain the IP addresses of all interfaces.

Object

OID

ipAdEntAddr

1.3.6.1.2.1.4.20.1.1

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.
  2. Perform the Walk operation on ipAdEntAddr to query the IP addresses of all interfaces.
