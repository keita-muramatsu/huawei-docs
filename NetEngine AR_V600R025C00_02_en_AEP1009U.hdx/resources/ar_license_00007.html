Obtaining Commercial Licenses for Capacity Expansion Projects

Prerequisites

  • The entitlement ID (LAC) and capacity expansion contract ID have been obtained.
  • The device ESNs have been obtained.
  • The product name and ESN in the contract are the same as those on the live network.
  • The entitlement in Ready state is available for the device that requires capacity expansion.

Context

For capacity expansion projects, the license management system automatically combines the licenses on the same device to generate a new license file. The version of product with capacity expanded must be the same as or later than the version of current product.

Procedure

  1. Log in to the ESDP (channel edition) at https://esdp.huawei.com.
  2. Activate the license.
    • Entitlement activation

      Activate an entitlement online by binding it to an ESN, so as to generate a license.

      If a large number of entitlements need to be activated, you can activate them in batches. For details, see Activating Entitlements in Batches.

      • Only entitlements whose delivery status is READY can be activated.
      • If the entered ESN does not exist in the system but meets ESN verification rules, an ESN will be created.
      • If an entitlement uses the SnS model, the entitlement can be activated only when the SnS service on the equipment (node) is within the validity period.
      • Activated entitlements with the same version, product, and configuration list are automatically combined.
      • If you encounter any problem that cannot be resolved, click Feedback on the home page to contact us.
      1. Enter search criteria and click Search.

        Path: License Management > License Activation > Entitlement Activation (Recommended)

      2. Select the entitlement to activate and click Activation.

      3. Enter the ESN and equipment (node) name, and click Next.

      4. Verify the data and click Confirm Activation.

      5. After successful activation, click Download to download the license file to the local PC.

    • Activating Entitlements in Batches
      1. Enter search criteria and click Search.

        Path: License Management > License Activation > Entitlement Activation (Recommended)

      2. Select one or more records and choose Batch Activation > Export Entitlements. If no record is selected, all search results will be exported.

      3. Enter ESNs and save the file.

      4. Choose Batch Activation > Import for Activation.

      5. Select the corresponding file and click Upload.

      6. After the file is uploaded successfully, click Confirm Activation.

      7. After successful activation, click Download to download the license file to the local PC.

    • Password activation
      1. Find the activation password in the "Proof of Entitlement."

      2. Enter the activation password and an ESN, and click Next.

        Path: License Management > License Activation > Password Activation

      3. Enter the company name and click Confirm Activation.

      4. After successful activation, click Download.
