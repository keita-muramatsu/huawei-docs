Overview of Centralized License Control

On a large enterprise network, multiple WACs are typically deployed to expand the networking scale or improve networking reliability. In such a scenario, you need to apply for a license for each WAC and each license is exclusive to the local WAC. With centralized license control, one WAC functions as the license server to manage all license resources, while the other WACs function as license clients to report local license resources to the license server. When APs go online on a WAC functioning as a license client, the license client applies for licenses from the license server. When the APs go offline, the license client notifies the license server of the event in a timely manner so that the license server can release licenses. Centralized license control achieves unified management and flexible allocation of licenses on the network, making license use easier and more efficient.
