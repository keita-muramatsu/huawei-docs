Creating a Security Profile

Context

A WLAN security policy can be used to authenticate STAs and encrypt STA packets, securing both the WLAN and STAs.

WLAN security policies are configured in security profiles, and only one security policy can be configured in a security profile. You can create multiple security profiles to achieve differentiated security policies and bind the profiles to different VAPs as required.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a security profile and enter the security profile view.

    security-profile name profile-name

    By default, the security profile default exists in the system and has no security policy configured. To ensure that STAs properly access the WLAN, you must configure a security policy in the security profile.
