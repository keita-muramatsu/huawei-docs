Enabling the Batch Packet Receiving Function for the TCP Proxy Stack

Context

After the batch packet receiving function is enabled for the TCP proxy stack, the protocol stack will combine multiple packets before sending them to the CPU, improving data processing efficiency.

Procedure

  1. Enter the system view.

    system-view

  2. Enable the batch packet receiving function when the TCP proxy sends packets.

    tcp-proxy batch-receive enable

    By default, the batch packet receiving function is disabled for the TCP proxy stack.
