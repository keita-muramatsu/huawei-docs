Configuring an AP-Offline Backup Service VAP

Prerequisites

Before configuring an AP-offline backup service VAP, complete the following task:

Deploy basic WLAN services and ensure that STAs can properly access the WLAN.

Context

After a CAPWAP link is disconnected, the AP-offline backup service VAP is automatically enabled. Users need to manually associate STAs with the SSID of the AP-offline backup service VAP so that the STAs can access the network through the AP-offline backup service VAP. If AP-offline service continuity is enabled on the VAP to which the STAs are originally connected, the STAs will not be disconnected from the VAP and users can determine whether to manually associate STAs with the SSID of the AP-offline backup service VAP as required. If AP-offline service continuity is disabled on the VAP to which the STAs are originally connected, the VAP will be disabled and the STAs will be disconnected. In this case, users need to manually associate the STAs with the SSID of the AP-offline backup service VAP.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a security profile and enter the security profile view.

    security-profile name profile-name

    By default, the security profile default exists in the system and has no security policy configured. To ensure that STAs properly access the WLAN, you must configure a security policy in the security profile.

  4. Run the security command in the new security profile to set the security policy to WPA3 SAE, WPA2-WPA3 PSK-SAE, open, WPA+PSK, WPA2+PSK, or WPA-WPA2+PSK for the backup VAP. For details, see Configuring Security Policies.

    By default, no security policy is configured.

  5. Return to the WLAN view.

    quit

  6. (Optional) Create an SSID profile and enter its view.

    ssid-profile name profile-name

    By default, the SSID profile default exists on the device.

  7. (Optional) Configure the SSID name.

    ssid ssid

    By default, the SSID HUAWEI-WLAN is configured in an SSID profile.

  8. Return to the WLAN view.

    quit

  9. Create a VAP profile and enter its view.

    vap-profile name profile-name

    By default, the VAP profile default exists on the device.

  10. The configuration in this VAP profile must be the same as that in the original VAP profile. For details about configurations supported in a VAP profile, see "WLAN STA Management Configuration" in CLI Configuration Guide > WLAN Configuration.
  11. Sets the VAP type to AP-offline backup service.

    type service-backup ap-offline

    The default type of a VAP is service.

  12. Bind the security profile to the new VAP profile.

    security-profile profile-name

    By default, the security profile default is bound to a VAP profile.

  13. (Optional) Bind the SSID profile to the new VAP profile.

    ssid-profile profile-name

    By default, the SSID profile default is bound to a VAP profile.

  14. Bind the new VAP profile to the same radio as the original VAP. For details, see Binding a VAP Profile.
