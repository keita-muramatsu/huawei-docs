Default Settings for Logical Interfaces

Table 1 describes the default settings for logical interfaces.

Table 1 Default settings for logical interfaces

Interface Type

Default Setting

VLANIF interface

Does not exist on devices.

Eth-Trunk interface

Does not exist on devices.

Layer 3 Ethernet sub-interface

Does not exist on devices.

Layer 3 Eth-Trunk sub-interface

Does not exist on devices.

VE interface

Does not exist on devices.

Loopback interface

An InLoopback0 interface is created automatically on device startup.

Null0 interface

A Null0 interface is created automatically on device startup.

Tunnel interface

Does not exist on devices.
