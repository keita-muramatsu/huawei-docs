Querying the BFD Status

Description of MIB Objects

hwBfdSessDown is an alarm object. It indicates that the BFD session status changes from Up to Down, which is notified to the NMS.

hwBfdSessUp is an alarm object. It indicates that the BFD session status changes from Down to Up, which is notified to the NMS.

Object

OID

hwBfdSessDown

1.3.6.1.4.1.2011.5.25.38.3.1

hwBfdSessUp

1.3.6.1.4.1.2011.5.25.38.3.2

Procedure

BFD alarms need to be manually triggered. Alarm objects do not save any content, so no data can be obtained through the Walk operation.

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.
  2. Query hwBfdSessDown on the alarm page. As shown in Figure 1, hwBfdSessDown is queried.
    Figure 1 Querying hwBfdSessDown
  3. Query hwBfdSessUp on the alarm page. As shown in Figure 2, hwBfdSessUp is queried.
    Figure 2 Querying hwBfdSessUp
