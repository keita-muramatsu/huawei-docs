Maintaining Security Policies

Table 1 lists the maintenance operations related to security policies.

Table 1 Maintaining security policies

Operation

Command

Enable the function to verify the configuration of the policy matching condition is configured.

policy configuration-verification enable

View the enabled debugging of the policy module.

display debugging policy

Reset the number of times security policy rules are matched.

reset security-policy counter { all | rule rule-name }
