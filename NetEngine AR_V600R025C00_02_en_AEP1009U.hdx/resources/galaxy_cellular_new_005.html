Cellular Network Implementation

Cellular Function Modules

The device uses a cellular card and a SIM card to implement the cellular function. A cellular card is provided by Huawei and delivers the cellular function, which involves a cellular modem, a cellular interface, and cellular channel interfaces. Figure 1 shows the relationships between these function modules. The functions of a SIM card are provided by the carrier. On the device, you need to configure functions of the cellular card and bind the cellular function modules with the SIM card.

Figure 1 Cellular function modules
  • Cellular modem: implements the cellular function on the cellular card. All cellular functions of the device need to invoke the cellular modem capability. The cellular modem is configured through a cellular profile and APN profile.
  • Cellular interface: a logical interface generated after a cellular card is installed on a device. This interface can be queried using the display interface command. The interface name is Cellular n/0/0, where n is the slot number of the cellular card. To enable a cellular interface to invoke the cellular modem capability, you need to apply a configured cellular profile to the cellular interface. In this way, services defined in the cellular profile are applied to the cellular interface.
  • Cellular channel interface: a sub-interface of a cellular interface. A cellular card can provide a single, two, or four channel interfaces. Figure 1 shows a cellular card that provides two channel interfaces. For a cellular card that provides a single channel interface, the channel interface is named Cellular n/0/0:1. For a cellular card that provides two channel interfaces, the channel interfaces are named Cellular n/0/0:1 and Cellular n/0/0:2. Cellular channel interfaces can be associated with different network service types. To achieve this, you need to apply different APN profiles to cellular channel interfaces. The cellular modem capability can then be used.

According to the description above, the cellular network configuration on a device is implemented based on cellular and APN profiles.

  • You can configure the following information in a cellular profile: carrier (by configuring PLMN information), network generation (3G/4G/5G, by configuring the cellular network connection mode), wireless network operating frequency band, wireless network dial-up interval, and international mobile subscriber identity (IMSI) authentication information of a SIM card.
  • You can configure the following information in an APN profile: network service type (such as the voice service, SMS service, and Internet service, specified by the APN name), associated SIM card, and security authentication information (PIN and PUK) of the SIM card.
  • Some models have built-in cellular modems. These models have cellular interfaces and cellular channel interfaces available even if you do not install a cellular card on them.
  • The ID of the cellular interface and the number of cellular channel interfaces vary according to devices.
  • By default, the device can automatically match the PLMN information of a SIM card. If the SIM card supports only a single carrier, there is no need to specify the PLMN information. However, if the SIM card supports multiple carriers, the device can match PLMN information of multiple carriers and automatically connects to the PLMN with the strongest signal. To avoid switching between carriers, you are advised to specify PLMN information on the cellular modem.
  • You can set the default network service type (default APN) in a cellular profile. Note that if the default APN is configured in a cellular profile, all cellular channel interfaces use the default APN to set up dial-up connections.

Cellular Dial-up Connection

The device connects to a carrier network in dial-up mode. After auto dial-up is enabled, the device automatically tries to set up a dial-up connection with the carrier network without being triggered by data packets. If the dial-up fails, the device tries again at specified intervals. Figure 2 shows the dial-up connection process.

Figure 2 Dial-up connection process

The process is as follows:

  1. The cellular channel interface sends a connection setup request to the cellular modem.
  2. The cellular modem sends a connection setup request to the carrier network. The request contains authentication information about the device identity, like the APN, user name, and password.
  3. The carrier network authenticates the device identity. After authentication succeeds, the core network sets up a connection with the cellular modem and assigns an IP address to the modem.
  4. The cellular modem instructs the cellular channel interface to go up.
  5. The cellular channel interface negotiates with the cellular modem for an IP address, and obtains the IP address assigned by the cellular modem.
  6. The cellular channel interface sets up a connection with the carrier network for data service forwarding.
