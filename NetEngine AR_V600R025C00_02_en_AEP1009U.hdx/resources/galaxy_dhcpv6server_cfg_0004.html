(Optional) Configuring Network Server Addresses for an IPv6 Address Pool

Context

To ensure that DHCPv6 clients can communicate normally, the DHCPv6 server needs to specify the DNS server, the SIP server, and other configuration parameters when assigning IPv6 addresses to clients. The DHCPv6 server can automatically assign configuration parameters such as the IPv6 addresses of the DNS and SIP servers to clients.

Procedure

  1. Enter the system view.

    system-view

  2. Create an IPv6 address pool and enter its view.

    dhcpv6 pool pool-name

    By default, no IPv6 address pool is created on a device.

  3. Perform the following steps in the IPv6 address pool view to configure network server addresses. You can perform one or more steps as needed:

    • Configure the DNS server address that the DHCPv6 server assigns to a DHCPv6 client.
      dns-server ipv6-address
    • Configure the DNS domain name suffix that the DHCPv6 server assigns to a DHCPv6 client.
      dns-domain-name domain-name
    • Configure the SIP server address that the DHCPv6 server assigns to a DHCPv6 client.
      sip-server ipv6-address
    • Configure the SIP domain name suffix that the DHCPv6 server assigns to a DHCPv6 client.
      sip-domain-name domain-name
    • Configure the NIS server address that the DHCPv6 server assigns to a DHCPv6 client.
      nis-server ipv6-address
    • Configure the NIS domain name suffix that the DHCPv6 server assigns to a DHCPv6 client.
      nis-domain-name domain-name
    • Configure the NISP server address that the DHCPv6 server assigns to a DHCPv6 client.
      nisp-server ipv6-address
    • Configure the NISP domain name suffix that the DHCPv6 server assigns to a DHCPv6 client.
      nisp-domain-name domain-name
    • Configure the SNTP server address that the DHCPv6 server assigns to a DHCPv6 client.
      sntp-server ipv6-address

    By default, no DNS, SIP, NIS, NISP, or SNTP server address is configured for an IPv6 address pool.
