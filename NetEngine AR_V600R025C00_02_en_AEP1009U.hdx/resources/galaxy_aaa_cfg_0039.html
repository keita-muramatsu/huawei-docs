Overview of HWTACACS

Huawei Terminal Access Controller Access Control System (HWTACACS), an enhancement to TACACS (RFC 1492), is a centralized information exchange protocol using the client/server architecture. It operates over TCP and uses TCP port 49 by default. The authentication, authorization, and accounting services provided by HWTACACS are independent of each other and can be implemented on different servers.

  • HWTACACS can only use the MD5 algorithm to obtain packet digests, which poses security risks.
  • To prevent data transmission risks between the device and HWTACACS server, you are advised to deploy the device and HWTACACS server in the same security domain.
Both HWTACACS and RADIUS have the following characteristics:
  • Client/Server model

    HWTACACS client: generally resides on the Network Access Server (NAS) and can reside on the entire network. The client is responsible for transmitting user information to the specified HWTACACS server and then performs operations accordingly based on the server-returned information.

    HWTACACS server: generally runs on the central computer or workstation. The server maintains user authentication and network access information, and is responsible for receiving user connection requests, authenticating users, and returning required information to clients.

  • Shared key used for encrypting user information
  • Good scalability

HWTACACS takes advantages over RADIUS in transmission and encryption reliability, and better suitability for security control. Table 1 lists the differences between HWTACACS and RADIUS.
