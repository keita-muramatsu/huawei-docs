Understanding an Intermediate File

An intermediate file is used to save information about the device to be deployed and its deployment files. The file name must be USB_AR_V600.INI, and the following is an example of such a file. For details about the fields included in this file, see Table 1.

;BEGIN USB
[GLOBAL CONFIG]
*TIME_SN=20200526120159 
*DEVICE_TYPE_NUM=1

[DEVICE_TYPE_1 DESCRIPTION]
DEVICE_TYPE=DEFAULT 
ESN=DEFAULT
MAC=DEFAULT
FILETYPENUM=1
FILENAME_1=ZTP_V600.INI
TYPE_1=CONFIG-LITE
EFFECTIVE_MODE_1=1
;END USB CONFIG
Table 1 Fields in the intermediate file

Field

Mandatory or Not

Description

;BEGIN USB

Yes

Start flag of a file. This field cannot be modified.

[GLOBAL CONFIG]

Yes

Start flag of the global configuration. This field cannot be modified.

*TIME_SN

No

Time when a file takes effect. The value format is yyyymmddhhmmss.

For example, this field can be set to 20200526120159, indicating 12:01:59 on 2020-05-26.

This field is not matched during streamlined USB-based deployment.

*DEVICE_TYPE_NUM

Yes

Number of device types.

In streamlined USB-based deployment, the value of DEVICE_TYPE_NUM is 1.

[DEVICE_TYPE_n DESCRIPTION]

Yes

Start tag of the device description. n indicates the device number. The value is an integer starting from 1.

DEVICE_TYPE

Yes

Device type.

In streamlined USB-based deployment, the value of DEVICE_TYPE is DEFAULT, indicating that the device type is not matched.

ESN

Yes

ESN of a device.

In streamlined USB-based deployment, the value of ESN is DEFAULT, indicating that the ESN does not need to be matched.

MAC

Yes

Device MAC address.

In streamlined USB-based deployment, the value of MAC is DEFAULT, indicating that the MAC address does not need to be matched.

FILETYPENUM

Yes

Number of deployment files to be loaded.

In streamlined USB-based deployment, the value of FILETYPENUM is 1.

NOTE:

The value of this field must be the same as the actual number of deployment files, and the value is the same as n in FILENAME_n.

FILENAME_n

Yes

Name of a deployment file.

In streamlined USB-based deployment, the deployment file name is ZTP_V600.INI.

TYPE_n

Yes

Type of a deployment file.

In streamlined USB-based deployment, the value is CONFIG-LITE.

EFFECTIVE_MODE_n

Yes

Activation mode.

In streamlined USB-based deployment, the value is 1, indicating that the deployment file takes effect immediately.

;END USB CONFIG

Yes

End flag of a file. This field cannot be modified.
