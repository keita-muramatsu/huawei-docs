Understanding Option Parameters

The DHCP server uses Option parameters to transmit network configurations to devices to implement automatic configuration during ZTP.

The device sends a DHCP Discover message that carries DHCPv4 Option parameters when the DHCP Discover phase starts in DHCPv4 scenarios. Table 1 describes the parameters.

Table 2 describes the DHCPv4 Option parameters to be configured on the DHCPv4 server.

The DHCP server does not support authentication and may be spoofed. You are advised to use a trusted DHCP server for deployment on a secure network.

Table 1 DHCPv4 Option parameters in a request

Option

Function

Example

Option 60

Vendor ID, which indicates the vendor and model of a device.

"huawei AR8140-12G10XG"

Option 61

Client ID, which indicates the MAC address of a device.

"00e0-fc12-3456"
Table 2 DHCPv4 Option parameters in a response for SZTP

Option

Mandatory or Not

Function

Option 1

Yes

Subnet mask of the device IP address.

Option 3

Yes

Egress gateway of the device.

Option 6

No

IP address of the DNS server.

A DNS server is required if a domain name (for example, www.ztp.com) is specified as the host name of the bootstrap server. It is not required if an IP address is specified as the host name.

Option 7

No

IP address of the Syslog server.

Option 143

Yes

Bootstrap server address list.

A maximum of 10 bootstrap servers can be configured. The bootstrap servers with the same IP address and VPN instance name are considered as one bootstrap server.

NOTE:

This field must be configured using the option 143 hex sub-hex-string command. The value of sub-hex-string is obtained by converting the character string of the bootstrap server address into a hexadecimal number.
