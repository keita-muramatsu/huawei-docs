Understanding Monitor Link

Monitor Link monitors an uplink interface and synchronizes the downlink interface status with the uplink interface status. The uplink and downlink interfaces form a Monitor Link group.

On the network shown in Figure 1, a Monitor Link group is configured on both DeviceB and DeviceD. Interface1 and interface3 are added to the Monitor Link groups as uplink interfaces, and interface2 and interface4 are added to the Monitor Link groups as downlink interfaces.

If the uplink interface in a Monitor Link group fails due to a link fault, a unidirectional OAM connectivity fault, or an OAM connection setup fault, the downlink interface in the Monitor Link group is forcibly shut down (in the Error-Down state). When the uplink recovers, the downlink interface is restored to the Up state. The failure of a downlink interface does not affect the uplink interface or the other downlink interfaces in the same Monitor Link group.

A Monitor Link group member can either be a single interface, static link aggregation group, or manual link aggregation group. If multiple interfaces are configured as the uplink interfaces of a Monitor Link group, the Monitor Link group is up as long as one uplink interface is up. Conversely, the downlink interfaces of the Monitor Link group are set to down only when all uplink interfaces are down. If a downlink interface is a link aggregation group and the uplink fails, Monitor Link forcibly sets all interfaces in the aggregation group to the Down state. When the uplink recovers, Monitor Link restores all interfaces in the link aggregation group to the Up state.
