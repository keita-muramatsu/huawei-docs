Understanding Inter-VLAN Communication

Two types of interfaces can be configured to implement inter-VLAN communication across network segments:

  • VLANIF interface: is a Layer 3 logical interface that is most commonly used to implement Layer 3 communication between hosts in different VLANs across different network segments.

    Each VLANIF interface corresponds to a VLAN. After an IP address is configured for a VLANIF interface, the VLANIF interface becomes the gateway of the user hosts within that VLAN and forwards packets across network segments at Layer 3.

    If users on multiple network segments need to communicate with each other, a primary IP address and multiple secondary IP addresses need to be configured on a VLANIF interface.

  • Layer 3 sub-interface: is a Layer 3 logical interface that allows Layer 3 communication between users in different VLANs across different network segments. Using VLANIF interfaces to implement inter-VLAN communication require multiple physical interfaces. To solve this problem, configure Layer 3 sub-interfaces instead.

For detailed fundamentals of the implementation, see Inter-VLAN Communication.
