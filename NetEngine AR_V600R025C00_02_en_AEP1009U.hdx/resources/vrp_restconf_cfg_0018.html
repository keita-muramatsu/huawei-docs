with-defaults

with-defaults indicates that a device is capable of specifying how information about default data nodes should be returned. This parameter is allowed only for the GET method. If it is used in other operation methods, "400 Bad Request" is returned.

The values of this parameter are as follows:
  • report-all: All data nodes are reported, and no operation is performed on any node. report-all is the default value.
  • trim: Nodes whose configuration values are equal to the default values are not displayed in query results.
  • report-all-tagged: All nodes are queried, and nodes whose configuration values are equal to the default values are marked using default="true".
Example: The fields parameter is specified when you want to query some specific content in the target data.

  • Request

    GET /restconf/data/huawei-aaa:aaa/domains?with-defaults=report-all-tagged  HTTP/1.1
Host: X.X.X.X
Accept: application/yang-data+xml
Content-Type: application/yang-data+xml
Content-Length: 84
Authorization: Basic YXBpLWFkbWluOkFkbWluQDEyMw==

  • Response

    HTTP/1.1 200 OK
Date: Wed, 18 Apr 2022 12:00:00 GMT
Content-Type: application/yang-data+xml
Content-Length: 449

<?xml version="1.0" encoding="UTF-8"?>
 <data xmlns="urn:ietf:params:xml:ns:yang:ietf-restconf">
    <aaa xmlns="urn:huawei:yang:huawei-aaa">
      <domains>
        <domain>
          <name>default</name>
          <authen-scheme-name>default</authen-scheme-name>
        </domain>
        <domain>
          <name>default_admin</name>
          <authen-scheme-name>default</authen-scheme-name>
        </domain>
      </domains>
    </aaa>
</data>
