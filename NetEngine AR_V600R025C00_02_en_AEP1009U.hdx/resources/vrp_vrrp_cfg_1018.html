Configuring the Mode for Sending VRRP Advertisement Packets in VLANs

Context

When a VRRP group is configured for a super VLAN, VRRP Advertisement packets can be sent to a specified sub-VLAN using commands, avoiding broadcasting every VRRP Advertisement packet in all sub-VLANs of the super VLAN. This reduces the bandwidth used by VRRP Advertisement packets and improves bandwidth usage efficiency.

Procedure

  1. Enter the system view.
    system-view
  2. Enter the view of the VLANIF interface where a VRRP group resides.
    interface vlanif vlan-id

    Only VLANIF interfaces can be configured on the device.

  3. Configure the mode for sending VRRP Advertisement packets.
    vrrp advertise vlan { sub-vlan-id | all }
    • If sub-vlan-id is specified, VRRP Advertisement packets are sent to a specified sub-VLAN.
    • If all is specified, VRRP Advertisement packets are broadcast to all sub-VLANs of a super VLAN.

    Specifying the parameter all is not recommended. If all is configured, a super VLAN broadcasts a VRRP Advertisement packet to all its sub-VLANs, reducing the CPU running efficiency.

    By default, a super VLAN sends VRRP Advertisement packets only to an up sub-VLAN with the smallest VLAN ID among all the sub-VLANs.

Verifying the Configuration

Run the display vrrp [ interface { interface-name | interface-type interface-number } ] [ virtual-id ] [ verbose ] command to check the VRRP group status.
