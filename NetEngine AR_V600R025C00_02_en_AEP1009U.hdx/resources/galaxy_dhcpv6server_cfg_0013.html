Configuring an IPv6 PD Address Pool

Context

An IPv6 PD address pool is used by a DHCPv6 PD server to assign IPv6 address prefixes to DHCPv6 PD clients.

Procedure

  1. Enter the system view.

    system-view

  2. Create an IPv6 address pool and enter its view.

    dhcpv6 pool pool-name

    By default, no IPv6 address pool is created on a device.

  3. Bind an IPv6 PD prefix to the IPv6 address pool.

    prefix-delegation ipv6-prefix/ipv6-prefix-length assign-prefix-length [ life-time { valid-lifetime | infinite } { preferred-lifetime | infinite } ] [ lock ]

    By default, no IPv6 PD prefix is bound to an IPv6 address pool.

  4. (Optional) Lock the IPv6 address pool.

    lock

    By default, no IPv6 address pool is locked on a device.

  5. (Optional) Configure a network prefix in the IPv6 address pool view.

    link-address ipv6-prefix/ipv6-prefix-length

    By default, no network prefix is configured in the IPv6 address pool view.

    To enable the DHCPv6 PD server function in the system view, you must perform this step to determine the network segment where clients need to be assigned IPv6 address prefixes from the PD address pool.

  6. (Optional) Bind an IPv6 prefix to a client DUID statically.

    static-bind prefix ipv6-prefix/ipv6-prefix-length duid client-duid [ iaid iaid ] [ life-time { valid-lifetime | infinite } { preferred-lifetime | infinite } ]

    By default, no IPv6 prefix is statically bound to a client DUID in an address pool.

    To statically assign fixed IPv6 prefixes to some specific clients, perform this step to specify the mapping between IPv6 prefixes and client DUIDs. When such a client requests an IPv6 prefix from the DHCPv6 server, the device functioning as the DHCPv6 server assigns the specified IPv6 prefix to the client.

    The IPv6 prefix specified in this step can be assigned only to the client with a specified DUID.
