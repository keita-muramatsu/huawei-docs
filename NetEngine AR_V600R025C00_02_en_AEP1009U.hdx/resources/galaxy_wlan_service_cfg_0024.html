AP Wired Port Link Profile

Overview

An AP wired port link profile allows for link-layer configurations on an AP's wired interface. Table 1 lists the functions that can be configured in an AP wired port link profile.

Table 1 Functions that can be configured in an AP wired port link profile

Function

Description

CLI-based Configuration Path

Shutting down or opening an AP's wired interface

You can shut down an AP's wired interface temporarily when a user initiates an attack on the network through this interface.

"Shutting Down an AP's Wired Interface" in CLI Configuration Guide > WLAN Configuration > AP Management

Configuring LLDP and the types of TLVs that can be advertised from an AP's wired interface

You can obtain the network topology of an AP through LLDP.

"Configuring LLDP on an AP" in CLI Configuration Guide > WLAN Configuration > AP Management

Configuring PoE on an AP's wired interface

Some APs can function as power sourcing equipment (PSE) to supply PoE power to powered devices (PDs). Configure PoE on an AP's wired interface, through which the AP can provide PDs with PoE power.

"Configuring the PoE Function of APs" in CLI Configuration Guide > WLAN Configuration > AP Management

Configuring the rate for an AP wired interface

You can configure the rate for an Ethernet interface working in either auto-negotiation or non-auto-negotiation mode.

  • In auto-negotiation mode, interfaces at both ends of a link negotiate the interface rate. If the negotiated interface rate is not the required value, you can manually set the interface rate.
  • In non-auto-negotiation mode, you must manually configure the interface rate to avoid communication failures.

"Configuring the Rate for an AP Wired Interface" in CLI Configuration Guide > WLAN Configuration > AP Management

Creating a Profile

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP wired port link profile and enter its view.

    port-link-profile name profile-name

    By default, the AP wired port link profile default exists on the device.

Applying a Profile

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP wired port profile and enter its view.

    wired-port-profile name wired-port-profile-name

    By default, the AP wired port profile default exists on the device.

  4. Bind an AP wired port link profile to the AP wired port profile.

    port-link-profile profile-name

    By default, the AP wired port link profile default is bound to an AP wired port profile.

  5. Return to the WLAN view.

    quit

  6. Enter the AP view or AP group view.
    • Enter the AP group view.
      ap-group name group-name
    • Enter the AP view.
      ap-id ap-id
  7. Bind the AP wired port profile to an AP group or a specific AP.

    wired-port-profile profile-name interface-type interface-number

    By default, the AP wired port profile default is bound to an AP group, but no AP wired port profile is bound to an AP.
