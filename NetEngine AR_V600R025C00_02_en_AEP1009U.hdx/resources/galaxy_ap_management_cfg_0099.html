Configuring the Bluetooth Working Mode for an AP

Context

Bluetooth of an AP can work in Bluetooth serial port or IoT mode. Only one Bluetooth working mode can be used at a time. If IoT services, such as electronic shelf label (ESL), need to be deployed on a network, you can switch the Bluetooth working mode to IoT.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP system profile and enter its view.

    ap-system-profile name profile-name

    By default, the AP system profile default exists on the device.

  4. Configure the Bluetooth working mode for an AP.

    ble work mode { iot | console }

    By default, when an AP has no external card or has one serial port card installed, Bluetooth works in Bluetooth serial port mode. When an AP has two serial port cards installed, the Bluetooth serial port does not work after the AP is started.

  5. Return to the WLAN view.

    quit

  6. Enter the AP view or AP group view.
    • Enter the AP group view.
      ap-group name group-name
    • Enter the AP view.
      ap-id ap-id
  7. Bind the AP system profile to an AP group or a single AP.

    ap-system-profile profile-name

    By default, the AP system profile default is bound to an AP group, but no AP system profile is bound to an AP.
