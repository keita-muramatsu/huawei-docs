Powering Off a PoE Interface

Context

A device generally starts providing power to a PD once the PD is connected to the device's PoE interface.

If a PD does not operate constantly (for example, it has a fixed idle time range), you can configure a power-off time range for the PoE interface. In this way, a PD is automatically powered off during the configured power-off time range, reducing power consumption.

Procedure

  1. Enter the system view.

    system-view

  2. Configure a time range.

    time-range time-name [ { time1 to time2 { days } &<1-7> | from time1 date1 [ to time2 date2 ] } ]

  3. Enter the interface view.

    interface interface-type interface-number

  4. Set the power-off time range of the PoE interface.

    poe power-off time-range time-name

    By default, no PoE power-off time range is configured for a PoE interface.

  5. (Optional) Enable the function of sending PoE interface power-off information to APs through LLDP.

    poe transmit power-off enable

    By default, this function is disabled, and an AP generates a power-off alarm when an interface is powered off within the power-off time range. After this function is enabled, LLDP packets carrying power-off information are sent to APs before the power-off time range of PoE interfaces, preventing APs from generating power-off alarms.

Verifying the Configuration

Run the display poe power-state [ slot slot-id | interface { interface-type interface-number | interface-name } ] command to check the power supply status of the PoE interface based on the Port power status field.
