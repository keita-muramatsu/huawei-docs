Displaying MAC Address Entries

During routine maintenance, you can run the following commands in any view to view MAC address table information.

Table 1 Commands used to display MAC address entries

Operation

Command

Display all MAC address entries.

display mac-address

Display static MAC address entries.

display mac-address static

Display static MAC address entries in a VLAN.

display mac-address static vlan vlan-id

Display MAC address entries learned in a VLAN.

display mac-address dynamic vlan vlan-id

Display MAC address entries learned on an interface.

display mac-address dynamic interface interface-type interface-number

Display MAC address entries learned through a Layer 2 tunnel.

display mac-address tunnel [ verbose ]

Display MAC address entries of a specified MAC address in the chip.

display mac-address mac-address vlan vlan-id slot slot-id forward-engine

Display a specified MAC address entry.

display mac-address mac-address

Display the system MAC address.

display system mac-address

Display the bridge MAC address.

display bridge mac-address

Display the MAC address of an interface.

display interface interface-type interface-number

Hardware address in the command output indicates an interface's MAC address.

Display the MAC address of a VLANIF interface.

display interface vlanif vlan-id

Hardware address in the command output indicates a VLANIF interface's MAC address.

Display statistics on MAC address entries.
  • Display the total statistics: display mac-address total-number
  • Display the statistics of various types of MAC address entries: display mac-address summary

Display types and the number of returned codes related to MAC addresses.

display mac-address statistics { insert | remove } slot <slot-id>

Display DB table, software table, and hardware table information about MAC addresses learned by the device.

display fwm mac diag
