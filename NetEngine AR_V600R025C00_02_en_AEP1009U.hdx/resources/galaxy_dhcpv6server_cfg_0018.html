Verifying the DHCPv6 PD Server Configuration

Procedure

  • Run the display dhcpv6 duid command to check the DUID of the DHCPv6 device on the network.
  • Run the display dhcpv6 pool [ pool-name [ allocated { address | prefix} | binding [ duid ] | conflict address | ipv6-address | ipv6-prefix/ipv6-prefix-length ] ] command to check the IPv6 address pool configuration.
  • Run the display dhcpv6 server [ interface { interface-name | interface-type interface-number } ] command to check the configurations of the interfaces where the DHCPv6 server function is configured.
  • Run the display dhcpv6 server database command to check the configuration of the DHCPv6 server's binding table database.
