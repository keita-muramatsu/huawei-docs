Intra-WAC roaming

For small- and medium-sized WLANs, a single WAC can meet coverage requirements. You can deploy intra-WAC roaming to ensure WLAN service continuity for STAs as they move.

After the basic WLAN access functions are completely by referring to Configuring Basic WLAN STA Access Functions, intra-WAC roaming can be implemented if the APs that participate in roaming meet the following conditions, without additional configurations required:

  • Associated to the same WAC.
  • Configured with the same security policy.
  • Configured with the same SSID.
  • With the same authentication policy and authorization policy delivered by the WAC if the network access control (NAC) service is configured

You can configure disabling Layer 3 roaming based on the WLAN plan.

Fast roaming using PMK caching

In 802.1X authentication scenarios, fast roaming using PMK caching can shorten the roaming handover time for 802.1X STAs.

It is applicable to only a few scenarios. During roaming, only key negotiation is required, without the need to perform 802.1X authentication again, therefore reducing the roaming delay.

You can deploy fast roaming using PMK caching on the basis of intra-WAC roaming.

802.11r fast roaming

It is applicable to multiple scenarios. This roaming mode does not require 802.1X authentication or key negotiation, thereby shortening the roaming latency.

AI roaming

AI roaming is an enhancement of smart roaming. A WAC provides personalized roaming steering policies for different types of STAs and starts roaming steering at a proper time through the coordinated measurement mechanism, thereby effectively improving the roaming sensitivity and success rate as well as resolving sticky STA issues.

You can deploy AI roaming on the basis of intra-WAC roaming.
