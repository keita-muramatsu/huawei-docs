Overview of Security Zones

Definition

A security zone is a logical entity to which one or more physical or logical interfaces are bound. The networks connected to the interfaces in the same security zone have the same security attributes.

Purpose

You can add interfaces on a device to different security zones so that the networks connected to the interfaces are assigned different security levels.

You can configure policies with the source and destination security zones as the matching conditions to centrally manage and control interzone service traffic, with no need for configuring security policies with the IP addresses or subnets as the matching conditions. This significantly simplifies the policy configuration.
