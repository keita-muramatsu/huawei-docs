Functions and Features

Table 5 Functions and features of the SIC-4E1-V2
Functions and Features Description
Overview

A 4E1 card is an E1/CE1 interface module for a router and provides four E1/CE1 interfaces for WAN connection and WAN aggregation.

A 4E1 card can be installed in a SIC slot of a router.
