Intelligent Simplified Campus Network with a Single Link

Context

As shown in Figure 1, when RUs are connected to a central device through a single link, the RUs are plug-and-play. The network is successfully deployed after the central device and RUs are powered on. To implement more functions and provide better user experience, you are advised to bind interconnection interfaces and enable RU protection by setting interfaces to the Error-Down state.

Figure 1 Intelligent simplified campus network with a single link

Procedure

  1. Connect an RU to the central device.
  2. Supply power to the RU by using a power adapter or the PoE power supply of the central device. If there is a single link, the intelligent simplified campus network is successfully deployed after this step.
  3. (Optional) Bind the interconnection interface.

    1. Enter the system view.
      system-view
    2. Enter the view of a single RU from the central device.
      remote-unit id
    3. Bind the interconnection interface.
      bind interface interface-type interface-number

      You can run the remote-unit connect-interface interface-type interface-number command on the central device to enter the view of a single RU through the interconnection interface and deliver configurations only after the interconnection interface is bound. If the RU only forwards Layer 2 traffic or configurations do not need to be delivered to the RU, the interconnection interface does not need to be bound. For details about RU configuration and O&M, see (Optional) Configuring an RU on the Central Device and Maintaining an Intelligent Simplified Campus Network.

    4. Return to the system view.
      quit

  4. (Optional) Enable or disable RU protection.

    remote-unit protect-action error-down { disable | enable }

    By default, this function is enabled. During RU deployment, a configuration error or link fault may occur. After detecting the fault, the central device sets the interface connected to the RU to the Error-Down state.

    After this protection mechanism is configured, if the device detects that the interface or relevant service fails, the device shuts down the interface and sets the interface status to ERROR DOWN to prevent the fault from affecting the entire network. Therefore, enabling this function is recommended.

Verifying the Configuration

Run the display remote-unit command in any view of the central device to check information about the RU.
