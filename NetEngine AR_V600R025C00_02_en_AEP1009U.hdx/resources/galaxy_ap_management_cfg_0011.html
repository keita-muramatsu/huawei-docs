Creating an AP Group

Context

A WAC on a WAC + Fit AP network manages multiple APs, which may each require the same configurations. To simplify configurations, you can group the APs and perform batch configurations as required.

Configurations specific to an AP take preference when the AP obtains both AP group and specific configurations from the WAC. For details, see "AP Group and AP" in CLI Configuration Guide > WLAN Configuration > WLAN Service Configuration Procedure. Each AP must and can join only one AP group when they go online on a WAC. An AP group is typically used to deliver unified configurations to multiple APs, while configurations specific to an AP can be performed on the AP.

By default, an AP is automatically added to the AP group default. This default AP group can be modified but cannot be deleted. By default, the following profiles that are all named default are bound to an AP group: AP system profile, 2.4 GHz radio profile, 5 GHz radio profile, regulatory domain profile, and AP wired port profile.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP group, and enter its view.

    ap-group name group-name

    By default, the AP group default exists on the device.
