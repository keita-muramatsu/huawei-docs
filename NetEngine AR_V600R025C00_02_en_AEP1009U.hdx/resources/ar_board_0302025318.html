Ports

Figure 3 Ports on the SIC-4STM1-V2

1. Four 155M POS interfaces

-
Table 4 Ports on the SIC-4STM1-V2
Port Connector Type Description Available Components
POS interface LC/PC

A POS interface transmits optical signals at 155 Mbit/s.

  • Optical interface attributes: The optical interface attributes depend on the optical modules used.
  • Standards compliance: ITUT G.707 SDH STM-1
  • Frame format: SDH
  • Network protocol: IP
  • Link-layer protocol: PPP and HDLC

Optical module

The following optical modules are supported:

  • SFP-FE-SX-MM1310
  • eSFP-FE-LX-SM1310
  • S-SFP-FE-LH40-SM1310

Functions and Features

Table 5 Functions and features of the SIC-4STM1-V2
Functions and Features Description
Overview

A 4STM1-V2 card is a high-speed WAN access module. It provides four 155M POS interfaces for high-density WAN interconnection and WAN aggregation.

A 4STM1-V2 card can be installed in a SIC slot on the device.
