Configuring Parameters for an RU

Context

If a central device manages multiple RUs, you can add aliases and descriptions for the RUs to facilitate management.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the single RU view.

    remote-unit { id | connect-interface interface-type interface-number | name remote-unit-name }

  3. Perform the following configurations as needed.

    Operation

    Command

    Description

    Configuring an alias for an RU

    name remote-unit-name

    After an alias is configured for an RU, you can directly enter the view of the RU using the remote-unit name remote-unit-name command.

    You can also view information about the RU based on its alias.

    Configuring a description for an RU

    description description

    The description of an RU includes information such as the usage of the RU to facilitate device management and maintenance.
