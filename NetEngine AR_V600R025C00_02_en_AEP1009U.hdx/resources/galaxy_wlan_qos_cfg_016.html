Configuring a Multicast-to-Unicast Conversion Policy for Wireless Packets on a VAP

Prerequisites

Before performing the configuration, you have completed the following tasks:
  • Configure AP onboarding and STA access.
  • Complete basic configurations of Layer 2 multicast, including IGMP snooping configuration for IPv4 multicast traffic on APs. (For details, see Configuring IGMP Snooping on APs.)

Context

Some applications have high requirements on multicast stream transmission, such as high-definition (HD) video on-demand (VoD) application. To meet such requirements, you can enable the multicast-to-unicast conversion function.

After this function is enabled, an AP listens to Internet Group Management Protocol (IGMP) Report and Leave messages to maintain multicast-to-unicast entries. When sending multicast packets to a STA, the AP converts the multicast packets to unicast packets based on the multicast-to-unicast entries, thereby improving multicast stream transmission efficiency.

In addition, you can configure the broadcast/multicast-to-unicast conversion function on the air interface in a traffic profile to reduce unnecessary packet forwarding and improve air interface performance.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a traffic profile and enter its view.

    traffic-profile name profile-name

  4. Perform the following operations as required:

    • Configure the multicast-to-unicast conversion function.
      traffic-optimize multicast-unicast enable

      By default, the multicast-to-unicast conversion function is disabled in a traffic profile.

    • Configure the broadcast/multicast-to-unicast conversion function on the air interface.

      1. Configure the broadcast/multicast-to-unicast conversion function on the air interface.

        traffic-optimize bcmc unicast-send { arp | nd | dhcp }*

        By default, the broadcast/multicast-to-unicast conversion function is enabled for ARP, ND, and DHCP packets on the air interface.

      2. Configure the system to discard the broadcast or multicast protocol packets that fail to be converted into unicast packets.

        traffic-optimize bcmc unicast-send mismatch-action drop

        By default, the system discards the broadcast or multicast protocol packets that fail to be converted to unicast packets.

    • Configure the function of forbidding the air interface to forward downstream broadcast or multicast packets.
      traffic-optimize bcmc deny all [ except mdns ]

      By default, the function of forbidding the air interface to forward downstream broadcast or multicast packets is disabled.

  5. Bind the traffic profile.

    Bind the traffic profile to an AP group or a single AP so that the configuration in the traffic profile can take effect. For details, see Traffic Profile.

Verifying the Configuration

  • Run the display traffic-profile { all | name profile-name } command to check the multicast-to-unicast conversion policy in a traffic profile.
