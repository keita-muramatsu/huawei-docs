Configuring IS-IS to Import External Routes

Prerequisites

Before configuring IS-IS to import external routes, you have completed the following task:

  • Configure basic IS-IS functions.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the IS-IS view.

    isis [ process-id ]

  3. Configure IS-IS to import external routes.

    • Configure IS-IS to import external routes and set a cost for the imported routes.
      • For IPv4 IS-IS:
        import-route { direct | static | { ospf | rip | isis } [ process-id ] | bgp } [ cost-type { external | internal } | cost cost | tag tag | { route-policy route-policy-name } | [ level-1 | level-2 | level-1-2 ] ] *
      • For IPv6 IS-IS:
        ipv6 import-route { direct | static | { ospfv3 | ripng | isis } [ process-id ] | bgp [ permit-ibgp ] } [ cost cost | tag tag | { route-policy route-policy-name } | [ level-1 | level-2 | level-1-2 ] ]
    • Configure IS-IS to import external routes and retain the original cost of each imported route.
      • For IPv4 IS-IS:
        import-route { { ospf | rip | isis } [ process-id ] | bgp | direct } inherit-cost [ { level-1 | level-2 | level-1-2 } | tag tag | route-policy route-policy-name ] *
      • For IPv6 IS-IS:
        ipv6 import-route { { ospfv3 | ripng | isis } [ process-id ] | bgp [ permit-ibgp ] | direct } inherit-cost [ tag tag | route-policy route-policy-name | [ level-1 | level-2 | level-1-2 ] ]

      This command cannot be used to import static routes.

  4. (Optional) Configure IS-IS to advertise only some imported external routes to the IS-IS routing domain.

    By default, IS-IS advertises all imported external routes to an IS-IS routing domain. To advertise only some imported external routes to the IS-IS routing domain, perform this step.

    • For IPv4 IS-IS:
      filter-policy { acl-number | acl-name acl-name-string | ip-prefix ip-prefix-name | route-policy route-policy-name } export [ direct | static | rip process-id | bgp | ospf process-id | isis process-id ]
    • For IPv6 IS-IS:
      ipv6 filter-policy { acl6-number | acl6-name acl6-name-string | ipv6-prefix ipv6-prefix-name | route-policy route-policy-name } { export [ direct | static | ripng process-id | bgp | ospfv3 process-id | isis process-id ] }
