RU Firmware Upgrade Exception

Symptom

The RU firmware fails to be upgraded.

Possible Causes

  • The RU firmware version and status are abnormal, and the authentication fails.
  • The RU fails to be upgraded and is in the cooldown period waiting for restart.
  • The upgrade function is disabled on the RU.
  • The PoE firmware of the RU does not need to be upgraded.

Procedure

  1. Check RU-related alarms on the central device to see whether there are alarms related to RU upgrade failures.

    RUMNG/2/RUUPGFWFAIL:OID [oid] The remote-unit firmware upgrade failed. (RemoteUnitEsn=[INTEGER], InterfaceName=[INTEGER], Firmware=[INTEGER], Reason=[STRING])

    In the preceding information, Reason=[STRING] indicates the failure information. For the meaning of the alarm, see hwRuMngFirmwareUpdateFail. Make a preliminary judgment based on the failure information.

  2. Check the RU status and available firmware versions.

    Run the display remote-unit upgrade information command to query the available firmware version of the central device. Then, run the display remote-unit verbose command to query the RU firmware version and status, and check whether the authentication is normal.

  3. Check the current upgrade mode and status.

    Run the display remote-unit upgrade information command to query the upgrade status of RUs and check whether any RU fails to be upgraded or is waiting to be restarted. If so, run the display remote-unit upgrade record command to query RU upgrade records.

    # Run the display remote-unit upgrade record command to query an RU's upgrade records. If the APP firmware and BIOS firmware of the RU connected to the interconnection interface have been upgraded successfully and No Need Upgrade is displayed in the PoE firmware upgrade result, you can ignore Version Match: No in the display remote-unit verbose command output.

    [HUAWEI] display remote-unit upgrade record 
-------------------------------------------------------------------------------

-------------------------------------------------------------------------------

2022/04/14 20:36:57   10GE0/0/1                BIOS       Success
2022/04/14 20:36:39   10GE0/0/1                POE        No Need Upgrade
-------------------------------------------------------------------------------

    # Run the display this command in the RU view to check whether the upgrade function is disabled. If "upgrade disable" is displayed in the command output, the upgrade function is disabled globally. In this case, enable the upgrade function.

    [HUAWEI] remote-unit
[HUAWEI-remote-unit] display this 
#
remote-unit
 upgrade disable
#
return
[HUAWEI] remote-unit 1
[HUAWEI-remote-unit-1] display this
#
remote-unit 1
 upgrade disable
 bind interface 10GE0/0/1
#
return
[HUAWEI-remote-unit-1] upgrade enable

  4. Perform forcible manual upgrade as the last resort.

    Run the upgrade { app | bios | poe } force command in the RU view to forcibly upgrade the firmware.

    [HUAWEI-remote-unit] remote-unit 1
[HUAWEI-remote-unit-1] upgrade app force 
Info: Successfully added to the upgrade list.

  5. Collect log and configuration information and contact technical support personnel. You can run the display diagnostic-information command to collect diagnostic information.
