HEAD

The HEAD method is used to query whether device configurations and status data exist. If the data exists, the "200 OK" status code is returned. Unlike the GET method, the HEAD method obtains only the header of the HTTP message without carrying the message-body.

Query information about the domains node and all the child nodes of this node, without the need to return the message-body.

  • Request

    HEAD /restconf/data/huawei-aaa:aaa/domains HTTP/1.1
Host: X.X.X.X
Accept: application/yang-data+xml
Content-Type: application/yang-data+xml
Content-Length: 0
Authorization: Basic YXBpLWFkbWluOkFkbWluQDEyMw==

  • Response

    HTTP/1.1 200 OK
Date: Wed, 18 Apr 2022 12:00:00 GMT
Content-Type:application/yang-data+xml
Content-Length:0
