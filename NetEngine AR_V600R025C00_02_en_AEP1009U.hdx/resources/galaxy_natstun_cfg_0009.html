Configuring a STUN Client

Prerequisites

Before configuring NAT detection for STUN clients, you need to configure necessary TNP and site information through SD-WAN Ethernet VPN (EVPN). For details, see "SD-WAN EVPN Configuration" in CLI Configuration Guide > VPN Configuration.

Context

STUN is used to solve the NAT traversal problem. Before the site where a STUN client is located advertises its TNP information, the STUN client will trigger NAT detection. After successful detection, the STUN client sends the result to the service module that requires NAT detection (such as the TNP module) and advertises its TNP information through BGP.

Procedure

  1. Enter the system view.

    system-view

  2. Enable the NAT detection function on the STUN client.
    1. Enter the view of an existing EVPN site.

      evpn site site-id

    2. Enter the TNP view.

      transport-network-port transport-network-port-id

    3. Enable the NAT detection function.

      nat detect enable

    4. (Optional) Configure the destination port number for the STUN client to access the STUN server.

      nat detect destination-port port-number
      • If a destination port number is configured in the STUN client view but not configured in the TNP view, the destination port number configured in the STUN client view takes effect.
      • If destination port numbers are configured in both the STUN client and TNP views, the destination port number configured in the TNP view takes effect.
      • If the destination port number is not configured either in the TNP or STUN client view, the default destination port number 3478 is used.

      The destination port number for the STUN client to access the STUN server must be identical to the port number checked by the STUN server for STUN messages.

    5. Return to the system view.

      quit

  3. Enter the STUN client view.

    stun client

  4. Configure the destination IP address for the STUN client to access the STUN server.

    peer ip ip-address [ vpn-instance vpn-instance-name ]

    A STUN client can trigger NAT detection only after the destination IP address for the client to access the STUN server is configured. In addition, this destination IP address must be identical to the IP address checked by the STUN server for STUN messages. If you run this command to change the destination IP address after NAT detection is complete, the new destination IP address takes effect in the next NAT detection.

  5. (Optional) Configure the destination port number for the STUN client to access the STUN server.

    destination-port port-number

    The destination port number configured in this view takes effect if this parameter is not configured in the TNP view.

    The destination port number for the STUN client to access the STUN server must be identical to the port number checked by the STUN server for STUN messages. If you run this command to change the destination port number after NAT detection is complete, the new destination port number takes effect in the next NAT detection.

  6. (Optional) Configure the source port number used by the STUN client to access the STUN server.

    source-port { port-number } &<1-4>

    After the source port number of a STUN client is changed using this command, the SD-WAN EVPN tunnels of this client are deleted and then re-established. Site traffic is interrupted before the tunnels are successfully re-established.

  7. (Optional) Configure an authentication username and a password for the STUN client.

    authentication-mode hmac-sha256 username username cipher password

    Currently, only HMAC-SHA256 authentication is supported. The STUN client and server must be configured with the same authentication username and password.

  8. (Optional) Configure the number of STUN hole punching retries and the retry interval.

    hole-punching retry-times count interval period

    By default, the number of STUN hole punching retries is 8 and the retry interval is 5 seconds.

Verifying the Configuration

  • Run the display stun client configuration command to check the STUN client configuration.
