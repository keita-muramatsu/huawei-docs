Sending Network Access Flow Logs of Users to a Log Server

Prerequisites

Configuring Log Backup on APs

Context

After the function of sending network access flow logs of users to a log server is enabled, an AP generates notice logs based on information about network access sessions of users accessing the VAP and then sends the logs to the log server for storage. Session information only includes users' MAC addresses and 5-tuple information of network access data flows, including the source IP address, destination IP address, source port number, destination port number, and protocol number.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a VAP profile view and enter its view.

    vap-profile name profile-name

    By default, the VAP profile default exists in the system.

  4. The function of sending network access flow logs of users to a log server is enabled.

    user flow syslog enable

    By default, the function of sending network access flow logs of users to a log server is disabled.

Follow-up Procedure

Apply the VAP profile. For details, see Binding a VAP Profile.
