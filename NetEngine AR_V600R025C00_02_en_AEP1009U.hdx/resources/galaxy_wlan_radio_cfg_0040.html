Configuring the Spectrum Analysis Function

Prerequisites

Before configuring spectrum analysis, complete the tasks in the following table.

Table 1 Pre-configuration tasks

Task

Description

Creating an AP group

Each AP will be added and can be added to only one AP group. An AP group is typically configured to provide the same configurations for multiple APs. By default, the system provides the AP group default. To create an AP group, execute this task. For details, see AP Group and AP.

Configuring AP onboarding

Configuring a DHCP server

To go online successfully, APs and STAs must obtain IP addresses. You can configure a WAC as a DHCP server or use an independent DHCP server to assign IP addresses to APs and STAs. For details, see DHCPv4 Configuration.

Configuring network connectivity

Configure network connectivity to enable APs and STAs to obtain IP addresses so that APs can discover the WAC and go online on the WAC, and STAs can access network resources. For details, see Configuring Network Connectivity.

Configuring a country code

Correct country code configuration ensures that radio parameters (such as the channel and power) of APs associated with the WAC comply with laws and regulations of countries and regions to which the APs are delivered. For details, see Configuring a Country Code.

Configuring a source interface or address

Configure a unique source interface or address for each WAC so that APs can establish CAPWAP tunnels with WACs. For details, see Configuring a CAPWAP Source Interface or Source Address.

Adding APs

Add APs in any of the following ways:

  • Import APs offline.
  • Configure the WAC to automatically discover APs.
  • Manually confirm APs in the list of unauthorized APs.

Importing APs offline is recommended when the MAC addresses or SNs of APs are available. For details, see Adding APs.

Context

You can configure the spectrum analysis function to detect interference channels and strength as well as interference types of non-Wi-Fi interference signals on the WLAN, which helps locate and eliminate interference signals in a timely manner.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP system profile and enter its view.

    ap-system-profile name profile-name

    By default, the system provides the AP system profile default.

  4. Configure the IP address and port number for the spectrum server.

    spectrum-analysis server { ip-address ip-address | ipv6-address ipv6-address } port port-number [ via-ac ac-port ac-port-number ]

    By default, no spectrum server is configured.

    • If APs upload the collected data directly to the spectrum server, you do not need to configure the via-ac ac-port ac-port-number command.
    • If APs upload the collected data to the spectrum server through the WAC, configure the via-ac ac-port ac-port-number command.
    • If no spectrum server is available, you can view the spectrum on the web system of a WAC. In this case, specify a valid IP address and port number for the spectrum server, which do not take effect, and configure the via-ac ac-port ac-port-number command.
    • When APs upload the collected data directly to the spectrum server, ensure that the IP protocol version used by the APs to communicate with the spectrum server is the same as that used by the APs to go online on the WAC. Otherwise, the spectrum analysis function does not take effect.

  5. (Optional) Configure the aging time for non-Wi-Fi device information during spectrum analysis.

    spectrum-analysis non-wifi-device aging-time aging-time

    By default, the aging time for non-Wi-Fi device information on a WAC is 3 minutes during spectrum analysis.

  6. Return to the WLAN view.

    quit

  7. (Optional) Configure the source IP address for a WAC to send packets to the spectrum server.

    spectrum-analysis source { ip-address ip-address | ipv6-address ipv6-address }

    By default, the WAC uses the IP address of the outbound interface on the matched route as the source IP address of packets sent to a spectrum server.

  8. Configure the air scan function.

    For details, see Configuring Air Scan.

  9. Return to the WLAN view.

    quit

  10. Create a VAP profile and enter its view.

    vap-profile name profile-name

    By default, the system provides the VAP profile default.

    When a VAP profile exists in the system, you can use the existing one or create a new one.

  11. Return to the WLAN view.

    quit

  12. Bind the VAP profile to radios of APs in an AP group or radios of a specified AP.

    Bind the VAP profile to radios of APs in an AP group or a specific AP to ensure that the radios requiring spectrum analysis properly work. For details, see VAP Profile.

  13. Return to the WLAN view.

    quit

  14. Bind the specified radio profile to an AP group or a specified AP.

    Bind the radio profile and spectrum profile to an AP group or a specified AP. For details, see Binding a Radio Profile.

    Binding the system profile to an AP group

    1. Enter the AP group view.

      ap-group name group-name

    2. Bind the specified AP system profile to the AP group.

      ap-system-profile profile-name

    Binding the system profile to an AP

    1. Enter the AP view.

      ap-id ap-id [ type-id type-id | ap-type ap-type ] { ap-mac ap-mac | ap-sn ap-sn | ap-mac ap-mac ap-sn ap-sn }

    2. Bind the specified AP system profile to the AP.

      ap-system-profile profile-name

  15. Enable spectrum analysis on AP radios.

    Enabling spectrum analysis on radios of APs in an AP group

    1. Enter the AP group view.

      ap-group name group-name

    2. Enter the AP group radio view.

      radio radio-id

    3. Enable spectrum analysis on radios of APs in the AP group.

      spectrum-analysis enable

    Enabling spectrum analysis on radios of a specified AP

    1. Enter the AP view.

      ap-id ap-id [ type-id type-id | ap-type ap-type ] { ap-mac ap-mac | ap-sn ap-sn | ap-mac ap-mac ap-sn ap-sn }

    2. Enter the AP radio view.

      radio radio-id

    3. Enable spectrum analysis on radios of the specified AP.

      spectrum-analysis enable

  16. Enable spectrum analysis data reporting on AP radios.

    spectrum-report enable

    By default, spectrum analysis data reporting is disabled on AP radios.

Verifying the Configuration

  • Run the display spectrum-analysis server-reporter command to check the list of APs reporting spectrum analysis data to a spectrum server.
  • Run the display air-scan-profile { all | name profile-name } command to check the configuration of an air scan profile.
  • Run the display radio-2g-profile { all | name profile-name } command to check the configuration of a 2.4 GHz radio profile.
  • Run the display radio-5g-profile { all | name profile-name } command to check the configuration of a 5 GHz radio profile.
  • Run the display ap-group { all | name group-name } command to check the configuration and reference information about an AP group.
