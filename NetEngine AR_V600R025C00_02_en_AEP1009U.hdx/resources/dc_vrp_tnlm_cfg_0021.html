Monitoring the Running Status of Tunnels

After configuring and applying a tunnel selector, run the following commands to check tunnel selector and tunnel policy information in the system.

Procedure

  • Run the display interface tunnel interface-number command to check tunnel interface information.
  • Run the display tunnel all command to check tunnel information.
  • Run the display tunnel tunnel-id command to check detailed tunnel information.
  • Run the display tunnel-policy policy-name command to check the configuration of a specified tunnel policy.
  • Run the display ip vpn-instance verbose [ vpn-instance-name ] command to check the tunnel policy applied to a VPN instance.
  • Run the display ip routing-table vpn-instance [ ip-address ] verbose or display ipv6 routing-table vpn-instance [ ipv6-address ] verbose command to check tunnels used by VPN routes.
