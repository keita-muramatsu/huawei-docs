Maintaining Local Attack Defense

During routine maintenance, you can also clear statistics on local attack defense. Run the following commands in the user view as required.

Cleared statistics cannot be restored. Exercise caution when running reset commands.

Table 1 Clearing local attack defense statistics

Operation

Command

Clear statistics about the packets sent to the CPU

reset cpu-defend statistics [ packet-type packet-type ] { all | slot slot-id }

Clear statistics about application layer association

reset cpu-defend linkup statistics [ packet-type packet-type ] { slot slot-id | all }

Clear session CAR statistics

reset cpu-defend session-car statistics [ packet-type packet-type ] { all | slot slot-id }

You cannot specify slot-id on the AR8700 and AR6700-H.

Clear packet statistics about user-level rate limiting

reset cpu-defend host-car [ mac-address mac-address ] statistics [ slot slot-id ]

Clear statistics about attack source tracing

reset auto-defend attack-source [ slot slot-id ]

Clear historical statistics about attack source tracing

reset auto-defend attack-source history [ slot slot-id ]

Clear attack source tracing statistics based on the source tracing mode

reset auto-defend attack-source trace-type { source-mac [ mac-address ] | source-ip [ ip-address | ipv6-address ] | source-portvlan [ interface interface-type interface-number vlan vlan-id ] } [ slot slot-id ]

Clear packet statistics about attack defense

reset anti-attack statistics [ abnormal | fragment | tcp-syn | udp-flood | icmp-flood ]

You cannot specify slot-id on the AR8700 series or AR6710-H4T4X2Y7.
