content

content indicates the type of the data you access. This parameter is allowed only for the GET or HEAD method. If it is used in other operation methods, "400 Bad Request" is returned.

The values of this parameter are as follows:
  • config: Only configuration data is accessed.
  • all: Both configuration data and non-configuration data are accessed. all is the default value.
Example 1 (XML format): If you want to view all data types, specify content as all or leave it unspecified.

  • Request

    GET /restconf/data/huawei-aaa:aaa/domains?content=all HTTP/1.1
Host: X.X.X.X
Accept: application/yang-data+xml
Content-Type: application/yang-data+xml
Content-Length: 0
Authorization: Basic YXBpLWFkbWluOkFkbWluQDEyMw==

  • Response

    HTTP/1.1 200 OK
Date: Wed, 18 Apr 2022 12:00:00 GMT
Content-Type: application/yang-data+xml
Content-Length: 614

<?xml version="1.0" encoding="UTF-8"?>
    <domains xmlns="urn:huawei:yang:huawei-aaa">
      <domain>
        <name>default</name>
        <authen-scheme-name>default</authen-scheme-name>
        <acct-scheme-name>default</acct-scheme-name>
        <state>active</state>
        <statistics-enable>false</statistics-enable>
      </domain>
      <domain>
        <name>default_admin</name>
        <authen-scheme-name>default</authen-scheme-name>
        <acct-scheme-name>default</acct-scheme-name>
        <state>active</state>
        <statistics-enable>false</statistics-enable>
      </domain>
</domains>
