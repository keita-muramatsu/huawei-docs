Configuring MU EDCA Parameters for a VAP

Prerequisites

Before performing the configuration, you have completed the following task:
  • Configure AP onboarding and STA access.

Context

STAs in compliance with 802.11ax or later standards (Wi-Fi 6/7 STAs) support two transmission modes: EDCA-based contention transmission and Trigger frame-based uplink transmission. In this way, Wi-Fi 6/7 STAs have more channel access opportunities than legacy STAs. As such, the MU EDCA mechanism is introduced to ensure channel access fairness. After being triggered by the AP to send data, Wi-Fi 6/7 STAs switch to the MU EDCA parameter set. The MU EDCA parameter set has a longer contention waiting time and a larger backoff window, and therefore has a lower priority compared with conventional EDCA parameters.

If Wi-Fi 6/7 STAs do not schedule Trigger frames for a long time, the STAs exit the MU EDCA mechanism and switch back to conventional EDCA parameters.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an SSID profile view and enter its view.

    ssid-profile name profile-name

  4. Configure MU EDCA parameters for STAs.

    wmm mu-edca-client { ac-vo | ac-vi | ac-be | ac-bk } { aifsn aifsn-value | ecw ecwmin ecwmin-value ecwmax ecwmax-value | muedcatimer muedcatimer-value } *

    The priorities of the four ACs are as follows: AC_VO > AC_VI > AC_BE > AC_BK.

  5. Bind the SSID profile.

    Bind the SSID profile to an AP group or a single AP so that the configuration in the profile can take effect. For details, see SSID Profile.

Verifying the Configuration

  • Run the display ssid-profile name profile-name command to check the WMM configuration in an SSID profile.
