Overview of E1/CE1

Definition

The working modes of an E1 system are classified as E1 or CE1. An E1/CE1 interface provided by a device is a physical interface of the E1 system and works in either E1 or CE1 mode to transmit voice, data, and image signals.

Purpose

An E1/CE1 interface can work in either E1 or CE1 mode, providing a wider range of WAN access modes.

  • When working in E1 mode, an E1/CE1 interface functions as a 2 Mbit/s interface without timeslot division.
  • When an E1/CE1 interface works in CE1 mode, the 2 Mbit/s transmission line is divided into thirty-two 64 kbit/s timeslots numbered from 0 to 31. Timeslot 0 is used to transmit synchronization information, and the other timeslots are randomly divided into several groups, each corresponding to a channel. Each group of bundled timeslots can be used as an interface.
