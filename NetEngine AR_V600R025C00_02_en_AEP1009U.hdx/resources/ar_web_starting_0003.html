Logging In to the Device for the First Time Through the Web System

Context

If you need to configure a device with factory default settings and no console cable or no serial port on a PC is available, you can log in to the device for the first time through the web system and configure the device. By default, the HTTPS service is enabled on the device.

Procedure

  1. Connect the network port of a PC to any LAN port or management port (MGMT) of the device using an Ethernet cable.

    For the AR8140-12G10XG, you can connect the network port of a PC only to the management port (MGMT) of the device.

    For devices equipped with the MPU-100 or SRU-700S, you can connect the network port of a PC only to the management port (MGMT) on the main control board of the device using an Ethernet cable.

  2. Set the IP address of the PC to be on the same network segment as the default IP address (192.168.1.1).
  3. Enter https://192.168.1.1:443 in the address box of the browser.

    If the browser displays a message indicating that the certificate is insecure, select to continue browsing.

  4. On the page displayed for creating an administrator account upon the first login, enter the user name, password, and confirm password, and click Create, as shown in Figure 1.

    Figure 1 Creating an account

  5. Click OK in the dialog box that is displayed. The account is successfully created.
  6. On the login page that is displayed, enter the created user name and password and click Login, as shown in Figure 2.

    Figure 2 Logging in to the web system using an account

    When you access the web login address, the browser cannot verify the default certificate provided by the device, and a security warning is displayed. You can click Download CA Certificate to download the certificate and double-click the certificate file to install it. No security warning is displayed upon the next login.

  7. When you log in to the device using a new administrator account for the first time, the page for changing the initial password is displayed. Enter the current password, new password, and confirm password, and click OK.
  8. On the login page that is displayed, enter the user name and new password and click Login.

Follow-up Procedure

After the successful login, you can perform the following operations to set login-related parameters:

  • Creating other administrators on the web system: Choose System > Administrator > Administrator.
