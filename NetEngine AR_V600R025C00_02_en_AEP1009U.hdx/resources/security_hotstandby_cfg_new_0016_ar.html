Status Information Backup

Two devices back up the information listed in the following table to each other, ensuring normal service processing in hot standby scenarios. Status information backup is automatically initiated by the SD-WAN EVPN service module without manual intervention.

Table 1 Entries that can be backed up

Backup Entry

Description

Transport network port (TNP) status information

This entry is generated when SD-WAN EVPN is configured. It can be synchronized for the establishment of a dual-gateway CPE node.

CPE link status information

This entry is generated when SD-WAN EVPN is configured. It can be synchronized for the establishment of a dual-gateway CPE node.

Application identification information of the session table

This entry is generated when application identification is configured. After this entry is synchronized, the device can continue to identify the application information of traffic that is switched between the active and standby devices or sent over different forward and return paths.

Link quality information

This entry is generated when SD-WAN EVPN is configured. It can be synchronized for smart policy routing (SPR) on a dual-gateway CPE node.

ASPF server mapping entries (without NAT translation)

When ASPF detection is enabled and ASPF traffic of a specified protocol exists, this type of entries can be generated. After the entries is synchronized, packets can match the server mapping table on the peer end and be directly forwarded, and sessions can be established, regardless of the security policy.
