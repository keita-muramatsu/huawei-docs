Configuring an FQ or SQ Profile

Context

  • QoS parameters of FQs and SQs are configured through profiles. The following QoS parameters can be configured in an FQ profile: the scheduling mode, shaping parameters, drop policy, and queue length. In addition, the following QoS parameters can be configured in an SQ profile: the scheduling mode and shaping parameters.
  • For the parent and child traffic policy configuration model, both the FQ and SQ profiles need to be configured. For the CBQ configuration model, only one of the FQ and SQ profiles needs to be configured.

Procedure

  • Configuring an FQ profile

    1. Enter the system view.
      system-view
    2. Create an FQ profile and enter the FQ profile view.
      flow-queue flow-queue-name

      By default, no FQ profile is created. A maximum of 1024 FQ profiles can be configured on the device. A maximum of 128 FQs can be configured in an FQ profile.

    3. Set QoS parameters for an FQ in the FQ profile.
      For the AR6700-H series and AR8100 series:
      queue queue-name { pq | drr weight weight-value [ weight-fix ] } { shaping { shaping-value | { shaping-percentage | cir-shaping-percentage } shaping-percentage-value } [ pbs pbs-value ] } [ drop-profile name ] [ queue-length packets packets-value ]

      For the AR8700 series:

      queue queue-name { pq | drr weight weight-value [ weight-fix ] } { shaping { shaping-value | { shaping-percentage | cir-shaping-percentage } shaping-percentage-value } [ pbs pbs-value ] } [ drop-profile name ] [ queue-length depth-value ]

      For the AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, and AR6710-L50T2X4-T:

      queue queue-name { pq | drr weight weight-value } { shaping { shaping-value | { shaping-percentage | cir-shaping-percentage } shaping-percentage-value } [ pbs pbs-value ] } [ drop-profile name ] [ queue-length depth-value ]
      For the AR5700 series, AR6710-L8T3TS1X2, and AR6710-L8T3TS1X2-T:
      queue queue-name { pq | drr weight weight-value } { shaping { shaping-value | { shaping-percentage | cir-shaping-percentage } shaping-percentage-value } [ pbs pbs-value ] } [ drop-profile name ] [ queue-length [ depth-value ] [ packets packets-value ] ]

      For the AR6710-L14T2X4:

      queue queue-name { pq | drr weight weight-value } { shaping { shaping-value | cir-shaping-percentage shaping-percentage-value } [ pbs pbs-value ] } [ drop-profile name ] [ queue-length packets packets-value ]

      drop-profile name specifies the name of a drop profile, which is configured using the drop-profile drop-profile-name command.

      By default, QoS parameters are not set for an FQ in an FQ profile.

  • Configuring an SQ profile

    1. Enter the system view.
      system-view
    2. Create an SQ profile and enter the SQ profile view.
      qos-user-profile profile-name

      By default, no SQ profile is created. A maximum of 1024 SQ profiles can be configured on the device. A maximum of 256 SQs can be configured in an SQ profile.

    3. Set QoS parameters for an SQ in the SQ profile.

      For the AR5700 series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6700-H series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR8700 series, and AR8100 series:

      user-queue user-name { pq | drr weight weight-value } { cir cir-value [ cbs cbs-value ] [ pir pir-value [ pbs pbs-value ] ] | cir-percentage cir-percentage-value [ cbs cbs-value ] [ pir-percentage pir-percentage-value [ pbs pbs-value ] ] }
      For the AR6710-L14T2X4:
      user-queue user-name { pq | drr weight weight-value } { cir cir-value [ cbs cbs-value ] | cir-percentage cir-percentage-value [ cbs cbs-value ] }

      By default, QoS parameters are not set for an SQ in an SQ profile.

    • If pir pir-value is not specified for the SQ profile, the value of pir-value is the same as that of cir-value. By default, the value of pbs-value is 25 times the value of pir-value, and the maximum value cannot exceed the value range.
    • For the parent and child traffic policy configuration model, if the percentages of parameters are specified in the SQ and FQ profiles, the corresponding base values are as follows:
      • If the cir-percentage cir-percentage-value and pir-percentage pir-percentage-value parameters are specified in the SQ profile to configure the bandwidth percentage, the bandwidth base value is the interface bandwidth.
      • If the shaping-percentage shaping-percentage-value parameter is specified in the FQ profile to configure the traffic shaping rate percentage, the base value of the traffic shaping rate is determined as follows:
        • If the pir-percentage pir-percentage-value or pir pir-value parameter is specified in the SQ profile, the parameter value is the base value.
        • If the pir-percentage pir-percentage-value and pir pir-value parameters are not specified in the SQ profile, the interface bandwidth is the base value.
      • If the cir-shaping-percentage shaping-percentage-value parameter is specified in the FQ profile to configure the traffic shaping rate percentage, the base value of the traffic shaping rate depends on the value of the cir-percentage cir-percentage-value or cir cir-value parameter configured in the SQ profile.
    • The interface bandwidth is calculated as follows:
      • Layer 3 Ethernet and Eth-Trunk interfaces (sub-interfaces included): If rate limiting is not configured, the interface bandwidth is the actual physical bandwidth of the interface. If rate limiting is configured, the interface bandwidth is the smaller value between the actual physical bandwidth and rate limit. For an Eth-Trunk interface and its sub-interfaces, the actual physical bandwidth is the total bandwidth of all member interfaces in up state.
      • For a tunnel interface, the interface bandwidth is determined by the interface rate limit configured using the qos lr command.
    • The SQ bandwidth is calculated as follows:
      • The device preferentially schedules the packets in the queues in PQ scheduling mode, and schedules the packets in the queues in WDRR scheduling mode only when there is remaining bandwidth.
      • When the WDRR scheduling mode is used (that is, drr weight is configured), if the sum of the guaranteed bandwidths of all SQs is greater than the interface bandwidth, the bandwidth of each SQ is allocated based on the value of weight-value in proportion, and the maximum bandwidth of each SQ cannot exceed the guaranteed bandwidth of each SQ.

Example

# Create an FQ profile named fq1. In the FQ profile, set the scheduling mode of data service flows to DRR, weight to 40, and traffic shaping rate to 2000 kbit/s; set the scheduling mode of voice service flows to DRR, weight to 60, and traffic shaping rate to 4000 kbit/s.

<HUAWEI> system-view
[HUAWEI] flow-queue fq1
[HUAWEI-flow-queue-fq1] queue data drr weight 40 shaping 2000
[HUAWEI-flow-queue-fq1] queue voice drr weight 60 shaping 4000

# Create an SQ profile named uq1. In the SQ profile, set the scheduling mode to DRR, weight to 40, and CIR to 200 kbit/s for user 1; set the scheduling mode to DRR, weight to 60, and CIR to 300 kbit/s for user 2.

<HUAWEI> system-view
[HUAWEI] qos-user-profile uq1
[HUAWEI-qos-user-profile-uq1] user-queue user1 drr weight 40 cir 200 
[HUAWEI-qos-user-profile-uq1] user-queue user2 drr weight 60 cir 300
