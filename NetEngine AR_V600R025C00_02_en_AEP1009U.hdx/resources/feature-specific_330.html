Example for Configuring a Manual IPv6 over IPv4 Tunnel

Networking Requirements

As shown in Figure 1, two IPv6 networks connect to DeviceB on the IPv4 backbone network through DeviceA and DeviceC, respectively. A manual IPv6 over IPv4 tunnel needs to be configured between DeviceA and DeviceC, so that hosts on the two IPv6 networks can communicate with each other.

Figure 1 Networking diagram of a manual IPv6 over IPv4 tunnel

In this example, interface 1 and interface 2 represent 10GE 0/0/1 and 10GE 0/0/2, respectively.


Precautions

When configuring a manual IPv6 over IPv4 tunnel, note the following:

  • Create tunnel interfaces before setting other tunnel parameters.

  • The configurations provided in "Procedure" need to be performed on both ends of the tunnel. Note that the source IP address of the tunnel configured on the local end is the destination IP address of the tunnel configured on the remote end. Similarly, the destination IP address of the tunnel configured on the local end is the source IP address of the tunnel configured on the remote end.

  • Configure IP addresses for tunnel interfaces, so that they support routing protocols.

Configuration Roadmap

The configuration roadmap is as follows:

  1. Configure IP addresses for physical interfaces on the two devices.

  2. Create tunnel interfaces, set the tunnel type to IPv6-IPv4, configure IPv6 addresses for the tunnel interfaces, and configure the source and destination addresses for the tunnel.

  3. Configure static routes, so that devices are mutually reachable.

Procedure

  1. Configure IP addresses for physical interfaces on DeviceA, DeviceB, and DeviceC.

    # Configure DeviceA.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] ip address 192.168.50.2 255.255.255.0
[DeviceA-10GE0/0/1] quit

    # Configure DeviceB.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceB
[DeviceB] interface 10ge 0/0/1
[DeviceB-10GE0/0/1] ip address 192.168.50.1 255.255.255.0
[DeviceB-10GE0/0/1] quit
[DeviceB] interface 10ge 0/0/2
[DeviceB-10GE0/0/2] ip address 192.168.51.1 255.255.255.0
[DeviceB-10GE0/0/2] quit

    # Configure DeviceC.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceC
[DeviceC] interface 10ge 0/0/1
[DeviceC-10GE0/0/1] ip address 192.168.51.2 255.255.255.0
[DeviceC-10GE0/0/1] quit
  2. Create tunnel interfaces, and configure the tunnel type, IPv6 addresses for the tunnel interfaces, and source and destination addresses for the tunnel.

    # Configure DeviceA.

    [DeviceA] interface Tunnel 1
[DeviceA-Tunnel1] tunnel-protocol ipv6-ipv4
[DeviceA-Tunnel1] ipv6 enable
[DeviceA-Tunnel1] ipv6 address 2001:db8::1 64
[DeviceA-Tunnel1] source 192.168.50.2
[DeviceA-Tunnel1] destination 192.168.51.2
[DeviceA-Tunnel1] quit

    # Configure DeviceC.

    [DeviceC] interface Tunnel 1
[DeviceC-Tunnel1] tunnel-protocol ipv6-ipv4
[DeviceC-Tunnel1] ipv6 enable
[DeviceC-Tunnel1] ipv6 address 2001:db8::2 64
[DeviceC-Tunnel1] source 192.168.51.2
[DeviceC-Tunnel1] destination 192.168.50.2
[DeviceC-Tunnel1] quit
  3. Configure static routes, so that DeviceA and DeviceC are mutually reachable.

    # Configure DeviceA.

    [DeviceA] ip route-static 192.168.51.0 255.255.255.0 192.168.50.1

    # Configure DeviceC.

    [DeviceC] ip route-static 192.168.50.0 255.255.255.0 192.168.51.1

Configuration Scripts

  • DeviceA

    #
sysname DeviceA
#
interface 10GE0/0/1
 ip address 192.168.50.2 255.255.255.0
#
interface Tunnel 1
 ipv6 enable
 ipv6 address 2001:db8::1/64
 tunnel-protocol ipv6-ipv4
 source 192.168.50.2
 destination 192.168.51.2
#
ip route-static 192.168.51.0 255.255.255.0 192.168.50.1
#
return

  • DeviceB

    #
sysname DeviceB
#
interface 10GE0/0/1
 ip address 192.168.50.1 255.255.255.0
#
interface 10GE0/0/2
 ip address 192.168.51.1 255.255.255.0
#
return

  • DeviceC

    #
sysname DeviceC
#
interface 10GE0/0/1
 ip address 192.168.51.2 255.255.255.0
#
interface Tunnel1
 ipv6 enable
 ipv6 address 2001:db8::2/64
 tunnel-protocol ipv6-ipv4
 source 192.168.51.2
 destination 192.168.50.2
#
ip route-static 192.168.50.0 255.255.255.0 192.168.51.1
#
return
