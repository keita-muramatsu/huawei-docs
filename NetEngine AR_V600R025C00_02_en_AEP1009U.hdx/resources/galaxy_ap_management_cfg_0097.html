Installing or Uninstalling a Container on an AP

Prerequisites

You have obtained the public key and container file and uploaded them to a file server.

Context

The public key files of different vendors are different. Only one public key file can be imported to an AP.

Only one container can be installed on an AP.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Configure information about the file server for the AP, including the IP address, port number, user name, and password of the file server. Perform configurations using any of the following methods as required, among which SFTP is recommended because it is more secure than FTP:

    • Configure FTP server information, and configure an IPv4 address for the server.
      ap file-transfer ftp-server ip-address server-ip-address [ port ftp-port ] username username password cipher password [ max-connect-number max-connect-number ]
    • Configure FTP server information, and configure an IPv6 address for the server.
      ap file-transfer ftp-server ipv6-address server-ipv6-address [ port ftp-port ] username username password cipher password [ max-connect-number max-connect-number ]
    • Configure SFTP server information, and configure an IPv4 address for the server.
      ap file-transfer sftp-server ip-address server-ip-address [ port sftp-port ] username username password cipher password [ max-connect-number max-connect-number ]
    • Configure SFTP server information, and configure an IPv6 address for the server.
      ap file-transfer sftp-server ipv6-address server-ipv6-address [ port sftp-port ] username username password cipher password [ max-connect-number max-connect-number ]

    By default, no file server information is configured for an AP.

    • APs do not support the double quotation marks ("). Therefore, ensure that these characters are not contained in the user name or unencrypted password of the FTP or SFTP server configured on the WAC. Otherwise, files will fail to be loaded.
    • The WAC can function as the FTP/SFTP server. Alternatively, use an external FTP/SFTP server, which is recommended.
    • When an external FTP/SFTP server is used, the maximum number of APs that can have files loaded simultaneously is the configured value of max-connect-number.
    • When a WAC is used as the FTP/SFTP server, a maximum of 15 files can be loaded using FTP/SFTP simultaneously even if the configured value of max-connect-number is larger than 15.
    • When a WAC is used as the FTP/SFTP server, if n VTY users have logged in, the maximum number of APs that can be upgraded simultaneously decreases by n – 1.
    • When IPv4 and IPv6 FTP/SFTP servers are both configured, set the maximum number of APs that can have files loaded simultaneously in both the two IP versions.

  4. Import the public key of the container to the AP.

    install container public-key { ap-id ap-id | ap-group ap-group | all } public-key public-key-name fingerprint fingerprint-key

  5. Install a container on the AP.

    install container application-software { ap-id ap-id | ap-group ap-group | all } software-name software-name

Verifying the Configuration

  • Run the display container { public-key | application-software } install status { ap-id ap-id | ap-group ap-group | all } command to check the progress of installing containers and container CA certificate files to Fit APs through the current WAC.
  • Run the display ap container public-key status { ap-id ap-id | all } command to check the public key installation status of the container on APs.
  • Run the display ap container information { ap-id ap-id | all } command to check the container status on APs.

Follow-up Procedure

If you do not need the functions of a container, perform the following configurations in the WLAN view:

Run the uninstall container application-software { ap-id ap-id | ap-group ap-group | all } command to uninstall the container from APs.

Run the uninstall container public-key { ap-id ap-id | ap-group ap-group | all } command to delete the public key imported to the container.
