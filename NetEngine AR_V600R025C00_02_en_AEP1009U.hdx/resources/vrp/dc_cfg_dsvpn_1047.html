The Standby Hub Only Forwards Data After the Active Hub Fails on a Dual-Hub DSVPN Network

Fault Symptom

On a dual-hub DSVPN network, after the active hub fails, the standby hub only forwards data and spokes cannot set up tunnels with each other.

Procedure

  1. Check whether the public addresses of the active and standby hubs are on the same network segment.

    Run the display this command in the mGRE interface view of the active and standby hubs to check whether the configured IP addresses are on the same network segment.

    • If they are on the same network segment, change the address of one hub to reside on a different network segment.
    • If they are on different network segments, go to step 2.

  2. Check whether spokes have routes to the active hub.

    Run the display ip routing-table command on the spokes to check whether they have a route to the active hub.

    If so, delete the route. For details, see CLI Configuration Guide > IP Routing Configuration.
