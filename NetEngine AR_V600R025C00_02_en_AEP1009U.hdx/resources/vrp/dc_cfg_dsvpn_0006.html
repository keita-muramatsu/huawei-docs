Configuring mGRE

Context

To implement DSVPN, you need to create a tunnel interface and set the tunnel type to mGRE. You only need to configure the source address or source interface for the mGRE tunnel interface, with no need to specify a destination address. Then, the mGRE tunnel interface can set up multiple GRE tunnels with different peers, which simplifies GRE configuration.

Perform the following configurations on the hub and spokes.

Procedure

  1. Enter the system view.

    system-view

  2. Create a tunnel interface and enter the tunnel interface view.

    interface tunnel interface-number

  3. Configure an IP address for the tunnel interface.

    ip address ip-address { mask | mask-length }

  4. Set the tunnel encapsulation mode to mGRE.

    tunnel-protocol gre p2mp

    Changing the tunnel encapsulation mode of a tunnel interface will delete existing parameter settings for the interface, including the source address or source interface, along with NHRP settings.

  5. Run one of the following commands as required:

    • Configure the source IP address of the tunnel interface.
      source [ vpn-instance vpn-name ] source-ip-address
    • Configure the source interface of the tunnel interface.
      source { ifName | ifType ifNum }
      • Changing the source command configuration will delete the IPsec configuration from the tunnel interface.
      • When specifying the source address of the tunnel interface, you cannot specify an interface's secondary IP address.

  6. (Optional) Set a tunnel identification keyword.

    gre key { simple key-number-simple | [ cipher ] key-number-cipher }

    By default, no identification keyword is configured for a GRE tunnel.

    If multiple mGRE tunnel interfaces use the same source address or source interface, you must configure a unique identification keyword for each mGRE tunnel.

    If mGRE and GRE tunnel interfaces use the same source address or source interface, you must configure a unique identification keyword for each tunnel.

    If simple is specified, the keyword is saved in the configuration file in cleartext, which is insecure. You are advised to specify cipher to save the keyword in ciphertext in the configuration file.

  7. (Optional) Modify the maximum segment size (MSS) allowed by the mGRE interface for incoming and outgoing TCP packets.

    tcp adjust-mss mss-value

    By default, the MSS of TCP packets is not configured on an interface.

    If the configured MSS is less than the total length of the MTU and the GRE header of a packet, the packet will not be fragmented when transmitted over the mGRE tunnel.

    If this command is run more than once, the latest configuration takes effect. When running this command, note that:

    • It applies only to IPv4 mGRE tunnels.
    • It applies only to IPv4 unicast and L3VPN scenarios.
    • The MSS of TCP packets can be modified for an mGRE tunnel only when their inner packets carried over the tunnel are unfragmented IPv4 TCP SYNC (or SYNC + ACK) packets.
