(Optional) Configuring a Coloring Policy

Context

During the creation of EVPN connections, if the source and destination TNPs belong to different TNs, you can execute the coloring policy for the connections to ensure that the coloring results of the EVPN connections created between two devices are the same. This ensures that the coloring policy configurations on the entire network are the same.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the site view.

    evpn site site-id

  3. Create a policy for coloring connections based on the TNP with a larger site ID.

    color-policy based-site-id larger

    By default, there is a policy for coloring connections based on the TNP with a smaller site ID.

  4. (Optional) Create a policy for coloring connections based on the specified coloring rule.

    color-policy based { transport-network-priority { smaller | larger } | bandwidth { smaller | larger } | { hub | spoke } } *

    If the coloring rule is to color connections based on the hub site attribute, run the hub enable command to enable the hub site function. By default, the hub site function is disabled on the device.

  5. Return to the system view.

    quit
