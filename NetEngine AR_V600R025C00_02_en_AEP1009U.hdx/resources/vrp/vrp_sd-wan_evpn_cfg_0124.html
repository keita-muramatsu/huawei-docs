Example for Configuring SD-WAN EVPN

Networking Requirements

An enterprise network consists of the headquarters and multiple branches. In Figure 1, DeviceA and DeviceB function as the egresses of the branches, and DeviceC functions as the headquarters egress. CPE sites need to communicate with each other, and data traffic between CPE sites needs to pass through the RR site. DeviceA and DeviceB function as CPEs, and DeviceC functions as an RR.

Figure 1 Network diagram for configuring SD-WAN EVPN

Interface 1 and interface 2 in this example represent 10GE 0/0/1 and 10GE 0/0/2, respectively.


Configuration Roadmap

The configuration roadmap is as follows:
  1. Configure OSPF on the RR, CPE1, and CPE2 to ensure that there are reachable routes between them.
  2. Configure TNPs on the RR, CPE1, and CPE2.
  3. Configure the RR as the DTLS server and configure CPE1 and CPE2 as the DTLS clients to establish a DTLS connection.
  4. Configure VPN instances on the RR, CPE1, and CPE2.
  5. Configure SD-WAN tunnel services on the RR, CPE1, and CPE2.
  6. Configure BGP SD-WAN peers and BGP EVPN peers on the RR, CPE1, and CPE2.

Procedure

  1. Assign IP addresses to interfaces.

    # Configure CPE1.

    <HUAWEI> system-view
[HUAWEI] sysname CPE1
[CPE1] interface 10ge 0/0/1
[CPE1-10GE0/0/1] ip address 1.1.1.1 24
[CPE1-10GE0/0/1] quit
[CPE1] interface loopback0
[CPE1-LoopBack0] ip address 10.1.1.1 32
[CPE1-LoopBack0] quit

    The configurations of the RR and CPE2 are similar to the configuration of CPE1. For detailed configurations, see Configuration Scripts.

  2. Configure OSPF.

    # Configure CPE1.

    [CPE1] ospf 1
[CPE1-ospf-1] area 0
[CPE1-ospf-1-area-0.0.0.0] network 1.1.1.0 0.0.0.255
[CPE1-ospf-1-area-0.0.0.0] quit
[CPE1-ospf-1] quit

    # Configure the RR.

    [RR] ospf 1
[RR-ospf-1] area 0
[RR-ospf-1-area-0.0.0.0] network 2.1.1.0 0.0.0.255
[RR-ospf-1-area-0.0.0.0] quit
[RR-ospf-1] quit

    # Configure CPE2.

    [CPE2] ospf 1
[CPE2-ospf-1] area 0
[CPE2-ospf-1-area-0.0.0.0] network 3.1.1.0 0.0.0.255
[CPE2-ospf-1-area-0.0.0.0] quit
[CPE2-ospf-1] quit

  3. Configure a TNP.

    # Configure CPE1.

    [CPE1] evpn site 1 site-type CPE
[CPE1-site-1] system-id 10.1.1.1
[CPE1-site-1] transport-network 10 name mpls 
[CPE1-site-1] routing-domain 100 name mpls 
[CPE1-site-1] transport-network-port 1
[CPE1-site-1-transport-network-port-1] transport-network mpls 
[CPE1-site-1-transport-network-port-1] routing-domain mpls 
[CPE1-site-1-transport-network-port-1] source-interface 10ge 0/0/1
[CPE1-site-1-transport-network-port-1] quit 
[CPE1-site-1] quit

    # Configure the RR.

    [RR] evpn site 2 site-type RR
[RR-site-2] system-id 10.2.2.2
[RR-site-2] transport-network 10 name mpls 
[RR-site-2] routing-domain 100 name mpls 
[RR-site-2] transport-network-port 1
[RR-site-2-transport-network-port-1] transport-network mpls 
[RR-site-2-transport-network-port-1] routing-domain mpls 
[RR-site-2-transport-network-port-1] source-interface 10ge 0/0/1
[RR-site-2-transport-network-port-1] quit 
[RR-site-2] quit

    # Configure CPE2.

    [CPE2] evpn site 3 site-type CPE
[CPE2-site-3] system-id 10.3.3.3
[CPE2-site-3] transport-network 10 name mpls 
[CPE2-site-3] routing-domain 100 name mpls 
[CPE2-site-3] transport-network-port 1
[CPE2-site-3-transport-network-port-1] transport-network mpls 
[CPE2-site-3-transport-network-port-1] routing-domain mpls 
[CPE2-site-3-transport-network-port-1] source-interface 10ge 0/0/1
[CPE2-site-3-transport-network-port-1] quit 
[CPE2-site-3] quit

  4. Configure DTLS.

    # Configure the RR as the DTLS server.

    [RR] dtls server 
[RR-dtls-server] dtls server enable 
[RR-dtls-server] listening-port 11111
[RR-dtls-server] listening-ip 2.1.1.1
[RR-dtls-server] quit

    # Configure CPE1 as a DTLS client.

    [CPE1] dtls client
[CPE1-client] peer system-id 10.2.2.2 ip 2.1.1.1 port 11111
[CPE1-client] quit

    # Configure CPE2 as a DTLS client.

    [CPE2] dtls client
[CPE2-client] peer system-id 10.2.2.2 ip 2.1.1.1 port 11111
[CPE2-client] quit

  5. Configure SD-WAN tunnels on the underlay network.

    # Configure an SD-WAN tunnel on CPE1.

    [CPE1] interface Tunnel 0 
[CPE1-Tunnel0] tunnel-protocol sd-wan
[CPE1-Tunnel0] sd-wan service enable
[CPE1-Tunnel0] ip address 10.11.11.11 32
[CPE1-Tunnel0] quit

    The configurations of the RR and CPE2 are similar to the configuration of CPE1. For detailed configurations, see Configuration Scripts.

  6. Configure static routes on the CPEs and RR to ensure that the IP addresses used to establish BGP peer relationships are reachable.

    # Configure CPE1.

    [CPE1] ip route-static 10.2.2.2 32 color 2

    # Configure the RR.

    [RR] ip route-static 10.1.1.1 32 color 1
[RR] ip route-static 10.3.3.3 32 color 3

    # Configure CPE2.

    [CPE2] ip route-static 10.2.2.2 32 color 2

  7. Configure a VPN instance.

    # Configure CPE1.

    [CPE1] route-policy test permit node 10
[CPE1-route-policy] apply extcommunity priority-color 10:1
[CPE1-route-policy] quit 
[CPE1] ip vpn-instance vpn1
[CPE1-vpn-instance-vpn1] ipv4-family 
[CPE1-vpn-instance-vpn1-af-ipv4] route-distinguisher 9:1 
[CPE1-vpn-instance-vpn1-af-ipv4] export route-policy test evpn 
[CPE1-vpn-instance-vpn1-af-ipv4] vpn-target 111:1 export-extcommunity evpn 
[CPE1-vpn-instance-vpn1-af-ipv4] vpn-target 111:1 import-extcommunity evpn 
[CPE1-vpn-instance-vpn1-af-ipv4] quit 
[CPE1-vpn-instance-vpn1] vn-id 90
[CPE1-vpn-instance-vpn1] quit
[CPE1] interface 10ge 0/0/2 
[CPE1-10GE0/0/2] ip binding vpn-instance vpn1 
[CPE1-10GE0/0/2] ip address 192.168.1.1 24
[CPE1-10GE0/0/2] quit

    # Configure the RR.

    [RR] route-policy test permit node 10
[RR-route-policy] apply extcommunity priority-color 10:2
[RR-route-policy] quit 
[RR] ip vpn-instance vpn1
[RR-vpn-instance-vpn1] ipv4-family 
[RR-vpn-instance-vpn1-af-ipv4] route-distinguisher 9:2
[RR-vpn-instance-vpn1-af-ipv4] export route-policy test evpn 
[RR-vpn-instance-vpn1-af-ipv4] vpn-target 111:1 export-extcommunity evpn 
[RR-vpn-instance-vpn1-af-ipv4] vpn-target 111:1 import-extcommunity evpn 
[RR-vpn-instance-vpn1-af-ipv4] quit 
[RR-vpn-instance-vpn1] vn-id 90
[RR-vpn-instance-vpn1] quit

    # Configure CPE2.

    [CPE2] route-policy test permit node 10
[CPE2-route-policy] apply extcommunity priority-color 10:3
[CPE2-route-policy] quit 
[CPE2] ip vpn-instance vpn1
[CPE2-vpn-instance-vpn1] ipv4-family 
[CPE2-vpn-instance-vpn1-af-ipv4] route-distinguisher 9:3
[CPE2-vpn-instance-vpn1-af-ipv4] export route-policy test evpn 
[CPE2-vpn-instance-vpn1-af-ipv4] vpn-target 111:1 export-extcommunity evpn 
[CPE2-vpn-instance-vpn1-af-ipv4] vpn-target 111:1 import-extcommunity evpn 
[CPE2-vpn-instance-vpn1-af-ipv4] quit 
[CPE2-vpn-instance-vpn1] vn-id 90
[CPE2-vpn-instance-vpn1] quit
[CPE2] interface 10ge 0/0/2 
[CPE2-10GE0/0/2] ip binding vpn-instance vpn1 
[CPE2-10GE0/0/2] ip address 192.168.3.1 24
[CPE2-10GE0/0/2] quit

  8. Configure SD-WAN tunnels on the overlay network.

    # Configure an SD-WAN tunnel on CPE1.

    [CPE1] interface tunnel 1 
[CPE1-Tunnel1] ip binding vpn-instance vpn1 
[CPE1-Tunnel1] tunnel-protocol sd-wan
[CPE1-Tunnel1] ip address 22.22.22.22 32
[CPE1-Tunnel1] sd-wan service enable 
[CPE1-Tunnel1] quit

    The configurations of the RR and CPE2 are similar to the configuration of CPE1. For detailed configurations, see Configuration Scripts.

  9. Configure a BGP SD-WAN peer and a BGP EVPN peer.

    # Configure CPE1.

    [CPE1] bgp 100 
[CPE1-bgp] router-id 10.1.1.1
[CPE1-bgp] peer 10.2.2.2 as-number 100
[CPE1-bgp] peer 10.2.2.2 connect-interface Loopback0
[CPE1-bgp] ipv4-family sd-wan 
[CPE1-bgp-af-ipv4-sdwan] peer 10.2.2.2 enable
[CPE1-bgp-af-ipv4-sdwan] peer 10.2.2.2 advertise-community
[CPE1-bgp-af-ipv4-sdwan] quit 
[CPE1-bgp] l2vpn-family evpn 
[CPE1-bgp-af-evpn] peer 10.2.2.2 enable
[CPE1-bgp-af-evpn] peer 10.2.2.2 advertise encap-type sd-wan
[CPE1-bgp-af-evpn] peer 10.2.2.2 advertise-community
[CPE1-bgp-af-evpn] quit 
[CPE1-bgp] ipv4-family vpn-instance vpn1 
[CPE1-bgp-vpn1] import-route direct 
[CPE1-bgp-vpn1] advertise l2vpn evpn 
[CPE1-bgp-vpn1] quit

    # Configure the RR.

    [RR] bgp 100 
[RR-bgp] router-id 10.2.2.2
[RR-bgp] peer 10.1.1.1 as-number 100
[RR-bgp] peer 10.1.1.1 connect-interface Loopback0
[RR-bgp] ipv4-family sd-wan 
[RR-bgp-af-ipv4-sdwan] peer 10.1.1.1 enable
[RR-bgp-af-ipv4-sdwan] peer 10.1.1.1 advertise-community
[RR-bgp-af-ipv4-sdwan] peer 10.1.1.1 reflect-client
[RR-bgp-af-ipv4-sdwan] quit 
[RR-bgp] l2vpn-family evpn 
[RR-bgp-af-evpn] reflect change-path-attribute 
[RR-bgp-af-evpn] peer 10.1.1.1 enable
[RR-bgp-af-evpn] peer 10.1.1.1 advertise encap-type sd-wan
[RR-bgp-af-evpn] peer 10.1.1.1 advertise-community
[RR-bgp-af-evpn] peer 10.1.1.1 reflect-client
[RR-bgp-af-evpn] quit 
[RR-bgp] peer 10.3.3.3 as-number 100
[RR-bgp] peer 10.3.3.3 connect-interface Loopback0
[RR-bgp] ipv4-family sd-wan 
[RR-bgp-af-ipv4-sdwan] peer 10.3.3.3 enable
[RR-bgp-af-ipv4-sdwan] peer 10.3.3.3 advertise-community
[RR-bgp-af-ipv4-sdwan] peer 10.3.3.3 reflect-client
[RR-bgp-af-ipv4-sdwan] quit 
[RR-bgp] l2vpn-family evpn 
[RR-bgp-af-evpn] reflect change-path-attribute  
[RR-bgp-af-evpn] peer 10.3.3.3 enable
[RR-bgp-af-evpn] peer 10.3.3.3 advertise encap-type sd-wan
[RR-bgp-af-evpn] peer 10.3.3.3 advertise-community
[RR-bgp-af-evpn] peer 10.3.3.3 reflect-client
[RR-bgp-af-evpn] quit 
[RR-bgp] ipv4-family vpn-instance vpn1 
[RR-bgp-vpn1] import-route direct 
[RR-bgp-vpn1] advertise l2vpn evpn
[RR-bgp-vpn1] quit
[RR-bgp] quit
[RR] ip extcommunity-list priority-color basic cpe2 permit 10:3 
[RR] route-policy cpe2 permit node 10 
[RR-route-policy] if-match extcommunity-list priority-color cpe2 
[RR-route-policy] apply ip-address next-hop 10.2.2.2
[RR-route-policy] apply extcommunity priority-color 10:2 
[RR-route-policy] quit 
[RR] route-policy cpe2 permit node 11 
[RR-route-policy] quit 
[RR] bgp 100 
[RR-bgp] l2vpn-family evpn 
[RR-bgp-af-evpn] peer 10.1.1.1 route-policy cpe2 export
[RR-bgp-af-evpn] quit 
[RR-bgp] quit 
[RR] ip extcommunity-list priority-color basic cpe1 permit 10:1 
[RR] route-policy cpe1 permit node 10 
[RR-route-policy] if-match extcommunity-list priority-color cpe1 
[RR-route-policy] apply ip-address next-hop 10.2.2.2
[RR-route-policy] apply extcommunity priority-color 10:2 
[RR-route-policy] quit 
[RR] route-policy cpe1 permit node 11 
[RR-route-policy] quit 
[RR] bgp 100 
[RR-bgp] l2vpn-family evpn 
[RR-bgp-af-evpn] peer 10.3.3.3 route-policy cpe1 export
[RR-bgp-af-evpn] quit 
[RR-bgp] quit

    # Configure CPE2.

    [CPE2] bgp 100 
[CPE2-bgp] router-id 10.3.3.3
[CPE2-bgp] peer 10.2.2.2 as-number 100
[CPE2-bgp] peer 10.2.2.2 connect-interface Loopback0
[CPE2-bgp] ipv4-family sd-wan 
[CPE2-bgp-af-ipv4-sdwan] peer 10.2.2.2 enable
[CPE2-bgp-af-ipv4-sdwan] peer 10.2.2.2 advertise-community
[CPE2-bgp-af-ipv4-sdwan] quit 
[CPE2-bgp] l2vpn-family evpn  
[CPE2-bgp-af-evpn] peer 10.2.2.2 enable
[CPE2-bgp-af-evpn] peer 10.2.2.2 advertise encap-type sd-wan
[CPE2-bgp-af-evpn] peer 10.2.2.2 advertise-community
[CPE2-bgp-af-evpn] quit 
[CPE2-bgp] ipv4-family vpn-instance vpn1 
[CPE2-bgp-vpn1] import-route direct 
[CPE2-bgp-vpn1] advertise l2vpn evpn 
[CPE2-bgp-vpn1] quit

Configuration Scripts

  • CPE1
    #
sysname CPE1
#
ip vpn-instance vpn1
 ipv4-family
  route-distinguisher 9:1
  export route-policy test evpn
  vpn-target 111:1 export-extcommunity evpn
  vpn-target 111:1 import-extcommunity evpn
 vn-id 90
#
interface 10GE0/0/1
 ip address 1.1.1.1 255.255.255.0
#
interface 10GE0/0/2
 ip binding vpn-instance vpn1
 ip address 192.168.1.1 255.255.255.0
#
interface LoopBack0
 ip address 10.1.1.1 255.255.255.255
#
interface Tunnel0
 ip address 10.11.11.11 255.255.255.255
 tunnel-protocol sd-wan
 sd-wan service enable
#
interface Tunnel1
 ip binding vpn-instance vpn1
 ip address 22.22.22.22 255.255.255.255
 tunnel-protocol sd-wan
 sd-wan service enable
#
ospf 1
 area 0
  network 1.1.1.0 0.0.0.255
#
bgp 100
 router-id 10.1.1.1
 peer 10.2.2.2 as-number 100
 peer 10.2.2.2 connect-interface loopback0
 #

  import-route direct
  advertise l2vpn evpn
 #
 l2vpn-family evpn
  peer 10.2.2.2 enable
  peer 10.2.2.2 advertise encap-type sd-wan
  peer 10.2.2.2 advertise-community
 #

  peer 10.2.2.2 enable
  peer 10.2.2.2 advertise-community

  transport-network mpls
  source-interface 10GE0/0/1
