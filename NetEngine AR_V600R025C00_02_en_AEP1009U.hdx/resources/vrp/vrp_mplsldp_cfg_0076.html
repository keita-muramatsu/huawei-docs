Verifying the Configuration

Procedure

  • Run the display mpls ldp session verbose command to check the configurations of LDP MD5 authentication and LDP keychain authentication.
  • Run the display gtsm statistics { slot-id | all } command to check GTSM statistics on a specified slot or all slots.
