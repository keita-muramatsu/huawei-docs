Clearing LDP Statistics

Context

Cleared LDP statistics cannot be restored. Exercise caution when performing this operation.

Procedure

  • To clear statistics about LDP error protocol packets, run the reset mpls ldp error packet { tcp | udp | all } command in the user view.
  • To clear statistics about LDP adjacencies that are down, run the reset mpls ldp event adjacency-down command in the user view.
  • To clear statistics about LDP sessions that are down, run the reset mpls ldp event session-down command in the user view.
