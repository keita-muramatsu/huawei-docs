Configuring IFIT Tunnel-Level Quality Measurement

Prerequisites

Before configuring IFIT to implement tunnel-level quality measurement in an SRv6 scenario, you have completed the following tasks:

  • Configure an SRv6 TE Policy manually or use a controller to dynamically deliver an SRv6 TE Policy.

    Bidirectional binding SIDs must be configured to ensure normal MCP calculation.

  • Configure basic NTP functions to implement clock synchronization between devices.

Context

Users want to use the controller to monitor the tunnel quality on the network in real time so that tunnel exceptions can be quickly detected and paths can be switched in a timely manner. You can configure IFIT measurement on devices so that the devices can periodically measure the packet loss rate and delay and perform intelligent traffic steering through tunnel quality analysis, simplifying the O&M process and improving O&M experience.

The following steps need to be performed only on the ingress and egress nodes.

Procedure

  1. Configure IFIT measurement for an SRv6 TE Policy.

    1. Enter the system view.
      system-view
    2. Enter the SRv6 view.
      segment-routing ipv6
    3. Enter the SRv6 TE Policy view.
      srv6-te policy name-value endpoint endpoint-ip color color-value
    4. Enable IFIT packet loss measurement for the SRv6 TE Policy.
      ifit loss-measure enable
    5. Enable IFIT delay measurement for the SRv6 TE Policy.
      ifit delay-measure enable
    6. (Optional) Configure the IFIT measurement interval for the SRv6 TE Policy.
      ifit interval interval-value
    7. Exit the SRv6 TE Policy view.
      quit
    8. Return to the system view.
      quit

  2. Enable IFIT globally and enter the IFIT view.

    ifit

  3. Configure the IFIT NE ID.

    node-id node-id

  4. Configure an IFIT working mode and enter the IFIT working mode view.

    work-mode [ mcp | dcp | auto ]

  5. Set the service type for IFIT measurement to SRv6 TE Policy.

    service-type srv6-segment-list

  6. Return to the IFIT view.

    quit

  7. (Optional) Set the aging time of IFIT dynamic flows to a multiple of the measurement interval.

    dynamic-flow age interval-multiplier multi-value

  8. (Optional) Clear an IFIT dynamic flow instance.

    reset dynamic flow { flowId | all }

Verifying the Configuration

  • Run the display ifit command to check IFIT flow information.
  • Run the display ifit dynamic-hop [ flow-id flow-id ] command to check IFIT flow information on the transit and egress nodes.
  • Run the display ifit srv6-segment-list [ segment-list-id ] command to check SRv6 TE Policy measurement instance information.
  • Run the display ifit statistic-type { two-way-delay | one-way-loss } { srv6-segment-list segment-list-id | flow-id flowId } command to check original performance data on the MCP.

Follow-up Procedure

After the preceding configuration is complete, the IFIT measurement result is reported to the SPR module for intelligent traffic steering. For details, see Configuring TE-Class-based Traffic Steering into an SRv6 TE Policy.
