Example for Configuring an NQA HTTP Test to Measure the Response Speed on a Network

Networking Requirements

In Figure 1, DeviceA is connected to the DNS server and HTTP server through a network. DeviceA needs to access the HTTP server using the domain name (https://huawei.com). In this process, an HTTP test instance can be configured on DeviceA to measure the speed at which DeviceA accesses the HTTP server.

Figure 1 Network diagram for configuring an HTTP test to measure the response speed on a network

Configuration Roadmap

The configuration roadmap is as follows:

  1. Configure reachable routes between DeviceA, the DNS server, and the HTTP server at the network layer.

  2. Configure an SSL policy for the HTTP test instance.

  3. Configure an HTTP test instance on DeviceA and start the test instance to measure the response speed at which DeviceA accesses the HTTP server.

Data Preparation

To complete the configuration, you need the following data:

  • IP address of the DNS server

  • Domain name of the HTTP server

Procedure

  1. Configure the name of DeviceA.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA]

  2. Configure reachable routes between DeviceA, the DNS server, and the HTTP server at the network layer. The configuration is not provided here.
  3. Configure an SSL policy for the HTTP test instance.

    # Upload the obtained digital certificate to the /pki/public directory of the device through SFTP. For details about how to apply for a digital certificate in PKI mode, see CLI Configuration Guide > PKI Configuration.

    # Configure a PKI realm and import the local certificate and private key file.

    [DeviceA] pki realm domain1
[DeviceA-pki-realm-domain1] quit
[DeviceA] pki import-certificate local realm domain1 pem filename restconf_local.pem
[DeviceA] pki import rsa-key-pair restconf-key pem restconf.pem //Skip this step if the private key file is generated on the local device.

    # Import the CA certificate of the peer collector to verify the validity of the local certificate for the collector.

    [DeviceA] pki import-certificate ca realm domain1 pem filename restconf_ca.pem

    # Configure an SSL policy and bind it to the PKI realm.

    [DeviceA] ssl policy policy1
[DeviceA-ssl-policy-policy1] pki-domain domain1
[DeviceA-ssl-policy-policy1] quit

  4. Configure an HTTP test instance and start it.

    [DeviceA] dns resolve
[DeviceA] dns server 10.3.1.1
[DeviceA] nqa test-instance admin http
[DeviceA-nqa-admin-http] test-type http
[DeviceA-nqa-admin-http] http-url ipv4 https://huawei.com
[DeviceA-nqa-admin-http] ssl-policy policy1
[DeviceA-nqa-admin-http] frequency 20
[DeviceA-nqa-admin-http] start now
