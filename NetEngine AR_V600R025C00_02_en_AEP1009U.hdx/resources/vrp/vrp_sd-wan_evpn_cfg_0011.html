Verifying the Configuration

Procedure

  • Run the display dtls client connection command to check DTLS client connection information.
  • Run the display dtls server command to check DTLS server information.
  • Run the display dtls esn-authenticate result command to check the DTLS ESN authentication result.
  • Run the display evpn connection command to check SD-WAN EVPN site connection information.
  • Run the display evpn connection verbose command to check detailed SD-WAN EVPN site connection information.
  • Run the display evpn connection { all | connection-id | { site site-id } } statistics command to check SD-WAN EVPN site connection statistics.
  • Run the display evpn site-tnp { site-id [ tnp-id tnp-id] | all} command to check SD-WAN EVPN site information.
  • Run the display ipsec p2mp-policy command to check P2MP policy information.
  • Run the display ipsec p2mp-sa { local | peer [ site site-id [ system-id system-id ] ] } command to check SA information about a P2MP policy.
  • Run the display ipsec p2mp-sa statistics command to check SA statistics of P2MP policies.
  • Run the display bgp sd-wan peer command to check BGP SD-WAN peer information.
  • Run the display bgp sd-wan peer ipv4-address log-info command to check log information about a specified peer in the BGP IPv4 SD-WAN address family.
  • Run the display bgp sd-wan peer ipv4-address statistics command to check statistics about a specified peer in the BGP IPv4 SD-WAN address family.
  • Run the display bgp sd-wan peer ipv4-address verbose command to check detailed information about a specified peer in the BGP IPv4 SD-WAN address family.
  • Run the display bgp sd-wan routing-table command to check routing information in the BGP IPv4 SD-WAN address family.
  • Run the display bgp sd-wan routing-table peer ipv4-address { advertised-routes | received-routes } [ sdwan-prefix ] command to check peer-based routing information in the BGP IPv4 SD-WAN address family.
  • Run the display bgp sd-wan routing-table statistics command to check route statistics in the BGP IPv4 SD-WAN address family.
  • Run the display bgp sd-wan slow-peer command to check BGP SD-WAN slow peer information.
  • Run the display bgp sd-wan update-peer-group [ index index-value ] command to check information about a specified update peer-group in the BGP IPv4 SD-WAN address family.
  • Run the display ip vpn-instance [ vpn-instance-name ] command to check the configuration of a specified VPN instance.
  • Run the display bgp evpn peer command to check BGP EVPN peer information.
  • Run the display bgp evpn peer ipv4-address verbose command to check detailed information about a specified BGP EVPN peer.
  • Run the display bgp evpn all routing-table [ peer ip-address { advertised-routes | received-routes } ] { prefix-route } prefix command to check information about BGP EVPN routes with a specified IP prefix.
  • Run the display bgp evpn all routing-table statistics command to check route statistics in the BGP EVPN address family.
  • Run the display bgp evpn group [ group-name ] command to check information about a specified BGP EVPN peer group.
  • Run the display bgp evpn update-peer-group [ index update-group-index ] command to check information about a specified update peer-group in the BGP EVPN address family.
  • Run the display sd-wan { ip | ipv6 } routing-table [ all-vpn-instance | vpn-instance vpn-instance-name ] [ dest-site site-id ] command to check SD-WAN route information on the device.
  • Run the display traffic-statistics applied-record command to check traffic statistics application records.
