Example for Configuring an OSPFv3 Stub Area

Networking Requirements

On the network shown in Figure 1, OSPFv3 runs on all devices, and the entire AS is divided into two areas: area 0 and area 1. DeviceA functions as an ABR and connects area 0 and area 1. DeviceB functions as an ASBR and communicates with an OSPFv3 external network. It is required that the size of the OSPFv3 routing table on DeviceC be reduced without affecting communication.

Figure 1 Network diagram of configuring an OSPFv3 stub area

In this example, interface1 and interface2 represent 10GE0/0/1 and 10GE0/0/2, respectively.


Precautions

To improve security, you are advised to deploy OSPFv3 authentication. For details, see "Configuring OSPFv3 Authentication." OSPFv3 area authentication is used as an example. For details, see "Example for Configuring Basic OSPFv3 Functions."

Configuration Roadmap

The configuration roadmap is as follows:

  1. Configure basic OSPFv3 functions on each device for interworking.

  2. Configure a static route to the external network on DeviceB and import the static route to the OSPFv3 routing table so that the external network is routable to the OSPFv3 network.

  3. Configure area 1 as a stub area to reduce the size of the OSPFv3 routing table on DeviceC.

  4. Configure area 1 as a totally stub area. That is, prevent the ABR (DeviceA) in area 1 from advertising Type 3 LSAs to the stub area to minimize the size of the OSPFv3 routing table on DeviceC.

Procedure

  1. Assign an IPv6 address to each involved interface. For detailed configurations, see Configuration Scripts.
  2. Configure basic OSPFv3 functions.

    # Configure DeviceA.

    [DeviceA] ospfv3
[DeviceA-ospfv3-1] router-id 1.1.1.1
[DeviceA-ospfv3-1] quit
[DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] ospfv3 1 area 0
[DeviceA-10GE0/0/1] quit
[DeviceA] interface 10ge 0/0/2
[DeviceA-10GE0/0/2] ospfv3 1 area 1
[DeviceA-10GE0/0/2] quit

    # Configure DeviceB.

    [DeviceB] ospfv3
[DeviceB-ospfv3-1] router-id 2.2.2.2
[DeviceB-ospfv3-1] quit
[DeviceB] interface 10ge 0/0/1
[DeviceB-10GE0/0/1] ospfv3 1 area 0
[DeviceB-10GE0/0/1] quit

    # Configure DeviceC.

    [DeviceC] ospfv3
[DeviceC-ospfv3-1] router-id 3.3.3.3
[DeviceC-ospfv3-1] quit
[DeviceC] interface 10ge 0/0/1
[DeviceC-10GE0/0/1] ospfv3 1 area 1
[DeviceC-10GE0/0/1] quit

    # Check the OSPFv3 neighbors of DeviceA. The command output shows that DeviceA has established neighbor relationships with DeviceB and DeviceC.

    [DeviceA] display ospfv3 peer
OSPFv3 Process (1)
OSPFv3 Area (0.0.0.0)
Neighbor ID     Pri  State            Dead Time Interface            Instance ID
2.2.2.2           1  Full/Backup      00:00:35  10GE0/0/1                      0
OSPFv3 Area (0.0.0.1)
Neighbor ID     Pri  State            Dead Time Interface            Instance ID
3.3.3.3           1  Full/DR          00:00:31  10GE0/0/2                      0

  3. Configure a static route to the external network on DeviceB and import the static route to the OSPFv3 routing table so that the external network is routable to the OSPFv3 network.

    [DeviceB] ipv6 route-static 2001:db8:fc01::1 96 null 0
[DeviceB] ospfv3
[DeviceB-ospfv3-1] import-route static type 1
[DeviceB-ospfv3-1] quit

    # Check the OSPFv3 routing table of DeviceC. The command output shows that the OSPFv3 routing table contains the AS external route.

    [DeviceC] display ospfv3 routing

Codes : E2 - Type 2 External, E1 - Type 1 External, IA - Inter-Area,
        N - NSSA
 Flags: A - Added to URT6, LT - Locator Routing

OSPFv3 Process (1)
     Destination                                               Metric
       Next-hop
  IA 2001:DB8:1000::/96                                            2
       via FE80::4E1F:CCFF:FE43:5A9E, 10GE0/0/2
     2001:DB8:1001::/96                                            1
       directly connected, 10GE0/0/2
  E1 2001:DB8:FC01::/96                                         3
       via FE80::4E1F:CCFF:FE43:5A9E, 10GE0/0/2

  4. Configure area 1 as a stub area to reduce the size of the OSPFv3 routing table on DeviceC.

    # Configure DeviceA.

    [DeviceA] ospfv3 1
[DeviceA-ospfv3-1] area 1
[DeviceA-ospfv3-1-area-0.0.0.1] stub
[DeviceA-ospfv3-1-area-0.0.0.1] default-cost 10
[DeviceA-ospfv3-1-area-0.0.0.1] quit
[DeviceA-ospfv3-1] quit

    # Configure DeviceC.

    [DeviceC] ospfv3 1
[DeviceC-ospfv3-1] area 1
[DeviceC-ospfv3-1-area-0.0.0.1] stub
[DeviceC-ospfv3-1-area-0.0.0.1] quit
[DeviceC-ospfv3-1] quit

    # Check the OSPFv3 routing table of DeviceC. The command output shows that the route to the destination outside the AS is suppressed on DeviceC and that a default route is added. The cost of the default route is the cost of a direct route plus the configured cost.

    [DeviceC] display ospfv3 routing

Codes : E2 - Type 2 External, E1 - Type 1 External, IA - Inter-Area,
        N - NSSA
 Flags: A - Added to URT6, LT - Locator Routing

OSPFv3 Process (1)
     Destination                                               Metric
       Next-hop
  IA ::/0                                                         11       
       via FE80::4E1F:CCFF:FE43:5A9E, 10GE0/0/2
  IA 2001:DB8:1000::/96                                            2
       via FE80::4E1F:CCFF:FE43:5A9E, 10GE0/0/2
     2001:DB8:1001::/96                                            1
       directly connected, 10GE0/0/2

  5. Configure area 1 as a totally stub area to prevent Type 3 LSAs from being advertised to the stub area and in turn minimize the size of the OSPFv3 routing table on DeviceC.

    [DeviceA] ospfv3
[DeviceA-ospfv3-1] area 1
[DeviceA-ospfv3-1-area-0.0.0.1] stub no-summary
[DeviceA-ospfv3-1-area-0.0.0.1] quit
[DeviceA-ospfv3-1] quit

Verifying the Configuration

Configuration Scripts

  • DeviceA

    #
sysname DeviceA
#
interface 10GE0/0/1
 ipv6 enable
 ipv6 address 2001:DB8:1000::1/96
 ospfv3 1 area 0.0.0.0
#
interface 10GE0/0/2
 ipv6 enable
 ipv6 address 2001:DB8:1001::1/96
 ospfv3 1 area 0.0.0.1
#
ospfv3 1
 router-id 1.1.1.1
 area 0.0.0.0
 area 0.0.0.1
  stub no-summary
  default-cost 10
#
return

  • DeviceB

    #
sysname DeviceB
#
interface 10GE0/0/1
 ipv6 enable
 ipv6 address 2001:DB8:1000::2/96
 ospfv3 1 area 0.0.0.0
#
ospfv3 1
 router-id 2.2.2.2
 area 0.0.0.0
 import-route static type 1
#
ipv6 route-static 2001:DB8:FC01::1 96 null 0
#
return

  • DeviceC

    #
sysname DeviceC
#
interface 10GE0/0/1
 ipv6 enable
 ipv6 address 2001:DB8:1001::2/96
 ospfv3 1 area 0.0.0.1
#
ospfv3 1
 router-id 3.3.3.3
 area 0.0.0.1
  stub
#
return
