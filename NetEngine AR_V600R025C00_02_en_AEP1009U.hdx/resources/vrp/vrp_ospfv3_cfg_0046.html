Understanding OSPFv3 Route Filtering

This section describes how to configure OSPFv3 to filter the routes to be advertised and accepted. OSPFv3 route filtering is classified into the following types:

  • Filtering the routes that do not belong to the local OSPFv3 area: This function can be configured on any device that runs OSPFv3.

  • Filtering routes in the local area: This function can be configured only on ABRs.
