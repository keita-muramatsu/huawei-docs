(Optional) Configuring IPsec

Context

In an SD-WAN EVPN scenario, you need to configure an IPsec tunnel between sites to encrypt data for secure data communication.

In an SD-WAN EVPN scenario, if one end is bound to an IPsec P2MP policy, the other end must also be bound to an IPsec P2MP policy.

Procedure

  1. Enter the system view.

    system-view

  2. Configure a point-to-multipoint (P2MP) policy.

    ipsec p2mp-policy policy-name

    By default, no P2MP policy is configured.

  3. Configure an authentication algorithm for the P2MP policy.

    esp authentication-algorithm { sha2-256 | sm3 }

    By default, the authentication algorithm is SHA2-256.

    The authentication algorithms are listed in descending order of security level as follows: SM3 > SHA2-256.

  4. Configure an encryption algorithm for the P2MP policy.

    esp encryption-algorithm { aes-128 | aes-256 | aes-128-gcm | aes-256-gcm | sm4 }

    By default, the encryption algorithm is AES-256-GCM.

    The authentication algorithms are listed in descending order of security level as follows: SM4 > AES-256-GCM > AES-128-GCM > AES-256 > AES-128.

    SM4 can meet high confidentiality and security requirements, but takes a relatively long processing time.

    The AES-128 and AES-256 algorithms are not secure enough and therefore not recommended.

  5. Configure a key exchange algorithm for the P2MP policy.

    key-exchange { dh-group19 | dh-group20 | dh-group21 } [ strict ]

    By default, no key exchange algorithm is configured.

  6. Configure the SA lifetime for the P2MP policy.

    sa duration time-based time-value

    By default, the SA lifetime is 1440 minutes.

  7. Return to the system view.

    quit

  8. Create a site and enter the site view.

    evpn site site-id [ site-type { cpe | rr | rr-cpe } ]

    By default, no site is created.

  9. Create a TNP and enter the TNP view.

    transport-network-port transport-network-port-id

    By default, no TNP is created.

  10. Bind the P2MP policy to the TNP.

    ipsec-p2mp-policy policy-name

    By default, no P2MP policy is bound to a TNP.
