IFIT Data Reporting

IFIT uses telemetry to send measurement data to the controller in real time for analysis. Telemetry is a technology that remotely collects data from physical or virtual devices at a high speed. Devices periodically send information such as interface traffic statistics, CPU usage, and memory usage to collectors in push mode. Compared with the traditional pull mode (question-answer interaction), the push mode provides faster and more real-time data collection. Telemetry flexibly collects data by subscribing to different sampling paths. This allows IFIT to manage more devices and obtain measurement data with higher precision, providing big data needed for fast locating of network faults and optimizing network quality.
