OSPF NSR

Non-stop routing (NSR) is a routing technique that prevents neighboring devices from detecting faults on the primary control plane of a device with a backup control plane. With NSR, if the primary control plane of the device fails, the neighbor or peer relationships set up through specific routing protocols, as well as the sessions of the protocols that are used to meet service requirements, are not interrupted.

As networks develop and expand, carriers place increasingly higher requirements on the reliability of IP networks. NSR was introduced as a high availability (HA) solution to ensure that the services transmitted by a device are unaffected by hardware or software failures on the device.

OSPF NSR synchronizes the protocol data on the master main control board to the slave main control board in real time. If the master main control board fails, or needs to be upgraded, the slave main control board immediately takes over services, and the neighbor remains unaware of the issue. Real-time data synchronization between the master and slave main control boards through OSPF NSR is implemented as follows:

  • OSPF backs up configuration data and dynamic data, including information about interfaces, neighbors, and LSDBs.
  • OSPF does not back up result data, such as routes, SPTs, and traffic engineering databases (TEDBs), as this information can be restored using the source data in the database backup process.
  • If a master/slave main control board switchover occurs, the new master main control board restores the operation data and takes over services from the former master main control board. Throughout this process, the neighbor remains unaware of the fault.

By default, OSPF NSR is enabled on the device and does not need to be configured.
