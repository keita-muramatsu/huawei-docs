Configuring Basic DSVPN Functions

Application Scenarios

The HQ (hub) connects to multiple branches (spokes) at different locations through a public network. To implement direct communication between branches, you need to deploy DSVPN on the hub-spoke network where branches set up VPN tunnels with each other and with the HQ.

Prerequisites

  • Before configuring DSVPN, apply for a DSVPN license and run the license active command to activate it.
  • Configure each involved interface and assign IP addresses to them.
