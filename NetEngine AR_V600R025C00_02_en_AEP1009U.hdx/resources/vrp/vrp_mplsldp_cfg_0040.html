Example for Configuring LDP Extension for Inter-Area LSPs

Networking Requirements

The network shown in Figure 1 has two IGP areas: Area 10 and Area 20. Inter-area LSPs need to be established from LSRA to LSRB and from LSRA to LSRC. LDP extension for inter-area LSPs needs to be configured on LSRA so that LSRA can search for routes based on the longest match rule to establish LSPs.

Figure 1 Configuring LDP extension for inter-area LSPs

In this example, interface1, interface2, and interface3 represent 10GE0/0/1, 10GE0/0/2, and 10GE0/0/3, respectively.


Configuration Roadmap

The configuration roadmap is as follows:

  1. Assign IP addresses to interfaces on each node and configure the loopback addresses to be used as LSR IDs.

  2. Configure basic IS-IS functions.

  3. Configure a policy for summarizing routes.

  4. Enable MPLS and MPLS LDP globally and on the interfaces of each node.

  5. Configure LDP extension for inter-area LSPs.

Procedure

  1. Assign IP addresses to interfaces on each node and configure the loopback addresses to be used as LSR IDs.

    Assign an IP address and a mask to each interface (including loopback interfaces) according to Figure 1.

  2. Configure basic IS-IS functions.

    # Configure LSRA.

    <LSRA> system-view
[LSRA] isis 1
[LSRA-isis-1] is-level level-2
[LSRA-isis-1] network-entity 20.0010.0100.0001.00
[LSRA-isis-1] quit
[LSRA] interface 10GE0/0/1
[LSRA-10GE0/0/1] isis enable 1
[LSRA-10GE0/0/1] quit
[LSRA] interface loopback 0
[LSRA-LoopBack0] isis enable 1
[LSRA-LoopBack0] quit

    # Configure LSRD.

    <LSRD> system-view
[LSRD] isis 1
[LSRD-isis-1] network-entity 10.0010.0200.0001.00
[LSRD-isis-1] quit
[LSRD] interface 10GE0/0/1
[LSRD-10GE0/0/1] isis enable 1
[LSRD-10GE0/0/1] isis circuit-level level-2
[LSRD-10GE0/0/1] quit
[LSRD] interface 10GE0/0/2
[LSRD-10GE0/0/2] isis enable 1
[LSRD-10GE0/0/2] isis circuit-level level-1
[LSRD-10GE0/0/2] quit
[LSRD] interface 10GE0/0/3
[LSRD-10GE0/0/3] isis enable 1
[LSRD-10GE0/0/3] isis circuit-level level-1
[LSRD-10GE0/0/3] quit
[LSRD] interface loopback 0
[LSRD-LoopBack0] isis enable 1
[LSRD-LoopBack0] quit

    # Configure LSRB.

    <LSRB> system-view
[LSRB] isis 1
[LSRB-isis-1] is-level level-1
[LSRB-isis-1] network-entity 10.0010.0300.0001.00
[LSRB-isis-1] quit
[LSRB] interface 10GE0/0/1
[LSRB-10GE0/0/1] isis enable 1
[LSRB-10GE0/0/1] quit
[LSRB] interface loopback 0
[LSRB-LoopBack0] isis enable 1
[LSRB-LoopBack0] quit

    # Configure LSRC.

    <LSRC> system-view
[LSRC] isis 1
[LSRC-isis-1] is-level level-1
[LSRC-isis-1] network-entity 10.0010.0300.0002.00 
[LSRC-isis-1] quit
[LSRC] interface 10GE0/0/1
[LSRC-10GE0/0/1] isis enable 1
[LSRC-10GE0/0/1] quit
[LSRC] interface loopback 0
[LSRC-LoopBack0] isis enable 1
[LSRC-LoopBack0] quit

  3. Configure a policy for summarizing routes.

    # On LSRD, run the summary command to summarize host routes to LSRB and LSRC.

    [LSRD] isis 1
[LSRD-isis-1] summary 10.10.3.0 255.255.255.0 avoid-feedback
[LSRD-isis-1] quit

  4. Configure MPLS and MPLS LDP globally and on interfaces on each node so that the network can forward MPLS traffic. Then, check information about established LSPs.

    # Configure LSRA.

    [LSRA] mpls lsr-id 10.10.1.1
[LSRA] mpls
[LSRA-mpls] quit
[LSRA] mpls ldp
[LSRA-mpls-ldp] quit
[LSRA] interface 10GE0/0/1
[LSRA-10GE0/0/1] mpls
[LSRA-10GE0/0/1] mpls ldp
[LSRA-10GE0/0/1] quit

    # Configure LSRD.

    [LSRD] mpls lsr-id 10.10.2.2
[LSRD] mpls
[LSRD-mpls] quit
[LSRD] mpls ldp
[LSRD-mpls-ldp] quit
[LSRD] interface 10GE0/0/1
[LSRD-10GE0/0/1] mpls
[LSRD-10GE0/0/1] mpls ldp
[LSRD-10GE0/0/1] quit
[LSRD] interface 10GE0/0/2
[LSRD-10GE0/0/2] mpls
[LSRD-10GE0/0/2] mpls ldp
[LSRD-10GE0/0/2] quit
[LSRD] interface 10GE0/0/3
[LSRD-10GE0/0/3] mpls
[LSRD-10GE0/0/3] mpls ldp
[LSRD-10GE0/0/3] quit

    # Configure LSRB.

    [LSRB] mpls lsr-id 10.10.3.1
[LSRB] mpls
[LSRB-mpls] quit
[LSRB] mpls ldp
[LSRB-mpls-ldp] quit
[LSRB] interface 10GE0/0/1
[LSRB-10GE0/0/1] mpls
[LSRB-10GE0/0/1] mpls ldp
[LSRB-10GE0/0/1] quit

    # Configure LSRC.

    [LSRC] mpls lsr-id 10.10.3.2
[LSRC] mpls
[LSRC-mpls] quit
[LSRC] mpls ldp
[LSRC-mpls-ldp] quit
[LSRC] interface 10GE0/0/1
[LSRC-10GE0/0/1] mpls
[LSRC-10GE0/0/1] mpls ldp
[LSRC-10GE0/0/1] quit

    # After completing the preceding configuration, run the display mpls lsp command on LSRA to check information about established LSPs.

    [LSRA] display mpls lsp

                  LSP Information: LDP LSP

 10.10.2.2/32         NULL/3        -/10GE0/0/1 
 10.10.2.2/32         1024/3        -/10GE0/0/1

    The preceding command output shows that by default, LDP does not establish inter-area LSPs from LSRA to LSRB or from LSRA to LSRC.

  5. Configure LDP extension for inter-area LSPs.

    # Run the longest-match command on LSRA to enable LDP to use the longest match rule to search for routes to establish LSPs.

    [LSRA] mpls ldp
[LSRA-mpls-ldp] longest-match
[LSRA-mpls-ldp] quit

  6. Verify the configuration.

    # After completing the preceding configuration, run the display mpls lsp command on LSRA to check established LSPs.

    [LSRA] display mpls lsp

Configuration Scripts

  • LSRA

    #
 sysname LSRA
#
 mpls lsr-id 10.10.1.1
 mpls
#
mpls ldp
 longest-match
#
isis 1
 is-level level-2
 network-entity 20.0010.0100.0001.00
#
interface 10GE0/0/1 
 ip address 10.1.1.1 255.255.255.0
 isis enable 1
 mpls
 mpls ldp
#
interface LoopBack0
 ip address 10.10.1.1 255.255.255.255
 isis enable 1
#
return

  • LSRD

    #
 sysname LSRD
#
 mpls lsr-id 10.10.2.2
 mpls
#
mpls ldp
#
isis 1
 network-entity 10.0010.0200.0001.00
 import-route isis level-1 into level-2 filter-policy ip-prefix permit-host
 summary 10.10.3.0 255.255.255.0 avoid-feedback
#
interface 10GE0/0/1 
 ip address 10.1.1.2 255.255.255.0
 isis enable 1
 isis circuit-level level-2
 mpls
 mpls ldp
#
interface 10GE0/0/2
 ip address 10.1.2.1 255.255.255.0
 isis enable 1
 isis circuit-level level-1
 mpls
 mpls ldp
#
interface 10GE0/0/3
 ip address 10.1.3.1 255.255.255.0
 isis enable 1
 isis circuit-level level-1
 mpls
 mpls ldp
#
interface LoopBack0
 ip address 10.10.2.2 255.255.255.255
 isis enable 1
#
 ip ip-prefix permit-host index 10 permit 0.0.0.0 32
#
return
