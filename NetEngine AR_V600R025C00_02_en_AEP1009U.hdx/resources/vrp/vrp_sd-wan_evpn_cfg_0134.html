(Optional) Configuring the Traffic-Triggered Dynamic Connection Establishment Function

Context

In the full-mesh networking, the specification of branch connections is limited. If only a small number of branches need to communicate with each other, the dynamic connection establishment function can be enabled.

Due to the limited specifications of small-capacity models, tunnels cannot be established between some branches during peak hours. Traffic from these branches is still forwarded through the hub site.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the site view.

    evpn site site-id

  3. Enable the dynamic connection establishment function.

    dynamic-connection enable

    By default, the dynamic connection establishment function is disabled on a device.
