Resetting BGP SD-WAN Connections

Context

Resetting BGP SD-WAN connections interrupts BGP SD-WAN peer relationships between devices. Exercise caution when performing this operation.

After a BGP SD-WAN routing policy changes, if the device does not support the route-refresh capability, you need to reset a BGP connection to make the new configuration take effect. If the device supports the route-refresh capability, you can perform a soft reset on a BGP SD-WAN connection. A soft reset can refresh BGP SD-WAN routes and apply a new routing policy without tearing down the BGP SD-WAN connection.

Run the following commands in the user view as required.

Table 1 Resetting BGP SD-WAN connections

Operation

Command

Reset all BGP SD-WAN connections.

reset bgp sd-wan all

Reset BGP SD-WAN connections with a specified AS.

reset bgp sd-wan as-number

Reset BGP SD-WAN connections with a specified peer.

reset bgp sd-wan peerIpv4Addr

Reset BGP SD-WAN connections with a specified peer group.

reset bgp sd-wan group groupName

Reset all EBGP SD-WAN connections.

reset bgp sd-wan external

Reset all IBGP SD-WAN connections.

reset bgp sd-wan internal

Perform a soft reset on all BGP SD-WAN connections.

refresh bgp sd-wan all { export | import }

Perform a soft reset on BGP SD-WAN connections with a specified peer.

refresh bgp sd-wan peerIpv4Addr { export | import }

Perform a soft reset on BGP SD-WAN connections with a specified peer group.

refresh bgp sd-wan group groupName { export | import }

Perform a soft reset on all EBGP SD-WAN connections.

refresh bgp sd-wan external { export | import }

Perform a soft reset on all IBGP SD-WAN connections.

refresh bgp sd-wan internal { export | import }

Reset SA information of P2MP policies.

reset ipsec p2mp-sa

Reset SA statistics of P2MP policies.

reset ipsec p2mp-sa statistics

Clear SA information of a specified site or device P2MP policy on the peer end.

reset ipsec p2mp-sa peer [ site site-id [ system system-id ] ]
