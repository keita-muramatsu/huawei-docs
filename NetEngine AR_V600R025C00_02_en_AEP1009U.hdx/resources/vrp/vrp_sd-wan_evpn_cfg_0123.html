Configuring SD-WAN Tunnel Services

Context

In SD-WAN scenarios, the SD-WAN encapsulation mode must be configured for tunnel interfaces. These interfaces serve as service interfaces of SD-WAN tunnels, where related feature, such as SA statistics collection and MQC policies, are applied.

Procedure

  1. Enter the system view.

    system-view

  2. Create a tunnel interface and enter the tunnel interface view.

    interface tunnel interface-number

  3. Configure the SD-WAN tunnel encapsulation protocol for the tunnel interface.

    tunnel-protocol sd-wan

    By default, no SD-WAN tunnel encapsulation protocol is configured for a tunnel interface.

  4. Enable SD-WAN services for the tunnel interface.

    sd-wan service enable

    By default, SD-WAN services are disabled for a tunnel interface.

  5. (Optional) Bind a VPN instance to the tunnel interface.

    ip binding vpn-instance vpn-instance-name

    By default, no VPN instance is bound to a tunnel interface. After this step is performed, Layer 3 features (including IPv4 and IPv6 features) configured on the interface, such as the IP address and routing protocol, will be deleted. If necessary, reconfigure them.

  6. (Optional) Bind a P2MP policy to the tunnel interface.

    ipsec-p2mp-policy policy-name

    By default, no P2MP policy is bound to a tunnel interface.

    After a P2MP policy is bound to a tunnel interface, packets of the VPN instance bound to the tunnel interface will be encrypted. This is applicable when data of department 1 needs to be encrypted but data of department 2 does not.

    After a P2MP policy is bound to a TNP, packets sent from the TNP will be encrypted. This is applicable when data of the Internet network needs to be encrypted but data of the MPLS network does not.

  7. (Optional) Enable traffic statistics collection for the tunnel interface.

    statistics enable

    By default, traffic statistics collection is disabled on a tunnel interface.
