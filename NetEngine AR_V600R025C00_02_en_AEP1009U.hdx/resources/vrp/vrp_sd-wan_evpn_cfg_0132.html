(Optional) Configuring DTLS Authentication

Context

In SD-WAN EVPN scenarios, after DTLS authentication is enabled, ESNs can be authenticated during DTLS interaction. You can configure the ESN blacklist and whitelist function to isolate identified devices. The isolated devices cannot communicate with other devices. Rules for matching the ESN blacklist and whitelist are as follows:

  • Only the blacklist is configured: Devices that match the blacklist are isolated, and devices that do not match the blacklist are not isolated.
  • Only the whitelist is configured: Devices that do not match the whitelist are isolated, and devices that match the whitelist are not isolated.
  • The blacklist and whitelist cannot be configured simultaneously.

DTLS authentication can be separately configured for RRs or CPEs.

Procedure

  • Configure DTLS authentication for RRs.
    1. Enter the system view.

      system-view

    2. Create an ESN blacklist or whitelist and enter the ESN blacklist or whitelist view.

      dtls esn-list list-name [ type { whitelist | blacklist } ]

      By default, no ESN blacklist or whitelist is created.

    3. Configure ESNs in the ESN blacklist or whitelist.

      esn esn

      By default, no ESN is configured in the ESN blacklist or whitelist.

    4. Return to the system view.

      quit

    5. Enter the DTLS server view.

      dtls server

    6. Enable ESN authentication on the DTLS server.

      esn-authenticate dtls-esn-list

      By default, ESN authentication is disabled on the DTLS server.

  • Configure DTLS authentication for CPEs.
    1. Enter the system view.

      system-view

    2. Create an ESN blacklist or whitelist and enter the ESN blacklist or whitelist view.

      dtls esn-list list-name [ type { whitelist | blacklist } ]

      By default, no ESN blacklist or whitelist is created.

    3. Configure ESNs in the ESN blacklist or whitelist.

      esn esn

      By default, no ESN is configured in the ESN blacklist or whitelist.

    4. Return to the system view.

      quit

    5. Enter the DTLS client view.

      dtls client

    6. Enable ESN authentication on the DTLS client.

      esn-authenticate dtls-esn-list

      By default, ESN authentication is disabled on the DTLS client.
