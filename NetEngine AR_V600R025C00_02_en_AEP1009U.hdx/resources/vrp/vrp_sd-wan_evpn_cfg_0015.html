Resetting BGP EVPN Connections

Context

Resetting BGP EVPN connections interrupts BGP EVPN peer relationships between devices. Exercise caution when performing this operation.

After a BGP EVPN routing policy changes, if the device does not support the route-refresh capability, you need to reset a BGP connection to make the new configuration take effect. If the device supports the route-refresh capability, you can perform a soft reset on a BGP EVPN connection. A soft reset can refresh BGP EVPN routes and apply a new routing policy without tearing down the BGP EVPN connection.

Run the following commands in the user view as required.

Table 1 Resetting BGP EVPN connections

Operation

Command

Reset all BGP EVPN connections.

reset bgp evpn all

Reset BGP EVPN connections with a specified AS.

reset bgp evpn as-number

Reset BGP EVPN connections with a specified peer.

reset bgp evpn ipv4-address

Reset BGP EVPN connections with a specified peer group.

reset bgp evpn group group-name

Perform a soft reset on all BGP EVPN connections.

refresh bgp evpn all { export | import }

Perform a soft reset on BGP EVPN connections with a specified peer.

refresh bgp evpn peer-address { export | import }

Perform a soft reset on BGP EVPN connections with a specified peer group.

refresh bgp evpn group group-name { export | import }

Reset SD-WAN EVPN site connection statistics.

reset evpn connection { all | connection-id | { site site-id } } statistics
