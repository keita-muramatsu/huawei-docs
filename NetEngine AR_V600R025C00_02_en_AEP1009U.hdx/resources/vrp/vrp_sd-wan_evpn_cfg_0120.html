Configuring a TNP

Prerequisites

The CPE and RR are routable to each other.

Context

A TNP is a logical WAN interface through which a site connects to a transport network. Key TNP information includes the site ID, transport network ID, public IP address, private IP address, and tunnel encapsulation. TNPs are used to establish connections between sites.

Procedure

  1. Enter the system view.

    system-view

  2. Create a site and enter the site view.

    evpn site site-id [ site-type { cpe | rr | rr-cpe } ]

    By default, no site is created.

  3. Configure the system ID of the site.

    system-id system-ip-param

    By default, no system ID is configured for a site.

  4. (Optional) Configure a site as an interworking gateway site.

    interworking gateway enable

    By default, a site is not an interworking gateway site.

    To connect an SD-WAN network domain to a legacy network domain, you can configure a site as the gateway between the two network domains. Such a site is known as the interworking gateway site. This function is supported only on the AR6700-H series and AR8000 series.

  5. (Optional) Configure a QoS local ID for the interworking gateway site.

    interworking gateway qos-local-id id

    By default, no QoS local ID is configured for an interworking gateway site.

    When an interworking gateway site connects to multiple CPE sites, you can configure a QoS local ID for the gateway site to rate-limit traffic on per-VPN and per-CPE basis. To do this, run this command to configure a QoS local ID for the interworking gateway site, configure an MQC policy that rate-limits traffic of the same QoS local ID, and finally apply the MQC policy to SD-WAN tunnel interfaces at the CPE sites.

  6. (Optional) Enable the function of discarding insecure packets.

    unsecure-packet discard enable

    By default, the function of discarding insecure packets is disabled.

    When the encryption function is enabled on the TNP or tunnel interface of a site, the forwarding process is performed even if unencrypted packets are received. To enhance security, you can enable the function of discarding insecure packets. Then the device discards received unencrypted packets.

  7. (Optional) In a dual-gateway scenario, configure the load balancing mode.

    load-balance-mode { local-prefer | local-and-peer }

    By default, the load balancing mode is local link first. That is, packets that do not match the SPR policy are load-balanced only among local links. If the mode is set to local-and-peer, packets that do not match the SPR policy can be load-balanced between the local links and the peer-link between gateways.

  8. Create a transport network domain.

    transport-network transport-network-id name transport-network-name [ priority priority ]

    By default, no transport network domain is created.

  9. Create a routing domain.

    routing-domain routing-domain-id name routing-domain-name

    By default, no routing domain is created.

  10. Create a TNP and enter the TNP view.

    transport-network-port transport-network-port-id [ type ipv6 ]

    By default, no TNP is created.

  11. Configure the TN to which the TNP belongs.

    transport-network transport-network-name

    By default, no TN is configured for a TNP.

  12. Configure the routing domain to which the TNP belongs.

    routing-domain routing-domain-name

    By default, no routing domain is configured for a TNP.

  13. Configure the source interface for the TNP.

    source-interface { interface-name | interface-type interface-number }

    By default, no source interface is configured for a TNP.

  14. (Optional) Configure a public IP address for the TNP.

    public-ip ip-address

    By default, no public IP address is configured for a TNP.

  15. (Optional) Enable traffic statistics collection for the TNP.

    statistics enable

    By default, traffic statistics collection is disabled for a TNP.

  16. (Optional) Configure the TNP weight.

    weight weight-value

    By default, the TNP weight is 6.

  17. (Optional) Set the MTU for the TNP.

    mtu mtu

    By default, the MTU of a TNP is 1500 bytes.
