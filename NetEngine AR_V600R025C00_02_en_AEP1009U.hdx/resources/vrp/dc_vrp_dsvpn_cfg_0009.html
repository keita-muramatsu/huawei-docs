Clearing DSVPN Running Statistics

Context

Statistics cannot be restored after being cleared. Exercise caution when clearing statistics.

Procedure

  1. Run the reset nhrp statistics interface tunnel interface-number command in the user view to clear NHRP packet statistics on a tunnel interface.
