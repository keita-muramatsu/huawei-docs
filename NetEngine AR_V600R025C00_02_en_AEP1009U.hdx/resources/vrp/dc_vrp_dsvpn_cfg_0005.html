Configuring DSVPN NAT Traversal

Prerequisites

Before configuring DSVPN NAT traversal, you have completed the following task:

  • Configure basic DSVPN functions. For details, see Configuring Basic DSVPN Functions.

Context

If spokes behind NAT devices want to set up VPN tunnels with the HQ or with each other, traffic must travel through the NAT devices. DSVPN supports NAT traversal to implement direct communication between spokes.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the view of the inbound interface of packets.

    interface interface-type interface-number

  3. Switch the interface working mode to Layer 3.

    undo portswitch

    Determine whether to perform this step based on the current interface working mode.

  4. Enable the NAT function on the interface.

    nat enable

  5. Return to the system view.

    quit

  6. Configure NAT Server.

    nat server name [ vpn-instance vpn-instance-name1 ] [ zone zone-name ] [ protocol protocol-type ] global global-address [ global-address-end ] inside host-address [ host-address-end ] [ no-reverse ] [ vpn-instance vpn-instance-name2 ] [ route ] [ nat-disable ] [ description description ]

    The NAT device must have NAT Server configured. NAT traversal cannot be implemented on a DSVPN network if source NAT policy-based dynamic NAT is configured on the NAT device.
