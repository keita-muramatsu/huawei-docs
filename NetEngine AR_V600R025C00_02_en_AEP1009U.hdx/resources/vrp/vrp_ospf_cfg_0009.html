Default Settings for OSPF

Table 1 describes the default settings for OSPF.

Table 1 Default settings for OSPF

Parameter

Default Setting

OSPF

Disabled.

Interval at which Hello packets are transmitted

10 seconds on P2P and broadcast interfaces; 30 seconds on P2MP and NBMA interfaces

Dead interval after which OSPF neighbor relationships fail

40 seconds on P2P and broadcast interfaces; 120 seconds on P2MP and NBMA interfaces

Period during which a device acts as a stub router

500 seconds

Bandwidth reference value used to calculate a link cost

100 Mbit/s
