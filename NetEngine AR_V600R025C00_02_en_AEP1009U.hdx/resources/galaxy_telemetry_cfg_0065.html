Overview of ELK

ELK stands for three open-source tools: ElasticSearch, Logstash, and Kibana. The ELK tool is an open-source O&M tool and can be installed on multiple platforms, such as Linux, Windows, and Mac OS X. Details about ElasticSearch, Logstash, and Kibana are as follows:

  • ElasticSearch is developed based on Java. It is a real-time full-text search and analytics engine that provides data collection, analysis, and storage.
  • Logstash is developed based on Ruby and is a tool for collecting, analyzing, and filtering data. It works using plug-ins and does not have the capability of receiving or converting telemetry data. Modules running on Logstash provide the capability of receiving or converting telemetry data, whereas Logstash provides a framework only. The framework consists of the following:
    • Plugins: implement functions such as recording telemetry service data using plug-ins.
    • HuaweiDialGrpc: a Linux server program that communicates with monitored devices.
  • Kibana is a web-based graphical user interface (GUI) developed for searching, analyzing, and visualizing data stored on ElasticSearch. It uses the REST interface of ElasticSearch to retrieve data. In addition, it allows users to create customized dashboard views for specified data and to query and filter data.
