Clearing All Dynamic MAC Address Entries on an AP's Wired Interface

Context

Before recollecting statistics about all dynamic MAC address entries on an AP's wired interface, you need to clear existing statistics.

The cleared records cannot be restored. Therefore, exercise caution when performing this operation.

Procedure

  • Run the reset mac-address ap-id ap-id interface-type interface-number command to clear all dynamic MAC address entries on an AP's wired interface.
