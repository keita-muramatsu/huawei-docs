Configuring U-BFD for SRv6 TE Policy

Context

U-BFD for SRv6 TE Policy can quickly detect segment list faults. If all the segment lists of a candidate path are faulty, U-BFD triggers a hot-standby candidate path switchover to minimize the impact on services.

Procedure

  1. Enter the system view.

    system-view

  2. Enable BFD globally.

    bfd

    BFD-related configuration can be performed only after BFD is enabled globally using the bfd command.

  3. Return to the system view.

    quit

  4. Enter the Segment Routing IPv6 view.

    segment-routing ipv6

  5. Configure U-BFD for SRv6 TE Policy.
    • Global configuration

      1. Enable U-BFD for all SRv6 TE Policies.

        srv6-te-policy bfd unaffiliated enable [ reverse-path binding-sid ]

      2. (Optional) Configure U-BFD parameters for the SRv6 TE Policies.

        srv6-te-policy bfd { min-tx-interval tx-value | detect-multiplier detectmulti-value } *
      3. (Optional) Configure U-BFD parameters for the backup candidate paths of the SRv6 TE Policies.
        srv6-te-policy bfd { min-tx-interval backup-tx-value | detect-multiplier backup-detectmulti-value } * backup-path
    • Single-policy configuration

      1. Enter the SRv6 TE Policy view.

        srv6-te policy name-value

      2. Enable or disable U-BFD for the SRv6 TE Policy.

        bfd unaffiliated enable [ reverse-path binding-sid ]
Alternatively:
bfd disable

      3. (Optional) Configure U-BFD parameters for the SRv6 TE Policy.

        bfd { min-tx-interval tx-value | detect-multiplier detectmulti-value } *
      4. (Optional) Configure U-BFD parameters for the backup candidate paths of the SRv6 TE Policy.
        bfd { min-tx-interval backup-tx-value | detect-multiplier backup-detectmulti-value } * backup-path
  6. (Optional) Configure segment list switching and deletion delays for SRv6 TE Policies.

    srv6-te-policy switch-delay switchDelay delete-delay deleteDelay

Verifying the Configuration

Run the display srv6-te policy [ endpoint ipv6-address color color-value | policy-name name-value ] command to check the U-BFD status of an SRv6 TE Policy.
