Configuring a Routing Policy List

Context

You can configure a routing policy list to control route acceptance and advertisement.

Procedure

  1. Enter the system view.

    system-view

  2. Create a routing policy list and enter its view. For details, see Table 1.

    Table 1 Creating a routing policy list

    Operation

    Command

    Create a Large-Community attribute list to set the Large-Community attribute for BGP routes.

    ip large-community-list name

Verifying the Configuration

Run the display current-configuration command to check information about the configured routing policy list.
