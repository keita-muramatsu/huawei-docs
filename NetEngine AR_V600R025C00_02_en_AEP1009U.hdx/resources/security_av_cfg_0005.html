Antivirus Profile

The antivirus profile is used to determine the protocols and file types on which the device performs virus detection, and the action to be taken on detected virus files.

Default Antivirus Profile

For the convenience of administrators, the device provides a default antivirus profile named default for defending against typical attacks. The antivirus profile defines the default actions for each protocol in the file upload or download direction. Table 1 provides details of the default antivirus profile. You cannot modify or delete the default antivirus profile.

Supported file types

-

Signature database-based antivirus can detect the following file types: OFFICE, PE, ELF, SCRIPT, EICAR, EML, FLASH, PDF, RTF, MACOS, JAR, APK, ARCHIVE, WEB, IMAGE, VIDEO, AUDIO, and OTHER.

By default, signature database-based antivirus can detect OFFICE, PE, ELF, SCRIPT, EICAR, EML, FLASH, PDF, RTF, MACOS, JAR, APK, and ARCHIVE files.

Virus exception

-

If you consider a detected virus as a false positive, you can add the virus to the exception list and set the action to allow. The device then directly permits the file traffic.

By default, no virus exception is configured.

Applying the Antivirus Profile

The antivirus function takes effect only after the antivirus profile is referenced in the security policy. The device performs the antivirus processing on traffic that matches the security policy.

The connection requests of protocols are initiated from clients. To successfully establish the connection, the direction of the security policy referencing the antivirus profile should be consistent with the direction in which the access is initiated. (Configure the source security zone to the security zone where the client is located, and the destination security zone to the security zone where the server is located.)

For example, to protect intranet PCs against virus attacks, the antivirus profile must be applied to the security policy for accessing the external network from the intranet, which is consistent with the direction in which access is initiated, even though the virus file is transmitted from the external network to the intranet.
