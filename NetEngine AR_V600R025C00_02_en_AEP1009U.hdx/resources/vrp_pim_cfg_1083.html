Configuring the Maximum Number of Multicast Sources Corresponding to One Multicast Group

Context

If too many invalid multicast source entries are generated for a multicast group, a large number of entry resources are consumed, affecting the generation of other multicast group entries. To prevent this problem, you can configure the maximum number of multicast sources corresponding to one multicast group. In this way, when the maximum number of multicast sources corresponding to a multicast group is reached, an alarm is generated and no more multicast source entries are generated for this multicast group. This prevents multicast services from being affected by excessive multicast source entries generated for a multicast group.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the PIM view.

    pim [ vpn-instance vpn-instance-name ]

  3. Configure the maximum number of multicast sources corresponding to one multicast group.

    source-per-group limit limit-count
