Checking Information About Non-Wi-Fi Devices on a WAC

Procedure

  • Run the display wlan non-wifi-device { all | ap-id ap-id radio radio-id } command to check detected non-Wi-Fi devices.
  • Run the display wlan non-wifi-device history { all | ap-id ap-id radio radio-id } command to check non-Wi-Fi devices in the historical list.
