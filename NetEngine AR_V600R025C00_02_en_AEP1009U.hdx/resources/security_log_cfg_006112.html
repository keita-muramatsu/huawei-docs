Configuring the Service Logs in Syslog Format

Procedure

  1. Enter the system view.

    system-view

  2. (Optional) Enable the function of sending service logs in syslog format.

    firewall log service log-type syslog

    By default, the function of sending service logs in syslog format is enabled.

  3. (Optional) Configure the function of generating service logs.

    engine log { ips | av } enable

    By default, the function of generating intrusion prevention service logs and antivirus service logs is enabled.

  4. Configure the device to output service logs to the log buffer, log file, console, terminal, and log host.

    The device can output these logs in syslog format to the log buffer, log file, console, terminal, and log host through the information center.
