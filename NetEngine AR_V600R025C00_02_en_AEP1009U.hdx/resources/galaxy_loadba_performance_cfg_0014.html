Configuring an ECMP Mode for IP Packet Forwarding

Procedure

  • Configure an ECMP mode for IPv4 packet forwarding.
    1. Enter the system view.

      system-view

    2. Configure an ECMP mode for IPv4 packet forwarding.

      Table 1 Configuring an ECMP mode for IPv4 packet forwarding

      Operation

      Command

      Description

      Configure a load balancing mode for IPv4 packet forwarding in a multi-egress scenario.

      ip load-balance { flow [ src-ip | dst-ip | src-port | dst-port ] * | packet }

      In a multi-egress scenario, if equal-cost routes exist on a device, the device forwards IPv4 packets in per-flow load balancing mode by default, and uses the source and destination IPv4 addresses for hash calculation to select an outbound interface. When the loads of multiple links are unbalanced:

      • If per-flow load balancing is required, configure a random combination of the source IPv4 address, destination IPv4 address, source port number, and destination port number for hash calculation. The device uses the hash algorithm to calculate a value based on the configured combination and selects a link to forward packets based on the value.
      • If per-packet load balancing is required, the device selects different links from multiple equal-cost links and forwards IPv4 packets through these links.
