Querying the Rate of an Interface

Description of MIB Objects

You can use ifSpeed in ifTable to obtain the rates of all interfaces, and then use ifIndex to query the rate of an interface.

Object

OID

ifIndex

1.3.6.1.2.1.2.2.1.1

ifDescr

1.3.6.1.2.1.2.2.1.2

ifSpeed

1.3.6.1.2.1.2.2.1.5

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.

  2. Perform the Walk operation on ifDescr to query the entity index ifIndex. As shown in Figure 1, the index of 10GE8/0/1 is 9.

    Figure 1 Obtaining the mapping between an interface and its index

  3. Perform the Walk operation on ifSpeed to query the rate of the corresponding interface based on the value of ifIndex. As shown in Figure 2, the rate of 10GE8/0/1 with the index of 9 is 4294967295 bit/s.

    Figure 2 Querying the rate of an interface through ifSpeed
