(Optional) Configuring the NTP Broadcast Mode

Context

When the broadcast mode is used, you need to perform the following configurations on both the broadcast server and client.

The broadcast mode can be used only on LANs.

The broadcast client can be synchronized with the broadcast server only after the clock of the broadcast server is synchronized.

Procedure

  • Configure an NTP broadcast server.
    1. Enter the system view.

      system-view

    2. Enter the view of the interface used for sending NTP broadcast packets.

      interface interface-type interface-number

    3. Configure the local device as the NTP broadcast server.

      ntp broadcast-server [ authentication-keyid key-id | version version-number | port port-number ] *

      By default, the broadcast service is not configured.

      After the configuration is complete, the local device functions as the NTP broadcast server periodically sending clock synchronization packets to the broadcast address 255.255.255.255 from a specified interface.

      If the authentication-keyid parameter is specified, perform the operations in Enabling NTP Authentication first.

      If the port parameter is specified, specify the same port number on the server using the ntp source-port portNum command.

  • Configure an NTP broadcast client.
    1. Enter the system view.

      system-view

    2. Enter the view of the interface used for receiving NTP broadcast packets.

      interface interface-type interface-number

    3. Configure the local device as the NTP broadcast client.

      ntp broadcast-client

      By default, the device is not configured as the NTP broadcast client.

      After the configuration is complete, the local device functions as the NTP broadcast client listening for the NTP broadcast packets sent from the server and synchronizing the local clock with the server.
