Summary of AAA Configuration Tasks

Table 1 lists the configuration tasks for each authentication, accounting, and authorization method.

Multiple authentication or authorization methods can be used in an AAA scheme. For example, local authentication can be used as a backup of RADIUS authentication and HWTACACS authentication, and local authorization can be used as a backup of HWTACACS authorization.

Table 1 Summary of AAA configuration tasks

Scenario

Configuration Task

Local authentication and authorization
  1. Configuring AAA Schemes
  2. Configuring a Local User
  3. Configuring a Domain

RADIUS authentication, authorization, and accounting
  1. Configuring AAA Schemes
  2. Configuring RADIUS Authentication, Authorization, and Accounting
  3. Configuring a Domain

HWTACACS authentication, authorization, and accounting
  1. Configuring AAA Schemes
  2. Configuring HWTACACS Authentication, Authorization, and Accounting
  3. Configuring a Domain

LDAP authentication and authorization
  1. Configuring AAA Schemes
  2. Configuring LDAP Authentication and Authorization
  3. Configuring a Domain

AD authentication and authorization
  1. Configuring AAA Schemes
  2. Configuring AD Authentication and Authorization
  3. Configuring a Domain
