Enabling Hot Standby

Procedure

  1. Enter the system view.

    system-view

  2. Optional: Configure a role for the device.

    hrp device { standby | active }

  3. Enable hot standby.

    hrp enable

Verifying the Configuration

  • Run the display hrp state [ verbose ] command in any view to check the hot standby status.
  • Run the display hrp interface command in any view to check the heartbeat interface status.
  • Run the display hrp statistic command in any view to check HRP packet statistics. To check HRP packets exchanged during any given period of time, run the reset hrp statistic command in the user view to clear historical HRP packet statistics and then run the display hrp statistic command after this period elapses.
