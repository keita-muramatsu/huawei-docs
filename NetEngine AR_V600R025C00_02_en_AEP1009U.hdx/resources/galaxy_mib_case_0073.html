Querying Whether STP Is Enabled

Description of MIB Objects

hwMstpStatus describes whether STP is enabled globally. It describes whether STP is enabled in process 0 when there are multiple processes.

hwMstpProTable describes MSTP process information, including the enabling status, priority, and root bridge type. You can use hwMstpProStpState in hwMstpProTable to obtain the STP enabling status of all processes.

hwMstpProNewPortTable describes port information, including the enabling status and priority. You can use hwMstpProNewPortStpStatus in hwMstpProNewPortTable to obtain the STP enabling status of interfaces.

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.
  2. Perform the Get operation on hwMstpStatus to query whether STP is enabled globally.
    Figure 1 Querying whether STP is enabled globally
  3. Perform the Walk operation on hwMstpProStpState to query whether STP is enabled in a process.
    Figure 2 Querying whether STP is enabled in a process
  4. Query whether STP is enabled on an interface.
    1. Perform the Walk operation on hwL2IfPortName to query mappings between interface names and interface indexes.
      Figure 3 Querying mappings between interface names and interface indexes
    2. Perform the Walk operation on hwMstpProNewPortStpStatus in hwMstpProNewPortTable to query whether STP is enabled on interfaces. Deduct 1 from an interface index to obtain the hwMstpPortId1 value. For example, the interface index of 10GE5/0/7 is 17. Deduct 1 from 17 to obtain the hwMstpPortId1 value 16, that is hwMstpProNewPortStpStatus.0.0.16.0.0.0.0 (integer) enabled(1). Therefore, the STP status of 10GE5/0/7 is enabled.
      Figure 4 Querying whether STP is enabled on an interface
