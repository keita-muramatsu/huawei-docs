Saving Device Configurations

Procedure

  1. Click Save in the upper right corner.
  2. In the dialog box that is displayed, save device configurations.

    • Click OK to save device configurations to the currently effective configuration file.
    • Click Save as new file and enter a new file name to save device configurations to a new configuration file.
