Checking Information About the Forwarding Table

You can diagnose routing problems on a network based on information about the forwarding table. For details, see Table 1. The display commands can be used in any view.

Table 1 Checking information about the forwarding table

Operation

Command

Check information about the IPv4 forwarding table on a specified board.

display ip fib slot slot-id [ vpn-instance vpn-instance-name ] [ dest-ip [ dest-ip-mask-len | dest-ip-mask ] ] [ verbose ]

Check statistics about the IPv4 forwarding tables of all VPN instances on a specified board.

display ip fib slot slot-id all-vpn-instance statistics

Check detailed information about the IPv4 forwarding tables of all VPN instances on a specified board.

display ip fib slot slot-id all-vpn-instance [ verbose ]

Check statistics about the IPv4 forwarding table of a specified VPN instance on a specified board.

display ip fib slot slot-id vpn-instance vpn-instance-name statistics

Check information about the IPv6 forwarding table on a specified board.

display ipv6 fib slot slotid all-vpn-instance [ statistics | verbose ]

display ipv6 fib slot slotid [ vpn-instance vpn-name ] [ destip [ destipmasklen ] ] [ verbose ]

display ipv6 fib slot slotid [ vpn-instance vpn-name ] statistics
