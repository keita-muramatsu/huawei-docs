Configuring MQC-based Traffic Policing

Context

There are various services on a network. When a large amount of service traffic enters the network side, congestion may occur due to insufficient bandwidth. To control a specific type of service traffic in the inbound or outbound direction on an interface, MQC-based traffic policing can be configured. MQC-based traffic policing uses traffic classifiers to implement differentiated services. When the receive or transmit rate of packets matching traffic classification rules exceeds the specified limit, the device discards the packets.

When both QoS CAR and MQC are used on an interface for traffic statistics collection, statistics about packets to which a QoS CAR profile is applied contain only the packets that do not match the traffic policy.

Procedure

  1. Configure a traffic classifier.

    For details about how to configure a traffic classifier, see Configuring a Traffic Classifier in "MQC Configuration".

  2. Configure a traffic behavior.
    1. (Optional) Disable the device from counting the inter-frame gaps and preambles when calculating the traffic policing rate.

      qos car ifg disable

      Only Ethernet links support this function.

    2. Create a traffic behavior and enter the traffic behavior view, or enter the view of an existing traffic behavior.

      traffic behavior behavior-name

    3. Configure a CAR action.

      car { cir cir-value [ kbps | mbps | gbps ] [ pir pir-value [ kbps | mbps | gbps ] ] } [ cbs cbs-value [ bytes | kbytes | mbytes ] pbs pbs-value [ bytes | kbytes | mbytes ] ] [ share ] [ mode color-blind ] [ green pass [ remark-8021p 8021p-value | remark-dscp dscp-value ] | yellow { discard | pass [ remark-8021p 8021p-value | remark-dscp dscp-value ] } | red { discard | pass [ remark-8021p 8021p-value | remark-dscp dscp-value ] } ]*

      The CIR and PIR can be set in percentages (by specifying cir-percentage and pir-percentage). Their base value is the traffic shaping bandwidth value (configured using the qos lr cir command) defined on an interface. If this bandwidth value is not configured, the base value is the interface bandwidth value. The percentage configuration can be applied only to the outbound direction and the corresponding command cannot be configured together with the preceding command for configuring absolute values.

      car cir pct cir-percentage [ pir pct pir-percentage ] hierarchical-bandwidth [ cbs cbs-value pbs pbs-value | share | mode color-blind ]*

    4. Exit the traffic behavior view.

      quit

  3. Configure a traffic policy.
    1. Create a traffic policy and enter the traffic policy view, or enter the view of an existing traffic policy.

      traffic policy policy-name

    2. Bind a traffic behavior and a traffic classifier to the traffic policy.

      classifier classifier-name behavior behavior-name [ precedence precedence-value ]

    3. Exit the traffic policy view.

      quit

  4. Apply a traffic policy.

    The application direction supported by a traffic policy is related to the configured action in a traffic behavior. For details, see configuration precautions for the feature.

    • Apply a traffic policy to an interface.
      1. Enter the interface view.
        interface interface-type interface-number
      2. Apply a traffic policy to the interface.
        traffic-policy policy-name { inbound | outbound } [ preprocess | firstprocess  ]
        traffic-policy policy-name inbound decap-process

        If the decap-process parameter is specified, you need to run the qos car inbound decap-process command in the interface view to configure the bandwidth limit for the decapsulation service in the inbound direction of the interface.

      3. Exit the interface view.
        quit
    • Apply a traffic policy to a site group.

      This command is supported only on the AR8100 series, AR6700-H series, and AR8700 series.

      1. Create a site group and enter the site group view.
        evpn site-group name
      2. Apply a traffic policy to the site group.
        traffic-policy policy-name outbound
      3. Exit the site group view.
        quit
