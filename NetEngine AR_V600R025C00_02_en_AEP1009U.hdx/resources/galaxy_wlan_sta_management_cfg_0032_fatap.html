Maintaining STA Running Statistics

Context

After STAs successfully associate with an AP, you can run the following commands in any view to check the STA running status.

Procedure

  • Run the display station { ap-group ap-group-name | ap-id ap-id | ssid ssid | sta-mac sta-mac-address | vlan vlan-id | all } command to check STA access information.
  • Run the display station statistics [ sta-mac sta-mac-address | ap-id ap-id ] command to check STA statistics.
  • Run the display station online-track sta-mac-address command to check the onboarding time information about a STA.
  • Run the display station assoc-info ap-offline-record { all | ap-id ap-id [ radio radio-id ]} command to check information about STAs that have onboarded an offline AP.
  • Run the display ap sta-signal strength ap-id ap-id [ radio radio-id ] command to check the average signal strength of STAs on a specified AP.
  • Run the reset station assoc-info ap-offline-record { all | ap-id ap-id [ radio radio ]} command to clear information about STAs that have onboarded an offline AP.
  • Run the reset station statistics [ sta-mac sta-mac-address ] command to clear statistics about online STAs.

    The cleared records cannot be restored. Therefore, exercise caution when performing this operation.
