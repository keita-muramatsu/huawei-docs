Binding Profiles

Context

After the configuration is complete, you need to bind profiles to an AP group or AP so that the configurations can be automatically delivered to specific APs and take effect.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP wired port profile and enter its view.

    wired-port-profile name wired-port-profile-name

    By default, the AP wired port profile default exists on the device.

  4. Bind the AP wired port link profile to the AP wired port profile.

    port-link-profile profile-name

    By default, the AP wired port link profile default is bound to an AP wired port profile.

  5. Return to the WLAN view.

    quit

  6. Enter the AP view or AP group view.
    • Enter the AP group view.
      ap-group name group-name
    • Enter the AP view.
      ap-id ap-id
  7. Bind the AP system profile to an AP group or a single AP.

    ap-system-profile profile-name

    By default, the AP system profile default is bound to an AP group, but no AP system profile is bound to an AP.

  8. Bind the AP wired port profile to an AP group or a single AP.

    wired-port-profile profile-name interface-type interface-number

    By default, the AP wired port profile default is bound to an AP group, but no AP wired port profile is bound to an AP.
