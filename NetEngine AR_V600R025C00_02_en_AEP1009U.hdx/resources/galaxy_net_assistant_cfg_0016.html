(Optional) Configuring Eth-Trunk Auto-negotiation

Context

An Eth-Trunk interface increases the link bandwidth by bundling a group of physical interfaces into a single logical interface, without needing to upgrade hardware. It also significantly improves link reliability through link backup. After Eth-Trunk auto-negotiation is configured in scenarios where multiple physical links exist between member devices, member devices automatically create an Eth-Trunk interface and add their interconnected physical interfaces to it, thereby forming a logical link.

You can enable Eth-Trunk auto-negotiation using either of the following modes:

  • Configure Eth-Trunk auto-negotiation on the master device.
  • Configure Eth-Trunk auto-negotiation on each NE. An NE can function as the master device or a member device.

You can configure both modes simultaneously; however, only the latest configuration takes effect.

After the configuration is delivered in either mode, the Eth-Trunk interface configuration is automatically generated based on the LLDP neighbor packets exchanged between NEs. The interaction process is as follows:
  1. Eth-Trunk auto-negotiation is enabled on NE A and NE B.
  2. NE A encapsulates information about the auto-negotiation status, whether a physical interface (the interface used by NE A to connect with NE B) is bound to the Eth-Trunk interface, and whether the Eth-Trunk interface is automatically aggregated into an LLDP packet and sends this packet to NE B.
  3. Based on the information carried in the packet received from NE A and the status of the local interface (the interface used by NE B to connect with NE A), NE B determines whether to generate an Eth-Trunk interface and whether to bind the corresponding physical interface to the Eth-Trunk interface.
  4. NE B automatically generates the Eth-Trunk interface configuration based on the calculation result.
  5. Similarly, NE A (the neighbor of NE B) performs the same operations upon receiving an LLDP packet from NE B.

Procedure

  • Configure Eth-Trunk auto-negotiation on the master device.

    • Configure Eth-Trunk auto-negotiation on the entire network.
      1. Enter the system view.
        system-view
      2. Enter the net assistant view.
        net-assistant

        By default, the net assistant view is not displayed.

      3. Enter the network view.
        network

        By default, the network view is not displayed.

      4. Configure auto-negotiation on the entire network.
        auto-link eth-trunk-mode { close | open | lock }

        By default, Eth-Trunk auto-negotiation is disabled.

        If the open parameter is specified, Eth-Trunk auto-negotiation is enabled on the entire network. If the lock parameter is specified, Eth-Trunk auto-negotiation is locked on the entire network. In this case, new physical interfaces cannot be added to an Eth-Trunk interface. If the close parameter is specified, Eth-Trunk auto-negotiation is disabled on the entire network. In this case, physical interfaces on all devices cannot be added to Eth-Trunk interfaces.

    • Configure Eth-Trunk auto-negotiation on a single member device.
      1. Enter the system view.
        system-view
      2. Enter the net assistant view.
        net-assistant

        By default, the net assistant view is not displayed.

      3. Enter the device view.
        device

        By default, the device view is not displayed.

      4. Approve the member device.
        device-granted mac-addr type type-paravalue

        By default, no device is approved.

      5. Configure Eth-Trunk auto-negotiation on the member device.
        auto-link eth-trunk-mode { close | open | lock }

        By default, the Eth-Trunk auto-negotiation mode of a member device is the same as the network-wide auto-negotiation mode.

        The Eth-Trunk auto-negotiation configuration on a member device takes precedence over the network-wide Eth-Trunk auto-negotiation configuration.

        • If the open parameter is specified, Eth-Trunk auto-negotiation is enabled on the member device. If the lock parameter is specified, Eth-Trunk auto-negotiation is locked on the member device. In this case, new physical interfaces cannot be added to an Eth-Trunk interface. If the close parameter is specified, Eth-Trunk auto-negotiation is disabled on the member device. In this case, physical interfaces on the member device cannot be added to an Eth-Trunk interface.
        • The undo auto-link eth-trunk-mode command restores the Eth-Trunk auto-negotiation mode of the member device to the network-wide auto-negotiation mode. For example, if the Eth-Trunk auto-negotiation mode of a single member device is open and the network-wide Eth-Trunk auto-negotiation mode is lock, the Eth-Trunk auto-negotiation mode of the single member device changes to lock after the command is executed.

  • Configure Eth-Trunk auto-negotiation on an NE. In this mode, you need to log in to each NE for configuration. An NE can function as the master device or a member device.

    1. Enter the system view.
      system-view
    2. Configure Eth-Trunk auto-negotiation on the device.
      auto-link aggregation  { open | lock }

      By default, Eth-Trunk auto-negotiation is disabled.

      • If the open parameter is specified, Eth-Trunk auto-negotiation is enabled on a single NE. If the lock parameter is specified, Eth-Trunk auto-negotiation is disabled on the current NE. New physical interfaces cannot be added to an Eth-Trunk interface.
      • After the negotiation is successful, the auto-link aggregation command configuration is automatically generated in the Eth-Trunk interface view, indicating that the Eth-Trunk interface configuration is generated through auto-negotiation rather than manual configuration.
