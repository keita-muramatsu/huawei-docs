Configuring the Rate Mode of an Interface

Context

To improve the application scenarios of devices, some devices support multiple rate modes for optical interfaces. You can switch the rate mode of an optical interface on the live network as required.

Only some devices support this function. The rate modes supported by different devices may be different. For details, see "Precautions" of the corresponding command.

Procedure

  1. Enter the system view.

    system-view

  2. Switch the rate mode of an optical interface.

    • Switch the rate mode of an optical interface in the system view.

      Operation

      Command

      Description

      Switch the rate mode of a 2.5GE/10GE multiplexing interface from 2.5GE to 10GE.

      port combination-mode 10GE interface { { interface-name1 | interface-type1 interface-number1 } [ to { interface-name2 | interface-type2 interface-number2 } ] } &<1-12>

      By default, the rate mode of an optical interface is not switched.
    • Switch the rate mode of an optical interface in the interface view.
      1. Enter the Ethernet interface view.
        interface interface-type interface-number
      2. Switch the rate mode of the optical interface in the interface view.

        Operation

        Command

        Description

        Switch the rate mode of the 25GE optical interface to 10GE.

        port mode 10G

        By default, the rate mode of an optical interface is not switched.
