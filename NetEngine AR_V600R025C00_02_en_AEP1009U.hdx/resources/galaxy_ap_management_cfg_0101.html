Configuring AP Certificate Expiration Warning

Context

To prevent the access and authentication of APs from being affected by the expiration of certificate files (including the CA certificate, local certificate, and CRL file), the WAC periodically sends warnings before these files expire to remind users to update the files in a timely manner until the new files are successfully replaced. By configuring AP certificate expiration warning, you can determine whether to generate warnings and set the start time and interval for the warnings as required. The supported functions and default values vary according to certificate files, as listed in the following table.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP system profile and enter its view.

    ap-system-profile name profile-name

    By default, the AP system profile default exists in the system.

  4. Configure expiration warning for CA and local certificates.

    1. Configure the pre-expiration warning period for CA and local certificates.
      pki set certificate expire-prewarning day

      By default, the pre-expiration warning period for CA and local certificates is 90 days.

    2. Configure the pre-expiration and post-expiration warning interval for CA and local certificates.
      pki set certificate warning-period hour

      By default, the pre-expiration and post-expiration warning interval for CA and local certificates is 24 hours.

  5. Configure the expiration warning function for CRL files.
    1. (Optional) Enable the expiration warning function for CRL files.

      undo pki set crl warning disable

      By default, the expiration warning function for CRL files is enabled.

    2. Configure the expiration warning interval for CRL files.

      pki set crl warning-period hour

      By default, the expiration warning interval for CRL files is 24 hours.

  6. Return to the WLAN view.

    quit

  7. Enter the AP view or AP group view.
    • Enter the AP group view.
      ap-group name group-name
    • Enter the AP view.
      ap-id ap-id
  8. Bind the AP system profile to an AP group or a single AP.

    ap-system-profile profile-name

    By default, the AP system profile default is bound to an AP group, but no AP system profile is bound to an AP.
