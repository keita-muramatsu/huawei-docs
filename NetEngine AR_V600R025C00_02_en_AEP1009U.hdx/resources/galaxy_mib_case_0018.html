Querying the Serial Number

Description of MIB Objects

You can use entPhysicalSerialNum in entPhysicalTable to obtain the serial numbers of all components.

Object

OID

entPhysicalName

1.3.6.1.2.1.47.1.1.1.1.7

entPhysicalSerialNum

1.3.6.1.2.1.47.1.1.1.1.11

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.
  2. Perform the Walk operation on entPhysicalName to query the component index entPhysicalIndex. As shown in Figure 1, the obtained index is 16777217.
    Figure 1 Querying the entPhysicalIndex value through entPhysicalName

  3. Perform the Walk operation on entPhysicalSerialNum based on the entPhysicalIndex value to query the corresponding serial number. As shown in Figure 2, the serial number of the component whose entPhysicalIndex value is 16777217 is 102215255446.
    Figure 2 Querying the serial number in entPhysicalSerialNum based on the entPhysicalIndex value
