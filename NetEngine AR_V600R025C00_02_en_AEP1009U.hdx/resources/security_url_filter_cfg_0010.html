(Optional) Querying a URL Category

Context

Before configuring the control actions for URL categories, you can query the category to which URLs belong on the Huawei Intelligent Security Center.

The remote query service provides a larger number of URL categories than is available in the predefined URL category database. You can configure this service so that the device can perform remote query if users attempt to access URLs that do not match those in the local database.

Procedure

  • Query the category to which a URL belongs.

    Log in to the Huawei Intelligent Security Center (isecurity.huawei.com), and choose Security Encyclopedia > URL Category Encyclopedia. Enter a URL in the search text box and click Query to view URL category information.

  • Configure the remote URL query service.
    1. Enter the system view.

      system-view

    2. Configure country information.

      country country-code

      To use the remote URL query service, you must run this command to configure country information. If no country information is configured or such information is inconsistent with the device's actual location, the remote URL query service will be unavailable. In addition, you must ensure that the following tasks are completed:

      • The remote URL query license is activated and valid.

      • There is a reachable route between the device and Huawei security center platform (sec.huawei.com).

      • A DNS server address is configured, and the DNS server can correctly resolve the domain name sec.huawei.com.

      • A security policy has been configured to allow the traffic for sec.huawei.com to pass through the device.

    3. Configure the timeout interval for remote URL query and the action to be taken if the URL query times out.

      url-filter query timeout { time time-value | action { allow | block | alert } } *

      When the timeout interval specified by time-value expires, the device takes the specified action on packets.

Verifying the Configuration

Run the display cloud-query configuration command to check the configuration for remote URL query.
