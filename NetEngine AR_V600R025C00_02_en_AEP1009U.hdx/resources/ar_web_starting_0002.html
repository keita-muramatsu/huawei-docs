System Requirements and Precautions

Browser Requirements

The following browsers are recommended for logging in to the web system of the device:

  • Firefox 107 or later

  • Google Chrome 107 or later

  • Edge 107 or later

Precautions

  • Login to the web system is supported only by an administrator whose user level is higher than 0 or who has higher user role permissions than the guest permissions.

  • The web system of a device supports TLS1.2 and TLS1.3, which are secure SSL protocols. A browser using an insecure SSL protocol will fail to display the login page, as will a browser that is not of a supported version.

  • Ensure that JavaScript is enabled. Otherwise, the web system may fail to be properly displayed. According to the browser in use, use one of the following methods to enable JavaScript:

    • Firefox: JavaScript is enabled by default in Firefox 23.0 and later versions.

    • Google Chrome: Choose Settings > Show advanced settings > Privacy > Content settings > JavaScript and select Allow all site to run JavaScript. The configuration method varies according to the Chrome version.

    • Edge: Choose Settings > Site permissions > JavaScript and ensure that JavaScript is enabled.

  • If the web system is inaccessible after a version upgrade, clear the browser's cache.
