Loading MIB Files

This section describes how to load MIB files.

The MIB files on which the MIB files to be loaded depend must be loaded first.

The following example describes how to load MIB files using MG-SOFT MIB Browser.

Obtaining MIB Files

Log in to Huawei technical support website for enterprise users to obtain required MIB files. For details, see Downloading MIB Files.

Compiling MIB Files

  1. Run MG-SOFT MIB Browser. In the MIB Browser window, click . The MIB Compiler window is displayed.
    Figure 1 MIB Browser window
  2. Select MIB files to be compiled.
    • Click the "Compile MIB file" button to select a single MIB file.
      Figure 2 Compiling a single MIB file
    • Click the "Compile multiple MIB files" button to select multiple MIB files.
      Figure 3 Compiling MIB files in batches
  3. Compile MIB files. After the compilation is complete, click Save All in the displayed dialog box shown in Figure 4 to save the MIB files to the default path.
    Figure 4 Saving the compiled MIB files
  4. You can view the successfully compiled MIB files under MIB Modules in the MIB Browser window.
    Figure 5 Viewing successfully compiled MIB files

Loading MIB Files

  1. Select the MIB files to be loaded under MIB Modules, and then click to load them.
    Figure 6 Loading MIB files
  2. Under Loaded MIB modules, you can check whether the MIB files are successfully loaded.
    Figure 7 Viewing successfully loaded MIB files
  3. You can also view the successfully loaded MIB files under MIB tree on the Query tab page.
    Figure 8 Viewing successfully loaded MIB files
