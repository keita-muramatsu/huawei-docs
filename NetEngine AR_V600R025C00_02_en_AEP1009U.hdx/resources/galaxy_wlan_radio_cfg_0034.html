Configuring the AMC Algorithm for Radios

Prerequisites

Before configuring AMC optimization, you have completed the following task:

  • Configure AP onboarding and STA access.

Context

AMC algorithm

Radios need to adjust the AMC algorithm according to different scenarios to deliver the optimal user experience. Three AMC algorithms are available:
  • auto-balance: applies to most common wireless scenarios.
  • high-stability: applies to wireless scenarios with continuous interference.
  • high-throughput: applies to scenarios with good wireless signals and without continuous interference.

AMC optimization in high-density scenarios

In typical high-density scenarios, a large number of hidden nodes exist, which interfere in communication between APs and STAs and affect product performance. The AMC optimization function can reduce such interference and improve the AMC algorithm performance.
  • It is recommended that this function be enabled in high-density scenarios where directional antennas are used.
  • This function is not applicable to scenarios where STAs move fast between APs.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an RRM profile and enter its view.

    rrm-profile name profile-name

  4. Configure the AMC algorithm for radios.

    amc-policy { auto-balance | high-stability | high-throughput }

    By default, a radio uses the AMC algorithm auto-balance.

  5. Enable AMC optimization in high-density scenarios.

    high-density amc-optimize enable

    By default, the AMC optimization function is disabled in high-density scenarios.

    Some APs do not support AMC optimization in high-density scenarios. For details, see the description in the command reference.

  6. Return to the WLAN view.

    quit

  7. Bind the RRM profile to a radio profile.
    1. Enter the 2.4 GHz or 5 GHz radio profile view.

      radio-2g-profile name profile-name
      radio-5g-profile name profile-name

    2. Bind the RRM profile to the 2.4 GHz or 5 GHz radio profile.

      rrm-profile profile-name

    3. Return to the WLAN view.

      quit

  8. Bind the radio profile.

    For details, see Binding a Radio Profile.

Verifying the Configuration

  • Run the display rrm-profile name profile-name command to check the AMC algorithm configured for radios in an RRM profile.
  • Run the display radio-2g-profile name profile-name command to check the RRM profile bound to a 2.4 GHz radio profile.
  • Run the display radio-5g-profile name profile-name command to check the RRM profile bound to a 5 GHz radio profile.
