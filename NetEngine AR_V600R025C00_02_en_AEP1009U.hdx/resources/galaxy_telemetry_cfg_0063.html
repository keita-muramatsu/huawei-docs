Developing Code

This section only provides the code that you need to pay attention to, which is for reference only.

Except the automatically generated code, you need to develop other code by yourself.

Add the automatically generated Java code to the Java project you have created, obtain the configuration information about the subscription initiated to the device through a configuration file (for example, ConfigeData.xml). After receiving the subscription content, the device pushes the subscribed data to the collector. Parse the telemetry header data, and then parse the subsequent data according to the corresponding Java class structure based on the sensor-path field value.

  4. Register the created class with the gRPC service framework.
