(Optional) Configuring the Device to Sample MPLS Packets

Context

After NetStream is configured on an MPLS network, only the inner IP packets of MPLS packets are sampled by default. Depending on your requirements, you can configure the NetStream original flow statistics collection function to sample the following type of information about MPLS IPv4 or IPv6 packets:

  • Only inner IP packets of MPLS packets

  • Only labels of MPLS packets

  • Both inner IP packets and labels of MPLS packets

When NetStream is configured on an MPLS network, the version of exported NetStream packets must be V9, which does not need to be configured.

Procedure

  1. Enter the system view.

    system-view

  2. Configure the type of MPLS IPv4 packet information to be sampled.

    netstream mpls-aware { ip-only | label-and-ip | label-only } ip

  3. Configure the type of MPLS IPv6 packet information to be sampled.

    netstream mpls-aware { ip-only | label-and-ip | label-only } ipv6
