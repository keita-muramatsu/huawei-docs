Security Configuration Overview

According to the analysis results of historical security events, the security industry holds that O&M security and product security are both important for network security. Without unified and replicable security configuration management, system configurations will be insecure, making the system exploitable and causing severe risks.

A software version is supposed to be secure when being released. However, configurations that are secure during deployment may become insecure with the passage of time. In addition, secure configurations may be changed to insecure ones during O&M. As such, a regular baseline check needs to be performed to ensure that routine O&M complies with security baseline requirements.

O&M personnel can prioritize security maintenance items based on whether the items are mandatory or optional.

Mandatory items refer to configuration items recommended according to industry standards or specifications. Due to the higher security risks caused by improper settings of mandatory items in contrast to optional items, you are advised to configure mandatory items based on network security requirements.
