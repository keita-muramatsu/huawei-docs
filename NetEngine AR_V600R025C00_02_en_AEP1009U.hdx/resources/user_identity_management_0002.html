Overview of Identity Management

Definition

Identity management means a device (firewall) functions as an authentication point or synchronizes user authentication results from other authentication points to identify the source IP addresses of traffic as users and dynamically control network access permissions based on users.

Purpose

As shown in Figure 1, identity management is deployed on the device to identify IP addresses of network traffic as users. This provides a user-based management dimension for network behavior control and network permission assignment, implementing refined management:

  • Manage and control policies based on users.
  • View and analyze threat and traffic reports based on users to audit users' network access behaviors.
  • Solve the policy control problem caused by dynamically changed IP addresses — Respond to the changing IP addresses with the same user policy.
