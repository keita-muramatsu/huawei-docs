Configuring the Priority Trust Mode

Context

You can configure the priority trust mode to enable the device to perform mapping based on EXP values on an MPLS network.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the interface view.

    interface interface-type interface-number

  3. Configure the interface to map packets based on the mapping of EXP values.

    trust exp

    By default, the device does not trust any packet priority.

  4. Enable mapping between PHBs and EXP values for outgoing packets.

    qos phb marking exp enable

    If the DiffServ mode is uniform, the egress PE trusts EXP values of outgoing packets and needs to map PHBs to EXP values and then map EXP values to CoS values of IP packets. Therefore, you need to configure the qos phb marking exp enable command on the outbound interface of the egress PE.

    If the DiffServ mode is pipe or short pipe, the egress PE trusts the original CoS values of outgoing packets and does not need to map PHBs to EXP values. Therefore, you do not need to configure the qos phb marking exp enable command on the outbound interface of the egress PE.
