Maintaining PM

If a large number of performance statistics are collected on a device, you can run the following reset command in the performance statistics task view to clear the current or historical performance statistics.

The statistics cannot be restored after being cleared. Exercise caution when running this command.

  • Run the reset pm current-data [ instance-type instance-type-name [ measure measure-name | instance { vpn-instance-name } &<1-8> ] * ] command to clear specified PM statistics.
