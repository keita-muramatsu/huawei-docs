Overview of the WLAN Service Configuration Procedure

Overview of WLAN

A wireless local area network (WLAN) is a network that uses high-frequency (such as 2.4 GHz or 5 GHz) signals such as radio waves, lasers, and infrared rays to replace the traditional media used for transmission on a wired LAN. WLAN technology described in this document is implemented based on 802.11 standards.

802.11 was originally a wireless networking standard defined by the Institute of Electrical and Electronics Engineers (IEEE) in 1997. Through continuous amendments to the standard, the IEEE formed the 802.11 family, including 802.11, 802.11a, 802.11b, 802.11e, 802.11g, 802.11i, 802.11n (Wi-Fi 4 defined by the Wi-Fi Alliance), 802.11ac (Wi-Fi 5), 802.11ax (Wi-Fi 6), and 802.11be (Wi-Fi 7).

Wired LANs use cables or optical fibers as transmission media, which are expensive and do not support user mobility. As further emphasis was placed on network mobility, wired LANs became unable to meet user's requirements. This led to the development of WLAN, which has become the most cost-effective and convenient network access mode. WLAN technology allows users to easily access a wireless network and move around within the coverage area of the wireless network.

  • High network mobility: WLANs are easily connected, and are not limited by cable or port positions. This makes WLANs ideal for scenarios where users are often moving, such as in office buildings, airport halls, resorts, hotels, stadiums, and cafes.

  • Flexible network deployment: WLANs provide wireless network coverage in places where cables are difficult to deploy, such as subways and highways. WLANs reduce the number of required cables, offer cost-effective and easy deployment, and have high scalability.

Configuration Procedure

You can follow the procedure in Figure 1 to configure basic WLAN services.
  1. Configure Control And Provisioning of Wireless Access Points (CAPWAP).

    Before configuring CAPWAP, configure devices to obtain IP addresses to ensure network connectivity. For details, see "CAPWAP Configuration" in CLI Configuration Guide > WLAN Configuration.

  2. Configure access point (AP) onboarding.

    Configure APs to go online on a WLAN access controller (WAC) so that the WAC can manage and configure APs. For details, see "Configuring AP Onboarding" in CLI Configuration Guide > WLAN Configuration > AP Management.

  3. Configure service set identifier (SSID) management.

    An SSID is a unique identifier that identifies a WLAN. For details about the configuration, see "SSID Management Configuration" in CLI Configuration Guide > WLAN Configuration.

  4. Configure WLAN STA management.

    Configure the WAC to deliver WLAN services to Fit APs so that STAs can go online. For details, see "WLAN STA Management Configuration" in CLI Configuration Guide > WLAN Configuration.

WLAN services are deployed using profiles, allowing for different WLAN service parameter settings. For details about WLAN profiles, see Reference Relationships Between WLAN Profiles.
