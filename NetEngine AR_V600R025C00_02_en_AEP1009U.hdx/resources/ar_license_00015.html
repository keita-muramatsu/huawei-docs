Merging Licenses

Context

If a device needs to be deactivated for maintenance or other reasons, you can merge the license of the device with that of another device. This makes full use of existing license resources to maintain service capabilities.

Channel partners and end users have no permission to merge licenses. If necessary, contact Huawei technical support personnel to merge licenses.

Procedure

  1. Obtain the revocation codes of the deactivated and target devices.

    1. Run the license revoke command in the user view to make the license enter the trial state and generate a license revocation code.

    2. After the license is in trial state, run the display license revoke-ticket command to obtain the revocation code of the license.

  2. Provide the revocation codes to Huawei technical support personnel for license merging.
