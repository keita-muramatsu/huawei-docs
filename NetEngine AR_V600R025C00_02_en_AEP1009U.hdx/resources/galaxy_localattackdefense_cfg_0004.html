Default Settings for Local Attack Defense

The following tables describe the default settings for local attack defense.

Table 1 Default settings for CPU attack defense

Parameter

Default Setting

Attack defense policy

Named default, and has been applied by default

CPCAR value for each type of protocol packets

Value in the default policy, and can be obtained using the display cpu-defend configuration command

CPCAR value for all packets sent to the CPU

You can run the display cpu-defend configuration command to view the default CAR of packets sent to the CPU.

Application layer association

For details about the supported packet types, run the application-apperceive enable command.

Session CAR

For details about the supported packet types, run the session-car enable command.

By default, the session CAR function is disabled for all protocols.

Adaptive adjustment of the default CPCAR value for protocol packets

For details about the supported packet types, run the cpu-defend dynamic-adjust enable command.
