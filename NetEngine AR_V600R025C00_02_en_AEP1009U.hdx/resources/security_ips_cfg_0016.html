(Optional) Configuring Correlation Detection

Context

Some attack behaviors are complex and cannot be accurately detected based on single-packet signature matching. In this manner, you need to perform behavior correlation analysis on packets of one or more data flows to detect the attacks. For example, if login attempts frequently occur within a certain period of time, behavior correlation analysis can be used to detect brute force cracking.

To defend against such attacks, the device provides the correlation detection function. Specifically, the device sets some attack signatures as correlation signatures and collects statistics on the number of times that traffic matches the correlation signatures based on certain conditions. If the collected statistics exceed the preset threshold, the device detects the attacks.

You can run the display ips-signature pre-defined associated command to check the preset correlation signatures. Then you can run the display ips-signature ips-signature-id command to view signature details based on the specified signature ID, such as the threshold for the number of times that the signature is matched, time range for collecting statistics on the matching times, and whether the statistics collection is performed based on the source or destination address. These parameter settings can be customized as required. For details, see Modifying a Predefined Correlation Signature.

Procedure

  1. Enter the system view.

    system-view

  2. Enable the blacklist function.

    firewall blacklist enable

    Only after the blacklist function is enabled, the dynamic source/destination IP address blacklist entries generated by the correlation detection function can take effect and the device can block attack traffic based on the blacklist.

  3. Enter the IPS profile view.

    profile type ips name name

  4. Configure correlation detection.

    assoc-check enable

    By default, correlation detection is enabled.

  5. Commit the configuration in the system view.

    engine configuration commit

    The IPS profile configuration does not take effect immediately. The activation process takes a long time. You are advised to complete all the IPS profile configurations and then submit the configurations at a time.
