Example for Configuring a DHCPv4 Server in VRRP Networking

Networking Requirements

As shown in Figure 1, a host (DHCPv4 client) in an enterprise is dual-homed to DeviceA and DeviceB through DeviceC. DeviceA is the master device and functions as a DHCPv4 server to allocate IPv4 addresses to clients. If DeviceA fails, the client needs to obtain an IPv4 address through DeviceB (backup device).

Figure 1 Network diagram of configuring a DHCPv4 server in VRRP networking

In this example, interface1, interface2, interface3, and interface4 represent 10GE 0/0/1, 10GE 0/0/2, 10GE 0/0/3, and 10GE 0/0/4, respectively.


Configuration Roadmap

The configuration roadmap is as follows:
  1. Configure IPv4 addresses for interfaces on DeviceA and DeviceB, and configure Layer 2 transparent transmission on DeviceC to ensure network-layer connectivity.
  2. Configure a VRRP group on DeviceA and DeviceB. Configure a high priority for DeviceA so that it functions as the master device to allocate IPv4 addresses to clients. Configure a low priority for DeviceB so that it functions as the backup device.
  3. Configure HRP hot standby on DeviceA and DeviceB.
  4. Create interface address pools on DeviceA and DeviceB and configure attributes for the address pools.

Procedure

  1. Configure connectivity between devices.

    # Configure IPv4 addresses for interfaces on DeviceA.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] vlan batch 100
[DeviceA] interface 10GE 0/0/2
[DeviceA-10GE0/0/2] portswitch
[DeviceA-10GE0/0/2] port link-type access
[DeviceA-10GE0/0/2] port default vlan 100
[DeviceA-10GE0/0/2] quit
[DeviceA] interface vlanif 100
[DeviceA-Vlanif100] ip address 10.1.1.1 24
[DeviceA-Vlanif100] quit

    # Configure IPv4 addresses for interfaces on DeviceB.

    <HUAWEI> system-view 
[HUAWEI] sysname DeviceB
[DeviceB] vlan batch 100
[DeviceB] interface 10GE 0/0/2
[DeviceB-10GE0/0/2] portswitch
[DeviceB-10GE0/0/2] port link-type access
[DeviceB-10GE0/0/2] port default vlan 100
[DeviceB-10GE0/0/2] quit
[DeviceB] interface vlanif 100
[DeviceB-Vlanif100] ip address 10.1.1.129 24
[DeviceB-Vlanif100] quit

    # Configure Layer 2 transparent transmission on DeviceC.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceC
[DeviceC] vlan batch 100
[DeviceC] interface 10GE 0/0/1
[DeviceC-10GE0/0/1] portswitch
[DeviceC-10GE0/0/1] port link-type acess
[DeviceC-10GE0/0/1] port trunk default vlan 100
[DeviceC-10GE0/0/1] quit
[DeviceC] interface 10GE 0/0/2
[DeviceC-10GE0/0/2] portswitch
[DeviceC-10GE0/0/2] port link-type acess
[DeviceC-10GE0/0/2] port trunk default vlan 100
[DeviceC-10GE0/0/2] quit
[DeviceC] interface 10GE 0/0/3
[DeviceC-10GE0/0/3] portswitch
[DeviceC-10GE0/0/3] port link-type access
[DeviceC-10GE0/0/3] port default vlan 100
[DeviceC-10GE0/0/3] quit

  2. Configure a VRRP group.

    # Create VRRP group 1 on DeviceA, and set the priority and preemption delay of DeviceA in the VRRP group to 120 and 40s, respectively.

    [DeviceA] interface vlanif 100
[DeviceA-Vlanif100] vrrp vrid 1 virtual-ip 10.1.1.111
[DeviceA-Vlanif100] vrrp vrid 1 priority 120
[DeviceA-Vlanif100] vrrp vrid 1 preempt timer delay 40 
[DeviceA-Vlanif100] quit

    # Create VRRP group 1 on DeviceB, and retain the default priority 100 for DeviceB in the VRRP group.

    [DeviceB] interface vlanif 100
[DeviceB-Vlanif100] vrrp vrid 1 virtual-ip 10.1.1.111
[DeviceB-Vlanif100] quit

  3. Configure HRP hot standby.

    # Specify an IPv4 address for the heartbeat interface on DeviceA.

    [DeviceA] interface 10GE 0/0/4
[DeviceA-10GE0/0/4]  ip address 10.10.0.1 24
[DeviceA-10GE0/0/4]  quit

    # Specify an IPv4 address for the heartbeat interface on DeviceB.

    [DeviceB] interface 10GE 0/0/4
[DeviceB-10GE0/0/4]  ip address 10.10.0.2 24
[DeviceB-10GE0/0/4]  quit

    # Specify the heartbeat interface, configure the authentication key, and enable hot standby on DeviceA.

    [DeviceA] hrp interface 10GE 0/0/4 remote 10.10.0.2
[DeviceA] hrp authentication-key YsHsjx_202206
[DeviceA] hrp enable

    # Specify the heartbeat interface, configure the authentication key, and enable hot standby on DeviceB.

    [DeviceB] hrp interface 10GE 0/0/4 remote 10.10.0.1
[DeviceB] hrp authentication-key YsHsjx_202206
[DeviceB] hrp enable

  4. Enable the DHCPv4 server function based on the interface address pool, and configure the DHCPv4 server to track the VRRP group.

    # Enable DHCPv4, enable the DHCPv4 server function based on the interface address pool, and configure the DHCPv4 server to track the VRRP group on DeviceA.

    [DeviceA] dhcp enable
[DeviceA] dhcp server track vrrp vrid 1 interface vlanif 100
[DeviceA] interface vlanif 100
[DeviceA-Vlanif100] dhcp select interface

    # Enable DHCPv4, enable the DHCPv4 server function based on the interface address pool, and configure the DHCPv4 server to track the VRRP group on DeviceB.

    [DeviceB] dhcp enable
[DeviceB] dhcp server track vrrp vrid 1 interface vlanif 100
[DeviceB] interface vlanif 100
[DeviceB-Vlanif100] dhcp select interface
