(Optional) Configuring the Function of Filtering Out System Configurations During Query

Context

When NETCONF-based get-config, full synchronization, and incremental synchronization operations are performed on a device, system configurations that exist upon device startup cause the amount of data to be queried to be large and the efficiency of data query to be low. In this case, you can configure the function of filtering out system configurations in the query result to reduce the amount of data to be queried and improve data validity.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the NETCONF user interface view.

    netconf

  3. Configure the function of filtering out system configurations during query.

    running-config query-mode mode-value

    By default, NETCONF query results contain system configurations.

    This command must be configured before operation packets are delivered.

    After the running-config query-mode command is run to configure the function of filtering out system configurations in the query result, if the user configuration is the same as the system configuration, the system configuration is not displayed in the get-config query output.
