Example for Configuring a Script Assistant for Setting User-Defined Environment Variables to Monitor Board Status Changes

Networking Requirements

As shown in Figure 1, a user manages a device through a remote network. The user wants to detect the change in time and record a log when the board in the specified slot restarts.

Figure 1 Network diagram of monitoring board status changes and recording logs

Configuration Roadmap

  1. Make a Python script slot_syslog.py.

  2. Remotely manage the device, upload the Python script to DeviceA, and install the script.

  3. Configure a user-defined environment variable and specify the slot ID of the board to be monitored. You can customize environment variables to switch the board to be monitored without rewriting the Python script.

  4. Configure a Python script assistant.

Procedure

  1. Configure IP addresses and routing protocols for interfaces shown in Figure 1. For details, see Configuration Scripts.
  2. Make a Python script.

    # Make a Python script named slot_syslog.py to implement the following functions:

    • Subscribes to the board status change event to monitor whether the board restarts. If yes, a log is recorded.

    • You can specify the slot ID of the board to be monitored.

    The following is an example of the Python script:

    # -*- coding: utf-8 -*-
import ops         # Import the ops module.
import sys         # Import the sys module.
import os         # Import the os module.
# Subscription processing function
def ops_condition(_ops):
    # Obtain the value of the user-defined environment variable slotid.
    slotid, errstr = _ops.environment.get("slotid")
    # Monitor the board restart event.
    conditions = []
    con1 = {'name':'Event', 'op':'eq', 'value':'9'}
    conditions.append(con1)
    con2 = {'name':' Position', 'op':'eq', 'value': slotid}
    conditions.append(con2)
    value1, err_str1 = _ops.event.subscribe("driver", "driver", "DEVM_ENT_STATUS_CHANGE_VERBOSE", conditions)
    return 0
# Work processing function
def ops_execute(_ops):
    # Obtain the value of the user-defined environment variable slotid.
    slotid, errstr = _ops.environment.get("slotid")
    slot = "slot " + slotid
    logstring = "Slot %s has been reset." %slotid
    # Print the user log Slot x has been reset.
    status, err_log = _ops.syslog(logstring, "informational", "syslog")

  3. Upload the script file to the device and install it.

    # Configure DeviceA as the SFTP client to download the Python script from the SFTP server.

    <HUAWEI> system-view

    # Install the Python script on DeviceA.

    [DeviceA] quit
<DeviceA> ops install file slot_syslog.py

  4. Configure a user-defined environment variable.

    # Configure the user-defined environment variable slotid and specify the slot ID of the board to be monitored. You can switch the board to be monitored without rewriting the Python script.

    For example, to monitor the board in slot 2, set slotid to 2. To monitor the board in slot 3, set slotid to 3. The following uses slotid 2 as an example.

    <DeviceA> system-view
[DeviceA] ops
[DeviceA-ops] environment slotid 2

  5. Configure a Python script assistant.

    # Configure a Python script assistant and register the subscribed event in the script slot_syslog.py. Wait for the event to be triggered.

    [DeviceA-ops] script-assistant python slot_syslog.py
[DeviceA-ops] quit

Verifying the Configuration
