Configuring the Device to Output Session Logs in Binary Format

Context

The device can output logs for IPv4 NAT sessions that use the PAT or No-PAT mode to a log server.

Procedure

  1. Configure the log host.
    1. Enter the system view.

      system-view

    2. Configure the log host for receiving session logs.

      firewall log host host-id { ip-address | ipv6-address } port [ vpn-instance vpn-instance-name ] [ secondary ] [ log-type { binary | syslog } ]

      vpn-instance indicates the VPN instance to which the log host belongs. The VPN instance has been configured using the ip vpn-instance vpn-instance-name command for route isolation.

      log-type indicates the format of session logs received by the log host. When sending logs, the device can construct log packets in different formats based on log servers. If log-type is not specified, the format of logs sent to the log host is determined by the log output format configured using the firewall log session log-type command.

      When the device sends logs in binary format to SecoManager, it is recommended that port 9002 be used. When the device sends logs in syslog format to SecoManager, it is recommended that port 514 be used.

    3. Set the source IP address and port for the device to send session logs.

      firewall log source { ip-address | ipv6-address } port

    4. (Optional) Enable the log concurrent function.

      firewall log session multi-host-mode concurrent

      If multiple log hosts are configured on the device, the device sends logs to the log hosts in turn by default. To be specific, one log is sent to only one log host.

      After the log concurrent function is enabled, the device sends each log to every log host.

  2. Configure the device to output session logs in binary format.
    1. Enable the function of sending NAT session logs.

      firewall log session nat enable

    2. Enable the function of sending session aging logs.

      firewall log session aging enable

    3. Set the format of session logs to binary.

      firewall log session log-type binary
