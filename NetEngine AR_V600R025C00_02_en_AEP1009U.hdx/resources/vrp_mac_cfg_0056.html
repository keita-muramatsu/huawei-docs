Displaying and Deleting MAC Address Flapping Information

Be careful when deleting MAC address flapping information. Deleted information cannot be restored.

Table 1 Commands used to display and delete MAC address flapping information

Operation

View

Command

Display historical records about MAC address flapping.

All views

display mac-address flapping [ slot slot-id ] [ begin datetime hourtime ]

Display active MAC address flapping records.

display mac-address flapping active-table [ slot slot-id ]

Display aged MAC address flapping records.

display mac-address flapping aged-table [ slot slot-id ]

Delete all MAC address flapping records.

User view

reset mac-address flapping record [ all ]
