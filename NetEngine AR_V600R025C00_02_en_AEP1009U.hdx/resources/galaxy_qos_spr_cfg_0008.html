(Optional) Adjusting Link Quality Detection Parameters

Context

The link quality detection parameters include the interval for sending keepalive packets, interval for calculating link quality data, link connectivity detection times, and IP precedence of keepalive packets.

  • Interval for sending keepalive packets: interval at which the device periodically sends keepalive packets carrying the number of service packets and timestamp to detect link quality.
  • Interval for calculating link quality data: interval at which the device periodically calculates the delay, jitter, packet loss rate, and CMI of SD-WAN EVPN links.
  • Link connectivity detection times: number of times that an SD-WAN EVPN link is detected to determine its connectivity. When the peer end receives a keepalive packet, the SD-WAN EVPN link is in up state.
  • IP precedence of keepalive packets: IP precedence of keepalive packets in MQC scheduling, which is configured to ensure that keepalive packets can be sent to the peer end in the case of heavy traffic on the live network.

Procedure

  1. Enter the system view.

    system-view

  2. Set link quality detection parameters as required.

    Table 1 Link quality detection parameters

    Operation

    Command

    Description

    Set the interval for sending keepalive packets.

    wan-quality-analysis detect interval interval-time

    By default, keepalive packets are sent at an interval of 1000 milliseconds.

    Configure the interval for calculating link quality data.

    wan-quality-analysis calculate interval interval-time

    By default, link quality data is calculated at an interval of 5 seconds.

    Set the number of link connectivity detection times.

    wan-quality-analysis fail count detect-count

    By default, the link connectivity is detected 6 times.

    Configure the IP precedence of keepalive packets.

    wan-quality-analysis ip-precedence precedence-value

    By default, the IP precedence of keepalive packets is 7.

  3. Configure the enhanced WAN quality analysis detection function.

    wan-quality-analysis detect enhance disable
undo wan-quality-analysis detect enhance disable

    By default, the enhanced WAN quality analysis detection function is enabled.

    When packet loss occurs on a network, keepalive packets may be randomly discarded, causing link flapping. After the enhanced detection function is enabled, both keepalive packets and tunnel traffic are detected. Even if keepalive packets are discarded, link flapping does not occur. You can enable or disable this function as required.
