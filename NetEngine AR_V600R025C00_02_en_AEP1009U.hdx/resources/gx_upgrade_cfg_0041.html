Example for Configuring In-Service Installation and Uninstallation of a Patch

Networking Requirements

In-service patch installation can be performed on a device if the device performance needs to be optimized without affecting the use of the current system software and the device must work uninterruptedly for a long time.

On the network shown in Figure 1, the performance of DeviceA needs to be optimized. Huawei has provided a patch package for the customer to install.

Figure 1 Network diagram for performing in-service patch installation

Configuration Roadmap

The configuration roadmap is as follows:

  1. Upload the patch file to the storage medium of the active main control board.
  2. Load and run the patch.

Procedure

  1. Configure the device as an SFTP server. For configuration details, see Configuring a Device as an SFTP Server.
  2. Upload the new patch file to the SFTP server.

    Run the sftp 10.1.1.1 command in the CLI window of the PC to set up an SFTP connection with DeviceA, and then run the put command to upload the new patch file RPG_PNFV600R023SPH001.pat to DeviceA.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] quit

  3. After the upload is complete, run the dir command on DeviceA to view the uploaded patch file.

    <DeviceA> dir
Directory of flashcfcard:/

  Idx  Attr     Size(Byte)  Date        Time       FileName
    0  drw-              -  Apr 16 2023 13:19:58   logfile
    1  -rw-     85,925,409  Apr 16 2024 13:18:02   basicsoft.cc
    2  -rw-              4  Oct 27 2023 17:25:22   snmpnotilog.txt
    3  -rw-          6,033  Jul 16 2023 16:40:02   private-data.txt
    4  -rw-          3,275  Jul 14 2024 14:18:08   vrpcfg.zip
    5  drw-              -  Nov 14 2022 19:14:26   sysdrv 
    6  drw-     88,239,759  Jul 16 2024 19:14:26   RPG_PNFV600R023SPH001.pat

670,092 KB total (569,904 KB free)

  4. Perform in-service patch installation.

    # For devices with a single main control board:

    <DeviceA> patch load RPG_PNFV600R023SPH001.pat all run

    # For devices with dual main control boards:

    <DeviceA> copy flash:/RPG_PNFV600R023SPH001.pat RPG_PNFV600R023SPH001.pat all flash:/
<DeviceA> patch load RPG_PNFV600R023SPH001.pat all run

  5. If an exception occurs after the patch is installed, delete the patch file from the system to uninstall the patch.

    <DeviceA> patch delete all

Verifying the Configuration

# Check the status of the patch that is running on DeviceA.

<DeviceA> display patch-information
Patch Package Name    :flash:/RPG_PNFV600R023SPH001.PAT
Patch Package Version :V600R023SPH001
Patch Package State   :Running   
Patch Package Run Time:2023-11-07 11:55:01

Configuration Scripts

# For devices with a single main control board:

#
sysname DeviceA
#
patch load RPG_PNFV600R023SPH001.pat all run
patch delete all
# 
return

# For devices with dual main control boards:

#
sysname DeviceA
#
copy flash:/RPG_PNFV600R023SPH001.pat RPG_PNFV600R023SPH001.pat all flash:/
patch load RPG_PNFV600R023SPH001.pat all run
patch delete all  
#
return
