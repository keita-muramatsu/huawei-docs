Verifying the Configuration

Procedure

  • Run the display cellular interface-number modem-configuration command to check the configuration of a cellular modem.
  • Run the display cellular interface-number { all | hardware | sim | network | radio | apn } command to check information about connections on a cellular modem. This includes information about the hardware, SIM card, network, radio, and APN profile. If the signal strength is not strong, adjust the antenna position until it becomes strong.
