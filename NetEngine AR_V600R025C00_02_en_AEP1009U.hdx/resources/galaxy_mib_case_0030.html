Interface Information Query

You can query interface information through ifTable and hwTrunkIfTable.

ifTable contains entry information about each interface. Each entry provides management information applicable to a particular interface. You can query ifDescr and the corresponding index ifIndex in ifTable, and then use ifIndex to query information about the corresponding physical interface and VLANIF interface. The OID prefix of this table is 1.3.6.1.2.1.2.2.1.

hwTrunkIfTable describes trunk-related information. You can query hwTrunkIfID and the corresponding index hwTrunkIndex in hwTrunkIfTable, and then use hwTrunkIndex to query information about the corresponding trunk interface. The OID prefix of this table is 1.3.6.1.4.1.2011.5.25.41.1.3.3.1.

The description of an interface configured using the description command cannot be queried using ifTable. If LLDP is enabled on a device, you can obtain the description through lldpLocPortDesc (OID: 1.0.8802.1.1.2.1.3.7.1.4) of lldpLocPortTable in LLDP-MIB.
