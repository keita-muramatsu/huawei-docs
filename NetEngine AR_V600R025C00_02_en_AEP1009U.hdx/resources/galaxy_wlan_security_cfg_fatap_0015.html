Configuring WPA3-SAE Authentication

Context

There are two types of WPA3 authentication: WPA3-802.1X authentication (also called WPA3-Enterprise) and WPA3-SAE authentication (also called WPA3-Personal).

Similar to WPA/WPA2-PSK authentication, WPA3-SAE authentication applies to small networks (such as individual and home networks) that do not require high network security or deployment of an authentication server. However, WPA3-SAE introduces the SAE handshake protocol. Compared with WPA/WPA2-PSK authentication, WPA3-SAE can effectively defend against offline dictionary attacks and increase the difficulty of brute force cracking. In addition, the SAE handshake protocol provides forward secrecy. Even if an attacker knows the password on the network, the attacker cannot decrypt or obtain traffic, greatly improving the security of the WPA3-Personal network.

WPA3 authentication automatically enables the PMF function in mandatory mode. That is, the pmf { optional | mandatory } command configuration does not take effect in WPA3 authentication mode.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a security profile and enter its view.

    security-profile name profile-name

    By default, the security profile default exists in the system.

  4. Configure WPA3-SAE authentication in a security policy.

    security wpa3 sae pass-phrase key-value aes

    By default, no security policy is configured.

  5. (Optional) Disable key negotiation for multicast traffic.

    wpa group-key-negotiation disable

    By default, key negotiation for multicast traffic is enabled.

  6. (Optional) Enable the function of disconnecting STAs when the device does not receive the last packet from the STAs during unicast key negotiation.

    wpa unicast-key-negotiation time-out kick-sta enable

    By default, the device does not disconnect STAs when it does not receive the last packet from the STAs during unicast key negotiation.
