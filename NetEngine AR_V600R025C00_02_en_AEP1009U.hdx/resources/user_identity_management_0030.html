Maintaining Identity Management

Managing Online Users and Local Users

Table 1 Managing online users and local users

Operation

Command

Description

View information about online users.

display identity-management online-user [ verbose ] [ ipv4-range start-ipv4-address end-ipv4-address | ipv6-range start-ipv6-address end-ipv6-address | user user-name | security-group security-group-name ] all-vpn-instance

-

Force an online user out

cut online-user { user user-name [ ipv4 ipv4-address | ipv6 ipv6-address ] | ipv4 ipv4-address | ipv6 ipv6-address | all } [ unknown | sso | portal | ip-mac-bind | ssl-vpn | ]

-

Lock or unlock a local user

state { active | block }

Locked users cannot go online, but online users are not affected.

A user will be locked if they enter incorrect passwords for consecutive times.

Disable user login and logout logs

undo userlog login-out enable

Users frequently go online and offline, and a large number of logs may affect device performance.
