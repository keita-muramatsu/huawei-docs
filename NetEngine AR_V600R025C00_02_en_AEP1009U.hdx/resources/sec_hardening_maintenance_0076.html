ACL Security

Overview

An access control list (ACL) is a set of one or more rules that define packet filtering conditions, such as source addresses, destination addresses, and port numbers of packets. ACL rules are used to classify data packets, and after the rules are applied to a device, it uses the rules to permit or deny data packets. ACLs accurately identify and control packets on a network to manage network access behaviors, prevent network attacks, and improve bandwidth utilization. In this way, ACLs ensure security and QoS.

Multiple rules can be defined in each ACL. This section describes advanced ACLs.

      system-view

        acl [ number ] advance-acl-number
