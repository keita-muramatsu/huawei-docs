Configuring IPsec Tunnel Rate Limiting

Prerequisites

IPsec tunnel rate limiting takes effect only for the following IPsec types:

  • ACL-based IPsec (involving ISAKMP IPsec policies and template IPsec policies)
  • Route-based IPsec (involving IPsec profiles)

Context

When multiple IPsec tunnels are established on a branch device, traffic conflicts will occur in case of high-volume data traffic. To ensure that traffic on each IPsec tunnel can be transmitted properly, rate limit the traffic of each tunnel.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the IPsec policy view or IPsec profile view.

    # Enter the ISAKMP IPsec policy view.

    ipsec policy policy-name seq-number [ isakmp ]

    # Enter the template IPsec policy view.

    ipsec policy-template template-name seq-number

    # Enter the IPsec profile view.

    ipsec profile profile-name

  3. Configure IPsec tunnel rate limiting.

    speed-limit { inbound | outbound } speed-limit [ policy-based | sa-based ]

    By default, the rate limit for encrypted traffic on IPsec tunnels is 0, that is, rate limiting is not performed.

    If a local interface will receive high-volume traffic over an IPsec tunnel, configure the inbound rate limit to limit the incoming traffic. If the local interface will send high-volume traffic over an IPsec tunnel, configure the outbound rate limit to limit the outgoing traffic.
