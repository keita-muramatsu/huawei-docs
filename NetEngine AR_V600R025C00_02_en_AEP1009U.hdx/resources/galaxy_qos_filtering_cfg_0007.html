Example for Configuring Packet Filtering Based on Application Identification

Networking Requirements

In Figure 1, the lab of a school uses DeviceA as the gateway to connect to the Internet. The use of instant messaging software (such as QQ and MSN) is prohibited to prevent students from engaging in affairs irrelevant to learning in the lab.

Figure 1 Network diagram for configuring packet filtering based on application identification

In this example, interface 1 represents 10GE 0/0/1.


Procedure

  1. Create an application group named Instant_Messaging and add instant messaging software QQ and MSN to the application group.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] application-group name Instant_Messaging 
[DeviceA-application-group-Instant_Messaging] add application QQ_IM
[DeviceA-application-group-Instant_Messaging] add application MSN_IM
[DeviceA-application-group-Instant_Messaging] quit

  2. Configure a traffic classifier to match the application group Instant_Messaging.

    [DeviceA] traffic classifier im
[DeviceA-classifier-im] if-match app-group Instant_Messaging
[DeviceA-classifier-im] quit

  3. Configure a traffic behavior to filter identified instant messaging software packets.

    [DeviceA] traffic behavior im
[DeviceA-behavior-im] deny
[DeviceA-behavior-im] quit

  4. Configure a traffic policy and apply it to the inbound direction of an interface.

    # On DeviceA, create a traffic policy p1 and bind a traffic classifier to a traffic behavior in the traffic policy.

    [DeviceA] traffic policy im
[DeviceA-trafficpolicy-im] classifier im behavior im
[DeviceA-trafficpolicy-im] quit

    # Apply the traffic policy p1 to the inbound direction of interface 1 and enable application identification on the interface.

    [DeviceA] interface 10GE0/0/1
[DeviceA-10GE0/0/1] traffic-policy im inbound
[DeviceA-10GE0/0/1] sa enable
[DeviceA-10GE0/0/1] quit

Verifying the Configuration

# Check the traffic classifier configuration.

<DeviceA> display traffic classifier im
  Traffic Classifier Information:
    Classifier: im
      Type: OR
      Rule(s):
        if-match app-group Instant_Messaging

# Check the traffic policy configuration.

<DeviceA> display traffic policy im
  Traffic Policy Information:
    Policy: im
      Classifier: im
        Type: OR
      Behavior: im
        Deny

Configuration Scripts

DeviceA

#
sysname DeviceA
#
application-group name Instant_Messaging
 add application QQ_IM
 add application MSN_IM
#
traffic classifier im type or
 if-match app-group Instant_Messaging  
#
traffic behavior im
 deny
#
traffic policy im 
 classifier im behavior im precedence 5
#
interface 10GE0/0/1
 traffic-policy im inbound 
 sa enable
#
return
