Verifying the Configuration

Procedure

  • Run the display drop-profile [ name drop-profile-name | brief ] command to check the configuration of a WRED drop profile.
  • Run the display qos configuration interface [ { interface-type interface-number | interface-name } ] command to check all QoS configurations on an interface.
  • Run the display qos queue statistics { slot slotid | interface { interface-type interface-number | interface-name } } [ cpu ] command to check queue-based traffic statistics.
