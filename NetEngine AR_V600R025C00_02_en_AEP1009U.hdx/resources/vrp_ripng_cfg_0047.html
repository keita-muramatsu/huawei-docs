Example for Configuring Basic RIPng Functions

Networking Requirements

On the network shown in Figure 1, RIPng must be enabled on all interfaces of DeviceA, DeviceB, DeviceC, and DeviceD, and these interfaces are interconnected through RIPng.

Figure 1 Network diagram of basic RIPng function configuration

In this example, interface 1, interface 2, and interface 3 represent 10GE 0/0/1, 10GE 0/0/2, and 10GE 0/0/3, respectively.


Precautions

During the configuration, note the following:

  • RIPng takes effect on an interface only after IPv6 is enabled.
  • If a RIPng process is bound to a VPN instance, the interfaces running the RIPng process are also bound to the VPN instance.

Configuration Roadmap

The configuration roadmap is as follows:

  1. Assign an IPv6 address to each interface to ensure network connectivity.
  2. Enable RIPng and configure basic RIPng functions on each device.

Procedure

  1. Assign an IPv6 address to each interface.
  2. Configure basic RIPng functions.

    # Configure DeviceA.

    [DeviceA] ripng 1
[DeviceA-ripng-1] quit
[DeviceA] interface 10ge0/0/1
[DeviceA-10GE0/0/1] ipv6 enable
[DeviceA-10GE0/0/1] ripng 1 enable
[DeviceA-ripng-1] quit

    # Configure DeviceB.

    [DeviceB] ripng 1
[DeviceB-ripng-1] quit
[DeviceB] interface 10ge0/0/1
[DeviceB-10GE0/0/1] ipv6 enable
[DeviceB-10GE0/0/1] ripng 1 enable
[DeviceB-10GE0/0/1] quit
[DeviceB] interface 10ge0/0/2
[DeviceB-10GE0/0/2] ipv6 enable
[DeviceB-10GE0/0/2] ripng 1 enable
[DeviceB-10GE0/0/2] quit
[DeviceB] interface 10ge0/0/3
[DeviceB-10GE0/0/3] ipv6 enable
[DeviceB-10GE0/0/3] ripng 1 enable
[DeviceB-10GE0/0/3] quit

    # Configure DeviceC.

    [DeviceC] ripng 1
[DeviceC-ripng-1] quit
[DeviceC] interface 10ge0/0/2
[DeviceC-10GE0/0/2] ipv6 enable
[DeviceC-10GE0/0/2] ripng 1 enable
[DeviceC-10GE0/0/2] quit

    # Configure DeviceD.

    [DeviceD] ripng 1
[DeviceD-ripng-1] quit
[DeviceD] interface 10ge0/0/3
[DeviceD-10GE0/0/3] ipv6 enable
[DeviceD-10GE0/0/3] ripng 1 enable
[DeviceD-10GE0/0/3] quit

Verifying the Configuration

# Check neighbor relationships of DeviceA.

[DeviceA] display ripng 1 neighbor

Neighbor : FE80::A0A:201:1 10GE0/0/1
Protocol : RIPNG

The command output shows that DeviceA has established neighbor relationships with other devices on the network.

[DeviceB] display ripng 1 route

Configuration Scripts

  • DeviceA

    #
sysname DeviceA
#
interface 10GE0/0/1
 ipv6 enable
 ipv6 address 2001:db8:1::1/96
 ripng 1 enable
#
ripng 1
#
return
