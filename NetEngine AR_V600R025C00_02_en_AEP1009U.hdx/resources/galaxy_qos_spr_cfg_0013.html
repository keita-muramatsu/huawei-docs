Associating a Policy with a Link

Context

A device selects the optimal link for services based on the link quality detection result, preferentially selecting a primary link with a high priority to transmit service traffic. If no high-priority link meets service requirements, the device selects a low-priority link. A backup link is used only when no primary links can meet service requirements.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the SPR configuration view.

    smart-policy-route

  3. Enter the policy profile view.

    spr-policy node node-index

  4. Associate the policy with a link and enter the link configuration view.

    link transport-network name [ id id ]

  5. Configure the transport network as the primary or backup link.

    link-role { master | backup }

    By default, a link has no role specified, is not added to any link group, and is not involved in policy-based traffic steering.

  6. Configure the link priority.

    link-priority priority-value

    By default, the priority of a link is 8.

  7. (Optional) Return to the policy profile view.

    quit

  8. (Optional) Enable the fixed transport network function in the policy.

    transport-network-fixed enable

    By default, the fixed transport network function is disabled in a policy.

    After the fixed transport network function is enabled in a policy, the traffic matching the policy can be transmitted only on the transport network configured in the policy. If the transport network has no connection or all connections on the transport network are down, the traffic matching the policy is discarded.

  9. (Optional) Return to the SPR configuration view.

    quit

  10. (Optional) Configure the path selection mode.

    path-selection-mode { symmetric | asymmetric }

    By default, the path selection mode is asymmetric.

    When the symmetric path selection mode is configured, the slave device is forced to use the traffic steering result of the master device so that the forward and return paths of traffic are consistent. When the asymmetric mode is configured, the slave device is not forced to use the traffic steering result of the master device.
