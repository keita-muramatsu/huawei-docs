(Optional) Configuring the Function to Save DHCPv6 Data

Context

When the device functions as a DHCPv6 or DHCPv6 PD server, you can enable the device to save DHCPv6 data. This avoids data loss caused by device faults. After this function is enabled, the device periodically saves address lease and address conflict information to the dhcpv6.txt file. After the device restarts due to a fault, it automatically restores DHCPv6 data from the dhcpv6.txt file.

Procedure

  1. Enter the system view.

    system-view

  2. Configure the function to save DHCPv6 data.

    dhcpv6 server database [ enable | write-delay interval ]

    By default, the function to save DHCPv6 data is disabled.

    You can specify write-delay to modify the interval at which DHCPv6 data is saved. By default, a device saves DHCPv6 data every 86400 seconds.

Result

Run the display dhcpv6 server database command to check the configuration of the DHCPv6 server's binding table database.
