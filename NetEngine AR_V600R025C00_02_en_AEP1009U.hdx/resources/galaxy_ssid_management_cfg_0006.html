Configuring an SSID Profile

Context

You can customize an SSID name and set other parameters in an SSID profile. For details, see "Configuring an SSID Profile" in WLAN STA Management Configuration > Configuring Basic WLAN STA Access Functions. The configuration in an SSID profile can take effect only after the profile is bound to a VAP profile.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an SSID profile and enter its view.

    ssid-profile name profile-name

  4. Configure the SSID name.

    ssid ssid

  5. (Optional) Set the maximum number of STAs that can be associated with a single VAP.

    max-sta-number max-sta-number

    By default, a maximum of 64 STAs can be associated with a single VAP.

  6. (Optional) Disable automatic SSID hiding when the number of access STAs on a VAP reaches the maximum.

    reach-max-sta hide-ssid disable

    By default, when the number of access STAs reaches the maximum, automatic SSID hiding is enabled and the function of replacing low-priority STAs with high-priority STAs is disabled.

  7. (Optional) Configure the radio type in the SSID profile.

    radio-type { dot11a | dot11b | dot11g | dot11n | dot11ac | dot11ax | dot11be }

    By default, the radio type in an SSID profile is dot11be.

    When the radio type is configured in both an SSID profile and a radio profile, the radio type configured in the SSID profile preferentially takes effect. However, if this radio type is not supported by the radio profile, the radio type configured in the radio profile takes effect. If the radio type is configured as dot11ac, the 2.4 GHz radio automatically operates in dot11n mode.

    Additionally, if the configured radio type is not supported by an AP, the actual radio type supported by the AP takes effect.

  8. (Optional) Disable the Unscheduled Automatic Power Save Delivery (U-APSD) function.

    u-apsd disable

    By default, the U-APSD function is enabled.

    Disable this function if some STAs on the network do not support it.

  9. (Optional) Reduce radio resource consumption in high-density scenarios.

    In high-density scenarios, a large number of Probe Response frames occupy excessive wireless resources. To reduce the consumption of wireless resources, do the following:

    1. Enable APs to deny broadcast Probe Request frames.
      deny-broadcast-probe enable

      By default, an AP responds to broadcast Probe Request frames.

    2. Configure the number of times Probe Response frames are retransmitted.
      probe-response-retry retry-time

      By default, the number of times Probe Response frames are retransmitted is 1.

  10. (Optional) Enable the target wake time (TWT) function.

    twt enable

    By default, the TWT function is disabled.

  11. (Optional) Enable the function of notifying STAs of AP load information.

    qbss-load enable

    By default, the function of notifying STAs of AP load information is disabled.

  12. (Optional) Disable the 802.11k protocol.

    dot11k disable

    By default, the 802.11k protocol is enabled.

    Some outdated STAs on the network may not support the 802.11k protocol. In this case, perform this step to disable the 802.11k function.

  13. (Optional) Disable the 802.11v BSS transition function.

    dot11v bss-transition disable

    By default, the 802.11v BSS transition function is enabled.

    Some outdated STAs on the network may not support 802.11v BSS transition. In this case, perform this step to disable the 802.11v BSS transition function.

  14. Return to the WLAN view.

    quit

  15. Create a VAP profile and enter its view.

    vap-profile name profile-name

  16. Bind the SSID profile to the VAP profile.

    ssid-profile profile-name

Verifying the Configuration

  • Run the display vap-profile { all | name profile-name } command to check the configuration and reference information about a VAP profile.
  • Run the display references vap-profile name profile-name command to check reference information about a VAP profile.
  • Run the display ssid-profile { all | name profile-name } command to check the configuration and reference information about an SSID profile.
  • Run the display references ssid-profile name profile-name command to check reference information about an SSID profile.

Follow-up Procedure

Bind the VAP profile so that the configuration in the SSID profile bound to the VAP profile can take effect. For details about how to bind a VAP profile, see "Binding a VAP Profile" in WLAN STA Management Configuration > Configuring Basic WLAN STA Access Functions.
