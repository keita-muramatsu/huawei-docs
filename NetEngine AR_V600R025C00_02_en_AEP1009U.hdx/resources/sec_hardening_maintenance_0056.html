Hot Standby Security

Overview

In hot standby networking, two devices synchronize entry information. Backup packets contain service information, which attackers may intercept, tamper with, or replay. To ensure the security of the two devices, you are advised to take the following security hardening measures:

  • Connect the heartbeat interfaces of the two devices directly.
  • Configure an authentication key that meets security requirements for HRP packets.
  • Enable validity check for HRP packets.
  • Enable encryption for HRP packets.

Impact on the System

Two devices with inconsistent security hardening configurations cannot form a hot standby group.

Procedure

  1. Configure an authentication key for HRP packets.

    system-view
hrp authentication-key key

    For security purposes, the key must contain at least two of the following: uppercase letters (A to Z), lowercase letters (a to z), digits (0 to 9), and special characters (such as !, @, #, $, and %).

  2. Optional: Enable validity check for HRP packets.

    hrp checksum enable

  3. Optional: Enable encryption for HRP packets.

    hrp encryption enable

Verifying the Security Hardening Result

Run the display hrp state verbose command in any view to check the hot standby status.
