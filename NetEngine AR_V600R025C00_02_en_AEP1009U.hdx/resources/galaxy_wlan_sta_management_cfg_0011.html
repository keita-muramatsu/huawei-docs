Configuring Network Connectivity

Context

Network connectivity between network devices allows STAs to obtain IP addresses and access the network.

Service packet exchange ensures proper transmission of service packets between STAs and the upper-layer network. Management packet exchange allows APs to transmit service packets of STAs and management packets to the WAC. For the process of AP onboarding on a WAC, see "AP Onboarding Process" in CLI Configuration Guide > WLAN Configuration > AP Management.

Procedure

  1. Configure management packet exchange.

    Management packets between the WAC and APs are transmitted only on the network between them. To ensure proper management packet exchange, you only need to configure correct VLANs or routes.

    The PVID for the network device port directly connected to an AP must be set to the same as the management VLAN of the AP.

  2. Configure service packet exchange.

    Configure APs to communicate with the upper-layer network through service VLANs.

  3. (Optional) Configure STAs to communicate with a DHCP server.

    STAs can be configured with static IP addresses or obtain IP addresses from a DHCP server. When STAs are configured to obtain IP addresses from a DHCP server, configure network connectivity between STAs and the DHCP server.

    Android STAs cannot obtain stateful IPv6 addresses from a DHCPv6 server. Instead, they automatically generate stateless IPv6 addresses through router advertisement (RA). If the WAC functions as a DHCPv6 server or DHCPv6 relay agent for STAs, run the ipv6 nd ra halt disable command to enable the function of sending RA messages.
