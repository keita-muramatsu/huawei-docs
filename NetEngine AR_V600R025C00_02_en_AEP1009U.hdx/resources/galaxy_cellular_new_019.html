Configuring SIM Card Security Management

Context

A SIM card stores a user's identity information and a key. These are used to verify the user identity and encrypt communication. To ensure SIM card security, a carrier provides two types of security codes: personal identification number (PIN) and PIN unblocking key (PUK). SIM card security management needs to be configured on a cellular interface.

  • A PIN consists of four to eight digits and helps secure a SIM card. After PIN authentication is enabled, a user must enter the correct PIN to use the SIM card. If the wrong PIN is entered three times in a row, the SIM card is locked.
  • A PUK consists of eight digits and unlocks a locked SIM card. After a SIM card is locked, a user must enter the correct PUK to unlock the SIM card. If the wrong PUK is entered 10 times in a row, the SIM card is locked permanently. In this case, you need to replace the SIM card.

    Before configuring SIM card security management, you need to configure basic cellular functions and ensure the device can connect to a carrier network through a cellular channel interface.

Procedure

  • Enable PIN authentication.

    To prevent unauthorized use of a SIM card, you are advised to enable PIN authentication. Then, only users who enter the correct PIN can use the SIM card. If PIN authentication is disabled, anyone can use the SIM card.

    1. Enter the system view.

      system-view

    2. Enter the cellular interface view.

      interface cellular interface-number

    3. Enable PIN authentication.

      sim-card lock

      By default, PIN authentication is disabled.

      In this step, you need to enter the correct PIN to enable PIN authentication.

  • Authenticate a PIN.

    After PIN authentication is enabled, the device authenticates the PIN each time the SIM card is started.

    1. Enter the system view.

      system-view

    2. Enter the cellular interface view.

      interface cellular interface-number

    3. Verify the PIN.

      pin verify

      Wait a little while after the PIN is entered. When the message "The PIN is verified successfully." is displayed, the PIN has been verified.

  • Change a PIN.

    For security purposes, you are advised to change the PIN periodically.

    1. Enter the system view.

      system-view

    2. Enter the cellular interface view.

      interface cellular interface-number

    3. Change a PIN.

      pin modify

      Enter the old PIN once and enter a new PIN twice. When the message "The PIN is changed successfully." is displayed, the PIN has been changed.

  • Use a PUK to unlock a SIM card.
    1. Enter the system view.

      system-view

    2. Enter the cellular interface view.

      interface cellular interface-number

    3. Use the PUK to unlock the SIM card and reset the PIN.

      pin unlock

      Enter the PUK and enter a new PIN twice. When the message "Warning: PIN will be unlocked and changed. Continue? [Y/N]:" is displayed, enter Y. When the message "The PIN is unlocked and changed successfully." is displayed, the SIM card has been unlocked.

Verifying the Configuration

  • Run the display cellular interface-number { all | hardware | sim | network | radio | apn } command and check the PIN authentication status based on the PIN Status field.
