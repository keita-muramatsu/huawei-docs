N:1 Mirroring Specifications

N:1 mirroring copies packets from N mirrored sources to one observing port. The number of mirrored sources is not limited.

Table 1 Meaning of N in different mirroring modes

Mirroring Mode

Meaning of N

Port mirroring

Number of mirrored ports

VLAN mirroring

Number of VLANs

Flow mirroring

Number of packet flows
