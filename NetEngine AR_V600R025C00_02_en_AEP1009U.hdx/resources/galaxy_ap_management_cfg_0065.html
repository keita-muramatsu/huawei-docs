Configuring PoE Power-On and Power-Off Management

Context

PoE power-on and power-off management includes the following functions:

  • Setting power-on and power-off time ranges

    PDs connected to an interface do not always keep working. You can set the power-off time range of a PoE interface so that it can automatically power off when becoming idle, thereby saving energy.

  • Configuring compatibility with non-standard PDs

    When a non-standard PD is connected to an AP, the AP cannot detect the proper resistance and therefore cannot identify the PD. You can enable the compatibility check function to enable the AP to detect the PDs incompliant with IEEE 802.3af or 802.3at and then provide power for these PDs.

  • Setting a PoE standard

    The AP that supports IEEE 802.3at provides a maximum power of 30 W, and the AP that supports IEEE 802.3af provides a maximum power of 15.4 W. The former provides higher current than the latter when they power on PDs. Some non-standard PDs cannot be powered on in high current. To power on these PDs, configure the AP to provide power with low current in conformance to IEEE 802.3af.

  • Configuring forcible PoE power supply

    After this function is configured, an interface forcibly powers on the connected PD even if the PSE cannot identify the PD. Before powering on the interface, ensure that the system power is sufficient.

Procedure

  1. Enter the system view.

    system-view

  2. Optional: Configure a time range if you need to configure a power-off time range for a PoE interface.

    time-range time-name [ { time1 to time2 { days } &<1-7> | from time1 date1 [ to time2 date2 ] } ]

    By default, no time range is configured.

  3. Enter the WLAN view.

    wlan

  4. Configure PoE power-on and power-off management. You can configure one or more of the following functions as required:
    • Set the power-off time range of the PoE interface.
      port-link-profile name profile-name
poe power-off time-range time-range-name

      By default, no PoE power-off time range is configured on an interface.

    • Configure compatibility with non-standard PDs in the AP wired port link profile view.
      port-link-profile name profile-name
poe legacy enable
quit

      By default, the PD compatibility check function is disabled on an AP.

    • Enable forcible PoE power supply on AP interfaces in the AP wired port link profile view.
      port-link-profile name profile-name
poe force-power
quit

      By default, forcible PoE power supply is disabled on AP interfaces.

    • Set the PoE power supply standard of APs to IEEE 802.3af in the AP system profile view.
      ap-system-profile name profile-name
poe af-inrush enable
quit

      By default, an AP provides PoE power in compliance with IEEE 802.3at.

      After running the poe af-inrush enable command, remove the non-IEEE 802.3at PDs and then install them so that the PDs can be powered on.
