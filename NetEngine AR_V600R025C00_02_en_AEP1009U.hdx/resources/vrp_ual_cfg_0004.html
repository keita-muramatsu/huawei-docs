Master Role Election

After NEs are powered on, the NE having the master capability can be elected as the master device. The master device uses the UAL protocol to implement automated network management.

Election Rules

  • If a device can be configured as the master device using the corresponding command, the device has the master capability. This manual configuration has the highest priority and does not trigger preemption.
  • Before the master device is elected, devices having the master capability periodically send broadcast query packets. The packets carry the isSupportmaster, deviceLevel, devicePriority, and deviceMac fields, which are used to compare the election priorities of devices. A device that receives the broadcast query packet compares its capability and priority. If the device has a higher priority, it responds in unicast mode; if the device has a lower priority, it does not respond. As long as the device sending the broadcast packet does not receive any unicast response packet from other devices with a higher priority, it is elected as the master device, and its master role is persistent. After the device restarts, it still functions as the master device and does not change its role. After the master role is persistent, if a device newly added to the network is specified as the master device, a conflict is detected through CoAP election and a message is displayed, indicating that the redundant master device needs to be deleted.

  • If the master device is faulty, you need to either manually re-specify the master role within 24 hours or wait for the device to restart and be set as the master device. After 24 hours, the master device will be re-elected.

Using a Virtual IP Address to Log in to the Master Device

  1. After the master device is elected, the Virtual-MEth0 interface is dynamically created, and a virtual IP address (10.231.10.253) is assigned to the interface.
  2. When a user PC connects to an NE, an HTTPS request is initiated. Only the master device detects the request and reports it to WebMaster.
  3. You can use this virtual IP address to access WebMaster from any location. You can set a virtual IP address as required.
