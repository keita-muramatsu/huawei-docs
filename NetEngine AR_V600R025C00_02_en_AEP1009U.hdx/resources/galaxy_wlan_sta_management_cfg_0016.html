Configuring a Security Profile

Context

A WLAN security policy can be used to authenticate STAs and encrypt STAs' packets, securing both the WLAN and STAs. After a WLAN security policy is configured in a security profile, the security profile needs to be bound to a VAP profile so that the security policy can take effect. In this manner, STAs are allowed to access the WLAN through an SSID only after they are successfully authenticated based on the security policy configured in the VAP. Note that each VAP profile can have only one security profile bound. You can create multiple security profiles to achieve differentiated security policies and bind the profiles to different VAPs as required.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a security profile and enter its view.

    security-profile name profile-name

    By default, the security profile default exists in the system. No security policy is configured in the security profile default. To ensure successful WLAN access, you must configure a security policy in the security profile.

  4. Configure a security policy. For details, see "Configuring a Security Policy" in CLI Configuration Guide > WLAN Configuration > WLAN Security Configuration.

  5. Create a VAP profile view and enter its view.

    vap-profile name profile-name

  6. Bind the security profile to the VAP profile.

    security-profile profile-name

    By default, the security profile default is bound to a VAP profile.
