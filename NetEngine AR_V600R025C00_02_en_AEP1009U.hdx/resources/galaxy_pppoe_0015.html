Maintaining PPPoE

Context

To disconnect users or trigger re-negotiation, reset PPPoE sessions on either the PPPoE server or client.

Resetting all PPPoE sessions will delete all online PPPoE users. Resetting PPPoE sessions on a specified dialer interface will delete only PPPoE users who dial up through the dialer interface.

Procedure

  1. Reset PPPoE sessions on the PPPoE client in the user view.

    reset pppoe-client session { all | dialer number }

    By default, PPPoE sessions are permanently online. When PPPoE sessions are terminated, the device automatically re-establishes PPPoE sessions after 16 seconds.
