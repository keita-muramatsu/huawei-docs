Overview of AD

The Active Directory (AD) server is a type of Lightweight Directory Access Protocol (LDAP) server software running on the Windows operating system. The AD server stores the user information of the operating system for authentication and authorization when users log in to the operating system. AD does not support accounting. Compared with LDAP, AD integrates Kerberos into the LDAP authentication process and uses the symmetric key mechanism of Kerberos to improve password transmission security and prevent user passwords from being disclosed during LDAP authentication.

Kerberos is a network authentication protocol that securely transmits data on an open network using a cipher key system. It does not require that all devices on a network be secure and assumes that all data may be read and modified during transmission. Kerberos runs over UDP/TCP and uses port 88. It adopts the client/server structure and allows the client and server to authenticate each other. In addition, Kerberos can prevent attacks as well as ensure data integrity.

AD Structure

Figure 1 shows a typical network consisting of user, AD client, and AD server.

Figure 1 AD networking diagram
  • AD client: an access device integrating Kerberos and LDAP.
  • AD server: a server integrating Kerberos and LDAP authentication. An AD server is a combination of an LDAP server and a Kerberos server.
    • LDAP server: stores all directory information.
    • Key Distribution Center (KDC): Kerberos server, which stores all password and account information of clients. The KDC consists of AS and TGS.
      • Authentication Server (AS): provides the tickets used to access TGS.
      • Ticket-Granting Server (TGS): provides the tickets used to access the AD server.
