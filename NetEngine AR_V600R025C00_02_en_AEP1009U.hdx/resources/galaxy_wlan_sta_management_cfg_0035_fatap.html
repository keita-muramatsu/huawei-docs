Configuring the Function of Logging STA Association and Onboarding Information

Context

After the function of logging STA association and onboarding information is enabled, the device records STA association or onboarding information in logs so that the administrator can easily view STA association or onboarding information.

Enabling this function will generate a large number of logs. If there are a large number of STAs, log files may overwrite each other due to limited storage space, which affects fault locating. If this function is necessary, it is recommended that a log server be configured to receive reported logs.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. (Optional) Enable the WAC to report STA traffic and duration when a STA is connected to an AP.

    report-sta-info enable

    By default, the WAC is disabled from reporting information about STA traffic statistics and online duration on APs.

  4. Enable the function of logging STA association and onboarding information.

    report-sta-assoc enable

    By default, the function of logging STA association and onboarding information is disabled.
