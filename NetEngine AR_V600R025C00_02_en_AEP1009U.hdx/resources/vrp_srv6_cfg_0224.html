Configuring an SRv6 Path MTU Value

Context

For packets forwarded over an SRv6 path, they will be discarded if the packet length is greater than the outbound interface MTU, and the forwarding efficiency will be reduced if fragments are too small. In this case, you can configure an SRv6 path MTU value on the ingress of the SRv6 path to ensure successful packet forwarding.

Procedure

  • Configure a path MTU value for SRv6 BE.
    1. Enter the system view.

      system-view

    2. Enable SRv6 and enter its view.

      segment-routing ipv6

    3. Configure a global path MTU value for SRv6 BE.

      path-mtu mtu-value

    4. (Optional) Configure a reserved value for the global path MTU value.

      path-mtu reserved reserved-value

      The global path MTU value minus the reserved value is the active path MTU value, which must be greater than or equal to 1280 bytes. The ingress sends packets using the smaller value of either the active path MTU value or the IPv6 MTU value of the involved physical interface.

  • Configure a path MTU value for an SRv6 TE Policy.
    1. Enter the system view.

      system-view

    2. Enable SRv6 and enter its view.

      segment-routing ipv6

    3. Configure a global path MTU value for an SRv6 TE Policy.

      path-mtu mtu-value

    4. (Optional) Configure a reserved value for the global path MTU value.

      path-mtu reserved reserved-value

      The global path MTU value minus the reserved value is the active path MTU value, which must be greater than or equal to 1280 bytes. The headend sends packets using the smaller value of either the active path MTU value or the IPv6 MTU value of the involved physical interface.

    5. (Optional) Configure a path MTU value for a segment list.

      A path MTU value configured for a segment list overrides the global path MTU value.

      1. Create an SRv6 TE Policy and enter its view.
        srv6-te policy name-value endpoint endpoint-ip color color-value
      2. Enter the candidate path view of the SRv6 TE Policy.
        candidate-path preference pref-value
      3. Configure a path MTU value for a segment list.
        segment-list list-name path-mtu mtu-value
