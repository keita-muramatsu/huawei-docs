When the northbound API function is enabled, you are not advised to log in to the device through the web UI or CLI to configure the device. Otherwise, the northbound API user and you may deliver configurations at the same time, causing inconsistency between configurations on the northbound API controller and those on the device.

You are advised to use the following browsers to log in to the device web page:

Firefox: 107 or later

Chrome: 107 or later

Edge: 107 or later

The web UI of a device supports TLS1.2 and TLS1.3, which are secure SSL protocols. A browser using an insecure SSL protocol will fail to display the login page, as will a browser that is not of a supported version.

1. If the web page cannot be accessed after the device software version is upgraded, clear the historical cache data of the browser.

2. When the web addresses of different devices are translated into the same IP address but different ports through NAT, you are advised to use different browsers to access the web addresses at the same time to avoid conflicts because the cookies of the same IP address are shared.

JavaScript must be enabled. Otherwise, GUI display problems may occur. The location for setting JavaScript varies according to browsers:

Firefox: JavaScript is enabled by default in Firefox 23.0 and later versions.

Chrome browser: Choose Settings > Show advanced settings > Privacy > Content Settings > JavaScript. Ensure that Allow all sites to run JavaScript (recommended) is selected. The configuration method varies according to the version.

Edge browser: Choose Settings > Site permissions > JavaScript and ensure that JavaScript is allowed.
