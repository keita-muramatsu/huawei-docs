Feature Requirements

Table 2 Feature requirements

Feature

Feature Requirements

SRv6 TE Policy

When the SRH contains only one SID and the reduce mode is configured in SRv6 TI-LFA FRR scenarios, the forward no-bypass function is restricted.

SRv6 TE Policy

When the SRH contains only one SID and the reduce mode is configured in SRv6 TI-LFA FRR scenarios, the BFD no-bypass function is restricted.

SRv6 TE Policy

When the SRH contains only one SID and the reduce mode is configured in SRv6 midpoint protection scenarios, the BFD no-bypass function is restricted.

SRv6 TE Policy

When the SRH contains only one SID and the reduce mode is configured in SRv6 midpoint protection scenarios, the forward no-bypass function is restricted.

SRv6 BE

VPN FRR does not support interface-based fast switching. Only BFD for locator or fast BGP route update can be used for fast switching.
