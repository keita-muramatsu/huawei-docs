Restrictions on sending dying gasp alarms

1. Only SNMPv1 and SNMPv2 are supported, and only one SNMP NMS address is supported. If multiple addresses are configured, the device randomly sends packets to one of the NMSs.

2. Dying gasp packets can be sent only in basic IPv4 forwarding mode.

3. When multiple physical interfaces are reachable to the SNMP NMS, the SNMP NMS may receive multiple packets.

4. The length of the SNMP packet template cannot exceed 158 bytes. You can run the display snmp-agent diagnose trap dyinggasp command to query the packet template length.

SNMP service

When the SNMP get-next/get-bulk operation is performed to query data in the cache, the default aging period is 5 seconds. Although the data in the cache may have been deleted from the database or APP or encounters a value change during the aging period, SNMP cannot detect this situation and still returns the data in the cache to the NMS.

SNMP service

The port number and authentication parameters configured on the NMS must be the same as those on the device, and the SNMP version used on the NMS must be enabled on the device; otherwise, the NMS cannot manage the device.

SNMP service

If the NMS frequently accesses a device (for example, the access frequency set on the NMS is high or multiple NMSs access the device), the CPU usage may increase and the device may respond slowly to the NMS. In this case, you can reduce the access frequency of the NMS to ensure that the device can respond to the SNMP packets sent by the NMS in a timely manner.

SNMP Security

When the number of nodes in the SNMP IP address locking list exceeds 512, the device stops processing SNMP packets.

SNMP Security

For security purposes, you are advised not to use any weak security algorithm or protocol provided by this feature. By default, the device provides the weak security algorithm or protocol feature package WEAKEA. If it is indeed necessary, run the install feature-software WEAKEA command to install the weak security algorithm or protocol feature package WEAKEA.
