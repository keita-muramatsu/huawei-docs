Feature Requirements

Table 2 Feature requirements

Feature

Feature Requirements

NTP

The NTP protocol version of the device ranges from V1 to V4.

NTP

1. Clients with IPv6 link-local addresses cannot be configured.

2. Dynamic sessions with IPv6 link-local addresses cannot be created.

NTP Basics

1. The existing configuration will not be deleted when the NTP service is disabled.

2. A device supports a maximum of 256 multicast servers, peers, and unicast servers, 1024 NTP authentication keys, and 1024 multicast clients. However, only a maximum of 256 multicast clients can take effect simultaneously.

3. A device running NTP supports a maximum of 256 concurrent sessions, including static and dynamic sessions.

4. NTP supports timestamp synchronization within the range of 2000/1/1 to 2036/2/8. Otherwise, packets are discarded.

NTP Basics

For security purposes, you are advised not to use weak security algorithms provided by this feature.

By default, the device provides the weak security algorithm feature package WEAKEA. If it is required, run the install feature-software WEAKEA command to install the weak security algorithm feature package WEAKEA.

NTP high-precision soft clock

In high-precision mode, the client communicates with the server. However, in broadcast mode, the server periodically broadcasts the clock of the local node, which is unidirectional communication. Therefore, high precision is not supported in multicast or broadcast mode.
