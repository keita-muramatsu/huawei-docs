The commands used to query information about interfaces, such as the display interface command, do not display offline interfaces.

Basic Interface Functions

Statistics about Layer 3 sub-interfaces, VLANIF interfaces, and tunnel interfaces obtained using a MIB file and collected using a command are not isolated. Therefore, if you run the reset interface counters and reset interface counters if-mib commands to clear statistics, all statistics obtained using a MIB file and collected using a command are cleared.

Basic Interface Functions

The interface fixed index function depends on the device.sys file. When data in the device.sys file is deleted, the interface index may not remain unchanged after the device restarts.

Basic Interface Functions

openconfig-vlan.yang has the following when condition: when "current()/oc-if:config/oc-if:type = 'ianaift:l3ipvlan'". This YANG file supports VLANIF and VBDIF interfaces. The types of VLANIF and VBDIF interfaces are respectively ianaift:propVirtual and ianaift:other, which can be queried using openconfig-vlan.yang. This does not meet the when condition.

Traffic Statistics Collection

For the AR8700-8:

During an active/standby switchover, the interface traffic and rate change abruptly.

The traffic volume decreases and the rate increases after an active/standby MPU switchover.

IP address unnumbered

The function to allow a Layer 3 interface to borrow the IPv4 address of a loopback interface:

1. After a Layer 3 interface borrows the IPv4 address of a loopback interface, remote routes can be learned using only IGP or BGP based on IGP.

2. After a Layer 3 interface borrows the IPv4 address of a loopback interface, ARP learning, direct routes, BGP based on direct routes, and lower-layer traffic forwarding are not supported. In this case, the outbound interface of the next hop cannot be determined because the same IP address corresponds to multiple outbound interfaces.
