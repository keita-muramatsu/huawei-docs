Configuration Precautions for Signature Database Update

Licensing Requirements

The update service of the IPS signature database is controlled by the IPS license control item. If the license control items are not activated, the device does not support the preset signature database, and cannot manually load or update the signature database. In this case, only the IPS function based on user-defined signatures is available. After the license control items are activated, you can load and update the signature database. After the license control items expire, the signature database cannot be manually loaded or upgraded. The intrusion prevention function is available, but the signature database may not be up-to-date, and the intrusion detection and defense capabilities are limited.

The update service of the antivirus signature database is controlled by the antivirus license control item. If the license control item is not activated, the signature database cannot be manually loaded or updated. After the license control item is activated, you can load and update the signature database. After the license control item expires, the signature database cannot be manually loaded or upgraded. The antivirus function is available, but the signature database may not be up-to-date. As a result, the virus detection and defense capabilities are limited.

The update service of the SA signature database is not under license control.

The update service of the geolocation database is not under license control.

Feature Requirements

Table 2 Feature requirements

Feature

Feature Requirements

Update Mode

If you run the update force online, update force local, update force restore sdb-default, or update force rollback command to forcibly update or roll back the signature database, the engine does not take effect in a short period of time and all engine-related session tables are reset, causing service interruption. Therefore, exercise caution when running such commands.

Update Mode

The source IP address of online update request packets (update host source) cannot be a loopback address.

Update Mode

Signature database update does not support IPv6. That is, the update server address cannot be an IPv6 address.

Update Mode

Before updating the signature database, ensure that the available memory space of the device meets the update memory space requirements. For details, see "Preparations for Signature Database Update" in Configuration Guide > System Management Configuration > Signature Database Update Configuration. If the available memory space does not meet the update memory space requirements, the signature database may fail to be updated and the ASE may restart.

Update Mode

If the scheduled update time is not configured, the device randomly selects a time point from 00:00 to 07:59 as the scheduled update time every day by default. You can select the scheduled update time based on your network conditions, but ensure that the update does not take up the network resources of normal services.
