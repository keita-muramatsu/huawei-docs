Feature Requirements

Table 2 Feature requirements

Feature

Feature Requirements

DHCPv4 Relay

The DHCP packets between the DHCP server and the DHCP client cannot be relayed for more than 16 times. Otherwise, the DHCP packets are discarded.

DHCPv4 Relay

All servers in a DHCP server group must be in the same VPN instance.

DHCPv4 Server

When configuring the range of IP addresses that can be dynamically allocated in the global address pool, ensure that the IP address range is on the same network segment as the IP address of the DHCP server interface or DHCP relay interface. Otherwise, incorrect IP addresses may be allocated.

DHCPv4 Server

Address conflict detection uses the ping address mode and needs to wait for the ping response packet. The timeout period is configurable. If the timeout period is not 0, the address allocation time increases, affecting the user login and logout rates.

DHCPv4 Server

The DHCPv4 server function can be used in VRRP master/backup scenarios but not in VRRP load balancing scenarios. When configuring the DHCPv4 server function in a VRRP master/backup scenario, ensure that the master and backup devices have the same address pool configuration and synchronized clocks. Otherwise, issues may occur during data backup.

Y

DHCPv4 common

Some or all DHCPv4 and DHCPv6 packets will be sent to the CPU globally, including request, reply, and Layer 3 unicast packets. After DHCP is enabled, DHCP packets are sent to the CPU. The DHCP component determines that the packets do not need to be processed and then forwards them through software.

DHCPv4 common

The DHCP function cannot be configured on Eth-Trunk member interfaces.

DHCPv4 common

When DHCPv4 and DHCPv6 users go online and offline at the same time, the total rate cannot exceed the DHCPv4 or DHCPv6 rate specification.
