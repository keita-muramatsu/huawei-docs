Basic Radio Parameters

For the AR5710-S8T1XWE-NRGL, AR5710-S8T1XWE:

For APs running R024C00 or later, the function of enabling radios to send packets at the maximum power takes effect only on the 2.4 GHz and 5 GHz radios, but not on 6 GHz radios.

Radio calibration

1. Number of active users and collection duration

For an AP without an independent scanning radio: 6 users active for 8 hours per day, data collection for 7 days

For an AP with an independent scanning radio: 1 user active for 8 hours every day, data collection for 1 day

STAs in the power saving state are considered inactive.

2. After the WAC is restarted or an active/standby switchover is performed, data needs to be collected again.

Radio Scanning

The scanning duration of an independent radio is fixed at 200 ms, regardless of the scanning interval or duration configured in the air scan profile. By default, an independent radio cyclically scans all channels supported by the country code of an AP. The scanning duration for each channel is 200 ms.

Basic Radio Parameters (802.11ax)

The 6 GHz frequency band supports only the HE mode, but not the HT or VHT mode.

Basic Radio Parameters (802.11ax)

The 6 GHz frequency band supports only OWE and WPA3 encryption modes, and MAC, Portal, and 802.1X authentication modes; but does not support open, OWE transition mode, WAPI, WPA, WEP, or WPA2.

CoSR Multi-AP Co-channel Scheduling (iCSSR)

1. Coordinated scheduling for 802.11a/b/g STAs is not supported.

2. To use iCSSR, ensure that APs are ceiling-mounted.

3. For co-channel APs, the concurrent coordination gain of iCSSR is affected by the reference signal received power (RSRP). When dynamic-zoom antennas work in directional mode and the RSRP of a co-channel neighboring AP is greater than –70 dBm, the concurrent coordination gain decreases as the RSRP increases. As such, you are advised to properly plan AP positions. For details, see Scenario-based WLAN Planning Design (80 MHz Continuous Networking).

4. For example, when the country code of China is configured, 80 MHz continuous networking is supported only across V600 APs with dynamic-zoom antennas. For details, see Scenario-based WLAN Planning Design (80 MHz Continuous Networking).

Spectrum Analysis

The number of non-Wi-Fi devices of the same type cannot be identified.

Spectrum Analysis

Some low-duty-cycle interference devices can be identified only when the interference persists. For example, if a Bluetooth mouse is used to perform click operations, the duty cycle of Bluetooth signals over the air interface is low. As a result, there is a low probability that the Bluetooth mouse can be scanned and identified by the AP. If a mobile phone is used to transmit audio and video data through Bluetooth, it can be easily scanned and identified.

Spectrum Analysis

1. This function depends on neighbor scanning. If the WDS or Mesh service is configured on a radio, the spectrum analysis function does not take effect on the radio. If the radio supports independent radio scanning, the spectrum analysis function on the radio is not affected.

2. Spectrum analysis can identify only the types of interference sources but not all device types.

3. Currently, the device can identify the following types of non-Wi-Fi devices: Bluetooth devices, microwave ovens, 2.4 GHz cordless phone sets and bases, Zigbee devices, game controllers, 2.4 GHz/5 GHz wireless video and audio devices, baby monitors, and fixed-band devices. Due to spectrum differences, some non-Wi-Fi devices may be not identified.

MIMO

If nodes on a Mesh network are fixed and distant from each other, enable the beamforming function to increase the demodulation SNR of Mesh links. Mobile nodes may cause a low demodulation SNR of Mesh links in Mesh scenarios. Therefore, it is recommended that the beamforming function be disabled.

To use the MU-MIMO function, enable the beamforming function.
