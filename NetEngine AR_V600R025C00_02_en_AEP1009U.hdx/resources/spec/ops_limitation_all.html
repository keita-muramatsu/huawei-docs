OPS protocol

RESTful API requests and responses can use only the ASCII character set. If a request or response contains non-ASCII characters, the request or response may fail to be parsed.

OPS protocol

1. URI: /restconf/operations/huawei-pkgm-moi:install-extended-system-software. Function: This API is used to install the on-board firmware and is invoked by the internal package management process.

2. URI: /restconf/operations/huawei-pkgm-moi:check-card-register-status. Function: This API is used to check the registration status of the on-board firmware and is invoked by the internal package management process.

3. URI: /restconf/operations/huawei-pkgm-moi:clear-ineffective-cch. Function: This API is used to maintain the on-board firmware and is invoked by the internal software management process.

4. URI: /restconf/operations/huawei-pkgm-moi:feature-package-record-rollback. Function: This API is used to record feature package rollback and is invoked by the internal software management process.

OPS basics

1. When the memory usage of the active main control board exceeds 80%, new Python scripts cannot be executed.

2. Running Python scripts are not stopped due to high memory usage.

3. This limitation does not apply to Python script assistants pre-installed by vendors.

OPS basics

For the AR8000 series, AR6700 series, AR5710-S52T2XE4, AR5710-H8T2TS1-T, AR5710-S8T2X-LTE4EA, AR5710-S8T2X, AR5710-H2T4PN2X-NRGL, AR5710-S8P2X, AR5710-H4T4N2X, AR5710-S10T1X2, AR5710-S8TWDSE-LTE4EA, AR5710-H4T4N2X-LTE4EA, AR5710-H8T2TS1, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8T1XWE-NRGL, AR5710-S8T2XE-LTE4EA-T, AR5710-H2T4N2X-NRGL, AR5710-S8T1XWE, AR5710-S8T2XE:

1. When the memory usage of the main control board exceeds 80%, new Python scripts cannot be executed.

2. Running Python scripts are not stopped due to high memory usage.

3. This limitation does not apply to Python script assistants pre-installed by vendors.

OPS service

1. Assistants are classified into command assistants and Python script assistants. A maximum of 100 command assistants and Python script assistants can be configured.

2. A single script assistant can be configured with one to eight conditions. If multiple conditions are configured, the conditions can be combined using the AND, OR, or NOT logic. A single command assistant can be configured with only one condition.

3. If the number of conditions subscribed to by all maintenance assistants (including preset maintenance assistants) exceeds 200, new maintenance assistants cannot be created.

4. The same subscribed event in a maximum of 10 Python scripts can be matched simultaneously.

5. A maximum of 100 script variables are allowed on the device.

6. Due to the startup time sequence of the distributed system, the OPS maintenance assistant may execute events in the startup phase. If high reliability is required for events in the startup phase, you are advised to use the Python script assistant to check the device status in the subscription phase for smooth recovery, or reconfigure the command assistant in R023C00 or later.

OPS service

Command assistant specifications: The command assistant supports the execution of a maximum of 10 associated commands. These commands are configured in the user view by default, but can also be configured in other views as required.

OPS service

The size of a single file to be installed cannot exceed 1 MB.

OPS service

The maximum number of script environment variables is 1000, including a maximum of 100 user-defined variables.
