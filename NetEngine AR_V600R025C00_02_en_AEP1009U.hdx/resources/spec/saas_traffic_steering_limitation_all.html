SaaS application intelligent traffic steering

HTTPS detection occupies the processing performance of the device. Therefore, it is recommended that the maximum number of detection instances be less than 8.

SaaS application intelligent traffic steering

When a proxy is used to access SaaS applications (no DNS process), most traffic cannot be identified because the destination address and port are those of the proxy server. As a result, SaaS application traffic steering is not supported. To prevent this, do not transmit SaaS application traffic through the proxy process.

SaaS application intelligent traffic steering

Huawei provides two application signature databases: SA_H30071000 and SA_H30071002. The SA_H30071000 signature database contains more than 6000 applications, and the SA_H30071002 signature database contains more than 500 applications. The preconfigured SaaS application signature database requires that devices support the capability of the SA_H30071000 signature database. Devices that support only the capability of the SA_H30071002 signature database can perform traffic steering based on user-defined applications (including domain names and IP addresses).

SaaS application intelligent traffic steering

The SaaS traffic steering policy does not take effect for encrypted DNS traffic. Currently, the encrypted DNS packets include the DNS packets encrypted by the Chrome browser (for example, Google free DNS server: 8.8.8.8), and the DNS packets encrypted by the iOS system when some applications use the free DNS server provided by Apple.
