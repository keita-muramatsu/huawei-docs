Feature Requirements

Table 2 Feature requirements

Feature

Feature Requirements

Basic NQA Functions

In ping and trace tests, IPv6 SIDs support only unicast addresses.

Basic NQA Functions

If a static route is associated with NQA and the path tested by NQA depends on the static route, association between static routes and NQA can be used only in direct connection scenarios.

Basic NQA Functions

For the ping/tracert ipv6-sid function, if the outbound interface of the End.OP SID does not have an IPv6 global address, the source address carried in the detection packet sent by the local end may be an unreachable IPv6 address. As a result, the test fails, but service traffic forwarding is not affected. You are advised to specify -a to initiate a test.

Basic NQA Functions

The tracert lsp command is used to detect an LSP tunnel. Inter-AS P nodes are not supported. If timeout is displayed in the command output on an inter-AS P node, the tracert test skips the inter-AS P node and continues to detect the egress.

Basic NQA Functions

The server and client of an ICMP jitter, UDP jitter, or TCP test instance must be Huawei devices.

Basic NQA Functions

Whether an ICMP jitter, UDP jitter, or TCP test is successful depends on the board hardware capability of the device.

Basic NQA Functions

In a scenario where FRR is configured on the headend of an SRv6 TE Policy, ping/trace cannot be performed on the SRv6 TE Policy during FRR switching.

Basic NQA Functions

1. A third-party responder does not send response packets carrying payload that contains Huawei proprietary extended information. In this scenario, the delay and jitter of ICMP jitter single-ended detection are large in inter-board scenarios.

2. A third-party responder does not support ICMP timestamp packets (standard non-private packets). ICMP timestamp packets are parsed as ICMP echo packets. In this scenario, ICMP jitter single-ended detection supports only two-way delay measurement but does not support one-way delay measurement.

Basic NQA Functions

1. IPv6 addresses can only be set to global addresses but not link-local addresses.

2. The ICMP jitter IPv6 instance supports echo packets and does not support timestamp packets.

Basic NQA Functions

In enhanced BSID scenarios, when a BSID is associated with multiple Policies in 1:N mode, SRv6 ping/tracert is not supported.

Basic NQA Functions

In IPv4/IPv6 over SRv6 for public and private network scenarios, if no address is configured for the outbound interface and the management interface address is selected as the source address of ping packets, ping or tracert operations may fail due to the isolation between the management, control, and user planes.

Basic NQA Functions

The start now command configuration may be lost during the configuration rollback of an NQA test instance. In this case, the start now command needs to be delivered again.

NQA Tests

If a URL is configured as the destination address of a TCP test instance and a source address is configured, the source address is not used when the device queries the DNS server for the destination address through the URL. The source address is used only in TCP connection setup detection.

NQA Tests

In an ICMP/TCP/HTTP test instance, after the record out-interface command is run, the outbound interface and SD-WAN site information needs to be displayed. A maximum of 256 outbound interfaces can be displayed and reported to the controller.

LSP PingTracert

Tests in inter-AS LDP LSP scenarios are not supported.
