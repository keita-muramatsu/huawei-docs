For the AR5710-S52T2XE4, AR5710-S28T2S2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2XE-NRGL:

An IPv4 over IPv6 tunnel supports only the one-dimension distributed tunnel interface, rather than the three-dimension centralized tunnel interface.

If you repeat the following steps to configure an IPv4 over IPv6 tunnel, duplicate tunnels with the same source and same destination may be created. In this case, only one tunnel is available, affecting services that depend on other tunnels.

1. Configure the source IPv6 address of the tunnel and then the source interface of the tunnel. Ensure that the source IPv6 address is configured on the source interface.

2. Configure the source interface of the tunnel and then the source IPv6 address of the tunnel. Ensure that the source IPv6 address is configured on the source interface.

3. Set the destination of the tunnel to a domain name.

IPv4 over IPv6 tunnels do not support tunnel nesting.
