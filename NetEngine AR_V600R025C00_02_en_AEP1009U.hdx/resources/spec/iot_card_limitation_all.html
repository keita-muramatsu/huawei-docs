Feature

Feature Requirements

IoT Card

Constraints on cards connected to APs running V600

APs running V600 support only one PCIe IoT card of the Ethernet type (large card, occupying two card slots).

Constraints on cards connected to APs running V200

In terms of interconnection with an AP running V200:

- In the two IoT cards, there can be only one card of the serial type.

The following card combinations are supported:

PCIe card (Ethernet) x 1 (large card, occupying two card slots) + USB card (Ethernet)

PCIe card (Ethernet) x 1 (large card, occupying two card slots) + USB card (serial)

PCIe card (serial) x 1 + USB card (Ethernet)

The following card combinations are not supported:

PCIe card (serial) x 1 + USB card (serial)

PCIe card (serial) (small card) x 2

PCIe card (serial) (small card) x 3

- Ensure that the operating frequency bands of two IoT cards do not interfere with each other.

IoT Card

The Bluetooth serial port function becomes unavailable after the Bluetooth working mode is switched to IoT.

IoT Card

Only one container image can be loaded to an AP. Therefore, only one card can be configured as the container type. When multiple cards are configured as the container type, the first installed card can be used as the container card in ascending order of card IDs.

IoT Card

When two cards of the serial type are installed, the Bluetooth serial port is unavailable.

In terms of interconnection with an AP running V200:
