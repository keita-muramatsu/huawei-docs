Feature Requirements

Table 2 Feature requirements

Feature

Feature Requirements

ASPF4

ASPF/ALG does not take effect for TCP fragments

ASPF4

The device applies only to the ASPF/ALG of the RFC and GB28181 SIP protocols, but does not apply to the ASPF/ALG of other SIP protocols such as SIP-I and SIP-T.

ASPF4

Disable the ASPF/ALG function of a specific protocol when it is not in use. For example, the SIP protocol usually corresponds to heavy service traffic. Enabling the ASPF/ALG function may cause performance deterioration. The performance deterioration proportion is related to the service traffic.

ASPF4

ASPF/ALG can process only IPv4 packets.

ASPF4

ASPF/ALG of SIP takes effect only for UDP-based SIP traffic.

ASPF4

For SIP, if NAT is required for mutual access between communication parties in three or more zones, ASPF/ALG does not take effect.

ASPF4

The ASPF and ALG functions use the same configuration. If either of them is enabled, the other takes effect at the same time.

ASPF4

For UDP fragmented packets, ASPF/ALG does not take effect for protocols other than SIP.

NAT44 ALG

If other NAT traversal devices exist on the SIP/H.323 network, the ALG function for the SIP/H.323 protocol does not need to be enabled on the device. Otherwise, services may be interrupted.

NAT44 ALG

The DNS ALG PTR reverse query function can query only the ALGs of the Answers resource type. ALGs of other resource types cannot be queried.

NAT44 ALG

For the DNS protocol, the ALG function takes effect only when server mapping is configured. In addition, when the server resides on the intranet and the client resides on the extranet, the no-reverse parameter cannot be configured for NAT Server. Otherwise, the ALG function does not take effect.

NAT44 ALG

When ALG and source NAT are used together and the ALG function is configured for multi-channel protocols such as FTP, you are advised not to specify service matching conditions in the source NAT policy. Otherwise, communication may fail. The port information of the data channel is dynamically negotiated. If a service is specified in the source NAT policy, data packets may fail to match the source NAT policy. As a result, communication fails.

NAT44 ALG

In RFC 2326 of RTSP, avoid using IP addresses in URLs. ALG cannot be performed on IP addresses in RTSP URLs.

NAT44 ALG

If source NAT and NAT Server are configured for the SIP client and server, the two SIP clients cannot call each other.

NAT44 ALG

DNS ALG supports only UDP.
