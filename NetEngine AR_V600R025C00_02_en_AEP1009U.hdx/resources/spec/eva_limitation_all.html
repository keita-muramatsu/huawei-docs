Feature Requirements

Feature Requirements

Unified fault management

1. By default, all fault modes are enabled.

2. When the fault mode is disabled, the fault status that is not recovered is not updated. After the fault mode is enabled again, new fault data is recorded based on the newly received data.

3. After the device is started, if the modified system time is earlier than the original system time, no fault data is generated for the alarms generated between the modified system time and the original system time.

Historical KPI management

During an active/standby switchover, new historical KPI data will be collected. In this case, the historical KPI data queried is empty.

Script function

1. Each EVA script contains a maximum of one get function. The execution of the get function is equivalent to that of the netconf get operation. For an XPath, if data cannot be obtained using the netconf get operation, data cannot be obtained using the get function in an EVA script either.

2. In all registered EVA scripts, a maximum of 500 get or exe operations can be performed at the same time.

3. The maximum size of the data obtained using the get operation is 12 KB. The data that exceeds 12 KB is not stored or displayed.

Script function

A maximum of one layer of EVA scripts can be invoked in nested mode. That is, the scripts that are invoked in nested mode cannot be nested, and cyclic invoking is not supported.

Script function

The exe function defined in an EVA script supports only the manual-switch action in huawei-redundancy-protocol.

Script function

For the AR8000 series, AR6710-H4T4X2Y7, AR5710-H8T2TS1, AR5710-H8T2TS1-T, AR5710-H4T4N2X, AR5710-H4T4N2X-LTE4EA, AR5710-H2T4N2X-NRGL, AR5710-H2T4PN2X-NRGL, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L14T2X4, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8T2XE-NRGL, AR5710-S8P2XE-NRGL, AR5710-S8T1XWE, AR5710-S8T1XWE-NRGL, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8TWDSE-LTE4EA:

When customized EVA scripts are used to subscribe to internal KPI data, data of only one KPI can be obtained on a per-port basis.

All scripts can subscribe to data of only one component whose ID is 10102 or 10024 at a time.

Script function

The OPS function needs to enabled for EVA.

Script function

1. The number of registered EVA scripts cannot exceed 100.

2. The number of events in all EVA scripts cannot exceed 100.

3. If both the number of registered scripts and the number of events do not exceed the specifications, a multi-event script can be registered with a maximum of 104 events.

4. Built-in scripts occupy specifications.

Script function

1. In the function for delivering commands or NETCONF actions used in JSON scripts, ensure that the command view parameters, CLI parameters, and xPath parameters in the function are correct.

2. When the eva.cliArray(view, cmdArray) function is used in a script, the cmdArray parameter must be referenced by a variable. An instance of a character string array cannot be directly written.

3. The input parameters of a function are written as follows:

(1) Parameters of the integer type: Only numeric constants and variables of the referenced integer type are supported. Object member variables of the integer type (in the ${object.member} format) cannot be referenced.

(2) Parameters of the string type: The string constants, variables of the referenced string type, and object member variables of the referenced string type (that is, ${object.member} format, excluding the eva.strcat function) are supported.

(3) Parameters of the array type: Only variables of the array type can be referenced. Array constants or object member variables of the referenced array type (in the ${object.member} format) are not supported.

4. When the calculation result of the eva.sum() function exceeds the upper limit of integer variables, the unsigned integer overflow processing mode of the C language is used.

5. When the eva.strcat(str1, str2) function is used in a script, the returned result of the function starts with the content of the first parameter str1 and contains a maximum of 2048 bytes.

Script function

The regular expression in the JSON script uses the POSIX syntax.

If the regular expression is written using the POSIX syntax in the user script, EVA uses the POSIX regular expression for matching.

If another syntax is used to write a regular expression, EVA attempts to translate the regular expression for matching. In this case, the filtering result cannot be guaranteed and the accuracy of the translated regular expression cannot be guaranteed.

The rules for EVA to obtain the matching information is as follows:

1. The matching information is stored as a character string array.

2. All results based on the overall matching of the regular expression can be obtained.

3. If the regular expression contains partial matching information, the matching results based on the overall matching are grouped. The first element in each group is the overall matching result, and the matching sequence is from outside to inside and from left to right. Each group stores a maximum of the first 10 matching results as members of the character string array.

Script function

The timeout period for executing the following commands with large command output is 60 minutes, and the timeout period for executing other commands is 10 minutes.

The command lines with large command output are as follows:

display diagnostic-information: This command can be followed by other parameters, excluding filtering conditions (such as include).

display current-configuration: This command can be followed by other parameters, excluding filtering conditions (such as include).

display vlan: This command cannot be followed by other parameters.

display interface: This command cannot be followed by other parameters.

Script function

The script name contains 2 to 31 case-sensitive characters. It starts with a letter and contains only letters, digits, and underscores (_). For a script file that contains a single script, the script name must be the same as the file name.

Script function

1. A maximum of 200 device patches and user-defined scripts can be registered at the same time.

2. Only one script is allowed in the device patch or user-defined JSON script file.

3. In the inspection scenario, only one inspection script file can be registered at a time, and one inspection script file can contain a maximum of 1000 scripts.

4. Before the inspection script is executed, it cannot be registered again.

5. A maximum of five events can be defined in each script.

6. The device patch script cannot be uninstalled.

Script function

The logs that trigger events in a JSON script are non-trap event logs.

Script function

This event is mutually exclusive with other types of events and cannot be written together with other types of events. Events in a PMI script can be triggered only once.

Script function

The interval for periodically triggering an event is an integer in the range from 1 to 65535, in hours. Only one timer can be defined in a script.

Script function

The time window of a multi-event combination strategy in a JSON script is 60 seconds.

Script function

1. If a function is used in the jump condition, the function must be on the left of the operator and is limited to the following functions:

(1) eva.strContains(str1, str2)

(2) eva.strContainsIgnoreCase(str1, str2)

(3) eva.strEquals(str1, str2)

(4) eva.strEqualsIgnoreCase(str1, str2)

(5) eva.arrayCount(array)

2. For bool comparison, the right side of the operator must be true or false. Variables or functions cannot be referenced.

Script function

The object to be traversed must be an array. The subscript variable must be used together with the traversed array. A maximum of three layers of loops can be configured. The execution scope includes the task where the loop is located and all its lower-level tasks.

Script function

The name of the first task in a script must be mainTask. You can customize the task name. The customized task name contains 2 to 16 case-sensitive characters. It starts with a letter, contains only letters, digits, and underscores (_), and cannot be mainTask. A maximum of 15 tasks can be created.

Script function

The variable name is a string of 2 to 16 case-sensitive characters. It starts with a letter and contains only letters, digits, and underscores (_). The name of each variable must be unique in scripts and cannot be result. The variable type can be bool, number, string, string array, number array, or object.

1. The variable of the number type must be 64 bits and neither decimals nor negative numbers are supported.

2. The variable of the string type can contain a maximum of 256 English characters. (If Chinese characters are used, each Chinese character occupies three English characters.)

3. The number of members in a numeric array ranges from 1 to 80.

4. A string array contains a maximum of 1600 English characters. The number of array members is not limited. The maximum length of a single member is the same as the variable of the string type.

5. One layer of objects is supported. Variables in an object must be strings. The number of member objects ranges from 1 to 5. Other variables cannot be referenced.

6. Object arrays are not supported.

7. Other variables cannot be referenced as the value of a global variable.

8. The result variable ${result} of the action can be used only in publish.

9. The variable value must comply with the Jansson character set (JSON library of the C language).

10. A maximum of 15 global variables can be defined. A maximum of five variables can be defined for local variables in a task and variables released in a task.

Script function

When the get function is used to obtain data of huawei-eca.yang, the operation will time out if the size of the returned content exceeds the message capacity of NETCONF rpc-reply.
