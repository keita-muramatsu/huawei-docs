Feature Requirements

Extended TLVs cannot be applied to LLDP on management interfaces.

In a multi-neighbor scenario, an interface can learn a maximum of 256 LLDP neighbors. In a multi-neighbor scenario, ensure that the number of LLDP neighbor relationships established on an interface does not exceed 256. When the number of neighbors reaches the maximum limit, the received neighbor information is discarded and no neighbor relationship is established.

The same character encoding format must be configured for two devices interconnected through LLDP. When the YANG NMS queries LLDP neighbors, a hyphen (-) is displayed if the character string is not in the UTF-8 format.

When the dot1dBasePort value of a main interface in the BRIDGE-MIB exceeds 4096, the LLDP-MIB cannot query or operate the interface beyond the range.

The involved entries include lldpPortConfigTable, lldpStatsTxPortTable, lldpStatsRxPortTable, lldpLocPortTable, and lldpRemTable.

You can run the display mib-index interface command to query PortIndex and the interface name. PortIndex is the value of dot1dBasePort in the BRIDGE-MIB.
