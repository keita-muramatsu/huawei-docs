Feature Requirements

Log sending

When the log outbound interface is an Eth-Trunk interface, all log traffic is transmitted on the same member interface. Packet loss may occur due to insufficient bandwidth.

You are advised to run the load-balance round-robin command to configure per-packet load balancing on the log outbound interface (Eth-Trunk interface).

Log sending

The log server does not support packet fragment assembling for service logs. As a result, the log server may fail to receive logs. It is recommended that the MTU value of network devices on the link for transmitting logs be greater than 1500.

Session log

Enabling the session log function affects device performance. Therefore, configure this function as required.
