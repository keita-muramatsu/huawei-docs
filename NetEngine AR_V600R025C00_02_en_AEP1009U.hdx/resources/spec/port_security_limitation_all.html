Feature Requirements

In a port security MAC address migration scenario, when port A learns a dynamic secure MAC address and traffic with this MAC address as the source MAC address enters port B, the traffic continuously matches this MAC address. As a result, the dynamic secure MAC address learned on port A cannot be aged out.

When a port receives packets with the system MAC address as the destination MAC address, the system does not check whether port security is enabled on the port or whether the number of secure MAC addresses learned by the port has reached the upper limit.
