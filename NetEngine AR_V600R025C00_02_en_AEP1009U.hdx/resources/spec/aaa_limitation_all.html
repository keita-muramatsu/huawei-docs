General AAA functions

1. The device sends TACACS accounting packets to report the commands that have been executed by administrators through SSH, Telnet, or the web system. Therefore, a TACACS accounting server needs to be configured on the device.

2. The device can use TACACS authorization packets to authorize administrators who log in through SSH or Telnet to run commands related to the HWTACACS server. On the web system, the commands that can be executed can be controlled only based on the administrator privilege level, and HWTACACS server authorization cannot be performed.

Authentication Management

Limitations on AD/LDAP authentication:

1. AD/LDAP authentication supports only the PAP mode. This is because the AD/LDAP server stores passwords in irreversible encryption mode and cannot restore the cleartext password to verify the hash value in CHAP packets. If the CHAP mode is used, configure the AD/LDAP server to store passwords in reversible encryption mode so that cleartext passwords can be restored. (This operation is risky and not recommended.)

2. When LDAP authentication is used, cleartext passwords are transmitted in LDAP bind messages. When AD authentication is used, cleartext passwords are not transmitted in LDAP bind messages, and SASL binding (similar to TLS tunnels) is used.
