Device Management

The sampling path for low-speed sampling of physical entity information is huawei-devm:devm/physical-entitys/physical-entity.

If there are a large number of ports, the actual sampling duration may exceed the minimum sampling period. You are advised to adjust the sampling period as follows:

If the number of ports is greater than 100, you are advised to set the sampling period to 60 seconds.

If the number of ports is greater than 200, you are advised to set the sampling period to 90 seconds.

If the number of ports is greater than 400, you are advised to set the sampling period to 120 seconds.

If the number of ports is greater than 500, you are advised to set the sampling period to 180 seconds.

Electromechanical Management

For the AR8700-8:

For details, see the card specifications.

1. When running the device voltage threshold command to configure a voltage threshold for a board, ensure that the current voltage does not exceed the configured voltage threshold. Otherwise, the board may be powered off due to overvoltage or undervoltage.

2. If the board is powered off due to overvoltage or undervoltage after an incorrect voltage threshold is configured, run the device voltage threshold command to cancel the voltage threshold configuration and then manually power on the board.

3. During configuration restoration, the system does not verify slot, threshold, and other information when the device voltage threshold command is run, and directly generates configuration records in the buildrun.
