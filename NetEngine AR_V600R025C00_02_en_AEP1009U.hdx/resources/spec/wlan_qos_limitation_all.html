Feature Requirements

EDCA

For the AR5710-S8T1XWE-NRGL, AR5710-S8T1XWE:

802.11be, 802.11ax, 802.11ac, and 802.11n STAs must support WMM. If the WMM function is disabled, 802.11be, 802.11ax, 802.11ac and 802.11n cannot work and STAs can access the network only in 802.11a/b/g mode.

If the WMM function is disabled, the function of denying access of non-HT STAs becomes invalid.

MLO scheduling

Only fixed radio combinations are available to form an MLD, and MLO concurrency is supported.

1. The AirEngine 8776-X7ET-T supports MLD only between radios 0 and 1.

2. The AirEngine 8776-X7F-T supports MLD only between radios 0, 2, and 4 and between radios 1 and 3.

3. The AirEngine 8776-X7T-T supports MLD only between radios 0 and 1.

4. The AirEngine 8776-X6THP supports MLD only between radios 0 and 1.

5. The AirEngine 8776I-X6FHP-T supports MLD only between radios 0 and 1.

6. The AirEngine 8776I-X6ETHP-T supports MLD only between radios 0 and 1.

Traffic Control

A maximum of eight ACL rules can be configured for packet filtering in the same direction. The rules take effect following the configuration sequence. To change the packet filtering sequence, delete all related configurations and reconfigure ACL-based packet filtering.

Traffic Control

The multicast-to-unicast conversion function depends on IGMP snooping. Before configuring multicast-to-unicast conversion, enable IGMP snooping.
