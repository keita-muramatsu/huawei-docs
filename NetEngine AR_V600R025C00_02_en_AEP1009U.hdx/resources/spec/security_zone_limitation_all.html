Feature Requirements

A user-defined security zone that has been allocated to a policy cannot be deleted. However, you can change the priority of the zone and add or delete bound interfaces. When a security zone is deleted, all configurations of the security zone are deleted.

Predefined security zones cannot be deleted, and their priorities cannot be reconfigured or cleared.

Different security zones cannot be configured with the same name or priority.

You cannot modify any configuration of the Local zone, including adding interfaces to the Local zone.

For the AR8000 series, AR6700 series, AR5710-H8T2TS1-T, AR5710-H4T4N2X, AR5710-H2T4PN2X-NRGL, AR5710-H4T4N2X-LTE4EA, AR5710-H8T2TS1, AR5710-H2T4N2X-NRGL:

After a user-defined security zone is deleted, the security zone configuration on an interface added to the zone will be cleared, which means the interface is not assigned to any security zone.
