Feature Requirements

Table 2 Feature requirements

Feature

Feature Requirements

Certificate application and management

Before applying for a certificate, check whether the clock on the device is correct. The device checks whether the current time is within the validity period of the certificate. If the certificate is beyond the valid range, the certificate registration fails.

Certificate application and management

The processing capability of the Windows Server 2003 server is limited. When the device is connected to the Windows Server 2003 server, do not configure too much entity information or a key pair with a large number of bits on the device. Otherwise, the device may fail to connect to the server.

Certificate application and management

The virtual IP address of the VRRP group can be specified as the source IP address only by configuring the source IP address. If the source IP address is not configured, the virtual IP address of the VRRP group cannot be automatically selected as the source IP address based on routes.

Certificate application and management

The certificate must be imported to all devices to which the certificate needs to be imported before the current certificate expires. If the certificate has expired and the administrator does not install a new certificate in time, the certificate verification fails.

Certificate application and management

SM2 certificate verification supports only the default user ID defined in GM/T 0009-2012. SM2 certificates without user IDs or non-default user IDs cannot be verified.

Security Management

For security purposes, you are advised not to use weak security algorithms or protocols provided by this feature. If it is necessary, run the install feature-software WEAKEA command to install the weak security algorithm/protocol feature package WEAKEA. By default, the device comes with the weak security algorithm/protocol feature package WEAKEA. For details about how to install or uninstall the feature package, see "Upgrade and Maintenance Configuration" in the CLI Configuration Guide - System Management Configuration.
