Feature Requirements

Table 2 Feature requirements

Feature

Feature Requirements

Automatic O&M

When a managed device is downgraded from V600R24C10 to V600R24C00 or an earlier version, the device status is displayed as offline and unmanaged. In this case, you need to remove the device from the to-be-approved list, and then perform inventory device import and approval operations to restore the device status to normal.

Automatic O&M

The health status of managed member devices running V200 or V300 cannot be displayed.

Automatic O&M

Inventory devices running V200 and V300 cannot be imported.

Automatic O&M

Only the following devices can be managed:

1. S series switches and WLAN devices running V200R024C10 and later versions

2. ARs running V300R024C10 and later versions

Automatic O&M

The net assistant function cannot be used to load licenses to managed member devices running V200 or V300.

Automatic O&M

The configuration-free replacement function is supported only when the source version is V600RC23C00 or later and the target version is V600RC24C10 or later.

If the source version is V600RC24C10 or later, a faulty device can be detected within 90 seconds.

If the source version is earlier than V600RC24C10, a faulty device can be detected within 30 minutes.

Automatic O&M

Configuration-free replacement is not supported for managed member devices running V200 and V300.

Automatic O&M

The configuration-free replacement function periodically backs up configuration files of member devices. If the authorized directory of the FTP user on the master device is manually changed, the configuration files of member devices will fail to be backed up, and the configuration-free replacement function will become invalid.

Automatic O&M

In the configuration-free replacement scenario, if the set system-mac mac-num command has been run to configure a system MAC address for the source member device, the target member device cannot go online after the replacement is complete. In this case, run the undo set system-mac mac-num command on the target member device to restore the default system MAC address, and restart the device.

Automatic O&M

If a cold patch is installed, you need to manually restart the device after the patch is installed.

Automatic O&M

Patches cannot be uninstalled, but incremental patches can be loaded.

Network-Wide Device Management

After a managed device is restored to factory settings, you need to unapprove the device and perform approval again so that the device can be managed.

Network-Wide Device Management

After a device is approved and onboarded for the first time, subsequent configuration changes by the user may cause exceptions of the Layer 3 network management channel (such as HTTP service being disabled, SSL certificate misconfiguration, or incorrect user name or password). As a result, the device cannot be managed even if its status is displayed as normal on the device management page of WebMaster.

Network-Wide Device Management

ARs running versions earlier than V600R024C10 do not support inventory import.

Network-Wide Configuration Management

The net assistant status data is not synchronized between the active and standby boards. After an active/standby switchover, you need to manually update and obtain the data. For example, you need to update the topology data on the UI and re-collect the topology data after an active/standby switchover.

In normal cases, the LC updates data every 30 minutes. If data is not synchronized between the active and standby boards and an active/standby switchover occurs, data synchronization is triggered after a maximum of 30 minutes.
