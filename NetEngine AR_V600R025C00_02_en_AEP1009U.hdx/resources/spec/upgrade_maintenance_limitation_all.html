Feature Requirements

Table 2 Feature requirements

Feature

Feature Requirements

Version Upgrade

For the AR6710-H4T4X2Y7, AR8700-8:

During the upgrade (by running a command or using YANG to set the next-startup package), an active/standby switchover is not allowed. A forcible active/standby switchover may cause an upgrade failure. If the upgrade fails, perform the upgrade again after the device is started and runs stably.

Version Upgrade

During an upgrade (by running a command or using YANG to set the next-startup package), formatting is not allowed. The formatting operation may cause the upgrade to fail. If the upgrade fails, wait until the device is stable or restarts and perform the upgrade again.

Patch

Ensure that the root directory of the user has sufficient space for storing the system software package, patch package, and MOD package.

Patch

Patch operations cannot be performed if the system CPU usage exceeds 70%. Otherwise, patch loading fails.

Perform patch operations after the system CPU usage falls below 70%.

Patch

During service configuration, patch operations, such as installing and uninstalling patch packages and specifying a patch package for the next startup, are not allowed. Otherwise, the patch operations may fail.

Patch

The MOD package version must match the system software package version. If the MOD package version does not match the system software package version, the MOD package cannot be loaded.

Patch

For the AR8700-8, AR5710-S28T2S2XE4, AR5710-S8P2XE-NRGL, AR5710-S8T2S:

Do not perform an active/standby switchover during patch installation. An active/standby switchover causes a patch operation failure and inconsistent status.

If the status is inconsistent, you can run the patch health check restoration command to restore the status.

Patch

1. Do not install or delete a patch when a board is being restarted or inserted/removed. Otherwise, the patch fails to be installed or deleted. To check the board status, run the display device command.

2. Do not insert or remove a board during patch installation or deletion. Otherwise, patch installation or deletion may fail.

Package Management

The maximum size of a software package obtained through the MIB is 2147483647 bytes. If the size of a software package queried through the hwSysImageSize MIB object exceeds 2147483647 bytes, the size of the software package is displayed as 2147483647 bytes.

Package Management

For the AR6710-H4T4X2Y7, AR8700-8:

The software package downloaded through smart-load is stored in the default root directory of the device. The directory cannot be manually changed and does not change when the current working directory is changed.

Digital Warranty

The digital warranty cannot be activated when the board is not registered.

Digital Warranty

For the AR6710-H4T4X2Y7, AR8700-8:

Digital warranties of fans and power modules are stored on the main control board. If the main control board is replaced, the digital warranties will be lost.
