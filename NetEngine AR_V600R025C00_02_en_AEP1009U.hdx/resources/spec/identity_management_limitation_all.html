User authentication

The IP address of the management interface cannot be used as the IP address of the local server for TSM SSO.

User authentication

The protocol stack on which TSM SSO depends does not support UDP fragment reassembly. The packets sent to the device for TSM SSO must be prevented from being fragmented. Otherwise, the packets cannot be correctly parsed.

Online user management

When the security group priority mode is local priority, if the name of a created local access user is the same as that of an online user, the security group to which the online user belongs is immediately switched to the security group to which the local access user belongs. No security group is specified for the local access user when the user is created. As a result, the online user cannot match the security policy, and the network access permission of the user is affected.

Online user management

Before running the cut online-user all command to forcibly log out all online users, be aware that this operation will affect services. The process of deregistering all users lasts for a certain period of time. If a new user goes online at this time, some new users may be deregistered from the active device but not from the standby device in a hot standby scenario. On a multi-CPU model, a user may be deregistered on some CPUs but not on other CPUs. If you want to log out all online users, you are advised to run this command multiple times until all users are logged out.
