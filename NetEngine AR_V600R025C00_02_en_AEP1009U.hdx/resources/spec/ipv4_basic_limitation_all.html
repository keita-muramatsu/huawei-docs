Basic IPv4 Functions

If the destination MAC address of a packet is the system MAC address but not the MAC address of the VLANIF interface, the packet may still be forwarded at Layer 3. If no routing entry is matched, the packet is discarded.

Basic IPv4 Functions

The forwarding engine does not support fragment reassembly. The interface MTU is set to the maximum value of the forwarding engine, and packets are transparently transmitted.

Basic IPv4 Functions

IPv4 packets with the option field in the IP packet header cannot be forwarded at Layer 3 and are sent to the control plane software for processing.

Basic IPv4 Functions

A lexicographical order error occurs when a walk operation is performed on the udpTable (OID: 1.3.6.1.2.1.7.5) and ipv6UdpTable (OID: 1.3.6.1.2.1.7.6) objects. When the device has multiple UDP connections with the same LocalAddress and LocalPort and the cache function of the SNMP agent is enabled (using the snmp-agent query-cache enable command), duplicate data is reported. As a result, when the display snmp-agent mib walk command is run, there is a possibility that a lexicographical order error (OID not increasing) is reported. However, this does not affect the display of all data. The NMS does not support this object.

Basic IPv4 Functions

The IP-MIB does not count the packets that need to be fragmented or reassembled.

1. The statistics about fragment packets sent by the device are 0. The following objects are involved:

ipIfStatsOutFragReqds, ipSystemStatsOutFragReqds, ipIfStatsOutFragOKs, ipSystemStatsOutFragOKs, ipIfStatsOutFragFails, ipSystemStatsOutFragFails, ipIfStatsOutFragCreates, ipSystemStatsOutFragCreates.

2. The statistics about reassembled IPv4 fragment packets received by the device are 0. The following objects are involved:

ipReasmTimeout, ipIfStatsReasmReqds, ipSystemStatsReasmReqds, ipIfStatsReasmOKs, ipSystemStatsReasmOKs, ipIfStatsReasmFails, ipSystemStatsReasmFails.

ICMPv4

1. The timestamp request packet cannot be processed.

ICMP ping

Description of ICMP fast reply packets when VRRP is configured on an interface

When VRRP is configured on an interface and ICMP fast reply is enabled or disabled, the source MAC address carried in ICMP reply packets is the virtual MAC address specified for VRRP.
