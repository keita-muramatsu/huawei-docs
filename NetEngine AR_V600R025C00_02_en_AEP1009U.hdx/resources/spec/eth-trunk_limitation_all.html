Basic Eth-Trunk functions

After the fault on an Eth-Trunk member interface is rectified, an alarm is generated:

1. A trap message is sent only when all member interfaces of a trunk interface change from down to up.

2. Trap sending can be suppressed for 3 seconds.

Basic Eth-Trunk functions

The default weight of each member interface of an Eth-Trunk interface is 1. You can adjust the weight. However, the adjustment changes the forwarding behavior of the Eth-Trunk interface. The hash operation is more likely to be performed on a member interface with a higher weight. The total weight of all member interfaces cannot be greater than the maximum number of member interfaces supported by the Eth-Trunk interface.

Basic Eth-Trunk functions

In 1:N scenarios, the maximum number of up member links of an Eth-Trunk in static LACP mode is set to 1. Before the active link becomes down and the standby link becomes the active link, the down status of the original active link is not reported to the Eth-Trunk interface. The down status of the original active link is reported to the Eth-Trunk interface only when either of the following conditions is met. This prevents route recalculation on the entire network when the Eth-Trunk interface goes down.

1. The Down timer times out after a delay of 60 seconds.

2. The standby link fails and cannot go up.

Basic Eth-Trunk functions

When a physical interface is added to an Eth-Trunk, excess broadcast packets may be generated or broadcast packet loss may occur.

Basic Eth-Trunk functions

If inner packets are VXLAN packets, load balancing takes effect only for IP packets. For non-IP packets (such as MAC-in-MAC packets), the IP-related fields in the hash template are set to 0 for hash calculation.

The chip cannot parse or perform hash calculation on the inner packets with more than two tags.

If the number of member ports is not an integral power of 2, route selection is uneven. The more member ports, the more obvious the problem.

Basic Eth-Trunk functions

BUM traffic flows are copied to all Eth-Trunk member interfaces, and then the Eth-Trunk member interfaces that do not need to send the flows are pruned. This occupies the forwarding bandwidth of the Eth-Trunk member interfaces, reducing the actual forwarding capability to be lower than expected. In this case, the device performs bandwidth compensation according to the BUM packet length. For example, if BUM packets with a length of 256 bytes are sent from four GE interfaces (100% BUM traffic) to one Eth-Trunk interface (consisting of two member interfaces), the actual outbound bandwidth is expected to be higher than 90% of the original bandwidth, but it is 50% without compensation and 65% with compensation. (In this example, 15% bandwidth is compensated.)

The outbound bandwidths after compensation are as follows based on the BUM packet length:

128 bytes: 70%

148 bytes: 69%

256 bytes: 65%

512 bytes: 62%

1024 bytes: 61%

Basic Eth-Trunk functions

When an Eth-Trunk member link is shut down, excess broadcast packets may be generated or broadcast packet loss may occur.

Basic Eth-Trunk functions

When a faulty member link of an Eth-Trunk recovers, a small number of excess packets may be generated or some packets may be lost during traffic switchback.

Basic Eth-Trunk functions

The unknown unicast, broadcast, and unknown multicast traffic on an Eth-Trunk outbound interface is replicated on each member interface and then discarded after hashing and pruning. The packets discarded after hashing and pruning also occupy the bandwidth of the outbound interface.

Basic Eth-Trunk functions

When an Eth-Trunk member interface is changed to an independent physical interface, excess broadcast packets may be generated or broadcast packet loss may occur.

Basic Eth-Trunk functions

During capacity expansion of an Eth-Trunk interface, there is a time difference on the devices at both ends when they process the operations of adding member interfaces to the Eth-Trunk interface. As a result, packet loss may occur when member interfaces are directly added to the Eth-Trunk interface.
