VLAN Basics

When using VLAN1, pay attention to the following points:

- You are not advised to use VLAN 1 as the management VLAN or service VLAN.

- Remove the interfaces that do not need to be added to VLAN 1 from VLAN 1 in time to prevent loops. Generally, the trunk interface must allow packets from VLAN 1 to pass through. Otherwise, some protocol packets transmitted in VLAN 1 will be discarded by the trunk interface, causing faults. To prevent potential security risks caused by allowing packets from VLAN 1 to pass through, you need to take measures.

- You are advised to remove interfaces from VLAN 1 on an Eth-Trunk or ring network.

- When a device is connected to an access device, it is recommended that the uplink interface of the access device not transparently transmit packets of VLAN 1. This prevents broadcast storms in VLAN 1.

- When an interface is bound to a VLANIF interface for Layer 3 forwarding, it is recommended that the interface be removed from VLAN 1 to prevent Layer 2 loops in VLAN 1.

VLAN Basics

In actual applications, the trunk interface transparently transmits packets of all VLANs. Therefore, do not use the port trunk allow-pass vlan all command.

VLAN Basics

After a VE interface is added to a VLAN, the VLANIF interface of the VLAN does not support Layer 3 forwarding.
