MAC Address Limitations

Each static MAC address entry can have only one outbound interface.

MAC Address Limitations

To prevent uplink traffic interruptions, do not configure the action to be taken upon detection of MAC address flapping on uplink interfaces.

MAC Address Flapping and Flapping Prevention

1. MAC address flapping detection takes effect only in a single ring. In a multi-ring scenario, this function takes effect only in the first ring where MAC address flapping occurs. Specially, if two or more rings exist in a VLAN where MAC address flapping is detected, only information about the interfaces in the first ring where MAC address flapping occurs is displayed in a MAC address flapping alarm, regardless of whether these interfaces are up or down.

2. A device with MAC address flapping detection enabled can detect MAC address flapping only in the first ring where MAC address flapping occurs in a VLAN within a set aging period (configurable, 5 minutes by default). For example, MAC address flapping occurs on PortA and PortB in a VLAN. After either PortA or PortB is set to down, MAC address flapping occurs on PortC and PortD within the same aging period. In this case, a MAC address flapping alarm is generated, indicating that MAC address flapping occurs between PortA and PortB.

3. When MAC address flapping occurs and the loop is not removed, the values in the Original-Port and Move-Ports fields remain unchanged in MAC address flapping records, if the interfaces where MAC address flapping occurs are added to or removed from an Eth-Trunk interface. Delete the MAC address entry that contains the move interface after the loop is removed, and perform MAC address flapping detection again. This facilitates detection on original and move interfaces, and ensures correct loop location and delivery of punishment actions (such as error-down and storm suppression on interfaces) to move interfaces.

4. When frequent switchovers occur on the ring network, the number of MAC address moves may exceed the specified value within a specified period. As a result, the mac-address flapping detection alarm is triggered. In this case, you are advised to lower the MAC address flapping detection security level or prolong the revertive switching time on the ring network.

MAC Address Flapping and Flapping Prevention

1. When MAC address flapping is associated with storm suppression, the suppression behavior takes effect on physical interfaces. Traffic on the sub-interfaces configured on the physical interface is also suppressed.

2. MAC address flapping-triggered storm suppression cannot take effect on sub-interfaces.

3. If the original interface where MAC address flapping occurs is a trusted interface, storm suppression and sandbox take effect only on the move interface of the local card.

4. MAC address flapping-triggered storm suppression can be implemented based on packet types, including unknown unicast, multicast, and broadcast packets. For example, the default suppression action is 1% of the interface rate. Then the rate of unknown unicast, multicast, and broadcast packets is 1% of the interface rate, respectively.

MAC Address Management

When a port is removed from a VLAN, MAC addresses are deleted in batches based on the port and VLAN. If there are more than 10 VLANs, the deletion type is changed to batch deletion based on the port. As a result, MAC addresses of other VLANs on the port are also deleted, causing unknown unicast flooding.

MAC Address Management

1. When the display mac-address command is used to query the MAC address table, the age time is the time recorded in the software MAC address table.

2. The time when software MAC address entries are learned on different cards may be different due to inter-card synchronization and synchronization between the software and hardware tables.

3. You are advised to query the MAC address table based on the slot.

MAC Address Management

If the device receives traffic in which the source MAC address is the local system MAC address, the local system MAC address is learned when there is no VLANIF interface on the device.

MAC Address Management

1. If MAC address flapping occurs more than 10 times, the device disables the MAC address-triggered ARP entry update function.

2. After MAC address flapping is eliminated, the device uses a 1-second timer to detect whether there are new MAC address flapping entries. If so, the device enables the MAC address-triggered ARP entry update function.
