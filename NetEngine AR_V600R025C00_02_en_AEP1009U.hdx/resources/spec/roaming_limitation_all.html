AI roaming

If the PMF function is enabled, the AI roaming function does not take effect.

Common Roaming

To implement WLAN roaming, the two APs before and after roaming must use the same SSID and same configuration in the security profiles (allowing for different profile names). Additionally, the authentication profiles on the two APs must have the same authentication mode and same authentication parameters.

Common Roaming

In direct forwarding mode, after a STA roams, ARP entries on the access device connected to the AP are not aged out in time, causing temporary service interruption. You are advised to run the undo learn-client-address { ipv4 | ipv6 } disable command in the VAP profile view of the WAC to enable STA address learning (enabled by default). The AP then sends gratuitous ARP packets to the access device to update ARP entries, ensuring service continuity during roaming.
