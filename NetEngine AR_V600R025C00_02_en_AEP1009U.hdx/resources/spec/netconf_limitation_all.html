PnP

1. If the link type of an interface is access and the default VLAN is not 1, the interface cannot be dynamically added to the PnP VLAN.

2. If the PVID of an interface is not 1, the PVID of the interface cannot be dynamically set to the PnP VLAN.

4. PnP automatically creates a VLAN globally. After the VLAN is created, PnP does not delete it unless the VLAN is deleted by the controller or users.

-URI: /restconf/data/huawei-private-scontroller:scontroller/common-infos. Function: This API is internally invoked for cloud management and is used to send notifications to components.

NETCONF maintainability

When a schema resource patch is installed or uninstalled during schema packet delivery, an error is returned for the schema packet.

NETCONF maintainability

During schema patch installation, configuration data is locked. In this case, full synchronization and lock operations cannot be delivered. Otherwise, full synchronization and lock operations fail.

NETCONF Protocol

For a NETCONF operation, if no service response is received within 32 seconds, a timeout occurs and a response timeout error packet is returned.

NETCONF Protocol

NETCONF limits the maximum size of an input packet. The size of the target configuration data imported through a URL cannot exceed 30 MB.

The following operations are involved:

1. edit-config operation (source being url)

2. copy-config (source being url)

NETCONF Protocol

For the AR5710-S8P2XE-NRGL:

1. If the capability set carried in the Hello packet sent by the peer contains extended capabilities, the device replies with a schema packet.

2. The exchange capability set is advertised to identify the mode of processing high-specification data.

3. The sync capability set is advertised to determine whether the packet returned by edit-config carries a flow ID.

NETCONF Protocol

The size of a delivered RPC message cannot be greater than 30 MB.

NETCONF Protocol

If the NMS client only notifies the base capability in compliance with the standard, the YANG mode is used for interconnection. If the exchange capability is advertised, the Huawei proprietary schema mode is used for interconnection.

NETCONF Protocol

An end-to-end NETCONF operation must be completed within 60 minutes. Otherwise, a timeout occurs.

NETCONF Protocol

The device can use only SSH as the transport protocol of NETCONF. Before using NETCONF to manage network devices, you must configure SSH.

NETCONF Protocol

1. There is an upper limit on the number of active alarms that can be generated for NETCONF disconnection. When the number of active alarms reaches the upper limit, the earliest disconnection alarm is cleared when a new disconnection alarm is generated.

Non-CU separation scenario: A maximum of 15 active alarms can be generated for NETCONF session disconnection.

CU separation scenario: A maximum of 15 alarms can be generated for NETCONF session disconnection between the device and NMS and a maximum of one alarm can be generated for configuration session disconnection between the CP and UP.

2. After the device is restarted, lost alarms before the restart are not reported again.
