Only HTTP packets whose Content-Encoding is gzip or deflate can be decoded.

Y

For the traffic sent to the ASE, if the security policy configuration is changed after the policy is determined, the policy is not re-checked on the engine. Only new traffic is processed based on the new policy.

The ASE can decode only HTTP1.0, HTTP1.1, and HTTP/2 traffic, but cannot decode HTTP/3 traffic. Therefore, related content security features, including intrusion prevention and antivirus, cannot be used to detect HTTP/3 traffic.

The device does not support the HTTP/2 multipart transmission format. Therefore, related content security features cannot be used to detect the content transmitted through HTTP/2 multipart, including intrusion prevention and antivirus.

After ASE-related configurations (including global configurations and service feature configurations) are rolled back, run the engine configuration commit command to commit the configurations. Otherwise, the configurations do not take effect.
