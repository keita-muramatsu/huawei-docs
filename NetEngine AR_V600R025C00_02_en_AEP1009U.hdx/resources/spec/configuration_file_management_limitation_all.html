Table 2 Feature requirements

Feature

Feature Requirements

Configuration Management Basics

If multiple users commit configurations at the same time, the operation may fail due to the conflict. A message indicating that the system is busy is displayed. Configurations need to be committed again.

Configuration Management Basics

During configuration editing, if the device memory usage exceeds 90%, the configuration editing fails.

Configuration Management Basics

For security purposes, FTP and TFTP are not recommended.

By default, the device provides the weak security algorithm/protocol feature package WEAKEA. If you need to use the weak security algorithm/protocol feature package WEAKEA, run the install feature-software WEAKEA command to install it.

Configuration Management Basics

Configurations cannot be committed when configuration data is being restored upon device startup.

Configuration Management Basics

The configuration cannot be saved during configuration data restoration when the device is just started.

Configuration Management Basics

When the configuration file for next startup is specified in FIPS mode, the configuration file created in non-FIPS mode cannot be specified.

Configuration Management Basics

When configurations are restored during device startup, you cannot query the current configurations.

Configuration Management Service

When the system is committing configurations or rolling back, there is a possibility that the card that is newly started cannot be registered for a long time.

Configuration Management Service

When the display configuration changes command is executed, if duplicate commands exist in the same view, the current command fails to be executed.

Configuration Management Service

Configuration change is not allowed when an NMS initiates full synchronization to the device.

Configuration Management Service

After the commit trial command is run, only the current trial run user can modify configurations.

Configuration Management Service

For operations such as setting the startup file and querying configuration file differences, the size of the configuration file in .cfg or .dat format cannot exceed 300 MB, and the size of the source file in the configuration file in .zip format cannot exceed 300 MB.
