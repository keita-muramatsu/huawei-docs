Example for Configuring RIPng to Filter Received Routes

Networking Requirements

In Figure 1, the prefixes of all the IPv6 addresses are 64 bits long, and interfaces between adjacent devices are connected using IPv6 link-local addresses.

All the devices are required to learn IPv6 routing information on the network through RIPng. DeviceB is required to filter out the route (2001:DB8:0:3::/64) received from DeviceC so that the route is not added to the routing table of DeviceB or advertised to DeviceA.

Figure 1 Networking diagram for configuring RIPng to filter received routes

In this example, interface 1, interface 2, and interface 3 represent 10GE 0/0/1, 10GE 0/0/2, and 10GE 0/0/3, respectively.


Configuration Roadmap

The configuration roadmap is as follows:

  1. Enable RIPng on each device so that the devices can communicate with each other.

  2. Configure an ACLv6 on DeviceB to filter received routes.

Procedure

  1. Assign an IPv6 address to each interface.

    # Configure DeviceA.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] ipv6 enable
[DeviceA-10GE0/0/1] ipv6 address auto link-local
[DeviceA-10GE0/0/1] quit
[DeviceA] interface 10ge 0/0/2
[DeviceA-10GE0/0/2] ipv6 enable
[DeviceA-10GE0/0/2] ipv6 address 2001:DB8:0:1::1 64
[DeviceA-10GE0/0/2] quit

    The configurations of DeviceB and DeviceC are similar to the configuration of DeviceA. For detailed configurations, see Configuration Scripts.

  2. Configure basic RIPng functions.

    # Configure DeviceA.

    [DeviceA] ripng 1
[DeviceA-ripng-1] quit
[DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] ripng 1 enable
[DeviceA-10GE0/0/1] quit
[DeviceA] interface 10ge 0/0/2
[DeviceA-10GE0/0/2] ripng 1 enable
[DeviceA-10GE0/0/2] quit

    # Configure DeviceB.

    [DeviceB] ripng 1
[DeviceB-ripng-1] quit
[DeviceB] interface 10ge 0/0/1
[DeviceB-10GE0/0/1] ripng 1 enable
[DeviceB-10GE0/0/1] quit
[DeviceB] interface 10ge 0/0/2
[DeviceB-10GE0/0/2] ripng 1 enable
[DeviceB-10GE0/0/2] quit

    # Configure DeviceC.

    [DeviceC] ripng 1
[DeviceC-ripng-1] quit
[DeviceC] interface 10ge 0/0/1
[DeviceC-10GE0/0/1] ripng 1 enable
[DeviceC-10GE0/0/1] quit
[DeviceC] interface 10ge 0/0/2
[DeviceC-10GE0/0/2] ripng 1 enable
[DeviceC-10GE0/0/2] quit
[DeviceC] interface 10ge 0/0/3
[DeviceC-10GE0/0/3] ripng 1 enable
[DeviceC-10GE0/0/3] quit

    # Check the RIPng routing table of DeviceB.

    [DeviceB] display ripng 1 route
   Route Flags: R - RIPng
                A - Aging, G - Garbage-collect
 ----------------------------------------------------------------
 Peer FE80::D472:0:3C23:1  on 10GE0/0/2
 Dest 2001:DB8:0:1::/64,
     via FE80::D472:0:3C23:1, cost  1, tag 0, RA, 4 Sec
 Peer FE80::F54C:0:9FDB:1  on 10GE0/0/3
 Dest 2001:DB8:0:2::/64,
     via FE80::F54C:0:9FDB:1, cost  1, tag 0, RA, 3 Sec
 Dest 2001:DB8:0:3::/64,
     via FE80::F54C:0:9FDB:1, cost  1, tag 0, RA, 3 Sec

    The preceding command output shows that the RIPng routing table of DeviceB contains the route of network segment 2001:DB8:0:3::/64.

    # Check the RIPng routing table of DeviceA.

    [DevicA] display ripng 1 route
   Route Flags:  R - RIPng
                A - Aging, G - Garbage-collect
 ----------------------------------------------------------------

 Peer FE80::476:0:3624:1  on 10GE0/0/2
 Dest 2001:DB8:0:2::/64,
     via FE80::476:0:3624:1, cost  2, tag 0, RA, 21 Sec
 Dest 2001:DB8:0:3::/64,
     via FE80::476:0:3624:1, cost  2, tag 0, RA, 21 Sec

    The preceding command output shows that the RIPng routing table of DeviceA contains the network segment route 2001:DB8:0:3::/64 advertised by DeviceB.

  3. Configure DeviceB to filter received routes.

    # Configure an ACL on DeviceB to deny the packets with the source address being 2001:DB8:0:3::/64.

    [DeviceB] acl ipv6 number 2000
[DeviceB-acl6-basic-2000] rule deny source 2001:DB8:0:3:: 64
[DeviceB-acl6-basic-2000] rule permit
[DeviceB-acl6-basic-2000] quit
[DeviceB] ripng 1
[DeviceB] filter-policy 2000 import

Verifying the Configuration

# Check the RIPng routing table of DeviceB. You can view that the RIPng routing table does not contain the route of network segment 2001:DB8:0:3::/64.

[DeviceB] display ripng 1 route
   Route Flags: R - RIPng
                A - Aging, G - Garbage-collect
 ----------------------------------------------------------------
 Peer FE80::D472:0:3C23:1  on 10GE0/0/2
 Dest 2001:DB8:0:1::/64,
     via FE80::D472:0:3C23:1, cost  1, tag 0, RA, 25 Sec
 Peer FE80::F54C:0:9FDB:1  on 10GE0/0/3
 Dest 2001:DB8:0:2::/64,
     via FE80::F54C:0:9FDB:1, cost  1, tag 0, RA, 14 Sec

# Check the RIPng routing table of DeviceA, and you can view that the RIPng routing table does not contain the route of network segment 2001:DB8:0:3::/64.

[SwitchA] display ripng 1 route
   Route Flags: R - RIPng
                A - Aging, G - Garbage-collect
 ----------------------------------------------------------------

 Peer FE80::476:0:3624:1  on 10GE0/0/2
 Dest 2001:DB8:0:2::/64,
     via FE80::476:0:3624:1, cost  2, tag 0, RA, 7 Sec

Configuration Scripts

  • DeviceA

    #
sysname DeviceA
#
interface 10GE0/0/1
 ipv6 enable
 ipv6 address auto link-local
 ripng 1 enable
#
interface 10GE0/0/2
 ipv6 enable
 ipv6 address 2001:DB8:0:1::1/64
 ripng 1 enable
#
ripng 1
#
return

  • DeviceB

    #
sysname DeviceB
#
acl ipv6 number 2000  
 rule 0 deny source 2001:DB8:0:3::/64  
 rule 1 permit
#
interface 10GE0/0/1
 ipv6 enable
 ipv6 address auto link-local
 ripng 1 enable
#
interface 10GE0/0/2
 ipv6 enable
 ipv6 address auto link-local
 ripng 1 enable
#
ripng 1
 filter-policy 2000 import
#
return

  • DeviceC

    #
sysname DeviceC
#
interface 10GE0/0/1
 ipv6 enable
 ipv6 address auto link-local
 ripng 1 enable
#
interface 10GE0/0/2
 ipv6 enable
 ipv6 address 2001:DB8:0:2::1/64
 ripng 1 enable
#
interface 10GE0/0/3
 ipv6 enable
 ipv6 address 2001:DB8:0:3::1/64
 ripng 1 enable
#
ripng 1
#
return
