Generating Code

The serialization and deserialization of GPB encoding can be implemented using the code automatically generated by software.

In this example, GPB encoding of telemetry involves the following .proto files:

  • huawei-grpc-dialin.proto: describes the dynamic subscription RPC definition supported by the device that functions as a server.
  • huawei-telemetry.proto: describes the sampled data, including the sampling interval and sampling path.
  • huawei-ifm.proto: defines the format of the sampled data.

In this example, the collector functions as a gRPC client and initiates a connection with the device that functions as a gRPC server and sends collected data to the collector.

    The software automatically generates three Java files based on the three .proto files. Each Java file defines the message structure, serialization interface, deserialization interface, as well as a class (a field is a member of a class and the Get method is provided to obtain data) and the corresponding serializing method (writeTo) and deserializing method (parseFrom) for each node.
