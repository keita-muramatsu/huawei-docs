Sampling Types

Table 1 lists common telemetry sampling types. The supported sampling types vary according to devices.

Table 1 Common telemetry sampling types

Sampling Type

Meaning

Description

Probe

Probe sampling

Supports high-speed sampling and periodic reporting within milliseconds.

Yang

YANG model sampling

Simulates the Get query process of YANG and supports periodic reporting within seconds or more.

Event

Event sampling

Reports an event when it is generated on the device.

Alarm

Alarm sampling

Reports an alarm when it is generated on the device.

Self-Defined-Event

Customized event sampling

Allows users to configure threshold conditions. Data is reported when the conditions are met.

OnChange

Immediate sampling

Reports changed data when data changes.
