Filtering Command Outputs

Filtering command outputs help you quickly find the information you need. For example, you can use a regular expression (specifying the rule to filter information) in a display command to filter the output information.

When the displayed information cannot be completely output on one screen, you can use the pause function to view the information on that screen, before moving onto the next screen. Table 1 describes the display functions.

Table 1 Display functions

Key

Function

Space

Continues to display the information on the next screen.

Enter

Continues to display the information in the next line.

Plus sign (+)+regular-expression

Same functions as | include regular-expression. The vertical bar (|) is a pipe character.

Minus sign (-)+regular-expression

Same functions as | exclude regular-expression The vertical bar (|) is a pipe character.

Slash (/)+regular-expression

Same functions as | begin regular-expression The vertical bar (|) is a pipe character.

Ctrl+C and any other key except the preceding ones

Stops information display and command execution.
