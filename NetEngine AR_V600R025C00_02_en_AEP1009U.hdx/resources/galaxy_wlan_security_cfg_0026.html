Configuring WPA3-802.1X Authentication

Context

There are two types of WPA3 authentication: WPA3-802.1X authentication (also called WPA3-Enterprise) and WPA3-SAE authentication (also called WPA3-Personal).

Compared with WPA2-802.1X authentication, WPA3-802.1X authentication enhances the algorithm strength by increasing the key length to 192 bits (WPA2 uses a 128-bit encryption key). WPA3-802.1X authentication is applicable to scenarios with high security requirements, such as governments and large enterprises.

WPA3-802.1X authentication has specific requirements on terminals and servers. To deploy WPA3-802.1X authentication, you may need to upgrade related hardware.

WPA3 authentication automatically enables the PMF function in mandatory mode. That is, the pmf { optional | mandatory } command configuration does not take effect in WPA3 authentication mode.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a security profile and enter its view.

    security-profile name profile-name

    By default, the security profile default exists in the system.

  4. Set the security policy to WPA3-802.1X authentication.

    security wpa3 dot1x { gcmp256 | aes }

    By default, no security policy is configured.

  5. (Optional) Disable key negotiation for multicast traffic.

    wpa group-key-negotiation disable

    By default, key negotiation for multicast traffic is enabled.

  6. (Optional) Enable the function of disconnecting STAs when the device does not receive the last packet from the STAs during unicast key negotiation.

    wpa unicast-key-negotiation time-out kick-sta enable

    By default, the device does not disconnect STAs when it does not receive the last packet from the STAs during unicast key negotiation.

Verifying the Configuration

  • Run the display wlan config-errors command in the diagnostic view to check whether an error message is displayed indicating that the authentication type in the security profile does not match that in the authentication profile. 802.1X authentication must be configured in both the security profile and authentication profile. For details about how to configure 802.1X authentication, see NAC Configuration.
