SNMP PDUs

SNMP defines five types of PDUs (SNMP packets), which are exchanged between the NMS and an agent, as shown in Figure 1.

Figure 1 SNMP packet exchange

The SNMP packets are as follows:

  • get-request: obtains one or more parameter values from an agent.

  • get-next-request: obtains the next parameter value from the agent.

  • set-request: sets one or more parameters for the agent.

  • get-response: returns one or more parameter values. This type of packets is sent by the agent in reply to the preceding three operations.

  • trap: informs the NMS of some important events. It is sent by the agent.

The first three types of packets are sent by the NMS to the agent. The last two types of packets are sent by the agent to the NMS.
