Example for Deploying an Intelligent Simplified Campus Network (VLANs Created Based on Interfaces)

Networking Requirements

A new campus network is deployed in a teaching building with multiple classrooms. Each classroom is equipped with cameras, laptops, phones, PCs, and APs. Phones and PCs are connected to RUs in serial mode. Terminals of different types need to be added to different VLANs, as shown in Figure 1.

Device deployment solution: Deploy a central device (DeviceA) in the ELV room of the teaching building. Deploy an RU (RUn, where n indicates the classroom number) in each ELV box of the classroom. The RUs are connected to the central device through a single link. The central device connects to RUs through hybrid cables and supplies power to RUs through PoE. The RU in each classroom is connected to cameras, laptops, PCs, and APs through Ethernet cables. The 8-interface RU in this example uses four downlink ports, and other downlink ports are reserved.

Figure 1 Networking for RU deployment in the office building

In this example, interface1, interface2, interface3, interface4, and interface5 represent 10GE0/0/1, 10GE0/0/2, 10GE0/0/3, 10GE0/0/4, and 10GE0/0/5, respectively.


Configuration Roadmap

This example provides only configurations of RUs connected to DeviceA. User authentication and Wi-Fi service configurations are not provided. RU101 is used as an example. The configuration roadmap is as follows:

  1. Connect the RU to the central device, and onboard the RU in plug-and-play mode.
  2. Bind an interconnection interface for each RU on DeviceA and configure interface isolation for the RU.
  3. Configure VLANs for interfaces on the central device.
  4. On the central device, configure interconnection interfaces for connecting to the RUs, add interfaces on the RUs to VLANs as planned, and add the interconnection interfaces to VLAN 1100, VLAN 1200, VLAN 1300, and VLAN 1400 in tagged mode.
  5. Configure voice VLANs for interconnection interfaces on the central device.

Procedure

  1. Connect the uplink port of each RU to the central device and check whether the RUs are successfully online.

    # Check the RU status. Normal indicates that the RU is running properly.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] display remote-unit 
------------------------------------------------------------------------------------------------------------------------
ESN                     ID        Type           ConnectInterface   Status     VersionMatch  Name 
------------------------------------------------------------------------------------------------------------------------
219801176801XXXXXXXX    -     S5731-L8P2HT-RUA    10GE0/0/2         Normal      YES           -
219801176802XXXXXXXX    -     S5731-L8P2HT-RUA    10GE0/0/3         Normal      YES           -
219801176803XXXXXXXX    -     S5731-L8P2HT-RUA    10GE0/0/4         Normal      YES           -  
219801176804XXXXXXXX    -     S5731-L8P2HT-RUA    10GE0/0/5         Normal      YES           -
------------------------------------------------------------------------------------------------------------------------
Total: 4, printed: 4
  2. Configure the interconnection interfaces and interface isolation for the RUs.

    # Bind the interconnection interface. The following uses 10GE0/0/2, 10GE0/0/3, 10GE0/0/4, and 10GE0/0/5 as examples. The operations for other interconnection interfaces are similar.

    [DeviceA] remote-unit 0
[DeviceA-remote-unit-0] name RU101
[DeviceA-remote-unit-0] description RU101_10ge0/0/2
[DeviceA-remote-unit-0] bind interface 10GE0/0/2
[DeviceA-remote-unit-0] quit
[DeviceA] remote-unit 1
[DeviceA-remote-unit-1] name RU102
[DeviceA-remote-unit-1] description RU102_10ge0/0/3
[DeviceA-remote-unit-1] bind interface 10GE0/0/3
[DeviceA-remote-unit-1] quit
[DeviceA] remote-unit 2
[DeviceA-remote-unit-1] name RU103
[DeviceA-remote-unit-1] description RU103_10ge0/0/4
[DeviceA-remote-unit-1] bind interface 10GE0/0/4
[DeviceA-remote-unit-1] quit
[DeviceA] remote-unit 3
[DeviceA-remote-unit-1] name RU104
[DeviceA-remote-unit-1] description RU104_10ge0/0/5
[DeviceA-remote-unit-1] bind interface 10GE0/0/5
[DeviceA-remote-unit-1] quit

    # Configure interface isolation in the global RU view and deliver the configuration to the RUs.

    [DeviceA] remote-unit
[DeviceA-remote-unit] isolate enable
[DeviceA-remote-unit] commit all
[DeviceA-remote-unit] quit
  3. Create VLANs and configure the allowed VLAN for the interfaces.

    # Add the interconnection interface 10GE0/0/2 to VLANs 1100, 1200, 1300, 1400, and 1500. The configurations for other interconnection interfaces are similar.

    [DeviceA] vlan batch 1100 1200 1300 1400 1500
[DeviceA] interface 10GE 0/0/2
[DeviceA-10GE0/0/2] description to_RU101
[DeviceA-10GE0/0/2] portswitch
[DeviceA-10GE0/0/2] port link-type trunk
[DeviceA-10GE0/0/2] port trunk allow-pass vlan 1100 1200 1300 1400 1500
[DeviceA-10GE0/0/2] quit

    # Configure the VLAN mode for the RUs.

    [DeviceA] remote-unit 
[DeviceA-remote-unit] vlan mode manual

    # Add downlink ports of the RUs to VLANs. RU101 to RU202 are used as examples. Assume that all RUs use the same port-to-terminal connections: port 1 is connected to a camera, port 2 to a laptop, port 3 to a phone (with a PC connected downstream), and port 4 to an AP. The configurations for other RUs are similar.

    [DeviceA-remote-unit] remote-unit 0 to 3 port 1 untagged vlan 1100  
[DeviceA-remote-unit] remote-unit 0 to 3 port 2 untagged vlan 1200  
[DeviceA-remote-unit] remote-unit 0 to 3 port 3 untagged vlan 1300  
[DeviceA-remote-unit] remote-unit 0 to 3 port 3 tagged vlan 1500
[DeviceA-remote-unit] remote-unit 0 to 3 port 4 untagged vlan 1400  
[DeviceA-remote-unit] remote-unit 0 to 3 port 1 default vlan 1100  
[DeviceA-remote-unit] remote-unit 0 to 3 port 2 default vlan 1200  
[DeviceA-remote-unit] remote-unit 0 to 3 port 3 default vlan 1300  
[DeviceA-remote-unit] remote-unit 0 to 3 port 4 default vlan 1400
    # Add uplink ports of the RUs to VLANs. RU101 to RU202 are used as examples. The configurations for other RUs are similar.
    [DeviceA-remote-unit] remote-unit 0 to 3 port uplink tagged vlan 1100 1200 1300 1400 1500
    # Run the commit command to deliver the configuration to the RU.
    [DeviceA-remote-unit] commit all
  4. Configure the allowed VLAN for the uplink port of the central device.
    [DeviceA] interface 10GE 0/0/1
[DeviceA-10GE0/0/1] portswitch
[DeviceA-10GE0/0/1] port link-type trunk
[DeviceA-10GE0/0/1] port trunk allow-pass vlan 1100 1200 1300 1400 1500
[DeviceA-10GE0/0/1] quit
  5. Configure a voice VLAN for the interconnection interface on the central device. The configurations for other interconnection interfaces are similar.
    [DeviceA] lldp enable
[DeviceA] interface 10GE 0/0/2
[DeviceA-10GE1/0/2] undo lldp disable
[DeviceA-10GE1/0/2] stp edged-port enable
[DeviceA-10GE1/0/2] lldp tlv-enable med-tlv network-policy voice-vlan vlan 1500
[DeviceA-10GE1/0/2] voice-vlan 1500 enable
[DeviceA-10GE1/0/2] lldp mdn enable txrx   //For IP phones that use non-standard discovery protocols such as CDP, perform this step to ensure that the device can establish neighbor relationships with these IP phones.
