Viewing Logs

After a URL filtering profile is referenced in a security policy on a device, the device checks the content of traffic matching the security policy. If the URL to be accessed by a user matches a filtering rule defined in the URL filtering profile, a service log is generated. A typical example of a URL filtering log is as follows:

URL/4/FILTER(l): The URL filtering policy was matched.(SyslogId=100, VSys="vsys_1", Policy="rule_1", SrcIp=192.168.0.100, DstIp=172.16.10.100, SrcPort=6096, DstPort=80, SrcZone=trust, DstZone=untrust, User="unknown", Protocol=TCP, Application="HTTP", Profile="profile_l", Type=Blacklist, EventNum=1, Category="none", SubCategory="none", Page="*ath", Host="www.example1.com", Referer="none", Item="www.example1.com", Action=Block, UserGroup="unknown" )

For the meaning of each field in the log, see Log Reference > URL > URL/4/FILTER.
