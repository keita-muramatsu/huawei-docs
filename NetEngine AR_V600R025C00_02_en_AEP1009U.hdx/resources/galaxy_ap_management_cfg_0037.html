Configuring Log Backup on APs

Context

Logs record user operations and system running information. After logs are backed up to a server, network administrators can summarize and analyze AP logs to learn about the operations performed on APs for fault location.

After log backup is configured, an AP automatically sends logs to the log server with a specified IP address.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create an AP system profile, and enter its view.

    ap-system-profile name profile-name

    By default, the AP system profile default exists on the device.

  4. Configure the level of AP logs to be backed up.

    log-record-level { alert | critical | debug | emergency | error | info | notice | warning }

    By default, the level of AP logs that need to be backed up is info.

  5. Configure the IP address and port number of a log server, and enable log backup.

    log-server ip-address ip-address [ port port ]

    By default, the port number of the log server is 514, the IP address of the log server is not specified, and log backup is disabled on an AP.

  6. Return to the WLAN view.

    quit

  7. Enter the AP view or AP group view.
    • Enter the AP group view.
      ap-group name group-name
    • Enter the AP view.
      ap-id ap-id
  8. Bind the AP system profile to an AP group or a single AP.

    ap-system-profile profile-name

    By default, the AP system profile default is bound to an AP group, but no AP system profile is bound to an AP.

Verifying the Configuration

  • Run the display ap-system-profile { name profile-name | all } command to check information about an AP system profile.
  • Run the display references ap-system-profile name profile-name command to check reference information about an AP system profile.
