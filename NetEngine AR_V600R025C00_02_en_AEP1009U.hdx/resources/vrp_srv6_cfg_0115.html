Configuring IS-IS Topology Advertisement to BGP-LS

Context

After IS-IS topology information is advertised to BGP-LS, BGP-LS reports the topology information to a controller for path planning.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the IS-IS view.

    isis [ process-id ]

  3. Enable IPv6 for the IS-IS process.

    ipv6 enable topology ipv6

  4. Configure the IS-IS wide metric attribute.

    cost-style { compatible [ relax-spf-limit ] | wide | wide-compatible }

  5. Enable IS-IS IPv6 topology advertisement.

    ipv6 bgp-ls enable [ level-1 | level-2 | level-1-2 ]

  6. Enable the IS-IS process to advertise IPv6 link attribute TLVs in LSPs.

    ipv6 advertise link attributes

    Link attributes include the IPv6 address and interface index.
