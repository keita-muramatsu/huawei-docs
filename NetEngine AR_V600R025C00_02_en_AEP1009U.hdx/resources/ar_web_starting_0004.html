Web System Layout

Understanding the web system layout is the basis of your proper operations on the web system.

As shown in Figure 1, the web system consists of five areas. Table 1 provides details about the areas.

Figure 1 Web system layout
Table 1 Web system layout

No.

Area

Description

1

Function tab

Based on function types, the web system provides the following menus:

  • Monitoring: allows you to view the device panels, device information, device status, AP list, and network connections.
  • Config: provides detailed service configuration guides, such as Internet access, wireless network, and LAN-side configuration wizards.
  • Diagnosis: provides comprehensive O&M tools, including AR information collection, AP information collection, and network diagnosis.
  • System: allows you to configure device management functions, such as administrators, AP upgrade, and software upgrade, providing a basis for normal system running.

2

Menu navigation tree

After you select a tab, menus corresponding to the tab are displayed in the navigation tree on the left. You can click menus to configure desired functions.

3

Operation area

After you select a menu, the configuration page corresponding to the menu is displayed in the operation area on the right.

4

Common operation button area

This area is located in the upper right corner of the web system and provides shortcut buttons for common operations, such as logout, language switching, and password change.

5

CLI console

This area is located in the upper right corner of the web system and used to switch from the web system to the CLI console.

6

Smart assistant button

This button is located in the lower right or left corner of the web system and used to switch from the web system to WeiKnow for assistance.
