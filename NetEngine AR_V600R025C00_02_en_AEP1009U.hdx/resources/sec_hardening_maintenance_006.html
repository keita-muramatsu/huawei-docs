MSTP Security

Overview

  • Root protection

    Root protection can be configured to prevent attacks launched using malicious packets from making a valid root device that receives BPDUs with a higher priority be no longer a root device and falsely changing the network topology.

  • BPDU protection

    When the edge interface directly connected to a user device receives BPDUs sent for malicious attacks, the edge interface changes to a non-edge one. As a result, the network topology is recomputed, and network flapping occurs. BPDU protection can be configured to prevent this problem.

  • TC protection

    TC protection is used to suppress TC-BPDUs. The number of times that TC-BPDUs are processed by a device within a given time period is configurable. If the number of TC-BPDUs that the device receives within a given time period exceeds the specified threshold, the device handles TC-BPDUs only for the specified number of times. Excess TC-BPDUs are processed by the device as a whole for once after the timer (that is, the specified time period) expires. This protects the device from frequently deleting MAC and ARP entries, avoiding overburden.

  • Loop prevention

    After loop prevention is enabled, if a root or alternate port on a device does not receive RST BPDUs from the upstream device for a long time, a notification is sent to the NMS. (The root port will enter the Discarding state.) The alternate port remains in the blocked state and does not forward packets, avoiding loops. The root port restores the Forwarding state until it receives RST BPDUs.

Impact on the System

None

Procedure

  • Root protection
    1. Enter the system view.

      system-view

    2. Enter the Ethernet interface view.

      interface interface-type interface-number

    3. Configure root protection on the device.

      stp root-protection

  • BPDU protection
    1. Enter the system view.

      system-view

    2. Configure BPDU protection on the edge port of the device.

      stp bpdu-protection

  • TC protection
    1. Enter the system view.

      system-view

    2. Configure TC protection.

      stp tc-protection

  • Loop prevention
    1. Enter the system view.

      system-view

    2. Enter the view of the root port or alternate port.

      interface interface-type interface-number

    3. Configure loop prevention on the interface.

      stp loop-protection

Checking the Security Hardening Result

  • Run the display stp [ process process-id ] [ instance instance-id ] [ interface interface-type interface-number | slot slot-id ] command to check the configurations of BPDU protection, root protection, and loop prevention based on the BPDU-Protection and Protection Type fields.
  • Run the display stp global command to check the TC protection configuration based on the Tc-protection, Tc-protection threshold, and Tc-protection interval fields.
