1. Eight GE electrical interfaces

Table 4 Ports on the WSIC-8GE-T-V2
Port Connector Type Description Available Components
GE electrical interface RJ45

A GE electrical interface (10/100/1000 Mbit/s auto-sensing) transmits and receives Ethernet services at 10 Mbit/s, 100 Mbit/s, or 1000 Mbit/s.

  • Standards compliance: IEEE 802.3, IEEE 802.3u, IEEE 802.3ab
  • Working mode: Full-duplex (10/100/1000 Mbit/s auto-sensing)
  • Maximum transmission distance: 100 m
NOTE:

All WAN-side GE interfaces can be switched to LAN-side interfaces.

Functions and Features

Table 5 Functions and features of the WSIC-8GE-T-V2
Functions and Features Description
Overview

The 8GE-T-V2 is a gigabit WAN access module. It provides eight GE electrical interfaces.

An 8GE-T-V2 card can be installed in a WSIC slot of a router.
