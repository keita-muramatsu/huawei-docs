Updating the Antivirus Signature Database

Prerequisites

  • For information about how to prepare for the update of a signature database, see "Preparations for Signature Database Update" in CLI Configuration Guide > System Management > Signature Database Update Configuration.
  • Before updating the antivirus signature database online, you need to configure the device to communicate with the Huawei Security Center. For details, see "Configuring the Device to Communicate with the Huawei Security Center" in CLI Configuration Guide > System Management > Signature Database Update Configuration > Configuring Online Signature Database Update.

Context

The Huawei Security Center (isecurity.huawei.com) periodically releases the antivirus signature database. Updating the signature database of a device to the latest version enhances the virus detection capability and efficiency of the device.

This section provides only the basic steps for updating a signature database online. For details about offline signature database update and other related update information, see "Signature Database Update Configuration" in CLI Configuration Guide > System Management Configuration.

Procedure

  1. Configure the DNS server to ensure that the device can correctly parse the domain name of the security center.

    system-view
dns resolve
dns server ip-address

  2. Update the antivirus signature database to the latest version manually.

    update online av-sdb

    After the command is executed, the device immediately queries and downloads the antivirus signature database, and then updates the local signature database to the latest version.

  3. Configure scheduled update of the antivirus signature database.
    1. Enable the scheduled update function.

      update schedule av-sdb enable

    2. Configure the scheduled update time.

      update schedule av-sdb { hourly minute | { daily | weekly { mon | tue | wed | thu | fri | sat | sun } } time }

      By default, the scheduled update function of the antivirus signature database is enabled. The device randomly selects a time from 00:00 to 07:59 as the scheduled time for updating the antivirus signature database every day. You can configure the time manually.

      You are advised to update the antivirus signature database once a week, and the frequency is customizable.

Verifying the Configuration

  • Run the display update configuration command to check whether the configuration for the antivirus signature database update is correct.
  • After the antivirus signature database is updated, run the display engine information command to check the running status of the ASE and version information of the antivirus signature database. Ensure that the database has been updated to the latest version.
