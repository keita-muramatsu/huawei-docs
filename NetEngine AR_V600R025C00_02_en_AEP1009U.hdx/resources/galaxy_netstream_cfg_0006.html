NetStream Flow Aging

After the NetStream function is enabled, the device stores NetStream flows in the cache. When the flows in the cache meet aging conditions, the device ages out the flows and exports them to the NSC.

NetStream flows are aged out in the following modes:

  • Aging based on customized conditions

    • Active flow aging

      A flow is sampled within a specified period, starting from the time that its first packet is sampled. When this specified period elapses, statistics about this flow are exported. This type of aging is known as active flow aging. It is suitable for analyzing flows that last for a long period and for periodically exporting flow statistics.

    • Inactive flow aging

      If a flow is not sampled within a specified period, counting back from the time that its last packet is sampled (time when the number of received packets does not increase within the specified period), the device exports statistics about this flow to the NetStream server. This type of aging is known as inactive flow aging. Inactive flow aging clears unnecessary entries in the NetStream cache to enable the device to fully leverage statistics entries. It is suitable for analyzing flows that span a relatively short period of time. Once packets are no longer transmitted in a flow, the device exports flow statistics to save memory space.

    • FIN- and RST-based aging

      The FIN or RST flag in a TCP packet indicates the termination of the TCP connection. A flow is aged out when the FIN or RST flag is detected in the packets of the flow.

  • Oversize-triggered aging

    • Oversized NetStream flow table aging

      The device limits the size of the NetStream flow table, and automatically ages out excess flow entries when that limit is exceeded, thereby ensuring accurate statistics.

    • Byte threshold-crossing aging

      The device records the number of bytes in NetStream flows in the cache. To prevent cache overflow and inaccurate statistics caused by the recording of new statistics, the device ages out a flow as soon as it detects that the number of bytes in the flow exceeds the limit.

  • Forced aging

    You can run a command to forcibly age out all flows in the NetStream cache. Forced aging is used when the aging conditions are not met but the latest flow statistics are required; or when flows in the cache cannot be aged out due to an exception of the NetStream service.
