Example for Configuring IPv6 Static Routes

Networking Requirements

The prefix length of all IPv6 addresses shown in Figure 1 is 64. It is required that IPv6 static routes be configured between devices so that all the devices can communicate with each other.

Figure 1 Network diagram of IPv6 static routes

In this example, interface 1, interface 2, and interface 3 represent 10GE0/0/1, 10GE0/0/2, and 10GE0/0/3, respectively.


Precautions

During the configuration, note the following:

  • If a broadcast interface is used as the outbound interface of an IPv6 static route, a next-hop address must also be specified.

Configuration Roadmap

The configuration roadmap is as follows:

  1. Configure IPv6 addresses for interfaces on each device.

  2. Configure IPv6 static routes and a default route on devices.

  3. Configure a default IPv6 gateway for each host so that any two hosts can communicate with each other.

Procedure

  1. Configure IPv6 addresses for interfaces on each device.

    # Configure DeviceA.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] interface 10ge 0/0/1
[DeviceA-10GE0/0/1] undo portswitch
[DeviceA-10GE0/0/1] ipv6 enable
[DeviceA-10GE0/0/1] ipv6 address 2001:db8:4::1 64
[DeviceA-10GE0/0/1] quit
[DeviceA] interface 10ge 0/0/2
[DeviceA-10GE0/0/2] undo portswitch
[DeviceA-10GE0/0/2] ipv6 enable
[DeviceA-10GE0/0/2] ipv6 address 2001:db8:1::1 64
[DeviceA-10GE0/0/2] quit

    The configurations of DeviceB and DeviceC are similar to the configuration of DeviceA. For detailed configurations, see Configuration Scripts.

  2. Configure IPv6 static routes on devices.

    # Configure a default IPv6 static route on DeviceA.

    [DeviceA] ipv6 route-static :: 0 10ge 0/0/1 2001:db8:4::2

    # Configure two IPv6 static routes on DeviceB.

    [DeviceB] ipv6 route-static 2001:db8:1:: 64 10ge 0/0/1 2001:db8:4::1
[DeviceB] ipv6 route-static 2001:db8:3:: 64 10ge 0/0/2 2001:db8:5::1

    # Configure a default IPv6 static route on DeviceC.

    [DeviceC] ipv6 route-static :: 0 10ge 0/0/1 2001:db8:5::2

  3. Configure the host address and gateway.

    Configure IPv6 addresses for hosts, and then configure the default gateways of PC1, PC2, and PC3 as 2001:db8:1::1, 2001:db8:2::1, and 2001:db8:3::1, respectively.

Configuration Scripts

  • DeviceA

    #
sysname DeviceA
#
interface 10GE0/0/1
 ipv6 enable
 ipv6 address 2001:db8:4::1/64
#
interface 10GE0/0/2
 ipv6 enable
 ipv6 address 2001:db8:1::1/64
#
ipv6 route-static :: 0 10GE0/0/1 2001:db8:4::2
#
return

  • DeviceB

    #
sysname DeviceB
#
interface 10GE0/0/1
 ipv6 enable
 ipv6 address 2001:db8:4::2/64
#
interface 10GE0/0/2
 ipv6 enable
 ipv6 address 2001:db8:5::2/64
#
interface 10GE0/0/3
 ipv6 enable
 ipv6 address 2001:db8:2::1/64
#
ipv6 route-static 2001:db8:1:: 64 10GE0/0/1 2001:db8:4::1
ipv6 route-static 2001:db8:3:: 64 10GE0/0/2 2001:db8:5::1
#
return
  • DeviceC
    #
sysname DeviceC
#
interface 10GE0/0/1 
 ipv6 enable
 ipv6 address 2001:db8:5::1/64
#
interface 10GE0/0/2
 ipv6 enable
 ipv6 address 2001:db8:3::1/64
#
ipv6 route-static :: 0 10GE0/0/1 2001:db8:5::2
#
return
