Understanding MAC Address Learning

If MAC address learning is enabled, a device can receive Ethernet frames sent from surrounding devices, parse source MAC addresses, locate interfaces receiving the Ethernet frames, and add new entries to the MAC address table. When receiving other Ethernet frames destined for the parsed MAC addresses, the device forwards the frames through the corresponding outbound interface according to the MAC address entries. The MAC address learning function reduces broadcast packets on a network.

Attackers sometimes send a large number of unwanted packets with different source MAC addresses to a device, consuming MAC address entry resources of the device. As a result, the device cannot learn the source MAC addresses of valid packets. The device broadcasts packets that do not match MAC address entries, wasting bandwidth resources. Disabling MAC address learning can effectively prevent such attacks.

Rules for limiting MAC address learning are invalid for existing online users but valid for those who go online after the rules have been configured.

You can disable MAC address learning using the methods listed in Table 1.

Table 1 Disabling MAC address learning

Mode

Description

Disable MAC address learning on an interface.

If MAC address learning is disabled on an interface, the interface does not automatically learn new dynamic MAC address entries. The learned dynamic MAC address entries will age out and be deleted when the aging time expires.

Disable MAC address learning in a VLAN.

If MAC address learning is disabled in a VLAN, interfaces in the VLAN do not automatically learn new dynamic MAC address entries in that VLAN. The learned dynamic MAC address entries will age out and be deleted when the aging time expires.
