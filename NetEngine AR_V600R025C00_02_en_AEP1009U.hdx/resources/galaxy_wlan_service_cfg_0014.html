Common Operations of WLAN Profiles

Viewing Reference Information About Profiles

After WLAN profiles are configured, you can run the display references profile-type name profile-name command in any view to check the objects to which a WLAN profile is bound. In this command, profile-type specifies the profile type. To check all profile types that can be displayed and their brief descriptions, run the display references ? command.

For example, to check reference information about a specified AP system profile, you can run the display references ap-system-profile name profile-name command.
