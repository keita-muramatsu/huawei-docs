Components

Figure 2 Components of the AR6710-H4T4X2Y7

1. Two power module slots

Applicable power modules:

PDC260S12-CL

PAC300S12-CL (300W AC Power Module)

PDC260S12-DL

NOTE:

If the PDC260S12-DL power module is used and the software version is V600R024C00SPC100, install V600R024HP1502 or a later patch.

2. Two SRU/SPU slots

Applicable SRU:

SRU-700S

NOTE:
  • Dual SRUs are supported in V600R024C00 and later versions. In dual-SRU scenarios, the two SRUs must be of the same model.
  • In versions earlier than V600R024C00, the SRU-700S can be installed only in slot 10. In V600R024C00 and later versions, the SRU-700S can be installed in either of the two slots.
  • When using a SIC-4GET-V2 interface card (running a version earlier than V600R024C00) for the first time, ensure that the SRU-700S is installed in slot 10. If the system uses dual SRU-700S boards, the active SRU must reside in slot 10. This requirement does not apply if both the interface card and SRU are running V600R024C00 or later.
  • SPUs are not supported in the current version.
