Using the Specifications Query Tool to Query Product Specifications

Info-Finder is a tool platform that allows you to search by product series and model for key product information, such as basic information including software specifications, hardware specifications, and life cycles, as well as operation and maintenance information including licenses, alarms, logs, commands, and MIBs. Using Info-Finder, you can:

  • Query the features and specifications supported by a product.
  • Compare the features and specifications supported by different products.
  • Export the features and specifications supported by a product.
