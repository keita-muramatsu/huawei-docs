depth

depth defines the number of levels of data that you can query. This parameter is allowed only for the GET or HEAD method. If it is used in other operation methods, "400 Bad Request" is returned. If the depth of a data node is greater than the value of the depth parameter, no query result is returned.

The value can be:

  • 1–65535: maximum number of levels of data that you can query. Figure 1 shows the data levels. depth=1 indicates that the target data is obtained.

  • unbounded: All child nodes are queried. unbounded is the default value.
Figure 1 Example of data levels
Example 1 (XML format): If you want to view all child nodes, specify depth as unbounded or leave it unspecified.

  • Request

    GET /restconf/data/huawei-aaa:aaa/domains?depth=unbounded  HTTP/1.1
Host: X.X.X.X
Accept: application/yang-data+xml
Content-Type: application/yang-data+xml
Content-Length: 0
Authorization: Basic YXBpLWFkbWluOkFkbWluQDEyMw==

  • Response

    HTTP/1.1 200 OK
Date: Wed, 18 Apr 2022 12:00:00 GMT
Content-Type: application/yang-data+xml
Content-Length: 614

<?xml version="1.0" encoding="UTF-8"?>
    <domains xmlns="urn:huawei:yang:huawei-aaa">
      <domain>
        <name>default</name>
        <authen-scheme-name>default</authen-scheme-name>
        <acct-scheme-name>default</acct-scheme-name>
        <state>active</state>
        <statistics-enable>false</statistics-enable>
      </domain>
      <domain>
        <name>default_admin</name>
        <authen-scheme-name>default</authen-scheme-name>
        <acct-scheme-name>default</acct-scheme-name>
        <state>active</state>
        <statistics-enable>false</statistics-enable>
      </domain>
</domains>
Example 2 (XML format): If you need to confirm whether one or more pieces of data exist in the specified target data, specify depth as 1.

  • Request

    GET /restconf/data/huawei-aaa:aaa/domains?depth=1  HTTP/1.1
Host: X.X.X.X
Accept: application/yang-data+xml
Content-Type: application/yang-data+xml
Content-Length: 84
Authorization: Basic YXBpLWFkbWluOkFkbWluQDEyMw==

  • Response

    HTTP/1.1 200 OK
Date: Wed, 18 Apr 2022 12:00:00 GMT
Content-Type: application/yang-data+xml
Content-Length: 102

<?xml version="1.0" encoding="UTF-8"?>
<domains xmlns="urn:huawei:yang:huawei-aaa">
</domains>
