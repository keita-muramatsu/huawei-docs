Configuring ASPF/ALG for Well-Known Protocols

Context

To simplify the configuration, the ASPF and ALG functions use the same configuration command. You do not need to perform repeated configurations.

Procedure

  1. Enter the system view.

    system-view

  2. Configure the ASPF/ALG function.

    firewall detect protocol

    When configuring ASPF/ALG, pay attention to the following points:

    • If ASPF/ALG processing is required for the traffic of multiple protocols, run this command for each involved protocol.

    • The ASPF/ALG function (for SIP) configured using the firewall detect sip command takes effect only for UDP-based SIP traffic.

    • Enable the ASPF/ALG function for a specific protocol as required. For the protocols that do not require the ASPF/ALG function, disable the function in a timely manner.

Verifying the Configuration

Run the display firewall detect global command to check the ASPF/ALG configuration.
