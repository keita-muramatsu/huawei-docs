Configuring a CAPWAP Source Interface or Source Address

Prerequisites

Before configuring a CAPWAP source interface, you have completed the following task:

Create a VLANIF or loopback interface and configure its IP address.

Context

Each WAC requires the configuration of one or two IP addresses, VLANIF interfaces, or loopback interfaces. In this manner, APs managed by the WAC can learn the specified IP address or the IP address of the specified interface to set up a CAPWAP tunnel with the WAC. This specified IP address or interface is called the source address or source interface. CAPWAP tunnels support IPv4/IPv6 dual-stack communication. You can configure both an IPv4 source address (or source interface) and an IPv6 source address (or source interface) for the WAC to establish CAPWAP tunnels with IPv4 and IPv6 APs simultaneously. In non-dual-stack scenarios, the WAC must be configured with a unique source address or source interface. In CAPWAP dual-stack scenarios, the WAC must be configured with an IPv4 source address (or source interface) and an IPv6 source address (or source interface). In CAPWAP dual-stack scenarios, the source address and source interface cannot be configured together.

Upon the first configuration, the CAPWAP source interface or source address can be successfully configured only when all of the following configurations exist: PSK used for DTLS encryption, the user name and password for AP login, and the global login password for the offline management VAP. If any of these configurations does not exist, the system prompts you to supplement the configurations first.

When configuring a CAPWAP source interface or source address, pay attention to the following:

  • A maximum of one IPv4 address and one IPv6 address can be configured for the CAPWAP source interface or as the source address.
  • VLANIF and loopback interfaces are applicable to different scenarios.
    • VLANIF interface: applies to the scenario where the APs that associate with the WAC belong to the same management VLAN.
    • Loopback interface: applies to the scenario where the APs that associate with the WAC belong to different management VLANs.

      When APs belong to multiple management VLANs, the WAC must have multiple VLANIF interfaces configured. If one of the VLANIF interfaces is configured as the source interface, all APs cannot work properly if the source interface fails. This problem will not occur when a loopback interface is configured as the source interface. A loopback interface remains up after being created. When a loopback interface is configured as the source interface and a VLANIF interface becomes faulty, only the AP that connects to the VLANIF interface cannot go online. This configuration improves network reliability.

  • If a VLANIF or loopback interface has been configured as the CAPWAP source interface, the following changes are not allowed on this interface:
    • Adding another IP address For example, if only one IPv4 address is configured on an interface, no IPv6 address can be configured on the interface; and vice versa.
    • Deleting or changing any IP address on the interface
    • Deleting the interface
  • The IP address configured as the CAPWAP source address cannot be modified or deleted.

  • To change the source interface or source address, run the undo capwap source interface { loopback loopback-number | vlanif vlan-id } or undo capwap source { ip-address ip-address | ipv6-address ipv6-address } command first to delete the source interface or source address.

  • After the undo capwap source interface { loopback loopback-number | vlanif vlan-id } or undo capwap source { ip-address ip-address | ipv6-address ipv6-address } command is executed, all online APs on the WAC go offline. Exercise caution when performing this operation.

  • During the configuration of the CAPWAP source interface or source address, if the user name and password for logging in to APs have not been changed on the WAC, the system prompts you to change the user name and password, ensuring AP access security.

Procedure

  1. Enter the system view.

    system-view

  2. Configure the CAPWAP source interface or source address as required.

    • Configure the source interface or source address of the IPv4 type.
      • A VLANIF or loopback interface can be configured as the source interface so that the IPv4 address of the source interface is used as the source address.
        capwap source interface vlanif vlan-id

        Or

        capwap source interface loopback loopback-number

        Or

        capwap source ip-address ip-address
    • Configure the source interface or source address of the IPv6 type.
      • A VLANIF or loopback interface can be configured as the source interface so that the IPv6 address of the source interface is used as the source address.
        1. Enable IPv6 for CAPWAP links.
          capwap ipv6 enable

          By default, a CAPWAP link works in IPv4 single-stack mode.

        2. Configure a VLANIF or loopback interface as the source interface, or use the IPv6 address of the source interface as the source address.
          capwap source interface vlanif vlan-id

          Or

          capwap source interface loopback loopback-number

          Or

          capwap source ipv6-address ipv6-address
    • Configure an IPv4/IPv6 dual-stack source address or source interface.
      • Create an interface, and use the interface as the source interface or its address as the source address.
        1. Create a VLANIF or a loopback interface, and configure an IPv4 address and an IPv6 address for the interface.
        2. Enable IPv4/IPv6 dual-stack for CAPWAP links.
          capwap double-stack enable

          By default, a CAPWAP link works in IPv4 single-stack mode.

        3. Configure a VLANIF or loopback interface as the source interface, or use the address of the source interface as the source address.

          capwap source interface vlanif vlan-id

          Or

          capwap source interface loopback loopback-number

          Or

          capwap source ip-address ip-address
capwap source ipv6-address ipv6-address
      • Create two interfaces, and use the two interfaces as the source interfaces or use their addresses as the source addresses.
        1. Create two interfaces (two VLANIF interfaces, two loopback interfaces, or one VLANIF interface and one loopback interface), and configure an IPv4 address for one interface and an IPv6 address for the other interface.
        2. Enable IPv4/IPv6 dual-stack for CAPWAP links.
          capwap double-stack enable

          By default, a CAPWAP link works in IPv4 single-stack mode.

        3. Configure source interfaces or source addresses.

          Configure two VLANIF interfaces as the source interfaces.

          capwap source interface vlanif vlan-id1
capwap source interface vlanif vlan-id2

          Configure two loopback interfaces as the source interfaces.

          capwap source interface loopback loopback-number1
capwap source interface loopback loopback-number2

          Configure the VLANIF interface and loopback interface as the source interfaces.

          capwap source interface vlanif vlan-id
capwap source interface loopback loopback-number

          Configure the IPv4 and IPv6 addresses of the interface as the source addresses.

          capwap source ip-address ip-address
capwap source ipv6-address ipv6-address

  3. Optional: Configure the IP version for APs to go online.

    When an AP goes online, the device checks the IP version of the AP. If the IP version number does not match, the AP cannot go online. CAPWAP tunnels support both IPv4 and IPv6. However, it is not recommended that an area contain both IPv4 and IPv6 APs. You are advised to group AP group by area and restrict AP versions based on AP groups. If both IPv4 and IPv6 APs exist in an area, services such as band steering, smart roaming, and load balancing are affected.

    wlan
ap-group name group-name
ap ip version { all | ipv4 | ipv6 }

    By default, an AP can use IPv4 or IPv6 to go online.

Verifying the Configuration

Run the display capwap configuration command to check the CAPWAP configuration.

Run the display ap ip-version-conflict status { all | backup-ac | log-server | wmi-server | spectrum-server } command to check whether the IP version of APs is the same as that of the standby AC and other third-party servers.
