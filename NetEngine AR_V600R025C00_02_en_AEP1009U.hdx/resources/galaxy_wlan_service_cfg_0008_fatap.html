Air Scan Profile

Overview

An air scan profile enables APs to periodically scan surrounding radio signals and report the collected information to the WAC.

The configuration in an air scan profile can take effect only after the profile is bound to radios in an AP group or on an AP.

Creating a Profile

  1. Enter the WLAN view.

    system-view
wlan

  2. Create an air scan profile.

    air-scan-profile name profile-name

Applying a Profile

  1. Enter the WLAN view.

    system-view
wlan

  2. Bind an air scan profile to an existing radio profile.
    • Bind an air scan profile to a 2.4 GHz radio profile.
      radio-2g-profile name profile-name
air-scan-profile profile-name
quit
    • Bind an air scan profile to a 5 GHz radio profile.
      radio-5g-profile name profile-name
air-scan-profile profile-name
quit
  3. Bind a radio profile to an AP group or a single AP. Perform one of the following steps:
    • Bind a radio profile to an AP group.
      ap-group name group-name
radio-2g-profile profile-name radio { radio-id | all }
radio-5g-profile profile-name radio { radio-id | all }
    • Bind a radio profile to an AP.
      ap-id ap-id
radio-2g-profile profile-name radio { radio-id | all }
radio-5g-profile profile-name radio { radio-id | all }
    • Bind a radio profile to radios on APs in an AP group.
      ap-group name group-name
radio radio-id
radio-2g-profile profile-name
radio-5g-profile profile-name
    • Bind a radio profile to radios on an AP.
      ap-id ap-id
radio radio-id
radio-2g-profile profile-name
radio-5g-profile profile-name
