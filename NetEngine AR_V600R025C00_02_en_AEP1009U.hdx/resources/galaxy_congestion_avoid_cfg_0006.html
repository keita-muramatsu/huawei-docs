Configuring WRED for Queues on an Interface

Context

WRED randomly discards packets based on WRED parameter settings, preventing global TCP synchronization and ensuring packets with higher priorities are less likely to be discarded.

In the congestion avoidance mechanism, colors (green, yellow, and red) are not used to discard packets based on priorities.

You can apply a drop profile to a queue on an interface to implement congestion avoidance for the queue.

Procedure

  1. Enter the system view.

    system-view

  2. Create a WRED drop profile and enter the WRED drop profile view.

    drop-profile drop-profile-name

    By default, a WRED drop profile named default exists on the device.

    A maximum of 63 WRED drop profiles, including the default drop profile, can be configured on the device. The default drop profile cannot be deleted, and only parameters in the profile can be modified.

  3. Set WRED parameters.

    • Configure the current WRED drop profile to drop packets based on the default priority.
      wred blind
color blind low-limit low-limit-percentage high-limit high-limit-percentage discard-percentage discard-percentage

      The default mode is blind and does not need to be changed. By default, the upper drop threshold in percentage, lower drop threshold in percentage, and maximum drop probability in a WRED drop profile are all 100.

    • Configure the current WRED drop profile to drop packets based on the DSCP priority.
      wred dscp
dscp { start-dscp-value [ to end-dscp-value ] } &<1-10> low-limit low-limit-percentage high-limit high-limit-percentage discard-percentage discard-percentage

      The default mode is blind. Before configuring a WRED drop profile in DSCP mode, change to DSCP mode first. By default, the upper drop threshold in percentage, lower drop threshold in percentage, and maximum drop probability in a WRED drop profile are all 100.

    For the AR8700 series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, and AR6710-L50T2X4-T, the default mode of a WRED drop profile is blind and cannot be configured. Therefore, only WRED parameters in blind mode can be configured.

    Only the AR8100 series, AR6700-H series, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6710-L14T2X4, and AR5700 series support the setting of WRED parameters in DSCP mode.

  4. Exit the WRED drop profile view.

    quit

  5. Enter the interface view.

    interface { interface-type interface-number | interface-name }

  6. (Optional) Enable the queue capability on the interface.

    qos queue-scheduling enable

    By default, the queue capability is disabled on an interface.

    After the queue capability is enabled on an Eth-Trunk interface or a tunnel interface, the loopback function is enabled by default.

    For other physical interfaces, when the queue capability is enabled on an interface, it is not enabled on a sub-interface of the interface. If the queue capability also needs to be used on a sub-interface, enable it in the sub-interface view.

    • Queue resources are not allocated to physical and logical interfaces by default for the AR5700 series, AR6710-L14T2X4, AR6710-L8T3TS1X2, and AR6710-L8T3TS1X2-T. This command can be configured on physical and logical interfaces. For other models, queue resources are allocated to physical interfaces, but are not allocated to logical interfaces by default. Therefore, this command can be configured only on logical interfaces.
    • This command cannot be configured on an MP-group interface or on a serial interface created on an E1 card. If queue resources are insufficient, creating these two types of interfaces will cause queue-related functions on the interfaces to become invalid. In this case, you need to create the interfaces again when queue resources are sufficient.

  7. Apply the WRED drop profile to a queue on the interface.

    qos queue queue-index wred drop-profile-name

  8. Exit the interface view.

    quit
