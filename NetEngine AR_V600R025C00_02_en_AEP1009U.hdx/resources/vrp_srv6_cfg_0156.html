Collecting SRv6 TE Policy Traffic Statistics

Context

SRv6 TE Policy traffic statistics collection enables you to collect statistics about the traffic forwarded through a specified or all SRv6 TE Policies.

This function supports both global configuration and single-policy configuration. If global configuration and single-policy configuration both exist, the single-policy configuration takes effect.

Procedure

  1. Global configuration
    1. Enter the system view.

      system-view

    2. Enter the Segment Routing IPv6 view.

      segment-routing ipv6

    3. Enable traffic statistics collection for all SRv6 TE Policies.

      srv6-te-policy traffic-statistics enable

  2. Single-policy configuration
    1. Enter the system view.

      system-view

    2. Enter the Segment Routing IPv6 view.

      segment-routing ipv6

    3. Enter the SRv6 TE Policy view.

      srv6-te policy name-value

    4. Enable or disable traffic statistics collection for the SRv6 TE Policy.

      traffic-statistics { enable | disable }

Verifying the Configuration

After configuring SRv6 TE Policy traffic statistics collection, run the display srv6-te policy traffic-statistics [ endpoint ipv6-address color color-value | policy-name name-value | binding-sid binding-sid ] command to check the traffic statistics about a specified SRv6 TE Policy.

Follow-up Procedure

To clear existing SRv6 TE Policy traffic statistics, run the reset srv6-te policy traffic-statistics [ endpoint ipv6-address color color-value | policy-name name-value | binding-sid binding-sid ] command.
