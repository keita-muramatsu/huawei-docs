Viewing the License Status

Run the display license state command to check the status of the license on the device.

<HUAWEI> display license state
Info: Current license state is Demo. The license for the current configuration will expire in 22 day(s).
Table 2 Description of the display license state command output

Item

Description

state
  • Demo: trial state.
  • Normal: indicates the normal state.
  • Default: The device is in the default state when no license is authorized. If no license file is activated after delivery or the license is not reactivated after the grace period expires, the license is in this state.
  • Trial: indicates the keep-alive state.
  • Emergency: emergency state.
