Configuring OWE Authentication

Context

OWE authentication is a Wi-Fi Enhanced Open authentication mode that allows users to access a Wi-Fi network without entering the password. In OWE authentication mode, a device uses the AES encryption algorithm to encrypt data on the network, thereby protecting data exchange between STAs and the Wi-Fi network.

OWE authentication or its transition mode automatically enables the PMF function in mandatory mode. That is, the pmf { optional | mandatory } command configuration does not take effect in OWE authentication or its transition mode.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a security profile and enter its view.

    security-profile name profile-name

    By default, the security profile default exists in the system.

  4. Configure OWE authentication in a security policy.

    security enhanced-open aes

    By default, no security policy is configured.
