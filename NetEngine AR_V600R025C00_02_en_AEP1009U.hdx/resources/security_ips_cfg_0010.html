Applying a Default IPS Profile

Context

To simplify the configuration, the device provides multiple IPS profiles for different application scenarios by default. Table 1 describes default IPS profiles. To apply a default IPS profile, you only need to reference it in a security policy. Default IPS profiles cannot be modified or deleted.

If you are familiar with networks and services, you can also manually create an IPS profile by referring to Manually Creating an IPS Profile and configure a signature filter to filter the required signatures.

You can run the display profile type ips name name command to check the configuration in the default profile. When configuring a security policy to reference a default profile using the CLI, you must enter the complete profile name (for example, default). Otherwise, the profile cannot be referenced.

Procedure

  1. Enter the system view.

    system-view

  2. Configure the service performance mode of the device.

    forward performance mode { routing | security | security-enhance }

    To enable security services, you are advised to switch the device's service performance mode to the secure forwarding mode (security) or enhanced security mode (security-enhance).

    You can run the display forward performance mode command to check the current service performance mode of the device.

    Some models do not support this command or some parameters. For details, see the command reference.

  3. Enter the security policy view.

    security-policy

  4. Create a security policy rule and enter its view.

    rule name rule-name

  5. Reference a default IPS profile in the security policy.

    profile ips profile-name

    This section describes only the procedure for referencing a default IPS profile in a security policy. For details about matching conditions in a security policy, see "Security Policy Configuration" in CLI Configuration Guide > Security Configuration.

  6. Set the action of the security policy rule to permit.

    action permit

  7. Return to the system view.

    quit
quit
