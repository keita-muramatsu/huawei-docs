Configuring MQC-based Redirection

Context

After redirection is configured, the device can redirect packets matching traffic classification rules to a specified next-hop address.

For details about MQC-related configuration precautions, see "Configuration Precautions for MQC" in MQC Configuration.

Procedure

  1. Configure a traffic classifier.

    For details about how to configure a traffic classifier, see Configuring a Traffic Classifier in "MQC Configuration".

  2. Configure a traffic behavior.
    1. Enter the system view.

      system-view

    2. Create a traffic behavior and enter the traffic behavior view, or enter the view of an existing traffic behavior.

      traffic behavior behavior-name

    3. Configure a redirection action.

      • Redirection to an interface

        redirect interface { dialer dialer-id | dialer-name | cellular interface-name | tunnel tunnel-id  | interface-name } [ track { nqa admin-name test-name | ip-route ip-address { ip-address-mask | mask-length } | ipv6-route ipv6-address ipv6-mask-length } ] [ fail-action discard ]

        Generally, if a packet needs to be redirected to the outbound interface, the outbound interface needs to be added to the VLAN corresponding to the packet.

      • Redirection to a backup interface
        redirect backup-interface { interface-type interface-number | interface-name }
      • Redirection to a single next-hop IP address
        redirect [ vpn-instance vpn-instance-name ] nexthop { ip-address [ track { nqa admin-name test-name | ip-route ip-address { ip-address-mask | mask-length } | vrrp vrid interface interface-type interface-number | interface interface-type interface-number } ] } &<1-2> [ fail-action discard ]
        redirect ipv6 [ vpn-instance vpn-instance-name ] nexthop { ipv6-address [ track { nqa admin-name test-name | ipv6-route ipv6-address ipv6-mask-length } ] } &<1-2> [ fail-action discard ]
      • Redirection to a backup next-hop address
        redirect [ vpn-instance vpn-instance-name ] backup-nexthop ip-address [ track { interface interface-type interface-number | nqa admin-name test-name } ]
      • Redirection to a site
        redirect site siteid
      • Redirection to a backup site
        redirect backup-site siteid

    4. Exit the traffic behavior view.

      quit

  3. Configure a traffic policy.
    1. Create a traffic policy and enter the traffic policy view, or enter the view of an existing traffic policy.

      traffic policy policy-name

    2. Bind a traffic behavior and a traffic classifier to the traffic policy.

      classifier classifier-name behavior behavior-name [ precedence precedence-value ]

    3. Exit the traffic policy view.

      quit

  4. Apply the traffic policy.

    The application direction supported by a traffic policy is related to the redirection action. For details, see "Configuration Precautions for Redirection."

    • Apply a traffic policy to an interface.
      1. Enter the interface view.
        interface interface-type interface-number
      2. Apply a traffic policy to the interface.
        traffic-policy policy-name { inbound | outbound } [ preprocess | firstprocess  ]
        traffic-policy policy-name inbound decap-process

        If the decap-process parameter is specified, you need to run the qos car inbound decap-process command in the interface view to configure the bandwidth limit for the decapsulation service in the inbound direction of the interface.

      3. Exit the interface view.
        quit

Verifying the Configuration

Operation

Command

Check the configured traffic classifiers.

display traffic classifier [ classifier-name ]

Check the configured traffic behaviors.

display traffic behavior [ behavior-name ]

Check the configured traffic policy.

display traffic policy [ policy-name [ classifier classifier-name ] ]

Check the traffic policy application records.

display traffic-policy applied-record

Check TCAM delivery failures.

display system tcam fail-record [ slot slot-id ]

Check the group indexes and rule counts occupied by different services.

display system tcam service brief [ slot slot-id ]

display system tcam service { cpcar slot slot-id | service-name slot slot-id [ chip chip-id ] }

Check the traffic policy application records.

display system tcam service traffic-policy

Check information about matched rules.

display system tcam match-rules slot slot-id

Check statistics on packets that match a traffic policy.

display traffic-policy statistics

Check matching fields and actions supported by a traffic policy in each view.

display system tcam acl group-information
