Configuring Intra-WAC Roaming

Prerequisites

Before configuring intra-WAC roaming, configure basic WLAN services by referring to Configuring Basic WLAN STA Access Functions and ensure each AP participating in roaming meets the following conditions:

  • Associated to the same WAC.
  • Configured with the same security policy.
  • Configured with the same SSID.
  • With the same authentication policy and authorization policy delivered by the WAC if the network access control (NAC) service is configured

Context

During intra-WAC roaming, a STA is associated with the same WAC before and after roaming. One WAC can meet the coverage requirements of a small WLAN. When a STA roams in the coverage area of the WAC, services are not interrupted.

Procedure

  1. After the pre-configuration tasks are complete, the WAC supports intra-WAC roaming without any extra configurations. A STA can roam between APs connected to this WAC.
  2. (Optional) Configure disabling of Layer 3 roaming as required.
    1. Enter the system view.

      system-view

    2. Enter the WLAN view.

      wlan

    3. Create a VAP profile and enter its view.

      vap-profile name profile-name

      By default, the VAP profile default exists on the device.

    4. Disable Layer 3 roaming.

      You can disable Layer 3 roaming on a device for network isolation so that STAs cannot roam between different subnets.

      layer3-roam disable

      By default, Layer 3 roaming is enabled on the device.

    5. Apply a VAP profile. For details, see Applying a Profile.

Verifying the Configuration

  • Run the display vap-profile { all | name profile-name } command to check the configuration and reference information about a VAP profile.
  • Run the display references vap-profile name profile-name command to check reference information about a VAP profile.
