Deleting MAC Address Entries

During routine maintenance, you can run the following commands to delete MAC address entries, including both static and dynamic MAC address entries.

Be careful when deleting MAC address entries. Deleted MAC address entries cannot be restored.

Table 1 Commands used to delete MAC address entries

Operation

View

Command

Delete all static and blackhole MAC address entries.

System view

undo mac-address all

Delete MAC address entries of a VLAN.

undo mac-address vlan vlan-id

Delete MAC address entries of an interface.

undo mac-address interface-type interface-number

Delete all static MAC address entries.

undo mac-address static

Delete all blackhole MAC address entries.

undo mac-address blackhole

Delete all MAC address learning limit rules.

undo mac-address limit all

Delete all dynamic MAC address entries.

User view

reset mac-address
