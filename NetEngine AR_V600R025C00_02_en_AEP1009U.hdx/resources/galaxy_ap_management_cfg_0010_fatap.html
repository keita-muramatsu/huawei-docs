Preparing for AP Onboarding

Context

Before configuring AP onboarding, you have completed the following tasks:
  • Establish CAPWAP tunnels between the WAC and APs. For details, see Configuring CAPWAP.
  • Configure the country code. For details, see "Configuring the Country Code" in CLI Configuration Guide > WLAN Configuration > RRM Configuration.

Before upgrading APs during the AP onboarding process, perform the operations described in Configuring Automatic AP Upgrade.
