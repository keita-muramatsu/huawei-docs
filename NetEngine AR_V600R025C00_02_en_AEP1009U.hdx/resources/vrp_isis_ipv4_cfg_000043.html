Removing the Limit on the Maximum Number of IS-IS Interfaces Supported by a Device

Prerequisites

Before removing the limit on the maximum number of IS-IS interfaces supported by the device, you have completed the following task:

  • Configure basic IS-IS functions.

Context

A limit on the maximum number of IS-IS interfaces supported can be configured on each routing router. To remove such a limit, you can run the isis interface limit disable command.

Procedure

  1. Enter the system view.

    system-view

  2. Remove the limit on the maximum number of IS-IS interfaces supported by the device.

    isis interface limit disable
