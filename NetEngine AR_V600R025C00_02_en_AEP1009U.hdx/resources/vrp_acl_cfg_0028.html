Example for Using a Layer 2 ACL to Prevent a Specified User from Accessing the Internet

Networking Requirements

As shown in Figure 1, the switch functions as a gateway and connects to PCs. The routes between the switch and subnets are reachable. The user of PC1 (MAC address: 00e0-fc12-3456) is an unauthorized user and is not allowed to access the Internet.

Figure 1 Network diagram of using a Layer 2 ACL to prevent a specified user from accessing the Internet

Configuration Roadmap

The configuration roadmap is as follows:

  1. Configure a Layer 2 ACL and ACL-based traffic classifier to filter packets with the MAC address 00e0-ffc12-3456, thereby preventing the corresponding user from accessing the Internet.
  2. Configure a traffic behavior to deny the packets matching the ACL.
  3. Configure and apply a traffic policy for the ACL and traffic behavior to take effect.

Procedure

  1. Configure a Layer 2 ACL.

    # Configure a Layer 2 ACL that meets requirements.

    <HUAWEI> system-view
[HUAWEI] sysname Switch
[Switch] acl 4000
[Switch-acl-L2-4000] rule deny source-mac 00e0-fc12-3456
[Switch-acl-L2-4000] quit

  2. Configure a Layer 2 ACL-based traffic classifier.

    # Configure a traffic classifier named tc1 to classify packets that match ACL 4000.

    [Switch] traffic classifier tc1
[Switch-classifier-tc1] if-match acl 4000
[Switch-classifier-tc1] quit

  3. Configure a traffic behavior.

    # Configure a traffic behavior named tb1 to deny packets.

    [Switch] traffic behavior tb1
[Switch-behavior-tb1] deny
[Switch-behavior-tb1] quit

  4. Configure a traffic policy.

    # Configure a traffic policy named tp1 and associate tc1 and tb1 with the traffic policy.

    [Switch] traffic policy tp1
[Switch-trafficpolicy-tp1] classifier tc1 behavior tb1
[Switch-trafficpolicy-tp1] quit

  5. Apply the traffic policy.

    # Apply the traffic policy tp1 to the inbound direction of 10GE0/0/4 (because packets from PC1 enter the switch through 10GE0/0/4 and flow to the Internet).

    [Switch] interface 10GE 0/0/4
[Switch-10GE0/0/4] traffic-policy tp1 inbound
[Switch-10GE0/0/4] quit

  6. Verify the configuration.

    # Check the ACL rule configuration.

    [Switch] display acl 4000
L2 ACL 4000, 1 rule                                                              
Acl's step is 5                                                                  
 rule 5 deny source-mac 00e0-fc12-3456 (0 times matched)

    # Check the traffic classifier configuration.

    [Switch] display traffic classifier
  Traffic Classifier Information:   
   Classifier: tc1     
     Type: OR     
     Rule(s) :
        if-match acl 4000                                                                                   

Total classifier number is 1

    # Check the traffic policy configuration.

    [Switch] display traffic policy tp1
  Traffic Policy Information:                                         
    Policy: tp1                                                                      
      Classifier: tc1                                                                 
        Type: OR                                                                   
      Behavior: tb1                                                                 
        Deny

    # Check the traffic policy application records.

    [Switch] display traffic-policy applied-record
Total record : 1                                                                                                                                    
-------------------------------------------------------------                                                                                     
 Policy Type/Name:    Apply Parameter      Slot       State
--------------------------------------------------------------
   tp1                10GE1/0/5(IN)       1/5      success      
--------------------------------------------------------------

    # Check that the user with the MAC address 00e0-fc12-3456 cannot access the Internet.

Configuration Scripts

Switch
# 
sysname Switch 
# 
acl number 4000  
 rule 5 deny source-mac 00e0-fc12-3456
# 
traffic classifier tc1 type or   
 if-match acl 4000 
# 
traffic behavior tb1  
 deny 
# 
traffic policy tp1 
 classifier tc1 behavior tb1 precedence 5
# 
interface 10GE0/0/4  
 traffic-policy tp1 inbound   
# 
return
