Understanding Option Parameters

The DHCP server uses Option parameters to transmit network configurations to devices to implement automatic configuration during ZTP.

The device sends a DHCP Discover message that carries DHCPv4 Option parameters when the DHCP Discover phase starts in DHCPv4 scenarios. Table 1 describes the parameters.

Table 2 describes the DHCPv4 Option parameters to be configured on the DHCPv4 server.

  • The DHCP server does not support authentication and may be spoofed. You are advised to use a trusted DHCP server for deployment on a secure network.
  • DHCP is a non-encrypted transmission protocol, so the user name and password of the file server carried by DHCP Option 66 and Option 67 parameters have security risks. You are advised to use this protocol on a secure network.

Option

Mandatory or Not

Function

Option 6

No

IP address of the DNS server.

A DNS server is required if a domain name (for example, www.ztp.com) is specified as the host name of the file server. It is not required if an IP address is specified as the host name.

Option 7

No

IPv4 address of the Syslog server.

Option 66

No

Host name of the intermediate file server.

The following file servers are supported:
  • SFTP server, whose address is in sftp://username:password@hostname:port or sftp-sha1://username:password@hostname:port format
  • HTTP server, whose address is in http://hostname:port format if no user name or password is available and is in http://username:password@hostname:port format if a user name and a password are available
  • TFTP server, whose address is in tftp://hostname format
  • FTP server, whose address is in ftp://username:password@hostname:port format

In this format, port is optional and hostname can be set to a domain name or an IP address. If hostname is set to a domain name, a DNS server is required.

NOTE:
  • The configured server URL cannot contain forward slashes (/) or number signs (#).
  • The domain name of a server is in the standard URL format.
  • SFTP is recommended because it is more secure than TFTP, FTP, and HTTP.
  • sftp-sha1 indicates that the unconfigured device functioning as a DHCP client supports the SHA1 algorithm when the SFTP server is used.

Option 150

No

Host name of the intermediate file server.

This field can be set to the IP address of the TFTP server only. The value format is hostname, for example, 10.1.1.1.

NOTE:

If both Option 66 and Option 150 are configured, Option 66 is preferentially parsed.

Option 67

Yes

Name of the intermediate file.

The value format is path/filename, whereby:

  • path may or may not contain the host name of the intermediate file server. For example, the value can be /script/ztp_script.py without a host name, or sftp://sftp_user:Hyx_Hy1234@10.1.3.2/script/ztp_script.py with a host name.
  • filename can be ***.ini or ***.py, and has a maximum length of 64 characters.
NOTE:
  • If the path without a host name is used, you must set Option 66. If the server type is TFTP server, you can also set Option 150.
  • If the path with a host name is used, see the description of Option 66 for the format of the server host name.
  • The configured intermediate file name cannot contain forward slashes (/) or number signs (#).
