Configuring the Maximum Rate at Which IPv6 Host Packets Are Processed

Context

If certain types of packets on a live-network host are heavy and packet loss occurs, you can increase the rate so that the host can process more packets. Conversely, if the live network is attacked by certain types of packets, you can reduce the maximum rate at which these packets are processed to protect the CPU.

Procedure

  1. Enter the system view.

    system-view

  2. Configure the maximum rate at which IPv6 host packets are processed.

    host-packet ipv6 rate-limit { hop-limit-exceeded | port-unreachable | icmp-echo } rate-value all
