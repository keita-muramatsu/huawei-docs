Example for Configuring a WPA/WPA2-PPSK Security Policy

Networking Requirements

A hotel needs to deploy a simple and secure network to provide wireless Internet access. WPA/WPA2-PPSK authentication is used to allow STAs to use different passwords. As shown in Figure 1, STAs connected to the same SSID use different passwords to access the network. STA1 and STA2 are different STAs of the same user and share the same password, and the password of STA3 is valid until January 1, 2023. Before the configuration, ensure that the network connectivity is normal and APs can go online. For details about the basic networking example, see Configuration Examples for WLAN STA Management.

To complete the configuration, you need the following data:

  • AP group name: ap-group1
  • SSID profile name: wlan-ssid; SSID name: wlan-net
  • Security profile name: wlan-security; security policy: WPA-WPA2+PPSK+AES
  • Passwords of STA1 and STA2: YsHsjx_202206; password of STA3: YsHsjx_202207; password of STA4: YsHsjx_202208
  • VAP profile name: wlan-vap; service VLAN: VLAN 101
Figure 1 Network diagram of the WPA2-PPSK-AES security policy configuration

In this example, interface1, interface2, and interface3 represent 10GE0/0/1, 10GE0/0/2, and 10GE0/0/3, respectively.


Configuration Roadmap

  1. Configure STA access services so that STAs can access the WLAN properly.
  2. Configure a WPA-WPA2 security policy using PPSK authentication and AES encryption in a security profile.

Precautions

  • No ACK mechanism is available for multicast packet transmission over unstable wireless links of air interfaces. For this reason, multicast packets are usually sent at low rates to ensure stable transmission. However, if a large number of multicast packets are sent from the network side, air interfaces may be congested. Therefore, you are advised to configure multicast packet suppression to reduce the impact of numerous low-rate multicast packets on the wireless network. Exercise caution when configuring the rate limit if there are multicast services on the network, as this may affect the multicast services.
    • In direct forwarding mode, you are advised to configure multicast packet suppression on the interfaces of a switch connected to APs.
    For details about the configuration method, see How Do I Configure Multicast Packet Suppression to Reduce Impact of a Large Number of Low-Rate Multicast Packets on the Wireless Network?

  • The port isolation configuration is recommended on the ports of the device directly connected to APs. If port isolation is not configured and direct forwarding is used, a large number of unnecessary broadcast packets may be generated in the VLAN, blocking the network and degrading user experience.

Procedure

  1. Create the security profile wlan-security and configure a WPA-WPA2+PPSK+AES security policy in the profile.

    <HUAWEI> system-view
[HUAWEI] sysname WAC
[WAC] wlan
[WAC-wlan] security-profile name wlan-security
[WAC-wlan-sec-prof-wlan-security] security wpa-wpa2 ppsk aes
[WAC-wlan-sec-prof-wlan-security] quit

  2. Create the SSID profile wlan-ssid and set the SSID name to wlan-net.

    [WAC-wlan] ssid-profile name wlan-ssid
[WAC-wlan-ssid-prof-wlan-ssid] ssid wlan-net
[WAC-wlan-ssid-prof-wlan-ssid] quit

  3. Create the VAP profile wlan-vap, set the service data forwarding mode and service VLAN, and bind the security profile and SSID profile to the VAP profile.

    [WAC-wlan] vap-profile name wlan-vap
[WAC-wlan-vap-prof-wlan-vap] service-vlan vlan-id 101
[WAC-wlan-vap-prof-wlan-vap] security-profile wlan-security
[WAC-wlan-vap-prof-wlan-vap] ssid-profile wlan-ssid
[WAC-wlan-vap-prof-wlan-vap] quit

  4. Bind the VAP profile wlan-vap to radios 0 and 1 of APs in the AP group ap-group1.

    [WAC-wlan] ap-group name ap-group1
[WAC-wlan-ap-group-ap-group1] vap-profile wlan-vap wlan 1 radio 0
[WAC-wlan-ap-group-ap-group1] vap-profile wlan-vap wlan 1 radio 1
[WAC-wlan-ap-group-ap-group1] quit

  5. Create a PPSK user and set parameters. Set the access password of STA1 and STA2 to YsHsjx_202206. Set the access password of STA3 to YsHsjx_202207, and set the expiration date of the PPSK account to January 1, 2023. Set the access password of STA4 to YsHsjx_202208.

    [WAC-wlan] ppsk-user id 1 psk pass-phrase YsHsjx_202206
[WAC-wlan-ppsk-user-1] ssid wlan-net
[WAC-wlan-ppsk-user-1] mac-address 00e0-fc12-3451
[WAC-wlan-ppsk-user-1] mac-address 00e0-fc12-3452
[WAC-wlan-ppsk-user-1] quit
[WAC-wlan] ppsk-user id 2 psk pass-phrase YsHsjx_202207
[WAC-wlan-ppsk-user-2] ssid wlan-net
[WAC-wlan-ppsk-user-2] expire-date 2023/1/1
[WAC-wlan-ppsk-user-2] quit
[WAC-wlan] ppsk-user id 3 psk pass-phrase YsHsjx_202208
[WAC-wlan-ppsk-user-3] ssid wlan-net
[WAC-wlan-ppsk-user-3] quit
