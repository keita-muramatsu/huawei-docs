RADIUS or RADIUS and local authentication:

If a RADIUS authentication server is deployed on the network, you can configure RADIUS authentication. User information is then created and maintained on the RADIUS authentication server in a unified manner. When the RADIUS authentication server does not respond, the device can use the local authentication configuration to perform local authentication for users. This prevents user authentication failures if the connection between the device and RADIUS authentication server times out.

Privilege level authorization of administrators

The supported user privilege level authorization modes and authorization priorities are as follows:

  • If local authentication is used, the following administrator privilege levels can be configured, which are listed in descending order of priority:
    • Local user privilege level configured using the local-user privilege level command
    • Administrator privilege level configured using the admin-user privilege level command in the service scheme view
    • User privilege level configured using the user privilege command in the VTY user interface view
  • If remote authentication is used, the following administrator privilege levels can be configured, which are listed in descending order of priority. The privilege level authorized by the RADIUS or HWTACACS server has the highest priority.
    • User privilege level authorized by the server after the authentication succeeds
    • Administrator privilege level configured using the admin-user privilege level command in the service scheme view
    • User privilege level configured using the user privilege command in the VTY user interface view
  • If both remote authentication and local authentication are configured for a user and remote authentication takes precedence over local authentication: The administrator privilege level is the one used during remote authentication. If the remote server does not respond, local authentication is used. In this case, the administrator privilege level is the local user privilege level configured using the local-user privilege level command.

For details about how to configure an authorization scheme, see Configuring an Authorization Scheme.

In the following examples, only the user privilege level needs to be configured for local authentication on the device. For remote authentication, the user privilege level needs to be configured on the server.
