Configuring HDLC

HDLC configuration includes configuring HDLC encapsulation and optional parameters.

Application Scenarios

HDLC can be configured when a bit-oriented link layer protocol is required for synchronous transmission.

Prerequisites

Before configuring HDLC, you have completed the following task:

  • Set physical attributes for synchronous serial interfaces to ensure that the interfaces are physically up.

    Configuring HDLC as the Encapsulation Protocol of an Interface
    Configure HDLC as the link layer encapsulation protocol of an interface.
    (Optional) Configuring HDLC Link Status Monitoring
    To effectively monitor the status of HDLC links, configure the HDLC link status monitoring function.
    (Optional) Configuring HDLC Link Flapping Dampening
    To prevent frequent HDLC link flapping from causing network instability at the link layer and network layer, configure HDLC link flapping dampening.
    Verifying the Configuration
    After configuring HDLC, check information about the interface status, the link layer encapsulation protocol, and so on.
