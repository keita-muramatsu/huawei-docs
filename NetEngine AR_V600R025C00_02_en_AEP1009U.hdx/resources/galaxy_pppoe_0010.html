Configuring the PPPoE Client as the Authentication Peer

Context

After PPP authentication is configured on the PPPoE server, you need to configure the user name and password corresponding to the authentication mode of the PPPoE server on the PPPoE client.

When the PAP authentication mode is configured on the PPPoE server, the PPPoE client sends the user name and password for authentication. The authentication succeeds only when the user name and password sent by the PPPoE client are the same as those configured on the PPPoE server.

When the CHAP authentication mode is configured on the PPPoE server, there are two scenarios:

  • A user name is configured on the PPPoE server: In this case, the PPPoE client matches the user name received from the PPPoE server against that configured on itself. If they match, the PPPoE client sends a packet containing its authentication user name and password to the PPPoE server. The PPPoE server then compares the user name and password in the received packet with the local access user name and password. The authentication succeeds if they are consistent.
  • No user name is configured on the PPPoE server: In this case, the PPPoE client sends a packet containing its authentication user name and password to the PPPoE server. The PPPoE server then compares the user name and password in the received packet with the local access user name and password. The authentication succeeds if they are consistent.

A PPPoE client can send the configured user name and password to the PPPoE server for CHAP authentication whether or not a user name is configured on the PPPoE server.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the dialer interface view.

    interface dialer number

  3. Configure the authentication user name and password on the PPPoE client based on the authentication mode configured on the PPPoE server.

    • When the authentication mode on the PPPoE server is PAP:
      Configure the user name and password sent by the PPPoE client for PAP authentication.
      ppp pap local-user user-name password { simple password | cipher { password1 | password2 } }

      The user name and password for PAP authentication configured on the PPPoE client must be the same as the local access user name and password on the PPPoE server.

      By default, the local device sends a request without the user name and password to the remote device for PAP authentication.

    • When the authentication mode on the PPPoE server is CHAP and a user name is configured on the PPPoE server:
      1. Configure the CHAP user name used by the PPPoE client during CHAP authentication by the PPPoE server.
        ppp chap user user-name

        The CHAP user name configured on the PPPoE client must be the same as the CHAP user name configured on the PPPoE server.

      2. Return to the system view.
        quit
      3. Enter the AAA view.
        aaa
      4. Create a local access user and configure the local access user name.
        local-access-user user-name
      5. Configure the password for the local access user.
        password cipher password

        The local access user name configured on the PPPoE client must be the same as the local access user name and CHAP user name configured on the PPPoE server.

        The local access user password configured on the PPPoE client must be the same as that configured on the PPPoE server.

      6. Configure PPP as the access type of the local access user.
        service-type ppp
    • When the authentication mode on the PPPoE server is CHAP and no user name is configured on the PPPoE server:
      1. Configure the user name used by the PPPoE client during CHAP authentication by the PPPoE server.
        ppp chap user user-name
      2. Configure the password used by the PPPoE client during CHAP authentication by the PPPoE server.
        ppp chap password { simple password | cipher { password1 | password2 } }

        If simple is specified, the password is saved in plain text in the configuration file. This presents potential security risks. You are advised to specify cipher so that the password is saved in cipher text in the configuration file.

    If the authentication mode on the PPPoE server is unknown, you can configure both CHAP authentication and PAP authentication. The authentication mode on the PPPoE server will be used.
