Configuring a Source NAT Policy

Procedure

  1. Enter the system view.

    system-view

  2. Enter the view of the outbound interface of packets.

    interface interface-type interface-number

  3. Change the interface working mode to Layer 3.

    undo portswitch

    Determine whether to perform this step based on the current interface working mode.

  4. Enable the NAT function on the interface.

    nat enable

  5. Return to the system view.

    quit

  6. Enter the NAT policy view.

    nat-policy

  7. Create a NAT rule and enter the NAT rule view.

    rule name rule-name

    The NAT function is implemented using NAT rules in a NAT policy. A NAT rule must be created in order to specify the data flow that requires NAT translation and translation action. If multiple NAT rules are configured, the device matches packets against the rules from top to bottom in the NAT rule list until a match is found. As such, ensure that NAT rules are configured in the correct sequence.

  8. Configure matching conditions in the NAT rule.

    Matching conditions are optional configurations. By default, the matching condition of a NAT rule is any, indicating that all traffic matches this rule. If matching conditions are configured for a NAT rule, traffic must satisfy all matching conditions in order to match this rule.

    Table 1 Configuring matching conditions in the NAT rule

    Matching Condition

    Command

    Description

    Source IP address

    source-address { ipv4-address { ipv4-mask-length | mask mask-address | wildcard wildcard } | range ipv4-start-address ipv4-end-address | any }

    Configures the source IP addresses of traffic. You can exclude addresses from the address range that is to be translated.

    For example, source NAT translation is required for users on the 10.1.1.0/24 network segment, excluding the users from 10.1.1.2 to 10.1.1.5.

    [HUAWEI] nat-policy
[HUAWEI-policy-nat] rule name policy1
[HUAWEI-policy-nat-rule-policy1] source-address 10.1.1.0 24
[HUAWEI-policy-nat-rule-policy1] source-address-exclude range 10.1.1.2 10.1.1.5

    source-address-exclude { ipv4-address { ipv4-mask-length | mask mask-address | wildcard wildcard } | range ipv4-start-address ipv4-end-address }

    Destination IP address

    destination-address { ipv4-address { ipv4-mask-length | mask mask-address | wildcard wildcard } | range ipv4-start-address ipv4-end-address | any }

    Configures the destination IP addresses of traffic.

    destination-address-exclude { ipv4-address { ipv4-mask-length | mask mask-address | wildcard wildcard } | range ipv4-start-address ipv4-end-address }

    Excludes addresses from the address range that is to be translated.

    Source security zone

    source-zone { zone-name &<1-6> | any }

    Configures the source security zone of traffic. The internal network typically belongs to this security zone.

    Destination security zone

    destination-zone { zone-name | any }

    Configures either a destination security zone or an outbound interface. An external network typically belongs to this security zone.

    Outbound interface

    egress-interface interface-type interface-number

    Service
    • service protocol { udp | tcp } [ source-port { source-port | start-source-port to end-source-port } &<1-64> | destination-port { destination-port | start-destination-port to end-destination-port } &<1-64> ] *
    • service protocol sctp

    • service protocol icmp [ icmp-type { icmp-name | icmp-type-number { icmp-code-number [ to icmp-code-number ] } &<1-64> } ]

    • service protocol protocol-number

    • service-exclude protocol { udp | tcp } [ source-port { source-port | start-source-port to end-source-port } &<1-64> | destination-port { destination-port | start-destination-port to end-destination-port } &<1-64> ] *
    • service-exclude protocol sctp

    • service-exclude protocol icmp [ icmp-type { icmp-name | icmp-type-number { icmp-code-number [ to icmp-code-number ] } &<1-64> } ]

    • service-exclude protocol protocol-number

    • service any

    Configure the port number and protocol number of a service.

    For example, you can configure services with source TCP ports 123 to 128 as a matching condition using either of the following methods:

    [HUAWEI] nat-policy
[HUAWEI-policy-nat] rule name policy1
[HUAWEI-policy-nat-rule-policy1] service protocol tcp source-port 123 to 128

  9. Define an action in the NAT rule.

    action { source-nat { address-group address-group-name | easy-ip } | no-nat }

    source-nat indicates that source NAT is performed for the matched traffic, whereas no-nat indicates that NAT is not performed for the matched traffic.

    no-nat primarily applies to certain special clients. For example, to perform NAT translation for all hosts except 192.168.1.2 on the 192.168.1.0/24 network segment, you can first configure a policy that does not translate 192.168.1.2 and then configure a policy to translate the 192.168.1.0/24 network segment.

Verifying the Configuration

Run the display nat-policy rule command to check the configuration of NAT rules.

Follow-up Procedure

After a source NAT policy is configured, you can enable, disable, rename, move, or copy the rules in the policy.

  1. Enter the system view.
    system-view
  2. Enter the NAT policy view.
    nat-policy
  3. Adjust the rules created in the NAT policy.

    Operation

    Command

    Description

    Enable or disable a rule.

    rule name rule-name

    enable / disable

    You can enable or disable a rule in the corresponding rule view.

    Rename a rule.

    rule rename old-name new-name

    An existing policy rule can be renamed.

    Move a rule.

    rule move rule-name1 { { after | before } rule-name2 | up | down | top | bottom }

    Generally, an earlier configured rule is placed above those configured later, so it has a higher priority. You can run the rule move command to move a rule to change its priority.

    Copy a rule.

    rule copy rule-name new-rule-name

    If a rule you want to create is similar to an existing rule, you can run the rule copy command to clone the existing rule as a new rule.
