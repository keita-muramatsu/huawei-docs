Verifying the Configuration

Procedure

  • Run the display vlan vlan-id [ verbose | to vlan-id2 ] command to check VLAN information.
  • Run the display interface vlanif [ vlan-id ] command to check information about a VLANIF interface.

Example

Run the display vlan vlan-id verbose command to check the VLAN type. For example:

<HUAWEI> display vlan 40 verbose
VLAN ID      : 20
  VLAN Type    : Super
  Description  : VLAN 0020
  Status       : Enable
  Broadcast    : Enable
  MAC Learning : Enable
  Statistics   : Disable
----------------
sub-VLAN List: 10
