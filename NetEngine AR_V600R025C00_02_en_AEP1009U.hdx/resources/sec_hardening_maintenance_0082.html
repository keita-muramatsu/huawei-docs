Login Through Telnet

Overview

Telnet is an application-layer protocol for remote login. It uses TCP to transmit data in cleartext, leaving the device vulnerable to denial of service (DoS), port scanning, brute force password cracking, and other attacks. As a result, device information may be disclosed, posing great security risks. To avoid these problems, use the following security policies:

  • Disable the Telnet service and use STelnet to log in to the device.
  • Configure an ACL whitelist to restrict login IP addresses, preventing DoS attacks.
  • Configure VTY user interfaces by segment to prevent DoS attacks.

Impact on the System

None

Procedure

  • Disable the Telnet service.

    system-view
undo telnet [ ipv6 ] server enable

  • Configure an ACL whitelist to prevent DoS attacks.
    1. Enter the system view.

      system-view

    2. Create a basic ACL. You can create a numbered or named ACL.

      • Create a numbered basic ACL and enter its view.
        acl [ number ] acl-number
      • Create a named basic ACL and enter its view.
        acl name basic-acl-name basic

    3. Configure a basic ACL rule.

      rule [ rule-id ] [ name rule-name ] { deny | permit } [ fragment-type fragment | source { source-ip-address { source-wildcard | 0 | src-netmask } | any } | time-range time-name | vpn-instance vpn-instance-name | logging ] *

    4. Exit the ACL view.

      quit

    5. Set the maximum number of VTY login users.

      user-interface maximum-vty number

    6. Enter the VTY user interface view.

      user-interface vty first-ui-number [ last-ui-number ]

    7. Configure the limit on incoming and outgoing calls for VTY user interfaces.

      acl { acl4name | acl4num } { inbound | outbound }
acl ipv6 { acl6name | acl6num } { inbound | outbound }

      To prevent users from using a specified IP address or an IP address in a specified network segment to access a device, specify inbound.

      To prevent users who have already logged in to a device from logging in to other devices, specify outbound.

  • Configure VTY user interfaces by segment to prevent DoS attacks.

    At least one user interface is configured with SSH.

    1. Enter the system view.

      system-view

    2. Set the maximum number of VTY login users.

      user-interface maximum-vty number

    3. Enter the VTY user interface view.

      user-interface vty first-ui-number [ last-ui-number ]

    4. Configure the protocols supported by the user interface.

      protocol inbound ssh

    5. Exit the VTY user interface view.

      quit

    6. Enter the VTY user interface view.

      user-interface vty first-ui-number [ last-ui-number ]

    7. Configure the protocols supported by the user interface.

      protocol inbound telnet

    8. Exit the VTY user interface view.

      quit

Verifying the Security Hardening Result

  • Run the display telnet server status command to check the current connection information of the Telnet server.
