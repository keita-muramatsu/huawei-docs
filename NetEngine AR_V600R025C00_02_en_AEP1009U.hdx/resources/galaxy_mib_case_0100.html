Querying IPsec Tunnel Statistics

Description of MIB Objects

You can use the following objects to query IPsec tunnel statistics.

Table 1 Description of MIB objects

Object

OID

hwIPSecTunnelByteInput

1.3.6.1.4.1.2011.6.122.26.4.1.4

hwIPSecTunnelByteOutput

1.3.6.1.4.1.2011.6.122.26.4.1.5

hwIPSecTunnelPacketInput

1.3.6.1.4.1.2011.6.122.26.4.1.6

hwIPSecTunnelPacketOutput

1.3.6.1.4.1.2011.6.122.26.4.1.7

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.

  2. Perform a walk operation on hwIPSecTunnelByteInput to query the number of bytes received through an IPsec tunnel. As shown in Figure 1, the number of bytes received through an IPsec tunnel is 0.

    Figure 1 Query result of hwIPSecTunnelByteInput

  3. Perform a walk operation on hwIPSecTunnelByteOutput to query the number of bytes sent through an IPsec tunnel. As shown in Figure 2, the number of bytes sent through an IPsec tunnel is 0.

    Figure 2 Query result of hwIPSecTunnelByteOutput
  4. Perform a walk operation on hwIPSecTunnelPacketInput to query the number of packets received through an IPsec tunnel. As shown in Figure 3, the number of packets received through an IPsec tunnel is 0.
    Figure 3 Query result of hwIPSecTunnelPacketInput

  5. Perform a walk operation on hwIPSecTunnelPacketOutput to query the number of packets sent through an IPsec tunnel. As shown in Figure 4, the number of packets sent through an IPsec tunnel is 0.

    Figure 4 Query result of hwIPSecTunnelPacketOutput
