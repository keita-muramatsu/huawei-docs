Configuring Tunnel Forwarding for mDNS Packets

Context

mDNS packets are encapsulated into Layer 2 packets during forwarding. They cannot be forwarded at Layer 3 on a network where the WAC and APs are deployed in Layer 3 networking and the APs are configured to work in direct forwarding mode. In this case, tunnel forwarding for mDNS packets can be configured so that APs can encapsulate mDNS packets and forward them to the WAC through CAPWAP tunnels.

Tunnel forwarding for mDNS packets takes effect only in direct forwarding mode.

When the WAC and APs are connected across Layer 3 and the APs work in direct forwarding mode, tunnel forwarding is enabled for HTTP, EAP, and WAPI packets by default, which cannot be configured. Tunnel forwarding for mDNS packets can be configured as follows.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a VAP profile view and enter its view.

    vap-profile name profile-name

  4. Configure tunnel forwarding for mDNS packets.

    mdns centralized-control enable

    By default, tunnel forwarding for mDNS packets is disabled.

  5. Apply the VAP profile by referring to Binding a VAP Profile to make the configuration take effect.

Verifying the Configuration

Run the display vap-profile name profile-name command to check the status of tunnel forwarding for mDNS packets based on the mDNS centralized control field.
