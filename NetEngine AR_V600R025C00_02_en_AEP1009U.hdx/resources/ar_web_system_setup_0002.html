Clock Configuration

Context

You can configure the system clock of the device.

Procedure

  1. Choose System > Setup > System Time. The page for configuring the system time is displayed, as shown in Figure 1.

    Figure 1 System Time page

  2. Set system time parameters. Table 1 lists the parameters.

    Table 1 Parameters for configuring the system time

    Parameter

    Description

    Configuration Mode

    Mode for setting the system time. The options include Manual, Synchronize with local server, and Synchronize with NTP server.

    If this parameter is set to Synchronize with local server, Time Zone and Date & Time cannot be set.

    Time Zone

    Time zone.

    Date & Time

    Date and time of the system.

    NTP Authentication

    NTP authentication mode, which can be HMAC-SHA256, AES-128-CMAC, or AES-256-CMAC. After NTP authentication is enabled, you need to enter a password. The password must contain at least 12 characters, including uppercase letters, lowercase letters, digits, and special characters.

    NTP Server

    IP address and port number of an NTP server.

    Outbound Interface

    Outbound interface.

    This parameter can be set when Configuration Mode is set to Synchronize with NTP server.

    DST

    Whether to enable automatic clock adjustment based on the daylight saving time (DST). Before enabling the DST, configure the system time.

    Start Time

    Time when the DST is enabled.

    This parameter can be set when the function of automatically adjusting the clock based on the DST is enabled.

    End Time

    Time when the DST is disabled.

    This parameter can be set when the function of automatically adjusting the clock based on the DST is enabled.

    Offset

    Offset of the system time when the DST is enabled.

    This parameter can be set when the function of automatically adjusting the clock based on the DST is enabled.

    For example, if Start Time and End Time are set to 08:00 on the first Monday in April and 10:00 on the first Monday in November, respectively, and this parameter is set to 01:00, the system time is automatically set to 09:00 at 08:00 on the first Monday in April, and to 09:00 at 10:00 on the first Monday in November.

  3. Click Apply.
