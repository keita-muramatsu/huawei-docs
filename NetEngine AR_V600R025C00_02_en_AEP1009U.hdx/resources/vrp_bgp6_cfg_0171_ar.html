Configuring the IPv4/IPv6 Dual Stack

The IPv4/IPv6 dual stack needs to be configured on the router at the edge of an IPv6 network and an IPv4 network.

Prerequisites

Before configuring 6PE, you have completed the following tasks:

  • Connect interfaces and configure physical parameters for the interfaces to ensure that the physical status of the interfaces is up.

  • Configure link layer protocol parameters for interfaces.

  • Ensure that routes on the IPv4/MPLS backbone network are reachable.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the interface view.

    interface interface-type interface-number

  3. Configure an IPv4 address for the interface.

    ip address ip-address { mask | mask-length }

  4. Return to the system view.

    quit

  5. Enter the interface view.

    interface interface-type interface-number

  6. Enable IPv6 on the interface.

    ipv6 enable

  7. Configure an IPv6 address for the interface.

    ipv6 address { ipv6-address prefix-length | ipv6-address/prefix-length } eui-64 or ipv6 address { ipv6-address prefix-length | ipv6-address/prefix-length }
