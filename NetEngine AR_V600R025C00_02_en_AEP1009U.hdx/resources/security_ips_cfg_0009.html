Updating the Intrusion Prevention Signature Database

Prerequisites

  • For details about how to prepare for signature database update, see "Preparation for Signature Database Updates" in CLI Configuration Guide > System Management Configuration > Signature Database Update Configuration.
  • Before updating the IPS signature database using the online update function, you need to configure the device to communicate with the Huawei Security Center. For details, see "Configuring the Device to Communicate with the Huawei Security Center" in CLI Configuration Guide > System Management Configuration > Signature Database Update Configuration > Configuring Online Signature Database Update.

Context

Huawei security center (isecurity.huawei.com) periodically releases the IPS signature database and updates the IPS signature database to the latest version in a timely manner to effectively defend against network intrusions.

This section provides only the basic steps for updating a signature database online. For details about offline signature database update and other related update information, see "Signature Database Update Configuration" in CLI Configuration Guide > System Management Configuration.

Procedure

  1. Configure the DNS server to ensure that the device can correctly parse the domain name of the security center.

    system-view
dns resolve
dns server ip-address

  2. Manually update the intrusion prevention signature database to the latest version.

    update online ips-sdb

    The device periodically updates the intrusion prevention signature database once a week.

  3. Configure scheduled update of the intrusion prevention signature database.
    1. Enable scheduled update.

      update schedule ips-sdb enable

    2. Set the scheduled update time.

      update schedule ips-sdb { hourly minute | { daily | weekly { mon | tue | wed | thu | fri | sat | sun } } time }

      By default, the scheduled update function of the intrusion prevention signature database is enabled. The device randomly selects a time from 00:00 to 07:59 as the scheduled time for updating the intrusion prevention signature database every day. You can configure the time.

      You are advised to update the IPS signature database once a week.
