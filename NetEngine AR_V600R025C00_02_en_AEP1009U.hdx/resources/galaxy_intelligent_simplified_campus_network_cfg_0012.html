Configuring the Auto-Negotiation Mode for an Interface

Context

In auto-negotiation mode, interfaces on both ends of a link can negotiate their operating parameters. In this way, the transmission capability is automatically configured to reach the maximum value supported by both ends.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the single RU view.

    remote-unit { id | connect-interface interface-type interface-number | name remote-unit-name }

  3. Configure the auto-negotiation mode for an interface.

    negotiation auto port { portid1 [ to portid2 ] } &<1-32>

    By default, an RU interface works in auto-negotiation mode. This function can be configured only on downlink interfaces of an RU.

  4. Deliver the configuration to the RU.

    commit
