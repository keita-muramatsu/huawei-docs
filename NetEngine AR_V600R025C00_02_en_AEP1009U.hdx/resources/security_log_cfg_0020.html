Understanding Service Logs

The device can output security service logs, which you can view on the log server. By viewing service logs, you can monitor the current network traffic, check security risks, and learn about types of network attacks. You can then take corresponding protection and control measures.

Table 1 describes functions and viewing methods of various logs.
Table 1 Log classification and function

Log Type

Function

Triggering Condition

Log Format

Viewing Method

Threat log

Threat logs generated for antivirus, intrusion prevention, and botnet, Trojan horse, and worm detection. By viewing these logs, you can check detection and defense records for threats such as the virus, intrusionbotnet, Trojan horse, and worm, and learn about historical and ongoing threat events. You can then adjust security policies or implement active defense in a timely manner.
  • Threat logs are recorded when the traffic destined for or traversing the device matches the AV or intrusion prevention profile.
  • Each time the traffic matches the AV or intrusion prevention profile, the device records a threat log.

Syslog
  • You can run the display logfile flash:/logfile/service/service.log command to view detailed contents in log files.
  • To view service logs stored in the log buffer, you can run the display logbuffer service-log command.
  • You can log in to the device through the console port, Telnet, or STelnet, and run the terminal monitor and terminal logging commands on the CLI to enable the function of displaying logs on the terminal.
  • The logs can be viewed on the log server.

URL filtering log

Logs generated by the URL filtering function. By viewing URL logs, you can obtain the URL access status (permitting, alerting, or blocking) and corresponding causes.
  • When the traffic arriving at or traversing the device matches a URL filtering profile, the device records a URL filtering log.
  • Each time a URL filtering profile is matched, the device records a URL filtering log.

Syslog
  • You can run the display logfile flash:/logfile/service/service.log command to view detailed contents in log files.
  • To view service logs stored in the log buffer, you can run the display logbuffer service-log command.
  • You can log in to the device through the console port, Telnet, or STelnet, and run the terminal monitor and terminal logging commands on the CLI to enable the function of displaying logs on the terminal.
  • The logs can be viewed on the log server.

User activity log

Logs generated for Internet user activities (such as login and logout). By viewing user activities logs, you can learn about the online records of a user, including login time, online duration, and IP address used for login, as well as user activities on the current network. Once abnormal user login or network access behaviors are detected, you can take measures in a timely manner.

When a user performs operations such as login and logout, the device records a log.

Syslog
  • You can run the display logfile flash:/logfile/service/service.log command to view detailed contents in log files.
  • To view service logs stored in the log buffer, you can run the display logbuffer service-log command.
  • You can log in to the device through the console port, Telnet, or STelnet, and run the terminal monitor and terminal logging commands on the CLI to enable the function of displaying logs on the terminal.

Resumable file transfer log

The device logs the blocking of malicious files that use resumable transfer. You can view resumable file transfer logs to learn about which malicious files that use resumable transfer are blocked by the content security detection function of the device.

The device records a log when it blocks a malicious file that uses resumable transfer.

Syslog
  • You can run the display logfile flash:/logfile/service/service.log command to view detailed contents in log files.
  • To view service logs stored in the log buffer, you can run the display logbuffer service-log command.
  • You can log in to the device through the console port, Telnet, or STelnet, and run the terminal monitor and terminal logging commands on the CLI to enable the function of displaying logs on the terminal.
