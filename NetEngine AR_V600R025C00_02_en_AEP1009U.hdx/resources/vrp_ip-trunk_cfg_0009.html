Creating an IP-Trunk Interface and Adding Interfaces to the IP-Trunk Interface

Create an IP-Trunk interface and add interfaces to the IP-Trunk interface.

Procedure

  • Configuration in the IP-Trunk interface view:
    1. Enter the system view.

      system-view

    2. Enter the IP-Trunk interface view.

      interface ip-trunk trunk-id

    3. Perform either of the following operations to add IP-Trunk member interfaces:

      • Add member interfaces in batches.
        trunkport PortType { beginifnum [ to endifnnum ] } &<1-16>
      • Add a single member interface.
        trunkport ifname

  • Configuration in the member interface view:
    1. Enter the system view.

      system-view

    2. Create an IP-Trunk interface.

      interface ip-trunk trunk-id

    3. Return to the system view.

      quit

    4. Enter the view of the member interface to be bundled to the IP-Trunk interface.

      interface pos interface-number

    5. Configure HDLC as the link layer encapsulation protocol of the interface.

      link-protocol hdlc

      The link layer encapsulation protocol of the member interfaces added to the IP-Trunk interface must be HDLC.

    6. Add the interface to the IP-Trunk interface.

      ip-trunk trunk-id

      When configuring an IP-Trunk interface, note the following issues:

      • HDLC must run on each interface to be added to the IP-Trunk interface.

      • An interface to be added to the IP-Trunk interface must have no Layer 3 features or any services configured.

      • A POS interface can be added to only one IP-Trunk interface. If you need to add the POS interface to another IP-Trunk interface, delete it from the current IP-Trunk interface first.

      • An IP-Trunk interface cannot be added to another IP-Trunk interface.

      • You can add POS interfaces from different interface boards to the same IP-Trunk interface.

      • If a member interface of an IP-Trunk is connected to a peer end, the peer interface directly connected to the local interface must also be a member interface of an IP-Trunk.
