Querying Data on the Local LLDP Device

Description of MIB Objects

You can use the following objects to obtain information about the local LLDP device.

Object

OID

lldpLocChassisIdSubtype

1.0.8802.1.1.2.1.3.1

lldpLocChassisId

1.0.8802.1.1.2.1.3.2

lldpLocPortId

1.0.8802.1.1.2.1.3.7.1.3

Procedure

  1. Search for an object in the MIB tree. However, it is difficult to locate an object if a large number of MIB files are imported to the MIB Browser. In this case, you can press Ctrl+F to locate an object.

  2. Perform the Walk operation on lldpLocChassisIdSubtype to query the ID sub-type of the local LLDP device. As shown in Figure 1, the ID sub-type of the local LLDP device is macAddress.

    Figure 1 Querying the ID sub-type of the local LLDP device

  3. Perform the Walk operation on lldpLocChassisId to query the ID of the local LLDP device. As shown in Figure 2, the ID of the local LLDP device is 64.3E.8C.48.F1.4A.

    Figure 2 Querying the ID of the local LLDP device
