Configuring IGMP Snooping on APs

Context

After IGMP snooping is enabled on an AP, the AP listens to and analyzes IGMP messages and creates multicast forwarding entries to instruct on-demand multicast data forwarding on the wireless side.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the WLAN view.

    wlan

  3. Create a traffic profile and enter its view.

    traffic-profile name profile-name

    By default, the system provides the traffic profile default.

  4. Enable IGMP snooping in the traffic profile.

    igmp-snooping enable

    By default, IGMP snooping is disabled in a traffic profile.

  5. (Optional) Enable suppression of IGMP Report and Leave messages in the traffic profile.

    igmp-snooping report-suppress

    By default, suppression of IGMP Report and Leave messages is disabled in a traffic profile.

  6. Apply the traffic profile.

    Bind the traffic profile to an AP group or a single AP so that the configuration in the traffic profile can take effect. For details, see Traffic Profile.

Verifying the Configuration

Run the display traffic-profile { all | name profile-name } command to check the IGMP snooping configuration in a traffic profile.
