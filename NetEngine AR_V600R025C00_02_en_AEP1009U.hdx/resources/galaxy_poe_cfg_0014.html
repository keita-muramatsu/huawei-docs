Configuring the Power Supply Mode for a PoE Interface

Context

A PoE interface supports the following power supply modes.
  • af-inrush: PoE mode
  • at-inrush: PoE+ mode
  • bt-inrush: PoE++ mode

For example, some non-standard PDs on the market do not support high-current power supply, and instead only support low-current power supply. In such cases, you can configure PoE interfaces to work in af-inrush mode. An interface in at-inrush mode provides a maximum of 30 W power, whereas an interface in af-inrush mode provides a maximum of 15.4 W power. These two modes provide different current values for PDs, with the current value of the former greater than that of the latter.

Changing the power supply mode of a PoE interface may power off the PDs connected to it.

After the poe af-inrush enable command is configured, you need to remove and then install the cables connected to non-IEEE-standard PDs so that the PDs can be powered on normally.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the interface view.

    interface interface-type interface-number

  3. Configure the power supply mode for the PoE interface.

    poe { af-inrush | at-inrush | bt-inrush } enable

    By default, interfaces supporting the PoE++ mode provide power in that mode (the power supply mode is bt-inrush). Interfaces that do not support the PoE++ mode provide power in at-inrush mode.

Verifying the Configuration

Run the display poe power-state [ slot slot-id | interface { interface-type interface-number | interface-name } ] command to check the power supply mode of the PoE interface based on the Port power-up mode field.
