(Optional) Configuring Adaptive QoS

Prerequisites

Before configuring the adaptive QoS function, ensure that the connection-based QoS function has been configured. For details, see (Optional) Configuring Connection-based QoS.

This function is supported only on the AR6700-H series and AR8000 series.

Context

The connection-based QoS function uses static traffic control policies, which cannot match the actual available line bandwidth. Based on the connection-based QoS function, the adaptive QoS function enables the hub to detect the available link bandwidth in a timely manner and adjust the traffic control policy on the transmit end in real time based on the link congestion status, ensuring the experience of key services.

Procedure

  1. Enter the system view.

    system-view

  2. Create an adaptive QoS policy and enter the adaptive QoS policy view.

    adaptive-qos policy name

    By default, no adaptive QoS policy is created.

  3. Configure adaptive QoS policy parameters, as described in Table 1.

    Table 1 Adaptive QoS policy parameters

    Function

    Command

    Default Setting

    Remarks

    Configure the connection bandwidth threshold.

    connection bandwidth-threshold percentage pct-value

    50%

    You can set the connection bandwidth threshold to specify the lower limit of the link bandwidth. If the link bandwidth reaches the lower limit, the link bandwidth is not decreased. This ensures that the link bandwidth is not decreased too low when the packet loss rate is high.

    Configure the service bandwidth threshold.

    service bandwidth-threshold percentage pct-value

    10%

    You can set the service bandwidth threshold to specify the lower bandwidth limit for a specific service. If the bandwidth of a service reaches the lower limit, the bandwidth is not decreased. This ensures that the bandwidth of specific services is not decreased too low when the packet loss rate is high.

    Configure the packet loss rate threshold.

    wan-loss-permillage loss-value

    2‰

    If the detected packet loss rate exceeds the threshold, the bandwidth is decreased.

    Configure the adjustment interval.

    adjustment-period period-value

    30s

    The device automatically adjusts the bandwidth based on the link congestion status at the specified interval.

    Configure the lower traffic usage threshold for increasing the bandwidth.

    traffic-usage lower-threshold lower-threshold

    50%

    When the ratio of the real-time traffic volume to the bandwidth is smaller than this value, adaptive QoS takes effect to increase the bandwidth, thereby preventing network congestion caused by subsequent traffic bursts.

  4. Return to the system view.

    quit

  5. Enter the site group view.

    evpn site-group name

  6. Apply an adaptive QoS policy.

    adaptive-qos-policy policy-name

    By default, no adaptive QoS policy is applied to a site group.

Verifying the Configuration

  • Run the display adaptive-qos history connection { connection-id | all } command to check historical information about adaptive QoS bandwidth adjustment.
  • Run the display adaptive-qos status connection { connection-id | all } command to check the current bandwidth information of adaptive QoS.
