Configuring the Device to Permit DNS Packets During Portal Authentication

Context

When Portal users access the network using domain names, the device must permit DNS packets destined for the DNS server.

Procedure

  1. Enter the system view.

    system-view

  2. Enable the device to permit DNS packets during Portal authentication.

    portal pass dns enable

    By default, the device does not permit DNS packets during Portal authentication.

    • After the portal pass dns enable command is run, all DNS packets are permitted. You are advised to configure the DNS server IP address as an authentication-free IP address by running the free-rule command. For details, see .
    • Only wireless users support this function.
