Routing Table

Context

You can check the routing table to learn routing information of the local device.

Procedure

  1. Choose Config > IP Services > Routing Protocol and click the Routing Table tab. The Routing Table tab page is displayed, as shown in Figure 1.

    Figure 1 Routing Table tab page

  2. View all routes in the routing table. You can enter a keyword in the search box to query routes based on the destination IP address, subnet mask, protocol type, outbound interface, next-hop address, and priority. Table 1 describes the parameters in the routing table.

    Table 1 Routing information

    Parameter

    Description

    Destination IP

    Destination IP address or network of IP packets.

    Subnet Mask

    Subnet mask of the destination address. The subnet mask and the destination address together identify the network segment where the destination host or router is located.

    Route Type

    Routing protocol that learns a route.

    Outbound Interface

    Outbound interface through which packets are forwarded.

    Next Hop Address

    IP address of the next-hop device that packets pass through.

    Priority

    Priority of a route. A smaller value indicates a higher priority.
