VLAN

Context

You can configure a VLAN and add interfaces to the VLAN.

Procedure

  • Creating a VLAN
    1. Choose Config > LAN Configuration > VLAN. The VLAN page is displayed, as shown in Figure 1.

      Figure 1 VLAN list

    2. Click Create. The Create VLAN page is displayed, as shown in Figure 2.

      Figure 2 Creating a VLAN

    3. Set parameters as needed. Table 1 describes the parameters.

      Table 1 Creating a VLAN

      Parameter

      Description

      Basic Information

      VLAN ID

      ID of a VLAN. The value ranges from 1 to 4094. VLAN 1 is the default VLAN, and the system will not re-create it.

      Description

      Description of a VLAN.

      Select Port

      Interface to be added to a VLAN.

      1. Click under Select Port. The page for selecting ports is then displayed.
      2. Select the desired ports to be added to the VLAN.
      3. Set Interface Mode to specify the mode in which the ports are added to the VLAN. The options are Access, Trunk, and Hybrid.
      4. Toggle on or off Tagged as required. This parameter is configurable only when Interface Mode is set to Hybrid.
      5. Click OK.

      Create a VLANIF interface

      Select to create a VLANIF interface.

      Interface status

      Whether to enable an interface. The options are as follows:

      • On: enabled
      • Off: disabled

      IPv4 MTU(bytes)

      IPv4 MTU of an interface.

      IP obtaining mode

      Mode for obtaining an IP address. The options are Static IP and DHCP.

      IPv4 Address

      Parameters in this area are available when IP obtaining mode is set to Static IP.

      IPv4 Address/Mask

      IPv4 address and mask of the interface.

      Secondary IPv4 address/mask

      Secondary IPv4 address and mask of the interface.

      To configure a secondary IPv4 address and mask, click . To delete a secondary IPv4 address and mask, click .

      Creating a DHCP Server

      The Creating a DHCP Server check box is available only when IP obtaining mode is set to Static IP. You can select this check box only after configuring an IPv4 address and mask.

      Lease

      Lease of an IP address allocated to a DHCP client.

      Primary DNS

      Primary DNS server.

      NOTE:

      A DNS server needs to be configured when users access network servers using domain names.

      Secondary DNS

      Secondary DNS server.

      Reserved IP address

      Reserved IP addresses.

  • Querying a VLAN
    1. Choose Config > LAN Configuration > VLAN. The VLAN page is displayed.
    2. Enter a VLAN ID in the search box. If you do not enter any VLAN ID, all created VLANs are displayed in the list.
    3. Press Enter. All the records that meet the search criteria are displayed, as shown in Figure 3.

      Figure 3 VLAN list

    4. Click in the Port column of a VLAN to check the ports added to the VLAN, as shown in Figure 4.

      Figure 4 Interface list

    5. Click next to a parameter to sort data records. indicates ascending order and indicates descending order.
  • Modifying a VLAN
    1. Choose Config > LAN Configuration > VLAN. The VLAN page is displayed.
    2. Click next to a VLAN ID. The Modify VLAN page is displayed.
    3. Modify the settings as required. Table 1 describes the parameters.
    4. Click OK.
  • Deleting a VLAN
    1. Choose Config > LAN Configuration > VLAN. The VLAN page is displayed.
    2. Select next to the desired VLAN and click Delete or . The system asks for your confirmation to delete the selected VLAN.

      VLAN 1 is the default VLAN and cannot be deleted.

    3. Click OK.
