(Optional) Enabling the Extended SD-WAN Tunnel Encapsulation Format

Context

The intermediate network can parse GRE packets only if the packets have the R field in GRE headers set to 0. To support GRE packet parsing on the intermediate network, you need to enable the extended SD-WAN tunnel encapsulation format. With this format enabled, the R field in the GRE header will be set to 0 during SD-WAN tunnel encapsulation.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the site view.

    evpn site site-id

  3. Enable the extended SD-WAN tunnel encapsulation format.

    evpn ext-format enable

    By default, the extended SD-WAN tunnel encapsulation format is disabled.

    The extended format takes effect only if the command is configured on both ends of an SD-WAN tunnel. If you run this command on only one end, traffic will be interrupted.
