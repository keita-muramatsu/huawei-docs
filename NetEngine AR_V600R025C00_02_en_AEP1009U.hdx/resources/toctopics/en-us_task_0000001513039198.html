(Optional) Configuring Short Sequence Number Negotiation

Context

A sequence number in the packet header indicates the sequence of a packet fragment. The header of an MP packet can use either a short sequence number (12 bits) or a long sequence number (24 bits).

Configuring a short sequence number shortens the packet length and improves communication reliability.

Procedure

  1. Enter the system view.

    system-view

  2. Create an MP-Group interface and enter the MP-Group interface view.

    interface mp-group number

  3. Configure short sequence number negotiation.

    short-sequence

    By default, an MP-Group interface uses a long sequence number to perform negotiation.

    After the configuration, run the shutdown command followed by the undo shutdown command in the MP-Group interface view to restart the interface for the configuration to take effect.
