Configuring a Clock Mode

Context

POS interfaces support the following clock modes:

  • Master: The interface that works in this mode uses the local clock and transmits clock signals to the peer device through the line.
  • Slave: The interface that works in this mode uses line clock signals.

When two devices are directly connected using two POS interfaces, one POS interface must work in master clock mode and the other must work in slave clock mode.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the POS interface view.

    interface pos interface-number

  3. Configure a clock mode for the POS interface.

    clock { master | slave }

    By default, POS interfaces use the master clock mode.
