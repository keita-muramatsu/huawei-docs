(Optional) Configuring the Portal Authentication Bypass Function

Context

If the Portal server is down, users cannot be authenticated and do not have network access rights. The Portal authentication bypass function allows the access device to meet the basic network access requirements of users. It does this by granting specific network access rights to users when it detects that the Portal server is down.

Pre-configuration Tasks

Before configuring the Portal authentication bypass function, complete the following tasks:
  1. Enable the heartbeat detection function for the Portal server.
  2. Enable the Portal server detection function for the access device. For details, see (Optional) Configuring the Portal Server Detection Function.
  3. Configure a service scheme. For details, see (Optional) Configuring a Service Scheme.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the Portal access profile view.

    portal-access-profile name access-profile-name

  3. Configure network access rights for users to use when the Portal server is down.

    authentication event portal-server-down action authorize service-scheme service-scheme-name

    By default, no network access rights are configured for users to use when the Portal server is down.

  4. (Optional) Enable the device to re-authenticate users when the Portal server changes from down to up.

    authentication event portal-server-up action re-authen

    By default, the device does not re-authenticate users when the Portal server changes from down to up.

    After this step is performed, the access device re-authenticates users when it detects that the Portal server changes from down to up. The access device sets users whose status is web-server-down to pre-connection. The re-authentication process starts when the users visit any web page. If the authentication is successful, the access device grants normal network access rights to the users.

Verifying the Configuration

  • Run the display portal-access-profile configuration [ name access-profile-name ] command to check authorization information configured for the Portal authentication bypass function.
