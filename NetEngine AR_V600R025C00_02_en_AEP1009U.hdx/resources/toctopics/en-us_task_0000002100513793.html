AP Upgrade

Context

APs require matching versions with an AR to function properly. If their versions do not match, it is necessary to upgrade the APs. In addition, upgrading the AP software version or installing patches on APs is required to use functions in a new version or fix software issues.

When configuring an AP upgrade task, you need to specify the files used for the upgrade and the mode in which APs obtain these files. After downloading the necessary upgrade files, APs need to restart to complete the upgrade. If a patch file needs to be loaded during the upgrade, you can specify this file when configuring an AP upgrade task.

APs can obtain upgrade files either from an AR or a file server. If you prefer the APs to obtain upgrade files from an AR, you need to upload the files to the AR in advance or upload them when configuring an upgrade task. If you want APs to obtain upgrade files from a file server (an SFTP or FTP server), you need to place the files on the server beforehand.

In most cases, a patch file takes effect immediately after it is loaded, without the need to restart APs. However, if the loaded patch file must be used in conjunction with the software version that takes effect after a restart, you need to configure the patch file to take effect upon the next startup.

For the AR5710-S8T1XWE, AR5710-S8TWDSE-LTE4EA and AR5710-S8T1XWE-NRGL, you can upgrade the built-in AP version together with the system software version on the System Upgrade page, or install a patch to separately upgrade the built-in AP version on the AP Upgrade page.

Procedure

  1. Choose System > Device Upgrade and click the AP Upgrade tab. The AP Upgrade tab page is displayed, as shown in Figure 1.

    Figure 1 AP Upgrade Configuration page

  2. Click APs in Version Mismatch State to check whether there are APs that cannot work properly due to a version mismatch.

    If so, upgrade these APs.

  3. Click New Upgrade Task to create an AP upgrade task.

    • If the required upgrade files are stored on the AR, create an upgrade task as shown in Figure 2.
      Figure 2 Creating an upgrade task
    • If the required upgrade files are stored on a server, create an upgrade task as shown in Figure 3.
      Figure 3 Creating an upgrade task

    Parameter

    Description

    Upgrade scope

    -

    Scope selection
    • Batch APs: You need to specify an AP type, so that APs of the specified type will be upgraded in batches. Alternatively, you can select an AP group to specify the range of APs to be upgraded.
    • Single AP: You need to specify the AP to be upgraded.

    Upgrade file placement location

    -

    Location selection

    On the AR: Select this option if the AP upgrade files are saved on the AR. You can upload the required files in advance or when you select the files to be used for upgrade. Since batch upgrade takes a long time, to reduce the service interruption time, you are advised to place the upgrade files on an SFTP server.

    On the server: Select this option if the AP upgrade files have been uploaded to a file server (FTP or SFTP server). Ensure that APs can communicate with the server.
    • Service type: Select a file transfer protocol. SFTP is recommended because FTP is not secure enough.
    • Maximum number of connections: Specify the number of APs that can simultaneously download files from the server.

    Upgrade mode

    -

    Mode selection

    Immediate upgrade: APs restart immediately to complete the upgrade after they download the upgrade files.

    Download upgrade file: APs only download the upgrade files. You need to restart the APs to complete the upgrade.

    Scheduled upgrade: APs are upgraded at the scheduled time. This can prevent the upgrade from affecting services.

    Automatic upgrade: APs download the upgrade files and complete the upgrade only when they go online again after disconnections. Online APs will not be upgraded.

    Upgrade type

    -

    Type selection
    • System file: With this option selected, you need to specify an AP upgrade file name.

      If Scheduled upgrade or Automatic upgrade is selected as the upgrade mode, you can select Preloading the system upgrade file, which makes APs download the upgrade files in advance, shortening the upgrade time.

    • Patch file: With this option selected, you need to specify an AP patch file name.

      If Effective upon the next startup is selected, the patch takes effect on the APs upon the next startup.

    If Location selection is set to On the AR but the upgrade files are not available on the AR, you can click Upload to upload these files to the AR when selecting the required upgrade files.

  4. Check the AP upgrade status and perform subsequent operations which vary according to the upgrade mode.

    • Immediate upgrade

      On the AP Upgrade Status page, check the upgrade process and result of each AP, as shown in Figure 4.

      Figure 4 AP Upgrade Status page
    • Download upgrade file

      On the AP Upgrade Status page, check the file download status. After the file is downloaded successfully, you can restart APs to complete the upgrade.

    • Restarting specified APs: Select one or more APs in the list and click Upgrade Restart.
    • Restarting APs in batches: Click AP Batch Upgrade Restart to restart APs of a specific type or in a specific AP group, or restart all APs that need to be restarted.
    • Restarting APs by channel-based group: also called multi-batch, scattered upgrade. You can divide APs into channel-based groups and restart the APs in sequence. In this case, services will not be interrupted. If such an AP restart task has started and you want to stop it, click Cancel Channel Group Restart. The APs that are not restarted will not be restarted.
    • Scheduled upgrade

      Click the Scheduled Upgrade Tasks tab to view upgrade tasks and results, as shown in Figure 5.

      Figure 5 Scheduled Upgrade Tasks page
    • Automatic upgrade

      When APs go online again, you can view the upgrade process and result on the AP Upgrade Status page.

Follow-up Procedure

  • Canceling an upgrade task

    Click Cancel Upgrade to cancel the upgrade task of a single AP or multiple APs, as shown in Figure 6.

    Figure 6 Cancel Upgrade page
  • Uninstalling a patch

    Click Uninstall Patch to uninstall a loaded patch or clear the patch that will take effect upon the next startup, as shown in Figure 7.

    Figure 7 Uninstall Patch page
