Device Upgrade

Context

On this page, you can upgrade devices on the entire network.

  • Do not power off devices during the upgrade.

  • The system file in this section is for reference only.

  • APs and offline devices cannot be upgraded. You need to upgrade APs on the WAC.

Procedure

  1. Choose Maintenance > Device Upgrade. The Network Device Upgrade page is displayed, as shown in Figure 1.

    Figure 1 Network Device Upgrade page

  2. Select an upgrade mode as required.
    • Upgrading a single device: Click in the Operation column of the device to be upgraded. In the dialog box shown in Figure 2, set the parameters according to Table 1, and click OK to upgrade the device.
      Figure 2 Upgrade Device dialog box

      Table 1 lists the parameters.

      Table 1 Device upgrade parameters

      Parameter

      Description

      Protocol

      File server where the software package or patch package is stored.

      Server address

      IP address of the file server.

      Port number

      Port number of the file server.

      Server username

      User name for accessing the file server.

      Server password

      Password for accessing the file server.

      Software package

      Software package for the device upgrade.

      After the preceding server parameters are set, the system automatically checks the connectivity of the SFTP/FTP server when you select the software package or click the refresh icon next to the drop-down list box. If the connection is successful, you can select the software package on the SFTP/FTP server from the drop-down list.

      Patch package

      Patch package for the device upgrade.

      After the preceding server parameters are set, the system automatically checks the connectivity of the SFTP/FTP server when you select a patch package or click the refresh icon next to the drop-down list box. If the connection is successful, you can select the patch package on the SFTP/FTP server from the drop-down list.
    • Upgrading devices in a batch: Select multiple devices to be upgraded and click Batch Upgrade. In the dialog box shown in Figure 2, set parameters and click OK to upgrade the devices in a batch. Table 1 lists the parameters.

      When upgrading devices in a batch, you need to select devices of the same model or software package.
