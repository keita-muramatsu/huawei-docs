Configuring MP Implementation

Context

An MP-Group interface is a logical interface in MP. MP is implemented by adding multiple serial interfaces to an MP-Group interface.

MP can be configured only on a device that supports E1 cards. Interfaces on different cards can be added to an MP-Group interface. During this configuration, you need to create an MP-Group 0/0/X interface first.

Procedure

  1. Install the E1 card on the device. Ensure that the E1 card is intact before installation and that it is securely seated after installation.

    After the E1 card is installed on the device, the MP configuration takes effect.

  2. Enter the system view.

    system-view

  3. Create an MP-Group interface and enter the MP-Group interface view.

    interface mp-group number

  4. Configure an IP address for the MP-Group interface.

    Perform one of the following operations as required:

    • Configure an IP address on the MP-Group interface.
      ip address ip-address { mask | mask-length }[ tag tag-value ]
    • Configure the device as a client so that the local interface obtains an IP address through IP address negotiation.
      ip address ppp-negotiate

      By default, the local interface is not configured with IP address negotiation.

  5. Return to the system view.

    quit

  6. Enter the view of a serial interface that needs to be added to the MP-Group interface.

    interface serial interface-number

  7. Add the current serial interface to the MP-Group interface so that the serial interface works in MP mode.

    ppp mp { interface-type interface-number | interface-name }

    Repeat Steps 5 and 6 to add multiple serial interfaces to the MP-Group interface.

  8. (Optional) Configure authentication as required. For details, see Configuring PAP Authentication or Configuring CHAP Authentication.
