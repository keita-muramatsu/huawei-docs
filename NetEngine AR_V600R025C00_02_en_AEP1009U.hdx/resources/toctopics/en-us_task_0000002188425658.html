Interface Traffic Information

Context

You can view the upload and download rates of unicast, multicast, and broadcast packets on each interface.

Procedure

  1. Choose Monitoring > Overview from the main menu. The Interface Traffic Information area is displayed where you can view statistics about traffic on interfaces, as shown in Figure 1.

    Figure 1 Interface Traffic Information area
    Table 1 Parameters in the Interface Traffic Information area

    Parameter

    Description

    Interface

    Interface where traffic statistics need to be collected.
