Network Connection

Context

You can view the network connection status of the router in the Network Connection area.

Procedure

  1. Choose Monitoring > Overview from the main menu. The Network Connection area is displayed, where you can view the network connection status of the router, as shown in Figure 1.

    Figure 1 Network Connection area

  2. To view details about the terminals connected to the router, click the number following Terminal.

    Figure 2 Terminal details

    Table 1 lists the parameters.

    Table 1 Connected terminal details

    Parameter

    Description

    MAC Address

    MAC address of a terminal.

    IP Address

    IP address of a terminal.

    Connection Mode

    Mode in which a terminal is connected.

  3. To view details about the Internet connection of the router, click Router. The Internet Connection Details dialog box is then displayed, as shown in Figure 3.

    Figure 3 Internet connection details

    Table 2 lists the parameters.

    Table 2 Internet connection details

    Parameter

    Description

    Public Address

    Public address used by the router to connect to the Internet.

    Connection Mode

    Mode in which the router connects to the Internet:

    • Broadband dial-up
    • Fixed address
    • Dynamic address automatically obtained
    • Automatic dial-up through a cellular interface

    For details about how to set this parameter, see Internet Access Wizard.

    Interface

    Interface used by the router to connect to the Internet.

    Operation

    When Connection Mode is Cellular, you can click Disconnect to disconnect the router from the Internet.
