Internet Access Using a Static IP Address

Context

If you have obtained a static IP address or IP segment from an ISP, you can connect a device to the Internet using the static IP address.

Procedure

  1. Choose Config > Config Wizard > Online Config Wizard and set Internet access mode to Static IP, as shown in Figure 1.

    Figure 1 Internet access through a static IP address
    1. Set parameters for Internet access using a static IP address. For details about the parameters, see Table 1.
      Table 1 Parameters for configuring Internet access through a static IP address (mandatory)

      Parameter

      Description

      Internet interface

      Layer 3 interface to be used for Internet access. If the interface you want to select is a Layer 2 interface, click on the interface icon to switch the interface to a Layer 3 interface and then select this interface.

      IP address

      IP address of the interface.

      This address must be different from the IP addresses of other interfaces on the device or other devices on the network.

      Subnet Mask

      Subnet mask of the interface.

      Gateway address

      Default gateway address of the interface.

      This address must be in the same network segment as the interface IP address.
    2. Set DNS server parameters. For details about the parameters, see Table 2.
      Table 2 Parameters for configuring DNS servers for Internet access through a static IP address (optional)

      Parameter

      Description

      DNS server 1

      Preferred DNS server address assigned to DHCP clients. To add a DNS server address, click on the right.
    3. Set advanced parameters. For details about the parameters, see Table 3.
      Table 3 Advanced parameters for configuring Internet access through a static IP address (optional)

      Parameter

      Description

      MTU

      MTU of an interface. The value is an integer from 46 to 9216, in bytes. By default, the MTU of an interface is 1500 bytes.

      NOTE:

      The value ranges and default values vary according to hardware and interfaces. The supported interface types, value ranges, and default values depend on the device model.

      TCP-MSS (bytes)

      MSS of TCP packets on an interface. The value ranges from 128 to 9500. The default value is 1200.

      Default route priority

      Route priority. The value ranges from 1 to 255. The default value is 60.

      Enable NAT

      Whether to enable NAT. By default, this function is enabled. After NAT is enabled, the IP address of an interface is used as the post-NAT address.

  2. Click Confirm. If you need to reset all parameters, click Clear and set the parameters again.
