ASPF Configuration

Context

The ASPF and ALG functions are configured using the same command, and you do not need to perform repeated configurations, which greatly simplifies configuration.

You can configure global, interzone, or intrazone ASPF/ALG on a device.

When ASPF/ALG is configured on the web system (corresponding to the firewall detect protocol command), they take effect globally; that is, both interzone ASPF/ALG and intrazone ASPF/ALG are enabled. This simplifies configuration, but consumes much more performance resources because some unnecessary traffic enters the ASPF/ALG process.

Procedure

  1. Log in to the web system and choose Config > IP Services > NAT Policy > ASPF Configuration. The ASPF Configuration page is displayed, as shown in Figure 1.

    Figure 1 ASPF configuration

    The SIP ASPF/ALG function takes effect only for UDP-based SIP traffic.

    You are advised to enable ASPF/ALG for specific protocols as required, and disable ASPF/ALG for protocols that do not require ASPF/ALG.

  2. Click OK.
