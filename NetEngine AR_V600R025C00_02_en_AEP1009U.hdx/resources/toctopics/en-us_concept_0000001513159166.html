Overview of PPP and MP

Definition

Point-to-Point Protocol (PPP) is a link-layer protocol used to transmit point-to-point data over full-duplex synchronous or asynchronous links.

Multilink PPP (MP) bundles multiple PPP links together to increase link bandwidth and reliability.

Purpose

PPP

PPP is built on the Serial Line Internet Protocol (SLIP). PPP supports more types of links compared with link-layer protocols such as X.25 that can run only on synchronous links. In addition, SLIP supports only the asynchronous transfer mode (ATM), transmits only IP packets, and does not support negotiation (such as negotiation of network-layer attributes including IP addresses of the two ends). Such shortfalls are why SLIP is gradually being replaced by PPP.

PPP has the following advantages:

  • PPP supports both synchronous and asynchronous links.
  • PPP is highly extensible.
  • PPP uses Link Control Protocol (LCP) to negotiate link-layer parameters.
  • PPP uses Network Control Protocols (NCPs) to negotiate network-layer parameters.
  • PPP supports the Challenge Handshake Authentication Protocol (CHAP) and Password Authentication Protocol (PAP) to ensure network security.
  • PPP has no retransmission mechanism, reducing the network cost and accelerating packet transmission.

MP

MP bundles multiple PPP links. MP fragments all packets that are not smaller than the minimum fragmentation size and sends the fragments to the remote device over multiple PPP links in the MP group. After receiving these fragments, the remote device reassembles the fragments into packets for forwarding to the network layer. In this manner, MP implements load sharing and reduces transmission delay.

MP can be used to increase bandwidth when users have high bandwidth requirements while a single PPP link cannot provide sufficient bandwidth.
