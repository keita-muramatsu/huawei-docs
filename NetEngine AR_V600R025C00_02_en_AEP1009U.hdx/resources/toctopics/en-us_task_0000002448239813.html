(Optional) Enabling the FEC Enhancement Function

Context

FEC probe instances are used to detect whether the peer end supports FEC, helping prevent FEC failures caused by mismatched capabilities between both ends. To enhance the performance of these probe instances, you can enable FEC enhancement.

This function is supported only on AR8700 series, AR8100 series, and AR6700-H series devices.

Procedure

  1. Enter the system view.

    system-view

  2. Create and enter the FEC configuration view.

    forward-error-correction

    By default, no FEC configuration view is created.

  3. Enable the FEC enhancement function.

    fec enhance enable

    By default, the FEC enhancement function is disabled.

Verifying the Configuration

Run the display forward-error-correction enhance status command to check the status of the FEC enhancement function.

Follow-up Procedure

After the FEC enhancement function is configured, run the save command to save the configuration and restart the device for the configuration to take effect.
