Logging In to a Device for the First Time

Context

Prepare third-party terminal emulation software. For usage instructions, refer to the software's user guide or online help.

The password entered in interactive mode will not be displayed on the terminal screen.

Procedure

  1. Turn on the external power supply system to power on the router. When the SYS indicator blinks once every two seconds, the router is running properly and ready for login.
  2. Use a console cable to connect a PC to the console port of the router.

    Connect the RJ45 connector of a console cable to the CON port (RJ45) of the router.

  3. Connect the DB9 connector of the console cable to the COM port of the management PC.

    Start the terminal simulation software, create a connection, select a connected interface, and set communication parameters on the PC as follows.

    • Transmission rate: 9600
    • Data bit: 8
    • Parity bit: None
    • Stop bit: 1
    • Flow control mode: None

  4. Press Enter until information similar to the following is displayed. Enter a password and confirm the password as prompted. (The following information is for reference only.)
