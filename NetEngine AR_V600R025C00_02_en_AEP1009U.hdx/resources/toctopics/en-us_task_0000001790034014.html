Configuring Data Compression

Context

To use the data compression feature, you need to configure the compression function at the transmit end and the decompression function at the receive end.

Procedure

  • Configure the compression function at the transmit end.
    1. Enter the system view.

      system-view

    2. Enter the per-packet compression configuration view.

      per-packet-compress

    3. Enable the compression function.

      compress enable

      By default, the compression function is disabled.

    4. Create a service profile and enter its view.

      service-map service-map-name

      By default, no service profile is created.

    5. Bind an ACL, application, or application group to the service profile.

      match acl { acl-number | acl-name }
match application application-name
match application-group application-group-name
match acl { acl-number | acl-name } application application-name
match acl { acl-number | acl-name } application-group application-group-name

      By default, no ACL, application, or application group is bound to a service profile.

    6. Return to the per-packet compression configuration view.

      quit

    7. Create a compression policy and enter its view.

      compress policy policy-name

      By default, no compression policy is created.

    8. Bind the service profile to the compression policy.

      binding service-map service-map-name precedence precedence-value

      By default, no service profile is bound to a compression policy.

    9. Return to the per-packet compression configuration view.

      quit

    10. Return to the system view.

      quit

    11. Enter the interface view.

      interface { interface-name | interface-type interface-number }

    12. Apply the compression policy to the interface.

      compress-policy policy-name

      By default, no compression policy is applied to an interface.

  • Configure the decompression function at the receive end.
    1. Enter the system view.

      system-view

    2. Enter the per-packet compression configuration view.

      per-packet-compress

    3. Enable the decompression function.

      uncompress enable

      By default, the decompression function is disabled.

Example

Configure the data compression feature to compress the service flows that match ACL 3001 on 10GE 0/0/1.

  • Transmit end
    <HUAWEI> system-view 
[HUAWEI] per-packet-compress 
[HUAWEI-per-packet-compress] compress enable
[HUAWEI-per-packet-compress] service-map map1 
[HUAWEI-per-packet-compress-service-map-map1] match acl 3001 
[HUAWEI-per-packet-compress-service-map-map1] quit 
[HUAWEI-per-packet-compress] compress policy comp1 
[HUAWEI-per-packet-compress-policy-comp1] binding service-map map1 precedence 10 
[HUAWEI-per-packet-compress-policy-comp1] quit
[HUAWEI-per-packet-compress] quit
[HUAWEI] interface 10GE0/0/1 
[HUAWEI-10GE0/0/1] compress-policy comp1
  • Receive end
    <HUAWEI> system-view 
[HUAWEI] per-packet-compress 
[HUAWEI-per-packet-compress] uncompress enable
