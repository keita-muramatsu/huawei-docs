Network Tool

Context

The Network Tool page provides common network O&M functions. You can perform operations such as ping and traceroute to diagnose the devices that function as gateways on the entire network.

Procedure

  1. Choose Diagnosis > Network Tool. The Network Diagnosis page is displayed, as shown in Figure 1.

    Figure 1 Network Diagnosis page

  2. Set network diagnosis parameters.

    Table 1 lists the parameters.

    Table 1 Network diagnosis parameters

    Parameter

    Description

    Diagnosis mode

    Network diagnosis mode.

    IP address/Domain name

    IP address or domain name for network diagnosis.

    This parameter is available only when Diagnosis mode is set to Ping or Traceroute.

    Domain name

    Domain name for network diagnosis.

    This parameter is available only when Diagnosis mode is set to DNS query.

    Number of pings

    Number of pings.

    This parameter is available only when Diagnosis mode is set to Ping.

    Data packet size

    Data packet size.

    This parameter is available only when Diagnosis mode is set to Ping.

    Maximum TTL for route tracing

    Maximum TTL for route tracing.

    This parameter is available only when Diagnosis mode is set to Traceroute.

  3. Click Start to start the diagnosis. After the diagnosis is complete, the diagnosis result is displayed in the Diagnosis Result area.
