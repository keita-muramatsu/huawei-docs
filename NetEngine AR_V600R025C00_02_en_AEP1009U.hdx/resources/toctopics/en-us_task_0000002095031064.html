Wi-Fi Settings

Context

If a WAC is deployed on the network, you can configure the WLAN on the master device and deliver the WLAN configuration to the WAC through the HTTPS communication channel between the master and member devices. This allows the WAC to manage APs. The configuration includes the SSID, password, encryption mode, and authentication mode of the WLAN.

Procedure

  • Creating an SSID
    1. Choose Wireless > Wi-Fi Settings. The SSID List page is displayed, as shown in Figure 1.

      Figure 1 SSID List page

    2. Click Create. The Create SSID page is displayed, as shown in Figure 2.

      Figure 2 Basic Configuration page

      Set related parameters. Table 1 lists the parameters.

      Table 1 Parameters on the Basic Configuration page

      Parameter

      Description

      SSID

      SSID.

      Forwarding mode

      Forwarding mode of service data. Currently, only direct forwarding is supported.

      Service VLAN ID

      ID of a service VLAN. You can only select VLAN IDs that have been created in Service Network.

    3. Click Next. The Security Authentication page is displayed, as shown in Figure 3.

      Figure 3 Security Authentication page

      Set related parameters. Table 2 lists the parameters.

      Table 2 Parameters on the Security Authentication page

      Parameter

      Description

      Security configuration

      Security configuration option. The options are Unencrypted and Encrypted.

      Authentication mode

      Authentication mode.

      • SAE: applicable to WPA3.
      • PSK: applicable to WPA and WPA2.
      • PSK-SAE: applicable to WPA2 and WPA3.

      A hyphen between two authentication or encryption modes indicates that both modes are supported.

      This parameter is available when Security configuration is set to Encrypted.

      Encryption mode

      Encryption mode.

      This parameter is available when Security configuration is set to Encrypted.

      Encryption algorithm

      Encryption algorithm for security authentication. AES is recommended for its enhanced security.

      This parameter is available when Security configuration is set to Encrypted.

      Key

      Key for security authentication.

      This parameter is available when Security configuration is set to Encrypted.

    4. Click Next. The Policy Control page is displayed, as shown in Figure 4.

      Figure 4 Policy Control page

      Set related parameters. Table 3 lists the parameters.

      Table 3 Parameters on the Policy Control page

      Parameter

      Description

      AP Group

      AP group to which the policy is to be applied.

      Effective radio

      Effective radio.

    5. Click Finish.

      You can also choose Entire-Network > Network, click next to Service Network. On the Add Network page that is displayed, create an SSID under Wireless Configuration. For details, see Service Network.

  • Modifying an SSID
    1. Choose Wireless > Wi-Fi Settings. The SSID List page is displayed, as shown in Figure 1.
    2. Click next to the SSID to be modified. The Modify SSID page is displayed.
    3. Modify the parameters. For details about the parameters, see Table 1, Table 2, and Table 3.
    4. Click Finish.
  • Deleting an SSID
    1. Choose Wireless > Wi-Fi Settings. The SSID List page is displayed, as shown in Figure 1.
    2. Select the SSID to be deleted and click Delete or . The system asks you to confirm the deletion.
    3. Click OK.
