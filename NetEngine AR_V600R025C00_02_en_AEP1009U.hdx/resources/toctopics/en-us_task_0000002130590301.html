Network Topology

Context

On this page, you can view the topology information of the network.

Procedure

  1. Click Topology. The topology information page is displayed, as shown in Figure 1.

    Figure 1 Network topology

    You can move the cursor to a link marked with a number to view the detailed information about the link.

    You can also set the topology refresh interval in the upper right corner as required.

  2. Click a device in the topology. The device details are displayed on the right, as shown in Figure 2.

    Figure 2 Device details

    To go to the web system of a device, click Jump to Single Device Web. If this button is unavailable, the selected device does not support redirection to its web system through the master device.

    To change the device name, click next to the device name. The new device name is used only for display on WebMaster and does not affect that set on the device.

    The interface status of switches and WACs running V200 and AR routers running V300 cannot be obtained. Therefore, -- is displayed in the interface list.
