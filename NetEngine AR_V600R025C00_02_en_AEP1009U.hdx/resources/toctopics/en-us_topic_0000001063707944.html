Checking the Power Supply System

Table Power supply requirements lists power supply requirements of different router models.

Table 1 Power supply requirements

Check Item

Requirement

Preparation

Ensure that the external power supply system is ready before the installation.

Voltage

The operating voltage of the router must be within the normal range. For the operating voltage range of a router, see the Hardware Description of the product.

Power outlets and power cables
  • If the external power supply system provides country-specific power outlets, use AC power cables comply with the local standards.
  • Each router has its own power cables delivered as accessories. The power cables can only be used on the router in the same package and cannot be used on any other device.
