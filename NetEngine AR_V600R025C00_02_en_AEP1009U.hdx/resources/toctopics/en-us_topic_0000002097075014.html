Understanding the System-level Forwarding Mode

Service Performance Mode

Service performance modes include the routing mode, enhanced security mode, and security mode.

  • Routing mode: This mode is recommended when the IPS, antivirus, and URL filtering functions are not used. In this mode, the forwarding performance is optimal.
  • Security mode: This mode is recommended when the system needs to use security functions. In this mode, the security performance is improved, but the forwarding performance deteriorates.
  • Enhanced security mode: This mode is recommended when the security capability needs to be maximized. Compared with the security mode, the security performance is further enhanced, but the forwarding performance further deteriorates.

Dynamic and Static Core Adjustment

In static core adjustment, after CPU resources are allocated for security services, the CPU resources cannot be used for forwarding services even if there is no security service traffic on the device. The CPU resource allocation can be adjusted only after the service performance mode is configured. Dynamic core adjustment can flexibly adjust CPU resource allocation. The device allocates CPU resources for security services only when there is security service traffic on the device. When there is no security service traffic on the device, CPU resources allocated for security services in service performance mode can be used for forwarding services.

Hardware-based Routing

Hardware-based routing can adjust data forwarding paths. Packets that meet the conditions can be directly forwarded by hardware. If all services configured on a device support hardware forwarding, the device directly forwards packets received using hardware, without forwarding them through the CPU. In this way, the forwarding performance is improved. If services that do not support hardware forwarding are configured on the device, the device still sends the received packets to the software for forwarding.
