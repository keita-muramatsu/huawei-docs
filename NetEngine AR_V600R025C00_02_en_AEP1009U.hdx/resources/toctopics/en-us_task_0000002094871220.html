Entire-Network Deployment Configuration

Context

You can log in to WebMaster on the master device to perform basic configurations for entire-network management and deployment.

Procedure

  1. Log in to the device and access the View Entire Network page, as shown in Figure 1.

    Figure 1 View Entire Network page

    If the devices in the discovered device list are inconsistent with those on the actual network, check whether the device software version is V600R024C10/V200R024C10/V300R024C00SPC200 or later and whether the physical connections of the devices are normal. If so, click Rediscover in the lower right corner to rediscover devices on the network. If devices still cannot be discovered, continue with the deployment configuration. After the deployment is complete, import devices in the device list.

  2. Click Start Configuration. The Entire Network Configuration page is displayed, as shown in Figure 2.

    Figure 2 Entire Network Configuration page

  3. Set the parameters of the Internet access mode.

    Table 1 lists the parameters.

    Table 1 Internet access parameters

    Parameter

    Description

    Egress configuration

    Egress gateway

    Egress gateway.

    Internet access port

    Port for Internet access.

    Internet access mode

    Internet access mode:

    • PPPoE: The username and password need to be configured.
    • Static IP: The IP address, subnet mask, and gateway address need to be configured.
    • DHCP: The IP address is automatically obtained.

    DNS Server

    Primary DNS server

    Primary DNS server. By default, the value is 114.114.114.114.

    Secondary DNS server

    Secondary DNS server.

    Enable NAT

    Whether to enable NAT.

    Wireless configuration

    WAC NE

    WAC on the network.

    AP approval-free

    Whether to enable the approval-free function for APs.

    Country Code

    Country code for APs on the entire network.

    Entire network management configuration

    Entire network account

    Account for entire network management.

    Entire network password

    Password for entire network management.

    Confirm password

    Confirm password for entire network management.

    Networking configuration

    Eth-Trunk auto-negotiation

    Whether to enable Eth-Trunk auto-negotiation.

  4. Click Deliver Configuration.

    After the configuration is successful, click Go to Overview in the displayed dialog box. The Overview page is displayed.
