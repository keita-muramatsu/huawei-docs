Change Entire-Network Password

Context

On the Change Entire-Network Password page, you can change the entire-network device password.

This operation will change the passwords of all managed devices on the entire network. Therefore, exercise caution when performing this operation.

Procedure

  1. Choose Entire-Network > System Settings. The System Settings page is displayed, as shown in Figure 1.

    Figure 1 System Settings page

  2. Click Change next to Change Entire-Network Password. The Change Password dialog box is displayed, as shown in Figure 2.

    Figure 2 Change Password dialog box

  3. Enter the new password and confirm password.
  4. Click OK.
