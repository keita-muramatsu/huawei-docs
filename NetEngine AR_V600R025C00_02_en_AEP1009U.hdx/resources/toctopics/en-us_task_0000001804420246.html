(Optional) Configuring Forwarding Loop Detection

Context

In the SD-WAN hub-spoke scenario, when return traffic packets destined for a CPE site are continuously forwarded between hub sites, packet loss occurs because the TTLs of the packets are exhausted. In this case, where packets are lost cannot be accurately located by configuring traffic statistics collection. To solve this problem, you can enable loop detection at the hub sites to record looped traffic.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the site view.

    evpn site site-id

  3. Enable forwarding loop detection.

    forward-loop-check enable

    By default, forwarding loop detection is disabled on the device.

  4. Configure the forwarding loop detection period.

    forward-loop-check cycle cycle-value

    By default, the detection period is 180s.

Verifying the Configuration

  • Run the display evpn forward-loop-check info command to check forwarding loop detection information.
  • Run the reset evpn forward-loop-check info command to clear forwarding loop detection information.
