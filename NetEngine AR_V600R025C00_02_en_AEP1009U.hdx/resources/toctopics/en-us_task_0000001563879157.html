(Optional) Disabling Endpoint Discriminator Negotiation

Context

An endpoint discriminator uniquely identifies a device and is received from the remote end during LCP negotiation in MP.

MP negotiation succeeds only when endpoint discriminator negotiation setting is consistent on the MP-Group interfaces at both ends. If one end does not support endpoint discriminator negotiation but the function is enabled on the other end, MP negotiation fails. In this case, you need to disable endpoint discriminator negotiation on the device enabled with the function so that MP negotiation can succeed.

Procedure

  1. Enter the system view.

    system-view

  2. Create an MP-Group interface and enter the MP-Group interface view.

    interface mp-group number

  3. Disable the endpoint discriminator negotiation function.

    undo discriminator

    By default, endpoint discriminator negotiation is enabled on an MP-Group interface.

    After running the undo discriminator command on an MP-Group interface, run the shutdown command followed by the undo shutdown command on the sub-channels of the MP-Group interface for the configuration to take effect.
