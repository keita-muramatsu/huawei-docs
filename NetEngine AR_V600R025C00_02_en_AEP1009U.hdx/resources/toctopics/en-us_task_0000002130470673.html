Specifying the Master Device and Logging In to WebMaster

Context

After setting up the network and specifying the master device on the network, you can configure the WebMaster function on the master device. Then, you can log in to WebMaster and perform simple web operations to centrally configure and manage devices on the network.

After a device is configured as the master device and the WebMaster function is enabled, a virtual IP address (10.231.10.253) is created on the device by default. You can use this virtual IP address to log in to WebMaster and manage devices on the network.

Procedure

  1. Connect devices according to the network plan and power on the devices.

  2. Log in to the master device and configure the WebMaster function.

    • Method 1: Log in to the device through the web system, and perform the following operations to configure the WebMaster function. For details, see Logging In to the Device for the First Time Through the Web System in the Web Configuration Guide.
      • Choose Config > Enable WebMaster. On the WebMaster Enable page, toggle on Enable WebMaster.
        Figure 1 Enabling WebMaster
    • Method 2: Log in to the device through the console port and configure the WebMaster function using commands. For details, see "Net Assistant Configuration > Enabling the Net Assistant Function" in CLI Configuration Guide > System Management Configuration.

  3. Log in to WebMaster.

    When you use the virtual IP address for login on any device on the network, you log in to the master device on the network.

    A level-3 administrator account must be used for logging in to WebMaster. Otherwise, the login fails.

    1. Connect the network port of the administrator PC to any service port of any device on the network.

      If you have logged in to the web system of a device using the management port in 2, connect your PC to the service port on the master device for login.

    2. Set the IP address of the PC to be on the same network segment as the virtual IP address.
    3. Enter https://10.231.10.253:port in the address box of the browser.

      port indicates the port number for web login and defaults to 443. If the browser displays a message indicating that the certificate is insecure, select to continue browsing.

    4. On the login page that is displayed, enter the created username and password and click Log In.

      When you access the web login address, the browser cannot verify the default certificate provided by the device, and a security warning is displayed. You can click Download CA Certificate to download the certificate and double-click the certificate file to install it. No security warning is displayed upon the next login.

      When you log in to the device for the first time, the system prompts you to change the password. Change the password and log in again.
