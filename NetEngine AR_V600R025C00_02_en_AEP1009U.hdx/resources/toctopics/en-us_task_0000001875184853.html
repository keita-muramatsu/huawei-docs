Configuring a URL for the Portal Server

Context

You can bind a URL or a URL template to a Portal server template. Compared with URL binding, URL template binding allows you to configure the redirect URL of the Portal server and enable the URL to carry parameters related to users or the access device. The Portal server then can obtain user terminal information based on the parameters carried in the URL and provide different Portal authentication pages for different users. You can choose URL binding or URL template binding based on actual requirements.

Procedure

  • URL binding
    1. Enter the system view.

      system-view

    2. Enter the Portal server template view.

      web-auth-server server-name

    3. Configure a URL for the Portal server.

      url url-string

      By default, no URL is configured for a Portal server.

  • URL template binding
    1. Enter the system view.

      system-view

    2. Create a URL template and enter the URL template view.

      url-template name template-name

      By default, no URL template is created on the device.

    3. Configure a redirect URL for the Portal server.

      url [ push-only | redirect-only ] url-string [ ssid ssid ]

      By default, no redirect URL is configured for a Portal server.

    4. Set parameters in the URL.

      url-parameter { device-ip device-ip-value | device-mac device-mac-value | ap-ip ap-ip-value | ap-mac ap-mac-value | login-url url-key url | redirect-url redirect-url-value | ssid ssid-value | sysname sysname-value | user-ipaddress user-ipaddress-value | user-mac user-mac-value | ap-group-name ap-group-name-value | ap-location ap-location-value | ap-name ap-name-value } *

      By default, a URL does not carry parameters.

    5. Configure the MAC address format in the URL.

      url-parameter mac-address format delimiter delimiter { normal | compact }

      By default, the MAC address format in a URL is XXXXXXXXXXXX.

    6. Configure characters used in the URL.

      parameter { start-mark parameter-value | assignment-mark parameter-value | isolate-mark parameter-value } *

      By default, the start character of parameters in a URL is a question mark (?), the assignment character of the parameters is an equal sign (=), and the delimiter between the parameters is an ampersand (&).

    7. (Optional) Set redirection parameters.

      url-parameter set device-ip ip-address

      By default, the device automatically obtains redirection parameter settings.

    8. Return to the system view.

      quit

    9. Enter the Portal server template view.

      web-auth-server server-name

    10. Bind the URL template to the Portal server template.

      url-template url-template [ ciphered-parameter-name ciphered-parameter-name iv-parameter-name iv-parameter-name key cipher key-string ]

      By default, no URL template is bound to a Portal server template.

      The device supports encryption of parameter information in the URL template only when it connects to iMaster NCE-Campus.
