Maintaining the FEC Encoding and Decoding Instance Tables

Context

After FEC capability probing is complete, the transmit end creates an encoding instance table, and the receive end creates a decoding instance table. You can query the two tables to view the FEC communication statistics at both ends, including the number of sent original packets, number of sent redundant packets, number of received original packets, number of received redundant packets, and packet loss rate.

Procedure

  • Run the display forward-error-correction instance encode brief tunnel-type sd-wan [ connection-id connection-id-value | vpn-instance vpn-instance-name | { profile profile-name | profile-id profile-id-value } ] * or display forward-error-correction instance encode brief tunnel-type gre [ interface tunnel tunnel-id | { profile profile-name | profile-id profile-id-value } ] * command in any view to check brief information about the FEC encoding instance table.
  • Run the display forward-error-correction instance encode details tunnel-type sd-wan connection-id connection-id-value [ vpn-instance vpn-instance-name ] { profile profile-name | profile-id profile-id-value } or display forward-error-correction instance encode details tunnel-type gre interface tunnel tunnel-id { profile profile-name | profile-id profile-id-value } command in any view to check detailed information about the FEC encoding instance table.
  • Run the display forward-error-correction instance decode brief tunnel-type sd-wan [ connection-id connection-id-value | vpn-instance vpn-instance-name | profile-id profile-id-value ] * or display forward-error-correction instance decode brief tunnel-type gre [ interface tunnel tunnel-id | profile-id profile-id-value ] * command to check brief information about the FEC decoding instance table.
  • Run the display forward-error-correction instance decode details tunnel-type sd-wan connection-id connection-id-value [ vpn-instance vpn-instance-name ] profile-id profile-id-value or display forward-error-correction instance decode details tunnel-type gre interface tunnel tunnel-id profile-id profile-id-value command in any view to check detailed information about the FEC decoding instance table.
  • Run the reset forward-error-correction instance all command in the user view to reset the FEC encoding instance table.

    If the tunnel interface keeps sending packets, new FEC configurations take effect after a delay. You can reset the FEC encoding instance table to make the new FEC configurations take effect immediately.
