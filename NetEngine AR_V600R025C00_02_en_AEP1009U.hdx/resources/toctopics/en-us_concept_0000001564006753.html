URL Filtering Mode

The device supports a variety of URL filtering modes. When a user's URL access request matches a URL rule, the device processes the request based on the configuration in the URL filtering profile.

URL Blacklist and Whitelist

The URL blacklist and whitelist can be considered a special user-defined URL category, but the control actions for the blacklist and whitelist are fixed and cannot be changed.

The URL blacklist and whitelist are typically used to filter websites with simple and fixed URLs. The blacklist is a list of URLs that users are not allowed to access, whereas the whitelist is a list of URLs that users are allowed to access. A device matches the URLs in access request packets against the URLs in the blacklist and whitelist. Access is denied if a URL matches one in the blacklist, or permitted if it matches one in the whitelist.

Predefined URL Categories

Predefined URL categories are generated on a device after a predefined URL category database is loaded to the device. This database maintains a large number of URLs of mainstream websites and the URL categories. These URL categories cannot be modified or deleted. After receiving a URL access request, the device queries the URL category to which the URL belongs. After finding the matching URL category, the device processes the request based on the category control action configured in the URL filtering profile.

A device can query URL categories locally or remotely. When a device is powered on for the first time, it automatically loads the predefined URL category database to its cache. After receiving a URL access request, the device first queries its local cache for the URL category. If no matching category is found for the URL, the device queries the remote query server for the URL category.

The remote query server provides more than 500 million URL categories. If a new URL is not covered by the remote query server, the device periodically and dynamically invokes the access server to simulate accesses to the URL and obtains the web page content for the URL category. The category information is synchronized to the remote query server.

To ensure the content of the cached database remains valid, the device periodically updates it, replacing the earliest accessed URLs with new ones if the cache is full. The device also periodically saves the cached content as files to storage media. In this way, the device can automatically load the latest file upon restart, without needing to relearn the URL categories. This helps to improve the detection efficiency.
