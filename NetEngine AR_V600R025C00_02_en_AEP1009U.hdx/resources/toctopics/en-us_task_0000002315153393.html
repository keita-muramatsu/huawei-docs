Validity Time

Context

You can configure the validity time of an ACL rule to enable some services or functions to start at a specified time point or at a specified interval.

Procedure

  • Create a validity time range.

    1. Log in to the web system and choose Config > Security > ACL. On the Validity Time tab page, click Create. The Create Time Range page is then displayed, as shown in Figure 1. Table 1 describes the parameters for creating a validity time range.
      Figure 1 Creating a validity time range
      Table 1 Parameters for creating a validity time range

      Parameter

      Description

      Time range name

      Name of a validity time range.

      Weekly Time Range

      Weekly effective time

      Periodic time range of an ACL rule, including the validity period in a week, start time, and end time.

      The validity period in a week can be Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, or Sunday. You can select one or more days.

      The start time and end time are in the range of 00:00 to 23:59. When both the start time and end time are 00:00, the time range is from 00:00 to 24:00 of the current day.

      After the validity period in a week, start time, and end time are selected, click Add. You can repeat the preceding operations to create multiple time ranges.

      Start time and end time

      Start time and end time of the weekly time range.

      Validity Time Range

      Start time and end time

      Validity period of an ACL rule, including the start time and end time.

      After the start time and end time are selected, click Add. You can repeat the preceding operations to create multiple validity periods.
    2. Click OK.

  • Modify a validity time range.

    1. Log in to the web system and choose Config > Security > ACL. On the Validity Time tab page, click on the right of the validity time range list. The Modify Time Range page is then displayed, as shown in Figure 2. Table 1 describes the parameters for modifying a validity time range.
      Figure 2 Modifying a validity time range
    2. Modify the validity time range and click OK.

  • Delete a validity time range.

    1. Log in to the web system and choose Config > Security > ACL. On the Validity Time tab page, click on the right of the validity time range list. The page for deleting a validity time range is then displayed, as shown in Figure 3.
      Figure 3 Page for deleting a validity time range
    2. Click OK to delete the validity time range.
