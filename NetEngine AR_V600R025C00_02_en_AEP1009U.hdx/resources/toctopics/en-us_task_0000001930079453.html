Configuring an L2TP Client

Procedure

  1. Enter the system view.

    system-view

  2. Enable L2TP globally.

    l2tp enable

    By default, L2TP is disabled.

  3. Create an L2TP group.

    l2tp-group group-number

    By default, no L2TP group is created.

  4. Specify the local name of a tunnel.

    tunnel name tunnel-name

    By default, the local name of a tunnel is the device name.

  5. Specify the trigger condition for initiating a call when the local end functions as an L2TP client.

    • Specify an IP address as a trigger condition.
      start l2tp ip ip-address &<1-5>

      By default, no IP address is specified as a trigger condition.

    • Specify a domain name as a trigger condition.
      start l2tp host host-name

      By default, no domain name is specified as a trigger condition.

  6. (Optional) Specify the VPN instance to which the IP address used by the L2TP group for establishing an L2TP connection belongs.

    vpn-instance vpn-instance-name

    By default, the IP address used by an L2TP group for establishing an L2TP connection does not belong to any VPN instance.

  7. Specify the password for tunnel authentication.

    tunnel password cipher password

    By default, tunnel authentication is enabled, but no authentication password is configured.

  8. Enable L2TP tunnel authentication.

    tunnel authentication

    By default, L2TP tunnel authentication is enabled.

  9. (Optional) Set the interval for sending Hello packets through the tunnel.

    tunnel timer hello interval

    By default, Hello packets are sent every 60 seconds.

  10. Return to the system view.

    quit

  11. Enter the dialer interface view.

    interface Dialer number

  12. Specify the number of the L2TP group and enable automatic L2TP dial-up on the dialer interface.

    l2tp-auto-client l2tp-group group-number

    By default, automatic L2TP dial-up is disabled on a dialer interface.
