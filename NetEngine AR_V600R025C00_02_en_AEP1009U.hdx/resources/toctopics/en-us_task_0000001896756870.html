Configuring PPP Authentication

Context

If PPP authentication has been configured on the LNS connected to an L2TP client, configure the user name and password for the corresponding authentication mode on the L2TP client. PPP supports Password Authentication Protocol (PAP) authentication and Challenge Handshake Authentication Protocol (CHAP) authentication. PAP authentication is initiated by the authenticated device, and CHAP authentication is initiated by the authenticating device.

  • When the authentication mode is set to PAP on the LNS, the L2TP client sends the authentication user name and password. If the user name and password are the same as those configured on the LNS, the authentication succeeds.
  • When the authentication mode is set to CHAP on the LNS, the authentication process varies depending on whether the LNS is configured with a user name.
    • If the LNS is configured with a user name, the L2TP client compares its configured user name with the user name received from the LNS. If the two user names are the same, the L2TP client sends a packet containing its authentication user name and password. After receiving the packet, the LNS compares its local access user name and password with the received ones. The authentication is successful only when they are consistent.
    • If the LNS is not configured with a user name, the L2TP client sends a packet containing its authentication user name and password. After receiving the packet, the LNS compares its local access user name and password with the received ones. The authentication is successful only when they are consistent.

    Regardless of whether the LNS is configured with a user name when it authenticates the L2TP client in CHAP mode, the L2TP client can perform CHAP authentication based on the configured CHAP user name and password.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the dialer interface view.

    interface Dialer number

  3. Configure the authentication user name and password for the L2TP client based on the authentication mode configured on the LNS.

    • When the authentication mode of the LNS is PAP:
      Configure the user name and password sent by the L2TP client for PAP authentication.
      ppp pap local-user user-name password { simple password | cipher { password1 | password2 } }

      The user name and password configured on the L2TP client for PAP authentication must be the same as the local access user name and password configured on the LNS.

      By default, the local device sends a packet with the user name and password fields being empty to the remote device if the remote device uses PAP authentication.

    • When the authentication mode of the LNS is CHAP and the LNS is configured with a user name:
      1. Configure the user name used by the LNS for CHAP authentication of the L2TP client.
        ppp chap user user-name

        The user name configured on the L2TP client for CHAP authentication must be the same as that configured on the LNS.

      2. Return to the system view.
        quit
      3. Enter the AAA view.
        aaa
      4. Create a local access user and configure the local access user name.
        local-access-user user-name
      5. Configure the password for the local access user.
        password cipher password

        The local access user name and password configured on the L2TP client must be the same as those configured on the LNS.

      6. Configure PPP as the access type of the local access user.
        service-type ppp
    • When the authentication mode of the LNS is CHAP and the LNS is not configured with a user name:
      1. Configure the user name used by the LNS for CHAP authentication of the L2TP client.
        ppp chap user user-name
      2. Configure the password used by the LNS for CHAP authentication of the L2TP client.
        ppp chap password { simple password | cipher { password1 | password2 } }

        If simple is specified, the password is saved in plain text in the configuration file, which poses security risks. You are advised to specify cipher so that the password is saved in cipher text in the configuration file.
