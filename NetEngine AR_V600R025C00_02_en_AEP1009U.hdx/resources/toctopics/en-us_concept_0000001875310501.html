Portal Authentication Protocol

Portal protocols include:

  • Portal access protocol: HTTP or HTTPS, which is used for interaction between clients and the Portal server.

    A client sends a connection request and a Portal authentication request to the Portal server in sequence through HTTP or HTTPS. For details about the authentication process, see Portal-based Portal Authentication Process or HTTP- or HTTPS-based Portal Authentication Process.

  • Portal authentication protocols include:

    • Portal protocol: is used for interaction between the Portal server and access devices. It transfers parameters such as the user name and password.

      After the Portal server receives a Portal authentication request from a client, the Portal server initiates a Portal authentication request carrying the user name and password to an access device through the Portal protocol. For details about the authentication process, see Portal-based Portal Authentication Process.

    • HTTP or HTTPS protocol: is used for interaction between clients and access devices. It transfers parameters such as the user name and password.

      After the Portal server receives a Portal authentication request from a client, the Portal server instructs the client to initiate a Portal authentication request to an access device through HTTP or HTTPS. The client then initiates a Portal authentication request carrying the user name and password to the access device through HTTP or HTTPS. For details about the authentication process, see HTTP- or HTTPS-based Portal Authentication Process.

It is recommended that an access device use the Portal protocol to communicate with the Portal server. If the Portal server does not support the Portal protocol, the access device can use the HTTP or HTTPS protocol.

HTTP or HTTPS can be used as the Portal access protocol and Portal authentication protocol. This section primarily describes the Portal authentication protocols supported by access devices.
