MAC Address-Prioritized Portal Authentication

MAC address-prioritized Portal authentication allows disconnected users who have passed Portal authentication to access the network again within a certain period of time, without having to reenter their user names and passwords, as long as they pass MAC address authentication. To use this function, you need to configure MAC address + Portal authentication on the access device, enable MAC address-prioritized Portal authentication on the authentication server, and set the MAC address validity period. After the configuration is complete, a user who has passed Portal authentication can access the network again through MAC address authentication within the validity period.

Authentication Process

On the network shown in Figure 1, when a client is to be authenticated for the first time, the access device sends the client's MAC address to the RADIUS server. However, the authentication fails because the RADIUS server does not find the client's MAC address. Then Portal authentication is triggered for the client. After the authentication is successful, the RADIUS server automatically saves the client's MAC address.

  • If the client's MAC address is stored on the RADIUS server, the RADIUS server checks the user name and password (the user name and password are the MAC address) and authorizes the client. Then the client can access the network without entering the user name and password again.
  • If the client's MAC address expires on the RADIUS server, the RADIUS server deletes the client's MAC address. In this case, MAC address authentication fails, and the access device redirects the client to the Portal authentication page. The client user needs to enter the user name and password for identity authentication.
