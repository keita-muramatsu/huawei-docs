Configuring PPP as the Link Layer Protocol of an Interface

Context

Before configuring PPP parameters of an interface, configure PPP as the link layer protocol of the interface and configure an IP address for the interface.

You can configure an IP address for the interface using any of the following methods:

  • Configure an IP address on the interface.
  • Configure the interface to obtain an IP address through IP address negotiation.
  • Configure the interface to borrow an IP address from another interface.

The IP address negotiation function of PPP allows a server to assign an IP address to a client. IP address negotiation can be configured in two scenarios as follows:

  • The device functions as a client.

    If the local interface runs PPP at the link layer but is not configured with an IP address, and the remote interface has an assignable IP address, you can configure the device as a client and configure IP address negotiation on the local interface so that it can obtain an IP address from the remote interface. For example, when the client accesses the Internet through an Internet service provider (ISP) network using PPP, it can obtain an IP address from the ISP.

  • The device functions as a server.

    The local interface assigns an IP address to the remote interface.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the interface view.

    interface interface-type interface-number

  3. Configure PPP as the link layer protocol of the interface.

    link-protocol ppp

  4. Configure an IP address for the local interface.

    • Configure an IP address on the interface.
      Configure an IPv4 address on the interface.
      ip address ip-address { mask | mask-length }[ tag tag-value ]

    • Configure the device as a client so that the local interface obtains an IP address through IP address negotiation.
      ip address ppp-negotiate

      By default, the local interface is not configured with IP address negotiation.

    • Configure the interface to borrow an IP address from another interface.
      ip address unnumbered interface { interface-name | interface-type interface-number }

  5. Configure the device as a server so that the local interface assigns an IP address to the remote interface.

    remote address ip-address

    By default, the local interface does not assign an IP address to the remote interface.
