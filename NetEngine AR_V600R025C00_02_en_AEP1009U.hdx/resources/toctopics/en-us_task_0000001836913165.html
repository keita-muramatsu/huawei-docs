Maintaining Data Compression

Context

Statistics cannot be restored after being cleared. Exercise caution when clearing statistics.

Procedure

  • Run the display per-packet-compress statistics command in any view to check statistics about per-packet compression.
  • Run the reset per-packet-compress statistics command in the user view to clear statistics about per-packet compression.
