Verifying the Configuration

Context

After an L2TP client is configured, you can view the L2TP configuration, tunnel status, and session status on the L2TP client.

Procedure

  • Run the display l2tp-group { all | [ group-number ] } command to check the L2TP group and L2TP group configuration on the device.
  • Run the display l2tp tunnel { brief | all | tunnel-id tunnel-id | peer-name remote-name } command to check information about established L2TP tunnels.
  • Run the display l2tp session { brief | all | session-id session-id | destination-ip dest-ip-addr | source-ip src-ip-addr } command to check information about L2TP sessions established on the current device.
