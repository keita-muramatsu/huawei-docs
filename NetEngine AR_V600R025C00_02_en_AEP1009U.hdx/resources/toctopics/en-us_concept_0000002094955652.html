Interface Layout

Figure 1 shows the typical user interface of WebMaster, and Table 1 describes each area of the user interface.

Figure 1 WebMaster interface layout
Table 1 Interface layout

No.

Description

1

Function menu area. The WebMaster page consists of four functional areas: Topology, Wireless, Maintenance, and Entire-Network.

NOTE:

You can click the icon next to Function Menu to display the function items in tile or list mode.

You can also click the Expand icon in the lower left corner to display both the menu icons and texts or click the Collapse icon to display only the menu icons.

2

Status display and operation area. This area displays the service status and allows you to perform create, modify, delete, and search operations.

3

Auxiliary menu area. This area displays the search box, alarm icon, Save Configuration icon, language, About, and account icon.

NOTE:
  • To quickly access a function page, click the search box, and then enter or click the desired function item.
  • To go to the Alarm page, click .
  • To save the configurations of network-wide devices, click . After the configuration is complete, you are advised to save the configuration in a timely manner to prevent configuration loss caused by the restart of network-wide devices.
  • To switch the WebMaster language, click the language attribute.
  • To log out of WebMaster, click the account icon and choose Log Out.
