Verifying the Configuration

Context

After configuring the Portal server template, run the following commands to check the configuration.

Procedure

  • Run the display web-auth-server configuration command to check the configuration of the Portal server using Portal.
  • Run the display url-template { all | name template-name } command to check the URL template configuration.
  • Run the display portal-server state [ web-auth-server server-name ] command to check the Portal server status.
