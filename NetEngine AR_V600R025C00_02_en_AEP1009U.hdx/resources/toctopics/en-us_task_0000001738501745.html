Configuring Loopback Detection on a POS Interface

Context

Configuring loopback detection (using the loopback command) causes a POS interface or link to stop working properly. After the detection is complete, run the undo loopback command promptly to cancel it.

Loopback detection needs to be enabled to perform some special functions, for example, diagnosing POS interface faults preliminarily.

Table 1 describes loopback classification.

Table 1 Loopback classification

Loopback Classification

Hardware loopback

The transmit and receive ends are directly connected using a cable so that the tested device receives signals sent by itself.

Software loopback

Remote loopback (external loopback)

The local interface sends a packet received from the remote interface back to the remote interface, instead of forwarding the packet to the destination address.

Local loopback (internal loopback)

A packet from an interface is sent back to this interface inside the system.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the POS interface view.

    interface pos interface-number

  3. Configure a loopback detection mode on the interface.

    loopback { local | remote }

    By default, loopback detection is disabled.
