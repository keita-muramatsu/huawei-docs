URL Filtering Profiles

A URL filtering profile is a set of URL filtering rules and contains all URL filtering configurations. To implement URL filtering, you need to configure a URL filtering profile and reference it in a security policy.

Table 1 describes the filtering modes defined in a URL filtering profile.

Table 1 Filtering modes defined in a URL filtering profile

Filtering Mode

Handling Action

URL blacklist-based

The default action is Block (non-configurable).

URL whitelist-based

The default action is Allow (non-configurable).

Whitelist mode

After this function is enabled, if a URL request matches the whitelist, the request is permitted; if not, the request is blocked.

URL category-based

The actions for URL categories can be configured in two ways:

  • Specify the control action level. In this way, default actions apply automatically to different URL categories without the need for you to manually configure them.
    • Low: blocks access to adult/mature content websites, but allows access to other categories.
    • Moderate: blocks access to adult/mature content websites and illegal content websites, but allows access to other categories.
    • High: blocks access to adult/mature content websites, illegal content websites, social networking websites, and video sharing websites, but allows access to other categories.
  • Define an action for each category.

    • allow: allows access to the requested URL and does not record any log.

    • alert: allows access to the requested URL and records a log with the action being alert.

    • block: blocks access to the requested URL and records a log with the action being block.

URLs do not match any filtering mode.

The default action is taken.

  • allow: allows access to the requested URL and does not record any log.

  • alert: allows access to the requested URL and records a log with the action being alert.

  • block: blocks access to the requested URL and records a log with the action being block.

Encrypted traffic filtering

After this function is enabled, the device processes the domain names extracted from encrypted traffic based on the control action of the matched URL blacklist, URL whitelist, or URL category.

The device has a default URL filtering profile named default. This profile cannot be modified or deleted. It uses the URL category-based filtering mode, with the user-defined control action level. The default action allow.
