(Optional) Configuring the Number of Fragments Cached During Packet Reassembly on an MP-Group Interface

Context

MP bundles multiple channels. If the traffic transmitted over an MP link contains large packets that need to be fragmented and the traffic exceeds the physical bandwidth of the MP link, packet reassembly at the receive end will fail.

To prevent this, you can configure a proper number of fragments cached during packet reassembly at the receive end.

Procedure

  1. Enter the system view.

    system-view

  2. Create an MP-Group interface and enter the MP-Group interface view.

    interface mp-group number

  3. Configure the number of fragments cached during packet reassembly on an MP-Group interface.

    packet-reassembly cache cache-size

    By default, 512 fragments are cached during packet reassembly on an MP-Group interface.

    After the configuration, run the shutdown command followed by the undo shutdown command or run the restart command in the interface view to restart the interface for the configuration to take effect.
