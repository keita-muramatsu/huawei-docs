Internet Access Through Broadband Dialup

Context

If you have obtained a user name and password from an Internet Service Provider (ISP), you can connect a device to the Internet through broadband dialup.

Procedure

  1. Choose Config > Config Wizard > Online Config Wizard and set Internet access mode to Broadband Dial-up, as shown in Figure 1.

    Figure 1 Internet access through broadband dialup
    1. Set parameters for Internet access through broadband dialup. For details about the parameters, see Table 1.
      Table 1 Parameters for configuring Internet access through broadband dialup (mandatory)

      Parameter

      Description

      Internet interface

      Layer 3 interface to be used for Internet access. If the interface you want to select is a Layer 2 interface, click on the interface icon to switch the interface to a Layer 3 interface and then select this interface.

      UserName

      Username used for PPPoE dialup. The value is a string of 1 to 253 characters.

      Password

      Password used for PPPoE dialup. The value is a string of 1 to 128 characters, including only uppercase letters, lowercase letters, digits, and special characters except question marks (?).
    2. Set DNS server parameters. For details about the parameters, see Table 2.
      Table 2 Parameters for configuring DNS servers for Internet access through broadband dialup (optional)

      Parameter

      Description

      DNS server 1

      Preferred DNS server address assigned to DHCP clients. To add a DNS server address, click on the right.
    3. Set advanced parameters. For details about the parameters, see Table 3.
      Table 3 Advanced parameters for configuring Internet access through broadband dialup (optional)

      Parameter

      Description

      MTU

      Maximum transmission unit (MTU) of an interface. The value is an integer from 128 to 2000, in bytes. By default, the MTU of an interface is 1492 bytes.

      TCP-MSS (bytes)

      Maximum segment size (MSS) of TCP packets on an interface. The value ranges from 128 to 2048. The default value is 1200.

      Default route priority

      Route priority. The value ranges from 1 to 255. The default value is 60.

      Enable NAT

      Whether to enable NAT. By default, this function is enabled. After NAT is enabled, the IP address of an interface is used as the post-NAT address.

  2. Click Confirm. If you need to reset all parameters, click Clear and set the parameters again.
