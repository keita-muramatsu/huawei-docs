Configuring the DHCPv6 PD Client Function

Context

When a device's upstream interface functions as a DHCPv6 PD client, it uses DHCPv6 to dynamically obtain an IPv6 address prefix from the DHCPv6 PD server. The obtained IPv6 address prefix is bound to a downstream interface, so that an IPv6 address can be automatically generated for a user connected to the downstream interface in route advertisement mode.

Procedure

  1. Enter the system view.

    system-view

  2. Configure the IPv6 function on an upstream interface.

    1. Enter the interface view.
      interface interface-type interface-number
    2. Switch the interface working mode to Layer 3.
      undo portswitch

      Determine whether to perform this step based on the current interface working mode.

    3. Enable the IPv6 function on the interface.
      ipv6 enable

      By default, the IPv6 function is disabled on an interface.

    4. Configure the global unicast IPv6 address function on the interface.
      ipv6 address { ipv6-address prefix-length | ipv6-address/prefix-length }

  3. Configure the DHCPv6 PD client function on the upstream interface to obtain network configuration parameters.

    1. Enter the system view.
      system-view
    2. (Optional) Configure a DUID for the DHCPv6 device.
      dhcpv6 duid { ll | llt | duid }

      By default, a device generates a DUID based on a link-layer (LL) address.

    3. Enter the interface view.
      interface interface-type interface-number
    4. Configure the DHCPv6 PD client function. Run either of the following commands as required. If a client is specified to use a message to obtain both an IPv6 address and a prefix, the union-mode parameter needs to be configured.
      dhcpv6 client dhcp [ hint ipv6-address ] pd iprefix-name [ hint ipv6-prefix ] [ rapid-commit ] [ unicast-option ] union-mode 
dhcpv6 client [ dhcp [ hint ipv6-address ] ] pd iprefix-name [ hint ipv6-prefix ] [ rapid-commit ] [ unicast-option ]

      By default, the DHCPv6 PD client function is disabled on a device.

      You can specify the rapid-commit parameter to configure a DHCPv6 PD client to request an IPv6 address prefix using the two-message exchange. The server assigns an IPv6 address prefix to a client using two-message exchange only when two-message exchange is enabled on both them. Otherwise, the server assigns an IPv6 address prefix to the client using four-message exchange.

Follow-up Procedure

Bind the obtained IPv6 address prefix to the device's downstream interface and enable the downstream interface to send RA messages, so that an IPv6 address can be automatically generated for a user in route advertisement mode.

  1. Enter the system view.
    system-view
  2. Enter the interface view.
    interface interface-type interface-number
  3. Switch the interface working mode to Layer 2.
    portswitch

    Determine whether to perform this step based on the current interface working mode.

  4. Enable the IPv6 function on the interface.
    ipv6 enable

    By default, the IPv6 function is disabled on an interface.

  5. Configure a link-local address for the interface.
    • Manually configure a link-local address for the interface.
      ipv6 address ipv6 address link-local
    • Configure the interface to automatically generate a link-local address.
      ipv6 address auto link-local

    By default, no link-local address is configured for an interface.

  6. Bind the IPv6 address prefix automatically obtained by the DHCPv6 PD client to the interface.
    ipv6 address dhcpv6-prefix { ipv6-address prefix-length | ipv6-address/prefix-length }

    By default, an interface is not bound to the IPv6 address prefix automatically obtained by a DHCPv6 PD client. The value of prefix-length for the IPv6 address prefix bound to the interface must be greater than the length of the prefix obtained by the DHCPv6 PD client; otherwise, the interface cannot generate a global unicast IPv6 address based on the bound IPv6 address prefix. You can run the display dhcpv6 client prefix [ name prefix-name ] command to check the length of the prefix obtained by the DHCPv6 PD client.

  7. Enable the interface to send RA messages.
    ipv6 nd ra halt disable

    By default, an interface is disabled from sending RA messages.
