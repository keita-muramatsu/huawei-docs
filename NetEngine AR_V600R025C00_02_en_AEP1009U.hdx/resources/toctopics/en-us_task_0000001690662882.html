Example for Configuring POS Interfaces

Networking Requirements

As shown in Figure 1, two devices are connected through an SDH network. DeviceB has been configured. To ensure successful interconnection, configure the POS interface on DeviceA.

The POS interface on DeviceB is configured as follows:

  • The link layer protocol is HDLC.
  • The clock mode is slave.
  • The MTU is 1200 bytes.
  • Payload scrambling is disabled.
  • The CRC code length is 16 bits.
  • C2 is 3, and J0 and J1 are abc and xyz, respectively, in 16-byte mode.
Figure 1 Network diagram of configuring a POS interface

Configuration Roadmap

The configuration roadmap for DeviceA is as follows:

  1. Set the link layer protocol of the POS interface on DeviceA to HDLC.
  2. Set the clock mode of the POS interface on DeviceA to slave.
  3. Set the MTU of the POS interface on DeviceA to 1200 bytes.
  4. Configure the scrambling function for the POS interface on DeviceA.
  5. Set the CRC code length of the POS interface on DeviceA to 16 bits.
  6. Set C2 to 3, and set J0 and J1 to abc and xyz, respectively, in 16-byte mode for the POS interface on DeviceA.

Procedure

  1. Set the link layer protocol of the POS interface on DeviceA to HDLC.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] interface pos 1/0/0
[DeviceA-Pos1/0/0] link-protocol hdlc

  2. Set the clock mode of the POS interface on DeviceA to slave.

    [DeviceA-Pos1/0/0] clock slave

  3. Set the MTU of the POS interface on DeviceA to 1200 bytes.

    [DeviceA-Pos1/0/0] mtu 1200

  4. Configure overhead bytes for the POS interface on DeviceA.

    [DeviceA-Pos1/0/0] flag c2 3
[DeviceA-Pos1/0/0] flag j0 16byte-mode abc
[DeviceA-Pos1/0/0] flag j1 16byte-mode xyz

  5. Configure the scrambling function for the POS interface on DeviceA.

    [DeviceA-Pos1/0/0] undo scramble

  6. Set the CRC code length of the POS interface on DeviceA to 16 bits.

    [DeviceA-Pos1/0/0] crc 16

  7. Configure an IP address for the POS interface on DeviceA.

    [DeviceA-Pos1/0/0] ip address 10.1.1.1 30

Configuration Scripts

DeviceA
#
 sysname DeviceA
#
interface Pos1/0/0
 link-protocol hdlc
 clock slave
 mtu 1200
 ip address 10.1.1.1 255.255.255.252
 flag c2 3
 flag j0 16byte-mode abc
 flag j1 16byte-mode xyz
 undo scramble
 crc 16
#
return
