Portal Authentication Process

The first thing to do during authentication is to initiate authentication. There are two methods for triggering authentication:

  • Active authentication

    A user proactively accesses the Portal authentication website through a browser, enters the IP address of the Portal server in the browser, and then enters the user name and password on the displayed web page for authentication.

  • Redirect authentication

    A user accesses a page other than the Portal authentication page, and then the user is redirected to the Portal authentication website for Portal authentication.
