AP Wired Port

Context

You can configure the wired port on an AP to deploy a Layer 2 network or directly associate with STAs.

This function can be configured only when a WAC running V600 is deployed on the network.

Procedure

  • Creating an AP wired port entry
    1. Choose Wireless > AP Wired Port. The AP Wired Port List page is displayed, as shown in Figure 1.

      Figure 1 AP Wired Port List page

    2. Click Add. The Add AP Wired Port page is displayed, as shown in Figure 2.

      Figure 2 Adding an AP wired port

    3. Enter the service network name and select an AP wired port.
    4. Click OK.
  • Modifying an AP wired port entry
    1. Choose Wireless > AP Wired Port. The AP Wired Port List page is displayed, as shown in Figure 1.
    2. Click next to an AP wired port. The Modify dialog box is displayed.
    3. Modify parameters as required.
    4. Click OK.
  • Deleting an AP wired port entry
    1. Choose Wireless > AP Wired Port. The AP Wired Port List page is displayed, as shown in Figure 1.
    2. Select the AP wired port to be deleted and click Delete or . The system asks you to confirm the deletion.
    3. Click OK.
