Configuring Parameters for a VDSL Interface

Context

When the device functions as a CPE, its bit exchange, seamless rate adaptation, and trellis coding settings must be the same as those on the DSLAM so that the device can communicate with the DSLAM.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the VDSL interface view.

    interface Ethernet interface-number

  3. Enable or disable bit exchange on the VDSL interface.

    adsl bitswap { off | on }

    By default, bit exchange is enabled on a VDSL interface.

  4. Enable or disable seamless rate adaptation on the VDSL interface.

    adsl sra { off | on }

    By default, seamless rate adaptation is disabled on a VDSL interface.

  5. Enable or disable trellis coding on the VDSL interface.

    adsl trellis { off | on }

    By default, trellis coding is enabled on a VDSL interface.

  6. (Optional) Enable the enhanced anti-noise function on the VDSL interface.

    vdsl anti-noise enable

    By default, the enhanced anti-noise function is disabled on a VDSL interface.

  7. (Optional) Enable the downstream retransmission function on the VDSL interface.

    vdsl downstream-retrans enable

    By default, the downstream retransmission function is enabled on a VDSL interface.

  8. (Optional) Enable the upstream retransmission function on the VDSL interface.

    vdsl upstream-retrans enable

    By default, the upstream retransmission function is enabled on a VDSL interface.

Verifying the Configuration

Run the display vdsl all interface or display vdsl interface { interface-type interface-number | interface-name } command to check the parameter settings and status of the specified VDSL interface.
