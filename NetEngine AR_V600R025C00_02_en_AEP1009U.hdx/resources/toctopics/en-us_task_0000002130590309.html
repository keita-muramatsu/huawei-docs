Service Network

Context

On this page, you can view the structure of the entire network in a topology and quickly divide the network.

Procedure

  • Adding a service network
    1. Choose Entire-Network > Network. The Service Network page is displayed.
    2. Click next to Service Network. The Add Network page is displayed, as shown in Figure 1.

      Figure 1 Adding a network

    3. Set the parameters.

      Table 1 lists the parameters.

      Table 1 Parameters for adding a network

      Parameter

      Description

      Service VLAN name

      Name of the service VLAN to be added.

      Service gateway

      Service gateway.

      VLAN ID

      VLAN ID.

      IP address/Mask

      IP address and mask of the service network to be added.

      DHCP Server

      Primary DNS server

      Primary DNS server of the service network to be added.

      Secondary DNS server

      Secondary DNS server of the service network to be added.

      Lease

      Lease time of the IP address.

    4. Click Next. The Wired Configuration page is displayed, as shown in Figure 2.

      Select the device and its interfaces to join the wired network. If no device or interface is selected, the wired network is not configured.

      Figure 2 Wired Configuration page

      You can perform the following operations on interfaces as required:

      • Selecting a single interface: Click the interface icon to select a single interface. To deselect the interface, click the interface icon again.
      • Selecting multiple consecutive interfaces: Drag the mouse to select multiple consecutive interfaces.
      • Selecting multiple non-consecutive interfaces: Click different interface icons one by one to select multiple interfaces. To deselect an interface, click the interface icon again.
      • Selecting all interfaces: Click Select All in the upper right corner of the panel. To deselect all interfaces, click Deselect All.
      • Inversely selecting non-consecutive interfaces: Click interface icons on the panel and click Invert in the upper right corner of the panel to select the other interfaces.

    5. Click Next. The Wireless Configuration page is displayed.

      You can set parameters on the Wireless Configuration page only when a WAC running V600 is deployed on the network.

      You can also choose Wireless > Wi-Fi Settings on the home page to configure a wireless network. For details, see Wi-Fi Settings.

      1. Click to add a wireless network, as shown in Figure 3.
        Figure 3 Adding a wireless network
      2. Set the parameters.

        Table 2 lists the parameters.

        Table 2 Wi-Fi network parameters

        Parameter

        Description

        Wi-Fi name

        Name of a wireless network.

        Authentication mode

        Authentication mode of the wireless network.

        Encryption mode

        Encryption mode of the wireless network.

        Key

        Key of the wireless network.

        AP group

        AP group.

        Effective radio

        Effective radio.

      If no wireless network is added, no wireless network is configured.

    6. Click Deliver Configuration.
  • Modifying a service network
    1. Choose Entire-Network > Network. The Service Network page is displayed.
    2. Click next to the service network to be modified. The page for modifying a service network is displayed.
    3. Modify parameters as required. The VLAN ID and gateway cannot be modified.
    4. Click Next. The Wired Configuration page is displayed.

      Select the device and its interfaces to join the wired network. If no device or interface is selected, the wired network is not configured.

    5. Click Next. The Wireless Configuration page is displayed.

      Modify parameters as required. Table 2 lists the parameters.

      You can set parameters on the Wireless Configuration page only when a WAC running V600 is deployed on the network.

      You can also choose Wireless > Wi-Fi Settings on the home page to configure a wireless network. For details, see Wi-Fi Settings.

    6. Click Deliver Configuration.
  • Deleting a service network
    1. Choose Entire-Network > Network. The Service Network page is displayed.
    2. Click next to the service network to be deleted. The system asks you whether to delete it.
    3. Click Delete.
  • Checking device details
    1. Choose Entire-Network > Network. The Service Network page is displayed.
    2. Click a device in the topology. The device information is displayed on the right of the page, as shown in Figure 4.

      Figure 4 Device details

      To go to the web system of a device, click Jump to Single Device Web. If this button is unavailable, the selected device does not support redirection to its web system through the master device.

      To change the device name, click next to the device name. The new device name is used only for display on WebMaster and does not affect that set on the device.

      The interface status of switches and WACs running V200 and AR routers running V300 cannot be obtained. Therefore, -- is displayed in the interface list.
