Configuring TCP FPM

Context

After TCP FPM is enabled, you can view the delay and packet loss rate of application programs, and then optimize the network accordingly.

Procedure

  1. Enter the system view.

    system-view

  2. Create a tunnel interface and enter the tunnel interface view.

    interface tunnel interface-number

  3. Enable the TCP FPM function.

    tcpfpm enable

Verifying the Configuration

Run the display tcpfpm session { all | number } command to check TCP FPM statistics.
