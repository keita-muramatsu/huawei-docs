Configuring the Scrambling Function

Context

To prevent excessive consecutive 1s or 0s and allow the receive end to extract line clock signals, POS interfaces support payload scrambling.

When configuring POS interfaces, you must ensure that the same scrambling function is configured on both ends. Otherwise, interconnection fails.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the POS interface view.

    interface pos interface-number

  3. Configure payload scrambling on the POS interface.

    scramble

    By default, payload scrambling is enabled on a POS interface.
