Change Virtual IP Address

Context

The virtual IP address can be used to log in to WebMaster and manage devices on the network. You can change the virtual IP address on this page. After changing the virtual IP address, use the new IP address for login.

Procedure

  1. Choose Entire-Network > System Settings. The System Settings page is displayed, as shown in Figure 1.

    Figure 1 System Settings page

  2. Click Change next to Change Virtual IP Address. The Change Virtual IP Address dialog box is displayed, as shown in Figure 2.

    Figure 2 Change Virtual IP Address dialog box

  3. Set the parameters.

    Table 1 lists the parameters.

    Table 1 Parameters for changing the virtual IP address

    Parameter

    Description

    New virtual IP address/mask

    New virtual IP address and mask.

    IP address conflict detection

    Whether to enable IP address conflict detection.

    Diagnosis Result

    Result of IP address conflict detection.

    If the IP address conflict detection function is enabled, you can click Start to check whether virtual IP addresses conflict. The result is displayed in the Diagnosis Result area.

  4. Click OK.
