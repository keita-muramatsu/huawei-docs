Installing a Wi-Fi Antenna

Context

This section applies to AR routers that run V600R024C10 and later versions and contain W in the model name (for example, AR5710-S8T1XWE). Table 1 lists the routers on which Wi-Fi antennas can be installed.

Table 1 Routers on which Wi-Fi antennas can be installed

Device Model

Antenna Type

AR5710-S8T1XWE

AR5710-S8T1XWE-NRGL

AR5710-S8TWDSE-LTE4EA

Wi-Fi antenna

NOTE:

Wi-Fi whip antennas are included in the installation accessory package.

Tools and Accessories

  • Wi-Fi antennas

Procedure

  1. Install Wi-Fi antennas in antenna interfaces of the router.

  2. Make the Wi-Fi antennas vertical to the ground so that the router can better transmit and receive wireless signals.
