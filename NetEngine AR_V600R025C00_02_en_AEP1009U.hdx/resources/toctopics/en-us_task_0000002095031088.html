Network Tools

Context

The Network Tools page provides common network O&M functions. You can perform operations such as ping to implement network diagnosis on devices.

Procedure

  1. Choose Maintenance > Network Tools. The Network Diagnosis page is displayed, as shown in Figure 1.

    Figure 1 Network Diagnosis page

  2. Set network diagnosis parameters.

    Table 1 lists the parameters.

    Table 1 Network diagnosis parameters

    Parameter

    Description

    Diagnosis mode

    Network diagnosis mode. Currently, only ping operations are supported.

    IP address/Domain name

    IP address or domain name for network diagnosis.

    Number of pings

    Number of pings.

    Data packet size

    Data packet size.

  3. Click Start to start the diagnosis. After the diagnosis is complete, the diagnosis result is displayed in the Diagnosis Result area.
