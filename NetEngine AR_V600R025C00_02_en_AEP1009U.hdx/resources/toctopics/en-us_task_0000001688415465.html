Configuring ACL-based Packet Statistics Collection

Prerequisites

Before configuring ACL-based packet statistics collection, configure a basic ACL or an advanced ACL.

Context

When packet loss occurs on a network, you can configure ACL-based packet statistics collection to compare packet statistics on each NE and determine the link where packets are discarded.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the interface view.

    interface { interface-name | interface-type interface-number }

  3. Enable ACL-based packet statistics collection.

    • Enable statistics collection for incoming packets on the interface.
      traffic-statistics inbound [ ipv6 ] acl { acl-number | acl-name } [ decap-process ]
    • Enable statistics collection for outgoing packets on the interface.
      traffic-statistics outbound [ ipv6 ] acl { acl-number | acl-name }

    By default, ACL-based packet statistics collection is disabled on an interface.

  4. (Optional) Enable collection of decapsulated packet statistics on tunnel interfaces.

    traffic-statistics decap-process enable

    By default, collection of decapsulated packet statistics is disabled on a tunnel interface. This command is supported only in the tunnel interface view.

  5. Return to the system view.

    quit

  6. Check packet statistics on an interface.

    display traffic-statistics interface { interface-type interface-number | interface-name } { inbound | outbound } [ rule-base ]

  7. Return to the user view.

    quit

  8. (Optional) Clear packet statistics on an interface.

    reset traffic-statistics interface { interface-type interface-number | interface-name } { inbound | outbound }

    When you run the display traffic-statistics command to check traffic statistics on an interface, the statistics are accumulated. To collect new statistics, run the reset traffic-statistics command to clear the existing statistics.
