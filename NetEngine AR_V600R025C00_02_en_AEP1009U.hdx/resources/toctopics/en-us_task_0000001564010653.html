Configuring the DHCPv6 Client Function

Context

When the device functions as a DHCPv6 client, it can dynamically obtain IPv6 addresses and other configuration information through the DHCPv6 server. This facilitates user configuration and centralized management.

Procedure

  1. Enter the system view.

    system-view

  2. Configure the IPv6 function on an interface.

    1. Enter the interface view.
      interface interface-type interface-number
    2. Switch the interface working mode to Layer 3.
      undo portswitch

      Determine whether to perform this step based on the current interface working mode.

    3. Enable the IPv6 function on the interface.
      ipv6 enable

      By default, the IPv6 function is disabled on an interface.

    4. Configure a link-local address for the interface.
      • Manually configure a link-local address for the interface.
        ipv6 address ipv6-address link-local
      • Configure the interface to automatically generate a link-local address.
        ipv6 address auto link-local

      By default, no link-local address is configured for an interface.

  3. (Optional) Configure the DHCPv6 client to add Option 16 to request messages to be sent.

    dhcpv6 option16 insert { ascii ascii-string | hex hex-string }

  4. (Optional) Configure a list of additional request options (in addition to the default options) carried in the Option 6 field of a request message sent by the DHCPv6 client.

    dhcpv6 client request option-list option-code &<1-2>

  5. (Optional) Configure the DHCPv6 client to add Option 15 to request messages to be sent.

    dhcpv6 client user-class { ascii ascii-string | hex hex-string }

    By default, request messages sent by a DHCPv6 client do not carry Option15.

  6. Configure the DHCPv6 client function to obtain network configuration parameters.

    1. Enter the system view.
      system-view
    2. (Optional) Configure a DUID for the DHCPv6 device.
      dhcpv6 duid { ll | llt | duid }

      By default, a device generates a DUID based on a link-layer (LL) address.

    3. Enter the interface view.
      interface interface-type interface-number
    4. Configure the DHCPv6 client function. A DHCPv6 client can obtain an IPv6 address through DHCPv6 stateful or stateless autoconfiguration. For details, see IPv6 Address Allocation Methods.
      • Configure the DHCPv6 client to obtain an IPv6 address and other network configuration parameters (such as IPv6 addresses of DNS and SNTP servers) through DHCPv6 stateful autoconfiguration.
        ipv6 address auto dhcp [ hint ipv6-address ] [ rapid-commit ] [ unicast-option ]
      • Configure the DHCPv6 client to obtain network configuration parameters (excluding its IPv6 address) through DHCPv6 stateless autoconfiguration.
        dhcpv6 client information-request

      By default, a DHCPv6 client is not configured to obtain an IPv6 address and other network configuration parameters through DHCPv6 stateful or stateless autoconfiguration.

      • The DHCPv6 server assigns an IPv6 address and other network configuration parameters to a DHCPv6 client using two-message exchange only when two-message exchange is enabled on both them. Otherwise, the server assigns an IPv6 address and other network configuration parameters to the client using four-message exchange.
      • Before modifying the address autoconfiguration mode of a DHCPv6 client, you must disable the configured mode. For example, the DHCPv6 client function has been enabled on a device so that the DHCPv6 client uses DHCPv6 stateful autoconfiguration to obtain an IPv6 address and other network configuration parameters (such as IPv6 addresses of DNS and SNTP servers). To enable the DHCPv6 client to use DHCPv6 stateless autoconfiguration to obtain network configuration parameters (excluding its IPv6 address), run the undo ipv6 address auto dhcp command to disable DHCPv6 stateful autoconfiguration and then run the dhcpv6 client information-request command to enable DHCPv6 stateless autoconfiguration.
    5. (Optional) Manually update the IPv6 addresses/prefixes obtained by the DHCPv6 client.
      dhcpv6 client renew
