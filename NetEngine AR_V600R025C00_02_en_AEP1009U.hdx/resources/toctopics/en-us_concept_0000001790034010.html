Introduction to Data Compression

Definition

Data compression is a technology that compresses to-be-sent packets to reduce the size of data transmitted on wide area networks (WANs).

Purpose

As distributed networks become more common and services more diverse, network traffic surges. This makes network congestion more severe, which in turn deteriorates service quality. Increasing the network bandwidth can mitigate network congestion, but this also increases O&M costs. As such, the data compression feature is introduced to compress packets transmitted on the network. It allows a larger volume of data to be transmitted without requiring additional bandwidth, giving customers a better return on investment (ROI) from their network construction.
