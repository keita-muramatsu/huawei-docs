Internet Access Through Automatic LTE/5G Dialup

Context

If the device supports LTE/5G functions, you can configure automatic LTE/5G dialup for Internet access.

Procedure

  1. Choose Config > Config Wizard > Online Config Wizard and set Internet access mode to LTE/5G Dial-up, as shown in Figure 1.

    Figure 1 LTE/5G dialup
    1. Set the interface to be used for Internet access. For details about the parameter, see Table 1.
      Table 1 Parameter for configuring the interface to be used for Internet access through automatic dialup (mandatory)

      Parameter

      Description

      Internet interface

      Cellular interface for Internet access.

      Channel

      Cellular channel interface for Internet access.

      APN

      APN.

      NOTE:

      To obtain an APN, contact the local ISP.

      UserName

      User name for accessing an external PDN, which is provided by the ISP.

      Password

      Password for accessing an external PDN network, which is provided by the ISP.
    2. Set DNS server parameters. For details about the parameters, see Table 2.
      Table 2 Parameters for configuring DNS servers for Internet access through automatic dialup (optional)

      Parameter

      Description

      DNS server 1

      Preferred DNS server address assigned to DHCP clients. To add a DNS server address, click on the right.
    3. Set advanced parameters. For details about the parameters, see Table 3.
      Table 3 Advanced parameters for configuring Internet access through automatic dialup (optional)

      Parameter

      Description

      MTU

      MTU of the interface. The value is an integer from 46 to 9216, in bytes. By default, the MTU of an interface is 1500 bytes.

      NOTE:

      The value ranges and default values vary according to hardware and interfaces. The supported interface types, value ranges, and default values depend on the device model.

      TCP-MSS (bytes)

      MSS of TCP packets on an interface. The value ranges from 128 to 9500. The default value is 1200.

      Default route priority

      Route preference. The value ranges from 1 to 255. The default value is 60.

      Enable NAT

      Whether to enable NAT. By default, this function is enabled. After NAT is enabled, the IP address of an interface is used as the post-NAT address.

  2. Click Confirm. If you need to reset all parameters, click Clear and set the parameters again.
