Overview of the System-level Forwarding Mode

Definition

The device uses the multi-core CPU forwarding architecture. The system-level forwarding mode can adjust the CPU core resource allocation for security service processing and data forwarding services.

Purpose

When receiving packets, the device distributes these packets to different CPU cores for processing based on the service type of the packets. However, the CPU core allocated to the service may not be able to process masses of packets in a timely manner, thereby reducing the processing efficiency of the service.

To resolve this problem, the system-level forwarding mode can be used to adjust CPU core resource allocation for security service processing and data forwarding services, meeting performance requirements in different service scenarios. In this case, the system-level forwarding mode can optimize service processing efficiency and process services in a timely manner, improving overall system performance.
