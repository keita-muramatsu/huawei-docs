Configuring Alarm Thresholds

Context

Different services have different requirements for bit error rates (BERs) on a link. You can configure alarm thresholds for BERs on a POS interface so that alarms are generated when the performance of the corresponding link deteriorates. The alarms help you locate and handle link faults to prevent services from being affected.

Both SD and SF alarms indicate the performance of a link. They are both generated when the receive end detects bit errors on the link. The difference is that their alarm thresholds for BERs are different. If a small number of bit errors occur, an SD alarm is generated. If the BER increases to a certain value, the quality of the link deteriorates severely. In this case, an SF alarm is generated.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the POS interface view.

    interface pos interface-number

  3. Configure SD and SF alarm thresholds.

    threshold { sd sd_value | sf sf_value }

    By default, the SD and SF alarm thresholds are 6 and 3, respectively.
