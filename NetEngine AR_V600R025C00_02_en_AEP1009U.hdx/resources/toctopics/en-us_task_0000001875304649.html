(Optional) Configuring Synchronization of Portal Authentication User Information

Context

In Portal authentication, if communication between the device and Portal server is interrupted due to a network failure or Portal server failure, online Portal authentication users cannot go offline as expected. As a result, user information on the device may be different from that on the Portal server, causing inaccurate accounting.

The user information synchronization function ensures user information consistency between the Portal server and the device, so that accounting can be performed accurately.

Only the Portal server running the Portal protocol supports this function.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the Portal server template view.

    web-auth-server server-name

  3. Enable user information synchronization.

    user-sync [ interval interval-period | max-times times ] *

    By default, user information synchronization is disabled.
