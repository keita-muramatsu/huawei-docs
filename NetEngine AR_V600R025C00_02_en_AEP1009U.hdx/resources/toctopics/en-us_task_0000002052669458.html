One-click Information Collection

Context

You can use the one-click information collection function to collect system logs, diagnostic information, diagnostic files, and log files from the selected device (AR or AP) within a specified time range. Collecting the information may take some time.

Procedure

  1. Choose Diagnosis > One-click Information Collection. The one-click information collection page is displayed, as shown in Figure 1.

    Figure 1 One-click information collection page

    Before collecting AP information, you need to configure an AP account and password. For details, see WLAN Configuration Wizard.

    Before collecting AP information for the first time, run the ssh client first-time enable command in the system view to enable first login for the SSH client.

  2. Select the items to be collected.

    Table 1 describes the parameters.

    Table 1 One-Click Information Collection page

    Parameter

    Description

    Collection Content

    Content to be collected.

    Log File Range

    Range of logs to be collected.

    Start Time

    Start time for collecting log files.

    This parameter is available when Log File Range is set to Time Range Logs.

    End Time

    End time for collecting log files.

    This parameter is available when Log File Range is set to Time Range Logs.

    Forcible Collection

    Whether to enable the forcible collection function. When this function is enabled, the CPU and memory usage restrictions of the device are ignored.

    AP

    APs whose information needs to be collected.

  3. Click Start Collect and wait until the collection is complete.
