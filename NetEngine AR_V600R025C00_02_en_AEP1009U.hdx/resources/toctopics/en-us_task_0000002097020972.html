Configuring the System-level Forwarding Mode

Procedure

  1. Enter the system view.

    system-view

  2. Configure the service performance mode.

    • For the AR8100 and AR8700 series:
      forward performance mode { routing | security }

      The default service performance mode is routing mode.

    • For the AR5700-H series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4-T, AR6710-L8T3TS1X2-T, AR6710-L50T2X4, and AR6710-L8T3TS1X2:
      forward performance mode { routing | security | security-enhance }

      The default service performance mode is security mode.

    • For AR6710-L14T2X4:
      forward performance mode { security | security-enhance }

      The default service performance mode is security mode. When the security mode or enhanced security mode is configured, the device supports dynamic core adjustment.

    • For the AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8T1XWE, AR5710-S8T2XE-NRGL, AR5710-S8P2XE-NRGL, AR5710-S8T1XWE-NRGL, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8TWDSE-LTE4EA:
      forward performance mode { routing | security }

      The default service performance mode is security mode.

  3. (Optional) Configure the traffic distribution mode

    • For the AR8100 and AR8700 series:
      forward deliver mode { flow | packet }

      By default, the traffic distribution mode is per-packet forwarding.

    • For the AR5700-H series, AR5710-S10T1X2, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8T1XWE, AR5710-S8T2XE-NRGL, AR5710-S8P2XE-NRGL, AR5710-S8T1XWE-NRGL, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8TWDSE-LTE4EA, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T:
      forward deliver mode { flow | port | auto }

      By default, the traffic distribution mode is the port core binding mode. In the factory configuration file, the traffic distribution mode is automatic.

      When the traffic distribution mode is auto, you can run the forward deliver auto-switch suppression-time time command to set the suppression time for automatic switchover. After the configured suppression time expires, the device automatically adjusts the mode.

  4. (Optional) Enable the hardware-based routing and forwarding function.

    hardware route-forwarding [ qos ] enable

    By default, the hardware-based routing and forwarding function is disabled. This function is supported only on the following models: AR8700 series, AR6710-L26T2X4, AR6710-L26T2X4-T, AR6710-L50T2X4, AR6710-L50T2X4-T, AR6710-L14T2X4, AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T, AR6700-H series, AR5700-H series, AR5710-S8P2X, AR5710-S8T2X, AR5710-S8T2X-LTE4EA, AR5710-S8T2S, AR5710-S10T1X2, AR5710-S28T2S2XE4, AR5710-S52T2XE4, AR5710-S8T2XE-NRGL, AR5710-S8P2XE-NRGL, AR5710-S8T1XWE-NRGL, AR5710-S8P1XDSE-2LTE4EA, AR5710-S8TWDSE-LTE4EA, AR5710-S8T1XWE, AR5710-S8T2XE, AR5710-S8T2XE-LTE4EA-T

    The qos parameter is supported only on the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T and AR5700-H series.

  5. (Optional) Configure hardware session filtering conditions. When the corresponding service is executed, no hardware session table is created for the traffic that matches the filtering conditions.

    hardware session filter acl { acl-number | acl-name }

    By default, no hardware session filtering condition is configured. Only the AR6710-L8T3TS1X2, AR6710-L8T3TS1X2-T and AR5700-H series support this command.

Verifying the Configuration

  • Run the display forward performance mode command to query the service performance mode.
  • Run the display forward deliver mode command to query the traffic distribution mode.
  • Run the display hardware route-forwarding status command to check the hardware-based routing and forwarding status.
