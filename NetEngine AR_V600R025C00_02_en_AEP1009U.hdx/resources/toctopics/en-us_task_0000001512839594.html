(Optional) Configuring Traffic Statistics Collection

Context

When you need to check the network status or troubleshoot network faults, you can enable traffic statistics collection on an MP-Group interface so that the device collects traffic statistics on the MP-Group interface.

Procedure

  1. Enter the system view.

    system-view

  2. Create an MP-Group interface and enter the MP-Group interface view.

    interface mp-group number

  3. Enable the traffic statistics collection function.

    statistics enable

    By default, traffic statistics collection is disabled on an MP-Group interface.
