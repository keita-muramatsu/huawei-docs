Overview of TCP FPM

Definition

TCP Flow Performance Measurement (FPM) is a technology for implementing real-time network performance monitoring and measurement. TCP FPM defines a group of performance metrics and collects network performance statistics including the network delay of TCP applications and packet loss rate of TCP connections.

Purpose

As network applications grow in number and complexity, they become subject to increased delay, which affects user experience. TCP FPM can measure the network delay of TCP applications and the packet loss rate of TCP connections, providing insight into the network quality for use as a reference for network and server optimization.
