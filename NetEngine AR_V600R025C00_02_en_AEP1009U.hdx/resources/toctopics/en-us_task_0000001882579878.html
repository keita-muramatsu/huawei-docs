(Optional) Configuring a UCL Group

Context

A user control list (UCL) group is a collection of network members. Members in a UCL group can be network terminals such as PCs and mobile phones. Compared with the solution in which network access control policies are deployed for each user, the UCL group-based network access control solution greatly reduces the workload of administrators.

Procedure

  1. Enter the system view.

    system-view

  2. Create a UCL group.

    ucl-group name group-name [ index group-index ]

    By default, the system has a built-in UCL group with the name default and index 1.

Follow-up Procedure

  • A UCL group needs to be used together with a security policy. You can run the user command in the security policy rule view to bind a UCL group or local users who have been configured with a UCL group to the security policy rule. To configure a UCL group for local users, run the ucl-group name group-name command.
