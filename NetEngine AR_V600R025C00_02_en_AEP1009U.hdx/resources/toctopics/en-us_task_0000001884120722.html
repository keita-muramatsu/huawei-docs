Example for Configuring an L2TP Client to Initiate an L2TP Tunnel Connection Through Dial-up (Using an Ethernet Interface)

Network Requirements

In Figure 1, the HQ and branch of an enterprise are located in different cities, and the branch has an Ethernet network deployed.

The HQ provides L2TP access services for branch users and allows all branch users to access the network. The LNS only needs to authenticate the L2TP client. In this case, you can configure the L2TP client to establish an L2TP connection with the LNS through dial-up.

Figure 1 Network diagram for configuring an L2TP client to initiate an L2TP tunnel connection through dial-up

In this example, interface1 and interface2 represent 10GE0/0/1 and 10GE0/0/2, respectively.


Configuration Roadmap

The configuration roadmap is as follows:

  1. Configure L2TP on the L2TP client.

  2. Configure a static route destined for the LNS on the L2TP client and enable the dial-up function on the L2TP client.

Procedure

  1. Configure the L2TP client.

    # Configure a public IP address.

    <HUAWEI> system-view
[HUAWEI] sysname L2TP Client
[L2TP Client] interface 10GE 0/0/1
[L2TP Client-10GE0/0/1] ip address 1.1.2.1 255.255.255.0
[L2TP Client-10GE0/0/1] quit

    # Configure a user-side IP address.

    [L2TP Client] interface 10GE 0/0/2
[L2TP Client-10GE0/0/2] ip address 192.168.10.1 255.255.255.0
[L2TP Client-10GE0/0/2] quit

    # Enable L2TP globally, create an L2TP group, and establish an L2TP connection with the LNS.

    [L2TP Client] l2tp enable
[L2TP Client] l2tp-group 1
[L2TP Client-l2tp-group-1] tunnel name L2TP-Client
[L2TP Client-l2tp-group-1] start l2tp ip 1.1.1.1
Warning: This operation may cause traffic interruption, Continue? [Y/N]:y

    # Enable tunnel authentication and set a password for tunnel authentication.

    [L2TP Client-l2tp-group-1] tunnel authentication
Warning: This operation may cause traffic interruption, Continue? [Y/N]:y
[L2TP Client-l2tp-group-1] tunnel password cipher YsHsjx_123456
Warning: This operation may cause traffic interruption, Continue? [Y/N]:y
[L2TP Client-l2tp-group-1] quit

    # Configure a dialer interface and configure the user name, password, PPP authentication mode, and IP address of the PPP user.

    [L2TP Client] interface Dialer 1
[L2TP Client-Dialer1] link-protocol ppp
[L2TP Client-Dialer1] ppp chap user huawei
[L2TP Client-Dialer1] ppp chap password cipher YsHsjx_202206
[L2TP Client-Dialer1] ip address ppp-negotiate
[L2TP Client-Dialer1] quit

    # Configure a reachable public network route to the LNS. For example, configure a static route with the next-hop IP address being 1.1.2.2.

    [L2TP Client] ip route-static 1.1.1.1 255.255.255.255 1.1.2.2

    # Trigger dial-up to establish an L2TP tunnel.

    [L2TP Client] interface Dialer 1
[L2TP Client-Dialer1] l2tp-auto-client l2tp-group 1
[L2TP Client-Dialer1] quit
    # Configure a private network route so that enterprise branch users can access the HQ private network.
    [L2TP Client] ip route-static 192.168.2.0 255.255.255.0 Dialer1

  2. Configure the LNS.

    The device cannot function as an LNS. The configuration procedure varies according to the device type. For details, see the related documentation of the device.
