Developer Guide

With the increasing network scale, automatic service deployment and intelligent O&M become more and more important. However, network devices are from different vendors, and there is no unified standard for commands provided by each vendor, which brings challenges to automatic service deployment and intelligent O&M. The device supports standard northbound protocols and model files and provides APIs for users to develop a network management system (NMS) using unified rules, implementing automatic service deployment and intelligent O&M on the entire network.

To help developers and partners efficiently interact with, understand, and use Huawei network devices, Table 1 describes the documentation system required by developers, including technical documents and developer tools.
