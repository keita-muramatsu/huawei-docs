Understanding TCP FPM

Network Model

The TCP FPM network model includes the following roles, as shown in Figure 1:

Application client: a PC or another kind of terminal that provides applications to users

Application server: a server, such as a file server, that provides services to application clients

Device: a device that collects statistics on network performance such as network delay and packet loss rate

Figure 1 TCP FPM network model

Implementation

Figure 2 TCP FPM implementation
  1. When receiving an SYN request packet (first handshake) from the application client, the device obtains the source and destination IP addresses, creates a bidirectional flow table, and records the timestamp. After that, the device sends the request packet to the application server.
  2. When receiving the SYN-ACK response packet (second handshake) from the application server, the device searches the bidirectional flow table, records the timestamp, and calculates the server network delay TCP_SND. After that, the device sends the response packet to the application client.
  3. When receiving the ACK response packet (third handshake) from the application client, the device searches the bidirectional flow table, records the timestamp, and calculates the client network delay TCP_CND. After that, the device sends the response packet to the application server.
  4. The device collects network performance statistics such as network delay and packet loss rate, which give insights into the network quality.
    • TCP_SND: delay of the server network
    • TCP_CND: delay of the client network
    • Data Server Network Delay (DATA_SND): response delay, which is the difference between the time when the data request is sent by the client and the time when the first response packet is sent by the server
    • Application Delay (AD): delay caused by the application server (AD = DATA_SND – TCP_SND)
    • Packet loss rate: The packet loss rate of TCP applications is calculated based on TCP retransmission. For a TCP flow, the TCP sequence numbers of a retransmitted packet and a lost packet are the same, so the packet loss rate is calculated as follows: Packet loss rate = Number of retransmitted packets/Total number of sent packets
