Configuring PAP Authentication

Prerequisites

Before configuring PAP authentication on an interface, you have completed the following task:

  • Configure PPP as the link layer protocol of the interface.

Context

PPP supports PAP and CHAP authentication. PAP authentication is initiated by the peer. The authentication succeeds only when the PAP user name and password configured on the peer are the same as the local access user name and password configured on the authenticator.

The user name and password of the peer can be added to the local user list of the authenticator in Authentication, Authorization and Accounting (AAA), Remote Authentication Dial-In User Service (RADIUS) authentication, or Huawei Terminal Access Controller Access Control System (HWTACACS) authentication mode. This section describes how to add the user name and password of the peer in AAA mode. For details about the configuration of RADIUS authentication and HWTACACS authentication, see "AAA Configuration" in Configuration Guide > User Access and Authentication Configuration.

PAP supports unidirectional and bidirectional authentication.

  • In unidirectional authentication, the device on one end functions as the authenticator, and the device on the other end functions as the peer.
  • In bidirectional authentication, each device functions as both the authenticator and peer.

The device supports unidirectional PAP authentication and can function as either the authenticator or peer.

In PAP authentication, passwords are transmitted in plain text on the network, presenting potential security risks. Therefore, CHAP authentication is recommended. For details about how to configure CHAP authentication, see Configuring CHAP Authentication.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the interface view.

    interface interface-type interface-number

  3. Set the PPP authentication mode to PAP.

    • Configure the device as the authenticator in PAP authentication.
      1. Set the authentication mode to PAP.
        ppp authentication-mode pap
      2. Return to the system view.
        quit
      3. Enter the AAA view.
        aaa
      4. Create a local access user.
        local-access-user user-name
      5. Configure the password for the local access user.
        password cipher password
      6. Configure PPP as the access type of the local access user.
        service-type ppp
    • Configure the device as the peer in PAP authentication.
      1. Configure the user name and password sent by the local device to the remote device during PAP authentication.
        ppp pap local-user user-name password { simple password | cipher { password1 | password2 } }

        The configured PAP user name and password must be the same as the local access user name and password configured on the authenticator.

    • If simple is specified, the password is saved in plain text in the configuration file. This presents potential security risks. You are advised to specify cipher so that the password is saved in cipher text in the configuration file.
    • After the configuration, run the shutdown command followed by the undo shutdown command in the interface view for the configuration to take effect.
