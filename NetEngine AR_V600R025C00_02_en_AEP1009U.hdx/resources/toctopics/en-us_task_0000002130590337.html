Configuration Result

Context

On the Configuration Result page, you can check the configuration delivery result of devices on the entire network.

Procedure

  1. Choose Entire-Network > Configuration Result. The Configuration Result page is displayed, as shown in Figure 1.

    Figure 1 Configuration Result page

  2. Click next to a device name to view details about the configuration delivered to devices.
