Creating a Portal Access Profile

Context

The device uses Portal access profiles to uniformly manage all access configurations of Portal authentication users. Before configuring Portal authentication, you need to create a Portal access profile.

Procedure

  1. Enter the system view.

    system-view

  2. Create a Portal access profile and enter the Portal access profile view.

    portal-access-profile name access-profile-name

    By default, the device has a built-in Portal access profile named portal_access_profile.

    • The built-in Portal access profile portal_access_profile can be modified and applied, but cannot be deleted.
    • Before deleting a Portal access profile, ensure that this profile is not bound to any authentication profile.
