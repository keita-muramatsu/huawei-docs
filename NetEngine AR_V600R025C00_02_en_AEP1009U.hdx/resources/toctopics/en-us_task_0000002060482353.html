(Optional) Enabling the Function of Adding a UDP Header to Packets in an SD-WAN Tunnel

Context

In SD-WAN scenarios, the use of EVPN GRE extension headers does not comply with common network standards. As a result, packets cannot be identified and may be out of order in some network environments. To solve this problem, configure the device to add a UDP header to packets in an SD-WAN tunnel. In this way, the device generates standard UDP packets, ensuring that other network devices can correctly identify the packets.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the site view.

    evpn site site-id

  3. Enable the function of adding a UDP header to packets in an SD-WAN tunnel.

    evpn ext-udp enable

    By default, the function of adding a UDP header to packets in an SD-WAN tunnel is disabled.

  4. Specify the port numbers in the UDP header to be added.

    evpn ext-udp { destination-port dest-port-number | source-port src-port-number } *

    By default, destination-port and source-port are both 4755.

    When modifying this configuration, ensure that the port numbers are the same on both ends of an SD-WAN tunnel. Otherwise, packets cannot be identified.
