LAN Configuration Wizard

Context

If a device needs to provide wired access and be added to VLANs, use the LAN configuration wizard to complete the corresponding configuration.

Procedure

  1. Choose Config > Config Wizard > LAN Config Wizard. The LAN configuration wizard page is displayed, as shown in Figure 1.

    Figure 1 LAN configuration wizard
    1. In the Select Interface area, select a Layer 2 interface, configure VLAN information for the interface, and click Apply, as shown in Figure 2. For details about the parameters, see Table 1.
      1. If the interface you want to select is working in Layer 3 mode, click on the interface icon to switch the interface to a Layer 2 interface and then select this interface.
      2. If the interface you want to select has been added to an Eth-Trunk, click on the interface icon and configure VLAN information for this interface.
      3. If you have selected multiple interfaces, you can click Batch Modify to configure them in batches.
      Figure 2 Selecting an interface
      Table 1 Parameters for configuring VLAN information for an interface

      Parameter

      Description

      Interface Name

      Name of the selected Layer 2 interface.

      Eth-Trunk

      ID of the Eth-Trunk to which the interface has been added. The value is an integer from 0 to 63.

      Interface Type

      Link type of the interface:

      • Access (recommended when the interface connects to a PC)
      • Trunk (recommended when the interface connects to an AP or switch)
      • Hybrid

      Default VLAN

      Default VLAN of a trunk interface. The value is an integer from 1 to 4094.

      VLAN (Tagged)

      VLAN to which a hybrid or trunk interface is added in tagged mode.

      VLAN (Untagged)

      VLAN to which a hybrid interface is added in untagged mode.

      Description

      Description of the interface. The value is a string of 0 to 242 case-sensitive characters and can contain spaces.
    2. In the VLAN List area, click Create. In the Create VLAN window that is displayed (as shown in Figure 3), set VLAN and interface parameters. For details about the parameters, see Table 2.
      Figure 3 Creating a VLAN
      Table 2 Parameters for configuring a VLAN and the corresponding VLANIF interface

      Parameter

      Description

      VLAN ID

      The value is an integer from 2 to 4094.

      Description

      Description of the interface. The value is a string of 0 to 242 case-sensitive characters and can contain spaces.

      Interface status

      Whether the interface is up or down.

      IPv4 MTU(bytes)

      MTU of the interface. The value is an integer from 46 to 9216. By default, the MTU of an interface is 1500 bytes.

      TCP-MSS(bytes)

      MSS of TCP packets on the interface. The value ranges from 128 to 9500. The default value is 1200.

      IP obtaining mode

      Mode in which the interface obtains an IP address:

      • Static IP: A static IP address is configured for this interface.
      • DHCP: An IP address is assigned to the interface through DHCP.

      IPv4 Address/Mask

      IPv4 address and mask of the interface, in dotted decimal notation.

      Secondary IPv4 address/mask

      Secondary IPv4 address and mask of the interface, in dotted decimal notation. Multiple secondary addresses can be configured.

      DHCP Enable

      Whether to enable the DHCP server function. After this function is enabled, the interface functions as a DHCP server to dynamically allocate IP addresses to peer devices.

  2. Click OK. If you need to modify or delete VLAN information, click the Edit button in the Operation column in the VLAN List area.
