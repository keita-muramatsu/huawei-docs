How Can Low Latency Queuing (LLQ) Be Implemented?

Run the queue command to set the queue scheduling mode to PQ scheduling and set the queue length to the minimum value. If the delay is still long after the queue length is set to the minimum value on some models, you can use this command together with WRED to change the queue buffer length to the minimum value.

For example, on the AR8140-12G10XG, you can run the queue command to set the queue scheduling mode to PQ scheduling and set the queue length (packets-value) to the minimum value 1, indicating that 512 packets can be buffered. Then, you can configure a WRED drop profile (dscp 0 to 63 low-limit 0 high-limit 12 discard-percentage 100) to implement LLQ.
