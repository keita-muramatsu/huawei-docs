Configuring a Dialer Interface

Context

Before configuring the device as an L2TP client, configure a dialer interface and configure an IPv4 or IPv6 address for the interface.

You can configure an IPv4 address for a dialer interface using either of the following methods:

  • Configure an IP address on the interface.
  • Enable the interface to obtain an IP address through address negotiation using PPP.

You can configure an IPv6 address for a dialer interface using any of the following methods:

  • Configure an IPv6 address on the interface.
  • Configure stateless address autoconfiguration for the interface to automatically generate a global IPv6 address.
  • Configure address allocation by DHCPv6.

Procedure

  1. Enter the system view.

    system-view

  2. Create a dialer interface and enter the dialer interface view.

    interface Dialer number

  3. Configure PPP as the link layer protocol of the interface.

    link-protocol ppp

  4. Configure an IP address for the dialer interface. Perform either of the following operations as required:

    • Configure an IPv4 address for the dialer interface.
      ip address ip-address { mask | mask-length } [ tag tag-value ]
    • Configure the interface to obtain an IPv4 address from the remote device.
      ip address ppp-negotiate

      By default, IP address negotiation is disabled on an interface.

    • Configure a global unicast IPv6 address for the interface.
      ipv6 enable
ipv6 address { ipv6-address prefix-length | ipv6-address/prefix-length } [ tag tag-value ]
    • Configure stateless address autoconfiguration for the interface to automatically generate a global IPv6 address.
      ipv6 enable
ipv6 address auto link-local
ipv6 address auto global
    • Configure address allocation by DHCPv6.
      ipv6 enable
ipv6 address auto link-local 
ipv6 address auto global 
ipv6 address auto dhcp
