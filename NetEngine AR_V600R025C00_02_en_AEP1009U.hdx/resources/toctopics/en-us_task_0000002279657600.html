Advanced ACL Settings

Context

After an advanced ACL is configured on the device, the device can classify IP packets based on information such as the source and destination IP addresses, source and destination port numbers, protocol type, priority, and time range of packets.

Procedure

  • Configure an advanced ACL.
    1. Create an advanced ACL.

      1. Log in to the web system and choose Config > Security > ACL. The Advanced ACL Settings tab page is displayed, as shown in Figure 1.
        Figure 1 ACL page
      2. Click Create. The Create Advanced ACL page is displayed, as shown in Figure 2. Table 1 describes the parameters for creating an advanced ACL.
        Figure 2 Creating an advanced ACL
        Table 1 Parameters for creating an advanced ACL

        Parameter

        Description

        ACL distinguisher

        ACL ID.

        ACL description

        ACL description.
      3. Click OK.

    2. Add a rule.

      1. Log in to the web system and choose Config > Security > ACL. On the Advanced ACL Settings tab page, click on the right of the ACL list. The Add Rule page is then displayed, as shown in Figure 3. Table 2 describes the parameters for adding a rule.
        Figure 3 Adding a rule
        Table 2 Parameters for adding a rule

        Parameter

        Description

        Rule ID

        ID of an ACL rule.

        Action

        Action to be taken for packets. The options include Permit and Deny.

        Protocol type

        Protocol type. The protocol types of advanced ACL rules include:

        • GRE(47)
        • ICMP(1)
        • IGMP(2)
        • IP
        • IPINIP(4)
        • OSPF(89)
        • TCP(6)
        • UDP(17)
        • Customized type
        • (IPv4)0 protocol

        ICMP parameter

        If ICMP(1) is selected, you can set the type and code for this parameter, such as 0/8. The type and code values both range from 0 to 255.

        Matching priority

        Matching priority of the advanced ACL rule. The options are as follows:

        • DSCP priority

          Packets matching the ACL rule are filtered based on the DSCP priority. After DSCP priority is selected, enter the DSCP priority value in the text box on the right.

        Time range

        Time range during which the ACL rule takes effect. You can select a configured time range from the drop-down list. Alternatively, you can click Create on the Validity Time tab page and add a time range on the displayed Create Time Range page.

        Matching IP

        Source IP

        Source IP address of packets that match the ACL rule, which is in dotted decimal notation.

        Source IP wildcard

        Wildcard of the source IP address of packets the match the ACL rule, which is in dotted decimal notation.

        Dest IP

        Destination IP address of packets that match the ACL rule, which is in dotted decimal notation.

        Destination IP wildcard

        Wildcard of the destination IP address of packets the match the ACL rule, which is in dotted decimal notation.

        Matching Interface

        Source port number

        Source port number. Set this parameter if Protocol type is set to TCP(6). The value is an integer from 0 to 65535.

        Destination port number

        Destination port number. Set this parameter if Protocol type is set to UDP(17). The value is an integer from 0 to 65535.
      2. Click OK.

  • Modify an advanced ACL.

    1. Log in to the web system and choose Config > Security > ACL. On the Advanced ACL Settings tab page, click on the right of the ACL list. The Modify Advanced ACL page is then displayed, as shown in Figure 4. Table 1 describes the parameters for modifying an advanced ACL.
      Figure 4 Modifying an advanced ACL
    2. Modify the advanced ACL and click OK.

  • Delete an advanced ACL.

    1. Log in to the web system and choose Config > Security > ACL. On the Advanced ACL Settings tab page, click on the right of the ACL list. The page for deleting an advanced ACL is then displayed, as shown in Figure 5.
      Figure 5 Page for deleting an advanced ACL
    2. Click OK to delete the advanced ACL.
