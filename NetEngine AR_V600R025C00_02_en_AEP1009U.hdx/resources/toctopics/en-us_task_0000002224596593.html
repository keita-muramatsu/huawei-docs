Static Route

This section describes how to configure static routes on the web system.

Context

Static routes are easy to configure, and apply to small, simple, and stable networks. You can configure static routes to accurately manage route selection on the network.

Procedure

  1. Choose Config > IP Services > Routing Protocol > Static Route. The Static Route page is displayed, as shown in Figure 1.

    Figure 1 Static Route page

  2. On the Static Route page, create, modify, copy, or delete a static route.

    • On the Static Route page, click Create, set parameters, and click OK to create a static route, as shown in Figure 2. For details about the parameters, see Table 1.
      Figure 2 Creating a static route
      Table 1 Configuring a static route

      Parameter

      Description

      Destination IP

      Destination IP address of an IPv4 static route.

      Subnet mask

      Subnet mask of an IPv4 static route.

      Next-hop address

      Next-hop IP address of an IPv4 static route. Either the next-hop address or outbound interface must be specified.

      Outbound interface

      Outbound interface of an IPv4 static route.

      Priority

      Priority of an IPv4 static route. A smaller value indicates a higher priority. The default value is 60.

    • On the Static Route page, click in the Operation column, modify parameters, and click OK, as shown in Figure 3.
      Figure 3 Modifying a static route
    • On the Static Route page, click , modify parameters, and click OK to copy the static route, as shown in Figure 4.
      Figure 4 Copying a static route

      When copying a static route, modify at least one of the destination IP address, subnet mask, outbound interface, and next-hop address. Otherwise, the static route cannot be copied.

    • Delete a static route using either of the following methods:
      • On the Static Route page, click . In the Confirm dialog box that is displayed, click OK to delete the static route.
      • On the Static Route page, select one or more static routes and click Delete. In the Confirm dialog box that is displayed, click OK to delete the static routes.
