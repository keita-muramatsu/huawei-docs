Maintaining Packet Replication

Context

Statistics cannot be restored after being deleted. Exercise caution when deleting them.

Procedure

  • Run the display packet-replication instance { inbound | outbound } [ src-ip src-ip-address | dst-ip dst-ip-address | src-port src-port | dst-port dst-port | vpn-instance vpn-instance | protocol protocol-num ] * [ verbose ] command in any view to check the packet replication instance list.
  • Run the display packet-replication probe-table { all | connection connection-id } command in any view to check the probe table information of packet replication.
  • Run the display packet-replication statistics command in any view to check statistics about packet replication.
  • Run the reset packet-replication instance all command in the user view to reset the packet replication instance table.
  • Run the reset packet-replication probe-table all command in the user view to reset the packet replication probe table.
  • Run the reset packet-replication statistics command in the user view to clear packet replication statistics.
