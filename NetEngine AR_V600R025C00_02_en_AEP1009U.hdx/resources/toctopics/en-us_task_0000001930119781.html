Collecting L2TP Packet Statistics

Context

When L2TP users go online, multiple types of protocol packets are exchanged. You can run the following commands to check or reset L2TP packet statistics.

Procedure

  • Run the display l2tp statistics tunnel { all | tunnel-id tunnel-id } command to check L2TP packet statistics.
  • Run the reset l2tp statistics tunnel { all | tunnel-id tunnel-id } command to reset L2TP packet statistics.
