Verifying the Configuration

Context

After PPP is configured, view PPP link information and information about received error protocol packets on an interface.

Procedure

  • Run the display ppp information interface { interface-type interface-number | interface-name } command to check detailed information about a PPP link.
  • Run the display ppp error-packet { interface-name | interface-type interface-number } [ verbose ] command to check information about error protocol packets received on an interface.
