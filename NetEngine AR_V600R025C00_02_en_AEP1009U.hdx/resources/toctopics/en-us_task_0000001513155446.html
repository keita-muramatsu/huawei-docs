(Optional) Configuring the Function of Preferentially Selecting the Same Link

Context

When the function of preferentially selecting the same link is enabled on the device, the device preferentially selects connections on the same TN. If connections on the same TN do not meet the requirements, the device selects connections on a different TN.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the SPR configuration view.

    smart-policy-route

  3. Enable the function of preferentially selecting the same link.

    same-network-prefer enable

  4. Return to the system view.

    quit
