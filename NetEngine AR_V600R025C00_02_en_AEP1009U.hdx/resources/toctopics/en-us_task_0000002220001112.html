Device Replacement

Context

Devices on the Network Device Replacement page are devices to be approved. If a device on the network needs to be replaced, you can select a device to be approved to replace the device.

A device can only be replaced by one of the same model. The software version of the new device must be later than or the same that of the device to be replaced.

Procedure

  1. Choose Maintenance > Device Replacement. The Network Device Replacement page is displayed, as shown in Figure 1.

    Figure 1 Network Device Replacement page

  2. Click Device Replacement in the Operation column of the device to be used for replacement. On the Device Replacement page, select the device to be replaced and click OK.
