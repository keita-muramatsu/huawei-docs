(Optional) Configuring the Minimum Number of Bundled Links for an MP Link

Context

The minimum number of bundled links configured for an MP link determines the minimum bandwidth of the MP link. You can configure a proper minimum number of bundled links to meet bandwidth requirements.

This configuration guarantees data transmission over the MP link and improves the link reliability.

Procedure

  1. Enter the system view.

    system-view

  2. Create an MP-Group interface and enter the MP-Group interface view.

    interface mp-group number

  3. Configure the minimum number of bundled links for the MP link.

    ppp mp threshold-least number

    By default, the minimum number of bundled links in up state in an MP group is 1.

    After the configuration, run the shutdown command followed by the undo shutdown command in the MP-Group interface view to restart the interface for the configuration to take effect.
