Certificate Management

Context

A digital certificate is a digitally signed file issued by the PKI certificate authority (CA) and contains the owner's public key and identity information.

A digital certificate, which is similar to an electronic copy of a passport or an ID card, is typically used for identity authentication on the network.

Procedure

  • Creating a certificate application
    1. Log in to the web system and choose Config > Security > Certificate Management. The Certificate Management page is displayed, as shown in Figure 1.

      Figure 1 Certificate Management page

    2. Click Apply for Certificate. The Certificate Management page is displayed, as shown in Figure 2.

      Figure 2 Create Certificate Application page

    3. Set parameters as needed. Table 1 describes the parameters.

      Table 1 Parameters for creating a certificate application

      Parameter

      Setting

      Identification Information

      Certificate Name

      Enter a certificate name.

      Common Name

      Enter the common name of the certificate.

      IP Address

      Configure an IP address.

      Domain Name

      Configure a domain name.

      Email

      Enter an email address.

      Country Code

      Enter a country code.

      State/Province

      Enter a state or province name.

      Locality

      Enter a geographical area name.

      Organization

      Enter an organization name.

      Department

      Enter a department.

      Key Options

      Key Type

      Enter a key type. The default value is rsa.

      Key Length

      Set the key length to 2048, 3072, or 4096. The default value is 3072.

      Certificate Server Configuration

      Regenerate Key Pair

      Whether to enable simultaneous key pair updates. Enabling this function can improve security.

      CA Server URL

      Enter the URL of the CA server.

      CA Identifier

      Enter a CA identifier.

      Reference Code

      Enter an authentication code (reference value).

      Secret Code

      Enter an authentication code (secret value).

      Cert Check

      Certificate Check Method

      Set the certificate check method to CRL, None, or CRL-None.

    4. Click OK.
  • Uploading a certificate
    1. Log in to the web system and choose Config > Security > Certificate Management. On the Certificate Management page that is displayed, click Upload Certificate. The Upload Certificate page is displayed, as shown in Figure 3.

      Figure 3 Upload Certificate page

    2. Set parameters as needed. Table 2 describes the parameters.

      Table 2 Parameters for uploading a certificate

      Parameter

      Setting

      Certificate Name

      Enter a certificate name.

      Certificate Type

      Select LOCAL or CA.

      Certificate Format

      Select pem, der, or pkcs12.

      Certificate File

      Select a certificate file to be uploaded.

      Private Key File Format

      Select pem, der, or pkcs12.

      Private Key File

      Select a private key file.

      Private Key Password

      Set a private key encryption password.

    3. Click OK.
  • Uploading a CRL
    1. Log in to the web system and choose Config > Security > Certificate Management. On the Certificate Management page that is displayed, click Upload CRL. The Upload CRL page is displayed, as shown in Figure 4.

      Figure 4 Upload CRL page

    2. Set Certificate File and Certificate Domain as required.
    3. Click OK.
  • Exporting a certificate
    1. Log in to the web system and choose Config > Security > Certificate Management. The Certificate Management page is displayed.
    2. Select next to the certificate to be exported and click Export Certificate. The dialog box shown in Figure 5 is displayed.

      Figure 5 Exporting a certificate
      Table 3 Parameters for exporting a certificate

      Parameter

      Setting

      Certificate Name

      Select the name of the certificate to be exported.

      Certificate Type

      Select a certificate type.

      Certificate Format

      Select pem or pkcs12.

      Certificate File

      Select the certificate file to be exported.

      Private Key Password

      Enter the private key encryption password.

      NOTE:

      The password must contain at least three types of the following characters: uppercase letters, lowercase letters, digits, and special characters (such as !, $, #, and %).

    3. Click OK.
  • Deleting a certificate
    1. Log in to the web system and choose Config > Security > Certificate Management. The Certificate Management page is displayed.
    2. Select next to the certificate to be deleted and click Delete Certificate. The dialog box shown in Figure 6 is displayed.

      Figure 6 Deleting a certificate

    3. Click OK.
