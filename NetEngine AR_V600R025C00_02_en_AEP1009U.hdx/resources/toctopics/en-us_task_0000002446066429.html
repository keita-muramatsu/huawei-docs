(Optional) Enabling Packet Replication Enhancement

Context

Packet replication probe instances are used to detect whether the peer end supports packet replication, helping prevent packet replication failures caused by mismatched capabilities between both ends. To enhance the performance of these probe instances, you can enable packet replication enhancement.

This function is supported only on AR8700 series, AR8100 series, and AR6700-H series devices.

Procedure

  1. Enter the system view.

    system-view

  2. Create and enter the packet replication configuration view.

    packet-replication

    By default, no packet replication configuration view is created.

  3. Enable packet replication enhancement.

    packet-replication enhance enable

    By default, packet replication enhancement is disabled.

Verifying the Configuration

Run the display packet-replication enhance status command to check whether packet replication enhancement is enabled.

Follow-up Procedure

After packet replication enhancement is configured, run the save command to save the configuration and restart the device for the configuration to take effect.
