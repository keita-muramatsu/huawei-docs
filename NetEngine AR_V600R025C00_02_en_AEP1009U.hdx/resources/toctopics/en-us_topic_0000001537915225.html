Example for Configuring Access Authentication in the Financial Scenario

Applicable Products and Versions

This example applies to AR5700 and AR6700 series routers running V600R022C00 and later versions.

Scenario

This document provides a typical configuration example for financial branch sites. It provides a detailed plan of access authentication, network deployment, traffic scheduling, and device management for terminals at branch sites, provides configuration examples based on the plan, and provides references for networking planning and device configuration.

Networking Requirements

On the enterprise network shown in Figure 1, two AR routers RouterA and RouterB are deployed. Users can access the Internet through RouterA or RouterB. The WAN links of the two devices back up each other. That is, if one WAN link fails, traffic is switched to the other WAN link. Load balancing can be implemented for LAN interface access. PCs on the same network segment can access the network through the interface of RouterA or RouterB. RouterA and RouterB are connected through an Eth-Trunk to ensure reliability. The bandwidth of high-priority services must be guaranteed. The implementation is as follows:

  • Deploy RouterA and RouterB as dual gateways and deploy Eth-Trunk between the gateways to ensure link reliability.
  • Deploy OSPF between the two gateways and between the gateways and the Internet to ensure route connectivity between the gateways and the Internet.
  • Deploy VRRP on the LAN-side gateways. Traffic of VRRP master devices on different network segments is evenly distributed on two routers to ensure that traffic is load balanced between WAN interfaces of the two routers.
  • Directly connect terminals to the routers, and enable NAC authentication on the router interfaces to ensure terminal access security.
  • Deploy HQoS to ensure that high-priority services (such as voice and video services) of different users are preferentially scheduled, highest-priority services enter the PQ queue and have bandwidth guaranteed, high-priority services enter the DRR queue and have a higher weight, and low-priority services enter the DRR queue and have a lower weight.
  • Deploy the NMS, log server, and clock server.
  • Apply user access restrictions, enable SSH, and restrict access IP addresses.

Configuration Roadmap

1. Configure LLDP globally on RouterA and RouterB.

2. Configure interfaces, VLANs, and IP addresses so that routers can communicate with each other.

3. Configure STP edge ports to ensure that terminal access interfaces on routers do not participate in STP calculation.

4. Configure OSPF neighbor relationships and advertise routes so that routers can communicate with each other and with the Internet.

5. Configure QoS to ensure that voice services enter the PQ queue and have bandwidth guaranteed, video and other services enter the DRR queue, and video services have a higher weight.

6. Configure NAC, configure 802.1X authentication on the interfaces connected to terminals, set the authentication mode to RADIUS, and enable MAC address bypass authentication upon an authentication failure.

7. Configure SNMP, including the SNMP version, community, and source interface for sending traps, and configure the device to be managed by the NMS only through SNMP.

8. Configure NTP synchronization to ensure that the device clock is synchronized with the NTP server clock.

9. Configure an SSH user, configure an AAA user, and set the user access mode to SSH.

10. Configure a VTY interface, set the authentication mode to AAA, and restrict the login IP address of the administrator so that users using other IP addresses are not allowed to log in.

11. Configure the information center, log server, and source interface for sending logs.

Procedure

  1. Configure LLDP globally.
    # Configure LLDP on RouterA.
    <HUAWEI> system-view
[HUAWEI] sysname RouterA
[RouterA] lldp enable
    # Configure LLDP on RouterB.
    <HUAWEI> system-view
[HUAWEI] sysname RouterB
[RouterB] lldp enable
  2. Create a loopback interface, assign an IP address to the loopback interface, and configure a VRRP group.

    Configure RouterA.

    [RouterA] vlan batch 21 30
[RouterA] interface LoopBack 0
[RouterA-LoopBack0] ip address 10.1.1.1 255.255.255.255
[RouterA-LoopBack0] quit
[RouterA] interface Vlanif 21
[RouterA-Vlanif21] ip address 21.1.1.1 255.255.255.0
[RouterA-Vlanif21] ip address 22.1.1.1 255.255.255.0 sub
[RouterA-Vlanif21] vrrp vrid 21 virtual-ip 21.1.1.254
[RouterA-Vlanif21] vrrp vrid 21 priority 120
[RouterA-Vlanif21] vrrp vrid 22 virtual-ip 22.1.1.254
[RouterA-Vlanif21] vrrp vrid 22 priority 90
[RouterA-Vlanif21] quit
[RouterA] interface Vlanif 30
[RouterA-Vlanif30] ip address 30.1.1.1 255.255.255.0
[RouterA-Vlanif30] vrrp vrid 30 virtual-ip 30.1.1.254
[RouterA-Vlanif30] vrrp vrid 30 priority 120
[RouterA-Vlanif30] quit

    Configure RouterB.

    [RouterB] vlan batch 21 30
[RouterB] interface LoopBack0
[RouterB-LoopBack0] ip address 10.1.1.2 255.255.255.255
[RouterB-LoopBack0] quit
[RouterB] interface Vlanif 21
[RouterB-Vlanif21] ip address 21.1.1.2 255.255.255.0
[RouterB-Vlanif21] ip address 22.1.1.2 255.255.255.0 sub
[RouterB-Vlanif21] vrrp vrid 21 virtual-ip 21.1.1.254
[RouterB-Vlanif21] vrrp vrid 21 priority 90
[RouterB-Vlanif21] vrrp vrid 22 virtual-ip 22.1.1.254
[RouterB-Vlanif21] vrrp vrid 22 priority 120
[RouterB-Vlanif21] quit
[RouterB] interface Vlanif 30
[RouterB-Vlanif30] ip address 30.1.1.2 255.255.255.0
[RouterB-Vlanif30] vrrp vrid 30 virtual-ip 30.1.1.254
[RouterB-Vlanif30] vrrp vrid 30 priority 90
[RouterB-Vlanif30] quit
  3. Add LAN ports to VLANs.

    Configure RouterA.

    [RouterA] interface GE 0/0/3
[RouterA-GE0/0/3] portswitch
[RouterA-GE0/0/3] port link-type access
[RouterA-GE0/0/3] port default vlan 21
[RouterA-GE0/0/3] quit
[RouterA] interface GE 0/0/4
[RouterA-GE0/0/4] portswitch
[RouterA-GE0/0/4] port link-type access
[RouterA-GE0/0/4] port default vlan 21
[RouterA-GE0/0/4] quit
[RouterA] interface GE 0/0/5
[RouterA-GE0/0/5] portswitch
[RouterA-GE0/0/5] port link-type access
[RouterA-GE0/0/5] port default vlan 30
[RouterA-GE0/0/5] quit

    Configure RouterB.

    [RouterB] interface GE 0/0/3
[RouterB-GE0/0/3] portswitch
[RouterB-GE0/0/3] port link-type access
[RouterB-GE0/0/3] port default vlan 21
[RouterB-GE0/0/3] quit
[RouterB] interface GE 0/0/4
[RouterB-GE0/0/4] portswitch
[RouterB-GE0/0/4] port link-type access
[RouterB-GE0/0/4] port default vlan 21
[RouterB-GE0/0/4] quit
[RouterB] interface GE 0/0/5
[RouterB-GE0/0/5] portswitch
[RouterB-GE0/0/5] port link-type access
[RouterB-GE0/0/5] port default vlan 30
[RouterB-GE0/0/5] quit
  4. Configure IP addresses for WAN ports.

    Configure RouterA.

    [RouterA] interface GE 0/0/0
[RouterA-GE0/0/0] ip address 20.1.1.2 255.255.255.0
[RouterA-GE0/0/0] quit

    Configure RouterB.

    [RouterB] interface GE 0/0/0
[RouterB-GE0/0/0] ip address 40.1.1.2 255.255.255.0
[RouterB-GE0/0/0] quit
  5. Configure an Eth-Trunk and its member interfaces.

    Configure RouterA.

    [RouterA] interface Eth-Trunk 1
[RouterA-Eth-Trunk1] portswitch
[RouterA-Eth-Trunk1] port link-type trunk
[RouterA-Eth-Trunk1] port trunk allow-pass vlan 2 to 4094
[RouterA-Eth-Trunk1] quit
[RouterA] interface GE0/0/1
[RouterA-GE0/0/1] eth-trunk 1
[RouterA-GE0/0/1] quit
[RouterA] interface GE0/0/2
[RouterA-GE0/0/2] eth-trunk 1
[RouterA-GE0/0/2] quit

    Configure RouterB.

    [RouterB] interface Eth-Trunk 1
[RouterB-Eth-Trunk1] portswitch
[RouterB-Eth-Trunk1] port link-type trunk
[RouterB-Eth-Trunk1] port trunk allow-pass vlan 2 to 4094
[RouterB-Eth-Trunk1] quit
[RouterB] interface GE0/0/1
[RouterB-GE0/0/1] eth-trunk 1
[RouterB-GE0/0/1] quit
[RouterB] interface GE0/0/2
[RouterB-GE0/0/2] eth-trunk 1
[RouterB-GE0/0/2] quit
  6. Configure LAN-side access ports as STP edge ports.

    Configure RouterA.

    [RouterA] interface GE 0/0/3
[RouterA-GE0/0/3] stp edged-port enable
[RouterA-GE0/0/3] quit
[RouterA] interface GE 0/0/4
[RouterA-GE0/0/4] stp edged-port enable
[RouterA-GE0/0/4] quit
[RouterA] interface GE 0/0/5
[RouterA-GE0/0/5] stp edged-port enable
[RouterA-GE0/0/5] quit

    Configure RouterB.

    [RouterB] interface GE 0/0/3
[RouterB-GE0/0/3] stp edged-port enable
[RouterB-GE0/0/3] quit
[RouterB] interface GE 0/0/4
[RouterB-GE0/0/4] stp edged-port enable
[RouterB-GE0/0/4] quit
[RouterB] interface GE 0/0/5
[RouterB-GE0/0/5] stp edged-port enable
[RouterB-GE0/0/5] quit
  7. Configure WAN ports to establish an OSPF neighbor relationship with the WAN network.

    Configure RouterA.

    [RouterA] interface GE 0/0/0
[RouterA-GE0/0/0] ospf network-type p2p
[RouterA-GE0/0/0] ospf cost 10
[RouterA-GE0/0/0] ospf authentication-mode hmac-sha256 1 cipher YsHsjx_202206
[RouterA-GE0/0/0] quit
[RouterA] ospf 1 router-id 10.1.1.1
[RouterA-ospf-1] area 3
[RouterA-ospf-1-area-0.0.0.3] nssa no-summary
[RouterA-ospf-1-area-0.0.0.3] network 21.1.1.0 0.0.0.255
[RouterA-ospf-1-area-0.0.0.3] network 22.1.1.0 0.0.0.255
[RouterA-ospf-1-area-0.0.0.3] network 20.1.1.0 0.0.0.255
[RouterA-ospf-1-area-0.0.0.3] network 30.1.1.0 0.0.0.255
[RouterA-ospf-1-area-0.0.0.3] network 10.1.1.1 0.0.0.0
[RouterA-ospf-1-area-0.0.0.3] quit
[RouterA-ospf-1] quit

    Configure RouterB.

    [RouterB] interface GE 0/0/0
[RouterB-GE0/0/0] ospf network-type p2p
[RouterB-GE0/0/0] ospf cost 10
[RouterB-GE0/0/0] ospf authentication-mode hmac-sha256 1 cipher YsHsjx_202206
[RouterB-GE0/0/0] quit
[RouterB] ospf 1 router-id 10.1.1.2
[RouterB-ospf-1] area 3
[RouterB-ospf-1-area-0.0.0.3] nssa no-summary
[RouterB-ospf-1-area-0.0.0.3] network 21.1.1.0 0.0.0.255
[RouterB-ospf-1-area-0.0.0.3] network 22.1.1.0 0.0.0.255
[RouterB-ospf-1-area-0.0.0.3] network 40.1.1.0 0.0.0.255
[RouterB-ospf-1-area-0.0.0.3] network 30.1.1.0 0.0.0.255
[RouterB-ospf-1-area-0.0.0.3] network 10.1.1.2 0.0.0.0
[RouterB-ospf-1-area-0.0.0.3] quit
[RouterB-ospf-1] quit
  8. Configure HQoS.
    # Configure a flow queue (FQ) profile.
    [RouterA] flow-queue fq1
[RouterA-flow-queue-fq1] queue voice pq shaping cir-shaping-percentage 15
[RouterA-flow-queue-fq1] queue video drr weight 30 shaping cir-shaping-percentage 30
[RouterA-flow-queue-fq1] queue data drr weight 10 shaping cir-shaping-percentage 45
[RouterA-flow-queue-fq1] quit
    # Configure an FQ traffic policy.
    [RouterA] traffic classifier voice
[RouterA-classifier-voice] if-match dscp 46
[RouterA-classifier-voice] quit
[RouterA] traffic classifier video
[RouterA-classifier-video] if-match dscp 40
[RouterA-classifier-video] quit
[RouterA] traffic classifier data
[RouterA-classifier-data] if-match dscp 15
[RouterA-classifier-data] quit
[RouterA] traffic behavior voice
[RouterA-behavior-voice] flow-queue fq1 queue voice
[RouterA-behavior-voice] quit
[RouterA] traffic behavior video
[RouterA-behavior-video] flow-queue fq1 queue video
[RouterA-behavior-video] quit
[RouterA] traffic behavior data
[RouterA-behavior-data] flow-queue fq1 queue data
[RouterA-behavior-data] quit
[RouterA] traffic policy sub-policy
[RouterA-trafficpolicy-sub-policy] classifier voice behavior voice
[RouterA-trafficpolicy-sub-policy] classifier video behavior video
[RouterA-trafficpolicy-sub-policy] classifier data behavior data
[RouterA-trafficpolicy-sub-policy] quit
    # Configure a subscriber queue (SQ) profile.
    [RouterA] qos-user-profile uq1
[RouterA-qos-user-profile-uq1] user-queue user1 drr weight 30 cir 50000 cbs 1000000
[RouterA-qos-user-profile-uq1] user-queue user2 drr weight 10 cir 30000 cbs 750000
[RouterA-qos-user-profile-uq1] user-queue user3 drr weight 10 cir 20000 cbs 500000
[RouterA-qos-user-profile-uq1] quit
    # Configure an SQ traffic policy.
    [RouterA] acl 2001
[RouterA-acl4-basic-2001] rule permit source 10.10.10.0 24
[RouterA-acl4-basic-2001] quit
[RouterA] acl 2002
[RouterA-acl4-basic-2002] rule permit source 10.10.20.0 24
[RouterA-acl4-basic-2002] quit
[RouterA] acl 2003
[RouterA-acl4-basic-2003] rule permit source 10.10.30.0 24
[RouterA-acl4-basic-2003] quit
[RouterA] traffic classifier user1
[RouterA-classifier-user1] if-match acl 2001
[RouterA-classifier-user1] quit
[RouterA] traffic classifier user2
[RouterA-classifier-user2] if-match acl 2002
[RouterA-classifier-user2] quit
[RouterA] traffic classifier user3
[RouterA-classifier-user3] if-match acl 2003
[RouterA-classifier-user3] quit
[RouterA] traffic behavior user1
[RouterA-behavior-user1] qos-user-profile uq1 user-queue user1
[RouterA-behavior-user1] traffic-policy sub-policy
[RouterA-behavior-user1] quit
[RouterA] traffic behavior user2
[RouterA-behavior-user2] qos-user-profile uq1 user-queue user2
[RouterA-behavior-user2] traffic-policy sub-policy
[RouterA-behavior-user2] quit
[RouterA] traffic behavior user3
[RouterA-behavior-user3] qos-user-profile uq1 user-queue user3
[RouterA-behavior-user3] traffic-policy sub-policy
[RouterA-behavior-user3] quit
[RouterA] traffic policy parent-policy
[RouterA-trafficpolicy-parent-policy] classifier user1 behavior user1
[RouterA-trafficpolicy-parent-policy] classifier user2 behavior user2
[RouterA-trafficpolicy-parent-policy] classifier user3 behavior user3
[RouterA-trafficpolicy-parent-policy] quit
    # Apply the HQoS parent policy to the outbound interface of RouterA.
    [RouterA] interface GE 0/0/0
[RouterA-GE0/0/0] traffic-policy parent-policy outbound
[RouterA-GE0/0/0] quit

    # The configuration of RouterB is the same as that of RouterA.

  9. Configure NAC.
    # Create and configure the RADIUS server template rd1.
    [RouterA] radius-server template rd1
[RouterA-radius-rd1] radius-server authentication 120.1.1.10 1812 weight 80
[RouterA-radius-rd1] radius-server authentication 120.1.1.11 1812 weight 70
[RouterA-radius-rd1] radius-server accounting 120.1.1.10 1813 weight 80
[RouterA-radius-rd1] radius-server accounting 120.1.1.11 1813 weight 70
[RouterA-radius-rd1] radius-server shared-key cipher YsHsjx_202206
[RouterA-radius-rd1] quit
    # Create the AAA authentication scheme abc and set the authentication mode to RADIUS.
    [RouterA] aaa
[RouterA-aaa] authentication-scheme abc
[RouterA-aaa-authen-abc] authentication-mode radius
[RouterA-aaa-authen-abc] quit
    # Configure the accounting scheme acco1.
    [RouterA-aaa] accounting-scheme acco1
[RouterA-aaa-accounting-acco1] accounting-mode radius
[RouterA-aaa-accounting-acco1] accounting realtime 12
[RouterA-aaa-accounting-acco1] quit
    # Create the authentication domain isp, and bind the AAA authentication scheme abc, accounting scheme acco1, and RADIUS server template rd1 to the domain.
    [RouterA-aaa] domain huawei.com
[RouterA-aaa-domain-huawei.com] authentication-scheme abc
[RouterA-aaa-domain-huawei.com] accounting-scheme acco1
[RouterA-aaa-domain-huawei.com] radius-server rd1
[RouterA-aaa-domain-huawei.com] quit
[RouterA-aaa] quit
    # Configure a MAC access profile.
    [RouterA] mac-access-profile name m1
[RouterA-mac-access-profile-m1] quit
    # Configure an 802.1X access profile, configure re-authentication for online 802.1X authentication users, set the re-authentication interval to 7200 seconds, and set the number of retransmissions of authentication request packets or handshake packets to 3.
    [RouterA] dot1x-access-profile name d1
[RouterA-dot1x-access-profile-d1] dot1x authentication-method eap
[RouterA-dot1x-access-profile-d1] dot1x reauthenticate
[RouterA-dot1x-access-profile-d1] dot1x timer reauthenticate-period 7200
[RouterA-dot1x-access-profile-d1] dot1x retry 3
[RouterA-dot1x-access-profile-d1] quit
    # Bind the MAC access profile and 802.1X access profile to the authentication profile p1.
    [RouterA] authentication-profile name p1
[RouterA-authen-profile-p1] mac-access-profile m1
[RouterA-authen-profile-p1] dot1x-access-profile d1
    # Enable MAC address bypass authentication and configure a forcible authentication domain.
    [RouterA-authen-profile-p1] authentication dot1x-mac-bypass
[RouterA-authen-profile-p1] access-domain huawei.com force
[RouterA-authen-profile-p1] quit
    # Bind the authentication profile p1 to interfaces.
    [RouterA] interface GE 0/0/3
[RouterA-GE0/0/3] authentication-profile p1
[RouterA] interface GE 0/0/4
[RouterA-GE0/0/4] authentication-profile p1
[RouterA] interface GE 0/0/5
[RouterA-GE0/0/5] authentication-profile p1

    # The configuration of RouterB is the same as that of RouterA.

  10. Configure SNMP.
    # Configure an ACL.
    [RouterA] acl 2001
[RouterA-acl4-basic-2001] rule 5 permit source 120.1.1.2 0.0.0.0
[RouterA-acl4-basic-2001] rule 6 deny source 120.1.1.1 0.0.0.0
[RouterA-acl4-basic-2001] quit
    # Configure SNMP.
    [RouterA] snmp-agent
[RouterA] snmp-agent sys-info version v2c v3
[RouterA] snmp-agent trap source LoopBack0
[RouterA] snmp-agent community read adminnms2 acl 2001
[RouterA] snmp-agent target-host inform address udp-domain 120.1.1.2 params securityname Huawei-1234 v3

    # The configuration of RouterB is the same as that of RouterA.

  11. Configure NTP synchronization.
    [RouterA] ntp source-interface LoopBack0
[RouterA] ntp authentication enable
[RouterA] ntp authentication-keyid 42 authentication-mode hmac-sha256 YsHsjx_202206
[RouterA] ntp trusted authentication-keyid 42
[RouterA] ntp unicast-server 120.1.1.5 authentication-keyid 42

    # The configuration of RouterB is the same as that of RouterA.

  12. Configure an SSH user.
    # Generate a local key pair on the SSH server.
    [RouterA] rsa local-key-pair create
The key name will be:Host     
The range of public key size is (2048, 4096). 
NOTE: Key pair generation will take a short while.
Please input the modulus [default = 3072]:3072
    # Create a local user on the server and configure the user service type.
    [RouterA] aaa
[RouterA-aaa] local-user admin123 password irreversible-cipher YsHsjx_202206
[RouterA-aaa] local-user admin123 service-type ssh
[RouterA-aaa] local-user admin123 privilege level 3
[RouterA-aaa] quit
    # Create an SSH user on the server and configure the authentication mode.
    [RouterA] ssh user admin123
[RouterA] ssh user admin123 authentication-type rsa
