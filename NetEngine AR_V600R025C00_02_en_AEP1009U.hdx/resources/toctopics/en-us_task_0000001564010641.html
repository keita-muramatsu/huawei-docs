Verifying the Configuration

Procedure

  • Run the display dhcpv6 client [ interface interface-type interface-number ] command to check DHCPv6 PD client information.
  • Run the display dhcpv6 client prefix [ name prefix-name ] command to check the IPv6 address prefixes obtained by DHCPv6 PD clients.
  • Run the display dhcpv6 client statistics [ interface interface-type interface-number ] command to check statistics about DHCPv6 PD client messages.
  • Run the display dhcpv6 duid command to check the DUID of the DHCPv6 device.
  • Run the display dhcpv6 client bfd session [ interface interface-type interface-number ] command to check information about dynamic BFD for DHCPv6 sessions.
