Maintaining FEC Statistics

Context

You can run commands to view FEC statistics on a device, including the number of encoding instances, number of decoding instances, encoding rate, decoding rate, and packet loss rates before and after FEC is performed.

Procedure

  • Run the display forward-error-correction statistics [ profile profile-name ] command in any view to check FEC statistics.
  • Run the reset forward-error-correction statistics command in the user view to clear FEC statistics.

    After this command is run, FEC statistics are cleared and cannot be restored.
