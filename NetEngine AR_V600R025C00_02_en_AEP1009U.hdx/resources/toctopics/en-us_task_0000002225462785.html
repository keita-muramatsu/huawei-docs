DHCP Relay

Context

When the device to be configured is on a different network segment from the DHCP server, the DHCP relay function needs to be configured to enable the device to obtain configuration information such as an IP address from the global address pool on the DHCP server.

Procedure

  1. Create a DHCP relay service.
    1. Log in to the web system, choose Config > IP Services > DHCP, and click the DHCP Relay tab. The tab page shown in Figure 1 is displayed.

      Figure 1 DHCP relay

    2. On the DHCP Relay page, click Create and configure the DHCP relay service, as shown in Figure 2. For details about the parameters, see Table 1.

      Figure 2 Creating a DHCP relay service
      Table 1 Creating a DHCP relay service

      Parameter

      Description

      Interface name

      Name of the interface corresponding to the interface address pool of the DHCP server.

      Interface IPv4 Address/Subnet Mask

      Subnet mask of the IP addresses allocated to DHCP clients, that is, the subnet mask of the selected interface.

      Server IPv4 address

      DHCP server IP address allocated to the DHCP client.

    3. Click OK.
  2. Modify a DHCP relay service.

    1. Log in to the web system, choose Config > IP Services > DHCP, and click the DHCP Relay tab.
    2. In the list of configured DHCP relay services, click on the right of the DHCP relay service to be modified. The Modify DHCP Relay page is displayed, as shown in Figure 3.
      Figure 3 Modifying a DHCP relay service
    3. On the Modify DHCP Relay page, set the parameters listed in Table 1.
    4. Click OK.

  3. Delete a DHCP relay service.

    1. Log in to the web system and choose Config > IP Services > DHCP. The DHCP Relay page is displayed.
    2. In the list of configured DHCP relay services, click on the right of the DHCP relay service to be deleted. In the dialog box that is displayed, click OK, as shown in Figure 4.
      Figure 4 Deletion page

  4. Refresh the DHCP relay configuration.

    1. Log in to the web system, choose Config > IP Services > DHCP, click the DHCP Relay tab, and click Refresh to refresh the DHCP relay agent list.
