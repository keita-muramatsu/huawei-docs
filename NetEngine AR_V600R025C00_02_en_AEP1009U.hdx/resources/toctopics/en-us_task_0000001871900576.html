(Optional) Configuring the User Offline Detection Period

Context

If a Portal authentication user goes offline due to a power outage or network interruption, the device and authentication server may retain the user information, leading to problems such as incorrect accounting. In addition, a limited number of users are allowed access to the device. If a user goes offline unexpectedly but the device retains the user information, other users may fail to access the network.

After the offline detection period is set for Portal authentication users, if a user does not respond within the period, the device considers the user offline. The device and authentication server then delete the user information to ensure efficient resource use.

  • This function applies only to Layer 2 Portal authentication.
  • The heartbeat detection function of the authentication server can ensure the normal online status of PC users for whom Layer 3 Portal authentication is used. If the authentication server detects that a user goes offline, it instructs the device to disconnect the user.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the Portal access profile view.

    portal-access-profile name access-profile-name

  3. Configure the offline detection period for Portal authentication users.

    portal timer offline-detect time-length

    By default, the offline detection period is 300 seconds. When the value is set to 0, user offline detection is not performed.
