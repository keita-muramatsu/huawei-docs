Entering the Machine-Machine Mode

Context

Human-machine mode: provides the CLI or web UI for administrators or O&M personnel to configure, monitor, and troubleshoot devices.

Machine-machine mode: is designed for automated communication between devices. Data exchange and collaboration between network devices are implemented using protocols (such as BGP, OSPF, and SNMP) without manual intervention.

The machine-machine mode emphasizes automated collaboration between devices, while the human-machine mode focuses on direct management of devices by users.

By default, a VTY user is in human-machine mode. After you switch to the machine-machine mode, some important commands that you need to use with caution can be run directly. In human-machine mode, users do not need to enter the machine-machine mode unless necessary.

Procedure

  1. Enter the system view.
    system-view
  2. Switch from the human-machine mode to the machine-machine mode.
    mmi-mode enable

    After the mmi-mode enable command is run, intelligent rollback is not supported. After the undo mmi-mode enable or mmi-mode enable matched upper-view command is run, whether intelligent rollback is supported depends on the terminal command forward matched upper-view command.
