Example for Configuring FEC

Network Requirements

On the network shown in Figure 1, DeviceA and DeviceB communicate with each other through Tunnel 1. FEC optimization needs to be performed for traffic sent from DeviceA to DeviceB. The FEC type is D-FEC, and the tunnel type is SD-WAN.

Figure 1 Network diagram of FEC

Configuration Roadmap

The configuration roadmap is as follows:

  1. Configure an FEC service profile and an FEC parameter profile on DeviceA and DeviceB.
  2. Configure an FEC policy on DeviceA and DeviceB.
  3. Apply the FEC policy to Tunnel 1 on DeviceA and DeviceB.
  • This example describes only the roadmap and procedure for configuring FEC. If the tunnel interface uses the SD-WAN encapsulation mode, ensure that the SD-WAN EVPN network configurations have been completed and SD-WAN EVPN site connections have been established. Before configuring FEC, you can run the display evpn connection all command to check the SD-WAN EVPN configurations.
  • For details about how to configure SD-WAN EVPN, see "SD-WAN EVPN Configuration" in VPN Configuration.

Procedure

  1. Configure an FEC service profile on DeviceA and DeviceB.

    # Create an FEC service profile named map1 on DeviceA.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceA
[DeviceA] forward-error-correction
[DeviceA-forward-error-correction] service-map map1
[DeviceA-forward-error-correction-service-map-map1] match acl 3000 application-group videos
[DeviceA-forward-error-correction-service-map-map1] quit

    # Create an FEC service profile named map1 on DeviceB.

    <HUAWEI> system-view
[HUAWEI] sysname DeviceB
[DeviceB] forward-error-correction
[DeviceB-forward-error-correction] service-map map1
[DeviceB-forward-error-correction-service-map-map1] match acl 3000 application-group videos
[DeviceB-forward-error-correction-service-map-map1] quit
  2. Configure an FEC parameter profile on DeviceA and DeviceB.

    # Create an FEC parameter profile named profile1 on DeviceA.

    [DeviceA-forward-error-correction] fec profile profile1
[DeviceA-forward-error-correction-profile-profile1] type determined-fec
[DeviceA-forward-error-correction-profile-profile1] quit

    # Create an FEC parameter profile named profile1 on DeviceB.

    [DeviceB-forward-error-correction] fec profile profile1
[DeviceB-forward-error-correction-profile-profile1] type determined-fec
[DeviceB-forward-error-correction-profile-profile1] quit
  3. Configure an FEC policy on DeviceA and DeviceB.

    # Create an FEC policy named policy1 on DeviceA.

    [DeviceA-forward-error-correction] fec policy policy1
[DeviceA-forward-error-correction-policy-policy1] binding service-map map1 fec-profile profile1 precedence 10
[DeviceA-forward-error-correction-policy-policy1] quit
[DeviceA-forward-error-correction] quit

    # Create an FEC policy named policy1 on DeviceB.

    [DeviceB-forward-error-correction] fec policy policy1
[DeviceB-forward-error-correction-policy-policy1] binding service-map map1 fec-profile profile1 precedence 10
[DeviceB-forward-error-correction-policy-policy1] quit
[DeviceB-forward-error-correction] quit
  4. Apply the FEC policy to Tunnel 1 on DeviceA and DeviceB.

    # Apply the FEC policy on DeviceA.

    [DeviceA] interface Tunnel 1
[DeviceA] tunnel-protocol sd-wan
[DeviceA-Tunnel1] fec-policy policy1

    # Apply the FEC policy on DeviceB.

    [DeviceB] interface Tunnel 1
[DeviceB] tunnel-protocol sd-wan
[DeviceB-Tunnel1] fec-policy policy1

Configuration Scripts

DeviceA
#
sysname DeviceA
#
forward-error-correction
 service-map map1
  match acl 3000 application-group videos
 fec profile profile1
  type determined-fec
 fec policy policy1
  binding service-map map1 fec-profile profile1 precedence 10
#
interface Tunnel 1
 tunnel-protocol sd-wan
 fec-policy policy1
#
return
DeviceB
#
sysname DeviceB
#
forward-error-correction
 service-map map1
  match acl 3000 application-group videos
 fec profile profile1
  type determined-fec
 fec policy policy1
  binding service-map map1 fec-profile profile1 precedence 10
#
interface Tunnel 1
 tunnel-protocol sd-wan
 fec-policy policy1
#
return
