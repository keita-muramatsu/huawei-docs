Example for Configuring Unidirectional CHAP Authentication

Networking Requirements

In Figure 1, serial1/0/0:0 on DeviceA is connected to serial1/0/0:0 on DeviceB.

DeviceA performs simple authentication on DeviceB, while DeviceB does not need to authenticate DeviceA.

Figure 1 Network diagram of CHAP authentication

Configuration Roadmap

  1. Configure CHAP authentication and configure a user name on the authenticator, because the customer requires reliable authentication and high security.
  2. Configure DeviceA as the authenticator and DeviceB as the peer so that unidirectional CHAP authentication is implemented.

Procedure

  1. Configure DeviceA.

    # Configure the access type for the user on DeviceB on DeviceA.

    <HUAWEI> system-view 
[HUAWEI] sysname DeviceA 
[DeviceA] aaa
[DeviceA-aaa] local-access-user sys-admin
[DeviceA-aaa-access-user-sys-admin] service-type ppp
[DeviceA-aaa-access-user-sys-admin] password cipher YsHsjx_202206
[DeviceA-aaa-access-user-sys-admin] quit 
[DeviceA-aaa] quit

    # Configure an IP address for serial1/0/0:0 and configure PPP as the link layer protocol of serial1/0/0:0.

    [DeviceA] interface serial 1/0/0:0
[DeviceA-Serial1/0/0:0] link-protocol ppp
[DeviceA-Serial1/0/0:0] ip address 10.10.10.9 30

    # Configure DeviceA to authenticate DeviceB in CHAP mode.

    [DeviceA-Serial1/0/0:0] ppp authentication-mode chap

    # Configure the user name of DeviceA.

    [DeviceA-Serial1/0/0:0] ppp chap user sys-admin

    # Enable the interface.

    [DeviceB-Serial1/0/0:0] shutdown 
[DeviceA-Serial1/0/0:0] undo shutdown

  2. Configure DeviceB.

    # Configure an IP address for serial1/0/0:0 and configure PPP as the link layer protocol of serial1/0/0:0. 

    <HUAWEI> system-view 
[HUAWEI] sysname DeviceB 
[DeviceB] interface serial 1/0/0:0
[DeviceB-Serial1/0/0:0] link-protocol ppp  
[DeviceB-Serial1/0/0:0] ip address 10.10.10.10 30

    # Configure the user name and password of DeviceB.

    [DeviceB-Serial1/0/0:0] ppp chap user sys-admin 
[DeviceB-Serial1/0/0:0] ppp chap password cipher YsHsjx_202206
[DeviceB-Serial1/0/0:0] shutdown 
[DeviceB-Serial1/0/0:0] undo shutdown

Verifying the Configuration

# Run the display interface serial 1/0/0:0 command to check the interface configuration. If the command output shows that both the physical layer status and link layer status of the interface are up and that both LCP and IPCP are in Opened state, it indicates that PPP negotiation succeeds and DeviceA and DeviceB can communicate with each other.
