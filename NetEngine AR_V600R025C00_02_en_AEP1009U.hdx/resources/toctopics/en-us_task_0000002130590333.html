Load License

Context

You can load licenses to devices on the entire network through the file server.

Procedure

  1. Choose Entire-Network > System Settings. The System Settings page is displayed, as shown in Figure 1.

    Figure 1 System Settings page

  2. Click Load License next to Load License. The Load License dialog box is displayed, as shown in Figure 2.

    Figure 2 Load License dialog box

  3. Set the parameters.

    Table 1 lists the parameters.

    Table 1 Parameters for loading licenses

    Parameter

    Description

    Protocol

    File server where the license file is stored.

    Server address

    IP address of the file server.

    Port

    Port number of the file server.

    Server username

    User name for accessing the file server.

    Server password

    Password for accessing the file server.

    Device

    Device to which the license is to be loaded.

    NOTE:

    Licenses can be loaded only on the following models:

    • AR502H-V2, AR5710-H, AR5710-S, AR6710-H, AR6710-L, and AR8000
    • S3710-H, S5735-L-V2, S5735-S-V2, S5735E-L-V2, S5735E-S-V2, S5735I-H-V2, S5735I-L-V2, S5735I-S-V2, S5735R-L-V2, S5735R-S-V2, S5755-H, S5755-S, S5755E-H, S6730-H-V2, S6730E-H-V2, S6750-H, S6750-S, S6750E-S, and S6780-H
    • S5535-L-V2 and S5535-S-V2
    • S8700
    • S12700H

    License file name

    License file to be loaded.

  4. Click OK.
