Configuring Overhead Bytes

Context

The POS interfaces provided by different vendors require different overhead byte settings. When configuring POS interfaces, you must ensure that the overhead bytes C2, J0, and J1 on both ends are the same. Otherwise, interconnection fails.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the POS interface view.

    interface pos interface-number

  3. Configure overhead bytes for the POS interface.

    flag j0 { 1byte-mode j0trace | 16byte-mode trace16 | 64byte-mode trace64 }
flag j1 { 1byte-mode j1trace | 16byte-mode trace16 | 64byte-mode trace64 }
flag c2 c2value

    By default, the overhead byte C2 of an interface is 22, and J0 and J1 are empty strings.
