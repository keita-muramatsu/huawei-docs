Online Behavior Management

Context

You can configure user bandwidth limiting to limit the bandwidth occupied by non-key services on the network, preventing these services from consuming a large number of bandwidth resources and affecting other services.

Procedure

  1. Configure a user bandwidth limit.
    1. Log in to the web system and choose Config > QoS > Network Behavior Management. The page shown in Figure 1 is displayed.

      Figure 1 Online behavior management

    2. Click Create. The User Bandwidth Limit Setting page is displayed, as shown in Figure 2. For details about the parameters, see Table 1.

      Figure 2 Configuring a user bandwidth limit

      Table 1 Parameters for configuring a user bandwidth limit

      Item

      Description

      Interface name

      Name of an interface on which rate limiting is performed.

      Direction
      Direction in which user bandwidth is limited. The values are as follows:
      • Inbound: limits the rate of incoming packets on the interface.
      • Outbound: limits the rate of outgoing packets on the interface.

      Rate limiting type
      Type of the user bandwidth limit. The options are as follows:
      • Source IP address rate limit: limits the rate of packets from a specified source IP address segment.
      • Destination IP address rate limit: limits the rate of packets to a specified destination IP address segment.

      IP address segment

      Source or destination IP address segment.

      Type

      Type of the bandwidth shared by packets from or to a source or destination IP address segment. The values are as follows:

      • Shared: Packets from or to the specified source or destination IP address segment share the configured bandwidth.
      • Exclusive: Packets from or to each IP address in the specified source or destination IP address segment exclusively use the configured bandwidth.

      Effective time

      Time when the bandwidth limit takes effect.

      CIR (kbps)

      Committed information rate (CIR), that is, the average rate at which traffic can pass through.

    3. (Optional) Set Effective time to specify the time when the bandwidth limit takes effect.

      1. On the User Bandwidth Limit Setting page, click on the right of Effective time to set the time when the bandwidth limit takes effect, as shown in Figure 3.
        Figure 3 Setting the effective time
      2. Click Create to create an effective time range, as shown in Figure 4. For details about the parameters, see Table 2.
        Figure 4 Creating an effective time range
        Table 2 Creating an effective time range

        Item

        Description

        Time range name

        Name of an effective time range.

        Weekly Time Range

        Weekly effective time

        Weekly effective time.

        Start time and end time

        Daily effective time range.

        Validity Time Range

        Start time and end time

        Start time and end time.
      3. Click OK.

    4. Click OK.
  2. Modify a user bandwidth limit.
    1. Log in to the web system and choose Config > QoS > Network Behavior Management.
    2. In the list of configured user bandwidth limits, click in the Operation column. The User Bandwidth Limit Setting page is displayed, as shown in Figure 5.

      Figure 5 Modifying a user bandwidth limit

    3. On the User Bandwidth Limit Setting page, modify one or more of the following parameters: Type, Effective time, and CIR (kbps).
    4. Click OK.
  3. Delete a user bandwidth limit.
    1. Log in to the web system and choose Config > QoS > Network Behavior Management.

    1. Under User Bandwidth Limit, click in the Operation column. In the dialog box that is displayed, click OK to delete the corresponding user bandwidth limit, as shown in Figure 6.
      Figure 6 Deletion page

  4. Refresh the user bandwidth limit list.

    1. Log in to the web system, choose Config > QoS > Network Behavior Management, and click Refresh to refresh the user bandwidth limit list.
