Configuring the CRC Code Length

Context

Cyclic redundancy check (CRC) is often used to detect transmission errors in a communication system. It checks for transmission errors by adding redundancy check code to the original data. When more redundancy check bits are added, transmission errors are more likely to be detected, but data is transmitted at a lower efficiency.

When configuring POS interfaces, you must ensure that the same CRC code length is configured on both ends. Otherwise, interconnection fails.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the POS interface view.

    interface pos interface-number

  3. Configure the CRC code length for the POS interface.

    crc { 16 | 32 }

    By default, the CRC code length is 32 bits.
