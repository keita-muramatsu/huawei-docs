Tearing Down an L2TP Tunnel and Session Connection

Context

When there are no access users, a network fault occurs, or an L2TP connection needs to be torn down, you can manually tear down the specified L2TP tunnel or session connection. After the L2TP tunnel or session connection is manually torn down, all L2TP users using the L2TP tunnel or session connection are disconnected.

After an L2TP tunnel is torn down, all control and session connections over the tunnel are removed. After a period of time, the tunnel and session connections are automatically reestablished.

Procedure

  • Run the reset l2tp tunnel { all | tunnel-id tunnel-id | peer-name remote-name } command to tear down a specified L2TP tunnel and all session connections over the tunnel.
  • Run the reset l2tp session { all | session-id session-id } command to tear down a specified L2TP session.
