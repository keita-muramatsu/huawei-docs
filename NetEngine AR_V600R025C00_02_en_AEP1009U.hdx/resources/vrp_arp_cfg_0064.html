Configuring a Device to Log a Received ARP Probe Packet Whose Destination Address Is the Same as the Local Interface Address

Context

As defined in RFC, an ARP probe packet is a special ARP request packet whose source IP address is 0 and destination IP address is the IP address to be probed. Currently, Huawei devices do not proactively send ARP probe packets but do receive them. If the destination IP address of a received ARP probe packet is the same as the local interface IP address, the receiver does not determine that this is an address conflict. Such packets are not logged by default in order to reduce the false reporting of conflict alarm logs and to improve maintenance efficiency.

Procedure

  1. Enter the system view.

    system-view

  2. Configure the device to log a received ARP probe packet whose destination address is the same as the local interface address.

    arp probe packet log enable
