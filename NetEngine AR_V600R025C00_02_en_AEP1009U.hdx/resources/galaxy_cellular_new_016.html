Searching for and Selecting a PLMN

Context

Some SIM cards can access multiple PLMNs (that is, multiple carrier networks), and users can select one PLMN for access as needed.

By default, a device automatically connects to the most appropriate PLMN, considering factors such as the PLMN that the SIM card belongs to and the wireless network signal strength. When the device needs to connect to a specific PLMN, for example, when it uses a SIM card that can simultaneously access wireless networks of multiple carriers, you can specify the PLMN. This prevents the device from switching between different carriers based on the signal strength and incurring additional fees. A PLMN needs to be configured in a cellular profile, and you can search for a PLMN only on a cellular interface.

Procedure

  1. Enter the system view.

    system-view

  2. Enter the cellular interface view.

    interface cellular interface-number

  3. Search for a PLMN.

    plmn search

  4. Return to the system view.

    quit

  5. Check the last PLMN search result.

    display { interface-type interface-number | interface-name } plmn search result

  6. Enter the cellular profile view.

    cellular-profile profile-name

  7. Configure manual PLMN selection for the modem.

    plmn select manual mcc mnc [ fail-over-auto ]

    By default, a PLMN is automatically selected.
