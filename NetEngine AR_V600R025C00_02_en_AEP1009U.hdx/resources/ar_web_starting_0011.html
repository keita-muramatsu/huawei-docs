Common Control Operations

There are two common styles of the operation area on the web UI. One is that the administrator can directly set parameters in the operation area by using buttons, drop-down list boxes, and text boxes. The other is that the administrator can configure multiple items and then manage the items in a list on the GUI.

Table 1 describes the functions of common buttons.
