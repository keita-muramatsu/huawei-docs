Configuring Smart Upgrade

Prerequisites

Before performing a smart upgrade, ensure that there are reachable routes between the device and HOUP server.

The basic software package contains the initial certificate HOUP_Actalis_CA.cer. When loading the basic software package, the device automatically saves the certificate to the flash:/pki/public directory. If the certificate does not exist or has expired, perform the following operations to obtain or update the certificate:
  1. Download the certificate: Click https://houp.huawei.com/download/public/houp.huawei.com.zip to download the certificate.
  2. Upload the certificate: Upload the certificate to the flash:/pki/public directory of the device through FTP or SFTP. For details, see Managing Files Using FTP/Managing Files Using SFTP. SFTP is recommended because it is more secure than FTP.

Context

The smart upgrade function enables a device to obtain upgrade files from Huawei HOUP and upgrade of the device in one-click or scheduled mode. This simplifies upgrade operations and reduces upgrade maintenance costs.

  • The device encrypts the contact information and reports it to the HOUP through HTTPS. During this process, the device and HOUP may obtain the contact information for authorized purposes. To ensure that contact information is fully protected, users should define privacy policies and take effective security measures in accordance with relevant country-specific laws and regulations.
  • If HOUP is unavailable, the smart upgrade function cannot be used.
  • If the space is insufficient during the space pre-check, the system determines whether historical software packages can be deleted based on the file name extension information in the list of software packages to be downloaded. (Historical software packages with the same file name extension and not protected can be deleted. Protected software packages include the current system software package, whitelisted packages, and packages to be downloaded.) If the space is sufficient, the software packages are downloaded. If the space is insufficient, the software packages are deleted while being downloaded.

Procedure

  1. Enter the system view.

    system-view

  2. Import the initial CA certificate to the default domain.

    pki import-certificate ca realm default pem filename HOUP_Actalis_CA.cer

    By default, the HOUP_Actalis_CA.cer certificate is not loaded to the default domain.

  3. Enter the smart upgrade view.

    smart-upgrade

  4. Configure the device to communicate with the HOUP server.

    Ensure that there are reachable routes between the device and HOUP server, and configure the URL and HTTPS port number of the HOUP server on the device. In this way, the smart upgrade function enables the device to connect to the HOUP server and obtain the files required for the upgrade.

    To ensure the security of smart upgrade, the device supports the configuration of CA certificate authentication and CN/SAN verification for the server.

    1. Configure a URL for the server. (To protect user privacy, related information may be anonymized.)
      http url host [ source { { ip ip-addr vpn vpn-name } | { interface { ifname | interface-type interface-num } } } ]
    2. (Optional) Configure an HTTPS port number for the server.
      http port port-value
    3. Bind an SSL policy.
      1. Exit the smart upgrade view.
        quit
      2. Create an SSL policy.
        ssl policy policy-name
      3. Bind the default PKI realm to the SSL policy.
        pki-domain default
      4. Exit the SSL policy view.
        quit
      5. Enter the smart upgrade view.
        smart-upgrade
      6. Bind an SSL policy.
        http ssl-policy policy-name
    4. (Optional) Disable the server certificate verification function.
      If the CA certificate for smart upgrade is invalid or no certificate is available, you can disable the server certificate verification function, but the SSL policy is still needed.
      http verify-server disable
    5. (Optional) Enable CN/SAN verification.
      http verify-dns enable

      By default, CN/SAN verification is disabled.

      If server certificate authentication is disabled, CN/SAN verification is not performed even if the function is enabled.

  5. (Optional) Check whether the HOUP has the system software that can be upgraded.

    check new-version

  6. (Optional) Download the system software.

    The download function in smart upgrade supports two download modes: scheduled download and manual download.

    • Scheduled download
      download scheduled scheduled-time scheduled-time-val { system-software | patch | feature-software { feature-name } &<1-9> } *
    • Manual download
      download software [ version software-version ]

      If version software-version is specified, the system software package of the specified version is downloaded from the HOUP.

      If version software-version is not specified, all system software packages (basic software package, patch package, and feature package) of the recommended version are downloaded from the HOUP.

  7. Set the smart upgrade mode.

    A smart upgrade can be triggered manually or at a scheduled time. You can select either or two of the following upgrade modes based on network maintenance requirements:

    • Configure a smart upgrade to be triggered at a scheduled time.
      1. Upgrade a specified software package periodically.
        upgrade-time { weekly week-day week-day-value | monthly month-day month-day-value | yearly date start-day-value } time action-time-value
      2. Upgrade a specified software package at a specified time.
        upgrade scheduled scheduled-time scheduled-time-val { system-software | patch | feature-software { feature-name } &<1-9> } *
    • Configure a smart upgrade to be manually triggered instantly.
      upgrade right-now [ system-software ] [ patch ] [ feature-software { feature-name } &<1-9> ]

Verifying the Configuration

After the smart upgrade configuration is complete, run the display smart-upgrade information command to check the configuration, upgrade version, upgrade status, and local information of the smart upgrade.

Follow-up Procedure

For a feature package downloaded from the HOUP by running the download software version software-version command, if the package has not been installed, you can run the install feature-software command in the user view to install it. For details, see "Configuring a Feature Software Package" in CLI Configuration Guide > Upgrade Maintenance Configuration.
